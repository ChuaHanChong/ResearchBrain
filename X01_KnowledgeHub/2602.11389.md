# Causal-JEPA: Learning World Models through Object-Level Latent Interventions

> [!summary] Summary
> Causal-JEPA presents an object-centric world model integrating Joint Embedding Predictive Architectures (JEPAs) with object-level latent interventions, fostering interaction-dependent dynamics learning and efficient planning. It improves counterfactual reasoning accuracy by approximately 20% and accelerates model predictive control planning by over 8 times.

## Problem

- Existing object-centric world models often fail to inherently capture interaction-dependent dynamics, instead relying on learning object self-dynamics or incidental correlations.
- Traditional masked prediction methods (e.g., patch-based) do not explicitly enforce object-level interaction reasoning and can be computationally inefficient for complex dynamic environments.
- World models require a deeper, more robust relational understanding for accurate prediction and control, which is not sufficiently induced by current learning objectives alone.

## Method

- Causal-JEPA leverages a frozen object-centric encoder (e.g., VideoSAUR, SAVi) to transform high-dimensional observations into compact sets of object-level latent representations.
- It employs a ==Joint Embedding Predictive Architecture (JEPA)==-style masked transformer as the core predictor, operating on these object latents and auxiliary variables (actions, proprioception).
- A central innovation is the application of ==object-level masking== as a latent intervention, replacing masked object states with an 'identity anchor' from an earlier timestep to force inference based on interactions with other objects.

## Results

- Achieved an absolute improvement of approximately **20%** in counterfactual visual question answering accuracy on the CLEVRER dataset, demonstrating enhanced causal understanding.
- Attained comparable task success rates to state-of-the-art patch-based world models on the Push-T robotic manipulation task, while enabling over **8 times faster** planning.
- Operated on only **1.02%** of the input features compared to patch-based models, leading to substantial computational efficiency during Model Predictive Control.

## Takeaways

> [!tip] Key Insights
> - Object-level masking, interpreted as a latent intervention, induces a causal inductive bias that compels the model to learn stable, interaction-dependent predictive relationships.
> - The masked history prediction objective formally necessitates reliance on a 'minimal sufficient set of contextual variables' (Influence Neighborhood) for optimal inference, making interaction reasoning functionally essential.
> - Integrating object-centric representations with JEPAs enables efficient world modeling by operating on a significantly reduced latent feature space, without sacrificing performance.
