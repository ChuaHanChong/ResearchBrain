# NORA: A Small Open-Sourced Generalist Vision Language Action Model for Embodied Tasks

> [!summary] Summary
> A 3B-parameter Vision-Language-Action model combines Qwen-2.5-VL-3B with FAST+ tokenization to enable real-time robotic control on consumer GPUs, achieving comparable or better performance than larger models across simulation and real-world robot manipulation tasks while reducing computational requirements by 57%.

## Problem

- Existing VLA models (7B+ parameters) are too computationally intensive for real-time robotics applications
- Current approaches struggle with visual encoding and action generation for precise manipulation tasks

## Method

- Leverage ==Qwen-2.5-VL-3B=='s visual-semantic capabilities with augmented ==action tokens==
- Implement **FAST+** tokenization for efficient action sequence generation
- Optimize training with ==FlashAttention== and ==bf16 precision==

## Results

- Outperforms baseline models on out-of-domain object grasping tasks
- Achieves comparable performance to OpenVLA on LIBERO benchmark tasks
- Runs effectively on consumer GPUs with **57%** lower computational overhead
- Demonstrates robust generalization across diverse manipulation scenarios

## Takeaways

> [!tip] Key Insights
> - Action chunking improves performance in simulation but creates challenges in real-world settings
> - Visual encoding quality significantly impacts manipulation success rates
> - Model size can be reduced while maintaining task performance through targeted architecture choices
