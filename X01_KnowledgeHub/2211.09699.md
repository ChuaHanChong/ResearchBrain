# PromptCap: Prompt-Guided Task-Aware Image Captioning

> [!summary] Summary
> PROMPTCAP introduces an image captioning model that generates question-aware captions, tailoring visual descriptions for black-box Large Language Models. This approach achieved 60.4% accuracy on OK-VQA and 73.1% on A-OKVQA, outperforming prior methods by providing task-relevant visual context.

## Problem

- Black-box Large Language Models (LLMs) require visual information to be converted into text, but generic image captions often lack task-specific details.
- Generic image captions, used as context for LLMs in Visual Question Answering (VQA), often omit crucial visual information needed to answer specific questions.
- Developing datasets of task-aware captions typically requires costly and time-consuming human annotation.

## Method

- Introduces PROMPTCAP, an image captioning model based on a pre-trained ==OFA encoder-decoder Transformer==, which generates captions conditioned on both an image and a ==natural language prompt (question)==.
- Develops an innovative ==data synthesis pipeline== leveraging GPT-3 with few-shot in-context learning to create question-aware caption training data from existing VQA datasets.
- Implements a ==two-stage filtering process== for synthesized captions, using VQA accuracy and CIDEr scores to ensure quality.

## Results

- PROMPTCAP + GPT-3 achieved **60.4%** accuracy on OK-VQA and **73.1%** on A-OKVQA (multiple-choice), outperforming prior methods on knowledge-based VQA benchmarks.
- Ablation studies showed PROMPTCAP provided an absolute accuracy gain of **3.8%** on OK-VQA, **5.3%** on A-OKVQA, and **9.2%** on VQAv2 compared to generic captioning.
- The system demonstrated strong generalization, outperforming supervised baselines on the WebQA benchmark without specific training.

## Takeaways

> [!tip] Key Insights
> - Providing Large Language Models with prompt-guided, task-aware image captions substantially improves their performance on knowledge-based Visual Question Answering tasks.
> - High-quality training data for specific visual-linguistic tasks can be synthesized cost-effectively using powerful black-box LLMs and few-shot in-context learning.
> - The selection of in-context examples using similarity metrics is crucial for maximizing the performance of black-box LLMs in multimodal inference.
