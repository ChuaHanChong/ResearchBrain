# Vision as LoRA

> [!summary] Summary
> Vision as LoRA (VoRA), developed by ByteDance, proposes an encoder-free architecture for Multimodal Large Language Models (MLLMs) by internalizing vision capabilities directly into LLMs using mergeable LoRA layers. This approach achieves performance comparable to encoder-based models with near-zero additional inference cost and supports arbitrary image resolutions, all while demonstrating stable and data-efficient training through block-wise distillation and bi-directional attention for vision.

## Problem

- Existing encoder-based Multimodal Large Language Models (MLLMs) suffer from high computational and memory overhead due to separate vision encoders, along with fixed-resolution constraints and sequential processing.
- Prior encoder-free MLLMs struggle with modality conflicts and catastrophic forgetting when trying to learn both language and vision within a single LLM, often requiring parameter expansion that doubles model size during inference.
- Teaching an LLM to understand vision from scratch is data-intensive and slow, and traditional attention mechanisms in LLMs (causal masks) are not optimal for global visual context understanding.

## Method

- Introduces =="Vision as LoRA" (VoRA)==, integrating ==LoRA layers== into the first N_vit blocks of an LLM to decouple vision-specific parameters, which are then merged into the base LLM weights post-training for inference efficiency.
- Employs a ==block-wise distillation paradigm== to transfer visual knowledge from a pre-trained Vision Transformer (ViT) to the LLM by aligning intermediate representations of each LLM block with corresponding ViT features.
- Adapts the LLM's attention mechanism by using ==bi-directional attention masks for visual tokens== to enable comprehensive spatial context understanding, while retaining causal masks for text tokens.

## Results

- VoRA achieved performance comparable to official and reproduced LLaVA-1.5 baselines (encoder-based models) across a wide range of standard benchmarks, including VQAv2, SQA-I, TextVQA, and MMBench, demonstrating an LLM can acquire native multimodal capabilities without an external vision model.
- Ablation studies confirmed that LoRA-based parameter decoupling successfully stabilized training, and the combination of bi-directional attention masks and block-wise distillation significantly improved data efficiency, requiring only 64.5% of the training steps to reach a comparable loss compared to a vanilla LoRA baseline.
- The LoRA parameters are mergeable into the base LLM weights post-training, eliminating additional computational cost and memory overhead during inference, making VoRA highly efficient for deployment.

## Takeaways

> [!tip] Key Insights
> - LoRA-based parameter decoupling within an LLM effectively stabilizes training and prevents catastrophic forgetting when introducing visual modalities, critically, without incurring additional inference-time overhead.
> - Block-wise knowledge distillation from a pre-trained Vision Transformer significantly accelerates visual learning in the LLM and improves data efficiency by transferring fine-grained visual priors.
> - Employing bi-directional attention masks for visual tokens within the LLM enhances the model's ability to capture comprehensive spatial and contextual relationships in images, improving performance.
