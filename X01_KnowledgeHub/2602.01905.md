# Learning Sparse Visual Representations via Spatial-Semantic Factorization

> [!summary] Summary
> STELLAR introduces Spatial-Semantic Factorization to learn sparse visual representations, resolving the "Invariance Paradox" by disentangling semantic concepts from spatial locations. The method achieves a unified representation that simultaneously excels at high-level semantic understanding (e.g., 79.10% ImageNet linear accuracy for ViT-H) and low-level pixel reconstruction (e.g., 2.60 FID for ViT-H), reducing latent representation size by up to 90%.

## Problem

- The "Invariance Paradox" in self-supervised learning, where representations optimized for semantics often lose spatial precision, and vice-versa.
- A lack of unified visual representations that can simultaneously achieve state-of-the-art performance in both high-level semantic understanding and low-level pixel reconstruction.
- Current self-supervised learning (SSL) paradigms diverge, with Joint Embedding methods prioritizing semantics and Masked Image Modeling methods focusing on reconstruction, failing to combine these strengths effectively.

## Method

- Introduces ==Spatial-Semantic Factorization==, representing an image as a low-rank product of a sparse ==Semantic Matrix (S)== for 'what' and a ==Localization Matrix (L)== for 'where'.
- Employs a ==multi-objective self-supervised training scheme== combining reconstruction loss, vision concept clustering loss, and set concepts alignment loss to structure and align sparse tokens.
- Uses a standard Vision Transformer (ViT) as an encoder augmented with learnable latent queries to produce sparse semantic tokens, and a lightweight ViT for decoding.

## Results

- Achieves a balance of **73.26%** ImageNet linear accuracy and a **3.06** FID score (ViT-B), outperforming baselines in semantics while matching MAE's reconstruction quality with **90%** latent size reduction.
- Demonstrates strong performance in fine-grained semantic segmentation, with STELLAR ViT-H achieving **36.66** mIoU on ADE20K, competitive with MAE-H and close to DINOv2-B.
- Empirically validates the resolution of the Invariance Paradox, showing semantic tokens (S) remain invariant under pixel shifts, while localization tokens (L) change equivariantly.

## Takeaways

> [!tip] Key Insights
> - The Invariance Paradox can be resolved by explicitly disentangling semantic (invariant) and spatial (equivariant) information within a factorized latent representation.
> - A sparse, low-rank representation (e.g., 16 tokens for ViT-B) can maintain a strong balance between reconstruction fidelity and semantic richness, despite significantly reducing latent dimensionality.
> - Multi-objective training with reconstruction, clustering, and optimal transport-based alignment is crucial for learning robust, view-invariant semantic concepts and holistic sparse tokens.
