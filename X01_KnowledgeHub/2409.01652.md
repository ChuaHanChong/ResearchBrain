# ReKep: Spatio-Temporal Reasoning of Relational Keypoint Constraints for Robotic Manipulation

> [!summary] Summary
> ReKep enables robots to perform diverse, multi-stage manipulation tasks in unstructured environments by automatically generating visually-grounded relational keypoint constraints from language instructions using foundation models. The system demonstrates robust real-time execution and zero-shot generalization across various complex behaviors, outperforming baseline methods on real-world robot platforms.

## Problem

- Existing constraint formulations for robotic manipulation often lack versatility for diverse, complex tasks, including multi-stage, in-the-wild, and bimanual operations.
- Manually specifying constraints, object models, or annotating keypoints for every new task is time-consuming and does not scale.
- Generated constraints must be in a format that allows off-the-shelf optimization solvers to produce real-time robot actions for continuous, closed-loop control.

## Method

- Introduces **ReKep** (==Relational Keypoint Constraints==), defined as Python functions encoding spatial relationships between ==3D keypoints==, which are used as ==cost functions== for manipulation.
- Employs a ==hierarchical optimization procedure==, decomposing tasks into 'sub-goal' and 'path' problems, solved in real-time (10 Hz) using off-the-shelf ==numerical solvers==.
- Automates keypoint proposal using ==DINOv2== and ==SAM== from RGB-D inputs, and leverages ==GPT-4o== to generate the ReKep Python functions directly from free-form language instructions and visual prompts.

## Results

- Achieved a **44.3%** total success rate across seven diverse real-world manipulation tasks, outperforming a VLM-based baseline (VoxPoser, **10.0%**) and demonstrating robustness to disturbances.
- Successfully generalized to novel manipulation strategies for **8** unique garment categories, achieving a **73.8%** execution success rate when the VLM generated a feasible strategy.
- Identified point tracking inaccuracies (due to occlusions) as the primary source of system failures, while the optimization module proved relatively robust.

## Takeaways

> [!tip] Key Insights
> - Visually-grounded keypoint constraints, automatically generated by VLMs, offer a versatile and scalable representation for complex robotic manipulation tasks.
> - A hierarchical, receding-horizon optimization framework enables real-time, reactive control, allowing robots to adapt to disturbances and execute multi-stage behaviors.
> - Leveraging foundation models (DINOv2 for keypoints, GPT-4o for constraint generation) automates the traditionally manual process of constraint specification, significantly reducing engineering effort.
