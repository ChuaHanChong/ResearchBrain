# Helping CLIP See Both the Forest and the Trees: A Decomposition and Description Approach

> [!summary] Summary
> Researchers from Tianjin University and collaborators developed 'Decomposition and Description' (D&D), a method to enhance Vision-Language Models like CLIP by integrating fine-grained local visual semantics with detailed textual descriptions. D&D achieves an average top-1 accuracy improvement of 1.85% in zero-shot classification and up to 1.95% in test-time adaptation over strong baselines.

## Problem

- Vision-Language Models (VLMs) like CLIP exhibit a strong inherent bias towards global image patterns, hindering their effective processing of fine-grained local semantics.
- A widely held assumption that VLMs inherently recognize local visual details when provided with descriptive text was found to be flawed.
- Existing VLM adaptation strategies struggle to effectively integrate both global image patterns and fine-grained local attributes for improved understanding.

## Method

- Introduces =="Decomposition and Description" (D&D)==, a plug-and-play approach that decomposes images into multiple stochastic local regions using ==multi-crop augmentation==.
- Utilizes Large Language Models (LLMs) to generate sets of fine-grained textual descriptors for each candidate class.
- Employs ==Earth Mover's Distance (EMD)== to compute set-level similarity between the set of local visual features and the set of textual descriptors, finding optimal latent correspondences.

## Results

- Achieved an average top-1 accuracy of **60.62%** in zero-shot classification across 11 datasets, representing a **1.85%** improvement over Zero-Shot CLIP and **1.17%** over CALIP.
- Improved few-shot learning performance, reaching an average top-1 accuracy of **71.46%** (16-shot setting) when integrated with Tip-Adapter, surpassing original Tip-Adapter by **1.14%**.
- Attained state-of-the-art test-time adaptation, outperforming the strongest baseline TDA by **1.95%** (**69.48%** vs. **67.53%** average accuracy with ViT-B/16 backbone) across cross-domain benchmarks, with a notable **+27.87%** on Aircraft.

## Takeaways

> [!tip] Key Insights
> - Empirical evidence disproves the common assumption that VLMs inherently process fine-grained local details, revealing a fundamental bias towards global semantics.
> - Explicitly decomposing visual inputs into local regions and aligning them with detailed textual descriptions via EMD effectively activates CLIP's latent capacity for localized feature analysis.
> - The D&D method is highly adaptable and can be integrated into existing VLM adaptation paradigms (zero-shot, few-shot, test-time adaptation) without architectural modifications.
