# Language Agent Tree Search Unifies Reasoning Acting and Planning in Language Models

> [!summary] Summary
> Language Agent Tree Search (LATS) unifies reasoning, acting, and planning capabilities in language models by adapting Monte Carlo Tree Search to incorporate external environmental feedback and LM-powered self-reflection. The framework achieves competitive or state-of-the-art results across diverse tasks, including reaching 92.7% Pass@1 accuracy on HumanEval and improving performance on interactive question answering and web navigation.

## Problem

- Existing LM-based reasoning methods (e.g., CoT, ToT) primarily rely on internal knowledge, often leading to factual hallucinations, error propagation, and an inability to incorporate real-time external feedback.
- Current LM acting methods (e.g., ReAct, Reflexion) are 'reflexive', exploring only a single trajectory at a time and lacking deliberate multi-path planning or deep lookahead in combinatorial action spaces.
- There was no single general framework that effectively unified reasoning, acting, and sophisticated planning while robustly incorporating continuous external feedback and self-reflection in language models.

## Method

- ==Language Agent Tree Search (LATS)== unifies reasoning, acting, and planning by framing problem-solving as a tree search, where each node represents a state with a history of actions and observations.
- It adapts ==Monte Carlo Tree Search (MCTS)== with six core operations: Selection (using UCT), Expansion (sampling multiple LM actions and executing them in the environment), Simulation, and Backpropagation.
- LATS introduces a novel ==LM-powered value function== that combines an LM's self-generated correctness score with a self-consistency score, and incorporates ==LM-generated self-reflection== for strategy refinement based on failures.

## Results

- Achieved **0.71** Exact Match (EM) on HotPotQA using GPT-3.5, outperforming strong baselines like ReAct (**0.32 EM**) and Reflexion (**0.51 EM**) by unifying CoT and ReAct prompting.
- Attained **92.7%** Pass@1 accuracy on HumanEval with GPT-4 and **83.8%** with GPT-3.5, surpassing Reflexion (**91.0%** and **68.1%** respectively) and demonstrating the value of external test suite feedback.
- Secured an average score of **75.9** and a **38.0%** success rate on WebShop with GPT-3.5, outperforming prompting-based methods (ReAct: **53.8** score, **28.0 SR**) and achieving competitive performance against fine-tuning approaches without additional model training.

## Takeaways

> [!tip] Key Insights
> - Monte Carlo Tree Search (MCTS) can be effectively adapted for language agents because many LM tasks allow convenient reversion to earlier states, bypassing a common challenge for model-free MCTS.
> - Pre-trained Large Language Models (LMs) can function not only as decision-makers but also as sophisticated heuristic state evaluators and self-reflection generators within a search framework, providing a 'semantic gradient signal'.
> - Unifying reasoning, acting, and planning with continuous external feedback and self-correction allows LMs to engage in deliberate, multi-path exploration, moving beyond greedy, reflexive problem-solving.
