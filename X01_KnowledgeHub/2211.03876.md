# CoNMix for Source-free Single and Multi-target Domain Adaptation

> [!summary] Summary
> CoNMix, developed by researchers at the Indian Institute of Science, introduces a three-stage framework for source-free single and multi-target domain adaptation, leveraging Vision Transformers and MixUp knowledge distillation. The method establishes new state-of-the-art performance for source-free single-target domain adaptation and provides the first comprehensive baselines for the novel source-free multi-target domain adaptation task, demonstrating robust generalization across various datasets.

## Problem

- Deep learning models trained on a source domain perform poorly when data distribution shifts in a target domain (domain shift).
- Traditional domain adaptation methods require access to labeled source data during adaptation, posing challenges due to privacy concerns and resource constraints on edge devices.
- Existing research lacked a robust solution for adapting a model from a single source to multiple diverse target domains simultaneously without source data (Source-Free Multi-Target Domain Adaptation).

## Method

- The CoNMix framework consists of three stages: source training with Vision Transformers, ==source-free single-target domain adaptation (SF-STDA)== for individual target domains, and ==source-free multi-target domain adaptation (SF-MTDA)== to consolidate knowledge.
- For SF-STDA, the method employs ==Nuclear-Norm Maximization== to improve class-discriminability and prediction-diversity, combined with pseudo-label refinement and a consistency loss using data augmentations.
- For SF-MTDA, a novel ==MixUp Knowledge Distillation== technique is used to distil knowledge from multiple target-specific "expert teacher" models (generated in SF-STDA) into a single student network capable of generalizing across all target domains.

## Results

- Achieved state-of-the-art results in Source-Free Single-Target Domain Adaptation (SF-STDA), improving average accuracy on Office-Home to **76.0%** and showing a **6.0%** improvement over existing SOTA on DomainNet.
- Established the first comprehensive baselines for Source-Free Multi-Target Domain Adaptation (SF-MTDA), outperforming existing non-source-free MTDA methods like D-CGCT by **5.6%** on Office-Home (**75.4%** average accuracy).
- CoNMix achieved a new SOTA for MTDA on Office-Caltech at **96.9%** and provided the first SF-MTDA results for the large-scale DomainNet dataset, achieving an average accuracy of **33.7%**.

## Takeaways

> [!tip] Key Insights
> - Vision Transformers (VTs) are empirically shown to provide superior feature representations for domain adaptation compared to CNNs, exhibiting better domain transferability and class-discriminative features.
> - Nuclear-Norm Maximization is a critical component for effective source-free adaptation, enhancing both class-discriminability and prediction diversity on unlabeled target data, especially when combined with pseudo-label refinement.
> - MixUp Knowledge Distillation effectively enables a single student model to generalize across multiple diverse target domains in a source-free setting by leveraging mixed inputs and pseudo-labels from domain-specific teacher models.
