# SPHINX: A Synthetic Environment for Visual Perception and Reasoning

> [!summary] Summary
> SPHINX is a new synthetic environment designed by researchers at RIT and the University of Washington to evaluate and advance visual perception and reasoning in Large Vision-Language Models (LVLMs). It features 25 procedurally generated task types with verifiable ground truth, revealing that state-of-the-art LVLMs achieve only 51.1% accuracy compared to 75.4% for humans, and demonstrating that Reinforcement Learning with Verifiable Rewards (RLVR) significantly improves LVLM performance and generalization.

## Problem

- Large Vision-Language Models (LVLMs) significantly lag behind Large Language Models (LLMs) in complex reasoning tasks, particularly those involving genuine visual understanding.
- Existing multimodal benchmarks often prioritize perception-focused tasks, allow models to bypass true visual reasoning, or lack systematic evaluation of fundamental cognitive primitives essential for fluid intelligence.
- There is a need for scalable, diverse, and verifiable datasets to thoroughly diagnose LVLM limitations and facilitate advanced training paradigms like reinforcement learning.

## Method

- SPHINX introduces a novel ==synthetic environment== with a modular, programmatic framework capable of generating diverse visual reasoning data through factorized control of appearance (motifs), spatial layout (tilings), and reasoning rules (tasks).
- It features **25** distinct task types categorized into five broad families (Geometric Reasoning, Counting, Symmetry & Pattern Recognition, Sequence & Transformation, Topological & Graph Reasoning), each with a ==deterministic checker== for unambiguous ground-truth answers.
- The environment includes =='difficulty knobs'== for precise control over problem complexity, enabling tailored dataset generation and making it suitable for ==Reinforcement Learning with Verifiable Rewards (RLVR)==.

## Results

- State-of-the-art proprietary LVLMs like GPT-5 achieved only **51.1%** accuracy across SPHINX's 25 tasks, notably lower than human performance at **75.4%**.
- RLVR consistently improved performance on in-distribution SPHINX tasks and demonstrated generalization, with RL-trained models showing an average accuracy improvement across eight external visual reasoning benchmarks (e.g., **+2.8%** for Qwen3-VL-8B).
- Model accuracy consistently decreased as task complexity increased across all evaluated models, validating SPHINX's ability to provide a tunable difficulty axis for evaluation.

## Takeaways

> [!tip] Key Insights
> - Current state-of-the-art LVLMs, including powerful proprietary models, still exhibit significant gaps in fundamental visual reasoning capabilities compared to human performance, especially in tasks requiring accurate low-level visual extraction and counting.
> - The modular design and verifiable ground truth of SPHINX enable systematic evaluation of cognitive primitives and provide a robust platform for diagnosing specific failure modes in multimodal AI systems.
> - Reinforcement Learning with Verifiable Rewards (RLVR), applied using SPHINX-generated data, is an effective paradigm for substantially improving LVLM accuracy on in-distribution tasks, enhancing generalization to held-out tasks, and yielding consistent gains on external visual reasoning benchmarks.
