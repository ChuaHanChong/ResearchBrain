# VisuLogic: A Benchmark for Evaluating Visual Reasoning in Multi-modal Large Language Models

> [!summary] Summary
> A new benchmark called VisuLogic evaluates true visual reasoning capabilities in multimodal language models through carefully designed tasks that prevent language-based shortcuts, revealing that current MLLMs achieve only 30% accuracy compared to 51.4% human performance while demonstrating how reinforcement learning can help bridge this gap.

## Problem

- Existing benchmarks allow MLLMs to solve visual tasks using language shortcuts rather than true visual reasoning
- Current evaluation metrics overestimate MLLMs' visual reasoning abilities by conflating them with basic perception or language-based solutions

## Method

- Created ==VisuLogic== benchmark with tasks that inherently require ==vision-centric reasoning== and cannot be solved through text alone
- Implemented ==reinforcement learning fine-tuning== approach to improve visual reasoning capabilities

## Results

- Current MLLMs achieve only **30%** accuracy on VisuLogic compared to **51.4%** human performance
- Models struggle most with spatial reasoning (LLMs) and stylistic reasoning (MLLMs)
- Reinforcement learning fine-tuning significantly improves performance by enabling iterative hypothesis revision
- Hint prompts boost performance but models still struggle to construct coherent reasoning chains

## Takeaways

> [!tip] Key Insights
> - Most MLLMs perform only slightly above random chance (25%) on genuine visual reasoning tasks
> - Text-only LLMs with detailed image descriptions barely exceed random baseline, confirming the necessity of true visual reasoning
> - Chain-of-thought prompting shows minimal benefit for visual reasoning tasks
