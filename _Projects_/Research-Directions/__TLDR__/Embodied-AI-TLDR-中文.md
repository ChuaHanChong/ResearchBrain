# TL;DR（中文）：VLA × WAM × 具身智能

> 原始研究方向文档：[[Embodied-AI|Promising Research Directions: VLA × WAM × Embodied AI]]（`_Projects_/Research-Directions/Embodied-AI.md`）。本篇是它的中文 TL;DR：逐方向给出**论点、第一性原理框架、具体研究问题、风险**四块，其余细节请回原文。

## Cluster A — 架构与训练（模型怎么学）

### A1 — 在潜空间中单回路协同进化的策略 + 世界模型
- **论点**：把策略和世界模型放进**同一个回路**训练，而非级联或交替。数据本身就承载了联合分布 $p(o',a\mid o,l)$，因此联合损失才是天然的损失函数。下注：在统一潜空间骨干上做单步联合梯度，能在**分布内 SR ≥97.2%（LIBERO）**与 **OOD SR ≥79.5%（LIBERO-Plus）**上同时超过交替训练，且不付出延迟代价（潜空间约 10 ms，像素约 150 ms）。
- **第一性原理框架**：
  - *第一性原理*：同一条数据流已经把每个未来观测和导致它的动作配成对，世界模型与策略学的是**同一分布的两半**；用分开的损失就是在丢掉这条联系，所以单一联合损失才是默认选择，分阶段反而需要理由。
  - *挑战的假设*：要训练稳定就必须交替更新世界模型与策略。现代潜空间骨干（慢更新的目标副本 + LeJEPA 的反坍缩几何项）也许已让单步联合更新足够稳，交替只是像素时代的遗留。
  - *下的赌注*：在共享潜空间骨干上做一次反向传播，能在**分布内 SR（≥97.2%）和 OOD SR（≥79.5%）上同时**胜过交替训练，且不增加延迟。
- **具体研究问题**：
  1. Q1 — 潜空间中的统一 GRPO：用预训练的潜空间 WAM，$\mathcal{L}=\mathbb{E}[A\cdot\log\pi(a,\hat{z}_{t+1}\mid s_t)]$，一次反传同时更新两个头。
  2. Q2 — 奖励分解：任务奖励 + 潜空间一致性（$\hat{z}_{t+1}$ 对齐编码器输出 $z_{t+1}$）+ 动作质量；潜空间提供了任务奖励给不了的稠密信号。
  3. Q3 — 联合回路中的知识隔离：把停梯度从「动作→VLM」扩展到「动作→WM 编码器」，保住预训练的物理先验。
  4. Q4 — 失败发现器协同进化：把 RoboMD 式的对抗者改写成 GRPO，在同一优化步里挑选扰动。
  5. Q5 — 真机迁移：只部署策略（在冻结的 WM 基座上做 LoRA），WM 与失败发现器留在仿真。
- **风险**：
  - 优化不稳定（离散动作 + 连续潜变量 + 对抗发现器，三者梯度冲突）→ 用分离的损失权重 + EMA 目标来平衡；先在冻结的 WM 上跑 Q1，以隔离动作头梯度。
  - 追逐问题（同步更新让 WM 去建模已经过时的策略）→ 用 EMA 目标网络把想象目标与在线策略解耦。
  - 潜空间一致性上的奖励黑客（把潜空间坍缩掉即可骗过）→ 用 LeJEPA 欧氏正则防御，套用 Latent-GRPO 的失败模式补丁。

### A2 — 面向潜空间策略推理的因果重要性步骤奖励
- **论点**：把**步骤奖励**打在**潜空间**推理词元上。结果奖励只看结局不看路径，分不清因果正确的推理和侥幸得到同样结局的路径。下注：潜空间思维链 + 步骤奖励在等延迟下把 LIBERO-Long SR 抬高 ≥+5 pp、组合任务上 ≥+10 pp，弥合 SEAL 记录的思维链忠实度缺口。
- **第一性原理框架**：
  - *第一性原理*：结果奖励把智能体绑在**结局**而非**推理路径**上；两条到达同样结局的路径得分相同，哪怕其中只有一条因果正确。要塑造推理，奖励就必须作用于中间状态。
  - *挑战的假设*：监督推理需要显式写出的思维链。CIR/SR 的步骤奖励对**潜空间（未写出）**的推理词元同样有效，因此 OneVL 的潜空间思维链能拿到同样的逐步监督，却不必付出推理时的额外词元与延迟。
  - *下的赌注*：潜空间思维链 + 步骤奖励在等延迟下使 LIBERO-Long SR ≥+5 pp、组合基准 ≥+10 pp，弥合 SEAL 记录的缺口。
- **具体研究问题**：
  1. Q1 — 操作任务的因果重要性谓词：把 130 个 LIBERO 任务各拆成 3–7 个可验证子目标（共约 600–900 个），用 Cosmos-Reason1 以 LLM-as-judge 自动生成，并在 100 个金标准子目标上验证（κ>0.7）。
  2. Q2 — 在潜空间推理词元上做步骤奖励训练：暴露 OneVL 的 K=8 个潜在词元，$\mathcal{L}=\lambda_a\mathcal{L}_{\text{action}}+\lambda_s\sum_i r_{\text{step},i}(z_i)$；目标 LIBERO-Long 在等延迟下 ≥+5 pp。
  3. Q3 — 潜变量利用率探针：潜变量利用指数 LUI = $a(\mathbf{z})$ 与 $a(\mathbf{z}+\epsilon)$ 之间归一化的动作 $L_2$ 距离；通过门槛 LUI>0.3。
  4. Q4 — 组合式步骤奖励：在简单指令上训练，在组合指令（「开抽屉 + 放红杯」）上测试，目标组合任务 ≥+10 pp、分布内退化 ≤−3 pp。
  5. Q5 — 推理成本消融：显式思维链（约 1.2 s）vs Abstract-CoT（约 50 ms）vs OneVL（约 0 ms）vs OneVL+CIR/SR（约 0 ms），覆盖 {分布内, OOD, 组合} 三类。
- **风险**：
  - 谓词难以规模化（手写子目标脆弱，改用 LLM-as-judge 又把验证成本带回）→ 规模化前先用 κ>0.7 的金标准集验证自动生成的谓词（Q1）。
  - 奖励黑客（模型可平凡地满足谓词）→ 用 EVOL-RL 的新颖性多样性 + LUI 探针（Q3）捕捉这类平凡满足。
  - 组合泛化在此规模或许尚不可解（SEAL 已记录此失败模式）→ 把组合主张限定在 LIBERO-Para 式的释义新颖性，而非无界组合。

### A3 — 面向开放世界策略生成的可验证物理一致训练
- **论点**：在**动作层**强制可验证的物理谓词。物理定律对留出数据和 OOD 数据同样成立，因此强制它们的损失不依赖分布、能够外推。下注：动作层谓词把障碍扰动下的 Safe-SR 从 **43.50% 抬到 >55%**（突破 Physical-Feasibility VLA 仅靠几何的上限），并达到 ≥0.70 的仿真到真机 SR 保持率，且谓词满足度与下游 SR 之间存在非平凡的皮尔逊 ρ。
- **第一性原理框架**：
  - *第一性原理*：物理定律（动量、重力、摩擦、接触）普适且可校验，不依赖训练集——对留出与 OOD 都成立。强制它们的损失在分布外仍然有效，不像只信任已见样本的普通损失。
  - *挑战的假设*：一个尊重物理的视频生成器会**免费**送你一个尊重物理的策略。从「生成视频里的物理」到「所选动作里的物理」这一交接是默认假设，却从未端到端验证过；ACWM-Phys 表明第一步就已在 OOD 处泄漏。
  - *下的赌注*：动作层物理谓词把障碍扰动下的 Safe-SR 从 **43.50% 抬到 >55%**，并达到 ≥0.70 的仿真到真机 SR 保持率（物理无关基线为 0.50–0.60），让物理一致的动作成为可度量的轴，而非生成端的副产品。
- **具体研究问题**：
  1. Q1 — 动作序列上的物理谓词：五个二元可验证谓词（P1 动量守恒、P2 物体间无穿透、P3 自由飞行段的反重力检验、P4 接触力旋量上的牛顿第三定律、P5 库仑摩擦）；在 50 个 LIBERO + 30 个 ReflectVLM 长程任务上插桩，约 4,000 条标注轨迹。
  2. Q2 — 隐式 vs 抽象 vs 显式接口消融（按 Video-to-Control 分类）：同骨干、等 FLOPs，报告 Safe-SR；目标把 Safe-SR 上限从 43.50% 抬到 >55%，潜空间方案在低延迟下保持在 ±2 pp 内。
  3. Q3 — 用 ABot-PhysWorld 负样本做开放世界测试：约 10k 偏好对，Diffusion-DPO，在留出的 1k 上 ≥90% 满足 $\beta(\log p_\theta(a_+)-\log p_\theta(a_-))>0$（基线约 74%）。
  4. Q4 — 仿真到真机链路：用 Real-to-Sim GS 软体孪生（12 个布/绳/面团），走仿真→孪生→真机，目标 SR 保持率 ≥0.70。
  5. Q5 — 奖励黑客诊断：静态输出检测（σ 下降 >2×）；$\rho(\sum P_i,\text{task SR})$ 回归；周期性 RoboMD 对抗探测；用 EVOL-RL 的新颖性多样性防御。
- **风险**：
  - 可验证物理难以规模化（杂乱场景的谓词很难写，PIRF 已表明这点）→ 从 ACWM-Phys 那类低维、结构干净的任务起步，再行扩展。
  - 物理一致的想象 ≠ 物理一致的动作（这正是要测的缺口，若缺口小则整个方向坍塌）→ Q5 中 $\sum P_i$ 与 SR 的皮尔逊 ρ 即规模化前的「继续/中止」判据。
  - 奖励黑客（NewtonRewards 已在生成端记录，动作端类比「模型冻结输出」很可能出现）→ 用 C1 静态输出检测 + EVOL-RL 的新颖性多样性防御。

## Cluster B — 评估、鲁棒性与部署

### B1 — 策略/世界模型联合评估：想象与动作之间的因果一致性
- **论点**：在**一条联合的因果一致性轴**上同时度量世界模型与策略，而非分成两条（WM 用 FVD/PSNR，动作用 LIBERO SR）。只有当想象未来里的动作与实际执行的动作相匹配时，二者才算因果耦合。下注：ASR + COD **联合**以皮尔逊 **ρ>0.7** 预测真机集群 SR（分离轴仅 ρ<0.4），可取代 FID 式的 WM 评估。
- **第一性原理框架**：
  - *第一性原理*：世界模型与策略真正耦合，当且仅当**想象**未来里的动作与**执行**未来里的动作相匹配。若从不直接度量这条联系，「WM 质量」分与「策略 SR」分会各自被刷高，而合成技能却原地踏步。
  - *挑战的假设*：生成未来「看起来多真」（FID、FVD）能告诉你策略会不会成功。WorldMark 表明这是**错的**（好看与物理一致无关）；stable-worldmodel 表明分布内视觉 SR 达 92–94% 时，规划 SR 仍会在扰动下崩塌。更尖锐的是：VLA Value Probing 从**冻结**的策略特征直接读出价值信号（R²≈0.55，配对序 94.22%，价值引导选择 +17.67 pp），说明策略本身或许已携带这套指标。
  - *下的赌注*：ASR + COD **联合**以皮尔逊 ρ>0.7 预测真机集群 SR，远超分离轴评估的 ρ<0.4，使这对指标成为现行 WM 评估的实用替代。
- **具体研究问题**：
  1. Q1 — 因果一致性度量：给定 $(s_t,a_t)\to\hat{s}_{t+1},s_{t+1}$，用 DINOv2 余弦 + 反事实探针（采样 $a'_t$ 生成 $\hat{s}'_{t+1}$，要求 $\|\hat{s}_{t+1}-\hat{s}'_{t+1}\|$ 随 $\|a_t-a'_t\|$ 单调）。
  2. Q2 — 50–100 任务的诊断套件：叠在 LIBERO(130) + LIBERO-Plus(10,030 扰动) + LIBERO-Para 上，每步记录（预测, 达成, 动作），每个 WAM 约 40k 对。
  3. Q3 — L1/L2/L3 子分（按 Agentic World Modeling 分级）：L1 预测器 = 1 步 MSE；L2 模拟器 = 8 步漂移（<2× 线性增长）；L3 进化器 = 把 COD 作为换动作检测的 AUROC，并配上 ASR。
  4. Q4 — 速度-质量帕累托：用联合指标重跑 WAM vs VLA Robustness 的约 12 组配置网格——4.8× 的成本是否换来 L3 上 ≥X pp 的提升？
  5. Q5 — 部署就绪轴：交叉核对 RoboArena（8 平台约 120 任务）+ VLA-REPLICA，看联合指标是否以斯皮尔曼 ρ>0.7 预测真机 SR，而分离子分仅 ρ<0.4？
- **风险**：
  - 度量噪声（特征空间相似度天然带有盲点）→ 与 A3 的显式物理谓词配对；用 VISER 实测的仿真-真机相关性做交叉验证。
  - 样本量（反事实探针每个任务实例或需 100+ 回合）→ 用 vla-eval 的 47× 加速来摊销回合成本。
  - 选择偏差（基准可能偏袒现有 WAM）→ 纳入对抗基线（JailWAM、VLA Patch Attack 90.7% 攻击 SR）与违反物理的基线（ABot-PhysWorld 拒样）。

### B2 — 面向真机部署的长程记忆 + 失败恢复回路
- **论点**：构建**一个带记忆的、集成的检测-诊断-恢复回路**，而非四个分离的模块。记不住就发现不了反复失败；发现了就必须改变行为，否则不算学习。下注：统一回路在 LIBERO-Long 记忆依赖任务上把长程 SR 抬高 ≥+15 pp（超过 ECHO-VLA 仅靠记忆的 +12.8 pp，在 RoboMemArena 上端到端，68.9% 子任务依赖记忆），并经状态机集成把振荡事件减少 ≥50%。
- **第一性原理框架**：
  - *第一性原理*：记不住的智能体无从识别反复失败；识别了就必须改变行为，否则不算学习。记忆 + 检测 + 恢复是同一能力的三个面，而非三个独立模块。
  - *挑战的假设*：记忆、失败检测、纠正、恢复是各自独立的问题。领域里有 5+ 篇记忆、8+ 篇检测、6+ 篇纠正论文，却没有系统级集成；它们能否平凡地组合起来从未被验证，而振荡、丢弃、延迟叠加都说明并不能。
  - *下的赌注*：带记忆的集成检测-诊断-恢复回路，在 LIBERO-Long 记忆依赖任务上比 ECHO-VLA 仅靠记忆的 +12.8 pp 再高 ≥+15 pp（同在 LIBERO-Long，并端到端延伸到 RoboMemArena），并经状态机集成把振荡事件减少 ≥50%。
- **具体研究问题**：
  1. Q1 — 记忆驱动的失败检测：用 ECHO-VLA / MemoryVLA 的层级记忆捕捉依赖历史的失败（「这个已经试过 3 次」）。
  2. Q2 — 带记忆的恢复：CycleVLA 回溯时查询记忆，把记忆库当作失败排除缓冲区。
  3. Q3 — 真机回路堆栈：(a) 记忆（PCMB/双曲）、(b) 并行检测器（Sentinel 模式）、(c) 纠正头（CycleVLA + CF-VLA）、(d) 恢复生成器（反事实失败合成）。
  4. Q4 — 算力 vs 鲁棒性权衡：在 RoboMemArena + LIBERO-Plus + 真机 RoboArena 上做消融，找出可部署的组合。
  5. Q5 — 从纠正中持续更新：每次成功恢复 → 转成一条训练样本（ARMADA 汇集干预模式），并按 Safety 综述做记忆投毒防御。
- **风险**：
  - 延迟叠加（每个组件加 10–100 ms，整条回路或许达不到实时）→ 并行化检测器（Sentinel 模式），仅在触发时调用恢复；与 B3 的效率预算协同设计。
  - 组件振荡（检测器可能被彼此的纠正动作触发）→ 用带显式模式转移的状态机来集成，这正是赌注所度量的对象（振荡减少 ≥50%）。
  - 记忆即攻击面（Safety 综述标记了记忆投毒）→ 把记忆写入门控在恢复成功检查之后，并把失败排除缓冲区当作不可信输入对待。

### B3 — 经架构-算法-数据协同设计实现实时可部署策略
- **论点**：把**效率当作一级研究目标**，而非「发表后再去解决的工程问题」。推理成本有三个独立杠杆——预测什么 / 多久预测一次 / 预测多精——它们的帕累托前沿需要协同设计。下注：经协同设计（架构 + 训练 + 数据 + 量化）的策略在边端设备（Jetson Orin / Apple M）上跑到 **≥30 Hz**（对比 AR 的 3–5 Hz 上限），同时保住 ≥95% 的基础策略 SR，证明延迟-质量曲线可以靠方法、而非仅靠硬件来推动。
- **第一性原理框架**：
  - *第一性原理*：接触丰富的策略是离散时间步上的反馈回路，存在**稳定性下限**，而不只是速度偏好。奈奎斯特采样律要求回路至少比所控制的最快运动快约 2×，慢于此就**无法**稳定，再怎么调也没用。一个接触时在数十 Hz 振铃的机械臂，根本不可能被 3–5 Hz 的回路稳住。
  - *挑战的假设*：效率「是工程而非研究」，更快的芯片会自动解决它。但在接触丰富的操作中，3–5 Hz 与 30 Hz 之间不是一个调参旋钮，而是稳定性下限上下、策略散架与收敛之间的分界线。
  - *下的赌注*：经协同设计（架构 + 训练 + 数据 + 量化）的策略在边端设备（Jetson Orin / Apple M）上达到 ≥30 Hz 且保住 ≥95% 基础策略 SR，证明延迟-质量曲线可以靠方法推动（95% 这条线是设计选定的目标，而非论文报告值）。
- **具体研究问题**：
  1. Q1 — 帕累托前沿扫描：骨干（Transformer / 线性注意力 / Mamba）× 解码（AR / 并行 / 扩散）× 精度（FP16 / INT8 / INT4），在 LIBERO + 1 个真机任务上跑；边端 30 Hz 能否在可接受的 SR 损失内达成？
  2. Q2 — 高效骨干上的知识隔离 RL：Mamba VLA + 知识隔离停梯度，在 LIBERO-Plus 上验证。
  3. Q3 — 经第一视角共训的数据高效预训练：用 EgoScale + Efficient VLA 综述的混合数据配方，测出要匹配 10× 数据基线所需的机器人数据量。
  4. Q4 — 潜空间中的实时联合策略 + 世界模型：A1 的联合回路配上 Mamba 潜空间 WM（SRPO 的 V-JEPA 2 基座），应达到 >30 Hz。
  5. Q5 — 边端部署链：训练→量化→蒸馏→部署到 Jetson Orin / Apple M，逐阶段测 SR 保持率，并用 VLA-REPLICA 做跨实验室验证。
- **风险**：
  - 线性注意力 / Mamba 在长上下文策略上或不及 Transformer（提速只有在 SR 守得住时才有意义）→ 每个帕累托点都用 SR 保持阈值把关，并报告未通过的点。
  - 边端硬件多样（Jetson、Apple M、定制 NPU 各需逐平台调优）→ 用 VLA-REPLICA 的可复现协议做跨平台验证，而非只在单台设备上。
  - 饱和风险（若「Mamba + LoRA + 共训」成了主导配方，贡献就缩成工程）→ 把交付物定位为帕累托曲线 + 系统级洞见，而非单点估计。

### B4 — 无灾难性遗忘的持续策略学习
- **论点**：在持续策略微调中**保护选择性子空间**，而非默认采用数据回放。在过参数化的策略里，新技能需要的参数方向与旧技能占用的方向**大多不相交**——遗忘-可塑性是子空间重叠问题，而非存储问题。下注：无回放的双路径/子空间方法在旧任务 SR 上比数据回放高 ≥+9.7 pp（C-Nav 在 HM3D 上 **42.61% vs 32.9%**）且存储更低，并把本体税保持在 <5%（UAM）。
- **第一性原理框架**：
  - *第一性原理*：大策略的权重远多于任一技能所需。新技能依赖的少数权重方向与旧技能已占用的方向几乎不重叠——遗忘只发生在**二者确实重叠**的一小撮共享方向上，而非模型没了空间。所以应当**保护那些共享方向**，而非重放旧数据。
  - *挑战的假设*：数据回放是安全、近乎免费的默认做法。C-Nav 表明回放带来真实的存储 + 隐私代价（要存整条轨迹），却**仍然输**给双路径设计；UAM 表明双流在无回放下胜过「全冻结或全解冻」。「回放是保持的代价」这一说法是从监督持续学习借来、从未对动作策略复核过的。
  - *下的赌注*：无回放的选择性子空间/双路径方法在旧任务 SR 上比数据回放高 ≥+9.7 pp（对齐 C-Nav 的 HM3D 42.61% vs 32.9%），存储严格更低，本体税 <5%（UAM），新任务 SR 在全量微调的 −3 pp 内，使遗忘成为可控的轴，而非被默认接受的损失。
- **具体研究问题**：
  1. Q1 — 子空间重叠测量：对一串 LIBERO-Plus / 物体导航任务，测量连续微调之间的梯度子空间重叠（主成分 / Fisher 重叠）；假设大多数任务对的重叠 <0.3，交付一张能预测哪些任务对会遗忘的重叠矩阵。
  2. Q2 — 无回放双路径微调：UAM 的语义/背侧分流 + C-Nav 的表征漂移与策略退化损失，仅对高重叠（Q1）方向施加 EWC 式 Fisher 惩罚；目标是旧任务 SR 比回放高 ≥+9.7 pp 且存储更低。
  3. Q3 — 本体税探针：每次微调后重跑冻结 VLM 的多模态套件（MMMU/MME/MMBench），通过门槛：连续 ≥5 个任务内税 <5%。
  4. Q4 — 持续恢复集成（接 B2）：把 B2 的恢复成功样本当作任务流，子空间方法能否阻止这些更新抹掉基础技能？测 100 次恢复更新前后的旧任务 SR。
  5. Q5 — 存储帕累托：扫描关键帧预算（C-Nav LOF）× 保护强度，画出保持率 vs 存储；找出在两轴上都压过回放的无回放点。
- **风险**：
  - 相似任务的子空间可能并非不相交（两个共享接触动力学的操作技能或许高度重叠，瓦解几何前提）→ Q1 的重叠矩阵即「继续/中止」判据：若 >0.5 占主导，就退回记忆方案（ECHO-VLA），放弃子空间保护。
  - 可塑性坍塌（保护太多方向会冻住新任务的学习，即 LoRA-Learns-Less 失败模式）→ 用 ≤−3 pp 新任务 SR 的目标来约束保护强度，报告保持/可塑前沿而非单点。
  - 回放在大规模下悄悄取胜（若存储便宜、隐私不成问题，回放或仍有竞争力）→ 把交付物定位为存储-保持帕累托（Q5），主张是**两轴上的支配**，而非仅与回放持平。

## Cluster C — 移动性与本体泛化

### C1 — 视觉-语言导航的策略内潜空间做梦
- **论点**：把潜空间「向前做梦」的头放进**导航策略内部**，而非外挂一个世界模型。前瞻只需要未来的**控制相关切片**，用潜空间词元来承载它远比渲染整帧便宜。下注：策略内的潜空间做梦头以远低的成本匹配或超越外部 WM 的 VLN SOTA——LatentPilot 在 R2R-CE Val-Unseen 上 **62.0% SR / 58.0% SPL，130 ms / 22.8 GB**，NavMorph 再以 **梯度自适应 2.1× 的速度**额外带来 **+4.1% SR**。
- **第一性原理框架**：
  - *第一性原理*：一个导航决策只需未来的**控制相关切片**（「这个动作会不会开出通往目标的路」），而非对下一视点的逼真渲染。该切片低维且天然存在于潜空间词元中；为恢复它而去渲染像素，是在逐步闭环上浪费算力。
  - *挑战的假设*：前瞻式 VLN 需要外部的像素空间世界模型。显式前瞻的工作（GAIA-1 式模拟器、候选未来渲染）把前瞻与生成当成同一个问题；而 LatentPilot 的 Pilot 词元与 NavMorph 的 RSSM 已能在潜空间以远低成本承载控制相关的未来，外部 WM 却仍是默认选择。
  - *下的赌注*：策略内的潜空间做梦头（可选配在线自进化）匹配或超越外部 WM 的 VLN SOTA——R2R-CE Val-Unseen ≥62.0% SR / 58.0% SPL，≤130 ms / 22.8 GB，且在线自适应带来 ≥+4.1% SR、速度为梯度自适应的 2.1×——证明前瞻是一种表征选择，而非一个外部模块。
- **具体研究问题**：
  1. Q1 — 融合策略内做梦与在线自进化：把 NavMorph 的上下文进化记忆装到 LatentPilot 的 Pilot 词元上，看测试时的 CEM 更新能否在不付出梯度自适应成本的前提下改进梦出的潜变量？目标是保持 ≤130 ms 同时拿到 +4.1% 的在线自适应 SR。
  2. Q2 — 潜空间做梦视野消融：变动想象视野（1 步 vs k 步 Pilot 词元展开），测 SR/SPL vs 延迟；在 R2R-CE / RxR-CE 上，更深的做梦从何处开始不再划算？
  3. Q3 — 特权监督迁移：LatentPilot 的 PilotLoop 在仿真中以未来观测作特权监督，这一信号能否迁移到真机部署（VLN-PE 跌倒/卡住率）而不在仿真上坍塌？
  4. Q4 — 潜空间 vs 推理词元前瞻：在骨干匹配的条件下，把潜在的 Pilot 词元与显式推理轨迹（AwareVLN）正面比较；那点精度差是否值得在闭环导航上付出延迟代价？
  5. Q5 — 跨本体导航部署：潜空间做梦头能否零样本迁移到新的移动底盘，还是需要 C2 那样的形态无关表示？
- **风险**：
  - 潜空间做梦在长程 RxR-CE 上或无助益（在显式推理仍占优的地方，Pilot 词元前瞻可能进入平台期）→ Q4 的正面比较把主张限定在潜空间前瞻成本可比的区间，并报告它失利的地方。
  - 在线自进化会漂移（测试时的 CEM 更新有针对误导性情节发生灾难性自适应的风险）→ 把 CEM 写入门控在置信度检查之后，借 B4 的遗忘感知保护来做测试时更新。
  - 仅限仿真的特权监督（PilotLoop 的未来观测监督只在仿真中存在，真机部署时就失去了）→ Q3 在主张真机前瞻之前先验证 VLN-PE 迁移，若坍塌则退回 NavMorph 的无监督 CEM。

### C2 — 面向跨本体零样本迁移的形态无关动作表示
- **论点**：用**形态无关的动作表示**，而非在每个机器人的原生关节空间里标注动作。「拿起杯子」无论由哪条臂执行，指代的都是同一**任务意图**，所以本体无关的动作空间才是自然的表示，逐形态标注只是偶然之举。下注：形态无关表示打破 AnyBody 的外推墙——AnyBody 在新颖连杆结构上报告 **0% 零样本 SR**，而 LAP 的语言-动作空间达 **>50% 零样本（先前策略的 2×）**、Demo-JEPA 达 **0.36 vs 0.04** 的单样本成绩——目标是在 AnyBody 外推分割上达 **>30%**。
- **第一性原理框架**：
  - *第一性原理*：「拿起杯子」对 7-DoF 臂、平行夹爪或仿人手而言，指代同一**任务意图**。意图是形态无关的，关节空间轨迹则是形态特定的。基于意图（语言、潜目标或任务空间）的表示**天生不变**，而原生关节标注才是把策略耦合到具体身体的偶然选择。
  - *挑战的假设*：跨本体迁移需要逐机器人微调（常态如此：RT-1 / HPT / X-VLA 都要逐身体重训或自适应）。LAP 的语言-动作与 Demo-JEPA 的潜目标已经从不变的中间表示拿到了**零样本**迁移，但 AnyBody 显示，最好的多本体策略在真外推上仍是 0%，原因正是它们在关节空间里标注。
  - *下的赌注*：形态无关动作表示在 AnyBody 外推分割上达到 >30% 零样本 SR（当前最佳为 0%），与 LAP 的 >50% 零样本、Demo-JEPA 的 0.36 单样本相一致，把对新颖连杆结构的外推从不可能变为可度量的迁移率。
- **具体研究问题**：
  1. Q1 — 在 AnyBody 上做不变表示对决：把 LAP（语言-动作）、Demo-JEPA（潜目标）、任务空间标注三者在 AnyBody 外推/组合分割上正面比较；哪种不变表示能突破 0%？目标外推 SR >30%。
  2. Q2 — 关节空间标注为何 0% 失败？探查 HPT 式的逐本体输入模块（stem）是否在记忆形态而非学习不变控制；测跨形态的表征重叠（重叠低 → 即记忆）。
  3. Q3 — 组合语言-动作 + 潜目标：LAP 的语言中间表示（管「做什么」）与 Demo-JEPA 的潜目标（管「在这具身体上怎么做」）能否组合？目标是在 AnyBody 组合分割上胜过单用任一者。
  4. Q4 — 不变性 vs 精度权衡：不变空间可能损失精细控制；在见过的机器人上测不变空间 vs 原生关节策略的精度（末端误差），以界定不变性税。
  5. Q5 — 迁移到移动/全身本体：不变表示能否从固定臂扩展到仿人全身，还是说全身耦合会破坏意图的不变性？
- **风险**：
  - 不变性可能损失精度（语言/潜动作空间或会模糊掉原生关节才能捕捉的精细控制）→ Q4 先在见过的机器人上界定不变性税，再主张外推增益，并报告精度下限。
  - AnyBody 的 0% 或许部分源于任务难度而非纯形态（外推任务本身可能更难）→ 用**同一批任务**的插值 SR 做对照，仅当插值成功时才把差距归因于形态。
  - 语言-动作会把连续控制离散化（LAP 的解析或会丢掉高频细节）→ 把语言中间表示与知识隔离的连续动作专家配对（这正是 LAP 自身的设计），而非直接在语言层面执行动作。
