# TL;DR（中文）：三维/四维空间与几何表示（3D/4D Spatial Representation）

> 原始研究方向文档：[[Spatial-4D|3D/4D Spatial & Geometric Representation Directions]]（`_Projects_/Research-Directions/Mechanism/Spatial-4D.md`）。本篇是它的中文 TL;DR：逐方向给出**论点、第一性原理框架、具体研究问题、风险**四块，其余细节请回原文。

## Cluster A — 几何原生策略（Geometry-Native Policies）
### A1 — 点云原生动作头 vs RGB 词元策略
- **论点**：动作是「物体在度量三维空间中的位置」的函数，点云直接给出这一位置，而 RGB 词元只能隐式编码它。点云原生动作头在跨本体零样本迁移上应胜过 RGB 词元策略（PointAction 零样本 xArm7 43.0%、RoboCasa365 同分布 47.7%；GeoVLA LIBERO 97.7%）。
- **第一性原理框架**：
  - *第一性原理*：操作动作由度量三维布局（夹爪、物体、接触点的位置）决定；几何在光照、纹理、视角、相机位置变化下保持不变，外观则不然。
  - *挑战的假设*：OpenVLA / SpatialVLA 持有的观点——大型二维主干已编码动作头所需的全部几何，显式三维分支纯属冗余开销。
  - *下的赌注*：在 RGB 策略崩溃之处，点云头仍能实现 ≥43.0% 的跨本体零样本迁移，且几何与 RGB 之间的差距随分布偏移加大而**拉大**。
- **具体研究问题**：
  1. Q1 — 几何不变性消融：固定主干，在受控外观偏移（纹理、光照、相机位姿）的扫描下，比较点云头与 RGB 词元头；二者的 SR 差距是否随偏移量单调增长？
  2. Q2 — 点云在何处见效：按任务阶段（运送 vs 接触）拆解 SR；点云优势是否集中在几何决定动作的接触密集子段，而在自由空间运送段近乎为零？
  3. Q3 — 最小充分几何：DP3 用稀疏点、GeoVLA 用完整点分支；要恢复大部分 SR 增益，所需的最小点密度与完整度是多少（即最廉价却仍胜过 RGB 的显式几何）？
  4. Q4 — 本体无关预训练的迁移：通过表示替换的对照实验，量化 PointAction 零样本 xArm7 的 SR 中有多少来自*点表示*、多少来自*分解式解码器*。
- **风险**：
  - 点云依赖深度传感或重建，部署时可能含噪或缺失。→ 改走预测点图的路线（PointAction），让几何由模型*生成*而非*传感*，去掉对深度传感器的硬依赖。
  - 在 RGB 主干已饱和的同分布基准（LIBERO ~97%）上，优势可能消失。→ 围绕外观偏移与跨本体的切分设计评测，把同分布持平视为预期而非失败。
  - 完整三维分支会增加延迟与参数。→ 以 Q3 的最小充分几何扫描，配合 A3 的深度词元桥作为轻量回退。

### A2 — 占据预测作为策略的前向模型
- **论点**：规划需要知道*哪些空间将被填充*，而非*场景看起来如何*——占据栅格直接回答这一问题，像素则每步都要重新推断几何。把驾驶领域成熟的占据世界模型移植到桌面操作，应能继承其长程稳定性（OccSim 3,000+ 稳定帧、相对 mIoU +22.1%、零样本 67%），而像素模型几十帧就开始漂移。
- **第一性原理框架**：
  - *第一性原理*：规划器需要知道哪些空间区域将被占据（无碰撞、接触、可达性），体素栅格直接给出这一信息；像素只是同一几何的有损、视角相关的再编码。
  - *挑战的假设*：操作前向模型应预测像素（CTRL-WORLD 等视频世界模型的惯例），理由是视频基础模型预测的就是像素——而 OccSim 的 80× 长程增益说明，像素基底本身正是漂移之源。
  - *下的赌注*：占据前向模型在操作回路中保持几何稳定的时长，比像素世界模型基线长一个数量级，且下游 SR 增益与 OccSim 的相对 mIoU +22.1% 提升同向。
- **具体研究问题**：
  1. Q1 — 占据 vs 像素的内循环：固定主干，把操作世界模型的像素预测循环换成占据预测循环，测推演到发散的帧数与下游 SR；驾驶领域的 80× 长程增益是否部分迁移到桌面尺度？
  2. Q2 — 体素分辨率 vs 规划精度：接触精确的操作（亚厘米）相比驾驶（米级）需要多高的占据分辨率？Warp-DiT 的误差约束机制能否随分辨率移植？
  3. Q3 — 动态体的类比：OccSim 把静态场景推演与动态体生成解耦；操作中的「动态体」是被操物与夹爪，同样的解耦能否稳定物体运动的预测？
  4. Q4 — 占据作为 A1 的输入：A2 预测的未来占据能否直接条件化 A1 的动作头，从而闭合一个全几何的感知-想象-行动回路？
- **风险**：
  - 跨域迁移未必成立——驾驶占据是米级且大体静态的，而操作需要亚厘米的动态占据。→ 以 Q2 的分辨率扫描配合 Q3 的动态体类比，作为是否声称迁移的明确门槛，并报告 Warp-DiT 误差约束失效的尺度。
  - 操作数据集中占据真值稀缺。→ 由深度配合已知夹爪几何推导占据（如驾驶领域从激光雷达推导），或在仿真中预训练预测器（占据真值免费可得）。
  - 亚厘米分辨率下体素栅格的内存占用大。→ 改用稀疏或分层占据（八叉树），并把声明限定在末端执行器周围的工作体积，而非整个场景。

### A3 — 深度词元桥：无需重训即可给预训练二维策略注入三维感知
- **论点**：二维策略的几何缺陷在于*缺一个通道*，而非*主干用错了*——因此一个廉价的深度词元旁路输入即可补上，又不扰动预训练的语义对齐。单视角深度词元桥应以一小部分代价恢复完整三维分支的大部分空间增益（QDepth-VLA 单视角，LIBERO-Spatial +8.8%、长程 +29.7%，优于 open_pi_0；对比 GeoVLA 完整三维分支 97.7%）。
- **第一性原理框架**：
  - *第一性原理*：二维策略的空间弱点在于*缺通道*（深度），而非表示被破坏；用离散词元经解耦专家补上该通道，即可提供度量线索，无需重建主干。
  - *挑战的假设*：GeoVLA / PointAction 的立场——真正的三维感知需要完整的平行三维分支与联合重训；而 QDepth-VLA 表明，在*冻结主干*上接入深度词元即可捕获大部分增益，且保住语义对齐。
  - *下的赌注*：单视角深度词元桥以一小部分新增参数、零重训，恢复完整三维分支 ≥80% 的空间任务 SR 增益，且仅凭*单视角*输入（完整三维方法需多视角或传感点云）。
- **具体研究问题**：
  1. Q1 — 恢复比例曲线：扫描深度词元容量（码本大小、专家深度），绘制「相对 GeoVLA 完整三维分支的 SR 增益恢复比例」对「新增参数」的曲线；拐点在哪？
  2. Q2 — 量化 vs 连续深度：QDepth-VLA 主张离散词元在抗噪上胜过逐像素回归；用 2×2 消融分离*量化*与*解耦专家*各自的贡献。
  3. Q3 — 单视角 vs 多视角深度桥：单视角深度词元的增益是否饱和，还是加上第二视角的深度词元能补上与「消费传感点云的完整三维方法」之间的剩余差距？
  4. Q4 — 对齐保持：相比把完整分支反传融入主干，深度专家旁路对冻结 VLM 语义对齐的扰动有多大（如在留出的 VQA 探针上测量）？
- **风险**：
  - 在最难的几何约束任务上，桥可能停在完整三维的上限之下。→ 用 Q1 的恢复比例曲线设定诚实预期，把贡献定位为*成本效率前沿*而非刷新 SR 的 SOTA。
  - 深度词元质量依赖深度估计器。→ QDepth-VLA 的量化可缓冲估计器噪声；报告对估计器质量的敏感性，把声明限定在现实的深度范围内。
  - 旁路仍可能细微扰动语义对齐。→ 用 Q4 的 VQA 探针量化扰动并据此设阈，而非假设冻结主干完全不受影响。

## Cluster B — 作为三维锚定认知层的空间推理（3D-Grounded Cognition）
### B1 — 显式三维场景图思维链做度量空间推理
- **论点**：度量空间关系是*建立在几何实体之上的图*；自由形式的语言思维链只能有损地描述该图，且在缺乏锚定时会幻觉。结构化场景图思维链配合 RL 锚定，应能缩小可测量的人-模型差距（VLM Spatial Reasoning RL +5–15%、CVBench 77.69%；SpatialCoT 操作 82.57% / 导航 61.83%），其残差在因果任务上最大（CausalSpatial GPT-5 54.17% vs 人类 84.49%）。
- **第一性原理框架**：
  - *第一性原理*：空间关系构成一张建立在几何实体（带度量位置的物体、两两关系、接触）之上的图；正确推理*就是*在该图上运算，而语言只是丢失了度量结构的有损序列化。
  - *挑战的假设*：缩放观点——足够大的多模态模型会隐式地推理空间，显式结构纯属多余脚手架；但实证显示，朴素思维链可能*有害*，只有*结构化*的场景图思维链才有帮助，且 GPT-5 仍落后人类 30 分。
  - *下的赌注*：带 RL 锚定的场景图思维链层，能在因果任务上缩小 CausalSpatial 差距（54.17%→84.49%）的可测量部分，且增益最大之处在于场景图最具度量性的地方，而非物体命名。
- **具体研究问题**：
  1. Q1 — 度量 vs 拓扑场景图：场景图是需要度量边标签（距离、角度），还是拓扑关系（左于、在上）就够？按关系类型拆解 CVBench 增益。
  2. Q2 — RL vs SFT 的 OOD 锚定：VLM Spatial Reasoning RL 显示，GRPO 能在 SFT 过拟合之处泛化；在因果任务上复现这一点——在 CausalSpatial 上，RL 锚定是否比 SFT 更好地把场景图习惯迁移到 OOD？
  3. Q3 — 人类差距究竟在哪：把 CausalSpatial 的 30 分差距按任务（碰撞、遮挡、轨迹）拆解；场景图思维链在哪类因果任务上缩得最多，其残差是*推理*失败还是*感知*（深度、遮挡）失败？
  4. Q4 — 场景图思维链 → 动作的交接：SpatialCoT 输出坐标；量化把 B1 场景图推理出的坐标喂给更简单的 RGB 动作头，能匹配多少 A1 点云头的 SR——即上游锚定能否替代下游几何？
- **风险**：
  - 场景图构建本身会幻觉——错误的图会毒化下游推理。→ 用 B2 的四维一致性与深度（CausalSpatial 的 COW 视觉模拟证据）锚定，并把图构建准确率与答案准确率分开报告。
  - 增益可能只对特定基准成立（在 CVBench 上调好的提示无法迁移）。→ 用 Q2 的 RL-OOD 协议显式测跨基准迁移，把 GRPO 当泛化机制而非提示调优。
  - 人类差距可能受感知而非推理约束——场景图思维链修不了坏的深度。→ 用 Q3 分离感知与推理失败；若受感知约束，则转交 A3 深度桥作上游修复。

### B2 — 四维一致策略：把时空几何作为推理约束
- **论点**：要在一段时域上规划动作，物体的几何与身份必须跨时间、跨视角保持连贯——即四维一致。*隐式*四维一致注意力应以远低的成本匹配显式三维的精度（ConsisVLA-4D LIBERO 98.1%、真实双臂 70.0% vs OpenVLA 28.5%、推理快 2.31×），且深度感知的推理轨迹能泛化到 OOD（MolmoAct 86.6%、OOD 72.1%）。
- **第一性原理框架**：
  - *第一性原理*：要在一段时域上规划动作，想象的几何必须在时间上、跨视角上一致（同一物体落在连贯的四维轨迹上）；一致性是表示须满足的约束，并不等于渲染出每一个中间帧。
  - *挑战的假设*：非此即彼——要么接受带投影偏置的二维（OpenVLA 一类的默认），要么为四维一致性付出显式生成未来帧（X-WAM 一类）的代价；而 ConsisVLA-4D 用隐式一致注意力同时拿到显式三维精度与 2.31× 加速，说明这一权衡可破。
  - *下的赌注*：隐式四维一致注意力在长程真实 SR 上匹配或胜过显式帧策略（≥70.0% 双臂 vs OpenVLA 28.5%），且推理成本更低（≥2.31× 加速），而驱动 OOD 鲁棒性的是*一致性约束*而非三维本身。
- **具体研究问题**：
  1. Q1 — 一致性消融的 OOD 测试：固定感知，从 ConsisVLA-4D 去掉时空一致注意力；OOD SR 是否比 ID SR 崩得更厉害，从而证实驱动鲁棒性的是一致性而非裸三维？
  2. Q2 — 隐式 vs 显式四维的成本/精度前沿：在 SR-延迟平面上把 ConsisVLA-4D（隐式）对照 Geometry-aware 4D Robot Video / X-WAM（显式）作图；隐式是帕累托占优，还是只在某一子类任务上占优？
  3. Q3 — 推理轨迹可操纵性的迁移：MolmoAct 的视觉轨迹带来 75% 的可操纵 SR（比语言 +33%）；把隐式一致（B2）与显式可操纵轨迹（MolmoAct）配对，是带来叠加增益还是冗余的锚定信号？
  4. Q4 — 时域长度的缩放：隐式一致相对二维的优势在多长的时域上出现、相对显式生成的优势又在多长的时域上消失？扫描任务长度以找出交叉点。
- **风险**：
  - 隐式一致可能不可检视——看不到注意力学到了什么四维结构，损害可调试性。→ 搭配 MolmoAct 的显式视觉推理轨迹（Q3），让时序推理可操纵、可审计。
  - 成本声明来源单一——2.31× 加速仅来自 ConsisVLA-4D。→ Q2 跨隐式与显式方法的完整成本/精度前沿，是声称泛化效率前的是否门槛。
  - 隐式四维可能在最长的时域上悄然失败，漂移不可见地累积。→ 用 Q4 的时域缩放交叉点圈定有效区间；越过它就转用 C4 的显式持久几何记忆，而非硬撑隐式一致。

## Cluster C — 几何原生世界模型与记忆（Geometry-Native World Models & Memory）
### C1 — 占据世界模型作为操作推演的基底
- **论点**：世界模型的长程稳定性受*几何*误差累积速度的限制——带刚体变换约束的显式占据栅格能约束该误差，潜在基底则不能。体素语义占据世界模型应在潜在世界模型已漂移的时域上仍保持几何连贯（OccSim 3,000+ 稳定帧、相对 mIoU +22.1%、相对潜在基线 80× 时域），其失效模式取决于*时域长度*而非逐帧 Chamfer。
- **第一性原理框架**：
  - *第一性原理*：世界模型的长程稳定性由推演过程中逐步几何误差的增长速度决定；带刚体变换约束的占据栅格（OccSim 的 Warp-DiT）压住逐步误差，而潜在基底没有这种约束，误差逐步复利、推演随之漂移。
  - *挑战的假设*：推演基底应是策略所见的同一份 RGB-D 潜在（CTRL-WORLD、C3 潜在 X-WAM 的惯例）；而 OccSim 的 80× 时域增益表明，专建的占据基底在对规划至关重要的长程稳定性上更胜一筹。
  - *下的赌注*：体素语义占据世界模型能在分钟级操作时域上保持几何连贯，而 C3 潜在四维基线（X-WAM）会漂移；二者的差距体现在*到发散的时域*上（而非逐帧 Chamfer，那里潜在四维更强），因此二者互补而非竞争。
- **具体研究问题**：
  1. Q1 — 到发散的时域，占据 vs 潜在：在匹配的操作任务上，测占据世界模型与 C3 X-WAM 一类潜在的几何发散帧数；驾驶领域的 80× 差距在桌面尺度上是否部分存活？
  2. Q2 — 可外部渲染的优势：量化占据栅格*可被第三方读取*的价值——现成规划器能否直接消费它做碰撞检测、无需学习解码器，且胜过解码潜在？
  3. Q3 — 互补基底的切换：长程可读的推演用占据，逐步高保真的想象切到 C3 X-WAM 潜在；这种混合是否在（时域 × 保真）上胜过单一基底？
  4. Q4 — 亚厘米的 Warp-DiT：OccSim 的刚体变换误差约束在操作分辨率下是否仍成立，还是会在其验证过的米级以下松弛？
- **风险**：
  - 驾驶→操作的尺度差距——占据在米级验证，操作却需亚厘米。→ Q4 的亚厘米 Warp-DiT 测试是是否门槛，应报告误差约束失效的分辨率，而非假设迁移成立。
  - 若显式与潜在的差异在实践中变得模糊，便会与 C3 重叠。→ 把贡献钉死在*可外部渲染的长程占据*（Q2）与*互补性*（Q3）上——C1 不是更好的 X-WAM，而是 X-WAM 所不具备的那种基底。
  - 操作数据中占据监督稀缺。→ 在仿真中（免费）和真实数据上由深度配合夹爪几何推导占据；把真实数据上的声明限定在占据真值可恢复之处。

### C2 — 四维几何一致视频预测用于六自由度位姿提取
- **论点**：六自由度位姿是几何量——跨视角一致的点图能把它直接暴露给任何跟踪器，而纯 RGB 帧只会让它变得含糊。联合预测 RGB 与跨视角一致点图，能产出可直接读取的六自由度轨迹，从而带来高得多的操作 SR（Geometry-aware 4D Robot Video 在三个仿真任务上平均任务 SR 0.64 vs Dreamitate 0.12、Diffusion Policy 0.12）。
- **第一性原理框架**：
  - *第一性原理*：六自由度位姿是几何量；只要点图跨视角一致，任何跟踪器都能直接读出位姿（位姿就是匹配三维点之间的刚体变换）。纯 RGB 帧隐藏了位姿，逼下游估计器每帧从头重解。
  - *挑战的假设*：Dreamitate 一类的惯例——像素视频模型配合下游位姿估计器就够了；而 ≈5× 的 SR 差距（0.64 vs 0.12）表明，事后估计器才是瓶颈，只有在模型内*一致地*预测几何才能使轨迹可提取。
  - *下的赌注*：联合预测 RGB 与跨视角一致点图，产出可直接读取的六自由度轨迹，平均任务 SR ≥0.64，对比「RGB 加估计器」基线的 ~0.12（≈5×），且增益随*跨视角一致性*（mIoU）变化。
- **具体研究问题**：
  1. Q1 — 跨视角一致性消融：固定 RGB 质量，去掉跨视角点图扩散损失；轨迹提取精度（及下游 SR）是否比 RGB FVD 退化得更厉害，从而证实驱动动作增益的是一致性而非外观？
  2. Q2 — 预测点图 vs 传感深度的位姿读出：在相同任务上比较「从预测点图」与「从传感深度」提取六自由度；用预测几何而非传感几何会损失多少精度？
  3. Q3 — 新视角泛化的边界：模型无需重训即可泛化到新视角；量化位姿提取精度退化前的视角外推范围——即可外部读取这一声明的工作包络。
  4. Q4 — 显式点图（C2）vs 隐式一致（B2）的同任务对比：固定任务，比较 C2 的「跟踪器读出」管线与 ConsisVLA-4D 的端到端隐式头；几何外部化（可调试、跟踪器可读）在何处胜过内部化（更便宜）？
- **风险**：
  - 方向锚点单一——核心结论仅靠 Geometry-aware 4D Robot Video 的三任务评测。→ Q1 一致性消融与 Q2 预测-vs-传感比较是内部有效性检查；在泛化 ≈5× 这一声明之前先扩充任务集。
  - 预测点图可能比传感深度更含噪，从而降低位姿读出精度。→ Q2 直接量化预测-vs-传感的差距；若差距大，则把 C2 限定在无传感场景（新视角、无深度传感器）。
  - 以三任务 SR 作基底，声明面太窄。→ 把贡献定位为*机制*（显式跨视角点图 → 跟踪器可读的位姿）已在三任务上得到验证，更广的评测作为明确的下一步，不夸大覆盖面。

### C3 — 原生四维几何作为世界表示基底
- **论点**：对接触类与空间类任务，动作由几何决定，而这种几何模型只能从像素间接推断——因此*原生四维*（RGB + 深度 + 随时间的三维几何）表示能直接携带它，事后从二维抬升则不行。四维原生基底应在几何约束任务上胜过潜在/像素基线——RoboCasa 79.2%（比 Cosmos Policy +12.1 pp）、Chamfer 0.0049 vs 0.0680、动作延迟加速 4.5× 至 15 Hz——这是一个任何策略或模型都能立足的表示。
- **第一性原理框架**：
  - *第一性原理*：对接触密集与空间约束任务，动作是*几何*（相对位姿、深度、表面法向、自由空间）的函数；不编码几何的像素基底逼消费者每步从外观重推，白白丢弃了本可直接携带的结构。
  - *挑战的假设*：只要帧看着对，像素基底就够了，显式四维太贵无法部署，因此几何应用单独的两阶段管线恢复；而 X-WAM 表明，两阶段路径的几何更差（Chamfer 0.0680 vs 0.0049），且比带异步去噪的统一四维模型更慢。
  - *下的赌注*：四维原生基底在几何约束操作上胜过潜在/像素基线——24 个 RoboCasa 任务 79.2%、比 Cosmos Policy +12.1 pp——几何保真更高（Chamfer 0.0049 vs 0.0680、+2.34 dB PSNR），且*不付*部署代价（动作延迟加速 4.5×，4665→1033 ms，物理机器人 15 Hz）。
- **具体研究问题**：
  1. Q1 — 原生四维 vs 事后抬升的消融：固定主干，在几何约束的 RoboCasa 任务上比较「X-WAM 交错深度分支」与「像素基底 + 事后深度估计器」；分离出*原生*四维相对*恢复*四维到底多买到什么。
  2. Q2 — 异步去噪在动作质量与视频保真间的权衡：推广异步噪声采样——动作调度能否缩到 1–4 步（步蒸馏，见伞文档 Embodied-AI 的效率方向），同时不降低消费者读取的四维几何？
  3. Q3 — 四维基底用于接触（C3 × B1 式离散接触）：显式三维几何通道是否让离散接触模式的预测比连续潜在更容易——几何直接暴露穿透与邻近？
  4. Q4 — 相机位姿由末端执行器导出的一致性：X-WAM 由末端执行器位姿导出相机位姿；测这一自一致约束相比自由相机条件是否改善 OOD 几何。
  5. Q5 — 四维想象作为模型无关的规划神谕：在候选动作下前向推演四维基底；在空间约束任务（插入、堆叠、倒液）上，显式几何规划是否胜过潜在规划，且同一基底能否从世界模型消费者迁移到策略动作头？
- **风险**：
  - 四维监督需要多数机器人数据集所没有的深度/三维真值。→ 用 X-WAM 由末端执行器导出的相机位姿配合现成深度估计器来缓解；把声明限定在几何可恢复的任务上。
  - 四维只在几何约束任务上才划算——外观约束任务上潜在已经胜出。→ 在接触/空间任务（RoboCasa 插入、堆叠）上评分，而非以 LIBERO SR 为核心指标，并显式报告任务类型的切分。
  - 实时四维仅靠一个结果（X-WAM）支撑。→ 把 Q1 原生-vs-恢复消融当作「四维属于部署阶段（而非仅训练时辅助）」这一声明前的是否门槛。

### C4 — 持久几何记忆实现长程连贯
- **论点**：长程连贯需要几何上的物体恒存——记住物体离开视野再返回时它们在哪——而这在纯注意力模型中会因漂移而流失。显式几何记忆应在马尔可夫/长上下文基底已漂移之处仍保持分钟级连贯（MosaicMem RotErr 0.51° vs 1.42°/4.65° @16 FPS，Chameleon 100%/73.5% 长程 DSR，RoboMemArena 显示 68.9% 子任务确实需要历史）——这是一种任何策略、模型或推理器都能把几何挂载上去的记忆。
- **第一性原理框架**：
  - *第一性原理*：长程连贯需要*物体恒存*——记住物体离开视野再返回时它们在哪；这是几何记忆问题而非序列长度问题，即便上下文无界，纯注意力模型仍会漂移，因为没有东西把想象的几何钉到持久坐标系上。
  - *挑战的假设*：足够长的上下文窗口或马尔可夫潜在就够了；而 MosaicMem 显示隐式注意力会漂移、静态三维缓存在动态场景下会失效，RoboMemArena 显示 68.9% 的子任务非马尔可夫，Chameleon 显示感知混淆会使决策依赖历史。
  - *下的赌注*：记忆增强的表示能在马尔可夫/长上下文基底已漂移之处保持分钟级几何连贯——MosaicMem RotErr 0.51° vs 1.42°（显式）/ 4.65°（隐式）@16 FPS，Chameleon 100.0% 情景回忆 / 73.5% 空间跟踪 / 72.2% 顺序 DSR——且这是在 RoboMemArena 确实需要历史的子任务（68.9%）上达成的。
- **具体研究问题**：
  1. Q1 — 几何记忆用于动作条件的消费者：把 MosaicMem 抬升的三维图块记忆从相机控制视频移植到*动作*条件的操作；RotErr 式的几何连贯是否转化为更高的长程 SR？
  2. Q2 — 情景记忆 × 几何记忆（C4 内部）：把 Chameleon 的可索引事件与 MosaicMem 的几何一致图块结合——消歧的*事件*加持久的*几何*能否在 RoboMemArena 上产生叠加增益？
  3. Q3 — 预测编码记忆作为校准信号：RoboMemArena 的预测编码头让隐状态对状态转移敏感；这能否兼作前向-逆向校准目标（即训练时的可信度杠杆）？
  4. Q4 — 记忆钉在世界坐标系 vs 机器人坐标系：钉在持久*世界坐标系*上的几何记忆（MosaicMem 抬升的三维图块）是否比钉在机器人坐标系上更好地保持长程连贯——即把记忆与身体位姿解耦能否减少漂移？
  5. Q5 — 记忆作为 C1/C2/C3 的持久层：把 C1 占据、C2 点图或 C3 潜在四维钉到 C4 的世界坐标系记忆上，能否在分钟级时域上保持其几何连贯——即跨簇的持久性测试？
- **风险**：
  - 显式几何记忆需要可靠的三维抬升——现成估计器在纹理贫乏的场景会失败（MosaicMem）。→ 与隐式注意力混合（MosaicMem 自身的设计），让模型在抬升含噪时优雅降级。
  - 情景记忆检索会在视觉相似但无关的事件上产生干扰（Chameleon）。→ 用消歧的可索引编码加目标导向检索，而非仅靠相似度检索，并在 RoboMemArena 的遮挡/计数切分上验证。
  - 记忆增加占用，与实时部署预算冲突。→ Q5 的「图块级 vs DexWorldModel O(1) TTT」帕累托是是否门槛；持久记忆只有在连贯增益胜过内存代价时才划算。

## Cluster D — 面向具身感知的重建（Reconstruction for Embodied Perception）
### D1 — 交互就绪的场景重建：可在其中行动的整个环境
- **论点**：具身智能体作用的是整个重建环境的*场景级交互就绪性*（几何有效性、物理参数化、运动学可执行性）而非外观。从单段视频烘焙出物理与运动学的管线，应产出可直接使用的交互式环境（Video2Game 单视频 → 100+ FPS 交互式 NeRF + 网格 + 物理），正面应对综述点名的瓶颈——「仿真就绪性高于视觉保真度」（3D Generation for Embodied AI Survey）。*单物体*的物理资产生成是 D2 的领地。
- **第一性原理框架**：
  - *第一性原理*：具身智能体交互的对象是几何、物理、运动学，而非辐射；重建的具身价值在于其*交互就绪性*（能否碰撞、抓取、铰接），这一属性与视觉保真正交，且不由后者蕴含。
  - *挑战的假设*：NeRF/3DGS 的默认观点——更高保真的重建（更好的 PSNR/FID）就是更好的资产；而综述记录了一种转向，即「交互就绪与仿真可部署性*高于*视觉保真」，保真优先的资产往往*并非*仿真就绪，因此目标定错了。
  - *下的赌注*：从单视频烘焙出物理与运动学分解的管线（Video2Game 100+ FPS 环境），能产出无需事后物理标注即可作用的资产，并在保真优先管线至少漏掉一项时满足综述的全部四项标准。
- **具体研究问题**：
  1. Q1 — 就绪与保真的解耦：对同一场景分别按 (a) PSNR 和 (b) 综述四项就绪标准优化；量化保真最优的资产有多大比例不满足某项就绪标准，以验证第一性原理所称的正交性。
  2. Q2 — 单视频的运动学恢复：Video2Game 把场景分解为刚体实体；能否从单视频恢复铰接结构（关节、自由度），从而产出可导出为 URDF/MJCF 的资产，还是说铰接需要多视角/交互数据？
  3. Q3 — 物理参数对策略迁移的充分性：要让在重建资产中训练的策略正确作用，物理参数化（质量、摩擦、恢复系数）需多高保真——即就绪阈值，区别于 Sim2Real 固有的迁移差距问题。
  4. Q4 — 就绪资产 → A/C 消费者：D1 的交互就绪资产能否直接喂给 A1 点云头（作用于几何）与 C1 占据世界模型（在几何上推演）？端到端测试 D→A 与 D→C 这条供应链。
- **风险**：
  - 交互就绪缺乏标准基准——就绪是一份清单而非一个排行榜数字。→ 采用综述四项标准作为显式记分卡（Q1），逐项报告通过/失败，而非单一保真数字。
  - 单视频可能无法恢复复杂场景的铰接/物理。→ 用 Q2 圈定单视频重建能恢复的范围；需要铰接时回退到多视角或交互数据，并陈述边界。
  - 与 Sim2Real-A1/B1 的边界模糊。→ 把 D1 钉死在*以就绪为优化目标*（Q1、Q3）上，并显式把*迁移差距评测*路由给 GS-Playground / Real-to-Sim GS。

### D2 — 物体级物理资产生成：单个物体自带其物理
- **论点**：交互环境可复用的单元是*物体*而非场景——而一个物体只有自带材质、质量与运动学结构（而非仅一张水密网格）才对具身有用。从一遍生成中同时恢复每个物体的材质 + 运动学，应能产出覆盖刚性、可形变*与*铰接三类的仿真就绪资产，正面应对综述点名的可形变资产缺口（PhysX-Omni 运动学得分 0.92；NeuROK Chamfer-L1 0.028，在未见类别上能量守恒）。
- **第一性原理框架**：
  - *第一性原理*：物体的具身价值是一个*联合体*（几何、材质、运动学）——物理不是可分离的事后标签，而是几何必须与之*一致地*生成的属性（网格及其质量/摩擦/关节共同决定它在接触下如何表现）；把二者拆开就丢掉了单遍生成本可强制的一致性。
  - *挑战的假设*：几何优先的三维生成惯例（先生成外观再贴物理，或干脆不贴；并假设可形变/铰接资产必须人工编写）——而 PhysX-Omni 与 NeuROK 表明，*统一*生成器能在同一遍里恢复材质 + 运动学并泛化到未见类别，所以分阶段管线只是纯保真目标遗留下来的产物。
  - *下的赌注*：物理-联合生成的物体，能在刚性 + 可形变 + 铰接三类上达到逐物体就绪（运动学得分 ≥0.92，PhysX-Omni；Chamfer-L1 ≤0.028 且能量守恒，NeuROK），而几何优先生成器 + 下游物理标注至少在一类上失败——且差距*最大处在可形变/铰接*物体，正是综述说尚无就绪方案之处，而非一块网格就近乎够用的刚性物体。
- **具体研究问题**：
  1. Q1 — 联合 vs 分阶段生成：对同一物体分别 (a) 几何优先再标注物理、(b) 经 PhysX-Omni 式统一头联合生成；量化逐项就绪（综述四项）以及分阶段管线在联合管线通过的运动学/材质项上失败的频率。
  2. Q2 — 可形变/铰接缺口落在何处：按物体类别（刚性 / 可形变 / 铰接）拆解就绪；联合生成的优势是否如第一性原理所预测——在刚性物体上近乎为零，而集中在可形变 + 铰接物体上？
  3. Q3 — 能量守恒作为泛化信号：NeuROK 在未见类别上保持能量守恒；在生成时施加物理一致性约束（能量、动量、GausSim 的质量守恒），相比单凭保真（PSNR/Chamfer），能否更好地预测跨类别就绪？
  4. Q4 — 生成物体 → 策略迁移：把 D2 物理-联合生成的物体放进 D1 的重建场景，在仿真中训练的策略能否正确作用于它——且该迁移的约束瓶颈是逐物体材质保真（质量/摩擦）还是运动学结构？
- **风险**：
  - 逐物体就绪在各类别间无共享排行榜——PhysX-Bench 偏刚性/铰接，PhysTwin/PhysHanDI 专攻可形变。→ 采用综述四项标准作为共同记分卡（Q1），按类别（刚性/可形变/铰接）逐项报告通过/失败，而非单一聚合分。
  - 从单视频/稀疏 RGB-D 推得的物理参数可能欠定（仅凭运动学观测不到质量/摩擦）。→ 用 Q3 的物理一致性约束（能量/动量）正则化欠定参数，并把声明限定在约束能辨识它们之处。
  - 与 D1 的边界在「物体」与「场景」相互渗透时变模糊。→ 把 D2 钉死在*单物体*生成单元（Q2、Q4）、D1 钉在*整场景*环境；一个 D2 物体*填充*进 D1 场景是预期的组合（Q4），而非重叠。
