# TL;DR（中文）：3D/4D 空间与几何表示

> [!info] 这是什么
> [[Spatial-4D|3D/4D 空间与几何表示]] 的速览版 TL;DR。每个方向都给出：**核心赌注**、推理逻辑、最尖锐的开放问题，以及风险。完整细节见原文。通俗版见：[[__ELI5-ZH__/Spatial-4D-ELI5|ELI5]]。

> [!abstract] 总览
> 几何是任务中保持不变的部分；外观只是叠加在上面的噪声。夹爪、物体及其接触点位于不随光照、纹理或相机改变而移动的度量级 3D 位置上。非共识的赌注是：动作信号由几何通道携带，而非外观——而且恰恰在几何稳定但像素移动的场景里（跨本体、视角偏移、遮挡、长时程），与 RGB 的差距会*拉大*。学界把显式 3D 当作额外开销。这 11 个方向把损失函数建立在 3D 之上。

## 簇图谱
| 簇 | 方向 | 共同瓶颈 |
|---|---|---|
| A — 几何原生策略 | A1–A3 | 动作头读取/预测 RGB 词元，把度量级 3D 留作隐式，并付出与本体绑定的数据成本 |
| B — 3D 锚定的认知 | B1–B2 | 推理未锚定到度量级几何：在 RGB 上做语言思维链会臆造空间关系与动力学 |
| C — 几何原生世界模型与记忆 | C1–C4 | 世界模型在像素中想象；几何是事后恢复的，无法对外使用、不是原生 4D、也不能在长时程上保持 |
| D — 面向具身感知的重建 | D1–D2 | 重建优化的是辐亮度，而非交互就绪度；资产不具备物理或运动学就绪性 |

## A — 几何原生策略
*条件状态是度量级几何，而非 RGB 词元。这三个方向覆盖了成本/收益前沿：一个完整的点云头、一个占据前向模型，以及一条廉价的深度词元旁路通道。*

### A1 — 点云原生动作头 vs RGB 词元策略
> [!abstract] 核心赌注
> A1：Point Cloud Matters 用简单编码器证明了几何优于 RGB 的优势。赌注是：这一优势在 2D 预训练 VLA 规模下依然成立，*而且*大部分可以从稀疏几何中恢复出来。(i) 恢复率-密度曲线的拐点远低于 GeoVLA 的完整分支——在 DP3 级稀疏度下即可获得完整分支 SR 增益的 ≥80%。(ii) 携带 43.0% xArm7 零样本迁移的是点*表示*本身，而非 PointAction 的分解式解码器：把点换成 RGB 特征（固定解码器）会让大部分增益崩塌；换解码器（固定点）则不会。

**为什么** — 当今的策略（SpatialVLA、OpenVLA 类）向动作头喂入 RGB 词元，把度量级 3D 留作隐式。GFM-VLA Study 对 GR00T-N1.5 的 VLM 输出做线性探测，深度 RMSE 为 0.73 m，而几何模型为 0.41 m。

**第一性原理**
- *原则：*动作是度量级 3D 布局的函数；点云直接说出了这个布局。
- *被挑战：*OpenVLA/SpatialVLA 所谓「3D 分支是浪费的开销」。Dexterity-BEV 在偏移后的 LIBERO 上保持 89.9%，而 2D 崩塌到 <10%。
- *赌注：*该优势在 VLA 规模下依然成立，DP3 级稀疏几何能恢复其中大部分，而胜出在于表示，而非架构。

**最尖锐的问题**
1. 点 > RGB 的优势在 2D 预训练 VLA 规模下是否依然成立？
2. 余量是否随偏移增大而增长、并在零偏移处约等于 0？
3. 最廉价几何的拐点在哪里——稀疏点条件能否恢复完整分支增益的 ≥80%？
4. 在 PointAction 上做 2×2 互换，携带零样本迁移的是表示而非解码器吗？
5. 原生点头在 OOD LIBERO-Plus 上是否能击败最佳潜在几何策略（VLA-JEPA、3DThinkVLA），但在分布内只打平？

> [!warning] 风险
> - 深度可能有噪声或不可用。对策：预测点图路径（PointAction）。
> - 优势可能在已饱和的 ID 基准上消失（LIBERO ~97%）。对策：在外观偏移与跨本体划分上评测；ID 上预期持平。
> - 完整 3D 分支会增加延迟。对策：最小几何扫描与 A3 的深度桥。

### A2 — 用占据预测作为策略的前向模型
> [!abstract] 核心赌注
> A2：一个*稠密显式*的体素占据前向模型，在 RoboCasa 规模下、漂移前能比像素世界模型基线保持准确 ≥10× 更长（发散前时程）。其 Warp-DiT 误差界（刚体变换精度保证）可延续到亚厘米级。其预测出的占据可以为 A1 的点头提供条件——一个完全几何化的「感知-想象-动作」闭环，在长时程 SR 上击败当前帧条件。还没有任何占据-操作论文做过其中任何一项。

**为什么** — 默认的像素前向模型每一步都要重新解析成几何，因此漂移迅速累积（驾驶领域的像素/占据世界模型上限为 <50 帧）。规划器需要知道哪些区域将被占据——体素网格直接给出答案。OccSim 的 80× 时程增益（4+ km 上超过 3,000 帧）表明像素底座正是漂移的来源。

**第一性原理**
- *原则：*规划原生的状态是占据，而非像素。
- *被挑战：*像素前向模型的惯例；OccSim 的 80× 和 RigidFormer 的显式状态稳定性表明几何能预测得更远。
- *赌注：*稠密显式体素底座（超越 ACID 的隐式场、3D-Occ-MPC 的单物体）在 RoboCasa 规模下能保持 ≥10× 像素基线的时程。

**最尖锐的问题**
1. 把世界模型的像素环路换成稠密体素占据（固定骨干网络）——发散前时程是否上升 ≥10×（RoboCasa 规模）？
2. OccSim 的 Warp-DiT 界在操作所需的亚厘米级体素上是否成立？
3. 把未来占据预测喂入 A1 的点头，是否在长时程成功率上击败当前帧条件？
4. 显式占据在时程上是否击败潜在 4D（X-WAM），同时在逐帧 Chamfer 上落败？（若是则两者互补）

> [!warning] 风险
> - 驾驶（米级/静态）vs 操作（亚厘米/动态）。对策：分辨率扫描与动态智能体类比；报告 Warp-DiT 在哪里失效。
> - 占据真值稀缺。对策：从深度加夹爪几何推导，或在仿真中预训练。
> - 体素网格在亚厘米级下占用大量内存。对策：限定在末端执行器的稀疏分层八叉树。

### A3 — 深度词元桥：无需重训即可把 3D 感知注入预训练 2D 策略
> [!abstract] 核心赌注
> A3：交付物是无人产出过的那个*测量值*（PointVLA 已经解决了存在性问题）。(i) 在同一骨干网络上，绘制深度词元桥的恢复增益 vs 新增参数曲线：曲线出现拐点，以低于完整分支的成本恢复 GeoVLA 完整 3D 分支 SR 增益的 ≥80%。还没有找到论文绘制过这条曲线。(ii) 这条冻结骨干的旁路通道对一个留出的 VQA 语义对齐探测的扰动，*小于*回传到骨干的完整分支融合——这正是所有人都假定、但 PointVLA 从未量化过的对齐成本。

**为什么** — A1 和 A2 把已部署的 RGB 预训练策略存量晾在一边。2D 策略的空间弱点是一个*缺失通道*（深度），而非被破坏的表示——通过一个解耦专家以词元形式把它加进来。「真正的 3D 需要一条完整并行分支外加重训」这个假设*已被推翻*：PointVLA 冻结了骨干；Spatial Forcing/VEGA 在零推理开销下蒸馏几何。

**第一性原理**
- *原则：*缺失通道是被补上的，而非重新学习——深度作为廉价的早期通道进入。
- *被挑战：*廉价 vs 昂贵的伪二元对立（已由 PointVLA / Depth Helps / Spatial Forcing 终结）；前沿与对齐成本仍未被跑通。
- *赌注：*存在一个以低于完整成本恢复完整分支增益 ≥80% 的拐点，而旁路通道几乎不扰动对齐。

**最尖锐的问题**
1. 在同一骨干上扫描深度词元容量——以参数的一小部分恢复 GeoVLA 完整分支增益 ≥80% 的拐点在哪里？
2. 冻结骨干的深度专家对 VQA 对齐探测的扰动，是否小于完整分支回传融合？
3. 仅训练时蒸馏（Spatial Forcing、SwiftVLA）能否在零推理成本下匹配推理期深度通道？
4. 驱动噪声鲁棒性增益的是量化（而不只是解耦专家）吗？
5. 第二视角的深度词元能否弥合到完整 3D 的差距？

> [!warning] 风险
> - 在最难任务上可能停在完整 3D 上限之下。对策：恢复率曲线设定预期；将其定位为成本效率前沿。
> - 深度词元质量取决于估计器。对策：QDepth-VLA 的量化能缓冲噪声；报告敏感性。
> - 旁路通道仍可能扰动对齐。对策：用 VQA 探测为「无干扰」主张设门槛。

## B — 空间推理作为一个 3D 锚定的认知层
*在显式度量级几何之上推理，位于动作头的上游。B1 锚定物体*在哪里*（场景图）；B2 让它在*时间上*保持连贯（4D 一致性）——同一层的空间与时间两半。*

### B1 — 用于度量级空间推理的显式 3D 场景图思维链
> [!abstract] 核心赌注
> B1：增益来自*度量级*内容，而非图拓扑，且瓶颈在*构建*，而非推理。(i) 带度量级边标签（距离、角度）的场景图在 CVBench 上击败拓扑图；差距集中在度量关系类型上，而在物体命名上约等于 0。(ii) 当场景图思维链在 CausalSpatial 因果切片上出错时（GPT-5 54.17% vs 人类 84.49%），大多数错误可追溯到一个*错误的图*（臆造或缺失实体）——构建准确率预测答案准确率。

**为什么** — 多模态大模型会*描述*度量级空间，缺乏锚定时就臆造；在因果任务上 GPT-5 得分 54.17% vs 人类 84.49%，过度自信。空间关系构成一个由几何实体组成的图；语言是一种有损的序列化。VLM Spatial Reasoning RL 表明朴素思维链甚至可能*有害*，只有结构化的场景图思维链才有帮助——但「任何图都有帮助」并未说明是哪个属性携带了增益。

**第一性原理**
- *原则：*正确推理*就是*在几何实体的度量级图上运算。
- *被挑战：*规模化观点（被 VLM Spatial Reasoning RL、CausalSpatial 的 30 分差距所推翻）以及「任何结构都有帮助」的共识；度量 vs 拓扑、构建 vs 推理均未被检验。
- *赌注：*度量级边内容携带增益，而构建是瓶颈。

**最尖锐的问题**
1. 度量级边标签（距离、角度）是否在 CVBench 上击败拓扑图，差距集中在度量关系类型上？
2. 当场景图思维链在因果切片上出错时，大多数错误是否可追溯到错误的图？
3. 与人类的差距是否会分裂——弥合*轨迹*（推理）部分，但几乎不弥合*遮挡*（感知）部分？
4. RL 锚定在把场景图习惯迁移到 OOD 因果案例上，是否比 SFT 做得更好？
5. 上游的场景图锚定能否部分替代 A1 的下游几何？

> [!warning] 风险
> - 构建可能臆造并毒化推理。对策：锚定到 B2 的 4D 一致性与深度；单独报告构建准确率。
> - 增益可能是基准特定的（针对 CVBench 调优）。对策：RL-on-OOD 协议检验跨基准迁移。
> - 与人类的差距可能受感知约束。对策：把两者分开；若受感知约束，则路由到 A3 的深度桥。

### B2 — 4D 一致策略：把时空几何作为推理约束
> [!abstract] 核心赌注
> B2：驱动 OOD 增益的是一致性*约束*——而非单纯的 3D 或视角几何——且它必须在*完整*的空间+时间 4D 上成立，而不是 GeoAware 圈定的仅视角切片。在*固定感知*的前提下消融 ConsisVLA-4D 的一致性注意力：OOD SR 崩塌（趋向 MolmoAct 72.1% 的基线）的幅度，大于消融任何单一感知特征，也大于它对 ID SR 的削弱。还没有论文做过这种隔离。

**为什么** — 一个在时程上规划的策略，必须让物体几何与身份跨时间和视角保持连贯，否则第 1 步动作会被臆造的第 5 步场景作废。现有的两种答案都不够：投影偏置的 2D（廉价、不一致）和显式未来帧生成（昂贵）。ConsisVLA-4D 用*隐式*一致性注意力同时获得了显式 3D 的精度*和* 2.31× 加速。

**第一性原理**
- *原则：*一个跨时程的动作需要一条在时间和视角上一致的 4D 轨迹。
- *被挑战：*2D vs 帧生成的二元对立（被 ConsisVLA-4D 打破）以及「隐式一致性有助于 OOD」的共识；究竟是一致性还是感知在驱动它、在完整 4D 上，均未被检验。
- *赌注：*一致性约束（而非单纯的 3D）才是 OOD 的驱动力。

**最尖锐的问题**
1. 在完整 4D 上，关闭一致性（固定感知）是否让 OOD 成功率崩塌的幅度大于消融任何感知特征、且大于它对 ID 的削弱？
2. 在成功率-延迟平面上，隐式 4D 是否在两个轴上都击败显式（Geometry-aware 4D Robot Video、STARRY），除非需要可读的几何？
3. 是否存在一个时程窗口，隐式一致性在其中最优（超过某一长度时击败 2D，超过更长的长度时输给显式）？
4. 一个场景流先验（LaMP）能否更廉价地恢复大部分一致性增益？
5. 隐式一致性与显式痕迹（MolmoAct）是否能叠加？

> [!warning] 风险
> - 隐式一致性可能不可检视。对策：与 MolmoAct 可操控的推理痕迹搭配。
> - 2.31× 加速仅依赖 ConsisVLA-4D 一个数据点。对策：先绘制完整的隐式 vs 显式成本/精度前沿。
> - 在最长时程上可能悄然失败。对策：时程交叉点界定安全区间；超出后路由到 C4 的持久记忆。

## C — 几何原生世界模型与记忆
*表示是几何，而非外观，并按读取者排序：规划器读取的占据（C1）和跟踪器读取的点图（C2）是外部的；潜在 4D（C3）是内部的；世界坐标系记忆（C4）让其中任何一种持久化。*

### C1 — 占据世界模型作为操作推演的底座
> [!abstract] 核心赌注
> C1：一个体素语义占据世界模型在桌面尺度上、于*发散前时程*上比潜在 4D 基线（同簇 C3，X-WAM）高 ≥10×——这是一场从未做过的正面对决（3D-Occ-MPC、DSR-Net）。但它在逐帧 Chamfer 上*落败*（潜在 4D 的 0.0049），因此两者互补。而它的 Warp-DiT 刚体变换误差界可延续到亚厘米级。

**为什么** — 默认的潜在/像素底座会累积几何误差；推演在数十帧内就漂移。一个带刚体变换约束的占据网格（OccSim 的 Warp-DiT）能界定误差增长，潜在表示则不能。「占据只用于驾驶」的说法是错的（DSR-Net 在 2020 年就做过；Occupancy World Model 把它移植到室内），所以真正的假设是底座不会界定时程——而 OccSim 的 80× 增益说明它会。

**第一性原理**
- *原则：*长时程稳定性追踪逐步几何误差的增长；受刚体变换约束的占据能界定它，潜在表示不能。
- *被挑战：*RGB-D 潜在推演的惯例，以及「底座选择不影响时程」的假设。
- *赌注：*占据在时程上以 ≥10× 击败潜在表示，同时在逐帧上落败，所以两者互补。

**最尖锐的问题**
1. 在匹配的任务上，占据世界模型是否能保持几何稳定 ≥10× 长于 X-WAM 类潜在表示？
2. 现成规划器能否直接对网格做碰撞检测，在延迟和精度上击败 C3 解码后的潜在表示？
3. 预测规划失败的是占据网格漂移（时程上的 mIoU），而非逐帧 Chamfer 吗？
4. 一个混合方案（占据用于长时程，潜在用于逐步细节）在时程 × 保真度上是否击败任一单独方案？
5. Warp-DiT 界能否延续到亚厘米级？

> [!warning] 风险
> - 驾驶（米级）vs 操作（亚厘米）。对策：亚厘米 Warp-DiT 测试是 go/no-go 关口；报告界在哪里失效。
> - 可能与同簇 C3 重叠。对策：把 C1 锚定在可外部渲染的长时程占据与互补性上，而非一个更好的 X-WAM。
> - 占据监督稀缺。对策：在仿真中并从深度加夹爪几何推导；限定在可恢复的真值范围内。

### C2 — 用于 6-DoF 位姿提取的 4D 几何一致视频预测
> [!abstract] 核心赌注
> C2：幸存的判别器是*由现成跟踪器读取的跨视角点图一致性*——不是单视角 RGB-D，不是学习式估计器，也不是仅 RGB 的 Gen6D。联合预测 RGB 加跨视角一致的点图，能产生跟踪器可读的 6-DoF 轨迹，平均任务 SR ≥0.64，而 RGB 加估计器基线约为 0.12（约 5×）。增益追踪*跨视角一致性*（mIoU）：消融点图损失对轨迹精度的破坏，大于降低 RGB 质量（FVD）。

**为什么** — 视频预测方法（Dreamitate 类）先预测未来 RGB，再外挂一个位姿估计器，但仅 RGB 的帧让 6-DoF 位姿存在歧义，所以策略很脆弱（Dreamitate、Diffusion Policy 平均任务成功率均为 0.12）。6-DoF 位姿是几何的：只要点图跨视角一致，任何跟踪器都能读出匹配 3D 点之间的刚体变换。约 5× 的差距表明事后的单视角估计器才是瓶颈。

**第一性原理**
- *原则：*6-DoF 位姿是匹配的跨视角 3D 点之间的刚体变换；一致的点图让它跟踪器可读。
- *被挑战：*像素视频加估计器的惯例（PEWM）以及单视角 RGB-D 的惯例（GVF-TAPE）。
- *赌注：*由跟踪器读取的跨视角点图一致性才是判别器，且增益追踪一致性，而非 RGB 保真度。

**最尖锐的问题**
1. 移除跨视角点图损失（固定 RGB）对轨迹精度和成功率的破坏，是否大于降低 RGB 质量（FVD）？
2. 单视角深度 + 学习式估计器的变体，是否比从跨视角跟踪器读取位姿更差？
3. 预测点图相对于感测点图的位姿读出成本有多小？
4. 视角能移动多远才会让位姿精度退化？
5. 在可调试性重要的场景，外部化几何是否击败内部化（ConsisVLA-4D）？
6. 遮挡是否是预测几何位姿读出胜出最多的地方（呼应 RecGen 的 +38.2 pp）？

> [!warning] 风险
> - 单一锚点：标题数字来自 Geometry-aware 4D Robot Video 的三任务评测。对策：一致性消融与预测 vs 感测对比是有效性检验；扩大任务集。
> - 预测点图可能比感测深度更嘈杂。对策：测量差距；限定在感测不可用的场景。
> - 三任务基础太窄。对策：把贡献定位为*机制*本身，在三个任务上验证，下一步扩大评测。

### C3 — 原生 4D 几何作为世界表示底座
> [!abstract] 核心赌注
> C3：两根支柱决定原生在线 4D 相对于训练时辅助手段是否物有所值；两者都没被跑过，包括 PointWorld 在内。(i) 固定骨干，X-WAM 的交错深度分支在几何受限的 RoboCasa 上击败「像素底座加外挂深度估计器」（Chamfer 0.0049 原生 vs 两阶段 0.0680），隔离出原生优于恢复。(ii) 推广异步噪声采样（一种少步去噪技巧），动作时间表步蒸馏到 1–4 步，把 X-WAM 的 5 步 15 Hz 运行（4665 ms 降到 1033 ms）扩展，且不降低读出几何——这正是 PointWorld 的点流 MPC 从未绘制过的延迟-保真度前沿。

**为什么** — 多数已部署模型在 2D 像素中想象，只能隐式地恢复几何——X-WAM 指出这会产生物理上不可信的预测。对接触密集任务而言，动作是几何的函数，而像素底座每一步都要重新推断它。X-WAM 表明两阶段路径在几何上更差*而且*比带少步（异步）去噪的统一 4D 模型更慢。PointWorld 占据了在线显式 + 迁移的主张，所以 C3 收窄到这两根支柱。

**第一性原理**
- *原则：*动作的几何存在于任务之中，而非渲染选择之中，所以原生 4D 底座能直接携带它。
- *被挑战：*「4D 太贵，两阶段恢复它」的假设（被 X-WAM 打破）；PointWorld 已占据宽泛的在线显式 + 迁移主张。
- *赌注：*原生 4D 在无部署代价下击败「像素后再抬升」，且动作时间表可蒸馏到 1–4 步。

**最尖锐的问题**
1. 固定骨干，X-WAM 的交错深度分支是否在几何受限的 RoboCasa 上击败像素底座 + 深度估计器？
2. 少步（异步）动作时间表能否缩到 1–4 步而不降低读出几何？绘制 Chamfer vs 步数。
3. 原生 4D 的 RGB-D 视频底座能否在外观完好的前提下从世界模型迁移到策略头，匹配 PointWorld 的点流迁移？
4. 显式 3D 通道相对于潜在表示，能否降低接触模式预测误差？
5. 从末端执行器推导的相机位姿能否改善 OOD 几何？

> [!warning] 风险
> - 4D 监督需要多数数据集缺乏的深度/3D 真值。对策：X-WAM 的末端执行器相机位姿加现成深度估计器；限定在可恢复的几何范围内。
> - 4D 只在几何受限任务上才划算。对策：在接触/空间任务（RoboCasa 插入、堆叠）上评分，而非标题级的 LIBERO。
> - 实时 4D 已被展示过两次（X-WAM、PointWorld）。对策：原生 vs 恢复的 Chamfer 消融与延迟-保真度前沿是 go/no-go 关口；承认 PointWorld 占据宽泛迁移。

### C4 — 持久几何记忆作为底座无关的持久层
> [!abstract] 核心赌注
> C4：(i) 一个单一的世界坐标系记忆层，叠加在 C1/C2/C3 各自之上，把分钟级连贯性抬升到裸底座之上，余量追踪 3D Persistent Embodied WM 的 SRC 81.7% vs 无记忆 63.4% 的差距——所以该层能在任何底座上工作，而不只是它为之而建的那一个。(ii) 几何记忆（MosaicMem）与情节记忆（Chameleon）在 RoboMemArena 上*叠加*（在 68.9% 需要历史的子任务上，两者结合击败任一单独方案），因为它们修复不同的失效模式。还没有单篇论文展示过其中任何一项。

**为什么** — 显式几何记忆在长时程连贯性上击败仅注意力，这一点*已经被占据*（3D Persistent Embodied WM，FVD 91.9 vs 194）。开放的缺口是：一个服务于*任何*底座的记忆层，以及一个几何 + 情节记忆*一同*评测的基准。物体恒存性是度量坐标系的一种属性，所以*同一个*世界坐标系机制应当能固定 C1 的占据、C2 的点图或 C3 的潜在 4D。而几何记忆修复*在哪里*，情节记忆修复*哪个事件*——所以它们叠加。

**第一性原理**
- *原则：*物体恒存性存在于度量级世界坐标系中，所以一个持久机制能服务任何底座；几何记忆与情节记忆互补。
- *被挑战：*「记忆每个底座各建一次，几何 vs 情节是二选一」的惯例。
- *赌注：*一个共享层能跨底座迁移，且两种记忆类型叠加。

**最尖锐的问题**
1. 把一个世界坐标系记忆层叠加在 C1/C2/C3 上——每个底座的分钟级连贯性是否以追踪 81.7% vs 63.4% 差距的余量上升？
2. 情节事件与几何记忆在 RoboMemArena 上是否叠加，在需要历史的子任务上击败任一单独方案？
3. 组合优势是否集中在「相似外观或不在视野内」的子任务上、而在纯重访上约等于 0？
4. 世界坐标系记忆是否比机器人坐标系记忆保持连贯性更好？
5. 在同等连贯性下，一个共享层是否比三套定制记忆成本更低？

> [!warning] 风险
> - 几何记忆需要可靠的 3D 抬升；估计器在纹理贫乏的场景上失效。对策：混入隐式注意力（MosaicMem）以实现优雅降级。
> - 情节检索可能在相似但无关的事件上触发。对策：消歧编码加目标导向检索；在 RoboMemArena 的遮挡和计数划分上验证。
> - 记忆增加占用。对策：patch 级 vs O(1)-TTT 的权衡是 go/no-go 关口；只有连贯性增益超过成本时，记忆才值得占一席之地。

## D — 面向具身感知的重建
*为交互就绪度而构建的重建：携带物理与运动学结构的几何，而非辐亮度。按单元划分——D1 是智能体在其中行动的整个场景；D2 是填充其中的可复用单个物体。*

### D1 — 交互就绪的场景重建：你可以在其中行动的整个环境
> [!abstract] 核心赌注
> D1：交付物是 HoloScene 联合目标遗漏掉的*受控测量*与*关节连接*就绪度。(i) 在 PSNR 目标下与综述的四项就绪度判据下构建同一场景。保真度最优的资产更频繁地在 ≥1 项判据上失败；按判据报告通过/失败。（HoloScene 仅把这一点作为消融的副产品浮现出来。）(ii) 单视频重建恢复刚性部件，但在没有多视角或交互数据时，无法为 URDF/MJCF 导出恢复带关节（articulated）的结构——这正是 HoloScene 点名却未跨越的刚体上限。

**为什么** — 重建社区优化辐亮度（PSNR/SSIM/FID）；综述把这点名为具身瓶颈。具身智能体与几何、物理和运动学交互，而非辐亮度——所以它的价值在于交互就绪度，与保真度无关。NeRF/3DGS 的「保真度越高 = 资产越好」的默认*已被记录为错误*（HoloScene 的表 3 权衡；Single-View Mesh for Robotics 未达 2 mm 标准）。

**第一性原理**
- *原则：*具身价值是交互就绪度（碰撞、抓取、关节连接），与视觉保真度无关，且不被它蕴含。
- *被挑战：*「保真度越高越好」的默认（被 HoloScene + Single-View Mesh for Robotics 推翻）；按判据测量与单视频关节连接仍未被跑通。
- *赌注：*保真度最优的场景在就绪度上失败得明显更多，且单视频会漏掉关节连接。

**最尖锐的问题**
1. 为 PSNR 与四项就绪度判据构建同一场景——保真度最优的资产是否更频繁地在 ≥1 项判据上失败？
2. 单视频重建是否能在没有多视角或交互数据时恢复刚性部件、但无法为 URDF/MJCF 导出恢复带关节的结构？
3. 是否存在一个物理参数就绪度*阈值*（质量/摩擦/恢复系数），低于仿真级精确保真度但策略仍能正确行动？
4. 一个 D1 就绪资产为 A1 的点头和 C1 的占据世界模型供料的效果，是否与手工搭建的资产相当？
5. 直接输出仿真器格式，是否在就绪度上击败事后网格化？

> [!warning] 风险
> - 没有标准的就绪度基准；它是一张清单。对策：采用综述的四项判据；按判据报告通过/失败。
> - 单视频可能无法恢复关节连接或物理。对策：界定它能恢复什么；回退到多视角或交互数据。
> - 与 Sim2Real-A1/B1 的边界可能模糊。对策：把 D1 锚定到以就绪度为目标；把迁移差距评测路由到 GS-Playground 与 Real-to-Sim GS。

### D2 — 物体级物理资产生成：一个携带自身物理的物体
> [!abstract] 核心赌注
> D2：决定它的是无人跑过的那个受控证伪实验，而非 PhysX-Omni 已有的生成器。(i) 用两种方式生成*同一*匹配物体集——先几何后标注，以及通过 PhysX-Omni 式统一头联合生成。分阶段流水线更频繁地在运动学/材料就绪度判据上失败，集中在可变形 + 带关节物体上、而在刚性道具上约等于 0（SOPHY 跳过刚体的选择暗示了这一点）。(ii) 一个物理一致性度量（能量/动量守恒检查，NeuROK 式，Chamfer-L1 ≤0.028）比保真度（PSNR/Chamfer）更好地预测跨类别就绪度——这是没有任何评分卡隔离出来的泛化信号。

**为什么** — D1 构建整个场景；其可复用部件是物体。保真度优先的物体是一个空壳道具——一个没有质量、摩擦或关节的水密曲面（综述把这点名为瓶颈，可变形资产尚未解决）。一个物体的具身价值是几何、材料与运动学的*联合体*。几何优先的惯例*已被推翻*（PhysX-Omni、SOPHY、UniArt 各自在一次通过中生成物理与几何）——但一个生成器*存在*并不证明联合 > 分阶段。

**第一性原理**
- *原则：*一个物体在接触下的行为由几何、材料与运动学联合决定，所以它们必须一同生成。
- *被挑战：*先几何后标注的惯例（被 PhysX-Omni / SOPHY / UniArt 推翻）；匹配物体的联合 vs 分阶段证伪实验、以及「一致性预测 OOD」检验仍未被跑通。
- *赌注：*联合生成在分阶段失败的地方通过就绪度，在可变形与带关节物体上差距最大；一致性（而非保真度）预测跨类别就绪度。

**最尖锐的问题**
1. 在一个匹配物体集上，分阶段的「先几何后标注」是否比联合生成更频繁地在运动学/材料就绪度判据上失败？对刚性、可变形、带关节分别评分。
2. 联合优势是否在刚性道具上近乎为零、集中在可变形 + 带关节上（让 SOPHY 跳过刚体的选择显式化）？
3. 生成时的能量/动量一致性约束，是否比保真度（PSNR/Chamfer）更好地预测跨类别就绪度？
4. 放进一个 D1 场景中，绑定迁移约束的是生成物体的材料还是其运动学结构？
5. 可变形是否是最宽的差距和最大的单次通过收益？

> [!warning] 风险
> - 没有共享的跨类别排行榜（PhysX-Bench 偏向刚性/带关节；PhysTwin、PhysHanDI 是可变形专用）。对策：采用综述的四项判据；按类别报告通过/失败。
> - 来自单视频或稀疏 RGB-D 的物理参数可能欠定。对策：能量/动量一致性约束对其正则化；限定在它们被确定的范围内。
> - 与 D1 的边界可能模糊。对策：把 D2 锚定到单物体单元，D1 到整个场景。一个 D2 物体放进一个 D1 场景，正是预期的组合方式。
