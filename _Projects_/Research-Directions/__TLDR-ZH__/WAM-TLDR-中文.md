# TL;DR（中文）：世界动作模型（WAM, World Action Model）

> 原始研究方向文档：[[WAM|World Action Models Research Directions]]（`_Projects_/Research-Directions/Mechanism/WAM.md`）。本篇是它的中文 TL;DR：逐方向给出**论点、第一性原理框架、具体研究问题、风险**四块，其余细节请回原文。

## Cluster A — WAM 底层表示与编码

### A1 — 混合潜空间+像素的 WAM 架构
- **论点**：「训练时用稠密信号、部署时丢掉稠密头只跑潜空间」这套混合机制本身已经坐实（UVA：单骨干、部署丢稠密头、纯潜空间推演、+40% OOD）。业界默认那个被丢掉的稠密头**形式无所谓**，于是从不去跑密度扫描。赌注：一个可渲染的 **3DGS 稠密头**（部署时丢弃）在 LIBERO-Plus 的 OOD 保持率上、于**同等分布内成功率**下，比一个**等容量的 2D 视频稠密头**（UVA 那种）高 ≥5 pp，同时把纯潜空间部署路径的延迟压在纯潜空间的 2× 以内、远低于像素 WAM 的 4.8× 成本。剩下唯一的非共识量，就是「3D 结构 × OOD」相对 UVA 视频头的那点增益。
- **第一性原理框架**：
  - *第一性原理*：训练密度与部署密度相互独立——模型可以从像素/3DGS 稠密信号中学习，却在潜空间稠密信号上行动；塑形权重的监督，与承载推演的表示，本就是解耦的，稠密分支只是部署路径无须保留的「老师」。GaussianDream 直接证明了这种解耦：可渲染 3D 头只存在于训练期、推理时丢弃且无成功率损失。
  - *挑战的假设*：不是裸的「丢稠密头」机制——UVA 已坐实「单骨干、丢头、纯潜空间推演、+40% OOD」，UWM 也复现了，这点已定。真正还活着的假设是被丢掉那个稠密信号的**形式可互换**——2D 视频头和可渲染 3DGS 头买到一样的 OOD，于是没人跑密度扫描。GaussianDream 与 GeoSem-WAM 暗示 3D 结构头不一样，但都没隔离出「3D 结构在同等分布内成功率下到底多买了多少 OOD」。
  - *下的赌注*：在同等分布内成功率（双方都压到 ≥97.2%，VLA-JEPA 纯潜空间基准）下，可渲染 3DGS 稠密头在 LIBERO-Plus OOD 保持率上比等容量 2D 视频头高 ≥5 pp，同时纯潜空间部署延迟 <2× 纯潜空间、远低于 4.8× 像素 WAM 成本——这是一次受控的密度扫描，而非单个工作点。可解释性只是定性附带，不进可证伪声明。
- **具体研究问题**：
  1. H1 — 3DGS 稠密头在同等分布内成功率下 OOD 胜过等容量 2D 视频头：三臂 A/B（无稠密头 / 2D 视频头 / 3DGS 头，等容量），均纯潜空间部署，比 LIBERO-Plus OOD 保持率（落点 GaussianDream vs UVA vs VLA-JEPA）。
  2. H2 — 部署密度前沿在纯潜空间延迟的 2× 以内：扫描部署表示从全像素到纯潜空间，真机成功率维持 ≥50% 时延迟 <2× 纯潜空间、远低于 4.8× 像素成本（落点 Flash-WAM 348 ms / WAM-vs-VLA 鲁棒性 4.8× 锚）。
  3. H3 — 共享潜变量 z 让一个骨干兼解码像素（看）与潜空间（动）：用 Pelican-Unified 的共享 z，想象解码到像素/3DGS、动作解码到潜空间，相对双从潜空间解码无成功率损失。
  4. H4 — 过程自适应门控胜过固定部署表示：按接触预测在纯潜空间（自由移动）与像素/3DGS 辅助（预测到接触）间切换，在接触密集任务上胜过 HarmoWAM 的固定双专家门控。
  5. H5 — 语义潜空间监督能在稠密像素分支下存活：DexWorldModel 的 DINOv3 目标优势在稠密像素/3DGS 分支协同监督下仍成立（不被冲淡），印证 A3 的正交性。
  6. H6 — 蒸馏与协同训练落在前沿的不同点：Flash-WAM 的事后蒸馏与协同训练的稠密头/潜空间混合体落在不同的成功率-延迟工作点（蒸馏训练更省但 OOD 保持更低）。
- **风险**：
  - 双分支训练成本主导算力开销。→ 采用 GaussianDream 的「推理时丢弃」模式 + Flash-WAM 的 23× 蒸馏，把预训练的像素/3DGS WM 蒸馏进潜空间编码器；H6 检验蒸馏能否以更低训练成本追回协同训练的 OOD。
  - 缺乏共享参数时，潜空间与像素会发散、被丢的头反而误导。→ 两分支锚到共享目标（DexWorldModel 的 DINOv3 目标）；H5 检验语义锚能否在稠密分支下存活。
  - 性能饱和区：纯潜空间已达 97.2% LIBERO、GaussianDream 已达 98.4%，分布内成功率无法区分方法。→ 把赌注绑定在 OOD（LIBERO-Plus）+ 部署延迟，而非分布内成功率；H1/H2 在此评分。

### A2 — 触觉/力觉融合的 WAM 想象
- **论点**：业界现在已经会「预测力」了，但要么是塞给策略的低维**当下力词元**（FD-VLA，无传感器也能拿 61.1%、胜过带传感器），要么是预测**触觉图像**（DreamTacVLA）。真正还没被占住的楔子，是把力表示成一个 WAM **向前推演、且策略在想象内部据之行动的「未来 6-DoF 力旋量」**（力+力矩）——因为在接触中力是生成性的因、所见是果，因果律就活在这个未来力旋量推演里。赌注：这样一个未来力旋量头在接触任务成功率上比 FD-VLA 的当下力词元（61.1%）高 ≥5 pp，且部署时无力传感器，并挽回 DexViTac「有触觉→无触觉」下降量的 ≥50%（移液 83.3%→43.3%），逼近其 85.8% 上限。能活下来的三点区分——*未来*时态、*6-DoF 力旋量*结构、*在推演内部被据以行动*——是承重新意，没有任何单篇论文三者全占。
- **第一性原理框架**：
  - *第一性原理*：在接触中，力是因、所见是果——物体之所以移动，正是*因为*受了力旋量。只向前推演果、缺了因这个变量的 WM，无法完整钉死接触动力学。数据前提现已充分满足：DexViTac 消融（无触觉预训练 83.3→43.3%）表明触觉潜空间携带视觉所缺的因果信息，FD-VLA 更证明这信息单凭视觉+本体感受就*可预测*（无传感器 61.1% > 带传感器 38.9%）——所以力旋量*推演*头有可解的目标。
  - *挑战的假设*：不是「力从未被预测」——FD-VLA 预测*当下*无传感器力词元（还胜过真传感器），HTD 预测*未来*逐关节力，裸的「预测力」声明已被占住。真正还活着的假设是：被预测的力只是个**被策略当输入消费的低维词元**——FD-VLA 的词元不透明（扭矩从未解出）、由动作专家读取而非向前推演；DreamTacVLA / Dream-Tac 预测的是触觉*图像*，不是力旋量。没人把力表示成 WM 向前推演、策略在*想象内部*据之行动的结构化*未来 6-DoF 力旋量*——而这正是因果「力→运动」律可被利用的地方。
  - *下的赌注*：一个把*未来 6-DoF 力旋量*作为向前推演的 WM 输出、策略在想象内据之行动的 WAM 头，在部署*无力传感器*下，接触任务成功率比 FD-VLA 当下力*词元*基准（61.1%）高 ≥5 pp，并挽回 DexViTac 触觉下降量的 ≥50%（移液 83.3→43.3，即把地板抬回约 63%），逼近带触觉 85.8% 上限。可证伪：若向前推演的力旋量在同等成功率下与 FD-VLA 的当下词元打平，则时态+推演角色相对被消费的力词元一无所添。
- **具体研究问题**：
  1. H1 — 未来力旋量推演头在部署时胜过当下力词元：6-DoF 力旋量头*向前推演*（预测 $\hat{\mathbf{w}}_{t+1..t+k}$、策略据推演行动），用 VTouch++ 的 3600 万同步帧 + Sparsh-X 的 100 万次接触训练，无传感器下比 FD-VLA 当下力词元 61.1% 高 ≥5 pp（落点 FD-VLA vs DexViTac）。
  2. H2 — 触觉潜空间作为跨传感器想象目标：以 TaF-VLA 的 VQ-VAE 力潜变量（或 DexViTac 的运动学锚定潜变量）作为 WAM 想象目标、按需逐传感器解码，胜过 TaF-VLA 60.3% 的策略侧跨传感器迁移（落点 TaF-VLA）。
  3. H3 — 想象力 vs 实测力作为有用的辅助损失：训练时（有传感器处）用实测力旋量监督想象力旋量，比等容量的纯本体感受辅助损失更提升接触任务成功率（落点 VTouch++）。
  4. H4 — 接触建立/断开更宜建模为离散潜空间转移：把建立/断开当作类别事件、连续力仅在接触状态内，在滑-粘任务上胜过纯连续力旋量头（与 B1 的离散接触模式共享底座；落点 DexViTac / 交叉引用 B1）。
  5. H5 — 力条件视频预测反向跑出可用的力预报：反转 Force Prompting（从帧预测力、再以预测力作为下一步条件），给出足够准的力预报以改进下一步操作（落点 Force Prompting）。
- **风险**：
  - 噪声底：细微滑移、微振动并不体现在视觉中——想象力可能淹没在实测力的噪声底之下。→ 把论断限定在力与视觉相关的区域、显式报告噪声底，并与 H4 的离散接触事件配对（视觉不提供信息处）。
  - 跨传感器脆弱性：60.3% 的零样本成绩（TaF-VLA）尚不足以部署。→ 借 DexViTac 的运动学锚定来稳定跨传感器潜空间；H2 检验「想象为目标」是否胜过「策略当消费者」。
  - 力预测现已拥挤——楔子是「时态+结构+角色」，不是「预测力本身」：FD-VLA 预测当下力（且胜过传感器）、HTD 预测未来关节力、DreamTacVLA / Dream-Tac 预测未来触觉图像、FACTR 2 估计当下 6-DoF 力旋量。→ 不要宣称「首个预测力」，只宣称交集（未来 + 6-DoF 力旋量 + 在推演内部被据以行动），并把 H1 锚向 FD-VLA 的当下力词元、以推演角色为承重新意。

### A3 — WAM 想象的潜空间编码质量
- **论点**：「语义/预测式潜空间胜过重建/静态」这一侧现已跨骨干坐实（JEPA-VLA）。真正还**开放且有争议**的，是瓶颈的*类型*：连续 vs 离散-FSQ vs VQ，以**闭环控制成功率**裁决——因为策略消费的是动力学而非像素，编码器被要求保留什么就给控制定了天花板。DiLA 押连续瓶颈、CompACT 押离散-FSQ 赢控制，两篇直接对立。赌注：在架构相同、部署延迟相同时，连续/语义潜空间与离散-FSQ 潜空间**不会打平**——必有一方在闭环成功率上高 ≥5 pp，从而了结 DiLA↔CompACT 之争；同时 Semantic-LDM-WM 的重建-vs-语义差距（+9.8 pp 闭环 / +13.6 pp OOD）能在第二个非 LDM 骨干上*带重建臂*复现（JEPA-VLA 当初漏了重建臂）。
- **第一性原理框架**：
  - *第一性原理*：策略消费的是动力学，而非像素。一个被训练去重建外观的潜空间，会把容量浪费在控制器丢弃的细节上；一个被训练去预测未来语义的潜空间，则恰好保留与动作相关的结构。编码器*被要求保留什么*，给下游控制定了一个天花板——下游再怎么改架构都抬不上去。Semantic-LDM-WM 的受控替换证明了这点：LDM 固定、只换编码器目标，闭环成功率即摆动 +9.8 pp。
  - *挑战的假设*：不是「语义胜过静态、且已跨骨干复现」——JEPA-VLA 已在非 LDM 骨干上跑过那次替换（视频预测式 > DINOv2/SigLIP，+6.7% OOD），重建-vs-语义的*方向*已成共识。真正还活着、且*有争议*的假设是：瓶颈*类型*会朝连续一边收敛——DiLA 押连续 > VQ/VAE，但 CompACT 押离散-FSQ 赢*控制*，而没人在同维度下跑过重建/VQ/连续三臂、以闭环成功率打破这个平局。
  - *下的赌注*：在架构相同、部署延迟相同时，连续/语义潜空间与离散-FSQ 潜空间*不*打平——一方闭环成功率高 ≥5 pp，了结 DiLA↔CompACT 矛盾；且重建-vs-语义差距（Semantic-LDM-WM 的 +9.8 pp 闭环 / +13.6 pp OOD）在第二个非 LDM 骨干（JEPA-VLA 漏了的重建/VAE 臂）上复现。可证伪：若重建、VQ、连续在同维度闭环成功率上三者打平，则瓶颈类型对控制是自由选择，只有（已定的）静态-vs-预测式之分才要紧。
- **具体研究问题**：
  1. H1 — 重建-vs-语义差距在非 LDM 骨干上*带重建臂*复现：在 JEPA-VLA 骨干上做三臂替换（重建-VAE / DINOv2 / V-JEPA 2），复现 Semantic-LDM-WM ≥9.8 pp 闭环 / ≥13.6 pp OOD 的语义胜重建差距——JEPA-VLA 当初漏掉的对比（落点 Semantic-LDM-WM → JEPA-VLA）。
  2. H2（领衔）— 瓶颈类型在闭环控制上打破 DiLA↔CompACT 平局：固定潜空间维度，消融 DiLA 连续瓶颈 vs CompACT 离散-FSQ vs LGQ/VQ 分词器，三者*不*在闭环操作成功率上打平、必有一方高 ≥5 pp，为*控制*而非生成/规划延迟了结连续-vs-离散之争（落点 DiLA vs CompACT vs LGQ）。
  3. H3 — 解耦动力学在动作条件下存活并助益控制：VideoWorld 2 的动力学/外观切分在动作条件下仍成立，且仅留动力学潜空间给策略，在固定部署成本下胜过纠缠潜空间（落点 VideoWorld 2）。
  4. H4 — 赢得控制的编码通过可辨识性检验：赢得控制的潜空间（语义/连续）正是通过 LeJEPA World Model 各向同性高斯可辨识性检验的那些——编码质量是该成员资格判据的代理（落点 LeJEPA / VLA-JEPA）。
  5. H5 — 语义潜空间优势在 A1 的稠密像素分支下存活：当稠密像素/3DGS 分支监督训练（A1 混合）时，语义潜空间优势仍在、不被稠密像素监督冲淡（正交性声明；落点 Semantic-LDM-WM / 交叉引用 A1）。
  6. H6 — 不确定性感知编码专在干扰下取胜：VJEPA-Probabilistic 的变分瓶颈*专门*在干扰密集 OOD 上（R²>0.84 vs ~0.50）胜过确定性语义编码器、在干净任务上打平，证明取胜来自丢弃噪声机制而非容量（落点 VJEPA-Probabilistic）。
- **风险**：
  - 编码增益是数据集特定的：+9.8 pp / +13.6 pp 的摆动可能离开 Semantic-LDM-WM 的 Bridge-V2 设置就不再成立。→ H1 先在第二个骨干+数据集上复现，再宣称杠杆通用；逐数据集报告 delta。
  - 语义潜空间需要架构适配：高维 SSL/VL 潜空间历来会破坏扩散训练的稳定性。→ 复用 Semantic-LDM-WM 的宽头 DiT + S-VAE 压缩配方，而非直接喂入原始高维潜空间；H2 把稳定性作为一等度量。
  - 编码质量 ≠ 可控性：一个能很好恢复动作的潜空间，规划起来仍可能很难。→ 把 IDM 可恢复性度量与闭环成功率、LeJEPA World Model 的可辨识性检验（H4）配对使用，而非只看动作恢复。

## Cluster B — WAM 训练时现实锚定

### B1 — 接触感知的精细操作（离散模式）
- **论点**：「离散胜过平滑」的结构性跳变论点现已成共识（PRISM-WM），但只在*运动*领域、用*隐式*学习门证明过。给 WAM 一个*显式、由触觉监督*的接触模式潜变量（无接触、建立、接触中、断开、滑移）用于亚毫米级操作——不是隐式自学的门，也不是放大的平滑潜空间。它必成立的理由：接触物理尖锐跳变，而在装配精度下，建立/断开/滑移的标签太稀疏，奖励驱动的门发现不了。赌注：*显式触觉监督*的模式（其分类法从 DOT-Sim 接触真值蒸馏，而非奖励门发现）达到 >90.5% AutoMate 成功率和亚毫米级装配，这是 (a) 纯平滑 WAM 在任何规模、(b) PRISM-WM 隐式 MoE 门模式潜空间在缺少触觉监督分类法时**都达不到**的，并超过 SPARR 在未见 NIST 迁移上 +74.5% 的相对提升。
- **第一性原理框架**：
  - *第一性原理*：接触物理是尖锐跳变的——摩擦锥边界、法向力奇异点、滑-粘都是突兀的、离散的状态切换，跳变源于物理本身。平滑潜空间只能在内部切成离散块才能表示硬台阶，逼近代价在边界处指数上升。DOT-Sim 的可微接触仿真证明建立/断开/滑移是*范畴上*不同、各有支配方程的区制。
  - *挑战的假设*：不是裸的「离散胜过平滑」结构性跳变论点——PRISM-WM、DHAL 与切换动力学文献已持有它，在混合系统圈内已是共识。真正还活着的假设是：离散结构可以保持*隐式、自学*（PRISM-WM 的 MoE 门从奖励中发现模式、DHAL 的自动机从滑行中涌现）。本方向押反面：在*亚毫米级操作*中模式必须是一套*由触觉接触真值监督的显式建立/断开/滑移分类法*——容量和自学门都在装配精度前就触顶，那里标签太稀疏、发现不了。DexWorldModel 的连续因果潜空间触顶；Discrete-WAM 的离散性是场景级、非接触级。
  - *下的赌注*：一个*显式、触觉监督*的接触模式 c_t ∈ {无接触, 建立, 接触中, 断开, 滑移}——分类法从 DOT-Sim 接触真值蒸馏、而非奖励门发现——达到 >90.5% AutoMate（接触无感天花板）与亚毫米级装配，这是 (a) 纯平滑 WAM 任何规模都够不着、且 (b) PRISM-WM *隐式* MoE 门模式潜空间在缺触觉监督分类法时也匹配不了的。可证伪：若放大的平滑潜空间*或*隐式自门离散潜空间在亚毫米插入上匹配了触觉监督分类法，则显式监督的声明就错了。
- **具体研究问题**：
  1. H1 — 显式触觉监督的接触模式潜空间在亚毫米插入上同时胜过平滑潜空间与*隐式*模式门：在 DexWorldModel 式因果潜空间上加由 DOT-Sim 触觉标签监督的 c_t，做三臂 A/B（纯连续 / 隐式门离散 / 显式触觉监督离散）等容量比 AutoMate >90.5%（落点 DexWorldModel vs PRISM-WM vs 显式触觉监督变体）。
  2. H2 — 放大的平滑潜空间补不上鸿沟：放大 PhysWorld 连续物理 WM（维度/层/参数）使插入成功率次线性、并*低于*离散模式 WAM 触顶——跳变对容量不敏感（落点 PhysWorld）。
  3. H3 — 接触模式条件物理损失胜过单一全局物理损失：库仑摩擦仅在「接触中」、弹道运动仅在「无接触」（模式门控损失），在接触起始密集任务上胜过区制无关的全局损失（落点 asRoBallet 作损失先验）。
  4. H4 — 蒸馏 DOT-Sim 接触真值提供平滑 WAM 缺的监督：把 DOT-Sim 可微建立/断开/滑移标签蒸馏进离散模式潜空间，使接触模式分类精度高到下游插入成功率随之走——平滑 WAM 无法自造这些标签（落点 DOT-Sim）。
  5. H5 — 离散接触模式在 AutoMate / NIST 上 sim-to-real：在 Real-to-Sim GS 孪生体上训练、真机 AutoMate / NIST 评测，零样本保住接触模式优势，超过 SPARR 在未见迁移上 +74.5% 的相对增益（落点 SPARR / Real-to-Sim GS）。
  6. H6 — 接触事件时间预测是有用的辅助头：辅助回归头预测接触起始时刻 t̂_contact（仿真器监督），改善接触前减速、在不含它的离散模式 WAM 之上抬升插入成功率（落点 DOT-Sim 提供时序监督）。
- **风险**：
  - 离散潜空间难以优化：Gumbel-softmax / REINFORCE 的方差大。→ 先软后硬，训练中退火温度逐步硬化；把接触模式分类精度作为下游成功率前的收敛诊断。
  - 接触模式监督依赖仿真器：真实建立/断开/滑移标签难以获得。→ 从带接触真值的 DOT-Sim / Real-to-Sim GS 孪生体蒸馏（H4）；H5 再测 sim-to-real 保持率。
  - 离散模式 WM 现已在运动领域有先例——PRISM-WM 出了*隐式* MoE 门模式潜空间，所以新意是面向精细操作的*显式、触觉监督*分类法，而非离散性本身。→ 把显式-vs-隐式正面对决（H1）与接触模式分类精度作为首批里程碑、先于任何下游成功率声明，让楔子守在亚毫米 + 触觉监督。

### B2 — WAM 驱动的自演化与故障恢复
- **论点**：「想象中的 RL 能提升真实成功率」现已是 2026 共识（RISE / WoVR / VLAW 等），不再是开口。所以残留的真正问题是三件没人配齐的事：**哪些**故障被想象（主动 vs 被动）、**何时**停（ρ 作为操作性停止门）、以及**是否信任**每个梦（独立验证器）。业界把想象-RL 闭环当成自足。赌注：在 RISE/WoVR 这类想象-RL 基线之上，补上这三件——*主动*故障发现器（vs RISE 的被动低优势发现）、锚到 Persistent Robot World Models 的 0.822 的想象-真实 ρ > 0.7 *停止门*、以及 Pre-VLA 级 ≥0.83 F1 的*独立*验证器——在同等想象推演预算下给出更高的每轮真实成功率增益，且*不*遗忘（WMAR 式 +0.071 vs 0.665）。
- **第一性原理框架**：
  - *第一性原理*：一个智能体能准备到多好，受限于它能想象什么。它只能学会从自己能*生成*的故障中恢复，因为恢复策略正是在它见过的故障上训练的。所以自我改进循环的上限取决于 WM 能想象出多广的故障，而非记录了多少真实交互。Counterfactual Failure Synthesis 的 Dream2Fix 证明了供给侧：在生成式 WM 中扰动动作产出 12 万对反事实故障+恢复对，把真实恢复抬到 46%。
  - *挑战的假设*：不是「自演化需要真实探索」——RISE、WoVR、VLAW 已用想象 RL 驱动真实改进，这已是共识、不再是逆向赌注。真正还活着的假设是：*被动*故障发现（RISE 靠低优势找故障）和一个*不设门、不验证*的循环就够了。B2 押反面：可达恢复能力受限于 WM 被*主动驱动*去想象什么，循环需要 ρ 作为*操作性停止条件*（而非只是诊断），且幻觉推演需要*独立*验证器——这些 RISE/WoVR 都没造。
  - *下的赌注*：以 RISE/WoVR 为想象-RL 基线，补上三件缺件——*主动*故障发现器（vs RISE 被动低优势发现）、锚到 Persistent Robot World Models 0.822 的想象-真实 ρ > 0.7（Pearson）*停止门*、以及 Pre-VLA 级 ≥0.83 F1 的独立验证器——在同等想象推演预算下给出更高每轮真实成功率增益，且*不*遗忘（WMAR 式 +0.071 vs 0.665）。可证伪：若主动发现器+ρ门+验证器在同预算下与朴素 RISE 式被动循环打平，则这三件多余、B2 退回想象 RL。
- **具体研究问题**：
  1. H1 — *主动* WAM 故障发现器在真实恢复上胜过 RISE 的*被动*发现：把 RoboMD 改造成 WAM 对手（发现器提初始状态、WAM 前向推演、策略依想象结果受评），在同等想象推演预算下覆盖更多故障模式、真实恢复高于 RISE 被动低优势发现，至少匹配 Counterfactual Failure Synthesis 离线 46% 真实恢复（落点 RISE vs RoboMD-as-WAM-对手）。
  2. H2 — 每轮成功率仅在想象-真实 ρ 维持 > 0.7 时上升：跨自演化轮次，真实成功率单调上升当 ρ > 0.7、ρ 一掉就停滞，故 ρ 是操作性停止条件，对照 PiL-World r=0.94 闭环参考（落点 SPIRAL，PiL-World 作 ρ 锚）。
  3. H3 — 对想象推演加运行时验证器胜过无验证循环：把恢复候选过一道 Pre-VLA 级验证器（≥0.83 F1）再执行，胜过无验证的同循环，差距在 WM 最爱幻觉的任务上最大（落点 Pre-VLA）。
  4. H4 — 对联合（动作，想象）做 GRPO 胜过仅对动作做 RL：优化联合（动作，想象）对数概率的 GRPO（奖励 = 想象任务成功率 + COD + 新颖度），胜过想象内的纯动作 PPO（World4RL），因联合目标同时塑造 WM 与策略（落点 World4RL）。
  5. H5 — 相位感知回放把遗忘压在 WMAR 级跨轮：用 PHASER 的相位感知、干扰感知回放从恢复中更新，把灾难性遗忘压到 WMAR 级（+0.071 vs 0.665）跨序列任务、胜过朴素微调（落点 PHASER / WMAR）。
  6. H6 — 环内红队防止 misevolution 漂移：每轮跑一次 JailWAM 式红队探测（配 EVOL-RL 新颖度防熵塌缩），使真实成功率单调，而无探测的循环会漂入奖励作弊的想象成功率（落点 SPIRAL 扩红队探测）。
- **风险**：
  - Misevolution 漂移：自奖励偏差跨轮放大（Misevolution 命名了这类风险）。→ 每轮后红队（JailWAM / SELF-REDTEAM 探测，H6）；保留对抗熵塌缩的新颖度奖励。
  - 在想象成功率上的奖励作弊：模型钻 WAM 的空子，而非优化真实表现。→ 周期性真机验证 + Pre-VLA 轨迹截断；ρ > 0.7 门（H2）是抓住它的停止条件。
  - WAM 偏离真实动力学：想象随轮次发散，旧恢复失效。→ 外循环 WAM 更新（Self-Adapting RL）+ ρ 停止条件；对照伞文档的联合因果绑定度量验证，而非只看想象成功率。

### B3 — 自验证 / 校准想象的 WAM
- **论点**：「验证比生成在结构上更便宜」这个前向-逆向不对称机制现已被集体占住（WAV / SWIRL / DeFI）。剩下两个没人答的问题：**(1)** *训练时*校准能否胜过*运行时*过滤；**(2)** 想象-真实 ρ 能否被*训练去最大化*、而非仅被拿来当门。业界在运行时过滤梦、且只把 ρ 当诊断。赌注：在一个*潜空间机器人 WAM* 上，训练时前向-逆向校准在「≥2× WM 样本效率」和「+22% 下游奖励」两项上都胜过同等的纯运行时验证器（WAV 的差距为目标）——这是没人跑过的正面对决；且把 WM 训练去最大化想象-真实 ρ，得到的最终 ρ 高于仅把 ρ 当门（对照 PiL-World r=0.94 / Persistent Robot World Models 0.822）。
- **第一性原理框架**：
  - *第一性原理*：做出一个预测与验证一个预测的难度并不相同。无动作标签的视频很充足，所以判断一个想象未来*看起来*是否合理很便宜；而状态中与动作相关的部分很小，所以判断一个未来是否*可达*只需很少标注。利用这一落差的验证器，从根本上比它所验证的生成器更便宜——现已被多重证明：WAV 的稀疏逆模型比稠密的更 OOD 鲁棒、SWIRL 的 FWM↔IDM 互逆循环无须标签、LAPO+ 形式证明 IDM 是更低复杂度假设类。
  - *挑战的假设*：不是「不对称可被利用」——WAV、SWIRL、DeFI 已集体占住它，LAPO+ 证明 IDM 是更低复杂度类。真正还活着、*未被占住*的假设是：*何时*校准（训练 vs 运行时）是自由选择，且想象-真实 ρ 只是个拿来*设门*的诊断、从不是*可训练的目标*。运行时验证线（Pre-VLA、FIPER）隐含押「校准时机无所谓」；B3 押训练时校准严格占优、且 ρ 可直接最大化。
  - *下的赌注*：在*潜空间机器人 WAM* 上，训练时前向-逆向校准在「≥2× WM 样本效率」与「+22% 下游奖励」（同等标签下、以 WAV 差距为目标）两项上都胜过同等的纯运行时验证器——这是没人跑过的正面对决；*且*把 WM 训练去最大化想象-真实 ρ，得到的最终 ρ 高于仅对其设门（对照 PiL-World r=0.94 / Persistent Robot World Models 0.822）。可证伪：若纯运行时验证器在样本效率与奖励上匹配训练时校准，*或* ρ「训练去最大化」并不高于「设门」，则训练时/ρ-目标这个楔子是空的、B3 退回 WAV+SWIRL+DeFI。
- **具体研究问题**：
  1. H1（领衔）— 训练时前向-逆向校准在潜空间 WAM 上胜过同等的纯运行时验证器：把 WAV 的子目标生成器+稀疏逆向分解包到 JEPA WAM（VLA-JEPA / UWM-JEPA）上做*训练时*校准，胜过把*同一*不对称信号只作 Pre-VLA 式*运行时*过滤——≥2× WM 样本效率 + 同等标签下 +22% 下游奖励，没人跑过的训练-vs-运行时对决（落点 WAV vs Pre-VLA）。
  2. H2 — 认知不确定性门控作为稠密奖励稳定 A1 的潜空间推演：把 RWM-U 的 MOPO 惩罚改造为 A1 混合骨干上的潜空间一致性奖励，惩罚高不确定性想象状态，使推演随视野的发散低于无门控（落点 RWM-U / ELVIS）。
  3. H3 — 训练去最大化想象-真实 ρ 胜过对其设门：把 B2 的 ρ > 0.7 门当作 B3 的*目标*（直接训练 WM 最大化想象-真实成功率相关，对照 PiL-World r=0.94），得到的最终 ρ 高于仅作停止条件（落点 PiL-World / Video WM Policy Eval）。
  4. H4 — 验证器分歧是有用的主动数据信号：用 WAV 的合理性/可达性差异决定下一步采集哪些真机交互（与 B2 故障发现器闭环），以更少真实交互达到目标成功率（落点 WAV）。
  5. H5 — IDM 奖励在 WM 校准上胜过人偏好与像素奖励：RLIR 的逆动力学帧级奖励在同等预算下比人偏好或像素奖励更校准 WM（更高动作可恢复性），跨 AR 与扩散 WM（落点 RLIR）。
  6. H6 — 稀疏逆 OOD 鲁棒性在接触密集区仍成立：WAV 的稀疏逆 OOD 鲁棒性在配 B1 离散接触模式的接触密集任务上仍成立——低维动作特征跨建立/断开转移仍可恢复（落点 WAV / 交叉引用 B1）。
- **风险**：
  - 稀疏逆模型漏掉细微动力学：低维动作特征可能丢失接触瞬态。→ 把论断限定在动作相关特征可恢复的范围内，接触密集区则与 B1 的离散接触模式配对（H6）。
  - 不确定性门控过于保守：惩罚所有高不确定性状态会扼杀探索（RWM-U 的惩罚系数是关键超参）。→ 在留出的真机校准集上调惩罚系数，而非仅在仿真中调；H2 报告探索代价。
  - 校准 ≠ 正确：一个 WM 可以对自己的「错误」校准得很好。→ 须同时对照 B2 的想象-真实 ρ（H3）*和*伞文档中开发的联合因果绑定度量来验证，不能只看校准。

### B4 — WAM 即数据引擎
- **论点**：「WAM 数据引擎胜过真机采集」现已被五篇以上论文坐实，不再是开放问题。真正没答的机制问题是：*哪种类型*的过滤器让想象数据可执行，且其承重性能否*跨生成器迁移*？因为一段视频可以看着对、却运动学上不可能，所以是过滤器决定策略学到什么；而一个运动学-物理谓词内在于数据、应当跨生成器迁移，成功回放或学习式裁判则未必。业界把引擎当贡献、把过滤器当管线杂活。赌注：VISTA 的运动学-物理可行性过滤器，在一个*不是为它造的*生成器（RoboDream 组合式引擎）下游复现其「校验-vs-未过滤」差距（≥15 pp，锚 0.65 vs 0.00）——即过滤器的承重性*可迁移*——而成功回放过滤器（CRAFT）则迁移得不那么干净。「引擎胜过采集」（≥25 pp，RoboDream +26.2 pp；≥2× 更省，2.2×）只是*已定*背景，不是赌注。
- **第一性原理框架**：
  - *第一性原理*：把*可执行*的想象数据与仅仅*看着像*的想象数据区分开的，是过滤器的属性、而非生成器——一段视频可以看着对、却运动学上不可能，所以过滤器才决定策略学什么。若该属性内在于数据（运动学-物理谓词），同一过滤器就应跨生成器迁移；若它是成功回放或学习式裁判，则可能被生成器绑定。是哪一种，就教会我们*什么让想象可执行*。VISTA 校验 0.65 vs 未过滤 0.00 把过滤器隔离为承重变量，独立于引擎。
  - *挑战的假设*：*引擎*是贡献、过滤器是可互换的管线杂活——这是数据引擎线（RoboDream、AnchorDream、DreamGen）所持，其校验靠成功回放或生成时锚定，而非被消融的下游过滤器。B4 押*过滤器类型*是承重且*可迁移*的：运动学-物理可行性过滤器（VISTA）干了 CRAFT 的成功回放与 GE-Sim 2.0 的学习式 VLM 裁判干不了的真活，且是在*非为它而造*的生成器上。
  - *下的赌注*：VISTA 的运动学-物理可行性过滤器在*另一个*生成器（RoboDream 组合式引擎）下游复现其校验-vs-未过滤差距（0.65 vs 0.00）——即过滤器承重性可迁移，在非为它而造的引擎上 ≥15 pp 下游成功率差距——而成功回放过滤器（CRAFT）迁移得不那么干净。「引擎胜过采集」（≥25 pp，RoboDream +26.2 pp；≥2× 更省，2.2×）是*已定*背景、非赌注。可证伪：若运动学-物理过滤器的差距在第二个生成器上消失，则它是生成器特定的装饰、B4 的迁移声明就错了。
- **具体研究问题**：
  1. H1（领衔）— 运动学-物理过滤器的承重性跨生成器迁移、成功回放则不：把 VISTA 的连续性/自碰撞/执行保真度评分接到 RoboDream 组合式生成器下游，在*非为它而造*的引擎上复现 VISTA 校验-vs-未过滤差距（≥15 pp，锚 0.65 vs 0.00），而 CRAFT 成功回放过滤器跨生成器差距更小——把*过滤器类型*隔离为可迁移变量（2×2 消融；落点 VISTA vs CRAFT on RoboDream）。
  2. H2 — Gen-Mix 胜过两个极端，且最优比例随任务族而异：扫描合成:真实比例，下游成功率在内部 Gen-Mix 点取峰（RoboDream 62.5% 胜过 Real-50 36.3% 与 Orig-100 0%），峰值比例随任务族不同（落点 RoboDream）。
  3. H3 — 引擎为「目标任务零真实演示」的机体合成可用数据：以 WLA 无动作跨机体视频为来源，引擎合成的数据能在某机体*零*真实演示下训练它、胜过无合成基线（落点 WLA）。
  4. H4 — 用引擎自身校正信号协同训练提升合成数据质量：τ0-WM 用同一骨干做生成与测试时校正——用其校正信号协同训练引擎（把 B3 校准闭进 B4 生成），下游成功率高于纯生成引擎（落点 τ0-WM）。
  5. H5 — 免道具遥操作可规模化且不损下游成功率：扩展 RoboDream 的纯运动学（免道具）采集（先想象物体、视觉随后合成），在不损下游成功率下覆盖操作课程的可测比例 vs 全遥操作（落点 RoboDream）。
  6. H6 — 合成数据把 OOD 覆盖拓宽到超过仅真实：在校验合成语料上训练的策略在 LIBERO-Plus OOD 上比仅真实策略泛化更广（同等分布内成功率下）——是多样性声明、不只是成功率声明（落点 GigaWorld-0 / Interactive World Simulator）。
- **风险**：
  - 合成数据看似合理却不可执行：物理上不可行的演示会教出错误的动力学。→ 把 VISTA 的物理校验过滤器设为强制、不可选（H1），并以校验 vs 未过滤的下游成功率作为首个消融。
  - 分布收窄到引擎自身的偏差：WM 只能合成它见过的东西，表面上的多样性可能很浅。→ 扫描想象:真实混合比例（H2，RoboDream Gen-Mix 胜过两个极端），保留真实数据作为锚点，绝不只用合成数据训练。
  - 误差累积：在 WM 数据上训练的策略会悄无声息地继承 WM 的故障模式。→ 在真机留出集和 LIBERO-Plus OOD 上验证下游（H6），而非仅在分布内的合成评测上验证。
