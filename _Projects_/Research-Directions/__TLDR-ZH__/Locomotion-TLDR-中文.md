# TL;DR（中文）：运动（Locomotion）— 双足与四足

> 原始研究方向文档：[[Locomotion|Locomotion Research Directions]]（`_Projects_/Research-Directions/Capability/Locomotion.md`）。本篇是它的中文 TL;DR：逐方向给出**论点、第一性原理框架、具体研究问题、风险**四块，其余细节（Evidence、Benchmarks、相关论文）请回原文。

## Cluster A — 双足运动与动态技能

### A1 — 感知式地形穿越与垂直机动
- **论点**：在控制循环里**在线**地依据运行时地形即时生成步态参考，*同时学会「往哪看、看多远」*——把在线参考生成与一个主动注视模块融进同一个感知策略，而不是固定步态库、也不是对整片地形做固定时域的被动扫描。「感知胜过盲走」已成定论；没定下来的是*该看什么、用多长的时域*。赌注：把"生成+注视"融合策略相对纯生成或纯注视的优势，集中在落脚点稀疏（≥70 cm 步距）的任务上——以全扫描 ≤40% 的算力守住 ≥0.95 成功率，并存在一个最优参考时域。
- **第一性原理框架**：
  - *第一性原理*：障碍地形上可行的落脚点取决于摆动脚前方的局部几何，而这几何是*稀疏*的——少数承重落脚点决定成败，整片高度扫描的大部分都没用；固定全扫描在每处都平摊同样的算力和同样的"过期"风险。TAGA 证了前半：学出来的注视以 65.2% 更低成本匹配全扫描；G1 WBC-Gen+Track 的 0.962 vs 0.230 攀箱消融证了预判这半——信号必须被*看到*，而非*碰到*。
  - *挑战的假设*：固定时域的整片高度扫描就是对的感知接口。共识感知策略（PRIOR-Loco 100% 穿越、G1 WBC-Gen+Track 0.5 s 固定生成时域）都吞下整片扫描、并已战胜盲跟踪器——那场仗已经打完。TAGA 押的是关于*接口*的反面：学出来的「往哪看」+ 自适应时域，胜过固定全扫描，并已把注视那一半证得很廉价。
  - *下的赌注*：*融合*在线参考生成（G1 WBC-Gen+Track 式）与学出来的主动注视（TAGA 式）的策略，胜过单用注视或单用生成，并把胜势集中在高度扫描稀疏处——稀疏踏石/宽缝任务上以 ≤40% 全扫描算力守住 ≥0.95，密集糙地上与全扫描打平（2 pp 内）；且存在一个*内部最优参考时域*——在 ~0.5 m 扰动（PHP 级）下，成功率随时域非单调，太长会因参考过期反受其害。
- **具体研究问题**：
  1. H1 — 四臂对比（盲走 / 纯注视 / 纯生成 / 注视+生成），在等算力下于稀疏踏石上比成功率与算力——融合策略能否在固定算力下守住 ≥0.95、胜过纯生成（全扫描）与纯注视（TAGA 无生成参考）？
  2. H2 — 扫描 G1 WBC-Gen+Track 的 0.5 s 生成时域并施加 PHP 那样的 0.5 m 扰动——成功率随时域是否呈非单调、存在一个内部最优时域，证明参考过期会带来代价？
  3. H3 — 把任务按落脚点稀疏度分层——TAGA 的主动注视是否正好在需要*远处*落脚规划的稀疏踏石上把"省 65.2% 成本"的优势挣到最大，而在密集地形上与全扫描打平？
  4. H4 — 把 PHP 的运动匹配技能图与 G1 WBC-Gen+Track 的在线生成组合——串接而成的生成技能能否通过 PHP 固定技能图单独覆盖不了的多障碍赛道？
  5. H5 — 当外感知退化（遮挡、黑暗）时，底层垫有 DWL 式本体感觉安全模式的感知策略能否在平地/糙地上优雅回退，而非灾难性失败？
- **风险**：
  - 感知失效是灾难性的，而非平滑降级——腾空中丢失深度可能致命。→ Q5 是放行的判据，要求感知策略底层垫有 DWL 级本体感觉安全模式（与 A3 恢复层耦合），并报告诱发丢帧下的摔倒率。
  - 生成的参考可能不可行——生成器可能提出跟踪器执行不了的动作。→ 用 G1 WBC-Gen+Track 的 RL 微调来过滤，并报告跟踪器的拒绝/截断率，而非只报最显眼的成功率。
  - 跑酷级技能有损伤硬件的风险——1.25 m 墙、3.41 m/s 腾跃的应力很大。→ 把激进的技能主张限定在已验证的平台上，并报告接触力与电机温度（与 A4 耦合）。

### A2 — 经物理可行运动模仿习得动态敏捷技能
- **论点**：在模仿*之前*，先把一段*固定的、预录的*动捕片段离线投影到机器人的动力学可行流形上，*并拒掉那些怎么改都跟不动的*——一次性修正加一道明确的"收/退"闸门，区别于 A1 那种逐步在线生成。"投影到可行流形"如今已成常态；没定下来的是：在极限敏捷-双足技能上，*拒绝* + *自适应容差*是否胜过"投影后照单全收地跟"。赌注：在 KungfuBot 高拒绝率（>30% 回合崩溃）的尾部，"拒绝+自适应容差"以等算力胜过 SPIDER 式"投影后全跟"，把误差压到 KungfuBot 的 53.25 mm（vs OmniH2O/ExBody2 >233 mm）、下游 RL 提到 ReActor 的 97.45%（G1），且增益集中在尾部、并非全程均摊。
- **第一性原理框架**：
  - *第一性原理*：要求策略去跟踪一个参考，只有当该参考是机器人物理上做得到的，才有意义；原始人类动捕做不到，所以第一步必须把参考投影到动力学可行流形上，模仿问题才可解——这个问题先于"有多少数据"。KungfuBot 证了这点：仅靠*过滤*不可跟踪的动作（而非加数据）就拿到 233→53 mm 的削减。
  - *挑战的假设*：*不是*"可行性胜过规模"——SPIDER（240 万帧、9 种形态）证了投影能扩展，二者其实是互补。被挑战的假设更窄：*"投影后照单全收地跟"就够了*。SPIDER/Opt2Skill 都是投影并全跟，谁都没暴露一道*拒绝*闸门、也没有对跟不动的残余做*自适应容差*。KungfuBot 的拒绝 + Adaptive Motion Tracking 的自适应容差押的是反面——在极限双足技能上，明确的"收/退"决定加一条容差课程，才是规模+投影给不了的杠杆。
  - *下的赌注*：在极限敏捷-双足技能（翻腾、武术）上，KungfuBot 式*拒绝* + *自适应跟踪容差*（Adaptive Motion Tracking 式）胜过 SPIDER/Opt2Skill 式"投影后全跟"的流水线——把误差降到 53.25 mm、下游 RL 提到 97.45%、且零穿透，增益集中在高拒绝（>30% 回合崩溃）的尾部，那里"全跟"流水线会默默地去追根本做不到的目标。
- **具体研究问题**：
  1. H1 — 按 KungfuBot 的拒绝率把技能集分层，做三臂对比（track-raw / SPIDER 式投影后全跟 / 拒绝+自适应容差），等 FLOPs 下逐层报告误差——增益是否集中在高拒绝尾部，而在易跟的大头上打平？
  2. H2 — KungfuBot / Adaptive Motion Tracking 自适应调整跟踪容差，将其与固定容差对比——"先松后紧"的容差课程能否学会固定奖励陷在局部最优、学不会的动态技能（武术、翻腾）？
  3. H3 — ReActor 的零穿透重定向带来 +15.22 pp，据此量化"可行性→RL 成功率"曲线——穿透/脚滑能否单调预测可训练性？
  4. H4 — EFGCL 的力引导课程能否找回 KungfuBot 的过滤器会丢弃的后空翻/侧空翻，且二者能否*组合*——可跟的过滤、跟不动的扩展，覆盖比单用任一法更宽的技能范围？
  5. H5 — 以运动*相位*锚定参考（PHASOR），一次投影能否跨形态（Human2Humanoid 式）迁移而保持可行性，从而一次投影摊销到多个身体、无需逐平台重新过滤？
- **风险**：
  - 物理过滤需要准确的机器人模型——修正的好坏受限于 URDF/动力学模型的准确度。→ 对照硬件验证可行流形，并报告仿真与真机之间的跟踪误差差距（KungfuBot 报告了相近匹配）。
  - 过滤会丢弃富有表现力的动作——拒绝"不可跟踪"的动捕可能砍掉最惊艳的技能。→ 用 EFGCL 式的力引导*扩展*可行域来配合过滤（Q4），并报告被找回技能的比例，而非只报拒绝率。
  - 下游 RL 增益可能是任务特定的——+15.22 pp 未必迁移到新技能。→ 用 Q3 的可行性→可训练性曲线测试通用性，并按技能类别分别报告。

### A3 — 自主跌倒恢复作为非周期性全身控制
- **论点**：把"站起来"当成一个自成一体的非周期、接触丰富、稀疏奖励的控制问题，而不是某种退化的步态。跌倒恢复没有相位时钟、也没有名义接触表，因此那些让运动变得可学的归纳偏置（周期性、足接触先验）反而会误导它。"学出来的、课程塑形的恢复胜过脚本"已是共识；没定下来的是*哪一种结构先验*让稀疏奖励技能变得可发现——以及一个运动相位时钟先验是否反而有害。赌注：向无先验恢复策略注入相位时钟/周期足接触先验会把任意姿态起身成功率*拉低*可测幅度（≥10 pp）；而 HUMANUP 的两阶段"先发现后部署"与 HoST 的单阶段多评论家在匹配的姿态/地形分布上*打平*（5 pp 内）——证明杠杆是课程塑形的探索，而非某一种具体分解，且步态结构确实有害。
- **第一性原理框架**：
  - *第一性原理*：跌倒恢复没有相位时钟、也没有名义接触表，初始状态是任意的跌后姿态、接触集未知；那种让运动变得良态的相位时钟与足接触先验在这里本应*缺席*，强行加上反而会把策略带偏，偏离恢复所需的接触丰富的起身过渡。两个独立结果都表明稀疏奖励地貌需要*某种*结构脚手架：HUMANUP（单阶段无法收敛 → 发现/精炼分阶段）与 HoST（单评论家不够 → 无多评论家时 0%）。脚手架是哪一种是开放的；而*步态式*先验是错的那一种，是这里最尖锐的主张。
  - *挑战的假设*：*不是*"学出来的课程恢复胜过脚本"——HoST、VIGOR、HiFAR、FRASA 都证了，那是共识。被挑战的更细：把*运动的相位时钟/足接触先验*强加到恢复策略上是中性的。它不是——这个步态先验应当*不利于*非周期的起身过渡、*拉低*成功率，而这是还没有任何恢复论文测过的预测。
  - *下的赌注*：注入相位时钟/周期足接触先验会把任意姿态起身成功率拉低 ≥10 pp（相对无先验的 HUMANUP/HoST）；且 HUMANUP 两阶段发现/精炼与 HoST 单阶段多评论家在匹配分布上打平（5 pp 内）——证实杠杆是课程塑形的探索而非某种特定分解，且步态结构确实有害。
- **具体研究问题**：
  1. H1 — 在相同姿态/地形分布上训练"发现/精炼""多评论家""无结构单阶段"三者，比收敛与成功率——HUMANUP 的两阶段与 HoST 的多评论家是否打平（5 pp 内），证明承重的是课程塑形的探索、而非某一种分解？另测 Stubborn 的涌现式恢复。
  2. H2 — 扫描随机仰卧姿态的数量（趋向 HUMANUP 的 20,000），考察其对留出姿态成功率的影响——是否次线性增长、存在一个覆盖阈值，越过后再加姿态收益甚微？
  3. H3 — 以感知到的地形（坡度、柔顺性）为条件，能否在雪/泥这类柔顺表面上胜过 HUMANUP 的地形盲策略，而在刚性混凝土上打平？
  4. H4 — 向无先验恢复策略注入相位时钟/足接触先验，报告相对无先验的成功率差——周期先验是否确实把非周期恢复的成功率*拉低*，而非中性或有益？
  5. H5 — 把跌倒恢复接成 A1 感知策略失衡时的回退，统一的"运动+恢复"栈能否在含跌倒的多障碍赛道上实现端到端自主，而纯运动栈在第一次跌倒就失败？
- **风险**：
  - 恢复动作会冲击硬件——挥舞肢体与触地冲击可能损伤电机/关节。→ HUMANUP 的强正则化降低了臂部电机温度；报告接触力与温度，把平滑度当成一等目标（与 A4 耦合）。
  - 发现阶段可能找到不安全的轨迹——弱正则化会产生硬件无法承受的剧烈动作。→ 两阶段设计把发现精炼为可部署策略，并报告发现到部署之间的安全裕度差距。
  - 真实跌倒可能超出仿真覆盖——20,000 个姿态可能漏掉对抗性的真实跌倒。→ 用 Q2 的覆盖曲线界定主张范围，并按初始姿态类别报告失败模式。

### A4 — 具身约束驱动的运动（力、声、热）
- **论点**：让一套步态在*一个受调控的头*下*权衡*它的物理代价——地面反作用力、噪声、电机发热——而不是各自单独调。单条件代价头与两代价耦合现在都有了，但还没有任何策略把热∧声∧力这个三元组*联合*调控，更没人去刻画它们之间的*跨代价*取舍。赌注：一个 QuietPaw 式*单条件代价头*（CNCP），同时喂入热+声+GRF，既把过热压在 Thermal-Aware Residual 的 <10% 内、把噪声控在 QuietWalk 均值 +1 dBA 内（任务成功率损失 ≤5%），又能描出一条非平凡的*热-声* Pareto 前沿——把噪声压低 ≥3 dBA 会可测地抬高峰值电机温度，这是两个单代价头各自跑出不来的。
- **第一性原理框架**：
  - *第一性原理*：真实机器人的步态受到硬性的具身极限约束——电机温度上限、执行器力极限、（人群附近的）噪声预算——这些都*不在*仿真奖励面上；只优化任务成功的策略会把这些极限顶满，因为没有任何东西惩罚它们，代价要到硬件失效或步态变得不可接受时才会显现。Thermal-Aware Residual 在标准策略下 70% 的过热率是直接证据：具身代价对部署是承重的。
  - *挑战的假设*：*不是*"具身代价是个独立杠杆"——这已是定论（QuietWalk、Thermal-Aware Residual、QuietPaw、IMF Reward 都证了）。被挑战的是：代价只能*逐个*调（顶多像 IMF 那样耦合能量+冲击这一对）。QuietPaw 的单条件头能扫一条噪声-敏捷 Pareto 却不碰热；IMF 耦合能量+冲击却不碰噪声。赌的是这些代价可在*一个头*下*联合*调控，且它们之间的*跨代价取舍*（热 vs 声）是真实可测的。
  - *下的赌注*：一个 QuietPaw 式单条件代价头，喂入热+声+GRF（按 QuietWalk 的 R²≈0.99 预测），既*同时*把过热压在 <10%、把噪声控在 +1 dBA 内（任务成功率损失 ≤5%），又描出一条*热-声* Pareto 前沿——把噪声压低 ≥3 dBA 会可测地抬高峰值电机温度——这是两个单代价头各自跑不出来的。
- **具体研究问题**：
  1. H1 — 把 QuietWalk 由 GRF 预测器驱动的策略与纯惩罚式的静音策略对比——显式的力*预测*（R²≈0.99）是否比事后惩罚测得的力更好地调控接触？
  2. H2 — Thermal-Aware Residual 指出整体式热策略响应慢、且在复杂地形上失败；把代价调控与基策略解耦（残差结构），能否守住地形适应性？
  3. H3 — QuietWalk 覆盖了赤足到高跟，那么 GRF 预测能否泛化到未见过的界面（冰、软地）且 R² 优雅退化，噪声/力目标能否随之迁移？
  4. H4 — 把 QuietPaw 的单条件头（CNCP）扩展到接收热+声+力阈值，它能否在 ≤5% 成功率损失下同时守住过热 <10% 与噪声 +1 dBA，从而胜过 QuietPaw（噪声）+ Thermal-Aware Residual（热）各自单跑——一个头胜过两个头之并？
  5. H5 — 在该联合头下，把噪声压低 ≥3 dBA 是否确实可测地抬高峰值电机温度（一条下倾的热-声 Pareto 前沿）——这条*跨代价*曲线是两个互相看不见对方目标的单代价策略画不出来的，IMF 的能量+冲击耦合是唯一先例且不含热与声？
- **风险**：
  - 代价调控会拉低任务表现——静音/低温步态可能更慢或更不敏捷。→ Thermal-Aware Residual 用残差保住表现；报告代价-任务的 Pareto 前沿（Q5），而非单一数字。
  - GRF/热模型是平台特定的——一台机器人上的 R²≈0.99 未必能迁移。→ 用 Q3 测泛化，把代价预测器当作逐平台的标定，并报告迁移差距。
  - 声学指标依赖环境——dBA 取决于表面与房间。→ QuietWalk 跨 4 种表面报告，按表面分别报告噪声，而非给单一平均。

### A5 — 样本高效的离策略与流式运动学习
- **论点**：既然离策略在墙钟时间上已经胜过 PPO（这点已是定论、退为背景），开放的问题变成两条：在多模接触的运动上，*流式*策略是否胜过高斯策略；以及*快速多次迭代*是否胜过一次慢跑。运动的稠密奖励与并行仿真让样本复用高效，但单峰高斯欠拟合多模接触，而一次漫长的 PPO 跑放弃了几分钟级离策略训练才负担得起的奖励/课程搜索。赌注：流式策略（FPO++/PolicyFlow 式）在多模接触技能（敏捷过渡、运动跟踪）上、以可测幅度胜过匹配的高斯离策略学习器，而在平地行走上打平；且在固定总墙钟下，N 次 Humanoid Loco 15min 式（15 分钟）快迭代收敛到比一次 AGILE 式（6–25 小时）PPO 跑更好的步态。
- **第一性原理框架**：
  - *第一性原理*：样本效率取决于每个环境步能带来多少次梯度更新；离策略回放会把每个转移复用多次，而在线 PPO 一次更新后就丢弃整条轨迹。运动的稠密奖励 + 并行仿真（转移廉价）让离策略的优势复利放大。FastTD3 证了这点：大批量离策略更新 + 分布式 critic、且*无*复杂稳定手段，就在墙钟时间上击败 PPO、DreamerV3、TDMPC2。
  - *挑战的假设*：*不是*"离策略胜过 PPO"——Parallel Q-Learning（2023）与 SAC Legged Locomotion 已经settled、退为背景。被挑战的是*高斯*策略这个默认：单峰高斯对运动的动作分布够用。多模接触（哪只脚、哪种过渡）正是高斯欠拟合之处；PolicyFlow 的抗模式坍缩结果与 FPO++ 的仿真到真机流式步态押的是反面——流式策略的丰富表达才是下一个杠杆，且专攻多模接触技能。
  - *下的赌注*：流式策略（FPO++/PolicyFlow 式）在多模接触技能上以可测幅度胜过匹配的高斯离策略学习器（步态质量 + 仿真到真机成功率），平地行走打平；且固定总墙钟下，N 次 15 分钟快迭代的奖励/课程搜索收敛到比一次 PPO 跑更好的步态——多次快跑胜过一次慢跑。
- **具体研究问题**：
  1. H1 — 等算力下比较流式与高斯策略，把任务按接触多模性分层（平地行走 vs 敏捷接触），报告步态质量与仿真到真机成功率——流式的优势是否正好集中在高斯欠拟合的多模接触处，而非全程均摊？
  2. H2 — FastTD3 把功劳归于批量 32,768 + 分布式 critic；做析因消融——哪一个才是稳定高自由度离策略控制的承重组件？
  3. H3 — 流式策略相对高斯离策略的训练开销能否守在 PolicyFlow 的 <50% 内（且 ReinFlow 的少步去噪保持推理实时）——H1 的步态质量增益是否*不*以墙钟为代价，使流式成为净 Pareto 改进，而非以质量换速度？
  4. H4 — 在固定总墙钟下，比较 N 次 Humanoid Loco 15min 式快迭代与一次等时长 PPO 跑——亚小时级训练能否实现 PPO 那种数小时到数天做不到的快速奖励/课程迭代，收敛到更好的步态？
  5. H5 — 在稀疏奖励的运动子任务（类跌倒恢复，A3）上，离策略的墙钟优势是否*收窄或反转*，从而把赌注界定在稠密奖励区间？
- **风险**：
  - 离策略在稀疏奖励技能上不稳定——稠密奖励带来的优势对稀疏的跌倒恢复（A3）可能不成立。→ 把赌注限定在稠密奖励运动上（Q5），并报告离策略在稀疏任务上相对 PPO 退化的地方。
  - 快速训练出的策略可能脆弱——15 分钟的策略可能过拟合仿真。→ Humanoid Loco 15min 与 FastTD3 都做了真机部署，报告仿真到真机的成功率差距，而非只报仿真的墙钟时间。
  - 消费级 GPU 的结果未必能扩展到感知——基于视觉的策略（A1）开销更大。→ 分别报告基于状态与基于视觉的墙钟时间，15 分钟这个数字是基于状态的。

## Cluster B — 四足运动与真实世界适应

### B1 — 纯本体感觉的扰动与负载鲁棒
- **论点**：仅凭本体感觉*历史*就推断出未观测到的环境上下文，无需外感知，也无需在线真机微调。特权状态（摩擦、负载、地形）会在近期本体感觉轨迹里留下可恢复的指纹。"本体感觉推断管用"如今已是共识、且骨干多样；开放的问题是：*一个*上下文模块能否同时扛住「重负载 × 不连续地形」这个合取，以及哪种骨干在二者之间如何取舍。赌注：在*相同*特权监督下做受控骨干替换（TCN / 对比 IMC / Transformer / Transformer-XL），*没有单一骨干*能同时匹配 RMA 的 12 kg（体重 80%）负载与 HIM/TERT 的不连续地形上限（≥60% 爬楼、TCN 为 0%）——存在一条可测的负载-地形取舍曲线，只有给足容量的注意力/长上下文骨干才有望兼顾（100 Hz 控制 / 10 Hz 适应、零真机微调）。
- **第一性原理框架**：
  - *第一性原理*：特权上下文（摩擦、负载、地形）无法从硬件直接读出，但它会塑造关节与 IMU 的响应，因而在近期本体感觉历史里留下可恢复的指纹；一个监督模块能把这段历史读回成上下文估计，无需直接感测就推断出特权状态。RMA 证了这点：一个 10 Hz 读本体感觉历史的适应模块，在 4 类地形上扛住 12 kg、零微调。
  - *挑战的假设*：*不是*"本体感觉推断行不行"——DreamWaQ、HIM、LoadAdapt 已settled，都不需视觉或微调。被挑战的是：单一骨干能同时扛住*重负载*与*不连续地形*。负载线（RMA/LoadAdapt）与不连续地形线（TERT/HIM）是*分开*研究的，领域默认一个模块覆盖二者。赌的是它们会*取舍*——为一条轴调优的骨干在另一条轴上吃亏，除非为这个合取专门分配容量。
  - *下的赌注*：受控骨干替换、相同特权监督下，没有单一骨干能同时匹配 RMA 的 12 kg 与 HIM/TERT 的 ≥60% 爬楼（TCN 为 0%）——存在可测的负载-地形 Pareto，只有带分配容量的注意力/长上下文骨干才能在 100 Hz/10 Hz、零微调下守住合取。
- **具体研究问题**：
  1. H1 — 在一系列摩擦/负载条件上，对比 RMA 的适应与外感知策略（LocoTransformer 式）——纯本体感觉是否在*动力学*上下文（摩擦/负载）上匹配视觉、只在*预判几何*（缝、台阶）上落败，从而画出一条清晰边界？
  2. H2 — 在相同特权监督下替换 TCN（RMA）↔ 对比 IMC（HIM）↔ Transformer（TERT/ROLT）↔ Transformer-XL（LocoFormer），各骨干的负载上限（趋向体重 80%）与不连续地形上限（TCN=0% 的爬楼）是否互相取舍、画出一条 Pareto，且只有注意力/长上下文骨干能同时守住 RMA 的负载与 HIM 的爬楼？
  3. H3 — RMA 基策略跑 100 Hz、适应跑 10 Hz，扫描适应率并匹配不同的扰动带宽——是否存在一个低于则跟不上、高于则收益饱和的带宽匹配最优速率？
  4. H4 — QUARD-Auto 的 MoE 容量有助于*技能*广度，那它是否同样按比例有助于*上下文推断*的广度（多地形/多负载），还是说上下文推断是与技能容量分开的另一个瓶颈？
  5. H5 — LocoFormer 的长上下文在线适应能否在*没有*特权上下文训练目标的情况下，匹配 RMA 的监督式外在参数推断，用上下文长度替代监督？
- **风险**：
  - 本体感觉无法预判几何——台阶或缺口在接触之前不可见。→ 把 B1 限定在动力学上下文推断（摩擦/负载），预判几何是 A1 的职责，二者互补而非竞争（Q1 画出边界）。
  - 适应监督需要特权仿真——推断目标需要仿真给出的外在参数（extrinsics）。→ 这是 RMA 家族的标准做法，特权到本体感觉的蒸馏机制交叉引用 Sim2Real。
  - TCN 与 Transformer 的差距可能是任务特定的——TERT 在楼梯上的优势未必泛化。→ 用 Q2 的骨干消融测通用性，逐地形报告而非给单一平均。

### B2 — 世界模型"做梦"实现少样本真机适应
- **论点**：用*极少量*真实轨迹去适应一个仿真预训练的*学到的潜世界模型*——靠*做梦*，而不是重搭一个数字孪生仿真再在里面重训策略。学到的动力学模型让策略得以*想象*动作的后果，每一次真实交互都用来更新一个能生成上千次合成交互的模型，再用一个认知边界让想象保持诚实。"反域随机化的少样本适应"已是共识；没定下来的是：在匹配的真实数据预算下，潜空间*做梦*是否胜过*重搭仿真再重训*，以及想象是否有界。赌注：匹配的 ≤5 条轨迹 / 15–30 分钟预算下，一个*有界潜空间做梦器*（DreamTIP + RWM-U 的认知惩罚，ANYmal D 0.91）达到 DreamTIP 的 100%-vs-10%（52 cm 攀爬），并在*留出地形*上以可测幅度胜过 LoopSR 式重搭-重训——因为做梦能在潜空间里泛化，而重搭的仿真只会过拟合它重建出来的几何。
- **第一性原理框架**：
  - *第一性原理*：学到的动力学模型是真实数据的*放大器*——每条真实转移都用来更新模型，再经想象生成多条合成转移供策略优化；样本效率取决于每次真实交互所提升的模型精度，而非原始交互的数量，好的模型能让 5 条轨迹抵得上千条。DreamTIP 证了这个放大器：约 5 条真实轨迹在 52 cm 攀爬上拿到 100%，不做梦的基线只有 10%。
  - *挑战的假设*：*不是*"少样本适应胜过域随机化"——LoopSR 与 Simulator Adaptation Loco 已经通过重建settled了这点（同一套反域随机化、无免费午餐框架）。被挑战的是：把这几条轨迹花在*重搭数字孪生仿真再重训*上是对的方式。重搭-重训（LoopSR）需要忠实重建仿真、且不带任何不确定性估计；赌的是*潜空间做梦*从每条轨迹榨取更多，而一个 LoopSR/Simulator-Adaptation 都缺的认知边界，才是让这点小预算变安全的关键。
  - *下的赌注*：匹配的 ≤5 轨迹 / 15–30 分钟预算下，有界潜空间做梦器（DreamTIP + RWM-U 的认知惩罚，0.91 ANYmal D）达到 100%-vs-10%（52 cm 攀爬），且在*留出地形*上以可测幅度胜过 LoopSR 式重搭-重训——因为做梦跨潜空间泛化、而重搭仿真过拟合重建几何。
- **具体研究问题**：
  1. H1 — 固定真实数据预算下做三臂对比（域随机化盲策略 / 重搭-重训 LoopSR 式 / 潜空间做梦 DreamTIP 式），在地形 A 上适应、到留出地形 B 上评估——潜空间做梦能否在留出地形上以可测幅度胜过重搭-重训（与 Simulator Adaptation 的参数辨识），二者又都胜过域随机化盲策略？
  2. H2 — RWM-U 用认知不确定性来惩罚奖励，系数 β 是否存在一个与长时域预测误差相匹配的标定——太小则利用模型盲区、太大则过度保守，存在一个内部最优？
  3. H3 — DreamTIP 学到的任务不变潜表征能否跨*地形*（而不只是跨任务）迁移，并与 B1 的本体感觉上下文推断*组合*？
  4. H4 — 形态条件世界模型（Hardware-Agnostic Quadruped WM 零样本到未见 Go1+ANYmal-D；RWM 在 ANYmal D+G1 上跑同一套流水线）有多少动力学能迁移到人形，比从头训多多少（交叉引用 Cluster A）——动力学模型是否可跨形态移植？
  5. H5 — DreamTIP 的 5 轨迹适应是否会过拟合适应地形——留出地形成功率是否明显低于适应地形，从而界定少样本主张、并印证认知惩罚的必要（带 vs 不带 RWM-U 惩罚）？
- **风险**：
  - 模型误差随时域累积——长程的想象回合会漂移。→ 用 RWM-U 的认知惩罚加以界定，报告预测误差随时域的变化，并在不确定性飙升处截断回合长度（Q2）。
  - 5 轨迹适应可能过拟合测试地形——极少量真实数据存在适应过窄的风险。→ 用 Q5 测跨地形迁移，报告留出地形的成功率，而非只报适应地形上的成功率。
  - 做梦需要好的仿真器来做预训练——垃圾输入会毒化模型。→ SimDist 强调多样、大规模的预训练，基底质量交叉引用 WAM、仿真侧交叉引用 Sim2Real。

### B3 — 感知式无地图"运动到目标"与可通行性
- **论点**：靠*习得的*无地图记忆加自监督可通行性来到达空间目标，而不是靠预先构建的度量地图或高层 VLN 规划器。长程"运动到目标"需要一个能撑过数百个控制步的循环空间状态——显式 SLAM 地图在非结构地形上既脆弱又难处理。"无地图记性管用"已有证据；新的关键洞见是：无地图的优势*随地形的"好建图程度"分级*。赌注：SRU 式"无地图减有地图"的成功率差，在特征丰富的静态赛道（Wheeled-Legged NavLoco 的"建图→规划→跟踪"最擅长处）近乎为零，并随特征密度下降、动态上升、漂移累积而*单调扩大到 ≥20 pp*；配上 SwarmDiffusion 式联合可通行性+轨迹生成与 COTRATE 跨平台感知，把优势保持到多种形态上。
- **第一性原理框架**：
  - *第一性原理*：长程"运动到目标"需要一个跨数百个控制步持续保持的空间状态（我去过哪、目标相对我在哪），*以及*该状态与步态的耦合；显式度量地图只是一种有损实现（在漂移和动态环境下脆弱），而"建图→规划→跟踪"的分解切断了策略本可利用的感知-步态耦合。SRU 证了替代方案：一个习得的循环空间状态把无地图成功率相对 LSTM/GRU 提高 23.5%，并零样本迁移 100+ m。
  - *挑战的假设*：目标到达能干净地分解为"建图→规划→跟踪"——由 Wheeled-Legged NavLoco（公里级城市导航、0 碰撞、*用地图*）这类栈持得最牢。SRU 的 23.5% 无地图增益与 HiPAN 的 94.7% 死胡同成功率押的是反面——*习得*空间记忆在地图最先垮掉处击败分解式流水线。但这些用地图的强基线逼出的开放问题是：它*究竟在哪垮*——无地图优势应是"好建图程度"的函数，而非一个常数。
  - *下的赌注*：无地图记忆的优势*随好建图程度分级*——SRU 式"无地图减有地图"的成功率差在特征丰富的静态赛道近乎为零（Wheeled-Legged NavLoco 的最佳场景），并随特征密度下降、动态上升、漂移累积而单调扩大到 ≥20 pp；配上 SwarmDiffusion 式联合可通行性+轨迹与 COTRATE 跨平台感知，把优势保持到多种形态上。
- **具体研究问题**：
  1. H1 — 按"好建图程度"（特征密度、动态、漂移）给赛道分级，对比 SRU 的无地图记忆与 Wheeled-Legged NavLoco 的"建图→规划→跟踪"——"无地图减有地图"的差是否在好建图赛道近乎为零、并随地形越不利于建图而单调扩大到 ≥20 pp，是一条分级曲线而非常数增益？
  2. H2 — SRU 胜过 LSTM/GRU，据此消融空间记忆结构并匹配不同的目标距离——目标越远优势是否越大，证明带空间增强的状态在数百步内守住相对目标信息、而普通循环会遗忘（与 Blind Nav Agents 的通用 LSTM 对比）？
  3. H3 — HiPAN 会为死胡同自适应地调整姿态，那么以姿态为条件的运动（蹲、挤）能否把可通行空间扩展到固定姿态导航之外，在死胡同/杂乱场景里把 SPL 提升多少？
  4. H4 — 把 SwarmDiffusion 式*联合*推断可通行性+生成轨迹的头，与 COTRATE 这种纯感知substrate接入无地图策略对比——联合推断能否在跨形态目标到达上更优（Spot→Husky 零样本有时甚至胜过逐平台持续学习），因为它把"哪里可走"耦合到"往哪走"？
  5. H5 — 报告 SPL 与成功率——无地图策略是否在易绕圈赛道上 SPL 明显低于成功率，暴露单看成功率藏住的低效，而加入 Path-Conditioned 式全局路径条件能否收窄 SPL–SR 差距（其 SPL 0.82 在退化路径下仍守住）？
- **风险**：
  - 无地图策略会绕圈或卡死——没有地图时策略可能重复造访死胡同。→ HiPAN 的 SPL 能捕捉这一点，应连同成功率一起报告 SPL，而非只报成功率（Q5）。
  - 与伞文档的 VLN 方向重叠——高层的目标*推理*属于 VLN 范畴。→ 本方向限定在低层的无地图*控制 + 可通行性*，语言指令的目标推理交叉引用 Embodied-AI，不在此重复。
  - 可通行性的自监督需要经验——COTRATE 从机器人回合中学习。→ 它在部分场景下能零样本跨平台迁移（Spot→Husky），应报告迁移成立的场景与需要持续学习的场景（Q4）。
