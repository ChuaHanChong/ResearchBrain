# TL;DR（中文）：聚焦方向：显式耦合全身研究计划

> [!info] 这是什么
> [[Focus-Direction|聚焦方向：显式耦合全身研究计划]]的快速 TL;DR。每个簇都给出：**押注**、推理逻辑、最尖锐的开放问题、风险。完整细节见原文。通俗版见：[[__ELI5-ZH__/Focus-Direction-ELI5|ELI5]]。

> [!abstract] 总览
> 这把伞下约有 77 个研究方向，其中**六个簇**收拢成**一个论点**：把联合控制的子系统之间的耦合*显式*表达出来。两个在物理上耦合的子系统一起控制，联合价值就无法拆分，$V(a_L, a_R) \neq V(a_L) + V(a_R)$；交叉项是个又小又有结构的量，该把它**预测**或**因式分解**出来，而不是采集出来。全身控制把它落到了两条轴上：**A** 与 **C** 是手臂的力抵达支撑腿的*两条主导力传导通路*，而 **B** 是一条*独立的运动学轴*。三条通道并行改进：**A 臂↔腿**（一次伸手是自激的*惯性*反作用）、**B 基座↔臂**（基座速度本身是一个*运动学*的操作自由度）、**C 负载下的力**（一股外部接触*力旋量*会传导到支撑多边形）。A 和 C 是*力*通道（腿要补偿手臂所感受到的力，自激 vs 外部，二者共享力旋量预测的*输出*）；B 是*运动学*通道。重力/质心项与科氏项确实存在，但它们被折叠进锚定现实的物理模型，而非作为单独的通道去预测。三个机制服务于全部三条通道：**预测**（WAM·A）、**锚定现实**（S2R·B）、**验证**（EAI·B）。先定架构，再谈数据。我们在*固定*数据预算下，让同一个耦合押注一次性三路并验。

## 这六个簇
*一个论点，三条耦合通道（A 臂↔腿 / B 基座↔臂 / C 负载下的力）：A 和 C 是两条主导力传导通路，B 是一条独立的运动学轴。三个机制（预测 / 锚定现实 / 验证）服务于全部三条。A 和 C 是力通道，共享力旋量预测的*输出*，但预测问题在性质上不同（A 自激 / C 外源）；B 是运动学通道。缺一个，闭环就有漏洞。*

### A — 臂↔腿，惯性（[[Whole-Body|WB · A]]）
> [!abstract] 押注
> 概念验证分两段。先是让耦合*根本算上*这一步，就已经把分布外边际从 **41.0**（分部式）拉到 **61.8**（一个*隐式*耦合策略，[[2604.07993|HEX]]，**79.8 分布内**），分部式那一套在此处崩掉，而且这一优势在漂移下还会*拉得更开*。真正的押注是下一个增量：把耦合做成一个*显式的预测项*。再加一个预测基座反作用的头 $\hat\delta_{\text{base}} = \hat M_{\text{base,arm}}\,\ddot q_{\text{arm}}$，在数据、骨干、任务、仿真全部相同、且不加一条新数据的前提下，它应当在 HEX 隐式耦合策略之上再加 **约 +3 个百分点**，且集中在反作用力矩最大的那些快速、激进的伸手上。

**为什么**：分部式策略把交叉项丢了；与其为它采集数据，不如直接预测它。HEX 的消融也佐证了这点：去掉耦合分量，会带来单分量里最大的一次性跌幅，而大规模预训练到收敛也只换来二阶的增益。

**第一性原理**：*原理：* 两个耦合的子系统一起控制，联合价值就无法拆分；惯性矩阵 $M(q)$ 并非块对角，所以一次手臂加速*本身*就是对基座/腿的扰动。*被挑战的假设：* HEX 把耦合藏进一个隐式混合，数据引擎那一派则认为数据越多、能力越强，但消融都指向架构优先。*赌注：* 隐式耦合策略本身已在大面上取胜（41.0→61.8 分布外），所以显式头的活儿是接下来那约 +3 个百分点，落在反作用力矩最大的快速、激进伸手上。

**最尖锐的问题**：1）*固定*预算下，显式真能在*隐式*耦合策略之上再添那约 +3 个百分点吗？先拿 HEX 的数据跑三路消融（显式前馈 / 观测器 / 隐式）。2）这点增量是不是集中在反作用力矩最大的那种快速、激进的手臂运动上？3）为了让证伪保持诚实而非循环（目标恰由策略自身要学的那个惯性模型来定义），用一个*被扰动过的*惯性模型来定义目标，并报告边际随模型误差的变化。

> [!warning] 风险
> - URDF 一旦不对，就会毒化 $\hat M_{\text{base,arm}}$，那时显式 ≈ 隐式，押注作废 → 所以把 GROUND（S2R·B）放进核心，从真实数据中恢复 $M_{\text{base,arm}}$。
> - 显式 ≈ 隐式（没有那约 +3 个百分点、激进运动上也没集中增益）→ 贡献作废。但这只需低成本就能看清，而这套清晰的消融还能借 VERIFY 的指标发表。
> - 一个反应式的扰动*观测器*（如 ADAPT，已核实为反应式）也许已经能拿下“耦合在分布外可泛化”这个宽泛主张，而且这个威胁对 A、C 两条力通道都成立 → 真正幸存的切口是*前瞻性前馈*（A：在手臂动起来*之前*就预测反作用；C：在负载被完全感受到*之前*就预测），所以消融要跑三路，并按力旋量最大处分层。
> - 真机上，*主导*的未建模项也许是足底接触或执行器带宽，而非惯性项（先给力感知定价，并把主导项排个序）；而一个被微调的通才也许会在规模上追上来，所以诚实的交付物是那条交叉边界，而不是宣布谁赢。

### B — 基座↔臂，运动学（[[Whole-Body|WB · B]]）
> [!abstract] 押注
> 基座速度本身就是一个操作自由度：它会在任务中途重新摆放可达工作空间，于是正确的手臂动作*取决于*基座的运动。把动作按 基座→躯干→臂 因式分解，每一环都以其上游为条件，而不是用一个扁平的 基座+臂 向量任由漂移累积。[[2503.05652|BRS]] 的 WB-VIMA 拿到 **子任务 88% / 整任务 58%**，较 DP3 / RGB-DP 高 **13x/21x**，而且恰好落在那种“先导航后固定基座”默认会丢掉的可达延伸任务上。

**为什么**：这一领域在手臂动作之前先把基座冻住，丢掉了任务中途那段能扩展工作空间的重新摆放，这正是 A 之外又一层的同一种因式分解错误。自回归的 基座→躯干→臂 把它保住了。

**第一性原理**：*原理：* 任务中途基座的移动让手臂动作成为条件分布 $p(a_{\text{arm}} \mid a_{\text{base}})$，因此联合策略无法拆成相互独立的基座头和手臂头。*被挑战的假设：* 扁平的 基座+臂 拼接默认二者独立，任由漂移累积。*赌注：* 自回归因式分解在可达延伸任务上能保住高子任务成功率、并对扁平基线拉开大边际，只有在固定基座的伸手上才退化为与扁平拼接持平。

**最尖锐的问题**：1）在可达延伸任务上，自回归 基座→躯干→臂 能否守住相对扁平拼接的边际，并只在固定基座伸手上退化为持平？2）增益是不是集中在工作空间位移最大的那种抓取中途的基座移动上？3）这套因式分解能否用同样的方法去循环化（自回归对扁平的目标来自被扰动过的模型，报告边际随误差变化）？

> [!warning] 风险
> - 固定基座任务上，因式分解什么也买不来 → 那是被预测到的边界，而非失败；按抓取中途的基座移动分层，让胜势出现在它该出现的地方。
> - 数据足够多的扁平策略也许会把差距抹平 → 报告那条交叉预算，而不是宣布谁赢。

### C — 负载下的力，外部力旋量（[[Whole-Body|WB · C]]）
> [!abstract] 押注
> A 的外部力版本：一股未知的手部力旋量不会停在手上，它会经 $J_{\text{ext}}^{\top}$ 传导到支撑多边形，因此力适应是个全身平衡问题。要*预判*外部力旋量、以及它引发的基座/腿反作用，而不是用一个把力晚晚才硬抗掉的刚性跟踪器。[[2505.06776|FALCON（运动操作）]] 把大力下的上身跟踪误差压到 **0.37 vs 0.60**（较最佳基线约 2x，零演示）；[[2604.07457|CMP]] 守住 **极端分布外 86.7%**。

**为什么**：C 与 A1 共享*输出*机制，同样是腿要补偿的那股前馈力旋量，也共享 WAM 的想象招法，于是这两条力通道能一同验证同一个力旋量预测器。所不同的是预测*问题*本身：A 的反作用可由它自己下达的 $\ddot q_{\text{arm}}$ 算出（自激），而 C 的外部力旋量是外源的，必须从上下文与负载中*预判*出来。

**第一性原理**：*原理：* 外部力旋量经 $J_{\text{ext}}^{\top}$ 传到每个关节，包括那些把质心稳在脚上的支撑腿。*被挑战的假设：* 刚性的抗力跟踪器把负载当成要反应式压制的扰动。*赌注：* 预判式的力旋量头在分布外负载上胜过反应式抗拒，增益集中在力旋量最大、方向最多变之处。

**最尖锐的问题**：1）预判力旋量的头能否在分布外负载上胜过刚性抗力跟踪器，且增益落在力旋量最大处？2）一个共享的残差头能否同时预测自激反作用（A）与外部力旋量（C）？3）这套前瞻性前馈能否扛住 ADAPT 式观测器的对照（三路：前馈 / 观测器 / 刚性）？

> [!warning] 风险
> - 同一个反应式*观测器*（ADAPT）威胁 C 一如威胁 A → 幸存的切口是在负载被完全感受到*之前*就预判力旋量；跑那套三路消融。
> - 真机上主导的项也许是接触或带宽，而非力旋量（先给力感知定价）；通才也许会在规模上追上来（报告交叉边界）。

### 预测 — WAM·A（[[WAM|WAM · A]]）
> [!abstract] 押注
> 一个会想象力旋量的 WAM，能把所测的触觉→无触觉接触跌幅（[[2603.17851|DexViTac]] **83.3→43.3**）找回 **≥50%**，*哪怕部署时根本没有力传感器*。想象出的力旋量是一种服务于全部三条通道的本体感受式预报，而*外部*力旋量（C）是其中最贴切的一例。

**为什么**：耦合项*本身*就是一个被预测出来的力旋量。招法是：把力旋量当成一个被建模的**输出**，而不只是喂给策略的**输入**，这样即便部署时没有力传感器，策略也能据一份耦合预报来规划。

**第一性原理**：*原理：* 接触之中，力是因，视觉是果。*被挑战的假设：* 那些把力当输入喂进去的方法（DexViTac 去掉触觉就从 83.3 跌到 43.3）默认部署时还得有这个传感器。*赌注：* 把力旋量想象成世界模型的输出，预报就能顶替传感器，至少把一半损失找回来，而同一份想象同时覆盖自激反作用（A）与外部力旋量（C）。

**最尖锐的问题**：1）没有传感器时，想象出的力旋量能不能把触觉移除的跌幅找回 ≥50%？2）想象出的力旋量能不能作为一个供策略规划的预报向前推演，而不只是一个静态的回归头？3）一份想象能不能同时覆盖两条力通道（内部反作用 A 与外部力旋量 C）？

> [!warning] 风险
> - 少了预测，耦合就只是个笨拙的回归头，谈不上可向前推演的预报 → 把这个头设计成一个会想象力旋量、并产出向前推演预报的 WAM。
> - 部署时没有力传感器，预报可能撑不住 → 重构为 WAM 这一步就把反作用预报能否在无传感器下存活作为闸门。

### 锚定现实 — S2R·B（[[Sim2Real|S2R · B]]）
> [!abstract] 押注
> 逐通道的梯度系统辨识，在每条通道所依赖的那确切物理上能赢过域随机化：A 看臂-基座惯性，C 看接触模型，B 看被操作物体的物理。[[2603.01151|D-REX]] 拿到 **9–10/10 vs 4–9/10**（已落到 DR 支撑域之下）；[[2510.11689|Phys2Real]] 在配重在顶的 T 形块上拿到 **57% vs 23%**。最重的押注是：一个摊销式推断网络，不用逐物体演示就能为没见过的通道/物体推断参数。

**为什么**：物理模型一旦错了，显式项就*毫无*优势；URDF 不好就会毒化 $\hat M_{\text{base,arm}}$（这正是 A 点名的风险）。可微系统辨识从交互中恢复那几个确切参数，而不是去猜一个模型。

**第一性原理**：*原理：* 显式耦合项有多准，全看它所乘的那些物理有多准，A 是惯性、C 是接触、B 是物体物理。*被挑战的假设：* 域随机化赌的是不辨识也能鲁棒，但 D-REX（9–10/10 vs 4–9/10）和 Phys2Real（57% vs 23%）都表明，碰上分布外物理，DR 一越出支撑域就垮。*赌注：* 可微系统辨识能从 ≤5 次真实演示里恢复逐通道的物理，让显式项*在真机上成立*，也能仿真到现实迁移。

**最尖锐的问题**：1）逐通道的物理能不能从 ≤5 次真实演示里由可微系统辨识恢复，并在分布外质量/负载上赢过 DR？2）校准过的耦合项能不能在真实人形机器人上完成仿真到现实迁移？3）逐物体的恢复能不能摊销进一个推断网络，从而不靠逐物体演示就服务于没见过的物体？

> [!warning] 风险
> - 少了锚定现实，显式项会被仿真物理误差毒化，塌回隐式基线 → 把锚定现实留在核心，让每条通道的项都由真实数据锚定。
> - 这个具名方向恢复的是*物体*物理，所以把它指向机器人自身的惯性/接触是一个方法迁移的押注 → 若某条通道上系统辨识学不干净，就退回该通道的隐式基线；你照样产出了清晰的消融（可借 VERIFY 发表）。每条分支都能给出一个结果。

### 验证 — EAI·B1（[[Embodied-AI|EAI · B1]]）
> [!abstract] 押注
> ASR + COD *联合*预测真实机群成功率，能到 **ρ > 0.7**；而把 WM 质量 / 策略 SR 拆成两轴各自评估，只有 **ρ < 0.4**。这个因果一致性指标如今做的是想象↔动作的绑定；押注则是把它*扩展*成跨*全部三条通道*绑定预测出的耦合↔实现出的耦合。这检验的，正是每条通道的押注所倚赖的那道绑定。

**为什么**：它是那个具名基准缺口的原理化形态：没有哪个基准能单独隔离出耦合，A 是平衡误差 vs 伸手激进程度，B 是工作空间位移 vs 基座移动，C 是平衡误差 vs 负载。一个指标把三者都打分。

**第一性原理**：*原理：* 耦合预报要成立，前提是预测出的耦合等于实现出的耦合，且二者一并度量。*被挑战的假设：* FID 式的分轴评估（WM 质量与策略 SR 分开打分，ρ < 0.4）放任想象和动作各自漂移，每根轴你都能 Goodhart（钻指标空子）。*赌注：* 一个联合的 ASR+COD 因果一致性指标，能以 ρ > 0.7 预测真实 SR、且跨全部三条通道，证明耦合在因果上站得住，而不只是看着合理。

**最尖锐的问题**：1）分轴还停在 ρ < 0.4 的地方，联合 ASR+COD 指标能不能对真实机群 SR 打到 ρ > 0.7？2）它能不能把那个缺失的基准变成一个真实可量的度量，跨全部三条通道？3）它能不能证明耦合预测在*因果上*正确，从而让显式对隐式这个结果在每条通道上不管成败都能发表？

> [!warning] 风险
> - 少了验证，押注既证不了、基准缺口也补不上，而 FID 式指标还会放任想象和动作漂移 → 把因果一致性指标当成贯穿全程的测评框架。
> - 这个指标也许分不清因果上正确的预报和仅仅看着合理的预报 → 那就把门槛定为：*联合*的 ASR+COD（ρ > 0.7）必须在全部三条通道上胜过分轴评估（ρ < 0.4）。

### 为什么是这个方向，以及最廉价的证伪
我们选这套计划，就是要把“想法决定成败的程度 × 区分人形机器人的权重”这两者一起拉满，一支押注想法、而非资本的单人团队，该追的正是这个。三条通道覆盖了手臂的力抵达腿的*两条主导*力传导通路（自激惯性 A、外部接触 C），外加一条*独立的运动学轴*（B），所以这套计划是*一个论点三路验证*，而非押在单一实例上。每条通道都有真实数字锚着：[[2604.07993|HEX]]（臂↔腿，**61.8% 分布外 vs 41.0%**）、[[2503.05652|BRS]]（基座↔臂，**子任务 88%**，较 DP3/RGB-DP 高 13x/21x）、[[2505.06776|FALCON（运动操作）]]（负载下的力，跟踪误差 **0.37 vs 0.60**，零演示），还有 [[2604.07457|CMP]] 的**极端分布外 86.7%**。

最廉价的证伪是**三路并行的证伪**，要最先跑：用*同一套*廉价的仿真消融配上三个不同的交叉项，每一路都是一个独立的 go/no-go，一次性把这个共享论点三向交叉验证。**A：** 显式前馈的基座反作用头 vs 反应式观测器 vs 隐式耦合策略，按手臂加速度分层。**B：** 自回归 基座→躯干→臂 vs 扁平拼接，按抓取中途的基座移动分层。**C：** 预判的外部力旋量 vs 反应式观测器 vs 一个刚性抗力跟踪器，按负载大小/方向分层（A、C 两条力通道都要加上反应式观测器这第三路，因为单凭显式对隐式无法把预判和反应区分开）。数据、骨干、任务、仿真全部相同，不加一条新数据。为了让每个测试保持诚实而非循环（每个目标都由策略自身也要学的那个模型来定），用一个*被扰动过的*模型来定义每个目标，并把显式相对隐式的边际报告成模型误差的函数，那些边际随误差变化的曲线就是验证框架的交付物。要是某条通道上显式 ≈ 隐式（分布外边际没拉开、增益也没集中在该通道交叉项最大处），那条通道的贡献作废，而你一次性就把三件事都弄明白了。三路都能在前期、低成本地*自证其谬*，正因如此它们才算好问题，而不只是诱人的问题。（[[Whole-Body|WB · C2]]，一个负载下*被认证*的安全集 / 屏障，推到扩展层，作为“认证”的收官之作，而非核心。）
