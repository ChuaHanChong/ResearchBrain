# TL;DR（中文）：三维/四维空间与几何表示（3D/4D Spatial Representation）

> 原始研究方向文档：[[Spatial-4D|3D/4D Spatial & Geometric Representation Directions]]（`_Projects_/Research-Directions/Mechanism/Spatial-4D.md`）。本篇是它的中文 TL;DR：逐方向给出**论点、第一性原理框架、具体研究问题、风险**四块，其余细节请回原文。

## Cluster A — 几何原生策略（Geometry-Native Policies）
### A1 — 点云原生动作头 vs RGB 词元策略
- **论点**：动作是「物体在度量三维空间中的位置」的函数，点云直接给出这一位置，而 RGB 词元只能隐式编码它。点云原生动作头在跨本体零样本迁移上应胜过 RGB 词元策略（PointAction 零样本 xArm7 43.0%、RoboCasa365 同分布 47.7%；GeoVLA LIBERO 97.7%）。
- **第一性原理框架**：
  - *第一性原理*：操作动作由度量三维布局（夹爪、物体、接触点的位置）决定；几何在光照、纹理、视角、相机位置变化下保持不变，外观则不然。
  - *挑战的假设*：OpenVLA / SpatialVLA 持有的观点——大型二维主干已编码动作头所需的全部几何，显式三维分支纯属冗余开销。
  - *下的赌注*：在 RGB 策略崩溃之处，点云头仍能实现 ≥43.0% 的跨本体零样本迁移，且几何与 RGB 之间的差距随分布偏移加大而**拉大**。
- **具体研究问题**：
  1. H1 — 渐进偏移优势在 VLA 尺度复现（已证先验、外推）：固定主干，把 Point Cloud Matters 的光照/噪声/背景扫描换上 2D 预训练 VLA 主干；点云头减 RGB 头的 SR 差距随偏移量单调增长、零偏移时 ≈0。
  2. H2 — 优势集中在关系/接触子段（已证先验、外推）：按任务阶段拆解 SR；点云优势集中在接触密集段、自由空间运送段近乎为零（Point Cloud RL 的关系性结论在 VLA 尺度重现）。
  3. H3 — 最小充分几何远低于完整点分支：大部分 SR 增益由稀疏点（DP3 密度）恢复，恢复比例-密度曲线的拐点远在 GeoVLA 完整分支之下。
  4. H4 — 是*点表示*而非分解式解码器扛起零样本迁移：固定解码器、把 PointAction 的点表示换成 RGB 特征会崩掉大部分 43.0% xArm7 迁移；固定点、换解码器则不会（2×2 对照）。
  5. H5 — 原生点云头在几何约束切分上（而非 ID）胜过最强潜在几何策略：对比 VLA-JEPA（97.2% LIBERO）/3DThinkVLA，点云头在 ID LIBERO 持平、在 LIBERO-Plus 扰动上超越。
- **风险**：
  - 点云依赖深度传感或重建，部署时可能含噪或缺失。→ 改走预测点图的路线（PointAction），让几何由模型*生成*而非*传感*，去掉对深度传感器的硬依赖。
  - 在 RGB 主干已饱和的同分布基准（LIBERO ~97%）上，优势可能消失。→ 围绕外观偏移与跨本体的切分设计评测，把同分布持平视为预期而非失败。
  - 完整三维分支会增加延迟与参数。→ 以 H3 的最小充分几何扫描，配合 A3 的深度词元桥作为轻量回退。

### A2 — 占据预测作为策略的前向模型
- **论点**：规划需要知道*哪些空间将被填充*，而非*场景看起来如何*——占据栅格直接回答这一问题，像素则每步都要重新推断几何。把驾驶领域成熟的占据世界模型移植到桌面操作，应能继承其长程稳定性（OccSim 3,000+ 稳定帧、相对 mIoU +22.1%、零样本 67%），而像素模型几十帧就开始漂移。
- **第一性原理框架**：
  - *第一性原理*：规划器需要知道哪些空间区域将被占据（无碰撞、接触、可达性），体素栅格直接给出这一信息；像素只是同一几何的有损、视角相关的再编码。
  - *挑战的假设*：操作前向模型应预测像素（CTRL-WORLD 等视频世界模型的惯例），理由是视频基础模型预测的就是像素——而 OccSim 的 80× 长程增益说明，像素基底本身正是漂移之源。
  - *下的赌注*：占据前向模型在操作回路中保持几何稳定的时长，比像素世界模型基线长一个数量级，且下游 SR 增益与 OccSim 的相对 mIoU +22.1% 提升同向。
- **具体研究问题**：
  1. H1 — 稠密体素占据内循环在 RoboCasa 尺度的到发散时域胜像素：固定主干换成*稠密体素*占据循环，推演到几何发散的时域 ≥10×（超出 ACID 隐式场、3D-Occ-MPC 单物体网格所证），驾驶的 80× 增益部分存活。
  2. H2 — Warp-DiT 误差约束可移植到亚厘米：刚体变换误差约束在接触精确所需的亚厘米分辨率下仍成立，随分辨率收紧优雅退化而非崩溃。
  3. H3 — 解耦动态体稳定物体运动预测：把 OccSim 的静态场景/动态体解耦搬到操作（被操物＋夹爪＝动态体），物体运动预测误差低于单体占据预测器。
  4. H4 — 预测的未来占据可直接条件化 A1 动作头：把 A2 的预测占据喂给 A1 点云头，闭合全几何感知-想象-行动回路，在长程任务上胜过仅当前帧几何。
  5. H5 — 显式占据在时域而非逐帧保真上胜潜在四维：对比 C3 X-WAM 潜在，占据循环赢在到发散帧数、输在逐帧 Chamfer——证实二者互补而非竞争。
- **风险**：
  - 跨域迁移未必成立——驾驶占据是米级且大体静态的，而操作需要亚厘米的动态占据。→ 以 H2 的分辨率扫描配合 H3 的动态体类比，作为是否声称迁移的明确门槛，并报告 Warp-DiT 误差约束失效的尺度。
  - 操作数据集中占据真值稀缺。→ 由深度配合已知夹爪几何推导占据（如驾驶领域从激光雷达推导），或在仿真中预训练预测器（占据真值免费可得）。
  - 亚厘米分辨率下体素栅格的内存占用大。→ 改用稀疏或分层占据（八叉树），并把声明限定在末端执行器周围的工作体积，而非整个场景。

### A3 — 深度词元桥：无需重训即可给预训练二维策略注入三维感知
- **论点**：二维策略的几何缺陷在于*缺一个通道*，而非*主干用错了*——因此一个廉价的深度词元旁路输入即可补上，又不扰动预训练的语义对齐。「冻结主干接深度桥能用」本身已被 PointVLA 坐实；真正的贡献是*没人量过的那把尺*：成本效率前沿（恢复比例拐点）与旁路对语义对齐的扰动代价（QDepth-VLA 单视角 LIBERO-Spatial +8.8%、长程 +29.7%；对比 GeoVLA 完整三维分支 97.7%）。
- **第一性原理框架**：
  - *第一性原理*：二维策略的空间弱点在于*缺通道*（深度），而非表示被破坏；用离散词元经解耦专家补上该通道，即可提供度量线索，无需重建主干。
  - *挑战的假设*：「真正的三维感知需要完整平行三维分支＋联合重训」*已被推翻*——PointVLA 冻结主干、零重训即接入三维，Spatial Forcing / VEGA 更以*零*推理开销蒸馏几何。所以廉贵二分*已是伪命题*；A3 现攻的开放假设是「能用」这个说法本身不够——因为没人画出成本效率前沿、也没人量过那本被假定为零的对齐代价。
  - *下的赌注*：交付的是*没人产出过的测量*，而非 PointVLA 已坐实的存在性——即（i）同一主干上「恢复比例 vs 新增参数」曲线有明显拐点，以远低于完整分支的代价恢复 GeoVLA 完整三维分支 ≥80% 的 SR 增益；（ii）冻结主干旁路对留出 VQA 语义对齐探针的扰动，可测地小于反传进主干的完整分支融合。
- **具体研究问题**：
  1. H1 — 恢复比例曲线有拐点：扫描深度词元容量（码本大小、专家深度），相对 GeoVLA 完整三维分支的 SR 增益恢复比例以一小部分新增参数达 ≥80%，前沿呈明显拐点（PointVLA/DepthVLA 都没画过）。
  2. H2 — 量化（而非仅解耦专家）带来抗噪增益（延伸已被预答）：Depth Helps 已示量化深度丢弃只损 0.8%；用「量化 vs 连续」×「解耦 vs 融合」2×2 在容量扫描上分离出量化的*可分离*贡献。
  3. H3 — 第二视角补上残差：单视角深度词元增益在完整三维上限之下饱和；加第二视角深度词元能补上与「消费传感点云方法」之间的大部分残差。
  4. H4 — 旁路扰动远小于完整分支融合：留出 VQA 探针显示，冻结主干深度专家对语义对齐的扰动可测地小于反传进主干的完整分支融合。
  5. H5 — 训练时蒸馏在几何约束任务上匹配推理期深度通道：Spatial Forcing 式训练时对齐以*零*推理代价恢复可观比例的完整三维增益；SwiftVLA 的掩码重建把这扩到*时空*（而非仅深度）特征——最廉价的可部署形态测试期无需深度。
- **风险**：
  - 在最难的几何约束任务上，桥可能停在完整三维的上限之下。→ 用 H1 的恢复比例曲线设定诚实预期，把贡献定位为*成本效率前沿*而非刷新 SR 的 SOTA。
  - 深度词元质量依赖深度估计器。→ QDepth-VLA 的量化可缓冲估计器噪声；报告对估计器质量的敏感性，把声明限定在现实的深度范围内。
  - 旁路仍可能细微扰动语义对齐。→ 用 H4 的 VQA 探针量化扰动并据此设阈，而非假设冻结主干完全不受影响。

## Cluster B — 作为三维锚定认知层的空间推理（3D-Grounded Cognition）
### B1 — 显式三维场景图思维链做度量空间推理
- **论点**：度量空间关系是*建立在几何实体之上的图*；自由形式的语言思维链只能有损地描述该图，且在缺乏锚定时会幻觉。「结构＋RL＋抗捷径让 OOD 泛化」已成共识（Thinking with Blueprints、MomaGraph）；尚未解决的是*图的哪条属性*（度量边 vs 拓扑序）扛起增益、以及图*在哪失败*（构建 vs 推理）——残差在因果任务上最大（CausalSpatial GPT-5 54.17% vs 人类 84.49%）。
- **第一性原理框架**：
  - *第一性原理*：空间关系构成一张建立在几何实体（带度量位置的物体、两两关系、接触）之上的图；正确推理*就是*在该图上运算，而语言只是丢失了度量结构的有损序列化。
  - *挑战的假设*：「足够大的多模态模型会隐式推理空间」*已被推翻*——朴素思维链可能*有害*，只有*结构化*场景图思维链才有帮助，GPT-5 仍落后人类 30 分；而「结构＋RL＋OOD 泛化」如今*也已成共识*。B1 现攻的开放假设是「加*任意*图就够」——真正没测的是*图的哪条属性*（度量边 vs 拓扑序）扛起增益、图*在哪*失败（构建 vs 推理）。
  - *下的赌注*：增益由*度量*内容（而非图拓扑）扛起、瓶颈在*构建*（而非推理）——即（i）带度量边标签（距离、角度）的场景图在 CVBench 上胜过纯拓扑图，差距集中在度量关系题型、在物体命名上 ≈0；（ii）当场景图思维链在 CausalSpatial 因果切分出错时，多数错误可溯源到*错图*（幻觉/缺失实体），故图构建准确率可预测答案准确率。
- **具体研究问题**：
  1. H1 — 是度量边而非拓扑关系扛起增益：带度量边标签（距离、角度）的场景图在 CVBench 上胜过纯拓扑图（左于、在上），差距集中在度量关系题型。
  2. H2 — RL 锚定比 SFT 更好地把场景图习惯迁移到 OOD（已证先验、在因果-OOD 上再确认）：GRPO 锚定的场景图思维链在 CausalSpatial 因果任务上泛化、SFT 退化（复现 +19.5% Depth-OOD 模式）——Thinking with Blueprints / MomaGraph 已在一般 OOD 上证之，B1 只在那些论文未隔离的*因果*切分上再确认。
  3. H3 — 残差在轨迹上受推理约束、在遮挡上受感知约束：把 30 分差距按任务拆解，场景图思维链补上*轨迹*切分（推理）的大部分，却几乎补不了*遮挡*切分（感知/深度）。
  4. H4 — 上游场景图锚定部分替代下游几何：把 SpatialCoT 推理出的坐标喂给更简单的 RGB 动作头，可恢复 A1 点云头 SR 的可测部分——但非全部，留有仅传感几何能补的残差。
  5. H5 — 瓶颈是图构建准确率而非答案准确率：场景图思维链出错时多数错误溯源到错图（幻觉/缺失实体），故单列图构建准确率即可预测答案准确率。
- **风险**：
  - 场景图构建本身会幻觉——错误的图会毒化下游推理。→ 用 B2 的四维一致性与深度（CausalSpatial 的 COW 视觉模拟证据）锚定，并把图构建准确率与答案准确率分开报告（H5）。
  - 增益可能只对特定基准成立（在 CVBench 上调好的提示无法迁移）。→ 用 H2 的 RL-OOD 协议显式测跨基准迁移，把 GRPO 当泛化机制而非提示调优。
  - 人类差距可能受感知而非推理约束——场景图思维链修不了坏的深度。→ 用 H3 分离感知与推理失败；若受感知约束，则转交 A3 深度桥作上游修复。

### B2 — 四维一致策略：把时空几何作为推理约束
- **论点**：要在一段时域上规划动作，物体的几何与身份必须跨时间、跨视角保持连贯——即四维一致。「隐式一致*有助* OOD」已成共识（视角侧 GeoAware、时间侧 EvoScene-VLA / OptimusVLA）；尚待证的是*一致性 vs 感知*孰为驱动、且须在*完整*时空四维（而非仅视角切分）上证之（ConsisVLA-4D LIBERO 98.1%、真实双臂 70.0% vs OpenVLA 28.5%、推理快 2.31×）。
- **第一性原理框架**：
  - *第一性原理*：要在一段时域上规划动作，想象的几何必须在时间上、跨视角上一致（同一物体落在连贯的四维轨迹上）；一致性是表示须满足的约束，并不等于渲染出每一个中间帧。
  - *挑战的假设*：非此即彼——要么接受带投影偏置的二维（OpenVLA 一类），要么为四维一致性付出显式生成未来帧（X-WAM 一类）的代价；ConsisVLA-4D 用隐式一致注意力同时拿到显式三维精度与 2.31× 加速，证此权衡可破。而「隐式一致*助* OOD」如今*也已成共识*（视角 GeoAware、时间 EvoScene-VLA / OptimusVLA），故争点变为*一致性 vs 感知*孰为驱动、且须在*完整*时空四维而非仅视角上证之。
  - *下的赌注*：驱动 OOD 增益的是一致性*约束*，而非裸三维或仅视角几何——且须在*完整*时空四维（而非 GeoAware 圈的仅视角切分）上证之：固定感知消融 ConsisVLA-4D 的一致注意力，OOD SR 崩得比消融任一感知特征更厉害、也比损 ID SR 更厉害。
- **具体研究问题**：
  1. H1 — 完整时空四维上，消融一致性比消融感知更崩 OOD：固定感知去掉一致注意力，OOD SR 崩得比去掉任一感知特征更厉害、也比损 ID 更厉害——GeoAware（仅视角）、VLA-4D（仅三维存在性）都没跑过的隔离，且要在*时间*而非仅视角上。
  2. H2 — 隐式四维在 SR-延迟平面帕累托占优，除某子类外：把隐式（ConsisVLA-4D）对照显式（Geometry-aware 4D Robot Video、STARRY）作图；隐式占优，除非需要可外读几何（可调试、交接追踪器）。
  3. H3 — 隐式一致＋显式轨迹叠加而非冗余：把隐式一致（B2）与 MolmoAct 可操纵视觉轨迹配对，OOD SR 超过任一单独——二者锚定不同（约束 vs 可审计）。
  4. H4 — 隐式优势存在时域交叉窗：隐式一致在某时域阈值之上胜二维、在更长阈值之上输给显式生成——存在隐式最优的可测窗口；越过上交叉就转 C4。
  5. H5 — 场景流先验以更低成本恢复大部分一致性增益：LaMP 稠密三维场景流先验以低于完整一致注意力的架构成本，恢复 ConsisVLA-4D OOD 增益的可观比例（趋近 79.3% LIBERO-Plus）——流是约束的廉价形态。
- **风险**：
  - 隐式一致可能不可检视——看不到注意力学到了什么四维结构，损害可调试性。→ 搭配 MolmoAct 的显式视觉推理轨迹（H3），让时序推理可操纵、可审计。
  - 成本声明来源单一——2.31× 加速仅来自 ConsisVLA-4D。→ H2 跨隐式与显式方法的完整成本/精度前沿，是声称泛化效率前的是否门槛。
  - 隐式四维可能在最长的时域上悄然失败，漂移不可见地累积。→ 用 H4 的时域缩放交叉点圈定有效区间；越过它就转用 C4 的显式持久几何记忆，而非硬撑隐式一致。

## Cluster C — 几何原生世界模型与记忆（Geometry-Native World Models & Memory）
### C1 — 占据世界模型作为操作推演的基底
- **论点**：世界模型的长程稳定性受*几何*误差累积速度的限制——带刚体变换约束的显式占据栅格能约束该误差，潜在基底则不能。占据用于操作推演*并非新事*、*也非仅驾驶*（DSR-Net 2020 早做了占据＋MPC 操作、Occupancy WM 把占据搬进室内）；没人跑过的是*显式占据 vs 潜在四维*在桌面尺度的到发散时域对决（OccSim 3,000+ 稳定帧、相对 mIoU +22.1%、相对先前 <50 帧 80× 时域）。
- **第一性原理框架**：
  - *第一性原理*：世界模型的长程稳定性由推演过程中逐步几何误差的增长速度决定；带刚体变换约束的占据栅格（OccSim 的 Warp-DiT）压住逐步误差，而潜在基底没有这种约束，误差逐步复利、推演随之漂移。
  - *挑战的假设*：「推演基底应是策略所见的同一份 RGB-D 潜在」（CTRL-WORLD、C3 潜在 X-WAM 的惯例）。旧卡「因占据只在驾驶建过而被跳过」的说法*实证为假*——DSR-Net（2020）、Occupancy WM 已在操作/室内做了占据，3D-Occ-MPC 已实例化占据推演。真正的开放假设是：*因为*占据与潜在都「能用」，基底之选便不约束时域——而 OccSim 的 80× 时域增益说明基底*就是*漂移之源。
  - *下的赌注*：体素语义占据世界模型在桌面尺度的*到发散时域*上以 ≥1 个数量级胜 C3 潜在四维基线（X-WAM）——3D-Occ-MPC、DSR-Net 都没跑过的对决——同时*输*在逐帧 Chamfer（潜在四维 0.0049），故二者互补而非竞争；其 Warp-DiT 误差约束存活至亚厘米。
- **具体研究问题**：
  1. H1 — 桌面尺度到发散时域，占据胜潜在（没人跑过的对决）：匹配操作任务上，占据世界模型的几何发散帧数以 ≥1 个数量级超过 C3 X-WAM 一类潜在——3D-Occ-MPC / DSR-Net 都没做过的显式-vs-潜在对决——驾驶的增益部分存活。
  2. H2 — 可外读占据在碰撞检测上胜解码潜在：现成规划器无需学习解码器即可消费占据栅格做碰撞检测，并在规划延迟与精度上胜过把 C3 潜在解码成可用状态。
  3. H3 — 混合基底在（时域 × 保真）上胜任一单一：长程可读推演用占据、逐步高保真想象切 C3 X-WAM 潜在，混合在联合指标上胜过任一单独。
  4. H4 — Warp-DiT 误差约束存活至亚厘米：OccSim 的刚体变换误差约束在操作分辨率下成立、优雅退化而非在米级以下崩溃。
  5. H5 — 是占据栅格漂移（而非 Chamfer）预测下游规划失败：下游长程规划 SR 与到发散时域（时域上的 mIoU）相关，而非与逐帧 Chamfer 相关——证实正确的失效轴是时域长度。
- **风险**：
  - 驾驶→操作的尺度差距——占据在米级验证，操作却需亚厘米。→ H4 的亚厘米 Warp-DiT 测试是是否门槛，应报告误差约束失效的分辨率，而非假设迁移成立。
  - 若显式与潜在的差异在实践中变得模糊，便会与 C3 重叠。→ 把贡献钉死在*可外部渲染的长程占据*（H2）与*互补性*（H3）上——C1 不是更好的 X-WAM，而是 X-WAM 所不具备的那种基底。
  - 操作数据中占据监督稀缺。→ 在仿真中（免费）和真实数据上由深度配合夹爪几何推导占据；把真实数据上的声明限定在占据真值可恢复之处。

### C2 — 四维几何一致视频预测用于六自由度位姿提取
- **论点**：六自由度位姿是几何量——跨视角一致的点图能把它直接暴露给任何跟踪器，而纯 RGB 帧只会让它变得含糊。联合预测 RGB 与跨视角一致点图，能产出可直接读取的六自由度轨迹，从而带来高得多的操作 SR（Geometry-aware 4D Robot Video 在三个仿真任务上平均任务 SR 0.64 vs Dreamitate 0.12、Diffusion Policy 0.12）。
- **第一性原理框架**：
  - *第一性原理*：六自由度位姿是几何量；只要点图跨视角一致，任何跟踪器都能直接读出位姿（位姿就是匹配三维点之间的刚体变换）。纯 RGB 帧隐藏了位姿，逼下游估计器每帧从头重解。
  - *挑战的假设*：Dreamitate 一类的惯例——像素视频模型配合下游位姿估计器就够了；而 ≈5× 的 SR 差距（0.64 vs 0.12）表明，事后估计器才是瓶颈，只有在模型内*一致地*预测几何才能使轨迹可提取。
  - *下的赌注*：联合预测 RGB 与跨视角一致点图，产出可直接读取的六自由度轨迹，平均任务 SR ≥0.64，对比「RGB 加估计器」基线的 ~0.12（≈5×），且增益随*跨视角一致性*（mIoU）变化。
- **具体研究问题**：
  1. H1 — 是跨视角一致性（而非 RGB 保真或单视角深度）驱动动作增益：固定 RGB 去掉跨视角点图扩散损失，轨迹提取精度与下游 SR 比损 RGB FVD 崩得更厉害；且「单视角深度＋学习估计器」（GVF-TAPE 式）变体输给跨视角一致的追踪器读出——隔离出两个近邻都没测的「一致性为追踪器服务」这条杠杆。
  2. H2 — 预测点图相对传感深度在位姿读出上代价小：从预测点图提取六自由度仅略输于从传感深度，小到足以在无传感场景下用预测代替。
  3. H3 — 新视角泛化有可测外推包络：位姿提取精度在有界的视角外推范围内保持、之后退化——即可外读声明的工作包络。
  4. H4 — 在可调试关键任务上外部化几何胜内部化：同任务上 C2 追踪器读出管线在需检视/复用几何处（多追踪器、失败诊断）胜过 ConsisVLA-4D 端到端隐式头，在仅看成本处输。
  5. H5 — 遮挡是预测几何位姿读出最占优之处：预测点图→位姿管线相对事后估计的优势在遮挡下最大，呼应 RecGen 的 +38.2 pp 遮挡增益。
- **风险**：
  - 方向锚点单一——核心结论仅靠 Geometry-aware 4D Robot Video 的三任务评测。→ H1 一致性消融与 H2 预测-vs-传感比较是内部有效性检查；在泛化 ≈5× 这一声明之前先扩充任务集。
  - 预测点图可能比传感深度更含噪，从而降低位姿读出精度。→ H2 直接量化预测-vs-传感的差距；若差距大，则把 C2 限定在无传感场景（新视角、无深度传感器）。
  - 以三任务 SR 作基底，声明面太窄。→ 把贡献定位为*机制*（显式跨视角点图 → 跟踪器可读的位姿）已在三任务上得到验证，更广的评测作为明确的下一步，不夸大覆盖面。

### C3 — 原生四维几何作为世界表示基底
- **论点**：对接触类与空间类任务，动作由几何决定，而这种几何模型只能从像素间接推断——因此*原生四维*（RGB + 深度 + 随时间的三维几何）表示能直接携带它，事后从二维抬升则不行。「显式几何在线胜潜在＋跨本体迁移」已被 PointWorld 坐实（点流基底，1B 参数）；C3 的独特性收窄到 PointWorld 没跑的两根支柱：*异步去噪零部署代价*的延迟对比、与*原生-vs-抬升 Chamfer* 消融（X-WAM RoboCasa 79.2%、Chamfer 0.0049 vs 0.0680、4.5× 至 15 Hz）。
- **第一性原理框架**：
  - *第一性原理*：对接触密集与空间约束任务，动作是*几何*（相对位姿、深度、表面法向、自由空间）的函数；不编码几何的像素基底逼消费者每步从外观重推，白白丢弃了本可直接携带的结构。
  - *挑战的假设*：「显式四维太贵无法部署，故几何应由单独两阶段管线恢复」——X-WAM 表明两阶段几何更差（Chamfer 0.0680 vs 0.0049）且更慢。而「显式几何在线胜潜在＋跨本体迁移」如今*已被 PointWorld 证实*，故 C3 的独特性收窄到 PointWorld 所略：*异步去噪零代价*的延迟对比与*原生-vs-抬升 Chamfer* 消融，且要在*原生四维-RGB-D-视频*（而非点流）基底上。
  - *下的赌注*：连 PointWorld 在内都没跑的两根支柱决定原生在线四维是否比训练时辅助更值——（i）固定主干，X-WAM 交错深度分支在几何约束 RoboCasa 任务上胜「像素基底＋事后深度估计器」（原生 Chamfer 0.0049 vs 两阶段 0.0680），隔离出原生-over-恢复；（ii）推广异步噪声采样，动作调度步蒸馏到 1–4 步（延伸 X-WAM 5 步 15 Hz、4665→1033 ms）而不降读出几何——PointWorld 点流 MPC 从未绘过的延迟-保真前沿。
- **具体研究问题**：
  1. H1 — 原生四维胜事后抬像素：固定主干，X-WAM 交错深度分支在几何约束 RoboCasa 任务上胜「像素基底＋事后深度估计器」，隔离出原生-over-恢复四维。
  2. H2 — 异步动作调度缩到 1–4 步而不降读出几何：推广异步噪声采样，动作去噪调度步蒸馏到 1–4 步，消费者读取的四维 Chamfer 不降。
  3. H3 — 显式三维让离散接触模式预测比潜在更易：显式三维几何通道相比连续潜在降低离散接触模式（穿透/邻近）的预测误差，因几何直接暴露接触。
  4. H4 — 末端执行器导出的相机位姿改善 OOD 几何：消融 X-WAM 的末端执行器→相机位姿自一致约束，OOD Chamfer 退化——证此约束有效。
  5. H5 — *原生四维-RGB-D-视频*基底的 WM→策略迁移不逊于 PointWorld 点流（部分已证、扩到 RGB-D）：PointWorld 已示点流基底的模型无关跨本体迁移；开放扩展是原生四维-RGB-D-视频基底*保留外观通道*能否同样迁移 WM→策略头——空间任务（插入、堆叠、倒液）上显式几何规划胜潜在，同一基底插入策略头匹配其 WM 消费者增益。
- **风险**：
  - 四维监督需要多数机器人数据集所没有的深度/三维真值。→ 用 X-WAM 由末端执行器导出的相机位姿配合现成深度估计器来缓解；把声明限定在几何可恢复的任务上。
  - 四维只在几何约束任务上才划算——外观约束任务上潜在已经胜出。→ 在接触/空间任务（RoboCasa 插入、堆叠）上评分，而非以 LIBERO SR 为核心指标，并显式报告任务类型的切分。
  - 实时四维如今已由两个结果支撑（X-WAM 原生 RGB-D、PointWorld 点流），故开放问题不再是「能否实现」而是「原生-vs-恢复＋异步步蒸馏是否划算」。→ 把 H1 原生-vs-恢复 Chamfer 消融与 H2 延迟-保真前沿当作是否门槛，并承认广义迁移声明归 PointWorld。

### C4 — 持久几何记忆实现长程连贯
- **论点**：「显式几何记忆在动作条件长程连贯上胜纯注意力」已被 3D Persistent Embodied WM（PEWM）坐实。尚未解决的是：一份世界坐标系记忆能否当作*可复用的持久层*，覆盖 C1 占据、C2 点图、C3 潜在四维；以及几何记忆＋情景记忆能否在动作条件、需历史的任务上*叠加*。领域每次都按基底各建一套记忆、也从不把两类记忆放一起测（PEWM SRC 81.7% vs 无记忆 63.4%，MosaicMem RotErr 0.51° vs 1.42°/4.65° @16 FPS，Chameleon 100%/73.5% DSR，RoboMemArena 68.9% 子任务需历史）。
- **第一性原理框架**：
  - *第一性原理*：世界坐标系几何记忆与*基底正交*——物体恒存（东西离开视野再回来时在哪）是度量坐标系的属性、而非填充它的表示的属性，故*同一*持久机制应能钉住 C1 占据、C2 点图或 C3 潜在四维；PEWM 已在 RGB-D 基底上证此机制，第一性原理说它不绑定该基底。且几何与情景记忆是*互补*原语——一个定*哪里*、一个定*哪个事件*，故应叠加。
  - *挑战的假设*：「记忆按基底各建一套」且「几何 vs 情景记忆是替代而非互补」。PEWM 与 MosaicMem 各为自家模型建*定制*几何记忆，Chameleon 仅建情景记忆，Long-Term Spatial Memory WM 虽合二为一却仅用于相机视频、从未在 RoboMemArena 定义的动作条件记忆任务上测。
  - *下的赌注*：（i）一份世界坐标系记忆层叠到 C1/C2/C3 任一之上，都把分钟级连贯抬到裸基底之上、幅度趋近 PEWM 的 SRC 81.7% vs 63.4% 差距——即该层基底无关、非定制；（ii）几何（MosaicMem）＋情景（Chameleon）记忆在 RoboMemArena 上*叠加*（合并 > 任一单独，于 68.9% 需历史子任务上），因二者治不同失效模式——皆无单篇论文证过。
- **具体研究问题**：
  1. H1 — 一份世界坐标系记忆层跨 C1/C2/C3 基底通用：把单一世界坐标系记忆机制叠到 C1 占据、C2 点图、C3 潜在四维上，各把分钟级连贯抬到裸基底之上、幅度趋近 PEWM 的 SRC 81.7% vs 63.4% 差距——即基底无关，而非 PEWM/MosaicMem 那种按模型定制的记忆。
  2. H2 — 情景事件＋几何记忆在动作条件任务上叠加：把 Chameleon 可索引事件与 MosaicMem 几何一致图块结合，在 RoboMemArena 上胜任一单独——把 Long-Term Spatial Memory WM 的相机视频叠加扩到动作条件需历史任务，消歧*事件*＋持久*几何*治不同失效模式。
  3. H3 — 叠加优势集中在感知混淆＋视野外子任务：按子任务类型拆解，情景＋几何相对仅几何的优势在感知混淆/遮挡子任务上最大（事件消歧）、在纯重访子任务上 ≈0（仅几何即够）。
  4. H4 — 世界坐标系记忆比机器人坐标系更保连贯：钉在持久*世界坐标系*的几何记忆（PEWM 动作→相机位姿检索、MosaicMem 抬升三维图块）比机器人坐标系更保长程连贯——把记忆与身体位姿解耦减少漂移。
  5. H5 — 基底无关层在等连贯下比定制记忆更省：单一共享 C4 层在三基底上达 PEWM 级连贯，其总参数/内存占用低于三套定制记忆（PEWM＋占据记忆＋点图记忆分别建），对照 DexWorldModel 的 O(1) TTT 预算。
- **风险**：
  - 显式几何记忆需要可靠的三维抬升——现成估计器在纹理贫乏的场景会失败（MosaicMem）。→ 与隐式注意力混合（MosaicMem 自身的设计），让模型在抬升含噪时优雅降级。
  - 情景记忆检索会在视觉相似但无关的事件上产生干扰（Chameleon）。→ 用消歧的可索引编码加目标导向检索，而非仅靠相似度检索，并在 RoboMemArena 的遮挡/计数切分上验证。
  - 记忆增加占用，与实时部署预算冲突。→ H5 的「图块级 vs DexWorldModel O(1) TTT」帕累托是是否门槛；持久记忆只有在连贯增益胜过内存代价时才划算。

## Cluster D — 面向具身感知的重建（Reconstruction for Embodied Perception）
### D1 — 交互就绪的场景重建：可在其中行动的整个环境
- **论点**：具身智能体作用的是整个重建环境的*场景级交互就绪性*（几何有效性、物理参数化、运动学可执行性）而非外观。从单视频烘焙仿真就绪孪生的做法*已很拥挤*（HoloScene 把物理烤进重建、并把就绪-vs-保真当作消融副产物报出，Video2Game 单视频 → 100+ FPS）；没人做的是*受控的逐项就绪-vs-保真测量*、以及从单视频恢复*铰接*就绪（HoloScene 点名的未来工作）。*单物体*物理资产生成是 D2 的领地。
- **第一性原理框架**：
  - *第一性原理*：具身智能体交互的对象是几何、物理、运动学，而非辐射；重建的具身价值在于其*交互就绪性*（能否碰撞、抓取、铰接），这一属性与视觉保真正交，且不由后者蕴含。
  - *挑战的假设*：「更高保真即更好资产」*已被记录为假*——HoloScene 的消融报出「场景级重建与实例级物理稳定性之间的权衡」，Single-View Mesh for Robotics 显示赢了 CV 基准的单视重建却差 2 mm 机器人门槛（约 5 mm–1 cm Chamfer、约 50% 抓取迁移）。正交性*已存在*；D1 现攻的开放假设是「让一个*联合目标*把它当副作用浮现（HoloScene）就够」——而没人做过*受控*逐项测量、也没人从单视频恢复*铰接*就绪。
  - *下的赌注*：交付的是 HoloScene 联合目标所略的*受控测量*与*铰接*就绪——（i）同一场景分别按 (a) PSNR 与 (b) 综述四项就绪标准建，保真最优资产可测地更频繁漏掉 ≥1 项、逐项报通过/失败（HoloScene 仅作消融副产物浮现的受控隔离）；（ii）单视频重建可靠恢复刚体分解、却失于铰接结构（关节/自由度）的 URDF/MJCF 导出，除非有多视角或交互数据——HoloScene 点名却未跨过的刚体天花板。
- **具体研究问题**：
  1. H1 — 保真最优场景更频繁漏就绪标准（受控、超出 HoloScene 副产物）：同一场景分别按 (a) PSNR 与 (b) 综述四项就绪标准建，保真最优资产可观地更频繁漏掉 ≥1 项——HoloScene 仅作 Table-3 权衡消融浮现、Single-View Mesh 仅作单侧探针所示的受控逐项隔离。
  2. H2 — 单视频恢复刚体但不恢复铰接（HoloScene 点名的天花板）：Video2Game/HoloScene 式单视频重建可靠恢复刚体实体分解、却失于铰接结构（关节、自由度）的 URDF/MJCF 导出，除非有多视角或交互数据——可由把 URDF-Anything+ / iTACO / VideoArtGS 铰接路径接进场景管线来闭合。
  3. H3 — 物理参数存在低于仿真精确保真的就绪阈值：在重建资产中训练的策略，一旦物理参数（质量、摩擦、恢复系数）越过远低于仿真精确保真的*充分性*阈值即可正确作用——就绪是阈值而非保真竞赛。
  4. H4 — 就绪资产端到端喂给 A1 与 C1：D1 交互就绪资产直接喂 A1 点云头（作用于几何）与 C1 占据世界模型（在几何上推演），D→A 与 D→C 链匹配手工资产基线。
  5. H5 — 仿真器格式输出在就绪上胜事后网格化：TriSplat 前馈仿真器格式网格在运动学可执行性＋格式兼容标准上比事后网格化保真优化的 3DGS 更可靠（且快得多）。
- **风险**：
  - 交互就绪缺乏标准基准——就绪是一份清单而非一个排行榜数字。→ 采用综述四项标准作为显式记分卡（H1），逐项报告通过/失败，而非单一保真数字。
  - 单视频可能无法恢复复杂场景的铰接/物理。→ 用 H2 圈定单视频重建能恢复的范围；需要铰接时回退到多视角或交互数据，并陈述边界。
  - 与 Sim2Real-A1/B1 的边界模糊。→ 把 D1 钉死在*以就绪为优化目标*（H1、H3）上，并显式把*迁移差距评测*路由给 GS-Playground / Real-to-Sim GS。

### D2 — 物体级物理资产生成：单个物体自带其物理
- **论点**：交互环境可复用的单元是*物体*而非场景——而一个物体只有自带材质、质量与运动学结构（而非仅一张水密网格）才对具身有用。赌注原本要*建*的统一生成器＋记分卡*已经建好*（锚点 PhysX-Omni 即为统一刚性＋可形变＋铰接生成、出 PhysX-Bench；SOPHY 已跑了 D2 自己的联合-vs-几何优先消融）；没人做的是*同物体匹配的联合-vs-分阶段对决*、逐类别在一张记分卡上（PhysX-Omni 运动学 0.92；NeuROK Chamfer-L1 0.028，未见类别能量守恒）。
- **第一性原理框架**：
  - *第一性原理*：物体的具身价值是一个*联合体*（几何、材质、运动学）——物理不是可分离的事后标签，而是几何必须与之*一致地*生成的属性（网格及其质量/摩擦/关节共同决定它在接触下如何表现）；把二者拆开就丢掉了单遍生成本可强制的一致性。
  - *挑战的假设*：几何优先惯例（NeRF/3DGS-再标注）*已被推翻*——PhysX-Omni、SOPHY、UniArt 各在同一遍生成物理-带-几何并泛化到未见类别，故「建统一生成器」已成定局。D2 现攻的开放假设是：证明统一生成器*存在*并不等于证明联合 > 分阶段——因为没人跑过*同物体匹配对照*，也没人测过能量/动量一致性（而非保真）是否预测*跨类别*就绪。
  - *下的赌注*：没人统一跑过的受控证伪决定一切，而非 PhysX-Omni 已建的生成器——（i）对*同一*匹配物体集 (a) 几何优先再标注 vs (b) PhysX-Omni 式统一头联合生成，分阶段管线可观地更频繁漏掉运动学/材质就绪标准，逐类别分解、优势集中在可形变＋铰接（刚性上 ≈0，如 SOPHY 跳过刚性已暗示）；（ii）物理一致性指标（能量/动量，NeuROK 式，Chamfer-L1 ≤0.028）比保真（PSNR/Chamfer）更能预测跨类别就绪。
- **具体研究问题**：
  1. H1 — 联合生成通过分阶段失败的运动学/材质标准（把 SOPHY 的可形变结果扩到跨类别）：对同物体匹配集 (a) 几何优先再标注 vs (b) PhysX-Omni 式统一头联合生成，分阶段可观地更频繁漏掉就绪标准——SOPHY 已在*可形变*上证之（材质 +>20%、Sim-CD 5×），开放测试是它在刚性＋可形变＋铰接*一张记分卡上*是否成立。
  2. H2 — 联合生成优势集中在可形变＋铰接（SOPHY 跳过刚性、明说出来）：按类别拆解就绪，联合生成优势在刚性道具上 ≈0（一块网格近乎够用，故 SOPHY *跳过*刚性）、集中在可形变＋铰接，如第一性原理所测。
  3. H3 — 能量守恒比保真更预测跨类别就绪：生成时施加物理一致性约束（能量、动量、GausSim 质量守恒）比保真（PSNR/Chamfer）更预测跨类别就绪，呼应 NeuROK 的能量守恒泛化。
  4. H4 — 生成物体经材质*或*运动学迁移到仿真训练策略：把 D2 物理-联合生成物体放进 D1 场景，仿真训练策略可正确作用，且绑定约束可辨识为逐物体材质保真（质量/摩擦）*或*运动学结构——而非二者均等。
  5. H5 — 可形变就绪是最宽缺口、单遍最大胜场：在综述点名的可形变缺口上，联合生成器（PhysHanDI 式可形变孪生）补上的就绪缺口多于任何分阶段管线，且可形变是分阶段失败最惨之处。
- **风险**：
  - 逐物体就绪在各类别间无共享排行榜——PhysX-Bench 偏刚性/铰接，PhysTwin/PhysHanDI 专攻可形变。→ 采用综述四项标准作为共同记分卡（H1），按类别（刚性/可形变/铰接）逐项报告通过/失败，而非单一聚合分。
  - 从单视频/稀疏 RGB-D 推得的物理参数可能欠定（仅凭运动学观测不到质量/摩擦）。→ 用 H3 的物理一致性约束（能量/动量）正则化欠定参数，并把声明限定在约束能辨识它们之处。
  - 与 D1 的边界在「物体」与「场景」相互渗透时变模糊。→ 把 D2 钉死在*单物体*生成单元（H2、H4）、D1 钉在*整场景*环境；一个 D2 物体*填充*进 D1 场景是预期的组合（H4），而非重叠。
