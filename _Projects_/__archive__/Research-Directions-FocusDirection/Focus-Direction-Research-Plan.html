CAWM: aims, falsifiers, staging, gates

the bet A World-Action Model whose latent explicitly and anticipatorily predicts the reaction wrench of whole-body motion (self-induced inertial reaction + external contact wrench), so the policy plans against a sensor-free coupling forecast instead of treating the three couplings as implicit residual. Trained dense, deployed latent, grounded by differentiable system-ID, verified by a causal-consistency metric. Working name CAWM.
first principles (the program bet) - §2

First principle: the generalized mass matrix is non-block-diagonal, so every whole-body motion transmits a low-dimensional, structured cross-term (reaction wrench, or kinematic feasibility constraint) between arm, base, legs - the cross-term is a quantity to predict, not data to collect.

Assumption challenged: the field decouples whole-body control into an arm controller plus a balance controller, leaving the coupling implicit or reactive.

Bet: making each coupling explicit, anticipatory, grounded, and a verified world-model output beats far larger data and compute on a fixed budget, gain concentrated where the cross-term is largest; falsifies cheaply via the ε-curve.

Real-robot deployment target: G1/H1. Mechanism depth is not uniform across the three coupling channels - A is deepest (own reactive-observer + analytic-residual baselines), C rides A's shared wrench head, B is a thinner factoring-only claim with no reactive-observer comparator.

Background and related work (§3)

click to expand - ~10 more papers this program is positioned against, one line each
Field context: reactive force-under-load, WAM imagination, differentiable sysID

For force-under-load, the field is reactive:

  • GentleHumanoid and Unified-Force-Position-Control get compliance via learned impedance.
  • UAN supplies a high-load actuator model (113N cart, 8kg lift).
  • HEFT handles heavy payload (24kg) via a windowed curriculum - all estimate-then-compensate from the past, except IMPACT, which predicts the arm's external wrench feedforward from torque residuals sensorlessly but stays one-directional, arm-side.

World-action models imagine scene futures (DINO-WM):

  • JOPAT shows predicting an explicit structured target beats pixels.
  • iKCE shows imagined rollouts stay kinematic, friction-invariant.
  • Differentiable system-ID recovers object physics (D-REX, gradSim).
  • structure-preserving sysID keeps recovered dynamics physically consistent (Physics-Aware-Sparse-EL, CaLiSym) - yet still targets object or generic systems, not the robot's own inertia.

Closest force-WAM FAWAM already forecasts end-effector wrenches jointly with actions, corrects on force residual, but is sensor-bound and single-arm.

No prior work makes either cross-term an explicit, anticipatory world-model output in one coupled humanoid policy.

Architecture (§5)

train dense, deploy latent - the dense teacher (red, dashed) is train-time only, dropped at deploy
The cross-term (Problem)
  • δbase = Mbase,arm(q) q̈arm + Cbase,arm(q, q̇) q̇arm (self-induced, channel A)
  • δbaseext = Jext⊤(q) Fext (external, channel C)
predicted anticipatorily from commanded q̈arm / estimated Fext, before either perturbs the base. The formal statement the architecture below implements.
green = shared wrench head + action head · red dashed = train-only, dropped at deploy
Coupling-conditioned latent - carries proprioception + commanded arm acceleration, not just scene appearance; an auxiliary reconstruction loss stops it collapsing to a proprioception-only regressor.
Shared wrench-imagination head - predicts both self-induced reaction delta_base (A) and external-wrench reaction J_ext^T F_ext (C) as a (6+n_leg)-vector per contact mode plus a mode classifier; A and C share this output head but differ in prediction problem.
Autoregressive action head - base-to-torso-to-arm factoring, forked from brs-algo (WB-VIMA, whole_body_decoding_order) and AC-DiT.
Dense teacher head - video/3DGS, train-only, dropped at deploy.

Risks (§9)

Explicit ≈ implicit — the three-way ablation + ε-sweep is still a definitive result per channel, even when the bet is void.
Wrong / unidentifiable inertia or contact model — gate Phase 2 on PR-0b; fall back to an analytic term + broad domain-randomization for the affected channel.
Hardware-dominant physics — instrument the residual budget first (PR-0a'); scope down if the base reaction is dominated by foot-contact / support-polygon transition (H8).
Engine floor error, not just a wrong model — GAUGE: physics engines given ground-truth-calibrated parameters still show order-of-magnitude errors on dynamic contact/deformation. Sharpens H8: its worst regime is exactly GAUGE's worst regime.
Base↔arm factoring buys little, or costs latency (B) — report B's margin stratified by reach-extension vs. fixed-base, not pooled; parallelize/distill the decode if latency bites.
WAM too slow for contact — async decoupling + quantization clear a 30 Hz floor; report the SR-vs-Hz Pareto honestly.
Force-under-load first-100ms hostage to composed loop latency (C) — price the whole onboard budget; if it eats the window, move C's headline to a steady-state max-load number.
External wrench unidentifiable, or implicit already suffices (C) — that is the C falsifier itself; fall back to the reactive/curriculum baseline, report the definitive ablation either way.
