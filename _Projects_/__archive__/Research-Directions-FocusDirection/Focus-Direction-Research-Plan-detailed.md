# Focus-Direction Research Plan: A Coupling-Aware World-Action Model (CAWM)

## 1. Abstract

> [!abstract] Contribution and program, one paragraph
> Target: conference contribution — **World-Action Model whose latent explicitly imagines reaction wrench of whole-body motion** (*self-induced* inertial reaction + *external* contact wrench). Humanoid policy plans against sensor-free *coupling forecast* instead of treating arm to leg, base to arm, force-under-load coupling as implicit residual. Model **trained dense, deployed latent** (real-time on G1/H1 humanoid), **grounded** by differentiable system-ID so imagined physics real, **verified** by causal-consistency metric binding predicted coupling to measured coupling. Working name **CAWM**. Thesis commits to **three** humanoid coupling channels — arm↔leg (inertial), base↔arm (kinematic), force-under-load (external wrench) — so coupling lift measured *first* on **balance / disturbance rejection** (direct test of arm→leg reaction prediction), **mobile-manipulation** (base↔arm anchor), **force-under-load / OOD-payload** (external-wrench anchor); remaining evaluation axes = **generality / robustness checks** that coupling term transfers across task families, not co-equal contributions. Two **force** channels (arm↔leg self-induced, force-under-load external) = two **dominant** force-transmission pathways; share one **output** wrench head (legs compensate) but solve **different prediction problems** (A computable from commanded $\ddot q_{\text{arm}}$ + inertia, C's exogenous wrench anticipated from context/load/contact); kinematic channel (base↔arm) factors action. Gravity/CoM folded into grounded model; arm-velocity-induced Coriolis cross-term predicted inside channel A (not separate channel). This document one plan: method (problem through experiments), then staged program producing it, reducing [[Focus-Direction]]'s six clusters to one executable bet. Scope (per project decisions): **full six-cluster program, staged parallelism** — de-risked core leads, three cross-cluster seams = named research contribution; **real humanoid available** (grounding near-term); **well-resourced lab**. Staging **not** five unconditional parallel tracks: **three cluster falsifiers = co-equal go/no-go gates**, each downstream build commits only after cluster(s) it serves pass — shared wrench head on WB.A + WB.C gates, autoregressive action head on WB.B gate, real grounding on force-cluster gates it serves. Verify track + three cheap cluster falsifiers (one per coupling cluster, Phase 1A/1B/1C) start at M0; everything downstream of gates conditional. All three clusters get co-equal falsifiers, none is master gate. Companions: [[Focus-Direction]] (thesis), [[Focus-Direction-Brief]] (one-page canvas pitch of full program), [[Focus-Direction-Paper-Code-Index]] (papers to code), [[Focus-Direction-Review]] (adversarial review absorbed here).

## 2. Introduction and motivation

> [!tip] First principles (program bet)
> - **First principle:** generalized mass matrix non-block-diagonal, so every whole-body motion transmits low-dimensional, structured cross-term (reaction wrench, or kinematic feasibility constraint) between arm, base, legs; cross-term = quantity to predict, not data to collect.
> - **Assumption challenged:** field decouples whole-body control into arm controller + balance controller, leaves coupling implicit or reactive.
> - **Bet:** explicit, anticipatory, grounded, verified world-model coupling output beats far larger data + compute on fixed budget, gain concentrated where cross-term largest, falsifies cheaply via epsilon-curve.

Whole-body humanoid control conventionally **decoupled**: arm/manipulation controller + balance/locomotion controller, physical coupling implicit. But generalized mass matrix non-block-diagonal, so fast arm reach **is** base/leg balance disturbance (channel **A**, self-induced), and *external* hand wrench propagates through $J_{\text{ext}}^{\top}$ to support legs (channel **C**, external) — force adaptation under load = whole-body equilibrium problem, not arm problem; discarding cross-terms makes whole-body policies brittle on aggressive motion, under load. Opportunity: each cross-term **low-dimensional, structured** — quantity to *predict*, not data to collect — predicted **anticipatorily** (from commanded arm motion for self-induced reaction, from estimate of unknown external wrench for force-under-load, before base perturbed). Two force channels (two **dominant** force-transmission pathways) share one **output** wrench head, different prediction problems (A computable from commanded $\ddot q_{\text{arm}}$, C anticipated from exogenous context/load/contact); kinematic channel (base↔arm, **B**) factors action; gravity/CoM folded into grounded model; arm-velocity-induced Coriolis cross-term predicted inside channel A (not separate channel). Plan tests: explicit prediction, carried on WAM trained dense / deployed latent, grounded by differentiable system-ID, verified by causal-consistency metric — beats implicit-coupling and reactive-observer baselines on fixed data + compute budget. Gap targeted + fixed premises (literature facts) below.

## 3. Background and related work

> [!abstract] Where CAWM sits across five literatures
> Contribution not in any single area — at intersection: takes *explicit reaction term* whole-body field leaves implicit, makes it *world-model output* WAM field has not targeted, *grounds* it with differentiable-sysID machinery, *certifies* it with metric WAM-evaluation field lacks.

**Whole-body loco-manipulation.** Field defaults to *decoupling*: arm controller + balance controller, coupling implicit ([[2604.07993|HEX]]'s predictive MoE), emergent ([[2505.06776|FALCON]]'s shared observation), or one-directional ([[2509.21231|SEEC]], base→arm only). Analytic-residual approaches add model term reactively ([[2504.06662|RAMBO]], [[2507.04140|Centroidal-Arm-Motion]]); [[2502.03206|HugWBC]] estimates privileged state; [[2606.16542|ADAPT]] feeds momentum-observed disturbance as observation; [[2512.11047|WholeBodyVLA]] splits loco/manip latents. Single closest *anticipatory* prior art: [[2201.03871|ALMA]] (legged mobile manipulator): whole-body MPC manipulation controller outputs **predicted external-wrench sequence** fed as **anticipatory observation** to *separate* RL locomotion policy — base proactively compensates manipulator disturbance. ALMA = sharpest neighbor, one this graph surfaces (its "anticipatory predicted-wrench observations" node), distinction must be explicit — see novelty-positioning table: ALMA = **decoupled two-controller handoff** (exact architecture CAWM argues against), predicts **self-induced applied arm wrench** (force its own manipulation exerts, from model-based MPC — not unknown external load, not **self-induced inertial cross-term** $M_{\text{base,arm}}\ddot q_{\text{arm}}$ as *learned* output), **not world-action model**, **no $\varepsilon$-curve de-circularization, no robot-self sysID grounding, no causal-consistency metric**. Benchmark: [[2403.10506|HumanoidBench]]. **Force-under-load** = external-force twin: humanoid field handles *reactively* — torque-limit-aware force curriculum ([[2505.06776|FALCON]]), force-augmented reward ([[2510.26280|Thor]], 167.7 N pull), history-estimated load context ([[2606.03297|SplitAdapter]], 6 kg OOD), learned impedance ([[2511.04679|GentleHumanoid]], [[2505.20829|Unified-Force-Position-Control]]), high-load actuator model ([[2502.10894|UAN]], 113 N cart / 8 kg lift); [[2606.13232|WT-UMI]] adds directly-sensed tactile force with admittance; ADAPT's momentum observer = reactive external-wrench estimate. All *estimate-then-compensate from past*; ALMA alone anticipates, but only self-induced known wrench on quadruped. *CAWM* makes self-induced arm→leg cross-term **and unknown external wrench** explicit, anticipatory, *imagined* prediction inside one coupled humanoid policy (two force channels share one head), ablates against exactly these implicit / observer / decoupled-anticipatory / reactive-impedance baselines.

**World(-action) models for manipulation.** Latent-dynamics WMs ([[2411.04983|DINO-WM]], [[2603.14482|V-JEPA-2.1]], [[2602.10098|VLA-JEPA]]), video-prediction policies ([[2412.14803|VPP]], [[2412.15109|Seer]], [[2505.11528|LaDi-WM]]), unified video+action models with drop-heads ([[2504.02792|UWM]], [[2503.00200|UVA]], [[2605.20752|GaussianDream]]) all imagine *scene* futures. Two recent results sharpen predict bet: [[2605.23856|JOPAT]] — WAM predicting explicit *structured* target (2D point tracks + visibility) beats pixel prediction; [[2607.08436|EgoWAM]] — auxiliary, train-dense / deploy-action-only world-model head robustly beats plain behavior cloning (representation choice matters). *CAWM*'s imagined output = *physics quantity* (reaction wrench), latent conditioned on commanded acceleration, not just appearance.

**Sim-to-real and differentiable system-ID.** Differentiable physics recovers *object* parameters ([[2104.02646|gradSim]], [[2603.01151|D-REX]], [[2504.16693|PIN-WM]], [[2503.17973|PhysTwin]]), learns constitutive laws ([[2304.14369|NCLaw]]), explores to identify ([[2404.12308|ASID]]); twins close real→sim→real loops ([[2504.03597|Real-is-Sim]]). Model-free foils skip physics model: few-shot humanoid dynamics adaptation ([[2606.28476|FADA]], LoRA on factored inverse-dynamics model), shaping actuator reality to fixed model ([[2607.02205|Actuator Reality Shaping]], zero-shot 22-DoF humanoid via control-theoretic actuator interface). Structure-preserving sysID keeps recovered dynamics physically consistent: [[2606.09640|Physics-Aware-Sparse-EL]] fits Euler-Lagrange residual holding inertia SPD + Coriolis term consistent (ground anchor for robot's own $M_{\text{base,arm}}$ + Coriolis cross-term, where D-REX and NCLaw recover only object physics); [[2607.06824|CaLiSym]] enforces symplectic actuation/contact ports, cuts OOD drift on coupled double-pendulum + real quadruped, but recovers no interpretable coupling inertia. *CAWM* re-points per-link sysID loop at *robot's own* inertia $M_{\text{base,arm}}$ (Seam 2) — target none of these address.

**World-model evaluation and runtime verification.** Reproducible WM harnesses ([[2605.21800|stable-worldmodel]]), visual-realism sim-real correlation ([[2605.06311|VISER]], $r{=}0.92$), executability-vs-plausibility ([[2604.19092|RoboWM-Bench]], [[2602.08971|WorldArena]]), self-consistency ([[2606.18610|SC3-Eval]]), asymmetry verifiers ([[2604.01985|WAV]]), failure diagnosis ([[2505.12224|RoboFAC]]), dynamics-realism diagnostics ([[2607.05966|iKCE]] — strong latent WM imagines *kinematically*, stays statistically invariant to friction: direct evidence generic WAMs dynamics-blind), decision-time inverse-dynamics action-consistency ([[2607.02403|ACID]] binds each predicted transition to recoverable action inside planning — verify build-on beyond SC3-Eval's metric-only use). *CAWM* adds causal-consistency metric binding *predicted to realized coupling* on hardware — no public benchmark measures (Seam 3).

**Efficiency and continual learning.** Real-time levers: distillation ([[2606.05254|Flash-WAM]]), quantization ([[2602.20309|QuantVLA]]), async architectures ([[2606.09811|AHA-WAM]]); forgetting-free continual via importance-weighted regularization + expert-routed PEFT ([[1612.00796|EWC]] Fisher prior, [[2605.06175|VLA-GSE]] generalized/specialized experts). *CAWM* composes these to clear contact-stability floor, protect coupling term across continual updates.

**Aims (one per cluster).**

### Aim WB.A (arm to leg, coupling core)
Improve arm-to-leg coupling direction as whole: make self-induced reaction wrench $\delta_{\text{base}}=M_{\text{base,arm}}\,\ddot q_{\text{arm}}$ explicit, anticipatory **prediction** (computable from commanded arm acceleration + coupling inertia), not something legs discover reactively; show explicit feedforward beats implicit + reactive baselines.

### Aim WB.B (base to arm, coupling core)
Improve base-to-arm coupling direction as whole: factor mobile-manipulation action autoregressively (base to torso to arm) so base becomes **predicted, coupled DoF**, not independently commanded; show coupled factorization beats decoupled base. Channel B = **kinematic** base-to-arm coupling (base velocity itself manipulation DoF). **Dynamic** base-to-arm inertial reaction (transpose term $M_{\text{arm,base}}\ddot q_{\text{base}}$ — fast base acceleration disturbing arm) **scoped out under quasi-static-base assumption** (mobile-manipulation base motion slow relative to arm dynamics), mirroring terrain scope-out; M0 check tests it; if top-quartile base acceleration violates, term folds into shared wrench head as channel-A transpose, not separate channel.

### Aim WB.C (force-under-load, coupling core)
Improve force-under-load coupling direction as whole (force-twin of WB.A): estimate **unknown external** hand wrench, anticipate base/leg reaction $J_{\text{ext}}^{\top}F_{\text{ext}}$ it induces, sharing WB.A's reaction-wrench output head; show anticipatory force handling beats reactive (curriculum / observer / impedance).

### Aim WAM.A (predict, complementary breakthrough)
Improve predictive substrate as whole: carry all three coupling channels on **train-dense / deploy-latent** WAM so coupling available sensor-free at deploy, latent conditioned on dynamics state (proprioception + commanded arm acceleration), not just scene appearance.

### Aim S2R.B (ground, complementary breakthrough)
Improve grounding direction as whole, serving all three coupling clusters: recover robot's own coupling inertia $M_{\text{base,arm}}$ (A) + contact model / $J_{\text{ext}}$ (C) from **real interaction** by differentiable system-ID; ground manipulated-object physics for mobile-manipulation (B) via same engine's native object recovery — each cluster's coupling terms measured, not read off URDF.

### Aim EAI.B (verify, complementary breakthrough)
Improve verification direction as whole: certify **predicted-vs-realized coupling** with causal-consistency metric + three-way error decomposition, computed on existing benchmark harnesses + hardware (no new benchmark built).

## 5. Approach

Method: seven parts, in order — problem formalization, architecture, coupling clusters (co-equal core), mechanism clusters (predict, ground, verify seams), decisive falsifier + de-circularization, training objectives + data pipeline.

### Problem formalization

Part-wise whole-body policy discards term physics has. Generalized mass matrix $M(q)$ non-block-diagonal, so arm acceleration = base/leg balance disturbance:

$$
M(q)\,\ddot q + C(q,\dot q)\,\dot q + g(q) = \tau + J_{\text{ext}}^\top F_{\text{ext}}, \qquad
\delta_{\text{base}} \;=\; M_{\text{base,arm}}(q)\,\ddot q_{\text{arm}} + C_{\text{base,arm}}(q,\dot q)\,\dot q_{\text{arm}}, \qquad
\delta^{\text{ext}}_{\text{base}} \;=\; J_{\text{ext}}^\top(q)\,F_{\text{ext}}
$$

$\delta_{\text{base}}$ **low-dimensional, structured**: 6-vector wrench (or per-contact-mode set) determined by commanded arm acceleration, current arm velocity, corresponding blocks of $M(q)$ + velocity-product (Coriolis) term $C(q,\dot q)\dot q$. Thesis: predict it, not collect data for it; predict *anticipatorily* (from commanded $\ddot q_{\text{arm}}$ + measured $\dot q_{\text{arm}}$, before base perturbed) to beat both implicit mixture + reactive observer, gain concentrated where $\ddot q_{\text{arm}}$ largest. External-wrench reaction $\delta^{\text{ext}}_{\text{base}}=J_{\text{ext}}^{\top}F_{\text{ext}}$ (channel **C**) = force-twin: same low-dimensional structure, same output head, *harder prediction problem* — force source = *unknown external* wrench anticipated from context, load, contact state, not computed from self-induced $\ddot q_{\text{arm}}$; predict whole-body reaction anticipatorily, gain concentrates in first ~100 ms after step load where reactive compensation lags.

> [!info] Precise definition (pin down before coding)
> - **$\ddot q_{\text{arm}}$** = *planned/commanded* arm acceleration, read from action chunk policy about to execute. *Planned* (not measured) acceleration makes prediction **anticipatory** (available before reaction occurs) — wedge over [[2606.16542|ADAPT]]'s reactive observer. Wedge falsifiable on timescales: arm→base reaction rises over arm-acceleration ramp (~1 to few 50 Hz policy steps, ~20 to 60 ms at top-quartile $\ddot q_{\text{arm}}$); momentum observer lags ~one state step + filter delay (one 500 Hz state step = 2 ms + 40 Hz low-pass group delay $\approx$ 4 ms $\approx$ **6 ms** observer-lag at 500 Hz state polling of real-robot stack). Anticipation buys margin **iff** (reaction rise-time + actuation delay) < (observer lag + one policy-step delay); pre-registered numeric form (PR-0a, frozen): **rise-time $\ge$ 31 ms** at top-quartile accel ($=$ ~6 ms observer-lag + 20 ms policy step + 5 ms margin) on both H1 and G1. If observer's next-step estimate already lands inside policy step, A1 has no delta.
> - **$M_{\text{base,arm}}(q)$** = off-diagonal block of generalized mass matrix coupling arm DoF to floating-base + leg DoF. In MuJoCo, full $M(q)$ = `mjData.qM` (sparse) made dense via `mj_fullM`; slice base/leg rows by arm columns (Phase-0 extraction step below). Target $\delta_{\text{base}}^{\star}$ for auxiliary loss = $\tilde M_{\text{base,arm}}\,\ddot q_{\text{arm}} + (C_{\text{base,arm}}\,\dot q_{\text{arm}})$: inertial term from **perturbed** $\tilde M$ (de-circularization protocol) + arm-velocity-induced base-row velocity-product (Coriolis) term. MuJoCo's `qfrc_bias` $= C(q,\dot q)\dot q + g(q)$ includes gravity + **all** base/leg velocity-product terms, so raw bias does **not** isolate $C_{\text{base,arm}}\dot q_{\text{arm}}$: obtain arm-velocity-induced Coriolis cross-term by finite-differencing bias against gravity-only bias `qfrc_bias(q,0)` with only arm joint velocities nonzero (gravity subtracted, base/leg velocity-product terms excluded). Isolation captures arm-velocity-quadratic self-reaction but **drops bilinear arm-velocity $\times$ leg-velocity Coriolis products** — defensible at stance/command instant where leg joint speed low; for dynamic loco-manip regime, **pre-registered switch**: when leg joint speed at prediction instant exceeds frozen threshold, target reverts to **full bias term** (full inertial+Coriolis self-reaction named next), **PR-0a' carries dropped cross-velocity magnitude inside residual budget** — size measured at M0, not assumed negligible. If retained quantity = full bias, named full inertial+Coriolis self-reaction (matching ADAPT's full-residual observer), not Coriolis term. Term retained (not bounded negligible): largest in fast-reach headline stratum $\varepsilon$-curve targets; reactive ADAPT observer estimates full bias term, so omitting mis-matches two arms.
>

Why **world-action model** (not just MLP): target $\delta_{\text{base}}=M_{\text{base,arm}}(q)\,\ddot q_{\text{arm}}+C_{\text{base,arm}}(q,\dot q)\,\dot q_{\text{arm}}$ = instantaneous analytic function of current state (including arm velocity) + commanded arm acceleration, all known at step $t$ — *not* quantity that must roll forward. Wrench head reads *current* coupling-conditioned latent; genuine forecast variant predicts $\delta_{\text{base}}$ along action-chunk horizon by integrating commanded accelerations, not from predicted pixels. Channel C = **stronger** WAM case: target $J_{\text{ext}}^{\top}F_{\text{ext}}$ **not** instantaneous analytic function of robot's own state (wrench exogenous) — must genuinely be anticipated from context, load, contact history, exactly imagination WAM provides. Three humanoid channels: arm to leg ($\delta_{\text{base}}$ from arm reaches, A), force-under-load ($J_{\text{ext}}^{\top}F_{\text{ext}}$ from unknown external wrench, C, sharing A's output head), base to arm (base velocity as manipulation DoF, B); all three falsifiers **co-equal, run in parallel**, A and C share one output head — both leg-compensated wrenches.

Three coupling clusters improve each as whole, co-equally: improving WB.A, WB.B, or WB.C = advancing all its directions together as one whole-body interface. Per-direction recipes below are parts of that single advance.

#### WB.A (arm to leg): improve WB.A1, WB.A2, WB.A3, WB.A4 together

> [!tip] First principles
> - **First principle:** arm motion imposes centroidal-momentum reaction on floating base before legs sense any base disturbance. Coupling causal, feed-forward - not disturbance to reject after the fact.
> - **Assumption challenged:** loco-manip stacks treat base as absorbing arm motion reactively (SEEC light-arm assumption, WholeBodyVLA separate feasibility stage, HiWET reactive base reward).
> - **The bet:** anticipating arm-induced base wrench one horizon ahead cuts base-pose deviation and end-effector acceleration under fast reach-while-walking vs implicit-coupling baseline, no inference-latency cost. Zeroing feed-forward path collapses gain.

Four WB.A directions = coordinated advances at different layers of one whole-body interface where upper-limb intent and lower-body support couple before commands issue, so legs anticipate arm inertial demand, not scramble to absorb after. Distinct layers: WB.A1 anticipates arm-induced base reaction, decoding [[2604.07993|HEX]] forecast arm latents through centroidal-momentum matrix of [[2506.14278|Heavy-Limbs-WBC]] into anticipatory base reaction wrench, closing back-coupling [[2509.21231|SEEC]] assumed away. WB.A4 encodes same coupling at command-vocabulary layer: emits [[2512.11047|WholeBodyVLA]] locomotion latent as residual conditioned on manipulation code ([[2506.13751|LeVERB]]-style), projects pair onto [[2606.18772|HALOMI]] behavior manifold so joint loco-plus-manip latent feasible by construction. WB.A2, WB.A3 secure feasibility once coupled command meets real robot and workspace: WB.A2 freezes [[2506.09366|SkillBlender]] blended hull plus [[2602.06341|HiWET]] world-frame transport as sim-to-real feasibility substrate, repairs only sim-to-real residual via entropy-gated [[2602.08594|MOSAIC]] adapter; WB.A3 schedules HiWET base by following gradient of [[2508.11275|Differentiable-Reachability-Maps]] field, shrinks its margin with measured tracking residuals. WB.A2 and WB.A4 = alternative feasibility substrates cluster evaluates, not single stacked pipeline: WB.A2 SkillBlender-plus-HiWET blended hull and WB.A4 HALOMI behavior manifold ([[2511.04131|BFM-Zero]] latent it projects onto) are different, non-stackable feasibility constructions, so WB.A2 residual cannot literally carry WB.A4 manifold-decoded latent. Each recipe targets layer next presumes: anticipate wrench (WB.A1), couple into command vocabulary as feasible-by-construction latent (WB.A4), secure sim-to-real feasibility (WB.A2), secure workspace feasibility by reachability-aware transport (WB.A3). Cluster advances one whole-body interface at four layers, not four point fixes.

##### WB.A1: CoReWA (Coupled Reaction-Wrench Anticipation): centroidal-momentum forecast bridging a whole-body VLA and its loco-controller

**Build on** [[2604.07993|HEX]] + [[2509.21231|SEEC]] + [[2506.14278|Heavy-Limbs-WBC]]. Turn HEX predicted future arm latents into explicit anticipatory base reaction wrench via centroidal-momentum matrix, inject into action-fusion gate and low-level controller.

1. Keep HEX as high-level whole-body VLA: inputs language tokens L, visual tokens V_t, history query token Q_t, part-slot proprioceptive state. HEX Unified Proprioceptive Predictor (UPP) already forecasts future proprio latents of all parts jointly over horizon tau_p: coupled short-horizon rollout of where arms will be.
2. Add Reaction-Wrench head on UPP: decode predicted future arm/hand latents into joint positions, velocities, accelerations via small MLP mirroring HEX state-decoder, push through centroidal-momentum matrix A(q) from Heavy-Limbs WBC, map through floating-base dynamics to anticipated base reaction wrench W_hat_b = [F_hat_b; T_hat_b]. Explicit arm-to-base inertial term closing SEEC Assumption 1 (negligible back-coupling).
3. Extend HEX dual cross-attention gate with anticipated wrench as third conditioning stream H^w (learned embedding of W_hat_b): g_t = sigma(W_g[H^vl; H^p; H^w; X_t]), residual injection F_t = H^vl + g_t * (H^p + H^w). VLA pre-shapes arm trajectory to keep anticipated base wrench inside balance-feasible envelope.
4. Feed same W_hat_b forward to low-level whole-body controller. RL instantiation: append to observation, add SEEC torque-imitation so legs pre-load before arm moves. Model-based instantiation: inject as known external disturbance into Heavy-Limbs HQP, preserve priority order (physical consistency, limb tracking, base tracking, contact force) so anticipation never overrides feasibility.
5. Train with total loss L = L_a + alpha L_s + beta L_w + gamma L_mom: L_a HEX flow-matching action loss, L_s its state-prediction loss, L_w SEEC torque-imitation generalized whole-body, tau_comp uses anticipated not instantaneous wrench, L_mom momentum-consistency ||A(q) qdot_pred - h_measured|| supervising head against realized centroidal momentum.
6. Pretrain HEX on its 12M+ humanoid frames unchanged. In sim: attach SEEC perturbation generator plus scripted aggressive reaches so head sees full arm-base interaction, train controller and head against realized momentum and measured torque, co-finetune VLA gate with wrench stream on task demos. Deploy: UPP forecasts latents, head emits W_hat_b one horizon ahead, gate pre-shapes, controller pre-stabilizes. Controller swappable: wrench comes from A(q), not black-box coupling.

- *Why it beats each:* HEX captures arm-leg coupling only implicitly in latent, emits to black-box controller, no explicit reaction term, so fast reach hands legs disturbance discovered late; CoReWA makes coupling explicit physics-grounded wrench forecast feeding policy and stabilizer, controller-agnostic. SEEC assumes away arm-to-base back-coupling, no high-level manipulation or VLA policy, only stabilization-oriented end-effector tracker; CoReWA inverts causal direction, forecasts arm reaction wrench on base, pre-loads legs, inherits SEEC distillation robustness. Heavy-Limbs WBC has momentum coupling and priority order but purely reactive, no manipulation policy or forecasting; CoReWA reuses its momentum matrix and HQP as physics core, drives with learned one-horizon-ahead VLA wrench forecast.
- *Falsifier:* Sim, heavy-limbed humanoid: ablate feed-forward path by zeroing W_hat_b into controller while keeping it in gate (and vice versa) during fast lateral reach-while-walking. If base-pose deviation and end-effector acceleration statistically indistinguishable from implicit-coupling HEX baseline, explicit anticipatory term adds nothing, method dead.
- *Benchmark:* Humanoid loco-manipulation, heavy-limbed bipedal platform (Booster T1 as in SEEC, Orca I as in Heavy-Limbs WBC): spill-free carry, mean/max end-effector linear and angular acceleration while walking, HEX whole-body manipulation suite (in-distribution and unseen-scene-variation success), base-pose deviation under scripted aggressive reaches.
- *Risk:* Forecast quality bounded by UPP arm-latent accuracy. Short tau_p or noisy latent forecast: anticipated wrench lags or mispredicts. High gait frequency: one-horizon lead may be too small to pre-load usefully, collapses toward SEEC-style reactive compensation. Sim-to-real of A(q)-derived wrench inherits Heavy-Limbs WBC modeling assumptions (drops contact-wrench-consistency constraints for real-time), so unmodeled friction or motor delay degrades feed-forward benefit.

##### WB.A2: BlendBridge: Sim-to-Real Whole-Body Loco-Manipulation by Entropy-Gated Residual-Adapting a Frozen Per-Joint Skill Blend

**Build on** [[2506.09366|SkillBlender]] + [[2602.08594|MOSAIC]] + [[2602.06341|HiWET]]. Treat SkillBlender per-joint softmax blend of frozen primitives as frozen feasibility substrate, close sim-only gap with zero-initialized per-joint residual adapter whose authority gated by blend per-joint softmax entropy.

1. Take SkillBlender N frozen goal-conditioned whole-body primitives (Walking, Reaching, Squatting, Stepping). High-level policy emits per-skill subgoals and raw per-joint weights, per-joint softmax-over-skills produces W_t^i, Hadamard-weighted sum a_blend_t = frozen feasibility substrate.
2. Stage 1: train blend in sim, PPO, 1 to 2 task rewards. Pretrain HiWET frozen Kinematic Manifold Prior on constrained-IK samples mapping bimanual end-effector targets to consistent upper-body reference. Partition upper-body authority to KMP path: set Reaching primitive upper-body raw weights large-negative so softmax drives them to zero, kills two-prior conflict. Add HiWET world-frame command policy emitting base-velocity, height, base-relative end-effector subgoals to actively transport base beyond static reach. Freeze everything.
3. Stage 2: slot trainable per-joint residual actor in same joint-target space, zero-bias near-zero-gain last layer so frozen blend dominates early. Deployed action a_deploy_t = a_blend_t + g(W_t) Hadamard Delta_a_t, g = novel per-joint authority gate.
4. Gate = explicit function of blend normalized per-joint entropy H_m = -(1/log N) sum_i p_m,i log(p_m,i + eps): g(W_t)[m] = g_min + (1 - g_min)(1 - H_m)^beta, strictly-positive floor g_min (e.g. 0.3), sharpness beta >= 1 (e.g. 2). Residual gets near-full authority where one skill dominates joint, damped where skills co-active. g computed no-grad: gradients flow only into residual.
5. Deploy: observation = proprioception, last action, world-frame command. Frozen path computes a_blend_t and g(W_t) no-grad, residual computes Delta_a_t, gated additive composition feeds PD torques tau = Kp(q_des - q) + Kd(qdot_des - qdot) at 50 Hz on Unitree humanoid.
6. Train only residual on ~30 minutes hardware data via MOSAIC dual-teacher behavior cloning (adaptation teacher on hardware transitions, frozen blend on general transitions), plus KMP-tracking reward pulling corrected upper body toward frozen manifold, plus L2 penalty on off-hull residual magnitude. Residual stays correction, not second policy.

- *Why it beats each:* SkillBlender blend sim-only, never shown on hardware; entropy-gated residual plus dual-teacher BC carries it across interface gap without retraining primitives. MOSAIC adapts one monolithic tracker with flat residual, no feasible composition or base transport; residual riding per-joint frozen blend gives feasibility-by-construction plus principled per-joint authority map MOSAIC lacks. HiWET caps repertoire to one IK manifold; keeping its KMP and world-frame command policy but swapping single controller for blendable primitive library lets same machinery compose squat, step, reach, walk per task, upper-body redundancy resolved by partition.
- *Falsifier:* Three real-hardware ablations, one per coupling claim. Gate: full BlendBridge vs constant-gate residual, same frozen blend, same 30 min data; entropy gate statistically indistinguishable on feasibility and task error means it collapses to MOSAIC-on-a-blend. Active-base: disabling base transport not shrinking reachable workspace or far-target success means commander adds nothing. Library: swapping blend for HiWET single IK-residual leaving squat/step feasibility unchanged means library buys nothing. Any one null kills its third.
- *Benchmark:* SkillBench (8 loco-manip tasks, Unitree H1/G1/H1-2) for sim feasibility metrics (Tilt/RootHeight/Torque/Power) plus new real-robot transfer protocol on Unitree G1. Cross-check sim world-frame hand error against HiWET 12.4 mm, reproduce its 25.2 mm no-KMP number in KMP-removal ablation.
- *Risk:* Entropy gate may encode blend confidence (which skill owns joint), not dynamic feasibility margin, so even with positive floor could under-authorize residual on exactly the coordination joints (waist/hip in loaded reach) where correction most needed; optimal g_min near 1 means entropy structure adds no value. Separately, arm-leg coupling at foot-contact transitions may be contact-wrench-dominated, invisible to kinematic KMP and joint-target residual, capping real-world hand precision.

##### WB.A3: ReachSched-WBT (Reachability-Scheduled Base Transport for World-Frame Loco-Manipulation)

**Build on** [[2602.06341|HiWET]] + [[2508.11275|Differentiable-Reachability-Maps]]. World-frame EE commander schedules base by following learned reachability field auto-diff gradient, screens each base placement before commitment, feeds tracking residual back as learned shrink on field margin.

1. Keep HiWET interface untouched: Commander consumes high-level state (Tracker state, world base pose, world L/R EE targets, active-arm mask), outputs HiWET exact structured command (base velocity, body height, base-frame EE subgoals, waist-engagement weight alpha) into frozen Stage-1 hybrid-action Tracker (KMP upper-body residual + absolute lower-body joint targets). Only HOW base velocity and EE subgoals computed changes.
2. Pretrain DRM-style continuous scalar reachability field f_R >= 0 (simultaneous-reachability formulation) on SAME PyRoki/IK feasibility data HiWET curated for its Kinematic Manifold Prior, using DRM NN realization for SE(3) inputs. Base-scheduling gradient df_R/d(base pose) by auto-diff backprop through trained net; deliberately not claiming DRM analytic RBF-SVM gradient.
3. Replace HiWET reward-only base term with reachability-shaped scheduling: each step follow auto-diff gradient to bias base velocity toward placements raising minimum reachability margin across active arms; screen chosen subgoals by requiring f_R(subgoal) >= m_eff (effective margin, step 4). Dense gradient also accelerates HiWET spatial curriculum.
4. Close certificate-to-dynamics gap with learned conservative margin: treat f_R as quasi-static kinematic screen, not dynamic certificate. Learn dynamic shortfall via m_eff(alpha, base speed, body-state) = m_0 + g_phi(...), g_phi >= 0 small head fit on Stage-2 logs of (f_R value, alpha, speed, gait-phase) vs actual tracking success. Screen tightens only where motion erodes reach, stays near zero in quasi-static regime.
5. Losses: DRM head pretrained with softplus binary-classification loss then frozen (mirrors frozen KMP); g_phi trained by logistic/pinball calibration loss on achieved-success logs; Tracker = HiWET PPO with asymmetric actor-critic plus CNN state-estimator MSE auxiliary, unchanged; Commander PPO with HiWET reward augmented by reachability-margin reward +w*min(f_R - m_eff) plus penalty for committed subgoals violating effective screen.
6. Train-and-deploy: Stage-0 pretrain KMP and alpha-augmented f_R field offline on shared IK/FK data; Stage-1 reuse HiWET frozen Tracker with frozen KMP and f_R; Stage-2 freeze Tracker, train reachability-scheduled Commander by PPO with spatial curriculum, co-fit g_phi online from rollout logs; deploy zero-shot sim-to-real on 29-DoF Unitree G1 querying f_R (0.062 ms/sample) and cheap g_phi head at real-time PD rate.

- *Why it beats each:* Beats HiWET (base scheduling = reactive planar-proximity reward, no forward reachability model): gradient-follow toward feasible placements, screen subgoals before commit, g_phi closes quasi-static-to-dynamic gap HiWET never models. Beats DRM (offline QP/SQP module, static IK model, ignores loco-manipulation coupling): embeds it in hierarchical RL, wraps with deployment-calibrated margin so static screen becomes closed-loop hardware scheduler, honest about what it certifies.
- *Falsifier:* Boundary targets forcing base repositioning. Ablation A reverts to HiWET reward-only base term: reach-to-infeasible failures not dropping means reachability coupling adds nothing, method collapses to HiWET. Ablation B keeps gradient scheduling, sets g_phi = 0: raw quasi-static screen matching full method means conservative-margin novelty unjustified, static-to-dynamic calibration claim falsified.
- *Benchmark:* HiWET long-horizon world-frame loco-manipulation suite on Unitree G1 (5 geometric world-frame trajectories from +/-5 m starts, avg EE position error target <20 mm vs HiWET 12-15 mm RMSE, base final-position error vs 0.101 m baseline), augmented with new static-workspace-boundary subset plus reach-to-infeasible failure rate plus screen-calibration metric at increasing base speeds, all on legged G1.
- *Risk:* One load-bearing assumption: alpha-conditioned reachability, which DRM never modeled. Multi-alpha IK labeling and per-alpha IoU sanity check = gating risks (fallback: alpha-indexed ensemble of fixed-alpha fields). Secondary: g_phi miscalibration if Stage-2 speeds miss deployment distribution (mitigation: refit from on-robot logs, prefer pessimistic quantile calibration). If dynamic shortfall large and pervasive, not localized, screen erodes workspace enough to narrow advantage; Ablation B detects.

##### WB.A4: CoLA-WB (Coupled Latent Actions for Whole-Body loco-manipulation)

**Build on** [[2512.11047|WholeBodyVLA]] + [[2506.13751|LeVERB]] + [[2606.18772|HALOMI]] (whose feasibility manifold = [[2511.04131|BFM-Zero]] Forward-Backward latent it builds on). One VLA predicts manipulation VQ code then locomotion latent as residual conditioned on it, fuses pair, projects onto frozen [[2511.04131|BFM-Zero]] manifold so joint loco+manip latent feasible by construction.

1. Keep WholeBodyVLA two domain-disentangled VQ-VAE Latent Action Models over frozen DINOv2 features: manip LAM and loco LAM pretrained on action-free egocentric human video. Kept separate so shared codebook not misread moving-camera loco as arm motion. Output: per-frame pseudo-labels, discrete manip code c_mani, continuous loco latent z_loco.
2. Couple via LeVERB residual CVAE: single policy pi_theta takes ego RGB plus language, first emits c_mani (what hands intend), then loco latent as residual conditioned on it, z_loco = z_prior(o,l) + delta(o,l,c_mani). Base moves in service of hands. Replaces WholeBodyVLA two independent cross-entropy heads with explicit loco-given-manip dependency across domains.
3. Train residual with LeVERB-style privileged kinematics encoder over ground-truth near-future whole-body states emitting posterior on z_loco, added onto VLA prediction, KL term forcing it to carry only loco detail not inferable from vision-language-plus-c_mani. Gradient-reversal modality discriminator keeps latent invariant to real-vs-blank images so language-only clips mix in. Encoder discarded at deployment.
4. Project for feasibility (HALOMI): concatenate decoded manip code and loco residual into one whole-body latent, project onto BFM-Zero spherical manifold, get z_tilde, decode through frozen BFM-Zero prior into joint commands a = pi_BFM(z_tilde, s_bfm). Manifold makes emitted coupled latent feasible-by-construction, removes WholeBodyVLA separate LMO RL stage that absorbs arm-base interference after the fact.
5. End to end: inputs ego RGB plus language at ~10 Hz high level, proprioception-only s_bfm at 50 Hz manifold controller. One policy emits (c_mani, z_loco-as-residual), controller outputs dual-arm and lower-body joint commands, no discrete handoff to velocity-tracking RL policy. Latent resampled every H steps so controller trains against multimodal latent distribution, not just mean.
6. Loss and schedule: VQ reconstruction for frozen LAMs + cross-entropy on c_mani + residual-CVAE objective on z_loco (future-state MSE through manifold decode + beta1 KL to privileged posterior + beta2 gradient-reversal modality-invariance), BFM-Zero frozen so no manifold loss, plus optional coupling-consistency penalty. #### WAM.A (predict): improve WAM.A1, WAM.A2, WAM.A3 together

> [!tip] First principles
> - **First principle:** train-time density and deploy-time density independent degrees of freedom. Grounding signal (3D geometry, contact wrench) only need shape latent during learning; teacher whose information fully transferred is discardable at deploy, zero inference cost.
> - **Assumption challenged:** training with dense or tactile supervision means needing dense or tactile signals to trust prediction at deploy.
> - **The bet:** latent grounded through shared code or training-only teacher yields calibrated residual. ECE + failure-detection AUROC beat uncalibrated baseline, match sensor-equipped ceiling, sub-2x pure-latent deploy cost.

Three directions build one shared artifact: predictive world-model latent, trained dense + grounded, deployed lightweight. One deploy interface: calibrated residual gate deciding execute vs replan by comparing cached forecast against freshly encoded real observation. WAM.A3 (DUET-WM, on [[2605.06388|Semantic-LDM-WM]], [[2503.00653|DC-MPC]], [[2505.04999|CLAM]]) supplies encoding substrate: action-recoverable dual continuous-plus-quantized latent, carries both bottleneck types, grounded to control via latent inverse-dynamics. Mutual reinforcement: each reuses cluster's train-teacher-then-discard-and-gate recipe on different prediction target (scene geometry, contact wrench, action-recoverable dynamics). Robot inherits one latent — visual, contact, control futures all calibrated + gateable, not three separate predictors.

**Grounding mechanism (Seam 1: represent to predict).** Condition latent on dynamics state it must forecast: proprioception, commanded arm acceleration $\ddot q_{\text{arm}}$, estimated external wrench $F_{\text{ext}}$ (from momentum observer, no F/T sensor at deploy). Supervise shared wrench head with analytic $\delta_{\text{base}}=M_{\text{base,arm}}(q)\,\ddot q_{\text{arm}}$ for channel A, $J_{\text{ext}}^{\top}F_{\text{ext}}$ for channel C. Dense-train / latent-deploy architecture carries wiring: train density and deploy density independent — learn from dense video/3DGS teacher, act on latent + wrench head. Deploy: load with teacher head off (`train_decoder=False`); wrench head stays active as latent read-off feeding action head. Planning minimizes latent-goal distance plus wrench-feasibility term:

$$
a^\star=\arg\min_a \;\|z_{\text{goal}}-\hat z_{t+1}(a)\|^2 \;+\; \beta\,\|\hat\delta_{\text{base}}(a)\|_{\text{balance}}
$$

Keep deploy latency under 2x pure-latent, clear contact-stability floor (see Grounding).

##### WAM.A1: GROVER (Grounded Latent Residual Verifier)

**Build on** [[2605.20752|GaussianDream]] + [[2602.10098|VLA-JEPA]] + [[2605.06222|FFDC-WAM]]. Train-dense / deploy-latent WAM: one shared motion code feeds dense future-Gaussian scene-flow head + leakage-free latent forecaster, geometry causally grounds latent, deploy gates execute-vs-replan on calibrated latent residual.

1. Interface + projection contract: continuous-action VLA backbone with flow-matching expert takes multi-view observations, short history, language, state. Prefix module emits renderable prefix Z_t (only thing surviving to deploy), branches through three adapters: P_act (existing prefix-to-action path, unchanged), P_geo (train-only Gaussian-geometry head decoding dense 3D Gaussian centers), P_lat (linear plus LayerNorm into VLA-JEPA latent space).
2. Shared motion code = actual coupling: small encoder reads Z_t into explicit horizon-indexed motion code m_t (offsets one through five), sole dynamics input to both train-only dense head H_vel (per-Gaussian 3D scene-flow displacements, GaussianDream pseudo-targets) and latent forecaster via P_lat. Supervising H_vel with metric scene-flow directly shapes same m_t latent must consume. Optional L1 consistency term between P_lat(m_t) and stop-gradient latent motion delta ties two readings.
3. Latent forecast, horizon reconciliation: autoregressive time-causal transformer predicts future latent world-states in VLA-JEPA frozen JEPA space, conditioned on prefix history, state-transition + action tokens, m_t. Reads out at same five horizon offsets H_vel uses via shared-embedding horizon-query tokens — grounding loss tied only to those five overlapping horizons. Forecast computed once per planning step from Z_t, cached (FFDC trick), stop-gradient-only latent targets keep leakage-free.
4. Capacity isolation: token-budget split reserves prefix sub-block for action expert behind stop-gradient-on-write boundary; geometry + latent share second sub-block. P_geo, Gaussian decoder, P_lat, forecaster = LoRA-style adapters — discardable train-only geometry never overwrites bulk weights. Gradient-cosine monitor down-weights per-horizon terms when geometry and latent gradients turn antagonistic.
5. Calibrated residual verifier: each control step encodes only fresh observation o_t through VLA-JEPA frozen encoder to s_real_t, computes residual norm against matching cached latent slot, maps (with aggregate over cached futures + Z_t) through g_psi + sigmoid to confidence e_t, Platt/temperature-calibrated to empirical open-loop success. Execute next cached action when e_t at least tau, else trigger one re-encode plus re-forecast refreshing cache — never full dense re-render. Per-step re-encode itemized separately as cost.
6. Staged losses: Stage I pretrains dense teacher (depth L1 plus render plus 3D scene-flow per horizon) jointly with leakage-free latent objective + consistency term on mixed action-free human and action-labeled robot video. Stage II jointly trains policy plus matched-horizon grounding (flow-matching action loss plus weighted dense, latent, consistency terms), verifier head absent. Stage III: dedicated frozen-policy calibration pass, trains only g_psi against stationary success-label distribution built from temporal-swap, gripper-flip, late-noise corruptions.

- *Why it beats each:* vs GaussianDream — routes same dense future-motion through m_t into cheap latent shadow surviving deploy, gates on realized-vs-imagined residual: one-shot discarded prior becomes closed-loop self-monitor. vs VLA-JEPA — consults training-only forecast at deploy as Stage-III-calibrated verifier, grounded by dense 3D scene-flow on five matched horizons, latent carries true metric motion via constructed coupling. vs FFDC — verifies in leakage-free geometry-grounded latent (robust to appearance nuisance), calibrated success probability instead of uncalibrated 2D-token binary classifier, still cuts dominant dense world-model forward passes.
- *Falsifier:* train two variants, identical except one routes latent forecaster's dynamics through shared m_t H_vel supervises, other decouples via separate motion encoder. If grounded variant improves neither e_t ECE nor failure-detection AUROC on corrupted-future segments, shared-code-grounds-the-latent claim dead, GROVER collapses to FFDC-on-JEPA. Second falsifier: remove token-budget split + adapter isolation, check whether LIBERO success regresses below both single-objective baselines.
- *Benchmark:* HumanoidBench in-distribution + held-out-task OOD success (backbone grid off/on; SR, FWT/NBT) plus humanoid balance, disturbance, force-under-load on G1 and H1 as in CAWM. World-model forward-pass-count reduction (FFDC 69.10 percent) reported separately from itemized wall-clock + verifier encode latency. ECE + failure-detection AUROC of e_t. Non-humanoid dev-only sims (not gated or reported): LIBERO / LIBERO-Plus (GaussianDream 98.4 percent, VLA-JEPA 97.2 / 79.5 percent), RoboTwin, FFDC real-robot pick-and-place reference (45 to 80 percent).
- *Risk:* shared prefix sub-block may be too small for both metric geometry and leakage-free latent (GaussianDream full dense supervision lifts LIBERO only to 98.4 percent, thin marginal room) — mitigated by gradient-cosine monitor, empirical reservation size. Per-step re-encode: wall-clock savings can trail forward-pass-count reduction. Matched five-horizon tie leaves long-horizon latent slots ungrounded. Stage III calibration stationary only for frozen policy — post-calibration drift reopens miscalibration, needs recalibration.
- *As a general advance:* discardable dense-geometry teacher (3D-Gaussian future scene-flow head) grounds leakage-free latent forecast through shared horizon-indexed motion code (one intermediate code, two decoders), not prefix correlation. Same cached forecast becomes Stage-III-calibrated residual verifier at deploy. Unifies drop-the-dense-head supervision, leakage-free latent dynamics, imagination-vs-reality gating into one train-dense / deploy-latent contract. Standalone contributions: cross-embedding-space grounding adapters, capacity-isolated multi-objective prefix training, calibrated execution confidence, honest deploy cost protocol separating forward-pass-count from wall-clock.
- *Complement to coupling:* predict-then-verify substrate CAWM needs. m_t = natural carrier for anticipatory self-induced reaction (base-arm coupled inertia times arm acceleration); exogenous force-under-load wrench heads added as further train-dense heads on same shared code, inheriting matched-horizon tie. Leakage-free latent + Stage III loop give clean place to inject differentiable-system-identification-grounded inertia + contact model. Calibrated latent residual = exactly the causal-consistency verifier CAWM needs, extended from scene-future mismatch to predicted vs measured base and leg reaction on hardware via head-versus-analytic-versus-measured decomposition.

##### WAM.A2: WrenchCast: Sensorless Multi-Step Contact-Wrench Forecasting via Action-Conditioned Latent Rollout with Inverse-Dynamics Grounding

**Build on** [[2606.09337|TORL-VLA]] + [[2606.13877|ContactWorld]] + [[2603.17851|DexViTac]]. World model rolls JEPA latent forward H steps under candidate actions, decodes calibrated 6-DoF contact wrench off each rolled latent, separates self-motion from external contact, survives tactile-sensor removal at deploy.

1. Interface: deploy takes vision (front plus wrist images or point cloud), language, proprioception q_t (joint state, joint velocity, end-effector pose), candidate action chunk over steps t to t+H-1. Emits calibrated future 6-DoF wrench sequence (fx, fy, fz, tx, ty, tz) over horizon, no tactile read at inference.
2. Reuse ContactWorld modality-specific encoders + action-conditioned JEPA predictor, autoregressively rolls next latent over 12-to-48-step horizons, prefers point-cloud structure (planning success 32.1 vs 20.7 percent for wrist images). ContactWorld fuses tactile at inference (PointCloud+TacFF planner); WrenchCast re-casts same tactile signal as training-only teacher, drops at deploy — rolled visual-plus-kinematic latent stays geometrically stable over long horizons without inference-time tactile input.
3. Temporal wrench head decodes 6-DoF wrench off each rolled-forward latent at step k, conditioned on history latent. Delta over TORL-VLA one-shot co-output: forecast decoded off H-step rollout, depends on whole candidate chunk + accumulated future dynamics, verified against realized signal not assumed correct. Extends action-wrench coupling from single-step co-prediction to multi-step rollout-conditioned verified prediction.
4. Condition predictor + head on DexViTac kinematic-inertial token from q_t, q_dot_t, end-effector pose. Head emits two outputs per step: self-motion wrench W_self from inertia, gravity, velocity-product (Coriolis) term; residual external-contact wrench W_ext. Total forecast = sum. Decomposition DexViTac never performs.
5. Train with sensors mounted for ground-truth total wrench, four losses: latent prediction term (rolled-vs-observed latent error plus ContactWorld visual regularizers); total-wrench error over horizon; self-motion term on W_self computed only on free-space frames (tactile field null) so W_ext forced to carry external contact; distillation feature-matching term regressing rolled vision-plus-kinematic latent onto stop-gradient frozen tactile-teacher latent. All training-time only.
6. Calibrate trust gate on deploy-time signal: held-out data, compute residual using same coarse joint-torque-residual wrench proxy available at deploy, fit conformal threshold on proxy-based residual, flag steps exceeding it as OOD coupling. Deploy: drop sensor, run ContactWorld-style receding-horizon CEM-MPC (latent goal distance plus W_ext over-force penalty) or feed gated forecast as TORL-VLA predictive contact reference, fall back to low-force chunk when proxy residual exceeds threshold.

- *Why it beats each:* beats TORL-VLA — sensor-bound one-shot wrench co-output becomes rollout-conditioned, verified, sensorless forecast. Beats ContactWorld — adds explicit calibrated 6-DoF wrench decoder on same rollout, decomposed self-motion/contact, plus distillation removing tactile input ContactWorld cannot drop. Beats DexViTac — reuses only kinematic token, adds inverse-dynamics decomposition + multi-step action-conditioned wrench forecast it never produces. Positions against two closest contact world-models: [[2607.02503|VT-WAM]] (visual-tactile World-Action Model jointly predicting contact deformation + action; its contact-gated attention against visual dominance motivates keeping wrench term from being buried) and [[2606.30988|MuSe]] (multisensory WM predicting future force-torque for anticipatory compliance, adapts to force modality forgetting-free) — adds inverse-dynamics self/contact decomposition + sensorless distilled deploy neither provides. [[2606.08555|FAWAM]] tightest force-WAM baseline: jointly forecasts future actions + end-effector wrenches with closed-loop force-residual correction. WrenchCast must beat it via sensorless deploy, self-versus-external decomposition, whole-body carry (legs compensating) FAWAM's sensor-bound single-arm setup lacks.
- *Falsifier:* against action-shuffled control (permuted chunk, vision + proprioception fixed), forecast must degrade materially vs true-action, else reading self-inertia not coupling. W_ext on contact frames must beat static proprioception-only self-inertia regressor, else decomposition not isolating contact. Forecast-driven MPC must beat ContactWorld point-cloud-only planning success.
- *Benchmark:* ContactWorld 12-task contact-rich suite (insertion, disassembly, screwing, exploration) under receding-horizon MPC across 12-to-48-step offsets. Held-out wrench MSE broken into total, self-motion (free-space), external-contact (contact) components plus action-shuffled sensitivity gap. Real-robot: sensorless WrenchCast vs sensorless base VLA, sensor-equipped TORL-VLA reported only as ceiling.
- *Risk:* contact wrench often visually under-determined under occlusion, micro-slip, identical appearance at different force — vision path may fail to reproduce tactile teacher, W_ext may collapse toward zero or toward what W_self already explains. Decomposition + action-shuffled falsifier detect exactly this safe-but-useless degeneration, signaling sensor cannot be removed for that task class.
- *As a general advance:* training-and-trust architecture for sensorless physical-quantity forecasting with built-in identifiability check: attach calibrated physical-quantity decoder to any action-conditioned latent world model supervised by training-only sensor; distill sensor into deploy path via teacher-student feature matching; decompose quantity into self-motion component (supervised where external part null) + external residual so signal identifiable; gate trust with conformal residual on same coarse proxy available at deploy. Converts fragile training sensor into cheap deploy-time forecast.
- *Complement to coupling:* enables coupling work on all three fronts. PREDICTS future 6-DoF wrench as explicit sensorless world-model output off multi-step action-conditioned rollout, extending TORL-VLA one-shot co-prediction. GROUNDS own inertia plus contact via inverse-dynamics decomposition into W_self (free-space supervised) + residual W_ext, beyond DexViTac mere conditioning. VERIFIES predicted-versus-realized coupling through conformal residual on same proprioceptive proxy used at deploy — closes forecast-to-reality loop without overpromising guarantee proxy cannot honor.

##### WAM.A3: DUET-WM (Dual-Encoded, Action-Recoverable Latent for World-Model Imagination)

**Build on** [[2605.06388|Semantic-LDM-WM]] + [[2503.00653|DC-MPC]] + [[2505.04999|CLAM]]. One latent objective splits d=96 semantic latent into continuous flow-matching channel + FSQ channel fed by continuous residual, gated per token, grounded by CLAM.

1. Fix Semantic-LDM-WM protocol (H=2 history frames plus actions). Map each RGB frame through frozen semantic encoder (V-JEPA 2.1 or Web-DINO) + pretrained KL-regularized S-VAE adapter to compact z-bar in R^{N x 96}. Hold dual factorization total bit budget to exactly this single-channel d=96 baseline.
2. Partition (not extend) budget into co-located sub-channels: reserve continuous part z^c in R^{N x d_c} (d_c swept + reported, e.g. 64 of 96); form residual r = z-bar minus stop-gradient reconstruction of z-bar from z^c; pass r through learned linear projection into b channel-organized scalar coordinates; apply DC-MPC Finite Scalar Quantization (levels e.g. L={5,3}) for discrete code z^q. Discrete arm quantizes only what z^c provably fails to carry.
3. Up-front channel-disjointness gate after short warm-up: estimate mutual information between z^c and z^q and each channel's MI with ground-truth action via IDM readout. If z^q action-information subsumed by z^c, stop, use cheaper single arm — DC-MPC discrete win was on proprioceptive state; orthogonality over compressed semantic latent must be measured, not assumed.
4. Learned per-token routing gate (lightweight MLP on z-bar, stop-gradient input, initialized 0.5) mixes two channels' contributions per token + per frame. Supervised indirectly by combined transition loss plus target-diversity regularizer so it routes, not averages.
5. Train one action-conditioned spatial-temporal DiT (Semantic-LDM-WM wide-head DDT) as shared trunk, two output heads over horizon K=8: flow-matching head for z^c, softmax classifier head over FSQ codebook (DC-MPC categorical dynamics). Stabilize straight-through-Gumbel branch via gradient-detach curriculum, capped Gumbel BPTT depth. Report two-head loss variance + gradient-norm ratio as first-class metrics.
6. Ground latent with CLAM full mechanism: latent inverse-dynamics readout to latent action z^a; latent forward-dynamics model whose reconstruction of next frozen semantic latent (not pixels) is the bottleneck forcing z^a compact; small-labeled-set latent-action decoder. FDM-latent loss also supervises residual projection. Train on Bridge V2, encoder + adapter frozen. Total loss: flow-matching + FSQ cross-entropy + CLAM FDM reconstruction + CLAM IDM plus decoder + gate diversity regularizer.

- *Why it beats each:* beats Semantic-LDM-WM — keeps semantic-over-reconstruction win at true d=96 budget while residual-FSQ channel + full CLAM grounding restore ordinal/contact structure + action-recoverability its S-VAE adapter distorts. Beats DC-MPC — ports categorical dynamics onto semantic features through learned residual projection re-creating channel organization DC-MPC had natively, gated on disjointness because transfer untested. Beats CLAM — adds discrete contact mode + semantic-prediction transition model to its single continuous bottleneck, reuses FDM bottleneck in latent space. Beats prior three-arm contingency map — ships one adaptive union latent, only after gate confirms non-redundancy.

Killed if disjointness gate never opens, or closed-loop SR fails to beat better single arm by powered minimum detectable effect stratified by task family, or gate per-token values fail to correlate with stratification.
- *Benchmark:* closed-loop VLA-in-the-loop SR on HumanoidBench (humanoid suite, held-out-task OOD) at power-analysis-sized per-task-family n, free-space / contact-rich / distractor-heavy stratification. Diagnostics: z^c-z^q + per-channel-with-action mutual information, IDM Pearson r, CEM action error, two-head loss variance + gradient-norm ratio. **Resolving the robot-self inertia entanglement (Seam 2).**

Object-side recipe ([[2603.01151|D-REX]] mass-inertia-routed differentiable graph, distilled SLAT-Phys-style, refined CAPTURE-style) explicitly defers robot's own inertia: carried-object physics observable through deliberate poke-and-track excitation, but arm-to-base reaction matrix M(base, arm) never excited in isolation, never gets clean trajectory of own, structurally entangled with leg dynamics reacting to every arm motion. Steps below: how harder seam grounded.

1. Define Seam-2 target as small, structured residual on top of URDF prior, not free fit. CAD/URDF already pins gross arm-link masses + kinematic placement — only unknowns needing grounding: deviations model gets wrong in practice: per-link mass-scale + center-of-mass offset for arm chain, off-diagonal base-arm coupling block of composite-rigid-body inertia M(base, arm) those deviations induce. Identifying low-dimensional residual (not re-estimating full mass matrix) makes tight tolerance achievable — model carries most signal, only coupling correction learned. Mirrors [[2603.01151|D-REX]] routing trajectory-matching loss analytically through mass-inertia matrix M to recover only free parameters, here narrowed to arm-chain residual not external object's mass.

2. Resolve never-excited-in-isolation problem with designed multi-trajectory excitation protocol + aggregation, not single rollout. M(base, arm) only ever appears coupled into whole-body reaction: run battery of short, deliberately diverse free-space arm maneuvers (varied joint-velocity + acceleration profiles, single-joint sweeps, multi-joint combinations), base held in stable near-quasi-static stance so leg controller operates in most linear regime. Each maneuver excites different projection of coupling block; aggregating differentiable-sim trajectory-matching residual ([[2603.01151|D-REX]] L_traj summed over measured base-and-arm response, here including base IMU + contact-force reaction, not just object's 6-DoF pose) across whole battery makes otherwise-unidentifiable off-diagonal terms observable. Aggregation across many partial excitations replaces one clean isolated trajectory that physically cannot exist for self-inertia.

3. Disentangle from leg dynamics by filtering, not ignoring. Leg controller reaction = dominant confound, two filters. First, gate identification windows: only accept maneuver segments where stance stable + base acceleration dominated by arm reaction (high contact-margin, no commanded base motion, no slip events flagged by contact estimator) — whole-body-stability gating [[2503.05652|BRS]] + [[2506.14278|Heavy-Limbs-WBC]] line already instruments. Second, project residual onto arm-coupling subspace, treat leg-side dynamics as known model-supplied feedforward to subtract, in spirit of [[2602.21919|Learning-in-the-Null-Space]]: leg reaction regressed out so remaining trajectory mismatch attributable to arm-to-base coupling block, not leg-controller behavior. What survives both filters = clean Seam-2 signal.

4. Amortize + refine with object-side stack, supervised by same offline differentiable loop. Run step 2's per-robot, per-payload-configuration differentiable identification offline across corpus sweeping plausible arm-residual range + varying carried payload — exactly as object recipe runs D-REX per-object loop offline as supervision generator. Distill recoveries into feed-forward predictor in spirit of [[2603.23973|SLAT-Phys]] lightweight regression head, conditioned on robot's proprioceptive interaction history (commanded arm trajectory, measured base IMU + joint torques) plus current payload estimate from object-side AMORTI-SIM pass, outputting arm-residual + coupling block in one forward pass. Front-load [[2410.20357|Dynamics-as-Prompts]] (CAPTURE) in-context refiner: when live base-vs-predicted reaction mismatch large (new payload, changed configuration), converges in handful of steps not fresh gradient loop — same zero-demo-prior-plus-few-step-residual structure object seam uses.

5. Justify narrow randomization range from residual framing. Step 1 identifies deviation on top of known URDF, not unknown absolute inertia — prior already tight: arm-link masses known to manufacturing + payload tolerance, residual lives in narrow band (small multiplicative mass-scale + bounded center-of-mass offset per link). Downstream simulator randomized only over this narrow identified band around recovered residual, not broad domain-randomization range — same plug-point shift D-REX makes replacing broad DR with narrow randomization around identified parameter. Narrow randomization credible here precisely because robot's own kinematic model supplies center of band, only coupling correction uncertain — unlike fully unknown external object.

6. Make ~15% Frobenius tolerance credible by tying to model already mostly right + measured per-object precedent. Tolerance on residual-corrected coupling block; URDF prior captures bulk of M(base, arm), learned correction only closes modeling-error fraction, not whole matrix. Frobenius error ~15% on coupling block = regime where corrected matrix within band whole-body controller stability margin tolerates, not arbitrary target. Anchored to [[2603.01151|D-REX]] demonstrated 4.8 to 12.0 percent percentile mass-recovery error on external objects under matched differentiable excitation: self-inertia strictly harder (coupled, never isolated, leg-confounded), so tolerance set modestly looser than D-REX clean-object band, ~15%, reflects added difficulty honestly, stays inside what URDF-anchored residual can plausibly deliver. Same percentile-error protocol D-REX uses for objects, scored as Frobenius error on coupling block against **known planted ground truth in PR-0b's SIM check** = instrument making number checkable not asserted. On **real robot** nominal CAD/URDF inertia is the model sysID corrects (not ground-truth reference), true inertia unobservable — real-robot grounding judged downstream by PR-4 force-plate self-consistency check, not CAD-plus-load-cell Frobenius reference.

7. Verify with self-consistency check doubling as falsifier. Feed predicted arm-residual + coupling block back through frozen differentiable whole-body graph, penalize residual base-and-arm trajectory mismatch over held-out excitation maneuvers — self-consistency term object recipe uses so prediction must reproduce real dynamics, not match label. Seam falsified if corrected M(base, arm) cannot be driven below ~15% Frobenius band on held-out maneuvers + payloads, or if narrow randomization around identified residual fails to beat broad-DR baseline on downstream whole-body reaction-compensation task — then self-inertia grounding buys nothing over URDF prior plus broad randomization.

##### S2R.B1: SENSE-T (Sensitivity-of-Embodied-Transfer)

**Build on** [[2503.17973|PhysTwin]] + [[2511.04665|Real-to-Sim-GS]] + [[2603.01151|D-REX]]. Fuse three into one differentiable graph whose backward pass yields, per fidelity channel, analytic sensitivity of physically-commensurate sim-real trajectory-divergence — replaces card's discrete fidelity sweep with single gradient.

1. Inputs: phone scene plus per-object scans, 1 to 3 RGBD interaction videos per object, robot URDF + RealSense intrinsics, GELLO demos, policy panel (ACT, DP, Pi-0, SmolVLA) to score. Outputs: joint twin, per-channel sensitivity vector g, budget allocator descending predicted divergence per unit reconstruction cost. Headline dependent variable = continuous trajectory-divergence, not forward Pearson-r or grasp-SR.
2. Assemble one differentiable rollout: reuse Real-to-Sim GS spring-mass twin, Warp engine, LBS, color-alignment loss (degree-2 IRLS RGB transform), ICP+RANSAC alignment as given substrate. Graft D-REX trajectory-matching loss L_traj = sum_t of squared 6-DoF object-pose error (poses from FoundationPose) onto end of shared rollout — canonical interaction run identically in real + twin emits one differentiable scalar.
3. Commensurate unit: canonical-interaction divergence D = L_traj at converged twin = common currency. Any channel perturbation (geometry control-point, stiffness, color-transform) scored by how many metres it moves D through shared rollout. Appearance channel does not enter D directly: route rendered policy-camera observation through frozen copy of each policy for commanded action, feed action into same Warp rollout — appearance reaches D, acquires same divergence unit.
4. Per-channel sensitivity analytic: autodiff through rollout gives g_c = dD/d(theta_c) for c in geometry, color, stiffness, mass — one backward pass per object, not regenerate-and-rollout sweep. Validate minimally: run card's within-object check once per object on held-out panel, confirm g's sign + rank-order match realized forward-r slope. Sweep demoted to one-shot calibration; g stays well-defined where forward grasp-SR is step function.
5. Loss + allocator: inversion loss = joint objective C (single-dir Chamfer + CoTracker3 track error + render L1/D-SSIM) plus color-alignment plus L_traj, unchanged in form. New top object = allocator: given per-channel cost vector k + analytic g, allocate next inversion increment to argmax_c of |g_c|/k_c — steepest metres-of-divergence reduction per unit cost. Keep separate additive control-dynamics residual D_ctrl L_traj cannot reduce — budget never spent on channel that cannot move ceiling.
6. Train, deploy, bound claim: training = per-object self-supervised inversion (no policy gradients, policies only scored) plus one-shot calibration of g against realized forward r. Novel object: run inversion once, read g from single backward pass, use locally to pick which channel to refine next, confirmed by one rollout. Report per-class aggregates of g only as descriptive prior with cross-object variance, never global predictor of absolute forward r. Outputs: per-twin sensitivity certificate + divergence-calibrated twin consumed by eval harness or as Sim2Real.B3 fold-back fidelity gate.

- *Why it beats each:* beats Real-to-Sim GS — differentiated rollout emits per-channel analytic slope in one divergence unit, binary present/absent ablation becomes continuous well-posed allocation gradient. Beats PhysTwin — reuses its differentiable graph in reverse, pushing forward-divergence gradient back onto reconstruction parameters, pricing each error in metres of divergence not floating resim metrics. Beats D-REX — differentiates its exact L_traj w.r.t. every reconstruction channel (including appearance path routed through frozen policy), gradients commensurate + rankable, extends to deformable regime via PhysTwin stiffness.
- *Falsifier:* one object: compute g by one backward pass, run card's within-object controlled-degradation sweep (pose clamped to ground truth), recompute realized forward-r slope per channel. If g fails to predict sign + rank-order of slopes, cheap gradient does not stand in for expensive transfer slope, allocator collapses to discrete sweep. One object, one backward pass, one sweep, no new hardware.
- *Benchmark:* primary DV = canonical-interaction sim-real trajectory-divergence D (metres of FoundationPose-tracked 6-DoF error through Warp rollout) on Real-to-Sim GS suite (plush-toy packing, rope routing, T-block pushing) across four policies, stratified rigid/articulated/deformable. Validation DVs: forward sim-real success-rate Pearson r, plus Single-View Mesh-for-Robotics graded Chamfer-to-grasp-transfer (2mm/5mm/1cm) as independent check; REALM (r=0.92) named reference, D_ctrl reported separately.
- *Risk:* g first-order — where divergence non-convex (contact making/breaking adds kinks), single-point gradient can mispredict finite channel improvement, chase locally steep but globally shallow channel. Mitigate: two-point secant (g at converged plus one perturbed point per channel), gate allocation on sign agreement, fall back to discrete step for disagreeing channel. Second risk: appearance pushforward through frozen policy is policy-specific — report g_color per policy, treat only cross-policy-stable component as allocatable.
- *As a general advance:* standalone instrumentation advance for real-to-sim inversion: one differentiable rollout, built from off-the-shelf differentiable twin + trajectory-matching loss, yields analytic per-channel sensitivity of forward transfer in one commensurate divergence unit. Reconstruction budget allocated by gradient not exhaustive sweep, defined even in threshold-dominated contact-rich regime where fidelity-to-success regression ill-posed. Packaged as per-twin sensitivity certificate any inversion engine can emit.
- *Complement to coupling:* supplies differentiable-sensitivity machinery, not free transfer of object-grounding to robot-grounding. Same backward-pass-through-shared-rollout could make Whole-Body A1/C1 wrench heads sensitive to arm-base inertia + contact-Jacobian errors, but SENSE-T grounds object physics not URDF inertia — object-to-robot-self grounding seam named in Seam 2 callout above, so wiring g to robot-self parameters = open contribution. #### De-circularization and the $\varepsilon$-curve

> [!example] Why this protocol is the heart of the de-risked core
> If explicit head's supervision target came from *same* inertia model rollout uses, explicit win = tautology (head re-derives number already in loop), will not survive any inertia error on hardware. Protocol below makes explicit head earn win **under deliberately wrong inertia model**: win = evidence inductive bias helps, not oracle labels.

**$\tilde M$ generation (the perturbed model, distribution pinned).** Per seed, build perturbed dynamics model $\tilde M(q)$: scale **each link's mass and each diagonal rotational-inertia entry** (optionally CoM offset) by **independently sampled multiplicative factor** $(1 + u_i)$ where, link $i$, **$u_i \sim \mathrm{Uniform}(-\varepsilon, +\varepsilon)$ i.i.d. per link, per seed** (named, symmetric, element-wise uniform draw - not normal, not single global scale). Element-wise: mass and each inertia component get own independent $u_i$. Explicit-head target $\delta_{\text{base}}^{\star} = \tilde M_{\text{base,arm}}(q)\,\ddot q_{\text{arm}}$ computed from this **wrong** model.
- **Per-link resampling rule (frozen, so reproducibility does not break).** Perturbation vector $\{u_i\}$ **drawn once per (seed, $\varepsilon$) pair, held fixed across whole rollout/training run**, NOT re-drawn per rollout step. Critically, **single random stream per seed** generates unit-variance draws $\{v_i\} \sim \mathrm{Uniform}(-1, +1)$ **once**; every $\varepsilon$ on grid reuses *same* $\{v_i\}$ scaled $u_i = \varepsilon\,v_i$. So $\varepsilon$-curve = **paired sweep along fixed perturbation direction** (only magnitude $\varepsilon$ changes across grid points, not random direction); curve shape reflects $\varepsilon$ alone, not confounded by re-randomization. Across $\ge 3$ seeds, directions $\{v_i\}$ differ; within seed, shared across $\varepsilon$.

**Structure-destroying control arm (matched Frobenius magnitude, so a win is inductive bias not a noisy-but-informative label).** Magnitude-only draw scales each entry by $(1+u_i)$, **preserving coupling block's sparsity pattern and sign structure at every $\varepsilon$** - still-informative noisy label could let explicit head win without structural prior. Foreclose: run **second, structure-destroying perturbation arm** at **matched Frobenius magnitude** to magnitude-only $\tilde M$ at same $\varepsilon$: **permute which arm-joint columns map to which base/leg rows of $M_{\text{base,arm}}$, randomize cross-term sign pattern**, rescale so $\lVert \tilde M_{\text{struct}} - M\rVert_F = \lVert \tilde M_{\text{mag}} - M\rVert_F$ (two perturbations differ only in keeping true coupling structure, not magnitude). Matrix-Frobenius matching **necessary but not sufficient**: head supervised on **induced label** $\delta^{\star}=\tilde M_{\text{base,arm}}\ddot q_{\text{arm}}$, not $\tilde M$ directly - label-magnitude exploit reads RMS of induced label over $\ddot q_{\text{arm}}$ distribution. So rescale additionally matches **induced-target RMS** (same criterion channel C already uses for wrench target): $\mathbb{E}\big[\lVert \tilde M_{\text{struct}}\ddot q_{\text{arm}} - M\ddot q_{\text{arm}}\rVert^2\big]^{1/2} = \mathbb{E}\big[\lVert \tilde M_{\text{mag}}\ddot q_{\text{arm}} - M\ddot q_{\text{arm}}\rVert^2\big]^{1/2}$ over training $\ddot q_{\text{arm}}$ distribution - label-magnitude-exploitation filter airtight, not under-controlled. Explicit head supervised on structure-destroyed target in this arm. **De-circularization PASSES only if magnitude-perturbed head keeps margin WHILE structure-destroyed head's margin collapses to $\approx 0$**: head winning equally under structure-destroyed label of same Frobenius size exploits label magnitude, not coupling structure - bet void.

**The asymmetry (this is what makes it non-circular).** Policy and **implicit baseline both run on true sim dynamics** (true `mj_fullM`), receive **no privileged target**. Only explicit head supervised, on $\delta_{\text{base}}^{\star}$ from *perturbed* $\tilde M$. So:
- explicit head: biased label from $\tilde M$ (wrong by $\varepsilon$), structured inductive bias;
- implicit baseline: no label, must discover coupling from reward/data on true dynamics;
- both act in true-dynamics world - neither has oracle access to ground-truth coupling at deploy.

**Justification of non-circularity.** Explicit head winning while own supervision wrong by $\varepsilon$: win cannot be label leakage (label wrong); must be that *predicting structured coupling term at all* = right inductive bias. Asymmetry = proof: explicit head handicapped (wrong labels), implicit baseline gets no help either - any margin attributable to structure, not oracle.

**$\varepsilon$-sweep grid and statistics.** Sweep $\varepsilon \in \{0,\ 0.05,\ 0.1,\ 0.25,\ 0.5,\ 1.0\}$ over $\ge 3$ seeds per point (shared per-link direction $\{v_i\}$ scaled by $\varepsilon$ within seed, per resampling rule). Report **explicit-vs-implicit margin as function of $\varepsilon$** with **bootstrap 95% CIs** at every grid point.
- **Margin metric (pinned, single definition).** $\varepsilon$-curve margin = exactly **OOD-split success-rate gap** $\Delta\text{SR}_{\text{OOD}}=\text{SR}_{\text{explicit}}-\text{SR}_{\text{implicit}}$ of Metrics section - single scalar SR difference, NOT composite of success+balance+quartile-concentration. Balance-recovery and per-quartile concentration = *separate* reported axes; $\varepsilon$-curve success-rate only so slope interpretable. 95% CIs computed by same paired bootstrap (shared seeds/init, 10k resamples) as per-quartile gap in Metrics section - two figures statistically commensurable.
- **Quartile feed (which split feeds the $\varepsilon$-curve vs the broader ablation #1).** $\varepsilon$-curve reported on **full OOD split, pooled across all arm-accel quartiles** (no quartile stratification): answers "does structure survive model error" - different question from "where is the wedge" (ablation #1's top-quartile stratification). To keep $\varepsilon$-curve from hiding quartile interaction, additionally report **one stratified variant: top-arm-accel-quartile $\varepsilon$-curve**, side by side with pooled. Headline pass condition (below) read on **pooled** curve; top-quartile curve = supporting panel.
- **Lambda-weight interaction (selectivity bias foreclosed).** $\lambda_w \in \{0.05, 0.1, 0.3\}$ (training-objectives sweep) orthogonal to $\varepsilon$ grid. Against post-hoc cherry-picking: $\lambda_w$ **selected once on $\varepsilon{=}0.1$ validation slice before any other $\varepsilon$ point read** (single frozen choice), **entire $\varepsilon$-curve reported at that one frozen $\lambda_w$**. Other two $\lambda_w$ values only appendix robustness panel (full $\lambda_w \times \varepsilon$ grid), never headline. Pre-registered as **PR-$\varepsilon$-lambda** - selectivity bias addressed, not assumed away.
- **When the $\varepsilon$-curve is computed (gate sequencing, disambiguated).** $\varepsilon$-curve = **Phase 1A deliverable computed during 1A training**, not separate Phase-0 prerequisite: requires trained explicit and implicit heads, which only exist in 1A. Phase-0 (M0) deliverable = *frozen protocol and $\varepsilon$-sweep procedure spec* (below, dry-run on toy model, value-free): M0 ships *defined gate*, 1A ships *computed curve* gate reads. $\varepsilon$-curve void condition (PR-$\varepsilon$) therefore evaluated **as part of Phase 1A go/no-go**, jointly with PR-1A, not before.

**The $\varepsilon$-curve IS the headline and the verify harness.** Each force cluster runs one (WB.A perturbing $\tilde M$, WB.C perturbing contact unknowns: contact point/normal, friction-cone, contact-stiffness); curve = both headline figure and falsification test, de-circularization arm of that cluster's own go/no-go (WB.A at Phase-1A, WB.C at Phase-1C). Each gates only own cluster's downstream build, not rest of program; WB.B kinematic falsifier has no $\varepsilon$-curve, gates independently.
- **Pass shape**: positive margin at small $\varepsilon$ that **degrades gracefully** as $\varepsilon$ grows (structure helps, robust to moderate inertia error). Graceful-degradation envelope licenses narrow-range sysID grounding (see S2R.B ground cluster).
- **Large-$\varepsilon$ discriminator (explicitly reported).** Margins at two **largest** grid points $\varepsilon\in\{0.5,1.0\}$ promoted to explicitly reported discriminator alongside small-$\varepsilon$ positivity: margin staying elevated at $\varepsilon\in\{0.5,1.0\}$ = perturbation-exploitation signature (head rides wrong label, not true structure); pass shape requires margin declined toward these large-$\varepsilon$ points. Large-$\varepsilon$ margin reported as headline number - same quantity structure-destroying control arm cross-checks (structure-destroyed head should already sit at $\approx 0$ there).
- **Void condition (pre-registered, numeric, two-part).** Contribution declared **void** unless BOTH hold; each = numeric test on $\varepsilon$-curve output, not qualitative read:
  1. **Small-$\varepsilon$ positivity (label-leakage / never-helped filter).** Pooled margins at **both $\varepsilon{=}0$ AND $\varepsilon{=}0.05$** must be **significantly $>0$ at Benjamini-Hochberg FDR $q<0.05$** (paired bootstrap, 10k resamples, one-sided $>0$, BH-corrected across six $\varepsilon$ points). $\varepsilon{=}0$ significant but $\varepsilon{=}0.05$ already collapses to non-significant = flat-then-collapse label-leakage signature, bet void; neither significant = structure never helped, bet void.
  2. **Graceful-degradation, not increase (negative-slope test).** Across six $\varepsilon$ points margin must be **monotone non-increasing with at most one reversal**, OR equivalently **non-positive trend (Spearman $\rho \le 0$ of margin-vs-$\varepsilon$, stronger declining envelope $\rho < -0.5$ confirmatory target)**. Margin that *rises AND stays elevated at large $\varepsilon$* = void (perturbation-exploitation signature: significant Spearman $\rho > 0$, $p<0.05$, over full grid AND large-$\varepsilon$ margin at $\varepsilon\in\{0.5,1.0\}$ not significantly below small-$\varepsilon$ margin). Bare positive local slope NOT sufficient to void: *small-$\varepsilon$ regularization bump* (margin rising slightly at $\varepsilon\in\{0.05,0.1\}$ then declining toward large-$\varepsilon$ points) benign - small-$\varepsilon$ label-noise can regularize; void triggers only on rise-and-stay-elevated signature, not any positive slope. "Flat" (margin not significantly $>0$ anywhere) trivially fails condition 1.
- Two-part numeric gate = $\varepsilon$-curve evaluation step (procedure below); force cluster's downstream build halts at own gate (WB.A at Phase-1A, WB.C at Phase-1C) if curve not satisfied; other clusters proceed on own co-equal gates.

**Procedure (built in Phase 0, as steps).** Generate $\tilde M$; each $\varepsilon$ over $\ge 3$ seeds, train explicit head on perturbed target $\delta^{\star}_{\text{base}}$, implicit baseline on true dynamics (no privileged target); evaluate OOD success-rate margin; bootstrap 95% CIs; apply two-part void gate; freeze $\lambda_w$ once on $\varepsilon{=}0.1$ slice (PR-$\varepsilon$-lambda). Implementation deferred to Phase 0 against `humanoid-bench` PPO substrate.

Within-backbone paired off/on = identified comparison; grid shows it generalizes.

"Matched-capacity" made **auditable, not asserted**: capacity parity = **trainable parameter count within ±2% AND forward FLOPs-per-step within ±5%** of explicit-head configuration, both reported. Explicit head's wrench-prediction parameters added to explicit configuration's budget before parity band computed - implicit MoE genuinely matched to *full* explicit head, not stripped backbone. **Optionally** also reproduce HEX UPP (unified predictive policy) ablation in-house as second implicit point. Forecloses "margin is just extra $\ddot q_{\text{arm}}$ observation, not structured prediction" rebuttal.

Foil at 500 Hz, not 50 Hz, makes anticipatory win (if any) real win over best reactive option.

> [!example] ADAPT implementation provenance (committed before M0, the single largest fairness commitment)
> Reactive foil locked to one implementation so parameters cannot be tuned post-hoc. This paragraph = falsifier-fairness anchor.
> - **Fork / code version.** Reimplement momentum-based generalized-momentum observer from [[2606.16542|ADAPT]] formulation in-house inside `FALCON` `BasePolicy` loop (ADAPT releases no standalone reusable observer module in `data/.repositories/`; version-of-record = in-house reimplementation, frozen and hash-pinned at M0, not external fork that could drift). [[2410.21229|HOVER]] privileged contact-force observation path = I/O template reimplementation matches.
> - **Exact momentum-observer formulation (frozen).** Generalized-momentum residual $\hat\delta_{\text{base}}^{\text{obs}} = K_o\!\left(p(t) - \int_0^t (\tau + C^\top\dot q - g + \hat\delta_{\text{base}}^{\text{obs}})\,ds - p(0)\right)$ with generalized momentum $p = M(q)\dot q$. Frozen parameters committed at M0: observer gain $K_o$ tuned once on held-out calibration episode (value frozen, never re-tuned per condition); **derivative window** = one 500 Hz state step (2 ms) finite difference for $\dot p$, never multi-step look-back that would smuggle in anticipation; **filter cutoff** = first-order low-pass at pre-registered $f_c$ (default 40 Hz, just above 30 Hz Nyquist floor, frozen at M0) on residual; **normalization** = per-DoF z-score using *same* mean/std statistics fit on *training* split that normalize explicit head's $\ddot q_{\text{arm}}$ input - both heads see identically-scaled inputs (input-isolation requirement below). On hardware, input-isolation control additionally requires anticipatory head and momentum observer consume **identical sysID-grounded $M(q)$**: control currently pins shared input normalization but not shared inertia source; clean in sim where $M$ exact for both, but divergent hardware inertia source would reopen model-quality-vs-timing confound.
> - **Does ADAPT train on true or perturbed inertia? (committed: TRUE).** Momentum observer's internal model ($M, C, g$ in residual integral) uses **true sim dynamics**, identical to implicit baseline and policy (de-circularization protocol). Observer *not* handicapped by $\varepsilon$-perturbation: only explicit head's supervision target $\delta_{\text{base}}^\star$ drawn from perturbed $\tilde M$. Comparison conservative for our claim: reactive foil runs on correct model, explicit head handicapped with wrong one - explicit win doubly non-circular (survives both wrong labels and true-model reactive competitor). De-circularization symmetry explicit: **policy, implicit baseline, ADAPT observer all run on true dynamics; only explicit-head label perturbed.**
- **Input-isolation control (layer-level spec, so confounds cannot hide in preprocessing).** Same head architecture, capacity, loss, data, seeds; swap **only head input**: planned/commanded $\ddot q_{\text{arm}}$ (anticipatory) vs 500 Hz observer's measured-past $\delta_{\text{base}}$ estimate (reactive). Pinned so swap genuinely input-only:
  - **Which layers stay identical vs differ.** Every layer byte-identical in architecture (same `Linear->ReLU->Linear->(6+n_leg)` per mode + mode classifier (Architecture), initialized from same seed. **Only** difference = contents of first-layer input vector. **No extra projection layer** on either arm; observer estimate injected into same input slot commanded $\ddot q_{\text{arm}}$ occupies.
  - **Shape / normalization match.** ADAPT observer estimate already a $(6+n_{\text{leg}})$-vector in *same physical units and DoF ordering* as $\delta_{\text{base}}$; commanded $\ddot q_{\text{arm}}$ = $n_{\text{arm}}$-vector. To make swap input-only despite differing native dimensionality: both inputs pass through **same frozen z-score normalizer fit on training split** (normalizer of ADAPT-provenance paragraph), zero-padded to common input width fixed at M0; padding mask identical across arms. Neither arm gets wider or differently-scaled input.
  - **Joint vs sequential head training (committed: each arm trained independently from scratch, jointly with its own backbone copy).** Anticipatory head and reactive head **not** trained sequentially or fine-tuned from each other (would leak one arm's representation into other). Each trained from shared seed init **jointly** with identical copy of backbone+policy on identical data/seeds, then compared paired. Decisive attribution to feedforward *timing*, not head capacity, init, or training order.
- **Data split (committed).** All Phase 1A runs use **public `humanoid-bench` release** task set and splits; any deviation = **documented local variant** (named tasks, named OOD perturbations) recorded in Pre-registration block. **Fixed seeds** ($\ge 3$, shared across conditions for paired comparison) set before data access.
- **Channel-C foil provenance (committed before data access).** C's reactive arm has two pinned foils: (i) **ADAPT momentum observer applied to external wrench** (same frozen formulation, gain $K_o$, 2 ms derivative window, 40 Hz filter as A foil; only change = residual it estimates is *external* $F_{\text{ext}}$, not self-induced reaction), (ii) **reactive impedance / admittance tracker** ([[2511.04679|GentleHumanoid]]-class learned impedance, [[2505.20829|Unified-Force-Position-Control]]-class estimate-then-impedance), tuned once on held-out calibration episode, frozen. C's implicit arm reuses [[2505.06776|FALCON]] torque-limit-aware force curriculum (no anticipatory term) as strong implicit force baseline. C's de-circularization perturbs **actual contact unknowns** (not $\tilde M$, not $J_{\text{ext}}$ directly: $J_{\text{ext}}$ = contact Jacobian, kinematic/analytic in $q$ once contact point fixed, not inertial parameter): **assumed contact point / surface normal by $\pm\varepsilon$ of link length, and/or friction-cone coefficient / contact-stiffness**, drawn by same symmetric uniform $\pm\varepsilon$ rule. Unknowns unit-incommensurate (contact point in link-lengths, surface normal angular tolerance, friction coefficient dimensionless, contact-stiffness in N/m), so each unknown's $\varepsilon$ expressed as fraction of own physical sensitivity / nominal scale - single $\varepsilon$ = common fractional-error axis, not one absolute magnitude across units; pooled C $\varepsilon$-curve read on normalized axis, per-unknown C sub-curves = supporting panel. Explicit head then supervised on $J_{\text{ext}}(q, \tilde p_{\text{contact}})^{\top}\tilde F_{\text{ext}}$ (Jacobian recomputed at perturbed contact point against perturbed wrench) - C's identifiability framed as **contact-localization + wrench-estimation**, not $J_{\text{ext}}$ Frobenius recovery. C $\varepsilon$-curve uses identical two-part void gate (significant at small $\varepsilon$, non-increasing) plus structure-destroying control arm (permute/sign-randomize contact-point-to-link assignment; discrete contact-point-to-link permutation has no Frobenius analogue to A's inertia perturbation, so "matched magnitude" = equal RMS shift of induced wrench target $J_{\text{ext}}^{\top}F_{\text{ext}}$ as magnitude-perturbed arm). Input-isolation control for C swaps only head input: *anticipated* $\widehat{J_{\text{ext}}^{\top}F_{\text{ext}}}$ (from estimated wrench, forward-modeled) vs observer's *measured-past* external-wrench reaction - any first-100 ms win attributed to feedforward timing, not capacity.

### Training objectives

$$
\mathcal L = \underbrace{\lambda_z\,\|z_{t+1}-\hat z_{t+1}\|^2}_{\text{latent dynamics}}
+ \underbrace{\lambda_d\,(\mathcal L_{\text{recon}}+0.25\,\mathcal L_{\text{vq}})}_{\text{dense teacher (train only)}}
+ \underbrace{\lambda_a\,\mathcal L_{\text{action}}}_{\text{flow/diffusion}}
+ \underbrace{\lambda_w\,\mathcal L_{\text{wrench}}}_{\text{coupling}}
+ \underbrace{\lambda_{\text{cond}}\,\mathcal L_{\text{cond}}}_{\text{conditioning (Seam 1)}}
+ \underbrace{\lambda_c\,\mathcal L_{\text{consistency}}}_{\text{causal}}
$$

- $\mathcal L_{\text{latent}}$: MSE on predicted vs target latent (DINO-WM `emb_criterion`, the `z_loss`).
- $\mathcal L_{\text{dense}}$: reconstruction + VQ on teacher head (DINO-WM `decoder_latent_loss_weight=0.25`); **train only**, dropped at deploy.
- $\mathcal L_{\text{action}}$: flow-matching/diffusion action loss (UWM `action_loss`, VPP `GCDenoiser`).
- $\mathcal L_{\text{wrench}}$ (new, shared across channels A and C): Huber on $\hat\delta_{\text{base}}-\delta_{\text{base}}^{\star}$ (A) **and** on $\widehat{J_{\text{ext}}^{\top}F_{\text{ext}}}-\delta^{\text{ext},\star}_{\text{base}}$ (C) + cross-entropy on contact mode. A target $\delta_{\text{base}}^{\star}$: MuJoCo `mj_fullM` in sim, sysID-recovered $\hat M_{\text{base,arm}}$ (see Grounding) for real data; C target $\delta^{\text{ext},\star}_{\text{base}}=J_{\text{ext}}^{\top}F_{\text{ext}}$: simulator contact state in sim, sysID-recovered $\hat J_{\text{ext}}$ + estimated wrench on real data.
- $\mathcal L_{\text{cond}}$ (new, **the Seam-1 learning mechanism**): auxiliary loss supervising coupling-conditioned latent to **encode control-relevant dynamics state** - small decoder reads $z_t$, trained (MSE) to reconstruct proprioception $q,\dot q$ and commanded $\ddot q_{\text{arm}}$ fused into it. Without this term latent free to *ignore* acceleration input at test time; wrench head degenerates into proprioception-only regressor (re-learns coupling only from whatever reward path happens to carry). $\mathcal L_{\text{cond}}$ forces latent to carry commanded-acceleration signal anticipatory wedge depends on. **Architecture's reliance on latent = experiment, not assertion:** ablation #3 measures wrench-head error with $\mathcal L_{\text{cond}}$ (and conditioning input) on vs off; ablation #8 (input-source) checks latent path beats trivial proprio + $\ddot q_{\text{arm}}$ MLP - claim that latent carries control-relevant state *validated*, not presumed.
- $\mathcal L_{\text{consistency}}$ (new): forward-inverse / counterfactual consistency (see Verification).

> [!warning] De-circularize the wrench target (the single most important fix)
> Define $\delta_{\text{base}}^{\star}$ from **perturbed** $\tilde M(q)$, not policy's own inertia model: full $\varepsilon$-perturbed protocol in De-circularization and the $\varepsilon$-curve sub-section. (From [[Focus-Direction-Review]].)

Sweep: $\lambda_z{=}1.0,\ \lambda_d{=}0.25,\ \lambda_a{=}1.0,\ \lambda_w{\in}\{0.05,0.1,0.3\},\ \lambda_{\text{cond}}{\in}\{0.0,0.1\}$ (the $0.0$ point IS ablation #3's conditioning-off arm),$\ \lambda_c{\in}\{0.0,0.1\}$.

### Metrics, statistical rigor, and budget

**Metric definitions.** *Success rate (SR)*: task completion per each benchmark's own criterion. *OOD margin*: $\Delta\text{SR}_{\text{OOD}}=\text{SR}_{\text{explicit}}-\text{SR}_{\text{implicit}}$ on OOD split; claim: grows with arm-acceleration quartile and with $\varepsilon$. *Balance-recovery rate*: fraction of perturbation episodes recovered without fall. *Coupling-prediction error*: $\|\hat\delta_{\text{base}}-\delta_{\text{base}}^{\star}\|$ (sim and sim→real). *Deploy*: control Hz, jerk-L2, peak memory.

**Statistical rigor.** Mean ± 95% CI over ≥3 training seeds; ≥50 eval episodes per task per condition; paired comparison (shared seeds/init) for three-way ablation; significance test on per-quartile gap. **Pre-register** go/no-go threshold before Phase 1A: matched-architecture anticipatory-vs-reactive gap (input-isolation control) at top arm-accel quartile ≥ frozen $\delta_{1A}$ (below) at $p<0.05$, alongside explicit-vs-implicit margin.

**Quartile stratification methodology (frozen at M0, so per-quartile claim auditable).**
- *Quartile assignment statistic:* episodes stratified by **peak commanded $\|\ddot q_{\text{arm}}\|$ within episode** (planned/anticipatory quantity, not measured, not RMS) - stratifier matches wedge's causal variable. Quartile cut-points computed **once, globally** over pooled eval set (not per-episode, not per-condition), **frozen** before any condition's results read - same accel-bins apply identically across explicit / implicit / reactive arms.
- *Statistical test:* per-quartile explicit-vs-implicit and anticipatory-vs-reactive gaps tested with **paired bootstrap** (shared seeds/init across arms, 10k resamples, two-sided) on per-episode SR difference; headline "concentration in top quartile" claim additionally requires **significant positive trend** of gap across four quartiles (Jonckheere-Terpstra trend test, $p<0.05$).
- *Multiple-comparison correction:* four per-quartile tests (and two ablation arms) corrected with **Benjamini-Hochberg FDR at $q=0.05$**; top-quartile-significance gate read off BH-adjusted p-values. BH (not Bonferroni) pre-registered: quartile tests positively dependent, Bonferroni over-conservative.

**Compute and data budget (well-resourced lab, order-of-magnitude).** Phase 1A: PPO on `humanoid-bench`, ~10 loco-manip tasks × 3 conditions × 3 seeds × ~1e8 env steps (days on few GPUs). CAWM: DINO-WM-scale backbone + heads on multi-GPU node, days to weeks; action-free video pretraining = largest, amortized cost. SysID grounding: few real demos per object/config, ~2 h compute each. Deploy: Jetson Orin at ≥30 Hz. Continual: humanoid continual stream on single node.

> - **PR-3 MSE computation (pooling pinned, ratio = single reproducible scalar).** Wrench-head error = **mean squared error of $\hat\delta_{\text{base}}-\delta_{\text{base}}^{\star}$ over all matched per-step pairs in held-out set**: (1) per timestep, squared error summed over $(6+n_{\text{leg}})$ DoF after **same per-DoF z-score normalization** used in training (high-magnitude base-wrench DoF never dominate leg-torque DoF); (2) **mean over all timesteps within task** (per-timestep mean, not per-trajectory sum, so longer trajectories not over-weighted); (3) **macro-average across held-out contact-rich tasks** (each task weighted equally, single long task cannot dominate pooled number). Numerator + denominator use identical pooling.
> - **PR-3 tactile-available baseline (denominator).** Baseline = **same head evaluated on held-out tasks with tactile/force channel available at inference** (easy, sensor-equipped condition): its pooled MSE (per pooling rule above) = *tactile-available error*. PR-3 numerator = **identical head, identical weights, identical held-out tasks, tactile/force channel removed at inference** (Touch Dreaming's published "w/o Touch" condition on real humanoid; 448-taxel channel zeroed in HumanoidBench sim arm), pooled identically. Gate = ratio sensor-free-MSE / tactile-available-MSE $\le 2$ **AND** significant reduction (paired bootstrap, BH-adjusted $p<0.05$): dropping deploy-time tactile must not more than double forecast error, channel must measurably help. Both numerator + denominator use same $\delta_{\text{base}}^{\star}$ target (measured contact wrench / hand-joint force on real humanoid; analytic `mj_contact` force in HumanoidBench sim arm), so ratio isolates tactile-removal cost.## 7. ### Phase 0 de-risk

> [!abstract] Before any training, kill or confirm the two existential risks
> Whole bet dead-on-arrival two ways regardless of model quality: (a) anticipatory wedge buys no time, reactive observer already fast enough; (b) robot's own coupling inertia not recoverable from real data, grounded target cannot exist. Each gets cheap, falsifiable Phase-0 experiment with pre-registered pass/fail. Both run at M0, before Phase 1A/1C training. Same two failure modes apply to **channel C**, get own M0 sim gates: (a-C) first-100 ms anticipatory window not exceed *composed* onboard loop latency (PR-0a-C); (b-C) contact model / $J_{\text{ext}}$ not recoverable to 15% Frobenius tolerance; per-channel branch table treats each force channel's (a)/(b) outcome independently.

**De-risk (a): observer-latency vs reaction rise-time (kills anticipatory wedge if fails).**
- *Data independence (committed, prevents Phase-0 to Phase-1A leakage).* Both Phase-0 de-risk experiments (a rise-time/dominance, b synthetic recoverability) draw reach trajectories from **dedicated Phase-0-only de-risk task pool, partitioned out of and never entering Phase-1A training or evaluation sets**. Concretely: `humanoid-bench` reach tasks/seeds used to *measure* rise-time, observer-lag, residual budget, synthetic sysID recovery reserved as held-out instrumentation split; Phase-1A training + its OOD eval split exclude them. Keeps Phase 0 genuine *prior* de-risk (informs go/no-go without contaminating result it gates); recorded in Pre-registration block (PR-data).
- *Measurement modality pre-registered BEFORE M0 (PR-0a-modality, breaks observer-is-its-own-ground-truth circularity).* Rise-time/observer-lag comparison of de-risk (a) executed **entirely in sim** at M0, ground truth = MuJoCo exact `mj_fullM`-derived $\delta_{\text{base}}$ (noise-free analytic reference, NOT observer), so Phase-0 gate **non-circular by construction**: timed thing (observer estimate) compared against independent analytic truth, never itself. **Hardware** modality for eventual Seam-3 *verify* also pre-registered now, not deferred: committed modality order on H1: (i) joint-torque sensing if H1 exposes per-joint torque, else (ii) **force plate under feet** (lab-feasible, recommended H1 fallback, assumed modality unless hardware audit shows otherwise). Only if BOTH unavailable on specific H1 unit does ADAPT observer become ground-truth proxy, then used with **quantified observer-noise bounds** (per-DoF residual standard deviation $\sigma_{\text{obs}}$ measured against `mj_fullM` truth in same M0 sim harness, reported as proxy noise floor), so self-referential read impossible: any hardware claim resting on observer-as-proxy stated **only** with $\sigma_{\text{obs}}$ error bar, flagged lower-fidelity. **Decision rule frozen at M0** (recorded as PR-0a-modality in Pre-registration block): force-plate = default Seam-3 modality; observer-as-proxy path permitted **only** with measured $\sigma_{\text{obs}}$ band, never as exact. Makes rise-time/observer-lag comparison executable on H1 regardless of hardware audit outcome, no circular test.
- *Measurement (sim, no hardware needed), frozen instrumentation:* on H1 + G1 in `humanoid-bench`, command top-quartile $\ddot q_{\text{arm}}$ reaches, measure (i) **arm→base reaction rise-time**, (ii) **momentum-observer estimate latency** (ADAPT estimator lag at 500 Hz state-poll, one state step + filter delay). Both read against **analytic `mj_fullM` truth** (not observer), so Phase-0 gate never measures observer with itself. Instrumentation pinned at M0:
  - *Signal / modality:* $\delta_{\text{base}}$ read from MuJoCo exact `mj_fullM`-derived $M_{\text{base,arm}}(q)\,\ddot q_{\text{arm}}$ ground truth (mass-matrix extraction), noise-free reference, **sampled per link at 500 Hz** (state-poll rate). No physical sensor needed in sim; hardware analogue (Seam 3) uses S2R.B ground cluster joint-torque / force-plate modality.
  - *Rise-time definition:* **10%-to-90% rise-time** of $\|\delta_{\text{base}}\|$ from reach onset, extracted by threshold crossing on 500 Hz trace (not peak-derivative), after 40 Hz low-pass suppressing sample noise. Observer-lag = time from same onset to when $\hat\delta_{\text{base}}^{\text{obs}}$ first reaches 90% of true value.
- *Pre-registered pass/fail (numeric, frozen at M0):* **anticipatory wedge claimed ONLY where reaction rise-time $\le$ observer-lag + one policy-step delay**, operationalized: at top-quartile $\ddot q_{\text{arm}}$, measured arm→base 10-90% rise-time must be **$\le$ (observer-lag at 500 Hz) + (one 50 Hz policy step = 20 ms)**; wedge viable only if inequality holds with margin **$\ge$ 5 ms** (one observer-uncertainty band) on **both** H1 and G1. Concretely budget to beat = observer best case: one 500 Hz state step (2 ms) + 40 Hz filter group delay ($\approx$ 4 ms) $\approx$ 6 ms observer-lag, so wedge viable iff reaction rise-time exceeds $\approx$ 26 ms (6 ms observer-lag + 20 ms policy step) by 5 ms margin, i.e. **rise-time $\ge$ 31 ms** at top-quartile accel. If observer next-step estimate already lands inside policy step (rise-time below bound), A1 has no delta, anticipatory framing dropped (fall back to explicit-vs-implicit-only claim).
- *Hardware-dominance / 6th-perspective check (same experiment, numeric ratio):* report **$\delta_{\text{base}}$ magnitude against other unmodeled terms** it competes with: foot-contact reaction, joint friction, actuator-bandwidth residual. Pre-registered numeric gate: at top-quartile $\ddot q_{\text{arm}}$, median $\|\delta_{\text{base}}\|$ must **exceed summed median magnitude of (foot-contact + friction + actuator-bandwidth) residual by $\ge$ 30%** on H1/G1 residual budget. Below 30% dominance ratio = term dominated, claim scoped down before Phase 1A. This is explicit hardware-dominance gate (distinct from identifiability).
- *Interaction with de-risk (b) (branch narratives, pre-registered):* two Phase-0 gates **independent**, both must clear for *full* program; branch table fixes each combination, no post-hoc reinterpretation possible.
  - *(a) pass, (b) pass:* full program proceeds (anticipatory + sysID-grounded).

De-risked core (sim falsifier + $\varepsilon$-curve) unaffected.
  - *(a) fail, (b) pass* (identifiable inertia, no anticipatory margin): **drop anticipatory framing**, fall back to explicit-vs-implicit-only claim; grounded explicit term still contribution (sysID-grounded explicit coupling head beating implicit on $\varepsilon$-curve), just not "anticipatory beats reactive".

**De-risk (b): inertia identifiability (gates Phase 2).**
- *Excitation design:* borrow [[2404.12308|ASID]] exploration-to-identify to design arm-reach excitation trajectories maximizing observability of $M_{\text{base,arm}}$, run **per contact mode** (use head's mode logits) so sliding/sticking regimes not mixed. Per-contact-mode identification, pinned:

Mode-logit classifier used *only on real data* (Phase 2), where ground-truth mode labels absent, purely to *segment* windows. **Sequencing (committed, non-circular):** PR-0b (M0, sim) uses sim labels; classifier Phase 2 needs = **lightweight standalone contact-mode classifier trained at start of Phase 2 on Phase-0 sim-labeled data** (small supervised head on proprio + tactile, NOT CAWM WAM, which not exist yet at Phase 0/early Phase 2). Earlier "trained in Phase 1A" reading retired: Phase 0 needs no classifier; Phase 2 classifier trained from sim labels before Phase 2 identification, so no future artifact required by earlier phase.
  - *Misclassification handling:* trajectory window admitted to mode's identification batch only if mode label (sim) or mode-logit confidence (real) stable **$\ge$ 3 consecutive 50 Hz steps**; windows straddling mode transition **discarded**, not assigned either mode, so misclassified boundary step cannot corrupt either mode's $\hat M_{\text{base,arm}}$.
  - *Logit stabilization:* during ~2 h real identification budget contact-mode classifier **frozen** (trained once on Phase-0 sim labels before Phase-2 identification, per sequencing above), so logit drift cannot move segmentation mid-identification; identification and classifier-update never interleaved.
  - *Classifier sim-to-real fallback (PR-0b-classifier, pre-registered, so classifier not unvalidated dependency).* Contact-mode classifier = **sim-trained head deployed on real data**, transfer itself a risk. **Pre-registered check + fallback frozen at M0:** at Phase 2 start, validate sim-trained classifier on small **real-labeled holdout** (tactile/contact-force thresholding gives real mode label on few hundred manually-segmented real steps); require classifier real-holdout accuracy $\ge$ **90%** before trusted to segment. **Fails 90% bar: frozen fallback = single-mode identification** (drop per-mode segmentation, identify one $\hat M_{\text{base,arm}}$ pooled across modes, accepting wider PR-0b sim-identifiability Frobenius tolerance / larger single-mode identification error) **or direct tactile-threshold segmentation** (no learned head, segment by raw contact-force magnitude), whichever yields lower single-mode identification error on real holdout. Classifier never hard dependency: failure mode pre-registered, not discovered at Phase 2.
- *Simulated sysID recoverability test (MuJoCo synthetic, no hardware):* plant **known** perturbed $\tilde M$ in MuJoCo, generate trajectories under excitation design, run D-REX / gradSim differentiable-sysID loop to recover $\hat M_{\text{base,arm}}$, compare to planted ground truth.
- *Pre-registered pass/fail (GATES Phase 2):* recovery error $\le \mathbf{15\%}$ **Frobenius** of planted $M_{\text{base,arm}}$ under chosen excitation + ~2 h budget. **Below threshold $\Rightarrow$ Phase 2 (real grounding) proceeds**; above threshold $\Rightarrow$ term non-identifiable, **fallback = analytic $M_{\text{base,arm}}\,\ddot q_{\text{arm}}$ term (from URDF / nominal inertia) + broad domain randomization**, sysID-grounding seam (Seam 2) dropped for that platform.

## 9. Risks and mitigation

> [!warning] Every branch yields a result
> - **Explicit ≈ implicit** (falsifier fails, per channel): still own definitive three-way explicit/observer/implicit ablation with $\varepsilon$-sweep, each channel independent.
> - **Wrong inertia or contact model poisons term**: mitigated by S2R.B ground cluster (inertia for A, contact model / $J_{\text{ext}}$ for C); fallback = that channel's implicit baseline.
> - **Hardware-dominant physics**: foot-contact/friction/actuator-bandwidth may swamp inertial term. Instrument real residual budget first; report $\delta_{\text{base}}$ magnitude vs other unmodeled terms before claiming dominance. Per upstream **H8**, take decomposition at worst instant (maximum CoM excursion), not only top-quartile acceleration: if foot-contact / support-polygon-transition share dominates there, inertial term mis-specified, channel A reframes as contact-constrained hybrid-dynamics prediction. Foot-ground / terrain contact = this pre-gate question, not separate predicted channel. Scope: channels A + C evaluated on flat / known ground with fixed nominal support polygon; non-flat terrain + support-polygon transitions enter only via H8 worst-instant decomposition, not separate evaluation axis (consistent with flat-ground humanoid benchmarks used: HumanoidBench balance/manipulation + BiGym).
> - **Engine-floor error survives grounding gate** (distinct from wrong model): [[2608.05948|GAUGE]] shows physics engines given *ground-truth-calibrated* parameters still show order-of-magnitude errors on dynamic contact + deformation; video world models hit near-perfect trajectory fit while inferring free-fall acceleration under 1% of gravity — so even channel clearing S2R.B grounding gate can forward-simulate wrong: simulator's own solver has regime-dependent error grounding step not touch. Sharpens **H8**: GAUGE worst regime = dynamic contact = exactly H8 target, so H8 budgets for engine-floor error, not only model mis-specification.
> - **Base↔arm factoring buys little, or decode adds latency** (channel B): autoregressive base→torso→arm win may live only on reach-extension stratum; if task distribution rarely needs in-task base repositioning, stratum thin, pooled margin dilutes; sequential base→torso→arm decode can also cost latency at deploy. Mitigation: report B margin **stratified by reach-extension vs fixed-base** (PR-1B), never pooled; parallelize/distill chunked decode if latency bites; either way definitive autoregressive-vs-flat ablation still ships.
> - **Coupling unidentifiable** (distinct from dominance): $M_{\text{base,arm}}$ may not be recoverable from few demos given entangled excitation; gate Phase 2 on identifiability check (S2R.B ground cluster), fall back to broad DR or implicit baseline if fails.
> - **WAM too slow for contact**: mitigated by async decoupling + quantization clearing 30 Hz floor; report SR-vs-Hz Pareto honestly.
> - **Two-rate/two-clock plumbing**: coupling term consumed at policy rate (30 to 50 Hz); if kHz WBC feedforward required it cannot come from WAM, fall back to analytic $M_{\text{base,arm}}\,\ddot q_{\text{arm}}$ term at WBC rate (see Grounding).
> - **Force-under-load first-100 ms hostage to composed loop latency** (channel C): C headline = transient measured across external-wrench-estimate → forward-model → leg-torque loop; price whole onboard budget (observer settling + inference + actuator bandwidth, PR-0a-C); if it eats 100 ms window, move C headline to steady-state max-load number. If contact model / $J_{\text{ext}}$ unidentifiable or [[2505.06776|FALCON]] implicit curriculum already suffices, that *is* C falsifier: fall back to reactive/curriculum baseline, report definitive anticipatory-vs-reactive ablation.
