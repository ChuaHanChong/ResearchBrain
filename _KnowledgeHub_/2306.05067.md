# Improving Visual Prompt Tuning for Self-supervised Vision Transformers

> [!summary] Summary
> Researchers at Seoul National University developed Gated Prompt Tuning, an adaptive method that allows prompt tokens to selectively interact with specific Vision Transformer blocks, enhancing transfer learning performance for self-supervised models. The approach consistently improved accuracy on classification and segmentation benchmarks, outperforming standard Visual Prompt Tuning methods while often using fewer parameters.

## Problem

- Visual Prompt Tuning (VPT) frequently underperforms when adapting self-supervised Vision Transformers (SSL ViTs) to downstream tasks.
- The optimal ViT blocks for prompt token interaction vary significantly depending on the SSL pretraining method and the specific downstream task.
- Manually identifying these optimal interaction locations for each combination of SSL ViT and task is computationally expensive and impractical.

## Method

- A **Gated Prompt Tuning** mechanism introduces ==learnable gates== that dynamically control the intervention of each ViT block on a single set of prompt tokens.
- Prompt representations are aggregated as a ==weighted sum==, where ==sigmoid-activated gates== determine the influence of each block's output.
- ==Adaptive Attention Shaping== further refines self-attention by incorporating ==learnable temperatures== within each ViT block to better encode task-specific instructions.

## Results

- Gated Prompt Tuning consistently surpassed VPT-shallow and often VPT-deep across FGVC and VTAB-1K classification benchmarks for both MAE and MoCo v3 backbones.
- The method achieved an average accuracy of **73.39%** for MAE on FGVC, exceeding VPT-deep's **72.02%**, and improved mIoU on ADE20K semantic segmentation (e.g., **38.44** SS mIoU for MAE).
- Analysis of learned gates demonstrated adaptive block selection, with varying selection ratios based on the downstream task and SSL method, confirming the mechanism's effectiveness.

## Takeaways

> [!tip] Key Insights
> - The information hierarchy within SSL ViTs differs from supervised models, with task-relevant information often concentrated in varying blocks depending on the pretraining method.
> - Dynamically learned gates can adaptively identify and leverage these task-relevant blocks, leading to more effective prompt-based adaptation.
> - Modulating self-attention with learnable temperatures allows for sharper or smoother attention patterns, aiding prompts in generating more beneficial task-specific instructions.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This work is situated within the broader context of transfer learning for large-scale Vision Transformers (ViTs), particularly focusing on models pretrained using self-supervised learning (SSL). Self-supervised learning with ViTs has demonstrated considerable success across various visual recognition tasks, showcasing strong scalability and generalizability compared to purely supervised models. However, the efficacy of these SSL ViTs is substantially influenced by the chosen transfer learning strategy. Existing transfer methods range from full fine-tuning, which updates all model parameters, to more parameter-efficient techniques like linear probing, which only trains a classification head.

Visual Prompt Tuning (VPT) is a parameter-efficient transfer learning technique originally inspired by prompt-based methods in Natural Language Processing (NLP). VPT adapts pretrained models to downstream tasks by prepending learnable "prompt tokens" to the input sequence, which then steer the frozen pretrained encoder. While VPT has been effective for supervised ViT backbones, it has shown comparative underperformance when applied to self-supervised Vision Transformers. This observed discrepancy highlights a gap in current prompt-based transfer strategies for SSL ViTs, where the unique properties of self-supervised representations may not be optimally exploited by standard VPT implementations. This paper aims to address this specific limitation, seeking to enhance the performance of prompt tuning for self-supervised Vision Transformers.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop an improved prompt-based transfer learning method that enhances the performance of Visual Prompt Tuning (VPT) when applied to self-supervised Vision Transformers (SSL ViTs).

The motivation for this work stems from several key observations:
- **VPT's Underperformance with SSL ViTs:** Despite its success with supervised ViTs, VPT frequently exhibits diminished performance when adapting SSL ViTs to downstream tasks. This suggests a mismatch between the standard VPT approach and the characteristics of representations learned through self-supervision.
- **Empirical Observation of Block-Dependent Performance:** Through empirical experiments (illustrated in Figure 1), the authors observed that the performance of VPT with SSL ViTs (specifically MAE and MoCo v3) on image classification tasks significantly varies depending on which Transformer blocks the prompt tokens are allowed to interact with. For instance, performance improved when prompt tokens interacted with later blocks (e.g., 11th block for MAE, 8th block for MoCo v3), indicating the existence of an optimal location for prompt token insertion or interaction. A performance gap of up to 36.4% was observed for MAE based on this factor.
- **Varying Information Hierarchies in Pretrained Models:** The authors posit that the "pretrained knowledge" embedded within ViT blocks differs based on the pretraining strategy. Using Deep Image Prior (DIP) analysis (Figure 2), they illustrate that supervised ViTs tend to discard more information in later blocks, while SSL ViTs (MoCo v3, MAE) retain richer information throughout their layers. Furthermore, even different SSL methods exhibit variations in information content across blocks (e.g., MoCo v3 showing a decrease in color information after middle blocks compared to MAE). Consequently, the specific blocks containing task-relevant information are expected to vary depending on the self-supervised pretraining method.
- **Task-Dependent Relevant Information:** Beyond pretraining, the nature of task-relevant information also varies with the downstream task. For example, fine-grained classification (CUB dataset) requires different features than distance estimation (KITTI dataset). This implies that the desirable blocks for prompt interaction can change based on the specific task, even for the same pretrained model (as shown in Figure 1, where optimal prompt locations differ between CUB and KITTI for the same SSL ViT).
- **Cost of Manual Optimization:** Manually identifying the optimal blocks for prompt insertion or interaction for every combination of SSL ViT, pretraining strategy, and downstream task is computationally expensive and impractical.

Therefore, the core motivation is to overcome the limitations of fixed-interaction VPT by proposing a method that can automatically and adaptively determine which ViT blocks should influence the prompt tokens, allowing prompts to selectively focus on task-relevant information and thereby unlock the full potential of prompt tuning for self-supervised Vision Transformers.

### 3. Methodology and Approach

The proposed methodology, termed **Gated Prompt Tuning**, introduces learnable gates and adaptive attention shaping to allow prompt tokens to selectively interact with desirable ViT blocks for task adaptation.

#### 3.1. Gated Prompt Tuning (GPT)

The core idea is to introduce learnable gates that adjust the intervention of each ViT block into the prompt tokens. Unlike VPT-shallow, which inserts prompts only once at the input, or VPT-deep, which inserts independent prompt sets into each block, Gated Prompt Tuning processes a single set of prompt tokens (similar to VPT-shallow) but with dynamic interaction control.

- **Gate Mechanism:** The method defines a set of scalar "gate priors" Γ = [γ_1..., γ_{L-1}] for all blocks except the last. Each gate prior γ_l is transformed into a gate value g_l using a sigmoid function: g_l = 1 / (1 + e^{-γ_l}). These gate values range between 0 and 1.
- **Gating Operation:** For each l-th block, the prompt representation Z_l^P passed to the subsequent (l+1)-th block is calculated as a convex combination of the prompt representation *before* the l-th block (Z_{l-1}^P) and the prompt representation *after* the l-th block (˜Z_l^P). Specifically, Z_l^P = g_l ⋅ ˜Z_l^P + (1 - g_l) ⋅ Z_{l-1}^P.
 - If g_l is close to 1, the prompt representation is primarily influenced by the current block's output (˜Z_l^P), allowing strong interaction.
 - If g_l is close to 0, the prompt representation largely bypasses the current block's influence, carrying over the prompt representation from the previous block (Z_{l-1}^P).
- **Selective Aggregation:** This gating operation results in a selective aggregation of output prompt representations from different ViT blocks. The input prompt representation for the last block (Z_{L-1}^P) can be expressed as a weighted sum of the initial prompt tokens (P) and the output prompt representations (˜Z_l^P) from all intermediate blocks, where the weights (defined as ˜g_l) are dynamically learned by the gates. This allows the model to learn to focus on blocks that contribute most beneficially to task adaptation.
- **Parameter-Efficiency:** Only the gate priors (Γ), the initial prompt tokens (P), and the classification head are trainable, keeping the pretrained ViT encoder frozen.

#### 3.2. Adaptive Attention Shaping

As an additional mechanism to enhance task-adaptability, the method introduces learnable temperatures for the self-attention mechanism within each ViT block.
- **Learnable Temperature:** A set of scalar values T = [τ_1..., τ_L] is defined, where each τ_l adjusts the attention score in the self-attention operation of the corresponding l-th block. The attention score a_l is modified to a_l = Softmax(Q_l K_l^T / τ_l).
- **Purpose:** These learnable temperatures reshape the blocks' self-attentions, making them sharper (lower τ_l) or smoother (higher τ_l). This mechanism is intended to help prompts encode more beneficial task-specific instructions by modulating how tokens attend to each other.

#### 3.3. Comparison with VPT

- **VPT-shallow:** Equivalent to Gated Prompt Tuning if all gates g_l are fixed to 1 and no learnable temperatures are used. It does not selectively interact with blocks.
- **VPT-deep:** Uses independent learnable prompt token sets for each block. While it allows block-wise task relevance, these prompts provide average task-relevant instructions and do not inherently allow for sample-specific instruction.
- **Gated Prompt Tuning:** Combines advantages by selectively interacting with blocks (via gates) and allowing for sample-specific but task-relevant instructions, as the prompt representation for each block is conditioned on the patch representations from the preceding block.

#### 3.4. Experimental Setup

- **Self-supervised ViT Backbones:** Experiments utilize two prominent SSL ViTs: MAE (Masked Autoencoder) and MoCo v3, both based on ViT-B/16 architecture pretrained on ImageNet-1K.
- **Downstream Tasks:**
 - **Image Classification:**
 - FGVC (Fine-Grained Visual Classification) benchmark: CUB, Oxford Flowers, Stanford Cars, Stanford Dogs, NABirds.
 - VTAB-1K benchmark: 19 diverse visual classification tasks categorized into Natural, Specialized, and Structured groups.
 - **Semantic Segmentation:** ADE20K dataset, using SETR-PUP (a ViT-based segmentation model) as the segmentation framework.
- **Metrics:** Accuracy for classification, mean Intersection over Union (mIoU) for semantic segmentation.
- **Baselines:** VPT-shallow and VPT-deep from the original VPT paper.

### 4. Main Findings and Results

The research presents several findings demonstrating the effectiveness of Gated Prompt Tuning across diverse tasks and SSL ViTs.

#### 4.1. Classification on FGVC (Fine-Grained Visual Classification)

- The proposed method consistently outperformed VPT-shallow across all five datasets for both MAE and MoCo v3 backbones, indicating that selective interaction significantly improves prompt token efficacy.
- For MAE, Gated Prompt Tuning achieved a higher average accuracy (73.39%) compared to VPT-deep (72.02%) while using a similar total number of parameters. It surpassed VPT-deep in nearly all individual datasets.
- For MoCo v3, Gated Prompt Tuning (83.00% average accuracy) showed performance comparable to VPT-deep (83.12% average accuracy), despite VPT-deep utilizing 20% more prompt tokens (120 vs. 100). This suggests improved parameter efficiency.
- Additional experiments with fewer prompt tokens further highlighted the method's efficiency, outperforming VPT-deep with half the number of tokens.

#### 4.2. Classification on VTAB-1K

- On the VTAB-1K benchmark, Gated Prompt Tuning demonstrated substantial gains over both VPT-deep and VPT-shallow across all three task groups (Natural, Specialized, Structured) for MAE.
- For MoCo v3, the method provided considerable performance boosts, particularly in the Natural and Structured groups.
- The largest performance improvements were observed in the Structured group (10.23% for MAE and 6.72% for MoCo v3 over VPT-deep), suggesting that the method is effective even when image domains differ or require structural understanding.

#### 4.3. Semantic Segmentation on ADE20K

- For the ADE20K semantic segmentation task, Gated Prompt Tuning achieved higher mIoU scores (38.44 mIoU SS, 39.81 mIoU MS for MAE; 36.81 mIoU SS, 38.55 mIoU MS for MoCo v3) compared to both VPT-shallow and VPT-deep.
- This performance was achieved with fewer prompt tokens than VPT-deep (100 vs. 120), indicating more effective utilization of prompt tokens in dense prediction tasks.

#### 4.4. Additional Analysis

- **Analysis on Learned Gates:** The learned "selection ratios" (r_l), representing the influence of each block on the final prompt representation, varied significantly across different downstream tasks and SSL methods (Figure 4). For example, MAE on NABirds focused primarily on the 11th block, while on Stanford Cars, it focused almost equally on the 4th and 11th blocks. MoCo v3 on NABirds and Stanford Cars tended to focus on the 10th block. For ADE20K segmentation, learned prompts exhibited more uniform ratios across blocks, which the authors interpret as beneficial for tasks requiring multi-level information. These results empirically support the motivation that task-relevant blocks vary and gates adaptively leverage this.
- **Adjusted Self-attention:** Visualizations of self-attention maps (Figure 5) indicated that both Gated Prompt Tuning and Adaptive Attention Shaping modify the attention patterns within the ViT blocks. For instance, MAE with Gated Prompt Tuning attended to the object's head in a late block, whereas baseline MAE attended to the object's boundary. This suggests that the proposed mechanisms aid in steering the ViT's attention to task-relevant regions.

#### 4.5. Ablation Studies

- **Efficacy of Gated Prompt Tuning:** Introducing Gated Prompt Tuning (GATE) consistently improved performance over VPT-shallow across all benchmarks and SSL ViTs. This validates that selective interaction with ViT blocks, rather than uniform interaction, enhances prompt token effectiveness for task adaptation.
- **Efficacy of Adaptive Attention Shaping:** Further adding Adaptive Attention Shaping (LT) generally resulted in additional performance improvements in most scenarios, confirming its role in aiding prompts to encode better instructions by modulating self-attention.
- **Soft vs. Hard Gates:** Experiments with hard gates (implemented via Gumbel-Sigmoid) showed improvements over VPT-shallow but underperformed the proposed soft gates. This suggests that allowing partial interaction with blocks (soft gates) is more beneficial than binary exclusion, as some blocks might be partially task-relevant.
- **Parameter Efficiency:** The proposed method demonstrated superior parameter efficiency compared to VPT-deep, achieving higher accuracy with fewer prompt tokens (e.g., outperforming VPT-deep with 48 tokens using only 24 tokens on Stanford Cars).

### 5. Significance and Potential Impact

This research introduces a method that addresses a known challenge in adapting Visual Prompt Tuning (VPT) to self-supervised Vision Transformers (SSL ViTs). The contributions and potential impact are multifaceted:

- **Improved Transferability for SSL ViTs:** The work demonstrates that by adaptively controlling the interaction between prompt tokens and different ViT blocks, the efficacy of prompt tuning for SSL ViTs can be substantially improved. This unlocks the potential of prompt tuning as a more universal and effective transfer strategy for this class of powerful pretrained models.
- **Reduced Manual Optimization:** By proposing a learnable gating mechanism, the method mitigates the need for costly manual investigation to identify optimal prompt insertion locations for different SSL methods and downstream tasks. This automation makes prompt tuning more practical and scalable.
- **Enhanced Parameter Efficiency:** The proposed Gated Prompt Tuning achieves competitive or superior performance compared to VPT-deep while often utilizing fewer prompt tokens. This is significant for deploying large models in resource-constrained environments or for scenarios where minimizing additional trainable parameters is crucial.
- **Deeper Understanding of Prompt-Model Interaction:** The analysis of learned gate values and adjusted self-attention maps provides insights into how prompts can selectively leverage information hierarchies within different layers of SSL ViTs. This understanding can inform future research in prompt design and parameter-efficient tuning.
- **Broad Applicability:** The method's effectiveness across various vision tasks, including fine-grained classification, diverse general classification, and semantic segmentation, indicates its broad applicability beyond specific task domains.
- **Advancement in Parameter-Efficient Tuning:** The introduction of a gating operation for prompt tokens in computer vision, distinctly different from prior scaling operations in parameter-efficient fine-tuning (e.g., AdaptFormer) or prompt gating in NLP, represents an advancement in the field of efficient adaptation techniques for large neural networks.

In summary, this work contributes to making self-supervised Vision Transformers more accessible and performant for a wider range of downstream tasks through an adaptive and parameter-efficient prompt tuning strategy.
