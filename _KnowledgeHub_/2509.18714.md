# A Generalized Bisimulation Metric of State Similarity between Markov Decision Processes: From Theoretical Propositions to Applications

> [!summary] Summary
> Researchers at Southeast University and Purple Mountain Laboratories developed a Generalized Bisimulation Metric (GBSM) for quantifying state similarity between distinct Markov Decision Processes. This metric is rigorously proven to possess fundamental metric properties and enables the derivation of strictly tighter theoretical bounds for policy transfer regret, state aggregation error, and sampling-based estimation error, along with a closed-form sample complexity expression, compared to prior bisimulation-based methods.

## Problem

- The traditional bisimulation metric (BSM) quantifies state similarity only within a single Markov Decision Process (MDP), limiting its direct application to theoretical analyses involving multiple MDPs.
- Prior attempts to extend BSM for multi-MDP comparisons often resulted in high computational costs, loose error bounds, and the loss of essential pseudometric properties like symmetry and the triangle inequality.
- There was a lack of rigorous theoretical guarantees for the long-term impacts of policy transfer and no explicit sample complexity expressions for estimating state similarities in multi-MDP contexts.

## Method

- Formally defined **GBSM** as a recursive function using the ==1-Wasserstein== distance between transition probabilities and the absolute difference in rewards, allowing comparison between a state in one MDP and a state in another.
- Rigorous proofs established that GBSM possesses fundamental metric properties: symmetry (d(s,M1), (s',M2)) = d((s',M2), (s,M1)), an inter-MDP triangle inequality, and a distance bound on identical state spaces.
- Applied the established GBSM properties to derive new, tighter theoretical bounds for policy transfer regret, value function approximation (VFA) and state similarity approximation (SSA) in aggregated MDPs, and sampling-based estimation with an explicit sample complexity expression.

## Results

- GBSM was formally proven to exist as a unique fixed point and demonstrated to provide an upper bound on the difference between optimal value functions: |V*_1(s) - V*_2(s')| ≤ d_1-2(s, s').
- Derived a policy transfer regret bound with a computational complexity of O(|S1|*|S2|), which is an improvement over the O(|S1+S2|^2) complexity of methods relying on disjoint union state spaces.
- Achieved strictly tighter theoretical error bounds for Value Function Approximation (VFA) in aggregated MDPs (˜σ1/(1-γ)) and State Similarity Approximation (SSA) aggregation (2˜σ1/(1-γ)) compared to existing BSM-based bounds, and provided a closed-form sample complexity expression for SSA estimation.
- Numerical experiments on random Garnet MDPs consistently validated that GBSM-based bounds were strictly tighter across all tested applications (policy transfer regret, SSA, VFA) compared to previous BSM-based bounds.

## Takeaways

> [!tip] Key Insights
> - By defining GBSM using the 1-Wasserstein distance, the core metric properties (symmetry, triangle inequality) are preserved when comparing states across distinct MDPs, addressing a key limitation of prior multi-MDP adaptations.
> - GBSM provides a direct upper bound for the difference between optimal value functions of states in different MDPs, establishing a strong theoretical link between state similarity and value function disparities.
> - The derivation of an explicit, closed-form sample complexity for GBSM estimation offers practical guidance on data requirements, moving beyond previous asymptotic results for achieving desired accuracy.
