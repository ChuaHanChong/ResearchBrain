# WebWatcher: Breaking New Frontier of Vision-Language Deep Research Agent

> [!summary] Summary
> WebWatcher is a multimodal deep research agent developed by Alibaba's Tongyi Lab, integrating vision-language reasoning with autonomous multi-tool interaction to process complex web information. The agent achieves state-of-the-art performance on several challenging multimodal benchmarks, including a new BrowseComp-VL benchmark designed for multi-page web browsing and fine-grained visual grounding.

## Problem

- Existing deep research agents are primarily text-centric, overlooking crucial visual information essential for many real-world web and research tasks.
- Current multimodal Visual Question Answering (VQA) benchmarks and models often lack the depth of reasoning, multi-step planning, and cross-modal integration required for advanced agent capabilities.
- There is a scarcity of high-quality, complex multimodal training data and benchmarks that demand autonomous, multi-tool interaction for deep research agents.

## Method

- Developed **WebWatcher**, a multimodal ==Deep Research Agent== equipped with external tools like web image search, web text search, webpage visiting, and a code interpreter, along with internal OCR.
- Introduced BrowseComp-VL, a novel VQA benchmark and a scalable data generation pipeline for creating synthetic, high-quality multimodal training data with complex multi-hop reasoning requirements.
- Trained the agent using a two-stage approach: Supervised Fine-Tuning (SFT) on auto-annotated, quality-filtered tool-use trajectories, followed by Reinforcement Learning (RL) using Group-Relative Policy Optimization (GRPO).

## Results

- WebWatcher-**32B** achieved a state-of-the-art score of **13.6%** Pass@1 on Humanity’s Last Exam (HLE-VL), outperforming GPT-4o's direct inference (**6.5%**) and RAG-based workflows (**12.3%**).
- On the new BrowseComp-VL benchmark, WebWatcher-**32B** scored **27.0%** Pass@1, significantly higher than GPT-4o RAG (**13.4%**) and OmniSearch (**16.3%**), demonstrating superior performance on complex web browsing tasks.
- Analysis of tool calls showed WebWatcher adaptively uses tools, with high reliance on Web Text Search and Visit for BrowseComp-VL (**62.1%** and **23.3%** respectively) and a shift towards Web Image Search for visually-centric tasks like LiveVQA and MMSearch.

## Takeaways

> [!tip] Key Insights
> - An SFT-based cold start is critical for stable and effective Reinforcement Learning, providing a robust foundation for agents to learn complex, multi-step tool-use sequences.
> - WebWatcher demonstrates adaptive utilization of its diverse set of multimodal tools, dynamically adjusting its strategy based on the specific demands and modality of different tasks.
> - The use of a multi-stage quality control process for both generated VQA data and tool-use trajectories is essential for producing high-quality supervision signals and enabling deep reasoning.
