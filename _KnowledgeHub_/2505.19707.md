# MLLM-Guided VLM Fine-Tuning with Joint Inference for Zero-Shot Composed Image Retrieval

> [!summary] Summary
> The MVFT-JI framework introduces a method for Zero-Shot Composed Image Retrieval by directly fine-tuning a Vision-Language Model using synthetic supervision generated by a Multimodal Large Language Model. This approach eliminates the need for manual annotations while consistently outperforming state-of-the-art methods across FashionIQ, CIRCO, and CIRR benchmarks.

## Problem

- Traditional image retrieval methods struggle with nuanced queries combining a reference image with textual modifications (e.g., 'this shirt, but in blue').
- Composed Image Retrieval (CIR) methods typically rely on expensive, manually annotated datasets of reference image, modifying text, and target image triplets.
- Existing Zero-Shot CIR (ZS-CIR) approaches suffer from a deficiency in capturing rich visual semantics (often relying on pseudo-text tokens) and use indirect supervision paradigms.

## Method

- MVFT-JI generates ==synthetic training data== for composed image retrieval using an MLLM (MiniCPM-V-2_6), creating target text retrieval triplets and text-to-image pairs from unlabeled images.
- A ==Q-Former-based Vision-Language Model (VLM)==, initialized with BLIP2, is directly fine-tuned with ==dual InfoNCE losses== for both target text retrieval and text-to-image retrieval tasks.
- During inference, the framework employs a ==joint inference strategy== that combines direct compositional matching from the fine-tuned VLM with an MLLM-augmented reasoning signal derived from MLLM-generated target descriptions.

## Results

- MVFT-JI achieved **34.84%** R@10 on FashionIQ, an improvement of **~7-10%** over the previous best (MLLM-I2W: **27.3%**).
- The framework attained **39.30%** R@1 on CIRR, an **11%** absolute gain over MCL (**26.22%**).
- On CIRCO, MVFT-JI achieved **21.69%** mAP@5, improving by **3.12%** over CIReVL (**18.57%**).

## Takeaways

> [!tip] Key Insights
> - A theoretical decomposition of the retrieval probability reveals two complementary tasks - text-to-image retrieval and target text retrieval, both addressed during training - with the Target Text Retrieval task proving more critical for overall performance than the Text-to-Image Retrieval task.
> - MLLM-generated synthetic supervision enables direct fine-tuning of a Vision-Language Model (VLM) for zero-shot composed image retrieval, eliminating the need for manual annotations.
> - The joint inference strategy, combining direct VLM compositional matching with MLLM-augmented reasoning (generating target descriptions), is crucial for achieving high retrieval performance.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

#### 1.1. Introduction

The MVFT-JI framework addresses a fundamental challenge in image retrieval: enabling users to search for images by combining a reference image with textual modifications, such as "this shirt, but in blue" or "this room, but with better lighting." This capability, known as Zero-Shot Composed Image Retrieval (ZS-CIR), has significant applications in e-commerce, creative design, and content discovery.

The key innovation of MVFT-JI lies in its approach to training. Rather than relying on expensive manually-annotated datasets or using indirect methods like adapter-based approaches, the framework directly fine-tunes a Vision-Language Model (VLM) using synthetic supervision generated by a Multimodal Large Language Model (MLLM). This approach eliminates the need for manual annotations while achieving superior performance across multiple benchmarks.

### 2. Key Objectives and Motivation

#### 2.1. Background and Problem Statement

Traditional image retrieval methods fall into two categories: content-based retrieval (matching visual features) and text-based retrieval (matching textual queries to captions). However, these approaches struggle when users need to express nuanced modifications to existing images. Composed Image Retrieval (CIR) emerged to address this limitation by allowing queries that combine a reference image with modifying text.

The challenge with conventional CIR methods is their dependency on manually annotated triplets of `<reference image, modifying text, target image>`. Creating such datasets is expensive and time-consuming, leading to the development of Zero-Shot CIR (ZS-CIR) methods that aim to perform retrieval without manual annotations.

Existing ZS-CIR approaches face two critical limitations:

1. **Semantic Nuance Deficiency**: Many methods rely on converting images to "pseudo-text tokens" that often fail to capture rich visual semantics
2. **Indirect Supervision**: Training paradigms don't directly optimize the alignment between composed queries and target images

### 3. Methodology and Approach

#### 3.1. Methodology Overview

MVFT-JI introduces a novel paradigm that directly addresses these limitations through a theoretically grounded approach combining MLLM-guided data synthesis with direct VLM fine-tuning.

#### 3.2. Theoretical Foundation

The framework is built on a theoretical decomposition of the retrieval probability. For a composed query `(x_i, m_i)` (reference image and modification text) and target image `x_t_i`, the goal is to maximize `P(x_t_i | x_i, m_i; θ)`.

The authors introduce a "latent semantic assumption": for every composed query, there exists a latent textual description `t_i` that precisely describes the target image's semantic intent. Using the law of total probability:

```
P(x_t_i | x_i, m_i; θ) = Σ P(x_t_i | t_i; θ) × P(t_i | x_i, m_i; θ)
```

This decomposition reveals two complementary tasks:
- **Text-to-Image Retrieval**: `P(x_t_i | t_i; θ)` - learning to retrieve images from textual descriptions
- **Target Text Retrieval**: `P(t_i | x_i, m_i; θ)` - learning to generate appropriate descriptions for composed queries

#### 3.3. Training Data Generation

The framework automatically generates training data from unlabeled images using an MLLM (MiniCPM-V-2_6). The process creates two types of synthetic data:

**Target Text Retrieval Data**: For each image `x_i`:
1. Generate modification text `m_i` using prompt `P_m`
2. Generate target description `t_i` using the image, modification text, and prompt `P_tt`
3. Create triplet `(x_i, m_i, t_i)`

**Text-to-Image Retrieval Data**: For each image `x_i`:
1. Generate detailed caption `c_i` using prompt `P_c`
2. Create pair `(c_i, x_i)`

The MLLM prompts are carefully designed to generate diverse, high-quality synthetic supervision without requiring manual intervention.

#### 3.4. Fine-Tuning Framework

The framework uses a Q-Former-based VLM initialized with BLIP2 (ViT-L/14). The fine-tuning process involves:

**Feature Extraction**: Learnable query tokens with Q-Former blocks extract representations for:
- Composed queries `(x_i, m_i)` → feature tokens `f_Q_i_j`
- Target texts `t_i` → feature tokens `f_T_i_j`
- Image captions `c_i` → feature tokens `f_C_i_j`
- Images `x_i` → feature tokens `f_I_i_j`

**Training Objectives**: The model is trained with InfoNCE losses for both tasks:
- `L_t` (Target Text Retrieval Loss): Maximizes similarity between composed queries and target texts
- `L_c` (Text-to-Image Retrieval Loss): Maximizes similarity between captions and images

The combined loss `L = L_t + L_c` enables the VLM to learn compositional retrieval capabilities.

#### 3.5. Joint Inference Strategy

During inference, MVFT-JI combines two complementary similarity signals:

1. **Direct Compositional Matching**: The fine-tuned VLM computes similarity `s_hat_qj` between query `(x_q, m_q)` and candidate images
2. **MLLM-Augmented Reasoning**: The MLLM generates target description `t_q` from the query, then computes similarity `s_tilde_qj` between this description and candidates

The final retrieval score combines both signals: `s_qj = 0.5 × (s_hat_qj + s_tilde_qj)`

### 4. Main Findings and Results

#### 4.1. Results and Evaluation

MVFT-JI was evaluated on three benchmark datasets: FashionIQ, CIRCO, and CIRR, consistently outperforming state-of-the-art methods.

**Key Performance Improvements**:
- **FashionIQ**: Achieved 34.84% R@10, improving ~7-10% over previous best (MLLM-I2W: 27.3%)
- **CIRR**: Achieved 39.30% R@1, an 11% absolute gain over MCL (26.22%)
- **CIRCO**: Achieved 21.69% mAP@5, improving 3.12% over CIReVL (18.57%)

**Ablation Study Insights**:
- Joint inference strategy is crucial - removing either similarity component degrades performance
- Target Text Retrieval Task (`L_t`) is more critical than Text-to-Image Retrieval Task (`L_c`)
- MLLM quality significantly impacts synthetic data quality and final performance
- Prompt design notably influences the diversity and quality of generated data

### 5. Significance and Potential Impact

#### 5.1. Limitations and Future Work

The primary limitation stems from the framework's reliance on MLLM-generated supervision. MLLMs can produce hallucinations or errors that introduce noise into the training data, potentially hindering retrieval performance. Future work should explore strategies to mitigate noisy synthetic supervision and enhance reliability.

Additionally, the framework inherits potential biases from pre-trained MLLMs, which could propagate through the synthetic supervision into the final retrieval model. Incorporating bias auditing and transparency tools represents an important direction for responsible AI development.

Despite these limitations, MVFT-JI represents a significant advancement in zero-shot composed image retrieval, offering a scalable, annotation-free solution that cleverly integrates the complementary strengths of MLLMs and VLMs. The consistent superior performance across diverse benchmarks demonstrates the framework's robustness and potential for real-world applications in e-commerce, creative industries, and content discovery platforms.
