# Dual Latent Memory in Vision-Language-Action Models for Robotic Manipulation

> [!summary] Summary
> LaMem-VLA, a Vision-Language-Action (VLA) model, integrates dual latent memory directly into its reasoning process to address temporal short-horizon bias in robotic manipulation. It achieved an average success rate of 73.9% on SimplerEnv-Bridge, outperforming a strong baseline by 16.6 percentage points, and recorded 97.6% across LIBERO suites, a 1.1 percentage point gain over MemoryVLA.

## Problem

- Mainstream VLA models operate under a Markovian assumption, leading to a "temporal short-horizon bias" that limits performance in long-horizon, multi-step robotic tasks.
- Existing memory augmentation methods for VLA models often treat historical context as an external or auxiliary input, preventing deep integration with the model's core multimodal reasoning.
- The challenge of effectively representing and utilizing diverse historical information, such as fine-grained visual details and high-level semantic task progress, within a VLA's continuous latent space.

## Method

- **LaMem-VLA** introduces an end-to-end native ==latent memory== framework that weaves dual-scale historical experience directly into the VLA model's internal latent embedding space.
- A **Latent Memory Curator** organizes visual perceptual evidence into a short-term vault and action hidden states into a long-term vault, employing a dynamic compression strategy for efficient storage.
- A **Latent Memory Condenser** transforms retrieved, variable-length historical evidence into fixed-length, query-conditioned latent memory tokens that are seamlessly compatible with the VLA's input sequence.

## Results

- Achieved an average success rate of **73.9%** across the SimplerEnv-Bridge suite, representing a **16.6 percentage point** improvement over the CogACT baseline (**57.3%**).
- Attained an average success rate of **97.6%** across all five LIBERO suites, outperforming MemoryVLA (**96.5%**) by **1.1 percentage points** and CogACT (**93.2%**) by **4.4 percentage points**.
- Ablation studies confirmed that both short-term and long-term memory streams are critical and complementary, with the latent-native integration method proving more effective than external memory conditioning.

## Takeaways

> [!tip] Key Insights
> - Deeply integrating historical memory as "latent-native" tokens within the VLA's continuous embedding space significantly enhances temporal awareness and manipulation performance compared to external or policy-side conditioning.
> - A dual-scale memory system, incorporating both short-term visual evidence and long-term semantic task progress, provides complementary information essential for resolving temporal ambiguities and maintaining task continuity.
> - Efficient mechanisms for curating, seeking, and condensing historical evidence into compact, fixed-length latent tokens allow the memory to directly participate in multimodal reasoning and action formation without incurring excessive computational cost.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Vision-Language-Action (VLA) models represent a paradigm in robotic manipulation, integrating capabilities from pre-trained vision-language models with policy learning to map visual observations and language instructions to robot actions. Despite advancements, many existing VLA models operate under a Markovian assumption, primarily predicting actions from the current observation. This approach exhibits a "temporal short-horizon bias," limiting their effectiveness in tasks that require reasoning over extended temporal dependencies, such as multi-step operations or long-horizon manipulation. Such tasks necessitate awareness of past state transitions, completed subtasks, and overall task progress.

Current efforts to augment VLA models with historical context or memory mechanisms typically fall into three categories:

1. **Temporal-Context Expansion:** This involves extending the input by concatenating historical frames or processing video sequences within a predefined context window. While providing recent state changes, this approach incurs increasing computational and memory costs with longer context lengths. Moreover, its fixed temporal horizon inherently limits the amount of memory, potentially discarding relevant evidence outside the window.
2. **Sparse History Abstraction:** This method compresses past interactions into lightweight proxy representations, such as recurrent latent states or action summaries. This reduces computational overhead but may lose fine-grained perceptual details and high-level semantic context critical for complex, long-horizon tasks.
3. **External Memory Conditioning:** In this approach, historical observations and action tokens are stored in an auxiliary memory bank, and a compact set of relevant evidence is retrieved to condition the current action policy. While demonstrating the utility of historical experience, these methods commonly consume the retrieved memory as an auxiliary, policy-side context. This architectural separation often prevents the memory from being deeply interleaved with the VLA model’s internal reasoning process, where perception, instruction interpretation, and action intent formation occur. The effectiveness of retrieval can also be compromised by weak cues or visual distractors in the current observation.

LaMem-VLA positions itself by addressing the fundamental limitation of external memory conditioning. It proposes a "latent-memory-native" framework where historical experience is represented, stored, retrieved, and consumed within the VLA model's native latent embedding space. This approach aims to allow memory to directly participate in multimodal reasoning and action formation, moving beyond its role as a supplementary input to a policy head. This aligns with a broader trend in AI and robotics research exploring more integrated and dynamic memory mechanisms to enhance agents' temporal awareness and reasoning capabilities.

### 2. Key Objectives and Motivation

The primary objective of this research is to reduce the temporal short-horizon bias inherent in mainstream Vision-Language-Action (VLA) models, thereby improving their performance on long-horizon and temporally dependent robotic manipulation tasks. The motivation stems from the observation that most existing VLA models, by relying on a Markovian assumption, predict actions based solely on current observations, neglecting crucial historical context. This limitation prevents them from effectively reasoning about task progress, previous state transitions, and the sequential nature of multi-step operations.

The authors identify a fundamental question regarding memory-dependent VLA models: "How can historical experience be represented as context-native robotic memory, stored, retrieved, and consumed within the same continuous space where the VLA model perceives, reasons, and acts?" This question underscores the motivation to integrate memory deeply into the VLA model's core reasoning rather than treating it as an external, auxiliary component.

To achieve this, the work is motivated by several specific design considerations:

1. **Latent Embedding Space Integration:** Modern VLA models already integrate diverse inputs (visual observations, language instructions) into a continuous token embedding space. The authors propose that robotic historical memory can similarly be organized as "machine-native latent memory tokens" that are compatible with this internal reasoning process. This aims to transform robotic memory into an intrinsic part of the model's operational context.
2. **Dual-Scale Memory Representation:** Long-horizon robotic manipulation often requires distinct types of historical information. This motivates the design of two complementary forms of memory:
 - **Short-term memory:** Primarily visually dominant, intended to preserve visually grounded evidence from the current episode, such as precise object locations and subtle state changes.
 - **Long-term memory:** Primarily semantically dominant, intended to preserve task progress, contextual semantics, and action continuity across longer horizons or multiple subtasks.
 The motivation here is to capture different aspects of history that are crucial for robust decision-making, acknowledging that both forms, despite differing in provenance and function, can ultimately be reconstructed as compatible latent memory tokens.
3. **Generative Latent Faculty:** The authors seek to architect historical memory as a "generative latent faculty" capable of fluidly reconstructing both short-term visual and long-term semantic evidence into compact memory tokens. These tokens must seamlessly interweave with the VLA reasoning and action generation process, ensuring that historical context directly influences perception, instruction understanding, and action-intent formation.

In summary, the key objectives are to overcome the temporal limitations of current VLA models by developing a framework that intrinsically integrates dual-scale historical memory into the VLA's latent reasoning space, enabling more temporally aware and robust robotic manipulation.

### 3. Methodology and Approach

LaMem-VLA is presented as an end-to-end native latent memory framework designed to interweave dual-scale historical experience directly into VLA reasoning. The model processes a natural-language instruction ($I$) and the current visual observation ($o_t$) to predict a chunk of future actions ($a_{t:t+H-1}$).

**Overall Architecture:**
The framework operates by first encoding the current visual observation ($o_t$) and instruction ($I$) into visual tokens ($X_t$) and instruction tokens ($I$) using a vision-language backbone. Learnable action queries are appended to form manipulation-relevant latent representations. LaMem-VLA then coordinates four main modules to integrate historical context: a latent memory curator, a latent memory seeker, a latent memory condenser, and a latent memory weaver.

**Detailed Module Breakdown:**

1. **Latent Memory Curator:**
 This module is responsible for maintaining and organizing historical experience into two distinct memory vaults:
 - **Short-term Memory Vault ($M_{short}$):** Stores visual perceptual evidence from the current episode. Each unit ($m_s$) is a key-value pair $(k_s, v_s)$. The value ($v_s$) is a set of compact short-term memory tokens distilled from the current visual tokens ($X_t$) by a learnable SE-bottleneck compression module ($C_s$). The key ($k_s$) is a mean-pooled representation of $v_s$, serving as a concise retrieval summary.
 - **Long-term Memory Vault ($M_{long}$):** Stores action hidden states ($H_{action}$) directly, which track task progress and action continuity across longer horizons. Unlike the short-term vault, it does not use key-value pairs but accumulates action hidden states as units ($m_l$).
 - **Memory Vault Updating Strategy:** Both vaults have a maximum capacity ($L=16$). When a new unit is added and the capacity is exceeded, a compression strategy is applied. For $M_{short}$, the cosine similarity between temporally adjacent keys is computed, and the most redundant pair is identified. This pair is then consolidated by averaging their respective keys and values, reducing redundancy while retaining information. A similar strategy is applied to $M_{long}$ based on mean-pooled long-term units.

2. **Latent Memory Seeker:**
 This module retrieves relevant historical evidence from the vaults based on the current context:
 - A context-aware query ($Q_{con\_t}$) is generated from the current visual tokens ($X_t$) and instruction tokens ($I$).
 - Learnable query slots ($Q_{init}$) are appended to $Q_{con\_t}$ and updated by a lightweight transformer-based query builder ($B$) to form $Q_t$. The mean-pooled version of $Q_t$ ($q_t$) acts as the global retrieval vector.
 - For $M_{short}$, $q_t$ is used to retrieve the Top-K (K=8) most similar short-term memory units (based on cosine similarity with their keys $k_s$). The values ($v_s$) of these units are concatenated into $Z_{short}$.
 - For $M_{long}$, $q_t$ is used to retrieve the Top-K (K=8) long-term memory units (based on cosine similarity with their mean-pooled representations). These units are stacked into $Z_{long}$.
 The retrieved sets $Z_{short}$ and $Z_{long}$ serve as raw evidence substrates.

3. **Latent Memory Condenser:**
 This module transforms the potentially redundant and variable-length retrieved evidence ($Z_{short}$, $Z_{long}$) into fixed-length, compact latent memory tokens that are compatible with the VLA embedding space:
 - Learnable short-term visual memory slots ($T_s$) and long-term semantic memory slots ($T_l$) are introduced.
 - Lightweight transformer-style memory formers ($F_v$ and $F_c$) update these slots, conditioned on the context query tokens ($Q_t$) and the retrieved evidence.
 - This process yields fixed-length latent short-term memory tokens ($M'_{short} \in \mathbb{R}^{L_s \times C}$, where $L_s=8$) and latent long-term memory tokens ($M'_{long} \in \mathbb{R}^{L_l \times C}$, where $L_l=4$). These tokens are query-conditioned and exist in the same C-dimensional embedding space as VLA reasoning.

4. **Latent Memory Weaver for Guidance Generation:**
 This module integrates the condensed latent memory tokens into the VLA reasoning sequence:
 - $M'_{short}$ and $M'_{long}$, augmented with learnable source embeddings, are prepended to the current VLA input sequence. The sequence becomes $S_t = [M'_{short}; M'_{long}; X_t; I; Q_{action}]$.
 - This memory-augmented sequence is then processed by the Vision-Language Model (VLM) backbone. Because the memory tokens are part of the input sequence, they directly participate in self-attention mechanisms with the current observation, language instruction, and action queries.
 - This results in "memory-grounded action tokens" ($Z_{action}$), which are then passed to the diffusion-based action expert.

**Diffusion-based Action Expert:**
Following the generation of memory-grounded action tokens, a diffusion-based action expert decodes these into a continuous action chunk (7-DoF end-effector control, chunk size of 16). The expert is trained with a Mean Squared Error (MSE) loss to predict injected noise during conditional denoising. During inference, DDIM sampling with 10 denoising steps iteratively refines the action chunk, generating history-aware control actions.

**Implementation Details:**
The LaMem-VLA model utilizes a 7B-parameter Prismatic VLM backbone, pre-trained on the Open-X Embodiment dataset, and a diffusion action expert with approximately 300M parameters. Input RGB observations are resized to 224x224. Training is conducted on 8 NVIDIA H800 GPUs with a global batch size of 256 and a learning rate of $2 \times 10^{-5}$.

### 4. Main Findings and Results

The efficacy of LaMem-VLA was evaluated through extensive experiments across two robotic manipulation simulators, SimplerEnv-Bridge and LIBERO, demonstrating performance improvements over baseline and existing memory-augmented VLA models.

#### 4.1. Simulated Evaluation on SimplerEnv-Bridge

- **Protocol:** LaMem-VLA was trained on the Bridge v2 dataset for 50,000 optimization steps, with validation every 2,500 steps. Evaluation involved 24 trials per task, reporting average success rates.
- **Results:** LaMem-VLA achieved an average success rate of 73.9% across the SimplerEnv-Bridge suite. This outcome represents a 16.6 percentage point improvement over the CogACT baseline (57.3%) and a 4.7 percentage point improvement over $\pi^0$ (69.2%). It also surpassed MemoryVLA (71.9%) and SemanticVLA (65.1%). Task-specific success rates included 83.3% for "Put Spoon on Towel," 75.0% for "Put Carrot on Plate," 41.7% for "Stack Cube," and 95.8% for "Put Eggplant in Basket."
- **Interpretation:** These results suggest that the integration of dual latent memory tokens into the VLA reasoning sequence provides effective historical context, leading to enhanced manipulation performance and robustness across diverse task settings in SimplerEnv-Bridge.

#### 4.2. Simulated Evaluation on LIBERO

- **Protocol:** Experiments were conducted using a Franka robot across five suites: Spatial, Object, Goal, Long-10, and Long-90. Training used 50 demonstrations per task, with separate models for Spatial, Object, and Goal (20,000 steps) and joint training for Long-10 and Long-90 (40,000 steps). Success rates were reported over 50 rollouts per task.
- **Results:** LaMem-VLA demonstrated an average success rate of 97.6% across all five LIBERO suites, establishing the highest overall performance. This improved upon MemoryVLA (96.5%) by 1.1 percentage points and CogACT (93.2%) by 4.4 percentage points. When compared to $\pi^0$ (which only reported on the first four suites), LaMem-VLA achieved an average of 97.7%, representing a 3.5 percentage point improvement. Specifically, LaMem-VLA obtained 98.8% on Spatial, 99.0% on Object, 97.2% on Goal, 95.8% on Long-10, and 97.0% on Long-90. Notably, the long-horizon suites (Long-10 and Long-90) saw improvements of 2.4 and 1.4 percentage points over MemoryVLA, respectively.
- **Interpretation:** The consistent high success rates across LIBERO suites, particularly the gains in long-horizon tasks, indicate that integrating short-term visual evidence and long-term semantic memory directly into the VLA reasoning sequence aids the policy in resolving temporally ambiguous states, preserving task progress, and generating more reliable actions for complex, sequential tasks.

#### 4.3. Ablation Study

- **Effectiveness of Dual-scale Latent Memory:**
 - **Finding:** The full LaMem-VLA model, utilizing both short-term and long-term latent memory, achieved the best performance on both SimplerEnv (73.9%) and LIBERO-90 (97.0%). Removing both memory streams ("w/o Dual Memory") resulted in the largest performance degradation (57.3% on SimplerEnv, 92.1% on LIBERO-90). Removing either short-term or long-term memory individually also led to performance drops compared to the full model, though less severe than removing both.
 - **Interpretation:** This confirms the complementary roles of the two memory vaults, with short-term memory preserving recent visual details (e.g., object states), and long-term memory maintaining task progress and action continuity over extended periods.

- **Latent-native Memory vs. Policy-side Conditioning:**
 - **Finding:** A memory-free baseline achieved 57.3% on SimplerEnv and 92.1% on LIBERO-90. Adding memory as an external policy-side condition improved performance to 71.9% and 94.8%, respectively. Directly feeding raw retrieved evidence to the action policy yielded 69.8% and 95.1%. LaMem-VLA, with its latent-native integration, achieved the highest performance (73.9% and 97.0%).
 - **Interpretation:** These results indicate that deep integration of memory into the VLA's latent reasoning process, where memory tokens participate in the same self-attention as observations and instructions, is more effective than external conditioning or uncompressed retrieval, which can introduce redundancy.

- **Number of Retrieved Memory Units (K):**
 - **Finding:** Performance improved when increasing K from 2 to 8 units retrieved from each vault (e.g., SimplerEnv: 66.7% to 73.9%). However, increasing K further to 12 slightly reduced performance (SimplerEnv: 71.8%).
 - **Interpretation:** This suggests an optimal balance for retrieval, where a moderate amount of historical evidence is beneficial, but excessive retrieval can introduce noise or redundancy, increasing the burden on the memory condenser.

- **Number of Latent Memory Tokens ($L_s$ and $L_l$):**
 - **Finding:** Increasing the number of short-term memory tokens ($L_s$) from 2 to 16 improved performance (e.g., SimplerEnv: 61.4% to 65.6%), with saturation observed beyond 16. Increasing the number of long-term memory tokens ($L_l$), while keeping $L_s$ fixed, also led to performance gains. The configuration ($L_s=8, L_l=4$) was identified as a balanced default.
 - **Interpretation:** A sufficient number of short-term tokens is necessary to preserve fine-grained perceptual evidence, while long-term tokens enhance task-progress and action-continuity cues. A trade-off exists between the number of tokens (and thus computational cost) and performance.

### 5. Significance and Potential Impact

The LaMem-VLA framework introduces a paradigm for integrating historical experience into Vision-Language-Action (VLA) models for robotic manipulation. Its significance lies in addressing a core limitation of existing VLA approaches: the "temporal short-horizon bias" resulting from a predominantly Markovian assumption. By treating historical experience as "context-native latent memory" rather than an external auxiliary input, LaMem-VLA enables deeper and more fluid interaction between past information and the current multimodal reasoning process.

The potential impacts of this research include:

1. **Enhanced Robustness for Long-Horizon Tasks:** The demonstrated performance improvements on complex, long-horizon benchmarks like SimplerEnv-Bridge and LIBERO, particularly in suites requiring extended temporal reasoning, indicate that LaMem-VLA can significantly enhance the robustness and reliability of robotic policies for multi-step and sequential manipulation tasks. This could enable robots to handle more intricate real-world operations.
2. **Improved Temporal Awareness:** By weaving dual-scale latent memory (short-term visual and long-term semantic) directly into the VLA model's input sequence, LaMem-VLA allows the policy to resolve temporally ambiguous states and maintain awareness of task progress. This represents a step towards VLA systems with a more comprehensive understanding of an ongoing task's history and future requirements.
3. **New Direction for Memory Integration in Embodied AI:** The concept of "latent-memory-native" integration, where memory is part of the model's continuous embedding space for perception, reasoning, and action, offers a novel architectural direction for embodied AI. This approach suggests that future VLA and generalist robot models could benefit from internalizing historical context more deeply, moving beyond simple input concatenation or external retrieval mechanisms.
4. **Foundation for More Generalizable Policies:** By better leveraging historical context, LaMem-VLA contributes to the development of more generalizable robotic policies. Tasks that require remembering object states, completed subtasks, or specific interaction sequences can be handled more effectively, potentially reducing the need for extensive task-specific training data.
5. **Efficiency in Memory Consumption:** The latent memory condenser, which reconstructs retrieved evidence into compact, fixed-length tokens, offers a mechanism for integrating relevant history without incurring the growing computational and memory costs associated with raw historical context expansion. This balance between informativeness and efficiency is crucial for deployable robotic systems.

A noted limitation in the current work is the empirical validation being conducted solely in simulated environments. The authors indicate ongoing work to extend LaMem-VLA to real-world robot platforms, which would be a critical next step in demonstrating its practical utility and impact beyond simulation. If successful in real-world applications, LaMem-VLA's principles could significantly influence the design of future robotic control architectures, enabling robots to perform more autonomously and intelligently in dynamic, unstructured environments.
