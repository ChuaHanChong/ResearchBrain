# Learning to summarize user information for personalized reinforcement learning from human feedback

> [!summary] Summary
> A framework called Preference Learning Using Summarization (PLUS) uses a language model to create natural language summaries of user preferences, which subsequently personalize a reward model for reinforcement learning from human feedback. This approach achieved higher prediction accuracy for personalized reward modeling across various benchmarks and enabled personalization of powerful proprietary LLMs.

## Problem

- Conventional Reinforcement Learning from Human Feedback (RLHF) assumes uniform user preferences, failing to account for diverse and often conflicting individual needs.
- Existing personalized RLHF methods typically represent user characteristics as opaque, fixed-length embedding vectors, which limits interpretability and the capacity to retain rich textual information.
- Personalizing Large Language Models (LLMs) for heterogeneous user populations in complex, real-world scenarios with sparse data remains a significant challenge.

## Method

- **PLUS** develops a novel framework that leverages an LLM as a ==summarizer== to generate concise, natural language summaries of user context and preferences.
- It employs an online co-adaptation mechanism, where the summarizer and a summary-conditioned reward model are jointly trained using a reinforcement learning loop (PPO for summarizer, NLL loss for reward model).
- The summarizer is explicitly optimized to create summaries that maximize the reward model's accuracy in predicting personalized user preferences.

## Results

- PLUS achieved up to **17.7%** higher prediction accuracy over standard baselines like BTL and other personalized methods (VPL, ICL) on complex UltraFeedback datasets.
- The framework demonstrated strong generalization capabilities, maintaining **93.67%** accuracy on out-of-distribution preference topics (Pets OOD) while ICL and VPL performance significantly dropped.
- PLUS-generated summaries improved the accuracy of GPT-4o's preference predictions by **19.5%** and enabled personalized response generation with a **72%** win rate against unpersonalized responses, as evaluated by an oracle reward model.

## Takeaways

> [!tip] Key Insights
> - Text-based, learned summaries provide a more interpretable and powerful representation of user preferences compared to opaque vector embeddings, enhancing predictive utility for personalized RLHF.
> - The co-adaptation of the summarizer and reward model is critical; training them jointly allows the summarizer to produce information directly relevant to improving reward model accuracy.
> - Effective user summaries can enable personalization of powerful proprietary LLMs without requiring their direct fine-tuning, demonstrating significant portability and practical value.
