# AutoPrune: Each Complexity Deserves a Pruning Policy

> [!summary] Summary
> Complexity-Adaptive Pruning (AutoPrune) introduces a training-free framework that dynamically adjusts visual token pruning policies for large vision-language models based on input complexity, achieving up to 76.8% FLOPs reduction while preserving high accuracy. The method demonstrates superior performance on various VLM benchmarks and, remarkably, can improve performance beyond unpruned baselines in Vision-Language-Action tasks for autonomous driving.

## Problem

- Large Vision-Language Models (LVLMs) incur significant computational costs due to extensive visual token sequences, hindering real-time deployment in resource-constrained environments.
- Existing training-free token pruning methods utilize fixed schedules or heuristic layer-specific strategies, failing to adapt to dynamic input/task complexity or guarantee adherence to computational budgets.
- Static pruning approaches cannot optimally reconcile the diverse reasoning demands of simple versus complex multimodal tasks, leading to suboptimal efficiency-accuracy trade-offs.

## Method

- Developed ==Complexity-Adaptive== Pruning (**AutoPrune**), a training-free, plug-and-play framework that dynamically tailors visual token pruning policies.
- Quantified cross-modal alignment and input complexity by measuring the mutual information between early-layer visual and textual tokens.
- Mapped the complexity indicator to a budget-constrained logistic retention function, dynamically adjusting the layer-wise token retention schedule while ensuring strict adherence to a predefined computational budget.

## Results

- AutoPrune achieved **96.7%** of the full-model accuracy on LLaVA-1.5-**7B** while removing **89%** of visual tokens (**76.8%** FLOPs reduction), consistently outperforming state-of-the-art training-free methods.
- Demonstrated robust generalizability across different LVLM architectures (LLaVA-1.5, LLaVA-NeXT) and diverse multimodal tasks, maintaining high performance retention even at stringent pruning budgets.
- Applied to the Senna VLA model for autonomous driving, AutoPrune not only reduced computational load but, at **25%** token retention, surpassed the unpruned model's performance by achieving **111.23%** relative accuracy.

## Takeaways

> [!tip] Key Insights
> - Vision-Language Models exhibit adaptive attention patterns, akin to human cognition, where simple tasks elicit rapid attention convergence and complex tasks sustain diffuse attention across layers.
> - Mutual information between early visual and textual tokens serves as an effective and reliable proxy for input complexity, allowing for dynamic pruning policy generation.
> - A logistic retention curve, modulated by input complexity and normalized to a computational budget, effectively models and allocates attentional resources, balancing exploration and exploitation in token pruning.
