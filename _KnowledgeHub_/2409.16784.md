# World Model-based Perception for Visual Legged Locomotion

> [!summary] Summary
> World Model-based Perception (WMP) integrates a learned world model with a reinforcement learning framework, enabling legged robots to perform vision-based locomotion on complex terrains. The system successfully transfers from simulation to a real Unitree A1 robot and consistently outperforms baseline methods across various challenging environments, including gaps, climbs, and tilts.

## Problem

- Legged robots relying solely on proprioceptive feedback struggle with complex terrains that require advanced planning based on visual information.
- Learning control policies directly from high-dimensional visual inputs using standard reinforcement learning is data-inefficient.
- Existing privileged learning frameworks create a performance gap between training (with extra information) and real-world deployment, and sim-to-real transfer remains challenging.

## Method

- A World Model-based Perception (WMP) framework combines a learned world model with a reinforcement learning policy for vision-based legged locomotion.
- A Recurrent State-Space Model (RSSM) is trained in simulation to learn compact, predictive latent representations of future depth images and proprioception.
- A policy network uses the world model's recurrent state and current proprioception to generate robot control actions, trained via Proximal Policy Optimization (PPO) with domain randomization.

## Results

- The simulation-trained world model accurately predicts real-world depth images across various terrains, demonstrating successful perceptual transfer.
- The full WMP system successfully transferred to a real Unitree A1 robot, enabling robust navigation across various complex real-world terrains like gaps, climbs, and tilts.
- WMP consistently achieved higher success rates compared to baseline methods, including student and blind policies, showing particular advantages in increasingly challenging visual locomotion tasks.

## Takeaways

> [!tip] Key Insights
> - A world model can learn distinct latent representations for various terrain types from visual and proprioceptive data, aiding environmental understanding.
> - Optimizing the world model update interval (e.g., 8-10 control steps) balances performance and computational cost.
> - Both visual (depth images) and proprioceptive information are crucial for the world model to accurately capture environmental dynamics and improve robot performance.
