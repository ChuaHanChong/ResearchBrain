# MaskedMimic: Unified Physics-Based Character Control Through Masked Motion Inpainting

> [!summary] Summary
> MaskedMimic introduces a unified framework for physics-based character control by reformulating it as a masked motion inpainting problem. This approach allows a single system to generate physically plausible full-body motions from various partial constraints, including full-body tracking, VR inputs, object interactions, path following, and text-to-motion synthesis.

## Problem

- Traditional physics-based character control methods require task-specific controllers, handcrafted reward functions, and extensive engineering, limiting their generalization beyond specific use cases.
- Existing character animation techniques, including physics-based animation, motion matching, and multi-modal control, often lack a unified framework capable of handling diverse input modalities simultaneously.
- Translating partial user specifications (e.g., a few joint positions, high-level commands) into complete, physically plausible full-body motions for simulated characters remains a challenge.

## Method

- A unified framework, **MaskedMimic**, which reformulates character control as a general motion inpainting problem, generating physically plausible full-body motions from partial constraints.
- A two-stage training process: first, a fully-constrained controller learns to track complete motion sequences using reinforcement learning; second, a partially-constrained controller is distilled via behavior cloning from masked versions of these sequences.
- A multi-modal transformer-based neural network architecture processes diverse inputs (e.g., pose targets, text instructions, object features, terrain information) and learns to predict actions given arbitrary combinations of partial constraints.

## Results

- MaskedMimic accurately reproduces complex full-body movements when provided with complete motion targets, maintaining physical plausibility.
- The system generates natural full-body motions from sparse inputs like VR-style hand and head tracking, supports path following over diverse terrains, and enables joystick-style interactive control.
- It produces appropriate human-object interaction behaviors based on object properties and can generate varied motions directly from natural language text descriptions, demonstrating robust multi-modal control capabilities.

## Takeaways

> [!tip] Key Insights
> - Reformulating physics-based character control as a masked motion inpainting problem allows for a unified framework that can generalize across diverse control modalities.
> - A two-stage training process, involving an initial fully-constrained controller (trained with RL) followed by distillation into a partially-constrained controller (trained with behavior cloning and masked inputs), effectively learns to generate plausible motions from incomplete information.
> - A multi-modal transformer architecture effectively processes various input types, including spatial constraints, temporal constraints, text descriptions, and environmental features, enabling flexible control.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

#### 1.1. Introduction

Creating realistic and controllable virtual characters remains a significant challenge in computer graphics, animation, and robotics. Traditional approaches to character control typically require task-specific controllers, handcrafted reward functions, and extensive engineering efforts. These methods often struggle to generalize beyond their specific use cases, resulting in fragmented solutions that are difficult to reuse across different applications.

#### 1.2. Background and Related Work

Character animation techniques have evolved along several parallel tracks:

**Physics-Based Character Animation** uses physical simulations to generate motions that adhere to physical laws. While these methods produce realistic movements, they typically require complex reward functions and are often limited to specific tasks or behaviors.

**Motion Matching and Synthesis** techniques use large databases of motion capture data to generate new animations. Recent approaches leverage deep learning to create motion fields or latent spaces of movements, but translating these into physically simulated characters remains challenging.

**Multi-Modal Control** methods aim to provide diverse interfaces for animation, including keyframe animation, path following, and text-driven synthesis. However, most existing systems support only a subset of these modalities, requiring users to switch between different controllers.

**Motion Inpainting** addresses the challenge of generating complete motions from partial specifications. While previous work has explored this for kinematic systems, applying inpainting to physics-based character control introduces additional complexities due to physical constraints and dynamic environments.

MaskedMimic builds upon these foundations while addressing their limitations through a novel approach that unifies diverse control modalities within a single framework.

### 2. Key Objectives and Motivation

#### 2.1. Proposed Approach

MaskedMimic addresses these limitations by introducing a unified framework for physics-based character control through masked motion inpainting. Instead of designing specialized controllers for each task, MaskedMimic reformulates character control as a general motion inpainting problem: given partial constraints (e.g., specific joint positions, text descriptions, or environmental information), the system generates physically plausible full-body motions that satisfy these constraints.

### 3. Methodology and Approach

#### 3.1. Framework Architecture

The architecture employs a two-stage training process:

During inference, users can provide various types of partial constraints, and the system generates full-body motions that satisfy these constraints while maintaining physical plausibility.

The architecture allows for selective masking of different input modalities during training, which enables the model to learn to generate complete motions from arbitrary combinations of inputs.

#### 3.2. Fully-Constrained Controller Training

The first stage of MaskedMimic involves training a fully-constrained controller using reinforcement learning. This controller learns to track complete motion sequences from a diverse dataset of motion capture clips.

The training dataset includes:
- Standard locomotion motions (e.g., walking, running, jumping)
- Athletic movements (e.g., cartwheels, backflips)
- Interactions with various objects (e.g., sitting on chairs, climbing)
- Motions performed on diverse terrains (flat ground, stairs, irregular surfaces)

The controller is trained using a reward function that encourages accurate tracking of joint positions, velocities, and orientations. The reinforcement learning objective is formulated as:

$$\pi_{FC} = \arg\max_\pi \mathbb{E}_{\tau \sim p(\tau|\pi)} \left[ \sum_{t=0}^{T} \gamma^t r_t(s_t, a_t, g_t^{full}) \right]$$

where $\pi_{FC}$ is the fully-constrained policy, $\tau$ represents trajectories, $r_t$ is the reward at time $t$, $s_t$ is the state, $a_t$ is the action, and $g_t^{full}$ are the full motion constraints.

The resulting controller can accurately track a wide variety of motions but requires complete motion specifications as input, limiting its practical applications.

#### 3.3. Partially-Constrained Controller Distillation

The second stage involves distilling the knowledge from the fully-constrained controller into a more versatile partially-constrained controller using behavior cloning. This is accomplished through masked motion inpainting:

1. Complete motion sequences are randomly masked, creating partial constraints.
2. The fully-constrained controller generates reference actions based on the complete (unmasked) sequences.
3. The partially-constrained controller is trained to predict the same actions given only the partial constraints.

The masking process is flexible, allowing for various types of constraints to be preserved while others are masked:
- Spatial constraints (specific joint positions at particular times)
- Temporal constraints (complete poses at specific keyframes)
- Modal constraints (text descriptions, environmental features, etc.)

The distillation process uses a conditional variational autoencoder (C-VAE) to model the distribution of behaviors that satisfy a particular set of partial goals:

$$\mathcal{L}_{BC} = \mathbb{E}_{(s_t, g_t^{partial}, a_t^{FC})} \left[ -\log p_{\pi_{PC}}(a_t^{FC} | s_t, g_t^{partial}) \right]$$

$$\mathcal{L}_{KL} = \mathbb{E}_{(s_t, g_t^{partial}, g_t^{full})} \left[ D_{KL}(q_\phi(z_t | s_t, g_t^{full}) || p_\psi(z_t | s_t, g_t^{partial})) \right]$$

$$\mathcal{L} = \mathcal{L}_{BC} + \beta \mathcal{L}_{KL}$$

where $\pi_{PC}$ is the partially-constrained policy, $z_t$ is the latent variable, and $\beta$ is a weighting coefficient.

### 4. Main Findings and Results

#### 4.1. Applications and Results

MaskedMimic demonstrates strong performance across a variety of character control tasks:

**Full-Body Motion Tracking**
When provided with complete motion targets, MaskedMimic accurately reproduces complex movements, including punching sequences and dance motions, while maintaining physical plausibility.

**VR-Style Control**
By tracking only the positions of hands and head (similar to VR systems), MaskedMimic generates natural full-body motions, allowing for intuitive control in virtual reality applications.

**Path Following and Steering**
The system can follow specified paths while adapting to diverse terrains, including rough surfaces and stairs. It also supports joystick-style steering for interactive control.

**Human-Object Interaction**
MaskedMimic generates appropriate interaction behaviors based on object properties, allowing characters to naturally sit on chairs, lean on tables, or interact with various furniture.

**Text-to-Motion Synthesis**
The system can generate motions from text descriptions, translating natural language instructions into physically plausible movements.

**Multi-Modal Control**
MaskedMimic excels at combining different control modalities, such as following a path while matching a text-described style or interacting with objects in a scene-aware manner.

### 5. Significance and Potential Impact

#### 5.1. Limitations and Future Work

Despite its capabilities, MaskedMimic has several limitations:

1. **Text Understanding**: While the system can interpret simple text commands, it struggles with complex or abstract instructions that require long-term planning or reasoning.

2. **Motion Diversity**: For highly constrained inputs, the system sometimes produces limited variation in the generated motions, reducing the diversity of possible solutions.

3. **Physical Realism**: In challenging scenarios (e.g., complex object interactions), the system may occasionally generate physically implausible motions that would be difficult for real humans to perform.

4. **Computational Requirements**: The transformer-based architecture requires significant computational resources, which may limit real-time applications on less powerful hardware.

Future work could address these limitations by:
- Incorporating more sophisticated language models for better text understanding
- Exploring adversarial training techniques to increase motion diversity
- Integrating more detailed physical constraints to improve realism
- Optimizing the architecture for better computational efficiency

#### 5.2. Conclusion

MaskedMimic represents a significant advance in physics-based character control by providing a unified framework that supports diverse control modalities through masked motion inpainting. By reformulating character control as an inpainting problem, the system eliminates the need for task-specific training and complex reward engineering, making character animation more accessible and versatile.

The approach demonstrates strong performance across various applications, including full-body motion tracking, VR control, path following, object interaction, and text-to-motion synthesis. This versatility makes MaskedMimic a promising foundation for future work in interactive character animation, virtual reality, and robotics.

The key contributions of MaskedMimic include:
1. A unified framework for physics-based character control that supports diverse input modalities
2. A novel masked motion inpainting approach that enables generalization to arbitrary partial constraints
3. A flexible architecture that integrates multimodal inputs, including spatial, temporal, and linguistic constraints
4. Demonstrated applications across a wide range of character control tasks

These advances bring us closer to the goal of creating virtual characters that can seamlessly adapt to diverse environments and user intents, opening new possibilities for interactive and immersive experiences.
