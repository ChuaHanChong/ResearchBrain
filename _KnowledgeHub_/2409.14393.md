# MaskedMimic: Unified Physics-Based Character Control Through Masked Motion Inpainting

> [!summary] Summary
> MaskedMimic introduces a unified framework for physics-based character control by reformulating it as a masked motion inpainting problem. This approach allows a single system to generate physically plausible full-body motions from various partial constraints, including full-body tracking, VR inputs, object interactions, path following, and text-to-motion synthesis.

## Problem

- Traditional physics-based character control methods require task-specific controllers, handcrafted reward functions, and extensive engineering, limiting their generalization beyond specific use cases.
- Existing character animation techniques, including physics-based animation, motion matching, and multi-modal control, often lack a unified framework capable of handling diverse input modalities simultaneously.
- Translating partial user specifications (e.g., a few joint positions, high-level commands) into complete, physically plausible full-body motions for simulated characters remains a challenge.

## Method

- A unified framework, **MaskedMimic**, which reformulates character control as a general motion inpainting problem, generating physically plausible full-body motions from partial constraints.
- A two-stage training process: first, a fully-constrained controller learns to track complete motion sequences using reinforcement learning; second, a partially-constrained controller is distilled via behavior cloning from masked versions of these sequences.
- A multi-modal transformer-based neural network architecture processes diverse inputs (e.g., pose targets, text instructions, object features, terrain information) and learns to predict actions given arbitrary combinations of partial constraints.

## Results

- MaskedMimic accurately reproduces complex full-body movements when provided with complete motion targets, maintaining physical plausibility.
- The system generates natural full-body motions from sparse inputs like VR-style hand and head tracking, supports path following over diverse terrains, and enables joystick-style interactive control.
- It produces appropriate human-object interaction behaviors based on object properties and can generate varied motions directly from natural language text descriptions, demonstrating robust multi-modal control capabilities.

## Takeaways

> [!tip] Key Insights
> - Reformulating physics-based character control as a masked motion inpainting problem allows for a unified framework that can generalize across diverse control modalities.
> - A two-stage training process, involving an initial fully-constrained controller (trained with RL) followed by distillation into a partially-constrained controller (trained with behavior cloning and masked inputs), effectively learns to generate plausible motions from incomplete information.
> - A multi-modal transformer architecture effectively processes various input types, including spatial constraints, temporal constraints, text descriptions, and environmental features, enabling flexible control.
