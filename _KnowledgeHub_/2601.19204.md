# MATA: A Trainable Hierarchical Automaton System for Multi-Agent Visual Reasoning

> [!summary] Summary
> MATA is a trainable hierarchical automaton system for multi-agent visual reasoning that employs an LLM-based hyper agent to learn dynamic transitions between specialized reasoning agents. It achieves state-of-the-art performance across compositional VQA, external knowledge VQA, and referring expression comprehension benchmarks, while providing enhanced transparency and robustness.

## Problem

- Monolithic Vision-Language Models (VLMs) often produce unexplainable reasoning and hallucinate when dealing with complex visual queries.
- Existing compositional and single-agent methods are rigid, lack robustness to errors, and struggle with multi-step, feedback-driven reasoning or flexible collaboration.
- Previous automaton-based systems relied on hand-crafted, rule-based transition rules, which are inflexible and difficult to scale with increasing complexity or ambiguous agent selection criteria.

## Method

- Developed ==MATA==, a multi-agent system structured as a ==hierarchical finite-state automaton== with an LLM-based 'hyper agent' controlling high-level state transitions.
- Specialized agents (e.g., ONESHOT, STEPWISE, SPECIALIZED) act as top-level states, each with rule-based sub-automata for micro-control, and communicate via an ==append-only shared memory==.
- Introduced a ==data generation pipeline (MATA-SFT-90K)== to create supervised finetuning examples for the hyper agent, enabling it to learn dynamic, context-aware transition policies between agents.

## Results

- MATA achieved state-of-the-art results, including **64.9%** accuracy on GQA (outperforming InternVL3.5 by **1.1%**), **76.5%** on OK-VQA (surpassing InternVL3.5 by **0.8%**), and **96.3%** on RefCOCO (exceeding Florence2-L by **1.2%**).
- Ablation studies confirmed the trainable hyper agent's crucial role, substantially improving accuracy (e.g., **64.9%** for MATA vs. **57.7%** for exhaustive on GQA) and reducing inference time.
- The learned transition policy demonstrated strong cross-task generalization, with a single hyper agent showing robust performance across diverse visual reasoning benchmarks with minimal performance drop.

## Takeaways

> [!tip] Key Insights
> - A trainable hyper agent governing high-level transitions allows dynamic selection and collaboration/competition among specialized agents, enhancing flexibility and robustness in visual reasoning.
> - The hierarchical design, separating learned high-level control from rule-based low-level execution, provides both adaptive decision-making and an explainable, auditable reasoning trace.
> - Supervised finetuning the hyper agent with systematically explored optimal reasoning trajectories yields an efficient and generalizable control policy for multi-agent systems.
