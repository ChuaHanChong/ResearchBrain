# CT-VAM: A Cerebello-Thalamic-Inspired Vision-Action Model for Efficient Visuomotor Control

> [!summary] Summary
> CT-VAM, a vision-action model inspired by the cerebello-thalamic system, enables efficient visuomotor control for robotics by decoupling high-level intent from low-level execution. The model achieved an 82.1% average success rate on the LIBERO benchmark and was deployed successfully on resource-constrained edge devices like the NVIDIA Jetson Orin NX.

## Problem

- Large Vision-Language-Action (VLA) models incur substantial inference and memory costs due to continuous processing of language instructions in high-frequency control loops.
- This computational overhead increases latency and hardware requirements, making deployment on resource-constrained robotic edge platforms challenging.
- Existing attention mechanisms often struggle with effectively fusing heterogeneous inputs (dense visual data and compact task conditions) without one dominating the other.

## Method

- **CT-VAM** introduces a modular architecture inspired by the ==cerebello-thalamic== system, separating high-level language grounding (for task intent) from high-frequency visuomotor execution.
- It employs a Thalamic Action Routing Stream (TARS) with stream-separated conditional attention to effectively integrate action tokens, visual observations, proprioceptive states, and a compact task identifier.
- The model utilizes rectified-flow training for continuous action generation and integrates Flow-Consistent Inpainting (FCI) with asynchronous chunk execution to minimize effective latency for real-time control.

## Results

- CT-VAM achieved an **82.1%** average success rate on the LIBERO benchmark with only **68M** parameters, outperforming larger non-VLM baselines and performing competitively with VLA models having billions of parameters.
- The model was successfully deployed on an NVIDIA Jetson Orin NX edge device, achieving a **90%** success rate for real-world tasks with an average inference time of **200.60 ms**.
- Flow-Consistent Inpainting (FCI) consistently reduced task execution time and allowed the model to achieve an effective control frequency of **20 Hz** by almost entirely hiding steady-state inference latency on an RTX 4080.

## Takeaways

> [!tip] Key Insights
> - Decoupling high-level language grounding from the fast, closed-loop sensorimotor feedback is crucial for developing computationally efficient robotic policies.
> - Stream-separated attention in the Thalamic Action Routing Stream (TARS) effectively handles heterogeneous inputs, preventing dense sensory tokens from overpowering compact yet critical task-relevant information.
> - Asynchronous action chunk execution combined with Flow-Consistent Inpainting (FCI) can significantly reduce effective inference latency, enabling high-frequency control on resource-constrained hardware.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Recent advancements in robot learning have increasingly focused on generalist policies that integrate visual perception, language understanding, and action generation, often referred to as Vision-Language-Action (VLA) models. These models leverage large language models (LLMs) and large-scale pretraining to enable broad generalization across various tasks, scenes, and robot embodiments. Early systems demonstrated the utility of LLMs for high-level task knowledge or planning, while more recent VLA models directly incorporate language instructions and visual observations into a unified policy for action generation. Examples include RT-1, RT-2, and OpenVLA, which often connect pre-trained vision-language backbones to robot action generation.

However, the direct deployment of these large, language-conditioned policies within the low-level control loop presents practical challenges. These challenges include substantial inference and memory costs, leading to increased latency and hardware requirements, particularly for resource-constrained robotic platforms at the edge. The raw language instruction often serves primarily to specify task intent, while high-frequency, fine-grained motor commands are predominantly guided by visual feedback and proprioceptive states. Therefore, repeatedly processing complex language-conditioned representations during fast closed-loop control may be inefficient.

This work addresses the tension between the semantic reasoning capabilities of large VLA models and the real-time efficiency required for low-level visuomotor execution. It proposes an architectural separation, suggesting that high-level language grounding for intent specification can be decoupled from the high-frequency sensorimotor feedback loop. This approach draws a functional analogy to biological skilled manipulation, where humans execute motor actions under sparse high-level intent, relying on rapid sensorimotor feedback rather than continuous reinterpretation of linguistic commands. The paper positions CT-VAM as a compact, efficient visuomotor policy designed for the low-level execution layer, compatible with an upstream language grounding module, thereby complementing the existing landscape of large VLA models by providing a specialized solution for efficient control.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop an efficient vision-action model for visuomotor control that can operate effectively on resource-constrained robotic platforms. The motivation for this objective stems from a critical observation regarding existing Vision-Language-Action (VLA) models: while language is valuable for specifying task intent and enabling generalization, its continuous processing in the high-frequency low-level control loop leads to significant computational overhead. This overhead manifests as increased inference latency and higher memory consumption, making real-world deployment on edge devices challenging.

The authors propose that high-level language grounding, which determines the overall task intent, can be decoupled from the rapid, closed-loop visual feedback control required for motor execution. This conceptual separation is formalized through the notion of a "grounded intent representation" (G). The paper posits that once a raw language instruction (L) is mapped into a compact, control-relevant intent representation G, the subsequent low-level policy (A_t) can condition solely on G and the current visual-proprioceptive observations (O_t) without needing to re-parse the raw language. This is formally expressed by the concept of G being $\epsilon_t$-control-sufficient, implying that the residual information about the action in the raw instruction, after conditioning on G and O_t, is negligible. This assumption forms the theoretical basis for avoiding repeated language processing during execution.

Based on this principle, the specific objectives of the CT-VAM model are:
1. **Formulate Grounded Visuomotor Execution:** To establish a framework where semantic language grounding is separated from high-frequency visual feedback control. Language is used to convert raw instructions into an intent representation, which then conditions a low-level policy using visual-proprioceptive observations for action generation.
2. **Efficient Heterogeneous Input Fusion:** To develop a mechanism that effectively fuses diverse input streams—action tokens, visual data, proprioception, and a compact task condition—without allowing dense sensory tokens to overpower the more compact but semantically critical task-relevant information. This addresses the challenge of designing attention mechanisms for heterogeneous data types.
3. **Support High-Frequency Real-Time Control:** To enable asynchronous action chunk execution, allowing the prediction of the next action chunk to overlap with the execution of the current chunk, while maintaining action continuity. This is crucial for minimizing effective latency and enabling deployment on resource-constrained hardware.
4. **Achieve Competitive Performance with Reduced Resources:** To demonstrate that a compact vision-action model (with a significantly lower parameter count than state-of-the-art VLA models) can achieve competitive success rates in complex manipulation tasks, both in simulation and in real-world settings, while being deployable on edge devices.

In summary, the motivation is to bridge the gap between powerful but computationally intensive VLA models and the practical requirements of real-time robotic control on edge hardware, by introducing a cerebellum-thalamic-inspired modular architecture that prioritizes efficiency and robust low-level execution based on a compact task condition.

### 3. Methodology and Approach

CT-VAM operates as a task-conditioned visuomotor policy, receiving dual-view visual observations, proprioceptive states, and a compact task identifier. It predicts action chunks, which are short sequences of continuous actions, for closed-loop execution. The model's architecture is inspired by the functional separation observed in biological cerebello-thalamic systems, where high-level intent is guided by cortical areas (analogous to a high-level VLM) and low-level motor execution is handled by the cerebellum (analogous to CT-VAM).

#### 3.1. Grounded Visuomotor Execution Formulation

The theoretical foundation of CT-VAM is built upon the concept of grounded visuomotor execution. A raw natural-language instruction (L) and initial context (X₀) are first processed by a grounding module (G ∼ q_ϕ(· | L, X₀)) to produce a compact, control-relevant intent representation (G). In the current implementation, G is a one-hot task identifier. The low-level controller then uses a learned visuomotor policy (A_t ∼ π_θ(· | G, O_t)) to predict actions, conditioning on G and the recent visual-proprioceptive history (O_t). The key is that once G is formed, the raw language L is not repeatedly processed, which is justified by the proposition that G can be $\epsilon_t$-control-sufficient, meaning the raw instruction provides only negligible additional information for action A_t after conditioning on G and O_t.

#### 3.2. CT-VAM Architecture Overview

CT-VAM comprises three main components:
1. **Visual Encoder:** Synchronized dual-view observations (primary and wrist cameras) are processed by a frozen DINOv3-S+ ViT backbone. Layer-wise visual memories are extracted, and wrist-query cross-attention is used to fuse information from both views, generating a dense spatial memory (D_ℓ) from patch tokens.
2. **Thalamic Action Routing Stream (TARS):** This is a transformer-based rectified-flow decoder that performs stream-separated conditional attention. It operates on a noised action state and updates action tokens by attending to four distinct streams:
 - **Self Stream (M_self):** The current action tokens themselves.
 - **Action-Query Stream (M_aq):** A set of learnable action queries, initialized from the register tokens of the pretrained DINOv3 visual backbone. These queries provide action refinement slots.
 - **Dense Stream (M_dense):** Dense visual patch tokens (D_ℓ) concatenated with encoded proprioceptive history (S).
 - **Task Stream (M_task):** A compact task token (r) derived from the one-hot task identifier.
 TARS employs stream-separated normalization, where each stream is normalized independently before its output is aggregated via explicit stream gates. This prevents dense streams from dominating compact but critical streams due to token count disparities.
3. **Rectified-Flow Training:** The decoder is trained to predict the velocity field between a base action sample (noise) and the expert action chunk. Rectified Flow (RF) matching is used, where the model learns to transform a noise vector into the target action chunk in a fixed number of steps, enabling efficient continuous action generation. The loss function is a masked element-wise mean squared error between the predicted and target velocities.

#### 3.3. Efficient On-Device Inference and Real-Time Execution

CT-VAM is designed for computational efficiency, having a parameter count of 68M (with the DINOv3-S+ visual backbone). To further enhance real-time performance, the model integrates:
- **Asynchronous Chunk Execution:** Inference for the next action chunk is overlapped with the physical execution of the current action chunk. This minimizes the exposed inference latency on the control path.
- **Flow-Consistent Inpainting (FCI):** To ensure smooth transitions between asynchronously generated action chunks, FCI constrains the overlapping portion of the new chunk to follow a rectified-flow-consistent trajectory towards the remaining actions of the current chunk. This maintains boundary continuity while preserving the in-distribution nature of the decoder's input, unlike direct hard clamping.
- **Real-time Equivalent Execution Metric:** The efficacy of asynchronous execution is quantified by a metric that accounts for physical action execution time and only the inference latency that cannot be hidden. This allows for an effective real-time control frequency closer to the desired physical control rate.

#### 3.4. Experimental Setup

Evaluation is performed on the LIBERO benchmark (LIBERO-Spatial, -Object, -Goal, -Long) for simulation performance and on the OpenArm platform for real-world tasks (Ball Pouring, Box Opening and Placement). For real-world deployment, the model is run on an NVIDIA RTX 4080 workstation and an NVIDIA Jetson Orin NX edge device. TensorRT optimization is applied for the Jetson deployment to enhance inference efficiency. Data for real-world tasks is collected via teleoperation (30 episodes per task).

### 4. Main Findings and Results

The research presents several findings across simulation and real-world experiments that support the efficacy and efficiency of CT-VAM.

#### 4.1. Performance on LIBERO Benchmark (Simulation)

- CT-VAM, with 68M parameters, achieved an average success rate of 82.1% across the LIBERO benchmark tasks. This performance is competitive with, and in many cases superior to, substantially larger VLA models and other non-VLM visuomotor policies. For instance, it surpassed Diffusion Policy (72.4%) and MDT (76.1%), both non-VLM baselines, while being significantly smaller than VLM-based models like OpenVLA (7000M parameters, 76.5% avg.) and π₀ (3300M parameters, 86.0% avg.).
- Specifically, CT-VAM demonstrated strong performance on LIBERO-Object (94.6%) and LIBERO-Spatial (89.0%), indicating effective visual-proprioceptive grounding for object-centric and spatial manipulation. These results suggest that a compact policy can achieve high performance for visuomotor execution once the task intent is adequately grounded.

#### 4.2. Ablation Studies on TARS and Scaling Behavior

- **Action Query Ablation:** The study on TARS action queries revealed that 32 learnable queries provided the optimal balance, yielding an 82.1% average success rate. Using fewer queries (4 learnable) resulted in lower performance (73.2%), indicating insufficient capacity. When 32 queries were fixed (not learnable), performance dropped to 77.2%, highlighting the benefit of adapting these slots. Increasing to 64 queries also led to a drop (73.0%), suggesting potential optimization difficulties with excessive queries. The learned gate for the action-query pathway consistently remained small (~0.02), indicating a subtle but effective role in action refinement, potentially by buffering nuisance variations.
- **Flow-matching Policy Scaling:** Comparison with vanilla flow-matching policies (FM-S, FM-B, FM-L) demonstrated that while increasing model size from FM-S (65.8% avg. with 68M params) to FM-B (76.9% avg. with 227M params) yielded significant gains, further scaling to FM-L (77.3% avg. with 758M params) showed diminishing returns. CT-VAM's 82.1% success rate, achieved with only 68M parameters (comparable to FM-S total parameters), outperformed even the largest FM-L variant. This indicates that CT-VAM's performance advantage stems from its architectural design (TARS, action queries) rather than just increased model capacity.

#### 4.3. Real-World Experiments

- **Ball Pouring Task:** On the Ball Pouring task, CT-VAM with FCI achieved a 95% success rate on an RTX 4080, comparable to π₀ (95%) and higher than Diffusion Policy (70%). Critically, CT-VAM achieved significantly lower average inference latency (56.84 ms with FCI vs. 117.24 ms for π₀ and 303.27 ms for Diffusion Policy). Without FCI, CT-VAM still achieved 100% success but with higher execution time (8.33s vs 6.41s for CT-VAM with FCI).
- **Edge Deployment on Jetson Orin NX:** CT-VAM with FCI successfully deployed on a resource-constrained Jetson Orin NX, achieving a 90% success rate with an average inference time of 200.60 ms and an execution time of 7.23 s. This demonstrated its practical viability on edge platforms, while π₀ and Diffusion Policy could not be deployed due to memory constraints or lack of testing on Jetson.
- **Impact of Flow-Consistent Inpainting (FCI):** FCI consistently reduced the average task execution time (e.g., from 8.33 s to 6.41 s on RTX 4080 for Ball Pouring) by overlapping next-chunk inference with current action execution. On RTX 4080, FCI effectively hid all steady-state inference latency, allowing an effective control frequency of 20 Hz, matching the target low-level control rate. On Jetson Orin NX, only 0.60 ms of inference latency remained exposed per FCI stride, resulting in an effective frequency of approximately 19.94 Hz.
- **Box Opening and Placement (Long-Horizon):** CT-VAM demonstrated robust execution of a long-horizon task requiring sequential subtask completion (box opening, object grasping, object placement). By manually switching the one-hot task label at subtask boundaries, the policy successfully guided the robot through consecutive stages, illustrating TARS's ability to coordinate task-level intent with visual and proprioceptive feedback.

### 5. Significance and Potential Impact

The development of CT-VAM contributes to the field of robot learning by addressing a practical challenge in deploying generalist robotic policies: the computational expense of continually processing complex language instructions during high-frequency low-level execution.

The primary significance of this work lies in its proposal for **decoupling high-level language grounding from high-frequency visual feedback control**. This modular approach suggests a pathway for integrating large language models for semantic reasoning and task specification with efficient, compact visuomotor policies for real-time action generation. This separation enables a potential "cloud-edge" paradigm, where computationally intensive semantic processing can occur remotely, while fast, closed-loop control executes locally on resource-constrained hardware.

Key aspects contributing to its potential impact include:
- **Computational Efficiency:** CT-VAM achieves competitive performance with a significantly smaller parameter count (68M) compared to state-of-the-art VLA models (often billions of parameters). This efficiency translates directly to lower inference latency and memory footprint, making it suitable for deployment on edge devices like the Jetson Orin NX, which is a critical requirement for many real-world robotic applications.
- **Effective Heterogeneous Input Fusion:** The introduction of TARS (Thalamic Action Routing Stream) provides a novel mechanism for integrating diverse input streams (action, visual, proprioceptive, task) using stream-separated conditional attention. This design mitigates the issue of dense sensory data overwhelming compact, yet semantically important, task conditions, leading to more robust and accurate action predictions.
- **Enhanced Real-Time Performance:** Flow-Consistent Inpainting (FCI) facilitates asynchronous chunk execution, effectively hiding much of the inference latency within the physical action execution time. This capability allows CT-VAM to operate at high effective control frequencies, crucial for stable and responsive real-time robot manipulation.
- **Competitive Performance:** Despite its compact size, CT-VAM demonstrates success rates on par with or exceeding larger baselines on the challenging LIBERO benchmark and robust performance in real-world tabletop manipulation tasks. This suggests that the architectural innovations, rather than brute-force scaling, can drive performance in visuomotor control.

While CT-VAM currently uses one-hot task tokens and relies on manual task switching for long-horizon tasks, its architecture is designed to be compatible with future integration of a dedicated language grounding module. Addressing this limitation and extending the model to broader task distributions and diverse robot embodiments represent important directions for future work.

Overall, CT-VAM represents a step toward practical, efficient, and robust visuomotor control for robotics, particularly for scenarios where computational resources are limited. Its design principles have implications for how future robot learning systems might be structured to balance semantic intelligence with real-time operational demands.
