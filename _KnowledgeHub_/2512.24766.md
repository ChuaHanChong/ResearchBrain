# Dream2Flow: Bridging Video Generation and Open-World Manipulation with 3D Object Flow

> [!summary] Summary
> Dream2Flow introduces a framework that enables robots to perform diverse manipulation tasks in open-world settings by converting high-level language instructions into 3D object flow extracted from AI-generated videos. This method successfully guides robots to manipulate rigid, articulated, deformable, and granular objects in both simulation and real-world scenarios without task-specific training, outperforming alternative intermediate representations by achieving up to 8/10 success rates on tasks like "Put Bread in Bowl" and "Open Oven".

## Problem

- Bridging the "embodiment gap" to translate human-centric video content from generative AI models into robot-executable actions.
- Enabling robots to perform zero-shot, generalizable manipulation tasks on novel objects in unstructured environments.
- Developing a scalable method for task specification that moves beyond brittle programming or extensive demonstrations.

## Method

- **Dream2Flow** utilizes off-the-shelf ==image-to-video generation== models to synthesize videos depicting a task based on an initial RGB image and a language instruction.
- Extracts ==3D object flow== by estimating depth, segmenting the target object, tracking 2D points across video frames, and lifting them to 3D coordinates.
- Infers robot actions by formulating an optimization problem where the robot's objective is to follow the extracted 3D object flow, adapting the planning mechanism based on the task domain (e.g., ==particle-based dynamics==, rigid-grasp trajectory optimization, or RL rewards).

## Results

- Achieved successful manipulation across diverse objects and tasks in both simulation (e.g., Push-T) and real-world (e.g., Put Bread in Bowl, Open Oven, Sweep Pasta), with up to **8/10** success rates on real-world tasks.
- Outperformed alternative intermediate representations like AVDC and RIGVID, demonstrating superior robustness and smoother planned motions.
- 3D object flow successfully served as a reward function for reinforcement learning, enabling policies to learn embodiment-specific strategies that reproduce the desired object motion on different robot platforms.

## Takeaways

> [!tip] Key Insights
> - 3D object flow serves as an effective, embodiment-agnostic intermediate representation that can guide robots to manipulate diverse object types (rigid, articulated, deformable, granular).
> - State-of-the-art video generation models can implicitly capture intuitive physics and common-sense priors, acting as a form of "visual planning" for robotic tasks.
> - Decoupling the desired object state changes ("what") from the specific robot actions ("how") allows for greater flexibility and generalizability in robotic manipulation.
