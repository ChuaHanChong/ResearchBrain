# Dynamic Open-Vocabulary 3D Scene Graphs for Long-term Language-Guided Mobile Manipulation

> [!summary] Summary
> DovSG is a mobile manipulation framework that enables robots to perform long-term, language-guided tasks in dynamic indoor environments using dynamic open-vocabulary 3D scene graphs. The system demonstrated 35% overall long-term task success, outperforming baselines at 5%, while also reducing memory consumption by 13 times and scene graph update times by 20-27 times.

## Problem

- Mobile robots struggle to perform multi-step, long-term tasks in real-world, dynamic environments where objects are frequently moved, added, or revealed.
- Existing robotic systems often assume static scenes, limiting their applicability and requiring frequent manual resets or interventions.
- A lack of robust, efficient methods for representing and continuously updating environmental knowledge in response to unpredicted changes.

## Method

- A comprehensive framework integrating dynamic open-vocabulary 3D scene graphs with language-guided task planning, navigation, and manipulation modules for mobile robots.
- Employs an open-vocabulary 3D object mapping pipeline using VLMs (Grounding DINO, SAM-2, CLIP) to build semantic 3D object representations and infer spatial relationships.
- Implements a localized and rapid dynamic scene adaptation mechanism that identifies and updates only affected portions of the 3D scene graph, rather than reconstructing the entire scene, through precise relocalization and voxel-index-based change identification.

## Results

- DovSG achieved 93-95% Scene Change Detection Accuracy and 88% Scene Graph Accuracy, outperforming LLM-based baselines by 28-54%.
- Demonstrated 35% overall long-term task success in dynamic environments, a substantial improvement over Ok-Robot's 5%, with consistently higher subtask success rates for navigation, pick-up, and place.
- Consumed 13 times less memory (0.15 GB vs 2 GB) and performed scene graph updates 20-27 times faster (1 minute vs 20-27 minutes) compared to baselines requiring full scene reconstruction.

## Takeaways

> [!tip] Key Insights
> - Localized updates to a 3D scene graph are crucial for efficient and robust long-term mobile manipulation in dynamic environments, significantly reducing computational overhead compared to full scene reconstruction.
> - Integrating state-of-the-art Vision-Language Models (VLMs) for open-vocabulary perception and Large Language Models (LLMs) for task planning enables more flexible and adaptive robot behavior.
> - Precise visual relocalization combined with voxel-based change detection is effective for identifying scene changes and maintaining map consistency in dynamic settings.
