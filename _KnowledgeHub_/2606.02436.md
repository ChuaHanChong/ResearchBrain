# Geometry-Aware Implicit Memory for Video World Models

> [!summary] Summary
> Researchers from Nanjing University, Kuaishou Technology, and Tsinghua University developed GIM-World, a video world model employing a geometry-aware implicit memory that is directly supervised by a 3D foundation model to encode cross-view scene geometry. This enabled the model to generate long-horizon rollouts with superior geometric consistency, achieving an 81.70 normalized 3D reprojection score in first-person views on the MIND dataset, outperforming strong baselines by up to +7.73 points.

## Problem

- Existing video world models struggle to maintain long-horizon geometric and visual consistency in autoregressive generations, leading to scene deformation and memory drift over time.
- Explicit memory methods (e.g., frame retrieval, online 3D reconstructions) suffer from heuristic errors, appearance redundancy, or high computational overhead and latency.
- Current implicit memory designs compress historical information into a compact state but lack explicit geometric training signals, often encoding redundant appearance rather than fundamental scene structure.

## Method

- Introduced GIM-World, a framework featuring a lightweight, fixed-size implicit memory encoder that aggregates historical frames and camera poses into a compact memory state.
- Developed a camera-queryable geometry supervision mechanism where the memory is directly trained to reconstruct dense per-frame 3D geometric features provided by a frozen 3D foundation model.
- Implemented an information-guided pruning rule based on a Gaussian Process model to efficiently select a maximally informative subset of history frames, managing computational cost for unbounded histories.

## Results

- GIM-World achieved superior memory consistency on the MIND dataset, with an LPIPS of 0.6304 and MSE of 0.0614 in first-person views, outperforming the best explicit memory baseline (FramePack) and implicit memory baseline (VideoSSM's SSM).
- Demonstrated substantial gains in 3D geometric consistency, obtaining an 81.70 normalized 3D reprojection score in first-person settings, significantly higher than FramePack (73.97) and SSM (53.95).
- Qualitatively, the model maintained overall scene geometry, layout, and fine texture details consistently over rollouts extending to a thousand frames, preventing structural collapse and drift observed in baselines.

## Takeaways

> [!tip] Key Insights
> - Directly constraining the implicit memory to encode cross-view scene geometry via camera-queryable supervision significantly improves long-horizon geometric consistency compared to applying geometry signals to the generator itself.
> - An information-guided pruning strategy that maximizes mutual information between retained and discarded history frames is crucial for efficiently selecting informative historical context, outperforming uniform or camera-based sampling.
> - A compact self-attention mechanism within the memory encoder can drastically reduce computational overhead (less than 0.3% of backbone time) without significant degradation in generation quality, ensuring an efficient memory module.
