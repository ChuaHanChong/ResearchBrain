# Dream to Recall: Imagination-Guided Experience Retrieval for Memory-Persistent Vision-and-Language Navigation

> [!summary] Summary
> Memoir presents an agent for memory-persistent Vision-and-Language Navigation that employs a language-conditioned world model to generate imagined future states, which then guide the selective retrieval of relevant environmental observations and navigation behavioral patterns from a hybrid memory. The agent achieved a 5.4% increase in SPL on unseen IR2R scenarios and reduced training latency by 8.3x compared to existing baselines.

## Problem

- Traditional Vision-and-Language Navigation (VLN) agents operate episodically, preventing progressive learning and long-term adaptation.
- Existing memory-persistent VLN methods suffer from ineffective memory access, either incorporating irrelevant information from full memory or relying on limited, fixed-horizon lookups.
- Prior memory-persistent VLN work predominantly stores environmental observations, neglecting valuable navigation behavioral patterns crucial for decision-making.

## Method

- A language-conditioned world model is used to imagine future navigation states, generating predictive queries for adaptive experience retrieval.
- A Hybrid Viewpoint-Level Memory (HVM) stores both environmental observations and navigation behavioral patterns, organized around a persistent graph.
- An experience-augmented navigation model integrates the retrieved observations and behavioral histories using specialized encoders and a dynamic fusion mechanism to guide action selection.

## Results

- Memoir achieved a 5.4% increase in SPL on unseen IR2R scenarios (73.3% vs. 67.9%) and an 11.6% increase on seen scenarios, outperforming the GR-DUET baseline.
- The approach demonstrated significant computational efficiency gains, including an 8.3x training speedup and a 74% reduction in inference memory compared to memory-intensive baselines.
- Ablation studies confirmed the effectiveness of the imagination-based retrieval, the multi-step overshooting objective in the world model, and the dedicated integration of navigation history.

## Takeaways

> [!tip] Key Insights
> - Imagination of future states can serve as an adaptive, predictive query mechanism for selective memory retrieval, addressing limitations of full memory incorporation or fixed-horizon lookups.
> - Unifying and retrieving both environmental observations and navigation behavioral patterns provides a more comprehensive and strategically richer knowledge base for embodied navigation.
> - Training a world model with multi-step overshooting and pretraining improves long-horizon prediction and effectively grounds retrieval in the agent's navigation intent.
