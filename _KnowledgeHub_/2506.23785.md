# Visual Textualization for Image Prompted Object Detection

> [!summary] Summary
> VisTex-OVLM is a novel image-prompted object detection method that projects visual exemplars into the text feature space of Object-level Vision-Language Models (OVLMs). This approach enhances detection capabilities for rare or novel categories without altering the OVLM's original architecture, thereby preserving its pre-trained object-text alignment and generalization.

## Problem

- OVLMs demonstrate suboptimal performance on rare or underrepresented objects not sufficiently covered in their vast pre-training datasets.
- Text prompts for object detection can suffer from granularity limitations, semantic bias, or omissions, making fine-grained object distinction challenging.
- Existing few-shot methods for OVLMs often disrupt the models' pre-trained object-text alignment and generalization capabilities when adapting to new data.

## Method

- A ==visual textualization== process is introduced to convert visual information from support images into a textualized feature format compatible with OVLM text prompts.
- ==Multi-scale Textualizing Blocks (MSTB)== extract and map multi-scale visual features from image-engineered support images into the OVLM's text feature space, using a parameter-sharing strategy for efficiency.
- Textualized visual tokens are consolidated via non-parametric ==Multi-Stage Fusion (MSF)== and concatenated directly with original text prompts, then fed into an unmodified and frozen pre-trained OVLM.

## Results

- VisTex-GLIP achieved state-of-the-art performance on PASCAL VOC (e.g., **74.8** AP50 on Split 1, 10-shot) and MSCOCO few-shot object detection benchmarks, outperforming prior VLM-based methods.
- The method demonstrated superior detection for novel categories across open-set scenarios including LVIS MiniVal, 11 ODinW35 datasets, and 5 challenging medical datasets (MoNu, CCRCC, ConSep, LIDC, Deeplesion).
- Ablation studies confirmed that multi-scale textualization, parameter-sharing in MSTB, and non-parametric multi-stage fusion are critical components that synergistically enhance performance and maintain OVLM integrity.

## Takeaways

> [!tip] Key Insights
> - Projecting visual semantics from few-shot exemplars directly into the text feature space enables seamless integration with text-prompt-exclusive OVLMs without architectural modifications.
> - Employing background blur in image prompt engineering effectively highlights target objects, and multi-scale visual textualization leverages diverse feature representations for robust object learning.
> - Strictly preserving the pre-trained OVLM architecture and its object-text alignment is crucial for maintaining strong generalization capabilities across both base and novel categories, preventing performance degradation.
