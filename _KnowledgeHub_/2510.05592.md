# In-the-Flow Agentic System Optimization for Effective Planning and Tool Use

> [!summary] Summary
> AGENTFLOW introduces a trainable agentic framework for large language models that integrates specialized modules with in-the-flow reinforcement learning for effective planning and tool use. Utilizing a 7B-scale backbone, this system surpassed GPT-4o's performance across diverse complex reasoning tasks.

## Problem

- Monolithic LLMs for tool-integrated reasoning face challenges in scaling, maintaining stability over long reasoning horizons, and generalizing to diverse tasks and toolsets.
- Existing agentic systems often rely on training-free, handcrafted logic or prompting, hindering robust coordination, adaptation to dynamic tool outputs, and recovery from early mistakes.
- Long-horizon, multi-turn tasks with sparse, final-outcome rewards create a credit assignment problem for reinforcement learning, making it difficult to attribute success or failure to intermediate actions.

## Method

- AGENTFLOW proposes a modular agentic architecture with four specialized components: an ==Action Planner== (the trainable policy), Tool Executor, Execution Verifier, and Solution Generator, which interact iteratively via an evolving memory.
- It implements Flow-based Group Refined Policy Optimization (Flow-GRPO), an algorithm for *in-the-flow* on-policy training that allows the planner to adapt dynamically within the multi-turn interaction loop.
- Flow-GRPO addresses sparse rewards by assigning a single, verifiable final-outcome reward to the entire trajectory, effectively converting the multi-turn RL problem into independent single-turn updates with a global success signal.

## Results

- AGENTFLOW, using a **7B**-scale backbone, consistently outperformed all baseline models, including specialized tool-integrated systems and GPT-4o, across 10 diverse reasoning benchmarks, achieving up to an **18.0%** gain in mathematical reasoning over GPT-4o.
- The Flow-GRPO fine-tuned planner demonstrated optimized and adaptive tool usage, such as increasing Google Search usage by **42.0%** for broad knowledge tasks and shifting to targeted searches for domain-specific retrieval.
- Training with Flow-GRPO substantially reduced tool-calling error rates by up to **28.4%** on tasks like GAIA, indicating improved reliability, and exhibited enhanced self-correction capabilities in complex problem-solving scenarios.

## Takeaways

> [!tip] Key Insights
> - Combining a modular agentic design with adaptive reinforcement learning provides a more robust and efficient approach to complex, multi-step tasks than monolithic LLM agents or static agentic systems.
> - Broadcasting a global, trajectory-level reward, coupled with group-normalized advantages, simplifies the credit assignment problem in long-horizon, sparse-reward environments, enabling stable on-policy learning.
> - In-the-flow optimization allows the agent to dynamically refine planning and tool use based on real-time feedback, leading to improved reliability, task-appropriate tool selection, and autonomous solution discovery.
