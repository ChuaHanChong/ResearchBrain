# WildDet3D: Scaling Promptable 3D Detection in the Wild

> [!summary] Summary
> Researchers from the Allen Institute for AI and University of Washington developed WildDet3D, a unified monocular 3D object detection system that generalizes to thousands of object categories in diverse real-world scenes, supporting multiple prompt types and optional depth input. The accompanying WildDet3D-Data dataset provides over 3.7 million 3D annotations across 13.5 thousand categories, enabling the model to achieve state-of-the-art performance on benchmarks like WildDet3D-Bench and Omni3D.

## Problem

- Existing monocular 3D object detection methods largely focused on closed-set categories and controlled environments, limiting their applicability in diverse, real-world 'in-the-wild' scenarios.
- Prior methods frequently specialized in a single input prompt type (e.g., text or 2D bounding boxes), lacking a unified framework for flexible user interaction.
- The generation of large-scale, open-vocabulary 3D datasets has been a bottleneck due to the resource-intensive nature of obtaining metric depth and calibrated camera intrinsics.

## Method

- Introduction of **WildDet3D**, a unified monocular 3D detector that integrates ==dual-vision encoders==, a ==depth fusion module==, and a promptable detector supporting text, 2D points, and 2D bounding box inputs.
- Creation of **WildDet3D**-Data, a large-scale dataset featuring over 1 million images and 3.7 million human-verified or VLM-selected 3D annotations across 13.5 thousand object categories, curated via a semi-automatic pipeline.
- Development of a ==deeply-supervised 3D detection head== with multi-source information aggregation, one-to-many matching, and unambiguous rotation normalization for robust 3D box parameterization and training.

## Results

- WildDet3D achieved **22.6** AP3D (text prompts) and **24.8** AP3D (box prompts) on the new WildDet3D-Bench, representing a **9.8x** improvement over prior methods, with additional gains up to **47.2** AP3D when ground-truth depth was available.
- The model set new state-of-the-art performance on the Omni3D benchmark (**34.2** AP3D with text, **36.4** AP3D with box) and demonstrated strong zero-shot generalization, improving ODS by **+16.5** on Argoverse 2 and **+17.4** on ScanNet compared to baselines.
- WildDet3D successfully deployed on consumer hardware (iPhone, Meta Quest 3) for real-time interactive 3D perception and integrated into robotic manipulation and Vision-Language Models, showcasing its practical applicability.

## Takeaways

> [!tip] Key Insights
> - The integration of auxiliary 2D detection and comprehensive geometric supervision is critical, with ablation studies showing significant performance drops when these components are removed or simplified.
> - WildDet3D's architecture effectively leverages optional depth cues at inference time, leading to substantial accuracy gains in 3D localization, particularly in resolving inherent scale and occlusion ambiguities.
> - A semi-automatic, multi-stage data curation pipeline (candidates generation, rule-based filtering, human/VLM selection) can effectively scale 3D annotation to open-vocabulary and in-the-wild scenarios.
