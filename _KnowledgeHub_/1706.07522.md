# Deep Hashing Network for Unsupervised Domain Adaptation

> [!summary] Summary
> Researchers at Arizona State University developed the Domain Adaptive Hashing (DAH) network, a deep learning framework that learns representative binary hash codes to simultaneously address unsupervised domain adaptation and provide efficient data representations. The DAH model achieved an average object recognition accuracy of 45.54% on the newly introduced Office-Home dataset and consistently outperformed existing unsupervised hashing methods in Mean Average Precision (mAP).

## Problem

- Deep learning models require extensive, costly labeled data, which is often unavailable for target domains.
- Models trained on a source domain suffer performance degradation (domain shift) when applied to an unlabeled target domain.
- Existing domain adaptation benchmark datasets were often too small for robust evaluation of deep learning algorithms.

## Method

- A novel deep learning framework, **Domain Adaptive Hashing (DAH)**, was developed, building upon ==VGG-F== to learn compact ==binary hash codes== directly from the network.
- A new, larger benchmark dataset, **Office-Home**, was introduced, featuring 15,500 images across 65 categories and four distinct domains.
- A multi-component loss function was designed, incorporating ==Multi-Kernel Maximum Mean Discrepancy (MK-MMD)== for domain alignment, a ==supervised hash loss== for source data, and an ==unsupervised entropy loss== for target data.

## Results

- DAH achieved an average object recognition accuracy of **45.54%** on the Office-Home dataset, outperforming deep learning baselines like DANN (**44.94%**).
- The framework consistently surpassed all other unsupervised hashing methods in Mean Average Precision (mAP) for data retrieval, demonstrating performance closer to supervised hashing.
- Feature analysis revealed that DAH features exhibited the least A-distance between source and target domains and showed superior category clustering in t-SNE visualizations, indicating effective domain shift reduction.

## Takeaways

> [!tip] Key Insights
> - The DAH framework is the first to integrate deep feature learning with hash code generation specifically for unsupervised domain adaptation, unifying category assignment and efficient data representation.
> - Minimizing entropy on unlabeled target data effectively guides the network to learn discriminative hash values, enhancing target sample alignment with source categories.
> - The proposed loss function and network architecture significantly reduce domain discrepancy in the feature space, leading to more transferable and discriminative representations.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work addresses two prominent challenges in contemporary machine learning and data management: the data dependency of deep learning models and the efficient handling of large-scale data.

Deep neural networks have demonstrated considerable success across various application domains, particularly in computer vision, due to their ability to automatically learn discriminative features. However, a fundamental limitation of these models is their requirement for extensive labeled datasets for training. Acquiring such datasets is often a resource-intensive process, demanding significant time, labor, and human expertise. This challenge motivates the field of **domain adaptation** (or transfer learning), where models leverage labeled data from a related but different "source" domain to develop a predictive model for a "target" domain that lacks sufficient labeled data. This paper specifically focuses on **unsupervised domain adaptation**, a more challenging scenario where no labeled data is available in the target domain. Traditional shallow domain adaptation methods typically involve two stages: feature extraction, followed by domain alignment, with fixed features. In contrast, deep transfer learning methods aim to learn transferable feature representations within the deep network itself, concurrently with the adaptation process.

Concurrently, the proliferation of digital data has created substantial challenges related to its storage, retrieval, and computational processing. **Hashing** has emerged as an effective technique to address these issues, offering fast query speeds and reduced memory requirements. Hashing transforms high-dimensional data into compact binary codes, ideally generating similar codes for similar data items. While unsupervised hashing techniques have been developed for efficient data retrieval, and cross-modal hashing explores learning common hash codes for multi-modal data, the integration of deep hashing with unsupervised domain adaptation had not been thoroughly explored.

This research contributes to the intersection of these fields by proposing a deep learning framework that learns representative hash codes to simultaneously address the unsupervised domain adaptation problem and provide efficient data representations. The paper identifies a gap in existing research, noting that it is the first effort to exploit the feature learning capabilities of deep neural networks to learn hash codes specifically for unsupervised domain adaptation.

### 2. Key Objectives and Motivation

The primary motivations for this research stem from the practical limitations associated with deploying deep learning models and managing large datasets:

- **Cost of Labeled Data:** Deep neural networks necessitate large volumes of labeled data for effective training. The acquisition of such data is often prohibitively expensive in terms of time, labor, and expert annotation.
- **Domain Shift:** When a model trained on a source domain is directly applied to a target domain, performance degradation often occurs due to differences in data distributions (domain shift). Domain adaptation techniques are crucial to mitigate this issue.
- **Data Growth and Efficiency:** The continuous expansion of digital data requires efficient methods for storage and retrieval. Hashing offers a solution by transforming high-dimensional data into compact binary codes, which can significantly reduce memory footprint and accelerate similarity searches.
- **Limitations of Existing Datasets:** Existing benchmark datasets for vision-based domain adaptation (e.g., Office, Office-Caltech) were developed prior to the widespread adoption of deep learning and are often too small to adequately train and evaluate deep learning algorithms.

Based on these motivations, the paper sets forth several key objectives:

1. **Introduce a New Benchmark Dataset:** To facilitate the development and evaluation of deep learning-based domain adaptation algorithms, the authors aimed to create and release a new, larger dataset named Office-Home. This dataset is designed to be more suitable for deep learning models by offering a greater volume of images and categories across multiple distinct domains.
2. **Develop a Novel Deep Learning Framework for Unsupervised Domain Adaptation with Hashing:** The central objective was to propose a deep learning framework, termed Domain Adaptive Hashing (DAH), that can leverage both labeled source data and unlabeled target data to learn informative hash codes. These hash codes are intended for accurate classification of unseen target data.
3. **Integrate Feature Learning, Hashing, and Domain Adaptation:** The framework was designed to be the first research effort to combine the feature learning capabilities of deep neural networks with the generation of representative hash codes within an unsupervised domain adaptation setting. This involves learning a deep network that outputs binary hash codes instead of traditional probability vectors.
4. **Design a Comprehensive Loss Function:** A unique, multi-component loss function was to be formulated to effectively train the deep network. This loss function needed to incorporate supervised constraints for source data, unsupervised alignment for target data, and domain discrepancy reduction across the network layers.
5. **Empirically Evaluate Framework Effectiveness:** The framework's performance was to be rigorously evaluated through extensive empirical studies on multiple transfer tasks, demonstrating its utility in learning efficient hash codes that surpass the performance of existing competitive baselines for unsupervised domain adaptation and unsupervised hashing.

### 3. Methodology and Approach

The proposed methodology involves the development of a novel deep learning framework called Domain Adaptive Hashing (DAH) and the introduction of a new dataset.

#### 3.1. Office-Home Dataset

The authors introduce a new object recognition dataset, Office-Home, to address the scarcity of sufficiently large datasets for deep learning-based domain adaptation. This dataset comprises approximately 15,500 images organized into 65 categories of everyday objects across four distinct domains:
- **Art:** Artistic renditions of objects (sketches, paintings, etc.).
- **Clipart:** Clipart images.
- **Product:** Images of objects without backgrounds (similar to Amazon listings).
- **Real-World:** Images of objects captured with a standard camera in natural settings.
The images were collected from public domain websites and manually filtered. Baseline classification accuracies using VGG-F features and LIBLINEAR SVM were reported for each domain.

#### 3.2. Domain Adaptive Hashing (DAH) Network Architecture

The DAH network is built upon the VGG-F convolutional neural network, which was pre-trained on the ImageNet 2012 dataset. This adaptation strategy circumvents the need to train a deep CNN from scratch with limited domain adaptation data. The architecture consists of:
- **Convolutional Layers:** Five layers (conv1-conv5) fine-tuned from VGG-F, recognized for producing generic, transferable features.
- **Fully Connected Layers:** Two layers (fc6, fc7) also fine-tuned, which tend to be more task-specific and require adaptation.
- **Hashing Layer (hash-fc8):** This layer replaces the standard fc8 layer. It is designed to output real-valued vectors in R^d, which are subsequently binarized using a sign function (sgn(.)) to produce binary hash codes h_i ∈ {-1, +1}^d.
- **Activation and Normalization:** To mitigate vanishing gradients and ensure the components of the real-valued output (u_i) are bounded between -1 and +1, a batch normalization layer is introduced before a tanh activation function within the hash-fc8 layer. This setup contributes to training stability.

#### 3.3. Multi-Component Loss Function

The DAH network is trained to minimize a combined loss function (J), comprising three main components weighted by hyperparameters γ and η:
min_U J = L(U_s) + γM(U_s, U_t) + ηH(U_s, U_t)

1. **Multi-Kernel Maximum Mean Discrepancy (MK-MMD) Loss (γM(U_s, U_t)):**
 - **Purpose:** To reduce the domain discrepancy between the feature representations of the source (U_s) and target (U_t) data. This aims to learn transferable features by aligning their distributions.
 - **Application:** This loss is applied at the fully connected layers (fc6, fc7, hash-fc8) of the network, as these layers produce more task-specific features that require adaptation.
 - **Mechanism:** MK-MMD measures the difference between two data distributions in a reproducing-kernel Hilbert space. A characteristic kernel k(.) is defined as a convex combination of multiple positive semi-definite (PSD) kernels, which enhances its ability to capture complex distribution differences. The authors use a linear-time estimate for the unbiased MK-MMD.

2. **Supervised Hash Loss for Source Data (L(U_s)):**
 - **Purpose:** To ensure that source data samples belonging to the same category have similar hash codes (low Hamming distance), while samples from different categories have dissimilar hash codes (high Hamming distance).
 - **Mechanism:** This loss is based on the negative log-likelihood of a similarity matrix S, where S_ij = 1 if x_i and x_j are from the same category, and 0 otherwise. The dot product of hash values (h_i^T h_j) is used as a similarity measure, related to the Hamming distance.
 - **Relaxation and Quantization:** The discrete optimization problem of learning binary hash codes is relaxed by solving for continuous real-valued outputs (u_i) from the network's hash-fc8 layer. To minimize the approximation error introduced by this relaxation and the subsequent binarization (u_i -> sgn(u_i)), a quantization loss term (||u_i - sgn(u_i)||^2) is added.

3. **Unsupervised Entropy Loss for Target Data (ηH(U_s, U_t)):**
 - **Purpose:** In the absence of labels for target data, this loss guides the network to learn discriminative hash values for target samples by aligning them with source categories. It encourages each target sample to align closely with exactly one source category and be distinct from others.
 - **Mechanism:** For each target data point x_i, a probability p_ij is calculated, representing the likelihood of x_i belonging to source category j. This probability is based on the similarity (dot product) between the target output u_t_i and multiple source outputs u_s_j_k from category j, normalized across all categories. The entropy of this probability vector p_i is then minimized. Minimizing entropy drives p_i towards a one-hot vector, indicating a strong assignment of the target sample to a single category. This makes the target hash codes discriminative even without direct labels.

#### 3.4. Training Details

- The network is trained end-to-end using standard backpropagation.
- Learning rates for convolutional and initial fully connected layers are set lower (1/10th) than the hash-fc8 layer, typically varying between 10^-4 and 10^-5 over 300 epochs, with momentum 0.9 and weight decay 5 × 10^-4.
- A batch size of 155 source samples (31 categories x 5 samples/category) and 155 randomly selected target samples is used for the Office dataset, totaling 310. For Office-Home (65 categories), the batch size is 650.
- The hash code length (d) is fixed at 64 bits for main experiments.
- Hyperparameters γ and η are tuned: η is set to 1 for entropy loss, while γ for MK-MMD is estimated by validating a binary domain classifier.
- The target classifier assigns a label based on the class with the largest probability (max_j(p_ij)) derived from the hash codes.

### 4. Main Findings and Results

The research presents extensive empirical studies on both unsupervised domain adaptation and unsupervised domain adaptive hashing across the Office and Office-Home datasets.

#### 4.1. Unsupervised Domain Adaptation (Classification Accuracy)

- **Office-Home Dataset:** The DAH algorithm consistently achieved higher object recognition accuracies compared to all evaluated baselines. These baselines included shallow learning methods (Geodesic Flow Kernel (GFK), Transfer Component Analysis (TCA), Correlation Alignment (CORAL), Joint Distribution Adaptation (JDA)) and deep learning methods (Deep Adaptation Network (DAN), Domain Adversarial Neural Network (DANN)). DAH achieved an average accuracy of 45.54%, outperforming DANN (44.94%) and DAN (43.46%).
- **Office Dataset:** For the Office dataset, DAH achieved an average accuracy of 73.04%. While DAH still outperformed most shallow and deep baselines, DANN marginally surpassed DAH with an average accuracy of 75.15%. The authors suggest that DAH's performance advantage may be more pronounced with a larger number of categories, as seen in Office-Home (65 categories vs. Office's 31 categories). They hypothesize that domain adversarial training might be more effective with fewer categories, whereas DAH's approach to learning transferable features for many categories is beneficial when the category count is high.
- **Impact of Entropy Loss:** Comparison between DAH (with entropy loss) and DAH-e (without entropy loss) showed that DAH consistently yielded better performance. This indicated that minimizing entropy on the target data, which encourages target samples to align with specific source categories, contributes to improved accuracy by enhancing the alignment of source and target samples.

#### 4.2. Feature Analysis

- **A-Distance:** An analysis of the A-distance, which quantifies the discrepancy between two domains, was performed on the fc7 layer features. DAH features exhibited the least A-distance between source and target domain pairs (e.g., Ar -> Cl, Ar -> Pr, Ar -> Rw) compared to features extracted by Deep (VGG-F without adaptation) and DAN models. This suggests that DAH effectively reduces the domain shift in the feature space.
- **t-SNE Embeddings:** Visualizations using t-SNE embeddings further supported these findings. While Deep features showed minimal overlap between domains and poor category clustering, DAN features demonstrated improved overlap and clustering. DAH features provided the most distinct domain overlap and category clustering, corroborating its efficacy in learning representative and transferable features for domain adaptation.

#### 4.3. Unsupervised Domain Adaptive Hashing (Mean Average Precision - mAP)

- **Performance Comparison:** DAH consistently outperformed all other unsupervised hashing methods. These included traditional unsupervised hashing algorithms (Iterative Quantization (ITQ), K-Means Hashing (KMeans)), and state-of-the-art deep unsupervised hashing techniques (Binary Autoencoders (BA), Binary Deep Neural Network (BDNN)). DAH also significantly surpassed the 'NoDA' baseline, which involved training a supervised hashing model on the source domain without any domain adaptation.
- **Relative to Supervised Hashing:** The DAH algorithm demonstrated performance closer to the upper bound set by supervised hashing (SuH), which uses labeled data directly from the target domain. This indicates its effectiveness in leveraging labeled source data to learn efficient hash codes for an unlabeled target domain.
- **Hash Code Length:** Experiments with varying hash code lengths (16, 64, and 128 bits) showed that while DAH's performance generally improved with increasing bit length, it was not always a linear increase. For instance, for the Real-World domain with d=128 bits, DAH surprisingly outperformed SuH, suggesting that in certain scenarios, domain adaptation can lead to a more generalized model for hashing even when local target labels are available. The 'NoDA' method consistently showed the poorest performance, highlighting the necessity of addressing domain disparity when learning hash codes from a different domain.

### 5. Significance and Potential Impact

This research introduces a deep learning framework that addresses critical challenges in machine learning and data management, demonstrating several significant contributions and potential impacts:

1. **Novel Integration of Hashing and Unsupervised Domain Adaptation:** The DAH framework is presented as the first research effort to comprehensively integrate the feature learning capabilities of deep neural networks with hash code generation for unsupervised domain adaptation. This unified approach simultaneously tackles the problem of category assignment under weak supervision (due to domain shift) and the estimation of compact hash codes for efficient data processing in an unsupervised setting.
2. **Addressing Data Scarcity and Cost:** By enabling models to effectively learn from labeled source data and unlabeled target data, DAH reduces the reliance on expensive and time-consuming manual annotation for target domains. This has broad applicability in scenarios where acquiring labeled data for new tasks or environments is impractical.
3. **Enhanced Efficiency for Large-Scale Data:** The generation of compact binary hash codes directly from the deep network allows for fast and memory-efficient storage and retrieval of large-scale visual data. This is particularly relevant in the era of exponential data growth, facilitating applications such as large-scale image search, content-based retrieval, and data indexing in real-world systems.
4. **Improved Model Transferability:** The DAH framework explicitly aims to learn transferable feature representations and align source and target domains through its multi-component loss function, leading to more robust models that generalize better to unseen target data distributions. The empirical results demonstrate that DAH produces more discriminative and domain-invariant features compared to several baselines.
5. **New Resource for Research:** The introduction of the Office-Home dataset provides a valuable, larger-scale benchmark for the deep learning and domain adaptation research communities. This dataset, with its 65 categories and 4 diverse domains, offers a more challenging and realistic environment for evaluating novel deep learning algorithms for domain adaptation, thereby fostering further innovation in the field.
6. **Broader Applicability:** The integrated framework has potential applications across various fields requiring efficient recognition, retrieval, and analysis of data across different modalities or environments, such as robotics, medical imaging, surveillance, and e-commerce.

In summary, the DAH framework offers a practical and effective solution for developing deep learning models that are efficient in both training data requirements and runtime data handling, thereby advancing the state-of-the-art in both domain adaptation and hashing techniques.
