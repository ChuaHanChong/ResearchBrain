# SPOT: SE(3) Pose Trajectory Diffusion for Object-Centric Manipulation

> [!summary] Summary
> SPOT is an object-centric imitation learning framework that leverages SE(3) object pose trajectories and diffusion models to learn complex robotic manipulation skills. It decouples robot embodiment and automatically learns planning constraints from demonstrations, achieving 79.4% average success on RLBench and successfully transferring skills from just eight iPhone-shot human demonstrations to a robot for tasks like pouring water.

## Problem

- Traditional robotic imitation learning methods tightly couple sensory inputs with robot-specific actions, limiting generalization across different robot embodiments and hindering learning from action-less human demonstrations.
- Complex manipulation tasks often involve implicit planning constraints (e.g., maintaining object orientation) that typically require manual rule-crafting or pre-programmed solutions, hindering scalability.
- Acquiring large quantities of high-quality robot demonstration data is resource-intensive and often inaccessible to non-experts.

## Method

- Introduce an object-centric, embodiment-agnostic representation by tracking SE(3) pose trajectories of task-relevant objects relative to each other using zero-shot 6D pose estimation.
- Develop a diffusion model that learns to synthesize future object pose trajectories, implicitly encoding complex planning constraints observed in demonstrations.
- Implement a closed-loop control system using receding horizon control to translate the synthesized object pose trajectories into robot end-effector subgoals, enabling reactive execution.

## Results

- Achieved an average success rate of **79.4%** across 13 RLBench tasks, performing comparably to a four-camera state-of-the-art method with only a single camera and outperforming other single-view baselines.
- Demonstrated successful transfer of skills to a physical robot from as few as eight action-less, iPhone-shot human video demonstrations for complex real-world tasks like pouring water.
- Showed superior performance over a point-tracking baseline in real-world scenarios, effectively adhering to implicit task constraints (e.g., maintaining object orientation) and exhibiting higher precision.

## Takeaways

> [!tip] Key Insights
> - The full SE(3) object pose trajectory, relative to a target object, acts as an effective intermediate representation for implicitly capturing complex task planning constraints from demonstrations.
> - Decoupling robot embodiment through object-centric pose trajectories enables learning from diverse, action-less human video demonstrations and facilitates cross-embodiment generalization.
> - Employing a diffusion model to synthesize future object pose trajectories provides a robust and generative approach for planning and executing intricate manipulation sequences.
