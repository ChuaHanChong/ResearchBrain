# DeltaMem: Towards Agentic Memory Management via Reinforcement Learning

> [!summary] Summary
> DeltaMem recasts persona memory management as a single-agent, end-to-end task: one ReAct agent reasons over an incoming dialogue session, searches the existing memory bank with a tool, and emits add/update/none operations. A memory-evolving data synthesis pipeline supplies operation-level labels, and a Memory-based Levenshtein Distance reward drives GRPO training. Both training-free and RL variants beat production multi-agent systems on LoCoMo, HaluMem, and PersonaMem.

## Problem

- Multi-agent memory pipelines split extraction, retrieval, and updating into stages whose discrete message passing acts as lossy compression, attenuating context in already session-fragmented long-term dialogue.
- OS-inspired stores manage memory reactively through atomic CRUD calls, without explicitly modeling how stored memories temporally evolve and get recontextualized across later sessions.
- Prior RL memory training uses downstream QA accuracy as a proxy reward, which is sparse and unreliable since questions rarely cover every memory entry in a session.

## Method

- **DeltaMem**, a single ==ReAct== memory agent that per session interleaves reasoning with a search tool over the memory bank, then outputs one consolidated add/update/none operation set.
- ==Memory-evolving guided data synthesis== in four steps (profile enrichment, event generation, memory generation, dialogue generation), with intra-event and inter-event evolution operators producing dialogues plus operation-level labels.
- ==Memory-based Levenshtein Distance==: ==optimal-transport matching== of state complements, thresholded and weighted by keyword local lexical fidelity, yielding a ==soft-F1 reward== combined with format and retrieval rewards for ==GRPO==.

## Results

- On LoCoMo, DeltaMem-8B-RL reaches **75.13** overall LLM-judge and **50.72** F1, above LightMem **66.43** and Zep **65.99**; RL adds **4.1** judge points over training-free.
- On HaluMem, RL lifts 8B extraction from **68.02** to **80.65** and updating to **41.54**, with best QA **66.43** versus LightMem **58.38** and Zep **55.47**.
- PersonaMem overall hits **63.61** versus Memobase **58.89**; New-Ideas rises **24.73** to **40.14**, and removing local lexical fidelity costs roughly **3** points.

## Takeaways

> [!tip] Key Insights
> - Collapsing a modular multi-agent pipeline into one end-to-end agent can beat it outright: stage boundaries leak more context than their structure buys back.
> - Rewarding the resulting memory state instead of individual operations avoids cross-type operation matching and converts sparse downstream signals into dense trajectory-level feedback.
> - Embedding similarity alone rewards vague near-matches; keyword anchoring fixes factual fidelity, but richer detail slightly hurt generalization to unseen scenarios.

## Detailed Report

### 1. How this work fits into the broader research landscape

The field of large language models (LLMs) has demonstrated capabilities across various real-life scenarios, leading to an increasing demand for personalized AI systems. A critical component for such personalization is an ancillary long-term persona memory management system.

Earlier approaches to persona memory management, such as MemGPT and MemoryBank, primarily drew inspiration from operating system designs and retrieval-augmented generation (RAG) paradigms. These systems treated memory management as akin to OS management, maintaining a memory database through atomic Create, Read, Update, and Delete (CRUD) operations. These methods largely operate in a reactive manner, lacking explicit modeling of memory's temporal evolution.

More recent advancements, exemplified by systems like Mem0 and LightMem, have explored multi-agent architectures to enhance the autonomy of memory management. These multi-agent systems typically decompose memory management into sequential steps: memory extraction, memory retrieval, and memory updating. While modular in design, the paper argues that this distinct separation introduces limitations. Specifically, in long-term interaction scenarios where context is often fragmented due to session-based slicing, imposing a multi-agent architecture can exacerbate context loss. The handover between discrete steps in a multi-agent setting is described as a "lossy compression" process, potentially stripping away subtle contextual dependencies. Previous research has also noted limitations when comparing single-agent and multi-agent systems in certain contexts.

A further limitation in the existing landscape is the scarcity of datasets that support operation-level evaluation for training memory systems. This has led prior studies, such as Memory-R1, to rely on downstream task accuracy as a proxy reward in reinforcement learning (RL) frameworks. However, this approach often results in sparse reward issues, hindering effective convergence of the training process.

DeltaMem positions itself within this landscape by proposing an alternative: formulating persona memory management as an end-to-end task within a single-agent setting. This aims to mitigate the information loss associated with modular multi-agent pipelines. Furthermore, the work addresses the data scarcity and sparse reward problems by introducing a novel data synthesis methodology and a tailored RL framework with a state-centric reward function. This shifts the focus from optimizing individual memory operations or downstream tasks to optimizing the overall memory state transition.

### 2. Key objectives and motivation

The primary objective of this research is to develop an agentic memory management system, termed DeltaMem, that addresses identified limitations in existing persona-centric memory systems. This overarching goal is underpinned by several specific objectives and motivations:

- **Formulating Persona Memory Management as a Single-Agent, End-to-End Task:** The central motivation for this objective stems from the perceived weaknesses of multi-agent memory systems. Current multi-agent frameworks, which separate memory management into distinct extraction, retrieval, and updating modules, are argued to suffer from "cascading information attenuation" and fragility across varying scenarios. This is particularly problematic in long-term interaction contexts where dialogue is inherently fragmented into sessions. The discrete message passing between agents in such modular systems can lead to lossy compression, diminishing subtle contextual dependencies. By adopting an end-to-end single-agent setting, DeltaMem aims to allow the system to dynamically adjust its focus across the entire memory context, thereby mitigating information loss. This approach employs the Reasoning-and-Act (ReAct) paradigm to enable the agent to autonomously reason, incorporate tools for memory extraction and retrieval, and generate operations to update its memory bank.

- **Developing a Learnable Memory Management Objective:** Beyond the architectural shift, a key objective is to enhance DeltaMem's capabilities through learning. The motivation here is the recognition that existing research lacks suitable datasets for operation-level evaluation and training of memory systems. Prior RL-based approaches (e.g., Memory-R1) resorted to using downstream task accuracy as a proxy reward, which often results in sparse reward signals and hindered convergence for the memory updating module. The authors aim to overcome this by creating a direct and effective learning mechanism.

- **Synthesizing Operation-Level Memory Updating Data:** To enable the learnable objective, a critical sub-objective is to generate a comprehensive dataset that includes user-assistant dialogues along with corresponding operation-level memory updating labels. This is motivated by the absence of such granular data in the current research landscape. Drawing inspiration from human memory evolution, the authors aim to synthesize data that explicitly details how memory should be updated (e.g., add, update, none operations) in response to dialogue.

- **Introducing a State-Centric Reward for Reinforcement Learning:** Building on the synthesized data, another objective is to formalize a reward mechanism that accurately reflects the quality of memory management. The motivation is to move beyond proxy rewards from downstream tasks, which can be unreliable and sparse. Instead, the authors propose a memory state-centric perspective, where the reward is derived from the difference between the generated memory state and a target memory state. This involves defining a novel metric, the Memory-based Levenshtein Distance, to quantify this divergence. This direct evaluation of memory state transitions is intended to provide a more precise and consistent learning signal for the RL framework.

In summary, the core motivations are to overcome the architectural limitations of multi-agent systems, address the data scarcity for operation-level memory training, and develop a robust RL framework with a direct, state-centric reward function to improve the long-term persona memory management capabilities of LLMs.

### 3. Methodology and Approach

DeltaMem proposes an agentic memory management system that operates in an end-to-end single-agent setting, departing from conventional multi-agent frameworks. The methodology is structured around three main components: the overall DeltaMem framework, a data synthesis method, and a reinforcement learning framework.

#### 3.1. Overall Framework of DeltaMem

DeltaMem formulates persona memory management as an end-to-end task within a single-agent architecture, utilizing the Reasoning-and-Act (ReAct) paradigm. The system manages a memory bank `m = {(m_i, t_i, id_i)}`, where each memory point is an atomic sentence `m` with a timestamp `t` and a unique ID `id`. A memory state `S_t` at time `t` is defined as a finite partial function mapping unique memory IDs to content-timestamp tuples.

The memory management process is viewed as a state transition: `S_{t+1} = f(S_t, d_{t+1})`, where `f` is a state transition function that transforms the current state `S_t` to the next state `S_{t+1}` based on a new dialogue session `d_{t+1}` and an operation space `O = {add, update}`.

Upon ingesting a new dialogue session, the DeltaMem agent autonomously reasons and interacts with a search tool. This interaction incorporates memory extraction and retrieval to identify relevant memories from the existing memory bank. Subsequently, the agent outputs a series of memory operations to update the memory bank before proceeding to the next session. This iterative process allows the memory bank to be maintained from scratch in an agentic manner.

#### 3.2. Memory Evolving Guided Data Synthesis

To address the scarcity of training data that supports operation-level evaluation, the authors introduce a novel data synthesis methodology inspired by human memory evolution. This process generates long-term user-assistant dialogues along with corresponding target memory updating operations. The synthesis involves four sequential steps:

1. **Profile Enrichment**: A detailed user profile and an initial memory state are synthesized based on a seed persona. This step establishes the foundational characteristics of the synthetic user.
2. **Event Generation**: A chronological sequence of `N=25` discrete event summaries is synthesized over a 1-3 year horizon, conditioned on the user profile. This step enforces distributional constraints across six semantic domains (e.g., work, health) and employs a state-delta tracking mechanism. This mechanism ensures that for each event `e_t`, an explicit state update vector `ΔS_t` is generated, targeting four specific tracks (career, health, relationship, preference) using operators like {new, expand, adjust, shift, partial deletion}. An "information preservation invariant" ensures that modifications to existing facts require reproducing the exact prior state string.
3. **Memory Generation**: This core step involves synthesizing diverse memory operations and their associated keywords for each event. It includes three components:
 - **Intra-Event Memory Evolving**: Models how specific events trigger alterations in user characteristics (career, health, relationship, preference) using mechanisms such as expand, adjust, shift, and partial deletion.
 - **Inter-Event Memory Evolving**: Models how subsequent events retrospectively alter a user’s perception of preceding ones. It establishes links between semantically related events, designating the chronologically earliest as a "memory anchor." Three evolution mechanisms (emotional updates, meaning updates, self-belief shifts) are used to integrate new context into this anchor.
 - **Memory Filling**: Leverages event summaries and existing update operations to synthesize remaining memory "add" operations. Semantically relevant memories from preceding events are sometimes reused for "none" operations to enhance robustness.
4. **Dialogue Generation**: For each event, user-assistant dialogues are synthesized based on the generated profile, events, and memory operations. This step enforces strict factual adherence and temporal consistency, employing a "user-first" information flow constraint where the AI assistant cannot reference entities until the user introduces them. An internal Chain-of-Thought process generates a "Work Plan" for fact introduction.

This synthesis process provides, for any session `d_t` at time `t`, its prior memory state `S_t`, a corresponding operation set `o_t = {(m, op, K)}`, and the resulting next memory state `S_{t+1}`.

#### 3.3. Reinforcement Learning via State Transition

To further enhance DeltaMem, a reinforcement learning (RL) framework is introduced, addressing the limitations of sparse rewards from downstream tasks.

- **Motivation: From Operation to State**: Instead of evaluating generated operations directly, the approach quantifies the semantic transition cost required to transform a predicted memory state (`S_pred`) into a target memory state (`S_target`). This involves isolating distinct components using relative complements: `Δ_pred = S_pred \ S_target` (redundant entries) and `Δ_target = S_target \ S_pred` (missing entries).

- **Memory-based Levenshtein Distance**: This metric quantifies the semantic transition cost between `Δ_pred` and `Δ_target`. It models alignment as an Optimal Transport problem, computing a semantic similarity matrix `Φ` between elements of the two sets. A similarity threshold `τ` filters low-similarity matches. Crucially, it incorporates **local lexical fidelity** (`s_ij`), which measures the proportion of pre-defined ground truth keywords (`K_j`) from a target entry (`y_j`) present in an aligned predicted entry (`x_i`). This ensures reward is given for factual detail, not just semantic proximity. The final distances (`dist+` for false positives, `dist-` for true negatives) are formulated by accounting for these keyword coverage scores.

- **State Transition-Based Reward Modeling**: The memory-based Levenshtein Distance is normalized into soft precision (`P_soft`) and soft recall (`R_soft`). Soft precision penalizes redundant predicted entries that do not align with target entries, while soft recall penalizes missing target entries. To provide a balanced optimization objective, the **soft F1 score** is used as the primary reward `r_trans`: `r_trans = 2 * (P_soft * R_soft) / (P_soft + R_soft + ε)`. Maximizing `r_trans` encourages minimizing edit costs to navigate the memory state towards the target.

- **Reinforcement Learning Formulation**: In addition to `r_trans` (weighted at 0.8), two binary rewards are introduced: `r_format` (0.1 weight) to ensure adherence to the ReAct paradigm, and `r_retrieval` (0.1 weight) to check if the model recalls existing memories for update/add operations. The overall reward `r = 0.1 * r_format + 0.1 * r_retrieval + 0.8 * r_trans`. The training framework follows standard GRPO (Group-normalized Proximal Policy Optimization). During training, the policy model interacts with the current memory state `S_t` for a given dialogue session `x`, generates operations, and `r_trans` is calculated based on the resulting `S_{t+1}` and generated pseudo memory states for RL training.

### 4. Main Findings and Results

The experiments conducted on LoCoMo, HaluMem, and PersonaMem benchmarks demonstrate the performance of DeltaMem, both in its training-free and reinforcement learning (RL)-trained configurations.

#### 4.1. General Performance Across Benchmarks

DeltaMem, both training-free and RL-trained versions, consistently outperformed product-level baselines across all evaluated long-term memory benchmarks. This indicates the effectiveness of the proposed single-agent, end-to-end framework and the subsequent RL optimization.

#### 4.2. LoCoMo Benchmark

On the LoCoMo benchmark (Table 1), which evaluates long-range conversational memory across single-hop, multi-hop, open domain, and temporal query categories, DeltaMem exhibited strong performance.
- The RL-optimized variant, **DeltaMem-8B-RL**, achieved an Overall LLM-as-a-Judge (LJ) score of 75.13 and an F1 score of 50.72. This represents a substantial margin over the highest-performing baselines, LightMem and Zep.
- The introduction of RL fine-tuning resulted in a 4.1 point increase in the LJ score for the 8B model, indicating the impact of optimizing the memory policy for dynamic contexts.
- DeltaMem demonstrated robustness in reasoning-intensive tasks, particularly in the Temporal category, scoring 73.83, which suggests improved handling of memory evolution compared to static retrieval methods.

#### 4.3. HaluMem Benchmark

The HaluMem dataset (Table 3) assesses memory extraction, updating, and downstream question answering capabilities.
- **DeltaMem-8B-RL** achieved a Question Answering score of 66.43, outperforming both the best training-free baseline, LightMem, and the commercial solution Zep.
- The RL optimization notably boosted the memory extraction score for the 8B model from 68.02 (training-free) to 80.65, suggesting enhanced learning in identifying salient information.
- While Zep achieved a higher Memory Updating score, DeltaMem-8B-RL maintained a competitive updating score while securing the best overall QA performance, which implies a more balanced and effective pipeline for integrating extracted and updated memories into final responses.

#### 4.4. PersonaMem Benchmark

On the PersonaMem benchmark (Table 2), which evaluates long-term personalization in multi-session human-AI interactions, DeltaMem-8B-RL achieved an Overall score of 63.61, surpassing baselines such as Memobase, Zep, and Mem0.
- The impact of reinforcement learning was particularly evident in generative tasks. For instance, in the "New-Ideas" metric, DeltaMem-8B-RL scored 40.14, a 62% relative improvement over its training-free counterpart (24.73).
- The method also demonstrated a balance between generative capabilities and precision, achieving a top-tier score of 76.47 in "Recall-Facts," indicating the agent's ability to evolve user preferences without compromising factual accuracy.

#### 4.5. Training Dynamics

Analysis of the RL training dynamics (Figure 2) showed that both DeltaMem-4B-RL and DeltaMem-8B-RL models exhibited rapid initial performance gains, followed by a steady convergence where rewards stabilized around 0.75. The validation reward closely tracked the training reward, suggesting robust generalization without overfitting.

#### 4.6. Ablation and Analysis

- **Effectiveness of Local Lexical Fidelity**: Replacing the local lexical fidelity score in the memory-based Levenshtein Distance with original similarity for training led to a performance drop. The original DeltaMem-8B-RL showed significant gains in "recalling user-shared facts" and "recalling facts mentioned by the user" (Figure 3). This suggests that local lexical fidelity enhances the memory manager's fact extraction capability and preserves memory integrity, contributing approximately 3 points of overall performance gain on PersonaMem.
- **Impact of Threshold τ**: Experiments on the threshold `τ` for filtering low-similarity matches revealed that both excessively small (e.g., 0.0) and large (e.g., 0.9) values degraded performance on LoCoMo (Table 4). Performance was stable when `τ` ranged from 0.7 to 0.8, with 0.75 chosen as the optimal setting.
- **Stable Performance Across Time**: Evaluation on HaluMem showed that all methods experienced a performance drop as the number of sessions increased. However, DeltaMem consistently surpassed LightMem as the memory bank expanded, and its accuracy curve demonstrated greater stability over time (Figure 4).
- **Alleviation of Heavy Retrieval**: The RL-trained DeltaMem models significantly reduced the number of queries per memory (0.13 for DeltaMem-4B-RL/8B-RL) compared to baselines like Mem0 (1.00 query per memory) (Table 7). This indicates that the agent learns to manage retrieval efficiently, contributing to overall performance improvement.

### 5. Significance and Potential Impact

The DeltaMem research presents a shift in the approach to long-term persona memory management for large language models, offering several points of significance and potential impact:

- **Paradigm Shift to Single-Agent End-to-End Management**: The core contribution is the formulation of persona memory management as an end-to-end task within a single-agent setting. This contrasts with previous multi-agent modular designs, which the paper argues suffer from information loss and fragility in fragmented, long-term conversational contexts. By integrating extraction, retrieval, and updating within one agent using the ReAct paradigm, DeltaMem offers a potentially more cohesive and robust approach to managing dynamic user memories.

- **Addressing Data Scarcity for Operation-Level Training**: The introduction of a novel memory evolving guided data synthesis framework is a significant advancement. The lack of operation-level datasets for memory updating has been a notable challenge in the field, leading previous methods to rely on suboptimal proxy rewards. This synthetic data generation method provides granular, operation-level labels, enabling more direct and effective training of memory management systems.

- **Novel State-Centric Evaluation and Reinforcement Learning**: The development of a memory-based Levenshtein Distance and its integration into a tailored reinforcement learning framework represents a new approach to optimizing memory management. By focusing on the semantic transition between memory states rather than individual operations or downstream task performance, the method provides a more direct and less sparse reward signal. The inclusion of local lexical fidelity further refines this reward, encouraging factual accuracy in memory updates.

- **Demonstrated Performance Advancement**: The extensive experimental results across diverse benchmarks (LoCoMo, HaluMem, PersonaMem) show that DeltaMem, particularly its RL-trained variants, consistently outperforms multiple product-level and training-free baselines. This indicates that the proposed architectural and learning-based innovations lead to tangible improvements in memory extraction, updating, and memory-augmented question answering. The notable performance gains in generative tasks and the ability to balance generative capabilities with factual precision underscore its effectiveness.

- **Improved Efficiency in Memory Retrieval**: The finding that RL-trained DeltaMem significantly reduces the number of queries per memory highlights an important efficiency gain. By autonomously choosing what to retrieve and how to organize queries, the system alleviates the "heavy retrieval" issue often associated with more rigid memory management pipelines.

**Potential Impact and Considerations (as per Impact Statement):**

- **Robust Agentic Memory Systems**: This work contributes to the development of more robust agentic memory systems, which are crucial for advanced, personalized AI agents. The ability to manage long-term persona memory effectively is foundational for more sophisticated human-AI interactions.
- **Scalable and Diverse Training Data**: The data synthesis method provides a scalable way to generate diverse training and evaluation data without the privacy concerns associated with using real user logs. This can accelerate research and development in agentic memory.
- **Ethical Considerations**: The authors acknowledge potential risks. Synthetically generated personas, even when sampled randomly for diversity, may still reflect or amplify social stereotypes present in the underlying LLM's training data. This implies that the synthesized conversations are approximations, not perfect substitutes, for human behavior.
- **Data Contamination**: The widespread generation of synthetic text poses a risk of data contamination for future models. To mitigate this, releasing the dataset with clear metadata indicating its synthetic nature is suggested.
- **Optimization on Synthetic Metrics**: Researchers are advised to exercise caution when optimizing solely on synthetic metrics, as these may diverge from real-world user preferences. This emphasizes the need for continued validation against real-world scenarios.
