# MVR: Multi-view Video Reward Shaping for Reinforcement Learning

> [!summary] Summary
> MVR leverages multi-view video-text similarity and a state-dependent reward shaping mechanism to provide robust visual guidance for reinforcement learning agents. This framework consistently improved performance on challenging dynamic locomotion and manipulation tasks by mitigating occlusion and adaptively integrating VLM feedback.

## Problem

- Existing VLM-based reward methods often rely on single, static images, leading to mis-specified guidance for tasks requiring dynamic motions and potentially incentivizing static poses.
- Single viewpoints are prone to occlusions and viewpoint-dependent biases, making it difficult to assess agent behavior comprehensively and requiring manual effort for optimal view selection.
- Linearly adding VLM-derived scores to task rewards without principled shaping can inadvertently alter the optimal policy or create persistent conflicts with the primary task objectives.

## Method

- **MVR** integrates multi-view video observations and ==video-text similarity== to better characterize dynamic behaviors and mitigate viewpoint-dependent biases.
- A state relevance model (`f_MVR`) is learned from multi-view videos using a paired comparison objective (`L_matching`) and state representation regularization (`L_reg`), bridging the semantic gap between states and visual features.
- A state-dependent reward shaping formulation automatically reduces the influence of VLM guidance (`r_VLM`) as the agent's behavior aligns with desired patterns, allowing the primary task reward to dominate later in learning.

## Results

- MVR achieved the best average rank (**1.67** for HumanoidBench, **1.50** for MetaWorld) across **19** challenging locomotion and manipulation tasks, outperforming existing VLM-based methods and task-reward-only baselines.
- Ablation studies confirmed the necessity of multi-view videos, the paired comparison objective, state representation regularization, and the automatic reward shaping mechanism for MVR's robust performance.
- The framework's `r_VLM` term for the 'Sit_Hard' task successfully identified and discouraged visually suboptimal sitting poses that were otherwise tolerated by `r_task`, leading to more stable and robust learned skills.

## Takeaways

> [!tip] Key Insights
> - Multi-view video analysis provides more robust and effective visual guidance for dynamic agent behaviors than single-image approaches, addressing limitations like occlusion and temporal mis-specification.
> - Learning a state relevance model by aligning relative orderings of state sequences with VLM video-text similarity, combined with viewpoint-invariant state representation regularization, is critical for robust reward shaping.
> - An adaptive reward shaping mechanism that naturally decays its influence as the agent improves ensures that VLM-based guidance aids early exploration without long-term conflicts with the core task objective.
