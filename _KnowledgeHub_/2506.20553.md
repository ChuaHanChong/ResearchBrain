# Sim2Val: Leveraging Correlation Across Test Platforms for Variance-Reduced Metric Estimation

> [!summary] Summary
> NVIDIA researchers developed Sim2Val, a framework for estimating real-world performance metrics of learning-based robotic systems using significantly fewer expensive real-world samples. The method leverages correlation across test platforms to reduce variance in metric estimation, enabling higher confidence intervals with less data.

## Problem

- The cost and time required for comprehensive real-world testing of autonomous systems are prohibitive.
- Achieving high-confidence performance estimates for safety-critical applications with limited real-world data is challenging.
- A persistent "sim-to-real gap" means performance in simulation does not perfectly translate to real-world outcomes.

## Method

- Sim2Val applies the classical statistical method of control variates, leveraging both a small set of paired real-world and surrogate samples, and a large set of surrogate-only samples.
- It addresses the unknown expectation of the surrogate metric by estimating it from abundant surrogate data, a key adaptation of the control variate technique.
- A Metric Correlator Function (MCF) is introduced to learn a mapping from surrogate measurements to better predictions of the real-world metric, enhancing correlation when it is initially weak.

## Results

- Sim2Val consistently reduced the variance of real-world metric estimates across autonomous driving and quadruped robotics, achieving reductions up to 82.9% for specific metrics (e.g., closest distance in autonomous driving).
- The framework demonstrated significant sample efficiency, allowing for the same confidence intervals with 51% to 58% fewer real-world samples, or effectively increasing real-world data requirements for baselines by up to 6x.
- The Metric Correlator Function (MCF) proved crucial in low-correlation scenarios, increasing the Pearson correlation coefficient from 0.07 to 0.61 in quadruped velocity tracking and yielding additional variance reduction.

## Takeaways

> [!tip] Key Insights
> - By leveraging correlation between expensive real-world measurements and cheaper surrogate measurements (e.g., from simulation), variance in real-world metric estimation can be substantially reduced.
> - The control variate framework can be effectively adapted for autonomous system validation, even when the auxiliary variable's true expectation is unknown and must be estimated from large datasets.
> - Learning a specialized metric correlator function can significantly improve the effectiveness of the control variate method, particularly in scenarios where the raw correlation between sim and real performance is low.
