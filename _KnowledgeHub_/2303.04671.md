# Visual ChatGPT: Talking, Drawing and Editing with Visual Foundation Models

> [!summary] Summary
> Visual ChatGPT, developed by Microsoft Research Asia, integrates large language models like ChatGPT with various visual foundation models to enable conversational interaction with visual content. The system performs complex image generation, editing, and understanding tasks by orchestrating specialized visual models through a novel Prompt Manager and adapting Chain of Thought reasoning.

## Problem

- Integrating the conversational abilities of large language models with the image processing and generation capabilities of visual models.
- Enabling complex, multi-step visual operations (e.g., image generation, editing, and style transfer) within a natural conversational flow.
- Developing a system that can leverage diverse, specialized visual models without requiring a single, monolithic, end-to-end trained multimodal model.

## Method

- A modular architecture combining ChatGPT, a collection of ==Visual Foundation Models (VFMs)==, and a novel =='Prompt Manager'== as an intermediary.
- The Prompt Manager facilitates communication by providing ChatGPT with VFM documentation, managing dialogue history, and structuring reasoning steps.
- An adaptation of ==Chain of Thought reasoning== is implemented to enable ChatGPT to orchestrate multiple VFMs for complex, multi-step visual tasks.

## Results

- Visual ChatGPT demonstrates the ability to perform complex visual operations, such as generating an image based on depth information and then applying a cartoon style, all within a **single conversational turn**.
- The system successfully supports multimodal conversation, allowing users to interact with and modify images iteratively through natural language commands.
- It showcases capabilities like visual question answering and chain of visual reasoning, breaking down requests into logical steps and explaining the process to users.

## Takeaways

> [!tip] Key Insights
> - A modular system that leverages existing large language models (LLMs) and visual foundation models (VFMs) can achieve multimodal capabilities without extensive end-to-end retraining.
> - The Prompt Manager mechanism effectively bridges the gap between the textual understanding of LLMs and the structured inputs required by VFMs, enabling complex visual task orchestration.
> - Adapting Chain of Thought reasoning allows the system to break down intricate visual tasks into a series of manageable steps, improving task execution and explainability.
