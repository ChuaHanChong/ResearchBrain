# EMP-SSL: Towards Self-Supervised Learning in One Training Epoch

> [!summary] Summary
> EMP-SSL introduces an approach to dramatically accelerate self-supervised learning by processing numerous overlapping image patches to efficiently learn co-occurrence statistics. This method achieves competitive performance, such as 85.1% accuracy on CIFAR-10, in a single training epoch, significantly reducing computational requirements compared to traditional SSL.

## Problem

- Current self-supervised learning (SSL) methods are computationally inefficient, typically requiring hundreds of training epochs to converge.
- This inefficiency creates substantial computational barriers, limiting the broad application of SSL approaches.
- Traditional SSL relies on a small number of augmented views per image, necessitating many passes through the dataset to accumulate sufficient statistics.

## Method

- EMP-SSL processes a large number of random, ==overlapping patches (20-200)== from each input image, instead of relying on a small number of augmented views.
- The architecture consists of a standard encoder network (ResNet-18) and a two-part objective function: ==Total Coding Rate (TCR)== to prevent collapse and an ==Invariance Loss== to enforce consistency among patch representations.
- The approach avoids complex components like momentum encoders, prediction networks, or non-differentiable operators, resulting in a clean and efficient implementation.

## Results

- EMP-SSL achieved impressive accuracies in a **single training epoch**: **85.1%** on CIFAR-10, **58.5%** on CIFAR-100, **38.1%** on Tiny ImageNet, and **58.5%** on ImageNet-100.
- The method significantly outperformed traditional SSL methods (BYOL, VICReg, SwAV, SimCLR) when all were limited to few training epochs, showing a strong performance gap in early stages.
- EMP-SSL attained over **90%** accuracy on CIFAR-10 in fewer than **10 epochs**, reaching competitive results in 10-30 epochs, compared to hundreds required by conventional methods.
- Representations learned by EMP-SSL showed clearer class separation in t-SNE visualizations and exhibited better transferability to out-of-domain datasets than baseline SSL methods.

## Takeaways

> [!tip] Key Insights
> - Self-supervised learning methods fundamentally learn the co-occurrence statistics of image patches.
> - Processing a large number of overlapping patches from a single image allows for efficient capture of co-occurrence statistics in a single training pass.
> - A balanced loss function combining invariance objectives with total coding rate regularization prevents representation collapse while encouraging meaningful feature learning.
