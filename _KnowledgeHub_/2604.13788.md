# Failure Identification in Imitation Learning Via Statistical and Semantic Filtering

> [!summary] Summary
> The FIDeL framework introduces a policy-independent monitoring module for robotic imitation learning, leveraging statistical anomaly detection combined with semantic filtering. It successfully differentiates between benign deviations and genuine task failures, enhancing system robustness for real-world deployment and achieving superior anomaly detection performance on new benchmarks.

## Problem

- Imitation learning policies are brittle to out-of-distribution (OOD) states in real-world environments, leading to unpredictable failures.
- Existing anomaly detection methods in robotics can flag deviations but cannot semantically distinguish between benign anomalies and task-critical failures.
- There is a scarcity of comprehensive, multimodal datasets specifically designed for benchmarking failure detection in robotic tasks.

## Method

- FIDeL employs a two-stage approach: an offline phase for learning nominal behavior representation using optimal transport and calibrating thresholds with spatially-aware conformal prediction.
- An online phase performs real-time anomaly detection by comparing current observations to memorized nominal behavior, generating localized anomaly heatmaps.
- A Vision-Language Model (VLM) is integrated for semantic filtering, interpreting detected anomalies and heatmaps to classify them as 'False positive' or 'Failure', thereby bridging the anomaly-failure gap.

## Results

- FIDeL's anomaly detection module achieved a **70.50%** AUROC and **62.90%** F1-score on the novel BotFails dataset, outperforming state-of-the-art baselines by a margin of **+5.30%** AUROC.
- Spatially-aware conformal prediction consistently improved anomaly detection accuracy and true negative rates compared to purely temporal CP and Gaussian thresholding.
- The integration of semantic filtering significantly improved end-to-end failure detection, preventing a substantial performance drop (e.g., mitigating a **23%** TNR loss on Real-π without filtering) by accurately distinguishing between benign and critical deviations.

## Takeaways

> [!tip] Key Insights
> - Optimal Transport alignment provides a robust and compact representation for nominal behavior, effectively capturing deviations from expert demonstrations.
> - Spatially-aware Conformal Prediction (CP-time&space) adaptively sets anomaly thresholds, accounting for both temporal progression and patch-level visual variations, outperforming simpler thresholding methods.
> - Semantic filtering via a VLM is critical for reliable failure identification, substantially reducing false positives by distinguishing benign anomalies from genuine task failures.
