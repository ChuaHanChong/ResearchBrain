# Training-Free Model Merging for Multi-target Domain Adaptation

> [!summary] Summary
> This paper introduces a training-free model merging technique for multi-target domain adaptation in semantic segmentation, overcoming the need for simultaneous access to all target domain data. The method leverages linear mode connectivity between domain-adapted models and proposes a principled approach to merge batch normalization statistics, achieving performance comparable to models trained with combined datasets.

## Problem

- Existing multi-target domain adaptation (MTDA) methods for semantic segmentation often require simultaneous access to data from all target domains during training.
- This requirement is impractical due to data privacy concerns, large data transfer costs, and computational scalability issues for numerous domains.
- Semantic segmentation models deployed in new environments experience significant performance degradation due to domain shift, posing challenges in safety-critical applications like autonomous driving.

## Method

- A two-stage pipeline is proposed: first, separate models are trained for each target domain using existing ==single-target domain adaptation (STDA)== methods.
- Second, these independently trained models are merged into a single unified model without accessing any original training data, leveraging ==linear mode connectivity==.
- Model merging involves averaging the trainable layer parameters and merging the ==batch normalization running statistics== using a method based on Gaussian distribution assumptions.

## Results

- The merged model achieves performance comparable to models trained by combining all target datasets, despite not requiring simultaneous access to domain data during training.
- The approach significantly outperforms previous MTDA methods that rely on explicit consistency training and provides better qualitative semantic segmentation outputs.
- Both parameter merging and the proposed batch normalization buffer merging are essential components, with the method scaling effectively with an increasing number of target domains.

## Takeaways

> [!tip] Key Insights
> - Domain-adapted models derived from the same pretrained weights exhibit linear mode connectivity, allowing for simple averaging of parameters without significant performance loss.
> - Batch normalization running statistics, which capture domain-specific characteristics, require a specialized merging approach based on Gaussian distribution assumptions for optimal performance.
> - Sharing identical pretrained weights is crucial for establishing the common optimization landscape that enables successful model merging.

## Detailed Report

### 1. Introduction

Domain adaptation (DA) is a critical challenge in machine learning where models trained on one data distribution (source domain) must generalize to different distributions (target domains). In real-world applications like autonomous driving, models need to perform well across diverse environments with varying lighting conditions, weather patterns, and urban layouts.

Many current approaches to multi-target domain adaptation (MTDA) require simultaneous access to data from all target domains during training. This assumption is often impractical due to data privacy regulations, storage limitations, or transmission costs. This paper introduces a training-free model merging technique that enables effective adaptation to multiple target domains without needing concurrent access to all domain data.

### 2. Domain Adaptation Challenges

Semantic segmentation, which assigns a class label to each pixel in an image, is particularly challenging for domain adaptation due to its dense prediction nature. When deploying segmentation models in new environments, performance often degrades significantly. This degradation is especially problematic in applications like autonomous driving where safety is paramount.

Traditional approaches to MTDA have several limitations:

1. They typically require simultaneous access to data from all target domains
2. The computational requirements scale poorly with the number of domains
3. Privacy concerns may restrict access to data from certain domains
4. Transferring large datasets across networks is expensive and time-consuming

### 3. Proposed Two-Stage Approach

The authors propose a two-stage pipeline to address these challenges:

#### 3.1. Stage 1: Single-Target Domain Adaptation (STDA)

In the first stage, separate models are trained for each target domain using existing STDA methods. Each model adapts from a labeled synthetic source domain to a single unlabeled target domain. This stage can be performed independently for each domain, potentially at different times or locations.

#### 3.2. Stage 2: Model Merging

The second stage involves merging the separately trained models into a single unified model without accessing any training data. This stage consists of two components:

1. **Parameter Merging:** The weights of the trainable layers are merged using simple midpoint averaging.
2. **Buffer Merging:** The running statistics (mean and variance) of batch normalization layers are merged using a method based on a Gaussian distribution assumption.

The mathematical formulation for parameter merging is straightforward. For two models A and B with parameters $\theta_A$ and $\theta_B$, the merged model parameters are calculated as:

$$\theta_{merged} = \frac{\theta_A + \theta_B}{2}$$

For scenarios with multiple models, this extends to:

$$\theta_{merged} = \frac{1}{n}\sum_{i=1}^{n}\theta_i$$

### 4. Linear Mode Connectivity

A key finding of this research is that domain-adapted models exhibit linear mode connectivity when they share the same pretrained weights. Linear mode connectivity means that a direct linear path exists between the parameter spaces of different models, allowing for simple averaging of weights without significant performance degradation.

The authors conduct extensive experiments to verify this property and explore the factors that contribute to it. They find that:

1. Models adapted from the same pretrained weights demonstrate strong linear mode connectivity
2. This property holds across different model architectures (ResNet50, ResNet101, MiT-B5)
3. Pretraining is crucial for establishing this connectivity

The authors investigate this phenomenon by interpolating between model parameters using:

$$\theta(\lambda) = (1-\lambda)\theta_A + \lambda\theta_B$$

where $\lambda \in$ controls the interpolation. Testing these interpolated models reveals that performance remains high across the interpolation path, confirming linear mode connectivity.

### 5. Batch Normalization Statistics Merging

While parameter merging works well for the trainable weights, batch normalization (BN) layers present a special challenge. BN layers contain running statistics (means and variances) that are not trained through gradient descent but are accumulated during training.

The authors observe that these statistics capture domain-specific characteristics and must be properly merged. They propose a method based on the assumption that the outputs of BN layers follow a Gaussian distribution:

Given BN statistics from two domains, $\Gamma_A = \{\mu_A^{(i)}, \sigma_A^{(i)}, n_A^{(i)}\}_{i=1}^L$ and $\Gamma_B = \{\mu_B^{(i)}, \sigma_B^{(i)}, n_B^{(i)}\}_{i=1}^L$, where $\mu$, $\sigma$, and $n$ represent the mean, standard deviation, and sample count, respectively, the merged statistics are calculated as:

$$n_{merged}^{(i)} = n_A^{(i)} + n_B^{(i)}$$

$$\mu_{merged}^{(i)} = \frac{n_A^{(i)}\mu_A^{(i)} + n_B^{(i)}\mu_B^{(i)}}{n_{merged}^{(i)}}$$

$$(\sigma_{merged}^{(i)})^2 = \frac{n_A^{(i)}((\sigma_A^{(i)})^2 + (\mu_A^{(i)})^2) + n_B^{(i)}((\sigma_B^{(i)})^2 + (\mu_B^{(i)})^2)}{n_{merged}^{(i)}} - (\mu_{merged}^{(i)})^2$$

This approach properly accounts for the different sample sizes used to estimate the statistics in each domain.

### 6. Experiments and Results

The authors evaluate their approach on standard MTDA benchmarks for semantic segmentation. They use the SYNTHIA dataset as the source domain and adapt to multiple real-world target domains: Cityscapes (CS), NTHU Cross-City (CC), Mapillary Vistas (MV), and IDD.

The results show that:

1. The merged model achieves performance comparable to models trained with combined datasets
2. The approach significantly outperforms previous MTDA methods that use explicit consistency training
3. Both parameter merging and buffer merging are essential for optimal performance
4. The method scales well with an increasing number of target domains

### 7. Importance of Pretraining

The authors conduct additional experiments to investigate the impact of pretraining on model merging effectiveness. They find that sharing the same pretrained weights is crucial for successful model merging.

When models are initialized with different pretrained weights (e.g., one from ImageNet and another from DINO), merging fails drastically, with accuracy dropping to near zero. This confirms that the shared initialization creates a common optimization landscape that enables linear mode connectivity.

### 8. Comparison with Other Methods

The authors compare their approach with several baselines and state-of-the-art methods:

1. **Source Only**: A model trained only on the source domain without adaptation
2. **Oracle**: Models trained with full supervision on target domains (upper bound)
3. **STDA**: Individual models adapted to each target domain
4. **STDA Ensemble**: An ensemble of individual STDA models
5. **Data Combination**: A model trained with data from all target domains combined
6. **MTDA Methods**: State-of-the-art MTDA approaches requiring simultaneous access to all domain data

The proposed model merging approach outperforms most baselines and achieves results comparable to data combination, despite not requiring simultaneous access to all domain data during training. It also significantly outperforms previous MTDA methods.

### 9. Conclusion

This paper introduces a training-free model merging technique for multi-target domain adaptation that addresses the practical limitations of existing approaches. By leveraging linear mode connectivity and properly handling batch normalization statistics, the method enables effective adaptation to multiple target domains without requiring simultaneous access to training data.

The key innovations include:

1. A two-stage pipeline that separates domain adaptation from model merging
2. Insights into linear mode connectivity in domain-adapted models
3. A principled approach to merging batch normalization statistics
4. Empirical validation of the method's effectiveness across multiple domains and architectures

These contributions open new possibilities for deploying machine learning models in diverse real-world environments, particularly in applications like autonomous driving where adaptation to multiple conditions is essential for safety and reliability.
