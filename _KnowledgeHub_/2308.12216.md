# SG-Former: Self-guided Transformer with Evolving Token Reallocation

> [!summary] Summary
> SG-Former introduces a hierarchical Vision Transformer that employs self-guided, evolving token reallocation to achieve efficient global self-attention with adaptive fine granularity. This architecture yields higher accuracy on ImageNet-1K classification, COCO object detection, and ADE20K semantic segmentation compared to prior Vision Transformers, frequently with reduced computational cost.

## Problem

- Vision Transformers incur quadratic computational and memory costs with input size, limiting their application to high-resolution images.
- Existing efficient Vision Transformers either sacrifice global context for local detail or lose fine-grained information for global context.
- Static token reduction methods fail to adaptively allocate computational resources based on the varying semantic importance of image regions.

## Method

- A hierarchical Transformer architecture is developed, featuring ==Self-guided Attention (SG-Attention)== and ==Hybrid-scale Attention== modules.
- SG-Attention dynamically reallocates Key and Value tokens based on a ==learned significance map==, assigning more tokens to salient regions for fine-grained analysis.
- Hybrid-scale Attention extracts multi-granularity information simultaneously and generates the significance map that guides ==evolving token reallocation== in SG-Attention.

## Results

- Achieved **84.7%** Top-1 accuracy on ImageNet-1K (224x224) with SG-Former-B, surpassing Swin-B by **+1.3%** and CSWin-B by **+0.4%**.
- Demonstrated **51.3 mAP** and **45.2 mIoU** on COCO object detection and instance segmentation, outperforming Swin-B by **+2.8 mAP**.
- Attained **52.7 mIoU** on ADE20K semantic segmentation using UperNet, exceeding Swin-B by **+3 mIoU**, often with competitive or reduced parameter and FLOP counts.

## Takeaways

> [!tip] Key Insights
> - Computational resources in Vision Transformers can be optimized by adaptively allocating more attention to semantically important image regions and less to less important ones.
> - A model's understanding of regional significance can be learned and dynamically refined, enabling self-guided and evolving token reallocation strategies.
> - Integrating hybrid-scale attention within a single layer effectively extracts both fine-grained local and coarse-grained global information while simultaneously generating a reliable significance map for adaptive processing.
