# RoboFollow: Unveiling the Instruction Following Mirage in Embodied Agents

> [!summary] Summary
> RoboFollow is a diagnostic benchmark testing whether language-conditioned robot policies actually use instructions. It builds high-scene-entropy training scenes (3.782 bits versus 0.880 for LIBERO suites) where one visual layout supports several feasible task branches, adds a four-level L0-L3 perturbation protocol, and separates Intent from Execution scoring. Nine VLA and WAM policies score near-perfectly in-distribution yet collapse under mild visual or semantic perturbation.

## Problem

- Manipulation benchmarks report final task success, entangling visual recognition, language grounding and low-level control, so they cannot reveal whether a policy actually used the instruction.
- Most benchmark episodes contain one canonical behavior inferable from the initial observation, making language redundant: a policy scores highly while treating it as a task identifier.
- Prior robustness studies perturb language only at test time; none constructs training-time task ambiguity, so visual shortcuts learned during training remain invisible to evaluation.

## Method

- **Scene entropy**, the ==conditional entropy== of training task labels given a task-independent initial scene specification, is used as a dataset design principle, reaching 3.782 bits over 75 task labels.
- A hierarchical **L0-L3 protocol** perturbs layout (==visual grounding==), instruction recombination (==semantic compositionality==), and both jointly, across four scene families: spatial relations, attributes, trajectory constraints, elementary logic.
- **Multi-Stage Intent-Execution scoring** decomposes each task into stages, scoring ==semantic target selection== apart from ==kinematic completion==, with a 20% finishing stage penalizing extra unrequested actions.

## Results

- On Scenes 1-2, one flow-matching policy reaches **99.1%** and **100.0%** L0 Intent but falls to **45.5%** at L1 and **34.2%** at L3; its predecessor drops **98.2%** to **0.0%**.
- QA probes score base, pre-trained and fine-tuned backbones at **1/20**, **2/20** and **3/20** on scene comprehension; a Qwen3-VL-4B backbone scores **19/20** yet its policy still collapses at L1.
- Classifier-free guidance at scale 1.2 cuts L0 Intent from **93.6%** to **50.4%**; doubling demonstrations to 50 per task leaves a **47.8-point** L0-L3 gap; real-robot success falls **50%** to **15%**.

## Takeaways

> [!tip] Key Insights
> - Benchmark construction decides what is measured: unless a scene admits multiple valid tasks, high success rates cannot separate language grounding from visual shortcuts.
> - A strong vision-language backbone is insufficient; comprehension must survive the action head, since about half of correctly answered scenes still produce wrong manipulation.
> - Classifier-free guidance presumes vision nearly determines the task; under genuine ambiguity the unconditional branch becomes noise and stronger guidance degrades performance.

## Detailed Report

### 1. Overview

RoboFollow starts from a gap between completing a task and following an instruction. When a scene strongly suggests one action, the language may be redundant, and a robot can succeed without truly following what it was told. That distinction matters in deployment, where a visually plausible action can still be semantically wrong.

The benchmark addresses this with tabletop manipulation scenes that offer several plausible objects or actions. The same or very similar scene supports multiple feasible tasks, so the instruction must select the intended one.

The central result is stark. π₀, fine-tuned on RoboFollow, achieves 98.2% Intent Score on Scene 1 at L0 but 0.0% at L1, where the layout changes but the instruction stays the same. This comparison is evidence of fragile grounding, not proof of the sole cause of failure. It comes from a deliberately controlled benchmark, not from real-world deployment.

### 2. Making language necessary

RoboFollow is built around **scene entropy**, which counts how many different task labels are possible given the same task-independent starting scene. When ambiguity is higher, vision alone cannot pick the intended branch. RoboFollow contains 75 training task labels grouped into six task-independent initial scene configurations.

Testing happens at four levels:

- **L0** keeps the familiar layout and instruction distribution.
- **L1** changes object positions while holding the instruction fixed.
- **L2** keeps the familiar layout but uses novel semantic recombinations.
- **L3** changes both.

These levels isolate separate generalization dimensions, not a strict ranking of difficulty. Actions targeted at test remain within the demonstrated behavioral repertoire.

Scoring separates choosing the right thing from physically doing it. **Intent Score (IS)** grades whether the policy selects the correct object, relation, waypoint, action, orientation, or logical branch. **Execution Score (ES)** grades whether the corresponding physical subgoal is completed. Tasks are decomposed into up to three stages, so a policy can receive semantic credit for choosing correctly even if execution is imperfect.

### 3. Strong scores, fragile transfer

Scene 1 tests relational grounding. When π₀ moves from L0 to L1, its instruction stays the same and only object positions change. The drop is a failure of intent selection, not merely a motor-execution shortfall, because IS itself is 0.0% for π₀ at L1.

The broader pattern runs across the nine fine-tuned VLA/WAM policies. Strong L0 results, where attained, do not reliably transfer to L1–L3, although results vary by model and scene.

An empty-language control shows how much the instruction contributes. In Scene 1, π₀.₅'s Intent Score is 99.1% at L0 and 45.5% at L1. The same model without language scores 16.0% and 0.5%, respectively. Removing the instruction greatly harms performance, so language matters to the measured behavior. Even with language, however, performance drops under changed layouts. The control therefore does not establish robust compositional understanding.

### 4. What the gap reveals

When a scene makes one task obvious, success can hide whether language selected the action. When multiple behaviors are feasible, intent scoring reveals a transfer failure that final success alone can obscure.

RoboFollow's contribution is this diagnosis of the evaluated fine-tuned policies. The result is bounded to that fine-tuning setup, in a deliberately controlled benchmark with simplified objects and short-horizon tasks.
