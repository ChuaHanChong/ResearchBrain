# RetouchIQ: MLLM Agents for Instruction-Based Image Retouching with Generalist Reward

> [!summary] Summary
> RETOUCHIQ presents an MLLM agent designed for instruction-based image retouching, translating natural language into precise, executable operations within professional software. The system addresses the inherent subjectivity of creative editing tasks through a Generalist Reward Model and Policy-Guided Reward Training, producing professional-grade, instruction-aligned image edits.

## Problem

- Existing AI methods for image editing (traditional and diffusion-based) either lack flexibility for natural language instructions or alter original image content, hindering precise, controlled retouching.
- Applying reinforcement learning to subjective creative tasks like image retouching is challenging due to the difficulty in defining reliable, objective reward signals for varied aesthetic goals.
- Reward models trained on synthetically perturbed edits face a distribution shift when evaluating complex edits generated by a policy model, leading to suboptimal guidance during RL.

## Method

- An MLLM agent (==policy model==) is developed to interpret natural language instructions and translate them into a reasoning trace and a sequence of executable, parameterized editing operations for professional software.
- A Generalist Reward Model (GRM) is introduced, which is an MLLM designed to dynamically generate context-aware evaluation metrics and scalar rewards, overcoming the challenge of subjective feedback for creative tasks.
- Policy-Guided Reward Training (PGRT) is implemented to align the reward model's training distribution with the policy's actual outputs, mitigating distribution shift by using policy-generated "weak" edits for GRM refinement.

## Results

- RETOUCHIQ consistently produces qualitative results that are more semantically aligned with user instructions and professionally styled compared to existing general-purpose MLLMs and diffusion-based editing methods.
- On the RETOUCHEVAL benchmark, RETOUCHIQ-GRM achieved state-of-the-art performance across all evaluation metrics (L1, L2, Semantic Consistency, Perceptual Quality, Overall Score) and categories.
- The Generalist Reward Model (GRM) trained with Policy-Guided Reward Training (PGRT) achieved the highest accuracy in distinguishing strong from weak edits on policy-generated data, directly correlating with the best performing policy model.

## Takeaways

> [!tip] Key Insights
> - MLLMs can be effectively leveraged as executable agents that translate high-level natural language instructions into precise, controllable parameter adjustments for professional-grade creative software.
> - Subjective creative tasks benefit significantly from a dynamically generated, context-aware reward model (GRM) that evaluates edits based on self-generated metrics, providing reliable feedback for reinforcement learning.
> - Aligning the reward model's training data distribution with the policy's evolving outputs through Policy-Guided Reward Training (PGRT) is critical for stable and effective RL, resolving issues of distribution shift.
