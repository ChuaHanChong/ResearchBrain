# Memory for Large Language Models

> [!summary] Summary
> A survey that reframes memory in LLMs as a first-class architectural dimension rather than a scaling byproduct, proposing a taxonomy along three orthogonal axes: representation (implicit vs explicit), update dynamics (offline vs online), and persistence (short- vs long-term), unifying attention, recurrence, retrieval, and parametric mechanisms under one framework.

## Problem

- Attention-based caching, recurrent states, test-time adaptation, retrieval modules, and conditional routing are studied in isolation despite addressing isomorphic questions about storage and access.
- Long-context models often fail to exploit their nominal context capacity, exposing a persistent gap between theoretical memory size and practical utilization in prior architectures.
- No principled structural framework exists to compare methodologies, analyze system-level trade-offs, or identify unexplored regions of the memory design space.

## Method

- ==Three-axis taxonomy== classifying memory systems by ==representation (implicit/explicit)==, ==update dynamics (offline/online)==, and ==persistence (short-term/long-term)==, applied across dozens of architectures.
- Fine-grained ==update-rule lens== distinguishing optimization-based writing, state-transition updates, signal-gated writing/routing, admission-eviction-consolidation, and objective-induced structural updates.
- Cross-cutting analysis of hybrid memory architectures, system-level efficiency techniques (==KV compression==, paging), and multi-dimensional evaluation protocols spanning implicit and explicit paradigms.

## Results

- Table I categorizes over **45** representative systems (Transformer KV cache through Mamba-3, Titans, Engram, Gated KalmaNet) across the three taxonomy axes, showing near-total dominance of online, long-term explicit designs since **2025**.
- Mixture-of-Experts models (Switch Transformer, Mixtral top-**2**-of-**8**, DeepSeek-MoE) are shown to scale capacity to **trillions** of parameters while keeping per-token FLOPs nearly constant, reframing MoE as conditional parameter memory.
- Positioning against **five** prior memory surveys (Zhang et al. 2024/2025, Wu et al. 2025, Du et al. 2025, Luo et al. 2026) shows this is the first model-level, architecture-centric taxonomy rather than an agent- or cognition-level one.

## Takeaways

> [!tip] Key Insights
> - No single memory paradigm satisfies all desiderata: token-level attention gives high-fidelity recall but poor scalability, recurrence gives compression but interference, explicit memory gives persistence but instability.
> - The offline/online distinction alone is insufficient; the finer update-rule (optimization, state-transition, signal-gated, consolidation) determines drift, interference, and irreversibility risk regardless of persistence class.
> - Current long-context and recall benchmarks conflate memory capacity with reasoning ability, so architectural memory gains cannot be rigorously disentangled from scaling effects without decomposed, multi-dimensional evaluation.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Large language models (LLMs) have demonstrated advanced capabilities across various tasks, with much of their success often attributed to scaling factors such as parameters, data, and computational resources. Concurrently, memory has emerged as a fundamental architectural dimension in LLMs. Historically, memory in neural language models was predominantly implicit, exemplified by the content-addressable working memory provided by Transformer attention, which operates within a fixed context window. However, this approach scales quadratically with sequence length, leading to significant computational and storage overheads.

Recent advancements have introduced diverse memory strategies, including sparse attention, structured state-space models, recurrent state dynamics, parameter-efficient adaptations, and scalable lookup storage. These developments extend context lengths and enhance computational efficiency but often entail performance trade-offs. More recently, there has been a shift towards incorporating explicit and persistent memory mechanisms that adapt beyond ephemeral inference, allowing models to retain, retrieve, and update information over extended sequences and interactions. This includes dynamic parameter updates during deployment (e.g., Titans), decoupling memory storage from dense computation (e.g., Engram), multi-timescale update strategies, and conditional parameter routing (e.g., Mixture-of-Experts).

Despite this rapid evolution, the literature on memory in LLMs has become fragmented. Different memory mechanisms—such as attention-based caching, recurrent sequence states, test-time adaptation, retrieval modules, and conditional parameter routing—are frequently studied in isolation. This fragmentation results in a lack of a unified perspective to elucidate the conceptual relationships among these disparate approaches. Without a principled structural framework, comparing methodologies, analyzing system-level trade-offs, and identifying unexplored design spaces presents a considerable challenge.

This survey positions itself to address this fragmentation by providing a systematic, architecture-centric taxonomy of memory in LLMs. It distinguishes itself from other memory-focused surveys (as noted in Section II.D, Table III) by primarily focusing on model-level architectural mechanisms, rather than agent-level memory, cognitively inspired categories, or memory lifecycle management. The paper aims to consolidate this emerging research frontier by offering a cohesive framework that bridges computation-coupled and independently addressable memory paradigms, thus providing a foundational structure for future architectural innovations.

### 2. Key Objectives and Motivation

The primary motivation for this work stems from the rapid and fragmented evolution of memory mechanisms in large language models. The authors observe that while various strategies have been introduced to enhance LLMs' ability to retain and utilize information over extended periods, a coherent and unified understanding of these diverse approaches is lacking. This fragmentation hinders systematic comparison, analysis of trade-offs, and the identification of new research directions.

Specifically, the key motivations include:
- **Addressing Architectural Evolution:** Memory in LLMs has transitioned from an implicit byproduct of computation to an explicit architectural design dimension. This shift necessitates a structured framework to understand the resulting diverse mechanisms.
- **Bridging Disparate Research Strands:** Concepts such as attention-based caching, recurrent states, test-time adaptation, retrieval modules, and conditional parameter routing are often investigated in isolation. The authors contend that these mechanisms address fundamentally similar questions regarding what information is stored, when and how it is updated, how it interacts with computation, its retention duration, and its storage granularity. A unified perspective is needed to connect these seemingly disparate approaches.
- **Facilitating Systematic Analysis:** Without a principled framework, it is difficult to compare methodologies, assess system-level efficiency trade-offs, and identify unexplored areas within the memory design space.
- **Guiding Future Innovation:** The absence of a consolidated view impedes the principled development of scalable and adaptive language models equipped with advanced memory capabilities.

To address these motivations, the paper sets forth the following key objectives (contributions):
- **Propose a Unified Memory Taxonomy:** To establish precise terminology and conceptual boundaries for classifying memory mechanisms. This taxonomy characterizes memory along three orthogonal axes: representation (implicit versus explicit), update dynamics (offline versus online), and persistence (short-term versus long-term). It also formalizes granular mechanisms for memory writing, routing, state transitions, and consolidation.
- **Systematically Review Advances:** To provide a comprehensive review of recent advancements across computation-driven (implicit) and parameterized (explicit) memory systems, including hybrid architectures, multi-timescale update policies, and conditional parameter routing.
- **Critically Analyze System-Level Aspects:** To evaluate efficiency trade-offs and multi-dimensional evaluation methodologies for memory-centric models, identifying current limitations and future research trajectories.

By achieving these objectives, the authors aim to consolidate the fragmented research landscape, clarify interdependencies among memory architectures, and lay a principled foundation for future innovations in LLM design.

### 3. Methodology and Approach

The methodology employed in this research is that of a systematic survey and conceptual synthesis of the existing literature on memory in large language models. The authors establish a novel architectural-centric framework to categorize and analyze diverse memory mechanisms.

The core of their approach is the development of a **three-axis taxonomy**:
1. **Representation (Implicit vs. Explicit Memory):**
 - **Implicit Memory:** Defined as information stored as a byproduct of the model's forward computation, tightly coupled with its internal dynamics. It lacks an explicit read, write, or lookup interface, with access fixed by the architecture (e.g., evolving states in recurrent networks, KV caches in Transformers).
 - **Explicit Memory:** Characterized as a distinct storage component with well-defined access semantics, supporting explicit addressing, retrieval, and update operations independent of standard forward computation. It can be non-parametric (e.g., external tables) or parametric (e.g., specialized trainable modules). The scope clarifies that static pretraining parameters are excluded.
2. **Update Dynamics (Offline vs. Online Memory):**
 - **Offline Memory:** Updated exclusively during a distinct model training phase, typically via gradient-based optimization, remaining fixed during inference (e.g., certain retrieval embeddings, MoE configurations).
 - **Online Memory:** Supports updates during inference, allowing models to incorporate new information on the fly. Updates can be triggered at various frequencies (per token, segment, batch) and governed by specialized rules (e.g., test-time training, recurrent state transitions).
 - **Fine-Grained Update Rules:** A secondary, more granular lens analyzes *how* memory is updated (Table II). This includes optimization-based writing, state-transition updates, signal-gated writing/routing, admission/eviction/consolidation, and objective-induced/structural updates.
3. **Persistence (Short-Term vs. Long-Term Memory):**
 - **Short-Term Memory:** Stores information at fine granularity, typically bounded by a local context window or inference episode. It allows precise local recall but has a limited effective horizon (e.g., attention KV caches).
 - **Long-Term Memory:** Designed to preserve information or its influence over extended contexts, potentially across sessions. This often involves higher compression, selective retention, or persistent storage, rather than solely large physical size (e.g., recurrent states, explicit stores, test-time updated parameters).

This orthogonal taxonomy serves as the primary analytical tool. The authors then apply this framework to systematically review the existing literature, categorizing representative models and mechanisms (summarized in Table I) and discussing their characteristics, strengths, and limitations across the three axes.

The survey's structure reflects this methodological approach:
- **Section II** formally introduces the taxonomy and clarifies its scope relative to other memory surveys.
- **Section III** delves into **Implicit Memory**, examining attention-based mechanisms (content-addressable, streaming/windowed), sparse, selective, and structured memory (access control, admission policies), and recurrent sequence memory (state transitions, compression, state editing). It also discusses the inherent limitations of implicit memory, such as bounded capacity and lack of adaptive read/write semantics.
- **Section IV** focuses on **Explicit Memory**, covering parameterized external memory modules (fast weights, test-time updates, dedicated slots), lookup-based and retrieval-oriented memory (kNN-LM, Engram, editable memory banks), conditional parameter memory (Mixture-of-Experts), and multi-timescale and nested update mechanisms. This section also analyzes the structural implications and risks associated with explicit memory, such as capacity growth, interference, and optimization challenges.
- **Section V** addresses broader **Model-Level Memory Architectures**, discussing hybrid memory architectures (interleaving attention and state dynamics, adaptive routing, multi-component designs), memory management and efficiency (KV cache compression, virtualization, consolidation), and the evaluation of memory systems (long-context retrieval, structured reasoning, forgetting, efficiency-performance tradeoffs).
- **Section VI** outlines **Open Challenges and Future Directions**, providing a forward-looking perspective based on the established framework.

Through this comprehensive, structured approach, the paper synthesizes a fragmented field, provides a unified vocabulary, and highlights critical architectural and operational distinctions among various memory paradigms.

### 4. Main Findings and Results

The paper's primary findings and results are conceptual and systematic, derived from its comprehensive literature review and the application of its novel taxonomic framework.

Key findings include:

- **Unified Taxonomic Framework for Memory in LLMs:** The introduction of a systematic, architecture-centric taxonomy is a central finding. This framework characterizes memory along three orthogonal axes—representation (implicit vs. explicit), update dynamics (offline vs. online), and persistence (short-term vs. long-term)—and further formalizes five granular update rules (optimization-based, state-transition, signal-gated, admission/eviction/consolidation, and objective-induced). This framework successfully unifies diverse memory mechanisms, clarifying their conceptual boundaries and interdependencies, which was previously a fragmented landscape.
- **Distinction Between Implicit and Explicit Memory Paradigms:**
 - **Implicit Memory:** The survey confirms that implicit memory, as seen in attention KV caches and recurrent states, is tightly coupled with the model's forward computation. It offers online, content-addressable processing but is inherently short-term, bounded by architectural design (e.g., context window size), and lacks independent control over read/write semantics. Sparsity and selective attention mechanisms within this paradigm aim to manage access within these constraints, rather than extending fundamental capacity.
 - **Explicit Memory:** The analysis demonstrates that explicit memory decouples storage from transient computation. This enables persistent, addressable, and adaptively updated information storage. Examples include parameterized memory modules (e.g., Titans, TTT-E2E), lookup-based systems (e.g., kNN-LM, Engram), and conditional parameter memory (e.g., Mixture-of-Experts). These systems allow for online plasticity, multi-timescale updates, and the accumulation of knowledge across inference episodes.
- **Elucidation of Memory Update Dynamics:** The detailed classification of update rules (offline vs. online, and the five fine-grained mechanisms) reveals the diverse ways memory content evolves. This highlights that memory is not merely static storage but a dynamic entity, with implications for stability, adaptability, and the balance between retaining existing knowledge and incorporating new information.
- **Prevalence and Benefits of Hybrid Architectures:** The survey observes a trend towards hybrid memory architectures (e.g., Jamba, AMOR, HAM) that combine implicit and explicit mechanisms to leverage their complementary strengths. These hybrids aim to balance high-resolution local recall with long-range context propagation, achieve computational efficiency, and allow for modular, adaptively routed memory access.
- **Critical Importance of Memory Management and Efficiency:** As memory capacity expands, efficiency considerations (e.g., KV cache compression, virtualization via PagedAttention, working-memory consolidation) are no longer secondary but fundamental architectural design axes for practical LLM deployment.
- **Challenges in Memory Evaluation:** The paper identifies that evaluating memory is more complex than standard performance metrics. It underscores the need for multi-dimensional evaluation protocols that assess not only long-context retrieval and structured reasoning (e.g., LongBench, SCROLLS) but also aspects like forgetting, interference robustness, temporal persistence, and computational efficiency, tailored to the specific characteristics of implicit versus explicit memory systems.
- **Identification of Key Open Challenges:** The survey synthesizes the current limitations into major open challenges for future research, including the need for a unified theoretical understanding of memory, development of continual and lifelong parametric memory, robust and interpretable update rules, adaptive memory allocation and control, and hardware-algorithm co-design.

In summary, the main "results" are the comprehensive structuring of the memory landscape in LLMs, the clarification of conceptual distinctions between various mechanisms, and a systematic overview of their operational characteristics, trade-offs, and future research directions.

### 5. Significance and Potential Impact

The significance of this work lies in its comprehensive synthesis and conceptual unification of the rapidly evolving and fragmented field of memory in large language models. Its potential impact is multi-faceted:

- **Standardization of Terminology and Conceptual Clarity:** By proposing a precise and orthogonal taxonomy for memory (representation, update dynamics, persistence, and granular update rules), the paper provides a standardized vocabulary. This is crucial for reducing ambiguity in research discussions, allowing researchers to communicate more effectively and to clearly delineate their contributions within the broader landscape. This conceptual clarity can accelerate research by fostering a shared understanding of memory architectures.

- **Framework for Comparative Analysis:** The established taxonomy offers a structured lens through which existing and future memory architectures can be systematically compared. This enables researchers to analyze the strengths, weaknesses, and trade-offs of different mechanisms (e.g., attention vs. recurrent states vs. retrieval systems) in a principled manner, beyond ad-hoc performance metrics. This framework can guide architectural design choices by highlighting how different memory properties contribute to overall model capabilities.

- **Identification of Design Space and Research Gaps:** By consolidating diverse advancements into a cohesive framework, the survey elucidates the unexplored design space for memory-centric LLMs. It explicitly identifies critical open challenges and promising future directions, such as developing a unified theory of memory, designing lifelong parametric memory systems, creating adaptive memory allocation mechanisms, and fostering hardware-algorithm co-design. This directly informs and prioritizes future research efforts.

- **Advancing Scalable and Adaptive LLMs:** The analysis underscores that memory has evolved into a "first-class compositional design problem." By providing a principled foundation for understanding how information is retained, modified, and forgotten, the survey can catalyze the development of next-generation LLMs that are more scalable (e.g., through efficient memory management), robust (e.g., through stable update protocols), and controllable (e.g., through adaptive routing and explicit interfaces). This will be particularly impactful for applications requiring long-context understanding, continual learning, and interactive agents.

- **Improved Evaluation Methodologies:** The critical analysis of current evaluation practices and the call for multi-dimensional metrics for memory performance can lead to the development of more rigorous and comprehensive benchmarks. This will enable researchers to disentangle genuine architectural innovations in memory from mere increases in context size or parameter count, ensuring that progress is measured against well-defined memory capabilities.

In essence, this survey serves as a foundational reference that organizes a complex and rapidly expanding domain. Its impact is to provide the intellectual infrastructure necessary for the scientific community to systematically advance the understanding, design, and deployment of memory-augmented large language models.
