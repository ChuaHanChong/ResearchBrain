# Integrating LMM Planners and 3D Skill Policies for Generalizable Manipulation

> [!summary] Summary
> LMM-3DP is a robotic framework that combines Large Multimodal Models for high-level planning with 3D feature fields for low-level control, enabling robots to execute diverse manipulation tasks in complex, dynamic environments. The system demonstrates robust adaptation to visual changes and achieves enhanced task success rates in real-world kitchen scenarios.

## Problem

- Bridging high-level task understanding (language instructions) with precise low-level continuous robotic control in real-world environments.
- Existing LLM-based systems lack visual understanding, limiting adaptation to dynamic environments and tasks requiring visual reasoning.
- Robotic systems often rely on predefined primitive skills, limiting generalizability and applicability to novel, open-world manipulation tasks.

## Method

- An LMM-3DP framework integrating an LMM-based high-level planner (GPT-4V) with a 3D semantic-geometric skill policy for low-level control.
- A closed-loop system incorporating continuous visual feedback, a critic agent for plan refinement, and a memory system for in-context learning.
- Low-level control leverages a unified 3D and semantic representation (DINO, PointNext, CLIP) to predict keyframe-based 6-DOF poses via a 3D transformer.

## Results

- Achieved high accuracy (**90%** without distractors, **56%** with) on individual manipulation skills, outperforming baselines like OWL-v2 and Voxposer.
- Demonstrated strong generalizability in skill composition, successfully combining untrained object-location pairs with 70-**90%** accuracy rates.
- Showed superior performance on long-horizon tasks, achieving an average success rate of **56.5%** compared to 7-**10%** for baseline approaches (SayCan, Voxposer), with planning module near **100%** accuracy.

## Takeaways

> [!tip] Key Insights
> - Closed-loop integration of high-level LMM planning with low-level 3D policies allows for dynamic adaptation to environmental changes and self-correction.
> - A critic agent, operating solely on visual input, can effectively identify and prompt correction of LMM planning flaws, improving plan robustness.
> - Representing actions as keyframe predictions based on fused 3D semantic and geometric features provides a sample-efficient and robust method for learning low-level manipulation skills.
