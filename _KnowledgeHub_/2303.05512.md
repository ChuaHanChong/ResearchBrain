# PAC-NeRF: Physics Augmented Continuum Neural Radiance Fields for Geometry-Agnostic System Identification

> [!summary] Summary
> PAC-NeRF introduces a framework that integrates dynamic neural radiance fields with differentiable continuum physics, enabling the simultaneous recovery of geometric structure and intrinsic physical properties of dynamic objects from multi-view video sequences without prior geometry assumptions. The model accurately estimated physical parameters across various materials in synthetic tests and outperformed existing baselines in geometry-agnostic system identification.

## Problem

- Existing system identification methods for inferring physical properties rely on a priori known object geometries, limiting their applicability to complex real-world scenes.
- Dynamic Neural Radiance Fields (NeRFs) learn object dynamics purely from visual data, often lacking physical interpretability, requiring extensive data, and not inherently adhering to physical laws.
- A unified computational framework was absent for jointly inferring both geometry and physical parameters of highly dynamic objects from visual input alone across a broad range of materials.

## Method

- PAC-**NeRF** integrates neural radiance fields with a differentiable continuum physics engine, specifically the ==Material Point Method== (==MPM==), to enforce conservation laws and enable geometry-agnostic system identification.
- The approach employs a hybrid Eulerian-Lagrangian representation, using voxel grids for rendering and particles for robust advection and handling of large deformations, with converters for seamless data transfer.
- The pipeline involves geometry seeding using a static voxel **NeRF** to establish initial object shape, followed by gradient-based optimization of physical parameters by minimizing rendering errors against ground truth videos.

## Results

- PAC-NeRF successfully reconstructed highly dynamic objects and accurately determined their physical properties across nine synthetic scenarios involving diverse materials, with optimized parameters showing close agreement with ground truth values.
- The framework demonstrated superior performance, achieving the best results in 14 out of 17 evaluated categories of physical properties, outperforming state-of-the-art baselines in geometry-agnostic system identification.
- PAC-NeRF was effectively applied to real-world multi-view videos of deformable objects, yielding qualitatively consistent scene reconstructions and parameter estimations, despite minor surface geometry errors with limited camera views.

## Takeaways

> [!tip] Key Insights
> - Enforcing continuum mechanics conservation laws within a neural radiance field architecture leads to physically plausible and interpretable dynamic states, contrasting with purely data-driven dynamic NeRFs.
> - A hybrid Eulerian-Lagrangian representation robustly couples neural scene representations with differentiable continuum physics, allowing for effective system identification for materials undergoing large deformations and topology changes.
> - Optimizing physical parameters through a fully differentiable rendering-simulation pipeline, leveraging pixel-level image-space signals, can accurately infer intrinsic physical properties without explicit 3D geometry supervision.
