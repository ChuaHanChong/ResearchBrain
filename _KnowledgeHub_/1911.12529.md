# One-Shot Object Detection with Co-Attention and Co-Excitation

> [!summary] Summary
> The Co-Attention and Co-Excitation (CoAE) framework, developed by researchers from National Tsing Hua University and Academia Sinica, addresses one-shot object detection by enabling models to identify novel object categories from a single example. It achieves this by integrating co-attention for enhanced region proposals and co-excitation for adaptive feature re-weighting, demonstrating state-of-the-art performance on PASCAL VOC and MS COCO.

## Problem

- Traditional object detection methods require large amounts of labeled training data for each new object class, limiting their applicability to novel categories.
- The challenge of detecting novel object categories not seen during training, given only a single example image.
- The need for a system to identify all instances of a specific object class within a target image when provided with just one query example of that class.

## Method

- The ==Co-Attention and Co-Excitation (CoAE)== framework, built upon the Faster R-CNN architecture, is introduced for one-shot object detection.
- It incorporates a ==Non-Local Object Proposals (Co-Attention)== component that enhances the Region Proposal Network by leveraging spatial relationships between query and target images.
- It integrates a ==Squeeze and Co-Excitation (SCE)== module that adaptively re-weights feature channels based on the relationships between query and target features, improving feature matching.

## Results

- The CoAE framework achieves state-of-the-art performance on standard one-shot object detection benchmarks, including PASCAL VOC and MS COCO datasets.
- Ablation studies confirm the necessity and effectiveness of both the co-attention and co-excitation mechanisms, with their removal leading to performance degradation.
- Visual analyses demonstrate that the co-excitation module adapts its feature weighting dynamically based on different query instances and contexts, highlighting relevant features for matching.

## Takeaways

> [!tip] Key Insights
> - Incorporating non-local co-attention into the Region Proposal Network improves proposal generation for novel classes by capturing spatial dependencies between query and target features.
> - Adaptive re-weighting of feature channels via Squeeze and Co-Excitation enables the model to focus on the most discriminative features for object matching.
> - A margin-based ranking loss effectively trains the model to score and rank region proposals based on their similarity to the query object.

## Detailed Report

### 1. Introduction

Object detection is a fundamental task in computer vision that aims to identify and locate objects within images. Traditional object detection methods require large amounts of labeled training data for each object class they aim to detect. This requirement poses a significant challenge when encountering novel object categories not seen during training. One-shot object detection addresses this limitation by enabling the detection of novel object categories given just a single example image.

This paper, authored by Ting-I Hsieh, Yi-Chen Lo, Hwann-Tzong Chen, and Tyng-Luh Liu from National Tsing Hua University and Academia Sinica in Taiwan, introduces a novel framework called Co-Attention and Co-Excitation (CoAE) for one-shot object detection. The approach leverages the spatial and feature relationships between a query image (containing the object to be detected) and a target image (where instances of the object are to be found).

### 2. Problem Background

One-shot object detection differs from traditional object detection in a fundamental way: instead of being trained to detect specific predefined classes, the model must learn to detect any object class based on a single example. This paradigm is more aligned with how humans learn—we can typically recognize new objects after seeing just one example.

The task is defined as follows: given a query image patch containing an object of interest and a target image, the goal is to detect all instances of the same object class as the query within the target image. Unlike standard object detection, the system should work with novel classes not seen during training.

This approach is different from object tracking, where the goal is to follow a specific object instance across video frames. In one-shot detection, the goal is to identify different instances of the same object class, even if they have significant appearance variations.

### 3. Architecture Overview

The CoAE framework is built upon the established Faster R-CNN architecture but introduces two key innovations:

1. **Non-Local Object Proposals (Co-Attention)**: This component enhances the region proposal network (RPN) by incorporating co-attention between the query and target images, enabling more accurate proposals for novel object classes.

2. **Squeeze and Co-Excitation**: This module adaptively re-weights feature channels based on the relationships between the query and target images, allowing for more flexible feature matching.

The overall pipeline, as shown in Figure 1, processes both the query image patch and target image through a shared convolutional network (ResNet-50), followed by the co-attention and co-excitation mechanisms, and concludes with a region proposal network and classifier.

### 4. Co-Attention Mechanism

Traditional object detection relies on a Region Proposal Network (RPN) trained on specific object classes. However, when encountering novel classes, the standard RPN may struggle to generate accurate proposals. The co-attention mechanism addresses this challenge by establishing spatial relationships between the query and target images.

The implementation utilizes non-local operations that create extended feature maps capturing the relationships between the query and target features. Mathematically, if $F(I)$ represents the feature map for the target image and $F(p)$ represents the feature map for the query patch, the non-local features are computed as:

$$\hat{F}(I) = F(I) + \text{NonLocal}(F(I), F(p))$$
$$\hat{F}(p) = F(p) + \text{NonLocal}(F(p), F(I))$$

This approach enables the RPN to generate proposals that are more relevant to the query object, even if the object class was not seen during training.

Figure 3 demonstrates the effectiveness of the non-local RPN compared to a standard RPN. The heatmaps show that the non-local approach focuses more precisely on regions containing objects similar to the query.

### 5. Co-Excitation Mechanism

Different object classes often have distinct visual characteristics. For example, when distinguishing between a cat and a dog, features related to ear shape or facial structure might be more important than color. The Squeeze and Co-Excitation (SCE) module adaptively emphasizes relevant feature channels based on both the query and target images.

The process involves:

1. **Squeeze Operation**: Global average pooling condenses spatial information into channel descriptors.
2. **Co-Excitation**: Two fully connected layers generate channel weights that are applied to both query and target features.

This adaptive re-weighting allows the model to focus on the most discriminative features for matching the query with potential regions in the target image. The SCE module can be represented as:

$$w = \sigma(W_2 \delta(W_1 [z_I, z_p]))$$

Where $z_I$ and $z_p$ are the squeezed representations of the target and query features, $W_1$ and $W_2$ are learned weight matrices, $\delta$ is a ReLU activation, and $\sigma$ is a sigmoid function. The resulting weight vector $w$ is used to scale the feature channels of both the query and target.

### 6. Proposal Ranking

Once region proposals are generated and feature channels are re-weighted, the model must rank the proposals based on their similarity to the query object. The authors employ a margin-based ranking loss to learn an implicit metric for this purpose.

For each proposal, a two-layer Multi-Layer Perceptron (MLP) predicts the foreground probability. The margin-based ranking loss encourages:

1. Higher scores for foreground proposals (those that match the query class) compared to background proposals
2. Similar scores for proposals of the same label (either foreground or background)

The overall training objective combines this ranking loss with the standard Faster R-CNN losses for classification and bounding box regression.

The CoAE framework was evaluated on standard benchmarks for one-shot object detection, including PASCAL VOC and MS COCO datasets. The evaluation followed established protocols where the datasets were split into base classes (used for training) and novel classes (used only for testing).

### 9. Significance and Impact

The CoAE framework represents a significant advancement in one-shot object detection for several reasons:

1. **Class-Agnostic Detection**: Unlike many previous approaches, CoAE can detect novel object classes without requiring fine-tuning or additional training.

2. **Contextual Understanding**: By incorporating both spatial context (through co-attention) and feature context (through co-excitation), the model achieves more robust detection capabilities.

3. **Practical Applications**: The approach enables applications where collecting large datasets for every object class is infeasible, such as robotics, image search, and medical imaging.

4. **Architectural Insights**: The success of the co-attention and co-excitation mechanisms provides valuable insights for designing future object detection models.

The ability to detect objects from a single example mitigates one of the fundamental limitations of deep learning approaches—the requirement for large quantities of labeled data. As such, this research brings machine perception closer to human-like capabilities, where learning can occur efficiently from minimal examples.

Future research directions could include extending the framework to zero-shot detection (where no examples are provided) or few-shot detection (where multiple examples are available), as well as incorporating temporal information for video applications.
