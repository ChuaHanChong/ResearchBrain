# Thinking with Programming Vision: Towards a Unified View for Thinking with Images

> [!summary] Summary
> Researchers from Zhejiang University and ByteDance introduced CodeVision, a "code-as-tool" framework that equips Multimodal Large Language Models (MLLMs) to programmatically interact with images. The approach significantly improves MLLM robustness by correcting common image corruptions and enables state-of-the-art multi-tool reasoning through emergent tool use and error recovery.

## Problem

- State-of-the-art MLLMs exhibit surprising brittleness to simple real-world visual perturbations like image rotations and flips, leading to significant performance degradation.
- Existing tool-augmented MLLMs often lack flexibility and scalability, relying on brittle, hand-specified tool interfaces that hinder generalization.
- Current MLLM tool-use paradigms frequently offer only marginal performance gains, raising questions about the genuine necessity and utility of tools for many tasks.

## Method

- The CodeVision framework employs a ==two-stage training process==: Supervised Fine-Tuning (SFT) to teach fundamental tool-use syntax and multi-tool sequences, followed by Reinforcement Learning (RL) for strategic decision-making.
- A =="code-as-tool" paradigm== allows MLLMs to generate code as a universal interface to invoke any image operation, moving beyond fixed tool registries for greater flexibility and scalability.
- A ==dense, multi-component reward function== for RL training guides the agent in achieving correct answers, mastering strategic tool selection (including discovery of emergent tools), and ensuring robust error recovery.

## Results

- CodeVision models consistently and substantially outperform baseline MLLMs on transformed OCRBench and ChartQAPro, achieving an average score of **73.4** on transformed OCRBench with CodeVision-7B, a **+17.4** improvement over its base model.
- The framework establishes a new state-of-the-art on the novel MVToolBench for multi-tool composition, with CodeVision-7B scoring **60.1**, nearly doubling the performance of Gemini2.5-Pro (**32.6**).
- Qualitative results demonstrate CodeVision's emergent capabilities, including the discovery and use of beneficial tools not explicitly trained, efficient chaining of multiple operations, and sophisticated error handling by revising incorrect tool calls based on runtime feedback.

## Takeaways

> [!tip] Key Insights
> - State-of-the-art MLLMs show significant vulnerability (up to 80% performance drop) to simple image orientation changes, highlighting a fundamental robustness issue that necessitates tool use.
> - A "code-as-tool" approach, combined with a multi-stage training methodology and dense reward, enables emergent behaviors like the discovery of unseen tools, efficient tool chaining, and robust error recovery.
> - Carefully curated SFT data with metadata-conditioned image transformations and a rich RL reward function are crucial for bootstrapping the model and guiding it towards strategic, multi-tool reasoning.
