# NativeMEM: Native Memory Compression for Long-Horizon Robotic Manipulation

> [!summary] Summary
> NativeMEM enables pretrained Vision-Language-Action (VLA) models to retain long-horizon visual histories by compressing each historical frame-view into a single action-relevant token using the VLA's own vision encoder. This approach resulted in an average success rate of 84.0% in simulated memory-dependent tasks and 98.7% on real-world manipulation tasks, while maintaining real-time inference with up to 5,000 historical frames.

## Problem

- Most pretrained Vision-Language-Action (VLA) models operate reactively, conditioning only on current observations and lacking the ability to handle long-horizon tasks requiring memory of past interactions or progress tracking.
- Existing memory augmentation techniques often face a 'compression dilemma,' struggling to retain fine-grained, long-horizon temporal histories without excessive computational cost or the loss of critical details.
- Integrating new memory modules into pretrained VLAs can introduce architectural complexity and compatibility issues, potentially degrading the VLA's performance or requiring substantial retraining.

## Method

- **NativeMEM** introduces a ==Native Memory Compression== scheme that repurposes the VLA's own vision encoder to compress each historical frame-view into a single, compact "native memory token".
- It employs a ==two-stage training pipeline==: first, an ==action-supervised learning== phase for the memory tokenizer with a frozen VLA backbone, followed by finetuning the VLA to utilize these learned memory tokens.
- The memory sequence is constructed by concatenating these compressed tokens and integrating them directly into the VLA's input, allowing the pretrained policy to leverage historical context through its existing attention mechanisms without architectural modifications.

## Results

- Achieved an average success rate of **84.0%** across simulated memory-dependent manipulation tasks and **98.7%** on real-robot manipulation tasks, significantly outperforming prior memory-free and memory-augmented baselines.
- Supported up to **5,000** historical frames within a **32 GB** GPU memory budget and maintained real-time inference (under **100 ms** latency) while attending to approximately **200** frames.
- Demonstrated high data efficiency, achieving a **60%** average success rate on three RMBench tasks with only **10** demonstrations, which was **3.5** times higher than a leading memory-augmented baseline.

## Takeaways

> [!tip] Key Insights
> - Highly compact, action-relevant memory tokens can be effectively generated by adapting and reusing the VLA's native vision encoder, ensuring compatibility and computational efficiency.
> - Training the memory tokenizer with an action-supervised objective forces it to distill historical information crucial for predicting correct robot actions, aligning memory content with the VLA's functional priors.
> - Decoupling the memory tokenization process from policy inference allows for frequent memory updates and extended historical contexts (up to 5,000 frames) while maintaining real-time reactive control during deployment.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The paper addresses a challenge within the field of Vision-Language-Action (VLA) models for robotic control. VLA models, which extend Vision-Language Models (VLMs) to embodied decision-making, are an area of active research aiming to achieve generalist robot control. Prior VLA models often operate reactively, conditioning solely on the current observation and language instruction. This reactive approach presents limitations for tasks requiring memory, such as long-horizon manipulation where actions depend on past interactions, progress tracking, or previously encountered occluded states.

Existing approaches to augment VLAs with memory broadly fall into two categories. The first involves external memory management, where a higher-level VLM module retrieves keyframes or generates sparse subtasks, often in text format, for a low-level VLA controller. While these methods can extend temporal context, they may necessitate costly annotations for training and may not capture subtle visual details adequately through language alone.

The second category integrates memory through newly initialized modules within the policy, employing recurrent states, compressed histories, or retrieval-augmented memory banks. These internal memory modules introduce architectural complexity and can pose compatibility issues with pretrained VLA policies, potentially leading to performance degradation. Furthermore, these methods often encounter a "compression dilemma": a trade-off between retaining fine-grained, long-horizon temporal histories, which can be computationally expensive if not sufficiently compressed, and discarding critical details if compression is excessive or poorly structured. NativeMEM aims to navigate this dilemma by proposing an approach that provides compact, action-relevant memory without external modules or substantial architectural modifications to the pretrained VLA.

### 2. Key Objectives and Motivation

The primary objective of this work is to enable pretrained Vision-Language-Action (VLA) models to effectively retain long-horizon, fine-grained visual histories with high-frequency updates, while maintaining computational efficiency and compatibility with the original pretrained policy. The authors explicitly pose the central question: "how can a VLA retain long-horizon, fine-grained histories with minimal memory cost, while remaining compatible with the pretrained policy it builds upon?"

This objective is motivated by several limitations of existing VLA models and memory augmentation techniques:

- **Reactive Nature of Current VLAs:** Most pretrained VLAs are reactive, conditioning only on the current observation and instruction. This design is insufficient for many manipulation tasks that require understanding task progress, recalling past interactions (e.g., objects previously manipulated, count of operations), handling occluded states, or learning from past failures. Such tasks are "non-Markovian," meaning the optimal action depends on the history, not just the current state.
- **Limitations of VLM-Driven External Memory:** Approaches that use external VLMs for memory (e.g., retrieving keyframes or generating textual subtasks) often convert visual memory into linguistic formats. This conversion can lead to a loss of subtle visual details critical for precise robotic actions. Additionally, generating detailed linguistic descriptions for training can require extensive and costly annotations.
- **Challenges with Internal External Memory Modules:** Integrating new, freshly initialized memory modules into pretrained VLAs introduces several challenges. These modules, being new, are not seen during the VLA's pretraining phase, which can increase architectural complexity and potentially degrade the performance of the pretrained VLA by requiring it to learn to integrate novel representations.
- **The Compression Dilemma:** Current internal memory methods face a fundamental trade-off. Representing full, fine-grained temporal histories is computationally expensive due to the rapidly increasing sequence length and associated processing costs. Conversely, aggressive compression might lead to the loss of action-critical details. The motivation is to find a balance that allows for significant compression (enabling long horizons) without sacrificing relevant information for action prediction.
- **Efficiency and Real-time Requirements:** Robotic manipulation often requires real-time decision-making. Memory augmentation methods must operate with low inference latency and reasonable GPU memory usage to be practical for real-world deployment.

By addressing these points, NativeMEM seeks to provide a memory solution that is both effective for complex, long-horizon tasks and highly compatible with the efficiency and learned priors of existing pretrained VLA models.

### 3. Methodology and Approach

NativeMEM introduces a method called Native Memory Compression, which aims to integrate long-horizon visual history into pretrained VLA policies without altering their core architecture or introducing external memory modules. The approach is characterized by its compact memory representation and a two-stage training pipeline.

#### 3.1. Problem Formulation

The work frames the problem as converting a reactive, single-frame VLA policy, which predicts actions $a_t$ based on current observation $o_t$, proprioceptive state $s_t$, and language instruction $\ell$ (Equation 1), into a memory-augmented policy. This new policy additionally conditions on a compact memory $M_t$ built from interaction history $H_t$ (Equation 3). The core challenge is designing $M_t$ to be efficient and compatible while preserving action-relevant history, particularly for non-Markovian tasks where identical current observations might require different actions depending on past events (Equation 2).

#### 3.2. Native Memory Compression

The core idea is to aggressively compress visual history. The method proposes representing each historical frame from each camera view as a single "native memory token" (M=1). This extreme compression addresses the memory fidelity and efficiency trade-off by minimizing the growth of memory length, which scales with the number of camera views ($V$), temporal horizon ($T$), update frequency ($N$), and per-frame token cost ($M$) as $|M_t| = V \cdot T \cdot N \cdot M$ (Equation 4).

To ensure these highly compressed tokens are interpretable by the pretrained VLA, NativeMEM repurposes the VLA's *own* vision encoder. Instead of using an external module, a "memory tokenizer" is initialized from the pretrained VLA's visual encoder ($E_{mem}$). This tokenizer processes a frame-view observation $o_v^\tau$ by taking a learnable memory query token $q_{mem}$ and attending to the visual patch-token sequence $P_v^\tau$ extracted by the encoder. This process aggregates the visual information into a single summary token $\hat{q}_v^\tau$ (Equation 5). A linear memory projection ($W_{mem}$) then maps this summary into the VLA's native token dimension, resulting in a single native visual memory token $m_v^\tau$ for that frame and view (Equation 6).

The memory sequence $M_t$ is constructed by concatenating these memory tokens across selected historical frames ($I_t$) and views, preceded by a learnable beginning-of-sequence token $b_{mem}$ (Equation 7). This memory sequence is then appended to the VLA's original input sequence, which includes current observation tokens ($x_{obs}^t$) and prompt tokens ($x_{prompt}(\ell, s_t)$) (Equation 8). This integration allows the VLA to process historical context through its existing attention mechanisms without architectural changes.

#### 3.3. Two-Stage Training Pipeline

NativeMEM employs a two-stage training procedure to align the memory tokens with the pretrained VLA's knowledge:

1. **Stage 1: Native Memory Compression (Learning the Memory Tokenizer)**
 - **Objective:** To learn a memory tokenizer that produces action-relevant and VLA-compatible memory tokens.
 - **Procedure:** The pretrained VLA's backbone is frozen. Only the memory branch, comprising the memory encoder ($E_{mem}$), memory query token ($q_{mem}$), linear projection ($W_{mem}$), and beginning-of-sequence token ($b_{mem}$), is trainable. The tokenizer is optimized using the VLA's native action prediction loss ($L_{act}$) (Equation 9). This action-supervised learning encourages the memory tokens to encode information useful for predicting the correct robot actions, rather than optimizing for reconstruction or generic visual representation.
 - **Data:** Training uses a mixture of standard manipulation data and memory-demanding tasks from both simulation and real-world demonstrations.
 - **Memory Selection:** For efficiency, the full visual history is not loaded. Instead, for each training step, $I_t$ includes the first frame of the episode (for task context) and a recent history window (for state changes and progress). The current frame is also included to ensure the tokenizer learns a consistent frame-level summarization.

2. **Stage 2: Task-Specific Finetuning (Integrating Memory into VLA Policy)**
 - **Objective:** To finetune the VLA policy to effectively utilize the learned compact memory tokens for specific tasks.
 - **Procedure:** The learned memory tokenizer is frozen. For each target-task demonstration episode, the visual history is preprocessed offline, converting each frame-view pair into its single corresponding memory summary token. These cached tokens are then retrieved to form the memory sequence $M_t$. The VLA backbone is initialized from the pretrained single-frame policy, and the memory projection ($W_{mem}$) and $b_{mem}$ from Stage 1 are loaded. The VLA backbone, action head, and memory projection are finetuned on a limited dataset of target-task demonstrations using the native action prediction loss (Equation 10).

#### 3.4. Real-Time Memory Inference

During deployment, the memory tokenizer operates independently. As new observations arrive, the tokenizer converts them into memory tokens at a specified frequency and maintains a compact memory queue. This decoupling allows the tokenizer to update historical memory frequently with low overhead. When the VLA needs to predict an action, the current memory queue is concatenated with the standard input tokens, maintaining the existing VLA inference pipeline and ensuring real-time reactiveness.

### 4. Main Findings and Results

The evaluation of NativeMEM encompassed manipulation tasks requiring long-horizon and adaptive memory understanding in both simulation and real-world settings.

#### 4.1. Simulation Experiments

NativeMEM demonstrated consistent performance across simulated memory-dependent manipulation tasks (Table 1), achieving an average success rate of 84.0%. This represents a substantial improvement over prior methods, including pretrained memory-free VLAs (e.g., π0.5 at 8.8%, X-VLA at 12.4%) and memory-augmented baselines. Specifically, VLM-driven memory methods like MemER (10.4%) and Mem-0 (32.4%) showed lower average success rates. External memory modules like HAMLET ∗ (9.0%) and MEM-short ∗ (12.8%), reproduced on the same backbone for fair comparison, also lagged behind. NativeMEM achieved high success rates across tasks requiring different memory functionalities, such as long-range recall (e.g., Put Back Block 100%, Observe and Pickup 44%) and continuous progress tracking (e.g., Click Buttons 94%, Click Buttons (Hard) 88%, Swap Blocks 94%). This suggests that the native memory compression scheme effectively represents both types of historical information.

#### 4.2. Real-World Experiments

On real-robot manipulation tasks, NativeMEM achieved an average cumulative success rate of 98.7% (Table 2). This significantly surpassed the performance of the baseline π0.5 policy (14.7%) and π0.5
- RTC (34.7%), which primarily exploits temporal action continuity rather than explicit historical recall. Mem-0 (0.0%) showed poor generalization in real-world settings with limited data, and MEM-short ∗ (30.7%) also exhibited instability under these conditions. NativeMEM maintained high success rates across all stages of complex tasks, including the unseen Grocery Checkout Scanning task, where it scored 100%. This indicates strong transferability and robustness to novel memory requirements.

#### 4.3. Inference Efficiency

Evaluation of inference latency and peak GPU memory usage (Figure 4a) indicated that NativeMEM can support up to 5,000 historical frames within a 32 GB memory budget. It can attend to approximately 200 frames while maintaining a real-time latency constraint of 100 ms. This capability enables substantially longer historical contexts compared to other methods without sacrificing real-time reactiveness.

#### 4.4. Data Efficiency

NativeMEM demonstrated strong data efficiency (Figure 4b). With only 10 demonstrations, it achieved a 60% average success rate on three RMBench tasks, which was 3.5 times higher than Mem-0. It consistently outperformed Mem-0 with 25 and 50 demonstrations, suggesting that reusing pretrained VLA manipulation priors, augmented with action-supervised native memory tokens, is an efficient approach to learning.

#### 4.5. Qualitative Analysis

- **Spatial Attention of the Memory Tokenizer:** Visualizations (Figure 5) showed that the memory tokenizer consistently focuses on manipulation-relevant regions of the image, such as the block and its original pad in "Put Back Block," rather than background elements. This behavior generalized to the unseen "Grocery Checkout Scanning" task, where the tokenizer attended to foreground objects, particularly those being manipulated. This indicates the tokenizer learns to extract action-relevant visual cues.
- **Action Attention over the Memory Sequence:** Analysis of attention from action tokens to historical memory tokens (Figure 6) revealed that the policy attends to specific task-relevant moments rather than merely the most recent observations. For instance, in "Click Buttons," high attention was observed on the timestamps corresponding to individual button presses. In "Put Back Block," attention concentrated on the moment the block was lifted from its original pad, which is critical for determining its return location.

#### 4.6. Ablation Study

The ablation study (Table 3) confirmed the importance of Native Memory Compression and comprehensive temporal coverage:

- **Unfrozen VLA during Stage 1:** When the VLA was unfrozen during memory-compression learning, performance dropped significantly to 23.2%. This suggests that freezing the VLA in Stage 1 is crucial to force the memory branch to learn representations aligned with the fixed VLA's action objective, rather than allowing the VLA to simply adapt itself.
- **Without Stage 1 (mean-pooled features):** Using generic mean-pooled vision-encoder features as memory tokens without Stage 1 training resulted in a success rate of 58.0%. While better than the unfrozen VLA, it failed to preserve fine details required for tasks like "Put Back Block" and "Observe and Pickup." This highlights the necessity of action-supervised native memory compression for distilling critical historical cues.
- **Sparse Update (0.5Hz):** Reducing the memory update frequency to 0.5Hz decreased success rates across tasks, indicating the need for fine-grained temporal evidence to track interaction states.
- **Short Horizon (2s, 4s, 6s):** Limiting the memory horizon degraded performance on tasks where critical information occurred outside the retained window, such as "Swap Blocks" and "Put Back Block." This confirmed that both dense temporal coverage and long-horizon retention are important for NativeMEM's performance.

### 5. Significance and Potential Impact

NativeMEM presents an advancement in enabling pretrained Vision-Language-Action (VLA) models to handle long-horizon, memory-dependent robotic manipulation tasks. The work addresses a core limitation of existing VLA policies, which are often reactive and lack the ability to effectively leverage historical context.

The primary significance lies in its novel **Native Memory Compression** scheme. By repurposing the VLA's own vision encoder to compress each historical frame-view into a single "native memory token," the method achieves extreme compactness without introducing external modules or significant architectural changes. This addresses the "compression dilemma" by allowing for minute-level visual histories (up to 5,000 frames) within practical memory and latency constraints. The action-supervised learning of these tokens ensures they are both efficient and aligned with the pretrained VLA's action-generation priors, making them directly interpretable by the policy's existing attention mechanisms.

The reported improvements in task success rates are substantial, increasing from low baseline percentages (e.g., 32.4% to 84.0% in simulation, 34.7% to 98.7% on real robots). This suggests a practical solution for enhancing robot autonomy in complex, sequential tasks that require recalling past states or tracking continuous progress. The demonstrated performance on unseen real-world tasks, such as Grocery Checkout Scanning, indicates a degree of generalization for the learned memory representation.

Furthermore, NativeMEM exhibits high **data efficiency**, achieving competitive results with only 20% of the training data compared to some prior methods. This characteristic is valuable in robotics, where collecting large-scale, high-quality demonstration data can be resource-intensive. The ability to effectively finetune a pretrained VLA with limited task-specific demonstrations, converting it into a memory-augmented policy within a few hours, could accelerate the deployment of VLA models in diverse applications.

The approach's **inference efficiency** with low latency and GPU memory usage ensures its suitability for real-time robotic control. By decoupling memory construction from policy inference, NativeMEM allows for high-frequency memory updates without significantly impacting the VLA's reactive capabilities.

The qualitative analyses provide insights into the internal workings of NativeMEM, showing that the memory tokenizer learns to focus on salient, action-relevant visual features and that the VLA attends to critical historical moments. This suggests that the system is not merely memorizing raw pixels but rather distilling and utilizing task-relevant abstract information from the visual history.

In terms of potential impact, NativeMEM could facilitate the development of more capable and robust generalist robots by endowing them with extended memory capabilities. This could unlock more complex, long-horizon manipulation tasks in unstructured environments, reducing the need for explicit resets or re-initializations, and enabling robots to learn from more extended interactions. While the authors note limitations regarding persistent memory over hours or days, and potential semantic gaps between low-level action losses and abstract memory requirements, the current work provides a foundational step towards more sophisticated memory integration in embodied AI.
