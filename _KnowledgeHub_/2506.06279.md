# CoMemo: LVLMs Need Image Context with Image Memory

> [!summary] Summary
> Chinese Academy of Sciences and Shanghai AI Lab researchers develop CoMemo, a dual-path architecture that addresses the "lost in the middle" phenomenon and positional encoding limitations in Large Vision-Language Models by combining a Context path (autoregressive processing) with an Image Memory path (cross-attention retrieval) alongside RoPE-DHR positional encoding that preserves 2D spatial relationships in high-resolution images, achieving 17.2% relative improvement on caption tasks and 7.0% on long-generation tasks compared to single-paradigm baselines while demonstrating superior performance across seven benchmark categories including multi-image reasoning where CoMemo maintains higher accuracy for information placed in middle sequences compared to conventional LVLM-S models, with the framework employing a three-stage training strategy that prevents optimization bias between pathways through gate freezing and validates consistent improvements at both 2B and 8B parameter scales across diverse fine-tuning datasets.

## Problem

- LVLMs exhibit "lost in the middle" phenomenon inherited from LLMs, where attention distribution becomes bimodal and neglects information in middle of long input sequences
- Conventional 1D positional encoding schemes like RoPE fail to preserve 2D spatial relationships in high-resolution images, leading to sparse encodings and remote decay when processing numerous image patches

## Method

- ==Dual-path architecture== combining Context path (LVLM-S-like autoregressive processing) with Image Memory path (LVLM-X-like cross-attention) using shared image representations
- ==RoPE-DHR positional encoding== that maps high-resolution image tiles to thumbnail coordinates, preserving 2D spatial awareness while preventing sparse encoding
- ==Three-stage training strategy== with projector/mixin tuning, gate freezing, and full-parameter finetuning to balance pathway optimization

## Results

- **17.2%** relative improvement on caption tasks and **7.0%** on long-generation tasks compared to single-paradigm baselines
- Superior performance across multi-image reasoning, long-context comprehension, and Needle-in-a-Haystack tasks with **5.6%** improvement on long-context benchmarks
- Consistent improvements at both **2B** and **8B** parameter scales while maintaining comparable training and inference efficiency to LVLM-S models

## Takeaways

> [!tip] Key Insights
> - Both LVLM-X and LVLM-S paradigms have complementary strengths that can be effectively combined through dual-stream processing
> - Positional encoding compression and 2D spatial preservation are crucial for handling dynamic high-resolution images in vision-language models
> - Training stage management prevents over-reliance on single pathways and ensures balanced multimodal representation learning
