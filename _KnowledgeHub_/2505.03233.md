# GraspVLA: a Grasping Foundation Model Pre-trained on Billion-scale Synthetic Action Data

> [!summary] Summary
> GraspVLA, a grasping foundation model from Galbot and Peking University, demonstrates robust zero-shot sim-to-real transfer and open-vocabulary grasping by pre-training exclusively on SynGrasp-1B, a billion-scale synthetic action dataset, achieving around 90% success rates on diverse real-world object categories.

## Problem

- Robot learning, particularly for Vision-Language-Action (VLA) models, faces a severe data bottleneck due to the high cost and labor intensity of collecting real-world robotic action data.
- Existing VLA models primarily rely on expensive real-world data, limiting scalability and generalization capabilities for diverse objects and environments.
- Bridging the sim-to-real gap for complex manipulation tasks like grasping, especially with synthetic-only pre-training, has been a significant challenge.

## Method

- Developed SynGrasp-1B, the first billion-frame, photorealistic synthetic robotic grasping dataset, generated with extensive domain randomization and detailed annotations for imitation learning.
- Introduced GraspVLA, a VLA model architecture that integrates a vision-language model with an action expert via a novel Progressive Action Generation (PAG) mechanism.
- Employed a unified training strategy that co-trains GraspVLA on SynGrasp-1B for action supervision and Internet semantics data (GRIT) for perception tasks, enabling open-vocabulary generalization.

## Results

- GraspVLA achieved around 90% success rates in zero-shot real-world grasping across five diverse test sets (lighting, background, distractors, etc.) for both synthetic and unseen web object categories, outperforming existing VLA generalists and imitation learning specialists.
- Demonstrated strong zero-shot performance in the LIBERO benchmark, surpassing fine-tuned baselines, and showed comparable language-conditioned grasping success (93.3%) with a state-of-the-art specialist, AnyGrasp (91.6%).
- Exhibited efficient few-shot adaptability, achieving 90% success on rare industrial components with only bounding box annotations and successfully learning specialized grasping patterns (80% success for mug-handle grasping) with minimal demonstrations.

## Takeaways

> [!tip] Key Insights
> - Large-scale, meticulously designed synthetic data can exclusively pre-train a VLA model to achieve direct sim-to-real transfer and robust zero-shot generalization across diverse real-world conditions.
> - The Progressive Action Generation (PAG) mechanism, formulated as a Chain-of-Thought process with intermediate 2D bounding box and 3D grasp pose predictions, effectively combines synthetic action data with Internet semantics to enable open-vocabulary grasping for novel objects.
> - Performance consistently scales with increasing training data (frames and object diversity) in both real-world and simulation, particularly benefiting generalization to unseen object categories.
