# GraSP-VLA: Graph-based Symbolic Action Representation for Long-Horizon Planning with VLA Policies

> [!summary] Summary
> The GraSP-VLA framework enables robots to perform complex, long-horizon tasks by automatically deriving symbolic action representations from human demonstrations using a Multi-Layer Continuous Scene Graph. This neuro-symbolic approach orchestrates existing low-level Vision-Language Action policies, achieving up to 0.4 task accuracy on 6-skill tasks where direct end-to-end VLA fine-tuning yielded 0.0 accuracy.

## Problem

- End-to-end Vision-Language Action (VLA) models lack high-level planning capabilities, limiting their performance on complex, long-horizon robotic tasks.
- Traditional symbolic Action Model Learning (AML) requires extensive human effort to define symbolic representations and domain knowledge, hindering its generalization and scalability.
- A gap exists in effectively integrating low-level perception and control from neural networks with high-level symbolic planning for robust autonomous robotics.

## Method

- A Multi-Layer Continuous ==Scene Graph== (ML-CSG) is introduced, extending scene graph generation with temporal aggregation and state refinement to create a dynamic, persistent symbolic representation.
- An algorithm automatically generates PDDL planning actions (preconditions and effects) by identifying changes in agent-object functional and topological relations within the Continuous Scene Graph during demonstrations.
- A client-server orchestrator maps the automatically generated PDDL actions to a bank of pre-trained low-level Vision-Language Action policies, enabling complex task execution by chaining atomic skills.

## Results

- The SGG backbone achieved R@**50/100** of 31.**4/34**.5, although it demonstrated limitations in detecting fine-grained action-related predicates (e.g., Recall@100 for 'holding' was 0.29).
- Automatic PDDL action generation, especially with informative selection, demonstrated improved detection of action-related predicates from the Continuous Scene Graph, yielding an average Action Accuracy of 0.96 in real-time robotic scenarios.
- GraSP-VLA substantially improved long-horizon task success rates compared to end-to-end VLA fine-tuning, achieving 0.6 vs 0.2 for 2-skill tasks, 0.4 vs 0.1 for 4-skill tasks, and 0.4 vs 0.0 for 6-skill tasks on a SO-101 robot arm.

## Takeaways

> [!tip] Key Insights
> - Scene Graph Generation, particularly with multi-layered and continuous temporal aggregation, offers a viable, low-cost method for automatic symbolic knowledge extraction for action model learning.
> - Decomposing long-horizon tasks into orchestrated sequences of atomic Vision-Language Action policies, guided by automatically generated PDDL plans, scales more effectively than training a single end-to-end VLA policy.
> - Real-time monitoring of the environment state via the Continuous Scene Graph allows for pre-condition validation and a robust fallback mechanism, enhancing task execution reliability.
