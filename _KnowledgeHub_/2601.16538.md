# OnlineSI: Taming Large Language Model for Online 3D Understanding and Grounding

> [!summary] Summary
> OnlineSI enables multimodal large language models to continuously perceive and understand 3D environments from streaming video by employing a finite spatial memory and fusing point cloud data with semantic information. The framework achieves an average Fuzzy F1-score of 0.4397 on ScanNet++, demonstrating improved 3D object grounding and recognition over baselines.

## Problem

- Existing MLLMs face prohibitive computational scaling issues and exhaust context windows when processing continuous, streaming 3D data.
- MLLMs often lack the ability to continuously learn, refine, and adapt their spatial understanding from dynamic real-world environments.
- Evaluating online 3D object detection with partial observations introduces significant ambiguity, making reliable performance assessment challenging.

## Method

- Introduces ==OnlineSI==, a framework utilizing a finite, explicit ==spatial memory== for continuous 3D point cloud and semantic label fusion from video streams, maintaining a bounded computational budget.
- Enhances the base SpatialLM by injecting ==semantic information==, derived from Llama token features, into point cloud features to create unified spatial memory tokens for the MLLM backbone.
- Proposes a novel ==Fuzzy F1-Score metric== to robustly evaluate online 3D object detection in scenarios with partial observations, addressing inherent ambiguities.

## Results

- OnlineSI achieved an average Fuzzy F1-score of **0.4397** on ScanNet++, significantly outperforming baselines such as SpatialLM-Finetune (**0.3943**) and SpatialLM-Merge (**0.3397**).
- Qualitative results demonstrate OnlineSI's capacity to continuously refine scene understanding, leveraging spatial memory and semantic cues for accurate 3D object localization and recognition in real-world scenes.
- Ablation studies confirmed the critical roles of explicit 3D point cloud memory, semantic information injection, and ground-plane aligned coordinate systems for optimal performance.

## Takeaways

> [!tip] Key Insights
> - Maintaining a persistent, explicit 3D spatial memory is crucial for aggregating observations over time and achieving robust online 3D understanding, outperforming implicit 1D latent state representations.
> - Injecting detailed semantic information, derived from the MLLM's own token features, significantly enhances the model's ability to localize and recognize objects within the 3D point cloud.
> - Aligning the point cloud with a ground-plane coordinate system is fundamental for the SpatialLM backbone, indicating its strong dependence on axis-aligned input for effective 3D reasoning.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This work is situated within the evolving field of Multimodal Large Language Models (MLLM) and their application to spatial understanding and reasoning, particularly in dynamic, real-world environments. Existing MLLM research has shown promise in integrating vision and language, but many methods encounter limitations when deployed in continuous, online settings, such as those required for embodied AI systems.

A primary challenge addressed by OnlineSI is the computational scalability and memory consumption of MLLMs when processing streaming data. Traditional MLLM architectures often reprocess all past observations, leading to rapid exhaustion of computational resources and model context as input accumulates. The paper highlights this as a significant barrier to the deployment of MLLMs on embodied systems, which require continuous operation and adaptation in ever-changing 3D worlds.

Furthermore, current MLLMs frequently struggle with fine-grained spatial understanding and reasoning due to a scarcity of 3D-grounded training data. While some previous works have explored memory management for embodied planning, they often exhibit infinitely growing memory banks and provide only coarse-grained 3D perception, which is insufficient for tasks requiring precise object manipulation. OnlineSI aims to address these issues by proposing a framework that maintains a finite spatial memory and integrates fine-grained 3D point cloud information with semantic cues.

The paper connects to several related areas:
- **3D Object Detection:** It draws from methods operating on 3D point clouds and single-view 2D images, noting how some leverage 2D knowledge or LLMs to enrich 3D representations. OnlineSI emphasizes online detection from video streams, distinguishing itself from static scene detection.
- **Multimodal Large Language Models:** It builds upon the success of MLLMs in unifying vision and language, specifically focusing on adapting them for 3D understanding and spatial reasoning. It contrasts with prior MLLMs that face computational overload with increasing input or lack continuous learning capabilities.
- **2D Object Detection:** It utilizes off-the-shelf 2D detectors to provide semantic information, which is then integrated into the 3D representation.

By focusing on online learning, bounded memory, and fine-grained 3D understanding, OnlineSI seeks to advance MLLMs towards practical deployment in dynamic, real-world embodied systems, moving beyond static, offline analysis.

### 2. Key Objectives and Motivation

The primary objective of this research is to enable Multimodal Large Language Models (MLLM) to continuously improve their spatial understanding of surroundings and perform object grounding in an online fashion, given a video stream. This overarching goal is motivated by the demands of embodied AI systems operating in complex, dynamic environments.

The key motivations and specific objectives are detailed as follows:

#### 2.1. Motivation

1. **Challenges in Embodied Systems:** Autonomous agents, such such as robots, are increasingly expected to operate in dynamic, open-world scenes and execute long-horizon tasks. This necessitates the ability to continuously learn and adapt from an ever-changing 3D world, updating their spatial understanding from new observations in real-time. This online learning capability is a prerequisite for downstream applications like active learning, long-term planning, and human-robot interaction.
2. **Computational Scaling Limitations of Existing MLLMs:** Most existing MLLM methods face prohibitive computational scaling as the input stream grows. Architectures that repeatedly process all past observations with full attention layers quickly exhaust model context and computational budgets due to spatial and contextual redundancy. This makes them unsuitable for long-term deployment in embodied systems.
3. **Deficiencies in Spatial Understanding and Reasoning:** Many current MLLMs exhibit limitations in understanding spatial relationships and performing effective spatial reasoning. This issue is compounded by a scarcity of high-quality 3D-grounded training data. Furthermore, some existing solutions for spatial memory management in embodied planning, while attempting to address memory, still suffer from infinitely growing memory banks and provide only coarse-grained 3D perception, rendering them inadequate for tasks requiring precise object manipulation.

#### 2.2. Key Objectives (Contributions)

To address these motivations, the authors established the following objectives:

1. **Develop OnlineSI for Online 3D Scene Understanding with Bounded Memory:** The primary objective is to introduce OnlineSI, a novel framework capable of incrementally processing video streams to continuously enhance its 3D scene understanding and object grounding. A core design principle is to maintain a finite, explicit spatial memory, ensuring that the memory space and inference cost growth are bounded, thus facilitating deployment on embodied systems.
2. **Propose a Novel Fusion Method for Enhanced Object-Level Spatial Understanding:** A secondary objective is to integrate 3D point cloud data with semantic information. This fusion technique is intended to provide the MLLM with a richer, object-level understanding of the scene, thereby improving its ability to precisely locate and identify objects, especially in partially reconstructed scenes.
3. **Introduce a Robust Evaluation Metric for Online Detection:** Recognizing the inherent ambiguities in evaluating object detection performance under partial observation in online settings, an objective is to propose the Fuzzy F1-Score. This new metric aims to mitigate the impact of such ambiguities, providing a more fair and reliable assessment of detection performance.

These objectives collectively aim to bridge the gap between static MLLM capabilities and the dynamic requirements of real-world embodied AI.

### 3. Methodology and Approach

OnlineSI is a framework designed for online 3D understanding and object grounding from a streaming video input. Its methodology focuses on continuous scene understanding, bounded memory management, and robust multimodal information fusion for object-level predictions.

#### 3.1. Problem Formulation and Coordinate System Unification

The system processes an potentially infinite sequence of images $\{I_t\}$ to predict 3D bounding boxes and class labels for observed objects in a unified coordinate frame. A critical design choice is to define this unified coordinate frame with its origin at the initial camera's position, its XY-plane parallel to the scene's ground, and its Z-axis perpendicular to it. This aligns with the requirement of the underlying SpatialLM, which is constrained to processing axis-aligned point clouds and predicting rotations only around the Z-axis. The transformation from the initial camera frame to this unified, aligned coordinate frame is assumed to be known (e.g., derived from camera pitch and roll angles). This choice ensures the MLLM can effectively interpret the 3D geometry.

#### 3.2. Spatial Memory Management

The core of OnlineSI's continuous learning capability is its spatial memory, denoted as $M_t = \{P_t, S_t\}$.
- $P_t \in \mathbb{R}^{N \times 6}$ represents the constructed point cloud (XYZ coordinates and RGB colors).
- $S_t \in \mathbb{Z}^N$ represents the semantic label for each point.

For each incoming frame $I_t$:
1. **3D Reconstruction:** A pre-trained reconstruction model (specifically, CUT3R) predicts a pointmap $X_t \in \mathbb{R}^{H \times W \times 3}$ in the initial camera frame.
2. **Semantic Annotation:** An off-the-shelf semantic annotator (Grounded SAM) generates a semantic map $Y_t \in \mathbb{Z}^{H \times W}$, where each pixel corresponds to a semantic label for a point in $X_t$.
3. **Coordinate Transformation:** The points in $X_t$ are transformed into the unified aligned coordinate frame, resulting in $X'_t$.
4. **Memory Fusion:** $X'_t$ and $Y_t$ are fused with the previous spatial memory $\{P_{t-1}, S_{t-1}\}$ to update the current memory $\{P_t, S_t\}$. This fusion involves sampling points from $P_{t-1}, X'_t, S_{t-1}, Y_t$ at specific ratios, followed by concatenation.
5. **Bounded Memory:** To prevent unbounded growth of $M_t$ and mitigate forgetting, the fusion ratios are adjusted dynamically based on the timestep $t$. This ensures the total number of points in $M_t$ remains below a predefined threshold, and the number of points sampled from each input frame is uniform. The sample indices are unified to maintain correspondence between points and their semantic labels.

#### 3.3. Point Cloud Encoder and Semantic Encoder

The updated spatial memory $\{P_t, S_t\}$ is processed by specialized encoders before being fed into the MLLM backbone.
- **Point Cloud Encoder:** This component follows the design of Sonata, encoding the point cloud $P_t$ into 3D feature patches $F \in \mathbb{R}^{K \times D}$.
- **Semantic Encoder:** This encoder is designed to inject semantic information into the point cloud features.
 - For each point's semantic label, it is converted into its corresponding Llama-3.2-1B-Instruct token feature.
 - These per-point features are aggregated into semantic feature patches using identical pooling operations to the point cloud encoder.
 - A final linear projection layer processes these patches.
 - The resulting semantic features are then added to the point cloud features obtained from the point cloud encoder, forming the "spatial memory tokens."
 - This design ensures semantic and point cloud features share the same granularity and spatial location, while minimizing trainable parameters for efficient fine-tuning.

#### 3.4. Multimodal Large Language Model (MLLM) Backbone

The MLLM backbone is initialized with SpatialLM1.1-Llama-1B. It receives the combined spatial memory tokens (point cloud + semantic features) and text prompt tokens (e.g., "Detect {categories} in the scene."). The LLM then generates a scene description in text format, which is subsequently interpreted as a set of 3D bounding boxes for detected objects. During training, only the last layers of the point cloud encoder, semantic encoder, and the LLM backbone are trainable, with other parameters frozen, using standard cross-entropy loss.

#### 3.5. Fuzzy F1-Score for Evaluation

To address the ambiguity of object detection in online settings with partial observations, the Fuzzy F1-Score is introduced.
- **Ground Truth Definition:** Two sets of 3D bounding box annotations are defined:
 - Strict ground truth ($O^s_{gt}$): Objects with a high visible proportion, expected to be detected.
 - Lenient ground truth ($O^l_{gt}$): Includes all objects, even those with low visibility. ($O^s_{gt} \subseteq O^l_{gt}$)
- **Metric Calculation:** The Fuzzy F1-Score is calculated using the recall on $O^s_{gt}$ and the precision on $O^l_{gt}$.
 $\text{Fuzzy-F1} = 2 \cdot \frac{\text{recall}(O_{pred}, O^s_{gt}) \cdot \text{precision}(O_{pred}, O^l_{gt})}{\text{recall}(O_{pred}, O^s_{gt}) + \text{precision}(O_{pred}, O^l_{gt})}$
This metric ensures that the system is not penalized for not detecting objects with very low visibility, while still rewarding correct detections within the lenient set.

### 4. Main Findings and Results

The experiments conducted aimed to evaluate OnlineSI's performance in novel scenes, its efficiency in computation and memory, the benefits of persistent spatial memory and semantic integration, and the impact of external modules.

#### 4.1. Quantitative Results (Table 1)

OnlineSI demonstrates superior performance against three lower-bound baselines on both ScanNet and ScanNet++ datasets. The two upper-bound baselines, which utilize ground-truth point clouds or semantic labels, indicate the potential performance limits if external reconstruction and semantic annotation modules were error-free.
- **Overall Effectiveness:** OnlineSI achieves an average Fuzzy F1-Score of 0.4397 on ScanNet++ and 0.3349 on ScanNet, significantly outperforming `SpatialLM-No-Finetune` (0.0351, 0.0383), `SpatialLM-Merge` (0.3397, 0.2214), and `SpatialLM-Finetune` (0.3943, 0.2733).
- **Importance of Spatial Memory:** OnlineSI's performance surpasses `SpatialLM-Merge` (which merges per-frame predictions), highlighting the benefit of explicitly maintaining and refining a global spatial memory over time.
- **Contribution of Semantic Information:** The framework's superior results compared to `SpatialLM-Finetune` (which omits the semantic component) confirm that injecting semantic information enhances object localization and recognition.

#### 4.2. Qualitative Results (Figure 3)

Visual comparisons illustrate the system's ability to build a continuous and accurate understanding.
- `SpatialLM-No-Finetune` performs poorly on the inherently partial and incomplete online reconstructed point clouds.
- `SpatialLM-Merge` often retains numerous erroneous predictions due to the incomplete information in single-frame analyses.
- `SpatialLM-Finetune` frequently produces incorrect detections due to imperfections in the reconstructed point cloud alone.
- In contrast, OnlineSI effectively aggregates information from its spatial memory and leverages semantic cues to refine detections and incrementally detect new instances, leading to a more consistent and accurate scene understanding over time.

#### 4.3. Inference Cost Scaling (Figures 4 and 5)

The study analyzed how computational and memory costs scale with an increasing number of input images.
- **Inference Computation (Figure 4):** OnlineSI exhibits sub-linear scaling of inference computation time per forward pass, significantly reducing the growth compared to VLM-3R. This suggests that the bounded memory approach effectively curbs computational overhead.
- **Memory Usage (Figure 5):** The system's memory consumption remains constant once a preset memory limit is reached, unlike the baseline (VLM-3R) which shows linear memory growth as it stores all past observations. This demonstrates the effectiveness of the selective fusion strategy in spatial memory management.

#### 4.4. Ablation Studies

- **Choice of Spatial Memory (Table 2):** Experiments comparing explicit 3D point cloud memory with implicit one-dimensional latent state representations (from CUT3R) showed that explicit 3D point clouds are substantially more effective (OnlineSI: 0.4397 vs. 1D State: 0.0764). This suggests that the MLLM struggles to interpret implicit 1D representations with the available training data.
- **Coordinate System Selection (Figure 6):** Aligning the reconstructed point cloud with the ground plane (unified coordinate frame) is crucial for performance. When using the initial camera's coordinate frame, both OnlineSI and `SpatialLM-Finetune` experienced a dramatic drop in Fuzzy F1-Score (e.g., OnlineSI from 0.4397 to 0.0007), confirming that SpatialLM requires axis-aligned inputs.
- **Fuzzy F1-Score (Figure 7):** Examples demonstrate that the Fuzzy F1-Score mitigates ambiguity by accounting for varying object visibility. It provides a more balanced evaluation compared to vanilla F1-scores, which are sensitive to strict or lenient ground truth definitions for partially observed objects.
- **Semantic Representation (Table 3):** Using Llama-3.2-1B-Instruct token features for semantic labels (0.4397) performed slightly better than CLIP features (0.4319), suggesting that consistency between the semantic representation and the LLM backbone's token space is marginally beneficial.

### 5. Significance and Potential Impact

OnlineSI represents an advancement in enabling Multimodal Large Language Models to operate effectively in dynamic, real-world environments. The significance and potential impact of this work span several areas:

1. **Enabling Embodied AI Systems:** The framework directly addresses critical limitations for embodied agents, such as robots. By allowing MLLMs to continuously learn and refine their 3D scene understanding from streaming video, OnlineSI paves the way for robots to execute long-horizon tasks, engage in active learning, and participate in more natural human-robot interactions within open-world scenes. This online learning capability is a fundamental requirement for truly autonomous systems.

2. **Addressing Computational and Memory Scalability:** A key contribution is the design of a bounded spatial memory and its associated management strategy. The demonstration of sub-linear inference cost scaling and constant memory usage, once a limit is reached, is crucial for practical deployment on systems with constrained computational resources. This mitigates the common MLLM challenge of prohibitive resource consumption with increasing input data.

3. **Enhanced 3D Spatial Understanding and Grounding:** The novel fusion of 3D point cloud data with semantic information allows the MLLM to achieve a finer-grained, object-level understanding of the environment. This is particularly important for tasks requiring precise object localization and manipulation, moving beyond coarse scene representations. The qualitative results illustrate the framework's ability to detect and refine object predictions more accurately over time.

4. **Robust Evaluation for Online Tasks:** The introduction of the Fuzzy F1-Score provides a more appropriate and fair evaluation metric for online detection scenarios where partial observations are inherent. This metric mitigates the ambiguity arising from varying object visibility, offering a more reliable assessment of model performance and facilitating future research in this area.

5. **Foundation for Future Research:** The identified limitations, such as the current restriction to indoor scenes and the "sample and concatenate" memory method, suggest avenues for future work. Expanding the base model with more diverse 3D data and exploring 4D reconstruction with tracking for dynamic scenarios could further enhance the framework's capabilities. OnlineSI establishes a foundation for building more spatially intelligent systems.

In summary, OnlineSI contributes to the practical deployment of MLLMs in dynamic environments by tackling computational efficiency, continuous learning, and robust 3D understanding, thereby bringing real-world embodied AI systems closer to realization.
