# VisionHOPE: Visual Backbones as Self-Modifying Learning Systems

> [!summary] Summary
> VisionHOPE is a visual backbone built as a self-modifying learning system: while it processes an image, five coupled memories (content, key, value, learning rate, retention) update together, so the model changes both what it stores and how it learns. A stability-matched step-size control keeps the memory dynamics non-expansive. Four directional scans aligned to rows and columns give linear cost, and the model matches or beats CNN, ViT, SSM and TTT backbones.

## Problem

- CNNs, ViTs, SSMs and TTT layers adapt their computation to each input, but the rule that governs that adaptation is fixed by the trained backbone.
- TTT-based visual backbones update an inner learner, but its key/value maps and update rule stay set by outer training and do not evolve within the image.
- Applying Nested Learning's unconstrained self-referential update directly to vision is unstable: memories produce their own update quantities, so expansive transitions compound and make training diverge.

## Method

- The ==Self-Referential Nested Learning== (SRNL) module couples five memories (content, key, value, learning rate, retention), each updated by a retained ==Delta Gradient Descent== rule that writes residual corrections against what is already stored.
- ==Stability-matched step-size control== pairs a ==soft cap== on self-referential injection with a ==spectral clamp== on the retained memory transition, which provably makes token-wise and chunk-wise memory recurrences non-expansive.
- ==Four directional scans== (forward and reverse, row-major and column-major) use chunks aligned to image rows or columns, independent per-direction states and channel-wise fusion, in both hierarchical and plain backbones.

## Results

- On ImageNet-1K, VisionHOPE-T/S/B reach **84.1**/**85.2**/**85.6%** Top-1, and P-VisionHOPE-T/S/B reach **78.4**/**82.3**/**83.4%**, the best or tied-best in every scale panel against Vision-TTT and H-ViT3.
- On dense prediction, VisionHOPE-T gets **47.9** box AP and **43.1** mask AP on COCO with Mask R-CNN, and **49.4** mIoU on ADE20K, **1.4 points** above H-ViT3-T.
- In ablations, removing the soft injection cap gives NaN divergence. Removing adaptive K/V and dynamics drops accuracy **82.3** to **81.7%**, and 1-way scanning drops it to **81.6%**. P-VisionHOPE-B uses far less memory than DeiT-B at high resolution.

## Takeaways

> [!tip] Key Insights
> - Letting a network learn its own learning rule within one input can beat a fixed adaptation rule, as long as the feedback loop is explicitly made non-expansive.
> - Self-referential fast-weight systems need a cap on how much signal they inject into themselves; the spectral clamp mattered far less because it almost never activated.
> - Classic associative-memory ideas such as delta-rule writes, retention and fast weights are now competitive vision backbones with linear cost in the number of tokens.

## Detailed Report

### 1. Overview

An image backbone must combine information across image locations. For high-resolution images, self-attention's quadratic complexity in token count is costly. Vision backbones have also become more adaptive to the image they are processing, but the rules that govern that adaptation usually remain fixed. VisionHOPE lets the rules change too. Five coupled memories evolve within an image, so the model adapts both what it stores and how it updates that store. Memories that generate their own update signals can feed back expansively, so the authors add a step-size control scheme. They prove that this scheme prevents memory-state norms from growing along token-wise and chunk-wise scans. The authors call VisionHOPE the first generic visual backbone formulated as a self-modifying learning system.

Conceptual comparison of within-image adaptation, from local operations to systems that alter their own update rules.

### 2. A memory that updates its own rules

An associative memory is a learned mapping from keys to values held in a state. VisionHOPE uses five memories, each with its own role:

- Content memory stores information.
- Key and value memories generate representations used for updates.
- Learning-rate and retention memories control update size and how much old state persists.

At each token, these memories generate quantities for their own subsequent updates and targets, so they co-evolve as context accumulates. Writes use Delta Gradient Descent (DGD). A simple write is based only on the current signal. DGD instead corrects the write by accounting for what the memory already returns at the current key.

The nearest conceptual predecessor is [[2512.24695|Nested Learning]], which already proposes self-referential learning and coupled memories. The closer visual comparison is [[2603.00518|Vision-TTT]], which already updates an inner learner along visual tokens. VisionHOPE's stated distinction is that its key/value representation maps and update dynamics also evolve within the image, rather than remaining largely outer-parameterized.

### 3. Stability is part of the mechanism

The memories generate the quantities used in their own later updates, so expansive transitions could compound. Two controls address this risk. A smooth cap limits self-referential injection while preserving sensitivity to small raw steps. A spectral clamp limits the retained transition. The proof assumes the stated stabilized key normalization and the control scheme. Under those conditions, the authors prove non-expansion of memory-state norms for token-wise recurrence. They also prove it for chunk-wise recurrence relative to chunk-boundary states. This guarantee covers those memory dynamics. It does not cover overall accuracy, training convergence in every setting, or inference speed.

The ablation study used P-VisionHOPE-S with the backbone and training protocol fixed. The full model scores 82.3% ImageNet-1K Top-1 accuracy. Removing within-image adaptation of the key/value memories and the learning-rate/retention dynamics together lowers the score to 81.7%. Removing the soft injection cap yields NaN (numerical divergence) early in training. Replacing it with a hard injection clamp scores 81.8%. Removing the spectral clamp also scores 82.3%. The authors suggest that the clamp's very rare activation helps explain its unchanged ablation accuracy.

This evidence supports the full control scheme and the importance of the soft injection cap in this training setting. It does not show a measurable accuracy gain from the spectral clamp in this ablation. The theoretical bound and the measured ablation answer different questions.

### 4. From scan to visual tasks

Each of four independent scans follows a row or column order and refreshes state at chunk boundaries. Each then restores its outputs to the same feature grid for channel-wise fusion. The recurrent computation scales linearly in token count. This complexity claim does not, by itself, establish lower elapsed time or higher throughput.

On COCO val2017, the reported comparison uses Mask R-CNN 1×. Hierarchical VisionHOPE-T reports 47.9 box AP and 43.1 mask AP, versus H-ViT³-T's 47.3 and 42.8. On ADE20K validation with UPerNet, VisionHOPE-T reports 49.4% mIoU, a mean segmentation-overlap score, versus H-ViT³-T's 48.0%. The paper reports VisionHOPE as best or tied-best in COCO box and mask AP across the three reported scales. These cross-model scores do not by themselves show that the memory mechanism caused the gains.

### 5. When the rule can learn

VisionHOPE adapts both stored content and the machinery that determines future writes. Explicit controls make that coupled recurrence non-expansive under the paper's conditions. Improvements are often small or ties, and the results concern general-purpose visual recognition. The model has not been evaluated as an MLLM visual encoder or on specialized medical-imaging and remote-sensing tasks.
