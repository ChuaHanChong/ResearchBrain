# Memory in the Age of AI Agents

> [!summary] Summary
> This survey provides a comprehensive analysis of memory systems in AI agents, introducing a novel "Forms–Functions–Dynamics" taxonomy to categorize and understand current research. It clarifies conceptual boundaries with related areas and identifies promising future research directions, establishing a unified framework for the field.

## Problem

- The rapid expansion of AI agent research has led to fragmentation and conceptual ambiguity regarding memory systems.
- Existing taxonomies, like the simple long-term/short-term dichotomy, are insufficient to capture the diversity of modern agent memory.
- A lack of clear distinctions between agent memory, LLM memory, Retrieval-Augmented Generation (RAG), and context engineering hinders systematic progress.

## Method

- The authors introduce a ==multidimensional "Forms–Functions–Dynamics" (FFD) taxonomy== for agent memory.
- They rigorously define agent memory and delineate its boundaries from related concepts such as LLM memory, RAG, and ==context engineering==.
- The survey systematically categorizes existing research within this FFD framework and outlines emerging research frontiers.

## Results

- The survey identifies **token-level memory** as the most prevalent form, detailing its structural variations (1D flat, 2D planar, 3D hierarchical) alongside parametric and latent memory forms.
- It presents a functional taxonomy distinguishing **factual memory** (user/environment consistency), **experiential memory** (case-based, strategy-based, skill-based learning), and **working memory** (single/multi-turn context management).
- Memory dynamics are decomposed into **formation** (summarization, distillation, structured construction), **evolution** (consolidation, updating, forgetting), and **retrieval** (timing, query construction, strategies, post-processing), each with detailed sub-processes.

## Takeaways

> [!tip] Key Insights
> - Agent memory differs from LLM memory, RAG, and context engineering by focusing on an external, evolving cognitive state for persistent, adaptive decision-making.
> - Memory forms are classified by *where it resides* and *how it's represented* (token-level, parametric, latent), with token-level memory further structured into flat, planar, and hierarchical organizations.
> - Memory functions are categorized by *purpose* (factual, experiential, working memory), while dynamics cover the lifecycle of memory via *formation*, *evolution*, and *retrieval* processes.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The emergence of increasingly capable Large Language Models (LLMs) has catalyzed a paradigm shift, transforming these models from static text generators into dynamic AI agents. These agents, endowed with capabilities like reasoning, planning, perception, memory, and tool-use, are advancing the trajectory toward Artificial General Intelligence (AGI). Among these faculties, memory is explicitly identified as a cornerstone, enabling LLMs to transition from static conditional generators to adaptive agents capable of continual evolution through environmental interaction.

However, the rapid expansion of research into agent memory has led to significant fragmentation. Existing works often diverge substantially in their motivations, implementations, assumptions, and evaluation protocols. Compounding this, a proliferation of loosely defined terminologies (e.g., declarative, episodic, semantic, parametric memory) has obscured conceptual clarity. Traditional taxonomies, such as the simple long-term/short-term memory dichotomy, are deemed insufficient to capture the diversity and dynamics of contemporary agent memory systems. This survey directly addresses this fragmentation by proposing an up-to-date and comprehensive landscape of current agent memory research.

A crucial aspect of this survey is its clear delineation of "agent memory" from closely related, yet distinct, concepts:
- **Agent Memory vs. LLM Memory:** While LLM memory broadly refers to managing the transformer's internal Key-Value (KV) cache, designing long-context processing, or modifying model architectures for better information retention, agent memory explicitly concerns an external, evolving cognitive state that supports persistent, adaptive decision-making. The survey argues that many early "LLM memory" works are, by modern definitions, instances of agent memory.
- **Agent Memory vs. Retrieval-Augmented Generation (RAG):** Both involve leveraging auxiliary information stores. However, classical RAG primarily augments an LLM with access to static, externally sourced knowledge for individual inference tasks to improve factual grounding. In contrast, agent memory systems operate within an agent's ongoing interaction with an environment, continuously incorporating new information generated by the agent's actions and environmental feedback into a persistent, self-evolving memory base across multiple tasks and sessions. The survey acknowledges the increasing blurriness of this boundary with "agentic RAG" but maintains the distinction based on task domain and the dynamic, self-evolving nature of agent memory.
- **Agent Memory vs. Context Engineering:** Context engineering treats the context window as a constrained computational resource, rigorously optimizing the information payload to maximize inference efficacy. Agent memory, while leveraging context engineering techniques for its implementation (especially for working memory), defines a broader cognitive scope: it governs *what* the agent knows, *what* it has experienced, and *how* these elements evolve over time, sustaining a persistent cognitive state beyond any single context window.

By providing this clarity and a novel, structured taxonomy, this work aims to unify the fragmented research landscape, serving as a foundational reference for understanding and advancing memory systems in AI agents.

### 2. Key Objectives and Motivation

The primary motivation for this survey stems from the observed fragmentation and conceptual ambiguity within the rapidly expanding field of agent memory research. The authors recognize that while memory is a critical capability for AI agents, the lack of a unified framework hinders systematic understanding and progress.

The survey explicitly states its objectives through five key questions it aims to address:
1. **Definition and Relation:** How is agent memory defined, and how does it relate to concepts like LLM memory, RAG, and context engineering? This objective focuses on establishing conceptual clarity and boundaries.
2. **Forms:** What architectural or representational forms can agent memory take? This delves into the structural implementations of memory.
3. **Functions:** Why is agent memory needed, and what roles or purposes does it serve? This explores the cognitive utility and objectives of memory.
4. **Dynamics:** How does agent memory operate, adapt, and evolve over time? This examines the lifecycle and active management of memory.
5. **Frontiers:** What are the promising frontiers for advancing agent memory research? This looks forward to future challenges and opportunities.

In addition to answering these questions, the authors highlight four main contributions:
1. **Multidimensional Taxonomy:** Presenting an up-to-date, multidimensional taxonomy of agent memory based on "forms–functions–dynamics" to provide a structured lens for understanding current developments.
2. **Suitability and Interplay:** Providing an in-depth discussion on how different memory forms align with various functional purposes and objectives.
3. **Emerging Research Directions:** Investigating promising and underdeveloped research frontiers to outline future opportunities.
4. **Comprehensive Resources:** Compiling a collection of benchmarks and open-source frameworks to support researchers and practitioners.

Ultimately, the core motivation is to establish a systematic framework that reconciles existing definitions, bridges emerging trends, and elucidates the foundational principles of memory in agentic systems, thereby promoting a coherent, forward-looking research agenda.

### 3. Methodology and Approach

The survey adopts a systematic and structured approach to analyze the vast literature on agent memory, organizing it around a novel, unified taxonomy of **Forms, Functions, and Dynamics**. This "Forms–Functions–Dynamics" (FFD) triangle provides a comprehensive lens through which to categorize, compare, and understand existing research, moving beyond simplistic temporal categorizations.

The methodology is structured as follows:

1. **Preliminaries (Section 2):**
 - **Formalization:** The paper begins by formalizing LLM-based agent systems and agent memory systems, defining agents as LLM backbones augmented with reasoning, planning, perception, memory, and tool-use capabilities. Memory is formalized as an evolving state *M_t* with three conceptual operators: Formation, Evolution, and Retrieval.
 - **Conceptual Delineation:** It then rigorously distinguishes agent memory from related concepts—LLM memory, Retrieval-Augmented Generation (RAG), and Context Engineering—to establish clear boundaries and address fragmentation in terminology.

2. **Forms (Section 3): What Carries Memory?**
 - This section examines the architectural and representational forms memory can take. It categorizes memory based on *where it resides* and *in what form it is represented*.
 - **Token-level Memory:** Stores information as explicit, discrete, and externally accessible units (e.g., text, code). This is further subdivided by structural organization:
 - **Flat Memory (1D):** No explicit inter-unit topology (sequences, bags of units).
 - **Planar Memory (2D):** Single-layer structured organization (graphs, trees, tables).
 - **Hierarchical Memory (3D):** Multi-layer structured organization with inter-layer links (pyramids, multi-layer graphs).
 - **Parametric Memory:** Information encoded within the model parameters. Subdivided into:
 - **Internal Parametric Memory:** Encoded within the original model weights.
 - **External Parametric Memory:** Stored in auxiliary parameter sets (e.g., adapters, LoRA modules).
 - **Latent Memory:** Implicitly carried in the model’s internal representations (e.g., KV cache, hidden states). Subdivided by origin:
 - **Generate:** Produced by independent models or modules.
 - **Reuse:** Directly carried over from prior computation.
 - **Transform:** Existing latent states are modified or compressed.

3. **Functions (Section 4): Why Agents Need Memory?**
 - This section explores the fundamental purpose and roles of agent memory, moving beyond coarse temporal distinctions. It proposes a finer-grained taxonomy:
 - **Factual Memory:** Declarative knowledge for consistency, coherence, and adaptability (e.g., explicit facts, user preferences, environment states). Subdivided into:
 - **User Factual Memory:** Sustains human-agent interaction consistency (identity, preferences, commitments).
 - **Environment Factual Memory:** Sustains consistency with the external world (documents, tools, other agents).
 - **Experiential Memory:** Procedural and strategic knowledge for continual learning and self-evolution (e.g., abstracting from past trajectories, failures, successes). Subdivided by abstraction level:
 - **Case-based Memory:** Stores raw historical episodes/solutions.
 - **Strategy-based Memory:** Distills transferable reasoning patterns/workflows.
 - **Skill-based Memory:** Encapsulates executable procedural capacities (code, APIs).
 - **Hybrid Memory:** Integrates multiple representations.
 - **Working Memory:** Capacity-limited, dynamically controlled scratchpad for active context management during a single task or session. Subdivided by interaction dynamics:
 - **Single-turn Working Memory:** Focuses on input condensation and abstraction within a single forward pass.
 - **Multi-turn Working Memory:** Addresses temporal state maintenance across sequential interactions.

4. **Dynamics (Section 5): How Memory Operates and Evolves?**
 - This section investigates the adaptive and evolutionary capabilities of agent memory systems, decomposing the memory lifecycle into three fundamental processes:
 - **Memory Formation:** Encoding raw contexts into compact knowledge. Subdivided into:
 - **Semantic Summarization:** Transforms lengthy data into high-level summaries.
 - **Knowledge Distillation:** Extracts specific cognitive assets (facts, strategies).
 - **Structured Construction:** Organizes data into explicit topological representations (graphs, trees).
 - **Latent Representation:** Encodes experiences into machine-native latent formats.
 - **Parametric Internalization:** Consolidates external memories directly into model weights.
 - **Memory Evolution:** Integrating newly formed memories with existing ones. Subdivided into:
 - **Consolidation:** Merges new and existing memories into generalized insights.
 - **Updating:** Resolves conflicts and revises knowledge.
 - **Forgetting:** Removes outdated, redundant, or low-value information.
 - **Memory Retrieval:** Accessing relevant and concise knowledge fragments. Subdivided into:
 - **Retrieval Timing and Intent:** Determines when and which memory store to query.
 - **Query Construction:** Transforms raw queries into effective retrieval signals.
 - **Retrieval Strategies:** Executes the search (lexical, semantic, graph-based, generative, hybrid).
 - **Post-Retrieval Processing:** Refines retrieved fragments (re-ranking, filtering, aggregation).

5. **Resources and Frameworks (Section 6):** The survey compiles a comprehensive list of representative benchmarks and open-source frameworks, supporting empirical research and practical development.

6. **Positions and Frontiers (Section 7):** This section articulates forward-looking perspectives, identifying emerging research directions and open challenges.

By meticulously breaking down agent memory into these interconnected dimensions, the authors provide a powerful analytical framework that facilitates a deeper understanding of the field's current state and its future trajectory.

### 4. Main Findings and Results

The core findings of this survey are presented through its comprehensive "Forms–Functions–Dynamics" taxonomy, which systematically organizes and analyzes the diverse landscape of agent memory research.

#### 4.1. Forms: What Carries Memory?

The survey identifies three primary forms of memory:
- **Token-level Memory:** This is the most prevalent form, storing explicit, discrete, and human-readable units. It is further categorized by its structural organization:
 - **Flat Memory (1D):** Simple accumulation of units (e.g., text chunks, dialogue logs, experience trajectories). Highly scalable and flexible for rapid updates but lacks explicit relational understanding. Used for dialogue, preference tracking, user profiles, and raw experience storage (e.g., MemGPT, Memento).
 - **Planar Memory (2D):** Introduces a single-layer topological structure (trees, graphs) to capture relational dependencies. Enhances structured reasoning and efficient retrieval beyond linear search. Examples include tree-structured conversation histories (MemTree) and knowledge graphs for entities and relations (A-Mem, M3-Agent).
 - **Hierarchical Memory (3D):** Organizes information across multiple layers of abstraction with inter-layer links. Supports multi-granularity representations (raw observations to high-level themes) and complex, multi-path queries. Examples include pyramid-like structures for tasks and knowledge graphs (HiAgent, G-Memory, HippoRAG).
- **Parametric Memory:** Information encoded directly within the model's weights. It leverages the model's inherent capacity for generalization.
 - **Internal Parametric Memory:** Direct modification of base model parameters, often via fine-tuning or model editing (e.g., Character-LM, ROME, MEND). Benefits from zero-latency access but suffers from high update costs and catastrophic forgetting.
 - **External Parametric Memory:** Memory stored in auxiliary parameter sets like adapters (LoRA modules). Offers modular updates and task-specific personalization without altering the base model (e.g., K-Adapter, WISE).
- **Latent Memory:** Implicitly carried in the model's internal representations (e.g., KV cache, hidden states). Offers efficiency and modality fusion.
 - **Generate:** Auxiliary models produce compact continuous states (e.g., gist tokens, summary vectors) to abstract long contexts (e.g., Gist, AutoCompressor, MemGen).
 - **Reuse:** Directly reuses the model's internal activations, primarily KV caches, as memory (e.g., Memorizing Transformers, SirLLM). Preserves fidelity but consumes significant resources.
 - **Transform:** Modifies or compresses existing latent states (e.g., KV caches) through selection or aggregation to reduce footprint while retaining essentials (e.g., Scissorhands, SnapKV).

#### 4.2. Functions: Why Agents Need Memory?

The survey proposes three primary functional roles for agent memory, moving beyond temporal distinctions:
- **Factual Memory:** Supports declarative knowledge about past events, users, and environment states, ensuring consistency and coherence.
 - **User Factual Memory:** Stores user-specific facts (identity, preferences) to maintain dialogue coherence and goal consistency over turns (e.g., MemGPT, MemoryBank, RMM).
 - **Environment Factual Memory:** Stores facts about the external world (documents, tools) for knowledge persistence and shared access in multi-agent systems (e.g., HippoRAG, MetaGPT, Generative Agent).
- **Experiential Memory:** Encapsulates procedural and strategic knowledge, enabling continual learning and self-evolution by abstracting from past interactions.
 - **Case-based Memory:** Stores raw trajectories and solutions as concrete exemplars for direct replay and evidence-driven learning (e.g., Memento, Expel).
 - **Strategy-based Memory:** Distills transferable reasoning patterns, workflows, and high-level insights to guide planning (e.g., Reflexion, AWM, ReasoningBank).
 - **Skill-based Memory:** Encapsulates executable procedural capacities, from code snippets to APIs, for tool use and modular capability expansion (e.g., Voyager, ToolLLM, Alita).
 - **Hybrid Memory:** Integrates multiple forms for balanced reasoning and execution (e.g., ExpeL, Agent KB).
- **Working Memory:** Manages active context within a single task or session under capacity constraints.
 - **Single-turn Working Memory:** Condenses and abstracts massive immediate inputs to maximize effective information payload (e.g., LLMLingua, AutoCompressors, VideoAgent).
 - **Multi-turn Working Memory:** Maintains temporal state and historical relevance across sequential interactions through state consolidation, hierarchical folding, and cognitive planning (e.g., MemAgent, HiAgent, KARMA).

#### 4.3. Dynamics: How Memory Operates and Evolves?

The survey details the active management of memory through three processes:
- **Memory Formation:** Encoding raw experiences into compact, reusable knowledge.
 - **Semantic Summarization:** Transforms raw data into high-level summaries (incremental or partitioned) (e.g., MemGPT, ReadAgent).
 - **Knowledge Distillation:** Extracts specific factual or experiential insights (e.g., TiM, Expel, Mem-α).
 - **Structured Construction:** Organizes data into explicit topological representations (knowledge graphs, trees) (e.g., GraphRAG, Zep, A-MEM).
 - **Latent Representation:** Encodes experiences directly into machine-native embeddings or KV states (e.g., MemoryLLM, CoMEM).
 - **Parametric Internalization:** Consolidates external memories directly into model parameters (e.g., MEND, ToolFormer).
- **Memory Evolution:** Integrating newly formed memories with existing ones, ensuring coherence, efficiency, and adaptability.
 - **Consolidation:** Merges new and existing memories to form generalized insights (local, cluster-level, global) (e.g., RMM, PREMem, AgentFold).
 - **Updating:** Revises or replaces existing memory to maintain factual consistency and adapt to changes (external memory updates, model editing) (e.g., Zep, Mem-α, ROME).
 - **Forgetting:** Deliberately removes outdated, redundant, or low-value information (time-based, frequency-based, importance-driven) (e.g., MemGPT, XMem, Livia).
- **Memory Retrieval:** Accessing relevant knowledge fragments at the right moment.
 - **Retrieval Timing and Intent:** Determines when and which memory source to query (automated by LLM or auxiliary modules) (e.g., MemGPT, ComoRAG, H-MEM).
 - **Query Construction:** Transforms raw queries into effective retrieval signals (decomposition into sub-queries, rewriting into hypothetical documents) (e.g., Visconde, HyDE).
 - **Retrieval Strategies:** Executes the search over the memory repository (lexical, semantic, graph, generative, hybrid methods) (e.g., TF-IDF, Sentence-BERT, HippoRAG).
 - **Post-Retrieval Processing:** Refines retrieved fragments (re-ranking, filtering, aggregation, compression) (e.g., RCR-Router, ComoRAG).

#### 4.4. Resources and Frameworks

The survey also compiles a comprehensive list of benchmarks (e.g., MemBench, LoCoMo, WebChoreArena, LongBench) designed for memory, lifelong learning, and self-evolving agents, as well as other relevant agent-oriented benchmarks. It also summarizes a rapidly growing ecosystem of open-source memory frameworks (e.g., MemGPT, Mem0, Zep, LangMem), indicating the increasing industrial and academic investment in this area.

### 5. Significance and Potential Impact

This survey holds significant implications for the future trajectory of AI agent research, positioning memory as a "first-class primitive" in the design of future agentic intelligence. Its comprehensive taxonomy, rigorous conceptual distinctions, and forward-looking analysis provide a much-needed foundation for a rapidly evolving and fragmented field.

The key significance and potential impact areas are:

1. **Conceptual Clarity and Unification:** By clearly defining agent memory and distinguishing it from related concepts like LLM memory, RAG, and context engineering, the survey provides a unified language and framework for researchers. This clarity will reduce ambiguity, facilitate more focused research, and enable better comparison of different memory systems.
2. **Structured Research Agenda:** The "Forms–Functions–Dynamics" taxonomy offers a systematic way to analyze and design agent memory systems. This structured approach helps researchers identify gaps in current knowledge, explore new combinations of memory types and functions, and develop more holistic memory architectures. It moves the field beyond ad-hoc designs towards principled engineering.
3. **Acceleration of Agent Development:** By summarizing existing benchmarks and open-source frameworks, the survey acts as a valuable resource for both researchers and practitioners. This consolidation of tools and evaluation methods will accelerate the development and empirical testing of new memory-augmented agents.
4. **Guiding Future Innovation:** The "Positions and Frontiers" section outlines critical emerging directions, providing a roadmap for future research:
 - **Memory Generation vs. Retrieval:** Shifting from merely retrieving stored information to actively synthesizing new, context-adaptive, and integrated memory representations will lead to more flexible and powerful memory systems.
 - **Automated Memory Management:** Moving from manually designed rules to autonomously managed and self-optimizing memory systems, possibly leveraging hierarchical and adaptive architectures, will enable agents to operate robustly in dynamic, open-ended environments.
 - **Reinforcement Learning Meets Agent Memory:** The increasing role of RL in internalizing memory management abilities—from selecting components to designing entire architectures—promises genuinely continual learning and long-term competence.
 - **Multimodal Memory:** As agents operate in embodied and interactive settings, developing omnimodal memory systems that integrate heterogeneous sensory inputs (visual, audio, text) will be crucial for holistic understanding and action.
 - **Shared Memory in Multi-Agent Systems:** Evolving shared memory from passive repositories to actively managed, agent-aware, and learning-driven collective representations will foster more sophisticated coordination and collective intelligence.
 - **Memory for World Models:** Memory's role in constructing high-fidelity, consistent, and interactive internal simulations of the world is critical for next-generation AI, moving from data caching to active state simulation.
 - **Trustworthy Memory:** Addressing privacy, explainability, and hallucination robustness will be paramount for real-world deployment, requiring mechanisms for granular permissions, verifiable forgetting, auditable updates, and causal tracing of memory's influence.
 - **Human-Cognitive Connections:** Drawing inspiration from biological memory processes, such as constructive memory and offline consolidation (sleep-like cycles), could lead to more efficient and robust learning mechanisms, bridging the gap between static storage and dynamic cognition in agents.

In essence, this survey does not just report on the state of the art; it actively shapes the future of agent memory research by providing a coherent intellectual framework and highlighting the most promising avenues for breakthroughs. It underscores that truly intelligent and autonomous agents will necessitate sophisticated, adaptive, and trustworthy memory systems that can learn, evolve, and reason over extended horizons.
