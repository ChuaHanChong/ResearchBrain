## Problem

- Standard feed-forward transformer architectures lack an inherent iterative structure, making them inefficient for emulating step-by-step algorithms like gradient descent.
- Direct solutions for some problems (e.g., linear regression) are computationally complex for transformers to learn in a single forward pass, potentially requiring many layers.
- The high parameter count of deep standard transformers for in-context learning poses efficiency challenges and limits deployment in resource-constrained environments.

## Method

- A ==single-layer looped transformer== (GPT-2 decoder) is repeatedly applied in a loop, with the original input ==additively injected== at each iteration to imbue the architecture with iterative processing capabilities.
- The looped transformer significantly reduces parameter count (**0.79M**) compared to a standard 12-layer transformer (**9.48M**) by reusing a single computational block.
- A specialized training methodology minimizes expected loss over a range of loop iterations with a ==truncated loss window==, encouraging performance improvement, convergence, and indefinite stability for fixed-point solutions.

## Results

- The looped transformer achieved comparable or superior in-context learning performance using **0.79 million** parameters, a **>90%** reduction compared to a standard 12-layer transformer (**9.48 million** parameters).
