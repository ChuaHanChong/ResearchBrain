# ATLAS: Agentic or Latent Visual Reasoning? One Word is Enough for Both

> [!summary] Summary
> ATLAS is a visual reasoning framework that integrates discrete 'functional tokens' into autoregressive Vision-Language Models, enabling them to represent and execute visual operations within a standard generation loop. This method allows models to perform complex interleaved visual reasoning more efficiently and interpretably than prior approaches, leading to improved performance on benchmarks like WeMath and BLINK.

## Problem

- Existing Vision-Language Models (VLMs) face challenges in performing multi-step, interleaved visual reasoning that necessitates dynamic manipulation of visual inputs.
- Current methods for interleaved visual reasoning are often computationally expensive (e.g., generating pixel-level images), introduce high latency due to verbose operations (e.g., tool calls), or lack compatibility with scalable training architectures.
- Reinforcement learning for visual reasoning in VLMs suffers from 'gradient dilution,' where sparse but critical functional tokens receive insufficient optimization.

## Method

- The **ATLAS** framework extends autoregressive Vision-Language Models by incorporating ==discrete functional tokens== (e.g., `<|Shape|>`, `<|Line|>`) directly into the vocabulary, allowing visual operations to be represented within the standard sequence generation.
- A two-stage training process combines ==Supervised Fine-Tuning== on the ==ATLAS-178K dataset== (curated from visual-code data and LLM-polished reasoning trajectories) with ==Reinforcement Learning== using a composite reward function.
- ==Latent-Anchored GRPO (LA-GRPO)== is introduced, which adds a ==token-level auxiliary loss== specifically for functional tokens during RL, mitigating ==gradient dilution== and stabilizing their optimization.

## Results

- ATLAS-LA-GRPO achieved an average score of **51.3%** on the BLINK benchmark and **45.0%** on WeMath, demonstrating substantial improvements over the baseline VLM and competitive performance against other state-of-the-art models.
- The framework significantly improved efficiency, reducing inference latency by approximately **80%** (from **18.83s to 3.80s**) and peak memory usage by **44%** (from **2.55GB to 1.43GB**) on the BLINK-Jigsaw benchmark compared to agentic methods.
- Qualitative analysis confirmed that ATLAS intelligently invokes functional tokens at relevant reasoning steps, with visual attention patterns aligning with the intended visual operations.

## Takeaways

> [!tip] Key Insights
> - Complex visual manipulation and reasoning steps can be compactly represented by a small set of discrete 'functional tokens' within the language model's vocabulary, avoiding computationally expensive image generation or verbose external tool calls.
> - Integrating functional tokens directly into the autoregressive generation loop allows for seamless compatibility with standard, scalable VLM training and inference pipelines without requiring architectural changes or recurrent dependencies.
> - A specialized reinforcement learning approach, Latent-Anchored GRPO, is essential for providing stable and sufficient learning signals to sparse functional tokens, overcoming the 'gradient dilution' issue and enhancing their effective invocation.
