# Learning to Evolve: Multi-modal Interactive Fields for Robust Humanoid Navigation in Dynamic Environments

> [!summary] Summary
> The Multi-modal Interactive Field (MIF) framework enables humanoid robots to safely navigate and interact in dynamic environments by addressing locomotion-induced perceptual distortions and map-reality mismatches. It achieved 94% success in interaction pose safety with no observed collisions and robustly adapted to object changes with up to 98% success, significantly outperforming prior methods.

## Problem

- Humanoid robots' bipedal locomotion causes torso oscillations and viewpoint shifts, leading to noisy egocentric RGB-D observations that degrade semantic grounding and geometric accuracy in scene maps.
- Existing semantic mapping systems assume static environments, failing when objects are relocated, removed, or added, which leads to unsafe navigation and incorrect interaction plans.

## Method

- A Multi-modal Interactive Field (**MIF**) framework integrating Appearance, Spatial, and Geometry fields within a closed-loop perception-adaptation pipeline.
- Confidence-aware Semantic 3D ==Gaussian Splatting== (Appearance Field) augmented with a confidence scalar to suppress gait-induced blur and distill open-vocabulary features from stabilized views.
- A discrepancy-triggered local map update mechanism (Spatial Field) for constructing hierarchical scene graphs and adapting topological memory to persistent scene changes without full re-mapping.
- An on-demand high-fidelity object geometry recovery module (Geometry Field) that actively selects optimal views and uses conditional ==Flow Matching== to generate watertight 3D meshes for Interaction Pose Safety (IPS) verification.

## Results

- MIF achieved **92%** semantic localization success with a 0.18m Mean Distance Error and maintained higher image quality (e.g., PSNR 29.8, SSIM 0.89 for fast walking) compared to baseline 3DGS methods.
- The system demonstrated **94%** Interaction Pose Safety (IPS) success with **0%** observed collisions, significantly outperforming point cloud (**62%** IPS, **32%** collision) and static mesh (**78%** IPS, **14%** collision) baselines.
- MIF adapted to object relocations, removals, and additions with up to **98%** task success, substantially surpassing existing scene graph methods (e.g., HOV-SG at 10-**12%** for removal/relocation).
- The discrepancy-triggered adaptation mechanism achieved a **95.1%** True Positive Rate in detecting persistent scene changes and operated efficiently with a 1.6s latency and under 4GB VRAM usage.

## Takeaways

> [!tip] Key Insights
> - Explicitly modeling and suppressing uncertainty in 3D Gaussian Splatting due to humanoid gait effectively maintains semantic and geometric integrity, mitigating locomotion-induced noise.
> - Locally updating scene graphs based on detected inconsistencies between map and reality allows for efficient adaptation in dynamic environments, which is crucial for continuous robot operation.
> - Integrating perception with a comprehensive Interaction Pose Safety (IPS) criterion, supported by on-demand, high-fidelity geometry recovery, is vital for ensuring physically safe and feasible manipulation actions for humanoids.
