# Automated Design of Agentic Systems

> [!summary] Summary
> Meta Agent Search frames Automated Design of Agentic Systems as search in code space: a foundation-model meta agent iteratively writes the forward function of a new agent, self-reflects for novelty and errors, evaluates it, and appends it to a growing archive that conditions the next design. Discovered agents beat state-of-the-art hand-designed agents across coding, math, reading and science, and transfer across domains and models.

## Problem

- Agentic building blocks like chain-of-thought, reflection, memory and tool use are hand-crafted, needing domain-specific tuning and heavy researcher effort to combine into working systems.
- Most prior automated attempts mutate only text prompts, leaving workflow, tool use and control flow fixed, so whole classes of agent designs cannot be represented at all.
- Works searching graphs or feed-forward node networks still freeze components such as tool usage, and their custom search spaces lack the coding priors foundation models already have.

## Method

- **ADAS** formulation: any agent-design method decomposes into ==search space==, ==search algorithm== and ==evaluation function==; the paper argues for ==Turing-complete code== as the search space.
- **Meta Agent Search**: a meta agent conditioned on an archive emits an idea plus a Python ==forward function==, passes two ==novelty self-reflections==, then up to five ==error-refinement reflections==.
- A ~100-line framework supplies ==foundation-model query== and ==prompt-formatting primitives==, so the meta agent writes only forward; validated agents plus their scores re-enter the archive as ==stepping stones==.

## Results

- Across four benchmarks the discovered agents win every domain: DROP **79.4** F1 versus **65.8** best baseline, MGSM **53.4%** versus **39.0%**, MMLU **69.6%**, GPQA **34.6%**, all above prompt optimization.
- Agents searched on MGSM transfer to held-out math, reaching **69.5%** on GSM8K and **31.2%** on GSM-Hard, gains of **25.9%** and **13.2%** over the strongest hand-designed baselines.
- On ARC, search over **25** iterations lifts held-out accuracy to **13.7%** with GPT-3.5; transferring the top agents raises GPT-4 to **37.0%** and Claude-Sonnet to **48.3%**.

## Takeaways

> [!tip] Key Insights
> - Making the search space executable code rather than prompts or graphs lets one method invent prompts, workflows and tool use together, exploiting the model's coding prior.
> - An archive of past designs supplies stepping stones: strong mechanisms emerge by recombining earlier low-scoring ideas, so intermediate failures still carry search value.
> - Gains concentrate where the model already knows enough and errs by hallucination or arithmetic; on graduate-level science, better orchestration cannot substitute for missing knowledge.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This research is situated at the intersection of several rapidly evolving fields in AI: **Large Language Models (LLMs)**, **Agentic Systems**, and **Meta-Learning/Automated AI Design (AI-Generating Algorithms, AutoML)**.

The current landscape of LLM applications is increasingly moving beyond single-query interactions to **compound agentic systems**. Researchers are developing sophisticated architectures that combine LLMs with various modules for planning, reasoning (e.g., Chain-of-Thought, Self-Reflection), memory (e.g., RAG), and tool use (e.g., Toolformer). However, the design of these complex agentic systems often involves significant manual effort, domain-specific tuning, and heuristic combinations of building blocks.

The paper argues that this manual design paradigm is inherently limited and, drawing parallels with the history of machine learning, posits that **learned solutions will eventually supersede hand-designed ones**. This "bitter lesson" has been demonstrated in areas like computer vision (where hand-designed features like HOG were replaced by learned features in CNNs) and neural network architecture design (Neural Architecture Search, NAS, outperforming manual designs). More recently, **AI-Generating Algorithms (AI-GAs)** and **AutoML** have shown the power of automating various aspects of AI system creation, such as generating training environments, discovering optimization algorithms, or even programming loss functions.

Against this backdrop, the authors introduce **Automated Design of Agentic Systems (ADAS)** as a new research area. ADAS aims to apply the principles of automated AI design to the specific challenge of creating agentic systems. While some prior works have explored automated prompt optimization (e.g., PromptBreeder, OPRO) or learning specific components like workflows (e.g., DyLAN, GPT-Swarm), these approaches often limit the search space (e.g., only prompts, or fixed workflow structures) or fail to integrate all components flexibly.

This paper distinguishes itself by proposing that the **entire agentic system can be defined and searched for in code**. This is a critical differentiator because programming languages are Turing Complete, meaning they can theoretically represent *any* possible computational process, including novel prompts, tool use, workflows, and their arbitrary combinations. This broad search space, combined with the increasing proficiency of LLMs in code generation (as seen in works like FunSearch, Eureka, and OMNI-EPIC), creates a powerful new paradigm for ADAS. By framing agents in code, the work leverages existing LLM strengths and provides a more interpretable and extensible design space than other more constrained representations.

### 2. Key Objectives and Motivation

The primary objective of this research is to address the significant manual effort and domain-specific tuning currently required to design and combine the various building blocks of powerful, general-purpose agentic systems. The authors are motivated by a core hypothesis derived from the history of machine learning: hand-designed solutions are invariably replaced by learned, automated solutions as computational resources and data increase.

Specifically, the key objectives and motivations are:

1. **Automate Agent Design:** To establish and explore a new research area, Automated Design of Agentic Systems (ADAS), which aims to automatically invent novel building blocks and design powerful agentic systems without extensive human intervention.
2. **Overcome Limitations of Manual Design:** To demonstrate that automated methods can transcend the limitations of human intuition and effort in discovering optimal agent configurations, potentially leading to more effective and efficient solutions than manual approaches.
3. **Propose a Generalizable Search Space:** To introduce and validate the idea that defining agentic systems entirely in code provides a theoretically boundless and highly flexible search space, capable of representing any possible agentic design, unlike existing prompt-centric or fixed-workflow ADAS attempts. This approach leverages the Turing Completeness of programming languages.
4. **Leverage LLMs for Meta-Programming:** To show that modern Foundation Models, given their increasing proficiency in code generation, can act as "meta agents" to program, evaluate, and iteratively improve new agent designs in code, thus automating the discovery process.
5. **Develop a Simple, Effective Algorithm:** To present a concrete algorithm, "Meta Agent Search," as an initial proof-of-concept for the code-based ADAS paradigm, demonstrating its viability and potential to outperform state-of-the-art hand-designed agents across various tasks and domains.
6. **Assess Robustness and Generality:** To thoroughly evaluate whether agents discovered through this automated process exhibit strong generalization capabilities and transferability across different domains and underlying Foundation Models.

In essence, the motivation is to "learn to learn" for agentic systems, accelerating the development of highly capable AI by automating the design process itself, rather than continuing to rely on labor-intensive, human-centric engineering.

### 3. Methodology and Approach

The authors formulate Automated Design of Agentic Systems (ADAS) as an **optimization process** comprising three fundamental components: a Search Space, a Search Algorithm, and an Evaluation Function.

1. **Search Space:**
 - **Definition in Code:** A cornerstone of their approach is defining the *entire* agentic system in code, specifically Python. This is a crucial departure from prior ADAS efforts that typically focused on optimizing prompts or fixed-structure workflows. By leveraging the Turing completeness of programming languages, this approach allows for the theoretical discovery of *any* possible agentic system, including novel prompts, tool use, complex workflows, and arbitrary combinations thereof.
 - **Framework:** To facilitate this, they provide a lightweight framework (under 100 lines of code) that gives the meta agent basic functionalities, such as querying Foundation Models (FMs) and formatting prompts. Within this framework, agents are defined by implementing a `forward` function that takes task information and outputs the agent's response. This mirrors practices in other code-generating AI-GA works like FunSearch.

2. **Search Algorithm: Meta Agent Search**
 - **Iterative Design:** The core idea is an iterative process where a "meta agent" (a powerful LLM, specifically GPT-4) programs new agents.
 - **Initialization:** The archive of discovered agents is optionally initialized with existing state-of-the-art hand-designed baselines (e.g., Chain-of-Thought, Self-Refine). The paper also experiments with empty initialization.
 - **Design Phase:** In each iteration, conditioned on the current archive of previously discovered agents and their performance, the meta agent designs a new agent. This involves:
 - Generating a high-level description of the new agentic system idea.
 - Implementing this idea in Python code.
 - **Self-Reflection and Refinement:** The generated design undergoes two rounds of self-reflection by the meta agent itself. This step aims to ensure novelty (by comparing to the archive) and to fix potential implementation mistakes. If runtime errors occur during evaluation, the meta agent performs additional self-reflection (up to five times) to debug and refine the code.
 - **Archive Integration:** After evaluation, the newly designed (and potentially refined) agent, along with its performance metrics, is added to the growing archive. This archive serves as a knowledge base, providing "stepping stones" for the meta agent to inform subsequent iterations, encouraging the exploration of "interesting" (novel or worthwhile) agents.

3. **Evaluation Function:**
 - **Performance Metrics:** The primary objective for optimization is the agent's performance, measured by standard metrics like accuracy rate or F1 score on validation data from the target domain.
 - **Cost Efficiency:** While the meta agent uses a powerful model (GPT-4), the discovered agents and baselines are evaluated using a more cost-effective model (GPT-3.5) to manage computational expenses.

The methodology essentially creates an automated discovery loop: propose an agent design (in code) -> test its performance -> learn from the outcome -> propose an even better agent design. This mimics a research cycle but is fully automated by the meta agent.

### 4. Main Findings and Results

The extensive experiments conducted across multiple domains consistently demonstrate the superior performance and generalizability of agents discovered by Meta Agent Search compared to state-of-the-art hand-designed baselines.

1. **Overall Performance:**
 - Across all tested domains (ARC, Reading Comprehension, Math, Multi-task, Science), Meta Agent Search discovers agents that substantially outperform conventional hand-designed solutions.

2. **Case Study: ARC Challenge (Abstraction and Reasoning Corpus):**
 - **Progressive Innovation:** The algorithm progressively discovers high-performance agents over iterations. It shows an "evolutionary" process where initial ideas (e.g., multi-Chain-of-Thought, refinement, ensembling) become "stepping stones" that later, more complex, and effective designs build upon. For example, the best-discovered agent incorporates a sophisticated feedback mechanism with multiple critics (e.g., Efficiency Expert, Readability Expert, Simplicity Expert) and human-like feedback, which emerged from combining earlier innovations.
 - **Outperformance:** Discovered agents significantly outperform baselines such as Chain-of-Thought, Self-Consistency, Self-Refine, LLM Debate, and Quality-Diversity on the challenging ARC task.

3. **Reasoning and Problem-Solving Domains (DROP, MGSM, MMLU, GPQA):**
 - **Substantial Gains:** Meta Agent Search achieved remarkable improvements in F1 scores for Reading Comprehension (DROP) by 13.6 points and accuracy rates for Math (MGSM) by 14.4 percentage points, highlighting its effectiveness in domains where LLMs have sufficient knowledge and errors are primarily due to reasoning or calculation mistakes.
 - **Consistent Outperformance:** Even in more knowledge-intensive domains like Multi-task (MMLU) and Science (GPQA), where LLM knowledge limitations might cap potential improvements, Meta Agent Search still outperformed baselines, albeit with smaller margins.
 - **Superior to Prompt Optimization:** Crucially, the code-based approach of Meta Agent Search consistently outperformed prompt-optimization methods (like OPRO), validating the advantage of learning across all agent components rather than just the prompt text.

4. **Generalization and Transferability:**
 - **Within-Domain Transfer:** Agents discovered in the Math (MGSM) domain showed strong transferability to other held-out math benchmarks (GSM8K, GSM-Hard, SVAMP, ASDiv), leading to substantial accuracy improvements (e.g., 25.9% on GSM8K and 13.2% on GSM-Hard) compared to baselines. This demonstrates the robustness of the discovered math-specific reasoning patterns.
 - **Cross-Domain Transfer:** Surprisingly, agents discovered in the math domain also transferred effectively to *non-math* domains (Reading Comprehension and Multi-task). While not matching agents specifically optimized for those domains, they still outperformed or matched state-of-the-art hand-designed baselines, indicating that the learned design patterns encode general problem-solving strategies.
 - **Cross-Model Transfer:** Agents discovered using GPT-3.5 on ARC maintained their superior performance when transferred to more powerful and different FMs like Claude-Haiku, GPT-4, and Claude-Sonnet. This highlights the generality and robustness of the *agentic system designs* themselves, independent of the specific underlying FM.
 - **Insights into FMs:** The transfer experiments also provided insights: GPT-3.5 benefited most from complex feedback mechanisms, while more advanced models (GPT-4, Claude-Sonnet) performed better with simpler feedback coupled with more refinement iterations, suggesting differences in their internal evaluative and refinement capabilities.

5. **Impact of Initialization:**
 - Experiments with empty initialization (no human-designed baselines at the start) showed that Meta Agent Search could still discover agents outperforming all hand-crafted baselines. This underscores the power of the code-space search.
 - Interestingly, for the math domain, starting from scratch led to even *superior* performance than with initialization, hypothesized to be due to broader exploration of diverse reasoning strategies without being confined by initial human-designed patterns.

Overall, the findings strongly support the central premise: automated design, particularly when agents are defined in code, can lead to the discovery of highly effective, novel, and generalizable agentic systems that surpass human-engineered counterparts.

### 5. Significance and Potential Impact

This work introduces **Automated Design of Agentic Systems (ADAS)** as a significant and promising new research frontier, with profound implications for the future of AI development.

1. **Accelerating AI Development and AGI:** By automating the design and discovery of agentic systems, ADAS has the potential to drastically accelerate the pace of AI research and development. It moves towards a paradigm where AI can build and improve itself, potentially leading to faster progress towards Artificial General Intelligence (AGI) than manual approaches. This echoes Jeff Clune's vision for AI-Generating Algorithms.
2. **Beyond Human Intuition:** The results demonstrate that automated search can uncover novel design patterns and combinations that might not be intuitively obvious or easily discoverable by human researchers. The emergence of complex feedback mechanisms and the surprising cross-domain transferability highlight this "beyond human intuition" discovery capability.
3. **Enhanced Generality and Robustness:** The consistent outperformance and strong transferability of discovered agents across different tasks, domains, and even underlying Foundation Models signify that ADAS can yield more general and robust AI systems. This is critical for deploying agents in diverse real-world applications where adaptability is key.
4. **Cost Efficiency in the Long Run:** While current computational costs are noted, the paper suggests future optimizations (e.g., cheaper LLMs, smarter evaluation functions) will make ADAS a more efficient path to creating powerful agents than continuous manual development.
5. **Interpretability and Safety Considerations:** A key advantage of the "code space" approach is that the resulting agents are defined in human-readable code. This inherent interpretability can lead to more controllable and auditable AI systems, which is a crucial safety benefit. The authors acknowledge the broader safety concerns of powerful self-improving AI and emphasize the importance of developing "safe-ADAS algorithms" (e.g., incorporating Constitutional AI principles) to ensure alignment with human values. The paper argues that revealing the accessibility of powerful ADAS algorithms (even without expensive hardware) is a net benefit, informing the community and fostering proactive safety research.
6. **Scientific Insights into FMs:** Observing how the meta agent designs agents and how these agents perform across different FMs can provide deeper scientific insights into the capabilities and limitations of the Foundation Models themselves. For instance, the differing optimal feedback mechanisms for GPT-3.5 versus more advanced models illustrate this point.
7. **Broader Implications for Emergent Complexity:** The paper provocatively suggests that studying ADAS could shed light on how complexity emerges in human organizations, given the analogy between agentic systems and human societal structures.

**Future Work Directions:** The paper concludes by outlining several exciting avenues for future research, including:
- **Higher-order ADAS:** Automating the improvement of the meta agent itself.
- **Online Continual Learning:** Enabling agents to continuously improve post-deployment.
- **Multi-objective ADAS:** Optimizing for factors beyond performance, such as cost, latency, and robustness.
- **More Complex Domains:** Applying ADAS to real-world, multi-step interactive environments.
- **Enriching the Search Space:** Seeding the meta agent with more existing tools (e.g., RAG, LangChain components, multimodal capabilities).
- **Advanced Search Algorithms:** Incorporating sophisticated techniques from Quality-Diversity and open-ended evolution.
- **Intelligent Evaluation Functions:** Moving beyond simple numerical performance to analyze detailed logs for richer debugging information and to handle subjective tasks.

In summary, "Automated Design of Agentic Systems" introduces a paradigm shift in how AI agents are developed. By automating the creation of agents themselves through meta-programming in code, the research opens doors to unprecedented levels of performance, generality, and efficiency in AI system design, while simultaneously providing a structured framework for addressing critical safety considerations.
