# Learning Coordinated Bimanual Manipulation Policies using State Diffusion and Inverse Dynamics Models

> [!summary] Summary
> Researchers from the University of Illinois at Urbana-Champaign developed a framework for coordinated bimanual robotic manipulation that explicitly disentangles state prediction using a diffusion model from inverse dynamics modeling. This approach, which models how object states evolve and then computes actions to achieve those states, achieved higher success rates and better generalization in complex simulated and real-world bimanual tasks involving deformable and multiple objects.

## Problem

- Learning coordinated robotic policies for bimanual manipulation, particularly for tasks involving deformable or multiple objects, remains challenging due to difficulties in cooperative force distribution and intricate spatial planning.
- Current imitation learning methods often struggle to generalize to multimodal goal configurations or unseen interactions, and may not fully capture complex object dynamics.
- Robots lack the ability to accurately predict how objects will move or interact under their actions, which is essential for planning long-horizon, precise manipulations.

## Method

- A novel imitation learning framework is proposed that explicitly disentangles state prediction from inverse dynamics modeling.
- A Denoising Diffusion Probabilistic Model (DDPM) is used to predict future object states, learning how the world evolves from historical observations.
- An inverse dynamics model, implemented as a multi-layer perceptron (MLP), translates the predicted future states into precise robot actions, with both components jointly optimized using human demonstration data.

## Results

- The framework achieved superior success rates in simulation (e.g., 29.3% in Franka Kitchen vs. baselines, 79.3% in Push-L), and demonstrated enhanced data efficiency compared to state-of-the-art imitation learning methods.
- It exhibited robust zero-shot sim-to-real transfer for 2D pushing and outperformed baselines in complex 3D bimanual real-world tasks involving deformable and multiple objects (e.g., 15/15 for Laundry Cleanup's first pillow vs. 0/15 for baseline on second pillow).
- The policy showed improved generalization, adaptability to out-of-distribution initial conditions, and robustness to human perturbations, indicating the synthesis of complex, emergent behaviors.

## Takeaways

> [!tip] Key Insights
> - Explicitly modeling object movement via a state prediction diffusion model provides a robust feedback mechanism, directly signaling coordination failures more effectively than action-based losses.
> - Disentangling state prediction from inverse dynamics allows for a deeper understanding of object behavior and enables more effective learning of bimanual coordination policies.
> - Anticipating future object states, mirroring human cognitive processes, is crucial for achieving stable and precise bimanual control in complex manipulation tasks.
