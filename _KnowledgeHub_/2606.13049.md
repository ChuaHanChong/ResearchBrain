# Y-BotFrame: An Extensible Embodied Agent Framework for Quadruped Robot Assistants

> [!summary] Summary
> Researchers from Xidian University developed Y-BotFrame, an extensible embodied agent framework for quadruped robots that integrates multimodal perception and an LLM-based cognitive core. This framework translates natural language instructions into robot actions, supporting intuitive human-robot interaction and a modular, distributed system design for deploying general-purpose intelligent ground assistants.

## Problem

- Existing intelligent systems for highly mobile quadruped robots are specialized (e.g., path planning, locomotion control, task-specific policies), lacking the generality and adaptability for diverse, real-world assistance tasks.
- Current end-to-end vision-language-action (VLA) models for robots are heavily dependent on specific task distributions and extensive training data, limiting their extensibility, interpretability, and stable deployment in open, dynamic environments.
- The lack of intuitive and efficient human-robot interaction paradigms, beyond traditional remote controllers, hinders seamless collaboration and accessibility for general users.

## Method

- A ==hierarchical== and modular framework (**Y-BotFrame**) was designed, decoupling a large language model (LLM) for high-level cognitive planning from low-level robot execution modules.
- An LLM-based task planner translates natural language instructions into sequences of executable actions by selecting and invoking modules from a 'Tool Factory' of defined robot capabilities, ensuring contextual consistency with historical interactions.
- The 'Tool Factory' organizes the quadruped's functionalities into standardized modules for speech interaction, autonomous navigation (including online mapping and path planning), and embodied question answering, each with clear interfaces.

## Results

- Successfully integrated multimodal perception, combining speech, vision (RGB observations), and LiDAR data to enable comprehensive environmental understanding.
- Implemented an LLM-centric cognitive core capable of understanding natural language instructions, contextual reasoning, and translating high-level commands into executable robot action plans.
- Demonstrated functional modules for speech interaction (ASR, TTS, LLM-based dialogue), autonomous navigation (LiDAR/GNSS/IMU fusion, A* path planning, online mapping), and embodied question answering (multi-view RGB scene description with Qwen3-VL-Flash and LLM reasoning).

## Takeaways

> [!tip] Key Insights
> - The hierarchical decoupling of the cognitive LLM from encapsulated execution modules enhances the system's interpretability, extensibility, and stability, overcoming limitations of monolithic end-to-end approaches.
> - Standardizing robot capabilities into 'plug-and-play' modules with well-defined interfaces facilitates modular upgrades and iterative development, allowing for easy integration of new functionalities.
> - A distributed system infrastructure, offloading computationally intensive tasks to a remote server, reduces onboard computational load on the robot, improving deployment flexibility and operational efficiency.
