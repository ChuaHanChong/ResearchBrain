# Self-Reference in Large Language Models: The Introspection Threshold for Recursive Self-Improvement

> [!summary] Summary
> This position paper argues sustainable recursive self-improvement in LLMs requires introspection: the capacity to simulate and evaluate one's own code. Using Kleene's Second Recursion Theorem, it constructs an introspective self-improvement program (ISIP) and proves completeness of self-modification, necessity of a reflective description/body architecture, undecidability of improvement, and rewrite-equivalence with Schmidhuber's Gödel machine. A survey finds current LLMs only quasi-introspective.

## Problem

- Self-refinement loops such as Self-Refine and Reflexion saturate within a few iterations; without external ground-truth feedback, LLMs often degrade after self-revision.
- Practical Gödel-machine descendants abandon formal proof verification for external benchmarks and human-engineered criteria, so improvement stays tethered to outside scaffolding.
- Model collapse degrades successive generations trained on synthetic output, an orthogonal bottleneck; prior work offers no formal account of why self-improvement saturates.

## Method

- Introspective self-improvement program (**ISIP**): apply ==Kleene's Second Recursion Theorem== to the composite operator M∘V∘f_T (bounded ==T-step self-simulator==, evaluator, modifier) yielding ==fixed-point code== that evaluates and rewrites itself.
- ==Standard-form reflective architecture== mapping von Neumann's ==constructor/copier/controller== onto a universal simulator, a copier-feeder, a supervisor, plus a generative description of the whole body.
- Four functional criteria (==self-modeling==, ==self-simulation==, ==self-evaluation==, ==self-modification==) plus ==reflexivity== and ==recurrent-processing structural criteria==, used as a rubric to audit current LLMs.

## Results

- Completeness Theorem A1: from a standard-form ISIP every source code is reachable by a finite viable trajectory; kernel, parameter block and payload are all rewritable, none immune.
- Necessity Theorem A2 plus Theorem A3: complete directed self-modification forces the description/body/interpreter form, while Rice's theorem makes any nontrivial improvement predicate undecidable; Theorems A4-A5 transfer Gödel-machine global optimality.
- Survey scores current LLMs partial on self-modeling, weak on self-simulation, unreliable on self-evaluation, shallow on self-modification; one study across **21** LLMs finds no privileged self-access.

## Takeaways

> [!tip] Key Insights
> - Any system that can rewrite every part of itself cannot hold a safety invariant internally; hard constraints must sit outside the program's write perimeter.
> - Bounded simulation horizons are not engineering shortcuts but necessary: unbounded evaluation of improvement is undecidable, so self-trust must stay approximate and finite.
> - Log-precision feedforward Transformers sit in uniform TC^0 per pass; chain-of-thought recurrence iterates over tokens, not weights, so it cannot substitute for mechanistic self-simulation.

## Detailed Report

### 1. Overview

Many current AI self-improvement loops alter prompts, strategies, memory, or code, but they often remain dependent on external evaluation. A more ambitious prospect is a system that can improve the mechanism that does the improving. The authors argue that this requires the system to model, test, evaluate, and modify its own operation. They call the requirement an "introspection threshold": a system cannot autonomously improve itself in a fully directed, recursive way unless it can build and use an adequate model of its own operation.

They construct such a loop in a formal program model. They frame the threshold as a functional analogue of von Neumann's self-reproduction threshold, not as a measured complexity score or a universal scalar for LLMs. The analogy and formal construction are distinct from evidence that any current LLM implements the construction.

The authors' proposed formal construction. Source code $\omega$ goes to $f^{T}$ (simulation for ≤T steps), then to V (evaluation), then to M (modification), which yields new source code $\omega'$. Below, $S_{0} \to S_{1} \to S_{2} \to \dots \to S_{n}$, with each program outputting a successor. This is a schematic, not observed model behavior or evidence of improving scores.

### 2. A self-model that can edit itself

In this paper, "introspection" means more than a model talking about itself. The authors define functional introspection through four linked abilities:

- model one's own computational process
- run that model on hypothetical inputs to predict behavior
- compare predictions with actual outcomes to find discrepancies
- modify operation to reduce those discrepancies

The formal program carries out these steps in order. It retrieves its own description and runs a bounded simulation of itself. It then evaluates what happened, modifies its own source, and produces a successor program. The simulator is limited to a finite horizon **T**. The evaluator **V** and modifier **M** must be total computable functions over that horizon, so the construction can use Kleene's Second Recursion Theorem. The output is a successor program, not a demonstrated increase in capability.

The authors prove two formal results:

- **Reachability.** Within the stated standard-form program model, every source code is reachable through a finite viable modification trajectory.
- **Necessity.** A reflective architecture is necessary for complete directed self-modification under self-containment and directedness assumptions.

Neither result proves that an LLM has this architecture. Neither proves that any chosen evaluator and modifier will produce monotonically better performance. Empirical improvement depends on the evaluator, modifier, objective, and viability conditions.

### 3. The evidence is about fragments, not a threshold test

The paper reports no new data. Its evidence about current LLMs comes from a literature review organized around the four criteria, not from a controlled experiment of the formal framework. The strongest conclusion is qualified. The reviewed evidence suggests fragmentary "quasi-introspection," but does not establish complete introspection in current LLMs.

The debate over privileged self-access shows why the question stays open. Binder et al. found that a model predicted its own held-out behavior better than an externally trained baseline, a result favoring privileged access. Song et al. compared implicit string probabilities with explicit self-reports across **21 LLMs**. They attributed the alignments to global model similarity rather than privileged self-access. Neither finding establishes the paper's four-part definition of complete introspection.

As their architectural assessment, not a theorem about deployed models, the authors emphasize three candidate bottlenecks:

- incomplete access to the system being changed
- limits on iterative self-simulation
- self-reports without causal grounding

### 4. What the paper establishes

The paper contributes a formal construction and a literature review, not a new benchmark result. It specifies a stronger capacity than describing oneself in words: predicting and directing changes to one's own machinery. Its review suggests current systems have not been shown to satisfy that standard. The threshold remains a proposed functional conjecture, not a universal scalar metric for LLMs. Two questions remain open: whether the proposed threshold is sharp, and what minimum architecture could cross it.
