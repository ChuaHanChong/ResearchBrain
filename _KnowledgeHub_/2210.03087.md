# Iterative Vision-and-Language Navigation

> [!summary] Summary
> The paper introduces the Iterative Vision-and-Language Navigation (IVLN) paradigm and its associated IR2R and IR2R-CE benchmarks, which evaluate language-guided agents in persistent environments across sequences of tasks. It demonstrates that agents utilizing structured semantic map memory can effectively leverage information from previous episodes to improve navigation, unlike those relying on unstructured implicit memory.

## Problem

- Existing Vision-and-Language Navigation (VLN) benchmarks operate on an "episodic" paradigm, where agents reset their memory for each new instruction, failing to simulate real-world robotic deployment.
- Physical robots function in persistent environments, continuously building maps and learning from past experiences, a capability not evaluated by current VLN benchmarks.
- Current VLN paradigms do not incentivize agents to retain and utilize long-term memory or semantic knowledge acquired across sequential tasks within the same environment.

## Method

- Introduces the **Iterative Vision-and-Language Navigation (IVLN)** paradigm, where agents navigate ==tours== (sequences of multiple instruction-following episodes) within the same ==persistent 3D environment==.
- Develops two new benchmarks, **IR2R** (discrete) and **IR2R-CE** (continuous), derived from existing VLN datasets, which provide structured tours for evaluating persistent agents.
- Proposes ==tour normalized Dynamic Time Warping (t-nDTW)== as a new metric to evaluate agent performance across an entire tour, accounting for cumulative success and path efficiency.

## Results

- Unstructured memory agents (TourHAMT on IR2R) showed a significant performance degradation, with `t-nDTW` dropping from **50%** (episodic) to **28%** on Val-Unseen, indicating their inability to leverage tour information.
- Map-based agents (MAP-CMA on IR2R-CE) consistently outperformed unstructured models, achieving a `t-nDTW` of **47-48%** on Val-Unseen, a **9 percentage point** improvement over the best unstructured CMA models (**~38%**).
- Agents evaluated with iteratively-updated maps consistently performed better (**3-4%** `t-nDTW` increase) than those with episodically reset maps, demonstrating the practical benefit of long-term spatial memory.

## Takeaways

> [!tip] Key Insights
> - Naive extensions of unstructured latent memory (e.g., HAMT, CMA) fail to effectively utilize long-term tour information, often degrading performance or offering no benefit.
> - Structured semantic map memory, when iteratively updated, allows agents to leverage prior environmental experience for improved navigation performance.
> - The process of building maps through exploration might be crucial for agent learning, as pre-computed known maps did not consistently outperform iteratively-built maps.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The paper addresses a critical disparity between current Vision-and-Language Navigation (VLN) benchmarks and the practical requirements of deployed robotic systems.

**Current VLN Landscape:**
Existing VLN benchmarks, such as Room-to-Room (R2R) and its continuous environment variant VLN-CE, typically operate on an "episodic" paradigm. In this paradigm, an agent is given a single natural language instruction to navigate a path in a new environment, and its memory is reset at the beginning of each episode. This setup tests an agent's "cold-start" navigation ability without any prior information about the scene. While useful for evaluating foundational language grounding and navigation skills, this episodic nature deviates significantly from how real-world robots operate.

**The Disparity and Missing Piece:**
Physical robots, intelligent vacuums, or assistive robots are deployed in persistent environments for extended periods. They continuously build maps, learn about their surroundings, and leverage past experiences to inform future actions. For instance, a robot that learns the layout of a living room when told to clean it should remember that layout for subsequent tasks or instructions. Existing VLN paradigms do not incentivize or evaluate this long-term memory and learning capability. While some VLN research explores "pre-exploration" to build maps before instructions, this work focuses on *iterative* map building *during* task execution.

**This Work's Contribution to the Landscape:**
"Iterative Vision-and-Language Navigation (IVLN)" directly addresses this gap. It proposes a new paradigm where agents navigate through "tours" – ordered sequences of multiple instruction-following episodes within the *same* persistent environment. This forces agents to maintain and utilize memory across episodes, mimicking real-world deployment scenarios. By introducing the IR2R (discrete) and IR2R-CE (continuous) benchmarks, the authors provide concrete platforms for evaluating agents in this more realistic setting.

This work marks a crucial evolution in embodied AI research. It moves beyond isolated task performance to emphasize continuous learning and adaptation within an environment. It also implicitly highlights the need for robust, long-term memory architectures and efficient environment representation methods, shifting the research focus from purely instruction-following to knowledge acquisition and utilization over time. The paper positions itself as a "logical next step" towards learning useful world representations through visual and linguistic information, paving the way for more capable and truly intelligent autonomous agents.

### 2. Key Objectives and Motivation

The core objective of this research is to bridge the gap between idealized episodic VLN benchmarks and the practical demands of real-world robotic deployment by introducing a new evaluation paradigm.

### 3. Key Objectives

1. **Define Iterative Vision-and-Language Navigation (IVLN):** To formally introduce a new paradigm where language-guided agents operate in persistent environments, follow sequences of instructions, and retain memory across tasks.
2. **Develop Iterative Benchmarks (IR2R and IR2R-CE):** To create concrete datasets and environments derived from existing VLN benchmarks (R2R and VLN-CE) that implement the IVLN paradigm, enabling standardized evaluation of persistent agents.
3. **Evaluate Existing VLN Agents in IVLN:** To test how state-of-the-art VLN models, specifically those relying on unstructured implicit memory, perform in this new persistent setting.
4. **Explore the Efficacy of Structured Memory (Maps):** To investigate whether agents that explicitly build and utilize semantic maps can effectively leverage environment persistence in IVLN, compared to those with unstructured memory.
5. **Propose a Tour-level Metric:** To introduce a suitable evaluation metric (`t-nDTW`) that can assess agent performance across an entire tour, not just individual episodes, thereby accounting for the cumulative nature of the task.

**Motivation:**
The primary motivation stems from the fundamental difference between how current VLN agents are trained and evaluated (episodic, memory-less) and how real robots are expected to function (persistent, learning over time).

- **Real-World Robotics:** Deployed robots (e.g., smart vacuums, assistive robots) occupy the same environment for extended periods. They need to learn from past experiences, associate semantic references with spatial information, and continuously improve their understanding of the environment. Current VLN benchmarks fail to simulate this reality.
- **Leveraging Prior Knowledge:** In a persistent environment, an agent might traverse the same hallway multiple times or encounter objects previously described. This offers a significant opportunity for improvement if the agent can retain and utilize this information. The authors explicitly state that "after just 10 episodes an agent has seen on average over 50% of the target path associated with the next language instruction in a tour," highlighting the potential for memory utilization.
- **Semantic Representations:** IVLN encourages the development of richer semantic representations grounded in language and visual experience. An agent could ground an "unusual, novel, and scene-specific referent" during one episode and then reason about it later.
- **Beyond Cold-Start:** While cold-start navigation is important, persistent operation demands adaptation and learning. IVLN shifts the focus to how agents can "improve over time" by leveraging "prior experiences to better follow future instructions within the same environment."
- **Renewed Focus on Mapping:** The authors hypothesize that explicit map-building strategies, common in robotics, might be essential for success in persistent VLN. This work aims to validate this hypothesis and motivate a "renewed focus on map-building agents in VLN."

In essence, the motivation is to make VLN research more aligned with the long-term goal of truly intelligent, adaptable, and deployable embodied AI agents.

### 4. Methodology and Approach

The core of the methodology is the introduction of the IVLN paradigm, the creation of new benchmarks based on this paradigm, and the evaluation of different memory architectures for agents.

#### 4.1. The Iterative Vision-and-Language Navigation (IVLN) Paradigm

- **Tours of Episodes:** IVLN defines a "tour" as an ordered sequence of instruction-following "episodes" within a single 3D scene. Unlike traditional VLN, agents retain memory across episodes within a tour.
- **Agent and Oracle Navigation Phases:** Each tour alternates between two phases:
 1. **Agent Navigation Phase:** The agent receives a language instruction and attempts to navigate independently. This phase ends when the agent stops or reaches a maximum action limit.
 2. **Oracle Navigation Phase:** Immediately after the agent's attempt, an "oracle" takes over. First, if the agent did not reach the correct goal, the oracle teleports it to the true goal location (simulating a human showing the robot its mistake). Second, the agent is then guided by the oracle to the starting point of the *next* episode in the tour, passively observing the environment. This ensures the agent is correctly positioned for the subsequent task while still allowing it to build its environmental understanding.

#### 4.2. Iterative Benchmarks (IR2R and IR2R-CE)

- **Dataset Generation:** Tours are generated from existing Room-to-Room (R2R) and VLN-CE datasets. The key challenge is chaining episodes to minimize the "oracle navigation distance" between an episode's end and the next episode's start. This is framed as an Asymmetric Traveling Salesperson Problem (ATSP), approximately solved using the Lin-Kernighan heuristic (LKH).
- **Discrete (IR2R) vs. Continuous (IR2R-CE):**
 - **IR2R:** Based on R2R's discrete navigation graph. Agents move along predefined edges and observe clear panorama images.
 - **IR2R-CE:** Based on VLN-CE's continuous 3D reconstructions of MatterPort3D scenes. Agents take continuous motion actions and observe noisy 3D environment images. Discontinuities in navigable areas lead to shorter tours on average compared to IR2R.
- **Dataset Characteristics:** The benchmarks comprise approximately 400 tours each across 80 indoor scenes, with tours ranging from a few to 100 episodes. Analysis shows significant overlap in observed environment regions: after just 10 episodes, agents have seen over 50% of the next target path and over 70% of the entire tour region on average.
- **Evaluation Metric (t-nDTW):** A new metric, "tour normalized Dynamic Time Warping" (t-nDTW), is introduced. It extends the episodic nDTW by computing the DTW cost over the *entire* tour path (concatenation of all episode paths) rather than individual episodes. Crucially, it penalizes alignments across episode boundaries, ensuring credit is only given for correct navigation within the current instruction's context. It aggregates nDTW scores weighted by episode count per tour.

#### 4.3. Agent Architectures and Memory Approaches

The paper evaluates two main categories of memory: unstructured latent memory and structured semantic map memory.

- **Unstructured Latent Memory Agents:**
 - **Discrete (IR2R): HAMT and TourHAMT:**
 - **HAMT (History-Aware Multimodal Transformer):** A state-of-the-art transformer agent that uses a history encoder for previous state-action pairs within an *episode*.
 - **TourHAMT:** Extends HAMT by including state-action pairs from *previous episodes* in the history embedding. A special `[PREV]` token delineates episode boundaries. The history encoder is unfrozen to learn this new long-term history.
 - **Continuous (IR2R-CE): CMA, TourCMA, PoolCMA, PoolEndCMA:**
 - **CMA (Cross-Modal Attention):** A common recurrent baseline with two GRUs (vision, general state) that reset per episode.
 - **TourCMA:** Resets only the vision GRU hidden state at the start of each *tour*, extending temporal receptive field. State GRU resets episodically.
 - **PoolCMA:** Resets vision GRU episodically but also incorporates a max-pooled, tour-persistent vector (reset each tour) into the vision GRU.
 - **PoolEndCMA:** Similar to PoolCMA, but the tour-persistent vector is also concatenated with the final state vector for action prediction.
 - **Training Method:** Teacher-forcing for all, with gradients updated per episode rollout. For tour-persistent memory, gradients from prior steps in previous episodes are disabled (adaptive truncated backpropagation through time).

- **Structured Semantic Map Memory Agents (MAP-CMA in IR2R-CE):**
 - **Map Construction:** Agents build egocentric occupancy maps and semantic maps (13 common labels) from RGB-D observations using inverse pinhole projection. Ground-truth semantics or RedNet-inferred semantics are used. Point clouds are collapsed to 2D.
 - **MAP-CMA Architecture:** Augments the CMA model by replacing the RGB input with encoded egocentric semantic and occupancy maps. A series of convolutional blocks (CoBRA) encodes the 14-channel (13 semantic + 1 occupancy) map input into spatial features that replace the visual features in CMA.
 - **Training Method:** A two-step process: initial teacher-forcing on augmented EnvDrop data ported to IR2R-CE, followed by fine-tuning with DAgger on IR2R-CE Train. Auxiliary Progress Monitor loss is used.
 - **Map Construction During Training/Evaluation:** Models are trained and evaluated under various conditions:
 - **Episodic Maps:** Maps reset at the start of each episode.
 - **Iterative Maps:** Maps continuously updated throughout the entire tour.
 - **Known Maps:** Pre-computed ground-truth maps of the entire scene (oracle information).

This comprehensive methodology allows for a detailed analysis of how different memory mechanisms handle the persistence inherent in the IVLN paradigm.

### 5. Main Findings and Results

The experiments provide clear insights into the effectiveness of different memory approaches in the IVLN paradigm.

#### 5.1. Unstructured Memory in IR2R and IR2R-CE Fails to Exploit Tour Information

- **Discrete (IR2R) with HAMT:** The naive extension of HAMT's implicit history memory to tours (TourHAMT variants) significantly *degraded* performance compared to the episodic HAMT baseline. TourHAMT's `t-nDTW` score dropped by nearly half (from 50% to 28% on Val-Unseen) compared to HAMT. Even with finetuning the history encoder and adding boundary tokens, performance remained substantially worse.
 - **Implication:** Simply concatenating past episode histories into a transformer's implicit memory is not sufficient. The distribution shift from single-episode to multi-episode history seems to overwhelm the model, and direct finetuning is insufficient to correct this. This suggests the need for more sophisticated long-term memory management or architectural changes.
- **Continuous (IR2R-CE) with CMA:** Similar to IR2R, simple extensions of CMA's unstructured latent memory (TourCMA, PoolCMA, PoolEndCMA) either slightly reduced or maintained performance (e.g., `t-nDTW` around 38% for most variants on Val-Unseen, similar to episodic CMA). While TourCMA showed a slight improvement on Val-Seen, it did not generalize to unseen environments.
 - **Implication:** This reinforces the finding that implicit, unstructured memory mechanisms, when naively extended, struggle to leverage persistent environment information for complex, long-horizon tasks.

#### 5.2. Semantic Map Memory in IR2R-CE Benefits from Prior Experience

- **Map-based Memory Outperforms Unstructured Memory:** MAP-CMA models consistently outperformed the best unstructured CMA models by a significant margin. The best MAP-CMA agent achieved a `t-nDTW` of 47-48% on Val-Unseen, a notable improvement (+9 points or ~24% relative increase) over the best unstructured CMA model (38%).
 - **Implication:** This is a crucial finding, strongly suggesting that *structured* memory, particularly in the form of semantic maps, is much better suited to leveraging environment persistence than unstructured latent representations.
- **Iteratively-Updated Maps Leverage Prior Experience:** Agents performed better when evaluated with maps that were iteratively updated throughout the tour ("Eval: It.") compared to maps reset for each episode ("Eval: Ep."). This improvement was consistent across all map sources (ground-truth or inferred semantics) and training procedures. The strongest benefit (3-4% `t-nDTW` increase) was observed when agents were *trained* with iteratively-updated maps.
 - **Implication:** This confirms that information gathered from previous episodes *can* be effectively used to improve performance on subsequent instructions within the same tour. It also suggests that learning to *utilize* this long-term map memory is a learned skill, as models trained on episodic maps showed less benefit from iterative evaluation maps.
- **Ground Truth vs. Inferred Semantics:** There was only a small, consistent drop in performance when using RedNet-inferred semantics compared to ground-truth semantics. The best inferred-semantics agent was only 1 point lower in `t-nDTW` than the best ground-truth agent.
 - **Implication:** This suggests that the models are somewhat robust to imperfect semantic segmentation, or perhaps that the current set of semantic labels or their usage by the agent is not fully bottlenecking performance.
- **Known Maps Fail to Outperform Iterative Maps:** Counter-intuitively, agents trained and evaluated with pre-computed "known maps" (oracle information of the entire scene) did *not* outperform those trained and evaluated with iteratively-built maps (which only know what they've seen).
 - **Implication:** This intriguing result indicates that simply having a full map isn't enough; the *process* of building the map through exploration and encountering explored/unexplored regions might be crucial for the agent's learning process. It also points to challenges in effectively encoding and decoding scene perception from pre-built maps for downstream reasoning.

**Summary of Findings:** The paper provides strong evidence that for persistent language-guided navigation, explicit, structured memory (like semantic maps) is critical, and agents can learn to leverage information gathered over long tours. Naive extensions of unstructured memory fall short, highlighting the need for memory architectures tailored for long-term spatial and semantic knowledge accumulation.

### 6. Significance and Potential Impact

The Iterative Vision-and-Language Navigation (IVLN) paradigm and its associated benchmarks represent a significant step forward for embodied AI research, offering several profound implications:

#### 6.1. Bridging the Reality Gap

- **More Realistic Evaluation:** IVLN directly addresses the long-standing gap between episodic simulation environments and the real-world deployment of robots. By requiring agents to operate in persistent environments and leverage long-term memory, it creates benchmarks that are more indicative of a robot's true capabilities and potential for continuous operation in human spaces.
- **Catalyst for Advanced Memory Architectures:** The clear failure of naive unstructured memory extensions and the success of structured map-based memory models highlight the critical need for new memory architectures in embodied AI. This paradigm will push research towards more sophisticated ways for agents to store, retrieve, and reason over spatial, semantic, and linguistic information over extended periods.

#### 6.2. Renewed Focus on Map-Building and Active Perception

- **Validation of Map-based Approaches:** The results strongly support the hypothesis that explicit map-building is crucial for persistent navigation. This could lead to a resurgence of interest in integrating robust SLAM (Simultaneous Localization and Mapping) and semantic mapping techniques into VLN agents.
- **Learning from Exploration:** The finding that iteratively-built maps sometimes outperform known maps suggests that the process of active exploration and incrementally building a world model is beneficial for learning. This could spur research into curiosity-driven exploration, efficient information gathering strategies, and the interplay between task execution and map refinement.

#### 6.3. Enabling Language Grounding and Reasoning over Time

- **Dynamic Language Grounding:** IVLN enables agents to ground "unusual, novel, and scene-specific referents" in one episode and utilize that grounding in subsequent episodes. This moves beyond static, pre-defined knowledge to dynamic, experience-driven language understanding.
- **Long-Horizon Reasoning:** The paradigm encourages agents to develop reasoning capabilities that span multiple instructions and interact with a dynamically growing internal representation of the environment. This is crucial for complex, multi-stage tasks in realistic settings.

#### 6.4. Future Research Directions

- **Advanced Memory and Representations:** The work opens avenues for developing more accurate, flexible, and expressive iterative maps. This includes exploring hierarchical maps, graph-based representations, or hybrid memory systems that combine implicit and explicit knowledge.
- **Improved Language-Map-Action Grounding:** The significant gap between current agent performance and human performance, even with maps, indicates a need for better methods to ground natural language instructions into spatial reasoning and actionable policies, especially in the context of an evolving map.
- **Transfer Learning and Data Efficiency:** Given the complexity of long tours, research into efficient transfer learning from simulated to real environments, as well as methods for generating diverse and challenging synthetic data, will be critical.
- **Beyond Labeled Semantics:** Exploring how agents can learn semantic understanding without relying on predefined labels or even how they can adapt to novel objects and places based on linguistic descriptions will be important.

#### 6.5. Limitations and Ethical Considerations (as noted by authors)

The authors responsibly highlight limitations: instructions are only in English, and environments are "lavish, staged homes and offices." This bias means the benchmarks currently serve "English-speaking, able-bodied folks as a 'default'," potentially hindering long-term goals for human-robot interaction and accessibility in diverse, cluttered, or less privileged environments. Future work must address these biases to ensure equitable and inclusive AI development.

In conclusion, IVLN is a foundational contribution that shifts the VLN research paradigm towards more ecologically valid and robot-centric challenges. By emphasizing persistence and memory, it lays the groundwork for more intelligent, adaptive, and ultimately more useful embodied AI agents capable of continuous learning and operation in complex human environments.
