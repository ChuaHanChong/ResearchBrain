# VLA-Pro: Cross-Task Procedural Memory Transfer for Vision-Language-Action Models

> [!summary] Summary
> VLA-Pro, from Fudan University and collaborators, introduces a framework for Vision-Language-Action (VLA) models to transfer procedural memory across tasks by storing manipulation experiences as task-specific LoRA adapters and dynamically fusing them at inference. This approach leads to substantial improvements in cross-task generalization, achieving up to a 207% relative increase in success rate on simulated benchmarks and elevating real-world average success from 5.8% to 65.0%.

## Problem

- Vision-Language-Action (VLA) models struggle with cross-task generalization, often overfitting to training data and failing on unseen tasks or objects.
- Existing architectural or prompt-based approaches for VLA adaptability do not fully internalize procedural experience into dynamically retrievable model parameters.
- Current VLA models often exhibit execution biases towards frequently observed actions, leading to incorrect behavior in novel, specific contexts.

## Method

- **VLA-Pro** stores task-specific procedural memories as compact ==LoRA== adapters, trained individually on seen tasks, after an initial shared base adapter captures general manipulation knowledge.
- It abstracts execution stages into structured procedural states (action type, object property, end-effector orientation, interaction point) from multimodal inputs for enhanced memory indexing and retrieval.
- During inference, the framework dynamically retrieves the most relevant procedural memories using action-aware matching, then fuses these LoRA adapters to adapt the base VLA model for the current action chunk.

## Results

- VLA-Pro boosted average success rates on unseen tasks in the RoboTwin benchmark by up to **207%** (RDT backbone) and **47%** (π0.5 backbone) and improved zero-shot performance on RLBench by **7.1** percentage points over the π0.5 baseline.
- In real-world robotic manipulation, the framework increased the average success rate from **5.8%** to **65.0%** across six held-out tasks using the π0.5 backbone.
- Analysis showed a positive correlation between procedural state extraction accuracy and physical execution success, and identified k=2 retrieved memories as optimal for overall performance on RLBench.

## Takeaways

> [!tip] Key Insights
> - Parameterizing procedural memory as lightweight, task-specific LoRA adapters allows for efficient storage and dynamic transfer of manipulation experiences.
> - Structured procedural states provide a robust and precise mechanism for memory retrieval, enabling VLA models to identify and apply highly relevant past experiences.
> - Dynamically fusing retrieved memories based on the current context and action type allows the base VLA policy to adapt to novel tasks and mitigate execution biases without permanent model modification.
