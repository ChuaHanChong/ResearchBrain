# Goal2Skill: Long-Horizon Manipulation with Adaptive Planning and Reflection

> [!summary] Summary
> Goal2Skill is a dual-system framework for long-horizon robot manipulation: a VLM-based high-level planner decomposes goals into sub-tasks, maintains structured memory, verifies outcomes, and reflects on failures, while a diffusion-based VLA executor acts on geometry-filtered observations; achieves 32.4% average success rate versus 9.8% for the strongest baseline on RMBench.

## Problem

- Existing VLA policies use limited observation windows and end-to-end action prediction, making them brittle on long-horizon, partially-observable, multi-stage tasks.
- Memory-augmented VLA methods treat memory as passive storage for context retrieval rather than an active substrate for verification, diagnosis, and recovery.
- High-level semantic reasoning and low-level motor control are often entangled in monolithic architectures, reducing robustness when both must be handled simultaneously.

## Method

- A ==VLM==-based high-level planner that generates structured sub-tasks with pre/post-conditions, execution horizons, and spatial constraints, and dynamically replans when needed.
- A ==structured memory== module combining episodic history, working memory summaries, and an error register, feeding a VLM ==verifier== and ==reflection engine== for closed-loop recovery.
- A ==VLA==-based low-level executor using ==geometry-preserving masked filtering== of distractor regions plus a ==diffusion==-based skill library for closed-loop action-chunk generation. Together these form **Goal2Skill**.

## Results

- Achieves **32.4%** average success rate on five RMBench tasks versus **9.8%** for the strongest baseline (X-VLA/ACT), with the gap widening on memory-intensive M(n) tasks: **38.7%** versus **9.0%**.
- Memory ablation shows structured memory raises average success from **6.7%** (base) to **35.3%** (full model), with Blocks Ranking Try jumping from **6%** to **60%**.
- Recovery ablation shows verification plus reflection raises average success from **8.0%** (base) to **28.0%** (full model), with Battery Try improving from **16%** to **46%**.

## Takeaways

> [!tip] Key Insights
> - Separating memory-guided semantic planning from geometry-oriented motor execution, mirroring cerebrum-cerebellum division, improves robustness on stateful multi-stage tasks.
> - Memory should actively drive verification and diagnosis, not just serve as passive context retrieval, since post-condition checking alone recovers much of the failure-handling gain.
> - Reflection that converts a failure signal into a concrete recovery action (retry, adjust, replan) matters more than failure detection alone for closed-loop robustness.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Recent advancements in Vision-Language-Action (VLA) systems have positioned them as a paradigm for embodied manipulation, capable of integrating visual perception, language understanding, and action generation within a unified policy. These systems, often leveraging large-scale multimodal pretraining, have demonstrated capabilities in instruction following, situational decision-making, and cross-object generalization, representing a step towards scalable embodied intelligence.

However, the existing landscape of VLA models primarily focuses on short-horizon decision-making, where actions are typically generated from recent observations with limited temporal dependency. This approach presents challenges in complex, long-horizon manipulation tasks that demand sustained memory, adaptive task decomposition, intermediate outcome verification, and robust recovery from execution failures. Such tasks are often characterized by partial observability, occlusions, and multi-stage dependencies. For instance, scenarios requiring a robot to perform a multi-step operation and then retry a sub-task upon failure highlight the need for persistent context and adaptive correction beyond reactive action generation.

Previous efforts to address these limitations have augmented VLA systems with explicit memory mechanisms, including retrieval-based memory and multi-scale representations. While these approaches enhance the accessibility of longer-range task context, they frequently treat memory as passive storage rather than an active component for decision-making, verification, or diagnosis. Furthermore, high-level semantic reasoning and low-level visuomotor control are often entangled within monolithic architectures, which can reduce robustness when fine-grained interaction and long-term planning must be managed concurrently.

This work positions itself within this landscape by proposing a modular, dual-system framework that explicitly separates high-level semantic planning from low-level motor execution. This framework aims to overcome the limitations of passive memory and monolithic architectures by enabling memory to actively support closed-loop decision-making, verification, diagnosis, and corrective actions, thereby improving robustness and adaptability in long-horizon embodied manipulation tasks.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a robust framework for long-horizon embodied manipulation that addresses the limitations of existing VLA systems. The core motivation stems from the observation that current VLA policies, largely designed for short-horizon tasks, struggle with real-world scenarios requiring persistent memory, adaptive task decomposition, and explicit recovery from execution failures. Specific challenges include:

- **Limited Observation Windows:** Many VLA policies rely on short temporal windows of observation, making them brittle in tasks where context needs to be maintained over extended periods.
- **End-to-End Action Prediction:** Purely end-to-end action generation can lead to locally plausible but globally incorrect actions in multi-stage tasks, resulting in accumulated failures.
- **Partial Observability and Occlusions:** Dynamic and cluttered environments exacerbate these issues, as task-relevant information may be obscured or require recalling past states.
- **Multi-stage Dependencies:** Complex tasks involve sequences of interdependent sub-tasks, requiring an agent to verify intermediate outcomes and adapt its plan if execution deviates from expectations.
- **Passive Memory Utilization:** While some VLA systems incorporate memory, it is often used as passive storage rather than an active substrate for decision-making, outcome verification, diagnosis, and recovery.
- **Entangled Reasoning and Control:** The entanglement of high-level semantic reasoning with low-level visuomotor control in monolithic architectures can reduce robustness when simultaneous adaptation and precise interaction are required.

To address these motivations, the paper proposes a dual-system framework with the following key objectives:

1. **Decouple High-Level Planning from Low-Level Control:** Explicitly separate high-level semantic reasoning (what to do) from low-level motor execution (how to do it). This aims to enhance modularity and robustness.
2. **Develop a VLM-based Planner with Structured Memory and Reflection:** Create a high-level planner, implemented as a Vision-Language Model (VLM)-based agentic module, that maintains structured task memory, performs goal decomposition, verifies outcomes, and facilitates error-driven correction through a reflection mechanism.
3. **Propose a VLA-based Executor with Geometry-Preserving Perception:** Design a low-level executor, instantiated as a VLA-based visuomotor controller, that executes sub-tasks using geometry-preserving filtered observations to suppress distractors and focus on task-relevant structures.
4. **Establish a Closed-Loop Interaction:** Implement a closed-loop system between planning and execution, enabling memory-aware reasoning, adaptive replanning, and robust online recovery by explicitly evaluating post-conditions and triggering corrective actions.

The overall motivation is to move beyond purely reactive policies toward a more modular and robust paradigm for embodied intelligence capable of handling the complexities of long-horizon manipulation.

### 3. Methodology and Approach

The proposed framework, named Goal2Skill, employs a dual-system architecture that explicitly separates high-level semantic planning from low-level visuomotor execution. This design is inspired by the functional distinction observed in biological systems.

#### 3.1. Overall Architecture

The system operates as a closed-loop control hierarchy with two temporal scales:

- **High-Level Planner:** Operates at a slower scale, receiving the global goal (G) and current observation (o_t). It maintains a memory state (M_t), generates or revises a sub-task plan (P), detects completion or failure, and triggers reflection when necessary.
- **Low-Level Executor:** Operates at a faster scale, receiving the current sub-task (τ_k) and raw sensor data. It performs geometry-oriented filtering and generates continuous motor actions (a_t) until termination is signaled by the planner.

Interaction between these modules is facilitated by a sub-task token (τ_k) issued by the planner and a completion signal (c_k) returned by the verifier within the planner.

#### 3.2. High-Level Planner

The high-level planner is built upon a pre-trained Vision-Language Model (VLM) (Φ) and comprises three integrated functional modules:

##### 3.2.1. Task Planning and Decomposition

The task planner, leveraging the VLM (Φ_plan), generates an ordered sequence of sub-tasks (P = ⟨τ_1, τ_2..., τ_K⟩) given a global goal (G), initial observation (o_0), and memory (M_0). Each sub-task (τ_k) is a tuple defined by:
- ℓ_k: a natural-language instruction.
- pre_k, post_k: symbolic predicates for required and expected world states.
- δ_k: maximum execution horizon.
- B_k: a set of bounding boxes identifying task-irrelevant spatial constraints (distractor regions). These guide the low-level executor for scene simplification.
- j_k: index of a primitive skill from the low-level tool library.
The planning process is dynamic, allowing for plan revision (P') based on environmental changes or execution failures.

##### 3.2.2. Memory Management

A structured memory state (M_t) aggregates multimodal context across an entire episode:
- **Episodic History (H_t):** A chronological record of observations (o_t'), active sub-tasks (τ_k(t')), low-level executor actions (a_t'), and completion signals (c_k(t')) up to time t. To manage VLM context windows, H_t is compressed via sliding-window summarization, retaining recent entries verbatim while older ones are absorbed into working memory.
- **Working Memory (W_t):** A compact natural-language summary of the world state, updated by the VLM (Φ_mem) after each sub-task transition based on W_t, o_t, τ_k, and c_k.
- **Error Register (E_t):** Stores sub-task failures and hypothesized causes, supporting the reflection engine.

Upon sub-task completion, a VLM-based verifier (Φ_verify) assesses if the post-condition (post_k) is satisfied, producing a completion signal c_k ∈ {success, fail, timeout}. If c_k is not 'success', a recovery strategy is initiated:
- `re-execute(τ_k)`: If `fail` and retry count (n_k) is below a threshold (N_max).
- `replan(P, M_t)`: If `timeout` or `n_k` exceeds `N_max`.

##### 3.2.3. Reflection Engine

Activated on failure (c_k ≠ success), the reflection engine (Φ_reflect) diagnoses the cause (d_k) and proposes a recovery action (ρ_k ∈ {retry, adjust-param, replan}). This information is recorded in E_t. If `ρ_k = adjust-param`, the planner modifies specific sub-task parameters (e.g., grasp-pose hint, distractor constraints) before retrying the same sub-task.

#### 3.3. Low-Level Executor

The low-level executor translates an assigned sub-task (τ_k) into continuous motor commands using closed-loop visual feedback. It comprises a geometry-oriented perception module, a diffusion-based skill library, and a local execution monitor.

##### 3.3.1. Geometry-Oriented Perception via Masked Filtering

The executor processes distractor bounding boxes (B_k) from the planner using a zero-shot segmentation model (S) to generate a pixel-level mask (Q_t). This mask is temporally propagated (K) and applied to the raw RGB image (I_t) via element-wise multiplication (ˆI_t = I_t ⊙ (1 − Q_t)). This process suppresses distractor regions, providing a filtered, task-relevant visual observation (ˆI_t).

##### 3.3.2. Diffusion-Based Skill Library and Action Generation

The executor uses a discrete library of skills (T = {π_1..., π_J}), where each primitive policy (π_j) is a diffusion-based visuomotor controller. The skill index (j_k) from τ_k selects the active primitive. Conditioned on ˆI_t, proprioceptive state (s_t), and sub-task instruction embedding (ℓ_k), the controller generates a sequence of future actions (action chunk A_t = {a_t..., a_t+H}) via a reverse diffusion process.

##### 3.3.3. Local Execution Monitoring and Interface to the High-Level Planner

The low-level executor operates with a receding-horizon approach. After executing an action chunk or at checkpoints, it pauses to return the updated observation to the high-level planner for semantic verification. The executor's role is not to assess global task completion but to provide local progress, leaving the determination of c_k to the high-level planner.

### 4. Main Findings and Results

The evaluation of the Goal2Skill framework was conducted across five representative RMBench tasks, focusing on long-horizon, memory-dependent manipulation, and included comparisons with baselines, targeted ablations, and qualitative rollouts.

#### 4.1. Comparison with Baselines

The framework was compared against four baselines: DP, ACT, Pi0.5, and X-VLA, on two M(1) tasks (Observe and Pick Up, Rearrange Blocks) and three M(n) tasks (Battery Try, Blocks Ranking Try, Press Button). M(1) tasks involve short-range retention, while M(n) tasks demand persistent task context, sequential bookkeeping, and handling delayed consequences.

- **Overall Performance:** The proposed framework achieved an average success rate of 32.4%, substantially outperforming the strongest baseline (X-VLA) at 9.8%.
- **Performance on M(n) Tasks:** The advantage was more pronounced on memory-intensive M(n) tasks, where the framework achieved 38.7% compared to the best competing approach's 9.0%. On M(1) tasks, it achieved 23.0% versus the best baseline's 15.0%.
- **Task-Specific Highlights:**
 - **Rearrange Blocks:** The framework reached 38%, improving over the strongest baseline at 29%.
 - **Battery Try:** Achieved 46% success, compared to the best baseline's 26%.
 - **Blocks Ranking Try:** Demonstrated a notable margin, achieving 60% while all baselines remained at or below 10%.
 - **Press Button:** Was the only method to achieve non-zero success (10%).
 - **Observe and Pick Up:** Achieved 8%, which was slightly below the best baseline's 9%. This suggests that the primary gain is not from uniformly stronger short-horizon execution, but from improved handling of long-horizon dependencies.

Qualitative results (Figure 4) corroborated the quantitative findings, showing coherent task progression across various manipulation sequences, demonstrating the framework's ability to maintain task context throughout execution. The results indicate that the framework's advantage increases with tasks requiring greater long-horizon memory and sequential dependency handling.

#### 4.2. Targeted Ablations

Two ablation studies were conducted to ascertain the contribution of structured memory and explicit recovery mechanisms.

##### 4.2.1. Memory Ablation Study

This ablation was performed on Observe and Pick Up, Rearrange Blocks, and Blocks Ranking Try tasks.

- **Base Model:** Achieved an average success rate of 6.7%, indicating the policy backbone alone is insufficient for memory-intensive tasks.
- **+Episodic History (H_t):** The average success rate increased significantly to 27.7%. This was particularly evident on Blocks Ranking Try, which improved from 6% to 54%, suggesting the importance of retaining temporally ordered experience.
- **+Episodic History (H_t) + Working Memory (W_t):** The average slightly changed to 28.0%. Rearrange Blocks improved from 21% to 36%, indicating that a compact state summary is beneficial for tracking evolving spatial arrangements. However, Observe and Pick Up and Blocks Ranking Try saw decreases, suggesting context-dependent utility of working memory.
- **Full Model:** Achieved the highest average success rate of 35.3%, improving all three tasks relative to the base model, including 38% for Rearrange Blocks and 60% for Blocks Ranking Try. This suggests that the combined and integrated functioning of structured memory components is most effective.

##### 4.2.2. Recovery Ablation Study

This ablation was performed on Battery Try and Press Button tasks, which are sensitive to execution failures.

- **Base Model:** Achieved an average success rate of 8.0%.
- **+Verifier (Φ_verify):** The average success rate rose to 17.5%. Battery Try improved from 16% to 30%, and Press Button from 0% to 5%. This demonstrates that explicit post-condition checking significantly improves robustness by detecting failures.
- **+Verifier (Φ_verify) + Reflection (Φ_reflect):** A further increase to 24.0% was observed. Battery Try rose to 38%. This indicates that beyond merely detecting failure, the ability to diagnose causes and propose corrective actions (reflection) is crucial for recovery.
- **Full Model:** Achieved the highest average of 28.0%, with Battery Try reaching 46%. This confirms that a complete closed-loop recovery mechanism, encompassing both verification and reflection, enhances robustness against execution failures.

In summary, the experiments collectively indicate that the Goal2Skill framework demonstrates superior performance in long-horizon manipulation, primarily due to its structured memory for persistent task state management and its explicit closed-loop recovery mechanisms for handling execution failures.

### 5. Significance and Potential Impact

The Goal2Skill framework presents a significant advancement in the field of embodied manipulation by addressing a critical limitation of current Vision-Language-Action (VLA) systems: their brittleness in long-horizon, memory-dependent tasks. The work introduces a modular and robust paradigm that deviates from purely reactive end-to-end action prediction, offering several areas of significance and potential impact:

- **Enhanced Robustness and Adaptability:** By explicitly separating high-level semantic planning from low-level visuomotor execution, the framework improves the system's ability to handle complex, multi-stage tasks. The integration of outcome verification and reflection-driven recovery allows the robot to detect failures, diagnose their causes, and adapt its plan or retry sub-tasks, leading to more resilient operation in dynamic and uncertain environments. This is particularly impactful for real-world robotic deployments where execution failures are inevitable.
- **Improved Long-Horizon Task Performance:** The substantial performance gains, particularly on memory-intensive M(n) tasks in the RMBench benchmark, demonstrate the efficacy of the dual-system approach. This indicates that structured memory, capable of maintaining task context over extended periods, is a key enabler for complex sequential manipulation, which has been a persistent challenge for VLA models.
- **Active Role for Memory:** The framework redefines the role of memory from passive storage to an active component that drives decision-making, verification, and corrective actions. This active memory management is crucial for tasks requiring sustained context, intermediate state tracking, and retrospective analysis of failures.
- **Modular Architecture for Embodied AI:** The proposed modular design, with distinct planner and executor components, offers a more interpretable and potentially scalable architecture for embodied intelligence. This separation allows for specialized development and optimization of each component, potentially simplifying the design of more complex robotic systems.
- **Guidance for Perception:** The concept of geometry-oriented perception via masked filtering, where the high-level planner guides the low-level executor to focus on task-relevant visual information by suppressing distractors, can lead to more efficient and robust visual processing in cluttered environments.
- **Future Research Directions:** The work lays a foundation for future research into more sophisticated memory-adaptation interactions, broader real-world manipulation settings, and handling greater scene uncertainty and embodiment variation. This could involve exploring more advanced reflection mechanisms, integrating learning for parameter adjustment, or extending the framework to collaborative multi-robot tasks.

In conclusion, the Goal2Skill framework contributes to the development of more capable and reliable robotic systems by offering a structured, adaptive, and reflective approach to long-horizon manipulation. Its findings suggest that effective embodied intelligence requires a holistic approach that combines strong action generation with sophisticated planning, memory management, and recovery mechanisms.
