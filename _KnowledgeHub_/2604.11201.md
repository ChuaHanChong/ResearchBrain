# CocoaBench: Evaluating Unified Digital Agents in the Wild

> [!summary] Summary
> Researchers introduced COCOABENCH, a benchmark evaluating unified digital agents on their ability to integrate vision, search, and coding to solve complex, long-horizon tasks in open digital environments. Evaluations reveal that current state-of-the-art agents achieve a maximum success rate of 45.1%, indicating substantial room for improvement in compositional reasoning.

## Problem

- Existing agent evaluation benchmarks focus on assessing individual capabilities in isolation (e.g., GUI-only, CLI-only) or within fixed tool ecosystems.
- A lack of systematic evaluation exists for unified digital agents on tasks explicitly demanding the adaptive composition of multiple core capabilities (vision, search, coding) in open-ended, real-world digital environments.
- Reliable and scalable evaluation for complex, long-horizon tasks, especially those involving multi-step interactions, is challenging to achieve without relying on subjective human or LLM judges.

## Method

- The **COCOABENCH** dataset was constructed, comprising 153 human-authored tasks designed for ==multi-capability integration== across nine diverse domains, with minimal instruction specification for infrastructure agnosticism.
- Each COCOABENCH task includes an ==automatic, outcome-based evaluation script== to ensure reproducible and scalable assessment without human or LLM judgment.
- A lightweight, modular agent scaffold called **COCOA-AGENT** was developed, utilizing an ==AIO Sandbox== and a ==ReAct-based== approach with general-purpose tools for browser interaction, file manipulation, execution, and control, enabling controlled comparisons across LLM backbones.

## Results

- GPT-5.4 under the Codex scaffold achieved the highest success rate at **45.1%**, demonstrating its strong performance across different configurations.
- Leading open-source multimodal models (Kimi-k2.5 and Qwen3.5-397B-A13B) showed significantly lower success rates (**11.8%** and **9.8%** respectively) compared to proprietary models.
- Error analysis revealed that reasoning and planning failures accounted for the largest share of issues (approximately **53%**), followed by visual grounding (**28%**) and tool/execution errors (**19%**).

## Takeaways

> [!tip] Key Insights
> - Current state-of-the-art unified digital agents exhibit limited reliability on complex compositional tasks, with the best-performing system achieving only a 45.1% success rate.
> - Agent scaffold design significantly influences performance and cost efficiency, with coding-centric scaffolds showing effective generalization for broader problem-solving.
> - Stronger agents strategically leverage programmatic execution (coding tools) extensively for multi-step reasoning, data processing, and structured output formatting, demonstrating a positive correlation between coding tool usage and success rates.
