# LensDFF: Language-enhanced Sparse Feature Distillation for Efficient Few-Shot Dexterous Manipulation

> [!summary] Summary
> Researchers from Agile Robots and TU Munich introduce LensDFF, a groundbreaking framework for few-shot dexterous manipulation that combines language-enhanced feature alignment with grasp primitives, achieving 64% success rate in real-world grasping while dramatically reducing training data requirements through innovative sparse feature distillation.

## Problem

- Traditional robotic manipulation requires extensive training data and struggles with view inconsistency across different angles
- Dense feature fields based on neural rendering are computationally expensive and impractical for real-time robotics
- Existing approaches struggle to generalize across different objects and grasp types

## Method

- Language-enhanced sparse feature distillation that aligns visual features using CLIP embeddings
- Integration of five grasp primitives (hook, cylindrical, pinch, tripod, lumbrical) for diverse manipulation
- Real2sim pipeline using SAM2 and FoundationPose for efficient grasp evaluation

## Results

- Achieved **64%** success rate in real-world experiments, outperforming SparseDFF (**54%**) and F3RM (**60%**)
- Demonstrated **40.8%** success rate in simulation, significantly better than baseline approaches
- Successfully reduced computational costs while maintaining or improving performance compared to dense feature methods

## Takeaways

> [!tip] Key Insights
> - Language features can effectively mitigate view inconsistency in multi-view feature fusion
> - Grasp primitives enable more versatile and stable manipulation while reducing computational costs
> - Test-time language feature alignment allows adaptive optimization based on object similarities
