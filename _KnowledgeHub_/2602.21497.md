# See It, Say It, Sorted: An Iterative Training-Free Framework for Visually-Grounded Multimodal Reasoning in LVLMs

> [!summary] Summary
> The "See It, Say It, Sorted" (ECRD) framework improves visually-grounded multimodal reasoning in Large Vision-Language Models by iteratively supervising each reasoning step with dynamically generated textual visual evidence. This training-free approach effectively reduces visual hallucination propagation, achieving up to 29.5% relative gains on reasoning benchmarks without costly retraining.

## Problem

- Large Vision-Language Models (LVLMs) frequently suffer from visual hallucination propagation, especially during extended Chain-of-Thought (CoT) reasoning, leading to incorrect final answers despite logical coherence.
- Current methods to mitigate hallucination are primarily training-based, demanding significant computational resources, extensive curated data, and complex reward designs, making them costly and model-specific.
- A lightweight, generalizable, and training-free approach is lacking to effectively enhance visual grounding at test time across diverse LVLM architectures.

## Method

- An iterative, training-free, and plug-and-play framework, ==Evidence-Constrained Reweighting Decoding (ECRD)==, is introduced to enhance visual grounding at test time without modifying base LVLMs.
- A ==Distribution Supervisor== adaptively reweights the base model's next-token probabilities using an "Evidence Pool" of dynamically growing textual visual observations.
- An ==Uncertainty-Triggered Visual Decider==, a lightweight VLM, is invoked on-demand when the base model's confidence is low, providing specific textual "micro-observations" to ground subsequent reasoning steps.

## Results

- ECRD consistently improved reasoning accuracy on the TreeBench benchmark, achieving relative gains of **16.5%** to **29.5%** across various open-source LVLM backbones (e.g., Qwen2.5-VL, LLaVA-OneVision).
- It surpassed the performance of several closed-source models (e.g., Gemini-2.5-Flash, GPT-4o) and training-based visual-grounded reasoning models on TreeBench, all without additional training.
- The framework enhanced the reasoning-perception balance on RH-Bench, increasing the RH-AUC from **0.51** to **0.58**, and showed generalizable improvements across five diverse multimodal benchmarks like OCRBench and HallusionBench.

## Takeaways

> [!tip] Key Insights
> - Visual hallucination in LVLMs can be effectively mitigated at test time by dynamically integrating semantic textual evidence into the decoding process without costly retraining.
> - An adaptive negotiation mechanism, where the visual evidence's influence scales with the base model's uncertainty, is crucial for balancing the LVLM's fluent generation with robust visual grounding.
> - Employing a lightweight, specialized visual decider only when the model exhibits low confidence allows for targeted visual clarification, preventing error propagation with minimal computational overhead.
