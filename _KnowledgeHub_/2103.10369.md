# Combining Pessimism with Optimism for Robust and Efficient Model-Based Deep Reinforcement Learning

> [!summary] Summary
> The Robust Hallucinated Upper-Confidence Reinforcement Learning (RH-UCRL) algorithm enables deep reinforcement learning agents to learn policies robust to worst-case disturbances through a model-based approach that combines optimistic exploration for the agent and pessimistic exploration for the adversary. This method provides sublinear robust cumulative regret guarantees and demonstrates superior worst-case performance and sample efficiency across adversarial, action-robust, and parameter-robust control tasks.

## Problem

- Reinforcement Learning (RL) agents often lack robustness when deployed in real-world environments with unknown conditions or unpredictable disturbances, leading to unreliable performance.
- Existing theoretical Robust RL approaches provide sample complexity guarantees but are often computationally impractical for complex, deep RL problems due to restrictive assumptions.
- Current empirical deep Robust RL methods scale to complex tasks but often lack provable robustness guarantees and can be sample-inefficient by not explicitly exploring the environment's adversarial spaces.

## Method

- Introduces **RH-UCRL**, a model-based deep RL algorithm that explicitly models the environment as a stochastic system with actions for both an agent and an adversary.
- Employs a 'calibrated' statistical model of dynamics, using neural networks, to provide mean estimates and confidence measures, differentiating between epistemic and aleatoric uncertainty.
- Combines optimistic policy evaluation for the agent (maximizing return within confidence bounds) and pessimistic policy evaluation for the adversary (minimizing return within confidence bounds) through 'hallucinated' control inputs to guide exploration.

## Results

- Achieved sublinear robust cumulative regret, RT=O(LrCHβTHH3/2TΓT)R_T = O(L_r C^H \beta_T^H H^{**3/2**} \sqrt{T \Gamma_T})RT​=O(Lr​CHβTH​H3/2TΓT​​), and provides sample complexity guarantees for learning ϵ\epsilonϵ-optimal robust policies.
- Empirically outperformed other robust deep RL algorithms (e.g., RARL, RAP) and non-robust baselines in worst-case return across adversarial, action-robust, and parameter-robust Mujoco environments.
- Demonstrated higher sample efficiency compared to on-policy robust methods, showing strong robust performance even after fewer episodes, and occasionally yielded better average performance than non-robust baselines.

## Takeaways

> [!tip] Key Insights
> - Differentiating between epistemic uncertainty (reducible through exploration) and aleatoric uncertainty (inherent noise) is critical for effective, uncertainty-guided exploration in robust settings.
> - Simultaneously applying optimism for the agent's policy search and pessimism for the adversary's policy search within a model-based framework enables efficient discovery of robust policies.
> - Leveraging 'hallucinated' control inputs based on confidence bounds allows both agent and adversary to actively explore worst-case dynamics and disturbances in a principled, theoretically grounded manner.
