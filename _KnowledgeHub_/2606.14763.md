# Bayesian Optimization for Learning Nonlinear MPC in Autonomous Agent Navigation

> [!summary] Summary
> A map-free navigation framework for autonomous agents, particularly quadrupedal robots, integrates a LiDAR-based Gaussian occupancy representation with A* planning and a nonlinear Model Predictive Control (MPC) tracker. The system leverages Tree-structured Parzen Estimators (TPE) for Bayesian Optimization to automatically tune 11 MPC cost function parameters, achieving a 38.7% reduction in path length and a 53.0% reduction in time to goal across diverse simulated environments, with parameters successfully transferring to real hardware.

## Problem

- Autonomous navigation for mobile robots, especially legged platforms in dynamic, unknown, and cluttered environments, faces challenges like jerky execution and poor generalization due to decoupled planning and control.
- The real-time deployment of Model Predictive Control (MPC) is constrained by the computational efficiency of environment representation for obstacle avoidance and the labor-intensive, often suboptimal manual tuning of MPC cost function weights.
- Existing navigation approaches often require extensive pre-built maps or struggle with transferring learned policies from simulation to real hardware (sim-to-real gap).

## Method

- A hierarchical, modular navigation stack was developed, integrating a reactive, semi-persistent LiDAR-based Gaussian occupancy grid for local environment representation with an A* planner for local path generation.
- A nonlinear ==Model Predictive Control== (**MPC**) tracker, formulated with CasADi and IPOPT, generates dynamically feasible velocity setpoints using a smooth sigmoid obstacle barrier function for collision avoidance.
- An offline Bayesian Optimization module, based on Tree-structured Parzen Estimators (TPE), systematically tunes an 11-dimensional vector of MPC hyperparameters to optimize a composite performance score across multiple navigation scenarios.

## Results

- Bayesian Optimization (BO)-tuned parameters reduced the average path length by **38.7%**, average MPC solve time by **25.3%**, and average time to goal by **53.0%** across three simulated environments, improving the overall success rate from **65.0%** to **90.0%**.
- The BO-tuned configuration demonstrated strong generalization to an unseen, out-of-distribution warehouse environment, achieving a **44.5%** reduction in path length without prior exposure during the tuning phase.
- Hardware deployment on a Unitree Go2 quadruped robot in a real laboratory environment validated the sim-to-real transfer, with BO-tuned parameters improving the success rate from 5/10 to 8/10 without any additional on-robot tuning.

## Takeaways

> [!tip] Key Insights
> - Automating MPC parameter tuning with Bayesian Optimization using Tree-structured Parzen Estimators significantly improves navigation performance and robustness across diverse, unseen environments, outperforming manual tuning methods.
> - Parameters optimized in simulation for a complex nonlinear MPC system effectively transfer to real-world quadruped robots (Unitree Go2) without requiring additional on-hardware tuning, addressing the sim-to-real gap for navigation.
> - Control jerk and control effort parameters exhibit the highest sensitivity in the MPC formulation, indicating their primary role in solution stability, and Bayesian Optimization contributes to a smoother optimization landscape with reduced overall parameter sensitivity.
