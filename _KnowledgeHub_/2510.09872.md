# WARC-Bench: Web Archive Based Benchmark for GUI Subtask Executions

> [!summary] Summary
> A new benchmark, WARC-Bench, evaluates multimodal AI agents on GUI subtasks by employing Web Archive (WARC) files to provide realistic, sandboxed web environments. Research shows that open-source models, when fine-tuned and further trained with reinforcement learning on this benchmark, achieve up to 52.33% success, surpassing some proprietary models in subtask execution.

## Problem

- Current web agent benchmarks primarily focus on either single-step visual grounding or comprehensive, multi-step web navigation, neglecting an intermediate layer of "GUI subtasks."
- GUI subtasks, defined as short-horizon, multi-action components like operating date pickers or scrolling content, are critical building blocks for complex web workflows but lack dedicated, realistic evaluation.
- Existing benchmarks for UI widgets often rely on simplified or synthetic environments, leading to a potential generalization gap for agents in real-world scenarios.

## Method

- Develop **WARC-Bench**, a new benchmark using ==Web Archive== (WARC) files to create high-fidelity, interactive, and sandboxed web environments for GUI subtasks.
- Implement programmatic reward functions within WARC-Bench to provide objective and deterministic evaluation of task success for web agents.
- Design the Subtask Vision Agent (SVA) architecture, a generalist VLM-based agent that uses only screenshots, and apply supervised fine-tuning (SFT) and reinforcement learning with verifiable rewards (RLVR) to improve open-source models.

## Results

- Frontier models achieved success rates up to **64.83%** (Claude-Sonnet 4.0) on the WARC-Bench real-world test set, while OpenAI's GPT-5 reached **51.33%**, demonstrating the benchmark's challenge.
- Supervised fine-tuning boosted open-source Qwen2.5-VL **72B** from **37.33%** to **48.33%** success, with subsequent reinforcement learning with verifiable rewards (RLVR) further increasing it to **52.33%**.
- The WARC-Bench approach highlighted unique stress-testing capabilities, revealing a **26%** performance gap between GPT-5 and Claude 4 Sonnet, contrasting with a narrower **11%** gap observed on the WebArena benchmark.

## Takeaways

> [!tip] Key Insights
> - GUI subtasks represent a distinct and challenging capability for web agents, with even frontier large language models showing significant room for improvement (e.g., Claude-Sonnet 4.0 achieved 64.83% success).
> - Combining supervised fine-tuning (SFT) with reinforcement learning using verifiable rewards (RLVR) effectively boosts open-source model performance on GUI subtasks, enabling a 72B model to achieve 52.33% success, surpassing some proprietary models.
> - Mastery of GUI subtasks, as evaluated by WARC-Bench, correlates with performance on long-horizon web navigation tasks, suggesting these intermediate capabilities are foundational for general web agent robustness.
