# WARC-Bench: Web Archive Based Benchmark for GUI Subtask Executions

> [!summary] Summary
> A new benchmark, WARC-Bench, evaluates multimodal AI agents on GUI subtasks by employing Web Archive (WARC) files to provide realistic, sandboxed web environments. Research shows that open-source models, when fine-tuned and further trained with reinforcement learning on this benchmark, achieve up to 52.33% success, surpassing some proprietary models in subtask execution.

## Problem

- Current web agent benchmarks primarily focus on either single-step visual grounding or comprehensive, multi-step web navigation, neglecting an intermediate layer of "GUI subtasks."
- GUI subtasks, defined as short-horizon, multi-action components like operating date pickers or scrolling content, are critical building blocks for complex web workflows but lack dedicated, realistic evaluation.
- Existing benchmarks for UI widgets often rely on simplified or synthetic environments, leading to a potential generalization gap for agents in real-world scenarios.

## Method

- Develop **WARC-Bench**, a new benchmark using ==Web Archive== (WARC) files to create high-fidelity, interactive, and sandboxed web environments for GUI subtasks.
- Implement programmatic reward functions within WARC-Bench to provide objective and deterministic evaluation of task success for web agents.
- Design the Subtask Vision Agent (SVA) architecture, a generalist VLM-based agent that uses only screenshots, and apply supervised fine-tuning (SFT) and reinforcement learning with verifiable rewards (RLVR) to improve open-source models.

## Results

- Frontier models achieved success rates up to **64.83%** (Claude-Sonnet 4.0) on the WARC-Bench real-world test set, while OpenAI's GPT-5 reached **51.33%**, demonstrating the benchmark's challenge.
- Supervised fine-tuning boosted open-source Qwen2.5-VL **72B** from **37.33%** to **48.33%** success, with subsequent reinforcement learning with verifiable rewards (RLVR) further increasing it to **52.33%**.
- The WARC-Bench approach highlighted unique stress-testing capabilities, revealing a **26%** performance gap between GPT-5 and Claude 4 Sonnet, contrasting with a narrower **11%** gap observed on the WebArena benchmark.

## Takeaways

> [!tip] Key Insights
> - GUI subtasks represent a distinct and challenging capability for web agents, with even frontier large language models showing significant room for improvement (e.g., Claude-Sonnet 4.0 achieved 64.83% success).
> - Combining supervised fine-tuning (SFT) with reinforcement learning using verifiable rewards (RLVR) effectively boosts open-source model performance on GUI subtasks, enabling a 72B model to achieve 52.33% success, surpassing some proprietary models.
> - Mastery of GUI subtasks, as evaluated by WARC-Bench, correlates with performance on long-horizon web navigation tasks, suggesting these intermediate capabilities are foundational for general web agent robustness.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of autonomous agent systems for complex web-based tasks is a significant area of research. Existing benchmarks in this domain primarily address two ends of a spectrum: single-step visual grounding and comprehensive, multi-step, long-horizon web navigation.

At one end, visual grounding tasks, such as those evaluated by benchmarks like SeeClick (Cheng et al., 2024) and VisualWebBench (Liu et al., 2024), focus on an agent's ability to map textual descriptions to precise pixel coordinates for a single UI action. These tasks assess granular interaction capabilities but do not necessarily reflect performance on multi-step workflows.

At the other end, comprehensive web navigation benchmarks, including WebArena (Zhou et al., 2023) and Mind2Web (Deng et al., 2023a), evaluate agents on complex, multi-step browser-based workflows. These tasks typically involve navigating through multiple pages, extracting information, filling forms, and making decisions over an extended horizon. While these benchmarks aim for realism, they are often resource-intensive to create and maintain, and may not specifically isolate intermediate agent capabilities. OS-World (Xie et al., 2024b) extends this to open-ended tasks in real operating systems.

The authors identify a gap at an intermediate level of agentic complexity, specifically "GUI subtasks." These are defined as smaller workflow components that involve multiple primitive UI actions (e.g., clicks, scrolls, types) but correspond to a single, short-horizon natural language instruction within a larger task. Examples include selecting a specific date in a date picker or accurately scrolling a container to extract information. While compositional frameworks like Agent-S2 (Agashe et al., 2025) suggest that breaking down complex tasks into subtasks is beneficial, existing realistic GUI benchmarks have not extensively addressed this intermediate layer.

Furthermore, previous benchmarks that focus on UI widgets or simple tasks, such as MiniWoB++ (Liu et al., 2018b) and FormFactory (Li et al., 2025), often rely on simplified or synthetically generated web environments that may lack the fidelity of real-world user interfaces, potentially leading to a generalization gap for agents deployed in practical scenarios.

WARC-Bench positions itself to address this gap by providing a benchmark for these GUI subtasks using high-fidelity, interactive, and sandboxed environments based on Web Archive (WARC) files. This approach allows for realistic interactions while offering the advantages of reproducibility and isolation, distinguishing it from both single-step grounding tasks and long-horizon live web environments. The work aims to demonstrate that subtask mastery is a distinct and crucial capability not adequately evaluated by existing benchmarks and that improvements in this area can lead to advancements in more general web agents.

### 2. Key Objectives and Motivation

The primary motivation for this research stems from the observation that training web agents to navigate complex, real-world websites necessitates the mastery of "subtasks." These are defined as short-horizon interactions involving multiple UI components, such as accurately choosing a date from a date picker or scrolling within a container to locate specific information. The authors contend that current research and benchmarking efforts in web automation largely overlook this intermediate level of agentic complexity, which bridges the gap between atomic visual grounding actions and extensive, long-horizon web navigation tasks.

The key objectives of this work are:

1. **Introduce and Formalize GUI Subtasks:** To define and conceptualize GUI subtasks as self-contained, unambiguous browser-based goals that can typically be completed by a human within 1-20 atomic UI actions. This includes skills such as navigating menus, setting date pickers, scrolling, filling forms, manipulating tables, and handling drag-and-drop elements. The motivation here is that these subtasks are fundamental building blocks for more complex web workflows, and their accurate execution by specialist models could significantly enhance the performance of general, long-horizon GUI agents.
2. **Develop WARC-Bench:** To create a novel benchmark, WARC-Bench (Web ARChive Benchmark), specifically designed to evaluate the accuracy of multimodal AI agents in executing these GUI subtasks. A core motivation for WARC-Bench's design is to provide realistic, dynamic, and interactive web environments while ensuring sandboxed, reproducible, and lightweight interactions. This is achieved through the use of Web Archive (WARC) files, which capture and replay entire website states, enabling high-fidelity replication of real-world websites.
3. **Establish Programmatic Evaluation:** To integrate per-task programmatic (and thus deterministic) reward functions within WARC-Bench. This allows for automated and objective measurement of task completion at the end of an agent's trajectory, making evaluation independent of the specific path taken by the agent.
4. **Evaluate State-of-the-Art Models:** To assess the performance of leading large vision-language models (VLMs) and computer-use agents on WARC-Bench. A key motivation is to ascertain if current frontier models, despite their general capabilities, exhibit deficiencies in executing these specialized subtasks, thereby identifying areas for improvement.
5. **Develop and Assess Training Techniques:** To explore and apply effective training techniques, specifically supervised fine-tuning (SFT) and reinforcement learning with verifiable rewards (RLVR), to improve the performance of open-source models on GUI subtasks within the WARC-Bench environment. This aims to demonstrate practical methods for enhancing subtask mastery and to evaluate the impact of synthetic data generation and environment interaction on real-world subtask performance.
6. **Highlight Unique Contributions:** To analyze WARC-Bench's distinct characteristics compared to existing benchmarks, illustrating that it evaluates a unique and crucial skill set not comprehensively covered by current visual grounding or long-horizon web navigation benchmarks. This aims to position WARC-Bench as a valuable tool for stress-testing GUI agents on essential capabilities.

In summary, the motivation is to address a critical, underexplored intermediate layer of web agent capabilities that is foundational for robust web navigation, and the objectives are to build a novel benchmark and demonstrate methods to enhance agent performance on these specific, challenging tasks.

### 3. Methodology and Approach

The methodology employed in this research centers on the creation of WARC-Bench, a new benchmark, and the development and evaluation of web agents using this benchmark.

#### 3.1. WARC-Bench Design and Construction

- **GUI Subtask Definition:** The authors define GUI subtasks as self-contained, unambiguous goals achievable with 1-20 atomic UI actions (e.g., clicks, scrolls, types, drags). Examples include navigating menus, manipulating date pickers, filling forms, extracting data from scrolled content, and using sliders.
- **Environment Replication using WARC Files:** WARC-Bench utilizes Web Archive (WARC) files to create realistic and interactive web environments. WARC files record the complete state of a website, including HTML, CSS, JavaScript, images, and HTTP headers. This allows for high-fidelity replay of archived webpages in a sandboxed, Chromium-based browser via a lightweight WARC replayer built using Playwright. This approach offers several advantages:
 - **High fidelity:** Exact replication of real websites.
 - **Task isolation:** Each task runs in a unique, isolated copy of an archived environment, preventing real write operations and interference between tasks.
 - **Scalable design:** New environments can be added by simply recording new websites.
- **Task Structure:** Each task in WARC-Bench consists of three components:
 1. **Environment:** A web environment backed by a single WARC file, with a starting URL and optional timestamp.
 2. **Goal:** A natural language description of the subtask (e.g., "Select 02/03/2025 as the start date").
 3. **Evaluator:** A code-based, deterministic reward function to measure task success. Four types of evaluators are supported: JS function-based, URL matcher, String matcher, and JSON matcher, enabling objective and verifiable reward signals.
- **Data Collection:**
 - **Subtask Categories:** A list of 15 common subtask categories (e.g., menu navigation, form filling, datepicker, drag and drop) was compiled.
 - **Real-world Data:** 29 real-world websites (e.g., Github, Zoho Desk, Zendesk) were selected and recorded as WARC files. Goals and evaluator functions for these were manually collected and labeled. The test set (200 tasks) exclusively comprises these real-world examples.
 - **Synthetic Data:** 62 synthetic websites were generated using an LLM-based pipeline to create HTML pages with diverse UI widgets. This pipeline automatically generated environments, task goals, and evaluator functions, which were then manually vetted for feasibility and correctness. The training set (1059 tasks) and a portion of the development set (178 out of 238 tasks) utilize these synthetic environments, combined with real-world tasks in the development set (60 tasks). In total, 1497 subtasks were created.

#### 3.2. Web Agent Design: Subtask Vision Agent (SVA)

- **Generalist VLM-based Agent:** The authors designed SVA to evaluate and compare Vision-Language Models (VLMs) on subtask execution.
- **Observe-Predict-Act Loop:** At each step, SVA receives the task goal, a screenshot of the current webpage, the available action space, and a history of up to 5 previous steps. It then generates a Chain-of-Thought (CoT) and predicts the next action.
- **Vision-Only Observations:** SVA relies solely on screenshots (1280x720 pixels) to observe the webpage state, avoiding the use of textual representations like accessibility trees or HTML DOM to prevent context length issues and better capture complex visual elements.
- **Action Space:** A minimal API action space of 8 types is provided: `click`, `complete`, `drag_and_release`, `hover`, `key_press`, `scroll`, `type`, and `wait`.
- **Browser Interaction:** BrowserGym (de Chezelles et al., 2025) serves as the underlying engine for SVA to interact with the browser.

#### 3.3. Training Techniques for Open-Source Models

To improve open-source models, the authors employed two training techniques using the Qwen2.5-VL family of models (7B and 72B parameters) with the SVA prompt architecture:

1. **Supervised Fine-Tuning (SFT):**
 - A large-scale SFT dataset was created by crawling approximately 12,000 unique subtask trajectories (decomposed into 50,000 single-step data points) using "teacher models" with strong UI interaction capabilities.
 - Website sources for this data included Common Crawl, UI component libraries, and synthetically generated websites. This dataset was used to distill grounding, planning, error correction, and reward modeling capabilities.
 - Training involved a learning rate of 1e-5, batch size of 128, max prompt length of 7168, max response length of 1024, for 1 epoch.
2. **Reinforcement Learning with Verifiable Rewards (RLVR):**
 - This technique involved applying the Proximal Policy Optimization (PPO) algorithm (Schulman et al., 2017) to SFT checkpoints.
 - Training was conducted on the illustrative synthetic training dataset of 1059 Gym-environment-based subtasks.
 - The agent directly interacted with the WARC-based environments, receiving a positive reward (10) for successful trajectories and 0 for failures or truncations. This allowed the model to learn from direct environment feedback.
 - For the 72B model, specific hyperparameters included 3 PPO updates per step, a batch size of 128, a clipping threshold (ϵ) of 0.15, and a KL coefficient (β) of 0.03, with actor and critic learning rates of 2e-6 and 5e-6, respectively, over 25 epochs.

#### 3.4. Evaluation Protocol

- **Benchmark Evaluation:** Models were evaluated on the WARC-Bench development and test splits, with success rate as the primary metric.
- **Baseline Models:** Proprietary computer-use agents (Anthropic's Claude-4.0-Sonnet CUA, OpenAI's GPT-5) and open-source models (Qwen2.5-VL 7B/72B, UI-Tars 1.5 7B CUA, OpenCUA 7B/32B CUA) were evaluated. All models, unless specified as CUA, used the SVA agent design.
- **Cross-Benchmark Comparison:** Agent performance was also compared on other GUI navigation benchmarks: WebArena (long-horizon), Screenspot V2 (GUI grounding), and MiniWoB++ (low-fidelity widget tasks) to contextualize WARC-Bench's contribution.

### 4. Main Findings and Results

The evaluation yielded several key findings regarding the challenge posed by GUI subtasks and the effectiveness of the proposed training methodologies.

#### 4.1. WARC-Bench as a Challenging Benchmark

- **Frontier Model Performance:** WARC-Bench presented a significant challenge for leading large foundation models. Anthropic’s Claude-Sonnet 4.0 achieved the highest success rate among proprietary models, at 64.83% on the real-world test set. OpenAI’s GPT-5 followed with 51.33%. These results indicate that even advanced models have substantial room for improvement in subtask execution.
- **Open-Source Model Baseline:** Vanilla open-source models exhibited lower performance. Qwen2.5-VL 72B, the best among them, achieved 37.33% success, while the 7B version scored 4.67%.

#### 4.2. Efficacy of Subtask Vision Agent (SVA) Design

- The SVA agent design demonstrated competitiveness. When paired with the same frontier models, SVA-based agents often outperformed their dedicated computer-use agent (CUA) counterparts. For instance, Claude Sonnet 4.0 using SVA achieved 64.83%, whereas the official Claude Sonnet 4.0 CUA achieved 47.17%. This suggests that the SVA's vision-only approach and structured prompting are effective for subtask resolution.

#### 4.3. Impact of Supervised Fine-Tuning (SFT)

- Distillation from strong teacher models through SFT significantly boosted the performance of open-source models.
 - The Ours-7B-SFT model (fine-tuned Qwen2.5-VL 7B) increased its success rate from 4.67% to 27.33% on the test set.
 - The Ours-72B-SFT model (fine-tuned Qwen2.5-VL 72B) improved from 37.33% to 48.33%. These results indicate that learning from expert trajectories is effective for improving subtask capabilities.

#### 4.4. Impact of Reinforcement Learning with Verifiable Rewards (RLVR)

- Further training with RLVR over SFT checkpoints led to additional performance gains, even with a relatively smaller, synthetic training dataset.
 - Ours-7B-RLVR improved from 27.33% (SFT) to 29.17%.
 - Ours-72B-RLVR increased from 48.33% (SFT) to 52.33%. The Ours-72B-RLVR model's performance notably surpassed that of many frontier closed-source models (e.g., GPT-5).
- Analysis on the development set indicated that RLVR training on synthetic data not only improved performance on synthetic tasks (+9.41% accuracy) but also generalized to real-website tasks (+9.43% accuracy), demonstrating its transferability.

#### 4.5. Behavioral Analysis of RLVR vs. SFT

- **Task Categories:** The RLVR model (Ours-72B-RLVR) showed substantial improvements in dynamic subtask categories such as form filling, menu navigation, table manipulation, and date picker interactions, compared to the SFT model.
- **Vision Grounding and Exploration:** These gains were attributed to enhanced vision grounding capabilities, leading to greater precision in identifying small interface elements (e.g., calendar dates, nested menu items), and better exploration through increased scrolling actions and contextual awareness, reducing errors from misplaced clicks.
- **Efficiency:** The RLVR model demonstrated improved efficiency, executing fewer overall actions and producing shorter trajectories on average (approximately 0.94 fewer steps per task) compared to the SFT model, often achieving goals with fewer steps in tasks where SFT failed.

#### 4.6. Comparison to Other GUI Navigation Benchmarks

- **Correlation with Long-Horizon Tasks:** Agent performance on single-step grounding (ScreenSpot V2) and low-fidelity widget tasks (MiniWoB++) exhibited weak correlation with long-horizon task performance (WebArena). In contrast, WARC-Bench performance tracked that of WebArena at a system level, suggesting that mastering subtasks is a precursor to strong performance on more complex web navigation tasks.
- **Generalization of Subtask Training:** Models fine-tuned on subtask data (Ours-RLVR variants) showed performance improvements on both low-fidelity widget tasks and long-horizon web navigation tasks (except for grounding tasks), indicating that subtask training enhances overall web navigation capabilities.
- **Stress Testing:** WARC-Bench uniquely stress-tests GUI agents on capabilities not well-covered by existing benchmarks. For example, while GPT-5 and Claude 4 Sonnet had an approximately 11% performance gap on WebArena, this gap widened to about 26% on WARC-Bench, highlighting its ability to differentiate model strengths in specific, crucial areas.

#### 4.7. Limitations of Frontier Models (Appendix I)

Analysis revealed common failure modes for frontier models on WARC-Bench, including suboptimal interaction strategies (e.g., failing to close pop-up windows), difficulties with complex input fields and widgets (e.g., inconsistent date formats, pre-filled text fields), weak instruction following, and limited exploration/navigation, particularly on canvas-based websites.

### 5. Significance and Potential Impact

The introduction of WARC-Bench and the accompanying research hold several significant implications for the development of autonomous web agents and the broader field of AI.

1. **Fills a Critical Research Gap:** WARC-Bench addresses a previously underexplored intermediate layer of agentic complexity: GUI subtasks. By focusing on these short-horizon, multi-action components, the research bridges the divide between single-step visual grounding tasks and complex, long-horizon web navigation benchmarks. This is crucial because subtask mastery is a foundational capability for effective and robust web planning.

2. **Novel and Realistic Benchmark:** The use of Web Archive (WARC) files for environment creation is a notable innovation. This approach allows for the high-fidelity replication of real-world websites in a sandboxed, reproducible, and lightweight manner. This solves challenges associated with live web environments (e.g., dynamic changes, non-determinism, environmental costs) and synthetic environments (e.g., lack of realism), providing a scalable and accessible platform for research.

3. **Reveals Limitations of Frontier Models:** The finding that even state-of-the-art models like Claude Sonnet 4.0 and GPT-5 achieve moderate success rates on WARC-Bench indicates that these powerful models still have significant deficiencies in precisely executing specialized GUI subtasks. This highlights critical areas for future research and development in improving the fine-grained control and interaction capabilities of large vision-language models.

4. **Advances Open-Source AI Capabilities:** The demonstration that open-source models, specifically the Qwen2.5-VL family, can be significantly improved through supervised fine-tuning (SFT) and reinforcement learning with verifiable rewards (RLVR) on WARC-Bench is impactful. The Ours-72B-RLVR model's ability to outperform many frontier closed-source models on this benchmark suggests that targeted training on subtasks can enable open-source alternatives to achieve competitive performance, fostering broader participation and innovation in the field.

5. **Blueprint for Generalist Agent Improvement:** The paper's hypothesis, supported by cross-benchmark comparisons, is that strong performance on WARC-Bench correlates with improved performance on longer-horizon web navigation tasks (e.g., WebArena). This suggests that WARC-Bench can serve as a valuable diagnostic and training tool, enabling researchers to stress-test and enhance specific, fundamental agent capabilities that contribute to overall generalization in web environments. Improving subtask execution could lead to more robust and reliable general-purpose web agents.

6. **Facilitates Scalable Research and Development:** The sandboxed nature of WARC-Bench, combined with its programmatic reward functions, makes it easier and faster for researchers to conduct experiments, iterate on model designs, and evaluate performance without the complexities and maintenance overhead of live or highly simulated environments. The planned open-sourcing of WARC-Bench and training recipes will further democratize access to this valuable resource.

7. **Informs Future Agent Design:** The detailed analysis of frontier model limitations, such as suboptimal interaction strategies, difficulties with complex widgets, and weak instruction following, provides specific insights that can guide the design of future web agents. These identified failure modes highlight the need for enhanced vision grounding, better contextual awareness, and more sophisticated planning mechanisms.

In conclusion, WARC-Bench provides a timely and relevant contribution to the field of autonomous agents, offering a novel approach to evaluating crucial subtask capabilities and demonstrating a path for significant improvements in web agent performance.
