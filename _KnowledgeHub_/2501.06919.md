# Shake-VLA: Vision-Language-Action Model-Based System for Bimanual Robotic Manipulations and Liquid Mixing

> [!summary] Summary
> This paper presents Shake-VLA, a Vision-Language-Action system that enables bimanual robotic manipulation for automated cocktail preparation through integrated vision, speech, and action modules.

## Problem

- Complex bimanual robotic manipulation requires precise coordination and control
- Need for natural human-robot interaction in service-oriented tasks
- Challenge of accurately detecting and handling ingredients in cluttered environments
- Difficulty in managing recipe requirements and ingredient availability discrepancies

## Method

- Integrated system combining visual detection, speech processing, and robotic control
- ==Retrieval-Augmented Generation (RAG)== module for recipe access and adaptation
- Force Torque sensors for precise liquid measurements
- Anomaly detection module to handle ingredient mismatches and suggest alternatives
- Language module to translate commands into robotic instructions

## Results

- Speech-to-text module achieved **93%** success rate in noisy environments
- Vision module attained **91%** success rate in object and label detection
- Anomaly module identified **95%** of recipe discrepancies
- Overall system achieved **100%** success rate in cocktail preparation
- System demonstrated effective handling of both English and Russian labels despite English-only training

## Takeaways

> [!tip] Key Insights
> - Modular architecture allows for independent component updates and improvements
> - Combining object detection with text retrieval improves accuracy in cluttered environments
> - Hybrid RAG approach increases efficiency in recipe retrieval and instruction generation
> - Real-time anomaly detection enables dynamic recipe adaptation

## Detailed Report

### 1. Introduction

Robotic systems capable of understanding natural language instructions and manipulating objects in unstructured environments represent a significant frontier in robotics research. The Shake-VLA system, developed by researchers at Skoltech, integrates vision, language, and action models to create a bimanual robotic system specialized in liquid mixing applications, specifically cocktail preparation.

The integration of these three domains—vision, language, and action—enables robots to perceive their environment, understand human commands, and execute complex manipulation tasks. Unlike traditional robotic systems that rely on pre-programmed routines, Vision-Language-Action (VLA) models provide flexibility and adaptability in dynamic environments where objects may be in different positions or where available ingredients might vary.

Shake-VLA builds upon advances in several key areas, including object detection, natural language processing, and robotic control. What distinguishes this system is its coordinated use of two robotic arms to perform complex manipulation tasks that would be impossible for single-arm systems, combined with intuitive human-robot interaction through speech interfaces.

### 2. System Architecture

The Shake-VLA system employs a modular architecture that integrates several specialized components:

1. **Visual Module**: Utilizes YOLOV8 for object detection and EasyOCR for text recognition on ingredient bottles
2. **Speech Interface**: Employs Whisper-1 for speech-to-text and Google Text-to-Speech (gTTS) for generating vocal responses
3. **Language Processing**: Leverages GPT-4o to generate detailed instructions and translate information into natural language
4. **Recipe Management**: Uses a Retrieval Augmented Generation (RAG) system with FAISS and OpenAI embeddings
5. **Anomaly Detection**: Compares available ingredients with recipe requirements and handles discrepancies
6. **Robotic Control**: Controls two UR3 robotic arms with specialized end effectors for different tasks

The architecture follows a sequential flow: first, the system receives a user request via speech, which is processed by the language module to identify the requested cocktail. Then, the visual module scans the environment to detect available ingredients. The anomaly detection module verifies whether all necessary ingredients are present. If all requirements are met, the language module generates a sequence of actions for the robots to follow, resulting in the preparation of the requested cocktail.

This modular design allows for easy updates and improvements to individual components without affecting the entire system, making Shake-VLA adaptable and extensible.

### 3. Visual Module

The visual perception component is fundamental to Shake-VLA's ability to interact with its environment. It employs a sophisticated object detection and recognition pipeline:

1. **Object Detection**: A YOLOV8 model trained on the COCO dataset identifies bottles and glasses in the workspace. This provides bounding box coordinates for each detected object.

2. **Text Recognition**: Once objects are detected, an EasyOCR model extracts text from the labels on bottles. This information is crucial for identifying the contents of each container.

3. **Data Organization**: The detected information is stored in a structured JSON format, containing details about:
 - Object type (bottle, glass)
 - Object position (x, y coordinates)
 - Detected label text
 - Confidence scores

One notable achievement of the visual module is its 91% accuracy rate in detecting objects and recognizing labels, even in cluttered environments. Interestingly, the system maintained high performance even when processing Russian labels despite being trained primarily on English text.

The system uses a Logitech camera mounted on one of the robotic arms, which allows for dynamic repositioning to obtain optimal viewing angles. This mobility is particularly valuable for identifying objects that might be partially occluded or positioned in difficult-to-view locations.

### 4. Language Processing and Interaction

The language component of Shake-VLA serves as the bridge between human users and the robotic system. It encompasses several key functions:

1. **Speech Recognition**: The system uses OpenAI's Whisper-1 model to convert spoken user requests into text with a 93% success rate, even in noisy environments. This enables natural interaction without requiring typed input.

2. **Recipe Retrieval**: When a user requests a specific cocktail, a Retrieval Augmented Generation (RAG) system searches a database of recipes. This system uses:
 - OpenAI's text-embedding-ada-002 model to generate embeddings for recipes
 - FAISS (Facebook AI Similarity Search) for efficient vector searching
 - A curated database of cocktail recipes with ingredients and preparation instructions

3. **Instruction Generation**: GPT-4o transforms structured recipe information into detailed natural language instructions for both the user and the robotic system. For example:

```
User: "I'm in the mood for a drink. Can you make me a Margarita?"

System (after processing): "I'll prepare a Margarita for you.
I'll need tequila, triple sec, and lime juice. Let me check
if I have all the ingredients..."
```

4. **Robot Command Generation**: The language module generates specific robot control commands in a structured format that can be directly executed:

```python
"Robot 1": [
  "take_glass()",
  "give_user()",
  "put_glass_empty()"
],
"Robot 2": [
  "take_bottle('tequila')",
  "pour_liquid(40)",
  "left_bottle('tequila')",
  "take_bottle('triple_sec')",
  "pour_liquid(20)",
  "left_bottle('triple_sec')"
]
```

This dual capability—communicating naturally with humans while generating precise machine instructions—makes the language module a central coordinator in the system.

### 5. Anomaly Detection and Error Handling

A distinguishing feature of Shake-VLA is its robust anomaly detection and error handling system. This component enables the robot to adapt to real-world uncertainties rather than failing when conditions don't perfectly match expectations.

The anomaly detection module performs several critical functions:

1. **Ingredient Verification**: Compares the required ingredients from a recipe with the detected available ingredients in the workspace.

2. **Discrepancy Handling**: When missing ingredients are identified, the system doesn't simply abort the operation. Instead, it:
 - Notifies the user of the missing ingredient
 - Suggests possible alternatives based on similarity
 - Asks for confirmation to proceed with modifications

3. **Real-time Monitoring**: Continuously updates its understanding of the environment through the visual system, allowing it to detect changes such as:
 - New ingredients being added
 - Containers being moved
 - Spills or other unexpected events

The experimental evaluation demonstrated an impressive 95% success rate in identifying discrepancies between detected ingredients and recipe requirements. This capability is crucial for creating a system that can function reliably in dynamic environments where perfect conditions cannot be guaranteed.

For example, if a user requests a Margarita but the system detects that lime juice is missing, it might suggest:

```
"I notice that lime juice is missing for the Margarita. Would you
like me to use lemon juice as a substitute, or would you prefer
a different cocktail that I can make with the available ingredients?"
```

This adaptive approach significantly enhances the system's practical usability compared to more rigid robotic systems.

### 6. Bimanual Robot Control

The physical implementation of Shake-VLA employs two Universal Robots UR3 robotic arms, each equipped with specialized end effectors for different aspects of the cocktail preparation process:

1. **Arm Configuration and Specialization**:
 - **First Arm**: Equipped with a 2F-Robotiq gripper for grasping bottles and other objects
 - **Second Arm**: Fitted with a custom-designed cup holder for securely manipulating glasses
 - The first arm also mounts a Logitech camera for visual perception

2. **Coordination Challenges**: Bimanual manipulation presents unique challenges that the system addresses:
 - **Spatial awareness**: Both arms must operate in a shared workspace without collisions
 - **Task allocation**: The system must determine which arm should perform which part of the task
 - **Synchronized actions**: Some operations require precisely timed coordination between arms

3. **Liquid Handling**: The system includes specialized capabilities for liquid measurement and pouring:
 - A force sensor on the cup-holding arm measures the weight to determine liquid quantity
 - Pouring actions are controlled with precise timing based on flow rate calculations
 - The position and orientation of bottles during pouring are optimized to minimize spills

The language module generates separate command sequences for each robot arm, which are then executed in a coordinated manner. This separation of concerns allows for parallel operation where appropriate and sequential coordination when necessary.

### 7. Experimental Results

The Shake-VLA system underwent comprehensive evaluation to assess both its individual components and overall performance:

1. **Component-Level Performance**:
 - Visual Module: 91% accuracy in object and label detection
 - Speech-to-Text Module: 93% success rate in interpreting commands
 - Anomaly Module: 95% accuracy in identifying ingredient discrepancies

2. **End-to-End System Evaluation**:
 - The integrated system achieved a 100% success rate in preparing requested cocktails
 - Testing included multiple cocktail recipes and various environmental conditions
 - Robustness was verified by introducing deliberate anomalies (missing ingredients)

3. **Task Execution Sequence**:

The execution follows a logical progression:
1. Receiving the user request
2. Retrieving the appropriate recipe
3. Scanning the environment for ingredients
4. Checking for anomalies
5. Executing the preparation sequence
6. Delivering the finished cocktail

The experiments demonstrated that the integrated system performed reliably across all stages of the process. The high success rates for individual modules contributed to the flawless performance of the complete system in the cocktail preparation task.

### 8. Applications and Significance

The Shake-VLA system represents a significant advancement in several areas:

1. **Service Robotics**: The system demonstrates practical applications in hospitality settings such as bars, restaurants, and hotels. The ability to prepare cocktails based on verbal requests showcases how robots can perform complex service tasks traditionally reserved for humans.

2. **Human-Robot Interaction**: By enabling natural language communication and handling unexpected situations, Shake-VLA illustrates how robots can interact with humans in intuitive ways, reducing the learning curve for users without technical backgrounds.

3. **Bimanual Manipulation**: The successful coordination of two robotic arms for complex tasks advances the field of robotic manipulation. This capability is applicable beyond cocktail preparation to areas such as:
 - Assembly tasks in manufacturing
 - Medical applications requiring precision and coordination
 - Food preparation and other culinary applications

4. **VLA Integration**: The seamless combination of vision, language, and action models provides a template for developing robotic systems that can perceive their environment, understand instructions, and execute appropriate actions. This integration approach has broad applications across robotics.

The research also aligns with broader trends toward Industry 6.0, where AI-powered robots work collaboratively with humans in flexible manufacturing and service environments.

### 9. Conclusion

Shake-VLA demonstrates an effective integration of vision, language, and action models to create a functional bimanual robotic system capable of preparing cocktails based on verbal instructions. The system's modular architecture allows for robust performance across various conditions and tasks.

Key contributions of this work include:

1. A comprehensive VLA-based architecture for bimanual robotic manipulation
2. Effective integration of state-of-the-art AI models for object detection, language processing, and robot control
3. Robust anomaly detection that enables adaptation to real-world uncertainties
4. Demonstrated success in a challenging application domain requiring precise manipulation and coordination

While the current implementation focuses on cocktail preparation, the underlying architecture and methodologies are applicable to a wide range of robotic manipulation tasks. The high success rates achieved in experimental evaluation suggest that this approach holds promise for advancing robotic capabilities in complex, dynamic environments where human-like dexterity and adaptability are required.

The Shake-VLA system represents a significant step forward in creating robots that can understand human instructions, perceive their environment, and perform useful physical tasks in service-oriented settings.
