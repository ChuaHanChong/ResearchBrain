# Shake-VLA: Vision-Language-Action Model-Based System for Bimanual Robotic Manipulations and Liquid Mixing

> [!summary] Summary
> This paper presents Shake-VLA, a Vision-Language-Action system that enables bimanual robotic manipulation for automated cocktail preparation through integrated vision, speech, and action modules.

## Problem

- Complex bimanual robotic manipulation requires precise coordination and control
- Need for natural human-robot interaction in service-oriented tasks
- Challenge of accurately detecting and handling ingredients in cluttered environments
- Difficulty in managing recipe requirements and ingredient availability discrepancies

## Method

- Integrated system combining visual detection, speech processing, and robotic control
- ==Retrieval-Augmented Generation (RAG)== module for recipe access and adaptation
- Force Torque sensors for precise liquid measurements
- Anomaly detection module to handle ingredient mismatches and suggest alternatives
- Language module to translate commands into robotic instructions

## Results

- Speech-to-text module achieved **93%** success rate in noisy environments
- Vision module attained **91%** success rate in object and label detection
- Anomaly module identified **95%** of recipe discrepancies
- Overall system achieved **100%** success rate in cocktail preparation
- System demonstrated effective handling of both English and Russian labels despite English-only training

## Takeaways

> [!tip] Key Insights
> - Modular architecture allows for independent component updates and improvements
> - Combining object detection with text retrieval improves accuracy in cluttered environments
> - Hybrid RAG approach increases efficiency in recipe retrieval and instruction generation
> - Real-time anomaly detection enables dynamic recipe adaptation
