# TransMamba: A Sequence-Level Hybrid Transformer-Mamba Language Model

> [!summary] Summary
> A sequence-level hybrid Transformer-Mamba language model, TransMamba, unifies these architectures through shared parameters and dynamic switching, achieving improved performance on various NLP and long-text tasks while reducing training time by up to 25%.

## Problem

- Transformers face quadratic computational complexity (O(T^2)) with sequence length, leading to high costs for very long sequences in both training and inference.
- Initial Mamba models, while efficient with linear complexity, exhibit unstable contextual learning and suboptimal multitask generalization compared to Transformers.
- Existing layer-level hybrid models suffer from rigid structural restrictions and often fail to dynamically adapt to varying sequence lengths and contextual demands.

## Method

- Unifies Transformer and Mamba architectures through ==shared parameter matrices==, allowing a single set of core parameters to serve as both QKV for Attention and CBx for SSM.
- Introduces a sequence-level dynamic switching mechanism via a ==TransPoint== within each layer, allowing the model to process different parts of the input sequence with either Attention or SSM.
- Employs a lossless ==Memory Converter== to seamlessly and without additional parameters transfer contextual information from the Attention mechanism to the initial hidden state of the ==Mamba SSM==.

## Results

- TransMamba consistently outperforms pure Transformer, pure Mamba2, and naive Hybrid models across general English tasks and long-context benchmarks like LongBench-v2 (e.g., **38.76** for TransMamba-1.5B vs. **31.61** for Transformer).
- Achieves up to a **2**5%** reduction** in average training time compared to Transformer models, demonstrating significant efficiency improvements consistent with theoretical FLOPs analysis.
- Effective TransPoint scheduling, particularly layer-specific, broad-range, and fine-grained approaches, yields the best validation loss (**2.898**) and perplexity (**1.813**).

## Takeaways

> [!tip] Key Insights
> - A deeper consistency exists between Transformer's attention and Mamba's state space model, enabling them to share core parameter matrices within a unified architecture.
> - Dynamic, sequence-level adaptation between different mechanisms (Attention and SSM) using principled scheduling can effectively balance computational efficiency and robust contextual learning.
> - Lossless information transfer between distinct architectural components, facilitated by a Memory Converter, is critical for effective integration in hybrid models.
