# RePrompt: Reasoning-Augmented Reprompting for Text-to-Image Generation via Reinforcement Learning

> [!summary] Summary
> RePrompt introduces a framework that trains a language model to produce reasoning-infused enhanced prompts for text-to-image (T2I) generation. This approach significantly improves T2I models' ability to interpret complex compositional elements, leading to more accurate spatial relations and object counts without requiring retraining of the T2I backbone.

## Problem

- Current text-to-image (T2I) models often misinterpret or fail to fully account for user intentions in short, vague, or underspecified prompts, leading to visual inconsistencies.
- Existing prompt enhancement methods either suffer from high latency due to iterative refinement or produce linguistically rich but visually unrealistic content from single-pass LLM rewrites.
- T2I models frequently struggle with accurately generating images that reflect complex compositional attributes, such as precise object counts, correct spatial relationships, and attribute bindings.

## Method

- A ==prompting policy==, implemented as a fine-tuned language model (Qwen2.5-3B), generates both a step-by-step reasoning trace and a detailed, visually coherent enhanced prompt from an initial user prompt.
- An ensemble, image-grounded reward model provides multi-faceted feedback, incorporating visual-reasoning rewards (ImageReward and VLM-Reward), a structure reward for format, and a length reward for prompt token count.
- The prompting policy is optimized using Group Relative Policy Optimization (GRPO), leveraging the non-differentiable visual feedback from an off-the-shelf T2I synthesizer to improve compositional correctness.

## Results

- RePrompt achieved a state-of-the-art overall accuracy of **0.76** on the GenEval benchmark, demonstrating significant improvements in spatial layout understanding (e.g., +**122.2%** on Pixart-Σ) and object counting across diverse T2I models.
- The framework consistently boosted performance across all compositional generalization dimensions in the T2I-Compbench, with notable improvements in spatial compositional scores and numeracy understanding.
- RePrompt maintained efficient inference at 30 seconds per image, delivering superior accuracy while being considerably faster than other optimization-heavy baselines that required 110-140 seconds.

## Takeaways

> [!tip] Key Insights
> - Integrating explicit, structured reasoning into the prompt generation process allows the LLM to 'internally simulate visual implications,' leading to better anticipation and mitigation of compositional errors.
> - Optimizing prompt generation directly with reinforcement learning, grounded in diverse visual feedback, is crucial for aligning LLM-generated prompts with physical reality and enhancing T2I fidelity.
> - Decoupling prompt enhancement from the T2I backbone creates a modular, efficient, and model-agnostic solution that can be broadly applied to various T2I architectures without expensive retraining.
