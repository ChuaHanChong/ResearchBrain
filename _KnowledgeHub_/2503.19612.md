# RL-finetuning LLMs from on- and off-policy data with a single algorithm

> [!summary] Summary
> Researchers from Meta GenAI and Meta FAIR present the Any-Generation Reward Optimization (AGRO) algorithm, a unified reinforcement learning approach for fine-tuning large language models using both on-policy and off-policy data. AGRO achieves a +7% performance increase on the MATH dataset with Llama 3 8B, demonstrating superior data efficiency and improved robustness in offline learning compared to traditional methods.

## Problem

- Existing RLHF algorithms for LLMs are largely compartmentalized into either computationally intensive online methods or static, often sub-optimal, offline methods.
- This dichotomy prevents the seamless integration of diverse data sources, such as iteratively collected online feedback and large, pre-collected offline datasets.
- Naive adaptations of on-policy KL-regularized policy gradient algorithms to off-policy settings do not reliably converge to the optimal target policy.

## Method

- AGRO introduces the theoretical concept of =="generation consistency"==, stating that at optimality, the KL-regularized reward is invariant across any generation for a given prompt.
- The algorithm derives ==unified loss functions== for both on-policy and off-policy settings, which minimize the ==variance of the regularized reward== to converge to the optimal policy.
- AGRO employs ==sample-based gradient estimates==, and for scenarios with multiple generations per prompt (n>1), it directly estimates variance, eliminating the need for an auxiliary value function.

## Results

- On-policy AGRO achieved a **+7%** performance improvement on the challenging MATH dataset compared to the supervised fine-tuned Llama 3 8B reference model.
- In on-policy settings, AGRO demonstrated superior data efficiency, making faster progress in training reward for the same number of learning iterations than standard regularized policy gradient methods.
- Off-policy AGRO consistently showed better overall performance and stability than adapted KL-regularized policy gradients in extreme offline learning scenarios, confirming its theoretical advantages.

## Takeaways

> [!tip] Key Insights
> - The core insight is that the optimal policy in a regularized RLHF problem ensures the quantity `r(x, y) - beta log(pi(y|x)/pi_ref(y|x))` is constant across all generated responses `y` for a given prompt `x`.
> - By minimizing the variance of this generation-consistent regularized reward, AGRO provides a single, theoretically grounded framework capable of learning from any mix of on-policy and off-policy data.
> - On-policy AGRO leverages both pathwise-derivative and likelihood ratio gradient estimates, leading to more efficient learning dynamics and faster training progress.
