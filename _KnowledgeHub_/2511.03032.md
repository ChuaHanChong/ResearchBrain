# Leveraging Discrete Function Decomposability for Scientific Design

> [!summary] Summary
> A new algorithm, DECOMPOSITION-AWARE DISTRIBUTIONAL OPTIMIZATION (DADO), enhances *in silico* design efficiency for high-dimensional discrete objects by explicitly leveraging the decomposable nature of objective functions. It consistently outperformed standard baselines on synthetic optimization tasks and protein property prediction benchmarks, demonstrating faster convergence to higher-performing designs.

## Problem

- Efficiently designing discrete objects (e.g., proteins, circuits) *in silico* is challenging due to the combinatorial explosion of high-dimensional search spaces.
- Current distributional optimization algorithms (like EDAs and RL) treat designs as indivisible, failing to leverage inherent decomposability often present in scientific objective functions.
- This lack of structural awareness leads to statistical inefficiency, requiring more samples and slower convergence for effective optimization.

## Method

- **DADO** represents objective function decomposability using a ==junction tree==, which factors the function into components over subsets of design variables.
- It employs a factorized generative model (search distribution) whose factors are independently updated using 'distributional value functions' computed via a message-passing scheme on the junction tree.
- These value functions act as localized, factor-specific weights for weighted maximum likelihood estimation (MLE) updates, coordinating learning across the interconnected factors of the search distribution.

## Results

- DADO consistently outperformed naive EDA, FDA, and PPO baselines on synthetic functions, demonstrating superior performance that scaled with increasing sequence length (L up to **200**) and alphabet size (D up to **100**).
- On protein property prediction tasks (AAV, Amyloid, Gcn4, TDP-43), DADO achieved significantly higher objective function values than all baselines, converging more effectively to high-performing designs.
- A case study on GB1 protein showed that stricter decomposition (smaller meta-variables) enhanced DADO's performance and improved predictive model robustness, especially when trained on suboptimal data.

## Takeaways

> [!tip] Key Insights
> - Explicitly leveraging objective function decomposability through a structured generative model and message passing enables a 'divide, collaborate, and conquer' strategy for significantly improved statistical efficiency in discrete design.
> - Distributional Q-functions, computed via expectation-based message passing on a junction tree, provide a tractable and unbiased way to guide factor-specific updates for the search distribution.
> - Decomposition structures for protein design can be practically derived from 3D contact graphs (e.g., using AlphaFold3), and enforcing such decomposition does not significantly compromise predictive model accuracy.
