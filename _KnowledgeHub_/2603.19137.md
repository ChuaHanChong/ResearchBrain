# GSMem: 3D Gaussian Splatting as Persistent Spatial Memory for Zero-Shot Embodied Exploration and Reasoning

> [!summary] Summary
> GSMem, a framework from Case Western Reserve University and the University at Buffalo, utilizes 3D Gaussian Splatting (3DGS) to create a persistent, re-renderable spatial memory for embodied agents, enabling them to virtually re-observe previously explored areas. This approach facilitates optimal view generation for Vision-Language Model (VLM) reasoning and achieves state-of-the-art performance on Active Embodied Question Answering and Multimodal Lifelong Navigation benchmarks, reaching a 67.2% Success Rate and 46.9% SPL on GOAT-Bench.

## Problem

- Embodied agents lack "post-hoc re-observability," preventing them from mentally revisiting explored scenes from new viewpoints to uncover missed details or clarify ambiguities.
- Object-centric memory representations discard raw visual data and are prone to irrecoverable omissions due to perception errors (e.g., missed or misidentified objects).
- View-based memory systems are sparse and static, restricting agents to initial observations and hindering the synthesis of alternative perspectives to resolve visual ambiguities.

## Method

- Integrated 3D Gaussian Splatting (3DGS) as a continuous, dense, and re-renderable spatial memory, explicitly parameterizing scene geometry and appearance.
- Developed a multi-level retrieval-rendering mechanism combining object-level scene graphs with an optimization-free 3D language field for robust localization of task-relevant regions.
- Designed a hybrid exploration strategy that balances Vision-Language Model (VLM)-driven semantic relevance with a 3DGS-based information-theoretic geometric coverage objective for efficient knowledge acquisition.

## Results

- Achieved state-of-the-art performance on the Active Embodied Question Answering (A-EQA) benchmark, surpassing existing baselines with improved LLM-Match and LLM-Match SPL scores.
- Demonstrated substantial gains on the Multimodal Lifelong Navigation (GOAT-Bench) benchmark, reaching a 67.2% Success Rate and 46.9% SPL, outperforming all previous reinforcement learning and VLM-based exploration methods.
- Qualitatively showed robustness against missing/incorrect object detections and view-dependent limitations by successfully localizing targets and providing clearer visual evidence for VLMs through optimal viewpoint rendering.
- Ablation studies confirmed the critical contributions of the CLIP language field, hybrid exploration strategy, and optimal viewpoint selection and rendering enhancement to overall performance and efficiency.

## Takeaways

> [!tip] Key Insights
> - A continuous, re-renderable 3DGS memory, coupled with an online language field, provides agents with "Spatial Recollection," overcoming view-dependency and perception limitations.
> - Combining object-level and semantic-level retrieval using the 3DGS language field enhances robustness against common perception failures like missing or incorrect object detections.
> - A hybrid exploration strategy that considers both semantic relevance and geometric coverage leads to more efficient and comprehensive environment mapping, reflected in improved path lengths.
> - Optimal viewpoint rendering from the 3DGS memory provides high-fidelity, well-aligned visual inputs, which significantly improves Vision-Language Model (VLM) reasoning performance.
