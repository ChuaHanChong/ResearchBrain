# DyQ-VLA: Temporal-Dynamic-Aware Quantization for Embodied Vision-Language-Action Models

> [!summary] Summary
> The research from Peking University and collaborators introduces DyQ-VLA, a dynamic quantization framework for Vision-Language-Action (VLA) models that adapts precision based on real-time kinematic sensitivity. It achieves an average success rate of 76.1% (99.5% of full-precision) in simulations, reduces memory footprint by 70%, and provides up to 1.49x inference speedup, enabling efficient deployment on edge devices.

## Problem

- Vision-Language-Action (VLA) models require substantial computational and memory resources, hindering their real-time deployment on resource-constrained edge devices.
- Existing static quantization methods are inefficient for VLA models due to their temporal-dynamic quantization sensitivity, where error tolerance fluctuates throughout a task, leading to uniform high precision even when lower precision would suffice.
- There is a lack of practical mechanisms for real-time identification of instantaneous quantization sensitivity to guide dynamic bit allocation without incurring prohibitive runtime overheads.

## Method

- DyQ-VLA proposes a dynamic quantization framework that utilizes a static 4-bit weight quantization (W4) and dynamically switches activation quantization (AX) based on real-time sensitivity.
- It leverages kinematic metrics, specifically Motion Fineness and Angular Jerk, as reliable, real-time proxies to estimate the instantaneous quantization sensitivity of the VLA model.
- An asynchronous CPU-GPU pipeline integrates a hysteresis-based precision switching strategy and a kinematic-guided bit allocation module to dynamically assign optimal bit-widths, hiding scheduling overhead.

## Results

- DyQ-VLA achieves 76.1% average success rate (99.5% of BF16 performance) in LIBERO simulations, while reducing memory footprint by 70% (10.5 GB saved) and providing a 1.49x average inference speedup.
- In real-world tests with a 6-DoF robotic arm, it demonstrates end-to-end latency speedups of 1.32x to 1.43x with minimal performance degradation (e.g., 0.0% for atomic grasping, 3.3-3.4% for spatial displacement and composite tasks).
- The framework adapts precision dynamically, achieving lossless routing with 1.51x speedup in LIBERO-Spatial tasks by reverting to BF16 during critical phases, and assigning low-bit states (W4A2) for 1.49x speedup in LIBERO-Long tasks.

## Takeaways

> [!tip] Key Insights
> - VLA models exhibit temporal-dynamic quantization sensitivity, meaning their error tolerance varies significantly throughout task execution, requiring high precision only during fine-grained manipulation.
> - Kinematic metrics like Motion Fineness (r=0.90) and Angular Jerk (r=0.87) strongly correlate with the VLA model's instantaneous quantization sensitivity and offer complementary information for real-time estimation.
> - An asynchronous, mixed-precision backend combined with a hysteresis-based switching strategy effectively manages dynamic bit allocation and minimizes overheads, enabling efficient real-time operation.
