# Qwen-RobotNav Technical Report: A Scalable Navigation Model Designed for an Agentic Navigation System

> [!summary] Summary
> A scalable navigation model, Qwen-RobotNav, built upon Qwen3-VL, enables dynamic adaptation of visual stream consumption through a reconfigurable observation strategy. It achieves state-of-the-art performance across diverse embodied navigation, question answering, and autonomous driving tasks while serving as a flexible component within agentic systems.

## Problem

- Existing unified navigation models rely on fixed observation strategies, which are suboptimal for the varied temporal context demands of different embodied navigation tasks.
- Agentic systems for complex real-world applications require navigation modules with dynamically reconfigurable observation strategies that an upper-level planner can control.
- Fine-tuning large vision-language models (VLMs) solely on trajectory data can lead to a degradation of their open-world perception and general spatial reasoning capabilities.

## Method

- **Qwen-RobotNav**, based on Qwen3-VL, introduces a unified, ==parameterised interface for observation encoding==, allowing dynamic control over visual token budget, temporal decay, and camera weights.
- A training-time randomization strategy for all observation hyperparameters fosters robustness and generalization to diverse inference-time configurations.
- The model is co-trained with a mix of navigation trajectory data and navigation-related vision-language reasoning data to preserve open-world perception and mitigate VLM degradation.

## Results

- Qwen-RobotNav achieved state-of-the-art performance across various benchmarks, including **72.1%** Success Rate (SR) on VLN-CE R2R, **91.4** PDM Score (PDMS) on NAVSIM, and top tracking rates on EVT-Bench.
- An agentic navigation system built with Qwen3.6-Plus and Qwen-RobotNav achieved new state-of-the-art results on Embodied Question Answering tasks (e.g., **76.7** SR on HM-EQA) with significantly fewer navigation steps.
- The model demonstrated successful zero-shot transfer to real-world robots, performing precise vision-and-language navigation and fine-grained language-based control in unseen indoor environments.

## Takeaways

> [!tip] Key Insights
> - Reframing multi-task navigation as an observation context modeling problem, instead of solely an architectural design problem, allows for a more adaptive and efficient navigation primitive.
> - Leveraging natural-language tags for viewpoint and temporal identification, alongside embodiment-aware prompts, enables the LLM to utilize its pre-existing language grounding for spatial reasoning without complex architectural modifications.
> - Dynamically reconfigurable observation strategies allow a navigation model to act as a flexible primitive, enabling complex, long-horizon behaviors when orchestrated by an upper-level agentic planner.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Embodied navigation research encompasses a variety of tasks, including instruction following, point-goal navigation, object searching, target tracking, and autonomous driving. Recent advancements have led to the development of unified navigation models capable of handling multiple task families within a single architecture. However, a limitation of these models has been their fixed observation strategies. Existing approaches, such as uniform frame sub-sampling or sliding windows, embed a single assumption about the relevance of observations, which cannot be reconfigured at inference time. This inflexibility hinders their integration into more complex agentic systems, particularly for long-horizon scenarios like Embodied Question Answering (EQA), where an external planner needs to dynamically adjust the navigation model's behavior and context strategy. Different navigation tasks intrinsically demand distinct temporal context and memory approaches; for instance, instruction following requires long-term memory for distant landmarks, while target tracking relies on recent frames.

Qwen-RobotNav addresses this challenge by reframing multi-task navigation as an observation context modeling problem, rather than solely an architectural design issue. It aims to provide a base navigation model whose observation strategy can be externally reconfigured at inference time, enabling dynamic adaptation to diverse task requirements within an agentic framework. This positions Qwen-RobotNav as a configurable navigation primitive within the landscape of general-purpose embodied agents, contrasting with prior unified models that often lack this dynamic reconfigurability.

### 2. Key Objectives and Motivation

The primary objective of this work is to develop a scalable navigation model, Qwen-RobotNav, that can function as a reconfigurable component within agentic navigation systems. This objective is motivated by several considerations:

- **Dynamic Reconfigurability for Agentic Systems:** Agentic navigation systems require a base navigation model whose observation strategy can be externally reconfigured during inference. This is crucial because a single perception-planning backbone must support diverse tasks—such as instruction following, object search, target tracking, and autonomous driving—each demanding fundamentally different strategies for consuming visual input streams. Existing models often employ fixed observation encoding methods, limiting their adaptability.
- **Unified Waypoint Prediction with Parameterized Interface:** The model aims to formulate all navigation tasks as unified waypoint trajectory prediction, exposing a parameterized interface. This interface consists of two complementary dimensions:
 1. **Multiple Task Modes:** Allowing an upper-level planner to select appropriate navigation behaviors (e.g., VLN, PointNav, ObjNav, Tracking) for specific sub-goals.
 2. **Controllable Observation Parameters:** Enabling dynamic adjustment of how visual history is encoded via parameters such as visual token budget, temporal decay, and per-camera importance weighting, without requiring task-specific retraining.
- **Robustness through Training-Time Randomization:** A key motivation is to ensure that Qwen-RobotNav is robust to any inference-time configuration without requiring architectural modifications or task-specific tuning. This is achieved by randomizing all observation parameters during training, preventing the model from overfitting to a fixed observation regime.
- **Preserving Open-World Perception via Co-training:** The developers aim to prevent the degradation of open-world perception that can occur when vision-language models are adapted solely to action prediction. Co-training with navigation-related vision-language data is designed to maintain the language understanding capabilities of the underlying large vision-language model (Qwen3-VL), which are essential for interpreting natural-language tags and prompts.
- **Enabling Long-Horizon, Complex Behaviors:** By providing a reconfigurable interface, Qwen-RobotNav is designed to be a natural building block for agentic systems. An upper-level planner can decompose complex goals into sub-tasks and dynamically switch Qwen-RobotNav’s task mode and context strategy mid-episode, thereby composing intricate behaviors from repeated calls to the same model. This hierarchical approach aims to enhance performance on long-horizon scenarios like Embodied Question Answering.
- **Cross-Embodiment and Zero-Shot Generalization:** The work seeks to achieve strong zero-shot generalization to real-world robots and diverse environments, including autonomous driving scenarios, through its joint multi-task training and embodiment-aware prompt design.

### 3. Methodology and Approach

Qwen-RobotNav is built upon the Qwen3-VL architecture and incorporates several methodological innovations to achieve its objectives:

#### 3.1. Model Architecture

- **Backbone:** Qwen-RobotNav inherits the Qwen3-VL architecture, a vision-language model (VLM), and augments it with a lightweight action head.
- **Vision Encoder:** Utilizes a SigLIP-2 Vision Transformer with dynamic-resolution support via 2D-RoPE. A two-layer MLP patch merger compresses spatial tokens, and a DeepStack mechanism injects visual tokens from multiple ViT layers into early LLM layers to preserve multi-level visual representations.
- **Language Backbone:** The LLM processes concatenated visual and language tokens. It benefits from rich world knowledge, spatial understanding, and cross-modal reasoning acquired during large-scale vision-language pretraining.
- **Action Head:** A lightweight 4-layer MLP maps the LLM's final hidden state to a 24-dimensional output, encoding K=8 waypoints, each with 3 degrees of freedom (x, y, θ). This design keeps most spatial reasoning within the LLM.

#### 3.2. Task-Adaptive Observation Encoding

The core innovation is a unified, parameterised interface for observation encoding, controlled by four orthogonal axes:

- **Visual Token Budget (B):** Total tokens across all cameras and timesteps (range: 2048–4096).
- **Temporal Decay (γ):** Recency bias toward the latest frames (range:).
- **Camera Weights (w_c):** Per-camera importance multipliers (e.g., front camera highest weight).
- **Frame Sample Mode (m):** Random (global coverage) or Latest (recency window).

The **Token Allocation Algorithm** involves:
1. Sub-sampling T' frames based on `m`.
2. Computing temporal weights ω_t based on `γ`.
3. Forming a joint weight matrix `W[t, c] = ω_t * w_c`.
4. A constrained allocation function `CONSTRAINEDALLOC` distributes the total budget `B` proportionally to `W`, ensuring each cell (t, c) receives a minimum `b_min` and does not exceed `b_max`.
5. Allocated tokens determine image pixel resolution, and images are resized to maintain aspect ratio.
- **Training-Time Randomization:** During training, all continuous observation hyperparameters (B, γ, w_c, b_min, b_max) are independently randomized per sample. The frame sample mode (`m`) alternates randomly. This ensures robustness to diverse inference configurations.

#### 3.3. Viewpoint and Temporal Identification

Visual tokens are interleaved with natural-language tags (e.g., "Time step t Camera: Front <image>") to explicitly communicate camera identity and temporal order to the LLM. This leverages Qwen3-VL's existing language grounding without architectural modifications.

#### 3.4. Embodiment-Aware Prompt Design

Natural-language preambles in the system prompt (e.g., "Imagine you are a robot..." or "Imagine you are a car...") differentiate between physical platforms, allowing the model to leverage platform-specific world knowledge.

#### 3.5. Action Planning

The 4-layer MLP action head predicts 8 waypoints (x, y, θ). Waypoints are normalized during training and denormalized at inference. MSE loss is used for trajectory regression.

#### 3.6. Training Strategy

- **Training Objective:** A composite loss combines trajectory regression (L_traj) and next-token prediction loss for vision-language alignment (L_VL), with λ=1.0.
- **Configuration Randomization:** All task-adaptive interface parameters are randomly sampled for each training sample to ensure generalization.
- **Co-training:** The corpus comprises 85% navigation trajectory planning data and 15% navigation-related vision-language reasoning data. This mixture aims to prevent degradation of open-world perception while acquiring embodied competence.
- **Optimization:** AdamW optimizer, cosine learning rate schedule with warm-up, gradient clipping. Fine-tuned from Qwen3-VL checkpoint.

#### 3.7. Agentic Navigation System

Qwen-RobotNav is designed as a core module for hierarchical agentic systems:
- **Upper-Level Planner:** An external LLM (e.g., Qwen3.6-Plus) decomposes long-horizon goals into sub-goals, selects task modes (τ_i), and specifies observation configurations (Φ_i) for Qwen-RobotNav.
- **Agent-Facing Interface:** Qwen-RobotNav exposes task modes (VLN, PointNav, ObjNav, Tracking) and observation control parameters (B, γ, m).
- **Navigation Harness:** Converts Qwen-RobotNav rollouts into compact evidence records (e.g., subgoal, task_mode, progress, salient observations, outcome, key_frames). This information is stored in a two-level memory: single-episode summary and a persistent "evidence notebook" for long-horizon reasoning. Auxiliary vision tools (object detection, scene understanding) can also be invoked by the planner.

#### 3.8. Data

The training corpus totals 15.6M samples, divided into:
- **Navigation Trajectory Planning (85%):**
 - **Instruction Following (5.63M):** VLN-CE R2R and RxR, with image quality enhancement (Qwen-Image-Edit) and LLM-based instruction refinement.
 - **Point-Goal Navigation (984K):** Matterport3D and HM3D, organized into difficulty curricula (direct-approach, short-range, long-range) and command-based motion primitives.
 - **Object-Goal Navigation (2.0M):** Matterport3D, HM3D, HM3D-OVON; uses skeleton-based exploration trajectories and VLM-based open-vocabulary goal annotation.
 - **Target Tracking (1.486M):** EVT-Bench, focused on Single Target Tracking.
 - **Autonomous Driving (3.2M):** nuScenes and OpenScene; cast as waypoint prediction conditioned on multimodal observations and configurable auxiliary priors.
- **Autogenerated Navigation Data (40K):** A text-to-video pipeline generates photorealistic instruction-following and target-tracking videos, filtered by VLMs and kinematic analysis.
- **Navigation Data Augmentation:** Instruction refinement (LLM paraphrasing), image quality enhancement (diffusion-based style transfer), observation and camera augmentation (height, FoV, aspect ratio randomization), and speed augmentation.
- **Vision Language Data (15%):**
 - **General VL Data (∼1.0M):** VQAv2, DVQA, FigureQA, CLEVR, image captioning, visual grounding (RefCOCO, COCO, Objects365), multi-image reasoning, etc.
 - **Navigation-Specific Reasoning (873K):** Derived from VLN trajectory data: free-form QA at key decision points, and structured multi-perspective reasoning (history, scene analysis, instruction progress, action reasoning).
 - **Discrete Multi-Round Navigation Data (362K):** VLN datasets (CVDN, SOON, REVERIE, SRDF) reformulated into multi-round, multi-image conversation format for single-step action prediction.

### 4. Main Findings and Results

Qwen-RobotNav demonstrated performance across various navigation benchmarks and real-world deployments.

#### 4.1. Deployment

- **Latency Comparison:** Remote-server deployment (196 ms average, 5.1 Hz) achieved slightly lower average end-to-end latency than on-device inference (204 ms average, 4.9 Hz) on Unitree Go2. Remote deployment showed higher latency variance due to network conditions, while on-device inference (using Jetson Thor with FP8 quantization and TensorRT) offered more consistent latency.

#### 4.2. Evaluation on Benchmarks

- **Vision-and-Language Navigation (VLN-CE):**
 - **R2R Val-Unseen (Panoramic):** Qwen-RobotNav-8B achieved 72.1% Success Rate (SR) and 66.6% Success weighted by Path Length (SPL), outperforming NavFoM by 10.4% SR and ABot-N0 by 5.7% SR.
 - **RxR Val-Unseen (Panoramic):** Qwen-RobotNav-8B reached 76.5% SR and 72.5% Normalized Dynamic Time Warping (nDTW), surpassing NavFoM by 12.1% SR and ABot-N0 by 7.2% SR.
 - **Monocular Setting:** Qwen-RobotNav-4B achieved 66.9% SR and 60.5% SPL on R2R, exceeding DualVLN by 2.6% SR and 2.0% SPL. Qwen-RobotNav-8B achieved 73.4% SR and 63.5% SPL on RxR, outperforming DualVLN by 12.0% SR and 11.7% SPL.
- **VLNVerse:**
 - **Fine-grained:** Qwen-RobotNav-8B achieved 63.75% SR and 57.93% SPL, surpassing NavFoM by 12.2% SR and 25.5% SPL.
 - **Coarse-grained:** Qwen-RobotNav-8B reached 46.59% SR and 41.54% SPL, outperforming NavFoM by 8.6% SR and 18.4% SPL. The SPL margins were larger than SR margins, indicating more efficient paths.
- **VLN-PE (Flash Controller):** Qwen-RobotNav-8B achieved 65.50% SR and 61.19% SPL, surpassing InternVLA-N1 by 5.1% SR and 6.3% SPL, also attaining the lowest Navigation Error (3.73 m) and highest Oracle Success Rate (72.99%).
- **Object-Goal Navigation (MP3D & HM3D):**
 - **MP3D (Closed-vocabulary):** Qwen-RobotNav-4B achieved 52.2% SR, surpassing all depth-based baselines like CogNav (46.6%) and WMNav (45.4%), despite operating from RGB only.
 - **HM3D v2 (Closed-vocabulary):** Qwen-RobotNav-4B reached 75.6% SR, surpassing HM3D v1 results of vision-only Uni-NaVid (73.7%).
 - **HM3D-OVON (Open-vocabulary):** Qwen-RobotNav-4B achieved 57.7% / 60.1% / 53.1% SR on Seen / Synonyms / Unseen splits, achieving the best SR on two splits and competitive on Unseen, using only a single forward-facing camera against panoramic ABot-N0. Lower SPL reflected a reach-first exploration behavior.
- **Active Visual Tracking (EVT-Bench):** Qwen-RobotNav achieved tracking rates of 90.0% (4B) and 89.7% (8B), outperforming ABot-N0 (87.6%), NavFoM (80.5%), and TrackVLA++ (81.0%). Qwen-RobotNav-8B also achieved a low collision rate (5.70% CR). Its success rate was noted to be slightly lower than specialist trackers.
- **Embodied Question Answering (EQA):** A Qwen3.6-Plus+Qwen-RobotNav agentic system achieved state-of-the-art performance on HM-EQA (76.7 SR), MT-HM3D (54.4 SR), and EXPRESS-Bench (79.27 LLM Score), improving over FAST-EQA by 7.5 points on HM-EQA and 10.57 points on EXPRESS-Bench. It also reduced normalized equivalent steps, indicating more efficient exploration.
- **Autonomous Driving (NAVSIM):** Qwen-RobotNav-4B achieved 91.4 PDMS (PDM Score), outperforming NavFoM by 7.1 points and AutoVLA by 2.3 points among vision-language driving models. It showed strong Navigation Compliance (99.8 NC) and Time-to-Collision (98.5 TTC). Providing historical ego-status priors led to over 11-point gain in PDMS.
- **Autonomous Driving (AlpaSim):** In a zero-shot setting, Qwen-RobotNav achieved non-trivial closed-loop performance, with 8B showing improvement in off-road rate (34.0% to 27.0%) and AlpaSim score (0.15 to 0.17) compared to 4B, indicating better stability and generalization.

#### 4.3. Ablation Study

- **Training Data Scale:** Performance generally improved with increased navigation training data, particularly for long-horizon tasks like VLN-CE RxR. Shorter-horizon tasks like tracking showed early saturation.
- **Token Budget (B) and Temporal Decay (γ):** Increasing `B` generally improved performance, with diminishing returns at very high budgets. Larger `γ` (more recency bias) also generally improved performance for tasks like VLN-CE, but strict success and path quality metrics sometimes saturated or fluctuated at extreme values, reflecting a trade-off between current scene resolution and early-history context.

#### 4.4. Real-World Deployment Results

- **Unseen Exhibition Hall:** Qwen-RobotNav successfully navigated a quadruped robot 21.78m from a living room to a medical room based on pure language instructions, leveraging visual landmarks. It also accurately executed a reverse language command, retracing its path.
- **Indoor Apartment Setting:** Demonstrated precise language-based control, such as stopping at a specific nightstand or performing detours as instructed, across multiple rooms.
- **Agentic Navigation Interface Demo:** On a real robot, an agentic system using Qwen-RobotNav answered an open-ended request ("check for a green umbrella at Cotti Coffee"), demonstrating task decomposition, landmark-based localization, memory updates, and evidence-grounded responses in a real-world, long-horizon scenario.

### 5. Significance and Potential Impact

Qwen-RobotNav introduces a reconfigurable navigation primitive through its parameterised observation encoding, distinguishing it from prior unified navigation models. This approach reframes multi-task navigation as a context modeling problem, enabling a single model to dynamically adapt its visual perception strategy for diverse sub-tasks, from instruction following to target tracking and autonomous driving.

The significance of this work lies in several areas:

- **Dynamic Adaptability in Agentic Systems:** By providing an externally controllable interface for observation strategy, Qwen-RobotNav facilitates the development of more sophisticated agentic systems. An upper-level planner can seamlessly switch between global-history modes for exploration and recency-focused modes for precise local maneuvering, allowing complex long-horizon behaviors to emerge from the composition of simpler, well-defined working modes. This contributes to bridging the gap between high-level planning and low-level execution in embodied AI.
- **Enhanced Generalization and Robustness:** Training-time randomization over all observation parameters ensures that the model is robust to varied inference-time configurations without requiring task-specific retraining. This design principle improves the model's generalization capabilities across different scenarios and input modalities (e.g., monocular vs. panoramic).
- **Architectural Efficiency and Open-World Grounding:** The use of natural-language tags for viewpoint and temporal identification demonstrates that architectural simplicity can be leveraged effectively. By communicating structural information through ordinary vocabulary tokens, the model preserves and utilizes its open-world language grounding from the Qwen3-VL backbone, without additional architectural complexity or parameters.
- **State-of-the-Art Performance:** Qwen-RobotNav achieves new state-of-the-art or competitive results across major navigation benchmarks, including VLN-CE, VLNVerse, VLN-PE, various Object-Goal Navigation tasks, Active Visual Tracking, and Embodied Question Answering. Its performance in autonomous driving (NAVSIM) also sets new benchmarks among vision-language models.
- **Real-World Applicability:** The demonstrated zero-shot transfer to real-world robots in previously unseen and diverse environments, including executing fine-grained verbal commands and operating within a long-horizon agentic loop, confirms the practical applicability and reliability of the unified design beyond simulated settings.

The concept of treating observation context as a first-class, externally controllable degree of freedom offers a promising direction for future navigation foundation models. This could lead to more versatile, deployable, and intelligent embodied agents capable of robustly navigating and interacting with the physical world under varied and complex conditions.
