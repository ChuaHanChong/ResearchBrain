# Agent RL Scaling Law: Agent RL with Spontaneous Code Execution for Mathematical Problem Solving

> [!summary] Summary
> Researchers developed ZeroTIR, a reinforcement learning framework enabling base Large Language Models to spontaneously utilize a Python code execution environment for mathematical problem-solving, establishing "Agent RL Scaling Law" which details predictable increases in code execution, response length, and task accuracy with training progression. This method allows 7B models to achieve 52.3% average accuracy on AIME24, AIME25, and MATH500 benchmarks, surpassing specialized supervised fine-tuned models.

## Problem

- Large Language Models (LLMs) inherently struggle with precise, multi-step mathematical reasoning, often producing computationally incorrect outputs.
- Existing tool-integrated reasoning (TIR) methods typically rely on extensive supervised fine-tuning data or explicit prompt engineering to trigger tool use.
- There is a lack of understanding regarding how LLMs can autonomously acquire and integrate external tools purely through outcome-based reinforcement learning (ZeroRL) without prior examples.

## Method

- Proposes **ZeroTIR**, an RL framework that trains base LLMs to spontaneously generate and ==execute Python code== using policy gradient algorithms like PPO and Reinforce++.
- Implements a decoupled, asynchronous Python code execution environment and an efficient dynamic stop-token-based mechanism for iterative reasoning and code integration.
- Incorporates training stability and efficiency techniques such as replay buffer filtering and an asynchronous rollout and pipelining framework compatible with OpenRLHF.

## Results

- The **7B** ZTRL model achieves an average performance of **52.3%** on AIME24, AIME25, and MATH500 benchmarks, significantly outperforming non-tool ZeroRL baselines (e.g., **39.1%**).
- ZTRL, trained from a general base model, surpasses specialized SFT-based TIR models like Qwen 2.5 Math Instruct (**41.6%** average) on mathematical reasoning tasks.
- Performance consistently scales with model size (**32B** outperforms **7B**, which outperforms **1.5B**) and allowed interaction budget, with Reinforce++ showing faster convergence than PPO for similar final accuracies.

## Takeaways

> [!tip] Key Insights
> - The work identifies "Agent RL Scaling Law," demonstrating a predictable positive correlation between RL training steps, spontaneous code execution frequency, response length, and mathematical task accuracy.
> - LLM agents can learn the utility of external tools and integrate them into their reasoning process purely from outcome-based rewards, without needing supervised tool-use examples.
> - Effective tool use often converges to efficient strategies involving few, highly impactful single-call interactions, with over 90% of correct code-using responses utilizing just one execution.
