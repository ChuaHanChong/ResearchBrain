# Agent RL Scaling Law: Agent RL with Spontaneous Code Execution for Mathematical Problem Solving

> [!summary] Summary
> Researchers developed ZeroTIR, a reinforcement learning framework enabling base Large Language Models to spontaneously utilize a Python code execution environment for mathematical problem-solving, establishing "Agent RL Scaling Law" which details predictable increases in code execution, response length, and task accuracy with training progression. This method allows 7B models to achieve 52.3% average accuracy on AIME24, AIME25, and MATH500 benchmarks, surpassing specialized supervised fine-tuned models.

## Problem

- Large Language Models (LLMs) inherently struggle with precise, multi-step mathematical reasoning, often producing computationally incorrect outputs.
- Existing tool-integrated reasoning (TIR) methods typically rely on extensive supervised fine-tuning data or explicit prompt engineering to trigger tool use.
- There is a lack of understanding regarding how LLMs can autonomously acquire and integrate external tools purely through outcome-based reinforcement learning (ZeroRL) without prior examples.

## Method

- Proposes **ZeroTIR**, an RL framework that trains base LLMs to spontaneously generate and ==execute Python code== using policy gradient algorithms like PPO and Reinforce++.
- Implements a decoupled, asynchronous Python code execution environment and an efficient dynamic stop-token-based mechanism for iterative reasoning and code integration.
- Incorporates training stability and efficiency techniques such as replay buffer filtering and an asynchronous rollout and pipelining framework compatible with OpenRLHF.

## Results

- The **7B** ZTRL model achieves an average performance of **52.3%** on AIME24, AIME25, and MATH500 benchmarks, significantly outperforming non-tool ZeroRL baselines (e.g., **39.1%**).
- ZTRL, trained from a general base model, surpasses specialized SFT-based TIR models like Qwen 2.5 Math Instruct (**41.6%** average) on mathematical reasoning tasks.
- Performance consistently scales with model size (**32B** outperforms **7B**, which outperforms **1.5B**) and allowed interaction budget, with Reinforce++ showing faster convergence than PPO for similar final accuracies.

## Takeaways

> [!tip] Key Insights
> - The work identifies "Agent RL Scaling Law," demonstrating a predictable positive correlation between RL training steps, spontaneous code execution frequency, response length, and mathematical task accuracy.
> - LLM agents can learn the utility of external tools and integrate them into their reasoning process purely from outcome-based rewards, without needing supervised tool-use examples.
> - Effective tool use often converges to efficient strategies involving few, highly impactful single-call interactions, with over 90% of correct code-using responses utilizing just one execution.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This research is situated at the forefront of efforts to enhance Large Language Models' (LLMs) reasoning capabilities, particularly in domains requiring precise computation like mathematics. LLMs, despite their remarkable abilities, inherently struggle with tasks demanding multi-step, verifiable reasoning due to their next-token prediction nature, which prioritizes high-likelihood generations over computational correctness.

The broader landscape features several existing strategies to address this:
- **Supervised Fine-Tuning (SFT)**: While effective, SFT requires extensive, high-quality, and often costly trajectory data. It can also lead to overfitting and limit a model's capacity to generalize or explore novel problem-solving strategies.
- **Tool-Integrated Reasoning (TIR)**: This approach augments LLMs with external tools (calculators, search engines, code interpreters). Existing TIR methods typically involve explicit prompt engineering, specific trigger mechanisms, or SFT on datasets containing tool invocation examples (e.g., Qwen2.5-Math, Toolformer). These methods guide or compel tool use according to predefined patterns.

This paper directly addresses a critical gap within this landscape: the autonomous acquisition of *spontaneous* tool use by LLMs. Instead of relying on supervised tool-use examples or predefined prompt structures, the authors explore how an LLM agent can learn *from a base model* to leverage a code execution environment solely through Reinforcement Learning (RL) based on outcome rewards. This approach, termed "ZeroTIR" (Zero-shot Tool-Integrated Reasoning), builds upon the "ZeroRL" paradigm (e.g., DeepSeek-R1), which focuses on scaling LLM reasoning capabilities directly from base models using only outcome-based rewards, fostering emergent abilities like self-correction.

The work acknowledges contemporaneous research, such as TORL (Li et al., 2025), which also explores code execution for mathematical tasks using ZeroRL. However, this paper differentiates itself by focusing on training from a *base LLM* rather than a fine-tuned or math-specialized model. This distinction is crucial as it allows for the observation and characterization of fundamental "Agent RL Scaling Law" that might be obscured when starting from models with pre-existing tooling capabilities or domain-specific fine-tuning. By providing a comprehensive and reproducible analysis of these scaling laws, the paper aims to offer foundational insights into how autonomous tool use is acquired and scales within Agent RL, serving as a benchmark for future studies.

### 2. Key Objectives and Motivation

The central objective of this research is to investigate how Large Language Models, initialized from base models, can *spontaneously* learn to leverage an external Python code execution environment through Reinforcement Learning. The authors term this process "ZeroTIR" (Zero-shot Tool-Integrated Reasoning) and aim to understand its underlying dynamics.

The core motivation stems from several critical observations and needs:
1. **Bridging the Gap in Mathematical Reasoning:** LLMs frequently falter on mathematical tasks requiring precise, multi-step computation. Their inherent reliance on next-token prediction often leads to computationally incorrect outputs, necessitating external, verifiable tools.
2. **Moving Beyond Supervised Tool Use:** While existing Tool-Integrated Reasoning (TIR) methods exist, they often depend on extensive supervised fine-tuning data or explicit prompting to trigger tool use. The authors seek to explore a more autonomous paradigm where the agent learns *when* and *how* to use a tool purely through task success signals, without prior examples of tool invocation.
3. **Understanding Emergent Abilities in ZeroRL:** Building on the success of ZeroRL in fostering emergent reasoning abilities (like self-correction), the paper aims to extend this paradigm to tool use. This involves understanding how an LLM can infer the utility of an external tool and integrate it into its reasoning process based solely on outcome-based rewards.
4. **Identifying "Agent RL Scaling Law":** The central hypothesis is that the learning process for autonomous tool utilization adheres to predictable patterns, which the authors term "Agent RL Scaling Law." A key objective is to identify and characterize these laws, particularly how metrics like code execution frequency, response length, and task accuracy scale with training progress.
5. **Developing a Robust and Reproducible Framework:** The motivation includes proposing and implementing an efficient framework, ARL, that enables training base LLMs for spontaneous code execution, compatible with community-mainstream RL training frameworks.
6. **Empirical Validation and Benchmarking:** The study aims to provide extensive empirical evidence that ZeroTIR significantly outperforms non-tool ZeroRL baselines and even SFT-based TIR methods on challenging mathematical benchmarks, thereby offering a reproducible benchmark for future research.

In essence, the paper seeks to provide a foundational understanding of the dynamics through which LLM agents autonomously acquire and integrate tools, paving the way for more capable and self-sufficient AI systems.

### 3. Methodology and Approach

The methodology centers on **ZeroTIR**, a framework designed to train base LLMs to autonomously utilize a Python code execution environment for mathematical problem-solving through reinforcement learning.

#### 3.1. RL Formulation for Spontaneous Code Execution

- **Algorithms:** The framework primarily employs policy gradient algorithms, including Proximal Policy Optimization (PPO) and REINFORCE variants like Reinforce++.
- **PPO Adaptation:** Special consideration is given to PPO, an actor-critic method. The value function $V_\phi(s_t)$ is specifically *not* trained on states corresponding to environment-generated tokens (e.g., code execution outputs), as these are not policy-generated actions. Similarly, advantage estimation ($\hat{A}_t$), particularly with Generalized Advantage Estimation (GAE), is adjusted to mask the influence of environment feedback tokens, often by setting $\hat{A}_t=0$ at such positions during policy loss calculation, preventing biased updates. The authors note that setting the GAE parameter $\lambda$ to 1 did not affect results, simplifying this aspect.
- **REINFORCE Adaptation:** REINFORCE-style algorithms directly estimate policy gradients using sampled trajectories. Here, the advantage $\hat{A}_t$ is calculated as the discounted Monte Carlo return $G_t$ minus a baseline $b(s_t)$. Careful reward attribution ensures only policy-generated actions (LLM tokens) contribute to the gradient. Reinforce++ is noted for incorporating advanced baseline techniques.
- **Overall Objective:** Regardless of the algorithm, the objective is to maximize the expected outcome-based reward $R(x,y)$, regularized by a KL divergence term from a reference policy $\pi_{ref}$ to maintain stability. The reward $R(x,y)$ is based on the final outcome of the problem, incorporating the full trajectory of interactions with the code environment.

#### 3.2. Training Stability and Efficiency Techniques

- **Replay Buffer Filtering:** To improve stability and focus learning on informative samples, the framework implements a replay buffer filtering mechanism. Multiple responses for the same prompt are grouped, and only those with final answer accuracies between a low threshold (0.2) and a high threshold (0.8) are prioritized. This avoids learning from already mastered or overly difficult problems.
- **Efficient Interaction Mechanism (Algorithm 1):** A dynamic stop-token-based state-machine approach manages the iterative process of reasoning, code generation, execution, and feedback integration (Figure 3). Instead of generating a complete sequence and then parsing for code, the LLM uses dynamic stop tokens (e.g., `'''python`, `'''`) to pause generation, extract code, execute it in the external environment, and then inject the results back into the context for further generation. This is significantly more efficient than post-hoc parsing. A maximum call limit ($N_{max}$) can be enforced for experimental control, with a notification injected into the context if the limit is reached.

#### 3.3. Environment Interaction Frameworks

- **Decoupled Code Execution Environment:** To ensure robustness and scalability, the Python code execution environment is implemented as an independent, network-accessible service. This decoupled architecture prevents training process crashes due to service failures, improves maintainability, and allows for independent scaling using standard web serving technologies (Flask, Gunicorn, Nginx) and client-side rate limiting (`aiolimiter`). The RL framework interacts with this service via standard HTTP calls.
- **Asynchronous Rollout and Pipelining:** For large-scale experiments and improved throughput, an enhanced interaction framework within OpenRLHF is used, featuring asynchronous rollout and pipelining. Rollout actors manage asynchronous queues pre-filled with generated experiences. Data retrieval and new task submission occur concurrently, allowing experience generation to proceed asynchronously while the trainer updates parameters. An adaptive mechanism handles data shortages in the replay buffer. This asynchronous approach significantly speeds up training (up to 4 times faster than synchronous methods).

In summary, the methodology combines advanced RL algorithms with robust engineering solutions for efficient and stable training, enabling the study of spontaneous tool acquisition in LLMs.

### 4. Main Findings and Results

The paper presents several key findings, primarily centered around the "Agent RL Scaling Law" and the comparative performance of their ZeroTIR approach (ZTRL).

#### 4.1. Agent RL Scaling Law

- **Predictable Scaling Dynamics:** The central contribution is the demonstration that as RL training progresses, key metrics scale predictably. There is a strong positive correlation where increased training steps lead to increases in spontaneous code execution frequency, average response length, and crucially, final task accuracy (Figure 1). This suggests a quantifiable relationship between computational effort and the emergence of effective, tool-augmented reasoning.
- **Code Usage Evolution:** Training dynamics (Figure 4) show that code usage (Code Proportion) initially dips, then significantly increases for TIR-enabled models, indicating the agent learns the utility of the tool. The "Code in Correct" metric rises sharply with "Raw Reward Avg," empirically linking effective tool use to task success.
- **Response Length:** Average response length generally increases with training, especially for larger models, correlating with the inclusion of code and execution outputs.
- **Tool Call Efficiency:** While higher interaction budgets ($N_{max}$) improve performance, the "Code Count Avg" often stabilizes between 1 and 2 calls per response. This indicates that agents predominantly learn strategies involving few, highly effective interactions. Over 90% of correct responses utilizing code use only a single execution, suggesting the model converges towards efficient, high-utility single-call strategies rather than complex multi-step interactions.

#### 4.2. Comparative Performance Analysis (Table 1)

- **Superiority over Baselines:** The 7B ZTRL model achieves an average performance of 52.3% on AIME24, AIME25, and MATH500. This significantly surpasses non-tool ZeroRL baselines (e.g., SimpleRL-Zero at 39.1%, Eurus-2-PRIME at 39.7%).
- **Outperforming TIR with Specialized Models:** ZTRL, trained from the *general* Qwen 2.5 Base model, outperforms the specialized Qwen 2.5 Math Instruct model even when the latter uses its integrated TIR capability (41.6% average for Math Instruct TIR vs. 52.3% for ZTRL).
- **Comparison with Contemporaneous Work (TORL):** ZTRL (54.0% average on AIME24, AIME25, MATH500) also slightly surpasses TORL (51.8%), despite TORL utilizing a math-specialized Qwen 2.5 Math Base model for training. This highlights the robustness and effectiveness of the ZeroTIR implementation.
- **Code Usage Correlation:** The high code usage proportion for ZTRL (90%) is comparable to TORL (83%) and correlates strongly with achieved performance, reinforcing the observed scaling law.

#### 4.3. Hyperparameter Analysis (Table 2 & 3)

- **Interaction Cap ($N_{max}$):** A strong monotonic relationship exists between the allowed interaction cap and accuracy, with gains tapering beyond 4 calls. This confirms that additional tool use improves problem-solving.
- **Model Scale:** Performance consistently grows with model size (32B outperforms 7B, which outperforms 1.5B), while the code usage ratio rises non-linearly, implying larger models may use code more efficiently or solve more tasks internally.
- **Algorithm Efficiency:** Reinforce++ converges faster (approx. 300 steps sooner) than PPO for 7B models, reaching similar final accuracies, making it more efficient.
- **Dataset Influence:** DeepMath training yields a small but consistent edge, particularly sharpening "peak reasoning" on certain datasets (e.g., HMMT Feb. 25 Max score). Heterogeneous contest data (Orz-57k) improves "majority robustness."
- **Decoding Entropy:** Higher top-p values (e.g., 1.0 vs 0.7) can increase peak scores (Max), but may reduce robustness (Maj, Avg), suggesting a trade-off.
- **Training vs. Inference Interactions (Figure 5 & 6):** Allowing more interactions at inference time generally yields higher scores, but the benefits diminish. Models trained with higher interaction budgets benefit most from generous inference budgets, but can be slightly worse in one-shot inference scenarios. This suggests aligning training and deployment budgets is crucial.

In summary, the results convincingly demonstrate that ZeroTIR successfully enables base LLMs to spontaneously use code for mathematical reasoning, with its performance scaling predictably with training effort, model size, and interaction budgets.

### 5. Significance and Potential Impact

The research presented in this paper carries significant implications for the development of more capable and autonomous Large Language Models, particularly in domains requiring precise and verifiable reasoning.

#### 5.1. Foundational Understanding of Emergent Tool Use

The most profound impact lies in the identification and characterization of **Agent RL Scaling Law** for spontaneous code execution. This provides a novel, empirical framework for understanding *how* LLMs autonomously acquire and integrate external tools through reinforcement learning. By demonstrating predictable scaling dynamics across training steps, code usage frequency, response length, and task accuracy, the work moves beyond anecdotal observations to a more quantifiable understanding of emergent tool-using behaviors. This foundational insight can guide future theoretical and empirical studies into the mechanisms of agentic intelligence.

#### 5.2. Advancement in Agent Reinforcement Learning

This work significantly advances the "ZeroRL" paradigm by extending it to the complex task of spontaneous tool integration. It showcases that base LLMs, without any prior supervised fine-tuning on tool use, can learn to leverage external environments effectively through outcome-based rewards alone. This pushes the boundaries of what is achievable with reinforcement learning for LLMs, demonstrating a path towards AI agents that can self-learn complex skills and adapt to new computational challenges.

#### 5.3. Enhanced Mathematical Reasoning Capabilities

By enabling LLMs to spontaneously generate and execute Python code, ZeroTIR provides a powerful mechanism to overcome inherent limitations in mathematical reasoning. The demonstrated performance surpassing non-tool baselines and even specialized, SFT-based TIR models (like Qwen 2.5 Math Instruct) underscores its practical utility. This capability is critical for applications requiring high precision and verifiability, such as scientific discovery, engineering design, and financial modeling.

#### 5.4. Robust and Reproducible Framework

The proposed ARL framework, featuring a decoupled code execution environment and an asynchronous rollout pipeline, offers a robust, scalable, and efficient solution for training tool-integrated agents. Its compatibility with mainstream community RL training frameworks (OpenRLHF, Open-Reasoner-Zero) and the release of code foster reproducibility and accelerate community research. This engineering contribution lowers the barrier for other researchers to experiment with and build upon these methodologies.

#### 5.5. Guidance for Model Development and Deployment

The detailed analysis of hyperparameters, including interaction caps and the interplay between training and inference budgets, provides valuable guidance for practitioners. The finding that models often converge to efficient, single-call tool usage strategies, even with larger budgets, informs the design of more effective training curricula and interaction policies. The insights into algorithm efficiency (e.g., Reinforce++'s faster convergence) and dataset choice (e.g., DeepMath for peak reasoning) are directly applicable to optimizing resource allocation in LLM training.

#### 5.6. Future Research Directions

The paper explicitly opens avenues for future work, including a more rigorous *quantitative* analysis of the precise mathematical form of these scaling relationships. It also encourages exploring scenarios with entirely unconstrained interaction counts and investigating performance in even more complex agentic environments. This highlights that the current work is a crucial stepping stone towards fully autonomous and adaptive LLM agents.

In conclusion, this research marks a significant step forward in understanding and engineering LLMs capable of autonomous tool integration. Its insights into "Agent RL Scaling Law" provide a new lens for viewing the development of agentic intelligence, with far-reaching implications for the design and application of future AI systems.
