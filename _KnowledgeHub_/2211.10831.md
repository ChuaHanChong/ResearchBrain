# Joint Embedding Predictive Architectures Focus on Slow Features

> [!summary] Summary
> Joint Embedding Predictive Architectures (JEPA) demonstrate efficacy in learning world models by predicting latent representations of future states from image and action sequences. While proficient at ignoring dynamic visual noise, JEPA methods are shown to struggle with static background features, which they can trivially learn, consequently neglecting dynamic objects important for decision-making.

## Problem

- Traditional world models, trained with pixel-level reconstruction objectives, often suffer from 'object-vanishing,' failing to inherently prioritize important dynamic objects over static background elements.
- These models can inefficiently allocate learning capacity to irrelevant details, potentially hindering the learning of salient features crucial for decision-making in reinforcement learning tasks.
- There is a need to evaluate reconstruction-free world model learning approaches, like Joint Embedding Predictive Architectures (JEPA), in environments with various visual distractors to understand their strengths and limitations.

## Method

- Implement and test Joint Embedding Predictive Architectures (JEPA) using ==VICReg== and SimCLR objectives to learn world models from offline image and action sequences without pixel-level reconstruction.
- Compare JEPA-based methods against a reconstruction-based generative architecture and an inverse dynamics modeling approach in a simplified moving dot environment with varying types and temporal characteristics of visual noise.
- Evaluate the quality of learned representations by training linear probes to recover known state properties, and provide theoretical analysis for observed failure modes.

## Results

- JEPA methods achieved low RMSE for dot location prediction in clean environments and with changing uniform/structured noise, outperforming reconstruction when hyperparameter tuning was not consistently applied.
- With fixed uniform or structured noise, JEPA methods largely failed, showing high RMSE values close to the random baseline, empirically confirming their bias towards static features.
- Inverse Dynamics Modeling demonstrated robust performance across all noise settings (changing and fixed), consistently focusing on action-relevant dynamic features, while reconstruction maintained efficacy with fixed noise where JEPA failed.

## Takeaways

> [!tip] Key Insights
> - JEPA methods (VICReg, SimCLR) effectively disregard dynamic visual noise that changes at each timestep, performing comparably or better than reconstruction-based methods in such scenarios.
> - A critical limitation of current JEPA formulations is their tendency to trivially minimize loss functions by focusing solely on static or 'slow' features (unchanging background noise), thereby neglecting dynamic, salient objects.
> - Unlike JEPA, reconstruction-based models compel learning representations of all pixel information (both static and dynamic), while Inverse Dynamics Modeling inherently focuses on features relevant to agent actions.
