# SG-Nav: Online 3D Scene Graph Prompting for LLM-based Zero-shot Object Navigation

> [!summary] Summary
> SG-Nav represents an explored 3D scene with an online hierarchical scene graph (object, group, room nodes) prompted to an LLM via hierarchical chain-of-thought, plus a graph-based re-perception mechanism that verifies detected goals. It surpasses prior zero-shot object navigation methods by over 10% success rate on MP3D, HM3D, and RoboTHOR, even beating supervised methods on MP3D.

## Problem

- Prior zero-shot navigation methods prompt LLMs with only text of spatially nearby object categories, discarding spatial and functional scene context needed for deep reasoning.
- Existing methods make LLM directly output frontier probabilities, an abstract task that underuses the LLM's reasoning capacity and yields unexplainable decisions.
- Conventional object navigation frameworks lack any mechanism to recover from perception errors, so a false-positive goal detection causes irreversible navigation failure.

## Method

- **Hierarchical 3D scene graph** built online with object, group, and room nodes, capturing affiliation and spatial/functional relationships as edges between observations.
- Incremental ==dense-connect-then-prune== edge construction using a batched LLM prompt that reduces complexity from ==O(m(m+n))== to ==O(m)== for m new and n existing nodes.
- **Hierarchical chain-of-thought** prompting over per-node subgraphs to predict goal-distance probabilities, interpolated to frontier scores, paired with a **graph-based re-perception** credibility accumulator.

## Results

- SG-Nav achieves **40.1/40.2%** SR on MP3D, **53.9/54.0%** on HM3D, and **47.3/47.5%** on RoboTHOR with LLaMA/GPT variants, beating prior zero-shot state-of-the-art VLFM by roughly **4-11** SR points.
- On MP3D, SG-Nav even outperforms supervised methods SemEXP (**36.0%** SR) and PONI (**31.8%** SR) despite requiring no training.
- Ablations show removing scene graph and re-perception drops MP3D SR from **40.1%** to **25.7%**, and removing only re-perception drops it to **36.5%**, confirming both components' contribution.

## Takeaways

> [!tip] Key Insights
> - Structuring LLM prompts as a hierarchical graph rather than flat text unlocks reasoning the LLM already has but flat-text prompting fails to elicit.
> - Giving an agent a mechanism to revoke a prior perception decision (re-perception) mainly boosts success rate, not path efficiency, since it still requires physically approaching to verify.
> - Batching relational queries into one LLM call instead of querying per-pair trades a larger single prompt for near-linear rather than quadratic scaling, a generally reusable trick for graph-construction-via-LLM.

## Detailed Report

### 1. Introduction

Object navigation is a fundamental capability for mobile robots operating in human environments. Enabling robots to find specific objects in unfamiliar settings based on natural language instructions remains a significant challenge in robotics. Traditional approaches rely on supervised learning methods that require extensive training and can only handle a limited set of predefined object categories.

SG-Nav is a novel framework that combines online 3D scene graph construction with large language model (LLM) reasoning to enable zero-shot object navigation. The system can navigate to objects specified in natural language without prior training on specific object categories or environments.

This figure illustrates the overall architecture of SG-Nav. The system builds a hierarchical scene graph from observations, divides it into subgraphs, employs hierarchical chain-of-thought prompting with an LLM to score exploration frontiers, and incorporates a re-perception mechanism to handle perception errors.

### 2. Background and Challenges

Object navigation involves guiding a robot to find a specific object in an unknown environment. Traditional approaches to this problem follow two main categories:

1. **End-to-end learning approaches**: These methods train neural networks to directly map observations to navigation actions using reinforcement learning. While they have shown promising results, they typically require substantial training data and struggle to generalize to new objects or environments.

2. **Modular approaches**: These methods separate perception, mapping, and planning into distinct modules. Although more interpretable, they often rely on supervised learning for object detection, limiting their ability to recognize novel objects.

Recent work has explored using large language models (LLMs) for zero-shot object navigation, leveraging their extensive world knowledge. However, these approaches face several challenges:

- **Context limitation**: LLMs have fixed context windows, making it difficult to represent complex 3D environments efficiently.
- **Spatial reasoning**: Purely text-based prompts struggle to capture spatial relationships between objects.
- **Perception errors**: Object recognition systems can make mistakes, leading to navigation failures if not properly handled.

### 3. SG-Nav Framework

SG-Nav addresses these challenges through three key innovations:

1. **Online 3D Scene Graph Construction**: A hierarchical representation that efficiently captures objects, groups, rooms, and their spatial relationships.
2. **Hierarchical Chain-of-Thought Prompting**: A structured prompting strategy that guides the LLM's reasoning about likely object locations.
3. **Re-Perception Mechanism**: A system that verifies object detections to handle perception errors.

The framework works as follows:

1. As the robot explores, it builds and updates a 3D scene graph from its observations.
2. This scene graph is divided into subgraphs that can fit within the LLM's context window.
3. Each subgraph is scored by the LLM based on the likelihood of the target object being nearby.
4. These scores are used to guide exploration toward promising areas.
5. When a candidate object is found, the re-perception mechanism verifies its identity.

### 4. Online 3D Scene Graph Construction

The 3D scene graph is a hierarchical representation with three types of nodes:

- **Object nodes**: Individual objects detected in the environment
- **Group nodes**: Collections of functionally related objects (e.g., "living room furniture")
- **Room nodes**: Spatial divisions of the environment (e.g., "kitchen," "bedroom")

Edges in the graph represent relationships between nodes, such as spatial relationships ("next to," "on top of") or functional relationships ("part of").

The graph is constructed incrementally as the robot explores. When new objects are detected, they are added to the graph. To maintain efficiency, the system uses a novel edge pruning strategy:

The system first creates connections between new nodes and existing nodes (dense connect). Then it applies two pruning strategies:

- **Long Edge Pruning**: Removes edges between distant objects unless they meet specific criteria (not obstructed, parallel to wall, in same room)
- **Short Edge Pruning**: Uses a vision-language model (VLM) to identify relevant short-range connections

This approach reduces the computational complexity from O(m(m+n)) to O(m), where m is the number of new nodes and n is the number of existing nodes.

### 5. Hierarchical Chain of Thought Prompting

To effectively leverage LLMs for navigation decisions, SG-Nav employs a hierarchical chain-of-thought (H-CoT) prompting strategy. This approach guides the LLM through a structured reasoning process:

1. **Subgraph Extraction**: The scene graph is divided into manageable subgraphs.
2. **Initial Question**: The LLM is asked to predict the probability of finding the target object near the subgraph.
3. **Follow-up Questions**: The LLM generates relevant questions about the scene context.
4. **Question Answering**: The LLM answers these questions based on the subgraph.
5. **Final Prediction**: The LLM summarizes the conversation and provides a probability estimate.

This example demonstrates how SG-Nav uses the scene graph to reason about object locations:

In this case, the LLM correctly identifies that the TV is likely to be opposite the sofa in the living room, while a conventional agent struggles with the spatial reasoning required.

The subgraph scoring is formally defined as:

$$
S(G_i) = \text{H-CoT}(G_i, g)
$$

Where $G_i$ is a subgraph, $g$ is the goal object, and H-CoT represents the hierarchical reasoning process.

### 6. Re-Perception Mechanism

Object detection systems are not perfect and may misidentify objects. SG-Nav incorporates a re-perception mechanism to handle these errors:

1. When a candidate goal object is detected, the system accumulates a credibility score based on:
 - Multiple observations from different viewpoints
 - The LLM's assessment of how likely the object is to appear in that context

2. If the credibility score exceeds a threshold, the object is confirmed as the goal. Otherwise, the system continues exploring.

This example shows the re-perception mechanism correcting an error where a sofa was initially misidentified as a chair. The LLM's reasoning suggests that a sofa is more likely to be found in this context.

### 7. Performance Evaluation

SG-Nav was evaluated on three benchmark datasets: Matterport3D (MP3D), HM3D, and RoboTHOR. The system was compared against state-of-the-art methods:

- **ESC**: An LLM-based navigation method using explicit spatial commonsense
- **CoW**: A method leveraging chain-of-thought reasoning

The key metrics used were:
- **Success Rate (SR)**: Percentage of successful navigation tasks
- **Success weighted by Path Length (SPL)**: Success rate weighted by path efficiency

SG-Nav achieved state-of-the-art performance across all benchmarks:

The results show that SG-Nav significantly outperforms previous methods across virtually all object categories. For example, when navigating to a fireplace, SG-Nav achieves a success rate of approximately a 70%, compared to 26% for ESC and just 3% for CoW.

SG-Nav is particularly effective for objects with strong contextual relationships, such as furniture items typically found in specific rooms (e.g., fireplace, towel, seating).

Ablation studies confirmed the importance of each component:
- Removing the 3D scene graph reduced success rate by 7.3%
- Removing hierarchical prompting reduced success rate by 5.1%
- Removing re-perception reduced success rate by 3.8%

### 8. Computational Efficiency

One of the challenges in using LLMs for robotics is computational efficiency. SG-Nav addresses this through its novel edge pruning strategy and optimized prompting format.

The graph shows how the time required to update the scene graph scales with the number of edges. While a naive approach (yellow line) exhibits quadratic growth, SG-Nav (green line) maintains near-linear performance.

The efficient prompting format further reduces computational requirements:

Instead of making m(m+n) separate LLM calls, SG-Nav batches the prompts efficiently, significantly reducing the total number of tokens processed.

### 9. Conclusion

SG-Nav represents a significant advancement in zero-shot object navigation by combining 3D scene graph representations with LLM reasoning. The system demonstrates several key advantages:

1. **Generalization**: SG-Nav can navigate to objects not seen during training, leveraging the LLM's world knowledge.

2. **Explainability**: The hierarchical chain-of-thought reasoning provides transparent explanations for navigation decisions.

3. **Robustness**: The re-perception mechanism effectively handles object recognition errors.

4. **Efficiency**: The optimized scene graph construction and prompting strategies maintain reasonable computational requirements.

The framework demonstrates how structured representations and guided reasoning can effectively leverage large language models for embodied AI tasks. This approach could be extended to other robotic tasks requiring spatial reasoning and commonsense knowledge.

SG-Nav also illustrates how the spatial reasoning capabilities of LLMs can be enhanced through appropriate prompting strategies and environmental representations. Instead of treating the LLM as a black box, the system guides its reasoning process through a carefully designed sequence of prompts.

By achieving state-of-the-art performance on zero-shot object navigation, SG-Nav demonstrates the potential for developing more adaptable and generalized robotic systems that can operate effectively in novel environments.
