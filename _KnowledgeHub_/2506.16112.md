# Loss-Oriented Ranking for Automated Visual Prompting in LVLMs

> [!summary] Summary
> An automated visual prompting framework, AutoV, dynamically selects optimal visual cues from a candidate pool to enhance Large Vision-Language Model performance. It consistently improves accuracy across diverse LVLMs and benchmarks, achieving up to 10.2% higher accuracy on VizWiz and demonstrating strong transferability to various model architectures, including closed-source ones.

## Problem

- Existing visual prompting methods for Large Vision-Language Models (LVLMs) rely on heuristic, fixed designs that lack adaptability.
- These static prompts are often sub-optimal, showing inconsistent performance across different tasks and requiring extensive manual tuning for specific benchmarks or instances.
- Efficiently and effectively guiding LVLM attention for diverse image-query contexts without laborious manual intervention remains a challenge.

## Method

- ==AutoV== introduces an automated framework that dynamically selects the most appropriate visual prompt for any given textual query and input image from a pre-defined pool of candidates.
- It employs a ==lightweight ranking network==, trained using the first layer of the LVLM's language decoder for modality interaction, to evaluate and score the relevance of each candidate prompt.
- An innovative ==automated data generation pipeline== is used, leveraging ==LVLM prediction loss== as a scalable, reward-based supervision signal to train the ranking network, avoiding manual annotation.

## Results

- AutoV consistently outperforms existing heuristic visual prompting methods, achieving average accuracy gains of **2.2%** to **4.2%** across various open-source LVLMs (LLaVA-1.5, InternVL2, Qwen2.5-VL) and benchmarks, with notable improvements such as **10.2%** on VizWiz and **3.8%** on MMMU.
- The framework demonstrates strong transferability, boosting closed-source models like Gemini-Pro (**+6.4 points**) and GPT-4o (**+6.0 points**) on VizWiz and LLaVA-Wild benchmarks without specific training.
- AutoV enhances model efficiency by enabling smaller 7B LVLMs to achieve performance levels competitive with larger 13B models, while introducing minimal inference latency (e.g., **6.9 ms** for LLaVA-7B).

## Takeaways

> [!tip] Key Insights
> - Dynamically selecting visual prompts tailored to specific image-query pairs yields superior and more robust LVLM performance compared to static, heuristic prompting methods.
> - LVLM prediction loss can serve as an effective and scalable reward signal for training prompt selection models, enabling automated data generation without costly human labeling.
> - A lightweight, trained ranking network can generalize its prompt selection strategy across diverse LVLM architectures, acting as a model-agnostic enhancement without requiring fine-tuning of the base models.
