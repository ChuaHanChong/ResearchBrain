# Loss-Oriented Ranking for Automated Visual Prompting in LVLMs

> [!summary] Summary
> An automated visual prompting framework, AutoV, dynamically selects optimal visual cues from a candidate pool to enhance Large Vision-Language Model performance. It consistently improves accuracy across diverse LVLMs and benchmarks, achieving up to 10.2% higher accuracy on VizWiz and demonstrating strong transferability to various model architectures, including closed-source ones.

## Problem

- Existing visual prompting methods for Large Vision-Language Models (LVLMs) rely on heuristic, fixed designs that lack adaptability.
- These static prompts are often sub-optimal, showing inconsistent performance across different tasks and requiring extensive manual tuning for specific benchmarks or instances.
- Efficiently and effectively guiding LVLM attention for diverse image-query contexts without laborious manual intervention remains a challenge.

## Method

- ==AutoV== introduces an automated framework that dynamically selects the most appropriate visual prompt for any given textual query and input image from a pre-defined pool of candidates.
- It employs a ==lightweight ranking network==, trained using the first layer of the LVLM's language decoder for modality interaction, to evaluate and score the relevance of each candidate prompt.
- An innovative ==automated data generation pipeline== is used, leveraging ==LVLM prediction loss== as a scalable, reward-based supervision signal to train the ranking network, avoiding manual annotation.

## Results

- AutoV consistently outperforms existing heuristic visual prompting methods, achieving average accuracy gains of **2.2%** to **4.2%** across various open-source LVLMs (LLaVA-1.5, InternVL2, Qwen2.5-VL) and benchmarks, with notable improvements such as **10.2%** on VizWiz and **3.8%** on MMMU.
- The framework demonstrates strong transferability, boosting closed-source models like Gemini-Pro (**+6.4 points**) and GPT-4o (**+6.0 points**) on VizWiz and LLaVA-Wild benchmarks without specific training.
- AutoV enhances model efficiency by enabling smaller 7B LVLMs to achieve performance levels competitive with larger 13B models, while introducing minimal inference latency (e.g., **6.9 ms** for LLaVA-7B).

## Takeaways

> [!tip] Key Insights
> - Dynamically selecting visual prompts tailored to specific image-query pairs yields superior and more robust LVLM performance compared to static, heuristic prompting methods.
> - LVLM prediction loss can serve as an effective and scalable reward signal for training prompt selection models, enabling automated data generation without costly human labeling.
> - A lightweight, trained ranking network can generalize its prompt selection strategy across diverse LVLM architectures, acting as a model-agnostic enhancement without requiring fine-tuning of the base models.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Recent advancements in large language models (LLMs) have driven significant progress in large vision-language models (LVLMs). LVLMs integrate visual encoders with language model decoders, enabling them to extend textual reasoning capabilities to visual understanding tasks. Visual input is critical for these models, facilitating fine-grained perception and grounding in multimodal scenarios.

Inspired by textual prompting in LLMs, visual prompting has emerged as a method to guide LVLM attention by injecting structured visual cues such as blur masks, bounding circles, or attention heatmaps. These prompts aim to direct models to task-relevant regions within an image. However, a limitation of existing visual prompting approaches is their reliance on fixed or heuristically designed prompts. Such handcrafted strategies typically assume that a single prompt design can generalize effectively across diverse visual scenes and textual queries.

In practice, this assumption often proves inadequate. Prior work indicates that fixed prompt designs tend to reach performance ceilings on specific benchmarks, limiting further gains through simple prompt engineering. The effectiveness of a visual prompt is observed to vary significantly based on the task and the specific instance (image-query pair). For example, a prompt effective for an Optical Character Recognition (OCR) task might not be optimal for an object detection task requiring salient object highlighting. This observation suggests that the optimal visual prompt is inherently instance-dependent.

This research shifts the paradigm from static visual prompt engineering to dynamic visual prompt retrieval. Instead of seeking a universally optimal prompt, the work addresses the challenge of identifying the most suitable visual prompt for a given image-query pair. This approach integrates existing prompt designs to leverage their complementary advantages, departing from methods that focus solely on developing new prompt types. The work also distinguishes itself from retrieval-augmented methods that retrieve external visual data, as AutoV performs lightweight in-model prompt selection from a compact, pre-defined candidate pool.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a framework, named AutoV, for instance-adaptive visual prompt identification. This framework aims to automatically select the most suitable visual prompt for a given input image and textual query from a diverse pool of candidates.

The motivation for this work stems from several limitations observed in current visual prompting strategies for LVLMs:
- **Performance Saturation:** Existing visual prompting methods, which rely on fixed or heuristically designed prompts, tend to achieve benchmark-specific performance ceilings. This makes further improvements through traditional "prompt engineering" increasingly ineffective. The paper highlights that marginal gains from such designs are diminishing.
- **Lack of Generalizability across Instances:** The implicit assumption that a single visual prompt design can generalize across diverse visual scenes and textual queries is often invalid. The optimal visual prompt is context-sensitive and instance-dependent. For example, a blur mask might be beneficial for an OCR task, while a highlight circle would be more effective for drawing attention to salient objects in a detection task. This variability necessitates a more flexible approach than static prompt designs.
- **Difficulty of Supervision for Retrieval Systems:** Training a visual prompt retrieval framework requires prompt-level supervision, meaning a clear indication of which prompt is "good" or "bad" for a given context. However, the quality of visual prompts is often ambiguous, subjective, and task-dependent, making reliable human annotation difficult and labor-intensive, particularly for complex reasoning or OCR-heavy tasks.

To address these motivations, AutoV proposes to:
1. **Shift from prompt engineering to prompt retrieval:** Instead of designing a single best prompt, AutoV focuses on dynamically selecting the best prompt from a pre-defined set for each specific instance.
2. **Enable automatic, scalable supervision:** To overcome the challenge of manual annotation for prompt quality, AutoV introduces a novel, fully automated supervision strategy. This involves evaluating each candidate visual prompt using a pre-trained LVLM and ranking them based on their prediction losses. The rationale is that a superior prompt should result in a lower conditional language modeling loss. This "loss-oriented ranking" provides a robust, automatic training signal for the retrieval network, allowing it to learn query-aware prompt preferences without human intervention.
3. **Enhance LVLM performance:** By dynamically providing instance-adaptive visual prompts, the framework aims to improve the perceptual and reasoning capabilities of LVLMs across various tasks, including image understanding, captioning, grounding, and classification.

### 3. Methodology and Approach

AutoV is a lightweight framework designed for instance-adaptive visual prompt retrieval. It comprises four main components: feature extraction from prompt candidates, a candidate ranking network, reward loss supervision with an automated data generation pipeline, and a robust inference pipeline.

#### 3.1. Feature Extraction of Prompt Candidates

The initial step involves preparing the visual prompt candidates. Given a set of `n` input visual prompts $\{x_1, x_2..., x_n\}$, a visual encoder, such as CLIP's `g(.)`, is used to generate a visual feature `Z_i` for each prompt. Subsequently, a projection matrix `W` transforms each `Z_i` into language embedding tokens `V_i = W × Z_i`. This aligns the visual features with the dimensionality of the language model's word embedding space. The visual encoder and the alignment projector are directly inherited from a fully trained LVLM and are not fine-tuned during this process. This results in a set of visual candidates represented as visual tokens `V_i ∈ R^{L×D}` for ranking, where `L` is the length of vision tokens and `D` is the language embedding dimension.

#### 3.2. Candidate Ranking Network

The ranking network's purpose is to evaluate and rank the visual prompt candidates based on their relevance to the input textual query. This is achieved by modeling the relationship between the visual tokens and the text.
- **Modality Interaction Module:** Drawing inspiration from observations that modality fusion occurs in shallow layers of LLMs, the first layer of the LLM decoder `f(.)` is utilized. Visual candidate tokens `V_i` and textual query tokens `T` are concatenated (`concat(V_i, T)`) and fed into this interaction module, producing `H_i = f(concat(V_i, T))`. The outputs are then separated into refined visual candidate tokens `~V_i = H_i[:l_v]` and query tokens `~T = H_i[-l_t:]`.
- **Vision Mapping Module:** The refined visual candidate tokens `~V_i` are passed through a feed-forward network (FFN) to generate final candidate features `V'_i ∈ R^{l_v × h}`, where `h` is a smaller output dimension than `D` to reduce computational cost.
- **Text Mapping Module:** Similarly, the query tokens `~T` are converted by another FFN (text mapping module) to obtain query embeddings `T' ∈ R^{l_t × h}`.
- **Reward Scalar Calculation:** Visual retrieval is framed as a customized ranking task. A cross-attention operation calculates a reward scalar `s(VP_i) = mean(cross-attn(V'_i, T'))` for each visual prompt candidate `VP_i`, where context similarity with the query serves as the target. Only the vision and text mapping modules, consisting of single FFNs, are trained, resulting in a lightweight network with `2h(D + h + 2)` parameters.

#### 3.3. Reward Loss Supervision

A core innovation of AutoV is its automated supervision strategy, which circumvents the challenges of manual prompt quality annotation.
- **Automated Data Generation:** The quality of visual prompts is assessed by a pre-trained LVLM. Each candidate prompt is combined with a query, processed by the LVLM, and its prediction loss (modeling loss relative to the ground truth) is computed. Lower loss indicates stronger alignment and a superior prompt. This loss acts as a proxy for model confidence. To ensure high-quality ranking data, two filtering criteria are applied:
 - Removal of (VP, query) pairs with low loss variance, as this suggests the LVLM relies on language priors rather than visual grounding.
 - Exclusion of pairs with excessively high average loss, indicating outlier cases or weak visual prompt-query correlation.
 Each raw (image, query) pair generates a training sample: `<query, {vp_0..., vp_{n-1}}, rank, reward loss>`.
- **Reward Loss `L_r`:** The ranking network is trained using a reward modeling approach inspired by human feedback, specifically tailored as a pairwise ranking task. For each instance, all `C(n, 2)` possible pairs of visual prompt candidates are formed. If `VP_c` has a lower loss than `VP_r` (chosen vs. rejected), the model is trained to predict a higher reward for `VP_c`. The reward loss `L_r` is defined as:
 `L_r := - (1/C(n, 2)) * E [log(σ(s(VP_c) - s(VP_r)))]`,
 where `s(VP_c)` and `s(VP_r)` are the scalar outputs from the ranking network for the chosen and rejected prompts, respectively, and `σ` is the Sigmoid function. This pairwise comparison is chosen over pointwise scoring or list-wise ranking for its ability to discriminate fine-grained preferences and robustness to noisy signals.

#### 3.4. Robust Inference Pipeline

During inference, multiple candidate visual prompts are input along with the query into the LVLM.
- The trained ranking network processes these inputs, outputting a reward scalar for each visual prompt.
- The prompt with the highest reward score is selected.
- Its corresponding visual tokens are concatenated with the text embeddings and then decoded by the LLM to generate the final answer.
- Additionally, a pre-filtering step is introduced to enhance robustness. The prompt whose visual features are farthest from the other candidates (measured by cosine distance) is removed before ranking. This aims to mitigate the negative effects of highly suboptimal or outlier prompts.

### 4. Main Findings and Results

The experimental evaluation of AutoV demonstrates consistent performance enhancements across various LVLMs and a diverse set of tasks.

#### 4.1. Overall Performance and Quantifiable Improvements

AutoV was applied to four open-source LVLMs: LLaVA-1.5 series (7B and 13B), LLaVA-OneVision (7B), InternVL2 (8B), and Qwen2.5-VL (7B).
- Across these models, AutoV yielded average improvements of 2.4% (LLaVA-7B), 2.3% (LLaVA-13B), 4.5% (LLaVA-OneVision), 5.0% (InternVL2), and 3.4% (Qwen2.5-VL) relative to their respective base models on a selection of seven benchmarks (MMMU, VizWiz, MMVet, TextVQA, LLaVA Wild, MMStar, MathVista).
- Notable specific gains include improving LLaVA-OneVision by 10.2% on VizWiz and boosting Qwen2.5-VL by 3.8% on MMMU.
- Extended evaluations on an additional seven benchmarks (CVBench, BLINK, RealWorld, MMVP, COCOCap, RefCOCO+, ImageNet-1K) also showed consistent enhancements in multimodal understanding and reasoning. For example, LLaVA-OneVision with AutoV improved by 3.4% on CVBench and 3.0% on RefCOCO+.

#### 4.2. Outperformance of Existing Visual Prompt Engineering Methods

AutoV consistently outperformed fixed, heuristically designed visual prompting methods such as FGVP, RedCircle (Circle), and API.
- On MMMU, AutoV achieved an average gain of 3.2% compared to API's 1.1%, representing a 2.1% absolute improvement. This highlights the effectiveness of instance-adaptive retrieval over benchmark-level prompt design.
- The results indicate that other visual prompting strategies lacking query-adaptive mechanisms generally underperform, sometimes even exhibiting negative gains on certain benchmarks.

#### 4.3. Supplementing Less Accurate Models

AutoV demonstrated the ability to enhance inherently less accurate models. For instance, LLaVA-7B equipped with AutoV achieved higher accuracy than the LLaVA-13B base model on 4 out of 7 tasks. This suggests that the lightweight addition of AutoV's MLP layers can be a more efficient choice for certain tasks compared to scaling up model parameters significantly.

#### 4.4. Model Agnosticism and Transferability

The retrieval strategy learned by AutoV exhibited strong transferability across heterogeneous LVLM architectures.
- The AutoV retrieval strategy, trained on LLaVA-OneVision, was directly applied to Qwen2.5-VL and InternVL2 without additional fine-tuning of these backbones. This resulted in an average accuracy gain of 4.2%, indicating that the approach is model-agnostic.
- Furthermore, the strategy transferred effectively to closed-source models like Gemini-1.5-Pro, GPT-4o, and Qwen-VL-Max, showing substantial gains (e.g., Gemini-1.5-Pro saw +9.6% on VizWiz, GPT-4o saw +9.0% on VizWiz), demonstrating broad applicability.

#### 4.5. Comparison with Other Retrieval Methods

An analysis comparing AutoV with other retrieval strategies using LLaVA-7B confirmed the benefits of pairwise ranking:
- **Heuristic Fixed Retrieval:** Showed that no single prompt is universally optimal.
- **Random Retrieval:** Provided a modest average gain (+0.7%) over baseline, suggesting inherent benefit from prompt diversity.
- **Regression Retrieval:** Performed worse than MoE and ranking-based methods, indicating difficulty in learning absolute loss scores due to small performance gaps and noise.
- **Mixture-of-Experts (MoE) Retrieval (GateNet):** Improved baseline by 1.1% but was still 1.2% behind AutoV, suggesting that soft gating is less effective than explicit preference modeling. Retrieval visualization showed GateNet often selected less optimal prompts.
- **List-wise Ranking:** Achieved consistent gains (+1.6%) but was more limited than pairwise ranking, possibly due to higher optimization complexity in estimating full permutations.
- **AutoV (Pair-wise Ranking):** Achieved the highest average gain (+2.3%), attributed to its query-aware adaptability, explicit relative preference modeling, and structured supervision.

#### 4.6. Scaling Law of AutoV

Experiments on varying prompt pool sizes (1 to 8 candidates) revealed:
- **Diminishing Returns:** Increasing the number of prompt candidates initially improved accuracy, but marginal gains decreased as the pool grew, suggesting an optimal range for efficiency.
- **Robustness to Quality:** AutoV was largely agnostic to the quality of individual prompts. Even when incorporating prompts that individually yielded negative gains (e.g., RedCircle or FGVP on certain benchmarks), the overall performance still improved.
- **Generalization to Unseen Prompts:** AutoV effectively indexed suitable candidates even when encountering unseen prompt types during inference, yielding additional improvements.
- A practical recommendation was to limit the prompt pool to fewer than 9 high-quality candidates to balance effectiveness and efficiency.

#### 4.7. Efficiency

AutoV is designed to be lightweight.
- Training AutoV on LLaVA-7B took 6 hours on 8 A100 GPUs. Its transferability means no retraining for new LVLMs.
- At inference, for LLaVA-7B (N=4 candidates), AutoV added only 0.74T FLOPs, which is negligible compared to the LLM decoder's 4.30T FLOPs.
- Latency increased by only 6.9 ms (from 254.8 ms to 261.7 ms) for an average +2.4% accuracy gain.

#### 4.8. Qualitative Visualization

Qualitative examples demonstrated that AutoV selects different visual prompts based on the specific textual query, effectively guiding the LVLM's attention to relevant regions for tasks focusing on global context versus specific details.

### 5. Significance and Potential Impact

The AutoV framework represents a significant advancement in enhancing the perceptual capabilities of large vision-language models (LVLMs) by addressing the limitations of static visual prompting. Its significance and potential impact are multifaceted:

- **Paradigm Shift from Engineering to Retrieval:** AutoV shifts the focus from manually designing a single optimal visual prompt to dynamically retrieving the most suitable prompt for each unique image-query pair. This instance-adaptive approach overcomes the performance saturation observed with fixed, heuristically designed prompts, leading to consistent and substantial performance improvements across various LVLMs and tasks.
- **Automated and Scalable Supervision:** The introduction of loss-oriented ranking for automatic supervision is a key innovation. By evaluating visual prompts based on their prediction losses from a pre-trained LVLM, AutoV eliminates the need for labor-intensive and subjective human annotation for prompt quality. This makes the training process scalable and efficient, enabling the development of more sophisticated visual prompting systems.
- **Enhanced LVLM Performance and Robustness:** AutoV consistently improves performance on a wide array of vision-language tasks, including image understanding, captioning, grounding, and classification. The demonstrated robustness across different LVLM architectures (open-source and closed-source) and its ability to generalize to unseen prompt types and varying pool sizes indicate a reliable method for enhancing multimodal understanding and reasoning.
- **Efficiency and Practicality:** AutoV is a lightweight framework, adding negligible computational overhead during inference compared to the core LLM decoding process. Its low training cost and transferability across different LVLMs (even without retraining for new backbones) make it a practical solution for deployment, allowing for performance gains with minimal resource expenditure.
- **Broad Applicability and Transferability:** The ability of AutoV's learned retrieval strategy to transfer effectively to different LVLMs, including powerful closed-source models, highlights its general applicability. This suggests that the principles of loss-oriented retrieval are robust and can benefit a wide ecosystem of multimodal AI models.
- **Addressing Model Limitations:** By supplementing less accurate models to achieve performance comparable to larger counterparts, AutoV offers a path towards more efficient model deployment for specific tasks, potentially reducing the need for extensive model scaling.

Overall, AutoV provides a robust, efficient, and adaptive mechanism for guiding LVLMs with visual prompts. This work has the potential to significantly improve the performance and reliability of multimodal AI systems, paving the way for more sophisticated and context-aware visual reasoning applications in diverse real-world scenarios.
