# Voyager: An Open-Ended Embodied Agent with Large Language Models

> [!summary] Summary
> VOYAGER introduces an AI agent capable of lifelong learning and open-ended exploration in Minecraft, leveraging a Large Language Model (LLM) to autonomously propose tasks, generate and refine executable code skills, and accumulate knowledge in a growing skill library. The agent discovered 3.3 times more unique items and unlocked advanced tech tree milestones like diamond tools, a feat not achieved by other methods.

## Problem

- Traditional reinforcement learning and imitation learning struggle with systematic exploration, policy interpretability, and generalization in vast, open-ended environments.
- Most existing Large Language Model (LLM)-powered agents lack the ability to perform lifelong learning, failing to continuously acquire, update, accumulate, and transfer knowledge over extended periods.
- Developing agents that can mimic human-like self-driven exploration, task proposal, and skill refinement in complex, dynamic virtual worlds like Minecraft remains a challenge.

## Method

- **VOYAGER** proposes tasks through an ==automatic curriculum== generated by GPT-4, which considers the agent's current state and past performance to suggest progressively challenging explorations.
- A ==skill library== stores learned behaviors as executable JavaScript code functions, enabling the reuse and composition of mastered skills indexed by their descriptions for future task execution.
- An ==iterative prompting== mechanism refines LLM-generated code based on real-time environment feedback, execution errors, and ==self-verification== from a separate GPT-4 critic, ensuring robust ==program synthesis== for embodied control.

## Results

- VOYAGER discovered **3.3 times** more unique items and unlocked the diamond level of the tech tree, which no other baseline achieved, demonstrating superior exploration and tech tree mastery.
- The agent traversed **2.3 times** longer distances and consistently solved all unseen tasks in zero-shot generalization tests, outperforming baselines which failed to solve any new tasks.
- Ablation studies confirmed the critical importance of VOYAGER's core components: the automatic curriculum, skill library, and especially self-verification, which resulted in a **73%** drop in discovered items when removed.

## Takeaways

> [!tip] Key Insights
> - Large Language Models (LLMs) can effectively drive autonomous, lifelong learning in embodied agents, extending beyond fixed tasks to open-ended environments.
> - Using executable code as the action space enables interpretability, compositionality, and scaffolding of complex, temporally extended skills for embodied agents.
> - Iterative refinement of LLM-generated code, incorporating environment feedback, execution errors, and self-verification, is crucial for robust and continuous skill acquisition in dynamic settings.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development of VOYAGER represents a significant step towards achieving **generally capable embodied agents** that can learn and adapt in complex, open-ended environments. This field is a grand challenge in AI, traditionally approached using **reinforcement learning (RL)** and **imitation learning (IL)**. However, these classical methods often struggle with systematic exploration, interpretability of learned policies, and generalization to novel situations, especially when operating on primitive actions over long horizons.

Recent advancements in **Large Language Models (LLMs)** have opened new avenues for agent design. LLMs, leveraging their vast pre-trained world knowledge, can generate high-level action plans and executable policies, offering better interpretability and planning capabilities than end-to-end RL systems. These LLM-based agents have seen applications in various embodied tasks, including games and robotics, as well as non-embodied NLP tasks.

However, a critical limitation of most existing LLM-powered agents is their inability to perform **lifelong learning** – continuously acquiring, updating, accumulating, and transferring knowledge over extended periods. VOYAGER directly addresses this gap, positioning itself as the first LLM-powered embodied agent specifically designed for lifelong learning in an open-ended environment without human intervention.

**Minecraft** serves as an ideal testbed for this research. Unlike many games with predefined goals, Minecraft is a procedurally generated 3D world with infinite possibilities, requiring continuous exploration, resource gathering, and progression through a complex "tech tree." This makes it a challenging benchmark for general intelligence, mimicking aspects of real-world learning and adaptation.

VOYAGER distinguishes itself from prior Minecraft AI research. While some works use pixel-based inputs and low-level controls, VOYAGER operates at a higher abstraction level using the **Mineflayer JavaScript API**. This choice shifts the focus from perception and low-level motor control to higher-level planning and skill acquisition, allowing the researchers to concentrate on the lifelong learning aspect. Compared to other LLM-based Minecraft agents that primarily focus on high-level planning by decomposing tasks or following recipes, VOYAGER introduces a unique combination of components (automatic curriculum, skill library, iterative prompting) to enable true open-ended, self-driven exploration and continuous skill development.

Furthermore, VOYAGER builds upon existing LLM agent paradigms such as **ReAct** and **Reflexion**, which combine reasoning and acting, and **AutoGPT**, which automates task decomposition. VOYAGER extends these by incorporating a sophisticated skill library and a more robust iterative prompting mechanism, proving to significantly outperform them in complex, open-ended scenarios. The work also contributes to the broader field of **code generation with execution**, demonstrating how environment feedback, execution errors, and self-verification can dramatically improve LLM-generated programs.

### 2. Key Objectives and Motivation

The overarching objective of the VOYAGER project is to build a **generally capable embodied agent** that can continuously explore, plan, and develop new skills in open-ended worlds. The researchers identify several key motivations and specific goals to achieve this:

1. **Overcome Limitations of Traditional Embodied AI**: Traditional RL and imitation learning approaches, while effective in some domains, struggle with the systematic exploration of vast environments, lack interpretability of their learned policies, and often fail to generalize to novel tasks or settings. VOYAGER aims to address these shortcomings by leveraging the reasoning and code generation capabilities of LLMs.

2. **Enable Lifelong Learning in LLM Agents**: While LLMs have shown impressive planning abilities, most LLM-based agents are not designed for lifelong learning. They typically operate in a static environment or with a fixed set of tasks, failing to progressively acquire, update, accumulate, and transfer knowledge over extended time spans. VOYAGER's core motivation is to instill this crucial capability, allowing agents to continuously grow their skill sets.

3. **Mimic Human-like Learning in Open-Ended Environments (Minecraft)**: The paper uses Minecraft as a challenging proxy for open-ended environments. The motivation here is to enable an agent to:
 - **Propose suitable tasks**: Similar to humans, the agent should dynamically identify relevant tasks based on its current skill level and environmental state (e.g., harvesting sand in a desert before iron).
 - **Refine and commit skills**: The agent should learn from environmental feedback and errors, refine its behaviors, and store mastered skills for future reuse and transfer, avoiding catastrophic forgetting.
 - **Self-driven exploration**: The agent should be intrinsically motivated to continually explore the world and seek out new challenges, rather than relying on predefined goals or human intervention.

4. **Leverage LLMs for Code Generation as Action Space**: The researchers are motivated to use executable code as the action space, believing it naturally represents temporally extended, interpretable, and compositional actions crucial for long-horizon tasks in Minecraft. This approach also allows for "blackbox queries" to LLMs like GPT-4, bypassing the need for computationally expensive model parameter fine-tuning.

5. **Develop Robust Self-Improvement Mechanisms**: Recognizing that LLMs may not produce correct code in a single shot, a key objective is to design an iterative refinement process that incorporates various forms of feedback (environment, execution errors, self-verification) to ensure program correctness and task completion.

In essence, VOYAGER's key objectives are to demonstrate the feasibility of an autonomous, LLM-powered agent that can learn continuously, adapt to its environment, and progressively master complex skills in an open-ended world, all while operating without human intervention beyond the initial setup.

### 3. Methodology and Approach

VOYAGER's methodology is built upon three novel, interconnected components designed to facilitate open-ended embodied lifelong learning using a blackbox LLM (GPT-4) without gradient-based training:

1. **Automatic Curriculum**:
 - **Goal**: To propose a steady stream of progressively challenging and diverse tasks that maximize exploration and skill acquisition.
 - **Mechanism**: GPT-4 acts as the curriculum generator. It takes as input the agent's current state (inventory, equipment, nearby blocks/entities, biome, time, health, hunger, position), along with previously completed and failed tasks.
 - **Prompting Strategy**: The prompt includes directives encouraging diverse behaviors and imposing constraints (e.g., "discover as many diverse things as possible," "task should not be too hard"). GPT-4 reasons about the agent's progress and capabilities to suggest the "next immediate task."
 - **Additional Context**: GPT-3.5 is leveraged (for cost efficiency) to self-ask and self-answer questions about Minecraft game mechanics based on the agent's state, which provides rich context to GPT-4.
 - **Warm-up Schedule**: A warm-up schedule gradually introduces more information (agent state, context) to the curriculum prompt as the agent completes more tasks, ensuring a natural progression from basic to complex skills.
 - **Analogy**: This approach functions as an in-context form of novelty search, driving the agent towards unexplored aspects of the environment.

2. **Skill Library**:
 - **Goal**: To store and enable the reuse and composition of learned behaviors, facilitating cumulative skill development and mitigating catastrophic forgetting.
 - **Representation**: Each skill is represented as an executable JavaScript code function (utilizing Mineflayer APIs), which naturally scaffolds temporally extended and compositional actions.
 - **Adding Skills**: Once a task is successfully completed and its generated program verified, it is committed to the skill library. The program is indexed by an embedding of its description (generated by GPT-3.5) in a vector database.
 - **Retrieval**: When a new task is proposed, VOYAGER first uses GPT-3.5 to generate a general suggestion for solving it. This suggestion, combined with environment feedback, forms a query context. The skill library is then queried to identify the top-5 most relevant pre-existing skills, whose code is included in the prompt for GPT-4 to generate a new program.
 - **Benefit**: This allows complex skills to be synthesized by composing simpler, already mastered programs, rapidly compounding the agent's abilities.

3. **Iterative Prompting Mechanism**:
 - **Goal**: To enable robust and accurate code generation for embodied control by iteratively refining programs based on feedback.
 - **Process**:
 - **Code Generation**: GPT-4 generates JavaScript code based on the task, current agent state, control primitive APIs, and retrieved skills. It uses Chain-of-Thought prompting for reasoning before code generation.
 - **Execution and Feedback**: The generated program is executed in the Minecraft simulation. This yields:
 - **Environment feedback**: Chat logs from the simulation indicating intermediate progress or immediate failures (e.g., "I cannot make X because I need Y").
 - **Execution errors**: Error traces from the JavaScript interpreter (e.g., syntax errors, invalid function calls).
 - **Self-Verification**: A separate GPT-4 agent acts as a "critic." By analyzing the agent's current state and the original task, it determines if the task was successfully completed. If not, it provides a critique suggesting how to proceed.
 - **Refinement Loop**: The environment feedback, execution errors, and self-verification critique are all incorporated back into GPT-4's prompt for another round of code refinement. This iterative process (up to 4 rounds per task) continues until self-verification confirms task completion or the agent gets stuck.
 - **Benefit**: This mechanism significantly improves the reliability of program synthesis for embodied control, allowing VOYAGER to continuously acquire diverse skills despite LLM hallucinations or initial errors.

**Overall Approach**: VOYAGER operates in a continuous loop: the automatic curriculum proposes a task, the iterative prompting mechanism generates and refines executable code until the task is complete, the mastered skill is added to the skill library, and then the process repeats with a new task. This modular design, combined with the use of powerful LLMs for reasoning and code generation, forms a self-improving, lifelong learning system.

### 4. Main Findings and Results

VOYAGER demonstrates strong empirical performance across various metrics in Minecraft, highlighting its effectiveness as an in-context lifelong learning agent.

1. **Significantly Better Exploration**:
 - VOYAGER discovered **3.3 times more unique items** (63 items) within 160 prompting iterations compared to baselines (AutoGPT, ReAct, Reflexion). This indicates superior self-driven exploration and ability to venture into novel aspects of the game.
 - Baselines, particularly ReAct and Reflexion, struggled to make significant progress in open-ended exploration, while AutoGPT lagged considerably.

2. **Consistent Tech Tree Mastery**:
 - VOYAGER consistently unlocked key tech tree milestones significantly faster than prior SOTA methods:
 - **Wooden tool level**: 15.3 times faster.
 - **Stone tool level**: 8.5 times faster.
 - **Iron tool level**: 6.4 times faster.
 - Crucially, VOYAGER was the **only method to unlock the diamond level** of the tech tree, demonstrating its ability to master systematic and compositional skills over long horizons. This success validates the effectiveness of the automatic curriculum in presenting suitably complex challenges.

3. **Extensive Map Traversal**:
 - VOYAGER traversed **2.3 times longer distances** compared to baselines, navigating a variety of diverse terrains.
 - This contrasts with baseline agents, which often remained confined to local areas, limiting their capacity for knowledge discovery. The broader exploration contributes directly to discovering more diverse items and resources.

4. **Efficient Zero-Shot Generalization to Unseen Tasks**:
 - When tested on novel tasks in a newly instantiated Minecraft world (with inventory cleared), VOYAGER consistently **solved all tasks**.
 - In contrast, baselines (ReAct, Reflexion, AutoGPT) failed to solve any of these tasks within the maximal prompting iterations, demonstrating VOYAGER's superior ability to generalize.
 - An interesting finding was that VOYAGER's learned skill library, when provided to AutoGPT, **boosted AutoGPT's performance**, proving the skill library's versatility as a plug-and-play asset for enhancing other methods.

5. **Ablation Studies**: The ablation studies systematically validated the importance of VOYAGER's core components:
 - **Automatic curriculum**: Crucial for consistent progress; replacing it with a random curriculum led to a 93% drop in discovered items, while a manual curriculum also fell short, highlighting the adaptability of VOYAGER's curriculum.
 - **Skill library**: Prevented performance plateauing in later stages, emphasizing its role in enabling increasingly complex actions through composition.
 - **Self-verification**: The most critical feedback mechanism; removing it resulted in a significant 73% drop in discovered items, underscoring its role in determining when to proceed or reattempt tasks.
 - **GPT-4 for code generation**: Significantly outperformed GPT-3.5 (5.7 times more unique items), confirming that the "quantum leap" in GPT-4's coding abilities is essential for VOYAGER's success.
 - **Environment feedback and execution errors**: Also important, though self-verification had the largest impact.

6. **Multimodal Feedback from Humans**: While VOYAGER primarily uses text, the research demonstrated its potential to integrate human visual feedback (as a critic) and guidance (as a curriculum) to construct complex 3D structures like a Nether Portal and a house, hinting at future capabilities with visual LLMs.
7. **Robustness to Model Variations**: VOYAGER's performance remained consistent across different versions of GPT-4 (gpt-4-0314 vs gpt-4-0613), indicating its design is robust to minor model updates.

In summary, VOYAGER's findings collectively demonstrate its unprecedented capability for lifelong learning, exploration, and skill acquisition in an open-ended environment, largely attributed to its innovative architecture that synergizes an automatic curriculum, a growing skill library, and iterative program refinement with LLM-based self-verification.

### 5. Significance and Potential Impact

VOYAGER marks a significant advancement in the field of embodied AI and the application of Large Language Models, with several key points of significance and substantial potential impact:

1. **Pioneering Lifelong Learning for Embodied LLM Agents**: VOYAGER is presented as the first LLM-powered embodied lifelong learning agent capable of continuous exploration and skill acquisition without human intervention. This is a crucial step towards building truly autonomous and adaptive AI, moving beyond agents trained for fixed tasks or limited durations.

2. **Demonstrating Efficacy of Blackbox LLMs for Control**: By achieving state-of-the-art performance using GPT-4 via blackbox queries, VOYAGER proves that powerful agents can be developed without needing to fine-tune the LLM's vast parameter space. This significantly broadens the applicability of cutting-edge, proprietary LLMs in complex control tasks, as it bypasses the immense computational and data requirements of fine-tuning.

3. **Novel Architectural Design for Robustness**: The integrated framework of an **automatic curriculum**, an **ever-growing skill library**, and an **iterative prompting mechanism with comprehensive feedback (environment, execution errors, self-verification)** is a highly significant contribution. This architecture effectively addresses common LLM limitations such as one-shot failures and hallucinations, making the agent robust and reliable for long-horizon, open-ended tasks. The skill library's ability to facilitate compositionality and prevent catastrophic forgetting is particularly impactful for continuous learning.

4. **Interpretability and Composability through Code as Actions**: Using executable code (Mineflayer JavaScript) as the action space is a powerful design choice. It makes the agent's learned behaviors inherently interpretable, allowing researchers and users to understand *how* the agent is solving tasks. Furthermore, the modular nature of code naturally supports the composition of simple skills into more complex ones, fostering rapid capability compounding. This contrasts with opaque blackbox policies learned by traditional RL.

5. **New Benchmark for Open-Ended AI**: VOYAGER's superior performance in Minecraft across metrics like unique item discovery, tech tree mastery, and map traversal sets a new benchmark for open-ended embodied AI. Its demonstrated zero-shot generalization capabilities in new worlds underline its ability to transfer learned knowledge effectively, a critical aspect of general intelligence.

**Potential Impact**:

- **Acceleration of Embodied AI Research**: VOYAGER provides a robust framework and empirical evidence that LLMs can drive complex, open-ended learning. This will likely inspire further research into similar architectures for other embodied domains, from robotics to other complex simulations.
- **Foundation for Generalist Agents**: The concept of a self-improving, lifelong learning agent that continuously builds a reusable skill library is a cornerstone for developing more generalist AI systems that can adapt to unforeseen challenges in dynamic environments.
- **Applications in Robotics**: While demonstrated in Minecraft, the core principles of VOYAGER (LLM-driven planning, code-based actions, iterative refinement with feedback, and skill libraries) are directly transferable to physical robotics. This could lead to robots that can autonomously acquire new manipulation skills, navigate unknown environments, and learn from their own failures without constant human reprogramming. The authors acknowledge this potential, emphasizing the need for safety constraints in real-world deployment.
- **Enhanced Human-AI Collaboration**: The interpretability of VOYAGER's code-based skills could facilitate better human understanding and interaction with AI agents. The demonstrated ability to integrate human feedback (as critic or curriculum) also points towards future avenues for more intuitive human-AI collaboration in complex tasks.
- **Improvements in Code Generation**: The iterative prompting mechanism provides valuable insights into how to make LLM-driven code generation more robust and reliable, which has broader implications for software engineering and automated programming.

**Limitations and Future Work**: The paper transparently discusses limitations such as the significant cost of GPT-4 API usage, occasional inaccuracies, and hallucinations. These highlight important areas for future research, including exploring more cost-effective LLMs, improving error handling and reasoning to reduce getting stuck, and further mitigating LLM hallucinations. The most exciting immediate future direction involves integrating VOYAGER with multimodal perception models (once visual LLMs become more accessible) to allow it to directly "see" and interact with the environment, opening up new possibilities for truly intelligent embodied agents.
