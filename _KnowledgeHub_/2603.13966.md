# vla-eval: A Unified Evaluation Harness for Vision-Language-Action Models

> [!summary] Summary
> Researchers developed `vla-eval`, an open-source evaluation harness that standardizes and accelerates the assessment of Vision-Language-Action (VLA) models across various simulation benchmarks. This framework achieved up to a 47x speedup for evaluating models on benchmarks like LIBERO and successfully reproduced published scores while uncovering several undocumented evaluation pitfalls.

## Problem

- Integrating VLA models with multiple simulation benchmarks incurs significant engineering costs due to incompatible software dependencies and distinct environments.
- Evaluation protocols in published VLA research are often underspecified, making it difficult to reproduce results and conduct fair comparisons.
- Comprehensive VLA model evaluations are time-consuming, hindering iterative development and broad assessment of generalization capabilities.

## Method

- A **vla-eval** ==client-server architecture== decouples model inference from benchmark execution, utilizing ==Docker containers== for benchmarks and isolated Python environments for models to resolve dependency conflicts.
- ==Declarative YAML configurations== define evaluation parameters, ensuring reproducibility, and a standardized interface simplifies integration of new benchmarks and models.
- A two-pronged ==parallelization strategy==, combining ==episode sharding== for environments and ==batched inference== for models, significantly accelerates evaluation wall-clock time.

## Results

- `vla-eval` successfully reproduced published scores for **six VLA models** across **three benchmarks**, with deviations generally within expected variance.
- Achieved significant speedups: **47x for LIBERO** (reducing 14 hours to **18 minutes** for 2,000 episodes), **16x for CALVIN**, and **12x for SimplerEnv**.
- Identified critical undocumented pitfalls: incorrect proprioceptive state sources causing a **55 percentage point drop** and quaternion conversion errors causing **14–39 percentage point drops**.

## Takeaways

> [!tip] Key Insights
> - Many previously undocumented parameters and subtle implementation differences in existing benchmark setups critically impact reported VLA model performance.
> - The vast majority of existing VLA models (81%) are evaluated on only a single benchmark, highlighting a community-wide need for more comprehensive, cross-benchmark assessments.
> - Decoupling model and benchmark dependencies into isolated environments effectively transforms the integration burden from an O(N 
	 M) to an O(N + M) cost.
