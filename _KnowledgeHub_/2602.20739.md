# PyVision-RL: Forging Open Agentic Vision Models via RL

> [!summary] Summary
> PyVision-RL introduces an open-weight reinforcement learning framework for agentic multimodal models, enabling dynamic Python-based tool use for images and videos. The framework effectively counters interaction collapse and achieves state-of-the-art performance on image benchmarks, while significantly improving visual token efficiency for video tasks (e.g., 7.3% accuracy increase on VSI-Bench with an order of magnitude fewer visual tokens).

## Problem

- Agentic capabilities with dynamic tooling are largely confined to proprietary systems or image-only tasks, limiting the accessibility and advancement of open-weight multimodal large language models (MLLMs).
- Reinforcement Learning (RL) fine-tuning for agentic MLLMs often suffers from "interaction collapse," where models learn to minimize tool usage and multi-turn reasoning.
- Traditional video MLLMs incur high computational costs due to uniform frame sampling, making efficient and scalable video understanding challenging.

## Method

- A unified agentic scaffold integrates ==Python as a primitive tool==, enabling dynamic, on-the-fly operation synthesis and iterative reasoning for both image and video tasks.
- An ==accumulative tool reward== (only for correct answers) and an oversampling–filtering–ranking strategy for rollouts stabilize RL training and sustain multi-turn tool usage, combating interaction collapse.
- For video understanding, an =="on-demand context construction"== mechanism allows the MLLM to selectively fetch and present task-relevant frames via Python, drastically reducing visual token consumption.

## Results

- PyVision-Image achieved state-of-the-art results on visual search (e.g., **+10.2%** on V* avg@32) and multimodal reasoning benchmarks (e.g., **+9.6%** on WeMath) over previous methods.
- PyVision-Video obtained a **7.3%** absolute accuracy improvement on VSI-Bench while reducing visual token usage from approximately **45K** to **5K** tokens per sample.
- Ablation studies confirmed that the accumulative tool reward is crucial for sustaining tool usage throughout training, and the oversampling–filtering–ranking rollout strategy significantly improves performance and stability.

## Takeaways

> [!tip] Key Insights
> - Interaction collapse in agentic RL is not an inherent limitation of multi-turn interaction but rather a solvable issue related to insufficient training incentives and unstable rollout selection.
> - Dynamic tool use, through treating a general-purpose language like Python as a primitive, provides superior expressiveness and compositional reasoning for both image and video understanding in open-weight MLLMs.
> - On-demand visual processing, where an agent intelligently samples and presents only relevant video frames, is crucial for achieving high performance and efficiency in video reasoning, reducing token consumption by an order of magnitude.
