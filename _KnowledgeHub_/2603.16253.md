# Grounding the Score: Explicit Visual Premise Verification for Reliable Vision-Language Process Reward Models

> [!summary] Summary
> Researchers at Alibaba and the Chinese Academy of Sciences introduced Explicit Visual Premise Verification (EVPV) to enhance the reliability of multimodal process reward models by explicitly verifying the visual premises of reasoning steps. This approach achieved the highest Macro-F1 score of 67.46% on VisualProcessBench for step-level verification and provided consistent gains of up to 9.78 points in Best-of-N reranking accuracy across various multimodal reasoning benchmarks.

## Problem

- Current Vision-Language Process Reward Models (VL-PRMs) struggle to differentiate between logical reasoning errors and verifier-side visual misperception.
- This ambiguity causes false positives (rewarding hallucinated visual premises) and false negatives (penalizing correct statements due to verifier misperception).
- Existing methods for addressing visual grounding issues, such as tool-integrated verification, are computationally prohibitive for large-scale test-time MLLM applications.

## Method

- The approach introduces **Explicit Visual Premise Verification (EVPV)**, which generates explicit ==visual premise declarations== (a "visual checklist") for each reasoning step.
- A dedicated ==constraint extractor== processes the input image once to produce a structured set of verifiable ==visual facts==.
- **EVPV** quantifies the consistency between the policy's visual claims and the independently extracted structured ==visual evidence== to derive a ==visual reliability score==, which is then used to calibrate ==step-wise rewards==.

## Results

- EVPV-PRM achieved the highest Macro-F1 score of **67.46%** on VisualProcessBench, surpassing other multimodal PRMs in step-level verification.
- Consistent improvements were observed in Best-of-N reranking, with accuracy gains up to **+9.78 points** over baseline policies on multimodal reasoning benchmarks.
- Controlled experiments demonstrated a causal link between the fidelity of structured visual constraints and verification performance, confirming that gains are not merely due to prompting effects.

## Takeaways

> [!tip] Key Insights
> - Perceptual correctness is a fundamental prerequisite for any meaningful logical evaluation in multimodal reasoning.
> - Decoupling visual understanding from logical evaluation via explicit premise verification reduces verification errors stemming from verifier-side perceptual failures.
> - Structured visual evidence (constraints) are more effective than general textual context for visual premise verification, and their fidelity directly impacts performance.
