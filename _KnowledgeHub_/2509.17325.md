# Generalizable End-to-End Tool-Use RL with Synthetic CodeGym

> [!summary] Summary
> CodeGym, developed by researchers from Carnegie Mellon University and ByteDance Seed, provides a scalable framework for training large language model agents using reinforcement learning by converting coding problems into diverse, verifiable, multi-turn tool-use environments. Training with CodeGym led to an 8.7 absolute accuracy gain on the out-of-distribution 	-Bench benchmark for the Qwen2.5-32B-Instruct model, demonstrating improved generalization.

## Problem

- Large Language Models (LLMs) are limited by static parametric memory, hindering dynamic interaction with external environments and new information acquisition.
- Current LLM agent training, primarily through supervised fine-tuning (SFT) or narrow reinforcement learning (RL), often results in brittle agents with poor generalization to out-of-distribution tools or workflows.
- There is a lack of diverse, scalable, and verifiable RL environments for LLM agents to develop broad, general-purpose tool-use capabilities.

## Method

- Introduced **CodeGym**, a scalable framework that synthesizes diverse, verifiable ==multi-turn tool-use== environments from competitive programming problems and their solutions.
- The framework extracts atomic functions from code solutions to create callable tools and formalizes interactive environments as Partially Observable Markov Decision Processes (POMDPs).
- Implemented a robust Gym Verification stage with LLM-generated unit tests and quality control filters based on tool-use complexity and difficulty to ensure high-quality training data for RL.

## Results

- CodeGym training consistently improved average reward across all model sizes, with Qwen2.5-**32B**-Instruct achieving an 8.7 absolute accuracy gain on the OOD 	-Bench benchmark and an average 7.3-point improvement across various OOD tasks.
- Models trained on CodeGym demonstrated consistent OOD generalization gains across tool-use (e.g., 	-bench, 	^2-bench), multi-turn interaction (ALFWorld), and reasoning (ZebraLogic, MMLU-Pro) benchmarks.
- Ablation studies confirmed that RL training within CodeGym yielded superior generalization compared to supervised fine-tuning, and explicit environment filtering was crucial for achieving strong performance.

## Takeaways

> [!tip] Key Insights
> - Coding problems, with their inherent rigorous execution logic, provide a structured and verifiable foundation for constructing rich, interactive tool-use environments.
> - Active learning via reinforcement learning within CodeGym environments significantly enhances LLM agent out-of-distribution (OOD) generalization capabilities, outperforming supervised fine-tuning.
> - Larger LLMs benefit more from CodeGym training, exhibiting improved planning capabilities and systematic problem-solving, which translates to better OOD performance.
