# CLEA: Closed-Loop Embodied Agent for Enhancing Task Execution in Dynamic Environments

> [!summary] Summary
> Researchers from CUHK-Shenzhen and Shanghai Jiao Tong University introduce CLEA, a groundbreaking closed-loop framework that enables robust LLM-based robotic task planning through four specialized language models working in concert, achieving a 67.3% improvement in success rate over baseline systems while demonstrating practical deployment in dynamic real-world environments.

## Problem

- Existing LLM-based robotic systems struggle to adapt to dynamic environments and unexpected changes
- Open-loop architectures lack real-time feedback integration and robust error recovery

## Method

- Developed **CLEA**, a closed-loop framework integrating four specialized LLMs with distinct roles
- Implemented interactive task planning with real-time environmental feedback and execution criticism
- Created environmental memory system for maintaining contextual awareness

## Results

- Achieved **67.3%** improvement in success rate over baseline systems
- Demonstrated **52.8%** increase in task completion rate
- Successfully validated on multiple robotic platforms in kitchen environment
- Proved effectiveness through ablation studies of individual components

## Takeaways

> [!tip] Key Insights
> - Functional decoupling of LLMs enables more robust and adaptable behavior
> - Real-time execution criticism significantly improves task completion success
> - Environmental memory helps maintain context for long-horizon tasks
