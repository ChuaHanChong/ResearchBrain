# CLEA: Closed-Loop Embodied Agent for Enhancing Task Execution in Dynamic Environments

> [!summary] Summary
> Researchers from CUHK-Shenzhen and Shanghai Jiao Tong University introduce CLEA, a groundbreaking closed-loop framework that enables robust LLM-based robotic task planning through four specialized language models working in concert, achieving a 67.3% improvement in success rate over baseline systems while demonstrating practical deployment in dynamic real-world environments.

## Problem

- Existing LLM-based robotic systems struggle to adapt to dynamic environments and unexpected changes
- Open-loop architectures lack real-time feedback integration and robust error recovery

## Method

- Developed **CLEA**, a closed-loop framework integrating four specialized LLMs with distinct roles
- Implemented interactive task planning with real-time environmental feedback and execution criticism
- Created environmental memory system for maintaining contextual awareness

## Results

- Achieved **67.3%** improvement in success rate over baseline systems
- Demonstrated **52.8%** increase in task completion rate
- Successfully validated on multiple robotic platforms in kitchen environment
- Proved effectiveness through ablation studies of individual components

## Takeaways

> [!tip] Key Insights
> - Functional decoupling of LLMs enables more robust and adaptable behavior
> - Real-time execution criticism significantly improves task completion success
> - Environmental memory helps maintain context for long-horizon tasks

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

#### 1.1. Research Context

- This work addresses key challenges in applying Large Language Models (LLMs) to real-world robotic systems
- It builds on recent advances in using LLMs for task planning while addressing limitations around adaptability and robustness
- The work differentiates itself through a novel closed-loop architecture integrating multiple specialized LLMs

### 2. Key Objectives and Motivation

#### 2.1. Key Objectives

1. Develop a more robust framework for LLM-based robotic task planning in dynamic environments
2. Enable continuous adaptation based on real-time environmental feedback
3. Demonstrate practical deployment on real robotic systems

### 3. Methodology and Approach

#### 3.1. Novel Framework (CLEA)

- Integrates four specialized open-source LLMs with functional decoupling
- Features an interactive task planner that dynamically generates executable subtasks
- Includes a multimodal execution critic for real-time feasibility assessment
- Maintains environmental memory for contextual awareness

#### 3.2. Methodology

- Implemented on real robotic platforms: dual-arm robot and single-arm robot
- Tested in kitchen environment with manipulable objects and containers
- Evaluated on three task types: search, manipulation, and integrated tasks
- Compared against baseline open-loop system and ablation studies

### 4. Main Findings and Results

#### 4.1. Results

- 67.3% improvement in success rate over baseline
- 52.8% increase in task completion rate
- Demonstrated superior performance in long-horizon tasks
- Validated effectiveness of critic module through ablation studies

### 5. Significance and Potential Impact

#### 5.1. Significance

- Advances state-of-the-art in practical LLM-robotics integration
- Provides open-source implementation for reproducibility
- Demonstrates feasibility of closed-loop LLM planning in real environments
- Identifies key challenges and failure modes for future work

#### 5.2. Potential Impact

- Could enable more robust autonomous robots in dynamic environments
- Advances integration of language models with physical systems
- Provides foundation for multi-robot coordination using LLMs

#### 5.3. Limitations & Future Work

- Action space limitations restrict recovery options
- Some challenges remain in multi-robot collaboration
- Opportunities to improve efficiency with smaller models
- Need for better integration with low-level robot control

The work represents a significant advance in making LLM-based robotics more practical and robust while clearly identifying remaining challenges and future research directions. The open-source implementation and real-world validation strengthen its potential impact on the field.
