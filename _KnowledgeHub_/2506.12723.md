# SP-VLA: A Joint Model Scheduling and Token Pruning Approach for VLA Model Acceleration

> [!summary] Summary
> Researchers from Tsinghua University developed SP-VLA, a unified framework to accelerate Vision-Language-Action (VLA) models by jointly optimizing model scheduling and token pruning based on temporal and spatial redundancies. The approach achieves up to 2.4x speedup and an average performance gain of 6% in simulation environments, enabling VLA models for real-time applications.

## Problem

- Vision-Language-Action (VLA) models incur immense computational costs, with billions of parameters, leading to slow inference times.
- The slow inference rates of VLA models make them impractical for real-time, latency-sensitive applications in robotics and autonomous systems.
- Existing VLM acceleration techniques often overlook VLA-specific temporal redundancy in sequential action generation and spatial redundancy in visual inputs.

## Method

- An action type-aware ==model scheduling== mechanism dynamically switches between a full VLA model for 'deliberative' actions and a lightweight Ridge Regression generator for 'intuitive' actions.
- A spatio-semantic dual-aware token pruning method reduces spatial redundancy by selecting tokens based on cumulative attention (semantic importance) and Canny edge features (spatial contours), while preserving token order.
- The framework jointly optimizes both scheduling and pruning, adapting computational load to the varying demands of different task phases and visual complexities.

## Results

- SP-VLA achieved **1.35x** lossless acceleration and up to **1.5x** speedup with less than a **3%** accuracy drop on LIBERO, and **2.4x** speedup with an average **6%** performance gain on SimplerEnv.
- Ablation studies showed model scheduling was the most effective for acceleration, yielding a **1.27x** speedup with only a **1%** accuracy drop, demonstrating considerable temporal redundancy.
- Removing Canny edge information from the token pruning process led to a dramatic **50%** performance degradation, highlighting the indispensable role of spatial contour cues for VLA models.

## Takeaways

> [!tip] Key Insights
> - VLA models exhibit distinct 'deliberative' and 'intuitive' action types, allowing for dynamic model scheduling based on task complexity, inspired by human motor control.
> - VLA models are highly sensitive to object relative positions and contour information, making the preservation of Canny edge features during token pruning critical for maintaining performance.
> - Temporal redundancy, addressed by the action type-aware model scheduling, is the most effective component for VLA acceleration, contributing significantly to speedup with minimal accuracy loss.
