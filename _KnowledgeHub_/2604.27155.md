# Generalizing the Geometry of Model Merging Through Frechet Averages

> [!summary] Summary
> GeoMerge presents a geometric framework that reformulates neural network model merging as computing a Fréchet mean on Riemannian manifolds, inherently accounting for architectural symmetries. This yields more robust and symmetry-invariant merging of Low-Rank Adapters (LoRA) for LLMs, empirically outperforming the KnOTS method on NLI tasks with an average normalized accuracy of 91.877% while preserving adapter rank.

## Problem

- Existing data-free (weight-only) model merging methods often fail for parameter-efficient fine-tuning (PEFT) techniques like LoRA due to "misalignment of task-updates," leading to destructive interference.
- Neural networks exhibit architectural symmetries (e.g., neuron permutations, scaling, gauge symmetries) where multiple distinct parameter settings represent the same function, making naive parameter-space averaging fragile and inconsistent.
- Prior alignment methods for LoRA, such as KnOTS, address subspace misalignment but may not be robust to coordinate system choices and underlying symmetries, as the notion of "alignment" itself can be ambiguous in non-canonical parameter spaces.

## Method

- Introduces **GeoMerge**, a geometric framework that reformulates model merging as computing a ==Fréchet mean on a Riemannian manifold==, treating the parameter space with an intrinsic geometry.
- Leverages ==quotient manifolds== to explicitly handle ==architectural symmetries==, grouping equivalent parameterizations into single equivalence classes to ensure symmetry-invariant distances and averages.
- Employs an ==iterative Riemannian gradient descent== algorithm that alternates between ==orbit minimization== (aligning models via symmetry transformations) and ==intrinsic averaging== via exponential and logarithm maps in the horizontal space.

## Results

- GeoMerge consistently outperformed the state-of-the-art LoRA merging method, **KnOTS**, on six NLI datasets using a **Llama 3 8B** base model, achieving an average normalized accuracy of **91.877%** compared to KnOTS's **90.38%**.
- The method demonstrates higher efficiency by preserving the original adapter rank (**r**), whereas KnOTS can increase the rank up to **T·r** (where T is the number of tasks), suggesting more efficient utilization of weight capacity.
- A toy linear network model analytically showed how GeoMerge correctly averages intrinsic function properties despite parameter symmetries, where naive Euclidean or Fisher averaging failed to produce a meaningful merge.

## Takeaways

> [!tip] Key Insights
> - Model merging can be fundamentally generalized as computing a Fréchet mean on a Riemannian manifold, providing a principled, coordinate-free framework that respects the intrinsic geometry of the parameter space.
> - Achieving robust and consistent model merges necessitates explicitly addressing architectural symmetries by performing averaging on quotient manifolds, ensuring the outcome is invariant to specific parameterizations.
> - Fisher-weighted merging can be understood as an approximation of a Fréchet mean under an information-geometric metric, but it remains symmetry-unaware in its averaging mechanism.
