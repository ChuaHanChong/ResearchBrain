# SteadyTray: Learning Object Balancing Tasks in Humanoid Tray Transport via Residual Reinforcement Learning

> [!summary] Summary
> The paper introduces ReST-RL, a hierarchical reinforcement learning framework that enables bipedal humanoid robots to robustly transport unsecured objects on a tray while maintaining stable locomotion. This approach decouples gait control from object stabilization, demonstrating zero-shot sim-to-real transfer on a Unitree G1 humanoid, successfully carrying diverse items like fluid-filled glasses and medical tools under external disturbances.

## Problem

- Humanoid robots face challenges in reliably transporting unsecured payloads on a tray in service environments due to inherent oscillations from bipedal gait.
- The nonrigid coupling between a robot's end-effectors and an unsecured payload complicates stabilization, requiring coordinated whole-body adaptation.
- Existing methods often struggle to simultaneously achieve robust bipedal locomotion and precise, dynamic stabilization of unsecured objects.

## Method

- ==Developed ReST-RL==, a hierarchical reinforcement learning framework that separates locomotion learning from payload stabilization.
- A base policy is first trained for robust locomotion, then a residual module is learned to provide corrective actions for object stabilization using privileged observations.
- A student encoder, conditioned on non-privileged, camera-based object observations, is distilled from a teacher to enable real-world deployment without privileged information.

## Results

- ReST-RL achieved substantial improvements in object stability (reduced Object Projected Gravity XY Tilt) while maintaining locomotion quality in simulation across various disturbance scenarios.
- The framework demonstrated high robustness against diverse body-level and payload-level push disturbances, with success rates of **74.4%** for Push Robot and **73.9%** for Push Object, and generalized to varying object geometries.
- Achieved reliable zero-shot sim-to-real transfer on a Unitree G1 humanoid robot, successfully transporting diverse real-world objects (e.g., fluid-filled wine glass, medical tools) under external forces without retraining.

## Takeaways

> [!tip] Key Insights
> - Decoupling locomotion and object stabilization into a hierarchical learning architecture effectively manages competing objectives, leading to superior robustness compared to end-to-end approaches.
> - Incorporating observation delays for object-centric sensing during training significantly improves sim-to-real transfer reliability and overall stabilization performance.
> - Extensive domain randomization, including variations in robot, tray, and object physical parameters, and application of push perturbations, is crucial for achieving robust real-world generalization.
