# Learning to Prompt for Vision-Language Models

> [!summary] Summary
> Context Optimization (CoOp) automates prompt engineering for large pre-trained vision-language models like CLIP by learning continuous context vectors. This method achieves superior few-shot performance on diverse image recognition tasks and surprisingly enhances domain generalization capabilities compared to hand-crafted prompts and linear probing.

## Problem

- Manually crafting effective textual prompts for vision-language models (VLMs) like CLIP is time-consuming, highly sensitive to minor wording changes, and requires specialized domain expertise.
- Adapting powerful pre-trained VLMs to specific downstream tasks often requires extensive fine-tuning or designing new classifiers, which can be computationally expensive and data-intensive.
- There was a lack of automated, data-efficient methods to leverage the strong zero-shot capabilities of VLMs while also improving their performance on task-specific data.

## Method

- ==Context Optimization (CoOp)== replaces hand-crafted textual prompt contexts with ==learnable, continuous vectors== that are optimized directly from a small amount of labeled data.
- The method keeps the entire pre-trained vision-language model (specifically, CLIP's image and text encoders) frozen during training, only updating the minimal set of context vectors.
- CoOp explores two main context designs: a ==unified context shared across all classes==, and a class-specific context (CSC) where each class learns its own set of context vectors.

## Results

- Context Optimization (CoOp) consistently outperforms zero-shot CLIP with hand-crafted prompts, achieving average gains of approximately **15%** in 16-shot scenarios across **11** diverse datasets.
- CoOp significantly enhances CLIP's robustness to domain shifts, outperforming zero-shot CLIP and linear probe models on out-of-distribution datasets like ImageNet-V2, -Sketch, -A, and -R.
- Unified context generally performs better in low-data regimes (e.g., **1-8 shots**), while class-specific context (CSC) can be more effective for fine-grained classification tasks when more training data is available.

## Takeaways

> [!tip] Key Insights
> - Optimizing continuous prompt vectors directly from data is a highly effective and parameter-efficient strategy for adapting large vision-language models (VLMs) to diverse downstream tasks.
> - Learned prompts can surprisingly enhance VLM robustness to domain shifts, outperforming even zero-shot methods on out-of-distribution benchmarks, which challenges prior assumptions about transfer robustness.
> - The benefits of prompt learning are consistent across different VLM vision backbones (e.g., ResNet, ViT), indicating its broad applicability beyond specific architectures.
