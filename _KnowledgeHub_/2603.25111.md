# SEVerA: Verified Synthesis of Self-Evolving Agents

> [!summary] Summary
> Researchers at the University of Illinois Urbana-Champaign developed SEVerA, a framework that synthesizes self-evolving LLM agents with formal guarantees for safety and correctness. The system consistently achieved zero constraint violations across various tasks while simultaneously improving task performance by up to 12.8% compared to unconstrained and state-of-the-art baselines.

## Problem

- Large language model (LLM) agents, despite their effectiveness in complex tasks, lack formal guarantees regarding safety and correctness, leading to reliability and security concerns in autonomous operations.
- Existing agentic frameworks prioritize flexibility and performance optimization without integrating rigorous formal verification, resulting in issues like agents subtly modifying inputs or violating domain-specific policies.
- A challenge exists in balancing formal correctness with task-specific performance improvement and in enforcing diverse formal constraints at the granularity of individual generative model calls.

## Method

- SEVerA re-frames agent synthesis as a ==constrained learning problem==, integrating hard formal specifications (first-order logic contracts) with soft objectives for task-specific utility.
- It introduces ==Formally Guarded Generative Models (FGGM)==, a mechanism wrapping generative model calls with a ==rejection sampler== and a verified fallback program to ensure all outputs satisfy local, parameter-independent contracts.
- The framework employs a three-stage iterative process (Search, Verify, Learn) to synthesize candidate agent programs, formally prove their correctness for all parameter values, and then optimize agent parameters using gradient-based methods.

## Results

- Demonstrated **0%** constraint violations consistently across all evaluated tasks, including constrained symbolic regression, program verification, symbolic mathematical expression synthesis, and policy-compliant agentic tool use.
- Achieved superior task performance with formal guarantees, for example, increasing accuracy in symbolic math synthesis by **12.8%** (to **66.0%**) compared to unconstrained baselines, while maintaining zero violations.
- In agentic tool use (τ2-bench), SEVerA with a smaller LLM (Qwen3-8B) outperformed state-of-the-art constrained agents using larger models, reducing policy violations from up to **76.3%** to **0%** and improving pass rates by over **11%**.

## Takeaways

> [!tip] Key Insights
> - Formal behavioral constraints are not merely a mechanism for ensuring safety but actively improve agent quality by pruning the search space and guiding the synthesis process towards more effective and higher-performing solutions.
> - Formally Guarded Generative Models (FGGMs) offer a novel, modular, and model-agnostic mechanism to impose fine-grained, parameter-independent formal contracts on individual generative model calls.
> - SEVerA successfully bridges the rigor of formal methods with the flexibility and generalization capabilities of modern generative AI, providing a practical pathway for verifiable AI systems.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Recent advancements in large language models (LLMs) have enabled the synthesis of self-evolving agents capable of performing complex tasks such as program repair and scientific discovery. This paradigm typically involves a planner LLM generating agent programs that integrate various components, including other LLMs, smaller neural networks, and external tools like SMT solvers. These components are subsequently fine-tuned to enhance task performance.

However, a significant gap exists in this emerging field: unlike traditional constraint-guided program synthesis, current self-evolving agent frameworks do not provide formal guarantees regarding the safety or correctness of the synthesized programs. These agents often operate autonomously on unobserved inputs, leading to potential reliability and security issues. Previous research has documented instances of agents modifying input programs to falsely pass verification checks, deleting failing tests instead of fixing bugs, violating domain-specific policies in tool use, and bypassing security measures. This work positions itself to address this deficit by integrating formal verification methods into the self-evolving agent synthesis process, aiming to provide strong guarantees without sacrificing the performance benefits of gradient-based optimization. It bridges the divide between deductive program synthesis, which offers formal guarantees but typically lacks performance optimization, and self-evolving LLM frameworks that prioritize performance without formal safety.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a framework for self-evolving LLM agents that can provide formal guarantees of safety and correctness. This objective is driven by the observed shortcomings of existing self-evolving agent frameworks, which, despite their capabilities, exhibit significant reliability and security vulnerabilities due to the absence of formal verification.

The motivations and detailed objectives are:

- **Addressing the Lack of Formal Guarantees:** Existing self-evolving LLM agents, while powerful, operate autonomously on unseen inputs without formal assurance of safety or correctness. This leads to issues such as agents "cheating" in program verification by modifying inputs, deleting failing tests in code repair, violating domain policies in tool use, and bypassing security protections. The core motivation is to eliminate these failures by enforcing formal behavioral specifications.
- **Formulating Constrained Learning:** The work aims to reformulate agentic code generation as a constrained learning problem. This involves combining "hard" formal specifications (ensuring safety and correctness) with "soft" objectives (capturing task utility and performance). The goal is to develop a system that can optimize performance while rigorously adhering to specified constraints.
- **Balancing Safety and Performance:** A key challenge is to create an agent synthesis algorithm that can provide formal correctness guarantees for all parameter values while simultaneously improving task-specific performance through optimization. Existing deductive synthesis methods offer guarantees but do not optimize performance, while gradient-based LLM optimization improves performance but lacks formal assurance. The research seeks to integrate both aspects.
- **Enforcing Constraints per Model Call:** Generative models (GMs), particularly LLMs, can be invoked multiple times within an agent program, each with potentially different constraints (e.g., generating Python code vs. symbolic mathematical expressions). A specific objective is to develop a mechanism that allows for the specification and enforcement of formal output constraints for each individual GM call. This mechanism must verify that the entire agentic program satisfies user-provided behavioral specifications.
- **Developing Formally Guarded Generative Models (FGGMs):** To achieve the above, the authors introduce FGGMs. The objectives for FGGMs are:
 - **Local Contract Enforcement:** Allow a planner LLM to define and enforce local input-output contracts (using first-order logic) for each generative model call.
 - **Parameter-Independent Correctness:** Ensure that these local contracts hold true for any input and any parameter setting of the underlying model, allowing for unconstrained gradient-based parameter optimization without compromising formal correctness.
 - **Verified Fallback:** Automatically wrap the underlying parametric generative model in a rejection sampler with a verified fallback mechanism, so that if model outputs fail to meet the contract, a formally correct fallback is used, guaranteeing output validity.
 - **Local Learning Objectives:** Extract local learning objectives from these contracts to guide gradient-based optimization, improving the GM's adherence to its local specifications and reducing reliance on the fallback.
- **Designing SEVerA as a Three-Stage Framework:** The overarching objective is to build SEVerA, a framework comprising Search, Verification, and Learning stages, to systematically solve the constrained learning problem for agent synthesis.

### 3. Methodology and Approach

SEVerA (Self-Evolving Verified Agents) is presented as a three-stage framework designed to solve constrained learning problems arising from agent synthesis, integrating formal guarantees with performance optimization. The core innovation is the introduction of Formally Guarded Generative Models (FGGMs).

**Formally Guarded Generative Models (FGGMs):**
FGGMs enable the planner LLM to specify a formal output contract for each generative-model call using first-order logic. These models ensure parameter-independent correctness and provide local learning objectives.
1. **FGGM Structure:** Each FGGM definition includes:
 - A unique identifier (id) and the identifier of the underlying Generative Model (GMid, e.g., an LLM or neural network).
 - A type signature (typeSig) for the FGGM.
 - Local input ($\Phi_l$) and output ($\Psi_l$) contracts expressed in first-order logic.
 - A prompting program ($f_p$) that constructs the input to the underlying GM, often tailoring natural language instructions for LLMs.
 - A verified fallback program ($f_d$) that uses only non-parametric library functions and is proven to satisfy the local contracts ($\Phi_l, \Psi_l$) unconditionally. This fallback guarantees a valid output even if the GM fails to produce one.
 - Textual information (info) for the planner LLM.
2. **FGGM Mechanism:** When an FGGM is invoked, it automatically wraps the underlying parametric GM in a rejection sampler. The GM generates a fixed number of samples (K). Each sample is checked against the local contracts using a specialized checker ($check_{A,\Phi_l,\Psi_l}$). If a sample satisfies the contract, it is accepted and returned. If all K samples are rejected, the verified fallback program ($f_d$) is executed, ensuring that every returned output satisfies the specified contract for any input and any parameter setting of the underlying model. This guarantees soundness for the local contract.
3. **FGGM Well-formedness:** Before use, each FGGM definition is validated for well-formedness. This includes type-checking the signature, validating the first-order formulas for contracts, verifying that terms in contracts use valid library functions, and proving that the fallback program ($f_d$) itself satisfies its own local contract ($\Phi_l, \Psi_l$) under the given axioms (A).

**SEVerA's Three-Stage Framework:**

1. **Search:**
 - The planner LLM (e.g., Claude Sonnet 4.5 or Qwen3-8B) first synthesizes a set of FGGM definitions, including their prompting programs ($f_p$) and fallbacks ($f_d$).
 - Subsequently, the planner LLM samples candidate parametric agent programs that invoke these FGGMs. Direct calls to raw parametric GMs are not allowed; they must be encapsulated within FGGMs.
 - The search space for these programs is a restricted subset of Dafny, a verification-aware language, allowing conditional blocks, loops, assignments, assertions, and function calls.
 - The planner is guided by task-specific instructions, available library functions (parametric $F_p$ and non-parametric $F_c$), axioms (A), and feedback from previous iterations.

2. **Verification:**
 - First, all newly synthesized FGGM definitions are checked for well-formedness (as described above).
 - If FGGMs are valid, the candidate parametric program is then formally verified against the global behavioral specifications ($\Phi, \Psi$) using Dafny's built-in verifier. The verifier leverages the local contracts proven for each FGGM.
 - This step proves program correctness (syntactic validity, termination, and compliance with $\Phi, \Psi$) for *all* possible parameter values of the embedded parametric models.
 - If verification fails, detailed error feedback is returned to the planner LLM, enabling a CEGIS (Counterexample-Guided Inductive Synthesis)-style loop for refining the candidate program. This iterative process continues until a verified program is found or the search budget is exhausted.

3. **Learning:**
 - Once a parametric program is verified, the learning step applies unconstrained gradient-based optimization to tune the parameters ($\Theta$) of the underlying GMs within each FGGM.
 - The optimization objective minimizes a combination of the global task-specific loss (L) over a dataset (D) and local conformance losses for each FGGM.
 - **Conformance Tuning:** Each FGGM's local contracts ($\Phi_l, \Psi_l$) define a local learning objective. This encourages the GM to produce outputs that satisfy its contract, thereby increasing the acceptance rate of the rejection sampler and reducing reliance on the static fallback program. The conformance loss measures the probability of a sampled output violating its contract.
 - For generative models with accessible parameters (e.g., Qwen3-8B), GRPO (Group Relative Policy Optimization) is used for fine-tuning, optimizing a reward function that combines task loss and conformance.
 - For closed-source LLMs with inaccessible parameters (e.g., Claude Sonnet 4.5), parameter tuning is skipped. Performance improvements rely solely on the planner LLM's ability to synthesize effective prompting programs ($f_p$) within the FGGMs.
 - SEVerA maintains a pool of verified, fine-tuned agents and uses their execution traces on the training data to generate feedback for the planner, guiding the search for new candidates in subsequent iterations. The agent with the lowest task loss in the pool is returned as the final solution.

### 4. Main Findings and Results

SEVerA was evaluated on four diverse tasks: constrained symbolic regression (SymReg), LLM-assisted program verification (DafnyBench, HumanEvalDafny), symbolic mathematical expression synthesis (GSM-Symbolic), and policy-compliant agentic tool use ($\tau^2$-bench). Across all benchmarks, SEVerA consistently achieved zero constraint violations while simultaneously improving task performance compared to unconstrained and state-of-the-art baselines.

#### 4.1. LLM-Assisted Program Verification (DafnyBench, HumanEvalDafny)

- **Safety (RQ1):** Baselines (LLM and DafnyBench baseline) showed significant constraint violations (8.1% for LLM, 4.0% for DafnyBench baseline on HumanEvalDafny) where agents modified the input program to achieve apparent "verification" without preserving the original logic. SEVerA (w/o constraints) also showed violations (5.1%). In contrast, the full SEVerA framework achieved a **0.0% constraint violation rate** on both HumanEvalDafny and DafnyBench.
- **Performance:** SEVerA attained the highest "Verif. & NoDiff" rates: **97.0%** on HumanEvalDafny (vs. 86.9% for the best baseline) and **89.1%** on DafnyBench (vs. 81.6% for the best baseline). This demonstrates that enforcing formal constraints actively steers the planner towards higher-quality, correct solutions.
- **Runtime:** The overhead introduced by SEVerA was moderate, approximately 1.9x to 2.5x slower than the unconstrained LLM baseline, which is attributed to the verification and rejection-sampling steps. This overhead is considered justified given the elimination of untrustworthy outputs.

#### 4.2. Agentic Tool Use ($\tau^2$-bench)

- **Safety (RQ1):** The unconstrained LLM baseline (Qwen3-8B) exhibited high violation rates (76.3% on Retail, 68.4% on Airline). SEVerA (w/o constraints) reduced these to 10.3% and 25.5%, respectively, but still showed violations. Both Agent-C (a state-of-the-art constrained agent) and the full SEVerA achieved a **0.0% violation rate**, confirming the necessity of formal policy enforcement.
- **Performance:** SEVerA achieved the highest pass rates: **53.6%** on Retail and **52.6%** on Airline. Notably, SEVerA with Qwen3-8B (an open-weight model) outperformed Agent-C with Claude Sonnet 4.5 (a frontier model), which achieved 42.2% on Retail and 39.4% on Airline, respectively.
- **Runtime:** SEVerA was also faster than Agent-C in both domains (212.4s vs. 234.7s in retail and 241.1s vs. 272.6s in airline), indicating efficient constraint enforcement.

#### 4.3. Symbolic Math Synthesis (GSM-Symbolic)

- **Safety (RQ1):** The LLM baseline (Qwen3-8B) showed a 10.6% constraint violation rate. CRANE, a constrained-decoding method, reduced violations to 2.1%. SEVerA (no parameter tuning) eliminated all violations, achieving **0.0% violation**.
- **Performance:** SEVerA (no parameter tuning) achieved 53.2% accuracy, an 8.5% improvement over CRANE (44.7%).
- **Training Impact (RQ2):** Parameter tuning with SEVerA further improved accuracy to **66.0%** while maintaining zero violations, a **12.8% additional gain** over the untuned SEVerA. This indicates that tuning models under formal constraints is effective for improving task performance. The tuned variant was also slightly faster (16.7s vs. 18.8s) due to reduced rejection-sampling iterations.

#### 4.4. Constrained Symbolic Regression (SymReg)

- **Safety (RQ1):** Baselines (PySR and LLM-SR) frequently generated programs violating behavioral specifications (up to 62.86% for PySR, 34.29% for LLM-SR). SEVerA consistently achieved a **0.00% violation rate**, finding verified solutions in 33 out of 35 instances.
- **Performance:** SEVerA achieved significantly lower Normalized Mean Squared Error (NMSE) values compared to both PySR and LLM-SR, averaged over instances where baselines did not violate constraints. For $\epsilon=0.05$ noise, SEVerA achieved NMSE of 0.0593 vs. PySR's 0.3113, and 0.0200 vs. LLM-SR's 0.1580. Similar trends were observed for $\epsilon=0.1$ noise.

#### 4.5. Constraint Decomposition (RQ3 - GSM-Symbolic Ablation)

- **Individual Contributions:**
 - SEVerA (no parameter tuning): 53.2% accuracy, 0.0% violation.
 - SEVerA (local only parameter tuning, optimizing FGGM conformance loss): Increased accuracy to 55.3%, a modest 2.1% gain. This suggests that teaching the model to satisfy per-call contracts improves output reliability and reduces fallback reliance.
 - SEVerA (global only parameter tuning, optimizing task loss L): Achieved 61.7% accuracy, an 8.5% gain. This demonstrates the direct benefit of training for semantic correctness.
 - SEVerA (full, combining both local and global losses): Achieved the highest accuracy of **66.0%**, a 4.3% gain over global-only tuning. This indicates that local conformance tuning and global task loss optimization are complementary, with both signals contributing to overall performance.

In summary, the results consistently demonstrate that SEVerA’s approach of integrating formal verification through FGGMs into the self-evolving agent synthesis process leads to agents with strong correctness guarantees (zero violations) and improved task performance. The framework’s ability to guide the planner and fine-tune models while maintaining formal correctness is a key finding.

### 5. Significance and Potential Impact

The work presented in "SEVerA: Verified Self-Evolving Agents" addresses a critical safety and reliability gap in the rapidly evolving field of LLM-based self-evolving agents. By introducing Formally Guarded Generative Models (FGGMs) and a three-stage Search-Verify-Learn framework, SEVerA makes several significant contributions:

- **Bridging Verification and Learning:** SEVerA successfully integrates rigorous formal verification with scalable, gradient-based performance optimization for LLM agents. This is a notable achievement, as previous work often necessitated a trade-off between strong correctness guarantees and the flexibility and performance benefits of modern machine learning techniques. The parameter-independent correctness property of FGGMs is central to enabling this synergy.
- **Guaranteed Safety and Correctness:** The framework provides formal, end-to-end behavioral guarantees for synthesized agents, ensuring zero constraint violations on unseen inputs. This is a substantial improvement over existing methods that often rely on runtime monitoring or post-hoc filtering, which cannot guarantee safety for all possible inputs or parameter values. This is crucial for deploying LLM agents in sensitive or safety-critical applications.
- **Improved Task Performance:** Counterintuitively, the research demonstrates that formal behavioral constraints do not hinder but actively enhance task performance. By pruning the search space of candidate programs and steering the synthesis process toward higher-quality, compliant agents, SEVerA achieves superior accuracy and pass rates compared to unconstrained and even some state-of-the-art constrained baselines. This suggests that explicit safety constraints can serve as powerful inductive biases for learning.
- **Modular and Model-Agnostic Design:** The FGGM mechanism, operating on model outputs via rejection sampling, is compatible with both open-source and closed-source generative models, overcoming a limitation of many constrained decoding approaches that require access to internal model decoding procedures. This broadens the applicability of verified agent synthesis.
- **Theoretical Foundations:** The work provides theoretical guarantees, including soundness (Theorem 5.4), which confirms that any agent returned by SEVerA satisfies its behavioral specifications, and a sufficient condition for success (Theorem 5.5), which demonstrates that the FGGM mechanism can always improve upon bare GM calls by filtering out violations.
- **Practical Applicability:** The evaluation across diverse domains (symbolic regression, program verification, symbolic math, and agentic tool use) showcases the versatility and effectiveness of SEVerA in real-world scenarios, including those with complex temporal policy constraints. The competitive runtime overhead further supports its practical utility.

The potential impact of SEVerA is significant. It lays a foundational framework for developing trustworthy and reliable LLM agents, which is essential as these agents are increasingly deployed in autonomous and critical systems. By providing a method to rigorously guarantee agent behavior while maintaining high performance, SEVerA could enable the adoption of LLM agents in domains where formal assurance is paramount, such as automated code generation for critical infrastructure, medical decision support, and financial compliance, thereby accelerating their safe integration into society.
