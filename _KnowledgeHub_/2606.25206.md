# RAVEN: Long-Horizon Reasoning & Navigation with a Visuo-Spatio-Temporal Memory

> [!summary] Summary
> RAVEN introduces a visuo-spatio-temporal memory system for robots, leveraging direct visual embeddings from foundation models to bypass the captioning bottleneck for long-horizon reasoning and navigation. The system achieves superior performance against caption-based methods, demonstrates high memory efficiency, and successfully deploys on a physical robot for complex natural language goal-reaching tasks.

## Problem

- Traditional robotic memory systems using explicit semantic maps are limited by a fixed vocabulary, hindering responses to nuanced, open-vocabulary queries.
- Raw perceptual data (e.g., video streams) is too voluminous and redundant for scalable, long-term memory storage and efficient retrieval.
- State-of-the-art caption-based memory systems suffer from a 'captioning bottleneck,' losing fine-grained visual details (shape, layout, texture) when observations are converted to text.

## Method

- **RAVEN** generates compact, information-rich visual embeddings from robot observations using pre-trained multimodal encoders, storing them with corresponding pose and timestamp in a ==vector database==.
- A Vision-Language Model (VLM) acts as an agent, iteratively invoking primitive tools for text-based, time-based, or position-based retrieval to augment its working memory with relevant visual context.
- For real-world deployment, the system integrates with RGB-D SLAM for 3D mapping and A* path planning to enable goal-reaching navigation based on VLM-predicted spatial coordinates.

## Results

- RAVEN consistently outperformed caption-based memory systems, showing a performance gap that widened to **30%** on 'hard' queries.
- Achieved significant memory compression rates (over **250x** without accuracy loss, up to 22,**315x** overall at **0.12** fps) while maintaining high performance.
- Successfully deployed on a Unitree Go1 quadruped robot, reaching up to **97.1%** success rates for natural language goal-reaching in real indoor environments, outperforming alternative approaches.

## Takeaways

> [!tip] Key Insights
> - Direct visual embeddings robustly preserve fine-grained semantic details that are often lost or inaccurately described by text-based captioning methods.
> - Providing similarity scores with retrieved memory items and ordering temporal memories chronologically significantly enhances the VLM's reasoning capabilities.
> - RAVEN offers a training-free, computationally lightweight, and plug-and-play memory system that is highly compact and scalable for long-horizon embodied AI tasks.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development of autonomous robots capable of operating effectively over extended periods in complex, dynamic environments necessitates robust and scalable memory systems. This work addresses a critical challenge within robot learning and visual navigation: enabling robots to remember previously visited locations and retrieve fine-grained visual and semantic information efficiently over long time horizons.

Traditional approaches to robotic memory often fall into two main categories: explicit semantic maps and raw perceptual streams. Explicit semantic maps, which assign predefined labels to metric representations like 3D point clouds or occupancy grids, are limited by a fixed vocabulary. This constraint prevents them from handling novel or highly specific queries, such as "Where did I last see a blue hat with a pink bow?" Raw video streams, while retaining complete observations, are generally too voluminous and redundant for direct use as a scalable memory system.

More recent advancements have explored open-vocabulary language supervision, typically by converting visual observations into text captions and storing their embeddings. However, the authors identify a "captioning bottleneck" in these state-of-the-art implicit cognitive memory pipelines (e.g., ReMEmbR). This bottleneck refers to the inherent information loss that occurs during the image-to-text conversion, where details regarding shape, precise spatial layout, and subtle visual styles are compressed into coarse textual descriptions. This compression can render retrieval brittle for queries whose discriminating details were not explicitly verbalized in the captions. Other implicit memory approaches, such as CLIP-Fields, avoid the language bottleneck by grounding features in learned 3D fields but are limited by per-scene optimization, hindering scalability across varied or changing environments. Recurrent Neural Network (RNN)-based memories often struggle with long-term forgetting, and retrieval-free context models face difficulties scaling to extremely long sequences.

RAVEN positions itself as a response to these limitations by proposing a shift from text-based memory to a direct visual representation utilizing rich visual embeddings. By leveraging the multimodal embedding space of modern visual foundation models, RAVEN aims to preserve fine-grained visual semantics that are lost in textual surrogates while retaining the scalability characteristic of vector databases optimized for efficient lookup. This approach aligns with recent findings that Retrieval-Augmented Generation (RAG) systems can benefit significantly from retrieving with multimodal embeddings rather than solely relying on text surrogates. The retrieval mechanism in RAVEN utilizes conventional vector retrieval, optimized for sub-linear complexity, which contrasts with less scalable methods like scaled dot-product attention for memory fusion. Therefore, RAVEN contributes to the landscape by offering a training-free, computationally lightweight, and information-dense memory system that aims for improved generalization and scalability for open-vocabulary, long-horizon tasks in embodied AI.

### 2. Key Objectives and Motivation

The primary motivation for this research stems from the requirements for long-term robot autonomy and effective human-robot interaction in real-world environments. For a robot to operate effectively over extended periods, it must possess a memory system that is not only compact and scalable but also capable of preserving detailed visual semantics and grounding observations precisely in space and time. This capability is essential for fulfilling diverse user queries and enabling navigation to previously encountered objects or locations.

The authors highlight several limitations of existing robotic memory systems that motivate the development of RAVEN:
1. **Limited Vocabulary in Conventional Maps:** Traditional categorical semantic maps and metric maps are restricted to a predefined set of labels. This inherent limitation prevents robots from answering nuanced queries about objects whose descriptions fall outside this vocabulary (e.g., "a blue hat with a pink bow").
2. **Inefficiency of Raw Perceptual Data:** While raw video streams capture complete observations, their sheer volume and redundancy make them impractical for direct use as a long-term memory, posing significant storage and retrieval challenges.
3. **Lossy Nature of Caption-Based Memory:** State-of-the-art approaches employing open-vocabulary language supervision often rely on captioning visual observations. This image-to-text captioning stage introduces a "semantic bottleneck," where fine-grained visual attributes (such as shape, spatial layout, texture, and style) are compressed into coarse textual descriptions. Consequently, critical details might be lost, rendering retrieval ineffective if the distinguishing visual features were not explicitly verbalized in the caption.

Given these challenges, the central objective of this work is to develop a novel memory representation that is both compact and information-rich, moving beyond text-based memory to a direct visual representation.

The key objectives of RAVEN are:
- To propose and implement **RetrievAl via Visual Embeddings for Navigation (RAVEN)**, a memory system that directly operates on rich visual embeddings from modern visual foundation models. This aims to preserve fine-grained visual semantics that are otherwise lost in text-based surrogates.
- To ensure the **scalability and efficiency** of the memory system by storing these visual embeddings with corresponding pose and time information in a vector database, enabling efficient storage and retrieval.
- To facilitate **long-horizon robotic question answering and navigation** by grounding retrieved visual information in a spatial map.
- To enable an **agentic reasoning loop** where a Vision-Language Model (VLM) can iteratively invoke function calls to retrieve relevant memory entries, reason over contextual information, and generate accurate answers or navigation goals.
- To demonstrate that this approach **outperforms caption-based memory systems** and achieves performance comparable to frontier VLMs on long-horizon tasks, while incurring significantly lower retrieval costs.
- To validate the **real-world feasibility** of RAVEN through deployment on a physical robot for natural language goal-reaching tasks in various indoor environments.

### 3. Methodology and Approach

RAVEN is designed as an agentic memory system for robotic question answering and navigation, operating in two distinct phases: Memory Building and Querying & Execution.

**Phase I: Memory Building through Exploration**
In this initial phase, the robot actively explores an environment over a defined time horizon to construct its memory and a spatial map.
- **Data Acquisition:** The robot collects a continuous sequence of observations, including RGB video frames ($O_{1:N}$), depth maps, and proprioceptive data such as 3D poses ($p_i = (x_i, y_i, z_i)$) and world-clock timestamps ($t_i$).
- **Visual Embedding Generation:** Each RGB frame ($o_i$) is processed by a pre-trained multimodal encoder (e.g., CLIP, SigLIP, Seed1.6-Embedding, QQMM-v2). This encoder transforms the high-dimensional image data into compact latent representations, or visual embeddings ($z_i$).
- **Visuo-Spatio-Temporal Memory Storage:** These visual embeddings are then indexed alongside their corresponding robot pose ($p_i$) and timestamp ($t_i$) within a vector database. This forms a composite "visuo-spatio-temporal memory" triplet for each observed frame: $\{m_i\}^N := \{(p_1, t_1, z_1, o_1)..., (p_N, t_N, z_N, o_N)\}$. The vector database, implemented using frameworks like FAISS or Milvus, is optimized for efficient nearest-neighbor searches, offering sub-O(N) time complexity for retrieval.

**Phase II: Querying & Execution**
Following memory construction, the robot addresses natural language queries ($q$) by leveraging its stored memory.
- **Reasoning with a Tool-Using Agent:** A Vision-Language Model (VLM) acts as an agent, orchestrating an iterative loop of perception, reasoning, and tool usage, conceptualized as a finite state machine.
 - **Context Management:** The VLM maintains a working memory, or current context ($R_0$).
 - **Iterative Retrieval:** If the accumulated evidence in the current context is insufficient to answer the query, the VLM invokes one of four primitive retrieval tools:
 1. **Text-based retrieval:** The VLM generates an internal query ($\hat{q}$) which is embedded and used to search the vector database for visual memories ($z_i$) with high cosine similarity. This returns the top-K most relevant visual embeddings.
 2. **Time-based retrieval:** This tool returns consecutive memory entries starting from a specified timestamp. The paper notes that a chronological ordering for time-based retrieval is more effective than similarity-based ranking, aligning with how multimodal models process temporal dynamics.
 3. **Position-based retrieval:** This tool finds memory entries that are spatially nearest to a given proposed location $(\hat{x}_q, \hat{y}_q, \hat{z}_q)$.
 4. **Image-based retrieval:** (Discussed in the Appendix as an extension) This tool allows the agent to issue image queries for retrieval.
 - **Context Augmentation:** Each retrieval call returns a set of K memory entries ($\{m'_i\}_K$), including retrieved locations, timestamps, and images. These are appended to the VLM's context ($R_{\tau+1} = R_\tau \cup \{m'_i\}_K$). Crucially, similarity scores for retrieved items are also provided to the VLM, serving as confidence cues to aid reasoning.
 - **Decision and Output:** The VLM continuously evaluates the updated working memory. Once confident, it exits the loop and produces a structured output: a textual answer, a spatial goal $(\hat{x}, \hat{y}, \hat{z})$, or a temporal reference.
- **Exploration & Navigation Execution (Real-World Deployment):**
 - **Mapping:** For real-world deployment on a Unitree Go1 quadruped robot equipped with a ZED 2i camera and Jetson Orin NX, RGB-D SLAM is used to reconstruct a 3D occupancy map during exploration. This 3D point cloud is filtered by height and projected onto a 2D plane to create an occupancy map.
 - **Exploration Strategy:** A greedy frontier exploration algorithm identifies candidate frontiers (boundaries between explored and unexplored free space). The robot plans a collision-free path to the nearest frontier using an A\* algorithm on a dilated occupancy map, guided by a low-level PD controller.
 - **Navigation:** When a spatial goal coordinate is predicted by the RAVEN system, the robot utilizes the pre-built occupancy map and A\* path planning to navigate directly to the target location without further exploration. Success is determined by arriving within a specified distance of the ground-truth target(s).

The core of RAVEN's methodology lies in its ability to harness the rich semantic information embedded in visual representations directly, integrate this with spatial and temporal context, and enable an intelligent agent to leverage these memories through an iterative, tool-using reasoning process. This design aims for a simple, efficient, training-free, and plug-and-play memory system capable of scaling to long trajectories and practical embodied decision-making.

### 4. Main Findings and Results

The evaluation of RAVEN focused on three key questions: information-richness of visual embeddings, scalability for long memory horizons, and real-world feasibility. The system was benchmarked against existing datasets (NaVQA, FindingDory) and a newly curated benchmark (RAVEN-QA) across simulated and real-world scenarios.

**Information-Richness: Raw Visual Embeddings vs. Captions**
- **Superiority over Caption-Based Systems:** RAVEN consistently outperformed caption-based memory systems like ReMEmbR across various benchmarks and environments (Table 1, Figure 3). The performance gap was particularly pronounced for "hard" queries, widening from approximately 13% on simple queries to 30% on hard queries (Table 8). This suggests that direct visual embeddings robustly preserve fine-grained semantic details (e.g., secondary objects, subtle visual features) that are frequently lost or inaccurately described due to the "captioning bottleneck" in text-based methods. ReMEmbR's failures were attributed to either under-captioning (loss of visual details) or over-captioning (introduction of irrelevant noise or misleading descriptions).

**Scalability and Efficiency**
- **Outperformance and Efficiency over Frontier VLMs:** RAVEN demonstrated comparable or superior performance to frontier Vision-Language Models (VLMs) used in a "VLM Only" baseline, while achieving significantly higher memory efficiency (10x) and lower retrieval costs (Table 2, Figure 3). This is attributed to RAVEN's precise retrieval mechanism, which shortens the working memory context presented to the VLM, allowing it to focus undiluted attention on relevant frames (Figure 4).
- **High Compactness:** RAVEN is a highly compact memory system. It retained over 97% of its performance when using frontier base models and 67% with smaller open-source models. The system achieved over 250x storage compression without a loss in accuracy. Impressively, downsampling videos to 0.12 frames per second (fps) resulted in a 22,315x compression rate over raw RGB data while still preserving 90% of its original capability (Figure 5).
- **Improved Reasoning with Context:** The provision of similarity scores alongside retrieved memory items to the VLM agent consistently improved performance, acting as a useful confidence cue (Figure 15). Furthermore, chronological ordering of retrieved memories proved more effective for time-based queries than similarity-based ordering, aligning with how modern multimodal models process temporal information (Table 12, Figure 16).

**Real-World Feasibility**
- **Successful Robot Deployment:** RAVEN was successfully deployed on a Unitree Go1 quadruped robot for long-horizon navigation tasks involving natural language goal-reaching in real indoor environments. The system achieved high success rates, up to 97.1% (SigLIP + GPT-5.2) and 92.4% with the main configuration (QQMM-v2 + Gemini-2.5-Flash), significantly outperforming alternative approaches (Table 1, Figure 4).
- **Robustness and Consistency:** RAVEN exhibited greater consistency across repeated runs (lower variance of 0-5%) compared to the VLM Only baseline (1-6% variance), indicating enhanced reliability for real-world applications. The system also demonstrated robustness to incomplete environmental exploration, achieving near-perfect task accuracy even with approximately 20% footprint coverage (Figure 18).
- **Performance of Embedders and VLMs:** While closed-source VLMs generally performed best, medium-sized open VLMs (e.g., Gemma3-27b, Qwen3-VL-32b) often performed worse than or only slightly better than a multimodal embedder-only baseline (Table 1, Table 8). This suggests that for offline deployments without internet access, a direct embedder-only approach might be preferable over incorporating less capable open VLMs. The study also highlighted the synergistic benefits of using images rather than text as VLM inputs for visuo-spatio-temporal retrieval (Table 7).

### 5. Significance and Potential Impact

The development of RAVEN represents a notable advancement in the field of robotic memory and embodied artificial intelligence, addressing fundamental challenges in long-term robot autonomy and human-robot interaction.

**Enhanced Semantic Understanding and Retrieval:** By directly leveraging high-fidelity visual embeddings as a memory substrate, RAVEN fundamentally bypasses the "captioning bottleneck" inherent in many language-centric memory systems. This allows robots to retain and retrieve information based on fine-grained visual details, subtle features, and implicit semantic relationships that are often lost in textual descriptions. This capability is critical for handling complex, open-vocabulary queries in diverse and unstructured environments, moving beyond the limitations of fixed-vocabulary semantic maps.

**Scalability and Efficiency for Long-Term Deployment:** RAVEN offers a memory system that is both compact and highly scalable. The demonstrated significant storage compression rates (e.g., 250x over raw videos without accuracy loss, up to 22,315x overall) and superior retrieval efficiency (10x higher than naive VLM approaches) are crucial for practical, lifelong robot deployments. This enables robots to operate for extended periods in large environments, accumulating vast amounts of experience without being overwhelmed by data volume or retrieval latency. Such efficiency is vital for continuous learning and adaptation in dynamic real-world settings.

**Robustness and Practicality for Embodied AI:** The system's demonstrated robust performance across simulated and real-world tasks, its consistent accuracy across multiple runs, and its ability to function effectively even with incomplete environmental exploration underscore its practical applicability. The training-free, plug-and-play nature of RAVEN facilitates its integration into existing robot planning and control architectures, reducing development overhead. This makes it a readily deployable solution for a range of embodied decision-making tasks, from assistive robots in homes to logistical robots in industrial settings.

**Validation of Multimodal Foundation Models:** This work validates the utility of multimodal foundation models for robotic memory, suggesting that retaining sparse, high-fidelity visual representations along with retrieval mechanisms is more effective than immediately compressing visual experience into language or concise prompts. This implies a potential paradigm shift toward memory architectures that prioritize direct visual reasoning for greater nuance and precision in understanding the world.

**Future Research Implications:** While robust, RAVEN's performance is bounded by the quality and alignment capabilities of its pre-trained multimodal encoders. This highlights a future research direction in domain-specific fine-tuning of embeddings to better suit robotic tasks. Furthermore, the current implementation treats memory as a static database. Future work could focus on developing mechanisms to handle highly dynamic environments, enabling robots to update, prune, or adapt their memory entries in response to environmental changes, thereby facilitating truly adaptive lifelong learning.
