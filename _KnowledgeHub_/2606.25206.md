# RAVEN: Long-Horizon Reasoning & Navigation with a Visuo-Spatio-Temporal Memory

> [!summary] Summary
> RAVEN introduces a visuo-spatio-temporal memory system for robots, leveraging direct visual embeddings from foundation models to bypass the captioning bottleneck for long-horizon reasoning and navigation. The system achieves superior performance against caption-based methods, demonstrates high memory efficiency, and successfully deploys on a physical robot for complex natural language goal-reaching tasks.

## Problem

- Traditional robotic memory systems using explicit semantic maps are limited by a fixed vocabulary, hindering responses to nuanced, open-vocabulary queries.
- Raw perceptual data (e.g., video streams) is too voluminous and redundant for scalable, long-term memory storage and efficient retrieval.
- State-of-the-art caption-based memory systems suffer from a 'captioning bottleneck,' losing fine-grained visual details (shape, layout, texture) when observations are converted to text.

## Method

- **RAVEN** generates compact, information-rich visual embeddings from robot observations using pre-trained multimodal encoders, storing them with corresponding pose and timestamp in a ==vector database==.
- A Vision-Language Model (VLM) acts as an agent, iteratively invoking primitive tools for text-based, time-based, or position-based retrieval to augment its working memory with relevant visual context.
- For real-world deployment, the system integrates with RGB-D SLAM for 3D mapping and A* path planning to enable goal-reaching navigation based on VLM-predicted spatial coordinates.

## Results

- RAVEN consistently outperformed caption-based memory systems, showing a performance gap that widened to **30%** on 'hard' queries.
- Achieved significant memory compression rates (over **250x** without accuracy loss, up to 22,**315x** overall at **0.12** fps) while maintaining high performance.
- Successfully deployed on a Unitree Go1 quadruped robot, reaching up to **97.1%** success rates for natural language goal-reaching in real indoor environments, outperforming alternative approaches.

## Takeaways

> [!tip] Key Insights
> - Direct visual embeddings robustly preserve fine-grained semantic details that are often lost or inaccurately described by text-based captioning methods.
> - Providing similarity scores with retrieved memory items and ordering temporal memories chronologically significantly enhances the VLM's reasoning capabilities.
> - RAVEN offers a training-free, computationally lightweight, and plug-and-play memory system that is highly compact and scalable for long-horizon embodied AI tasks.
