# GameFactory: Creating New Games with Generative Interactive Videos

> [!summary] Summary
> GameFactory is a framework that generates interactive game videos by leveraging large-scale pre-trained video diffusion models. It enables action-controllable and scene-generalizable game content creation, moving beyond style-locked game-specific engines.

## Problem

- Existing generative game engines lack scene generalization, often overfitting to specific game styles and physics, limiting the creation of diverse new games.
- Achieving precise action controllability, particularly for both discrete keyboard inputs and continuous mouse movements, within generated videos is a core technical challenge.
- The impracticality of collecting large-scale, unbiased, action-annotated datasets for diverse open-domain game environments hinders generalizable model training.

## Method

- A transformer-based ==latent video diffusion model== forms the core, enhanced with a specialized ==Action Control Module== to integrate granular user inputs.
- The **GF-Minecraft** dataset, custom-collected from Minecraft, provides unbiased action distributions and diverse scene descriptions to facilitate robust action control learning.
- A ==multi-phase training strategy== combined with a ==LoRA domain adapter== decouples game style from action control, allowing for generalization to open-domain scenes by preserving the base model's generative priors.

## Results

- **GameFactory** achieved superior action following and preserved the generative priors of the base model in open-domain scenarios, outperforming one-phase fine-tuning by maintaining higher generation quality and text alignment.
- The GF-Minecraft dataset enabled the model to correctly execute rare or complex actions that models trained on human-biased datasets often failed to perform.
- The framework successfully generated long, continuous interactive videos exceeding **300 frames**, demonstrated implicit collision detection, and showed transferability of learned control to different game types like racing.

## Takeaways

> [!tip] Key Insights
> - Decoupling game-specific visual styles from action control mechanisms is critical for enabling generative models to create interactive content in diverse, open-domain scenes.
> - Training data with an unbiased distribution of atomic actions, rather than human-biased gameplay, leads to superior and more robust action following, especially for less frequent actions.
> - Different integration methods for action control module—cross-attention for discrete inputs and concatenation for continuous inputs—optimize the model's ability to interpret and respond to varied user actions.
