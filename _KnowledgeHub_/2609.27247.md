# Memory That Changes Action Is Not Memory That Guides It: Counterfactual Auditing of History-Conditioned Robot Policies

> [!summary] Summary
> The Counterfactual Memory Audit (CMA) is an evaluation protocol for frozen history-conditioned robot policies. It builds two task-consistent pasts that reconverge to a verified-identical present, queries the policy once per memory under common randomness, and scores each saved action in both evaluator worlds across four levels: sensitivity, warranted choice, matched-world value, reliability. Audited policies change actions without reliably choosing the branch their memory warrants.

## Problem

- Memory benchmarks credit policies at the episode level, but task success can hide a wrong local decision that later replanning recovers, certifying outcome rather than decision.
- Probing and retrieval accuracy show historical information is decodable or accessible, yet accessibility never establishes that the stored content is actually used for the task.
- Action-distance and ablation tests detect that behavior changes under memory perturbation, but an action can change without changing the task branch the memory warrants.

## Method

- **CMA** protocol: two lawful histories built from the task's own motion primitives update native memories, then reconverge to a verified-exactly-equal current packet; the frozen policy is queried once per memory under common randomness.
- Four ==decision-level metrics==: executed-action sensitivity, signed faithfulness from a preregistered branch oracle with choice margin, matched-world value as a World-by-Memory contrast, and per-pair bidirectional reliability across all registered seeds.
- Native-rollout interventions: event-triggered replacement of the declared history carrier with own or donor content, plus ==matched-prefix restoration== of a 4096-byte protected anchor tensor after an injected bank clear.

## Results

- On Mem-0 Put Back, all **64** pairs change action with correct-choice **0.729**, faithfulness **0.529** and value **0.185**, yet only **20/64** pairs are fully reliable and regret is **0.442**.
- At the later Swap decision, all **24** pairs change action (sensitivity **0.059**) but the branch never changes: correct-choice **0.5**, faithfulness **0**, zero fully reliable pairs.
- Opposite-target history replacement drops success to **0/48** with every continuation committing to the donor target; anchor restoration lifts Swap success from **6/36** to **20/36**, plus **38.9 points**.

## Takeaways

> [!tip] Key Insights
> - Reacting to memory is not using it: sensitivity, warranted choice, physical value and per-pair reliability are distinct verdicts that dissociate on one frozen checkpoint.
> - Implement memory as a declared, protectable component; a kilobyte-scale anchor can restore competence lost to faults as well as a full history rebuild.
> - On hardware, action-seed noise can exceed the memory-induced action difference, so decision-level audits need matched seeds and per-pair, bidirectional reporting.

## Detailed Report

### 1. Overview

A robot can return a block to its original tray only if it remembers which tray the block came from. The hard case is when two lawful histories lead to the same visible scene, with both candidate trays now empty, but call for different returns. The authors test the policy at that identical present. They change the stored history, leave what the policy currently sees unchanged, and check whether the resulting action chooses the branch that history warrants. This matters because task success can conceal a wrong local choice, while a changed action can still head down the same task branch. On Mem-0, actions change in every audited Put Back pair, but just 20 of 64 pairs are reliable in both history directions across all three action-seed repeats. At the later Swap decision, actions also change in every pair, yet the policy selects the same branch under both memories.

An illustrative frame sequence from one frozen Put Back pair, not a results summary. The two histories mark different origin mats. After reconvergence, both candidate mats are empty, so the warranted return is absent from the current scene alone.

### 2. Holding the present fixed and swapping the past

The audit follows a fixed sequence:

1. Construct two task-consistent histories with different warranted branches.
1. Let each history update the policy's native memory.
1. Reconverge the two histories to a verified-identical current input.
1. Query the same frozen policy once per memory, using common action randomness.
1. Save both actions, then score each one in both evaluator worlds.

The evaluator worlds define branch correctness and physical value, but they are never input to the policy. A failed equality check excludes a pair, and pair eligibility is outcome-blind.

The authors call this the CMA protocol. It asks four questions:

- **Sensitivity:** does the action change?
- **Choice:** does it select the branch warranted by its matching memory?
- **Matched-world value:** how does physical progress compare when memory matches versus mismatches the evaluator world?
- **Reliability:** within a pair, are both directions correct for every registered seed?

Ambiguous oracle outcomes are distinct from both correct and incorrect choices. The independent unit is the pair cluster, not each direction, world, or repeated seed.

### 3. What action change and averages miss

Executed action sensitivity, $S_{\text{exec}}$, is the preregistered distance between saved action chunks. Signed faithfulness is a signed summary that penalizes wrong choices and treats ambiguity separately. $U_{1}$ is the one-chunk matched-world contrast in raw signed progress.

**Put Back.** Mem-0 has $S_{\text{exec}}=0.054$ [95% pair-cluster bootstrap CI 0.051–0.057], correct-choice rate 0.729 [0.677–0.781], signed faithfulness 0.529, and $U_{1}=0.185$ [0.155–0.215]. Only 20/64 pairs are fully reliable. A positive average matched-world value therefore does not imply reliable choices pair by pair.

**Later Swap.** Every one of 24 pairs changes action, with $S_{\text{exec}}=0.059$ [0.053–0.065], but the selected branch never changes. The correct-choice rate is 0.5, signed faithfulness is 0, and 0/24 pairs are fully reliable.

Horizontal jitter is for visibility. (B) Per-pair bidirectional correctness over three seeds, with a mean of 0.458; 20/64 pairs are fully reliable. (C) Two 31-point paths from one later-Swap pair start together, differ, and both select branch b. The cohort statistics come from the 24 pairs.

### 4. A past must pick the branch

When today's scene cannot distinguish two task histories, changed behavior falls short as evidence. The audit instead asks whether the action follows the branch that history warrants. The constructed audit isolates decisions at deliberately matched, perceptually aliased states. It does not establish how often such states occur naturally. The evidence is limited to the audited policies, tasks, and interventions.
