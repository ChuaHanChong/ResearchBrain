# Label, Verify, Correct: A Simple Few Shot Object Detection Method

> [!summary] Summary
> Researchers at the University of Oxford developed "Label, Verify, Correct" (LVC), a pseudo-labelling method for few-shot object detection that expands novel class training data. This approach leverages self-supervised features and cascaded regressors to generate high-quality pseudo-annotations, resulting in state-of-the-art performance on MS-COCO and PASCAL VOC benchmarks.

## Problem

- "Supervision collapse" where detectors, trained on abundant base categories, treat novel objects as background, leading to biased features and poor generalization.
- The Region Proposal Network (RPN) and RoI features struggle to identify or discriminate novel categories effectively due to the initial base training bias.
- Extreme class imbalance in few-shot settings, with limited novel class examples (K-shot) causing overfitting and inadequate generalization ability.

## Method

- An improved ==two-phase fine-tuning== strategy for ==Faster R-CNN==, updating RPN, RoI, and classification layers with data augmentations to create a stronger baseline detector.
- The **"Label, Verify, Correct" (LVC)** ==pseudo-labelling== pipeline, which involves sourcing initial novel class candidates, verifying their labels using ==kNN with DINO ViT features==, and correcting bounding box precision with ==cascaded regressors==.
- End-to-end retraining of the detector using both original ground truth and the high-quality pseudo-annotations, incorporating ==ignore regions== for unverified detections to prevent misclassification.

## Results

- Ablation studies demonstrated that Label Verification boosts novel AP by **3.4 points**, and Box Correction further adds **3.7 points**, confirming the individual contributions of each LVC step.
- Achieved state-of-the-art performance on MS-COCO for **K=30 shots**, showing improvements of up to **2.9 nAP**, **6.1 nAP50**, and **10.4 nAP75** compared to previous methods.
- Consistently delivered state-of-the-art or highly competitive performance across various K-shot settings on PASCAL VOC, while maintaining strong base class detection capabilities.

## Takeaways

> [!tip] Key Insights
> - Mitigating "supervision collapse" in few-shot object detection necessitates updating RPN and RoI layers in addition to the classification head, supported by extensive data augmentations.
> - The quality of pseudo-annotations is paramount, with rigorous label verification (using self-supervised features) and precise box correction yielding substantial performance gains.
> - Strategically incorporating "ignore regions" for unverified novel instances during end-to-end retraining prevents them from being incorrectly treated as background, enhancing overall model robustness.

## Detailed Report

### 1. How this Work Fits into the Broader Research Landscape

Object detection, the task of identifying and localizing objects within images, has achieved significant advancements with deep learning models trained on large, exhaustively annotated datasets such as MS-COCO and PASCAL VOC. However, this success is contingent on the availability of extensive labeled data for each category. The broader research landscape increasingly focuses on addressing the limitations of such data-intensive paradigms, particularly the challenge of expanding an object detector's vocabulary to new categories with only a limited number of training instances. This problem is known as Few-Shot Object Detection (FSOD).

Current FSOD methods generally fall into two categories: meta-learning approaches and two-phase fine-tuning strategies. Meta-learning methods aim to learn "how to learn" from a few examples, often involving complex network architectures or specialized training procedures. Two-phase fine-tuning, exemplified by approaches like TFA (Frustratingly Simple Few-Shot Object Detection), typically involves an initial training phase on base categories with abundant data, followed by a second phase where only a small number of layers (e.g., the final classification layer) are fine-tuned using the few available novel class examples. This work positions itself within the two-phase fine-tuning paradigm, but it identifies and addresses critical limitations inherent in existing two-phase strategies, particularly the issue of "supervision collapse."

"Supervision collapse" occurs when an object detector, initially trained on base categories, treats novel class instances as background, leading to features that are biased against novel objects. This manifests as poor generalization of the Region Proposal Network (RPN) to novel objects and a lack of discriminative power in RoI features for novel categories. Furthermore, FSOD inherently deals with extreme class imbalance, where the number of novel class samples is orders of magnitude smaller than base class samples.

This paper proposes a pseudo-labelling method to mitigate these issues. While self-training and semi-supervised object detection also utilize pseudo-labels to leverage unlabelled data, they typically assume an unlabelled dataset where all objects are unknown, and therefore, "supervision collapse" to novel categories is not the primary concern. This work specifically tailors its pseudo-labelling approach to the FSOD context, where the objective is to *find* novel instances within an existing training set that were initially treated as background. By refining the pseudo-labelling process through verification and correction steps, the authors aim to generate higher-quality annotations for novel classes, thereby increasing training data and reducing class imbalance, a distinct contribution to the FSOD landscape. The integration of self-supervised learning features (DINO ViT) for label verification is also a notable aspect, leveraging recent advancements in unsupervised representation learning to address the data scarcity in FSOD.

### 2. Key Objectives and Motivation

The primary objective of this research is to advance Few-Shot Object Detection (FSOD), enabling an existing object detector to learn to detect instances of new categories with only a limited number of training examples (K-shot annotations). This capability aims to bridge the gap between human learning, which can rapidly adapt to new categories from few examples, and traditional computer vision systems that demand extensive labeled data.

The motivation for this work stems from two critical limitations identified in current FSOD training procedures, particularly when using modern two-stage detectors like Faster R-CNN:

1. **"Supervision Collapse":** During the initial "Base Training" phase, where the detector is trained on abundant data for a set of "base categories," instances belonging to "novel categories" are implicitly treated as background. This creates a bias in the learned features, making the detector's components (e.g., the Region Proposal Network or RPN, and the RoI feature module) less effective at identifying or discriminating novel class objects.
 - **RPN Generalizability:** An RPN trained solely on base categories often fails to propose regions for novel object instances, leading to many false negatives and limiting the detector's recall for new classes. This is critical because subsequent classification and regression steps depend on the quality of these initial proposals.
 - **Feature Transferability:** Features learned by the image encoder and RoI module during base training may not be discriminative enough to classify novel instances accurately. When only the final classification layer is fine-tuned for novel classes (as in some prior works), the underlying features remain biased, resulting in poor precision for novel class detection.

2. **Extreme Class Imbalance:** In the few-shot setting, only K instances (e.g., 1 to 30) are available per novel category for training, while base categories have a much larger number of samples. This severe imbalance can lead to models overfitting to the few novel examples and lacking generalization ability. It also makes it difficult to train robust classification heads for novel categories.

To address these issues, the paper proposes to expand the novel class annotation set by sourcing high-quality pseudo-annotations from unlabelled images within the existing dataset. However, a naive application of pseudo-labelling with initial model predictions typically yields suboptimal performance due to inherent noise (incorrect class labels or imprecise bounding boxes). This motivates the development of specific mechanisms to improve the precision of the pseudo-labelling process.

Specifically, the key motivations for the proposed methodology are:
- To generate a substantial number of reliable training instances for novel categories, thereby alleviating class imbalance.
- To counteract "supervision collapse" by providing the detector with novel class supervision during end-to-end retraining, allowing it to learn more general features that are not biased against novel objects.
- To improve the quality (both class labels and bounding box coordinates) of pseudo-annotations, moving beyond naive predictions, to ensure that the expanded training data is beneficial rather than detrimental to performance.

### 3. Methodology and Approach

The proposed method, termed "Label, Verify, Correct" (LVC), is a pseudo-labelling strategy designed to expand the training data for novel classes in few-shot object detection (FSOD). It operates in several sequential stages, beginning with an enhanced baseline detector.

#### 3.1. Baseline Detector and Training Strategy

The foundation of the method is a Faster R-CNN detector with a Feature Pyramid Network (FPN). The training involves a two-phase procedure:
- **Base Training:** The model is initially trained on base categories using standard exhaustive annotations. No modifications are made at this stage.
- **Novel Training (Improved Baseline):** Unlike some prior works that only fine-tune the classification layer (Φ_CLS), this method emphasizes updating more parameters. Based on empirical evaluation, it is determined that updating all parameters specific to the Region Proposal Network (Φ_RPN) and the Region of Interest (RoI) feature module (Φ_ROI), in addition to the classification layer (Φ_CLS), is crucial. This helps alleviate "supervision collapse" by enabling the RPN to propose novel regions and allowing the RoI features to become more discriminative for novel classes, even with limited K-shot data. Data augmentations, including RandomCrop, ColorJitter, and Mosaic (for MS-COCO), along with Dropout on RoI activations, are applied during this phase to further combat overfitting.

#### 3.2. Pseudo-Labelling Procedure (Label, Verify, Correct)

The core of the LVC method involves three distinct steps applied to unlabelled images using the detector trained in the "Novel Training" phase:

1. **Candidate Sourcing (Label):**
 - The detector from the "Novel Training" phase is used to perform inference on the large set of unlabelled training images (D).
 - This generates an initial set of "candidate detections" (ˆY_NOVEL), each with a predicted class label and bounding box coordinates.
 - To manage the volume and initial quality, only novel class detections with a high confidence score (e.g., q > 0.8) are retained. This step, while generating many potential instances, also produces noisy pseudo-annotations with incorrect labels and imprecise boxes.

2. **Label Verification (Verify):**
 - This step aims to filter out candidate detections with incorrect class labels.
 - A kNN classifier is constructed specifically for the novel categories. To ensure high-quality feature representations from limited data, the kNN classifier utilizes features from a self-supervised vision model (specifically, the CLS token output from a DINO ViT-S/8 model).
 - Features are extracted for each of the given K-shot novel class ground truth annotations, forming the kNN's training data.
 - Similarly, features are extracted for each candidate detection (by cropping the image using its bounding box and resizing).
 - A candidate detection is "verified" if its kNN classification (based on cosine similarity) matches the class label predicted by the baseline detector. This process removes a large number of false positives from the candidate set.

3. **Box Correction (Correct):**
 - Following label verification, this step refines the bounding box coordinates for all remaining (verified) candidate detections.
 - Inspired by Cascade R-CNN, a separate model consisting of three class-agnostic regressors is trained. These regressors are designed to progressively improve bounding box quality, each specializing in boxes within a specific IoU range (e.g., IoU > 0.3, > 0.5, > 0.7).
 - During Novel Training, RPN proposals are divided by IoU thresholds and passed through corresponding regressors.
 - Once trained, the bounding boxes of the verified candidate detections are sequentially fed through these three regressors, leading to significantly improved box precision.

#### 3.3. End-to-End Retraining with Pseudo-Annotations

After the LVC steps, a large set of high-precision pseudo-annotations (with verified class labels and corrected bounding boxes) for novel categories is obtained. These pseudo-annotations, combined with the original ground truth annotations for base categories, are then used to retrain the final object detector end-to-end. This comprehensive retraining strategy aims to address class imbalance and further alleviate "supervision collapse" by providing robust supervision for all categories.

#### 3.4. Ignore Regions

To prevent undiscovered novel instances (those not captured or verified by the pseudo-labelling process) from being wrongly treated as background during end-to-end retraining, "ignore regions" are introduced. All unverified novel class detections from the baseline detector (including those with scores below 0.8) are designated as ignore regions. During retraining, RoIs overlapping significantly with ignore regions are treated as neither foreground nor background for the second-stage detector, while the RPN is still trained to propose regions covering them.

### 4. Main Findings and Results

The research paper presents empirical evidence to support its claims regarding the effectiveness of the proposed "Label, Verify, Correct" (LVC) method and the importance of specific training components in Few-Shot Object Detection (FSOD).

#### 4.1. Ablation Studies

- **Importance of Augmentations and Improved Novel Training:**
 - The study demonstrated that standard augmentations (ColorJitter, RandomCrop, Mosaic) have a limited impact when only the classification layer (Φ_CLS) is fine-tuned, as in some prior baseline methods (e.g., TFA).
 - However, when the "Novel Training" strategy is improved by fine-tuning the Region Proposal Network (Φ_RPN) and the RoI feature module (Φ_ROI) in addition to Φ_CLS, augmentations yield a substantial performance boost. Specifically, the combination of augmentations improved novel class Average Precision (nAP) by 3.2 points (from 13.0 nAP for baseline B1 to 16.2 nAP for C2 with augmentations and improved training). Mosaic augmentation was particularly beneficial for small objects.
 - Adding Dropout on RoI activations provided a further marginal improvement (0.4 nAP). These findings indicate that extensive augmentations are crucial for FSOD when more layers are enabled for fine-tuning, helping to mitigate overfitting on limited novel class data.

- **Ablation of Pseudo-Labelling Steps:**
 - **Candidate Sourcing Only:** Treating naive detections from the baseline detector as pseudo-annotations yielded a modest improvement of 1.8 nAP over the strong baseline (16.6 nAP to 18.4 nAP), highlighting the limitations of unrefined pseudo-labelling.
 - **+ Label Verification:** The introduction of the Label Verification step, which filters out misclassified candidates using a kNN classifier based on self-supervised features, provided an additional significant boost of 3.4 nAP (from 18.4 nAP to 21.8 nAP). This indicates that accurately labeled pseudo-annotations are critical for performance.
 - **+ Box Correction:** The final Box Correction step, which refines bounding box coordinates using a cascade of regressors, further improved performance by 3.7 nAP (from 21.8 nAP to 25.5 nAP). This improvement was particularly evident in the nAP75 metric, demonstrating a reduction in bounding box regression errors and an increase in overall detection quality.
 - These ablation results quantitatively confirm the individual contributions of each step in the LVC pipeline to producing high-quality pseudo-annotations.

- **Effect on Base Class Performance:**
 - The improved "Novel Training" (baseline in ablation) led to a drop in base class Average Precision (bAP) from 36.1 to 29.5, suggesting a trade-off where novel class performance initially comes at the expense of base classes.
 - The full LVC pseudo-labelling method, however, not only enhanced novel class detection but also recovered and maintained base class performance (bAP of 33.3, bAP50 of 53.6, bAP75 of 36.1), demonstrating that the expanded and refined pseudo-annotations enable the detector to generalize across both base and novel categories more effectively.

- **Utility of Ignore Regions:**
 - An additional ablation showed that "ignore regions" significantly improved performance (by 4.4 nAP, 3.5 nAP50, and 4.7 nAP75). This indicates that explicitly handling undiscovered novel instances as neither foreground nor background prevents them from being detrimental during end-to-end retraining.

#### 4.2. Quantitative Benchmarking

The LVC method was benchmarked against existing state-of-the-art (SotA) approaches on MS-COCO and PASCAL VOC datasets for various K-shot settings (K=10, 30 for MS-COCO; K=1, 2, 3, 5, 10 for PASCAL VOC).

- **MS-COCO Results:**
 - Using a ResNet-50 backbone, the "Baseline" (improved Novel Training with augmentations) outperformed many existing works for K=30 shots.
 - The full "Pseudo-Labelling" method (LVC) achieved state-of-the-art performance for K=30, showing significant boosts of up to 2.9 nAP, 6.1 nAP50, and 10.4 nAP75 over previous methods.
 - With a ResNet-101 backbone, the LVC method achieved state-of-the-art or second-best performance across nAP, nAP50, and nAP75 for K=10. While DeFRCN slightly outperformed it in nAP for K=10, the paper notes that DeFRCN does not maintain base class detection capabilities, which is a different objective.
 - The method also showed further performance gains when employing more powerful Transformer-based backbones (Swin-T, Swin-S).

- **PASCAL VOC Results:**
 - On the three standard novel splits, the LVC method was consistently among the top two best-performing models across nearly all K-shot settings, frequently establishing new state-of-the-art performance.
 - For Novel Split 3, the LVC method with a ResNet-101 backbone achieved state-of-the-art for all K-shots, with a notable boost of up to 4.7 nAP50.

#### 4.3. Qualitative Results

Qualitative examples illustrate the effectiveness of Label Verification in filtering false positives and Box Correction in significantly improving the accuracy of bounding boxes for both poorly and acceptably localized verified candidates. Precision-Recall curves on MS-COCO further visually confirm the substantial improvements in both precision and recall for novel classes achieved by the LVC method.

### 5. Significance and Potential Impact

This research presents a pseudo-labelling method that contributes to the field of Few-Shot Object Detection (FSOD) by addressing challenges associated with limited novel class annotations.

One significant aspect of this work is its detailed examination and amelioration of "supervision collapse," an issue where object detectors trained on abundant base class data become biased against novel classes. By demonstrating that updating more parameters (RPN, RoI feature module, and classification layer) during novel training and employing specific augmentations can create a stronger baseline, the work provides insights into adapting standard detectors for FSOD.

The core contribution lies in the "Label, Verify, Correct" (LVC) pseudo-labelling pipeline. This method systematically enhances the quality of pseudo-annotations by:
1. **Sourcing candidates** from unlabelled data.
2. **Verifying class labels** using a kNN classifier built upon robust self-supervised features. This step is crucial for increasing the precision of labels and reducing misclassifications.
3. **Correcting bounding box coordinates** with a specialized cascaded regressor, leading to high-quality localization.

By generating a substantial number of high-precision pseudo-annotations, the method effectively mitigates the problem of extreme class imbalance in FSOD. This expanded, high-quality dataset then enables end-to-end retraining of the detector, which is shown to alleviate "supervision collapse" and improve generalization across both base and novel categories, maintaining performance on established classes while expanding to new ones.

The empirical results, demonstrating state-of-the-art or competitive performance across challenging benchmarks like MS-COCO and PASCAL VOC, suggest the practical utility of this approach. The work shows that a simple, yet carefully constructed, pseudo-labelling strategy can outperform or stand alongside more complex meta-learning or transfer-learning methods. This indicates that leveraging unlabelled data effectively through precision-focused pseudo-labelling is a viable and powerful direction for FSOD.

The potential impact of this work includes:
- **Reduced Annotation Cost:** Facilitating the deployment of object detection systems in domains where extensive manual annotation for new categories is infeasible or costly.
- **Enhanced Adaptability:** Enabling existing object detectors to continuously expand their vocabulary and adapt to new object types with minimal new data.
- **Foundation for Future Research:** Providing a strong pseudo-labelling baseline that can be extended, for example, by incorporating iterative pseudo-labelling or integrating with noisy label learning techniques, as the authors suggest in their limitations.
- **Insights into Self-Supervision:** Highlighting the utility of features from self-supervised models (like DINO) for tasks where labeled data is scarce, reinforcing the value of such pre-training.

The authors also acknowledge limitations, such as benchmarking on datasets with a relatively smaller number of classes (MS-COCO, PASCAL VOC) compared to larger vocabulary datasets (e.g., LVIS), and the potential for further refinement through iterative pseudo-labelling. Ethical considerations regarding the potential misuse of such adaptable detection technologies are also briefly mentioned, which is a responsible practice in scientific reporting.
