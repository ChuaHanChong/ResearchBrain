# Code World Model: Coding Agent as World Brain

> [!summary] Summary
> Code World Model splits world simulation into executable evolution and visual realization. A coding agent writes and revises code that maintains persistent world state and rules; a deterministic compiler turns that state into a coarse proxy video encoding positions, poses, trajectories and camera motion, which conditions a fine-tuned video model alongside structured text. The adapted MiniMax-H3 backbone follows these frame-wise spatiotemporal specifications while preserving high-fidelity appearance and dynamics.

## Problem

- Video world models learn dynamics only from pixels, which reveal outcomes rather than the knowledge, rules and mechanisms that actually govern world evolution.
- State changes occurring off-screen or beyond a sub-minute training context leave no visual trace, so consequences fail to persist coherently over long horizons.
- Text or low-dimensional action and camera conditions cannot specify precise frame-wise entity motion; explicit 3D worlds add control but cost assets and cap visual fidelity.

## Method

- An ==agent-code loop== splits duties: the coding agent handles sparse complex reasoning and rewrites the world program, while generated code executes dense deterministic state updates without per-step model calls.
- **Proxy**, a coarse programmable representation of entity position, pose, trajectory, layout and camera, compiled by a lightweight ==deterministic rasterizer== into a proxy video conditioning the video model with structured text.
- Aligned data pipelines: gameplay runtime state recorded synchronously with target video for instance-level proxies, plus geometry-assisted offline proxy compilation from ==KITTI-360== reconstructions, needing no action or camera labels.

## Results

- Rank-**128** LoRA over all **50** transformer blocks, **596M** trainable parameters, three epochs and **3,534** steps on eight H800 GPUs, using **9,420** clips from **5.6** hours of gameplay.
- From only that five-hour GTA V corpus, generated **124**-frame **1344x768** videos follow proxy-specified character positions, action trajectories, scene layouts and camera motion across unseen characters, styles and environments.
- Proxy conditions run at one quarter resolution per dimension, one sixteenth the visual tokens, adding negligible inference overhead; project-page comparisons show finer control than action- or camera-conditioned world models.

## Takeaways

> [!tip] Key Insights
> - Separate what happens from how it looks: code supplies persistent rule-consistent state, generative priors supply appearance, so neither component must learn both jobs.
> - Condition bandwidth is the core design trade-off; richer proxies ground better but demand controls, such as joint-level motion, that current coding agents cannot author reliably.
> - Conditioning in the output modality removes the need for action and camera labels, unlocking real video, but the evidence here is qualitative with no quantitative benchmark.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development of world models is a recognized area of research in artificial intelligence, aiming to simulate how complex environments evolve under various actions and events. These models are considered fundamental for applications requiring an understanding, prediction, and interaction within dynamic environments, such as autonomous driving, embodied intelligence, and open-ended game generation. A significant challenge in this field involves modeling complex interactive worlds with numerous entities, attributes, relationships, and behaviors that evolve over extended periods, where actions can have propagating and persistent consequences.

Existing approaches to interactive world modeling largely fall into several categories:

- **Video World Models:** These models learn world dynamics directly from visual experience, often formulating the task as action- or prompt-conditioned video generation. Recent advancements have led to improvements in visual quality, action controllability, long-horizon temporal consistency, and memory capabilities, allowing for streaming and real-time interaction. These models acquire rich priors over environments, agents, and motion from large-scale visual data. However, a primary limitation is their reliance on visual observations, which reveal only the outcomes of world dynamics rather than the underlying knowledge, rules, and mechanisms that govern them. This indirect learning makes it challenging to infer hidden causal mechanisms, maintain persistent consequences, or handle state changes that occur off-screen or beyond the temporal context available to the model. Consequently, these models often lack the commonsense reasoning and long-horizon planning capabilities required for open-ended world evolution.

- **Generative 3D World Models:** This direction focuses on creating explicit 3D scene representations that support navigation, spatial editing, and free-viewpoint rendering. While these systems offer strong spatial control and are valuable for applications requiring explicit geometry, their construction involves significant costs associated with creating production-quality geometry, assets, animation, materials, and rendering systems. This approach can also prematurely constrain the final visual realization and struggles to scale efficiently to open-ended worlds that continually introduce novel elements.

- **Coding Agents and World Models:** A separate line of research explores the use of programs and coding agents to represent environment dynamics. Large Language Models (LLMs) have been used to build world models by writing and refining Python programs, or by inducing probabilistic programs for model estimation. Agentic LLMs have also shown increasing capability in autonomously generating and maintaining complex codebases. However, previous work in this area has primarily focused on generating game artifacts or simulating code execution, rather than integrating persistent, revisable code as the operational foundation for a *learned visual world model*.

The current work, "Code World Model," identifies a gap in these existing approaches: the challenge of combining the strengths of knowledge-driven, rule-consistent world evolution with the ability of generative models to produce high-fidelity visual realizations. Video models excel at visual synthesis but struggle with deep causal reasoning and state persistence, while explicit 3D models are rigid and costly. Coding agents offer rule-based control but have not been effectively coupled with flexible visual generation for open-ended environments. This paper proposes a framework to bridge this gap by functionally decomposing the problem into world reasoning/execution and visual generation, aiming to leverage the complementary strengths of language models (for reasoning and code generation) and video models (for visual synthesis).

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a robust framework, termed "Code World Model," that can create open-ended virtual worlds capable of exhibiting real-world causal complexity and maintaining high visual fidelity. This overarching goal is motivated by several identified limitations in current world modeling approaches and the potential benefits of integrating distinct AI capabilities.

The motivation for this approach stems from the following observations:

- **Deficiencies of Purely Visual World Models:** Existing video-based world models primarily infer world dynamics from visual observations. While capable of impressive visual generation, they encounter difficulties in understanding the underlying knowledge, rules, and mechanisms that govern environmental evolution. This limitation prevents them from maintaining persistent consequences of events—such as the long-term geopolitical repercussions of an assassination in a game, even when the relevant location is off-screen. They also struggle to support coherent, open-ended evolution where interactions are not confined to predefined trajectories, largely due to their inability to directly access or reason about the hidden causal logic. Learning these mechanisms indirectly from sparse visual effects is inefficient and suboptimal for generating complex, interactive worlds.

- **Necessity for Persistent State and Rule-Consistent Evolution:** Complex interactive environments require a mechanism to continually maintain a complete world state, infer the consequences of events based on world knowledge and rules, and ensure these changes persist over long time horizons. Such a mechanism needs broad knowledge, an understanding of complex entity relationships, and the ability to perform continuous reasoning, planning, and decision-making. Language models, with their extensive knowledge acquired from text and code, are identified as suitable candidates for this role, capable of abstract understanding and long-horizon reasoning.

- **Efficiency of Code for Low-Level Operations:** While language models are effective for high-level reasoning, invoking them for every fine-grained, repetitive state change (e.g., updating positions, collision detection, numerical attributes) would be computationally inefficient. Code provides a natural and efficient execution substrate for these high-frequency, rule-consistent, and reproducible operations. The emergent capabilities of coding agents to generate, modify, and maintain complex codebases further support the dynamic adaptability of such rule systems.

- **Requirement for High-Fidelity Visual Realization:** After the world state has evolved according to rules and reasoning, a robust visual component is needed to render this state into high-fidelity, open-ended visual observations. Video models, trained on large-scale visual data, possess rich priors for appearance, motion, and interaction, allowing them to synthesize visually expressive outcomes without requiring manual crafting of every visual detail, unlike explicit 3D rendering pipelines. This provides a higher ceiling for visual realism and adaptability to open-ended content.

Based on these motivations, the key objectives of the Code World Model are:

1. **To establish a functional decomposition:** Separate the complex reasoning and rule-based execution of world state from its visual manifestation.
2. **To empower a coding agent:** Design a framework where a coding agent serves as the "world brain," continuously maintaining and operating the world by generating, invoking, and revising executable code. This allows the agent to reason about event consequences and ensure persistence of changes.
3. **To design a novel interface ("proxy"):** Develop a lightweight, programmable interface that translates the executable world state into a conditioning representation ("proxy video") that a video model can reliably interpret for precise spatiotemporal control, without requiring a full 3D rendering pipeline.
4. **To develop data pipelines:** Construct aligned proxy–observation pairs from both gameplay and real-world videos to train the video model to accurately translate proxy conditions into high-fidelity visual observations.
5. **To demonstrate feasibility:** Provide preliminary evidence for the viability of the framework's core components and the potential for combining code-driven world evolution with flexible visual generation.

### 3. Methodology and Approach

The Code World Model framework is designed to integrate the reasoning and coding capabilities of language models with the generative priors of video models, aiming to achieve coherent, open-ended world evolution and high-fidelity visual realization. This is achieved through a functional decomposition of the world state and a novel conditioning mechanism.

#### 3.1. Code World Model Architecture

The core idea is to decompose the complete world state $S_t$ into an executable state $S_{exe_t}$ and a visual state $S_{vis_t}$.
- The **executable state** ($S_{exe_t}$) encompasses the evolving world program, entity attributes, rules, relations, and event history. This state is directly operated upon by the coding agent and code.
- The **visual state** ($S_{vis_t}$) contains appearance, motion, and other visual information generated by the video model, designed to maintain temporal consistency.

The evolution of these states is governed by coupled processes:
- The **agent-code transition** ($T_{AC}$) updates the executable state: $S_{exe_{t+1}} = T_{AC}(S_{exe_t}, A_t)$, where $A_t$ represents actions or events. This transition involves a continuous loop where the coding agent interprets events, reasons about long-term consequences, and translates these decisions into executable, reusable, and modifiable code. This code then performs high-frequency, deterministic updates on variables like positions, attributes, and collision resolutions. This decoupling allows the coding agent to focus on complex, infrequent reasoning tasks while the code handles dense, repetitive operations efficiently.
- A **video model** ($G_{\theta}$) generates the next visual state: $S_{vis_{t+1}} \sim G_{\theta}(S_{vis_t}, \text{condition from } S_{exe_{t+1}})$. The visual observation $O_{t+1}$ is then derived from $S_{vis_{t+1}}$. The key here is how the relevant information from $S_{exe_{t+1}}$ is selected and represented as a condition for the video model.

#### 3.2. World-State Conditioning for the Video Model (The Proxy)

A central technical challenge is to bridge the gap between the executable world state and the visual generation process. Direct use of raw code or full executable state is impractical, and purely text-based conditioning, while flexible, often lacks the precision needed for fine-grained spatiotemporal control (e.g., exact entity positions, camera trajectories). Relying on complete 3D explicit construction is costly and visually restrictive.

To address this, the paper introduces a novel intermediate representation called **proxy**:
- **Definition:** The proxy is a coarse, programmable world representation that encodes interaction-relevant state such as camera motion, entity positions, poses, trajectories, and spatial relations.
- **Generation:** It is deterministically generated from the world state by the coding agent. A lightweight deterministic compiler then renders this proxy into a **proxy video**, which serves as a spatiotemporal visual condition for the video model.
- **Functionality:** The proxy video provides direct, frame-wise spatiotemporal constraints to the video model (e.g., coarse spatial relations, overall trajectories) while leaving details like appearance, textures, and fine-grained dynamics unspecified. These unspecified elements are then synthesized by the video model using its learned priors.
- **Constructability:** The proxy is designed to be programmatically constructed by the coding agent using simple, reusable primitives (e.g., capsule skeletons for characters, wireframes for vehicles, low-poly proxies for vegetation, bounding boxes for complex or uncommon objects). This approach minimizes the representational burden on the agent and ensures the path from state to condition is transparent and controllable.
- **Joint Conditioning:** The proxy is used jointly with structured text prompts. The text communicates semantic intent (e.g., character identity, appearance, action semantics, overall visual style), while the proxy video provides precise spatiotemporal grounding.
- **Efficiency:** The proxy video is generated at a lower resolution (1/4th of the target video's spatial dimensions), leading to 1/16th fewer visual tokens and negligible additional inference overhead for the video model.

#### 3.3. Data Pipelines for Training the Video Model

To train the video model to interpret and follow proxy conditions, spatiotemporally aligned proxy and target video pairs are required.

- **Game Data:**
 - Gameplay recordings are utilized, as they allow synchronous capture of both the target RGB video and the underlying runtime state (camera, entity positions/orientations, scale, scene layout, interaction state).
 - From this runtime state, the proxy is programmatically constructed and rendered along the target video's camera trajectory. Importantly, only state information reproducible by a coding agent (e.g., coarse geometry, not detailed 3D models or skeletal poses) is retained in the proxy.
 - Pixel-wise ground-truth instance maps are extracted to establish precise identity correspondence between visual regions in the proxy and character/object descriptions in structured text.
 - The authors specifically fine-tuned MiniMax-H3 Ref2VA backbone on approximately 5.6 hours of GTA V gameplay data, sampled into 9,420 five-second clips. Each target RGB video was 1344x768 at 24 FPS, paired with a 336x192 proxy sequence containing fixed-log depth and categorical semantic-ID maps.

- **Real-world Data (Proof of Concept):**
 - The framework is designed to incorporate real-world videos to enhance visual realism and acquire broader physical priors. The proxy's design (representing action consequences and camera motion visually) alleviates the need for explicit action labels or camera pose annotations, simplifying real-data integration.
 - A proof-of-concept utilized the KITTI-360 dataset. Rectified RGB frames served as targets. Calibrated camera poses, semantic 3D reconstruction, and 3D object annotations were used *offline* to compile corresponding proxy conditions (e.g., capsule skeletons for pedestrians, wireframes for vehicles). These projected geometries and primitives were rasterized through a shared depth buffer to preserve spatial alignment and occlusion.

#### 3.4. Implementation Details

- **Video Model Training:** The official MiniMax-H3 Ref2VA backbone was fine-tuned using LoRA (rank-128) across 50 transformer blocks, resulting in approximately 596 million trainable parameters. AdamW optimizer, BF16 mixed precision, FlashAttention-3, and gradient checkpointing were employed.
- **Coding Agent Inference:** GPT-5.6 Sol was used as the coding agent. It was provided with basic game-engine code (player controls, collision, update loop) and the same proxy primitives used for training data construction. The agent leverages existing game scenes as templates, modifying and extending them to construct interactive worlds, then records the resulting proxy video.
- **Video Model Inference:** Explicit Euler sampling (20 steps) was used. GPT Image 2 generated a first-frame appearance anchor from the initial proxy frame and a text prompt, which initialized the target latent slot and conditioned the video model. For long-video inference, an overlapping window approach (124-frame windows with 34-frame overlap) was used to maintain temporal continuity, reusing the appearance anchor for global consistency.

### 4. Main Findings and Results

The experiments conducted to evaluate the Code World Model framework primarily focused on demonstrating the viability of its core components and the qualitative performance of the video model under proxy conditioning.

- **Qualitative Adherence to Proxy Specifications:** Following LoRA adaptation on a limited dataset of approximately 5.6 hours of GTA V gameplay, the fine-tuned MiniMax-H3 video model exhibited the ability to closely follow the spatiotemporal specifications provided by the proxy. This included:
 - **Entity Positions and Motion:** The generated videos showed characters adhering to specified locations, movements, and action trajectories within the environment.
 - **Scene Layout:** The model rendered scenes consistent with the layout provided by the proxy.
 - **Camera Trajectories:** The viewpoint and camera movements in the generated videos accurately matched the camera trajectories encoded in the proxy.
 - **Visual Fidelity:** Despite adhering to these coarse spatiotemporal constraints, the video model simultaneously preserved high-fidelity appearance and fine-grained dynamics, synthesizing details such as textures, lighting, and realistic motion not explicitly defined by the proxy.

- **Generalization Capabilities:** The qualitative examples presented, which feature diverse characters, environments, motions, and camera trajectories (e.g., "Sailor Moon performs a lively wand dance," "James Bond swims," "A celestial manta-skiff glides"), suggested that the adapted video model retained strong generalization abilities beyond the specific training content, translating varied text prompts into corresponding visual styles while respecting proxy inputs.

- **Improved Spatiotemporal Control:** Comparative qualitative analyses indicated that the proxy-based conditioning mechanism provided more precise and responsive control over character actions, motion, and camera movements than control interfaces relying solely on coarse intent via text or low-dimensional action/camera signals, as found in some existing video world models (e.g., LingBot-World 2.0, WorldPlay, Matrix-Game 3.0). The direct frame-wise specification of poses and trajectories via the proxy enabled a granularity of control comparable to that of a modern 3D game.

- **Viability of Framework Components:**
 - **Coding Agent:** The research provided preliminary evidence that the GPT-5.6 Sol coding agent, when provided with existing game-engine code and proxy primitives, could construct simple interactive worlds. It demonstrated the ability to modify the state and operating mechanisms of these worlds by writing and revising code.
 - **Video Model Integration:** The fine-tuned video model successfully rendered the world states expressed by the proxy into corresponding visual observations, validating the proposed interface between the executable world and visual generation.

- **Data Pipeline Effectiveness:** The development of data pipelines capable of constructing spatiotemporally aligned proxy–observation pairs from both gameplay videos and real-world recordings (demonstrated with KITTI-360) indicated the feasibility of generating suitable training data for the visual backend. The ability to construct proxies from 3D reconstructions and object annotations in real-world data without requiring action labels was highlighted as a method for lowering annotation burden.

The results, while qualitative and based on limited computational resources, suggest that the conceptual separation of world evolution and visual realization, mediated by a programmable proxy, offers a viable path toward creating open-ended and coherent interactive world models.

### 5. Significance and Potential Impact

The Code World Model represents a conceptual shift in the design of interactive world models, proposing a novel architecture that integrates distinct AI capabilities to overcome limitations observed in existing approaches. Its significance and potential impact can be summarized as follows:

- **Advancement Towards Open-Ended World Models:** By separating the logical evolution of a world from its visual rendering, the framework addresses a core challenge for open-ended world models: maintaining persistent consequences and coherent narratives over long time horizons. The coding agent, acting as the "world brain," can reason about and enforce underlying rules, allowing for continuous and complex world evolution that extends beyond predefined trajectories or visible contexts. This is a step towards creating more dynamic and believable virtual environments.

- **Enhanced Coherence and Persistence:** The reliance on executable code for maintaining world state ensures rule consistency and persistence of changes, even for events that occur off-screen or have delayed consequences. This capability is critical for creating immersive and interactive experiences where player or agent actions have meaningful and lasting impacts, a feature often difficult to achieve with purely visual world models.

- **Improved Controllability and Fidelity in Visual Generation:** The introduction of the proxy-based interface offers a new level of fine-grained spatiotemporal control over visual generation. This allows for precise specification of entity movements, spatial relationships, and camera trajectories, which is often challenging with text- or low-dimensional action-based conditioning. Simultaneously, by leveraging the generative priors of video models, the framework can synthesize high-fidelity visual appearance and dynamics, potentially reaching levels of realism that are difficult or costly to achieve with traditional 3D asset pipelines.

- **Scalability for Complex Interactions:** The agent-code organizational structure is designed to handle both infrequent, complex reasoning tasks (by the coding agent) and high-frequency, repetitive state updates (by the code). This decoupling can improve the scalability of world models to environments containing numerous entities and intricate interaction logic, allowing for more complex and dynamic simulated worlds.

- **Broader Applications in AI Research:**
 - **Game Generation:** The framework has direct implications for automatically generating open-ended game worlds that are both visually rich and logically consistent.
 - **Embodied AI and Agent Training:** By enabling the creation of high-fidelity, causally complex visual environments that can incorporate real-world visual and physical priors (through real-world data pipelines), Code World Model can provide more realistic and diverse training grounds for embodied agents and vision-language models, facilitating their development and evaluation in environments closer to deployment distributions.
 - **Reducing Annotation Burden:** The proxy's ability to encapsulate action and camera information visually can simplify the process of constructing training data from real-world videos, as it reduces the need for explicit, labor-intensive action labels or camera pose annotations.

- **Future Directions for Coding Agents:** This work positions coding agents not just as tools for static software development, but as dynamic operators of evolving virtual worlds. It highlights a path for advancing coding agents to design, implement, test, and maintain increasingly complex and adaptive world mechanisms.

In conclusion, Code World Model proposes a synergistic integration of symbolic reasoning and generative visual models, offering a promising direction for building more intelligent, coherent, and visually rich interactive artificial worlds. It lays groundwork for future advancements in open-ended simulation, AI agent development, and human-computer interaction within complex digital environments.
