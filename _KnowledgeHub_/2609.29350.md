# Learning a Flow to Self-Supervised Representations

> [!summary] Summary
> FBDM (Flow-Based Distribution Matching) is a non-adversarial self-supervised objective that transports normalized encoder outputs along spherical geodesics toward a fixed, ETF-inspired reference mixture by regressing analytic conditional velocities. A capacity-constrained two-view consensus picks one shared destination per image, and an explicit start-point loss aligns the views. It matches adversarial distribution matching from CIFAR to ImageNet at 1.48-1.83x higher training throughput, with a population bound on downstream error.

## Problem

- Most self-supervised objectives only specify what representations must not become, leaving the desired global distribution of the representation implicit instead of explicitly prescribed.
- Adversarial distribution matching estimates the Wasserstein-1 distance with a critic, requiring opposing updates, several critic steps per encoder step, and careful hyperparameter tuning.
- The prior coordinate reference assigns at most one template per orthogonal axis, forcing template count below the flow dimension, so finer granularity demands a larger matching dimension.

## Method

- ==Simplex-spectral reference==: leading-eigenvector projection of the ideal simplex Gram matrix into the flow space, row-normalized into ==ETF==-inspired unit centers, then spherically perturbed for local spread.
- ==Two-view capacitated assignment==: a stop-gradient consensus of both views solves an injective max-inner-product assignment under epoch-indexed per-center capacity, yielding one shared endpoint per image.
- ==Spherical conditional flow matching==: great-circle paths with a decreasing-rate time reparameterization and inverse-transform progress sampling, regressing the analytic velocity, plus a weighted start-point alignment loss.

## Results

- Frozen ResNet-18 linear/5-NN reaches **92.37/89.68** on CIFAR-10, **66.59/56.74** on CIFAR-100, **89.79/86.23** on STL-10, **48.55/33.01** on Tiny ImageNet, comparable to adversarial matching.
- Matched single-V100 training gives **1.83x**, **1.69x** and **1.48x** per-epoch speedups, saving **9.52-15.55** V100-hours per 1000 epochs for about 0.50 GiB extra allocated memory; ImageNet-1K scores **59.32** versus SimCLR's **60.14**.
- Ablations favor spherical over linear interpolation on every dataset (**92.37** versus **90.50** linear on CIFAR-10), and removing the alignment term drops accuracy to **80.85/75.02**.

## Takeaways

> [!tip] Key Insights
> - Analytic velocity regression can replace an adversarial critic for explicit distribution matching, removing opposing min-max updates while keeping a prescribed reference geometry.
> - Shared flow destinations supply only implicit view alignment; an explicit start-point penalty stays necessary, worth roughly twelve linear-accuracy points on CIFAR-10.
> - Low-rank spectral projection of a simplex Gram matrix decouples template count from latent dimension, so reference granularity need not inflate the matching space.

## Detailed Report

### 1. Overview

Self-supervised learning has to make two augmented views of an image agree without letting every image collapse to the same representation. Existing Distribution Matching (DM) gives the encoder an explicit target geometry. However, it estimates the match with an adversarial critic that must be trained against the changing encoder. FBDM keeps an explicit destination. Instead of training a critic to detect the mismatch, it teaches an auxiliary network to predict how representations should move toward that destination. On CIFAR-10, FBDM reports similar linear-probe accuracy to DM and takes less time per epoch in a single-GPU comparison.

FBDM in one view. Two augmentation branches pass through the same encoder/projector. A stop-gradient consensus is assigned, under a capacity constraint, to a fixed simplex-spectral reference mixture. The selected component is locally perturbed to form a shared target, and a learned field predicts the target velocity along a spherical transport path. Only the backbone is retained.

### 2. A destination, not a critic

Two independently augmented views of an image pass through the backbone and projector. Their outputs are normalized to lie on a unit sphere. The detached, normalized consensus of the two views then selects a shared reference component through a capacity-constrained assignment. This capacity limits how many images can be assigned to a center, but it does not force equal occupancy. A small random spherical perturbation gives the chosen center a local target.

For each view, FBDM defines a shortest great-circle path from its starting representation to that target. A learned velocity field predicts the analytic target velocity at sampled positions along the path. The flow-matching loss trains this field and the representation. A separate start-point alignment loss pulls the two view representations together. The shared destination provides only implicit alignment, so the explicit penalty is still needed. At inference, the flow and projector are discarded, and the paper evaluates the backbone features. Training uses neither critic maximization nor a numerical ODE solve.

The reference itself also changes. Each template is a label-free reference destination, not a ground-truth class. In prior DM, orthogonal coordinate directions limit the number of templates to the flow-space dimension. FBDM starts from the ideal regular-simplex Gram geometry and keeps leading spectral directions to project it into a smaller target space. It then normalizes the resulting rows into spherical centers. This allows more components than flow-space dimensions. For lower-dimensional projections, the resulting arrangement is an ETF-inspired approximation, not an exact ETF.

### 3. What the comparisons establish

Top-1 accuracy is the percentage of test examples for which the classifier's highest-scoring class is correct. The linear probe is trained on frozen features. For CIFAR-10 with a ResNet-18 backbone, the reported frozen-feature linear-probe top-1 accuracy is 92.37% for FBDM and 92.11% for DM. Across CIFAR-10, CIFAR-100, STL-10, and Tiny ImageNet, FBDM is competitive with DM and other SSL methods, with no across-the-board win.

ImageNet-1K is an exception. After 100 epochs of ResNet-50 pretraining at global batch size 512, FBDM's linear-evaluation top-1 accuracy is 59.32%. The reported SimCLR reproduction reaches 60.14%. That SimCLR result is reproduced from [Andrew Atanov's SimCLR-PyTorch README](https://github.com/AndrewAtanov/simclr-pytorch).

The practical bottleneck is elapsed training time spent on critic updates. On one Tesla V100, the measured CIFAR-10 epoch time is 41.35 seconds for FBDM versus 75.61 seconds for DM, a reported 1.83× speedup. FBDM uses 5.28/5.82 GiB peak allocated/reserved memory, compared with DM's 4.78/5.14 GiB. The reported per-epoch speedups on CIFAR-10, CIFAR-100, and STL-10 are 1.83×, 1.69×, and 1.48×.

The comparison holds backbone, batch size, views, workers, precision, and GPU constant. Native DM uses five critic updates per encoder update. This is a matched native-stack comparison, not an architecture-independent complexity result or a universal elapsed-time guarantee.

### 4. The destination still matters

FBDM's flow is a temporary training signal. Its shared reference geometry and explicit view alignment shape the representation that remains. The result is a concrete alternative to critic-based matching. It does not win every comparison, and its speed claim concerns measured per-epoch time against native critic-based DM on one GPU, with somewhat higher memory.
