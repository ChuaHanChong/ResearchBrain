# MM-ReCoder: Advancing Chart-to-Code Generation with Reinforcement Learning and Self-Correction

> [!summary] Summary
> MM-ReCoder, developed by researchers from Amazon AGI and Brown University, enables a multimodal large language model to iteratively refine chart-to-code generation through reinforcement learning and self-correction. This system establishes new state-of-the-art performance, achieving 86.5% low-level and 84.9% high-level scores on ChartMimic with iterative refinement.

## Problem

- Supervised fine-tuning (SFT) based chart-to-code models frequently generate non-executable code or fail to precisely replicate visual details.
- Existing reinforcement learning (RL) approaches for chart-to-code typically treat generation as a one-shot task, lacking capabilities for iterative refinement.
- Many open-source multimodal large language models (MLLMs) struggle with effective self-correction, often only fixing unexecutable code rather than enhancing the visual quality of already functional outputs.

## Method

- A two-phase training curriculum initiates with supervised fine-tuning (SFT) on the ==Chart2Code-160k== dataset, followed by multi-turn SFT on 7,000 self-correction conversations to recover conversational ability.
- A two-stage multi-turn self-correction reinforcement learning (RL) strategy, based on Group Relative Policy Optimization (GRPO), iteratively refines code outputs.
- A composite reward function integrates rule-based metrics for visual element similarity, a model-based reward from a larger MLLM for holistic visual quality, and a binary format adherence reward.

## Results

- MM-ReCoder achieves state-of-the-art performance on ChartMimic (**86.5%** low-level, **84.9%** high-level with 4 turns), Plot2Code (**63.2%** text-match), and ChartX benchmarks, surpassing comparable open-source and larger proprietary models.
- The model demonstrates consistent self-correction, improving already executable code by an average of **0.30%** low-level and **0.89%** high-level score on ChartMimic for examples where both first and second-turn solutions are executable.
- Performance continuously improves over the first few self-correction turns, with the low-level score increasing from **83.5%** (1 turn) to **86.5%** (4 turns) on ChartMimic.

## Takeaways

> [!tip] Key Insights
> - A two-stage RL approach, beginning with shared first-turn optimization and progressing to full-trajectory optimization, is crucial for developing and sustaining robust self-correction capabilities.
> - Both rule-based and model-based rewards are complementary and essential for comprehensive chart quality assessment, with model-based rewards effectively capturing high-level visual aspects.
> - The initial cold start phase, particularly multi-turn SFT, is vital for re-establishing the model's multi-turn conversational capacity, allowing it to leverage multi-turn RL effectively.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work presented in this paper is situated within the rapidly developing field of Multimodal Large Language Models (MLLMs), specifically focusing on their application to multimodal coding tasks. A prominent example of such a task is chart-to-code generation (Chart2Code), where an MLLM takes a chart image as input and generates executable code (e.g., Python Matplotlib code) to reproduce it.

Prior research in Chart2Code primarily relies on supervised fine-tuning (SFT) methods, training MLLMs on large datasets of chart-image-to-code pairs. While these SFT-based approaches have demonstrated initial capabilities, they frequently encounter limitations. These limitations include an inability to consistently produce executable code and faithfully reproduce visual details, as next-token prediction alone does not inherently guarantee code correctness or visual fidelity.

To address these shortcomings, recent efforts have begun exploring reinforcement learning (RL) in Chart2Code tasks. Models like ChartMaster introduced reward functions that consider both low-level chart elements (e.g., chart type, color, legends) and high-level visual similarity to guide model improvement. However, existing RL-based Chart2Code methods generally treat the task as a one-shot generation problem, meaning the model produces a final code output without iterative refinement based on execution feedback. This contrasts with human iterative problem-solving, where code is written, executed, visualized, and refined.

The concept of self-correction, or iterative refinement based on feedback, has been explored in both Large Language Models (LLMs) and MLLMs. Studies indicate that while very large MLLMs might exhibit some self-correction abilities, many open-source MLLMs struggle to effectively refine their outputs even with explicit feedback. This often manifests as improvements primarily in code executability rather than in the quality of already executable code.

MM-ReCoder positions itself to advance the Chart2Code landscape by integrating effective self-correction capabilities into MLLMs using a novel reinforcement learning framework. It aims to bridge the gap between one-shot generation and human-like iterative refinement, thereby improving both the executability and visual quality of generated chart code. This work contributes to the broader understanding of how to train MLLMs for complex, multi-turn coding tasks that require interaction with an execution environment and iterative policy optimization.

### 2. Key Objectives and Motivation

The primary objectives of the MM-ReCoder research are to:

1. **Develop a Chart-to-Code generation model with effective self-correction capabilities**: The core goal is to enable an MLLM to iteratively refine its generated code based on feedback from code execution, moving beyond one-shot generation paradigms common in existing methods.
2. **Improve the accuracy and executability of generated chart code**: The model aims to produce Python Matplotlib code that not only runs without errors but also accurately reproduces the visual elements and overall appearance of the input chart.
3. **Overcome the limitations of supervised fine-tuning (SFT) and existing one-shot reinforcement learning (RL) approaches**: SFT alone does not guarantee executable or visually faithful code, and current RL methods typically do not leverage iterative refinement. MM-ReCoder seeks to address these gaps.
4. **Explore and validate novel RL training strategies for multi-turn self-correction**: The research aims to identify effective methods for teaching MLLMs to self-correct in an iterative dialogue, specifically proposing and testing a two-stage GRPO-based approach.
5. **Investigate the utility of combined rule-based and model-based rewards**: The objective includes understanding how different reward components contribute to improving both the low-level fidelity and high-level visual quality of generated charts during RL training.

The motivation behind these objectives stems from several observations and challenges:

- **Tedious Manual Chart Creation**: Manually generating scientific charts through GUIs or coding is a time-consuming process. Automating this with MLLMs has significant practical utility.
- **Limitations of Current MLLMs in Coding Tasks**: Despite progress, MLLMs often generate code that is syntactically incorrect, semantically inaccurate, or fails to capture subtle visual details of the target chart. This highlights a gap in reliable code generation.
- **Struggle with Self-Correction**: Existing MLLMs, including large proprietary models, demonstrate limited ability to genuinely self-correct. Analysis revealed that observed score improvements often come from fixing unexecutable code rather than refining already-functional outputs. This indicates a need for explicit training to foster true self-correction for visual quality.
- **Human-like Iterative Process**: Humans typically approach coding iteratively, writing, executing, observing results, and refining. Mimicking this iterative process in MLLMs is believed to be crucial for achieving high-quality code generation.
- **Need for Robust RL Framework**: To enable effective self-correction, a specialized RL framework is required that can optimize multi-turn interactions, reward iterative improvements, and handle the complexities of code execution feedback.

By addressing these motivations, MM-ReCoder aims to significantly advance the state-of-the-art in chart-to-code generation, making MLLMs more robust, accurate, and capable of human-like iterative problem-solving in multimodal coding contexts.

### 3. Methodology and Approach

MM-ReCoder employs a two-phase training curriculum consisting of a cold start phase and a multi-turn self-correction reinforcement learning (RL) phase. The base model utilized for MM-ReCoder is Qwen2.5-VL-7B.

#### 3.1. Cold Start Phase

The cold start phase aims to equip the model with foundational coding knowledge and multi-turn conversational ability:

1. **Single-Turn SFT on Chart2Code-160k**: The model is initially fine-tuned using supervised fine-tuning (SFT) on the Chart2Code-160k dataset, which comprises 160,000 chart-code pairs. This stage primarily enhances the model's capability to generate code for charts.
2. **Multi-Turn SFT with Self-Correction Data**: After single-turn SFT, the model's multi-turn conversational ability can diminish. To re-establish this, a dataset of 7,000 two-turn self-correction conversations is constructed. This data is generated by Qwen3-VL-235B-A22B-Instruct on images from Chart2Code-160k. Rejection sampling is applied to filter these generated conversations, retaining only those where the second-turn low-level score improves upon the first turn by at least 0.02, ensuring that the filtered data represents successful self-correction attempts. The model is then fine-tuned on this constructed multi-turn dataset.

#### 3.2. Multi-Turn Self-Correction Reinforcement Learning Phase

The core of MM-ReCoder's methodology lies in its two-stage multi-turn self-correction RL strategy, which is based on Group Relative Policy Optimization (GRPO).

##### 3.2.1. Reward Design

The reward function for RL training combines three components:

1. **Rule-based Reward**: This reward quantifies the similarity of visual elements between the generated chart and the reference chart. It uses metrics derived from ChartMimic, including F1-score for chart type and text, CIE Lab color distance for color, and comparison of rows/columns for layout. The average of these metrics, ranging from 0 to 1, forms the rule-based reward. This reward is effective for capturing specific visual element fidelity but may miss overall visual quality issues like overlapping elements.
2. **Model-based Reward**: To address the limitations of rule-based rewards, an open-source MLLM, Qwen2.5-VL-72B, is employed as a reward model. Given a reproduced image and the reference image, the reward model evaluates visual and semantic similarity across six aspects: chart type, layout, text, data, style, and clarity. Each aspect is scored, summing to a total of 100 points, which is then scaled to a range. This provides a more holistic assessment of chart quality.
3. **Format Reward**: A binary reward (1 or 0) is given based on whether the model's output adheres to a predefined format, which includes thinking trace enclosed in `<think>...</think>` tags and Python code in `` ```python...``` `` blocks.

The final combined reward is calculated as: `(1 - α - β) * Format + α * Rule-based + β * Model-based`, where α and β are hyperparameters for weighting. The optimal setting found for RL training (single-turn) was with `α=0.8` and `β=0.1`.

##### 3.2.2. Roll-out Strategies for Self-correction

The RL phase employs two distinct roll-out strategies, applied sequentially:

1. **Stage 1: Shared First Turn Optimization**: For each input chart, the model first generates a single "shared" first-turn output (`o^(1)`). Based on the execution feedback (`f^(1)`) from this first turn (either rendered image or error message), the model then rolls out multiple second-turn refinement candidates (`o^(2)i`). During this stage, RL optimization is applied only to the second-turn generation. The objective is `J^(shared)GRPO(θ) = E[1/G * Σ_i π_θ(o^(2)i | q, o^(1), f^(1)) / SG[π_θ(o^(2)i | q, o^(1), f^(1))] * Ai]`, where `Ai` is the advantage. This strategy primarily focuses on enhancing the model's ability to self-correct by exploring diverse refinement strategies for a given initial output.
2. **Stage 2: Full-Trajectory Optimization**: Following the shared-first-turn stage, this stage jointly optimizes both the first and second turns of a trajectory. For each input, `G` full trajectories are independently rolled out, sampling `o^(1)i` and then `o^(2)i`. The reward `R(o^(1)i, o^(2)i)` is computed over the entire trajectory and can optionally include a boosting reward `B` to encourage improvements in the second turn. The objective is `J^(full)GRPO(θ) = E[1/G * Σ_i π_θ(o^(1)i | q)π_θ(o^(2)i | q, o^(1)i, f^(1)i) / SG[π_θ(o^(1)i | q)π_θ(o^(2)i | q, o^(1)i, f^(1)i)] * Ai]`. For reward calculation, it was found that using only the final turn reward (i.e., `γ=0` and `η=0` for first-turn and boosting rewards) yielded the best performance in this stage. This stage aims to further improve overall coding performance by optimizing both turns simultaneously.

#### 3.3. Implementation Details

The training for cold start involves LLaMA-Factory with a batch size of 128. For RL, the VeRL framework is used with GRPO (group size G=8), batch size 128, and a learning rate of 10^-6. The Qwen2.5-VL-72B reward model operates on separate GPUs.

### 4. Main Findings and Results

The MM-ReCoder model demonstrates advancements in chart-to-code generation, particularly in its self-correction capabilities.

#### 4.1. State-of-the-Art Performance in Chart-to-Code Generation

- **Overall Benchmarks**: MM-ReCoder achieves state-of-the-art performance on three chart-to-code benchmarks: ChartMimic, Plot2Code, and ChartX.
 - On ChartMimic, MM-ReCoder achieves an 86.5% low-level score and 84.9% high-level score with 4 self-correction turns. Even with one turn, it achieves 83.5% low-level and 81.2% high-level scores.
 - On Plot2Code, it obtains a 63.2% text-match score.
- **Comparison with Baselines**:
 - **Open-Source Models**: MM-ReCoder significantly outperforms other open-source chart-domain models (e.g., ChartLlama, ChartCoder) and general-domain MLLMs of comparable size (e.g., Qwen2.5-VL-7B). For instance, compared to its base model Qwen2.5-VL-7B, MM-ReCoder (single-turn) shows a 29% improvement in execution rate, 48% in low-level score, and 63% in high-level score on ChartMimic.
 - **Larger Models**: MM-ReCoder (7B parameters) achieves performance comparable to or surpassing much larger open-source models like Qwen3-VL-235B-A22B on specific metrics (e.g., ChartMimic low-level score and Plot2Code text-match score). It also outperforms proprietary models like GeminiProVision and Claude-3-opus on ChartMimic metrics and matches or slightly exceeds GPT-4o on low-level scores.

#### 4.2. Demonstrated Self-Correction Ability

- **Quantitative Improvement**: Unlike many baselines that show minimal or negative improvement on already executable codes, MM-ReCoder consistently improves the quality of executable code. On ChartMimic, MM-ReCoder demonstrates a 0.30% average low-level score improvement and a 0.89% average high-level score improvement on charts where both first and second-turn solutions are executable. It improves 7.3% of charts while degrading only 4.5% in terms of low-level score.
- **Multi-Turn Iteration**: The model exhibits continuous improvement over the first few self-correction turns. With up to 4 reflection turns, the low-level score reaches 86.5% and high-level score reaches 84.9%. The rate of improvement and proportion of improved samples diminish by the fifth turn, indicating a plateau in self-correction for the given model.

#### 4.3. Analysis of Self-Correction Training Strategies

- **Effectiveness of Two-Stage RL**: The proposed two-stage RL strategy (shared-first-turn optimization followed by full-trajectory optimization) is identified as the most effective.
 - Shared-first-turn optimization initially elicits strong self-correction capabilities (14.4% improved cases, 0.72% average low-level improvement).
 - Full-trajectory optimization, when applied after the shared-first-turn stage, retains strong self-correction while achieving the highest overall low-level score (86%).
- **Limitations of Other Strategies**:
 - Full-trajectory optimization alone tends to lead to code repetition (46.9% of cases), with minimal improvement in executable codes.
 - Introducing a self-correction bonus (η) in full-trajectory optimization without balancing first-turn rewards can lead to models intentionally generating poor first-turn outputs to exploit the bonus.
 - Turn-wise training and other combinations did not effectively enable robust self-correction.
- **Impact of Cold Start**: Cold start, particularly the multi-turn SFT stage, is crucial for recovering the model's multi-turn ability and enabling it to benefit from the multi-turn self-correction RL. Models without cold start or with only single-turn cold start performed suboptimally in self-correction.

#### 4.4. Analysis of RL Rewards

- **Complementary Nature**: Both rule-based and model-based rewards are necessary for comprehensive chart quality.
 - Removing the model-based reward significantly reduces the high-level score (e.g., from 83.7% to 78.6%), leading to charts with clarity issues like overlapping text.
 - Removing the rule-based reward degrades the low-level score (e.g., from 83.9% to 78.2%), indicating issues with reproducing faithful visual elements.
- **Weight Sensitivity**: The exact weighting of reward components was found to have limited impact once a sufficient signal is provided, suggesting that even small weights can guide learning.
- **Reward Model Choice**: Using a larger, more capable MLLM (Qwen2.5-VL-72B) as the model-based reward judger yields better overall performance compared to using the base model itself (Qwen2.5-VL-7B) as the judger.

#### 4.5. Qualitative Results and Failure Analysis

- **Successful Self-Correction**: MM-ReCoder can effectively revise labels, axis ranges, chart styles, and data points, as well as handle runtime errors (Figure 4, A2-A8).
- **Comparison to Baselines**: Qualitatively, MM-ReCoder produces charts with more accurate colors, texts, styles, and data points compared to ChartCoder and Qwen3-VL-235B on various examples (Figure A9).
- **Failure Modes**: Common self-correction failure modes include diagnosis errors (incorrect discrepancy identification), coding errors (failure to fix identified issues in code), and regression errors (fixing one issue while breaking another). MM-ReCoder exhibits fewer diagnosis errors than Qwen3-VL-8B and fewer regression errors than Qwen3-VL-235B-A22B.

### 5. Significance and Potential Impact

The MM-ReCoder research introduces several significant contributions and holds potential for broad impact:

1. **Pioneering Effective Self-Correction in Chart2Code**: MM-ReCoder is presented as the first multimodal coding MLLM equipped with demonstrable and effective self-correction capabilities for chart-to-code generation. This moves beyond the limitations of one-shot generation and addresses a critical challenge in multimodal code synthesis. By enabling models to iteratively refine their output, it brings MLLM behavior closer to human problem-solving in coding tasks.

2. **Advancement in Multi-Turn Reinforcement Learning for MLLMs**: The proposed two-stage multi-turn self-correction RL strategy, based on GRPO, offers a novel and effective paradigm for training MLLMs in iterative tasks. The finding that shared-first-turn optimization is crucial for initially eliciting self-correction, followed by full-trajectory optimization for overall performance, provides a valuable architectural blueprint for future RL applications in similar multi-turn generation contexts. This contributes to the broader field of RL for MLLMs by demonstrating how to structure learning processes for complex, multi-step problem-solving.

3. **Improved Performance and Robustness in Chart-to-Code Generation**: By achieving state-of-the-art performance on multiple benchmarks, MM-ReCoder sets a new benchmark for chart-to-code accuracy and executability. Its ability to outperform both comparable open-source models and even much larger proprietary models on specific metrics highlights the efficacy of its training approach. This improved performance can lead to more reliable and accurate automation of chart creation, reducing manual effort and potential errors in scientific visualization.

4. **Enhanced Understanding of Reward Design**: The ablation studies on reward components demonstrate the complementary roles of rule-based and model-based rewards. This insight is important for designing effective feedback mechanisms in complex generation tasks, indicating that a combination of objective fidelity metrics and holistic quality assessments from other MLLMs can guide learning more comprehensively. The observation that even small reward weights can provide sufficient signal is also a practical finding for RL system design.

5. **Practical Implications for Scientific Data Visualization**: The ability to accurately and reliably convert chart images into executable code has direct applications in scientific research, data analysis, and technical communication. Researchers could use such a tool to reverse-engineer visualizations, adapt existing charts, or programmatically generate new ones from visual specifications, accelerating data interpretation and publication workflows.

6. **Foundation for Future Multimodal Coding Research**: MM-ReCoder's success in integrating self-correction into a multimodal coding task can serve as a foundation for developing MLLMs capable of tackling other complex vision-to-code problems (e.g., webpage-to-code, UI-to-code) that also benefit from iterative refinement and interaction with an execution environment. The analysis of self-correction failure modes also provides insights for future improvements in diagnosis and reasoning within MLLMs.
