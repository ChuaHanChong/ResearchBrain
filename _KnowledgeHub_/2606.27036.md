# RelAfford6D: Relational 6D Affordance Graphs for Constraint-Driven Robotic Manipulation

> [!summary] Summary
> RelAfford6D introduces a training-free framework for robotic manipulation that bridges the perception-action gap by utilizing a Relational 6D Affordance Graph. This graph explicitly encodes relative rigid-body geometry and kinematic constraints between object parts, enabling robust zero-shot task execution. The system achieved a 74% average success rate on articulated manipulation tasks, outperforming data-driven baselines, and demonstrated robust generalization in real-world environments.

## Problem

- Bridging the "perception-action gap" to translate abstract natural language into precise, low-level robotic control commands in open-world environments.
- Limitations of existing object representations, where 2D affordances lack depth, sparse 3D representations miss continuous relative geometry, and dense fields lack explicit kinematic constraints for articulated objects.
- Data-driven methods often require extensive task-specific training, limiting zero-shot generalization and robustness against environmental disturbances.

## Method

- Introduces the ==Relational 6D Affordance Graph (R6DAG)== as an intermediate representation to explicitly model dynamic SE(3) relationships and kinematic constraints between object parts.
- Leverages a three-module framework: Semantic Topology Generation (using a kinematic knowledge base and LLM), Metric Visual Grounding (with open-world segmentation and 6D pose estimation), and Constraint-Driven Kinematic Execution (formulating manipulation as an SE(3) kinematic constraint satisfaction problem).
- Employs a closed-loop execution strategy with dynamic replanning, continuously tracking object poses and recalculating constraint manifolds in real-time to ensure robustness against disturbances.

## Results

- Achieved an average success rate of **74%** on ten articulated object categories in simulation, outperforming four data-driven baselines that were trained on 10,000 successful trajectories.
- Demonstrated **100%** success on classical rigid object manipulation tasks (PickCube, StackCube, PushCube) across 250 trials, highlighting broad generalizability without re-training.
- Maintained strong performance under visual corruptions (e.g., Stack Cube **85%** with **30%** occlusion) and successfully deployed on a robotic arm in real-world environments, showcasing robust zero-shot generalization.

## Takeaways

> [!tip] Key Insights
> - Explicitly embedding rigid-body and articulation constraints into an SE(3) manifold representation offers a mathematically rigorous and robust foundation for manipulating articulated objects, surpassing methods relying on implicit or isolated affordances.
> - A hybrid approach that combines LLM semantic understanding with structured kinematic priors and precise VFM-based 6D pose estimation effectively translates abstract language instructions into physically valid robotic actions.
> - Dynamic, closed-loop tracking and real-time manifold recalculation are critical for maintaining physical consistency and task success in unpredictable real-world environments with potential disturbances.
