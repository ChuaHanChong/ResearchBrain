# Inference-time Scaling of Diffusion Models through Classical Search

> [!summary] Summary
> Researchers from Helixon US Inc., Stanford University, and Harvard University introduce a unified framework that scales diffusion model inference through classical search algorithms. This approach jointly leverages global and local search strategies, including an adaptive Depth-First Search (DFS) and annealed Langevin MCMC, to efficiently generate higher-quality outputs and achieve state-of-the-art performance across diverse tasks without retraining.

## Problem

- Diffusion model outputs often lack precise alignment with specific real-world objectives, physical laws, or task-specific constraints.
- Existing inference-time control methods are either computationally expensive, prone to generating out-of-distribution samples, or limited to exploring modes within the base model's distribution.
- Efficiently controlling and adapting generated samples to meet diverse test-time objectives in continuous, high-dimensional generative spaces remains a significant challenge.

## Method

- The work formulates diffusion model inference as a ==search problem==, aiming to sample from a compositional distribution that combines the original model's distribution with a verifier function.
- It introduces a dual search strategy: global search using classical tree-search algorithms (BFS and an adaptive DFS) for efficient mode identification, and local search via annealed Langevin MCMC for optimizing samples beyond the base model's capabilities.
- A double-verifier strategy is proposed to mitigate reward hacking, using distinct verifiers for local and global search to reduce overestimation and improve robustness.

## Results

- An improved BFS design, using 'Increase' tempering, 'Max' scoring, and 'SSP' resampling, consistently outperformed prior particle-based methods on image generation tasks.
- Adaptive DFS demonstrated superior efficiency, achieving comparable or better performance with up to **2x** less computational cost on text-to-image generation while dynamically allocating compute based on prompt difficulty.
- The Test-Time Search (TTS) method achieved state-of-the-art performance in offline reinforcement learning on D4RL tasks without model retraining, and showed that fine-tuning the base model on TTS-generated actions can outperform existing online RL methods.

## Takeaways

> [!tip] Key Insights
> - Classical search algorithms, specifically an adaptive DFS with backtracking, can effectively navigate continuous generative spaces, enabling dynamic compute allocation based on task difficulty.
> - Recurrent training-free guidance in diffusion models is theoretically unified with annealed Langevin MCMC, providing a principled understanding of its ability to pull samples back to the data manifold and prevent out-of-distribution samples.
> - Jointly scaling both global and local search strategies provides a more efficient and effective Pareto frontier for diffusion model performance, surpassing methods that scale these components in isolation.
