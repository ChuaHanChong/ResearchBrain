# Recursive Harness Distillation across Agents for Robot Manipulation

> [!summary] Summary
> Recursive Harness Distillation (RHD) has a strong LLM agent work with a frozen VLA, write down which interventions worked in a playbook, and then revise that playbook using a lighter agent's rollouts. No model weights change. The interventions cover three sites: the instruction, the attention, and the action. On SimplerEnv Bridge the light agent rises from 43.8% to 66.7%. Real-world Franka success rises from 37.3% to 64.0%.

## Problem

- VLA policies trained on diverse data still execute unreliably when scenes and execution states change, and they cannot diagnose their own failures or adapt mid-episode.
- LLM harnesses that orchestrate VLAs give agents ways to intervene, but they do not explain how effective intervention strategies can be accumulated and transferred across agents.
- Strong agents can learn to operate a VLA, but running them continuously during deployment is too expensive, and lighter agents lack that policy-specific experience.

## Method

- ==Three-site intervention interface==: ==instruction rewriting== (up to 512 characters), an ==attention-logit bias== of strength 0-4 on a chosen image region, and end-effector and gripper corrections over up to five control steps.
- ==Playbook distillation==: the strong agent turns its interaction experience into playbook.md entries that say when to intervene, how to adjust execution, and what to verify afterward.
- ==Recursive refinement== framed as ==policy optimization==: the teacher revises the playbook from the recipient's own rollouts, and a revision is accepted only if the recipient matches the teacher's success rate on the development tasks.

## Results

- On SimplerEnv Bridge with frozen GR00T, the light agent reaches **66.7%** with the refined playbook, against **43.8%** without one and **41.7%** for GR00T alone. The strong agent reaches **79.2%** with the same playbook.
- On real Franka tasks with pi0.5, overall success is **64.0%**, against **37.3%** for the policy alone and **0%** for the light agent with no playbook. That is **75** trials across **three** tasks.
- The initial unrefined playbook drops the light agent to **31.3%**. A playbook built by the light agent itself reaches only **22.9%**. Removing instruction editing causes the largest ablation drop, to **47.9%**.

## Takeaways

> [!tip] Key Insights
> - What an agent knows about how to operate a frozen policy can be stored as editable text and reused by other agents, with no weight updates.
> - Guidance must be refined on the rollouts of the agent that will use it. The teacher's unrefined first draft can perform worse than giving the agent no guidance.
> - Giving an agent intervention tools without the know-how to use them can hurt badly. With no playbook, the light agent scored 0% on real-robot tasks.

## Detailed Report

### 1. Overview

A robot is asked to put a spoon on a towel, but it carries nothing to the towel because the spoon remained on the table. A written guide prompts a return to the source and a regrasp. The examples show how an agent can return, reattempt, and continue execution through the existing policy. This is an illustrative recovery. It is not proof that every failed grasp can be fixed.

The paper's approach is to record what intervention worked and then refine the guidance from another agent's attempts. The authors claim that a robot agent can get better at steering a vision-language-action (VLA) policy without retraining it. A VLA is a model that uses visual and language inputs to produce robot actions.

Playbook-guided recovery. Top row, "put the spoon on the towel": failure ("Moves to towel empty"), an instruction to return to the source, "Return and regrasp," and "Carry to the towel," ending with a success label. Each row pairs failure, observation/playbook guidance, intervention, and subsequent execution; multiple interventions can contribute to a recovery.

### 2. A playbook for steering a frozen policy

The practical bottleneck goes beyond knowing a task. The agent also has to diagnose why the deployed policy misbehaves and what intervention will help. Relying on a costly capable agent throughout execution is a second motivation for transferring that know-how.

The method, RHD, works in a loop:

- **Build.** A strong agent interacts with the frozen VLA and records when an intervention helps and what to check afterward. It distills this experience into a playbook.
- **Use.** A lighter agent consults the guide during execution.
- **Revise.** The strong agent reviews the lighter agent's observations, interventions, and outcomes and revises the guide, repeating the cycle.

The guide is external text, not a set of updated model weights.

The playbook guides a choice among three intervention sites. The agent can edit the instruction, bias attention to selected visual features, or change the generated action. These are options, not a mandatory sequence.

From experience to guidance. An initial "retry closure, then lift" instruction is revised into geometry/contact/regrasp checks. The light agent then consults the expanded guide to choose an attention intervention, and recipient feedback returns for another revision. The empty-lift example illustrates the mechanism; it is not a benchmark result.

### 3. What the comparisons establish

The main test is on SimplerEnv Bridge, across four WidowX tasks and 48 held-out instances. Success means completing the original task within the episode horizon.

The frozen GR00T policy alone scores 41.7%. Luna, the lighter agent, scores 43.8% without a playbook and 66.7% with the refined playbook. The same playbook raises Astra, the capable agent, to 79.2%. These are task-success rates, not measures of speed or tokens.

Refinement is essential to that gain. The initial playbook actually lowers Luna's success to 31.3%, below its no-playbook score.

A skeptical reader might ask whether the gains come from a capable teacher rather than from recursive refinement alone. In a matched Bridge comparison, both recipients use frozen GR00T on the same 48 held-out instances, and teachers and recipients use separate contexts. Luna as both teacher and recipient yields 22.9%. Astra as teacher with Luna as recipient yields 66.7%. This supports the teacher–recipient hierarchy in this setup. It does not establish which difference between Astra and Luna is the sole cause, or that the result generalizes to every teacher–student pairing.

Bridge success rates. GR00T 41.7%, Luna without a playbook 43.8%, with the initial playbook 31.3%, and with the refined playbook 66.7%. With the refined playbook fixed, removing instruction editing gives 47.9%, attention editing 64.6%, and action editing 62.5%. Astra scores 54.2% without and 79.2% with the refined playbook.

### 4. Experience travels as guidance

The useful transfer here is intervention knowledge that can be checked and revised through the recipient's own execution, rather than a skill copied into new weights. The main boundary is scope. The evidence covers four Bridge tasks and three physical tasks under the reported setups, and the strong result is for the refined guide.
