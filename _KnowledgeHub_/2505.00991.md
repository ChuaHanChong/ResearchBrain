# DexCtrl: Towards Sim-to-Real Dexterity with Adaptive Controller Learning

> [!summary] Summary
> A novel adaptive controller learning framework enables successful sim-to-real transfer of dexterous manipulation policies by jointly predicting actions and controller parameters based on historical trajectories, demonstrating improved performance on in-hand object rotation and flipping tasks using a LEAP robotic hand while reducing the need for manual parameter tuning.

## Problem

- Transferring policies from simulation to real robots is challenging due to discrepancies in low-level controller dynamics
- Manual tuning of controller parameters is labor-intensive and task-specific while domain randomization can increase training difficulty

## Method

- DexCtrl framework that learns to predict both actions and controller parameters adaptively based on historical information
- Two-module architecture using self-attention for action prediction and cross-attention for controller parameter prediction
- Training an oracle policy in simulation and distilling into a student policy for real-world deployment

## Results

- Outperformed manual tuning baseline in simulation and achieved successful transfer to real robot without additional training
- Demonstrated robust performance across objects with varying physical parameters
- Showed significantly better performance than baseline without controller adaptation, especially in real-world experiments

## Takeaways

> [!tip] Key Insights
> - Mismatch in robot controller behavior is a critical but often overlooked factor in the sim-to-real gap
> - Adaptive controller parameter prediction is crucial for robust real-world performance
> - Controller parameters systematically adapt to object properties (e.g., increased stiffness for heavier objects)
