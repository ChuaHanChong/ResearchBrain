# FAMA: Failure-Aware Meta-Agentic Framework for Open-Source LLMs in Interactive Tool Use Environments

> [!summary] Summary
> The FAMA (Failure-Aware Meta-Agentic Framework) is a two-stage approach designed to enhance the performance of open-source Large Language Models in interactive tool-use environments by identifying specific failure modes and dynamically activating a minimal subset of helper agents for mitigation. The framework achieved performance gains of up to 27% across various benchmarks like τ-bench, τ-trait, and ACEBench, while reducing token overhead and latency compared to indiscriminate multi-agent systems.

## Problem

- Open-source Large Language Models (LLMs) frequently fail in multi-turn, interactive tool-use scenarios due to accumulating decision-making errors, often exacerbated by their smaller parameter sizes and limited context windows.
- Existing improvement methods like supervised fine-tuning or reinforcement learning are often costly, require extensive data, and do not specifically target observed failure patterns.
- Static multi-agent frameworks frequently lead to unnecessary context injection, increased token usage, higher latency, and potentially degraded performance for resource-constrained open-source models.

## Method

- **FAMA** employs a ==Failure Analysis== stage where a baseline agent's failed trajectories are categorized into predefined error types via dedicated error-analysis agents and an orchestrator.
- In the ==Dynamic Mitigation== stage, a mitigation agent — conditioned on identified failure categories — selects an efficient, minimal subset of specialized helper agents from a predefined pool.
- The baseline agent is re-executed with its context dynamically constructed using only the recommended helper agents, providing targeted interventions for specific weaknesses.

## Results

- **FAMA** improved performance by up to **27%** across τ-bench, τ-trait, and ACEBench versus ReAct, Function Calling, and IRMA baselines.
- Reduced token overhead by **~30%** and lower latency vs. indiscriminate multi-agent systems (IRMA's **50-58%** overhead), with fewer context overflow errors.
- Strong generalizability across Airline, Retail, Telehealth, and Telecom domains without manual redesign.

## Takeaways

> [!tip] Key Insights
> - Open-source LLMs consistently struggle with specific failure modes in tool-use tasks, such as Domain Policy Violation, Contextual Misinterpretation and Hallucination, and Incomplete Fulfillment.
> - Dynamically composing a minimal, task-relevant subset of specialized helper agents, based on identified failure modes, is more efficient and effective than static, indiscriminate multi-agent approaches for resource-constrained models.
> - The optimal memory size for an agent in interactive tool-use environments is domain-dependent rather than model-dependent, highlighting the need for adaptive context management strategies.
