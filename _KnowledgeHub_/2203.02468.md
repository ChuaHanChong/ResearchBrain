# Symbolic State Estimation with Predicates for Contact-Rich Manipulation Tasks

> [!summary] Summary
> A Bayesian framework employing binary predicate classifiers enables data-efficient and robust estimation of high-level symbolic states from multimodal sensor observations in contact-rich manipulation. This approach yielded a 0.92 offline accuracy and 0.72 online success rate in insertion tasks, demonstrating superior generalization to unseen tasks compared to direct classification and differentiable filtering.

## Problem

- High-level robotic manipulation relies on brittle hand-tuned heuristics for symbolic state detection, leading to failures due to sensor noise or unexpected disturbances.
- Data-driven methods for symbolic state estimation often require extensive datasets, yield noisy predictions with limited data, and struggle to generalize or scale to new tasks.
- Integrating high-dimensional sensory input into robust, discrete symbolic state estimation, especially for contact-rich tasks, remains a challenge for existing Bayesian and differentiable filtering approaches.

## Method

- A Bayesian framework estimates symbolic states by leveraging intermediate 'predicates'—atomic, binary properties—which are easier to classify and generalize.
- Binary predicate classifiers, trained on high-dimensional multi-modal sensor inputs (e.g., images, forces), act as 'virtual sensors' whose probabilistic outputs are incorporated into the Bayesian update using Gaussian Mixture Models.
- Sensor fusion is achieved by defining modality-specific predicates and assuming conditional independence, allowing complementary information from different sensors to be combined effectively.

## Results

- The proposed 'Pred' method achieved an offline state estimation accuracy of 0.92 and an F1 score of 0.67, outperforming direct symbolic state classification (0.81 accuracy, 0.60 F1) and a differentiable filter (0.85 accuracy, 0.53 F1).
- It demonstrated superior generalization to unseen tasks, maintaining 0.80 accuracy (compared to 0.38 for direct state classification), with motion and force-based predicates showing particular robustness.
- In online closed-loop policy execution, the framework achieved the highest average success rate of 0.72 across error-prone insertion tasks, consistently surpassing a hand-tuned manual baseline.

## Takeaways

> [!tip] Key Insights
> - Decomposing complex symbolic states into simpler, atomic binary predicates significantly enhances data efficiency and generalization capabilities for state estimation.
> - A Bayesian framework, when informed by robust predicate classifiers, effectively fuses multimodal, high-dimensional observations to estimate discrete symbolic states even with limited real-world data.
> - Sensor fusion is critical for reliable symbolic state estimation, as different modalities provide distinct and complementary information (e.g., force for contact nuances, vision for object presence and spatial relationships).

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of robotic manipulation is challenged by the need for robots to perform tasks robustly despite perception uncertainty. A fundamental aspect of addressing this challenge is state estimation, which involves inferring the true state of the environment from noisy sensor observations.

Traditional state estimation often focuses on continuous states, such as object poses. While these continuous states are crucial for guiding robot motion (e.g., aligning an end-effector), robotic tasks frequently require understanding higher-level, discrete "symbolic states" to inform decision-making. Examples include whether a door is locked, an object is aligned, or a sub-task has succeeded. These symbolic states are integral to high-level execution frameworks like state machines, behavior trees, task planners, and Robust Logical-Dynamical Systems.

Current approaches to symbolic state estimation exhibit limitations. Hand-tuned heuristics, commonly used for defining state transition conditions, can be brittle and susceptible to sensor noise or unexpected disturbances. Data-driven methods, while offering an alternative, can yield noisy predictions, especially when training data is limited—a common constraint in real-world robotics. Furthermore, direct training of symbolic state classifiers for each task often limits data reuse and generalizability to new tasks or failure cases.

Previous work in Bayesian state estimation has made progress, particularly with differentiable filtering for continuous states, enabling end-to-end learning from high-dimensional observations like images. However, its application to discrete symbolic states, especially with limited datasets, has not been extensively demonstrated to be effective. Similarly, existing state estimation methods for assembly tasks often rely on force data, manually defined visual features, or computationally expensive particle filters, which can struggle with nonlinear contact dynamics and real-time operation. A relevant prior Bayesian symbolic state estimation framework by Kappler et al. directly trained task-specific state classifiers, which hampered generalization.

This paper addresses these limitations by proposing a method that bridges the gap between high-dimensional sensory input and robust symbolic state estimation in data-limited scenarios. It seeks to overcome the brittleness of heuristics and the data dependency of direct state classification by introducing an intermediate representation: predicates. By focusing on learning binary, atomic properties (predicates) that compose symbolic states, the work aims to enhance data efficiency, improve generalization across tasks, and enable effective sensor fusion, thus contributing to more robust and adaptable robotic manipulation. It positions itself as a data-efficient Bayesian framework that can handle multimodal observations, contrasting with methods that either require extensive data, are task-specific, or struggle with the discrete nature of symbolic states.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a robust and data-efficient method for estimating high-level symbolic states in contact-rich manipulation tasks. This capability is intended to allow robots to dynamically adjust their sensorimotor skills based on their current environmental state, thereby improving the reliability of task execution.

The motivations for pursuing this objective stem from several challenges observed in current robotic manipulation systems:

- **Brittleness of Heuristic-Based State Detection:** Many high-level execution frameworks, such as state machines and behavior trees, rely on mechanisms to detect symbolic states. A common approach involves handcrafting rules or thresholds based on sensor readings (e.g., a force exceeding 2N to indicate contact). This method is prone to failure if sensor noise or unforeseen disturbances trigger false positives or negatives, leading to incorrect decision-making and task failure (e.g., dropping an object prematurely). The paper aims to replace these brittle heuristics with a more robust, learned approach.
- **Limitations of Data-Driven Methods for Symbolic States:** While data-driven approaches can learn state classifiers, they often require substantial datasets, which are costly and time-consuming to acquire in real-world robotic scenarios. Furthermore, direct multi-class classification of symbolic states can be noisy, especially with limited data, and struggle to scale or generalize to unseen tasks or failure conditions without complete retraining.
- **Scalability and Generalization:** Previous data-driven symbolic state estimation methods, such as those that train classifiers for each state within a task-specific state machine, are not easily scalable. Adding new states, objects, or tasks typically necessitates retraining the entire system from scratch. This limits the reuse of learned knowledge and hinders the deployment of robots in diverse, dynamic environments.
- **Ineffectiveness of Differentiable Filtering for Discrete States with Limited Data:** Differentiable filtering has shown promise for continuous state estimation by embedding recursive Bayesian updates within neural networks for end-to-end learning. However, its direct adaptation to discrete symbolic states with small, real-world datasets has not been demonstrated to be effective, as it can struggle with data imbalance and the sparse nature of discrete transitions.
- **Need for Functional Understanding:** Beyond continuous pose estimation, robots require a "functional understanding" of their environment to make informed decisions. Estimating symbolic states (e.g., "aligned," "in-contact," "fallen") directly contributes to this understanding, enabling the robot to determine sub-task success, detect failures, and select the next appropriate action.

To address these motivations, the paper proposes reducing high-dimensional observations not directly to symbolic states, but to an intermediate space of "predicates." This approach is motivated by two main benefits:
1. **Data Efficiency and Generalization:** Predicates are defined as atomic, binary properties (e.g., `above(a, b)`, `near(a, b)`). Learning binary predicate classifiers is considered easier and requires less data than learning complex multi-class state classifiers. If trained on diverse data, these atomic classifiers are expected to generalize more effectively to novel tasks within the same task family.
2. **Modularity and Composability:** Predicates are modular, allowing them to be composed into different symbolic states and shared across tasks. This means that adding or removing states from the overall state space does not necessitate retraining all predicate classifiers, enhancing the system's flexibility and scalability.

By implementing a Bayesian framework that leverages these predicate classifiers, the authors aim to achieve robust symbolic state estimation from multimodal, high-dimensional sensor inputs, even with minimal training data, and demonstrate its utility in enhancing the performance of manipulation policies on real robots.

### 3. Methodology and Approach

The core of the proposed method is a data-efficient Bayesian framework for symbolic state estimation using predicates, designed to handle high-dimensional, multi-modal observations. The framework draws inspiration from Bayesian state estimation with virtual sensors but introduces predicates as an intermediate representation to enhance data efficiency and generalization.

**A. Domain Specification**
The system is defined by a 6-tuple $\langle S, \Phi, A, T, \Omega, O \rangle$:
- **S:** The set of symbolic states (unobservable).
- **Φ:** The set of predicates that compose the symbolic states.
- **A:** The set of actions the robot can perform.
- **T:** The set of state transition probabilities, $T(s | s_{prev}, a)$, estimated from training data.
- **Ω:** The set of observations (e.g., images, forces, positions).
- **O:** The set of conditional observation probabilities, $O(o | s, a)$.

**B. Belief States**
The agent's estimate of the symbolic state is represented as a probability distribution over states, known as a belief state $b(s)$. This belief state is updated at each time step using the recursive Bayesian update rule:
$b(s) \propto O(o | s, a) \sum_{s_{prev}} T(s | s_{prev}, a) b(s_{prev})$
The initial belief state $b(s_0)$ and transition probabilities $T(s | s_{prev}, a)$ are estimated from state visit counts in the training data.

**C. Virtual Predicate Sensors**
To address the challenge of computing $O(o | s, a)$ directly from high-dimensional observations and with limited data, the method uses binary predicate classifiers as "virtual sensors."
- **Predicates (Φ):** These are atomic binary properties, similar to those in PDDL (Planning Domain Description Language), such as `inside(a, b)` or `above(a, b)`.
- **Symbolic States (S):** Each symbolic state $s$ is defined as a set of predicates, e.g., $s_{inserted} \equiv \{inside(peg, hole), \neg above(peg, surface)\}$.
- **Classifier Training:** For each predicate $\phi \in \Phi$, a binary classifier $h_\phi(o)$ is trained to output a noisy probability that the predicate is true, given an observation $o$.
- **Loss Function:** A modified cross-entropy loss is used for training, focusing only on predicates whose truth values are determined by the ground truth state $s$:
 $L = \sum_{k=1}^{K_s} \phi_k^s \log h_{\phi_k^s}(o) + (1 - \phi_k^s) \log (1 - h_{\phi_k^s}(o))$
 where $\phi_k^s$ is the ground truth value of the $k$-th predicate in state $s$. This approach allows the model to learn efficiently by not requiring truth values for all predicates for every state.

**D. Virtual Predicate Observation Models**
To incorporate the continuous probability outputs of the predicate sensors into the Bayesian framework without computationally expensive sampling for normalization, the observation model $O(h_\phi(o) | s, a)$ is represented using Gaussian Mixture Models (GMMs).
- GMMs are fit to the logits of the virtual predicate sensor outputs (i.e., $\log h_\phi(o)$) for each state and action. This allows for closed-form normalization over the observation space.
- The GMMs are trained on a validation set to mitigate overfitting that could occur if trained on the same data as the predicate classifiers.

**E. Sensor Fusion**
Observations from multiple sensors are integrated by assuming conditional independence given the state and action. The overall conditional observation probability is computed as the product of individual predicate observation probabilities:
$O(o | s, a) = \prod_\phi O(h_\phi(o) | s, a)$
To fuse different physical sensor modalities (e.g., vision and force), modality-specific predicates are defined (e.g., `visual-in-contact`, `force-in-contact`). A symbolic state can then be defined as the conjunction of these modality-specific predicates.

**F. Predicate Classifiers (Implementation Details)**
- **Motion and Force-based Classifiers:** These utilize logistic regression on handcrafted features (e.g., force magnitude for detecting contact). This choice is motivated by the simplicity of these predicates and the limited dataset size.
- **Image-based Classifiers:** For image-based predicates, SimCLRv2 with a ResNet-50 backbone is employed. The network is pre-trained on ImageNet and a linear layer is fine-tuned on the collected dataset (47,752 images from 120 policy executions across 8 tasks). Data augmentation (random cropping, color distortion) is used during fine-tuning.

**G. Real-World Environment**
The framework is evaluated on insertion tasks using the NIST Assembly Task Board I.
- **Hardware:** Kuka IIWA7 arm, Robotiq Hand-E gripper, ATI Mini45 Force/Torque sensor, and a wrist-mounted Basler acA1920-50gc camera.
- **Tasks:** Eight connector insertion tasks involving four types of connectors (D-sub, RJ45, USB, waterproof) and four types of pegs (8x7 rectangle, 12x8mm rectangle, 12mm round, 16mm round).

**H. Insertion Task Domain Specification**
- **States (S):** ABOVE, ONSURFACE, ALIGNED, INSERTED, FALLEN.
- **Predicates (Φ):** A set of 9 predicates including `motion-force-axis-aligned(a, b)`, `motion-force-dropping(a)`, `visual-above(a, b)`, `visual-fallen(a)`, etc., designed to maximize individual classifier performance across sensor modalities (e.g., image classifiers for `above/below`, motion/force for `on-surface/aligned`).
- **Actions (A):** Four low-level manipulation primitives implemented with an impedance controller: Prepare, MakeContact, Search (Lissajous search), and Insert.
- **Observations (Ω):** 3D positions, 3D velocities, 3D forces, and 500x500 RGB images.
- **Transitions (T) and Observation Models (O):** Transitions are computed from collected trajectories. Observation models are provided by the trained predicate classifiers and GMMs.

### 4. Main Findings and Results

The evaluation of the proposed Bayesian symbolic state estimation framework ("Pred") involved three main experiments: offline state estimation accuracy, generalization to unseen tasks, and online closed-loop policy execution success rate. Comparisons were made against several baselines: direct symbolic state classification ("State"), a differentiable filter ("Filter"), and a manually tuned open-loop policy ("Manual"). Sensor modality ablations (e.g., "Pred-Image", "Pred-MF") were also conducted.

**A. Predicate Classifier Performance**
Individual predicate classifiers exhibited high accuracy, precision, and recall (Table I). The overall average accuracy was 0.95, with precision of 0.93, and recall of 0.92. This suggests that defining atomic binary predicates simplifies the classification problem, enabling high performance even with a relatively small training dataset. For instance, `motion-force-axis-aligned` achieved 0.96 accuracy, while `visual-fallen` reached 0.99 accuracy.

**B. Offline State Estimation**
- **Accuracy and F1 Score:** The proposed "Pred" method achieved the highest offline state estimation accuracy (0.92) and the best average F1 score (0.67) across all states (Fig. 4). The F1 score is particularly relevant for evaluating performance on short-duration states, such as `ALIGNED`, which are critical for task success but are often underrepresented in datasets.
- **Comparison to Baselines:** "Pred" significantly outperformed "State" (0.81 accuracy, 0.60 F1), indicating that predicate-based classification is more robust than direct multi-class symbolic state classification. The sensor ablations also showed this trend (e.g., Pred-MF vs. State-MF, Pred-Image vs. State-Image).
- **Differentiable Filter Performance:** "Filter" achieved a relatively high accuracy (0.85) but a lower F1 score (0.53). This discrepancy suggests that the differentiable filter struggled with short-duration states, likely due to data imbalance issues at the sequence level, even with resampling strategies.
- **Sensor Fusion Benefits:** Methods fusing multiple sensor modalities (e.g., "Pred") consistently achieved higher accuracy and F1 scores than their single-modality counterparts (e.g., "Pred-Image", "Pred-MF"). This supports the hypothesis that motion/force and image signals provide complementary information, such as force signals distinguishing `ONSURFACE` from `ALIGNED` where images appear similar, and images distinguishing `FALLEN` from `SEARCHING` where force signals might be ambiguous.

**C. Generalization to Unseen Tasks**
- **Improved Generalization:** When models were trained on 7 of the 8 tasks and tested on the 8th unseen task, "Pred" demonstrated superior generalization (0.80 accuracy, 0.42 F1) compared to "State" (0.38 accuracy, 0.20 F1) (Fig. 5). The accuracy of "Pred" decreased by 0.12, whereas "State" saw a drop of 0.43, highlighting the benefits of predicates for generalization.
- **Modality-Specific Generalization:** "Pred-MF" (motion/force predicates) achieved the best generalization performance among predicate-based methods (0.87 accuracy, 0.48 F1). This suggests that motion and force-based predicates can be more generic across tasks within the same family (e.g., connector-socket insertion). Conversely, "Pred-Image" showed weaker generalization (0.45 accuracy), indicating that image-based predicates might require larger and more diverse datasets to generalize effectively, or further fine-tuning on novel task data.

**D. Online Closed-Loop Policy Execution**
- **Highest Success Rate:** Integrating the state estimation methods into a closed-loop policy for three error-prone insertion tasks (D-sub, USB, RJ45) showed that "Pred" achieved the highest average success rate (0.72) over 20 trials (Fig. 6).
- **Outperforming Manual Baseline:** "Pred" was the only method that consistently outperformed the "Manual" (hand-tuned thresholds) baseline across all tested tasks. This demonstrates the practical utility of the proposed estimator in improving the robustness of high-level manipulation policies by enabling dynamic state-based decision-making.
- **Failure Modes:** Common failure modes for "Pred" were primarily related to the low-level execution policy (e.g., connector repeatedly falling off, prolonged searching leading to time limits), rather than misclassification by the state estimator itself.
- **Differentiable Filter Limitation:** "Filter" performed poorly in online execution, with 0 successes in the D-sub task. This was attributed to its inability to reliably detect short-duration states like `ALIGNED`, causing the robot to continue searching even when the connector was correctly positioned.

### 5. Significance and Potential Impact

This research presents a notable contribution to the field of robotic manipulation, particularly concerning robust symbolic state estimation in challenging, real-world scenarios.

**Core Contribution:** The primary significance lies in the development of a Bayesian framework that leverages binary predicate classifiers for data-efficient estimation of high-level symbolic states from multi-modal, high-dimensional sensor observations. This approach addresses key limitations of prior methods by introducing predicates as a modular and generalizable intermediate representation.

**Key Advantages Demonstrated:**
- **Enhanced Robustness and Data Efficiency:** The method outperforms existing baselines, including direct symbolic state classification and differentiable filtering, especially when confronted with limited training data, which is characteristic of real-world robotic applications. The use of binary predicate classifiers simplifies the learning problem and contributes to this data efficiency.
- **Improved Generalization:** The predicate-based approach demonstrates superior generalization capabilities to unseen tasks within the same task family. This is crucial for deploying robotic systems in diverse environments without requiring extensive retraining for every new task variant. The observation that motion and force-based predicates generalize particularly well suggests potential for learning generic interaction skills.
- **Effective Sensor Fusion:** The framework effectively integrates information from various sensor modalities (e.g., vision, force, motion). By allowing for modality-specific predicates, the system leverages complementary information from different sensors, increasing the overall reliability of state estimation.
- **Practical Impact on Policy Execution:** The online experiments show that integrating this symbolic state estimator can directly improve the success rate of high-level manipulation policies. By providing accurate and timely detection of symbolic states, the robot can make more informed decisions, recover from failures, and execute task transitions more reliably than with manually tuned thresholds.

**Broader Applicability:** While demonstrated on contact-rich insertion tasks, the framework's design principle—using predicates as a low-level, composable building block for high-level symbolic states—is broadly applicable. It can be readily integrated with various high-level execution models, including behavior trees and task planners, beyond the state machines used in this work. This suggests a pathway towards more intelligent and adaptable robotic systems that can reason about and react to their environment at a higher level of abstraction.

**Future Directions and Implications:** The work opens avenues for future research, such as optimizing the choice of generative observation models beyond GMMs, enhancing the generalization of image-based predicates with larger datasets or more sophisticated transfer learning techniques, and integrating this robust state estimation with adaptive low-level control policies to further improve overall task success rates. The ability to estimate symbolic states robustly and efficiently is fundamental for developing autonomous robots capable of performing complex, human-like manipulation tasks in unstructured and uncertain environments.
