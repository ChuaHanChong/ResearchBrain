# OakInk: A Large-scale Knowledge Repository for Understanding Hand-Object Interaction

> [!summary] Summary
> The OakInk dataset from Shanghai Jiao Tong University provides a comprehensive knowledge repository for human hand-object interactions by integrating object affordances with diverse interaction data. This enables machines to understand not only how to grasp objects, but also the specific reasons behind chosen grasps for particular tasks.

## Problem

- Existing hand-object interaction datasets often lack awareness of object functionality (affordances), focusing primarily on geometric properties.
- Current datasets offer insufficient diversity in grasp types and interaction intents, limiting the ability of robotic systems to perform context-aware manipulation.
- Many systems struggle with generalizing manipulation knowledge between objects that share similar functional properties but vary in shape.

## Method

- The **OakInk** dataset comprises three components: ==Oakbase==, an object affordance knowledge base; ==Inkbase==, a collection of real human hand-object interactions; and ==Tink==, a method for transferring interaction knowledge.
- **Oakbase** organizes 1,800 common household objects in a ==semantic knowledge graph==, annotating object parts with descriptive phrases related to their functionality.
- **Inkbase** contains data captured from 12 participants interacting with 100 objects across five distinct manipulation intents, recording detailed ==3D hand and object movements==, ==contact regions==, and ==force distributions==.

## Results

- The OakInk dataset compiles over **50,000** affordance-aware hand-object interactions, providing a comprehensive resource for robotics research.
- The dataset improves performance in standard tasks such as hand pose estimation and grasp generation, and introduces novel applications including intent-based interaction generation and object handover generation.
- Human evaluation studies demonstrate that interactions generated using OakInk are rated as more natural and appropriate compared to those produced by previous methods.

## Takeaways

> [!tip] Key Insights
> - Integrating object affordances into a hierarchical knowledge graph, Oakbase, allows for a nuanced understanding of objects beyond their physical properties, mapping functionality to specific object parts.
> - Capturing multi-modal human interaction data (3D poses, contact regions, force distribution) across five distinct intents (use, hold, lift-up, hand-out, receive) reveals how humans adapt manipulation strategies based on context.
> - The Tink method enables transferring observed interaction knowledge from real objects to novel virtual objects with similar affordances but different shapes, using implicit shape interpolation, explicit contact mapping, and iterative pose refinement.

## Detailed Report

### 1. Introduction

Understanding how humans interact with objects is fundamental to developing robust robotic systems that can operate effectively in human environments. The OakInk dataset presents a significant advancement in this domain by creating a comprehensive knowledge repository for hand-object interactions (HOI) that emphasizes the crucial role of object affordances—the functional properties that dictate how objects can be used.

Developed by researchers at Shanghai Jiao Tong University, OakInk addresses critical limitations in existing datasets by integrating object functionality with interaction data. This integration enables machines to understand not just how to grasp objects, but why specific grasps are chosen for particular tasks—a capability essential for context-aware manipulation.

### 2. The Challenges in Hand-Object Interaction

Current approaches to hand-object interaction face several limitations:

1. **Limited affordance awareness**: Most datasets focus on geometric properties without adequately representing object functionality.
2. **Insufficient interaction diversity**: Existing collections often lack variety in grasp types and interaction intents.
3. **Constrained generalization**: Many systems struggle to transfer knowledge between similar objects with different shapes.

The disconnect between object functionality and manipulation strategy creates a significant gap in robotic systems' ability to interact naturally with objects. For instance, a cup might be grasped differently when drinking versus when passing it to someone else—the intent affects the interaction strategy.

### 3. OakInk Dataset Architecture

OakInk consists of three main components:

1. **Oakbase**: A comprehensive object affordance knowledge base containing 1,800 common household objects organized in a semantic knowledge graph.
2. **Inkbase**: A collection of captured human hand-object interactions featuring diverse manipulation intents and strategies.
3. **Tink**: A novel method for transferring interaction knowledge between objects with similar affordances but different shapes.

This multi-layered architecture enables OakInk to provide both breadth and depth in its representation of hand-object interactions, resulting in over 50,000 distinct affordance-aware interactions.

### 4. Oakbase: Object Affordance Knowledge Base

Oakbase organizes objects into a hierarchical knowledge graph that emphasizes functionality. Objects are categorized as either manipulation tools (used to manipulate other objects) or function tools (used directly for specific tasks).

Each object part is annotated with descriptive phrases that explain its functionality, such as "hold by sth" or "point to sth." This detailed representation allows the system to understand how different parts of an object relate to specific interaction strategies.

Oakbase's structure enables more nuanced understanding of objects beyond their physical properties, laying the groundwork for more sophisticated manipulation strategies that consider the object's intended use.

### 5. Inkbase: Interaction Knowledge Base

To build Inkbase, the researchers invited 12 participants to interact with 100 selected objects in a motion capture environment. The data collection setup combined multiple cameras with an infrared motion capture system to record detailed 3D hand and object movements.

Participants performed five distinct interaction intents:
- Use (manipulating the object according to its function)
- Hold (maintaining a stable grasp)
- Lift-up (raising the object)
- Hand-out (offering the object to someone else)
- Receive (accepting an object from someone else)

For each interaction, the system recorded:
- 3D hand and object poses
- Contact regions between hand and object
- Contact force distribution

This multi-modal data provides unprecedented insight into how humans adjust their manipulation strategies based on different intents while interacting with the same object.

### 6. Tink: Transferring Interaction Knowledge

A key innovation of OakInk is the Tink method, which transfers interaction knowledge from captured real-world objects to virtual objects with similar affordances but different shapes. This capability significantly expands the dataset and enhances its utility for training generalized manipulation models.

The Tink process involves three main steps:

1. **Implicit Shape Interpolation**: Objects are represented as Signed Distance Functions (SDFs) and interpolated using a neural generative model (DeepSDF).

2. **Explicit Contact Mapping**: Contact regions are transferred from source to target objects through iterative closest point registration.

3. **Iterative Pose Refinement**: Hand poses are optimized to maintain contact consistency while respecting anatomical constraints and avoiding interpenetration.

This approach solves a critical limitation of direct pose copying, which often results in unrealistic hand configurations when applied to objects with different shapes.

The equation governing pose refinement is:

$$E(\theta) = w_c E_c(\theta) + w_a E_a(\theta) + w_p E_p(\theta)$$

where $E_c$ represents contact consistency, $E_a$ enforces anatomical constraints, and $E_p$ prevents interpenetration. The weights $w_c$, $w_a$, and $w_p$ balance these competing objectives.

### 7. Applications and Benchmarking

OakInk serves as both a training resource and a benchmark for various hand-object interaction tasks. The researchers evaluated it on:

#### 7.1. Hand Pose Estimation

The dataset enables more accurate hand pose estimation during object manipulation, addressing the challenge of occlusion that occurs when parts of the hand are hidden by the object.

OakInk improves grasp generation by providing a more diverse set of examples that consider object functionality:

### 8. Impact and Significance

OakInk represents a significant advancement in hand-object interaction modeling with several important implications:

1. **Comprehensive Knowledge Repository**: By integrating object affordances with interaction data, OakInk enables a deeper understanding of the relationship between object functionality and manipulation strategy.

2. **Diverse Interaction Scenarios**: The dataset captures a wide range of interaction intents, providing examples for various real-world tasks.

3. **Knowledge Transfer**: The Tink method allows for generalizing interaction knowledge across objects with similar affordances but different shapes.

4. **Novel Applications**: OakInk enables new applications like intent-based interaction generation and handover generation that were not well-supported by previous datasets.

The t-SNE visualization of the interaction space shows how OakInk captures meaningful patterns in hand-object interactions.

### 9. Conclusion

OakInk significantly advances our ability to model and understand hand-object interactions by creating a comprehensive knowledge repository that integrates object affordances with diverse interaction data. By focusing on the relationship between object functionality and manipulation strategy, OakInk enables more natural and context-aware object manipulation.

The dataset's combination of affordance knowledge (Oakbase), diverse interaction examples (Inkbase), and the innovative knowledge transfer method (Tink) creates a powerful resource for developing more capable robotic systems. The applications demonstrated—from improved grasp generation to intent-based interaction and object handovers—illustrate how OakInk can enhance robotic manipulation capabilities across various tasks.

As robotics continues to move toward more human-like manipulation capabilities, datasets like OakInk that capture the nuanced relationship between object functionality and manipulation strategy will become increasingly valuable. By making this dataset publicly available, the researchers have provided a significant resource for advancing the field of hand-object interaction and robotic manipulation.
