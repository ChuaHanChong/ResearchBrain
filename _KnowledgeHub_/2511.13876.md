# QwenCLIP: Boosting Medical Vision-Language Pretraining via LLM Embeddings and Prompt tuning

> [!summary] Summary
> Researchers at LIPADE, Université Paris Cité, developed QwenCLIP, a medical vision-language pretraining framework that integrates dedicated Large Language Model embeddings and a hybrid prompt tuning strategy. This approach effectively processes lengthy clinical texts, achieving state-of-the-art performance in medical image retrieval tasks with improvements in CUI@K and Precision@K across multiple benchmarks.

## Problem

- Existing Vision-Language Pretraining (VLP) models like CLIP struggle with limited text input length (77 tokens), failing to process the often hundreds of tokens in detailed medical reports.
- Even domain-specific BERT encoders used in medical CLIP variants face context limits (e.g., 512 tokens), leading to significant information loss in comprehensive clinical narratives.
- Prior attempts to integrate Large Language Models (LLMs) often involve complex, computationally intensive two-stage training to adapt generative LLMs for discriminative embedding tasks.

## Method

- Replaces the traditional CLIP text encoder with a frozen ==Qwen3-embedding-8B model==, a dedicated LLM embedding model designed for dense representation learning and long context windows.
- Implements a ==hybrid prompt tuning strategy==, combining static explicit instructions with ==learnable soft prompt vectors==, to optimally guide the LLM for cross-modal medical tasks.
- Utilizes a learnable Vision Transformer (ViT-B/16) as the image encoder, trained with the LLM embeddings via a standard ==InfoNCE contrastive loss== to align visual and textual modalities.

## Results

- QwenCLIP achieved state-of-the-art CUI@K scores on the ROCOv2 dataset (e.g., **45.96** @5, **52.47** @50), indicating enhanced alignment between medical images and their associated concepts.
- The framework demonstrated superior performance across all zero-shot image-to-image retrieval benchmarks, including ROCOv2 (Modality, Organ, Modality & Organ) and IRMA, with leading Precision@K scores (e.g., **96.24** @5 for Modality on ROCOv2, **98.49** @5 for Organ on IRMA).
- Ablation studies confirmed that both the dedicated LLM embedding model and the learnable prompt tuning strategy independently and synergistically contribute to the observed performance improvements.

## Takeaways

> [!tip] Key Insights
> - Dedicated Large Language Model embedding models significantly improve semantic understanding of medical texts and boost cross-modal alignment performance compared to generic or BERT-based text encoders.
> - A hybrid prompt tuning strategy, combining static instructions with learnable soft prompts, is crucial for optimally adapting the LLM's representations to specific medical vision-language tasks.
> - Integrating a dedicated embedding LLM is more efficient and architecturally suitable for VLP than repurposing generative LLMs, reducing complexity and computational cost.
