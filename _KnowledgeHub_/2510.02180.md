# GRACE: A Language Model Framework for Explainable Inverse Reinforcement Learning

> [!summary] Summary
> GRACE (Generating Rewards As CodE), developed at Apple and the University of Oxford, introduces an Inverse Reinforcement Learning framework that infers interpretable, executable Python reward functions directly from expert demonstrations. It achieved competitive policy learning performance on tasks in MuJoCo, BabyAI, and AndroidWorld, often matching ground-truth rewards and outperforming prior methods with an order of magnitude fewer demonstrations, while also fostering the creation of reusable code modules.

## Problem

- Manually designing reward functions for Reinforcement Learning (RL) is often labor-intensive, error-prone, and doesn't scale well to complex or multi-task environments.
- Existing Inverse Reinforcement Learning (IRL) methods, especially those using deep neural networks, often produce "black-box" reward models that lack interpretability and verifiability, hindering debugging and trust.
- Prior LLM-based approaches for generating rewards as code typically require explicit task descriptions, goal states, or ground-truth reward signals beyond just demonstrations.

## Method

- **GRACE** employs an ==evolutionary search== framework powered by Large Language Models (LLMs) to iteratively generate and refine reward functions represented as executable Python code.
- The system uses an AIRL-like discriminator loss as a fitness function to evaluate how well a candidate reward function differentiates expert from negative trajectories.
- LLMs serve as both initializers and mutation operators, generating new reward functions and intelligently debugging/refining existing ones by analyzing "wrong examples" and their associated reward values.

## Results

- GRACE consistently achieved a reward accuracy of 1.0 on BabyAI and AndroidControl tasks, and learned policies matched or outperformed GAIL with **200x** fewer expert trajectories (e.g., 10 for GRACE vs. 2000 for GAIL on MuJoCo).
- The framework demonstrated high sample efficiency, recovering perfect reward functions on BabyAI tasks with as few as eight expert demonstrations and non-trivial accuracy with just one.
- The evolutionary process fostered the emergence of reusable code modules and functions, forming a domain-specific library for multi-task scenarios, which improved generalization and efficiency.

## Takeaways

> [!tip] Key Insights
> - Leveraging LLMs within an evolutionary search paradigm can effectively synthesize high-quality, interpretable reward functions directly from demonstrations without requiring additional explicit task descriptions or ground-truth rewards.
> - Generating rewards as human-readable and executable code inherently provides interpretability and verifiability, addressing a core limitation of black-box deep IRL models.
> - The LLM's strong priors and reasoning capabilities enable superior sample efficiency, allowing accurate reward recovery and policy learning with significantly fewer expert demonstrations than traditional deep IRL methods.
