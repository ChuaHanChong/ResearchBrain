# SkeleWAM: Skeleton World-Action Modeling for Efficient Robotic Manipulation

> [!summary] Summary
> SkeleWAM is a compact world action model that represents a manipulation scene as a sparse 3D skeleton of robot joints, object centers and interaction points, built online from RGB-D and proprioception. It is trained with flow matching to predict actions and future skeletons together, and drops the future branch at inference. With 57.1M parameters it reaches 85.9% on LIBERO-Plus, beating Cosmos-Policy by 3.7 points.

## Problem

- Existing world action models predict videos or learned visual latents, which encode robot-object interaction geometry only implicitly rather than as explicit state variables.
- Visual latents are shaped by the encoder's pretraining objective and keep appearance information unrelated to control, while compressing pixels does not isolate spatial configurations or relative motion.
- Strong VLA and video-based world models need billions of parameters, and their dense future prediction is computationally heavy without clearly targeting manipulation-relevant structure.

## Method

- ==Skeleton world representation==: robot keypoints from ==forward kinematics== plus object centers and interaction points estimated by a frozen RGB-D perception network, all placed in a shared robot-centric frame.
- ==Two-expert Mixture-of-Transformers==, following Fast-WAM: a world expert predicts future skeletons and an action expert predicts action chunks, trained jointly with ==flow matching== under a ==block mask== that blocks cross-branch attention.
- ==Medoid Action Consensus== samples K action chunks from independent noise and executes the one with the smallest average distance to the others over the first h steps, with no reward model.

## Results

- On full LIBERO-Plus zero-shot, it scores **85.9%** overall versus **82.2%** for Cosmos-Policy and **79.7%** for pi0.5, and **93.4%** under camera perturbations, **17.6** points above Cosmos-Policy.
- Ablations: removing future-skeleton supervision drops success from **85.9%** to **80.1%**, using only object centers gives **82.3%**, only interaction points gives **77.7%**, and MAC with K=3 beats single sampling (**84.2%**).
- Real ARX R5 robot, five tasks with **20** trials each: **89%** average versus **87%** for Cosmos-Policy, **83%** for Fast-WAM and **76%** for pi0.5. Layout perturbation stays weak at **66.6%**.

## Takeaways

> [!tip] Key Insights
> - A sparse, explicit geometric state can replace pixels or visual latents as the prediction target for a world action model, cutting parameters by about 40x with no loss in robustness.
> - The gain from future prediction comes from co-training a shared representation, not from passing information between branches, so the world branch can be dropped at inference for free.
> - Explicit geometry handles viewpoint and appearance shifts well but does not fix generalization to new spatial layouts, even with perfect simulator coordinates, so that gap is in the policy, not perception.

## Detailed Report

### 1. Overview

A robot must use a camera view and an instruction to manipulate an object while tracking how the robot and object relate in space. Many existing world action models predict videos or visual features. In those models, interaction geometry is represented only implicitly and may be mixed with appearance details that do not help control. SkeleWAM instead gives the policy a compact, explicit map of the geometry it needs to act: robot joints, object centers, and points on objects that matter for contact. On a specified zero-shot benchmark, the compact model reaches 85.9% overall success, but unfamiliar layouts remain difficult.

The project page's featured front-view open-drawer visualization shows RGB with a reconstructed skeleton. Skeleton views are reconstructions from recorded interactions, and the RGB clips are separate recordings. This video is not a success-rate demonstration.

### 2. From pixels to a control state

A world action model learns action generation together with prediction of a future scene state. SkeleWAM turns RGB-D observations and robot proprioception into 3D landmarks. It learns to predict both an action and how those landmarks will move. It then uses the future prediction as training supervision rather than generating it at deployment.

The landmarks form a scene skeleton. Robot joint and end-effector positions come from forward kinematics. Each object has a center for overall location and interaction points for manipulation-relevant regions. A fixed pretrained perception network estimates object landmarks from RGB-D observations. The nodes are kept in a consistent order and expressed in a shared robot-centric coordinate frame.

Training has an action branch and a future-skeleton branch that share the current-skeleton context, and both receive the language instruction. The branches are trained jointly with flow matching, a way of learning to transform noise into demonstration targets. At inference, the future-skeleton branch is omitted, and the robot acts from the current skeleton and instruction.

Overview of SkeleWAM. During training, RGB, depth, robot state, and language pass through perception and forward kinematics to produce the current skeleton. World and action experts train on future-skeleton and action targets using the shared current-skeleton context. At inference, the future-skeleton branch is removed, and the selected action chunk is executed for a prefix before observing and replanning.

### 3. What the comparisons establish

The evaluation uses LIBERO-Plus, which contains 10,030 variants across seven perturbation categories. The authors report zero-shot success rates without fine-tuning on evaluation variants. In the RGB-D observation setting, SkeleWAM scores 85.9% overall with approximately 57.1 million parameters. The strongest compared observation-based baseline, Cosmos-Policy, scores 82.2% with approximately 2B parameters. That is an absolute difference of 3.7 percentage points. This comparison does not by itself isolate geometry as the cause, since the systems differ in more than representation.

The cleaner test is the action-only ablation on the same RGB-D LIBERO-Plus setup. Removing the future-skeleton loss and future tokens drops success from 85.9% to 80.1%. This comparison keeps current-skeleton processing, the action-generation backbone, and action-only inference the same. The result supports the claim that the auxiliary prediction objective helps in this setup. It does not show that the predicted future skeleton is needed at inference.

Model ablations on the full LIBERO-Plus benchmark in the RGB-D setting. Panel (b) compares action only (80.1) with action plus future skeleton (85.9).

The main boundary concerns layout perturbations. Under layout perturbations, SkeleWAM scores 66.6%, below π0.5's 84.1%. A diagnostic version with privileged simulator coordinates raises overall success only to 87.7%. Even this version reaches only 69.0% on layout. This suggests that localization error is not the only challenge, though it does not identify a single remaining cause.

### 4. Closing

In SkeleWAM, future-state learning does not require reconstructing future pixels. Named landmarks let the model learn a geometric change signal, while action generation at inference uses the current skeleton. The matched action-only ablation gives the clearest evidence that this training signal helps. Large layout changes mark the boundary of the claim.
