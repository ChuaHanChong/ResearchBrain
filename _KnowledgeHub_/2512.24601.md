# Recursive Language Models

> [!summary] Summary
> Recursive Language Models (RLMs) introduce an inference-time paradigm allowing large language models to process inputs exceeding 10 million tokens, vastly extending their effective context window. This approach achieved 91.3% accuracy on multi-document retrieval tasks where base models failed and dramatically outperformed other long-context methods on information-dense problems.

## Problem

- Large Language Models (LLMs) are severely limited by finite context windows, experiencing "context rot" and performance degradation with longer prompts.
- Existing LLM architectures struggle to effectively process and reason over extremely long inputs, such as millions of tokens required for "long-horizon" tasks.
- Conventional methods for handling long contexts often involve lossy compression or architectural changes that require extensive retraining.

## Method

- Recursive Language Models (RLMs) scaffold a base LLM within a ==Read-Eval-Print Loop (REPL)== programming environment, treating the user prompt as an external object.
- The LLM generates code to ==symbolically interact==, decompose, and transform the long prompt, examining selective portions rather than ingesting the full input directly.
- The RLM enables ==symbolic recursion==, allowing the LLM to programmatically invoke itself on arbitrary slices or transformations of the prompt, overcoming output length limitations.

## Results

- RLMs successfully processed inputs up to **10 million tokens**, achieving **91.3%** accuracy on a multi-document task (BrowseComp-Plus) where base models scored **0.0%**.
- They dramatically outperformed vanilla frontier LLMs and common long-context baselines on tasks requiring deep reasoning over extensive inputs, like OOLONG-Pairs (RLM(GPT-5) achieved **58.0%** F1 vs. **<0.1%** for base models).
- Post-training smaller models (e.g., RLM-Qwen3-8B) on RLM trajectories from larger models significantly improved their RLM performance, demonstrating a promising path for native RLM capabilities.

## Takeaways

> [!tip] Key Insights
> - Offloading the prompt into a REPL environment is essential for scaling beyond the base LLM's inherent context window.
> - Symbolic recursion, where the LLM can programmatically invoke sub-LLMs, provides significant performance gains for information-dense and complex tasks.
> - This inference-time scaling approach enables LLMs to robustly handle increasing task complexity and context length, exhibiting slower performance degradation than base models.
