# GROVE: A Generalized Reward for Learning Open-Vocabulary Physical Skill

> [!summary] Summary
> GROVE is a generalized reward framework that enables simulated agents to learn open-vocabulary physical skills from natural language instructions. It integrates LLM-generated physical constraints with VLM-based semantic evaluations using a novel Pose2CLIP network, achieving 25.7% higher task completion and 22.2% better motion naturalness compared to baselines, while converging 8.4 times faster.

## Problem

- Manually designing task-specific reward functions for Reinforcement Learning (RL) is time-consuming and does not scale for diverse physical tasks.
- Existing LLM-based approaches struggle with holistic motion assessment and stylistic qualities, leading to unnatural movements, while VLM-based methods face a significant sim-to-real domain gap and cannot enforce precise kinematic constraints.
- Leveraging VLMs for simulated environments often necessitates computationally expensive high-fidelity rendering to bridge the visual domain gap, hindering efficient RL training.

## Method

- A generalized reward function combines an LLM-generated component for precise physical constraints (RLR_LRL​) with a VLM-based semantic evaluation (RVR_VRV​) from a frozen CLIP model.
- A lightweight neural network, Pose2CLIP, directly maps agent pose representations to CLIP's feature space, circumventing the need for computationally expensive rendering to address the sim-to-real gap.
- ==An Iterative Reward Design Process (RDP)== employs an adaptive rejection sampling strategy to dynamically refine the LLM-generated reward function, using the VLM-based reward as a fitness evaluator to ensure semantic alignment.

## Results

- GROVE achieved **25.7%** higher task completion scores and a **22.2%** improvement in perceived motion naturalness for open-vocabulary humanoid skill acquisition compared to state-of-the-art baselines.
- It demonstrated robust generalizability across five diverse RL tasks and embodiments, exhibiting superior training efficiency (faster convergence) in three out of four tasks compared to directly optimizing expert rewards.
- The framework achieved **8.4** times faster convergence than previous methods and significantly outperformed VLM-RM while using only **11.4%** of its training time for the humanoid bowing task, highlighting its efficiency.

## Takeaways

> [!tip] Key Insights
> - Combining LLM-derived precise kinematic constraints and VLM-derived holistic semantic evaluation offers a more complete and robust reward signal than either modality alone for open-vocabulary physical skill learning.
> - Directly mapping agent poses to VLM feature space via Pose2CLIP dramatically improves computational efficiency by bypassing costly rendering, making VLM-based rewards practical for real-time RL training.
> - An adaptive, VLM-guided regeneration process for LLM-based rewards ensures that optimization leads to both physically correct and semantically natural behaviors, preventing divergence towards unintended solutions.
