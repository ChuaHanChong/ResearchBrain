# ReasoningBank: Scaling Agent Self-Evolving with Reasoning Memory

> [!summary] Summary
> A novel memory framework, ReasoningBank, coupled with Memory-aware Test-Time Scaling (MaTTS), enables large language model agents to distill generalizable reasoning strategies from both successes and self-judged failures, facilitating continuous self-evolution and enhancing performance by up to 8.3% on web-based tasks and reducing interaction steps.

## Problem

- LLM agents struggle to learn from past experiences, repeating errors and discarding valuable insights, limiting their self-evolving capabilities.
- Existing agent memory systems primarily store raw trajectories or specific successful routines, which often lack high-level, transferable reasoning patterns.
- Current approaches often neglect the rich learning opportunities presented by failures, focusing predominantly on successful experiences.
- Test-time scaling (TTS) has not been synergistically integrated with memory to create a positive feedback loop for continuous agent learning and performance enhancement.

## Method

- ==ReasoningBank== introduces a structured memory framework that distills generalizable reasoning strategies (Title, Description, Content) from an agent's self-judged successful and failed experiences.
- ==Memory-aware Test-Time Scaling (MaTTS)== instantiates parallel and sequential scaling mechanisms to generate diverse exploration histories, which are then used to synthesize higher-quality, transferable memory.
- The framework integrates a ==closed-loop process== of memory retrieval, construction from new experiences (including self-judged failures), and consolidation.
- MaTTS fosters a ==bidirectional synergy== where memory guides test-time exploration, and the enriched exploration yields better memory curation.

## Results

- ReasoningBank consistently outperformed memory-free and other memory baselines (Synapse, AWM) across WebArena, Mind2Web, and SWE-Bench-Verified, achieving up to an **8.3%** absolute improvement in overall success rate on WebArena.
- The framework enhanced agent efficiency, reducing the average number of interaction steps by up to **1.4** on WebArena and **2.8** on SWE-Bench-Verified.
- MaTTS, leveraging both parallel (k=5) and sequential scaling, further improved success rates (e.g., from **49.7%** to **55.1%** with parallel scaling on WebArena-Shopping) and consistently surpassed vanilla test-time scaling.
- Learning from failures significantly contributed to ReasoningBank's performance, improving its success rate from **46.5%** (success-only) to **49.7%** (with failures), demonstrating robust knowledge acquisition.

## Takeaways

> [!tip] Key Insights
> - Distilling high-level, transferable reasoning patterns from both successful and self-judged failed experiences is crucial for LLM agents to generalize and adapt effectively.
> - A bidirectional synergy exists between memory and test-time computation: high-quality memory enables more effective scaling, and scaling generates richer experiences that lead to better memory curation.
> - Learning from self-judged failures significantly boosts agent robustness, transforming counterfactual signals into constructive strategies and preventing future errors.
> - ReasoningBank's memory items demonstrate emergent behaviors, evolving from simple execution steps to complex, adaptive, and compositional reasoning strategies over time.
