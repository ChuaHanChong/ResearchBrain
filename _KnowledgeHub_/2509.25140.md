# ReasoningBank: Scaling Agent Self-Evolving with Reasoning Memory

> [!summary] Summary
> A novel memory framework, ReasoningBank, coupled with Memory-aware Test-Time Scaling (MaTTS), enables large language model agents to distill generalizable reasoning strategies from both successes and self-judged failures, facilitating continuous self-evolution and enhancing performance by up to 8.3% on web-based tasks and reducing interaction steps.

## Problem

- LLM agents struggle to learn from past experiences, repeating errors and discarding valuable insights, limiting their self-evolving capabilities.
- Existing agent memory systems primarily store raw trajectories or successful routines, lacking high-level, transferable reasoning patterns, and neglect the rich learning opportunities presented by failures, focusing predominantly on successful experiences.
- Test-time scaling (TTS) has not been synergistically integrated with memory to create a positive feedback loop for continuous agent learning and performance enhancement.

## Method

- ==ReasoningBank== introduces a structured memory framework that distills generalizable reasoning strategies (Title, Description, Content) from an agent's self-judged successful and failed experiences.
- ==Memory-aware Test-Time Scaling (MaTTS)== instantiates parallel and sequential scaling mechanisms to generate diverse exploration histories, which are then used to synthesize higher-quality, transferable memory.
- The framework integrates a ==closed-loop process== of memory retrieval, construction from new experiences (including self-judged failures), and consolidation, fostering a ==bidirectional synergy== where memory guides exploration and the enriched exploration yields better memory curation.

## Results

- ReasoningBank consistently outperformed memory-free and other memory baselines (Synapse, AWM) across WebArena, Mind2Web, and SWE-Bench-Verified (up to **8.3%** absolute improvement on WebArena), while reducing average interaction steps by up to **1.4** on WebArena and **2.8** on SWE-Bench-Verified.
- MaTTS, leveraging both parallel (k=5) and sequential scaling, further improved success rates (e.g., from **49.7%** to **55.1%** with parallel scaling on WebArena-Shopping) and consistently surpassed vanilla test-time scaling.
- Learning from failures significantly contributed to ReasoningBank's performance, improving its success rate from **46.5%** (success-only) to **49.7%** (with failures), demonstrating robust knowledge acquisition.

## Takeaways

> [!tip] Key Insights
> - Distilling high-level, transferable reasoning patterns from both successful and self-judged failed experiences - turning counterfactual failure signals into constructive strategies - is crucial for LLM agents to generalize, adapt, and become more robust.
> - A bidirectional synergy exists between memory and test-time computation: high-quality memory enables more effective scaling, and scaling generates richer experiences that lead to better memory curation.
> - ReasoningBank's memory items demonstrate emergent behaviors, evolving from simple execution steps to complex, adaptive, and compositional reasoning strategies over time.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development of large language model (LLM) agents has advanced their application in complex real-world tasks requiring multi-turn interactions, such as web browsing, computer operation, and scientific discovery. However, a limitation of these agents is their inability to systematically learn from accumulated interaction history. This deficiency often results in agents repeating errors, discarding valuable insights, and lacking capabilities for self-evolution over time.

Existing research on agent memory has predominantly focused on storing past interactions, typically in the form of raw trajectories or successful task routines. These approaches exhibit two primary limitations: they often fail to distill high-level, transferable reasoning patterns, and they tend to over-emphasize successful experiences, leaving lessons from an agent's failures largely unutilized. Consequently, many current memory designs function as passive record-keeping systems rather than sources of actionable, generalizable guidance.

Concurrently, Test-Time Scaling (TTS) has emerged as a strategy to enhance the performance of LLM agents in problem-solving tasks like coding and mathematical reasoning. Methods such as best-of-N sampling, beam search, and verifiers are employed to allocate additional computational resources at inference time. However, the application of TTS to multi-turn interactive agent tasks, especially concerning the role of agent memory in this scaling, has remained less explored. Existing works in agentic TTS have focused on scaling aspects like search space, the number of agents, or interactions with the environment, without explicitly integrating memory mechanisms.

This research addresses these gaps by proposing ReasoningBank, a memory framework designed to distill generalizable reasoning strategies from an agent’s self-judged successful *and* failed experiences. It then integrates this robust memory with a novel memory-aware test-time scaling (MaTTS) approach. This integration aims to establish a synergistic relationship where memory guides the scaling process and the scaled experience, in turn, enhances memory quality, thereby introducing memory-driven experience scaling as a new dimension for agent development.

### 2. Key Objectives and Motivation

The primary motivation for this work is to overcome a fundamental limitation in current LLM agents: their failure to effectively learn from their accumulated interaction history when deployed in persistent, real-world roles. This leads to inefficient operation characterized by repetitive errors, the discarding of valuable insights, and a lack of mechanisms for continuous self-evolution.

The research pursued two key objectives:

1. **To develop a novel memory framework called ReasoningBank that distills and organizes generalizable reasoning strategies.**
 - **Motivation:** Existing agent memory systems are often limited to storing raw interaction trajectories or merely successful operational routines. This approach lacks the capacity to extract higher-level, transferable reasoning patterns that could generalize across tasks. Furthermore, prior work tends to neglect the valuable lessons that can be derived from an agent's failures, focusing predominantly on successes. ReasoningBank aims to bridge this gap by creating structured memory items from both successful and failed experiences, offering more comprehensive and actionable guidance for future decisions. The self-judged nature of these experiences, without relying on external ground-truth labels, is crucial for continuous self-improvement in dynamic environments.

2. **To introduce Memory-aware Test-Time Scaling (MaTTS), which synergizes memory and test-time scaling to accelerate and diversify the learning process.**
 - **Motivation:** While test-time scaling (allocating more compute during inference) has shown promise in boosting LLM performance in other domains, its application to multi-turn interactive agents, particularly in conjunction with a learning memory mechanism, is underexplored. The direct application of conventional test-time scaling might generate abundant but potentially redundant experiences without optimized learning signals. MaTTS is motivated by the hypothesis that a high-quality, reasoning-focused memory can guide scaled exploration more effectively, leading to diverse and high-contrast experiences. These richer experiences, in turn, can be used to synthesize even higher-quality memory, creating a positive feedback loop. This objective aims to establish memory-driven experience scaling as a new and effective dimension for enhancing agent capabilities.

Through these objectives, the research endeavors to enable LLM agents to become more capable over time, fostering continuous self-evolution and the emergence of increasingly complex behaviors.

### 3. Methodology and Approach

The methodology centers on two core components: ReasoningBank, a memory framework, and MaTTS, a memory-aware test-time scaling approach.

#### 3.1. Problem Formulation

The study focuses on LLM-based agents, where the agent's policy ($\pi_L$) is conditioned on a backbone LLM (L), a memory module (M), and an action space (A). Agents perform tasks by interacting sequentially with an environment, characterized by state transitions. The action space (A) comprises web navigation operations for web browsing tasks and bash commands for software engineering tasks. The memory module (M), ReasoningBank, is initially empty and populated over time. The agent generates a trajectory of observations and actions for each task.

The work operates under a test-time learning paradigm, where tasks arrive sequentially, and agents must complete each task without foreknowledge of future tasks or external ground-truth feedback during testing. This necessitates continuous self-evolution, posing challenges in extracting, preserving, and leveraging useful memory to avoid repeating errors or redundant discoveries.

#### 3.2. ReasoningBank

ReasoningBank distills past experiences into structured, transferrable knowledge units called memory items, designed to abstract low-level execution details while preserving generalizable reasoning patterns.

- **Memory Schema**: Each memory item consists of three components:
 - **Title**: A concise summary of the core strategy or reasoning pattern.
 - **Description**: A brief, one-sentence summary of the item.
 - **Content**: Detailed reasoning steps, decision rationales, or operational insights extracted from past experiences.
 These items are designed to be both human-interpretable and machine-usable.

- **Integrating ReasoningBank with Agents (Closed-Loop Process)**: The integration involves three steps:
 1. **Memory Retrieval**: For a new task, the agent queries ReasoningBank to identify the top-𝑘 most relevant memory items. This is achieved using embedding-based similarity search (e.g., Gemini-embedding-001 with cosine distance) on the current query context. The retrieved items are then injected into the agent's system instruction, providing actionable guidance for decision-making.
 2. **Memory Extraction**: After a task is completed, its corresponding trajectory is analyzed to generate new memory items.
 - **Proxy Correctness Signals**: An LLM-as-a-judge (using the same backbone LLM as the agent, with temperature 0.0 for determinism) provides binary signals (success or failure) for each trajectory based on the query, trajectory, final state, and agent response, without relying on ground-truth labels.
 - **Differentiated Extraction**: Distinct prompts guide the extraction process. For successful trajectories, the extractor focuses on synthesizing validated strategies. For failed trajectories, it identifies counterfactual pitfalls and preventative lessons. Up to three concise, non-redundant, and generalizable memory items are extracted per trajectory.
 3. **Memory Consolidation**: The newly extracted memory items are directly appended to the ReasoningBank memory pool. The consolidation strategy is kept minimal (simple addition) to isolate the contribution of ReasoningBank's content, though advanced mechanisms like merging or forgetting are acknowledged as future possibilities. The memory pool is maintained in JSON format, storing task query, trajectory, and memory items, with pre-computed embeddings for efficient retrieval.

#### 3.3. MaTTS: Memory-aware Test-Time Scaling

MaTTS extends ReasoningBank by generating diverse exploration to provide rich contrastive signals for synthesizing higher-quality memory, thereby establishing a synergy between memory and test-time scaling. It aims to overcome the limitations of vanilla test-time scaling, which independently converts more trajectories into memory items without leveraging contrastive signals from redundant explorations. The scaling factor 𝑘 denotes the number of trajectories for parallel scaling or refinement steps for sequential scaling.

- **Parallel Scaling**:
 - Multiple trajectories (up to 𝑘) are generated for the same query under the guidance of retrieved memory items.
 - A "self-contrast" mechanism is employed, where the agent compares and contrasts these diverse trajectories to identify consistent successful reasoning patterns and filter spurious solutions. This process curates more reliable memory.
 - For evaluation, a separate LLM selects the "best" trajectory from the 𝑘 candidates based on criteria such as progress, efficiency, loop detection, and error severity (Best-of-N).

- **Sequential Scaling**:
 - The agent iteratively refines its reasoning within a *single* trajectory after its initial completion, following a "self-refinement" principle.
 - Intermediate notes, capturing reasoning attempts, corrections, and insights during the refinement process, are used as valuable signals for memory extraction.
 Both parallel and sequential strategies are memory-aware, ensuring that additional computation allocated at test time translates into more transferable and higher-quality memory.

### 4. Main Findings and Results

The experiments were conducted on WebArena (general web navigation), Mind2Web (generalization across tasks, websites, domains), and SWE-Bench-Verified (software engineering issue resolution) benchmarks, using Gemini-2.5-Flash, Gemini-2.5-Pro, and Claude-3.7-Sonnet as backbone LLMs. Baselines included memory-free agents, Synapse (trajectory-based memory), and AWM (workflow-based memory). Evaluation metrics focused on success rate (SR) for effectiveness and average steps (AS) for efficiency.

#### 4.1. ReasoningBank Performance

- **Consistent Outperformance**: ReasoningBank consistently exceeded the performance of baseline methods across all tested LLM backbones and datasets. On WebArena, it improved the overall success rate by +8.3, +7.2, and +4.6 percentage points (relative to memory-free agents) depending on the LLM. Similar gains were observed on Mind2Web across cross-task, cross-website, and cross-domain settings, with the most significant improvements in the challenging cross-domain scenario. Performance on SWE-Bench-Verified also showed improved issue resolution rates.
- **Enhanced Generalization**: ReasoningBank demonstrated better transferrable memory. For instance, on the WebArena "Multi" subset (requiring memory transfer across multiple websites), ReasoningBank achieved a notable average SR gain of +4.6 over the strongest baseline, where AWM sometimes degraded. This indicates that its curated memory is more robust and capable of generalizing across diverse scenarios.
- **Superior Efficiency**: In addition to higher success rates, ReasoningBank reduced the average number of interaction steps required to complete tasks. On WebArena, it lowered step counts by up to 1.4 steps compared to "No Memory" and 1.6 steps compared to other memory baselines. On SWE-Bench-Verified, it saved 2.8 and 1.3 steps respectively. This suggests that ReasoningBank enables agents to solve tasks more efficiently by leveraging refined reasoning knowledge, thereby reducing redundant exploration.

#### 4.2. MaTTS Results

- **Performance Boost from Scaling**: Both parallel and sequential MaTTS strategies improved performance (success rate) as the scaling factor (𝑘) increased, affirming the benefit of allocating more inference-time computation. For instance, on WebArena-Shopping, parallel scaling with MaTTS grew from 49.7% (𝑘=1) to 55.1% (𝑘=5), and sequential scaling from 49.7% to 54.5%.
- **MaTTS vs. Vanilla Test-Time Scaling**: MaTTS consistently outperformed "MaTTS w/o aggregation" (vanilla TTS), which converts multiple trajectories to memory items independently. At 𝑘=5, MaTTS achieved 55.1% in parallel scaling versus 52.4% for vanilla TTS, and 54.5% versus 51.9% in sequential scaling. This suggests that memory-aware coordination and aggregation within MaTTS are critical for effective scaling.
- **Scaling Strategy Comparison**: With ReasoningBank, sequential scaling provided higher gains at smaller 𝑘 but saturated quickly. Parallel scaling, however, continued to provide diverse rollouts, allowing for internal critique and improvement, eventually surpassing sequential scaling at larger 𝑘 (e.g., 55.1% vs. 54.5% at 𝑘=5). For vanilla TTS (without memory-aware aggregation), sequential scaling yielded minimal benefit, and parallel scaling consistently dominated.

#### 4.3. Synergy of Memory and Test-Time Scaling

A bidirectional synergy between memory and TTS was observed:

- **Better Memory Enables Stronger TTS**: The benefit of scaling (measured by Best-of-N, selecting the best outcome among multiple rollouts) was contingent on the underlying memory mechanism. Without memory, scaling yielded minor improvements (39.0% to 42.2% SR). Weaker memory mechanisms provided moderate gains, while MaTTS with ReasoningBank delivered the most significant increase (49.7% to 55.1% SR). This indicates that high-quality memory guides scaling towards more promising rollouts.
- **Scaling Yields Better Memory Curation**: When measuring the average quality of individual trajectories after memory curation (Pass@1), scaling *decreased* or provided only marginal benefits for weaker memories. In contrast, ReasoningBank's Pass@1 rose from 49.7% to 53.0%. This asymmetry highlights that scaling, when paired with an effective memory mechanism like ReasoningBank, contributes to the curation of higher-quality, more effective memory, completing a virtuous learning cycle.

#### 4.4. Additional Analyses

- **Emergent Behaviors**: ReasoningBank fostered emergent strategies in agents. Case studies showed memory items evolving from basic procedural actions to adaptive self-reflection, then to generalized and eventually compositional strategies, reflecting a progression from low-level actions to high-level reasoning.
- **Learning from Failures**: ReasoningBank effectively utilized failure trajectories. While baselines showed limited or even degraded performance when failures were included in memory induction, ReasoningBank improved from 46.5% (success-only) to 49.7% (with failures). This demonstrates its ability to transform failures into constructive learning signals.
- **Robustness to LLM-as-a-Judge**: The framework exhibited robustness to the accuracy of the LLM-as-a-judge (used for self-evaluation). Performance remained consistent within a reasonable accuracy range (70%-90%), with ground-truth accuracy yielding the highest performance.
- **Targeted Efficiency Gains**: ReasoningBank's efficiency gains were particularly pronounced in successful cases, reducing steps by up to 2.1 (26.9% relative reduction) more than in failed cases. This indicates that memory guides the agent toward efficient, successful paths rather than merely truncating failed attempts.
- **Inference Cost**: ReasoningBank incurred only a 4.3% increase in total token consumption compared to a "No Memory" baseline, while delivering a 20.5% performance boost. This suggests cost-effectiveness relative to other memory baselines, which showed higher computational overheads for smaller gains.
- **Generalizability to Smaller LLMs**: The benefits of ReasoningBank extended to smaller open-source models like Gemma-3-12B-Instruct on WebArena-Shopping, improving SR from 17.1% to 24.1% and reducing average steps.

### 5. Significance and Potential Impact

This research introduces ReasoningBank and MaTTS, proposing memory-driven experience scaling as a novel dimension for advancing large language model agents. The findings suggest a practical pathway toward building adaptive and lifelong-learning agents capable of continuous self-evolution.

The work's primary significance lies in shifting agent memory mechanisms from passive record-keeping to active, generalizable reasoning guidance. By distilling transferable strategies from both successful and failed experiences, ReasoningBank enables agents to learn more comprehensively and robustly, overcoming limitations of prior memory systems that focused narrowly on successes or raw data. This approach has the potential to make agents more intelligent by allowing them to internalize lessons and prevent repeating past errors.

The demonstrated synergy between memory and test-time scaling is a notable contribution. It indicates that these two dimensions are not merely additive but enhance each other bidirectionally. High-quality memory from ReasoningBank guides scaled exploration toward more productive paths, while the diverse experiences generated through scaling, in turn, enrich and refine the memory. This synergistic loop can lead to greater and more sustained performance improvements in effectiveness, efficiency, and generalization across diverse tasks, including complex web browsing and software engineering.

The emergent behaviors observed, where strategies evolve from basic actions to complex compositional reasoning, suggest that ReasoningBank fosters a form of genuine learning and adaptation in agents. This capability is crucial for deploying LLM agents in dynamic, open-ended environments where continuous learning and adaptation are necessary.

Potential impacts include:
- **More Capable Agents**: Enabling agents to tackle more complex, long-horizon tasks with higher success rates and greater efficiency.
- **Reduced Development Cycles**: By facilitating self-evolution, agents may require less human intervention or retraining over time.
- **Broader Applications**: Expanding the feasible applications of LLM agents in critical domains that demand robust, adaptive, and continuously improving autonomous systems.
- **Foundation for Future Research**: The work opens new avenues for research into modular and compositional memory architectures, advanced memory management policies, and integration with stronger verification mechanisms.
