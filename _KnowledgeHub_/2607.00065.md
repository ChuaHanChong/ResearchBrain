# Optimal any-angle path planning in static and dynamic environments

> [!summary] Summary
> Researchers at Delft University of Technology developed a framework using elliptical forward expansion and field of view for optimal any-angle path planning in both static and dynamic environments. Their Zeta* algorithm achieved performance comparable to state-of-the-art Anya in static settings, while Zeta*-SIPP provided a significant 20-fold speedup over TO-AA-SIPP for dynamic obstacles, consistently finding optimal and conflict-free paths.

## Problem

- Traditional graph-based path planning algorithms like A* on grids produce suboptimal 'zig-zag' paths and do not guarantee true shortest paths in continuous space.
- Existing optimal any-angle planners are often specialized for static environments, using complex node representations that limit their extensibility to dynamic or 3D scenarios.
- Optimal any-angle path planning in dynamic environments is computationally intensive, making real-time application challenging for prior state-of-the-art methods like TO-AA-SIPP.

## Method

- Introduced two general techniques: ==Elliptical Forward Expansion== to prune the search space and ==Field of View (symmetric shadowcasting)== for efficient visibility checks between non-adjacent vertices.
- Developed **Zeta\*** for static environments, which integrates these techniques into an A*-like search, focusing on ==taut paths== and obstacle corners while retaining point-based search nodes for extensibility.
- Extended the approach to **Zeta\*-SIPP** for dynamic environments, combining the core techniques with ==Safe Interval Path Planning (SIPP)== and ==inverted expansion== for efficient conflict detection and resolution.

## Results

- Zeta* (forward scanning variant) achieved performance comparable to the state-of-the-art Anya algorithm in static environments, consistently finding optimal paths and demonstrating an average **10-fold** speedup over Theta*.
- Zeta*-SIPP (forward scanning variant) delivered an average **24-fold** speedup over the prior state-of-the-art TO-AA-SIPP in dynamic environments, while maintaining time-optimal and conflict-free paths.
- The proposed framework offers a unified, optimal any-angle path planning approach applicable to both static and dynamic grid-based environments, significantly improving computational feasibility for optimal solutions.

## Takeaways

> [!tip] Key Insights
> - Combining elliptical search space pruning with efficient field-of-view visibility checks provides an effective method for accelerating optimal any-angle pathfinding.
> - Decoupling visibility calculations from node expansion, particularly through forward scanning, leads to more efficient search in optimal any-angle planners.
> - Retaining point-based search nodes in optimal any-angle algorithms (unlike specialized node representations) enhances their extensibility to complex scenarios like 3D or non-uniform costmaps.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Path planning is a fundamental problem in various fields, including aerospace, robotics, and logistics. Traditional graph-based algorithms, such as A*, are often limited by predefined graph structures, leading to paths that are not the true shortest in continuous space. Specifically, on regular grids, A* typically restricts movement to 45-degree increments, resulting in "zig-zag" patterns. While post-hoc smoothing can be applied, it does not guarantee optimality.

Any-angle path planning addresses this limitation by allowing movement between any pair of visible vertices, effectively integrating path smoothing directly into the search process. Early any-angle algorithms, like Theta*, improve path straightness and length but do not consistently guarantee true shortest paths. The development of optimal any-angle planners, such as Anya, represented a advancement for static environments by restricting the search to taut paths (paths whose turns occur only at obstacle corners). However, algorithms like Anya, with their specialized search node representations, face challenges in extensibility to more complex scenarios, such as 3D environments or those with dynamic obstacles. Non-grid-based Euclidean Shortest Path Problem (ESPP) solvers (e.g., RayScan, R2, EPS) also exist but are primarily tailored for static environments.

For dynamic environments, the challenge of optimal any-angle path planning is more pronounced. Few algorithms are capable of handling moving obstacles while maintaining optimality. Any-Angle Safe Interval Path Planning (AA-SIPP) and Time-Optimal AA-SIPP (TO-AA-SIPP) are notable grid-based examples, with TO-AA-SIPP being a state-of-the-art optimal planner. However, these methods, particularly TO-AA-SIPP, can be computationally intensive.

This research aims to bridge the gap by introducing general techniques that facilitate optimal any-angle path planning on grids in both static and dynamic settings. It seeks to provide a unified approach that is scalable and more readily extensible than existing specialized optimal algorithms, addressing the computational efficiency limitations observed in optimal dynamic environment planners.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop and validate general computational techniques for optimal any-angle path planning that are efficient in both static and dynamic environments while preserving path optimality.

Specific objectives include:
- **Accelerating Computation:** Introduce methods to reduce the computational cost of optimal any-angle path planning.
- **Maintaining Optimality:** Ensure that the developed techniques consistently yield true shortest paths in static environments and time-optimal conflict-free paths in dynamic environments.
- **Generalizability and Extensibility:** Design techniques that can be applied across different environmental settings and extended to more complex scenarios (e.g., 3D or non-uniform costmaps), unlike some specialized existing algorithms.
- **Developing Zeta* for Static Environments:** Create an optimal any-angle path planner for static obstacles that retains point-based search nodes (similar to A* and Theta*), thereby enhancing extensibility, while achieving performance comparable to the state-of-the-art Anya algorithm.
- **Developing Zeta*-SIPP for Dynamic Environments:** Extend the principles of Zeta* to incorporate dynamic obstacles, building upon Safe Interval Path Planning (SIPP) and inverted expansion to improve computational efficiency over existing optimal dynamic planners like TO-AA-SIPP.
- **Unifying the Approach:** Present a cohesive framework that demonstrates how the proposed techniques can be adapted for both static and dynamic planning problems.

The motivation for these objectives stems from several factors:
- The inherent limitations of traditional graph-based path planning in continuous spaces, necessitating any-angle solutions for straighter and shorter paths.
- The difficulty in extending specialized optimal any-angle planners (e.g., Anya) to varied environments due to their complex search node representations.
- The computational expense of existing optimal any-angle planners for dynamic environments (e.g., TO-AA-SIPP), which can hinder their practical application in real-time scenarios.
- The wide applicability of grid representations in real-world path planning across domains such as air traffic management, warehouse logistics, and autonomous navigation, where both static and dynamic obstacles are common.

### 3. Methodology and Approach

The research introduces two general techniques and two integration methods, which form the basis for the Zeta* and Zeta*-SIPP algorithms.

#### 3.1. Core Techniques

1. **Elliptical Forward Expansion:** This technique leverages the geometric property of ellipses to restrict the search space. The start and target points are defined as the foci of an ellipse. The major axis length (L) of this ellipse is continuously updated based on the minimum f-value (g + h) in the open list. This ensures that only nodes within the expanding elliptical boundary, which have a potential to lead to an optimal path, are considered for expansion. This approach aims to prune unnecessary nodes that are far from the direct line between the start and target, thereby accelerating the search while preserving optimality.
2. **Field of View (FoV):** To enhance the efficiency of visibility checks between non-adjacent vertices, the research proposes using a field-of-view approach, specifically symmetric shadowcasting, instead of traditional line-of-sight (LoS) methods. Shadowcasting efficiently determines all visible cells from a "light source" (a given node) by processing grid cells radially and narrowing/splitting slope ranges upon encountering obstacles. This ensures that each cell within the view is scanned once per light source, reducing redundant computations common in iterative LoS checks for large neighborhoods.

#### 3.2. Integration Methods

1. **Inverted Scanning:** In this method, newly added *open* nodes are treated as "light sources." When an open node is processed, shadowcasting is performed from it to identify other visible nodes within the elliptical boundary. Connections are recorded, allowing the system to identify potential parent-child relationships. A buffer is applied around the elliptical boundary to mitigate grid aliasing issues where unseen areas might be mistakenly treated as obstacles.
2. **Forward Scanning:** This method treats *closed* nodes as "light sources." Shadowcasting is initiated from a closed node to identify visible *open* nodes. An incremental version of shadowcasting is employed to avoid repeatedly scanning already connected nodes as the elliptical search range expands. A "cost-bounded" variant further refines the scan by limiting its depth using a local ellipse, where the foci are the current closed node and the target node, and the major axis length is derived from the minimum f-value in the open list minus the g-value of the closed node.

#### 3.3. Algorithm Development

- **Zeta* (for Static Environments):** This algorithm integrates elliptical forward expansion and field of view into an A*-like search framework. To optimize performance in static environments, Zeta* restricts its search space to obstacle corners and taut paths, similar to Anya.
 - **Zeta*-i (Inverted Scanning):** Utilizes inverted scanning. It employs a `bound` list to manage nodes along the expanding elliptical boundary, deferring their insertion into the `open` list until their `f_low` value is below the `min f` in `open`. Visible connections (`children(n)`) are recorded.
 - **Zeta*-f (Forward Scanning):** Employs forward scanning. It uses a `scan` list to manage incremental shadowcasting ranges. This approach allows for more aggressive scan range pruning by exploiting the known parent of a closed node, focusing the scan in relevant directions.
 - Both variants include a `updateParent` function that incorporates a path tautness check. The algorithms are proven to be complete and optimal.

- **Zeta*-SIPP (for Dynamic Environments):** This algorithm extends Zeta* to handle dynamic obstacles by integrating with Safe Interval Path Planning (SIPP) and inverted expansion. For dynamic environments, search nodes are typically center-based, and taut-path constraints are not applicable.
 - **Safe Interval Conflict Detection and Resolution (SI-CDR):** This component is responsible for checking visibility and resolving conflicts along paths between nodes in space-time, considering predefined trajectories of dynamic obstacles.
 - **Inverted Expansion:** Rather than immediately calculating the real cost (g-value) and parent of a newly expanded node, inverted expansion stores potential parents and estimates costs using heuristics. The full SI-CDR calculation is only performed for the node with the minimum f-value when it is considered for closing, reducing the number of expensive SI-CDR operations.
 - **Inverted Expansion Pruning:** Potential parent connections are pruned if they cannot reach a child node within its safe time interval `[t1, t2]`, further optimizing the search.
 - **Zeta*-SIPP-i and Zeta*-SIPP-f:** Apply inverted and forward scanning within this SIPP-based framework. The core `findNextClosedNode` and `nodeExpansion` functions are adapted from TO-AA-SIPP and augmented with the proposed techniques.
 - The algorithms are proven to be complete and optimal.

The algorithms were implemented in JavaScript on Node.js. Experiments utilized various benchmark maps from the Moving AI Lab, including game maps, city maps, maze maps, random maps, and room maps, with varying numbers of dynamic obstacles for dynamic environment evaluations.

### 4. Main Findings and Results

The experimental evaluation was conducted on two sets of scenarios: static and dynamic environments.

**Static Environments (Zeta*):**
- **Runtime Performance:**
 - A* with increasing k (neighborhood size) exhibited increased runtime, primarily due to more intensive visibility checks rather than more sorted elements.
 - Theta* performed comparably to A*-16 despite scanning a larger number of vertices, likely due to the relative efficiency of line-of-sight checks per grid cell versus shadowcasting.
 - Anya demonstrated superior performance on most maps (except random maps), attributed to its taut-path search and implicit field-of-view nodes.
 - Zeta*-f (forward scanning) achieved performance comparable to Anya, being approximately 10 times faster than Theta* on average. This indicated that decoupling visibility checks from node expansion, while maintaining point-based search nodes, can be effective.
 - Zeta*-i (inverted scanning) was significantly slower than Zeta*-f, largely due to less effective scan range pruning, resulting in a higher number of scanned vertices.
- **Path Quality:** Anya, Zeta*-f, and Zeta*-i consistently found optimal paths. Theta* generated paths that were marginally longer than the true shortest paths.

**Dynamic Environments (Zeta*-SIPP):**
- **Runtime Performance:**
 - All algorithms, especially optimal planners, showed increased runtime with a higher number of dynamic obstacles.
 - SIPP-16, a suboptimal variant, demonstrated competitive performance with AA-SIPP on larger-scale maps.
 - TO-AA-SIPP, the prior state-of-the-art optimal planner, was substantially slower than other optimal planners. This was attributed to its exhaustive visibility checks to all nodes and its reliance on line-of-sight rather than field-of-view scanning.
 - TO-AA-FoV-SIPP, an extension of TO-AA-SIPP with field of view, significantly reduced scanned grids and improved performance.
 - Zeta*-SIPP-f achieved an average speedup of approximately 24-fold over TO-AA-SIPP. Zeta*-SIPP-i achieved about a 21-fold speedup.
 - In environments with narrow passages (e.g., Room and Maze maps), TO-AA-FoV-SIPP occasionally outperformed Zeta*-SIPP variants. This was attributed to the overhead of elliptical forward expansion in highly constrained spaces, where the elliptical search range frequently expands to touch obstacles, leading to similar node expansions but additional computational steps.
 - Zeta*-SIPP-f was generally faster and more memory-efficient than Zeta*-SIPP-i.
- **Sorted Elements and Scanned Grids:** Zeta*-SIPP-f generally reduced the number of scanned grids compared to TO-AA-FoV-SIPP, but sometimes resulted in a higher number of sorted elements (scan list size). Path time optimality was maintained across all optimal planners.

**Overall Findings:** The research demonstrated that elliptical forward expansion and field of view, when integrated appropriately, provide an effective framework for optimal any-angle path planning. Zeta*-f showed comparable performance to Anya in static environments and Zeta*-SIPP-f achieved significant speedups over TO-AA-SIPP in dynamic environments, making optimal solutions more computationally feasible.

### 5. Significance and Potential Impact

This research introduces a generalized approach to optimal any-angle path planning that is applicable across both static and dynamic environments, addressing a challenge identified with existing specialized optimal algorithms.

The significance and potential impact of this work include:
- **Unified Framework for Optimal Planning:** The proposed techniques (elliptical forward expansion and field of view) and their integration via inverted/forward scanning offer a cohesive methodological framework for optimal any-angle path planning. This is particularly relevant as many existing optimal algorithms are tailored for specific scenarios (e.g., static environments) and lack generalizability.
- **Enhanced Computational Efficiency:** The Zeta*-SIPP algorithm provides substantial speed improvements (over 20 times faster) compared to the prior state-of-the-art optimal planner, TO-AA-SIPP, for dynamic environments. This makes optimal any-angle path planning in the presence of dynamic obstacles more practical for real-world applications where real-time performance is a consideration.
- **Improved Extensibility:** By retaining point-based search nodes, Zeta* is designed to be more easily extensible to complex settings such as weighted terrains, 3D environments, and varying agent dynamics. This contrasts with algorithms like Anya, which use more complex search node representations that can hinder adaptation to new problem variants.
- **Deeper Understanding of Optimal Path Planning:** The research contributes to the theoretical understanding of optimal any-angle path planning by offering new mechanisms for search space pruning and visibility checks while ensuring optimality guarantees.
- **Broad Applicability:** The techniques are applicable to general grid-based path planning. Zeta* is suitable for optimal pathfinding in static maps where taut paths are important (e.g., in game AI or autonomous navigation in structured environments). Zeta*-SIPP is recommended for scenarios requiring optimal, conflict-free paths in dynamic environments, such as air traffic control, multi-robot coordination, and logistics. It also holds potential as a low-level planner for optimal any-angle Multi-Agent Path Finding (MAPF).

Future research could explore extending these techniques to non-uniform costmaps and 3D scenarios, further broadening their applicability and contributing to advancements in path planning research.
