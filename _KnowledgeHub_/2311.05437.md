# LLaVA-Plus: Learning to Use Tools for Creating Multimodal Agents

> [!summary] Summary
> LLaVA-Plus, developed by researchers from Tsinghua University and Microsoft Research, introduces an approach that trains a Large Multimodal Model (LMM) to intelligently leverage external vision and vision-language tools from a skill repository. It establishes new state-of-the-art performance on benchmarks like VisiT-Bench and LLaVA-Bench (Tools), demonstrating improved visual understanding, content generation, and interactive capabilities.

## Problem

- End-to-end Large Multimodal Models (LMMs) struggle to seamlessly integrate a wide range of specialized vision and vision-language skills like precise segmentation or advanced image generation.
- Existing tool-chaining methods, while flexible, heavily rely on brittle prompt engineering for tool selection and composition, lacking robustness and adaptability in dynamic real-world scenarios.
- Prior tool-augmented LLMs often lose active visual grounding during the interaction, only engaging the image when a specific multimodal tool is activated, which limits their planning and reasoning.

## Method

- Extends existing LMMs (like LLaVA) by training them with ==visual instruction tuning== to act as planners that leverage a diverse ==skill repository== of specialized vision models.
- Implements a ==four-step dialogue flow== (Human Input, LMM Planning, Tool Execution, LMM Aggregation & Response) where the LMM continuously considers the raw image query while planning tool usage.
- Constructs a novel, comprehensive ==multimodal instruction-following dataset== for tool use via a self-instruct method, using GPT-4 to generate diverse human-AI interaction sessions and skill composition scenarios.

## Results

- LLaVA-Plus variants consistently outperform LLaVA on LLaVA-Bench, SEED-Bench (e.g., LLaVA-Plus (All Tools) achieves **83.9** on LLaVA-Bench COCO vs. LLaVA's **81.2**), and MMVet, demonstrating improved existing capabilities, especially in OCR and spatial categories.
- Achieves a new State-of-the-Art Elo rating of **1203** on VisiT-Bench, surpassing LLaVA (**1095**) and other leading methods, showcasing its practical effectiveness in real-world use cases.
- Exhibits emergent capabilities such as precise object detection and contextual reasoning, semantic segmentation with mask-based conditional image generation, and multimodal social media post creation, while also reducing false positives from individual tools like Grounding DINO (from **90** to **20** instances in a test set).

## Takeaways

> [!tip] Key Insights
> - An end-to-end trained Large Multimodal Model (LMM) can effectively learn to select, activate, and compose diverse external tools, offering greater robustness and adaptability than prompt-engineered methods.
> - Maintaining active visual grounding throughout the entire human-AI interaction significantly improves the LMM's ability to understand complex visual instructions and generate coherent, visually grounded responses.
> - A high-quality, large-scale multimodal instruction-following dataset, particularly curated with advanced LLMs like GPT-4, is critical for teaching LMMs to intelligently utilize external tools.
