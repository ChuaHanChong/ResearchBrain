# ViperGPT: Visual Inference via Python Execution for Reasoning

> [!summary] Summary
> ViperGPT, developed by researchers at Columbia University, enables visual reasoning by having a large language model generate Python programs that orchestrate calls to specialized vision and language modules. The system achieves state-of-the-art zero-shot performance across various visual reasoning benchmarks, including compositional image Q&A and knowledge-dependent Q&A.

## Problem

- End-to-end deep learning models for visual reasoning often lack interpretability and provide opaque decision-making processes.
- These models struggle with systematic generalization to novel compositions and complex multi-step reasoning tasks.
- Training specialized models for every unique visual task or adapting them to new capabilities can be inflexible and resource-intensive.

## Method

- ViperGPT utilizes a large language model (Codex) to ==generate Python programs== from natural language queries that solve visual reasoning tasks.
- The generated code orchestrates a set of predefined, specialized ==vision and language API modules== (e.g., object detection, depth estimation, property verification) that act as building blocks.
- A ==Python interpreter== executes the generated program on visual inputs, enabling complex reasoning through control flow, mathematical operations, and logical conditions.

## Results

- Achieves **state-of-the-art zero-shot accuracy** on compositional image question answering (GQA) and knowledge-dependent question answering (OK-VQA) benchmarks.
- Outperforms other zero-shot methods in visual grounding tasks (RefCOCO/RefCOCO+).
- Performs comparably to supervised models on video reasoning tasks (NExT-QA) despite not being specifically trained for video processing.

## Takeaways

> [!tip] Key Insights
> - Leveraging large language models' code generation capabilities allows for explicit, interpretable reasoning steps in visual tasks.
> - Decomposing complex visual queries into sub-problems solvable by modular, pre-trained vision components enhances flexibility and adaptability.
> - Using Python's native programming constructs (control flow, loops, conditionals) provides a robust framework for implementing multi-step and conditional visual reasoning.
