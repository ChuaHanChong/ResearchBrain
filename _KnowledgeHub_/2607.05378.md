# CompactionRL: Reinforcement Learning with Context Compaction for Long-Horizon Agents

> [!summary] Summary
> CompactionRL is a PPO-based reinforcement learning framework that trains long-horizon agentic LLMs with trainable context compaction: when context runs low, the policy summarizes its history and resumes from that summary, and both execution and summary tokens are optimized under one shared task reward using token-level loss normalization and cross-trajectory GAE. It lifts GLM-4.5-Air to 66.8% on SWE-bench Verified and 24.5% on Terminal-Bench 2.0.

## Problem

- Long-horizon agent trajectories exhaust finite context windows before task completion, and merely scaling context length is costly and degrades effective utilization over long sequences.
- Prior compaction, memory and reflection work treats summarization as an inference-time heuristic or external module, so summary quality is never optimized against task outcome.
- Group-relative RL like GRPO assumes fixed-size groups of whole rollouts, which breaks when compaction splits a rollout into a variable number of reward-sharing segments.

## Method

- **Trainable context compaction** during rollout: when remaining budget falls below a threshold, the policy itself samples a summary, then resumes from a template context holding that summary plus the last k steps.
- Joint ==PPO== optimization with a critic over both execution and summarization segments under one shared trajectory reward, replacing ==group-relative== baselines and needing no hand-designed summary-quality reward.
- **Token-level loss normalization** to remove segment-count and length weighting bias, plus **cross-trajectory GAE** that discounts each segment's local advantage by the optimized tokens generated after it.

## Results

- Under compacted evaluation, it adds **7.0** points on SWE-bench Verified (**66.8%**) and **3.1** on Terminal-Bench 2.0 (**24.5%**) for GLM-4.5-Air; **5.5** and **6.8** points for GLM-4.7-Flash.
- Ablations: dropping token-level loss falls from **66.8** to **60.0** on SWE-bench Verified, dropping cross-trajectory GAE to **63.0**; masking summary loss gives **64.5** versus **66.8**.
- Swapping only the summarizer while fixing the executor moves SWE-bench Verified accuracy from **49.0** to **55.5**, and trained compaction cuts tool calls per trace from **83.4** to **60.7**.

## Takeaways

> [!tip] Key Insights
> - When a summary replaces history, summarization becomes a performance-critical policy decision, not preprocessing, and it should be trained with the same outcome reward as actions.
> - Segment-split rollouts make group-relative advantages ill-posed; a learned critic plus token-level normalization handles variable segment counts and lengths more soundly.
> - Compaction-aware training creates a train-test mismatch: gains appear only with compaction enabled and single-window performance can regress below the base model.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of large language model (LLM) agents has seen increasing application in complex, long-horizon interactive tasks such as software engineering, terminal-based problem-solving, and web interaction. These tasks often require agents to engage in multi-step processes involving reasoning, action, observation of environment feedback, and plan revision. A fundamental challenge in this domain is the finite context window of LLMs. As interaction trajectories lengthen, the accumulated history—comprising tool outputs, intermediate reasoning, error messages, and partial solutions—can quickly exceed the maximum context length an LLM can process. While advancements in model architecture have led to longer context windows, these solutions are often computationally expensive and do not fundamentally resolve the issue of degraded information utilization over very long sequences.

Existing approaches to mitigate this limitation include developing models with inherently longer context capabilities, applying prompt or observation compression techniques, and integrating explicit memory or reflection mechanisms into agent systems. However, these methods often treat context management as an inference-time heuristic or an external module. The integration of context compaction directly into the reinforcement learning (RL) training pipeline for LLM agents, where the compaction policy itself is learned and optimized alongside task execution, remains a relatively underexplored area.

Current RL pipelines for LLM agents, such as those employing Proximal Policy Optimization (PPO) or group-wise methods like GRPO, typically assume complete rollouts or fixed-context representations. These assumptions are challenged by context compaction, which can split a single rollout into multiple segments of variable lengths, making standard group normalization and temporal credit assignment problematic. This paper addresses this gap by proposing an RL framework designed to jointly optimize both task execution and the generation of context summaries, treating compaction as an integral, learned component of the agent's behavior rather than a static preprocessing step. This work builds upon the idea that the quality of compaction directly influences an agent's ability to maintain task-relevant state over extended horizons, thus warranting its inclusion in the training objective.

### 2. Key Objectives and Motivation

The core objective of this research is to develop a reinforcement learning strategy that enables long-horizon agentic LLMs to effectively operate under fixed context window constraints by incorporating trainable context compaction. The specific motivations and objectives are detailed as follows:

- **Addressing Context Window Limitations for Long-Horizon Agents:** The primary motivation stems from the inherent limitation of finite context windows in LLMs when deployed for tasks requiring extensive, multi-step interactions. As interaction histories grow, they inevitably exceed the maximum context length, forcing agents to either truncate crucial information or terminate early. This restricts the complexity and duration of tasks that LLM agents can reliably tackle.
- **Integrating Context Compaction into RL Training:** While context compaction (summarizing past interactions) offers a natural solution to context limits, existing work predominantly treats it as an inference-time heuristic or an external memory operation. The authors hypothesize that for compaction to be truly effective in long-horizon tasks, it must be an integral part of the learning process. The quality of a summary directly determines the information available for subsequent actions, making it a performance-critical component. Thus, a key objective is to incorporate compaction into the RL training loop such that the agent learns to generate effective summaries.
- **Joint Optimization of Task Execution and Summary Generation:** A central motivation is to jointly optimize the LLM agent's task execution actions and its summarization actions. This implies that the summarizer is not a separate, pre-trained module but rather a learned part of the overall policy, optimized under the same final task reward. This ensures that the summaries produced are tailored to facilitate successful task completion, rather than adhering to generic summarization metrics that might not capture task-specific utility.
- **Adapting RL Frameworks for Compacted Trajectories:** Existing RL methods are ill-suited for the structural changes introduced by context compaction. Compaction splits a single rollout into a variable number of segments, each with its own local context but sharing a single task-level reward. This poses challenges for:
 - **Loss Weighting:** Naive segment-level optimization could disproportionately weight rollouts with more compaction events.
 - **Temporal Credit Assignment:** Placing the shared terminal reward at the end of every segment in earlier parts of a compacted rollout can artificially shorten the perceived temporal distance to the final outcome, leading to distorted credit assignment.
 Therefore, a specific objective is to develop modifications to standard RL techniques (specifically PPO) that can correctly handle these segmented and variable-length trajectories, preserving proper credit assignment and loss weighting across compaction boundaries.
- **Extending Effective Training Horizon Without Increasing Physical Context Length:** The ultimate goal is to enable LLM agents to learn from and effectively tackle tasks that span horizons much longer than the model's physical context window, without incurring the computational costs associated with massively increased context lengths. By training the agent to compact its own history, the "effective" context horizon for learning is extended while the "working" context budget remains fixed.

In summary, the research is motivated by the need for LLM agents to scale to increasingly complex, long-horizon tasks, and aims to achieve this by making context compaction a learned, optimized component within an adapted RL framework.

### 3. Methodology and Approach

CompactionRL is presented as a PPO-based reinforcement learning framework designed to train long-horizon language agents with an integrated, trainable context compaction mechanism. The methodology focuses on making context compaction a core part of the rollout collection process and modifying the PPO objective to handle the resulting segmented trajectories.

#### 3.1. Trainable Context Compaction

The approach introduces context compaction directly into the agent's interaction loop during rollout collection:
- **Interaction History Representation:** The interaction history `h_t` is defined as a sequence of system prompts, user instructions, and assistant-observation pairs `z_i = (a_i, o_i)`.
- **Compaction Triggering:** Compaction is triggered when the remaining context budget (`C - |h_t|`) falls below a predefined threshold `T_comp` (e.g., 10,240 tokens). This ensures that a new summary is generated before the context window is exhausted.
- **Summary Generation:** Once triggered, a fixed summarization instruction (`q_sum`) is appended to the current history, and the policy itself samples a summary (`S_t`) from the model. The `q_sum` prompt guides the model to preserve crucial task-relevant information such as the original goal, completed actions, important observations, unresolved errors, current state, and plausible next steps.
- **Context Reconstruction:** Following summary generation, the rollout continues from a reconstructed context (`h_t`). This reconstructed context comprises the system prompt, a fixed template incorporating the generated summary (`u_resume(S_t)`), and the `k` most recent interaction steps (`z_{t-k+1}, ..., z_t`). The inclusion of recent steps ensures that immediate environmental state is precisely retained, while the summary provides long-range information. The default `k` is 2, adjusted if necessary to fit the context budget.
- **Training Segments:** A complete rollout, potentially involving multiple compaction events, is partitioned into a sequence of "training segments." Each segment is either an "execution segment" (tokens generated while solving the task) or a "summarization segment" (tokens forming the summary). Crucially, the summarizer is part of the trainable policy, meaning summary tokens are included in the RL objective.
- **Shared Task Reward:** All segments originating from the same complete rollout share the same final task reward `R(τ)`, determined by task correctness. No separate, hand-designed reward for summary quality is introduced, as the utility of a summary is directly tied to its contribution to task success.
- **Importance of Summarization Quality:** The paper experimentally demonstrates that the quality of the summary agent significantly impacts overall task performance, underscoring the need for trainable, rather than heuristic, compaction.

#### 3.2. Optimization under Compacted Rollouts

The paper identifies limitations of existing RL methods for handling compacted trajectories and introduces specific modifications:
- **Critique of Group-Wise Methods:** Methods like GRPO, which rely on grouping complete rollouts and normalizing advantages within the group, are deemed unsuitable. When rollouts are split by compaction, a group of `G` rollouts yields `ΣK_g` segments, where `K_g` is the number of segments in rollout `g`. If each segment is treated as an independent sample, rollouts with more compactions would be over-represented, distorting group statistics. If normalization is only at the complete-rollout level, it does not provide segment-level advantages.
- **PPO Adoption:** CompactionRL uses a PPO-based framework. PPO's value-function-based advantage estimation avoids reliance on fixed-size reward groups and inherently supports a variable number of compacted segments, including single-rollout scenarios.
- **Token-Level Loss for Length Imbalance:** To address the issue of variable segment lengths and counts introduced by compaction, the loss computation is performed at the token level, not the sequence level. The PPO clipped surrogate objective `J_CLIP(θ)` is averaged over the set `M` of all optimized assistant-token positions in a batch. This token-level normalization ensures that each trainable token receives equal weight, preventing bias from segments of different lengths or from rollouts with varying numbers of compaction events.
- **Cross-Trajectory Generalized Advantage Estimation (GAE):** To resolve the temporal credit-assignment problem across segment boundaries, a correction is applied to the standard GAE calculation. For a segment `σ_s` within a rollout, a local GAE estimator `A_loc_s,i` is computed for tokens `i` within that segment. This local advantage is then corrected by a factor `(γλ)^N_>s` to yield the final advantage estimate `b_A_s,i`. Here, `N_>s` represents the total number of optimized tokens generated *after* segment `σ_s` in the same rollout. This correction effectively discounts earlier segments based on their true temporal distance to the final outcome within the concatenated, compacted rollout, aligning the reward term's discount with its actual position in the full trajectory.

#### 3.3. Experimental Setup

- **Models:** Experiments utilized GLM-4.7-Flash (30B parameters) and GLM-4.5-Air-SFT (106B parameters), with critics initialized from the same checkpoints and value pretraining performed.
- **Training Data:** Open-source SWE-Dev data was used.
- **RL Framework:** Slime, an open-source asynchronous RL framework, was employed.
- **Hyperparameters:** A global batch size of 128, group size of 1, and context budgets of 64k (GLM-4.7-Flash) and 80k (GLM-4.5-Air-SFT) were used. Policy and critic learning rates were `2 × 10^-6` and `3 × 10^-6` respectively. Length-adaptive GAE with `λ = 1 - 1/(αl)` and `α = 1.5` was adopted. Two critic updates per policy update were performed. Max assistant response length was 10,240 tokens. Compaction triggered when remaining context fell below 10,240 tokens, with at most three compaction operations per rollout.
- **Evaluation:** Benchmarks included SWE-bench Verified (200 random instances) and Terminal-Bench 2.0 (full set). Pass@1 accuracy was the metric. Evaluations were conducted in the Harbor environment with the Terminus-KIRA agent scaffold, allowing up to 250 interaction turns and three compactions. Both "Single (×1)" evaluation (no compaction, one peak-length context) and "Compacted (×4)" evaluation (up to three compactions, effective 4× peak length) were performed.

### 4. Main Findings and Results

The research presents several findings regarding the effectiveness of CompactionRL and its components:

#### 4.1. Main Results on Long-Horizon Agentic Coding Tasks

Table 2 demonstrates that CompactionRL consistently outperforms baseline models and standard PPO (trained without compaction) when evaluated under the "Compacted (×4)" setting, which allows for multiple compaction operations.
- **GLM-4.7-Flash (30B-A3B):** CompactionRL achieved a Pass@1 score of 56.0% on SWE-bench Verified, representing a 5.5 point absolute gain over the base GLM-4.7-Flash model (50.5%) and an 8.0 point gain over standard RL without compaction (48.0%). On Terminal-Bench 2.0, CompactionRL scored 20.2%, an absolute gain of 6.8 points over the base model (13.4%) and 7.8 points over standard RL (12.4%).
- **GLM-4.5-Air (106B-A30B):** CompactionRL achieved a Pass@1 score of 66.8% on SWE-bench Verified, an absolute gain of 7.0 points over the base GLM-4.5-Air model (59.8%) and 4.3 points over standard RL (62.5%). On Terminal-Bench 2.0, CompactionRL scored 24.5%, an absolute gain of 3.1 points over the base model (21.4%) and 0.9 points over standard RL (23.6%).

It was observed that standard PPO, while improving "Single (×1)" window execution (e.g., GLM-4.7-Flash: 47.5% to 50.0% on SWE-bench Verified), did not consistently transfer these benefits to compacted inference, sometimes even degrading performance. Conversely, CompactionRL did not consistently improve single-window performance, which is attributed to the mismatch between its compaction-aware training and single-window evaluation without compaction. These results indicate that joint training of task execution and compaction is crucial for leveraging context compaction effectively.

#### 4.2. Ablation Studies

- **Effect of Summary Training (Table 3):** The ablation study comparing CompactionRL with a variant where compaction is enabled during training but the loss on summary-response turns is masked ("CompactionRL (w/o sum.)") revealed that optimizing the summarizer is critical. Including summary responses in the RL objective ("CompactionRL (ours)") consistently improved compacted inference performance across both model scales and benchmarks. For GLM-4.7-Flash on SWE-bench Verified (Comp. (×4) setting), summary training improved Pass@1 from 54.5% to 56.0%. On Terminal-Bench 2.0, it improved from 12.4% to 20.2%. Similar trends were observed for GLM-4.5-Air. This demonstrates the benefit of directly optimizing summarization. The compaction-aware training also performed competitively with or surpassed longer-context baselines ("Long" setting), suggesting it effectively extends the usable context horizon.
- **Effect of Token-Level Loss and Cross-Trajectory GAE (Table 4):** Ablating the two specific optimization components designed for compacted trajectories (token-level loss normalization and cross-trajectory GAE) demonstrated their importance.
 - Removing token-level loss normalization ("− w/o token-level loss") for GLM-4.5-Air on SWE-bench Verified reduced Pass@1 from 66.8% to 60.0% (a 6.8 point drop), and on Terminal-Bench 2.0 from 24.5% to 21.3% (a 3.2 point drop).
 - Removing cross-trajectory GAE ("− w/o cross-trajectory GAE") resulted in a performance drop to 63.0% on SWE-bench Verified (a 3.8 point drop) and 22.5% on Terminal-Bench 2.0 (a 2.0 point drop).
 The larger degradation observed when token-level loss normalization was removed suggests that correcting optimization bias from variable segment counts and lengths is particularly critical.

#### 4.3. Analysis of Compaction Behavior and Training Dynamics

- **Compaction Behavior (Figure 3):** Analysis of compaction behavior on SWE-bench Verified for the GLM-4.5-Air setting showed that CompactionRL (ours) required fewer compactions and tool calls per trace compared to the base model and the variant without summary training. It performed more compactions and tool calls than standard RL trained with an extended context (RL-160k), which effectively had a larger context budget. CompactionRL achieved the highest Pass@1 accuracy on the subset of tasks that actually triggered compaction (47.7%), indicating improved reliability in continuing from compacted histories. These results suggest that trained summaries help retain task-relevant information and reduce redundant re-exploration after compaction, leading to higher interaction efficiency.
- **Training Dynamics (Figure 4):**
 - **Summary Length:** During training, CompactionRL (with summary training) produced increasingly longer and more detailed summaries, unlike the variant without summary training where summary length decreased. This indicates that optimizing summary responses encourages the model to retain more useful, detailed information.
 - **Reasoning Tokens:** CompactionRL exhibited an increase in reasoning tokens per turn throughout training, while variants without summary training or without compaction showed a decrease. This suggests that learned compaction effectively expands the usable context window, allowing for a larger reasoning budget.
 - **Entropy:** CompactionRL showed a slower entropy increase, which implies more controlled policy optimization compared to baselines.

### 5. Significance and Potential Impact

The CompactionRL framework represents a notable advancement in training long-horizon LLM agents, offering several significant contributions and potential impacts:

- **Effective Mitigation of Context Window Limitations:** The primary significance of this work lies in providing a practical and effective method to overcome the fundamental context window limitation of LLMs in long-horizon interactive tasks. By integrating trainable context compaction into the RL training loop, CompactionRL enables agents to operate effectively on tasks that far exceed their physical context length, making complex tasks like software engineering or long-term problem-solving more tractable.
- **Novel Integration of Compaction into RL:** Unlike prior approaches that treated context compaction as an inference-time heuristic or an external memory system, CompactionRL makes summarization a trainable component of the agent's policy. This joint optimization of task execution and summary generation under a shared task reward is a methodological innovation, ensuring that summaries are optimized for task-relevant information retention rather than generic quality metrics.
- **Methodological Advancements in RL for LLMs:** The introduction of token-level loss normalization and cross-trajectory Generalized Advantage Estimation (GAE) specifically addresses the challenges of credit assignment and loss weighting in segmented, variable-length trajectories resulting from compaction. These modifications provide a more robust and accurate learning signal, which is crucial for the effective training of agents in such dynamic environments.
- **Demonstrated Performance Gains on Complex Tasks:** CompactionRL consistently achieves substantial performance improvements on challenging agentic coding benchmarks like SWE-bench Verified and Terminal-Bench 2.0. These results are achieved under fixed peak context budgets, demonstrating that the gains are due to improved context utilization and not simply increased computational resources. The ability to enhance performance on tasks that inherently require long-term memory and reasoning is a key indicator of its practical utility.
- **Practical Deployment and Scalability:** The fact that CompactionRL is already deployed in the RL pipeline for training the open GLM-5.2 model highlights its immediate practical relevance and scalability. This suggests that the framework is robust enough for real-world application in developing advanced LLM agents.
- **Broader Implications for Agent Architectures:** This work contributes to the evolving understanding of how to design and train more capable and efficient LLM agents. By demonstrating the benefits of learned context management, it encourages further exploration into adaptive and dynamic memory mechanisms within agent architectures, potentially paving the way for agents that can self-regulate their information processing over extended periods.

While the current work focuses on coding tasks and notes limitations regarding performance transfer to single-window evaluation and the approximation nature of cross-trajectory GAE, it lays a strong foundation. Future research directions could involve generalizing the approach to broader agent domains with diverse observation structures and reward signals, as well as refining credit assignment mechanisms for even longer-term dependencies.
