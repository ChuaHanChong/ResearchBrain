# GauDP: Reinventing Multi-Agent Collaboration through Gaussian-Image Synergy in Diffusion Policies

> [!summary] Summary
> GauDP, developed by researchers from Sun Yat-sen University, The University of Hong Kong, and others, introduces a multi-agent diffusion policy that integrates 3D Gaussian scene representations with local 2D image features. This framework enables robust collaborative robotic tasks using only decentralized 2D RGB camera inputs, achieving higher average success rates (19.67%) on the RoboFactory benchmark compared to 3D point cloud methods (14.33%).

## Problem

- Multi-agent embodied systems face a dilemma between achieving fine-grained local control from individual observations and maintaining global scene understanding for coordination.
- Existing 2D vision-based imitation learning struggles with robust 3D spatial reasoning for manipulation, while 3D sensor-based methods are costly and require specialized hardware.
- Current multi-agent policies often lead to miscoordination from local views or imprecise control from overly generalized global views.

## Method

- A self-supervised, feed-forward 3D ==Gaussian Splatting== (3DGS) module reconstructs a globally consistent 3D scene representation from decentralized 2D RGB camera inputs, fine-tuned with depth supervision.
- This global 3D context is selectively allocated and fused at a pixel-aligned level with each agent's local 2D image features, creating a 'Gaussian-image synergistic representation'.
- A global diffusion policy uses these fused features to jointly predict actions for all agents, promoting coordinated behavior by modeling inter-agent dependencies.

## Results

- GauDP achieved a **19.67%** average success rate across RoboFactory benchmark tasks, outperforming 2D image-based policies (e.g., DP's **3.67%**) and 3D point cloud-based policies (e.g., DP3's **14.33%**).
- The 3D Gaussian reconstruction module showed significant quantitative improvement over the Noposplat baseline (e.g., PSNR increased from **17.918** to **23.424**).
- Real-robot experiments confirmed practical efficacy, with GauDP achieving higher success in tasks like "Card Box Stacking" (17/30 vs. DP's 11/30) and demonstrating robustness to visual disturbances.

## Takeaways

> [!tip] Key Insights
> - Robust 3D scene understanding for multi-agent collaboration can be achieved with only 2D RGB inputs by explicitly reconstructing a consistent 3D Gaussian field.
> - Pixel-level fusion of global 3D context with local 2D image features is crucial for balancing fine-grained local control with comprehensive global awareness.
> - A global diffusion policy, utilizing the synergistic representation, effectively models inter-agent dependencies, leading to superior coordination compared to independent local policies.
