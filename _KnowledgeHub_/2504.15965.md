# From Human Memory to AI Memory: A Survey on Memory Mechanisms in the Era of LLMs

> [!summary] Summary
> Researchers from Huawei Noah’s Ark Lab present a systematic survey mapping human memory concepts to AI memory mechanisms in large language models. The paper introduces a three-dimensional, eight-quadrant (3D-8Q) taxonomy for AI memory, classifying it by object, form, and time, and uses this framework to categorize and analyze existing memory solutions in LLMs.

## Problem

- Large Language Models (LLMs) face limitations in retaining and utilizing information over extended interactions due to finite context windows, hindering prolonged coherence and personalized conversations.
- A systematic and unified framework for understanding and developing AI memory, particularly one drawing parallels to human memory, was lacking in the rapidly evolving field of LLMs.
- Existing categorizations of AI memory often relied solely on time (short-term vs. long-term), neglecting crucial dimensions like the memory's object (what is remembered) and form (how it is stored).

## Method

- The authors developed a systematic survey approach that first meticulously details human memory mechanisms to serve as a blueprint for AI memory design.
- They proposed a novel 3D-8Q memory taxonomy for AI, organizing memory based on its object (personal or system), form (parametric or non-parametric), and time (short-term or long-term).
- Existing research and systems in LLM memory were systematically reviewed and categorized according to the proposed 3D-8Q framework, demonstrating its utility in structuring the field.

## Results

- Successfully established parallels between human memory categories (sensory, working, explicit, implicit) and their functional equivalents in LLM-driven AI systems.
- Introduced a novel and comprehensive three-dimensional, eight-quadrant (3D-8Q) memory taxonomy for AI, classifying memory by Object (personal/system), Form (non-parametric/parametric), and Time (short-term/long-term).
- Systematically categorized a broad range of existing AI memory research and systems within the 3D-8Q framework, detailing specific examples for personal and system memory across different forms and durations.

## Takeaways

> [!tip] Key Insights
> - A comprehensive taxonomy for AI memory requires considering the object (personal/system), form (parametric/non-parametric), and time (short-term/long-term) dimensions, moving beyond simple temporal classifications.
> - Drawing explicit parallels between human memory categories (sensory, working, explicit, implicit) and AI memory mechanisms provides a bio-inspired framework for designing more robust and human-like AI systems.
> - Current AI memory research, when organized under the proposed 3D-8Q taxonomy, reveals clear areas for improvement and future focus, such as multimodal memory, stream memory, and comprehensive integration.
