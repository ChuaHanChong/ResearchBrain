# Path Channels and Plan Extension Kernels: a Mechanistic Description of Planning in a Sokoban RNN

> [!summary] Summary
> An investigation into a model-free reinforcement learning agent for Sokoban mechanistically elucidated its planning process, identifying internal "path channels" that represent future movements and a bidirectional planning algorithm built from specialized convolutional kernels. This work revealed mechanisms for plan extension, stopping, backtracking, and a Winner-Takes-All selection system, which consistently emerged across multiple trained networks.

## Problem

- Lack of transparency in deep neural networks, especially agentic models, hindering understanding of their complex decision-making and preventing predictability.
- The challenge of understanding how model-free reinforcement learning agents achieve long-horizon planning without explicitly programmed planning components.
- Difficulty in conducting detailed, weight-level mechanistic interpretability for complex, high-performing networks beyond simpler "toy" models.

## Method

- Conducted a mechanistic ==reverse-engineering== of a DRC(3,3) convolutional recurrent neural network trained on Sokoban using qualitative inspection, quantitative validation, and causal interventions.
- Identified specific "path channels" in the hidden state that directly represent future agent and box movements, distinguishing between short-term and long-term planning horizons.
- Analyzed convolutional kernels to uncover a learned bidirectional planning algorithm, detailing mechanisms for plan extension, stopping, backtracking, and path selection.

## Results

- Fifty-nine "path channels" were identified, directly representing future agent and box movements; ablating these channels reduced the solve rate by **57.6%**.
- A bidirectional planning algorithm was characterized, comprising encoder kernels for initialization, plan extension kernels for propagation, obstacle-based stopping mechanisms, and a Winner-Takes-All mechanism for path selection.
- These planning mechanisms consistently emerged early in training and were replicated across five independently trained networks, demonstrating their robust and common learning trajectory.

## Takeaways

> [!tip] Key Insights
> - Model-free reinforcement learning agents can implicitly learn sophisticated planning algorithms, including bidirectional search, through specialized internal circuits and recurrent computations.
> - The network develops an internal, value-like representation within path channels that implicitly prioritizes path length, suggesting characteristics of a learned "mesa-optimizer."
> - Detailed, weight-level mechanistic interpretability for complex, high-performing neural networks is feasible, moving beyond probe-based or localized feature analyses.
