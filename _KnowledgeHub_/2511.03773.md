# Scaling Agent Learning via Experience Synthesis

> [!summary] Summary
> DreamGym introduces a framework for scalable online reinforcement learning that enables autonomous LLM agents to train efficiently by synthesizing diverse, causally grounded interaction experiences. This approach leverages a reasoning-based experience model, replay buffer, and curriculum task generator, yielding improved performance and reduced real-world data requirements across interactive environments.

## Problem

- Reinforcement learning for LLM agents faces high costs and low sample efficiency when interacting with real-world environments.
- Existing environments offer limited task diversity, requiring costly human expertise for scalable task generation and validation.
- Dynamic interactive settings provide unreliable, sparse, and inconsistent reward signals, hindering stable agent learning.

## Method

- A reasoning-based ==experience model== (Mexp) distills environment dynamics into abstract textual states, predicting transitions and rewards using Chain-of-Thought reasoning, interaction history, and retrieved past experiences.
- An experience replay buffer is continuously enriched with synthetic trajectories generated by Mexp, providing stable context and reducing hallucinations during training.
- A curriculum-based task generator, co-trained with Mexp, adaptively creates new, progressively challenging tasks using a reward entropy heuristic to maximize learning information.

## Results

- Achieved over **30%** improvement in success rates on non-RL-ready environments (e.g., WebArena) compared to baselines.
- Agents trained purely on synthetic rollouts performed on par with traditional RL baselines requiring 80,000 real-world interactions in environments like WebShop and ALFWorld.
- The Sim-to-Real approach (DreamGym-S2R) demonstrated over **40%** performance improvement while needing less than **10%** of external real-world data for fine-tuning.

## Takeaways

> [!tip] Key Insights
> - Synthesizing learning-centric interaction data in an abstract, reasoning-driven textual space effectively addresses the data bottleneck for LLM agent RL.
> - Explicit Chain-of-Thought reasoning in the experience model enhances causal consistency and factual grounding of generated synthetic experiences.
> - Adaptive curriculum generation, guided by task difficulty and information gain, is crucial for continuous agent improvement and preventing learning plateaus.
