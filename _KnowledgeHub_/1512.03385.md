# Deep Residual Learning for Image Recognition

> [!summary] Summary
> Microsoft Research introduced Residual Networks (ResNets), an architecture that solves the degradation problem in very deep neural networks by reformulating layers to learn residual functions via identity shortcut connections. This enabled the successful training of networks with up to 152 layers, achieving a 3.57% top-5 error rate on ImageNet classification and securing first place in ILSVRC 2015.

## Problem

- As deep neural network depth increased beyond a certain point, accuracy saturated and then rapidly declined, even on the training set (the "degradation problem").
- This degradation was not due to overfitting; deeper models had higher training errors than shallower ones, suggesting an optimization challenge.
- Stacked layers in traditional architectures found it difficult to learn identity mappings, which are theoretically optimal in some cases for deeper layers.

## Method

- The authors introduced a ==residual learning== framework where layers learn a ==residual function F(x) = H(x) - x==, with the actual output being F(x) + x.
- This is implemented via ==shortcut connections== that add the input directly to the output of a stack of layers, facilitating the learning of ==identity mappings==.
- The architecture uses ==identity shortcuts== when input and output dimensions match, and ==projection shortcuts (1x1 convolutions)== when dimensions change.

## Results

- Plain networks demonstrated the degradation problem, with a **56-layer** network exhibiting higher training error than a **20-layer** network.
- Residual Networks (ResNets) successfully overcame degradation, allowing training of networks up to **152 layers** deep, and showed improved training dynamics compared to plain networks.
- An ensemble of ResNets achieved a **3.57%** top-5 error rate on ImageNet classification, securing first place in the ILSVRC 2015 competition and setting a new state-of-the-art.

## Takeaways

> [!tip] Key Insights
> - Reformulating layers to learn residual functions (F(x) = H(x) - x) provides an effective method to train very deep networks.
> - Simple identity shortcut connections introduce no extra parameters or computational complexity while significantly improving training dynamics and enabling greater depth.
> - With residual learning, deeper networks consistently outperform shallower ones, confirming the importance of depth in representation learning when optimization challenges are addressed.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

#### 1.1. Introduction

Deep neural networks have revolutionized computer vision tasks, with increasing depth (number of layers) generally leading to better performance. However, researchers faced a puzzling challenge: simply adding more layers to deep networks eventually led to worse performance, not better. This "degradation problem" was not caused by overfitting, as it occurred even during training.

In 2015, Kaiming He, Xiangyu Zhang, Shaoqing Ren, and Jian Sun from Microsoft Research proposed a groundbreaking solution in their paper "Deep Residual Learning for Image Recognition." They introduced Residual Networks (ResNets), a novel architecture that allowed successful training of networks with unprecedented depths of up to 152 layers, far deeper than previous architectures.

### 2. Key Objectives and Motivation

#### 2.1. The Degradation Problem

When neural networks become very deep, they suffer from the degradation problem: as network depth increases, accuracy saturates and then rapidly declines. Counterintuitively, deeper models produce higher training errors than their shallower counterparts. This is not caused by overfitting, as deeper models should theoretically be able to represent at least the same functions as shallower ones (by mimicking the shallower model and setting additional layers to identity mappings).

The authors hypothesized that the problem stems from the difficulty in optimizing deep networks. Specifically, they proposed that it's challenging for stacked layers to learn identity mappings when they would be optimal. In other words, if the ideal function for certain layers is to do nothing and simply pass the input through unchanged, traditional network architectures struggle to learn this seemingly simple transformation.

### 3. Methodology and Approach

#### 3.1. Residual Learning Framework

The key insight of ResNets is the introduction of "residual learning." Instead of trying to learn a direct mapping between input and output (denoted as H(x)), the authors reformulated the problem to learn a residual function F(x) = H(x) - x. The desired mapping can then be recast as F(x) + x.

This approach is implemented through "shortcut connections" (also called skip connections) that skip one or more layers and perform identity mapping by adding the input directly to the output of the stacked layers:

```
y = F(x, {W_i}) + x
```

Where F represents the residual mapping to be learned, and {W_i} are the weights of the layers. When the dimensions of F(x) and x are the same, this identity shortcut requires no extra parameters. When dimensions differ, a linear projection W_s can be used to match dimensions:

```
y = F(x, {W_i}) + W_s·x
```

The elegance of this approach is that if the optimal function is the identity mapping, the network can easily learn to set the weights of the residual function F(x) close to zero, effectively making the layer learn an identity function.

#### 3.2. Network Architecture

ResNets follow the general design principles of previous deep convolutional networks with some key differences:

1. **Plain Network (Baseline)**: Similar to VGG nets, using mostly 3×3 filters, following two simple design rules:
 - For the same output feature map size, the layers have the same number of filters
 - If the feature map size is halved, the number of filters is doubled to preserve time complexity per layer

2. **Residual Network**: Based on the plain network, but with added shortcut connections. Two types of shortcuts are used:
 - Identity shortcuts when input and output dimensions match
 - Projection shortcuts (using 1×1 convolutions) when dimensions change

The ResNet architecture comes in various depths including ResNet-18, ResNet-34, ResNet-50, ResNet-101, and ResNet-152, with the number indicating the layer count.

Deeper variants like ResNet-50 use a "bottleneck" design for efficiency. Instead of two 3×3 convolutional layers, they use three layers: 1×1, 3×3, and 1×1 convolutions. The 1×1 layers reduce and then restore dimensions, while the 3×3 layer operates on a reduced input/output dimension.

#### 3.3. Training Deep Residual Networks

The networks were trained on the ImageNet dataset using standard stochastic gradient descent (SGD) with a mini-batch size of 256. Key training details include:

- Batch normalization after each convolution and before activation
- Learning rate starting at 0.1 and divided by 10 when the error plateaus
- Weight decay of 0.0001 and momentum of 0.9
- No dropout used (as batch normalization provides regularization)

Images were resized with the shorter side randomly sampled between 256 and 480 pixels for scale augmentation, then a 224×224 crop was randomly sampled from the image or its horizontal flip.

### 4. Main Findings and Results

#### 4.1. Experimental Results

The experiments demonstrated several important findings:

1. **Plain Networks Suffer from Degradation**: The training error of plain networks increases with depth, confirming the degradation problem. For example, a 56-layer plain network showed higher training error than a 20-layer network.

2. **ResNets Solve Degradation**: Residual networks showed substantially improved training dynamics and final performance compared to plain networks of the same depth.

3. **Deeper ResNets Give Better Results**: Unlike plain networks, ResNets continued to benefit from added depth. The authors successfully trained networks with 152 layers, and even experimented with networks over 1000 layers deep.

4. **State-of-the-Art Performance**: ResNet achieved state-of-the-art results on the ImageNet classification task, with a top-5 error rate of 3.57% using an ensemble of residual nets. This was a remarkable improvement over previous methods and secured first place in the ILSVRC 2015 classification competition.

5. **Feature Response Analysis**: The authors analyzed the responses of the network layers and found that ResNets have smaller responses and more uniformly distributed responses across layers, suggesting better information flow.

### 5. Significance and Potential Impact

#### 5.1. Impact and Applications

ResNet has had a profound impact on deep learning research and applications:

1. **Foundational Architecture**: ResNet has become a foundational architecture in computer vision, serving as a backbone for many state-of-the-art systems in image classification, object detection, and segmentation.

2. **Transfer Learning**: Pre-trained ResNet models are widely used for transfer learning, where the knowledge gained on ImageNet is repurposed for other tasks with limited training data.

3. **Conceptual Breakthrough**: The concept of residual learning has influenced numerous subsequent architectures like DenseNet, ResNeXt, and EfficientNet.

4. **Deep Learning Theory**: ResNets have contributed to theoretical understanding of deep neural networks, particularly regarding optimization dynamics and the role of skip connections in facilitating gradient flow.

5. **Practical Applications**: ResNets power numerous real-world computer vision applications, from autonomous vehicles to medical image analysis, surveillance systems, and content moderation.

#### 5.2. Conclusion

Deep Residual Learning for Image Recognition represents a watershed moment in deep learning research. The introduction of residual connections elegantly solved the degradation problem that had previously limited the depth of neural networks. This enabled the successful training of networks with unprecedented depths, leading to significant performance improvements.

The key insights from this work include:

1. **Residual Learning**: Reformulating layers to learn residual functions provides an effective way to train very deep networks.

2. **Identity Shortcuts**: Simple identity shortcuts introduce no extra parameters or computational complexity while dramatically improving training dynamics.

3. **Depth Matters**: With the degradation problem solved, deeper networks consistently outperform shallower ones, confirming the importance of depth in representation learning.

The success of ResNets demonstrates that carefully designed architectures can overcome fundamental optimization challenges in deep learning. The principles introduced in this paper continue to influence neural network design and have enabled advances across computer vision and beyond.
