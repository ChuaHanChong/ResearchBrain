# Learning to Match Features with Seeded Graph Matching Network

> [!summary] Summary
> Researchers at the Hong Kong University of Science and Technology developed the Seeded Graph Matching Network (SGMNet), which reduces the O(N²) computational and memory complexity of graph-based feature matching to O(NK) by using a sparse, seed-guided message passing mechanism. This approach achieves competitive matching accuracy while running up to 7 times faster and consuming half the GPU memory compared to previous dense GNN methods.

## Problem

- Dense attention mechanisms in Graph Neural Networks (GNNs) for feature matching incur quadratic computational (O(N²)) and memory (O(N²)) costs, making them impractical for a large number of keypoints.
- Fully-connected graphs in previous GNNs like SuperGlue suffer from redundant message passing due to many weak or irrelevant connections, leading to inefficiencies and potential distraction.
- Existing deep learning methods often focus on outlier rejection post-matching, failing to improve the initial quantity or quality of matches found by basic nearest neighbor methods.

## Method

- **SGMNet** introduces a ==sparse graph structure== with a 'Seeding Module' to generate a small set of reliable matches (seeds) as initial guides.
- A 'Seeded Graph Neural Network' (==Seeded GNN==) utilizes these seeds as ==attention bottlenecks== for efficient message passing, structured around ==Attentional Pooling==, ==Seed Filtering==, and ==Attentional Unpooling== operations.
- The network incorporates a ==reseeding module== for refining seeds and a ==weighted attentional unpooling== mechanism that uses predicted inlier likelihood scores to selectively propagate information, suppressing noisy seeds.

## Results

- **SGMNet** achieves up to **7 times** faster runtime and approximately **half** the GPU memory consumption compared to SuperGlue when processing a large number of keypoints (e.g., **10,000**).
- The method demonstrates competitive or superior matching accuracy across various image matching and visual localization benchmarks, performing well with different local feature descriptors.
- In Structure-from-Motion (SfM) experiments, SGMNet produces more complete 3D reconstructions with significantly reduced matching time (e.g., **5.5 hours** versus **42 hours** for SuperGlue), highlighting its practical utility for large-scale applications.

## Takeaways

> [!tip] Key Insights
> - A sparse, seed-guided message passing mechanism can effectively reduce computational complexity in GNNs for feature matching without compromising accuracy.
> - Leveraging a small, reliable set of 'seed' matches as attention bottlenecks provides a compact and efficient way to propagate contextual information across images.
> - Weighting the information broadcast based on predicted inlier likelihoods during unpooling significantly enhances robustness to noise and unreliable initial seed matches.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Establishing reliable correspondences between features across multiple images is a foundational problem in computer vision, critical for applications such as Structure-from-Motion (SfM), Multiview Stereo (MVS), and Simultaneous Localization and Mapping (SLAM). Traditionally, this task has relied on nearest neighbor (NN) searches of local feature descriptors, often combined with heuristic pruning methods like mutual nearest neighbor (MNN) checks and ratio tests (RT).

Recent advancements have focused on integrating deep learning into the feature matching pipeline. Early deep learning approaches primarily addressed outlier rejection by feeding correspondence coordinates into permutation-equivariant networks, predicting inlier likelihood scores. However, these methods were limited as they operated on pre-matched correspondences, thereby not improving upon the number of matches found by basic nearest neighbor search, and often neglected the original local visual descriptors.

A more recent and influential development has been the formulation of feature matching as a graph matching problem, utilizing Graph Neural Networks (GNNs). A representative work in this area, SuperGlue, constructs densely-connected graphs between image keypoints to exchange messages that incorporate both visual and geometric context. While SuperGlue demonstrated high performance, its fully-connected attention mechanisms result in a quadratic computational complexity (O(N²)) with respect to the number of keypoints (N). This quadratic complexity leads to significant computational and memory costs, hindering its practical application, especially when dealing with a large number of keypoints (e.g., up to 10,000). Furthermore, the dense connectivity has been observed to introduce redundancy, with many graph edges having minimal strength, suggesting that a sparser graph might be sufficient and potentially less prone to distraction from irrelevant message exchanges.

The work presented in this paper, Seeded Graph Matching Network (SGMNet), aims to address these limitations. It seeks to develop a feature matching strategy that maintains high accuracy while substantially improving efficiency and reducing computational and memory requirements. SGMNet positions itself as an evolution of GNN-based matching by introducing a sparse graph structure and a seeded message-passing mechanism, drawing inspiration from guided matching approaches and graph pooling operations. This approach targets the core inefficiencies of dense attention networks like SuperGlue, seeking a more compact and effective message-passing design.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a feature matching network that achieves both high accuracy and significantly improved computational and memory efficiency. This overarching goal is driven by several specific motivations:

1. **Addressing the Computational and Memory Bottleneck of Dense GNNs**: Existing advanced GNN-based feature matching methods, such as SuperGlue, employ densely-connected attention mechanisms. This design leads to a computational complexity of O(N²C) for matrix multiplications and a memory footprint of O(N²) for storing attention matrices, where N is the number of keypoints and C is the feature channel dimension. For applications requiring a large number of keypoints (e.g., 10,000), these quadratic costs render such methods impractical due to excessive processing time and GPU memory consumption. The authors were motivated to reduce these costs to make GNN-based matching more accessible and scalable.

2. **Mitigating Redundancy in Message Passing**: The dense connectivity in previous GNN architectures like SuperGlue implies that every keypoint potentially interacts with every other keypoint within and across images. The paper argues that this dense interaction can introduce significant redundancy, particularly in feature matching tasks where a large portion of keypoints might be unrepeatable or form outlier correspondences. Empirical observations, including those reported in SuperGlue's original paper and confirmed by the authors' experiments, indicate that many graph edges exhibit negligible strength. This suggests that a more targeted and sparse message-passing mechanism could be equally, if not more, effective by reducing irrelevant information exchange.

3. **Leveraging Guided Matching for Enhanced Compatibility**: The authors drew inspiration from guided matching approaches, which use a small set of highly reliable initial matches (referred to as "seeds") to guide the subsequent matching process. They hypothesized that integrating such a seeding mechanism within a GNN framework could more effectively identify inlier compatibility and streamline the message-passing process by focusing on promising regions or correspondences.

Based on these motivations, the key objectives of the SGMNet research are:
- To design a graph neural network with a sparse structure that reduces redundant connectivity and learns a more compact representation for feature matching.
- To propose a "Seeding Module" that initializes the matching process by generating a small set of reliable matches to serve as guides.
- To develop a "Seeded Graph Neural Network" that utilizes these seed matches as attention bottlenecks to efficiently pass messages within and across images, thereby predicting assignment costs.
- To introduce novel operations (Attentional Pooling, Seed Filtering, Attentional Unpooling) as fundamental components for this efficient, seed-guided message passing.
- To achieve competitive or superior performance in terms of matching accuracy compared to existing state-of-the-art methods, particularly dense attention-based GNNs, while demonstrably reducing computational and memory complexity.
- To evaluate the method across various computer vision tasks (image matching, visual localization, SfM) to demonstrate its efficiency and effectiveness in practical applications.

### 3. Methodology and Approach

The Seeded Graph Matching Network (SGMNet) is designed to learn correspondences between two sets of keypoints and their associated visual descriptors. The network operates in two primary stages: a Seeding Module to initialize reliable matches and a Seeded Graph Neural Network (Seeded GNN) to refine and extend these matches through efficient message passing.

#### 3.1. Input Representation

For a pair of images A and B, with *n* and *m* keypoints respectively, each keypoint *i* in image *I* (A or B) is represented by its coordinate *pᵢᴵ* and a *d*-dimensional visual descriptor *dᵢᴵ*. Keypoint positions are embedded into a high-dimensional feature space using an MLP and combined with the visual descriptors via element-wise summation to form the initial feature representations, *F⁰ₐ* and *F⁰ₑ*.

#### 3.2. Seeding Module

The initial Seeding Module generates a set of putative matches, referred to as seed matches (S), to guide the subsequent message passing.
- **Initial Seed Generation**: Putative matches are identified using a nearest neighbor search of the initial feature descriptors.
- **Reliability Scoring**: The inverse of the distance ratio (ratio of distance to the first and second nearest neighbors) is used to score the reliability of these putative matches.
- **Spatial Coverage**: Non-Maximum Suppression (NMS) is applied to ensure a better spatial distribution and coverage of the selected seeds.
- The output `S` consists of index lists for the selected seed matches in both images (`Sₐ`, `Sₑ`).

#### 3.3. Seeded Graph Neural Network (Seeded GNN)

The Seeded GNN takes the initial features (*F⁰ₐ*, *F⁰ₑ*) and the seed matches (S) as input. It utilizes the seeds as attention bottlenecks for message passing, structured around a pooling-processing-unpooling strategy within each processing unit (block). The network is constructed by stacking multiple such units (6 for the initial stage, 3 for a refinement stage).

The core of the message passing relies on a proposed **Weighted Attentional Aggregation** operation `Att(X, Y, w)`. This operation updates features `X` by aggregating information from `Y`, where `w` is a weight vector applied to the value projection `V` to modulate the importance of elements in `Y`.

Within each processing unit, three novel operations facilitate message passing:

1. **Attentional Pooling**:
 - This operation aggregates contextual information from the full keypoint set onto the seed matches.
 - Features for the seed matches (`S¹ᵢ`) are first retrieved from the full keypoint features (`Fᵢ`) using the seed indices.
 - These seed features are then updated by applying the `Att` operation (`S²ᵢ = Att(S¹ᵢ, Fᵢ, 1)`), where they query and aggregate information from all keypoints within their respective images (with `w=1` indicating no specific weighting at this stage).
 - The updated seed features from both images (`S²ₐ`, `S²ₑ`) are concatenated and fused via a Multi-Layer Perceptron (MLP) to produce `S³ₐ`, `S³ₑ`.

2. **Seed Filtering**:
 - This stage processes the pooled seed features to enhance them and facilitate cross-image communication, while also identifying outlier seeds.
 - **Intra-graph communication**: Self-attention (`Att`) is applied to the seed features within each image (`S⁴ᵢ = Att(S³ᵢ, S³ᵢ, 1)`).
 - **Inter-graph communication**: Cross-attention (`Att`) is applied between the seed features of the two images (`S⁵ᵢ = Att(S⁴ᵢ, S⁴ⱼ, 1)`).
 - **Inlier Likelihood Prediction**: A lightweight Context Normalization (CN) branch processes the concatenated seed features (`S⁵ₐ`, `S⁵ₑ`) to predict inlier likelihood scores (`γ`) for each seed correspondence. These scores are crucial for the subsequent unpooling stage.

3. **Attentional Unpooling**:
 - This operation broadcasts the refined, context-rich seed features back to all original keypoints, using the predicted inlier scores for selective propagation.
 - The keypoint features for the next layer (`Fᵗ⁺¹ᵢ`) are updated by applying `Att` operation (`Fᵗ⁺¹ᵢ = Att(Fᵗᵢ, S⁵ᵢ, γ)`) where the full keypoint set (`Fᵗᵢ`) queries the filtered seed features (`S⁵ᵢ`).
 - The inlier scores (`γ`) serve as the weighting vector `w`, which suppresses the influence of unreliable (outlier) seed matches during information propagation, leading to cleaner feature updates and improved robustness to seeding noise.

#### 3.4. Reseeding Module

After a set of initial Seeded GNN blocks, a second seeding module is introduced. Unlike the initial module that uses raw descriptors and ratio tests, the reseeding module leverages the assignment matrix (`M`) derived from the updated features. It selects correspondences with the highest scores in both rows and columns as candidates, and then the top-k are chosen as new seeds, with NMS applied. These refined seeds are then fed into a second (typically shorter) Seeded GNN for further refinement.

#### 3.5. Assignment Matrix Formulation

After all GNN processing units, the final updated keypoint features (`Fᴺₐ`, `Fᴺₑ`) are used to compute a correlation matrix. The Sinkhorn algorithm, extended with a learnable "dustbin" channel to account for unmatchable keypoints, is then applied to this correlation matrix to produce the final probabilistic assignment matrix `M`. Matches are extracted from `M` by applying a confidence threshold.

#### 3.6. Loss Function

The network is trained end-to-end with a combined loss function:
- **Assignment Loss (`L_assign`)**: A cross-entropy loss applied to both the reseeding assignment matrix and the final assignment matrix, supervising matches based on ground truth correspondences and unmatchable points.
- **Weight Loss (`L_t_weight`)**: A cross-entropy loss for the inlier/outlier binary classification of seeds in each processing unit, where seed correspondences are labeled as inliers if their epipolar distance is below a threshold. A weighting term `δ` balances these two loss components.

#### 3.7. Implementation Details

The network is trained on the GL3D dataset. During training, 1,000 keypoints and 128 seeds are sampled. An Adam optimizer is used, and gradient flow between initial and refinement stages is blocked in early iterations. All attentional operations employ 4-head attention.

### 4. Main Findings and Results

The research paper presents a comprehensive evaluation of SGMNet across various benchmarks and tasks, highlighting its efficiency and accuracy.

#### 4.1. Efficiency and Scalability

- **Computational Complexity Reduction**: SGMNet effectively reduces the computational complexity of the attention mechanism from O(N²C) (as in SuperGlue) to O(NKC), where N is the number of keypoints and K is the number of seeds. Since K is generally much smaller than N (e.g., 512 seeds for 8,000 keypoints), this constitutes a significant reduction.
- **Runtime Performance**: Experiments demonstrate that SGMNet achieves substantial runtime improvements. For matching 10,000 features, SGMNet runs 7 times faster than SuperGlue. Notably, when excluding the Sinkhorn iterations, the runtime reduction is even more pronounced, indicating that the GNN design itself is considerably more efficient.
- **Memory Consumption**: SGMNet exhibits lower memory usage. During the test phase, for keypoint numbers exceeding 2,000, SGMNet consumes approximately half the GPU memory compared to SuperGlue. The memory advantage is even more significant during training; with a batch size of 16 and 1,000 keypoints, SGMNet requires less than 9GB of GPU memory, whereas SuperGlue demands up to 23GB.
- **Faster Convergence**: The compactness and reduced redundancy of SGMNet also contribute to faster convergence during training, requiring fewer iterations to reach comparable performance levels.
- **Performance with More Keypoints**: SGMNet shows increasing accuracy with a larger number of keypoints (up to 8,000 keypoints tested on Aachen Day-Night). Its efficiency advantage makes it more practical to leverage a higher density of keypoints, providing a better trade-off between performance and computational cost for downstream tasks.

#### 4.2. Accuracy in Image Matching

- **YFCC100M, ScanNet, FM-Bench (CPC, T&T)**: SGMNet generally achieves competitive or superior results compared to state-of-the-art methods, including SuperGlue, when evaluated on pose estimation (AUC), mean matching score (M.S.), and precision (Prec.). This holds true across different local feature descriptors such as RootSIFT, ContextDesc, and SuperPoint.
- **FM-Bench (TUM, KITTI)**: For small-baseline datasets, where matching is inherently less challenging, the performance differences between advanced learnable methods tend to narrow. SGMNet performs comparably in these scenarios.
- **Match Quality**: The method often identifies a higher mean number of inlier correspondences after RANSAC while maintaining high matching precision, which contributes to the final pose accuracy.
- **Generalization**: SGMNet demonstrates strong generalization capabilities, performing well on indoor scenes (e.g., ScanNet) despite not being specifically trained on such data.

#### 4.3. Accuracy in Visual Localization (Aachen Day-Night Dataset)

- When integrated into a visual localization pipeline, SGMNet exhibits improved performance over SuperGlue using RootSIFT features and competitive results with SuperPoint or ContextDesc, particularly in challenging nighttime conditions.
- It consistently outperforms OANet across all tested descriptors, confirming its robustness and effectiveness in a demanding real-world application.

#### 4.4. Ablation Study

The ablation study confirms the individual contributions of SGMNet's components:
- **Seeding Mechanism**: The initial seeding of reliable matches plays a critical role in guiding message passing, significantly contributing to the final performance.
- **Weighted Attentional Unpooling**: The use of inlier scores to weight the unpooling process is crucial for robustness. Experiments show that SGMNet maintains high matching quality even with seed precision as low as 20%, whereas models without weighted unpooling degrade much faster with noisy seeds. This mechanism effectively suppresses information from false seed matches.
- **Attentional Pooling and Reseeding**: Both attentional pooling and the reseeding module contribute positively to the overall performance, indicating their importance in refining features and improving match accuracy.

#### 4.5. Comparison with Other Pooling Designs

Experiments with alternative pooling designs like DiffPool and Induced Set Attention (ISA), originally developed for generic GNNs or efficient transformers, showed only marginal improvements over baselines when applied to image matching. This highlights that SGMNet's seed-based attentional pooling/unpooling design is specifically tailored and effective for the image matching task.

#### 4.6. SfM Experiment (Alamo Scene)

In an SfM pipeline, SGMNet produces a more complete reconstruction (higher number of registered images and sparse points) compared to vanilla NN matching. While SuperGlue also improves reconstruction completeness, its matching time significantly lengthens the overall SfM pipeline (e.g., 42 hours for matching), whereas SGMNet maintains a feasible matching time (e.g., 5.5 hours), demonstrating its practical utility for large-scale 3D reconstruction.

### 5. Significance and Potential Impact

The Seeded Graph Matching Network (SGMNet) represents a notable advancement in the field of feature matching, particularly for its ability to address the long-standing challenge of achieving both high accuracy and computational efficiency in learnable matching strategies. Its significance and potential impact can be summarized as follows:

1. **Breaking the Efficiency Bottleneck for GNN-based Matching**: The primary impact of SGMNet is its successful mitigation of the quadratic complexity inherent in dense attention-based Graph Neural Networks like SuperGlue. By reducing the computational and memory complexity from O(N²) to O(NK), where K is a small number of seeds, SGMNet makes sophisticated GNN-based feature matching significantly more practical and scalable. This efficiency gain is crucial for real-world applications that often involve a large number of keypoints (e.g., high-resolution imagery).

2. **Enhanced Applicability Across Diverse Tasks**: The improved efficiency enables the use of GNN-based matching in scenarios previously limited by computational resources. This extends the applicability of advanced matching techniques to demanding computer vision tasks such as large-scale Structure-from-Motion, real-time Simultaneous Localization and Mapping (SLAM), and dense 3D reconstruction, where processing hundreds or thousands of images with many keypoints is common. The demonstrated performance in visual localization and SfM underscores this potential.

3. **Introduction of a Principled Sparse Attention Mechanism**: SGMNet's novel design, incorporating Attentional Pooling, Seed Filtering, and Attentional Unpooling, offers a principled approach to sparse attention in GNNs for feature matching. This seed-guided message passing reduces redundant computations while focusing information exchange through reliable correspondences, potentially leading to cleaner feature representations and more robust matching. This design could inspire new architectures for GNNs in other computer vision domains requiring efficient relational reasoning.

4. **Robustness to Initial Noise**: The inclusion of weighted attentional unpooling, which leverages inlier likelihood scores to suppress the influence of false seed matches, significantly enhances the method's robustness to potential noise in the initial seeding. This capability makes the system more resilient to imperfect initial conditions, a common challenge in real-world data.

5. **Competitive or Superior Performance without Compromise**: SGMNet demonstrates that substantial efficiency gains do not necessitate a compromise in performance. It achieves competitive or, in some cases, higher accuracy than previous state-of-the-art methods across various image matching and pose estimation benchmarks, validating its effectiveness.

In summary, SGMNet addresses a critical practical limitation of highly accurate but computationally intensive deep learning matching approaches. By providing a more efficient, scalable, and robust solution, it advances the state of the art in feature matching and is poised to have a tangible impact on the development of more practical and high-performing geometry-based computer vision pipelines.
