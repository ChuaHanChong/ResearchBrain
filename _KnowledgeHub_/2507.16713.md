# A Pragmatist Robot: Learning to Plan Tasks by Experiencing the Real World

> [!summary] Summary
> PRAGMABOT enables a robot to learn task planning through direct interaction with the real world, integrating VLM-driven self-reflection via short-term memory and cumulative knowledge from long-term memory. This approach achieved an 84% average task success rate and led to emergent intelligent behaviors like tool use in challenging manipulation tasks.

## Problem

- Large language and vision-language models (LLM/VLM) struggle to translate abstract reasoning into physically feasible plans for real-world robots due to their lack of embodied experience.
- Existing methods for robotic task planning often rely heavily on human supervision or extensive pre-training, limiting autonomous learning and adaptation in dynamic environments.
- Robots frequently fail at complex manipulation tasks because VLMs lack the ability to effectively evaluate action outcomes and self-reflect on failures for online course correction.

## Method

- A closed-loop framework using a VLM for task planning and a success detector for real-time feedback on action outcomes.
- Short-term memory (STM) enables the VLM to self-reflect on failures within an episode, facilitating online adaptation and generating revised plans.
- Long-term memory (LTM) stores summarized successful experiences, which are retrieved via ==Retrieval-Augmented Generation (RAG)== to inform planning for new tasks and generalize learned behaviors.

## Results

- Achieved an **84%** average task success rate across four manipulation tasks with self-reflection via STM, compared to **35%** for a baseline without this capability.
- Demonstrated emergent intelligent behaviors, including autonomously pushing aside obstructions, repositioning contained objects, and using a sponge as a tool to push small items.
- Improved single-trial success rates to **79.5%** on twelve diverse real-world scenarios by utilizing LTM and RAG, significantly outperforming methods without cumulative experience.

## Takeaways

> [!tip] Key Insights
> - Integrating VLM-driven self-reflection with short-term memory allows robots to adapt to failures online and exhibit emergent intelligent behaviors, such as creative tool use and obstruction handling.
> - Cumulative long-term memory, effectively leveraged through RAG, significantly improves a robot's first-attempt success rates and enables generalization of learned strategies to unseen, similar scenarios.
> - An on-demand image annotation module enhances VLM spatial reasoning for precise low-level skill execution, leading to more accurate grasping and pushing actions.
