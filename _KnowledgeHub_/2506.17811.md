# RoboMonkey: Scaling Test-Time Sampling and Verification for Vision-Language-Action Models

> [!summary] Summary
> RoboMonkey is a framework that scales test-time sampling and verification for Vision-Language-Action models, employing a learned action verifier trained on synthetic preference data. It demonstrated a 25% absolute improvement in success rates on real-world out-of-distribution tasks and established the existence of inference-time scaling laws for VLAs.

## Problem

- Vision-Language-Action (VLA) models often lack robustness and generalization, exhibiting failures like imprecise grasping and collisions in unstructured real-world environments.
- Current efforts to improve VLA performance primarily focus on pre-training and post-training, with test-time compute scaling largely unexplored for robotics.
- The cost and difficulty of human annotation make training effective verifiers for robotic actions a significant challenge.

## Method

- **RoboMonkey** employs a two-stage framework, first training an action verifier using a novel automated pipeline for synthetic action preference data generation.
- At deployment, the system samples multiple diverse candidate actions from a VLA model, efficiently using Gaussian perturbation, and then selects the optimal action with the learned verifier.
- A VLA serving engine built on SGLang optimizes inference for both the base VLA and the verifier, significantly reducing computational overhead.

## Results

- RoboMonkey achieved a **25%** absolute improvement in success rates on real-world out-of-distribution tasks, reaching **60%** compared to **35%** for the base OpenVLA model.
- On in-distribution tasks, it delivered an average success rate of **47.5%**, an absolute improvement of **9%** over standalone OpenVLA.
- The system processed and verified 16 candidate actions in approximately 650 ms (**1.5** Hz) on a single NVIDIA H100 GPU, demonstrating practical real-time applicability.

## Takeaways

> [!tip] Key Insights
> - An inference-time scaling law exists for Vision-Language-Action models, where action error consistently decreases as the number of generated samples increases.
> - High-quality action verifiers can be trained scalably using automatically generated synthetic action comparison data, eliminating the need for expensive human labeling.
> - Efficient sampling methods like Gaussian perturbation, combined with optimized inference engines, enable practical test-time scaling for robotic control within real-time constraints.
