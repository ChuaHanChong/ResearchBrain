# Value Flows

> [!summary] Summary
> Value Flows leverages flow-based generative models to estimate full, continuous future return distributions, providing a more granular understanding of uncertainty than existing discrete or quantile-based methods. This approach achieved competitive or superior performance in offline and offline-to-online reinforcement learning benchmarks, demonstrating a 3x lower 1-Wasserstein distance to ground-truth distributions and up to a 40% mean improvement on certain tasks.

## Problem

- Reinforcement learning primarily uses scalar Q-values, which average out crucial information about the spread and shape of future returns.
- Existing distributional RL methods use coarse approximations like discrete bins or a finite set of quantiles, limiting expressiveness and potentially overlooking fine-grained structural details or true return uncertainty.
- The inability to accurately quantify aleatoric uncertainty hinders robust learning and application in areas like exploration and safe RL.

## Method

- Developed **Value Flows**, a framework using ==flow-based generative== models to estimate the full, continuous probability density function of future returns.
- Formulated a novel distributional flow-matching objective that ensures the generated probability density paths satisfy the distributional Bellman equation.
- Introduced a distributional conditional flow matching (DCFM) loss for practical estimation and a bootstrapped conditional flow matching (BCFM) loss for regularization to stabilize learning.
- Quantified aleatoric uncertainty (return variance) directly from the learned flow models using an efficient flow derivative ODE and employed confidence weighting to prioritize learning at uncertain transitions.

## Results

- Value Flows achieved a 1-Wasserstein distance **3x** lower than the best-performing baseline, demonstrating a more accurate alignment with ground-truth return distributions.
- Outperformed or matched all baselines on 9 out of 11 OGBench and D4RL domains in offline RL, including a **40%** mean improvement on easier state-based tasks and **1.24x** better performance on image-based tasks.
- Showcased strong fine-tuning performance in offline-to-online RL, achieving **15%** higher performance on tasks like puzzle-4x4-play and demonstrating improved sample efficiency compared to baselines.
- Ablation studies confirmed that BCFM regularization boosted performance by **2.6x** and confidence weighting, which prioritizes uncertain transitions, increased the average success rate by **60%**.

## Takeaways

> [!tip] Key Insights
> - Flow-matching models can effectively represent complex, continuous return distributions, capturing fine-grained structural details and multi-modality more accurately than discrete or quantile-based methods.
> - The distributional Bellman equation can be satisfied by learning a time-dependent vector field within a flow-matching framework, ensuring theoretical convergence guarantees.
> - Efficiently computable aleatoric uncertainty, derived from the flow derivative ODE, provides a powerful signal to adaptively reweight learning objectives, leading to more robust and accurate return estimation.
