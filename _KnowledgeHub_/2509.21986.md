# Developing Vision-Language-Action Model from Egocentric Videos

> [!summary] Summary
> Researchers from Kyoto University, NII, and Sony Interactive Entertainment developed a method to pre-train Vision-Language-Action (VLA) models using raw egocentric videos. Their approach automatically extracts explicit 6DoF object manipulation trajectories without requiring auxiliary labels, creating a scalable dataset that enables VLA models to achieve performance comparable to those trained on costly real-robot data.

## Problem

- Training Vision-Language-Action (VLA) models for robotics demands massive datasets, but human teleoperation is prohibitively costly and labor-intensive, limiting data scalability.
- Prior attempts to use egocentric videos for robot learning either require dense auxiliary annotations (e.g., hand poses, depth) or learn implicit action representations that lack the fine-grained detail for complex manipulation.
- Robot policies trained on real-world egocentric data can face a visual domain gap when applied in simplified simulated environments, leading to performance degradation.

## Method

- Utilized and extended the EgoScaler framework to automatically extract explicit 6DoF object manipulation trajectories (position and rotation) directly from raw egocentric videos.
- Constructed a large-scale pre-training dataset by applying EgoScaler to diverse egocentric video resources, including Ego4D, Ego-Exo4D, HD-EPIC, and Nymeria.
- Implemented a rigorous rule-based data curation process (e.g., travel distance threshold, background track similarity, smoothing) to filter out noisy or incomplete trajectories and ensure data quality.

## Results

- VLA models pre-trained on the egocentric video-derived dataset achieved an average of **55%** success on real-robot tasks, substantially outperforming models trained from scratch (**0%** success) and prior implicit pre-training methods like LAPA (38-**45%** success).
- The performance of models pre-trained on the egocentric dataset (21 successful rollouts out of 40) was competitive with or superior to models pre-trained on existing real-robot datasets such as BC-Z (**19/40**) and BridgeData V2 (**17/40**) in real-robot evaluations.
- Combining the egocentric-derived dataset with existing real-robot data (BridgeData V2) led to synergistic improvements, achieving **27/40** successful rollouts, demonstrating its complementary value for building multi-embodiment VLA models.

## Takeaways

> [!tip] Key Insights
> - Explicit 6DoF object manipulation trajectories extracted from raw egocentric videos provide more robust and informative supervision for VLA models than implicit latent action representations, especially for complex manipulation tasks.
> - Large-scale egocentric video datasets, when effectively processed and curated, offer a scalable and cost-effective alternative to human teleoperation for VLA pre-training data acquisition.
> - Rigorous data curation, including automatic filtering based on movement characteristics, is crucial for mitigating inaccuracies from automated trajectory extraction and enhancing the utility of the derived datasets.
