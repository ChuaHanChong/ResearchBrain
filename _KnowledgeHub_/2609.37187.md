# InsightMap: Structured Spatial Modeling for Embodied Multimodal Reasoning

> [!summary] Summary
> InsightMap is a vision-and-language navigation framework built on the BAGEL unified multimodal backbone. It uses top-down maps both as explicit spatial memory, with past views tied to labeled map locations, and as prediction targets: during training the model learns to predict actions together with the map that results after each action. It reaches 56.9% SR on R2R-CE and 54.9% on RxR-CE, and beats NaVid and NaVILA on a Unitree Go2.

## Problem

- Map-based navigation systems collect spatial evidence in topological, grid or semantic maps, but are trained only on action labels, never on how the map changes after an action.
- Video-based vision-language navigation models keep raw frame history without explicitly recording where each past view was captured, so trajectory geometry and visual evidence are hard to relate.
- World models and world action models predict future pixels or video, leaving structured spatial representations unused as compact, ego-motion-aware targets for action-conditioned prediction.

## Method

- **Spatial memory interface**: sampled history frames share location IDs with a ==TSDF==-reconstructed top-down map showing the trajectory and current pose, so views and geometry are read together.
- **Structured world imagination**: a factorized joint objective trains action text by ==cross-entropy== plus the post-action map latent by ==rectified flow==; at inference only actions are decoded.
- **Aligned RGB-D data pipeline**: 800K examples mixing R2R, RxR, ScaleVLN and DAgger navigation transitions with ScanQA, SQA3D and ScanRefer, all built on the same map interface, plus target-annotated grounding maps.

## Results

- On R2R-CE val-unseen: **56.9** SR and **64.7** OS, best listed, with SPL **50.7**. On RxR-CE: SR **54.9**, SPL **46.1** and nDTW **62.8**, beating NaVILA by **5.6** SR.
- Ablations: map-prediction loss adds **4.3** SR and **3.2** SPL, location IDs add **2.8** SR, and the full task mixture lifts SR from **49.2** to **56.9**.
- Static scene tasks: **103.7** CIDEr on ScanQA, **60.1%** EM on SQA3D, and **53.1%** ScanRefer Acc@0.5 with proposals (**20.8%** raw). On Go2: **95/90/65%** SR, beating NaVILA by up to **45 points**.

## Takeaways

> [!tip] Key Insights
> - Predicting a structured post-action spatial representation is a useful auxiliary world-model loss for policies, even when no map is generated at inference time.
> - Explicitly indexing where each past observation was captured beats feeding raw history frames, which suggests memory needs spatial addressing and not just more context.
> - Static 3D question answering and grounding data improve navigation through a shared spatial interface, so non-embodied spatial reasoning tasks are valuable co-training signal for embodied policies.

## Detailed Report

### 1. Overview

Following a language instruction through a partly observed indoor environment means connecting what a robot sees now to where it has been. The robot must make a route from incomplete views, remember where those views were taken, and connect new observations to what it has already seen. Action-label training alone does not teach a model to predict how its spatial representation changes after a move. InsightMap links sampled past views to labeled locations on a top-down map. It then trains a shared model to predict both the next action and the map after that action. The figure below shows one recorded example of the map and view history together. It does not guarantee that every instruction succeeds.

Recorded trajectory for the instruction “Go around the right side of the center unit and stop by the right side doorway with the dining table and mirror in it.” Each step pairs a top-down map with a current RGB view and a strip of past-to-current views. Green circles mark the agent, blue points mark observation history, and yellow lines trace the path. The sequence ends with STOP.

### 2. Memory needs a place

The top-down map is an explicit spatial reference. It records observed geometry, the trajectory, the current pose, and labels that associate selected historical views with locations. Linking each view to a location helps the model interpret which earlier observation came from which place as the robot moves. The map does not replace visual history: InsightMap retains sampled past views.

The paper's location-ID ablation supports this link on R2R-CE validation-unseen. Adding historical location IDs to an otherwise unnumbered map raises SR from 54.1% to 56.9% and SPL from 49.9% to 50.7%. In this comparison, generation trainability and future-map supervision are held unchanged. This is evidence for the view–location link in this setup. It does not show that the link is the only useful map feature.

### 3. Teach the map to change

Before each move, the model receives the instruction, the current observation, the selected history, and the current map. During training, it first predicts the action as text. The ground-truth action text then conditions generation of the map reconstructed after that action is executed. This matters because motion changes the map's local reference frame, and a new view can reveal geometry not seen before.

The map prediction is an auxiliary training target, used only during training. During evaluation, the model decodes the action from observed spatial context. It then updates history and the observed map from new sensor data and does not generate the future map.

The decisive test is a controlled ablation on R2R-CE validation-unseen. Two metrics are used:

- **SR (success rate):** the percentage of episodes meeting the benchmark's success criterion.
- **SPL (success weighted by path length):** weights success by path length, so it reflects both success and path efficiency.

The generation module is trainable in both variants. Variant A2 has map supervision off, and variant A3 turns it on. Adding post-action map supervision raises SR from 52.6% to 56.9% and SPL from 47.5% to 50.7%. A separate change, unfreezing the generation module without map supervision (A1 to A2), raises SR/SPL from 50.3/45.1% to 52.6/47.5%. The A2-to-A3 gain comes on top of that.

R2R-CE validation-unseen ablation (percentages). A1: Frozen/Off/50.3/45.1; A2: Trainable/Off/52.6/47.5; A3 (Full): Trainable/On/56.9/50.7. A2 to A3 keeps module trainability the same and adds the map loss.

### 4. A map that remembers

In training, the map does more than compactly show where the robot has been. It also provides a target for how spatial evidence should change after movement. The controlled ablation supports map prediction as useful auxiliary supervision under this setup. It does not show that the model generates future maps at test time, or that map prediction is the only cause of the gains. It also does not show that navigation uses fewer attempts, fewer tokens, or less elapsed time.
