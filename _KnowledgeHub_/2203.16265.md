# SeqTR: A Simple yet Universal Network for Visual Grounding

> [!summary] Summary
> SeqTR introduces a universal Transformer-based network that reformulates visual grounding tasks like phrase localization and referring expression segmentation into a unified auto-regressive point prediction problem. The model achieves state-of-the-art or competitive performance on benchmark datasets while utilizing a simpler architecture and a single cross-entropy loss.

## Problem

- Existing visual grounding methods often rely on complex, specialized network architectures and intricate multi-modal fusion mechanisms.
- Previous approaches require hand-crafted, task-specific loss functions (e.g., for bounding boxes vs. segmentation) and complicated tuning of loss coefficients in multi-task settings.
- Many models suffer from limited generalization, requiring significant re-engineering to adapt to different visual grounding tasks (REC vs. RES) or new datasets due to task-specific output branches.

## Method

- ==SeqTR== reformulates both bounding box and binary mask outputs as ==sequences of discrete coordinate tokens==, unifying visual grounding tasks into an ==auto-regressive point prediction problem==.
- A standard Transformer encoder-decoder architecture processes multi-modal features and auto-regressively generates the coordinate sequences.
- The model is trained with a single, simple ==cross-entropy loss== across all visual grounding tasks, eliminating the need for complex, task-specific loss functions and coefficient tuning.

## Results

- SeqTR achieves new state-of-the-art performance on various RefCOCO datasets for Referring Expression Comprehension (REC), reaching **8**5.00%** Precision@0.5** on RefCOCO testA without pre-training.
- For Referring Expression Segmentation (RES), SeqTR obtains results on par with state-of-the-art models, reaching **6**9.79%** mIoU** on RefCOCO testA despite using a novel contour-based segmentation approach.
- The model is compact with **7.9M parameters** and achieves real-time inference speed (**50ms** on GTX 1080 Ti), demonstrating efficiency comparable to many one-stage models.

## Takeaways

> [!tip] Key Insights
> - Mask contour sampling, especially uniform sampling of a small number of points along the contour, effectively serializes binary masks for sequential prediction.
> - Randomly shuffling the order of sampled points during training for masks enhances robustness by forcing the model to learn context-independent coordinate prediction.
> - Surprisingly, multi-task training for REC and RES does not significantly improve performance, suggesting SeqTR's mask generation is robust independently.
