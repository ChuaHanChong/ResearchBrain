# Grounding Computer Use Agents on Human Demonstrations

> [!summary] Summary
> Researchers from Mila, ServiceNow Research, and several universities developed GROUNDCUA, a large-scale, human-annotated dataset for desktop UI grounding, along with GROUNDNEXT vision-language models. These models achieved state-of-the-art accuracy across five benchmarks with significantly less training data than prior methods, demonstrating the efficacy of high-quality data for robust computer-use agents.

## Problem

- Computer-use agents (CUAs) face a critical bottleneck in accurately grounding natural language instructions to visual elements within complex desktop user interfaces.
- Existing datasets for desktop UI grounding often lack the high quality, dense annotations, and real-world complexity necessary for robust agent training, relying on automated or synthetic generation.
- Desktop environments present unique challenges due to diverse layouts, high-resolution displays, numerous visually similar elements, and user-specific content.

## Method

- Developed GROUNDCUA, a large-scale dataset featuring 56K ==screenshots== and over 3.56 million human-verified annotations from expert demonstrations across 87 open-source desktop applications.
- Generated 700K image-instruction pairs for supervised fine-tuning (SFT) and 10K for reinforcement learning (RL) using a multimodal LLM to create diverse instruction types (direct, functional, spatial).
- Trained GROUNDNEXT vision-language models, based on Qwen2.5-VL-Instruct (3B and 7B), using a two-stage approach combining SFT with RL post-training, employing a custom discrete reward function.

## Results

- GROUNDNEXT models established state-of-the-art accuracy across five challenging benchmarks (e.g., ScreenSpotPro, OSWorld-G), outperforming previous best models by over 10 average percentage points despite being trained on significantly less data (**700K** vs. **9M** samples).
- The **3B** parameter GROUNDNEXT model achieved an impressive **50.6%** on the OSWorld-Verified agentic benchmark, outperforming many larger open-source models and proprietary APIs.
- The models demonstrated substantial improvements in desktop UI grounding, especially for icon recognition, and showed strong cross-platform generalization to mobile and web interfaces, despite being trained exclusively on desktop data.

## Takeaways

> [!tip] Key Insights
> - Superior data quality, derived from human experts, proves more effective for UI grounding than relying solely on larger volumes of less precise data.
> - Reinforcement learning consistently refines model performance but yields smaller gains when initial supervised fine-tuning is conducted with high-quality data, suggesting SFT captures most of the grounding capabilities.
> - Models trained exclusively on diverse desktop application data can exhibit strong generalization capabilities to cross-platform user interfaces, including mobile and web environments.
