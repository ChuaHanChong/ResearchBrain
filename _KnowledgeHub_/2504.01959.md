# Slot-Level Robotic Placement via Visual Imitation from Single Human Video

> [!summary] Summary
> NVIDIA Research and collaborators develop SLeRP, a system that enables robots to perform precise slot-level object placement by learning from a single human demonstration video, combining visual foundation models (SAM, DINOv2) with a specialized slot detection network to achieve accurate object placement across multiple real-world scenarios.

## Problem

- Teaching robots fine-grained placement tasks traditionally requires extensive programming or large amounts of demonstration data
- Existing visual imitation methods focus on coarse object-level tasks and struggle with precise slot-level placement

## Method

- ==Developed SLeRP== system that parses human demonstration videos to identify objects and placement slots
- Created Slot-Net, a specialized neural network for detecting placement slots using absolute image differences as visual prompts
- Implemented 2D-to-3D transformation pipeline to map human demonstrations to robot actions

## Results

- System successfully performs slot-level placement tasks on physical robot from single demonstrations
- Outperforms baseline methods in 2D mask accuracy and 3D transformation precision
- Demonstrates generalization across different objects and slot types despite training on synthetic data
- Maintains effectiveness under various lighting conditions and object appearances

## Takeaways

> [!tip] Key Insights
> - Visual foundation models can enable one-shot learning of precise manipulation tasks
> - Synthetic data generation using AI techniques enables effective training of slot detection networks
> - Combining multiple vision models (SAM, DINOv2, MASt3R) improves robustness in real-world scenarios
