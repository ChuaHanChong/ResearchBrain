# MEM: Multi-Scale Embodied Memory for Vision Language Action Models

> [!summary] Summary
> Multi-Scale Embodied Memory (MEM) integrates efficient multi-modal memory into Vision Language Action Models (VLAs), combining dense short-term visual memory with compressed long-term language memory. This system allows robots to complete complex tasks requiring memory spanning up to fifteen minutes, adapt to in-context failures, and maintain high performance on dexterous manipulation.

## Problem

- Endowing autonomous robots with effective memory for real-world tasks is challenging, especially for long-horizon scenarios due to computational intractability and latency constraints of dense observation sequences.
- Effective memory requires different granularities at various time scales (e.g., dense visual for immediate dynamics, compressed semantic for long-term task progression), which single-modality memory solutions struggle to provide without significant trade-offs.
- Existing memory approaches often lead to performance degradation in dexterous manipulation or fail to meet real-time inference latency requirements for on-robot deployment.

## Method

- **MEM** factorizes action prediction into a low-level policy using dense, short-term visual memory and a high-level policy managing abstract, long-term semantic memory via ==natural language summaries==.
- An efficient video encoder, utilizing ==space-time separable attention==, processes multi-second horizons of observations for dense short-term visual context while adhering to real-time latency.
- Long-term language memory is managed by the high-level policy, which updates an LLM-generated summary of past semantic events, allowing for ==targeted compression== and retention of relevant information.

## Results

- **MEM-VLA** successfully solved long-horizon tasks like "Recipe Set Up" and "Clean Kitchen," requiring memory over tens of minutes, showing substantial increases in task progress compared to memoryless baselines.
- The system enabled in-context adaptation, improving success rates by **11%** to **62%** on tasks requiring strategy adjustments after prior failures, demonstrating effective learning from past mistakes.
- MEM-VLA matched the state-of-the-art performance of memoryless **π_0.6** VLA on challenging dexterous manipulation tasks, indicating memory benefits were achieved without performance degradation or causal confusion.

## Takeaways

> [!tip] Key Insights
> - Factoring robotic memory into distinct short-term (dense video) and long-term (abstract language) components enables efficient multi-scale information processing tailored to different temporal needs.
> - Leveraging off-the-shelf Large Language Models to generate and compress semantic summaries provides a scalable method for training policies to update and utilize long-term language-based memory.
> - Modifying standard Vision Transformers with space-time separable attention allows for processing dense multi-second video inputs without prohibitive computational cost, preserving fine-grained visual context for real-time control.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of robotic learning, particularly with Vision Language Action Models (VLAs), has seen advancements in generalizable manipulation through training on extensive and diverse robot experiences. However, a persistent challenge in developing autonomous robots for real-world tasks is endowing them with effective memory.

Conventionally, memory in end-to-end robotic learning often involves feeding a sequence of past observations directly into the learned policy. This approach faces limitations as task complexity and duration increase, primarily due to computational intractability and latency constraints for long-horizon tasks. Encoding long sequences of raw observations densely becomes infeasible, necessitating aggressive subsampling or very short memory horizons.

Prior work has explored various methods to integrate memory into robotic policies, including recurrent memory modules, dense histories of observations (often limited by computational cost), latent memory architectures, and heuristics for compression (e.g., proprioceptive memory, 2D point tracks, keyframes, or natural language summaries). However, these single-modality solutions often involve trade-offs:
- Proprioception, point traces, or natural language alone may lose fine-grained spatial information crucial for dexterous manipulation (e.g., correcting a slipped grasp).
- Keyframe-based methods, while compressing observation history, can lose the density required to estimate environment and robot dynamics effectively.
- Directly encoding long sequences of observations quickly exceeds real-time inference latency requirements for on-robot performance.

This research addresses these limitations by proposing a multi-modal memory system. It operates within the context of VLAs, such as the π_0.6 model, which are known for transferring web knowledge to robotic control. The paper argues that an effective memory architecture should represent information at multiple levels of abstraction, combining dense, short-term visual memory with compressed, long-term semantic memory. This approach aims to overcome the computational and representational compromises of single-modality memory systems, enabling VLAs to tackle more complex, long-horizon, and adaptable tasks. It also draws on developments in long-context models in NLP and efficient video encoders, adapting them to the real-time latency demands of robotics.

### 2. Key Objectives and Motivation

The primary objective of this work is to develop and implement an effective memory architecture for long-horizon robotic control that can operate across multiple levels of granularity and time scales, while adhering to real-time latency constraints.

The motivation for this objective stems from several challenges observed in current end-to-end robotic learning:

1. **Intractability of Dense Long-Term Memory**: For complex, multi-stage real-world tasks (e.g., cooking a meal, cleaning a kitchen), a robot's memory needs to span significant durations (tens of minutes). Simply feeding all past observations into a policy quickly becomes computationally prohibitive, limiting the practical application of memory in long-horizon scenarios.
2. **Diverse Memory Requirements at Different Time Scales**: The information required for effective control varies significantly with the time horizon.
 - **Short-Term Memory**: For recent events, dense, image-based memory is crucial for resolving partial observability (e.g., self-occlusion by the robot's arm), understanding immediate dynamics, and enabling rapid, fine-grained in-context adaptation of manipulation strategies (e.g., adjusting a grasp after a failure).
 - **Long-Term Memory**: For semantic events spanning longer periods, highly compressed, abstract memory is sufficient. For instance, remembering completed recipe stages or objects already moved to a specific location requires only a few bits of semantic information, not raw pixel data.
3. **Limitations of Single-Modality Memory Approaches**: Existing memory solutions often rely on a single modality, leading to compromises. Purely proprioceptive or linguistic memories may lack spatial detail, while aggressively compressed visual memories (like keyframes or pooled features) might lose critical temporal or dynamic information. Conversely, dense visual histories are too computationally expensive for long horizons.
4. **Enabling New Capabilities**: An effective memory system is hypothesized to unlock several new capabilities for VLAs, including:
 - **Solving long-horizon tasks**: Tasks requiring memory retention over tens of minutes.
 - **Robustness to partial observability**: Handling situations where relevant objects are temporarily out of view.
 - **In-context adaptation**: Allowing the policy to learn from and correct its own past mistakes by remembering prior actions and their outcomes.
 - **Maintaining performance on dexterous tasks**: Ensuring that the addition of memory does not degrade the policy's ability to perform precise manipulations, a common issue in prior work due to "causal confusion."

By addressing these motivations, the authors aim to develop a robust, efficient, and versatile memory system that can be integrated into existing VLA architectures, thereby extending their capabilities to more complex and realistic robotic applications.

### 3. Methodology and Approach

The proposed system, Multi-Scale Embodied Memory (MEM), integrates multi-modal, long-horizon memory into Vision Language Action Models (VLAs) by combining an efficient video encoder for short-horizon visual memory with a language-based mechanism for long-horizon semantic memory.

**A. Multi-Scale Embodied Memory (MEM) System Overview**

MEM factorizes the action prediction problem into two interacting policies:
1. **Low-Level Policy (π_LL)**: Predicts a chunk of continuous robot actions `a_t:t+H` conditioned on the task goal `g`, a short sequence of observations `o_t-K:t` (where `K` is small), and a subtask instruction `l_t+1`. This policy relies on dense, short-term visual memory.
2. **High-Level Policy (π_HL)**: Generates the subtask instruction `l_t+1` and predicts an updated language memory `m_t+1`. This policy is conditioned on the current observation `o_t`, the previous language memory `m_t`, and the task goal `g`. This policy handles long-term semantic memory.

This factorization allows the low-level policy to focus on immediate execution with dense visual context, while the high-level policy manages the abstract, long-term task progression via language memory, significantly reducing the `K` (number of dense observations) required by the low-level policy compared to a monolithic approach.

**B. Language Memory for Long-Term Memory**

The language memory `m_t` is a natural language summary of past semantic events relevant to the task. The high-level policy (π_HL) is trained to update this summary from `m_t` to `m_t+1` based on current observations and the task goal. This explicit memory update mechanism allows the model to decide what information to retain.

- **Training Data Generation**: To train π_HL, a pipeline generates training data for `m_t` to `m_t+1` transitions. Given a robot episode with subtask language annotations (`l_0:T`) and success/failure indicators, an off-the-shelf pre-trained Large Language Model (LLM) is prompted to summarize relevant information from previous subtasks that are still pertinent for future execution. This LLM-generated output serves as the ground truth for `m_t+1`.
- **Memory Compression**: A key aspect is instructing the LLM to compress or discard irrelevant information. For example, instead of remembering precise attributes of multiple similar objects, it might summarize them generically (e.g., "I placed three bowls"). This compression maintains succinctness, speeds up inference, and helps mitigate train-inference distribution shifts that can occur when policies repeatedly fail and generate redundant subtask instructions.

**C. Video Encoder for Dense Short-Term Visual Memory**

To provide dense, short-horizon visual context without incurring prohibitive computational overhead, MEM employs an efficient video encoder. This encoder processes `o_t-K:t` (multi-second horizon of observations) and compresses them before feeding into the VLM backbone.

- **Architecture**: The video encoder extends standard Vision Transformers (ViTs), typically used as vision encoders in VLAs. It patchifies all images in the input video separately.
- **Space-Time Separable Attention**: To manage the computational complexity of joint attention over numerous patches in both space and time, the architecture modifies the attention mechanism every 4th layer of the ViT. It interleaves layers applying bidirectional spatial attention (standard in ViTs) with layers that additionally apply causal-temporal attention across observations for the same image patch. This factorization reduces the computational complexity from O(n^2 K^2) to O(K n^2 + n K^2), where `n` is the number of spatial patches and `K` is the number of timesteps.
- **Token Compression**: After processing, the encoder only passes the representation computed for the *current* timestep onwards to the VLA transformer backbone, dropping tokens from past timesteps. This ensures the number of tokens passed to the VLA backbone matches that of single-timestep VLAs without memory, while the temporal information is implicitly incorporated into the current observation's representation.
- **Parameter Efficiency and Initialization**: The video encoder does not introduce new learnable parameters compared to standard single-image ViTs. It only modifies the attention pattern and adds a fixed sinusoidal temporal position encoding. This allows initialization from pre-trained ViT weights of any VLM, with the `e(0)=0` boundary condition ensuring exact matching for `K=1` (single-image input).

**D. Integrating MEM into the π_0.6 VLA**

MEM is integrated into the π_0.6 VLA, which is initialized from a pre-trained Gemma3-4B VLM.

- **Action Expert**: The model is trained with discrete FAST action token prediction and a flow-matching action expert (860M parameters), with gradients not flowing from the action expert into the VLM backbone.
- **Input Resolution**: Uses 448x448 px per camera stream, with up to four camera streams.
- **Proprioceptive State**: Past proprioceptive states (e.g., joint angles) are represented as continuous state embeddings, projected into the backbone embedding space with a linear projection, generating `K` proprioceptive state tokens for `K` observations.
- **Pre-training and Post-training**: π_0.6-MEM is pre-trained on a diverse data mixture including teleoperated robot demonstrations, policy rollouts, human corrections, vision-language tasks, and video-language tasks (e.g., video captioning). During pre-training, it uses six observations (five past, one current) with a one-second stride. During post-training, the observation horizon can be flexibly expanded (up to 18 frames, 54 seconds).
- **Real-time Inference**: On-robot experiments utilize either inference-time real-time chunking (RTC) or training-time RTC for asynchronous real-time inference, ensuring latency constraints are met.

### 4. Main Findings and Results

The experimental evaluation aimed to assess MEM's capability for long-horizon tasks, in-context adaptation, and comparative performance against existing memory approaches and memoryless VLAs.

**A. MEM Solves Tasks Requiring Long-Horizon Memory**

- **Tasks**: Evaluated on "Recipe Set Up" (fetching ingredients for a recipe, remembering assembled items, closing appliances, up to 15 minutes) and "Clean Kitchen" (wiping, storing, washing, remembering cleaned surfaces and steps).
- **Results**: Figure 6 shows that without memory (π_0.6 No Memory), policies struggle significantly on these tasks. π_0.6-MEM demonstrates a substantial increase in task progress, effectively leveraging memory for both short- and long-horizon requirements.
- **Ablation Study**:
 - Removing short-horizon video memory led to issues like getting stuck (e.g., not knowing how long a plate has been washed).
 - Removing long-horizon language memory hindered tracking semantic events (e.g., recipe steps, closing doors). Both components were found to be essential.
 - A "Naive Text + Video Memory" ablation (concatenating all past subtask instructions without compression) performed significantly worse than MEM's model-predicted summaries. This was attributed to large train-inference distribution shifts, as failed attempts during inference caused repetitive subtask instructions, which the model struggled to process without semantic compression. MEM's compression mechanism mitigated this by only updating memory upon successful subtask completion.

**B. In-Context Adaptation of Manipulation Strategies**

- **Tasks**: "Pick Up Chopstick" (out-of-distribution table height leading to mis-grasps) and "Open Fridge" (unclear door opening direction). These tasks were designed to test adaptation to past failures.
- **Methodology**: Targeted human feedback (correction demonstrations after policy failure) was used to finetune both MEM-VLA and a memoryless π_0.6 policy.
- **Results**: Figure 7 indicates that MEM-VLA with memory was more effective at leveraging corrections, showing significant improvements in success rate (+11% for chopstick, +62% for fridge). The memoryless policy, lacking context of prior attempts, could not intelligently adjust its strategy. This demonstrates MEM's ability to enable in-context adaptation.

**C. Analysis Experiments**

- **Core Memory Capabilities (Figure 8)**:
 - **Tasks**: "Swap 3 Mugs" (sequential placement and removal), "Find Object" (remembering hidden object location), "Unpack Groceries" (remembering remaining items in bag), "Scoop Coffee" (counting scoops), "Grilled Cheese" (timing, multi-stage process), "Window Cleaning" (spatial memory of wiped areas).
 - **Comparisons**:
 - **No Memory (π_0.6)**: Struggled significantly, often resorting to random chance on memory-dependent tasks.
 - **Pool Memory**: Compressed all past observations into a single "memory token" via average pooling. Performed better than no memory but struggled with longer-term memory tasks (e.g., remembering multiple mug positions or remaining items in a bag) due to aggressive compression.
 - **Proprio Memory**: Conditioned only on low-dimensional robot states. Effective for tasks requiring self-state memory, but poor when environment state memory was critical (e.g., object location).
 - **MEM VLA (Ours)**: Achieved strong performance across all tested core memory capabilities, reliably handling partial observability, counting, and visual memory.
- **Impact of Pre-training (Figure 9)**:
 - **Comparison**: "Ours" (pre-trained with MEM) vs. "Ours (post-train only)" (memory introduced only during post-training on target task).
 - **Results**: Pre-training MEM on a diverse mixture of robot and non-robot video data significantly enhanced its ability to leverage memory, even when the memory horizon was expanded in post-training. The "post-train only" version performed substantially worse, highlighting the importance of developing memory capabilities during large-scale pre-training.
- **Dexterous Manipulation Tasks (Figure 10)**:
 - **Tasks**: "Table Bussing," "Shirt Folding," "Clean Up Counter," "Make Bed," "Dishes to Sink," "Batch Folding," "Box Building." These tasks primarily test manipulation skill rather than long-term memory.
 - **Results**: MEM-VLA not only utilized memory effectively where needed but also matched the state-of-the-art performance of the memoryless π_0.6 VLA on these challenging dexterous manipulation tasks. This suggests that MEM did not introduce performance degradation often associated with memory in prior work (e.g., due to causal confusion). The authors attribute this to their diverse pre-training data, which contained varying optimality, speed, and control frequency, preventing spurious correlations in the video encoder.

### 5. Significance and Potential Impact

The development of Multi-Scale Embodied Memory (MEM) presents a significant advancement in equipping Vision Language Action Models (VLAs) with robust and efficient memory capabilities, addressing limitations of prior single-modality or short-horizon approaches.

**Key Contributions and Significance:**

- **Enabling Long-Horizon Task Execution**: MEM allows VLAs to successfully perform complex, multi-stage tasks that require retaining memory for durations up to fifteen minutes, such as cleaning an entire kitchen or preparing a multi-step recipe. This extends the operational horizon of robotic policies beyond previously demonstrated capabilities.
- **Multi-Modal Memory for Granularity and Efficiency**: The core insight of combining short-horizon, dense video-based memory with long-horizon, compressed language-based memory is demonstrated to be effective. This multi-modal approach addresses the diverse representational needs of different memory timescales, enabling both fine-grained adaptation and high-level semantic tracking.
- **Computational Efficiency**: The efficient video encoder architecture for short-term memory allows for processing multiple seconds of dense visual observations while staying within critical real-time inference latency thresholds. This is crucial for practical on-robot deployment. The language-based memory's compression further contributes to efficiency for long-term context.
- **In-Context Adaptation and Robustness**: MEM enables policies to intelligently adapt manipulation strategies in-context based on recent failures, as demonstrated in tasks requiring adjustments to grasp height or door-opening direction. It also improves resilience to partial observability by remembering hidden object locations or task states.
- **Maintenance of State-of-the-Art Dexterity**: Importantly, MEM achieves these memory benefits without degrading performance on challenging dexterous manipulation tasks, matching the performance of state-of-the-art memoryless VLAs. This indicates that the proposed memory system avoids common pitfalls like "causal confusion" by leveraging diverse pre-training data.
- **Foundation for Future Research**: MEM provides a foundation for developing more capable and autonomous robots. Its ability to manage multi-scale memory opens avenues for robots to operate in unstructured, dynamic environments over extended periods.

**Potential Impact:**

- **More Capable Autonomous Systems**: The ability to perform long-horizon tasks and adapt to errors makes robots more autonomous and useful in complex real-world settings, from household chores to industrial applications.
- **Enhanced Human-Robot Interaction**: Robots that remember past events and adapt to situations can engage in more fluid and intuitive interactions with humans, understanding context and anticipating needs over longer interactions.
- **Advancements in Generalist Robotics**: By integrating multi-scale memory into generalist VLAs, this work contributes to the development of more versatile robot policies that can learn from and perform a wide array of tasks.
- **Catalyst for Continual Learning**: The explicit memory management, particularly the language memory, could be a building block for robots that continually learn and accumulate knowledge over weeks, months, or years of deployment, rather than being limited to single episodes or fixed task horizons.

Overall, MEM represents a significant step towards enabling robots to operate intelligently and robustly in complex, real-world environments by effectively managing information across diverse temporal and semantic scales.
