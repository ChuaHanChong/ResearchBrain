# Towards Long-horizon Embodied Agents with Tool-Aligned Vision-Language-Action Models

> [!summary] Summary
> Researchers propose the "VLAs-as-Tools" framework to enable Vision-Language-Action (VLA) models to reliably execute long-horizon embodied tasks by reframing them as callable tools for a high-level Vision-Language Model agent. This approach, using a VLA tool-family interface and Tool-Aligned Post-Training (TAPT), demonstrates improved task success rates (e.g., +35.5 points for OpenVLA-OFT on RoboTwin) and enhanced instruction following fidelity in simulated environments.

## Problem

- Current VLA models face a "dual burden" for long-horizon tasks, requiring extensive closed-loop planning and diverse physical operations within a single monolithic policy, which is difficult with current data and model scale.
- End-to-end VLAs exhibit limitations in long-horizon reasoning and planning and can be prone to biases from visual priors or demonstration regularities, overriding explicit language instructions.
- Existing embodied agentic systems, while capable of high-level planning, often rely on less capable, frequently manually specified, or task-specific robotic tools for physical execution.

## Method

- The **VLAs-as-Tools** strategy formalizes VLAs as a family of ==bounded, callable executors== within an embodied agentic control loop, managed by a high-level ==Vision-Language Model (VLM) agent==.
- A ==bidirectional VLA tool-family interface== is established, enabling the VLM agent to send ==discrete invocation messages== to select specific VLA tools and receive ==continuous progress feedback== for efficient, event-triggered replanning.
- ==Tool-Aligned Post-Training (TAPT)== adapts base VLAs to function as reliable tools by structuring training data around bounded invocations and employing ==tool-family residual parameterization==, providing distinct execution paths for each tool while preserving shared representations.

## Results

- The framework improved long-horizon task success rates, with gains such as **+35.5pp** for OpenVLA-OFT on RoboTwin and **+5.2pp** for OpenVLA on LIBERO-Long when compared to standalone SFT baselines.
- Invocation fidelity was substantially enhanced, demonstrating **+34.6pp** in Faithful Rate and **+16.2pp** in Non-biased Rate for OpenVLA-OFT on the LIBERO-CF-Long counterfactual benchmark.
- Agent planning efficiency increased significantly, reducing the number of high-level VLM calls per task from **109.5 to 1.988** for OpenVLA, while achieving effective replanning success rates (e.g., **61.4%** for 
0.5
).

## Takeaways

> [!tip] Key Insights
> - Reframing VLAs as specialized, callable tools within an agentic framework effectively distributes the computational and cognitive burden of long-horizon tasks, allowing high-level planning and low-level execution to be handled by distinct components.
> - Explicit invocation-aligned training through TAPT is critical for improving a VLA's fidelity to instructions, ensuring it faithfully executes commanded subtasks rather than defaulting to visual priors or dataset regularities.
> - Continuous progress feedback from VLA tools to the high-level VLM agent provides a lightweight and efficient mechanism for timely intervention and replanning, significantly reducing the frequency and cost of VLM queries compared to constant monitoring.
