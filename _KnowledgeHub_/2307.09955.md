# XSkill: Cross Embodiment Skill Discovery

> [!summary] Summary
> XSkill enables robots to acquire complex manipulation skills from unlabeled, unaligned human demonstration videos by discovering shared skill representations across different embodiments. This framework allows for one-shot learning of novel tasks through skill composition, achieving up to 70.2% success in simulation and 60% in real-world four-subtask compositions with human video prompts.

## Problem

- Enabling robots to acquire complex skills from readily available human demonstration videos despite significant differences in physical embodiment.
- Developing methods to decompose long-horizon tasks into reusable sub-skills directly from unlabeled human videos without requiring explicit task labels or robot-specific data for skill discovery.
- Allowing robots to generalize to unseen task compositions by leveraging a single human prompt video, without needing additional robot demonstrations or costly reinforcement learning.

## Method

- **XSkill**'s ==self-supervised learning== framework discovers a set of shared ==skill prototypes== from unlabeled and unaligned human and robot manipulation videos, creating a ==cross-embodiment skill representation space==.
- A ==skill-conditioned diffusion policy== is trained on robot teleoperation data to translate these abstract skill representations into concrete robot actions.
- A ==Skill Alignment Transformer (SAT)== enables the robot to compose learned skills for unseen tasks by adaptively aligning its execution with a single human prompt video, accounting for speed differences and potential failures.

## Results

- XSkill successfully learns a disentangled representation where skills executed by human and robot for the same object manipulation cluster together, confirming cross-embodiment alignment.
- The framework achieves **70.2%** success in simulation and **60%** success in real-world four-subtask compositions for unseen tasks, outperforming baselines when using cross-embodiment prompts.
- Ablation studies confirm that both shared skill prototypes (via prototype loss) and the Skill Alignment Transformer (SAT) are critical for robust cross-embodiment generalization and adaptive task execution.

## Takeaways

> [!tip] Key Insights
> - A shared, morphology-invariant skill representation space can be learned from unaligned human and robot videos by focusing on action effects rather than specific embodiments.
> - Decomposing complex tasks into reusable skill prototypes is essential for achieving cross-embodiment transfer and enabling generalization to novel task compositions.
> - An adaptive skill alignment mechanism is crucial for robust execution of human-demonstrated sequences, allowing the robot to handle variations in demonstration speed and recover from execution failures.
