# IterResearch: Rethinking Long-Horizon Agents with Interaction Scaling

> [!summary] Summary
> An iterative deep-research paradigm for LLM agents, IterResearch, is introduced to manage context and information over long-horizon tasks by dynamically reconstructing the workspace and maintaining an evolving report. This approach achieves an average 14.5 percentage point performance improvement across six benchmarks compared to existing open-source agents and demonstrates robust scaling to 2048 interactions.

## Problem

- Current LLM agents for deep research suffer from "context suffocation" as information linearly accumulates, limiting sustained reasoning over long horizons.
- "Noise contamination" occurs when irrelevant or erroneous information from external interactions becomes permanently embedded in the agent's context, hindering subsequent reasoning.
- The prevalent "mono-contextual paradigm" struggles to scale effectively beyond a limited number of interactions, making truly complex, multi-step tasks infeasible.

## Method

- **IterResearch** introduces an ==Iterative Deep-Research== Paradigm, modeling long-horizon tasks as a Markov Decision Process (MDP) that enforces state independence.
- It employs iterative workspace reconstruction at each step, maintaining a strategically compressed "evolving report" as memory while discarding full history to ensure a constant effective context window size.
- Efficiency-Aware Policy Optimization (EAPO) is developed, utilizing discounted reward shaping to incentivize efficient exploration strategies and policy optimization across multi-round trajectories.

## Results

- IterResearch significantly outperformed existing open-source deep-research agents, achieving an average 14.5 percentage point improvement across six challenging benchmarks.
- The agent demonstrated unprecedented interaction scaling, extending to 2048 turns using only a **40K** context length and improving performance on BrowseComp from **3.5%** with 2 turns to **42.5%** with 2048 turns.
- Applying the IterResearch paradigm as a prompting strategy to frontier models (e.g., OpenAI o3) yielded up to 19.2 percentage points improvement over standard ReAct prompting on BrowseComp without explicit training.

## Takeaways

> [!tip] Key Insights
> - The "mono-contextual paradigm" is a fundamental architectural limitation for long-horizon agents; simply expanding context windows does not resolve context suffocation or noise contamination.
> - An active, synthesis-driven "report-based memory" intrinsically linked to the decision process is more effective for sustained reasoning than separate, explicit memory modules.
> - Formulating agent reasoning as an MDP with strategically reconstructed states enables theoretically unbounded exploration, preventing performance degradation with increasing interactions and promoting efficiency.
