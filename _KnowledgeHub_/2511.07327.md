# IterResearch: Rethinking Long-Horizon Agents with Interaction Scaling

> [!summary] Summary
> An iterative deep-research paradigm for LLM agents, IterResearch, is introduced to manage context and information over long-horizon tasks by dynamically reconstructing the workspace and maintaining an evolving report. This approach achieves an average 14.5 percentage point performance improvement across six benchmarks compared to existing open-source agents and demonstrates robust scaling to 2048 interactions.

## Problem

- Current LLM agents for deep research suffer from "context suffocation" as information linearly accumulates, limiting sustained reasoning over long horizons.
- "Noise contamination" occurs when irrelevant or erroneous information from external interactions becomes permanently embedded in the agent's context, hindering subsequent reasoning.
- The prevalent "mono-contextual paradigm" struggles to scale effectively beyond a limited number of interactions, making truly complex, multi-step tasks infeasible.

## Method

- **IterResearch** introduces an ==Iterative Deep-Research== Paradigm, modeling long-horizon tasks as a Markov Decision Process (MDP) that enforces state independence.
- It employs iterative workspace reconstruction at each step, maintaining a strategically compressed "evolving report" as memory while discarding full history to ensure a constant effective context window size.
- Efficiency-Aware Policy Optimization (EAPO) is developed, utilizing discounted reward shaping to incentivize efficient exploration strategies and policy optimization across multi-round trajectories.

## Results

- IterResearch significantly outperformed existing open-source deep-research agents, achieving an average 14.5 percentage point improvement across six challenging benchmarks.
- The agent demonstrated unprecedented interaction scaling, extending to 2048 turns using only a **40K** context length and improving performance on BrowseComp from **3.5%** with 2 turns to **42.5%** with 2048 turns.
- Applying the IterResearch paradigm as a prompting strategy to frontier models (e.g., OpenAI o3) yielded up to 19.2 percentage points improvement over standard ReAct prompting on BrowseComp without explicit training.

## Takeaways

> [!tip] Key Insights
> - The "mono-contextual paradigm" is a fundamental architectural limitation for long-horizon agents; simply expanding context windows does not resolve context suffocation or noise contamination.
> - An active, synthesis-driven "report-based memory" intrinsically linked to the decision process is more effective for sustained reasoning than separate, explicit memory modules.
> - Formulating agent reasoning as an MDP with strategically reconstructed states enables theoretically unbounded exploration, preventing performance degradation with increasing interactions and promoting efficiency.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This work is positioned at the forefront of the rapidly evolving field of Large Language Model (LLM) agents, particularly those designed for "deep research" or "long-horizon" tasks. These agents aim to move beyond static information retrieval to autonomously construct knowledge through dynamic reasoning and interaction with external environments, such as the web.

The paper directly addresses fundamental limitations prevalent in current LLM agent designs, which it terms the "mono-contextual paradigm." In this paradigm, agents accumulate all retrieved information and intermediate reasoning steps into a single, continuously expanding context window. While straightforward, this approach leads to two critical problems:
1. **Context Suffocation:** As the context window fills, the available reasoning space for the LLM shrinks, forcing increasingly constrained and potentially superficial conclusions.
2. **Noise Contamination:** Irrelevant information from web searches or early exploration errors becomes permanently embedded in the context, diluting signal quality and leading to cascading interference throughout the reasoning process.

IterResearch distinguishes itself from prior work by proposing a paradigm shift. While acknowledging the remarkable capabilities of frontier proprietary systems (e.g., OpenAI Deep Research, Google Gemini Deep Research, Perplexity Research, xAI Grok3-ResearchSearch, MoonshotAI Kimi-Researcher) and recent open-source agents (e.g., WebThinker, WebSailor, MiroThinker), the authors argue that these systems largely operate under the mono-contextual paradigm, and thus suffer from its inherent scaling limitations.

The paper draws a clear distinction from traditional Retrieval-Augmented Generation (RAG) by emphasizing dynamic, multi-step exploration in real-world environments, rather than static knowledge bases. It also carefully situates its approach relative to other memory-centric LLM research. Unlike systems that focus on explicit memory modules or databases (e.g., MemoryLLM, MEM1, Memory-R1, MemAgent, MemOS), IterResearch integrates memory via an "evolving report" directly within a Markovian workspace reconstruction. This design eliminates the overhead of separate memory management and ensures memory evolution is intrinsically aligned with the research trajectory.

Furthermore, the authors note a "convergent evolution" with similar iterative paradigms emerging in other domains, such as algorithmic discovery with AlphaEvolve. This parallel suggests that iterative synthesis with an evolving report might be a fundamental architectural solution for tackling complex, long-horizon tasks across diverse AI applications, solidifying IterResearch's claim as a general and advanced framework.

### 2. Key Objectives and Motivation

The overarching objective of this research is to **reimagine how autonomous agents maintain sustained reasoning capacity to effectively tackle long-horizon, complex tasks** that require extensive and dynamic interaction with external information sources.

The motivation for IterResearch stems directly from the critical shortcomings of the prevailing mono-contextual paradigm in deep-research agents:
- **To overcome Context Suffocation:** Existing methods fail on long-horizon tasks because the constant linear accumulation of information quickly exhausts the LLM's finite context window. This limits the agent's ability to engage in prolonged, in-depth reasoning, leading to premature termination or shallow analyses. IterResearch aims to solve this by providing a mechanism for theoretically unbounded exploration.
- **To mitigate Noise Contamination:** In real-world web environments, retrieved information often contains irrelevant or erroneous details. When all information is permanently stored, these "noise" elements can continuously interfere with subsequent reasoning steps, leading to misguided exploration and incorrect conclusions. The paper seeks to introduce a way to strategically filter out noise.
- **To enable true Interaction Scaling:** Current agents struggle to perform well beyond a certain number of interactions. A key motivation is to develop an architecture that can gracefully scale to hundreds or even thousands of interactions, unlocking the potential for tackling problems that demand genuinely extensive information gathering and synthesis.
- **To train efficient exploration strategies:** Beyond merely enabling deep exploration, the motivation includes training agents to be *efficient* explorers, achieving correct answers with minimal, focused interactions, thus reducing computational costs and improving practical utility.

In essence, the paper aims to provide a principled, architecturally sound solution—the Iterative Deep-Research Paradigm—to replace the flawed linear accumulation approach, thereby unlocking the full potential of LLM agents for complex, real-world research.

### 3. Methodology and Approach

IterResearch introduces a novel **Iterative Deep-Research Paradigm** that models long-horizon research as a Markov Decision Process (MDP) and employs a strategic workspace reconstruction mechanism.

#### 3.1. MDP-Inspired Formulation

The core of IterResearch is its MDP formalism defined by ⟨S, D, E, T, R⟩, which enforces state independence by separating internal thought updates from external interactions.
- **State Space (S):** Unlike mono-contextual methods, each state $s_t$ is a *strategically reconstructed workspace*. It contains only the constant question ($q$), an **evolving report ($M_t$)** acting as a compressed memory of validated findings, and the immediate context from the previous step ($\{a_{t-1}, TR_{t-1}\}$). This design ensures that the state size remains approximately O(1), independent of trajectory length.
- **Decision Space (D):** At each state, the agent's policy ($\pi$) generates a composite decision $d_t = [\text{Think}_t, M_{t+1}, a_t]$. Here, $\text{Think}_t$ is the internal reasoning, $M_{t+1}$ is an *active memory update generated by the LLM itself*, and $a_t$ is the external action (tool call or final answer).
- **Environment (E) and Reward (R):** The environment executes action $a_t$ and returns a response $TR_t$. The reward $R(s_t, a_t)$ is binary: 1 for a correct final answer, 0 otherwise.
- **Transition Function (T):** This is the crucial element: $s_{t+1} = T(s_t, d_t, TR_t) = (q, M_{t+1}, \{a_t, TR_t\})$. The transition function explicitly *reconstructs* the workspace, discarding the full history and ensuring the next state depends only on the current state (via $d_t$) and immediate environmental feedback.

#### 3.2. Iterative Workspace Reconstruction

This mechanism is the cornerstone of the paradigm. Instead of linearly accumulating information, IterResearch maintains a bounded workspace by:
- **Selective Compression:** The LLM's decision process naturally includes generating $M_{t+1}$, which synthesizes all critical findings from previous steps while filtering out noise and irrelevant details. This leverages the LLM's inherent ability for summarization and relevance filtering.
- **Constant Complexity:** By reconstructing the workspace at each step, the model's effective context window size remains constant, regardless of the number of interactions. This prevents context suffocation and noise contamination, enabling theoretically unbounded exploration.

#### 3.3. Efficiency-Aware Policy Optimization (EAPO)

To effectively train agents within this iterative paradigm, EAPO is introduced:
- **Discounted Reward Shaping for Efficiency:** Standard geometric discounting is adapted. For a terminal reward $R_T$, the reward at step $t$ is $r_t = \gamma^{T-t} \cdot R_T$, where $T$ is the terminal step and $\gamma \in (0,1)$ is the discount factor. This creates an implicit efficiency pressure, rewarding shorter, successful trajectories more highly than longer ones, even if both achieve the correct answer. This addresses the sparse reward problem and incentivizes focused exploration.
- **Policy Optimization with Multi-Round Trajectories:** The iterative paradigm naturally decomposes each trajectory into multiple independent training samples (one per round). To handle the variable sample counts in distributed training, adaptive downsampling is used, reducing the training corpus to the largest multiple of the data parallel size while minimizing data loss. The optimization objective is based on a modified Group Sequence Policy Optimization (GSPO) algorithm.

#### 3.4. Tool Environment and Implementation Details

- **Tools:** IterResearch utilizes four robust tools: Google Search, Google Scholar, Visit (a web browser with goal-oriented summarization, powered by Jina Reader for content extraction), and a secure Python Interpreter (using Code Sandbox). These tools cover comprehensive information gathering, academic research, content processing, and computational analysis.
- **Backbone Model:** Qwen3-30B-A3B (a 30 billion parameter model from Alibaba) is used as the base LLM.
- **Training Process:** A two-stage process is employed:
 1. **Supervised Fine-tuning (SFT):** Rejection Sampling Fine-Tuning (RFT) is applied using 110K synthesized trajectories (from Qwen3-235B-A22B) to instill the iterative deep-research paradigm capabilities.
 2. **Reinforcement Learning (RL):** EAPO is applied. A crucial step involves "difficulty calibration" and "learning zone selection" of training questions (20-60% success rate with SFT checkpoint) to ensure optimal learning signals.
- **Maximum Round Settings:** Training is constrained to $T_{max} = 32$ to promote efficiency, but inference allows adaptive $T_{max}$ values, going up to 256 for complex benchmarks like BrowseComp, demonstrating the paradigm's extrapolation capability.

### 4. Main Findings and Results

The experimental results overwhelmingly support the effectiveness and transformative potential of IterResearch:

- **Superior Performance against Open-Source Agents:** IterResearch significantly outperforms all existing open-source deep-research agents, achieving an average improvement of **14.5 percentage points (pp)** across six challenging benchmarks (Humanity's Last Exam, BrowseComp, BrowseComp-zh, GAIA, Xbench-DeepSearch, SEAL-0).
- **Competitive with Frontier Proprietary Systems:** Remarkably, IterResearch closes the performance gap with frontier proprietary deep-research systems, even surpassing some (e.g., OpenAI's DeepResearch on HLE and BrowseComp-zh) and achieving comparable results on others (BrowseComp and GAIA).
- **Validation of Core Design Principles:** Consistent improvements across diverse benchmarks—from information-seeking (BrowseComp) to complex reasoning (HLE, GAIA)—validate that workspace reconstruction effectively addresses context suffocation and noise contamination.
- **Ablation Studies:**
 - **EAPO's Efficiency:** EAPO is shown to reduce average interactions by 5.7% compared to standard GSPO while maintaining or improving accuracy, confirming that geometric discounted rewards successfully incentivize efficient exploration strategies.
 - **Iterative Paradigm's Fundamental Advantage:** When compared against a mono-contextual agent trained on identical data (and even provided a substantially larger context window of 64K tokens vs. IterResearch's 40K), IterResearch consistently outperforms it by an average of **12.6 pp**. This unequivocally confirms that context suffocation is a fundamental limitation of the mono-contextual approach, which simply expanding context cannot resolve.
 - **Cross-Paradigm Knowledge Transfer:** Trajectories generated by IterResearch can significantly enhance mono-contextual agents (average +5.4 pp improvement). This indicates that the iterative paradigm induces superior exploration behaviors that generate high-quality training signals transferable across different agent architectures.
- **Unprecedented Interaction Scaling:** IterResearch demonstrates extreme interaction scaling, extending to **2048 interactions** using only a 40K context length (a feat structurally impossible for mono-contextual approaches). Performance dramatically improves from 3.5% with 2 turns to **42.5% with 2048 turns** on BrowseComp, suggesting that perceived task difficulty may stem from insufficient exploration capacity. The agent also learns intelligent resource allocation, using only ~80 turns on average even with a 2048-turn budget.
- **Effective Prompting Strategy:** Without any training, applying the IterResearch paradigm as a prompting strategy to frontier models (OpenAI o3 and DeepSeek-V3.1) yields substantial improvements over ReAct (the standard mono-contextual prompting paradigm), achieving up to **19.2 pp improvement on BrowseComp**. This highlights IterResearch as a model-agnostic solution for long-horizon reasoning.
- **Computational Efficiency:** The theoretical analysis and empirical results confirm IterResearch's constant O((|M|+|TR|)^2) attention computation per round, ensuring consistent computational efficiency regardless of research depth, in stark contrast to the quadratic growth of mono-contextual methods.
- **Extrapolation Beyond Training Horizon:** Agents trained with a maximum of 32 rounds can extrapolate to 2048 rounds during inference, a 64x extrapolation factor, achieving significant performance gains without degradation. This is attributed to the position-agnostic MDP formulation and the scale-invariant report-based memory.

### 5. Significance and Potential Impact

The IterResearch paper makes several significant contributions with far-reaching potential impacts on the field of AI agents and beyond:

- **Fundamental Paradigm Shift for Long-Horizon Reasoning:** The work establishes "iteration with strategic synthesis" as a more effective and scalable paradigm for long-horizon reasoning compared to the prevalent "mono-contextual accumulation." This fundamentally rethinks how LLM agents should manage information and context over extended interactions.
- **Unlocking New Levels of Agent Capability:** By overcoming context suffocation and noise contamination, IterResearch enables agents to tackle genuinely complex, open-ended research tasks that require extensive, sustained exploration. The unprecedented interaction scaling to 2048 turns demonstrates a capability previously thought infeasible for LLM-based agents, potentially expanding the scope of problems AI can autonomously address.
- **State-of-the-Art Open-Source Performance:** Achieving substantial improvements over existing open-source agents and bridging the gap with frontier proprietary systems significantly elevates the capabilities of publicly accessible AI research tools. This can accelerate innovation within the open-source community by providing a more robust foundation.
- **Versatile and Model-Agnostic Solution:** IterResearch's effectiveness both as a trained agent and as a prompting strategy for frontier models (without training) makes it highly versatile. This model-agnostic nature suggests that the underlying iterative paradigm provides a general cognitive architecture that improves how *any* powerful LLM can approach long-horizon tasks.
- **Efficiency and Resource Optimization:** The Efficiency-Aware Policy Optimization (EAPO) is a crucial development for practical deployment. By incentivizing efficient exploration, it can lead to reduced computational costs, lower API usage, and faster task completion in real-world scenarios, making complex AI agents more economically viable.
- **Implications for Future Research:**
 - **Memory in LLMs:** The paper offers a new perspective on memory management, advocating for active, synthesis-driven "report-based memory" as intrinsically linked to the decision process rather than separate memory modules.
 - **Reinforcement Learning for Agents:** EAPO provides a robust training strategy for complex, sparse-reward agent environments, particularly for those with iterative, variable-length trajectories.
 - **Understanding Task Complexity:** The findings suggest that the perceived difficulty of some long-horizon tasks might be less about inherent logical complexity and more about the architectural limitations of current agents to conduct sufficient, sustained exploration.
- **Real-World Applications:** The advancements in deep-research agents have direct implications for diverse applications requiring complex information gathering and synthesis, such as scientific discovery, market research, investigative journalism, and advanced problem-solving in various domains.

In conclusion, IterResearch represents a significant step forward in the development of autonomous AI agents. By challenging the traditional mono-contextual paradigm and introducing a robust iterative framework, it paves the way for more capable, efficient, and scalable agents poised to tackle the most challenging long-horizon reasoning tasks across numerous real-world applications.
