# NaVILA: Legged Robot Vision-Language-Action Model for Navigation

> [!summary] Summary
> NaVILA introduces a two-level Vision-Language-Action model that enables legged robots to navigate complex real-world environments by interpreting natural language instructions, leveraging training from human touring videos. The framework demonstrates high success rates on physical quadrupedal and humanoid robots and achieves substantial performance gains on established Vision-Language Navigation benchmarks.

## Problem

- Translating high-level natural language navigation instructions into precise low-level joint actions for complex, dynamic legged robots in real-world environments.
- Generalization limitations of existing Vision-Language-Action (VLA) models, which often struggle to adapt across robot platforms or perform robustly in diverse, unseen real-world conditions.
- Inefficiencies and environmental vulnerabilities (e.g., strong sunlight affecting depth sensors) in training robust locomotion policies for legged robots.

## Method

- A two-level framework decoupling high-level VLA (==Vision-Language-Action==) reasoning from low-level visual locomotion execution, using mid-level language instructions as an intermediate.
- A high-level VLA component (based on VILA) trained on a diverse dataset including novel human touring videos, augmented simulation data, and auxiliary spatial reasoning tasks.
- A low-level visual locomotion policy developed using single-stage reinforcement learning in Isaac Sim, incorporating LiDAR-based height maps for robust terrain perception.

## Results

- Achieved over a **17%** improvement in success rate on R2R-CE and outperformed prior state-of-the-art models on RxR-CE using only single-view RGB input.
- Demonstrated an **88%** overall success rate on real-world navigation tasks with a Unitree Go2 quadruped and generalized the VLA model to a Booster T1 humanoid robot without retraining.
- Introduced VLN-CE-Isaac, a new high-fidelity simulation benchmark for legged robot navigation, showing a 14-**21%** improvement in success rate with vision-based policies over blind policies.

## Takeaways

> [!tip] Key Insights
> - Decoupling high-level vision-language understanding from low-level robot control through intermediate natural language commands enhances VLA generalizability across different robot platforms.
> - Training the VLA model directly on real-world human touring videos, leveraging metric-pose estimation, improves generalization capabilities for continuous navigation.
> - A single-stage reinforcement learning approach with LiDAR-based height maps provides a robust and efficient method for low-level visual locomotion, handling complex terrains and obstacles.
