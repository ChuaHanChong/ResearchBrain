# Koopman global linearization of contact dynamics for robot locomotion and manipulation enables elaborate control

> [!summary] Summary
> Researchers from MIT developed a Control-Coherent Koopman Model Predictive Control (CCK-MPC) framework that globally linearizes robot contact dynamics using causal, continuous contact models. This framework enables real-time convex optimization for contact-rich tasks, allowing robots to autonomously discover elaborate strategies for legged locomotion and dynamic manipulation while achieving superior performance over traditional local linearization methods.

## Problem

- Controlling robots in dynamic contact poses a challenge due to the switching nature of system dynamics at contact boundaries, which leads to non-convex optimization problems for predictive controllers.
- Real-time control with Model Predictive Control (MPC) becomes computationally intensive and difficult to implement on hardware for contact-rich tasks.
- Prior approaches often rely on simplifications like local linearization, pre-defined contact mode sequences, or reduced dynamics, which limit dynamic exploration, adaptability, and the discovery of optimal multi-contact strategies.

## Method

- A Control-Coherent ==Koopman== Model Predictive Control (CCK-MPC) framework was developed to transform piecewise-nonlinear contact dynamics into a single, globally linear model in a higher-dimensional embedding space.
- Discontinuities in contact dynamics are addressed by employing causal physical models with viscoelastic contact compliance, ensuring continuity of momentum and state transitions suitable for Koopman operator application.
- The CCK framework extends Koopman theory to non-autonomous systems, directly incorporating control inputs into the lifted linear system, thereby enabling convex Model Predictive Control.

## Results

- The CCK-MPC controller enabled a rimless wheel to discover emergent rocking motions for locomotion and consistently achieved continuous forward rolling, significantly outperforming local linearization and Dynamic Mode Decomposition with Control (DMDc).
- For dynamic pushing, the system autonomously generated optimal paths and strategic behaviors (e.g., continuous pushing vs. intermittent shoving) and demonstrated robustness to significant modeling errors, such as variations in floor friction.
- The controller achieved real-time performance with a mean runtime of approximately 5.2ms (~190Hz) on consumer-grade hardware for the dynamic pushing task, demonstrating its practical applicability for reactive control.

## Takeaways

> [!tip] Key Insights
> - Using causal, compliant physical models (e.g., viscoelastic contact) is fundamental for resolving causal conflicts and ensuring the continuity required for valid Koopman operator application to contact-rich systems.
> - The CCK framework provides a unified, globally linear representation of segmented dynamics, allowing MPC to proactively predict and optimize control strategies across multiple contact mode changes over a given time horizon.
> - Transforming non-convex contact problems into convex optimizations via Koopman linearization facilitates real-time computation and enables robots to autonomously discover complex, elaborate control strategies without explicit pre-programming.
