# Mobile ALOHA: Learning Bimanual Mobile Manipulation with Low-Cost Whole-Body Teleoperation

> [!summary] Summary
> Researchers at Stanford University developed Mobile ALOHA, a low-cost mobile bimanual manipulation system that learns complex whole-body tasks from human teleoperated demonstrations. The system combines an intuitive whole-body teleoperation interface with a co-training methodology, allowing it to achieve high success rates across diverse tasks like cooking and cleaning with improved data efficiency by leveraging existing stationary manipulation datasets.

## Problem

- Integrating mobile bases with dexterous manipulation arms remains challenging due to the complex coordination required between mobility and manipulation.
- Existing mobile manipulation systems are often high-cost, limiting accessibility for research and development.
- Collecting sufficient data for learning complex mobile manipulation policies is resource-intensive and difficult.

## Method

- A low-cost, open-source hardware system, **Mobile ALOHA**, integrates bimanual ALOHA arms with an AgileX Tracer mobile base, featuring 16 degrees of freedom for ==whole-body control==.
- An intuitive ==whole-body teleoperation== interface allows human operators to simultaneously control both the robot's arms and its mobile base for data collection.
- An ==imitation learning== approach (==behavior cloning==) is used to train policies on human demonstrations, augmented by a ==co-training methodology== that combines mobile data with existing stationary bimanual manipulation data.

## Results

- **Mobile ALOHA** achieved high success rates (**over 90%** for some tasks) across **seven** diverse bimanual mobile manipulation tasks, including 'Wipe Wine', 'Cook Shrimp', and 'Call Elevator'.
- Co-training with static ALOHA data substantially improved performance, with success rates increasing from **20% to 40%** for the 'Wipe Wine' task with **25 demonstrations**, and from **50% to 95%** with **50 demonstrations**, demonstrating improved data efficiency (**40-60% fewer demonstrations** needed).
- User studies showed that novice users could rapidly learn the whole-body teleoperation interface, approaching expert-level performance within **five trials**.

## Takeaways

> [!tip] Key Insights
> - Whole-body teleoperation, enabled by tethering the operator's waist to the mobile base, provides an intuitive and rapid method for collecting human demonstrations that capture complex mobile manipulation coordination.
> - A co-training methodology significantly improves data efficiency and task performance by combining new mobile manipulation demonstrations with existing static bimanual manipulation datasets, effectively leveraging prior knowledge.
> - The system successfully learns to perform a diverse set of complex bimanual mobile manipulation tasks, including cooking, cleaning, and human interaction, from a relatively small number of human demonstrations.
