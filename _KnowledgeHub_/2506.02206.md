# Reinforcement Learning with Data Bootstrapping for Dynamic Subgoal Pursuit in Humanoid Robot Navigation

> [!summary] Summary
> A hierarchical framework enables humanoid robots to navigate cluttered environments by integrating a high-level reinforcement learning planner for dynamic subgoals with a low-level Model Predictive Control for stable gait generation, augmented with data bootstrapping. This system demonstrated superior navigation success rates (93.3% in seen, 89.3% in unseen environments) and more efficient goal-reaching compared to previous model-based and learning-based methods in simulation.

## Problem

- Humanoid robot navigation in complex, cluttered environments faces challenges in balancing computational efficiency with locomotion precision.
- High-dimensional, underactuated dynamics of bipedal robots make stable navigation difficult, with discrepancies between planned and executed paths potentially leading to instability.
- Existing model-based methods struggle with integrating detailed environmental information for real-time computation, while learning-based methods suffer from sample inefficiency and generalization issues for complex bipedal systems.

## Method

- A hierarchical framework is proposed, featuring a high-level ==Reinforcement Learning (RL)== planner that generates dynamic subgoals based on local occupancy maps and robot state.
- A low-level Linear Inverted Pendulum (LIP)-based Model Predictive Control (MPC) controller translates these subgoals into dynamically stable walking gaits.
- A data bootstrapping technique utilizes an expert RRT-LMPC to pre-populate the RL replay buffer, progressively reducing reliance on expert data during training to improve sample efficiency and stability.

## Results

- The proposed "Subgoal Pursuit" method achieved the highest success rates (**93.3%** in testing-seen, **89.3%** in testing-unseen environments) and highest accumulated rewards among all compared methods.
- It demonstrated superior performance over baseline model-based methods (e.g., LMPC, RRT+LMPC) and other learning-based methods (PPO, SAC without demonstration, CQL) in terms of navigation efficiency and goal-reaching time.
- The RL high-level planner operated in real-time (**1.3** ± **0.5** ms), ensuring compatibility with the low-level MPC's real-time gait generation, enabling robust navigation and generalization to unseen environments.

## Takeaways

> [!tip] Key Insights
> - Combining high-level RL for complex environmental decision-making with low-level MPC for dynamic stability effectively addresses the trade-off between computational efficiency and locomotion precision in humanoid navigation.
> - Data bootstrapping from a model-based expert significantly accelerates and stabilizes RL training for complex continuous control tasks, mitigating sample inefficiency without sacrificing adaptability.
> - The proposed reward function and comprehensive state representation for the RL planner enable the robot to learn robust strategies for goal pursuit and obstacle avoidance in cluttered scenarios.
