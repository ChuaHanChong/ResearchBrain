# Task-CoEvolve: Efficient Harness Optimization via Adaptive Validation Task Selection

> [!summary] Summary
> Task-CoEvolve co-evolves validation task selection with iterative harness optimization: it uses variance-weighted sampling to pick tasks near the capability frontier and Horvitz-Thompson-style full-set score estimation from partial evaluations. On text classification it matches full-set search at 7% budget and beats it at 20%; on Terminal-Bench 2.1 it matches full search while cutting evaluation cost 67-80%.

## Problem

- Existing harness optimization methods evaluate the entire fixed validation set at every iteration, making evaluation cost dominate the optimization loop for expensive long-horizon tasks.
- Fixed validation sets are static: tasks every candidate already solves or that none can solve keep consuming budget while giving little discriminative signal as the harness evolves.
- Naive subsampling to cut cost either overfits to one reused subset or, when resampled randomly, yields raw scores that are incomparable across iterations due to differing subset difficulty.

## Method

- ==Variance-weighted task selection==: sampling weight per task combines Bernoulli variance of its historical success rate (peaks near 0.5) with an uncertainty bonus for under-observed tasks and a floor for never-solved tasks.
- **Sampling-aware full-set score estimation**: uses task inclusion probabilities to reweight sampled outcomes, choosing between a ==Hajek estimator== or an ==anchored-difference estimator== depending on whether pool success rates sit near the extremes or near 0.5.
- **Phase-0 initialization** reuses the two starting harnesses' full-validation-set evaluation as prior history, seeding per-task success rates before the first adaptive subset is drawn, at no extra cost.

## Results

- On text classification, **Task-CoEvolve** reaches **47.6%** average accuracy at 7% budget (vs **48.6%** full search) and **49.3%** at 20% budget, surpassing full search's 48.6% while using **16x** fewer samples.
- On Terminal-Bench 2.1, Task-CoEvolve at 20% budget scores **51.7%** average (GPT-5.6 Luna **61.8%**, Qwen3.6 **41.6%**) versus **52.8%** for full search, only about one task out of 89 lower.
- Search cost on Terminal-Bench 2.1 drops **80%** (GPT-5.6 Luna) and **67%** (Qwen3.6) in input tokens, and search time nearly halves, while ablation shows resampling, estimation, and variance-weighting each add incremental gains (**47.2** to **48.2** to **48.8** to **49.3**).

## Takeaways

> [!tip] Key Insights
> - Reusing a fixed validation subset causes overfitting; resampling alone recovers most of the gain, but sampling-aware estimation is needed to make cross-iteration comparisons trustworthy.
> - Evaluation informativeness is a moving target: over 70% of a task pool can sit at uninformative extremes (always/never solved), and this distribution shifts as the harness improves.
> - Reducing evaluation-set size is orthogonal to reducing candidate count, budget savings can compound with other harness-search efficiency techniques rather than substitute for them.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development and deployment of Large Language Model (LLM) agents for real-world tasks often rely heavily on the "harness" – the surrounding code that manages memory, retrieval, and presentation of information to the LLM. Prior research has demonstrated that harness design can significantly impact performance, sometimes yielding up to a six-fold difference on the same benchmark, without altering the underlying LLM weights. Historically, harnesses have been manually designed, a process that is costly and iterative due to the vast design space.

Recently, automated harness optimization has emerged as a field, where meta-level agents iteratively refine harness code based on evaluation feedback. Existing approaches, such as Meta-Harness, typically evaluate each candidate harness on the entire fixed set of validation tasks at every iteration. This strategy, while straightforward, presents two primary limitations: high computational cost, particularly for expensive tasks like long-horizon terminal operations, and a static evaluation process where less discriminative tasks continue to consume budget as the harness evolves.

This work addresses the efficiency limitations of automated harness optimization by focusing on the validation task selection process. It introduces the problem of optimizing which tasks are used for evaluation, a direction orthogonal to other efficiency-focused research that aims to reduce the number of candidate harnesses generated or improve sample efficiency in candidate generation (e.g., DemoEvolve, ShinkaEvolve, TurboEvolve, HarnessCompass). While curriculum learning and adaptive task selection exist for training models, this paper applies adaptive selection to the *evaluation* phase of harness optimization. Furthermore, it differentiates itself from sample-efficient model evaluation techniques (e.g., tinyBenchmarks, AcTracer) by focusing on selecting tasks to discriminate among *evolving* harness candidates rather than estimating the performance of a fixed model. Task-CoEvolve positions itself as a method to reduce the per-candidate evaluation cost, thereby complementing existing efficiency advancements on the search side.

### 2. Key Objectives and Motivation

The central objective of this research is to develop an efficient method for Large Language Model (LLM) harness optimization by adaptively selecting validation tasks. The authors aim to significantly reduce the evaluation cost associated with iterative harness refinement while maintaining or improving the final performance of the optimized harness.

The motivation for this work stems from two key limitations identified in existing automated harness optimization approaches:

1. **High Evaluation Cost:** Current methods typically evaluate every candidate harness on the entire validation task set at each iteration. This "full-set evaluation" strategy incurs substantial computational and time costs. For tasks that are inherently expensive to execute, such as long-horizon terminal tasks requiring dedicated sandbox environments for extended periods, the evaluation process can become the dominant bottleneck in the entire optimization loop. This cost restricts the feasibility of extensive harness search and development.

2. **Static and Inefficient Validation:** As a harness evolves through iterative optimization, its capabilities change. Tasks that were initially challenging may become consistently solvable, and tasks that were initially impossible may remain so. In either case, tasks that are consistently solved or consistently failed by all candidate harnesses provide minimal discriminative signal for ranking and selecting the most promising candidates. Evaluating these "less informative" tasks at every iteration represents an inefficient allocation of evaluation resources, as they contribute little to guiding the optimization process. The static nature of a fixed validation set prevents the optimization process from adapting its focus to the most relevant and challenging tasks at a given stage of harness evolution.

To address these motivations, Task-CoEvolve pursues two specific sub-objectives:
- **Selecting Informative Tasks:** The method must identify and prioritize validation tasks that are most effective at distinguishing between the performance of different candidate harnesses at each iteration. These are typically tasks where candidate harnesses exhibit varying success outcomes, indicating they are near the current "capability frontier" of the evolving harness.
- **Estimating Full-Set Performance from Partial Evaluations:** Since only a subset of tasks is evaluated, a mechanism is required to estimate the overall performance of a harness on the full validation set. This estimation must account for the non-uniform sampling probabilities of tasks to ensure that performance scores are comparable across iterations, even when different subsets are used. This comparability is crucial for reliable candidate selection and for tracking optimization progress.

By achieving these objectives, the authors aim to enable more efficient and scalable automated harness optimization, making the development of robust LLM agents more practical in real-world scenarios.

### 3. Methodology and Approach

Task-CoEvolve proposes a method for efficient harness optimization that co-evolves the validation tasks alongside the harness itself. The approach integrates adaptive task selection with sampling-aware performance estimation.

**Problem Statement:**
The problem is defined for a fixed LLM and a harness `h`. A set of `N` validation tasks `T` is given. `x_t(h)` denotes the average success rate of harness `h` on task `t` over `r` trials. The true performance `S(h)` is the average success rate over all tasks: `S(h) = (1/N) * Σ_{t∈T} x_t(h)`. The goal is to select the harness with the highest `S(h)` among all candidates generated during `K` iterations, under a limited evaluation budget measured by total task executions.

**Review of Meta-Harness (Base Framework):**
Task-CoEvolve builds upon Meta-Harness (Lee et al., 2026), a representative automated harness optimization framework. In Meta-Harness, a meta-agent generates candidate harnesses `h_k` based on past evaluation results. Each `h_k` is evaluated on the *entire* validation set `T`, and its score is recorded. After `K` iterations, the candidate with the highest score is selected. This process incurs `K * N * r` task executions.

**Proposed Approach: Task-CoEvolve:**
Task-CoEvolve aims to reduce evaluation costs by evaluating each candidate on only a subset `S_k ⊂ T` of size `m = ⌈ρN⌉`, where `ρ` is the sampling rate. This reduces executions to `K * m * r`. The method consists of three phases:

- **Phase 0: Initialization:** Before the optimization loop begins, two initial harnesses (zero-shot and few-shot) are evaluated on the full task set `T`. The outcomes from these initial runs are used to establish an initial history of success rates (`p_t`) for each task `t`. These evaluations are considered part of the standard Meta-Harness setup and not an additional cost for Task-CoEvolve.

- **Phase 1: Variance-Weighted Task Selection:** At each iteration `k`, a subset `S_k` of tasks is selected from `T`. The selection criterion is based on the "informativeness" of each task, measured by the Bernoulli variance of its past outcomes. A task is considered more informative if previous harnesses have exhibited varied success/failure outcomes on it (i.e., its success rate `p_t` is closer to 0.5).
 The sampling weight `w_t` for task `t` is defined as:
 `w_t = max(p_t(1 - p_t), ℓ_t) + (λ / √n_t)`
 Where:
 - `p_t` is the mean historical success rate for task `t`.
 - `n_t` is the number of outcomes observed for task `t` in previous iterations.
 - `p_t(1 - p_t)` is the Bernoulli variance.
 - `ℓ_t` is a small positive constant `ℓ` if `p_t = 0` (task never solved), and 0 otherwise. This ensures tasks that are currently unsolvable are not entirely excluded, as they might become solvable later.
 - `λ / √n_t` is a bonus term that gives higher weight to tasks with fewer observations, promoting exploration of under-sampled tasks.
 This weighting scheme results in an adaptive sampling distribution that focuses evaluation on tasks near the capability frontier of the evolving harness.

- **Phase 2: Sampling-Aware Full-Set Estimation:** To ensure fair comparison of candidates evaluated on different subsets, Task-CoEvolve estimates the full-set performance `S(h)` from the sampled tasks. The choice of estimator depends on the characteristics of the task pool, determined by the Phase-0 evaluations:

 - **Hájék Estimation (Equation 3):** Used when task success rates tend to be near 0 or 1 within distinct task pools, and the benchmark can be split into separate pools.
 `S(h) = (Σ_{t∈S_k} x_t(h) / π_t) / (Σ_{t∈S_k} 1 / π_t)`
 Here, `π_t = Pr[t ∈ S_k]` is the inclusion probability of task `t` under the sampling design, estimated via Monte Carlo simulation. This estimator weights each sampled outcome by the inverse of its inclusion probability. This was used for online text classification.

 - **Anchored Difference Estimation (Equation 4):** Used when task success rates are generally near the middle (e.g., 0.5) for the entire pool, or when rare samples with tiny `π_t` could disproportionately influence Hájék estimation.
 `S(h) = (1/N) Σ_{t∈T} p_t + (1/N) Σ_{t∈S_k} (x_t(h) - p_t) / π_t`
 This estimator anchors the score to the historical mean `p_t` for all tasks and adds the weighted deviation from this anchor for sampled tasks. This was used for Terminal-Bench 2.1. The anchor `p_t` is fixed before sampling, ensuring it cancels out in expectation.

- **Phase 3: Final Selection:** After `K` optimization iterations, the candidate harness with the highest estimated full-set score `S(h)` is selected as the final harness. Ties are broken by favoring the candidate from the earliest iteration.

**Hyperparameters:** Key hyperparameters for variance-weighted task selection include `ℓ` (weight floor for tasks never solved, 0.125), `λ` (uncertainty bonus coefficient, 0.025), and Monte Carlo repetitions for `π_t` estimation (4,000). The history window for `p_t` uses all past iterations.

### 4. Main Findings and Results

The efficacy of Task-CoEvolve was evaluated across two distinct settings: online text classification and Terminal-Bench 2.1, with comprehensive experiments quantifying performance and cost reductions.

**Online Text Classification:**
- **Performance at Reduced Budget:** Task-CoEvolve demonstrated performance comparable to, and in some cases surpassing, full-set search (Meta-Harness) at significantly reduced evaluation budgets.
 - At `ρ = 7%` evaluation budget (480 total sample evaluations), Task-CoEvolve achieved an average test accuracy of 47.6% ± 0.9, nearly matching Meta-Harness (Full Search) at 48.6% ± 0.8. This represents a substantial improvement over baselines like Naive (45.2% ± 3.2) and Random-Resample (47.0% ± 2.2).
 - At `ρ = 20%` evaluation budget (1,560 total sample evaluations), Task-CoEvolve achieved an average test accuracy of 49.3% ± 0.8. This result *outperformed* Meta-Harness (Full Search) by approximately 1 percentage point, suggesting that adaptive sampling can mitigate overfitting to a fixed validation set.
- **Efficiency:** With a 7% budget, Task-CoEvolve achieved comparable performance to full-set search while using 16 times fewer samples.

**Terminal-Bench 2.1:**
- **Performance at Reduced Cost:** On this compute-intensive benchmark, Task-CoEvolve at `ρ = 20%` achieved a pass rate of 51.7%, closely matching Meta-Harness (Full Search) at 52.8%. This performance was superior to both Naive (47.2%) and Random-Resample (48.4%) baselines. For GPT-5.6 Luna, Task-CoEvolve achieved 61.8% compared to Full Search's 62.9%. For Qwen3.6-35B-A3B, it achieved 41.6% versus 42.7%.
- **Search Cost and Time Reduction (Table 3):**
 - **Token Usage:** For GPT-5.6 Luna, Task-CoEvolve reduced input token consumption by 80% (from 2,888M to 579M tokens) compared to Full Search. For Qwen3.6-35B-A3B, it reduced input tokens by 67% (from 741M to 246M).
 - **Cost (USD):** For GPT-5.6 Luna, the cost was reduced from $117 to $30.
 - **Time:** Search time was reduced by approximately half, from 22.2 hours to 11.5 hours for GPT-5.6 Luna, and from 38.0 to 20.5 hours for Qwen3.6-35B-A3B. The reduction in time was less pronounced than token usage due to fixed costs of candidate generation and parallel execution.
 - The paper notes that the same 20% evaluation budget can result in different costs for different protocols. Task-CoEvolve, by concentrating evaluation on long-running, discriminative tasks, consumed more tokens per trial than uniform sampling baselines, yet still achieved substantial overall cost reductions compared to full search due to fewer total trials.

**Ablation Study (Table 4):**
- **Contribution of Components:**
 - Random-Resample (uniform subset resampling) alone provided the largest single performance gain (from 47.2% to 48.2% accuracy), indicating that a fixed subset leads to significant overfitting.
 - Adding full-set estimation (`S`-max selection) further improved performance to 48.8%.
 - Incorporating variance-weighted adaptive selection (the full Task-CoEvolve method) yielded the highest average performance of 49.3%.

**Analysis of Sample Discriminability (Table 5):**
- The study showed that in both settings, a large majority (>70%) of validation tasks consistently fell into the "always solved" or "never solved" categories, which provide little discriminative information.
- The distribution of sample difficulty was dynamic; as the harness evolved, the number of "mostly solved" tasks increased, and "nobody solves it" tasks decreased, supporting the need for adaptive task selection.

**Accuracy of Estimated Scores (Table 6):**
- At `ρ = 20%`, the Spearman rank correlation between estimated `S` and true full-validation scores was 0.62, indicating a useful ranking signal. The selected candidate ranked 12th out of 60, within the top fifth.
- At `ρ = 7%`, the rank correlation dropped to 0.13 due to limited sample size, but the selected candidate still ranked 10th out of 60, preventing selection of a poorly performing harness.

**Discovered Harnesses (Appendix D):**
- For online text classification, the selected harness combined two TF-IDF indices (word bigrams and character n-grams) using reciprocal rank fusion for few-shot example retrieval, and applied a diversity penalty to prevent a single label from dominating the context. This allowed it to adapt to different types of similarity across datasets.
- For Terminal-Bench 2.1, the harness adapted the post-command wait time. Instead of a fixed sleep, it would return as soon as the shell prompt reappeared after a command-executing keystroke, saving time in scenarios where the command finished quickly.

### 5. Significance and Potential Impact

This work introduces a novel dimension to the efficiency of automated harness optimization by focusing on the adaptive selection of validation tasks, rather than solely on the generation or refinement of candidate harnesses. The proposed Task-CoEvolve method demonstrates that significant reductions in evaluation cost can be achieved without compromising, and in some cases, even improving, the final performance of the optimized harness.

The **significance** of Task-CoEvolve lies in several key areas:
1. **Cost Reduction:** By reducing evaluation costs by 67-80% (in terms of tokens and compute) on demanding benchmarks like Terminal-Bench 2.1 and by 16-fold in terms of sample evaluations on text classification, Task-CoEvolve makes automated harness optimization more economically viable and accessible. This is particularly relevant for expensive, long-horizon tasks.
2. **Performance Maintenance/Improvement:** The method consistently matches the performance of full-set search and, in some settings (online text classification at 20% budget), even surpasses it. This suggests that adaptive sampling can mitigate overfitting to a fixed validation set, leading to more robust and generalizable harnesses.
3. **Adaptive Resource Allocation:** The core innovation of co-evolving validation tasks with the harness, by focusing evaluation on tasks that are most discriminative (near the "capability frontier"), represents a more intelligent use of limited computational resources. This dynamic approach is more efficient than static evaluation sets, which waste budget on tasks that no longer provide useful signal.
4. **Complementary Efficiency:** Task-CoEvolve addresses an orthogonal source of cost (evaluation per candidate) compared to prior work focusing on search efficiency (number of candidates). This makes it potentially combinable with other advancements to achieve even greater overall optimization efficiency.

The **potential impact** of this work is substantial for the development and deployment of LLM agents:
- **Accelerated Agent Development:** Researchers and developers can iterate on harness designs more rapidly and cost-effectively, fostering faster innovation in LLM agent capabilities.
- **Broader Application of Automated Optimization:** The reduced cost barriers could enable automated harness optimization to be applied to a wider range of complex, real-world tasks where full-set evaluation is prohibitively expensive.
- **Improved Harness Quality:** By reducing overfitting and focusing on informative tasks, Task-CoEvolve may lead to the discovery of more robust and generalizable harness designs.
- **Foundation for Future Research:** This work establishes a new problem setting—optimizing the evaluation process itself—which can inspire further research into adaptive and intelligent evaluation strategies for evolving AI systems.

A **limitation** acknowledged by the authors is that Task-CoEvolve currently fixes the number of tasks evaluated per candidate *before* seeing any results. This prevents dynamic adjustments such as early stopping for clearly inferior candidates or increased evaluation for hard-to-distinguish candidates. **Future work** is identified to address this limitation by dynamically deciding the number of tasks to evaluate during the evaluation process itself.
