# X-Fusion: Introducing New Modality to Frozen Large Language Models

> [!summary] Summary
> A dual-tower architecture enables integration of visual capabilities into frozen Large Language Models by introducing separate modality-specific weights, achieving strong performance on both image-to-text and text-to-image tasks while preserving the LLM's original language capabilities through parameter isolation.

## Problem

- Existing approaches to adding visual capabilities to LLMs either require expensive training from scratch or risk degrading language abilities through fine-tuning
- Cross-modal reasoning and error accumulation challenges in current hybrid approaches combining LLMs with image generation models

## Method

- ==Dual-tower architecture== with frozen LLM "text tower" and trainable "vision tower" with ==modality-specific weights==
- ==Feature alignment== at intermediate processing levels between towers while maintaining parameter isolation
- Optional ==X-Fuse operation== to combine text features from both towers

## Results

- Outperforms alternative architectures on both image-to-text and text-to-image tasks while preserving language capabilities
- Successfully handles multiple downstream tasks including visual QA and image editing without task-specific weights
- Demonstrates practical efficiency advantages over training from scratch or fine-tuning approaches

## Takeaways

> [!tip] Key Insights
> - Incorporating understanding-focused data (image-to-text) improves generation quality (text-to-image)
> - Reducing image data noise in image-to-text samples enhances overall performance
> - Feature alignment with pre-trained vision features accelerates convergence for smaller models but has minimal impact on larger ones
