# MARFT: Multi-Agent Reinforcement Fine-Tuning

> [!summary] Summary
> A framework called Multi-Agent Reinforcement Fine-Tuning (MARFT) is introduced to optimize Large Language Model-based Multi-Agent Systems (LaMAS) using reinforcement learning techniques. It leverages a Flexible Markov Game formulation and achieves performance improvements on agentic tasks like mathematical problem-solving and coding, with MARFT-A increasing episodic return by approximately 18.45% on the MATH dataset and 14.75% in coding benchmarks.

## Problem

- LLM-based Multi-Agent Systems (LaMAS) lack principled methods for optimization and fine-tuning using foundational reinforcement learning (RL) techniques.
- Conventional Multi-Agent Reinforcement Learning (MARL) methods are not directly applicable to LaMAS due to their unique characteristics, such as asynchronous interactions, agent heterogeneity, and dynamic organizational structures.
- Existing LaMAS optimization approaches are primarily tuning-free or rely on ad-hoc parameter fine-tuning without strong theoretical grounding in RL.

## Method

- Introduces ==Multi-Agent Reinforcement Fine-Tuning (MARFT)== as a novel paradigm that reframes LaMAS optimization as a sequential decision-making process for effective reinforcement fine-tuning.
- Proposes the ==Flexible Markov Game (Flex-MG)== formulation, which includes a dynamic dependency function to model asynchronous and dependency-driven interactions inherent in LaMAS workflows.
- Develops two main instantiations, ==MARFT-A (action-level optimization)== and ==MARFT-T (token-level optimization)==, utilizing LoRA fine-tuning and a modified PPO objective with agent-by-agent updates.

## Results

- MARFT-A on a Duo system improved Episodic Return by approximately **8** percentage points (**~18.45%**) on mathematical problem-solving tasks (MATH) and achieved stable score increases of **~14.75%** in coding tasks.
- MARFT-A-tuned LaMAS demonstrated improved generalization, effectively enhancing performance in both in-domain and out-of-domain settings for mathematical problems.
- Multi-agent systems, particularly the Duo setup, significantly outperformed solo agents on complex tasks (e.g., **7.5** p.p. better on MATH500), while MARFT improved even initially sub-optimal multi-agent configurations.

## Takeaways

> [!tip] Key Insights
> - The Flexible Markov Game (Flex-MG) provides a suitable theoretical foundation for LaMAS by explicitly modeling dynamic inter-agent dependencies and asynchronous execution.
> - Optimizing agent policies at the action-level (MARFT-A) generally yields more stable and faster performance improvements compared to token-level optimization (MARFT-T) for end-task objectives.
> - Integrating explicit agent profiles into the joint observation space and using PPO's clipping mechanism helps preserve base LLM language capabilities while enhancing task-specific skills.
