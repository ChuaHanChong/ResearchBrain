# Accelerating Conditional Prompt Learning via Masked Image Modeling for Vision-Language Models

> [!summary] Summary
> ProMIM is a plug-and-play framework that enhances the generalization of conditional prompt learning in Vision-Language Models by integrating masked image modeling to generate more robust, instance-conditioned prompts. This approach improves average accuracy on unseen classes across 11 datasets from 71.69% to 73.96% with minimal computational cost, demonstrating better cross-dataset transferability and domain generalization.

## Problem

- Existing prompt learning methods for Vision-Language Models often overfit to training (seen) classes, resulting in poor generalization to novel, unseen categories.
- Conditional prompt generation, even with methods like CoCoOp, can suffer from "data leakage" where full image features lead to prompts overly specialized to training data, reducing robustness.
- Adapting large VLMs to specific downstream tasks typically requires substantial computational resources or struggles with efficient, generalizable adaptation strategies.

## Method

- Introduces ==ProMIM==, a plug-and-play framework that integrates ==masked image modeling (MIM)== with existing conditional prompt learning methods.
- The meta-network for prompt generation processes only visible patches of a randomly masked input image, forcing it to learn more robust and essential visual features.
- Incorporates a ==regularization term (L_kg)== to minimize the distance between ProMIM's learned textual embeddings and CLIP's original text embeddings, enhancing transferability.

## Results

- ProMIM, when integrated with CoCoOp, increased average "New" class accuracy from **71.69%** to **73.96%** across 11 datasets and improved the harmonic mean from **75.83** to **77.16**.
- The framework enhanced cross-dataset transferability, achieving an average accuracy of **66.09%** across 10 diverse datasets, and improved domain generalization on ImageNet variants.
- ProMIM operates with negligible additional computational cost, adding only approximately **3 minutes** to training time and **0.1ms** to inference time per image while delivering performance benefits.

## Takeaways

> [!tip] Key Insights
> - Leveraging masked image modeling during prompt generation forces the model to extract more fundamental and domain-invariant visual features, preventing overfitting.
> - Conditioning prompts on masked image features, rather than full features, effectively mitigates data leakage, leading to prompts that generalize better to unseen classes.
> - A simple, plug-and-play integration of visual masking with existing prompt learning methods can achieve substantial generalization improvements with minimal computational cost.
