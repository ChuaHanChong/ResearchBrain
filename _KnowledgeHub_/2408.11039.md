# Transfusion: Predict the Next Token and Diffuse Images with One Multi-Modal Model

> [!summary] Summary
> Transfusion introduces a unified AI model capable of both text generation and high-quality image synthesis by directly processing continuous image representations alongside text tokens. The framework eliminates the information loss associated with quantizing continuous data, outperforming quantization-based multi-modal models in scaling efficiency and achieving image quality comparable to specialized diffusion models like DALL-E 2 and Stable Diffusion XL.

## Problem

- Current AI systems excel at single modalities (e.g., LMs for text, diffusion models for images) but struggle to integrate both discrete and continuous data types within a unified framework.
- Existing multi-modal approaches either quantize continuous data, leading to information loss and quality degradation, or rely on complex tool integration of separate, specialized models.
- The challenge lies in reconciling the distinct processing paradigms for discrete (next token prediction) and continuous (denoising) data within a single, coherent architecture.

## Method

- ==Transfusion== introduces a ==mixed-modal representation== where text is tokenized into discrete tokens and images are encoded into ==continuous latent patches==, delimited by special tokens.
- A single transformer backbone processes these mixed-modal sequences, employing dual processing modes: standard language modeling for text and ==diffusion modeling== for image regions.
- The architecture uses shared transformer core with modality-specific components (embeddings for text, U-Net components for images) and mixed attention patterns (==causal for text==, ==bidirectional for images==).

## Results

- Transfusion models demonstrate superior scaling behavior and achieve text perplexity parity with less computational resources compared to quantization-based models like Chameleon.
- The **7B** parameter Transfusion model generates images comparable in quality to specialized diffusion models such as DALL-E 2 and Stable Diffusion XL, while simultaneously performing text generation.
- The model exhibits capabilities in both text-to-image generation and various image editing tasks (e.g., object removal, replacement, style transfer) after fine-tuning.

## Takeaways

> [!tip] Key Insights
> - Avoiding quantization for continuous data (images) within a unified model preserves information and leads to higher quality image generation.
> - A single transformer architecture can effectively process both discrete text tokens (with causal attention) and continuous image patches (with bidirectional attention for images) by employing a combined loss function.
> - U-Net components, when integrated around the transformer, and bidirectional attention within image regions are crucial for achieving high-quality image generation performance.
