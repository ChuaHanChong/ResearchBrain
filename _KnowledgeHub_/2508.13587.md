# Breaking the SFT Plateau: Multimodal Structured Reinforcement Learning for Chart-to-Code Generation

> [!summary] Summary
> Meituan researchers developed Multimodal Structured Reinforcement Learning (MSRL) to address the performance limitations of Supervised Fine-Tuning in chart-to-code generation. Leveraging a new large-scale realistic dataset and multi-granularity rewards, MSRL achieved a new state-of-the-art among open-source models, outperforming a saturated SFT model by 6% on ChartMimic and showing competitive performance against proprietary models like GPT-4o.

## Problem

- Supervised Fine-Tuning (SFT) in multimodal large language models (MLLMs) reaches a performance plateau for chart-to-code generation, failing to generalize effectively from simplistic synthetic datasets.
- Generating precise, executable plotting code from complex visual charts is challenging for MLLMs, as critical information is sparse within boilerplate code, and SFT treats all tokens uniformly.
- Existing chart-to-code datasets are often limited in scale, diversity, and realism, hindering robust model development and generalization.

## Method

- A large-scale (3 million pairs), realistic ==chart-to-code== training corpus was constructed from arXiv tables, with a high-quality subset curated for reinforcement learning (RL) training through code content and visual fidelity filtering.
- Multimodal Structured Reinforcement Learning (MSRL) was developed, featuring a two-stage training strategy and a multi-granularity reward system that integrates rule-based textual accuracy and MLLM-based visual fidelity assessments.
- The approach fine-tuned an SFT-trained Qwen2.5-VL base model using Group Relative Policy Optimization (GRPO), leveraging code normalization and weighted rewards for detailed code aspects and execution success.

## Results

- MSRL achieved state-of-the-art performance for open-source MLLMs on chart-to-code generation, with a **96.5%** execution rate and **83.8%** high-level score on ChartMimic, and **98.2%** execution rate and **89.9%** high-level score on ReachQA.
- The MSRL strategy significantly broke the SFT plateau, yielding an average improvement of **6%** on the ChartMimic benchmark over the saturated SFT model.
- MSRL demonstrated strong generalization capabilities, improving execution rates and high-level scores on unseen Seaborn and Plotly charts, and performed comparably to larger proprietary models like GPT-4o on detailed low-level metrics.

## Takeaways

> [!tip] Key Insights
> - Simply scaling supervised fine-tuning data leads to diminishing returns, confirming an SFT performance plateau in complex structured output tasks like chart-to-code generation.
> - Reinforcement learning, when equipped with multi-granularity, structured rewards combining both textual and visual feedback, can effectively push MLLM performance beyond the SFT plateau for code generation from complex visual inputs.
> - A two-stage RL curriculum, prioritizing computationally cheaper textual rewards before incorporating more expensive visual rewards, balances optimization efficiency with overall performance gain.
