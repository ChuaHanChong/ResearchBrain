# OmniLabel: A Challenging Benchmark for Language-Based Object Detection

> [!summary] Summary
> Researchers from NEC Laboratories America and Rutgers University developed OmniLabel, a new benchmark for language-based object detection that evaluates models on complex, free-form textual descriptions, including instances with zero, one, or multiple objects. Evaluations show state-of-the-art models exhibit significantly lower Average Precision on this benchmark, particularly struggling with longer descriptions and the inclusion of negative examples.

## Problem

- Existing object detection benchmarks rely on fixed, limited categories, which restricts evaluation of models capable of understanding natural language descriptions.
- Open-vocabulary detection benchmarks typically use simple category names, failing to assess models' ability to handle complex, compositional free-form text.
- Referring expression datasets often assume the presence of a target object and lack negative examples, which limits their utility for evaluating a model's true detection and discrimination capabilities.

## Method

- A novel benchmark, **OmniLabel**, is introduced, defining a ==language-based object detection== task with a ==dynamic label space== comprising plain categories and complex free-form text.
- The dataset construction leverages existing high-quality ==bounding box datasets== and a ==multi-step annotation process== to collect diverse descriptions, including multi-instance references and challenging negative examples.
- A modified ==Average Precision (AP)== metric is proposed, which combines ==semantic and localization matching==, handles ==multi-label predictions==, and uses a ==harmonic mean== to equally weigh performance on plain and free-form descriptions.

## Results

- All evaluated state-of-the-art models achieved significantly lower **Average Precision (AP)** scores on OmniLabel, confirming the benchmark's increased difficulty compared to existing evaluations.
- Models showed higher accuracy on plain categories (**AP-categ**) than free-form descriptions (**AP-descr**, dropping further with negatives), with shorter descriptions (up to **3 words**) scoring higher AP than longer ones (**8+ words**).
- **GLIP-T/L** and **FIBER-B** demonstrated the highest overall performance among the baselines on the OmniLabel benchmark; e.g. **FIBER-B** scored **87.1%** on RefCOCOg (val) under its native metric but only **33.0%** under the stricter OmniLabel metric.

## Takeaways

> [!tip] Key Insights
> - Current state-of-the-art language-based object detection models exhibit limitations when presented with OmniLabel's complex, free-form descriptions and negative examples.
> - A notable performance gap exists between detecting plain categories and understanding intricate natural language queries, indicating a challenge in compositional language understanding.
> - The presence of semantically related negative descriptions severely impacts model accuracy, highlighting the need for improved discriminative capabilities.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work presented in this paper addresses a critical need for comprehensive evaluation within the rapidly evolving field of language-based object detection. Recent advancements in vision and language models have enabled new approaches to object localization that move beyond predefined category names, allowing for descriptions using natural language. However, the existing benchmarks designed for traditional object detection, open-vocabulary detection, or referring expressions possess limitations that prevent a holistic assessment of these advanced capabilities.

Traditional object detection datasets, such as Pascal VOC, MS COCO, Objects-365, OpenImages, and LVIS, operate under a fixed and limited set of object categories. While they have driven significant progress in detection architectures, their scope does not accommodate the flexibility of natural language descriptions. Open-vocabulary object detection, a more recent development, relaxes the fixed-label space assumption by allowing detectors to identify objects from categories not seen during training. Benchmarks like ODinW fall into this category. However, these benchmarks typically evaluate models only on simple, single-word category names, neglecting the compositional and relational complexity of natural language.

Referring expression datasets, including RefCOCO/g/+ and PhraseCut, move closer to language-based understanding by utilizing free-form text to describe objects. Yet, these datasets often assume a specific context—for instance, RefCOCO/g/+ largely expects each phrase to refer to exactly one object instance, and generally lacks "negative" examples where a description has no corresponding object in the image. This limits their utility for evaluating true detection ability, which inherently involves discerning the presence or absence of an object matching a description. Visual grounding tasks, exemplified by Flickr30k and Visual Genome, aim to localize every object mentioned in a phrase, which is a detailed but distinct task from referring to a specific object or set of objects with a single description. The annotation costs for visual grounding are also typically higher, potentially leading to noisier ground truth.

OmniLabel positions itself by unifying and extending upon these disparate tasks. It aims to create a benchmark that can evaluate models across the spectrum of natural language descriptions, from simple categories to complex, free-form phrases, including instances where descriptions refer to multiple objects or no objects at all. This approach seeks to provide a more realistic and challenging environment for developing and assessing advanced language-based object detection systems that can mirror human perception's nuanced understanding of the visual world through language.

### 2. Key Objectives and Motivation

The primary objective of this research is to establish a novel benchmark, OmniLabel, that comprehensively evaluates the ability of models to understand complex, free-form textual descriptions of objects and accurately locate their corresponding instances within images. This goal is driven by several motivations related to the current limitations in the field:

Firstly, human visual perception demonstrates a nuanced understanding of semantic information, allowing for the identification of objects from highly compositional descriptions (e.g., "person wearing blue-and-white striped T-shirt standing next to the traffic sign"). Automating this capability is critical for advancing applications in domains such as robotics, autonomous vehicles, navigation, and retail, where flexible and natural human-computer interaction is beneficial. However, existing object detection and vision-language benchmarks do not adequately assess a model's capacity for such complex, natural language understanding.

Secondly, despite significant progress in vision & language models and their extension to object localization, a proper and comprehensive evaluation mechanism has been lacking. Current benchmarks often make simplifying assumptions:
- **Fixed Label Space:** Standard object detection benchmarks rely on a predefined and limited set of object categories, which is restrictive for real-world scenarios where the variety of objects is virtually limitless.
- **Simple Descriptions:** While open-vocabulary detection addresses the fixed-label space, its benchmarks typically only evaluate detection based on simple category names, failing to capture the rich semantic detail of free-form text.
- **Lack of True Detection Scope:** Referring expression datasets focus on localizing an object *assumed* to be present. They generally do not include "negative examples" where a description is semantically relevant but refers to no object in the image, which is a fundamental aspect of object detection. Moreover, most referring expression datasets typically target descriptions of a single object instance.

The OmniLabel benchmark is specifically motivated to overcome these limitations. It introduces a task where the label space is dynamic and virtually infinite, encompassing both plain category names and intricate free-form text. It explicitly incorporates descriptions that can refer to zero, one, or multiple object instances, including challenging negative examples that demand robust discriminative capabilities from detectors. By addressing these gaps, OmniLabel aims to provide a rigorous testing ground to stimulate the development of more advanced and human-like language-based object detectors.

### 3. Methodology and Approach

The methodology employed in this research involved defining a novel benchmark task, developing a specific evaluation metric, and implementing a multi-step data collection and verification process to construct the OmniLabel dataset.

**Benchmark Task Definition:**
The task is defined by its input and output. The input to a model is an RGB image $I_i$ along with a dynamic label space $D_i$. This label space is unique to each image, varying in both content and size. It comprises "object descriptions," which can be plain category names (as in standard detection) or newly collected free-form text. The free-form nature of these descriptions means each can be effectively unique. Crucially, $D_i$ contains both positive descriptions (referring to objects present in the image) and negative descriptions (semantically related to the image but referring to no object). The model's output must be a set of triplets $P_i = \{(b_l^i, s_l^i, g_l^i)\}$ for each image, where $b$ is a bounding box, $s$ is a confidence score, and $g$ is an index linking the prediction to an object description in $D_i$. Multiple predictions can correspond to the same object description.

This definition differentiates OmniLabel from existing benchmarks:
- **Object Detection:** OmniLabel's label space is more complex (natural text, potentially unseen during training) and dynamic, contrasting with the fixed label spaces of traditional object detectors.
- **Referring Expressions:** While similar, OmniLabel's data allows descriptions to range from plain categories to highly specific free-form text. Descriptions can refer to zero, one, or multiple instances, addressing the limitations of referring expression datasets which typically assume the object's presence and often only one instance.

**Evaluation Metric:**
To evaluate models, a modified Average Precision (AP) metric is proposed, adapting the standard object detection metric to the unique characteristics of OmniLabel:
- **No Category Grouping:** Standard AP computes and averages metrics per category. OmniLabel omits this initial grouping due to the high specificity and potentially infinite nature of free-form descriptions. Instead, the matching process is adjusted.
- **Semantic and Localization Matching:** A prediction is considered a match to a ground truth only if it points to the *same object description* (semantic agreement via index $g_l^i$) and their bounding boxes sufficiently overlap (localization via Intersection-over-Union, IoU).
- **Multi-label Predictions:** Unlike standard detection where each object instance has one category, OmniLabel allows a single ground truth box to be correctly matched by multiple predictions, provided each prediction corresponds to a *different* object description (e.g., "person" and "woman in red shirt" both refer to the same object).
- **Harmonic Mean for Balance:** To ensure equal importance for plain category names and complex free-form text, AP is calculated separately for each type (AP-categ and AP-descr) and then combined using the **harmonic mean**. This approach incentivizes models to perform well across both description types, as poor performance in one significantly pulls down the overall score.

**Dataset Collection Process:**
The OmniLabel dataset was constructed through a multi-step annotation and verification process, primarily leveraging existing object detection datasets:
1. **Existing Datasets:** The validation/test sets of COCO, Objects-365, and OpenImages-V5 were used as a foundation, providing pre-existing bounding boxes and (super-)category information. This reduced annotation costs and facilitated diverse sampling.
2. **Image/(Super)category Pair Sampling:** A sampling strategy was employed to select image and (super-)category pairs for annotation. Criteria included requiring at least two instances of a (super-)category or two different sub-categories for super-categories. Filters were applied to exclude images with too many instances (>10), very small bounding boxes (<80 pixels), high object overlap (>50%), or crowd annotations, thereby encouraging descriptions focusing on appearance, relations, and actions.
3. **Object Description Collection:** Amazon Mechanical Turk (AMT) annotators were given an image and bounding boxes for a selected (super-)category. They were instructed to select a *subset* of these instances and provide a free-form text description that *only* matched their selection. Constraints were applied (e.g., for N instances, selecting 2 to N-1 for N>2) to necessitate descriptions beyond simple category names. For super-categories, annotators were encouraged to avoid super-category names, promoting higher-level descriptions. A semi-automatic profanity check was also performed.
4. **Verification:** A second AMT task involved presenting annotators with the original bounding boxes and the collected description, asking them to re-select the matching objects. Only descriptions where the initial and verification selections were identical were retained (approximately 80% retention).
5. **Negative Description Collection:** To gather challenging negative examples, existing free-form object descriptions were used. For an image/(super-)category pair, five object descriptions from the *same* (super-)category but a *different* image were randomly sampled. Two AMT annotators then confirmed if these descriptions *did not* refer to any object in the current image. Descriptions with two confirmations were kept (approximately 30% retention), ensuring semantic relatedness as difficult distractors.
6. **Quality Check:** A final manual quality check involved correcting misspellings and ambiguous descriptions. Entirely incorrect descriptions were discarded (approximately 10%).

**Dataset Analysis:**
Analysis of the OmniLabel validation set showed 12.2K images and 15.8K free-form descriptions (11.7K positive, 9.4K negative). It featured a higher average number of bounding boxes per description (1.7) compared to other datasets. Part-of-speech (POS) tagging revealed more unique nouns, verbs, and adjectives in OmniLabel's descriptions, indicating greater diversity and complexity. Descriptions were generally longer and more sentence-like. Manual tagging of a subset showed that over 80% involved category names (with 4.6K unique nouns), ~40% required attribute, spatial, or external knowledge understanding, and 5-10% involved functional relations, actions, or numeracy. The distribution of instances per description also indicated a lower bias towards single instances compared to other datasets.

### 4. Main Findings and Results

The research evaluated several prominent language-based object detection models on the OmniLabel benchmark, including RegionCLIP, Detic, MDETR, GLIP-T, GLIP-L, and FIBER-B. The evaluation utilized the proposed modified Average Precision (AP) metric to assess performance across various aspects of the task.

**Overall Difficulty:**
A primary finding was that the OmniLabel benchmark poses a significant challenge for all evaluated methods. The AP values achieved by state-of-the-art models were generally lower than those reported on less complex benchmarks, indicating the increased rigor of OmniLabel.

**Performance Discrepancy Between Plain and Free-form Descriptions:**
Almost all evaluated methods exhibited higher accuracy on plain object categories (AP-categ) compared to free-form text descriptions (AP-descr). This suggests that models are generally more proficient at detecting predefined, simple categories than at understanding and localizing objects based on complex, natural language queries. The performance gap was notably more pronounced for images originating from the COCO dataset subset.

**Impact of Negative Descriptions:**
The inclusion of negative descriptions, which are semantically related to an image but refer to no present object, had a substantial impact on model performance. A significant drop in AP was observed when comparing results that included negative descriptions (AP-descr) versus those that excluded them (AP-descr-pos). This difference indicates that current models struggle to robustly discriminate between relevant textual cues that refer to an object and those that serve as distractors. The largest performance disparity attributable to negative descriptions was observed on COCO images, a consequence of the data collection process that resulted in a higher density of negative descriptions in this subset. The findings suggest that negative descriptions represent a major challenge for contemporary language-based detectors.

**Correlation with Description Length:**
The study found an inverse correlation between description length and detection accuracy. Models generally achieved higher AP values for shorter descriptions (AP-descr-S, up to three words) compared to longer ones (AP-descr-L, more than eight words). This indicates that increasing textual complexity, in terms of word count, presents a greater challenge to models in accurately localizing objects.

**Top-Performing Models:**
Among the baselines, GLIP-T/L and FIBER-B achieved the highest overall results on the OmniLabel benchmark, demonstrating their relative strength in handling complex language-based object detection tasks.

**Model-Specific Observations:**
- **MDETR:** This model showed reasonable performance when only positive descriptions were considered (AP-descr-pos) but experienced a substantial decline in accuracy when negative descriptions were included (AP-descr). This suggests a limitation in its ability to handle hard negative examples, potentially due to its specific training algorithm. Due to significant runtime demands with a large label space, AP and AP-categ results for MDETR were not reported.
- **Detic:** While Detic performed commendably on plain categories (AP-categ), its performance on free-form descriptions (AP-descr) was comparatively lower. This aligns with its design as an open-vocabulary detector primarily leveraging CLIP embeddings for class names, which may be less robust for highly complex linguistic structures.
- **RegionCLIP:** This model generally exhibited lower performance, which the authors attribute to a combination of a potentially weaker backbone architecture and the characteristics of its training data.

**Comparison with Other Datasets:**
A comparative analysis using the OmniLabel evaluation metric on RefCOCOg and PhraseCut datasets confirmed that OmniLabel presents a more difficult challenge. This increased difficulty is particularly evident due to the presence of negative descriptions. Furthermore, the proposed evaluation metric itself was found to be more stringent than the metrics typically used in RefCOCO/g/+. For example, FIBER-B, which achieved 87.1% accuracy on RefCOCOg (val) using its native metric, recorded 33.0% using the OmniLabel metric, highlighting the stricter nature of the new evaluation protocol.

### 5. Significance and Potential Impact

The OmniLabel benchmark represents a significant contribution to the field of language-based object detection by addressing several limitations inherent in prior evaluation methodologies. Its significance and potential impact stem from its comprehensive design and the challenges it poses to current models.

Firstly, **unifying and advancing the evaluation landscape**, OmniLabel provides a single benchmark that effectively subsumes and extends traditional object detection, open-vocabulary detection, and referring expression tasks. By integrating diverse description types—from simple categories to complex, free-form text—and incorporating multi-instance references alongside crucial negative examples, it creates a more holistic and realistic testing environment. This allows for a more comprehensive assessment of a model's ability to truly understand and localize objects based on natural language.

Secondly, the **novel annotation strategy** is impactful. By building upon existing high-quality bounding box datasets (COCO, Objects-365, OpenImages-V5), the researchers efficiently collected a vast and diverse set of free-form text descriptions. The controlled annotation process, which encourages descriptions beyond simple category names, focuses on attributes, relations, and actions, and explicitly solicits both multi-instance and challenging negative examples, ensures the dataset’s relevance and difficulty. The inclusion of negative descriptions, in particular, is critical as it forces models to develop robust discriminative capabilities, a necessary component for real-world detection systems.

Thirdly, the **development of a robust evaluation metric** is crucial. The modified Average Precision (AP) metric, which accounts for the virtually infinite label space, integrates semantic matching with localization accuracy, allows for multi-label predictions for a single ground truth object, and utilizes the harmonic mean to balance performance across plain and free-form descriptions, provides a more stringent and fair assessment. This metric helps to identify areas where models underperform, guiding future research toward more balanced and capable solutions.

Fourthly, the **identification of current model limitations** through baseline evaluations has substantial implications. The findings clearly demonstrate that state-of-the-art language-based object detectors face significant challenges with complex free-form text, especially when dealing with negative descriptions and longer queries. This highlights key areas for future research and development, such as improving models' capacity for compositional language understanding, enhancing their ability to discern the absence of an object from semantically related text, and handling higher-order reasoning required by intricate descriptions.

Ultimately, OmniLabel is expected to **accelerate progress towards robust and human-like object detectors**. By providing a challenging and representative benchmark, it will drive the development of new algorithms and architectures that are better equipped to understand semantically rich and complex natural language descriptions of objects. Such advancements are vital for improving the performance and usability of real-world applications in domains like robotics, autonomous driving, retail, and assistive technologies, where flexible and intuitive human-computer interaction based on visual perception is increasingly desired.
