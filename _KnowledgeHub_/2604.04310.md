# frax: Fast Robot Kinematics and Dynamics in JAX

> [!summary] Summary
> Researchers from Stanford University developed `frax`, a JAX-based library for robot kinematics and dynamics. It delivers low-microsecond computation times on CPU for real-time control and scales to over 100 million dynamics evaluations per second on GPU for parallel workloads, all while natively supporting automatic differentiation.

## Problem

- Existing rigid-body dynamics libraries, often C++-based, lack seamless and efficient integration with modern Python automatic differentiation tools like JAX.
- A unified framework for robot dynamics that performs efficiently across diverse computing architectures (CPU, GPU, TPU) without compromising on performance or ease of use is largely absent.
- Current solutions typically specialize in either low-latency CPU execution or high-throughput GPU workloads, requiring separate implementations or introducing overhead when bridging architectures.

## Method

- Introduced `**frax**`, a pure-Python library built on the JAX framework, specifically designed for high-performance robot kinematics and dynamics computations across multiple devices.
- Utilized a fully-vectorized formulation of rigid-body dynamics algorithms, employing an ancestor mask to enable fine-grained parallelism suitable for JAX's XLA compiler.
- Leveraged JAX's Just-In-Time (JIT) compilation, native automatic differentiation capabilities, and multi-device compatibility to create a cohesive and performant single codebase.

## Results

- Achieved low-microsecond CPU computation times (e.g., 4.09 µs for Franka Panda differential inverse kinematics), enabling kilohertz-rate control and demonstrating a 2-**5x** speedup over Python APIs of Pinocchio and MuJoCo.
- Showcased strong GPU scaling for parallel workloads, exceeding 100 million dynamics evaluations per second for batch sizes of 4096, performing comparably to or slightly faster than other JAX-backend libraries like MJX and BRAX.
- Exhibited significantly faster JIT compilation times of 1-2 seconds, compared to 6-12 seconds for competing JAX-based libraries, thereby improving the iterative development process.

## Takeaways

> [!tip] Key Insights
> - The vectorized dynamics approach, while theoretically increasing algorithmic complexity (O(n) to O(n^2)), translates to practical performance gains on accelerators due to XLA's ability to exploit fine-grained parallelism.
> - A pure-Python JAX-native library can offer competitive real-time performance for single-robot CPU control tasks compared to optimized C++ libraries, while providing superior scalability and automatic differentiation support for parallel GPU workloads.
> - Efficient JIT compilation and automatic differentiation within JAX simplify the development and deployment of complex, gradient-reliant control and planning algorithms in robotics.
