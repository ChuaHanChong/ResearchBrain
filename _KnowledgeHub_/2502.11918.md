# VLP: Vision-Language Preference Learning for Embodied Manipulation

> [!summary] Summary
> Vision-Language Preference learning (VLP) automates preference annotation for embodied manipulation tasks by leveraging vision-language models. It generates accurate preference feedback from natural language instructions, enabling RL agents to perform comparably or better than those trained with scripted labels and outperforming other VLM-based reward methods while generalizing to unseen tasks.

## Problem

- Reward engineering in reinforcement learning (RL) is a labor-intensive process requiring domain expertise, often leading to reward hacking where agents exploit the reward function rather than achieving intended goals.
- Preference-based reinforcement learning (PbRL) typically relies on expensive and time-consuming human preference annotations, limiting its scalability.
- Existing VLM/LLM-based preference labeling methods often require access to environment information or produce inaccurate labels.

## Method

- ==Introduces Vision-Language Preference== learning (**VLP**), a framework leveraging vision-language models (VLMs) to automate preference annotation for embodied manipulation tasks.
- Constructs a Multi-Task Vision-Language Preference (MTVLP) dataset, combining videos of agent trajectories from Meta-World tasks with GPT-4V-generated natural language instructions and preference labels.
- Develops a VLP model architecture that uses CLIP's visual and text encoders, a cross-modal transformer for feature interaction, and an MLP to predict a trajectory-level preference score based on three types of language-conditioned preferences.

## Results

- VLP-generated preference labels, when used with offline RLHF algorithms, achieve performance comparable to, and in some cases, better than scripted preference labels derived from ground-truth rewards.
- VLP significantly outperforms other VLM-based reward shaping methods (e.g., R3M, VIP, LIV, CLIP, VLM-RM, RoboCLIP) in training RL agents for embodied manipulation tasks.
- The VLP framework demonstrates strong generalization abilities, maintaining high preference prediction accuracy on both unseen tasks and novel language instructions.

## Takeaways

> [!tip] Key Insights
> - Vision-language models (VLMs) can automate preference annotation for embodied tasks by effectively aligning visual observations with natural language instructions.
> - Training a VLM on a multi-task video-language preference dataset enables the model to learn generalizable preference representations for diverse manipulation tasks.
> - Defining explicit language-conditioned preference types (intra-task, inter-language, inter-video) enhances the model's ability to robustly predict accurate preferences, leading to better RL agent performance.
