# Learning What to Recall: Adaptive Multi-Cue Episodic Memory for World Models

> [!summary] Summary
> Future-Aware Recall (FAR) learns which episodic memories a video diffusion world model should retrieve. During training, each candidate memory is credited by how much it lowers the diffusion prediction loss of the realized future; this future-aware posterior distills into a future-blind retriever that fuses time, pose, vision and audio cues with learned query-dependent weights. FAR beats hand-designed recall on LoopNav, SoundSpaces and AI2-THOR.

## Problem

- Existing world-model memories retrieve by fixed rules like recency, pose field-of-view overlap, or visual embedding similarity, yet cue similarity does not imply usefulness for predicting the future.
- Cue reliability varies across queries: pose can favor a memory behind a wall and vision is ambiguous across similar corridors, but prior retrievers use one cue or fixed combinations.
- Discrete Top-K selection blocks gradients from the world-model objective, so external retrievers are not optimized for prediction, and geometry-matched memories can show stale states after objects change.

## Method

- ==Predictive utility== and ==future-aware posterior==: the log-likelihood of the realized future given a candidate memory, approximated by negative ==diffusion loss== over four timesteps, combines with retriever scores via ==Bayes' rule== into a teacher distribution.
- ==EMDR2==-style retriever distillation: a ==KL loss== with stop-gradient trains the future-blind recall distribution to match the posterior, adapting latent-variable ==retrieval-augmented generation== training to episodic recall from interaction history.
- ==Adaptive multi-cue fusion==: per-cue scorers for time, pose, vision and audio are standardized and combined by a learned ==query-dependent gate==, with frozen cacheable memory encoders and temporally chunked ==Top-K recall==.

## Results

- On LoopNav loop closure, learned visual recall cuts DreamSim **17%** versus LongLive-RAG and learned metadata recall **19%** versus WorldMem; full Multi-Cue FAR reaches **17.27** PSNR versus **15.37** for WorldMem.
- Ablation: frozen vision encoder gives **16.25** PSNR, MLP query adapter **16.48**, fixed 0.5 metadata fusion **16.91**, learned fusion weights **17.27**; in sparse-memory SoundSpaces, audio fusion's advantage grows with return length.
- In AI2-THOR off-scene dynamics prediction, Temporal and WorldMem reach **41.9%** and **32.4%** accuracy, metadata-only FAR **67.1%**, and Multi-Cue FAR **94.6%**; it also beats baselines on container-reveal state accuracy.

## Takeaways

> [!tip] Key Insights
> - Similarity under any single cue is a proxy, not relevance; supervising retrieval with the downstream prediction likelihood directly targets what memory is actually for.
> - Hindsight available only at training time, the realized future, can be distilled into a future-blind inference module via a posterior teacher, a reusable recipe beyond world models.
> - Caution: diffusion-loss utility underweights small local visual changes and adds training compute; recall quality for subtle state changes needs task-aware utilities, and evidence remains simulation-only.

## Detailed Report

### 1. Overview

An agent explores a space, then returns to a place it saw earlier. A world model must predict what the agent will see on return. The current view may hide changes or omit evidence needed for that prediction. Episodic memory keeps past observations available. Fixed rules such as “use the newest frame” or “use the view with the most pose overlap” can still select a poor memory. FAR trains the retriever using the future the world model is learning to predict. At inference, the retriever uses only the current query and available cues. The clearest measured comparison comes from LoopNav, a static Minecraft return-navigation task. At loop closure, FAR’s metadata-based retriever reports **19% lower DreamSim** than WorldMem while using the same respective cue types. DreamSim is a lower-is-better perceptual distance between generated and ground-truth frames. The project page [describes this metric and comparison](https://1202kbs.github.io/FAR-Project-Page/).

Author project-page teaser: qualitative rollout videos across LoopNav, SoundSpaces, and AI2-THOR.

### 2. Train on the future, recall without it

An episodic memory is a set of separately stored past observations that can later be retrieved. FAR selects a compact Top-K subset of them to condition a video-diffusion world model. During training, the actual future observation is available. A memory’s **predictive utility** is how well the world model predicts that realized future when given the memory and the current observation/action query. For diffusion models, the paper approximates this by negative diffusion prediction loss, evaluated over four diffusion noise levels. Lower prediction loss earns more retrieval credit.

Training proceeds in two steps. The future first reweights candidate memories according to their predictive utility. The retriever then learns to match that future-aware target. At inference, the future is absent, and the learned retriever selects memories from the current query and available cues only.

Cue-specific scorers assign relevance using available signals such as time, pose, vision, and audio. A learned gate gives those scores query-dependent weights. The fused scores select the Top-K memories. There is one approximation. Retrieval-credit training evaluates candidate memories individually, whereas the world model is trained on the complete recalled context. This practical approximation therefore does not explicitly credit memories that become useful only in combination.

Interaction history and memory cues feed separate time, pose, vision, and audio scorers. The scores are fused with query-dependent weights, and Top-K selection forms the recalled context. The world model combines that context with the current observation and action to predict the future. The observed future and predictive utility feed back into retriever training only.

### 3. Does learning to recall beat fixed rules?

LoopNav’s baselines use recency (Temporal), field-of-view overlap (WorldMem), or reconstructive visual similarity (LongLive-RAG). At loop closure, FAR with metadata cues achieves the reported 19% lower DreamSim than WorldMem despite using the same respective cue types. This supports the claim that cue similarity need not equal predictive usefulness. It does not show that FAR always improves every metric in every environment.

A skeptic might ask whether adaptive weighting matters, or whether FAR simply adds another cue. A LoopNav ablation addresses this by keeping the same vision-plus-metadata configuration and replacing fixed fusion ($\lambda = 0.5$) with learned fusion. With learned fusion:

- PSNR rises from 16.912 ± 0.117 to 17.267 ± 0.116 (higher is better).
- LPIPS falls from 0.353 ± 0.005 to 0.337 ± 0.005 (lower is better).
- DreamSim falls from 0.088 ± 0.002 to 0.082 ± 0.002 (lower is better).

This comparison supports adaptive weighting over uniform fusion in this ablation. It does not isolate all possible causes of the overall method’s gains.

### 4. Scope

FAR’s training signal connects the memory choice to the prediction the model must make. Its learned cue weights let that choice depend on the query. The scope is limited in several ways. This is recall from an external episodic memory, not a complete memory system. The experiments use controlled simulations. FAR needs informative cues and adds training-time computation to score predictive utility. The paper also warns that its diffusion-loss surrogate can underweight semantically important, local changes.
