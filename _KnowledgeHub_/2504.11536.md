# ReTool: Reinforcement Learning for Strategic Tool Use in LLMs

> [!summary] Summary
> ReTool, developed by ByteDance Seed, introduces a reinforcement learning framework that enables Large Language Models to strategically use code interpreters for complex problem-solving. It achieved 67.0% accuracy on the AIME 2024 benchmark, significantly improving performance over text-based reasoning and demonstrating emergent self-correction capabilities in code generation.

## Problem

- Large Language Models (LLMs) often struggle with tasks requiring high precision, complex numerical computation, or symbolic manipulation (e.g., advanced mathematics) due to the inherent 'fuzziness' of textual reasoning.
- Existing tool-integrated reasoning (TIR) methods, primarily based on supervised fine-tuning (SFT), train LLMs to imitate pre-defined tool invocation patterns, limiting their ability to adaptively decide when and how to strategically use tools.
- Pure text-based reasoning can lead to compounding errors and lack of verifiable accuracy in domains requiring exact solutions.

## Method

- ==ReTool== employs a two-stage training framework: an initial cold-start supervised fine-tuning (SFT) phase, followed by a reinforcement learning (RL) phase using Proximal Policy Optimization (PPO).
- The SFT phase utilizes automatically constructed ==code-integrated data (D_CI)== to teach foundational tool invocation and output interpretation.
- The core RL phase features ==dynamic, interleaved code execution==, where the LLM generates code that is immediately run in an external sandbox, and the interpreter's output (success or error) is fed back to the model, guiding subsequent reasoning based on a simple accuracy reward.

## Results

- ReTool achieved **67.0%** accuracy on AIME 2024 using Qwen2.5-32B-Instruct, significantly outperforming the text-based RL baseline (**40.0%**) and other competitive baselines.
- The approach demonstrated high training efficiency, reaching superior performance in only **400** training steps, compared to over **1000** steps for the text-based RL baseline.
- Cognitive analysis revealed a **40%** reduction in average response length (from **10k** to **6k** tokens), a near **fivefold** increase in code lines per response, and a high code pass rate (approaching **100%**) in correct responses after RL training.

## Takeaways

> [!tip] Key Insights
> - Reinforcement learning enables LLMs to develop strategic tool-use behaviors, such as increasing code invocation frequency and learning to invoke tools earlier in the reasoning process.
> - The model exhibits emergent meta-cognitive abilities, including autonomously self-correcting non-executable code based on real-time interpreter error feedback.
> - RL training promotes more diverse code utilization, moving beyond basic calculations to encompass a wider range of problem-solving purposes.
