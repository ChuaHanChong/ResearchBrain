# GENMANIP: LLM-driven Simulation for Generalizable Instruction-Following Manipulation

> [!summary] Summary
> This paper presents GENMANIP, a large-scale, photorealistic robotic simulation platform built on NVIDIA Isaac Sim, designed to evaluate instruction-following robotic manipulation policies. It features an LLM-driven scenario generation pipeline and a standardized benchmark (GENMANIP-BENCH) to assess policy generalization, revealing distinct strengths and limitations of modular and end-to-end learning approaches across different task categories.

## Problem

- Existing robotic simulation platforms lack scenario diversity and photorealism, hindering comprehensive evaluation of generalization for instruction-following robots.
- There is an absence of standardized evaluation frameworks and benchmarks specifically designed to compare different policy architectures for natural language instruction following.
- Current robotic manipulation approaches struggle to generalize across varying objects, spatial configurations, and task instructions, particularly for complex, long-horizon tasks.

## Method

- GENMANIP introduces a realistic, large-scale tabletop simulation platform built on NVIDIA Isaac Sim, featuring 10,000 annotated 3D objects and 100 articulated objects.
- An LLM-driven pipeline automatically generates diverse manipulation scenarios using a Task-oriented Scene Graph (ToSG) to bridge natural language instructions with simulation configurations.
- GENMANIP-BENCH provides a standardized evaluation framework with 200 human-curated scenarios to systematically assess the generalization of both modular and learning-based robotic manipulation policies.

## Results

- Modular systems achieved up to 23.0% overall success rate (CoPA with GPT-4.5) but performed poorly on long-horizon tasks (9.07% average success) and showed planning inefficiencies (low SPL scores).
- End-to-end learning methods (e.g., GR-1) demonstrated strong performance scaling with data, reaching 95.0% success on familiar tasks, but completely failed (0.0% success) on novel instructions and unseen objects.
- Error analysis revealed task decomposition failures and grounding errors as primary limitations for modular systems, while learning-based methods suffered from a lack of compositional understanding.

## Takeaways

> [!tip] Key Insights
> - Modular systems, while demonstrating zero-shot capabilities and semantic understanding, struggle with efficient low-level planning and long-horizon tasks, achieving only 9.07% success on the latter.
> - End-to-end learning methods show strong data scaling (e.g., GR-1 improving from 33.0% to 95.0% success with more data) but exhibit semantic brittleness, failing completely (0.0% success) on unseen instructions or objects.
> - Future research should explore hybrid architectures combining LLM-driven high-level reasoning with learning-based low-level control to leverage complementary strengths.
