# DynaMem: Online Dynamic Spatio-Semantic Memory for Open World Mobile Manipulation

> [!summary] Summary
> DynaMem introduces an online dynamic spatio-semantic memory architecture enabling open-vocabulary mobile manipulation in changing real-world environments. The system achieved a 70% pick-and-drop success rate on non-stationary objects, representing a more than 2x improvement over static state-of-the-art baselines.

## Problem

- Existing open-vocabulary mobile manipulation (OVMM) systems fundamentally rely on the assumption of static environments, severely limiting their applicability in dynamic real-world settings.
- Current robot memory structures lack the ability to adapt online by both adding new information and explicitly removing outdated data when objects move, appear, or disappear.
- Limitations within individual modules, such as navigation systems built on static maps, propagate and degrade the overall performance of modular OVMM architectures.

## Method

![[2411.04999-method.png]]
*An illustration of how our online dynamic spatio-semantic memory DynaMem responds to open vocabulary queries in a dynamic environment. During operation and exploration, DynaMem keeps updating its semantic map in memory. DynaMem maintains a voxelized pointcloud representation of the environment, and updates with dynamic changes in the environment by adding and removing points.*

- **DynaMem** introduces a novel dynamic 3D voxel memory that continuously updates its understanding of the environment by supporting both the online addition and removal of objects and obstacles.
- It employs a ray-casting mechanism to detect when existing voxels should be visible but are not, inferring that objects have moved or been removed and purging outdated information.
- A robust, two-stage querying process combines VLM-feature-based semantic similarity with Multimodal Large Language Model (mLLM-QA) for precise object localization, explicitly reporting if an object is 'not found' to prevent false positives.

## Results

- In real-world experiments with Stretch SE3 robots, DynaMem achieved a **70%** pick-and-drop success rate for non-stationary objects, demonstrating a more than **2x** improvement over static baselines (**30%** success rate).
- DynaMem drastically reduced failures due to inability to locate dynamic objects to **6.7%**, compared to **53.3%** for static systems, validating its core capability for dynamic environments.
- On the new DynaBench offline benchmark, a hybrid querying method (VLM-feature-based filtering followed by mLLM-QA) achieved the highest performance at **74.5%** accuracy.

## Takeaways

> [!tip] Key Insights
> - Enabling a memory system to dynamically add and remove object information online is crucial for adapting to real-world environment changes, such as moving objects, which is a major bottleneck for mobile manipulation.
> - A hybrid approach leveraging both VLM-feature similarity and mLLM-QA queries offers complementary strengths, leading to more robust and accurate open-vocabulary object localization than either method alone.
> - Explicitly handling and reporting when an queried object is not found in the environment prevents incorrect or wasted robot actions, enhancing the system's reliability in dynamic scenarios.
