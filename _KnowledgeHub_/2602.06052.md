# A Survey of Agent Memory in the Second Half: Towards Self-Evolving and Long-Horizon Agents

> [!summary] Summary
> This survey organizes foundation-agent memory along three dimensions: substrate (internal parametric weights, latent states, KV caches versus external vector, text, and graph stores), cognitive mechanism (sensory, working, episodic, semantic, procedural), and subject (user-centric versus agent-centric). It further reviews single- and multi-agent memory operations, prompting, fine-tuning, and reinforcement-learning policies, plus evaluation benchmarks and metrics, curating 218 papers and six open challenges.

## Problem

- Benchmarks report high scores on short, isolated, static tasks, so they fail to measure long-horizon accumulation, cross-session retention, and user adaptation that real deployments demand.
- Prior memory surveys organize work by task application or human-memory analogy, without characterizing underlying substrates or modeling whose information the memory actually serves.
- Literature is fragmented across RAG, long-context modeling, cognitive architectures, personalization, and continual learning, obscuring how mechanisms relate and how deployable memory systems should be designed.

## Method

- A three-dimensional taxonomy: ==memory substrate== (external vector, text, structural stores versus internal weights, latent states, ==KV cache==), ==cognitive mechanism== (sensory, working, episodic, semantic, procedural), and ==subject== (user-centric versus agent-centric).
- A system-design analysis of memory operations, covering single-agent read, write, update, consolidate, forget primitives and multi-agent routing, isolation, and conflict handling via write control or feedback-loop consistency.
- A learning-policy axis casting memory management as trainable: static and dynamic ==prompt-driven control==, supervised ==fine-tuning== that internalizes policies into parameters, and ==reinforcement learning== at step, trajectory, and cross-episode scopes.

## Results

- Curation of **218** papers published 2023 Q1 to 2025 Q4 shows cumulative memory publications rising sharply through 2025, steepest in Q4, across all three taxonomy dimensions.
- A **15**-benchmark user-centric table spanning **ten** memory abilities finds multi-session reasoning and user preferences near-universally covered, while forgetting, update-refresh, and abstention remain sparsely or indirectly evaluated.
- Benchmark scale spans **1K**-token MSC contexts to **1.5M**-token LongMemEval and **3M**-token ConvoMem, yet early suites still score memory with BLEU, ROUGE, or perplexity, which mask recall errors.

## Takeaways

> [!tip] Key Insights
> - Memory is the substrate of self-evolution: without recording, consolidation, and reuse, every episode leaves the agent unchanged and long-horizon interaction degenerates into isolated one-shot tasks.
> - Treat memory management as a learned policy rather than heuristics; reinforcement signals supply the credit assignment that prompt-mediated reflection and frozen supervised retrieval policies lack.
> - Similarity and fluency metrics mask memory failures; memory integrity, false-memory rate, and retrieval rank attribute errors to specific memory operations instead of generation quality.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The paper positions itself within a significant paradigm shift in Artificial Intelligence, moving from an emphasis on model architecture and benchmark performance (termed the "first half" of AI development) towards prioritizing real-world utility in complex, dynamic, and user-dependent environments. Previous progress, largely driven by scaling data and model size to achieve high scores on standardized, often short-context benchmarks (e.g., MMLU, MATH), is noted as insufficient for real-world applications such as agentic coding, deep research, and computer use. In these settings, Large Language Model (LLM)-based agents encounter "context explosion," necessitating continuous accumulation, management, and selective reuse of vast amounts of information across extended interactions.

The authors identify memory as the "critical solution" to this utility gap, asserting that it is becoming the substrate for agents to self-evolve. This self-evolution involves a continuous loop where short-term memory processes experiences, and long-term memory consolidates them into reusable knowledge and skills.

The paper acknowledges existing surveys on agent memory but highlights their limitations. Prior reviews often organize memory primarily by task applications or management strategies, or adopt neuroscience-inspired analogies without systematically characterizing underlying memory substrates or explicitly modeling the memory's subject within an agent system. These approaches, according to the authors, fall short in distinguishing optimization goals and overlooking crucial connections across complementary dimensions relevant for designing real-world autonomous agents. This survey aims to address these gaps by providing a unified, multi-dimensional view of foundation agent memory, particularly focusing on its system-design implications for increasingly complex environments. The work reflects a rapid increase in memory-related research, with hundreds of papers released in 2025 alone, underscoring the growing importance of this area.

### 2. Key Objectives and Motivation

The central objective of this survey is to provide a unified and comprehensive understanding of foundation agent memory, addressing the critical utility problem faced by LLM-based agents in real-world, long-horizon, dynamic, and user-dependent settings. The core motivation stems from the recognition that current AI models, despite impressive benchmark performance, struggle with "context explosion" and the need for continuous learning and adaptation beyond static, short-context interactions.

Specifically, the key objectives and motivations are:

- **Bridging the Utility Gap:** To identify and analyze memory as the fundamental solution to enable foundation agents to operate effectively in complex real-world scenarios where persistent information management and adaptation are essential. This moves the focus from achieving high scores on simplified benchmarks to enabling practical utility.
- **Understanding Agent Self-Evolution:** To characterize memory not merely as passive storage, but as the active mechanism through which agents learn from their own experiences and continuously improve. This involves analyzing how short-term memory facilitates experience perception and abstraction, while long-term memory accumulates and consolidates knowledge and skills, forming a closed-loop system for continual learning.
- **Developing a Unified Taxonomy:** To introduce a novel, three-dimensional taxonomy for classifying foundation agent memory. This taxonomy aims to overcome the fragmentation in existing literature by systematically categorizing memory along:
 - **Memory Substrate:** The physical form in which memory is represented (internal parametric state and external retrieval-augmented stores).
 - **Memory Cognitive Mechanisms:** The functional role memory plays in the agent's cognitive pipeline (sensory, working, episodic, semantic, and procedural).
 - **Memory Subjects:** Whose information the memory is designed to capture and support (user-centric personalization and agent-centric experience).
- **Analyzing System-Design and Operational Mechanisms:** To detail how memory is instantiated and operated within agent systems, covering both single-agent and multi-agent topologies. This includes exploring memory operations such as storage, retrieval, update, compression, summarization, forgetting, and retention, as well as multi-agent considerations like architecture, routing, and isolation.
- **Investigating Memory Evolution and Optimization Policies:** To analyze how memory management itself is becoming a trainable, self-evolving capability. This involves reviewing various learning policies (prompt-driven, fine-tuning, reinforcement learning) that guide agents in deciding what, when, and how to remember, and how to transform experiences into reusable knowledge.
- **Reviewing Evaluation Methodologies and Future Challenges:** To survey existing evaluation benchmarks and metrics for assessing memory utility in agents, and to identify open challenges and promising future directions in foundation agent memory research, thereby guiding the next generation of memory system design.

In essence, the paper is motivated by the need for a coherent framework to understand, design, and evaluate memory systems that can empower LLM agents to achieve genuine, sustained autonomy and personalization in dynamic, long-horizon, real-world applications.

### 3. Methodology and Approach

This paper is a survey, and its methodology centers on a comprehensive literature review and the development of a structured analytical framework to categorize and discuss existing research on foundation agent memory.

**Literature Collection and Curation:**
The authors conducted a systematic literature search by:
1. **Querying Google Scholar** using memory-related keywords such as "agent memory," "long-term memory," "context management," and "personalization memory."
2. **Manually scrutinizing proceedings** of major computer science conferences and journals in top-tier NLP, Machine Learning (ML), Information Retrieval (IR), and Artificial Intelligence (AI) venues.
3. **Iterative Screening:** From an initial pool of several hundred papers, a selection of 218 key articles published between Q1 2023 and Q4 2025 was curated based on relevance. The rapid growth in publications during this period (especially 2025) is highlighted.

**Taxonomy Development:**
A core aspect of the methodology is the introduction of a unified, three-dimensional taxonomy to classify foundation agent memory systems. This taxonomy aims to offer a comprehensive system-design perspective:
1. **Memory Substrates:** This dimension describes the physical form of memory storage. It is categorized into:
 - **External Memory:** Information stored outside the model's parameters, including vector indices, text records, structural stores (relational tables, graph-based, tree-based), and hierarchical stores.
 - **Internal Memory:** Information stored directly within the model's architecture, covering weights (parametric memory), latent-state representations (intermediate hidden states), and KV caches (inference-time attention keys and values). Trade-offs across these substrates are analyzed (Table 1).
2. **Memory Cognitive Mechanisms:** This dimension describes the functional roles memory serves, drawing inspiration from human cognitive models. It is categorized into five atomic types:
 - **Sensory Memory:** Temporary retention of raw perceptual signals.
 - **Working Memory:** Temporary storage and active manipulation of current task-relevant information.
 - **Episodic Memory:** Persistent storage of specific, contextualized interactive experiences.
 - **Semantic Memory:** Storage of abstract facts, general concepts, and structured knowledge.
 - **Procedural Memory:** Encoding of operational skills, execution strategies, and automated routines (Table 2).
3. **Memory Subjects:** This dimension distinguishes whom the memory primarily models and serves. It is categorized into:
 - **User-Centric Memory:** Stores user-specific facts, preferences, and interaction history for personalization.
 - **Agent-Centric Memory:** Stores the agent’s own distilled knowledge, skills, and operational priors from task execution and environment interaction.

**Analytical Framework:**
Beyond the taxonomy, the survey employs a structured analytical framework to discuss various aspects of foundation agent memory:
- **Memory Operation Mechanisms (Section 4):** Details the procedures agents use to construct, organize, access, and maintain memory. This includes five core single-agent operations (storage & index, loading & retrieval, update & refresh, compression & summarization, forgetting & retention) and extends to multi-agent considerations (memory architecture, routing, isolation, and conflict resolution) (Figure 6).
- **Memory Evolution and Optimization Policies (Section 5):** Examines how agents acquire policies for managing memory. This is categorized by optimization mechanism: prompt-driven control (static and dynamic), fine-tuning (policy internalization, stabilization, efficiency), and reinforcement learning (step-level, trajectory-level, cross-episode/multi-agent) (Figure 7).
- **Evolving and Scaling (Section 6):** Discusses how memory systems address scalability issues in increasingly complex environments, considering long-horizon interactions, environmental complexity, and multi-agent systems, contrasting with context-limited settings.
- **Evaluation (Section 7):** Reviews metrics (accuracy-based, similarity-based, LLM-as-a-judge) (Table 3) and benchmarks (user-centric and agent-centric) (Tables 4 and 5) used to assess memory performance.
- **Applications (Section 8):** Summarizes representative works and memory utilization across various application domains (education, scientific research, gaming, robotics, healthcare, dialogue systems, workflow automation, software engineering, online streaming/recommendation, information search, finance/accounting, and legal/consulting) (Table 6, Figure 8).
- **Future Directions (Section 9):** Identifies six open challenges and promising research avenues (Figure 9).

By adopting this multi-faceted approach, the authors aim to provide a comprehensive, systematic, and actionable overview of the field, enabling researchers to better understand, design, and deploy autonomous agent systems in realistic settings.

### 4. Main Findings and Results

The paper's main findings and results are presented through its comprehensive taxonomy, detailed analysis of memory mechanisms, and review of current research, emphasizing the shift towards memory as a self-evolving substrate for foundation agents.

**1. Unified Taxonomy of Foundation Agent Memory:**
The survey's primary contribution is a three-dimensional taxonomy that unifies fragmented research:
- **Memory Substrates:** The paper delineates **internal memory** (model weights, latent states, KV caches) which offers fast, integrated recall but is costly to update and prone to forgetting, and **external memory** (vector indices, text records, structural stores like graphs/trees, hierarchical stores) which provides scalability, explicit editing, and cross-session persistence but can introduce retrieval latency and noise. A comparative analysis (Table 1) highlights these trade-offs, suggesting hybrid architectures are optimal.
- **Memory Cognitive Mechanisms:** Five cognitive types are identified:
 - **Sensory Memory:** Transient buffers for raw perceptual inputs, becoming critical for multimodal and embodied agents.
 - **Working Memory:** The active context where agents maintain and manipulate task-relevant state under capacity constraints; its management is increasingly learned.
 - **Episodic Memory:** Stores specific contextualized interaction histories for background reconstruction and cross-session continuity.
 - **Semantic Memory:** Accumulates abstract facts, concepts, and schemas, derived from distilled episodic memories, forming a stable knowledge base.
 - **Procedural Memory:** Encodes reusable skills, routines, and workflows, increasingly externalized as shareable "agent skills" (Table 2). These mechanisms collectively form a loop where short-term processes experiences for long-term consolidation.
- **Memory Subjects:** Memory is characterized by its primary beneficiary:
 - **User-Centric Memory:** Focuses on storing persistent user facts (preferences, goals, history) to enable long-term personalization, consistent dialogue, and realistic user simulation, while emphasizing privacy preservation.
 - **Agent-Centric Memory:** Captures the agent's own accumulated knowledge, skills, and operational priors from task execution to support long-horizon task completion, domain-specific problem-solving, cross-task generalization, and continuous skill evolution. The relationship between subjects and cognitive mechanisms is explored (Figure 5).

**2. Memory Operation Mechanisms:**
The survey details how memory is actively manipulated:
- **Single-Agent Operations:** Includes storage and indexing (vector, structured, text formats), loading and retrieval (filtering, ranking, injection), update and refresh (revising content, adjusting prominence), compression and summarization (condensing histories), and forgetting and retention (selectively removing obsolete data while preserving high-utility knowledge) (Figure 6).
- **Multi-Agent Operations:** Introduces architectural considerations (private-only, shared-workspace, hybrid, orchestrated), routing mechanisms (orchestrator-based, agent-initiated, memory-driven), and strategies for memory isolation and conflict resolution (write control, feedback loops) to ensure consistency and efficiency in collaborative settings.

**3. Memory Evolution and Optimization Policies:**
The paper finds a progression in how memory policies are acquired:
- **Prompt-Driven Control:** Utilizes natural language prompts to guide memory operations without modifying model parameters. This includes static, predefined rules and dynamic approaches that adapt based on reflection or feedback (e.g., Reflexion).
- **Fine-Tuning:** Internalizes memory policies into model parameters through supervised learning, enabling more stable, reusable, and efficient behaviors for content internalization, policy stabilization, and retrieval refinement.
- **Reinforcement Learning (RL):** Optimizes memory policies through interaction and reward feedback, allowing memory construction and management to become a learnable skill, spanning step-level decisions, trajectory-level representation learning, and cross-episode/multi-agent memory coordination (Figure 7).

**4. Scaling and Real-World Challenges:**
A key finding is that context-limited simple environments of traditional benchmarks fail to represent real-world "context explosion." Scalable memory is crucial for long-horizon interactions, accommodating increasingly complex environmental states (heterogeneous data, asynchronous tools, evolving schemas), and functioning across multiple environments and agents. This necessitates explicit, system-level memory management beyond simple context window expansion.

**5. Evaluation Gaps:**
The review of evaluation metrics (accuracy-based, similarity-based, LLM-as-a-judge) (Table 3) and benchmarks (user-centric and agent-centric, Tables 4 and 5) reveals that current evaluation largely under-specifies real-world memory demands. Benchmarks often lack explicit measurement of long-term consistency, adaptation to preference drift, selective forgetting, or efficiency trade-offs, making it difficult to fully attribute performance to memory mechanisms.

**6. Broad Application Impact:**
The survey illustrates memory's transformative role across diverse applications, including education, scientific research, gaming, robotics, healthcare, dialogue systems, workflow automation, software engineering, online streaming/recommendation, information search, finance, and legal/consulting (Table 6, Figure 8). In each domain, memory is found to enable critical capabilities such as personalization, knowledge synthesis, skill acquisition, and strategic consistency.

In summary, the paper systematically demonstrates that memory is no longer a peripheral component but a central, actively managed, and increasingly self-evolving capability that underpins the utility and autonomy of foundation agents in complex, long-horizon real-world settings.

### 5. Significance and Potential Impact

This survey paper holds significant implications for the field of Artificial Intelligence, particularly in the development and deployment of advanced foundation agents. Its potential impact spans several key areas:

**1. Unifying and Structuring Research:**
The most immediate impact is the provision of a **unified, multi-dimensional taxonomy** for foundation agent memory. By classifying memory along its substrate, cognitive mechanism, and subject, the survey offers a coherent framework that can help organize the rapidly growing and often fragmented research landscape. This structure can enable researchers to:
- **Identify gaps:** Pinpoint areas where certain memory types or architectural considerations are underdeveloped.
- **Foster interdisciplinary connections:** Bridge concepts from neuroscience, cognitive psychology, and various computer science subfields (e.g., RAG, continual learning, multi-agent systems).
- **Improve communication:** Provide a common language and conceptual model for discussing agent memory design.

**2. Guiding System Design for Real-World Utility:**
The paper strongly emphasizes moving beyond idealized benchmarks to tackle the "critical utility problem" in real-world environments characterized by long-horizon interactions, dynamic contexts, and user dependencies. By detailing memory operation mechanisms, architectural considerations, and learning policies, the survey provides a **roadmap for designing more robust, adaptive, and scalable agent systems**. This can lead to:
- **More capable agents:** Agents that can manage context explosion, learn from their own experiences, maintain long-term coherence, and adapt to evolving user needs.
- **Improved agent autonomy:** By enabling memory management itself to be a trainable, self-evolving capability, agents can become less reliant on human-designed heuristics and more self-sufficient.
- **Informed trade-offs:** The analysis of memory substrate trade-offs (e.g., speed vs. scalability, update flexibility vs. forgetting risk) offers practical guidance for engineers and researchers in selecting appropriate memory designs for specific applications.

**3. Advancing Agent Self-Evolution and Continual Learning:**
The survey highlights memory as the "substrate of agent self-evolution itself." This perspective is crucial for developing lifelong learning agents that can continuously improve after deployment. The detailed analysis of prompt-driven, fine-tuning, and reinforcement learning policies for memory optimization lays the groundwork for:
- **More sophisticated learning algorithms:** Techniques that enable agents to distill experiences into reusable knowledge, adapt to new environments, and mitigate catastrophic forgetting.
- **Novel agent architectures:** Designs that integrate internal and external memory systems in a mutually reinforcing loop for sustained adaptation.

**4. Elevating Evaluation Standards:**
By critically reviewing existing metrics and benchmarks, the paper exposes limitations in current evaluation methodologies that often fail to assess true long-horizon, adaptive memory capabilities. This can catalyze the development of **new, more rigorous benchmarks** that:
- **Measure long-term consistency and adaptability:** Evaluate how well agents handle preference drift, conflicting information, and persistent state over extended periods.
- **Account for efficiency and resource constraints:** Assess memory quality in relation to computational cost, storage, and latency, reflecting real-world deployment challenges.
- **Probe memory-specific failure modes:** Go beyond end-task accuracy to identify issues like hallucinated memories or incorrect retention.

**5. Impact Across Application Domains:**
The comprehensive overview of memory's role across a wide array of application domains (education, healthcare, robotics, finance, etc.) demonstrates its **broad transformative potential**. This can encourage researchers and practitioners in these fields to:
- **Innovate with memory-centric designs:** Leverage advanced memory mechanisms to create personalized educational tutors, more accurate scientific research assistants, safer healthcare agents, and more efficient workflow automation tools.
- **Address domain-specific challenges:** Recognize how memory can solve particular problems like maintaining strategic consistency in finance or managing legal provenance.

**6. Addressing Trustworthiness and Ethics:**
The discussion on lifelong personalization implicitly raises concerns about privacy and security. By explicitly calling for "Lifelong Personalization and Trustworthy Memory" as a future direction, the paper underscores the importance of **ethical considerations in memory design**. This can drive research into:
- **Privacy-preserving memory architectures:** Mechanisms for user-controlled deletion, transparent auditing, and defense against memory extraction attacks.
- **Robustness against adversarial manipulation:** Safeguards to ensure the integrity and reliability of stored information in dynamic environments.

In conclusion, this survey serves as a foundational reference and forward-looking agenda for the field of foundation agent memory. Its comprehensive scope, systematic categorization, and identification of critical challenges are poised to significantly influence the direction of research and accelerate the development of truly intelligent, self-evolving, and reliable AI agents for real-world impact.
