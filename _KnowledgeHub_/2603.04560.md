# From Local Corrections to Generalized Skills: Improving Neuro-Symbolic Policies with MEMO

> [!summary] Summary
> MEMO, a framework from Virginia Tech, enables robots to expand their skill sets by using a retrieval-augmented skillbook that aggregates and generalizes human feedback and successful code snippets. It achieves a 78% task success rate in simulation and 88% in real-world manipulation tasks with fewer human interventions compared to baseline methods.

## Problem

- Current neuro-symbolic robot control policies are limited by static, predefined skill libraries, preventing task completion if a required skill is missing.
- Robots struggle to ground complex semantic subtasks into executable motions when existing skills are insufficient for novel contexts.
- While humans provide local natural language corrections, leveraging this feedback for long-term, generalized skill acquisition remains a challenge.

## Method

- **MEMO** introduces a ==retrieval-augmented skillbook== that systematically collects and stores human language corrections and successful robot code snippets.
- Human feedback is ==paraphrased into general descriptions==, and successful executed code is converted into ==parameterized function templates==, both stored as skillbook entries.
- An ==offline clustering process== aggregates related skillbook entries, prunes inconsistent feedback, and synthesizes generalized language guidance and new parameterized code functions, conditioned on successful templates.

## Results

- **MEMO** achieved a **78%** task success rate on five held-out simulation tasks, outperforming DROC-V (**40%**) and MEMO-C (**42%**).
- In real-world evaluations, **MEMO** attained an **88%** average success rate with an average of **1.52** human feedback instances per task, compared to π0.5's **12%** and DROC-V's **60%** with **2.76** feedback instances.
- The clustering mechanism was critical, as MEMO without clustering (MEMO-C) showed **reduced performance** due to retrieval of incorrect or extraneous feedback, demonstrating the importance of generalization.

## Takeaways

> [!tip] Key Insights
> - Aggregating and generalizing local human language feedback and successful actions into a dynamic skillbook can significantly expand a robot's functional repertoire.
> - Offline clustering, especially when conditioned on successful code templates, is crucial for resolving conflicting feedback, removing redundancy, and creating robust, generalized skills.
> - Synthesizing parameterized code templates from successful subtask executions allows the robot to learn new, adaptable skills that go beyond its initial capabilities.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of robotics is progressing towards more general-purpose systems capable of performing complex manipulation tasks. Neuro-symbolic approaches are a promising direction, combining the pattern recognition and reasoning capabilities of neural networks (often large foundation models) with structured symbolic logic and control. These frameworks allow robots to break down high-level natural language instructions (e.g., "toast food") into semantic subtasks (e.g., "open the door").

A fundamental challenge in this paradigm is the "grounding problem"—converting ambiguous natural language subtasks into precise, executable robot motions. Existing research addresses this by equipping robots with libraries of "skills," which are predefined motion primitives or simple policies associated with semantic characteristics and interpretable parameters (e.g., a `grasp(pose)` skill). While effective for known domains, the reliance on a finite, predefined set of skills inherently constrains the robot's capabilities. If a required skill is not available or cannot be generated, the policy fails.

Prior work in this area includes:
- **Robotics Vision-Language-Action (VLA) models** like RT-2, Octo, and $\pi^{0.5}$, which learn direct mappings from observations and language instructions to robot actions. These models, while demonstrating generalization, often operate as monolithic policies, making adaptation to new behaviors difficult without extensive data or fine-tuning.
- **Neuro-symbolic approaches with skill libraries** such as SayCan and ProgPrompt, which use foundation models to select and parameterize skills from a predefined set. These systems still face the limitation of a finite skill repertoire.
- **Code generation approaches** like Code as Policies and Language Movement Primitives (LMP), which generate open-ended code or parameterize general motion controllers at test time. Even with these, the generated behaviors can still fail to complete tasks.
- **Skill learning from feedback and experience**, where systems like Voyager generate executable programs and store successful behaviors, or DROC distill language corrections into text-based knowledge bases. However, these methods primarily adjust existing skill parameters or task plans, remaining limited by the original skill set.
- **Retrieval-Augmented Generation (RAG) in robotics**, where systems like PragmaBot and DROC retrieve past experiences, corrections, or summaries to augment decision-making. ELLMER retrieves code examples from curated knowledge bases. These approaches retrieve existing information but generally do not focus on actively evolving or synthesizing new, generalized executable code templates from aggregated, varied feedback.

MEMO distinguishes itself by addressing the bottleneck of fixed skill libraries through the dynamic expansion of robot skills. It leverages human feedback not merely for local corrections or adjustments, but to synthesize *generalized*, parameterized code functions and text guidance that enable the creation of *novel* skills. Unlike approaches that rely on static or text-based memories, MEMO actively evolves its knowledge base by clustering raw human feedback and successful code, thereby moving towards a continuously growing set of capabilities that extends beyond initial programming or foundational model output.

### 2. Key Objectives and Motivation

The central objective of this research is to enable neuro-symbolic robot policies to dynamically expand their skill sets, thereby overcoming the limitations imposed by predefined or fixed skill libraries. This aims to improve the robot's ability to generalize to novel tasks and configurations that were not part of its initial training or existing skill repertoire.

The motivation behind this work stems from the inherent bottleneck in current neuro-symbolic robotics:
- **Constraint of Existing Skills:** While vision and language models are proficient at breaking down complex tasks into semantic subtasks, they are constrained by the available skills to ground these subtasks into embodied motions. If the robot lacks the necessary skill for a given subtask (e.g., opening a specific type of door), its policy will inevitably fail.
- **Ambiguity of Language to Motion Conversion:** Natural language instructions are inherently ambiguous, making it difficult to convert high-level semantic subtasks directly into precise, low-level robot control parameters. Skills serve as an effective intermediate layer, but their finite nature limits overall capability.
- **Inefficiency of Local Corrections:** Humans can intuitively provide natural language feedback when a robot fails (e.g., "no, go higher"). While simply recalling this exact text for similar future situations can provide local adaptation, it does not lead to generalized, long-term improvements across different tasks or contexts.

To address these limitations, the authors hypothesize that by collecting, clustering, and re-phrasing natural language corrections from multiple users across various tasks, it is possible to synthesize more general text guidance and coded skill templates. This aggregated knowledge, stored in a retrieval-augmented "skillbook," can then guide the robot's policy in generating new, more effective skills.

The specific contributions of this work are:
1. **Collecting and Retrieving Feedback:** Introducing a "skillbook," a database that stores both human feedback (paraphrased into task-specific and task-invariant entries) and successful robot code (converted into generalized templates). These entries can be retrieved to inform the robot's actions in similar contexts.
2. **Clustering Feedback around Skill Templates:** Developing an offline process to cluster skillbook entries, conditioned on successful code templates. This process aims to remove repetitive or contradictory feedback, summarize multiple human corrections, and distill more general guidance. This generalized knowledge is then used at runtime to generate code for new skills.
3. **Improving Beyond Local Feedback:** Demonstrating that by aggregating local feedback into general skill templates, the robot achieves enhanced generalization to novel tasks, surpassing the performance of baselines that rely solely on foundational models or context-specific human feedback.

In essence, the research is motivated by the desire to create general-purpose robots that can autonomously expand their capabilities over time through intuitive human interaction, moving beyond fixed skill sets towards continuous learning and adaptation.

### 3. Methodology and Approach

The proposed method, Memory Enhanced Manipulation (MEMO), aims to convert localized human feedback into generalized, reusable skills by building and maintaining a retrieval-augmented skillbook (denoted as S). The robot's policy, previously defined as $\pi(\cdot | \tau, G, \rho)$, is re-defined to explicitly condition on this adaptive skillbook: $\pi(\cdot | \tau, G, \rho, S)$, where $\tau$ is the user task description, $G$ is the scene graph, and $\rho$ is a fixed prior (e.g., a task-invariant system prompt).

MEMO operates through three primary stages: Collecting Feedback, Retrieving Relevant Entries, and Clustering Entries into Generalized Skills.

**A. Collecting Feedback into Skillbook Entries**
The skillbook S is structured as a vector database, $S = \{(v, s)\}$, where $v$ is an embedding vector serving as a key, and $s$ contains the associated skill information.

1. **Parsing Human Feedback:**
 - During robot operation, a human user can intervene and provide natural language feedback about a robot's mistake.
 - A language model (LM) is then employed to paraphrase this feedback. This step aims to remove task-specific details, redundancy, or irrelevant information, yielding more general guidance (e.g., "place its end-effector at position (0.5, -0.3, 0.2) to grab the handle" becomes "move to the door handle").
 - The paraphrased text ($s$) is stored as a new entry in S. The embedding vector ($v$) for this entry is constructed from two parts: an action token (e.g., "open") and an object token (e.g., "toaster" and/or "door") relevant to the subtask where feedback was given.
 - The LM also attempts to extract higher-level, task-invariant corrections (e.g., "ensure the robot stays a safe height above the table" from "you hit the table"). These general statements are indexed with a shared global key ($v_g$) in the skillbook, making them applicable across diverse contexts.

2. **Leveraging Task Success as Implicit Feedback:**
 - When the robot successfully completes a subtask, the executable code it generated for that subtask is converted into a generalized function template.
 - The LM processes this code, abstracting away hardcoded values and introducing parameters based on environmental elements like the scene, robot configuration, and object positions.
 - This generalized code template ($s_f$) is stored in the skillbook. Its retrieval vector ($v_f$) also incorporates the action performed and the objects interacted with. This reinforces correct behaviors by making successful strategies available for future tasks.

**B. Retrieving Relevant Skillbook Entries**
As the skillbook grows, it becomes impractical to pass all entries to the policy's language model due to context window limitations and performance degradation. MEMO employs a Retrieval-Augmented Generation (RAG) approach to select the most relevant entries.

1. **Subtask Decomposition:** The neuro-symbolic policy first uses a vision and language model to decompose the user's task ($\tau$) into a semantic sequence of subtasks (e.g., "toast food" $\rightarrow$ "open the toaster").
2. **Query Formulation:** For the current subtask, the policy forms a query $q = \{q_{act}, q_{obj}\}$ based on the intended action and objects.
3. **Similarity Search:** This query is compared against the embedding vectors ($v$) of the entries in the skillbook using a weighted cosine similarity function:
 $r(q, v) = \frac{1}{\lambda_1 + \lambda_2} (\lambda_1 \cos(q_{act}, v_{act}) + \lambda_2 \cos(q_{obj}, v_{obj}))$
 where $\lambda_1, \lambda_2 > 0$ are hyperparameters. A higher $\lambda_1$ emphasizes action similarity (e.g., "grasping" retrieves "grab," "pick up").
4. **Context Augmentation:** The top-k most relevant entries retrieved from S are added to the context window of the policy $\pi$.
5. **Code Generation:** The robot's policy then generates new code for the current subtask, reasoning over its static system prompt $\rho$ and the retrieved skillbook entries. It does not merely copy templates but uses them as references to construct new, context-specific embodied motions.

**C. Clustering Entries into Generalized Skills**
To ensure scalability, prevent redundancy, resolve contradictions, and extract truly generalized knowledge, MEMO performs an offline clustering process on the skillbook.

1. **Grouping:** Skillbook entries are grouped into clusters $C_k = \{(v_k, s_i)\}_{i=1}^{n_k}$ based on shared embedding vectors $v_k$.
2. **Condensing and Generalization:** Each cluster $C_k$ is passed through a language model. The goal is to obtain a condensed set of feedback descriptions $C'_k$ that combine similar entries and remove redundant or contradictory information.
3. **Conditioning on Success:** Crucially, this condensation process is conditioned on any related function templates ($v_f, s_f$) that were generated from successful subtask executions. This ensures that the clustered feedback remains consistent with successful behaviors and helps prune erroneous or unhelpful human guidance.
4. **Refined Skillbook:** The output $C'_k$ is a refined set of skillbook entries, equal to or smaller in size (number of entries and characters) than the original cluster. These entries represent more invariant, generalized guidance and code templates. This process improves the quality of retrieval by providing a more compact, mutually exclusive set of guidance for the policy to reason over, leading to better skill generation.

This integrated approach allows MEMO to continuously learn and refine its capabilities, dynamically expanding the robot's action space from local human corrections and successful experiences.

### 4. Main Findings and Results

The experiments conducted aimed to evaluate MEMO's capabilities in zero-shot generalization, the efficacy of its clustering mechanism, and its transferability to real-world scenarios.

**Experimental Setup:**
- **Robot System:** A 7-DoF Franka Emika Panda robot with a UMI gripper was used for both simulated and real-world experiments.
- **Tasks:** 25 tabletop manipulation tasks were selected, categorized by type: Long-Horizon planning (LH), Contact-Rich manipulation (CR), Semantic Reasoning (SR), and Translational and Rotational control (TR). Twenty tasks were used for skillbook creation (feedback collection), and five held-out tasks were reserved for evaluation.
- **Perception (Real World):** An Orbbec Femto Mega RGB-D camera and two Intel RealSense D435 cameras (one wrist-mounted, one side-view) provided visual input. Gemini Robotics-ER 1.5 and LangSAM were used for 3D object detection, segmentation, and bounding box reconstruction. ArUco markers were used for specific object component pose estimation.
- **Language Models:** `gemini-3-flash-preview` was used as the large language model, and `all-MiniLM-L6-v2` as the sentence transformer for embeddings.
- **Metrics:** Task success rate over five trials was reported for all methods.
- **Baselines and Ablations:**
 - **DROC-V:** A neuro-symbolic approach that stores human feedback for context-specific corrections, similar to MEMO but without code templates, general feedback, or clustering.
 - **$\pi^{0.5}$:** A representative vision-language-action (VLA) model, trained on 20,000 steps of real-world demonstrations across all 25 tasks.
 - **MEMO-C:** An ablation of MEMO without the clustering stage.
 - **MEMO-S (TrajGen):** An ablation of MEMO without any skillbook, equivalent to a language model generating trajectories from scratch.

**A. Building the Skillbook: Human Subject Study**
- **Participants:** 20 human subjects (age 24 ± 5.5, 7 female, 13 male) provided free-form natural language feedback on the 20 training tasks in simulation. Some participated multiple times.
- **Protocol:** Sessions lasted 30 minutes, with participants interrupting the robot to provide feedback, which was then paraphrased, labeled, and added to the skillbook. The environment reset, and the robot re-attempted the subtask with the updated skillbook.
- **Feedback Volume:** A total of 224 feedback entries were collected across three rounds of interaction, requiring 13, 4, and 3 participants for each round, respectively.

**B. Zero-Shot Generalization (Simulation)**
- **Performance:** MEMO achieved a 78% task success rate on the five held-out evaluation tasks, significantly outperforming TrajGen (28%) and DROC-V (40%). This indicates that the skillbook and its mechanisms (code templates, general feedback, clustering) enable generalization to unseen task configurations.
- **Impact of Skillbook Growth:** As the skillbook grew with more user interaction data (up to 12 hours), MEMO's performance consistently improved, while MEMO-C and DROC-V tended to stagnate without the clustering of local corrections into generalized guidance.
- **Clustering's Role:** The clustering mechanism (difference between MEMO and MEMO-C) contributed to a 36% improvement in success rate, particularly evident after significant amounts of feedback (beyond the 10-hour mark), suggesting its importance for scaling.

**C. Skillbook Clustering (Detailed Analysis)**
- **Task-Specific Improvements:** Analyzing individual held-out tasks revealed the specific benefits of clustering. For instance, in the "Pour the Can" task, MEMO achieved 100% success, whereas MEMO-C (without clustering) only managed 40%.
- **Mitigation of Erroneous Retrieval:** The inferior performance of MEMO-C in some tasks (e.g., "Empty the Cabinet", "Close the Bottle", "Pour the Can") was attributed to its retrieval of incorrect or extraneous feedback from an unclustered skillbook, leading to ineffective skill generation.
- **Compression and Resolution:** These results underscore that clustering is crucial not only for simplifying context and managing skillbook size but also for resolving conflicting or irrelevant feedback, thereby enhancing the quality and relevance of retrieved guidance.

**D. Real-World Evaluation**
- **Cross-Environment Transfer:** The skillbook constructed in simulation was directly applied to a real-world Franka Emika Panda robot for the same five held-out evaluation tasks.
- **Superior Performance:** MEMO demonstrated an 88% overall success rate, significantly outperforming MEMO-C (84%), DROC-V (60%), and $\pi^{0.5}$ (12%).
- **Efficiency in Real World:** Importantly, MEMO achieved this high performance with considerably less human feedback required *during real-world evaluation* (an average of 1.52 pieces of feedback per task attempt) compared to MEMO-C (2.2) and DROC-V (2.76).
- **Transferability:** The ability of MEMO to extrapolate code for new and performant skills in the real world, using feedback collected solely in simulation, suggests effective cross-task and cross-environment skill transfer.

In summary, the findings indicate that MEMO effectively utilizes aggregated human feedback and successful code snippets to dynamically expand a robot's skill set. The clustering mechanism is critical for generalizing local corrections, resolving ambiguities, and improving retrieval accuracy, leading to enhanced zero-shot generalization capabilities in both simulated and real-world environments.

### 5. Significance and Potential Impact

This research presents a notable advancement in robot learning and neuro-symbolic AI, with several areas of significance and potential impact:

1. **Dynamic Skill Expansion:** MEMO provides a method for robots to dynamically expand their skill repertoire beyond predefined libraries. This capability is fundamental for achieving general-purpose robots that can adapt to novel situations and execute tasks in unstructured, changing environments without continuous manual programming or extensive retraining. It moves neuro-symbolic policies closer to addressing the long-standing grounding problem more effectively.

2. **Efficient Human-Robot Interaction for Learning:** The approach leverages intuitive natural language feedback from humans to inform robot learning. By transforming local, specific corrections into generalized skill templates and guidance, MEMO makes human oversight a more efficient and scalable mechanism for long-term robot improvement, rather than just immediate task correction. This reduces the burden on human operators and potentially lowers the barrier for non-expert users to teach robots.

3. **Enhanced Zero-Shot Generalization:** The demonstrated superior zero-shot success rates in both simulated and real-world held-out tasks indicate MEMO's ability to generalize to unseen configurations and tasks. This is crucial for deploying robots in dynamic environments where every possible task or object interaction cannot be explicitly pre-programmed or demonstrated.

4. **Robustness and Scalability through Clustering:** The introduction and validation of the clustering mechanism are significant. It addresses critical issues of information overload, redundancy, and contradictory feedback that arise in growing knowledge bases. By distilling complex feedback into concise, generalized, and consistent guidance, MEMO enhances the robustness and scalability of the skillbook, ensuring that the robot's learning remains efficient and effective over time.

5. **Cross-Environment Skill Transfer:** The ability to collect human feedback in simulation and successfully apply it to real-world robot tasks is a substantial practical implication. This reduces the need for costly and time-consuming real-world data collection, accelerating the development and deployment cycle of new robotic capabilities. It suggests a pathway for developing robot skills in virtual environments and then transferring them with minimal real-world adjustments.

6. **Advancement in Neuro-Symbolic Integration:** MEMO represents a step forward in integrating the strengths of large language models with grounded physical control. By augmenting LLM reasoning with a curated and evolving skillbook, it mitigates the common challenge of converting abstract language commands into precise robot actions, making the neuro-symbolic framework more capable and practical.

7. **Foundation for Continuous Learning Robots:** The framework lays a foundation for robots that can continuously learn and self-improve throughout their operational lifespan. As robots accumulate more experience and human feedback, their skillbook evolves, leading to an ever-expanding set of capabilities and adaptability to a wider range of open-ended tasks. This aligns with the vision of lifelong learning in robotics.

In conclusion, MEMO contributes a novel and effective method for improving robot manipulation policies by dynamically expanding skill sets through aggregated human feedback and successful code. Its emphasis on generalization and robustness through clustering, coupled with demonstrated cross-environment transferability, marks a significant step towards more autonomous, adaptable, and general-purpose robots.
