# From Local Corrections to Generalized Skills: Improving Neuro-Symbolic Policies with MEMO

> [!summary] Summary
> MEMO, a framework from Virginia Tech, enables robots to expand their skill sets by using a retrieval-augmented skillbook that aggregates and generalizes human feedback and successful code snippets. It achieves a 78% task success rate in simulation and 88% in real-world manipulation tasks with fewer human interventions compared to baseline methods.

## Problem

- Current neuro-symbolic robot control policies are limited by static, predefined skill libraries, preventing task completion if a required skill is missing.
- Robots struggle to ground complex semantic subtasks into executable motions when existing skills are insufficient for novel contexts.
- While humans provide local natural language corrections, leveraging this feedback for long-term, generalized skill acquisition remains a challenge.

## Method

- **MEMO** introduces a ==retrieval-augmented skillbook== that systematically collects and stores human language corrections and successful robot code snippets.
- Human feedback is ==paraphrased into general descriptions==, and successful executed code is converted into ==parameterized function templates==, both stored as skillbook entries.
- An ==offline clustering process== aggregates related skillbook entries, prunes inconsistent feedback, and synthesizes generalized language guidance and new parameterized code functions, conditioned on successful templates.

## Results

- **MEMO** achieved a **78%** task success rate on five held-out simulation tasks, outperforming DROC-V (**40%**) and MEMO-C (**42%**).
- In real-world evaluations, **MEMO** attained an **88%** average success rate with an average of **1.52** human feedback instances per task, compared to π0.5's **12%** and DROC-V's **60%** with **2.76** feedback instances.
- The clustering mechanism was critical, as MEMO without clustering (MEMO-C) showed **reduced performance** due to retrieval of incorrect or extraneous feedback, demonstrating the importance of generalization.

## Takeaways

> [!tip] Key Insights
> - Aggregating and generalizing local human language feedback and successful actions into a dynamic skillbook can significantly expand a robot's functional repertoire.
> - Offline clustering, especially when conditioned on successful code templates, is crucial for resolving conflicting feedback, removing redundancy, and creating robust, generalized skills.
> - Synthesizing parameterized code templates from successful subtask executions allows the robot to learn new, adaptable skills that go beyond its initial capabilities.
