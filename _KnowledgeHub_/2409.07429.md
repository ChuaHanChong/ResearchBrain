# Agent Workflow Memory

> [!summary] Summary
> Agent Workflow Memory (AWM) lets language model agents induce reusable routines, called workflows, from past trajectories and inject them into memory to guide later actions. It works offline from training examples or online from test queries. It raises relative success rate by 24.6% on Mind2Web and 51.1% on WebArena, with fewer steps.

## Problem

- Language model agents struggle on long-horizon web tasks with complex action trajectories, failing to compose many steps into a successful plan.
- Current agents use a fixed set of given examples through training or in-context learning, so they cannot learn from their own experience as they act.
- Humans distill reusable task workflows from past experience, but existing agents lack a mechanism to induce, store, and selectively reuse such routines across tasks and domains.

## Method

- ==Workflow induction==: an LM-based module abstracts commonly reused routines, with example-specific values replaced by ==placeholders==, from past successful trajectories into reusable workflows.
- ==Workflow memory== integration: induced workflows are added to the agent's memory and provided in context to guide later action generation, and later workflows can build on earlier ones.
- Two deployment modes: ==offline== **AWM** induces workflows from training examples beforehand, while ==online== **AWM** induces them on the fly from test queries, judged successful without ground-truth labels, in a growing loop.

## Results

- On WebArena, AWM improves baseline success rate by **51.1%** relative and reduces the number of steps taken to solve tasks successfully.
- On Mind2Web, AWM improves the baseline by **24.6%** relative success rate across **1000+** tasks from **200+** domains such as travel, shopping, and social media.
- Online AWM generalizes across task, website, and domain splits, beating baselines by **8.9** to **14.0** absolute points as the train-test distribution gap widens.

## Takeaways

> [!tip] Key Insights
> - Abstracting experience into reusable, parameterized sub-routines gives agents transferable procedural knowledge, more useful than storing raw example trajectories as in-context demonstrations.
> - Agents can improve continually at test time by inducing workflows from their own successful attempts, without labeled data, which suits settings where training data is scarce.
> - Workflow memory helps most when the train-test gap is large, so the benefit comes from reusable abstraction, not memorization of specific tasks or websites.

## Detailed Report

### 1. Introduction

Language Model-based agents have shown remarkable capabilities in performing tasks in digital environments such as web navigation, mobile app operation, and robotic control. However, these agents often struggle with long-horizon tasks that require complex action sequences, particularly when faced with changes in task contexts or environments. While humans naturally learn reusable task workflows from past experiences and apply them to new situations, current LLM-based agents lack this crucial ability.

The paper "Agent Workflow Memory" by researchers from Carnegie Mellon University and MIT introduces a method that enables language model-based agents to learn and reuse task workflows, significantly improving their performance on complex tasks. This approach draws inspiration from human cognition, specifically how we build memory of task routines and leverage them to guide future actions.

### 2. Understanding Agent Workflow Memory

Agent Workflow Memory (AWM) is a method that allows agents to extract and reuse task workflows from their past experiences. These workflows represent commonly used routines that can guide the agent in performing similar tasks in the future. Unlike traditional approaches that rely on fixed examples or human annotations, AWM enables agents to autonomously learn from their own experiences.

The core mechanism of AWM involves:

1. **Inducing workflows**: Extracting reusable routines from past experiences
2. **Storing workflows in memory**: Building a repository of task-specific workflows
3. **Applying workflows**: Selectively providing these workflows to guide the agent during new tasks

### 3. Workflow Representation and Induction

In AWM, a workflow consists of:

- A textual description that summarizes the workflow's function
- A series of steps to complete the workflow

Each step in a workflow includes:
- A description of the current environment state in natural language
- The reasoning process for deciding the next action
- The action itself, represented as an executable program

The workflow induction process uses a language model to extract common sub-routines from past experiences. This induction focuses on:

1. Identifying fine-granularity sub-tasks that appear across different experiences
2. Abstracting example-specific contexts to create more general workflows
3. Creating workflows that capture the essential patterns while ignoring irrelevant details

For example, a workflow for "finding a specific location on a map" might include steps like searching for the location, identifying it on the map, and selecting it from a list of options.

### 4. Key Implementation Scenarios

AWM can operate in two primary scenarios:

1. **Offline AWM**: In this approach, workflows are extracted from training examples beforehand and integrated into the agent's memory for test-time inference. This is useful when a corpus of successful task completions is available.

2. **Online AWM**: Here, workflows are induced on the fly in a supervision-free setting. The agent learns from its own successful predictions and continuously updates its workflow memory as it encounters new tasks.

Online AWM is particularly powerful as it enables continual learning - the agent's capabilities improve as it completes more tasks, similar to how humans develop expertise through repeated practice.

### 5. Experimental Results

The researchers evaluated AWM on two established web navigation benchmarks:

1. **WebArena**: A complex web navigation environment with realistic websites
2. **Mind2Web**: A diverse set of web tasks across multiple domains

The results demonstrated significant improvements:

- On WebArena, AWM improved baseline results by 51.1% relative success rate
- AWM surpassed methods augmented with human-written workflows by 7.9%
- On Mind2Web, AWM improved cross-task results by 24.6% in relative step-wise success rate

AWM also reduced the number of steps required to solve tasks successfully, indicating that the agent was learning more efficient approaches.

### 6. Learning and Generalization Capabilities

One of the most impressive aspects of AWM is its ability to generalize across different scenarios. The experiments demonstrated that:

1. **Cross-task generalization**: AWM can apply workflows learned from one type of task to other related but different tasks.

2. **Cross-website generalization**: Workflows learned on one website can be effectively applied to similar tasks on different websites.

3. **Cross-domain generalization**: Even more impressively, AWM shows the ability to generalize across different domains (e.g., from e-commerce to travel websites).

As the gap between training and testing task distributions widened, AWM consistently outperformed baselines by 8.9 to 14.0 absolute percentage points, highlighting its robust generalization capabilities.

### 7. Comparative Advantages

AWM offers several advantages over existing approaches:

1. **Autonomy**: Unlike methods that rely on human-annotated examples, AWM can learn autonomously from its own experiences.

2. **Adaptability**: The agent continuously updates its workflows, improving its capabilities over time.

3. **Efficiency**: AWM exhibits a fast learning curve, rapidly acquiring essential workflows from a small amount of data.

4. **Compositionality**: AWM can build increasingly complex workflows by learning from both past examples and previously induced workflows.

### 8. Potential Applications and Impact

The AWM approach has significant implications for various applications:

1. **Web Automation**: Agents with AWM can learn to navigate and complete complex tasks on websites with minimal supervision.

2. **Personal Digital Assistants**: AWM could enable more capable digital assistants that learn from user interactions and become increasingly helpful over time.

3. **Robotic Control**: The principles of AWM could extend to physical environments, helping robots learn reusable skill sequences.

4. **Software Testing**: AWM agents could test software applications by learning common interaction patterns.

5. **Accessibility Tools**: AWM could power tools that help users with disabilities navigate digital interfaces more effectively.

### 9. Conclusion

Agent Workflow Memory represents a significant advance in the development of LLM-based agents by addressing a fundamental limitation: the inability to learn and reuse task workflows. By enabling agents to induce, store, and apply workflows from their experiences, AWM creates more adaptable and capable agents that can handle complex tasks across varied environments.

The key innovations of AWM include:

1. A method for automatically inducing reusable workflows from past experiences
2. The ability to operate in both offline and online learning scenarios
3. Robust generalization capabilities across tasks, websites, and domains
4. A learning mechanism that improves with more experience

These capabilities bring LLM-based agents closer to human-like learning and adaptation, where past experiences inform and guide future actions. As this research direction continues to develop, we can expect to see increasingly capable agents that can handle a wider range of complex tasks with greater autonomy and efficiency.
