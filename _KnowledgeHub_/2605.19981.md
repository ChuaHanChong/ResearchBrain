# CEER: Compliant End-Effector and Root Control as a Unified Interface for Hierarchical Humanoid Loco-Manipulation

> [!summary] Summary
> CEER introduces a compliant end-effector and root (EE-root) control abstraction for humanoid robots, providing a unified task-space interface for hierarchical loco-manipulation. The framework, built on a learned policy using a teacher-student setup, enables smoother end-effector motions and facilitates diverse contact-rich tasks in both simulation and hardware experiments.

## Problem

- Existing humanoid control methods often require high-dimensional, embodiment-specific joint trajectories from planners, which is computationally demanding and limits transferability.
- Traditional joint-tracking approaches lack explicit compliance modulation, hindering safe and robust interaction with objects and the environment during contact-rich tasks.
- A mismatch between sparse, task-level goals from high-level planners and dense, full-body references required by low-level execution complicates modular system integration.

## Method

- Developed a compliant End-Effector–Root (EE-root) control abstraction, defining a unified, interpretable task-space interface for humanoid loco-manipulation.
- Trained a low-level whole-body policy using a teacher-student framework to translate high-level EE-root commands into dynamically feasible and compliant joint actions, incorporating estimators for privileged states and target joints.
- Constructed a three-layer hierarchical architecture that integrates the low-level **CEER** policy with modular mid-level skills (e.g., teleoperation, path planning, VLM-based) and a high-level LLM-based task manager.

## Results

- Achieved an end-effector position RMSE of **3.3** cm and an RMS jerk of **4.5** × 10^3 m/s^3 in simulation, demonstrating smoother and more stable motions compared to baseline methods.
- Successfully executed complex contact-rich teleoperation tasks on a Unitree G1 humanoid robot, including forceful manipulation (e.g., whiteboard writing, box rotation) and delicate object handling like opening a paper bag.
- The hierarchical system, managed by an LLM, showed comparable or better performance than human teleoperation in single-object loco-manipulation tasks in simulation, with faster average completion times.

## Takeaways

> [!tip] Key Insights
> - A compact, compliant EE-root abstraction effectively bridges high-level task planning and low-level whole-body execution, promoting modularity and transferability across different robot platforms.
> - Integrating impedance control into a learned policy enables compliant interaction, resulting in significantly smoother end-effector motions (reduced jerk) and robust execution of contact-rich tasks.
> - The hierarchical system, utilizing the EE-root interface as a universal communication protocol, allows for seamless integration of heterogeneous planners and mid-level skills without requiring retraining of the foundational low-level controller.
