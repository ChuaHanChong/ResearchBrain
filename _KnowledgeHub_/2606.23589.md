# KEMO: Event-Driven Keyframe Memory for Long-Horizon Robot Manipulation with VLA Policies

> [!summary] Summary
> KEMO, an event-driven keyframe memory framework, addresses stage ambiguity in long-horizon robot manipulation by enhancing Vision-Language-Action (VLA) policies with context from sparse, task-relevant state transitions. The system improves aggregate Task Success Rate by 23.6 percentage points and Stage Completion Rate by 34.1 percentage points on six real-world dual-arm manipulation tasks.

## Problem

- VLA policies struggle with long-horizon robot manipulation due to 'stage ambiguity' and 'partial observability,' where identical visual observations require different actions based on prior task progression.
- Existing dense memory methods often dilute critical task-state transitions with redundant information during compression, making relevant events less discernible.
- Task-decomposition methods require subtask-level supervision, incur additional online inference costs, and are susceptible to error propagation from VLM hallucinations.

## Method

- **KEMO** introduces a lightweight, plug-in memory framework that augments VLA policies with a temporally ordered bank of ==event keyframes==, acting as explicit historical evidence.
- An event-driven keyframe detector identifies task-relevant state transitions by combining kinematic cues (robot deceleration) with a visual change filter, operating without task-specific annotations.
- A memory integration module uses masked cross-attention and gated residual fusion to incorporate encoded keyframes into the VLA policy's visual representation, complemented by keyframe-consistent training that up-weights losses around keyframe windows.

## Results

- KEMO achieved an aggregate Task Success Rate of **51.4%**, demonstrating an absolute improvement of **23.6** percentage points over the memory-free baseline (**27.8%**) across six real-world dual-arm manipulation tasks.
- The framework improved the aggregate Stage Completion Rate from **42.3%** (memory-free baseline) to **76.4%**, representing a gain of **34.1** percentage points.
- Ablation studies confirmed that both the event-driven keyframe selection strategy and the learned gated residual fusion are essential for KEMO's improved performance, with gated fusion being particularly critical.

## Takeaways

> [!tip] Key Insights
> - Event-driven keyframe selection is more effective than uniform sampling or retaining recent frames for providing relevant historical context in long-horizon tasks.
> - A learned residual gate in the memory fusion module is critical, adaptively integrating memory features without allowing them to dominate the current observation, which can weaken current state understanding.
> - Emphasizing learning at critical transition moments through keyframe-aligned loss weighting provides complementary benefits, aligning policy learning with the selective memory mechanism.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work addresses a challenge in robot manipulation: performing long-horizon tasks that involve sequences of interdependent subtasks. A core issue in such scenarios is "stage ambiguity" and "partial observability," where the robot encounters visually similar observations at different points in a task, but the appropriate action depends on previous steps. This problem is particularly relevant for Vision-Language-Action (VLA) policies, which typically condition actions primarily on the current observation.

Existing approaches to imbue VLA policies with memory broadly fall into two categories:
- **Dense memory methods**: These approaches store all past or recent frames, requiring compression techniques like token merging, recurrent states, or fixed-size latent representations. A limitation of these methods is the potential to dilute critical task-state transitions with a large amount of redundant information, making relevant events less discernible in the compressed memory.
- **Task-decomposition methods**: These utilize Vision-Language Models (VLMs) or high-level modules to track task progress and generate subgoals or semantic summaries. However, these methods often necessitate subtask-level supervision, incur additional online inference costs, and are susceptible to error propagation from generated semantic information or subgoals, which can include VLM hallucinations.

KEMO positions itself within this landscape by proposing a lightweight memory mechanism designed to preserve sparse, task-relevant events directly. This approach aims to overcome the challenges associated with dense memory compression and the overhead/potential errors of explicit task decomposition, thereby providing a more efficient and robust way to manage historical context for long-horizon robot manipulation. It builds upon the idea that "keyframes," representing significant task transitions, can provide a more compact and effective historical record than dense or heavily compressed continuous observations.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a lightweight, plug-in memory framework that enhances VLA policies for long-horizon robot manipulation by addressing the problem of stage ambiguity and partial observability. The motivation stems from the inherent difficulties VLA policies face in complex, multi-stage tasks where the correct action is non-Markovian, meaning it depends on the execution history rather than solely on the current observation.

Specific motivations and objectives include:

- **Resolving Stage Ambiguity**: Long-horizon tasks often present scenarios where identical or highly similar visual observations can occur at different stages of execution, requiring distinct actions based on prior completed steps. For example, picking up an object might be the correct action at one point, while placing it down is correct at another, even if the visual scene is similar. The objective is to provide the VLA policy with historical context to differentiate these stages.
- **Overcoming Limitations of Existing Memory Methods**:
 - **Dense Memory Compression**: Current methods that store dense histories (all past observations) often require compression, which can inadvertently obscure or discard sparsely occurring, yet critical, task-relevant events. The objective is to develop a memory mechanism that selectively retains only the most pertinent historical information.
 - **Task-Decomposition Overhead and Error Propagation**: Methods relying on explicit task decomposition, often utilizing VLMs, introduce additional computational costs during online inference and are vulnerable to errors or "hallucinations" from the high-level reasoning modules. The goal is to create a task-agnostic memory that operates without such external semantic supervision or online VLM queries.
- **Improving Policy Performance on Long-Horizon Tasks**: The overarching objective is to improve the Task Success Rate (TSR) and Stage Completion Rate (SCR) of VLA policies on real-world, complex manipulation tasks that span multiple interdependent subtasks and extended durations.
- **Lightweight and Plug-in Design**: The motivation is to create a memory framework that can be easily integrated with existing VLA policy backbones without requiring significant architectural changes or substantial increases in computational complexity.
- **Data-Efficient Learning**: By focusing on keyframes, the method aims to emphasize learning at critical transition points, potentially leading to more efficient training and better policy generalization in sequential tasks.

In essence, KEMO aims to provide VLA policies with "event-driven keyframe memory" to act as explicit historical evidence, allowing the policy to infer task progress and make contextually appropriate decisions in non-Markovian long-horizon manipulation scenarios.

### 3. Methodology and Approach

KEMO is presented as a plug-in memory framework designed to augment VLA policies with historical keyframe evidence. The methodology comprises three main components: event-driven keyframe detection, keyframe memory integration, and keyframe-consistent training.

#### 3.1. Problem Formulation

The system considers long-horizon robot manipulation where at each timestep *t*, the robot receives an observation *o_t* (RGB images *I_t* from multiple cameras and proprioceptive state *s_t*) and a language instruction *ℓ*. The policy predicts an action chunk *a_t:t+H*. To address stage ambiguity, the policy conditions its action *π_θ(a_t:t+H | o_t, ℓ, M_t)* on a history memory *M_t*, which is constructed as a temporally ordered set of event keyframes detected up to timestep *t*. Each keyframe represents a task-relevant state transition.

#### 3.2. Framework Overview

The KEMO framework augments a VLA policy with an event-driven keyframe memory pipeline.
1. **Keyframe Detector**: This module processes current multi-view visual observations and robot states. It employs kinematic cues to identify candidate transition moments and then applies a visual change filter to eliminate redundant candidates. The output is a sequence of accepted event keyframes with their timestep indices.
2. **Memory Bank**: Accepted keyframes are encoded into compact visual tokens and stored in a temporally ordered memory bank *M_t*.
3. **Memory Integration Module**: This module takes current visual tokens as queries and the stored keyframe tokens as historical context. It uses masked cross-attention and gated residual fusion to produce a memory-augmented visual representation.
4. **VLA Backbone**: The memory-augmented visual representation is then combined with the current robot state and language instruction by the VLA backbone to predict the next action chunk.
5. **Keyframe-Consistent Training**: The detected keyframe indices are also used to define higher-weight supervision windows during training, emphasizing learning at critical task transitions.

#### 3.3. Event-Driven Keyframe Detection

This module identifies stage transitions without task-specific annotations.
1. **Event Saliency Score**: A score *S_t* is calculated based on the inverse of the mean joint-space displacement over a sliding window (*w*). A high score indicates recent robot deceleration, commonly occurring near key manipulation events (e.g., grasping, placing). The formula is *S_t = 1 / (1 + mean_displacement_over_window)*.
2. **Causal Peak Detection**: Candidate keyframes are identified as local peaks in the *S_t* sequence. A candidate peak is confirmed after observing a short temporal window, indicating a local slowdown in robot motion.
3. **Visual Deduplication Filter**: To remove visually uninformative candidates (e.g., pauses without scene changes), each candidate frame *c_i* is compared to the most recently accepted keyframe *k_i-1* using a frozen DINOv2 encoder. A visual dissimilarity score *v_i* is calculated based on the cosine similarity of their global image embeddings. A candidate is accepted only if *v_i* exceeds a predefined threshold *ϵ* (set to 0.05). Otherwise, it is discarded.
4. **Refractory Period**: A minimum refractory period *r* is enforced between consecutive accepted keyframes to prevent redundant detections within the same sustained transition. Task-specific values for *w*, peak detection window, and *r* are tuned (e.g., *w* from 10-40, *r* from 8-60).

#### 3.4. Keyframe Memory Integration

This module processes and integrates the detected keyframes into the VLA policy.
1. **Keyframe Encoding**: Keyframe images are encoded using the same SigLIP visual encoder as the base policy, producing patch-level tokens. Spatial average pooling (4x4) reduces each keyframe's representation from 256 to 16 tokens for computational efficiency.
2. **Keyframe Memory Bank Construction**: At timestep *t*, the memory bank *M_t* stores up to *K* most recent accepted keyframes. If fewer than *K* keyframes exist, the bank is padded with the most recent keyframe, and a binary padding mask is maintained. *K* is manually set based on the expected number of subtask transitions.
3. **Temporal Positional Encoding**: Learnable temporal position embeddings are added to each keyframe slot based on its position in the bank. This provides ordering information, enabling the policy to distinguish different stages even if their visual content is similar.
4. **Memory Injection via Cross-Attention and Gated Residual Fusion**:
 - Current frame tokens from SigLIP (*X_t*) act as queries.
 - Projected keyframe bank tokens form Keys and Values (*KV*).
 - Masked cross-attention is applied: *X'_t = CrossAttn(X_t, KV, mask = m)*.
 - The output *X'_t* is fused with the current representation *X_t* via a learned residual gate: *^X_t = X_t + σ(g([X_t; X'_t])) · X'_t*.
 - The gate function *g(·)* is a linear projection with a negative bias initialization, ensuring the memory contribution is initially suppressed and adaptively learned, preventing memory features from overwhelming current observations when not yet informative.
 - The updated tokens *^X_t* are then passed to the language model.

#### 3.5. Keyframe-Consistent Training

The detected keyframe indices are also used to inform the training process. A weighted flow matching loss is employed:
- The per-timestep loss *ℓ_t* is up-weighted by *λ* (set to 8.0) if the timestep *t* falls within a window radius *δ* (set to 3) around any detected keyframe *k_i*.
- This consistency ensures that the policy is encouraged to be accurate at the critical transition moments that will later be stored as memory, aligning memory content with learning emphasis.

### 4. Main Findings and Results

The research evaluates KEMO on six real-world dual-arm manipulation tasks, designed to be memory-dependent and ranging from 2 to 6 scored subtasks, with trajectory durations from 28 to 95 seconds (830 to 2846 execution steps). Performance is measured using Task Success Rate (TSR) and Stage Completion Rate (SCR).

#### 4.1. Effect of Memory Selection Strategy (Q1)

An ablation study on the "Cover Blocks" task compared KEMO's event-driven keyframe selection against alternative strategies:
- **Uniform Sampling**: Achieved 0/12 (0%) TSR and 1.833/6 (30.6%) SCR. This strategy was noted to be inconsistent due to trajectory length variations during inference.
- **Recent-Frame Retention**: Achieved 1/12 (8.3%) TSR and 0.700/6 (11.7%) SCR. This method preserved dense short-term context but discarded earlier, potentially relevant, observations.
- **Event-Driven Keyframe Selection (without gated fusion and loss weighting)**: Achieved 3/12 (25.0%) TSR and 2.500/6 (41.7%) SCR.

These results indicate that event-driven keyframe selection is more effective than uniform sampling or retaining only recent frames for providing relevant historical context.

#### 4.2. Module Contribution Analysis (Q2)

Further ablations on "Cover Blocks" explored the individual contributions of KEMO's components:
- **Without Gated Fusion**: Removing the learned residual gate resulted in 0/12 (0%) TSR and 0.000/6 (0%) SCR. The paper attributes this to memory features potentially dominating the visual representation, weakening the understanding of the current observation.
- **Without Keyframe-Aligned Loss Weighting**: Removing this component, while keeping event-driven keyframes and gated fusion, resulted in 3/12 (25.0%) TSR and 2.500/6 (41.7%) SCR.
- **Full KEMO Model**: Achieved 9/12 (75.0%) TSR and 5.250/6 (87.5%) SCR.

This analysis suggests that both the gated memory fusion and keyframe-aligned loss weighting contribute complementary benefits to the overall performance, with gated fusion being particularly critical.

#### 4.3. Comparison with Baselines (Q3)

KEMO was benchmarked against a memory-free baseline (π_0.5) and a memory-augmented baseline (MemoryVLA) across all six tasks.
- **Aggregate Performance**:
 - π_0.5: Achieved an aggregate TSR of 27.8%.
 - MemoryVLA: Achieved an aggregate TSR of 1.4%.
 - KEMO: Achieved an aggregate TSR of 51.4%, representing an absolute improvement of 23.6 percentage points over π_0.5. KEMO also improved aggregate SCR from 42.3% (π_0.5) to 76.4%, a gain of 34.1 percentage points.
- **Task-Specific Results (TSR/SCR out of total stages):**
 - **Swap Foods**: π_0.5 (6/12, 1.500/2), MemoryVLA (1/12, 0.750/2), KEMO (8/12, 1.580/2)
 - **Find Block**: π_0.5 (0/12, 0.353/4), MemoryVLA (0/12, 1.000/4), KEMO (2/12, 3.167/4)
 - **Cover Blocks**: π_0.5 (0/12, 1.333/6), MemoryVLA (0/12, 0.333/6), KEMO (9/12, 5.250/6)
 - **Box Refill**: π_0.5 (4/12, 2.580/4), MemoryVLA (0/12, 0.000/4), KEMO (7/12, 3.330/4)
 - **Make Sandwich**: π_0.5 (10/12, 3.330/4), MemoryVLA (0/12, 1.000/4), KEMO (11/12, 3.750/4)
 - **Drawer Items Replacement**: π_0.5 (0/12, 0.000/4), MemoryVLA (0/12, 0.000/4), KEMO (0/12, 1.417/4)

KEMO demonstrates improvements over both baselines in most tasks, particularly showing notable gains in aggregate success rates and stage completion. For "Drawer Items Replacement," while KEMO did not achieve full task success (TSR 0/12), it showed an improvement in sequential progress (SCR 1.417/4) compared to baselines (0.000/4).

### 5. Significance and Potential Impact

The KEMO framework represents an approach to addressing the challenge of long-horizon robot manipulation by integrating an event-driven keyframe memory into VLA policies. The significance of this work can be attributed to several factors:

- **Effective Handling of Non-Markovian Tasks**: By providing policies with a compact, task-relevant historical context, KEMO offers a method for robots to disambiguate visually similar observations that require different actions based on prior task progression. This addresses a core limitation of policies relying solely on current observations in sequential tasks.
- **Lightweight and Plug-in Design**: The framework's design as a plug-in module allows for integration with existing VLA policy backbones without necessitating fundamental architectural changes. This facilitates adoption and avoids the computational overhead associated with more complex memory systems or high-level reasoning modules.
- **Task-Agnostic Keyframe Detection**: The proposed keyframe detector relies on general robot kinematic cues and visual changes rather than task-specific annotations or online VLM inference. This reduces the need for extensive manual supervision and mitigates potential errors or latency from external large language models, contributing to robustness and scalability.
- **Demonstrated Real-World Performance**: Evaluation on six diverse and challenging real-world dual-arm manipulation tasks, spanning various durations and numbers of subtasks, indicates that the method is applicable in practical robotic setups. The observed improvements in aggregate Task Success Rate (23.6% over memory-free baseline) and Stage Completion Rate (34.1% over memory-free baseline) suggest a practical impact on robot autonomy for complex tasks.
- **Component Validation**: The ablation studies systematically demonstrate the individual contributions of key components, namely event-driven keyframe selection, gated memory fusion, and keyframe-aligned loss weighting. This provides insight into the design choices and their roles in enhancing policy performance.
- **Future Directions**: While the method shows improvements, the identified limitations regarding hyperparameter tuning and fixed memory bank capacity suggest avenues for further research. Investigating learned event selection and dynamically sized memory could lead to more generalizable and autonomous memory systems for robotics.

In summary, KEMO offers a principled method for equipping VLA policies with a selective memory of critical task events, contributing to the development of more capable and reliable robots for complex, long-horizon manipulation tasks in real-world environments.
