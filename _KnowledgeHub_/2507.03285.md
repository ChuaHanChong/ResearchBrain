# Memory Mosaics at scale

> [!summary] Summary
> Memory Mosaics v2 scales associative memory networks to the Llama-8B parameter size, demonstrating enhanced new task learning and in-context learning capabilities over transformers. The architecture, trained on 1 trillion tokens, outperformed transformers by over 10% on classification tasks and achieved a 22% accuracy improvement on QA tasks with minimal fine-tuning, often requiring significantly less training data than transformers for comparable performance in new learning scenarios.

## Problem

- Machine learning models face persistent challenges in robust compositional capabilities and in-context/out-of-distribution learning.
- While transformer models exhibit some of these abilities, their underlying mechanisms are often opaque, hindering transparency.
- Previous Memory Mosaics architectures showed promise on smaller scales and synthetic data, but their scalability to large language models and real-world datasets remained unproven.

## Method

- Developed "**Memory Mosaics v2**," an enhanced architecture based on ==associative memories==, incorporating adaptive bandwidth and a gated time-variant key feature extractor.
- Implemented a 3-level memory design, integrating distinct short-term, long-term, and persistent memory components to handle different knowledge types.
- Trained models up to Llama-8B scale on 1 trillion real-world tokens and evaluated their performance against Llama-architecture transformer baselines.

## Results

- Memory Mosaics v2 achieved parity with transformers on 19 persistent-knowledge benchmarks but demonstrated superior performance (**12.3%** to **14.8%** higher) on new-knowledge QA tasks at 32k context length.
- Consistently outperformed transformers by over **10%** across various in-context classification tasks (semantic and anonymous labels), improving with more examples where transformers often degraded.
- A Memory Mosaics v2 model trained on 1 trillion tokens matched or surpassed transformers trained on 8 trillion tokens for new task learning, demonstrating significant data efficiency.
- Showed rapid fine-tuning, achieving a **22%** accuracy improvement with a single mini-batch on RULER QA tasks, significantly outperforming a transformer fine-tuned with 800 mini-batches.

## Takeaways

> [!tip] Key Insights
> - Architectural innovation, as seen in Memory Mosaics, can offer an efficient alternative to simply scaling data and computation for achieving advanced learning capabilities.
> - A structured memory system with dedicated short-term, long-term, and persistent components is crucial for transparently processing and distinguishing between new and pre-existing knowledge.
> - Memory-based architectures provide a more transparent framework for understanding compositional and disentanglement phenomena compared to transformer models.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work addresses ongoing challenges in Machine Learning concerning compositional capabilities and in-context/out-of-distribution learning. Historically, approaches to these goals included disentanglement via statistical independence methods (e.g., Comon, 1994; Roth et al., 2022) and optimization-based learning from multiple environments (e.g., Finn et al., 2017; Arjovsky et al., 2019; Bengio et al., 2019). While transformer-based models have demonstrated some compositional and in-context learning abilities, the underlying mechanisms for these capabilities are not fully understood.

Memory mosaics, introduced in prior work (Zhang et al., 2025), presented an alternative architecture based on networks of associative memories, noted for their transparency in explaining compositional and disentanglement phenomena. Earlier iterations of memory mosaics exhibited promising in-context learning capabilities on medium-scale networks (e.g., GPT-2 scale) and synthetic small datasets. This current work extends the investigation into whether these properties persist and scale to large language model sizes (e.g., Llama-8B scale) when trained on real-world datasets, thereby positioning memory mosaics as a potential alternative or complement to transformer architectures for advanced learning capabilities, particularly in new task scenarios. The paper contrasts its approach with the prevalent "more data, more computation" paradigm in large model development, suggesting that architectural innovation can offer a "middle-risk-high-return" alternative.

### 2. Key Objectives and Motivation

The primary objective of this research is to investigate whether the appealing compositional and in-context learning capabilities previously observed in medium-scale Memory Mosaics models (Zhang et al., 2025) can be successfully scaled to large language model sizes (specifically, Llama-8B scale) and effectively applied to real-world datasets. This overarching objective is motivated by several specific goals:

- **Addressing Challenges in Compositional and In-Context Learning:** The introduction highlights that achieving robust compositional and in-context/out-of-distribution learning remains a persistent challenge in Machine Learning. While transformers exhibit some of these capabilities, their underlying mechanisms are often opaque. Memory mosaics offer a comparatively transparent framework for understanding these phenomena.
- **Scaling Memory Mosaics to Large Scale:** The prior work demonstrated Memory Mosaics on smaller networks and synthetic data. A key motivation for this study is to determine if these favorable properties are retained when the architecture is scaled to 10 billion parameters and trained on a significantly larger corpus of real-world data (one trillion tokens). This addresses the question of practical applicability and generalization beyond controlled, synthetic environments.
- **Architectural Refinement for Enhanced Performance:** To facilitate scaling and improve performance on real-world tasks, the authors aimed to introduce architectural modifications to the original Memory Mosaics design. These modifications, termed "memory mosaics v2," were motivated by insights into mechanisms like transformer induction heads and principles of kernel regression, intending to achieve a "stronger and more general new task learning capability."
- **Comprehensive Evaluation of Model Capabilities:** A specific objective was to develop and employ a comprehensive evaluation framework. This framework was designed to assess model abilities across a spectrum of scenarios, from in-distribution (i.i.d.) to out-of-distribution (o.o.d.) learning. The three proposed evaluation dimensions—training-knowledge storage, new-knowledge storage, and in-context learning—were motivated by the need for a transparent and controlled assessment of capabilities relevant to learning new tasks with minimal examples and prior knowledge.
- **Challenging the "More Data, More Computation" Paradigm:** The research is motivated by an implicit critique of the dominant strategy in large model development, which often relies on simply increasing training data and computational resources for existing architectures. By demonstrating superior performance in new task learning with potentially less data than transformers, the authors seek to highlight the "risk-return trade-off" and explore whether architectural innovations can provide a more resource-efficient path to advanced learning capabilities.
- **Investigating Fine-tuning Efficiency:** An additional motivation was to assess the efficiency with which Memory Mosaics v2 could be fine-tuned for new domains or tasks, anticipating that models with strong in-context learning abilities might require fewer examples for adaptation.

In essence, the core motivation is to advance the understanding and capabilities of large language models by proposing and validating a novel architecture that offers both transparency and enhanced performance, particularly in scenarios requiring rapid adaptation to new information or tasks.

### 3. Methodology and Approach

The methodology employed in this research involved scaling the Memory Mosaics architecture, introducing specific architectural enhancements, training these models on large-scale real-world datasets, and conducting a multi-faceted evaluation against transformer baselines.

#### 3.1. Background on Associative Memory

The work is founded on the concept of associative memories, defined as devices storing key-value pairs $\{(k_1, v_1) \dots (k_n, v_n)\}$ and retrieving values given a key $k$. The retrieval function is formulated as a conditional expectation, estimated via kernel regression, specifically Gaussian kernel regression (Equation 3):
$f(k; \{(k_1, v_1) \dots (k_n, v_n)\}) = \sum_{i=1}^{n} \frac{e^{-\beta\|k-k_i\|^2}}{\sum_{j=1}^{n} e^{-\beta\|k-k_j\|^2}} v_i$.
This formulation is connected to attention mechanisms in transformers (Equation 4) when key vectors share the same squared norm. Key distinctions highlighted are the use of $L_2$ normalized key vectors with an explicit bandwidth parameter $\beta$, a symmetric kernel for keys and queries, and the absence of explicit position encoding.

#### 3.2. Memory Mosaics v2 Architecture

Building upon the original Memory Mosaics (Zhang et al., 2025), which constructs associative memories using keys representing the recent past and values representing the near future (Equation 5), Memory Mosaics v2 incorporates three primary architectural modifications:

1. **Adaptive Bandwidth in Gaussian Kernel Smoothing:** The original Memory Mosaics used a fixed bandwidth parameter $\beta$. Memory Mosaics v2 introduces an adaptive bandwidth by scheduling $\beta$ as $\beta = \beta_1 n^\alpha + \beta_0$ (Equation 6), where $n$ is the number of key-value pairs (size of associative memory), and $\beta_0, \beta_1, \alpha$ are learnable parameters. This aims to optimize the bias-variance trade-off of kernel regression based on the memory size.
2. **Gated Time-Variant Key Feature Extractor:** The previous version used a simple, time-invariant leaky averaging for key feature extraction. Memory Mosaics v2 replaces this with a gated time-variant key feature extractor (Equation 8): $k_T = \text{Norm}(\bar{k}_T)$ with $\bar{k}_T = g_T \tilde{k}_T + \lambda_T \bar{k}_{T-1}$, where $\tilde{k}_T = W_\phi x_T$. The gating $g_T = e^{W_g x_T}$ and averaging weights $\lambda_T = e^{-|W_\lambda x_T|}$ are made semantically dependent on the input $x_T$. The value feature extractor (Equation 9) remains a convolutional design: $v_T = \alpha_\psi \text{Norm}(\bar{v}_T)$ with $\bar{v}_T = \gamma \tilde{v}_T + (1-\gamma) \tilde{v}_{T+1}$.
3. **3-Level Memory Design:** Inspired by observations of attention scores in Memory Mosaics (Figure 1), which showed position-dependent patterns for near tokens and position-invariant patterns for far tokens, Memory Mosaics v2 replaces each contextual associative memory with two distinct associative memories:
 - **Short-term memory:** Stores key-value pairs of near-tokens, from $t-h+1$ to $t-1$ (Equation 10), using distinct parameters.
 - **Long-term memory:** Stores key-value pairs before position $t-m$, skipping near tokens, also using distinct parameters. By setting $m < h$, an overlap is created, forming a soft boundary. The outputs of these memories are concatenated and projected.
 - **Persistent Memory:** This component, present in original Memory Mosaics, is implemented using dense two-layer neural networks with SwiGLU activation for computational efficiency.

#### 3.3. Training Process

- **Model Sizes:** Two Memory Mosaics v2 models were trained: "small" (Llama-1.5B scale, 24 layers, 2048 hidden dimensions, 16 heads) and "large" (Llama-8B scale, 32 layers, 4096 hidden dimensions, 32 heads).
- **Data:** The small model was trained on 200 billion tokens, and the large model on 1 trillion tokens, both using a diverse datamix.
- **Context Length:** Models were initially trained on a 4,096 context length, followed by fine-tuning on a 32,768 context length.
- **Stochastic Long-Term Memory Size:** During training, the long-term memory delay step $m$ was sampled from $$, while short-term memory window $h$ was fixed at $256$. At inference, $m$ was fixed to $64$. This stochastic approach aimed to encourage segregation of position-invariant and position-dependent signals.
- **Baselines:** Two baseline transformers (small/large) with Llama architecture and multi-head attention were trained with configurations matching their Memory Mosaics v2 counterparts.

#### 3.4. Evaluation Dimensions

Three evaluation dimensions were designed to assess model capabilities comprehensively:

1. **Persistent-knowledge storage and retrieval:** Evaluates the ability to store and retrieve knowledge from the training dataset, relevant for reusable knowledge. Assessed using 19 common language benchmarks, with a subset of 13 tasks confirmed to rely primarily on persistent memory (by removing long-term memory post-training).
2. **New-knowledge storage and retrieval:** Assesses the ability to store and retrieve novel information from test datasets, prerequisite for learning new tasks. Evaluated using "multi-unrelated-documents question-answering" tasks from the RULER benchmark (Hsieh et al., 2024), which feature high information entropy.
3. **In-context Learning:** Directly evaluates the capacity to learn new tasks or distributions at inference time with few examples and minimal prior knowledge. Utilized classic multiclass classification problems (Banking77, Tacred, Goemotion) in few-shot learning setups, including both semantic and anonymous target labels to isolate new task learning from reliance on pre-trained knowledge. Prompts were constructed by serializing (x, y) pairs followed by a test query.

#### 3.5. Risk-Return Trade-off Analysis

This analysis compared Memory Mosaics v2 (1T training tokens) against transformers trained on varying amounts of data (200B, 1T, and 8T tokens) to quantify how much more data transformers require to match Memory Mosaics v2's performance on new task learning benchmarks.

#### 3.6. Fine-tuning Speed Analysis

The fine-tuning efficiency of Memory Mosaics v2 was compared to transformers by evaluating performance gains on RULER QA tasks after a limited number of fine-tuning mini-batches.

### 4. Main Findings and Results

The research yielded several findings regarding the capabilities of Memory Mosaics v2 compared to transformer architectures.

#### 4.1. Persistent-Knowledge Storage and Retrieval

- **Performance Parity:** Memory Mosaics v2 and baseline transformers demonstrated similar performance across 19 common language benchmarks (Table 1). On a subset of 13 tasks, identified as relying primarily on persistent knowledge (where removing long-term memory had minimal impact), Memory Mosaics v2 and transformers performed comparably (Table 2). This suggests both architectures are similarly effective at storing and retrieving persistent knowledge.
- **Efficiency:** Removing the long-term memory component from Memory Mosaics v2 after training resulted in a model with fewer parameters (8.3B vs. 9.9B) and reduced computational cost (15.6B FLOPs/token vs. 18.9B FLOPs/token) while maintaining comparable performance to transformers on these 13 persistent-knowledge benchmarks.

#### 4.2. New-Knowledge Storage and Retrieval

- **Superiority over Transformers:** Memory Mosaics v2 consistently outperformed transformers on "multi-unrelated-documents question-answering" tasks from the RULER benchmark.
 - For models trained on 4k context length, Memory Mosaics v2 (small and large) surpassed transformers by 1.4% to 5.6% on 4k task-length tasks (Table 3).
 - After fine-tuning on 32k context length, Memory Mosaics v2 (small and large) showed a performance advantage of 12.3% to 14.8% over transformers on 32k task-length tasks (Table 4).
- **Context Length Extrapolation:** Memory Mosaics v2, trained on 4k context length, exhibited capability to extrapolate context length by 4 to 8 times without fine-tuning, maintaining performance, unlike transformers which struggled (Table 3).
- **Necessity of Long-Term Memory:** Removing long-term memory from Memory Mosaics v2 after training significantly degraded performance on RULER QA tasks by 20% to 30%, indicating its crucial role in these new-knowledge tasks (Table 10).
- **Limitations of Other Architectures:** The paper notes that memory compression algorithms (e.g., RNNs, xLSTM, RWKV, state-space models) and local-window memory approaches generally fail on these tasks due to their inability to store extensive, uncompressed information before queries are presented.

#### 4.3. In-Context Learning

- **Consistent Improvement with More Shots:** Memory Mosaics v2 consistently improved classification performance as more demonstration shots were provided in multiclass classification tasks (Banking77, Tacred, Goemotion) with semantic labels (Figure 3) and anonymous labels (Figure 4).
- **Transformer Performance Degradation:** In contrast, transformers often struggled to maintain or showed degraded performance as more demonstrations were provided, particularly on semantic label tasks (Figure 3).
- **Significant Performance Margin:** Memory Mosaics v2 significantly outperformed transformers by over 10% across all evaluated classification tasks, for both semantic and anonymous labels (Figures 3, 4, 13, 14). This advantage was observed even under matched model size or computational budgets (FLOPs) (Figure 12).
- **Architectural Distinctiveness:** Augmenting transformers with a long-short term attention mechanism did not mitigate their in-context learning limitations, suggesting that Memory Mosaics v2's advantages stem from its unique architectural principles beyond simple memory partitioning (Figure 5).

#### 4.4. Risk-Return Trade-off of Frontier-Model-Sized Memory Mosaics v2

- **Data Efficiency:** Memory Mosaics v2, trained on 1 trillion tokens, demonstrated superior new task learning abilities compared to transformers.
 - On new-knowledge storage and retrieval (RULER QA, 32k task-length), Memory Mosaics v2 (1T tokens) outperformed a transformer trained on 1T tokens by 12.3% (53.4% vs. 41.1%). Even a transformer trained on 8T tokens still lagged behind Memory Mosaics v2 (1T tokens) by 6.5% (46.9% vs. 53.4%) (Table 5).
 - For semantic label in-context learning, a transformer trained on 8T tokens began to match the performance of Memory Mosaics v2 trained on 1T tokens (Figure 6).
 - However, for the more challenging anonymous label in-context learning tasks, transformers, even with 8T training tokens, continued to lag significantly behind Memory Mosaics v2 trained on 1T tokens, and in some cases, exhibited degraded performance with more data (Figure 7).

#### 4.5. Fine-tuning Speed

- **Rapid Adaptation:** Memory Mosaics v2 demonstrated rapid fine-tuning capabilities. A single mini-batch (one optimization step) of fine-tuning yielded a 22% accuracy improvement on RULER QA tasks (32k task-length), with optimal performance achieved within two mini-batches.
- **Transformer Disparity:** In contrast, a transformer fine-tuned with 800 mini-batches still underperformed Memory Mosaics v2 fine-tuned with a single mini-batch (Figure 8).

### 5. Significance and Potential Impact

This work presents Memory Mosaics v2 as an architecture that scales associative memories to large language model dimensions (Llama-8B scale) and demonstrates consistent advantages over transformer models in specific learning capabilities.

The primary significance lies in its **demonstrated superiority in new task learning and in-context learning**. Memory Mosaics v2's ability to significantly outperform transformers (by over 10% in some tasks) and improve performance with increasing demonstrations, particularly on tasks requiring novel information processing or anonymous labels, suggests a more robust capacity for adapting to and learning from new distributions at inference time. This contrasts with transformers' observed struggles or even performance degradation in similar scenarios, highlighting a functional distinction between the architectures.

The findings challenge the prevailing "more data, more computation" paradigm as the sole path to advanced model capabilities. The "risk-return trade-off" analysis indicates that Memory Mosaics v2, trained on 1 trillion tokens, can achieve or surpass the performance of a transformer trained on 8 trillion tokens for certain new task learning benchmarks. In tasks heavily reliant on genuinely new task learning (e.g., anonymous label classification), increased data for transformers did not necessarily translate to improved performance, and in some cases, led to degradation. This implies that architectural innovation, as exemplified by Memory Mosaics v2, may offer a more efficient route to certain types of intelligence, potentially mitigating the escalating computational and data requirements of large language models.

Furthermore, the **rapid fine-tuning capability** of Memory Mosaics v2—achieving substantial performance gains with as little as a single mini-batch—indicates a potential for greater efficiency in deployment and adaptation to specific domains. This could reduce the resources and time required for customizing models post-pre-training.

The introduction of **three distinct evaluation dimensions** contributes to the field by providing a structured framework for assessing model capabilities beyond general language understanding. By differentiating between persistent-knowledge, new-knowledge, and in-context learning, the work offers a more granular understanding of where different architectures excel or fall short.

Potential impacts include:

- **Inspiration for Novel Architectures:** Memory Mosaics v2 provides a concrete example of an alternative to the transformer paradigm that exhibits distinct advantages in specific, critical areas of learning. This could encourage further research into memory-based or hybrid architectures.
- **More Efficient AI Development:** If architectural innovations can achieve comparable or superior performance with less data and computation, it could lead to more democratized access to advanced AI models and reduce the environmental footprint of large model training.
- **Enhanced Few-Shot and Continual Learning:** The strong in-context learning and rapid fine-tuning capabilities could significantly advance few-shot and continual learning paradigms, making models more adaptable to evolving real-world scenarios with limited supervision.

Future directions highlighted by the authors include reducing the computational cost for very long context lengths using techniques such as fuzzy hashing and hierarchical memory, suggesting ongoing efforts to optimize the efficiency of this novel architecture.
