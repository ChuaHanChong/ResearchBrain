# REMAC: Self-Reflective and Self-Evolving Multi-Agent Collaboration for Long-Horizon Robot Manipulation

> [!summary] Summary
> Researchers from Tsinghua University, CMU, UNC-Chapel Hill, and UC Berkeley introduce REMAC, a framework enabling multi-robot systems to execute long-horizon manipulation tasks through self-reflection and adaptation, achieving 40% higher success rates and 52.7% improved execution efficiency compared to single-robot baselines without task-specific prompting.

## Problem

- Existing VLM-based robot control systems struggle with dynamic environments and unexpected changes during long-horizon tasks
- Current approaches rely heavily on detailed task-specific prompts and prior environmental knowledge

## Method

- ==Three-stage framework== combining ==scene exploration==, ==task planning with check mechanisms==, and ==iterative self-evolution==
- Integration of VLMs for visual understanding with LLMs for reasoning and planning in a ==multi-agent system==
- ==Self-reflection module== for pre/post-condition checks and plan refinement

## Results

- **40%** higher task success rate compared to single robot baseline
- **52.7%** improvement in execution efficiency across diverse tasks
- Demonstrated effectiveness across **4** task categories with **27** task styles and **50+** objects
- Reduced need for task-specific prompting while maintaining high performance

## Takeaways

> [!tip] Key Insights
> - Multi-robot coordination reduces average subtask duration by 20% through optimized task decomposition
> - Self-evolution mechanism improves planning efficiency by reducing initial plan length 35-62%
> - Storing reflections in long-term memory enables continuous learning and performance improvement
