# Seeing Beyond Words: Self-Supervised Visual Learning for Multimodal Large Language Models

> [!summary] Summary
> JARVIS integrates a JEPA-inspired self-supervised visual learning objective into Multimodal Large Language Models (MLLMs), enabling them to acquire fine-grained visual perception and reasoning beyond textual descriptions. The framework achieves consistent improvements on vision-centric benchmarks across various LLM families, including a 0.8 to 1.6 average point gain on visual tasks, while maintaining performance on general multimodal benchmarks.

## Problem

- Current MLLMs often rely too heavily on subjective and incomplete textual descriptions for visual understanding, leading to an inability to grasp nuanced visual details.
- MLLMs frequently exhibit poor performance in fundamental visual reasoning tasks such as object counting, precise spatial relationship understanding, and distance estimation.
- Models tend to overfit strong language priors from their pre-training, which can result in visual 'hallucinations' or interpretations based on linguistic association rather than actual visual evidence.

## Method

- JARVIS introduces a ==Joint Embedding Predictive Architecture (JEPA)==-inspired masked predictive objective during the first (alignment) stage of ==LLaVA-style MLLM== training.
- It leverages early layers of the LLM as a ==predictor network== to reconstruct masked visual embeddings, derived from an unbiased target visual encoder (e.g., DINOv2), from visible context embeddings.
- The approach combines this self-supervised visual loss (
L
JEPA
) with a modified next-token prediction objective for image captioning, ensuring a concurrent focus on both intrinsic visual understanding and text-image alignment.

## Results

- JARVIS consistently improved vision-centric task performance across different LLM backbones, achieving an average gain of **0.8 points** for Vicuna-7B and **0.7 points** for Qwen2-7B compared to the LLaVA baseline.
- The method maintained or improved performance on general, knowledge, and OCR tasks, demonstrating no trade-off in broader multimodal reasoning abilities.
- Qualitative examples illustrated JARVIS's superior performance in detailed visual tasks like object counting, spatial reasoning, and depth estimation over LLaVA and other related methods such as VIRAL, which did not improve vision-centric tasks.

## Takeaways

> [!tip] Key Insights
> - Integrating a purely visual, self-supervised learning signal, like the JEPA objective, is crucial for MLLMs to develop robust visual grounding independent of linguistic supervision.
> - The early-to-middle layers of the Large Language Model are more effective for processing and predicting fine-grained visual information, making them ideal for the JEPA task.
> - Using negative cosine similarity as the distance function in the JEPA loss and periodically training on unmasked images (with a dropout rate
λ) are critical for balancing effective visual learning with general multimodal capabilities.
