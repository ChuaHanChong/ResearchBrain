# Successor Features for Transfer in Reinforcement Learning

> [!summary] Summary
> DeepMind researchers developed a framework based on Successor Features (SFs) and Generalized Policy Improvement (GPI) to enable efficient transfer learning in reinforcement learning when reward functions vary across tasks but environmental dynamics remain constant. This approach led to over 100% average return improvement in navigation tasks and successful generalization to unseen robotic arm control objectives.

## Problem

- Traditional reinforcement learning (RL) requires training an agent from scratch for each new task, which is inefficient and does not leverage prior knowledge.
- Agents need to efficiently transfer knowledge across tasks, particularly in scenarios where the environment dynamics remain constant but the reward function changes.
- Lack of a theoretically grounded and practically effective framework for seamlessly integrating knowledge transfer into standard RL algorithms.

## Method

- The paper introduces **Successor Features (SFs)** as a generalization of ==Successor Representations==, enabling the decomposition of the ==action-value function== into features dependent only on dynamics and a ==reward weight vector==.
- A novel ==Generalized Policy Improvement (GPI)== operator is proposed, which allows an agent to leverage a library of optimal Successor Features from past tasks to construct a high-performing policy for a new task.
- When a new reward function is encountered, the agent estimates its ==reward weights==, re-evaluates stored SFs, and applies GPI to immediately derive a strong policy, which can then be further refined.

## Results

- The SF + GPI framework significantly outperformed baseline Q-Learning (QL) and Probabilistic Policy Reuse Q-Learning (PRQL) in a 2D continuous navigation task, achieving over **100%** average return improvement compared to PRQL.
- In a simulated robotic arm task, the method generalized effectively to **8** unseen target locations, improving performance on these novel tasks even without direct training, demonstrating strong transfer capabilities with deep neural networks.
- The approach showed robustness to imperfections in feature representations (learning features from data) and the Generalized Policy Improvement component was confirmed to be crucial for observed strong transfer benefits.

## Takeaways

> [!tip] Key Insights
> - Successor Features (SFs) effectively decouple the environment's dynamics from the reward function, allowing for instant re-evaluation of Q-values when only the reward changes.
> - Generalized Policy Improvement (GPI) extends Bellman's theorem, providing a principled method to combine multiple previously learned policies to form a new policy with theoretical performance guarantees for novel tasks.
> - The framework provides formal bounds on performance loss for transferred policies, relating it to the distance between reward functions of known and new tasks.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This paper addresses a fundamental challenge in reinforcement learning: **transfer learning**. Traditional RL often focuses on training an agent from scratch for a single task. However, for RL to be truly scalable and applicable to real-world problems, agents must be able to leverage knowledge gained from one task to accelerate learning or improve performance on new, related tasks. This work specifically targets a common and practical transfer scenario: when the **environment's dynamics remain constant, but the reward function changes** between tasks.

The paper builds directly upon and generalizes several existing concepts in RL:
- **Successor Representation (SR):** Introduced by Peter Dayan (1993), SR represents the expected future occupancy of states under a given policy. This paper generalizes SR to "Successor Features" (SFs), extending it to continuous spaces and explicitly decoupling the reward function from the dynamics, making it amenable to function approximation and linear reward models. This is a crucial conceptual step from a state-centric view to a feature-centric one, allowing greater flexibility.
- **Value Functions and Dynamic Programming (DP):** The core of the proposed framework rests on modifying the standard Bellman equation and policy improvement operations. The paper's "Generalized Policy Improvement" (GPI) directly extends Bellman's theorem to combine multiple policies, a significant theoretical contribution in itself.
- **Generalized Value Functions (GVFs) and Universal Value Function Approximators (UVFAs):** The paper acknowledges the close relationship between SFs and GVFs (Sutton et al., 2011), which extend value functions to predict arbitrary pseudo-rewards. SFs can be seen as a specific, highly useful instance of GVFs. Similarly, UVFAs (Schaul et al., 2015) learn value functions conditional on a goal or task; SFs achieve a similar goal by parameterizing the value function with the reward weight vector `w`.
- **Hierarchical Reinforcement Learning (HRL) and Temporal Abstraction:** The concept of learning "skills" or "options" (Sutton et al., 1999) resonates strongly with SFs. By learning `ψ` for various optimal policies, the agent implicitly builds a library of fundamental movement patterns or behaviors that can be recombined for new tasks. This work suggests a principled way to select and combine these "options" via GPI.
- **Prior Transfer Learning Methods:** The paper contrasts its approach with existing methods like probabilistic policy reuse (Fernández et al., 2010) and other works that assume observability of reward features (Mehta et al., 2008). Unlike some prior methods, this approach seamlessly integrates transfer within the standard RL loop, rather than treating it as a separate meta-learning problem. It also provides strong theoretical guarantees on performance.

In essence, this work bridges theoretical foundations (SR, Bellman) with modern deep reinforcement learning, offering a theoretically grounded and practically effective framework for transfer learning in a common and important setting. It addresses the scalability bottleneck of traditional RL by enabling agents to generalize knowledge across tasks more efficiently, moving towards more intelligent and flexible artificial agents.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a robust and efficient framework for **transfer learning in reinforcement learning**, specifically for scenarios where the **reward function changes between tasks but the environment's dynamics remain constant**. This particular setup is highly relevant to real-world applications, as agents often need to adapt to shifting preferences, goals, or values within a stable environment (e.g., a robot performing different assembly tasks in the same factory, or a self-driving car adapting to different passenger preferences).

The authors are motivated by several key desiderata for an effective transfer learning framework:
1. **Generalization Across Tasks:** Beyond generalizing *within* a single task (e.g., to unseen states), the framework should enable agents to generalize knowledge *across different tasks*.
2. **Flexible Information Exchange:** The flow of information between tasks should not be constrained by rigid, pre-defined hierarchies or temporal dependencies. Instead, knowledge should be exchanged whenever it proves useful, regardless of the explicit relationship between tasks.
3. **Seamless Integration with RL:** Transfer mechanisms should be integrated as much as possible within the existing reinforcement learning framework, ideally in a way that is "almost transparent to the agent," rather than being a separate, ad-hoc module. This promotes algorithmic elegance and ease of implementation.
4. **Performance Guarantees:** The framework should offer theoretical guarantees on the performance of the transferred policy, even *before* any new learning takes place on the target task. This is crucial for reliability and understanding the limits of generalization.
5. **Building a "Skill Library":** The approach should facilitate the creation and reuse of a library of "skills" or "options" that can be recombined to efficiently solve previously unseen tasks, thereby increasing the autonomy and adaptability of RL agents.

By addressing these objectives, the authors aim to overcome a significant hurdle in RL's applicability: the need for extensive retraining for every slight change in objectives. Their proposed solution promises to make RL agents more adaptive, efficient, and ultimately, more intelligent.

### 3. Methodology and Approach

The core of the proposed transfer framework lies in the synergy of two key conceptual pillars: **Successor Features (SFs)** and **Generalized Policy Improvement (GPI)**.

#### 3.1. Successor Features (SFs)

The paper generalizes Dayan's (1993) Successor Representation. It starts by assuming that the reward function can be expressed as a linear combination of `d` features: `r(s, a, s') = φ(s, a, s')^T w`, where `φ` are environment features and `w` are reward weights. Building on this, the action-value function `Q_π(s, a)` can be decomposed as `Q_π(s, a) = ψ_π(s, a)^T w`.
- **Decoupling:** `ψ_π(s, a)` are the Successor Features. They represent the expected discounted sum of future `φ` features when following policy `π` from state-action pair `(s, a)`. Crucially, `ψ_π(s, a)` depends *only* on the environment's dynamics and the policy `π`, *not* on the specific reward weights `w`. The reward information is entirely encapsulated in `w`.
- **Efficiency:** This decoupling means that if the reward function changes (i.e., `w` changes), the `Q`-value for *any* existing policy `π` can be recomputed instantly by simply taking the dot product `ψ_π(s, a)^T w` with the new `w`, *without needing to relearn the policy or its value function from scratch*.
- **Learning `ψ_π`:** SFs satisfy a Bellman-like equation (`ψ_π(s, a) = φ(s, a, s') + γE_π[ψ_π(S', π(S')) | S=s, A=a]`), allowing them to be learned using any standard RL algorithm (e.g., Q-learning, DQN) where `φ` acts as a vector of pseudo-rewards.
- **Function Approximation:** The framework naturally extends to continuous state/action spaces and function approximation by learning `ψ_π(s, a)` as functions of `s` and `a`. The paper demonstrates this using linear approximation (Radial Basis Functions) and deep neural networks.

#### 3.2. Generalized Policy Improvement (GPI)

This is an extension of Bellman's classical policy improvement theorem.
- **Mechanism:** Given a set of `n` policies `π_1, ..., π_n` (e.g., optimal policies from previously solved tasks), GPI defines a new policy `π(s)` by selecting actions that are greedy with respect to the *maximum* value across all available policies: `π(s) ∈ argmax_a max_i Q_{π_i}(s, a)`.
- **Performance Guarantee (Theorem 1):** The paper proves that the new policy `π` is guaranteed to be at least as good as the best of the `n` policies, accounting for approximation errors. This is significant because `max_i Q_{π_i}` is generally not the value function of any single policy.
- **Transfer Specificity (Theorem 2):** For the specific case of SFs (where `Q_{π_j}(s,a) = ψ_{π_j}(s,a)^T w_i`), a stronger guarantee is provided. The loss in performance for the GPI policy `π` on a new task `M_i` (with reward `w_i`) compared to the optimal policy `π^*_i` for `M_i` is bounded by a term related to the distance `||w_i - w_j||` between the new task's reward weights `w_i` and the closest previously solved task's reward weights `w_j`. This formalizes the intuition that "similar tasks" should lead to good transfer.

#### 3.3. Integrated Approach

The two ideas integrate as follows:
1. **Pre-training Phase:** As an agent learns to solve a task `M_j` (defined by `w_j`), it simultaneously learns and stores its optimal Successor Features `ψ_{π^*_j}`. It also learns an approximation of `w_j` if not explicitly provided.
2. **New Task Adaptation:** When a new task `M_i` (defined by `w_i`) is encountered:
 - The agent estimates `w_i` (a supervised learning problem, if not provided).
 - It then re-evaluates all stored `ψ_{π^*_j}` under the new reward `w_i` to obtain `Q_{π^*_j, i}(s,a) = ψ_{π^*_j}(s,a)^T w_i`. This step is computationally cheap.
 - GPI is applied: `π(s) ∈ argmax_a max_j Q_{π^*_j, i}(s,a)`. This provides an immediate, theoretically guaranteed good policy for the new task, even before any explicit learning on `M_i` takes place.
 - The agent can then further refine `π` for `M_i` by learning `ψ_{π^*_i}` for the new task, potentially starting from a much better initial policy.

This methodology allows for a flexible library of "skills" (captured by `ψ`s) that can be instantly recomposed to form effective policies for novel reward functions, leading to significant acceleration in learning and improved generalization.

### 4. Main Findings and Results

The paper evaluates its proposed Successor Features for Generalized Policy Improvement (SFQL/SFDQN) framework across two distinct environments: a 2D continuous navigation task (four-room domain) and a simulated robotic arm control task (reacher domain).

#### 4.1. Four-Room Navigation Task

- **Setup:** The agent navigates a 4-room environment, collecting objects with varying rewards and reaching a goal. Reward functions change frequently. Baselines include Q-Learning (QL) and Probabilistic Policy Reuse Q-Learning (PRQL). SFQL uses linear function approximation with Radial Basis Functions. Two versions of SFQL were tested: SFQL-φ (perfect, pre-defined features) and SFQL-h (learning features from data).
- **Performance:** All versions of SFQL **significantly outperformed** both QL and PRQL. SFQL achieved an average return improvement of over 100% compared to PRQL, which itself improved on QL by approximately 100%. This demonstrates a substantial practical benefit in non-stationary reward scenarios.
- **Feature Learning (SFQL-h vs. SFQL-φ):** Surprisingly, SFQL-h (which learns its features) sometimes achieved good overall performance *faster* than SFQL-φ (which used perfectly defined features). The authors hypothesize this might be because learned features activate over a broader state-action space, providing a "denser pseudo-reward signal" that aids learning.
- **Ablation Study (Supplementary Material):** An important finding in the supplementary material highlights the contribution of GPI. SFQL without GPI initially outperforms PRQL (likely due to the decoupled representation and weak `ψ` transfer) but eventually reaches the same performance level. SFQL *with* GPI consistently and significantly outperforms all other methods, confirming that GPI is a crucial component for the observed strong transfer.

#### 4.2. MuJoCo Reacher Robotic Arm Task

- **Setup:** A two-joint robotic arm must reach specific target locations. There are 12 tasks (target locations), but the agent only trains on 4. The objective is to evaluate transfer to the 8 *unseen* test tasks. The method uses Deep Q-Networks (DQN) as its underlying RL engine, resulting in SFDQN.
- **Performance on Training Tasks:** SFDQN quickly reached near-optimal performance on the 4 training tasks, comparable to standard DQN.
- **Generalization to Unseen Tasks:** Crucially, as SFDQN learned a given training task, its performance also **improved in all other tasks, including the 8 unseen test tasks**, for which it had no specialized training policies. This is a powerful demonstration of generalization and transfer. The GPI mechanism allowed the agent to leverage learned SFs from *any* trained task to construct a good policy for *any* (trained or untrained) target, simply by knowing the target's `w` vector.
- **Normalized Return:** The results were normalized against a baseline of DQN training on each task separately, showing that SFDQN's transferred policies achieved a high fraction of the optimal performance on novel tasks.

In summary, the experiments provide strong empirical evidence that the SF + GPI framework effectively promotes transfer learning, leading to significantly faster adaptation and improved generalization to new tasks, even when using complex non-linear function approximators like deep neural networks.

### 5. Significance and Potential Impact

The research presented in "Successor Features for Transfer in Reinforcement Learning" offers a significant contribution to the field of reinforcement learning, with both theoretical advancements and practical implications.

#### 5.1. Theoretical Significance

- **Generalized Policy Improvement (GPI):** The paper formally defines and proves GPI (Theorem 1), extending Bellman's classical policy improvement theorem. This is a fundamental theoretical contribution that allows principled combination of multiple policies, providing a lower bound on the performance of the resulting policy.
- **Formal Performance Guarantees for Transfer:** Theorem 2 is particularly impactful. It quantitatively links the similarity between tasks (measured by the distance between their reward weight vectors, `||w_i - w_j||`) to the performance loss of a transferred policy. This provides a formal basis for understanding *why* and *how much* transfer should occur, offering a powerful tool for analyzing and designing transfer learning systems.
- **Unified Framework:** The work provides a theoretically sound and elegant framework that seamlessly integrates elements of value function approximation, policy improvement, and transfer learning within the standard RL paradigm.

#### 5.2. Practical Impact and Potential Applications

- **Efficient Adaptation to Changing Rewards:** The most direct impact is enabling RL agents to rapidly adapt to new reward functions in environments with stable dynamics. This is highly relevant for:
 - **Robotics:** A robot arm performing different assembly tasks (different goals/rewards) in the same workspace.
 - **Personalized Agents:** AI assistants or recommender systems that need to adapt to individual user preferences (varying `w`) while operating in a consistent environment.
 - **Game AI:** Agents that need to switch objectives or play modes within the same game engine.
- **Building Reusable Skill Libraries:** The framework facilitates the creation of "libraries of skills" (represented by `ψ` functions) that can be readily combined via GPI to solve an infinite number of new tasks. This moves RL beyond "training from scratch for every task" towards a more generalized intelligence, akin to humans learning foundational motor skills and then combining them for new activities.
- **Reduced Training Time and Computational Cost:** By leveraging previously learned dynamics (via `ψ`) and combining existing policies, the need for extensive retraining on new tasks is drastically reduced. This is critical for scaling RL to complex, high-dimensional problems where training is computationally expensive.
- **Robustness to Approximations:** The empirical results show the method's robustness to imperfections in feature representations (learning `φ` or adding noise), suggesting its practical applicability in real-world scenarios where perfect models are rare.
- **Integration with Deep RL:** Demonstrating successful integration with DQN shows the broad applicability of the SF+GPI approach to state-of-the-art deep reinforcement learning algorithms, opening avenues for high-performance, generalizable agents.

In conclusion, this paper presents a foundational contribution to transfer learning in RL, providing both theoretical insights and empirical validation for a framework that enables agents to efficiently reuse learned knowledge across tasks. Its emphasis on decoupling dynamics from rewards and leveraging generalized policy improvement lays a strong groundwork for developing more flexible, adaptable, and ultimately, more intelligent artificial agents.
