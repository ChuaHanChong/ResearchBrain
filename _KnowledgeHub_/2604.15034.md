# Autogenesis: A Self-Evolving Agent Protocol

> [!summary] Summary
> Autogenesis introduces a self-evolving agent protocol (AGP) that formalizes resource management and state transitions for LLM-based agents. This protocol enables auditable and safe self-modification, leading to enhanced performance across scientific, general agent, and algorithmic coding benchmarks.

## Problem

- Existing LLM-based agent systems often have static architectures that struggle to adapt to dynamic real-world environments.
- Current agent protocols lack standardized mechanisms for managing resource lifecycles, tracking version lineage, and ensuring safe, auditable updates for self-modifying agents.
- Ad hoc implementations of self-evolution lead to fragmented systems that are difficult to compose, maintain, and debug, with risks of instability and unrecoverable errors.

## Method

- The **Autogenesis Protocol (AGP)** is introduced as a ==two-layer architecture==: the ==Resource Substrate Protocol Layer (RSPL)== and the ==Self-Evolution Protocol Layer (SEPL)==.
- RSPL defines ==evolvable agent components== (prompts, agents, tools, environments, memory) as protocol-registered resources with explicit lifecycle and versioned interfaces.
- SEPL establishes a ==control-theoretic formalism== for evolution through a ==closed-loop operator algebra== (Reflect, Select, Improve, Evaluate, Commit) that rigorously governs state mutations.

## Results

- Weaker models showed up to **71.4%** relative improvement on AIME mathematical benchmarks, while stronger models achieved consistent gains (e.g., **2.3%** on GPQA-Diamond) through combined prompt and solution evolution.
- The Autogenesis System (AGS) achieved an **89.04%** Pass@1 on the GAIA benchmark, outperforming prior state-of-the-art by **1.66** percentage points and showing **33.3%** improvement on Level 3 tasks through tool evolution.
- Self-evolution consistently improved pass rates (**10.1%** to **26.7%** relative gains) and reduced execution errors and average runtime (e.g., **19.8-46.4%** in compiled languages) across five programming languages on the LeetCode benchmark.

## Takeaways

> [!tip] Key Insights
> - Decoupling evolvable resources from the core agent logic and managing them via a standardized protocol (RSPL) enables modularity, maintainability, and reusability.
> - Formalizing self-evolution through a defined operator algebra and strict version control ensures that all evolutionary steps are traceable, reversible, and adhere to safety invariants.
> - The protocol provides a unified framework for integrating diverse optimization strategies (e.g., reflection-driven, TextGrad, reinforcement learning) to safely and systematically improve various agent components.
