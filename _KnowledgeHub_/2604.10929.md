# Ro-SLM: Onboard Small Language Models for Robot Task Planning and Operation Code Generation

> [!summary] Summary
> Researchers from UMass Dartmouth and CSU San Marcos introduce Ro-SLM, a framework that distills Large Language Model reasoning into Small Language Models (SLMs) for robot task planning and operation code generation. The fine-tuned SLM (Llama-3.1-8B) achieved up to 97.7% task success rate on basic UAV tasks and 75% on advanced tasks, demonstrating effective onboard autonomy for resource-constrained robots.

## Problem

- Large Language Models (LLMs) are impractical for onboard robot deployment due to their high computational demands, requiring either substantial hardware or stable cloud connectivity.
- Small Language Models (SLMs), while deployable on resource-constrained robots, inherently lack the robust reasoning and code generation capabilities of LLMs.
- A significant performance gap exists between LLMs and SLMs, limiting SLMs' ability to reliably interpret complex human instructions and generalize to novel robotic tasks.

## Method

- The **Ro-SLM** framework employs a two-stage methodology: LLM-driven dataset synthesis and SLM fine-tuning with LLM feedback, designed to transfer LLM knowledge to SLMs.
- Dataset synthesis involves using LLMs (GPT-5.1, o4-mini) to generate diverse task instructions, ground truth robot operation code, and augmented real-world application scenarios, with human assistance for complex code verification.
- SLM fine-tuning uses Supervised Fine-Tuning (SFT) with ==LoRA== on the synthesized dataset, followed by optimization with Group Relative Policy Optimization (==GRPO==) where an LLM (GPT-5.1) acts as a binary reward function for code correctness.

## Results

- Ro-SLM enabled Llama-3.1-8B to achieve a **97.7%** task success rate and **98.9%** completeness on basic UAV tasks, and **70.0%** SR and **83.7%** completeness on advanced UAV tasks, significantly outperforming the untuned SLM (approx. 5-**10%** SR).
- The framework demonstrated robust performance on real-world mapped advanced tasks, achieving **75%** SR and **87%** completeness, even outperforming some LLM baselines on 'Very High' complexity tasks (**50%** SR vs. **25%** SR).
- Ro-SLM showed generalization capability by achieving **75%** SR and **81.1%** completeness on an unseen ground vehicle platform, approaching the performance of state-of-the-art LLM methods for that domain.

## Takeaways

> [!tip] Key Insights
> - Removing comments from the code in the training dataset significantly improves SLM performance, increasing success rate on advanced tasks by 20%, indicating that comments introduce noise during training.
> - Dataset augmentation with diverse, naturalistic language enhances the SLM's robustness and generalization to various instruction styles, improving performance on real-world mapped tasks.
> - Training with a diverse range of task complexities is crucial for robust SLM performance, as SLMs tend to overfit to specific task distributions, failing to generalize to different complexity levels.
