# ToMPC: Task-oriented Model Predictive Control via ADMM for Safe Robotic Manipulation

> [!summary] Summary
> A novel Task-oriented Model Predictive Control (ToMPC) framework integrates full-body dynamics, whole-body collision avoidance, and compliant interaction for robotic manipulation, utilizing ADMM to decompose the optimization problem for real-time performance and strict safety constraint satisfaction. The method demonstrated reduced computation times by an order of magnitude and achieved superior task execution quality compared to existing approaches.

## Problem

- Integrating versatile motion, compliant physical interaction, and comprehensive collision avoidance into a single control framework for robots operating in complex and obstructed environments.
- Achieving real-time performance for dynamics-based Model Predictive Control (MPC) while rigorously satisfying hard safety inequality constraints (e.g., obstacle avoidance).
- Existing efficient nonlinear solvers like DDP struggle with hard inequality constraints, and methods using barrier functions may compromise strict constraint satisfaction.

## Method

- A unified Task-oriented ==Model Predictive Control== (**ToMPC**) framework incorporating full-body dynamics, whole-body collision avoidance, and compliant environment interaction.
- A task-oriented avoidance strategy that utilizes kinematic redundancy to proactively maneuver robot links, enhancing manipulation efficiency in obstructed spaces.
- The Alternating Direction Method of Multipliers (ADMM) decomposes the complex optimization into a DDP-solved dynamics subproblem and parallel QP-solved constraint subproblems for real-time performance and strict constraint satisfaction.

## Results

- ToMPC rigorously satisfied hard safety constraints (e.g., obstacle avoidance) and demonstrated an order of magnitude faster computation times (e.g., 0.0009s for T=10) compared to benchmark solvers.
- In hardware, the task-oriented avoidance strategy enabled robots to leverage kinematic redundancy for proactive obstacle navigation, resulting in enhanced manipulation efficiency and lower position errors (e.g., 0.0201m mean error).
- The framework achieved accurate and smooth force tracking during compliant environment interaction and successfully performed hybrid motion-force tasks while avoiding obstacles, expanding the robot's effective workspace.

## Takeaways

> [!tip] Key Insights
> - ADMM-based decomposition effectively separates the complex MPC problem into dynamic (DDP) and constraint (QP) subproblems, enabling real-time control with strict satisfaction of hard inequality constraints.
> - Task-oriented avoidance, utilizing kinematic redundancy, allows robots to proactively navigate obstacles without compromising task performance, extending the effective manipulation workspace.
> - Incorporating full-body dynamics and an impedance-based interaction model within an MPC framework leads to smoother and more accurate force tracking during compliant robot-environment interactions.
