# From Local Matches to Global Masks: Template-Guided Instance Detection and Segmentation in Open-World Scenes

> [!summary] Summary
> The L2G-Det framework from The University of Texas at Dallas enables robots to detect and segment novel objects in complex scenes by reconstructing global masks from dense local feature matches, bypassing object proposal limitations. It achieved a 12.3 AP improvement on the HR-InsDet dataset, reaching 76.2 AP, and successfully identified all target objects in real-world robotic trials.

## Problem

- Existing methods for novel object instance detection and segmentation often rely on object proposal pipelines, which are sensitive to proposal quality.
- These proposal-based approaches struggle with challenges like occlusions, background clutter, and diverse viewpoints in open-world robotic environments.
- Accurately locating and precisely segmenting specific object instances given only a small set of template images remains a critical challenge.

## Method

- **L2G-Det** employs a local-to-global strategy, integrating ==dense local feature matching== (DINOv3) with an adapted foundation model (SAM) to reconstruct global instance masks.
- A ==Candidate Selector== refines initial dense matches using single-point SAM probing and a learnable residual MLP adapter, filtering out false positives.
- An ==Augmented SAM (SAM*)== module with instance-specific object tokens addresses incomplete masks and enables incremental learning without catastrophic forgetting.

## Results

- L2G-Det achieved **76.2 AP** on the HR-InsDet dataset, outperforming the previous baseline (NIDS-Net) by **12.3 AP**, with a **17.6 AP** gain on challenging "hard" subsets.
- It obtained **71.9 AP** on the RoboTools dataset, surpassing NIDS-Net by **7.0 AP**, and produced more complete and accurate detections in cluttered scenes.
- Successfully deployed on a Fetch robot, the system detected all **8 target objects** in real-world cluttered indoor environments, demonstrating practical applicability and improved mask accuracy with the Augmented SAM module.

## Takeaways

> [!tip] Key Insights
> - Bypassing explicit object proposals and relying on dense local correspondences significantly improves robustness against occlusion and clutter in complex scenes.
> - Adapting powerful foundation models (like DINOv3 and SAM) with lightweight, learnable components (e.g., residual MLP adapter, instance-specific object token) can effectively specialize them for novel instance detection tasks.
> - Synthetic data generation from template images and a dedicated object token memory provide an efficient and scalable approach for continual learning of new object instances without catastrophic forgetting.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work addresses the problem of novel object instance detection and segmentation within open-world environments, a critical challenge in robotic perception. This involves locating and precisely segmenting specific object instances in novel, cluttered scenes, given only a small set of template images of the target object.

Existing approaches in this field predominantly rely on an object proposal-based pipeline. These methods typically involve generating object-like regions (proposals) in a query image, followed by matching template embeddings against these proposals to identify the target instance. While effective in some scenarios, these proposal-based methods exhibit sensitivity to the quality of the generated proposals. In environments characterized by occlusions, background clutter, diverse viewpoints, or partial object visibility, proposals can be inaccurate or incomplete, leading to degraded detection and segmentation performance.

This research leverages advancements in dense local feature matching, employing large-scale pretrained visual encoders such as DINOv3, which produce semantically meaningful patch-level features. It also builds upon the capabilities of foundation models, particularly the Segment Anything Model (SAM), for image segmentation. Prior works have explored dense feature matching for tasks like localization or pose estimation, often focusing on geometric alignment or sparse keypoints. Other research has adapted foundation models like SAM through fine-tuning for specific tasks or utilized detectors such as GroundingDINO for open-vocabulary object localization.

The presented work, L2G-Det, positions itself as an alternative to proposal-based pipelines. It aims to overcome the limitations of proposal generation by adopting a local-to-global strategy. This involves reconstructing global instance masks from dense local correspondences rather than relying on explicit object proposals. By integrating dense feature matching with an adapted foundation model for segmentation, the paper contributes a method designed to be more robust to challenging real-world conditions frequently encountered in robotic applications.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a robust framework for detecting and segmenting novel object instances in open-world environments, a fundamental requirement for autonomous robotic systems. The goal is to enable a robot, provided with a small collection of template images of a specific object, to accurately locate and segment that object within complex, previously unencountered scenes.

The motivation for this work stems from observed limitations in current state-of-the-art approaches:
1. **Dependency on Object Proposal Quality:** Many existing methods rely on generating object proposals in the query image before performing instance matching. The effectiveness of these methods is critically tied to the quality of these initial proposals. In real-world robotic scenarios, proposals can be inaccurate, covering only partial object parts, including background clutter, or entirely missing the target instance. This dependency leads to compromised detection and segmentation performance, particularly under challenging conditions such as occlusions, diverse viewpoints, or objects being only partially visible.
2. **Robustness in Open-World Scenes:** Real-world environments are inherently complex and dynamic. Objects can appear in varied lighting, poses, and degrees of occlusion, surrounded by clutter. Current proposal-based detectors often struggle to produce high-quality proposals that align with the complete appearance of the target object as represented by templates, making them less suitable for deployment in unstructured settings.

To address these issues, the authors established several key objectives for their proposed L2G-Det framework:
- **Bypass Explicit Object Proposals:** Design a pipeline that avoids the generation of explicit object proposals, thereby circumventing the quality issues associated with them.
- **Leverage Dense Local Correspondences:** Utilize fine-grained, patch-level matching between template images and the query image to identify object-specific local cues. This aims to capture richer, more resilient information about the object's presence than coarser proposals.
- **Refine Local Matches:** Implement mechanisms to filter out false positives that naturally arise from local appearance ambiguities during dense feature matching, ensuring that only reliable local cues are used.
- **Reconstruct Complete Instance Masks:** Develop a method to synthesize a complete and accurate global instance segmentation mask from potentially sparse and localized candidate points.
- **Enable Incremental Learning of Novel Instances:** Create a system that can continuously learn and incorporate new object instances without diminishing its performance on previously learned ones (catastrophic forgetting). This is crucial for scalability in open-world applications where new objects may be introduced over time.
- **Improve Performance in Challenging Settings:** Achieve superior detection and segmentation accuracy compared to existing methods, especially in scenes with high clutter, occlusions, and varied viewpoints.

These objectives collectively aim to develop a more robust, adaptable, and scalable instance detection and segmentation framework for robotic perception in open-world environments.

### 3. Methodology and Approach

The proposed framework, named L2G-Det (Local-to-Global Instance Detection), operates by replacing traditional proposal-based pipelines with a three-stage approach: dense feature matching, candidate selection, and augmented mask reconstruction. The model assumes access to `K` template images {I^k_temp} with corresponding object masks {M^k_temp} for each target instance.

**A. Dense Feature Matching:**
1. **Feature Extraction:** A frozen DINOv3 backbone is utilized to extract dense patch-level features from both the template images and the query image (I_query).
2. **Patch Sampling:** For each template image `I^k_temp`, `S` patches are uniformly sampled from within its ground-truth object mask `M^k_temp`. Each sampled patch yields a feature embedding `f^k_i`.
3. **Cross-Image Matching:** For each template patch feature `f^k_i`, its cosine similarity is computed against all `N` patch features `{f_j}` extracted from the query image.
4. **Candidate Point Generation:** The query patch `j*` with the highest cosine similarity to `f^k_i` is selected. The spatial center of this selected query patch is then designated as a candidate point `p^k_i`. This process generates a set of initial candidate points `C^k` for each template image.

**B. Candidate Selector:**
This module refines the initial set of candidate points to suppress false positives caused by local appearance ambiguities.
1. **Single-point SAM Probing:** Each candidate point `p^k_i` from `C^k` is used as a single-point prompt for a frozen Segment Anything Model (SAM). SAM generates a local mask region `M^k_i` around the queried point in the query image.
2. **Candidate and Template Embedding Generation:**
 - **Candidate Embedding:** The local mask `M^k_i` is applied to the query image (`I_query ⊙ M^k_i`), and the resulting masked region is passed through a frozen feature encoder `E(·)` followed by a lightweight, learnable residual MLP adapter `A(·)`. This yields the candidate embedding `z^k_i`.
 - **Template Embedding:** Similarly, the full object region from the `k`-th template image (`I^k_temp ⊙ M^k_temp`) is processed by `E(·)` and `A(·)` to obtain the template embedding `z^k_temp`.
3. **Learnable Residual MLP Adapter:** The adapter `A(x) = x + α · MLP(x)` is designed to enhance instance-level discrimination. Only the adapter's parameters are learned, while `E(·)` remains frozen. It is trained using an InfoNCE-style contrastive loss with template images and synthetic images, where embeddings from the same instance are positive pairs, and those from different instances are negative.
4. **Similarity Scoring and Filtering:** The cosine similarity `s^k_i` is calculated between each candidate embedding `z^k_i` and its corresponding template embedding `z^k_temp`. Candidate points are filtered based on these scores: a point `p^k_i` is retained if its score `s^k_i` is within a threshold `δ` of the maximum score `s^k_max` for that template (`s^k_max - s^k_i < δ`). This strategy preserves primary and secondary relevant local regions. The selected points from all templates are aggregated into a final set `P`. A farthest-point-first strategy is then applied to `P` to select the final prompt points for mask reconstruction, ensuring spatial diversity.

**C. Augmented SAM (SAM\*):**
This module addresses the issue of potentially incomplete masks generated by a frozen SAM from sparse candidate points.
1. **Instance-Specific Object Token:** A learnable, instance-specific object token `t_O` is introduced. This token is injected into the SAM mask decoder `D_mask(·)` along with the frozen image tokens `T_I` (from SAM's image encoder `E_I`) and prompt tokens `T_P` (from SAM's prompt encoder `E_P`). The predicted mask is `ˆM = D_mask(T_I, T_P, t_O)`. Only `t_O` is learnable.
2. **Template-based Synthetic Training Data:** To train the adapter and the object token, synthetic images are generated. This involves compositing masked object regions from template images onto publicly available open-world background images. Three types of scenes are synthesized: single-object, multi-object without overlap, and multi-object with overlap (simulating occlusions). This approach is designed to be computationally efficient.
3. **Training Loss:** The object token `t_O` is optimized using a hybrid segmentation loss combining binary cross-entropy loss, Dice loss, and IoU loss. Randomly sampled pixel locations within the ground-truth target mask serve as point prompts for SAM during training.
4. **Object Token Memory for Incremental Addition:** Each learned `t_O` for a specific object instance is stored in a memory pool. As new objects are introduced, new tokens are appended, and their training does not modify previously stored tokens. This design prevents catastrophic forgetting and supports continual learning, allowing the framework to scale to new novel instances over time.

For high-resolution images like those in HR-InsDet, a local-window inference strategy is employed, processing quarter-resolution windows of the image.

### 4. Main Findings and Results

The L2G-Det framework was evaluated on two challenging benchmarks and in real-world robotic experiments.

**Benchmarking Results:**
- **HR-InsDet Dataset:** L2G-Det achieved an Average Precision (AP) of 76.2, representing a 12.3 AP improvement over the previous top-performing baseline, NIDS-Net (63.9 AP). On the "hard" subset, characterized by severe occlusion and clutter, L2G-Det demonstrated an even larger gain of 17.6 AP (75.4 AP vs. NIDS-Net's 57.8 AP on hard, 81.2 AP vs. NIDS-Net's 72.7 AP on easy), indicating robustness in complex scenarios.
- **RoboTools Dataset:** L2G-Det obtained an AP of 71.9, outperforming NIDS-Net (64.9 AP) by 7.0 AP. Qualitative comparisons suggested that L2G-Det produces more complete and accurate detections in cluttered scenes.

**Ablation Studies:**
- **Effect of Adapter and Augmented SAM (Table III):** Both the adapter in the Candidate Selector and the Augmented SAM module (SAM\*) individually contributed to performance improvements. Their combined application yielded the highest detection performance on both datasets, with more pronounced gains on the High-Resolution dataset. This suggested their complementary roles in improving instance-level discrimination and mask completion.
- **Candidate Selector Design (Table IV):** Removing the filtering step (using all candidate points from dense matching) resulted in significantly lower AP (48.7). Simple score-based filtering improved performance (53.4 AP), but the full Candidate Selector, incorporating single-point SAM probing and embedding comparison, achieved substantially better results (64.8 AP with PE encoder). The use of Perception Encoder (PE) for candidate embedding extraction (64.8 AP) consistently outperformed using DINO-CLS class tokens (62.7 AP), indicating the benefit of stronger semantic representations.
- **Effect of Number of Template Images (Fig. 5):** Increasing the number of template images (K) generally improved performance, with the full L2G-Det model showing diminishing returns after K=8-12, suggesting a practical range for template collection.
- **Training Strategies (Table V):** The proposed SAM\* (Augmented SAM) strategy, which uses instance-specific object tokens, achieved the best performance (71.9 AP) compared to conventional joint training (69.9 AP) and continual-learning joint training (69.5 AP). This supports the effectiveness and scalability of the instance-specific tokenization approach.
- **Effect of Dense Feature Extractors (Table VI):** DINOv3-Large (64.8 AP for base L2G-Det, 71.9 AP for full L2G-Det) consistently outperformed DINOv2-Large and LoFTR as the dense feature extractor, demonstrating the positive correlation between the quality of dense features and detection performance.
- **Effect of Backbone Choice (Table VII):** L2G-Det maintained superior performance even when using smaller DINOv2 backbones compared to baselines using larger ones, indicating that the architectural design of the local-to-global pipeline is a primary contributor to its effectiveness.
- **Effect of Template-specific Similarity Computation (Table XI, Appendix):** Computing similarity with the corresponding template embedding (64.8 AP) was found to be more effective than using an averaged template embedding (61.4 AP), suggesting that preserving specific local cues from individual templates aids in more accurate candidate selection.

**Real-World Robotic Experiments:**
- L2G-Det was deployed on a Fetch robot equipped with an RTX 4090 laptop and a Realsense D415 camera.
- The system successfully detected all 8 target objects in cluttered indoor environments (8 out of 8 trials successful).
- L2G-Det with SAM\* consistently yielded more accurate and complete masks, resulting in better performance under stricter IoU thresholds compared to L2G-Det with the basic SAM model (e.g., 8 detections with IoU>0.75 for SAM\* vs. 7 for basic SAM).

**Computational Cost (Tables IX and X):**
- Training an object token per object took approximately 25 minutes, and training the adapter for all objects took 2 hours.
- Inference runtime for K=4 templates was 1.10 seconds on RoboTools (1920x1080) and 4.10 seconds on HR-InsDet (8192x6144). GPU memory usage was 8300 MiB and 20000 MiB, respectively.
- Inference time increased with the number of templates, reflecting a trade-off between efficiency and robustness.

### 5. Significance and Potential Impact

This research presents a framework, L2G-Det, that addresses critical limitations in novel object instance detection and segmentation, particularly in open-world robotic contexts. The significance and potential impact of this work include:

1. **Enhanced Robustness in Challenging Environments:** By bypassing explicit object proposal generation, L2G-Det offers a more robust solution to object detection and segmentation under occlusions, diverse viewpoints, and background clutter. This is a substantial improvement over proposal-based methods, which often struggle in such conditions. The demonstrated performance gains on hard subsets of benchmarks and in real-world robotic experiments underscore this robustness.
2. **Scalability and Continual Learning for Robotics:** The introduction of an instance-specific object token memory enables the system to incrementally learn and adapt to new object instances without suffering from catastrophic forgetting. This is a crucial capability for robotic systems operating in dynamic environments where new objects may be introduced frequently, allowing for scalable instance-level perception over time.
3. **Efficient Data Generation:** The use of template-based synthetic images for training the adapter and object tokens offers a computationally efficient alternative to generating complex real-world datasets or relying on expensive generative models. This practical approach can accelerate the deployment of novel object recognition capabilities.
4. **Effective Integration of Foundation Models:** The work demonstrates an effective strategy for integrating and adapting powerful, pre-trained foundation models (DINOv3 for dense features, SAM for segmentation) into a specialized pipeline for novel instance detection. This highlights how general-purpose models can be tailored to challenging perception tasks beyond their original scope.
5. **Direct Applicability in Robotic Systems:** The successful deployment and evaluation of L2G-Det on a Fetch robot for object search and localization tasks validates its practical utility. This capability is fundamental for numerous robotic applications, including service robotics (e.g., retrieving specific items), warehouse automation (e.g., handling new products), and general object manipulation in unstructured settings.
6. **Guidance for Future Research:** The identified limitations, such as the non-end-to-end nature of the current framework and the simplicity of synthetic data generation, point towards clear directions for future research. This includes exploring more end-to-end detection architectures and leveraging advanced generative models to create more realistic training data, potentially leading to further performance and efficiency improvements.

In summary, L2G-Det represents a step forward in equipping robots with more capable and adaptable perception systems for interacting with novel objects in complex, real-world environments.
