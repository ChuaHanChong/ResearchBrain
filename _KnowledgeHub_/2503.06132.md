# USP: Unified Self-Supervised Pretraining for Image Generation and Understanding

> [!summary] Summary
> USP (Unified Self-Supervised Pretraining) introduces a framework for masked latent modeling within a frozen VAE's latent space, enabling a single pretraining phase to efficiently initialize models for both image generation and understanding tasks. This approach achieves substantial acceleration in diffusion model convergence (e.g., 11.7x for DiT-XL/2) and demonstrates superior performance in image classification and semantic segmentation compared to baselines like MAE.

## Problem

- Determining if pretraining is feasible and necessary for diffusion-based image generation.
- Investigating whether a single, unified pretraining framework can simultaneously improve performance in both image generation and understanding tasks.
- Addressing input and architecture mismatches between traditional image recognition models and modern diffusion models (e.g., clean images vs. noisy latent features, standard ViT vs. DiT/SiT).

## Method

- Proposes a ==masked latent modeling== approach where input images are first encoded into a latent space using an off-the-shelf, frozen ==Variational Autoencoder (VAE)==.
- A Vision Transformer (ViT) encoder is trained via self-supervision to reconstruct randomly masked patches of these latent features, inspired by ==Masked Autoencoders (MAE)==.
- The pretrained ViT encoder weights are then adapted to initialize models for downstream image generation (==DiT/SiT==) and image understanding tasks (classification, segmentation, detection).

## Results

- Achieved significant acceleration in diffusion model training, with **11.7x** speedup for DiT-XL/2 and **46.6x** speedup for SiT-XL/2 compared to baselines, leading to substantial computational efficiency.
- Demonstrated enhanced generation quality, consistently achieving better Fréchet Inception Distance (FID) and Inception Score (IS) across various model sizes and training steps.
- Outperformed MAE in image understanding tasks, showing improved linear probe accuracy on ImageNet (e.g., **66.9%** for ViT-Base) and higher mIoU on ADE20K semantic segmentation (e.g., **46.7%** for ViT-Base).

## Takeaways

> [!tip] Key Insights
> - Pretraining within the latent space of a frozen VAE effectively addresses input and architecture mismatches between generative and discriminative models.
> - Masked latent modeling learns robust and discriminative representations beneficial for both image generation and understanding tasks, decoupling pretraining from specific downstream objectives.
> - Using a general-purpose self-supervised pretraining for diffusion models leads to substantial convergence speedups and improved generation quality.
