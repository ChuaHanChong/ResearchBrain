# Improving Visual Reasoning with Iterative Evidence Refinement

> [!summary] Summary
> The paper introduces SIEVE (Self-revisit Iterative Evidence Refinement), a framework enabling Vision-Language Models to automatically identify and inject task-relevant visual embeddings from their internal states into the reasoning chain. This method achieves substantial accuracy improvements across high-resolution visual reasoning, perception, and hallucination benchmarks, such as a 7.85% gain on V*Bench for the 4B model, without relying on external tools or image re-encoding.

## Problem

- Vision-Language Models (VLMs) typically have a text-centric inference pipeline where visual information becomes less influential as textual reasoning extends.
- Current VLMs struggle with targeted, step-dependent revisiting of visual evidence, leading to underutilization of fine-grained visual details in complex multi-step reasoning.
- Existing solutions using external visual tools (e.g., zooming, cropping) disrupt reasoning continuity, require complex training, and introduce inference overhead due to repeated image re-encoding.

## Method

- **SIEVE** uses a self-guided visual evidence identification mechanism that automatically extracts embeddings of visually salient regions by combining ==token-level gradient saliency== with ==multimodal hidden state matching==.
- A ==reinforcement learning (RL) policy== is trained to determine when to trigger visual revisiting and which cached region embeddings to retrieve and insert into the VLM's reasoning chain.
- A comprehensive ==trajectory-level reward function== is designed to guide the RL process, incentivizing correct answers, proper output formatting, active embedding utilization, and stable, meaningful reasoning.

## Results

- SIEVE achieved consistent performance gains, including a **7.85%** overall accuracy improvement on V*Bench and up to **4.00%** on HR-Bench 8K for the Qwen3-VL-4B-Instruct base model.
- The framework demonstrated strong generalization, improving perception benchmarks (e.g., **12.8%** on MME-Real-Lite reasoning split for the 4B model) and reducing hallucination metrics on HallusionBench by **3.89%** for the 8B model.
- Inference time analysis showed SIEVE did not substantially increase computational overhead, and in some cases, it was faster than existing tool-invocation methods.

## Takeaways

> [!tip] Key Insights
> - VLMs' internal visual embeddings contain sufficient information for complex visual reasoning, and the key is enabling the model to selectively access and reuse relevant localized evidence.
> - Task-relevant visual evidence can be efficiently identified and extracted from intermediate hidden states using gradient saliency and multimodal alignment without external tools or image re-encoding.
> - Reinforcement learning with a carefully designed reward function can effectively train VLMs to dynamically integrate relevant visual cues, leading to improved performance across diverse reasoning tasks and reduced hallucination.
