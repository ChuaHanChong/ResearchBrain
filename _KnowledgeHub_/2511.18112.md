# EchoVLA: Synergistic Declarative Memory for VLA-Driven Mobile Manipulation

> [!summary] Summary
> EchoVLA, a Vision-Language-Action (VLA) model, introduces a neuro-inspired synergistic declarative memory system for robust mobile manipulation, distinguishing between persistent spatial scene memory and dynamic episodic memory. The research also presents MoMani, an automated benchmark that generates over 7,800 simulated and 1,200 real-world expert-level trajectories for diverse mobile manipulation tasks, enabling EchoVLA to achieve an average success rate of 0.31 in simulation and 0.44 on real robots, outperforming baseline VLA models.

## Problem

- Existing Vision-Language-Action (VLA) models are largely confined to short-horizon, table-top manipulation and operate under a Markovian control paradigm, lacking long-term reasoning for complex mobile manipulation.
- Mobile manipulation tasks require sophisticated memory and reasoning for coordinating navigation and manipulation across changing spatial contexts, which current VLA systems struggle to provide.
- The absence of comprehensive, scalable, and automated benchmarks with real-robot data hinders the development and rigorous evaluation of advanced mobile manipulation agents.

## Method

![[2511.18112-method.png]]
*The architecture of EchoVLA showing how multimodal tokens interact with the dual memory systems to produce actions.*

- **EchoVLA** implements a biologically-inspired declarative memory system with distinct Scene Memory (a persistent voxelized 3D map) and Episodic Memory (a time-indexed buffer of recent multimodal tokens).
- A hierarchical (coarse-to-fine) attention mechanism integrates retrieved information from both memory systems to condition a ==diffusion==-based, per-part action policy for coordinated base and arm control.
- MoMani, an automated two-stage benchmark, generates expert-level mobile manipulation trajectories in simulation (via MLLM-guided planning and quality gates) and collects real-robot demonstrations to provide diverse, high-quality training data.

## Results

- In simulation (RoboCasa), EchoVLA achieved an average success rate (SR) of 0.31 for mobile manipulation tasks, surpassing strong baselines like π0.5 (0.20) and WB-VIMA (0.11).
- On real robots (TidyBot++), EchoVLA demonstrated a mean SR of 0.44 across six diverse tasks, outperforming π0.5 (0.33) and Diffusion Policy (0.32), and achieved an SR of 0.10 in a long-horizon task where baselines largely failed.
- Ablation studies confirmed the individual contributions of both Scene Memory and Episodic Memory, with their removal leading to performance degradation, and highlighted the importance of both RGB and 3D point cloud inputs.

## Takeaways

> [!tip] Key Insights
> - A dual memory system, separating stable spatial understanding (Scene Memory) from dynamic temporal task experiences (Episodic Memory), provides a robust foundation for long-horizon mobile manipulation.
> - Integrating memory through hierarchical attention allows the robot policy to effectively leverage both persistent environmental knowledge and recent task context, mitigating issues like 'plan forgetting'.
> - Automated data generation with strict quality controls is feasible and crucial for creating large-scale, high-quality datasets necessary to train complex mobile manipulation models.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of Vision-Language-Action (VLA) models has progressed in enabling embodied agents to interpret multimodal instructions and execute complex tasks. Contemporary VLA models, such as RT-2, OpenVLA, and ManipLLM, utilize large-scale vision-language pretraining to facilitate robot control and achieve zero-shot generalization across objects and scenes. However, a significant limitation of many existing VLA systems is their confinement to short-horizon, table-top manipulation tasks. These systems typically operate under a Markovian control paradigm, wherein each decision relies solely on the current observation, lacking the capability for consistent reasoning over extended task sequences or a comprehensive long-term spatial understanding necessary for more complex scenarios.

Mobile manipulation presents a more challenging domain, requiring agents to coordinate both navigation and manipulation actions across changing spatial contexts, which demands advanced memory and reasoning capabilities. Prior efforts to integrate memory into VLA models include approaches like BSC-Nav, which employs landmark memory and a cognitive map for LLM-based reasoning and planning, and MemoryVLA, which uses perceptual and cognitive memories to condition a diffusion policy. While these methods introduce forms of memory, they often lack an explicit, persistent spatial representation or a detailed task-level experience storage that could support truly long-horizon reasoning.

Concurrently, the development of benchmarks for mobile manipulation has been ongoing. Early platforms such as RoboTHOR and iGibson 2.0 focused on navigation and basic interaction. More recent suites like Habitat 2.0, BEHAVIOR-100/1K, and ManiSkill2 have expanded task diversity but often simplify the mobile manipulation aspect or focus on static manipulation. Simulators like RoboCasa offer realistic scenes, but their task spectrum may remain domain-specific. RoboTwin 2.0 automates data generation for dual-arm tasks but does not typically include base navigation. TidyBot and TidyBot++ contribute platforms for data collection but do not offer broad, automated task generation.

This work addresses these gaps by proposing a memory-aware VLA model, EchoVLA, which draws inspiration from human declarative memory to integrate distinct spatial and episodic memory systems. Furthermore, it introduces MoMani, an automated benchmark designed to generate expert-level trajectories for diverse mobile manipulation tasks, including real-robot demonstrations, thereby facilitating large-scale training and evaluation in this complex domain. This research aims to extend the capabilities of VLA models beyond short-horizon manipulation by providing a structured memory architecture and a comprehensive benchmark for mobile manipulation.

### 2. Key Objectives and Motivation

The primary objectives and motivations behind the EchoVLA research are multi-faceted, addressing limitations in current embodied agent capabilities and data generation methodologies:

1. **Overcome Limitations of Existing Vision-Language-Action (VLA) Models for Mobile Manipulation**: Current VLA models predominantly operate in restricted, short-horizon, table-top manipulation environments. They rely on Markovian control, where decisions are made based only on immediate observations, which is insufficient for tasks requiring sequential reasoning, long-term spatial understanding, and coordination between navigation and manipulation in dynamic environments. The motivation is to extend VLA capabilities to mobile manipulation, where agents must perform complex tasks across varying spatial contexts.

2. **Integrate Biologically-Inspired Memory Mechanisms**: The human brain's declarative memory system, comprising complementary subsystems for spatial and experiential memory, serves as a direct inspiration. The parahippocampal cortex (PHC) provides stable spatial and semantic representations of scenes, while the hippocampus integrates contextual inputs into temporally organized episodic traces of experiences. The objective is to design an artificial memory system, mirroring this dual structure, to enable an embodied agent to remember environmental layouts ("where things are") and task execution steps ("how tasks were accomplished"). This neuro-inspired approach is motivated by the potential for more robust, consistent, and context-aware robot reasoning.

3. **Develop a Synergistic Declarative Memory System**: Specifically, the work aims to implement two distinct memory components:
 - **Scene Memory**: To maintain a persistent spatial representation of the environment, akin to the PHC, as a voxel map. This memory is intended to capture stable environmental geometry and object relations.
 - **Episodic Memory**: To store time-indexed multimodal tokens representing task-level experiences, analogous to hippocampal processing. This memory is designed to track task progress and recent interactions.
 The motivation for this synergistic design is to allow for both stable spatial understanding and dynamic temporal reasoning, which are crucial for long-horizon mobile manipulation.

4. **Enhance Policy Control through Memory Integration**: The objective is to integrate these dual memory systems into a robot control policy using a hierarchical retrieval and attention mechanism. This involves retrieving relevant information from both scene and episodic memories and fusing these representations via coarse- and fine-grained cross-attention to guide base-arm diffusion policies. This approach is motivated by the need for context-aware action generation that can leverage both static environmental knowledge and dynamic task history.

5. **Create a Comprehensive and Automated Mobile Manipulation Benchmark**: Existing mobile manipulation benchmarks often have limitations in scale, task diversity, or the inclusion of real-robot data. The motivation is to develop a new benchmark, MoMani, that generates expert-level trajectories through an automated pipeline, including multimodal large language model (MLLM)-guided planning and feedback-driven refinement. This benchmark is designed to provide richer task coverage and incorporate real-robot demonstrations, thereby supporting large-scale training and rigorous evaluation of mobile manipulation systems.

6. **Demonstrate Improved Performance and Robustness**: The ultimate objective is to empirically validate that the proposed EchoVLA model, leveraging its synergistic declarative memory and trained on the MoMani benchmark, achieves substantial performance gains in mobile manipulation tasks compared to existing strong baselines in both simulated and real-world environments. This includes improving success rates for coordinated navigation and manipulation over long horizons and under perceptual noise.

### 3. Methodology and Approach

EchoVLA integrates a neuro-inspired memory architecture with a diffusion-based action generation framework. The methodology also includes the development of MoMani, an automated benchmark for data generation.

#### 3.1. EchoVLA Architecture

The EchoVLA framework comprises three main components: multimodal state representation, memory retrieval and interaction, and diffusion-based action generation.

1. **Multimodal State Representation**:
 - **Inputs**: The agent receives multi-view RGB-D images, proprioceptive states (robot's internal configuration), and natural-language instructions.
 - **Encoders**:
 - **Language**: A frozen SigLIP text encoder processes instructions into language tokens.
 - **Multi-view RGB Images**: Three fixed cameras capture RGB images, which are processed independently by a frozen SigLIP vision tower. The resulting view-specific features are concatenated and projected into a shared feature space.
 - **3D Structure (Depth)**: Depth observations are fused into a point cloud and encoded by a trainable PointAttn network, generating 3D geometric tokens.
 - **Proprioceptive State**: Robot states are transformed into tokens using a small MLP.
 - **Unified Token Sequence**: All encoded modalities are concatenated into a unified token sequence, `S_t`, which serves as the query for memory retrieval and conditions the action policy.

2. **Memory Retrieval and Interaction**:
 EchoVLA utilizes two complementary memory banks and a two-level hierarchical (coarse-to-fine) attention mechanism for retrieval.

 - **Scene Memory**:
 - **Structure**: A persistent, voxelized 3D feature map (`V_3D`) that accumulates spatial information across episodes within the same environment.
 - **Initialization and Update**: Initially an empty grid, it is updated using a discrepancy-driven rule. Current voxel features are compared with a reconstruction from existing memory, and only regions exceeding a threshold in reconstruction error are updated with new PointAttn features. This allows the scene map to evolve and converge to a stable representation of the environment's geometry.
 - **Retrieval**: The current voxelized 3D feature map (`V_3D_t`) queries stored scene maps using cosine similarity to select top-k matches. Coarse cross-attention then processes these matches to produce `Z_scene_t`.

 - **Episodic Memory**:
 - **Structure**: A time-indexed, fixed-size FIFO buffer (`M_epi`) storing a short horizon of recent multimodal token sequences (`S_t-k` to `S_t-1`) along with their timesteps.
 - **Function**: It preserves fine-grained temporal information related to recent interactions and task progress (e.g., whether a drawer is open).
 - **Retrieval**: The current multimodal state tokens (`S_t`) query historical states in `M_epi` using cosine similarity to select relevant subsets. Fine cross-attention then processes these subsets to produce `Z_epi_t`.

 - **Memory Fusion**: The outputs from both memory interactions (`Z_scene_t` and `Z_epi_t`) are combined into a memory-augmented representation (`H_t`), which serves as the conditioning input for the action policy.

3. **Diffusion-based Action Generation**:
 - **Per-part Policy**: A per-part diffusion policy is used to model the distinct dynamics of mobile-base motion and arm manipulation. Each action subspace (base, arm) is generated by an independent denoising diffusion process.
 - **Denoiser**: For each part `p`, a denoiser `Denoiser_p` predicts the noise of a perturbed action sample (`z_t`), conditioned on the memory-augmented representation (`H_t`) and the diffusion step (`t`).
 - **Training Objective**: The training objective minimizes the denoising loss for each part, encouraging coordinated yet decoupled learning of locomotion and manipulation.

#### 3.2. MoMani Benchmark

MoMani is an automated benchmark designed for high-quality mobile manipulation data generation, incorporating both simulation and real-robot data.

1. **Simulation Data Construction (Two-Stage Pipeline)**:
 - **Stage I: Online Candidate Generation**:
 - **MLLM-guided Planning**: Task specifications are processed by a Multimodal Large Language Model (MLLM) prompter.
 - **Sequential Operations**: This involves Target-Aligned Sampling (L1), Safety-Aware Navigation (L2), and Continuous Nav-Manip Stitching (L3), supporting simultaneous base and arm execution with continuous collision detection.
 - **Hard Quality Gates**: Candidate trajectories must pass stringent quality checks (zero collisions, precise alignment within thresholds, 100% task success) to enter a feasible pool (`D_pool`).
 - **Stage II: Offline Selection & Audit**:
 - **Lexicographic Ranking**: Candidates in `D_pool` are ranked based on path length and planning cost to identify an expert-level `Top-K` set (`D_topK`).
 - **Scene-Camera Audit**: A final audit ensures the dataset is ready for training. This pipeline is capable of generating over 5,000 multimodal trajectories.

2. **Real-Robot Demonstration Collection**:
 - **Hardware**: A TidyBot++ platform is used, featuring a Kinova Gen3 7-DoF manipulator on a holonomic mobile base, equipped with front RGB-D and top-view stereo cameras.
 - **Data Collection**: A web-based teleoperation interface records multimodal data streams at 30 Hz. Trajectories are segmented into motion primitives. Successful attempts are verified via replay, while failed ones are discarded.

3. **Dataset Distribution**:
 - **Simulation Dataset**: Comprises 7,889 episodes, including a large navigation-only subset (57.0%) and various mobile manipulation tasks (e.g., PickPlaceCounterToStove, PickPlaceSinkToCounter, TurnOnSinkFaucet, TurnOnStove).
 - **Real-world Dataset**: Contains 1,200 episodes, with a balanced distribution of manipulation tasks (e.g., Open Refrigerator Door, Close Microwave, Place Cup in Sink, Rotate Knob) and a complex long-horizon task (Enter Room and Place Pears).

### 4. Main Findings and Results

The evaluation of EchoVLA was conducted in both simulation using the RoboCasa simulator and in real-world environments using the TidyBot++ platform.

#### 4.1. Simulation Results (RoboCasa)

EchoVLA was compared against several baselines, including BC-T, Diffusion Policy, DP3, WB-VIMA, and π0.5, across four core mobile manipulation tasks: PickPlaceCounterToStove (PnP C2S), PickPlaceSinkToCounter (PnP S2C), TurnOnSinkFaucet (TOF), and TurnOnStove (TOS), as well as a pure navigation task. Performance was categorized into Manipulation/Navigation and Mobile Manipulation, with Success Rate (SR) as the primary metric.

- **Overall Performance**:
 - For **Manipulation/Navigation tasks**, EchoVLA achieved an average SR of 0.52, which was a substantial improvement over π0.5 (0.32), BC-T (0.28), DP3 (0.22), WB-VIMA (0.15), and Diffusion Policy (0.01). Specifically, EchoVLA showed strong performance on PnP S2C (0.68) and TOS (0.67).
 - For **Mobile Manipulation tasks**, which involve coordinated base and arm control, EchoVLA achieved an average SR of 0.31. This also surpassed π0.5 (0.20), WB-VIMA (0.11), DP3 (0.06), and BC-T (0.05). The success rates for all methods generally decreased in mobile manipulation scenarios compared to manipulation/navigation-only tasks, indicating the increased complexity of coordinated control. EchoVLA maintained its lead in this more challenging category, with notable SRs on PnP S2C (0.34) and TOS (0.43).

- **Ablation Study**:
 - **Observation Modalities**: Removing point cloud (PC) input resulted in performance drops (e.g., SR from 0.17 to 0.08 for PnPC2S (Mobile) and from 0.21 to 0.15 for PnPC2S). Removing RGB input also led to significant degradation (e.g., SR from 0.17 to 0.02 for PnPC2S (Mobile)). This indicates the importance of both visual appearance and 3D geometric cues for accurate object localization and grasping.
 - **Memory Modules**: Disabling either Episodic Memory (EM) or Scene Memory (SM) led to performance degradation. For instance, removing EM reduced SR from 0.17 to 0.14 on PnPC2S (Mobile), and removing SM reduced SR to 0.09. This suggests that both memory components contribute to robust performance.
 - **Hyperparameter Sensitivity**: The study found optimal hyperparameters for EM window size (L=8) and SM update threshold (τ=0.5), balancing memory freshness and stability. Smaller window sizes led to "plan forgetting," while excessively large ones introduced diminishing returns. Incorrect thresholds affected representation stability and scene memory accuracy.

#### 4.2. Real Robot Experiment (TidyBot++)

EchoVLA was evaluated on six diverse real-world tasks, including opening a drawer (OD), closing a microwave (CM), placing a cup into the sink (PCIS), opening a refrigerator (OR), rotating a knob (RK), and a long-horizon task of entering a room to place pears (EnP).

- **Performance Comparison**: EchoVLA achieved a mean SR of 0.44 across the real-world tasks, outperforming π0.5 (0.33) and Diffusion Policy (0.32).
 - EchoVLA demonstrated superior robustness in tasks like CM (0.70 SR) and RK (0.50 SR), compared to baselines.
 - In the most challenging long-horizon task, EnP, EchoVLA achieved an SR of 0.10, while π0.5 achieved 0.00 and Diffusion Policy achieved 0.03.
- **Robustness to Real-World Perceptual Noise**: The improved performance of EchoVLA, particularly in long-horizon precision tasks like RK, suggests that the temporal context provided by episodic memory helps to compensate for spatial inaccuracies or "ghosting" artifacts that can occur in the scene memory due to real-world perceptual noise.
- **Failure Analysis on Dynamic Occlusion**: Despite its general robustness, EchoVLA's performance notably dropped in tasks involving dynamic occlusion, such as opening a refrigerator door (OR). The rapid changes in geometry during door opening degraded the explicit 3D scene memory. In such cases, baselines relying on implicit "muscle memory" sometimes showed more resilience to these blind spots where explicit geometry became unreliable, indicating a sensitivity of explicit 3D representations to extreme structural dynamics.

### 5. Significance and Potential Impact

The research on EchoVLA and the MoMani benchmark contributes to the field of embodied AI and robot learning in several ways:

1. **Advancement in Mobile Manipulation Capabilities**: EchoVLA addresses a limitation of many existing VLA models by enabling robust, long-horizon mobile manipulation. Its neuro-inspired synergistic memory architecture allows agents to integrate navigation and manipulation effectively under changing spatial contexts, moving beyond the short-horizon, table-top scenarios that typically characterize current VLA applications. This represents a step toward more versatile and generalist robotic systems capable of operating in complex, dynamic environments.

2. **Introduction of Biologically-Inspired Memory for Robotics**: The work demonstrates the utility of drawing inspiration from human declarative memory, specifically differentiating between persistent spatial (scene) memory and dynamic experiential (episodic) memory. This dual-memory approach, integrated through hierarchical attention, provides a structured mechanism for embodied agents to maintain consistent reasoning and task execution, which has implications for developing more intelligent and adaptable robotic policies.

3. **Development of a Comprehensive Mobile Manipulation Benchmark (MoMani)**: MoMani provides a valuable resource for the research community. By offering an automated pipeline for generating expert-level trajectories across diverse mobile manipulation tasks in both simulation and real-world settings, it addresses the scarcity of high-quality, scalable datasets for this challenging domain. The inclusion of real-robot demonstrations further helps to bridge the simulation-to-real gap, accelerating the development, training, and evaluation of future robot learning algorithms.

4. **Improved Robustness and Generalization**: The empirical results indicate that EchoVLA's memory system enhances the model's ability to handle non-Markovian decision-making and generalize across varied tasks. The explicit scene memory provides stable environmental grounding, while episodic memory contributes fine-grained temporal context, together mitigating issues like "plan forgetting" and perceptual noise, which are common challenges in long-horizon tasks.

5. **Identification of Future Research Directions**: The paper's discussion of limitations, such as the sensitivity of explicit 3D scene memory to dynamic occlusions and cumulative odometry drift in real-world deployments, highlights specific areas for future research. This includes potential integration of techniques like loop-closure or visual SLAM to improve the accuracy and robustness of spatial representations, which can lead to further advancements in memory-augmented robot control.

In summary, this work offers a memory-enhanced VLA architecture and a robust benchmarking tool that together facilitate the development of more capable and general-purpose mobile manipulators.
