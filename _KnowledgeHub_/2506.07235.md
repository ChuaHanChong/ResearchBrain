# Multi-Step Visual Reasoning with Visual Tokens Scaling and Verification

> [!summary] Summary
> Researchers develop VTS-V (Visual Token Scaling with Verification), a framework that enables multimodal language models to perform iterative visual reasoning through dynamic interaction with visual tools, achieving 6.90-point improvements on BLINK benchmark for GPT-4o and consistent gains across open-source models (4.18-7.58 points) through a Markov Decision Process formulation where a reasoner proposes visual actions from ten tool types (depth, cropping, OCR, segmentation) while a verifier trained on 301K preference pairs via direct preference optimization determines reasoning termination, supported by a novel VTS-SFT dataset of 315K tool-grounded reasoning trajectories that enables open-source models to transition from static "look once" visual encoding to adaptive "look deeper and verify" inference patterns with theoretical guarantees for bounded reasoning steps.

## Problem

- Current multimodal large language models use static visual inference, processing entire images into fixed visual tokens upfront, limiting their ability to iteratively refine understanding or adapt to visual ambiguities during reasoning
- Existing visual reasoning approaches focus primarily on scaling text tokens or using predefined visual tools in fixed pipelines, neglecting dynamic scaling of visual tokens based on reasoning context
- Available datasets lack multi-step, tool-grounded reasoning trajectories with preference labels needed to train models for dynamic visual interaction and verification

## Method

- Formulate visual reasoning as a ==Markov Decision Process== with a ==reasoner== that proposes visual actions and a ==verifier== that evaluates reasoning quality and determines termination
- Introduce ==ten diverse visual tools== (grounding, depth, zoom, visual search, crop, OCR, segmentation, captioning, similarity, overlay) that enable fine-grained visual interaction
- Create VTS-SFT dataset with **315K** verified tool-grounded reasoning trajectories and VTS-DPO dataset with **301K** preference pairs for training reasoner and verifier components respectively
- Train verifier using multi-step ==Direct Preference Optimization== to learn when reasoning should terminate based on diminishing reward differences between consecutive states

## Results

- GPT-4o with VTS-V achieves **69.15%** average accuracy on BLINK benchmark, outperforming base GPT-4o (**62.25%**), Chain-of-Thought (**64.96%**), Set-of-Mark (**60.13%**), and Visual Sketchpad (**66.78%**) approaches
- Fine-tuned open-source models show consistent improvements: Qwen2.5VL-7B increases from **49.07%** to **56.65%**, Qwen2VL-7B from **48.01%** to **52.19%**, and LLaMA3.2-11B from **47.98%** to **50.32%** on BLINK
- Ablation studies confirm verifier's critical role, with removal causing accuracy drops across all models (e.g., Qwen2.5VL drops from **54.44%** to **47.09%** without verifier)
- Generalization validated across diverse benchmarks including V*Bench, MMStar, and MathVista, with enhanced interpretability through explicit step-by-step visual evidence backing each reasoning decision

## Takeaways

> [!tip] Key Insights
> - Open-source models require supervised fine-tuning on tool-grounded trajectories before they can effectively utilize verifier signals and external visual tools, unlike closed-source models that demonstrate inherent tool-use capabilities
> - Dynamic visual token scaling enables models to focus computational resources on relevant image regions rather than uniformly processing all pixels, leading to more efficient and accurate reasoning
> - Verifier-guided termination prevents infinite reasoning loops while ensuring sufficient exploration, with theoretical guarantees that total reasoning steps form a finite stopping time under mild conditions
> - Complex compositional tasks benefit most from iterative visual reasoning, with largest improvements observed in counting, functionally-correlated, and visually-correlated reasoning categories
