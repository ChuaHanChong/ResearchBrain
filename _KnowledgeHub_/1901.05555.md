# Class-Balanced Loss Based on Effective Number of Samples

> [!summary] Summary
> A theoretically grounded re-weighting method for deep learning on imbalanced datasets, Class-Balanced Loss, calculates sample weights based on an "effective number of samples" that accounts for diminishing returns from additional data. This approach, proposed by Cui et al., consistently improves performance across various imbalanced datasets, including iNaturalist, and is applicable to any loss function and neural network architecture.

## Problem

- Deep learning models struggle with long-tailed data distributions where many "tail" classes have very few samples compared to "head" classes.
- Traditional re-sampling (oversampling/undersampling) methods can lead to overfitting or loss of valuable information.
- Existing re-weighting methods, typically using inverse class frequency, assume a linear relationship between samples and information gained, which is inaccurate for real-world data due to redundancy and overlap between samples within a class

## Method

- Introduces the =="effective number of samples" (En) framework==, which models the diminishing returns of additional samples due to data overlap, expressed as En = (1 - "beta"^n) / (1 - "beta").
- Proposes **Class-Balanced (CB) Loss**, a re-weighting scheme that assigns weights inversely proportional to the effective number of samples for each class.
- The method is loss-agnostic and model-agnostic, allowing its application to any base loss function (e.g., ==softmax cross-entropy==, ==sigmoid cross-entropy==, ==focal loss==) and neural network architecture without structural changes

## Results

- Class-Balanced Loss consistently outperforms baseline loss functions across various artificially imbalanced CIFAR datasets (imbalance factors up to **200x**) and real-world iNaturalist datasets.
- On iNaturalist, ResNet-50 with CB Focal Loss achieves performance comparable to a larger ResNet-152 with standard softmax, demonstrating efficiency gains.
- The optimal "beta" value varies by dataset, with lower "beta" (more aggressive re-weighting) performing better on fine-grained datasets like CIFAR-100, aligning with the theoretical interpretation of fewer unique prototypes for such classes

## Takeaways

> [!tip] Key Insights
> - The value of additional training samples exhibits diminishing returns due to data overlap and redundancy, rather than a linear increase in information.
> - Modeling data overlap through a simplified random covering problem provides a principled, theoretically grounded basis for re-weighting imbalanced data.
> - The hyperparameter "beta" controls the degree of diminishing returns, reflecting the inherent diversity or redundancy within a class, and can provide insights into dataset characteristics.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

#### 1.1. Overview and Problem Context

Deep learning models excel when trained on large, balanced datasets, but real-world data often exhibits severe class imbalance. This paper by Cui et al. addresses a fundamental challenge in machine learning: how to train neural networks effectively when some classes have thousands of examples while others have only a few. The authors propose a theoretically grounded approach called "Class-Balanced Loss" that redefines how we measure the value of training samples.

#### 1.2. Understanding Long-Tailed Data Distributions

Real-world datasets frequently exhibit long-tailed distributions where a small number of "head" classes contain the majority of samples, while numerous "tail" classes are severely underrepresented. This pattern appears across domains: species identification datasets like iNaturalist, medical diagnosis datasets, and web-scale image collections all demonstrate this characteristic.

The standard approach to handling class imbalance involves two main strategies:

**Re-sampling methods** modify the dataset by either oversampling minority classes (potentially causing overfitting) or undersampling majority classes (discarding valuable information). These methods directly manipulate the training data distribution.

**Re-weighting methods** assign different weights to samples during training, typically using inverse class frequency. However, this simple heuristic often performs poorly on highly imbalanced datasets because it treats all samples within a class as equally informative.

The authors identify a crucial flaw in existing re-weighting approaches: they assume a linear relationship between the number of samples and the information gained. In reality, as more samples are collected for a class, each additional sample provides diminishing marginal benefit due to redundancy and overlap with existing data.

### 2. Key Objectives and Motivation

#### 2.1. Motivation and Key Insight

Traditional approaches to class imbalance rely on heuristics like inverse class frequency weighting, but these often fail on real-world datasets. The key insight of this work is that not all data points contribute equally to learning—additional samples provide diminishing returns due to data overlap and redundancy. By quantifying this "effective number of samples," the authors create a principled framework for addressing class imbalance that can be applied to any loss function and neural network architecture.

### 3. Methodology and Approach

#### 3.1. The Effective Number of Samples Framework

The core theoretical contribution introduces the concept of "effective number of samples," which accounts for data overlap and diminishing returns. The authors model this through a simplified version of the random covering problem.

Instead of treating each data point as a single entity, the framework associates each sample with a "small neighboring region" in feature space. This region captures:
- Inherent similarities among real-world data
- Near-duplicate samples in the dataset
- Effects of data augmentation (cropping, flipping, etc.)

The effective number of samples $E_n$ for a class with $n$ observations is derived as:

$$E_n = \frac{1 - \beta^n}{1 - \beta}$$

where $\beta \in [0, 1)$ is a hyperparameter defined as $\beta = \frac{N-1}{N}$, with $N$ representing the total volume of possible unique data for that class.

The parameter $\beta$ provides intuitive control:
- When $\beta = 0$ (N=1): All samples are essentially duplicates, so $E_n = 1$
- As $\beta \to 1$ (N→∞): Every sample is unique, so $E_n \to n$
- Intermediate values smoothly interpolate between these extremes

#### 3.2. Class-Balanced Loss Design

Based on the effective number framework, the authors design a re-weighting scheme that assigns weights inversely proportional to the effective number of samples. For a sample from class $y$ with $n_y$ training examples, the weighting factor is:

$$\alpha_y = \frac{1-\beta}{1-\beta^{n_y}}$$

The Class-Balanced (CB) loss takes the general form:

$$CB(p, y) = \frac{1-\beta}{1-\beta^{n_y}} L(p, y)$$

where $L(p,y)$ is any base loss function and $p$ represents the model's predicted probabilities.

This approach is both **loss-agnostic** and **model-agnostic**—it can be applied to any existing loss function (softmax cross-entropy, sigmoid cross-entropy, focal loss) and any neural network architecture without requiring structural changes.

The authors demonstrate applications to three common loss functions:

**Class-Balanced Softmax Cross-Entropy**: Standard multi-class classification assuming mutual exclusivity between classes.

**Class-Balanced Sigmoid Cross-Entropy**: Treats multi-class problems as multiple binary classifications, suitable when classes aren't mutually exclusive.

**Class-Balanced Focal Loss**: Combines the effective number re-weighting with Focal Loss's emphasis on hard examples, showing these approaches are complementary rather than competing.

### 4. Main Findings and Results

#### 4.1. Experimental Validation

The experimental evaluation spans both controlled synthetic datasets and challenging real-world scenarios:

**Synthetic Long-Tailed Datasets**: CIFAR-10 and CIFAR-100 were artificially imbalanced with exponential reduction in samples per class, creating imbalance factors from 10× to 200×.

**Real-World Long-Tailed Datasets**: iNaturalist 2017/2018 datasets provide natural species classification with extreme class imbalance—some species have thousands of images while others have fewer than 10.

**Standard Benchmarks**: ILSVRC 2012 (ImageNet) tests generalization beyond extreme imbalance scenarios.

The experimental methodology includes careful hyperparameter search for $\beta$ values (0.9, 0.99, 0.999, 0.9999) and comparison across multiple network architectures (ResNet-32, ResNet-50, ResNet-101, ResNet-152).

#### 4.2. Results and Performance

The experimental results demonstrate consistent improvements across datasets and loss functions:

**Key Findings**:

1. **Consistent Improvements**: CB loss variants outperform their baseline counterparts across all tested scenarios, with particularly strong gains on highly imbalanced datasets.

2. **Dataset-Dependent Optimal β**:
 - CIFAR-10 (coarse-grained): Higher β values work better
 - CIFAR-100 (fine-grained): Lower β values are optimal
 - This aligns with the theoretical interpretation that fine-grained classes have fewer unique prototypes

4. **Large-Scale Performance**: On iNaturalist datasets, ResNet-50 with CB Focal Loss achieved performance comparable to much larger ResNet-152 models with standard softmax, demonstrating efficiency gains.

The comprehensive heat maps show performance across different imbalance factors and β values, revealing that the method provides robust improvements across a wide range of conditions.

### 5. Significance and Potential Impact

#### 5.1. Significance and Applications

This work makes several important contributions to the field:

**Theoretical Foundation**: The effective number of samples framework provides the first principled theoretical basis for re-weighting in imbalanced learning, moving beyond empirical heuristics to a mathematically grounded approach.

**Universal Applicability**: The loss-agnostic and model-agnostic design enables seamless integration with existing deep learning pipelines without requiring architectural changes or complex training procedures.

**Practical Impact**: Demonstrated effectiveness on both controlled synthetic datasets and challenging real-world scenarios like iNaturalist shows immediate practical value for applications dealing with imbalanced data.

**Complementary Approach**: The framework complements rather than replaces existing techniques like Focal Loss, opening possibilities for combining multiple principled approaches.

**Data Understanding**: The β parameter provides insight into dataset characteristics, with optimal values reflecting the degree of within-class diversity—a useful tool for dataset analysis and characterization.

The work addresses a pervasive challenge in machine learning where traditional approaches often fail. By providing a theoretically sound, empirically validated, and broadly applicable solution, it establishes a new foundation for handling long-tailed distributions in deep learning. The method's simplicity and effectiveness make it particularly valuable for practitioners working with real-world datasets where perfect class balance is rarely achievable.
