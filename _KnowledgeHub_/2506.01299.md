# Scalable In-Context Q-Learning

> [!summary] Summary
> Scalable In-Context Q-Learning (S-ICQL) introduces a framework for in-context reinforcement learning that combines world modeling for precise prompt construction with dynamic programming-based Q-learning. This approach enables agents to learn optimal policies from suboptimal data and generalize effectively to novel tasks, consistently outperforming existing ICRL baselines across various continuous and discrete environments.

## Problem

- Existing in-context reinforcement learning (ICRL) methods struggle to learn optimal policies when relying on suboptimal datasets, often limited to imitating collected data.
- Current ICRL prompts, frequently composed of verbose and redundant raw transitions, can hinder efficient and precise in-context task inference.
- Integrating robust reinforcement learning principles like dynamic programming into ICRL frameworks while maintaining scalability and training stability is challenging.

## Method

- A ==multi-head transformer== architecture is employed to simultaneously predict in-context policies, state value functions, and action-value functions, leveraging parameter sharing.
- A generalized world model is pretrained to infer compact, task-relevant representations from experience, which are then used to construct lightweight and precise prompts.
- In-context Q-learning integrates dynamic programming through expectile regression for state values and advantage-weighted regression for policies, enabling learning from suboptimal data.

## Results

- S-ICQL consistently achieved superior data efficiency and higher asymptotic performance compared to six ICRL baselines across diverse MuJoCo, DarkRoom, and Meta-World environments.
- The framework demonstrated a genuine "stitching" capability, learning policies that surpassed the best returns observed within suboptimal offline datasets.
- S-ICQL showed robust generalization to out-of-distribution tasks and maintained superior performance even with suboptimal ("Medium" quality) datasets, attributed to its world modeling and Q-learning components.

## Takeaways

> [!tip] Key Insights
> - Integrating dynamic programming principles, specifically Q-learning, into an in-context learning framework allows agents to "stitch" optimal behaviors from suboptimal trajectories, learning beyond the quality of the offline data.
> - Abstracting environment dynamics into compact, semantically rich task representations via a pretrained world model provides efficient and precise contextual cues for in-context adaptation.
> - A unified multi-head transformer architecture can jointly optimize in-context policies and value functions in a scalable and stable manner, leveraging the benefits of supervised pretraining and value-based updates.
