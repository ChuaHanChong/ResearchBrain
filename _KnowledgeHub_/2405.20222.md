# MOFA-Video: Controllable Image Animation via Generative Motion Field Adaptions in Frozen Image-to-Video Diffusion Model

> [!summary] Summary
> Researchers at The University of Tokyo and Tencent AI Lab developed MOFA-Video, a framework that integrates Generative Motion Field Adapters into a frozen Image-to-Video diffusion model to enable precise animation. This method achieves superior control precision and visual quality for diverse image animation tasks, supporting controlled motion via trajectories, facial landmarks, or reference videos, and allows for longer, temporally consistent video generation.

## Problem

- Existing domain-specific image animation methods offer high control but lack generalizability to diverse, "in-the-wild" images.
- Open-domain Image-to-Video (I2V) diffusion models generalize well but often produce content that deviates from the input image, offer weak motion control, or generate only simple idle animations.
- There was a need for a unified framework that combines open-domain generalizability with precise, fine-grained control using various external signals like trajectories or key-points.

## Method

- Introduced Generative Motion Field Adapters (MOFA-Adapters) as an additional network branch to condition a frozen, pre-trained Stable Video Diffusion (SVD) model, allowing for diverse motion control.
- MOFA-Adapters utilize a Sparse-to-Dense (S2D) Motion Generator to convert sparse motion hints (from ==optical flow== or human key-points) into dense motion fields for explicit frame-wise motion modeling.
- Implemented a training strategy that optimizes only the MOFA-Adapter parameters while keeping the base SVD model frozen, efficiently leveraging its generative priors.

## Results

- Achieved superior control precision and visual quality for trajectory-based image animation, demonstrating improved LPIPS (0.2274 vs. 0.2705 for DragNUWA) and higher Control Precision in user studies (3.58 vs. 2.76).
- Demonstrated enhanced performance for portrait image animation, producing more natural expressions and higher resolution results (e.g., CPBD 0.4075 vs. 0.3218 for SadTalker, ID 0.9293 vs. 0.9188).
- Successfully enabled the generation of longer, temporally coherent videos and supported zero-shot combination of multiple control signals (e.g., facial landmarks and trajectories) using a mask-aware approach.

## Takeaways

> [!tip] Key Insights
> - Explicitly modeling frame-wise motion through generative motion field adapters is crucial for achieving fine-grained, domain-aware control within a frozen I2V diffusion model.
> - Converting sparse motion hints into dense motion fields allows for a balanced integration of precise control signals with the generative capabilities of the base video diffusion model.
> - A periodic sampling strategy with overlapping frames and noise averaging effectively mitigates error accumulation and flickering, enabling the generation of longer, temporally consistent video sequences.
