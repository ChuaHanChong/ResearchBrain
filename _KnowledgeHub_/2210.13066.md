# DaXBench: Benchmarking Deformable Object Manipulation with Differentiable Physics

> [!summary] Summary
> Researchers from the National University of Singapore and Sea AI Lab developed DaXBench, a differentiable simulation framework using JAX for deformable object manipulation across liquid, rope, and cloth. This benchmark evaluates planning, imitation learning, and reinforcement learning algorithms, showing differentiable physics benefits long-horizon, low-level control tasks and enables sim-to-real transfer with a Kinova Gen 3 robot.

## Problem

- Deformable object manipulation (DOM) presents significant challenges in robotics due to high-dimensional state/action spaces and complex, non-linear dynamics.
- Existing DOM simulators and benchmarks often lack differentiability, specialize in a single type of deformable object, or offer insufficient support for diverse manipulation tasks and algorithms.
- While differentiable physics shows promise for DOM control policies, current differentiable simulators are typically limited to modeling only one type of deformable material.

## Method

- Introduced DaXBench, a general-purpose differentiable simulation framework built on JAX, which supports diverse deformable objects including liquid, rope, cloth, and elasto-plastic materials.
- Integrated memory and efficiency optimizations, such as Lazy Dynamic Update and Checkpointing, into the custom DaX simulator to manage the computational demands of long-horizon differentiable physics tasks.
- Provided a comprehensive set of DOM tasks wrapped with the OpenAI Gym API, including novel long-horizon and low-level control tasks, for benchmarking various algorithmic paradigms.

## Results

- Differentiable Reinforcement Learning (APG) outperformed PPO on long-horizon, low-level control tasks (e.g., "Whip-Rope"), while PPO showed better performance on macro-action tasks.
- Imitation Learning via Differentiable physics (ILD) achieved superior performance with substantially fewer expert demonstrations compared to non-differentiable Transporter for macro-action tasks.
- Differentiable planning (diff-CEM-MPC) consistently matched or exceeded CEM-MPC, but its success was highly reliant on good initialization, with randomly initialized diff-MPC largely failing.
- Real-world experiments validated DaX's simulated dynamics, enabling a Kinova Gen 3 robot to successfully plan and execute a "Push-Rope" task, with observed trajectories aligning with simulation predictions.

## Takeaways

> [!tip] Key Insights
> - Differentiable physics significantly enhances DOM methods, particularly for tasks requiring long-horizon, low-level controls, and improves imitation learning with fewer expert demonstrations.
> - The effectiveness of differentiable methods is context-dependent: they can struggle with exploration in macro-action tasks but improve planning when provided with good initialization.
> - DaXBench demonstrated successful sim-to-real transfer for deformable object manipulation, evidenced by a Kinova Gen 3 robot executing a rope pushing task with dynamics fidelity similar to simulation.
