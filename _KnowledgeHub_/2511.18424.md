# CrossJEPA: Cross-Modal Joint-Embedding Predictive Architecture for Efficient 3D Representation Learning from 2D Images

> [!summary] Summary
> CrossJEPA introduces a mask-free Joint-embedding Predictive Architecture for efficient 3D representation learning, leveraging a frozen 2D image foundation model to guide a 3D point cloud encoder. It achieves 94.2% accuracy on ModelNet40 and 88.3% on ScanObjectNN using only 14.1M parameters and approximately 6 pretraining GPU hours.

## Problem

- Existing 3D self-supervised learning methods suffer from 3D data scarcity, computational expense, and large model sizes, hindering deployment on resource-constrained devices.
- The full potential of Joint-embedding Predictive Architectures (JEPA) remains largely unexplored in cross-modal 2D-to-3D learning, partly due to the misconception that masking is a core requirement.
- Current cross-modal approaches are computationally heavy (e.g., reconstruction-based methods) or prone to collapse (e.g., contrastive learning with learnable teachers), making knowledge transfer from 2D inefficient.

## Method

- Developed a ==cross-modal== JEPA that distills knowledge from a frozen 2D image foundation model (teacher) to a learnable 3D point cloud encoder (student) using a lightweight predictor.
- Introduced a 'latent view prediction task' where the predictor infers target 2D image embeddings from 3D features, explicitly conditioned on image-specific latent information like camera pose and color histogram.
- Achieved significant efficiency by freezing the 2D image encoder and precomputing/caching all target image embeddings, drastically reducing learnable parameters and on-the-fly computation.

## Results

- Achieved a new state-of-the-art accuracy of **94.2%** on ModelNet40 and **88.3%** on ScanObjectNN for linear probing, surpassing prior unimodal and cross-modal methods.
- Demonstrated unprecedented pretraining efficiency, requiring only **14.1M** parameters and approximately 6 GPU hours, significantly less than other methods (e.g., Point-JEPA: **46.0M** parameters, ~21 hours).
- Outperformed all prior work across various few-shot learning settings on ModelNet40 (e.g., **97.8%** for 5-way 10-shot), indicating superior generalization from limited labeled data.

## Takeaways

> [!tip] Key Insights
> - JEPA's predictive principle can be effectively applied in a cross-modal setting without relying on input masking, which can even be detrimental in 2D-to-3D knowledge transfer.
> - Explicitly conditioning the predictor with modality-specific nuisance factors (e.g., camera pose) purifies the supervision signal for the point encoder, enabling it to focus on shared semantic features and accelerate convergence.
> - Pre-caching teacher embeddings is a crucial optimization for cross-modal JEPA, transforming it into a highly efficient and practically viable pretraining framework by amortizing the teacher's computational cost.
