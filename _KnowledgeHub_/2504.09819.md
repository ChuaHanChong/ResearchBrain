# Density-based Object Detection in Crowded Scenes

> [!summary] Summary
> This paper from the City University of Hong Kong presents a unified framework for object detection in crowded scenes that incorporates object density information into both the training and inference processes. The approach improves anchor assignment using an unbalanced optimal transport framework and enhances post-processing with density-guided non-maximum suppression, leading to gains of up to 4.2% AP on the CrowdHuman dataset.

## Problem

- Heavy occlusion among objects in crowded scenes makes accurate feature extraction difficult.
- Traditional anchor assignment strategies struggle to correctly associate anchors with ground truth objects when significant overlap occurs.
- Standard Non-Maximum Suppression (NMS) often suppresses legitimate detections in crowded areas by misclassifying them as duplicates.

## Method

- Introduces ==Density-Guided Anchors (DGA)== which use a predicted multi-level density map to guide anchor assignment during training.
- Develops an ==Unbalanced Optimal Transport (UOT)== framework for anchor assignment, treating it as a mass distribution problem to dynamically select positive anchors.
- Proposes ==Density-Guided NMS (DG-NMS)== that adaptively adjusts the suppression threshold based on the predicted density, preserving detections in crowded regions.

## Results

- Achieved **91.2%** AP with an FCOS backbone on the CrowdHuman dataset, representing a **3.5%** improvement over the baseline.
- Showed consistent performance gains on the CityPersons dataset, confirming effectiveness across different crowding levels.
- Ablation studies validated the individual contributions of the Unbalanced Optimal Transport framework, the overlap-aware transport cost, and Density-Guided NMS.

## Takeaways

> [!tip] Key Insights
> - Object density information can be effectively leveraged during both training (anchor assignment) and inference (NMS) to improve detection in crowded scenes.
> - Formulating anchor assignment as an Unbalanced Optimal Transport problem allows for dynamic and context-aware positive anchor selection, especially for overlapping objects.
> - An overlap-aware transport cost function helps distinguish an anchor's relevance to its target object amidst nearby overlapping objects.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Object detection in crowded scenes presents unique challenges that traditional detection methods struggle to address effectively. In crowded environments, objects frequently overlap and occlude one another, making it difficult to maintain accurate detections. The paper "Density-based Object Detection in Crowded Scenes" by Zhao, Wan, and Chan from the City University of Hong Kong introduces innovative techniques to overcome these challenges.

#### 1.1. Challenges in Crowded Scene Detection

Object detection in crowded scenes faces three principal challenges:

1. **Heavy Occlusion**: Objects frequently overlap, making feature extraction difficult and reducing detection reliability.
2. **Ambiguous Anchor Assignment**: When objects overlap significantly, traditional anchor assignment strategies struggle to properly associate anchors with the correct ground truth objects.
3. **Post-processing Issues**: Standard Non-Maximum Suppression (NMS) can mistakenly suppress correct detections in crowded regions by treating them as duplicate predictions.

Previous solutions have attempted to address these challenges through occlusion-aware methods, loss function modifications, or advanced NMS techniques. However, these approaches often treat symptoms rather than addressing the core issue of ambiguous anchor assignments during training, which this paper specifically targets.

### 2. Key Objectives and Motivation

The research proposes a unified framework that utilizes object density information to improve both the training process (through better anchor assignment) and the inference process (through an adaptive non-maximum suppression technique). Unlike previous approaches that focus primarily on visible regions or loss function modifications, this work directly addresses the fundamental issue of ambiguous anchor assignments in crowded scenes.

### 3. Methodology and Approach

#### 3.1. Density-Guided Anchors

The cornerstone of the proposed approach is the Density-Guided Anchors (DGA) mechanism. This technique introduces a multi-level density map that represents anchor confidence throughout the image. The density map provides crucial information about where objects are likely to be detected reliably, even in crowded scenarios.

The density map serves two key purposes:
1. It guides the anchor assignment process during training
2. It informs the NMS threshold selection during inference

Rather than using fixed strategies, the density map enables dynamic, context-aware decisions that adapt to the specific crowding conditions of each image region. This adaptive approach significantly improves detection performance in areas where objects heavily overlap.

#### 3.2. Unbalanced Optimal Transport Framework

To effectively utilize the density map concept, the authors introduce an Unbalanced Optimal Transport (UOT) framework for anchor assignment. Traditional object detection methods typically assign anchors to ground truth objects based on fixed rules (e.g., IoU thresholds). However, these approaches often struggle with overlapping objects.

The UOT framework mathematically formulates anchor assignment as a transport problem. Each ground truth object has a certain "mass" (the sum of density values) that needs to be distributed among potential anchor locations. This distribution is determined by minimizing a transport cost while respecting certain constraints.

The UOT loss function combines three components:
1. **Transport Loss**: Ensures optimal assignment of density values
2. **Object-wise Loss**: Maintains the appropriate total mass for each object
3. **Anchor-wise Loss**: Constrains the total density assigned to each anchor

Mathematically, the UOT loss can be expressed as:

$$\mathcal{L}_{UOT} = \sum_{i,j} \pi_{ij} C_{ij} + \lambda_{obj} \sum_i KL(\sum_j \pi_{ij} || r_i) + \lambda_{anc} \sum_j KL(\sum_i \pi_{ij} || c_j)$$

Where $\pi_{ij}$ represents the transport plan, $C_{ij}$ is the transport cost, and the KL terms enforce constraints on object and anchor density sums.

This framework naturally handles ambiguous cases by dynamically adjusting the number of positive anchors per object based on the density distribution. Objects in crowded regions may have fewer reliable anchors, while isolated objects can utilize more anchors.

#### 3.3. Overlap-Aware Transport Cost

A key innovation in the paper is the design of an overlap-aware transport cost function. This cost determines how effectively an anchor can represent a particular ground truth object.

The overlap-aware cost considers not only the IoU between an anchor and its target ground truth box but also how distinctively that anchor represents the target compared to other nearby objects. This is accomplished through a formula that incorporates both the IoU with the target and the "distinctiveness" relative to other ground truth objects:

$$C_{ij}^{tou} = (1 - \phi_{ij}) \times (bce(\phi_{ij}, 1) + (1 - \psi_{ij}) \times bce(\phi_{ji'}, 0))$$

Where:
- $\phi_{ij}$ is the IoU between anchor $j$ and ground truth $i$
- $\psi_{ij}$ represents the overlap between ground truth objects
- $bce$ is the binary cross-entropy function

This cost function penalizes anchors that cannot clearly distinguish between overlapping objects, leading to more reliable positive anchor assignments in crowded regions.

#### 3.4. Density-Guided NMS

Beyond improving the training process, the authors also enhance the inference stage through Density-Guided NMS (DG-NMS). Traditional NMS uses a fixed threshold to suppress duplicate detections, which can be problematic in crowded scenes where legitimate detections may be incorrectly suppressed.

DG-NMS adapts the suppression threshold based on the predicted density map:

1. In high-density (crowded) regions, the NMS threshold is increased to preserve legitimate detections
2. In low-density regions, the threshold is decreased to eliminate false positives more aggressively

The adaptive threshold is calculated as:

$$th_{nms} = th_{base} + \alpha \cdot D(b)$$

Where $D(b)$ is the density value for box $b$, $th_{base}$ is the base threshold, and $\alpha$ is a scaling factor.

Additionally, DG-NMS implements a density reduction mechanism that decreases the density values of nearby predictions after selecting a box for the final set. This further refines the suppression process by considering the changing context as detections are iteratively selected.

#### 3.5. Implementation and Training

The proposed approach is framework-agnostic and can be integrated into various object detection architectures. In their implementation, the authors incorporate DGA and DG-NMS into popular detection frameworks including FCOS, RetinaNet, and FPN.

The density map prediction is implemented as an additional branch in the detection network, sharing features with the existing classification and regression branches. This multi-task learning approach allows the network to jointly learn object detection and density estimation, with the density information enhancing both training and inference phases.

The entire system is trained end-to-end using a combined loss function:

$$\mathcal{L} = \mathcal{L}_{det} + \lambda \mathcal{L}_{UOT}$$

Where $\mathcal{L}_{det}$ is the standard detection loss (classification and regression components) and $\mathcal{L}_{UOT}$ is the unbalanced optimal transport loss for density map prediction.

### 4. Main Findings and Results

The proposed approach was extensively evaluated on two challenging crowded scene datasets: CrowdHuman (heavily crowded) and CityPersons (moderately crowded). The results demonstrate consistent and significant improvements across different detection backbones.

On the CrowdHuman dataset, the density-guided approach achieves:
- 91.2% AP with FCOS backbone (+3.5% over baseline)
- 92.0% AP with RetinaNet backbone (+4.2% over baseline)
- 90.9% AP with FPN backbone (+3.3% over baseline)

Similar improvements were observed on the CityPersons dataset, confirming the approach's effectiveness in varying crowding conditions.

Ablation studies verified the contributions of different components:
1. The UOT framework outperforms traditional anchor assignment strategies
2. The overlap-aware transport cost yields better results than standard IoU-based costs
3. DG-NMS provides further improvements over standard NMS techniques

The results confirm that the density-guided approach effectively addresses the main challenges of crowded scene detection, particularly the ambiguous anchor assignment issue.

### 5. Significance and Potential Impact

#### 5.1. Limitations and Future Work

Despite its effectiveness, the approach has certain limitations:

1. **Computational Overhead**: Adding the density prediction branch increases computational requirements, though the overhead is relatively modest (approximately 5-10% additional parameters).

2. **Hyperparameter Sensitivity**: The balance between different loss components requires careful tuning, particularly the weights in the UOT loss function.

3. **Domain Generalization**: While the approach shows consistent improvements across datasets, its effectiveness in extreme crowding conditions or specialized domains (e.g., aerial imagery) remains to be fully explored.

Future work could extend the density-guided concept to other vision tasks beyond object detection, such as instance segmentation or tracking in crowded scenes. Additionally, exploring more efficient implementations or self-adaptive parameter selection could further enhance the approach's practical applicability.

#### 5.2. Conclusion

The paper presents a novel density-guided approach to object detection in crowded scenes that addresses fundamental challenges in this domain. By introducing density information to guide both anchor assignment during training and NMS during inference, the method achieves substantial improvements over traditional detection approaches.

The key contributions include:

1. A unified framework for density-guided object detection that enhances both training and inference
2. An unbalanced optimal transport formulation for anchor assignment that naturally handles ambiguous cases
3. An overlap-aware transport cost that improves anchor assignment in crowded regions
4. A density-guided NMS technique that adaptively adjusts suppression thresholds based on predicted density

These innovations collectively enable more accurate and reliable object detection in crowded environments, with applications ranging from pedestrian detection and crowd analysis to autonomous driving and surveillance systems. The approach's consistent performance improvements across different detection frameworks and datasets demonstrate its broad applicability and effectiveness in addressing this challenging computer vision task.
