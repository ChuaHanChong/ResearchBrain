# ScoreFlow: Mastering LLM Agent Workflows via Score-based Preference Optimization

> [!summary] Summary
> ScoreFlow automates LLM multi-agent workflow design by training a small open-source generator to write a task-specific Python workflow for each input problem. Optimization uses Score-DPO, a preference-optimization variant that weights pairs and rewards by quantitative evaluation scores. It averages 85.3% across six benchmarks, 8.2% above the best baseline, and lets smaller executors beat larger ones at lower cost.

## Problem

- Prior workflow optimizers restrict the search space through rigid representations, such as graphs that lose conditional states, or through fixed communication structures like DyLAN's debate topology.
- Code-based methods still struggle: ADAS accumulates irrelevant data through coarse workflow storage, while AFlow's tree search converges prematurely on structures and relies on discrete, LLM-driven refinement that scales poorly.
- Existing methods optimize one static workflow for an entire task set, so they cannot adapt to diverse problems, and they depend on costly API calls for workflow generation.

## Method

- ==Adaptive generation==: an open-source LLM generator (Llama-3.1-8B) reads each task plus an ==operator guidance prompt== and writes a ==per-problem Python workflow==, choosing operators and structural complexity.
- ==Quantitative preference labeling==: k=8 workflows are sampled per task, executed by a third-party ==executor LLM==, scored in [0,1], and paired by score to build the preference dataset.
- **Score-DPO**: pairs with larger ==score gaps== are up-weighted in sampling, and ==implicit rewards== are scaled by the scores inside the ==Bradley-Terry loss==, with a theorem that per-sample influence rises with score.

## Results

- Across six benchmarks with a GPT-4o-mini executor, ScoreFlow averages **85.3%** versus AFlow's **80.6%**, ADAS's **76.6%**, and chain-of-thought's **76.7%**, and it wins on every dataset, for example MATH **64.4** versus **55.8**.
- Within the same pipeline, Score-DPO beats SFT, PPO and DPO on every test set: MATH **64.4** versus **60.4** for DPO, and GSM8K **94.6** versus **91.7**.
- On HumanEval, ScoreFlow with GPT-4o-mini reaches **95.7%**, above GPT-4o chain-of-thought at **93.4%**, at lower API cost. Optimization is also cheaper than AFlow's, and gains converge by the second iteration.

## Takeaways

> [!tip] Key Insights
> - Replacing discrete LLM-driven search with gradient-based fine-tuning of a generator scales better, because optimization pressure is applied across the whole task distribution rather than to one workflow.
> - Conditioning workflow generation on the input task matters, since simple problems suffer from overly complex workflows while hard ones need review and program operators.
> - When evaluator scores are noisy, use their magnitudes, not just pairwise order: weighting by score gap makes preference learning more robust and faster to converge.

## Detailed Report

### 1. Research Landscape Context

This work addresses key challenges in the emerging field of LLM-based multi-agent systems:
- Builds on recent work showing LLMs' capabilities in complex problem-solving through multi-agent workflows
- Addresses limitations of existing workflow optimization approaches like DyLAN, GPTSwarm, AFlow and ADAS
- Advances the field by introducing more flexible and scalable optimization techniques
- Contributes to the growing body of work on preference optimization methods for LLMs

### 2. Key Objectives and Motivation

Primary goals:
- Develop a more flexible and efficient framework for optimizing LLM agent workflows
- Address limitations of existing methods including:
 - Inflexible workflow representations
 - Poor scalability of discrete optimization techniques
 - Limited adaptability to diverse tasks
- Create a cost-effective solution using open-source LLMs

### 3. Methodology and Approach

Core components:
- Code-based workflow representation for maximum flexibility
- Novel Score-DPO optimization method incorporating quantitative feedback
- Adaptive workflow generation based on task characteristics
- Efficient gradient-based optimization in continuous space

Implementation:
- Utilizes open-source LLMs as base models
- Iterative optimization process with evaluation feedback
- Integration of evaluation scores into preference optimization

### 4. Main Findings and Results

Key results:
- 8.2% average improvement over baseline methods across six benchmarks
- Successful optimization across diverse tasks (QA, coding, math reasoning)
- Smaller models outperforming larger ones with lower inference costs
- Demonstrated scalability and adaptability to varied problem types

### 5. Significance and Potential Impact

The work advances the field by:
- Providing a more efficient and flexible framework for LLM workflow optimization
- Introducing a novel preference optimization method (Score-DPO)
- Demonstrating cost-effective performance improvements
- Enabling smaller models to achieve competitive performance

The research has potential applications in:
- Automated reasoning systems
- Code generation
- Complex problem-solving
- Question-answering systems

This work represents a significant step forward in making LLM-based multi-agent systems more practical and efficient while reducing computational costs and manual intervention requirements.
