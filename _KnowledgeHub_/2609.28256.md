# MemBodied: Recurrent Associative Memory for Vision-Language-Action Models

> [!summary] Summary
> MemBodied adds a fixed-size episodic memory to vision-language-action policies: layer-wise associative matrices updated by a gated delta rule that writes each executed action together with its observed visual consequence, plus an episode anchor preserving a pooled view of the first frame. Readouts condition a memory token inside the action expert, lifting mean RMBench success to 50.0% against 6.4% for a stateless policy.

## Problem

- Most VLA policies condition only on the current observation and instruction, discarding episode history, so visually identical states demand different actions the policy cannot disambiguate.
- Keeping raw past frames in context grows context length, memory and latency across an episode, while fixed windows silently drop evidence that falls outside them.
- Compressed-history methods still enlarge the policy context, recurrent-token methods expose information only implicitly, and memory-bank or language-scratchpad schemes add retrieval pipelines and auxiliary objectives.

## Method

- ==Associative state==: one r-by-r matrix per action-network layer (r=128), updated by a ==gated delta-rule== write whose retention and write gates revise existing key-value associations instead of accumulating them.
- Transition-conditioned write value: state-queried pooling of the post-execution frame is concatenated with the summed action chunk, so a delayed-write schedule stores each action with its visual consequence.
- ==Episode anchor== plus ==memory-token injection==: first-frame patches pooled from 16x16 to 4x4 are read by rank-64 cross-attention, and each layer readout is gated into a dedicated suffix token before self-attention.

## Results

- On five memory-dependent RMBench tasks MemBodied reached **50.0%** mean success versus **6.4%** stateless, **16.8%** vanilla recurrent memory and **38.4%** NativeMEM.
- Against NativeMEM it cut inference latency **91.9%** (**129 ms** versus **1594 ms**) and added **40M** parameters versus **415M**; real-robot success rose from **3.33%** to **26.67%**.
- Ablations: removing the anchor drops mean success from **50.0%** to **37.6%**; combined vision-plus-action write values beat vision-only, **46.7%** versus **42.7%**; LIBERO-Long hit **90.6%** versus **85.2%**.

## Takeaways

> [!tip] Key Insights
> - Fixed-size associative state can replace growing observation context, keeping memory cost independent of episode length; recurrence alone is insufficient without a well-formed write rule.
> - How memory is exposed matters more than that it exists: injecting readouts as contextual tokens beat attention steering and hierarchical gating by large margins.
> - Delta-rule states overwrite early detail, so pair them with a persistent anchor; anchors can still hurt tasks that track evolving progress rather than recall the initial scene.

## Detailed Report

### 1. Overview

A robot performing a multi-step manipulation job may need information that is no longer visible when it chooses its next action. Two common workarounds have costs. Keeping complete history in the input can make context length and inference cost grow. A fixed observation window can lose evidence that matters later. MemBodied, the authors' approach, carries a compact episode memory between policy calls rather than appending every past observation to the policy's input. The memory has two parts: a small record of interactions and a reference to the starting scene. The authors tested this approach on five history-dependent manipulation tasks and report higher average task success than a stateless policy.

### 2. A fixed memory, updated after the outcome

MemBodied combines an evolving record of interactions with a fixed reference to the episode's opening scene. At each policy call, several inputs inform an action chunk: the current observation, the robot state, the instruction, and the previous associative state.

The associative state comprises one fixed-size matrix per action-network layer, with rank 128 in the experiments. The current state queries these matrices. A learned gate controls how the retrieved information enters a dedicated memory token, which participates in self-attention. This token is recreated for each call, and the matrices carry the recurrent information between calls.

The episode anchor stores a compact reference to the first scene. For each camera, frozen visual patch tokens are average-pooled from a 16×16 grid to a 4×4 grid. The current observation queries that unchanged anchor to condition the action tokens.

Memory is used and updated on a causal schedule:

1. The policy reads existing memory.
1. It generates and executes the action.
1. It receives the next observation.
1. It writes the action together with its observed visual consequence.

A gated delta update retains existing state while correcting the association, and the future observation is not available to the action that caused it. Memory parameters are learned through sequence-level action prediction, without a separate memory-prediction loss.

The proposed mechanism, with one layer shown. The current state queries the old matrix, and the readout enters a memory token for self-attention. The current scene queries an anchor built from pooled first-observation patches. After execution, the action and its observed consequence feed the write to a fixed $r \times r$ state initialized at episode start.

### 3. The gains concentrate at history-dependent decisions

The test setting is RMBench, a bimanual manipulation benchmark. The paper evaluates five of its tasks, not all nine. Three tasks require information from one earlier event: Put Back Block, Rearrange Blocks, and Swap Blocks. Two require information across multiple earlier events: Battery Try and Block Ranking Try. Each task receives 50 rollouts.

The headline metric is the unweighted mean task success rate: the arithmetic average of the five task success percentages, each given equal weight. On this metric, MemBodied reached 50.0%, versus 6.4% for the π₀ stateless baseline, which the authors report as 7.81× the mean. It also exceeded the π₀ vanilla recurrent-memory baseline, which scored 16.8%. These results support the claim that memory helps on the tested history-dependent tasks, not that it solves them, since the aggregate still corresponds to only 50% mean success. The comparisons also do not isolate one architectural feature as the sole cause.

An ablation tests the anchor directly. The anchor-free memory-token variant has 37.6% mean success. Adding the anchor raises this to 50.0% and improves four of five tasks. The exception is Block Ranking, which falls from 32% to 22%. This supports complementarity between the anchor and evolving interaction memory, not a universal benefit. The authors suggest that a first-scene reference may be less useful when tracking evolving progress matters more.

Combined content is highest on these three tasks, with three-task means of 46.7%, 42.7%, and 34.7%.

### 4. What the result establishes

A fixed-size state can preserve information across calls without keeping the full history in the policy context. On the tested RMBench tasks, this raised mean success well above the stateless and vanilla recurrent baselines. The compression has limits, however. Fixed capacity means capacity does not grow with episode length at a fixed configuration. It does not mean unlimited recall, perfect memory, or zero inference cost. The memory must choose what to retain. Anchor benefits are task-dependent, and the authors report remaining execution and longer-term tracking failures.
