# ARC-AGI Without Pretraining

> [!summary] Summary
> CompressARC, developed by researchers at Carnegie Mellon University, addresses the ARC-AGI benchmark by achieving 20% accuracy on evaluation puzzles without any pretraining, learning entirely at inference time from the target puzzle. It leverages a custom equivariant neural network and the Minimum Description Length principle to discover abstract reasoning patterns with extreme data efficiency.

## Problem

- The ARC-AGI benchmark poses a challenge for abstract visual reasoning, requiring rapid skill acquisition and generalization from minimal input-output examples.
- Prevailing state-of-the-art methods, particularly those based on Large Language Models, heavily rely on massive pretraining data and extensive computational resources.
- Directly applying information-theoretic principles like Minimum Description Length (MDL) for program discovery is computationally intractable.

## Method

- CompressARC reframes ARC-AGI as a "code-golfing" problem, aiming to find the shortest self-contained program capable of generating a given puzzle, guided by the ==Minimum Description Length (MDL) principle==.
- It employs an ==inference-time learning== approach for each individual puzzle, approximating MDL optimization using a differentiable loss function composed of KL divergence (for seed length) and cross-entropy (for reconstruction error).
- A custom, parameter-efficient (**76K** parameters) neural network architecture is utilized, featuring strong ==inductive biases== such as equivariance to permutations, rotations, and flips, and processing information across "multitensors" of varying ranks.

## Results

- The model correctly solved **20%** of evaluation set puzzles and **34.75%** of training set puzzles (with 2 allowed guesses) without any pretraining or use of the ARC-AGI training set.
- CompressARC demonstrates extreme data efficiency, performing all its "learning" purely at inference time, using only the single target puzzle as input data.
- Qualitative analysis shows the system generalizes to a diverse range of ARC-AGI puzzles, performing tasks like color assignment, infilling, cropping, connecting dots, and identifying pixel adjacencies.

## Takeaways

> [!tip] Key Insights
> - Abstract reasoning and generalization can be achieved with extreme data efficiency, challenging the conventional necessity of massive pretraining for complex AI capabilities.
> - The Minimum Description Length principle can be effectively operationalized in deep learning through differentiable approximations, providing a practical link between information compression and intelligent behavior.
> - Carefully engineered architectural inductive biases, such as equivariance and multitensor processing, are crucial for enabling rapid, few-shot generalization from extremely limited data.
