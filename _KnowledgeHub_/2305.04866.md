# Causal Policy Gradient for Whole-Body Mobile Manipulation

> [!summary] Summary
> A reinforcement learning framework called Causal MoMa automatically discovers causal dependencies between robot actions and reward terms in whole-body mobile manipulation tasks. This framework then leverages these dependencies within a causal policy gradient to reduce variance, yielding policies that demonstrate successful zero-shot transfer from simulation to real-world mobile manipulators and improved performance over baselines.

## Problem

- Whole-body mobile manipulation (MoMa) tasks involve high-dimensional action spaces and multi-objective reward functions, leading to unstable reinforcement learning (RL) training due to high variance.
- Existing RL approaches for MoMa often manually segregate locomotion and manipulation, hindering synergistic control and requiring extensive human domain knowledge.
- Traditional planning and control methods struggle with dynamic or uncertain environments and the direct optimization of complex, perceptual-driven tasks.

## Method

- A two-step reinforcement learning framework, Causal MoMa, is proposed: first, it automatically discovers causal dependencies, and second, it integrates them into policy learning.
- Action-reward causal discovery infers a binary bi-adjacency matrix using Conditional Mutual Information (CMI) from exploratory robot interactions.
- Policy learning, built on PPO, employs a modified policy gradient that multiplies per-reward-term advantages by the discovered causal matrix, selectively assigning credit to action dimensions to reduce variance.

## Results

- The causal discovery module accurately identified ground truth action-reward dependencies in a controlled Minigrid environment.
- Causal MoMa consistently achieved superior performance (e.g., 93.6% success rate for HSR vs. 74.3% for vanilla PPO) and higher rewards in realistic simulated environments like iGibson with various mobile manipulators.
- Learned policies successfully transferred zero-shot to a real-world Toyota HSR robot, demonstrating robust whole-body control and outperforming traditional planning and control methods in dynamic and unseen environments.

## Takeaways

> [!tip] Key Insights
> - Mobile manipulation tasks inherently possess a causal structure where specific robot action dimensions directly influence particular reward function terms.
> - Leveraging these precise causal relationships between actions and rewards can significantly reduce the variance of policy gradient estimators in reinforcement learning.
> - These causal dependencies can be automatically discovered from robot interaction data, eliminating the need for manual, human-engineered factorization.
