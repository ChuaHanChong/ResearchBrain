# Show-o: One Single Transformer to Unify Multimodal Understanding and Generation

> [!summary] Summary
> Show-o, developed by Show Lab at NUS and ByteDance, presents a single transformer capable of unifying multimodal understanding and generation by adaptively combining autoregressive modeling for text and discrete diffusion for images. The model achieves competitive performance across various vision-language benchmarks with only 1.3 billion parameters and significantly improves image generation efficiency with fewer sampling steps.

## Problem

- Existing unified multimodal models typically rely on fragmented architectures with multiple specialized 'expert' components, leading to increased complexity and redundancy.
- Prior single-transformer approaches for multimodal unification, like Chameleon, suffered from inefficient image generation due to fully autoregressive modeling requiring a prohibitively large number of sampling steps.
- There was a need for a truly unified foundational model that could intelligently adapt its modeling approach (e.g., sequential for text, parallel denoising for images) to different modalities within a single coherent architecture.

## Method

- ==Show-o== is built upon a single pre-trained LLM backbone, expanded with ==unified discrete tokenization== for both text and images, allowing for a shared vocabulary.
- An innovative =='Omni-Attention' mechanism== dynamically switches between causal attention for text tokens and full attention for image tokens, enabling adaptive processing within the unified transformer.
- The model integrates two distinct training objectives: ==Next Token Prediction (NTP)== for autoregressive text tasks and ==Mask Token Prediction (MTP)== for discrete diffusion-based image generation.

## Results

- Achieved comparable multimodal understanding performance to dedicated understanding-only models with only **1.3B** parameters across various benchmarks (POPE, MME, VQAv2, GQA).
- Demonstrated superior text-to-image generation quality, achieving a FID-30K of **9.24** on MSCOCO and a GenEval score of **0.68**, outperforming several larger generation-only and unified models.
- Natively supports novel mixed-modality applications like text-guided image inpainting, extrapolation, and interleaved video keyframe generation without specific fine-tuning, showcasing its versatility.

## Takeaways

> [!tip] Key Insights
> - A single transformer can effectively unify multimodal understanding and generation by adaptively applying different optimal modeling paradigms (autoregressive for text, discrete diffusion for images).
> - This adaptive, unified architecture significantly enhances efficiency in image generation, requiring approximately 20 times fewer sampling steps compared to fully autoregressive models.
> - By leveraging a pre-trained LLM as its foundation, the model can inherently encode text conditional information and maintain strong language capabilities while learning robust cross-modal alignment.
