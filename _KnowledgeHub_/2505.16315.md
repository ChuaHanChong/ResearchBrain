# Incentivizing Dual Process Thinking for Efficient Large Language Model Reasoning

> [!summary] Summary
> This paper introduces Adaptive Cognition Policy Optimization (ACPO), a reinforcement learning framework that enables Large Reasoning Models (LRMs) to dynamically adjust their reasoning depth based on task complexity, inspired by human dual process thinking. ACPO reduces reasoning token usage by up to 60.5% on challenging tasks like AIME 2024, while maintaining or improving accuracy and achieving a better balance between accuracy and computational cost.

## Problem

- Large Reasoning Models (LRMs) suffer from 'overthinking,' generating excessively long and redundant reasoning paths regardless of task difficulty, leading to inefficient inference and increased computational costs.
- Existing LRM reasoning strategies are often fixed or rely on offline length estimations, lacking the real-time adaptability to adjust cognitive effort to varying task complexities.
- Prior methods for CoT compression or length penalization can lead to 'overcompression' for complex tasks (sacrificing accuracy) or insufficient compression for simpler ones.

## Method

- **ACPO**, a reinforcement learning framework, enables LRMs to dynamically switch between ==fast and slow thinking== modes by introducing explicit system-aware reasoning tokens (e.g., ``).
- It integrates online difficulty estimation and token length budgeting directly into the RL framework, using a task's sampling success rate as a proxy for difficulty.
- A two-stage training strategy involves initial Supervised Fine-Tuning (SFT) using GPT-4-annotated data to teach explicit thinking patterns, followed by Reinforcement Learning (RL) with a composite reward function that balances accuracy, token length budget adherence, and appropriate system pattern usage.

## Results

- ACPO significantly reduces the average number of tokens per response across benchmarks, achieving up to a **60.5%** reduction on AIME 2024 (e.g., from 16,894 to 6,670 tokens for DeepSeek-R1-Distill-Qwen-**1.5B**).
- This efficiency gain is achieved with minimal or improved accuracy; for instance, ACPO-**1.5B** improved accuracy from **28.9%** to **30.0%** on AIME 2024 while drastically cutting tokens.
- ACPO demonstrates adaptive behavior by dynamically adjusting reasoning length based on problem difficulty and increasing the proportion of 'slow thinking' for harder tasks, validating the dual process approach.

## Takeaways

> [!tip] Key Insights
> - Operationalizing cognitive science's dual process theory allows LRMs to mimic human-like adaptive cognition, applying more deliberate thought to harder problems and faster thinking to easier ones.
> - Online estimation of task difficulty and token length budgeting, directly within the RL loop, facilitates real-time adaptive control over reasoning length, moving beyond static or offline strategies.
> - Explicit system-aware reasoning tokens make the model's internal cognitive processes transparent and interpretable, offering fine-grained control and monitoring of its thinking modes.
