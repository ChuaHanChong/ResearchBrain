# MEMORA: Embodied Action Memory from Egocentric Videos for Reasoning and Planning

> [!summary] Summary
> MEMORA introduces a structured Embodied Action Memory (EAM) system, enabling agents to form, maintain, and utilize persistent embodied experience derived from egocentric videos for long-horizon robot planning. This system improves memory-assessment accuracy by up to 20.5 points and robot-grounded planning performance by up to 16.6% on generalization tasks through explicit online memory editing and offline consolidation.

## Problem

- Existing foundation-model robot planners lack persistent memory of past interactions, environmental states, and learned procedures, hindering long-horizon planning in familiar environments.
- Interpreting future goals and making contextually appropriate decisions requires memory of past experiences, routines, and object states beyond real-time observations.
- Current memory approaches for embodied agents, such as append-only logs or static entity graphs, struggle to manage the dynamic nature of embodied experience and consolidate knowledge across sessions.

## Method

- **MEMORA** implements ==Embodied Action Memory (EAM)== through a lifecycle of memory formation, online editing, ==offline consolidation==, and ==typed retrieval== from continuous egocentric video.
- The system utilizes four distinct ==typed memory stores==: Environment, Entity, Activity, and Inferred Knowledge, each designed to capture different 'continuities' within embodied experience.
- Memory formation involves a ==multimodal segment encoder== for observations, an online **Memory Editor** for active state revision (e.g., updating object states and locations), and offline consolidation to abstract recurring patterns into reusable knowledge.

## Results

- MEMORA improved memory-assessment accuracy (EAM-QA) by up to **20.5 points** over baselines, with particularly strong gains for cross-event question types (e.g., routines and habits) due to offline consolidation.
- The system achieved up to **16.6%** relative improvement in Robot-Grounded Plan (RGP) scores on out-of-distribution Generalize tasks, demonstrating the value of structured, consolidated memory for novel goals requiring composition or transfer of knowledge.
- The online Memory Editor efficiently maintained memory by reducing cumulative entity records by a median of **~18x** compared to an append-only policy, while qualitative robot deployments validated that language-level plans successfully guided physical actions.

## Takeaways

> [!tip] Key Insights
> - A structured memory lifecycle, including active online editing and offline consolidation, is crucial for efficient and accurate embodied memory, enabling significant reduction in redundant entity records and abstraction of reusable knowledge.
> - Typed memory stores and a type-aware retrieval mechanism allow planners to effectively access distinct evidence (procedural, grounding, preference), leading to improved performance on complex and generalized planning tasks.
> - Leveraging egocentric human video enables the creation of participant-specific embodied memory, which is essential for interpreting ambiguous instructions and making contextually appropriate choices in familiar environments.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The paper addresses challenges in long-horizon robot planning, specifically the need for robots to leverage accumulated embodied experience in familiar environments. Existing foundation-model robot planners can translate language goals and observations into action sequences, but they often lack a persistent memory of past interactions, environmental states, and learned procedures. Human planning, in contrast, heavily relies on such memory, drawing distinctions between episodic events and abstracted semantic regularities, which are consolidated over time.

This work positions itself within several ongoing research areas:
- **Foundation-model planning for embodied agents**: While language models and vision-language models connect perception, reasoning, and action in embodied systems, MEMORA focuses on providing a memory layer that can condition these planners with prior embodied experience, moving beyond large but transient context windows.
- **Egocentric human video for robot learning**: Egocentric video is a significant data source for robot learning, including imitation, manipulation, and cross-embodiment learning. MEMORA proposes a complementary use of this signal: instead of directly converting video into policies or trajectories, it transforms accumulated experience into persistent semantic and procedural memory that informs a planner about relevant routines, objects, preferences, and prior states.
- **Embodied and spatial memory**: Current embodied agents maintain various forms of memory (spatial, semantic, 3D) for navigation and interaction. MEMORA distinguishes itself by forming typed records of embodied experience (spatial context, object identity and state, action traces, and consolidated regularities) from longitudinal human experience, rather than focusing solely on geometric scene mapping or visuomotor memory.
- **Memory formation in language agents**: Research in LLM agents has explored memory formation, consolidation, and retrieval. MEMORA extends this lifecycle view to real egocentric video, introducing active, structured online editing and organizing memory by embodied continuities rather than a single linear transcript or graph.
- **Benchmarks for embodied memory**: Existing benchmarks for long-video QA or conversational memory do not fully evaluate an agent's ability to form and utilize memory across multiple sessions for planning. MEMORA-Bench aims to fill this gap by assessing both retrospective memory faithfulness and prospective memory-grounded planning from continuous embodied experience.

MEMORA's contribution is in establishing a structured, active, and consolidated memory system that operates in conjunction with, rather than replacing, these existing capabilities, providing experience-grounded context for decisions.

### 2. Key Objectives and Motivation

The primary objective of this research is to define, implement, and evaluate Embodied Action Memory (EAM) as a fundamental capability for embodied agents. EAM aims to enable agents to form, maintain, and utilize embodied experience as a persistent memory state to inform future decisions, particularly for long-horizon robot planning.

The motivation for this work stems from several observations and requirements:

- **Interpreting Future Goals**: For an embodied agent operating in familiar environments, understanding future goals often requires more than real-time scene observations. It necessitates memory of past experiences, such as where specific tools are typically kept, how objects have changed state, which procedures have been performed previously, and underlying behavioral regularities. Without such memory, goals can be ambiguous or uninterpretable.
- **Human Cognitive Models**: Human planning provides an analogy. People draw upon both episodic traces of specific events and semantic knowledge abstracted across repeated experiences, with consolidation playing a role in transforming episodes into reusable knowledge. Replicating a similar "planning-facing memory" capability in robots is a driving motivation.
- **Limitations of Current Robot Planners**: Existing foundation-model robot planners, while capable, often rely on large context windows for immediate information. However, this approach is insufficient for maintaining persistent, evolving state across sessions, which is critical for long-term tasks and adapting to participant-specific behaviors.
- **Transforming Egocentric Video**: Egocentric human video is a rich source of embodied experience, capturing a participant's interactions with their environment over time. The motivation is to convert this continuous stream into structured, persistent memory that remains useful long after individual episodes have passed, preserving context and temporal changes.
- **Need for Structured Memory Management**: A simple append-only log or a static entity graph struggles to manage the dynamic nature of embodied experience. A robust system requires explicit mechanisms for encoding perceptions, actively revising persistent states as new evidence arrives, consolidating repeated experiences into generalizable knowledge, and retrieving the appropriate blend of procedural and grounding evidence for planning. This necessitates a lifecycle view of memory, accounting for different rates of change in spatial, entity-state, action, and consolidated knowledge domains.

In essence, the research aims to provide robots with a persistent, adaptive memory that enables them to plan and reason in a manner more aligned with how humans leverage past experience in familiar settings.

### 3. Methodology and Approach

MEMORA implements Embodied Action Memory (EAM) through a structured lifecycle of memory formation, maintenance, retrieval, and consolidation.

#### 3.1. Embodied Action Memory (EAM) Formulation

EAM is formulated as a system where an agent's memory state `M_t` at time `t` is updated by a formation function `F` based on the previous memory state `M_{t-1}` and current observation `o_t` (`M_t = F(M_{t-1}, o_t)`). Later decisions `d_τ` are made by a decision function `G` based on the memory `M_τ` and a given context `x_τ` (language question, goal) (`d_τ = G(M_τ, x_τ)`). Decisions are language-level (e.g., multiple-choice answers or sequences of grounded action-entity-location triples). The memory is designed to be experience-dependent, capturing participant-specific routines, preferences, and action histories.

#### 3.2. MEMORA Architecture and Lifecycle

MEMORA operates with four distinct typed memory stores, each designed to capture different "continuities" within embodied experience:

- **Environment Memory**: Records persistent places, layout descriptions, named zones, and spatial relationships. It is updated deterministically, merging information by detected place identifiers.
- **Entity Memory**: Maintains object identities, visual attributes, current locations, states, and a `state_history` list. This ensures that objects retain their identity despite changes in state or location.
- **Activity Memory**: Stores temporally ordered action records, summarizing 10-second video segments with narratives and action breakdowns. This store is primarily append-only, capturing the event stream.
- **Inferred Knowledge**: Contains high-level abstractions like routines, habits, preferences, and workflow patterns, consolidated across repeated experiences. This store is populated offline.

#### 3.3. Memory Formation: Encoding, Editing, and Consolidation

The memory formation process for MEMORA involves several stages:

- **Segment Encoding (ϕ)**: A multimodal model (Qwen2.5-Omni-7B) processes continuous egocentric video. Each 10-second video segment `v_t` is converted into structured textual observations `z_t`, encompassing environmental, activity, and entity information. A bounded textual summary `c_t` acts as a short-term working memory across segments.
- **Online Memory Processor (EDIT)**: This component actively updates the persistent memory state `M_t`.
 - **Memory Editor**: For `Entity Memory`, the editor (Qwen3-30B-A3B-Instruct-2507) makes explicit decisions for each new object observation: `ADD` (new object), `UPDATE` (change state/location of existing object, preserving history), `DELETE` (remove inconsistent identification), or `NOOP` (no change). This active editing reduces redundant entity records (by a median of ~18x) while maintaining accurate object state histories.
 - `Environment Memory` and `Activity Memory` are updated deterministically, merging spatial data and appending temporal activity logs, respectively.
- **Offline Consolidation**: After observations from videos are processed, an offline process analyzes the `Entity Memory` and `Activity Memory` of a participant. This process abstracts recurring patterns, forming `Inferred Knowledge` entries such as storage preferences, organizational habits, and workflow patterns, which are then linked to supporting episodic evidence.

#### 3.4. Memory-Guided Retrieval and Planning

Once memory is formed, MEMORA supports two primary interfaces:

- **Retrieval (EAM-QA)**: Used for memory assessment tasks. Given a question and a specific `ask_turn_id` (temporal anchor), the system ensures that only memory evidence strictly preceding that time is retrieved. This prevents temporal leakage.
- **Planning (MEMORA-Planning)**: Used for generating grounded plans. The system produces a sequence of (action, entity, location) triples.
- **ReAct Loop and Tools**: Both interfaces utilize an iterative ReAct (Reasoning and Acting) loop. The primary mechanism for accessing memory is a type-aware search tool that dispatches queries to the appropriate typed memory index (objects, activities, environment, patterns). Specialized memory-read tools include:
 - `get_state_at_time`: Recovers historical object states.
 - `get_object_history`: Accesses the full history of an object.
 - `get_routine_skill`: Retrieves consolidated procedural routines from `Inferred Knowledge`.
 - `get_preferences`: Accesses participant-specific preferences from `Inferred Knowledge`.

#### 3.5. MEMORA-Bench Evaluation Suite

A 45-hour dataset derived from EPIC-KITCHENS-100 extension videos (18 participants) is used for evaluation:

- **MEMORA-Embodied Memory Assessment (EAM-QA)**: Consists of 2,212 multiple-choice questions across four types (SPREF: preferences, SHABIT: habits, SROUTINE: routines, ERECALL: episodic recall). It includes an "information-not-available" option to distinguish missing memory from forced guesses.
- **MEMORA-Planning**: Includes 207 in-distribution Replay tasks and 153 out-of-distribution Generalize tasks. Plans are scored using Robot-Grounded Plan (RGP), an unweighted mean of OrderExec (step order), KeyObj (required objects), and PrefAdh (matched preferences).
- **Comparison Conditions**: Evaluates against "Parametric" (no memory), "Flat-1D" (chronological text memory), "Graph-2D" (entity-relation graph memory), "MEMORA-Episodic" (MEMORA without offline consolidation), and full "MEMORA." All comparisons control for perception, retrieval mechanisms, and the backbone language model used for reasoning.

### 4. Main Findings and Results

The evaluation of MEMORA utilized MEMORA-Bench, a 45-hour dataset from EPIC-KITCHENS-100 extension videos, and compared various memory conditions across four open-weight language models.

#### 4.1. Overall Performance

Full MEMORA, which integrates online editing, typed memory stores, and offline consolidation, achieved the strongest aggregate results across all evaluated memory conditions and language model backbones.

#### 4.2. MEMORA-Embodied Memory Assessment (EAM-QA) Results

- **Accuracy Improvements**: MEMORA improved memory-assessment accuracy by up to 20.5 points over the strongest controlled baseline (Flat-1D after online editing) when using the Gemma-4-31B-it backbone. This lead was observed across all four question types: SPREF (preferences), SHABIT (habits), SROUTINE (ordered procedures), and ERECALL (within-video recall).
- **Contribution of Online Editing**: Online editing, applied before graph construction, improved Graph-2D performance by +7.0 points but Flat-1D by only +2.0 points. This suggests that the structured revision provided by online editing is more effective than simply processing noisy text for maintaining typed state revisions.
- **Contribution of Offline Consolidation**: The difference between full MEMORA and MEMORA-Episodic (without offline consolidation) demonstrated a gain of +14.4 points in overall accuracy. This gain was particularly pronounced for cross-event question types (SPREF: +9.4, SHABIT: +13.7, SROUTINE: +24.6), indicating that consolidating repeated observations into explicit regularities is crucial for these categories.
- **Consistency Across Backbones**: These performance trends, including the benefits of online editing and offline consolidation, were consistent across the four different open-weight language model backbones.

#### 4.3. MEMORA-Planning Results

- **Performance on Generalize Tasks**: MEMORA consistently achieved the highest Robot-Grounded Plan (RGP) scores across all Replay and Generalize tasks and all four backbones. The performance gains were notably larger on Generalize tasks (up to +16.4% relative RGP on Gemma-4-31B-it, +16.6% on Qwen3.6-35B-A3B) compared to Replay tasks. This indicates that structured, consolidated memory is particularly valuable for novel goals requiring composition or transfer of knowledge.
- **Impact of Offline Consolidation on Planning**: For Generalize tasks, full MEMORA demonstrated improved performance over MEMORA-Episodic, especially with stronger reasoning backbones like Qwen3.6-35B-A3B and Gemma-4-31B-it. These backbones could effectively utilize the reusable routines and preferences from Inferred Knowledge. For instance, on Gemma-4-31B-it, significant relative gains were observed in OrderExec (+43%) and PrefAdh (+14%).
- **Diagnostics of Planning Gains**: Tool use analysis revealed that MEMORA enabled planners to query separable evidence for procedure, preference, object state, and location through a typed cascade of tool calls (e.g., `get_routine_skill`, `search_objects`). In contrast, flat retrieval baselines primarily issued keyword searches, which were effective for Replay tasks (direct recall) but less so for Generalize tasks requiring composition. Weakening the Memory Editor's capacity from Qwen3-30B-A3B to Qwen3-14B led to a 5.8 EAM-QA point drop and a notable increase in "information-not-available" selections, indicating a reduction in usable memory.
- **Memory Compression**: The active editing in Entity Memory resulted in a median ~18x reduction in cumulative records compared to an append-only policy, demonstrating efficient memory maintenance.

#### 4.4. Qualitative Robot Deployment

A qualitative study involving a Unitree G1 robot demonstrated the practical application of MEMORA's language-level plans.
- **Prepare Drink Task**: The robot successfully selected the remembered bottled Coca-Cola over a Fanta can and the participant's orange plastic cup over other colored cups.
- **Breakfast Task**: The robot correctly selected the yellow bowl, Cinnamon Tea, yellow spoon, and bread, following the remembered assembly order.
These demonstrations indicated that memory formed from human egocentric video could effectively guide physical action selection, entity grounding, and sequencing in a robot execution setting, achieving success on the first attempt for both tasks.

### 5. Significance and Potential Impact

The MEMORA framework and its evaluation through MEMORA-Bench contribute to the field of embodied AI by demonstrating the utility of a structured, actively maintained, and consolidated memory system for robot planning.

- **Enhanced Robot Planning Capabilities**: MEMORA positions memory as a critical substrate for long-horizon robot planning, moving beyond reactive or short-term contextual understanding. By providing distinct procedural and grounding evidence, MEMORA enables robots to make more informed decisions, particularly in novel situations (Generalize tasks) where direct experiential recall is insufficient. This could lead to more adaptive and capable embodied agents in complex environments.
- **Validation of Memory Lifecycle**: The research provides empirical evidence for the importance of a complete memory lifecycle—formation, online editing, offline consolidation, and typed retrieval. The controlled experiments clearly isolate the contributions of online editing (for efficient and accurate entity state tracking) and offline consolidation (for abstracting reusable routines and preferences), affirming their necessity for robust embodied memory.
- **Complementary to Existing Robot Learning**: MEMORA does not seek to replace existing robot policy learning or vision-language-action (VLA) systems. Instead, it offers a complementary memory layer. While VLA systems and imitation learning focus on *how* actions are executed from human video, MEMORA provides the *what*—the experience-grounded context, routine cues, and preference-based choices that guide higher-level planning. This suggests a composable architecture where memory informs policy.
- **Leveraging Egocentric Experience**: The work highlights the value of egocentric video as a rich source for building participant-specific, rather than generic, embodied memory. This personalized memory is crucial for interpreting ambiguous instructions and making contextually appropriate choices in familiar environments.
- **Comprehensive Evaluation Paradigm**: MEMORA-Bench introduces a novel evaluation suite that addresses both retrospective memory faithfulness and prospective planning utility, providing a more holistic assessment of embodied memory systems than previous benchmarks. This framework can facilitate future research and development in this domain.
- **Foundational for Adaptive Autonomy**: By enabling robots to learn and retain knowledge about their environment and interactions over extended periods, MEMORA lays groundwork for more autonomous and adaptive robotic systems. Such systems could learn from continuous experience, adapt to user preferences, and navigate complex, dynamic environments with greater efficiency and intelligence.

**Limitations identified by the authors include**:
- The current domain is limited to kitchen activity in EPIC-KITCHENS-100, and the horizon (up to 15 sessions per participant) is not extensive enough to study months-long drift or rare events.
- The pipeline's performance is dependent on the quality of upstream perception and write-time editing, with errors potentially propagating.
- The robot deployment is qualitative and serves as a sanity check for language-level grounding, not a statistical evaluation of robot generalization or full closed-loop autonomy.
- The development of participant-specific persistent memory necessitates careful consideration of privacy, consent, and access controls in practical deployments.
