# CLAM: Continuous Latent Action Models for Robot Learning from Unlabeled Demonstrations

> [!summary] Summary
> University of Southern California researchers develop CLAM (Continuous Latent Action Models), a two-stage framework that learns robot policies from unlabeled expert demonstrations by first pretraining a latent action model using self-supervised inverse and forward dynamics, then training policies on relabeled data, achieving 2-3x performance improvements over state-of-the-art methods in both simulated and real robot tasks while demonstrating that continuous latent actions and joint training of action decoders are critical for fine-grained control without requiring expensive action-labeled expert data.

## Problem

- Collecting action-labeled expert demonstrations for robot learning is expensive, time-consuming, and requires specialized skills, limiting the scalability of imitation learning approaches
- Existing methods that learn from unlabeled data often discretize latent action spaces, which is unsuitable for continuous control tasks requiring fine-grained manipulation
- Previous approaches fail to effectively ground learned latent actions to real-world executable actions due to separate training phases

## Method

![[2505.04999-method.png]]
*Overview of CLAM's two-stage approach. Stage 1 (left) involves pretraining a latent action model with both unlabeled and a small amount of labeled data. Stage 2 (right) uses the pretrained model to annotate unlabeled expert demonstrations with latent actions, which are then used to train a policy.*

- Develop a two-stage framework where Stage 1 pretrains a latent action model using self-supervised inverse and forward dynamics on unlabeled data
- Jointly train the latent action decoder with the dynamics models to ensure better grounding of latent actions to real-world actions
- Use continuous latent action representations instead of discrete ones to enable fine-grained robot control
- Train policies in Stage 2 using the pretrained inverse dynamics model to relabel unlabeled expert data with latent actions

## Results

- Achieves 2-**3x** higher success rates compared to state-of-the-art baselines across DMControl, MetaWorld, and real robot manipulation tasks
- Approaches the performance of behavior cloning trained on privileged expert action-labeled data while using only unlabeled expert demonstrations
- Demonstrates that performance scales with the amount of unlabeled expert data, showing the method's potential for leveraging large-scale observation datasets
- Shows successful transfer from simulation to real-world robot tasks, validating the approach's practical applicability for robotics deployment

## Takeaways

> [!tip] Key Insights
> - Continuous latent actions are essential for robot control tasks, as discretization significantly degrades performance in manipulation scenarios
> - Joint training of the action decoder with the latent action model is critical for learning representations that can be effectively grounded to executable actions
> - Unlabeled expert data combined with small amounts of non-expert action-labeled data can achieve performance comparable to methods using expensive expert action-labeled datasets
> - Image features learned by the pretrained inverse dynamics model provide effective initialization for downstream policy learning
