# gradSim: Differentiable simulation for system identification and visuomotor control

> [!summary] Summary
> Researchers at Mila and NVIDIA developed ∇Sim, an end-to-end differentiable framework that integrates multiphysics simulation and differentiable rendering into a single computational graph. This framework accurately infers physical properties of objects and enables visuomotor control policies directly from video data, eliminating the need for 3D state supervision.

## Problem

- Accurately inferring the physical properties and dynamics of objects from raw visual observations (video sequences) without requiring precise 3D labels or state-space supervision.
- The limitation of 'white box' physics-based methods which traditionally depend on expensive and often infeasible 3D ground truth for training, especially for complex deformable objects.
- Challenges in learning visuomotor control policies that rely solely on visual input, typically needing complex 3D state perception modules or extensive trial-and-error.

## Method

- Unifies a differentiable multiphysics simulation engine with a differentiable rendering engine into a single, cohesive computational graph, allowing gradients to flow from pixels to physical parameters.
- Employs the discrete adjoint method for efficient gradient computation through complex physical dynamics and differentiable rasterizers (like SoftRas and DIB-R) for gradients through 3D-to-2D image formation.
- Enables end-to-end learning by computing a pixel-wise loss between a target video and a synthetic video generated by the model, then backpropagating this loss to adjust underlying physical attributes or control parameters.

## Results

- Achieved high accuracy in estimating physical attributes for rigid bodies (e.g., 9.01e-5 mean absolute relative error for mass) and deformable objects directly from video, outperforming or matching 3D-supervised baselines in various scenarios.
- Successfully trained neural network policies for visuomotor control of deformable objects towards a target visual pose using only pixel-wise MSE loss, demonstrating effectiveness for complex control tasks like cloth manipulation.
- Demonstrated impressive computational efficiency, achieving faster-than-real-time simulation rates (e.g., 1500 steps/second for 10000 tetrahedra) for both forward and backward passes of complex deformable geometries.

## Takeaways

> [!tip] Key Insights
> - The unified differentiable simulation and rendering pipeline produces remarkably smooth and well-behaved loss landscapes, which is highly conducive to gradient-based optimization for inverse problems.
> - Accurate physical modeling (e.g., correct object type) is more critical for robust parameter estimation than imperfections in the rendering model.
> - Including richer visual cues like shading and texture in the differentiable renderer significantly improves the convergence speed of parameter estimation by providing better gradients.
