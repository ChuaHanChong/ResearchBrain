# CAD-Assistant: Tool-Augmented VLLMs as Generic CAD Task Solvers

> [!summary] Summary
> CAD-Assistant presents a tool-augmented Vision and Large Language Model (VLLM) framework that integrates GPT-4o with specialized CAD tools and the FreeCAD software to enable generic CAD task solving. This framework demonstrates robust performance across diverse multimodal inputs, achieving superior results compared to baselines in tasks like autoconstraining and hand-drawn sketch parameterization.

## Problem

- Existing CAD automation solutions are primarily task-specific, focusing on fixed workflows and lacking the generality to support the entire iterative design process.
- Vision and Large Language Models (VLLMs) inherently struggle with precise geometric reasoning, mathematical accuracy, and understanding the complex effects of CAD commands.
- There is a need for adaptable CAD agents capable of processing diverse multimodal inputs and interacting dynamically with evolving design states to provide comprehensive AI assistance.

## Method

- A ==tool-augmented VLLM framework==, CAD-Assistant, was developed using GPT-4o as a high-level planner to generate natural language plans and corresponding Python code actions.
- The framework integrates a comprehensive set of CAD-specific tools, including a hand-drawn image parameterizer, sketch/3D solid recognizers, and a constraint checker, along with direct ==FreeCAD API== access.
- An ==iterative plan-action-execution-feedback loop== allows the VLLM to dynamically refine its strategy based on textual feedback and visual renderings from the CAD environment.

## Results

- CAD-Assistant achieved **0.979** Primitive F1 (PF1) and **0.484** Constraint F1 (CF1) on the SketchGraphs benchmark for autoconstraining, outperforming raw GPT-4o (**0.693** PF1, **0.274** CF1) and supervised methods like Vitruvion.
- It demonstrated strong performance in CAD Question Answering (CQA), with **0.791** Accuracy (2D) and **0.857** Accuracy (3D), representing substantial gains over raw VLLM baselines.
- The system successfully performed real-world tasks such as 3D reverse engineering from scans, visual interpretation of hand-drawn commands, and 3D solid generation from sketches, with an average cost per user request ranging from
0.0299to0.0887.

## Takeaways

> [!tip] Key Insights
> - Tool-augmentation effectively overcomes the geometric reasoning shortcomings of VLLMs, enabling them to achieve high precision in complex CAD tasks by offloading specific operations to dedicated tools.
> - Multimodal input, specifically precise 2D renderings of sketches and over-parameterized JSON representations, significantly improves the VLLM's understanding and reasoning about CAD geometry.
> - The training-free nature and reliance on docstrings for tool integration make the framework highly extensible and adaptable to a wide array of CAD commands without requiring extensive retraining.
