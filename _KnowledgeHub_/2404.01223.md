# Feature Splatting: Language-Driven Physics-Based Scene Synthesis and Editing

> [!summary] Summary
> Feature Splatting enhances 3D Gaussian Splatting by embedding semantic features from vision-language models, enabling real-time language-driven scene editing and physics-based simulation. The method demonstrates realistic material behaviors and robust editing capabilities while maintaining rendering performance.

## Problem

- Most existing 3D scene representation methods, like NeRFs and 3D Gaussian Splatting, primarily focus on visual appearance without integrating semantic understanding.
- There was a lack of unified frameworks that combine language-driven control with physics-based dynamics for 3D scene manipulation.
- Prior scene editing approaches often lacked the ability to connect high-level language queries with detailed physical interactions in a 3D environment.

## Method

- Augments ==3D Gaussian== primitives with latent feature vectors derived from vision-language models like **CLIP** and **DINOv2**, optimized against 2D reference features.
- Develops a differentiable feature splatting component to efficiently incorporate and optimize semantic features within the Gaussian representation.
- Implements language-guided scene decomposition for object segmentation and a language-driven physics synthesis module for assigning material properties and simulating interactions.

## Results

- Demonstrates realistic physics-based behaviors for various materials, including elastic deformation, granular flow, and rigid body dynamics, driven by language commands.
- Enables robust language-guided scene editing operations such as object removal, geometric transformations, appearance editing, and duplication, producing artifact-free results.
- Maintains real-time rasterization performance, comparable to standard 3D Gaussian Splatting, while incorporating semantic and physical capabilities.

## Takeaways

> [!tip] Key Insights
> - Enriching explicit 3D Gaussians with view-invariant semantic features enables intuitive language-based object selection and manipulation.
> - Fusing features from multiple foundation models (CLIP, DINOv2, SAM) provides robust semantic understanding for accurate scene decomposition and feature refinement.
> - Integrating a particle-based Material Point Method (MPM) simulator allows for realistic physics-based interactions and material property assignment via language.
