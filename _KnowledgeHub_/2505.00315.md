# Mixture of Sparse Attention: Content-Based Learnable Sparse Attention via Expert-Choice Routing

> [!summary] Summary
> A novel sparse attention mechanism called MoSA (Mixture of Sparse Attention) enables more efficient transformer models by dynamically selecting relevant tokens for each attention head, achieving 27% better perplexity than dense attention baselines while reducing computational costs and KV-cache size.

## Problem

- Traditional self-attention in transformers has quadratic computational and memory complexity
- Existing sparse attention methods often fail to match dense attention performance in practice

## Method

- ==Expert-choice routing== allows each attention head to dynamically select the most relevant tokens
- ==Hybrid architecture== combines sparse MoSA heads with dense attention heads for stability
- Sparse computation only on selected tokens reduces resource requirements

## Results

- **27%** better perplexity compared to dense baselines with equal compute budget
- Significant reductions in wall-clock time, training memory, and KV-cache size
- Only sparse attention method tested that outperforms dense baseline in IsoFLOP setting
- Maintains effectiveness across varying sequence lengths

## Takeaways

> [!tip] Key Insights
> - Dynamic content-based token selection outperforms static sparse patterns
> - Hybridization with dense heads is crucial for optimal performance
> - Performance advantage increases with longer sequence lengths
