# $\mathcal{P}^3$: Toward Versatile Embodied Agents

> [!summary] Summary
> The P3 framework introduces a system for versatile embodied agents to operate in dynamic real-world environments by integrating active omni-task perception, feedback-agnostic tool integration, and dynamic multi-task planning. It achieves robust performance across various real-world tasks, including proactive task generation and adaptive execution, demonstrated with physical robots and smart home devices.

## Problem

- Embodied agents typically rely on passive environmental perception, missing dynamic changes caused by external factors and leading to incomplete observations.
- Existing agents are limited by rigid tool compatibility, often requiring bidirectional communication, which hinders integration with many real-world, unidirectional IoT devices.
- Multi-task planning in current systems is often simplistic (e.g., FIFO), failing to account for task dependencies, priorities, or dynamic adaptations in complex environments.

## Method

- A Perception Module continuously observes the environment via video streams, generating scene graphs, captions, and actively proposing new tasks using Vision-Language Models (VLMs), decoupling perception from specific tool feedback.
- A "Tool Plug-ins" architecture enables the integration of diverse devices (navigation, manipulation, IoT, web agents) without requiring direct bidirectional feedback, with their environmental impact observed by the Perception Module.
- An LLM-based Task Planner dynamically schedules passive, active, and scheduled tasks by evaluating priorities and dependencies, allowing for adaptive execution, interruptions, and resumptions.

## Results

- The Active Perception Capability Evaluation showed that VLMs like QwenVL-max achieved **77.09%** accuracy in identifying active tasks from video snapshots while minimizing false positives.
- Real-world deployment on humanoid robots demonstrated robust performance across 11 diverse tasks, successfully integrating navigation, manipulation, IoT, and web agents.
- The framework effectively managed competing tasks, handling interruptions and dynamically adjusting execution plans, showcasing human-like prioritization and adaptability in complex scenarios.

## Takeaways

> [!tip] Key Insights
> - Active, continuous environmental perception, decoupled from specific tool feedback, is crucial for real-world adaptability and enables agents to proactively identify and respond to dynamic changes.
> - Decoupling tool feedback from the core agent's perception allows for seamless integration of a wide array of devices, including simple IoT components, significantly expanding agent versatility and deployment possibilities.
> - An LLM-based dynamic task scheduler can effectively manage competing tasks, priorities, and dependencies, facilitating human-like adaptive behavior in complex, open-ended environments.
