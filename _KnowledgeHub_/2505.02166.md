# CrayonRobo: Object-Centric Prompt-Driven Vision-Language-Action Model for Robotic Manipulation

> [!summary] Summary
> A multi-modal prompt-driven framework enables robots to perform complex manipulation tasks through crayon-style visual overlays combined with language instructions, demonstrating improved success rates on manipulation tasks while introducing a novel keyframe-based approach for long-horizon task execution through the integration of contact points, end-effector orientation, and movement direction specifications.

## Problem

- Existing robotic manipulation approaches struggle with precise task specification and complex, long-horizon tasks
- Current methods (pure vision, language, or goal-image based) lack either functional understanding or contain excessive irrelevant information

## Method

- Developed **CrayonRobo**, combining visual prompts (contact points, orientations, movement directions) with language instructions
- Implemented a keyframe sequencing system to break down complex tasks into manageable steps
- Created a ==Vision-Language-Action== model using LLaMA-adapter and CLIP's visual encoder

## Results

- Achieved higher success rates compared to baseline methods in manipulation tasks
- Demonstrated robustness to noise in visual prompts while maintaining performance
- Successfully transferred to real-world robot deployment without sim-to-real fine-tuning
- Showed effective generalization to unseen tasks and objects

## Takeaways

> [!tip] Key Insights
> - Multi-modal prompts (visual + language) outperform single-modality approaches
> - Progressive training strategy improves model comprehension of different prompt types
> - Visual prompts can be automatically extracted using Grounded-DINO and GPT-4
