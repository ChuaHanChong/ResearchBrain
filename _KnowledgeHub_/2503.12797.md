# DeepPerception: Advancing R1-like Cognitive Visual Perception in MLLMs for Knowledge-Intensive Visual Grounding

> [!summary] Summary
> DeepPerception introduces an MLLM-based framework to advance R1-like cognitive visual perception for knowledge-intensive visual grounding through a two-stage training process. The framework achieves an average accuracy of 62.20% on the new KVG-Bench, an 8.08% improvement over direct fine-tuning, and establishes new state-of-the-art results on fine-grained visual recognition tasks.

## Problem

- Current MLLMs lack fine-grained visual discrimination when tasks require deep domain-specific knowledge and structured cognitive reasoning.
- Existing MLLMs tend to provide direct answers without integrating their vast knowledge bases with perceptual features through a step-by-step cognitive analysis.
- There is a scarcity of high-quality, knowledge-aligned training data suitable for developing advanced cognitive visual perception in MLLMs.

## Method

- Defined the ==Knowledge-Intensive Visual Grounding (KVG)== task and introduced ==KVG-Bench==, a comprehensive benchmark for evaluating cognitive visual perception.
- Developed DeepPerception, an MLLM-based framework with a two-stage cognitive training process combining ==Chain-of-Thought SFT (CoT-SFT)== and ==Perception-oriented Reinforcement Learning (GRPO)==.
- Implemented an ==automated data synthesis pipeline== to generate knowledge-aligned training samples, including composite images, to overcome data scarcity for KVG.

## Results

- DeepPerception achieved **62.20%** average accuracy on KVG-Bench, an **8.08%** increase over direct fine-tuning, and surpassed **70B**-scale MLLMs using a **7B**-scale base model.
- The framework demonstrated strong cross-domain generalization with **60.85%** accuracy on unseen categories and established state-of-the-art performance on standard Fine-Grained Visual Recognition tasks (**83.21%** average accuracy).
- General multimodal understanding and reasoning abilities were preserved, as shown by comparable performance to the base model on benchmarks like MMBench and MMMU.

## Takeaways

> [!tip] Key Insights
> - Explicitly integrating cognitive reasoning processes (planning, analysis, comparison, conclusion) into MLLM training significantly enhances their ability to perform fine-grained visual discrimination.
> - A two-stage framework, combining CoT-SFT for establishing cognitive chains and GRPO for refining perceptual accuracy, effectively optimizes the synergy between MLLM perception and cognition.
> - Automated data synthesis, especially through composite image generation with visually similar entities, is an effective strategy to create data for knowledge-intensive visual tasks, reducing reliance on manual annotation.
