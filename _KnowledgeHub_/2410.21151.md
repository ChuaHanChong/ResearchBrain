# BraVE: Offline Reinforcement Learning for Discrete Combinatorial Action Spaces

> [!summary] Summary
> Researchers from the University of Virginia and MBZUAI developed BraVE (Branch Value Estimation), an offline reinforcement learning algorithm for discrete combinatorial action spaces. It addresses the scalability-expressivity tradeoff by structuring the action space as a tree and using a Q-guided neural network for linear-time action selection. BraVE consistently outperformed state-of-the-art baselines in high-dimensional environments with strong sub-action dependencies.

## Problem

- Offline reinforcement learning (RL) faces computational intractability when applied to high-dimensional, discrete combinatorial action spaces due to the exponential growth of possible joint actions.
- Accurately modeling complex interactions and dependencies among sub-actions from static, pre-collected datasets is challenging for existing offline RL methods.
- Prior approaches exhibit a scalability-expressivity tradeoff: factorized methods are scalable but sacrifice modeling of sub-action dependencies, while standard value-based methods are intractable in high dimensions.

## Method

- **BraVE** structures the ==combinatorial action space== as a tree, where each node represents a partial action, allowing a neural network to guide traversal and evaluate a linear number of actions.
- A Q-guided tree traversal mechanism uses predicted Q-values and branch values (estimated maximum Q-values within subtrees) to efficiently identify the greedy action.
- The training objective combines a behavior-regularized temporal difference (TD) loss with a novel branch value supervision loss that recursively propagates TD targets up the action tree to stabilize learning.

## Results

- BraVE consistently outperformed Factored Action Spaces (FAS) and Implicit Q-Learning (IQL) across increasing action dimensionalities (2-D to 11-D, over 4 million actions) in the Combinatorial Navigation Environment (CoNE).
- It maintained stable performance in environments with strong, non-factorizable sub-action dependencies (e.g., 50-**100%** pit density in 8-D CoNE), while baselines like FAS showed sharp declines.
- The method demonstrated robustness to the ordering of sub-action dimensions and achieved comparable or slightly superior performance to IQL during online fine-tuning after offline pretraining.

## Takeaways

> [!tip] Key Insights
> - Structuring the combinatorial action space as a tree enables efficient, linear-time action selection in exponentially large spaces while preserving the ability to model complex sub-action dependencies.
> - A branch value supervision loss, which recursively propagates TD targets, effectively stabilizes learning and provides reliable gradient updates to ancestor nodes in the action tree, even for rarely sampled regions.
> - Sparsifying the action space tree by pruning unobserved sub-action combinations from the offline dataset reduces computational overhead and prevents value overestimation due to extrapolation to unrealistic actions.
