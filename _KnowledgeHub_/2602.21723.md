# LessMimic: Long-Horizon Humanoid Interaction with Unified Distance Field Representations

> [!summary] Summary
> The LESSMIMIC framework enables humanoid robots to perform long-horizon interactions with diverse physical objects by utilizing unified Distance Field representations. This system achieves 80-100% success rates on object generalization tasks across varying scales and robustly executes sequences of up to 40 tasks, reliably transferring these learned capabilities to a real-world robot using only vision.

## Problem

- Existing humanoid interaction methods suffer from either rigid coupling to specific motion references, which limits generalization to novel object geometries, or reliance on extensive task-specific reward engineering, hindering flexible skill composition.
- Conventional geometric representations like voxels or meshes are often computationally intensive for real-time whole-body control or lack the continuous distance information crucial for contact-aware interaction.
- Achieving truly autonomous, generalizable, and adaptable humanoid behavior requires a unified representation that can decouple interaction logic from specific motion patterns.

## Method

- A novel ==Distance Field (DF)== based representation is introduced, capturing continuous geometric and dynamic interaction cues (signed distance, surface normals, decomposed velocities) for humanoid links, which is invariant to global object pose and scale.
- A three-stage training pipeline is employed, starting with behavior cloning and DAgger distillation from a reference-based teacher to a DF-based student policy.
- The policy is further refined using reinforcement learning with Adversarial Interaction Priors (AIP) in procedurally randomized environments to promote geometric generalization, followed by visual-motor distillation for real-world deployment using egocentric depth observations.

## Results

- The system achieved 80-**100%** success rates on `PickUp` and `SitStand` tasks across a wide range of object scales (**0.4x** to **1.6x**) and successfully generalized to entirely unseen object shapes, significantly outperforming existing baselines.
- A single LESSMIMIC policy demonstrated robust long-horizon skill composition, achieving **61.7%** success on sequences of 5 randomly ordered heterogeneous tasks and maintaining viability for up to 40 consecutive task instances without environment resets.
- Capabilities reliably transferred to a physical humanoid robot, achieving 10/10 real-world success on `PickUp` and `SitStand` tasks, with the vision-based variant also showing strong performance and successfully demonstrating long-horizon real-world sequences.

## Takeaways

> [!tip] Key Insights
> - Distance Fields provide a geometrically invariant and unified representation of humanoid-object interaction, abstracting local contact patterns from global object properties, which is key for robust generalization across object shapes and scales.
> - Adversarial Interaction Priors (AIP) effectively guide the reinforcement learning process, encouraging the policy to learn and maintain geometry-consistent interaction patterns in procedurally varied environments.
> - A multi-stage learning approach, combining initial behavior cloning for skill acquisition, reinforcement learning for generalization, and visual distillation for deployment, is effective for creating versatile and autonomous humanoid agents.
