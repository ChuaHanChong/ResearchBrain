# MemoAct: Atkinson-Shiffrin-Inspired Memory-Augmented Visuomotor Policy for Robotic Manipulation

> [!summary] Summary
> MemoAct, a visuomotor policy for robotic manipulation, incorporates a hierarchical memory system inspired by the Atkinson-Shiffrin human memory model to manage both precise short-term task state tracking and robust long-horizon retention. The system achieved an average success rate of 96.5% on the new MemoryRTBench benchmark, significantly outperforming existing history-aware and Markovian policies in memory-dependent tasks across simulated and real-world environments.

## Problem

- Robotic manipulation policies often adhere to the Markov assumption, making them unable to handle memory-dependent tasks that require historical context due to perceptual aliasing.
- Existing history-aware policies either use fixed-size FIFO memory, losing long-horizon retention, or similarity-based merging, which extends memory but sacrifices fine-grained details for precise task state tracking.
- There is a persistent trade-off between maintaining lossless short-term information and achieving compressed long-term retention in current memory-augmented robotic policies.

## Method

- MemoAct introduces a hierarchical memory system inspired by the Atkinson-Shiffrin model, featuring a lossless Short-Term Memory Bank (STMB) for recent task flow and a compressed Long-Term Memory Bank (LTMB) for distant historical context.
- A specialized memory consolidation module orchestrates the transfer of summarized information from STMB to LTMB, ensuring efficient long-horizon retention while preserving short-term precision.
- A conditional diffusion-based action decoder generates robot actions, guided by an adaptively fused token representing both current sensory input and retrieved historical context.

## Results

- MemoAct achieved an average success rate of 96.5% on the new MemoryRTBench, substantially outperforming the strongest baseline (MVMP at 72%) and Markovian policies (ACT 4.5%, DP 3%).
- It demonstrated superior performance in diverse simulated (49.5% average success on RMBench) and real-world tasks (87.5% average success), consistently surpassing baselines that struggled with memory-dependent challenges.
- The Long Short-Term Memory Consolidation Module (MCM) showed plug-and-play extensibility, boosting a baseline policy (DP3) from 26% to 76.5% success rate on MemoryRTBench, confirming its modular effectiveness.

## Takeaways

> [!tip] Key Insights
> - A hierarchical memory architecture, mirroring human cognitive processes, effectively resolves the trade-off between precise short-term task state tracking and robust long-horizon retention in visuomotor policies.
> - Explicit temporal modeling and an adaptive gating network are crucial for correctly interpreting sequential dependencies and effectively fusing current sensory perception with relevant historical context.
> - Optimal capacities for both short-term (T_s=6) and long-term (T_k=8) memory banks are essential; excessively large or small capacities can degrade performance by introducing noise or losing critical information.
