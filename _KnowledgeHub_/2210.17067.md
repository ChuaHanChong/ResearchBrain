# Unified Optimal Transport Framework for Universal Domain Adaptation

> [!summary] Summary
> A unified Optimal Transport framework addresses Universal Domain Adaptation by automatically detecting common classes and discovering distinct private categories in the target domain, outperforming existing methods on standard benchmarks, as evidenced by a new H3-score. This approach eliminates the need for manual thresholds and enables fine-grained recognition of unknown classes.

## Problem

- Universal Domain Adaptation (UniDA) is challenging as both source and target domains can possess private classes, with no prior knowledge of label set overlap.
- Existing UniDA methods often rely on manually specified thresholds to distinguish common samples from target-private ones, making them difficult to generalize across varying scenarios.
- Current approaches typically group all target-private samples into a single 'unknown' category, failing to discover and differentiate distinct classes within these private samples.

## Method

- Proposes **UniOT**, a unified ==Optimal Transport (OT)== framework using ==Unbalanced OT== for common class detection and standard OT for private class discovery.
- Introduces an adaptive, threshold-free mechanism for common sample detection based on ==UOT assignment confidence scores== and an ==adaptive filling strategy== for robust statistics.
- Employs standard OT for ==intra-domain representation learning==, fostering global discrimination and local consistency among target features to enable the discovery and differentiation of private classes.

## Results

- UniOT achieved state-of-the-art H-scores across four UniDA benchmarks: Office (**91.13%** average), Office-Home (**76.57%** average), VisDA, and DomainNet.
- The method demonstrated superior performance on the new H3-score, designed to evaluate private class discovery, with an average of **82.24%** on Office and **70.84%** on Office-Home datasets.
- Qualitative t-SNE visualizations confirmed UniOT's ability to separate and cluster distinct target-private categories, unlike prior methods that group them as a single unknown.

## Takeaways

> [!tip] Key Insights
> - Unbalanced Optimal Transport's inherent ability to model partial mappings naturally distinguishes common samples from private ones without requiring hard thresholds.
> - Standard Optimal Transport can effectively regularize feature spaces within the target domain, enabling the discovery of intrinsic clusters for private categories.
> - A unified framework combining inter-domain partial alignment for common classes and intra-domain representation learning for private classes via Optimal Transport offers a comprehensive solution for Universal Domain Adaptation.
