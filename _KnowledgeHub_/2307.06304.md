# Patch n' Pack: NaViT, a Vision Transformer for any Aspect Ratio and Resolution

> [!summary] Summary
> NaViT, developed by Google DeepMind, is a Vision Transformer that processes images at their native resolutions and aspect ratios, eliminating the need for fixed-size input preprocessing. This approach enables NaViT to train 4-5 times faster than traditional ViTs for comparable performance while also improving out-of-distribution robustness and fairness metrics.

## Problem

- Traditional Vision Transformers (ViTs) require images to be resized to a fixed square resolution, which distorts original proportions and potentially removes valuable visual information.
- Preprocessing methods for ViTs often introduce padding to accommodate rectangular images, leading to computational inefficiencies by processing unnecessary tokens.
- Most modern visual datasets contain a high percentage of non-square images (e.g., 85.9% in ImageNet), creating a mismatch between real-world data and square-input models.

## Method

- Google DeepMind developed NaViT (==Native-resolution Vision Transformer==), which processes images at their native resolutions and aspect ratios, eliminating the need for fixed-size input preprocessing.
- The core innovation is =="Patch n' Pack"==, a technique that preserves original image aspect ratios, packs multiple images into a single sequence batch, and uses masks to prevent cross-image attention.
- NaViT incorporates architectural adaptations, including masked self-attention and ==factorized positional embeddings with fractional coordinates==, to handle variable resolutions and aspect ratios efficiently.

## Results

- NaViT trains **4-**5x** faster** than traditional ViTs for comparable accuracy, allowing it to process up to **2x more** training examples with the same computational budget.
- A single NaViT model demonstrates high performance across a wide range of input resolutions, achieving **5-**6x** sequence length reductions** with less than a **1%** accuracy drop at inference time.
- The model shows improved out-of-distribution robustness (e.g., ImageNet-A accuracy of **63.8%** vs. ViT's **45.9%**) and enhanced fairness across demographic attributes compared to fixed-resolution ViTs.

## Takeaways

> [!tip] Key Insights
> - Processing images at their native resolutions and aspect ratios significantly improves training efficiency and model performance.
> - Packing multiple variable-sized image token sequences into a single batch, combined with masked attention, allows for efficient batch processing without requiring uniform input dimensions.
> - Dynamically adjusting the token dropping rate during training, particularly with a decreasing schedule, enhances efficiency while maintaining or improving accuracy, allowing the model to see more diverse examples earlier in training and more complete examples later on.

## Detailed Report

### 1. Introduction

Vision Transformers (ViTs) have become fundamental to modern computer vision systems, yet they remain constrained by a critical limitation: they typically require images to be resized to a fixed square resolution. This preprocessing step distorts original image proportions, potentially removes valuable information, and introduces computational inefficiency through unnecessary padding.

Researchers from Google DeepMind have developed NaViT (Native-resolution Vision Transformer), a model that removes this constraint by enabling processing of images at their native resolutions and aspect ratios. This innovation represents a significant step forward in computer vision architecture design.

### 2. Background and Challenges

Vision Transformers segment images into patches that are processed as a sequence of tokens. Traditional approaches use fixed-size square inputs, which requires preprocessing that:

1. Distorts original aspect ratios through resizing or cropping
2. Introduces padding to accommodate rectangular images
3. Removes potentially important visual information
4. Creates computational inefficiency by processing unnecessary padding tokens

Most modern visual datasets contain predominantly non-square images. Analysis of several datasets shows:
- ImageNet: 85.9% non-square images
- LVIS: 92.2% non-square images
- WebLI: 57.3% non-square images

The histogram shows the diversity of aspect ratios across these datasets, highlighting the mismatch between rectangular real-world images and square-input models.

### 3. The Patch n' Pack Approach

The core innovation in NaViT is the "Patch n' Pack" technique, inspired by example packing in natural language processing. This approach:

1. Preserves original image aspect ratios during processing
2. Packs multiple images into a single sequence batch
3. Introduces masks to prevent cross-image attention

The diagram illustrates how images of varying shapes are first processed with patching (middle panel) and then may undergo token dropping (right panel) to increase efficiency.

The packing process involves carefully combining tokens from multiple images:

As shown, each token's receptive field is restricted to tokens from the same image through masked attention. This enables efficient batch processing while preventing information leakage between unrelated images.

### 4. Architectural Innovations

NaViT incorporates several key architectural modifications to handle variable resolutions and aspect ratios:

#### 4.1. Masked Self-Attention

To prevent cross-example attention during processing, NaViT implements masked self-attention:

```python
def masked_self_attention(query, key, value, mask):
    """Self-attention with mask to prevent cross-example attention."""
    attention_weights = softmax(query @ key.transpose(-1, -2) + mask)
    return attention_weights @ value
```

The mask is constructed to allow tokens to attend only to other tokens from the same image, effectively creating independent processing streams within a single computation.

#### 4.2. Positional Embeddings

NaViT introduces two crucial positional embedding adaptations:

1. **Factorized Positional Embeddings**: Separate embeddings for x and y coordinates, enabling generalization to new aspect ratios.

2. **Fractional Coordinates**: Normalizing positions to the range, making them invariant to absolute image dimensions.

The image shows different coordinate systems: absolute (left), fractional without aspect ratio preservation (middle), and fractional with aspect ratio preservation (right). These coordinate systems influence how the model interprets spatial relationships in images of varying dimensions.

```
Increasing token dropping rate:     72.2% accuracy

```

This comparison highlights the importance of gradually exposing the model to more complete images as training progresses.

### 9. Conclusion

NaViT represents a significant advancement in vision transformer architecture, addressing the fundamental limitation of fixed-resolution inputs. By enabling processing of native-resolution, variable aspect ratio images, it achieves:

1. **Improved efficiency**: 4-5× faster training for comparable performance
2. **Enhanced flexibility**: A single model works across various resolutions
3. **Better robustness**: Improved performance on out-of-distribution data
4. **Increased fairness**: More accurate representations across demographic attributes
5. **Practical deployability**: Dynamic resolution-computation trade-offs

The Patch n' Pack methodology opens new possibilities for computer vision systems that can handle real-world image diversity without compromising on performance or efficiency. As vision models continue to evolve, the ability to process images in their natural form will likely become increasingly important, with NaViT establishing a strong foundation for this direction.
