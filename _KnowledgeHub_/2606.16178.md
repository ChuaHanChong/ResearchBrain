# Scaling Short-Term Memory of Visuomotor Policies for Long-Horizon Tasks

> [!summary] Summary
> PRISM is a transformer visuomotor policy architecture that scales short-term memory to two-minute horizons via gated attention (filters irrelevant retrieved tokens) and a hierarchical local-to-global compression scheme. Paired with the REMEMBENCH benchmark, it beats memory baselines by 5-15% absolute on REMEMBENCH, ROBOCASA, and LIBERO.

## Problem

- Most imitation-learned visuomotor policies are myopic, using only immediate sensory input and ignoring past experience needed for tasks like retrieving occluded objects or timed actions.
- Transformer memory over raw token histories scales quadratically in compute and memory with context length, making long visual histories intractable at test time.
- Existing memory-focused embodied AI benchmarks probe memory only indirectly or cover narrow task-specific categories, lacking a benchmark spanning diverse short-term memory types.

## Method

- **Gated attention**: a learned gate selectively filters retrieved historical information per token, suppressing spurious correlations between stale history and current action prediction.
- **Hierarchical architecture**: compresses local per-timestep visual/proprioceptive/action tokens into compact summary tokens before ==global self-attention==, cutting cost by a factor of m.
- **REMEMBENCH**: an eight-task household manipulation and navigation benchmark built on ROBOCASA spanning four short-term memory categories (spatial, prospective, object-associative, object-set).

## Results

- PRISM beats the strongest baseline by **5-12%** absolute on REMEMBENCH and real-world evaluations, and by **11-15%** over its no-memory variant and finetuned VLA baselines (GR00T-N1-3B, OpenVLA) on ROBOCASA/LIBERO.
- LSTM and Mamba recurrent baselines reach only **12%** and **25%** success versus PRISM's **41%** on REMEMBENCH, a **29** and **16** point absolute gap respectively.
- Success rate scales with memory window from **16%** at n=1 to **42%** at n=512 timesteps without saturation, and ablated gating variants drop to **22-36%** success.

## Takeaways

> [!tip] Key Insights
> - Filtering retrieved memory (gating), not just storing more of it, is what prevents spurious history-action correlations from degrading policy performance.
> - Local-to-global hierarchical compression is a general recipe to make attention-based memory computationally tractable over long, high-dimensional sensory histories.
> - A benchmark spanning multiple memory categories (spatial, prospective, object-associative, object-set) is needed to avoid rewarding siloed, task-specific memory hacks.

## Detailed Report

### 1. Broader Research Landscape

The development of generalist visuomotor policies through imitation learning represents a significant area of advancement in robot learning. These policies enable robots to perform a variety of tasks by learning from human demonstrations. However, a common limitation in many existing visuomotor policies is their reliance on immediate sensory input, rendering them "myopic" and unable to leverage past experiences to guide decisions, particularly in situations involving partial observability.

Short-term memory, which involves retaining information over seconds to minutes, is a fundamental aspect of intelligent behavior in humans and is crucial for many everyday robotic tasks, such as remembering the location of a recently seen object or executing a task over a specific duration. Current visuomotor policies often lack explicit mechanisms for robust short-term memory. While transformer backbones are commonly used, a naive extension to incorporate long context windows faces two primary challenges: susceptibility to irrelevant information within the context window, leading to spurious correlations and degraded performance, and a significant increase in computational and memory footprint that scales linearly or quadratically with context length, making it inefficient for processing high-dimensional sensory inputs over extended temporal sequences.

Prior approaches to memory in machine learning include recurrent neural networks (RNNs) like LSTMs and state-space models such as Mamba, which compress history into hidden states. Transformers have been introduced to address some limitations of RNNs by decoupling memory capacity from parameters and enabling direct access to representations, but they present new challenges regarding context length and token costs. In visuomotor policies specifically, short-term memory has been handled by recurrent policies, but these often struggle with scaling to long-horizon manipulation tasks where relevant information might be separated by hundreds of timesteps. Some transformer-based policies either discard history or employ aggressive compression, losing fine-grained temporal information. More specialized approaches incorporate modules for spatial memory or use auxiliary objectives like Past-Token Prediction (PTP) to reconstruct past tokens. The field currently lacks a generalizable and efficient mechanism for scaling short-term memory in visuomotor policies that can handle diverse, long-horizon tasks.

Furthermore, existing embodied AI benchmarks either probe memory indirectly (e.g., ALFRED, Habitat MultiON) or focus on specific, narrow aspects of memory (e.g., spatial memory in MemoryBench). This fragmentation makes it challenging to holistically assess and foster the development of general memory mechanisms in robots. There is a need for a comprehensive benchmark that spans various categories of short-term memory relevant to visuomotor control, encouraging unified architectural solutions rather than task-specific ones. This work aims to bridge these gaps by introducing an architecture designed for scalable short-term memory and a benchmark to systematically evaluate it.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a visuomotor policy architecture capable of effectively leveraging short-term memory to address long-horizon tasks, thereby moving beyond the limitations of policies that rely solely on immediate sensory input.

The motivation for this work stems from several key observations and challenges in current robot learning:

- **Addressing Policy Myopia:** Many current visuomotor policies are "myopic," meaning they operate based only on immediate sensory information. This limits their capability in tasks requiring recall of past events or maintaining intentions over time, such as retrieving an object that is no longer visible or performing sequential actions with timed intervals. The research aims to imbue policies with a form of short-term memory to guide decisions based on recent experiences.
- **Overcoming Scalability Issues in Transformer-based Memory:** While transformers offer a framework for incorporating context, a naive extension to use long context windows for visuomotor policies presents two significant drawbacks. First, the attention mechanism in transformers can be susceptible to irrelevant information within the context window, leading to the formation of spurious correlations that degrade performance, particularly in behavior cloning where errors can compound. Second, the computational and memory costs of processing high-dimensional visual inputs over long temporal sequences scale unfavorably, making long-horizon memory inefficient. The research is motivated to address these efficiency and robustness challenges.
- **Enabling Robustness to Partial Observability:** Many real-world robotic tasks operate under partial observability, where the current observation alone is insufficient to determine the correct action. Short-term memory is essential to resolve ambiguities that arise from visually identical inputs requiring different actions (e.g., distinguishing between "just grasped" and "about to place" an object). The work seeks to enhance policy robustness by enabling them to condition actions on a rich history of interactions.
- **Developing General Memory Mechanisms:** Existing benchmarks often test memory indirectly or focus on specific memory types. This encourages the development of siloed, task-specific solutions rather than generalizable memory mechanisms. A key motivation is to introduce a systematic and diverse benchmark that explicitly evaluates various categories of short-term memory, fostering the creation of unified memory architectures that can generalize across different visuomotor tasks.
- **Improving Performance on Both Memory-Dependent and Standard Tasks:** The researchers hypothesize that augmenting policies with short-term memory can not only improve performance on tasks explicitly requiring memory but also on standard visuomotor tasks not primarily designed for memory testing, by providing additional context that reduces ambiguity and multimodality in action distributions.

In summary, the motivation is to create a more intelligent, context-aware robotic agent by developing a scalable, efficient, and robust short-term memory mechanism within visuomotor policies, supported by a comprehensive evaluation benchmark.

### 3. Methodology and Approach

The researchers introduce **PRISM (Policy Architecture with Short-Term Memory)**, a transformer-based architecture designed to integrate short-term memory into visuomotor policies, and **REMEMBENCH**, a benchmark for evaluating these capabilities.

**Problem Formulation and Policy Training:**
The problem is framed as imitation learning under partial observability. The policy, $\pi_\theta$, learns to predict actions $a_t$ based on a sequence of past sensory inputs $o_{\le t}$, past actions $a_{<t}$, and a task language instruction $l$. Training is performed via behavior cloning, minimizing a loss function that matches the expert action distribution, $p_\theta(a_t | o_{\le t}, a_{<t}, l)$. During inference, the policy operates autoregressively, accumulating observation and action tokens in a context window of fixed memory budget $n$.

**PRISM Architecture:**
PRISM extends the standard transformer architecture with two core components:

1. **Gated Attention for Selective Information Filtering:**
 - **Motivation:** Standard transformers with long context windows can be susceptible to irrelevant information, leading to spurious correlations and performance degradation. The softmax operation in attention distributes weights across the history, potentially amplifying noise.
 - **Mechanism:** PRISM incorporates a post-attention gating mechanism. After the attention output $z$ is computed (softmax-weighted value aggregation), it is modulated by a learnable gate $g(x)$, where $x$ is the input to the transformer block. The gate $g(x)$ is implemented as an MLP with sigmoid activation, producing a vector of values between 0 and 1. The gated output $\tilde{z} = g(x) \odot z$ (element-wise multiplication) is then projected and incorporated via a residual connection. This allows the model to adaptively suppress irrelevant information based on the current input features.

2. **Hierarchical Architecture for Reducing Memory and Compute Footprint:**
 - **Motivation:** Naively attending to all tokens from $n$ timesteps, where each timestep contributes visual, proprioceptive, and action tokens, results in quadratic computational and memory costs during training ($O((nk_{tot})^2)$) and linear costs during evaluation ($O(nk_{tot})$). This becomes prohibitive for long sequences.
 - **Mechanism:** PRISM employs a hierarchical design. At each timestep, a **local memory encoder** first processes the current timestep's high-dimensional sensory information (images, proprioception) using a transformer block. A perceiver-style resampler then compresses these $k_{tot}$ tokens into a smaller, compact set of summary tokens (e.g., $k_{tot}/m$). A **global memory encoder** then performs attention over these concatenated compressed summary tokens from across all past timesteps. This factors a single expensive computation into two cheaper stages, reducing the total training-time compute to $O(nmk_{tot} + (nk_{tot}/m)^2)$ and evaluation-time compute/memory by a factor of approximately $m$. A residual skip connection broadcasts global information back to the local memory encoder, preserving per-token individuality while injecting global context.

**REMEMBENCH Benchmark:**
REMEMBENCH is a benchmark specifically designed to systematically evaluate short-term memory in visuomotor policies, guided by cognitive science literature. It aims to encourage general memory mechanisms.

- **Structure:** It comprises eight diverse household manipulation tasks built on the ROBOCASA environment, spanning four categories of short-term memory. Each task provides 50 expert teleoperated demonstrations.
- **Memory Categories:**
 - **Spatial Memory:** Recalling object locations. Tasks: "Retrieve Fruit," "Retrieve Oil."
 - **Prospective Memory:** Retaining intentions over a delay and executing them at the right time. Tasks: "Cook Meat," "Cook Meat and Vegetable."
 - **Object-Associative Memory:** Recalling object-location associations. Tasks: "Wash and Return to Container," "Wash and Return to Original Spot."
 - **Object-Set Memory:** Maintaining and updating sets of multiple objects over time. Tasks: "Microwave Breadsticks," "Relocate Bowls."

**Experimental Design:**
PRISM is evaluated against a range of baselines grouped by their memory mechanisms:
- **Recurrent Baselines:** LSTM, Mamba.
- **Segment-level Recurrent Transformers:** Transformer-XL (TrXL), Gated Transformer-XL (GTrXL).
- **Transformer Variants:** Linear-attention transformer.
- **Visuomotor Policy Architectures for Partial Observability:** Past Token Prediction (PTP), Scene Memory Transformer (SMT), SAM2Act++.

Evaluations are conducted on REMEMBENCH, standard benchmarks like ROBOCASA and LIBERO, and a real-world adaptation of a REMEMBENCH task. Performance is measured by success rates. Ablation studies are performed on gated attention and hierarchical architecture.

### 4. Main Findings and Results

The experiments demonstrate PRISM's performance improvements and efficiency gains across various evaluation scenarios.

**Performance on REMEMBENCH (Q1):**
- PRISM achieved an average success rate of 41%, outperforming all baselines on REMEMBENCH.
- Recurrent models (LSTM: 12%, Mamba: 25%) and segment-level recurrent transformers (TrXL: 15%, GTrXL: 26%) showed lower performance, attributed to challenges in long-horizon credit assignment and gradient vanishing.
- Linear-Attention (22%) also performed lower, likely due to forgetting over long horizons.
- Prior attention-based methods struggled to regulate information: PTP (28%) did not filter irrelevant information, SMT (36%) discarded fine-grained temporal information, and SAM2Act++ (22%) relied on task-specific spatial coordinate storage without broader semantic understanding.
- PRISM demonstrated an absolute improvement of 5-12% over the strongest baseline (SMT, 36%).

**Real-World Results (Q1):**
- On a real-world adaptation of the 'Wash and Return to Container' task, PRISM achieved a 30% success rate. This was higher than the PTP baseline (15%) and significantly higher than a policy without memory (0%).

**Performance on Standard Benchmarks (Q2):**
- PRISM with memory (n=256) improved performance on benchmarks not explicitly designed to test memory.
- On ROBOCASA, PRISM achieved 43% success, an absolute 11 percentage point (pp) improvement over its no-memory variant (32%). It also outperformed GR00T-N1-2B fine-tuned on ROBOCASA by 11 pp.
- On LIBERO, PRISM achieved an average success of 89%, an absolute 12 pp improvement over its no-memory counterpart (77%). It also outperformed pretrained OpenVLA fine-tuned on LIBERO by 15 pp. These improvements are attributed to PRISM's ability to disambiguate visually identical inputs by incorporating recent observations.

**Scalability with Memory Capacity (Q3):**
- PRISM demonstrated scalability with increasing memory size on REMEMBENCH. As the memory window expanded from $n=1$ to $n=512$ timesteps, the success rate consistently increased from 16% to 42%, without reaching saturation. This indicates that PRISM effectively extracts useful information from extended temporal histories.

**Effectiveness of Gated Attention (Q4):**
- The gating mechanism was found to be crucial. Removing the gating led to a 16 pp performance drop (from 42% to 26% on REMEMBENCH).
- A variant using a per-layer scalar "blind gating" (29%) performed substantially worse than PRISM's input feature-aware gating (42%), indicating that feature-wise information selection, rather than just added non-linearity or parameters, is responsible for the gains.
- Attention sink tokens, which allow attention to a dummy token, were ineffective in this context.
- Qualitative analysis for the "Cook Meat" task showed higher gating values aligning with critical task moments (stove on/off), suggesting adaptive information control. A qualitative visualization also showed gating enabling attention to correct past object locations, whereas without gating, attention shifted to irrelevant regions.

**Computational and Memory Efficiency of Hierarchical Architecture (Q5):**
- The hierarchical architecture significantly improved efficiency. At a memory size of $n=512$ timesteps, PRISM achieved a 0.20x reduction in peak GPU memory usage (-80%) and a 0.60x reduction in runtime (-40%) compared to both full attention and hybrid global attention with a sliding window. This efficiency is achieved by processing global operations on a compact set of summary tokens.
- Analysis of the compression factor ($m$) showed that more aggressive compression (larger $m$) generally led to a modest increase in average performance (e.g., from 31% for $m \approx 2$ to 45% for $m \approx 200$) while providing clear efficiency gains.

### 5. Significance and Potential Impact

This research introduces both an architectural contribution and a new evaluation methodology, addressing critical limitations in developing intelligent visuomotor policies.

**Architectural Advancement:** PRISM represents an effective and scalable approach to incorporating short-term memory into visuomotor policies. By combining gated attention and a hierarchical architecture, it addresses two key challenges: the susceptibility to irrelevant information in long contexts and the prohibitive computational and memory costs. The demonstrated ability to scale memory to sequences of up to two minutes, an order of magnitude larger than prior methods, extends the practical applicability of visuomotor policies to more complex and temporally extended tasks. The fact that PRISM achieves this without requiring auxiliary losses or additional supervision indicates a seamless integration with standard imitation learning frameworks.

**Comprehensive Benchmark:** REMEMBENCH fills a gap in existing embodied AI benchmarks by offering a systematic and diverse set of tasks explicitly designed to evaluate various categories of short-term memory. Its foundation in cognitive science and its focus on fostering general memory mechanisms, rather than siloed task-specific solutions, is significant. This benchmark can serve as a standardized tool for future research, promoting the development of more robust and generalizable memory capabilities in robots.

**Improved Robot Capabilities:** The consistent outperformance of PRISM over a range of strong baselines, including those with recurrent architectures and other transformer variants, underscores its contribution to enhancing robot learning. The substantial improvements on both REMEMBENCH tasks and standard benchmarks like ROBOCASA and LIBERO suggest that PRISM can enable robots to perform more reliably in partially observable environments and reduce ambiguities in action prediction. The successful real-world deployment demonstrates its potential for practical applications.

**Foundation for Future Research:** This work establishes a foundation for future investigations into memory-augmented visuomotor policies. The identified challenges and the performance headroom on REMEMBENCH indicate fertile ground for further improvements in perception, control, and memory components. The discussion of limitations, such as the focus on short-term memory, points towards future directions in integrating persistent long-term memory and leveraging internet-scale priors for memory module pretraining, which could further advance the capabilities of generalist robots.
