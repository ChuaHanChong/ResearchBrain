# MosaicMem: Hybrid Spatial Memory for Controllable Video World Models

> [!summary] Summary
> MosaicMem introduces a hybrid spatial memory system for video diffusion models that combines explicit 3D geometry with implicit attention-based learning. The model enables long-horizon, camera-controlled video generation with superior consistency, dynamic object modeling, and manipulability, alongside facilitating real-time autoregressive generation.

## Problem

- Developing consistent, explorable "world simulators" in video diffusion models that maintain object permanence and viewpoint consistency over long durations.
- Existing explicit spatial memory methods struggle with dynamic scenes and limit generative flexibility by relying on static 3D geometric caches.
- Current implicit spatial memory methods suffer from inaccurate egomotion (drift), redundancy, inefficiency in context usage, and difficulty in manipulating latent scene representations.

## Method

- Proposes **MosaicMem**, a hybrid spatial memory approach that lifts 2D patches from observations into 3D space using off-the-shelf 3D estimators, then uses these 3D-localized patches as contextual conditioning for a ==Diffusion== ==Transformer== (DiT).
- Introduces Warped RoPE and Warped Latent mechanisms to align memory patches across time and camera motion in latent space, ensuring geometry-consistent correspondence and addressing coordinate resolution issues.
- Integrates Projective Positional Encoding (PRoPE) as a principled camera conditioning interface within the DiT to achieve precise and controllable camera motion adherence.

## Results

- MosaicMem achieved superior camera motion accuracy (e.g., RotErr 0.51°) compared to explicit (SEVA 1.42°) and implicit (CaM 4.65°) baselines.
- Demonstrated enhanced dynamic object modeling (Dynamic Score 2.58) and significantly higher memory retrieval consistency (SSIM 0.75, PSNR 23.57) over existing methods.
- Enabled minute-level coherent video generation, memory-based scene editing (object manipulation, scene stitching), and an autoregressive variant ("Mosaic Forcing") for real-time generation at **16** FPS with improved VBench metrics over other real-time systems.

## Takeaways

> [!tip] Key Insights
> - A hybrid spatial memory, unifying explicit 3D localization with implicit attention, effectively combines precise geometric consistency with the flexibility to model dynamics and text-driven content.
> - Targeted, patch-level 3D memory retrieval significantly reduces context redundancy compared to full-frame memory, enabling more efficient and persistent long-horizon generation.
> - Advanced warping mechanisms are crucial for maintaining spatiotemporal alignment and high-resolution coordinate information during feature compression and re-projection across views.
