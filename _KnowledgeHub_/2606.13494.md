# NavWAM: A Navigation World Action Model for Goal-Conditioned Visual Navigation

> [!summary] Summary
> NavWAM introduces a navigation world action model that integrates visual foresight, goal-progress estimation, and action generation into a single diffusion-transformer policy for goal-conditioned visual navigation. This approach overcomes the need for external planning, improving real-robot success rates to 79.2% and significantly reducing inference latency compared to prior world models.

## Problem

- Direct navigation policies often lack explicit prediction of future visual consequences, acquiring foresight only implicitly through action supervision.
- Existing Navigation World Models (NWMs) provide explicit visual foresight but depend on computationally intensive external planners (e.g., CEM) for action selection, creating a bottleneck for real-time control.
- The separation between future prediction and action generation limits the direct utility of learned visual foresight for closed-loop control and introduces external dependencies.

## Method

- **NavWAM** represents the current observation, goal, robot state, action chunk, future egocentric observations, and goal-progress value within a shared latent canvas.
- It reformulates ==goal-conditioned== navigation as a joint denoising problem, solved by a pretrained diffusion-transformer video world model (Cosmos Predict2).
- A multi-mode training strategy (policy, world-model, value modes) allows a single model to learn all necessary aspects, complemented by a training curriculum involving simulator pretraining and real-robot fine-tuning.

## Results

- NavWAM achieved a **79.2%** task success rate in real-world closed-loop image-goal navigation on a Diablo mobile robot across 24 episodes, outperforming OmniVLA (**58.3%**) and NWM (**16.7%**).
- On the GO STANFORD offline benchmark, a fine-tuned NavWAM achieved an Absolute Trajectory Error (ATE) of **0.192** and Relative Pose Error (RPE) of **0.070**, demonstrating improved trajectory accuracy over planning-based world models.
- Inference latency and computational cost per action were significantly reduced, operating at approximately **5 Hz** compared to sub-Hz rates for CEM-based baselines (e.g., NavWAM at **205.7 ms** latency versus NWM with N=120 candidates at 233,**831 ms**).

## Takeaways

> [!tip] Key Insights
> - Integrating future observation prediction, goal-progress estimation, and action generation into a single, executable policy formulation enables explicit visual foresight to directly support closed-loop robot control without external planners.
> - A pretrained diffusion-transformer video world model can be effectively repurposed to jointly denoise diverse navigation-relevant information, including actions, future perceptions, and goal-progress values.
> - Robust navigation performance relies not only on predicting future images but also on explicit supervision for actions, states, and goal-progress values, which collectively contribute to improved control accuracy.
