# AR-WAM: A Visual-Conditioned Agent-Ready World Action Model for Robotic Manipulation

> [!summary] Summary
> AR-WAM is a 0.5B-parameter world action model for dual-arm manipulation that drops language conditioning entirely, taking instead a bounding-box visual grounding prompt plus a learnable atomic-operation token. A reasoning expert emits supervisable intent signals and dual-level latent foresight keeps control future-aware, while a detect/execute/query interface lets any agent supply grounding, memory and recovery. It reaches 87.2% average success with 14.1 ms latency.

## Problem

- Natural-language task conditioning is referentially ambiguous when several similar objects sit on a table, so text cannot uniquely identify the manipulation target.
- Policies relearning language understanding duplicate what agents already do best, and their imperfect internal language encoders prevent precise spatial steering.
- Monolithic models entangle understanding, planning, memory and action generation, leaving failures unattributable between wrong intent and improper execution.

## Method

- Task conditioning factorizes manipulation into learnable ==atomic-operation embeddings== plus a normalized ==bounding-box prompt==, participants and style embeddings, fused via ==AdaLN== conditional modulation.
- A **reasoning expert** shares its 0.2B transformer with the ==world action expert== and decodes object mask, terminal end-effector poses and a structured task abstract as supervised intent.
- **Dual-level foresight** aligns ==flow-matched== predictions to an offline ==latent inverse-dynamics foresight gist== and to the backbone's own future reasoning token under stop-gradient.

## Results

- On ten RoboTwin 2.0 tasks AR-WAM leads the randomized setting at **84.2%** average success and reaches **87.2%** clean, versus **87.8%** for Fast-WAM and **68.1%** for the language-conditioned baseline.
- Ablations show swapping the visual prompt for text costs **13.0%** success, cross-attention instead of AdaLN costs **13.8%**, and raw future patch targets instead of the gist cost **10.8%**.
- RMBench totals reach **67.8%** with a local 27B agent versus **61.9%** for the strongest hierarchical baseline; three real Astribot S1 tasks average **71.7%** versus **35.0%**, at **14.09 ms** end-to-end latency.

## Takeaways

> [!tip] Key Insights
> - Spatial bounding-box conditioning is a stronger policy interface than language, and adding text on top of grounding is redundant rather than complementary.
> - Compressed latent foresight targets beat raw future patch features, indicating that the compression itself, not future information volume, makes foresight useful.
> - Keeping the policy Markovian and delegating memory upstream extends horizon by extending agent context, but end-to-end success then inherits the agent's grounding errors on small objects.

## Detailed Report

### 1. Overview

AR-WAM changes what a robot's language-understanding agent passes to its manipulation policy. The authors argue that in agent-driven control, a policy that receives only a sentence must still work out which object or location the words refer to, and errors can come from wrong intent or improper execution. Their alternative is for the agent to mark the target with a box and choose a short skill, leaving the policy to focus on generating the action. In a controlled comparison, this visual condition did better than text.

The agent's box specifies *where* to act, and its atomic operation specifies *what* skill to perform. The model has 0.5B parameters in total, a 0.2B shared transformer plus a frozen 0.3B vision encoder. It predicts action chunks with two foresight signals. The reasoning expert runs once per control cycle, and subsequent action denoising reuses its KV cache.

### 2. A spatial handoff

The box gives the target's location as normalized image coordinates. A learnable atomic-operation token names the short-horizon skill, such as pick, place, handover, or click. The policy is a "world action model." Here that means it is trained to predict future scene representations along with actions, rather than actions alone.

The agent and policy interact through three primitives:

- **detect** turns the agent's language query into a box.
- **execute** runs the policy on the box and skill.
- **query** returns feedback about the execution.

The policy has no language pathway and no recurrent memory. The agent keeps the task history and decides what to do next. Language understanding, planning, memory, and recovery therefore belong to the agent.

### 3. Box versus text, and memory tasks

The clearest controlled test is an ablation on RoboTwin 2.0. Its variants use the same backbone, data budget, and training schedule, and all of them use AdaLN modulation. Performance is measured as average success rate across the task set:

- The visual-prompt model averages 87.2% success.
- Text conditioning averages 74.2%, which is 13.0 percentage points lower.
- Adding text to the visual prompt gives 84.6%, which is 2.6 points below the visual prompt alone.

These results support the visual condition over text in this evaluation. They do not show that boxes always outperform language.

The second comparison uses RMBench, where tasks depend on memory. M(1) tasks require retaining one relevant past observation. M(n) tasks require information across multiple observations or attempts. The same AR-WAM policy was paired with two agents, Kimi-K3 and Qwen3.8-27B. Over the four M(n) tasks, average success was:

- 63.5% for Qwen-driven AR-WAM
- 52.5% for Kimi-driven AR-WAM
- 38.7% for Goal2Skill, the strongest listed memory-augmented baseline

The authors attribute this pattern to delegating memory to the agent. This comparison is between whole agent–policy systems, so it does not isolate delegation alone as the cause of the gap.

AR-WAM does not lead on the five M(1) tasks. There, Cortex averages 75.2%, versus 71.2% for Qwen-driven AR-WAM. The authors point to inaccurate boxes on small objects as one source of errors.

### 4. A clearer contract

The authors propose leaving language-level intent with the agent and giving the controller a spatial target plus an executable skill. They frame this visual, agent-native interface as the right contract between high-level agents and low-level manipulation policies. That framing is their interpretation.

The ablation supports the visual condition in its tested setting. The memory results are compatible with the agent holding the task history. The boundary is agent-side perception: end-to-end performance depends on agent-generated boxes, and grounding small objects is a reported limitation.
