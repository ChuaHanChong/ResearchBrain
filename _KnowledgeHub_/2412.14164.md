# MetaMorph: Multimodal Understanding and Generation via Instruction Tuning

> [!summary] Summary
> This paper introduces a method to enable Large Language Models to both understand and generate visual content through a simple instruction tuning approach

## Problem

- Existing multimodal models often treat visual understanding and generation as separate capabilities requiring complex architectures and extensive training
- Current unified models need substantial architectural changes and large-scale pretraining to handle both tasks
- Unclear how visual understanding and generation abilities relate and influence each other

## Method

- Proposes ==Visual-Predictive Instruction Tuning (VPiT)== that extends standard instruction tuning to predict both text and visual tokens
- Uses a pretrained LLM with ==separate heads for text and vision prediction==, trained jointly on understanding and generation tasks
- Leverages a ==diffusion model== to visualize the predicted visual tokens

## Results

- Model achieves competitive performance on both visual understanding and generation benchmarks
- Visual generation can be unlocked with as little as **200k** samples when jointly trained with understanding data
- Model demonstrates ability to leverage LLM knowledge for generation and perform implicit visual reasoning
- Shows that unified models can be developed effectively from pretrained LLMs without extensive architectural changes

## Takeaways

> [!tip] Key Insights
> - Visual generation ability emerges naturally from improved visual understanding with minimal additional training data
> - Understanding and generation capabilities are mutually beneficial but asymmetric - understanding data contributes more to both abilities
> - LLMs appear to have inherent visual capabilities that can be efficiently unlocked through instruction tuning
> - Joint training with diverse data types improves performance compared to training on generation data alone
