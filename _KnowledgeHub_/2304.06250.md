# RSIR Transformer: Hierarchical Vision Transformer using Random Sampling Windows and Important Region Windows

> [!summary] Summary
> The RSIR Transformer, developed at Southwest Jiaotong University, introduces Random Sampling Windows (RS-Win) and Important Region Windows (IR-Win) to create an efficient hierarchical Vision Transformer. This architecture achieved 83.9% Top-1 accuracy on ImageNet-1K with its tiny variant, outperforming MaxViT-T by 0.3%, and demonstrated superior performance across object detection and semantic segmentation tasks.

## Problem

- Existing Vision Transformers suffered from high computational costs due to global self-attention, hindering practical application for high-resolution images.
- Local window-based self-attention in hierarchical ViTs restricted receptive fields, leading to insufficient global context modeling and reduced model capacity.
- Previous methods for inter-window communication often resulted in complex architectures, fixed patterns, or slow growth of the effective receptive field.

## Method

- A hierarchical Vision Transformer that integrates two parallel self-attention modules: ==Random Sampling Windows (RS-Win)== and ==Important Region Windows (IR-Win)== within each block.
- RS-Win uses randomized token sampling across the entire image to introduce flexible global context modeling with ==linear computational complexity==.
- IR-Win employs ==data-dependent attention==, grouping patches based on an inferred importance map to deterministically focus on salient regions for local interaction.

## Results

- Achieved **83.9%** Top-1 accuracy on ImageNet-1K with RSIR-T (outperforming MaxViT-T by **0.3%**) and **85.1%** with RSIR-B (outperforming MaxViT-B by **0.2%**), demonstrating state-of-the-art performance at competitive GFLOPs.
- Showcased improved data efficiency on small datasets like Caltech-256 and Mini-ImageNet, consistently surpassing MaxViT variants.
- Set new benchmarks on COCO object detection (e.g., RSIR-T achieved **47.6 box mAP**, +0.7 over MaxViT-T) and ADE20K semantic segmentation (e.g., RSIR-T **49.9% SS mIoU**, +0.4 over MaxViT-T).

## Takeaways

> [!tip] Key Insights
> - Combining randomized global context exploration (RS-Win) with deterministic data-dependent local focusing (IR-Win) effectively balances efficiency and rich feature learning.
> - Parallel execution of distinct attention mechanisms within a single block allows for simultaneous incorporation of global and intelligently guided local information, optimizing computational cost.
> - The proposed attention mechanism significantly improves data efficiency and robustness of hierarchical Vision Transformers, making them more suitable for smaller datasets.
