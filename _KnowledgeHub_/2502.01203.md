# KL-Regularized RLHF with Multiple Reference Models: Exact Solutions and Sample Complexity

> [!summary] Summary
> This research introduces the first exact solutions and sample complexity guarantees for Reinforcement Learning from Human Feedback (RLHF) when incorporating multiple reference models. The multi-reference approach consistently improves performance over single-reference methods, with specific theoretical bounds derived for both Reverse and Forward Kullback-Leibler regularization.

## Problem

- Current Reinforcement Learning from Human Feedback (RLHF) frameworks primarily rely on a single reference model, which limits response diversity and can inherit biases.
- The single-reference approach underutilizes the growing ecosystem of diverse pre-trained open-source large language models (LLMs).
- A robust theoretical foundation, including exact solutions and sample complexity guarantees, for integrating multiple reference models into RLHF was previously absent.

## Method

- Formulated multi-reference RLHF problems for both ==Reverse KL== (RKL) and Forward KL (FKL) regularization.
- Derived the first exact closed-form solution for RKL-regularized RLHF with multiple references, introducing a 'generalized escort reference policy' based on a weighted geometric mean.
- Developed an implicit solution for FKL-regularized RLHF with multiple references, utilizing a 'weighted reference policy' based on an arithmetic mean.

## Results

- Multi-reference RLHF significantly outperforms single-reference methods in both online (GRPO on GSM8K) and offline (DPO on UltraFeedback) experiments.
- The proposed exact analytical solution for RKL-regularized RLHF consistently surpasses the performance of an existing lower-bound approximation (MRPO).
- Theoretical analysis established an O(1/n) sample complexity for the sub-optimality gap in RKL-RLHF and O(1/sqrt(n)) for both sub-optimality and optimality gaps in FKL-RLHF. Large-scale DPO experiments showed a multi-reference DPO achieved a **66.1%** win rate, a gain over single-reference DPO baselines (**56.4%** and **59.8%**).

## Takeaways

> [!tip] Key Insights
> - The theoretical framework provides precise mechanisms, such as the generalized escort policy for RKL and weighted policy for FKL, for combining diverse reference models.
> - The analysis shows that incorporating multiple references does not degrade the sample complexity convergence rates for RKL-RLHF's sub-optimality gap compared to single-reference methods.
> - This work provides the first theoretical study of sample complexity for FKL-regularized RLHF, quantifying its data efficiency.
