# GenerativeMPC: VLM-RAG-guided Whole-Body MPC with Virtual Impedance for Bimanual Mobile Manipulation

> [!summary] Summary
> Researchers at Skolkovo Institute of Science and Technology developed GenerativeMPC, a hierarchical cyber-physical framework that unifies semantic understanding from a VLM-RAG module with low-level physical control via whole-body MPC and impedance control for bimanual mobile manipulators. The system demonstrated dynamic adaptation of velocity limits, safety margins, and compliance parameters based on environmental context, achieving a 60% reduction in robot speed near humans and 17.5 mm position accuracy on a physical platform.

## Problem

- A fundamental division exists between high-level semantic reasoning (e.g., from VLMs) and low-level physical control (e.g., classical MPC) in robotic systems, preventing seamless integration.
- Existing robot control methods often use static, predefined parameters for physical interaction properties (stiffness, damping, safety margins), hindering dynamic adaptation to changing contexts or human presence.
- Robots currently lack robust memory mechanisms for experience-driven adaptation of control parameters, requiring continuous retraining or manual tuning of cognitive models for new scenarios.

## Method

- A three-layer hierarchical framework integrates a VLM-RAG module for task planning, a Whole-Body ==Model Predictive Control== (MPC) for trajectory optimization, and a Unified Impedance-Admittance Controller for compliant execution.
- The VLM processes visual and linguistic context to generate structured JSON descriptions, which a Retrieval-Augmented Generation (RAG) module with ChromaDB uses to retrieve validated physical control parameters (velocity limits, safety margins, stiffness, damping) from an experience database.
- The MPC operates at 10 Hz to plan coordinated base and dual-arm trajectories with integrated obstacle avoidance, while the impedance-admittance controller executes these plans at 50 Hz, applying consistent spring-damper dynamics across both the mobile base and manipulator arms for compliant tracking.

## Results

- The robot demonstrated human-aware navigation, automatically reducing its linear velocity by **60%** and increasing base damping when humans were detected, achieving **17.5** mm position accuracy and **1.5**° heading error on hardware.
- In simulation, the system adapted to human hand presence during bimanual reaching by automatically retrieving parameters that reduced arm stiffness (K_i=**8.0**) and increased damping (D_i=**25.0**) and safety margin (**0.15** m), preventing collisions and maintaining safe interaction distances.
- The framework successfully operated on a physical bimanual mobile manipulator using onboard computation (NVIDIA Jetson Orin Nano), with observed sim-to-real performance degradation attributed primarily to communication latency rather than fundamental control issues.

## Takeaways

> [!tip] Key Insights
> - Semantic context derived from visual-language models can be directly grounded into low-level physical control parameters, enabling dynamic and context-aware robot behaviors like speed reduction and compliance modulation during human interaction.
> - Integrating a Retrieval-Augmented Generation (RAG) module with an experience database allows robots to adapt control parameters based on past validated behaviors, creating a self-improving memory mechanism without continuous large cognitive model fine-tuning.
> - A unified impedance-admittance control formulation consistently applied to both the mobile base and manipulator arms provides a cohesive and robust approach to whole-body compliance, simplifying control design for high-DoF bimanual mobile manipulators.
