# Training Language Models to Generate Quality Code with Program Analysis Feedback

> [!summary] Summary
> The REAL framework, developed by researchers from UC San Diego, Microsoft Research, and CausalFlow Inc., trains Large Language Models to generate code that is both functionally correct and free of security vulnerabilities and maintainability issues. It achieves this by leveraging automated program analysis to provide feedback during reinforcement learning, outperforming baselines in joint functionality and security metrics across various code generation tasks.

## Problem

- Large Language Models (LLMs) often generate code with security vulnerabilities (e.g., SQL injection, XSS) and maintainability issues (e.g., missing type annotations), compromising production readiness.
- Traditional supervised fine-tuning for secure code requires prohibitively expensive, manually curated datasets.
- Rule-based post-processing methods for security are brittle and lack generalization to diverse or novel vulnerabilities.

## Method

- REAL employs a reinforcement learning approach using Proximal Policy Optimization (PPO), guided by automated ==program analysis== tools.
- It utilizes static analysis techniques, including information flow analysis for security (18 CWEs) and type checking (MyPy) for maintainability, to provide automated quality feedback.
- A hybrid reward system combines a binary quality reward (from vulnerability detection) with a functionality reward (from unit test pass rates), ensuring a balance between correctness and security.

## Results

- REAL consistently achieved the best overall performance on SafeSQL and SecCodePLT+ datasets, outperforming baselines in both security quality and functional correctness.
- On APPS+, REAL demonstrated superior performance across all maintainability metrics and model sizes, showing excellent scalability.
- Ablation studies confirmed the hybrid reward system is essential, as training with only functionality led to insecure code and only quality led to non-functional code; the hybrid approach yielded substantially higher joint scores.

## Takeaways

> [!tip] Key Insights
> - Automated program analysis can effectively provide scalable and comprehensive quality feedback for training Large Language Models.
> - A hybrid reward mechanism, balancing functionality and quality, is crucial for preventing reward hacking and achieving both correct and secure code generation.
> - The learning progression in reinforcement learning for code generation first optimizes for secure practices, then refines for full functional correctness.
