# Training Language Models to Generate Quality Code with Program Analysis Feedback

> [!summary] Summary
> The REAL framework, developed by researchers from UC San Diego, Microsoft Research, and CausalFlow Inc., trains Large Language Models to generate code that is both functionally correct and free of security vulnerabilities and maintainability issues. It achieves this by leveraging automated program analysis to provide feedback during reinforcement learning, outperforming baselines in joint functionality and security metrics across various code generation tasks.

## Problem

- Large Language Models (LLMs) often generate code with security vulnerabilities (e.g., SQL injection, XSS) and maintainability issues (e.g., missing type annotations), compromising production readiness.
- Traditional supervised fine-tuning for secure code requires prohibitively expensive, manually curated datasets.
- Rule-based post-processing methods for security are brittle and lack generalization to diverse or novel vulnerabilities.

## Method

- REAL employs a reinforcement learning approach using Proximal Policy Optimization (PPO), guided by automated ==program analysis== tools.
- It utilizes static analysis techniques, including information flow analysis for security (18 CWEs) and type checking (MyPy) for maintainability, to provide automated quality feedback.
- A hybrid reward system combines a binary quality reward (from vulnerability detection) with a functionality reward (from unit test pass rates), ensuring a balance between correctness and security.

## Results

- REAL consistently achieved the best overall performance on SafeSQL and SecCodePLT+ datasets, outperforming baselines in both security quality and functional correctness.
- On APPS+, REAL demonstrated superior performance across all maintainability metrics and model sizes, showing excellent scalability.
- Ablation studies confirmed the hybrid reward system is essential, as training with only functionality led to insecure code and only quality led to non-functional code; the hybrid approach yielded substantially higher joint scores.

## Takeaways

> [!tip] Key Insights
> - Automated program analysis can effectively provide scalable and comprehensive quality feedback for training Large Language Models.
> - A hybrid reward mechanism, balancing functionality and quality, is crucial for preventing reward hacking and achieving both correct and secure code generation.
> - The learning progression in reinforcement learning for code generation first optimizes for secure practices, then refines for full functional correctness.

## Detailed Report

### 1. Introduction

Large Language Models (LLMs) have transformed software development through tools like GitHub Copilot, enabling rapid code generation that many developers now rely on for their daily workflows. However, a critical gap exists between the speed of AI-generated code and its production readiness. While LLMs excel at creating functionally correct code, they often produce outputs with security vulnerabilities and maintainability issues that can compromise real-world applications.

This paper introduces REAL (Reinforcement rEwards from Automated program anaLysis), a framework developed by researchers from UC San Diego, Microsoft Research, and CausalFlow Inc. REAL addresses the fundamental challenge of training LLMs to generate code that meets production-quality standards for both functionality and security. The collaboration between academic researchers and industry experts reflects the practical importance of this problem in real-world software development.

### 2. The Problem with Current Code Generation

Current approaches to improving code quality in LLMs face significant limitations. Traditional supervised fine-tuning requires massive datasets of manually curated, vulnerability-free code, which is expensive and labor-intensive to create. Rule-based post-processing methods apply predefined heuristics but are brittle and fail to generalize to novel vulnerabilities.

The authors identify two critical classes of vulnerabilities that plague AI-generated code:

1. **Security Vulnerabilities**: Including SQL injection, cross-site scripting (XSS), command injection, and path traversal attacks that can expose applications to malicious exploitation
2. **Maintainability Issues**: Such as missing type annotations in Python, unreachable code paths, and inconsistent function signatures that lead to technical debt and runtime errors

These problems are particularly acute because they often don't manifest during initial testing but can cause serious issues in production environments. The challenge is developing a scalable method to train LLMs that can simultaneously optimize for functional correctness and code quality without relying on expensive human annotations.

### 3. The REAL Framework

REAL introduces a reinforcement learning approach that leverages automated program analysis to provide feedback during training. The framework's core innovation is its use of static analysis tools as automated "quality evaluators" that can assess generated code for vulnerabilities without requiring human-written examples of secure code.

The system operates on three key principles:

1. **Automated Feedback**: Instead of relying on human annotations to identify secure code, REAL uses program analysis tools to automatically detect vulnerabilities in generated code
2. **Hybrid Reward System**: The framework balances functionality (measured by unit test pass rates) with quality (measured by vulnerability detection) through a weighted reward mechanism
3. **Scalable Training**: By automating the quality assessment process, REAL can train on large datasets without the prohibitive cost of manual security auditing

The framework is designed to be "prompt-agnostic" and "reference-free" for quality assessment, meaning it doesn't require specific prompt engineering or human-written examples of secure code for each task.

### 4. Methodology and Technical Approach

#### 4.1. Vulnerability Detection Through Program Analysis

REAL's vulnerability detector employs sophisticated static analysis techniques tailored to different types of code quality issues:

**Security Analysis**: The system targets 18 Common Weakness Enumerations (CWEs) using information flow analysis. It converts programs into Static Single Assignment (SSA) form and analyzes Control Flow Graphs (CFGs) to identify potential vulnerabilities. The detector traces data flows from "sources" (like user inputs) to "sinks" (like database APIs) to identify cases where untrusted data reaches sensitive operations without proper sanitization.

**Maintainability Analysis**: For Python code, REAL integrates MyPy, a static type checker that analyzes Abstract Syntax Trees (ASTs) to detect issues like missing type annotations, type mismatches, and unreachable code paths.

#### 4.2. Reinforcement Learning with Hybrid Rewards

REAL uses Proximal Policy Optimization (PPO) with a carefully designed reward system:

- **Quality Reward (r_quality)**: Binary signal from vulnerability detection (1 if secure, 0 if vulnerable)
- **Functionality Reward (r_function)**: Standard unit test pass rate
- **Hybrid Reward**: Weighted combination r_hybrid = α × r_quality + (1-α) × r_function

This hybrid approach is crucial because optimizing for quality alone can lead to "reward hacking" where models generate empty or overly conservative code that passes security checks but lacks functionality. The balanced reward ensures models learn to generate code that is both correct and secure.

#### 4.3. Training Process and Learning Dynamics

The training process demonstrates interesting learning dynamics. Initially, models generate code that is both functionally incorrect and vulnerable. Through iterative refinement guided by the hybrid reward, models first learn to implement secure practices (like parameterized queries) but may still have semantic errors. Finally, they achieve both functional correctness and security robustness.

### 5. Experimental Results

The researchers evaluated REAL across three custom-curated benchmarks using Qwen2.5-Coder-Instruct models at 0.5B, 3B, and 7B parameter scales:

- **SecCodePLT+**: Enhanced security-focused dataset with 17 CWE types
- **SafeSQL**: New dataset targeting SQL injection vulnerabilities in realistic database scenarios
- **APPS+**: Augmented programming contest problems with maintainability assessment

#### 5.1. Performance Metrics

The evaluation used a holistic approach that jointly assesses functionality and quality, moving beyond traditional separate evaluations. Key findings include:

**Security Performance**: REAL consistently achieved the best overall performance on SafeSQL across all model sizes, significantly outperforming baselines in both security quality and functional correctness. On SecCodePLT+, REAL led in security quality and joint metrics at 3B and 7B scales.

**Maintainability Performance**: On APPS+, REAL achieved superior performance across all metrics and model sizes, demonstrating excellent scalability with increasing model capacity.

**Ablation Studies**: Critical validation showed that the hybrid reward system is essential. Training with only functionality rewards produced correct but insecure code, while training with only quality rewards produced secure but non-functional code. The hybrid approach achieved substantially higher joint functionality-quality scores.

**Program Analysis vs Unit Tests**: A key finding was that REAL's program analysis-based feedback consistently outperformed traditional safety unit tests for quality assessment, highlighting the robustness and broader coverage of automated static analysis.

### 6. Impact and Significance

REAL represents a significant advancement in making AI-generated code suitable for production environments. The framework addresses several critical challenges:

**Scalability**: By automating quality feedback through program analysis, REAL eliminates the need for expensive human annotations while providing more comprehensive coverage than rule-based approaches.

**Production Readiness**: The focus on security and maintainability directly addresses the gap between rapid prototyping capabilities and production requirements, potentially accelerating development cycles while reducing vulnerabilities.

**Methodological Innovation**: The holistic evaluation paradigm that jointly assesses functionality and quality establishes a more realistic benchmark for code generation models, reflecting real-world software engineering requirements.

**Research Resources**: The three enhanced datasets (SecCodePLT+, SafeSQL, APPS+) provide valuable resources for future research in secure and maintainable code generation.

The work has immediate practical implications for AI coding assistants and could lead to a new generation of tools that proactively guide developers toward more secure and maintainable solutions.

### 7. Conclusion

REAL demonstrates that automated program analysis can effectively guide reinforcement learning to produce LLMs capable of generating production-quality code. By balancing functionality with security and maintainability through a hybrid reward system, the framework addresses a critical gap in current AI-assisted development tools.

The success of REAL suggests a promising direction for future code generation research, where automated analysis tools can provide scalable, comprehensive feedback for training increasingly sophisticated AI coding assistants. As software development becomes increasingly dependent on AI-generated code, frameworks like REAL will be essential for ensuring that the speed of AI-assisted development doesn't come at the cost of security and reliability.

The collaborative effort between academic researchers and industry experts reflects the practical urgency of this problem, positioning REAL as a significant step toward making AI code generation truly viable for enterprise-level software development.
