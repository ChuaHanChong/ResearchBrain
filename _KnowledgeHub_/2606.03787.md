# Worth Remembering: Surprise-Gated Robot Episodic Memory

> [!summary] Summary
> Robotic episodic memory system that gates memory formation via Bayesian surprise computed in V-JEPA-2 latent space, storing only tail-event moments as sparse episodes augmenting a 4D scene graph. Achieves 12% or more gains over prior memory methods on spatio-temporal question answering and state-of-the-art unsupervised event boundary detection on Kinetics-400.

## Problem

- Existing spatio-temporal robot memory systems capture persistent environment state but keep no structured record of discrete past events like an object appearing or a person acting.
- Prior episodic memory systems for embodied AI store observations at fixed intervals, random moments, or hand-designed task-specific triggers with no principled selection criterion.
- No existing system offers a general, deployment-agnostic criterion for deciding which observations are worth retaining as long-term robot memory.

## Method

- **Bayesian surprise gating**: computes a ==diagonal Gaussian predictive distribution== over a sliding window of ==V-JEPA-2== features and measures per-frame ==KL divergence== between consecutive predictives as the surprise signal.
- Robust ==median absolute deviation thresholding== with ==non-maximum suppression== selects local maxima of the surprise score above a sensitivity-controlled threshold to trigger sparse episode storage.
- Integration with DAAAM's ==4D scene graph== adds a surprise-gated episodic memory layer, retrieved via ==Perception-Encoder== text-image similarity for downstream agentic question answering.

## Results

- On OC-NaVQA, surprise-gated memory improves question accuracy by **12.0%**, reduces positional error by **12.4%**, and temporal error by **15.7%** over the DAAAM baseline.
- Ablation against uniform and random episodic memory at equal budget shows surprise gating reaches **0.796** accuracy versus **0.761** for both baselines, with lower positional and temporal error.
- On Kinetics-400 GEBD, the unsupervised online method scores **0.833** average F1, beating supervised and offline baselines like ESTimator at **0.748** and CoSeg at **0.782**, while storing only about **1.7%** of frames.

## Takeaways

> [!tip] Key Insights
> - A prediction-error signal computed in a general self-supervised latent space can serve as a domain-agnostic proxy for what counts as memorable, without deployment-specific training.
> - Selective, surprise-driven storage beats both uniform and random sampling at the same memory budget, showing that when to store matters as much as what is stored.
> - The same M-estimator family (L1 loss, L1 surprise score, median plus MAD threshold) chosen for heavy-tailed robustness generalizes across memory gating and unsupervised event segmentation tasks.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This research addresses a fundamental challenge in robotics: enabling robots to operate effectively over extended time horizons by selectively remembering past events. Existing spatio-temporal memory systems for robots primarily focus on building persistent semantic representations of the environment, such as 3D scene graphs or view-based retrieval methods. These systems are adept at capturing the static state of the environment and how it changes over time, but they generally lack a structured mechanism to record and retrieve discrete "events" that have occurred, independent of the current world state. For instance, they can describe "what exists" but struggle with queries like "where did the chemical spill happen yesterday?" which require knowledge of "what happened" at a specific time and place.

Recent advancements in embodied AI have begun to incorporate episodic storage, typically by compressing observations into latent vectors, storing Vision-Language Model (VLM) generated captions, or retaining visual snapshots. However, a common limitation across these methods is the lack of a principled criterion for selecting which observations are worth remembering. Episodes are often stored at fixed temporal intervals, triggered by task-specific heuristics, or indiscriminately, leading to inefficient memory usage. A robot exploring for hours might accumulate vast amounts of redundant data, while a critical but brief event could be missed if it falls between storage intervals. This highlights the need for efficient, selective memory systems that conserve resources while retaining high-utility information.

The authors draw inspiration from cognitive science, particularly mammalian memory systems, which solve the memory selection problem through prediction error. Theoretical frameworks like the Complementary Learning Systems (CLS) propose that the brain uses hippocampal prediction errors to inform episodic memory encoding. Similarly, predictive coding posits that the brain reacts to mismatches between expectations and observations. Event Segmentation Theory suggests that humans segment continuous experience into discrete events at moments of high prediction error. Bayesian surprise, defined as the Kullback-Leibler (KL) divergence between posterior and prior predictive distributions, has been empirically supported as a robust formalization of this error signal, correlating with human-perceived event boundaries.

While prediction error has been utilized in deep reinforcement learning for intrinsic motivation and exploration, and some systems apply surprise-like signals for tasks such as anomaly detection or context compression, these approaches have not directly addressed the problem of *episodic storage* for robot long-term memory in a general, deployment-agnostic manner. This paper bridges this gap by proposing Bayesian surprise as a principled, cognitively-inspired gating mechanism for forming robot episodic memories, thereby providing a general criterion for deciding *when* and *what* to store in a robot's long-term memory. The work integrates this mechanism with existing robot spatial memory systems, such as 4D scene graphs, to enhance their capabilities in answering complex spatio-temporal queries.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop an effective and efficient method for robots to selectively store and retrieve salient past experiences, addressing the inherent limitations of memory resources in long-term robot operation. This objective is driven by several key motivations:

1. **Grounding Human Instructions in Past Experience:** Generalist robots are increasingly expected to interact with humans and execute complex tasks that often require reference to past events. For example, a human might ask a robot to "Take me to where the golf cart stopped" or "Show me the intersection where the chemical spill happened yesterday." Answering such queries necessitates an episodic memory system that can recall specific occurrences, rather than just the current state or persistent features of the environment. Current robot memory systems are often insufficient for this, as they primarily focus on static scene representations or short-term operational memory.

2. **Addressing Memory Limits and Scalability:** Robots operating over extended durations (e.g., hours or days) continuously perceive vast amounts of data. Storing every observation as an explicit memory is computationally prohibitive and resource-intensive. Therefore, a selective memory mechanism is crucial. The challenge is to identify and retain only those episodes that possess high utility for future tasks without *a priori* knowledge of what those tasks might be. This necessitates a generic criterion for memory selection.

3. **Drawing Inspiration from Cognitive Science:** Human and mammalian memory systems demonstrate remarkable efficiency in selecting what to remember. Cognitive research indicates that prediction error plays a significant role in memory formation, particularly in the hippocampus, which rapidly encodes specific episodes. Moments of "surprise"—when observations significantly mismatch predictions—are identified as critical for driving memory updates and segmenting continuous experience into discrete events. The authors leverage Bayesian surprise, a formalization of prediction error as KL divergence between predictive distributions, as a biologically plausible and principled signal for determining memorability.

4. **Enhancing Robot Perception and Reasoning:** By selectively storing episodes based on surprise, the goal is to provide downstream robot agents with a more curated and meaningful set of past experiences. This augmented memory should enable improved performance in tasks requiring temporal and spatial reasoning, such as question answering, and provide richer contextual information that complements existing spatial memory representations.

In summary, the key objectives are:
- To formalize a **surprise-gated episodic memory formation** paradigm for robotic systems, establishing a principled, cognitively-inspired method for deciding *what* and *when* to store based on prediction error.
- To design and implement an **online, causal, and unsupervised architecture** for computing Bayesian surprise directly from robot visual observations, utilizing a semantically rich, deployment-agnostic latent space provided by a V-JEPA-2 model. This architecture should be capable of storing sparse but notable episodic events.
- To seamlessly **integrate this episodic memory system** with an existing robust spatio-temporal memory framework, specifically DAAAM (a 4D scene graph representation), to provide a more comprehensive and actionable robot memory.
- To **empirically evaluate the utility and effectiveness** of the proposed surprise-gated memory in real-world robotics applications, such as long-horizon spatio-temporal question answering, and to demonstrate its generality for unsupervised video understanding tasks like generic event boundary detection.

### 3. Methodology and Approach

The proposed methodology introduces a surprise-gated mechanism for episodic memory formation in robots, integrated with an existing spatio-temporal scene graph system. The core of the approach involves computing Bayesian surprise in a latent embedding space derived from robot observations and using this surprise signal to selectively store memorable episodes.

#### 3.1. Surprise-Gated Episodic Memory Formation

The central concept is to leverage Bayesian surprise, defined as the KL divergence between a predictive distribution *before* an observation and the updated distribution *after* the observation, as the gating mechanism. This signal is intended to highlight moments where new information significantly deviates from expectations, thus indicating a potentially memorable event.

##### 3.1.1. Latent Space for Surprise Computation

To ensure the surprise signal is meaningful and robust, it must be computed in a feature space that is insensitive to stochastic noise (e.g., minor environmental fluctuations) and is generalizable across various deployment environments.
- **V-JEPA-2 Encoder:** The authors employ a Video Joint-Embedding Predictive Architecture (V-JEPA-2) encoder. V-JEPA models are self-supervised on large, unlabeled video datasets, training by predicting held-out spatio-temporal feature blocks from visible context. This training regimen forces the encoder to capture essential spatio-temporal continuity, motion, and semantic structure while filtering out unpredictable noise.
- **Feature Embedding:** At each timestep, a causal sliding window of $M=64$ most recent frames is fed into the V-JEPA-2 encoder. The output tokens are pooled into a single feature vector, $z_t \in \mathbb{R}^D$, where $D=1024$. Consecutive windows share $M-1$ frames, so changes in $z_t$ primarily reflect the content of the newest arriving frame that was unpredictable from preceding context.

##### 3.1.2. Bayesian Surprise Metric Derivation

- **Local Predictive Model:** A diagonal Gaussian distribution, $p_t = \prod_{d} N(\mu_W[t,d], \sigma_W^2[t,d])$, is fitted over a sliding window of length $W=64$ of past $z$ values. $\mu_W$ and $\sigma_W$ represent the per-dimension running mean and standard deviation, respectively. This Gaussian serves as a local, causal predictive model of the incoming latent features.
- **Surrogate Surprise Score:** The per-frame Bayesian surprise, $s(t)$, is computed as an $\ell_1$ surrogate of the KL divergence:
 $s(t) = \frac{1}{D} \sum_{d=1}^{D} \frac{|z_t[d] - \mu_W[t,d]|}{\sigma_W[t,d]}$
- **Equivalence to KL Divergence:** The authors demonstrate in Appendix A that for this Gaussian model, the Bayesian KL divergence between consecutive predictive distributions $D_{KL}(p_{t+1} \Vert p_t)$ approximates the pointwise surprisal $S_t = -\log p_t(z_t)$ up to a $z_t$-independent constant, especially for large window sizes $W$. This validates the use of the surprisal metric as an indicator of Bayesian surprise.

##### 3.1.3. Episodic Memory Triggering

- **Thresholding:** Memory episodes are stored at local maxima of the surprise signal $s(t)$ that exceed a dynamically determined robust threshold.
- **Robust Threshold Calculation:** The threshold $\tau$ is computed as:
 $\tau = \text{med}(s) + \gamma \cdot \frac{1}{\Phi^{-1}(0.75)} \cdot \text{MAD}(s)$
 where $\text{med}(s)$ is the median of the surprise signal, $\text{MAD}(s)$ is the Median Absolute Deviation, and $\gamma=1.0$ is a sensitivity parameter. The factor $1/\Phi^{-1}(0.75) \approx 1.4826$ is a Gaussian-consistency factor that makes $1.4826 \cdot \text{MAD}$ an unbiased estimator of the standard deviation under Gaussian likelihood, while remaining robust to heavy-tailed distributions.
- **Robustness to Outliers:** The use of $\ell_1$ training loss for V-JEPA, the $\ell_1$ surrogate score for surprise, and the median + MAD threshold are all part of the same M-estimator family, which enhances stability in the presence of outliers common in high-dimensional feature trajectories. An $\ell_2$-norm would amplify such outliers.
- **Non-Maximum Suppression (NMS):** After thresholding, NMS is applied to deduplicate closely clustered peaks, ensuring only distinct, significant events are recorded.
- **Episode Content:** Each triggered event (a "surviving peak") generates an episode record containing: the trigger timestamp, the robot's pose at that moment, a short window of 8 frames around the trigger, the computed surprise score, and a joint vision-text embedding for later retrieval.

#### 3.2. Agentic Retrieval

The surprise-gated episodes augment an existing robot memory system, DAAAM, which maintains a 4D scene graph representation.
- **Integration with DAAAM:** The stored episodes form an additional layer of episodic records within DAAAM's scene graph.
- **Encoding for Retrieval:** For each of the 8 frames in a stored episode, a contrastive text-image embedding model, Perception-Encoder (PE-Core-L14), is used to encode the visual information.
- **LLM-Agent Retrieval:** DAAAM's downstream Large Language Model (LLM)-agent can then retrieve these visual episodes. Retrieval is based on maximizing text-image similarity (across the eight frames of an episode) with a given query, location, or observation time.
- **Reasoning Augmentation:** The retrieved episodes are provided in an image format to the multimodal LLM agent, enriching its contextual understanding and aiding its reasoning process for tasks like question answering.

### 4. Main Findings and Results

The research demonstrates the effectiveness of surprise-gated episodic memory across two distinct evaluation settings: long-horizon spatio-temporal robot question answering and generic event boundary detection.

#### 4.1. Large-scale, Long-term Spatio-temporal Question Answering (OC-NaVQA)

The utility of surprise-gated episodic memories for downstream robotics applications was evaluated on the OC-NaVQA benchmark, which features in-the-wild recordings and questions requiring knowledge of past robot experiences.

- **Overall Performance Improvement:** The proposed "DAAAM + surprise EM (Ours)" consistently improved performance metrics compared to existing methods.
 - **Question Accuracy:** Increased by 12.0% (from 0.711 for DAAAM to 0.796 for Ours).
 - **Positional Error:** Decreased by 12.4% (from 41.75 m to 36.57 m).
 - **Temporal Error:** Decreased by 15.7% (from 1.792 min to 1.510 min).

- **Ablation Study (Table 1):** The ablation study highlighted the importance of the surprise-based selection mechanism.
 - "DAAAM + uniform episodic memory (EM)" and "DAAAM + random episodic memory (EM)" provided some improvement over DAAAM alone but were significantly outperformed by the surprise-gated method. For instance, uniform/random EM achieved 0.761 accuracy, while surprise EM reached 0.796.
 - This demonstrates that merely adding episodic memory is not sufficient; the *selective* nature provided by surprise gating is crucial for high utility. Uniform or random storage can sometimes degrade performance for temporal and spatial queries due to the inclusion of redundant information, which complicates agentic reasoning.

- **Comparison with Other Baselines (Table 2):** The proposed method also outperformed other established spatio-temporal memory systems, such as ReMEmbR (NVILA-Lite-2B/8B) and Concept-Graphs, which typically exhibit lower question accuracy and higher positional/temporal errors.

- **Qualitative Insights:** Surprise-gated memories were found to be beneficial even for questions not explicitly referencing surprising events (e.g., "What was the color of the hat of the person who opened the door for you when you entered the building?"). The system successfully captured the moment of the person opening the door as a surprising event, stored it, and retrieved the visual episode to answer the detailed query. This suggests that human referring expressions often align with noteworthy occurrences.

- **Memory Efficiency:** With a sensitivity threshold $\gamma=1.0$, the method stored an average of 1.28 episodes per minute, resulting in approximately 30 episodes per CODa sequence. This corresponds to storing only 1.7% of all observed frames, demonstrating efficient resource utilization.

- **Limitations and Trade-offs:** While effective, the episodic memories increase token usage by 13% on average and necessitate a multimodal LLM for reasoning.

#### 4.2. Generic Event Boundary Detection (GEBD)

To evaluate the generality of the method in segmenting continuous video into meaningful, context-shifting events, it was tested on the GEBD benchmark using the Kinetics-400 validation set. The evaluation metric is F1-score against a temporal distance threshold.

- **State-of-the-Art Performance:** The proposed method achieved state-of-the-art results among unsupervised and online (causal) approaches.
 - Across relative distance thresholds (0.05 to 0.50), the method consistently outperformed prior supervised, offline (noncausal), and other unsupervised baselines.
 - The average F1-score for "Ours" was 0.833, significantly higher than supervised offline methods like PC (0.817), online supervised methods like ESTimator (0.748), and other unsupervised offline methods like CoSeg (0.782).
- **Method Characteristics:** The strong performance in GEBD demonstrates the method's capacity for unsupervised and causal event boundary detection, meaning it identifies events in real-time without future context or explicit training labels.

#### 4.3. TAPOS GEBD Evaluation (Appendix B)

- **Domain-Specific Performance:** On the TAPOS dataset, which consists of Olympic sports videos, the method was outperformed by other approaches.
 - This is attributed to the dataset's strong domain bias and the nature of its event boundaries, which are often semantically informed by knowledge of specific sports rather than generic context shifts.
 - In such domain-specific scenarios, supervised methods or offline approaches (which can "look ahead" in time) tend to perform better as they can leverage domain knowledge or future context to precisely time semantic event boundaries.

### 5. Significance and Potential Impact

The research introduces a novel, principled, and biologically-inspired approach to robot episodic memory, with significant implications for the development of more capable and autonomous robotic systems.

#### 5.1. Enhanced Robot Autonomy and Interaction

- **Efficient Memory Management:** The core contribution is a robust mechanism for selective memory formation, addressing the critical problem of memory scalability in long-horizon robot operations. By storing only genuinely "surprising" or notable events, robots can conserve computational resources and focus on information most likely to be relevant for future tasks or human queries.
- **Improved Task Grounding:** The ability to retrieve specific past events enables robots to better understand and execute human instructions that refer to historical occurrences ("Take me to where the golf cart stopped"). This is crucial for natural human-robot interaction and for robots to operate effectively in complex, dynamic environments over extended periods.
- **Smarter Question Answering:** The demonstrated performance improvements in spatio-temporal question answering signify that robots can now answer more detailed and complex queries about their past experiences, bridging the gap between perception, memory, and high-level reasoning.

#### 5.2. Validation of Cognitive Science Principles

- The work provides empirical validation for the application of cognitive science theories, particularly the role of prediction error and Bayesian surprise in memory encoding, to artificial embodied agents. This cross-disciplinary approach can foster further research at the intersection of neuroscience, cognitive science, and artificial intelligence, potentially leading to more biologically plausible and intelligent AI systems.

#### 5.3. General-Purpose Video Understanding

- Beyond specific robotics applications, the strong performance in generic event boundary detection on Kinetics-400 indicates that the surprise-gating mechanism is a powerful and general method for segmenting continuous visual streams into meaningful events in an unsupervised and online manner. This has broader implications for video analytics, surveillance, and content summarization, where identifying salient moments without prior knowledge is valuable.

#### 5.4. Foundation for Future Research

- **Advanced Predictive Models:** The current approach uses a causal Gaussian model as a surrogate predictive model. Future work can explore more sophisticated causal video world models (e.g., V-JEPA-2-AC) to generate an even richer surprise signal, potentially capturing more nuanced event boundaries.
- **Temporal Event Representation:** The current episodic memory stores short windows of visual frames. Integrating text-to-video embeddings or developing new retrieval mechanisms could better capture the temporal evolution of events, rather than just static snapshots.
- **Memory Consolidation and Learning:** The paper suggests avenues for future research into memory consolidation, such as encoding frames into compressed representations and using replay of stored episodes to extract statistical regularities and distill context-free knowledge, mimicking neocortical learning.
- **Habituation Mechanisms:** Addressing the limitation of repeated "surprising" subjects continually triggering storage, future work could explore habituation mechanisms to prevent redundant memory formation for recurring non-novel stimuli.

In essence, this research offers a significant step towards creating robots with more human-like, efficient, and context-aware long-term memory capabilities, paving the way for more intelligent and adaptable autonomous agents.
