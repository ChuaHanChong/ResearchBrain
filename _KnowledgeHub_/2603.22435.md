# CaP-X: A Framework for Benchmarking and Improving Coding Agents for Robot Manipulation

> [!summary] Summary
> The research introduces CaP-X, an open-access framework for benchmarking and enhancing "Code-as-Policy" agents in robot manipulation, investigating how agent performance changes with varying levels of human-provided abstraction. It demonstrates that increasing test-time computation through multi-turn interaction and visual grounding allows agents to perform complex tasks using low-level primitives, achieving human-level reliability on several benchmarks and showing robust real-world transfer.

## Problem

- Prior "Code-as-Policy" (CaP) approaches often rely on high-level, human-crafted primitives, making it unclear whether observed performance stems from agent reasoning or embedded human knowledge.
- There was no unified, open-access framework to systematically evaluate CaP agents across varying levels of abstraction, interaction paradigms, and perceptual grounding.
- The extent to which increased test-time computation (e.g., iterative debugging, skill synthesis) could compensate for the removal of high-level primitive scaffolding was not quantified.

## Method

- The **CaP-X** framework was developed, including ==CaP-Gym== for interactive robot coding and ==CaP-Bench== for systematic evaluation of agentic capabilities across varying abstraction levels and interaction modes.
- **CaP-Agent0**, a training-free agentic framework, was designed to augment coding models by integrating ==multi-turn visual differencing==, auto-synthesized and persistent ==skill libraries==, and ==parallel reasoning==.
- **CaP-RL** was introduced to apply ==reinforcement learning== directly to the coding agent, using ==verifiable rewards== to improve code compilation rates and strategic robustness, particularly with abstract API reasoning.

## Results

- CaP-Bench evaluation showed a persistent performance gap between frontier LLMs/VLMs and human experts in single-turn, low-abstraction settings, with performance monotonically increasing with primitive abstraction.
- **CaP-Agent0**, a training-free method, achieved human-level reliability on **4 out of 7** CaP-Bench tasks using low-level primitives, outperformed state-of-the-art training-based VLA methods in instruction robustness on LIBERO-PRO, and demonstrated robust zero-shot real-world generalization.
- **CaP-RL** significantly improved code compilation and strategic robustness for a Qwen2.5-Coder-7B-Instruct model (e.g., **80%** vs **25%** for Cube Lift on the S2 tier), demonstrating successful zero-shot sim-to-real transfer to a real Franka Emika robot with high success rates.

## Takeaways

> [!tip] Key Insights
> - A fundamental trade-off exists between primitive abstraction level and agent expressivity: higher abstraction simplifies tasks but limits behaviors and masks low-level reasoning challenges.
> - Increased test-time computation, through multi-turn interaction and structured visual grounding (Visual Differencing Module), can substantially mitigate performance degradation at lower abstraction levels, enabling robust code generation from atomic primitives.
> - Reinforcement learning applied to code generation over abstract perception APIs can significantly improve policy robustness and achieve minimal sim-to-real transfer gap, as the learned policies are optimized for abstract reasoning rather than raw visual features.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Robot control has historically relied on explicit programming, where human engineers manually design software to decompose tasks, integrate perception and control modules, and manage failure cases. This classical approach, including Hierarchical Task-and-Motion Planning (TAMP), offers robustness, interpretability, and precision but is labor-intensive, challenging to scale, and often results in task-specific solutions with limited generalization capabilities.

In parallel, data-driven Vision-Language-Action (VLA) models have emerged, leveraging large-scale visual-motor datasets to learn policies for continuous, contact-rich tasks. While VLAs demonstrate capabilities in areas like shirt folding and tool use, they are constrained by their training data and design, often lacking interpretability and struggling to generalize to novel robot embodiments or long-horizon tasks without extensive retraining.

Recent advancements in Large Language Models (LLMs) have introduced a third paradigm: "Code-as-Policy" (CaP). This approach utilizes general-purpose coding agents to generate executable code that can orchestrate robot behaviors, thereby potentially bridging the gap between symbolic planning and data-driven control. Prior CaP work has demonstrated the feasibility of this approach, but often relies on high-level, human-crafted primitives (e.g., `stack_objs_in_order`) that simplify tasks by embedding significant human knowledge and abstraction. This reliance makes it difficult to ascertain whether observed performance stems from the agent's reasoning capabilities or the inherent structure provided by these high-level abstractions.

This work, CaP-X, addresses a critical gap in the CaP landscape by systematically investigating the effectiveness of coding agents as the level of human-provided abstraction is varied. It explores how agent performance changes when operating over low-level, atomic primitives (akin to how human developers interface with robot APIs) and quantifies the extent to which increased test-time computation—through mechanisms like iterative debugging, skill synthesis, ensembled reasoning, and multimodal grounding—can compensate for the removal of high-level scaffolding. By providing a unified framework for evaluating and improving code-based robot control, CaP-X seeks to advance the understanding and development of generalist embodied coding agents that can reason robustly over fundamental robot interfaces.

### 2. Key Objectives and Motivation

The primary objective of this research is to establish a unified, open-access framework, CaP-X, for systematically studying and advancing Code-as-Policy (CaP) agents in robot manipulation. This overarching objective is motivated by several key gaps and unanswered questions in the field of embodied AI and robotic control:

1. **Systematic Characterization of Abstraction Impact:** Previous CaP approaches often rely on high-level primitives that incorporate substantial human-engineered task knowledge. The authors observe that it remains unclear how much of the reported performance in robot control is attributable to the agent's inherent reasoning abilities versus the structural simplification provided by these abstract primitives. A key motivation is to systematically characterize how agent performance varies as this human-crafted scaffolding (abstraction level) is progressively reduced, moving towards atomic, low-level perception and control primitives that more closely resemble the interfaces human developers use.

2. **Quantifying the Role of Test-Time Computation:** As agents operate over lower-level interfaces, the complexity of generating correct and robust code increases. The research is motivated to investigate to what extent increased "test-time computation" can mitigate the performance degradation associated with reduced abstraction. This includes exploring the impact of multi-turn interaction for iterative debugging and refinement, structured execution feedback, visual differencing to ground perceptual information, automatic skill synthesis to create reusable code, and ensembled reasoning to improve robustness.

3. **Development of a Principled Evaluation Platform:** The lack of a standardized benchmark that allows for controlled evaluation across varying levels of abstraction, interaction paradigms, and perceptual grounding modalities hinders systematic progress. A core motivation is to create such a platform (CaP-Gym and CaP-Bench) that integrates diverse robot manipulation tasks under a shared primitive design compatible with both simulation and real-world systems. This platform aims to facilitate a principled study of agentic capabilities.

4. **Advancing Training-Free and Reinforcement Learning Approaches for Coding Agents:** The project is motivated to develop and evaluate methods for improving code-based agents. Specifically, it seeks to derive a training-free agentic framework (CaP-Agent0) by incorporating insights from the benchmark results, and to explore the application of reinforcement learning directly to the coding agent (CaP-RL) using verifiable rewards, thereby demonstrating how agents can learn to generate more robust code through environmental interaction.

In essence, the research aims to move beyond anecdotal demonstrations of CaP by providing a rigorous framework to understand the capabilities and limitations of current language and vision-language models in generating programmatic robot control, and to develop generalizable strategies for improving their performance at the fundamental level of robot interaction.

### 3. Methodology and Approach

The CaP-X framework is designed for the systematic evaluation and improvement of code-based robot control agents, encompassing an interactive environment, a benchmark, and two approaches for performance enhancement.

#### 3.1. CaP-Gym: Interactive Robot Coding Environment

CaP-Gym is a hierarchical control framework built on the standard Gymnasium interface, designed to facilitate interaction between coding agents and robot environments.
- **Architecture:** It integrates a Low-Level Environment loop (physics simulator or real world) with a stateful Code Executor loop. A single code environment "turn" involves the execution of a generated code program, which may trigger multiple underlying simulation steps.
- **Integration:** CaP-Gym supports diverse robot manipulation simulators including RoboSuite, LIBERO-PRO, and BEHAVIOR.
- **Primitives:** Computationally intensive perception and control primitives are implemented as stateless services.
 - **Perception Primitives:** Abstract raw sensor data into structured semantic objects. Examples include SAM3 for language-conditioned segmentation and Molmo 2 for open-vocabulary pointing, alongside standard libraries like OpenCV and Open3D.
 - **Control Primitives:** Agents call motion planners or inverse kinematics solvers (e.g., PyRoki) to reason in task-oriented Cartesian space, delegating execution feasibility, collision checking, and reachability constraints to these controllers rather than directly emitting joint-space commands. The design ensures compatibility with both simulation and physical robot systems.

#### 3.2. CaP-Bench: Evaluating Frontier Models

CaP-Bench is a benchmark for systematically evaluating agentic capabilities along three axes:
- **Models Evaluated:** 12 state-of-the-art open- and closed-source language models and vision-language models were tested, including Gemini-3-Pro, OpenAI GPT models (o1, o4-mini, 5.1, 5.2, OSS-20B, 120B), and Claude models (Haiku 4.5, Opus 4.5), Qwen3 235B, Qwen-2.5-Coder-7B-Instruct, Kimi K2 Instruct, and DeepSeek-V3.1-Terminus.
- **Task Suite:** Primary analysis was conducted across 7 core tasks (Cube Lift, Cube Stack, Spill Wipe, Peg Insertion, Cube Re-stack, Two-Arm Lift, Two-Arm Handover). Each task was evaluated with 100 trials per tier. Further analysis extended to tasks from LIBERO-PRO and BEHAVIOR.
- **Protocol:** A Zero-Shot Pass@1 protocol was used. Agents interact with the environment over one or multiple turns, observing execution feedback. The environment is not reset during a trial, allowing only one continuous interaction episode. Performance was compared against human expert-written reference solutions.
- **Evaluation Tiers:**
 - **Single-Turn Benchmarks (S1-S4):**
 - **High-Level (S1 & S2):** Evaluate reasoning with human-designed primitives.
 - **S1 (Privileged):** Uses ground-truth simulation state (object masks and poses) to isolate high-level planning from perception noise.
 - **S2 (Non-Privileged):** Relies on real perception modules processing raw RGB-D inputs, typical for prior work.
 - **Low-Level (S3 & S4):** Primitives are replaced by their constituent low-level APIs.
 - **S3:** Documentation includes usage examples to scaffold low-level composition.
 - **S4:** Usage examples are removed, requiring agents to infer program structure from interface definitions (function signatures and docstrings) alone.
 - **Multi-turn Benchmarks (M1-M4):**
 - **M1 (Text-Only Multi-turn):** Agent receives standard output (stdout) and error traces (stderr) from the Python sandbox after each turn, enabling textual introspection and debugging.
 - **M2 (Multimodal):** Current RGB observation is directly piped into the agent’s context window (only for multimodal models).
 - **M3 (Visual Differencing Module - VDM):** A VLM converts visual observations into structured natural language. In the first turn, it generates a scene description; in subsequent turns, it explicitly describes visual differences and task completion status.
 - **M4 (Low-Level with VDM):** Combines VDM feedback (M3) with low-level primitives and in-context usage examples (S3).

#### 3.3. CaP-Agent0: A Training-Free Agentic Framework

CaP-Agent0 is designed to augment coding models based on insights from CaP-Bench results:
- **Multi-turn Visual Differencing (VDM):** Integrates the VDM (from M3) as part of the per-turn observation, providing structured textual grounding for visual information.
- **Auto-Synthesized and Persistent Skill Libraries:** From successful S3 rollouts, commonly recurring, task-agnostic utility functions are extracted via regular-expression matching and LLM analysis. These functions are then promoted into a reusable skill library that persists across trials, offloading fragile low-level logic.
- **Parallel Reasoning:** Employs an ensemble strategy:
 - **Single-model:** 9 queries to one model (e.g., Gemini-3-Pro) with varying sampling temperatures (0.1 to 0.9).
 - **Multi-model:** 3 queries each to GPT-5.2, Claude Opus 4.5, and Gemini-3-Pro, with varying temperatures (0.1, 0.5, 0.9).
 - A central coding agent synthesizes these candidate solutions into a final code snippet. This applies to both code generation and multi-turn decision-making.

#### 3.4. CaP-RL: Reinforcement Learning on the Coding Agent

CaP-Gym enables direct reinforcement learning on the coding agent itself, using verifiable rewards (RLVR).
- **Methodology:** Group Relative Policy Optimization (GRPO) was applied to post-train a Qwen2.5-Coder-7B-Instruct base model. Training was conducted on the privileged state-based APIs of tier S1 to ensure stable convergence by avoiding noisy reward signals from perception and control errors.
- **Sim-to-Real Transfer:** The approach leverages the abstract nature of API reasoning to achieve minimal sim-to-real gap, as the learned policy is optimized for abstract perception APIs rather than raw visual features.

### 4. Main Findings and Results

The CaP-X framework yielded several findings regarding the capabilities of coding agents for robot manipulation and demonstrated methods for improving their performance.

### 5. Persistent Performance Gap in Single-Turn Evaluation

- A notable gap exists between frontier language models (LLMs/VLMs) and human experts in generating robot control code in a single-turn, zero-shot setting (S4). While closed-source models generally outperformed open-source ones, and newer architectures showed stronger capabilities, none matched the success rate of human-crafted programs.

### 6. Abstraction vs. Expressivity Trade-off

- Task success rates monotonically increased with higher primitive abstraction levels (from S4 to S1). High-level, human-designed abstractions (S1, S2) simplified the problem by reducing the effective search space for models, allowing them to focus on task sequencing.
- However, this performance gain came at the cost of expressivity. Increased abstraction constrained the agent's action space with human priors, masking potential failures in low-level reasoning. Performance degradation at lower abstraction levels (S3, S4) highlighted the inherent difficulty of low-level code synthesis, yet these tiers enabled more expressive behaviors (e.g., hierarchical perception fallback strategies) not possible with fixed high-level primitives. This motivated a focus on agents capable of recovering structure from low-level primitives.

### 7. Mitigation through Multi-turn Interaction and Visual Grounding

- **Text-Only Multi-turn (M1):** Allowing agents to iterate and inspect execution traces (stdout/stderr) consistently improved performance across models, demonstrating the importance of explicit feedback for debugging and error recovery.
- **Raw Multimodal Feedback (M2):** Directly interleaving raw RGB observations paradoxically degraded performance compared to text-only feedback (M1). This was hypothesized to be due to a cross-modal alignment gap, as models are not typically trained to jointly reason over software code and raw physical task images.
- **Visual Differencing Module (M3):** Converting visual observations into structured natural language via VDM substantially outperformed both naive image interleaving (M2) and execution-only feedback (M1). VDM bridged the cross-modal gap by providing semantically relevant textual descriptions of scene changes.
- **Low-Level Primitives with Multi-turn Feedback (M4):** Agents operating over low-level primitives augmented with multi-turn feedback (M4) not only surpassed high-level single-turn performance (S2) but also achieved parity with high-level multi-turn performance (M3). This supported the "test-time compute scaling hypothesis," indicating that robustness can be synthesized at runtime through increased agent reasoning and self-correction over atomic primitives. Iterative interaction (M1-M4) allowed recovery from both coding errors and physical execution failures.

#### 7.1. CaP-Agent0 Performance

- **Performance on CaP-Bench:** By integrating multi-turn visual differencing, a self-synthesized skill library, and parallel reasoning, CaP-Agent0 significantly outperformed single-turn baselines. Despite operating solely on low-level primitives, it achieved success rates comparable to or exceeding human-written programs on 4 out of 7 CaP-Bench tasks, narrowing the performance gap to expert levels.
- **CaP-Bench++ (LIBERO-PRO):** When evaluated on 30 long-horizon manipulation tasks from LIBERO-PRO, CaP-Agent0, a training-free method, demonstrated comparable or superior performance to state-of-the-art *training-based* VLA methods (OpenVLA, π0, π0.5) under initial position and instruction perturbations. CaP-Agent0 was notably more robust to instruction variations, which often caused VLAs to perform poorly.
- **CaP-Bench++ (BEHAVIOR):** On two mobile manipulation tasks (Pick up Radio, Pick up Soda Can) in BEHAVIOR, CaP-Agent0 achieved substantially higher task success rates than the S3 baseline and performance similar to human experts. It mitigated issues like limited field of view and occlusion by repositioning the robot and adapted search strategies, demonstrating recovery capabilities for physical disturbances (e.g., re-sampling grasp poses after an object is knocked over).
- **Real-World Generalization:** CaP-Agent0 was deployed zero-shot on real robot embodiments (Franka Panda, AgiBot G1) without major cross-embodiment modifications. It demonstrated complex embodied reasoning, including mechanical search for occluded objects, multimodal symbolic reasoning (solving a math problem from physical blocks), common-sense physics-aware stacking (placing round objects on square ones for stability), and incorporating human feedback. It also demonstrated tool generalization by using SciPy's RANSAC algorithm for surface normal calculation in an elevator button-pushing task.

#### 7.2. CaP-RL Performance

- **Simulation Results:** On-policy reinforcement learning (GRPO) applied to a Qwen2.5-Coder-7B-Instruct base model, post-trained on the privileged S1 tier, significantly improved code compilation rates and strategic robustness. When evaluated on the S2 tier (noisy perception), the RL-trained model achieved substantial gains over the base model across tasks like Cube Lift, Cube Stack, and Spill Wipe (e.g., 80% vs 25% for Cube Lift). Qualitatively, the RL-trained model learned causal sequencing (grasp before place) and dynamic geometric reasoning (calculating stacking height based on object dimensions).
- **Sim-to-Real Transfer:** The RL-learned policies demonstrated a minimal Sim-to-Real gap, transferring zero-shot to a real Franka Emika robot with high success rates (e.g., 84% for cube lifting, 76% for stacking). This was attributed to the agent being optimized for reasoning over abstract perception APIs, which minimized the visual domain gap.

### 8. Significance and Potential Impact

The CaP-X framework, comprising CaP-Gym, CaP-Bench, CaP-Agent0, and CaP-RL, contributes to the field of embodied AI and robot manipulation by providing a structured, open-access platform for research and development.

**1. Advancing the Study of Embodied Coding Agents:** CaP-X offers a principled methodology to evaluate and improve code-generating agents for robot control. By enabling controlled studies across varying abstraction levels, interaction modes, and learning paradigms, it facilitates a deeper understanding of the capabilities and limitations of current language and vision-language models in generating executable robot code. This is significant for moving beyond demonstrations based on highly abstract APIs towards agents that can operate closer to the fundamental control interfaces of robots.

**2. Quantifying Performance Dependencies:** The research quantitatively demonstrates that while high-level human-crafted abstractions can boost agent performance, they often mask underlying challenges in low-level reasoning and limit expressivity. This finding highlights the importance of evaluating agents on primitive-level performance to ensure robust reasoning rather than reliance on over-engineered, task-specific APIs.

**3. Demonstrating the Power of Test-Time Computation:** The work reveals that increased inference-time computation, through mechanisms like multi-turn interaction, visual differencing, automatic skill synthesis, and ensembled reasoning (as integrated in CaP-Agent0), can substantially mitigate performance gaps. CaP-Agent0's ability to achieve human-level reliability on several tasks using low-level primitives, without task-specific training data, suggests a scalable path towards robust generalist robot policies. This challenges the notion that massive, specialized datasets are the sole path to capable robot agents.

**4. Bridging Sim-to-Real with RL for Coding Agents:** The introduction of CaP-RL, which applies reinforcement learning directly to the coding agent, demonstrates an effective method for improving code generation for robotics. The minimal sim-to-real gap achieved by optimizing reasoning over abstract perception APIs offers a promising direction for developing policies that transfer robustly to the real world, avoiding the complexities of visual domain randomization or real-world data collection for policy training.

**5. Facilitating Future Research Directions:** The findings point to several avenues for future work, including the development of hybrid CaP–VLA policies to combine the strengths of both paradigms (high-level reasoning from CaP, low-level contact-rich control from VLA). It also underscores the need for stronger embodiment-aware planning, more effective visual grounding, and optimized control primitives for agents. By framing robot control as a problem of machine intelligence where various components are co-studied, CaP-X is positioned to serve as a foundational testbed for general-purpose embodied intelligence.
