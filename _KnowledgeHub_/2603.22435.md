# CaP-X: A Framework for Benchmarking and Improving Coding Agents for Robot Manipulation

> [!summary] Summary
> The research introduces CaP-X, an open-access framework for benchmarking and enhancing "Code-as-Policy" agents in robot manipulation, investigating how agent performance changes with varying levels of human-provided abstraction. It demonstrates that increasing test-time computation through multi-turn interaction and visual grounding allows agents to perform complex tasks using low-level primitives, achieving human-level reliability on several benchmarks and showing robust real-world transfer.

## Problem

- Prior "Code-as-Policy" (CaP) approaches often rely on high-level, human-crafted primitives, making it unclear whether observed performance stems from agent reasoning or embedded human knowledge.
- There was no unified, open-access framework to systematically evaluate CaP agents across varying levels of abstraction, interaction paradigms, and perceptual grounding.
- The extent to which increased test-time computation (e.g., iterative debugging, skill synthesis) could compensate for the removal of high-level primitive scaffolding was not quantified.

## Method

- The **CaP-X** framework was developed, including ==CaP-Gym== for interactive robot coding and ==CaP-Bench== for systematic evaluation of agentic capabilities across varying abstraction levels and interaction modes.
- **CaP-Agent0**, a training-free agentic framework, was designed to augment coding models by integrating ==multi-turn visual differencing==, auto-synthesized and persistent ==skill libraries==, and ==parallel reasoning==.
- **CaP-RL** was introduced to apply ==reinforcement learning== directly to the coding agent, using ==verifiable rewards== to improve code compilation rates and strategic robustness, particularly with abstract API reasoning.

## Results

- CaP-Bench evaluation showed a persistent performance gap between frontier LLMs/VLMs and human experts in single-turn, low-abstraction settings, with performance monotonically increasing with primitive abstraction.
- **CaP-Agent0**, a training-free method, achieved human-level reliability on **4 out of 7** CaP-Bench tasks using low-level primitives, outperformed state-of-the-art training-based VLA methods in instruction robustness on LIBERO-PRO, and demonstrated robust zero-shot real-world generalization.
- **CaP-RL** significantly improved code compilation and strategic robustness for a Qwen2.5-Coder-7B-Instruct model (e.g., **80%** vs **25%** for Cube Lift on the S2 tier), demonstrating successful zero-shot sim-to-real transfer to a real Franka Emika robot with high success rates.

## Takeaways

> [!tip] Key Insights
> - A fundamental trade-off exists between primitive abstraction level and agent expressivity: higher abstraction simplifies tasks but limits behaviors and masks low-level reasoning challenges.
> - Increased test-time computation, through multi-turn interaction and structured visual grounding (Visual Differencing Module), can substantially mitigate performance degradation at lower abstraction levels, enabling robust code generation from atomic primitives.
> - Reinforcement learning applied to code generation over abstract perception APIs can significantly improve policy robustness and achieve minimal sim-to-real transfer gap, as the learned policies are optimized for abstract reasoning rather than raw visual features.
