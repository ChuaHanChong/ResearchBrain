# WebSailor-V2: Bridging the Chasm to Proprietary Agents via Synthetic Data and Scalable Reinforcement Learning

> [!summary] Summary
> WebSailor-V2 introduces an open-source web agent that significantly reduces the performance gap between open-source and proprietary systems, achieving state-of-the-art results on six challenging benchmarks including BrowseComp-EN (35.3) and Humanity’s Last Exam (30.6), often outperforming larger proprietary models. This advancement is built on innovations in synthetic data generation and a scalable reinforcement learning framework from Tongyi Lab, Alibaba Group.

## Problem

- A significant performance disparity existed between open-source web agents and powerful proprietary systems, hindering broader accessibility to advanced "Deep Research" capabilities.
- Current training data for web agents lacked sufficient complexity and diversity in logical structures and uncertainty types, limiting generalization to intricate real-world problems.
- Reinforcement Learning (RL) for web agents faced challenges from the high cost, latency, and inconsistency of real-world web interactions and external API calls, impeding scalable and robust training.

## Method

- Developed a comprehensive ==post-training pipeline== for open-source web agents, integrating advanced synthetic data generation, Supervised Fine-Tuning (SFT), and Reinforcement Learning (RL).
- Introduced SailorFog-QA-V2, a novel data construction method that creates dense knowledge graphs and incorporates a wide array of uncertainty definitions to foster complex reasoning.
- Implemented a dual-environment RL framework, combining a high-fidelity simulator for efficient experimentation with a robust real-world tool execution interface to ensure stable and scalable training despite real-world web complexities.

## Results

- WebSailor-V2-**30B**-A3B achieved state-of-the-art performance on six challenging benchmarks, notably scoring 35.3 on BrowseComp-EN and 30.6 on Humanity’s Last Exam, surpassing the **671B** DeepSeek-V3.1.
- The agent demonstrated strong competitiveness with top proprietary systems, including a score of 48.9 on DeepResearch Bench, placing it second only to Gemini-2.5-pro-DeepResearch.
- Supervised Fine-Tuning (SFT) alone provided formidable baseline capabilities, scoring 24.4 on BrowseComp-EN and 23.9 on HLE, establishing a critical foundation for subsequent Reinforcement Learning.

## Takeaways

> [!tip] Key Insights
> - The quality and diversity of training data, alongside the stability of the training environment, are more critical for successful agentic Reinforcement Learning than the specific RL algorithm.
> - An initial strong Supervised Fine-Tuning (SFT) policy is essential to provide a sufficiently dense reward signal, enabling effective exploration in the subsequent sparse-reward RL phase.
> - Generating dense knowledge graphs with varied uncertainty definitions in synthetic data (SailorFog-QA-V2) can significantly enhance an agent's ability to perform complex information retrieval and synthesis.
