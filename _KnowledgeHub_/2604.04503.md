# Memory Intelligence Agent

> [!summary] Summary
> The Memory Intelligence Agent (MIA) framework enhances Deep Research Agents by integrating a brain-inspired memory system within a Manager-Planner-Executor architecture. MIA improved average accuracy by 5.5 percentage points on multimodal benchmarks and 7.5 percentage points on text-only tasks compared to prior memory-based methods, also enabling unsupervised self-evolution.

## Problem

- Deep research agents face ineffective memory evolution, struggling to consolidate historical experiences into refined strategies.
- Existing memory systems for LLMs incur high storage and retrieval costs due to long contexts, often leading to diluted attention and noise.
- Current systems primarily capture factual knowledge, lacking process-oriented memory needed for guiding complex search path planning and strategy reuse.

## Method

- **MIA** introduces a ==Manager-Planner-Executor architecture== that decouples historical memory storage, strategic planning, and dynamic execution.
- It employs a ==dual-memory system== with a non-parametric ==Memory Manager== storing compressed trajectories and a parametric ==Planner== internalizing high-value experiences through training.
- The framework utilizes a ==two-stage alternating Reinforcement Learning== paradigm and ==continual test-time learning== for the Planner, enabling autonomous adaptation in unsupervised environments.

## Results

- MIA achieved an average accuracy of **53.6%** on multimodal datasets and **53.5%** on text-only datasets, surpassing previous memory-based methods by **5.5** and **7.5** percentage points, respectively.
- The framework consistently enhanced the performance of closed-source LLMs (e.g., GPT-5.4, Gemini-3-Flash) on tasks like LiveVQA and HotpotQA, with GPT-5.4 showing up to an **8.9%** accuracy gain.
- An unsupervised self-evolution mechanism allowed MIA to accumulate useful experience and progressively solve previously failed problems, achieving performance comparable to or superior to supervised baselines.

## Takeaways

> [!tip] Key Insights
> - Decoupling memory management and execution through a multi-agent architecture (Manager-Planner-Executor) improves reasoning efficiency and robustness, mitigating long-context limitations.
> - A bidirectional conversion loop between non-parametric episodic memory and parametric strategic knowledge facilitates efficient memory evolution and reduces computational overhead.
> - An alternating RL training approach combined with an unsupervised evaluation framework enables agents to continuously improve planning and execution strategies without explicit ground-truth supervision.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work presented in "Memory Intelligence Agent" (MIA) is situated within the field of Deep Research Agents (DRAs), which aim to integrate the reasoning capabilities of Large Language Models (LLMs) with external tools, such as search engines, to accomplish complex, open-ended tasks. DRAs typically operate through a multi-round paradigm of interleaved reasoning and external information retrieval, building upon tool-augmented LLMs.

As agents engage in more extended, multi-turn interactions, memory systems have emerged as a critical component, enabling agents to accumulate experience, refine search strategies, and improve performance over time rather than re-solving each task from scratch. Existing approaches to agent memory primarily focus on expanding context windows to store traces of search experience. However, these "long-context memory" methods present several limitations when applied to deep research agents. These limitations include:
- **Attention Dilution:** Long contexts can disperse the model's attention, hindering its focus on the current problem.
- **Noise Introduction:** Irrelevant or weakly related content within extensive memory can introduce noise, potentially degrading reasoning accuracy.
- **Storage Challenges:** Continuously growing historical contexts impose substantial storage requirements, particularly for agents operating over prolonged periods.
- **Computational Costs:** Retrieval over massive memory structures incurs increasing computational expenses, leading to inefficiencies.

Furthermore, existing memory systems predominantly capture knowledge-oriented or factual memory, focusing on "what" the result is (e.g., user attributes, historical facts, retrieved documents). Deep research, however, frequently requires process-oriented memory and conceptual knowledge, detailing "how" a result is obtained (e.g., search trajectories, failed attempts, successful reasoning strategies). The objective of memory in deep research is to guide future planning and exploration using historical experiences, rather than merely storing retrieved knowledge.

Prior memory systems that attempt to guide search path planning often employ pre-trained models as planners to generate Chain-of-Thought (CoT) prompting with few-shot examples. These methods face additional challenges:
- **Suboptimal Planning:** Planners typically operate without task-specific training, resulting in less effective planning.
- **Inadequate Example Selection:** Few-shot example selection often relies solely on relevance, neglecting other important dimensions such as quality and frequency.
- **Executor Misinterpretation:** The Executor agent may not adequately interpret and follow planning instructions without task-specific training.

In essence, the broader landscape highlights a need for memory systems that move beyond simple contextual expansion to offer efficient memory evolution, effective strategic planning, and synergistic cooperation between planning and execution components, especially in complex, open-ended research tasks across various modalities. MIA aims to address these identified limitations by introducing a structured memory framework and a co-evolutionary training paradigm.

### 2. Key Objectives and Motivation

The primary objective of the Memory Intelligence Agent (MIA) framework is to enhance the reasoning performance and self-evolution capabilities of Deep Research Agents (DRAs) by integrating brain-inspired memory mechanisms into a structured architecture. The motivation behind MIA stems directly from the limitations observed in existing agent memory systems, particularly in the context of deep research tasks.

The key problems MIA aims to address are:
1. **Ineffective Memory Evolution:** Current methods often struggle to dynamically update and refine their memory over time, leading to static or inefficient utilization of historical experiences.
2. **Increasing Storage and Retrieval Costs:** The reliance on ever-growing "long contexts" for memory results in substantial storage demands and escalating computational costs for retrieval, alongside issues like attention dilution and noise introduction.
3. **Suboptimal Planning and Execution:** Existing Planner components, often operating without specific training, generate suboptimal search plans. Concurrently, Executor agents may lack the necessary training to effectively interpret and act upon these plans, leading to a disconnect between planning and execution.
4. **Limited Process-Oriented Memory:** There is a gap in effectively capturing and leveraging "how-to" knowledge, such as successful reasoning strategies and failed attempts, which is crucial for guiding future exploration in deep research.
5. **Lack of Autonomous Self-Evolution:** Agents often require explicit supervision for memory updates and performance improvement, hindering their ability to adapt and evolve in unsupervised or open-world environments.

To overcome these challenges, MIA proposes several interconnected objectives:
- **Develop a Manager-Planner-Executor Architecture:** This aims to decouple historical memory storage, parametric planning, and dynamic execution, thereby addressing storage bottlenecks and reasoning inefficiencies.
- **Implement Efficient Memory Management:** The goal is to store compressed historical search trajectories (non-parametric memory) while also consolidating these experiences into parametric memory via Planner training, reducing overhead and improving extraction.
- **Enable Synergistic Planner-Executor Co-evolution:** Through a specialized training paradigm, MIA seeks to optimize the interaction between the Planner and the Executor, ensuring alignment between high-level planning and low-level task execution.
- **Facilitate Continuous Test-Time Learning:** The framework aims to allow the Planner to continuously evolve its parametric knowledge during inference, enabling adaptation to new information without interrupting the reasoning process.
- **Establish Bidirectional Memory Conversion:** MIA seeks to create a mechanism for efficient evolution by converting experiences between non-parametric (explicit, episodic) and parametric (implicit, internalized) memory forms.
- **Incorporate Autonomous Self-Assessment and Correction:** By integrating reflection and unsupervised judgment mechanisms, MIA intends to enhance reasoning robustness and enable continual self-evolution even in sparsely annotated or unsupervised open-world scenarios.

Ultimately, MIA is motivated by the vision of creating more intelligent, efficient, and adaptable deep research agents that can effectively learn from experience and autonomously improve their performance over their operational lifetime.

### 3. Methodology and Approach

MIA operates through a **Manager-Planner-Executor architecture**, designed to integrate brain-inspired memory mechanisms for lifelong learning. The core reasoning process is structured into three stages: Memory Retrieval, Collaborative Reasoning, and Experience Consolidation, forming a continuous agent loop.

#### 3.1. MIA Framework Architecture

- **Memory Manager:** This component is a non-parametric memory system responsible for storing compressed historical search trajectories. It comprises a memory buffer and a pre-trained, frozen LLM (e.g., Qwen3-32B) for managing the buffer through context prompts. Its role is to organize and retrieve high-value historical trajectories that serve as Chain-of-Thought (CoT) cases.
- **Planner:** A parametric memory agent (e.g., Qwen3-8B), initialized from a pre-trained LLM, tasked with generating search plans for questions. It leverages retrieved historical cases to formulate step-by-step sub-goals.
- **Executor:** Another agent (e.g., Qwen2.5-VL-7B), initialized from a pre-trained Large Multimodal Model (LMM), responsible for executing the plans generated by the Planner. It interacts with the environment using tools and performs reasoning to derive final results.

#### 3.2. MIA Agent Loop: Lifelong Learning

1. **Memory Retrieval:**
 - Initiates with parsing a multimodal query.
 - Once sufficient historical experiences are accumulated, similar past experiences are retrieved.
 - The Memory Manager converts visual inputs into textual captions to align with stored memory units.
 - A **hybrid retrieval strategy** scores each memory based on three dimensions:
 - **Semantic Similarity:** Measures the semantic distance between the current input (question, image caption) and historical questions/captions using an embedding model (e.g., sup-simcse-bert-base-uncased).
 - **Value Reward:** Prioritizes memory units with high success rates (empirical success ratio: `s_i / (u_i + 1)`).
 - **Frequency Reward:** Rewards low-frequency memory units (`1 / (u_i + 1)`) to encourage exploration of diverse knowledge.
 - This process retrieves both successful (positive paradigms) and failed (negative constraints) trajectories to construct a rich contextual prior for planning.

2. **Collaborative Reasoning:**
 - The **Planner**, using retrieved trajectories, generates a step-by-step search plan via a few-shot CoT strategy.
 - The **Executor** interprets this plan, performing task reasoning and interacting with the environment through a **ReAct loop** (Thought-Action-Observation) using external search tools (text-to-text, image-to-image).
 - A **dynamic feedback loop** connects the agents: the Executor reports its status, and the Planner may trigger a **Reflect-Replan mechanism** if an impasse or unexpected feedback occurs. This re-planning is triggered at most once per task.

3. **Experience Consolidation:**
 - An LLM Judger (Qwen3-32B) evaluates the final result.
 - The Memory Manager compresses the current trajectories: images into captions and verbose trajectories into structured workflow summaries.
 - New memory is stored: if a high semantic similarity knowledge unit exists, it is replaced; otherwise, it's added as a new unit. Value rewards and frequency counts of relevant units are updated.
 - A **real-time exploration and update strategy** retrains the Planner with current batches of questions, trajectories, and results, internalizing episodic memory into parametric memory. After training, memory units are selectively cleared to prevent memory explosion.

#### 3.3. Two-Stage Alternating Reinforcement Learning (RL) Training

MIA employs a two-stage alternating RL strategy based on Group Relative Policy Optimization (GRPO) to enhance Planner-Executor cooperation:

1. **Executor RL Training (Stage 1):**
 - Objective: Train the Executor to understand and follow plans, perform deep reasoning, and execute tool calls within the ReAct paradigm. The Planner is frozen as a plan provider.
 - The GRPO objective function (Eq. 1) is modified to focus on Executor-generated tokens, masking tokens generated by tools or the Planner.

2. **Planner RL Training (Stage 2):**

#### 3.4. Test-Time Learning (TTL)

TTL enables online, continuous self-evolution during inference:

- **Non-parametric Memory (Contextual):** The Planner generates multiple candidate plans. The Executor executes these plans, and an LLM Judger evaluates the outcomes. The Memory Manager then extracts and compresses positive paradigms (shortest successful trajectory) and negative paradigms (random failed trajectory) into structured workflow summaries, storing them as explicit contrastive references.
- **Parametric Memory (Internalized):** Executor-generated execution feedback serves as the training signal for the Planner. Rewards are calculated for each plan-trajectory pair, advantages are computed, and the Planner's parameters are updated using the GRPO objective (Eq. 3). This occurs simultaneously with non-parametric memory extraction, creating a positive feedback loop.
- **Meta Plan Memory Strategy:** During exploration in TTL, a lightweight Meta Plan Memory conditionally selects the optimal trajectory from multiple generated rollouts. A Router references examples in this memory to select the highest-quality plan for the final response.

#### 3.5. Self-Evolution in Unsupervised Environments

To enable self-evolution without explicit ground-truth supervision, MIA proposes a novel **unsupervised evaluation framework** mimicking scientific peer review (Reviewer-Area Chair process):

- **Dimensional Orthogonality:** Decomposes the judgment task into specialized dimensions: Reasoning & Logical Consistency (evaluates causal chain), Information Sourcing & Credibility (scrutinizes understanding and factual hallucination), and Result Validity (assesses completeness and task status).
- **Evidence-Based Accountability:** Each reviewer provides "evidence quotes" or "atomic requirements."
- **Conflict Resolution via Meta-Decision:** An Area Chair Agent (Qwen3-32B) performs a meta-analysis of structured JSON outputs from the three reviewers to make a final judgment. This process generates an approximate supervision signal for both non-parametric memory selection and parametric memory updating, enabling continuous self-evolution in open-world scenarios.

### 4. Main Findings and Results

The experiments conducted across eleven diverse benchmarks demonstrate the capabilities of the MIA framework.

#### 4.1. Overall Performance on Multimodal Datasets

MIA achieved the highest overall performance among open-source models on multimodal deep research tasks, with an average accuracy of 53.6. Specifically:
- MIA surpassed previous state-of-the-art (SOTA) memory-based methods by an average of 5.5% accuracy, including improvements of 3.3% on FVQA-test, 6.4% on LiveVQA, and 9.1% on In-house 1.
- A notable observation was that traditional long-context memory methods (e.g., RAG, Mem0, A-Mem) generally performed worse than the "No Memory" baseline, indicating that excessive context can introduce noise and degrade performance. MIA's dual-memory mechanism and online parameter updates effectively mitigate this.
- Using a lightweight Qwen2.5-VL-7B Executor, MIA approached or outperformed several larger closed-source LLMs such as GPT-4o, Gemini-2.5-Pro, and GPT-5.4, and exhibited competitive performance with Gemini-3-Flash. This highlights MIA's ability to achieve high performance not through sophisticated tools, but through effective memory and internalized historical experiences.
- MIA also demonstrated competitive and often superior performance compared to specialized search agents like Deepeyes2, despite utilizing a simpler toolset (basic text and image search).

#### 4.2. Overall Performance on Text-Only Datasets

MIA consistently outperformed alternative methods across all text-only datasets, achieving an average accuracy of 53.5.
- Compared to the strongest baseline, Memento, MIA improved average accuracy by 7.5%, with significant gains of 7.6% on 2Wiki and 8.8% on the challenging GAIA benchmark. This indicates the modality-agnostic effectiveness of MIA's Manager-Planner-Executor architecture and continuous evolution mechanism.

#### 4.3. Training Analysis

- Reward curves for both the Planner and Executor showed an upward trend during training. The Executor's reward curve demonstrated a clearer increase and faster convergence in response length, attributed to more direct and stable feedback signals. The Planner's rewards increased more slowly with larger fluctuations, reflecting the indirect nature of its feedback through Executor actions.
- In the Test-Time Learning (TTL) stage, response lengths adapted to dataset characteristics, becoming shorter for the 2Wiki dataset and longer for the LiveVQA dataset as training steps increased. This suggests that reinforcement learning enables MIA to capture dataset-specific characteristics and enhance reasoning.

#### 4.4. Generalization to Closed-Source Executors

- MIA demonstrated generalization by consistently enhancing the performance of powerful closed-source LLMs (GPT-5.4, Gemini-3-Flash, Claude-Sonnet-4.6) on LiveVQA and HotpotQA, even when only the Planner was trained (as in TTL).
- The improvement margin was inversely correlated with the base capability of the Executor: GPT-5.4 saw the largest gains (+8.9% on LiveVQA, +6.4% on HotpotQA), followed by Gemini-3-Flash and Claude-Sonnet-4.6. This indicates MIA's ability to augment various base models.

#### 4.5. Tool Call Analysis

- Models lacking memory mechanisms (e.g., No-Memory) exhibited low tool usage and poor accuracy, emphasizing the necessity of memory.
- Methods incorporating an explicit Planner (Memento, MIA) performed better than those relying solely on long-context memory or meta-guidance memory, suggesting that active planning is more effective than passive recall of historical experiences.
- MIA, by combining heterogeneous memory components with continual test-time learning, achieved the strongest performance among all memory-based systems.

#### 4.6. Ablation Study

An ablation study confirmed the contribution of each component to MIA's performance:
- The "Memory for Planner" architecture (using memory as a contextual prior for the Planner) significantly improved average accuracy by 3.5% (multimodal) and 4.15% (text-only) compared to the "Base" baseline, while simply introducing non-parametric memory ("Only Memory") led to a slight performance drop.
- The "Reflect" mechanism yielded positive gains (0.43% multimodal, 3.28% text-only) on complex multi-hop reasoning.
- The "Trained Planner" (utilizing a smaller Qwen3-8B with alternating RL training) further boosted overall performance by 2.37% (multimodal) and 1.72% (text-only) compared to using a larger Qwen3-32B as the Planner.
- The online "TTL" mechanism provided an additional substantial increase of 3.23% (multimodal) and 2.64% (text-only).
- Overall, MIA significantly increased average accuracy by 8.94% on multimodal benchmarks and 12.38% on text-only benchmarks compared to the initial baseline.

#### 4.7. Unsupervised Self-Evolution

- Unsupervised MIA achieved performance comparable to supervised baselines on multimodal benchmarks and surpassed almost all supervised baselines on text-only benchmarks (only inferior to supervised MIA), validating the effectiveness of the unsupervised evaluation framework.
- Experiments on continual evolution across multiple epochs in the unsupervised setting showed steady performance improvement (e.g., 59.6% → 61.1% → 61.7% on 2Wiki), indicating that MIA can accumulate useful experience and solve previously failed problems through continual exploration.

### 5. Significance and Potential Impact

The Memory Intelligence Agent (MIA) framework offers several significant advancements that have the potential to impact the development and deployment of Deep Research Agents (DRAs):

1. **Addressing Core Memory Limitations:** MIA directly tackles the inefficiencies and limitations of existing memory systems in DRAs, particularly concerning storage overhead, retrieval costs, attention dilution, and the inability to effectively evolve. By compressing historical trajectories and converting them between non-parametric and parametric forms, MIA provides a more scalable and efficient memory solution.

2. **Novel Manager-Planner-Executor Architecture:** The proposed architecture provides a structured approach to agent reasoning, clearly decoupling memory management, strategic planning, and task execution. This modularity can enhance the interpretability and robustness of complex agents.

3. **Enhanced Reasoning and Planning through RL:** The two-stage alternating reinforcement learning paradigm is a notable contribution, fostering synergistic cooperation between the Planner and Executor. This ensures that planning is optimized for effective execution and that the Executor is adept at interpreting and following instructions, leading to improved task performance across diverse domains.

4. **Continuous Self-Evolution with Test-Time Learning:** The integration of an online test-time learning mechanism allows the agent to continuously adapt and improve during inference, a crucial capability for agents operating in dynamic, open-world environments. This mechanism facilitates the internalization of new experiences into the agent's parameters without interrupting its workflow.

5. **Autonomous Learning in Unsupervised Settings:** The novel unsupervised evaluation framework, inspired by scientific peer review, is significant for enabling agents to self-evolve without constant ground-truth supervision. This capability is critical for deploying agents in real-world scenarios where explicit feedback may be sparse or unavailable, thereby broadening the applicability of DRAs.

6. **State-of-the-Art Performance and Scalability:** MIA's demonstrated superiority over existing SOTA methods across a wide range of multimodal and text-only benchmarks highlights its effectiveness. Furthermore, its ability to significantly enhance both frontier (e.g., GPT-5.4) and smaller, open-source (e.g., Qwen2.5-VL-7B) LLMs underscores its scalability and generalizability. This suggests that MIA can democratize access to advanced agent capabilities by improving the performance of more resource-efficient models.

The potential impact of MIA extends to various applications requiring intelligent information seeking, complex problem-solving, and continuous learning, such as scientific discovery, real-time data analysis, and sophisticated virtual assistants. By providing a robust and evolving memory system, MIA contributes to the development of more autonomous, adaptive, and effective AI agents capable of operating in increasingly complex and dynamic environments. The framework's current focus on deep research tasks suggests future work could explore its extension to broader, more dynamic environments, further solidifying its role in agent research.
