# Force-Aware Residual DAgger via Trajectory Editing for Precision Insertion with Impedance Control

> [!summary] Summary
> Researchers from Xi'an Jiaotong-Liverpool University developed TER-DAgger, a human-in-the-loop imitation learning framework for robotic precision insertion. This framework mitigates covariate shift through force-aware error detection and an optimization-based trajectory editing method, achieving an average 77.2% success rate across various insertion tasks while ensuring compliant interaction.

## Problem

- Imitation learning policies perform poorly in contact-rich precision insertion tasks due to covariate shift (out-of-distribution states), causing failures or damage.
- Human-in-the-loop (HIL) methods for addressing covariate shift require continuous human supervision, limiting scalability for widespread robotic deployment.
- Ensuring compliant and safe robot interaction during contact-rich tasks remains challenging, with existing methods often leading to excessive forces or damage.

## Method

- Proposed Trajectory Editing Residual DAgger (TER-DAgger), a framework combining a force-aware base policy, an error detector, a residual policy, and Cartesian impedance control.
- Implemented force-aware error detection by comparing predicted and measured end-effector forces, triggering human intervention only for out-of-distribution states.
- Developed an optimization-based trajectory editing method to smoothly integrate human corrections with the base policy's trajectory, generating consistent residual training data.

## Results

- TER-DAgger achieved a **77.2%** average success rate across simulation and real-world precision insertion tasks (e.g., **96%** for two-pin plug in real-world), surpassing existing baselines by over **37%**.
- The force prediction error detector demonstrated an average precision of **98.8%** for identifying out-of-distribution states, maintaining **100%** recall of failure cases.
- Ablation studies confirmed that including end-effector force in the base policy and the multi-component trajectory editing for residual data generation were essential for TER-DAgger's performance.

## Takeaways

> [!tip] Key Insights
> - Integrating end-effector force as input into imitation learning policies enhances performance and interaction awareness for contact-rich tasks.
> - Using force prediction error as an error detection mechanism offers high precision for identifying out-of-distribution states in contact-rich scenarios, reducing the need for continuous human supervision.
> - An optimization-based approach to smoothly merge human corrective demonstrations with existing policy trajectories effectively generates high-quality residual training data, improving policy adaptation.
