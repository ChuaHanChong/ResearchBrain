# Effective Reasoning Chains Reduce Intrinsic Dimensionality

> [!summary] Summary
> Effective reasoning chains reduce the intrinsic dimensionality of a task, making it more compressible and easier for a model to learn and generalize from, as evidenced by a 0.93 Spearman rank correlation with generalization performance for a 4B parameter model. This framework offers a quantitative explanation for Chain-of-Thought reasoning benefits, rooted in information theory.

## Problem

- The precise mechanisms by which Chain-of-Thought (CoT) reasoning strategies improve large language model (LLM) generalization are poorly understood, relying on qualitative or conflicting quantitative explanations.
- There is a lack of a principled, robust, and generalizable metric to characterize *why* and *when* specific reasoning strategies are effective.
- Existing metrics like trajectory length or perplexity offer inconsistent or incomplete insights into CoT efficacy, hindering practical guidance for LLM development and data annotation.

## Method

- The authors introduce ==intrinsic dimensionality== (ID) as a quantifiable measure of a task's learnability, defined by the minimum number of model parameters required to achieve a specified performance threshold.
- Intrinsic dimensionality is measured by fine-tuning **Gemma-3** 1B and 4B base models with ==Low-Rank Adaptation== (**LoRA**) using various ranks and adapted layers, sweeping parameter counts.
- They systematically evaluate 14 diverse reasoning strategies, generated by powerful teacher models, on the GSM8K dataset and out-of-distribution stress tests to correlate ID with generalization performance.

## Results

- Intrinsic dimensionality strongly predicts generalization performance, showing a 0.93 inverse Spearman rank correlation with overall test performance for the Gemma-3 4B model, and 0.75 for the 1B model.
- This metric consistently outperformed baseline proxies; trajectory length showed weak positive correlation (0.31 for 4B), and sequence KL divergence exhibited weak or negative correlation (-0.17 for 4B).
- The 'Executed PoT' (Program-of-Thought with actual program execution) strategy consistently exhibited the lowest intrinsic dimensionality and achieved the strongest out-of-distribution generalization across both model sizes.

## Takeaways

> [!tip] Key Insights
> - Effective reasoning strategies reduce the intrinsic dimensionality of a task, making it more compressible and thus easier for a language model to learn and generalize from, even if the explicit output length increases.
> - Intrinsic dimensionality provides a robust, quantitative, and theoretically grounded explanation for CoT effectiveness, outperforming commonly used proxy metrics like trajectory length and sequence KL divergence.
> - The inherent learnability and compressibility of a reasoning task, as captured by ID, is a strong predictor of generalization performance, offering a new perspective on optimizing LLM reasoning.
