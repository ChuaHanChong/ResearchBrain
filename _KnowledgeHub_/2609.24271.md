# ME-Brain-1.0: Memory, Cognition and Action for Evolving Embodied Intelligence

> [!summary] Summary
> ME-Brain is a self-evolving embodied system of three modules: Evolvable Memory, a hierarchical short/mid/long-term multimodal memory graph held outside the context window; Cognitive Core, one model fusing embodied cognition with multimodal agent skills; and Focus-VLWA, an interaction-event-centric vision-language-world-action policy. Together they close an execute-record-evolve-execute loop, reaching 47.88% mean success on RoboMME and 66.7% real-robot success.

## Problem

- Pretrained embodied brains freeze perception, planning and control after training, so deployment-time distribution shifts cannot be resolved through continued physical interaction.
- Robots accumulate successes, failure diagnoses and site-specific fixes during deployment, yet prior systems cannot feed that experience back into models, wasting the learning signal.
- Existing memory systems retain only textual or semantic abstractions in length-limited context, while policies spend computation uniformly on static frames, background pixels and unfiltered history.

## Method

- ==Evolvable Memory== builds an external ==task-parent/event-child memory graph== across short, mid and long-term tiers via a ==recording-consolidation-abstraction== process, with per-module hierarchical retrieval.
- **Cognitive Core** is one model trained by ==SFT==, ==RL== and ==MOPO distillation==, unifying embodied scene understanding, planning, action understanding and replanning with agentic skill invocation and attribution.
- **Focus-VLWA** adds a world expert to a ==pi-0.5== backbone: keyframe actions (1 degree joint, 5 mm gripper), 3x3 ==EventCell== local latents (85.9% fewer world tokens), ==FiLM-style== memory modulation.

## Results

- Cognitive Core's ME-VLM 35B-A3B averages **70.9** across 26 embodied benchmarks and **72.5** on the agent suite, exceeding the strongest comparison model by **8.2** and **9.6** points.
- On RoboMME it reaches **47.88%** mean success, **3.26** points above the strongest baseline; on RoboDojo **21.51** Score and **16.03%** SR, leading second-best by **1.28** and **1.15**.
- On six-task ME-RealBench with a Piper dual-arm robot it scores **69.5** and **66.7%** success, beating DM0.5 by **12.8** and **11.7** points, including **50%** versus **10%** on block-covering.

## Takeaways

> [!tip] Key Insights
> - Decision-relevant signal in manipulation is sparse across time, space and history; concentrating model capacity on keyframes, interaction neighbourhoods and retrieved evidence is the paper's central design bet.
> - Routing history into the action head through cross-attention and feature-wise modulation, rather than the vision-language prefix, keeps backbone context fixed and attention cost linear.
> - Reported gains are architecture-level: the post-deployment self-evolution loop itself is never ablated over long horizons, so continual-improvement claims remain unverified by these experiments.

## Detailed Report

### 1. Overview

A robot completing a long manipulation task may need to recall where an object was before it became occluded, what subtask remains after the scene changed, or why a grasp failed. A frozen model cannot recover that evidence, and feeding an ever-growing history into a single policy makes each decision more expensive. ME-Brain-1.0 responds by making execution itself produce structured experience: Evolvable Memory records and compresses each task; Cognitive Core interprets outcomes and turns validated strategies into skills; and the Action Model draws on selected historical evidence to execute the next step. The authors call this a closed loop of action execution → experience acquisition → experience evolution → improved execution, without model retraining.

The four-step loop couples within-task control (Action Model ↔ physical world) with across-task updates (Evolvable Memory ↔ Cognitive Core ↔ Skill Library). This is the authors' proposed architecture; the paper's quantitative evidence is benchmark and deployment evaluation rather than a months-long learning curve.

### 2. Memory as usable evidence

Evolvable Memory is an external graph independent of the model context window. During each task execution, raw multimodal observations, actions, states, and outcomes are recorded in short-term memory, consolidated into task-level events in mid-term memory, and abstracted across tasks into long-term success conditions, failure patterns, and skill procedures, supporting retrieval, transfer, and reuse in subsequent tasks. Each downstream role pulls the level of abstraction it needs: the Action Model retrieves fine-grained spatiotemporal states for movement, while the Cognitive Core retrieves event relationships for planning and semantic experience for skill reuse, preventing injection of irrelevant content.

A concrete case shows why abstraction level matters. If a cup must be returned after a tablecloth change, "the cup was on the table" is insufficient; multimodal memory preserves the original spatial location and visual context needed to place it correctly.

Left: multimodal observations enter a memory encoder. Bottom: Working Memory holds frames and states in a FIFO. Middle: event consolidation produces Approach, Grasp, Move, and Place records with source links. Top: Experience Memory stores Skill procedures, Success conditions, and Failure patterns, with duplicate merging and stale-information downweighting. Right: current state and task query layer-wise retrieval; selected frames, events, and skills feed cross-attention outputs to VLA execution, VLM planning, and skill reuse. Memory maintenance and long-term persistence are design claims; the paper does not report a lifelong benchmark result.

### 3. Selective action computation

The Action Model combines three forms of selectivity. **Temporally**, dense trajectories are compressed to event-driven keyframes: a new keyframe is retained when a joint changes by more than 1° or gripper displacement exceeds 5 mm, and the model predicts 50 consecutive 14-dimensional keyframe targets rather than fixed-rate motor commands. **Spatially**, EventCell predicts only a 3×3 neighborhood around the next interaction cell in head, left-wrist, and right-wrist views; across ten future chunks this yields 270 local visual tokens instead of 1,920 for the full 8×8 grids—a reported 85.9% reduction in representation length, not a measured end-to-end latency reduction. **Historically**, action features query a separate visual memory bank of up to 32 sampled head-camera frames × 16 tokens; the retrieved evidence generates feature-wise scale and shift modulation inside the action expert rather than appending history to the language prefix.

**(a)** A shared PaliGemma prefix with bidirectional attention feeds both the Action Expert and World Expert. **(b)** Three camera grids (head, left-wrist, right-wrist) each with a 3×3 EventCell predicting 270 local visual tokens versus 1,920 full-grid tokens. **(c)** History-bank cross-attention supplies $\gamma$, $\beta$ scale and shift modulation after RMSNorm inside the action stream. **(d)** Two consecutive 50-keyframe windows receive soft guidance from an event target that may lie beyond the current horizon.

The decisive comparison is selective retrieval and modulation versus context expansion with full history. On RoboMME, ME-Brain's mean success rate is **47.88%**, versus **44.62%** for FrameSampling + Modulation, the paper's strongest listed baseline, with improvement across all four task suites. On RoboDojo—54 task configurations × 24 trials each—ME-Brain averages **21.51 Score** and **16.03% terminal success rate** versus π0.5's **11.41 Score** and **6.91%**. The largest gain appears in the Memory dimension: 25.57 vs 5.78 Score and 24.67% vs 4.56% terminal success rate. The RoboMME comparison supports the combined selective design; the paper does not supply an ablation isolating each component individually.

### 4. Contribution and boundary

ME-Brain's contribution is the connected memory–cognition–action loop: memory preserves evidence at multiple abstraction levels, cognition interprets outcomes and updates skills, and the Action Model selects the relevant subset of that evidence for each physical interaction. The results show strong performance on evaluated memory-dependent tasks and on a real dual-arm robot. Controlled long-term-operation, environmental-change, and skill-reuse ablations are explicitly future work.
