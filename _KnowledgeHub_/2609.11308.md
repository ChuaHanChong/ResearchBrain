# 2AM: Grounding Agent-Side Memory as Guidance for Steerable Action Models in Long-Horizon Manipulation

> [!summary] Summary
> 2AM splits long-horizon manipulation into a multimodal Agent holding all task memory and a single RGB-only, episodically stateless Action Model executing all motion. The Agent emits subtask language plus optional normalized 2D grasp, place, and move hints; the policy trains on demonstration-derived hints with condition dropout, spatial noise, and temporal jitter. On LIBERO-Mem it reaches 76.3% completion versus 14.8% for the best published baseline.

## Problem

- Memory placed inside demonstration-trained policies couples a retry to the failed trajectory preceding it, despite training almost entirely on successful demonstrations.
- Agentic toolboxes add planners, depth, and calibrated geometry, giving several components authority to move the robot and confounding whether gains come from sensing or policy.
- Prior externalized-memory hierarchies pass remembered state to the low-level policy as text only, leaving the bandwidth of that interface untested and motor competence possibly hidden.

## Method

- ==Compositional steering contract==: local language plus independently optional normalized 2D grasp, place, and move points in [0,1000]^2, each valid at a different temporal scale, missing fields omitted not encoded.
- ==Teacher-free supervision== pass recovers subtask, grasp, and place targets from object box centers and move cues from projected end-effector position sampled 10-20 steps ahead.
- Robustness training: ==constrained hint dropout== keeping at least one nonempty field, ==isotropic Gaussian coordinate noise== with clipping, feeding one Qwen3-VL-4B backbone with ==flow-matching action expert== predicting 16-step chunks.

## Results

- On LIBERO-Mem, **76.29%** completion, **63.00%** relaxed success, **11.83%** strict success, versus **14.80%** completion and **0%** strict for the best published baseline SlotSSM.
- Against an aligned reproduction of the same backbone, completion rises **5.50** points and relaxed success **25.58** points, while strict success drops slightly from **12.25%** to **11.83%**.
- Removing all 2D hints and keeping Agent subtask language drops completion to **53.72%** and relaxed success to **19.42%**, so grounded hints add **22.57** and **43.58** points.

## Takeaways

> [!tip] Key Insights
> - Persistent task memory can sit entirely outside the controller when its current consequence is groundable in the present observation, keeping the executor stateless.
> - Measured policy capability reflects interface bandwidth, not just learned skill: an under-specified language-only call understates a policy that grounded hints unlock.
> - Reaching the intended state and stopping exactly there are separate problems; the 63.0% relaxed versus 11.8% strict gap shows steering leaves semantic termination unsolved.

## Detailed Report

### 1. Position Within the Broader Research Landscape

Long-horizon robotic manipulation requires a system to retain information about previous actions and outcomes. For example, a robot may need to remember which of several similar objects it has already moved, how many repetitions have been completed, or which destination was selected earlier in the task. Recent research has addressed this problem in several ways.

One line of work incorporates memory directly into the vision-language-action (VLA) policy through visual history, recurrent state, object-centric representations, or learned memory modules. These approaches allow the action policy itself to use information from previous steps. However, the paper argues that persistent memory inside a demonstration-trained controller can create undesirable coupling between failures and subsequent retries. A policy may inherit a latent representation of a failed trajectory even though its training data predominantly contains successful demonstrations.

A second line of work places VLAs within a larger agentic system. In these systems, a high-level language or vision-language agent plans tasks and may call multiple tools, including geometric planners, object-specific controllers, depth-based perception, motion primitives, or learned policies. Such systems can achieve broader functionality, but their architecture makes attribution difficult. Improvements may result from better sensing or auxiliary motion tools rather than from the VLA itself. Similarly, failures may result from inadequate policy capability or from an interface that does not convey the high-level agent’s physical intention precisely enough.

The paper studies this interface problem in isolation. Its central design choice is asymmetric: the multimodal Agent holds task memory and decides what should happen next, while a single RGB-based Action Model executes all task-relevant movements. The Action Model is episodically stateless and does not receive the task history. Instead, the Agent communicates the current consequence of that history through a structured command containing language and optional two-dimensional spatial hints.

This places the work at the intersection of agentic robotics, steerable VLAs, hierarchical control, and memory-dependent manipulation. Unlike systems that emphasize additional tools or privileged geometry, 2AM deliberately restricts sensing and motor pathways in order to examine whether a richer Agent-to-Action Model interface can make externalized memory actionable.

### 2. Objectives and Motivation

The primary objective is to determine whether long-horizon task memory must reside inside the low-level action policy. The authors propose a narrower hypothesis: for event-scale manipulation tasks, the full interaction history may not need to be available to the Action Model if the Agent can convert the relevant historical information into a compact, grounded command.

The paper distinguishes between two kinds of state:

1. **Fast local control state**, including current object appearance, gripper configuration, contact status, and robot motion.
2. **Slower task state**, including object identity, destination, repetition count, and semantic stage.

The Action Model is expected to infer local control behavior from current RGB observations and robot state. The Agent is responsible for slower task state and for deciding how it should affect the next action segment. This separation is intended to permit the Agent to revise its decision after a failed or incomplete attempt, while allowing the Action Model to restart from the current observation without carrying a persistent latent account of the failure.

A second objective is to test whether language alone provides enough bandwidth to communicate remembered physical intent. A command such as “place the bowl on the plate” may describe the behavior but fail to identify which bowl, which plate, or what local motion should occur next when multiple objects are present. The proposed interface therefore supplements language with optional 2D grasp, place, and move targets.

The study also addresses robustness. In deployment, an Agent may omit a hint, provide an imprecise location, or update a hint slightly earlier or later than expected. The authors therefore train the Action Model with missing conditions, spatial perturbations, and temporally varied motion targets. The aim is to ensure that the system does not depend on perfect high-level annotations.

### 3. Methodology and Approach

#### 3.1. Two-Model Architecture

The 2AM system consists of an Agent Model and an Action Model with an explicit division of responsibilities.

At Agent update step \(k\), the Agent receives the task instruction, a current global or agent-view RGB image, and a consolidated history containing selected observations, prior commands, and visible outcomes. The history retains task variables such as the active object, destination, count, and stage. The Agent outputs a command:

- **Subtask language**, specifying the desired behavior.
- **Grasp target**, identifying the next object instance.
- **Place target**, identifying the intended destination.
- **Move target**, indicating a useful near-term gripper position.

The Action Model receives the current agent-view RGB image, wrist-camera RGB image, robot state, and the current command. It predicts a chunk of 16 absolute end-effector actions. The Agent operates at a slower frequency, updating after each short action chunk, while the Action Model performs local control within the chunk.

The Action Model does not receive task history and carries no persistent state across Agent calls. Nevertheless, it is not memoryless in the sense of being blind to motion: it receives the current robot state, visual observations, and short-horizon action context.

#### 3.2. Compositional Spatial Interface

The three spatial fields correspond to different temporal roles.

- **Grasp target:** Used before contact to identify which object should be acquired. It is removed after the object is visibly held or when the task stage changes.
- **Place target:** Used during transport and release to preserve the destination commitment, including when the destination is distant from or occluded in the wrist view.
- **Move target:** A short-term directional cue derived from a future gripper position. It is not a hard waypoint or a prescribed trajectory.

These fields are optional and independently available. During approach, language, grasp, and move information may be provided. During transport, the grasp field may disappear while place and move remain. During release, the place target may be sufficient. This structure permits one type of error or omission to affect only one aspect of the command.

The coordinates are normalized to a 0–1000 range in the agent-view image. The points are semantic guidance rather than direct geometric commands. The Action Model must still infer feasible grasping, alignment, transport, collision avoidance, and release behavior.

#### 3.3. Demonstration-Derived Supervision

The authors derive the steering labels from synchronized demonstrations rather than asking a language model to describe trajectories. Training data include RGB observations, robot states, actions, stage labels, object boxes or masks, gripper contact, object motion, and projected robot motion.

Object-box centers provide grasp and place labels. The move target is generated by sampling a future time offset between 10 and 20 steps and projecting the robot’s future motion into the image. This future-window sampling prevents the Action Model from associating a move point with one exact temporal offset and provides tolerance for variable Agent update timing.

Action labels follow the original VLA alignment: the policy receives the current end-effector state and predicts the next-frame absolute end-effector pose and gripper command. Action windows may cross subtask boundaries, preserving continuous behavior around grasp, lifting, and release.

The implementation uses a Qwen3-VL-4B backbone and a flow-matching Action Expert. There are no separate grasp, place, or move controllers.

#### 3.4. Robustness Training and Closed-Loop Execution

During training, valid command fields are independently dropped, subject to a nonempty-condition constraint. This creates language-only, point-only, and mixed command examples. Retained spatial points receive Gaussian coordinate noise and are clipped to the valid image range. Together with future-window sampling, these procedures model omission, localization error, and temporal misalignment.

During evaluation, the Agent observes fresh global RGB after each action chunk, updates its consolidated history, and can revise the command. The deployment system uses only task language, agent-view RGB, wrist RGB, and robot state. It does not use depth, segmentation, object identifiers, object poses, online geometry, oracle subgoals, rewards, stage flags, or benchmark completion predicates.

### 4. Main Findings and Results

The experiments use the ten tasks in the LIBERO-Mem benchmark. These tasks include single and repeated bowl or bottle lift-and-return sequences, bowl swapping and rotation, and basket-placement tasks conditioned on prior occupancy. The benchmark is designed so that local manipulation skills recur while history determines the correct object, destination, repetition count, or stage.

The authors compare 2AM with published results for π0, SlotVLA, and SlotSSM, an in-house π0 reproduction using the same Qwen3-VL-4B backbone, dual RGB views, and 16-step action chunks, and a language-only ablation that removes all 2D hints.

The published baselines achieve only **14.8% average completion** for the strongest reported method, SlotSSM. However, the aligned in-house π0 reproduction reaches **70.79% completion**, indicating that implementation and observation differences substantially affect the benchmark comparison. For this reason, the paper treats the reproduced π0 as the primary reference.

Against this aligned baseline, 2AM achieves:

- **76.29% average completion**, compared with 70.79% for reproduced π0.
- **63.00% relaxed success**, compared with 37.42% for reproduced π0.
- **11.83% strict success**, compared with 12.25% for reproduced π0.

Thus, 2AM improves completion by 5.50 percentage points and relaxed success by 25.58 percentage points, but does not improve strict success. Strict success requires completing the full task, including the exact requested repetition count, whereas relaxed success permits completion before a later overshoot. The difference indicates that 2AM more reliably reaches the intended goal sequence but still has difficulty stopping precisely.

The language-only ablation performs substantially worse:

- **53.72% completion**
- **19.42% relaxed success**
- **7.25% strict success**

Adding grounded hints therefore increases completion by 22.57 percentage points and relaxed success by 43.58 points relative to language-only steering. The results support the claim that language identifies the behavior but often lacks sufficient information to bind the relevant object, destination, and local motion.

At the task level, 2AM obtains higher relaxed success on all ten tasks and higher completion on seven. It is particularly stronger than reproduced π0 on the relational and occlusion-heavy tasks, including bowl swapping, bowl rotation, and basket-occupancy conditions. The reproduced π0 has higher strict success on the first six tasks, which are primarily lift-and-return sequences. This pattern suggests that grounded steering is most useful when task history must determine object or destination binding, while exact termination remains a separate control problem.

The reported failure cases include inaccurate grasp localization, incorrect subtask selection, and incorrect destination binding. Noise and dropout training help with imperfect spatial hints, but they cannot repair an incorrect high-level decision by the Agent.

### 5. Significance, Potential Impact, and Limitations

The paper’s main significance is architectural and methodological. It provides evidence that persistent task memory can remain outside the low-level Action Model when the Agent communicates its current physical consequences through a sufficiently expressive interface. The results also show that evaluating an Action Model through language-only commands may underestimate its motor capability if the interface omits essential spatial arguments.

This design could simplify future agentic manipulation systems by separating long-term reasoning from short-horizon motor execution. An episodically stateless controller may be easier to reset, retry, and analyze than a policy with persistent internal memory. The compositional interface also offers a way to diagnose errors: failures can be associated with language reasoning, object or destination grounding, spatial localization, or low-level execution.

The evidence is limited, however. The evaluation uses a single simulated benchmark and tasks whose historical consequences can be expressed in current RGB observations. A 2D interface cannot represent hidden geometry, force, contact history, or detailed continuous trajectories. The paper does not isolate the contribution of each individual hint, evaluate stronger Agent models, or quantify the trade-off between Agent update frequency, latency, and performance. In addition, strict success remains low, and the system has not yet been validated on a real robot.

Overall, the work supports a specific conclusion rather than a universal claim about memoryless control: Agent-side memory can guide an episodically stateless Action Model for a defined class of long-horizon manipulation tasks, provided that the interface conveys both semantic behavior and grounded physical arguments.
