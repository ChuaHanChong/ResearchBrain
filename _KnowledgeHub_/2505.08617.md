# OpenThinkIMG: Learning to Think with Images via Visual Tool Reinforcement Learning

> [!summary] Summary
> Researchers from Soochow University, Microsoft, and other institutions developed OPENTHINKIMG, an open-source framework, and V-TOOLRL, a reinforcement learning method, enabling Large Vision-Language Models to adaptively use visual tools for complex reasoning tasks. This approach improved accuracy on chart reasoning by 29.83 points over baseline models and outperformed GPT-4.1, teaching agents to efficiently invoke tools with visual feedback.

## Problem

- Current Large Vision-Language Models (LVLMs) predominantly rely on textual reasoning, even for visual tasks, contrasting with human-like active manipulation of visual information.
- Existing tool-augmented multimodal reasoning approaches suffer from heterogeneous tool definitions, high costs in generating tool-use trajectories, and limited policy generalization from static supervised fine-tuning.
- The absence of a unified framework complicates the integration of diverse visual tools and hinders systematic development and reproducibility.

## Method

- Introduces ==OPENTHINKIMG==, a comprehensive open-source framework with a unified registry for seamlessly integrating diverse vision tools (e.g., GROUNDINGDINO, SAM, OCR) and LVLM backbones.
- Proposes ==V-TOOLRL==, a novel reinforcement learning paradigm that combines a ==supervised fine-tuning cold-start== with ==Group-wise Proximal Policy Optimization (GRPO)== to learn adaptive tool-usage policies using visual feedback.
- Develops a scalable ==three-stage pipeline== for constructing high-quality vision tool-use trajectories, leveraging GPT-4o for planning, batch tool invocation, and multi-stage filtering with rule-based validation.

## Results

- V-TOOLRL achieved **59.39%** accuracy on the CHARTGEMMA test set, outperforming open-source baselines like TACO-8B (**30.50%**) and COGCOM-13B (**15.07%**), and closed-source GPT-4.1 (**50.71%**).
- The full V-TOOLRL framework provided a **+29.83** point accuracy improvement over the Qwen2-VL-2B base model and a **+7.76** point gain over a text-based RL approach, highlighting the impact of visual feedback.
- During V-TOOLRL training, the average number of tool calls per sample decreased from approximately **0.63** to **0.10-0.12**, while the average output length increased from **~66** tokens to **83-86** tokens, indicating greater efficiency and reasoning depth.

## Takeaways

> [!tip] Key Insights
> - Direct integration of visual tool outputs as feedback into the reinforcement learning process (V-TOOLRL) is crucial for maximizing performance on visually grounded tasks, significantly outperforming text-only RL.
> - Reinforcement learning enables LVLMs to learn highly efficient and parsimonious tool invocation strategies, substantially reducing the number of unnecessary tool calls over time while increasing reasoning complexity.
> - The framework and RL approach equip LVLMs with adaptive behaviors for dynamic tool invocation, moving beyond static demonstrations to foster human-like interactive visual cognition.
