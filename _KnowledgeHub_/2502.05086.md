# REASSEMBLE: A Multimodal Dataset for Contact-rich Robotic Assembly and Disassembly

> [!summary] Summary
> The REASSEMBLE dataset provides a comprehensive, multimodal resource for contact-rich, long-horizon robotic assembly and disassembly, utilizing the standardized NIST Assembly Task Board #1. It includes a unique combination of RGB, proprioceptive, force-torque, audio, and event camera data, along with detailed hierarchical annotations for multi-task learning and anomaly detection.

## Problem

- Existing robotic datasets primarily focus on simple, short-horizon tasks (e.g., pick-and-place) and lack the complexity of intricate physical interactions required for real-world assembly and disassembly.
- Current datasets often lack comprehensive multimodal sensor data, particularly high-quality force-torque measurements and event camera data, which are crucial for understanding contact-rich manipulation.
- There is a need for standardized, comprehensive datasets that support long-horizon tasks, task inversion learning (disassembly), multi-task learning, and anomaly detection in robotics.

## Method

- The REASSEMBLE dataset was created using the standardized NIST Assembly Task Board #1 for collecting assembly and disassembly demonstrations.
- Data was collected via haptic teleoperation of a Franka Emika FR3 robotic arm, recording synchronized multimodal sensor data including RGB cameras, robot proprioception, audio, 6-axis force-torque, and event camera streams.
- Demonstrations are comprehensively annotated with hierarchical temporal action segmentation labels, success/anomaly flags, and structured for motion policy learning and task inversion learning (TIL).

## Results

- REASSEMBLE comprises 4,551 high-level action demonstrations (781 minutes of data), including 4,035 successful and 516 failed attempts, covering 4 actions and 17 objects with balanced distribution.
- A state-of-the-art Temporal Action Segmentation (TAS) model achieved an F1@50 of 44.1% on REASSEMBLE, demonstrating the dataset's increased complexity compared to human-centric datasets.
- Dynamic Movement Primitives (DMPs) demonstrated success rates of 70-100% across pick, insert, remove, and place tasks, with insertions being the most challenging (70% success) for the large gear assembly/disassembly.
- An execution monitoring pipeline achieved 96% accuracy, precision, and recall in anomaly detection using REASSEMBLE's annotations, showing the dataset's utility for building robust systems.

## Takeaways

> [!tip] Key Insights
> - The 'Insert' action is the most challenging, accounting for the highest number of failures due to its multi-step nature and demand for precise alignment and force application.
> - Force-torque data reveals distinct patterns corresponding to different action phases (e.g., free-space movement, contact, pushing, twisting), underscoring its value for understanding contact dynamics.
> - Randomizing the NIST Assembly Task Board #1 and object poses for each trial successfully created diverse interaction points, which is essential for training generalizable robotic policies.
