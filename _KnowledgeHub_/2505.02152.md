# Interleave-VLA: Enhancing Robot Manipulation with Interleaved Image-Text Instructions

> [!summary] Summary
> Interleave-VLA introduces a new paradigm for robot manipulation that processes interleaved image-text instructions, enabling superior out-of-domain generalization and mitigating attentional hallucination in robot policies. The method also allows for flexible, zero-shot instruction following from varied visual inputs and comes with a large-scale, real-world interleaved embodied dataset.

## Problem

- Generalist robot policies primarily use text-only instructions, resulting in limited generalization to novel objects and environments.
- Linguistic commands can be ambiguous and lead to "attentional hallucination," where robots misinterpret visually specific goals.
- A scarcity of large-scale, real-world datasets with interleaved image-text instructions hinders the development of robust multimodal robot policies.

## Method

- Introduce **Interleave-VLA**, a paradigm that adapts existing VLA models to process ==interleaved image-text instructions== via a lightweight module and special tokens.
- Create the Open Interleaved X-Embodiment Dataset, an automatically generated large-scale, real-world dataset by converting text-only robot data using LLMs and VLMs.
- Implement a versatile inference interface for zero-shot instruction following using various visual input modalities, including web images and sketches.

## Results

- Interleave-VLA demonstrates **2x** stronger out-of-domain generalization in simulation and 2-**3x** higher performance on real robots compared to text-only VLA models.
- The approach effectively reduces "attentional hallucination" by providing explicit visual grounding, consistently directing the robot's attention to target objects.
- Robots using Interleave-VLA exhibit zero-shot instruction following with diverse visual inputs like cropped images, web photos, and hand-drawn sketches, and also improves OpenVLA performance by **2x** on VIMA-Bench tasks.

## Takeaways

> [!tip] Key Insights
> - Interleaved image-text instructions offer richer, less biased context, leading to improved generalization and reduced attentional hallucination compared to text-only instructions.
> - Training with cross-modal, interleaved image-text instructions develops robust multimodal representations, enhancing robot understanding even for text-only evaluations.
> - Incorporating diverse instruction image types, including Internet images, alongside task-specific cropped images during training yields optimal performance across various generalization scenarios.
