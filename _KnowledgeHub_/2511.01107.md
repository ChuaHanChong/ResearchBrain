# SLAP: Shortcut Learning for Abstract Planning

> [!summary] Summary
> Researchers developed SLAP, a method integrating reinforcement learning with abstract planning to autonomously discover efficient low-level "shortcuts" for robotic tasks. The approach reduced plan lengths by 32% to 73% across various complex environments and achieved a 100% success rate, significantly outperforming pure reinforcement learning methods.

## Problem

- Addressing long-horizon decision-making in robotics where tasks have sparse rewards and continuous state/action spaces.
- Existing Task and Motion Planning (TAMP) methods use predefined skills, limiting agents to programmed behaviors and often leading to inefficient execution plans.
- Hierarchical Reinforcement Learning (HRL) approaches have shown limited success in complex robotic manipulation, struggling with sparse rewards and generalization.

## Method

- **SLAP** builds a two-level ==planning graph==, combining abstract planning for high-level structure with low-level execution details.
- It autonomously learns efficient "shortcut" policies using Proximal Policy Optimization (PPO) for connections between abstract states.
- Learned shortcuts generalize over objects by identifying relevant objects for a policy's input and applying object substitution at evaluation time.

## Results

- Achieved plan length reductions ranging from **32%** to **73%** in four complex robotic manipulation environments compared to pure planning.
- Maintained a **100%** success rate across all challenging, long-horizon tasks, significantly outperforming pure and hierarchical reinforcement learning baselines (**0%** success in most cases).
- Showcased generalization capabilities to novel object configurations, varying object counts, unseen goals, and robustness in stochastic or partially observable environments.

## Takeaways

> [!tip] Key Insights
> - Integrating classical abstract planning with model-free reinforcement learning allows for the discovery of dynamic, efficient low-level behaviors (shortcuts) beyond human-defined skills.
> - Learned shortcuts, often involving multi-object interactions, enable substantial reductions in task execution time by replacing sequences of sub-optimal predefined actions.
> - Leveraging object-oriented representations from abstract planning allows learned policies to generalize to novel object configurations and counts.
