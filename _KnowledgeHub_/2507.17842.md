# Shop-R1: Rewarding LLMs to Simulate Human Behavior in Online Shopping via Reinforcement Learning

> [!summary] Summary
> Researchers at Michigan State University, Amazon, Northeastern University, University of Illinois Urbana-Champaign, and Northwestern University developed Shop-R1, a reinforcement learning framework that significantly enhances large language models' ability to simulate human online shopping behavior. This framework achieved a 65% relative improvement in exact-action accuracy compared to supervised fine-tuning alone, reaching 27.72% on a real-world shopping dataset.

## Problem

- Large language models (LLMs) often struggle to accurately simulate nuanced, non-deterministic human behavior in interactive web environments like online shopping.
- Existing methods, such as zero-shot prompting or Supervised Fine-Tuning (SFT) with synthetic rationales, are limited in personalization, adaptability, and the quality of generated reasoning.
- Traditional reinforcement learning (RL) for web agents faces challenges with sparse binary rewards, leading to inefficient learning and vulnerability to reward hacking for complex, multi-component actions.

## Method

- The approach initializes the model with ==Supervised Fine-Tuning== (SFT) using LLM-generated rationales to provide a strong behavioral prior.
- It decomposes the simulation task into distinct sub-tasks for rationale generation and action prediction, each guided by tailored reinforcement learning reward signals.
- A hybrid reward scheme is implemented, featuring a self-certainty score for rationale generation and a hierarchical reward for action prediction that includes difficulty-aware scaling (DARS) to encourage complex, high-entropy actions.

## Results

- The Shop-R1 framework achieved **27.72%** exact-action accuracy on the SHOP-CART dataset, representing a relative improvement of over **65%** compared to supervised fine-tuning alone.
- It simultaneously boosted action-type accuracy to **36.40%** and action-type F1 to **31.28%**, indicating enhanced fidelity in both high-level intent and fine-grained action component prediction.
- Ablation studies confirmed that each component—SFT warm-start, format reward, self-certainty reward, and hierarchical difficulty-scaled action rewards—is necessary for preventing reward hacking and ensuring robust performance across diverse action types.

## Takeaways

> [!tip] Key Insights
> - An SFT warm-start is crucial for stable RL training, providing essential linguistic priors and structural knowledge for generating complex, long-text arguments.
> - A combined reward system featuring a self-certainty score for rationales and a hierarchical, difficulty-aware reward for actions effectively provides fine-grained feedback, stabilizes RL, and mitigates reward hacking.
> - Providing explicit simplified HTML context from previously visited pages is critical for generating precise, fine-grained action arguments beyond merely inferring coarse action types.
