# Mind the Gap: Benchmarking Spatial Reasoning in Vision-Language Models

> [!summary] Summary
> University of Edinburgh researchers develop a comprehensive benchmark for evaluating spatial reasoning capabilities in vision-language models (VLMs), revealing that current state-of-the-art models perform near random chance across multiple spatial reasoning tasks while demonstrating particular weakness in mental rotation abilities.

## Problem

- Existing VLM benchmarks don't effectively isolate or assess spatial reasoning abilities
- Lack of standardized evaluation methods for comparing spatial reasoning capabilities across different VLM architectures

## Method

- Created a multi-component benchmark combining ==synthetic==, ==GenAI-generated==, and ==real-world images==
- Developed specific tests for ==spatial relations==, orientation, navigation, and ==mental rotation==
- Evaluated **13** state-of-the-art VLMs using the new benchmark framework

## Results

- Average accuracy across **13** tested VLMs was close to random chance
- Mental rotation tasks proved particularly challenging for all models
- Models demonstrated inconsistent performance across different spatial reasoning components
- Ablation studies showed limitations persist even with different image generation approaches

## Takeaways

> [!tip] Key Insights
> - VLMs show relatively strong performance on basic spatial relations but struggle with complex transformations
> - Success in one spatial reasoning component doesn't translate to robust performance across others
> - Using GenAI-generated images doesn't significantly improve model performance
