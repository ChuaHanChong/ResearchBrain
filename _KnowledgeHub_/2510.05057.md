# StaMo: Unsupervised Learning of Generalizable Robot Motion from Compact State Representation

> [!summary] Summary
> An unsupervised framework, StaMo, learns a compact two-token state representation from static images, allowing robot motion to emerge as a simple difference between states. This approach enhances Vision-Language-Action (VLA) models, improving task success rates on benchmarks like LIBERO by up to 11.1% and enabling strong zero-shot generalization to new environments while maintaining high inference speeds.

## Problem

- Robotic state representation learning faces a trade-off between compactness (efficient) and expressiveness (semantically rich), hindering efficient world modeling and action generation.
- Learning robot motion from video data is computationally expensive, often yields ambiguous action representations, and struggles with temporal complexities.
- Current Vision-Language-Action (VLA) models are often reactive, lack explicit world modeling capabilities, and rely on redundant state representations, which limits generalization and predictive reasoning.

## Method

- A ==Diffusion Autoencoder== with a frozen DINOv2 encoder and a trainable Diffusion Transformer decoder is employed to compress high-dimensional images into a compact two-token latent state.
- Robot motion is represented as the direct vector difference between consecutive compact latent state tokens, defining ==latent actions== from static observations.
- The compact state representations are integrated into existing VLA models (e.g., OpenVLA) as an auxiliary task for future state prediction, and used to generate pseudo-actions for policy co-training from unlabeled video data.

## Results

- StaMo reconstructs high-quality images from its compact two-token latent state and enables plausible, continuous motion interpolation, demonstrating strong generalization across diverse robotic datasets.
- Integration into VLA baselines like OpenVLA and OpenVLA-OFT improved task success rates on the LIBERO benchmark by up to **11.1%** and **4.6%** respectively, with minimal inference overhead.
- The method shows superior zero-shot transfer performance to unseen environments and enhances real-world manipulation, achieving an average success rate of **0.56** for OpenVLA + StaMo state compared to **0.25** for the OpenVLA baseline on real-world tasks.

## Takeaways

> [!tip] Key Insights
> - It is possible to learn a highly compact (e.g., two 1024-dimensional tokens) yet semantically expressive state representation from static images alone, capturing critical information like robot poses and object interactions.
> - Robot motion can naturally emerge as a simple vector difference between consecutive compact state representations, challenging the necessity of complex temporal modeling from video data.
> - Integrating compact state representations into VLA models enables efficient world modeling and future state prediction, which regularizes policies and enhances primary action prediction without significant computational overhead.
