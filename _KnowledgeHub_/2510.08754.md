# Whole Body Model Predictive Control for Spin-Aware Quadrupedal Table Tennis

> [!summary] Summary
> Researchers at the RAI Institute, MIT, and Georgia Tech developed an integrated system that enables a Boston Dynamics Spot quadruped robot with an arm to play spin-aware table tennis, achieving a 90.1% return rate and accurate spin generation in dynamic rallies with human players. The system combines high-speed perception, refined spin prediction using a residual network, and a whole-body model predictive control framework that facilitates emergent stroke strategies.

## Problem

- Existing robotic table tennis systems often use fixed-base arms or gantry setups, bypassing the complexities of whole-body dynamic control and active balance required for human-like agility.
- Accurately perceiving and predicting the high-speed trajectory and spin of a small table tennis ball in real-time is challenging due to unmodeled aerodynamic effects and contact dynamics.
- Developing agile, coordinated whole-body control for a legged robot to execute precise, high-speed strikes while maintaining balance is a difficult problem.

## Method

- An integrated system combines high-speed, dual-camera perception with background subtraction and YOLO for low-latency 3D ball localization.
- Ball trajectory and spin are predicted using a model-based approach, enhanced by a learned residual neural network to account for unmodeled dynamics.
- Whole-body ==model predictive control== (MPC) leverages parametric Bezier curves and Sequential Quadratic Programming (SQP) to generate dynamically feasible arm and body motions for precise strikes while maintaining robot balance.

## Results

- The perception system achieved a median 3D ball localization error below 1 cm, enabling precise real-time tracking.
- The integrated residual network improved spin prediction accuracy, increasing the R² metric from **0.42** to **0.70** compared to purely model-based estimation.
- The full system demonstrated a **90.1%** return rate in targeted striking experiments and successfully rallied with human players, handling incoming spin up to 280 rad/s and generating outgoing spin up to 200 rad/s.

## Takeaways

> [!tip] Key Insights
> - Real-time, low-latency ball detection and 3D localization are achievable using a dual-camera setup with efficient image processing, yielding sub-centimeter accuracy.
> - Hybridizing model-based spin prediction with a learned residual neural network significantly improves prediction accuracy, accounting for unmodeled dynamics crucial for dynamic tasks.
> - A continuous MPC formulation for whole-body control can generate a diverse range of stroke strategies for legged robots, allowing emergent behaviors based on desired ball return objectives.
