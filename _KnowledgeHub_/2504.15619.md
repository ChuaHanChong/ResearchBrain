# AdaViP: Aligning Multi-modal LLMs via Adaptive Vision-enhanced Preference Optimization

> [!summary] Summary
> Researchers from USTC develop AdaViP, a preference optimization framework that reduces hallucinations in multimodal language models by incorporating vision-based preference pairs and adaptive optimization, achieving state-of-the-art performance on multiple benchmarks including Object HalBench and AMBER while surpassing GPT-4V on certain trustworthiness metrics.

## Problem

- Existing preference learning methods for MLLMs focus primarily on language preferences while neglecting visual context
- MLLMs frequently generate responses that contradict or ignore important visual information (hallucinations)

## Method

- ==Vision-based preference pair construction== using cascade of visual foundation models to create modified images
- ==Adaptive optimization strategy== that dynamically balances vision and language-based preferences during training

## Results

- Outperforms existing DPO methods and hallucination-specific baselines across multiple benchmarks
- Achieves superior trustworthiness compared to proprietary models like GPT-4V on certain metrics
- Ablation studies confirm both vision-based pairs and adaptive optimization contribute to improvements
- Analysis shows successful transition from visual-heavy to balanced preference integration during training

## Takeaways

> [!tip] Key Insights
> - Removing key visual elements from images creates effective preference pairs for training
> - Adaptive weighting between visual and language preferences improves optimization
> - Models initially rely more on visual preferences before achieving balanced integration
