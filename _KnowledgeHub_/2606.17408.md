# Where Should Action Generation Begin? A Learnable Source Prior for Generative Robot Policies

> [!summary] Summary
> LeaP, a learnable, proprioception-conditioned stochastic prior, improves generative robot policies by replacing the standard Gaussian action generation source with an informed yet uncertain starting point. This method achieved an 81.6% average success rate across 15 simulated manipulation tasks and 80.0% in real-world experiments, outperforming existing baselines with minimal overhead.

## Problem

- Generative robot policies typically initialize action generation from an observation-independent standard Gaussian distribution, requiring the generator to transform samples from an uninformed noise source.
- This leads to inefficient computational effort as the generator must perform fundamental "transport" tasks before fine-grained action synthesis.
- Prior attempts to use observation-derived starting points often neglect the inherent uncertainty of action generation, using deterministic point estimates.

## Method

- Introduces **LeaP**, a learnable, ==proprioception-conditioned diagonal Gaussian prior==, which replaces the default standard Gaussian source distribution.
- A lightweight MLP maps proprioceptive state features to the prior's mean and log-variance, anchoring the initial sample in a state-dependent region of the action space.
- The prior is trained jointly with the generative model using a combined loss function that includes flow matching, negative log-likelihood for the prior, and an instance-level alignment term.

## Results

- Achieved an average success rate of **81.6%** across 15 simulated manipulation tasks, surpassing existing baselines by **6.5** to **25.5** percentage points.
- Demonstrated an **80.0%** average success rate on three real-world robot manipulation tasks, outperforming baselines by **11.7** to **33.3** percentage points.
- Introduced minimal parameter overhead (**1.6%** of total model parameters) and exhibited faster, more stable training convergence compared to other methods.

## Takeaways

> [!tip] Key Insights
> - The source distribution is a critical and independently designable component within generative robot policies, not just the generative dynamics.
> - A learnable, proprioception-conditioned stochastic prior enhances efficiency by providing an informed yet uncertain starting point, allowing the generator to focus on action refinement.
> - State-adaptive uncertainty in the source prior is more effective for local anchoring of generation than fixed stochasticity or increased prior expressivity.
