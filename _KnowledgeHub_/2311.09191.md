# Domain Aligned CLIP for Few-shot Classification

> [!summary] Summary
> The Domain Aligned CLIP (DAC) framework enhances few-shot image classification by adapting large vision-language models through explicit optimization of both intra-modal (image-to-image) and inter-modal (image-to-text) alignment on target distributions. The method consistently outperforms competitive baselines across 11 diverse datasets, showing improved robustness to distribution shifts.

## Problem

- Large vision-language models like CLIP perform sub-optimally on specific downstream tasks due to domain gaps between pre-training and target data distributions.
- Existing few-shot adaptation methods for CLIP often neglect comprehensive alignment, focusing on only one modality or type of alignment.
- Full fine-tuning of CLIP for adaptation requires significant computational resources and can reduce out-of-distribution robustness.

## Method

- A two-stage ==Domain Aligned CLIP (DAC)== framework is proposed, comprising ==DAC-V== for visual domain adaptation and ==DAC-VT== for textual domain adaptation.
- DAC-V employs ==intra-modal contrastive learning== with a lightweight adapter to improve visual feature alignment and create an adapted visual cache for better class separation.
- DAC-VT directly fine-tunes the text embeddings of class labels to enhance ==inter-modal alignment== with the adapted visual features from the first stage.

## Results

- The Domain Aligned CLIP (DAC-VT) framework consistently outperforms competitive baselines, including Tip-Adapter, across **11** diverse image classification benchmarks in few-shot settings.
- DAC-VT demonstrates enhanced robustness to distribution shifts, making fewer classification errors compared to vanilla CLIP across various datasets.
- Performance improvements from the DAC framework scale positively with the number of training examples, showing more pronounced gains as the shot number increases.

## Takeaways

> [!tip] Key Insights
> - Explicitly optimizing both intra-modal (image-to-image) and inter-modal (image-to-text) alignment for the target domain is crucial for superior few-shot adaptation of vision-language models.
> - Intra-modal contrastive learning with a lightweight adapter effectively creates better-separated visual feature representations for different classes.
> - Directly adapting textual embeddings of class labels significantly improves inter-modal alignment, particularly for domain-specific vocabularies.

## Detailed Report

### 1. Introduction

Large vision-language models like CLIP (Contrastive Language-Image Pre-training) have demonstrated impressive zero-shot capabilities across various visual recognition tasks. However, these models often perform sub-optimally on specific downstream tasks due to domain gaps between the pre-training data distribution and target domain distribution. The research paper "Domain Aligned CLIP for Few-shot Classification" by researchers at Amazon addresses this challenge by proposing a novel framework that improves CLIP's performance in few-shot learning scenarios.

The proposed Domain Aligned CLIP (DAC) framework enhances few-shot domain adaptation of CLIP by improving both intra-modal alignment (image-to-image) and inter-modal alignment (image-to-text) on target distributions. This dual alignment strategy represents a significant advancement over existing adaptation methods, which primarily focus on one type of alignment.

### 2. Background and Challenges

CLIP and similar vision-language models are trained on massive datasets of image-text pairs using contrastive learning objectives. While they excel at zero-shot transfer to new tasks, their performance is limited by several factors:

1. **Domain Gap**: The distribution of the pre-training data differs from specific target domains, leading to sub-optimal performance.

2. **Limited Few-shot Adaptation**: Existing methods for adapting CLIP to new domains with few examples often neglect important aspects of alignment.

3. **Adaptation Trade-offs**: Full fine-tuning of CLIP requires significant computational resources and can reduce out-of-distribution robustness.

Traditional approaches to adapting CLIP for few-shot classification include:

- **Zero-shot CLIP**: Using the pre-trained model directly without adaptation.
- **Linear Probe**: Training a linear classifier on frozen CLIP features.
- **Tip-Adapter**: Adding a cache of visual features for nearest-neighbor matching.

However, these approaches have limitations, particularly in leveraging the rich information embedded within each modality and in adapting both visual and textual features to the target domain.

### 3. DAC Framework

The Domain Aligned CLIP (DAC) framework introduces a two-stage approach to improve few-shot domain adaptation:

1. **DAC-V**: Adapts the visual domain using intra-modal contrastive learning
2. **DAC-VT**: Further adapts the textual domain to improve inter-modal alignment

The key innovation lies in explicitly optimizing both intra-modal and inter-modal alignment for the target domain, unlike previous methods that primarily focus on one type of alignment.

### 4. Visual Domain Adaptation

The first stage (DAC-V) focuses on improving intra-modal alignment within the visual domain. The process involves:

1. **Intra-modal Contrastive Learning**: A lightweight adapter (linear layer) is trained using a supervised contrastive loss to improve alignment of visual features from the same class.

2. **Visual Cache Construction**: The adapter transforms CLIP image embeddings to create an adapted visual cache as shown in Figure 1(c).

The supervised contrastive loss used for training the adapter can be formulated as:

$$\mathcal{L}_{cont} = \sum_{i \in I} \frac{-1}{|P(i)|} \sum_{p \in P(i)} \log \frac{\exp(z_i \cdot z_p / \tau)}{\sum_{a \in A(i)} \exp(z_i \cdot z_a / \tau)}$$

where $z_i$ represents the adapted image embedding, $P(i)$ is the set of positives (same class as $i$), $A(i)$ is the set of all images except $i$, and $\tau$ is a temperature parameter.

This contrastive learning approach creates better-separated feature representations for different classes, as visualized in Figure 3, which shows the improved class separation in DAC-V Cache compared to CLIP Cache.

### 5. Textual Domain Adaptation

The second stage (DAC-VT) focuses on adapting the textual domain to improve inter-modal alignment:

1. **Text Cache Adaptation**: Unlike previous methods, DAC directly fine-tunes the text embeddings of class labels to better align with the visual features in the target domain.

2. **Optimization in Ensemble Setting**: The text embeddings are optimized while keeping the intra-modal classifier from the first stage frozen.

The text cache construction process is illustrated in Figure 1(b), where class labels are processed through the CLIP Text Encoder to create a text cache that will be fine-tuned.

The adaptation of text embeddings is particularly important for domains where the vocabulary or class names might differ from the pre-training distribution. By fine-tuning the text embeddings, DAC-VT can better capture domain-specific semantics and improve inter-modal alignment.

### 6. Performance Evaluation

The DAC framework was evaluated on 11 diverse image classification benchmarks using few-shot learning settings (1, 2, 4, 8, and 16 shots). The results show:

1. **DAC-V Performance**: DAC-V, which only optimizes visual representations, performs comparably to strong baselines like Tip-Adapter-F.

2. **DAC-VT Superior Performance**: DAC-VT, which aligns both visual and textual domains, consistently outperforms all competitive baselines across datasets.

3. **Scaling with Shot Number**: The performance improvement becomes more pronounced as the number of training examples increases, as shown in Figure 5.

### 7. Analysis of Intra-modal and Inter-modal Alignment

The DAC framework's effectiveness can be attributed to its dual focus on improving both intra-modal and inter-modal alignment. An analysis of cosine similarities between embeddings reveals distinct patterns:

1. **CLIP's Inter-modal Alignment**: CLIP's Image-Text similarities (green) are centered around 0.2, showing reasonable alignment but room for improvement.

2. **DAC's Intra-modal Alignment**: DAC's Image-Image similarities (yellow) show a sharp peak near 0.9, indicating strong intra-modal alignment where images of the same class are brought closer together.

3. **Complementary Information**: The different peaks in the similarity distributions suggest that intra-modal and inter-modal classifiers capture complementary information, which explains why ensembling them leads to improved performance.

### 8. Robustness Analysis

DAC-VT not only improves accuracy but also enhances robustness to distribution shifts. The error inconsistency analysis in Figure 7 shows that DAC-VT makes fewer errors than vanilla CLIP across all datasets.

This robustness extends to challenging cases like the ones shown in Figure 8, where objects with similar visual appearances but different semantic meanings (stage vs. missile) are more accurately classified by DAC-VT.

### 9. Ablation Studies

Several ablation studies provide insights into the design choices of the DAC framework:

1. **Effect of CLIP Backbone**: DAC-VT consistently outperforms vanilla CLIP across different backbone architectures (RN50, RN101, ViT variants), as shown in Figure 9.

2. **Augmentation Analysis**: Using multiple augmented views during cache construction improves performance up to a point, as shown in Figure 10.

3. **Ensemble Weighting**: The optimal weighting between intra-modal and inter-modal classifiers (alpha parameter) was determined through ablation, with the peak occurring around 3.8 as shown in Figure 11.

### 10. Conclusion

The Domain Aligned CLIP (DAC) framework represents a significant advancement in adapting large vision-language models for few-shot classification tasks. By explicitly optimizing both intra-modal and inter-modal alignment for the target domain, DAC achieves superior performance compared to existing methods while maintaining computational efficiency.

Key contributions of the work include:

1. A novel two-stage adaptation framework that improves both visual and textual domain alignment
2. Explicit intra-modal alignment through contrastive learning that enhances discrimination between visually similar classes
3. Direct optimization of text embeddings to improve inter-modal alignment in the target domain
4. Consistent performance improvements across diverse datasets and few-shot settings
5. Enhanced robustness to distribution shifts compared to vanilla CLIP

The DAC framework provides a practical and effective solution for adapting large pre-trained models to specific domains with limited labeled data, which is particularly valuable in real-world applications where labeled data is scarce or expensive to obtain.
