# Domain Aligned CLIP for Few-shot Classification

> [!summary] Summary
> The Domain Aligned CLIP (DAC) framework enhances few-shot image classification by adapting large vision-language models through explicit optimization of both intra-modal (image-to-image) and inter-modal (image-to-text) alignment on target distributions. The method consistently outperforms competitive baselines across 11 diverse datasets, showing improved robustness to distribution shifts.

## Problem

- Large vision-language models like CLIP perform sub-optimally on specific downstream tasks due to domain gaps between pre-training and target data distributions.
- Existing few-shot adaptation methods for CLIP often neglect comprehensive alignment, focusing on only one modality or type of alignment.
- Full fine-tuning of CLIP for adaptation requires significant computational resources and can reduce out-of-distribution robustness.

## Method

- A two-stage ==Domain Aligned CLIP (DAC)== framework is proposed, comprising ==DAC-V== for visual domain adaptation and ==DAC-VT== for textual domain adaptation.
- DAC-V employs ==intra-modal contrastive learning== with a lightweight adapter to improve visual feature alignment and create an adapted visual cache for better class separation.
- DAC-VT directly fine-tunes the text embeddings of class labels to enhance ==inter-modal alignment== with the adapted visual features from the first stage.

## Results

- The Domain Aligned CLIP (DAC-VT) framework consistently outperforms competitive baselines, including Tip-Adapter, across **11** diverse image classification benchmarks in few-shot settings.
- DAC-VT demonstrates enhanced robustness to distribution shifts, making fewer classification errors compared to vanilla CLIP across various datasets.
- Performance improvements from the DAC framework scale positively with the number of training examples, showing more pronounced gains as the shot number increases.

## Takeaways

> [!tip] Key Insights
> - Explicitly optimizing both intra-modal (image-to-image) and inter-modal (image-to-text) alignment for the target domain is crucial for superior few-shot adaptation of vision-language models.
> - Intra-modal contrastive learning with a lightweight adapter effectively creates better-separated visual feature representations for different classes.
> - Directly adapting textual embeddings of class labels significantly improves inter-modal alignment, particularly for domain-specific vocabularies.
