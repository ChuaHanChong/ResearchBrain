# DeeR-VLA: Dynamic Inference of Multimodal Large Language Models for Efficient Robot Execution

> [!summary] Summary
> The DeeR-VLA framework enables efficient deployment of Multimodal Large Language Models (MLLMs) on resource-constrained robotic platforms by introducing a dynamic inference approach. It significantly reduces computational costs by 5.2-6.5x and GPU memory usage by 2-6x while maintaining competitive task success rates on manipulation benchmarks.

## Problem

- Integrating Multimodal Large Language Models (MLLMs) into robotic systems incurs significant computational costs, making deployment on resource-constrained platforms challenging.
- Many robotic tasks are relatively simple and do not require the full computational capacity of large models, leading to inefficient use of resources.
- Excessive processing by full models introduces unnecessary latency in robot responses, which can be critical in real-time control.

## Method

- Introduces **DeeR-VLA**, a multi-exit MLLM architecture that allows dynamic inference, enabling processing to terminate at intermediate layers.
- Develops an "action consistency" termination criterion that stops processing when the predicted action from consecutive exits is sufficiently stable.
- Employs a specialized training methodology with random exit sampling and auxiliary action heads at each exit point to ensure reliable predictions across all depths.

## Results

- Reduces the computational cost of the LLM by **5.2**-**6.5x** and GPU memory usage by 2-**6x** on the CALVIN LH-MTLC benchmark without performance loss.
- Achieves competitive task success rates compared to state-of-the-art methods while requiring significantly less computation.
- Demonstrates scalability to larger 9B parameter models, maintaining a **5.7x** reduction in computational cost and **2.7**-**4.0x** memory reduction while preserving performance.

## Takeaways

> [!tip] Key Insights
> - Not all robotic tasks require the full computational power of large MLLMs; simpler scenarios can be handled by earlier network layers.
> - Focusing on the consistency of the predicted action, rather than internal features or confidence scores, is a more effective early-exit criterion for robot control tasks.
> - The framework allows for budgeted task execution, dynamically adjusting computation based on available resources and desired performance for specific platform constraints.
