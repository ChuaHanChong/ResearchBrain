# Remember what you did?: Learning Behavioral Memories for Partially Observable Object Manipulation

> [!summary] Summary
> The Compressed Action Memory Policy (CAMP) enables robots to execute long-horizon, contact-rich manipulation tasks under partial observability by learning a compact behavioral memory from their own action history. This approach significantly improved performance on memory-dependent tasks, achieving a 94% success rate on simulated multi-goal pushing and successfully completing challenging real-robot scenarios where memoryless baselines failed.

## Problem

- Robots struggle with long-horizon, contact-rich manipulation due to partial observability, where current visual observations do not fully capture past interactions or task progress.
- Standard visuomotor policies and existing vision-language-action (VLA) models often lack robust memory mechanisms, leading to
- Prior memory-augmented methods are often computationally expensive due to high-dimensional visual history or rely on tedious human-crafted language prompts, limiting scalability.

## Method

- Introduces Compressed Action Memory Policy (**CAMP**), which learns a recurrent behavioral memory by reconstructing past action trajectories in a self-supervised manner.
- Employs ==Discrete Cosine Transform (DCT)== to compress action sequences into low-frequency coefficients and a Vector Quantizer (VQ) to discretize memory states, promoting generalized learning.
- Integrates this learned memory module with a diffusion policy for action prediction, utilizing a staged warm-up-then-finetune training schedule to preserve long-horizon memory.

## Results

- CAMP achieved **94%** success on the simulated Memory-T-Bench 'Push-T Multi-Goals' task, significantly outperforming the memoryless Diffusion Policy (DP) which scored **56%**.
- On the 3D Memory-Manip-Bench, CAMP achieved an average success rate of **64.3%**, surpassing the strongest baseline, DP, by over **23%** across seven tasks.
- In real-robot experiments, CAMP successfully completed 7/10 trials on tasks like Push-T-Multi-Goals and Swap-Can, while memoryless baselines consistently failed with 0 successes due to inability to track task progress.

## Takeaways

> [!tip] Key Insights
> - A robot's own action history, being lower-dimensional than visual observations, provides an effective and self-supervised signal for learning relevant behavioral memory in partially observable environments.
> - Combining DCT for action compression and VQ for memory state discretization is crucial for the memory to learn generalized behavioral summaries rather than overfitting to specific trajectory details.
> - The most effective memory for policy execution may not be the one that most accurately reconstructs past actions, but rather one refined through finetuning to align with the action head's decision-making process.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The paper addresses a fundamental challenge in robotics: long-horizon, contact-rich manipulation tasks that are inherently partially observable. This partial observability arises because a single visual observation often fails to capture the full context of a robot's interaction history, including previous attempts, physical interactions, or intermediate task progress. This limitation hinders the performance of standard visuomotor policies and contemporary vision-language-action (VLA) models, which typically operate without a robust memory mechanism.

Existing research has begun to acknowledge the importance of memory in long-horizon robotic manipulation. Benchmarks such as MemoryBench, RoboMME, RMBench, MIKASA-Robo, and LIBERO-Mem have explored memory requirements from various perspectives, including spatial, temporal, object-centric, procedural, and reinforcement learning. However, these benchmarks largely focus on quasi-static pick-and-place tasks, where the relevant memory pertains to observed objects or locations. In contrast, contact-rich manipulation, which involves direct physical interaction, demands a different form of memory: the ability to recall the robot's own physical attempts, the partial progress resulting from those contacts, and how earlier interactions altered the physical state, as this history is frequently unobservable from current sensory input alone.

Memory-augmented visuomotor policies have explored various strategies, including visual-token memory, prompt memory, retrieval mechanisms, and long-history encoding (e.g., SAM2Act+, EchoVLA, MemoryVLA, CronusVLA, MAP-VLA, MEM, MemER, RoboFlamingo, BPP, Past-Token Prediction, HiF-VLA, UniVLA, TraceVLA). While these methods demonstrate the utility of memory, they often depend on visual observations, language prompts, retrieved keyframes, or full observation histories. The computational cost and potential for capacity exhaustion on task-irrelevant visual details remain concerns. This work aims to differentiate itself by proposing a memory mechanism derived directly from the robot's own action history, framing it as a self-supervised signal. This approach is positioned as a novel method for addressing contact-rich, partially observable manipulation by leveraging learned behavioral memory.

### 2. Key Objectives and Motivation

The primary objective of this research is to enable robots to autonomously execute complex, extended objectives in real-world environments, particularly those involving long-horizon and contact-rich manipulation. The authors identify partial observability as the core challenge in these scenarios. Current robotic policies, which often rely on immediate or recent visual observations, suffer from "amnesia," failing to retain critical context such as prior failed attempts, current task phase, or physical interaction history. This leads to suboptimal performance in tasks requiring sequential decisions based on unobserved past states.

The motivation for developing the Compressed Action Memory Policy (CAMP) stems from addressing the limitations of existing approaches:

1. **Inadequacy of Memoryless Policies:** Standard visuomotor policies, including diffusion-based methods, are inherently "memoryless" in the context of long-horizon tasks. Even with basic observation history, they struggle to disambiguate identical-looking states that have different underlying histories (aliased signals).
2. **Challenges with Existing Memory-Augmented Policies:**
 - **Vision-Language-Action (VLA) models:** While powerful, VLA approaches typically require meticulous, human-crafted task-specific prompts to instruct the robot on what information to retain for long-horizon objectives. This reliance on human domain knowledge is considered tedious and not scalable for diverse, real-world applications.
 - **Visual History Prediction:** Approaches that attempt to learn history by predicting high-dimensional past or future visual observations are often computationally prohibitive. Such methods can also exhaust model capacity on learning visual details that are irrelevant to the task's behavioral context.
3. **Core Insight: Action History as Self-Supervised Signal:** The authors propose that a robot's own action history provides a highly informative and self-supervised signal for learning relevant behavioral memory. Analogous to how humans recall their physical actions or sensations to guide subsequent behavior, a robot can leverage its past actions to infer task progress and learn from previous interactions (including failures), without requiring additional human supervision or external oversight. By learning to reconstruct its own past actions, the system can implicitly extract and retain the most critical task-relevant behavioral information.

Therefore, the key objectives are to:
- Develop a scalable, self-supervised memory formulation based on action history reconstruction.
- Propose a novel architectural framework, CAMP, that integrates a recurrent memory module with a diffusion policy.
- Enable policies to implicitly track generalized task progress and learn from failed attempts in contact-rich manipulation tasks.
- Validate the effectiveness of this approach on new benchmarks designed for memory-dependent, contact-rich tasks, as well as real-robot setups, demonstrating substantial performance gains over state-of-the-art baselines.

### 3. Methodology and Approach

The Compressed Action Memory Policy (CAMP) models vision-based manipulation as a Partially Observable Markov Decision Process (POMDP). The central methodological insight is that the robot's own past action trajectory, being relatively lower-dimensional than visual observations, can serve as an effective self-supervised signal for learning a compact history representation.

**Problem Formalization:**
The environment is characterized by states `s_t`, actions `a_t`, transitions `T(s_{t+1}|s_t, a_t)`, observations `o_{t+1}`, and an observation function `Z(o_{t+1}|s_{t+1}, a_t)`. The policy's goal is to summarize the full interaction history `τ_{1:t} = (o_1, a_1..., o_{t-1}, a_{t-1}, o_t)` compactly to inform the next action.
- **Observation `o_t`:** Consists of two RGB views (a third-person `o_third_t` and a wrist-mounted `o_wrist_t`) and proprioception `p_t`.
- **Action `a_t`:** A 7-dimensional vector (`d_a = 7`) specifying an absolute end-effector target (3D position, 3D Euler orientation) and a binary gripper command. Absolute actions are chosen for their consistent low-frequency structure, beneficial for the DCT-based memory objective.
- **Training:** Entirely based on imitation learning from a dataset of expert demonstrations `D = {τ_i}`.

**CAMP Architecture (Figure 2):**

1. **Recurrent Memory Module (E_θ):**
 - **Implementation:** A two-layer Long Short-Term Memory (LSTM) network.
 - **Input:** At time `t`, the input `x_{t-1}` is a concatenation of the visual feature from the third-person observation `f_ψ(o_third_{t-1})`, proprioception `p_{t-1}`, and the previous action `a_{t-1}`. The third-person view is selected for its consistent spatial reference.
 - **Output:** Updates its hidden state `h_t`, which acts as a latent summary of the history.
 - **Pretraining Objective:** To force `h_t` to capture critical behavioral context, the memory module is pretrained to reconstruct the robot's past action trajectory `a_{t-L:t-1}` (where `L` is the full episode length) from `h_t`.
 - **Discrete Cosine Transform (DCT) Compression:** Instead of reconstructing raw actions, the trajectory is compressed in the frequency domain using the Discrete Cosine Transform. A linear head `g_ϕ` maps `h_t` to `K` low-order DCT coefficients `ĉ_t ∈ R^{K×d_a}`, where `K ≪ L`. This lossy reconstruction ensures `h_t` is a compact behavioral summary, focusing on the shape of the trajectory rather than step-level details.
 - **Pretraining Loss (L_mem):** Composed of two terms:
 - `L_rec` (Reconstruction Loss): Supervises in DCT coefficient space with frequency weights `w_k` that exponentially down-weight high-frequency coefficients, emphasizing low-frequency action structure.
 - `L_cons` (Temporal Consistency Loss): Penalizes disagreement between reconstructions of the same past action sequence at different timesteps. This ensures the memory's account of earlier events remains consistent as new observations arrive.
 - `L_mem = L_rec + λ_cons L_cons` is minimized jointly over the memory module parameters `{θ, ψ, ϕ}`.

2. **Memory Discretization:**
 - To improve generalization, the continuous hidden state `h_t` is discretized using a Vector Quantizer (VQ). It maps `h_t` to its nearest entry `z_t` in a learned codebook `C`.
 - The VQ objective `L_VQ` is used to train the codebook.
 - An MLP `g_ξ` then projects the quantized state `z_t` into a memory code `m_t ∈ R^{d_m}`, which is the sole historical information passed to the action head.

3. **Diffusion Action Head:**
 - **Architecture:** Based on Diffusion Policy, it predicts a chunk of future actions `a_{t:t+H}` (horizon `H`) by iteratively denoising a Gaussian sample.
 - **Conditioning:** The noise-prediction network `ϵ_η` is conditioned on a vector `c_t` that concatenates features from both camera views `(f_ψ(o_third_t), f_ψ(o_wrist_t))`, proprioception `p_t`, and the memory code `m_t`. The wrist view provides close-range detail for contact-rich actions, while the third-person view and memory module track task progress.
 - **Training:** Uses the standard score-matching loss `L_DP`.

**Training Schedules (Staged Warm-up-then-Finetune):**
CAMP employs a two-stage training process to prevent the action loss from immediately eroding the long-horizon memory learned during pretraining.
1. **Pretraining:** The memory module is initially pretrained on `L_mem`.
2. **Staged Action Head Training:** The action head is trained using `L_act = L_DP + L_VQ`.
 - **Warm-up Phase:** For the first `N_warm` gradient steps, the memory module (E_θ, g_ϕ, g_ξ) remains frozen. This allows the action head to adapt to the pretrained memory representation.
 - **Finetuning Phase:** After the warm-up, the memory module is unfrozen and updated jointly with the action head, but with a scaled-down learning rate `α < 1`. This strategy aims to preserve the long-horizon information while allowing the memory representation to adapt to the specific requirements of the action policy.

### 4. Main Findings and Results

The evaluation of CAMP was conducted across various simulated and real-robot benchmarks, demonstrating its efficacy in addressing partial observability in contact-rich manipulation.

**Simulation Experiments:**

- **Memory-T-Bench (2D Contact-Rich Pushing):**
 - CAMP consistently outperformed the memoryless Diffusion Policy (DP) across all four variants of this benchmark, which are designed to require tracking task progress or learning from failure.
 - On "Push-T Multi-Goals," CAMP achieved 94.0% success rate compared to DP's 56.0%. Similar significant gains were observed on "Swap-Direct" (CAMP 94.0% vs. DP 74.0%), "Swap-Shuffle" (CAMP 92.0% vs. DP 48.0%), and "Find-Track" (CAMP 90.0% vs. DP 62.0%).
 - For the fully observable "plain Push-T" task, CAMP (98.0%) performed comparably to DP (94.0%), indicating that its memory mechanism does not introduce a performance penalty when not required. The performance gap directly correlated with the degree of partial observability inherent in each task.

- **Memory-Manip-Bench (3D Vision-Based Manipulation):**
 - Across seven 3D manipulation tasks, CAMP achieved the highest average success rate of 64.3%, surpassing the strongest baseline, DP, by over 23%.
 - CAMP demonstrated the best per-task results on six out of seven tasks. The largest performance margin was observed in tasks with high memory demands, such as "Swap-Block" (CAMP 86.0% vs. DP 18.0%). It also led in five "learn-from-failure" tasks (e.g., "Uncover-Blocks," "Probe-Insert").
 - On "Open-Door," a short-horizon task with minimal memory requirements, CAMP (50.0%) trailed DP (54.0%) slightly, consistent with the pattern that CAMP's advantage is proportional to the task's partial observability.
 - MemoryVLA, a prior memory-based method, averaged only 5.7% success on this suite, with its limitations primarily attributed to its visual observation modality (single third-person view without wrist camera or depth information), which hindered precise grasping in small feature manipulation.

- **Scaling with Demonstrations:**
 - On the "Multi-Goals" task, CAMP's success rate improved monotonically with an increasing number of demonstrations, rising from 42% with 80 demonstrations to 94% with 320 demonstrations.
 - In contrast, the memoryless Diffusion Policy showed no consistent improvement, fluctuating between 26% and 56% over the same data range. This suggests that for memoryless policies, partial observability acts as a bottleneck, preventing them from benefiting from additional data to disambiguate identical-looking states.

- **Ablation Studies:**
 - **Vector Quantizer (VQ):** Removing the VQ component significantly reduced success from 94% to 60%. This indicated that conditioning the action head on continuous hidden states led to poor generalization by over-fitting to specific trajectory identities rather than abstract behavioral states.
 - **Reconstruction Target:** Replacing the DCT basis with Fourier (DFT) or raw waypoints dropped performance to 64% and 66%, respectively. This highlighted the importance of DCT's ability to compress trajectories into a few low-frequency coefficients, thereby forcing the memory module to learn a compact behavioral summary.
 - **Training Schedule:**
 - Joint training from scratch yielded 66% success, suggesting the action loss can override the long-horizon memory.
 - Pretraining the memory and then freezing it for action head training achieved 80% success, confirming the utility of the pretrained representation.
 - Pretraining followed by immediate finetuning performed worst at 46%, as joint gradients erased the pretrained memory too quickly.
 - Only the proposed "warm-up-then-finetune" schedule achieved the full 94% success, by allowing the action head to adapt to the frozen memory first, then enabling joint finetuning while preserving the pretrained memory.

- **Memory Representation Characteristics:**
 - Analysis indicated that the memory representation most effective for the policy was not the one that most faithfully reconstructed the past action trajectory.
 - The finetuned memory, achieving 94% success, exhibited a degraded reconstruction quality (L_rec increased from 0.35 to 1.46) compared to the pretrained memory (80% success). This implies that finetuning shaped the memory to be aligned with the action head's decision-making process, even at the cost of detailed historical fidelity. The reconstruction loss is interpreted as a scaffold to initially embed history, which is then refined for policy utility.

**Real-Robot Experiments:**

- **Tasks:** Evaluated on four real-robot tasks (Push-T-Multi-Goals, Probe-Insert, Swap-Can, Wipe-Plate) designed to test tracking task progress and learning from failure.
- **Performance:**
 - All memoryless baselines (ACT, DP, π_0.5, MemoryVLA) largely failed, achieving 0 successes out of 10 or 15 trials on Push-T-Multi-Goals, Swap-Can, and Wipe-Plate. Some non-zero successes on Probe-Insert were attributed to lucky first guesses, with no recovery mechanism.
 - CAMP achieved 7/10 successes on Push-T-Multi-Goals, Swap-Can, and Wipe-Plate, and 11/15 on Probe-Insert.
- **Failure Analysis:** Baselines exhibited specific failure modes directly linked to their memory deficit: oscillating between goal candidates without committing (Push-T-Multi-Goals), stalling after initial movements without memory of subsequent steps (Swap-Can), or repeatedly using the same brush/plate or failing to switch (Wipe-Plate). CAMP's ability to track these elements allowed it to complete the tasks consistently.

### 5. Significance and Potential Impact

This research presents a significant advancement in robot manipulation, particularly for tasks characterized by long horizons and contact-rich interactions under partial observability. The key significance and potential impact include:

- **Addressing a Fundamental Challenge:** CAMP provides a robust and scalable method to overcome partial observability, a pervasive issue that limits the autonomy and generalization capabilities of robots in real-world, unstructured environments. By demonstrating success on tasks where memoryless policies consistently fail, this work highlights the criticality of incorporating effective memory mechanisms.
- **Novel Self-Supervised Memory Formulation:** The innovative use of the robot's own action history as a self-supervised signal for learning behavioral memory offers a scalable alternative to methods relying on high-dimensional visual history or explicit human-engineered language prompts. This approach is computationally efficient and less prone to visual aliasing, making it more practical for real-time applications.
- **Enhanced Robotic Autonomy and Robustness:** By allowing policies to implicitly track task progress and learn from failed attempts without additional supervision, CAMP contributes to the development of more autonomous and resilient robotic systems. This capability is crucial for applications ranging from household tasks to industrial assembly, where robots must adapt to dynamic environments and recover from unforeseen interactions.
- **Improved Generalization:** The ablation studies reveal that the combination of Discrete Cosine Transform for action trajectory compression and Vector Quantization for hidden state discretization is crucial for learning a generalized "behavioral summary" rather than mere memorization of specific trajectories. This enables the policy to perform effectively across diverse scenarios.
- **Insight into Memory for Control:** The finding that the optimal memory for the action policy is not necessarily the most accurate historical reconstructor provides a new perspective on designing memory systems. It suggests that control policies benefit from compressed, task-aligned representations that prioritize decision-relevant information over high-fidelity historical detail, informing future memory architecture designs.
- **Introduction of New Benchmarks:** The release of Memory-T-Bench and Memory-Manip-Bench provides standardized platforms explicitly designed to evaluate action-interaction memory in contact-rich tasks. These benchmarks will facilitate further research and development in this underexplored area, fostering comparative studies and innovation.
- **Demonstrated Real-World Applicability:** The consistent performance gains observed on real-robot tasks, where other state-of-the-art methods failed, underscore CAMP's practical utility. This provides empirical evidence for the transferability of the proposed memory mechanism from simulation to physical systems.

The limitations of the current work, such as challenges with extremely long-horizon memory and extension to dexterous manipulation, represent natural directions for future research. Nevertheless, CAMP establishes a foundation for building more capable and intelligent robotic manipulation systems.
