# Continual Learning with Strong Experience Replay

> [!summary] Summary
> A new method called Strong Experience Replay (SER) improves continual learning by incorporating dual consistency losses, one for past experiences and a novel one leveraging current training data as "future experiences" for the old model. This approach effectively reduces catastrophic forgetting, demonstrating, for instance, a 20.5 percentage point accuracy improvement over DER++ on CIFAR100 Class-IL with a limited memory buffer.

## Problem

- Deep neural networks experience catastrophic forgetting when learning new tasks sequentially, struggling to balance the acquisition of new knowledge with the retention of old information.
- Conventional Experience Replay (ER) methods often overfit to the limited samples stored in their memory buffers, leading to continued forgetting, especially when memory capacity is low or the number of tasks is high.
- Existing knowledge distillation techniques within ER extensions are constrained by the small size of the memory buffer, offering insufficient signal to fully stabilize the model's performance across all prior tasks.

## Method

- **Strong Experience Replay (SER)** enhances the traditional ==Experience Replay== framework by integrating two distinct ==consistency losses== into the overall training objective.
- A ==backward consistency loss== distills knowledge from the previous model by enforcing consistency between current and old model predictions on samples replayed from the memory buffer.
- A novel ==forward consistency loss== leverages the complete current training data to enforce consistency with the previous model's predictions, using this data as "future experiences" to mitigate overfitting to the limited memory buffer.

## Results

- SER consistently achieved superior average accuracy and lower average forgetting rates across CIFAR10, CIFAR100, TinyImageNet, and MNIST datasets in Class-IL, Task-IL, and Domain-IL settings.
- On CIFAR100 Class-IL (5 tasks, 200-sample memory buffer), SER reached **47.96%** average accuracy, an improvement of **20.5 percentage points** over the DER++ baseline (**27.46%**).
- In challenging TinyImageNet Class-IL with a 200-sample memory, SER demonstrated a **17.54 percentage point** accuracy gain over DER++, achieving **28.50%** average accuracy.

## Takeaways

> [!tip] Key Insights
> - Overfitting to a small memory buffer is a critical bottleneck for rehearsal-based continual learning methods, significantly hindering knowledge preservation.
> - Leveraging current training data as "future experiences" for the old model provides a rich, generalizable signal for consistency regularization, extending beyond the limited scope of the memory buffer.
> - Combining both backward (memory-based) and forward (current data-based) consistency losses creates a more comprehensive and robust mechanism for balancing stability and plasticity during sequential task learning.
