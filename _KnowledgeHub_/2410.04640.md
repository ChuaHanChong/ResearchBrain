# Unpacking Failure Modes of Generative Policies: Runtime Monitoring of Consistency and Progress

> [!summary] Summary
> Sentinel, a runtime monitoring framework developed by Stanford University researchers, detects unknown failures of generative robot policies by combining a statistical temporal action consistency (STAC) detector for erratic behavior with a Vision Language Model (VLM) for task progression assessment. This framework identifies 18% more failures than individual detectors, demonstrating high accuracy in both simulated and real-world mobile manipulation tasks.

## Problem

- Generative robot policies, trained via imitation learning, are prone to unpredictable failures when operating in out-of-distribution (OOD) scenarios, posing a barrier to scalable and safe robot deployment.
- Existing OOD detection or uncertainty quantification methods are often insufficient for the multimodal action distributions and closed-loop, temporal nature of generative policy failures.
- The diverse failure modes of generative policies, ranging from rapid erratic actions to slow, incorrect task progression, require a comprehensive detection strategy that single metrics cannot provide.

## Method

![[2410.04640-method.png]]
*Sentinel, a runtime monitor for generative robot policies: calibrated on successful rollouts, it flags unknown deployment failures via (a) statistical temporal action consistency (STAC) and (b) online VLM video QA.*

- Introduces **Sentinel**, a runtime monitoring framework that employs a ==divide and conquer== strategy by running two complementary detectors in parallel: ==STAC== for erratic failures and a VLM for task progression failures.
- The **STAC** (==Statistical Temporal Action Consistency==) detector quantifies erratic policy behavior by measuring the statistical consistency of the generative policy's action distributions over time using ==Maximum Mean Discrepancy (MMD)== or ==KL-divergence==, calibrated solely on successful policy rollouts.
- A ==Vision Language Model (VLM)== is used in a zero-shot, ==Chain-of-Thought Video Question Answering== setup to assess high-level task progress over longer durations, identifying failures where the policy consistently takes correct but ultimately non-task-completing actions.

## Results

- **Sentinel** achieved high overall balanced accuracy across all tested domains (e.g., **91%** in Close Box simulation, **95%** in real-world Push Chair) and detected **18%** more failures than using either detector alone.
- STAC demonstrated high accuracy and fast detection for erratic failures (e.g., **>90%** balanced accuracy in PushT, **96%** in Close Box), outperforming various baselines in temporal consistency detection.
- VLMs effectively identified task progression failures where STAC struggled (e.g., **85%** True Positive Rate for Claude 3.5 in Cover Object), with VLM performance significantly boosted by video context and prompt ensembling.

## Takeaways

> [!tip] Key Insights
> - A "divide and conquer" strategy with specialized, complementary detectors (fast for erratic, slower for task progression) is crucial for robustly monitoring the diverse failure modes of generative robot policies.
> - Statistical distances (like MMD or KL-divergence) applied to action distributions are essential for effectively detecting erratic behavior in multimodal generative policies, outperforming non-distributional baselines.
> - Vision Language Models can provide valuable high-level, contextual reasoning for task progression failures in a zero-shot manner, particularly when provided with video context rather than single images.
