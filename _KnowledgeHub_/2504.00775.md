# Visual Environment-Interactive Planning for Embodied Complex-Question Answering

> [!summary] Summary
> Researchers at Xidian University developed a framework that enables embodied agents to answer complex, multi-step questions by integrating sequential planning, a structured semantic space, and continuous visual feedback. It consistently improved accuracy over one-step planning methods in both simulated and real-world environments, particularly for tasks involving abstract language and dynamic observation.

## Problem

- Embodied Question Answering (EmbodiedQA) systems typically struggle with complex human questions that involve intricate grammatical structures, abstract semantics, or require multi-step reasoning.
- Current LLM-based planning methods for embodied agents often generate 'once-for-all' plans, leading to limited understanding of dynamic visual environments and susceptibility to LLM hallucinations.
- The black-box nature of solely LLM-based planning makes it challenging to interpret an agent's actions, diagnose errors, or refine strategies in complex, dynamic scenarios.

## Method

- A sequential '==Observation-Planning-Action==' framework that allows for multi-turn feedback and dynamic adjustment of plans based on real-time visual perception.
- A structured semantic space that iteratively integrates hierarchical visual scene graph representations with chained linguistic expressions from parsed complex questions.
- Specialized tools for language parsing to standardize complex human questions, and a hybrid task planning system combining rule-based reasoning with LLM-based guidance to reduce direct LLM reliance.

## Results

- The proposed framework achieved an LLM-Match score of **65.4%** using ChatGPT-4O, outperforming the ReAct baseline (**61.8%**) in simulated environments.
- It consistently surpassed ReAct on both template-based (**66.8%** vs. **59.1%**) and multi-step questions (**62.0%** vs. **52.6%**) within the newly introduced ECQA dataset.
- The framework demonstrated practical applicability in a real-world home environment, successfully answering complex, multi-step questions involving small objects and people while mitigating issues like visual occlusion.

## Takeaways

> [!tip] Key Insights
> - Integrating external, rule-based planning derived from human observation habits with LLM-based reasoning significantly improves robustness and interpretability for embodied task execution.
> - A hierarchical visual scene graph, dynamically updated with transient information about small objects, provides essential prior knowledge and supports fine-grained interaction with the environment.
> - Parsing complex natural language questions into standardized patterns within a structured semantic space clarifies intent, enabling more precise and multi-turn task planning.
