# WorldMemArena: Evaluating Multimodal Agent Memory Through Action-World Interaction

> [!summary] Summary
> WorldMemArena introduces a comprehensive benchmark and diagnostic framework for evaluating multimodal agent memory within an "Action–World Interaction Loop," comprising 461 multi-session tasks and a four-stage memory lifecycle to pinpoint failures in writing, maintenance, retrieval, and utilization of multimodal evidence.

## Problem

- Existing MLLM memory benchmarks measure static recall, often consolidate performance into a single metric, and reduce complex visual observations to text, hindering fine-grained failure diagnosis.
- Current evaluation methodologies lack a standardized framework to compare pre-designed memory pipelines with emerging self-managing, interaction-driven agent harness memory systems.
- A principled diagnostic framework is needed to assess memory performance across its observable lifecycle stages in dynamic, multimodal environments, moving beyond simple information retention.

## Method

- The research formulates multimodal agent memory as an "Action–World Interaction Loop," where memory dynamically supports observation, action, feedback, and state retention.
- A four-stage memory lifecycle (Observe to Write, Update and Consolidate, Retrieve for Decision, Use and Act) is introduced for fine-grained diagnostic evaluation of memory system performance.
- **WorldMemArena** is constructed as a benchmark featuring 461 multi-session multimodal interaction tasks across 'Lifelong Evolution' and 'Agentic Execution' regimes, with detailed annotations for each memory stage.

## Results

- Text-based memory systems often achieve more stable final answer quality compared to multimodal systems, which struggle with effectively utilizing visual inputs.
- Retrieval is identified as a critical bottleneck, with systems demonstrating strong evidence retrieval showing better final answer correctness.
- Performance varies significantly across domains and trajectories, with systems performing better in 'Lifelong Evolution' tasks than in 'Agentic Execution,' and long-context agents generally performing poorly.

## Takeaways

> [!tip] Key Insights
> - Current multimodal agent memory systems struggle to effectively encode and utilize visual evidence as reliable long-term memory for complex reasoning tasks.
> - High memory storage and recall quality do not consistently translate to high question-answering performance, indicating that successful writing is insufficient without effective retrieval and utilization.
> - Most evaluated systems show brittleness in memory updating and interference rejection, tending to accumulate information rather than actively revising, consolidating, or discarding obsolete content.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development of multimodal large language models (MLLMs) has enabled their deployment as long-horizon agents that operate in dynamic environments. In this context, the role of memory extends beyond simple recall to encompass tracking evolving world states, revising stale information, and retrieving pertinent evidence to support decision-making. Existing benchmarks for evaluating MLLM memory systems exhibit several limitations. These benchmarks often measure recall over static dialogues, consolidate memory performance into a single end-of-task accuracy metric, and frequently reduce complex visual observations to textual captions. This approach hinders fine-grained diagnosis of memory failures, making it difficult to pinpoint whether issues arise during memory writing, maintenance, retrieval, or utilization.

A further development in the field is the emergence of agent harness systems, which enable agents to autonomously author and reorganize their own memory during interaction. This trend accentuates the gap in current evaluation methodologies, as there is no standardized or principled framework to compare the performance of pre-designed memory pipelines with these self-managing, interaction-driven alternatives. "WorldMemArena" addresses these lacunae by providing a comprehensive benchmark and diagnostic framework that redefines multimodal agent memory within an "Action–World Interaction Loop." This work contributes to the broader effort of developing more robust and diagnostically capable evaluation paradigms for advanced agentic AI systems operating in complex, dynamic, and multimodal environments.

### 2. Key Objectives and Motivation

The primary objective of this research is to formulate multimodal agent memory as an Action–World Interaction Loop and to instantiate this conceptualization in a comprehensive benchmark, WorldMemArena, that allows for a detailed, stage-level diagnosis of memory system performance.

The motivation for this work is driven by several critical shortcomings in existing memory evaluation methodologies:

- **Inadequate Evaluation for Dynamic Agentic Behavior:** Current benchmarks are often designed for static recall tasks within long dialogues or extended contexts. They primarily test a model's ability to retain information rather than its capacity to utilize past experiences to guide future actions in dynamic environments. This focus overlooks the operational aspects of memory essential for long-horizon agents.
- **Lack of Lifecycle-Level Diagnosis:** Many existing evaluations provide only a final question-answering accuracy score, which obscures the specific stages where memory failures occur. Without evaluating distinct phases such as writing, updating, retrieving, and using relevant evidence, it is challenging to identify the root causes of performance degradation in agent memory systems.
- **Limited Multimodal Interaction and Pressure:** Existing benchmarks are largely text-centric, frequently converting visual inputs into captions. They often lack real-world interaction and do not sufficiently stress the agent's ability to effectively use multimodal evidence for decision-making. This limits their applicability to agents operating in visually rich environments.
- **Addressing the Rise of Agent Harness Systems:** With the advent of agent harness systems that enable agents to autonomously manage their own memory, there is a need for an evaluation framework that can compare these self-organizing approaches with traditional, manually designed memory modules. The research aims to answer whether memory should be evaluated as a predefined pipeline or as an emergent capability formed through interaction.
- **Formulating a Principled Diagnostic Framework:** The authors propose a new formulation of memory as an "Action–World Interaction Loop," where memory functions as a dynamic process supporting observation, action, feedback, and state retention. This conceptual shift necessitates a diagnostic framework that can assess memory performance across its observable lifecycle stages.

By addressing these motivations, WorldMemArena seeks to provide a more rigorous and diagnostically informative approach to evaluating multimodal agent memory, thereby enabling better design and development of future agent systems.

### 3. Methodology and Approach

The methodology employed in this research centers on the formulation of multimodal agent memory as an "Action–World Interaction Loop" and its instantiation in a new benchmark called WorldMemArena.

#### 3.1. Problem Formulation: Memory as an Action–World Interaction Loop

The core conceptual framework defines an agent-world interaction process where an agent, at each step `t`, observes a partial world state `o_t = Ω(z_t)`, selects an action `a_t = π(o_t, m_t)` based on its observation and current memory `m_t`, and receives feedback `f_t` as the environment updates its state `(z_t+1, f_t) = ℰ(z_t, a_t)`. The entire process forms a trajectory `τ = (x; η_1..., η_T)`, which is further segmented into sessions `τ = τ^(1) ◦ τ^(2) ◦ ... ◦ τ^(S)`. This multi-session structure ensures that later decisions often depend on evidence not directly visible in the current session, necessitating robust memory mechanisms.

#### 3.2. Memory Lifecycle as a Diagnostic Framework

To evaluate diverse memory systems, the research introduces a four-stage memory lifecycle:

- **Observe to Write:** Assesses the system's ability to identify and retain useful evidence from the current session for future use. The output is a memory delta `∆_s = Write(m_s-1, τ^(s))`, emphasizing selective retention over full trajectory storage.
- **Update and Consolidate:** Evaluates how newly written information is integrated and reconciled with existing memory. The system updates its state as `m_s = Maintain(m_s-1, ∆_s)`, requiring revision and consolidation to handle evolving preferences, task states, and environmental evidence.
- **Retrieve for Decision:** Measures the system's capacity to access the correct evidence when a query `q` or decision arises, returning `R_s,q = Retrieve(m_s, q)`. The goal extends beyond semantic similarity to decision relevance.
- **Use and Act:** Evaluates whether the retrieved memory `R_s,q` is faithfully employed to generate a response `ŷ_s,q = Answer(q, R_s,q)` or action. Failures can occur if relevant evidence is ignored, outdated memory is used, or experience is not translated into appropriate action.

#### 3.3. WorldMemArena Benchmark Construction

WorldMemArena comprises 461 multi-session multimodal interaction tasks across two regimes:

- **Lifelong Evolution:** Focuses on scenarios where personal and task states evolve across sessions, requiring continuous tracking, updating, and reuse of long-term memories. Examples include lifelong personal evolution and long-horizon projects.
- **Agentic Execution:** Places memory within realistic agent trajectories, demanding extraction of reusable evidence from observations, actions, and feedback, rather than pre-organized narratives.

The data collection follows a four-step automated pipeline:
1. **Raw Data Segmentation:** Raw data is segmented into multi-session instances. For Lifelong Evolution, a hidden world state is defined, and sessions are generated. For Agentic Execution, existing agent trajectories are split at subgoal boundaries or state changes.
2. **Gold Memory Point Extraction:** Key facts to retain, state updates, and evidence for future questions are extracted for each session window.
3. **Merge, Revise, Deduplicate:** Memory points are processed across sessions to remove redundancy and ensure temporal consistency.
4. **QA Checkpoint Construction:** Question-answer pairs are generated from refined gold memory points, covering 11 question types, and reviewed by human annotators.

**Data Statistics:** The benchmark includes 24,258 QA pairs and 15,595 images/screenshots across 461 tasks, averaging 18.4 sessions and 9.1K tokens per sample. Lifelong Evolution spans 6 domains (academic, finance, health, software, startup, education), while Agentic Execution covers 6 GUI and 4 Embodied subcategories. Fine-grained annotations include an average of 10 key memory points, 3 update points, and 2 interference points per session.

#### 3.4. Evaluation Protocol

Performance is assessed across the four lifecycle stages using specific metrics:

- **Stage 1 (Write):** Measures memory recall (coverage of gold memory points) and the purity of written items (correctness, hallucination, irrelevance), using an LLM-as-a-Judge.
- **Stage 2 (Maintain):** Evaluates "Update Handling" (success in preserving new and discarding old information) and "Interference Rejection" (distinguishing valid evidence from noise).
- **Stage 3 (Retrieve):** Assesses retrieval quality through "Retrieval Coverage" (RC), "Recall@K," and "Normalized Discounted Cumulative Gain" (NDCG@K) against gold evidence, covering both textual and visual information.
- **Stage 4 (Use):** Measures final answer quality using "QA Correctness," "Hallucination," "Omission," F1 score, and BLEU-1. Questions are categorized into Basic, Robustness, Reasoning, and Multimodal capabilities for fine-grained analysis.

#### 3.5. Experimental Setup

The evaluation compares three memory paradigms:
- **Long-Context Agents:** Models (e.g., GPT-5.4-mini, DeepSeek V4) that use in-context learning by concatenating full interaction history without explicit memory modules. Only final QA performance is measured.
- **Manually Designed Memory Systems:** Explicitly engineered systems, including External Memory agents (e.g., MemGPT, A-Mem) with abstraction/consolidation modules and Retrieval-Augmented Generation (RAG) systems (e.g., UniversalRAG) using indexed document stores. These systems use GPT-5.4-nano as the base model and allow full lifecycle evaluation.
- **Harness-Based Memory Agents:** Agents (e.g., OpenClaw, Codex) where memory is autonomously managed by the harness during interaction. End-to-end evaluation is primarily conducted due to the difficulty in decomposing internal memory processes.

### 4. Main Findings and Results

The experiments conducted on WorldMemArena reveal several key findings regarding multimodal agent memory across different system paradigms:

1. **Ineffective Use of Multimodal Evidence:** Text-based memory systems (e.g., MemoryGPT, A-Mem) often achieve more stable final answer quality compared to multimodal systems (e.g., ViLoMem, MIRIX), despite the latter having access to visual inputs. This suggests that current multimodal systems struggle to effectively encode and utilize visual evidence as reliable long-term memory, particularly for complex visual reasoning tasks.
2. **Discrepancy Between Memory Quality and QA Performance:** High memory storage and recall quality do not consistently translate to high question-answering (QA) quality. Systems like Qwen3-VL-Embedding and M2A may store memories effectively but show limitations in final answer generation, indicating that successful writing is insufficient without effective retrieval and use during answer generation.
3. **Retrieval as a Critical Bottleneck:** The ability to retrieve relevant information is a significant factor in overall performance. MemoryGPT demonstrates strong evidence retrieval and answer correctness. Conversely, systems like AUGUSTUS may construct adequate memories but fail to surface key evidence during inference, limiting their final QA performance.
4. **Weaknesses in Memory Updating and Distractor Rejection:** Most evaluated systems exhibit brittleness when information changes or irrelevant content is introduced. They tend to accumulate memories in an append-only manner rather than actively revising, consolidating, or discarding obsolete information, indicating a struggle to maintain temporal consistency and reject interference.
5. **Performance Varies Across Domains and Trajectories:** Memory performance is inconsistent across different domains, with most systems performing better in "Lifelong Evolution" tasks than in "Agentic Execution." Extracting usable memory from action traces and environment feedback in agentic trajectories proves more challenging. Performance also degrades on long-horizon embodied tasks.
6. **Harness-Based Memory Offers Flexibility but Lacks Reliability:** Harness-based memory agents generally outperform many manually designed memory systems, suggesting greater flexibility in agent-managed memory. However, their performance is less reliable and more computationally expensive, indicating that native memory design and adaptation mechanisms are crucial. Long-context agents, relying solely on context, generally perform poorly compared to dedicated memory systems.
7. **Memory Failures Compound Over Time:** Failures in early stages of the memory lifecycle (e.g., omissions in writing) can compound, reducing evidence availability for later retrieval and leading to an escalating difficulty in later-session reasoning tasks.

Overall, the findings indicate that current agent memory systems prioritize raw recall over dynamic maintenance and effective utilization of both textual and visual information within interactive contexts.

### 5. Significance and Potential Impact

WorldMemArena contributes significantly to the research landscape of artificial intelligence by addressing fundamental challenges in evaluating multimodal agent memory. Its significance and potential impact can be summarized as follows:

- **Introduction of a Comprehensive Diagnostic Framework:** By formulating multimodal agent memory as an Action–World Interaction Loop and decomposing its lifecycle into four observable stages (writing, maintenance, retrieval, and use), the work provides a principled and fine-grained diagnostic framework. This framework enables researchers to localize memory failures more precisely, moving beyond aggregate accuracy metrics to identify specific bottlenecks in memory pipelines.
- **Development of a Novel Benchmark:** WorldMemArena introduces a large-scale, multi-session, multimodal benchmark with 461 tasks spanning "Lifelong Evolution" and "Agentic Execution" regimes. The rich annotations—including gold memory points, state updates, distractors, and evidence chains—provide a robust foundation for evaluating diverse memory systems, from long-context models to manually designed and harness-based agents.
- **Identification of Critical Memory System Limitations:** The experimental results reveal several systemic weaknesses in current agent memory systems. The findings highlight the limited effectiveness of multimodal memory, the disconnect between high memory storage quality and actual QA performance, the persistent challenges in memory updating and interference rejection, and the instability of systems across different task domains, particularly in realistic agentic trajectories.
- **Insights into Different Memory Paradigms:** The unified comparison of long-context, manually designed, and harness-based memory agents offers valuable insights into their respective strengths and limitations. It suggests that while harness-based agents offer greater flexibility, they remain costly and less reliable, whereas fixed architectures struggle to adapt to dynamic memory demands.
- **Guidance for Future Research and Development:** The research distills specific directions for future work, advocating for:
 - **Interaction-Shaped Memory:** Moving beyond fixed memory modules towards systems where memory capabilities are developed and optimized through end-to-end interaction objectives.
 - **Consistent State Maintenance:** Prioritizing mutable memory states that support revision, conflict resolution, and selective forgetting, rather than continuous information accumulation.
 - **Effective Multimodal Memory:** Developing architectures that preserve and utilize visual memories in a usable form for reasoning and decision-making, transcending text-centric reductions.
 - **Experience-Based Learning:** Shifting evaluation focus from retrospective QA to assessing an agent's ability to learn from past experiences and failures to improve future behavior.

The potential impact of WorldMemArena is to catalyze the development of more robust, adaptive, and intelligent long-horizon agents. By providing a common ground for evaluating agent memory capabilities in dynamic, multimodal environments, this work is expected to foster innovation in memory architectures, training paradigms, and diagnostic tools, ultimately enabling AI agents that can operate more effectively and reliably in complex real-world scenarios.
