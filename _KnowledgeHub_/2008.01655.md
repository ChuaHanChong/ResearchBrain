# Deep Visual Odometry with Adaptive Memory

> [!summary] Summary
> A deep visual odometry (VO) method integrates adaptive memory and a recurrent refining module to leverage global information and mitigate error accumulation, a common limitation in learning-based approaches. It demonstrates improved translational and rotational accuracy on KITTI and TUM-RGBD datasets, outperforming many learning-based methods and showing superior robustness in texture-less or abrupt motion scenarios compared to classic VO.

## Problem

- Existing learning-based visual odometry (VO) methods suffer from significant error accumulation over long sequences, primarily due to their difficulty in representing and leveraging global information.
- Many deep learning VO models often treat the problem as pure tracking, focusing on short-term frame-to-frame estimations without mechanisms to integrate long-term historical knowledge or refine past pose estimates.
- RNN-based approaches for VO have finite memory capacity, which limits their ability to retain long-term dependencies and global context necessary for robust and consistent pose estimation over extended periods.

## Method

- Developed an end-to-end Deep Visual Odometry framework featuring an Encoder for feature extraction, a Tracking module with ConvLSTM for relative pose estimation, an Adaptive Remembering module, and a Recurrent Refining module.
- Implemented an Adaptive Remembering module that constructs a hierarchical global map by storing selected ConvLSTM hidden states based on motion-based keyframe-like selection criteria, ensuring diverse and non-redundant contextual information.
- Designed a Recurrent Refining module utilizing two-level spatial-temporal attention to selectively extract relevant features from the global memory and current observations, which then refines absolute pose estimates by propagating corrected information through a dedicated ConvLSTM branch.

## Results

- Achieved superior performance on the KITTI dataset, consistently outperforming state-of-the-art supervised and unsupervised learning-based VO methods in terms of average translational and rotational RMSE drift.
- Demonstrated enhanced robustness on the TUM-RGBD dataset, performing comparably to ORB-SLAM2 and DSO in rich texture scenes, and exhibiting superior stability in challenging texture-less regions and scenarios with abrupt motions.
- Ablation studies confirmed that both the Remembering and Refining modules, along with the spatial-temporal attention mechanisms, are critical for the model's performance, particularly in mitigating error accumulation and improving accuracy in difficult conditions.

## Takeaways

> [!tip] Key Insights
> - Explicitly integrating global information through an adaptive memory and a recurrent refinement mechanism is effective in significantly mitigating error accumulation in learning-based visual odometry.
> - A two-level spatial-temporal attention mechanism enhances the refinement process by selectively focusing on co-visible and geometrically stable features from both current observations and stored global memories.
> - Adaptive memory management, similar to keyframe selection in classic SLAM, is crucial for building a concise yet informative global map, balancing computational efficiency with the retention of long-term contextual information.
