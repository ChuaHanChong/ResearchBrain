# Fast-in-Slow: A Dual-System Foundation Model Unifying Fast Manipulation within Slow Reasoning

> [!summary] Summary
> Fast-in-Slow (FiS) proposes a unified Vision-Language-Action foundation model that integrates a fast manipulation module directly within a pre-trained VLM-based reasoning system. This architecture enables high execution frequencies and strong generalization, demonstrating improved success rates and control speeds across diverse simulated and real-world robotic tasks compared to previous dual-system approaches.

## Problem

- Vision-Language-Action (VLA) models, while improving generalization through large VLMs, suffer from low execution frequencies due to their size and autoregressive nature, hindering responsive closed-loop control.
- Existing dual-system approaches, which separate a lightweight action model (System 1) from a VLM-based reasoning model (System 2), fail to allow System 1 to fully leverage the rich, pre-trained knowledge embedded within System 2.
- There is a need for robotic policies that can seamlessly coordinate slow, high-level reasoning with fast, real-time action execution, similar to integrated dual-process cognition in humans.

## Method

- A unified dual-system ==Vision-Language-Action (VLA)== model called **Fast-in-Slow** (FiS) that embeds the fast System 1 execution module directly within the pre-trained VLM-based System 2 by repurposing its final transformer blocks.
- Design of heterogeneous modality inputs (2D images, 3D point clouds, robot state) for System 1 and System 2, alongside asynchronous operating frequencies (e.g., 1:4 ratio) tailored to their distinct roles.
- A dual-aware co-training strategy that optimizes System 1 via a diffusion modeling objective for continuous action generation and preserves System 2's reasoning capabilities using an autoregressive next-token prediction objective.

## Results

- Achieved an average success rate of **69%** across 10 RLBench tasks in simulation, outperforming prior dual-system methods like CogACT (**61%**) and π0 (**55%**), while operating at **21.9** Hz (and up to **117.7** Hz with action chunking).
- Demonstrated superior real-world performance on dual-arm tasks, achieving **68%** mean success on Agilex and **74%** on AlphaBot, compared to π0's **59%** and **61%** respectively.
- Exhibited stronger generalization capabilities in real-world scenarios with unseen objects, complex backgrounds, and varying lighting, showing a smaller performance drop compared to baselines (e.g., **19%** vs. **38%** for unseen objects on AlphaBot).

## Takeaways

> [!tip] Key Insights
> - Embedding a fast execution module (System 1) directly within the final layers of a pre-trained Vision-Language Model (System 2) enables System 1 to inherit and leverage the VLM's extensive knowledge without sacrificing execution speed.
> - Asynchronous operation and heterogeneous modality inputs tailored to each system's role are crucial for balancing high-level reasoning with precise, real-time action generation.
> - A dual-aware co-training strategy, combining diffusion modeling for actions and an autoregressive objective for reasoning, is essential to jointly optimize both systems and preserve the VLM's complex capabilities.
