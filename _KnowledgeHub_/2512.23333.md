# CME-CAD: Heterogeneous Collaborative Multi-Expert Reinforcement Learning for CAD Code Generation

> [!summary] Summary
> Fudan University and ByteDance researchers developed CME-CAD, a heterogeneous collaborative multi-expert reinforcement learning framework that automatically generates high-precision, editable CAD models from 2D engineering drawings. The method achieved an 80.71% IoU and 98.25% executability rate on the new CADExpert dataset, outperforming previous state-of-the-art methods by 8.87 percentage points in IoU.

## Problem

- Traditional CAD modeling is complex and requires specialized engineering skills, making automated generation of precise, editable models challenging.
- Existing methods for CAD code generation, particularly those using Reinforcement Learning with Verifiable Rewards (RLVR), are often on-policy, limiting exploration of diverse reasoning paths and robustness.
- A significant lack of high-quality, open-source, industrial-grade datasets with detailed trajectory descriptions and complex operations hinders the development of robust CAD automation.

## Method

- **CME-CAD** introduces a Heterogeneous Collaborative ==Multi-Expert== Reinforcement Learning paradigm with two stages: Multi-Expert Fine-Tuning (MEFT) and Multi-Expert Reinforcement Learning (MERL).
- MEFT leverages diverse pre-trained expert models to generate varied Chain-of-Thought (CoT) paths, using a reverse-task approach to produce reliable CoT by reasoning from code to 2D drawings.
- MERL employs a comprehensive reward function, Expert-Internal Advantage Estimation (EIAE), Multi-Expert Collaborative Learning (MECL), and a Hard Negative Sample Buffering (HSB) mechanism to enhance performance and facilitate knowledge transfer.

## Results

- CME-CAD achieved an IoU of **80.71%**, an 8.87 percentage point improvement over the previous state-of-the-art (CAD-RL* at **71.84%**).
- The method demonstrated high code executability at **98.25%**, surpassing CAD-RL* (**97.32%**), indicating reliable and practical CAD code generation.
- Ablation studies confirmed that the Hard Negative Sample Buffering (HSB) mechanism had the most substantial effect on overall performance, especially IoU, due to the complexity of the CADExpert dataset.

## Takeaways

> [!tip] Key Insights
> - Collaborative learning among heterogeneous experts, guided by unique system prompts, effectively generates diverse and robust reasoning paths for complex CAD code generation.
> - A comprehensive reward function, evaluating format, executability, geometric accuracy (IoU), and work plane consistency, is critical for precise and industrially relevant CAD outputs.
> - The creation of the CADExpert dataset, featuring 17,299 instances of orthographic projections, expert-generated CoT, and executable CADQuery code, addresses the data scarcity and complexity issues in the field.
