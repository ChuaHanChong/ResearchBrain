# SoFar: Language-Grounded Orientation Bridges Spatial Reasoning and Object Manipulation

> [!summary] Summary
> SOFAR introduces semantic orientation, a language-grounded representation that enables Large Language Model (LLM) agents to bridge spatial reasoning and 6-DoF object manipulation. It achieves superior performance in real-world and simulated tasks by integrating a novel semantic orientation predictor and a large-scale annotated 3D object dataset.

## Problem

- Current Vision-Language Models (VLMs) and robotic systems primarily understand object position (3-DoF) but struggle with precise object orientation (3-DoF rotation), limiting fine-grained 6-DoF manipulation.
- Traditional object pose estimation relies on pre-defined references, lacking generalization to novel objects and failing to connect geometric poses with semantic meanings in natural language.
- Robots faced difficulty interpreting complex, open-vocabulary instructions for tasks requiring specific object alignments in dynamic, open-world environments.

## Method

- **SoFar** introduces ==semantic orientation== as a language-grounded, reference-frame-free representation that directly links functional semantics (e.g., 'handle direction') to spatial directions.
- Developed ==OrienText300K==, a dataset of **350K+** 3D objects with language-guided orientation labels, created using GPT-4o for filtering and annotation.
- Designed ==PointSO==, a cross-modal 3D Transformer, to predict semantic orientations zero-shot from 3D point clouds and natural language descriptions, integrated into SoFar for ==6-DoF== spatial reasoning and manipulation.

## Results

- Achieved **85.3%** success rate on positional tasks and **48.9%** on 6-DoF real-world manipulation, outperforming SOTA baselines like ReKep-Auto.
- PointSO: **74.42%** average zero-shot accuracy in semantic orientation prediction at 5° threshold; robust under real-world input perturbations.
- New SOTA on Open6DOR V2: **48.7%** on Overall 6-DoF Track with reduced planning time; strong zero-shot execution on SIMPLER-Env and articulated-object tasks.

## Takeaways

> [!tip] Key Insights
> - Grounding object orientation in natural language using a unit vector representation (semantic orientation) enables more intuitive and functional robotic understanding for manipulation tasks.
> - Large Language Models (LLMs) like GPT-4o can effectively serve as scalable annotators for complex 3D data, significantly reducing the bottleneck of dataset creation for embodied AI.
> - Simple token-wise addition for cross-modal fusion within a Transformer architecture can be highly effective for integrating high-level language features into 3D geometric processing for orientation prediction.
