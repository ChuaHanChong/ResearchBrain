# Learning-Based Collaborative Control for Bi-Manual Tactile-Reactive Grasping

> [!summary] Summary
> A learning-based collaborative control framework for bi-manual tactile-reactive grasping enables robots to handle fragile, deformable, and irregularly shaped objects with enhanced stability. The multi-agent Model Predictive Controller, utilizing GelSight Mini sensors, achieved higher grasping success rates across various objects and maintained a favorable 45% average runtime increase despite doubling input data.

## Problem

- Most robotic grasping systems struggle with fragile, deformable, or irregularly shaped objects, requiring precise contact force regulation to prevent damage or slippage.
- Single-agent tactile-reactive grasping is limited in handling large, heavy, or elongated objects, which typically demand multiple contact points for stability and effective force distribution.
- Existing single-agent solutions often assume ideal object positioning and orientation, which is not representative of dynamic, unstructured real-world environments.

## Method

- A learning-based ==collaborative multi-agent Model Predictive Controller (MPC)== was developed, integrating two robotic manipulators each equipped with a ==GelSight Mini tactile sensor==.
- The system employs a modified ==ResNet-152 CNN encoder== to compress high-dimensional tactile images into low-dimensional embeddings for each agent, which then feed into a ==differentiable MPC layer==.
- The MPC optimizes a cost function over a prediction horizon, incorporating ==learnable cross-arm coupling parameters== for tactile sensory input coupling between agents and leveraging ==parameter sharing== for computational efficiency.

## Results

- The multi-agent MPC achieved superior grasping success rates (up to **10/10** for several objects like Banana, Pringles Can, PVC Pipe) across all tested objects compared to single-agent MPC and PD baselines.
- Qualitative analysis indicated that the proposed method produced substantially more stable grasps with smaller fluctuations and more consistent gripper positions, demonstrating effective collaborative control.
- Despite effectively doubling input data and increasing matrix dimensions, the multi-agent system showed an average runtime increase of only **45%** for batch sizes greater than one, attributed to efficient parameter sharing.

## Takeaways

> [!tip] Key Insights
> - Bi-manual control, by distributing contact forces across two manipulators, significantly enhances grasping stability for soft and irregularly shaped objects, minimizing localized pressure and potential damage.
> - Integrating real-time, high-resolution tactile feedback from GelSight sensors allows the learning-based MPC to dynamically infer contact dynamics and object compliance, enabling adaptive control policies.
> - Parameter sharing across the CNN and MPC layers in a homogeneous multi-agent framework provides computational efficiency, leading to a less-than-linear increase in runtime despite increased input data and agents.
