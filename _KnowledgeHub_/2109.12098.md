# CLIPort: What and Where Pathways for Robotic Manipulation

> [!summary] Summary
> Researchers from the University of Washington and NVIDIA developed CLIPORT, a system for language-conditioned robotic manipulation. It uses a two-stream architecture inspired by human vision, combining CLIP's semantic understanding with Transporter Networks' spatial precision to enable robots to perform pick-and-place tasks guided by natural language. CLIPORT achieved over 80% success on simulation tasks with 100 demonstrations and demonstrated generalization to unseen objects and real-world deployment.

## Problem

- Bridging the gap between semantic understanding of natural language commands and the precise spatial execution required for robotic manipulation.
- Traditional robotic manipulation systems either excel at precision without semantic understanding or achieve semantic understanding without the fine-grained precision for complex tasks.
- Developing robots that can interpret diverse natural language instructions to manipulate objects in real-world environments.

## Method

- Introduces **CLIPORT**, a ==two-stream architecture== with a ==semantic (ventral) stream== using a frozen CLIP ResNet50 for object identity and a ==spatial (dorsal) stream== using an untrained Transporter ResNet for precise localization.
- Integrates natural language instructions by encoding them into embeddings using ==CLIP's text encoder==, which are then fused with visual features in both streams via ==lateral connections==.
- Formulates manipulation as predicting ==dense pixel-wise pick and place affordances== from RGB-D images, trained using ==imitation learning== from expert demonstrations.

## Results

- CLIPORT achieved superior performance compared to one-stream baselines (Transporter-only, CLIP-only) and other architectures across **10** language-conditioned manipulation tasks in simulation, reaching over **80%** success rate on seen tasks with **100 demonstrations**.
- Demonstrated strong generalization capabilities to unseen object attributes (colors, shapes) and entirely new objects (toys, kitchen utensils) by leveraging CLIP's pre-trained semantic understanding.
- Successfully deployed on a Franka Panda robot arm for real-world manipulation tasks, including colored blocks, insertion, and deformable objects like cloth, processing real camera images and compensating for inaccuracies.

## Takeaways

> [!tip] Key Insights
> - A two-stream architecture, inspired by the human ventral ('what') and dorsal ('where') visual pathways, effectively separates semantic understanding from spatial precision.
> - Integrating pre-trained vision-language models like CLIP for semantic understanding with Transporter Networks for precise spatial manipulation allows for language-conditioned robotic control.
> - Fusing language embeddings with visual features across multiple processing levels enables the model to ground natural language instructions in specific pick-and-place actions.

## Detailed Report

### 1. Introduction

Robots that can interpret natural language commands to manipulate objects in their environment have long been a goal in robotics research. Imagine being able to tell a robot to "put the blue blocks in a green bowl" or "fold the cloth in half" and having it understand and execute these instructions. This capability requires bridging two crucial aspects of intelligence: semantic understanding (what needs to be done) and spatial precision (where and how to do it).

Traditional approaches to robotic manipulation have either excelled at precise manipulation without semantic understanding or achieved semantic understanding without the precision required for fine-grained manipulation. CLIPORT, developed by researchers from the University of Washington and NVIDIA, presents a novel solution to this challenge by combining these capabilities through a two-stream architecture inspired by cognitive neuroscience.

CLIPORT builds upon two key technologies: Transporter Networks for precise spatial manipulation and CLIP (Contrastive Language-Image Pre-training) for semantic understanding. By combining these in a carefully designed architecture, CLIPORT enables robots to perform complex manipulation tasks guided by natural language commands.

### 2. Two-Stream Architecture

The core innovation of CLIPORT is its two-stream architecture, inspired by the ventral and dorsal pathways in the human visual system. In cognitive neuroscience, the ventral ("what") pathway processes object identity and semantics, while the dorsal ("where") pathway handles spatial relationships and action planning.

CLIPORT's architecture mirrors this division:

1. **Semantic (Ventral) Stream**: Processes RGB images using a frozen pre-trained CLIP ResNet50 model, which has been trained on vast amounts of image-text pairs from the internet. This stream understands "what" needs to be manipulated.

2. **Spatial (Dorsal) Stream**: Processes RGB-D (color and depth) images using an untrained Transporter ResNet. This stream specializes in precise spatial localization, determining "where" to act.

3. **Lateral Fusion**: The streams are connected through lateral fusion mechanisms, allowing information to flow between them. This fusion happens at multiple levels of processing, enabling the model to integrate semantic understanding with spatial precision.

The architecture can be described mathematically as:

For the semantic stream with features $v_t^{(l)}$ at layer $l$:
$v_t^{(l+1)} = f_v^{(l)}(v_t^{(l)})$

For the spatial stream with features $d_t^{(l)}$ at layer $l$:
$d_t^{(l+1)} = f_d^{(l)}(d_t^{(l)})$

With lateral fusion:
$v_t^{(l+1)} = f_v^{(l)}(v_t^{(l)} \oplus g_t \cdot d_t^{(l)})$

Where $g_t$ represents the language embeddings from CLIP's text encoder, and $\oplus$ denotes feature concatenation.

### 3. Language-Conditioned Manipulation

CLIPORT enables language-conditioned manipulation by encoding natural language instructions using CLIP's text encoder. The resulting language embeddings are integrated into the processing streams to guide the network's attention toward relevant objects and actions.

For example, given the instruction "put the blue blocks in a green bowl," CLIPORT:

1. Encodes the instruction into a 1024-dimensional language embedding vector
2. Tiles this vector spatially and fuses it with visual features
3. Uses the fused representation to predict where to pick (blue blocks) and where to place (green bowl)

This approach allows CLIPORT to generalize to new instructions involving object attributes (colors, shapes) and spatial relationships that it has learned to ground in visual perception.

### 4. Methodology

CLIPORT formulates tabletop manipulation as a series of pick-and-place actions. The framework predicts two sets of dense pixel-wise affordances:

1. **Pick Affordance**: A probability distribution over possible pick locations
2. **Place Affordance**: A conditional probability distribution over possible place locations, given the chosen pick location

These affordances are predicted using fully convolutional networks that maintain translational equivariance, allowing the model to generalize to objects in positions not seen during training.

The training process uses imitation learning from expert demonstrations. For each demonstration, CLIPORT observes:

- RGB and depth images of the scene
- A language instruction describing the task
- Expert pick and place positions

The model is trained to minimize the cross-entropy loss between predicted affordances and ground truth actions:

$L = -\sum_{i} y_i^{\text{pick}} \log(p_i^{\text{pick}}) - \sum_{j} y_j^{\text{place}} \log(p_j^{\text{place}})$

Where $y_i^{\text{pick}}$ and $y_j^{\text{place}}$ are one-hot representations of the ground truth pick and place positions, and $p_i^{\text{pick}}$ and $p_j^{\text{place}}$ are the predicted probabilities.

### 5. Experimental Results

CLIPORT was evaluated on a suite of 10 language-conditioned manipulation tasks in simulation, ranging from picking and placing blocks to stacking pyramids and manipulating ropes.

The results demonstrate several key findings:

1. **Superior Performance**: CLIPORT significantly outperforms one-stream baselines (Transporter-only, CLIP-only) and other alternative architectures across most tasks.

2. **Data Efficiency**: CLIPORT achieves strong performance with relatively few demonstrations. With just 100 demonstrations per task, it reaches over 80% success rate on seen tasks.

3. **Complementary Capabilities**: The ablation studies confirm that both streams contribute significantly to performance. The semantic stream provides understanding of task objectives, while the spatial stream enables precise execution.

The visualizations of CLIPORT's pick and place affordances reveal how the model grounds language instructions in spatial actions.

### 6. Generalization Capabilities

A key strength of CLIPORT is its ability to generalize to unseen attributes and objects, thanks to the pre-trained CLIP model's rich semantic understanding.

The experiments demonstrate that CLIPORT can:

1. **Generalize to Unseen Colors**: Successfully manipulate objects with colors not seen during training (e.g., orange, purple, pink)

2. **Generalize to Unseen Shapes**: Correctly identify and manipulate novel shapes (e.g., heart, hexagon)

3. **Generalize to Unseen Objects**: Handle completely new objects like toys, kitchen utensils, and office supplies

This generalization capability is illustrated in the following example, where CLIPORT successfully generalizes the concept of "pliers" from a single training example to new types of pliers in testing.

### 7. Real-World Applications

Beyond simulation, CLIPORT was successfully deployed on a Franka Panda robot arm to perform real-world manipulation tasks. The system demonstrates the ability to:

1. Process real camera images with lighting variations and complex textures
2. Compensate for robot kinematic inaccuracies through closed-loop visual feedback
3. Handle real-world objects with varying physical properties

For example, in real-world tests, CLIPORT successfully manipulated colored blocks, performed insertion tasks, and even handled deformable objects like cloth.

### 8. Limitations and Future Work

Despite its impressive capabilities, CLIPORT has several limitations:

1. **Primitive Actions**: The framework is limited to pick-and-place primitives and cannot handle complex 6-DOF manipulation tasks like screwing or pouring.

2. **Multi-Object Reasoning**: CLIPORT struggles with tasks requiring reasoning about relationships between multiple objects, particularly when the relationships are complex.

3. **Task Completion**: The framework relies on an expert to indicate when a task is complete, lacking the ability to determine this autonomously.

4. **Pre-Trained Model Limitations**: The CLIP model can inherit biases and vulnerabilities from its training data, potentially affecting CLIPORT's behavior.

Future work directions include extending the framework to:

1. Support a richer set of manipulation primitives
2. Incorporate feedback mechanisms for determining task completion
3. Enable more complex reasoning about object relationships
4. Deploy the system in more diverse real-world scenarios

### 9. Conclusion

CLIPORT represents a significant advance in language-conditioned robotic manipulation by effectively bridging semantic understanding and spatial precision through its innovative two-stream architecture. By leveraging pre-trained vision-language models like CLIP, it achieves impressive generalization to new tasks and objects while maintaining the precision required for manipulation.

The ability to control robots through natural language instructions opens up new possibilities for human-robot interaction, making robots more accessible to non-expert users and more versatile in unstructured environments. While limitations remain, CLIPORT demonstrates a compelling approach to creating more capable and intuitive robotic systems.

As robotic systems continue to move beyond controlled industrial environments into our homes and workplaces, approaches like CLIPORT that combine semantic understanding with precise manipulation will be essential for enabling robots to assist humans in everyday tasks through natural language communication.
