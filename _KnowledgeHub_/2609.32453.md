# DRAM: Delta-rule Recurrent Associative Memory for Robot Manipulation Policies

> [!summary] Summary
> DRAM is a plug-and-play memory module that gives frozen pretrained robot policies long-horizon history at a fixed state size. It keeps a gated delta-rule associative memory and writes all tokens of a frame at once through one closed-form ridge solve. Patches read memory before each write, and a zero-initialized residual fuses the readout. DRAM reaches 99.0% average on LIBERO and 57.8% on RMBench.

## Problem

- Most pretrained robot policies condition only on the current observation or a short window, so information from earlier steps cannot shape decisions in partially observable, multi-stage tasks.
- Existing memory approaches feed multi-frame windows that raise inference cost, or rely on hand-defined semantic features that limit generality and often require retraining the backbone.
- Additive linear-attention memory piles new associations onto old ones without removing them, and token-by-token delta updates make a frame's write depend on an arbitrary patch order.

## Method

- ==Frame-synchronous joint write==: each frame's key-value pairs in **DRAM** are written jointly as one ==proximal least-squares== problem anchored to the decayed state, solved by ==Cholesky factorization== and differentiated implicitly.
- ==Gating==: a per-frame ==softplus retention gate== decays the state, and per-token write strengths in odds form make the joint write reduce exactly to the ==gated delta rule== for one token.
- ==Patch-level read-before-write== with a ==zero-initialized gated residual FUSE==, attached as learned query slots for pi0.5 or as shared-source tokens for DiT, and trained by ==TBPTT== with the backbone frozen.

## Results

- On LIBERO with pi0.5, DRAM averages **99.0%**, beating HAMLET's **97.6%**, and reaches **99.0%** on LIBERO-10 against **95.8%** for the next-best memory method.
- Matched-backbone tests: DiT rises from **84.31%** to **94.63%** average (LIBERO-10 from **75%** to **91%**), and pi0.5 rises from **97.5%** to **99.0%**; Native KV write sources work best.
- On RMBench, DRAM averages **57.8%** against **42.0%** for Mem-0 and wins **8 of 9** tasks. On a real robot, the full task rises from **0%** to **85%**.

## Takeaways

> [!tip] Key Insights
> - When all tokens of one observation arrive together, treat the whole frame as one recurrent write step; serializing them adds an order bias that has no physical meaning.
> - A frozen backbone plus a zero-initialized residual memory branch, trained only by the control loss, can add memory to a policy without auxiliary memory objectives.
> - A policy trained with memory comes to depend on it: periodic resets push LIBERO-10 to about 75%, below the no-memory baseline, so continuity of state must be guaranteed.

## Detailed Report

### 1. Overview

Many manipulation tasks depend on history. An image may no longer show an object, a completed task stage, or the outcome of an earlier interaction, so two similar-looking current observations can call for different actions. DRAM does not feed a growing stack of past images to the policy. Instead, it keeps a compact memory, lets the current image query that memory, and then updates it for the next observation.

On a longer real-world loading task, the authors kept the same DiT-based policy and changed only the memory; all other training and evaluation settings were unchanged. Without DRAM, the policy succeeded in 0% of Full Task trials. With DRAM, it succeeded in 85%. Each task-policy setting had 20 trials.

Real-world success rates (%) for the same DiT policy with and without DRAM, 20 trials per setting. Insertion: 90.0% vs. 100.0%. Full Task: 0.0% vs. 85.0%.

### 2. One frame, one memory update

Linear attention can act as an associative memory. It stores cue–information associations in a recurrent matrix, and a current query can retrieve a value associated with a cue. These associations can be written in two ways:

- An additive write simply accumulates associations.
- A delta-rule write first retrieves the current prediction and then writes the correction.

DRAM uses a delta-rule write. Its update corrects existing associations rather than piling new ones on top.

DRAM treats each whole frame as one moment in time. Its patch tokens are local visual representations from the current image. They count as simultaneous inputs, not a time-ordered sequence. Each step of DRAM's cycle runs in this order:

1. The frozen host policy encodes the current observation and supplies query and write tokens.
1. Every query retrieves from the previous memory state, before the current frame is written, which produces patch-specific historical features.
1. A gated residual fuses those features with the current representation for action prediction.
1. A frame-level retention gate and a joint delta update use the current frame's key–value associations to form the next state.

Retrieving before writing prevents the current frame from entering its own retrieval. The joint write fits all of the current associations together. It does not serially update the state in an arbitrary patch order. The state has a fixed size, so persistent storage does not grow with episode length.

The vision tower and the vision-language model backbone stay frozen. Training on the downstream control objective updates only the memory, adapter and action expert, with no separate memory-specific loss.

Conceptual overview (paper Figure 1). Left: instruction, robot state and visual input enter a VLA encoder. Current-frame token representations interact with a DRAM memory bank carried across frames, producing memory-augmented representations for the action expert. Right: READ queries retrieve from the previous state and are fused through a gate. WRITE updates memory from the current frame for later use.

### 3. What the comparisons establish

LIBERO success rate is the percentage of evaluation episodes that succeed. The benchmark has four suites: Spatial, Object, Goal and LIBERO-10, and LIBERO-10 is the longer-horizon suite. The paper's "Average" is the arithmetic mean of the four suite-level success rates.

The strongest evidence comes from matched comparisons, where the same policy is tested with and without DRAM. On LIBERO-10, the DiT policy's success rate rises from 75% to 91%, a gain of 16 percentage points. DiT improves in all four suites. π0.5 improves on Spatial, Object and LIBERO-10, and it holds at 98% on Goal.

The main cross-method table is less conclusive. In that table, published baselines used their own training and evaluation protocols.

Success rates (%) on the four LIBERO suites for DiT and π0.5, each with and without DRAM. Bold marks the better result within each pair, including ties. Average: DiT 84.31 / 94.63; π0.5 97.50 / 99.00.

The real-robot results add practical evidence. Insertion success is 90% versus 100%, but the more consequential difference is on the longer Full Task. The authors interpret that larger gain as support for persistent memory in this real-world setting.

There are limits to what these results show. The paper proves that the joint write is invariant to within-frame token permutation in exact arithmetic. However, it reports no direct ablation against sequential token writes or against a competing delta-update rule. The gains therefore cannot be attributed to the joint update alone.

### 4. Memory between frames

DRAM maintains a fixed-size memory state. It treats each image as a simultaneous observation and retrieves past context before writing the current frame. Matched policy comparisons show gains in the tested tasks. The paper does not measure latency or total inference cost. Its bounded persistent state also does not bound training activation memory, which grows with the TBPTT window length.
