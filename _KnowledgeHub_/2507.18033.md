# OpenNav: Open-World Navigation with Multimodal Large Language Models

> [!summary] Summary
> Researchers at the University of Toronto present OpenNav, a framework that enables robots to perform open-world navigation by interpreting complex, free-form language instructions and synthesizing dense trajectory points. It achieves zero-shot open-world navigation with improved success rates and lower navigation errors compared to text-only approaches, while maintaining geometry-compliant and collision-free trajectories.

## Problem

- Existing robot navigation methods are often confined to structured or "closed-set" scenarios, struggling with generalization in complex, unstructured open-world environments characterized by open-set objects and inherent uncertainty.
- Many approaches decouple perception (e.g., object detection) from LLM-based reasoning, losing crucial spatial and visual information, which limits adaptability to rich real-world scenes.
- Translating an MLLM's abstract reasoning into concrete, continuous, and geometry-compliant physical robot actions remains challenging, often relying on limited, predefined motion primitives rather than direct trajectory synthesis.

## Method

- Introduces **OpenNav**, a zero-shot ==Vision-Language Navigation (VLN)== framework that leverages Multimodal Large Language Models (MLLMs), an open-vocabulary perception system (OVPS), and classical motion planning.
- Employs a single, task-agnostic prompt for the MLLM (ChatGPT-4o) that guides its reasoning and code generation for dense trajectories, without requiring pre-trained skills or in-context examples.
- Integrates the MLLM with an OVPS that provides both textual descriptions and annotated RGB images for robust object understanding, and uses classical A* planning with dynamic Bird-Eye-View (BEV) value maps for geometry-compliant, collision-free trajectory refinement.

## Results

- OpenNav achieved an **84%** success rate in ambiguous object navigation tasks, substantially outperforming text-only LLM-TG which had a **26%** success rate.
- The framework demonstrated a lower average navigation error of **1.68** in ambiguous object navigation compared to LLM-TG's **4.91**.
- OpenNav produced trajectories with the best language alignment (Fréchet Distance: **12.60**, NDTW: **0.38**) while maintaining a low collision rate (2/30), effectively balancing intent with safety.

## Takeaways

> [!tip] Key Insights
> - Providing multimodal input (annotated images and text) to MLLMs significantly enhances their ability to resolve ambiguities and robustly interpret instructions in open-world scenarios, outperforming text-only approaches.
> - MLLMs can effectively synthesize executable Python code for generating dense, task-aligned trajectories, bridging the gap between high-level language understanding and low-level robot control.
> - A hybrid approach combining MLLM-based semantic reasoning for coarse trajectory generation with classical geometry-compliant path planning is crucial for achieving both language alignment and collision-free, safe navigation.
