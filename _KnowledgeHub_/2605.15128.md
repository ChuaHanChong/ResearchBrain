# MemEye: A Visual-Centric Evaluation Framework for Multimodal Agent Memory

> [!summary] Summary
> MemEye introduces a visual-centric evaluation framework and benchmark to assess multimodal agent memory, specifically targeting the preservation and reasoning over fine-grained, temporally evolving visual evidence. Through this framework, the study reveals that current VLM-based agents exhibit significant limitations in retaining high-granularity visual details and synthesizing coherent world states from dynamic visual observations.

## Problem

- Existing evaluations for multimodal agent memory primarily focus on textual information or permit visual questions to be answered using captions, masking agents' inability to retain crucial visual details.
- Current agents frequently fail to preserve fine-grained visual evidence, such as region layouts, object identities, or textures, as these details are often lost when images are compressed into textual representations.
- Benchmarks largely neglect scenarios that require agents to reason about evolving visual states, where visual information changes, updates, or conflicts across different interaction sessions.

## Method

- The MemEye framework was developed, a two-dimensional taxonomy that categorizes memory challenges by Visual Evidence Granularity (X1-X4: Scene to Pixel-level) and Memory Reasoning Depth (Y1-Y3: Atomic Retrieval to Evolutionary Synthesis).
- A new benchmark was constructed with 371 questions across eight life-scenario tasks, employing a multi-stage filtering process to ensure questions require genuinely irreplaceable visual evidence.
- Thirteen diverse memory methods were evaluated across four VLM backbones, categorized into text-based (converting images to captions) and multimodal (processing original images) approaches, using Exact-Match and LLM-as-a-Judge metrics.

## Results

- Performance consistently degraded as the required visual granularity increased (X1 to X4), with native visual memory methods demonstrating substantial advantages over text-based methods for high-granularity tasks (X3, X4).
- Reasoning complexity (Y1 to Y3) also significantly impacted performance, with retrieval-oriented methods struggling in evolutionary synthesis (Y3) where methods like M2A and Reflexion, which incorporate abstraction or explicit revision, showed competitiveness.
- Diagnostic probes confirmed that image-based memory systems yielded higher gains for high-granularity questions compared to dense-caption memory, empirically validating the loss of fine-grained details in text abstractions. Oracle evidence in Y3 questions showed that failures often stemmed from the inability to identify the *currently valid visual state* rather than inherent visual unreadability.

## Takeaways

> [!tip] Key Insights
> - Current multimodal agent memory systems struggle significantly with both preserving fine-grained visual details and performing complex reasoning over the temporal evolution of visual states.
> - Textual abstractions of images, even dense captions, inherently lose critical instance-level and pixel-level visual details that are often indispensable for specific tasks.
> - Simply having access to raw images is insufficient for dynamic environments; systems must explicitly interpret the temporal context of visual evidence to identify and prioritize the currently valid visual state.
