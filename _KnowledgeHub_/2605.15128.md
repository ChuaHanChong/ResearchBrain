# MemEye: A Visual-Centric Evaluation Framework for Multimodal Agent Memory

> [!summary] Summary
> MemEye introduces a visual-centric evaluation framework and benchmark to assess multimodal agent memory, specifically targeting the preservation and reasoning over fine-grained, temporally evolving visual evidence. Through this framework, the study reveals that current VLM-based agents exhibit significant limitations in retaining high-granularity visual details and synthesizing coherent world states from dynamic visual observations.

## Problem

- Existing evaluations for multimodal agent memory primarily focus on textual information or permit visual questions to be answered using captions, masking agents' inability to retain crucial visual details.
- Current agents frequently fail to preserve fine-grained visual evidence, such as region layouts, object identities, or textures, as these details are often lost when images are compressed into textual representations.
- Benchmarks largely neglect scenarios that require agents to reason about evolving visual states, where visual information changes, updates, or conflicts across different interaction sessions.

## Method

- The **MemEye** framework was developed, a two-dimensional taxonomy that categorizes memory challenges by Visual Evidence Granularity (X1-X4: Scene to Pixel-level) and Memory Reasoning Depth (Y1-Y3: Atomic Retrieval to Evolutionary Synthesis).
- A new benchmark was constructed with 371 questions across eight life-scenario tasks, employing a multi-stage filtering process to ensure questions require genuinely irreplaceable visual evidence.
- Thirteen diverse memory methods were evaluated across four VLM backbones, categorized into text-based (converting images to captions) and multimodal (processing original images) approaches, using Exact-Match and LLM-as-a-Judge metrics.

## Results

- Performance consistently degraded as the required visual granularity increased (X1 to X4), with native visual memory methods demonstrating substantial advantages over text-based methods for high-granularity tasks (X3, X4).
- Reasoning complexity (Y1 to Y3) also significantly impacted performance, with retrieval-oriented methods struggling in evolutionary synthesis (Y3) where methods like M2A and Reflexion, which incorporate abstraction or explicit revision, showed competitiveness.
- Diagnostic probes confirmed that image-based memory systems yielded higher gains for high-granularity questions compared to dense-caption memory, empirically validating the loss of fine-grained details in text abstractions. Oracle evidence in Y3 questions showed that failures often stemmed from the inability to identify the *currently valid visual state* rather than inherent visual unreadability.

## Takeaways

> [!tip] Key Insights
> - Current multimodal agent memory systems struggle significantly with both preserving fine-grained visual details and performing complex reasoning over the temporal evolution of visual states.
> - Textual abstractions of images, even dense captions, inherently lose critical instance-level and pixel-level visual details that are often indispensable for specific tasks.
> - Simply having access to raw images is insufficient for dynamic environments; systems must explicitly interpret the temporal context of visual evidence to identify and prioritize the currently valid visual state.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development of long-term memory is a critical area in the construction of intelligent agents, particularly with the advent of Vision-Language Models (VLMs). These models enable agents to process and integrate both textual and visual inputs, necessitating memory systems capable of retaining and reasoning over multimodal information across extended interactions. While human visual memory can store rich object details and track scene changes over time, existing evaluations for VLM-based agents exhibit limitations in assessing these specific capabilities.

Prior benchmarks for long-term agent memory have predominantly focused on textual information or, if multimodal, often permit visually grounded questions to be answered through captions, surrounding dialogue, or answer options, rather than requiring the preservation and utilization of fine-grained visual evidence. For instance, benchmarks such as LoCoMo, MMRC, and Mem-Gallery have shown smaller gains when original images are provided compared to when only captions are used, suggesting a weaker dependence on authentic visual information. Furthermore, scenarios that require agents to reason about evolving visual states, where visual information changes over time, are largely underrepresented in current evaluation schemes.

These limitations pose two core challenges within the research landscape:
1. **Preservation of Fine-Grained Visual Details**: Agents frequently fail to retain visual evidence at the necessary level of detail, such as region layouts, object identities, or fine textures, as these are often lost when images are compressed into textual representations.
2. **Reasoning Beyond Simple Retrieval**: Agents struggle to reason over their history when it involves linking evidence across multiple sessions, handling updates, or synthesizing a current world state from evolving observations, rather than merely retrieving isolated facts.

MemEye positions itself within this landscape by introducing a framework and benchmark specifically designed to address these unaddressed challenges. It aims to provide a visual-centric evaluation that rigorously tests whether agents can preserve irreplaceable visual evidence and perform complex reasoning over its temporal evolution, thereby offering a more diagnostic assessment of multimodal agent memory systems compared to prior work.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop and validate a comprehensive framework and benchmark, named MemEye, for evaluating the long-term multimodal memory capabilities of VLM-based intelligent agents. This evaluation specifically targets the agents' capacity to preserve and reason over visual evidence, particularly in scenarios where such evidence is fine-grained and evolves over time.

The motivation for this work stems from identified limitations in existing methodologies for assessing agent memory:

- **Inadequate Evaluation of Visual Information Necessity**: Current benchmarks frequently do not ascertain whether the original visual information is genuinely indispensable for answering questions. Many "visually grounded" questions can be resolved using only textual descriptions (e.g., captions or dialogue), which masks an agent’s potential inability to retain or process actual visual cues. The authors observed that prior benchmarks show smaller performance differences between "caption-only" and "multimodal" settings, indicating a lack of true visual dependence. This motivated the creation of a benchmark where visual evidence is irreplaceable.
- **Neglect of Fine-Grained Visual Details**: While text captions can summarize general scene information, they often omit specific attributes critical for understanding, such as precise object identities, spatial layouts within regions, or fine textures. These details are frequently lost during the compression of visual data into textual format. A key motivation was to evaluate if agents could preserve and utilize these specific, high-granularity visual attributes.
- **Limited Assessment of Reasoning Over Evolving States**: Existing evaluations largely overlook scenarios where visual states change, update, or conflict across different interaction sessions. This makes it difficult to determine if agents can track temporal validity, link evidence across sessions, and synthesize a coherent, updated understanding of the world state as new observations supersede old ones. The research aims to introduce complex reasoning challenges involving non-monotonic memory synthesis.
- **Need for Diagnostic Failure Analysis**: Many evaluations provide aggregate performance metrics without isolating the specific sub-components of memory that fail. A system might discard crucial perceptual details during abstraction, retrieve semantically relevant but temporally stale information, or fail to synthesize a valid state even when relevant evidence is available. The motivation was to create a framework that can diagnose *when* and *why* a memory system fails, rather than just *if* it fails.

In summary, the detailed objectives include proposing a novel, two-dimensional evaluation framework (MemEye), constructing a benchmark with a strong emphasis on irreplaceable visual evidence across diverse life-scenario tasks, and employing this benchmark to conduct a comprehensive evaluation of existing memory methods to provide empirical insights into their strengths and weaknesses concerning visual preservation and temporal reasoning.

### 3. Methodology and Approach

The methodology employed in this research centers around the introduction of the MemEye framework, which serves as a two-dimensional taxonomy for evaluating multimodal agent memory, complemented by a newly constructed benchmark and a comprehensive experimental setup.

**MemEye Framework Design:**
The framework organizes multimodal memory challenges along two orthogonal dimensions, forming a coordinate system (X, Y):

- **X-axis: Visual Evidence Granularity**: This dimension measures the level of detail of decisive visual evidence required to answer a question, ranging from coarse to fine-grained:
 - **X1: Scene-level**: Evaluates preservation of global semantic gist, scene type, activity, often recoverable from a general caption.
 - **X2: Region-level**: Assesses perception and reasoning over semantically coherent subregions, local context, and interactions.
 - **X3: Instance-level**: Focuses on localizing and distinguishing specific object or person instances, emphasizing entity identity across images, which captions often struggle to preserve.
 - **X4: Pixel-level**: Requires reasoning over minute visual details such as exact color, texture, small text, or precise counts, cues typically absent from text.

- **Y-axis: Memory Reasoning Depth**: This dimension captures the complexity of reasoning operations needed over retrieved memory to answer a question, moving from simple recall to complex synthesis:
 - **Y1: Atomic Retrieval**: Measures the ability to retrieve a single fact from memory without requiring cross-session reasoning or composition.
 - **Y2: Relational Association**: Evaluates the capacity to associate distributed, non-conflicting evidence across multiple sessions, modalities, or references, implying monotonic information accumulation.
 - **Y3: Evolutionary Synthesis**: Tests non-monotonic reasoning where the model must handle updates, conflicts, or overrides of information, inferring a coherent, currently valid world state from evolving evidence.

Each question in the benchmark is assigned an (X, Y) coordinate based on the highest-bottleneck rule, indicating the most demanding level of visual detail and reasoning depth required.

**Benchmark Construction:**
A new benchmark was constructed under the MemEye framework, comprising 371 questions mirrored into multiple-choice (MCQ) and open-ended formats (742 QA pairs). The benchmark involves 221 sessions, 848 dialogue rounds, and 438 images across eight life-scenario tasks grouped into four domains: Leisure, Domestic, Professional, and Personal. Images originate from diverse sources including public, archival, and generated content (e.g., photographs, comic panels, UI screenshots).

To ensure the benchmark's visual-centricity and prevent shortcut answers, a rigorous multi-stage filtering process was applied to each question:
1. **Eliminating Answer Leakage (Leakage Filter)**: Questions solvable from only the question text, answer choices, and gold clue-round text (without images or captions) were identified and removed.
2. **Eliminating Visual Bypass-ability (Bypass Filter)**: Images were replaced with minimal, generic captions. Questions still answerable under this condition were revised or removed, confirming the necessity of original visual evidence.
3. **Controlling Problem Difficulty (Difficulty Calibration)**: Models were tested on questions with the relevant image and answer-specific context provided. If models failed, it indicated a limitation of the underlying VLM rather than a memory issue, leading to revision or removal.
This process ensured that selected questions required genuine visual information and were suitable for evaluating memory rather than foundational recognition abilities.

**Evaluation Setup:**
The study evaluated 13 memory methods across four VLM backbones: Qwen3-VL-8B-Instruct, GPT-4.1-nano, GPT-5.4-mini, and Gemini-2.5-flash-lite. The memory methods were categorized into:
- **Text-based Memory (7 methods)**: These methods (e.g., Full Context (T), Semantic RAG (T), Reflexion, Generative Agents) operated by converting all images into dense textual captions (using GPT-5.2) before storage and processing.
- **Multimodal Memory (6 methods)**: These methods (e.g., Full Context (V), Semantic RAG (V), MIRIX, MMA) directly operated on the original visual inputs.
Evaluation metrics included Exact-Match accuracy (EM) for multiple-choice questions and LLM-as-a-Judge (primary) and BLEU-1 (auxiliary) for open-ended questions. An extensive human-judge agreement study confirmed the reliability of the LLM-as-a-Judge metric (Cohen’s κ = 0.94).

**Framework Validation:**
The framework's axes were validated through specific diagnostics:
- **Caption-Proof Diagnostic**: Quantified the performance gap (Acc_image - Acc_caption) between native-image and dense-caption memory, confirming that the X-axis effectively captures visual granularity challenges.
- **Oracle-Evidence Diagnostic**: Assessed performance when models were provided with gold-truth clue rounds and original images, isolating reasoning capabilities from retrieval challenges and confirming that the Y-axis reflects increasing reasoning depth.

### 4. Main Findings and Results

The comprehensive evaluation conducted using the MemEye framework revealed that current multimodal agent memory systems face significant challenges, operating far from saturation on the benchmark. The findings pinpoint specific failure modes related to visual evidence granularity and reasoning over evolving states.

**Overall Performance and Interacting Stressors:**
- **Aggregate Performance**: Semantic RAG (V) achieved the highest aggregate performance with an LLM-as-a-Judge score of 0.4937 for open-ended questions and an EM score of 0.6177 for multiple-choice questions (using gpt-5.4-mini). The observed disparity between EM and LLM-as-a-Judge scores suggests that while models might select correct options, they struggle to articulate precise memory states in open-ended responses.
- **Visual Granularity (X-axis) as a Stressor**: Performance consistently degraded as the required visual granularity increased (from X1 to X4). For low-granularity questions (X1, X2), text-based memory methods were competitive with multimodal methods. However, for high-granularity questions (X3, X4), native visual memory methods (e.g., SRAG(V), MMA) demonstrated substantial performance advantages over their text-based counterparts. This indicates that text abstractions (even dense captions) often lose critical instance-level and pixel-level details.
- **Reasoning Depth (Y-axis) as a Stressor**: The complexity of reasoning over memory also significantly impacted performance. Retrieval-oriented methods (e.g., SRAG(V)) performed well in Y1 (atomic retrieval) and Y2 (relational association) scenarios. However, their advantage diminished in Y3 (evolutionary synthesis) scenarios, where agents must resolve updates, conflicts, or overrides of information. In these Y3 cases, methods incorporating abstraction or explicit revision mechanisms (e.g., M2A, Reflexion) sometimes became more competitive, suggesting that structuring state transitions can be beneficial even if visual details are generalized. No single architecture performed optimally across all (X, Y) coordinates, indicating a trade-off between preserving fine visual details and managing evolving states.

**Analysis of Visual Information Loss (RQ2):**
- **Caption-Proof Diagnostic**: The evaluation of the Caption-Proof diagnostic demonstrated that image-based memory systems showed significantly higher gains over dense-caption memory for high-X questions (instance-level and pixel-level evidence) compared to low-X questions (scene-level and region-level evidence). This empirically confirmed that dense captions often fail to preserve decisive fine-grained visual details.
- **Caption Robustness Ablation**: Further investigation with stronger, task-aware captions, which were 2-3 times longer and more detailed, showed that while performance of text-based methods improved, a notable performance gap between caption-only and native-image input still persisted for high-X, particularly X4. This implies a fundamental limitation in fully capturing certain fine visual details (e.g., exact colors, small text, identity bindings) through textual mediation alone.

**Analysis of Evolving Visual State Loss (RQ3):**
- **Challenges in Y3**: The benefits of native image preservation were less pronounced in Y3 questions, where answers rely on the temporal validity of visual states. This suggests that simply having access to raw images is insufficient; the system must also interpret their temporal context.
- **Oracle-Evidence Probe**: When oracle evidence (gold-truth rounds and original images) was provided, performance in Y3 questions was significantly higher than that of any memory system. Furthermore, providing only the latest valid visual state (Latest-only) yielded performance close to the full oracle chain. This indicated that failures in Y3 often stemmed from systems' inability to identify and prioritize the *currently valid visual state* from a history, rather than from inherent visual unreadability.
- **Retrieval Diagnostics**: Analysis of retrieval-based methods (e.g., SRAG(V)) revealed that while they frequently retrieved evidence related to the correct topic in Y3 questions, they often missed the decisive latest clue or failed to recover the complete update chain. Semantic similarity in retrieval did not guarantee temporal validity, leading to the dominance of stale evidence in many cases.
- **Recency Signal and Cross-Topic Scaling**: A recency re-ranking probe showed that incorporating temporal signals could reduce the dominance of stale evidence in retrieval, but it could not recover relevant clues that were not initially retrieved. Moreover, a cross-topic dialogue scaling ablation demonstrated that full-context memory methods were highly sensitive to irrelevant information as history length and topic diversity increased. In contrast, retrieval-based and structured memory mechanisms (e.g., SRAG(V), MMA) maintained greater stability by filtering irrelevant evidence, highlighting the importance of routing mechanisms in long histories.

In conclusion, the findings indicate that current systems grapple with two distinct but interacting challenges: preserving fine-grained visual details (high X) and tracking the temporal evolution of visual states (high Y). Text-based memory can aid in structuring state changes but loses visual fidelity, while image-based memory preserves details but struggles with temporal validity.

### 5. Significance and Potential Impact

The MemEye framework and its accompanying benchmark offer several significant contributions to the field of multimodal AI agents, with potential impacts on future research and development:

- **Diagnostic Evaluation Capabilities**: MemEye introduces a diagnostic framework that moves beyond aggregate performance metrics by precisely categorizing memory failures along two critical dimensions: visual evidence granularity and memory reasoning depth. This allows researchers to pinpoint specific weaknesses in multimodal agent memory systems, determining whether failures stem from the inability to preserve fine visual details, to retrieve temporally valid evidence, or to synthesize a coherent state from evolving information. This diagnostic power is crucial for targeted system improvement.

- **Guidance for Memory Architecture Design**: The empirical findings provide concrete implications for the design of future multimodal memory architectures:
 - **Necessity of Native Image Preservation**: For tasks requiring fine-grained visual details (high-X scenarios), the research demonstrates that text-based summaries or captions, even highly detailed ones, are often insufficient. This indicates that future memory systems must incorporate mechanisms for preserving native image evidence to retain crucial instance-level and pixel-level information.
 - **Importance of Temporal State Tracking**: For scenarios involving evolving visual states (high-Y scenarios), merely storing images is not enough. Systems require advanced mechanisms to track temporal validity, resolve conflicts, and prioritize the most current visual evidence over stale information. This suggests a need for memory components that can manage updates, overrides, and an explicit understanding of chronological changes.
 - **Hybrid Memory Approaches**: The observed trade-offs between text-based and image-based memory imply that effective long-term multimodal memory systems will likely be hybrid. They should combine the detail-preserving capabilities of image-based memory with the state-managing and organizational strengths of text-based or structured memory records, augmented by intelligent evidence routing and selection mechanisms (e.g., temporal signals, filtering of irrelevant history).

- **Advancing Multimodal Agent Capabilities**: By exposing the current limitations of VLM-based agents in handling complex visual memory tasks, MemEye directly contributes to the development of more capable and reliable multimodal agents. Addressing these identified failure modes can lead to agents that can genuinely understand, remember, and reason about dynamic and visually rich environments over extended periods. This has implications for various applications, including robotics, interactive assistants, and personalized AI experiences.

- **Ethical Considerations and Future Directions**: The paper also touches upon broader impacts, specifically acknowledging the increased privacy risks associated with more robust visual memory systems that store user images or personal environment data. This highlights the need for integrating ethical design principles, such as consent, data minimization, deletion policies, and access control mechanisms, into the development of future multimodal memory architectures. The work also suggests avenues for future research, including exploring broader human baselines and conducting deployment-scale studies to further validate and refine these memory systems in real-world contexts.
