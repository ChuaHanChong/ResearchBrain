# INTELLECT-2: A Reasoning Model Trained Through Globally Decentralized Reinforcement Learning

> [!summary] Summary
> A decentralized reinforcement learning framework enables training of a 32-billion parameter language model across distributed compute nodes, demonstrating improved performance on mathematics and coding tasks while reducing reliance on centralized infrastructure through novel asynchronous training methods and verifiable inference protocols.

## Problem

- Traditional LLM training requires massive centralized computing resources, limiting access to well-funded organizations
- Existing distributed training approaches face challenges with trust, verification, and efficient resource utilization

## Method

- Custom infrastructure (==PRIME-RL==, ==SHARDCAST==) for decentralized RL training across untrusted nodes
- ==Modified GRPO training== with two-sided clipping and ==TOPLOC verification== for stable distributed learning
- ==Asynchronous training pipeline== optimizing compute-communication overlap

## Results

- Successfully trained **32B** parameter model with improved mathematics and coding performance vs QwQ-32B baseline
- Achieved efficient resource utilization with high ratio of inference to training compute
- Released open-source implementation enabling wider access to LLM training infrastructure
- Demonstrated stable training across heterogeneous computing environments through modified GRPO objective

## Takeaways

> [!tip] Key Insights
> - Reinforcement learning is naturally suited for decentralized training due to its asynchronous nature
> - Separating trusted training nodes from untrusted inference nodes enables scalable distributed compute
> - Test-time compute scaling represents a new axis for improving LLM capabilities
