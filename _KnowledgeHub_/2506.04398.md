# Bridging the Performance Gap Between Target-Free and Target-Based Reinforcement Learning

> [!summary] Summary
> Iterated Shared Q-Learning (iS-QL) offers a deep reinforcement learning method that closes the performance gap between target-free and target-based approaches, notably reducing memory usage. This technique matches or exceeds the performance of target-based algorithms across a wide range of online, offline, discrete, and continuous control tasks.

## Problem

- Target networks, crucial for stabilizing deep reinforcement learning, introduce a significant memory overhead by duplicating Q-networks.
- Target-free methods, while memory-efficient, frequently suffer from training instabilities, reduced sample efficiency, and degraded final performance.
- Deep reinforcement learning typically presents a binary choice between memory efficiency (target-free) and learning stability/performance (target-based), lacking a robust intermediate solution.

## Method

- The method, **iS-QL**, utilizes a ==single Q-network== where only the parameters of the last linear layer are copied to form a 'target head,' while the feature extractor is shared and updated online.
- Iterated Shared Q-Network (iS-QN) extends this by employing K+1 linear heads with a shared feature extractor, training each online head against the Bellman target derived from the previous head.
- A periodic update mechanism propagates learned value functions down the chain of heads, effectively approximating K consecutive Bellman iterations in parallel, while action sampling encourages exploration across different temporal horizons.

## Results

- iS-DQN K=9 outperformed target-based DQN by **6%** AUC with approximately half the parameters on Atari games, while iS-SAC K=1 recovered performance with a **49%** parameter reduction on DeepMind Control tasks.
- The approach effectively closed the performance gap between target-free and target-based methods across diverse settings, including online/offline, discrete/continuous control, language-based RL, and streaming RL.
- Analysis revealed that iS-QN yielded higher gradient cosine similarity to target-based methods, achieved greater target stability than target-free approaches, and produced more expressive feature representations.

## Takeaways

> [!tip] Key Insights
> - Stabilizing deep reinforcement learning and achieving target-based performance is possible with significantly reduced memory by sharing feature extractors and maintaining only light-weight target heads.
> - Chained Bellman updates within a single network, where each head learns from the previous one, enhances learning stability and sample efficiency without duplicating the entire network.
> - The proposed method fosters richer state representations and aligns gradient dynamics more closely with stable target-based approaches, contributing to its improved performance.
