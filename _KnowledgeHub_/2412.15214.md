# LeviTor: 3D Trajectory Oriented Image-to-Video Synthesis

> [!summary] Summary
> A new image-to-video synthesis framework, LeviTor, introduces 3D trajectory control by abstracting object masks into depth-augmented cluster points, enabling users to define complex object movements with interactive depth adjustment. The system generated videos with improved quality, achieving an FVD of 190.44 and FID of 25.41 in multi-point control scenarios, and accurately depicted mutual occlusions and perspective changes.

## Problem

- Existing 2D trajectory-based image-to-video synthesis methods face ambiguity when representing out-of-plane or depth-changing object movements.
- Achieving precise 3D object trajectory control in video generation typically requires complex 3D tools or dense per-frame 3D inputs, which are not user-friendly.
- Generating physically plausible videos that correctly handle occlusions and perspective changes for moving objects remains a challenge for controllable I2V models.

## Method

- **LeviTor** introduces a novel control signal that abstracts object masks into K-means clustered points, augmented with relative depth and instance information.
- A user-friendly inference pipeline allows users to draw 2D trajectories and interactively adjust point depths, which is then converted into a dense, physically consistent multi-point control signal.
- The framework fine-tuned a ==ControlNet==-enhanced ==Stable Video Diffusion== model on the SA-V dataset to effectively integrate these 3D trajectory controls for video generation.

## Results

- LeviTor quantitatively outperformed baselines like DragAnything and DragNUWA **1.5** in video quality (FVD **190.44** vs. **324.95** and **299.96**) and image quality (FID **25.41** vs. **36.04** and **42.34**) in multi-point control scenarios.
- Qualitative evaluations demonstrated the model's ability to generate videos with accurate mutual occlusion control, realistic forward/backward object movements, and complex 3D orbital motions.
- Ablation studies confirmed the importance of instance and depth information, with a moderate number of clustered control points effectively balancing rigid and non-rigid motion generation.

## Takeaways

> [!tip] Key Insights
> - Abstracting object masks into sparse, depth-augmented K-means cluster points provides an effective and compact representation for encoding 3D motion information for generative models.
> - Dynamically rendering 3D-transformed object masks back to 2D for K-means clustering ensures physically plausible motion, perspective scaling, and occlusion handling.
> - Combining intuitive 2D drag interaction with interactive depth adjustment offers an accessible method for users to specify 3D trajectories, overcoming limitations of purely 2D or complex 3D input.
