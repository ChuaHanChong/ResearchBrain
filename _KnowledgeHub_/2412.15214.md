# LeviTor: 3D Trajectory Oriented Image-to-Video Synthesis

> [!summary] Summary
> A new image-to-video synthesis framework, LeviTor, introduces 3D trajectory control by abstracting object masks into depth-augmented cluster points, enabling users to define complex object movements with interactive depth adjustment. The system generated videos with improved quality, achieving an FVD of 190.44 and FID of 25.41 in multi-point control scenarios, and accurately depicted mutual occlusions and perspective changes.

## Problem

- Existing 2D trajectory-based image-to-video synthesis methods face ambiguity when representing out-of-plane or depth-changing object movements.
- Achieving precise 3D object trajectory control in video generation typically requires complex 3D tools or dense per-frame 3D inputs, which are not user-friendly.
- Generating physically plausible videos that correctly handle occlusions and perspective changes for moving objects remains a challenge for controllable I2V models.

## Method

- **LeviTor** introduces a novel control signal that abstracts object masks into K-means clustered points, augmented with relative depth and instance information.
- A user-friendly inference pipeline allows users to draw 2D trajectories and interactively adjust point depths, which is then converted into a dense, physically consistent multi-point control signal.
- The framework fine-tuned a ==ControlNet==-enhanced ==Stable Video Diffusion== model on the SA-V dataset to effectively integrate these 3D trajectory controls for video generation.

## Results

- LeviTor quantitatively outperformed baselines like DragAnything and DragNUWA **1.5** in video quality (FVD **190.44** vs. **324.95** and **299.96**) and image quality (FID **25.41** vs. **36.04** and **42.34**) in multi-point control scenarios.
- Qualitative evaluations demonstrated the model's ability to generate videos with accurate mutual occlusion control, realistic forward/backward object movements, and complex 3D orbital motions.
- Ablation studies confirmed the importance of instance and depth information, with a moderate number of clustered control points effectively balancing rigid and non-rigid motion generation.

## Takeaways

> [!tip] Key Insights
> - Abstracting object masks into sparse, depth-augmented K-means cluster points provides an effective and compact representation for encoding 3D motion information for generative models.
> - Dynamically rendering 3D-transformed object masks back to 2D for K-means clustering ensures physically plausible motion, perspective scaling, and occlusion handling.
> - Combining intuitive 2D drag interaction with interactive depth adjustment offers an accessible method for users to specify 3D trajectories, overcoming limitations of purely 2D or complex 3D input.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This work is positioned within the field of video generation, specifically focusing on image-to-video (I2V) synthesis with an emphasis on controllable object trajectories. Diffusion models have significantly advanced video generation capabilities, leading to various frameworks such as Text-to-Video (T2V) and I2V synthesis. While these models can produce high-quality videos from prompts, they often lack fine-grained control over specific elements within the scene.

A sub-area within controllable video generation involves guiding motion through trajectories. Earlier methods frequently employed 2D trajectory inputs, where users draw paths directly on an image. However, these 2D approaches face inherent limitations, particularly ambiguity when attempting to represent movements that involve changes in depth or out-of-plane motion. For example, a 2D line cannot unambiguously convey whether an object should pass in front of or behind another. This ambiguity stems from the loss of 3D spatial information.

More recent developments have explored using multimodal video sequences as conditions for video generation, such as pose or dense depth maps. While these provide precise control, they often require dense, per-frame control signals, which are cumbersome for typical users. The challenge of inputting valid 3D trajectories also persists, as it often requires specialized tools or knowledge.

LeviTor addresses these limitations by introducing a method for 3D trajectory control in I2V synthesis. It aims to bridge the gap between user-friendly 2D interaction and the need for explicit 3D spatial information to resolve ambiguities. The paper positions LeviTor as a pioneering effort in integrating efficient and effective 3D trajectory control into image-to-video synthesis, specifically by abstracting complex object masks into a manageable set of clustered points augmented with depth information. This contrasts with methods that use only 2D trajectories or require dense 3D inputs, thus contributing to the development of more intuitive and capable video generation tools.

### 2. Key Objectives and Motivation

The primary objectives and motivations behind the development of LeviTor are rooted in the limitations of existing controllable image-to-video synthesis techniques:

- **Addressing 2D Trajectory Ambiguity:** Current drag-based interaction methods for controlling object trajectories in image-to-video synthesis primarily operate in 2D space. This leads to ambiguity when depicting out-of-plane movements, such as whether an object should pass in front of or behind another, or when its distance from the camera changes. The motivation is to resolve this inherent ambiguity.
- **Introducing a Depth Dimension for Interaction:** To overcome the 2D limitation, a key objective is to augment the user interaction with a depth dimension. This allows users to assign a relative depth value to each point on a drawn trajectory. The motivation is to retain the convenience of 2D dragging while enabling more precise control over object movements in 3D space, thereby broadening creative possibilities.
- **Simplifying 3D Trajectory Input:** Directly inputting accurate 3D trajectories often necessitates specialized knowledge and tools, which presents a barrier for general users. The research aims to design a user-friendly inference pipeline that simplifies 3D trajectory input, making the process accessible without requiring extensive 3D modeling or animation expertise. Users should be able to draw trajectories on 2D images and interactively adjust point depths.
- **Developing an Implicit 3D Control Signal Representation:** Explicit 3D trajectory estimation and dense 3D annotations are challenging to obtain for large datasets. A motivation is to implicitly capture 3D motion information from readily available 2D data (like Video Object Segmentation datasets) by abstracting object masks into a few cluster points, combined with estimated depth and instance information. This representation is intended to clearly indicate occlusion and depth changes through the spatial aggregation or separation of these points and their associated depth values.
- **Ensuring Photo-Realistic Video Generation with Precise Control:** The overarching goal is to enable the generation of photo-realistic videos from static images where object movements are precisely manipulated according to user-defined 3D trajectories. This involves fine-tuning pre-trained video generation models to effectively incorporate the novel 3D trajectory control mechanism.
- **Leveraging Existing High-Quality Datasets:** Given the scarcity of datasets with explicit 3D motion trajectories, a motivation is to utilize high-quality Video Object Segmentation (VOS) datasets, such as the recently released SAM2 dataset, which offer rich mask annotations. This necessitates a method to derive or infer the necessary 3D motion cues from these 2D-centric datasets for training.

In summary, the work is motivated by the need for intuitive and precise 3D object trajectory control in image-to-video synthesis, aiming to enhance creative expression and user accessibility by overcoming the limitations of 2D control and complex 3D input methods.

### 3. Methodology and Approach

LeviTor proposes a methodology for 3D trajectory-oriented image-to-video synthesis built upon a novel control signal representation and a user-friendly inference pipeline.

**Core Control Signal Representation:**
The central innovation is the abstraction of object masks into a few K-means clustered points, augmented with depth and instance information.
1. **K-means Control Points:** For each object mask M_t at frame *t*, K-means clustering is applied to its pixels to obtain a set of *N* representative 2D control points (x_i_t, y_i_t). The number of clusters (*k*) is dynamically determined:
 - It starts with a value proportional to the mask's area ratio (S_M_j_i / (H * W)) multiplied by a hyper-parameter α.
 - If the object's area ratio changes significantly (e.g., maximum to minimum area ratio > 10) across video frames, indicating 3D motion, *k* is ensured to be at least 3 to better represent temporal changes, and capped at 8 to avoid excessive density.
 - These points implicitly encode 3D information, as their spatial distribution and density changes reflect object depth and motion (e.g., points spreading out as an object moves closer).
2. **Depth Information Integration:** A depth estimation network, DepthAnythingV2, is used to predict relative depth maps {D_t} for each frame. The depth value (d_i_t) at each control point (x_i_t, y_i_t) is then sampled from the corresponding depth map. This provides approximate 3D coordinates without requiring absolute depth or explicit 3D annotations.
3. **Instance Information:** Each control point is associated with instance information, indicating which specific object it belongs to. This is crucial for distinguishing between multiple moving objects.
4. **Complete Control Trajectory:** The final control trajectory T for an object combines its 2D coordinates, depth information, and instance information: { (x_i_t, y_i_t, d_i_t, instance_i) for i=1..N, t=1..L }. This sparse, yet information-rich, signal is then converted into a dense representation suitable for the diffusion model. 2D trajectories are represented using Gaussian heatmaps, which are concatenated with instance points and depth points to form the full control signal.

**Training Pipeline:**
1. **Base Model:** Stable Video Diffusion (SVD) is used as the base video generation model, enhanced with ControlNet to inject the custom control signals.
2. **Dataset:** The Segment Anything Video (SA-V) dataset is utilized for training. This dataset provides high-quality videos with precise object mask annotations, which are essential for generating the K-means control points and instance information.
3. **Control Signal Generation for Training:** For each video in the dataset, object masks are processed to generate dynamic K-means control points. DepthAnythingV2 predicts relative depth maps. These are combined with instance information to form the training control signals.
4. **Optimization:** The model is trained to minimize a standard diffusion loss function (L = E[ϵ - ϵ_c_θ(z_t; t, z_0, c_traj)]^2), where z_0 is the VAE-encoded latent feature of the first frame, c_traj is the generated control signal, and ϵ_c_θ represents the combined denoising U-Net and ControlNet branch.
5. **Training Configuration:** Training is conducted on 16 consecutive frames at 288x512 resolution for 200K iterations, using the AdamW optimizer with a learning rate of 1e-5 on 16 NVIDIA A100 GPUs with a total batch size of 16.

**Inference Pipeline (User-Friendly Interactive System):**
1. **Initial Input:** A static image is provided by the user.
2. **Automatic Scene Analysis:** DepthAnythingV2 automatically extracts depth information, and SAM extracts object masks from the input image.
3. **User Interaction (Retrieval Panel):** Users select objects to animate by clicking on their masks. The system automatically provides relative depth values for these clicked points.
4. **User Interaction (Interactive Panel):** Users then draw desired 3D trajectories by clicking on more points to define the object's path over time. They interactively adjust depth values for these points, referencing the automatically obtained relative depths.
5. **Conversion of Sparse Input to Dense Control:** This is a critical step that converts the user's sparse 3D trajectory input into a rich, physically consistent multi-point control signal:
 - **3D Point Projection:** Pixels from the user-selected masks in the starting image are combined with their estimated depth values to form 3D spatial points in camera coordinates.
 - **3D Transformation:** These 3D points are then transformed (translated) according to the user-specified movement vectors (T) derived from their drawn 3D trajectory. This assumes constant camera intrinsics and a static camera, using a simplified transformation without rotation.
 - **2D Re-rendering:** The transformed 3D points are rendered back to 2D images (using PyTorch3D), generating a sequence of 2D object masks over time. This rendering process inherently accounts for perspective scaling, occlusion, and movement changes in a physically plausible manner.
 - **K-means on Rendered Masks:** K-means clustering is applied to these newly rendered 2D masks to obtain the final set of control points for each frame. This step is crucial because directly using dense rendered masks as control signals would primarily result in rigid translations, limiting the model's ability to generate non-rigid deformations. The clustered points provide a balance, allowing the generative model to infer and add non-rigid motion details.
6. **Video Synthesis:** The derived control points, combined with user-specified depth changes and instance information, are then fed into the ControlNet-enhanced SVD model to generate the final video.

### 4. Main Findings and Results

The efficacy of LeviTor was evaluated through both qualitative and quantitative comparisons against existing controllable video generation methods, alongside ablation studies.

**Qualitative Comparisons:**
LeviTor was qualitatively compared against DragNUWA, DragAnything, SG-I2V, and MOFA-Video, with a focus on 3D motion aspects:
- **Mutual Occlusion Control:** LeviTor demonstrated the ability to generate videos where objects correctly pass in front of or behind other scene elements based on input depth variations. For instance, a tornado was shown to either sweep across the front of a building or pass behind it, depending on the assigned depth. In contrast, DragAnything sometimes misinterpreted movement as camera motion, leading to blurring, while DragNUWA, lacking depth awareness, produced objects with inappropriate size changes that did not conform to perspective.
- **Forward and Backward Object Movements:** LeviTor accurately depicted objects moving closer to or further from the camera, with corresponding size changes in accordance with perspective projection rules (e.g., planets moving in depth). Baselines, relying solely on 2D trajectories, often produced blurry videos or failed to simulate the depth-induced size changes.
- **Complex Motions:** The method successfully simulated complex 3D motions, such as an object orbiting another, accurately handling occlusion relationships throughout the rotation. Competing methods, using 2D inputs, typically failed to achieve the desired swirling effect, either producing simple translations or interpreting the input as camera movement.
- **Entity-Level Control:** By leveraging SAM for initial object mask extraction, LeviTor ensured that only user-selected objects were animated, preventing the model from misinterpreting object movement as camera movement.

**Quantitative Comparisons:**
Evaluations were conducted on the DAVIS dataset using Frechet Inception Distance (FID) for image quality, Frechet Video Distance (FVD) for video quality, and ObjMC for motion controllability.
- **Overall Performance:** LeviTor achieved a notable advantage in both FID and FVD metrics compared to DragAnything and DragNUWA 1.5. For instance, in the Multi-Points setting, LeviTor reported FID 25.41 and FVD 190.44, significantly outperforming DragAnything (FID 36.04, FVD 324.95) and DragNUWA 1.5 (FID 42.34, FVD 299.96). This improvement is attributed to the integration of 3D trajectory information and training on the SA-V dataset.
- **Impact of Multiple Control Points:** Increasing the number of control trajectories (Multi-Points setting) enhanced the performance of LeviTor and DragNUWA, indicating the benefit of explicitly considering object size changes and occlusion over time. DragAnything's performance gain from multiple points was comparatively limited due to its training approach.
- **Motion Controllability (ObjMC):** LeviTor exhibited a higher ObjMC score (37.39 for Single-Point, 25.97 for Multi-Points) compared to DragNUWA (33.03 for Single-Point, 23.12 for Multi-Points). The authors attributed LeviTor's slightly worse ObjMC score to its training approach, which does not strictly enforce perfect alignment with tracked trajectories but rather encourages physically plausible motion, and does not use tracking methods to obtain complete ground truth point trajectories.

**Ablation Studies:**
- **Depth and Instance Information:** Both depth and instance information were found to contribute to model performance. Instance information was identified as more critical, preventing confusion between control points of different objects and avoiding blurry or unrealistic results. Depth information, while helpful, had a comparatively smaller individual impact because some depth cues are implicitly encoded in the clustering and dispersion of points.
- **Number of Control Points for Inference:** The study showed a trade-off: fewer control points allowed for greater movement amplitude but could lead to object deformation. Conversely, an overly dense number of control points (approaching the object's mask) limited the model's ability to generate non-rigid movements, resulting primarily in rigid translation. This confirmed that a moderate number of clustered points is effective for enabling the generative model to capture motion variation and some non-rigid movements.
- **Single-point Control:** A comparison with a single-point control model (2D trajectory + depth value changes) revealed that the multi-point clustering approach of LeviTor is more effective at representing complex 3D motions, especially for subtle occlusions and size variations. This highlights that the clustering and dispersion of multiple points, rather than just a single point's depth value change, are key for 3D motion representation in this method.

**Limitations:**
The authors acknowledged several limitations:
- LeviTor's capabilities are constrained by the quality of SAM segmentation and the precision of user-provided trajectories; it does not inherently understand physical laws for unguided movements.
- It cannot control the internal pose changes of objects due to the absence of tracking data in its training.
- The quality of generated results is partially limited by the underlying base model, SVD, which can struggle with reconstructing small faces or generating scenes with large, complex, or unnatural movements (e.g., blurry faces, unnatural limb movements, confusion of similar object parts).

### 5. Significance and Potential Impact

LeviTor introduces a method for 3D trajectory control in image-to-video synthesis, addressing a long-standing challenge in generating dynamic content with precise spatial movements. Its significance and potential impact span several areas:

- **Advancement in Controllable Video Generation:** By augmenting 2D drag-based interaction with depth information, LeviTor provides a more robust and less ambiguous control mechanism for object motion in video synthesis. This moves beyond the limitations of purely 2D trajectory inputs, enabling generation of videos with explicit control over occlusion, depth changes, and complex 3D paths.
- **Enhanced User Accessibility and Creativity:** The user-friendly inference pipeline, which allows users to draw 2D trajectories and interactively adjust depth, significantly lowers the technical barrier for creating 3D animated content. This accessibility has the potential to broaden the user base for advanced video generation tools, including artists, designers, and non-expert creators, allowing for more diverse and intricate visual narratives.
- **Improved Realism and Physical Plausibility:** The methodology of dynamically rendering 3D transformed object masks back to 2D space, followed by K-means clustering, ensures that object movements, size changes due to perspective, and occlusion relationships adhere more closely to physical laws. This contributes to the generation of more realistic and visually convincing videos.
- **Foundational for Future Research:** This work establishes a precedent for integrating efficient 3D control signals into existing video diffusion models. It opens avenues for future research into more sophisticated 3D control, potentially incorporating richer representations for non-rigid object deformations, complex physical interactions, and potentially integrating with more advanced video base models that can handle intricate dynamics.
- **Applications in Creative Industries:** The capabilities demonstrated by LeviTor could have implications for various applications in computer graphics, virtual reality, and interactive media. It could simplify the animation of characters in virtual environments, enable more precise simulation of physical phenomena, and facilitate the development of advanced visual effects requiring controlled object interactions.
- **Efficient Data Utilization:** The approach of inferring 3D motion cues from 2D-centric VOS datasets, rather than requiring explicit 3D trajectory data, offers an efficient way to leverage existing high-quality datasets for training, potentially mitigating data scarcity issues in 3D-aware video generation.

In summary, LeviTor contributes to making advanced 3D motion control in video synthesis more intuitive and effective, thereby expanding the creative possibilities for dynamic content generation and setting a direction for future research in this domain.
