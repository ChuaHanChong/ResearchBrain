# 3D-Mem: 3D Scene Memory for Embodied Exploration and Reasoning

> [!summary] Summary
> 3D-Mem introduces a scalable 3D scene memory framework for embodied agents, leveraging multi-view image "Memory Snapshots" for explored regions and "Frontier Snapshots" for unexplored areas. This enables efficient lifelong exploration and enhanced spatial reasoning, outperforming baselines in various embodied question answering and navigation tasks by effectively integrating with Vision-Language Models.

## Problem

- Traditional 3D scene representations either oversimplify spatial relationships (object-centric graphs) or are computationally expensive and unscalable for growing environments (dense 3D representations).
- Embodied agents lack a compact yet informative scene memory that supports nuanced spatial reasoning over long periods and allows for effective integration with powerful 2D-trained Vision-Language Models (VLMs).
- Current systems struggle with lifelong autonomy, lacking mechanisms for incremental memory construction and efficient retrieval in continuously explored 3D environments.

## Method

- Introduces **3D-Mem**, a framework centered on two types of multi-view images: "Memory Snapshots" for explored regions and "Frontier Snapshots" for unexplored areas.
- Utilizes a co-visibility clustering algorithm for efficient and incremental construction of Memory Snapshots, ensuring each captures rich visual context of co-visible objects.
- Implements Prefiltering for scalable memory retrieval, presenting only relevant snapshots to Vision-Language Models (VLMs), enabling VLM-guided exploration and reasoning.

## Results

- Achieves 52.6 LLM-Match and 42.0 LLM-Match SPL in Active Embodied Question Answering (A-EQA), outperforming baselines by enabling more effective spatial and functional reasoning.
- Demonstrates high compactness and informativeness, using an average of 10.94 memory snapshots from 39.76 egocentric observations, further reduced to 3.26 snapshots via prefiltering for VLM input.
- Secures a **69.1%** Success Rate and **48.9** SPL on GOAT-Bench for multi-modal lifelong navigation, confirming the significant benefit of its lifelong memory system for extended tasks.

## Takeaways

> [!tip] Key Insights
> - Multi-view image snapshots provide a compact and informative 3D scene representation that effectively leverages the reasoning capabilities of 2D-trained Vision-Language Models (VLMs).
> - The explicit representation of unexplored regions as "Frontier Snapshots" enables intelligent, VLM-guided active exploration, improving efficiency in discovering new areas.
> - An incremental memory construction pipeline combined with efficient retrieval via Prefiltering is essential for supporting lifelong autonomy and scalability in embodied agents.
