# A Stable Whitening Optimizer for Efficient Neural Network Training

> [!summary] Summary
> From UC Berkeley, SPlus introduces a stable whitening optimizer that improves the efficiency of training large Transformer models by addressing common issues in second-order methods. It enables faster loss decrease, matching Adam's validation performance in 44-58% fewer gradient steps and 62-83% less wall-clock time.

## Problem

- Existing whitening-based optimizers like Shampoo are prone to divergence, particularly when computationally expensive matrix inversions are cached.
- Optimal learning rates for these optimizers often lack transferability across different neural network widths, complicating hyperparameter tuning.
- Whitening-based optimizers can suffer from significant parameter noise and oscillations at high learning rates, which can degrade final validation performance.

## Method

- ==Instant-sign normalization== is introduced to bound update magnitudes, preventing divergence and allowing eigendecomposition results to be cached for over 100 steps.
- A ==symmetric shape-aware scaling factor (2 / (m + n))== is applied per-layer to standardize update magnitudes, making learning rates robust and transferable across network widths.
- ==Iterate averaging (Exponential Moving Average)== is incorporated to reduce parameter noise at high learning rates, allowing fast learning without compromising final validation performance.

## Results

- SPlus consistently achieved faster loss decrease across language modeling, image classification, and diffusion modeling tasks, reaching Adam's performance in **44-**58%** fewer gradient steps** and **62-**83%** less wall-clock time**.
- Instant-sign normalization eliminated divergence, allowing SPlus to remain stable with eigendecomposition cached for over **100 gradient steps**, significantly improving wall-clock efficiency.
- The symmetric shape-aware scaling enabled learning rate transfer across different network widths, and iterate averaging consistently improved final validation loss by mitigating parameter noise at higher learning rates.

## Takeaways

> [!tip] Key Insights
> - Divergence in whitening optimizers can be effectively addressed by bounding update magnitudes through an instant-sign normalization on rotated gradients.
> - Achieving learning rate transferability across network widths is possible with a symmetric shape-aware scaling, which simplifies hyperparameter tuning for adaptive optimizers.
> - Iterate averaging provides an effective annealing mechanism, enabling aggressive learning rates for rapid training while preserving or enhancing final model performance by smoothing parameter updates.
