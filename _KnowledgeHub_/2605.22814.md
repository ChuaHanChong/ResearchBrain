# Remember to be Curious: Episodic Context and Persistent Worlds for 3D Exploration

> [!summary] Summary
> A framework for curiosity-driven 3D exploration addresses "amnesiac exploration" by combining a persistent 3D Gaussian Splatting (3DGS) world model with a transformer-based agent maintaining long-term episodic memory. This approach enabled the agent to achieve higher 3D scene completeness and efficiently adapt to downstream tasks using only RGB observations, demonstrating robust generalization.

## Problem

- Curiosity-driven reinforcement learning agents often suffer from "amnesiac exploration," repeatedly revisiting already-explored locations and receiving spurious novelty rewards in complex 3D environments.
- Existing world models lack spatial persistence, and agent memory often fails to maintain sufficient episodic context for long-horizon strategic exploration.
- Traditional active mapping methods typically rely on ground-truth depth observations or SLAM, which can abstract rich semantic information and limit the flexibility of end-to-end learning.

## Method

- A Persistent 3D Forward Model, instantiated as an online 3D ==Gaussian Splatting== (3DGS) model, continuously builds and refines a spatially consistent representation of the environment to provide a stable intrinsic curiosity reward based on prediction error.
- A Long-Context Transformer Agent processes a full sequence of past RGB observations and actions, incorporating a global linear-attention memory module to maintain long-term episodic context for strategic navigation.
- A ==self-supervised== ==reinforcement learning== framework trains the agent using Proximal Policy Optimization (PPO), with the intrinsic curiosity reward as the sole signal, enabling map-free operation solely on RGB inputs at test time.

## Results

- The proposed agent achieved higher 3D scene completeness and a lower average distance to nearest observed points across various time horizons compared to active-mapping baselines on HM3D and Gibson datasets, using only RGB input at test time.
- Ablation studies confirmed that both the persistent 3DGS world model and the agent's long-term episodic memory are crucial for effective exploration, as agents lacking these components exhibited degraded or failed exploratory behaviors.
- The pre-trained exploration policy efficiently fine-tuned to downstream sparse-reward tasks (e.g., apple-picking, image-goal navigation) with few episodes, outperforming agents trained from scratch, and demonstrated robust zero-shot generalization to novel AI-generated worlds.

## Takeaways

> [!tip] Key Insights
> - Effective curiosity-driven exploration in 3D environments fundamentally requires both a world model with spatial persistence and an agent with long-term episodic memory to overcome the "amnesiac exploration" problem.
> - 3D Gaussian Splatting (3DGS) provides a viable and continuously updatable proxy for a persistent world model, generating a reliable novelty signal by rendering predictions from an evolving 3D scene representation.
> - A transformer architecture, augmented with a global linear-attention memory module, enables agents to maintain the necessary long-horizon episodic context from RGB observations, facilitating strategic and far-reaching exploration.
