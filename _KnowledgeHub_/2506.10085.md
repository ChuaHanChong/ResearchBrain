# VITA: Zero-Shot Value Functions via Test-Time Adaptation of Vision-Language Models

> [!summary] Summary
> Researchers at Imperial College London developed VITA, a method for zero-shot value function learning that improves Vision-Language Models' generalization and temporal reasoning via test-time adaptation. VITA effectively provides reward shaping for offline reinforcement learning, achieving an interquartile mean return of 0.815 on Meta-World MT10, which exceeds the simulation's native fuzzy-logic dense rewards.

## Problem

- Existing Vision-Language Models (VLMs) with frozen pre-trained representations struggle to generalize effectively to novel, out-of-distribution robotic tasks, environments, or robot embodiments.
- Current VLM-based approaches often lack robust temporal reasoning, failing to capture sequential context necessary for accurate task progress estimation and distinguishing visually similar states at different task stages.
- Developing generalist robotic policies or value functions typically requires extensive expert demonstrations, large-scale domain-specific fine-tuning, or massive multimodal pre-training, which are resource-intensive.

## Method

- **VITA** combines a frozen contrastive VLM (OpenCLIP ViT-B/32) with a lightweight, meta-learned adaptation module and a regression head for goal-conditioned value function estimation.
- The adaptation module is updated online at each test-time step via a single gradient step on a self-supervised reconstruction loss, which implicitly encodes temporal history into its parameters.
- A dissimilarity-based sampling strategy is used during meta-training to construct mini-batches from visually diverse sub-trajectories, mitigating shortcut learning and encouraging reliance on semantic cues.

## Results

- VITA demonstrated superior Value Order Correlation (VOC) for predicting task progress across diverse out-of-distribution environments, tasks, and robot embodiments, outperforming autoregressive VLMs and recurrent VLM baselines in most scenarios.
- The method achieved perfect discrimination (BinVOC = 1.0) between expert and non-expert trajectories, consistently assigning higher VOC scores to optimal paths across five scripted datasets.
- Utilized for zero-shot reward shaping in offline reinforcement learning on Meta-World MT10, VITA yielded an interquartile mean return of **0.815**, surpassing the simulation's native fuzzy-logic dense rewards (**0.779**) and other CLIP-based baselines.

## Takeaways

> [!tip] Key Insights
> - Test-time adaptation of a small, meta-learned module can effectively imbue frozen VLM representations with both generalization capabilities and robust temporal reasoning without extensive retraining.
> - Implicitly retaining temporal context within the adapter's parameters through sequential, per-timestep updates is more effective for value function estimation and less prone to overfitting than explicit recurrent models or memoryless adaptation.
> - Mitigating shortcut learning through dissimilarity-based sampling during meta-training is crucial for developing value functions that rely on meaningful semantic and temporal understanding rather than superficial chronological cues.
