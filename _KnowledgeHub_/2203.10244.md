# ChartQA: A Benchmark for Question Answering about Charts with Visual and Logical Reasoning

> [!summary] Summary
> The ChartQA benchmark, a dataset with 20,882 real-world charts and over 32,000 human-authored and machine-generated questions, is introduced to evaluate chart question answering systems. The VisionTaPas model, which integrates visual and tabular features, achieved state-of-the-art results on several benchmarks but demonstrated a notable performance gap compared to human ability on complex reasoning tasks.

## Problem

- Automated systems struggle to answer natural language questions about data visualizations due to the need for both visual understanding and logical data reasoning.
- Existing Chart Question Answering (ChartQA) datasets use artificial, template-based questions and synthetic charts, limiting their real-world applicability and evaluation of complex reasoning.
- Current benchmarks inadequately test a system's ability to understand visual attributes, perform diverse mathematical operations, and generate free-form answers.

## Method

- Developed **ChartQA**, a new dataset comprising 20,882 real-world charts and over 32,000 diverse questions, including human-authored queries focusing on complex reasoning.
- Extracted underlying data from charts using a combination of ==parsing==, ==computer vision==, and manual verification to enable structured table inputs.
- Proposed **VisionTaPas**, a model extending the ==TaPas== framework by integrating visual features from a ==vision transformer (ViT)== with tabular data using a ==cross-modality encoder== to enable visual reasoning.

## Results

- VisionTaPas achieved state-of-the-art performance across multiple existing ChartQA datasets (FigureQA, PlotQA, DVQA) and the newly introduced ChartQA benchmark.
- Models that integrated visual features from chart images consistently outperformed models relying solely on tabular data, especially for visually-oriented questions.
- A substantial performance gap was observed between the best-performing models and human capabilities on human-authored questions, particularly those requiring complex reasoning.

## Takeaways

> [!tip] Key Insights
> - Integrating visual features from chart images with structured tabular data significantly improves model performance for chart question answering.
> - Human-authored questions and real-world charts expose a notable performance gap between state-of-the-art models and human ability, particularly for complex reasoning.
> - Enhancing models with support for a wider range of mathematical operations (e.g., subtraction, ratio) improves their ability to answer calculation-based queries.

## Detailed Report

### 1. Introduction

Charts and visualizations have become essential tools for communicating complex data in business, science, journalism, and education. While humans can quickly interpret and reason about the information presented in charts, developing automated systems that can answer natural language questions about visualizations remains challenging. This task, known as Chart Question Answering (ChartQA), requires systems to understand both the visual elements of charts and perform logical reasoning about the underlying data.

ChartQA is a specialized subset of Visual Question Answering (VQA) that focuses specifically on data visualizations rather than natural images. What makes ChartQA particularly challenging is that it requires understanding the relationship between visual elements (bars, lines, colors) and the underlying data, as well as performing calculations and logical operations to answer questions.

### 2. Limitations of Existing Datasets

Current ChartQA datasets and systems face several significant limitations that restrict their practical application and evaluation:

1. **Template-based questions**: Many existing datasets use predefined templates to generate questions, resulting in artificial language that doesn't reflect the diversity and complexity of real-world queries.

2. **Synthetic charts**: Most benchmark datasets use programmatically generated charts, which lack the design variations, annotations, and visual complexity found in real-world visualizations.

3. **Fixed-vocabulary answers**: Many systems are designed to select answers from a predefined set of options rather than generating free-form responses.

4. **Limited visual reasoning**: Existing datasets don't adequately test a system's ability to understand visual attributes of charts such as colors, patterns, and spatial relationships.

The authors of ChartQA identified these gaps and developed a new benchmark specifically designed to address these limitations.

### 3. The ChartQA Dataset

The ChartQA dataset represents a significant advancement in chart question answering research, offering:

- **Real-world charts**: 20,882 diverse charts collected from reputable sources including Statista, Pew Research, Our World in Data (OWID), and the OECD.

- **Two question categories**:
 - **Human-authored questions (ChartQA-H)**: 9,608 questions written by humans, ensuring natural language diversity and complexity.
 - **Machine-generated questions (ChartQA-M)**: 23,111 questions algorithmically generated from chart summaries, providing additional training data.

- **Diverse chart types**: The dataset includes various visualization types such as bar charts, line charts, pie charts, and area charts, with different styling and design choices.

- **Focus on reasoning complexity**: The questions require different levels of reasoning, including:
 - Simple data extraction (e.g., "What is the peak value of the orange line?")
 - Mathematical operations (e.g., comparing values, calculating differences)
 - Visual reasoning (e.g., questions about colors, trends, and visual patterns)
 - Compositional reasoning (questions requiring multiple steps or operations)

### 4. Data Collection and Annotation

The creation of the ChartQA dataset involved several key steps:

1. **Chart collection**: The authors crawled charts from four major sources: Statista, Pew Research, Our World in Data, and OECD, capturing both the chart images and associated metadata (title, description, etc.).

2. **Data extraction**: For each chart, the underlying data was extracted using a combination of methods:
 - Text parsing from SVG files when available
 - Computer vision techniques to detect chart elements and extract values
 - Manual verification for a subset of charts

3. **Question collection**:
 - **Human-authored questions**: The authors used Amazon Mechanical Turk to collect diverse questions from human annotators, with specific instructions to create both visual and compositional questions.
 - **Machine-generated questions**: Additional questions were generated by fine-tuning a T5 model on chart summaries, using a data augmentation approach.

4. **Quality control**: The dataset underwent rigorous verification to ensure question clarity, answer correctness, and reasoning diversity.

### 5. Model Architecture

The authors propose two main models to establish strong baselines for the ChartQA dataset:

1. **TaPas**: A table-based question answering model that treats the chart's underlying data as a structured table and learns to select cells and perform operations over them.

2. **VisionTaPas**: An extension of TaPas that incorporates visual features from the chart image alongside the tabular data, enabling it to answer questions that require visual reasoning.

The VisionTaPas architecture combines:

- A vision transformer (ViT) to process chart image patches
- The TaPas model to process tabular data and questions
- A cross-modality encoder that fuses visual and tabular representations
- An operation head that supports various mathematical operations (SUM, COUNT, AVERAGE, DIFF, RATIO)

This approach allows the model to handle questions that require:

1. **Pure data retrieval**: Finding and returning specific values from the chart
2. **Mathematical operations**: Performing calculations on one or more values
3. **Visual reasoning**: Understanding visual attributes like colors, positions, and trends

The models process input in three main steps:

1. **Data extraction**: Converting the chart image into a structured table using computer vision techniques
2. **Feature integration**: Combining visual features from the image with the tabular data
3. **Question answering**: Processing the question and generating an appropriate answer

### 6. Evaluation Results

The authors evaluated their models on both existing datasets (FigureQA, PlotQA, DVQA) and the new ChartQA benchmark. Key findings include:

1. **State-of-the-art performance**: VisionTaPas achieved top performance across multiple datasets, demonstrating the value of integrating visual and tabular features.

2. **Impact of visual features**: Models that incorporated visual information consistently outperformed those using only tabular data, especially for questions requiring visual reasoning.

3. **Performance gap**: Despite strong results, there remains a significant gap between model performance and human performance, particularly on human-authored questions that involve complex reasoning.

4. **OCR robustness**: The models showed reasonable robustness to OCR noise, with only a marginal decrease in performance when using automatically extracted data instead of oracle data tables.

5. **Operation improvements**: Adding support for subtraction and ratio operations significantly improved model performance on questions requiring these calculations.

### 7. Key Challenges

Despite the advances presented in the paper, several key challenges remain in chart question answering:

1. **Data extraction accuracy**: Automatically extracting accurate data from diverse chart types remains difficult, particularly for charts with unusual designs or dense information.

2. **Complex visual reasoning**: Current models struggle with questions that require understanding complex visual patterns or making comparisons across multiple visual elements.

3. **Multi-step reasoning**: Questions that require multiple reasoning steps or operations in sequence remain challenging for existing models.

4. **Chart-specific knowledge**: Many charts require domain knowledge or familiarity with specific visualization conventions to interpret correctly.

5. **Answer generation**: Generating natural language explanations or justifications for answers, rather than just providing a numerical result, remains an open challenge.

The error analysis revealed that models particularly struggle with:

- Questions involving relative comparisons (e.g., "Which category showed the largest increase?")
- Visual questions about color patterns or spatial relationships
- Questions requiring multi-step reasoning

### 8. Future Directions

Based on the findings, several promising directions for future research emerge:

1. **Improved data extraction**: Developing more robust computer vision techniques for extracting data from diverse chart types and styles.

2. **Enhanced visual reasoning**: Creating models that better understand the visual grammar of charts and can reason about visual attributes.

3. **Explainable answers**: Extending models to not only provide answers but also explain their reasoning process.

4. **Interactive ChartQA**: Developing systems that can engage in multi-turn conversations about charts, allowing for clarification and exploration.

5. **Domain adaptation**: Creating approaches that can adapt to specialized chart types and conventions used in specific domains like finance, healthcare, or scientific research.

### 9. Conclusion

The ChartQA benchmark represents a significant advancement in chart question answering research. By addressing the limitations of existing datasets through real-world charts, human-authored questions, and an emphasis on visual reasoning, it provides a more realistic evaluation environment for ChartQA systems.

The proposed VisionTaPas model demonstrates the value of integrating visual and tabular features, achieving strong performance across multiple datasets. However, the performance gap on complex reasoning questions highlights the need for continued research in this area.

As data visualization becomes increasingly prevalent across domains, developing systems that can accurately interpret and reason about charts will be essential for making this information accessible to all users. The ChartQA benchmark provides a valuable resource for driving progress toward this goal.

The ability to automatically answer questions about charts has numerous practical applications, from making data more accessible to vision-impaired users to enabling more efficient data analysis in business and research settings. The ChartQA dataset and the accompanying models represent an important step toward realizing these applications.
