# Quantized Evolution Strategies: High-precision Fine-tuning of Quantized LLMs at Low-precision Cost

> [!summary] Summary
> Researchers from UCLA and Cognizant AI Lab introduce Quantized Evolution Strategies (QES), a method for high-precision, full-parameter fine-tuning of quantized Large Language Models directly within their low-precision discrete parameter space. QES achieves significant performance improvements (e.g., up to 31.85% accuracy on Qwen2.5-3B INT4) over prior zeroth-order methods while maintaining an inference-level memory footprint.

## Problem

- Fine-tuning quantized Large Language Models (LLMs) is difficult because traditional backpropagation methods require high-precision, differentiable operations incompatible with discrete, low-precision weights.
- Existing zeroth-order (ZO) optimization and Evolution Strategies (ES) for quantized models suffer from "stagnation" where small gradient signals vanish or become inaccurate in discrete parameter spaces.
- Storing high-precision optimizer states (e.g., error vectors or Adam states) for quantized models can negate the memory benefits of quantization, hindering deployment on resource-constrained devices.

## Method

- QES combines Evolution Strategies with a ==stochastic discrete perturbation strategy and boundary gating== to operate directly within the quantized parameter space.
- It implements an ==accumulated error feedback mechanism==, inspired by Delta-Sigma modulation, which accumulates fractional updates in a high-precision residual vector to prevent gradient stagnation.
- A ==Stateless Seed Replay mechanism== is used to reconstruct the high-precision error vector on-the-fly from a limited history of random seeds and rewards, drastically reducing memory overhead.

## Results

- QES significantly improved arithmetic reasoning accuracy on the Qwen2.5-3B INT4 model from a base of **2.80%** and QuZO's **14.25%** to **31.85%**.
- The stateless seed replay method achieved performance remarkably close to storing the full high-precision residual (e.g., **31.85%** vs. **33.50%** for Qwen2.5-3B INT4), demonstrating minimal approximation impact.
- Analysis showed that parameter updates are sparse (~**10^-2** of parameters change per step), and updates hitting quantization boundaries are extremely rare (**<1×10^-5** for INT4), ensuring high fidelity for stateless reconstruction.

## Takeaways

> [!tip] Key Insights
> - Accumulating fractional update errors over time allows for precise gradient ascent in discrete parameter spaces, enabling effective optimization despite the integer-based parameter updates.
> - Maintaining a high-precision error state is crucial for optimization in quantized spaces, and this state can be efficiently reconstructed without being stored, trading computation for memory.
> - Parameter updates in quantized models are sparse, and instances where updates hit quantization boundaries are rare, which validates the high fidelity and low approximation error of the stateless reconstruction method.
