# I-FailSense: Towards General Robotic Failure Detection with Vision-Language Models

> [!summary] Summary
> I-FailSense introduces a Vision-Language Model framework that excels at detecting subtle semantic misalignment errors in language-conditioned robotic manipulation. The model achieved 90.64% accuracy on simulated semantic errors and generalized to control errors and new environments, outperforming specialized baselines and demonstrating effective real-world transfer with minimal fine-tuning.

## Problem

- Current VLM-based robotic control lacks robust self-failure detection capabilities, particularly for errors beyond low-level physical mistakes.
- Semantic misalignment failures, where a robot's action is physically plausible but semantically incorrect relative to the instruction, are a critical yet underexplored challenge for VLMs' fine-grained grounding and temporal reasoning.
- Existing robotic failure detection methods often focus on generative explanations or solely on control errors, lacking the discriminative accuracy required for triggering automated recovery mechanisms.

## Method

- A pipeline was developed for constructing Semantic Misalignment Failure (SMF) datasets by repurposing existing language-conditioned manipulation data, generating challenging negative examples through intentionally mismatched instructions.
- **I-FailSense**, a two-stage post-training framework built upon a pre-trained VLM (PaliGemma2-mix-3B), was designed, utilizing Parameter-Efficient Fine-Tuning (PEFT) with ==LoRA== in the first stage to adapt the VLM.
- The second stage, termed 'Grounded Arbitration,' attaches lightweight FailSense (FS) binary classification blocks to multiple internal VLM layers, training them independently and ensembling their predictions with the VLM's output for robust failure classification.

## Results

- I-FailSense achieved **90.64%** accuracy and a 0.9132 F1 score on detecting semantic misalignment failures in the D_SMF-CALVIN dataset, substantially outperforming zero-shot VLMs which performed close to random or exhibited significant precision-recall gaps.
- The framework demonstrated strong generalization by achieving an **89.0%** failure detection rate on the D_AHA dataset (predominantly control errors), surpassing specialized AHA baselines by approximately 19 percentage points.
- Effective sim-to-real transfer to real-world trajectories (D_SMF-DROID) was achieved with **74.28%** accuracy and a 0.7300 F1 score after minimal fine-tuning of only the FS blocks on real data, matching the performance of a larger zero-shot VLM like Qwen2.5-VL.

## Takeaways

> [!tip] Key Insights
> - Detecting semantic misalignment errors is crucial for advancing VLM grounding capabilities, as it reveals limitations in understanding complex, nuanced instructions beyond simple physical execution.
> - A model trained on semantic misalignment errors can generalize effectively to diverse control error types and across different simulation environments, indicating that the learned failure detection patterns are robust and transferable.
> - Leveraging multi-level internal VLM representations through specialized classification heads (FS blocks) significantly enhances discriminative failure detection accuracy and robustness by grounding failure identification in language-space reasoning.
