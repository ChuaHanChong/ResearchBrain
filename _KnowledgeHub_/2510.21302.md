# Towards Reliable Code-as-Policies: A Neuro-Symbolic Framework for Embodied Task Planning

> [!summary] Summary
> NeSyRo is a neuro-symbolic framework that makes LLM-generated robot code reliable under partial observability. It alternates SMT-based symbolic verification with skill-level validation using a confidence score. Low-confidence skills trigger safe exploratory probe code that recovers missing observations. On RLBench and a real Franka arm, it improves success rate by 46.2% over Code as Policies.

## Problem

- Code-as-policies methods produce ungrounded or incomplete code when observations are sparse, delayed, or ambiguous, since the LLM never detects what it does not know.
- Existing code verification and validation work relies on static analysis or simulation, so it lacks grounding in real environments where task-relevant states are hidden.
- Existing neuro-symbolic agents and replanners use fixed modular pipelines or react only after failure, so they cannot adapt to missing observations and often cause irreversible actions.

## Method

- ==Neuro-Symbolic Code Verification==: the LLM writes a ==chain-of-thought== task specification plus policy code, and a ==Z3 SMT solver== checks it, feeding violations back for iterative refinement.
- **NeSyConf** validation: each skill's score multiplies ==Common Sense Confidence== (==perplexity== from a small LLM with retrieved demonstrations) by a binary ==Logic Confidence== from a ==Fast Downward PDDL planner== precondition check.
- ==Recursive safe probe==: if **NeSyConf** falls below a threshold, exploratory probe code is generated and itself verified and validated, building a ==policy tree==. New observations then trigger ==skill-level code regeneration==.

## Results

- On RLBench, NeSyRo beats the best baselines (AutoGen, CaP with CodeSift) by **26.3%** success rate across observability levels. Long-horizon tasks under High incompleteness reach **45%** success versus **0%** for CaP.
- In real-world Franka experiments, NeSyRo reaches **57.5%** total success versus **10.6%** for CaP and CaP with CodeSift, cutting irreversible actions from **29** to **7** and approaching the **68.8%** Complete-observation upper bound.
- Ablations show removing either Logic Confidence or Common Sense Confidence drops success rate by about **21.2%** on average, while a **3B** CSC model matches larger ones and a **1B** model degrades.

## Takeaways

> [!tip] Key Insights
> - Pair a symbolic feasibility check with an LLM plausibility score: each catches failures the other misses, and neither component alone recovers the gain.
> - Treat missing observations as something to actively acquire: verified exploratory probes beat replanning after failure, especially on long-horizon tasks where uncertainty compounds.
> - Regenerating only the failing skill after new observations, rather than the whole policy, keeps refinement cheap, and the confidence estimator can be a small model without losing accuracy.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This paper addresses a critical challenge at the intersection of large language models (LLMs), embodied AI, and robotics: the reliability and environmental grounding of LLM-generated code for physical agents. The research landscape is rapidly evolving, with several key trends converging:

- **LLM-based Embodied Control:** Recent breakthroughs have demonstrated LLMs' ability to translate natural language instructions into executable actions for robots. Approaches like SayCan (Brohan et al., 2023) combine LLM interpretation with reinforcement learning affordance models, while "code-as-policies" paradigms (Liang et al., 2023; Mu et al., 2024) directly generate executable code. This shift offers modularity, interpretability, and adaptability, positioning LLMs as general-purpose planners. However, a major limitation, particularly in dynamic or partially observable environments, is the lack of *grounding*. LLMs may generate syntactically correct but semantically unexecutable or unsafe code due to sparse, delayed, or ambiguous perceptual input. This work directly tackles this "grounding problem."

- **Code Verification and Validation (V&V):** Drawing inspiration from established software engineering principles, the paper integrates V&V into the LLM-robot control loop. Traditional V&V (e.g., formal verification, unit testing, runtime verification) ensures software correctness and robustness. While recent works (Aggarwal et al., 2024; Dolcetti et al., 2024) have begun exploring LLM-enhanced V&V for code generation, they often remain limited to static analysis or simulated settings. An essential requirement for embodied agents is real-world grounding, which involves identifying and acquiring missing observations from the physical environment—a gap that NESYRO aims to fill.

- **Neuro-Symbolic Systems:** The field of neuro-symbolic AI seeks to combine the strengths of neural networks (e.g., generalization, pattern recognition from LLMs) with symbolic reasoning (e.g., logical consistency, interpretability, planning from formal systems). In embodied AI, neuro-symbolic approaches often use LLMs for high-level perception and instruction understanding, while symbolic tools handle task planning (Lin et al., 2024; Capitanelli & Mastrogiovanni, 2024). Existing systems, however, often rely on fixed modular structures or predefined procedures, which limits their adaptability when facing environmental uncertainty or missing observations. NESYRO distinguishes itself by dynamically integrating symbolic reasoning with *interactive validation and exploratory actions*, enabling flexible adaptation to unknown environmental states.

In essence, NESYRO occupies a crucial niche by addressing the "reliability gap" in LLM-generated robot code for complex, real-world tasks. It moves beyond static verification or simple replanning by introducing a *recursive, interactive neuro-symbolic V&V loop* that actively probes the environment to achieve robust grounding. This positions it as a significant step towards more trustworthy and capable embodied AI systems.

### 2. Key Objectives and Motivation

The core motivation for this research stems from the recognized shortcomings of current LLM-based code-as-policies approaches for embodied agents, especially in realistic, dynamic, and partially observable environments. While LLMs excel at generating executable code, this code often lacks sufficient environmental grounding. This deficit leads to:
1. **Suboptimal Task Success Rates:** Generated code may be incorrect or incomplete because the LLM lacks a full understanding of the current environmental state.
2. **Unreliable Execution:** Attempting to execute ungrounded code can lead to failures, damage, or irreversible actions, posing significant risks in real-world robotic deployments. For example, trying to grasp an object without accurate depth perception might cause it to be dropped or broken.

To counteract these issues, the primary objective of this work is to develop a neuro-symbolic framework that significantly enhances the reliability and success rates of LLM-generated code for embodied task planning. This overarching goal is broken down into several specific objectives:

- **Integrate Explicit Symbolic Verification:** To ensure the logical consistency and correctness of the generated code against a task specification before execution.
- **Incorporate Interactive Validation:** To assess the environmental feasibility of the code by actively engaging with the environment to acquire missing observations.
- **Enable Exploratory Code Generation:** To synthesize "safe probe" policies that interact with the environment to resolve ambiguities and gather crucial information without jeopardizing the task or agent.
- **Preserve Task-Relevant States:** To ensure that exploratory actions are designed not only to acquire information but also to maintain or facilitate the overall task objectives.
- **Achieve Robustness in Complex Environments:** To validate the framework's ability to maintain high task success rates and executability in dynamic, partially observable real-world and simulated settings.

By pursuing these objectives, the authors aim to bridge the gap between LLMs' impressive code generation capabilities and the stringent reliability requirements of real-world robotic applications.

### 3. Methodology and Approach

The proposed framework, named **NESYRO** (Neuro-Symbolic Robot Task Planning Framework), employs a recursive neuro-symbolic approach to achieve reliable and grounded code generation. It operates through two tightly integrated phases: Neuro-Symbolic Code Verification and Neuro-Symbolic Code Validation.

**Overall Framework Structure (Figure 2):**
NESYRO processes an instruction (`g`) and current observation history (`o_<=t`) through an iterative loop of verification and validation. This recursive structure generates a policy tree where sub-policies (probes) are created to resolve uncertainties.

**Phase i: Neuro-Symbolic Code Verification:**
This phase focuses on the logical correctness and consistency of the policy code.
1. **LLM-based Code Generation (Φ_veri):** A verification LLM (GPT-4o-mini) is prompted with the current observation, goal, domain knowledge, and a chain-of-thought (CoT) prompt. It generates a symbolic task specification (`T_spec`) and an initial policy code (`π_main`) (e.g., in Python), detailing a sequence of skills. If previous verification attempts failed, feedback and the previously generated code are provided to the LLM for refinement.
2. **Symbolic-based Code Verification (Ψ_veri):** A symbolic tool, specifically an SMT solver (Z3), formally checks if the generated `π_main` satisfies `T_spec`. If `π_main` violates any constraints, the SMT solver provides detailed feedback (`F_veri`) to the LLM, prompting an iterative refinement process until the code is symbolically consistent.

**Phase ii: Neuro-Symbolic Code Validation:**
Once verified, `π_main` is parsed into a sequence of individual skill function calls (`f_0, ..., f_N`). This phase assesses the environmental feasibility of each skill sequentially.
1. **Neuro-Symbolic Confidence Score (NeSyConf):** For each skill `f_n`, NESYRO computes a `NeSyConf` score by multiplying two components:
 - **Common Sense Confidence (CSC_f_n):** A validation LLM (Llama-3.2-3B) estimates the plausibility of `f_n` succeeding in the current environment (`o_<=t`) given the instruction (`g`). This is done by inserting the skill snippet into the LLM prompt along with domain knowledge (`D`), context-relevant retrieved demonstrations (`E_demo`), and computing a perplexity-based score.
 - **Logic Confidence (LC_f_n):** A symbolic validation tool (a PDDL planner like Fast Downward) assesses whether the preconditions of `f_n` are met in the current `o_<=t` based on `D`. It produces a binary score: 1 if feasible, 0 otherwise.
 - `NeSyConf = CSC_f_n * LC_f_n`. This combined score indicates the skill's grounding and likelihood of success.

2. **Safe Probe and Recursive Validation:** If `NeSyConf_f_n` falls below a predefined threshold `ϵ`, it signals that the skill is not sufficiently grounded. NESYRO then synthesizes a "safe probe policy code" (`π_probe`) to acquire missing observations. This `π_probe` is itself subject to the *entire* recursive verification and validation process (Phase i and ii), ensuring that even exploratory actions are safe and grounded before execution. This recursive call creates a policy tree.
3. **Policy Code Refinement:** After `π_probe` is executed and new observations (`o_<=t+1`) are collected, the system refines the original `π_main`. Instead of regenerating the entire policy, only the problematic skill `f_n` and subsequent steps are prompted for regeneration via the Neuro-Symbolic Code Verification process, now incorporating the updated observations. This refinement and safe probe loop continues until `NeSyConf_f_n` meets or exceeds `ϵ` for all skills in `π_main`.

**Experimental Setup:**
- **Environments:** RLBench simulation and real-world experiments using a 7-DoF Franka Emika Research 3 robotic arm.
- **Observability Levels:** Tasks are evaluated under High, Low, Stochastic, and Complete incompleteness conditions to test robustness to missing information.
- **Task Types:** Object Relocation, Object Interaction, Auxiliary Manipulation, and Long-Horizon tasks, each associated with specific probe types (e.g., Robot Pose Adjust, Object State Check, Object State Change).
- **Baselines:** Compared against Code as Policies (CaP), CaP w/ Lemur, CaP w/ CodeSift, LLM-Planner, and AutoGen to cover various V&V and replanning paradigms.
- **Metrics:** Success Rate (SR), Goal Condition (GC), and Irreversible Actions (IA) for real-world scenarios.

### 4. Main Findings and Results

The experimental results consistently demonstrate NESYRO's superior performance and robustness across simulated and real-world environments, particularly in dynamic and partially observable settings.

#### 4.1. Task Performance on RLBench (Table 2)

- **Significant Outperformance:** NESYRO consistently achieves higher Success Rates (SR) and Goal Conditions (GC) compared to all state-of-the-art baselines. Across all observability incompleteness levels and task types, NESYRO outperforms baselines like AutoGen and CaP w/ CodeSift by an average of 26.3% in SR and 24.3% in GC.
- **Robustness to Incompleteness:** Unlike baselines, which show sharp performance degradation as observability becomes more incomplete, NESYRO maintains strong performance, often approaching its "Complete" (full observation) variant. This highlights its effective detection of missing observations and safe, purposeful exploration.
- **Long-Horizon Task Efficacy:** The framework particularly excels in long-horizon tasks, where bridging extensive observation gaps is crucial, showcasing its ability to manage multi-step planning and recursive probing.

#### 4.2. Task Performance on Real-World (Table 3, Figure 3)

- **Real-World Reliability:** NESYRO achieves the highest SR and GC in real-world settings, significantly outperforming baselines. It improves SR by an average of 47.0% and GC by 42.6% over CaP w/ CodeSift.
- **Enhanced Safety:** A critical finding is the dramatic reduction in Irreversible Actions (IA), from 29 (CaP w/ CodeSift) to only 7 with NESYRO. This directly validates the framework's emphasis on safe, grounded execution.
- **Addressing Specific Challenges:** For tasks like Object Relocation and Object Interaction, baselines fail due to unaddressed missing observations, whereas NESYRO successfully recovers them to complete tasks. For Auxiliary Manipulation, NESYRO achieves performance on par with its "Complete" variant, indicating that physical execution challenges (e.g., precise light switch pressing) rather than perceptual or reasoning limits are the bottleneck.
- **Illustrative Failures:** Figure 3 visually presents how baselines often lead to irreversible failures (e.g., attempting to open a locked drawer forcefully), while NESYRO uses safe probes to prevent such outcomes and successfully completes tasks.

#### 4.3. Ablation Studies

- **Neuro-Symbolic Code Verification Impact (Table 4, Figure 4):**
 - The quality of the underlying LLM (e.g., GPT-4o-mini vs. GPT-4.1) directly correlates with performance.
 - Crucially, NESYRO consistently improves SR and GC over CaP, regardless of the LLM used, demonstrating the inherent value of the verification process.
 - NESYRO exhibits the *lowest compile error rate* in real-world tasks, signifying the robustness of its V&V pipeline in preventing syntactically or semantically invalid code, especially compared to CaP w/ CodeSift, which can suffer from LLM hallucinations without grounded feedback.
- **Neuro-Symbolic Code Validation Impact (Table 5, Table 6):**
 - Both Logic Confidence (LC) and Common Sense Confidence (CSC) components are vital. Removing either component leads to substantial performance drops (average 21.2% SR and 20.0% GC reduction), confirming the importance of their parallel neuro-symbolic integration.
 - CSC computation is robust to LLM parameter scale beyond a moderate threshold (e.g., Llama-3.2-3B and above perform comparably), offering flexibility in resource allocation.

#### 4.4. Real-World Analysis (Figure 5, Appendix D)

A detailed real-world example ("Place one dice into a drawer in dark room") illustrates NESYRO's step-by-step adaptive planning. It successfully navigates initial darkness and unknown drawer states by generating a sequence of safe probes (turn on light, check drawer lock status, check drawer contents), iteratively refining the policy until a fully grounded and executable plan is achieved. This dynamic process prevents irreversible actions and ensures task completion.

### 5. Significance and Potential Impact

The NESYRO framework represents a significant advancement in the field of embodied AI and robotic control, addressing the crucial need for reliability and grounding in LLM-generated policies. Its potential impact is multi-faceted:

- **Enhanced Reliability and Safety in Robotics:** By integrating explicit symbolic verification and interactive, environment-aware validation, NESYRO drastically improves the robustness and safety of robot control code. The demonstrated reduction in irreversible actions in real-world settings is a key indicator of its practical value, making LLM-powered robots more trustworthy for deployment in sensitive or human-proximate environments.
- **Improved Environmental Grounding for LLMs:** The framework effectively bridges the gap between the abstract reasoning capabilities of LLMs and the concrete realities of physical environments. By enabling LLMs to actively query and observe the environment through safe probes, NESYRO grounds the generated code in actual perceptions, moving beyond purely speculative planning.
- **Adaptive and Robust Task Planning:** NESYRO's recursive structure and dynamic code refinement mechanism allow it to adapt to unforeseen uncertainties and partial observability. This makes it highly suitable for complex, open-world tasks where complete initial information is rarely available and environments can change unpredictably.
- **Advancement in Neuro-Symbolic AI:** The work showcases a powerful synergy between neural and symbolic methods. LLMs provide flexible code generation and common-sense reasoning (CSC), while symbolic tools provide rigorous logical verification (SMT solver) and feasibility checks (PDDL planner). This hybrid approach leverages the strengths of both paradigms to tackle challenges that neither could fully address alone.
- **Foundational for Future Embodied Agents:** NESYRO provides a robust blueprint for developing next-generation embodied AI systems capable of more autonomous and intelligent interaction with the physical world. It paves the way for robots that can learn, plan, and execute tasks more reliably, even when faced with significant unknowns.

**Limitations and Future Work:**
The authors acknowledge limitations, such as the current reliance on binary Logic Confidence (LC) and predefined domain knowledge. Future work aims to incorporate probabilistic and temporal reasoning (e.g., probabilistic PDDL) to enhance generality and applicability to more diverse, dynamic domains where outcomes are not always certain or explicitly defined. Expanding validation to skills not explicitly present in domain knowledge is also a goal.

**Ethical Considerations:**
The paper explicitly addresses ethical concerns regarding LLM-based robot control potentially leading to unsafe behavior with hazardous tools. NESYRO mitigates these risks through "explicit safety checks and transparent safeguard mechanisms" that verify tool affordances and action preconditions, ensuring interpretable and safe operation. This proactive consideration of safety is crucial for responsible AI development in robotics.

In conclusion, NESYRO represents a critical step towards deploying reliable and intelligent embodied agents by systematically enhancing the grounding and trustworthiness of LLM-generated robotic policies through a novel neuro-symbolic verification and interactive validation process.
