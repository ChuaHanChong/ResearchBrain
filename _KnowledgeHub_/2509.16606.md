# Bayesian Ego-graph Inference for Networked Multi-Agent Reinforcement Learning

> [!summary] Summary
> Researchers at the Australian Artificial Intelligence Institute at the University of Technology Sydney developed BayesG, a decentralized actor-critic framework for networked multi-agent reinforcement learning that infers dynamic, context-aware interaction graphs using only local observations. This approach achieved higher average episode returns and faster convergence compared to existing baselines across various adaptive traffic signal control benchmarks, demonstrating superior scalability in large-scale scenarios.

## Problem

- Existing networked multi-agent reinforcement learning methods often rely on static communication graphs, leading to inefficient coordination and unnecessary message overhead.
- Methods for learning dynamic interaction graphs typically require global state access and centralized infrastructure, rendering them impractical for real-world decentralized systems.
- Decentralized agents in real-world settings operate under local sensing and communication constraints, necessitating solutions that respect these physical limitations without global supervision.

## Method

- Introduced **BayesG**, a ==decentralized actor-critic== framework enabling agents to learn stochastic, context-aware ego-graphs from their local physical neighborhoods.
- Formulated the learning of latent interaction masks as a Bayesian variational inference problem, approximating the posterior distribution of relevant communication links for each agent.
- Jointly optimized agent policies and variational parameters using an Evidence Lower Bound (ELBO) objective, which integrates task feedback into the graph inference process and utilizes Gumbel-Softmax reparameterization.

## Results

- BayesG consistently achieved higher average episode returns and faster convergence rates compared to six baseline methods across five adaptive traffic signal control benchmarks.
- Demonstrated superior scalability in large-scale NewYork traffic scenarios, exhibiting higher asymptotic returns and more stable learning curves than baselines.
- Qualitative analysis and case studies revealed that BayesG learned task-adaptive and directional communication patterns, such as prioritizing communication from less congested areas to more congested ones, effectively reducing traffic congestion.

## Takeaways

> [!tip] Key Insights
> - Decentralized agents can dynamically adapt their communication structures using only local observations and task feedback, overcoming the limitations of static graphs or centralized dynamic graph learning.
> - Learning context-dependent interaction graphs through Bayesian inference allows for adaptive pruning of irrelevant communication links, leading to more efficient and effective coordination.
> - The dual entropy regularization over both actions and communication structures contributes to the robustness and uncertainty-aware neighbor selection in dynamic multi-agent environments.
