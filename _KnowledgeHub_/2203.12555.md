# GriTS: Grid table similarity metric for table structure recognition

> [!summary] Summary
> GriTS (Grid Table Similarity) is a new metric developed by Microsoft researchers for evaluating Table Structure Recognition (TSR), which directly assesses predicted tables in their two-dimensional matrix form. It unifies the evaluation of cell topology, content, and location using a polynomial-time heuristic that provides highly accurate similarity estimates, demonstrating superior robustness and interpretability over existing methods.

## Problem

- Existing TSR metrics often decompose tables, losing the inherent two-dimensional structure and leading to unintuitive scores.
- Current evaluation approaches offer inconsistent task definitions, sometimes conflating TSR with functional analysis or other table extraction subtasks.
- Many metrics are unduly sensitive to the absolute position of cells or treat rows and columns with unequal importance, leading to biased evaluations.

## Method

- Represents tables as matrices of grid cells, conceptually replicating cell content across spanned grid positions to preserve 2D structure.
- Generalizes the NP-hard ==2D-Longest Common Substructure (2D-LCS)== problem to ==2D-Most Similar Substructures (2D-MSS)== using a general cell similarity function.
- Employs a polynomial-time ==Factored 2D-MSS== heuristic that decouples row and column optimizations via nested ==dynamic programming== to approximate true similarity.
- Defines specific **GriTS** variants (**GriTS_Top**, **GriTS_Con**, **GriTS_Loc**) using ==Intersection over Union (IoU)== or ==Longest Common Subsequence (LCS)== similarity functions for comparing cell properties (topology, content, location).

## Results

- The Factored 2D-MSS heuristic produces remarkably tight bounds, with the difference between upper and lower bounds for GriTS_Con being less than **0.0001** for models trained for **4** or more epochs.
- GriTS demonstrates strong adherence to row and column equivalence and cell position invariance, yielding nearly identical scores when **50%** of rows or columns are removed, regardless of their specific positions.
- GriTS's precision and recall values respond predictably and consistently to varying probabilities of randomly missing rows or columns, showing a clear, linear relationship unlike other evaluated metrics.

## Takeaways

> [!tip] Key Insights
> - Preserving the global two-dimensional structure of a table is crucial for a robust and intuitively interpretable evaluation of table structure recognition.
> - A computationally efficient, polynomial-time heuristic can closely approximate the NP-hard 2D-MSS problem, making principled 2D-structure-aware evaluation practical.
> - A unified framework that evaluates cell topology, content, and location concurrently provides a more comprehensive and comparable assessment across diverse TSR models.
