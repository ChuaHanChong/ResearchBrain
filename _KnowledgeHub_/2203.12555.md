# GriTS: Grid table similarity metric for table structure recognition

> [!summary] Summary
> GriTS (Grid Table Similarity) is a new metric developed by Microsoft researchers for evaluating Table Structure Recognition (TSR), which directly assesses predicted tables in their two-dimensional matrix form. It unifies the evaluation of cell topology, content, and location using a polynomial-time heuristic that provides highly accurate similarity estimates, demonstrating superior robustness and interpretability over existing methods.

## Problem

- Existing TSR metrics often decompose tables, losing the inherent two-dimensional structure and leading to unintuitive scores.
- Current evaluation approaches offer inconsistent task definitions, sometimes conflating TSR with functional analysis or other table extraction subtasks.
- Many metrics are unduly sensitive to the absolute position of cells or treat rows and columns with unequal importance, leading to biased evaluations.

## Method

- Represents tables as matrices of grid cells, conceptually replicating cell content across spanned grid positions to preserve 2D structure.
- Generalizes the NP-hard ==2D-Longest Common Substructure (2D-LCS)== problem to ==2D-Most Similar Substructures (2D-MSS)== using a general cell similarity function.
- Employs a polynomial-time ==Factored 2D-MSS== heuristic that decouples row and column optimizations via nested ==dynamic programming== to approximate true similarity.
- Defines specific **GriTS** variants (**GriTS_Top**, **GriTS_Con**, **GriTS_Loc**) using ==Intersection over Union (IoU)== or ==Longest Common Subsequence (LCS)== similarity functions for comparing cell properties (topology, content, location).

## Results

- The Factored 2D-MSS heuristic produces remarkably tight bounds, with the difference between upper and lower bounds for GriTS_Con being less than **0.0001** for models trained for **4** or more epochs.
- GriTS demonstrates strong adherence to row and column equivalence and cell position invariance, yielding nearly identical scores when **50%** of rows or columns are removed, regardless of their specific positions.
- GriTS's precision and recall values respond predictably and consistently to varying probabilities of randomly missing rows or columns, showing a clear, linear relationship unlike other evaluated metrics.

## Takeaways

> [!tip] Key Insights
> - Preserving the global two-dimensional structure of a table is crucial for a robust and intuitively interpretable evaluation of table structure recognition.
> - A computationally efficient, polynomial-time heuristic can closely approximate the NP-hard 2D-MSS problem, making principled 2D-structure-aware evaluation practical.
> - A unified framework that evaluates cell topology, content, and location concurrently provides a more comprehensive and comparable assessment across diverse TSR models.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Table extraction (TE) is a critical task in document understanding, aiming to identify, structure, and interpret tabular data within various documents. This field is typically divided into subtasks: table detection (identifying the presence and bounding box of tables), table structure recognition (TSR), and functional analysis (identifying cell roles like headers and data). This paper specifically focuses on **table structure recognition (TSR)**, which involves inferring the two-dimensional cellular organization (rows, columns, and cell spans) of a table from its unstructured presentation.

Despite significant advancements in deep learning for document analysis, formalizing the TSR task for effective performance evaluation has remained a substantial challenge. Traditional evaluation methods, such as exact matches of cell sets, are often too strict, as minor segmentation or content errors can disproportionately penalize an otherwise good prediction. This led to the development of "partial correctness" metrics that score tables on a continuous scale between 0 and 1. However, existing partial correctness metrics for TSR suffer from several limitations:

- **Loss of 2D Structure:** Many metrics decompose the table's inherent two-dimensional grid into alternative representations, such as sets of adjacency relations (DAR) or sequences of HTML tokens (BLEU-4, TEDS). This loss of the global 2D structure can lead to sensitivities or invariances that do not align with an intuitive understanding of table similarity. For example, a single error can shift subsequent cells, leading to a cascade of penalties not fully captured by these representations.
- **Inconsistent Task Definition:** Existing metrics offer differing perspectives on what constitutes the core TSR task, what cell properties are evaluated (content, topology, location), and whether partial correctness for individual cells is considered. Some metrics conflate TSR with functional analysis (e.g., TEDS, BLEU-4), making it harder to isolate and evaluate structural performance purely.
- **Sensitivity to Position/Orientation:** Some metrics might be unduly sensitive to the absolute position of cells or treat rows and columns with unequal importance, leading to biased evaluations.

GriTS enters this landscape as a proposed solution to these problems. It addresses the fundamental issue of preserving the table's global 2D structure by treating tables directly as matrices of grid cells. By generalizing the NP-hard 2D-Largest Common Substructure (2D-LCS) problem to 2D-Most Similar Substructures (2D-MSS) and offering a polynomial-time heuristic, GriTS aims to provide a more robust, interpretable, and unified evaluation framework. This work is a significant step towards standardizing TSR evaluation, much like IoU became a standard for object detection, or BLEU/ROUGE for text generation. The intention is to create a metric that better reflects human perception of table similarity and enables more meaningful comparisons between different TSR models and approaches.

### 2. Key Objectives and Motivation

The primary objectives and motivations behind the development of GriTS stem from the identified shortcomings of existing table structure recognition (TSR) evaluation metrics. The authors aim to introduce a new class of metric that provides a more accurate, robust, and interpretable assessment of TSR model performance.

The key objectives are:

1. **Preserve Global 2D Structure:** To evaluate predicted tables directly in their natural form as a matrix of cells, thereby maintaining the global two-dimensional relationships between cells. This is a crucial departure from prior metrics that often flatten or decompose tables, losing vital spatial information.
2. **Unify TSR Subtasks:** To integrate the evaluation of cell topology (layout), cell content (text), and cell location (bounding boxes) within a single, coherent framework. This unification simplifies the evaluation process and allows for a more comprehensive and comparable assessment across different types of TSR approaches, regardless of what cell properties they predict.
3. **Achieve Desirable Metric Properties:** To design a metric that adheres to several ideal attributes:
 - **Task Isolation:** Evaluate TSR independently of other table extraction tasks like detection or functional analysis.
 - **Cell Isolation:** Ensure a one-to-one correspondence between predicted and ground truth cells for true positives.
 - **Two-dimensional Order Preservation:** Maintain the relative spatial order of matched cells in both dimensions.
 - **Row and Column Equivalence:** Be invariant to transposing rows and columns, treating them with equal importance.
 - **Cell Position Invariance:** Give equal credit to correctly predicted cells regardless of their absolute position within the table.
 - **Partial Correctness:** Allow for partially correct cells, providing a more granular and less brittle scoring mechanism than exact matching.
4. **Provide a Computationally Tractable Solution:** Given that the ideal 2D-LCS problem is NP-hard, a practical metric requires an efficient approximation. The objective is to develop a polynomial-time heuristic that is proven to be accurate in practice, providing tight bounds on the true similarity.

The core motivation is to overcome the limitations of existing metrics, which often lead to ambiguous interpretations, biased comparisons, or an incomplete understanding of model strengths and weaknesses. By establishing a more principled and consistent evaluation standard, GriTS aims to foster clearer progress in the field of table structure recognition and facilitate the development of more accurate and robust table extraction systems.

### 3. Methodology and Approach

The methodology behind GriTS is centered on transforming table structure recognition evaluation into a matrix similarity problem, drawing inspiration from sequence alignment algorithms.

#### 3.1. Grid Cell Representation

The first foundational step is representing a table as a **matrix of grid cells**. Each entry M[i, j] in this matrix corresponds to a single grid cell at row `i` and column `j`. If a cell spans multiple rows or columns, its content (text, bounding box, topology) is conceptually replicated across all grid cells it occupies. This representation inherently preserves the table's two-dimensional structure, addressing a key limitation of prior metrics.

#### 3.2. Generalizing 2D-LCS to 2D-MSS

The core conceptual leap is the generalization of the **Two-Dimensional Longest Common Substructure (2D-LCS)** problem. 2D-LCS aims to find the largest identical substructures (sub-matrices) common to two input matrices. However, 2D-LCS assumes an exact match between matrix elements, which is too rigid for practical TSR evaluation where partial correctness is desired.
GriTS extends this to the **Two-Dimensional Most Similar Substructures (2D-MSS)** problem. Instead of requiring exact matches, 2D-MSS uses a general **similarity function, `f(e1, e2)`**, to compare elements (grid cells) between substructures. This function outputs a score between 0 and 1, allowing for partial matches. The objective is to find the pair of substructures, `˜A` and `˜B`, from matrices A and B, respectively, that maximize the sum of similarities of their corresponding elements.

#### 3.3. The Factored 2D-MSS Heuristic

Since the 2D-LCS problem (and by extension, 2D-MSS) is NP-hard, a direct optimal solution is computationally intractable for large tables. The authors propose a **polynomial-time heuristic** called the **Factored 2D-MSS algorithm**. This heuristic tackles the problem by decoupling the optimization of rows and columns, similar to the RowColAlign algorithm for spreadsheet diffing:
1. **Nested Dynamic Programming (DP):** The algorithm employs a nested dynamic programming approach.
2. **Row Optimization:** An inner DP first computes the best possible sequence alignment of grid cells for every pair of rows from the predicted and ground truth tables. These pairwise row similarity scores are then used by an outer DP to determine the best alignment of subsequences of rows between the two matrices.
3. **Column Optimization:** The entire procedure is then repeated, substituting columns for rows, to determine the best alignment of subsequences of columns.
4. **Resulting Substructures:** The outcome of this factored optimization is a valid 2D substructure for each matrix. While this approach is an approximation due to the independent optimization of rows and columns, it offers a practical computational complexity of O(|A| · |B|).

#### 3.4. Approximation Bounds

A crucial aspect of the Factored 2D-MSS algorithm is its ability to produce both a **lower bound** and an **upper bound** on the true similarity between the matrices.
- The similarity computed by the algorithm (GriTS score) represents a *lower bound* because it corresponds to a valid, albeit potentially suboptimal, common substructure.
- By relaxing constraints during the optimization (e.g., considering the best possible alignment of rows and columns independently), an *upper bound* on the true similarity can also be derived. The difference between these bounds quantifies the uncertainty in the true similarity, providing a measure of the heuristic's accuracy.

#### 3.5. Defining Specific GriTS Metrics

The general GriTS framework is made concrete by defining specific metrics based on the property of the grid cell being compared and the similarity function `f`:
- **GriTS_Top (Topology Recognition):** Compares the topological properties of cells. `A_i,j` contains a bounding box representing the cell's rowspan and colspan relative to its grid cell position. The similarity function `f` is **Intersection over Union (IoU)** between these relative bounding boxes.
- **GriTS_Con (Content Recognition):** Compares the text content of cells. `A_i,j` contains the text content. The similarity function `f` is **normalized Longest Common Subsequence (LCS)** similarity between text sequences.
- **GriTS_Loc (Location Recognition):** Compares the absolute bounding box locations of cells. `A_i,j` contains the actual bounding box coordinates. The similarity function `f` is **IoU** between these absolute bounding boxes.

Finally, GriTS is formulated as an F-score, using the sum of similarities from the 2D-MSS as the numerator, and the total number of grid cells in both the ground truth (`|A|`) and predicted (`|B|`) matrices as the denominator:
`GriTS_f (A, B) = (2 * Σ_i,j f(˜A_i,j, ˜B_i,j)) / (|A| + |B|)`
This formulation also allows for the derivation of GriTS-Recall and GriTS-Precision, providing further interpretability.

### 4. Main Findings and Results

The experiments conducted by the authors primarily focused on two aspects: validating the practical accuracy of their polynomial-time heuristic and empirically comparing GriTS against existing metrics based on desired properties.

#### 4.1. Tightness of Approximation Bounds

- **Experiment Setup:** The authors evaluated the difference between the lower and upper bounds of GriTS_Con produced by the Factored 2D-MSS algorithm. They used the Table Transformer (TATR) model trained on the PubTables-1M dataset for 20 epochs, effectively generating models of varying performance levels.
- **Results:** The findings demonstrated that the difference between the upper and lower bounds for GriTS_Con was remarkably small in practice. For the worst-performing model (1 epoch), the difference was 0.0005, and for 81.2% of instances, the bounds were identical. As model performance improved, this difference rapidly decreased, approaching zero. For models trained for 4 epochs or more, the difference was less than 0.0001, and for 93% or more of instances, the GriTS score was precisely the true similarity.
- **Significance:** This result is crucial as it validates the practical utility of the Factored 2D-MSS heuristic. Despite the NP-hard nature of the optimal 2D-MSS problem, the proposed polynomial-time approximation provides a highly accurate estimate of the true similarity, making GriTS a reliable and practical metric.

#### 4.2. Comparison with Other Metrics for Desired Properties

The authors compared GriTS with DAR_Con and TEDS_Con (a version of TEDS with functional analysis removed for fair comparison) against the ideal metric properties outlined in the paper. They used a subset of 44,381 tables from PubTables-1M without spanning cells to simplify controlled corruption.

- **Row and Column Equivalence & Cell Position Invariance:**
 - **Experiment Setup:** Predicted tables were created by removing 50% of either rows or columns using three schemes: "First" (first 50%), "Alternating" (every other), and "Random." This tested sensitivity to whether rows or columns were removed, and *which* rows/columns were removed.
 - **Results:**
 - **DAR_Con:** Showed sensitivity to both whether rows or columns were selected and to *which* rows or columns were selected (e.g., "First" vs. "Random").
 - **TEDS_Con:** Was sensitive to whether rows or columns were selected, but largely insensitive to *which* specific rows or columns were selected (i.e., "First", "Alternating", "Random" schemes yielded similar scores for rows, and similarly for columns).
 - **GriTS_Con:** Produced nearly identical values across all six scenarios (removing 50% of rows by any scheme, or removing 50% of columns by any scheme). This indicates strong insensitivity to both the dimension (rows vs. columns) and the absolute position of the missing cells.
 - **Significance:** GriTS demonstrated superior adherence to the principles of row/column equivalence and cell position invariance, which are critical for an unbiased evaluation metric.

- **Sensitivity to Probability of Missing Rows/Columns:**
 - **Experiment Setup:** Rows or columns were randomly removed with varying probabilities `p(x)` from 0 to 1. All three GriTS variants (Top, Con, Loc) were included.
 - **Results:**
 - **DAR_Con:** Showed a consistent response to randomly missing rows versus columns across all `p(x)`, but its F-score behavior was less directly interpretable relative to `p(x)`. Its precision showed a slight sensitivity to rows vs. columns.
 - **TEDS_Con:** Displayed different sensitivities to randomly missing columns compared to randomly missing rows, with the relative magnitude of this difference varying with `p(x)`.
 - **GriTS (all variants):** Exhibited very similar responses for randomly missing rows and columns across the entire range of `p(x)`. Crucially, GriTS's recall values closely mirrored `p(x)` (the probability of a cell *being present* in the predicted table, i.e., `1 - p(missing)`), and its precision values also behaved predictably.
 - **Significance:** GriTS's consistent and predictable behavior, where its precision and recall directly corresponded to the manipulated probabilities, further underscores its interpretability and robustness compared to alternatives. The clear and linear relationship between `p(x)` and GriTS's recall/precision is highly desirable.

Overall, the experimental results strongly support the claims that GriTS closely resembles an ideal metric for TSR. Its practical accuracy (tight bounds of the heuristic) combined with its desirable behavioral properties (row/column equivalence, cell position invariance, and predictable precision/recall) make it a significantly improved evaluation tool for the field.

### 5. Significance and Potential Impact

The introduction of Grid Table Similarity (GriTS) represents a significant advancement in the field of table structure recognition (TSR) evaluation, with far-reaching potential impacts on research and development.

#### 5.1. Improved Interpretability and Stability of Evaluation

By directly evaluating tables in their natural matrix form, GriTS ensures that the inherent two-dimensional structure is preserved, which is fundamental to how humans perceive and understand tables. This approach leads to evaluation scores that are more intuitive and better reflect the actual quality of a predicted table. The empirical validation showing GriTS's insensitivity to cell position and equal treatment of rows and columns demonstrates a more stable and less arbitrary metric, reducing noise in performance assessment. This improved stability means that reported model performances are more reliable, fostering greater confidence in research findings.

#### 5.2. Unification of TSR Subtasks

GriTS is the first metric to address cell topology, cell content, and cell location recognition within a single, unified framework. This is a major contribution because it simplifies the evaluation process significantly. Researchers no longer need to rely on separate, potentially conflicting metrics for different aspects of TSR. This unification makes it easier to compare diverse modeling approaches (e.g., those primarily focused on layout vs. those incorporating content) and to understand their overall strengths and weaknesses under a consistent lens. It encourages the development of models that perform well across all critical dimensions of table structure.

#### 5.3. Facilitating Meaningful Model Comparisons

With a more robust and unified metric, the ability to conduct meaningful comparisons across different TSR models, datasets, and methodologies is greatly enhanced. Discrepancies in reported performance can often be attributed to differences in evaluation metrics rather than true model capabilities. GriTS aims to mitigate this by providing a standardized, principled benchmark. This clarity will accelerate research progress by allowing researchers to more accurately identify state-of-the-art models, pinpoint areas for improvement, and focus on genuine architectural or algorithmic innovations rather than being misled by metric artifacts.

#### 5.4. Practical Applicability and Industry Impact

Developed by Microsoft researchers, GriTS is designed with practical applications in mind. The tight bounds of the polynomial-time heuristic ensure that the metric is not only theoretically sound but also computationally efficient enough for large-scale datasets and real-world deployment. As table extraction is crucial for enterprise document processing, business intelligence, and data analytics, a superior evaluation metric like GriTS will directly contribute to the development of more accurate and reliable table extraction tools for products and services. This, in turn, can improve data quality, automate workflows, and unlock valuable information from unstructured documents across various industries.

#### 5.5. Open-Source Contribution

The commitment to releasing the code on GitHub (`https://github.com/microsoft/table-transformer`) ensures that GriTS can be widely adopted by the research community. This open-source availability is critical for establishing GriTS as a new standard, enabling reproducibility, fostering collaboration, and driving collective progress in table structure recognition.

In conclusion, GriTS addresses a long-standing challenge in table structure recognition evaluation by offering a principled, unified, and empirically validated metric. Its adoption is poised to elevate the quality of research, streamline model development, and ultimately lead to more effective and robust table extraction technologies.
