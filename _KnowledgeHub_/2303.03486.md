# Sampling-based Exploration for Reinforcement Learning of Dexterous Manipulation

> [!summary] Summary
> A framework integrating sampling-based planning with reinforcement learning allows robots to acquire dexterous in-hand manipulation skills for complex and concave objects without external support surfaces. The learned policies, relying solely on intrinsic tactile and proprioceptive feedback, successfully transfer to a real robot, enabling robust multi-revolution object reorientation.

## Problem

- Reinforcement Learning (RL) faces significant exploration challenges in the high-dimensional, constrained state spaces of dexterous manipulation, often leading to inefficient learning or task failure.
- Existing RL methods for in-hand manipulation frequently rely on simplifying assumptions like convex objects, passive support surfaces, or extensive extrinsic sensing, limiting their real-world applicability.
- Learning complex finger-gaiting skills to achieve large object reorientation using only intrinsic sensing and maintaining a stable grasp without external support is difficult due to non-holonomic transitions and narrow state space passages.

## Method

- The research integrates ==Sampling-Based Planning (SBP)== algorithms, specifically a ==General-purpose RRT (G-RRT)== leveraging full dynamics simulation and parallel execution in IsaacGym, to generate effective and diverse ==reset distributions== for RL training.
- A custom policy architecture uses only ==intrinsic observations== (hand joint positions and contact feedback) for its actor, while the critic receives additional ==privileged information== (object pose and contact forces).
- Reinforcement Learning is performed using an ==Asymmetric Actor-Critic PPO== algorithm with a reward function designed to encourage object angular velocity around a hand-centric axis, penalizing translation and promoting stable grasp through contact maintenance.

## Results

- **G-RRT** consistently explored the manipulation state space farther and enabled more efficient RL training, particularly for 'hard' concave objects (e.g., L-shape) where baseline exploration methods failed to learn.
- Policies trained with SBP-informed resets successfully transferred to a physical robot hand, demonstrating robust finger-gaiting and multi-revolution reorientation for various objects, including challenging L-shapes (median **1.5 revolutions**).
- An ablation study confirmed that a sufficiently large SBP tree (e.g., **~10⁵ nodes**) is necessary for reliable RL training, and tactile feedback significantly contributes to learning performance on complex objects.

## Takeaways

> [!tip] Key Insights
> - SBP-generated state distributions are crucial for overcoming exploration difficulties in dexterous manipulation, enabling RL to learn skills for complex, concave objects where random or simpler exploration methods fail.
> - Leveraging full physics simulation for SBP (G-RRT) is more effective and efficient than approximate kinematic methods (M-RRT) for generating diverse and stable manipulation states, especially when parallel simulation is available.
> - Tactile feedback is essential for learning robust manipulation policies for challenging objects without object pose information, proving more beneficial and leading to faster learning compared to relying solely on proprioception or even global object pose.
