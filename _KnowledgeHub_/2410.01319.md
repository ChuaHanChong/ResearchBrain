# Finetuning Pre-trained Model with Limited Data for LiDAR-based 3D Object Detection by Bridging Domain Gaps

> [!summary] Summary
> The Domain Adaptive Distill-Tuning (DADT) framework improves the finetuning of pre-trained LiDAR-based 3D object detection models, effectively bridging domain gaps, particularly those stemming from point density variations, using only limited target domain data. This approach yields significant performance gains, such as a 20.98 AP and 18.77 APH improvement on Waymo with 64 frames, while enabling the model to retain robust, generalizable features.

## Problem

- LiDAR-based 3D object detection models experience performance degradation when applied to new environments or sensor configurations due to domain shifts.
- Adapting pre-trained models to new target domains typically demands extensive labeled data, which is costly and time-consuming to acquire and annotate.
- Differences in LiDAR point density, termed 'beam-induced discrepancies,' create a substantial domain gap that simple finetuning with limited data cannot adequately address.

## Method

- The Domain Adaptive Distill-Tuning (DADT) framework employs a teacher-student architecture for finetuning pre-trained models.
- A frozen teacher network processes density-aligned target data (via pseudo low beam generation), while a finetuned student network processes original density-non-aligned target data.
- Two BEV-based similarity losses (object similarity and context similarity) are introduced to regularize the student, guiding it to learn representations consistent with the teacher and prevent overfitting.

## Results

- DADT achieved substantial performance gains on the Waymo Open Dataset, improving by **20.98** AP and **18.77** APH overall with only 64 labeled target frames compared to vanilla finetuning.
- On the KITTI dataset, DADT improved mean Average Precision by **4.90** for SECOND and **4.36** for PV-RCNN++ using just **1%** of the training data.
- The framework demonstrated improved performance in continual finetuning and semi-supervised learning scenarios, indicating better retention of generalizable features and enhanced adaptability to multiple datasets.

## Takeaways

> [!tip] Key Insights
> - Explicitly accounting for and mitigating 'beam-induced discrepancies' in point density is crucial for successful domain adaptation in LiDAR-based 3D object detection.
> - A teacher-student distillation approach, where the teacher's input is density-aligned, effectively helps the student retain robust pre-trained representations and generalize better with limited target data.
> - Regularizing the student's BEV features through object and context similarity losses enables it to adapt to a new domain while preventing overfitting and preserving the broader contextual understanding.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The research addresses a persistent challenge in LiDAR-based 3D object detection: adapting models trained on one dataset (source domain) to new environments or sensor configurations (target domains) when only a limited amount of labeled data is available in the target domain. This issue is particularly relevant for applications like autonomous vehicles and mobile robots, where diverse operational environments and sensor setups are common, and large-scale data collection and annotation for every new scenario are impractical and expensive.

Traditional 3D object detection models often exhibit performance degradation when encountering domain shifts, which can stem from differences in LiDAR sensor types (e.g., 16-beam vs. 64-beam), spatial resolution, field of view (FOV), or geographical locations. The emergence of self-supervised pre-training on large-scale unlabeled point clouds has provided models with expressive representations, capable of learning general features. However, as noted by the authors and prior studies, these pre-trained models still require substantial amounts of target domain data to effectively finetune and overcome inherent domain gaps, which include "beam-induced discrepancies" related to point density.

This work specifically positions itself at the intersection of self-supervised pre-training, domain adaptation, and efficient model finetuning. While unsupervised domain adaptation (UDA) methods exist for point clouds, they often overlook specific challenges like beam-induced domain gaps or are constrained by reliance on unlabeled target data. Furthermore, general model finetuning methods, which aim to transfer pre-trained representations to downstream tasks, have primarily been explored in 2D classification, with limited attention given to 3D object detection, especially under conditions of severe domain shift and data scarcity. This paper aims to bridge these gaps by proposing a finetuning framework designed to retain the robust representations of a pre-trained model while adapting it to new domains using only a small number of labeled target samples.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a method that enables effective finetuning of pre-trained LiDAR-based 3D object detection models using a limited amount of labeled data from a new target domain. This objective is driven by several key motivations:

1. **Addressing Domain Gaps in LiDAR-based 3D Object Detection:** LiDAR-based detectors often struggle to generalize across different sensor configurations (e.g., varying beam numbers, spatial resolution, density, FOVs) or geographical locations. This "domain shift" leads to performance degradation in target environments. The motivation is to overcome these discrepancies without requiring extensive new data collection and annotation.

2. **Mitigating the Need for Large-Scale Target Data:** Current practices often necessitate collecting and annotating large datasets for each new target domain, a process that is costly, time-consuming, and labor-intensive. The research aims to reduce this dependency by enabling successful adaptation with only approximately 100 LiDAR frames from the target domain.

3. **Improving Finetuning Efficacy for Pre-trained Models:** While self-supervised pre-training methods (like AD-PT) provide robust initial representations from large unlabeled datasets, empirical observations suggest that simply finetuning these models with limited target data can lead to suboptimal performance. This is attributed to the mismatch between source and target domain data distributions, which can cause the model to lose its generalizable pre-trained features and overfit to the small target dataset. The motivation is to design a finetuning strategy that retains the expressive power of the pre-trained model while effectively adapting it to the target domain's specifics.

4. **Counteracting "Beam-Induced Discrepancy":** A specific and significant aspect of domain shift in LiDAR data is the difference in point density due to varying LiDAR beam configurations. The authors empirically demonstrate that this beam-induced discrepancy significantly impacts representation learning. A key motivation is to explicitly address this density-driven representational gap during finetuning.

5. **Developing a Robust and Generalizable Finetuning Framework:** The researchers aim to create a finetuning approach that is not only effective with limited data but also maintains model robustness against distribution shifts, preventing performance degradation and supporting potential applications in continual learning and semi-supervised scenarios. This involves regularizing the finetuning process to guide the model towards learning features similar to an "oracle" model (one hypothetically finetuned with complete target data).

In essence, the paper seeks to provide a practical and efficient solution for deploying LiDAR-based 3D object detection systems in diverse real-world scenarios by enabling rapid and effective adaptation of pre-trained models using minimal target-specific labeled data.

### 3. Methodology and Approach

The proposed method, called Domain Adaptive Distill-Tuning (DADT), is designed to finetune a pre-trained 3D object detection model with limited target domain data by bridging domain gaps, particularly those related to LiDAR point density. DADT employs a teacher-student architecture coupled with specific BEV-based regularization losses.

**A. Problem Statement Formalization**

The problem is defined as adapting a pre-trained model $f_{\theta_p} \cdot g_{\phi_p}$ to a new downstream dataset $D_d = \{(X_i, Y_i)\}_{i=1}^N$ where $N$ is small. $f_{\theta_p}$ represents the 3D and BEV encoders (backbone), and $g_{\phi_p}$ is the detection head. The downstream model $f_{\theta_d} \cdot g_{\phi_d}$ is initialized with $f_{\theta_d}$ from $f_{\theta_p}$ and $g_{\phi_d}$ randomly. The challenge arises from a "beam-induced discrepancy" (density domain shift) between the pre-training dataset $D_p$ and the downstream dataset $D_d$. Vanilla finetuning, which directly optimizes the detection loss on $D_d$, is identified as suboptimal due to this density mismatch and limited data.

**B. Teacher-Student Architecture for Reducing a Density-driven Representational Gap**

To address the density domain shift, DADT utilizes a teacher-student learning paradigm:
1. **Teacher Network:** This network uses a *frozen* pre-trained backbone. Its input is a *density-aligned* version of the target LiDAR data, denoted as $D_d^{pseudo}$. The teacher network serves as a stable reference for robust feature representations.
2. **Student Network:** This network's backbone is initialized from the pre-trained model, and its parameters are *finetuned* during training. Its input is the *original density-non-aligned* target LiDAR data $D_d$.

**Pseudo Low Beam Generation:** To align the point density for the teacher network, the target domain LiDAR data $D_d$ is downsampled to create $D_d^{pseudo}$. This process mimics the characteristics of the pre-training dataset $D_p$. The steps are:
- Convert LiDAR points from Cartesian $(x, y, z)$ to Spherical coordinates $(r, \phi, \theta)$.
- Apply K-means clustering to the inclination angle $\phi$ to assign points to "beam labels."
- Uniformly downsample points within each beam cluster along $\phi$.
- Convert the downsampled points back to Cartesian coordinates to obtain $D_d^{pseudo}$.
This procedure ensures that the teacher processes data with a point density comparable to the source domain of the pre-trained model, effectively reducing the beam-induced domain gap for the teacher.

**C. BEV-based Similarity Losses**

DADT introduces two regularization losses applied to the Bird's Eye View (BEV) features to guide the student network's learning, encouraging it to retain the representational distribution of the teacher network and prevent overfitting.

1. **Object Similarity Loss ($L_o$):** This loss aims to make the BEV features of the same objects in the teacher and student networks similar.
 - For each object $i$ of a given class $c$, object BEV features $z^T_i$ (from the teacher) and $z^S_i$ (from the student) are extracted using ground truth bounding boxes.
 - The loss is computed as the Mean Squared Error (MSE) between these features, summed across objects and normalized per class:
 $L_o = \sum_{c \in C} \frac{1}{N_c} \sum_{i=1}^{N_c} \|z^T_i - z^S_i\|^2$.
 - Per-class normalization addresses class imbalance during finetuning.

2. **Context Similarity Loss ($L_c$):** This attention-based loss focuses on aligning grid-level semantic region features between the teacher and student.
 - For the student network, an attention mechanism is used where the object BEV feature $z^S_i$ acts as the query, and the student's overall BEV features $F^S$ serve as key and value vectors. This generates an attended feature $a^S_c$ for each class $c$, emphasizing semantic regions.
 - Similarly, for the teacher network, $a^T_c$ is computed using $z^T_i$ as the query and $F^T$ (teacher's BEV features) as key/value.
 - The loss is the MSE between these attended features:
 $L_c = \sum_{c \in C} MSE(a^T_c, a^S_c)$.
 - This encourages the student to focus on and represent similar semantic regions as the teacher, preserving broader contextual understanding.

**D. Total Loss Function**

The overall objective function to be minimized during finetuning combines the standard object detection loss ($L_{Det}$) with the two proposed regularization terms:
$L = L_{Det} + \lambda_c L_c + \lambda_o L_o$
where $\lambda_c$ and $\lambda_o$ are hyperparameters controlling the weight of the context and object similarity losses, respectively. These weights are determined via grid search.

### 4. Main Findings and Results

The research evaluates DADT using the Waymo Open Dataset and KITTI dataset, employing SECOND and PV-RCNN++ detectors pre-trained with AD-PT on the ONCE dataset.

**A. Effect of Finetuning Pre-trained Model with Limited Data**

- **Evaluation on Waymo Open Dataset:** DADT consistently demonstrated performance improvements over vanilla finetuning across different numbers of limited LiDAR frames (32 to 128 frames). For instance, with 32 frames, DADT achieved gains of 4.44 AP and 3.81 APH (Absolute Performance Heading) overall. With 64 frames, the gains were 20.98 AP and 18.77 APH overall. These improvements were observed across vehicle, pedestrian, and cyclist categories, indicating the method's effectiveness in adapting pre-trained models with limited data. Visual comparisons confirmed DADT's ability to detect more objects, including distant ones, compared to the baseline.
- **Evaluation on KITTI Dataset:** Similar significant gains were observed on the KITTI dataset. For 1% (37 frames) of training data, DADT improved the mean Average Precision (mAP) by 4.90 for SECOND and 4.36 for PV-RCNN++. With 3% (111 frames), the gains were 3.33 mAP for SECOND and 5.20 mAP for PV-RCNN++. This confirms DADT's effectiveness across different datasets and detector architectures.
- **UMAP Analysis:** UMAP visualizations of BEV features showed that vanilla finetuning with limited data leads to distributional shifts, implying overfitting to the small dataset and poor generalization. In contrast, DADT guided the model to produce representational distributions similar to an "Oracle" model (finetuned with 100% data), indicating better retention of generalizable features and prevention of overfitting.
- **Ablation Study:** An ablation study on the Waymo Open Dataset (with 96 frames) confirmed the contribution of each component:
 - Pseudo Low Beam Generation (PLBG) contributed to an average mAP increase.
 - The object similarity loss ($L_o$) contributed to an average mAP increase.
 - The context similarity loss ($L_c$) also contributed to an average mAP increase.
 - The combination of all three components yielded the highest performance (33.77 Avg. AP), significantly outperforming the baseline (15.02 Avg. AP), demonstrating a synergistic effect. Visualization of context similarity heatmaps showed DADT highlighting objects and their surrounding environment effectively.

**B. Performance in Continual Training Scenarios**

- **Continual Finetuning:** When evaluated in a sequential adaptation scenario (finetuning on Waymo then KITTI), DADT showed improved performance over direct transfer and vanilla finetuning. For car detection on KITTI, DADT achieved gains of 2.65, 2.05, and 1.35 in AP for easy, moderate, and hard difficulties, respectively, compared to the baseline. This suggests that DADT helps models retain original representational distributions, which facilitates continuous adaptation to multiple datasets.
- **Semi-supervised Learning:** In a semi-supervised setting on KITTI (using 3% labeled data and pseudo-labels for the rest), DADT achieved an average mAP of 68.29, outperforming the baseline (66.83 mAP). This performance was closer to a model trained from scratch with 100% labeled data (70.84 mAP). This result indicates DADT's potential to maintain high performance with limited initial labels followed by self-training on unlabeled data.

### 5. Significance and Potential Impact

The DADT framework presents several significant contributions and potential impacts on the field of LiDAR-based 3D object detection:

1. **Reduced Data Dependency and Cost:** The primary significance lies in enabling effective adaptation of pre-trained 3D object detectors using only a limited number of labeled target data samples (approximately 100 frames). This directly addresses the high cost and time investment associated with large-scale data collection and annotation for every new operational domain or sensor setup. This reduction in data dependency can accelerate the development and deployment cycles for autonomous systems.

2. **Enhanced Generalization and Robustness:** DADT's approach of bridging domain gaps, particularly the beam-induced discrepancy, and regularizing finetuning with teacher-student distillation helps the model retain the generalizable representations learned during extensive pre-training. This prevents overfitting to small target datasets and leads to more robust performance in diverse real-world conditions, which is crucial for safety-critical applications like autonomous driving.

3. **Improved Practicality for Autonomous Systems:** For autonomous vehicles and mobile robots operating in varied geographical locations (e.g., different cities or countries) or equipped with different LiDAR sensors, DADT offers a practical solution for adapting their perception systems quickly and efficiently. This makes the technology more scalable and adaptable to global deployment requirements.

4. **Advancement in Finetuning Methodologies for 3D Perception:** By introducing a teacher-student architecture with density alignment and novel BEV-based object and context similarity losses, DADT contributes a specialized finetuning framework tailored for the unique challenges of 3D point cloud data. Unlike prior finetuning methods largely developed for 2D tasks, DADT specifically addresses issues like point density variations which are critical in LiDAR perception.

5. **Facilitating Continual Learning and Semi-supervised Paradigms:** The demonstrated effectiveness in continual finetuning and semi-supervised learning scenarios suggests that DADT can serve as a foundational component for more dynamic and adaptive perception systems. In industrial settings, this could translate to "online learning" where models are continuously updated with limited labels and unlabeled streams of data, maintaining high performance over time as environments change.

In summary, DADT represents a step towards more resource-efficient and adaptable LiDAR-based 3D object detection, with direct implications for the practical realization of robust autonomous systems that can operate reliably across diverse and evolving domains.
