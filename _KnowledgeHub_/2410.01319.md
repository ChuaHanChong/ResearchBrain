# Finetuning Pre-trained Model with Limited Data for LiDAR-based 3D Object Detection by Bridging Domain Gaps

> [!summary] Summary
> The Domain Adaptive Distill-Tuning (DADT) framework improves the finetuning of pre-trained LiDAR-based 3D object detection models, effectively bridging domain gaps, particularly those stemming from point density variations, using only limited target domain data. This approach yields significant performance gains, such as a 20.98 AP and 18.77 APH improvement on Waymo with 64 frames, while enabling the model to retain robust, generalizable features.

## Problem

- LiDAR-based 3D object detection models experience performance degradation when applied to new environments or sensor configurations due to domain shifts.
- Adapting pre-trained models to new target domains typically demands extensive labeled data, which is costly and time-consuming to acquire and annotate.
- Differences in LiDAR point density, termed 'beam-induced discrepancies,' create a substantial domain gap that simple finetuning with limited data cannot adequately address.

## Method

- The Domain Adaptive Distill-Tuning (DADT) framework employs a teacher-student architecture for finetuning pre-trained models.
- A frozen teacher network processes density-aligned target data (via pseudo low beam generation), while a finetuned student network processes original density-non-aligned target data.
- Two BEV-based similarity losses (object similarity and context similarity) are introduced to regularize the student, guiding it to learn representations consistent with the teacher and prevent overfitting.

## Results

- DADT achieved substantial performance gains on the Waymo Open Dataset, improving by **20.98** AP and **18.77** APH overall with only 64 labeled target frames compared to vanilla finetuning.
- On the KITTI dataset, DADT improved mean Average Precision by **4.90** for SECOND and **4.36** for PV-RCNN++ using just **1%** of the training data.
- The framework demonstrated improved performance in continual finetuning and semi-supervised learning scenarios, indicating better retention of generalizable features and enhanced adaptability to multiple datasets.

## Takeaways

> [!tip] Key Insights
> - Explicitly accounting for and mitigating 'beam-induced discrepancies' in point density is crucial for successful domain adaptation in LiDAR-based 3D object detection.
> - A teacher-student distillation approach, where the teacher's input is density-aligned, effectively helps the student retain robust pre-trained representations and generalize better with limited target data.
> - Regularizing the student's BEV features through object and context similarity losses enables it to adapt to a new domain while preventing overfitting and preserving the broader contextual understanding.
