# Video2Game: Real-time, Interactive, Realistic and Browser-Compatible Environment from a Single Video

> [!summary] Summary
> Video2Game presents a framework that transforms a single real-world video into a real-time, interactive, and browser-compatible 3D environment, integrating a large-scale neural radiance field with mesh baking and physics modeling. The system enables free exploration and physically plausible interactions, achieving over 100 FPS in browser-based environments and outperforming state-of-the-art neural rendering and mesh-based baselines in novel view synthesis and geometry reconstruction.

## Problem

- Creating high-quality, interactive virtual environments is costly, time-consuming, and demands specialized expertise, often requiring extensive manual modeling.
- Existing automated methods like photogrammetry necessitate substantial post-processing for interactive use, while neural radiance fields (NeRFs) primarily focus on visual fidelity, lacking real-time interaction, physical plausibility, and game engine compatibility for large, unbounded scenes.
- Current solutions struggle with efficient real-time performance, defining physical interactions within volumetric representations, and direct integration into conventional game engines.

## Method

- **Video2Game** uses a three-component pipeline that converts a single input video into a functional 3D environment by integrating a large-scale Neural Radiance Field (NeRF) with a mesh module and a physics module.
- An enhanced ==Instant-NGP== model is developed to handle sparsely-captured, large-scale, and unbounded scenes by incorporating a contraction function, predicting semantics and surface normals, and regularizing geometry with 2D monocular depth, normal, and semantic priors.
- The learned ==NeRF== is distilled into a game-engine compatible mesh with a ==neural texture map== for efficient real-time rendering and is decomposed into discrete entities equipped with rigid body physics attributes to enable interactive collision detection and object manipulation.

## Results

- The large-scale **NeRF model** achieved superior novel view synthesis (e.g., higher PSNR, SSIM) and more accurate geometry reconstruction (lower Outlier-%, RMSE, MAE) on datasets like KITTI-360 compared to baselines like Instant-NGP and Nerfacto.
- The baked mesh rendering performed comparably to or better than other mesh-based methods while enabling the highest interactive compatibility, including real-time rendering, rigid-body physics, and scene decomposition.
- The browser-based interactive environment achieved real-time frame rates exceeding **100 FPS** across diverse hardware, demonstrating realistic game features (e.g., object manipulation with rigid-body dynamics) and robot simulations (e.g., pushing/picking objects) with high physical plausibility.

## Takeaways

> [!tip] Key Insights
> - Monocular 2D priors (depth, normals, semantics) effectively regularize large-scale NeRF training, significantly improving geometry accuracy and novel view synthesis from sparsely captured, unbounded video data.
> - Distilling a complex NeRF into a game-engine compatible mesh with a neural texture allows for a balance between photo-realistic rendering and the efficiency required for real-time interaction and broad compatibility.
> - Decomposing the reconstructed scene into individual, actionable entities with assigned rigid body physics attributes enables robust physical interactions (e.g., collisions, manipulation) within the generated virtual environment.
