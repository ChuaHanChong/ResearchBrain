# Multimodal Latent Language Modeling with Next-Token Diffusion

> [!summary] Summary
> This paper introduces a unified framework called LatentLM for handling both discrete and continuous data using causal Transformers with next-token diffusion

## Problem

- Existing multimodal models struggle to handle both discrete data (text, code) and continuous data (images, audio, video) in a unified way
- Previous approaches rely on pipelines or quantization which creates information bottlenecks
- Different objectives and architectures for discrete vs continuous data make joint training challenging

## Method

- Represents continuous data as latent vectors using ==σ-VAE== with fixed variance
- Introduces ==next-token diffusion== to autoregressively generate latent vectors one by one
- Uses a shared ==causal Transformer backbone== with a unified language modeling objective, integrating a ==diffusion head== for continuous data and a softmax head for discrete data

## Results

- Outperforms DiT in image generation when scaling up model size, with strong scalability properties across different model sizes and batch sizes
- Better performance than Transfusion and VQ models on multimodal language tasks
- **10x** fewer decoding steps than VALL-E 2 on text-to-speech while maintaining quality

## Takeaways

> [!tip] Key Insights
> - Higher compression ratio than vector quantization while maintaining quality; σ-VAE with fixed variance helps prevent collapse and improves autoregressive generation
> - Unified architecture enables better information sharing between modalities and simpler implementation by reusing existing language model infrastructure
> - Allows end-to-end training across modalities

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Artificial intelligence systems that can seamlessly work with different types of data—text, images, audio, and video—represent one of the most important frontiers in AI research. The paper "Multimodal Latent Language Modeling with Next-Token Diffusion" introduces LatentLM, a groundbreaking approach to creating AI systems that can process and generate multiple types of data using a unified framework.

Developed by researchers from Microsoft Research and Tsinghua University, LatentLM represents a significant advancement in multimodal AI by solving a fundamental challenge: how to elegantly handle both discrete data (like text and code) and continuous data (like images and audio) within a single model architecture.

### 2. Key Objectives and Motivation

Traditional AI approaches tend to handle different data types in separate ways:

1. **Discrete data** (text, code): Typically processed using language models with next-token prediction
2. **Continuous data** (images, audio): Often handled with specialized architectures like diffusion models

This separation creates challenges when trying to build models that can seamlessly work across modalities. Previous approaches have attempted to bridge this gap in several ways:

Each previous approach has significant limitations:

- **Vector Quantization (VQ-VAE)**: Converts continuous data into discrete tokens, but this process is lossy and has low compression ratios
- **Diffusion for Discrete Data**: Compromises performance on discrete data like text
- **Hybrid Approaches**: Uses different objectives for different modalities, making unified training difficult

### 3. Methodology and Approach

#### 3.1. LatentLM Architecture

LatentLM introduces a novel approach that leverages the strengths of both autoregressive language models and diffusion models. The architecture consists of:

1. **Unified Causal Transformer Backbone**: A single Transformer network processes all data types
2. **Dual Output Heads**:
 - A standard language modeling head for discrete tokens
 - A diffusion head for generating continuous latent vectors
3. **σ-VAE Encoder/Decoder**: A modified variational autoencoder that encodes continuous data into latent vectors with controlled variance

This allows the model to naturally handle sequences that interleave different data types, such as text with embedded images or audio clips.

#### 3.2. σ-VAE: Solving the Variance Collapse Problem

Standard VAEs suffer from a "variance collapse" problem that makes them unsuitable for autoregressive generation. The authors introduce σ-VAE, which fixes this issue:

The key innovation is that σ-VAE enforces a fixed variance in the latent space, which makes it much more suitable for autoregressive modeling. This is achieved by sampling the variance from a fixed distribution rather than predicting it from the input.

#### 3.3. Next-Token Diffusion

The second major innovation is "next-token diffusion," which allows the model to autoregressively generate latent vectors for continuous data. Unlike traditional diffusion models that generate an entire image at once, next-token diffusion generates one token at a time, conditioning on the previously generated sequence.

The diffusion process works by:
1. Starting with random noise
2. Progressively denoising it over multiple steps
3. Conditioning each denoising step on the Transformer's hidden state

The mathematical formulation of the diffusion process can be expressed as:

```
z_t = αt * z_0 + σt * ε
```

Where:
- z_t is the noisy latent vector at timestep t
- z_0 is the clean latent vector
- αt and σt are diffusion schedule parameters
- ε is random noise

#### 5.1. Applications and Use Cases

LatentLM enables a wide range of applications:

1. **Rich Content Creation**: Generate text with embedded images, audio clips, or videos
2. **Multimodal Understanding**: Comprehend and reason about content that includes multiple data types
3. **Interactive Assistants**: Create AI systems that can perceive and respond to various input modalities
4. **Cross-Modal Translation**: Convert content from one modality to another (e.g., text to speech, images to text)

The research presented in this paper has several important implications for the future of AI:

1. **Unified Foundation Models**: LatentLM points toward a future where a single model architecture can handle all types of data, eliminating the need for specialized models for each modality.

2. **More Natural Interfaces**: By seamlessly integrating multiple modalities, future AI systems based on this approach could interact with humans in more natural and intuitive ways.

3. **Computational Efficiency**: The approach's improved inference efficiency could make sophisticated multimodal AI more accessible and practical for real-world applications.

By solving the fundamental challenge of unifying discrete and continuous data processing, it opens new possibilities for more capable, flexible, and efficient AI systems.
