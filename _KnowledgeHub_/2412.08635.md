# Multimodal Latent Language Modeling with Next-Token Diffusion

> [!summary] Summary
> This paper introduces a unified framework called LatentLM for handling both discrete and continuous data using causal Transformers with next-token diffusion

## Problem

- Existing multimodal models struggle to handle both discrete data (text, code) and continuous data (images, audio, video) in a unified way
- Previous approaches rely on pipelines or quantization which creates information bottlenecks
- Different objectives and architectures for discrete vs continuous data make joint training challenging

## Method

- Represents continuous data as latent vectors using ==σ-VAE== with fixed variance
- Introduces ==next-token diffusion== to autoregressively generate latent vectors one by one
- Uses shared ==causal Transformer backbone== with unified language modeling objective
- Integrates both ==diffusion head== for continuous data and softmax head for discrete data

## Results

- Outperforms DiT in image generation when scaling up model size
- Better performance than Transfusion and VQ models on multimodal language tasks
- **10x** fewer decoding steps than VALL-E 2 on text-to-speech while maintaining quality
- Strong scalability properties across different model sizes and batch sizes
- Higher compression ratios enable more efficient training and inference

## Takeaways

> [!tip] Key Insights
> - Higher compression ratio than vector quantization while maintaining quality
> - Unified architecture enables better information sharing between modalities
> - σ-VAE with fixed variance helps prevent collapse and improves autoregressive generation
> - Simpler implementation by reusing existing language model infrastructure
> - Allows end-to-end training across modalities
