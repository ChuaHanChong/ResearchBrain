# DiffTaichi: Differentiable Programming for Physical Simulation

> [!summary] Summary
> DiffTaichi introduces a differentiable programming language that enables high-performance physical simulators with enhanced developer productivity, achieving near hand-tuned CUDA speeds and up to 188x faster execution than TensorFlow for complex simulations. The system also offers improved gradient quality for discontinuous events by incorporating Time-of-Impact collision detection.

## Problem

- Existing deep learning frameworks and general-purpose differentiable programming systems are inefficient for physical simulations, leading to poor performance for irregular memory access and complex control flow.
- Manually writing and differentiating complex physical simulators in low-level languages is time-consuming, error-prone, and requires specialized expertise.
- Current differentiable programming tools lack native support for imperative parallel programming, 'megakernels,' and flexible indexing crucial for physics simulations.

## Method

- A ==two-scale automatic differentiation== system is implemented, using ==source code transformation== for local kernel differentiation and a ==light-weight tape== for global program backpropagation.
- The system builds on the ==Taichi== programming language, leveraging its compiler optimizations and support for ==imperative parallel programming== with flexible data structures.
- Discontinuities in simulations are addressed by integrating ==Time-of-Impact (TOI)== collision detection directly into the forward simulator for more accurate gradient computation.

## Results

- DiffTaichi achieved near hand-tuned CUDA performance and was up to **188x** faster than TensorFlow for complex physics simulations, while requiring **4.2x** fewer lines of code compared to CUDA.
- The system successfully built and differentiated **10** diverse physical simulators, including continuum mechanics, fluid dynamics, and rigid body dynamics, validating its broad applicability.
- Incorporating Time-of-Impact collision resolution yielded higher quality gradients for discontinuous systems, resulting in significantly faster and more stable convergence for optimization tasks like robot controller learning.

## Takeaways

> [!tip] Key Insights
> - Achieving high performance in differentiable physical simulations requires a hybrid AD approach that supports both fine-grained kernel differentiation and coarse-grained program-level differentiation while preserving "megakernel" structures.
> - Preprocessing imperative code within kernels, such as flattening branching and converting to SSA form, simplifies the application of reverse-mode automatic differentiation.
> - For physically accurate and useful gradients in systems with discontinuities, directly resolving events like collisions via methods such as Time-of-Impact is crucial, rather than relying solely on time-step-based approximations.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

DiffTaichi emerges at the nexus of several rapidly evolving fields: differentiable programming, high-performance computing (HPC), physical simulation, and machine learning.

**Differentiable Programming (DP)** has become a cornerstone of modern machine learning, particularly with the rise of deep neural networks. Frameworks like TensorFlow (Abadi et al., 2016) and PyTorch (Paszke et al., 2017) provide automatic differentiation (AD) capabilities for tensors, enabling efficient gradient computations for model training. More recently, there's been a push towards more general-purpose differentiable programming languages, such as Autograd (Maclaurin et al., 2015), JAX (Bradbury et al., 2018), Julia's Zygote (Innes et al., 2019), and Swift AD (Wei et al., 2019), aiming to extend AD beyond neural networks to broader scientific computing.

**Differentiable Physical Simulators** represent a critical sub-area within DP. The ability to differentiate through physical processes allows for gradient-based optimization in various applications, including:
- **Robotics:** Optimizing robot controllers, motion planning, and soft robot design (e.g., de Avila Belbute-Peres et al., 2018a; Hu et al., 2019b).
- **Inverse Problems:** Inferring material properties, initial conditions, or forces from observed behavior (e.g., Liang et al., 2019 for cloth simulation).
- **Graphics and Vision:** Learning 3D models from images, inverse rendering (e.g., Li et al., 2018a; Nimier-David et al., 2019).
- **Scientific Discovery:** Exploring parameter spaces in complex physical systems.

While the *need* for differentiable physical simulators is clear, their *implementation* has historically been challenging. Existing deep learning frameworks, designed for dense matrix operations prevalent in neural networks, often struggle with the irregular memory access patterns, complex control flow (e.g., collisions, boundary conditions), and diverse data structures found in physics simulations. Implementing these in TensorFlow or PyTorch can lead to:
- **Poor Performance:** Excessive kernel launches, temporary buffer allocations, and inefficient use of hardware (as highlighted by Hu et al., 2019b, showing TensorFlow to be orders of magnitude slower than custom CUDA).
- **Low Productivity:** Verbose code due to the need to express non-element-wise operations (like stencils or particle-grid interactions) using scatter/gather primitives, leading to cumbersome and error-prone implementations.
- **Limited Customization:** Inability to easily fuse multiple computational stages into "megakernels" that are crucial for achieving high arithmetic intensity on GPUs.

DiffTaichi directly addresses these limitations. It positions itself as a specialized differentiable programming language, building on the Taichi language's strengths in high-performance computation for spatially sparse data structures, to offer a solution tailored for complex, imperative physical simulations. Unlike other DP systems that are either general-purpose (and thus potentially inefficient for physics) or functional array-based (making imperative physics code difficult to port), DiffTaichi aims to provide both the performance of hand-optimized code and the productivity of automatic differentiation specifically for the physics domain. This work is thus a significant step towards democratizing the development of high-performance differentiable simulators, a bottleneck identified by several prior works.

### 2. Key Objectives and Motivation

The primary objective of DiffTaichi is to provide a new differentiable programming language that enables researchers to **build high-performance differentiable physical simulators with high productivity.** This overarching goal is driven by several key motivations stemming from the shortcomings of existing tools when applied to complex physical simulations:

1. **Overcome Performance Limitations of Existing Differentiable Programming Tools:** Current deep learning frameworks (e.g., TensorFlow, PyTorch) and general-purpose differentiable array programming languages (e.g., JAX, Autograd) are not optimized for the specific computational patterns of physical simulations. They often lead to:
 - **Low Arithmetic Intensity:** Decomposing complex simulation steps into sequences of basic tensor operations results in numerous, small kernel launches and excessive data transfer between CPU/GPU memory, preventing full utilization of hardware.
 - **Inefficient Memory Management:** Proliferation of temporary buffers for intermediate results.
 The authors aim to achieve performance comparable to hand-engineered CUDA implementations while retaining the benefits of automatic differentiation.

2. **Enhance Productivity for Simulator Development:** Writing both forward and adjoint (gradient) versions of complex physical simulators manually (e.g., in CUDA) is a highly time-consuming, error-prone, and specialized task. DiffTaichi seeks to automate this differentiation process, drastically reducing the lines of code required and the development burden on researchers.

3. **Address Unique Requirements of Physical Simulations:** The paper highlights three specific features crucial for physical simulators that are often poorly supported by existing differentiable programming systems:
 - **Megakernels:** The ability to fuse multiple computation stages into a single kernel. This is vital for achieving high arithmetic intensity and exploiting data locality, which is often lost when composing fine-grained operations in frameworks like TensorFlow.
 - **Imperative Parallel Programming:** Most traditional physical simulators are written in imperative languages (C++, Fortran) and rely on constructs like parallel loops and control flows (e.g., `if` statements for collisions, boundary conditions). DiffTaichi aims to support this imperative style and parallel constructs naturally, making it easier to port existing simulation algorithms.
 - **Flexible Indexing:** Physics simulations frequently involve complex, non-element-wise memory access patterns (e.g., numerical stencils, particle-grid interactions, scatter/gather operations, partial array updates). Existing systems often provide only element-wise operations on arrays of the same shape, making these patterns difficult to express efficiently and intuitively.

4. **Facilitate Gradient-Based Learning and Optimization:** By providing efficient and accurate gradients, DiffTaichi intends to enable faster and more effective optimization of parameters (e.g., neural network controllers, initial conditions, material properties) within machine learning systems that interact with physical environments. This includes tasks in robotics, inverse design, and scientific discovery, where differentiable simulators have shown significant advantages over model-free approaches.

In essence, the motivation is to create a specialized tool that combines the high-performance capabilities of low-level languages with the productivity of automatic differentiation, precisely tailored for the unique demands of physical simulation.

### 3. Methodology and Approach

DiffTaichi's core methodology is a **two-scale automatic differentiation (AD) system** built upon the existing **Taichi programming language**. This design specifically targets the challenges of high-performance imperative physical simulations.

#### 3.1. Foundation: The Taichi Programming Language

DiffTaichi is an extension of the Taichi programming language (Hu et al., 2019a). Taichi is an imperative, compiled, statically-typed, and parallel language embedded in Python (with a C++14 backend). Key features of Taichi that DiffTaichi leverages include:
- **Decoupling Computation from Data Structures:** Allows flexible data layouts while accessing elements with intuitive indexing (e.g., `x[i, j, k]`).
- **Compiler Optimizations:** The Taichi compiler uses both data structure and algorithm information to apply performance optimizations.
- **First-class Parallel-for Loops:** Simplifies writing parallel code for modern hardware (CPUs/GPUs).
The DiffTaichi language frontend is Python-embedded, using a Python AST transformer to compile code into Taichi Intermediate Representation (IR), which is then further compiled and differentiated.

#### 3.2. Two-Scale Automatic Differentiation System

To achieve both performance (by preserving megakernels) and flexibility (for end-to-end backpropagation), DiffTaichi employs a hybrid AD approach:

- **Local AD: Source Code Transformation (SCT) within Kernels:**
 - **Goal:** Differentiate individual Taichi kernels, which represent the "megakernels" of computation. SCT is chosen for its ability to preserve arithmetic intensity and parallelism within a kernel.
 - **Preprocessing Steps (IR Simplification):** Before applying reverse-mode AD, kernels undergo two transformations:
 1. **Flatten Branching:** `if` statements (common in physics for collisions, boundary conditions) are converted into ternary `select` operators (e.g., `value = select(condition, value_if_true, value_if_false)`). This simplifies the control flow for AD.
 2. **Eliminate Mutable Local Variables:** Local variables are transformed into Single Static Assignment (SSA) form through store forwarding, ensuring each variable is assigned only once. This makes the code effectively "straight-line" within a loop body, simplifying the reverse-mode AD process.
 - **Reverse-Mode AD:** After preprocessing, a standard reverse-mode AD source code transformation is applied to the simplified IR. For each instruction, local adjoint variables are allocated, and gradients are accumulated by traversing the statements in reverse order.
 - **Parallelism and Thread Safety:** Parallel loop structures are preserved during AD. Atomic operations (e.g., `+=`) for thread-safe accumulation in forward kernels are automatically differentiated, contributing to adjoint tensors via atomic adds in backward kernels.

- **Global AD: Light-Weight Tape for End-to-End Backpropagation:**
 - **Goal:** Differentiate the entire simulation program, which consists of multiple kernel launches. Tracing is used here for flexibility.
 - **Light-Weight Tape:** Unlike deep learning frameworks that often record entire intermediate tensors, DiffTaichi's tape is "light-weight." It only records kernel function pointers and their (scalar) input parameters during the forward pass. The actual intermediate results (simulation states) are stored in global tensors, which serve as natural checkpoints.
 - **Replay:** During backpropagation, the tape is traversed in reverse order, and the corresponding gradient kernels (generated by local AD) are invoked with the recorded parameters, accumulating gradients to the adjoint global tensors.

#### 3.3. Global Data Access Rules and Adjoint Storage

To ensure automatic differentiation is well-defined in an imperative setting, DiffTaichi enforces two "Global Data Access Rules" for global tensors within kernels:
1. Subsequent writes to a global tensor element must be atomic adds (accumulations).
2. No reads to a global tensor element until its accumulation is complete.
Users can specify the storage of adjoint tensors using Taichi's data structure description language or opt for automatic placement (`ti.root.lazy_grad()`).

#### 3.4. Complex Kernels for Customization and Checkpointing

DiffTaichi provides mechanisms (`ti.complex_kernel`, `ti.complex_kernel_grad`) to allow users to **override the default automatic differentiation** for specific kernels. This is useful in cases where:
- Manual gradient implementations are more numerically stable (e.g., SVD derivatives for iterative solvers).
- Specific optimization techniques like **checkpointing** are desired. Checkpointing is demonstrated to reduce memory consumption from O(N) to O(sqrt(N)) for N time steps by recomputing intermediate states during backward passes, using complex kernels to define custom forward/backward logic.

#### 3.5. Improving Gradients for Discontinuities: Time-of-Impact (TOI)

A crucial methodological insight is the recognition that naive time integrators in simulations with discontinuities (like rigid body collisions) can yield misleading gradients, even if the forward simulation appears accurate. DiffTaichi proposes incorporating **continuous collision resolution using Time-of-Impact (TOI)** into the forward simulator. This ensures that collisions are detected precisely in time, rather than only at discrete time steps, which significantly improves the quality and correctness of the computed gradients, leading to better optimization convergence.

### 4. Main Findings and Results

DiffTaichi's effectiveness is demonstrated through a comprehensive evaluation across 10 diverse physical simulators, highlighting its superior performance, productivity, and the quality of gradients generated.

#### 4.1. Performance and Productivity (Elastic Object Simulator - `diffmpm`)

- **Productivity:** The DiffTaichi implementation of a differentiable elastic object simulator (using MLS-MPM) is remarkably concise. It is **4.2× shorter** in terms of lines of code (LoC) compared to a hand-engineered CUDA version and **1.7× shorter** than a TensorFlow implementation. This underscores the significant boost in development efficiency.
- **Performance:**
 - **Near CUDA Speed:** DiffTaichi achieves performance almost on par with hand-tuned CUDA. For a 2D simulation with 6.4K particles, DiffTaichi's total forward+backward time is 0.26 ms, very close to CUDA's 0.24 ms.
 - **Massive Speedup over TensorFlow:** DiffTaichi is **188× faster** than the TensorFlow implementation (0.26 ms vs. 48.90 ms). The authors attribute TensorFlow's poor performance to verbose code and inefficient GPU kernel launches arising from its functional array programming paradigm.

#### 4.2. Performance Comparison (Incompressible Fluid Simulator - `smoke`)

- DiffTaichi demonstrates strong performance against other differentiable array programming systems for an incompressible fluid simulator on a 110x110 grid with 100 time steps and 6 Jacobi iterations per step.
 - **GPU Performance:** DiffTaichi (GPU) achieves a total time of 53 ms, making it:
 - **13.4× faster** than PyTorch (GPU, 711 ms).
 - **28.4× faster** than Autograd (CPU, 1504 ms, using f64).
 - **1.9× faster** than JAX (GPU, 99 ms).
 - **CPU Performance:** DiffTaichi (CPU) also performs well, at 198 ms, still outperforming PyTorch and Autograd on CPU.
- The comparison highlights DiffTaichi's ability to maintain high performance even for moderately complex grid-based simulations, largely due to its megakernel approach.

#### 4.3. Versatility and Application Across Diverse Simulators

DiffTaichi was successfully used to build and differentiate 10 distinct physical simulators, demonstrating its broad applicability:
- Continuum mechanics (elastic objects, liquids)
- Fluid dynamics (incompressible fluid, shallow water)
- Rigid body dynamics (mass-spring systems, billiards, general rigid bodies with collisions)
- Differentiable rendering (water surface, volume rendering)
- Electric field simulation
This breadth of examples validates the language's design for handling various simulation paradigms and complexities.

#### 4.4. Improved Gradient Quality with Time-of-Impact (TOI)

- For simulations involving discontinuities, particularly rigid body collisions, the authors identify a critical issue: naive time integrators can produce misleading gradients, even if the forward simulation is visually plausible. This is because time discretization itself is not differentiated.
- Their proposed solution, incorporating **Time-of-Impact (TOI) collision detection**, significantly improves gradient quality. While TOI barely affects the forward simulation's visual outcome, it leads to vastly better convergence and optimization results in tasks like robot controller optimization (e.g., in mass-spring and rigid-body robot examples, TOI consistently leads to lower loss values and faster convergence, as shown in Fig. 5). This finding is a significant practical contribution to differentiable physics.

#### 4.5. Effective Gradient-Based Optimization

- Through the evaluated examples, DiffTaichi enables efficient gradient-based optimization. Neural network controllers for soft robots and rigid body robots, as well as physical parameters (e.g., spring rest lengths, initial velocity fields for fluids), are typically optimized within only tens of iterations.
- Examples include training a soft robot to move forward, optimizing initial velocity to make smoke form a "Taichi" symbol, and making a rigid robot learn to walk. The differentiable renderer examples also show inverse problem-solving, like reconstructing 3D density fields from 2D projections.

In summary, the results overwhelmingly support DiffTaichi's claim of providing both high performance and high productivity for differentiable physical simulation, outperforming general-purpose deep learning frameworks by orders of magnitude in critical tasks, and offering crucial insights into practical gradient computation for discontinuous systems.

### 5. Significance and Potential Impact

DiffTaichi represents a significant advancement in the field of differentiable programming, particularly at the intersection of scientific computing, machine learning, and computer graphics. Its potential impact is multi-faceted:

1. **Lowering the Barrier for Differentiable Physics:** Perhaps the most immediate impact is the democratization of high-performance differentiable physical simulation. Previously, achieving both high performance and differentiability often required specialized expertise in both physics simulation and low-level GPU programming (e.g., CUDA) to hand-engineer forward and adjoint kernels. DiffTaichi drastically reduces this burden by automating the differentiation process while maintaining efficiency. This will enable a wider range of researchers (e.g., in robotics, ML, materials science) to leverage gradient-based optimization in complex physical systems without becoming compiler or CUDA experts.

2. **Enabling New Research in Robotics and Control:** The ability to efficiently differentiate through complex robotic simulations (rigid body, soft body, fluid-coupled) will accelerate research in controller optimization, inverse kinematics/dynamics, and learning-based control strategies. This can lead to more robust, adaptive, and efficiently learned robot behaviors. The example of optimizing neural network controllers within tens of iterations is a strong indicator of this potential.

3. **Advancing Inverse Problems and Scientific Discovery:** Differentiable simulators are powerful tools for inverse problems – inferring causes from observed effects. DiffTaichi's efficiency and flexibility will facilitate research in areas like material parameter estimation, optimal design of physical systems, and reconstructing hidden properties from sensory data (e.g., inferring 3D shapes from 2D images, as shown in the differentiable renderer examples). This has implications for scientific discovery, engineering design, and computer vision.

4. **Bridging the Gap Between HPC and Machine Learning:** DiffTaichi effectively bridges the gap between the high-performance computing community (with its focus on optimal hardware utilization, memory locality, and custom kernel design) and the machine learning community (with its emphasis on automatic differentiation and gradient-based optimization). By building on the Taichi language, which is already designed for sparse data structures and parallel computation, DiffTaichi brings the benefits of imperative, high-performance programming to the differentiable world.

5. **Methodological Contributions to Differentiable Programming:** The paper offers valuable methodological insights, especially regarding the handling of complex, imperative code and discontinuous physical phenomena:
 - The **two-scale AD system** (SCT for kernels, light-weight tape for global simulation) is an elegant solution to balance performance and flexibility, addressing a known limitation of purely functional or purely tracing-based AD systems for physics.
 - The **Global Data Access Rules** for imperative AD provide practical guidelines for writing differentiable code in this paradigm.
 - The emphasis on and solution for **correctly differentiating through discontinuities** (e.g., using Time-of-Impact for collisions) is a critical contribution. This highlights that simply differentiating a functional forward simulation is not always sufficient for useful gradients, and careful consideration of the underlying physics and numerical methods is crucial. This insight has broader implications for AD in scientific computing.

6. **Fostering an Open-Source Ecosystem:** By open-sourcing the language, compiler, and all simulator code, the authors encourage community adoption, contributions, and further research. This fosters an ecosystem where complex differentiable simulators can be easily shared, built upon, and integrated into larger ML pipelines.

In conclusion, DiffTaichi is more than just another differentiable programming tool; it is a purpose-built language and system addressing a critical bottleneck in the application of machine learning to physical systems. Its impact will be felt across numerous domains by enabling faster, more efficient, and more robust development of differentiable physical simulators.
