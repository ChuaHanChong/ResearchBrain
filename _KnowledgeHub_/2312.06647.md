# 4M: Massively Multimodal Masked Modeling

> [!summary] Summary
> The 4M framework from EPFL and Apple presents a unified transformer-based architecture for massively multimodal masked modeling. It enables a single model to process diverse inputs and generate various outputs across vision tasks by converting all modalities into a common discrete token representation, demonstrating competitive performance on tasks like detection, segmentation, and depth estimation.

## Problem

- Computer vision lacks a versatile foundation model comparable to large language models (LLMs) that can handle diverse tasks through a unified architecture.
- Traditional computer vision models are typically specialized for specific tasks with fixed input-output structures, limiting their versatility.
- The scarcity of fully aligned multimodal datasets presents a challenge for training general-purpose vision models.

## Method

- Proposes **4M**, a unified transformer encoder-decoder architecture that processes all modalities through the same model with shared parameters.
- Employs a novel ==tokenization== approach using modality-specific tokenizers (e.g., VQGAN for images, subword for text) to map all diverse data into a common discrete token space.
- Trains the model using a ==multimodal masked modeling== objective, predicting masked tokens from varied input and output modalities, and leverages ==pseudo-labeling== to scale data for training.

## Results

- 4M achieves competitive performance on downstream tasks such as object detection, segmentation, and depth estimation when fine-tuned, outperforming baselines.
- The model demonstrates zero-shot capabilities for certain tasks, indicating the acquisition of generalizable representations.
- It enables high-quality multimodal generation, allowing for fine-grained control of the generation process by conditioning on multiple modalities simultaneously (e.g., generating images from text and depth maps).

## Takeaways

> [!tip] Key Insights
> - Unifying diverse modalities into a single, shared token representation enables a single transformer model to learn cross-modal relationships and perform various vision tasks.
> - Multimodal masked modeling allows for efficient training by predicting masked token subsets from various input and output modalities.
> - Pseudo-labeling effectively expands training data for multimodal tasks by generating missing modalities for partially labeled datasets.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

While large language models (LLMs) have demonstrated remarkable versatility in natural language processing, computer vision has not yet achieved a comparable foundation model capable of handling diverse tasks through a unified architecture. The paper "4M: Massively Multimodal Masked Modeling" addresses this gap by presenting a training framework that enables a single model to process multiple input and output modalities for various vision tasks.

### 2. Key Objectives and Motivation

The authors, researchers from EPFL and Apple, propose that multimodality—the ability to process different types of data such as images, text, and geometric information—is key to developing more versatile vision models. Their approach, 4M, trains a transformer-based architecture on diverse modalities using a masked modeling objective, where the model learns to predict masked portions of inputs.

### 3. Methodology and Approach

#### 3.1. The 4M Framework

The 4M framework consists of a unified transformer encoder-decoder architecture that processes all modalities through the same model. Unlike specialized models designed for specific tasks, 4M aims to achieve versatility through:

1. A single, shared architecture for all modalities
2. A unified training objective (masked modeling)
3. A common representation space via tokenization

This approach contrasts with traditional computer vision models that typically specialize in one task with a fixed input-output structure. Instead, 4M can handle tasks ranging from image captioning to depth estimation and object detection using the same model parameters.

The architecture follows a transformer encoder-decoder design, where:
- The encoder processes tokens from input modalities
- The decoder predicts tokens for target modalities
- Cross-attention mechanisms connect the encoder and decoder

#### 3.2. Unified Representation through Tokenization

A key innovation in 4M is the tokenization approach that maps all modalities into a unified representation space. This is achieved by using modality-specific tokenizers:

1. **Visual tokenization**: Images are processed using VQGAN or other discrete VAE approaches to convert pixel data into discrete tokens
2. **Text tokenization**: Standard subword tokenization similar to BERT or GPT
3. **Geometric data tokenization**: Depth maps, surface normals, and other geometric data are quantized into discrete tokens
4. **Semantic tokenization**: Class labels and segmentation masks are encoded as discrete tokens

By representing all modalities as sequences of discrete tokens, the transformer can process them using the same mechanisms, enabling true multimodal learning within a single architecture.

The tokenization process can be represented mathematically as:

$$X_m \rightarrow E_m(X_m) \rightarrow Q_m(E_m(X_m)) = Z_m$$

Where $X_m$ is the input from modality $m$, $E_m$ is the modality-specific encoder, $Q_m$ is a quantization function, and $Z_m$ is the resulting sequence of discrete tokens.

#### 3.3. Training Approach

The 4M training strategy employs several innovative techniques:

#### 3.4. Multimodal Masked Modeling

The primary training objective is to predict masked tokens from a variety of input and output modalities. During training:

1. A subset of tokens from all modalities is randomly selected as inputs
2. Another subset is selected as prediction targets
3. The model learns to reconstruct the target tokens based on the input tokens

This approach is efficient because it doesn't require processing all tokens from all modalities at once, which would be computationally expensive. Instead, by selecting sparse inputs and targets, the model can learn from multimodal data while maintaining reasonable computational requirements.

#### 3.5. Pseudo-Labeling for Data Scaling

To address the scarcity of fully aligned multimodal data, 4M employs pseudo-labeling techniques:

```python
# Simplified pseudo-code for pseudo-labeling
def generate_pseudo_labels(image, existing_labels):
    # Generate missing modalities using specialized models
    if "depth" not in existing_labels:
        depth_map = depth_estimation_model(image)
        existing_labels["depth"] = depth_map

    if "normal" not in existing_labels:
        surface_normals = normal_estimation_model(image)
        existing_labels["normal"] = surface_normals

    return existing_labels
```

This approach allows the model to train on much larger datasets by leveraging existing single-modal or partially-labeled data, enhancing the model's ability to generalize across modalities.

#### 3.6. Decoding Schemes

The paper explores multiple decoding strategies:
- MaskGIT: Non-autoregressive parallel decoding
- Random order autoregressive: Predicting tokens in random order
- Left-to-right autoregressive: Sequential token prediction

These different decoding schemes allow the model to balance generation quality and inference speed depending on the requirements of the task.

#### 3.7. Multimodal Capabilities

A distinct advantage of 4M is its ability to condition generation on multiple modalities simultaneously. For example, the model can:

1. Generate an image conditioned on both text description and depth map
2. Predict depth and surface normals from an RGB image
3. Complete missing parts of an image while respecting geometric constraints

This multimodal conditioning provides a level of control over generation that is difficult to achieve with unimodal models. The flexibility to mix and match input and output modalities enables a wide range of applications that would otherwise require multiple specialized models.

### 4. Main Findings and Results

#### 4.1. Experimental Results

The paper demonstrates that 4M achieves competitive performance across various vision tasks:

1. **Transfer Learning**: 4M transfers exceptionally well to downstream tasks, outperforming baselines on detection, segmentation, and depth estimation when fine-tuned.

2. **Zero-shot Capabilities**: The model demonstrates the ability to perform some tasks without any task-specific fine-tuning, suggesting it has learned generalizable representations.

3. **Multimodal Generation**: 4M can generate high-quality images conditioned on multiple modalities, allowing for fine-grained control of the generation process.

4. **Scaling Properties**: Performance improves with:
 - Larger datasets
 - Longer training
 - Increased model size

The authors found that models trained with the 4M approach develop representations that capture both semantic and geometric properties of scenes. This enables the model to predict physically plausible arrangements while considering the semantic context.

### 5. Significance and Potential Impact

#### 5.1. Applications and Use Cases

The versatility of 4M enables numerous applications:

1. **Content Creation**: Artists and designers can use multimodal controls to precisely specify the desired output (e.g., "a mountainous landscape with specific depth characteristics").

2. **Computer Vision Systems**: A single model can perform multiple vision tasks, simplifying system design and reducing computational resources.

3. **Multimodal Editing**: Users can edit images by specifying modifications through different modalities (e.g., changing the style via text while preserving geometric structures).

4. **Cross-Modal Translation**: Converting between modalities becomes straightforward (e.g., generating captions from images or vice versa).

The ability to handle multiple modalities with a single model reduces the need for specialized models and simplifies the development of complex vision-based systems.

#### 5.2. Limitations and Future Work

Despite its achievements, 4M has several limitations that present opportunities for future research:

1. **Computational Efficiency**: Training multimodal models requires significant computational resources, which could be addressed through more efficient training techniques.

2. **Data Requirements**: While pseudo-labeling helps, the quality of multimodal learning still depends on the availability of diverse, high-quality data.

3. **Model Size**: Like other foundation models, the performance of 4M scales with model size, raising concerns about accessibility and deployment.

4. **Fine-grained Control**: While the model enables multimodal conditioning, achieving precise control over all aspects of generation remains challenging.

Future work could explore ways to reduce the computational requirements, improve the efficiency of multimodal learning, and enhance the model's ability to follow complex, multi-constraint instructions.

#### 5.3. Conclusion

The 4M framework represents a significant step toward versatile foundation models for computer vision. By unifying multiple modalities through tokenization and masked modeling, it achieves a level of flexibility previously unseen in vision models, enabling a single architecture to handle diverse tasks.

The ability to process and generate multiple modalities opens new possibilities for applications that require multimodal understanding and generation. As research in this area continues, we can expect even more capable models that further bridge the gap between specialized vision systems and the versatile foundation models seen in natural language processing.

The integration of semantic, geometric, and visual understanding within a single model suggests a path toward more comprehensive AI systems that, like humans, can seamlessly interpret and generate different types of information.
