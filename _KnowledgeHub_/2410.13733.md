# Improving Multi-modal Large Language Model through Boosting Vision Capabilities

> [!summary] Summary
> Arcana improves the visual perception of Multi-Modal Large Language Models by introducing the Query Ladder Adapter for enhanced visual feature extraction and Multimodal LoRA for modality-specific learning in the decoder. This approach achieves competitive performance on general VQA and LVLM benchmarks, outperforming many existing MLLMs on OKVQA, ScienceQA, and AI2D, all while maintaining computational efficiency.

## Problem

- Current Multi-Modal Large Language Models (MLLMs) exhibit limitations in low-level visual perception (e.g., color recognition, counting) and high-level visual understanding (e.g., small object detection, accurate localization).
- Existing MLLMs often use CLIP as a visual encoder, which is not optimized for detailed visual understanding, leading to insufficient visual feature representation.
- Language-driven decoders in MLLMs suffer from modality interference, where language processing can dominate and hinder effective visual information processing.

## Method

- ==Arcana== introduces the ==Query Ladder Adapter (QLadder)==, a lightweight module that enhances visual feature extraction from a frozen CLIP encoder using learnable query tokens and progressive refinement.
- It integrates ==Multimodal LoRA (MM-LoRA)== into the language model decoder, utilizing distinct parameter sets for visual and textual information to mitigate modality interference.
- The model is trained in a two-stage process, beginning with pre-training for vision-language alignment, followed by multimodal instruction fine-tuning on diverse datasets.

## Results

- Arcana achieves competitive performance across **6** general VQA benchmarks, notably outperforming most existing MLLMs on OKVQA, ScienceQA, and AI2D.
- The model demonstrates robust reasoning and generalization capabilities on **5** LVLM benchmarks, including MMBench and SEED-Bench, while maintaining competitive performance on pure language understanding tasks.
- Ablation studies confirm that MM-LoRA significantly outperforms traditional LoRA by separating visual and language learning spaces, and QLadder effectively enhances visual representation.

## Takeaways

> [!tip] Key Insights
> - Enhancing visual perception in MLLMs can be achieved efficiently through lightweight architectural innovations without requiring extensive computational resources.
> - Separating learning spaces for different modalities within the decoder, as demonstrated by MM-LoRA, effectively reduces interference and improves multimodal understanding.
> - Augmenting existing visual encoders with adaptable modules, like the Query Ladder Adapter, is an effective strategy for learning complementary and detailed visual representations.

## Detailed Report

### 1. Introduction

Multi-Modal Large Language Models (MLLMs) have made significant advances in understanding and generating content that combines text and images. However, current models often struggle with fundamental visual perception tasks, from basic color recognition to complex object localization. This paper introduces Arcana, an innovative approach to enhancing the visual understanding capabilities of MLLMs without incurring significant computational overhead.

Arcana tackles two critical limitations in existing MLLMs: inadequate visual feature representation and modality interference in the decoding process. The paper introduces two key innovations: the Query Ladder Adapter (QLadder) for enhancing visual feature extraction, and Multimodal LoRA (MM-LoRA) for creating separate learning spaces for visual and textual information in the decoder.

### 2. Background and Motivation

MLLMs integrate visual and language modeling capabilities to enable understanding and reasoning across different modalities. Models like LLaVA, CogVLM, and mPLUG-Owl2 have shown impressive performance on various multimodal tasks. However, most existing MLLMs suffer from insufficient visual perception abilities, particularly in:

1. **Low-level perception tasks**: Recognizing colors, counting objects, and identifying shapes
2. **High-level visual understanding**: Detecting small objects, accurately localizing items, and spatial reasoning

These limitations stem from two primary sources:

1. **Visual encoder constraints**: Most MLLMs use CLIP as their visual encoder, which was optimized for image-text matching rather than detailed visual understanding.
2. **Language-driven decoder bias**: Current MLLMs typically adapt LLMs for multimodal tasks, which can lead to modality interference where language processing dominates visual processing.

The authors identify that improving visual perception is crucial for advancing MLLMs toward more comprehensive multimodal understanding.

### 3. Architecture Overview

Arcana consists of three main components:

1. **Enhanced Visual Encoder**: Combines a frozen pre-trained CLIP image encoder with the novel Query Ladder Adapter (QLadder)
2. **Vision-Language Adapter**: A simple two-layer MLP that maps visual features to the language embedding space
3. **Multimodal Decoder**: A pre-trained Vicuna-7B language model enhanced with Multimodal LoRA (MM-LoRA)

The architecture is designed to be parameter-efficient while significantly improving visual understanding. Unlike approaches that incorporate additional high-resolution encoders or completely fine-tune the visual backbone, Arcana introduces a lightweight adaptation mechanism that preserves the original capabilities of CLIP while enhancing its visual representation power.

### 4. Query Ladder Adapter (QLadder)

The QLadder is a novel module designed to augment the visual features extracted by the frozen CLIP encoder without significantly increasing computational overhead. Its key features include:

1. **Learnable query tokens**: A small set of trainable tokens (typically 64 tokens) that capture complementary visual information
2. **Progressive refinement**: Multiple layers of cross-attention and feed-forward networks (FFNs) that iteratively refine the query tokens by interacting with CLIP features
3. **Feature augmentation**: The final visual representation combines the original CLIP features with the enhanced features from QLadder

The QLadder creates a "ladder" structure where each layer progressively refines the query tokens by attending to the frozen CLIP features. This design allows Arcana to learn new visual representations that complement the existing CLIP features without the need to fine-tune the entire visual encoder.

The mathematical formulation of the QLadder process can be described as:

1. Initialize a set of learnable query tokens Xq
2. For each layer in the QLadder:
 - Apply cross-attention between query tokens and CLIP features
 - Update query tokens through a feed-forward network
3. Concatenate the final query tokens with the original CLIP features for the complete visual representation

This approach effectively increases the model's capacity to capture detailed visual information while maintaining computational efficiency.

### 5. Multimodal LoRA (MM-LoRA)

Traditional MLLMs often suffer from modality interference, where the language processing capabilities can dominate and hinder visual understanding. To address this, Arcana introduces MM-LoRA, a novel adaptation of the Low-Rank Adaptation (LoRA) technique.

Key features of MM-LoRA include:

1. **Separate learning spaces**: MM-LoRA maintains distinct parameter sets for visual and language modalities
2. **Dual LoRA structure**: Two parallel LoRA modules (Vision LoRA and Language LoRA) with separate down-projection and up-projection matrices
3. **Modality-specific processing**: Each modality is processed through its dedicated parameters, preventing interference

The MM-LoRA approach can be formalized as:

For a pre-trained weight matrix W₀, traditional LoRA computes:
W = W₀ + ΔW = W₀ + BA

Where B and A are low-rank matrices.

In contrast, MM-LoRA computes:
W = W₀ + ΔW^v + ΔW^l = W₀ + B^v A^v + B^l A^l

Where B^v, A^v are vision-specific parameters and B^l, A^l are language-specific parameters.

This design allows the model to maintain the integrity of each modality's processing while still enabling their integration for multimodal understanding.

### 6. Training Paradigm

Arcana employs a two-stage training process:

1. **Pre-training Stage**:
 - Focuses on aligning the visual encoder with the language model
 - Only the QLadder and vision-language adapter are trained
 - The CLIP encoder and Vicuna LLM remain frozen
 - Uses image-text pairs from CC3M dataset

2. **Multimodal Instruction Fine-tuning Stage**:
 - Adapts the model to specific multimodal tasks
 - Trains the QLadder, vision-language adapter, and MM-LoRA
 - Uses a diverse set of instruction-following data
 - Incorporates various multimodal datasets covering VQA, captioning, and reasoning

This staged approach allows the model to first establish a strong foundation of vision-language alignment before being refined for specific multimodal tasks and instruction following.

### 7. Experimental Results

Arcana demonstrates impressive performance across a wide range of benchmarks:

1. **General VQA Benchmarks**: Achieves competitive results on six general VQA benchmarks, outperforming most existing MLLMs on OKVQA, ScienceQA, and AI2D.

2. **LVLM Benchmarks**: Shows strong performance on five LVLM benchmarks (MMBench, MM-Vet, SEED-Bench, LLaVA-W, and POPE), demonstrating robust reasoning and generalization capabilities.

3. **Language Understanding**: Maintains competitive performance on pure language understanding benchmarks (BBH, AGIEval, and ARC), showing that the visual enhancements do not compromise language abilities.

Ablation studies reveal:

- **Effectiveness of MM-LoRA**: Significantly outperforms traditional LoRA by separating visual and language learning spaces
- **Optimal QLadder Configuration**: Performance peaks with 64 query tokens, offering the best balance of enhanced representation and computational efficiency
- **Computational Efficiency**: Achieves performance comparable to methods using dual visual encoders (like DINOv2 + CLIP) but with lower computational requirements

### 8. Discussion and Implications

The success of Arcana has several important implications for the development of MLLMs:

1. **Balance of Efficiency and Performance**: Arcana demonstrates that significant improvements in visual perception can be achieved without massive computational resources, making advanced MLLMs more accessible.

2. **Importance of Modality Separation**: The effectiveness of MM-LoRA highlights the value of maintaining separate learning spaces for different modalities, suggesting a promising direction for future multimodal models.

3. **Complementary Feature Learning**: Rather than replacing existing visual encoders, complementing them with adaptable modules like QLadder offers an efficient path to enhanced visual perception.

4. **Architectural Innovation over Scale**: Arcana shows that thoughtful architectural innovations can sometimes be more effective than simply scaling up model size or computational resources.

The authors acknowledge that while Arcana significantly improves visual perception in MLLMs, challenges remain in areas requiring complex spatial reasoning and long-range visual dependencies. These areas represent promising directions for future research.

### 9. Conclusion

Arcana represents a significant advancement in enhancing the visual perception capabilities of Multi-Modal Large Language Models. By introducing the Query Ladder Adapter and Multimodal LoRA, the authors demonstrate that it's possible to substantially improve visual understanding without extensive computational overhead.

The model's strong performance across various benchmarks validates the effectiveness of the proposed approaches and suggests promising directions for future MLLM development. By addressing the fundamental limitations in visual perception, Arcana takes an important step toward more capable and versatile multimodal AI systems.

The parameter-efficient design principles employed in Arcana also make advanced multimodal capabilities more accessible to researchers and developers with limited computational resources, potentially accelerating innovation in this rapidly evolving field.
