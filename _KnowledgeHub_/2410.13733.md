# Improving Multi-modal Large Language Model through Boosting Vision Capabilities

> [!summary] Summary
> Arcana improves the visual perception of Multi-Modal Large Language Models by introducing the Query Ladder Adapter for enhanced visual feature extraction and Multimodal LoRA for modality-specific learning in the decoder. This approach achieves competitive performance on general VQA and LVLM benchmarks, outperforming many existing MLLMs on OKVQA, ScienceQA, and AI2D, all while maintaining computational efficiency.

## Problem

- Current Multi-Modal Large Language Models (MLLMs) exhibit limitations in low-level visual perception (e.g., color recognition, counting) and high-level visual understanding (e.g., small object detection, accurate localization).
- Existing MLLMs often use CLIP as a visual encoder, which is not optimized for detailed visual understanding, leading to insufficient visual feature representation.
- Language-driven decoders in MLLMs suffer from modality interference, where language processing can dominate and hinder effective visual information processing.

## Method

- ==Arcana== introduces the ==Query Ladder Adapter (QLadder)==, a lightweight module that enhances visual feature extraction from a frozen CLIP encoder using learnable query tokens and progressive refinement.
- It integrates ==Multimodal LoRA (MM-LoRA)== into the language model decoder, utilizing distinct parameter sets for visual and textual information to mitigate modality interference.
- The model is trained in a two-stage process, beginning with pre-training for vision-language alignment, followed by multimodal instruction fine-tuning on diverse datasets.

## Results

- Arcana achieves competitive performance across **6** general VQA benchmarks, notably outperforming most existing MLLMs on OKVQA, ScienceQA, and AI2D.
- The model demonstrates robust reasoning and generalization capabilities on **5** LVLM benchmarks, including MMBench and SEED-Bench, while maintaining competitive performance on pure language understanding tasks.
- Ablation studies confirm that MM-LoRA significantly outperforms traditional LoRA by separating visual and language learning spaces, and QLadder effectively enhances visual representation.

## Takeaways

> [!tip] Key Insights
> - Enhancing visual perception in MLLMs can be achieved efficiently through lightweight architectural innovations without requiring extensive computational resources.
> - Separating learning spaces for different modalities within the decoder, as demonstrated by MM-LoRA, effectively reduces interference and improves multimodal understanding.
> - Augmenting existing visual encoders with adaptable modules, like the Query Ladder Adapter, is an effective strategy for learning complementary and detailed visual representations.
