# WebGen-Agent: Enhancing Interactive Website Generation with Multi-Level Feedback and Step-Level Reinforcement Learning

> [!summary] Summary
> Researchers at The Chinese University of Hong Kong's MMLab developed WebGen-Agent, an advanced system for generating interactive and visually appealing websites from natural language instructions using multi-level visual and functional feedback. This approach, enhanced by step-level reinforcement learning (Step-GRPO), significantly improves the accuracy and aesthetic quality of generated websites, especially when applied to smaller, open-source large language models.

## Problem

- Existing LLM-powered code agents rely on simple code execution feedback, which is insufficient for tasks like website generation that require visual aesthetics and interactive functionality.
- Traditional code agents often produce web applications with undetected visual defects (e.g., misaligned components) or functional problems (e.g., unresponsive buttons) that basic code checks miss.

## Method

- **WebGen-Agent** implements an iterative, ==multi-step workflow== combining code generation, execution, and comprehensive multi-level feedback.
- Multi-level feedback includes visual analysis from a VLM (for appearance scores and suggestions) and functional testing by a GUI-agent (for interactivity scores and suggestions).
- A novel Step-GRPO reinforcement learning strategy is introduced, using combined visual and functional scores as dense, step-level rewards to train the LLM, alongside backtracking and 'select-best' mechanisms for robustness.

## Results

- WebGen-Agent improved Claude-3.5-Sonnet's accuracy from **26.4%** to **51.9%** (a **25.5%** absolute gain) and its appearance score from 3.0 to 3.9 on the WebGen-Bench dataset.
- Step-GRPO training boosted Qwen2.5-Coder-**7B**-Instruct's accuracy from **38.9%** (SFT only) to **45.4%** and its appearance score from 3.4 to 3.7, demonstrating effectiveness for smaller models.
- Ablation studies confirmed GUI-agent testing feedback provided the largest accuracy gain (**3.3%**), while screenshot feedback significantly improved appearance scores (from 3.0 to 3.6).

## Takeaways

> [!tip] Key Insights
> - Integrating multi-level feedback (visual appearance and interactive functionality) is crucial for generating high-quality websites, addressing limitations of solely execution-based feedback.
> - Step-level reinforcement learning (Step-GRPO) effectively leverages these rich, multi-modal feedback signals to significantly improve the performance and reasoning capabilities of even smaller open-source LLMs.
> - Robustness mechanisms like backtracking and 'select-best' are essential for mitigating errors and ensuring the delivery of the highest quality output in iterative code generation processes.
