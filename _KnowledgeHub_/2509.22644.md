# WebGen-Agent: Enhancing Interactive Website Generation with Multi-Level Feedback and Step-Level Reinforcement Learning

> [!summary] Summary
> Researchers at The Chinese University of Hong Kong's MMLab developed WebGen-Agent, an advanced system for generating interactive and visually appealing websites from natural language instructions using multi-level visual and functional feedback. This approach, enhanced by step-level reinforcement learning (Step-GRPO), significantly improves the accuracy and aesthetic quality of generated websites, especially when applied to smaller, open-source large language models.

## Problem

- Existing LLM-powered code agents rely on simple code execution feedback, which is insufficient for tasks like website generation that require visual aesthetics and interactive functionality.
- Traditional code agents often produce web applications with undetected visual defects (e.g., misaligned components) or functional problems (e.g., unresponsive buttons) that basic code checks miss.

## Method

- **WebGen-Agent** implements an iterative, ==multi-step workflow== combining code generation, execution, and comprehensive multi-level feedback.
- Multi-level feedback includes visual analysis from a VLM (for appearance scores and suggestions) and functional testing by a GUI-agent (for interactivity scores and suggestions).
- A novel Step-GRPO reinforcement learning strategy is introduced, using combined visual and functional scores as dense, step-level rewards to train the LLM, alongside backtracking and 'select-best' mechanisms for robustness.

## Results

- WebGen-Agent improved Claude-3.5-Sonnet's accuracy from **26.4%** to **51.9%** (a **25.5%** absolute gain) and its appearance score from 3.0 to 3.9 on the WebGen-Bench dataset.
- Step-GRPO training boosted Qwen2.5-Coder-**7B**-Instruct's accuracy from **38.9%** (SFT only) to **45.4%** and its appearance score from 3.4 to 3.7, demonstrating effectiveness for smaller models.
- Ablation studies confirmed GUI-agent testing feedback provided the largest accuracy gain (**3.3%**), while screenshot feedback significantly improved appearance scores (from 3.0 to 3.6).

## Takeaways

> [!tip] Key Insights
> - Integrating multi-level feedback (visual appearance and interactive functionality) is crucial for generating high-quality websites, addressing limitations of solely execution-based feedback.
> - Step-level reinforcement learning (Step-GRPO) effectively leverages these rich, multi-modal feedback signals to significantly improve the performance and reasoning capabilities of even smaller open-source LLMs.
> - Robustness mechanisms like backtracking and 'select-best' are essential for mitigating errors and ensuring the delivery of the highest quality output in iterative code generation processes.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The paper positions itself within the rapidly evolving landscape of Large Language Model (LLM)-powered agent systems, particularly in the domain of code generation. Recent advancements have shown impressive performance for LLMs in repository-level code generation tasks, such as fixing GitHub issues and implementing new features. However, the authors identify a critical gap: existing code agents primarily rely on simple code execution for feedback and verification. This approach is insufficient for tasks like website generation, where visual aesthetics, user interface (UI) quality, and interactive functionality are paramount and cannot be adequately assessed by mere code compilation or runtime error logs.

Traditional code agents, by focusing solely on execution feedback, often produce web applications with visual defects (e.g., misaligned components, disharmonious coloring) or functional problems (e.g., unresponsive buttons, broken links) that go undetected by basic code checks. This work addresses this limitation by proposing a novel, iterative feedback mechanism that incorporates both visual and interactive assessments.

In the broader context, this research moves beyond rudimentary code generation towards "full-stack" agentic development that considers the end-user experience. It contrasts with prior efforts in visual code generation (e.g., pix2code), which often focus on single-file HTML reconstruction from screenshots, or other web development tasks that use rigid, sequential pipelines. WebGen-Agent aims for end-to-end, multi-file, repository-level website development from natural language instructions, a more complex and holistic challenge. By introducing multi-level feedback (visual language model for appearance, GUI agent for functionality), WebGen-Agent enhances the agent's perception of the generated output quality, a critical step towards more autonomous and capable software engineering agents. This approach also contributes to the field of reinforcement learning for agents by demonstrating how rich, step-level feedback, inherent to the problem domain, can be effectively leveraged to train more robust and capable LLMs.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop an advanced code generation system, named **WebGen-Agent**, that can generate interactive and visually appealing websites from natural language instructions. The core motivation stems from the recognized limitations of current LLM-powered code agents when confronted with tasks that require significant visual and interactive fidelity, such as website development.

Specifically, the key objectives and motivations are:

- **Address Insufficient Feedback Mechanisms:** Current code agents' reliance on simple code execution feedback is inadequate for website generation. The motivation is to overcome this by introducing comprehensive, multi-level feedback that captures the actual quality of the generated codebase in terms of both appearance and functionality.
- **Iterative Refinement for High-Quality Websites:** The goal is to enable agents to iteratively generate and refine website codebases, leading to projects that not only meet functional requirements but also adhere to high aesthetic standards. This involves using detailed and expressive text descriptions and suggestions, along with quantitative scores, derived from visual and interactive assessments.
- **Enhance LLM Reasoning with Step-Level Supervision:** A significant motivation is to improve the reasoning capabilities of LLMs acting as the core engine of these agents. The authors aim to leverage the accurate visual and functional scores produced by WebGen-Agent to provide dense, step-level supervision for reinforcement learning (specifically, GRPO), thereby boosting the LLM's ability to act as a robust reasoning engine.
- **Improve Cost-Effectiveness of Open-Source Models:** While powerful proprietary models show promise, using smaller, open-source models for such complex tasks is more cost-efficient. A key objective is to demonstrate that with effective training strategies, even smaller open-source LLMs (e.g., 7B-8B parameters) can achieve significantly improved performance in website generation, thus democratizing access to advanced agent capabilities.
- **Develop a Robust Agent Workflow:** To create a resilient system that can navigate challenges in website generation, the paper aims to integrate mechanisms like backtracking and "select-best" based on the multi-level quality scores, ensuring that the final output is the highest quality version produced during the iterative process.

In essence, the motivation is to bridge the gap between abstract code generation and the tangible, user-centric experience of a functional and beautiful website, making LLM-driven web development a more practical and high-quality solution.

### 3. Methodology and Approach

The WebGen-Agent employs a novel, iterative, multi-step paradigm combining code generation, execution, and comprehensive multi-level feedback, further enhanced by a specialized reinforcement learning strategy.

#### 3.1. WebGen-Agent Workflow

The workflow operates in a continuous loop, refining the website codebase based on natural language instructions:

1. **Initialization:** The agent starts with an initial website generation instruction and an empty codebase. A system prompt (similar to Bolt.diy) is concatenated with the user request.
2. **Code Generation:** A large language model (LLM), acting as the agent's engine, generates code edits (∆C) to modify the current codebase (C).
3. **Code Execution:** The modified codebase is then executed. This involves installing dependencies and starting the website service.
 - If execution fails (e.g., dependency errors, service startup failures), the error message (O) is fed back to the LLM, prompting it to fix the error in the next step.
 - **Error Handling and Backtracking:** If five consecutive execution errors occur, a "backtracking" mechanism is triggered. The agent reverts the codebase and trajectory to a previously saved "best" non-erroneous step.
4. **Feedback Gathering (Multi-level):** If code execution is successful, detailed feedback is gathered:
 - **Screenshot Feedback (Visual):** A screenshot of the website's landing page is captured. A Visual Language Model (VLM, e.g., Qwen2.5-VL-32B-Instruct) then analyzes the screenshot. It provides:
 - A textual **description** of the website's appearance.
 - An **appearance score** (Score_shot) quantifying visual quality (0-5).
 - **Suggestions** for improving the website's aesthetics (e.g., layout, colors, component alignment).
 - **GUI-Agent Testing Feedback (Functional):** If the VLM deems the appearance satisfactory, a GUI-agent session is initiated. The LLM generates instructions for the GUI agent to explore specific functional requirements outlined in the original user instruction. The GUI agent performs these actions, and its trajectory is analyzed by the LLM (or VLM) to determine:
 - A **functional score** (Score_gui) for interactive correctness (1-5).
 - **Suggestions** for fixing functional issues.
5. **Iterative Refinement:** The LLM uses the combined feedback (error messages, visual suggestions, functional suggestions) to generate further code edits in subsequent steps.
6. **Termination:** The process continues until the website passes all GUI-agent tests, or a maximum number of iterations (set to 20 in experiments) is reached.
7. **Select-Best Mechanism:** At the end of the entire trajectory, the system doesn't necessarily take the last generated codebase. Instead, it reviews all saved steps (codebase, Score_shot, Score_gui) and selects the "best" step based on a predefined criterion: highest Score_gui, then highest Score_shot, and finally the latest among those ties. This ensures the delivery of the most robust and high-quality outcome.

#### 3.2. Step-GRPO with Screenshot and GUI-agent Feedback

To enhance the performance of smaller open-source LLMs, the authors introduce a novel training approach called Step-GRPO with Screenshot and GUI-agent Feedback:

1. **Supervised Fine-tuning (SFT) Warm-up:** Initially, a "light" SFT is performed on the target LLM (e.g., Qwen2.5-Coder-7B-Instruct). This uses approximately 700 WebGen-Agent trajectories generated by a powerful model (DeepSeek-V3) to provide a warm start and teach basic website generation patterns.
2. **Reinforcement Learning (Step-GRPO):** After SFT, the model undergoes Step-GRPO training.
 - **Trajectory Generation:** For a given instruction, multiple WebGen-Agent trajectories are generated by the fine-tuned LLM.
 - **Step-Level Reward Signal:** Crucially, for each step in a trajectory, a dense and reliable reward is computed by summing the **Score_shot** and **Score_gui** obtained from the WebGen-Agent workflow (r = Score_shot + Score_gui). This dual supervision effectively guides the model.
 - **Advantage Calculation:** Unlike naive GRPO (which might use a single outcome reward) or cumulative advantage from future steps, Step-GRPO uses the immediate, standardized step-level reward (r_j - mean(R) / std(R)) as the advantage for the code generation tokens of that specific step. This direct feedback is considered more appropriate as the scores reflect the immediate quality of the website at that point.
 - **Objective:** The GRPO objective optimizes the LLM's policy to generate code that leads to higher step-level rewards, effectively teaching it to make choices that improve website appearance and functionality iteratively.

This methodology combines an intelligent iterative agent workflow with a targeted reinforcement learning strategy, leveraging the rich, multi-modal feedback to improve both the agent's performance and the underlying LLM's reasoning capabilities for complex, visually-driven code generation tasks.

### 4. Main Findings and Results

The experiments conducted on the WebGen-Bench dataset, encompassing 101 website generation instructions and 647 GUI-agent test cases, yielded several significant findings:

1. **Superior Performance of WebGen-Agent:**
 - WebGen-Agent consistently and significantly outperforms previous state-of-the-art code agent systems (OpenHands, Aider, Bolt.diy) across a wide range of proprietary and open-source LLMs.
 - For **Claude-3.5-Sonnet**, WebGen-Agent increased accuracy from 26.4% to **51.9%** (a 25.5% absolute gain) and improved the appearance score from 3.0 to **3.9**.
 - The highest performance among all tested models was achieved by **Qwen3-Coder-480B-A35B-Instruct** with WebGen-Agent, reaching an accuracy of **58.2%** and an appearance score of **4.3**.
 - Even with **30B–72B sized open-source models**, WebGen-Agent demonstrated strong gains, outperforming Bolt.diy by 22.5% in accuracy and 2.2 in appearance scores for Qwen2.5-Coder-32B-Instruct.

2. **Effectiveness of Step-GRPO Training for Smaller Models:**
 - The proposed Step-GRPO with Screenshot and GUI-agent Feedback significantly boosts the performance of smaller open-source models (7B-8B parameters).
 - For **Qwen2.5-Coder-7B-Instruct**:
 - Supervised Fine-tuning (SFT) alone increased accuracy from 12.4% (no training) to 38.9% and appearance score from 1.6 to 3.4.
 - Step-GRPO further improved accuracy to **45.4%** (an additional 6.5% gain) and appearance score to **3.7**.
 - Similar improvements were observed for **Qwen3-8B**: SFT improved accuracy from 34.1% to 38.6% and appearance from 3.2 to 3.4. Step-GRPO further raised accuracy to **43.4%** and appearance to **3.6**.
 - Qualitative analysis showed SFT reducing errors and improving appearance adherence, while Step-GRPO further refined aesthetics and harmony.

3. **Ablation Study Insights (WebGen-Agent Workflow):**
 - Each component of the WebGen-Agent workflow contributes positively to performance.
 - **GUI-agent testing feedback** provided the largest accuracy gain (3.3%), highlighting its crucial role in ensuring functional correctness.
 - **Screenshot feedback** significantly improved the appearance score (from 3.0 to 3.6), validating its impact on visual aesthetics.
 - **Backtracking and Select-best mechanisms** mitigated negative impacts on appearance that sometimes arise from functional modifications, ensuring a robust final output.

4. **Ablation Study Insights (Step-GRPO Training):**
 - Using both screenshot and GUI-agent scores as rewards (Score_shot + Score_gui) was superior to using either score alone, demonstrating the necessity of dual feedback for comprehensive improvement.
 - The specific step-level reward calculation in Step-GRPO outperformed naive outcome-based GRPO and cumulative advantage variants.

5. **Efficiency of Feedback VLM:**
 - A relatively small and cost-effective open-source VLM, **Qwen2.5-VL-32B-Instruct**, proved sufficient for providing accurate screenshot and GUI-agent testing feedback. Its performance was comparable to using a more powerful, proprietary VLM like GPT-4o for feedback, while being significantly more cost-efficient.
 - Human annotation confirmed the high accuracy of both screenshot scores (93-96%) and GUI-agent scores (89-93%), validating their reliability as feedback signals.

These findings collectively demonstrate the efficacy of WebGen-Agent's iterative multi-level feedback system and the power of Step-GRPO in effectively training LLMs for complex, visually and interactively driven code generation tasks.

### 5. Significance and Potential Impact

The WebGen-Agent system and the accompanying Step-GRPO training methodology represent a significant leap forward in the field of LLM-powered code agents, particularly for visually-intensive tasks like website generation. Its significance and potential impact can be summarized as follows:

1. **Democratizing Web Development:** By enabling LLMs to generate functional and aesthetically pleasing websites from natural language instructions, WebGen-Agent lowers the barrier to entry for website creation. Non-expert users, without coding knowledge, could potentially articulate their vision in natural language and receive a working website, significantly broadening access to web development tools.
2. **Advancement in Agentic AI:** This work pushes the boundaries of autonomous AI agents by demonstrating a robust framework for iterative self-correction based on multi-modal (visual and interactive) feedback. It provides a blueprint for developing more capable agents that can operate in complex, real-world environments where output quality is perceived beyond mere code execution success.
3. **Enhanced LLM Capabilities for Visually-Driven Tasks:** The integration of VLMs and GUI agents as feedback mechanisms equips LLMs with a richer "understanding" of their generated output. This ability to "see" and "interact" with the generated artifact allows LLMs to reason more effectively about visual aesthetics and user experience, which is critical for tasks beyond just website generation.
4. **Cost-Effective High-Quality Generation:** The success of Step-GRPO in significantly improving smaller, open-source models (7B-8B parameters) is particularly impactful. This suggests that high-performance, autonomous code generation capabilities might not be exclusively tied to frontier, closed-source LLMs. By making these capabilities more accessible through efficient training of smaller models, the research contributes to the democratization and broader adoption of advanced AI in software engineering.
5. **Robustness and Reliability:** The inclusion of backtracking and select-best mechanisms, combined with highly accurate feedback scores, significantly enhances the robustness and reliability of the generated output. This ensures that even through iterative trial and error, the system is designed to deliver the best possible version of the website.
6. **Catalyst for Future Research:** The release of WebGen-Agent's workflow code, training code, data, and model weights fosters reproducibility and encourages further research in several directions. This includes exploring more complex web functionalities, integrating advanced performance metrics (e.g., website response speed, network conditions), and scaling the Step-GRPO approach to even larger open-source models. The framework can also inspire similar multi-modal feedback loops for other AI design and generation tasks.

In conclusion, WebGen-Agent represents a pivotal step towards truly autonomous AI software engineers capable of producing high-quality, user-centric web applications, with significant implications for both AI research and practical applications in web development.
