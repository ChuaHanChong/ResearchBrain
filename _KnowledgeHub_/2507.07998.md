# PyVision: Agentic Vision with Dynamic Tooling

> [!summary] Summary
> The PyVision framework equips multimodal large language models with the ability to autonomously generate, execute, and refine Python code for visual reasoning tasks. This approach leads to consistent performance improvements across various benchmarks, including a 7.8% gain on fine-grained visual search with GPT-4.1 and a 31.1% increase on symbolic vision tasks with Claude-4.0-Sonnet.

## Problem

- Multimodal Large Language Models (MLLMs) struggle with novel or complex visual reasoning due to reliance on static, predefined toolsets.
- Current MLLM agents lack the ability to dynamically generate custom computational tools, limiting their adaptability to diverse visual tasks.
- Prior approaches lacked sufficient interpretability and verifiability for complex, compositional visual reasoning tasks.

## Method

- An interactive, ==multi-turn framework== empowers MLLMs to dynamically generate and execute Python code for visual reasoning.
- Python and its rich ecosystem of libraries (e.g., OpenCV, NumPy) serve as the ==exclusive primitive for tool creation==, enabling dynamic composition of task-specific solutions.
- The framework ensures robust multi-turn interaction through ==process isolation==, cross-turn state persistence, and secure I/O for iterative refinement.

## Results

- PyVision-GPT-4.1 achieved performance increases of **+1.8%** on MathVista, **+2.4%** on MMMU, and **+7.8%** on V* benchmarks.
- PyVision-Claude-4.0-Sonnet showed significant gains, including **+4.8%** on MathVista, **+8.3%** on Visual Puzzles, and **+31.1%** on VLMsAreBlind-mini.
- Analysis of dynamically generated code revealed adaptive tool usage, with specific tool types predominantly invoked according to task demands and domain characteristics.

## Takeaways

> [!tip] Key Insights
> - MLLMs can move beyond static tool usage to dynamically invent task-specific computational tools using a Python-based framework.
> - The framework provides enhanced interpretability and verifiability by allowing inspection of the AI's generated Python code and execution steps.
> - PyVision's dynamic tooling complements and amplifies the inherent strengths of its backend MLLMs, leading to varied performance boosts depending on the model's core capabilities.
