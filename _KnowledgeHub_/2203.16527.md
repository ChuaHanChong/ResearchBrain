# Exploring Plain Vision Transformer Backbones for Object Detection

> [!summary] Summary
> This research from Facebook AI Research demonstrates that plain, non-hierarchical Vision Transformer (ViT) backbones can achieve state-of-the-art results for object detection. It shows that with minimal adaptations during fine-tuning, such as a simple feature pyramid and window attention with limited cross-window propagation, and crucially, pre-training with Masked Autoencoders, these plain architectures can surpass or match performance of hierarchical ViT counterparts on COCO and LVIS datasets.

## Problem

- Integrating Vision Transformers (ViTs) into object detection frameworks was challenging due to their single-scale output (difficulty handling multi-scale objects) and the quadratic computational cost of global self-attention on high-resolution images.
- The prevailing approach adapted ViTs into hierarchical designs (e.g., Swin Transformer) to mimic ConvNet properties, hindering the original ViT's 'plain' and 'fewer inductive biases' philosophy.
- Existing object detection systems were heavily reliant on hierarchical backbones like ConvNets or hierarchically-modified ViTs, requiring complex feature pyramid networks (FPNs) for multi-scale feature fusion.

## Method

- Proposing a ==simple feature pyramid== that generates multi-scale feature maps from only the last single-scale feature map of a plain ViT backbone using convolutional and deconvolutional layers.
- Adapting the pre-trained plain ViT backbone with ==window attention== for computational efficiency and incorporating a few (e.g., 4) strategically placed ==cross-window propagation blocks== (global attention or convolutional) during fine-tuning.
- Leveraging ==Masked Autoencoders (MAE)== for self-supervised pre-training of the plain ViT backbones, which proved essential for learning robust and transferable visual representations.

## Results

- The proposed ViTDet with a plain ViT-Huge backbone achieved **61.3 AP box** on the COCO dataset, outperforming hierarchical counterparts that used larger ImageNet-21K supervised pre-training.
- A simple feature pyramid built from only the last 1/16 stride feature map performed comparably to or better than FPN-mimicking variants, simplifying the detection pipeline for plain backbones.
- ViTDet demonstrated competitive wall-clock performance for large models due to simpler block designs and showed consistent strong performance across different detector frameworks (Mask R-CNN, Cascade Mask R-CNN, RetinaNet) and datasets (COCO, LVIS).

## Takeaways

> [!tip] Key Insights
> - Simple feature pyramids constructed from a single last-layer feature map are sufficient for plain Vision Transformer backbones in object detection, negating the need for complex top-down/lateral FPN connections.
> - Applying window attention with minimal cross-window propagation (e.g., 4 blocks) during fine-tuning is effective for handling high-resolution inputs in plain ViTs without altering the pre-training architecture.
> - Masked Autoencoder (MAE) self-supervised pre-training is crucial for the success of plain ViT backbones, providing substantial performance gains for object detection tasks.
