# Exploring Plain Vision Transformer Backbones for Object Detection

> [!summary] Summary
> This research from Facebook AI Research demonstrates that plain, non-hierarchical Vision Transformer (ViT) backbones can achieve state-of-the-art results for object detection. It shows that with minimal adaptations during fine-tuning, such as a simple feature pyramid and window attention with limited cross-window propagation, and crucially, pre-training with Masked Autoencoders, these plain architectures can surpass or match performance of hierarchical ViT counterparts on COCO and LVIS datasets.

## Problem

- Integrating Vision Transformers (ViTs) into object detection frameworks was challenging due to their single-scale output (difficulty handling multi-scale objects) and the quadratic computational cost of global self-attention on high-resolution images.
- The prevailing approach adapted ViTs into hierarchical designs (e.g., Swin Transformer) to mimic ConvNet properties, hindering the original ViT's 'plain' and 'fewer inductive biases' philosophy.
- Existing object detection systems were heavily reliant on hierarchical backbones like ConvNets or hierarchically-modified ViTs, requiring complex feature pyramid networks (FPNs) for multi-scale feature fusion.

## Method

- Proposing a ==simple feature pyramid== that generates multi-scale feature maps from only the last single-scale feature map of a plain ViT backbone using convolutional and deconvolutional layers.
- Adapting the pre-trained plain ViT backbone with ==window attention== for computational efficiency and incorporating a few (e.g., 4) strategically placed ==cross-window propagation blocks== (global attention or convolutional) during fine-tuning.
- Leveraging ==Masked Autoencoders (MAE)== for self-supervised pre-training of the plain ViT backbones, which proved essential for learning robust and transferable visual representations.

## Results

- The proposed ViTDet with a plain ViT-Huge backbone achieved **61.3 AP box** on the COCO dataset, outperforming hierarchical counterparts that used larger ImageNet-21K supervised pre-training.
- A simple feature pyramid built from only the last 1/16 stride feature map performed comparably to or better than FPN-mimicking variants, simplifying the detection pipeline for plain backbones.
- ViTDet demonstrated competitive wall-clock performance for large models due to simpler block designs and showed consistent strong performance across different detector frameworks (Mask R-CNN, Cascade Mask R-CNN, RetinaNet) and datasets (COCO, LVIS).

## Takeaways

> [!tip] Key Insights
> - Simple feature pyramids constructed from a single last-layer feature map are sufficient for plain Vision Transformer backbones in object detection, negating the need for complex top-down/lateral FPN connections.
> - Applying window attention with minimal cross-window propagation (e.g., 4 blocks) during fine-tuning is effective for handling high-resolution inputs in plain ViTs without altering the pre-training architecture.
> - Masked Autoencoder (MAE) self-supervised pre-training is crucial for the success of plain ViT backbones, providing substantial performance gains for object detection tasks.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

For a long time, the dominant backbone architectures in computer vision, especially for dense prediction tasks like object detection and segmentation, have been **Convolutional Neural Networks (ConvNets)**. ConvNets naturally produce hierarchical, multi-scale feature maps through their progressive downsampling layers. This hierarchical structure has heavily influenced the design of detection necks and heads, such as the widely adopted **Feature Pyramid Network (FPN)**, which leverages features from different scales to detect objects of varying sizes.

The introduction of **Vision Transformers (ViT)** marked a paradigm shift in image recognition. Unlike ConvNets, the original ViT is a "plain," non-hierarchical architecture that maintains a single-scale feature map throughout its layers. While ViTs have demonstrated superior performance in image classification, their application to object detection posed immediate challenges:
1. **Multi-scale objects:** How to effectively detect objects of vastly different scales with a single-scale backbone?
2. **High-resolution inputs:** Global self-attention in plain ViTs becomes computationally prohibitive (quadratic complexity) for the high-resolution images typically used in object detection.

To address these challenges, the prevailing research trend has been to **redesign Vision Transformers to incorporate hierarchical structures**, mimicking ConvNets. Notable examples include **Swin Transformers** and **Multiscale Vision Transformers (MViT/MViTv2)**. These hierarchical Transformers adopt mechanisms like shifted window attention or pooling attention to achieve multi-scale representations and manage computational complexity, effectively bridging the gap between ViTs and existing ConvNet-based detection frameworks. This approach allowed for a relatively straightforward replacement of ConvNet backbones with Transformer backbones while largely retaining the established detection pipeline (e.g., using FPN).

This paper, however, pursues a **fundamentally different and counter-trending direction**: it explores the feasibility of using **original, plain, non-hierarchical ViT backbones** for object detection. The authors argue for maintaining the "minimalist" pursuit of ViT, which involves "fewer inductive biases" and a separation between the general-purpose backbone and task-specific fine-tuning components. This approach aims to decouple the pre-training design from the fine-tuning demands, a philosophy that has been highly successful in Natural Language Processing (NLP) with models like BERT and GPT, where a single large pre-trained model can be fine-tuned for diverse downstream tasks without architecture modifications. By proving the viability of plain ViTs for detection, this work challenges the entrenched position of hierarchical backbones and advocates for a more unified and flexible approach to visual representation learning.

### 2. Key Objectives and Motivation

The central objective of this research is to **demonstrate the viability and competitiveness of plain, non-hierarchical Vision Transformer (ViT) backbones for object detection**. This goes against the current trend of adapting ViT architectures to be hierarchical for dense prediction tasks.

The key motivations driving this exploration are:

- **Decoupling Pre-training and Fine-tuning:** The authors aim to maintain a clear separation between the task-agnostic backbone (pre-trained on large-scale datasets, potentially with self-supervision) and the task-specific detection components (necks and heads). If a plain ViT can serve as an effective backbone for detection with minimal adaptation during fine-tuning, it means the development of general-purpose visual learners is not constrained by the specific demands of a downstream task like object detection. This allows for parallel evolution of backbones and task heads.
- **Adhering to ViT's "Fewer Inductive Biases" Philosophy:** The original ViT paper advocated for networks with fewer built-in assumptions (like translation equivariance from convolutions). This work extends that philosophy to scale equivariance. Instead of hard-coding multi-scale properties into the backbone, the goal is to see if the model can learn scale-equivariant features from data, especially when empowered by powerful self-supervised pre-training.
- **Leveraging Existing and Future Plain ViT Backbones:** If plain ViTs can be effectively used for detection, it makes the entire ecosystem of readily available pre-trained ViT models (e.g., from ImageNet classification or self-supervised methods like MAE) directly transferable to detection without needing specialized "detection-friendly" hierarchical versions. This future-proofs the approach, making it compatible with advances in plain ViT architectures, self-supervised learning, and scaling techniques.
- **Simplicity and Efficiency:** By avoiding complex hierarchical designs and shifting window mechanisms, the proposed adaptations are minimal and aim for computational efficiency and practical performance tradeoffs, particularly important for high-resolution detection inputs.

In essence, the paper seeks to answer: Can the "minimalist" and "universal feature" pursuit of the original ViT architecture be successfully extended to the complex domain of object detection, or is a hierarchical backbone fundamentally necessary? The authors hypothesize that with the right simple adaptations and powerful pre-training, plain ViTs can indeed compete.

### 3. Methodology and Approach

The core of the methodology lies in making **minimal adaptations to a plain, pre-trained ViT backbone** specifically during the fine-tuning phase for object detection. This ensures that the backbone itself remains task-agnostic and doesn't require redesigning for pre-training. The detector then uses standard components like Mask R-CNN or Cascade Mask R-CNN.

The two primary adaptations are:

1. **Simple Feature Pyramid Construction:**
 - **Problem:** Plain ViTs maintain a single-scale feature map (e.g., 1/16 stride relative to input). Object detection requires multi-scale features to detect objects of varying sizes. Traditional FPN relies on hierarchical backbones tapping into multiple stages.
 - **Solution:** Instead of mimicking FPN's complex top-down and lateral connections across artificial stages, the authors propose a "simple feature pyramid." This pyramid is built **solely from the last, strongest single-scale feature map (1/16 stride)** of the plain ViT backbone.
 - **Mechanism:** Convolutional layers are used in parallel to produce feature maps at different scales (e.g., 1/32, 1/16, 1/8, 1/4). Specifically, strided convolutions generate smaller scales (e.g., 1/32), while deconvolutions (fractional strides) generate larger scales (e.g., 1/8, 1/4).
 - **Hypothesis:** The authors hypothesize that for plain ViTs, the benefit of multi-scale features comes from the pyramid itself and the explicit scale-equivariant mapping of anchors/regions, rather than the intricate top-down/lateral connections of FPN, because the high-dimensional ViT patch embeddings may already retain sufficient information.

2. **Backbone Adaptation for High-Resolution Inputs:**
 - **Problem:** Applying global self-attention across the entire high-resolution image used in object detection is computationally infeasible due to quadratic complexity.
 - **Solution:** The backbone is adapted to use **non-overlapping window attention** during fine-tuning. Self-attention is computed only within fixed-size windows, drastically reducing computation.
 - **Cross-Window Propagation:** To ensure information flows across windows (which is crucial for understanding global context and relationships between objects), a *very small number* (e.g., 4) of "cross-window propagation blocks" are strategically inserted or modified within the ViT backbone. Two strategies are explored:
 - **Global Propagation:** In the designated blocks, global self-attention is performed across the entire feature map. Since only a few blocks do this, the overall computational cost remains manageable.
 - **Convolutional Propagation:** As an alternative, an extra convolutional residual block (initialized to be an identity) is added after each subset of window attention blocks. Even though convolutions are local, they can effectively propagate information across window boundaries, especially when followed by self-attention in subsequent blocks.
 - **Key Distinction:** Crucially, these adaptations (window attention and propagation blocks) are applied *only during fine-tuning* and **do not require modifying the ViT architecture during pre-training**. This allows the use of standard pre-trained ViT models.

**Pre-training Strategy:** While not a "methodology" in terms of architecture, the choice of pre-training is a critical component of their approach. The paper extensively leverages **Masked Autoencoders (MAE)**, a self-supervised learning technique developed by some of the same authors. MAE pre-trains plain ViTs by reconstructing masked patches of an image, showing remarkable scalability and transferability. The authors show that MAE pre-training is essential for the success of plain ViT backbones in detection.

**Implementation Details:** The authors use vanilla ViT-B, ViT-L, and ViT-H as backbones. The patch size is fixed at 16x16. Standard detector heads like Mask R-CNN and Cascade Mask R-CNN are employed. Input images are 1024x1024, with large-scale jittering for augmentation.

### 4. Main Findings and Results

The research yields several surprising and significant findings that challenge conventional wisdom in object detection:

1. **Sufficiency of Simple Feature Pyramids:**
 - The paper demonstrates that for plain ViT backbones, the intricate top-down and lateral connections characteristic of the FPN design are **not necessary**.
 - A "simple feature pyramid" built by applying convolutions/deconvolutions to only the last, single-scale feature map (1/16 stride) performs as well as, or even slightly better than, FPN-mimicking variants (which artificially divide the plain backbone into stages).
 - This highlights that the benefit of feature pyramids primarily stems from the availability of multi-scale feature maps themselves and the explicit scale-equivariant mapping used by the RPN and RoI heads, rather than the specific cross-level fusion mechanism.

2. **Window Attention with Minimal Cross-Window Propagation is Sufficient:**
 - Pure window attention (without any cross-window propagation) still yields reasonable results, suggesting that later detector layers (pyramid, RPN, RoI heads) contribute to cross-window communication.
 - However, a **few (e.g., 4) cross-window propagation blocks** (either global attention or convolutional blocks) significantly improve performance (e.g., +1.7 to +1.9 AP box for ViT-L).
 - Both global and convolutional propagation strategies perform similarly well, with convolutional propagation being more practical in terms of memory and speed.
 - Crucially, these adaptations are **only applied during fine-tuning** and do not alter the pre-training architecture, preserving the "plain" nature of the ViT backbone. This offers a practical and high-performing trade-off between computational cost and accuracy.

3. **Masked Autoencoders (MAE) are Critical for Plain ViT Performance:**
 - MAE self-supervised pre-training on ImageNet-1K (without labels) provides **massive performance gains** (e.g., +4.6 AP box for ViT-L) compared to supervised pre-training on ImageNet-1K or even ImageNet-21K.
 - The authors hypothesize that plain ViTs, with their fewer inductive biases, require higher capacity to learn fundamental visual properties like translation and scale equivariance. MAE pre-training effectively helps the models acquire these robust representations, mitigating overfitting and enabling strong transfer performance.
 - The gains from MAE are more pronounced for plain ViTs than for hierarchical backbones (e.g., MViTv2), suggesting that MAE might specifically compensate for the lack of built-in inductive biases in plain architectures.

4. **ViTDet Competitiveness against Hierarchical Backbones:**
 - Named **ViTDet**, the proposed plain-backbone detector, when combined with MAE pre-training, achieves **competitive and often superior results** compared to leading hierarchical-backbone detectors (Swin, MViTv2), especially for larger model sizes.
 - On the COCO dataset, ViTDet with a plain ViT-Huge backbone, pre-trained only on ImageNet-1K (without labels), achieves **61.3 AP box**, outperforming hierarchical counterparts that used larger ImageNet-21K supervised pre-training.
 - ViTDet also demonstrates better **wall-clock performance** for large models, as its simpler blocks are more hardware-friendly.
 - Competitive results are also shown on the long-tailed LVIS dataset, further validating the approach's generality.
 - The findings hold across different detector frameworks (Mask R-CNN, Cascade Mask R-CNN, RetinaNet).

### 5. Significance and Potential Impact

The significance and potential impact of this research are substantial, challenging the current paradigm in object detection and offering a more unified vision for computer vision research:

1. **Paradigm Shift in Object Detection Backbones:** This work provides compelling evidence that hierarchical backbones are not strictly necessary for state-of-the-art object detection. By demonstrating the competitive performance of plain ViTs, ViTDet encourages a re-evaluation of fundamental architectural choices in dense prediction tasks. This could lead to a divergence from the current trend of making Vision Transformers more ConvNet-like for detection.

2. **Reinforcement of Decoupling Pre-training and Fine-tuning:** The paper successfully demonstrates a methodology where the general-purpose visual backbone (ViT) remains largely task-agnostic during pre-training, with detection-specific adaptations applied only during fine-tuning. This aligns computer vision research more closely with the successful paradigm in Natural Language Processing (NLP), where large, general-purpose pre-trained models (like BERT, GPT) are fine-tuned for diverse downstream tasks without modifying their core architecture. This decoupling simplifies the research ecosystem, allowing independent advancements in backbone design and task-specific heads.

3. **Broadened Compatibility and Future-Proofing:** By showing that standard, globally-attending ViTs (especially those pre-trained with MAE) can be directly leveraged for object detection, ViTDet enables the use of a wider range of available and future ViT models. Any improvements in plain ViT architectures, self-supervised learning techniques for ViTs, or scaling methods can now directly benefit object detection without requiring specialized hierarchical versions. This fosters greater synergy across different areas of computer vision research.

4. **Emphasis on Self-Supervised Learning:** The critical role of MAE pre-training in ViTDet's success highlights the power of self-supervised learning for training robust, transferable representations, especially for architectures with fewer inductive biases. This reinforces the importance of exploring and advancing self-supervised methods for pre-training large-scale vision models.

5. **Inspiration for Future Research:** ViTDet opens several new avenues for research:
 - **Further exploration of plain backbones:** Investigating more sophisticated yet minimal adaptation strategies for plain backbones.
 - **Reducing inductive biases in detection heads:** The paper uses standard detection heads (Mask R-CNN). Future work could explore how to develop detection heads that also rely on fewer inductive biases, potentially moving towards more end-to-end learning (like DETR) but benefiting from the strong, generic features of plain ViT backbones.
 - **Understanding representation learning:** Further studies could delve into *how* plain ViTs, especially with MAE, learn scale-equivariant and hierarchical features implicitly from data, without explicit architectural constraints.

In conclusion, "Exploring Plain Vision Transformer Backbones for Object Detection" is a landmark paper that challenges the status quo, advocating for a return to the minimalist philosophy of the original Vision Transformer. Its strong empirical results, particularly when combined with Masked Autoencoder pre-training, position plain-backbone detectors as a highly promising direction that could streamline and advance the field of computer vision.
