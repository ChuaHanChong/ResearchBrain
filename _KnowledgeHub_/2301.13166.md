# ESC: Exploration with Soft Commonsense Constraints for Zero-shot Object Navigation

> [!summary] Summary
> ESC is a zero-shot object navigation method that combines a pretrained vision-language grounder (GLIP) for open-world scene understanding with a pretrained language model's commonsense reasoning, fused via Probabilistic Soft Logic into frontier-based exploration. Needs no navigation training and sets new zero-shot state-of-the-art on MP3D, HM3D, RoboTHOR.

## Problem

- Supervised object navigation methods need large labeled trajectory data per environment and generalize poorly to novel objects or unseen environments under distribution shift.
- Existing zero-shot navigation approaches still require training on other goal-oriented navigation tasks and environments, undermining true zero-shot generalization.
- Prior heuristic exploration and neural methods lack explicit commonsense reasoning, so frontier choices ignore likely room-object correspondences during search.

## Method

- Prompt-based scene grounding with ==GLIP== detects open-world objects and rooms from egocentric RGB via text prompts, projected into a semantic map without task-specific training.
- ==LLM-based commonsense reasoning== (mainly ==Deberta v3==) scores likelihood of goal object co-occurring with detected objects and rooms as continuous [0,1] values.
- Soft commonsense constraints formulated as ==Probabilistic Soft Logic== rules over frontier, object, and room atoms, solved via a fast ==one-hot constraint solver== to pick next exploration frontier.

## Results

- On MP3D, ESC achieves **288%** relative success rate and **284%** relative SPL improvement over CoW, the only other training-free zero-shot baseline.
- ESC outperforms ZSON, which trains on HM3D at scale, by **196%** relative SPL on MP3D and **85%** relative SPL on HM3D despite using no navigation training.
- Ablations show the one-hot PSL solver beats ADMM (**13.7** vs **12.9** SPL) while running **8.5x** faster (**0.25s** vs **2.13s** per inference).

## Takeaways

> [!tip] Key Insights
> - Explicit, interpretable soft-logic commonsense rules can substitute for costly in-domain navigation training while still beating trained zero-shot baselines.
> - Room-level commonsense reasoning contributes more than object-level reasoning, suggesting coarse spatial priors carry more transferable signal than fine object co-occurrence.
> - Detection errors dominate failure modes, indicating open-vocabulary grounding accuracy, not commonsense reasoning, is the main bottleneck for further zero-shot navigation gains.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work presented in this paper addresses a fundamental challenge within embodied artificial intelligence (AI): object navigation (ObjNav). ObjNav requires an agent to locate and navigate to a specific object in an unknown environment. Current state-of-the-art methods for this task often rely on extensive training within specific visual environments with labeled objects. While these methods achieve high performance on their respective training datasets, they exhibit limited generalization capabilities when encountering novel objects or entirely new environments. This deficiency is a significant barrier to deploying embodied agents in real-world scenarios, which are characterized by diverse objects and varied environments, making large-scale, annotated data collection impractical and costly.

This research specifically focuses on *zero-shot* object navigation, a more challenging variant where the agent must adapt to unseen environments and novel object types without any prior training on navigation data or specific object labels. Existing zero-shot ObjNav approaches have explored various strategies, including training on related goal-oriented navigation tasks (e.g., image-goal navigation) in large datasets, or employing simple heuristic-based exploration techniques. However, these methods often fall short in explicitly incorporating commonsense reasoning, which humans inherently use to infer object locations (e.g., a fireplace is typically found in a living room).

The paper positions itself within the context of recent advancements in large pre-trained models, particularly vision-and-language models (VLMs) and large language models (LLMs). These models have demonstrated strong generalization and reasoning abilities in zero-shot scenarios across various tasks. This work leverages these pre-trained models, specifically a grounded language-image model (GLIP) for open-world semantic scene understanding and a commonsense reasoning LLM, to integrate high-level knowledge directly into the navigation process. The novelty lies in bridging the gap between the abstract commonsense knowledge inferred by LLMs and the concrete, executable navigation actions required for exploration, which previous methods have not effectively addressed. By modeling this knowledge as "soft" constraints within a Probabilistic Soft Logic (PSL) framework, the research aims to provide a robust and training-free approach to generalized object navigation, moving beyond implicit learning of commonsense through neural networks.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a novel zero-shot object navigation method, termed Exploration with Soft Commonsense constraints (ESC), that can accurately locate and navigate to a specified goal object within unseen environments and for novel object types. A core aspect of this objective is to achieve this without any prior navigation experience or specific training on visual environments.

This objective is driven by several motivations:

1. **Addressing Generalization Limitations in Object Navigation:** Conventional object navigation methods, while effective in controlled settings, typically suffer from poor generalization when confronted with objects or environments outside their training distribution. This limitation arises from the need for large-scale, object-specific, and environment-specific training data, which is expensive and time-consuming to collect for real-world deployment. The motivation is to overcome this "distribution shift" challenge by enabling agents to generalize effectively to novel scenarios.

2. **Incorporating Explicit Commonsense Reasoning:** Successful object navigation in unfamiliar environments requires more than just visual perception; it necessitates semantic scene understanding and commonsense reasoning. Agents need to infer probable locations of goal objects based on contextual knowledge (e.g., "a bed is likely in a bedroom"). Existing zero-shot object navigation approaches often lack this explicit commonsense reasoning, relying instead on simpler heuristics or being implicitly learned through extensive navigation training on other tasks, which may not transfer well. The motivation is to directly leverage and integrate commonsense knowledge into the navigation strategy.

3. **Leveraging Pre-trained Vision-and-Language and Large Language Models:** The recent emergence and success of large pre-trained models, such as vision-and-language grounding models (e.g., GLIP) and commonsense language models (e.g., Deberta, ChatGPT), have demonstrated their ability to perform open-world understanding and robust reasoning in zero-shot settings. The motivation is to harness the inherent knowledge within these pre-trained models for semantic scene understanding (identifying objects and rooms) and for inferring spatial relationships relevant to object localization.

4. **Translating Commonsense Knowledge into Executable Actions:** A significant challenge in utilizing LLMs for embodied tasks is converting their abstract textual commonsense inferences into concrete, actionable navigation policies. Additionally, commonsense relationships are often probabilistic rather than deterministic (e.g., a book has a *high probability* of being in a living room, but it's not guaranteed). The motivation is to devise a mechanism that can effectively bridge this gap, modeling the "soft" or uncertain nature of commonsense knowledge and translating it into efficient exploration strategies.

5. **Enhancing Frontier-Based Exploration:** Traditional frontier-based exploration (FBE) methods, which guide an agent to the nearest unexplored region, can be inefficient in semantically rich environments. Such methods do not account for the likelihood of a goal object being present in a particular area. The motivation is to augment FBE with commonsense constraints, guiding the agent to prioritize frontiers that are semantically more promising for finding the goal object, thereby improving exploration efficiency and overall navigation success.

### 3. Methodology and Approach

The ESC (Exploration with Soft Commonsense constraints) framework is designed for zero-shot object navigation by integrating pre-trained vision-and-language models with commonsense reasoning through a probabilistic logic framework. The approach is structured into three main components: Open-World Semantic Scene Understanding, Commonsense Reasoning for ObjNav via LLM, and Commonsense Guided Exploration.

#### 3.1. Open-World Semantic Scene Understanding

This module is responsible for converting raw egocentric RGB images and depth observations into a semantic representation of the environment.

- **Prompt-Based Scene Grounding:** The framework utilizes GLIP (Grounded Language-Image Pre-training), a pre-trained vision-and-language model, to perform open-world object and room detection. GLIP formulates detection as a grounding problem, aligning image regions with phrases in a text prompt.
 - **Object Prompt ($P_o$):** A list of common indoor objects and all possible goal objects is concatenated into a single text prompt (e.g., "cabinet. chair. table."). GLIP processes the agent's egocentric RGB image ($I_t$) with $P_o$ to detect objects and their bounding boxes.
 - **Room Prompt ($P_r$):** Similarly, a list of common indoor rooms is used as a prompt. GLIP processes $I_t$ with $P_r$ to detect rooms and their bounding boxes.
 - This prompt-based approach allows for generalization to new objects and environments without specific model retraining.

- **Semantic Map Construction:** The detected 2D bounding boxes for objects and rooms are projected into 3D space using the depth input ($D_t$), agent's pose, and camera parameters. These 3D points are then projected onto a 2D navigation map.
 - The 2D map maintains information about detected object locations (center of bounding box projection) and room extents (all pixels in bounding box projection).
 - This map is continuously updated as the agent explores the environment, also tracking free space, obstacles, and unexplored frontiers.

#### 3.2. Commonsense Reasoning for ObjNav via LLM

This component leverages large language models to infer commonsense spatial relationships between the goal object and environmental entities.

- **LLM Inference:** Pre-trained LLMs, such as Deberta v3 or ChatGPT, are used to assess the likelihood of a goal object ($G$) being associated with specific detected objects ($o_i$) or rooms ($r_i$).
 - **Prompting:** Textual prompts are crafted for the LLM, such as "What is a GoalObject likely to be near?" or "If you want to find a GoalObject, where should you go?". The candidate objects ($o_c \cup o_g$) and rooms ($r_c$) are provided as potential answers.
 - **Score Generation:** The LLM provides real-value scores, $S(G|o_i)$ and $S(G|r_i) \in$, representing the co-occurrence likelihood or spatial relevance between the goal and other objects/rooms. These scores quantify the commonsense knowledge.

#### 3.3. Commonsense Guided Exploration

This module integrates the semantic scene understanding and commonsense reasoning with a frontier-based exploration strategy.

- **Frontier-Based Exploration (FBE):** The system identifies frontiers on the 2D navigation map. A frontier is defined as the boundary between observed free space and unexplored areas. Traditionally, FBE might select the closest frontier. ESC aims to enhance this by incorporating semantic guidance.

- **Soft Commonsense Constraints with Probabilistic Soft Logic (PSL):** To convert probabilistic commonsense knowledge from LLMs into navigation decisions, ESC employs Probabilistic Soft Logic (PSL). PSL is a declarative programming language that defines hinge-loss Markov Random Fields using first-order logical rules, capable of reasoning with continuous-valued facts and uncertainty.
 - **Logical Rules:** ESC defines four types of rules to guide frontier selection:
 1. **Object Reasoning (Positive):** `w : IsCooccur(Goal, Object) ∧ IsNearObj(Frontier, Object) → ChooseFrontier(Frontier)`
 - This rule encourages selecting a frontier if it is near an object that is likely to co-occur with the goal object. `IsCooccur` values come from LLM scores, and `IsNearObj` is derived from GLIP detections and proximity to the frontier in the semantic map.
 2. **Object Reasoning (Negative):** `w : !IsCooccur(Goal, Object) ∧ IsNearObj(Frontier, Object) → !ChooseFrontier(Frontier)`
 - This rule discourages selecting a frontier if it is near an object unlikely to co-occur with the goal.
 3. **Room Reasoning (Positive/Negative):** Similar rules are defined for rooms, encouraging/discouraging frontiers within or near rooms where the goal object is likely/unlikely to be found.
 4. **Distance Constraint:** `w : ShortDist(Frontier) → ChooseFrontier(Frontier)`
 - This rule incorporates the traditional FBE heuristic, favoring closer frontiers to the agent.
 5. **Sum Constraint (Hard):** `ChooseFrontier(+Frontier) = 1`
 - This ensures that exactly one frontier is chosen for exploration by enforcing that the sum of the probabilities of choosing all frontiers equals one.
 - **PSL Inference:** The logical rules are relaxed using Łukasiewicz continuous-valued logical semantics, creating hinge-loss potentials. PSL then solves a convex optimization problem to find the optimal truth values for the target variables (e.g., `ChooseFrontier(Frontier)`) that minimize the weighted sum of constraint violations.
 - **One-hot Constraint PSL Solver:** Instead of a general convex optimizer (ADMM), ESC uses a custom one-hot constraint solver. This solver directly calculates the violation of constraints for each possible one-hot encoding (representing the selection of a single frontier). The frontier corresponding to the one-hot encoding with the lowest loss is chosen, which is faster and aligns with the discrete nature of frontier selection.

- **Navigation Policy:**
 - The agent uses a deterministic policy to navigate to the currently chosen frontier.
 - At each step, GLIP continues to detect objects. If the goal object is detected, the agent immediately stops exploration and navigates directly to the goal object's location.
 - Once a frontier is reached, or if the current frontier becomes invalid, the PSL module is invoked again to select a new, semantically informed frontier.

### 4. Main Findings and Results

The research evaluates the ESC framework against various baselines, including zero-shot and supervised methods, across three object goal navigation benchmarks: MP3D, HM3D, and RoboTHOR. Performance is measured using Success Rate (SR) and Success Rate weighted by inverse path Length (SPL), with SoftSPL also reported in ablation studies.

#### 4.1. Result Comparison with State-of-the-Art Methods

- **Superior Zero-Shot Performance:** ESC establishes new state-of-the-art results for zero-shot object navigation.
 - On **MP3D**, ESC achieves 14.2 SPL and 28.7 SR, marking a 284% relative SPL and 288% relative SR improvement over CoW (CLIP on Wheels), which shares the same zero-shot, no-navigation-training setting.
 - On **HM3D**, ESC achieves 22.3 SPL and 39.2 SR, outperforming ZSON (which requires large-scale navigation training on HM3D) by 85% relative SPL.
 - On **RoboTHOR**, ESC achieves 22.2 SPL and 38.1 SR, demonstrating a 35% relative improvement in SPL and SR over CoW.
- **Consistent Generalizability:** Unlike other zero-shot methods (e.g., ZSON, ProcTHOR-ZS) that show inconsistent performance across different datasets due to distribution shifts, ESC consistently performs well on all three benchmarks (MP3D, HM3D, RoboTHOR). This suggests strong generalizability to diverse house styles, sizes, and object types.
- **Reduced Gap with Supervised Methods:** ESC significantly narrows the performance gap between zero-shot and supervised methods on HM3D and RoboTHOR. Notably, on the MP3D dataset, ESC's zero-shot performance (14.2 SPL) is comparable to or even surpasses previous state-of-the-art supervised methods like PONI (12.1 SPL).
- **Category-wise Performance:** Analysis on MP3D shows that ESC consistently outperforms CoW across almost all goal object categories. ESC demonstrates particular efficacy for objects with strong commonsense associations to specific rooms or other objects (e.g., 'toilet', 'bed'), where CoW often fails.

#### 4.2. Ablation Studies

- **Effect of Semantic Scene Understanding (GLIP vs. CLIP):** Replacing CLIP with GLIP for object detection in a baseline FBE (termed "GLIP on Wheels" or GoW) resulted in substantial performance gains. GoW achieved 12.4 SPL on MP3D compared to CoW's 3.7 SPL, and 21.6 SPL on RoboTHOR compared to CoW's 16.9 SPL. This demonstrates the superior open-world object grounding capability of GLIP over CLIP for this task.
- **Effectiveness of Commonsense Reasoning:** ESC, which incorporates commonsense reasoning via PSL, consistently outperforms GoW (which uses GLIP but no commonsense) across all datasets and metrics. This validates the utility of explicitly integrating commonsense knowledge beyond basic semantic scene understanding.
- **Impact of Different Levels of Commonsense Reasoning:**
 - Both object-level reasoning (ESC w/o Room) and room-level reasoning (ESC w/o Object) individually improve performance over GoW.
 - Room-level reasoning generally yielded larger improvements than object-level reasoning on MP3D and HM3D.
 - Combining both room and object reasoning (full ESC) provided the best results on MP3D (14.2 SPL) and HM3D (22.3 SPL). However, on RoboTHOR, exploration without object reasoning performed marginally better, potentially due to the more random object placement in that dataset.
- **Impact of Different LLMs:** Both Deberta v3 and ChatGPT were tested for commonsense reasoning on HM3D, showing comparable performance and significant improvements over GoW. Deberta was used as the primary LLM due to its accessibility.
- **Exploration Efficiency Analysis:**
 - ESC's chosen frontiers were, on average, closer to the actual goal object (7.6m for ESC vs. 8.2m for GoW on HM3D). This indicates that commonsense guidance leads to more semantically relevant exploration.
 - Error analysis showed that ESC significantly reduced "exploration errors" (cases where the agent never saw the goal object without getting stuck or false detection) compared to GoW (10.6% vs. 14.3% on HM3D). Both methods, however, still exhibited a high rate of "detection errors."
- **Effect of PSL Solvers:** The custom one-hot constraint PSL solver achieved slightly better performance (13.7 SPL) and significantly faster inference times (0.25 seconds) compared to a standard ADMM solver (12.9 SPL, 2.13 seconds) for frontier selection. This efficiency is critical for real-time navigation.

### 5. Significance and Potential Impact

The ESC framework represents a notable advancement in the field of embodied AI, particularly for zero-shot object navigation, and offers several significant contributions and potential impacts:

1. **Enabling Robust Zero-Shot Object Navigation:** The work establishes a new benchmark for zero-shot object navigation, demonstrating that agents can effectively navigate to novel objects in unseen environments without any navigation training data. This addresses a critical limitation of previous methods that struggled with generalization, paving the way for more adaptable and versatile embodied agents in real-world applications.

2. **Effective Integration of Commonsense Knowledge:** ESC provides a concrete methodology for extracting and leveraging commonsense knowledge from large language models and integrating it directly into an agent's navigation policy. This is a significant step towards bridging the gap between high-level human-like reasoning and low-level robotic actions, a long-standing challenge in embodied AI.

3. **Neuro-Symbolic Reasoning for Embodied AI:** The framework's combination of neural components (pre-trained VLMs and LLMs for perception and reasoning) with a symbolic logic framework (Probabilistic Soft Logic for action selection) exemplifies a successful neuro-symbolic approach. This allows for robust reasoning under uncertainty inherent in commonsense knowledge, translating fuzzy logical rules into probabilistic decision-making.

4. **Reduced Data and Training Requirements:** By operating in a training-free manner for navigation, ESC substantially reduces the computational resources, data collection efforts, and development time typically required for training embodied agents. This makes the deployment of object navigation capabilities more practical and scalable in diverse and dynamic environments.

5. **Improved Exploration Efficiency:** The integration of soft commonsense constraints into frontier-based exploration leads to more intelligent and goal-directed exploration strategies. Instead of merely seeking the nearest unexplored area, the agent prioritizes regions that are semantically more likely to contain the goal object, as inferred by commonsense, thereby enhancing navigation efficiency and success rate.

6. **Broader Applicability to Embodied Tasks:** The modular nature of ESC suggests its potential applicability beyond object navigation. The approach of combining open-world semantic perception, LLM-driven commonsense reasoning, and probabilistic logic for decision-making could be adapted to other embodied AI tasks that require intelligent exploration and contextual understanding, such as household task completion, vision-and-language navigation, or even interactive tasks where an agent needs to reason about object locations for manipulation.

7. **Future Research Directions:** The work also highlights avenues for future research, including acquiring more sophisticated spatial commonsense from LLMs (e.g., inter-room relationships), exploring the integration of this framework into other embodied tasks, and investigating strategies to relax the strict zero-shot constraint with limited fine-tuning to further optimize frontier selection policies.
