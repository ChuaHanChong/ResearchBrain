# Model-based Offline RL via Robust Value-Aware Model Learning with Implicitly Differentiable Adaptive Weighting

> [!summary] Summary
> ROMI introduces a model-based offline reinforcement learning approach that uses robust value-aware model learning and implicitly differentiable adaptive weighting to achieve controllable conservatism and stable training. The method demonstrates superior performance over RAMBO by 18.6% on D4RL MuJoCo datasets and achieves top results on NeoRL and D4RL Antmaze benchmarks, while maintaining training stability.

## Problem

- Model exploitation in model-based offline RL, where policies exploit inaccuracies in learned dynamics, particularly in Out-Of-Distribution (OOD) regions.
- Existing adversarial model learning methods, like RAMBO, exhibit hyperparameter sensitivity, training instability (e.g., gradient explosion), and over-conservatism with increased adversarial influence.
- Difficulty in precisely controlling the degree of conservatism, as fixed hyperparameters often lead to either minimal adversarial impact or severe Q-value underestimation and training collapse.

## Method

- The ==Robust Value-aware== Model Learning (**RVL**) component redefines adversarial model learning to characterize one-step value estimation error, ensuring value predictions are consistent with the minimum value over a dynamics uncertainty set. This set's scale (ξ) directly controls conservatism.
- Implicitly Differentiable Adaptive Weighting (IDAW) employs a bi-level optimization framework, using an adaptive weighting network to prioritize transitions for dynamics model updates while minimizing the robust value-aware loss.
- The overall ROMI algorithm combines the learned robust dynamics model from the bi-level optimization with Soft Actor-Critic (SAC) for policy learning, sampling from both the offline dataset and a model buffer.

## Results

- ROMI outperformed RAMBO on 11 out of 12 D4RL MuJoCo datasets, achieving a total normalized score **18.6%** higher, and showed competitive or superior performance against other state-of-the-art methods.
- The method surpassed all baselines on 6 out of 9 NeoRL datasets, achieving the highest total normalized score and consistently outperforming RAMBO across all NeoRL tasks.
- Ablation studies confirmed that adaptive weighting improved performance and reduced model prediction error during multi-step rollouts, while the uncertainty set scale (ξ) provided stable and controllable conservatism without causing training collapse.

## Takeaways

> [!tip] Key Insights
> - Minimizing the expected value over a dynamics uncertainty set defined by Wasserstein distance is theoretically equivalent to minimizing over a scale-adjustable state uncertainty set, allowing direct control of conservatism via the scale parameter ξ.
> - The implicitly differentiable adaptive weighting within a bi-level optimization effectively balances both dynamics awareness (through weighted supervised learning) and value awareness (through the robust value-aware loss) for improved OOD generalization.
> - Unlike previous methods, ROMI's design ensures controllable conservatism and stable model updates by moving away from problematic direct model gradient approaches, preventing Q-value underestimation and training instability.
