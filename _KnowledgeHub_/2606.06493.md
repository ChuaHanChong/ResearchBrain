# HANDOFF: Humanoid Agentic Task-Space Whole-Body Control via Distilled Complementary Teachers

> [!summary] Summary
> Researchers at Caltech and IHMC developed HANDOFF, a humanoid whole-body controller, that enables versatile loco-manipulation using a compact 10-dimensional task-space command interface. This controller, trained via distillation of complementary expert policies, significantly expanded the robust manipulation workspace while maintaining competitive velocity tracking on a Unitree G1 robot.

## Problem

- High-level task planners struggle to synthesize the dense, full-body kinematic references typically required by state-of-the-art whole-body controllers (WBCs).
- Generating detailed motion references often requires laborious data collection, retargeting, and feasibility filtering for each new skill, limiting planner versatility and scalability.
- Existing controllers either require dense inputs, use architectural decompositions, or abstract actions in ways that limit planner modularity, creating a gap for a truly 'planner-friendly' interface.

## Method

- A whole-body controller, **HANDOFF**, was developed that operates on a compact, explicit ==10-dimensional command vector==, including planar base velocities, root height, and bilateral pelvis-frame wrist targets.
- A ==context-based multi-teacher distillation== pipeline was used to integrate expertise from three specialized policies: a ==WBC motion-tracking teacher==, a ==locomotion teacher==, and a ==fall-recovery teacher==.
- The student policy, using a soft ==Mixture-of-Experts (MoE)== head, employs ==context-conditioned gating== and ==action-sliced KL divergence distillation== to smoothly blend these complementary behaviors into a single, unified controller.

## Results

- HANDOFF achieved a robust manipulation workspace volume of **0.31 m³** with **97.7%** feasibility, outperforming state-of-the-art WBCs like FALCON (**0.06 m³**) and SONIC (**0.26 m³**).
- It demonstrated velocity tracking errors competitive with SOTA controllers, achieving mean absolute errors of **0.06 m/s** for `v_x` and **0.06 rad/s** for `ω_z`.
- The controller was successfully deployed on a Unitree G1 humanoid robot for various natural-language-driven loco-manipulation tasks (e.g., pick-and-place, bimanual hand-off) without requiring task-specific data collection or controller fine-tuning.

## Takeaways

> [!tip] Key Insights
> - Distilling diverse, complementary expert policies (e.g., motion-tracking, locomotion, fall recovery) into a single student policy effectively enables robust and varied humanoid behaviors without explicit runtime switching.
> - A compact 10-D command interface can serve as an intuitive and effective bridge between high-level agentic planners (including VLMs) and low-level whole-body control, reducing the planning burden.
> - Context-conditioned action-sliced distillation, using continuous and discrete contextual signals, allows for dynamic blending of expert supervision across different parts of the robot's action space.
