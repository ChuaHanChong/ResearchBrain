# RT-H: Action Hierarchies Using Language

> [!summary] Summary
> RT-H structures robot control by predicting fine-grained "language motions" as an intermediate step, enabling better data sharing across diverse tasks. This approach improves robot performance and generalization while allowing for more sample-efficient human intervention using natural language.

## Problem

- Existing language-conditioned robot policies struggle with data efficiency and generalization across semantically diverse tasks.
- Traditional robot correction methods via teleoperation are often costly, non-intuitive, and sample-inefficient.
- Scaling robot learning to a wide array of real-world tasks requires better mechanisms for sharing learned behaviors.

## Method

- A single ==Vision-Language Model== (PaLI-X 55B) is used with a two-phase query mechanism for hierarchical action prediction.
- Automated extraction of language motions from robot proprioception data generates supervision without manual annotation.
- Enables human intervention by allowing users to provide language motions directly, with targeted learning that updates only the high-level policy.

## Results

- RT-H achieves a **15%** higher average success rate compared to RT-2 on diverse multi-task robot manipulation, with **20%** lower end-to-end action prediction MSE offline.
- Training with 30 episodes of language motion corrections improves RT-H's average success rate from **40%** to **63%**, outperforming teleoperated correction methods.
- The system demonstrates improved generalization to new scenes and achieves a **65%** success rate on tasks with novel objects, compared to **55%** for the baseline.

## Takeaways

> [!tip] Key Insights
> - Introducing an intermediate language-based action hierarchy can improve data sharing and generalization across diverse robot tasks.
> - Language motions are learned to be contextual and flexible, adapting their precise execution based on the visual scene and task, rather than being rigid primitives.
> - Correcting robot behavior at the level of language motions is more sample-efficient and intuitive for humans than correcting low-level actions.
