# EvoVLMA: Evolutionary Vision-Language Model Adaptation

> [!summary] Summary
> EvoVLMA, developed by the Institute of Automation, Chinese Academy of Sciences, automates the design of training-free Vision-Language Model adaptation algorithms using a two-stage, LLM-driven evolutionary framework. This system discovers algorithms that consistently outperform manually designed state-of-the-art methods in few-shot classification and domain generalization, achieving accuracy gains up to 1.91 percentage points.

## Problem

- Developing Vision-Language Model (VLM) adaptation algorithms relies heavily on manual design by human experts, a process that is time-consuming, labor-intensive, and requires specialized domain knowledge.
- Existing parameter-efficient and training-free VLM adaptation methods are predominantly human-engineered, limiting the speed and scope of innovation.
- The search space for effective VLM adaptation algorithms is vast and complex, making manual exploration inefficient.

## Method

- EvoVLMA employs a ==two-stage evolutionary algorithm== that leverages Large Language Models (LLMs) to automatically generate and refine VLM adaptation algorithm code, represented by both natural language 'thoughts' and Python 'code'.
- It decomposes the complex algorithm search problem into two sequential optimization stages: first for ==feature selection==, then for ==logits computation==, managing the expansive search space more effectively.
- Technical enhancements like low-precision code conversion, web-based parallel execution, and a process monitor ensure efficient and fault-tolerant evaluation of LLM-generated code on GPUs.

## Results

- EvoVLMA-designed algorithms consistently surpassed manually designed state-of-the-art methods (e.g., Tip-Adapter, APE, GDA) in few-shot classification, with gains up to **1.91 percentage points** in recognition accuracy.
- The automatically generated algorithms achieved superior performance on source domains and competitive, well-balanced performance on target domains (ImageNetV2, ImageNet-Sketch) for domain generalization tasks.
- Ablation studies confirmed the critical role of initializing the search with existing algorithms, the effectiveness of the two-stage optimization, and the robustness of discovered algorithms across different visual backbones (ResNet-50, ResNet-101, ViT-B/16).

## Takeaways

> [!tip] Key Insights
> - LLMs can generate creative and functional code for VLM adaptation, combining existing concepts and introducing novel terms for both feature selection and logits computation, although they can also produce impractical code.
> - A population-based evolutionary search strategy significantly outperforms individual-based iterative refinement in discovering superior algorithms, demonstrating a better balance between exploration and exploitation.
> - Sequential optimization of interdependent components (feature selection and logits computation) is more effective than attempting joint optimization, which current LLMs struggle with due to increased complexity.
