# ViT-CoMer: Vision Transformer with Convolutional Multi-scale Feature Interaction for Dense Predictions

> [!summary] Summary
> ViT-CoMer introduces a Vision Transformer backbone that integrates convolutional multi-scale feature interaction for dense prediction tasks. It leverages existing ViT pre-trained weights while achieving state-of-the-art performance, with ViT-CoMer-L reaching 64.3% AP on COCO val2017 for object detection when using DINOv2 pre-training.

## Problem

- Plain Vision Transformers (ViTs) lack inner-patch information interaction, leading to a loss of fine-grained local details necessary for dense prediction tasks.
- ViTs typically produce single-scale features, limiting their ability to handle objects at diverse scales and contexts in dense prediction.
- Adapting ViTs for dense prediction often requires costly re-pre-training of modified architectures, hindering research and application development.

## Method

- ==ViT-CoMer== employs a ==two-branch architecture== combining a plain ViT with a CNN stream, facilitating ==bidirectional feature interaction== across multiple stages.
- A ==Multi-Receptive Field Feature Pyramid (MRFP)== module enhances the CNN branch by providing rich multi-scale spatial information and expanded receptive fields.
- A ==CNN-Transformer Bidirectional Fusion Interaction (CTI)== module integrates and unifies features from both branches through multi-scale self-attention and bidirectional injection, without altering the core ViT structure or requiring re-pre-training.

## Results

- Achieved **6**4.3%** AP** on COCO val2017 for object detection with ViT-CoMer-L using DINOv2 pre-training, setting a new record without extra detection-specific training data.
- Outperformed plain ViT-S by **+**5.6%** APb** and **+**3.4%** APm** on COCO val2017, and surpassed many existing vision-specific and adapted backbones of comparable size.
- Demonstrated competitive results on semantic segmentation, with ViT-CoMer-L achieving **55.6%** MS mIoU on ADE20K, a **2.1%** improvement over Swin-L.

## Takeaways

> [!tip] Key Insights
> - Bidirectional interaction between CNN (local, multi-scale) and Transformer (global context) features effectively combines their strengths, enhancing ViTs with local and multi-scale perception.
> - Directly utilizing powerful, open-source ViT pre-trained weights while only randomly initializing new CNN-based components significantly reduces computational costs and accelerates development.
> - The MRFP module, by generating diverse receptive fields within the CNN stream, is crucial for improving plain ViT's performance in dense prediction tasks.
