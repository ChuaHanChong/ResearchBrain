# Scaling Linear Attention with Sparse State Expansion

> [!summary] Summary
> Sparse State Expansion (SSE) provides architectural enhancements for linear attention, enabling efficient long-context modeling by expanding state capacity without proportional parameter growth. This approach improves performance in tasks requiring deep contextual understanding, such as in-context retrieval and mathematical reasoning.

## Problem

- Standard Transformer attention suffers from quadratic computational and memory complexity with increasing sequence length, limiting its application to very long contexts.
- Existing linear attention models, while efficient, often experience performance degradation due to aggressive and lossy context compression into a fixed-size state.
- Achieving a balance between high modeling fidelity and computational efficiency in long-context scenarios remains a challenge for current sequence models.

## Method

- Introduces a ==row-sparse state== update formulation that reinterprets state updates as an 'information classification' problem, using softmax-based top-k selection for incoming key vectors.
- Proposes **Sparse State Expansion** (SSE) to increase contextual state capacity by partitioning the state into multiple segments while using shared attention parameters to decouple parameter count from state size.
- Develops a hierarchical write-read gating mechanism to efficiently select and optimize updates for relevant state partitions, ensuring targeted information flow.

## Results

- The **2B** SSE-H model achieved state-of-the-art mathematical reasoning performance among small reasoning models, scoring 64.5 on AIME24 and 50.2 on AIME25.
- SSE consistently and significantly outperforms other pure linear attention models (GLA, GDN) on various in-context retrieval tasks, substantially narrowing the performance gap with Transformers.
- Maintains nearly constant runtime for long sequences when the number of selected partitions is fixed, demonstrating high efficiency through its optimized varlen implementation.

## Takeaways

> [!tip] Key Insights
> - Reconceptualizing state updates in linear attention as an information classification task, where incoming keys sparsely activate specific state rows, improves state discriminability and effective receptive field.
> - Scaling linear attention's memory capacity can be achieved by decoupling the state size from the model's parameter count through state partitioning and shared projection weights.
> - Efficient parallelized implementations, like the varlen technique for long contexts, are crucial for translating theoretical efficiency gains into practical runtime benefits.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The Transformer architecture, since its introduction, has become the de facto standard for sequence modeling, particularly in natural language processing. Its success stems from the attention mechanism's ability to model long-range dependencies effectively. However, this comes at a significant cost: the computational complexity and memory usage of standard softmax attention scale quadratically with sequence length. This quadratic scaling poses a major bottleneck for processing very long contexts (e.g., hundreds of thousands or millions of tokens) during both training and inference, limiting the practical applicability of Transformers in memory-intensive or real-time scenarios.

In response to this challenge, the research community has actively explored "efficient Transformer" variants, broadly categorized into sparse attention, recurrent architectures, and various forms of linear attention or state-space models. Linear attention variants aim to reduce complexity to linear time and constant memory per token by compressing historical context into fixed-size states, often by replacing the softmax kernel with feature map dot products. While these methods achieve substantial efficiency gains, a persistent problem is their "performance degradation" compared to full softmax attention, particularly in tasks requiring fine-grained token-level information flow such as in-context retrieval and complex reasoning. This degradation is largely attributed to the inherent lossy compression of context into a small, fixed-size state, which can lead to "forgetting" or insufficient discriminative power.

This paper directly addresses this critical trade-off between modeling fidelity and computational efficiency in long-context scenarios. It positions itself as a solution to the "key question: how can context compression be designed to balance modeling fidelity and computational efficiency in long-context scenarios?" By introducing Sparse State Expansion (SSE), the authors aim to augment the capacity of the compressed contextual state without sacrificing the computational benefits of linear attention. The work builds upon existing linear attention models (like GLA, GDN, MoM) and state-space models (like Mamba) by proposing an alternative approach to context compression. Unlike many prior works that focus on refining the state transition matrix (Λt), SSE innovatively re-examines how new information (`ϕ(k_t)`) is incorporated into the state, framing it as an "information classification" problem. Furthermore, it explores hybrid architectures, a common strategy to bridge the performance gap between efficient models and full Transformers, by integrating a few softmax attention layers. The paper thereby contributes to the ongoing effort to develop highly performant, scalable, and deployable sequence models for next-generation AI applications.

### 2. Key Objectives and Motivation

The primary motivation for this research stems from the inherent limitations of current linear attention models. While these models successfully address the quadratic computational and memory costs of Transformers, they frequently suffer from performance degradation in tasks requiring deep contextual understanding, such as in-context retrieval and complex reasoning. This degradation is attributed to their aggressive compression of contextual information into a fixed-size state, which acts as a bottleneck for memory capacity and discriminative power.

The central objective of this work is to develop a more effective context compression mechanism for linear attention that can "balance modeling fidelity and computational efficiency in long-context scenarios." Specifically, the authors aim to overcome the "lossy compression" issue and enable linear models to achieve performance comparable to, or even exceeding, Transformers in challenging long-context tasks.

To achieve this, the paper sets out two key objectives:
1. **Introduce a novel, more effective state update formulation for linear attention:** This involves reconceptualizing how information is written into the fixed-size state. The authors propose an "information classification" perspective, where the key vector mapping acts as a classifier, and updates are applied sparsely based on class assignments. This is intended to achieve larger receptive fields and reduce "inter-class interference" within the compressed state.
2. **Propose an efficient state expansion mechanism within this sparse framework (Sparse State Expansion - SSE):** Recognizing that the fixed size of the state matrix is a fundamental limitation, the objective is to expand the "memory capacity" of linear attention. Critically, SSE aims to achieve this expansion by "decoupling parameter size from state capacity," meaning the model can hold more context without a proportional increase in trainable parameters.

Ultimately, the overarching goal is to demonstrate that, through these innovations, linear attention, especially in hybrid architectures, can deliver strong performance across diverse benchmarks—including language modeling, in-context retrieval, and sophisticated mathematical reasoning—while maintaining its inherent efficiency benefits for long-context scenarios.

### 3. Methodology and Approach

The proposed methodology revolves around two core innovations: a row-sparse update formulation and Sparse State Expansion (SSE), underpinned by an "information classification" paradigm and supported by efficient parallelized implementations.

#### 3.1. Row-Sparse State Update: An Information Classification Perspective

The paper reinterprets the update mechanism of linear attention, `S_t = Λ_t S_{t-1} + ϕ(k_t)ᵀv_t`, by focusing on the `ϕ(k_t)` component. Instead of uniformly updating all state rows, the key vector `k_t = f(x_t, W_k)` is conceptualized as a "classification function" that assigns incoming information (`v_t`) to specific state rows. The hypothesis is that each state row can represent a distinct feature subspace.
- **Problem Identification:** Traditional linear attention (even with non-linear `ϕ` like SiLU) updates all state rows simultaneously, leading to "inter-class mixing," noise, and information forgetting due to uniform decay. Theoretical analysis (Appendix A) supports this, showing higher row-wise cosine similarity in vanilla linear attention, indicating less discriminative states.
- **Proposed Solution:** A "softmax-based top-k hard classification" strategy is introduced.
 - The classification function `f(x_t, W_k)` is changed to `softmax(top-k(x_t W_k))`. This means only the `k` most relevant state rows (classes) are selected and updated, making the updates row-sparse.
 - This explicit hard assignment ensures that each state row stores more homogeneous information, improving inter-row discriminability and extending the effective receptive field by reducing decay on non-selected rows.
 - An auxiliary loss `L_balance` is used to encourage uniform distribution of updates across state rows, stabilizing training and improving parameter utilization.

#### 3.2. Sparse State Expansion (SSE) under the Row-Sparse Framework

To overcome the limited state capacity of linear attention (typically `c x d`, where `c` is small), SSE expands the contextual state without proportionally increasing parameter count.
- **State Partitioning:** The state is expanded into `N` partitions, effectively increasing the total number of state rows to `N × c`.
- **Shared Attention Parameters:** A crucial design choice is to use a *single set of projection weights* (QKV) across all `N` partitions. This achieves the decoupling of parameter size from state capacity. This is akin to segmented clustering of input information along the sequence dimension.
- **Write-Read Gating for Partition Selection:** Instead of applying top-k classification across all `N × c` rows, a hierarchical selection mechanism is used:
 - A gate vector `e_t ∈ R^N` is computed (`softmax(x_t W_e)`) to select the top-k partitions (`T = {i | e_i_t ∈ top-k(e_t)}`).
 - Within the *selected* partitions, `softmax(x_t W_k)` is applied for soft row selection.
 - The gate `e_t` is applied to both state input (KV) for writing and state output (Q) for reading, ensuring "targeted optimization."
- **Training Stability:** An "always-selected partition" is included, and LoRA (Low-Rank Adaptation) is applied to QK projections for this partition to stabilize sparse component training while maintaining a nearly constant parameter count.
- **Empirical Validation of State Properties:** SSE's state exhibits low inter-partition and inter-row similarity (Figure 3d) and higher singular value entropy (Figure 5) compared to baselines, indicating more diverse and efficiently utilized state representations. It also demonstrates a significantly larger receptive field (Figure 10).

#### 3.3. Efficient Implementations of SSE

To ensure practical scalability, two efficient implementations are developed:
- **Naive Masking (for short contexts):** For variable-length short sequences, activations are replicated `N` times, and top-k indices are used to mask QKV vectors to zero. This allows the use of larger, optimized chunk sizes by merging the additional dimension into batch or head dimensions for parallel processing.
- **Varlen Technique (for long contexts):** For long, uniformly distributed sequences, QKV vectors are reordered by their assigned partitions, and new `cu_seqlens` parameters are computed. This enables chunk-wise computation only on relevant tokens within each partition, avoiding redundant masked computations and maintaining nearly constant runtime when the number of selected partitions `K` is fixed.
- **Shared Partition Fusion:** Optimizes by concatenating shared partitions to avoid multiple sequential linear attention kernel calls.

#### 3.4. Evaluation Approach

SSE is rigorously evaluated in both pure linear and "hybrid" (SSE-H) architectures (where a softmax attention layer is added after every five linear layers).
- **Benchmarks:** Language modeling, in-context retrieval (real-world and synthetic RULER tasks), and mathematical reasoning (MATH500, AIME, AMC, OlympiadBench).
- **Training Regimes:** Pretraining (600M, 2B parameters on 15B/100B tokens, and 2B models on 2T tokens), long-context extension (up to 32k), distillation, and reinforcement learning (RL) using GRPO.
- **Baselines:** Standard Transformer (softmax attention), GLA, GDN, and MoM.
- **Scalability Studies:** Investigating performance with varying `N` and `K` values, and evaluating the conversion of pretrained Transformers to SSE-H.

### 4. Main Findings and Results

The extensive experimental validation across diverse tasks, model scales, and training regimes demonstrates the effectiveness and efficiency of SSE.

- **Language Modeling Performance (Table 1):** In small-scale pretraining (600M, 2B params), pure SSE-n4 shows strong commonsense reasoning performance, outperforming Transformers and matching MoM at 600M parameters. The hybrid SSE-H variant surpasses both GLA-H and Transformer baselines at the 2B scale.
- **In-context Retrieval Prowess (Tables 1, 2, 3, 4):**
 - SSE consistently and significantly outperforms other pure linear attention models (GLA, GDN) on real-world retrieval-intensive tasks (e.g., FDA, SWDE, SQuAD) at both 600M and 2B scales, narrowing the performance gap with Transformers.
 - On synthetic RULER S-NIAH tasks (Table 2), SSE demonstrates superior retrieval capabilities under controlled conditions.
 - The hybrid SSE-H variant further boosts retrieval performance, closely approaching Transformer-level accuracy, and shows strong long-context retrieval performance up to 32k tokens on various RULER tasks (Table 11 in Appendix).
 - When converting a pretrained Transformer, SSE-H achieves substantially better retrieval consistency than GLA-H, further bridging the gap with the original Transformer (Table 4).
- **State-of-the-Art Mathematical Reasoning (Table 5):**
 - The 2B SSE-H model, after supervised distillation and reinforcement learning (RL) training, achieves state-of-the-art mathematical reasoning performance among small reasoning models. It scores 64.5 on AIME24 and 50.2 on AIME25, significantly outperforming similarly sized open-source Transformers (e.g., +16.2 on AIME24 and +13.4 on AIME25 over Qwen3-1.7B).
 - Crucially, when trained with the *exact same pipeline* as a Transformer baseline, SSE-H achieves comparable reasoning results, confirming its competitive capabilities.
 - Scalability is further demonstrated by a 12B SSE-H conversion matching its softmax-attention counterpart in reasoning accuracy (Table 10 in Appendix).
- **Scalability with State Capacity (Figure 1 Right, Figure 7):** SSE demonstrates favorable scalability with respect to the number of state partitions (`n`). Recall performance improves approximately proportionally with `n` when the sparsity ratio (`k/n`) is constant. Increasing `k/n` also yields gains up to a certain threshold.
- **Efficiency:** The varlen implementation enables SSE to maintain nearly constant runtime when the number of selected partitions (`K`) is fixed, making it efficient for long sequences (Figure 6). Masking is efficient for shorter sequences.
- **Ablation Studies (Tables 6, 7, 8; Figures 5, 8, 10):**
 - **Softmax-based Row Selection:** Using softmax for `k_t` yields significantly higher recall (+6.93 recall points on average) compared to SiLU, validating the information classification concept. It also induces higher sparsity in updates (Figure 8).
 - **Write-Read Gating:** The proposed write-read gate (applied to both KV and Q) consistently outperforms alternatives (no gate, write-only, read-only), highlighting its effectiveness in partition selection.
 - **Shared Attention Parameters:** This design choice is validated as effective; a variant with separate parameters (nearly doubling non-embedding parameters) showed lower recall and marginal reasoning gains, supporting the decoupling of parameter count and state capacity.
 - **State Properties:** SSE states exhibit lower inter-row similarity (Figure 3d), higher singular value entropy (Figure 5), and larger effective receptive fields (Figure 10) compared to baselines, indicating more discriminative and effectively utilized memory.

### 5. Significance and Potential Impact

The work "Scaling Linear Attention with Sparse State Expansion" represents a significant advancement in the field of efficient long-context language modeling, with several far-reaching implications:

- **Bridging the Performance Gap for Linear Attention:** Traditionally, linear attention models have struggled to match the performance of Transformers, especially in complex tasks like in-context retrieval and reasoning. SSE effectively addresses this critical limitation. By conceptualizing state updates as information classification and introducing sparse state expansion, the paper demonstrates that efficient linear architectures can achieve comparable, and in some cases, superior performance to similarly sized Transformers, particularly in mathematical reasoning after advanced RL training. This significantly enhances the viability of linear attention as a robust alternative to Transformers.

- **Efficient Long-Context Modeling:** The ability to scale state capacity independently of parameter count is a crucial breakthrough. SSE allows for a much larger "contextual memory" without the prohibitive increase in computational and memory resources typically associated with scaling Transformer models quadratically. This is essential for scenarios demanding extremely long contexts, such as processing entire books, legal documents, or complex codebases, where quadratic attention becomes impractical. The efficient parallelized implementations (masking and varlen) ensure that these theoretical gains translate into practical speedups, making SSE highly relevant for real-world deployment.

- **Advancing AI Reasoning Capabilities with Smaller Models:** The achievement of state-of-the-art mathematical reasoning performance for a 2B model, surpassing larger open-source Transformers, is a particularly impactful result. It suggests that architectural innovations focused on memory management and sparse updates can unlock high-level reasoning capabilities in smaller, more efficient models. This has profound implications for democratizing access to advanced AI, enabling the development of powerful reasoning agents that can run on more resource-constrained hardware or be integrated into applications where large, energy-intensive Transformers are not feasible.

- **Novel Paradigm for Memory Management:** The "information classification" perspective offers a fresh theoretical framework for designing recurrent memory mechanisms. By explicitly guiding how information is assigned and retrieved from the state, SSE provides a more structured and discriminative memory system. This paradigm could inspire future research in memory-augmented neural networks, potentially leading to more interpretable and robust long-term memory solutions in AI.

- **Practical Applicability and Flexibility:** The demonstrated ability to convert pretrained Transformers into SSE-H variants with maintained performance consistency highlights the flexibility of the architecture. This allows for leveraging existing large-scale pretrained models and enhancing their long-context capabilities without requiring training from scratch, easing adoption in current research and industry pipelines.

In conclusion, SSE offers a promising and efficient architecture for high-fidelity long-context modeling. Its success in both efficiency and performance, particularly in challenging reasoning tasks, positions it as a key development in the ongoing quest for more scalable, performant, and practical large language models.
