# Scaling Linear Attention with Sparse State Expansion

> [!summary] Summary
> Sparse State Expansion (SSE) provides architectural enhancements for linear attention, enabling efficient long-context modeling by expanding state capacity without proportional parameter growth. This approach improves performance in tasks requiring deep contextual understanding, such as in-context retrieval and mathematical reasoning.

## Problem

- Standard Transformer attention suffers from quadratic computational and memory complexity with increasing sequence length, limiting its application to very long contexts.
- Existing linear attention models, while efficient, often experience performance degradation due to aggressive and lossy context compression into a fixed-size state.
- Achieving a balance between high modeling fidelity and computational efficiency in long-context scenarios remains a challenge for current sequence models.

## Method

- Introduces a ==row-sparse state== update formulation that reinterprets state updates as an 'information classification' problem, using softmax-based top-k selection for incoming key vectors.
- Proposes **Sparse State Expansion** (SSE) to increase contextual state capacity by partitioning the state into multiple segments while using shared attention parameters to decouple parameter count from state size.
- Develops a hierarchical write-read gating mechanism to efficiently select and optimize updates for relevant state partitions, ensuring targeted information flow.

## Results

- The **2B** SSE-H model achieved state-of-the-art mathematical reasoning performance among small reasoning models, scoring 64.5 on AIME24 and 50.2 on AIME25.
- SSE consistently and significantly outperforms other pure linear attention models (GLA, GDN) on various in-context retrieval tasks, substantially narrowing the performance gap with Transformers.
- Maintains nearly constant runtime for long sequences when the number of selected partitions is fixed, demonstrating high efficiency through its optimized varlen implementation.

## Takeaways

> [!tip] Key Insights
> - Reconceptualizing state updates in linear attention as an information classification task, where incoming keys sparsely activate specific state rows, improves state discriminability and effective receptive field.
> - Scaling linear attention's memory capacity can be achieved by decoupling the state size from the model's parameter count through state partitioning and shared projection weights.
> - Efficient parallelized implementations, like the varlen technique for long contexts, are crucial for translating theoretical efficiency gains into practical runtime benefits.
