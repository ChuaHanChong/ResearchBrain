# Learning with pyCub: A Simulation and Exercise Framework for Humanoid Robotics

> [!summary] Summary
> A Python-based simulation and exercise framework, pyCub, enables accessible learning of humanoid robotics fundamentals for the iCub robot by abstracting complex C++ and YARP middleware dependencies. The platform allows students to directly engage with core robotics concepts through hands-on exercises and demonstrates real-time simulation performance on standard hardware.

## Problem

- Existing robotics education tools, particularly for humanoid robots like iCub, often present high barriers to entry due to complex C++ programming and middleware requirements.
- Students using previous iCub simulation environments reported difficulties with system setup and troubleshooting, diverting focus from core robotics principles.
- There was a recognized need for more accessible, hands-on simulation and exercise frameworks to complement theoretical humanoid robotics textbooks.

## Method

- Developed pyCub, a Python-centric simulation framework for the iCub humanoid robot, utilizing the PyBullet physics engine and a custom Open3D-based GUI.
- Implemented a detailed iCub model including simulated eye cameras and over 4000 tactile sensors for artificial skin feedback, offering customizable features via YAML configurations.
- Created a suite of scalable educational exercises, ranging from basic robot control (joint and Cartesian) to advanced tasks like gaze control, reactive tactile-based interaction, and vision-guided grasping.

## Results

- The pyCub simulation achieved real-time factors sufficient for educational use (e.g., approximately **0.95**-**1.46** with GUI and skin on an average laptop, and up to **10.82** with a simplified model without skin on a workstation).
- Course evaluations demonstrated a reduction in reported system complexity and an improved focus on core robotics concepts among students compared to previous C++/YARP-based approaches.
- Students exhibited higher engagement and creativity in solving exercises, with the framework and its associated exercises made publicly available as an open-source resource.

## Takeaways

> [!tip] Key Insights
> - Abstracting complex middleware and language dependencies (C++, YARP) into a Python-only environment significantly lowers the technical barrier for students in humanoid robotics education.
> - A well-designed simulation with customizable features, including sensory feedback like artificial skin and cameras, can provide a rich and engaging platform for learning advanced robotics concepts.
> - Structured educational exercises, coupled with an intuitive simulation framework, effectively redirect student attention from software infrastructure to the fundamental principles of robot control, perception, and interaction.
