# Composition of Memory Experts for Diffusion World Models

> [!summary] Summary
> The Composition of Memory Experts (CoME) framework enhances diffusion-based world models by distributing memory functions across specialized experts to improve temporal consistency and scalability. This approach leads to improved perceptual quality, with LPIPS reducing to 0.097 on the Memory Maze dataset, and better planning accuracy, achieving an Absolute Trajectory Error (ATE) of 0.96 on the RECON benchmark, while operating at a fraction of the computational cost of monolithic architectures.

## Problem

- Existing world models struggle with a fundamental memory trade-off, where high-fidelity architectures (e.g., Transformers) incur quadratic computational costs for long contexts, while efficient ones (e.g., recurrent networks) lose detail over time.
- Maintaining robust cross-time consistency over long temporal horizons is challenging for future state prediction, hindering reliable planning and decision-making in reinforcement learning.
- Scaling context length naively for a single model is computationally prohibitive, leading to escalating training costs, instability, and impractical inference budgets.

## Method

- A diffusion-based world model framework, ==Composition of Memory Experts== (**CoME**), is introduced to decouple future-past consistency by distributing memory functions across specialized experts.
- Three distinct memory experts are instantiated: Short-Term Memory (STM) for local dynamics, Long-Term Memory (LTM) for episodic history via test-time finetuning with LoRA adapters, and Spatial Long-Term Memory (SLTM) for geometric coherence.
- A novel Product of Contrastive Experts (PoCE) formulation is developed to combine heterogeneous experts, effectively suppressing spurious distribution modes while preserving diversity and sharpening consensus.

## Results

- CoME achieved superior consistency and perceptual quality, evidenced by an LPIPS of **0.097**, SSIM of **0.892**, and PSNR of 23.07 on the Memory Maze dataset, outperforming a base Diffusion Transformer (LPIPS **0.209**, SSIM **0.771**, PSNR 19.16).
- The framework improved navigation planning accuracy on the RECON benchmark, yielding an Absolute Trajectory Error (ATE) of **0.96** and Relative Pose Error (RPE) of **0.28**, surpassing existing navigation models.
- CoME demonstrated computational efficiency by achieving comparable or superior consistency at a fraction of the training and inference costs compared to brute-force scaling methods (e.g., a full-attention baseline requiring **60x** more training compute).

## Takeaways

> [!tip] Key Insights
> - Distributing memory functions across specialized experts can overcome the inherent memory trade-off in world models, enabling scalable and temporally consistent long-horizon predictions.
> - The Product of Contrastive Experts (PoCE) formulation provides a principled method for fusing heterogeneous memory experts, addressing the limitations of naive PoE by preventing mode collapse and preserving diversity.
> - Lightweight test-time finetuning using LoRA adapters for Long-Term Memory (LTM) efficiently injects episodic knowledge into diffusion models, allowing constant-time reuse of past experience without catastrophic forgetting or significant computational overhead.
