# DART: Learning-Enhanced Model Predictive Control for Dual-Arm Non-Prehensile Manipulation

> [!summary] Summary
> The DART framework enables dual-arm robotic systems to precisely manipulate objects on a tray using non-prehensile techniques, integrating Model Predictive Control with learning-enhanced dynamics models. It demonstrates superior performance, including faster settling times and low steady-state errors (e.g., down to 2mm accuracy), and robust generalization across diverse object geometries, masses, and friction coefficients in simulation.

## Problem

- Current robotic manipulation largely depends on grasping, limiting handling of large, fragile, or awkwardly positioned objects.
- Dual-arm non-prehensile manipulation on a shared tray presents significant challenges due to dynamic arm coupling and uncertain object-tray dynamics.
- Accurately modeling the complex, varying dynamics between a tray and free-sliding objects (friction, inertia, contact) is difficult, hindering robotic adaptability.

## Method

- A two-layer **DART** framework integrating a high-level ==Model Predictive Control== (MPC) for object trajectory generation with a low-level optimization-based dual-arm impedance controller.
- MPC computes optimal tray tilt trajectories, using desired end-effector poses derived for the dual arms.
- Three distinct dynamics models are evaluated within the MPC for object-tray interaction: a physics-based model (PMPC), an online regression model (RMPC), and a reinforcement learning model (LMPC).

## Results

- The LMPC variant achieved the shortest settling times (e.g., **0.82** s for a 2kg sphere) and generally lowest steady-state errors (e.g., **0.0026** m for a 1kg cylinder), demonstrating superior performance for rapid object repositioning.
- LMPC and RMPC exhibited superior generalization capabilities across 18 diverse object configurations (varying mass, geometry, and friction) compared to PMPC, which relied on accurate, object-specific physical parameters.
- While LMPC had higher control effort, RMPC showed lower effort for lighter objects and online adaptation, whereas PMPC provided consistent but moderate effort with variable performance depending on object contact dynamics.

## Takeaways

> [!tip] Key Insights
> - The DART framework pioneers dual-arm non-prehensile tray manipulation, addressing complexities of bimanual coordination and contact-rich object handling on a shared surface.
> - Evaluating physics-based (PMPC), online regression (RMPC), and reinforcement learning (LMPC) dynamics models reveals LMPC achieves the fastest settling times and lowest errors, while RMPC offers online adaptability.
> - Learning-enhanced models (LMPC and RMPC) significantly improve generalization across diverse object properties compared to purely physics-based approaches.
