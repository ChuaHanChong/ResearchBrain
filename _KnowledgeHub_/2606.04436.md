# 3DThinkVLA: Endowing Vision-Language-Action Models with Latent 3D Priors via 3D-Thinking-Guided Co-training

> [!summary] Summary
> 3DThinkVLA equips Vision-Language-Action (VLA) models with latent 3D priors through a 3D-thinking-guided co-training framework, allowing them to perform implicit 3D spatial reasoning from 2D images. This method achieves state-of-the-art performance with 98.7% average success on the LIBERO benchmark and robust generalization on LIBERO-Plus and real-world tasks, without requiring external 3D sensors at inference.

## Problem

- VLA models typically rely on 2D visual inputs, leading to a gap between 2D semantic understanding and the 3D spatial reasoning needed for physical interaction.
- Previous methods for injecting 3D information often require specialized external 3D sensors, modify pre-trained VLM backbones, or fail to provide high-level spatial reasoning (e.g., object localization, relative orientation).
- Co-training with 3D data can suffer from a "prompt-induced reasoning gap," where action-prediction prompts bypass learned spatial priors, defaulting to "action shortcuts" instead of leveraging 3D understanding.

## Method

- A co-training framework simultaneously trains a VLA model on action data and real-world 3D reasoning data, disentangling 3D geometry perception and spatial reasoning into distinct ==latent== representations.
- A latent 3D geometry perception module uses a lightweight adapter to align intermediate visual features from the VLM with 3D geometric features from a 3D foundation model in a patch-level manner.
- An online 3D reasoning distillation module transfers high-level spatial thinking from a teacher's explicit 3D reasoning prompts to the student's action prompts via a shared reasoning anchor token in latent space, mitigating the prompt-induced reasoning gap.

## Results

- Achieved state-of-the-art (SOTA) performance on the LIBERO benchmark with an average success rate of **98.7%**, including **100%** success in LIBERO-Spatial and LIBERO-Object suites.
- Demonstrated robust generalization on the LIBERO-Plus benchmark, achieving an **81.0%** average zero-shot success rate across various perturbations (e.g., Camera, Robot, Language, Layout).
- Outperformed previous methods in real-world evaluations on a Realman robot, showing robust performance (**88.0%** for height variation, **93.3%** for transparent container placement) on challenging manipulation tasks requiring 3D spatial understanding.

## Takeaways

> [!tip] Key Insights
> - 3D geometry perception (low-level) and 3D spatial reasoning (high-level) are distinct capabilities that can be effectively disentangled and injected at different feature hierarchies within a VLA model.
> - A shared reasoning anchor token in latent space can effectively distill high-level 3D spatial reasoning from explicit prompts to action-prediction prompts, ensuring spatial understanding is utilized during action execution without explicit Chain-of-Thought text generation.
> - Directly incorporating disentangled geometric and reasoning features into the action-query token (spatially augmented action integration) prevents "action shortcuts" and fully leverages learned spatial knowledge for robust action prediction.
