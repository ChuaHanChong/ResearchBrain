# TextGrad: Automatic "Differentiation" via Text

> [!summary] Summary
> TextGrad treats an AI system as a computation graph and backpropagates natural-language feedback from LLMs to improve its variables, such as prompts, code, solutions or molecules. It copies PyTorch's abstractions and needs no per-task tuning. It raises GPT-4o on Google-Proof QA from 51% to 55%, gives a 20% relative gain on LeetCode Hard, and improves prompts, molecule design and radiotherapy plans.

## Problem

- Compound AI systems that chain LLMs, tools and simulators are mostly hand-crafted by domain experts and tuned by heuristics, with no principled automated way to optimize them.
- Backpropagation and automatic differentiation need differentiable components, so they cannot pass gradients through black-box parts such as LLM API calls, search engines or external solvers.
- Earlier textual-feedback and prompt-optimization methods were narrow, often tied to single-prompt tuning or a specific domain, and lacked a general graph-based abstraction for arbitrary variables and tasks.

## Method

- Any system becomes a ==computation graph== of variables, the inputs and outputs of function calls, and each variable carries a ==role description== so the LLM knows what to improve.
- A fixed ==LLM-based gradient operator== returns critical ==natural-language feedback== on a variable, given the variable, its downstream output and that output's own feedback, chained backward through the graph like the ==chain rule==.
- **Textual Gradient Descent** takes a variable plus its collected feedback and asks an LLM to rewrite it. The API mirrors ==PyTorch==: Variable, loss, backward, step, with ==minibatch== and ==test-time== use.

## Results

- On LeetCode Hard with GPT-4o, TextGrad reaches a **0.36** completion rate with zero demonstrations, versus **0.31** for Reflexion and **0.26** for zero-shot, about a **20%** relative gain over the best baseline.
- Test-time solution refinement lifts GPT-4o from **51.0%** to **55.0%** on GPQA, from **85.7%** to **88.4%** on MMLU Machine Learning, and from **91.2%** to **95.1%** on MMLU College Physics.
- Optimizing the GPT-3.5 system prompt with GPT-4o feedback lifts Object Counting from **77.8%** to **91.9%**, beating DSPy's **84.9%**. It ties DSPy on GSM8k at **81.1%** and on Word Sorting at **79.8%**.

## Takeaways

> [!tip] Key Insights
> - Natural-language critiques can stand in for gradients wherever components are non-differentiable, so one domain-agnostic feedback operator works across code, prompts, molecules and treatment plans with no framework changes.
> - A stronger model's feedback can improve a cheaper model's prompt once, at a fixed cost, so a weaker model can be pushed toward stronger-model accuracy at low inference cost.
> - Instruction optimization and few-shot demonstration selection are complementary: adding DSPy demonstrations to TextGrad's optimized prompt raised GSM8k from 81.1% to 82.1%, so the two approaches can be combined.

## Detailed Report

### 1. Introduction

Modern artificial intelligence is increasingly built as compound systems composed of multiple large language models (LLMs) and specialized tools working together to solve complex tasks. While these systems offer tremendous capabilities, optimizing them remains challenging, often relying on manual tweaking by experts.

This paper introduces TextGrad, a novel framework that performs "automatic differentiation via text" to optimize compound AI systems. Just as backpropagation revolutionized neural network training, TextGrad aims to transform how we optimize AI systems by using LLMs to generate natural language feedback that guides improvements across all system components.

### 2. Background and Motivation

The success of deep learning can be largely attributed to automatic differentiation (AD) and backpropagation, which allow efficient computation of gradients for optimizing neural networks. Before these techniques, neural networks were difficult to train at scale, requiring manual derivation of gradients or inefficient numerical approximations.

Modern AI systems face similar challenges. They often combine multiple components including:
- Large language models
- External tools and APIs
- Domain-specific simulators
- Database queries and search engines

Optimizing these systems traditionally requires:
1. Manual experimentation with different prompts and parameters
2. Expert knowledge to tune system components
3. Bespoke heuristics that may not generalize well

TextGrad draws inspiration from automatic differentiation but adapts it to work with complex, non-differentiable AI systems where many components are "black boxes." Instead of numerical gradients, TextGrad uses LLMs to generate textual feedback describing how to improve each component.

### 3. The TextGrad Framework

TextGrad transforms AI systems into computation graphs where:
- Variables represent inputs and outputs of function calls
- Edges represent information flow between components
- Functions can be complex operations like LLM API calls, simulators, or external tools

The key innovation is the introduction of textual gradients and a gradient operator (∇LLM) for LLM calls:

```python
# The gradient operator returns natural language feedback
gradients = ∇LLM(variable, objective)
```

This operator instructs an LLM to provide feedback on how to modify a variable to improve performance on an objective function. The objective function can be:
- A natural language description of desired outcomes
- Unit test results for code
- Simulation-based metrics (e.g., binding affinity for molecules)
- Task-specific evaluation metrics

For example, in molecule design, the gradient operator might return:
> "Introduce functional groups that can form hydrogen bonds or hydrophobic interactions"

The framework supports two optimization modes:
1. **Instance Optimization**: Improving a specific solution (e.g., a particular molecule or code snippet)
2. **Prompt Optimization**: Finding a prompt that improves LLM performance across multiple queries

### 4. Textual Gradient Descent

After obtaining textual gradients, TextGrad applies them to update variables in a process analogous to gradient descent:

```python
# Pseudocode for Textual Gradient Descent
def textual_gradient_descent(variable, objective, steps=5):
    for i in range(steps):
        gradients = ∇LLM(variable, objective)
        variable = apply_gradients(variable, gradients)
        # Evaluate new variable against objective
    return variable
```

The `apply_gradients` function uses an LLM to modify the variable based on the textual feedback. This process continues iteratively until performance converges or a maximum number of steps is reached.

TextGrad implements several optimization techniques inspired by numerical optimization:

1. **Minibatch TGD**: Applies gradients computed on subsets of examples
2. **Constrained Optimization**: Incorporates natural language constraints (e.g., "the molecule must be soluble in water")
3. **Momentum**: Maintains a memory of previous gradient directions
4. **Learning Rate Scheduling**: Adjusts how aggressively to apply gradients in each iteration

### 5. Applications

TextGrad demonstrates impressive versatility across various domains:

#### 5.1. Drug and Molecule Design

TextGrad can design drug-like molecules with specific properties:

```python
# Example of molecule optimization
molecule = tg.Variable("benzene")
objective = tg.TextLoss("Maximize binding affinity to PPARA while maintaining drug-likeness")
optimizer = tg.TGD([molecule], learning_rate=0.5)
for _ in range(5):
    loss = objective(molecule)
    loss.backward()
    optimizer.step()
```

Starting from simple molecules like benzene or pentane, TextGrad progressively improves binding affinity while maintaining drug-likeness:

The optimized molecules often include functional groups similar to known drugs targeting the same proteins, despite TextGrad having no explicit knowledge of these existing drugs.

#### 5.2. Radiation Treatment Planning

TextGrad can optimize radiation treatment plans for cancer therapy, balancing:
- Delivering sufficient radiation to tumor targets (PTV)
- Minimizing radiation to sensitive organs (bladder, rectum)

TextGrad provided specific feedback such as:
> "The current plan does not meet the criteria for the PTV. The constraints on OARs are currently being met. Recommendation: Increase the importance weight for the PTV."

Over multiple iterations, TextGrad improved the treatment plan to meet clinical goals better than radiation oncologist-designed plans in specific metrics.

#### 5.3. Code Optimization

TextGrad can improve code by identifying and fixing bugs or inefficiencies:

```python
# Example of buggy code
code = """
for i in range(n):
    if nums[i] < k:
        balance = -1
    elif nums[i] > k:
        balance += 1
    if nums[i] == k:
        result += count.get(balance, 0)
    else:
        count[balance] = count.get(balance, 0) + 1
"""

# TextGrad identifies the issue and provides a fix
gradients = "Handling `nums[i] == k`: The current logic does not correctly handle the case when `nums[i] == k`. The balance should be reset or adjusted differently when `k` is encountered..."
```

TextGrad improved GPT-4o's performance on LeetCode problems by 20% and enhanced zero-shot accuracy on Google-Proof Question Answering from 51% to 55%.

#### 5.4. Prompt Optimization

TextGrad can optimize prompts to improve LLM performance on specific tasks:

```python
# Initial prompt
prompt = "You will answer a reasoning question. Think step by step."

# After TextGrad optimization
optimized_prompt = "You will answer a reasoning question. List each item and its quantity in a clear and consistent format, such as '1. Item: Quantity'. Sum the values directly from the list and provide a concise summation. Ensure the final answer is clearly indicated in the format: 'Answer: $VALUE' where VALUE is a numerical value. Verify the relevance of each item to the context of the query and handle potential errors or ambiguities in the input. Double-check the final count to ensure accuracy."
```

This optimization improved GPT-3.5's accuracy on reasoning tasks from 77.8% to 91.9%, bringing it closer to GPT-4's performance.

### 6. Results and Evaluation

TextGrad demonstrated significant improvements across multiple domains:

1. **Drug Discovery**: Generated molecules with 3-4× better binding affinity than initial molecules while maintaining drug-likeness properties. Some designed molecules showed structural similarity to FDA-approved drugs for the same targets.

2. **Radiation Therapy**: Achieved treatment plans meeting clinical goals while reducing radiation to organs at risk (17.18 Gy vs. 23.88 Gy for rectum exposure compared to oncologist plans).

3. **Code Optimization**: Improved GPT-4o performance by 20% on difficult coding problems and enhanced zero-shot accuracy on question-answering tasks.

4. **Prompt Engineering**: Increased GPT-3.5's accuracy on reasoning tasks by 14.1 percentage points, significantly closing the gap with GPT-4.

These results demonstrate TextGrad's ability to optimize diverse AI systems without requiring domain-specific heuristics or expert knowledge.

### 7. Limitations and Future Work

While TextGrad shows promising results, several limitations and future directions remain:

1. **Exploration vs. Exploitation**: Like gradient-based methods, TextGrad may converge to local optima. Future work could implement analogues of exploration strategies used in reinforcement learning.

2. **Evaluation**: For domains like molecule design, additional wet-lab validation is needed to confirm computational predictions.

3. **Tool Integration**: Extensions to support more complex LLM applications with tool use and retrieval-augmented generation.

4. **Theoretical Framework**: Exploring deeper connections between numerical optimization and TextGrad could yield new insights and improvement techniques.

5. **Computational Efficiency**: Current implementations require multiple LLM calls, which can be computationally expensive. Techniques to reduce this overhead would be valuable.

### 8. Conclusion

TextGrad represents a significant advance in optimizing compound AI systems by introducing "automatic differentiation via text." By using LLMs to generate natural language feedback on how to improve system components, TextGrad enables systematic optimization of complex, non-differentiable systems.

The framework demonstrates impressive versatility across domains from drug discovery to code optimization, often achieving results comparable to or better than human experts. TextGrad provides a principled approach to optimization that could accelerate the development of next-generation AI systems.

As compound AI systems become more prevalent in solving real-world problems, frameworks like TextGrad will be essential for unlocking their full potential. The open-source release of TextGrad aims to foster further research and development in this promising direction.
