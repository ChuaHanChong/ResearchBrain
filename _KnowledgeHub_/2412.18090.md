# Multi-Point Positional Insertion Tuning for Small Object Detection

> [!summary] Summary
> Goto et al. introduce Multi-Point Positional Insertion (MPI) tuning, a parameter-efficient fine-tuning method that enhances small object detection by strategically injecting positional information at multiple points within frozen pre-trained models. The method achieves competitive mean average precision on the challenging SODA-D dataset with significantly fewer trainable parameters, for instance, yielding 39.7% mAP with only 1.34M parameters using a Swin-B backbone.

## Problem

- Small object detection remains challenging due to limited visual information and insufficient resolution of small targets.
- Fine-tuning large pre-trained vision-language models for specific tasks like small object detection is computationally expensive and memory-intensive.
- Precise positional information, critical for detecting small objects, can be lost or inadequately represented within the general features of large models.

## Method

- Introduces ==Multi-Point Positional Insertion (MPI) tuning==, a parameter-efficient fine-tuning (PEFT) method specifically for small object detection.
- The core of MPI tuning is the ==Multi-Head Positional (MHP) encoder==, which uses sinusoidal positional embeddings, tiny MLPs, and a multi-head mixer to generate positional representations.
- MHP encoders are strategically inserted at multiple points within a frozen pre-trained model (e.g., Grounding DINO's BERT, Swin Transformer, ==Feature Enhancer==, and Decoder components) to maintain spatial awareness throughout the network.

## Results

- MPI tuning achieves comparable mean average precision (mAP) to conventional PEFT methods on the SODA-D dataset while using significantly fewer trainable parameters.
- For the Swin-B backbone, MPI tuning attains a **39.7%** mAP with **1.34M** trainable parameters, outperforming CoOp (**39.2%** mAP with 8.07M params) and showing comparable performance to VPT (**40.0%** mAP with 7.54M params).
- Qualitative results demonstrate MPI tuning's ability to detect extremely small objects, such as distant vehicles or small animals, which are frequently missed by zero-shot detection models.

## Takeaways

> [!tip] Key Insights
> - Injecting explicit positional information at multiple points throughout a frozen network effectively enhances small object detection without requiring full model fine-tuning.
> - The Multi-Head Positional (MHP) encoder, comprising sinusoidal embeddings, tiny MLPs, and a multi-head mixer, efficiently integrates spatial context into latent features with a low parameter count.
> - Strategic placement of these positional encoders, particularly within the feature enhancer block, is crucial for improving spatial awareness and localization precision for small objects.
