# Active Learning via Vision-Language Model Adaptation with Open Data

> [!summary] Summary
> Active Learning with Open Resources (ALOR) enhances active learning by integrating open-source Vision-Language Models with their vast pretraining datasets. The framework significantly improves data efficiency, achieving state-of-the-art performance with approximately 7.2% higher accuracy over baselines by adopting contrastive tuning and a novel tail-first sampling strategy.

## Problem

- Minimizing the high costs and efforts associated with manual data labeling for specific downstream tasks in active learning.
- Underutilization of the massive open pretraining datasets (e.g., LAION-400M) of Vision-Language Models (VLMs) in existing VLM-based active learning methods.
- A prevalent assumption that prompt tuning is the most suitable VLM adaptation strategy for active learning, potentially limiting performance.
- Addressing inherent biases and long-tailed distributions within real-world and retrieved data, which can hinder fair and robust model performance.

## Method

- Introduces ==Active Learning with Open Resources (ALOR)==, a framework integrating ==Retrieval-based Data Augmentation (RDA)== and ==Tail First Sampling (TFS)==.
- Employs RDA to augment limited labeled data with relevant examples from VLM pretraining datasets via efficient string-matching and filtering, with hard-capping to balance retrieved data.
- Proposes TFS, an active learning strategy that prioritizes selecting highly uncertain examples from underrepresented "tail" classes identified through pseudo-labeling.
- Rigorously evaluates VLM adaptation strategies in active learning contexts, identifying ==Contrastive Tuning (CT)== as the superior approach over Prompt Tuning (PT), Linear Probing (LP), and Finetuning (FT).

## Results

- Retrieval-based Data Augmentation (RDA) consistently boosted performance, achieving **1.7 times** higher accuracy in Round-0 and over **8%** accuracy gains in subsequent rounds for all active learning methods.
- Tail First Sampling (TFS) consistently outperformed all other state-of-the-art active learning baselines when VLM adaptation was performed via prompt tuning.
- Contrastive Tuning (CT) proved to be the superior VLM adaptation approach, outperforming all other strategies across initial low-data regimes and subsequent active learning rounds.
- The full ALOR framework, combining CT, RDA, and TFS, achieved state-of-the-art performance with average accuracy gains of approximately **+7.2%** over strong baselines across five benchmark datasets.

## Takeaways

> [!tip] Key Insights
> - Open pretraining data of Vision-Language Models is a valuable, underutilized resource that can universally and significantly boost active learning performance.
> - Contrastive Tuning (CT) is a more effective VLM adaptation strategy for active learning than Prompt Tuning (PT), challenging existing assumptions about lightweight adaptation in limited-data scenarios.
> - Explicitly addressing data imbalance by prioritizing sampling from underrepresented 'tail' classes, guided by insights from retrieved data, is critical for improving overall model robustness and performance.
