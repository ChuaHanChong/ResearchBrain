# ATPO: Adaptive Tree Policy Optimization for Multi-Turn Medical Dialogue

> [!summary] Summary
> Researchers developed Adaptive Tree Policy Optimization (ATPO), an uncertainty-aware reinforcement learning algorithm employing adaptive tree search within a Hierarchical Markov Decision Process for multi-turn medical dialogue. The method enabled a Qwen3-8B model to achieve 0.92% higher accuracy than GPT-4o on the MedQA benchmark, demonstrating enhanced information-gathering capabilities.

## Problem

- Current large language models struggle with multi-turn information gathering in medical dialogues, often failing to proactively ask clarifying questions necessary for accurate assessment.
- Existing reinforcement learning approaches for multi-turn interactions face limitations such as poor long-horizon credit assignment (GRPO) and unstable value estimation (PPO).
- Prior tree-based reinforcement learning methods for LLMs are largely token-level and single-turn focused, making them unsuitable for turn-level macro-action decisions in complex dialogues.

## Method

- Develops ==Adaptive Tree Policy== Optimization (**ATPO**), an reinforcement learning algorithm that frames multi-turn dialogue as a Hierarchical Markov Decision Process (H-MDP).
- Implements an adaptive tree search mechanism that prioritizes dialogue paths with high uncertainty for expansion to improve exploration efficiency.
- Guides tree expansion and pruning using a composite uncertainty metric, combining Bellman error for critic accuracy and action-value variance for sampling diversity.

## Results

- ATPO-trained Qwen3-**8B** achieved **0.92%** higher accuracy than GPT-4o on the MedQA benchmark, outperforming strong baselines across multiple datasets.
- The algorithm demonstrated superior sample efficiency, converging faster and requiring fewer training turns compared to previous tree-based methods like TreePO.
- Models trained with ATPO maintained consistent performance when evaluated with an unseen user simulator, indicating robust generalization capabilities.

## Takeaways

> [!tip] Key Insights
> - Modeling multi-turn dialogue as a Hierarchical Markov Decision Process (H-MDP) allows for explicit management of turn-level macro-actions and token-level micro-actions, enhancing decision-making.
> - An adaptive tree search guided by a composite uncertainty metric significantly improves exploration efficiency and sample diversity in complex multi-turn dialogues.
> - Normalizing policy updates by visit count and response length, combined with efficient computational strategies like KV cache reuse, is crucial for stable and scalable tree-based reinforcement learning with LLMs.
