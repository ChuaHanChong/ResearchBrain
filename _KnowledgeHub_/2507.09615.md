# Towards Fine-Grained Adaptation of CLIP via a Self-Trained Alignment Score

> [!summary] Summary
> A framework called Fine-grained Alignment and Interaction Refinement (FAIR) enhances the performance of Vision-Language Models like CLIP in unsupervised fine-grained classification by introducing a learned alignment score and adaptively refining cross-modal interactions. The approach achieved an average accuracy gain of 2.78% over the prior state-of-the-art, DPA, across 13 fine-grained datasets.

## Problem

- Pretrained Vision-Language Models (VLMs) like CLIP struggle with fine-grained classification due to their reliance on global features and generic text prompts, failing to capture subtle visual distinctions.
- Acquiring labeled data for fine-grained domains is often costly or infeasible, necessitating effective unsupervised adaptation (UA) methods.
- Existing UA methods use fixed alignment scores, limiting their adaptability to evolving class distinctions, or computationally expensive localized feature processing for pseudo-labeling.

## Method

- Introduces ==Fine-grained Alignment and Interaction Refinement (FAIR)==, an unsupervised adaptation framework for CLIP that dynamically aligns localized image features with adaptive language embeddings.
- Employs ==learnable Class Description Anchors (CDAs)== initialized by an LLM, which adapt concurrently with the image encoder during self-training to capture evolving class semantics.
- Utilizes ==selective crop relevance weighting== to choose only the top-k most informative localized image crops, significantly reducing computational cost while enhancing local feature utilization.
- Integrates a ==confidence-adjusted weighting mechanism== during self-training to refine pseudo-labels, especially for visually similar classes, thereby mitigating ambiguity.

## Results

- FAIR improved average classification accuracy by **2.78%** across **13** fine-grained datasets compared to the state-of-the-art DPA, and by over **9%** compared to zero-shot CLIP and CuPL.
- The framework achieved a notable performance of **91.92%** accuracy on the EuroSAT dataset, significantly outperforming DPA's **79.94%**, demonstrating strong capability in distinguishing highly similar classes.
- FAIR exhibited computational efficiency, achieving competitive performance with only **45.1K** trainable parameters (for ViT-B/32 on EuroSAT) and faster convergence (**15** epochs), while also outperforming prior methods in transductive settings.

## Takeaways

> [!tip] Key Insights
> - Dynamically learning and adapting class representations through a Learned Alignment Score (LAS) is critical for capturing fine-grained distinctions, contributing a 7.04% performance boost.
> - Refining pseudo-labels with an adaptive confidence-adjusted weighting mechanism significantly enhances self-training robustness by 1.84%, particularly for ambiguous fine-grained classes.
> - Selectively weighting and utilizing only the most relevant localized image crops ([CLS]-based top-k selection) provides a computationally efficient way to leverage fine-grained visual cues.
> - Parameter-efficient fine-tuning of only layer normalization weights and Class Description Anchors enables competitive performance with a small number of trainable parameters.
