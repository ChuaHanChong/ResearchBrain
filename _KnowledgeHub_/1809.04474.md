# Multi-task Deep Reinforcement Learning with PopArt

> [!summary] Summary
> A multi-task deep reinforcement learning agent from DeepMind leverages PopArt normalization within the IMPALA architecture to surpass median human performance across all 57 Atari games and achieve state-of-the-art results on DeepMind Lab-30. The approach adaptively normalizes value targets, stabilizing learning across tasks with vastly different reward scales without altering the objective.

## Problem

- Multi-task reinforcement learning agents struggled with tasks having vastly different reward scales and densities, leading to "task saliency" where certain tasks disproportionately influence learning.
- Previous multi-task RL systems, even scalable ones like DeepMind's IMPALA, failed to match the performance of single-task agents when evaluated against human benchmarks across a diverse set of tasks.
- Heuristic solutions like reward clipping alter the agent's objective and do not adapt to non-stationarity in rewards due to evolving agent competence.

## Method

- ==Integrates PopArt== (Preserving Outputs by Adaptive Rescaling of Targets) normalization into the distributed Importance Weighted Actor-Learner Architecture (IMPALA).
- Re-parameterizes the value estimate for each task as a linear transformation of a normalized network output, where task-specific mean (μ\muμ) and standard deviation (σ\sigmaσ) statistics are updated online.
- Utilizes an output-preserving property by simultaneously adjusting the final network layer's parameters when μ\muμ and σ\sigmaσ update, ensuring the unnormalized value prediction remains consistent while normalized targets become stationary.

## Results

- Achieved **110.7%** median human-normalized score on Atari-57 with reward clipping and **107.0%** with unclipped rewards, becoming the first single policy to surpass median human performance across all 57 games.
- Attained a mean capped human-normalized score of **72.8%** on the DeepMind Lab-30 benchmark, significantly outperforming an improved IMPALA baseline.
- Demonstrated enhanced data efficiency when combined with an auxiliary task (Pixel Control), matching final performance with approximately 2 billion frames, a substantial reduction from 10 billion frames for PopArt-IMPALA alone.

## Takeaways

> [!tip] Key Insights
> - Adaptive normalization of value targets with PopArt effectively addresses the task saliency problem by ensuring consistent learning signal magnitudes across diverse tasks.
> - The output-preserving property of PopArt allows the underlying network to learn stable, scale-invariant representations of values even as the reward statistics evolve over training.
> - Applying PopArt to task-specific value heads while maintaining a shared, task-agnostic policy network enables a single agent to generalize across many tasks without requiring task IDs during evaluation.
