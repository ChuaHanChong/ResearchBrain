# Towards Fusing Point Cloud and Visual Representations for Imitation Learning

> [!summary] Summary
> Researchers at the Karlsruhe Institute of Technology developed FPV-Net, a multimodal imitation learning method that integrates point cloud and RGB image representations using Adaptive LayerNorm (AdaLN) conditioning. This approach enables state-of-the-art performance on challenging robotic manipulation tasks on the RoboCasa benchmark, demonstrating enhanced generalization and robust skill acquisition.

## Problem

- Robotic manipulation tasks often require both precise 3D geometric understanding (from point clouds) and rich semantic/texture information (from RGB images), but single modalities are insufficient for consistent high performance.
- Existing multimodal fusion techniques in imitation learning frequently lead to a loss of global contextual information from RGB images when 2D features are assigned to 3D space.
- Prior diffusion policies for 3D robotics sometimes discard critical local geometric features through aggressive pooling, limiting their efficacy for fine-grained manipulation.

## Method

- ==FPV-Net== utilizes a transformer-based diffusion policy for action generation, adopting an EDM-based approach for robust learning.
- It processes RGB images with a language-conditioned FiLM-ResNet to extract both global and local visual tokens, preserving fine-grained details, and processes point clouds using Furthest Point Sampling and k-Nearest Neighbors to capture structured local geometric features.
- The core fusion mechanism involves Adaptive LayerNorm (AdaLN) conditioning, where rich RGB features modulate the primary point cloud and language representations, balancing geometric precision with semantic context.

## Results

- FPV-Net variants (FPV-MLP and FPV-SUGAR) achieved average success rates of **49.42%** and **50.50%** on the RoboCasa benchmark, substantially outperforming baselines like BC (**28.80%**), 3D Diffusion Policy (**22.75%**), and 3D Diffuser Actor (**5.50%**).
- AdaLN conditioning, specifically using image features to modulate point cloud and language inputs, consistently demonstrated the most effective fusion strategy, outperforming direct concatenation and other conditioning approaches.
- Ablation studies confirmed that incorporating local RGB features significantly improves performance on fine-grained tasks, and finetuning pretrained 3D encoders (SUGAR) further boosts average success rates by **2%**.

## Takeaways

> [!tip] Key Insights
> - Intelligent fusion of complementary modalities, specifically using AdaLN conditioning with RGB features to modulate point cloud representations, significantly outperforms single modalities or simpler concatenation strategies.
> - The preservation and integration of local RGB features alongside global visual context are crucial for achieving high performance in fine-grained robotic manipulation tasks.
> - Transformer-based diffusion policies, when effectively combined with this multimodal sensor fusion strategy, can learn robust and generalizable robotic manipulation skills from limited demonstrations.
