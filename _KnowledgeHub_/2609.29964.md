# World Action Agent: Harnessing VLMs for Robot Manipulation via World Action Rehearsal

> [!summary] Summary
> World Action Agent is a multi-agent harness that lets a general-purpose VLM pilot a robot with basic tools inside one visual action workspace: auto-selected Contact views, action proposals rehearsed against a motion planner before execution, and in-view drag corrections. Multimodal skills evolve from expert videos and human teaching. It reaches a state-of-the-art 75.6% average success on LIBERO-Pro.

## Problem

- Fine-tuning VLMs into action predictors can weaken their general reasoning, while world action models still need robot data and action alignment for executable control.
- Constraint-prediction and code-as-policy systems involve the VLM only indirectly, and an open-loop program cannot inspect whether a specific pose is appropriate before it runs.
- Prior visual harnesses show the scene but not a world to act in: no interaction-centered views, no trial before execution, and perception and action live in separate spaces.

## Method

- Interaction-centered ==Canvas==: Contact views solved from the scene point cloud by an objective balancing interaction visibility, compact framing, view redundancy and temporal stability, constrained to two orthogonal directions.
- ==Action rehearsal== and in-view correction: proposals solved by IK plus ==cuRobo planning==, previewed as translucent overlays, revised by an **Imagination Agent**; image-space drags in a Contact view become bounded end-effector displacements.
- Skill evolution: **Learner**, **Editor** and **Reviewer** agents distill expert videos and Canvas-GUI human teaching into a multimodal skill library consulted at runtime by a separate **Skill Agent**.

## Results

- With evolved skills WAA reaches **75.6%** average success on LIBERO-Pro, above ASPIRE at **72.0%**, RATs at **43.8%**, pi-0.5 at **12.8%**, and Show-Harness at **6.7%**.
- Skills drive the gain: **28.9%** zero-shot, **43.3%** with text-only seed skills, **75.6%** evolved; the two Spatial splits rise from **13.3%** and **6.7%** to **80.0%** and **73.3%**.
- Frozen LIBERO skills lift robosuite restacking from **60.0%** to **100.0%** versus **46.0%** for a code-as-policy baseline; fine-tuned Qwen3.5-9B reaches **43.3%** out-of-domain, from **1.7%**.

## Takeaways

> [!tip] Key Insights
> - Changing what a VLM sees and how its decisions take effect can beat retraining it for action, though results stay bounded by backbone multi-view perception.
> - Rehearsing an action against a motion planner before committing turns irreversible physical trial-and-error into cheap, revisable inspection.
> - Skills stated as relations plus reference images, with independent evidence review, transfer across simulators; text-only procedures help inconsistently and can even hurt.

## Detailed Report

### 1. Overview

Take a small manipulation task: placing a bowl accurately on a plate. From one close view, the bowl looks nearly aligned over the plate. A complementary angle reveals that it is offset. Vision-language models (VLMs) can recognize objects and reason about spatial goals, but turning that judgment into precise, recoverable physical actions is difficult. World Action Agent (WAA) does not replace the VLM with a newly trained robot policy. It changes the workspace around the model, so the model can inspect close-up views, revise a proposed action against planning feedback, and make small corrections in the same views where it sees the error. In the bowl example, the agent sees the offset from the second view, drags the bowl toward the target, and the bowls end up stacked.

(a) An initially infeasible grasp proposal, a rotated proposal the planner reports as feasible, and the main agent's further shift toward the handle. (b) The same bowl-placement state from Contact A ("nearly aligned") and Contact B ("offset revealed"), a drag toward the target, then the bowls stacked. Interface examples rendered from RGB-D point clouds.

### 2. A proposal before motion

WAA pairs a global view, which supplies task context, with automatically selected Contact views. The Contact views expose local relations among the gripper, the object, and the target. All views are calibrated, so a point or drag in an image can map to movement in robot space. The two Contact views expose complementary directions.

The agent builds a pose proposal from points on the Canvas, the shared visual workspace. The harness solves inverse kinematics and asks the motion planner to check the path. It then shows a translucent preview along with feasibility feedback. The main agent, or a separate Imagination Agent, can revise the proposal and replan while the physical scene remains unchanged. Only a proposal with an executable plan can be committed to physical motion. A feasible plan does not by itself establish task completion.

For small residual errors, the agent drags a visible reference point, on the gripper or the held object, toward its desired location in a Contact view. Calibration converts that visual intent into a bounded end-effector displacement. A fresh observation then lets the agent decide whether to adjust again or release. As a result, the VLM does not have to translate every observed offset into an absolute coordinate before correcting it.

### 3. What the benchmark establishes

LIBERO-Pro has six splits. They cross Object, Goal, and Spatial tasks with initial-position swaps (Pos.) or task perturbations (Task). Each split has ten tasks, and WAA evaluates six episodes per task. Each split score is the percentage of successful episodes, and the average is the mean of the six split percentages.

The paper's closest prior work is [[2609.10522|Show-Harness]], which already places a VLM in a closed visual perception–action loop. With the same Gemini 3.7 Flash backbone, WAA without skills reports 28.9% average success on LIBERO-Pro, compared with 6.7% for Show-Harness. Show-Harness scores 0% on both Spatial splits. This is not a matched evaluation. WAA evaluates 60 episodes per split and reruns Show-Harness for 30 per split. The comparison also changes a package of interface features together, so it supports a system-level difference rather than proof that any one feature caused the gain.

WAA can also use skills. Each skill pairs conditions for use with a relational procedure, reference images of key states, observable outcome checks, and recovery guidance. For evaluation, the skill library is learned only from LIBERO-90 and frozen, so it receives no LIBERO-Pro evaluation updates. With these evolved skills, WAA reaches 75.6% average success, versus 72.0% for [[2607.00272|ASPIRE]], the strongest average baseline in the table. WAA leads on both Spatial splits and Goal-Task. ASPIRE leads on both Object splits and Goal-Pos. Some baseline results are taken from their original papers, so their evaluation protocols are not identical to WAA's.

Success rate (%) across Object, Goal, and Spatial splits (Pos./Task) and the average. WAA with evolved skills averages 75.6; ASPIRE averages 72.0.

### 4. The useful change

A second view can reveal an error. In WAA, the agent can turn that observation into a proposal it checks and revises before motion, then into a correction it can observe again. The result is a strong LIBERO-Pro score, though not a win on every split. The paper reports no ablation that removes Contact views or rehearsal one at a time, so it does not show which feature drives the gain.
