# GenDP: 3D Semantic Fields for Category-Level Generalizable Diffusion Policy

> [!summary] Summary
> This paper presents GenDP, a framework that integrates 3D semantic fields with a diffusion-based policy, allowing robotic systems to generalize manipulation skills across varying instances within the same object category. The approach achieved an average success rate of 93% on unseen object instances, significantly outperforming existing methods like vanilla Diffusion Policy (20%) across a diverse set of manipulation tasks.

## Problem

- Robotic manipulation policies struggle to generalize across different instances within the same object category (e.g., varying mugs or shoes) due to differences in appearance, geometry, or environment.
- Existing diffusion-based policies, while powerful, have limited generalization capabilities when faced with variations in object appearance, geometric ambiguities, or environmental changes.
- Current representations often lack a sufficient combination of both precise geometric details and high-level semantic understanding necessary for robust category-level generalization.

## Method

- **GenDP** introduces 3D semantic fields that unify geometric and semantic information by extracting rich semantic features from multi-view RGBD observations using DINOv2.
- A ==Semantic Fields Constructor== creates low-dimensional semantic fields by comparing these extracted descriptor fields against reference descriptors of task-relevant object categories.
- A diffusion-based action policy takes both the geometric point cloud and the newly constructed semantic fields as input to predict robot actions, facilitating generalization across object instances.

## Results

- GenDP achieved an average success rate of **93%** on unseen object instances, a substantial improvement compared to **20%** for vanilla Diffusion Policy.
- The method consistently outperformed baseline methods across all tested manipulation tasks involving unseen instances, including those requiring attention to geometric details or handling ambiguities.
- Ablation studies confirmed that the 3D semantic fields are critical for generalization, with the 'without Semantics' baseline achieving only **58%** success on unseen instances.

## Takeaways

> [!tip] Key Insights
> - Combining geometric information (point clouds) with rich semantic features from vision foundation models creates a unified 3D representation that is robust to object variations.
> - 3D semantic fields, derived by comparing descriptor fields to reference features, enable policies to attend to task-relevant parts of objects, resolving geometric ambiguities and focusing on subtle details.
> - A diffusion-based policy can effectively leverage this combined geometric and semantic input to learn generalizable manipulation skills from demonstrations.

## Detailed Report

### 1. Introduction

Robotic manipulation requires a system to adapt to various objects within the same category, such as different types of mugs, shoes, or utensils. This ability to generalize across object instances while maintaining task performance remains a significant challenge in robotics. Current approaches often struggle when faced with new instances of objects that differ in appearance, geometry, or background environments.

The research paper "GenDP: 3D Semantic Fields for Category-Level Generalizable Diffusion Policy" introduces a novel approach to address this challenge. By combining geometric and semantic information in a 3D representation, GenDP enables robotic systems to generalize manipulation skills across different object instances within the same category, achieving significant improvements in performance on unseen objects compared to existing methods.

### 2. Background

Robotic manipulation policies have evolved significantly in recent years, with imitation learning (IL) emerging as a powerful paradigm for teaching robots complex skills through demonstrations. Diffusion models, originally developed for image generation, have recently been applied to robotics through approaches like Diffusion Policy, which effectively captures the multimodal nature of action distributions and provides stable training.

However, existing diffusion-based policies suffer from limited generalization capabilities when faced with:
1. Variations in object appearance
2. Geometric ambiguities that confuse purely geometric approaches
3. Environmental changes including backgrounds and lighting conditions
4. Subtle geometric details crucial for task completion

These limitations stem from an insufficient representation of both geometric and semantic information. While geometric information (such as point clouds) captures shape and position, it lacks understanding of object function and meaning. Conversely, semantic information helps identify object categories and functionality but may miss critical geometric details.

### 3. Method Overview

GenDP introduces a comprehensive framework that addresses these limitations through three key components:

1. **3D Descriptor Fields Encoder**: Extracts rich semantic features from multi-view RGBD observations using a vision foundation model (DINOv2).

2. **Semantic Fields Constructor**: Creates low-dimensional semantic fields by comparing the descriptor fields against reference descriptors extracted from images of task-relevant object categories.

3. **Action Policy**: A diffusion-based policy that takes both the geometric point cloud and semantic fields as input to predict appropriate robot actions.

This approach enables the policy to attend to both geometric details and semantically meaningful parts of objects, facilitating generalization across different instances within the same category.

### 4. 3D Semantic Fields

The core innovation of GenDP is the introduction of 3D semantic fields that combine geometric and semantic information in a unified representation. This is achieved through several steps:

1. **Multi-view RGBD Processing**: The system captures multiple RGB-D views of the scene, providing both color information and depth data.

2. **Feature Extraction**: A pre-trained vision foundation model (DINOv2) extracts semantic features from the RGB images, creating dense descriptor maps that encode rich semantic information.

3. **Descriptor Field Construction**: The 2D descriptors are projected into 3D space using the depth information, creating a 3D descriptor field where each point in space is associated with a high-dimensional feature vector.

4. **Semantic Field Generation**: The system computes similarity scores between the descriptor field and reference descriptors extracted from images of the target object category, creating semantic fields that highlight task-relevant parts of objects.

Mathematically, the process can be represented as:

$$\mathbf{F}_{\text{semantic}} = \text{sim}(\mathbf{F}_{\text{descriptor}}, \mathbf{F}_{\text{reference}})$$

where $\text{sim}(\cdot, \cdot)$ is a similarity function (typically cosine similarity) that measures the correspondence between the descriptor field and reference features.

### 5. Diffusion Policy Framework

GenDP employs a diffusion-based policy that leverages Denoising Diffusion Probabilistic Models (DDPM) to predict robot actions. The diffusion policy works as follows:

1. The policy takes as input the semantic fields and point cloud, which provide complementary information about the scene.

2. During training, the policy learns to denoise action trajectories corrupted with Gaussian noise, effectively learning a conditional probability distribution over actions given the current state.

3. The diffusion model is trained using imitation learning, minimizing the difference between predicted actions and ground truth actions from human demonstrations.

4. At inference time, the model samples from the learned distribution to generate actions that are appropriate for the current state.

The training objective can be expressed as:

$$\mathcal{L} = \mathbb{E}_{t, \mathbf{a}_0, \epsilon} \left[ \| \epsilon - \epsilon_\theta(\alpha_t \mathbf{a}_0 + \sigma_t \epsilon, t, \mathbf{s}) \|^2 \right]$$

where $\mathbf{a}_0$ is the ground truth action, $\mathbf{s}$ is the state representation combining semantic fields and point cloud, $\epsilon$ is random noise, and $\epsilon_\theta$ is the neural network that predicts the noise.

### 6. Experimental Setup

The researchers evaluated GenDP on a diverse set of manipulation tasks using a robotic setup consisting of two 7-DoF Franka Emika robot arms equipped with parallel grippers. The experimental evaluation focused on testing the policy's ability to generalize to unseen object instances within familiar categories.

The evaluation included eight manipulation tasks:
1. Hanging a mug on a rack
2. Inserting a pencil into a container
3. Placing a soda can in a specified location
4. Using a toothbrush
5. Collecting a knife
6. Opening a pen
7. Aligning shoes
8. Using a spoon

For each task, the policy was trained on a limited set of object instances and tested on both seen instances (to verify learning) and unseen instances (to evaluate generalization). The experimental setup included a diverse collection of everyday objects with varying appearances, geometries, and functional properties.

### 7. Results and Performance

The experimental results demonstrate GenDP's exceptional generalization capabilities:

1. **Overall Performance**: GenDP achieved an average success rate of 93% on unseen instances, compared to just 20% for vanilla Diffusion Policy, representing a substantial improvement in generalization capability.

2. **Seen Instances**: On objects seen during training, GenDP performed comparably to the original Diffusion Policy, confirming that the addition of semantic information does not compromise performance on familiar objects.

3. **Unseen Instances**: The most significant improvements were observed on unseen instances, where GenDP consistently outperformed baseline methods across all task categories:
 - Geometry Details: Tasks requiring attention to specific geometric features (e.g., using a toothbrush, placing a can)
 - Geometry Ambiguity: Tasks with potentially confusing geometric similarities (e.g., collecting a knife, opening a pen)
 - Category Generalization: Tasks testing true category-level generalization (e.g., aligning shoes, using a spoon)

4. **Ablation Studies**: The comparison with "Ours without Semantics" (which uses only point clouds) demonstrates the critical importance of semantic information for generalization, as this baseline achieved only 58% success on unseen instances.

### 8. Advantages Over Previous Approaches

GenDP offers several key advantages over existing approaches:

1. **Improved Generalization**: By combining semantic and geometric information, GenDP significantly outperforms methods that rely solely on either type of information.

2. **Resolution of Geometric Ambiguities**: The semantic fields help distinguish between objects with similar geometries but different functions, enabling more intelligent manipulation.

3. **Attention to Subtle Details**: The approach enables the policy to focus on small but critical geometric details that are essential for task success.

4. **No Distillation Requirement**: Unlike some approaches that require distillation from dense to sparse representations, GenDP directly extracts 3D descriptor fields from multi-view observations, preserving more information.

5. **Consistency Across Instances**: The semantic fields exhibit consistent patterns across different instances within the same category, facilitating transfer of manipulation skills.

The approach differs from object-centric embeddings and neural implicit models by maintaining explicit 3D structure while incorporating rich semantic information, providing a more comprehensive representation for robotic manipulation.

### 9. Limitations and Future Work

Despite its impressive performance, GenDP has several limitations that present opportunities for future research:

1. **Fixed Reference Features**: The current implementation uses fixed reference features for constructing semantic fields, which may be suboptimal for long-horizon tasks or tasks requiring fine-grained manipulation.

2. **Task-Specific Semantics**: Future work could focus on developing mechanisms to construct task-specific semantic fields that adaptively select the appropriate level of abstraction based on the task requirements.

3. **Explicit Geometric Properties**: While the current approach implicitly captures geometric information, incorporating more explicit geometric properties could improve interpretability and efficiency.

4. **Long-Horizon Tasks**: The current evaluation focused on relatively short manipulation tasks; extending the approach to longer-horizon tasks with multiple stages remains an open challenge.

5. **Computational Efficiency**: The extraction and processing of 3D semantic fields introduce computational overhead that may need to be optimized for real-time applications.

### 10. Conclusion

GenDP represents a significant advancement in robotic manipulation by introducing 3D semantic fields that combine geometric and semantic information to enable category-level generalization. The approach achieves remarkable improvements in generalization performance compared to existing methods, demonstrating its potential for real-world applications in manufacturing, logistics, and service robotics.

By addressing the limitations of purely geometric or purely semantic approaches, GenDP provides a more comprehensive framework for robotic manipulation that can adapt to the variations and complexities of real-world environments. The integration of vision foundation models with diffusion-based policies creates a powerful paradigm for learning generalizable manipulation skills from demonstrations, bringing robots closer to the flexibility and adaptability of human manipulation.
