# Progressive Object Transfer Detection

> [!summary] Summary
> Researchers from Huazhong University of Science and Technology and Shenzhen Institutes of Advanced Technology developed the Progressive Object Transfer Detection (POTD) framework, which efficiently combines low-shot and weakly-supervised learning. This system achieves high object detection accuracy using few instance-level annotations and many image-level labels, notably improving performance over state-of-the-art weakly/semi-supervised methods while requiring significantly less weakly-annotated data than comparable low-shot techniques.

## Problem

- State-of-the-art object detectors require extensive, fully-annotated datasets, which are costly and time-consuming to create in real-world applications.
- Existing weakly-supervised and low-shot methods often suffer from limited performance, local optima, or demand large amounts of other resource-intensive data (e.g., videos).
- Detecting novel objects when source and target categories are non-overlapping poses a significant challenge for transfer learning.

## Method

- A two-stage, end-to-end ==Progressive Object Transfer Detection (POTD)== framework is proposed, mimicking human-like learning from few precise examples to broad generalization.
- The framework utilizes a ==hybrid detection architecture== that combines a Faster R-CNN style Region Proposal Network (RPN) with an SSD-style shared bounding box regressor to facilitate transfer.
- It integrates ==Low-Shot Transfer Detection (LSTD)== with novel regularization (Background Depression and Source Detection Knowledge) and ==Weakly-Supervised Transfer Detection (WSTD)== with Recurrent Object Labelling (ROL).

## Results

- LSTD's hybrid architecture demonstrated improved low-shot detection, achieving **15.9-16.5** mAP for 1-shot learning, surpassing Faster R-CNN and SSD by over **3 mAP**.
- The complete POTD framework boosted 1-shot LSTD performance from **34.0 mAP** to **62.6 mAP** by integrating WSTD with approximately **250** weakly-annotated images per class.
- Recurrent Object Labelling (ROL) consistently outperformed prior weakly-supervised methods like OICR (e.g., **61.3 mAP** vs. **55.5 mAP**), attributed to its selective background proposal mining.
- POTD achieved state-of-the-art performance, significantly outperforming existing weakly/semi-supervised methods and using substantially less weakly-annotated data than comparable low-shot techniques like CBL.

## Takeaways

> [!tip] Key Insights
> - Mimicking human-like learning, starting with few strong examples and progressing to broad generalization from weaker supervision, proves effective for data-efficient object detection.
> - A hybrid detector architecture that decouples bounding box regression from classification enhances transferability, especially in low-shot scenarios.
> - Novel regularization techniques like Background Depression and Source Detection Knowledge are vital for stable fine-tuning and knowledge transfer with minimal instance-level annotations.
> - The Recurrent Object Labelling (ROL) mechanism's selective background proposal mining is crucial for generating high-quality pseudo-labels and improving weakly-supervised learning.
