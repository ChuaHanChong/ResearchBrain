# Automating Reinforcement Learning with Example-based Resets

> [!summary] Summary
> Researchers at Seoul National University developed a deep reinforcement learning framework that autonomously learns reset policies from examples of initial states, significantly reducing the need for manual intervention in real-world robot training. The system achieved competitive performance with an oracle method in simulations and enabled continuous, efficient learning on a physical UR3 manipulator.

## Problem

- Deep reinforcement learning (DRL) algorithms assume instantaneous, reliable episodic resets, which are trivial in simulation but challenging and costly for real-world robots.
- Existing real-world reset solutions rely on extensive human supervision, task-specific scripts, or specialized mechanical setups, hindering the goal of autonomous robot learning.
- These conventional workarounds introduce external dependencies and prior knowledge, contradicting DRL's aim for autonomous skill acquisition with minimal prior input.

## Method

- The framework concurrently trains a ==forward agent== (for the primary task) and a ==self-supervised reset agent==, integrating the reset mechanism directly into the learning process.
- The reset agent learns to return the system to an ==initial state distribution== solely from examples of desired initial states, without requiring explicit reward engineering.
- A ==preemptive reset trigger==, based on an ==ensemble of reset success classifiers==, activates the reset agent before the forward episode ends or leads to an irrecoverable state.

## Results

- In simulations, the method reduced manual resets and achieved performance comparable to, and in some cases exceeding, an oracle using dense, hand-engineered reset rewards (e.g., **19.51** average return vs. **10.38** for ball-in-cup (catch)).
- The learned reset agent imposed an implicit curriculum on the forward agent, confining its exploration during early training and expanding its range as reset capabilities improved.
- The method was successfully deployed on a physical **UR3** manipulator for peg-insertion and reaching tasks, demonstrating high train time efficiency (**85%** and **84%** respectively) and autonomous learning from scratch on hardware.

## Takeaways

> [!tip] Key Insights
> - Self-supervised learning of a reset policy from initial state examples, using Recursive Classification of Examples (RCE), effectively replaces complex, hand-engineered reset reward functions.
> - A preemptive reset mechanism, driven by an ensemble of reset success classifiers, acts as a safety layer, implicitly generating a curriculum for the forward agent by initially confining its exploration.
> - Alternating training of forward and reset agents enables continuous operation on real robots, significantly enhancing training efficiency by minimizing manual intervention.
