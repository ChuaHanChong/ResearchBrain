# Video World Models with Long-term Spatial Memory

> [!summary] Summary
> Researchers from Stanford University, Shanghai Jiao Tong University, NTU, and CUHK develop a memory-augmented video world model that overcomes the "forgetting problem" in long-term video generation by implementing three distinct memory mechanisms inspired by human cognition: working memory (recent context frames), geometry-grounded spatial memory (persistent 3D point clouds of static scenes updated via TSDF fusion), and sparse episodic memory (keyframes from previously explored regions), achieving substantial improvements in view recall consistency with 19.10 vs 11.71-12.16 PSNR when revisiting camera poses and demonstrating superior performance across VBench metrics for aesthetic quality (0.5835), temporal flickering (0.7580), and motion smoothness (0.9886) compared to baselines like TrajectoryCrafter and DaS, with the framework built upon CogVideoX-5B-I2V and trained on a custom 90K-sample dataset where static point clouds are extracted using CUT3R reconstruction and TSDF filtering to suppress dynamic elements, enabling infinite-length consistent world generation through explicit 3D geometry understanding rather than relying solely on image-based temporal contexts.

## Problem

- Current video world models suffer from severe "forgetting" when revisiting previously generated scenes due to limited temporal context windows in autoregressive generation
- Existing approaches rely primarily on image-based representations of the past, lacking persistent 3D understanding of world geometry
- Models struggle to maintain long-term consistency between static background elements and dynamic foreground content over extended video sequences
- Computational constraints from quadratic attention complexity prevent processing of numerous past frames simultaneously

## Method

- Implement three-tier memory system: working memory (recent frames), spatial memory (3D point clouds), and episodic memory (sparse keyframes)
- Use TSDF fusion to extract and maintain persistent static scene geometry, automatically filtering out dynamic elements through depth consistency
- Integrate memory mechanisms into diffusion transformer via condition latents from point cloud rendering and historical cross-attention modules
- Create custom training dataset with explicit 3D reconstructions and paired static/dynamic annotations using Mega-SaM and action labeling

## Results

- Achieved 19.10 PSNR vs 11.71-12.16 for baselines on view recall consistency tasks, with corresponding improvements in SSIM (0.6471 vs 0.4380-0.4512) and LPIPS (0.3069 vs 0.5874-0.5996)
- Superior VBench performance across aesthetic quality (0.5835), temporal flickering (0.7580), motion smoothness (0.9886), and subject consistency (0.9359)
- Human evaluation rankings of 3.6260 for camera accuracy, 3.3846 for static consistency, and 3.4011 for dynamic plausibility, significantly outperforming all baseline methods
- Ablation studies confirm each memory component contributes essential functionality, with full model achieving best results across all evaluated metrics

## Takeaways

> [!tip] Key Insights
> - Human-inspired memory mechanisms can effectively address temporal consistency challenges in generative models through explicit geometric representation
> - Static scene geometry can be disentangled from dynamic content using TSDF fusion, which naturally suppresses inconsistent dynamic elements
> - Combining geometry-grounded spatial memory with sparse visual episodic memory provides both structural consistency and fine-grained detail preservation
> - Point cloud rendering as conditioning signal enables precise camera control while maintaining static background coherence across arbitrary time horizons
