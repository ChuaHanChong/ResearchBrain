# Video World Models with Long-term Spatial Memory

> [!summary] Summary
> Researchers from Stanford University, Shanghai Jiao Tong University, NTU, and CUHK develop a memory-augmented video world model that overcomes the "forgetting problem" in long-term video generation by implementing three distinct memory mechanisms inspired by human cognition: working memory (recent context frames), geometry-grounded spatial memory (persistent 3D point clouds of static scenes updated via TSDF fusion), and sparse episodic memory (keyframes from previously explored regions), achieving substantial improvements in view recall consistency with 19.10 vs 11.71-12.16 PSNR when revisiting camera poses and demonstrating superior performance across VBench metrics for aesthetic quality (0.5835), temporal flickering (0.7580), and motion smoothness (0.9886) compared to baselines like TrajectoryCrafter and DaS, with the framework built upon CogVideoX-5B-I2V and trained on a custom 90K-sample dataset where static point clouds are extracted using CUT3R reconstruction and TSDF filtering to suppress dynamic elements, enabling infinite-length consistent world generation through explicit 3D geometry understanding rather than relying solely on image-based temporal contexts.

## Problem

- Current video world models suffer from severe "forgetting" when revisiting scenes, since limited temporal context windows and quadratic attention complexity prevent processing enough past frames during autoregressive generation
- Existing approaches rely primarily on image-based representations of the past, lacking persistent 3D understanding of world geometry
- Models struggle to maintain long-term consistency between static background elements and dynamic foreground content over extended video sequences

## Method

- Implement three-tier memory system: working memory (recent frames), spatial memory (persistent 3D point clouds built via TSDF fusion, filtering out dynamic elements through depth consistency), and episodic memory (sparse keyframes)
- Integrate memory mechanisms into diffusion transformer via condition latents from point cloud rendering and historical cross-attention modules
- Create custom training dataset with explicit 3D reconstructions and paired static/dynamic annotations using Mega-SaM and action labeling

## Results

- Achieved 19.10 PSNR vs 11.71-12.16 baselines on view recall (SSIM 0.6471 vs 0.4380-0.4512, LPIPS 0.3069 vs 0.5874-0.5996), plus superior VBench scores: aesthetic quality 0.5835, temporal flickering 0.7580, motion smoothness 0.9886
- Human evaluation rankings of 3.6260 for camera accuracy, 3.3846 for static consistency, and 3.4011 for dynamic plausibility, significantly outperforming all baseline methods
- Ablation studies confirm each memory component contributes essential functionality, with full model achieving best results across all evaluated metrics

## Takeaways

> [!tip] Key Insights
> - Human-inspired memory mechanisms address temporal consistency challenges through explicit geometric representation, combining geometry-grounded spatial memory with sparse visual episodic memory to provide both structural consistency and fine-grained detail preservation
> - Static scene geometry can be disentangled from dynamic content using TSDF fusion, which naturally suppresses inconsistent dynamic elements
> - Point cloud rendering as conditioning signal enables precise camera control while maintaining static background coherence across arbitrary time horizons

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This research is situated at the cutting edge of **generative AI**, specifically within the rapidly evolving domain of **video world models**. World models are computational systems designed to learn and predict an environment's dynamics in response to actions, making them invaluable for simulation, robotics, and interactive applications. Recent advancements in **video diffusion models** have revolutionized image and video generation, offering unprecedented fidelity and diversity.

However, the current landscape of video generation models, especially those built on autoregressive next-frame prediction, faces a critical challenge: **long-term consistency**. These models often operate with limited temporal context windows, typically due to the quadratic computational complexity of attention mechanisms in underlying diffusion transformers. This limitation leads to severe "forgetting" of previously generated environments, resulting in inconsistencies when scenes are revisited or when generating very long videos. Existing solutions, such as keeping context windows small or progressively downsampling older frames, offer only partial remedies, often at the cost of detail or true spatial understanding. Many state-of-the-art models either struggle with precise camera control or cannot handle dynamic scenes while maintaining long-term static consistency.

"Video World Models with Long-term Spatial Memory" directly addresses this fundamental limitation by proposing a novel framework that transcends the typical image-based context windows. Inspired by human memory mechanisms, the paper introduces an **explicit, geometry-grounded 3D spatial memory** alongside a sparse episodic memory. This approach significantly differentiates it from prior works that primarily rely on image-based representations of the past, thereby lacking a persistent 3D understanding of the world.

The paper builds upon and extends several key areas:
- **Video Diffusion Models:** Leveraging architectures like CogVideoX, it integrates memory mechanisms into existing powerful generative backbones.
- **Autoregressive Video Generation:** It tackles the inherent memory limitations of sliding-window autoregressive approaches.
- **Controlled Video Generation:** It advances models that support camera control and structural conditioning by grounding the generation in persistent 3D geometry, distinguishing itself from methods focused solely on camera trajectory or dynamic content within a single short clip.
- **Long-Context Video Generation:** While other works explore efficient architectures or frame compression, this paper introduces a *semantic* and *geometric* form of long-term memory, which complements these computational efficiency efforts by providing a richer, more robust context. It bridges the gap between methods that perform 3D reconstruction for camera control (e.g., TrajectoryCrafter, DaS) and general-purpose video generation models (e.g., Wan2.1) by enabling complex dynamic scenes while preserving static 3D consistency.

By explicitly integrating 3D geometry and human-inspired memory systems, this work represents a significant step towards developing more robust, intelligent, and truly "world-modeling" AI systems capable of generating infinitely long, consistent, and controllable videos.

### 2. Key Objectives and Motivation

The primary motivation behind this research stems from a critical bottleneck in the advancement of video world models: their inability to maintain long-term consistency. Current state-of-the-art world models, often built on autoregressive video diffusion architectures, rely on a limited temporal context window. This constraint is largely due to the computational demands, specifically the quadratic growth of complexity in the attention modules of diffusion transformers, which makes processing numerous past frames prohibitively expensive. As a result, these models frequently "forget" previously generated environments when revisiting scenes, leading to noticeable inconsistencies, visual degradation, and a lack of coherence over extended video sequences. This fundamental flaw hinders their application in scenarios requiring persistent world understanding, such as long-horizon simulations, interactive virtual environments, or robotics training.

To address this challenge, the key objectives of this paper are:

1. **Enhance Long-term Consistency:** The overarching goal is to overcome the "forgetting problem" in video world models and enable consistent generation over extended temporal horizons, particularly during scene revisits.
2. **Develop a Geometry-Grounded Memory Framework:** To achieve long-term consistency, the authors propose a novel framework inspired by human memory. This framework aims to integrate explicit, geometry-grounded memory mechanisms into existing video world models.
3. **Implement Distinct Memory Mechanisms:** Specifically, the paper aims to model three types of memory:
 - **Short-term Working Memory:** To capture immediate temporal dynamics and motion continuity (similar to existing autoregressive context frames).
 - **Long-term Spatial Memory:** To store persistent 3D structural information of the static environment, represented as a point cloud. This memory should be incrementally updated and should effectively filter out dynamic elements.
 - **Sparse Episodic Memory:** To retain specific visual details and identities from important past events or keyframes, compensating for the sparsity of the spatial memory.
4. **Design Storage and Retrieval Mechanisms:** To make these memory types functional, the authors aim to develop effective methods for storing newly generated information into the memory banks and for retrieving relevant information to condition the generation of new video frames.
5. **Curate Custom Training and Evaluation Datasets:** Recognizing the unique data requirements for geometry-grounded memory-augmented models, a specific objective is to build and annotate a dataset that facilitates the training and rigorous evaluation of such mechanisms.
6. **Demonstrate Superior Performance:** A key objective is to quantitatively and qualitatively show that the proposed memory-augmented framework outperforms existing baselines in terms of video quality, spatial consistency, and ability to handle long-term contexts and camera movements.

Ultimately, the motivation is to pave the way towards realizing "infinite-length, consistent world generation capabilities" for diverse applications in computer graphics, robotics, and other interactive domains, pushing world models beyond short, isolated video clips into truly persistent and interactive environments.

### 3. Methodology and Approach

The core of the proposed methodology lies in augmenting conventional autoregressive video generation models with a sophisticated memory system inspired by human cognition. The framework integrates three distinct memory types: **working memory**, **spatial memory**, and **episodic memory**, each with a dedicated representation and mechanism for storage and retrieval. The overall system is built upon a latent video diffusion model, specifically adapted from CogVideoX-5B-I2V.

#### 3.1. Memory Mechanisms Design

- **Working Memory (Short-Term):** This is analogous to the standard autoregressive approach. The model conditions the generation of new frames on a small number of most recent context frames (e.g., the last five latent frames). This provides immediate temporal continuity and captures dynamic aspects of the scene in the very recent past.
- **Spatial Memory (Long-Term, Geometry-Grounded):** This mechanism is designed to remember long-term spatial relationships, primarily focusing on the static elements of the environment.
 - **Representation:** A persistent 3D point cloud is used to represent the static scene structure.
 - **Storage (Online Update):** During autoregressive generation, newly generated video frames are processed to reconstruct "static point maps" using CUT3R, an online recurrent 4D reconstruction framework. These maps are then filtered using **Truncated Signed Distance Function (TSDF) fusion**. TSDF fusion inherently suppresses dynamic elements (like characters or vehicles) because their inconsistent depth observations across frames lead to low-confidence TSDF values, allowing the memory to predominantly store static background structures. The filtered static point cloud is then merged with the global spatial memory, ensuring consistent alignment across steps.
 - **Retrieval:** The current static spatial memory (global point cloud) is rendered into a condition video along the input camera trajectory. This static point cloud rendering is then encoded by a pre-trained 3D VAE into "condition latents."
- **Episodic Memory (Long-Term, Sparse Visual Details):** While spatial memory provides geometric guidance, it can be sparse and may not retain fine visual details or identities of objects/characters.
 - **Representation:** A sparse set of historical reference frames (keyframes) is maintained.
 - **Storage:** Keyframes are selected and added to the memory when new, previously unrevealed regions of the scene (identified via mask-based visibility checks) exceed a predefined threshold, ensuring that important visual details from newly explored areas are preserved.
 - **Retrieval:** These selected historical reference frames are also encoded by the 3D VAE and patchified into "reference tokens."

#### 3.2. Memory-guided Video Generation

The generative process is orchestrated by a diffusion transformer (DiT) architecture, which is conditioned by these three memory streams:

- **Static Point Cloud Conditioning:** The condition latents derived from the static point cloud rendering guide camera movement and maintain static consistency. This is implemented similar to ControlNet, where the output features from a "condition DiT" (copied from the main DiT and processed through zero-initialized linear layers) are added to corresponding feature maps in the main denoising DiT. This design allows the model to learn to disentangle static geometry control from dynamic content generation.
- **Dynamic Context Guidance (Working Memory):** The latent tokens of the most recent context frames are concatenated with the target video tokens along the frame dimension. This provides the necessary information for smooth motion prediction and temporal extension of dynamic elements.
- **Historical Cross-Attention (Episodic Memory):** A dedicated "historical cross attention" module facilitates information exchange. Video tokens (currently being generated) act as queries, while the reference tokens (from episodic memory) serve as keys and values. This mechanism allows the model to "recall" visual details and identities from distant past frames, improving long-term consistency for subjects and objects.
- **Action and Text Prompts:** In addition to memory, the model is also conditioned on action instructions and text prompts (processed by T5 encoder) to control the dynamic content and overall scene description.

#### 3.3. Geometry-grounded Video Dataset Creation

A crucial part of the methodology was the creation of a custom dataset suitable for training and evaluating models with explicit 3D memory.

- **Data Source:** Raw videos from MiraData were used.
- **Clip Segmentation:** Each video was segmented into 97-frame clips, with the first 49 frames as the "source sequence" and the remaining 48 as the "target sequence," linked by a shared transition frame.
- **4D Reconstruction:** Mega-SaM was employed to recover scene geometry, extracting camera intrinsics, extrinsics, and per-frame depth maps.
- **Static Scene Extraction:** TSDF-Fusion was applied to the source frames' RGB-D observations to generate a clean reconstruction of the *static scene*. This process is key to suppressing dynamic elements.
- **Paired Training Data:** For the target sequence, static-region reconstructions and visibility masks were rendered using the fused geometry and target camera poses. The full RGB frames of the target sequence were retained as future supervision, providing ground truth for dynamic elements.
- **Action Annotation:** Qwen was used to generate annotations for actions in the future target frames.
- **Scale:** The final dataset comprises 90K structured video samples, each paired with explicit 3D spatial memory and future observations. During inference, CUT3R is used instead of Mega-SaM for online 4D reconstruction and point cloud fusion due to efficiency and alignment concerns.

This comprehensive approach, combining cognitive inspiration with advanced deep learning architectures, 3D reconstruction, and custom data curation, forms a robust framework for long-term consistent video generation.

### 4. Main Findings and Results

The research presents compelling quantitative and qualitative evidence to support the effectiveness of its memory-augmented video world model framework.

#### 4.1. Quantitative Evaluation

- **View Recall Consistency and Camera Accuracy (Table 1):**
 - The method was evaluated on reversed trajectories, where the same camera pose is revisited, allowing for comparison of reconstruction metrics (PSNR, SSIM, LPIPS) and Camera Accuracy (Cam-Acc).
 - **Results:** The proposed method achieved significantly higher PSNR (19.10 vs. 11.71-12.16), SSIM (0.6471 vs. 0.4380-0.4512), and lower LPIPS (0.3069 vs. 0.5874-0.5996) compared to baselines like TrajectoryCrafter, DaS, and Wan2.1-Inpainting. Camera Accuracy also saw a substantial improvement (3.6260 vs. 1.6320-2.5660).
 - **Implication:** This demonstrates that the geometry-grounded spatial memory mechanism is highly effective in maintaining consistency when revisiting previously generated parts of the world, directly addressing the core problem of forgetting static scene details.
- **Video Quality (VBench, Table 2):**
 - The model's general video quality was assessed using six VBench metrics, covering aesthetic quality, imaging quality, temporal flickering, motion smoothness, subject consistency, and background consistency.
 - **Results:** The proposed approach showed superior performance in aesthetic quality (0.5835), reduced temporal flickering (0.7580), smoother motion (0.9886), and improved subject consistency (0.9359). While Wan2.1-Inpainting marginally outperformed it in imaging quality and background consistency, the authors note that Wan2.1's tendency to generate relatively static scenes might artificially inflate its background consistency score.
 - **Implication:** The memory mechanisms not only improve consistency but also contribute to overall higher quality and more plausible video generation, particularly for dynamic elements and their interactions with the scene.

#### 4.2. Qualitative Evaluation (Figure 4)

Qualitative comparisons against baselines (TrajectoryCrafter, DaS, Wan2.1) further highlight the advantages of the proposed memory system across three key criteria:

- **Camera Trajectory Following:** The model exhibits superior ability to accurately follow complex camera trajectories, guided by its persistent point map rendering. Baselines often fail, especially with significant camera motions.
- **View Recall Consistency:** When comparing frames generated at the same camera pose at different points in the sequence, the proposed method demonstrates significantly higher consistency in static regions compared to baselines, validating the effectiveness of the static memory mechanism.
- **Action Generation and Static/Dynamic Integration:** The model excels at generating new actions based on instructions while harmoniously integrating them with the static memory. Baselines frequently show action drifting, severe deformation, or even character disappearance, failing to maintain coherence between dynamic subjects and the static environment.

#### 4.3. User Study (Table 1, right)

- A comprehensive user study involved 20 subjects with experience in video/3D/4D generation, ranking results from all four methods across three criteria: camera accuracy (Cam-Acc), static consistency (Stat-Cons), and dynamic plausibility (Dyn-Plaus).
- **Results:** The proposed method achieved the highest average human ranking (lower score indicating poorer quality implies higher ranking for our method), significantly outperforming baselines in all three metrics. For example, our method scored 3.6260 for Cam-Acc, 3.3846 for Stat-Cons, and 3.4011 for Dyn-Plaus, whereas the best baseline scores were 2.5660, 2.4396, and 2.7033 respectively.
- **Implication:** Human perception strongly confirms the model's superior performance in crucial aspects of long-term consistent video generation.

#### 4.4. Ablation Study (Table 3 & Figure 5)

- Ablation studies were conducted to assess the contribution of each memory component (working, episodic, spatial).
- **Results:** Removing any of the memory mechanisms led to a noticeable performance degradation across VBench metrics.
 - **Without working memory:** Significant drop in temporal flickering and motion smoothness, confirming its role in short-term motion coherence.
 - **Without episodic memory:** Reductions in aesthetic quality, imaging quality, and consistency, indicating its importance for retaining long-term visual details and improving plausibility of moving entities.
 - **Full model:** Achieves the best results across all metrics, validating the synergistic effect of combining all three memory types.
- **Implication:** Each proposed memory mechanism plays a crucial and distinct role in enhancing the model's ability to generate high-quality, consistent, and plausible long-term videos.

In summary, the main findings robustly demonstrate that the introduction of geometry-grounded long-term spatial memory, complemented by working and episodic memory, effectively addresses the long-standing challenge of consistency in video world models, leading to superior quantitative metrics, compelling qualitative results, and strong user preference.

### 5. Significance and Potential Impact

The work "Video World Models with Long-term Spatial Memory" represents a significant advancement in the field of generative AI, particularly for its contributions to achieving long-term consistency in video generation. Its significance and potential impact can be elaborated as follows:

#### 5.1. Addressing a Core Limitation

The most critical contribution is the effective tackling of the "forgetting problem" in video world models. By demonstrating significantly improved consistency over extended periods and during scene revisits, the paper moves beyond the limitations of short-term, context-window-constrained generation. This is a fundamental step towards making video world models truly capable of simulating persistent environments.

#### 5.2. Novelty in Memory Mechanisms

The approach of integrating distinct memory types—working, spatial, and episodic—inspired by human cognition, is highly novel. While previous works have explored architectural changes for longer contexts, this paper introduces a *semantic* and *geometry-grounded* form of memory. The explicit representation of static scene geometry as a point cloud, updated via TSDF fusion, and its disentangled integration into the diffusion model is a key innovation. This allows for precise control over static background consistency while simultaneously handling dynamic foreground elements.

#### 5.3. Paving the Way for Infinite-Length Generation

By enhancing long-term consistency, the research directly contributes to the vision of "infinite-length, consistent world generation." This is crucial for applications that require continuous, evolving environments rather than isolated clips. The ability to maintain scene and subject coherence over arbitrary lengths of time opens up new possibilities for generative AI.

#### 5.4. Impact on World Models and Simulation

The improved consistency makes video world models more robust and reliable for various applications:
- **Robotics:** More consistent and realistic simulated environments for training AI agents and robots, allowing for more complex long-horizon tasks and better generalization to the real world.
- **Computer Graphics and Content Creation:** Enables the creation of highly coherent and controllable virtual environments, reducing the need for manual consistency checks. This has massive implications for film, animation, and video game development, allowing for automated generation of realistic, extended scenes.
- **Interactive AI Systems:** Supports the development of AI systems that can "remember" and interact with their environment over prolonged periods, leading to more intelligent and adaptive agents.

#### 5.5. Advancing 3D-Aware Generation

The geometry-grounded nature of the spatial memory pushes the boundaries of 3D-aware video generation. Unlike many previous models that operate primarily in 2D pixel space, this work effectively leverages 3D understanding to solve a challenging 2D generation problem. This dual focus on geometric and temporal consistency is a powerful paradigm for future generative models.

#### 5.6. Future Research Directions

The paper also highlights limitations and inspires future research. Acknowledging issues like ghosting artifacts from abrupt camera movements in the 4D reconstruction, it points towards the need for more robust 3D reconstruction and fusion techniques. The distinction between static spatial consistency and character consistency (e.g., identity preservation) suggests potential for integrating this work with "frame packing" strategies. Furthermore, the paper explicitly states that it does not address "drift" (image quality degradation due to error accumulation), indicating another fertile ground for future research.

#### 5.7. Societal Implications

As with any powerful generative AI, the societal implications are noted. While offering immense benefits for content creation, these models can also be misused for generating deceptive content like DeepFakes. The authors acknowledge this risk and explicitly state their opposition to such malicious applications, underscoring the ethical considerations inherent in developing advanced generative technologies.

In conclusion, this research makes a profound contribution by offering a principled solution to a major hurdle in video world models. By mimicking the sophisticated memory systems of humans and grounding them in explicit 3D geometry, the authors have significantly advanced the capability of AI to generate long, consistent, and coherent virtual worlds, setting a new benchmark and opening numerous avenues for future innovation and application.
