# PromptDet: Towards Open-vocabulary Detection using Uncurated Images

> [!summary] Summary
> PromptDet presents a framework for open-vocabulary object detection, establishing an annotation-free pipeline that leverages a vision-language model (CLIP) and an iterative self-training strategy on uncurated web images. This approach achieves 21.4 AP_novel on LVIS and 26.6 AP50_box novel on MS-COCO, outperforming existing methods with lower resource requirements.

## Problem

- Traditional object detection models require extensive, expensive manual bounding box annotations for each new object category, limiting scalability and adaptability.
- A domain gap exists between scene-level image-text pairs used for Vision-Language Pre-training (VLP) and the object-centric proposals generated by object detectors.
- Lexical ambiguity in simple class names can hinder accurate classification of visual concepts in open-vocabulary settings.

## Method

- Integrates a pre-trained VLP model's (CLIP) frozen text encoder into a two-stage object detector to enable ==open-vocabulary classification== via cosine similarity between visual and textual embeddings.
- Implements ==Regional Prompt Learning (RPL)== by optimizing learnable prompt vectors and incorporating detailed descriptions with the text encoder, aligning object-centric visual features with textual representations.
- Develops an ==iterative self-training framework== that sources uncurated web images, generates pseudo-labels by selecting bounding boxes with maximal classification scores, and then retrains the detector's visual backbone and RPN.

## Results

- PromptDet achieved **21.4 AP** novel on the LVIS v1.0 validation set, surpassing ViLD-ens by **4.8 AP** and Detic by **3.6 AP** while using fewer additional training images.
- On the MS-COCO open-vocabulary benchmark, the method reached **26.6 AP50** box novel and **50.6 AP50** box all, outperforming Detic with the same input image resolution.
- Ablation studies confirmed that RPL improved novel category AP by **2.1 points** over manual prompts, and iterative self-training further boosted AP novel from **11.1** to **19.3**, demonstrating the efficacy of leveraging uncurated web images.

## Takeaways

> [!tip] Key Insights
> - Regional Prompt Learning (RPL) effectively bridges the domain gap between scene-level VLP and object-centric detection, improving alignment of visual and textual features for novel categories.
> - An iterative self-training process, combined with refined prompt learning and image sourcing, can robustly extract valuable supervision from vast, noisy, and uncurated web datasets.
> - Selecting pseudo-labels based on the maximal classification score from RPN proposals is a critical strategy for generating high-quality annotations from noisy uncurated images, significantly outperforming other heuristics.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Object detection has been a cornerstone of computer vision for decades, with modern frameworks largely categorized into two-stage (e.g., Faster R-CNN, Mask R-CNN) and one-stage (e.g., YOLO, FCOS) detectors. While these models have achieved remarkable accuracy, their primary limitation lies in their reliance on extensive, manually annotated datasets (like PASCAL VOC and MS-COCO) that define a fixed, closed set of object categories. Expanding these detectors to new, "novel" categories traditionally required further laborious annotation and retraining, making them unscalable for real-world applications with evolving object vocabularies.

This inherent scalability challenge has led to the emergence of **Open-Vocabulary Object Detection (OVD)** as a critical research area. OVD aims to enable detectors to recognize objects beyond the categories seen during initial training, often with minimal or zero additional annotations for novel classes. PromptDet directly contributes to this burgeoning field.

The broader landscape of OVD has seen several lines of inquiry:
- **Early Zero-Shot Detection (ZSD) methods** often replaced the final classification layer with language embeddings of class names or attempted to transfer knowledge from seen to unseen classes using visual attributes or semantic descriptors.
- **Leveraging External Text Information:** Some works integrated external textual descriptions during classifier embedding computation.
- **Contrastive Learning with Image-Text Pairs:** Approaches like OVR-CNN utilized contrastive learning on image-text pairs to align visual and textual representations for detection.
- **Knowledge Distillation from Vision-Language Pre-training (VLP) Models:** A significant breakthrough came with the advent of large-scale VLP models like CLIP (Contrastive Language-Image Pre-training) and ALIGN. These models, trained on billions of noisy image-text pairs, learned powerful joint visual-language embeddings. Methods like ViLD (Vision and Language Knowledge Distillation) and ZSD-YOLO leveraged CLIP's visual encoder to distill knowledge into object detection backbones.
- **Self-Training on Curated External Data:** Detic is a closely related work that sought to expand vocabulary by self-training on ImageNet21K, a large but *manually curated* dataset, still requiring significant human effort in its initial construction.

PromptDet situates itself firmly within the VLP-driven OVD paradigm but carves out a distinct niche by addressing several key limitations of prior art:
1. **Directly Leveraging CLIP's Text Encoder:** Unlike some methods that distill from CLIP's *visual* encoder, PromptDet focuses on using CLIP's *frozen text encoder* as a classifier generator, directly aligning object-centric visual features with textual embeddings.
2. **Bridging the Domain Gap with Regional Prompt Learning:** It explicitly tackles the domain gap between scene-centric images used for VLP (e.g., CLIP training) and object-centric proposals generated by RPNs. The proposed Regional Prompt Learning (RPL) mechanism recalibrates the textual latent space to better match localized object features, a novel approach to fine-tuning VLP models for detection.
3. **Harnessing Uncurated Web Images for Self-Training:** Crucially, PromptDet moves beyond curated external datasets (like ImageNet21K used by Detic) and demonstrates a robust self-training framework capable of effectively exploiting *noisy, uncurated web images* from sources like LAION-400M. This represents a significant step towards truly scalable OVD, as such data is vastly more abundant and requires no initial human annotation.
4. **Iterative Refinement:** The iterative prompt learning and image sourcing mechanism distinguishes PromptDet by enabling a continuous improvement loop for identifying and utilizing higher-quality external images.

In summary, PromptDet advances the state-of-the-art in OVD by proposing a pipeline that deeply integrates VLP models, innovative prompt learning, and a self-training strategy that thrives on the most challenging yet abundant data source: uncurated web images, all while adhering to the critical constraint of zero manual annotations for novel categories.

### 2. Key Objectives and Motivation

The primary objective of PromptDet is to **establish a scalable and annotation-free pipeline for expanding the vocabulary of an object detector to novel, unseen categories.** This ambitious goal is driven by several motivations:

- **Overcoming Annotation Bottlenecks:** Traditional object detection models are limited by the prohibitive cost and time required for manually annotating bounding boxes and category labels for every new object class. This restricts their scalability and adaptability to real-world scenarios where object vocabularies are vast and constantly evolving. PromptDet aims to eliminate this barrier by requiring "zero manual annotations" for novel categories.
- **Leveraging the Power of Vision-Language Pre-training (VLP):** The recent success of large-scale VLP models like CLIP and ALIGN in open-vocabulary image classification has demonstrated their capacity to learn generalized visual and linguistic representations from massive, noisy image-text pairs. The authors are motivated to harness this power for the more complex task of object detection.
- **Bridging the Scene-Object Domain Gap:** VLP models are typically trained on scene-level image-text pairs, where objects might occupy only a small portion of the image. In contrast, object detectors produce object-centric proposals. A direct application of VLP features often suffers from a "domain gap" between these global (scene) and local (object) representations. A key motivation is to devise a mechanism to align these distinct latent spaces effectively.
- **Addressing Lexical Ambiguity:** Simple class names alone can be semantically ambiguous (e.g., "almond" referring to a nut or a tree). The motivation is to enhance the precision of textual embeddings to accurately capture visual concepts.
- **Exploiting Abundant Uncurated Data:** Rather than relying on painstakingly curated datasets, the authors are motivated to develop a framework that can effectively utilize the immense, freely available, but noisy, corpus of uncurated web images. This addresses the challenge of data scarcity for novel classes by turning a potential liability (noise) into an asset.
- **Improving Generalization to Novel Categories:** The ultimate aim is to significantly boost the detection performance on object categories that the detector has never explicitly seen during supervised training, pushing the boundaries of generalization in object detection.

In essence, PromptDet seeks to democratize open-vocabulary object detection by making it highly scalable, resource-efficient, and capable of learning from the vast ocean of imperfect web data, thereby moving closer to truly adaptable and "open-world" AI vision systems.

### 3. Methodology and Approach

PromptDet proposes a two-stage open-vocabulary object detection framework that integrates a pre-trained vision-language model (CLIP) with novel prompt learning and self-training techniques. The methodology is structured around four core contributions:

#### 3.1. Open-Vocabulary Object Detector Foundation

The framework builds upon a standard two-stage object detector, such as Mask R-CNN, which consists of a visual backbone encoder ($\Phi_{ENC}$), a Region Proposal Network (RPN, $\Phi_{RPN}$), and a classification module ($\Phi_{CLS}$).
- **Class-Agnostic RPN:** The RPN is trained to generate high-quality object proposals independent of their category. This allows the RPN to suggest potential object locations for both base and novel categories.
- **Open-Vocabulary Classification:** The classification module is designed to categorize these proposals beyond a fixed vocabulary. It leverages a frozen text encoder ($\phi_{text}$) from a pre-trained VLP model (CLIP) as a "classifier generator." For a given visual object feature `v` (ROI-pooled from an RPN proposal), its probability of belonging to a category (e.g., "almond") is computed by measuring the cosine similarity between `v` and the textual embedding of that category (`c_almond`), typically generated from a template like "this is a photo of [category]". The visual backbone is trained to align regional visual embeddings with their corresponding textual embeddings.

#### 3.2. Alignment via Regional Prompt Learning (RPL)

To address the limitations of naive alignment (e.g., lexical ambiguity, domain gap between scene-centric VLP and object-centric RPN features), PromptDet introduces **Regional Prompt Learning (RPL)**.
- **Mechanism:** Instead of using fixed text templates, RPL prepends and appends a sequence of learnable "continuous prompt vectors" to the textual input that goes into the frozen CLIP text encoder. These vectors act as "virtual tokens" that are optimized to steer the textual latent space.
- **Enriched Descriptions:** To further mitigate lexical ambiguity, detailed descriptions (e.g., from Wikipedia) are integrated into the prompt template alongside the category name (e.g., "{category: “almond”, description: “oval-shaped edible seed of the almond tree”}").
- **Offline Optimization:** The prompt vectors are learned in an offline manner for computational efficiency. Object crops from the *base categories* of a dataset (e.g., LVIS-base) are fed through a *frozen CLIP visual encoder* to generate image embeddings. The learnable prompt vectors are then optimized using a standard cross-entropy loss to classify these image crops, effectively recalibrating the textual latent space to better match object-centric visual embeddings.

#### 3.3. PromptDet: Alignment via Self-training with Uncurated Images

To scale up the learning procedure and leverage vast online resources, PromptDet proposes an iterative self-training framework, illustrated in a three-stage process:

- **Stage I: Initial Regional Prompt Learning:** The prompt vectors are initially learned using object crops from the base categories (as described in 4.2).
- **Stage II: Iterative Image Sourcing:**
 - **Candidate Image Acquisition:** Utilizing a large corpus of uncurated image-text pairs, such as LAION-400M (which has pre-computed CLIP visual embeddings), the learned regional prompts are used to compute similarity scores between images and category embeddings for both base and *novel* categories. Images with the highest similarity scores are selected as "candidate images" (referred to as LAION-novel).
 - **Iterative Refinement:** This process can be iterated. The prompts can be re-learned using both the original base category images and additional base category images sourced from LAION-400M. These refined prompts are then used to source even higher-quality candidate images for novel categories. This iterative loop improves the precision of mining object-centric images.
- **Stage III: Bounding Box Generation and Self-training:**
 - **Pseudo-Labeling:** For each candidate image sourced in Stage II (which lacks ground truth bounding boxes), the current open-vocabulary detector performs inference. From the top-K object proposals generated by the class-agnostic RPN, the bounding box with the *maximal classification score* (most confident prediction) is selected as the pseudo ground truth. Multi-scale inference is employed for robust pseudo-label generation.
 - **Self-Training:** The detector's visual backbone and RPN (including the regression head) are then retrained using a combination of the original LVIS-base dataset (with true labels) and the newly sourced LAION-novel images (with pseudo-labels). This resembles a standard supervised training regime but leverages automatically generated annotations.

PromptDet's methodology distinguishes itself by its emphasis on *zero manual annotations* for novel classes, its explicit handling of the visual-textual domain gap through RPL, and its robust iterative self-training framework designed to extract valuable supervision from large-scale, noisy, and uncurated web data.

### 4. Main Findings and Results

PromptDet demonstrates superior performance and the effectiveness of its core components through extensive experiments on the LVIS and MS-COCO datasets.

#### 4.1. Ablation Studies

- **Effectiveness of Regional Prompt Learning (RPL):**
 - Using a simple manual prompt ("a photo of [category]") yielded 7.4 AP on novel categories (AP$_{novel}$).
 - Adding detailed descriptions to the manual prompt improved performance to 9.0 AP$_{novel}$ (+1.6 AP), reducing lexical ambiguity.
 - The proposed Regional Prompt Learning (RPL) with learnable prompt vectors further boosted performance to 11.1 AP$_{novel}$ (+2.1 AP over manual + description), confirming RPL's ability to better align textual and object-centric visual features.

- **Effectiveness of Self-training and Iterative Sourcing:**
 - Self-training alone (even with manual prompts) significantly improved AP$_{novel}$ (e.g., from 9.0 to 15.3 AP).
 - PromptDet, combining RPL and one-iteration self-training, achieved 15.9 AP$_{novel}$.
 - **Crucially, iterative prompt learning and image sourcing showed significant benefits:** 2-iteration PromptDet reached 19.0 AP$_{novel}$, and 3-iteration PromptDet achieved 19.3 AP$_{novel}$. This validates the framework's ability to iteratively source higher-quality images from uncurated web data, leading to substantial gains in open-vocabulary generalization.

- **Box Generation Strategy:**
 - The proposed strategy of selecting the bounding box with the **maximal classification score** as pseudo ground truth (max-pred.-score) proved superior, yielding 19.0 AP$_{novel}$.
 - This significantly outperformed other heuristics, such as using the whole image (9.9 AP$_{novel}$), the max-sized proposal (9.5 AP$_{novel}$), or the max RPN objectness score (11.3 AP$_{novel}$). This highlights the importance of confident predictions over mere size or objectness for noisy uncurated data.

- **Impact of Number of Sourced Web Images:**
 - Increasing the number of sourced uncurated web images for self-training (from 0 to 300 per novel category) monotonically improved performance on novel categories, increasing AP$_{novel}$ from 10.4 (no self-training) to 19.0 AP (300 images). This demonstrates the scalability and positive impact of leveraging more external data.

- **Updating RPN and Box Head During Self-training:**
 - Freezing the class-agnostic RPN classifier and bounding box regression head during self-training was detrimental, leading to a 1.8 AP drop compared to updating them (17.2 AP$_{novel}$ vs. 19.0 AP$_{novel}$). This indicates that the pseudo-labels provide valuable supervision not just for classification but also for refining object localization.

- **Top-K Proposals for Pseudo-labeling:**
 - Selecting the most confident prediction among the top-20 RPN proposals yielded optimal performance (19.0 AP$_{novel}$). Using all 1000 proposals performed poorly (10.4 AP$_{novel}$), emphasizing the need for quality control in pseudo-label generation.

#### 4.2. Comparison with State-of-the-Art

- **LVIS Dataset:** PromptDet (trained for 72 epochs with 0.1M external images) achieved **21.4 AP$_{novel}$** on the LVIS v1.0 validation set. This significantly surpasses:
 - ViLD-ens (16.6 AP$_{novel}$) by 4.8 AP.
 - Detic (17.8 AP$_{novel}$) by 3.6 AP.
 - Notably, PromptDet achieves this with *fewer additional training images* (0.1M vs. 1.2M for Detic) and *zero manual annotations* on those external images (Detic used *curated* ImageNet21K). PromptDet also has lower training costs (e.g., fewer epochs, smaller image resolution).

- **Open-Vocabulary COCO Benchmark:** PromptDet (trained for 24 epochs) achieved **26.6 AP50$_{box novel}$** and **50.6 AP50$_{box all}$** on the MS-COCO dataset (48/17 base/novel split). This outperforms Detic (24.1 AP50$_{box novel}$ and 44.7 AP50$_{box all}$) with the same input image resolution.

- **Cross-dataset Transferability:** A detector trained on LVIS-base using PromptDet's learnable prompts showed better generalization (29.0 AP$_{novel}$) when directly transferred to MS-COCO novel categories without fine-tuning, compared to using manual prompts (27.4 AP$_{novel}$).

In summary, PromptDet consistently achieves state-of-the-art performance in open-vocabulary object detection, particularly for novel categories, demonstrating the power of its regional prompt learning and self-training framework using uncurated web images.

### 5. Significance and Potential Impact

PromptDet represents a significant advancement in the field of open-vocabulary object detection, with profound implications for both academic research and real-world applications. Its significance can be broken down into several key areas:

- **Breaking the Annotation Barrier:** The most impactful contribution is the demonstration of a robust, scalable pipeline that achieves strong open-vocabulary detection performance with *zero manual annotations* for novel categories. This effectively addresses the long-standing bottleneck of data annotation, which has traditionally limited the scalability and practical deployment of object detectors in diverse and dynamic environments. It makes object detection accessible for tasks with rapidly changing or niche object vocabularies.

- **Effective Utilization of Uncurated Data:** PromptDet pioneers a highly effective method for leveraging the vast, but noisy, corpus of uncurated web images (like LAION-400M). Previous approaches often relied on meticulously curated datasets (e.g., ImageNet21K in Detic), which still involved significant human effort. PromptDet's ability to extract high-quality supervision from "found data" opens up new avenues for training powerful vision models at unprecedented scale and minimal human cost, pushing the boundaries of self-supervised and weakly-supervised learning.

- **Advancing Vision-Language Alignment:** The introduction of **Regional Prompt Learning (RPL)** is a critical methodological innovation. It provides a clever mechanism to bridge the inherent domain gap between global, scene-centric vision-language pre-training and local, object-centric detection tasks. By recalibrating the textual latent space to better fit object features, RPL maximizes the utility of pre-trained VLP models like CLIP for fine-grained object recognition. This concept could inspire similar prompt-tuning strategies for other downstream tasks involving VLP models.

- **Enhanced Generalization Capabilities:** The substantial performance gains on novel categories across challenging benchmarks (LVIS and MS-COCO) underscore PromptDet's superior generalization ability. This moves the field closer to truly "open-world" detectors that can adapt to an ever-expanding set of observable objects.

- **Industrial Relevance and Impact:** For large technology companies like Meituan, where diverse object recognition is crucial for services ranging from autonomous delivery and quality control to content understanding, PromptDet offers a direct and highly practical solution. It enables rapid expansion of detection capabilities for new products or operational items without incurring massive annotation costs, accelerating the deployment and evolution of AI-powered services.

- **Foundation for Future Research:** PromptDet establishes a strong baseline and a versatile framework for future research in several directions:
 - **More Advanced Prompt Engineering:** Exploring dynamic prompt generation or learning prompts that are even more context-aware.
 - **Robustness to Noise:** Further improving the resilience of self-training against even higher levels of noise and ambiguity in web data.
 - **Multi-modal Self-supervision:** Integrating other forms of weak supervision beyond image-text pairs.
 - **Task Generalization:** Extending the principles of PromptDet to other open-vocabulary tasks beyond object detection, such as instance segmentation or video object detection.

In conclusion, PromptDet is a landmark work that makes object detection significantly more scalable and accessible by innovatively harnessing the power of vision-language models and uncurated web data. Its emphasis on annotation-free expansion of object vocabularies positions it as a pivotal development in the journey towards truly intelligent and adaptable computer vision systems.
