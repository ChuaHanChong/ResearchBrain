# GeoAlign: Beyond Semantics with State-Guided Spatial Alignment in VLA Models

> [!summary] Summary
> GeoAlign, developed by researchers from institutions including Tongji University and Shanghai Jiao Tong University, introduces a framework for Vision-Language-Action (VLA) models that uses state-guided spatial alignment to enhance robot manipulation with geometry-aware features derived from RGB images. It achieves an average success rate of 78.8% on real-world ALOHA tasks, outperforming an RGB-only baseline by 13.8 percentage points on geometry-critical manipulation scenarios.

## Problem

- Current Vision-Language-Action (VLA) models often prioritize high-level semantic understanding, leading to failures in fine-grained manipulation tasks that require precise geometric detail.
- Challenges arise in tasks demanding tight clearances, exact alignments, contact-sensitive motions, or handling objects like transparent or annular structures where standard depth sensing can be unreliable.
- Existing methods struggle to dynamically select locally relevant geometry from visual inputs while maintaining a compact and efficient conditioning interface for continuous action generation.

## Method

- **GeoAlign** employs offline post-training of a pre-trained depth model's encoder on robot-domain RGB-D data to create Geometry-Enhanced Post-Trained (GEP) features from RGB images, without using predicted depth during policy execution.
- The robot's proprioceptive state dynamically generates query slots, which cross-attend to these GEP features, extracting compact, phase-dependent geometry tokens.
- These geometry tokens are then integrated with standard RGB-language semantic tokens to condition a flow-matching action decoder, enabling precise action generation with critical spatial awareness.

## Results

- GeoAlign achieved an average success rate of **99.0%** on the LIBERO benchmark, improving upon the RGB-only Isaac-GR00T N1.6-3B baseline's **97.0%**.
- On eight geometry-critical real-world ALOHA tasks, GeoAlign demonstrated an average success rate of **78.8%**, surpassing the RGB-only baseline (**65.0%**) and π0.5 (**67.5%**).
- Ablation studies confirmed that both robot-domain geometry post-training and proprioceptive state-guided querying were crucial for performance, with variants lacking these components showing up to an 7.4 percentage point decrease in LIBERO success.

## Takeaways

> [!tip] Key Insights
> - Adapting a depth-aware visual encoder on robot-specific RGB-D data allows for the distillation of robust geometry features from RGB images, making the system less susceptible to depth sensing failures with challenging objects.
> - Leveraging the robot's proprioceptive state to dynamically query and align with image-space geometry features enables the VLA model to focus on execution-relevant spatial cues as the task progresses.
> - Combining these compact, state-guided geometry tokens with high-level semantic context effectively bridges the gap between semantic understanding and the precise geometric intelligence needed for successful physical robot manipulation.
