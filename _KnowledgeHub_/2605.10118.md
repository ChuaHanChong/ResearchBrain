# Plan in Sandbox, Navigate in Open Worlds: Learning Physics-Grounded Abstracted Experience for Embodied Navigation

> [!summary] Summary
> The SAGE framework enables embodied agents to learn robust navigation capabilities from scratch, leveraging abstracted, physics-grounded experiences synthesized in a sandbox environment. It achieved state-of-the-art performance on embodied navigation benchmarks and demonstrated effective transfer to physical robot deployment.

## Problem

- Embodied navigation agents face data scarcity, lacking large-scale, aligned real-world vision and robot control datasets.
- The Sim2Real transfer problem arises from a modality gap between high-level VLM reasoning and low-level robot actuation, leading to brittle policies in physical environments.
- Reinforcement Learning approaches for embodied navigation suffer from sample inefficiency and the 'cold-start' problem without structured guidance or embodied priors.

## Method

- Introduces **SAGE**, a three-phase framework (==Genesis, Evolution, Navigation==) that generates, optimizes, and deploys embodied navigation policies.
- The Genesis phase leverages Vision-Language Models (VLMs) in a ==physics-grounded sandbox== to synthesize diverse navigation tasks and explicit ==IF-THEN experience rules== from multi-view trajectories, stored in a vector database for retrieval.
- The Evolution phase optimizes the agent's policy using ==hybrid prompt-augmented sampling== with a time-varying injection probability and ==Asymmetric Adaptive Clipping (AAC)==, which applies aggressive upper clipping bounds to augmented samples and conservative bounds to standard ones, within a ==Homogeneous Group Advantage Estimation== (GRPO-style) framework.

## Results

- SAGE (Qwen3-4B) achieved a new state-of-the-art on **A-EQA** with **60.2%** LLM-Match Success Rate (SR†) and **47.2%** SPL†, outperforming baselines and GPT-4o.
- Demonstrated strong performance on **GOAT-Bench**, with SAGE (Qwen3-4B) reaching **64.8%** Success Rate and **44.9%** SPL, significantly surpassing previous methods.
- Successfully deployed the framework on a **physical robot** for real-world indoor navigation and Q&A tasks, showcasing its practical transferability from sandbox learning.

## Takeaways

> [!tip] Key Insights
> - Synthesizing physics-grounded, abstracted experiences in a sandbox environment effectively mitigates data scarcity and the Sim2Real gap for embodied navigation agents.
> - An adaptive policy optimization strategy like Asymmetric Adaptive Clipping, combined with prompt augmentation, allows efficient distillation of VLM-generated semantic reasoning into robust control policies.
> - Decomposing complex navigation into VLM-selected subgoals (e.g., Frontier or Memory Nodes) that are executable by a geometric planner facilitates practical grounding of abstract intent into reliable robot behaviors.
