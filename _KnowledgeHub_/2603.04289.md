# IPD: Boosting Sequential Policy with Imaginary Planning Distillation in Offline Reinforcement Learning

> [!summary] Summary
> IPD introduces a framework that enhances Transformer-based sequential policies in offline reinforcement learning by integrating implicit dynamic programming via a quasi-optimal value function and explicit model predictive control. The method leverages an uncertainty-aware world model to augment suboptimal datasets with reliable, imagined optimal trajectories, demonstrating superior performance and improved stability across D4RL benchmarks.

## Problem

- Transformer-based policies in offline RL primarily perform conditional imitation, struggling to synthesize optimal policies or effectively "stitch" together optimal segments from suboptimal offline data.
- Current Transformer-based methods often lack explicit planning mechanisms and the principles of dynamic programming throughout their training and inference cycles.
- Manually specified `return-to-go` (RTG) values, commonly used to condition Transformer policies, are susceptible to tuning complexities and can lead to unstable decision-making during inference.

## Method

- Learns a robust quasi-optimal value function from the original offline dataset, utilizing Huber-expectile regression to mitigate value overestimation.
- Trains an uncertainty-aware probabilistic ensemble ==world model== that quantifies both aleatoric and epistemic uncertainty, employing a geometric Jensen-Shannon (GJS) divergence measure to filter unreliable rollouts.
- Augments the dataset by identifying suboptimal trajectory segments and generating high-quality, reliable new segments via Model Predictive Control (MPC) planning within the learned world model, ensuring operations in model-confident regions.
- Distills imaginary planning knowledge into the final Transformer policy through a composite loss that integrates MPC-enhanced data, action gradient guidance from the Q-function, and a dynamic quasi-optimal value function to replace conventional `return-to-go`.

## Results

- IPD achieved superior performance across a range of D4RL benchmarks, including Gym, Kitchen, and Adroit tasks, consistently outperforming state-of-the-art offline RL methods (e.g., **103.2** ± **3.7** on `hopper-medium-replay` and **78.4** ± **4.6** on `kitchen-complete`).
- Ablation studies confirmed that MPC-based data generation significantly outperformed greedy Q-learning for data augmentation, supporting the efficacy of the trained world model and MPC's strategic decision-making.
- Using a learned Quasi-Optimal Value (QOV) function as dynamic guidance resulted in significantly lower variance and improved stability during inference compared to manually tuned `return-to-go` values, which often led to performance degradation.

## Takeaways

> [!tip] Key Insights
> - Integrating implicit dynamic programming (via learned value functions) and explicit model predictive control (MPC) with uncertainty awareness can significantly enhance the planning capabilities and performance of Transformer-based policies in offline RL.
> - Reliable data augmentation using an uncertainty-aware world model and MPC-driven planning is crucial for generating high-quality, imagined trajectories that can effectively improve suboptimal offline datasets.
> - Replacing manually tuned `return-to-go` values with a learned, dynamic quasi-optimal value function provides more stable and robust guidance for Transformer policies during inference, reducing tuning complexity and improving performance consistency.
