# SkillWeaver: Web Agents can Self-Improve by Discovering and Honing Skills

> [!summary] Summary
> SkillWeaver is a framework that lets web agents improve themselves by exploring a new website and turning what they learn into reusable skills. The agent proposes skills, practices them, and distills successful runs into Python Playwright APIs. It then tests and debugs those APIs. This raises WebArena success by 31.8% and real-website success by 39.8% relative, and APIs from strong agents lift weaker ones.

## Problem

- Trajectory-based self-improvement stores skills implicitly as demonstrations or fine-tuning data. This yields heavy training demands, poor generalization to new websites, catastrophic forgetting, and bulky data that is hard to share between agents.
- Agent Workflow Memory and ICAL abstract routines in natural language. That makes formal verification and precise composition into new workflows difficult, and they rely on test-query access or annotated demonstrations.
- Web agents trained on large trajectory datasets overfit to specific website structures and task distributions. They cannot autonomously discover, refine, and compose procedural skills on unfamiliar sites without external supervision.

## Method

- ==Skill Proposal== uses an LLM as an ==automatic curriculum==. It sees screenshots, URLs, and ==accessibility trees==, and proposes novel short-horizon procedural, navigational, and information-seeking skills beyond the current library.
- ==Skill Synthesis== has the agent practice each proposed skill, and an ==LLM reward model== judges the trajectory. Successful runs become ==Python Playwright APIs== whose docstrings carry a usage log and prerequisite state.
- ==Skill Honing== runs each synthesized API as a ==unit test==, with LLM-generated parameter values where needed. It debugs failures with execution and reward-model feedback, so the ==skill library== stays reliable and composable.

## Results

- On WebArena with GPT-4o, average success rises from **22.6%** to **29.8%** after **160** exploration iterations, a **32%** relative gain. Per-site gains run from **23%** to **38%**.
- Transfer to a weaker agent works. GPT-4o-mini with GPT-4o-synthesized skills goes from **9.2%** to **14.1%** average, a **45%** gain, up to **133%** on CMS. Real-world Online-Mind2Web success goes from **40.2%** to **56.2%**.
- Synthesized APIs match human-crafted ones on low- and medium-support sites like Reddit and Shopping. They trail on high-support sites like GitLab and Map, and beat the SteP baseline on CMS and Map.

## Takeaways

> [!tip] Key Insights
> - Store learned skills as executable, verifiable code APIs rather than trajectories or natural-language routines. They are lightweight, testable, composable, and easy to share across agents without retraining or forgetting.
> - Skills distilled by a strong agent act as plug-and-play knowledge distillation. Weaker agents gain proportionally more, and a weak agent with these skills can beat a stronger unaugmented one.
> - The bottleneck shifts from skill creation to skill use. LLMs still pick the wrong API or pass bad parameters, and this hurts weaker models most, so tool-calling robustness caps the gains.

## Detailed Report

### 1. How This Work Fits Into the Broader Research Landscape

This work is positioned within the rapidly growing field of AI web agents and LLM-based automation. The significance of this paper lies in its unique approach to self-improvement through skill discovery and API synthesis, which addresses limitations of previous methods.
- **Existing Web Agents:** LLM-based web agents like those described by Deng et al. (2023), Zhou et al. (2024a), and Zheng et al. (2024) aim to automate web browsing and interaction tasks. However, they often struggle with generalization across diverse websites and task types due to overfitting to specific website structures.
- **Self-Improvement in AI:** The concept of self-improvement is recognized as a critical aspect of human intelligence, and recent studies have begun to explore how AI agents can achieve similar capabilities. Traditional methods involve storing skills as action trajectories for in-context learning or fine-tuning. However, these methods often lack explicit abstraction of reusable procedural knowledge.
- **Related Approaches:** Recent methods such as Agent Workflow Memory and ICAL generate abstract, reusable routines. However, these approaches rely on natural language-based routines, which pose challenges for formal verification and precise composition into new workflows. Additionally, they require external supervision or high-quality annotated demonstrations.
- **SkillWeaver's Contribution:** SkillWeaver contributes to the field by introducing a skill-centric framework that enables web agents to autonomously synthesize reusable APIs. The framework addresses the limitations of previous methods by explicitly abstracting reusable procedural knowledge, reducing training demands, and improving generalization to new websites and tasks.

### 2. Key Objectives and Motivation

The key objectives and motivation behind this research are:
- **Addressing the Challenges of Web Environments:** Recognizing the complexity and diversity of web environments, the authors aim to develop a generalist web agent capable of generalizing to out-of-distribution task types and adapting to novel websites.
- **Overcoming Limitations of Existing Approaches:** The authors identify limitations of existing efforts, such as overfitting to specific website structures and task distributions, high training demands, and limited generalization to new websites and tasks.
- **Inspired by Human Self-Improvement:** Drawing inspiration from human self-improvement mechanisms, the authors aim to equip web agents with similar capabilities to explore website environments, accumulate procedural knowledge as skills, compose simple skills into more complex ones, and leverage these learned skills to enhance their decision-making processes.
- **Introducing SkillWeaver:** To address these challenges, the authors propose SkillWeaver, a skill-centric framework that enables web agents to autonomously self-improve by exploring website environments and synthesizing reusable, structured skills.

### 3. Methodology and Approach

The methodology and approach employed in this research involve a three-stage pipeline:
- **Skill Proposal:** Identifying new skills for the agent to practice based on observations of the environment and available APIs in the skill library.
 - Leveraging LLMs as an automatic curriculum for discovering website functionalities.
 - Providing LLMs with detailed webpage observations, including screenshots, website names, URLs, and accessibility trees.
 - Emphasizing skill diversity by explicitly prompting LLMs to propose novel and reusable skills beyond the current skill repertoire.
 - Targeting short-horizon, reusable skills that can be completed within a single API call.
 - Following a curriculum progression from simple to complex skill compositions.
- **Skill Synthesis:** Practicing the proposed skills and converting practiced trajectories into reusable Python functions, encapsulating learned behaviors into structured APIs.
 - Leveraging a base agent to generate actions to repeatedly attempt to complete tasks.
 - Using a reward model to determine successful completion.
 - Synthesizing data extraction code to gather target information from webpages, incorporating any necessary navigation steps.
 - Prompting an LLM to provide reward signals indicating task completion success based on task description, action trajectory, and environmental feedback.
- **Skill Honing:** Testing and debugging the synthesized APIs using feedback from the environment and the reward model to ensure reliability.
 - Executing APIs directly as standalone unit tests.
 - Leveraging the LLM to generate appropriate parameter values that serve as comprehensive test cases.

### 4. Main Findings and Results

The main findings and results of this research are:
- **WebArena Results:**
 - Substantial performance improvements after equipping web agents with APIs synthesized by SkillWeaver.
 - Relative gains in success rate from 25% to 38% with just 160 iterations of the three-stage pipeline.
 - Even more dramatic improvements with weaker agents, ranging from 40% to 130%.
 - The synthesized APIs can substantially enhance agent performance, and weaker agents particularly benefit from APIs generated by more powerful counterparts.
- **Real-World Website Results:**
 - SkillWeaver achieved a 39.8% relative improvement in success rate on real-world websites.
 - Demonstrating the effectiveness of SkillWeaver in complex, dynamic web environments.
- **Generalization across Website:**
 - SkillWeaver is able to encapsulate skills and knowledge on website environments into code files containing accumulated skills.
 - Achieved stable performance improvements across all 5 WebArena websites and the 4 real-world live websites.
- **Generalization across Agents:**
 - Synthesized API library can be reused to expand and enhance the action space of other agents capable of API calling.
 - Demonstrated that the weaker agent based on GPT-4o-mini achieves remarkable relative success rate improvements ranging from 40% to 133% across five websites after integrating the synthesized APIs.
- **Comparison with Human-Crafted APIs:**
 - The performance of the synthesized APIs is comparable with human-crafted APIs on websites with low API support and those with medium API support.
 - Suggesting that the exploration process is capable of generating APIs with quality that is comparable to or even superior to manually crafted APIs found in official documentation.
- **Emergence of Compositional APIs:**
 - The pipeline begins to generate compositional APIs that call multiple simpler APIs after a certain number of exploration iterations.
 - Indicating an increasing level of abstraction and efficiency in SkillWeaver’s ability to synthesize and integrate discovered skills.

### 5. Significance and Potential Impact

The significance and potential impact of this research are:
- **Advancing the Field of AI Web Agents:** SkillWeaver presents a novel approach to self-improvement in AI web agents, which addresses limitations of existing methods and enhances the capabilities of web agents to adapt to diverse and complex web environments.
- **Improving Generalization and Transferability:** The framework enables web agents to generalize across different websites and agents, allowing them to leverage accumulated knowledge and skills in new environments.
- **Enhancing Agent Performance:** The experiments demonstrate substantial performance improvements after equipping web agents with APIs synthesized by SkillWeaver, indicating the effectiveness of the framework in enhancing agent capabilities.
- **Promoting Knowledge Distillation:** The results show that weaker agents can benefit from APIs generated by more powerful counterparts, effectively distilling advanced knowledge into plug-and-play modules.
- **Enabling Autonomous Self-Improvement:** The framework enables web agents to autonomously self-improve through exploration and API synthesis, reducing the need for manual intervention and improving the scalability of web automation.
- **Practical Applications:** The research has practical applications in various domains, such as web automation, information retrieval, e-commerce, and online services, where web agents can be used to automate routine tasks and enhance user experiences.
- **Future Directions:** This research opens up new avenues for future research, such as exploring more sophisticated exploration strategies, developing more robust reward models, and improving the composition and generalization capabilities of synthesized APIs. Additionally, this research highlights areas of LLM reasoning that need improvement, such as their ability to generate functional test cases for various sites.
