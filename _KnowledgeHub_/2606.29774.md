# Analytic Concept-Centric Memory for Agentic Embodied Manipulation

> [!summary] Summary
> Researchers at Zhejiang University and collaborators developed Analytic Concept-centric Memory (ACM), a structured memory framework for embodied agents performing long-horizon robotic manipulation tasks. The system enables agents to persistently track objects, reason about state changes, and reuse manipulation knowledge, achieving higher success rates on memory-demanding benchmarks and improved real-world performance compared to existing methods.

## Problem

- Existing agent memory systems (e.g., unstructured histories, textual summaries, embedding-based records) are often insufficient for the fine-grained, state-dependent demands of robotic manipulation tasks.
- Current long-horizon embodied task strategies either implicitly manage memory (end-to-end VLA policies) or lack a unified, language-addressable, object-structured, and execution-grounded memory interface (agentic systems), leading to inconsistent or inapplicable actions.
- Agents struggle with persistent object re-identification, robust state tracking, and efficient reuse of prior manipulation knowledge in dynamic physical environments over extended periods.

## Method

- The **Analytic Concept-centric Memory (ACM)** framework organizes experience around ==structured object concepts==, decomposing objects into semantic parts, parametric templates, geometric attributes, grounded poses, affordances, and manipulation states.
- **ACM** features ==stable prior knowledge== (semantic and template libraries) and ==dynamic experience memory== (object, scene, transition, and skill memories) which are updated online through a ==closed-loop system==.
- The framework integrates perception, memory retrieval, task reasoning, and robot execution by using ==manipulation-aware keys== for retrieval and explicitly ==checking preconditions and predicting effects== for skill selection.

## Results

- The proposed method achieved an average success rate of **70%** on the RMBench benchmark, outperforming reactive policies (**7-12%** SR) and memory-augmented VLA baselines (**28-53%** SR).
- It demonstrated improved concept generalization on PartNet-Mobility, with success rates for cross-object transfer increasing, for instance, from **22.3%** to **30.4%** for 'Washing Machine' compared to A3VLM.
- In real-world memory evaluation tasks, the system achieved an **84%** average success rate, significantly higher than a keyframe retrieval baseline (**56%** SR), with higher retrieval accuracy (**98%** vs. **68%**) and lower latency (**1.3s** vs. **4.5s**).

## Takeaways

> [!tip] Key Insights
> - Organizing memory around explicit, analytic object concepts with decomposed semantic parts and parametric templates allows for robust object persistence, state tracking, and fine-grained manipulation reasoning.
> - A unified memory interface, simultaneously language-addressable, object-structured, and execution-grounded, bridges the gap between high-level task instructions, environmental understanding, and low-level robot execution.
> - Explicitly linking actions to object state transitions and storing template-grounded skills facilitates effective knowledge transfer and generalization across different object instances and categories.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work addresses a challenge in the field of embodied artificial intelligence, specifically focusing on long-horizon robotic manipulation tasks in dynamic physical environments. Such tasks require agents to operate over extended periods, necessitating robust mechanisms for remembering objects, tracking state changes, and reusing accumulated knowledge.

Current approaches to agent memory and embodied manipulation face several limitations that this research attempts to overcome. Existing agent memory systems often store information as unstructured interaction histories, general scene observations, textual summaries, or embedding-based records. While these methods provide context, they are frequently insufficient for the specific demands of robotic manipulation. Unstructured memories can hinder efficient retrieval of task-relevant object parts, physical states, action effects, and executable skills. Embedding-based memories, while capturing similarity, typically lack explicit access to fine-grained information such as object parts, affordances, and the precise effects of actions. Scene-level or episode-level memories tend to describe past events without explicitly representing how object structures facilitate manipulation or how actions alter object states.

Furthermore, current strategies for long-horizon embodied tasks generally follow two paths:
1. **End-to-end Vision-Language-Action (VLA) policies:** These policies offer strong visuomotor execution capabilities but often keep task reasoning and memory largely implicit.
2. **Agentic systems:** These systems explicitly manage planning and tool use but frequently rely on manually specified skills or task-specific robot APIs. They often lack a unified memory interface that is simultaneously language-addressable, object-structured, and execution-grounded. This can lead to agents retrieving semantically relevant memories that are physically inapplicable or selecting skills without adequate verification of object states and part-level constraints.

This research positions itself as an effort to bridge these gaps by proposing an explicit memory framework designed to support persistent object reasoning, state-consistent execution, and compositional manipulation. It aims to unify object semantics, environmental understanding, and manipulation skills into a transferable memory representation, addressing the limitations of existing memory systems in real-world robotic interaction. The proposed Analytic Concept-centric Memory (ACM) framework seeks to provide an interface between perception, memory retrieval, task reasoning, and robot execution that is more structured and manipulation-aware than prior work.

### 2. Key Objectives and Motivation

The primary objective of this work is to enable embodied agents to perform long-horizon robotic manipulation tasks by augmenting them with a structured and persistent memory system. The motivation stems from the inherent demands of such tasks, which extend beyond immediate perception and reactive action, requiring agents to:

- **Remember persistent objects:** Agents need to maintain identity and characteristics of objects over time, even when they are not directly in view.
- **Track changing scene states:** The ability to record and recall how the environment and object states evolve due to agent actions or external factors is crucial for multi-step tasks.
- **Reuse prior interaction knowledge:** Efficiently leveraging past experiences, particularly regarding how objects can be manipulated and the effects of specific actions, can improve learning and performance.
- **Recover from execution failures:** A robust memory system can aid in diagnosing failures and selecting alternative strategies.

The authors identify specific shortcomings in existing memory systems that motivate their proposed Analytic Concept-centric Memory (ACM):

- **Inefficient retrieval in unstructured memories:** Memories stored as flat histories or raw observations make it challenging to efficiently retrieve information pertinent to manipulation, such as specific object parts, their physical states, or applicable actions.
- **Lack of explicit semantic and physical grounding in embedding-based memories:** While embedding-based memories capture similarity, they often do not provide explicit access to the functional components of objects (parts), their physical properties (affordances), or the precise effects of actions. This limits their utility for physical interaction where such details are critical.
- **Limited utility of scene- or episode-level memories for manipulation:** These memories typically describe "what happened" rather than "how object structures facilitate manipulation" or "how actions change object states," which is essential for planning and executing manipulation tasks.
- **Absence of a unified, explicit memory interface:** Existing VLA policies often have implicit memory, while agentic systems, despite explicit planning, lack a memory interface that is simultaneously addressable by language, structured around objects, and directly linked to execution capabilities. This gap can lead to incorrect skill application or state inconsistencies.

To address these, the core motivation for ACM is to organize experience around *structured object concepts* rather than raw data. An analytic concept represents an object by decomposing it into semantic parts, parametric templates, geometric attributes, grounded poses, affordances, and manipulation states. This structured representation is intended to explicitly store:
- **What an object is:** Its category and fundamental nature.
- **How it is composed:** Its constituent semantic parts.
- **Where it appears in a scene:** Its grounded 6D pose and geometric attributes.
- **How its state changes under actions:** The effects of manipulations.
- **Which executable skills can be applied to it:** Direct links to manipulation capabilities.

By making these elements explicit and interconnected, the ACM framework aims to establish a robust bridge between the agent's perception of the environment, its memory retrieval processes, its task reasoning capabilities, and its ability to execute robot actions.

### 3. Methodology and Approach

The proposed Analytic Concept-centric Memory (ACM) framework operates as a closed-loop system for long-horizon embodied manipulation. It processes instructions and observations, maintains a structured memory, performs reasoning, executes actions, and updates its memory based on execution outcomes.

#### 3.1. Analytic Concept Memory (ACM) Organization

The memory (`M`) is organized into stable prior knowledge and dynamic experience memory:
`M = {M_sem, M_temp, M_obj, M_scene, M_trans, M_skill}`.

- **Stable Prior Knowledge:** These components are fixed across episodes.
 - **Semantic Library (`M_sem`):** Stores natural-language synopses for templates, indexed by template type (`τ`). Each entry includes a description (`d_τ`), interaction affordances (`a_τ`), and intended functional use (`u_τ`). This library provides a language-level interface for template selection during grounding and retrieval.
 - **Template Library (`M_temp`):** Contains reusable analytic templates, also indexed by `τ`. Each template defines its valid parameter space (`Ω_τ`) and a set of supported manipulation functions (`F_τ`), which are implemented using atomic primitives (e.g., grasp, push, rotate). Templates provide symbolic and geometric blueprints.

- **Dynamic Experience Memory:** These components are updated online during interaction.
 - **Object Memory (`M_obj`):** Stores persistent, object-level analytic concepts grounded in the current environment. Each entry (`m_obj_k`) includes a persistent ID, object category, a collection of grounded semantic parts, the object's 6D pose, and its state and history. Each part `P_k,i` links to a template type from `M_temp` and is instantiated with scene-specific parameters, poses, affordances, and manipulation functions.
 - **Scene Memory (`M_scene`):** Tracks the evolving environment state as a graph (`G_t = (V_t, E_t)`). Nodes represent object instances, and edges encode spatial, visibility, containment, support, and state relations, supporting multi-step planning beyond immediate observations.
 - **Transition Memory (`M_trans`):** Records action-induced state changes for grounded objects and parts. An entry (`m_trans`) links a target object ID, its part, the executed skill/primitive, pre- and post-action states, and the execution outcome. This enables direct linking of action effects to object instances for precondition checking and effect prediction.
 - **Skill Memory (`M_skill`):** Stores executable procedures. Each skill (`m_skill_u`) has an identifier, type (template- or policy-grounded), associated template type (if applicable), target object/part schema, applicability preconditions, bound parameters, an execution backend (`π_exec`), and execution statistics. Template-grounded skills instantiate functions from `F_τ`, while policy-grounded skills invoke learned policies (e.g., finetuned VLA models).

#### 3.2. Memory Construction & Update

This module converts instructions, observations, and execution outcomes into memory updates.

- **Task and Scene Parsing:** The instruction `L` is decomposed into subtasks (`l`). The observation `o_t` is parsed to detect task-relevant objects, semantic parts, and environmental elements, extracting preliminary spatial, state, and functional relations. This forms a structured context `Q_t = (l, O_t, R_t)`.
- **Object and Scene Concept Grounding:**
 - Observed entities are grounded into analytic concepts. For each detected object, semantic parts are localized, matched to templates in `M_temp`, and instantiated into a grounded analytic concept `ˆO_k` with part parameters, poses, affordances, and candidate manipulation templates. This process uses a tool-augmented perception pipeline, including VLM-guided recognition, SAM-based segmentation, FoundationPose for 6D pose, and a Point-Transformer encoder for structural parameter estimation.
 - **Object Identity Resolution:** A hierarchical filtering process matches newly grounded objects `ˆO_k` to existing `M_obj` entries based on category and part-level consistency. A similarity score (`S_k,j`) combining geometric, pose, and relational factors determines merging with an existing identity or registering a new one.
 - The scene graph in `M_scene` is updated with persistent object nodes and observed relations.
- **Episode-Level Transition and Skill Updates:** After a subtask or episode, observed outcomes are consolidated. A transition entry (`m_trans`) is recorded for each executed skill/primitive. Successful template-based executions are abstracted into template-grounded skills in `M_skill`. Learned policies are also stored as policy-grounded skills. This converts scene-specific instances into reusable knowledge.

#### 3.3. Structured Memory Retrieval

Memory entries are indexed by manipulation-aware keys (object identities, part types, affordances, geometric signatures, scene relations, action tuples, applicability conditions, execution statistics). Retrieval follows a coarse-to-fine process:
- `Retrieve_coarse` identifies candidate categories, templates, and manipulation contexts.
- `Retrieve_fine` retrieves specific object, scene, transition, and skill entries using hard filters (category, part, affordance consistency) followed by ranking based on geometry, pose, scene state, transition applicability, and skill statistics.

#### 3.4. Memory-Grounded Reasoning and Execution

Retrieved memory entries are integrated with the current subtask to select an action plan.
- **Precondition Checking:** The agent checks if candidate skills are applicable by verifying their preconditions (`pre(u)`) against the current scene state (`G_t`).
- **Effect Prediction:** Transition memory is used to estimate the expected postcondition (`ˆs_t+1`) of an applicable skill, allowing the agent to avoid redundant or inconsistent actions.
- **Skill Selection and Execution:** An applicable skill (`u*`) consistent with the subtask is selected. Template-grounded skills are instantiated with object parameters and executed by a motion planner. Policy-grounded skills invoke learned VLA models.
- **Feedback and Update Loop:** The observed outcome (`o_t+1`) is compared with the predicted postcondition. If verified, object states, scene relations, transitions, and skill statistics are updated. If execution fails or contradicts prediction, the attempt is recorded, and the agent can re-query memory for an alternative skill.

### 4. Main Findings and Results

The research evaluates the Analytic Concept-centric Memory (ACM) framework across several dimensions, demonstrating its performance benefits over alternative memory systems.

#### 4.1. Memory-dependent Manipulation Results (RMBench)

Experiments on the RMBench benchmark, designed for memory-demanding manipulation tasks, indicated that the proposed method achieved a higher overall success rate compared to baselines.
- The method achieved an average success rate of 70% (Ours(DP) variant) and 66% (Ours(CS) variant), outperforming reactive policies like DP (7% SR) and π_0.5 (12% SR), as well as memory-augmented VLA baselines (Mem-0: 53% SR, Mem-VLA: 28% SR) and experience retrieval systems like MemER (31% SR).
- The results suggested that the explicit indexing of structural representations in ACM enabled more consistent subtask selection and reduced redundant or physically inconsistent actions, particularly in tasks requiring object persistence, state tracking, and action-effect reasoning. The performance of both concept-grounded and policy-based execution variants (Ours(CS) and Ours(DP)) indicated the memory's support for diverse skill backends.

#### 4.2. Concept Generalization (PartNet-Mobility)

Evaluation on articulated object manipulation tasks from PartNet-Mobility focused on transferring manipulation knowledge. The ACM framework consistently improved success rates across categories in both cross-instance and cross-object transfer settings.
- **Cross-instance transfer:** The method demonstrated improved robustness to geometric and pose variations within the same object category (e.g., Microwave: 52.2% SR compared to A3VLM's 49.7% SR).
- **Cross-object transfer:** This more challenging setting, which involves transferring part-level manipulation knowledge across different categories with similar articulation, showed larger gains. For instance, the success rate for "Washing Machine" increased to 30.4% from A3VLM's 22.3%, and for "Safe" to 50.6% from A3VLM's 40.0%.
- A "Semantic-memory" baseline, which stored only coarse category/affordance cues, performed significantly worse, suggesting that explicit modeling of reusable part-level templates and action effects is a critical factor for effective knowledge transfer.

#### 4.3. Real-World Memory Evaluation

Five real-world tabletop tasks, designed to specifically stress memory capabilities, were used for evaluation.
- The proposed method achieved an average success rate of 84%, which was a substantial improvement over a MemER-style keyframe retrieval baseline (56% SR).
- It also demonstrated higher retrieval accuracy (98% vs. 68% for the baseline) and lower retrieval effort (average query latency of 1.3 vs. 4.5 for the baseline).
- The improvements were attributed to the ACM's explicit indexing of persistent object identities, scene relations, state transitions, and executable skills, enabling more precise retrieval, state-dependent precondition verification, and appropriate skill selection with reduced candidate inspections. The structured representation also contributed to more efficient retrieval by narrowing the search space.

#### 4.4. Ablation Study (LLM Model Sensitivity)

An ablation study investigated the impact of different LLM models used for high-level reasoning (subtask decomposition, concept/skill selection, memory query formulation).
- Stronger LLMs (e.g., GPT-5.5, GPT-4o) generally led to higher task success rates on RMBench (69% and 67%, respectively) and improved retrieval accuracy (95% and 91%) compared to less capable models (e.g., Gemini-3.1-pro at 65% SR and 89% retrieval accuracy; Qwen-3.5 at 61% SR and 88% retrieval accuracy). This suggests that more precise subtask decomposition and memory queries from stronger LLMs translate into better execution.
- Object re-identification accuracy was observed to be less variable across different LLM models (ranging from 75% to 80%), indicating that this capability benefits primarily from the structured analytic concept representation and matching signals, rather than being heavily dependent on the LLM's reasoning abilities for identity resolution itself.

### 5. Significance and Potential Impact

This research presents a novel framework that addresses a fundamental challenge in embodied AI: enabling agents to perform complex, long-horizon manipulation tasks by leveraging persistent and structured memory. The introduction of an analytic concept-centric memory system signifies a notable contribution to the field.

The key significance lies in its departure from unstructured or purely embedding-based memory approaches. By organizing experience around structured analytic concepts, the framework establishes an explicit link between high-level language instructions, fine-grained object properties (parts, parameters, affordances), dynamic scene states, action effects, and executable robot skills. This integration facilitates capabilities that are crucial for advanced robotic autonomy:

- **Enhanced Object Persistence and Re-identification:** The memory structure allows agents to consistently track and re-identify objects across different observations and over extended periods, which is vital for multi-step tasks where objects may move or go out of view.
- **Improved State-Consistent Reasoning:** By explicitly storing and tracking scene states and action transitions, the agent can perform more robust reasoning about preconditions and postconditions, leading to more physically consistent and effective action selection and reducing redundant or inappropriate actions.
- **Effective Skill Reuse and Generalization:** The structured representation of objects and skills, particularly the use of template-grounded skills and the abstraction of experiences into transition memory, enables the agent to reuse manipulation knowledge across structurally similar objects and generalize skills to new instances or categories. This addresses a common limitation in learning-based robotics, where generalization can be challenging.
- **Bridging Symbolic and Embodied AI:** The framework effectively combines the interpretability and reasoning capabilities of symbolic, structured representations (analytic concepts) with the learning and execution power of modern visual-language-action models and motion controllers.

The potential impact of this work extends to various aspects of robotics and AI:

- **Robust Autonomous Systems:** It offers a pathway towards developing more robust and autonomous robotic systems capable of operating in complex, dynamic, and open-ended environments for extended periods without constant human supervision.
- **Faster Task Acquisition:** By allowing agents to accumulate and reuse manipulation knowledge, it could accelerate the acquisition of new manipulation skills and the adaptation to new tasks and objects.
- **Improved Human-Robot Interaction:** A more structured and interpretable memory system could potentially lead to more transparent and explainable agent behaviors, facilitating better human-robot collaboration and trust.
- **Foundation for Future Research:** The framework lays a foundation for future advancements, such as scaling the template library to handle deformable objects, improving robustness to perception noise and state drift, and exploring hybrid learning-based retrieval methods while retaining the interpretability of analytic concepts. This suggests the work is a step towards more capable and general-purpose embodied agents.
