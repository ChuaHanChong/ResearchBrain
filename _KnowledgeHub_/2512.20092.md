# Memory-T1: Reinforcement Learning for Temporal Reasoning in Multi-session Agents

> [!summary] Summary
> The MEMORY-T1 framework enables conversational agents to perform robust temporal reasoning in multi-session dialogues using a reinforcement learning-based memory retrieval system. It achieved a 67.0% overall score on the Time-Dialog benchmark, outperforming larger language models and specialized agents by over 17 percentage points, while maintaining performance across long contexts and noisy data.

## Problem

- Large Language Models (LLMs) struggle with accurate temporal reasoning in extended, multi-session dialogues, often treating history as flat text and failing to resolve ambiguous time expressions.
- Existing memory-augmented LLM frameworks degrade in lengthy and noisy real-world conversations, as they lack effective mechanisms to filter temporally irrelevant information.
- Previous time-aware approaches often rely on explicit supervision, handcrafted structures, or structured metadata, limiting their applicability to unstructured conversational data and leading to error accumulation.

## Method

- MEMORY-T1 employs a ==coarse-to-fine filtering== principle for memory retrieval, initially using an LLM to predict temporal windows for hard filtering, followed by a retriever (BM25) for relevance filtering.
- A reinforcement learning (RL) agent, trained with Group Relative Policy Optimization (GRPO), performs fine-grained evidence selection, explicitly citing chosen session IDs before generating the answer.
- A dense, multi-level reward function integrates task accuracy, evidence grounding (Jaccard Index), and a novel temporal consistency reward (chronological proximity and fidelity at session/utterance levels) to guide RL training.

## Results

- MEMORY-T1 (**7B**) achieved a state-of-the-art overall score of **67.0%** on the Time-Dialog benchmark, outperforming larger LLMs (e.g., Qwen2.5-**14B**) and specialized agents (e.g., Time-R1 by 17.6 percentage points).
- Ablation studies confirmed the criticality of the multi-level reward function; removing the temporal consistency reward component led to a **5.1%** overall performance drop, and removing all dense rewards resulted in a **22.4%** drop.
- The framework demonstrated high robustness to increasing context lengths, maintaining stable F1 scores up to 128k tokens, and exhibited strong out-of-domain generalization, achieving **37.7%** on the LoCoMo benchmark in a Non-RAG setting.

## Takeaways

> [!tip] Key Insights
> - A dense, multi-level reward function is essential for effective RL training in complex temporal reasoning, significantly improving performance over sparse, task-accuracy-only rewards.
> - A coarse-to-fine memory filtering strategy enables robustness and consistent performance even with extremely long and noisy dialogue histories, mitigating the 'lost in the middle' problem.
> - Learning a specialized, temporal-aware memory selection policy through reinforcement learning is more effective for temporal reasoning than relying solely on increased LLM context window size or general retrieval-augmented generation.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of conversational AI, particularly with the advent of Large Language Models (LLMs), has seen rapid advancements. However, a critical and persistent challenge remains the ability of these agents to perform robust **temporal reasoning** over extended, multi-session dialogues. This paper directly addresses this gap, positioning itself at the intersection of several key research areas:

- **Long-Context LLMs and Memory Architectures:** Recent LLMs have significantly increased their context windows, aiming to handle longer conversations. However, as highlighted by works like Liu et al. (2024) on the "lost in the middle" problem, simply expanding context size does not inherently grant robust reasoning capabilities, especially temporal ones. Existing memory-augmented LLM frameworks (e.g., MemAgent, MemoryBank) focus on general information retrieval but often treat dialogue history as flat text, struggling to correctly order events, identify temporal relationships, or resolve ambiguous time expressions. MEMORY-T1 directly tackles this by proposing a *temporal-aware* memory selection mechanism.
- **Temporal Reasoning in LLMs:** There is a growing recognition that LLMs struggle with temporal understanding. Benchmarks like TimeBench (Chu et al., 2024) and TIME (Wei et al., 2025) explicitly expose these deficiencies. Prior research in this area has explored aligning knowledge with temporal contexts (Zhao et al., 2024), specialized temporal training (Timo, TG-LLM), or rule-based systems (TReMu, Ge et al., 2025). However, these often rely on explicit supervision, handcrafted structures, or struggle with ambiguous temporal expressions and error accumulation. MEMORY-T1 distinguishes itself by learning implicit memory selection and temporal alignment through reinforcement learning, without external tools, thus offering a more adaptive and generalizable solution for unstructured dialogue.
- **Reinforcement Learning (RL) for LLM Agents:** RL is increasingly a core technology for enhancing LLM reasoning, planning, and tool-use capabilities. Algorithms like PPO, DPO, and GRPO (Zheng et al., 2025) are used to fine-tune LLMs for specific objectives, enabling models like DeepSeek-R1 and Search-R1 to exhibit improved reasoning and interaction with external tools. MEMORY-T1 extends this trend by applying RL to the highly specific, yet critical, problem of temporal reasoning in memory retrieval. It utilizes RL to teach an agent how to intelligently select *temporally relevant* information from a noisy memory bank, going beyond simple fact retrieval.
- **Retrieval-Augmented Generation (RAG):** While RAG (Lewis et al., 2020) is a popular paradigm for grounding LLMs in external knowledge, this paper shows that a naive RAG approach for temporal reasoning in multi-session dialogues is insufficient. MEMORY-T1 integrates a sophisticated, RL-driven retrieval *policy* that is specifically optimized for temporal consistency, rather than just semantic relevance, ensuring that the retrieved context is not only pertinent but also chronologically accurate.

In essence, MEMORY-T1 pushes the boundaries of conversational AI by providing a robust, data-driven approach to a long-standing challenge that traditional LLMs and simpler RAG systems have failed to solve effectively. It demonstrates that intelligent, temporally-aware memory management is crucial for the next generation of conversational agents capable of truly understanding and engaging in long-term interactions.

### 2. Key Objectives and Motivation

The central objective of this research is to develop a robust and scalable framework, **MEMORY-T1**, that enables conversational agents to perform accurate **temporal reasoning over long, multi-session dialogues**.

The primary motivations driving this work stem from critical limitations observed in existing AI systems:

1. **Inadequacy of Current Long-Context Models:** Despite significant advancements in LLMs and their ability to handle longer input contexts, a pilot study and existing literature (Wu et al., 2025; Maharana et al., 2024) consistently demonstrate that these models struggle with temporal reasoning in extensive dialogue histories. They tend to treat dialogue as flat text, failing to accurately identify, order, or resolve implicit temporal expressions. This leads to fundamental errors such as incorrectly ordering past events, conflating information from different sessions, and generating factually inconsistent or inaccurate answers.
2. **Challenge of Noise and Length in Real-World Dialogues:** Real-world multi-session dialogues are inherently lengthy and noisy, containing vast amounts of information, much of which is temporally irrelevant to a given query. Existing models degrade significantly in such environments, illustrating a crucial need for effective information filtering and selection.
3. **Limitations of Existing Time-Aware Approaches:** While some frameworks (e.g., TReMu, Ge et al., 2025) attempt temporal reasoning, they often falter with ambiguous temporal expressions ("the week before that") and suffer from error accumulation due to their reliance on inferred event summaries. Other RL-based temporal models (e.g., Time-R1, Liu et al., 2025) heavily depend on structured metadata, rendering them ineffective for unstructured conversational data.
4. **Sparse Supervision in RL Training:** Training an agent to select precise evidence for temporal reasoning is challenging due to the sparse nature of answer-only supervision. A model trained solely on answer accuracy often fails to develop effective temporal understanding or robust retrieval policies. This necessitates a richer, more structured reward signal.

Therefore, MEMORY-T1 is motivated by the need for a solution that can:
- Accurately locate and resolve both explicit and ambiguous temporal expressions.
- Ground answers in the correct, temporally pertinent dialogue sessions.
- Maintain robustness in the face of long, noisy conversational histories.
- Overcome the limitations of sparse reward signals in reinforcement learning for complex reasoning tasks.

The ultimate goal is to enable conversational agents to achieve factual consistency and logical coherence across extended interactions, which is essential for more intelligent and trustworthy AI assistants.

### 3. Methodology and Approach

MEMORY-T1 introduces a novel, reinforcement learning-based memory retrieval framework designed specifically for temporal reasoning in multi-session dialogues. Its methodology is built upon a **coarse-to-fine filtering principle** combined with a **dense, multi-level reward function**.

The framework operates in two main phases:

#### 3.1. Phase 1: Candidate Generation (Coarse-grained Filtering)

This phase aims to efficiently narrow down the vast and potentially noisy dialogue history (memory bank M) into a manageable set of high-recall candidate sessions. This cascade ensures that the subsequent fine-grained selection operates on a relevant and reduced search space.

1. **Temporal Filtering:** Given a user query `q`, an LLM is first used (in a zero-shot manner) to predict the target temporal window (`t_start`, `t_end`) relevant to the query. This predicted time range acts as a *hard filter*, discarding any dialogue sessions whose timestamps (`τ_i`) do not overlap with this predicted window. This step drastically reduces the search space based on a strong temporal heuristic, creating a temporally-filtered set `M_temp`.
2. **Relevance Filtering:** From the `M_temp` sessions, a standard retriever (BM25 is used in the implementation) is employed to rank the remaining sessions based on their textual relevance to the query `q`. The top-ranked `k` sessions are then selected to form the final candidate pool `C`. This step ensures that the candidates are not only temporally relevant but also textually pertinent, fitting within the agent's context budget.

#### 3.2. Phase 2: Fine-grained Selection via Reinforcement Learning

After the candidate pool `C` is established, a reinforcement learning (RL) agent performs the crucial fine-grained evidence selection and answer generation.

1. **RL Agent Policy:** The agent's policy `π_θ` takes the query `q` and the candidate pool `C` as input. Its output is a composite string explicitly citing the chosen session IDs as evidence (e.g., `{selected_memory: [session_3, session_16]}`) followed by the natural language answer. This integrated action space allows the model to learn a direct correlation between the evidence it selects and the answer it generates.
2. **RL Algorithm:** The agent is trained using **Group Relative Policy Optimization (GRPO)** (Zheng et al., 2025). GRPO is chosen for its effectiveness in LLM fine-tuning, particularly for mitigating high reward variance by utilizing a batch-average baseline. The objective function maximizes an advantage-weighted log-probability of sampled outputs, regularized by a KL divergence term against a frozen reference policy (`π_ref`) to maintain training stability.

#### 3.3. Multi-Level Reward Design (Core Contribution)

To address the challenge of sparse supervision in complex temporal reasoning, MEMORY-T1 introduces a novel, dense, multi-level reward function. The overall reward `R` is a weighted sum of three components (`w_a R_a + w_g R_g + w_t R_t`), with a fixed penalty if parsing the model's output fails.

1. **Accuracy Reward (`R_a`):** This reward directly measures the correctness of the final predicted answer. It is multifaceted and tailored to different answer formats:
 - **Option Answers:** Strict Exact Match (EM).
 - **Timestamp Answers:** Unit-aware Accuracy, canonicalizing date/time formats.
 - **Time Interval Answers:** ε-Exact Match (ϵ-EM), allowing a small tolerance for numerical durations.
 - **Sequential Answers (Event Order):** Hamming Accuracy, providing partial credit for correctly ordered items.
 The reward is normalized to [-1, 1], with 0 score mapping to -1 and positive scores mapping to themselves.

2. **Evidence Grounding Reward (`R_g`):** This component incentivizes the model to select the correct dialogue session(s) as evidence. It is calculated using the Jaccard Index between the agent's selected session IDs and the gold-standard evidence set (`M^*`) from the dataset, scaled to [-1, 1].

3. **Temporal Consistency Reward (`R_t`):** This is a novel and crucial component that ensures fine-grained temporal alignment. It provides dense signals at two levels:
 - **Chronological Proximity (`R_s`, session-level):** Measures the temporal distance between the timestamp of a selected session and the gold temporal range (`I_Q`) of the query. It uses a logistic function to apply a *soft, differentiable penalty*, allowing for some imprecision (e.g., a 7-day tolerance margin) while heavily penalizing distant sessions. This handles real-world ambiguities better than hard cutoffs.
 - **Chronological Fidelity (`R_f`, utterance-level):** Evaluates the quality of events *within* each utterance of a selected session. It rewards sessions dense with evidence whose events are *actually temporally aligned* with the query's `I_Q`. Individual events are scored (+1 for full overlap, +0.5 for partial, -1 for no overlap), then averaged across relevant utterances and sessions. This prevents the model from selecting a broadly relevant session but grounding an answer in a temporally incorrect utterance within it.

#### 3.4. Dataset Augmentation

The research utilizes the Time-Dialog benchmark, extending it from the existing Time dataset. Crucially, the dataset is augmented with fine-grained annotations specifically for training-time reward computation:
- Target temporal range (`I_Q`) for each query.
- Ground-truth evidence sessions (`M^*`) and utterances.
- Utterance-level events with their time spans, distinguishing event time from utterance time.
These annotations are *only* used for calculating rewards during training and are **never accessible during inference** to ensure a fair and realistic evaluation. GPT-4 assisted with initial annotations, followed by human verification to achieve high accuracy.

### 4. Main Findings and Results

MEMORY-T1 achieved significant advancements in temporal reasoning for multi-session agents, demonstrated through comprehensive experiments and ablation studies.

1. **State-of-the-Art Performance:**
 - MEMORY-T1 (7B) achieved an overall score of **67.0%** on the Time-Dialog benchmark, setting a new state-of-the-art for open-source models. The 3B model also performed exceptionally well at 66.9%.
 - It **outperformed larger baseline LLMs**, including Qwen2.5-14B (60.7%), Gemma-4B (45.0%), and Llama-3-8B (48.4%), highlighting that its learned policy is more critical than raw model scale for this task.
 - It **surpassed closed-source models** like GPT-4 (Full Prompt: 64.8%, ReAct: 62.8%), although a gap remained to GPT-4 with oracle evidence (86.2%).
 - It **significantly out-performed specialized SOTA agents** such as Time-R1 (49.4%) and MemAgent (49.9%) by over 17 absolute percentage points, confirming the effectiveness of its targeted training.
 - The model showed particularly strong performance on complex reasoning tasks like Order Reasoning (OR) and Range Reasoning (RR), directly validating its temporally grounded memory selection policy.

2. **Crucial Role of Multi-Level Reward Function (Ablation Studies):**
 - Training with **only task accuracy (R_a)** led to a catastrophic **22.4% overall performance drop**, with complex reasoning tasks collapsing, underscoring the necessity of dense, structured rewards.
 - Removing the **evidence grounding reward (R_g)** resulted in a **9.1% overall drop**, severely impacting localization and extraction tasks (Category A: -17.4%), confirming its role in ensuring correct evidence usage.
 - Removing the entire **temporal consistency reward (R_t)** component caused a **5.1% overall drop**, with a notable **-19.9% reduction** in the most complex reasoning tasks (Category C).
 - A more granular ablation showed a crucial synergy: removing *only* the session-level chronological proximity (`R_s`) surprisingly *improved* simpler tasks (Category A: +23.4%) but **collapsed complex reasoning (Category B: -56.2%)**. This indicates `R_s` and `R_f` (chronological fidelity) provide complementary constraints, and removing one without the other can lead to unexpected trade-offs or a complete failure in holistic temporal understanding.

3. **Robustness in Long-Context Scenarios:**
 - MEMORY-T1 demonstrated exceptional resilience to increasing context lengths, maintaining a **high and stable F1 score even up to 128k tokens**.
 - In stark contrast, baseline models (e.g., Qwen2.5-7B) showed severe performance degradation (over 30 F1 points drop) as context length increased, suffering from the "lost in the middle" effect.
 - This resilience created a performance gap that widened dramatically, reaching a **+25.0 percentage point lead** for MEMORY-T1 (7B) in the 64k-128k token bracket, directly attributable to its effective context filtering and learned policy.

4. **Out-of-Domain (OOD) Generalization:**
 - On the LoCoMo benchmark, MEMORY-T1 achieved a top score of **37.7%** in the Non-RAG setting, outperforming the base Qwen-2.5-3B model (33.5%) and showing better generalization than RAG-based approaches for this task. This suggests that the model learned a superior internal memory management skill applicable across domains.

5. **Robustness under Time Label Noise:**
 - MEMORY-T1 showed strong robustness to realistic levels of time label noise. With 5% noise, its overall F1 score remained **67.0%**. Even at 20% noise, it maintained **60.0%**, with key temporal reasoning tasks remaining highly performant. This indicates its practical applicability in real-world scenarios where data may be imperfect.

6. **Efficiency:**
 - The framework introduced negligible additional inference latency, averaging **1.26 seconds per query**, comparable to baselines. The retrieval overhead was minimal (0.01 seconds), confirming that its improved performance does not come at a significant computational cost during inference.

### 5. Significance and Potential Impact

The MEMORY-T1 framework represents a significant leap forward in the capabilities of conversational AI, particularly for applications requiring sophisticated temporal reasoning. Its impact extends across several dimensions:

1. **Enabling Reliable Long-Term Conversational Agents:** This work is a critical step towards building more reliable, factual, and logically consistent long-term conversational agents. By effectively addressing the challenge of temporal reasoning across multiple dialogue sessions, MEMORY-T1 allows agents to remember events accurately, understand chronological relationships, and provide coherent responses grounded in a comprehensive understanding of past interactions. This is crucial for applications like personal assistants, customer support, mental health companions, and complex task-oriented dialogues where long-term memory and temporal accuracy are paramount.

2. **Addressing Core LLM Limitations:** MEMORY-T1 directly tackles fundamental limitations of current LLMs, specifically the "lost in the middle" problem and their struggle with ambiguous temporal expressions in long contexts. The framework demonstrates that intelligent, policy-driven memory retrieval can shield LLMs from irrelevant information, allowing them to maintain high performance even with extremely long and noisy dialogue histories where unaugmented models fail.

3. **Novelty in Reinforcement Learning for NLP:** The introduction of a dense, multi-level reward function, particularly the temporal consistency reward (`R_t`) at both session and utterance levels, is a significant methodological contribution. This innovative reward design provides a blueprint for overcoming sparse supervision challenges in complex reasoning tasks, offering richer signals that guide the RL agent to learn nuanced temporal alignment rather than just superficial accuracy. This approach could inspire similar multi-faceted reward designs for other challenging LLM reasoning problems.

4. **Efficiency and Accessibility of Advanced AI:** By enabling a 3B parameter model to outperform significantly larger models (e.g., 14B Qwen2.5, 8B Llama-3, even GPT-4 in some settings), MEMORY-T1 demonstrates that advanced temporal reasoning capabilities can be achieved without relying solely on ever-larger LLM scales. The coarse-to-fine retrieval strategy combined with a lightweight RL agent makes these sophisticated capabilities more accessible, deployable, and resource-efficient for a wider range of applications and hardware constraints.

5. **Broader Implications for Knowledge Management and Narrative Understanding:** Beyond conversational agents, the principles of temporally-aware memory selection and reasoning have broader implications. They could enhance systems for knowledge graph construction, narrative summarization, event extraction from large text corpora, and any domain where understanding event sequences and their timing is critical for accurate interpretation and querying.

6. **Fostering Open Science and Reproducibility:** The commitment to publicly releasing the annotated dataset and source code is commendable. This will lower barriers for future research, enable fair comparisons, and accelerate advancements in temporal reasoning for AI, benefiting the broader scientific community.

In conclusion, MEMORY-T1 represents a robust and innovative solution to a long-standing challenge in conversational AI. By integrating a sophisticated RL-driven memory retrieval policy with a novel temporal-aware reward system, it paves the way for a new generation of conversational agents that are not only smarter but also more factually consistent and reliable in long-term interactions.
