# Memory-T1: Reinforcement Learning for Temporal Reasoning in Multi-session Agents

> [!summary] Summary
> The MEMORY-T1 framework enables conversational agents to perform robust temporal reasoning in multi-session dialogues using a reinforcement learning-based memory retrieval system. It achieved a 67.0% overall score on the Time-Dialog benchmark, outperforming larger language models and specialized agents by over 17 percentage points, while maintaining performance across long contexts and noisy data.

## Problem

- Large Language Models (LLMs) struggle with accurate temporal reasoning in extended, multi-session dialogues, often treating history as flat text and failing to resolve ambiguous time expressions.
- Existing memory-augmented LLM frameworks degrade in lengthy and noisy real-world conversations, as they lack effective mechanisms to filter temporally irrelevant information.
- Previous time-aware approaches often rely on explicit supervision, handcrafted structures, or structured metadata, limiting their applicability to unstructured conversational data and leading to error accumulation.

## Method

- MEMORY-T1 employs a ==coarse-to-fine filtering== principle for memory retrieval, initially using an LLM to predict temporal windows for hard filtering, followed by a retriever (BM25) for relevance filtering.
- A reinforcement learning (RL) agent, trained with Group Relative Policy Optimization (GRPO), performs fine-grained evidence selection, explicitly citing chosen session IDs before generating the answer.
- A dense, multi-level reward function integrates task accuracy, evidence grounding (Jaccard Index), and a novel temporal consistency reward (chronological proximity and fidelity at session/utterance levels) to guide RL training.

## Results

- MEMORY-T1 (**7B**) achieved a state-of-the-art overall score of **67.0%** on the Time-Dialog benchmark, outperforming larger LLMs (e.g., Qwen2.5-**14B**) and specialized agents (e.g., Time-R1 by 17.6 percentage points).
- Ablation studies confirmed the criticality of the multi-level reward function; removing the temporal consistency reward component led to a **5.1%** overall performance drop, and removing all dense rewards resulted in a **22.4%** drop.
- The framework demonstrated high robustness to increasing context lengths, maintaining stable F1 scores up to 128k tokens, and exhibited strong out-of-domain generalization, achieving **37.7%** on the LoCoMo benchmark in a Non-RAG setting.

## Takeaways

> [!tip] Key Insights
> - A dense, multi-level reward function is essential for effective RL training in complex temporal reasoning, significantly improving performance over sparse, task-accuracy-only rewards.
> - A coarse-to-fine memory filtering strategy enables robustness and consistent performance even with extremely long and noisy dialogue histories, mitigating the 'lost in the middle' problem.
> - Learning a specialized, temporal-aware memory selection policy through reinforcement learning is more effective for temporal reasoning than relying solely on increased LLM context window size or general retrieval-augmented generation.
