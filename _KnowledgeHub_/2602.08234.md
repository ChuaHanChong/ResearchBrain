# SkillRL: Evolving Agents via Recursive Skill-Augmented Reinforcement Learning

> [!summary] Summary
> Researchers from the University of North Carolina at Chapel Hill and collaborators developed SKILLRL, a framework enabling Large Language Model (LLM) agents to learn and recursively evolve abstract skills from diverse experiences. SKILLRL achieves state-of-the-art performance with a 89.9% success rate on ALFWorld, 72.7% on WebShop, and an average score of 47.1% on search-augmented QA tasks, outperforming larger closed-source models and memory-augmented baselines.

## Problem

- Large Language Model (LLM) agents often operate episodically, failing to learn and generalize from past experiences, which limits their scalability and adaptability.
- Existing memory-augmented LLM agents predominantly store raw, verbose, and noisy interaction trajectories, leading to "context bloat" and inefficient extraction of high-level behavioral patterns.
- Current memory mechanisms typically function as external references without fundamentally adapting the agent's internal policy or evolving to address new failure modes and challenges.

## Method

- Employs a teacher model to distill raw interaction trajectories, including both successful episodes and failures, into concise ==strategic patterns== and ==failure lessons==.
- Constructs a hierarchical ==SKILLBANK== that organizes distilled knowledge into general skills (universal strategies) and task-specific skills, designed for efficient retrieval and significant token compression.
- Utilizes ==Supervised Fine-Tuning (SFT) for cold-start initialization==, followed by ==recursive skill evolution== during Group Relative Policy Optimization (GRPO) to dynamically refine the skill library and agent policy based on ongoing performance.

## Results

- Achieved state-of-the-art success rates, including **89.9%** on ALFWorld, **72.7%** on WebShop, and an average score of **47.1%** on search-augmented QA tasks.
- Outperformed strong baselines, including GPT-4o by **41.9%** and Gemini-2.5-Pro by **29.6%** on ALFWorld, demonstrating that intelligent skill learning can compensate for model scale.
- Reduced prompt token usage by approximately **10.3%** compared to raw memory retrieval, while also exhibiting faster convergence and a dynamic expansion of the skill library from **55** to **100** skills during training.

## Takeaways

> [!tip] Key Insights
> - Abstracting experiences into high-level, hierarchical skills provides superior performance and context efficiency for LLM agents compared to storing or compressing raw interaction trajectories.
> - A dynamic and recursive skill evolution mechanism, where the skill library co-evolves with the agent's policy, is critical for continuous improvement, adaptability, and effectively addressing emergent failure modes.
> - Initial Supervised Fine-Tuning on skill-augmented reasoning traces is essential for enabling the base LLM agent to effectively utilize and integrate abstract skills into its decision-making process.
