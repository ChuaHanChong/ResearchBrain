# Struct2D: A Perception-Guided Framework for Spatial Reasoning in MLLMs

> [!summary] Summary
> Struct2D introduces a perception-guided framework enabling Multimodal Large Language Models (MLLMs) to perform 3D spatial reasoning using structured 2D representations, bypassing direct 3D input. The framework, along with its automatically generated instruction tuning dataset Struct2D-Set, achieves an average score of 43.6% on VSI-Bench for open-source MLLMs and competitive performance on other 3D scene understanding benchmarks.

## Problem

- Multimodal Large Language Models (MLLMs) traditionally struggle with robust 3D spatial reasoning and typically require explicit 3D representations like point clouds as direct inputs.
- Existing 3D-input methods for MLLMs face limitations in adaptability, generalization across diverse textual queries, and architectural complexity.
- Prior 2D-based approaches for inferring 3D spatial cues often omit crucial object appearance details and explicit spatial priors (e.g., coordinates, categories), limiting their effectiveness.

## Method

- Struct2D proposes a ==perception-guided prompting strategy== that transforms raw egocentric RGB-D video inputs into structured 2D representations, including ==Bird's-Eye-View (BEV) images== with object marks, object-centric metadata (category, 3D coordinates), and intelligently selected egocentric keyframes.
- A large-scale instruction tuning dataset, ==Struct2D-Set==, is automatically generated from over 6K indoor scenes, designed for open-source MLLMs to acquire robust 3D spatial reasoning skills using only 2D projected inputs during training.
- The framework is applied in a zero-shot setting to closed-source MLLMs (e.g., GPT-o3) and also used to fine-tune an open-source MLLM (Qwen2.5VL) on the Struct2D-Set.

## Results

- In zero-shot analysis, GPT-o3 achieved high scores with Struct2D inputs on VSI-Bench (e.g., **96.5%** on relative distance and **94.4%** on relative direction with ground-truth object annotations).
- The Qwen2.5VL model fine-tuned on Struct2D-Set attained the highest average score (**43.6%**) among open-source MLLMs on VSI-Bench, with notable gains in relative direction (**45.9%**) and route planning (**35.8%**).
- The instruction-tuned model demonstrated competitive performance on standard 3D question answering and visual grounding benchmarks (ScanQA, SQA3D, Scan2Cap, ScanRefer, Multi3DRefer), often outperforming methods reliant on explicit 3D point cloud inputs.

## Takeaways

> [!tip] Key Insights
> - MLLMs can achieve strong 3D spatial reasoning capabilities by leveraging carefully constructed structured 2D inputs, even without direct 3D features as input.
> - Object-centric metadata and filtered object marks are crucial for effectively grounding spatial context and reducing ambiguity, while guide prompts and rotation-aligned BEV images are essential for complex reasoning tasks like relative direction.
> - Large-scale instruction tuning with step-by-step reasoning traces (using augmented QA pairs and `` tokens) substantially enhances an MLLM's ability to perform complex spatial reasoning.
