# Egocentric World Model for Photorealistic Hand-Object Interaction Synthesis

> [!summary] Summary
> EgoHOI is an egocentric world model that synthesizes photorealistic hand-object interactions purely from action signals, bypassing the need for future object state information by integrating physics-informed embeddings derived from 3D geometry and kinematics. The model demonstrates enhanced photorealism, improved alignment with user actions, and more realistic hand-object interaction dynamics compared to existing baselines.

## Problem

- Existing egocentric Human-Object Interaction (HOI) world models struggle with challenges like rapid head motions, severe occlusions, and high hand articulation degrees of freedom.
- Many HOI video generation methods operate from static, exocentric views or rely on privileged future object information, hindering true first-person, action-driven simulation for embodied AI applications.
- A reliable egocentric HOI world model capable of predicting future hand-object interactions solely from current action signals, without future-state shortcuts, was lacking.

## Method

- EgoHOI formulates HOI synthesis as an action-driven ==world model==ing problem within a compact latent state space, utilizing a Diffusion Transformer backbone for state evolution.
- The model avoids relying on privileged future object states by distilling 3D geometric and kinematic estimates into three physics-informed embeddings: Hand Kinematic Embeddings (HKE), Ego-Motion Embeddings (EME), and Object Entity Embeddings (OEE).
- These embeddings are integrated into a frozen Wan-DiT backbone via lightweight adapters, providing explicit metric and kinematic structure to guide physically plausible, egocentric rollouts.

## Results

- EgoHOI achieved superior performance across frame prediction, ego-motion consistency, and kinematic fidelity metrics, outperforming baselines like Cosmos 14B and Uni3C.
- Frame prediction metrics improved, with EgoHOI demonstrating a PSNR of **21.05** (vs. Cosmos 14B's **15.89**) and an Object-CLIP score of **0.92** (vs. **0.88**), indicating enhanced visual quality and object preservation.
- The model significantly reduced ego-motion drift (Absolute Trajectory Error of **0.084** vs. Cosmos 14B's **0.112**) and improved kinematic fidelity (Missing Ratio of **5.84%** vs. Cosmos 14B's **14.61%**), confirming the effectiveness of physics-informed embeddings.
- Ablation studies demonstrated that Hand Kinematic Embeddings, Ego-Motion Embeddings, and Object Entity Embeddings each contribute to specific improvements in hand articulation, viewpoint stability, and object integrity, respectively.

## Takeaways

> [!tip] Key Insights
> - Integrating explicit 3D geometric and kinematic priors, extracted from unstructured videos, can effectively regularize egocentric HOI rollouts, leading to physically plausible and consistent interaction dynamics.
> - Causal simulation of hand-object interactions from action signals, without future-state shortcuts, is achievable by augmenting generative models with physics-informed embeddings.
> - Distilling complex 3D information into compact, interpretable embeddings for hand kinematics, ego-motion, and object integrity provides a robust inductive bias for world models in egocentric contexts.
