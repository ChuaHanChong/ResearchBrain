# SERF: Spatiotemporal Environment and Robot Feature Map for Long-Horizon Mobile Manipulation

> [!summary] Summary
> The Spatiotemporal Environment and Robot Feature (SERF) map integrates a dynamically updated 4D feature representation of both the environment and the robot body into Vision-Language-Action (VLA) policies for long-horizon mobile manipulation. This approach enables robots to maintain persistent spatial memory and explicit robot-environment reasoning, leading to an average 14.7% improvement in task progress and enhanced recovery from common failures in simulation.

## Problem

- Long-horizon mobile manipulation in large, dynamic environments requires continuous reasoning about robot localization, environmental changes, and task progression over extended periods.
- Existing Vision-Language-Action (VLA) models and memory systems often lack explicit mechanisms for persistent spatiotemporal information beyond immediate observations or represent only static environments, failing to capture dynamic robot-environment interactions.
- Prior memory approaches either abstract scenes into high-level objects (omitting dense geometric cues) or lack explicit spatial grounding for policy architectures, making it difficult for policies to infer the relevance of past observations to current states.

## Method

- Developed **SERF**, a dynamically updated ==spatiotemporal feature map==, representing both the environment and the articulated robot body as "neural points" with learnable latent features in a shared 3D space.
- Introduced online update mechanisms for the map: tracking object-level rigid transformations for environment points via 3D keypoint correspondences and using forward kinematics for robot points based on proprioceptive state.
- Designed a map-conditioned VLA policy that uses a "map tokenizer" to extract multi-scale and multi-frame context tokens from SERF, integrating them with image observations, proprioception, and language embeddings to predict robot actions.

## Results

- SERF achieved an average **58.7%** task progress across three BEHAVIOR-**1K** long-horizon mobile manipulation tasks in simulation, outperforming image-only baselines (**44.0%**) and static map baselines (**54.0%**).
- The approach demonstrated enhanced robustness to out-of-distribution scene configurations, showing up to a **23%** improvement in task progress compared to image-only baselines when faced with relocated goals or additional objects.
- SERF significantly improved recovery from object-drop failures, successfully re-localizing and re-grasping objects in **95%** of attempts (compared to **65%** for image-only baselines) and achieving faster recovery times (20.5 vs. 24.3 seconds).

## Takeaways

> [!tip] Key Insights
> - A unified spatiotemporal feature map explicitly encoding both the dynamic environment and the robot body provides persistent allocentric (scene-level) and egocentric (robot-environment) spatial context crucial for long-horizon tasks.
> - Jointly optimizing latent features for environment and robot neural points within a shared Vision Foundation Model (VFM) embedding space, coupled with inter-category and intra-instance contrastive losses, enables effective representation of diverse entities and their relationships.
> - Integrating a structured map representation as an explicit state input, via a specialized map tokenizer, allows VLA policies to leverage pre-trained knowledge while gaining robust spatial reasoning without extensive retraining of foundation models.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of robot learning has demonstrated capabilities in short-horizon manipulation tasks. However, extending these abilities to long-horizon mobile manipulation within large, dynamic environments presents challenges. Such tasks necessitate continuous reasoning about robot localization, environmental changes, and task progression, which are difficult to infer from limited, short observation sequences.

Existing Vision-Language-Action (VLA) models, while showing promise, typically encode spatial and temporal context without explicit mechanisms to maintain information beyond immediate observations. This limitation becomes pronounced in mobile manipulation, where decisions rely on long-term context that evolves through robot-environment interactions.

Previous research has explored persistent memory formulations for embodied agents. One category involves modular mobile manipulation systems that integrate various components like perception, navigation, and planning. These systems often employ structured scene representations such as dynamic 3D scene graphs or spatio-semantic object memories. While providing explicit and interpretable memory, these approaches often abstract the scene into high-level objects or symbols, potentially omitting dense geometric and robot-environment interaction cues necessary for continuous visuomotor control.

A second approach embeds memory directly into policy architectures through episodic memories, history tokens, or retrieval buffers. These methods extend temporal context but often lack explicit spatial grounding, requiring the policy to implicitly infer the relevance of past observations to current states. Some work incorporates spatial grounding by conditioning policies on 3D feature maps derived from vision foundation models (VFMs), such as semantic 3D reconstruction maps or latent 3D feature maps. These maps offer spatial memory for object and goal locations but generally represent only the static environment, lacking support for online updates as the robot interacts. Furthermore, these methods typically exclude the robot body from the memory, necessitating indirect inference of robot-environment relationships from separate inputs.

This research addresses these identified gaps by developing a spatiotemporal memory system that evolves with robot interaction, explicitly represents robot-environment spatial relationships, and provides structured context for neural policies.

### 2. Key Objectives and Motivation

The primary motivation for this research stems from the inherent difficulties of long-horizon mobile manipulation tasks in complex, dynamic environments. Robots performing tasks such as tidying a room must continuously answer fundamental questions: "Where am I?", "What has changed around me?", and "How far along am I in my task?". Answering these questions cohesively requires persistent and integrated spatiotemporal reasoning that tracks both the robot's motion and the evolving environment over extended periods. Current VLA models, often relying solely on image observations, struggle to maintain such a coherent understanding, particularly when task-relevant objects leave the robot's immediate field of view or when the environment changes due to robot interactions.

The key objectives of this work are:

1. **Develop a Spatiotemporal Environment and Robot Feature (SERF) map:** This map aims to provide a unified, persistent memory by representing both the environment and the articulated robot body within a shared latent feature space. The map is designed to be dynamically updated online, incorporating information from egocentric observations and proprioceptive state.
 - Specific aspects of this objective include:
 - Representing both environment objects and robot body parts as "neural points," which are 3D points endowed with learnable latent features.
 - Enabling efficient online updates for environment neural points by tracking object-level rigid transformations based on 3D keypoint correspondences.
 - Allowing real-time updates for robot neural points by leveraging forward kinematics from the robot's current proprioceptive state.
 - Facilitating *allocentric reasoning* by providing a global, persistent spatial memory for tracking the robot's position within the scene and monitoring object and goal locations over time.
 - Supporting *egocentric reasoning* by explicitly embedding the robot body within the same map, thereby exposing direct robot-environment spatial relationships, such as distance, orientation, and reachability, which are critical for fine-grained manipulation decisions.

2. **Design a map-conditioned VLA policy:** This objective involves integrating the SERF map as an explicit, structured state input into a VLA model to enhance its reasoning capabilities.
 - Specific aspects include:
 - Developing a "map tokenizer" that extracts compact feature tokens from the SERF map.
 - Ensuring these tokens capture context across multiple reference frames (e.g., end-effector, robot-base) and spatial scales (local and global) to provide comprehensive situational awareness to the VLA policy.
 - Combining these map tokens with other policy inputs, such as image observations, proprioceptive state, and language task embeddings, to predict robot actions.

3. **Demonstrate improved long-horizon mobile manipulation performance:** The ultimate objective is to empirically validate that policies conditioned on the SERF map outperform existing image-only VLA baselines in complex, long-horizon tasks.
 - This includes demonstrating improvements in:
 - Overall task progress and success rates.
 - Efficiency of robot trajectories, leading to faster subgoal achievement.
 - Robustness and generalization capabilities when faced with unforeseen scene configurations or shifts.
 - The robot's ability to recover from common execution failures, such as accidentally dropping an object.

### 3. Methodology and Approach

The research formulates mobile manipulation as a two-part learning problem: first, learning a spatiotemporal feature map that summarizes the robot's history, and second, learning a map-conditioned policy that uses this map.

**Problem Formulation:**
At each timestep $\tau$, the robot accesses its proprioceptive state $s_\tau$ (base pose, joint angles) and RGB-D observations $o_\tau = \{(I_\tau, Z_\tau)\}$ from head and wrist cameras. Each RGB image $I_\tau$ is associated with instance segmentation labels $C_\tau$. A pretrained Vision Foundation Model (VFM) such as DINOv3 extracts per-patch embeddings $Y_\tau$. Using depth and camera pose, image patch centroids are back-projected into 3D coordinates $(x)$ and paired with VFM embeddings $(y)$, yielding $(x, y)$ pairs. The robot executes a task specified by a natural language command $\ell$, embedded as $e_\ell$. The goal is to learn a policy $\pi_\phi(a_\tau | o_{1:\tau}, s_{1:\tau}, e_\ell)$ by conditioning it on a spatiotemporal feature map $m_\tau$, which summarizes the observation-state history.

**Spatiotemporal Feature Mapping (SERF):**
The map $m_\tau$ is parameterized by neural points $P_\tau = \{(p_{i,\tau}, f_i, c_i)\}$, where $p_{i,\tau}$ is the world-frame position, $f_i$ is a learnable latent feature vector, and $c_i$ is the object instance label. A neural network decoder $D_\theta$ maps interpolated latent features to the VFM embedding space.
- **Neural Point Representation:** To query the map at location $x$, the system interpolates latent features from the $K=6$ nearest neighbors within $P_\tau$ using a softmax-weighted average. The interpolated feature is then passed through the decoder $D_\theta$ to produce the VFM embedding. The learnable map parameters $\Theta$ consist of the latent features $\{f_i\}$ and the decoder parameters $\theta$. The full neural point set $P_\tau$ is a union of environment points $P_{e,\tau}$ and robot points $P_{r,\tau}$.
- **Environment Points:** These are generated by lifting VFM patch locations from robot observations into 3D, voxelizing them, and registering a neural point for each newly occupied voxel in a spatial hash table. Each point is assigned an instance label (privileged from simulation) and a randomly initialized latent feature. During execution, only the positions $p_{e,i,\tau}$ of these points are updated, tracking object motion, while features $f_{e,i}$ and labels $c_{e,i}$ remain fixed.
- **Robot Points:** The robot body is represented by sampling surface points $u_j$ from its kinematic model (URDF) meshes and storing them in their respective local link frames. Each robot point $j$ has a randomly initialized latent feature $f_{r,j}$ and a shared robot-body label $c_r$. Given a robot state $s$, forward kinematics are used to compute the world-frame positions $p_{r,j}(s)$.
- **Latent Feature Learning:** During offline training, latent features for both environment and robot points, along with the shared decoder $D_\theta$, are jointly optimized. The primary objective is a cosine-similarity reconstruction loss, $L_{rec}$, which encourages the decoder to accurately reconstruct VFM embeddings from queried neural point features. This shared decoder forces environment and robot features into a common latent space.
 - Additionally, contrastive losses are employed: $L_{map} = L_{rec} + \lambda_{inter} L_{inter} + \lambda_{intra} L_{intra}$.
 - The **inter-category objective** ($L_{inter}$) promotes clustering of same-category features and separation of different-category features across training scenes, including robot features as a distinct category.
 - The **intra-instance objective** ($L_{intra}$) encourages features from the same object part to cluster while separating features from different parts of the same instance, inducing part-level semantic structure. SAM 2 segments are used for environment parts, and robot links provide robot part labels.
- **Map Updates (Online Execution):** During task execution, latent features, instance labels, and the decoder remain fixed, with only point positions being updated.
 - **Environment Updates:** Each movable object instance is treated as a rigid body. Neural points are grouped by instance label. 2D keypoints (Shi-Tomasi corners tracked by CoTracker3) within each instance mask are tracked between consecutive observations and lifted to 3D. An object-level SE(3) transform is estimated (initialized with Fast Global Registration and refined with Iterative Closest Point) to update the positions of all neural points belonging to that instance. Objects with minimal 3D displacement are considered stationary.
 - **Robot Updates:** Based on the current proprioceptive state $s_\tau$, forward kinematics are applied to compute each robot link's transform. This updates the world-frame positions of all robot neural points.

**Map-Conditioned VLA Policy:**
To enable decision-making, a map-conditioned VLA policy is developed.
- **Map Tokenizer:** A filtered subset of neural points (robot body and task-relevant objects) is fed into a Point Transformer backbone. Eight parallel heads, organized into five groups, extract map tokens (2048-dimensional) by selecting spatial subsets of features via ball queries or mask-based selection. These groups include:
 - Three robot-base tokens at varying radii (1m, 2m, 4m) for multi-scale local context.
 - Two end-effector tokens around grippers for grasp reasoning.
 - One robot-only token summarizing robot configuration.
 - One environment-only token summarizing environment state.
 - One global token aggregating all points for scene-level reasoning.
 Relative positional encodings from the Point Transformer are used, omitting absolute coordinates to reduce overfitting.
- **Map-Conditioned Policy Learning:** The policy builds upon the $\pi_{0.5}$ VLA model. Map tokens $e_m$, derived from the tokenizer, are concatenated with image features $E(o_\tau)$ (from a VLA vision encoder), state tokens $e_s$ (from proprioceptive state), and a learnable task embedding $e_\ell$. This combined input $h_\tau$ is then fed to the VLA's action expert. The policy is optimized using a conditional flow-matching objective, where an action expert $v_\psi$ is trained to predict target velocities for action chunks. During inference, actions are generated by integrating this velocity field. To preserve pretrained knowledge, the VLM backbone and vision encoder are frozen, and LoRA layers are inserted into the action expert. The map tokenizer, projection layer, and LoRA parameters constitute the learnable policy parameters.

### 4. Main Findings and Results

The SERF approach was evaluated on three long-horizon mobile manipulation tasks from the BEHAVIOR-1K benchmark in OmniGibson, specifically Task 21 (Collecting Children’s Toys), Task 22 (Putting Shoes On Rack), and Task 26 (Assembling Gift Baskets). Performance was measured by task progress (percentage of completed subgoals) over 20 evaluation configurations.

**Quantitative Performance Comparison:**
The full SERF policy consistently achieved the highest task progress across all evaluated tasks compared to image-only and static map baselines:
- **Task 21 (Collecting Children’s Toys):** SERF achieved 63.5% task progress, outperforming the best image-only baseline (PI0.5 (ft) at 40.7%) and the static map baseline (SBP at 57.9%). SERF (env), without robot points, also scored 57.9%.
- **Task 22 (Putting Shoes On Rack):** SERF achieved 60.1% task progress, compared to PI0.5 (ft) at 43.0% and SBP at 52.5%. SERF (env) scored 59.0%.
- **Task 26 (Assembling Gift Baskets):** SERF achieved 52.5% task progress, compared to PI0.5 (ft) at 48.4% and SBP at 51.6%. SERF (env) scored 49.4%.

On average across the three tasks, map-conditioned policies demonstrated higher mean task progress than image-only baselines. Specifically, SERF improved average task progress from 44.0% (image-only baselines) to 58.7%. The temporal map updates in SERF (env) provided an average improvement over the static SBP baseline. The inclusion of robot neural points (SERF vs. SERF (env)) yielded further average gains, suggesting the benefit of explicit robot-environment spatial relationships for egocentric reasoning.

**Qualitative Observations:**
Qualitative comparisons revealed that the SERF policy exhibited more direct trajectories and reached subgoals faster. In contrast, image-only baselines, such as PI0.5 (ft), often stalled or exhibited inefficient movements when task-relevant objects moved out of the current camera's field of view, indicating a lack of persistent spatial memory.

**Scene-Configuration Generalization:**
SERF's robustness to scene-configuration shifts was assessed under three out-of-distribution (OOD) test variations:
- **Moved Goal:** In Task 21, with a relocated bookcase goal, SERF achieved 63.0% task progress, significantly higher than PI0.5 (ft)'s 42.9%.
- **Additional Objects:** In Task 21, with extra target teddy bears, SERF achieved 50.8% task progress, compared to PI0.5 (ft)'s 28.0%.
- **Unvisited Region:** In Task 22, with target sandals placed in a previously unvisited navigation area, SERF achieved 51.0% task progress, while PI0.5 (ft) managed 28.0%.
These results indicate that the explicit spatial representation provided by SERF supports more robust behavior under OOD configuration changes.

**Failure Recovery:**
The ability to recover from object-drop failures during transport was evaluated. When the gripper opened and an object dropped out of camera view, SERF re-localized and re-grasped the dropped object with a higher success rate (95%) compared to PI0.5 (ft) (65%). SERF also achieved faster recovery times, averaging 20.5 seconds versus 24.3 seconds for PI0.5 (ft). This demonstrates SERF's generalization beyond demonstrated trajectories, as recovery scenarios were not present in the training data.

**Map Token Ablation (Appendix F):**
An ablation study on Task 22 showed that the full SERF model, utilizing all five map-token groups, achieved the highest task progress (60.1%). Omitting any single token group (e.g., robot-base, end-effector, robot-only, environment-only, or global) resulted in a decrease in performance, suggesting that each group contributes to the overall effectiveness of the map-conditioned policy.

### 5. Significance and Potential Impact

The introduction of the Spatiotemporal Environment and Robot Feature (SERF) map addresses critical limitations in long-horizon mobile manipulation, particularly concerning persistent spatial memory and explicit robot-environment reasoning. By integrating a dynamically updated 4D feature map into VLA policies, this work demonstrates a method for robots to maintain a coherent understanding of their evolving environment and their own body's relationship within it.

The primary significance lies in SERF's ability to provide both allocentric scene memory and egocentric robot-environment reasoning. This dual capability allows the robot to track objects and goals even when they are out of immediate view and to make spatially grounded decisions for manipulation tasks. The experimental results quantitatively support these benefits, showing improved task progress, more efficient trajectories, and enhanced robustness to unexpected changes in scene configuration. The demonstrated ability to recover from object-drop failures, a common challenge in real-world robotics, highlights the practical impact of providing persistent spatial context and signifies a step towards more resilient robotic systems.

Potential impacts include:
- **Enhanced Autonomy in Complex Environments:** Robots could operate more effectively in dynamic and unstructured settings like homes or warehouses, performing tasks that require extensive navigation, object interaction, and long-term planning.
- **Improved Generalization and Robustness:** The explicit spatial representation allows policies to generalize better to novel scene layouts and recover from execution errors, reducing the need for extensive retraining for every new scenario or failure mode.
- **Foundation for Future Robot Learning:** SERF provides a structured memory representation that can serve as a foundation for more sophisticated reasoning capabilities, potentially enabling robots to learn more complex tasks and adapt to greater environmental variability.

However, the authors acknowledge several limitations that indicate future research directions:
- **Reliance on Privileged Information:** Current SERF implementations depend on a prior map and privileged instance labels from simulation. Transitioning to real-world applications would necessitate feed-forward encoders for neural point features and robust online instance segmentation models (e.g., SAM 2).
- **Real-world Validation:** The current evaluation is restricted to simulation; real-world mobile manipulation experiments are necessary to assess transferability and performance in physical environments.
- **Rigid Motion Assumption:** The map update mechanism assumes object-level rigid motion, which limits its applicability to articulated or deformable objects. Extending the mapping formulation to handle richer real-world dynamics, such as object articulation and deformation, is an important area for future work.
- **Temporal Reasoning Enhancement:** Integrating map tokens from multiple temporal windows, including past observations and predicted future states, could further strengthen the policy's temporal reasoning capabilities.
- **Advanced Tokenization:** The current map tokenizer uses manually specified spatial subsets. Developing task-conditioned tokenization that semantically disentangles robot, object, and scene-state cues could lead to more robust and interpretable map representations for long-horizon tasks.

Overall, SERF represents a significant contribution to addressing the memory and reasoning challenges in long-horizon mobile manipulation, laying groundwork for more capable and adaptable robotic agents.
