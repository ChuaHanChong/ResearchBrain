# Latent evolving World Action Model

> [!summary] Summary
> LeWAM replaces the video-diffusion backbone of world action models with a frozen I-JEPA encoder: a single lightweight predictor jointly denoises action chunks via flow matching and regresses future I-JEPA embeddings under a structured attention mask, with AdaFuse layer fusion and DemoDPO offline preference refinement. With 0.4B trainable parameters it reaches 92.28% average success on RoboTwin 2.0.

## Problem

- VDM-based WAMs feed compressed VAE posterior means to action heads, so useful features need a large pretrained video diffusion backbone, tying cost and scalability to video pretraining.
- Prior encoder comparisons test few representations or only as add-ons to VLA features; no study feeds representative frozen encoders into one identical action predictor.
- Imitation objectives match demonstrated actions without ranking better against worse ones; online RL could fix this but needs rollouts, rewards, resets and human safety oversight.

## Method

- **LeWAM** conditions flow-matching action generation on frozen I-JEPA embeddings and predicts future embeddings in the same space, dropping the video diffusion backbone entirely.
- A single predictor processes observation, noisy plus clean action tokens and future queries under a ==structured attention mask== preventing ==clean-action leakage==; each future query sees only its horizon prefix.
- **AdaFuse** learns per-channel softmax weights over encoder layers; **DemoDPO** ranks candidates from a frozen reference policy by demonstration MSE, filters near-ties, optimizes a velocity-error DPO surrogate.

## Results

- Frozen encoder sweep: Wan2.2-VAE **10.81%** average success, SigLIP **79.20%**, V-JEPA2-Huge **81.70%**, I-JEPA-Huge best at **86.17%** despite ImageNet-22K-only pretraining.
- Ablations: direct future-embedding regression **87.02%** beats the flow-matching variant **86.21%**; AdaFuse lifts to **90.69%**; DemoDPO reaches **92.28%** versus **91.83%** for Fast-WAM.
- **1,000** extra supervised updates give **73.25%** on eight hard tasks; DemoDPO reaches **76.63%**; latency **103.53 ms** and **1.988 GiB** peak memory, lowest among baselines.

## Takeaways

> [!tip] Key Insights
> - Prediction-trained embeddings expose geometry and object structure a small action head can use; reconstruction-optimized latents can discard action-relevant directions entirely.
> - Pretraining data scale does not decide policy quality: ImageNet-22K I-JEPA beat encoders trained on far larger image and video corpora.
> - Preference supervision can come from demonstrations alone; ranked pairs need a moderate similarity gap, since no filtering and over-strict filtering both hurt.

## Detailed Report

### 1. Overview

Bimanual robots stack blocks, fold a towel, and arrange flowers. In manipulation, matching a demonstrated action is not necessarily enough, because small action deviations can cause a rollout to fail. LeWAM's approach has two parts. One predictor learns both robot actions and how visual embeddings change under those actions. The deployed policy then generates actions without predicting future embeddings. In the real-world evaluation, LeWAM has the highest task progress of the four methods shown on all three tasks.

Panel (a) compares frozen encoders and LeWAM on RoboTwin 2.0. Panel (b) shows real-world task progress across three tasks, with LeWAM highest in each group: 84.9%, 60.7%, and 53.0% for Stack Blocks, Fold Towel, and Arrange Flowers. These are milestone-progress scores, not success rates.

Task progress measures milestone completion averaged over 50 rollouts per task. It uses task-dependent penalties, and scores are normalized by each task's maximum.

### 2. A better visual basis for action

A World Action Model (WAM) is a policy that learns actions alongside environment dynamics. A VLA, by contrast, maps current observations and task context directly to actions. Many WAMs depend on large video-diffusion backbones to extract useful features from compressed visual latents. The authors are concerned that image-reconstruction-oriented compression may preserve visually prominent information without preserving the information an action predictor needs.

A controlled comparison tested this concern using the same downstream action-predictor recipe. The Wan2.2 VAE representation scores **10.81%** average success, while frozen I-JEPA-Huge scores **86.17%**. These encoder comparisons use a discrete task ID rather than natural-language conditioning, and they disable future-embedding prediction. I-JEPA-Huge was pretrained on ImageNet-22K. The result is evidence about how these representations work as direct inputs to that predictor. It does not show that raw VAE latents are unhelpful when processed by a large pretrained video-diffusion backbone.

### 3. One predictor, two objectives

A frozen I-JEPA encoder provides the current visual features. AdaFuse learns feature-dimension-specific weights to combine information from the encoder's layers. A single predictor then learns two things: the action-generation objective and action-conditioned future-embedding prediction. A future embedding is a visual representation of a later observation, not a rendered future image.

(a) A frozen JEPA encoder, layer representations, and AdaFuse. (b) Observation, noisy-action, clean-action and future-query tokens entering a predictor with action and state heads. (c) The structured attention mask.

A structured attention mask keeps demonstrated clean actions from leaking into action generation. It also limits each future query to the action prefix for its prediction horizon. At inference, the model encodes the current observation and generates an action chunk, omitting clean action tokens and future queries. Future prediction therefore supplies training supervision without adding that branch to inference.

The authors also add DemoDPO. It uses demonstrations to rank candidate actions offline, so it requires neither new robot rollouts nor human preference labels. In this construction, "preferred" means lower MSE to the demonstration, not measured success in the environment.

### 4. What the benchmark shows

RoboTwin 2.0 tests bimanual manipulation on 50 tasks, with 100 evaluation cases per task in each of two settings, clean and randomized. LeWAM's success rates are **93.14%** clean and **91.42%** randomized, for a **92.28%** average. The closest reported baseline, LingBot-VA, averages **92.20%**. LeWAM has **0.4B trainable parameters** and no additional embodied robot pretraining, although its frozen I-JEPA encoder is pretrained on ImageNet-22K. This is comparable performance with fewer trainable parameters. It is not a controlled proof of superiority, because the baselines' pretraining and result sources differ.

### 5. Learn futures, act now

LeWAM uses future-embedding learning to shape the action policy. When the robot acts, it does not run a future-prediction pathway. The results support the authors' view that the representation, training objective, and deployment pipeline work together. They do not show that any single part is the sole cause of success.
