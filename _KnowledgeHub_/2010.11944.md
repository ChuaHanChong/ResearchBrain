# Accelerating Reinforcement Learning with Learned Skill Priors

> [!summary] Summary
> The SPiRL method from USC's CLVRai lab enables accelerated reinforcement learning by jointly learning continuous skill embeddings and a state-conditioned prior over these skills from unstructured data. This approach effectively guides exploration in high-dimensional skill spaces, leading to more efficient transfer to new, complex tasks and demonstrating improved performance over baselines on robot manipulation and navigation.

## Problem

- Reinforcement learning is often data-inefficient, requiring extensive online interaction to learn new tasks from scratch.
- Existing methods struggle to effectively leverage large amounts of unstructured, offline experience data due to lack of task-specific rewards or the need for structured task distributions.
- Exploring the high-dimensional, continuous skill embedding space resulting from skill extraction poses a significant challenge for downstream learning, potentially hindering efficiency.

## Method

- **SPiRL** learns a ==continuous skill embedding space== and a ==state-conditioned skill prior== offline from unstructured data using a ==stochastic latent variable model==, minimizing ==KL divergence== between inferred posteriors and the learned prior.
- A ==hierarchical policy== for downstream tasks uses the pre-trained skill decoder to execute skills, while a high-level policy predicts skill embeddings.
- ==Maximum-entropy RL== (==Soft Actor-Critic==) is modified to explicitly regularize the high-level policy towards the learned state-conditioned skill prior, guiding exploration in the skill space.

## Results

- **SPiRL** consistently outperforms flat model-free RL and skill-based methods without prior guidance across Maze Navigation, Block Stacking, and Kitchen environments, reliably solving complex tasks.
- Ablation studies confirm that the learned state-conditioned skill prior is critical for efficient exploration and successful downstream learning.
- The method demonstrates robustness, learning effective skills and priors even from sub-optimal or mixed-quality training data, and learned priors can be reused for multiple downstream tasks.

## Takeaways

> [!tip] Key Insights
> - Learning a state-conditioned prior over skills is crucial for effectively guiding exploration in high-dimensional continuous skill spaces.
> - Without such a learned prior, exploration in rich skill embedding spaces can be prohibitively difficult, often negating the benefits of skill transfer.
> - Temporal abstraction provided by skills is essential for solving complex, long-horizon tasks efficiently, while single-step action priors are insufficient.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of reinforcement learning has made significant strides, but a persistent challenge remains: the immense amount of online interaction data required for agents to learn new tasks. This is particularly problematic for real-world applications like robotics or autonomous driving, where data collection can be costly, time-consuming, or even dangerous. Concurrently, there is an ever-growing abundance of *unstructured, offline* agent experience data, which often lacks explicit task definitions or reward signals. The core problem this paper addresses is how to effectively leverage this wealth of unstructured prior experience to accelerate the learning of new downstream tasks.

Several existing research avenues attempt to tackle this problem:

- **Meta-learning (e.g., MAML):** These approaches aim to learn "how to learn" across a distribution of tasks. While effective, they typically require a defined set of training tasks and often rely on online data collection during pre-training, limiting their applicability to truly unstructured offline datasets.
- **Offline Reinforcement Learning (Offline RL):** This paradigm focuses on learning policies purely from logged offline data without any further environment interactions. While promising for leveraging large datasets, most offline RL methods require the logged experience to be annotated with rewards for the *specific downstream task*, which is infeasible for vast, diverse, and unstructured real-world datasets collected across many different implicit tasks. Some works also use learned behavior priors to constrain exploration in offline RL, but these often operate on primitive action spaces.
- **Skill Extraction and Transfer:** A flexible approach to utilize unstructured data is to first extract "skills" – temporally extended actions representing useful behaviors – which can then be repurposed. These skills can be learned from diverse sources, including human demonstrations or autonomous exploration.
 - **Early works:** Represent skills as discrete options or primitive libraries (e.g., SKILLS, PolicyBlocks).
 - **Recent advancements:** Embed skills into a continuous latent space using stochastic latent variable models. This allows for representing a large number of diverse behaviors compactly. Examples include works by Merel et al., Shankar et al., and Hausman et al.

The crucial gap identified and addressed by Pertsch, Lee, and Lim lies within these continuous skill embedding approaches. While powerful latent variable models can represent an arbitrary number of behaviors, the resulting *rich skill embedding space* itself becomes a high-dimensional action space for a higher-level policy. This, paradoxically, reintroduces a challenging exploration problem, as the agent still needs to efficiently explore this vast skill space during downstream learning. Prior work has noted that large skill libraries can even *worsen* downstream learning efficiency due to this exploration challenge.

This paper directly tackles this "skill-space exploration problem" by proposing to **learn a *prior distribution* over skills** in conjunction with the skill embedding itself. By guiding the high-level policy's exploration towards more "promising" or "relevant" skills given the current state, the method aims to overcome the exploration bottleneck in large, continuous skill spaces. It differentiates itself from existing behavior prior methods by focusing on *temporally extended actions (skills)* rather than just primitive actions, enabling scalability to complex, long-horizon tasks. Thus, SPiRL bridges the gap between scalable skill extraction from unstructured data and efficient transfer to new tasks by introducing a learned mechanism for intelligent skill exploration.

### 2. Key Objectives and Motivation

The primary motivation behind this research stems from the disparity between how intelligent agents (humans and animals) learn new tasks by leveraging vast prior experience, and how typical reinforcement learning (RL) agents often learn each task from scratch. This "from scratch" learning is highly data-inefficient and costly, particularly for real-world applications in robotics, autonomous driving, or complex control systems. While large amounts of unstructured, offline data are available in these domains, their lack of task-specific rewards and clear annotations makes them challenging to use directly with traditional RL methods.

The authors identify that existing approaches for leveraging prior experience, such as meta-learning or offline RL, often come with significant limitations (e.g., requiring pre-defined tasks, online pre-training, or reward-annotated data). Skill extraction, as a means of temporal abstraction, offers a flexible way to utilize unstructured data. However, the scalability of skill transfer faces a critical impediment: as the diversity and volume of prior experience grow, so does the "richness" or dimensionality of the extracted skill library. This leads to a challenging exploration problem for downstream RL policies that operate in this high-dimensional skill space, often diminishing the benefits of skill transfer.

Against this backdrop, the **key objectives** of this work are:

1. **To devise a scalable approach for leveraging unstructured prior agent experience** to accelerate the learning of new downstream tasks.
2. **To learn an intelligent prior distribution over skills** concurrently with the skill library itself, which can effectively guide exploration in the skill space. The intuition is that not all skills are equally relevant in a given state (e.g., picking up a kettle when already holding it is more promising than sweeping).
3. **To seamlessly integrate this learned skill prior into existing maximum-entropy RL frameworks** for efficient downstream task learning.

The paper clearly articulates its contributions, which directly address these objectives:

- **Design a model for jointly learning an embedding space of skills and a prior over these skills from unstructured data.**
- **Extend maximum-entropy RL to incorporate learned skill priors** for downstream task learning.
- **Empirically demonstrate that learned skill priors accelerate learning** of new tasks across diverse simulated navigation and robot manipulation tasks, proving their essential role for effective skill transfer from rich datasets.

### 3. Methodology and Approach

The SPiRL approach decomposes the problem of prior-guided skill transfer into two main sub-problems: (1) the offline extraction of skill embeddings and a corresponding skill prior from unstructured data, and (2) the online prior-guided learning of downstream tasks using a hierarchical policy.

#### 3.1. Learning Continuous Skill Embedding and Skill Prior (Offline Pre-training)

The first stage focuses on processing a large, unstructured dataset of pre-recorded state-action trajectories ($\mathcal{D}$).
- **Skill Definition:** A skill $a_i$ is defined as a fixed-horizon sequence of actions (e.g., $H$ steps). This fixed length simplifies skill learning, though the authors note that the model could be extended to flexible-length skills.
- **Skill Embedding:** A stochastic latent variable model $p(a_i|z)$ is trained to learn a low-dimensional continuous skill embedding space $Z$.
 - An **inference network (skill encoder) $q(z|a_i)$** maps observed action sequences to a posterior distribution over latent skill embeddings. It's implemented as a one-layer LSTM.
 - A **generative network (skill decoder) $p(a_i|z)$** reconstructs action sequences from sampled latent skill embeddings. It mirrors the encoder's LSTM architecture.
 - The model is trained by maximizing the Evidence Lower Bound (ELBO), which includes a reconstruction term (reproducing action sequences) and a regularization term (keeping the posterior $q(z|a_i)$ close to a unit Gaussian prior $p(z)$ in the latent space).
- **Learned Skill Prior:** Crucially, a **state-conditioned skill prior $p_a(z|s_t)$** is introduced. This component maps the current environment state $s_t$ to a prior distribution over skill embeddings, intuitively indicating which skills are likely to be useful or relevant in that state.
 - This prior is implemented as a multi-layer fully-connected network. For image-based states, a convolutional encoder pre-processes the input.
 - It is trained **jointly** with the skill embedding model by minimizing the Kullback-Leibler (KL) divergence between the inferred skill posterior $q(z|a_i)$ (derived from the observed data) and the predicted state-conditioned skill prior $p_a(z|s_t)$. Using the reverse KL divergence $D_{KL}(q, p)$ ensures the prior covers all observed skills in a given situation (mode-covering). Gradient stopping is used to stabilize joint training.

#### 3.2. Skill Prior Regularized Reinforcement Learning (Online Fine-tuning)

The second stage utilizes the learned skill embedding and prior for accelerating downstream task learning.
- **Hierarchical Policy:** Instead of learning a policy over primitive actions, a high-level policy $\pi_\theta(z|s_t)$ is learned, which outputs skill embeddings $z$. These embeddings are then passed to the pre-trained skill decoder $p(a_i|z)$ to generate the actual H-step action sequences. This hierarchical structure provides temporal abstraction, beneficial for long-horizon tasks.
- **MDP Transformation:** The downstream learning problem is cast as a standard Markov Decision Process (MDP) where the action space is the continuous skill space $Z$, single-step rewards are replaced by H-step accumulated rewards $\tilde{r}$, and single-step transitions by H-step transitions.
- **Prior-Guided Exploration (Key Innovation):** To address the challenge of exploring the rich skill space, the authors modify maximum-entropy RL algorithms (specifically Soft Actor-Critic, SAC).
 - Traditional maximum-entropy RL maximizes policy entropy, implicitly regularizing towards a *uniform* action prior.
 - SPiRL replaces this with a regularization term that explicitly minimizes the KL divergence between the high-level policy $\pi(z_t|s_t)$ and the *learned state-conditioned skill prior* $p_a(z_t|s_t)$. The objective becomes: $J(\theta) = E_\pi [\sum \tilde{r}(s_t, z_t) - \alpha D_{KL}(\pi(z_t|s_t), p_a(z_t|s_t))]$.
 - The temperature parameter $\alpha$, which controls the trade-off between reward maximization and prior regularization, is automatically tuned by defining a target divergence $\delta$, similar to SAC's target entropy mechanism.
- **Algorithm 1 (SPiRL):** Presents the modified SAC algorithm, highlighting the changes for integrating the skill prior into the Q-target computation, policy update, and alpha adjustment. Policy weights are optionally initialized with the learned skill prior network.

In essence, SPiRL enables agents to learn a compact representation of diverse behaviors from untagged data and, critically, learns a context-dependent guidance mechanism (the skill prior) that directs the agent's exploration in this learned behavior space, making downstream task learning significantly more efficient.

### 4. Main Findings and Results

The authors conducted extensive experiments across three challenging simulated environments: Maze Navigation, Block Stacking, and a Kitchen Environment, all characterized by complex, long-horizon behaviors and sparse reward signals. The core aim was to validate SPiRL's ability to accelerate downstream learning by leveraging unstructured datasets and to confirm the necessity of learned skill priors.

#### 4.1. Performance Against Baselines

SPiRL was compared against several baselines:
- **Flat Model-Free RL (SAC):** Learns from scratch.
- **Behavioral Cloning w/ finetuning (BC + SAC):** Pre-trains policy via imitation, then finetunes with SAC.
- **Flat Behavior Prior (Flat Prior):** Uses a single-step action prior, lacking temporal abstraction.
- **Hierarchical Skill-Space Policy (SSP, "Skills w/o Prior"):** Uses the learned skill embedding space but *without* the skill prior guidance.

The results (summarized in Figure 4 and further discussed in Sections 4.2-4.3) consistently showed:
- **SPiRL (Ours) significantly outperforms all baselines across all tasks.** It is the only method that reliably solves the complex, long-horizon tasks, demonstrating effective skill transfer and exploration.
- **Importance of Temporal Abstraction:** "Flat Prior" (single-step action prior) performs poorly, often similar to Behavioral Cloning, highlighting that learning skills (temporal abstractions) is crucial for complex, long-horizon tasks. It fails to learn coherent, extended behaviors.
- **Importance of Learned Skill Prior:** "SSP w/o Prior" (hierarchical skills but no prior guidance) performs comparably or even *worse* than learning from scratch (SAC). This is a critical finding, validating the paper's core hypothesis: without the learned skill prior, exploration in rich, high-dimensional skill embedding spaces becomes prohibitively difficult, essentially negating the benefits of skill transfer. This addresses the "paradoxical" inefficiency observed in prior work.
- **Failure of From-Scratch and Finetuning:** Both SAC from scratch and BC+SAC fail to converge to good performance on these complex tasks, underscoring the necessity of leveraging prior experience in a sophisticated manner.

#### 4.2. Exploration Behavior (Maze Navigation)

Qualitative analysis of exploration in the Maze Navigation task (Figure 5) provides strong evidence for SPiRL's effectiveness:
- **SPiRL:** Shows wide-ranging and targeted exploration, effectively navigating hallways and doorways, attributed to the skill prior guiding the agent to sample promising skills.
- **Random Skill Exploration ("Skills w/o Prior"):** Leads to poor exploration, with the agent frequently sampling skills that result in collisions or unproductive movements.
- **Flat Prior:** While showing some movement, lacks the coherence needed for effective maze traversal due to the absence of temporal abstraction.

#### 4.3. Ablation Studies

- **Skill Horizon (H):** (Figure 6) An optimal skill horizon exists. Too short a horizon means insufficient temporal abstraction, while too long a horizon makes skill exploration harder.
- **Embedding Dimension (|Z|):** (Figure 6) The skill embedding space needs to be large enough to represent diverse skills. Beyond this, increasing dimensionality does not significantly hinder performance, attributed to the learned skill prior focusing exploration on relevant parts of the space, effectively keeping the *active* dimensionality manageable.
- **State-Conditioned Skill Decoder:** (Appendix D, Figure 9) Conditioning the skill decoder on the state did not improve downstream learning and sometimes destabilized it, suggesting that the primary role of the state is in the *prior* (guiding skill selection), not necessarily in how skills are executed.
- **Prior Regularization Ablation:** (Appendix E, Figure 10) Directly proves that continuous regularization towards the learned prior during downstream RL is essential. Simply initializing the policy with the prior and then using standard SAC (which encourages high entropy, thus diverging from the learned prior) leads to poor performance.
- **Prior Initialization Ablation:** (Appendix F, Figure 11) While prior regularization is key, initializing the high-level policy weights with the pre-trained skill prior network improves convergence speed and stability, though the task can still be learned without it via careful exploration strategies.
- **Training with Sub-Optimal Data:** (Appendix G, Table 1, Figure 12) SPiRL demonstrates robustness to training data quality. It can learn effective skill embeddings and priors even from a significant fraction of low-quality, random data or from purely non-expert (behavior cloning-generated) data, making it applicable to more realistic datasets.

#### 4.4. Reuse of Learned Skill Priors

(Appendix H, Figure 13) A single learned skill prior can be effectively reused to guide the learning of *multiple different downstream tasks* (e.g., reaching different goals in the same maze). This highlights the generalizability of the learned prior, as it captures fundamental "meaningful" behaviors in the environment independent of the specific task goal.

In summary, the main findings strongly support SPiRL's core hypothesis: learned skill priors are critical for enabling efficient and effective skill transfer from large, unstructured datasets, addressing a long-standing challenge in hierarchical reinforcement learning.

### 5. Significance and Potential Impact

The work presented in "Accelerating Reinforcement Learning with Learned Skill Priors" by Pertsch, Lee, and Lim marks a significant advancement in the field of reinforcement learning, particularly at the intersection of skill learning, transfer learning, and offline RL. Its significance and potential impact can be summarized as follows:

1. **Enabling Efficient Use of Unstructured Offline Data:** The most immediate and impactful contribution is providing a scalable method to leverage the vast amounts of unstructured, untagged data that exist in many real-world domains (e.g., robot logs, autonomous driving footage, human demonstrations). Unlike traditional offline RL which often requires reward labels for the downstream task, or meta-learning which needs structured task distributions, SPiRL can extract useful behavioral primitives and their context-dependent relevance from "raw" experience. This significantly broadens the applicability of RL to data-rich, reward-sparse environments.

2. **Addressing the Skill-Space Exploration Bottleneck:** The paper effectively identifies and resolves a critical limitation of previous hierarchical skill learning methods: the difficulty of exploration in rich, continuous skill embedding spaces. By learning a state-conditioned prior over skills, SPiRL provides a crucial guiding mechanism that makes high-level policy learning tractable and efficient, even when dealing with extremely diverse skill libraries. This shifts the focus from merely *extracting* skills to intelligently *utilizing* them.

3. **Enhanced Data Efficiency and Acceleration of Downstream Learning:** The empirical results conclusively demonstrate that SPiRL drastically accelerates downstream task learning compared to learning from scratch or skill transfer methods without prior guidance. This translates directly into reduced data collection costs and faster deployment cycles for complex robotic and embodied AI systems.

4. **Robustness to Sub-optimal Data:** The finding that SPiRL can learn effective skills and priors even from sub-optimal or mixed-quality data is highly significant for practical applications. Real-world datasets are rarely perfectly optimal or expert-driven, and the method's robustness broadens its utility.

5. **Generalizability of Learned Priors:** The ability to reuse a single learned skill prior for multiple different downstream tasks suggests that these priors capture fundamental, task-agnostic behavioral knowledge about the environment. This reusability reduces the need for re-training foundational models for every new task variant, contributing to overall learning efficiency.

**Potential Impact:**

- **Robotics:** This work is highly relevant for robotics, where data collection is expensive and often done via teleoperation or scripted behaviors that are unstructured. SPiRL could enable robots to quickly learn new manipulation or navigation tasks by leveraging massive archives of past robot experience.
- **Autonomous Systems:** In fields like autonomous driving, where safety is paramount, random exploration is often unacceptable. Learning skill priors from human driving data could guide RL agents towards safe and efficient behaviors, avoiding dangerous exploration.
- **Embodied AI:** For agents operating in complex virtual or physical environments, SPiRL offers a pathway to acquire rich behavioral repertoires and then adapt them efficiently to new challenges, mimicking human-like learning by leveraging prior experience.

**Future Directions (as suggested by the authors):**
The authors themselves point to promising avenues for future research, including combining learned skill priors with methods for extracting semantic skills of flexible length, and explicitly applying SPiRL to safety-critical domains where guided exploration is paramount. These directions underscore the broad potential of skill priors to advance intelligent agents beyond current limitations.

In conclusion, SPiRL represents a significant step towards enabling intelligent agents to learn efficiently in complex, data-rich, but unstructured environments. By intelligently guiding exploration in learned skill spaces, it lays foundational groundwork for more capable and robust real-world AI systems.
