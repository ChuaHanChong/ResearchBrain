# Learning Linear Attention in Polynomial Time

> [!summary] Summary
> Researchers at MIT CSAIL established the first polynomial-time learnability results for Multi-Head Linear Attention (MHLA) Transformers, offering strong, agnostic PAC learning guarantees. Their work introduces a framework for certifiable identifiability, ensuring all learned models compute an identical function out-of-distribution, and empirically demonstrates the benefits of architectural "width" (more heads) for efficient optimization.

## Problem

- A lack of polynomial-time learnability guarantees for Transformer models, particularly for efficiently learning optimal parameters from arbitrary datasets with provable bounds.
- The absence of a data-dependent, efficiently checkable condition to ensure all empirical risk minimizers of a Transformer model learn the identical function for robust out-of-distribution generalization.
- Prior theoretical work on Transformer expressivity had not fully addressed whether these capabilities could be efficiently learned with strong, agnostic PAC guarantees.

## Method

- Reparameterizing ==Multi-Head Linear Attention== (MHLA) into a higher-dimensional feature space, which transforms its non-convex optimization into a convex linear regression problem.
- Developing an efficient polynomial-time algorithm (Algorithm 1) that leverages Ordinary Least Squares (OLS) to solve the relaxed problem and then recovers MHLA parameters via Singular Value Decomposition (SVD).
- Proposing a "certifiable identifiability" condition based on the full-rank property of the input feature map's second-moment matrix, ensuring all optimal models compute the same function.

## Results

- The first polynomial-time algorithm for strong, agnostic PAC learning of single-layer MHLA was achieved, with concrete bounds on time and sample complexity (e.g., N = O(1/ϵ (d^4 + log(δ^-1)))).
- A certifiable identifiability condition was proven, demonstrating that a full-rank second-moment matrix of the input feature map guarantees all empirical risk minimizers compute an identical function, providing robust generalization.
- Empirical experiments revealed that increasing model "width" (more heads) significantly improved linear attention's optimization and that the identifiability certificate's minimum eigenvalue correlated directly with generalization performance.

## Takeaways

> [!tip] Key Insights
> - Multi-Head Linear Attention's (MHLA) non-convex learning objective can be efficiently solved in polynomial time by reparameterizing it into a convex linear regression problem.
> - A data-dependent, efficiently checkable "certifiable identifiability" condition on the feature map's second-moment matrix guarantees that all empirically optimal MHLA models compute the identical function.
> - Empirical evidence suggests that increasing "width" (number of heads) significantly aids the optimization and learnability of linear attention, aligning with the theoretical convex relaxation benefits.
