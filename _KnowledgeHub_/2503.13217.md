# Dense Policy: Bidirectional Autoregressive Learning of Actions

> [!summary] Summary
> Researchers from Shanghai Jiao Tong University introduce Dense Policy, a bidirectional autoregressive learning framework for robotic manipulation that generates precise action sequences through coarse-to-fine prediction, achieving superior performance across simulated and real-world tasks while requiring half the parameters and 10x faster inference compared to existing approaches.

## Problem

- Traditional autoregressive policies for robotic manipulation struggle to capture long-term dependencies in action sequences
- Current next-token prediction approaches perform worse than holistic generative policies despite success in other domains

## Method

- Developed **Dense Policy** framework using bidirectional expansion learning without action tokenization
- Implemented coarse-to-fine action generation starting from single frames and recursively expanding through upsampling
- Created lightweight encoder-only architecture for hierarchical action prediction from observations

## Results

- Outperformed existing generative policies across 2D and 3D manipulation tasks
- Achieved comparable inference speed to ACT with <**50%** parameters
- Demonstrated successful real-world performance on diverse tasks like drawer opening and pouring
- Showed superior learning efficiency on challenging tasks with shorter training time

## Takeaways

> [!tip] Key Insights
> - Bidirectional modeling of action sequences enables smoother and more coherent actions
> - Coarse-to-fine generation mimics human manipulation strategies of envisioning keyframes
> - Encoder-only architecture provides practical advantages in training and inference speed
