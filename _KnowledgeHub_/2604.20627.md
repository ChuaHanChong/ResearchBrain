# Occupancy Reward Shaping: Improving Credit Assignment for Offline Goal-Conditioned Reinforcement Learning

> [!summary] Summary
> Occupancy Reward Shaping (ORS) enhances offline Goal-Conditioned Reinforcement Learning by extracting long-horizon temporal information from learned generative world models through optimal transport to create policy-preserving dense rewards. The method improves performance by up to 2.2x over sparse-reward baselines across various complex locomotion, manipulation, and real-world Tokamak control tasks, while also reducing non-monotonicity in learned value functions.

## Problem

- Long-horizon, sparse-reward tasks in offline Goal-Conditioned Reinforcement Learning suffer from difficult credit assignment due to significant temporal delays between actions and outcomes.
- Existing methods relying on local temporal distance estimators or graph constructions struggle with scalability and can accumulate errors in complex, long-horizon settings.
- Learned goal-conditioned value functions frequently show high non-monotonicity, hindering effective policy learning and trapping agents in sub-optimal states.

## Method

- Learn a state-action conditioned ==occupancy measure== using a recursive Bellman-like formulation and a flow matching model to capture multi-modal future state distributions.
- Extract global temporal dependencies by defining a policy-preserving reward function as the negative squared Wasserstein-2 distance between the goal and the learned occupancy measure.
- Train a goal-conditioned policy using the dense, shaped rewards with standard offline GCRL algorithms, leveraging the improved credit assignment signal.

## Results

- Achieved an average **2.2x** improvement in success rate over sparse-reward GCIQL across 13 challenging OGBench locomotion and manipulation tasks.
- Outperformed state-of-the-art long-horizon GCRL baselines, including graph-based and hierarchical methods, and demonstrated consistent superiority in three real-world Tokamak control tasks.
- Led to significantly lower value non-monotonicity error and smoother value function estimates, particularly in long-horizon antmaze navigation, providing a dense and structured reward signal.

## Takeaways

> [!tip] Key Insights
> - Generative world models, by learning the occupancy measure, implicitly capture the global geometry and long-term temporal dependencies of the environment.
> - Optimal transport provides a formal framework to extract goal-reaching temporal information from a learned occupancy measure, which can be directly translated into a reward signal.
> - The proposed reward shaping mechanism is provably policy-preserving, ensuring that the optimal policy derived from the shaped rewards aligns with the true optimal policy in the original sparse-reward setting.
