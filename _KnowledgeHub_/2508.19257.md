# TTF-VLA: Temporal Token Fusion via Pixel-Attention Integration for Vision-Language-Action Models

> [!summary] Summary
> Peking University researchers developed TTF-VLA, a temporal token fusion framework that enhances Vision-Language-Action (VLA) model inference by intelligently fusing historical and current visual tokens. TTF-VLA achieved up to an 8.7% relative improvement in real-world robot tasks with less than 2% additional runtime overhead, while also revealing that implicit Query matrix reuse can improve performance.

## Problem

- Current VLA models process visual inputs independently at each timestep, discarding valuable temporal information and leading to computational inefficiency.
- Frame-by-frame visual processing renders VLA models vulnerable to common visual noise, such as lighting fluctuations, motion blur, and sensor artifacts, inherent in real-world robotic environments.
- VLA models fail to exploit the structured temporal patterns in manipulation sequences where most of the visual scene remains static, neglecting opportunities to leverage inherent coherence.

## Method

- ==Introduces TTF==, a training-free, model-agnostic framework that intelligently integrates historical and current visual representations to enhance VLA model inference quality.
- Employs a hard fusion strategy for each visual patch, selectively reusing tokens from the previous frame for static regions and updating tokens for dynamic or semantically critical regions.
- Utilizes a dual-dimension detection mechanism, combining grayscale pixel difference analysis for low-level changes with attention-based semantic relevance assessment, alongside a keyframe mechanism to prevent error accumulation.

## Results

- Improved average success rates on the LIBERO benchmark by **4.0** percentage points for OpenVLA and **2.7** percentage points for VLA-Cache, showing particular gains for long-horizon tasks.
- Achieved consistent improvements across diverse environments, including a **1.6** percentage point average gain on SimplerEnv and an **8.7%** relative improvement in real-world robot manipulation tasks.
- Ablation studies confirmed the complementary effectiveness of the dual-dimension detection and the critical role of periodic keyframes in maintaining performance stability against error accumulation.

## Takeaways

> [!tip] Key Insights
> - Intelligent fusion of temporal visual tokens, achieved through a dual-dimension detection combining pixel differences and attention-based relevance, consistently enhances VLA model robustness and task success rates.
> - The 'training-free' and model-agnostic nature of TTF allows it to be seamlessly integrated into existing VLA architectures (e.g., OpenVLA, VLA-Cache) with minimal additional runtime overhead (less than 2%).
> - Implicit reuse of Query (Q) matrices for static visual patches, a consequence of TTF's token-level fusion, can surprisingly improve VLA performance, challenging conventional transformer design and suggesting avenues for computational acceleration.
