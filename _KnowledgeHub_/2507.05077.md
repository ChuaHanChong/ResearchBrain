# Sequential Attention-based Sampling for Histopathological Analysis

> [!summary] Summary
> The SASHA framework enables efficient and accurate automated diagnosis of histopathological images by using a deep reinforcement learning agent to sequentially sample a small fraction of high-resolution patches. It achieves diagnostic accuracy on par with full-resolution analysis while delivering up to an 8x speedup in inference time and vastly reduced memory footprint.

## Problem

- Gigapixel Whole Slide Images (WSIs) present computational and memory challenges, making full high-resolution analysis impractical.
- Diagnostically relevant information is sparse within WSIs, leading to inefficiency when processing entire slides.
- Existing deep reinforcement learning (DRL) based sparse sampling methods suffered from poor diagnostic accuracy, reliance on generic feature extractors, and training instability.

## Method

- A deep reinforcement learning (DRL) agent is developed to learn an optimal ==sequential strategy== for sampling only 10-20% of high-resolution WSI patches.
- A Hierarchical Attention-based Feature Distiller (HAFED) generates label-informed and compressed feature representations from sampled high-resolution patches.
- A Targeted State Updater (TSU) efficiently updates the WSI state based on similarity between sampled and other patches, preventing corruption of unrelated patch states.

## Results

- SASHA-**0.2** achieved diagnostic performance (**0.953** Accuracy, **0.979** AUC on CAMELYON16) comparable to state-of-the-art full-sampling methods while outperforming competing sparse sampling approaches.
- The framework demonstrated an **8x** speedup in inference time per WSI and a >**16x** improvement in WSI compressibility compared to full-sampling models.
- SASHA-**0.2** exhibited better-calibrated predictions (lower Expected Calibration Error) than several state-of-the-art attention-based MIL models, providing more reliable confidence scores for diagnoses.

## Takeaways

> [!tip] Key Insights
> - Integrating histopathology-pretrained Vision Transformers with hierarchical attention and targeted state updates is crucial for achieving high diagnostic accuracy while selectively sampling.
> - A step-wise reward strategy based on negative cross-entropy loss significantly improves the training efficiency and performance of the DRL agent compared to terminal rewards.
> - The DRL agent learns an explainable patch selection policy that prioritizes tumor-rich regions and areas with high attention scores, mimicking human pathologists' scanning behavior.
