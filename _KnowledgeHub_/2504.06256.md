# Transfer between Modalities with MetaQueries

> [!summary] Summary
> Meta and NYU researchers introduce MetaQueries, a framework that bridges frozen multimodal language models (MLLMs) with diffusion models using learnable query tokens, enabling high-quality image generation while preserving the MLLMs' understanding capabilities and requiring only image-caption paired data for training.

## Problem

- Existing unified multimodal models require complex training procedures and often compromise between understanding and generation capabilities
- Difficulty in leveraging pre-trained MLLMs' knowledge and reasoning abilities for image generation without extensive fine-tuning

## Method

- Introduced ==MetaQueries== as learnable query tokens that extract multimodal conditions from frozen MLLMs
- Developed a ==trainable connector== to align MLLM's latent space with diffusion model's input space
- Created a novel data curation pipeline for instruction-tuning using naturally occurring image pairs

## Results

- Achieved **state-of-the-art** performance in both multimodal understanding and generation tasks
- Successfully demonstrated complex image manipulation including reconstruction, editing, and subject-driven generation
- Enabled advanced multimodal generation without sacrificing MLLM's understanding capabilities
- Showed effective knowledge transfer through complex prompt handling requiring real-world understanding

## Takeaways

> [!tip] Key Insights
> - Freezing the MLLM preserves its pre-trained understanding capabilities while enabling strong generative performance
> - MetaQueries can effectively transfer MLLM's reasoning and knowledge to image generation tasks
> - Simple image-caption paired data and standard diffusion objectives are sufficient for training
