# $π^3$: Permutation-Equivariant Visual Geometry Learning

> [!summary] Summary
> Researchers from Shanghai Jiao Tong University and Shanghai AI Laboratory developed `π^3`, a permutation-equivariant neural network for visual geometry learning that removes the dependency on a fixed reference view. The model achieved new state-of-the-art results in camera pose and point map estimation on benchmarks like Sintel and NRGBD, while significantly improving robustness to input ordering with near-zero variance.

## Problem

- Traditional and modern visual geometry reconstruction methods commonly anchor their 3D reconstructions to a single, fixed reference view, defining the global coordinate system.
- This reliance on a reference view introduces an unnecessary inductive bias, making state-of-the-art feed-forward models sensitive to the specific choice of the initial view.
- A suboptimal selection of the reference view can lead to a substantial degradation in reconstruction quality and hinder the robustness of systems in real-world scenarios.

## Method

- Introduced **π^3**, a ==permutation-equivariant neural network architecture== that inherently eliminates the need for a designated reference frame by omitting order-dependent components and reference view tokens.
- The model predicts ==scale-invariant local 3D point maps== for each view, defined in its own camera coordinate system, ensuring a consistent but unknown scale factor across all images.
- Camera poses are estimated as ==affine-invariant==, defined up to an arbitrary similarity transformation, with supervision applied to relative poses and translations rectified by an optimally determined scale factor.

## Results

- π^3 established new SOTA for zero-shot camera pose estimation on Sintel and RealEstate10K, reducing **ATE on Sintel from VGGT's 0.167 to 0.074**.
- Achieved SOTA point map estimation on NRGBD, DTU, and ETH3D (**mean Accuracy 0.194 on ETH3D vs VGGT's 0.280**).
- Empirically validated **near-zero standard deviation** across all reconstruction metrics under input order permutation (**0.003 on DTU vs VGGT's 0.033**).

## Takeaways

> [!tip] Key Insights
> - The dependency on a fixed reference view in visual geometry reconstruction constitutes an unnecessary inductive bias that limits the performance and robustness of existing models.
> - A fully permutation-equivariant architecture, which treats all input views equally, can fundamentally enhance the stability and consistency of 3D reconstructions.
> - By predicting scale-invariant local point maps and affine-invariant relative camera poses, the system can achieve high accuracy and superior robustness to input variations without relying on a global coordinate system defined by a single view.
