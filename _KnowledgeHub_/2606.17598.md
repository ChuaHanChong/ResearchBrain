# MuseVLA: An Adaptive Multimodal Sensing Vision-Language-Action Model for Robotic Manipulation

> [!summary] Summary
> MuseVLA is an adaptive multimodal sensing Vision-Language-Action (VLA) model that dynamically selects relevant sensor modalities and processes them into unified "grounded sensor images" for robotic manipulation. The model achieves an average success rate of 76.4% across thermal, acoustic, and mmWave-guided tasks, and improves zero-shot generalization by 39% on unseen tasks by leveraging a synthetic data pipeline.

## Problem

- Existing VLA models primarily rely on RGB images, limiting a robot's perception of physical properties not discernible from visible light alone (e.g., temperature, sound).
- Current multisensory VLA models often employ modality-specific architectures, require extensive modality-specific datasets, and use static sensor configurations, leading to inefficiencies and scalability issues.
- Integrating diverse sensors for generalized action generation in complex dexterous manipulation tasks remains challenging, requiring fine-grained spatial understanding and precise control.

## Method

- **MuseVLA** introduces an ==adaptive sensor selection== mechanism where a VLA model generates a task-relevant sensor token and target description, treating sensors as on-demand tools.
- It processes diverse sensor observations into "grounded sensor images," a unified intermediate representation that spatially overlays color-coded sensor heatmaps onto task-relevant regions of RGB images.
- A data synthesis pipeline augments existing RGB video datasets with simulated multisensory information to address data scarcity and facilitate robust training for generalization.

## Results

- MuseVLA achieved an average success rate of **76.4%** across thermal, acoustic, and mmWave-guided manipulation tasks, outperforming RGB-only baselines (**22.2%**) and baselines using raw concatenated sensor inputs (**33.3%**).
- The adaptive sensor selection mechanism reduced inference GPU memory usage from **13.23** GB (for all sensors) to **6.61** GB (for selected sensors), demonstrating improved efficiency.
- Pretraining with the synthesized data significantly boosted zero-shot generalization, improving average success on unseen tasks by **39%** (from **27.1%** to **66.7%**).

## Takeaways

> [!tip] Key Insights
> - Treating sensors as on-demand tools with adaptive selection significantly enhances efficiency by processing only task-relevant modalities, reducing computational overhead and memory footprint.
> - Unifying heterogeneous sensor data into "grounded sensor images" allows a single, pre-trained vision encoder to process diverse sensory inputs, simplifying the model architecture and enabling scalable multimodal fusion.
> - Synthesizing multisensory training data from readily available RGB datasets effectively mitigates data scarcity, leading to improved zero-shot generalization capabilities for unseen tasks and objects.
