# Mimir: A Neuro-Symbolic Memory System with Dynamic Grounding for Embodied Agents in Interactive Environments

> [!summary] Summary
> Mimir, a neuro-symbolic memory system, enhances embodied agents' ability to execute long-horizon tasks in interactive environments by dynamically grounding active goals with relevant world knowledge. The system improved success rates by up to 42.5 percentage points on embodied AI benchmarks, outperforming existing memory systems and several closed-source multimodal models.

## Problem

- Embodied agents face challenges in completing long-horizon tasks in partially observable, interactive environments due to difficulties in retaining and leveraging information.
- Existing approaches often use "flat histories" or implicit policy states, which lack structured ways to discern goal-relevant world facts or explicitly track task progress.
- Many memory-augmented systems do not provide a direct interface between world belief and task progress, leading to agents losing track of hidden objects or confusing subgoals.

## Method

- **Mimir**, a neuro-symbolic memory system, explicitly separates world knowledge (==World Memory==) from task execution progress (==Task Memory==).
- World Memory is a structured graph of entities and attributes, updated by observation and action feedback, persisting knowledge about objects even when not visible.
- Task Memory symbolically tracks goals, their status, hand state, and failed hypotheses, while a ==dynamic grounding== module connects the active goal with relevant entities recalled from World Memory.

## Results

- Mimir consistently improved Success Rate (SR) by up to **42.5 percentage points** and achieved an average gain of **23.0% SR** across 13 different multimodal backbones on EB-ALFRED and EB-Habitat benchmarks.
- The system surpassed prior memory-augmented frameworks, achieving **68.0% SR** on EB-ALFRED and **90.0% SR** on EB-Habitat, an increase of **16.0 percentage points** SR over the previous best memory system (RoboMemory) on EB-Habitat.
- Mimir, with a mid-sized open-source backbone, outperformed leading closed-source multimodal models (e.g., Claude-Sonnet-4-6) by **4.0 SR points** and **6.2 Goal Condition** success points on EB-Habitat's long-horizon subset.
- Ablation studies demonstrated that removing either world memory or task memory components resulted in significant performance degradation, validating the necessity of both for Mimir's effectiveness.

## Takeaways

> [!tip] Key Insights
> - Explicitly managing and dynamically grounding world facts with active task goals is crucial for robust long-horizon task execution in embodied agents.
> - Structuring memory to separate world knowledge (scene belief) from task progress (execution state) provides a more actionable and intelligent interface for decision-making.
> - Effective neuro-symbolic memory organization can enable mid-sized open-source models to achieve performance comparable to or exceeding larger, closed-source foundation models.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This work is situated within the field of embodied AI, specifically focusing on the challenges of long-horizon task execution for agents operating in partially observable, interactive environments. Embodied agents, which perceive and act in a physical or simulated world, require robust mechanisms to manage information over extended periods.

Current approaches often face limitations in maintaining a coherent and actionable understanding of their environment and task progress. Many agents rely on "flat histories" of past observations or implicit policy states within large language models (LLMs) and vision-language models (VLMs). While these can retain information, they often lack an explicit interface to discern which world facts are relevant to the currently active goal, or to inspect, update, and reuse this information effectively. This can lead to agents losing track of hidden objects, confusing completed with pending subgoals, or failing to recall critical past interactions.

Previous research has explored various forms of memory for embodied agents. Some memory-based systems, such as LLM-State and CAPEAM, enhance world-state tracking by recording object attributes and changes or action contexts. However, these systems often leave task progress implicit and do not directly bind recalled environmental evidence to the active goal. Other frameworks like CLEA and RoboMemory integrate environmental memory or coordinate different cognitive memory types, but an explicit interface between world belief and task progress is not consistently provided.

Complementary lines of research have focused on creating reusable knowledge (e.g., AutoManual, MSI-Agent) or injecting temporal context into policy execution (e.g., MemoryVLA, recurrent architectures). These methods are frequently coupled to specific model architectures or emphasize knowledge transfer across episodes rather than a transparent, episode-level decision state for real-time action selection.

Furthermore, environment modeling through open-vocabulary maps, multimodal 3D maps, and scene graphs has advanced spatial reasoning and navigation capabilities. However, these world-level memory representations often do not encode the agent's task history or progress, indicating a gap in unifying world-level and task-level memory for comprehensive decision-making. The presented work aims to address this identified gap by proposing a neuro-symbolic memory system that explicitly separates and dynamically connects world and task knowledge.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a neuro-symbolic memory system, Mimir, that enables embodied agents to perform long-horizon tasks more effectively in partially observable and interactive environments. The authors identify a fundamental operational link missing in current embodied AI systems: the explicit connection between what an agent knows about its world and what it needs to accomplish next.

The motivation for Mimir stems from several observed limitations in existing approaches:
1. **Insufficient Memory for Long-Horizon Tasks:** Agents often need to retain information beyond immediate observations due to partial observability, where relevant objects may leave view or change state. Flat histories or implicit policy states, while storing past observations, do not provide a structured way to determine which information is critical for the current goal, leading to a loss of actionable state.
2. **Lack of Explicit State Management:** Current LLM and VLM-based agents, despite advancements in instruction decomposition and control, struggle to maintain persistent world state for hidden objects and explicit task state for multi-step execution. Information preserved in long prompts or implicit policy states lacks an interface for structured inspection, updates, and reuse.
3. **Limitations of Prior Memory Systems:** While systems like LLM-State and CAPEAM improve world state tracking, they do not sufficiently address explicit task progress or the direct binding of recalled evidence to the active goal. Similarly, other memory systems (e.g., CLEA, RoboMemory, VLA policy memory systems) either lack a direct interface between world belief and task progress or are too tightly coupled to specific model architectures, hindering general applicability to planning and execution.
4. **Need for Dynamic Grounding:** The authors argue that memory should not be passive storage but an active interface that dynamically grounds the current task objectives with the relevant world facts. This enables informed action selection even when the full context is not immediately observable.

In response to these motivations, the authors outline three key contributions (objectives) for Mimir:
- **Formulate Embodied Memory:** To establish a conceptual framework where embodied memory is understood as the interaction between world state (scene belief) and task state (execution progress), emphasizing dynamic grounding as a central operation before action.
- **Instantiate Mimir as a Closed-Loop System:** To implement this formulation as a concrete system that maintains an ordered task memory and an episode-level "TreeMemory" for object locations, states, and evidence. This system would dynamically ground each active goal through memory recall, track hand state and execution failures, and translate grounded abstract actions via embodiment-specific adapters.
- **Extensive Evaluation:** To conduct comprehensive evaluations across diverse multimodal backbones and embodied environments (EB-ALFRED and EB-Habitat) to demonstrate Mimir's effectiveness in improving success rates and goal completion.

### 3. Methodology and Approach

Mimir is designed as a neuro-symbolic memory system that explicitly separates world and task knowledge to facilitate long-horizon embodied manipulation. Its core methodology revolves around maintaining two distinct memory types and a dynamic grounding module that connects them.

**Memory System Components:**

1. **Task Memory (T_t):** This component records the agent's execution progress and what remains to be accomplished. It is symbolic and comprises:
 - **Symbolic Goals (G):** The set of all goals for the task.
 - **Agenda Order (⪯):** Defines prerequisites and sequencing for goals.
 - **Goal-Status Map (s_t):** Assigns a state (pending, completed, or blocked) to each goal.
 - **Current Hand State (h_t):** Tracks what the agent is currently holding.
 - **Failed Object–Source Hypotheses (F_t):** Records bindings that were attempted but contradicted by feedback, preventing repeated failures.
 - **Evidence for Completed Goals (C_t):** Stores verified evidence of task completion.
 The active goal (g_t) is dynamically identified as the first pending goal according to the agenda order (`min_⪯ P_t`). Task memory is updated (`U_T`) based on action outcomes and feedback, with goal completion determined by whether an action's effect establishes the goal's postcondition. This allows task memory to remain stable during environmental changes while reflecting execution progress.

2. **World Memory (W_t):** This component maintains the agent's belief about the current scene entities and their evolving relationships. It is structured and comprises:
 - **Entity Set (V_t):** All known entities in the environment.
 - **Parent Relations (E_t):** Defines hierarchical relationships (e.g., object in receptacle, held by hand).
 - **Scene Root (r):** A conceptual root for the scene graph.
 - **Label Function (ℓ_t):** Records semantic identity for entities.
 - **Attribute-and-Evidence Store (ϕ_t):** Stores observed attributes, interaction-supported states, and the specific observation or interaction that led to a record.
 World memory is updated through two distinct operators: an **observation update (`U_obs_W`)** based on current sensor readings (`o_t`), which adds new entities or refines hypotheses, and an **action update (`U_act_W`)** based on execution feedback (`y_t`), which records changes like an object being picked up or placed. This separation allows the world model to persist knowledge about objects even when they leave the agent's view.

**Dynamic Grounding and Execution Loop:**

Mimir operates in a closed-loop inference cycle, as summarized in Algorithm 1.
1. **Initial State and Observation:** The agent begins with an instruction, initial memories (`T_0`, `W_0`), legal action space (`A_e`), and initial observation (`o_0`).
2. **World Memory Update:** The current observation (`o_t`) first updates the world memory (`W_t` to `W+_t`) to incorporate recent perceptions.
3. **Active Goal Retrieval:** The agent identifies the current active goal (`g_t`) from the pending goals in task memory.
4. **Goal-Conditioned Recall:** A query (`q_t`) is constructed from `g_t`. The retrieval operator (`R`) searches `W+_t` to return an ordered, bounded list (`R_t`) of candidate entities, their remembered parents, and supporting evidence relevant to `q_t`. This list excludes previously contradicted bindings.
5. **Dynamic Grounding:** The grounding operator (`G`) takes `g_t`, `R_t`, `F_t`, the action space (`A_e`), instruction (`x`), and current observation (`o_t`) to select the most suitable candidate (v*\_t) to instantiate the active goal.
 - It filters out candidates that cannot support a legal interaction, conflict with explicit constraints, or have been previously contradicted.
 - If the goal omits a source, `G` resolves it from the selected entity's remembered parent in world memory.
 - The supporting evidence is attached to form a `grounded goal (ĝ_t)`. If no candidate is viable, `G` returns `⊥_grd`, preventing unsupported actions. A VLM aids in visual disambiguation if multiple candidates remain.
6. **Action Planning and Adaptation:** A planner (`Π`) generates an embodiment-independent abstract action (`ā_t`) based on `ĝ_t`, `T_t`, and `W+_t`. An embodiment-specific adapter (`ρ_e`) then maps `ā_t` to a legal, executable action (`a_t`) in `A_e`. If `ā_t` cannot be mapped, replanning or an exploration step is triggered.
7. **Execution and Feedback:** If a valid action (`a_t`) is generated, it is executed in the environment (`Step_e`). The environment returns the next observation (`o_t+1`), execution feedback (`y_t`), and a termination flag (`z_t+1`).
8. **Memory Updates:** Finally, `y_t` updates both world memory (`U_act_W`) with physical changes and task memory (`U_T`) with goal progress, completing the loop.

This neuro-symbolic approach leverages structured symbolic representations for memories and a VLM for perception, decision-making, and grounding.

### 4. Main Findings and Results

The evaluation of Mimir focused on its long-horizon task-solving capabilities on the EB-ALFRED and EB-Habitat benchmarks from EmbodiedBench. Performance was measured using Success Rate (SR) for full-task completion and Goal Condition Success Rate (GC) for completion of ordered goal conditions.

**1. Consistent Performance Improvements Across Diverse Backbones:**
- Mimir consistently improved both SR and GC across 13 different multimodal large language models of varying scales (e.g., Qwen3-VL-8B, InternVL3-8B, Gemma-3-12B, Qwen2.5-VL-72B).
- Maximum gains observed were 42.5 SR percentage points (InternVL3-8B on EB-ALFRED) and an average gain of 23.0% SR across all tested backbones and environments.
- Improvements in SR and GC were generally aligned, indicating that Mimir not only facilitated partial progress but also more reliably led to full task completion.
- The results suggest that explicit state management can partially compensate for backbone capacity. For instance, InternVL3-8B with Mimir achieved SRs of 60.0% (EB-ALFRED) and 60.5% (EB-Habitat), matching or exceeding the performance of its 38B and 78B counterparts without Mimir.

**2. Superiority over Prior Agent and Memory Systems:**
- When compared against existing memory-augmented agent frameworks (Voyager, Reflexion, Cradle, RoboOS, RoboMemory) using a matched Qwen2.5-VL-72B backbone, Mimir demonstrated higher performance.
- Mimir achieved the highest SR on EB-ALFRED (68.0%) and the strongest SR (90.0%) and GC (94.6%) on EB-Habitat.
- Specifically, on EB-Habitat, Mimir raised the SR by 16.0 percentage points and GC by 13.6 percentage points compared to RoboMemory, which was the previous best performing memory-centered system in the comparison. This indicates that Mimir's approach to memory organization and grounding is effective, particularly in object and location-centric tasks.

**3. Outperforming Closed-Source Foundation Models:**
- Mimir, utilizing a mid-sized open-source backbone (Qwen3-VL-32B), achieved an 86.0% SR and 93.0% GC on the EB-Habitat Long-horizon subset.
- This performance exceeded that of several leading closed-source multimodal models (e.g., GPT-5.5, Claude-Sonnet-4-6, Gemini-3.5-Flash, Gemini-3.1-Pro) by 4.0 SR points and 6.2 GC points compared to the strongest baseline (Claude-Sonnet-4-6). This result suggests that the effectiveness of long-horizon embodied performance relies significantly on how task progress and world evidence are structured and organized for decision-making, beyond just the raw capacity of the underlying language model.

**4. Ablation Studies:**
- **Component Removal:** Removing either world memory or task memory from Mimir significantly degraded performance.
 - On EB-Habitat, removing world memory resulted in a drastic drop in SR (e.g., from 65.0% to 12.5% for Qwen3-VL-8B). This indicates the critical role of world memory in providing object and location evidence.
 - On EB-ALFRED, removing task memory led to larger losses in SR (e.g., a 37.5 percentage point drop for Qwen3-VL-32B), highlighting its importance for preserving ordered progress and execution constraints.
 - The full Mimir system consistently performed best, validating the synergistic coupling of world and task memories through grounding.
- **Reasoning Mode:** With Mimir, the "Instruct" reasoning mode (direct instruction following) consistently outperformed the "Thinking" mode (internal deliberation) on all metrics. This suggests that once task progress and world evidence are explicitly externalized and managed, the Instruct model can efficiently utilize this grounded decision state, with additional internal reasoning providing less advantage in this specific context.

**5. Failure Analysis:**
- Common failure cases included ambiguous target descriptions (e.g., "pick up the red object" when multiple red objects exist without further disambiguation) and insufficient visual evidence (e.g., targets being invisible, occluded, or lacking sufficient detail for reliable recognition). These failures highlight the limits of Mimir, as it organizes and connects available evidence but cannot resolve ambiguities or reconstruct information that was never perceivable by the agent.

### 5. Significance and Potential Impact

Mimir represents an advancement in the field of embodied AI by introducing a neuro-symbolic memory system designed to manage the complexities of long-horizon tasks in interactive environments. The significance and potential impact of this work are multi-faceted:

- **Enhanced Embodied Agent Capabilities:** By explicitly separating world belief from task progress and dynamically grounding goals, Mimir enables embodied agents to operate more effectively and reliably in complex, partially observable settings. The demonstrated consistent improvements in success rates and goal completion across various backbones indicate a more robust approach to long-horizon planning and execution.
- **Improved Memory Management Paradigm:** The formulation of embodied memory as a dynamic interaction between world state and task state, rather than passive storage, offers a more actionable and intelligent memory interface. This paradigm shift could influence future designs of cognitive architectures for embodied agents, emphasizing explicit state management over implicit information retention.
- **Resource Efficiency and Scalability:** The finding that Mimir allows mid-sized open-source backbone models to outperform much larger backbones (without Mimir) and even state-of-the-art closed-source models is significant. This suggests that effective memory organization can compensate for raw model capacity, potentially leading to more efficient and scalable embodied AI systems. It could democratize access to high-performing embodied agents by reducing reliance on extremely large, computationally expensive models.
- **Transparency and Debuggability:** The explicit, structured nature of Mimir's world and task memories provides a more transparent and interpretable decision-making process. Researchers and developers can inspect the agent's current understanding of the world and its task progress, which could facilitate debugging, analysis of failures, and a deeper understanding of agent behavior.
- **Guidance for Future Research:** The identified failure modes, such as ambiguous instructions and limitations due to insufficient visual evidence, provide clear directions for future research. This includes exploring methods for handling uncertainty in grounding, integrating interactive clarification mechanisms, or developing more robust perception systems that can extract richer information from challenging visual inputs. The work also opens avenues for investigating how Mimir's structured memory could be integrated with other forms of cognitive memory or learning paradigms for even broader capabilities.
- **Open-Source Contribution:** The planned release of Mimir's code is expected to foster further research and development in the embodied AI community, enabling other researchers to build upon this framework and accelerate progress in the field.
