# TRACE: Trajectory-Routed Causal Memory for Delayed-Evidence Visuomotor Imitation

> [!summary] Summary
> TRACE is a memory framework for visuomotor imitation policies that stores task-relevant visual and robot-state evidence in fixed-size latent slots, indexed by path-signature features of the executed trajectory rather than time or task labels. Attached via lightweight adapters, it lets robots recall a vanished early cue to resolve visually ambiguous later branch points, raising average task progress from 25-25% to 59-69% on five real-world long-horizon manipulation tasks.

## Problem

- Visuomotor policies condition on current or short-window observations, an implicit Markov assumption that breaks when the decisive cue disappeared earlier in the episode.
- Longer context windows raise cost and force the policy to infer which stale observations still matter, without guaranteeing retention of the decisive cue.
- Recurrent policies and generic memories carry information forward but let branch-relevant cues be overwritten, diluted, or entangled with unrelated task-progress signals.

## Method

- **Path-signature trajectory keys**: order-sensitive, fixed-length ==depth-3 signatures== of the executed robot-state path (plus a delta signature) serve as deterministic causal keys for memory access, not as stored content.
- **Signature-routed slot memory**: a fixed K-slot latent memory is written and read via routing weights computed from the trajectory key against previous slot contents, with a ==gated update== that only overwrites selected slots.
- **Policy-family adapters**: lightweight, ==zero-initialised== adapters translate the shared **TRACE** memory state into ==action-chunking== or ==diffusion policy== conditioning inputs without altering backbone, action head, or imitation loss.

## Results

- On five real robot tasks, TRACE raises Regression policy average stage progress from **25.50%** to **69.23%** and Diffusion policy progress from **25.00%** to **59.53%**, beating the strongest VLA baseline by **18.76** and **9.06** points respectively.
- Against matched memory baselines under the same regression policy, TRACE's signature-routed slots reach **69.23%** average versus **56.30%** for retrieval-prompt memory, **53.93%** for LRU external memory, and **45.83%** for GRU recurrent memory.
- Ablations show each component matters: removing memory drops to **25.50%**, signature-only reaches **45.50%**, unrouted slot memory **52.17%**, and order-reversal diagnostics collapse route similarity from **100%** to **37.80%**, confirming causal-order dependence.

## Takeaways

> [!tip] Key Insights
> - Indexing memory by the executed trajectory geometry, not raw time or task labels, lets a policy retrieve different stored evidence at visually identical branch points reached via different histories.
> - Separating memory content (what to remember, from visual-state features) from memory access (where to store/retrieve, from trajectory signatures) generalizes better than simply extending context length or capacity.
> - A causal memory can be bolted onto existing action-chunking or diffusion policies via a thin adapter, leaving the base backbone and imitation objective untouched, suggesting memory is a portable module rather than an architecture choice.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work addresses a challenge in visuomotor control for autonomous robots: making decisions based on evidence that is no longer directly observable. This scenario, termed "delayed-evidence tasks," often arises in long-horizon manipulation where an initial cue disappears before a later decision point. Current visuomotor policies, including imitation learning methods, typically operate under an implicit Markov assumption, where the current observation or a short history window is considered a sufficient state for action selection.

The broader landscape of visuomotor imitation policies includes various approaches such as action-chunking policies, diffusion policies for action sequence generation, and generalist policies leveraging language conditioning and large robot datasets (e.g., RT-1, RT-2, π$_{0.5}$, SmolVLA, X-VLA, GR00T N1.6). While these methods have advanced robot control, their effectiveness is limited in partially observable environments where critical information from the past is absent from the current sensory input. Existing solutions for partial observability, such as recurrent policies, context windows, or explicit memory mechanisms, can suffer from issues like information dilution, entanglement with irrelevant signals, or requirements for significant architectural changes, long contexts, or demonstration retrieval.

Concurrently, research on trajectory signatures offers compact, order-sensitive summaries of continuous paths, which have been explored as sequence features in machine learning contexts. Some approaches have utilized external memory or keyframe memories in hierarchical imitation. However, these often involve modifying the policy backbone or specializing memory for specific planners.

The presented work, TRACE, positions itself by offering a memory framework that specifically targets delayed-evidence scenarios by providing a causal, fixed-budget memory. It aims to integrate with existing visuomotor policies through lightweight adapters, without altering their core backbone, action head, or imitation objective. By leveraging path signatures as unique trajectory-conditioned keys for memory access, TRACE seeks to provide a distinct solution for preserving and retrieving task-relevant historical evidence, thereby enhancing visuomotor imitation in complex, partially observable settings.

### 2. Key Objectives and Motivation

The primary motivation for this research stems from the limitations of current visuomotor policies in handling "delayed-evidence tasks." In such tasks, robots must make critical "branch" decisions (e.g., choosing a target, route, or manipulation routine) based on information that was observed earlier in an episode but is no longer visually present at the decision point. This creates a scenario where visually similar observations can require different actions, rendering the current observation insufficient for control. Policies relying on short observation windows fail when the decisive cue falls outside the window, while excessively long windows increase computational cost and necessitate complex inference regarding which past observations remain relevant. Furthermore, generic recurrent policies or memory mechanisms may dilute, overwrite, or entangle crucial branch-relevant cues with other task-progress signals.

Against this background, the key objectives of the research are detailed as follows:

- **Formulate Delayed-Evidence Imitation:** To formally define a class of visuomotor imitation problems where visually ambiguous branch points necessitate different actions, with the decisive evidence having appeared earlier in the episode. This formulation explicitly acknowledges the violation of the implicit Markov assumption inherent in many current visuomotor policies.
- **Introduce TRACE Memory:** To develop a fixed-budget, causal memory framework designed for visuomotor imitation policies. This memory system is intended to store task-relevant visual and robot-state evidence online. A central aspect of this objective is the novel use of path signatures, which are order-sensitive summaries of the executed robot-state trajectory, as keys for both writing and reading memory. This approach aims to link memory access directly to the robot's trajectory history, allowing retrieval of context that is no longer visible.
- **Plug-in Integration and Evaluation:** To ensure the practical applicability and modularity of the TRACE framework, an objective is to enable its integration with existing action-chunking and diffusion policies through lightweight adapters. This integration should occur without requiring modifications to the base policy's backbone, action head, or imitation loss. Following integration, the framework is to be rigorously evaluated on real-world delayed-evidence manipulation tasks, with diagnostics designed to demonstrate that performance gains are attributable to the preservation and utilization of historical evidence.

In summary, the research is motivated by the need for robots to retain and utilize past, non-visible information for robust decision-making in complex tasks, and its objectives aim to provide a specific, modular, and empirically validated memory solution for this problem.

### 3. Methodology and Approach

The TRACE framework addresses the delayed-evidence problem by augmenting existing visuomotor imitation policies with a fixed-size causal memory. The core approach involves storing task-relevant evidence in latent memory slots and retrieving it based on the robot's executed trajectory.

**Problem Setup:**
The work frames delayed-evidence tasks within imitation learning, where demonstrations $\mathcal{D} = \{\tau^i\}_{i=1}^N$ consist of multi-view observations $o_t$, robot state $s_t$, and expert actions $a_t$. The critical aspect is that at a branch point $t_b$, different histories $H_t$ and $H'_t$ can lead to visually similar observations $x_{t-w+1:t} \approx x'_{t-w+1:t}$ but require distinct expert actions $a^\star_t(H_t) \neq a^\star_t(H'_t)$. TRACE aims to provide a compact causal history summary $m_t$ such that a policy $\pi(a_t | x_t, m_t)$ can resolve this ambiguity.

**Path Signatures as Streaming Trajectory Keys:**
TRACE uses path signatures as deterministic, fixed-budget keys for memory access. A path signature $\text{Sig}_{\le p}(S_t)$ is an order-sensitive summary of the robot's piecewise-linear state trajectory $S_t$. This feature captures both net changes and ordered interactions among state coordinates. The signature is robust to monotone time reparameterization, making it less dependent on raw execution speed than time-step indexing. TRACE maintains a streamed depth-$p$ path signature $\xi_t = \text{Sig}_{\le p}(S_t)$ and a local change feature $\delta_t = \xi_t - \xi_{t-1}$. Learned projections $\phi_g$ and $\phi_\Delta$ embed these into $g_t$ and $\Delta g_t$, which are then combined to form the trajectory key $q_t = \phi_q([g_t, \Delta g_t])$. This key is distinct from task labels, visual memories, or recurrent states, serving solely to index memory.

**Signature-Routed Slot Memory:**
The core of TRACE is a K-slot latent memory $M_t \in \mathbb{R}^{K \times d}$ that stores task-relevant evidence.
1. **Content Encoding:** The current visual and robot-state input $x_t$ is encoded into an evidence feature $e_t = \phi_x(x_t)$.
2. **Routing:** The trajectory key $q_t$ is used to compute a routing state $\rho_t = \phi_\rho(q_t)$. This $\rho_t$ is compared with the previous slot contents $m_{t-1,k}$ (potentially augmented with fixed slot identities $\eta_k$) to compute attention-like routing weights $\omega_{t,k}$ for each slot. This allows slot selection to adapt dynamically as memory contents evolve.
3. **Writing:** A write input $u_t = \phi_w(e_t, q_t)$ combines current evidence with the trajectory key. Each slot $m_{t-1,k}$ is proposed new content $\tilde{m}_{t,k}$ via $\phi_m$, and a routing-modulated write gate $\beta_{t,k}$ (derived from $\omega_{t,k}$) controls how strongly the new content updates the slot: $m_{t,k} = (1 - \beta_{t,k})m_{t-1,k} + \beta_{t,k}\tilde{m}_{t,k}$. Slots less relevant to the current trajectory key remain largely unchanged.
4. **Reading:** After writing, a query derived from $e_t$ and $\rho_t$ computes read weights $\alpha_{t,k}$ over the updated slots $M_t$. These weights are used to form a compact memory readout $z_{\text{mem},t}$.

This memory system updates online and causally, processing only observations and states available up to the current time step. It employs auxiliary losses during training to stabilize memory dynamics, including $L_\text{bal}$ (for balanced slot usage), $L_\text{ent}$ (to discourage diffuse writing), and $L_\text{cons}$ (to align readout with write proposals).

**Policy Adapter:**
TRACE integrates with base policies via lightweight, policy-specific adapters $A_\theta^{(e)}$. These adapters translate the shared TRACE memory state $R_t = (M_t, z_{\text{mem},t}, g_t, \Delta g_t)$ into a memory condition $c_t$ suitable for the base policy's native conditioning space.
- For **action-chunking regression policies**, the adapter projects memory slots into memory tokens and summarizes $z_{\text{mem},t}, g_t, \Delta g_t$ into a summary token. These tokens are concatenated to the policy's attention memory.
- For **diffusion policies**, the adapter pools slots, concatenates the pooled memory with $z_{\text{mem},t}, g_t, \Delta g_t$, and maps the result through a zero-initialized MLP into an additive global conditioning vector.
In both cases, the base policy's action representation, action head, and imitation loss remain unchanged.

**Experimental Setup:**
Evaluation was conducted on five real-world, long-horizon manipulation tasks: Tool, Book, Laundry, Cable, and Medicine, each featuring distinct delayed-evidence scenarios. These tasks involved diverse objects, origins, routes, and manipulation routines. Performance was measured by stage-level task progress, inspired by established benchmarks, averaged across 25 physical rollouts per task. Baselines included the base regression (ACT) and diffusion policies, as well as fine-tuned versions of large-scale visuomotor models like SmolVLA, $\pi_{0.5}$, X-VLA, and GR00T N1.6, all trained on the same single-task demonstrations. Diagnostic experiments, such as history transforms (time resampling, speed jitter, state offset, sparse sampling, order reversal), were performed to assess how TRACE utilizes historical evidence.

### 4. Main Findings and Results

The empirical evaluations were structured to address four primary questions regarding TRACE's performance and mechanism.

**1. Does adding causal memory improve delayed-evidence manipulation?**
The results indicate a substantial improvement in task success when TRACE is integrated. For the regression-style action-chunking policies, the average stage progress increased from 25.50% to 69.23%. For diffusion-based policies, it rose from 25.00% to 59.53%. TRACE also surpassed the best non-TRACE baseline, $\pi_{0.5}$, by 18.76 percentage points for the Regression variant and 9.06 points for the Diffusion variant. The most pronounced gains were observed in tasks such as Book, Laundry, and Medicine, where an initial object or origin cue is critical for a later, visually ambiguous branch decision. Variance analysis, specifically a "drop-Tool" evaluation removing the task with highest variance, further confirmed that the aggregate improvement was not solely driven by this particular task, maintaining a significant advantage over baselines.

**2. Does the gain transfer across policy families?**
The performance improvements were observed across both the regression (ACT) and diffusion policy families. While the Regression variant generally exhibited stronger average performance in the measured rollouts, both policy types benefited from the same TRACE updater module. The only component that changed between these two variants was the lightweight policy-facing adapter. This finding supports the modular design claim that TRACE provides a unified way to supply missing historical information without requiring significant modifications to the underlying policy's architecture, action representation, or imitation loss. Visualizations of memory signals confirmed that signature-indexed writes were distributed across slots and that routing adapted over episode progress, maintaining selectivity near branch points.

**3. Is TRACE better than generic history memory?**
TRACE demonstrated superior performance compared to alternative memory mechanisms, including recurrent (GRU-based), transformer-context, LRU (Least Recently Used) external memory, and retrieval-prompt memory approaches. While these generic memory solutions improved performance relative to policies with no memory, they did not match TRACE's efficacy. This suggests that merely providing more history or storage capacity is insufficient; the history must be organized and indexed specifically around the executed causal trajectory to effectively preserve and retrieve delayed cues at the appropriate branch points.

**4. Do diagnostics show that TRACE uses earlier evidence rather than only the decision-point observation?**
History-transform diagnostics provided evidence that TRACE utilizes ordered historical information. Transforms that preserved the causal order of the robot-state trajectory, such as time resampling, speed jitter, state offset, and sparse sampling, maintained high route similarity (agreement between transformed and original slot routing) and branch consistency (agreement in branch-point memory readout and action). In contrast, deliberately reversing the order of the history sharply reduced both route similarity and branch consistency. This outcome indicates that TRACE relies on the sequential, ordered nature of the executed trajectory to route and retrieve memory, rather than solely on the immediate, potentially ambiguous, observation at the decision point. Furthermore, long-horizon stability diagnostics indicated low slot churn, balanced slot occupancy, and high readout and decision consistency even under extended history and repeated distractor segments, supporting the memory's ability to retain information over time.

### 5. Significance and Potential Impact

The development of TRACE represents an advancement in addressing the problem of delayed-evidence decision-making in visuomotor robot control. By introducing a modular, fixed-budget causal memory framework, TRACE offers a practical solution to a common limitation of current imitation learning policies that often assume sufficient information within the immediate observation window.

The primary significance lies in its capacity to enable robots to make accurate decisions when critical context is no longer visually present. This capability is crucial for enhancing the autonomy and robustness of robots in complex, long-horizon manipulation tasks encountered in various real-world scenarios. The utilization of path signatures as trajectory-conditioned keys for memory routing is a notable contribution, providing a robust, order-sensitive, and deterministic mechanism for memory access that is less susceptible to issues like time reparameterization or execution speed variations.

The modular design of TRACE, which integrates with existing policy backbones via lightweight adapters without modifying their core architecture or loss functions, contributes to its potential broad applicability. This "plug-in" nature simplifies adoption for various visuomotor policy families, including regression-based and diffusion-based models, as demonstrated in the evaluations. This could facilitate faster development and deployment of intelligent robotic systems capable of more sophisticated temporal reasoning.

Potential impacts extend beyond the specific manipulation tasks evaluated. The principles of trajectory-routed causal memory could be applied to other partially observable robotic control problems, such as navigation, assembly, or human-robot interaction, where historical context is vital for safe and effective decision-making. The framework's ability to retain and selectively retrieve past evidence could pave the way for more intelligent robotic agents that can operate reliably in dynamic and ambiguous environments, ultimately contributing to more capable and adaptable autonomous systems.

A noted limitation is the rapid growth of signature dimensionality with increased state dimension and signature depth, which may present computational challenges for very high-dimensional robot states or more complex temporal dependencies requiring deeper signatures. However, the current implementation offers a pragmatic balance, and alternative representations like log signatures may mitigate this in future work. Overall, TRACE contributes a method for endowing visuomotor policies with an essential form of long-term memory, thereby expanding the capabilities of robot learning from demonstration.
