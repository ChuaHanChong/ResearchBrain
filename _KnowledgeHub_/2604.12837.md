# GGD-SLAM: Monocular 3DGS SLAM Powered by Generalizable Motion Model for Dynamic Environments

> [!summary] Summary
> GGD-SLAM presents a monocular 3D Gaussian Splatting SLAM system that effectively operates in dynamic environments by employing a generalizable motion model for robust dynamic object identification without external priors. This framework achieves enhanced camera tracking and produces superior dense scene reconstructions, evidenced by higher PSNR and SSIM values on dynamic datasets.

## Problem

- Visual SLAM algorithms, including 3D Gaussian Splatting (3DGS) based methods, traditionally assume static environments, leading to performance degradation in dynamic settings.
- Robustly identifying dynamic objects without relying on predefined semantic annotations or external depth input is challenging for existing dynamic SLAM systems.
- Current dynamic SLAM approaches often struggle with misjudgment due to reliance on single-frame analysis or per-scene 3DGS reconstruction quality, especially when objects are transiently static.

## Method

- A **Generalizable Motion Model** (==GMM==) is introduced, leveraging a ==sequential attention mechanism== and a ==FIFO queue== of image features to extract dynamic semantics from temporal sequences without requiring external priors.
- The tracking module integrates the GMM-generated ==dynamic prior== to proactively mask out dynamic regions, preventing incorrect factor graph construction and enhancing camera pose estimation.
- The mapping module incorporates ==GMM-guided uncertainty==, utilizes a ==static Gaussian KD-tree== for occlusion recovery, and employs a novel ==distractor-adaptive SSIM loss== to maintain high-fidelity static scene reconstruction.

## Results

- **GGD-SLAM** achieved competitive and often superior camera tracking performance (lower ATE) compared to state-of-the-art dynamic dense SLAM approaches on challenging dynamic datasets like TUM RGB-D and Bonn RGB-D Dynamic.
- The framework demonstrated the best dense map reconstruction quality among monocular GS-based systems, consistently recording higher PSNR (average **23.03**) and SSIM (average **0.859**) values across evaluated dynamic sequences.
- The Generalizable Motion Model (GMM) successfully extracted dynamic object semantics, outperforming single-image methods and addressing misjudgment issues in uncertainty-aware approaches, contributing to cleaner and more consistent reconstructions.

## Takeaways

> [!tip] Key Insights
> - Accurate dynamic object identification in SLAM systems is significantly improved by incorporating temporal context and correlation across multiple consecutive frames, rather than relying solely on instantaneous observations.
> - A learned, generalizable motion prior that extracts dynamic semantics from progressive SLAM inputs, without needing semantic labels or depth, can effectively enhance robustness in both tracking and mapping.
> - Tailoring loss functions, such as a distractor-adaptive SSIM, is crucial for robustly optimizing static scene components in the presence of dynamic distractors, preserving reconstruction quality.
