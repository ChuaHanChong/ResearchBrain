# MPViT: Multi-Path Vision Transformer for Dense Prediction

> [!summary] Summary
> Researchers from ETRI and KAIST developed MPViT, a Vision Transformer architecture that enhances multi-scale feature representation for dense prediction tasks through a novel multi-scale patch embedding and multi-path processing. It achieves state-of-the-art results across image classification, object detection, and segmentation benchmarks, often with fewer parameters and FLOPs than prior ViTs.

## Problem

- Dense computer vision tasks require effective multi-scale feature representation to accurately process objects of widely varying sizes.
- Existing Vision Transformers (ViTs) often use single-scale patches at each feature level, limiting multi-scale diversity, or incur high computational overhead for complex multi-scale interactions.
- Traditional ViTs may overlook fine-grained local relationships, an area where Convolutional Neural Networks (CNNs) historically excel due to their local connectivity inductive bias.

## Method

- Introduces a multi-stage architecture with a ==Multi-Scale Patch Embedding (MS-PatchEmbed)== module, which simultaneously tokenizes visual patches of different sizes at the same feature level using overlapping convolutional operations.
- Employs ==Multi-Path Transformer (MP-Transformer)== blocks featuring parallel independent Transformer encoders for each patch scale, combined with a ==Global-to-Local Feature Interaction (GLI)== module.
- Leverages efficient ==factorized self-attention== and a 'deeper and thinner' model scaling strategy to manage computational costs while maximizing performance across multiple processing paths.

## Results

- MPViT-Small achieves **83.0%** Top-1 accuracy on ImageNet-1K with **22.8M** parameters and **4.7 GFLOPs**, surpassing several larger and more computationally intensive Vision Transformers.
- On COCO object detection with RetinaNet, MPViT-S obtains **47.6%** AP, outperforming Swin-T and Focal-T by **2.1-2.6%**, and on Mask R-CNN, MPViT-S reaches **43.9%** mask AP.
- For ADE20K semantic segmentation using UperNet, MPViT-S achieves **48.3%** mIoU, outperforming Swin-T, Focal-T, and XCiT-S12/16 by margins of **3.8%**, **2.5%**, and **2.4%** respectively.

## Takeaways

> [!tip] Key Insights
> - Processing truly multi-scale patches concurrently within a Transformer block, rather than relying solely on hierarchical stages, leads to richer and more diverse feature representations for dense prediction.
> - A hybrid Global-to-Local Feature Interaction module that concatenates and learns interactions between convolutional local features and Transformer's global features effectively combines their respective strengths.
> - For multi-path Transformer architectures, a 'deeper and thinner' configuration (more layers, fewer channels per path) is more effective than wider, shallower designs for improving accuracy while managing computational resources.
