# Self-Questioning Language Models

> [!summary] Summary
> Carnegie Mellon University researchers developed Self-Questioning Language Models (SQLM), an autonomous self-improvement framework enabling LLMs to enhance reasoning by generating and solving their own problems. This approach reduces reliance on human-curated data, achieving up to 16% accuracy gains across arithmetic, algebra, and coding benchmarks.

## Problem

- LLM refinement for reasoning and alignment heavily depends on costly and labor-intensive human-curated datasets.
- Existing unsupervised reward functions alleviate the need for ground-truth answers but still require human-authored questions.
- The primary bottleneck in LLM post-training is the extensive manual effort required to generate high-quality problem instances and their solutions or preference labels.

## Method

- Developed ==Self-Questioning Language Models (SQLM)==, an ==asymmetric self-play framework== where an LLM functions as both a "proposer" (generating problems) and a "solver" (attempting solutions).
- Employed self-supervised reinforcement learning for both roles, with reward functions adapted to the problem domain's verifiability (e.g., majority voting for arithmetic, unit tests for coding).
- Initiated training with only a high-level ==topic prompt==, eliminating the need for any initial human-authored questions or labeled data.

## Results

- Achieved substantial performance gains, including a **14%** accuracy increase (from **0.791** to **0.948**) in three-digit multiplication and a **16%** increase (from **0.440** to **0.600**) for algebra linear equations.
- Showed a **7%** accuracy improvement (from **0.320** to **0.391**) on Codeforces-like programming problems.
- Qualitatively demonstrated an emergent curriculum where the proposer generated increasingly complex problems, and confirmed that online problem generation maintained greater data diversity compared to static methods.

## Takeaways

> [!tip] Key Insights
> - Large language models inherently possess capabilities for self-directed learning and can improve their reasoning without external human supervision.
> - An asymmetric self-play mechanism fosters an emergent curriculum, where the proposer dynamically generates progressively challenging problems that match the solver's improving skills.
> - Online generation and adaptive updating of problems by the proposer effectively maintain data diversity, outperforming static dataset generation approaches.
