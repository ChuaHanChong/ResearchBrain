# Mobility VLA: Multimodal Instruction Navigation with Long-Context VLMs and Topological Graphs

> [!summary] Summary
> Mobility VLA, developed by Google DeepMind, enables robots to understand and navigate based on complex multimodal instructions by combining the semantic reasoning of long-context Vision-Language Models with robust topological graphs. The system demonstrated high success rates in real-world environments, including 85% for multimodal instructions in an office, and showed that long-context VLMs are crucial for high-level understanding while a classical low-level controller is essential for reliable action execution.

## Problem

- Existing robot navigation methods like Object Goal Navigation (ObjNav) and Vision-Language Navigation (VLN) often lack the ability to handle complex, multimodal instructions or require extensive real-time exploration.
- Large Vision-Language Models (VLMs) struggle with practical embodied navigation due to context length limitations when processing entire environment representations and their inability to output low-level robot actions directly.
- Robots needed a more intuitive and human-like interaction paradigm for navigation, allowing for combined natural language and visual cues, and common-sense reasoning for ambiguous instructions.

## Method

- ==Introduces Multimodal Instruction Navigation== with Tours (MINT), which uses an easily collectable demonstration tour video of the environment as prior knowledge.
- Employs a hierarchical Vision-Language-Action (VLA) policy: an offline phase constructs a topological graph from the tour video, and an online phase executes the navigation.
- A long-context VLM (Gemini 1.5 Pro) performs high-level semantic goal finding by identifying a target frame from the tour based on multimodal user instructions, while a low-level policy uses the topological graph for robust localization, path planning, and waypoint action generation.

## Results

- Mobility VLA achieved high end-to-end success rates in real-world environments: **80%** for reasoning-required/free instructions and **85%** for multimodal instructions in an office setting, and **100%** in a home-like environment using smartphone-recorded tours.
- The system's high-level goal finding significantly outperformed CLIP-based retrieval and text-only VLM baselines (e.g., **90%** vs. **30%** for multimodal tasks) by effectively leveraging long-context VLMs.
- Direct VLM prompting for actions resulted in **0%** end-to-end navigation success, validating the necessity of a separate topological graph-based low-level controller which consistently achieved **100%** success for goal reaching.

## Takeaways

> [!tip] Key Insights
> - Long-context Vision-Language Models (VLMs) are crucial for high-level semantic understanding of complex, multimodal instructions, as evidenced by drastic performance drops when context length is constrained.
> - Directly prompting VLMs for low-level robot actions is ineffective and inefficient for navigation due to their lack of embodied control understanding and slow inference for real-time operation.
> - A hierarchical approach, combining VLM for high-level goal identification with a robust topological graph-based low-level policy, effectively bridges the gap between semantic understanding and precise robot action.
