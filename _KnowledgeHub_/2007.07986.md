# Boosting Weakly Supervised Object Detection with Progressive Knowledge Transfer

> [!summary] Summary
> A progressive knowledge transfer framework significantly improves weakly supervised object detection by iteratively refining a one-class universal detector and a multiple instance learning classifier through pseudo ground truth mining. This method addresses the incomplete label problem in transfer learning, achieving 59.7% mAP on Pascal VOC 2007 with multi-scale testing.

## Problem

- Weakly supervised object detection (WSOD) using only image-level labels typically underperforms compared to fully supervised methods due to the lack of explicit bounding box annotations.
- Existing Multiple Instance Learning (MIL) approaches for WSOD, while making progress, still fall short of fully supervised accuracy.
- Previous transfer learning approaches for WSOD struggle with the "incomplete label problem," where objects belonging to target categories in the source dataset are unannotated, creating noisy supervision.

## Method

- A ==progressive knowledge transfer framework== that iteratively refines both a ==One-Class Universal Detector (OCUD)== and a Multiple Instance Learning (MIL) classifier.
- The OCUD is initially trained on a fully-annotated source dataset to detect objects as a single generic class, providing robust proposals.
- ==Pseudo ground truths== are iteratively mined from both source and target datasets, which are then used to refine the OCUD and the MIL classifier in subsequent training steps.

## Results

- Achieved **59.7%** mAP on Pascal VOC 2007 with multi-scale testing, outperforming prior state-of-the-art weakly supervised object detection methods.
- Further retraining a fully supervised Faster R-CNN with the mined pseudo ground truths led to **60.2%** mAP on Pascal VOC 2007.
- Demonstrated consistent performance improvement over multiple refinement iterations and showed robust performance even with limited target training data (e.g., **20%** of the dataset).

## Takeaways

> [!tip] Key Insights
> - Iterative pseudo ground truth mining enables progressive discovery of objects and refinement of both the one-class universal detector and the MIL classifier.
> - Training a one-class universal detector helps mitigate category-specific biases and addresses the incomplete label problem by treating all objects generically in the source domain.
> - Leveraging fully-annotated source data through this progressive knowledge transfer can significantly bridge the performance gap between weakly supervised and fully supervised object detection.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Object detection is a fundamental challenge in computer vision, but traditional fully supervised approaches require expensive bounding box annotations for training. Weakly supervised object detection (WSOD) offers a promising alternative by learning from image-level labels alone, which are significantly cheaper to obtain. However, WSOD methods typically underperform compared to their fully supervised counterparts.

This paper introduces a novel progressive knowledge transfer framework that significantly improves WSOD performance by leveraging existing fully-annotated datasets. Unlike previous transfer learning approaches that struggle with the "incomplete label problem," this method implements an iterative refinement process that progressively mines and refines pseudo ground truth annotations across both source and target domains.

### 2. Key Objectives and Motivation

WSOD aims to train object detectors using only image-level labels (indicating object presence, not location). While this reduces annotation costs, it creates a significant technical challenge: how to accurately locate objects without explicit location supervision.

Previous WSOD methods have primarily employed Multiple Instance Learning (MIL) approaches, where each image is treated as a "bag" of object proposals. These approaches have made substantial progress but still fall short of fully supervised methods in terms of detection accuracy. Transfer learning has emerged as a promising direction to bridge this gap.

However, existing transfer learning approaches for WSOD face a critical challenge: the "incomplete label problem." This occurs when objects in the source dataset that belong to target categories remain unannotated because they weren't part of the source dataset's category set. This creates noisy supervision signals that can mislead the knowledge transfer process.

### 3. Methodology and Approach

The proposed framework consists of two key components:

1. **One-Class Universal Detector (OCUD)**: Trained to detect objects of any category as a single, generic class.
2. **Multiple Instance Learning (MIL) Classifier**: Trained on the target dataset using image-level labels, with proposals from the OCUD.

The innovation lies in the progressive refinement strategy, which iteratively improves both components through pseudo ground truth mining:

1. Initial training of the OCUD on the source dataset
2. Initial training of the MIL classifier on the target dataset
3. Mining of pseudo ground truths from both source and target datasets
4. Refinement of the OCUD using original source annotations and mined pseudo ground truths
5. Refinement of the MIL classifier with the improved OCUD

This iterative process is repeated multiple times, progressively improving detection performance.

#### 3.1. One-Class Universal Detector

The OCUD is designed to detect "objectness" rather than specific categories. It follows a Faster R-CNN-like architecture but with a single class output. The OCUD provides high-quality object proposals that help the MIL classifier focus on relevant regions.

The OCUD is initially trained on the fully-annotated source dataset. All object annotations are treated as a single "object" class, regardless of their original category. This provides the model with a strong foundation for generic object detection capabilities.

During each refinement iteration, the OCUD is updated using:
1. Original annotations from the source dataset
2. Mined pseudo ground truths from both source and target datasets

This approach maintains stability while incorporating new knowledge.

#### 3.2. Iterative Refinement Process

The core of the framework is the iterative refinement process:

1. **Pseudo Ground Truth Mining**: In each iteration, the current OCUD and MIL classifier are used to generate object detections on both source and target datasets. High-confidence detections are selected as pseudo ground truths based on a confidence threshold τ. For the source dataset, pseudo ground truths are filtered to ensure they don't conflict with existing annotations.

2. **OCUD Refinement**: The OCUD is retrained using both the original source annotations and the mined pseudo ground truths from both datasets.

3. **MIL Classifier Refinement**: The MIL classifier is retrained using the improved OCUD to generate proposals.

The MIL classifier follows a two-stream architecture similar to WSDDN, but with an additional regularization term that encourages agreement with the OCUD's objectness predictions:

L = L_cls + λ · L_reg

Where L_cls is the standard MIL classification loss and L_reg is the L2 regularization loss between the MIL classifier's detection scores and the OCUD's objectness scores.

#### 3.3. Addressing the Incomplete Label Problem

The progressive refinement approach effectively addresses the incomplete label problem in two ways:

1. **Unified Object Treatment**: By using a one-class universal detector, the method avoids category-specific biases in the source dataset.

2. **Iterative Discovery**: Through multiple refinement iterations, the method progressively identifies objects of target categories in the source dataset even if they were not originally annotated.

This approach allows the model to leverage knowledge from the source dataset while avoiding the pitfalls of incomplete labeling.

### 4. Main Findings and Results

The method was evaluated on the Pascal VOC 2007 and 2012 datasets, with MS COCO serving as the source dataset. The results demonstrate significant improvements over existing WSOD methods:

- On Pascal VOC 2007, the method achieved a mAP of 59.7% with multi-scale testing, surpassing previous state-of-the-art WSOD methods.
- By further retraining a fully supervised Faster R-CNN with the mined pseudo ground truths, the method achieved a mAP of 60.2%.

The results show that iterative refinement is crucial, with performance consistently improving over multiple iterations. The threshold τ for pseudo ground truth mining affects the trade-off between precision and recall, with higher thresholds favoring precision at the expense of recall.

The method was also tested in the ILSVRC transfer setting, achieving competitive results compared to existing state-of-the-art methods.

#### 4.1. Ablation Studies

Several ablation studies were conducted to validate the importance of different components in the framework:

1. **Source Dataset Importance**: Maintaining the source dataset during refinement is crucial. As shown in Figure 4(a), when only using the target dataset (VOC) for refinement, performance initially improves but then deteriorates in later iterations. In contrast, using both source and target datasets leads to consistent improvement.

2. **Source Dataset Quality**: The quality of annotations in the source dataset affects performance. Using COCO-60 (with complete annotations for 60 categories) outperforms COCO-60-full (with missing annotations), as shown in Figure 4(b).

3. **Amount of Target Data**: The method performs well even with limited target data. Figure 5 shows that with just 20% of the target dataset, the method achieves similar performance to using the full dataset after multiple refinement iterations.

#### 4.2. Qualitative Results and Visualization

Qualitative results show the progression of object detection quality across refinement iterations. Figure 6 and Figure 7 demonstrate how the detection quality improves significantly after multiple refinement iterations, with more accurate bounding boxes and better object classification.

The visualizations also highlight the method's ability to discover objects of target categories in the source dataset that were not originally annotated, demonstrating how the approach addresses the incomplete label problem.

Additional examples in Figure 8 show the diversity of objects and scenes the method can handle, with successful detections across various categories like animals, vehicles, furniture, and more.

### 5. Significance and Potential Impact

The progressive knowledge transfer framework represents a significant advancement in weakly supervised object detection. By leveraging existing fully-annotated datasets through an iterative refinement process, the method bridges the gap between weakly supervised and fully supervised object detection.

Key contributions of this work include:

1. A novel progressive knowledge transfer framework that iteratively refines both a one-class universal detector and a target-domain MIL classifier
2. An effective approach to address the incomplete label problem in transfer learning for WSOD
3. State-of-the-art performance on standard benchmarks, with consistent improvement across refinement iterations

The method is particularly valuable because it reduces the need for expensive bounding box annotations while achieving detection accuracy approaching that of fully supervised methods. This makes high-quality object detection more accessible for applications where annotation resources are limited.

Future directions might include extending the approach to more diverse datasets, exploring different architectures for the OCUD and MIL classifier, and applying the progressive knowledge transfer concept to other weakly supervised tasks beyond object detection.
