# RE-0: Verified Recursive Improvement of Embodied Code-as-Policy Agents through Local On-Policy Distillation

> [!summary] Summary
> RE-0 improves LLM Code-as-Policy robot agents using a stronger but imperfect teacher. On the student's own failed runs, the teacher writes small local code patches. Each patch is tested from the same saved simulation state against the student's original action and kept only if a confidence-bounded gain is positive. RE-OPD then distills the verified patches into a teacher-free student, lifting success from 4-68% to 62-100%.

## Problem

- Existing distillation copies the teacher's full behavior as the target, so it wrongly gives credit on states where the teacher itself fails.
- Prior code-policy repair, self-refinement and search methods regenerate whole programs or select by final outcome, and never test whether one specific teacher correction actually helped.
- Sparse end-of-episode rewards, as in GRPO, cannot find which harmful decision inside a long generated program caused the failure, so credit assignment breaks down.

## Method

- ==Diagnose-repair contracts==: a diagnostic agent finds the earliest harmful ==code boundary==, and the teacher emits one bounded ==code macro-action== within contracts of increasing scope, then hands control back to the student.
- ==Same-snapshot LCB gate==: the environment is restored to the saved boundary snapshot, teacher patch and student resample run under ==shared randomness==, and a patch is admitted only if the ==lower confidence bound== of its paired advantage is positive.
- **RE-OPD**: ==on-policy distillation== that combines a ==student-retention KL== term with a ==teacher-projection term== weighted by verified credit, run from a cold start (teacher's own runs) and then refined recursively, with a provable per-round improvement lower bound.

## Results

- On **six** robosuite tasks, RE-OPD-cold reaches **62-100%** with **3-67** verified rows, e.g. restack **8%** to **62%** with **3** rows and nut **4%** to **88%** with **27** rows.
- On lift, LCB admission averages **9.7/50** successes across three seeds versus **3.7** with no filter and **4.3** with sign-only selection; GRPO collapses to **0-1/50** on unsaturated tasks.
- Zero-shot deployment on a real dual-arm AgileX PiPER robot, with no teacher calls, scores **13/20** restack, **12/20** nut, **20/20** spill, **20/20** cubestack and **2/20** lift.

## Takeaways

> [!tip] Key Insights
> - Which data gets verified matters more than how it is weighted: uniform fine-tuning on the verified corpus matches credit-weighted training, while unverified corpora fail.
> - Counterfactual replay from the same saved state can measure whether a teacher holds real local credit, so a weak global teacher can still give useful supervision.
> - Room to improve and a teacher whose effect clears the noise floor must both hold; refining with thin verified credit dropped lift from 76% to 58%.

## Detailed Report

### 1. Overview

When a language model writes the program that controls a robot, one bad segment changes the robot's state and the history on which all later code depends. Advice from a stronger teacher can help, but the teacher is not necessarily reliable on every state the student reaches, so copying its whole behavior can give training credit to bad advice.

RE-0 treats advice as a local intervention instead. It finds a candidate failure boundary in the student's execution and compares a bounded teacher repair with the student's action from the same saved state. It trains on repairs only when the environment supports giving them positive credit.

On a held-out two-arm lift task, the RE-OPD-cold student gets 38 successes out of 50. The base student gets 2/50, and the same teacher used in a single-shot baseline without the diagnose–repair–verify loop gets 6/50. The cold result used 7 verified training rows.

### 2. Test a repair, then hand control back

The process starts with the student executing a program. A diagnostic agent identifies the earliest candidate harmful boundary and structured evidence, and the simulator saves its state. The boundary is a hypothesis to check. It does not prove that this is the only cause of failure.

A teacher then proposes a bounded code repair. Contracts restrict the repair's scope, the program symbols and APIs it may use, and its maximum segment length. RE-0 checks contracts from smaller to larger scope and uses the smallest verified scope.

From the same saved state, RE-0 runs the student baseline and the teacher patch with shared subsequent randomness. After the bounded segment, the same student resumes. The comparison is "paired" because the two continuations run under matched randomness from the same snapshot. A confidence gate admits the intervention only when the lower confidence bound (LCB) on paired advantage is positive. The experiments use threshold $\epsilon=0$.

The training step, RE-OPD, uses histories visited by this hybrid assistant. The student's behavior supplies a retention term. The contract-constrained teacher supplies the local target where the gate admits credit. The next student generates fresh histories, and the process repeats. Because the teacher is black-box, the experiments use a trajectory-level hard estimator.

### 3. Selection is what the evidence supports

The student is Qwen3.8-27B and the teacher is a black-box qwen3.8-max API. Each task's score is the number of successful task completions among 50 held-out seeds.

Main results: successes out of 50 for Base, Flash-API (the same teacher, single-shot, without the diagnose–repair–verify loop), RE-OPD-cold (with row count), and RE-OPD-refine. A "—" means the criterion abstained.

The decisive test is an ablation on lift that holds the collection journal and a common training recipe fixed. With uniform weights, the LCB-selected corpus reached 11/50, 5/50, and 13/50 across three trainer seeds (mean 9.7/50). Selecting all candidates reached 6/50, 2/50, and 3/50 (mean 3.7/50). Admitting any candidate with positive estimated advantage reached 5/50, 4/50, and 4/50 (mean 4.3/50).

Sign-only selection accepts estimated positive values even when they are statistically indistinguishable from zero. The authors report four such lift events that the LCB rejected.

This supports confidence-based selection over those two alternatives in this ablation. It does not establish that weighting is necessary. The authors report that uniform SFT on the same verified corpus is within trainer-seed variance of their weighted objective. Weighting did not measurably outperform uniform weighting there.

### 4. Where the result stops

The authors' results support verified corpus selection. They do not support the claim that advantage-based weighting itself is the decisive ingredient.

A verified local advantage also does not guarantee that distillation improves the standalone student. In lift, a refinement round with one admitted event and weight 0.069 fell from 38/50 to 29/50. The outer criterion halted rather than retaining that regression.

The paper's per-round guarantee is conditional. It assumes bounded returns, valid repair contracts, simultaneous statistical coverage from the verifier, and bounded projection error. Its analysis covers the augmented process after rewind, with snapshot and evidence state. It is not a guarantee for a snapshot-free online policy.
