# MetaFold: Language-Guided Multi-Category Garment Folding Framework via Trajectory Generation and Foundation Model

> [!summary] Summary
> MetaFold provides a framework for language-guided multi-category garment folding in robotics by disentangling high-level trajectory generation from low-level action prediction. The system achieved up to 94% success rates in real-world experiments and outperformed existing baselines in handling diverse garments and language-conditioned tasks.

## Problem

- Robotic manipulation of deformable objects like garments faces challenges due to their high-dimensional state space and complex dynamics.
- Existing garment folding methods often lack generalization across diverse garment categories and struggle to adapt to varied user instructions, frequently relying on structural representations or specific demonstrations.
- Current robotic systems struggle to effectively bridge abstract, high-level task planning (understanding the goal) with concrete, low-level action execution for complex deformable object tasks.

## Method

- **MetaFold** introduces a disentangled framework separating language-guided point cloud trajectory generation for high-level planning from low-level action prediction using a fine-tuned ManiFoundation model.
- A new large-scale dataset, MetaFold, was created using a differentiable simulator to generate point cloud trajectories and language descriptions for various garment folding tasks.
- The framework incorporates a closed-loop control system that continuously acquires the garment's current state and iteratively updates planning and action execution, enhancing robustness to environmental disturbances.

## Results

- MetaFold consistently outperformed baseline methods like UniGarmentManip and GPT-Fabric, achieving superior rectangularity, area ratio, and success rates (e.g., **0.88** success rate for No-sleeve garments on MetaFold dataset) across various garment categories.
- The framework demonstrated robust language understanding and generalization capabilities, achieving higher success rates (e.g., **0.63** for 'unseen' instructions vs. **0.46** for baseline) in language-guided folding tasks.
- Real-world experiments using an xArm6 robot showed strong practical applicability, with Rectangularity between **0.85**-**0.94** and Success Rates ranging from 8/10 to 10/10 across different garment types.

## Takeaways

> [!tip] Key Insights
> - Disentangling high-level task planning (trajectory generation) from low-level action prediction significantly enhances robustness and generalization in robotic manipulation of deformable objects.
> - Utilizing complete point cloud trajectories for planning, rather than sparse keypoint representations, provides a more comprehensive spatial and temporal understanding crucial for precise garment deformation.
> - Integrating a large language model (LLaMA) for semantic feature extraction enables effective interpretation of diverse user instructions and open-vocabulary generalization for complex folding tasks.
