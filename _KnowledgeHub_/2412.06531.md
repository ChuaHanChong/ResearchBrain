# Unraveling the Complexity of Memory in RL Agents: an Approach for Classification and Evaluation

> [!summary] Summary
> A structured framework for defining, classifying, and evaluating memory in Reinforcement Learning (RL) agents is introduced, formalizing short-term (STM), long-term (LTM), declarative, and procedural memory. An experimental methodology is proposed to precisely differentiate these memory types in partially observable environments, demonstrating its effectiveness in revealing architectural limitations.

## Problem

- Inconsistent definitions and usage of "memory" concepts in Reinforcement Learning (RL) literature.
- Lack of standardized, objective methodologies for evaluating and comparing memory capabilities in RL agents.
- Challenges in applying RL to Partially Observable Markov Decision Processes (POMDPs) that necessitate robust information recall.

## Method

- Formalizes ==memory types== (STM, LTM, declarative, procedural) for RL, adapting definitions from cognitive science with precise RL-centric parameters like Agent Context Length (K) and Correlation Horizon (ξ).
- Introduces a principled experimental methodology (Algorithm 1) to systematically configure tests, isolating and evaluating specific memory types based on the relationship between K and ξ.
- Defines "memory-intensive environments" as a crucial setting for valid memory evaluation, where at least one event-recall pair requires information from more than one past step.

## Results

- Revealed that agents showing high performance in "variable mode" tasks (mixed correlation horizons) could mislead, as they failed when forced to use LTM in "fixed mode" (ξ > K).
- Demonstrated that agent performance consistently drops when the task's correlation horizon (ξ) exceeds the agent's context length (K), indicating reliance on short-term recall.
- Showed that the Decision Transformer (fixed attention) excelled within its context but failed to generalize beyond ~**90** steps, whereas BC-LSTM (recurrent) generalized effectively to much longer sequences, indicating LTM.

## Takeaways

> [!tip] Key Insights
> - An agent's memory classification (STM vs. LTM) is relative, depending on the interplay between its internal context (K) and the task's required information recall horizon (ξ).
> - Naive memory testing can lead to misinterpretations by allowing agents to succeed via short-term dependencies, masking true long-term memory limitations.
> - Different RL architectures exhibit distinct memory profiles: fixed attention windows primarily support STM, while recurrent networks can achieve LTM and better generalization to unseen sequence lengths.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Reinforcement Learning (RL) has demonstrated effectiveness in addressing problems formulated as Markov Decision Processes (MDPs). However, applying RL to tasks characterized by partial observability, known as Partially Observable Markov Decision Processes (POMDPs), presents a significant challenge. These tasks often necessitate that agents efficiently process and recall information from their past interactions to make informed decisions.

Within the current RL literature, the concept of "memory" is inconsistently defined and applied. Various studies attribute memory to different agent capabilities or architectural features. Some researchers interpret memory as the capacity to manage dependencies within a fixed temporal context, such as a transformer's context window. Others extend this definition to encompass the utilization of information beyond the immediate context, implying a more persistent form of storage. In the domain of Meta-RL, memory is frequently understood as an agent's ability to adapt to new environments by leveraging prior experiences.

This lack of a unified definition is compounded by the absence of standardized methodologies for evaluating an agent's memory capabilities. Memory is often inferred from architectural components like recurrence or attention mechanisms, without explicit validation or isolation of the specific memory effects. Consequently, claims regarding memory capacity in RL agents can be vague or potentially misleading. For instance, an agent might appear to exhibit long-term memory due to specific task configurations that permit shortcuts or overlap with short-term contextual information, rather than demonstrating genuine long-range recall. This situation can lead to the conflation of different memory mechanisms, hinder the accurate diagnosis of architectural limitations, and impede objective comparisons between memory-enhanced agents.

This research aims to address these inconsistencies by providing a structured framework for defining, classifying, and evaluating memory in RL agents. It endeavors to bridge the gap between informal references to cognitive science memory concepts and precise, testable definitions within the RL context, thereby establishing a more rigorous foundation for future memory-enhanced RL research.

### 2. Key Objectives and Motivation

The primary objective of this research is to streamline and clarify the concept of memory within the domain of Reinforcement Learning agents. This overarching goal is broken down into several specific objectives and is motivated by the recognized ambiguities and inconsistencies in current RL memory research.

The key objectives are:
1. **Formalize Memory Definitions:** The paper aims to provide practical and precise definitions for various types of agent memory, specifically distinguishing between short-term (STM) and long-term (LTM), and declarative and procedural memory. These definitions are inspired by cognitive science but are adapted and formalized for rigorous application in RL settings. The motivation here is to resolve the prevalent terminological ambiguity and inconsistent usage of memory concepts across different RL studies.
2. **Categorize Agent Memory:** Based on the formalized definitions, the research seeks to categorize different classes of agent memory. This classification is designed to directly link memory types to the agent's internal mechanisms and the nature of the information being recalled. The motivation is to establish a structured framework that enables a clearer understanding of how various memory models function and to avoid incorrect assumptions about an agent’s memory capabilities.
3. **Propose a Robust Experimental Methodology:** A core objective is to introduce a principled experimental methodology for evaluating the memory capabilities of RL agents. This includes defining precise criteria for identifying the boundaries between different memory types, particularly for STM and LTM. The motivation is to standardize memory evaluation protocols, ensuring that assessments are objective, reproducible, and accurately reflect an agent’s actual memory performance.
4. **Standardize Evaluations:** By establishing a unified methodology, the paper seeks to standardize the evaluation process, thereby enabling fair and objective comparisons between diverse memory-enhanced RL agents. This standardization is motivated by the current difficulty in comparing agents due to disparate evaluation setups and informal interpretations of memory.
5. **Empirically Demonstrate Methodology Importance:** The research aims to empirically demonstrate the practical importance of adhering to the proposed experimental methodology. This involves conducting experiments with various RL agents and illustrating how deviations from the methodology can lead to erroneous conclusions regarding an agent's memory capabilities. The motivation is to underscore the necessity of rigorous experimental design to prevent misinterpretations and foster accurate scientific understanding.

In summary, the motivation stems from the critical role of memory in enabling RL agents to succeed in complex, partially observable environments that require processing historical information, adapting to novel situations, and improving sample efficiency. The current lack of a unified framework hinders scientific progress by obscuring true agent capabilities, impeding fair comparisons, and delaying the development of more advanced memory-capable agents. By providing clear definitions and a robust evaluation framework, this work aims to establish a common ground for research in memory-enhanced RL.

### 3. Methodology and Approach

The methodology of this paper focuses on formalizing memory concepts in RL, classifying memory types, and establishing a principled experimental framework for their evaluation.

#### 3.1. Formalization of Memory in RL

The work begins by adopting a high-level definition of memory from cognitive science: "memory – is the ability to retain information and recall it at a later time," and adapts it for RL agents. Key definitions include:
- **Agent Context Length (K):** Defined as the maximum number of previous steps (triplets of observation, action, reward) that an agent's base model can process at any given time `t`.
- **Memory Decision-Making (Memory DM):** A class of POMDPs where an agent's decision-making process at time `t` relies on its history `h_0:t-1` within a single environment and single episode. The objective is to find an optimal policy that maximizes cumulative reward.
- **Meta-RL:** A class of POMDPs where an agent learns to learn from past experiences across multiple tasks, memorizing common patterns to facilitate adaptation to new tasks.

Building upon these, the paper formalizes declarative and procedural memory in RL:
- **Declarative Memory:** Characterized by knowledge transfer within a single environment and across a single episode (`n_envs × n_eps = 1`). This is primarily evaluated in Memory DM tasks.
- **Procedural Memory:** Characterized by skill transfer across multiple environments or multiple episodes within a single environment (`n_envs × n_eps > 1`). This is primarily evaluated in Meta-RL settings.

Within the Memory DM framework, declarative memory is further divided into short-term (STM) and long-term (LTM):
- **Correlation Horizon (ξ):** Defined as the minimal time delay between the start of an event (`t_e`) and the decision-making point where information from that event is recalled (`t_r`), specifically `ξ = t_r - t_e - Δt + 1`.
- **Short-term memory (STM):** An agent's ability to use information about local correlations from the past *within* its context length `K` (`ξ ≤ K`).
- **Long-term memory (LTM):** An agent's ability to utilize information about global correlations from the past *outside* its context length `K` (`ξ > K`).

#### 3.2. Memory-Intensive Environments

To properly evaluate memory, the paper defines "memory-intensive environments" (`~M_P`). An environment is memory-intensive if `min_n ξ_n > 1`, meaning at least one event-recall pair requires information from more than one step in the past. If `max_n Ξ = 1`, the task is considered Markovian.

#### 3.3. Principled Experimental Methodology (Algorithm 1)

The core of the methodology is Algorithm 1, which provides steps for configuring experiments to test STM and LTM in Memory DM tasks:
1. **Estimate Event-Recall Pairs:** Confirm that the environment is memory-intensive (`n ≥ 1` event-recall pairs).
2. **Estimate Context Memory Border (`K_bar`):** Calculate `K_bar = min_n ξ_n - 1`. This threshold is crucial: if an agent's effective context `K` is less than or equal to `K_bar`, it is forced to rely on LTM mechanisms.
3. **Conduct Appropriate Experiment:**
 - **To test STM:** Set the agent's context length `K > K_bar`. In this configuration, some correlation horizons will fall within the agent's context window.
 - **To test LTM:** Set the agent's context length `K ≤ K_bar`. This ensures that all critical correlation horizons `ξ` are beyond the agent's direct context window. LTM requires "memory mechanisms" (`μ(K)`) that extend the agent's effective context (`K_eff = μ(K)`) beyond its base context `K`, such that `K ≤ K_bar < ξ ≤ K_eff`.
4. **Analyze Results:** Interpret agent performance based on these controlled `K` and `ξ` settings.

#### 3.4. Experimental Setup

The research validates its methodology using several memory-intensive tasks:
- **Passive T-Maze:** A classic task requiring recall of an initial cue after a variable delay.
- **Minigrid-Memory:** A grid-world task testing long-term memory and credit assignment with partial observability.
- **POPGym–Autoencode and RepeatPrevious:** Tasks from a benchmark designed for partially observable RL, requiring observation reconstruction or action repetition over time.

A range of RL agents, both online and offline, are evaluated:
- **Online RL:** Deep Transformer Q-Networks (DTQN), DQN-GPT-2, and SAC-GPT-2, representing attention-based memory architectures.
- **Offline RL:** Decision Transformer (DT) and BC-LSTM, comparing attention-based sequence modeling with recurrent neural networks.

Experiments vary agent context length `K` and task correlation horizon `ξ` (e.g., by adjusting corridor length in T-Maze) to control whether a task requires STM or LTM. Performance is measured by success rate or return. A key approach involves testing generalization across sequence lengths, training agents on specific episode lengths, and then evaluating them on both seen and longer, unseen lengths to differentiate between memorization within a fixed context and true LTM capabilities.

### 4. Main Findings and Results

The experiments conducted within the proposed framework demonstrated several key findings regarding the classification and evaluation of memory in RL agents.

#### 4.1. Pitfalls of Naive Memory Tests

The research highlights that evaluations neglecting the defined correlation horizons (`ξ`) can lead to misinterpretations of agent memory capabilities. Experiments with SAC-GPT-2 in the Minigrid-Memory environment illustrate this. When tested in a "variable mode" where correlation horizons varied, the agent showed high success rates for both short-term (K=22, `ξ` covering up to 22 steps) and long-term (K=14, `ξ` covering up to 22 steps) memory settings. This seemingly positive performance could lead to an erroneous conclusion about the agent's LTM capacity. However, when the task was configured in a "fixed mode" with a consistent `ξ` (specifically, `ξ = 22` requiring recall beyond the `K = 14` context), the agent's performance in the LTM setting significantly dropped. This empirically confirms that tasks with mixed correlation horizons can obscure an agent's true memory limitations by allowing it to rely on shorter-term dependencies, thereby misrepresenting its LTM capacity. The proposed methodology provides a systematic way to expose such limitations.

#### 4.2. The Relative Nature of an Agent’s Memory

The findings support the assertion that an agent's memory type (STM or LTM) is not an absolute characteristic but is relative to the interaction between its context length (`K`) and the environment's correlation horizon (`ξ`). Experiments using DTQN and DQN-GPT-2 in the Passive T-Maze, POPGym–Autoencode, and POPGym–RepeatPrevious tasks showed a consistent pattern: agent performance was high when `ξ ≤ K` (conditions conducive to STM) but sharply declined when `ξ > K` (conditions requiring LTM). This indicates that these attention-based agents primarily utilize information within their defined context window. To successfully address long-range dependencies, explicit memory mechanisms capable of processing information beyond this immediate context are required. This result emphasizes that memory claims for an agent must be considered in conjunction with the specific task parameters and agent context.

#### 4.3. Generalization Across Sequence Lengths

The study assessed the generalization capabilities of different architectural approaches, specifically comparing the Decision Transformer (DT) with BC-LSTM, in the Passive T-Maze environment. Agents were trained on varying corridor lengths and evaluated on both familiar and significantly longer, unseen sequence lengths.
- **Decision Transformer (DT):** DT exhibited strong performance when validation sequence lengths were within its training distribution or its effective context length. However, its performance significantly deteriorated when validated on sequences longer than approximately 90 steps, even if trained on much longer sequences (e.g., 300, 600, 900 steps). This indicates that DT, relying on a fixed attention window, primarily operates as an STM agent, excelling at recalling information within its context but failing to generalize to dependencies outside it. The results illustrate DT's architectural limitation in handling long-term dependencies that extend beyond its fixed receptive field.
- **BC-LSTM:** In contrast, BC-LSTM demonstrated a capacity for generalization to much longer sequences than it was trained on. For example, after training on an `L=30` length, it could achieve high success rates for validation lengths up to `L=900`. This behavior is indicative of true LTM, where the recurrent state allows the agent to maintain and retrieve information over extended temporal horizons. While BC-LSTM did eventually show performance drops for extremely long training lengths (e.g., `L=600`, `L=900`), likely due to issues such as vanishing gradients, its ability to extrapolate beyond its training context length within its effective learning regime distinguished it from the attention-based DT.

These findings confirm that the proposed framework effectively distinguishes between architectures primarily suited for STM (like transformers with fixed attention windows) and those capable of LTM (like recurrent networks with dynamic state updates). The experiments underscore the importance of testing beyond the training distribution to accurately assess an agent's memory capabilities and avoid attributing LTM to mere memorization within a limited context.

### 5. Significance and Potential Impact

This research contributes a unified framework for the classification and evaluation of memory in Reinforcement Learning (RL) agents, which holds several significant implications for the field.

**Clarification and Standardization of Terminology:** The paper addresses a prevalent issue in RL research: the ambiguous and inconsistent use of the term "memory." By providing formal definitions of short-term (STM) versus long-term (LTM) and declarative versus procedural memory, grounded in cognitive science but adapted for RL, it establishes a standardized vocabulary. This is critical for clear communication, reducing misunderstandings, and fostering a shared understanding of memory phenomena among researchers.

**Enhanced Evaluation Rigor and Objectivity:** The proposed experimental methodology, particularly the introduction of concepts like agent context length (`K`), correlation horizon (`ξ`), and the context memory border (`K_bar`), enables a more rigorous and objective evaluation of agent memory capabilities. This methodology provides a principled means to configure experiments that isolate specific memory types, preventing the conflation of different memory mechanisms. This is vital for accurately assessing an agent's true memory capacity and for avoiding misleading conclusions drawn from poorly designed experiments. The empirical demonstrations show that adhering to this methodology can reveal architectural limitations that might otherwise be masked by naive testing approaches.

**Guidance for Agent Design and Development:** By clarifying the distinctions between different memory types and how they are empirically identified, the framework offers valuable guidance for the design and development of memory-enhanced RL agents. Researchers can now more precisely understand whether a particular architectural choice (e.g., attention mechanisms versus recurrent neural networks) is better suited for STM or LTM tasks. This insight can lead to the creation of more targeted and effective memory architectures, optimizing agents for specific task requirements.

**Improved Comparability of RL Models:** The standardization of memory definitions and evaluation protocols facilitates fair and objective comparisons between different memory-enhanced RL agents and architectures. When all agents are evaluated under consistent and well-defined conditions, the field can make more meaningful progress in identifying superior memory mechanisms and understanding their underlying principles. This improved comparability can accelerate innovation and the development of more capable RL systems.

**Foundation for Future Research:** The framework lays a foundation for several future research directions. It suggests expanding the classification to include other cognitive science memory systems, such as working memory or episodic memory, and exploring how these might manifest in complex RL tasks. Furthermore, the paper highlights the importance of studying adaptive dynamic updating of memory representations, moving beyond static memorization and retention to how agents actively revise and integrate information over time. The explicit decoupling of Meta-RL into inner-loop POMDP and MDP tasks also offers new avenues for more granular analysis of memory requirements in meta-learning settings.
