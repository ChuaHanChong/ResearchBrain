# AgenticNav: Zero-Shot Vision-and-Language Navigation as a Tool-Calling Harness

> [!summary] Summary
> AgenticNav introduces a tool-calling harness for zero-shot Vision-and-Language Navigation in continuous environments, enabling large vision-language models to directly control actions, query precise depth, and manage memory efficiently. This approach achieves a 55% success rate and 48.41% SPL on the R2R-CE val unseen benchmark, outperforming prior methods and demonstrating robust real-world generalization.

## Problem

- Existing zero-shot VLN-CE methods rely on learned waypoint predictors, which limit the VLM's action space and prevent precise target selection.
- VLMs struggle to effectively utilize raw depth information for quantitative spatial reasoning, as it is not explicitly exposed in a usable format.
- Prior memory management strategies often overload the VLM's context window with irrelevant historical data, hindering long-horizon decision-making.

## Method

- **AgenticNav** reframes zero-shot VLN-CE as an agentic ==tool-calling== process, where a VLM interacts with the environment via specific tools for action, perception, and memory.
- It introduces an Action Tool for direct pixel-level target selection, bypassing waypoint predictors and enabling fine-grained continuous motion control with geometric safety checks.
- A Depth Tool allows on-demand, precise metric depth queries for specific pixels, while an Agentic Memory system with a Recall Tool provides a compact map and selective retrieval of past visual observations to avoid context overload.

## Results

- AgenticNav achieved new state-of-the-art zero-shot performance on the R2R-CE val unseen benchmark, with a **55%** Success Rate (SR) and **48.41%** Success Weighted by Path Length (SPL), a substantial improvement over prior baselines.
- In real-world robot experiments across challenging environments, AgenticNav more than doubled the success rate of the strongest reproducible baseline, reaching **46.7%** SR with four views, demonstrating strong generalization.
- Ablation studies confirmed the critical contribution of each tool: the Action Tool for direct targeting, the Depth Tool for structured metric queries, and Agentic Memory for efficient historical context.

## Takeaways

> [!tip] Key Insights
> - Designing a structured tool-calling harness for VLMs is crucial for effective grounding in embodied tasks, abstracting low-level complexities while enhancing VLM reasoning.
> - Providing direct, fine-grained action control and on-demand, structured metric perception enables VLMs to make more precise spatial decisions than relying on pre-computed waypoints or raw sensor data.
> - Efficient memory management through selective visual recall and compact map representations is essential for long-horizon navigation tasks, preventing VLM context saturation.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Vision-and-Language Navigation (VLN) is a field in robotics and artificial intelligence that requires an agent to follow natural language instructions within a visual environment. Initially, VLN research focused on discrete environments where agents navigated predefined graphs. The progression to Vision-and-Language Navigation in Continuous Environments (VLN-CE) removed this constraint, demanding agents to execute low-level movements in open, continuous 3D spaces. Early supervised methods for VLN-CE often employed spatial intermediates, such as learned waypoint predictors, to bridge high-level language understanding with executable motion.

The emergence of large language models (LLMs) and large vision-language models (VLMs) has facilitated the exploration of zero-shot navigation. This paradigm aims for agents to navigate unseen environments based solely on instructions and general VLM capabilities, without requiring extensive task-specific training data or policies. Recent zero-shot VLN-CE systems leverage VLMs as high-level decision-makers. However, existing approaches, including Open-Nav, SmartWay, and EvoNav, commonly rely on a learned waypoint predictor to generate a limited set of navigable actions for the VLM to choose from. This design, while simplifying continuous control for the VLM, introduces several limitations, such as a restricted action space, an inability for the VLM to directly access or effectively utilize raw depth information for spatial reasoning, and sub-optimal memory management. Memory in prior systems often involves accumulating extensive textual or visual histories, much of which can be irrelevant and overwhelm the VLM's context window, or retrieving cross-episode experiences, which deviates from a strict zero-shot setting.

This work contributes to the embodied AI and robotics landscape by proposing an alternative interface for zero-shot VLN-CE. It reframes the interaction between a VLM and its environment as an agentic tool-calling process, aligning with a broader trend in robotics where foundation models are grounded through harnesses that expose specific perception, memory, and action capabilities. This approach seeks to overcome the limitations of waypoint predictors and inefficient memory handling in zero-shot VLN-CE by providing the VLM with direct, precise, and on-demand control over action, depth perception, and memory recall.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a lightweight navigation harness, named AgenticNav, that enables strictly zero-shot Vision-and-Language Navigation in continuous environments (VLN-CE) by reframing the VLM-environment interface as an agentic tool-calling process. The motivation behind this approach stems from identified limitations in existing zero-shot VLN-CE methods.

Specifically, the key motivations and objectives are:

1. **Addressing the Limited Action Space of Waypoint Predictors:** Existing zero-shot VLN-CE methods frequently rely on learned waypoint predictors that propose a small, predefined set of navigable points. This design restricts the VLM's action space, preventing it from selecting instruction-relevant locations if they are not among the predicted candidates. A core objective of AgenticNav is to eliminate this dependency by allowing the VLM to directly select any visible target pixel in an RGB observation, thereby expanding the action space and enabling more precise and flexible navigation.

2. **Improving Effective Utilization of Depth Information:** Current methods often incorporate depth inputs into waypoint predictors but do not explicitly expose this metric information to the VLM in a usable format for detailed spatial reasoning. This makes it challenging for the VLM to make quantitative comparisons (e.g., comparing distances to multiple objects or assessing navigability of a corridor). A key objective is to provide an on-demand, precise pixel-depth tool that allows the VLM to query metric distances at specific image locations, facilitating targeted spatial reasoning without requiring the VLM to parse dense depth maps.

3. **Enhancing Memory Management and Reducing Context Overload:** Many prior methods handle memory by accumulating long textual or visual histories within the VLM's prompt context. This often includes substantial irrelevant information that can distract the model as the context grows, hindering long-horizon decision-making. Other approaches, such as retrieving cross-episode experiences, weaken the zero-shot assumption. AgenticNav aims to introduce a more efficient and selective memory mechanism. This involves providing a compact map image summarizing the historical trajectory and a recall tool that allows the VLM to selectively retrieve specific past visual observations only when they are deemed relevant, thus avoiding prompt context saturation.

By addressing these limitations through a tool-calling interface, the researchers aim to enable VLMs to more effectively leverage their visual reasoning capabilities for robust and efficient navigation in unseen continuous environments, ultimately improving success rates and path efficiency in zero-shot settings.

### 3. Methodology and Approach

AgenticNav reimagines zero-shot VLN-CE as an agentic interface where a VLM interacts with the environment through a set of callable tools. The VLM acts as the high-level decision-maker, while the harness provides grounded capabilities for action, perception, and memory.

**Overall Framework:**
At each decision step, the AgenticNav harness provides the VLM with multi-view RGB observations, a compact map image summarizing the historical trajectory, and the current dialogue/tool history. Crucially, dense depth maps are not directly provided to the VLM; instead, depth information is accessed through a dedicated tool. The VLM core can then issue calls to one of four exposed tools: `query_depth`, `recall`, `move_to`, or `stop`. Multiple tool calls can be made within a single decision step; `query_depth` and `recall` return evidence for subsequent VLM turns, while `move_to` and `stop` are terminal actions for the current step.

**The Four Tools:**

1. **Depth Tool (`query_depth(P)`):**
 - **Purpose:** To provide the VLM with precise metric depth information at specific points of interest.
 - **Mechanism:** The VLM can specify a batch of candidate pixels `P = {p_i = (k_i, u_i, v_i)}`, where `k_i` is the index of a panoramic RGB view and `(u_i, v_i)` are normalized image coordinates.
 - **Output:** For each queried pixel, the tool returns a tuple `(d_i, s_5x5_i, θ_i, ρ_i)`.
 - `d_i`: The metric depth (distance in meters) at the selected pixel.
 - `s_5x5_i`: Local depth statistics (minimum, mean, median depth) from a 5x5 neighborhood around the pixel, aiding in judging surface stability or proximity to depth boundaries.
 - `(θ_i, ρ_i)`: An "action preview" indicating the relative yaw angle and executable forward distance if this pixel were subsequently chosen by the `move_to` tool.
 - **Rationale:** This on-demand query mechanism allows the VLM to acquire quantitative spatial evidence for specific locations without needing to interpret complex dense depth images directly, enabling targeted comparisons and spatial reasoning.

2. **Agentic Memory and Recall Tool (`recall(p, k)`):**
 - **Purpose:** To manage navigation history compactly and selectively retrieve past visual observations.
 - **Mechanism:** Agentic Memory `M_t` consists of two components:
 - `B_t`: A compact Map Image that visually summarizes the agent's historical trajectory. This map image is consistently included in the VLM's prompt.
 - `C_t`: A bounded cache of past observed images. These images are not automatically appended to the prompt.
 - The VLM can explicitly call `recall(p, k)` to retrieve a specific RGB observation from a past decision point `p` and view `k` from `C_t`. The recalled image is then appended to the current prompt.
 - **Rationale:** This design ensures that context grows only with information deemed task-relevant by the VLM, preventing prompt overload with redundant historical frames and supporting effective long-horizon decision-making.

3. **Action Tool (`move_to(k, u, v)`):**
 - **Purpose:** To enable the VLM to directly select a target pixel in an RGB image for continuous motion, bypassing waypoint predictors.
 - **Mechanism:** The VLM specifies a target pixel by its view index `k` and normalized coordinates `(u, v)`.
 - **Execution Process:**
 - **3D Back-projection:** The selected pixel, its corresponding depth value `d = D_k_t(x, y)` from the aligned depth map, and camera intrinsics `K` are used to back-project the target into a 3D point `p_t` in the agent's frame.
 - **Action Calculation:** The tool computes a ground-plane bearing `θ` and an executable forward distance `ρ` towards `p_t`, incorporating stopping margins, maximum-step clipping, and step-size discretization.
 - **Safety Check:** Before execution, the proposed motion undergoes a geometric safety check. This involves:
 - Rejecting out-of-range targets, invalid depth values, or motions shorter than one executable step.
 - Identifying potential body-height obstacles by back-projecting all valid depth pixels and filtering for points within a specified height range.
 - Ensuring no identified obstacle falls within the robot's swept corridor for the proposed `(θ, ρ)`.
 - **Output:** If safe, the tool returns `Execute(θ, ρ)`; otherwise, it returns `Reselect`, prompting the VLM for a new action.
 - **Rationale:** This design provides the VLM with fine-grained control over its movement, allowing it to target any visible point directly. It offloads complex geometric transformations and safety computations to deterministic tools, abstracting these low-level details from the VLM's reasoning process.

4. **Stop Tool (`stop`):**
 - **Purpose:** To terminate the navigation episode when the instruction is considered fulfilled.

This tool-calling interface, with its structured approach to perception, memory, and action, allows the VLM to focus on high-level reasoning and instruction following, while robust, deterministic tools handle the complexities of grounded interaction with the continuous 3D environment.

### 4. Main Findings and Results

The evaluation of AgenticNav was conducted through simulation experiments on the R2R-CE benchmark, real-world robotic deployments, and comprehensive ablation studies to assess the contribution of individual tool components and VLM backbones.

#### 4.1. Simulation Experiments (R2R-CE val unseen benchmark)

- **State-of-the-Art Performance:** AgenticNav, using the GPT-5.5 VLM core, achieved new state-of-the-art (SOTA) zero-shot performance among comparable methods on the 100 R2R-CE val unseen episodes. It recorded a Success Rate (SR) of 55% and Success Weighted by Path Length (SPL) of 48.41%.
- **Comparison to Baselines:** These results represent a substantial improvement over a same-backbone reproduction of SmartWay-GPT-5.5, which achieved 44% SR and 35.04% SPL. This indicates an 11 percentage point increase in SR and a 13.37 percentage point increase in SPL for AgenticNav.
- **VLM Backbone Generalization:** When using Gemini-2.5-Pro as the VLM core, AgenticNav also surpassed Gemini-based Open-Nav and EvoNav comparisons under a strict episodic zero-shot setting (EvoNav uses cross-episode experience, which is not considered strictly zero-shot in this context). This suggests that the performance improvement is attributable to the tool-calling harness design, rather than being exclusive to a single VLM. The gains in SPL suggest not only higher goal achievement but also increased efficiency in navigating to the goal.

#### 4.2. Real-world Experiments

- **Deployment and Setup:** AgenticNav was deployed on an omnidirectional four-wheel robot equipped with an Intel RealSense D435 RGB-D camera and FAST-LIO localization. The robot collected multi-view observations by rotating in place.
- **Challenging Scenarios:** The evaluation comprised 30 real-world episodes across laboratory, office, and outdoor yard scenes. These scenarios were designed to be more complex than simulation, involving aspects like sign reading, long-range navigation, ambiguous directions, and precise target arrival.
- **Performance vs. SmartWay:** AgenticNav-GPT-5.5 demonstrated superior performance compared to SmartWay-GPT-5.5 (the strongest reproducible prior baseline).
 - With a single view, AgenticNav achieved 33.3% SR and 3.20m Navigation Error (NE), outperforming SmartWay (23.3% SR, 3.57m NE).
 - With four views, AgenticNav reached 46.7% SR and 2.67m NE, effectively doubling SmartWay's success rate. The largest performance gains were observed in the outdoor yard, where the ability to make wide turns and target distant goals was critical.
- **Generalization Advantage:** The real-world results highlight the zero-shot generalization capability of AgenticNav. The pixel-level action selection through the Action Tool allowed the VLM to directly target goal-aligned locations, effectively bypassing limitations where SmartWay's learned waypoint predictor might miss instruction-relevant directions or struggle with precise target selection, indicating a generalization limitation of trained waypoint modules.
- **Qualitative Demonstrations:** Real-world examples illustrated the practical utility of the tools:
 - The Depth Tool provided precise spatial evidence for correct turn timing by allowing queries around signs, walls, and the floor.
 - The Recall Tool converted an initially observed sign into a persistent route constraint, supporting long-horizon navigation after the sign left the current view.
 - The Action Tool enabled the VLM to directly select a goal-aligned target, overcoming scenarios where a waypoint predictor might fail to propose the desired direction.

#### 4.3. Ablation Studies

- **Tool Components (AgenticNav-GPT-5.5 on R2R-CE):**
 - **Action Tool:** Replacing the Action Tool with SmartWay's waypoint predictor reduced SR by 5 percentage points and SPL by 4.42 points, affirming the benefit of direct pixel-level target selection.
 - **Depth Tool:** Removing the Depth Tool led to a significant drop in SR to 42%. While adding raw depth images as input recovered some performance (SR 53%), it did not fully compensate, indicating that structured metric queries are more effectively utilized by the VLM than parsing dense depth maps.
 - **Agentic Memory:** Removing both the map image and the Recall Tool reduced SR to 41%. Using only the map image (without the Recall Tool) improved SR to 51%, demonstrating that selective visual recall adds value beyond a general visual map, particularly for instructions dependent on previously seen landmarks.
- **VLM Cores (Same AgenticNav Harness on R2R-CE):**
 - GPT-5.5 demonstrated the strongest performance, followed by Gemini-3-Flash and Gemini-2.5-Pro. Even smaller models like Qwen3.6-27B achieved a respectable 35% SR with a high OSR. This pattern indicates that while VLM reasoning quality influences final stopping and path efficiency, the AgenticNav tool structure provides a consistent benefit, enabling various VLM backbones to effectively discover goal-relevant regions, query metric evidence, and use memory.

### 5. Significance and Potential Impact

AgenticNav presents a significant contribution to the field of zero-shot Vision-and-Language Navigation in continuous environments (VLN-CE) by proposing a paradigm shift in how large vision-language models (VLMs) interact with their embodied environments.

1. **Redefinition of VLM-Environment Interface:** The research reframes zero-shot VLN-CE as an agentic tool-calling process, moving away from reliance on learned waypoint predictors. This approach posits that the interaction harness—how a VLM perceives, acts, and remembers—is as critical as the VLM itself for effective navigation.
2. **Enhanced Zero-Shot Performance and Generalization:** AgenticNav achieves new state-of-the-art zero-shot performance on the R2R-CE benchmark, demonstrating improvements in both success rate and navigation efficiency. The robust real-world validation further highlights its strong generalization capabilities compared to prior methods that struggled with sim-to-real transfer due to learned modules. This indicates a more broadly applicable and reliable navigation system for novel environments.
3. **Improved VLM Grounding and Reasoning:** The tool-calling interface allows VLMs to leverage their reasoning capabilities more effectively by providing:
 - **Direct, Fine-grained Action Control:** The pixel-level action tool offers unrestricted selection of navigation targets, enabling precise and flexible movements that bypass the limitations of predefined waypoints.
 - **Targeted Perception:** The on-demand pixel-depth tool provides precise metric spatial evidence only where needed, facilitating quantitative spatial reasoning without overwhelming the VLM with raw sensor data.
 - **Efficient Memory Management:** The agentic memory with selective recall avoids context overload, ensuring that only task-relevant historical visual information is presented to the VLM, crucial for long-horizon tasks.
4. **Reduced Dependency on Task-Specific Training:** By operating in a strictly zero-shot, episodic manner and removing the need for trained waypoint predictors, AgenticNav simplifies the deployment pipeline and reduces the need for extensive, domain-specific training data or cross-episode experience. This fosters greater adaptability to novel scenes and instructions.
5. **Blueprint for Embodied AI Systems:** The work demonstrates a successful blueprint for integrating foundation models into embodied systems through a structured tool-calling harness. This approach offers a robust way to ground high-level VLM reasoning into low-level robot capabilities, offloading complex geometric computations and safety checks to deterministic tools.
6. **Future Research Directions:** The findings open avenues for future research, particularly in distilling the agentic tool-use capabilities into smaller, more efficient models. This could enable faster inference and more stable local deployment, addressing current limitations related to VLM decision latency and network instability in real-time applications.

In summary, AgenticNav represents a methodological advancement in zero-shot VLN-CE, emphasizing the critical role of a well-designed VLM-environment interface in unlocking the full potential of foundation models for robust and generalizable embodied navigation.
