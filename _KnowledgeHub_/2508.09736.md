# Seeing, Listening, Remembering, and Reasoning: A Multimodal Agent with Long-Term Memory

> [!summary] Summary
> M3-Agent, developed by ByteDance Seed, introduces a multimodal AI agent framework that processes continuous video and audio streams, constructs an entity-centric long-term memory, and performs multi-turn reasoning. The system achieves 30.7% accuracy on the M3-Bench-robot dataset and 48.9% on M3-Bench-web, demonstrating enhanced person understanding and cross-modal reasoning capabilities.

## Problem

- Existing multimodal agents struggle to process infinitely long input streams and are limited by finite context windows or ineffective feature compression.
- Current AI memory systems often fail to form consistent, entity-centric world knowledge from diverse multimodal content, leading to ambiguity in long-term understanding.
- Standard Long Video Question Answering (LVQA) benchmarks primarily assess low-level visual tasks, lacking the evaluation of higher-level cognitive abilities essential for truly intelligent agents.

## Method

- M3-Agent employs an ==entity-centric multimodal graph== as long-term memory, continuously generating episodic and semantic memories from incoming video and audio streams.
- It integrates external tools for facial and speaker recognition to assign and maintain ==consistent character identities== across different modalities and clips.
- A reinforcement learning (DAPO) based ==control workflow== enables multi-turn reasoning, allowing the agent to iteratively query its comprehensive memory to answer complex, instruction-based questions.

## Results

- M3-Agent achieved an overall accuracy of **30.7%** on the M3-Bench-robot dataset, surpassing the strongest baseline, MA-LMM, by **6.3%**.
- On M3-Bench-web, it obtained **48.9%** accuracy, outperforming the Gemini-GPT4o-Hybrid baseline by **7.7%**, with notable improvements of **15.5%** in Person Understanding and **6.7%** in Cross-modal Reasoning.
- Ablation studies demonstrated that removing character identity equivalence or semantic memory resulted in substantial accuracy drops (e.g., up to **19.2%** on M3-Bench-web), affirming their critical roles.

## Takeaways

> [!tip] Key Insights
> - Explicitly managing character identity equivalence and integrating multimodal features into memory is crucial for maintaining long-term consistency and improving agent understanding.
> - The construction of detailed semantic memory, including character attributes, relationships, and general world knowledge, is essential for enabling higher-level cognitive reasoning in agents.
> - Reinforcement learning, specifically DAPO, is effective in training agents to perform flexible, multi-turn reasoning and strategic memory retrieval in complex, dynamic environments.
