# Look Before You Leap: Using Serialized State Machine for Language Conditioned Robotic Manipulation

> [!summary] Summary
> Researchers at Johns Hopkins University and the University of Arkansas developed a state-aware imitation learning framework that uses Large Language Models (LLMs) to generate and filter Finite State Machines (FSMs) for robust robotic demonstration collection. This method achieved up to 98.0% success rates on complex long-horizon tasks like Towers of Hanoi, significantly outperforming control methods that struggled to generalize with random environment initializations.

## Problem

- Current LLM-based imitation learning for robotics struggles with long-horizon tasks requiring precise, state-dependent reasoning due to policies failing to generalize to dynamically evolving states.
- Training data generated from randomly initialized object placements often leads to cascading errors as policies encounter unseen or structurally inconsistent environmental states.
- Existing methods lack a systematic approach to ensure comprehensive coverage of all possible, structurally consistent intermediate states during demonstration collection.

## Method

- Introduced a 'state-aware' imitation learning framework that systematically integrates LLM-generated and filtered ==Finite State Machines (FSMs)== with environment-conditioned robot policy training.
- Developed a State Machine Serialization Language (SMSL), a textual FSM representation generated by LLMs through a multi-step process of identifying states, operations, and valid transitions via filtering.
- Modified task demonstration code to enable environment passing between executions and deterministic object referencing, ensuring state consistency while allowing initial state randomization under constraints.

## Results

- Achieved significantly higher success rates on complex long-horizon tasks, with the proposed method reaching **98.0%** for Towers of Hanoi and Chess, and **96.2%** for River Crossing at 1000 demonstrations.
- The control method (simulating GenSim with random object placements) consistently underperformed, achieving only **58.0%** for Towers of Hanoi, **5.5%** for River Crossing, and **44.3%** for Chess at 1000 demonstrations.
- Demonstrated robust FSM navigation across the entire state space, validating the approach for tasks where intermediate states are as critical as final goal states, unlike control methods that suffered catastrophic failures in state-dependent puzzles.

## Takeaways

> [!tip] Key Insights
> - Leveraging LLMs to *indirectly* generate and filter formal FSM definitions ensures logical consistency and correctness in task planning, overcoming challenges of direct, unstructured LLM plan generation.
> - Systematic, state-aware demonstration collection, covering all valid FSM transitions, is crucial for training robust policies for long-horizon tasks that involve dynamically evolving environments.
> - Decoupling low-level object instantiation from high-level task logic, while preserving diversity through constrained initial state randomization, significantly improves generalization in complex manipulation scenarios.
