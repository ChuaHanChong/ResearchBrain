# HoloAgent-0: A Unified Embodied Agent Framework with 3D Spatial Memory

> [!summary] Summary
> HoloAgent-0, a unified embodied agent framework developed by Horizon Robotics and D-Robotics Robotics, bridges the divide between large language model reasoning and real-world physical robot execution. It integrates persistent 3D spatial memory and a structured skill interface to facilitate robust, closed-loop task execution, demonstrating high success rates in real-robot navigation and competitive performance in semantic mapping.

## Problem

- Transferring LLM agent paradigms from digital environments to physical robots is challenging due to the 'embodiment gap,' characterized by continuous, uncertain, and safety-critical execution.
- Existing embodied AI systems often feature specialized, isolated modules for robot capabilities like manipulation or navigation, lacking a comprehensive framework for unified orchestration.
- Achieving robust, long-horizon tasks on real robots is difficult without persistent memory grounding, continuous progress tracking, and effective recovery from physical failures.

## Method

- **HoloAgent-0** introduces a unified framework comprising an Embodied AgentOS, a ==3D Spatial Memory Layer==, and an Embodied Skill Layer, interacting via a ROS2 command/status bus for closed-loop operation.
- It employs a 'memory-centric' and 'closed-loop first' design, using persistent spatial and temporal memory to ground planning, continuously monitoring execution, and enabling feedback-driven re-planning.
- Robot capabilities are exposed as 'typed embodied skills' with structured command schemas and detailed runtime status interfaces, making them composable, observable, and verifiable.

## Results

- HoloAgent-Nav achieved a **97.70%** success rate for Top-1 candidate selection in real-robot long-horizon navigation across physical apartments.
- HoloAgent-Memory demonstrated competitive performance in open-vocabulary 3D semantic mapping, achieving **31.58%** mIoU on the ScanNet dataset and **29.93%** mIoU on the Replica dataset.
- Qualitative demonstrations showcased robust closed-loop execution of complex tasks, including active object search, long-horizon mobile manipulation (e.g., laundry folding), and cross-robot coordination on real humanoid and mobile manipulator platforms.

## Takeaways

> [!tip] Key Insights
> - Grounding high-level agent planning in persistent 3D spatial and temporal memory is critical for enabling robots to reason beyond immediate observations and perform long-horizon tasks robustly.
> - A standardized, monitorable 'typed skill interface' allows for seamless orchestration of heterogeneous robot capabilities (e.g., navigation, manipulation) by a higher-level agent OS.
> - A closed-loop execution design with continuous monitoring, verification, and feedback-driven re-planning is essential for reliably handling the inherent uncertainty and potential failures in real-world physical environments.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of artificial intelligence has seen advancements in Large Language Model (LLM) agents operating within digital environments. These agents typically follow an execution loop involving reasoning over structured states, invoking software tools, inspecting feedback, and revising actions. However, extending this paradigm to physical robots presents substantial challenges, characterized by what the authors term the "embodiment gap." Physical execution is inherently continuous, embodiment-dependent, subject to uncertainty, and constrained by safety requirements, differing significantly from the deterministic, reversible nature of software API calls.

Existing embodied AI systems have developed specialized modules for capabilities such as manipulation, spatial understanding, navigation, and humanoid motion control. Examples include vision-language-action (VLA) models, spatial understanding techniques, and advanced motion controllers. While these modules contribute to individual robotic functionalities, they often remain isolated or are loosely coupled within larger decision loops. Consequently, a comprehensive framework that unifies these heterogeneous capabilities, grounds execution in persistent 3D memory, tracks partial progress, and facilitates recovery from embodied failures has remained a challenge.

HoloAgent-0 addresses this gap by proposing a unified framework designed for real-world robot deployment. It positions itself not as a replacement for low-level policy models but as an organizing layer that integrates these diverse robot capabilities into a closed-loop workflow. The work builds upon existing research in LLM agents, instruction-conditioned robot policies, and 3D spatial memory, but emphasizes a system-level solution that prioritizes robust physical execution, persistent memory grounding, and feedback-driven adaptation. This approach contrasts with systems that treat robot capabilities as discrete, unmonitored tools or rely solely on immediate sensory input without maintaining a persistent understanding of the environment and task history.

### 2. Key Objectives and Motivation

The primary objective of this work is to develop HoloAgent-0, a unified embodied agent framework capable of deploying LLM-agent-like reasoning loops to real-world physical robots. The motivation stems from the inherent difficulties in transferring digital agent paradigms to physical systems, specifically the "embodiment gap."

The core motivations and objectives are detailed as follows:

- **Addressing the "Embodiment Gap":** The central challenge is that physical robot execution differs fundamentally from digital tool invocation. Physical actions are continuous, dependent on specific robot kinematics and dynamics, inherently uncertain (e.g., objects moving, stale memory), and must adhere to safety protocols. This necessitates a system-level execution abstraction that makes physical skills composable, observable, and verifiable for long-horizon tasks. HoloAgent-0 aims to provide this abstraction.

- **Unifying Heterogeneous Robot Capabilities:** Current embodied AI often features specialized modules for different robot functionalities (e.g., navigation, manipulation, motion control, perception). These modules typically operate in isolation or are loosely coordinated. HoloAgent-0 seeks to integrate these disparate capabilities within a single, coherent framework, enabling seamless orchestration of complex tasks that require multiple robot skills.

- **Enabling Closed-Loop Execution for Real-World Deployment:** The framework is designed for practical deployment on real hardware. It aims to convert natural-language instructions into executable skill graphs, schedule robot resources effectively, continuously monitor execution progress and outcomes, and trigger clarification or re-planning based on runtime feedback. This closed-loop approach is crucial for robustness in uncertain physical environments.

- **Grounding Planning in Persistent 3D Memory:** Digital agents often operate on explicit, structured states. For physical robots, this translates to understanding and remembering the 3D physical world. HoloAgent-0 aims to incorporate persistent spatial and temporal memory layers to provide continuous grounding for planning, enabling the agent to reason beyond immediate sensor observations and recall past states or plan history. This facilitates long-horizon tasks where the robot might need to revisit locations or remember object states.

- **Providing a Robust Physical Execution Interface:** The work seeks to define a standardized interface for robot capabilities, treating them as "typed embodied skills." This interface should include structured inputs, progress signals, failure modes, and recoverability status, allowing a higher-level AgentOS to compose and monitor these skills effectively, regardless of their internal implementation (e.g., learned policies, classical controllers).

- **Facilitating Real-World Evaluation and Debugging:** A practical objective is to enable systematic evaluation and debugging of embodied agents on real hardware. The framework is designed to be observable by default, logging command/status events, memory states, and skill outcomes. This supports diagnosis of failures across perception, memory, planning, and control, which is essential for developing reliable robot systems.

In summary, HoloAgent-0 is motivated by the need for a unified, robust, and deployable framework that bridges the gap between language-based reasoning in digital environments and continuous, uncertain execution in the physical world, leveraging persistent memory and a structured skill interface for closed-loop control.

### 3. Methodology and Approach

HoloAgent-0 is structured as a unified embodied agent framework comprising three coupled layers: the Embodied AgentOS, the 3D Spatial Memory Layer, and the Embodied Skill Layer. These layers interact via a ROS2 command/status bus, forming a closed-loop system for task execution, monitoring, and adaptation.

#### 3.1. Design Principles

The framework adheres to four design principles:
- **Closed-loop first:** Planning is treated as a continuous observe-retrieve-act-monitor cycle, allowing for plan revision based on runtime feedback.
- **Memory-centric:** Persistent spatial and temporal memory serve as the primary context for planning, beyond immediate sensory data.
- **Typed skill interface:** Robot capabilities are exposed as typed, monitorable skill calls with structured parameters, progress signals, and failure modes.
- **Observable by default:** The system records and surfaces execution events, memory states, and outcomes for verification and debugging.

#### 3.2. Runtime Layers and ROS2 Execution Interface

The system's functionality is distributed across four conceptual layers connected by a ROS2 command/status bus:

- **Embodied AgentOS Layer:** This is the core runtime that translates natural language instructions into executable skill graphs. It parses user requests, retrieves context from memory, decomposes instructions into skill nodes (with preconditions and recovery dependencies), schedules skill calls, processes status feedback, and triggers re-planning or clarification if execution deviates from the plan.
- **Skill Layer:** This layer represents the robot's physical capabilities as callable skills. Each skill defines command parameters and publishes status events (progress, success/failure mode, confidence, latency, recoverability). This modular interface allows AgentOS to compose diverse backends without requiring internal architectural knowledge.
- **Memory Layer:** This layer maintains persistent spatial and temporal memory. Spatial memory stores geometric, topological, and occupancy information, robot pose, 3D semantic maps, and a Hierarchical Multimodal Scene Graph (HMSG). Temporal memory records goal/plan state, execution traces, and outcome summaries.
- **Monitoring & Verification Layer:** This layer processes raw execution evidence, verifying skill outcomes, providing user feedback (text/voice), and signaling AgentOS for re-planning. It also records comprehensive logs (ROS2 bags, structured logs, RViz, Rerun) for development and debugging.

#### 3.3. Skill Layer: Embodied Skills as the Executable Action Interface

The Skill Layer grounds AgentOS plans on robot hardware. It abstracts robot capabilities into typed, monitorable skill calls:
- **Command Schema:** Each skill declares a name, typed parameters, preconditions, target references, and expected effects (e.g., `move_to(room=kitchen)`, `pick(object=mug)`).
- **Runtime Status Interface:** Backends publish detailed execution traces including progress, success/failure, confidence, and recoverability.
- **Embodiment-specific Backend:** Learned policies, classical controllers, or hybrid systems implement these skills for specific robot platforms.

Key skill families include:
- **Interaction and Perception Skills:**
 - **Interaction:** Wraps ASR, dialogue state, and TTS (e.g., `listen`, `speak`), returning transcription confidence, clarification requests, and completion status.
 - **Perception:** Provides open-vocabulary capabilities (e.g., `detect`, `localize`, `verify`), supplying detected instances, confidence scores, and view evidence.
- **Spatial Navigation and Exploration: HoloNavi:**
 - Handles `move_to` and `find` skill calls.
 - **Hierarchical Object Navigation:** Parses language requests into spatial and semantic queries, performing fast matching over HMSG using hierarchical CLIP-feature matching.
 - **Online Verification Loop:** Uses a Vision-Language Model (VLM) for visual verification of candidate goal views, refining the target or triggering re-planning if verification fails.
 - **Active Spatial Exploration:** Initiates exploration when the target cannot be localized from existing memory, scoring viewpoints by information gain, semantic relevance, traversability, and safety.
- **Manipulation: HoloBrain:**
 - Implements manipulation calls like `pick`, `place`, `open`, `fold`.
 - Combines task intent, visual observations, robot priors, and memory-grounded object information for end-to-end policy inference.
 - Reports detailed status including object not found, grasp failure, collision risk, and low policy confidence for recovery.
- **Whole-Body Motion: HoloMotion:**
 - Provides humanoid motion capabilities: reference tracking, velocity control, posture adjustment, recovery.
 - Supports motion-tracking (e.g., dancing) and velocity-tracking (e.g., walking) modes.
 - Reports progress, balance state, contact risk, and recovery availability.
- **Cross-Embodiment Coordination:** Achieved by enabling heterogeneous robots to share memory records, typed skill calls, and status events. AgentOS assigns tasks based on robot capability, location, and availability, coordinating concurrent execution and enabling responsibility transfer.

#### 3.4. Memory Layer: Spatial and Temporal Memory for Embodied Agents

The Memory Layer provides persistent understanding of the physical world and task history.
- **Spatial Memory:** Converts sensor streams into a 3D world representation.
 - **Geometry Memory:** Maintains coordinate frames, robot pose, dense geometry, and traversability.
 - **LiDAR-based backend:** Fuses LiDAR, IMU, and camera data (e.g., FAST-LIVO).
 - **Vision-only backend:** Builds geometry from synchronized RGB streams using GeoFlow-SLAM++, predicting dense depth with a 3D foundation model and optimizing multi-view constraints.
 - **Semantic Memory:** Lifts open-vocabulary 2D features onto 3D points, voxels, and instances. Uses SAM2 for masks and fused SigLIP descriptors for open-vocabulary retrieval. Employs instance association to maintain persistent object identities.
 - **Hierarchical Multimodal Scene Graph (HMSG):** Organizes memory into floor, room, view, and object layers with hierarchical and topological edges. This structure enables coarse-to-fine retrieval, VLM-based verification, and memory updates.
- **Temporal Memory:**
 - **Goal and plan state:** Stores parsed user intent, active skill graph, pending sub-goals, and assigned embodiments.
 - **Execution and recovery trace:** Records command parameters, retrieved context, status events, verification results, and recovery decisions.
 - **Outcome and experience summary:** Stores compact summaries of task segments for later planning and debugging.
- **Memory Update:** Triggered by new sensor observations, skill outcomes, or user feedback. It relocalizes the robot, refreshes geometry and semantic instances, and updates only the affected HMSG subgraph.

### 4. Main Findings and Results

The evaluation of HoloAgent-0 encompasses both quantitative measurements of its components and qualitative demonstrations of its integrated closed-loop execution on real robots.

#### 4.1. Experimental Setup

- **Platforms:** Experiments were conducted on Unitree G1 humanoid, R1 humanoid, and a wheeled dual-arm mobile manipulator.
- **Environments:** Real physical apartments with matched digital twins were used for real-robot evaluations, alongside simulated scenes.
- **Metrics:** For semantic mapping: mIoU, mAcc, frequency-weighted mIoU, frequency-weighted accuracy. For navigation: Success Rate (SR), Success weighted by Path Length (SPL), and real-robot goal-reaching success under Top-1 and Top-5 candidate selection with various distance thresholds.

#### 4.2. Long-Horizon Navigation: Agent-Loop Evaluation

- **Simulation Evaluation (HM3D-ObjNav benchmark):** HoloAgent-Nav demonstrated improved performance over existing state-of-the-art navigation systems.
 - It achieved a **Success Rate (SR) of 82.6%** and **Success weighted by Path Length (SPL) of 42.8%**.
 - This compares to FSR-VLN (slow-reasoning) at 80.8% SR and 41.0% SPL, and MSGNav at 74.1% SR and 33.4% SPL.
 - These results indicate that the AgentOS loop, integrating memory retrieval, candidate verification, and execution monitoring, contributes to both goal-reaching success and path efficiency in simulated zero-shot object navigation.

- **Real-Robot Evaluation:** HoloAgent-Nav achieved a high success rate in reaching language-specified goals in physical apartments.
 - It obtained **97.70% success rate** for Top-1 candidate selection across 1.0m, 2.0m, and 3.0m distance thresholds.
 - For Top-5 candidate selection, it achieved **98.90% success rate** across the same distance thresholds.
 - These scores were competitive with or superior to FSR-VLN (91.95% Top-1@1.0m, 94.25% Top-1@3.0m) and other baselines like HOV-SG and OK-Robot.
 - The consistent high scores across different distance thresholds suggest precise goal localization, with remaining failures indicating issues requiring better recovery mechanisms rather than relaxed localization.

#### 4.3. Memory Evaluation: Semantic Mapping and Update Visualization

- **3D Semantic Mapping Evaluation (ScanNet and Replica datasets):** HoloAgent-Memory demonstrated competitive performance in open-vocabulary 3D semantic mapping.
 - On **ScanNet**, HoloAgent-Memory achieved **31.58% mIoU, 45.54% mAcc, 47.43% f-mIoU, and 61.58% f-Acc**, outperforming several online methods and remaining competitive with others.
 - On **Replica**, it achieved **29.93% mIoU, 43.60% mAcc, 57.00% f-mIoU, and 65.39% f-Acc**, showing competitive online operation.
 - The results support the memory layer's ability to provide language-grounded 3D spatial memory for downstream planning tasks.

- **Memory Update Visualization:** Qualitative visualizations demonstrated the system's ability to perform instance association (merging new 2D observations into persistent 3D objects) and dynamic updates (refreshing changed regions without rebuilding the entire map). This ensures object identities remain stable and the memory reflects environmental changes during execution.

#### 4.4. Qualitative Closed-Loop Robot Execution

Qualitative demonstrations on real robots illustrated the full HoloAgent-0 runtime across various complex tasks:
- **Humanoid Motion Control:** Execution and verification of short-horizon whole-body commands.
- **Active Object Search:** Exploration, map building, and verification of target objects (e.g., finding a coffee machine).
- **Cross-Robot Coordination:** Orchestrating multiple robots, such as routing one robot while another performs a dance skill.
- **Long-Horizon Mobile Manipulation:** Decomposing complex tasks like laundry folding into sequential navigation, pick-and-place, motion, and manipulation steps, demonstrating the composition of skills and feedback-driven re-planning.

These qualitative results provide evidence for the framework's capability to compose heterogeneous skills through shared task state, status feedback, and memory-grounded planning.

### 5. Significance and Potential Impact

HoloAgent-0 represents a contribution to the field of embodied AI and robotics by addressing the fundamental challenges of deploying sophisticated language-model agents to real-world physical systems. Its significance and potential impact can be understood through several key aspects:

- **Bridging the "Embodiment Gap":** The framework directly confronts the difficulties of transferring digital LLM agent paradigms to physical robots, which involve continuous, uncertain, embodiment-dependent, and safety-critical execution. By providing a unified system-level abstraction, HoloAgent-0 offers a pathway to enable complex, long-horizon tasks that were previously limited by the lack of robust interfaces between high-level reasoning and low-level physical control.

- **Enabling Robust Real-World Deployment:** HoloAgent-0 provides a practical framework for real-world robot deployment, moving beyond simulation-centric research. The closed-loop design, which includes task planning, resource scheduling, execution monitoring, and feedback-driven re-planning, enhances the robustness and adaptability of robots in dynamic and uncertain physical environments. This is crucial for real-world applications where unexpected events or partial failures are common.

- **Unified Orchestration of Heterogeneous Capabilities:** The framework's ability to organize diverse robot capabilities (navigation, manipulation, perception, whole-body motion, interaction) into a cohesive system, rather than treating them as isolated modules, is significant. The typed skill interface and ROS2 command/status bus enable seamless composition of these skills, allowing for the execution of complex, multi-modal tasks (e.g., mobile manipulation, cross-robot coordination) that require integration of different robotic functionalities.

- **Memory-Centric Grounding:** The emphasis on persistent spatial and temporal memory provides a robust grounding mechanism for robot planning. By maintaining an evolving understanding of the 3D environment (geometry, semantics, scene graph) and task history (goal state, execution traces), HoloAgent-0 allows agents to reason beyond immediate sensor observations. This supports long-horizon tasks, enables better contextual understanding, and facilitates recovery from failures by recalling past states or successful strategies.

- **Enhanced Observability and Debuggability:** The "observable by default" principle, with comprehensive logging and visualization tools, has a direct impact on the development and debugging of embodied agents. This transparency is critical for diagnosing failures in complex robot systems where issues can arise across perception, planning, control, or hardware, accelerating research and development cycles.

- **Advancing Human-Robot Interaction:** The framework integrates interaction skills (ASR/TTS, dialogue state) within its closed loop, allowing for human-in-the-loop clarification and confirmation. This enhances the robot's ability to handle ambiguous instructions or uncertain execution outcomes, making robots more user-friendly and adaptable to human guidance.

In summary, HoloAgent-0 has the potential to accelerate the development and deployment of generalist embodied agents by providing a structured, robust, and adaptive framework that bridges the gap between high-level AI reasoning and the complexities of physical robot execution, ultimately paving the way for more capable and reliable robots in diverse real-world scenarios.
