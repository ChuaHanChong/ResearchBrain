# XIRL: Cross-embodiment Inverse Reinforcement Learning

> [!summary] Summary
> XIRL proposes a self-supervised, label-free framework that learns a vision-based reward function from unlabeled video demonstrations to enable robots to learn tasks despite stark embodiment differences. It leverages Temporal Cycle-Consistency to discover an embodiment-invariant notion of task progress, facilitating more efficient reinforcement learning without requiring human-labeled frame correspondences.

## Problem

- Robots struggle to learn from third-person video demonstrations due to the 'embodiment gap' between demonstrator and robot morphology.
- Acquiring ground-truth actions for a robot from observation-only human videos is often impossible or prohibitively difficult.
- Existing methods for cross-embodiment learning frequently rely on costly and unscalable manual annotations, such as frame-level correspondences.

## Method

- A two-stage framework is introduced: first, a self-supervised visual encoder is trained using Temporal Cycle-Consistency (TCC) on unlabeled, multi-embodiment video demonstrations.
- This encoder learns an embodiment-invariant representation of task progression.
- A dense reward function is then defined as the negative L2 distance between the current observation's embedding and a learned goal embedding (mean of final states), which is used by a reinforcement learning algorithm to train the robot's policy.

## Results

- XIRL achieved comparable or superior sample efficiency to ground-truth sparse rewards in same-embodiment tasks on the new X-MAGICAL benchmark.
- It consistently and significantly outperformed all baseline methods when generalizing to unseen robot embodiments.
- The method showed improved sample efficiency for a simulated robot arm using real-world human demonstration videos, notably without requiring human-labeled frame correspondences.

## Takeaways

> [!tip] Key Insights
> - An effective reward function for robot learning can be learned from diverse cross-embodiment video demonstrations in a self-supervised manner, encapsulating task progression irrespective of morphology.
> - Temporal Cycle-Consistency (TCC) is particularly effective for extracting an embodiment-invariant understanding of temporal task progress from unlabeled video data.
> - A dense, learned reward function provides a more efficient signal for reinforcement learning compared to sparse environment rewards, even outperforming them in some cases.
