# HAMLET: Switch your Vision-Language-Action Model into a History-Aware Policy

> [!summary] Summary
> The HAMLET framework integrates history-awareness into pre-trained Vision-Language-Action (VLA) models, employing compact moment tokens and a lightweight memory module to efficiently process past observations. This approach leads to an average 47.2% improvement in success rates on real-world long-horizon tasks, while introducing only minimal computational overhead (e.g., 1.02x latency, 1.96x peak memory for 4 history frames).

## Problem

- Most existing Vision-Language-Action (VLA) models rely on a single-frame assumption for action prediction, which fundamentally restricts their capabilities on history-dependent robotic manipulation tasks.
- Complex robotic tasks often involve object occlusion, multi-step reasoning, or conditional actions that necessitate access to historical context, making current VLA policies prone to failure or inefficiency.
- Naively incorporating history by concatenating multiple past observation frames into VLA inputs leads to substantial computational overhead, increasing forward pass time by approximately 35% and peak memory consumption by 3.6 times for just four additional frames.

## Method

- A framework called **HAMLET** (History-Aware Memory with LEarned Tokens) is proposed as a fine-tuning module that integrates into pre-trained VLAs to efficiently incorporate historical context.
- Context compression is achieved using "moment tokens" which are learnable tokens appended to the VLM input sequence, summarizing the current observation and task instruction into a compact, task-relevant representation.
- A lightweight, shallow ==Transformer==-based memory module aggregates these moment tokens across past timesteps, consolidating historical information into a "memory feature" which is then used to augment the VLA's action prediction.

## Results

- HAMLET achieved an average **47.2%** improvement in success rate on real-world history-dependent long-horizon tasks (e.g., **66.7%** vs **12.5%** on Pick-and-Place Twice) compared to the GR00T N1.5 baseline.
- It incurred minimal computational overhead, with approximately **1.02x** latency and **1.96x** peak memory increase for a history length of 4, significantly outperforming the naive multi-frame baseline (**1.35x** latency, **3.64x** memory).
- Performance consistently improved across various state-of-the-art VLA backbones (GR00T N1.5, CogACT, OpenVLA, π0-FAST) and simulation benchmarks (RoboCasa, LIBERO, SimplerEnv-Bridge), with gains up to an **8.8%** improvement over strong baselines.

## Takeaways

> [!tip] Key Insights
> - Time-Contrastive Learning (TCL) effectively initializes moment tokens to capture temporally discriminative cues, filtering out static elements and focusing attention on task-relevant, changing regions of the scene.
> - A dedicated memory module, rather than simple concatenation of past observations, is crucial for effectively integrating historical context, enabling selective attention to important past events.
> - The learned memory representations and the memory module itself exhibit generalizability, demonstrating transferability across different robot manipulation datasets and embodiments.
