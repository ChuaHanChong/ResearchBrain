# Multi-Goal Dexterous Hand Manipulation using Probabilistic Model-based Reinforcement Learning

> [!summary] Summary
> This paper presents Goal-Conditioned Probabilistic Model Predictive Control (GC-PMPC), a model-based reinforcement learning framework for multi-goal dexterous manipulation. The method combines probabilistic neural network ensembles with an asynchronous model predictive control policy, achieving sample-efficient learning and robust performance in both simulation and on a real DexHand 021, learning new goals while retaining old ones.

## Problem

- Dexterous robotic hands face challenges due to high-dimensional state and action spaces (20+ degrees of freedom).
- Complex dynamics, particularly hand-object interactions involving contact mechanics and friction, are difficult to model analytically.
- Learning-based approaches struggle with sparse rewards and require high sample efficiency for training on physical hardware.
- Generalizing to multiple manipulation goals, where objects need to be moved to various positions and orientations, is difficult.

## Method

- Introduces Goal-Conditioned Probabilistic ==Model Predictive Control== (GC-PMPC), a model-based reinforcement learning framework for multi-goal dexterous manipulation.
- Employs Goal-Conditioned Neural Network Ensembles to learn probabilistic dynamics models, accounting for uncertainty and incorporating goal information.
- Implements an Asynchronous MPC Policy with State Smoothing, where planning runs in a separate thread for real-time control, and a smoothing term minimizes large state changes for stable movements.

## Results

- GC-PMPC significantly outperformed baseline methods (SAC, TD7, DPETS, TDMPC) in simulation, achieving higher success rates across all four complex dexterous manipulation tasks with fewer samples.
- On a real DexHand 021, GC-PMPC learned three different die manipulation goals within approximately 28 minutes per goal (84 minutes total), consistently achieving higher rewards than DPETS and TD7.
- The framework demonstrated knowledge retention in real-world settings, maintaining performance on previously learned goals while acquiring new ones, and producing smooth, deliberate manipulation trajectories.

## Takeaways

> [!tip] Key Insights
> - Conditioning the dynamics model on the desired goal enables efficient learning of multiple manipulation objectives without forgetting previously acquired skills.
> - Utilizing probabilistic neural network ensembles quantifies uncertainty in dynamics predictions, enhancing robustness to noise and modeling errors.
> - An asynchronous Model Predictive Control (MPC) policy allows for real-time, high-frequency control by decoupling planning from execution, crucial for physical robotic systems.
> - Including a state smoothing term in the MPC objective leads to smoother and more stable robot movements, improving overall performance and reducing wear on hardware.
