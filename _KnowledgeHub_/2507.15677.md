# Data-Driven MPC with Data Selection for Flexible Cable-Driven Robotic Arms

> [!summary] Summary
> Tsinghua University researchers developed a data-driven Model Predictive Control (MPC) approach, augmented with a data selection algorithm, for Flexible Cable-Driven Robotic Arms, achieving an average positioning accuracy of 2.070 mm and a tracking error of 0.541%uFFFD%uFFFD%uFFFDa substantial reduction compared to PID methods%uFFFD%uFFFD%uFFFDwhile decreasing computational time by approximately 80%. This method allows FCRAs to achieve high-precision tasks without requiring an explicit physical model.

## Problem

- Flexible Cable-Driven Robotic Arms (FCRAs) exhibit complex, nonlinear dynamic behaviors due to cable properties like resilience, hysteresis, and friction.
- Traditional model-based control methods face limitations in accurately capturing these dynamics, leading to suboptimal control precision, slow response, and stability issues.
- Explicit physical models for FCRAs are difficult and inaccurate to construct and maintain, hindering high-precision control.

## Method

- A data-driven ==Model Predictive Control== (MPC) strategy was developed, leveraging behavioral systems theory to infer system dynamics from input-output data without an explicit physical model.
- A Data Search Algorithm (DSA) was introduced to dynamically select the most relevant data subgroup for MPC optimization, significantly reducing computational load.
- Pre-trained Multi-Layer Perceptrons (MLPs) are used as equivalent forward and inverse models, aiding in both validation and providing target motor velocities for the MPC cost function.

## Results

- The FCRA achieved an average positioning accuracy of **2.070** mm and a repeatability (3-sigma) of **7.750** mm across multiple target points.
- The data-driven MPC demonstrated an average tracking error of **0.541**%uFFFD, significantly outperforming a PID control method which yielded **1.418**%uFFFD error for single-point tasks.
- The Data Search Algorithm reduced the average MPC solution time from approximately 19 ms to 4 ms per step (an **80%** reduction), enabling effective real-time control for complex trajectory tracking, such as drawing letters.

## Takeaways

> [!tip] Key Insights
> - Complex, nonlinear systems like FCRAs can be effectively controlled using implicit models derived directly from input-output data, bypassing the need for explicit physical modeling.
> - Introducing a data selection mechanism significantly enhances the real-time computational efficiency of data-driven MPC, reducing processing time by nearly 80%.
> - The effectiveness of data-driven MPC for nonlinear systems is sensitive to hyperparameters like data length (N) and estimation horizon (n_ini), requiring careful tuning for optimal tracking performance.
