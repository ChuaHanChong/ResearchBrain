# Accelerating Sampling-Based Control via Learned Linear Koopman Dynamics

> [!summary] Summary
> This work introduces MPPI-DK, a control framework that integrates learned linear Deep Koopman Operator (DKO) dynamics into Model Predictive Path Integral (MPPI) control to accelerate real-time optimization for complex nonlinear robotic systems. The approach replaces computationally intensive nonlinear dynamics with efficient linear propagation in a lifted space, achieving comparable control performance to classic MPPI with significant reductions in computational cost, especially with GPU acceleration.

## Problem

- Real-time control of complex nonlinear and high-dimensional robotic systems faces computational bottlenecks due to repeated online optimization and nonlinear dynamics propagation.
- Model Predictive Path Integral (MPPI) control, while robust to nonlinearities, is limited by the computational expense of repeatedly propagating full nonlinear system dynamics during trajectory sampling.
- Even data-driven deep neural network models for dynamics can incur substantial computational costs when repeatedly evaluated in sampling-based controllers.

## Method

- A Deep ==Koopman== Operator (DKO) framework is used to learn a linear representation of the nonlinear system dynamics in a higher-dimensional, lifted state space from observed data.
- The proposed MPPI-DK method integrates these learned linear DKO dynamics into the MPPI controller, replacing the true nonlinear dynamics for trajectory propagation.
- Trajectory rollouts are performed by propagating states in the lifted space using efficient matrix multiplications, with the actual state reconstructed via a linear output mapping, avoiding repeated evaluations of complex lifting functions.

## Results

- MPPI-DK demonstrated control performance comparable to classic MPPI with true system dynamics across simulations (pendulum balancing, surface vehicle navigation) and real-world hardware (quadruped robot reference tracking).
- On a Unitree Go1 quadruped robot, GPU-accelerated MPPI-DK achieved a lower per-step computation time of **8.8** ms compared to **11.7** ms for GPU-accelerated classic MPPI.
- MPPI-DK produced smoother control inputs and a slightly smaller final state tracking error (**0.0043** vs. **0.0072**) than classic MPPI on the quadruped, while maintaining a **100%** success rate across tested initial states.

## Takeaways

> [!tip] Key Insights
> - Learned structured linear Koopman dynamics can act as effective computational accelerators within sampling-based control methodologies, significantly reducing the per-step computation time.
> - By computing the deep neural network lifting function only once per control step and propagating subsequent states linearly, MPPI-DK can leverage the efficiency of linear dynamics while maintaining compatibility with MPPI's stochastic sampling.
> - The MPPI-DK framework naturally benefits from parallel computation, particularly on GPU hardware, enabling substantial speedups crucial for high-frequency control tasks.
