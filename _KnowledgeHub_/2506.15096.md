# DyNaVLM: Zero-Shot Vision-Language Navigation System with Dynamic Viewpoints and Self-Refining Graph Memory

> [!summary] Summary
> DyNaVLM, developed by researchers at Shanghai Jiao Tong University, proposes a zero-shot vision-language navigation system for robots that utilizes dynamic viewpoints and a self-refining graph memory. The system demonstrates enhanced navigation flexibility and efficiency in both extensive simulations and real-world deployments on a quadrupedal robot.

## Problem

- Existing Vision-Language Navigation (VLN) methods often restrict robotic agents to fixed, discrete action spaces, limiting navigation flexibility and efficiency in continuous real-world settings.
- Applying pre-trained Vision-Language Models (VLMs) to embodied navigation typically requires extensive and costly task-specific fine-tuning, which can lead to catastrophic forgetting of broader semantic understanding.
- Current spatial memory systems for embodied agents frequently lack semantic richness or rely on prohibitive prior knowledge like pre-built 3D scene graphs, hindering adaptability in unexplored or dynamic environments.

## Method

- **DyNaVLM** introduces a dynamic action space formulation that allows the VLM to freely select continuous navigation targets by spatially sampling and safety-aware filtering potential points using real-time RGB-D data.
- It develops a self-refining graph memory that dynamically constructs and updates a knowledge graph of object instances and their topological relations during exploration, providing persistent semantic and spatial context.
- The system operates in a zero-shot, end-to-end manner by employing a multimodal prompt engineering strategy, feeding annotated images, task templates, and retrieved memory entries to a VLM for confidence-based action selection.

## Results

- DyNaVLM achieved a **45.0%** Success Rate (SR) and **0.232** Success weighted by Path Length (SPL) on the ObjectNav benchmark, outperforming prior VLM frameworks like VLMnav (**42.8%** SR, **0.218** SPL) and PIVOT.
- The system demonstrated **25.5%** SR and **0.102** SPL on the challenging GOAT-Bench, establishing the best performance among all VLM-based approaches, and competitive results against specialized non-zero-shot methods.
- In real-world deployment on a Unitree Go2 quadrupedal robot, DyNaVLM notably outperformed a VLMnav baseline in both success rate and travel distance across various indoor tasks, particularly in multi-target navigation scenarios.

## Takeaways

> [!tip] Key Insights
> - Vision-Language Models (VLMs) can function as a zero-shot, end-to-end navigation policy for robots when integrated with dynamic action spaces and a self-refining memory system.
> - A dynamically constructed, self-refining graph memory significantly improves an agent's ability to retain and leverage spatial reasoning and contextual information over long navigation horizons.
> - Allowing VLMs to directly reason over dynamically sampled continuous target points, rather than predefined discrete actions, enhances navigation flexibility and efficiency in complex environments.
