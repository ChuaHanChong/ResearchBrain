# DynaMimicGen: A Data Generation Framework for Robot Learning of Dynamic Tasks

> [!summary] Summary
> DynaMimicGen (D-MG) introduces a data generation framework for robot learning of dynamic tasks, producing large-scale, diverse datasets from as few as one or two human demonstrations. It leverages Dynamic Movement Primitives and continuous object pose monitoring to synthesize adaptable Cartesian trajectories, leading to improved policy success rates up to 97.33% in simulation and 96.0% in real-world for tasks like Lift, while significantly reducing human data collection effort.

## Problem

- Learning from Demonstration (LfD) and Imitation Learning (IL) for robots demand large, diverse datasets for effective generalization.
- Collecting extensive human demonstrations is time-consuming, labor-intensive, and often impractical for complex, dynamic real-world scenarios.
- Existing synthetic data generation methods for IL primarily assume quasi-static environments, limiting their applicability to tasks where object positions or orientations change during execution.

## Method

- **DynaMimicGen** (D-MG) parses minimal human demonstrations into ==object-centric subtask segments==.
- It employs ==Dynamic Movement Primitives (DMPs)== to learn and generalize each subtask's trajectory from a single selected demonstration segment.
- The framework continuously monitors ==object poses== during trajectory execution, adapting DMP goals in real-time to new scene configurations and introducing ==structured environmental perturbations== to generate dynamic, diverse data.

## Results

- D-MG achieved comparable or superior data generation rates (DGRs) using **1-2** human demonstrations compared to a baseline method requiring **10**, significantly reducing human supervision.
- Datasets generated with D-MG led to substantial improvements in downstream policy performance, with Diffusion Policy reaching **97.33%** success in the 'Square' task and Behavior Cloning achieving **96.0%** in the 'Lift' task on a real robot.
- Ablation studies confirmed that dynamic scene perturbations are critical for robust policy learning, with image-based agent performance dropping significantly (e.g., from **83.33%** to **45.33%** for DP in Stack D0) when these dynamic variations were disabled.

## Takeaways

> [!tip] Key Insights
> - Scalable robot data generation from minimal human input (1-2 demonstrations) is achievable by leveraging DMPs to generalize object-centric subtask trajectories.
> - Integrating dynamic environmental perturbations during data generation is crucial for creating robust and generalizable policies, especially for image-based observations in evolving scenes.
> - Continuous monitoring and adaptation of robot trajectories based on real-time object poses enables effective data synthesis for dynamic tasks, a capability largely absent in prior imitation learning data generation frameworks.
