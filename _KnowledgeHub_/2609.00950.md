# HitMem: Hierarchical Temporal 3D Memory with Multi-Modal Context-Aware Retrieval for Dynamic Environments

> [!summary] Summary
> HitMem is a 3D memory framework for embodied agents in dynamic homes. It stores objects in a lightweight carrier-carried topological graph with fine-grained 3D attributes, applies exponential temporal decay to memory activeness, and, when a target is found missing, relocates it by combining external-agent trajectory pruning with class-affinity scanning. On the new Dyna-THOR benchmark it reaches 51.67% success versus 35.00% for the strongest baseline.

## Problem

- Existing 3D scene-graph and dense-reconstruction memories assume a static world, so human-displaced objects trigger memory-observation conflicts they cannot cheaply resolve.
- Updating those representations requires re-inferring edge correspondences or recomputing geometric clusters, which is computationally expensive and error-prone during continuous operation.
- Prior dynamic-memory methods fall back on exhaustive global search or single-modality matching when relocating an object, wasting steps and exceeding budgets.

## Method

- **Hierarchical temporal 3D memory**: ==CLIP==-featured object nodes linked by ==carrier-carried edges== scored from proximity, horizontal coverage, vertical support and height consistency, with bidirectional ==ICP fusion== for deduplication.
- **Temporal decay mechanism** assigning each node an exponentially decaying ==activeness score==, zero decay for carriers and a scene-scale-modulated rate for carried objects, also used to order external-agent trajectory points.
- **Multi-modal context-aware retrieval**: semantic-plus-activeness ranking, active verification with node pruning, then two-stage relocation via ==trajectory-derived displacement-vector sector filtering== plus ==softmax class-affinity scanning==.

## Results

- On Dyna-THOR, HitMem reaches **51.67** SR / **34.24** SPL / **64.08** GCR overall, beating DynaMem (**35.00** / **16.86** / **47.69**), DovSG (**18.33**), ConceptGraphs (**11.67**) and DELTA (**3.33**).
- Ablations: dropping the retrieval strategy plus decay cuts SR to **31.67** and SPL to **12.66**; removing decay alone gives **43.33** SR, removing hierarchy gives **46.67** SR.
- Robustness holds under imperfect tracking (**50.00** SR with **30%** trajectory dropout or Gaussian noise) and transfers zero-shot to perturbed ALFRED valid-unseen at **52.94** SR versus **41.18** for DynaMem.

## Takeaways

> [!tip] Key Insights
> - Modeling only categorical carrier-carried relations, not instance-level geometric clusters, buys cheap incremental updates while keeping enough structure to prune search in changing scenes.
> - Forgetting is an active capability: decaying stale entries yields larger efficiency gains than accuracy gains, since it mainly stops repeat trips to ghost locations.
> - Physical cues and semantic priors are complementary and each degrades gracefully; affinity alone still recovers most performance when trajectory observation is unavailable.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of embodied AI aims to develop agents capable of performing complex tasks in real-world environments. A critical component for such agents is a robust memory system that enables them to store and retrieve environmental information to support long-term task execution. Historically, many 3D memory frameworks for embodied agents have been developed under a static world assumption. These frameworks often convert sensory inputs into 3D representations through methods like dense reconstruction or scene graph modeling, providing spatial awareness for navigation and manipulation.

However, real-world environments are inherently dynamic, with objects frequently being displaced by human activities or unobserved events. This dynamism introduces challenges such as memory-observation conflicts when an agent encounters a scene that differs from its memorized state. Existing methods exhibit several limitations in addressing these dynamics:
- **Computational Inefficiency:** Re-inferring relational structures or recomputing geometric clusters to update memory is computationally expensive and prone to errors.
- **Lack of Temporal Dynamics:** Many frameworks do not explicitly model temporal aspects, leaving agents vulnerable to using obsolete information.
- **Inefficient Relocation Strategies:** When objects are displaced, current methods often resort to exhaustive global searches or rely on single-modmodality information, which is inefficient.

The paper notes that human cognitive search behaviors for misplaced objects involve leveraging multi-modal contextual cues (e.g., physical spatial dynamics, recent interactions, semantic relevance) rather than random or exhaustive scanning. This observation highlights a gap in current AI approaches to object relocation.

This research positions itself by addressing these limitations through the introduction of a hierarchical temporal memory and a multi-modal context-aware retrieval mechanism. It aims to bridge the gap between static memory assumptions and the requirements of dynamic environments, ultimately enhancing an embodied agent's adaptability and efficiency in long-term tasks. The introduction of the Dyna-THOR benchmark also contributes to the broader landscape by providing a tool for evaluating dynamic adaptability, a feature often lacking in existing embodied AI benchmarks like R2R, VirtualHome, and ALFRED.

### 2. Key Objectives and Motivation

The primary objective of this research is to enable embodied agents to perform complex, long-term tasks robustly in dynamic environments, specifically addressing scenarios where objects are unexpectedly displaced. The motivation stems from several limitations observed in existing 3D memory frameworks:

- **Reliance on Static World Assumptions:** Current embodied AI systems often assume that the environment remains unchanged. In dynamic real-world settings, where objects are frequently moved by human interaction or unobserved events, this assumption leads to memory-observation conflicts when an agent cannot find an object at its memorized location. This discrepancy can cause task failures and necessitate costly recomputations or inefficient global re-exploration. The authors are motivated to move beyond this static constraint.
- **Inefficiency of Memory Updates:** When changes occur, existing methods for updating 3D scene representations (e.g., re-inferring relational structures, recomputing geometric clusters) are computationally inefficient and susceptible to errors. There is a need for a memory framework that can be continuously and efficiently updated to reflect environmental changes without significant computational overhead.
- **Vulnerability to Obsolete Information:** The absence of explicit temporal dynamics modeling in most existing memory frameworks means agents might rely on outdated information, which can degrade task accuracy and efficiency. The authors aim to integrate a mechanism that quantifies and manages the temporal validity of memorized information.
- **Ineffectiveness of Current Object Relocation Strategies:** When an object is known to be displaced, existing search strategies (e.g., exhaustive global search, reliance on single-modality cues) are often inefficient. The research is motivated by human cognitive strategies, which synthesize multi-modal contextual cues (e.g., recent human interactions, semantic common sense about where objects are typically found) to efficiently locate misplaced items. This suggests a need for a more intelligent, context-aware retrieval mechanism.
- **Lack of Suitable Benchmarks:** Existing embodied AI benchmarks largely focus on static environments and do not adequately capture the challenges of object manipulation by external agents. This limits the rigorous evaluation of methods designed for dynamic settings. A motivation for this work is to introduce a benchmark (Dyna-THOR) that explicitly simulates real-world dynamics, enabling a more accurate assessment of an agent's adaptability and robustness.

In summary, the key objectives are to:
1. Develop a hierarchical 3D memory framework that unifies semantic, spatial, and temporal information.
2. Implement a temporal decay mechanism to manage memory activeness and filter obsolete observations.
3. Design a multi-modal context-aware retrieval mechanism that can efficiently relocate displaced objects by integrating physical spatial cues (external agent trajectories) and semantic common sense (class affinities).
4. Create a novel benchmark, Dyna-THOR, to evaluate embodied agents in dynamic environments with external agent interactions.

### 3. Methodology and Approach

HitMem is proposed as a hierarchical temporal 3D memory framework incorporating a multi-modal context-aware retrieval mechanism. The methodology can be broken down into three main components: Hierarchical Temporal 3D Memory, Multi-Modal Context-aware Retrieval, and the Dyna-THOR benchmark.

### 4. Hierarchical Temporal 3D Memory

This component focuses on constructing and maintaining a dynamic, multi-level representation of the environment.

- **Topological and Semantic Representations:**
 - **Node Instantiation (V_t):** The system continuously processes RGB-D observations from the ego-agent. An open-vocabulary recognition and detection model (e.g., RAM-Grounded-SAM2) extracts instance-level bounding boxes and segmentation masks. Each detected instance forms a node v_i in the memory graph V_t, storing visual embeddings (derived from CLIP), reconstructed point clouds, global coordinates, and physical dimensions.
 - **Carrier-Carried Edges (E_t):** Nodes are categorized into "carriers" (C_r, e.g., tables, shelves) and "carried objects" (C_d, e.g., cups, apples). A node is classified as a carrier if its visual feature similarity to "furniture or appliances for holding objects" exceeds a semantic threshold. For non-carrier nodes, their spatial relationship with all existing carriers is evaluated using a composite support score (S_support). This score integrates four geometric metrics: spatial proximity (R_p), horizontal coverage (R_c), vertical support (R_v), and height consistency (S_h). A directed edge E(v_i, v_j) is established, assigning v_j to C_d, if the maximum support score with any carrier exceeds a threshold. Objects not meeting this condition are temporarily labeled as "unassigned" and re-evaluated later. This categorical C_r → C_d topological structure is designed for efficient local updates, avoiding global graph reconstruction.

- **Temporal Decay Mechanism:**
 - To address memory obsolescence, each node v_i is assigned a dynamic "activeness score" A(v_i, t) ∈ (0, 1]. This score exponentially decays over time based on the elapsed duration since the node's last observation.
 - The decay rate λ(v_i) is object-specific and scaled by the environment's spatial scale. Carrier objects (C_r) have a decay rate of zero, maintaining stable structural memory. Carried objects (C_d) have a baseline decay rate λ_base, inversely scaled by a scene factor η(S_scene) (larger scenes lead to slower decay), preventing premature forgetting in extensive environments. A higher activeness score indicates more reliable memory.
 - **External Agent Trajectory Tracking:** External agents (e.g., "human/robot") are also recognized by the perception module. Their individual observation nodes are recorded (V_agent) and chronologically ordered by their activeness scores to reconstruct their coherent motion trajectories (T). These trajectories provide physical context for subsequent retrieval.

- **Continuous Memory Fusion:**
 - New observations are fused with existing memory nodes to ensure consistency. A bidirectional Iterative Closest Point (ICP) matching process is used, requiring both forward and backward alignment scores to pass respective thresholds. This method aims to prevent segmentation inaccuracies or localization noise from absorbing small objects or losing memory entries. Upon a successful match, the new point cloud is merged, the node's temporal state is refreshed (A(v_i, t) = 1), and its visual feature is updated via a weighted average.

### 5. Multi-Modal Context-aware Retrieval

This mechanism is designed for efficient target object localization, particularly when objects are displaced.

- **Hierarchical Semantic Querying and Active Verification:**
 - User instructions are parsed by a Large Language Model (LLM) into structured semantic queries (e.g., <Pick, Apple, Table>).
 - The system first filters relevant carrier nodes (C_r), then restricts the search to carried objects (C_d) topologically linked to these carriers. If no carrier context is provided, a top-down traversal is used.
 - A retrieval score S_retrieval(v_i) is calculated for each candidate carried object, combining the cosine similarity between its visual embedding and the query's textual embedding (F_query), and its temporal activeness score A(v_i, t). These components are normalized and weighted (α_1, α_2).
 - Top-ranked candidates (e.g., up to three) exceeding a threshold are selected. The ego-agent navigates to the expected location of the highest-ranked candidate.
 - **Active Verification:** Upon arrival, the agent visually verifies if the current observation matches the anticipated target. If successful, the task proceeds. If the target is absent (a memory-observation conflict), the obsolete node v_i and its associated edge are pruned from the graph (V_t ← V_t \ {v_i}), and a two-stage relocation strategy is triggered.

- **Two-Stage Retrieval for Relocated Objects:**
 - **Stage 1: Trajectory-Based Search Space Filtering:**
 - The system identifies the "interaction point" P_closest in the external agent's historical trajectory (T) that is spatially closest to the target object's last known position.
 - A local trajectory segment (τ_local) of `k` consecutive points following P_closest is extracted.
 - A displacement vector D is estimated as a weighted average of these subsequent trajectory segments, with weights based on activeness score differences.
 - This vector guides the creation of a candidate exploration set C_cand, which includes carrier objects (C_r) whose positions lie within a specific angular sector (θ_R) relative to D from the object's last known position. This step aims to prune the search space directionally.
 - **Stage 2: Semantic Class Affinity Scanning:**
 - Candidate carriers in C_cand are prioritized based on "class affinities" with the target category (Cat_t).
 - A contextualized textual embedding E_text(Cat_t) is generated (e.g., using a template like "A receptacle where a [Cat_t] is most often placed"). The raw semantic affinity A_affinity(Cat_t, v_j) is calculated as the cosine similarity between E_text(Cat_t) and the visual embedding of the candidate carrier v_j. This can also be informed by an LLM prior.
 - These affinity values are normalized using a softmax function to form a probability distribution P(v_j | Cat_t). The ego-agent then explores candidate carriers in C_cand according to this prioritized list.

### 6. Dyna-THOR Benchmark Design

- Built upon the AI2-THOR simulator, this benchmark is designed to address the lack of interaction-driven environmental dynamics in existing datasets.
- It introduces "external agents" that actively manipulate and relocate task-relevant objects prior to or during the ego-agent's task execution, without explicit notification. This creates unpredictable dynamics and memory-observation conflicts.
- Dyna-THOR includes 12 interactive scenes across four room categories, each with five long-term tasks requiring sequential natural language instructions.
- Evaluation metrics include Success Rate (SR), Success weighted by Path Length (SPL), and Ground-truth Completion Rate (GCR).

### 7. Main Findings and Results

The evaluation of HitMem was conducted primarily on the newly constructed Dyna-THOR benchmark, supplemented by ablation studies, scalability analyses, and qualitative visualizations.

- **Comparison with Baselines (Table 2):**
 - HitMem demonstrates improved performance across all metrics (SR, SPL, GCR) and room categories compared to baseline methods.
 - Static memory approaches (DELTA, ConceptGraphs) exhibited low success rates, indicating their limited adaptability to dynamic object displacements. Their success was typically confined to cases where displacement was minor or objects remained visible from their original positions.
 - Methods with dynamic update capabilities (DovSG, DynaMem) showed improvement over static approaches, but their performance was constrained by limitations in their update strategies (e.g., local updates only before manipulation for DovSG) or inefficient global search mechanisms (DynaMem).
 - HitMem's superior performance is attributed to its multi-modal context-aware retrieval, which efficiently narrows the search space and locates displaced targets, allowing the agent to complete tasks within step limits. For example, overall, HitMem achieved an SR of 51.67% compared to DynaMem's 35.00%, and an SPL of 34.24% compared to DynaMem's 16.86%.

- **Ablation Study (Table 3):**
 - **Without Hierarchical Structure (M_H):** A noticeable degradation in SR (46.67% vs. 51.67%) and SPL (26.71% vs. 34.24%) was observed. This indicates that the hierarchical topological graph, which provides high-level semantic stratification and filtering of the search space, is important for task understanding and re-localization efficiency.
 - **Without Decay Mechanism (M_D):** This variant resulted in a substantial drop in SPL (20.45% vs. 34.24%), highlighting the importance of temporal activeness scoring. Without it, the agent treats stale and fresh observations equally, leading to wasted steps navigating to outdated or "ghost" memory entries.
 - **Without Retrieval Strategy & M_D:** The most significant performance drop occurred when both the context-aware retrieval strategy and the decay mechanism were removed (SR 31.67%, SPL 12.66%). This suggests that the two-stage retrieval, which integrates external agent trajectories and semantic affinity, is critical for efficient re-localization, preventing the agent from engaging in blind and exhaustive global searches that often exceed task step limits.

- **Scalability Analysis (Fig. 4):**
 - The impact of the temporal decay rate (λ) on performance was found to be more significant in larger, multi-room environments than in small ones.
 - In larger environments, a smaller λ value (slower decay) was found to be more beneficial, allowing memory to persist longer given reduced revisit frequencies. An excessively large λ led to premature forgetting and a sharp decline in success rates.
 - HitMem, when utilizing an appropriately tuned decay rate, consistently outperformed a fixed baseline (without decay mechanism) across varying spatial scales, demonstrating its robustness and scalability.

- **Case Visualization (Fig. 5):**
 - A successful object relocation scenario illustrated how HitMem functions. After an external agent moved a "Book," the ego-agent detected a memory-observation conflict at the book's last known location. It then inferred a displacement vector from the external agent's trajectory to prune the search space. Subsequent class affinity analysis prioritized candidate carriers, leading the agent to successfully locate the book on an armchair after sequential exploration.

- **Additional Experiment Results (Appendix):**
 - **Impact of Descriptions and LLMs (Table 4):** Task success rates were influenced by the clarity of natural language instructions and the choice of LLM. Clearer instructions and GPT-4o generally yielded better performance, while ambiguous descriptions or LLMs that generated redundant actions (e.g., Gemini-2.5-Pro) led to performance degradation.
 - **Resilience to Imperfect Tracking (Table 5):** HitMem demonstrated robustness against challenges like "off-screen" displacements (where trajectory data is absent, relying only on affinity) and imperfect perception (30% trajectory dropout, Gaussian noise). Performance drops were marginal, suggesting that the combined spatial pruning and semantic common sense ensure resilience.
 - **Generalizability (Table 6):** HitMem also showed improved performance on the ALFRED benchmark (valid_unseen split with artificial dynamics) compared to other dynamic memory baselines, indicating its robust zero-shot generalization to new environments and tasks.

### 8. Significance and Potential Impact

This research presents a framework, HitMem, that contributes to the field of embodied AI by addressing the challenges of operating in dynamic environments. Its significance and potential impact can be summarized as follows:

- **Enhanced Adaptability in Dynamic Environments:** HitMem moves beyond the static world assumption prevalent in many embodied AI systems. By explicitly modeling temporal dynamics and object displacements, it enables agents to adapt to changes introduced by external factors (e.g., humans or other robots). This is a critical step towards deploying embodied agents in real-world, interactive settings where environments are rarely static.
- **Improved Object Relocation Efficiency:** The multi-modal context-aware retrieval mechanism, particularly the two-stage strategy, offers a more efficient approach to re-localizing displaced objects. By integrating external agent trajectories and semantic common sense (class affinities), HitMem reduces the need for exhaustive global searches. This can lead to substantial reductions in exploration costs and time, which are practical considerations for robotic applications.
- **Robust 3D Scene Representation:** The hierarchical temporal 3D memory framework structurally unifies semantic, spatial, and fine-grained geometric information. The temporal decay mechanism dynamically regulates memory activeness, ensuring that the agent's internal representation remains aligned with the evolving physical world by filtering obsolete observations. This contributes to more robust and reliable long-term memory for agents.
- **Introduction of a Relevant Benchmark:** The development of Dyna-THOR provides a benchmark for evaluating embodied agents specifically under dynamic conditions caused by external agent interactions. This addresses a gap in existing datasets and offers a tool for the research community to rigorously test and compare methods designed for dynamic environments, thereby fostering further advancements in this area.
- **Inspiration from Human Cognition:** The design of the multi-modal retrieval mechanism is inspired by human cognitive search behaviors, which leverage diverse contextual cues. This approach could influence future designs of AI systems that aim to emulate more human-like reasoning and problem-solving strategies in complex environments.
- **Broader Applications:** The principles and mechanisms introduced in HitMem could be relevant for a range of applications beyond general embodied agents, including service robotics, augmented reality, assistive technologies, and autonomous navigation systems that need to maintain coherent environmental understanding despite changes.
