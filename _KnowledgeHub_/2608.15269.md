# Remember Smarter: Visual History Compressor and Hyperbolic Experience Space for Robotic Memory

> [!summary] Summary
> Remember Smarter is a plug-and-play memory module for VLA robot policies with two branches: bidirectional spatial and causal temporal Mamba compress multi-view visual history into fixed-shape state read via residual cross-attention, while a Poincare-VAE hyperbolic space stores and hierarchically retrieves successful past experiences as geodesic prompt tokens. Applied to pi_0, it raises total LIBERO-Plus success from 53.6% to 70.6% without expanding VLA context.

## Problem

- Feeding more historical frames into VLA backbones is costly and noisy, wasting token budget while obscuring the sparse state changes needed for decisions.
- Flat memory banks used by prior VLA memory designs do not represent hierarchical abstractions explicitly, limiting reuse of structured past experience.
- Existing approaches require global retrieval over a growing set of demonstrations, which does not scale as accumulated experience expands.

## Method

- ==Mamba-compressed visual history==: bidirectional spatial Mamba plus causal temporal Mamba compress multi-view patch histories into constant-shape recurrent state, trained with truncated backpropagation and stop-gradient chunk boundaries.
- ==Residual history cross-attention adapter==: lets action-facing hidden states query the compressed visual-history memory as keys/values without altering the VLM's own visual-token stream.
- **Remember Smarter (RS)**'s hyperbolic experience-memory branch: stores successful final-layer VLM states in a ==Poincare VAE== space, organizes them via ==entailment-cone routing== into a binary hierarchy, and asynchronously converts cone-guided retrievals into four geodesic prompt tokens.

## Results

- Adapted to pi_0, RS increases total success on LIBERO-Plus from 53.6% to **70.6%** (also reported as 70.3% on a selected subset), a large margin over the unmodified backbone.
- Component ablation on four standard LIBERO suites: the visual-Mamba-compressor-only variant (VMC) raises Long-suite success from 85.2% to **92.6%**; adding the hyperbolic experience branch further raises it to **94.2%** and overall four-suite score to **96.2%**, a **2.1-point** gain over pi_0.
- RS trails the zero-shot MemoryVLA++ baseline's reported 73.1% total by **2.5 points** on the dimension-level LIBERO-Plus comparison, while substantially improving over the pi_0 backbone across camera, robot, language, light, background, noise, and layout perturbation dimensions.

## Takeaways

> [!tip] Key Insights
> - Separating memory into a fine-grained recurrent compression branch and a coarse-grained hierarchical retrieval branch lets each address a distinct failure mode without inflating context length.
> - Hyperbolic geometry's natural fit for tree-structured, directional relationships makes it a principled choice for organizing and retrieving hierarchically related experiences, not just a Euclidean drop-in.
> - Gains from added memory concentrate on long-horizon tasks, implying memory modules should be evaluated on horizon-stressing benchmarks, not just aggregate short-task success rates.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of robotic control, particularly for long-horizon tasks, relies on Vision-Language-Action (VLA) models that integrate visual perception, language understanding, and action generation. A significant challenge for these models is their memory capacity, which can be limited and fragile, especially in tasks requiring retention of information beyond immediate observations or recall of past experiences. Existing VLA models often struggle with efficiently managing extended visual histories due to computational costs and the potential for irrelevant information to dilute the context. Furthermore, traditional memory banks in robotics typically lack hierarchical organization, making global retrieval from a growing set of demonstrations inefficient.

Current approaches to address VLA memory limitations include using visual memory, modeling phase or object states, generating prompts from demonstrations, or employing multi-scale perceptual and cognitive memory architectures. While some works explore hierarchical organization for lifelong robot experience or multi-memory planning, these often focus on explicit symbolic task trees or direct integration within the VLA backbone. Similarly, State Space Models (SSMs), particularly Mamba, have emerged as efficient linear-time sequence processors, with applications in long video understanding and direct integration into VLA policies. Hyperbolic geometry, with its capacity for representing hierarchies, has been utilized for latent variable models (Poincare VAEs), directed relations (entailment cones), and clustering.

This research introduces a memory module, Remember Smarter (RS), which aims to augment existing VLA policies without modifying their core backbone. RS distinguishes itself by coupling a fixed-state visual compressor, based on Mamba, with an asynchronously queried hierarchical experience space founded on hyperbolic geometry. This design assigns distinct computational roles to fine-grained, online visual history and coarse-grained, reusable experience. It positions itself as a plug-and-play solution that addresses the memory fragility and context expansion issues of VLA models by providing complementary memory mechanisms, rather than solely relying on a single, unified memory paradigm or directly altering the VLA architecture.

### 2. Key Objectives and Motivation

The primary objective of this research is to enhance the performance of VLA robot policies on long-horizon tasks by providing efficient and compact access to both recent observations and reusable past experiences, without increasing the context length of the VLA backbone itself.

The motivation behind this work stems from several limitations observed in current VLA models:
- **Fragile Memory on Long-Horizon Tasks:** Standard VLA models often exhibit limited memory capabilities, making them susceptible to failure in tasks that require retaining information or executing sequential steps over extended periods.
- **Costly and Noisy Context Expansion:** Directly feeding more historical frames into the VLA backbone to improve memory is computationally expensive. It can also introduce redundancy, consuming token budgets and obscuring sparse, task-relevant state changes with a large volume of irrelevant observations.
- **Lack of Hierarchical Abstraction:** Existing flat memory banks in VLA systems do not inherently represent hierarchical abstractions of tasks or experiences. This deficiency can hinder efficient retrieval and generalization across various task complexities.
- **Inefficient Global Retrieval:** As the repository of demonstration data grows, performing global retrieval from a flat memory bank becomes increasingly inefficient, impacting the scalability and responsiveness of the policy.
- **Need for a Plug-and-Play Solution:** There is a practical need for memory augmentation modules that can be easily integrated with pre-trained VLA backbones without requiring extensive modifications or retraining of the entire foundation model.

To address these issues, the authors propose Remember Smarter (RS), designed with the following specific objectives:
- **Develop a Complementary Dual-Branch Memory System:** Create a system with two distinct but complementary branches: one for fine-grained visual history compression and another for coarse-grained hierarchical experience retrieval.
- **Implement Online Visual-History Compression:** Design an efficient visual history compressor that uses State Space Models (Mamba) to process multi-view visual patch histories. This compressor should maintain a compact, fixed-shape recurrent state, allowing for online updates during inference without storing the full visual history.
- **Establish a Hierarchical Experience Memory:** Construct a structured memory for successful past experiences using hyperbolic geometry. This memory should organize experiences hierarchically to enable efficient, targeted retrieval and asynchronous integration into the VLA policy.
- **Ensure Plug-and-Play Compatibility:** Design RS as a module that can be easily integrated with existing pre-trained VLA backbones, communicating through residual connections and prompt tokens without altering the VLA model's internal architecture or visual token stream.
- **Improve Task Success Rates:** Demonstrate that RS significantly improves success rates on complex, long-horizon manipulation tasks in both simulated and real-robot environments by providing VLA policies with enhanced memory capabilities.

### 3. Methodology and Approach

Remember Smarter (RS) is designed as a plug-and-play memory module that augments pre-trained VLA policies with two complementary branches: a visual-history compressor and a hyperbolic experience memory.

#### 3.1. Mamba-Compressed Visual History

This branch handles fine-grained, recent observations. It takes a multi-view image stream and converts it into a compact recurrent memory.
1. **Visual Feature Extraction and Adaptation:** The current and historical images are processed by the VLA policy's existing visual encoder (E_vis_). The resulting patch features (F_v_τ_) are then adapted to a shared Mamba width (d) by a lightweight, independently trained adapter module (A_φ_). This adapter decouples the compressor from the specific dimensions of the VLA backbone's visual features.
2. **Per-Frame Bidirectional Serpentine Encoding:** For each view and frame, the adapted patch grid is linearized using a serpentine permutation. This ensures spatial adjacency of consecutive patches across row boundaries. This sequence is then processed by two parallel spatial Mamba blocks: a forward Mamba and a backward Mamba (on the reversed sequence). Their outputs are then reversed (for the backward path) and averaged to provide complementary spatial context while preserving aligned patch positions. A learned query (q) then pools this fused sequence, and a learned projection (A_pool_) generates a compact frame-level representation (p_v_τ_).
3. **Causal Temporal Aggregation:** The pooled frame representations for each view are processed chronologically by two stacked causal temporal Mamba layers. These layers aggregate the history for each view, with temporal parameters shared across views but each view maintaining its own recurrent state (s_v_τ_). This ensures that the memory for each view depends only on past observations up to the current time step. The output is an ordered multi-view memory tensor (M_t_).
4. **Residual History Cross-Attention:** The aggregated multi-view memory (M_t_) serves as the source of keys and values for a residual cross-attention adapter. The queries for this attention module are derived from the final hidden representations of the VLA backbone (H_t_), which are used for action prediction. The output of the cross-attention (∆H_t_) is then added as a residual to the original hidden representations (H_t_) with a small scaling factor (γ=0.05). This integration allows the VLA's action head to consume an enhanced representation without modifying the VLA's visual token stream or backbone.
5. **Training and Streaming Inference:** During training, trajectories are divided into fragments. The temporal state is passed across fragment boundaries, but gradients are stopped at these boundaries (Truncated Backpropagation Through Time, TBPTT) to manage computational load. At inference, the same fixed-shape recurrent state is updated online for each new frame, obviating the need to store the full visual history. Episode resets clear all recurrent states.

#### 3.2. Hyperbolic Experience Space

This branch provides coarse-grained, reusable experience from successful demonstrations.
1. **Experience Storage:** After policy training, final action-facing VLA hidden representations from successful demonstrations are collected. A Poincare Variational Autoencoder (P-VAE) maps these representations into mean vectors (z_i_) within a Poincare ball, which serve as retrieval leaves. The P-VAE decoder can reconstruct policy representations from selected latent points. Failed demonstrations are explicitly excluded from this experience memory.
2. **Hierarchical Organization:** A separate binary hierarchy is constructed over these P-VAE leaves, using an optimization process inspired by Hyperbolic Hierarchical Clustering (HypHC). This process optimizes an auxiliary copy of the leaf coordinates, leaving the original P-VAE retrieval coordinates unchanged. After tree construction, each internal node's prototype is initialized as the Karcher mean of its descendant leaves, minimizing aggregate hyperbolic distance. Entailment cones are then calibrated for internal prototypes, providing directed parent-to-descendant containment relations.
3. **Asynchronous Hierarchical Retrieval:** At inference time, the current VLA hidden representation is encoded into a query (q_t_) in the same P-VAE space. A non-blocking background worker then traverses the constructed binary tree. It uses hyperbolic distance and entailment cones of internal prototypes to prioritize relevant subtrees, and then ranks candidate leaves. Up to eight most relevant leaves are returned, limiting subsequent processing costs. The action loop proceeds without waiting for this retrieval process, managed by a queue and timeout mechanism.
4. **Geodesic Experience-Token Generation:** The retrieved leaves are summarized by their lowest common internal ancestor (a_t_) in the hierarchy. The corresponding P-VAE space prototype (p_a_t_) is used to guide the generation of experience tokens. RS samples four points along the geodesic path from the current query (q_t_) to this shared prototype (p_a_t_). These points are then decoded by the P-VAE decoder into four fixed-size experience tokens. These tokens are inserted into the VLA's input prompt (specifically, before the first image embedding) to provide a fixed-budget contextual prompt to the VLA's self-attention mechanism, which fuses them with the visual and language context. A learned `[MEM_QUERY]` token is also inserted after the task prompt, its final hidden state forming the query for the next retrieval.

### 4. Main Findings and Results

The evaluation of Remember Smarter (RS) was conducted across simulated and real-robot environments, demonstrating its effects on VLA policy performance, particularly for long-horizon tasks.

#### 4.1. Simulation Benchmarks (LIBERO-Plus)

The system was evaluated on the LIBERO-Plus benchmark, which assesses robustness across seven perturbation dimensions (camera, robot, language, light, background, noise, layout). RS was adapted only using original LIBERO demonstrations, not the LIBERO-Plus training set.
- **Overall Success Rate:** When adapted to the π₀ policy, RS increased the total strict success rate on LIBERO-Plus from 53.6% (for base π₀) to 70.6%. This represents an absolute increase of 16.9 percentage points across 10,030 task instances.
- **Performance Across Dimensions:** RS demonstrated substantial improvements across most perturbation dimensions:
 - Camera: ↑37.0 points (from 13.8% to 50.8%)
 - Robot: ↑39.8 points (from 6.0% to 45.8%)
 - Language: ↑6.5 points (from 58.8% to 65.3%)
 - Light: ↑7.1 points (from 85.0% to 92.1%)
 - Background: ↑12.6 points (from 81.4% to 94.0%)
 - Noise: ↑9.1 points (from 68.9% to 78.0%)
 - Layout: ↑2.2 points (from 79.0% to 81.2%)
- **Comparison with Baselines:** The 70.6% total success rate of π₀+RS was 2.5 points below the 73.1% reported for MemoryVLA++ in a zero-shot setting, but significantly higher than other baselines like MemoryVLA (70.2%), OpenVLA-OFT (69.6%), and π₀-Fast (61.6%).

#### 4.2. Real-Robot Memory Tasks

RS was tested on seven real-robot task conditions designed to evaluate memory retention and experience utilization, including repeated actions, ordered sequences, object-name alignment, and compositional long-horizon execution. RS was trained on simpler conditions and then evaluated on both familiar and held-out complex tasks.
- **General Performance Improvement:** π₀+RS achieved higher strict success rates in six out of seven conditions compared to base π₀.
- **Long-Horizon Compositional Task (Chenchen-Hard):** On the held-out Chenchen-hard task, which requires retaining object identity and recognizing subgoal completion, success rose from 20% for π₀ to 80% for π₀+RS, a 60-point increase.
- **Counting Tasks:** For repeated-action tasks:
 - Press-2: Improved from 64% to 92%.
 - Press-4: Improved from 20% to 70%.
 - Press-6: Improved from 0% to 60%.
- **Ordering Task:** Order task success improved from 20% to 40%.
- **Occluded Placement:** Improved from 72% to 88%.
- **Short-Horizon Task (Chenchen-Simple):** A slight decrease was observed on Chenchen-S (from 64% to 60%).

#### 4.3. Ablations and Analysis

**Component Contributions (LIBERO Standard Suites):**
- **Visual Mamba Compressor (VMC):** The VMC component alone (π₀+VMC) increased success on the Long-horizon LIBERO suite from 85.2% (π₀) to 92.6%. The overall mean across Spatial, Object, Goal, and Long suites rose from 94.1% to 94.5%.
- **Full Remember Smarter (RS):** Adding the hyperbolic experience memory to VMC (π₀+RS) further increased Long-horizon suite success to 94.2% and the overall mean to 96.2%. This represents a 2.1-point overall improvement over base π₀, with the gains concentrated on long-horizon tasks while maintaining comparable performance on short-horizon suites.

**History Length and Truncated Backpropagation (Mamba Compression):**
- **History Length:** Evaluation on LIBERO-Long showed that Mamba history lengths of 64 and 128 frames yielded similar improvements of approximately 6%-7% in success rate by 20k-25k training steps, outperforming shorter history lengths (8, 16, 32 frames). This suggests that a 64-frame history provides sufficient context for effective compression.
- **TBPTT Truncation Length:** For a fixed 64-frame history, a Truncated Backpropagation Through Time (TBPTT) length of 16 frames resulted in the fastest sustained loss reduction and the lowest training loss at 25k steps. Shorter windows (4, 8) plateaued earlier, while longer windows (24, 32) did not show improved convergence.

### 5. Significance and Potential Impact

The development of Remember Smarter (RS) represents a significant contribution to enhancing the capabilities of Vision-Language-Action (VLA) robot policies, particularly in the context of long-horizon and complex tasks.

The **primary significance** of this work lies in its provision of a **complementary, dual-branch memory architecture** that addresses key limitations of existing VLA models without requiring modifications to the core VLA backbone. This "plug-and-play" characteristic is crucial for practical deployment, allowing pre-trained foundation models to be augmented with advanced memory capabilities.

**Specific impacts and advancements include:**
- **Improved Long-Horizon Task Performance:** The substantial gains observed in LIBERO-Plus (16.9 percentage points total success increase) and especially in real-robot compositional tasks (e.g., 60-point increase on Chenchen-Hard) indicate that RS effectively mitigates the memory fragility of VLA models. This enables robots to execute more complex, multi-step instructions and recover from subtask failures.
- **Efficient Visual History Management:** The Mamba-compressed visual history branch offers an effective solution to the problem of costly and noisy context expansion. By using spatial and temporal Mamba blocks, RS maintains a compact, fixed-shape recurrent state for recent observations. This allows for online updates during inference, removing the need to store or re-process extensive raw visual history, thereby conserving computational resources and token budgets.
- **Structured Experience Retrieval:** The hyperbolic experience space provides a mechanism for organizing and efficiently retrieving reusable patterns from successful past demonstrations. The use of Poincare VAEs, HypHC-inspired hierarchies, and geodesic token generation offers a structured approach to leveraging prior knowledge, which is more scalable and semantically rich than flat memory banks. The asynchronous nature of retrieval further ensures that memory access does not impede real-time action inference.
- **Addressing Robustness Challenges:** The performance improvements across various perturbation dimensions in LIBERO-Plus (camera, robot, language, light, background, noise, layout) suggest that RS contributes to the robustness of VLA policies in varied and challenging environments.
- **Generalizability of Memory Components:** The ablation studies demonstrate the independent value of both the visual compressor and the experience memory. The visual compressor alone provides significant benefits for long-horizon tasks, and the addition of experience memory further enhances performance, particularly in complex scenarios where past successes are relevant.
- **Guidance for Future Memory System Design:** The analysis of Mamba history length and TBPTT truncation parameters provides empirical insights into optimizing recurrent state-space models for robotic memory applications.

In conclusion, Remember Smarter offers a practical and effective framework for endowing VLA-controlled robots with enhanced memory capabilities. Its dual-branch approach, combining efficient online visual history with structured, asynchronously retrieved experience, contributes to the development of more capable and robust robotic systems for real-world long-horizon manipulation tasks.
