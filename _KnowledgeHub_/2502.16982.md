# Muon is Scalable for LLM Training

> [!summary] Summary
> Moonshot AI researchers demonstrate a breakthrough in large language model training efficiency with the Muon optimizer, achieving 2x faster convergence than AdamW while successfully scaling to 16B parameter models and maintaining superior performance across key benchmarks like MMLU and GSM8K.

## Problem

- Traditional optimizers like AdamW face efficiency challenges in large-scale LLM training
- Scaling promising optimization techniques to massive models remains technically challenging
- Distributed training implementations often introduce additional complexity and instability

## Method

- Enhanced ==Muon optimizer== with ==weight decay== and careful parameter update scaling
- Developed efficient distributed implementation compatible with ==ZeRO-1 optimization==
- Built comprehensive training framework demonstrated on ==3B/16B parameter MoE models==

## Results

- Achieved **2x** computational efficiency improvement compared to AdamW
- Successfully trained **3B**/**16B** parameter models with improved benchmark performance
- Demonstrated better weight matrix properties through improved singular value distribution
- Provided open-source implementation and model checkpoints for reproducibility

## Takeaways

> [!tip] Key Insights
> - Matrix orthogonalization techniques can significantly improve training efficiency
> - Proper scaling and implementation choices are crucial for optimizer performance
> - Stable training without loss spikes can be achieved through careful parameter updates
