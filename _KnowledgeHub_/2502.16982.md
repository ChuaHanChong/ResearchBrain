# Muon is Scalable for LLM Training

> [!summary] Summary
> Moonshot AI researchers demonstrate a breakthrough in large language model training efficiency with the Muon optimizer, achieving 2x faster convergence than AdamW while successfully scaling to 16B parameter models and maintaining superior performance across key benchmarks like MMLU and GSM8K.

## Problem

- Traditional optimizers like AdamW face efficiency challenges in large-scale LLM training
- Scaling promising optimization techniques to massive models remains technically challenging
- Distributed training implementations often introduce additional complexity and instability

## Method

- Enhanced ==Muon optimizer== with ==weight decay== and careful parameter update scaling
- Developed efficient distributed implementation compatible with ==ZeRO-1 optimization==
- Built comprehensive training framework demonstrated on ==3B/16B parameter MoE models==

## Results

- Achieved **2x** computational efficiency improvement compared to AdamW while successfully scaling to **3B**/**16B** parameter models with improved benchmark performance
- Demonstrated better weight matrix properties through improved singular value distribution
- Provided open-source implementation and model checkpoints for reproducibility

## Takeaways

> [!tip] Key Insights
> - Matrix orthogonalization techniques can significantly improve training efficiency
> - Proper scaling and implementation choices are crucial for optimizer performance
> - Stable training without loss spikes can be achieved through careful parameter updates

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This work addresses a critical gap in large language model (LLM) training optimization. While the Muon optimizer showed promise in small-scale training, its scalability to large models remained unproven. The research builds upon:
- Recent developments in LLM optimization beyond AdamW
- Prior work on matrix orthogonalization techniques
- Scaling laws for language model training
- Distributed training approaches like ZeRO and Megatron-LM

### 2. Key Objectives and Motivation

The research aimed to:
- Scale up the Muon optimizer for large-scale LLM training
- Resolve implementation challenges in distributed settings
- Validate Muon's effectiveness across different training stages
- Demonstrate computational efficiency improvements over AdamW

### 3. Methodology and Approach

The team employed several key technical innovations:
- Added weight decay and careful parameter update scaling
- Developed a distributed implementation with ZeRO-1 optimization
- Conducted extensive scaling law experiments
- Built and trained a 3B/16B parameter MoE model (Moonlight)
- Performed comprehensive benchmarking against baseline models

### 4. Main Findings and Results

Key discoveries include:
- Muon achieves ~2x computational efficiency vs AdamW
- Successfully scaled to train 3B/16B parameter models
- Improved performance on key benchmarks like MMLU and GSM8K
- Demonstrated stable training without loss spikes
- Showed better singular value distribution in weight matrices

### 5. Significance and Potential Impact

The research presents several important contributions:
- Establishes Muon as a viable replacement for AdamW in large-scale training
- Provides significant computational efficiency improvements
- Opens new directions for optimizer research in LLM training
- Offers open-source implementation and model checkpoints

The work advances both the theoretical understanding of optimization methods and provides practical tools for more efficient LLM training. The released code and models will likely accelerate further research in this direction.

The report effectively demonstrates that Muon can scale to large models while providing significant computational benefits, potentially reducing the resource requirements for training large language models.
