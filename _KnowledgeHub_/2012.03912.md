# MultiON: Benchmarking Semantic Map Memory using Multi-Object Navigation

> [!summary] Summary
> Researchers from IIT Kanpur, Simon Fraser University, and UIUC benchmarked the utility of map-like memory for embodied AI agents in complex visual navigation tasks. They introduced the `multiON` framework to evaluate various agent models, demonstrating that navigation performance significantly degrades with increased task complexity while explicit semantic map representations enhance agent success compared to implicit memory baselines.

## Problem

- Embodied AI agents exhibit brittle performance and high failure rates in long-horizon navigation tasks that require visiting multiple locations.
- A systematic understanding of the specific utility of different map information and the value of egocentrically-acquired maps in varying task complexities was lacking.
- Existing long-horizon navigation benchmarks lacked controlled variation in task difficulty, hindering focused evaluation of memory mechanisms.

## Method

- Proposed `multiON`, a novel task framework requiring agents to navigate an ordered sequence of goal objects in photorealistic 3D environments, allowing systematic control over task complexity.
- Evaluated various agent models—including implicit memory, oracle map, and learned map approaches—under the assumption of perfect localization and map aggregation to isolate map representation benefits.
- Developed learned map agents that either project predicted object categories (`ObjRecogMap`) or neural image features (`ProjNeuralMap`, `EgoMap`) into a global semantic map.

## Results

- Navigation performance, including success rates and efficiency, consistently degraded for all agents as task complexity increased from 1-ON to 3-ON; `OracleMap`'s success rate dropped from **94%** on 1-ON to **48%** on 3-ON tasks.
- Agents leveraging explicit spatial map memory, particularly with object category information, significantly outperformed implicit memory baselines, with `OracleMap` achieving **48%** SUCCESS on 3-ON compared to **10%** for `NoMap(RNN)`.
- A simpler learned semantic map (`ObjRecogMap`) proved competitive, and learned map agents showed increased success (up to +**25%**) when a target goal had been previously encountered, highlighting the utility of storing past observations.

## Takeaways

> [!tip] Key Insights
> - Embodied navigation performance consistently degrades significantly across all agent types as the number of ordered goals in a task increases, even for agents with oracle access to maps.
> - Explicit spatial map memory, especially when enriched with object category information, provides substantial performance advantages over implicit memory systems for multi-object navigation.
> - A relatively simple method for learning to populate semantic maps (`ObjRecogMap`) can be surprisingly effective, sometimes outperforming more complex neural feature projection methods.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of embodied AI has demonstrated substantial progress in visual navigation and related tasks, such as embodied question answering and natural language instruction following. This advancement has been facilitated by the development of photorealistic 3D environments and simulation platforms that enable the training of AI agents. While basic visual navigation tasks have seen near-perfect performance under certain controlled conditions, a critical bottleneck has emerged concerning longer-horizon tasks: agent memory. Existing embodied navigation agents often exhibit brittle performance and high failure rates when the complexity of the navigation path or the number of visited locations increases even modestly.

In response to this challenge, prior research has increasingly incorporated map-like memory structures to enhance performance in extended tasks. These approaches typically focus on methods for constructing maps from partial observations and designing architectures to leverage these map representations. Map-like memories offer advantages such as spatial abstraction, human interpretability, and inductive biases that have been shown to surpass implicit memory architectures in various navigation contexts.

This paper distinguishes itself within this landscape by focusing on a systematic investigation of *what information* in maps is beneficial for navigation and *how much value* egocentrically-acquired maps add, relative to oracle maps or agents without map representations. A key differentiating aspect is the assumption of perfect agent localization and map aggregation. This simplifying assumption allows the researchers to decouple the utility of map representations from the complexities associated with noisy sensing, actuation, and imperfect localization, which are often the focus of other works (e.g., those dealing with Simultaneous Localization and Mapping - SLAM).

Furthermore, the paper introduces a novel task framework, `multiON`, which generalizes existing visual navigation tasks like PointGoal and ObjectGoal. While previous long-horizon tasks, such as multi-target Embodied QA or object search, exist, they often involve fixed object lists or unordered goals within environments that do not allow for controlled variations in task complexity. `multiON` is designed to allow precise control over task difficulty by defining an episode-specific, ordered sequence of goal objects in photorealistic 3D environments. This framework allows for a focused benchmarking of agent models across a spectrum of navigation complexities, specifically addressing the gap in understanding the impact of map memory under varying long-horizon task demands.

### 2. Key Objectives and Motivation

The primary objective of this research is to conduct a controlled and systematic investigation into the utility of map-like memory for embodied AI agents performing visual navigation tasks in photorealistic 3D environments. The authors aim to benchmark the performance of various agent models across a range of navigation task complexities, with a particular focus on understanding the impact and benefits of explicit spatial map representations.

The motivation for this work stems from several observations in the field of embodied AI:
- **Memory as a Bottleneck:** Despite significant advancements in visual navigation, agents struggle with long-horizon tasks that require navigating complex paths or visiting multiple locations. This "brittleness" suggests that current memory mechanisms are insufficient.
- **Prevalence of Map-like Memory:** A growing body of work integrates map-like memory to address this limitation. However, a focused, systematic study on the *impact* of maps, particularly across varying task complexities, has been lacking.
- **Understanding Map Information:** While maps are used, there is a limited understanding of what specific information within a map is most beneficial for core navigation tasks.
- **Benchmarking Map Utility:** The performance of egocentrically-acquired maps (constructed by the agent) relative to oracle maps (ground truth) or implicit memory systems needs to be quantified to establish benchmarks and identify areas for improvement.
- **Controlled Task Complexity:** Existing tasks for long-horizon navigation often have fixed complexities, making it difficult to systematically vary parameters and isolate the effect of memory. A new task framework is needed to precisely control factors like the number and order of goal objects.

To achieve these objectives, the authors make specific design choices:
- **Perfect Localization Assumption:** By assuming perfect agent localization and map aggregation, the study isolates the question of *what* is useful in a map representation from the challenges of dealing with noisy sensing and actuation. This allows for a clearer assessment of the intrinsic value of different map contents and structures.
- **Introduction of `multiON`:** This task framework directly addresses the need for controlled complexity. It generalizes the ObjectGoal navigation task by requiring an agent to navigate to an ordered sequence of semantically distinct objects, allowing the number of goals (`m`) to serve as a direct measure of task difficulty.
- **Focus on Core Navigation:** To avoid confounding factors, the `multiON` task is intentionally designed to be devoid of higher-level understanding, planning, or reasoning elements such as natural language understanding, embodied question answering, or environment interaction. This allows for a cleaner investigation into the impact of map memory on visual navigation alone.

In summary, the key contributions articulated by the authors are:
1. Proposing the `multiON` task framework to enable controlled and systematic investigation of visual navigation in 3D environments.
2. Benchmarking the performance impact of egocentrically-constructed map representations and oracle maps on navigation across a range of task complexities.
3. Demonstrating that agent navigation performance significantly decreases with increased task complexity, that a simple semantic map construction method can outperform more complex neural image feature map agents, and that even oracle map agents achieve relatively modest performance, suggesting significant potential for future research.

### 3. Methodology and Approach

The research introduces the `multiON` task and evaluates various embodied AI agent models on this task using a standard deep reinforcement learning framework.

#### 3.1. The `multiON` Task Definition

An `m-ON` episode requires an agent to navigate to an ordered sequence of `m` specific objects (G) within a realistic 3D environment.
- **Inputs:** At each timestep, the agent receives egocentric RGB and depth sensor images ($o_t$), and a $k$-dimensional one-hot vector ($g_t$) specifying the current goal object. The previous action ($a_{t-1}$) is also provided.
- **Actions:** The agent can perform four actions: `FORWARD`, `TURN-LEFT` (by 30 degrees), `TURN-RIGHT` (by 30 degrees), and `FOUND`. `FORWARD` moves the agent by 0.25m.
- **Goal Progression:** Upon navigating to the vicinity of the current goal object ($G_n$) and executing a `FOUND` action, the goal specification updates to $G_{n+1}$. This continues until all objects are located.
- **Failure Conditions:** An episode fails if `FOUND` is called incorrectly (not near the current goal) or if a maximum number of steps (2,500) is exceeded.
- **Object Specifications:** For this study, objects are randomly sampled without replacement from a set of 8 distinct colored cylinder objects ({red, green, blue, cyan, magenta, yellow, black, white}).
- **Environment:** Experiments are conducted in Matterport3D scenes, partitioned into train/validation/test sets with no scene overlap. Agent start positions and goal locations are randomly sampled from navigable points on the same floor, ensuring a geodesic distance between 2m and 20m from start to first goal, and between successive goals.

#### 3.2. Agent Models

All agents share a base architecture (Figure 1) which processes sensory inputs through a CNN, embeds object goals and previous actions, and uses a Gated Recurrent Unit (GRU) for implicit memory and state representation. An actor-critic pair then predicts actions and values. The key differentiation lies in how global map information is constructed and utilized.

- **Implicit Memory Baselines (No Explicit Map):**
 - `NoMap(RNN)`: Uses the base architecture with only the GRU for implicit memory.
 - `FRMQN` (from Oh et al.): Stores observation embeddings in an LSTM-like memory with soft attention for retrieval.
 - `SMT` (Scene Memory Transformer from Fang et al.): Stores observation embeddings in memory and uses an encoder-decoder network for information retrieval.

- **Oracle Baselines (Ground Truth Maps):**
 - `OracleMap`: Has access to the entire ground truth global map ($M_{GT}$), a 300x300 grid (0.8m cells). Each cell has two 16-dimensional embedding channels: occupancy (navigable, non-navigable, outside scene) and goal object category (k goal categories, plus 'no goal'). Serves as an upper bound for map utility.
 - `OracleEgoMap`: Similar to `OracleMap`, but the global map is progressively revealed based on the agent's egocentric field of view (79 degrees, up to 5m, ray tracing against depth frame). Represents an idealized egocentric mapping agent.

- **Learned Map Agents:**
 - `ObjRecogMap`: Progressively builds a global map by storing predicted categories of goal objects visible in the sensory inputs. An auxiliary $(k+1)$-way classification network predicts the object category in view (or 'no object'). This predicted category's embedding is stored at the agent's current position on the map.
 - `ProjNeuralMap`: Projects neural image features (derived from RGBD) onto an egocentric map using depth-conditioned projection (similar to MapNet). This egocentric map is then registered into a global map ($M_t$) using element-wise max-pooling for feature integration.
 - `EgoMap` (adapted from Beeching et al.): Uses a projection architecture based on MapNet to construct a semantic map, but with an attention-based read mechanism to access information from it.

- **Random Baseline Agents:**
 - `Rand`: Chooses actions uniformly randomly.
 - `Rand+OracleFound`: Randomly navigates, but an 'oracle' calls the `FOUND` action when the agent is within the threshold distance of the current goal.

#### 3.3. Training Details

- **Reward Function:** $r_t = 1_{[\text{reached-goal}]} \cdot r_{goal} + r_{closer} + r_{time-penalty}$. $r_{goal}=3.0$ for successful goal discovery, $r_{closer}$ is the decrease in geodesic distance to the current goal, and $r_{time-penalty}=\alpha=-0.01$ is a negative slack reward.
- **Optimization:** Proximal Policy Optimization (PPO) for 40 million frames, using 16 parallel threads, 4 mini-batches, and 2 epochs per PPO update.
- **Auxiliary Task:** The object recognition network in `ObjRecogMap` is supervised with a cross-entropy loss based on ground truth object categories.

#### 3.4. Metrics

- `SUCCESS`: Binary indicator (1 if all goals found in order and correctly, 0 otherwise).
- `PROGRESS`: Fraction of goal objects successfully found.
- `SPL` (Success weighted by Path Length): $s \cdot d / \max(p, d)$, where $s$ is `SUCCESS`, $p$ is agent's path length, and $d$ is shortest path length through all goals.
- `PPL` (Progress weighted by Path Length): $\bar{s} \cdot \bar{d} / \max(p, \bar{d})$, where $\bar{s}$ is `PROGRESS`, $\bar{d}$ is shortest path length through *found* goals. This is the main metric for partial credit.

### 4. Main Findings and Results

The experiments, conducted on 1-ON, 2-ON, and 3-ON tasks across 18 unseen test scenes, yielded several observations regarding navigation performance and the utility of map memory:

- **Performance Degradation with Task Complexity:**
 - Navigation performance, as measured by PPL, SPL, SUCCESS, and PROGRESS, consistently degrades across all agent models as the task complexity increases from 1-ON to 3-ON. For instance, the `OracleMap` agent's SUCCESS rate drops from 94% (1-ON) to 48% (3-ON), and PPL drops from 77% to 38%.
 - This decline is more pronounced than a simple exponential decay, indicating a significant challenge in maintaining robustness for multi-object, long-horizon tasks.
 - Even `Rand+OracleFound` (random navigation with perfect `FOUND` calls) achieved only 2% success for 3-ON, highlighting the inherent difficulty of the `multiON` tasks.

- **Utility of Spatial Maps:**
 - Agents with access to ground truth maps (`OracleMap`, `OracleEgoMap`) significantly outperform `NoMap` baselines across all metrics and complexities. This indicates that explicit spatial map information is highly beneficial for embodied navigation.
 - For 3-ON, `OracleMap` achieved 48% SUCCESS and 38% SPL, compared to `NoMap(RNN)` at 10% SUCCESS and 4% SPL.
 - Among `NoMap` variants, `FRMQN` performed best, surpassing `SMT`.

- **Importance of Object Category Information in Maps:**
 - Ablation studies showed that object category information within the map is considerably more valuable than just occupancy information. `OracleMap (Obj)` achieved 59% SUCCESS (3-ON) compared to `OracleMap (Occ)` at 16% SUCCESS. This suggests that occupancy, primarily for collision avoidance, can be largely handled by direct depth sensing, while semantic object localization requires explicit mapping.

- **Performance of Learned Map Agents:**
 - The `ObjRecogMap`, which uses a relatively simple approach of learning to project predicted object categories into the map, was surprisingly competitive. It outperformed `ProjNeuralMap` and `EgoMap` for 1-ON and 2-ON tasks.
 - For the most complex 3-ON task, `ProjNeuralMap` and `EgoMap` slightly surpassed `ObjRecogMap` (e.g., `ProjNeuralMap` 27% SUCCESS vs `ObjRecogMap` 22% SUCCESS).
 - The performance of `ProjNeuralMap` and `EgoMap` was very similar, suggesting a limited additional benefit from the attention-based read mechanism in `EgoMap` over simple neural feature projection.
 - Despite their effectiveness, learned map agents (`ObjRecogMap`, `ProjNeuralMap`, `EgoMap`) did not match the performance of `OracleEgoMap`, indicating room for improvement in learned map representations.

- **Ability to Remember Previously Seen Objects (Backtracking Analysis):**
 - Supplemental analysis on 3-ON tasks revealed that agents capable of storing previously observed goal information (`OracleEgoMap`, `ProjNeuralMap`, `ObjRecogMap`) showed a significant increase in success rate when a target goal had been encountered earlier in the episode.
 - `ObjRecogMap` showed the largest gains (+19% for second goal, +25% for third goal when previously seen), followed by `ProjNeuralMap` and `OracleEgoMap`. `NoMap(RNN)` and `OracleMap` (which always has all information) showed minimal or no gains. This confirms the utility of explicit map memory for multi-object tasks requiring potential backtracking or re-visiting areas.

- **Generalization Across Task Complexities:**
 - Agents trained on 1-ON tasks demonstrated poor generalization to more complex `m-ON` tasks. For example, `NoMap(RNN)` trained on 1-ON achieved 62% PROGRESS on 1-ON but only 11% on 3-ON.
 - Conversely, agents trained on 2-ON or 3-ON tasks showed better, though still limited, generalization, particularly when tested on less complex tasks than their training regimen.

### 5. Significance and Potential Impact

This research provides a systematic benchmark and foundational insights into the role of semantic map memory for embodied AI agents in complex, long-horizon visual navigation tasks.

#### 5.1. Significance of Findings

- **Validation of Semantic Maps:** The work unequivocally demonstrates the substantial benefit of semantic map representations for navigation, particularly in multi-object, ordered goal scenarios. This reinforces the importance of incorporating spatial memory into agent architectures.
- **Effectiveness of Simple Semantic Mapping:** The surprising competitive performance of `ObjRecogMap` (simple object category projection) against more complex neural feature projection methods indicates that effective semantic grounding can be achieved with relatively straightforward approaches. This finding can guide future architecture design towards prioritizing clear, interpretable semantic information.
- **Highlighting Current Limitations:** The dramatic drop in performance for all agents, including oracle map agents, as task complexity increases, underscores a critical limitation in current embodied AI. Even with perfect information or idealized egocentric mapping, agents struggle significantly with tasks involving just a few ordered goals. This reveals a gap in the robustness and long-term planning capabilities of existing models.
- **Defining a Challenging Benchmark:** The `multiON` task framework itself is a significant contribution. By offering precise control over task difficulty and focusing on episode-specific, ordered goals in photorealistic environments, it provides a flexible and challenging benchmark for systematically evaluating progress in spatial memory and mapping mechanisms.

**Potential Impact:**
- **Guiding Future Research:** The identified performance gaps—between learned and oracle maps, and the general non-robustness to increased task complexity—point towards promising avenues for future work. This includes developing more sophisticated learned modules for aggregating and integrating egocentric information into map representations, and designing architectures that can better handle long-term planning and memory retrieval for sequences of goals.
- **Advancement in Embodied AI:** By clarifying what information in maps is useful and setting a benchmark for map-based navigation, this research contributes directly to the development of more capable and robust embodied AI agents.
- **Real-world Robotics Applications:** The ultimate goal is to enable robots that can navigate and operate effectively in real-world environments. Improved map memory and navigation capabilities are fundamental for applications such as assisting the elderly, delivering goods, or performing logistics in warehouses. The insights from this simulation-based study are a crucial step towards realizing such practical robotic systems.
- **Ethical Considerations:** The authors responsibly acknowledge the broader societal implications of advanced robotic agents, including potential job displacement and the risks associated with deploying imperfect systems. By studying agent behavior in controlled simulations first, the work contributes to a methodology that prioritizes safety and minimizes risks before real-world deployment.
