# SPARC: Reliable Spatial Annotations from Robot Demonstrations at Scale

> [!summary] Summary
> SPARC is a risk-aware framework that automatically generates structured spatial annotations from robot demonstrations, assigning a continuous reliability score to each. The method achieves 80.2% accuracy for interacted object localization on the new IA-Bench benchmark and leads to significant improvements in downstream embodied spatial reasoning and real-world robot manipulation task success rates.

## Problem

- Automated pipelines for generating spatial annotations from robot demonstrations often lack reliable quality signals, leading to high-confidence but incorrect labels in cluttered scenes.
- The unreliability of existing methods forces a scale-quality tradeoff, where researchers must either accept noisy labels or discard large amounts of potentially useful data.
- Existing alternatives like human review are expensive, and simulation environments suffer from a reality gap, while prior automated methods underutilize rich spatio-temporal and proprioceptive cues.
- There is a lack of benchmarks capable of assessing interacted object identity and its spatio-temporal properties within dynamic robot demonstrations.

## Method

- **SPARC** introduces a three-stage pipeline that decomposes long demonstrations into ==subtasks== using gripper signals and language-based parsing via LLMs, then detects and tracks object candidates.
- It leverages multi-modal signals including phase-aware object motion, 3D gripper proximity, robot-overlap filtering, and appearance-based detector confidence to identify manipulated objects.
- The framework computes a continuous, physically-grounded reliability score by combining these cues, allowing for fine-grained control over annotation quality and enabling selective prediction.
- A new benchmark, IA-Bench, is introduced with 1,748 human-annotated start and target locations across diverse robot demonstrations to evaluate interaction-aware object localization.

## Results

- SPARC achieved an **80.2%** accuracy for interacted object localization on the IA-Bench benchmark, surpassing detection-only baselines by over 22 percentage points (**58.1%**).
- It demonstrated superior quality-coverage tradeoff, retaining **77.6%** of samples at **90%** precision and **58%** at **95%** precision, significantly outperforming baselines that retained only **20%** at **95%** precision.
- VLM models fine-tuned on SPARC-annotated data achieved state-of-the-art grounding performance on several object-grounding and pointing benchmarks, and showed improved scaling behavior over detection-only data.
- Real-world robot policies trained with SPARC annotations more than doubled the success rate (**31%** vs **12%**) compared to policies trained with detection-annotated data in challenging, cluttered tabletop manipulation tasks.

## Takeaways

> [!tip] Key Insights
> - Reframing automatic spatio-temporal annotation as a selective-prediction problem, by combining diverse cues like object motion, gripper proximity, and robot overlap, provides a more robust reliability signal than appearance-based confidence alone.
> - A continuous, calibrated reliability score allows users to explicitly control the tradeoff between annotation quality (precision) and dataset scale (coverage) without manual review.
> - High-quality, spatio-temporally grounded annotations derived from robot interactions are crucial for significantly enhancing embodied spatial reasoning in Vision-Language Models and improving the robustness of real-world robot manipulation policies.
> - Evaluating interaction-aware object localization requires dynamic benchmarks that consider robot proprioception and spatio-temporal properties, which traditional static benchmarks cannot provide.
