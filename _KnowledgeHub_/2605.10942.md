# HarmoWAM: Harmonizing Generalizable and Precise Manipulation via Adaptive World Action Models

> [!summary] Summary
> HarmoWAM introduces a unified World Action Model that resolves the trade-off between generalizable robot movement and precise manipulation by adaptively coordinating a predictive expert and a reactive expert. The framework achieved an 89% average success rate in-domain and maintained an 81% success rate across out-of-domain scenarios with only a 7.9% performance drop.

## Problem

- Existing robotic World Action Models (WAMs) face a fundamental trade-off, struggling to achieve both broad movement generalization and precise manipulation simultaneously.
- "Imagine-then-Execute" WAMs generalize well for transit but lack precision in fine-grained object interaction.
- "Joint Modeling" WAMs offer high precision near target objects but exhibit limited exploration and poor generalization to out-of-domain scenarios.

## Method

- **HarmoWAM** integrates a ==generative world model== with two complementary action experts: a ==predictive expert== for precise actions and a ==reactive expert== for generalizable exploration.
- A ==Process-Adaptive Gating Mechanism== dynamically switches between these experts based on the current task stage (transit or interaction), guided by visual observations.
- The world model provides ==spatio-temporal physical priors==, conditioning the predictive expert with current-step latent features and the reactive expert with future predicted frames and latents.

## Results

- **HarmoWAM** achieved an **89%** average success rate across six in-domain real-world robotic tasks, surpassing existing VLA and WAM baselines.
- The framework demonstrated robust zero-shot generalization to out-of-domain scenarios, experiencing only a **7.9%** average performance drop relative to in-domain success rates.
- Ablation studies confirmed that both the predictive and reactive action experts, along with the Process-Adaptive Gating Mechanism, are essential for HarmoWAM's combined exploration and precision capabilities.

## Takeaways

> [!tip] Key Insights
> - A systematic empirical study revealed a fundamental trade-off in existing WAMs between generalizable transit and precise manipulation, motivating the need for a unified approach.
> - Dynamically coordinating complementary action experts, a predictive one for precision and a reactive one for generalization, allows a single system to address both aspects.
> - Incorporating latent features from a generative world model into both action experts significantly enhances their ability to model physical dynamics and maintain temporal coherence.
