# BUMBLE: Unifying Reasoning and Acting with Vision-Language Models for Building-wide Mobile Manipulation

> [!summary] Summary
> Researchers at The University of Texas at Austin developed BUMBLE, a framework that enables mobile manipulation robots to perform long-horizon tasks across multi-floor buildings. BUMBLE unifies reasoning and acting using vision-language models, a dual-layered memory system, and a diverse skill library, achieving a 47.1% average success rate in real-world building environments, which surpassed existing baselines.

## Problem

- Developing mobile manipulation robots capable of performing complex, long-horizon tasks across diverse, multi-floor building environments.
- Traditional task and motion planning (TAMP) methods struggle with open-world scenarios and require extensive engineering for new environments.
- Existing LLM-based planning approaches lack sufficient visual grounding for effective perception-action coupling in real-world settings.

## Method

- The **BUMBLE** framework ==unifies reasoning and acting== by integrating a ==vision-language model== (GPT-4o) as the central decision-making module.
- A ==dual-layered memory system== tracks execution history and stores valuable experiences to facilitate learning and adaptation.
- A comprehensive ==skill library== (navigation, manipulation, infrastructure interaction) combined with an open-world perception system enables task execution and object interaction in diverse environments.

## Results

- BUMBLE achieved a **47.1%** average task success rate across **70 real-world trials** in three buildings, outperforming COME (**36.2%**) and Inner-Monologue (**17.4%**) baselines.
- Performance scaled with VLM capabilities, reaching an **80.2%** success rate with GPT-4o, compared to **51.8%** with GPT-4o-mini and **65.3%** with Pro-1.5 Gemini.
- Ablation studies demonstrated that Chain-of-Thought reasoning improved success by **25.7%**, Set-of-Mark prompting by **16.9%**, and long-term memory by **10.9%**.

## Takeaways

> [!tip] Key Insights
> - Vision-language models (VLMs) like GPT-4o can serve as central reasoning modules, unifying perception, memory, and motor skills for complex robotic tasks.
> - A dual-layered memory system (short-term for current task history, long-term for past experiences) enables robots to learn from errors and adapt strategies over time.
> - Integrating open-world perception via tools like Grounded-SAM and Set-of-Mark prompting allows robots to recognize and interact with previously unseen objects without predefined models.

## Detailed Report

### 1. Introduction

Mobile manipulation robots capable of operating throughout multi-floor buildings hold enormous potential for various applications, from healthcare and elderly care to office assistance and hospitality. However, developing robots that can perform complex tasks across large-scale environments presents significant challenges that have limited their practical deployment.

The paper "BUMBLE: Unifying Reasoning and Acting with Vision-Language Models for Building-wide Mobile Manipulation" by researchers at The University of Texas at Austin presents a novel framework that enables robots to perform long-horizon tasks across building environments. BUMBLE (Building-wide Unified Mobile manipulation with Bumble LEarning) integrates vision-language models (VLMs) with a comprehensive skill library and dual-layered memory system to provide robots with the reasoning capabilities needed to navigate complex environments and manipulate objects effectively.

### 2. Challenges in Building-wide Mobile Manipulation

Building-wide mobile manipulation presents several key challenges:

1. **Environmental Diversity**: Buildings contain diverse spaces (offices, kitchens, elevators) with varying layouts and objects.
2. **Spatial Scale**: Navigating across multiple floors requires understanding topological relationships and using building infrastructure like elevators.
3. **Interactive Navigation**: Robots must interact with obstacles (pushing chairs, opening doors) to navigate effectively.
4. **Long-horizon Planning**: Tasks often involve multiple steps across different locations, requiring effective subtask decomposition and planning.
5. **Open-world Understanding**: Robots must recognize and interact with previously unseen objects without predefined models.

Traditional approaches to these challenges have relied on task and motion planning (TAMP) with symbolic representations, which struggle to handle open-world scenarios and require extensive engineering for each environment. More recent approaches using large language models (LLMs) for planning lack the visual grounding needed for effective perception-action coupling.

### 3. The BUMBLE Framework

BUMBLE addresses these limitations through a unified framework that integrates four key components:

1. A vision-language model (VLM) serving as the central reasoning module
2. A dual-layered memory system for tracking execution history and storing valuable experiences
3. A diverse skill library for mobile manipulation
4. An open-world perception system enabling visual reasoning

The framework enables robots to:
- Process natural language task instructions
- Decompose complex tasks into executable subtasks
- Select appropriate skills and estimate skill parameters based on visual perception
- Learn from past experiences and failures
- Adapt to new environments and tasks

### 4. Key Components

#### 4.1. Vision-Language Model (VLM)

BUMBLE uses GPT-4o as its core VLM, leveraging its multimodal capabilities to process both visual and textual information. The VLM serves as the central reasoning module, connecting perception, memory, and motor skills. It processes:

- RGB images from the robot's camera
- Depth information via Set-of-Mark (SoM) prompting
- Task instructions in natural language
- Historical information from short and long-term memory
- Available skills and their requirements

#### 4.2. Dual-Layered Memory

BUMBLE implements a dual-layered memory system:

1. **Short-term Memory**: Tracks the robot's execution history within the current task, including:
 - Previous subtasks and their outcomes
 - Successful and failed skill executions
 - Current state and progress toward the goal

2. **Long-term Memory**: Stores valuable experiences from past trials, including:
 - Common failure modes and their solutions
 - Environment-specific knowledge (e.g., elevator button configurations)
 - Successful strategies for similar tasks

This memory system enables the robot to learn from past mistakes and improve performance over time.

#### 4.3. Skill Library

BUMBLE includes a diverse skill library with three categories:

1. **Navigation Skills**:
 - `GoToLandmark`: Navigate to a specific location
 - `NavigateNearObj`: Move near a specified object

2. **Manipulation Skills**:
 - `Pickup`: Grasp and lift an object
 - `PushObjOnGround`: Push objects like chairs
 - `MoveBase`: Adjust the robot's position for better manipulation

3. **Infrastructure Interaction Skills**:
 - `OpenDoor`: Open doors with specified arm and direction
 - `CallElevator`: Press elevator call buttons
 - `UseElevator`: Navigate into and operate elevators

Each skill is parameterized, allowing the VLM to specify execution details based on the current scene.

#### 4.4. Open-World Perception

BUMBLE's perception system enables reasoning about open-world scenes through:

- RGB-D camera input for visual understanding
- Grounded-SAM (GSAM) for open-vocabulary object segmentation
- Set-of-Mark (SoM) prompting to convey depth information to the VLM
- Point cloud processing for spatial understanding

This perception system allows the robot to recognize and interact with previously unseen objects without requiring pre-defined models.

### 5. Decision Making Process

BUMBLE's decision-making process consists of two main steps:

1. **Subtask Prediction and Skill Selection**:
 The VLM processes visual information, task instructions, and memory to:
 - Predict the next subtask to accomplish
 - Select the appropriate skill from the library
 - Use Chain-of-Thought (CoT) reasoning to improve accuracy

2. **Skill Parameter Estimation**:
 The VLM then estimates parameters for the selected skill by:
 - Analyzing the visual scene for relevant objects
 - Incorporating depth information via SoM prompting
 - Considering past experiences from long-term memory
 - Using CoT reasoning to improve parameter accuracy

The robot executes the skill with the estimated parameters and updates its memory based on the outcome.

### 6. Experimental Evaluation

The researchers evaluated BUMBLE using a Tiago mobile manipulator robot in real-world building environments across three different buildings. The experiments included:

1. **Task Types**:
 - Object retrieval (e.g., "Find a diet soda")
 - Chair rearrangement (e.g., "Make the reception area more welcoming")
 - Tasks requiring multi-floor navigation using elevators

2. **Experimental Setup**:
 - 70 total trials across 3 buildings
 - Random initial positions and obstacles
 - Various distractors to test robustness
 - Comparison against baseline methods (Inner-Monologue and COME)

3. **Evaluation Metrics**:
 - Task success rate
 - Subtask prediction accuracy
 - Skill parameter estimation accuracy
 - Human preference (through user studies)

### 7. Results and Performance

BUMBLE demonstrated strong performance across the experiments:

1. **Overall Success Rate**:
 - BUMBLE: 47.1% average success rate
 - COME baseline: 36.2%
 - Inner-Monologue baseline: 17.4%

2. **VLM Scaling**:
 BUMBLE's performance scaled with VLM capabilities, with success rates improving as more capable models were used:
 - GPT-4o: 80.2% success rate
 - GPT-4o-mini: 51.8%
 - Pro-1.5 Gemini: 65.3%

3. **Ablation Studies**:
 - Chain-of-Thought reasoning improved success rate by 25.7%
 - Set-of-Mark prompting improved success rate by 16.9%
 - Long-term memory improved success rate by 10.9%

4. **User Study**:
 - 59% of human participants preferred BUMBLE's decisions over the COME baseline
 - BUMBLE received higher Likert ratings for decision quality

### 8. Failure Analysis

The researchers conducted a detailed analysis of failure modes to understand BUMBLE's limitations:

Key failure causes included:

1. **VLM Reasoning Errors (28/70 trials)**:
 - Incorrect subtask prediction
 - Poor skill parameter estimation
 - Failure to leverage past experiences

2. **Manipulation Challenges (11/70 trials)**:
 - Difficulties adjusting the robot base for optimal object reachability
 - Incorrect object selection for manipulation

3. **Perception Issues (10/70 trials)**:
 - Bad depth values
 - GSAM segmentation errors
 - Objects outside the field of view

4. **Navigation Problems (8/70 trials)**:
 - Collisions with the environment
 - Incorrect interaction with building infrastructure

### 9. Comparative Advantages

BUMBLE offers several advantages over existing approaches:

1. **Unified Reasoning Framework**:
 Unlike approaches that separate planning and execution, BUMBLE integrates perception, reasoning, and action through the VLM.

2. **Open-World Understanding**:
 Traditional TAMP approaches require predefined symbolic representations, while BUMBLE can recognize and interact with previously unseen objects.

3. **Learning from Experience**:
 The dual-layered memory system allows BUMBLE to improve performance over time by learning from past successes and failures.

4. **Building-wide Operation**:
 Many existing approaches focus on single rooms or confined spaces, while BUMBLE can operate across multiple floors and navigate building infrastructure.

5. **Natural Language Instruction**:
 BUMBLE can process natural language instructions, making it more accessible to non-expert users.

### 10. Limitations and Future Work

Despite its strengths, BUMBLE has several limitations:

1. **Perception Challenges**:
 - Limited field of view affects scene understanding
 - Depth estimation errors impact skill parameter estimation
 - GSAM sometimes fails to segment objects correctly

2. **Manipulation Capabilities**:
 - Limited dexterity of the robot arm
 - Challenges with precise object manipulation
 - Difficulties with fine-grained actions like opening drawers

3. **VLM Limitations**:
 - Occasional hallucination of non-existent objects
 - Reasoning errors in complex scenarios
 - Computational demands of running VLMs on robots

Future work directions include:
- Expanding the skill library for more complex tasks
- Improving perception through multi-view integration
- Enhancing the memory system for better generalization
- Developing more efficient VLM prompting strategies

### 11. Conclusion

BUMBLE represents a significant advancement in building-wide mobile manipulation by unifying reasoning and acting through vision-language models. Its integration of open-world perception, dual-layered memory, and a comprehensive skill library enables robots to perform complex tasks across large-scale environments without requiring environment-specific engineering.

The framework's ability to process natural language instructions, learn from experience, and leverage the continuously improving capabilities of vision-language models makes it a promising approach for developing service robots that can operate effectively in human-inhabited spaces. While challenges remain, particularly in perception and manipulation, BUMBLE demonstrates how vision-language models can bridge the gap between high-level reasoning and low-level action in complex robotic systems.
