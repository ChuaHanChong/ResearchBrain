# BUMBLE: Unifying Reasoning and Acting with Vision-Language Models for Building-wide Mobile Manipulation

> [!summary] Summary
> Researchers at The University of Texas at Austin developed BUMBLE, a framework that enables mobile manipulation robots to perform long-horizon tasks across multi-floor buildings. BUMBLE unifies reasoning and acting using vision-language models, a dual-layered memory system, and a diverse skill library, achieving a 47.1% average success rate in real-world building environments, which surpassed existing baselines.

## Problem

- Developing mobile manipulation robots capable of performing complex, long-horizon tasks across diverse, multi-floor building environments.
- Traditional task and motion planning (TAMP) methods struggle with open-world scenarios and require extensive engineering for new environments.
- Existing LLM-based planning approaches lack sufficient visual grounding for effective perception-action coupling in real-world settings.

## Method

- The **BUMBLE** framework ==unifies reasoning and acting== by integrating a ==vision-language model== (GPT-4o) as the central decision-making module.
- A ==dual-layered memory system== tracks execution history and stores valuable experiences to facilitate learning and adaptation.
- A comprehensive ==skill library== (navigation, manipulation, infrastructure interaction) combined with an open-world perception system enables task execution and object interaction in diverse environments.

## Results

- BUMBLE achieved a **47.1%** average task success rate across **70 real-world trials** in three buildings, outperforming COME (**36.2%**) and Inner-Monologue (**17.4%**) baselines.
- Performance scaled with VLM capabilities, reaching an **80.2%** success rate with GPT-4o, compared to **51.8%** with GPT-4o-mini and **65.3%** with Pro-1.5 Gemini.
- Ablation studies demonstrated that Chain-of-Thought reasoning improved success by **25.7%**, Set-of-Mark prompting by **16.9%**, and long-term memory by **10.9%**.

## Takeaways

> [!tip] Key Insights
> - Vision-language models (VLMs) like GPT-4o can serve as central reasoning modules, unifying perception, memory, and motor skills for complex robotic tasks.
> - A dual-layered memory system (short-term for current task history, long-term for past experiences) enables robots to learn from errors and adapt strategies over time.
> - Integrating open-world perception via tools like Grounded-SAM and Set-of-Mark prompting allows robots to recognize and interact with previously unseen objects without predefined models.
