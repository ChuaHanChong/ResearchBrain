# Minimal Recurrent Behavioral Memory for Imitation under Partial Observability

> [!summary] Summary
> This paper characterizes the least recurrent memory an imitator needs under partial observability. A compatibility relation defines the exact target: distinctions that must persist because future observations will not restore them before use. A discrete sole-carrier recurrent policy, trained with annealed event-agnostic future-behavior supervision, realizes it. Learned code rates match certified zero- and two-bit requirements up to 512 hidden modes, and lift held-out pixel success from 0.08 to 0.57.

## Problem

- Prior targets such as predictive states, bisimulation and system identification preserve future observations, dynamics or hidden parameters, keeping distinctions a specified expert treats identically.
- The instantaneous conditional entropy of the behavioral quotient ignores recurrence, so it never says which distinctions must persist across intervals with no new reveal.
- Plain training of compact recurrent codes degrades with temporal distance and memory load, and matching a full-history teacher's internal state fails to expose pending classes.

## Method

- ==Behavioral memory compatibility== defines the recurrent target; under transitivity its classes attain the exact minimum conditional entropy, and the general case is entropy minimization over closed compatible state assignments.
- A ==sole-carrier measurement protocol== plus a ==backward-refinement solver== certifies requirements, checks sufficiency before minimality, and attributes bits using leak, body-memory and matched-side-information probes.
- The **DIACRITIC** realization uses ==residual proposal==, hard ==nearest-code quantization==, ==straight-through gradients== and a ==conditional-prior rate penalty==, with an ==event-agnostic future-behavior head== annealed to zero.

## Results

- Task A has a zero-bit grasp requirement: **8/8** sufficient seeds at every hidden-mode count 4 to 512, grasp rate **0.00** to **0.10 bit**, closed-loop success **0.91** to **0.99**.
- Readout-2 keeps a two-bit first-gap requirement while full-history information grows **6** to **10 bits**; learned rates stay near **2 bits** with success **0.85** to **0.96**.
- On pixel inputs the annealed event-agnostic learner reaches **2.00** then **1.13 bits**, **13/16** sufficient seeds and **0.65** success, versus **1/16** and **0.14** for plain training.

## Takeaways

> [!tip] Key Insights
> - Memory requirements are time-varying: a distinction expires after its last behavioral use, or earlier if a future observation restores it before use.
> - Acquisition and minimality answer to different signals; predictive supervision helps a code commit but adds surplus that only rate pressure after annealing removes.
> - Never judge memory by code rate or task success alone; a persistent hidden state or the robot's own pose can silently carry the history.

## Detailed Report

### 1. Overview

A robot sees a grasp-side cue and a placement-slot cue, then waits, grasps, waits again, and places. During the waits its action can be the same regardless of either cue, yet it may need to carry both cues forward. After grasping, it needs only the placement information. The authors ask what past differences must survive so the policy can still behave like its expert as new observations arrive, crediting observations that restore a distinction before it is needed. In their task A′, the answer is a certified staircase: the recurrent-memory requirement falls from two bits to one to zero.

Paper Figure 1. The upper diagram runs from history to a current class, which holds distinctions needed for the present action. It also shows a behavioral-memory class, which holds distinctions that must persist given future observations. Both lead to a learned code labeled sole carrier. The lower A′ timeline runs cue → wait → first grasp → wait → first place → done. Its recurrent-memory row reads 2, 2, 1, 1, 0 bits, and its instantaneous-behavior row reads 0, 1, 0, 1, 0 bits. The annotation about a class re-observed before use refers to a separate re-reveal toy, not an event in A′.

### 2. From current behavior to recurrent need

A current-action measure groups states that share the same current observation and expert action distribution. In A′, the instantaneous requirement during both waits is zero, because the current expert action is identical across cue values. The recurrent requirement is different. The paper calls histories *compatible* when they imply the same current behavior and remain behaviorally indistinguishable under every continuation reachable from both. Histories need to agree only on continuations reachable from both, since a later observation can restore a distinction before it is used.

Under transitivity, the compatibility classes are the exact minimum-memory recurrent representation among zero-distortion realizations. If compatibility is non-transitive, those classes need not define the minimum. The general target is instead an entropy-minimizing, closed compatible assignment. For that case the authors give exact solutions for small instances and matching certificates for finite corridor instances, not a general efficient solver.

In A′, two independent binary labels, one for grasp and one for placement, jointly require four memory states during the first wait. After the grasp, only the placement bit remains. A bit here is the conditional entropy of the needed behavioral distinction given the current symbolic observation. It is not codebook capacity, bytes of hardware storage, or a universal continuous-control requirement.

### 3. When training can find it

A compact recurrent code must retain a pending distinction across a long interval, even when ordinary imitation loss gives little reason to expose it before use. The authors call this the problem of *commitment*.

Their intervention works at training time. It samples a future offset and trains an auxiliary head on the code to predict a causal forecaster's future-action estimate. No latent labels or event annotations enter the objective, and the forecaster and head are removed at evaluation.

Measured rates count only if the code is sufficient. A seed passes the empirical gate when normalized sufficiency scores exceed 0.9 at the specified positive-requirement steps. This gate is a diagnostic, not proof of exact zero distortion.

Paper Table 1. The table reports full-gate sufficient seeds out of eight at gap 6, gap 10, gap 20, M=16 and M=32. Event-agnostic future behavior reaches 8/8, 7/8, 8/8, 6/8, 7/8, and teacher internal state reaches 2/8, 0/8, 0/8, 0/8, 1/8. Event-agnostic all-seed closed-loop success is .99.87.90.79.93. The teacher-state comparison is a training-target control, not a proof that the teacher's internal state is intrinsically inadequate.

Matching a full-history teacher's internal state yielded only 0–2/8 sufficient seeds across the tested A′ settings. Event-agnostic supervision yielded 36/40 over its five settings. This points to long-range training signal as an important bottleneck, but does not identify a unique optimization mechanism.

With pixels at A′ gap 20, the authors held out seeds for testing. The 60%-annealing schedule was selected on seeds 0–7 and then tested unchanged on seeds 8–15. On those held-out seeds, event-agnostic supervision passes the gate on 6/8 seeds, versus 0/8 for plain training. All-seed closed-loop success is 0.57 versus 0.08. Grasp-side accuracy is high for all learners, so the difference concerns the later placement. Pixel control precision still limits task success.

### 4. What this establishes

The paper replaces "what changes the present action" with "what must survive until a later decision that observations cannot restore." Under transitive compatibility, this yields an exact minimum, and in A′ it is certified at 2 → 1 → 0 bits. The learning results show that defining this boundary and acquiring it are separate problems. In the tested settings, supervision can help commitment, while annealing can let the rate objective reduce predictive surplus. These results are evidence that the target can be learned in tested settings, not a guarantee for longer horizons.
