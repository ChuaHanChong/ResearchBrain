# Memory Attention

> [!summary] Summary
> Memory Attention (MA) removes attention's dedicated value projection and instead builds values as V = K + Norm(M), where M is a layer-specific token-indexed memory table looked up by token ID. Keys supply context, memory supplies token-specific content. At inference normalization folds into the tables, leaving lookup plus addition, and tables can sit on CPU with prefetching. MA improved perplexity, downstream average, and needle retrieval at matched token budgets.

## Problem

- Standard attention derives values from contextual hidden states via a dense projection, even though part of that content may be token-specific and reusable across contexts.
- Prior lookup-based capacity methods such as value embeddings, per-layer embeddings and n-gram memory only supplement existing computation rather than replacing any of it.
- Growing model capacity through dense projections raises GPU parameter storage and arithmetic proportionally, leaving limited headroom under fixed compute and memory budgets.

## Method

- ==Memory-based value construction==: each layer holds a vocabulary-sized table, ==RMSNorm== applied per key/value head to retrieved rows, added to pre-RoPE keys to form values, dropping the value projection entirely.
- ==Inference-time norm folding== rewrites every table row through RMSNorm offline, so online value construction is just embedding lookup plus element-wise addition instead of a matrix multiply.
- **MA-Offload** keeps folded tables in CPU memory and prefetches rows by token ID and layer index, overlapping retrieval and host-to-device transfer with layer computation; **MA-Recall** analyzes rebuilding values from cached keys.

## Results

- At 24 layers and hidden size 1,024 on **10B** tokens, WikiText perplexity fell **31.55** to **28.64** for MHA; downstream average rose **0.71** points for MHA, **0.61** for GQA, **1.16** at hidden size 2,048.
- Single-needle retrieval improved on all nine task-length cells: mean **96.8%** versus **82.1%** at 2K, and **41.9%** versus **25.9%** at 4K, which is twice the 2K training window.
- MA-Offload held **2.08x** the total parameters while cutting GPU parameter storage **55.45%** versus GPU-resident MA and **7.38%** versus standard, with decode latency **17.189 ms** versus **17.636 ms**.

## Takeaways

> [!tip] Key Insights
> - Keys already carry enough contextual signal to double as the contextual part of values, so a dedicated value projection is not architecturally necessary.
> - Addresses that depend only on token IDs and layer indices make memory prefetchable, turning added parameter capacity into CPU-resident storage rather than GPU pressure.
> - Gains here confound structure with roughly 2x parameter capacity, and reduced value-construction FLOPs did not translate into consistent latency wins.

## Detailed Report

### 1. Position Within the Broader Research Landscape

This work addresses the problem of increasing language-model capacity without proportionally increasing dense computation or GPU memory requirements. In conventional Transformer attention, queries, keys, and values are all generated from contextual hidden states using learned linear projections. The value projection is responsible for transforming each token’s contextual representation into the content that attention aggregates. Although effective, this projection introduces a dense matrix multiplication at every layer and token.

The paper situates its proposal within a recent line of research on lookup-based or memory-augmented representations. Methods such as Value Embeddings, Per-Layer Embeddings, STEM, DeepEmbed, and Engram add learned token- or pattern-indexed information to neural representations. These approaches generally supplement existing computation. Memory Attention (MA) instead asks whether a learned memory can replace one component of the standard attention computation, specifically the dedicated value projection.

MA is also related conceptually to Multi-head Latent Attention (MLA), because both use a representation that contributes to both attention scoring and content aggregation. However, the paper does not claim that MA is algebraically equivalent to MLA. MLA applies a learned value transformation to a shared latent representation, whereas MA directly aggregates contextual keys and adds token-indexed memory to them.

The work also intersects with systems research on parameter offloading. Since MA’s memory entries are addressed using token IDs rather than dynamically generated activations, they can potentially be retrieved in advance and stored outside GPU memory. The proposed MA-Offload variant therefore connects architectural changes in attention with CPU memory, host-to-device transfer, and prefetching strategies.

### 2. Objectives and Motivation

The primary objective is to determine whether token-specific memory can replace the standard value projection while retaining the contextual information needed for language modeling. The central hypothesis is that the two sources of information serve complementary functions:

1. **Token-indexed memory** can provide representations associated with individual vocabulary items. These representations are reusable across contexts and can encode stable token-specific information.
2. **Contextual keys** can provide information derived from the current hidden states, including local and broader context and the intermediate computations accumulated in earlier layers.

The proposed value representation is therefore:

\[
V = K + \operatorname{Norm}(M),
\]

where \(K\) is the contextual key representation and \(M\) is retrieved from a layer-specific memory table using token IDs. In standard attention, values are generated independently through \(V = XW_V\). MA removes \(W_V\), reuses the key projection, and adds a memory vector.

A second objective is to examine the computational consequences of this replacement. Dense value projections require matrix multiplications, whereas MA requires memory lookup, normalization during training, and addition. At inference, the normalization can be folded into the memory table in advance, leaving only lookup and element-wise addition.

A third objective is to investigate whether the token-indexed structure permits greater parameter capacity without placing all parameters on the GPU. MA-Offload stores the folded memory tables in CPU memory and prefetches entries for upcoming layers. The paper also introduces MA-Recall as a proposed extension that reconstructs historical values from cached keys and token IDs, potentially reducing key-value cache storage. MA-Recall is analyzed theoretically but not included in the reported inference measurements.

### 3. Methodology and Approach

#### 3.1. Memory Attention Formulation

For a sequence with hidden states \(X\) and token IDs \(s\), the model computes queries and keys in the usual manner:

\[
Q = XW_Q,\qquad K = XW_K.
\]

Each MA layer contains its own memory table:

\[
E \in \mathbb{R}^{N \times d_v},
\]

where \(N\) is the vocabulary size and \(d_v\) is the combined dimension of the key/value heads. For every token position, the model retrieves the corresponding row:

\[
M = \operatorname{Norm}(E[s]).
\]

RMSNorm is applied independently within each key/value head. The value representation is then formed as:

\[
V = K + M.
\]

The attention weights remain standard:

\[
\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+C\right),
\]

with a causal mask \(C\). With rotary positional embeddings, RoPE is applied to queries and keys used for scoring, while values are constructed from the unrotated keys and memory vectors. This preserves the usual attention aggregation mechanism while changing only value construction.

The memory tables are independent across layers, so the same vocabulary token can have a distinct stored representation at every depth. Query heads that share a key/value head also share the corresponding memory contribution.

#### 3.2. Computational and Storage Analysis

The paper compares MA with standard attention across \(L\) replaced layers. Standard attention contains \(Ldd_v\) value-projection parameters, where \(d\) is the hidden dimension. MA replaces these with approximately \(LNd_v\) memory parameters, plus normalization parameters. Because vocabulary size \(N\) is generally much larger than hidden size \(d\), MA increases total parameter capacity.

During training, standard value construction requires a dense projection and associated forward and backward operations. MA removes that projection but introduces normalization, lookup, addition, and gradient accumulation for accessed memory entries. The paper estimates lower arithmetic for value construction, while noting that lookup and optimizer-related costs are not fully captured by the FLOP comparison.

At inference, normalization is folded into the table:

\[
E[i] \leftarrow \operatorname{Norm}(E[i]).
\]

Online value construction then becomes:

\[
V = K + E[s].
\]

This reduces arithmetic but does not necessarily reduce latency, because memory access, synchronization, and kernel efficiency may dominate.

#### 3.3. MA-Offload and MA-Recall

MA-Offload places memory tables in CPU memory and transfers only the entries required by the current tokens. Since token IDs and layer indices are known before the corresponding hidden states are computed, retrieval and transfer can be prefetched and overlapped with model computation.

MA-Recall proposes avoiding a persistent value cache by retaining historical keys and token IDs. Historical values can then be reconstructed as:

\[
V_{1:T} = K_{1:T} + E[s_{1:T}].
\]

For equal key and value dimensions, retaining only one key representation rather than both keys and values could reduce the corresponding cache component by approximately 50 percent. This benefit would be offset by repeated memory retrieval, addition, and potentially positional transformations. The paper does not measure this extension experimentally.

#### 3.4. Experimental Design

The authors train Transformer language models using NVIDIA H800 GPUs and the flash-linear-attention framework. The backbone uses 24 layers, gated MLPs, RoPE, and RMSNorm. Models are trained on FineWeb-10BT with AdamW, a peak learning rate of \(3 \times 10^{-4}\), 1,024 warmup steps, cosine decay, gradient clipping at 1.0, and a sequence length of 2,048 tokens. Standard and MA models use the same training settings and random seed within each comparison.

Experiments cover multi-head attention (MHA), grouped-query attention (GQA), multi-query attention (MQA), and a gated attention configuration. Smaller models use hidden size 1,024 and approximately 10 billion training tokens. A larger MHA configuration uses hidden size 2,048 and approximately 20 billion training tokens.

Evaluation includes LAMBADA and WikiText perplexity, LAMBADA word-prediction accuracy, and seven zero-shot downstream accuracy benchmarks: ARC-Easy, ARC-Challenge, HellaSwag, PIQA, WinoGrande, and OpenBookQA. Retrieval is evaluated using three single-needle “Needle in a Haystack” tasks at 1,024, 2,048, and 4,096 tokens. Inference tests compare standard attention, GPU-resident MA, and CPU-offloaded MA under prefill and decoding workloads.

### 4. Main Findings and Results

#### 4.1. Language Modeling and Downstream Tasks

MA improves both reported perplexity measures in every attention configuration. For the smaller MHA model, LAMBADA perplexity decreases from 44.35 to 42.78, while WikiText perplexity decreases from 31.55 to 28.64. The corresponding average downstream score increases from 40.68 to 41.39 percentage points.

For GQA, LAMBADA perplexity falls from 50.46 to 43.68 and WikiText perplexity from 31.71 to 29.45. The average downstream score increases from 40.90 to 41.51. For MQA, the average increases from 41.11 to 41.34, with LAMBADA perplexity improving from 50.38 to 45.93. The gated configuration shows an average increase from 41.40 to 42.88 and reductions in both perplexity measures.

The larger MHA model also improves, although the perplexity changes are smaller: LAMBADA decreases from 18.59 to 18.15 and WikiText from 21.52 to 20.79. The average downstream score rises from 49.06 to 50.22. Gains are uneven across tasks. For example, OpenBookQA and ARC-Challenge improve at the larger scale, while ARC-Easy and PIQA decline slightly.

MA models contain substantially more parameters. In the smaller MHA comparison, the standard model has 373 million parameters and MA has 1.135 billion. In the larger MHA comparison, the counts are 1.364 billion and 2.836 billion, respectively. Consequently, the results demonstrate the effectiveness of the combined architecture and increased capacity, but they do not establish that MA itself is superior to a parameter-matched alternative.

#### 4.2. Retrieval

MA outperforms the standard baseline on all nine single-needle retrieval task-length combinations. Within the 2,048-token training context, mean scores are 97.4 percent versus 82.6 percent at 1,024 tokens and 96.8 percent versus 82.1 percent at 2,048 tokens.

At 4,096 tokens, twice the training context length, MA achieves a mean score of 41.9 percent compared with 25.9 percent for the baseline. Both models degrade substantially under extrapolation, so the results indicate improved performance on these evaluated retrieval tasks rather than reliable long-context generalization in general.

#### 4.3. Training and Inference Efficiency

At selected matched-loss points, MA requires fewer training tokens than the baseline. Reported token-efficiency ratios are 1.42 for the 1,024-dimensional model and 1.16 for the 2,048-dimensional model, corresponding to approximately 29.6 percent and 13.8 percent fewer tokens. These measurements are not wall-clock speed comparisons.

For the larger reference model, reported training computation is 934 TFLOPs for MA versus 525 TFLOPs for the baseline, reflecting the larger model and additional memory parameters. Thus, lower value-construction arithmetic does not imply lower total training cost.

GPU-resident MA has a prefill latency of 88.202 ms versus 90.970 ms for standard attention, but decode latency is slightly higher: 17.788 ms versus 17.636 ms. MA-Offload records 90.686 ms for prefill and 17.189 ms for decoding in the reported workload. The memory tables increase total parameters from 1.364 billion to 2.836 billion, but offloading moves approximately 1.573 billion parameters, or 3,000 MiB at BF16 precision, to CPU memory. GPU parameter storage falls from 5,410 MiB for MA to 2,410 MiB for MA-Offload, slightly below the standard model’s 2,602 MiB.

### 5. Significance and Potential Impact

The paper presents a design in which learned token memory replaces, rather than supplements, the value projection in attention. Its main significance is architectural: it explores a trade-off between dense computation and lookup-based parameter capacity while preserving ordinary attention weights and aggregation.

If the reported behavior generalizes, MA could be relevant to language models constrained by dense compute, GPU parameter capacity, or both. CPU offloading may allow models to retain larger token-indexed tables without requiring equivalent GPU residency. MA-Recall could also provide a route to reducing persistent value-cache storage, although its practical costs remain unmeasured.

Several limitations qualify the conclusions. MA models have more parameters than their baselines, and no parameter-matched control isolates the effect of key reuse and memory addition from increased capacity. The retrieval tests use a limited synthetic-style benchmark and only extend to twice the training context. Offloading measurements are prototype, workload-specific forward-pass timings that exclude some serving costs, including token-ID transfers, initialization, sampling, and transfer buffers. Finally, MA-Recall is conceptual in this study rather than experimentally validated.

Overall, the work contributes an alternative attention parameterization and a corresponding systems strategy. Its results support further investigation of memory-based value construction, especially through capacity-matched ablations, broader model scales, end-to-end serving measurements, and direct evaluation of cache reconstruction.
