# ToRL: Scaling Tool-Integrated RL

> [!summary] Summary
> The paper "TORL: Scaling Tool-Integrated RL" introduces a framework for training large language models (LLMs) to autonomously use computational tools by scaling reinforcement learning directly from base models. The TORL framework consistently improves mathematical reasoning across benchmarks, achieving up to a 14.7% absolute accuracy gain for a 7B model compared to SFT-based baselines, and enables emergent behaviors like self-correction and reflection.

## Problem

- Large language models (LLMs) struggle with precise computation and symbolic manipulation, necessitating external tools despite their advanced natural language reasoning.
- Existing Tool-Integrated Reasoning (TIR) approaches rely on supervised fine-tuning (SFT), which limits the model's exploration and ability to discover optimal or novel tool usage strategies.
- The implementation transparency of some prior reinforcement learning (RL) applications to tool use has been limited, hindering community understanding and reproducibility.

## Method

- The paper introduces ==TORL==, a framework that integrates a ==code interpreter== directly into a reinforcement learning environment, enabling LLMs to learn tool utilization from base models without prior supervised fine-tuning.
- It utilizes a high-quality mathematical dataset constructed through ==reinforcement learning data distillation (LIMR)== and adopts an iterative ==Tool-Integrated Reasoning (TIR)== paradigm for problem-solving.
- The framework employs the ==GRPO algorithm== within the veRL framework, uses Qwen-2.5-Math models as foundational LLMs, and feeds code execution error messages back to the LLM to enhance code generation.

## Results

- TORL-1.5B achieved an average accuracy of **48.5%** on mathematical benchmarks, marking an absolute **7.2%** improvement over the SFT-based TIR baseline (Qwen2.5-Math-1.5B-Instruct-TIR).
- TORL-7B attained an impressive **62.1%** average accuracy, outperforming other open-source models on the same base by **14.7%** absolute, and reached **43.3%** on AIME24, comparable to some **32B** models.
- The model demonstrated emergent cognitive behaviors, including self-regulation (correcting code based on error messages) and reflection (cross-validating analytical reasoning with tool outputs and making corrections).

## Takeaways

> [!tip] Key Insights
> - Sophisticated tool-augmented reasoning capabilities, including strategic tool invocation and error recovery, can emerge in LLMs purely through reward-driven learning from base models, without prior supervised fine-tuning.
> - The model autonomously learns to generate code more frequently, correctly, and effectively over training, demonstrating an increased pass ratio and purposeful code use.
> - While increasing the maximum number of allowed tool calls per problem can enhance performance, it substantially reduces training efficiency due to increased GPU idle time, highlighting an important trade-off.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of Large Language Models (LLMs) has witnessed remarkable progress in recent years, particularly in their ability to perform complex reasoning tasks. This advancement has been significantly propelled by reinforcement learning (RL) techniques, as evidenced by proprietary models like o1, R1, and Kimi, which exhibit emergent capabilities such as backtracking, self-correction, and reflection. Concurrently, numerous open-source initiatives are exploring similar promising avenues.

Historically, LLMs have relied on pure natural language approaches, such as Chain-of-Thought (CoT) prompting, to perform reasoning. While effective for many tasks, CoT struggles with scenarios demanding precise computation, equation solving, or other processes requiring external, executable tools. This limitation has spurred research into Tool-Integrated Reasoning (TIR), which enables LLMs to invoke external computational tools by generating and executing code through interpreters. Prominent examples of TIR implementations include ToRA, MathCoder, and Qwen2.5-Math-Instruct-TIR, which have shown considerable success in enhancing mathematical problem-solving.

However, existing TIR approaches typically face two critical limitations that TORL aims to address. Firstly, most prior work primarily relies on Supervised Fine-Tuning (SFT), where models are trained by distilling trajectories from stronger, often human-curated, models. This SFT-based approach restricts the model's ability to explore novel or optimal strategies for tool utilization, confining it to predetermined usage patterns. Secondly, while some research, such as Qwen-Math, has applied RL to SFT-trained models, the transparency and detail of their implementation within an RL framework have often been limited, making it difficult for the broader community to understand and build upon.

TORL directly tackles these challenges by introducing a framework for scaling reinforcement learning *directly from base models*, meaning models that have not undergone prior supervised fine-tuning for tool use. This distinguishes TORL from its predecessors, as it empowers models to discover optimal strategies for tool invocation and integration through unrestricted, reward-driven exploration. By starting with a "blank slate" (a base model) and allowing RL to sculpt tool-use behaviors, TORL promises to yield qualitatively different and potentially more robust emergent cognitive capabilities compared to methods that incrementally refine pre-aligned models. This work thus represents a significant step towards enabling more autonomous and adaptable LLM agents capable of leveraging external tools effectively.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop **TORL (Tool-Integrated Reinforcement Learning)**, a framework designed to train large language models (LLMs) to autonomously utilize computational tools by scaling reinforcement learning directly from *base models*—that is, models without any prior post-training for tool use.

The motivation behind TORL stems from the critical limitations observed in the existing landscape of LLM reasoning and tool integration:
1. **Bridging the Computational Gap:** Traditional natural language reasoning methods, like Chain-of-Thought (CoT), often fall short when tasks require precise computation, complex equation solving, or exhaustive enumeration. LLMs, despite their advanced reasoning capabilities, are inherently poor at arithmetic and symbolic manipulation. Tools like code interpreters are essential to overcome these intrinsic limitations.
2. **Overcoming SFT-based Limitations:** Previous Tool-Integrated Reasoning (TIR) approaches largely rely on Supervised Fine-Tuning (SFT). This process involves distilling problem-solving trajectories (including tool use) from stronger models or human demonstrations. While effective to some extent, SFT inherently constrains the model to patterns of tool usage that are predefined or already known. This limits the model's capacity for exploration and discovering truly optimal or novel strategies for integrating tools into its reasoning process. The authors hypothesize that an RL approach, allowing "unrestricted exploration," can lead to superior and more flexible tool utilization.
3. **Enabling Emergent Tool-Augmented Reasoning:** The researchers are motivated to demonstrate that sophisticated tool-augmented reasoning capabilities can emerge *effectively and robustly* when LLMs are trained with RL directly from base models, rather than needing an initial alignment phase through SFT. This aims to show that reward-driven learning alone is sufficient to teach models how and when to invoke external tools, integrate their outputs, and even engage in self-correction and reflection based on computational feedback.
4. **Enhancing Transparency and Accessibility:** The paper also implicitly aims to contribute to the open-source community by providing a transparent and reproducible implementation of tool-integrated RL. This addresses the "limited implementation transparency" observed in some prior RL applications to tool use, facilitating further research and development.

In essence, the core motivation is to move beyond mere imitation of human-designed tool-use patterns towards an autonomous acquisition of tool-integrated reasoning skills through the powerful mechanism of reinforcement learning.

### 3. Methodology and Approach

TORL introduces a novel framework that integrates a code interpreter directly into the reinforcement learning environment, allowing LLMs to learn tool utilization from scratch.

### 4. Dataset Construction

The foundation of TORL's training is a robust dataset of mathematical competition questions.
- **Sources:** The dataset was constructed from high-quality sources including Numina-MATH, MATH, and DeepScaleR.
- **Initial Filtering:** An initial pool of 75,149 verifiable questions was created by removing proof-based problems and those with ambiguous verification criteria.
- **Data Distillation:** To ensure high quality and a balanced difficulty distribution, the LIMR (Less Is More for RL Scaling) reinforcement learning data distillation technique (Li et al., 2025) was applied.
- **Final Dataset:** This process yielded a final dataset of 28,740 questions, serving as the training ground for all experiments.

### 5. Tool-Integrated Reasoning (TIR)

TORL adopts and extends the existing Tool Integrated Reasoning (TIR) paradigm. TIR allows LLMs to overcome their inherent computational limitations by generating executable code, executing it via an interpreter, and using the output to inform subsequent reasoning.
- **Iterative Process:** Given a language model `M`, a code interpreter `I`, and an input question `Q`, TIR constructs a reasoning trajectory `s_k` iteratively. At each step `k`, the model generates natural language reasoning (`r_k`) and code (`c_k`) based on the question and previous trajectory (`Q ⊕ s_{k-1}`). The interpreter then executes `c_k` to produce an output `o_k`, which is appended to the trajectory (`s_k = s_{k-1} ⊕ r_k ⊕ c_k ⊕ o_k`). This cycle continues until a final answer is produced, allowing dynamic adjustment of reasoning paths based on computational feedback.

### 6. TORL Framework

TORL combines TIR with reinforcement learning, starting directly from base language models without supervised fine-tuning.
- **TIR Rollout Framework:**
 - **Prompting:** A specific prompt template (e.g., "Please integrate natural language reasoning with programs to solve the problem...") guides the model to generate both natural language and code blocks.
 - **Code Detection and Execution:** During the model's rollout, when a code termination identifier (`'''output`) is detected, text generation pauses. The latest code block is extracted, executed by the interpreter, and its structured result (e.g., `'''output\nOBSERVATION\n'''`) is injected back into the context.
 - **Error Handling:** Critically, error messages from code execution failures are deliberately returned to the LLM. The authors hypothesize this diagnostic feedback enhances the model's ability to generate syntactically and semantically correct code in subsequent iterations.
 - **Tool Call Frequency Control (Hyperparameter `C`):** To manage GPU idle time and maintain training speed, a hyperparameter `C` defines the maximum number of tool calls allowed per single response generation. If this limit is exceeded, further code execution requests are ignored, forcing the model into pure-text reasoning mode.

### 7. Design Choices and Reward Design

Several design choices were made to optimize training efficiency and effectiveness:
- **Execution Environment:** After testing, Sandbox Fusion was chosen over `qwen-agent` due to its isolated execution environment, which provides superior stability for sustained training operations despite slightly higher latency.
- **Error Message Processing:** To minimize context length, only the final line of error messages (e.g., `NameError: name 'a' is not defined`) is extracted and provided to the model.
- **Sandbox Output Masking:** `OBSERVATION` outputs from the sandbox environment are masked during loss computation. This crucial step prevents the model from memorizing specific execution outputs, encouraging it to learn generalizable reasoning patterns instead.
- **Reward Design (Rule-based):**
 - **Answer Correctness Reward:** The primary reward. A correct final answer yields a reward of +1, while an incorrect answer results in -1.
 - **Code Executability Reward:** An additional, optional penalty. Responses containing non-executable code incur a -0.5 reward reduction. This was explored in analysis but not used by default in main experiments.

### 8. Experimental Setup

- **Training Framework:** All RL experiments were conducted using the `veRL` framework, leveraging `Sandbox Fusion` as the code interpreter.
- **Algorithm:** The GRPO (Generalized Reinforcement Learning with Policy Optimization) algorithm was employed.
- **Hyperparameters:** Rollout batch size was set to 128, with 16 samples generated per problem. KL loss was omitted, and temperature was set to 1 to encourage model exploration.
- **Base Models:** The Qwen-2.5-Math series (1.5B and 7B parameters) served as the foundational LLMs.
- **Default Settings:** The default maximum number of tool calls (`C`) was set to 1. Only the Answer Correctness Reward was used by default in the main experiments.
- **Evaluation:** Greedy decoding (temperature = 0) was used for evaluation across all models.
- **Benchmarks:** Performance was assessed on several challenging mathematical benchmarks: AIME24, AIME25, MATH500, OlympiadBench, and AMC23.

### 9. Main Findings and Results

The experiments demonstrate that TORL significantly enhances the mathematical reasoning capabilities of LLMs, primarily through its novel approach of directly scaling RL for tool integration from base models.

### 10. Quantitative Performance

- **Overall Superiority:** TORL consistently outperformed baseline models across all tested mathematical benchmarks, including both traditional RL models without tool integration and existing Tool-Integrated Reasoning (TIR) models that rely on supervised fine-tuning (SFT).
- **1.5B Model Performance:** TORL-1.5B achieved an average accuracy of 48.5%, marking a substantial improvement over Qwen2.5-Math-1.5B-Instruct (35.9%) and Qwen2.5-Math-1.5B-Instruct-TIR (41.3%). This represents a +7.2% absolute improvement over the SFT-based TIR baseline.
- **7B Model Performance:** The improvements were even more pronounced with the larger model. TORL-7B attained an impressive 62.1% average accuracy, outperforming other open-source models built on the same base model by a significant margin (+14.7% absolute improvement). Notably, TORL-7B achieved 43.3% accuracy on AIME24 problems, surpassing RL without tool integration by 14% and the best existing Tool-Integrated Reasoning (TIR) model by 17%. Its performance on AIME24 is also comparable to some 32B models trained with reinforcement learning.
- **Consistent Training Dynamics:** Performance graphs (Figure 4) show that TORL-7B demonstrated consistent improvement throughout the training steps and maintained a clear advantage over both baselines across all benchmarks, particularly on challenging ones like AIME24, AIME25, and OlympiadBench.

### 11. Emergent Cognitive Behaviors and Analysis

Beyond raw performance, the study uncovered several key insights into the model's learned behaviors and the impact of design choices.

- **Code Usage Evolution (Figure 5):**
 - **Increased Code Generation:** The proportion of responses containing code significantly increased over training (from 40% to 80% within 100 steps), indicating the model's autonomous acquisition of tool utilization strategies.
 - **Improved Code Quality:** The "Pass Ratio" (proportion of successfully executed code) showed a continuous upward trend, reflecting enhanced coding capability and reduced syntax/runtime errors.
 - **Correlation with Correctness:** Analysis revealed that correct responses exhibited a higher code pass rate compared to incorrect responses, suggesting a strong link between successful tool execution and problem-solving accuracy.
 - **Effective Code:** Both the "executed code ratio" (successfully interpreted code) and "before final answer code ratio" (code used for reasoning, not just verification) increased, implying that the model learned to generate more effective and purposeful code.
 - **Takeaway-I:** The model autonomously learns to use code more frequently, correctly, and effectively, while also identifying and reducing ineffective code patterns.

- **Impact of Key Settings (Figure 6, Table 4):**
 - **Maximum Tool Calls (`C`):** Increasing the maximum allowed tool calls (`C`) per problem significantly enhanced performance (e.g., ~2% average accuracy gain when `C` was increased from 1 to 2). However, this came at a severe cost to training efficiency, substantially increasing GPU idle time and average step time (e.g., from 18s/step for C=1 to 37s/step for C=1 and 88s/step for C=2 on an 8*A800 GPU system). This highlights a critical efficiency-effectiveness trade-off.
 - **Code Executability Reward:** Surprisingly, incorporating a penalty for non-executable code (Code Executability Reward) did not improve model performance. The authors hypothesize that this might incentivize the model to generate overly simplistic code to avoid errors, thereby hindering its ability to solve complex problems correctly.
 - **Takeaway-II:** While more tool calls can boost performance, they drastically slow down training, necessitating careful hyperparameter tuning. Penalizing execution errors directly might be counterproductive.

- **Emergent Cognitive Behaviors (Tables 5, 6):**
 - **Self-regulation and Error Correction:** The model demonstrated the ability to interpret error messages from the code interpreter and subsequently correct its own generated code (Table 5). This suggests an emergent form of metacognition about tool utility and code correctness.
 - **Reflection and Cross-validation:** TORL exhibited sophisticated behaviors where it first reasoned in natural language, then used the tool to verify its solution. Upon detecting inconsistencies between its analytical reasoning and the tool's output, it engaged in reflection and made corrections, ultimately arriving at the correct answer (Table 6).
 - **Dynamic Adaptation:** The ability to obtain feedback from code execution results and cross-check between computational and analytical approaches indicates a dynamic adaptation of reasoning strategies based on problem characteristics.
 - **Takeaway-III:** These advanced cognitive behaviors, including strategic tool invocation, self-regulation, and dynamic adaptation between computational and analytical reasoning, emerged *without explicit instruction*, purely through reward-driven learning.

### 12. Significance and Potential Impact

The research presented in "TORL: Scaling Tool-Integrated RL" holds significant implications for the development and understanding of advanced large language models (LLMs), particularly in their ability to interact with and leverage external computational tools.

### 13. Significance of the Work

1. **Paradigm Shift in Tool Integration:** TORL introduces a critical paradigm shift by demonstrating that robust tool-augmented reasoning capabilities can emerge effectively through reinforcement learning applied directly to *base models*, circumventing the limitations of prior supervised fine-tuning (SFT) approaches. This fundamentally changes how we might train LLMs for tool use, freeing them from imitating predefined patterns and enabling them to discover optimal strategies through unconstrained exploration.
2. **State-of-the-Art Performance with Efficiency:** The framework achieves substantial performance gains on challenging mathematical benchmarks. TORL-7B, for instance, significantly outperforms existing open-source Tool-Integrated Reasoning (TIR) models and even competes with much larger (32B parameter) models, showcasing the efficiency and effectiveness of the TORL approach with smaller model sizes. This indicates that intelligent tool use is not solely a function of model scale but also of the training methodology.
3. **Revelation of Emergent Cognitive Behaviors:** Perhaps one of the most profound findings is the observation of sophisticated emergent cognitive behaviors—such as strategic tool invocation, self-regulation of ineffective code, reflection, cross-validation between analytical and computational results, and dynamic adaptation of reasoning strategies. The fact that these capabilities arise *solely through reward-driven learning* without explicit instruction or human-demonstrated patterns provides compelling evidence for the power of scaled reinforcement learning in fostering complex intelligence in LLMs.
4. **Advancement in RL for LLMs:** The paper contributes to the broader field of Reinforcement Learning for LLMs by showcasing successful scaling techniques (e.g., using GRPO, managing rollout efficiency, specific reward designs) that lead to meaningful improvements and emergent properties. The discussion on the trade-offs of tool call frequency and the non-effectiveness of execution-based penalties offers valuable practical insights for future RL research.

**Potential Impact:**
1. **More Autonomous and Capable AI Agents:** By enabling LLMs to autonomously learn tool utilization, TORL paves the way for the development of more robust, versatile, and independent AI agents. These agents could tackle a wider array of complex, real-world problems that require precise computation, data analysis, or interaction with external systems, moving beyond purely language-based reasoning.
2. **Reduced Reliance on Human Annotation:** The ability to learn tool use directly from base models through RL reduces the heavy reliance on extensive, high-quality human-curated datasets for supervised fine-tuning. This could accelerate the development cycle for new capabilities and make advanced LLM training more accessible.
3. **New Avenues for Scientific Discovery:** LLMs enhanced with autonomous tool integration could become powerful assistants for scientific research, capable of executing simulations, analyzing large datasets, or verifying hypotheses through computation, potentially accelerating discovery processes.
4. **Improved Mathematical and Symbolic Reasoning:** The significant performance improvements on mathematical benchmarks highlight TORL's direct impact on problem domains traditionally challenging for LLMs. This could lead to more reliable AI tutors, problem-solvers, and technical assistants.
5. **Foundation for Future Research:** By open-sourcing their implementation, datasets, and models, the authors provide a valuable resource for the research community. This will undoubtedly encourage further exploration, refinement, and extension of tool-integrated reinforcement learning, potentially leading to even more advanced and specialized LLM capabilities.

In summary, TORL represents a crucial step forward in LLM research, demonstrating that sophisticated, adaptive tool use can be a directly learned behavior from reinforcement learning, leading to powerful and intelligent agents with emergent cognitive abilities.
