# SE-VLN: A Self-Evolving Vision-Language Navigation Framework Based on Multimodal Large Language Models

> [!summary] Summary
> SE-VLN introduces a self-evolving vision-language navigation framework powered by Multimodal Large Language Models (MLLMs). This training-free system enables embodied agents to continuously refine navigation skills through hierarchical memory, retrieval-augmented reasoning, and a reflection mechanism, achieving state-of-the-art performance on R2R and REVERIE datasets with notable improvements in navigation metrics.

## Problem

- Existing LLM-powered Vision-Language Navigation (VLN) agents utilize historical data statically, failing to extract reusable general knowledge for continuous improvement.
- Current agents possess limited reasoning capabilities, relying on pre-trained knowledge without effective dynamic adaptation from real-time experience or error learning.
- The 'evolution' of current VLN agents is tied to manual tuning or model retraining, lacking autonomous self-adaptation akin to biological intelligence.

## Method

- A training-free, self-evolving VLN framework (**SE-VLN**) is proposed, leveraging MLLMs within a closed-loop system for continuous interaction, decision-making, reflection, and knowledge updates.
- It employs a Hierarchical Memory Module, integrating a dynamic Verbal Topological Map for short-term contextual memory and an Experience Repository for long-term, reusable knowledge.
- The framework includes a Retrieval-Augmented Thought-Based Reasoning Module that combines few-shot experience retrieval with multi-step ==Chain-of-Thought== prompting, and a Reflection Module for autonomous error correction and experience refinement.

## Results

- SE-VLN significantly outperformed existing training-free LLM-powered VLN methods, showing relative improvements of **23.9%** in Success Rate (SR) and **15.0%** in SPL on the R2R validation unseen set.
- The framework demonstrated robust self-evolution capabilities, with Object Success Rate (OSR) improving from **64.1%** to **68.0%** as accumulated experience increased, validating continuous learning across tasks.
- Ablation studies confirmed the positive impact of the Retrieval-Augmented Thought-Based Reasoning and Reflection modules, with GPT-4o identified as the most effective MLLM within the framework compared to alternatives.

## Takeaways

> [!tip] Key Insights
> - Continuous self-evolution in VLN is achievable by enabling agents to dynamically accumulate, retrieve, and refine experiences through a structured memory system and explicit post-task reflection.
> - Combining retrieval-augmented generation (RAG) with multi-step Chain-of-Thought (CoT) prompting enhances MLLM-based reasoning capabilities, leading to more transparent and informed decision-making in complex navigation tasks.
> - A precise quantitative outcome evaluator is critical for providing targeted feedback to the reflection mechanism, allowing for accurate error identification and effective refinement of stored navigation strategies.
