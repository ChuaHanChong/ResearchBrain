# AI Meets Brain: Memory Systems from Cognitive Neuroscience to Autonomous Agents

> [!summary] Summary
> This paper IS a unified survey bridging cognitive neuroscience and LLM-driven agent memory research. It synthesizes memory definitions across brain, LLM, and agent perspectives; proposes a nature- and scope-based agent memory taxonomy; maps storage location/format and a four-stage extraction-update-retrieval-application management lifecycle; and catalogs benchmarks and attack/defense security methods, closing the interdisciplinary gap between neuroscience and AI.

## Problem

- LLMs are natively stateless, so each inference is independent, preventing cross-session continuity or accumulation of experience from historical interactions.
- Prior agent-memory works remain confined to a single disciplinary perspective or lack depth in biological research, blocking deep neuroscience-AI integration.
- No systematic benchmark taxonomy or cross-disciplinary security analysis existed, leaving memory fidelity, dynamics, generalization, and attack/defense evaluation fragmented across isolated studies.

## Method

- ==Nature- and scope-based memory taxonomy==: classifies agent memory as ==episodic== vs ==semantic== (content type) and ==inside-trail== vs ==cross-trail== (persistence scope), extending Hu et al. and Zhang et al.
- ==Four-stage memory management lifecycle==: ==extraction== (flat, hierarchical, generative), ==updating== (inside-trial vs cross-trial), ==retrieval== (similarity-based vs multi-factor), and ==application== (contextual augmentation vs parameter internalization).
- ==Security taxonomy== for agent memory: ==extraction-based== and ==poisoning-based== attacks paired against ==retrieval-based==, ==response-based==, and ==privacy-based== defense mechanisms across the memory lifecycle.

## Results

- Table 1 catalogs **32** semantic-oriented benchmarks (LoCoMo, MemBench, LongMemEval, HaluMem) spanning text, image, audio, and video, with dataset sizes ranging from **33** to **108,000** samples.
- Table 2 catalogs **12** episodic-oriented benchmarks (ToolBench, GAIA, WebArena, Mind2Web) covering web, tool-use, and environment interaction, with data volumes up to **142,950** samples.
- The survey spans **57** pages and cites roughly **400** works, unifying **ten** sections from cognitive neuroscience through LLM parametric/working/external memory to agent taxonomies.

## Takeaways

> [!tip] Key Insights
> - Biological short-term memory coexists in two formats, active persistent firing and activity-silent synaptic states, suggesting agent memory should similarly blend context-window and latent/parametric substrates rather than picking one.
> - Agent memory diverges from RAG in kind, not degree: RAG grounds generation in static external knowledge, while memory continuously accumulates and reshapes itself from ongoing agent-environment interaction.
> - Current agent retrieval is a passive selective-activation lookup, unlike biological retrieval which is reconsolidative and modifies the trace itself, a mechanistic gap future memory-updating agents could exploit.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development of sophisticated memory systems is a critical frontier in artificial intelligence, especially with the advent of Large Language Models (LLMs) and autonomous agents. The broader research landscape is characterized by an increasing recognition that while LLMs possess impressive reasoning and generation capabilities, they inherently suffer from a "stateless" nature. This statelessness means that each interaction or inference is treated independently, preventing models from accumulating experience, maintaining long-term context across sessions, or dynamically updating their knowledge base. This limitation leads to challenges such as high knowledge update costs, computational complexity in processing long contexts, and the inability to maintain a consistent "identity" or "persona" over time.

Autonomous agents, which aim to perform complex, long-horizon tasks in dynamic environments, are particularly impacted by these limitations. For agents to truly be autonomous—to learn, adapt, and plan effectively over extended periods—they require robust memory systems that go beyond the basic context window of an LLM.

Existing research has begun to explore memory mechanisms for AI, often drawing inspiration from cognitive neuroscience. However, as the authors note, these efforts are frequently "constrained by interdisciplinary barriers," remaining "confined to a single disciplinary perspective or lack depth in biological research." This siloed approach hinders the potential for deep mutual validation and inspiration between fields, preventing AI memory systems from fully assimilating the richness and efficiency of human cognitive memory.

This survey directly addresses this critical gap. It aims to unify the understanding of memory systems across cognitive neuroscience, LLMs, and autonomous agents. By systematically synthesizing knowledge from these disparate domains, the paper seeks to provide a holistic framework that informs the design of more human-like and effective memory systems for AI. It positions memory not merely as a passive data repository but as a "dynamic cognitive hub" essential for complex decision-making, adaptive learning, and long-term intelligence in autonomous agents. This work is pivotal for moving beyond superficial analogies and towards a foundational understanding that can drive the next generation of AI development.

### 2. Key Objectives and Motivation

The motivation for this comprehensive survey stems from the fundamental role of memory as a "pivotal nexus bridging past and future," essential for both human cognition and advanced AI systems. The authors highlight several specific challenges that current LLM-driven agents face due to the limitations of their inherent memory capabilities:

- **Statelessness of LLMs:** LLMs inherently process each input independently, making it difficult to maintain continuity across multiple interactions or to accumulate experience over time. This leads to issues like "knowledge update costs" and high "computational complexity" when dealing with extended contexts.
- **Need for Persistence in Agents:** Autonomous agents require "information persistence" and "long-horizon planning" to navigate complex tasks and environments effectively. Without robust memory, agents are prone to repetitive errors and inability to learn from past experiences.
- **Interdisciplinary Gap:** Despite the growing interest in designing AI memory systems inspired by cognitive neuroscience, a significant barrier exists between the disciplines. Existing works often lack a deep integration of biological research, preventing the assimilation of "the essence of human memory mechanisms."

Against this backdrop, the key objectives of the survey are explicitly articulated:

1. **Elucidate Memory Definitions and Functions:** To progressively define memory from the perspective of cognitive neuroscience, through LLMs, and ultimately to autonomous agents, clarifying its fundamental role in each context.
2. **Comparative Analysis of Memory Systems:** To provide a detailed comparison of memory taxonomy, storage mechanisms (location and format), and the complete management lifecycle (extraction, updating, retrieval, utilization) from both biological and artificial intelligence viewpoints.
3. **Review Evaluation Benchmarks:** To systematically outline and categorize mainstream benchmarks used for evaluating the memory capabilities of AI agents.
4. **Investigate Memory Security:** To address the often-overlooked yet critical aspect of memory security in AI agents, exploring both attack vectors and defensive strategies.
5. **Envision Future Research Directions:** To propose promising avenues for future research, with a particular focus on the development of multimodal memory systems and advanced agent skills that enable memory sharing and transfer.

By addressing these objectives, the authors aim to facilitate cross-disciplinary research, offering both newcomers an accessible introduction and seasoned researchers deeper insights into the complex interplay of biological and artificial memory systems.

### 3. Methodology and Approach

This paper is a literature survey, and its methodology revolves around a systematic, structured synthesis of knowledge across distinct scientific domains. The authors adopted a multi-faceted approach to integrate and present information effectively:

1. **Progressive Trajectory for Definitions:** The survey first establishes a foundational understanding of memory by tracing its definition and function along a "progressive trajectory": starting from the fundamental principles in cognitive neuroscience, transitioning to its manifestations within Large Language Models (LLMs), and finally detailing its operation as a dynamic cognitive mechanism in autonomous agents. This step-wise approach helps build a coherent understanding for readers from various backgrounds.

2. **Comparative and Unified Analysis:** A core methodological element is the comparative analysis. For key aspects of memory, the paper systematically contrasts biological mechanisms (human brain) with artificial intelligence implementations (LLMs and agents). This includes:
 - **Taxonomy:** Starting with the classical short- and long-term memory dichotomy in cognitive neuroscience, the authors then propose a novel classification for agent memory based on "nature" (episodic vs. semantic) and "scope" (inside-trail vs. cross-trail), directly linking artificial categories to biological inspirations.
 - **Storage Mechanisms:** Comparing memory storage in terms of "location" (e.g., sensory-frontoparietal networks, hippocampus-neocortex in the brain vs. context window, external memory banks in agents) and "format" (e.g., persistent neural activity, synaptic weights, cognitive maps in the brain vs. natural language text, graphs, parameters, latent representations in agents).
 - **Management Lifecycle:** Analyzing the complete closed-loop process of memory management, including "extraction" (encoding/integration in brain), "updating" (reconsolidation/differentiation), "retrieval" (pattern completion/reinstatement), and "utilization" (guiding behavior) from both biological and artificial perspectives.

3. **Comprehensive Review of Agent-Specific Aspects:** Beyond the comparative analysis, the survey dedicates specific sections to aspects crucial for AI agent development:
 - **Memory Utility:** Detailing how memory enhances agent capabilities by breaking context window constraints, constructing long-term personalized profiles, and driving experience-based reasoning.
 - **Benchmarks:** Reviewing existing evaluation benchmarks for agent memory, categorizing them into semantic-oriented (internal state, cognition) and episodic-oriented (domain-specific performance), and defining evaluation attributes (fidelity, dynamics, generalization).
 - **Security:** Investigating memory security from dual perspectives: attack paradigms (extraction-based, poisoning-based) and defense mechanisms (retrieval-based, response-based, privacy-based).

4. **Future-Oriented Discussion:** The methodology concludes by identifying and elaborating on critical future research directions, specifically focusing on multimodal memory systems and the development of composable and transferable "agent skills," highlighting current limitations and open challenges.

The authors consistently reference a wide array of existing literature, as evidenced by the extensive citation list (over 400 references), underpinning the comprehensiveness of their review. The structure is designed to guide readers through increasing levels of complexity, from foundational biological concepts to advanced AI implementations and future challenges, thus fulfilling the objective of bridging interdisciplinary gaps.

### 4. Main Findings and Results

The survey meticulously synthesizes insights across cognitive neuroscience and AI, offering a structured understanding of memory systems.

**A. Memory Definitions:**
- **Cognitive Neuroscience:** Memory is a dynamic neural process for information processing and management, crucial for learning, adaptation, and connecting past experiences to future decisions. It involves encoding, integration, consolidation, and retrieval.
- **LLMs:** Memory manifests in three forms:
 - *Parametric Memory:* Knowledge internalized in model weights during training, fundamental but static, prone to hallucination, and costly to update.
 - *Working Memory:* Utilizes the context window for real-time interaction, limited in capacity, and exhibits positional bias.
 - *Explicit External Memory:* External storage via Retrieval-Augmented Generation (RAG) using vector databases or knowledge graphs, decoupling computation from storage, reducing hallucination and enabling real-time updates, but facing latency and noise issues.
- **Agents:** Memory is a dynamic cognitive architecture inspired by neuroscience, enabling identity persistence, experiential accumulation, and long-horizon planning. It differs from RAG by being embedded within dynamic interaction processes, continuously incorporating agent operations and environmental feedback. Key dimensions include structured storage, dynamic scheduling, and cognitive processing/evolution.

**B. Memory Utility for LLM-Driven Agents:**
- **Breaking Context Window Constraints:** Achieved through heuristic context design (virtual context, gist memory, task-structure folding) and autonomous memory optimization (RL-based summarization, deletion, context folding as a skill).
- **Constructing Long-term Personalized Profiles:** Agents distill traits from interactions to build user models, ensuring precise recall and structured attribute storage. This guides preference-aligned execution in task planning and generation.
- **Driving Experience-based Reasoning:** Memory aids reasoning through strategic guidance (textual reflection, historical trajectory exemplars, guideline retrieval) and procedural solidification (encapsulating successful code into skill libraries, trajectory distillation into generalizable skills, workflow graphs).

**C. Memory Categorization:**
- **Cognitive Neuroscience:**
 - *Short-term Memory:* Temporary maintenance of small information amounts (seconds), limited capacity (4-9 items).
 - *Long-term Memory:* Stores vast information for extended periods, dynamic and interacts with short-term memory. Further divided into:
 - *Episodic Memory:* Specific, personally experienced events with temporal/spatial context ("mental time travel").
 - *Semantic Memory:* Factual knowledge, concepts, rules, de-contextualized from acquisition events.
- **Agents (Proposed Taxonomy):**
 - *Nature-based:*
 - *Episodic Memory:* Experiential memory, sequential interaction trajectories, tool-augmented, records "how-to."
 - *Semantic Memory:* Knowledge repository without tool dependencies, factual information, concepts, rules, "what-is."
 - *Scope-based:*
 - *Inside-trail Memory:* Confined to a single trajectory, context-specific, transient.
 - *Cross-trail Memory:* Persists across multiple trajectories, generalizable patterns, supports continual learning.

**D. Memory Storage:**
- **Cognitive Neuroscience:**
 - *Short-term:* Distributed sensory-frontoparietal network; formats include persistent neural activity and activity-silent synaptic connection weights.
 - *Long-term:* Coordinated activity of hippocampus (index) and neocortex (storage); formats include event-based units (segmented experiences) and cognitive maps (organizing abstract knowledge, concepts, and experiences).
- **Agents:**
 - *Location:* Context Window (inside-trail, dynamically folds information); Memory Bank (external, persistent, stores cross-trail memory, supports reusability, e.g., user preferences, distilled strategies, shared memory banks).
 - *Format:* Text (raw or summarized, high interpretability); Graph (entities and relationships, supports complex reasoning, multimodal graphs); Parameters (embedded in model weights, efficient, deep integration via imitation/RL); Latent Representation (high-dimensional vectors, efficient compression, end-to-end trainable, aligns with human cognition).

**E. Memory Management:**
- **Cognitive Neuroscience:** A dynamic cycle of:
 - *Formation:* Encoding (neural activity patterns), Consolidation (hippocampal replay stabilizes representations), Integration (assimilating discrete memories into broader knowledge structures).
 - *Updating:* Triggered by prediction error, involves differentiation (distinct representations for similar events) and integration (unifying new information with prior memories).
 - *Retrieval:* Initiated by cues, involves hippocampal pattern completion and neocortical reinstatement; it's a transformative process (reconsolidation) that modifies existing traces and facilitates subsequent encoding.
- **Agents:** A closed-loop pipeline:
 - *Extraction:* Flat (direct recording, lightweight summarization), Hierarchical (multi-granular abstraction, gist memory, episodic/semantic separation), Generative (dynamic context reconstruction via summarization tools).
 - *Updating:* Inside-Trial (filter-based, just-in-time resource management, summarization actions for working memory); Cross-Trial (selective retention/forgetting, semantic merging, RL for optimal policies for external knowledge bases).
 - *Retrieval:* Similarity-based (semantic matching, top-k); Multi-factor (recency, importance, efficiency, expected rewards, structured approaches).
 - *Application:* Contextual Augmentation (dynamic synthesis for understanding, personalization, reasoning); Parameter Internalization (distilling explicit memory into implicit parameters, agent self-evolution via RL).

**F. Benchmarks for Agent Memory:**
- **Semantic-oriented:** Evaluate internal memory state, retrieval accuracy, dynamics, and self-evolution. Attributes: Fidelity, Dynamics, Generalization. Examples: LoCoMo, MemBench, HaluMem.
- **Episodic-oriented:** Assess performance in vertical domains (web search, tool use, environmental interaction), emphasizing actual performance gains. Attributes: Fidelity, Dynamics, Generalization. Examples: WebChoreArena, ToolBench, ScienceWorld.

**G. Security of Agent Memory:**
- **Attacks:** Extraction-based (stealing sensitive user data from external memory, e.g., privacy leakage in RAG) and Poisoning-based (injecting malicious data to compromise decision-making, implanting backdoors, degrading judgment with noise/bias).
- **Defenses:** Retrieval-based (purifying memory at source, anomaly detection); Response-based (blocking malicious logic during generation, multi-agent review, MCTS); Privacy-based (safeguarding data lifecycle, isolated private memory, anonymization).

### 5. Significance and Potential Impact

This survey represents a significant contribution to the fields of artificial intelligence, cognitive neuroscience, and interdisciplinary research for several key reasons:

**A. Bridging Interdisciplinary Gaps:** The most prominent significance lies in its explicit goal and execution of bridging the conceptual and mechanistic divide between human cognitive memory and artificial memory systems. By systematically comparing and contrasting memory definitions, taxonomies, storage, and management from both biological and computational perspectives, the authors provide a much-needed unified framework. This synthesis will likely foster greater understanding and collaboration between neuroscientists and AI researchers, potentially leading to more biologically plausible and robust AI architectures.

**B. Comprehensive Roadmap for AI Memory Systems:** For AI researchers and developers, the survey offers a detailed and structured roadmap for understanding, designing, and evaluating memory systems in LLM-driven agents. It moves beyond superficial discussions to provide granular insights into memory utility, categorization, storage formats, and management lifecycles. This comprehensive overview is invaluable for newcomers seeking an accessible entry point and for seasoned researchers looking for a structured synthesis of current advancements and challenges.

**C. Driving the Development of Advanced Autonomous Agents:** By emphasizing memory as a "dynamic cognitive hub" rather than a passive data store, the paper underscores its critical role in enabling true autonomy, personalization, and continuous learning in agents. The discussions on breaking context window constraints, constructing personalized profiles, and fostering experience-based reasoning highlight practical avenues for developing more capable, adaptive, and human-like agents that can operate effectively in complex, long-horizon tasks.

**D. Highlighting Critical Emerging Challenges:** The survey proactively identifies and elaborates on crucial emerging challenges, particularly in multimodal memory and agent skills.
- **Multimodal Memory:** The discussion on integrating diverse sensory inputs (text, image, audio, video) into coherent memory representations is vital for agents operating in real-world environments. By outlining limitations such as semantic degradation, temporal alignment issues, and computational efficiency, the authors set a clear agenda for future research.
- **Agent Skills:** The concept of modular, composable, and transferable agent skills, drawing an analogy to equipment in video games, is a visionary direction. It addresses the "reinventing the wheel" problem in isolated agent development and advocates for an ecosystem of shared, reusable domain expertise. This has profound implications for scalability and generalization across heterogeneous agent architectures.

**E. Emphasizing Trustworthy AI:** The dedicated section on memory security (attacks and defenses) is particularly timely and impactful. As agents become more integrated into critical applications, their memory systems become significant attack surfaces. By systematically analyzing privacy leakage and poisoning attacks, and outlining multi-layered defense mechanisms, the survey contributes to the development of more secure and trustworthy AI agents, which is essential for public adoption and ethical deployment.

In conclusion, "AI Meets Brain" is more than just a review; it's a foundational document that redefines the discourse around memory in AI. Its interdisciplinary breadth, systematic depth, and forward-looking perspective will undoubtedly encourage cross-pollination of ideas, accelerate research, and ultimately contribute to the creation of more intelligent, adaptable, and robust AI systems that truly learn from and interact with the world in a human-like manner.
