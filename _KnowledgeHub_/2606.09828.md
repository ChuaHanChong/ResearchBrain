# Latent Spatial Memory for Video World Models

> [!summary] Summary
> Mirage introduces a video world model that uses a latent spatial memory to generate 3D-consistent videos, achieving up to 10.57 times faster end-to-end generation and 55 times lower GPU memory usage compared to prior RGB-based memory approaches while enhancing geometric coherence.

## Problem

- Maintaining 3D spatial consistency across long video sequences generated by world models is challenging, leading to geometric drift.
- Existing 3D memory systems, typically based on explicit RGB point clouds, incur substantial computational costs due to repetitive 'rasterize-and-encode' operations between latent and pixel space.
- Converting latent features to pixel-space RGB and then re-encoding results in information loss, introducing artifacts and providing a suboptimal conditioning signal for generative models.

## Method

- Mirage develops a '==latent spatial memory==' (LSM) that stores scene information as latent-attributed 3D points directly in the diffusion model's latent space, avoiding pixel-space conversion.
- It employs an iterative initialize-readout-update cycle over overlapping video chunks, populating the LSM with VAE-encoded latents and estimated depths, explicitly excluding dynamic objects and sky regions.
- A ControlNet-style side branch is used to integrate the latent memory readouts directly into the video diffusion backbone, efficiently conditioning the generative process without altering the pretrained VAE.

## Results

- Mirage achieved an average score of 70.36 on the WorldScore benchmark, outperforming all compared systems with superior 3D Consistency (92.21) and Photometric Consistency (93.95) on the static axis.
- The system demonstrated up to 10.57 times faster end-to-end video generation and up to 55 times lower GPU memory usage for the 3D cache compared to RGB point cloud baselines.
- On RealEstate10K, Mirage secured the best SSIM (**0.779**) and LPIPS (**0.250**) for novel view synthesis and achieved the highest PSNR_C (20.05) and SSIM_C (**0.825**) in closed-loop consistency tests.

## Takeaways

> [!tip] Key Insights
> - Operating 3D memory directly within the VAE latent space dramatically improves efficiency and preserves feature fidelity compared to RGB-based memory systems.
> - Filtering dynamic objects and sky from the persistent 3D cache is essential for maintaining long-term geometric stability and preventing memory contamination.
> - A two-stage training approach, initially freezing the diffusion backbone, effectively adapts pre-trained video transformers to leverage latent spatial memory while preserving their generative priors.
