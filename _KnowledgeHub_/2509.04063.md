# Balancing Signal and Variance: Adaptive Offline RL Post-Training for VLA Flow Models

> [!summary] Summary
> The paper introduces Adaptive Reinforced Flow Matching (ARFM), an adaptive offline reinforcement learning post-training framework for Vision-Language-Action (VLA) flow models. ARFM improves action accuracy and robustness by adaptively balancing the reinforcement learning signal with gradient variance in the flow matching loss, achieving a 4.5% higher success rate on the LIBERO benchmark compared to the baseline 
	0.

## Problem

- Vision-Language-Action (VLA) flow models, like 
	0, fine-tuned with imitation learning (IL) often lack sufficient action accuracy on complex robotic tasks.
- Existing offline RL approaches for VLA models struggle to effectively integrate with VLA *flow models* because scalar RL return signals inefficiently guide the generation of trajectory vector fields.
- A principled method is needed to leverage the nuanced quality distribution within offline data (RL advantage) without introducing training instability or excessive gradient variance.

## Method

- Proposes ==Adaptive Reinforced Flow Matching== (**ARFM**), which extends ==Energy-Weighted Flow Matching== (**EWFM**) by incorporating an RL advantage signal into the VLA flow model loss function.
- Introduces an adaptive scaling factor (
	) for the RL advantage, derived from an optimization objective that balances gradient variance minimization and RL signal maximization.
- Utilizes a ==bisection iterative algorithm== to efficiently solve for the optimal 
	 in each fine-tuning step, ensuring dynamic balance between signal and stability.

## Results

- Achieved the highest average success rate of **92.1%** on the LIBERO benchmark, a **4.5%** improvement over the 
	0 baseline (**88.1%**).
- Demonstrated superior robustness to action noise, with an **11.4%** improvement over 
	0 (**48.2%** vs. **43.3%**) across LIBERO suites, and validated this in real-world UR5 tasks.
- Significantly reduced Negative Backward Transfer (NBT) by **38.0%** in continual learning and achieved best performance in few-shot learning scenarios (**36.5%** average success rate on LIBERO-Long).

## Takeaways

> [!tip] Key Insights
> - Effectively integrating RL into VLA *flow models* requires directly modulating the flow matching loss based on an adaptive RL advantage signal rather than indirect guidance.
> - A principled bias-variance trade-off objective can derive an optimal scaling factor for the RL signal, enabling adaptive control over its influence.
> - Balancing the exploitation of high-quality data via RL signals with the control of gradient variance is crucial for stable and effective VLA flow model fine-tuning.
