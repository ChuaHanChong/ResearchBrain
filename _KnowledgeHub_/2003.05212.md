# A Mobile Robot Hand-Arm Teleoperation System by Vision and IMU

> [!summary] Summary
> Researchers at Universität Hamburg and collaborators developed a mobile robotic hand-arm teleoperation system integrating a vision-based deep learning network for dexterous hand control and an IMU-based method for arm control. The system, utilizing a wearable camera holder, allows operators to perform complex manipulation tasks in an unrestricted physical space, demonstrating high success rates in tasks like precision grasping and object insertion.

## Problem

- Achieving dexterous manipulation with anthropomorphic robotic hands via teleoperation remains difficult due to complex human-robot kinematic differences.
- Existing vision-based teleoperation systems restrict operator mobility and workspace, relying on fixed camera setups.
- Previous end-to-end deep learning methods for teleoperation were often limited to simpler grasping tasks or stationary robot positions.

## Method

- An auto-encoder based deep learning network, Transteleop, is introduced to translate human hand depth images into robot hand joint angles using an image-to-image translation approach.
- An IMU-based system tracks human arm movements, which are then mapped to the robot arm's joint angles via inverse kinematics for arm control.
- A custom-designed wearable camera holder enables the depth sensor to move with the operator's arm, providing an unrestricted workspace for teleoperation.

## Results

- The Transteleop network demonstrated an average **10.63%** improvement in joint angle prediction accuracy compared to a baseline TeachNet approach.
- The integrated teleoperation system achieved **100%** success rates in pick-and-place tasks and cup insertion, completing these in average times of **18.5** to **37.2** seconds and **25.5** seconds, respectively.
- The system successfully performed more complex tasks, including object pushing with an **80%** success rate and dual-arm handover with a **60%** success rate, indicating robust multi-task manipulation capabilities.

## Takeaways

> [!tip] Key Insights
> - Image-to-image translation, particularly with a keypoint-weighted reconstruction loss, effectively learns shared pose features between human and robot hands, outperforming direct regression or GAN-based approaches for joint angle prediction.
> - Combining a vision-based deep learning network for dexterous hand control with an IMU-based arm control, facilitated by a wearable camera, enables mobile teleoperation in unrestricted workspaces.
> - While the system achieved high performance in mapping human-to-robot poses, a robot-only model operating within the robot's visual domain still demonstrates an upper performance bound.
