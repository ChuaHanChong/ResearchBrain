# Look Back to Reason Forward: Revisitable Memory for Long-Context LLM Agents

> [!summary] Summary
> ReMemR1 introduces a long-context LLM agent capable of non-linear reasoning by dynamically retrieving information from its memory history. This system, guided by a multi-level reinforcement learning reward, achieved higher accuracy in multi-hop question answering across various context lengths and datasets with minimal inference overhead.

## Problem

- Existing "memorize while reading" LLM agents suffer from premature pruning of latent evidence, overlooking information whose significance emerges later in a multi-hop reasoning process.
- Sequential processing leads to progressive information loss as fixed-length memory buffers overwrite older, potentially vital, context.
- Training memory agents typically relies on sparse, delayed final reward signals, which hinders effective optimization of intermediate memory update decisions.

## Method

- **ReMemR1** augments the agent's state with a "==callback query==," enabling explicit, non-linear retrieval of relevant information from its entire history of past memories.
- It employs a lightweight recall-based heuristic for efficient selection of relevant content from memory history, ensuring minimal computational overhead.
- A multi-level reinforcement learning reward system is utilized, integrating trajectory-level outcome rewards with dense, step-level action rewards (information gain, callback bonus, format reward) for robust optimization.

## Results

- ReMemR1 consistently surpassed baseline memory agents and larger general LLMs, achieving up to **7.6%** higher accuracy on multi-hop QA benchmarks and substantially outperforming a **32B** model at 6400 documents.
- The system demonstrated improved coordination of distant evidence, effectively utilizing interdependent facts scattered across long document spans in challenging reverse reasoning order settings.
- Inference-time overhead for the callback mechanism was minimal, adding less than 2 seconds of latency and under 1MB of memory for 6400 documents, representing less than **0.2%** of total inference time.

## Takeaways

> [!tip] Key Insights
> - Enabling an LLM agent to actively revisit historical memories during sequential document processing significantly mitigates information loss and facilitates non-linear reasoning over extended contexts.
> - A balanced, multi-level reward structure, combining global task outcomes with fine-grained step-level signals, is essential for effectively training complex memory agent behaviors.
> - Dynamically learning when and what to recall, via an RL-driven callback, is critical for effective long-context reasoning, outperforming static, rule-based retrieval methods.
