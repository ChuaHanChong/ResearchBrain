# CanvasAgent: Enabling Complex Image Creation and Editing via Visual Tool Orchestration

> [!summary] Summary
> CanvasAgent is a tool-augmented multimodal agent that orchestrates heterogeneous visual tools (generation, localization, segmentation, editing, compositing, OCR, enhancement) over multiple turns. It is trained on CanvasCraft, a dataset of 140K executable trajectories, first with SFT and then with GRPO under a hybrid outcome and process reward. Experiments assess both final image quality and trajectory behavior.

## Problem

- Complex image requests need several steps such as synthesis, localization, segmentation, editing, compositing, text reading and enhancement, which a single generation or editing model cannot handle.
- Existing multimodal tool-use agents are optimized for perception, search or domain-specific editing, not for manipulation-centered creation where tools actively transform visual states.
- Large-scale supervision for executable multi-tool image-creation trajectories is lacking, so agents cannot learn to orchestrate heterogeneous visual tools reliably.

## Method

- **CanvasCraft** dataset: 140K fully annotated ==executable tool-use trajectories== for image creation and editing, plus 10K task specifications reserved for reinforcement learning.
- Two-stage training: ==SFT== teaches executable ==reasoning-action trajectories==, then ==GRPO== optimizes the agent with a ==hybrid reward== combining ==outcome-level and process-level signals==.
- ==Multi-turn rollout loop==: the agent inspects intermediate results, tracks visual assets, and adapts tool choices to the evolving ==canvas state==.

## Results

- On the 250-sample CanvasCraft evaluation split, CanvasAgent (SFT+RL) reaches **0.821** overall reward and **0.869** alignment, versus **0.426** / **0.493** for its Qwen3-VL-8B base with the same tools.
- Its **0.869** alignment beats image-only GPT-Image-2 (**0.799**), and RL raises average tool calls from **1.320** (SFT only) to **5.436**, with trajectory score rising from **0.576** to **0.849**.
- Ablations: RL from scratch reaches only **0.604** overall, dropping the process reward falls to **0.379**, and in a 12-sample human study CanvasAgent scores **3.97** task alignment versus **2.93** for Qwen3-VL-32B.

## Takeaways

> [!tip] Key Insights
> - Complex visual creation is better framed as sequential tool orchestration over an evolving visual state than as a single generative call.
> - Large-scale executable trajectory supervision is the missing ingredient for manipulation-centered multimodal agents, and it can be bootstrapped by SFT before RL refinement.
> - Combining outcome-level and process-level rewards in GRPO lets the agent be trained on trajectory quality, not only on the final image.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of artificial intelligence has seen rapid advancements in image creation and editing, largely driven by diffusion models, instruction-guided editors, and multimodal large language models (MLLMs). However, many complex user requests still exceed the capabilities of single-model calls. Such requests often necessitate a sequence of operations including image generation, object localization, region segmentation, content editing, intermediate asset compositing, text recognition (OCR), and final image enhancement.

Current research in multimodal tool-use agents primarily focuses on perception-augmented reasoning, visual search, or domain-specific editing tasks. These systems typically connect language models with visual foundation models or external expert modules to facilitate multi-step reasoning and execution. While progress has been made in active visual inspection and programmatic visual reasoning, existing agents are often not optimized for tasks that involve actively transforming visual states over long-horizon, visually grounded, and stateful workflows. Similarly, specialized image editing systems, such as instruction-guided editors or photo-retouching agents, tend to focus on single-model operations or retouching within specific environments, lacking the capacity for large-scale, heterogeneous tool orchestration through executable trajectories.

This research addresses a gap in the existing landscape by developing a framework specifically designed for complex, multi-tool image creation and editing. It shifts the paradigm from perception-centric or single-step editing to manipulation-centered visual creation, where an agent learns to orchestrate diverse visual tools in a coherent, multi-turn workflow. The work introduces both a large-scale dataset for this specific challenge and a corresponding agent capable of learning these complex trajectories, distinguishing it from prior work that focused on more limited aspects of visual tool use.

### 2. Key Objectives and Motivation

The primary objective of this research is to enable complex image creation and editing that requires orchestrating multiple heterogeneous visual tools through multi-turn interactions. The motivation stems from the limitations of current image generation and editing models, which often fail to handle practical user requests involving a sequence of interdependent visual operations.

The authors identify three key characteristics of these complex workflows that differentiate them from standard image generation or single-step editing tasks:
1. **Long-horizon dependency:** Later operations in a workflow often depend on visual artifacts or outputs produced by earlier tools. This necessitates a sequential planning and execution capability that considers the evolving visual state.
2. **Visually grounded interaction:** After each tool call, the agent must inspect and understand the intermediate visual output rather than assuming successful execution. This requires active visual perception and adaptation.
3. **Stateful asset management:** Multiple visual assets, such as images, masks, crops, or extracted objects, may coexist during a workflow. The agent must be able to track and select the correct asset for each subsequent operation, implying explicit state management.

To address these challenges, the research sets out to achieve the following specific objectives:
- **Develop a large-scale multimodal tool-use dataset:** This dataset, named CanvasCraft, is designed to provide comprehensive supervision for complex image creation and editing workflows. It aims to overcome the lack of large-scale supervision for executable image-creation trajectories in existing datasets. CanvasCraft is structured into two complementary subsets: CanvasCraft-SFT for supervised fine-tuning of executable trajectories and CanvasCraft-RL for reinforcement learning based on task specifications.
- **Instantiate a tool-augmented multimodal agent:** The agent, CanvasAgent, is designed to learn how to orchestrate a diverse set of visual tools. Its goal is to move beyond passive visual perception by actively transforming visual states through multi-turn reasoning, tool execution, and observation.
- **Design a robust training framework and reward mechanism:** The training framework for CanvasAgent involves a two-stage process (Supervised Fine-Tuning + Group Relative Policy Optimization, SFT+GRPO). A key objective is the design of a task-specific hybrid reward function that evaluates both the final output image quality and the validity and efficiency of the tool-use process, addressing the difficulty of evaluating long-horizon visual manipulation tasks.

By pursuing these objectives, the research aims to bridge the gap between advanced individual image generation/editing models and the holistic requirements of complex, multi-step visual creation tasks.

### 3. Methodology and Approach

The methodology centers on the development of a novel dataset, CanvasCraft, and a two-stage training framework for CanvasAgent, a tool-augmented MLLM.

#### 3.1. CanvasCraft Dataset and Construction

CanvasCraft is designed to provide supervision for complex image creation and editing, emphasizing coverage of essential visual operations and diversity in reasoning difficulty, trajectory length, and tool combinations. It comprises two subsets: CanvasCraft-SFT for supervised learning of executable trajectories and CanvasCraft-RL for reinforcement learning.

**4.1.1 CanvasCraft Tool Set:** The dataset and CanvasAgent utilize a unified toolkit of 11 heterogeneous visual tools. These tools cover functionalities such as:
- **Generation:** Text-to-image synthesis (using FLUX.2-Klein-4B).
- **Edit:** Instruction-based image editing (using FLUX.2-Klein-4B).
- **Grounding:** Object localization (using Grounding-DINO).
- **SAM:** Mask generation (using SAM).
- **Extract:** Object extraction (using a Python script).
- **Overlay:** Object/text compositing (using a Python script).
- **Crop:** Region cropping (using a Python script).
- **OCR:** Text recognition (using Paddle-OCR).
- **Rotate/Flip:** Geometric transformations (using Python scripts).
- **SR (Super-Resolution):** Image enhancement (using Real-ESRGAN).
Each tool has structured JSON-style inputs and outputs, facilitating their composition into complex workflows.

**4.1.2 Construction of CanvasCraft-SFT:** This subset provides fully annotated executable trajectories. Each sample includes a user instruction (Q), optional input images (I), an executable tool-use trajectory (τ) detailing step-level reasoning, tool calls, parameters, intermediate assets, and the final output image (I_final).
The construction pipeline involves:
1. **Tool-chain design:** Templates are designed to cover atomic operations and inter-tool dependencies.
2. **Image sampling:** Input images are sampled from PICO-Banana-400K.
3. **Instruction generation:** Natural user instructions are reverse-engineered from the intended tool-use behavior.
4. **Tool execution and quality control:** The instructions are executed in the tool environment, and only trajectories passing checks (e.g., tool-call parsability, parameter validity, asset-reference consistency, execution success, non-redundancy) are retained. CanvasCraft-SFT contains 140K trajectories, including 3.8K examples with longer execution paths and richer tool combinations.

**4.1.3 Construction of CanvasCraft-RL:** This subset contains 10K task specifications without complete trajectories, allowing for policy exploration during RL. Each sample includes a user instruction (Q), optional input images (I_0), and an expected tool set (T).
The construction process focuses on three task dimensions:
- **Reasoning (R):** Complexity of conditional reasoning and state awareness.
- **Trajectory Length (L):** Number of expected execution steps.
- **Tool Diversity (D):** Number of distinct tools required.
Diverse task seeds are generated, expanded into natural user instructions, and annotated with expected tool sets. Tasks are then filtered by a large language model (DeepSeek-V4-Flash) and human annotators for ambiguity, simplicity, or inconsistency. Initial images are generated for visually grounded tasks. This subset emphasizes medium and hard difficulty levels across R, L, and D dimensions.

#### 3.2. Two-Stage Training Framework

CanvasAgent is trained using a two-stage SFT+GRPO framework.
1. **SFT for Tool-Use Bootstrapping:** In the first stage, CanvasAgent is fine-tuned on CanvasCraft-SFT using a standard next-token prediction objective. This stage teaches valid reasoning-action formats, JSON-style tool calls, parameter generation, cross-tool dependencies, and referencing intermediate visual assets. This provides a stable initialization for subsequent reinforcement learning by establishing basic executable behavior.
2. **RL for Image Planning and Manipulation:** After SFT, CanvasAgent is further optimized on CanvasCraft-RL using Group Relative Policy Optimization (GRPO). GRPO samples multiple executable rollouts and updates the policy based on their relative rewards, encouraging exploration of different task decompositions and tool-use strategies under weak supervision.

#### 3.3. Hybrid Reward Design

A task-specific hybrid reward function (R(τ)) is designed to guide RL training, evaluating both the final output and the execution trajectory:
R(τ ) = 0.3 · R_align(τ ) + 0.1 · R_aes(τ ) + 0.2 · R_traj(τ ) + 0.4 · R_rule(τ ).

**4.3.1 Outcome Score:** Evaluates the final image.
- **Alignment Score (R_align):** Measures whether the final image satisfies the user's instruction, focusing on semantic correctness, requested objects, attributes, and actions. An LLM-as-judge model (Qwen3.5-Plus) provides this score.
- **Aesthetic Score (R_aes):** Measures the perceptual quality of the final image, evaluating composition, color, lighting, clarity, and absence of artifacts. This is also provided by an LLM-as-judge.

**4.3.2 Process Score:** Evaluates the execution trajectory.
- **Trajectory Score (R_traj):** Assesses the reasonableness of the trajectory, including logical tool selection, valid dependency handling, concise reasoning, and appropriate verification. An LLM-as-judge provides this score. It penalizes single-tool trajectories.
- **Rule-based Reward (R_rule):** Provides deterministic feedback on low-level executability, combining format reward, action reward, and efficiency penalty:
 - **Format Reward (R_format):** Verifies adherence to the reasoning-action protocol (e.g., valid JSON tool calls, presence of blocks, proper termination).
 - **Action Reward (R_action):** Evaluates the executability of each tool invocation given the current visual state. It checks tool name validity, schema compliance, asset reference validity, tool-specific constraints, and execution success.
 - **Efficiency Penalty (P_eff):** Discourages degenerate or costly trajectories, penalizing failed executions, repeated calls, overly long reasoning segments, excessive tool usage, and missing expected tools.

This hybrid reward balances semantic, perceptual, procedural, and symbolic constraints to provide comprehensive supervision and mitigate reward hacking.

### 4. Main Findings and Results

The research evaluates CanvasAgent on the CanvasCraft-RL evaluation split, comprising 250 complex image creation and editing tasks. Performance is assessed using six metrics: Overall Reward (the hybrid reward), Alignment Score, Aesthetic Score, Trajectory Score, Rule-based Score, and average Trajectory Length.

#### 4.1. Quantitative Evaluation

The results demonstrate the effectiveness of CanvasAgent and the proposed two-stage training:
- **Comparison with general-purpose MLLMs:** Base models like LLaVA-OneVision-7B and Qwen3-VL-8B-Instruct, when equipped with CanvasCraft tools but without CanvasCraft training, exhibited low overall rewards (0.402 and 0.426, respectively) and particularly low trajectory scores (0.132 and 0.092). Qwen3-VL-32B-Instruct showed a higher trajectory score (0.512) but suffered in alignment and aesthetics, suggesting difficulties in effective tool orchestration despite a larger model size.
- **Impact of SFT:** CanvasAgent (SFT), trained only on CanvasCraft-SFT, significantly improved the overall reward to 0.557 and the trajectory score to 0.576 compared to the Qwen3-VL-8B-Instruct baseline. This indicates that supervised fine-tuning on executable trajectories effectively teaches structured reasoning-action formats and basic tool-use capabilities. However, its average trajectory length was low (1.320), suggesting limited active multi-tool planning.
- **Impact of RL:** CanvasAgent (SFT+RL), the full model incorporating reinforcement learning with GRPO, achieved the highest performance across all metrics. It boosted the overall reward to 0.821, image-prompt alignment to 0.869, trajectory quality to 0.849, and the rule-based score to 0.785. The average number of tool calls increased substantially from 1.320 (SFT-only) to 5.436, indicating that RL effectively encouraged richer multi-step visual manipulation and dynamic task decomposition.
- **Comparison with image-only models:** Reference models such as Qwen-Image-2.0, Wan2.7-Image, and GPT-Image-2, which directly generate or edit final images, demonstrated high aesthetic scores (e.g., GPT-Image-2 at 0.895) but their alignment scores were lower than CanvasAgent (SFT+RL) (0.799 vs. 0.869). This suggests that even advanced image-only models struggle with the complex, multi-step requirements of the tasks, which benefit from tool orchestration.

#### 4.2. Ablation Studies

Ablation studies confirmed the contributions of both the two-stage training strategy and the hybrid reward design:
- **Training Strategy:** SFT-only training established executable patterns (overall reward 0.557). RL from scratch (RL Only) improved the overall reward slightly (0.604) but led to unstable exploration, hurting alignment and aesthetics. The SFT+RL combination achieved the best performance (0.821 overall reward, 0.869 alignment, 0.762 aesthetics, 0.849 trajectory score), validating the necessity of both stages.
- **Reward Design:** Removing the outcome reward (w/o outcome reward) maintained a high trajectory score (0.907) but significantly decreased alignment (0.320) and aesthetics (0.565). Conversely, removing the process reward (w/o process reward) drastically reduced the overall reward (0.379) and trajectory score (0.357). The full hybrid reward yielded the most balanced performance, demonstrating that both outcome-level (alignment, aesthetics) and process-level (trajectory, rule-based) signals are crucial and complementary for robust optimization.

#### 4.3. Qualitative Case Study

A qualitative example illustrated CanvasAgent's ability to handle complex multi-image editing. Given three input images and an instruction requiring text extraction, translation, reconstruction, and compositing into a new scene while preserving visual consistency, CanvasAgent successfully executed a multi-turn trajectory. This involved using perception (Grounding, SAM, OCR), extraction, editing, and compositing tools. The agent demonstrated closed-loop visual orchestration by performing self-checks with OCR and Grounding after editing operations to verify intermediate results and adapt subsequent actions, highlighting its iterative reasoning and refinement capabilities.

#### 4.4. Human Evaluation

A human evaluation on 12 samples corroborated the automatic metrics. Human annotators scored CanvasAgent highest across Task Alignment, Key Details Alignment, and Aesthetic Quality, indicating superior instruction satisfaction, information preservation, and visual quality compared to general-purpose MLLMs.

### 5. Significance and Potential Impact

This research introduces CanvasAgent and CanvasCraft, contributing significantly to the field of multimodal AI agents for visual creation.

The primary significance lies in addressing the long-standing challenge of enabling complex image creation and editing tasks that require multiple, heterogeneous visual operations orchestrated in a coherent, multi-turn workflow. Existing approaches primarily focused on single-step editing or perception-oriented reasoning. CanvasAgent, by learning to actively transform visual states and manage intermediate assets, moves beyond these limitations.

Specifically, the contributions and their potential impact include:
- **First Tool-Augmented Multimodal Agent for Complex Image Creation:** CanvasAgent demonstrates that MLLMs can be trained to orchestrate diverse visual tools for generation, editing, extraction, composition, transformation, and enhancement through multi-turn reasoning. This paradigm shift can reduce the manual effort required in professional design, prototyping, and general image editing workflows, making complex visual tasks more accessible.
- **Novel Large-Scale Multimodal Tool-Use Dataset:** CanvasCraft is presented as the first large-scale dataset specifically designed for complex image creation and editing. Its two components, CanvasCraft-SFT (140K fully annotated trajectories) and CanvasCraft-RL (10K RL task specifications), provide crucial supervision that was previously unavailable. This dataset can serve as a benchmark and training resource for future research in visual tool orchestration, fostering advancements in agentic visual intelligence.
- **Robust Training Framework with Hybrid Reward:** The two-stage SFT+GRPO training framework, combined with the proposed hybrid reward system, is critical for CanvasAgent's success. The hybrid reward, which integrates outcome-level (alignment, aesthetics) and process-level (trajectory validity, rule-based executability, efficiency) signals, provides comprehensive guidance for optimizing both the final visual output and the underlying tool-use strategy. This approach mitigates issues like unstable exploration and reward hacking, enabling robust learning for complex, long-horizon tasks.

The ability of CanvasAgent to perceive intermediate results, track visual assets, and adapt tool decisions based on evolving visual states represents a step towards more autonomous and intelligent visual assistants. This work establishes a foundation for future research into dynamic tool discovery, self-improving agents, and extensions to more complex media like video, potentially unlocking new creative possibilities and increasing productivity in visual content generation.

However, the increased capabilities for generation and editing also highlight the importance of responsible deployment, as stronger visual manipulation tools could be misused for deceptive or harmful content. The authors acknowledge these broader impacts, emphasizing the need for responsible release, dataset filtering, and clear documentation of limitations.
