# Dynamic Manipulation with World-Action Models via Counterfactual Planning

> [!summary] Summary
> Dynamic Predictive Planning (DPP) lets frozen World-Action Models trained only on static demonstrations manipulate moving targets without retraining. It uses the model's own rollout to predict when a grasp or release will occur and extrapolates target motion to that moment. It then edits a counterfactual observation that places the target there in a familiar robot context, and bridges the resulting plan onto the robot's live state. DPP reaches 83% bimanual-grasp success, versus 52% for dynamically trained baselines.

## Problem

- Reactive replanning pairs advanced robot states with relocated targets never seen together in static demonstrations, which pushes frozen policies outside their demonstrated action support.
- Pretrained World-Action Models suffer target-response collapse: later robot context biases rollouts toward the learned continuation, and grasp-response gain falls from 0.897 to 0.078 after 48 actions.
- Existing dynamic-manipulation methods, such as motion-aware policies, synthesized dynamic episodes or future-token predictors, need extra dynamic data or trained modules instead of reusing existing static skills.

## Method

- ==Interaction-time prediction==: the model rolls out past its native action chunk, a task predicate detects the first grasp or release action, and ==SAM 2== plus ==FoundationPose== fit the target's motion to that time.
- ==Counterfactual canonical planning==: RGB-D editing moves the target to its predicted interaction position inside the initial robot observation and proprioception, so the frozen model invokes a familiar static skill.
- Asynchronous execution with an ==activation bridge==: the robot executes initial-plan actions while planning runs, joins the canonical trajectory through a velocity-limited ==inverse-kinematics bridge==, then replans from its realized state with time resampling.

## Results

- On RoboTwin2.0-Dyn, FastWAM with DPP reaches **83.33%** bimanual grasp and **80.73%** pick-and-place, versus **52.00%**/**53.13%** for DynamicWAM and **50.33%**/**9.38%** for PUMA, both trained on dynamic data.
- On a real robot, DPP scores **76.7%** on moving piggy-bank pick-and-place, where reactive and future-conditioned baselines score **0%**, and **86.7%** on ball interception versus **40.0%** for reactive.
- Ablations: removing canonical-state conditioning drops success from **83.33%** to **51.67%** and removing initial execution drops it to **50.33%**; removing current-state planning costs only **3.33** points.

## Takeaways

> [!tip] Key Insights
> - Failures under distribution shift can reflect skills that are inaccessible rather than missing; rewriting the conditioning context can retrieve learned behavior without any retraining.
> - Separating the context used to generate a plan from the state used to execute it is a general way to reuse frozen policies outside their training support.
> - Simply showing a policy fixed-horizon future frames helps little; predicting when the interaction happens is what makes world-model rollouts useful for moving targets.

## Detailed Report

### 1. Overview

A real robot must grasp a moving piggy bank and place it in a basin. A robot can know how to grasp an object and still fail when that object moves during execution. Reacting to the object's current position may be too late. DPP instead plans for where the target is expected to be at interaction time, then joins that plan to the robot's real, moving execution. It is a way to reuse a learned skill, not to teach the model a new dynamic skill.

An illustrative successful DPP trial on Task A: picking the moving piggy bank (5.2–7.3 cm/s) and placing it in the basin, played at real-time speed.

In Task A, complete-task success requires both grasp and placement, not merely contact. The paper evaluates each method over 30 trials per task.

### 2. Why "just replan" can fail

A World–Action Model (WAM) predicts future visual states as well as actions. Static demonstrations often start from a shared robot pose and vary the target. Later robot poses then become tied to particular demonstrated target locations. When the target moves, replanning from each new view can pair a later robot pose with a target location that was absent from the demonstrations.

The authors call the measured pattern **target-response collapse**: the model adjusts less to a moved target as execution advances. They measured this with a directional target-response gain. The gain compares how far the predicted grip point shifts in the direction the target was moved with the size of that displacement. A gain near one means the plan follows the relocation, and a gain near zero means little adjustment. In FastWAM's matched-prefix roller-grasp probe, the mean gain declines from 0.897 at zero executed actions to 0.078 after 48 actions. This average covers the same 33 noncentral cells of a fixed, empirically defined static-support set.

The probe shows a decline in behavior, but it does not inspect the model's internal cause. Uneven demonstration support is a plausible explanation, not a proven sole cause. Missing temporal information, prediction error, delayed actuation, and insufficient static competence can also contribute.

### 3. How DPP changes the planning query

DPP works in five steps:

1. The WAM rolls out a skill and detects a task-specific predicted event, such as a grasp.
1. Target tracking estimates the target's motion, and DPP evaluates that estimate at the event time to predict the interaction position.
1. DPP builds a counterfactual planning observation that shows the target at the predicted position. It edits RGB–D geometry consistently across views and preserves robot occlusion.
1. DPP generates a canonical plan from the initial robot context. The robot does not jump to that state. It keeps executing available actions, and an activation bridge then connects its actual state to the canonical plan.
1. After the bridge, DPP uses fresh observations and the current robot state to refine the rest of the trajectory, while keeping the predicted interaction position as its planning target.

DPP pipeline (schematic, not a measured trajectory). Canonical planning pairs the initial robot state $S_{0}$ with the predicted target $\hat{x}(\tau)$. Current-state planning pairs a later state $S_{k}$ with that same target. The unscaled timeline shows planning overlapping execution.

### 4. What the evidence shows

On RoboTwin2.0-Dyn T1 Bimanual Grasp, FastWAM + DPP reached 83.33% official task success, compared with 52.00% for DynamicWAM. Each method ran 300 trials. The scenes were within empirically validated static-support regions. DynamicWAM received additional dynamic-task training, and DPP did not. DPP achieved the highest reported success among the evaluated methods on both main simulator tasks with both tested WAM backbones.

RoboTwin2.0-Dyn results. T1 is Bimanual Grasp. Compare the T1 Success entries: FastWAM + VP DPP scores 83.33 and DynamicWAM scores 52.00. The additional-training column marks DynamicWAM "O" and DPP "X". Contact is a separate diagnostic and is not the success metric.

A canonical-state ablation tests the mechanism. In this variant, the canonical-state conditioning is replaced with the current robot context. Initial execution, the inferred interaction time and target, and later current-state planning are all kept. T1 success falls from 83.33% to 51.67%. This result supports the importance of canonical conditioning in this system. It does not show that canonical conditioning alone explains the result.

### 5. A skill, more accessible

DPP's contribution is to ask an existing policy for its known skill in a context that matches the future interaction, then reconnect that plan to the real robot. The authors describe the counterfactual observation as an implicit retrieval query for learned manipulation capabilities. The method depends on predictable target motion over the planning horizon and on the relevant static skill already being present in the backbone. Its event-derived interaction time is a practical prior, not an optimized time for a moving target.
