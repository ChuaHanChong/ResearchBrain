# ReFocus: Visual Editing as a Chain of Thought for Structured Image Understanding

> [!summary] Summary
> This paper introduces REFOCUS, a framework that enhances multimodal LLMs' structured image understanding through iterative visual editing and reasoning

## Problem

- Current multimodal LLMs lack selective attention and multi-hop visual reasoning abilities
- Models typically limit intermediate reasoning to text formats only
- Understanding structured images like tables and charts requires strategically focusing on different parts

## Method

- Introduces ==REFOCUS framework== that enables LLMs to generate and execute Python code for ==visual editing==
- Allows models to draw boxes, highlight sections, and mask areas to enhance visual reasoning
- Creates a ==multi-step iterative process== where models can iteratively edit and reason about images

## Results

- Improved performance over GPT-4o baseline by **11.0%** on table tasks and **6.8%** on chart tasks
- Consistent gains across multiple types of structured image understanding tasks
- Models finetuned on REFOCUS data outperform those trained on standard QA pairs by **8.0%**
- Visual chain-of-thought supervision yields **2.6%** improvement over standard chain-of-thought training

## Takeaways

> [!tip] Key Insights
> - Visual editing helps models achieve selective attention without introducing additional information
> - The approach improves OCR abilities and reduces hallucinations through focused attention
> - REFOCUS data provides better supervision than standard QA pairs when used for model training
> - Simple visual editing techniques can significantly boost model performance on structured image tasks

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Multimodal large language models (LLMs) have shown remarkable capabilities in combining visual and textual understanding. However, when faced with complex structured images like tables and charts, these models struggle with what researchers call "multi-hop selective attention" - the ability to dynamically focus on relevant visual information across multiple reasoning steps. REFOCUS addresses this fundamental limitation by introducing a framework that enables multimodal LLMs to generate "visual thoughts" through programmatic image editing.

#### 1.1. The Problem with Current Multimodal LLMs

Traditional approaches to structured image understanding typically follow a two-stage process: first, extract visual information (often through OCR), then perform textual reasoning using techniques like Chain-of-Thought prompting. While effective for simple tasks, this approach has a critical flaw - the models "never look back at the image again" after initial extraction.

This limitation becomes particularly problematic when dealing with:
- Dense tables with multiple rows and columns
- Charts with overlapping data points
- Images requiring multi-step visual reasoning
- Scenarios where irrelevant visual elements create distractions

The result is often hallucination, misgrounding of visual elements, or incorrect interpretation of structured data. Existing solutions like Visual Programming (VisProg) or Visual Sketchpad attempt to address these issues but either operate primarily on textual representations or rely on external computer vision tools that add information rather than refining attention.

### 2. Key Objectives and Motivation

The key insight behind REFOCUS is that human understanding of structured data inherently involves strategic shifts in visual attention. When analyzing a complex table or chart, humans naturally highlight relevant sections while mentally filtering out distractions. Current multimodal LLMs lack this selective attention mechanism, often leading to errors when processing visually dense information.

### 3. Methodology and Approach

#### 3.1. REFOCUS Framework Overview

REFOCUS introduces an iterative framework where multimodal LLMs can modify their own visual input through Python code generation. The process works as follows:

1. **Initial Analysis**: The LLM receives an image and question, generating a "THOUGHT" about its reasoning strategy
2. **Action Generation**: If visual editing is needed, the LLM generates Python pseudocode calling predefined image editing functions
3. **Visual Modification**: REFOCUS executes the code, applying edits like masking, highlighting, or drawing boxes
4. **Iterative Refinement**: The edited image becomes the new input for the next reasoning step
5. **Final Answer**: The process continues until the LLM has sufficient information to provide an answer

This approach enables the model to perform "visual chain-of-thought" reasoning by strategically modifying its visual input at each step, effectively simulating human-like selective attention.

#### 3.2. Visual Editing Tools and Implementation

REFOCUS provides three fundamental types of visual editing operations:

**Core Editing Methods:**
- **Mask Out**: Places white masks over irrelevant areas to eliminate distractions
- **Draw Box**: Overlays red bounding boxes around focus areas
- **Highlight Color**: Adds semi-transparent red overlays to relevant regions

**Task-Specific Adaptations:**

For **table tasks**, the framework provides tools like:
- `Highlight Column/Row`: Focus on specific table sections
- `Mask Column/Row`: Remove irrelevant table parts
- `Draw Column/Row`: Emphasize important table elements

For **chart tasks**, tools focus on:
- Subplot manipulation for complex scientific charts
- Bar selection by x-values or y-values
- Coordinate-based focusing for different chart types

**Technical Implementation:**
The system uses OpenCV for coordinate acquisition, detecting table structures through line and box analysis, and identifying chart elements through contour detection. The LLM generates Python pseudocode that calls these functions with appropriate parameters (column names, row headers, coordinate values), which REFOCUS then executes to produce the modified images.

### 4. Main Findings and Results

#### 4.1. Experimental Results and Performance Gains

REFOCUS demonstrated substantial performance improvements across multiple structured image understanding benchmarks:

**Table Understanding Results:**
- **VWTQ (Wikipedia tables)**: 10.4% improvement over vanilla GPT-4o
- **VWTQ_syn (synthetic tables)**: 3.4-12.4% improvement depending on model version
- **VTabFact**: Modest improvements of 0.0-0.8%
- **Overall table performance**: 11.0% average gain

**Chart Understanding Results:**
- **CharXiv (scientific charts)**: 8.3% improvement (with some variability across model versions)
- **Horizontal Bar Charts**: 7.2% improvement
- **Vertical Bar Charts**: 4.8% improvement
- **Overall chart performance**: 6.8% average gain

**Key Findings:**
1. **Consistent Outperformance**: REFOCUS+GPT-4o consistently outperformed other state-of-the-art multimodal LLMs including LLaVA-NeXT-34B, Phi-3 vision, and Gemini-Pro 1.5
2. **Equivalence to Text Input**: Performance often matched or exceeded GPT-4o given "gold text + figure inputs," suggesting REFOCUS enables near-perfect visual information extraction
3. **High Usage Frequency**: GPT-4o chose to perform visual edits in over 85% of VWTQ and CharXiv cases, indicating the tools' utility

The improvements stem from enhanced visual grounding, reduced hallucinations, and more accurate OCR capabilities achieved through strategic attention focusing.

#### 4.2. Visual Chain of Thought for Model Training

A significant finding emerged from experiments using REFOCUS-generated data for model training. The researchers collected a 14,000-sample dataset containing rich "Visual Chain-of-Thought (VCoT)" data that includes:

- Original images and questions
- LLM-generated thoughts and reasoning steps
- Python code for visual editing
- Bounding box coordinates for focus areas
- Edited images and subsequent reasoning
- Final answers

**Training Results:**
When fine-tuning Phi-3.5-vision with this VCoT data:
- **3.2%** improvement over the base model
- **8.0%** improvement over training with standard QA pairs
- **2.6%** improvement over text-only Chain-of-Thought training

This demonstrates that explicit visual reasoning steps provide a superior supervision signal compared to traditional training approaches, suggesting a new paradigm for multimodal model training.

### 5. Significance and Potential Impact

#### 5.1. Significance and Future Implications

REFOCUS represents a significant advancement in multimodal AI by addressing fundamental limitations in visual reasoning capabilities. Its importance extends across several dimensions:

**Technical Contributions:**
- First framework to enable "visual chain-of-thought" through programmatic image editing
- Achieves substantial performance gains without external knowledge injection
- Provides interpretable reasoning traces through visual editing sequences
- Demonstrates superior supervision signals for model training

**Practical Applications:**
The enhanced structured image understanding capabilities have direct implications for:
- Scientific document analysis and data extraction
- Financial statement interpretation and analysis
- Business intelligence from visual dashboards
- Accessibility tools for complex visual information

**Research Directions:**
REFOCUS opens new avenues for exploration in multimodal AI, encouraging research into:
- Dynamic visual perception and interaction
- Interactive data analysis systems
- Visual problem-solving agents with strategic attention
- More sophisticated visual reasoning architectures

The framework's simplicity and effectiveness suggest that enabling LLMs to "think visually" through explicit image manipulation may be a fundamental step toward achieving more genuinely intelligent multimodal understanding. By demonstrating that strategic visual focus can unlock latent model capabilities, REFOCUS provides both a practical solution to current limitations and a conceptual foundation for future advances in multimodal artificial intelligence.
