# AutoDex: An Automated Real-World System for Dexterous Grasping Data Collection

> [!summary] Summary
> AutoDex is an automated real-world system that collects physically validated data for multi-finger dexterous grasping, achieving a 4.8x higher throughput than human teleoperation. It uses dense multi-camera perception and active grasp-based object resetting, demonstrating that physically validated grasps achieve 76% real-world success compared to 34% for simulation-screened candidates.

## Problem

- Learning robust dexterous grasping policies is challenged by the lack of large-scale, physically validated real-world data, as simulation often fails to capture complex contact mechanics.
- Existing data collection methods for dexterous grasping are either slow and prone to human bias (teleoperation) or suffer from significant 'sim-to-real' gaps (simulation-based synthesis).
- Fully automated data collection for multi-finger dexterous grasping is difficult due to requirements for robust object tracking under occlusion, reliable success/failure labeling, and efficient inter-trial scene reset.

## Method

- **AutoDex** integrates a grasp candidate generator with an automated real-world execution system, featuring a ==20-camera multi-view perception== system for robust object pose estimation and tracking.
- The system performs collision-monitored grasp execution with a multi-finger hand, automatically labeling grasp success or failure post-hoc based on 6D object pose tracking.
- An active, grasp-based reset module precisely reorients objects to different stable poses, enabling comprehensive testing of candidates across various object orientations.

## Results

- AutoDex achieved a **4.8x** higher throughput for data collection compared to human teleoperation, gathering 500 grasp trajectories in **10.3** hours.
- Real-world success rates for physically validated grasps from AutoDex reached **76%**, substantially higher than the **34%** success rate for simulation-screened grasps.
- The active 'Stable Reorient Placement' reset method consistently achieved near **100%** success in transitioning objects to target stable poses, proving reliable for unattended operation.

## Takeaways

> [!tip] Key Insights
> - Physical validation of grasp candidates on real hardware is crucial to overcome the sim-to-real gap, as simulation-based screening alone poorly predicts real-world dexterous grasp success.
> - Dense, multi-camera perception is critical for reliable 6D object pose estimation and tracking during dynamic dexterous manipulation, especially when the robot hand heavily occludes the object.
> - Active, grasp-based object resetting is a reliable and efficient method for inter-trial scene reconfiguration, enabling a wider exploration of grasp candidates across stable object poses compared to passive dropping.
