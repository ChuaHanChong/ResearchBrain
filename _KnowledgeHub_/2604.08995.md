# Matrix-Game 3.0: Real-Time and Streaming Interactive World Model with Long-Horizon Memory

> [!summary] Summary
> Researchers at Skywork AI developed Matrix-Game 3.0, an interactive world model that achieves real-time, 720p generation at up to 40 FPS with a 5B parameter model. This system integrates advancements in data generation, model architecture, and inference optimization to maintain memory-enabled long-term temporal consistency over minute-long sequences.

## Problem

- Existing interactive world models struggle to concurrently deliver high-resolution output, real-time performance, and long-horizon memory consistency.
- A significant data bottleneck exists in acquiring large-scale, high-quality, and precisely annotated video datasets required for training robust interactive models.
- Current approaches face trade-offs between maintaining long-horizon memory, coherence, and controllability, and managing error accumulation during streaming inference.

## Method

- Developed an industrial-scale data engine to generate high-quality Video–Pose–Action–Prompt quadruplet data from synthetic, AAA game, and real-world sources.
- Designed an error-aware interactive Diffusion Transformer (DiT) base model with a novel camera-aware memory retrieval and injection mechanism for long-horizon consistency.
- Implemented a training–inference aligned few-step distillation pipeline and a real-time acceleration module featuring DiT quantization, pruned VAE, and GPU-based memory retrieval.

## Results

- Achieved real-time generation speeds of up to 40 FPS at 720p resolution with a 5B parameter model in an asynchronous 8+1 GPU setup.
- The memory-augmented base model successfully recovered previously observed scene structures and fine-grained appearance details during scene revisitation, demonstrating effective long-term memory.
- Scaling the model to 28B parameters resulted in enhanced temporal consistency in scene layout, character identity, and vivid motion dynamics under continuous camera and action changes.

## Takeaways

> [!tip] Key Insights
> - Training an interactive base model with error injection and collection enhances its robustness to imperfect historical contexts, crucial for stable streaming inference.
> - A unified self-attention mechanism, processing memory, history, and current latents with camera-aware Plücker encoding, enables effective long-horizon memory integration.
> - Strategic inference accelerations, such as INT8 quantization, VAE pruning, and GPU-based memory retrieval, are essential for achieving real-time high-resolution generation.
