# Entropy Is Not Enough: Unlocking Effective Reinforcement Learning for Visual Reasoning via Vision-Anchored Token Selection

> [!summary] Summary
> Researchers from Fudan University developed VEPO, a framework that integrates vision-sensitivity with token entropy to address the failure of traditional entropy-based token selection in reinforcement learning for visual reasoning. This method, using Jensen–Shannon Divergence and absolute entropy gap, achieved an average accuracy of 58.82% at 7B-scale, outperforming full-token baselines by +1.71 points and showing competitive performance against significantly larger models.

## Problem

- Traditional entropy-based token selection, effective in text-only RL tasks, collapses when applied to visual reasoning, often underperforming full-token baselines.
- This failure stems from the omission of critical, vision-sensitive tokens which frequently exhibit low entropy as visual evidence can resolve ambiguities.
- Existing multimodal RL approaches struggle to systematically measure and integrate visual signals with token entropy for effective credit assignment in complex visual reasoning.

## Method

- **VEPO** employs a dual pass: a standard rollout with the original image and a counterfactual pass with a noise-perturbed image to obtain distinct next-token distributions.
- Token-level visual dependency is quantified using ==Jensen–Shannon Divergence== (JSD) to measure distributional shifts and Absolute Entropy Gap (|∆H_t|) to capture changes in predictive uncertainty due to visual perturbation.
- A joint ==vision-entropy score== is computed by multiplicatively combining these visual signals with normalized token entropy, enabling the selection of tokens that are both visually grounded and semantically informative for policy gradient updates.

## Results

- VEPO-7B achieved an average accuracy of **58.82%** on visual reasoning benchmarks, outperforming the strongest entropy-only baseline by +2.28 points and the full-token GRPO baseline by +1.71 points.
- The method demonstrated consistent improvements on a 3B-scale model and showed competitiveness with several open-source multimodal models that are 4 to 10 times larger.
- Ablation studies confirmed that all three components (JSD, absolute entropy gap, and policy entropy) are complementary and crucial for VEPO's performance, with visual signals contributing most significantly.

## Takeaways

> [!tip] Key Insights
> - The entropy-only token selection mechanism, while effective in text-only contexts, fails in visual reasoning because visually-grounded tokens often inherently exhibit low entropy due to visual disambiguation.
> - Visual dependency can be systematically captured at the token level by measuring distributional shifts (JSD) and changes in predictive uncertainty (|∆H_t|) when visual input is perturbed.
> - Effective credit assignment in multimodal reinforcement learning requires explicitly coupling visual sensitivity with token entropy, rather than solely relying on semantic uncertainty for identifying critical reasoning steps.
