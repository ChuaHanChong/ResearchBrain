# Simple Image-level Classification Improves Open-vocabulary Object Detection

> [!summary] Summary
> A method for Open-Vocabulary Object Detection (OVOD), SIC-CADS, integrates global scene understanding from Vision-Language Models (VLMs) by training a multi-label recognition module to generate image-level contextual scores that refine instance-level detection scores. This approach leads to 1.4-3.9 points improvement in AP_r on OV-LVIS and 1.7-3.2 points in AP_novel on OV-COCO, while also improving cross-dataset generalization.

## Problem

- Existing Open-Vocabulary Object Detection (OVOD) methods insufficiently utilize the global scene understanding capabilities of Vision-Language Models (VLMs).
- OVOD models struggle to accurately detect "hard objects" (small, blurred, occluded, ambiguous) as these rely heavily on surrounding contextual information, which regional features often miss.
- There is a performance gap in detecting novel object categories, particularly for challenging instances, due to the lack of explicit contextual feature learning for these classes.

## Method

- SIC-CADS introduces a ==Multi-modal Multi-Label Recognition (MLR) module== that leverages CLIP's global image encoder to predict image-level scores for object categories.
- The MLR module combines a ==Text MLR branch==, aligning learned image embeddings with CLIP text embeddings, and a ==Visual MLR branch==, distilling knowledge from the CLIP image encoder.
- Instance-level detection scores from existing OVOD models are refined by fusing them with the MLR module's image-level contextual scores using a ==weighted geometric mean== during inference.

## Results

- SIC-CADS consistently improved novel category detection by **1.4-3.9** AP_r points on OV-LVIS and **1.7-3.2** AP_novel points on OV-COCO across various base models.
- The method enhanced cross-dataset generalization, showing **1.9-2.1** mAP_50 points gain on Objects365 and **1.5-3.9** mAP_50 points gain on OpenImages.
- Achieved these gains with minimal additional computational cost (**8.3-12.5%** increase in GFLOPs) and only a marginal decrease in inference speed (FPS).

## Takeaways

> [!tip] Key Insights
> - Vision-Language Models (VLMs) possess rich global scene understanding, including object co-occurrence patterns, that is underexploited by region-focused Open-Vocabulary Object Detection (OVOD) models.
> - Explicitly leveraging image-level global contextual information from VLMs can substantially improve the detection of challenging objects (small, occluded, ambiguous), especially for novel categories.
> - A lightweight, independently trained multi-label recognition module can serve as a general and efficient plug-and-play mechanism to boost the performance of diverse OVOD architectures.
