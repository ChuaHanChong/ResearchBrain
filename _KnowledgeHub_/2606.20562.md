# MemoryWAM: Efficient World Action Modeling with Persistent Memory

> [!summary] Summary
> A hybrid memory design is presented for World Action Models, enabling efficient and persistent long-range context for robotic manipulation in memory-dependent tasks. This approach achieves comparable or superior performance to full-history models on benchmarks like RMBench and real-world scenarios while significantly reducing inference latency and GPU memory consumption.

## Problem

- Vision-Language-Action (VLA) models often lack explicit memory of historical events and a direct model of world dynamics, struggling with non-Markovian tasks.
- Existing World Action Models (WAMs) face a trade-off: efficient models use a fixed-size sliding window (short-term memory), while autoregressive models (full history) incur linear increases in computational cost for long-horizon tasks.
- Robotic manipulation tasks requiring long-range temporal context, such as recalling transient or occluded information, are challenging due to the limitations of current memory mechanisms.

## Method

- **MemoryWAM** introduces a hybrid memory design, inspired by human cognition, integrated into a Mixture-of-Transformers (MoT) architecture.
- The memory system combines three components: a sliding-window short-term memory for immediate, high-fidelity context; ==event-boundary memory== for persistent 'anchor frames' (e.g., task initiation); and gist memory for compressing long-range history.
- Gist memory uses learnable 'gist tokens' (8 tokens per frame, 15x compression) to summarize past observations, replacing full visual tokens and allowing action generation to attend to this compact historical representation.

## Results

- MemoryWAM achieved an average success rate of **83.0%** on the RMBench simulation benchmark, outperforming full-history WAMs (LingBot-VA at **78.2%**) and short-term baselines (FastWAM at **5.9%**).
- On real-world memory-dependent tasks, MemoryWAM achieved 18/20 successes on "Shell Game" and 15/20 on "Look and Press", surpassing LingBot-VA and policies without persistent memory.
- The hybrid memory approach substantially reduced inference latency and GPU memory usage compared to full-attention methods, achieving the same **87%** success rate as full attention on the 'Press Button' task while exhibiting more favorable computational scaling.

## Takeaways

> [!tip] Key Insights
> - A hybrid memory system, combining detailed short-term context, salient event boundaries, and compressed long-term gist, effectively overcomes the memory-efficiency trade-off in WAMs.
> - Selectively compressing long-range historical information into 'gist tokens' can be more effective than retaining an entire uncompressed history, potentially by filtering redundant information, leading to better performance and efficiency.
> - Drawing inspiration from human cognitive memory architectures provides a viable strategy for designing artificial intelligence systems capable of robust and scalable long-horizon decision-making.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of robotic manipulation is advancing through the development of models that can robustly interact with the real world. Two dominant paradigms have emerged: Vision-Language-Action (VLA) models and World Action Models (WAMs).

VLA models, such as RT-2 and OpenVLA, leverage large-scale vision-language models to achieve generalization across various tasks by transferring semantic priors to robot control. While effective for tasks that primarily rely on current observations and semantic understanding, most VLAs operate by mapping current observations directly to actions. This policy-centric approach often lacks explicit memory of historical events and a direct model of how the physical world evolves through robot interaction. Consequently, they may struggle with non-Markovian tasks where crucial information is transient, occluded, or has delayed effects, or tasks requiring reasoning about physical dynamics over extended periods.

World Action Models (WAMs) address these limitations by jointly modeling visual foresight (predicting future observations) and actions, conditioned on both current and historical observations. By grounding manipulation in learned world dynamics, WAMs offer a pathway toward memory-aware and data-efficient robotic manipulation, potentially leveraging large volumes of unlabeled video data. However, existing WAMs face a fundamental trade-off regarding memory efficiency:
- **Efficient WAMs** (e.g., FastWAM, X-WAM) typically rely on a fixed-size sliding window of recent observations. This approach is computationally practical but provides only short-term memory, rendering them inadequate for tasks requiring long-range temporal context.
- **Autoregressive WAMs** (e.g., LingBot-VA, DreamZero) preserve the full history of observations as memory. While this strategy maintains rich temporal context, it leads to computational inefficiency, with inference latency and GPU memory consumption growing linearly with the sequence length, making them impractical for long-horizon tasks.

MemoryWAM positions itself within this landscape by addressing the memory-efficiency trade-off inherent in WAMs. It aims to develop a WAM that can maintain persistent, long-range memory without incurring the substantial computational costs associated with full-history caching. This approach is inspired by human cognitive memory systems, suggesting a more biologically plausible and computationally efficient method for incorporating memory into robotic control.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop an efficient and effective world action model capable of robust robotic manipulation in long-horizon, memory-dependent tasks. The core motivation stems from the limitations of existing robotic manipulation paradigms:

1. **Addressing the "Memory-Efficiency Trade-off" in WAMs:** As detailed in the broader research landscape, current WAMs either sacrifice long-term memory for computational efficiency (sliding-window methods) or achieve persistent memory at the cost of rapidly increasing inference latency and GPU memory usage (full-history caching methods). This trade-off significantly limits their applicability to complex real-world tasks that inherently require recalling past events, even if those events occurred far in the past or are no longer directly observable. The objective is to overcome this dilemma, enabling WAMs to scale to arbitrary task lengths without prohibitive computational overhead.

2. **Enabling Non-Markovian Decision-Making:** Many real-world manipulation tasks are inherently non-Markovian, meaning the optimal action cannot be determined solely from the current observation. Information crucial for decision-making might be transient (e.g., an object briefly visible before being occluded), have delayed effects (e.g., a button press that triggers a distant event), or be part of a long sequence of interactions. Existing WAMs with limited memory struggle with such scenarios. The motivation is to imbue WAMs with a persistent memory mechanism that reliably stores and retrieves task-relevant historical context to support robust decision-making in these complex, memory-dependent environments.

3. **Drawing Inspiration from Human Cognitive Memory:** The authors are motivated by insights from cognitive psychology, which describe human memory as a hybrid system comprising complementary forms:
 - **Short-term memory:** For immediate, ongoing action planning with limited capacity.
 - **Long-term memory:** Preserves abstract "gist" traces rather than exact details.
 - **Event-boundary memory:** Emphasizes salient moments, such as the initiation of a task, for memory organization.
 This biological inspiration suggests that a similarly structured, hybrid memory system could be more efficient and effective for artificial intelligence systems, offering a way to selectively retain high-fidelity, immediate context while compactly summarizing long-range history and marking critical event points.

By pursuing these objectives, MemoryWAM aims to advance the capabilities of robotic manipulation, moving beyond short-horizon, Markovian tasks towards complex, open-world scenarios where memory and dynamics modeling are critical for success.

### 3. Methodology and Approach

MemoryWAM addresses the memory-efficiency trade-off in World Action Models (WAMs) by introducing a hybrid memory design inspired by human cognitive memory. The approach integrates three distinct memory components to maintain persistent historical context efficiently.

#### 3.1. Overview of World Action Model Architecture

MemoryWAM is built upon a Mixture-of-Transformers (MoT) architecture, which consists of a video Diffusion Transformer (DiT) and a separate action DiT.
- **Video DiT (Φ_v):** This component processes visual observations. Given an observation $o_t$, it is first encoded into a compact video latent $z_t$ using a causal video VAE. The video DiT extracts dynamics-aware visual representations and is responsible for maintaining the temporal context (KV cache). During training, it provides dense supervision for dynamics modeling through video prediction, but this expensive video generation is not required during inference, contributing to efficiency.
- **Action DiT (Φ_a):** This component is responsible for predicting future action chunks ($a_{t:t+h-1}$). It denoises action tokens by attending to the cached video representations provided by the video DiT and a task instruction.

The model architecture ensures that the video DiT extracts and manages memory, while the action DiT uses this memory to generate actions.

#### 3.2. Hybrid Memory Design

The core innovation of MemoryWAM lies in its hybrid memory mechanism, which replaces the costly full-history KV cache with a more efficient, selective approach. At any time step $t$, the temporal cache $C_{v}^{\le t}$ is composed of three components:
$C_{v}^{\le t} = C_{v}^{short} \cup C_{v}^{anchor} \cup C_{v}^{gist}$

1. **Short-term Memory ($C_{v}^{short}$):**
 - **Purpose:** To provide high-fidelity, immediate context necessary for closed-loop control and rapidly changing interaction cues (e.g., object motion, contact state).
 - **Mechanism:** Implemented as a sliding-window cache that stores the full visual tokens of the $N_{recent}$ most recent video frames. This bounds the computational cost of attending to immediate history to a constant window size. In the implementation, $N_{recent} = 4$ recent clean frames are used.

2. **Event-Boundary Memory ($C_{v}^{anchor}$):**
 - **Purpose:** To retain crucial information from salient moments, particularly task initiation or initial scene configurations, which may later become occluded or fall outside the short-term memory window.
 - **Mechanism:** A small set of "anchor frames" (e.g., initial observations of a task) are preserved with their full visual tokens. These frames are never evicted from memory. The implementation uses $N_{init} = 2$ initial frames.

3. **Gist Memory ($C_{v}^{gist}$):**
 - **Purpose:** To compress and summarize long-range history efficiently, preventing the linear growth of memory and computational cost associated with full-history attention.
 - **Mechanism:** For video frames that are neither anchor frames nor recent frames, their full visual tokens ($L$ tokens per frame) are not retained. Instead, a small set of $M$ learnable "gist tokens" are attached to each frame. These gist tokens attend to their associated frame's visual tokens and its historical context during training. During inference, when a frame leaves the short-term window and is not an anchor frame, its full visual tokens are evicted from the KV cache, but its corresponding gist tokens are preserved. Subsequent video and action tokens attend to these compact gist tokens, which represent a compressed summary of the historical frame.
 - **Efficiency:** If $L$ is the number of visual tokens per frame and $M$ is the number of gist tokens, the compression ratio is $d = L/M$. The long-term cache size is reduced from $O(N L)$ to $O(N M) = O(N L/d)$, where $N$ is the trajectory length. In the implementation, $L=120$ visual tokens per frame and $M=8$ gist tokens per frame are used, yielding a compression ratio of $d=15$. This results in a 15x reduction in KV cache size for long-term memory compared to full-history attention.

#### 3.3. Attention Mechanism

MemoryWAM employs a tailored attention mechanism that allows the action DiT to query this hybrid memory. Action generation attends to the combined $C_{v}^{short} \cup C_{v}^{anchor} \cup C_{v}^{gist}$. This unified interface allows the model to access high-fidelity recent context, salient task-boundary information, and a compact representation of the long-term history, enabling memory-dependent action generation while managing computational resources.

#### 3.4. Training and Inference Protocol

- **Training:** A continuous flow-matching formulation is used for both video and action branches. During training, a per-frame autoregressive sequence of interleaved clean/noisy video tokens and action chunks is built. The hybrid memory attention mask is applied to ensure the training-time visibility matches the inference-time KV cache. Conditioning latents are augmented with Gaussian noise to prevent overfitting to perfectly clean frames.
- **Inference:** MemoryWAM rolls out autoregressively. After each action chunk is executed, new observations are encoded, and the corresponding keys/values of clean latent frames and gist tokens are prefilled into the hybrid memory KV cache. Video generation is disabled during inference.

This methodology aims to provide a balance between context retention, inference efficiency, and performance for long-horizon robotic manipulation tasks.

### 4. Main Findings and Results

The research evaluates MemoryWAM through a systematic comparison of memory mechanisms, simulation experiments, real-world tasks, and ablation studies.

#### 4.1. Comparison of Memory Mechanisms

A controlled comparison of different memory mechanisms—full attention, test-time training (TTT), recurrent neural networks (RNNs), and MemoryWAM's hybrid memory—was conducted regarding inference latency, GPU memory usage, and task success rate on the "Press Button" task.
- **Efficiency:** Full attention showed rapidly increasing latency and GPU memory usage with sequence length. TTT- and RNN-based methods maintained constant complexity but introduced higher baseline latency and memory usage due to additional parameters and operations. MemoryWAM's hybrid memory demonstrated a more favorable trade-off, substantially reducing inference latency and GPU memory usage, even outperforming RNN- and TTT-based alternatives in efficiency at trajectory lengths up to 1,600 frames.
- **Performance:** While full attention achieved a high success rate (87%) by preserving complete context, its computational cost was high. RNN- and TTT-based methods achieved lower success rates (not specified but implied by the graph to be significantly lower than hybrid memory or full attention), suggesting their compressed states or update-based mechanisms struggled to retain sufficient task-relevant details. MemoryWAM achieved the same 87% success rate as full attention, demonstrating its ability to preserve long-term context effectively while being substantially more efficient.

#### 4.2. Simulation Experiments on RMBench

MemoryWAM was evaluated on RMBench, a benchmark for long-horizon, memory-dependent manipulation tasks requiring policies to retain and retrieve historical observations. Baselines included π$_{0.5}$ (direct observation-to-action), FastWAM (efficient WAM with bounded observation window), and LingBot-VA (WAM with full history).
- **Overall Performance:** MemoryWAM achieved an average success rate of 83.0% across nine tasks, outperforming all baselines.
- **Comparison to Short-Term Memory Baselines:** π$_{0.5}$ and FastWAM, which rely on bounded observation windows, performed poorly, with average success rates of 10.4% and 5.9% respectively, failing on most tasks. This highlights the necessity of persistent memory for RMBench tasks.
- **Comparison to Full-History WAM:** LingBot-VA, which preserves the full historical KV cache, achieved a strong average success rate of 78.2%. MemoryWAM improved upon LingBot-VA by 4.8 percentage points, demonstrating that its compact memory representation can be more effective than retaining all historical tokens, potentially by filtering redundant information. MemoryWAM achieved leading performance on every task.

#### 4.3. Real-World Experiments

MemoryWAM was tested on two challenging real-world memory-dependent tasks: "Shell Game" (tracking occluded objects) and "Look and Press" (counting and working memory). The hardware included an ARX dual-arm robot and a RealSense D455 camera.
- **Performance:** MemoryWAM achieved 18/20 successes on Shell Game and 15/20 on Look and Press.
- **Comparison to Baselines:** π$_{0.5}$ struggled (5/20 on Shell Game, 0/20 on Look and Press). LingBot-VA performed better (13/20 on Shell Game, 14/20 on Look and Press) but was outperformed by MemoryWAM.
- **Efficiency Impact:** The paper notes that LingBot-VA's high inference latency caused it to miss cup swaps in the Shell Game, leading to task failures. MemoryWAM's lower latency and GPU memory cost, combined with superior performance, suggest its practical applicability for real-time robotic manipulation.

#### 4.4. Effectiveness of Design Choices (Ablation Studies)

Ablation studies were conducted on "Cover Blocks" and "Press Button" tasks to evaluate the contribution of each hybrid memory component:
- **"w/o Gist Tokens"**: Removing long-term gist memory led to the largest performance drop, with an average success rate of 40%, indicating the critical role of gist tokens for long-term history.
- **"w/o Anchor Frames"**: Removing event-boundary anchor frames resulted in a performance degradation (average 74.0%), showing the importance of task-boundary information.
- **"w/o Sliding Window"**: Removing the high-fidelity recent frame window also degraded performance (average 82.5%), confirming the complementary benefits of immediate, detailed observations.
- **"Full Attention"**: Retaining all historical video latents without compression achieved an average success rate of 91.5%. While this is higher than most ablations, it was slightly lower than MemoryWAM's 92.5% average on these two tasks. This suggests that simply retaining the entire history is not always optimal, as dense historical context can introduce redundancy and complicate the retrieval of task-relevant information.

Overall, the findings indicate that MemoryWAM's hybrid memory design provides an effective balance between efficiency and performance, outperforming baselines that rely on either short-term memory or uncompressed full history, and demonstrating that selective memory retention can be more advantageous than exhaustive storage.

### 5. Significance and Potential Impact

The development of MemoryWAM presents several significant contributions and potential impacts on the field of robotic manipulation:

1. **Bridging the Memory-Efficiency Gap in WAMs:** The most direct significance of MemoryWAM is its success in overcoming the fundamental memory-efficiency trade-off that has limited the applicability of World Action Models (WAMs). By reducing the time and space complexity from $O(N)$ to $O(N/d)$ (where $N$ is trajectory length and $d$ is the compression ratio) while retaining persistent memory, MemoryWAM makes long-horizon, memory-dependent tasks computationally feasible for WAMs. This paves the way for deploying WAMs in more complex, real-world scenarios that were previously impractical due to escalating computational demands.

2. **Enabling Robust Long-Horizon Robotic Manipulation:** The demonstrated performance improvements on challenging memory-dependent tasks in both simulation (RMBench) and real-world scenarios (Shell Game, Look and Press) indicate that MemoryWAM can significantly enhance the robustness and capabilities of robotic systems. Tasks requiring tracking occluded objects, counting, or remembering transient cues can now be addressed more effectively. This could expand the range of problems that robots can solve autonomously, particularly in unstructured and dynamic environments where historical context is crucial for decision-making.

3. **Validation of Cognition-Inspired Memory Architectures:** The success of MemoryWAM, explicitly inspired by human cognitive memory systems (short-term, event-boundary, and gist memory), provides empirical validation for leveraging principles from biological intelligence in artificial intelligence design. This could encourage further research into biologically plausible memory architectures for other sequential modeling tasks, potentially leading to more efficient, effective, and perhaps more interpretable AI systems.

4. **Systematic Understanding of Memory Mechanisms:** The systematic study and ablation analyses of various memory mechanisms (full attention, TTT, RNNs, and hybrid memory) contribute to a deeper understanding of their respective trade-offs in terms of efficiency and performance for WAMs. The finding that a selectively compressed history can sometimes outperform an uncompressed full history (as suggested by the ablation on "Full Attention") is notable, indicating that intelligent memory management is not merely an efficiency compromise but can be a performance enhancer by potentially reducing noise or irrelevant information.

5. **Practical Deployment in Real-World Robotics:** The ability of MemoryWAM to operate with significantly lower inference latency and GPU memory usage compared to full-history baselines, while achieving superior or comparable performance, is critical for real-world robotic deployment. Reduced latency enables faster reactive control, which is essential for tasks requiring precise timing or interaction with dynamic environments. Lower memory footprint allows for deployment on more constrained hardware.

**Limitations and Future Work:**
The paper acknowledges that MemoryWAM inherits the limitations of video diffusion models, particularly regarding semantic understanding and abstract reasoning capabilities. Future work could address these limitations by integrating dual-system architectures (combining symbolic reasoning with perceptual learning) or by developing unified models that intrinsically bridge these gaps.

In summary, MemoryWAM represents a step forward in creating more capable and practical robotic agents by addressing a key bottleneck in World Action Models. Its impact is likely to be seen in the development of more intelligent and autonomous robots capable of tackling complex, long-horizon tasks in diverse environments.
