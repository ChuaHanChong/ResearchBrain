# MemoryWAM: Efficient World Action Modeling with Persistent Memory

> [!summary] Summary
> A hybrid memory design is presented for World Action Models, enabling efficient and persistent long-range context for robotic manipulation in memory-dependent tasks. This approach achieves comparable or superior performance to full-history models on benchmarks like RMBench and real-world scenarios while significantly reducing inference latency and GPU memory consumption.

## Problem

- Vision-Language-Action (VLA) models often lack explicit memory of historical events and a direct model of world dynamics, struggling with non-Markovian tasks.
- Existing World Action Models (WAMs) face a trade-off: efficient models use a fixed-size sliding window (short-term memory), while autoregressive models (full history) incur linear increases in computational cost for long-horizon tasks.
- Robotic manipulation tasks requiring long-range temporal context, such as recalling transient or occluded information, are challenging due to the limitations of current memory mechanisms.

## Method

- **MemoryWAM** introduces a hybrid memory design, inspired by human cognition, integrated into a Mixture-of-Transformers (MoT) architecture.
- The memory system combines three components: a sliding-window short-term memory for immediate, high-fidelity context; ==event-boundary memory== for persistent 'anchor frames' (e.g., task initiation); and gist memory for compressing long-range history.
- Gist memory uses learnable 'gist tokens' (8 tokens per frame, 15x compression) to summarize past observations, replacing full visual tokens and allowing action generation to attend to this compact historical representation.

## Results

- MemoryWAM achieved an average success rate of **83.0%** on the RMBench simulation benchmark, outperforming full-history WAMs (LingBot-VA at **78.2%**) and short-term baselines (FastWAM at **5.9%**).
- On real-world memory-dependent tasks, MemoryWAM achieved 18/20 successes on "Shell Game" and 15/20 on "Look and Press", surpassing LingBot-VA and policies without persistent memory.
- The hybrid memory approach substantially reduced inference latency and GPU memory usage compared to full-attention methods, achieving the same **87%** success rate as full attention on the 'Press Button' task while exhibiting more favorable computational scaling.

## Takeaways

> [!tip] Key Insights
> - A hybrid memory system, combining detailed short-term context, salient event boundaries, and compressed long-term gist, effectively overcomes the memory-efficiency trade-off in WAMs.
> - Selectively compressing long-range historical information into 'gist tokens' can be more effective than retaining an entire uncompressed history, potentially by filtering redundant information, leading to better performance and efficiency.
> - Drawing inspiration from human cognitive memory architectures provides a viable strategy for designing artificial intelligence systems capable of robust and scalable long-horizon decision-making.
