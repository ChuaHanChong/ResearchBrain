# Weakly Supervised Deep Detection Networks

> [!summary] Summary
> Researchers from the University of Oxford developed Weakly Supervised Deep Detection Networks (WSDDN), an end-to-end framework that adapts pre-trained CNNs for object detection using only image-level labels. This architecture, featuring distinct classification and detection streams, achieved a new state-of-the-art performance, reaching 39.3% mAP on PASCAL VOC 2007 for weakly supervised object detection.

## Problem

- The high cost and labor intensity of obtaining detailed bounding box annotations for fully supervised object detection models.
- Limitations of traditional weakly supervised detection (WSD) methods, such as Multiple Instance Learning (MIL), which often suffer from non-convex optimization and sensitivity to initialization.
- The need for an end-to-end, efficient deep learning architecture capable of leveraging pre-trained CNNs for object localization with only image-level supervision.

## Method

- Modified pre-trained CNNs by replacing the final pooling layer with a ==Spatial Pyramid Pooling== layer to handle arbitrary input sizes and extract region-level features.
- Introduced a **two-stream architecture** (**WSDDN**), splitting region-level features into a 'classification stream' (==softmax per region==) and a 'detection stream' (==softmax per class==), with their outputs combined by an ==element-wise product==.
- Trained the network end-to-end using a sum of ==binary-log-loss== terms (one per class) on image-level labels, optionally incorporating a ==spatial regularizer== to encourage complete object detections.

## Results

- Achieved state-of-the-art performance on PASCAL VOC 2007 with **39.3% mAP** (ensemble) and PASCAL VOC 2010 with **36.2% mAP** (ensemble) for weakly supervised object detection, significantly outperforming previous methods.
- Demonstrated improved image classification performance, with WSDDN models S and M increasing image-level AP by **8** and **7 points**, respectively, over standard fine-tuning baselines on PASCAL VOC 2007.
- Found that integrating objectness scores from Edge Boxes proposals and applying a spatial regularizer consistently improved detection performance, particularly benefiting larger networks in localizing entire objects rather than just parts.

## Takeaways

> [!tip] Key Insights
> - Pre-trained CNNs implicitly encode rich spatial and semantic information about objects that can be effectively harnessed for localization tasks through targeted architectural modifications.
> - Decoupling region-level classification and object salience ranking into two specialized streams with distinct softmax operations is crucial for effective weakly supervised object detection.
> - The WSDDN's region-aware processing and dual-stream approach not only enhance detection but also contribute to improved image-level classification performance compared to traditional fine-tuning methods.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The research presented in this paper addresses the problem of weakly supervised detection (WSD) within the context of deep convolutional neural networks (CNNs) for image understanding. In recent years, CNNs have become the leading framework for image recognition, demonstrating robust performance when trained on large, labeled datasets. A notable characteristic of these networks is their capacity to learn generic visual features that transfer effectively across various tasks, including object detection, semantic segmentation, and human pose estimation, especially when pre-trained on extensive datasets like ImageNet ILSVRC.

Weakly supervised detection is a sub-field of computer vision focused on training object detectors using only image-level labels, rather than detailed bounding box annotations. This approach is motivated by two primary factors: the increasing number of complex visual concepts that image understanding systems aim to learn (e.g., hundreds of thousands of object categories in ImageNet), and the high data annotation costs associated with fully supervised methods. Reducing the cost of data annotation by leveraging weak supervision is crucial for scaling object detection to broader domains.

Prior work in WSD largely frames the problem as Multiple Instance Learning (MIL). In MIL, an image is considered a "bag" of regions; for positive images, at least one region is assumed to contain the object of interest. MIL methods typically alternate between estimating an object's appearance model and selecting relevant regions. However, MIL often results in non-convex optimization problems, making solvers prone to getting stuck in local optima, with solution quality dependent on initialization. Researchers have attempted to mitigate these issues through various initialization strategies, regularization techniques (e.g., self-paced learning, multi-fold splits, smoothed MIL, enforcing symmetry or mutual exclusion), and graph-based algorithms to identify similar image parts.

More recent research has explored weakly supervised localization principles to enhance CNN classification performance without explicit location annotations. Examples include Oquab et al.'s work on learning mid-level representations and coarsely localizing objects, and Jaderberg et al.'s spatial transformer networks that align objects to a common reference frame. The method of Wang et al. represented a state-of-the-art approach in weakly supervised object detection, utilizing pre-trained CNNs to describe image regions and learning object categories as visual topics. However, this method comprises multiple components and requires significant tuning.

This paper positions its proposed Weakly Supervised Deep Detection Network (WSDDN) as an end-to-end, CNN-centric solution that aims to overcome the limitations of MIL and simplify the architecture compared to multi-component CNN-based WSD systems. By modifying pre-trained CNNs to explicitly reason about image regions while only receiving image-level supervision, the authors aim to develop a more elegant and efficient approach to weakly supervised object detection.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a novel, end-to-end method for weakly supervised object detection leveraging the capabilities of deep convolutional neural networks (CNNs) that have been pre-trained on large-scale image classification tasks.

The key objectives and motivations driving this work include:

1. **Exploiting Pre-trained CNN Power:** The authors hypothesize that pre-trained CNNs, which have demonstrated remarkable generalization capabilities across numerous visual tasks, already contain meaningful, implicit representations of objects and their parts. These networks learn complex visual features without explicit information about object locations, suggesting they might already hold much of the necessary information for object detection. The objective is to devise an architecture that can leverage this inherent knowledge for localization.

2. **Addressing Data Annotation Costs:** A significant motivation is the high cost and labor intensity associated with collecting detailed bounding box annotations for fully supervised object detection. As the scope of image understanding expands to include a growing number of complex visual concepts (e.g., hundreds of thousands of categories in ImageNet), the ability to learn from less detailed, image-level labels becomes crucial for scalability. The paper aims to reduce this annotation burden.

3. **Developing an End-to-End Architecture:** The research seeks to contribute a new method that is integrated and trainable end-to-end using standard CNN back-propagation mechanisms. This contrasts with many existing weakly supervised detection techniques, particularly those based on Multiple Instance Learning (MIL), which often involve alternating optimization schemes, multiple stages, or complex combinations of components beyond the core CNN. An end-to-end system would offer simplicity and efficiency.

4. **Improving Upon Existing Weakly Supervised Detection (WSD) Limitations:**
 - **MIL's Drawbacks:** Traditional MIL-based approaches frequently encounter non-convex optimization problems, leading to solutions that can become trapped in local optima. The authors aim to circumvent these pitfalls by introducing a dedicated "detection branch" that is distinct from the recognition branch, offering a different mechanism for region selection.
 - **Complexity of Other CNN-based Methods:** While methods like Wang et al. utilize pre-trained CNNs, they often involve several discrete components and extensive tuning. The objective is to propose a simpler, more elegant modification to a pre-trained CNN that integrates region selection and classification seamlessly.

5. **Simultaneous Region Selection and Classification:** A specific objective is to modify a pre-trained CNN to operate at the level of image regions, performing both region selection (identifying relevant object areas) and classification (determining the object category) concurrently within a single network architecture.

6. **Enhancing Image-Level Classification:** As a secondary outcome, the authors aim for the proposed architecture, while primarily designed for detection, to also deliver improved performance on the original task of image-level classification compared to standard fine-tuning techniques. This would demonstrate the general utility of the WSDDN's region-aware processing.

In summary, the motivation stems from the desire to make object detection more scalable and less reliant on costly bounding box annotations by effectively harnessing the generalization power of deep CNNs through a simplified, end-to-end, and efficient weakly supervised learning framework.

### 3. Methodology and Approach

The proposed method, termed Weakly Supervised Deep Detection Network (WSDDN), modifies a pre-trained Convolutional Neural Network (CNN) to perform weakly supervised object detection using only image-level labels. The approach consists of three main steps: obtaining a pre-trained CNN, architecturally modifying it to form the WSDDN, and fine-tuning the WSDDN on a target dataset.

#### 3.1. Pre-trained Network

The process begins with a CNN pre-trained on a large-scale image classification task, such as the ImageNet ILSVRC 2012 dataset. This pre-training utilizes only image-level supervision, without bounding box annotations. The paper evaluates three specific pre-trained CNN models: VGG-CNN-F (referred to as S, for small), VGG-CNN-M-1024 (M, for medium), and VGG-VD16 (L, for large).

#### 3.2. Weakly Supervised Deep Detection Network (WSDDN) Architecture

The pre-trained CNN undergoes several architectural modifications to become the WSDDN:

1. **Spatial Pyramid Pooling (SPP) Layer:** The last pooling layer (e.g., `pool5` following `relu5`) of the pre-trained CNN is replaced with a Spatial Pyramid Pooling layer. This modification allows the network to handle input images of arbitrary sizes and efficiently extract fixed-size feature vectors `φ(x; R)` for candidate image regions `R`. The SPP layer is configured to be compatible with the network's subsequent fully connected layers (e.g., `fc6`) and is implemented as a network layer to facilitate end-to-end training.
2. **Region Proposals:** A shortlist of candidate object regions `R = (R_1, ..., R_n)` is generated using an external region proposal mechanism. The paper experiments with Selective Search Windows (SSW) and Edge Boxes (EB). The SPP layer is adapted to process this list of regions by concatenating the feature vectors `φ(x; R_j)` for all `j` regions along the fourth dimension.
3. **Two Data Streams:** After the region-level features pass through two fully connected layers (`φ_fc6` and `φ_fc7`), the network branches into two parallel data streams:
 - **Classification Stream:** This stream maps each region to a `C`-dimensional vector of class scores (where `C` is the number of target classes) via a linear map `φ_fc8c`. The resulting scores `x_c` are then subjected to a *softmax operator applied per region*. This `σ_class` operator compares the class scores for each individual region, effectively performing recognition of what object a region contains.
 - **Detection Stream:** This stream also processes the features with a linear map `φ_fc8d`, producing a `C`-dimensional matrix of scores `x_d`. Critically, these scores are then passed through a *softmax operator applied per class*. This `σ_det` operator compares the scores of different regions for each specific class, indicating which regions are more likely to contain a salient image structure for that class, thus serving as a proxy for detection.
4. **Combined Region Scores:** The final score for each region (`x_R`) is computed by taking the element-wise (Hadamard) product of the outputs from the classification stream (`σ_class(x_c)`) and the detection stream (`σ_det(x_d)`). This combination allows the network to leverage both the class-specificity of `σ_class` and the region-ranking capability of `σ_det`.
5. **Image-Level Classification Scores:** To derive an image-level class prediction, the region scores `x_R` are summed over all candidate regions: `y_c = Σ_r=1^|R| x_R_cr`. Since images can contain multiple object classes, a final softmax is not applied at this stage.

#### 3.3. Training WSDDN

The WSDDN is fine-tuned on the target dataset (e.g., PASCAL VOC training and validation sets) using only image-level labels `y_i ∈ {-1, 1}^C`.

1. **Loss Function:** The training optimizes an energy function `E(w)` which is a sum of `C` binary-log-loss terms, one for each class. This formulation treats each class as an independent binary classification problem, which is appropriate for datasets where multiple classes can co-occur in an image. Stochastic gradient descent with momentum is used for optimization.
2. **Fine-tuning Schedule:** All layers of the network are fine-tuned. The learning rate is set to `10^-5` for the first ten epochs and reduced to `10^-6` for the subsequent ten epochs. Each mini-batch is composed of all region proposals from a single image.
3. **Spatial Regularizer (Optional):** An additional regularization term can be incorporated into the loss function. This term penalizes discrepancies in the `fc7` feature map between the highest-scoring region for a given class and other highly overlapping regions (IoU ≥ 60%). The aim is to promote spatial smoothness, ensuring neighboring regions with high overlap also have similar high scores, encouraging complete object detection.

#### 3.4. Experimental Setup

- **Data Augmentation:** During training, random horizontal flips are applied, and images are resized to five different scales (e.g., max dimension {480, 576, 688, 864, 1200}) with a scale selected randomly, serving as jittering.
- **Test-Time Inference:** At test time, outputs from 10 versions of each image (5 scales and their flips) are averaged to improve robustness.
- **Objectness Score Integration:** When using Edge Boxes (EB), the provided objectness scores can be exploited by scaling the `φ_SPP` feature map proportionally.
- **Detection Post-processing:** After obtaining region scores, standard non-maxima suppression (with a 40% IoU threshold) is applied to generate the final list of class-specific detections.
- **Implementation:** The MatConvNet CNN toolbox is used for conducting experiments.

### 4. Main Findings and Results

The WSDDN was extensively evaluated on the PASCAL VOC 2007 and 2010 datasets for both weakly supervised object detection and image classification tasks.

#### 4.1. Object Detection Results

- **Baseline Performance:** A single-stream classification-detection network, serving as a baseline (without the distinct classification and detection branches of WSDDN), achieved 21.6% mean Average Precision (mAP) on PASCAL VOC 2007, which was significantly lower than the then state-of-the-art (31.6% by Wang et al.). This indicated the specific architectural contributions of WSDDN were impactful.

- **Performance with Different CNN Architectures (PASCAL VOC 2007):**
 - WSDDN models S (VGG-CNN-F) and M (VGG-CNN-M-1024) achieved 34.5% mAP and 34.9% mAP respectively, already surpassing the state-of-the-art method.
 - The ensemble of WSDDN models achieved 39.3% mAP, further boosting performance and exceeding all previously published results.
 - **Network Depth and Width:** Interestingly, deeper or wider networks (Model L, VGG-VD16) did not consistently improve detection performance. Model L achieved 34.8% mAP, performing comparably to S and M, but not better. This was attributed to Model L's tendency to focus on object parts rather than whole instances due to its finer resolution and smaller convolution strides.

- **Impact of Object Proposals:**
 - Edge Boxes (EB) proposals generally yielded slightly better detection performance than Selective Search Windows (SSW).
 - Incorporating the objectness score provided by EB ("Box Sc") led to a notable improvement of 2-5% mAP across models. For instance, WSDDN S improved from 31.5% to 33.4% mAP with Box Sc.

- **Effect of Spatial Regularizer:** The introduction of the spatial regularizer consistently improved detection performance. Models S, M, and L saw improvements of 1, 2, and 4 mAP points, respectively. This suggests that larger networks, which were prone to part-based detections, particularly benefited from this regularization, indicating its role in encouraging more complete object localization.

- **Comparison to State-of-the-Art:** WSDDN consistently demonstrated superior performance over previous state-of-the-art methods on both PASCAL VOC 2007 and 2010 datasets for object detection (mAP) and correct localization (CorLoc).
 - **VOC 2007 Detection (AP):** WSDDN Ensemble (39.3%) significantly outperformed Wang et al. (31.6%) and other methods (e.g., Bilen et al., Cinbis et al.).
 - **VOC 2007 Correct Localization (CorLoc):** WSDDN Ensemble achieved 58.0%, surpassing Wang et al. (48.5%).
 - **VOC 2010 Detection (AP):** WSDDN Ensemble achieved 36.2% mAP, outperforming Cinbis et al. (27.4%).
 - **VOC 2010 Correct Localization (CorLoc):** WSDDN Ensemble achieved 59.7%, outperforming Cinbis et al. (55.2%).

- **Failure Analysis:** The primary failure mode observed was the detection of object *parts* (e.g., a person's face) instead of the entire object. This was attributed to such parts often being more discriminative and having less variable appearance, making them more "predictive" for a class. Other errors included grouping multiple object instances into a single bounding box.

#### 4.2. Image Classification Results (PASCAL VOC 2007)

- The WSDDN, while primarily designed for detection, also performed effectively as an image classifier.
- WSDDN models S and M improved image classification AP by 8 and 7 points, respectively, over their corresponding baselines (VGG-F and VGG-M-1024) which used standard fine-tuning techniques.
- WSDDN L achieved 89.7% mAP, marginally outperforming the competitive VGG-VD16 (89.3%), which also incorporates coarse local information.
- The ensemble of WSDDN models achieved 89.0% mAP. These results indicate that the region-aware processing and the two-stream architecture contribute to enhanced image-level classification performance compared to traditional fine-tuning.

### 5. Significance and Potential Impact

The work presented in "Weakly Supervised Deep Detection Networks" demonstrates several advancements and carries potential implications for the field of computer vision:

1. **Advancement in Weakly Supervised Object Detection:** The WSDDN method establishes a new benchmark for weakly supervised object detection, achieving notably higher average precision and correct localization scores on standard datasets (PASCAL VOC 2007 and 2010) compared to existing methods. This represents a significant step towards closing the performance gap between weakly and fully supervised detection.

2. **Efficiency and Simplicity:** The proposed architecture is a straightforward modification of existing pre-trained CNNs. Its end-to-end trainability using standard back-propagation and region proposals makes it efficient during both training and inference, achieving performance comparable to fully supervised detectors like Fast R-CNN in terms of computational cost. This stands in contrast to multi-stage or more complex weakly supervised systems, offering a more practical solution.

3. **Reduced Annotation Burden:** By demonstrating that high-quality object detectors can be learned effectively from readily available image-level labels, the WSDDN significantly reduces the demand for costly and time-consuming bounding box annotations. This has substantial implications for scaling object detection to a much larger number of categories and for applications where dense annotations are impractical to obtain.

4. **Leveraging Pre-trained CNNs:** The research reinforces the power of transfer learning from large-scale image classification tasks. It illustrates that pre-trained CNNs implicitly encode rich spatial and semantic information about objects, which can be effectively harnessed for localization tasks through targeted architectural modifications. The distinct classification and detection streams, with their specialized softmax operations, highlight a novel way to disentangle these intertwined objectives within a unified deep learning framework.

5. **Improved Image Classification:** As a beneficial byproduct, the WSDDN architecture also demonstrates superior performance in image-level classification compared to traditional fine-tuning methods. This indicates that the region-aware processing and the dual-stream approach contribute not only to detection but also to a more robust overall understanding of image content, potentially enhancing general visual recognition systems.

6. **Direction for Future Research:** The paper identifies the detection of object parts instead of complete objects as a primary failure mode, particularly for certain categories like "chair" and "person." This observation provides a clear avenue for future research, suggesting the need to integrate additional contextual or regularization cues into the model to promote the detection of whole objects. Furthermore, the high-quality region scores generated by WSDDN could serve as powerful inputs for subsequent weakly-supervised detection algorithms, opening up possibilities for hybrid approaches.

In essence, WSDDN contributes a practical, effective, and efficient deep learning approach to weakly supervised object detection, pushing the boundaries of what is achievable with limited supervision and providing a foundation for continued research in less annotation-intensive computer vision.
