# POCA: Pareto-Optimal Curriculum Alignment for Visual Text Generation

> [!summary] Summary
> Researchers from Tohoku University and Amazon Web Services developed POCA, a framework for visual text generation that employs Pareto-optimal set selection and adaptive curriculum alignment. This approach stabilizes multi-reward reinforcement learning and improves data efficiency, leading to higher text accuracy, image coherence, and aesthetic quality, outperforming state-of-the-art models like AnyText2 in CLIP and HPS scores.

## Problem

- Existing multi-reward reinforcement learning for visual text generation experiences training instability from scalarizing conflicting reward signals (e.g., text accuracy versus aesthetic quality).
- Current RL methods face challenges in efficient and effective prompt selection, leading to high computational costs and slow convergence when managing diverse, multi-objective training data.
- Achieving a balanced trade-off between precise text rendering and overall image aesthetic quality remains difficult for visual text generation models.

## Method

- A Joint ==Pareto Set== Selection component re-frames multi-reward optimization, using bi-directional Pareto sorting to filter ambiguous signals within GRPO groups for clearer policy updates.
- The Pareto-guided GRPO objective only incorporates samples from the identified Pareto set, guiding the model towards optimal trade-off solutions.
- An Adaptive Curriculum Planning strategy dynamically measures prompt difficulty via OCR reward, creating an "easy-to-hard" learning path through multi-stage data partitioning for efficient training.

## Results

- POCA consistently outperforms the AnyText base model and the GRPO baseline in text accuracy (Sentence Accuracy, Normalized Edit Distance), text-image alignment (CLIP score), and aesthetic quality (HPS score).
- Ablation studies confirm that Pareto-guided optimization achieves significantly higher OCR and CLIP rewards with more stable convergence compared to weighted-sum approaches.
- The adaptive curriculum achieves performance on 1k images comparable to Pareto-guided methods on 10k images, demonstrating substantial data efficiency, and user studies confirm superior outputs.

## Takeaways

> [!tip] Key Insights
> - Scalarizing conflicting multi-reward signals destabilizes RL training, demonstrating that multi-objective Pareto-optimal selection is crucial for achieving superior trade-offs in visual text generation.
> - Bi-directional Pareto sorting provides clear, unambiguous positive and negative optimization signals, enabling stable convergence to better text accuracy, image coherence, and aesthetic quality.
> - Dynamically adjusting the training curriculum based on prompt difficulty significantly enhances data efficiency and accelerates the learning process in complex multi-reward RL environments.
