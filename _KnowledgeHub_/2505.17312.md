# AdaReasoner: Adaptive Reasoning Enables More Flexible Thinking in Large Language Models

> [!summary] Summary
> AdaReasoner is an LLM-agnostic framework that employs a reinforcement learning approach to dynamically configure reasoning hyperparameters, including instruction formats, generation temperature, and reasoning steps. This method consistently achieved higher average accuracy across six diverse LLMs and various reasoning tasks, demonstrating efficient few-shot training and robust out-of-distribution generalization.

## Problem

- Large Language Model (LLM) reasoning performance is highly sensitive to configuration parameters, leading to suboptimal outcomes when using fixed, general-purpose settings.
- Existing prompting strategies like Chain-of-Thought often rely on rigid reasoning structures that fail to achieve optimal performance across diverse tasks, especially creative or subjective ones.
- Manually identifying the best configuration for LLMs is impractical due to the vast, combinatorial search space of hyperparameters and the high computational cost of data collection for task-specific tuning.

## Method

- The authors developed **AdaReasoner**, an ==LLM-agnostic plugin== that uses a reinforcement learning (RL) framework to automate adaptive reasoning configurations for various tasks.
- The problem is formulated as a multi-armed bandit, where an RL agent selects a 3-dimensional action vector comprising generation temperature, reasoning instruction format, and the number of reasoning steps.
- AdaReasoner utilizes a neural architecture with a shared encoder and factorized policy heads, trained with the REINFORCE algorithm and Boltzmann exploration, using a pre-trained language judgment model for reward signals.

## Results

- AdaReasoner achieved the highest average accuracy across all six tested LLMs (e.g., **80.42%** with GPT-4o, **81.43%** with Claude-3.5-sonnet) and diverse reasoning tasks, outperforming standard baselines.
- Experiments demonstrated rapid convergence, showing "marginal gains beyond 100 shots," validating its efficiency in few-shot learning scenarios.
- The system exhibited strong out-of-distribution (OOD) generalization, maintaining stable superior performance on unseen datasets, and highlighted the crucial role of adaptive reasoning instruction formats.

## Takeaways

> [!tip] Key Insights
> - Dynamically adapting reasoning configurations with an RL agent leads to consistently higher LLM performance across diverse tasks compared to static prompting strategies.
> - Factorizing the action space into discrete components (temperature, instruction, steps) and employing a shared encoder with specific policy heads enables efficient learning of coherent, adaptive policies.
> - Few-shot training, combined with Boltzmann exploration and a differentiable reward model, facilitates rapid convergence and efficient tuning, overcoming the impracticality of extensive data collection.
