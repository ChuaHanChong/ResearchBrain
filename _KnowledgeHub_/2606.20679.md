# MemoryVAM: Integrating Memory into Video Action Model for Robot Manipulation

> [!summary] Summary
> MemoryVAM adds episodic memory to video-world-model robot policies via a Recap-Cue module: a Perceiver-based Recap Compressor turns CLIP frame history into compact memory tokens, injected into both the video backbone and action decoder, plus a Cue Gate for task-completion detection. Works across UNet and DiT backbones, raising LIBERO-Mem average success from 5% to 42.5%.

## Problem

- Video-world-model policies condition only on a short fixed observation window, so long-horizon tasks become non-Markovian once the correct action depends on events no longer visible.
- Existing video backbones (VPP, Cosmos-based) predict futures and decode actions from recent frames alone, causing visually similar states from different task stages to be indistinguishable.
- Prior memory mechanisms for diffusion policies and VLAs treat memory as an auxiliary input to the action head, not as a signal shaping the world model's own future predictions.

## Method

- **Recap Compressor**: a ==Perceiver-style resampler== with ==order-aware positional encoding== that compresses variable-length CLIP embedding history into fixed-size memory tokens G.
- **Dual injection**: the same memory tokens G are ==cross-attention==-injected into both the video backbone (Pathway 1, backbone-specific interface for UNet vs DiT) and the action decoder (Pathway 2).
- **Cue Gate**: a lightweight classifier fusing pooled visual features, memory tokens, and language to estimate task completion, trained via ==episode-boundary supervision== plus a ==delta-reconstruction auxiliary loss==, no per-frame progress labels needed.

## Results

- On LIBERO-Mem average success rises from **5%** (VPP, no memory) to **42.5%** (UNet) and from **3.0%** to **40.5%** (Cosmos-RF DiT), beating memory-augmented baselines like MemoryVLA (**9.5%**) and Gated Memory Policy (**19.5%**).
- Real-robot deployment reaches **78.3%** success on counting (Toy Pickup), **80.0%** on spatial recall (Place and Return), and **75.0%** on sequential tracking (Shell Game), versus **0%** for the memoryless Cosmos-RF baseline.
- Ablations show dual injection is necessary: Pathway 1 alone gets **28.5%** and Pathway 2 alone gets **7.5%** average success versus **42.5%** combined, and reconstruction loss cuts completion-timing error from **62.0** to **28.8** frames at strict threshold.

## Takeaways

> [!tip] Key Insights
> - Episodic memory should condition the generative backbone's imagined futures, not just the action head, since a mismatched world-model state undermines memory even when the policy sees it directly.
> - Memory modules can be self-supervised through video prediction and episode-boundary signals rather than requiring dense per-frame progress labels, letting memory training scale with video data.
> - Temporal order in compressed history matters: shuffling history frames degrades completion-timing accuracy, showing the compressor exploits sequence order rather than bag-of-frames statistics.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This research contributes to the field of robotic manipulation, specifically focusing on policies derived from video world models. Video world models (VWMs) aim to provide rich visual representations for robot policies by learning how visual observations evolve over time. Existing approaches, such as Video Prediction Policy (VPP) based on UNet models like Stable Video Diffusion (SVD) and Diffusion Transformer (DiT)-based systems like Cosmos and MimicVideo, leverage predictive video backbones as sources for action-relevant features. These models are effective when tasks are approximately Markovian, meaning the current observation provides sufficient information to determine the next action.

However, a recognized limitation in these systems is their reliance on a fixed-length observation window. This design can render long-horizon, multi-stage manipulation tasks non-Markovian. In such scenarios, the correct action might depend on events or states that occurred earlier in the episode but are no longer visible in the current observation window. For instance, tasks requiring counting repetitions, recalling initial object positions, or tracking occluded objects often present visually similar states that demand different actions based on unobservable history.

The paper addresses this "memory issue" by drawing parallels with prior work on memory mechanisms in other robot policy paradigms, including Gated Memory Policy for diffusion policies and Vision-Language-Action (VLA) models such like MemoryVLA and MemER. MemoryVAM distinguishes itself by integrating episodic memory directly into the *generative backbone* of video-world-model policies. This approach is designed to allow memory to supervise and influence future-frame prediction, thereby making the world model itself history-aware, rather than merely using memory as an auxiliary input to a downstream action head. The work positions memory as an integral component of the world-model state, impacting both imagined futures and direct policy execution.

### 2. Key Objectives and Motivation

The primary motivation for MemoryVAM stems from a fundamental challenge in current video-world-model policies for robotic manipulation: their inability to effectively handle long-horizon, multi-stage tasks that require recalling past events. Current video models typically process a short, fixed window of recent observations to predict future frames and inform action decoding. While this suffices for short, Markovian tasks where the current visual state is self-sufficient for action inference, it falters in scenarios where crucial context is hidden or depends on the cumulative history of an episode.

The authors detail several examples to illustrate this limitation:
- **Counting tasks**: In a task like "pick up the red block three times," the visual appearance of picking up the block might be nearly identical across different repetitions. Without memory of how many times the action has already been performed, the policy cannot determine if it should pick up the block again or terminate the task.
- **Spatial recall tasks**: For a task such as "find the cup containing the hidden object," the robot needs to remember where an object was placed, even if the object is now occluded or cups have been swapped. Similarly, "pick up, place object on the plate, then return it to its original" requires recalling the initial position of the object after an intermediate placement.
- **Sequential tracking**: Tasks involving a series of steps where the outcome of an earlier step dictates a later action, but the intermediate state is no longer visually apparent.

In these situations, the current observation alone renders the task non-Markovian for a memoryless policy. The core objective of MemoryVAM is to overcome this limitation by introducing an episodic memory mechanism that enables video-world-model policies to condition both their future predictions and action decisions on the full history of an episode.

Specifically, the key objectives are:
1. **Integrate episodic memory into video-world-model policies**: Develop a robust system to capture and utilize episode-level history.
2. **Enable dual memory conditioning**: Allow this episodic memory to influence both the video backbone's future predictions (shaping "what the model should imagine next") and the action decoder's control outputs (conditioning "what action to take").
3. **Develop a compact and informative memory representation**: Design a mechanism, the Recap Compressor, that can distill variable-length episode histories into a fixed-size, informative memory representation.
4. **Facilitate autonomous task completion**: Introduce a Cue Gate module that can estimate task completion from memory, language instructions, and current observations, allowing for self-termination of tasks.
5. **Ensure architectural versatility**: Demonstrate that the proposed memory mechanism is compatible with diverse video backbone architectures, specifically UNet-based and Diffusion Transformer (DiT)-based models.
6. **Supervise memory using generative objectives**: Leverage the dense future-frame prediction capability of video world models to train the memory module, reducing reliance on explicit per-frame progress labels.

By achieving these objectives, the authors aim to enhance the capability of robot policies to perform complex, long-horizon manipulation tasks that require temporal reasoning and recall of unobservable past states.

### 3. Methodology and Approach

MemoryVAM integrates episodic memory into video-world-model policies through a mechanism termed "dual memory conditioning." The approach involves processing the history of an episode into compact memory tokens and injecting these tokens into both the video backbone and the action decoder.

#### 3.1. Episode History Encoding

At each timestep `t`, the model maintains an episode history `H_t = {x_0, ..., x_{t-1}}`. Each `x_i` is a CLIP visual embedding of frame `I_i`, obtained using a frozen CLIP ViT-B/32 encoder. The choice of CLIP embeddings is motivated by their language-aligned semantic features, which allow the memory to track task-relevant changes rather than only low-level pixel variations. The history cache stores these embeddings, with mechanisms for padding or truncation to a maximum length during training and evaluation.

#### 3.2. Recap-Cue (RC) Module

The core of the memory mechanism is the Recap-Cue module, composed of two main sub-modules:

- **Recap Compressor**: This module transforms the variable-length episode history `H_t` into a fixed-size memory matrix `G ∈ ℝ^(K×d)`, where `K` is the number of memory tokens and `d` is their dimension. It employs a Perceiver cross-attention architecture, inspired by the Flamingo resampler. Learned queries within the Perceiver selectively attend to salient events in the history. Order-aware positional encoding is incorporated, allowing `G` to capture not only *what* events occurred but also *when* they occurred within the episode.

- **Cue Gate**: This is a lightweight classifier designed to estimate the task completion score, `q_ω(F_vis,t, G, ℓ) ∈`. The Cue Gate fuses three streams of information:
 1. Pooled backbone features (`F_vis,t`).
 2. Mean-pooled memory tokens (`G`).
 3. The CLIP language embedding of the task instruction (`ℓ`).
 This combined input is processed through a multi-layer perceptron (MLP) to output the completion score. The Cue Gate is supervised using binary cross-entropy, where the final `w_eos` frames of each episode are labeled as completed (`y_t = 1`), and earlier frames are labeled as incomplete (`y_t = 0`). This self-supervised approach, utilizing episode boundaries, encourages the Recap Compressor to retain completion-relevant information without requiring per-frame progress labels.

#### 3.3. Dual Memory Conditioning

MemoryVAM implements a "dual injection" strategy to ensure history awareness influences both future prediction and action decoding:

- **Pathway 1: Cross-attention Injection into the Video Backbone**: The memory tokens `G` are integrated into the video backbone's cross-attention layers as an additional conditioning matrix.
 - For **Cosmos DiT backbones**, `G` is appended to the text-conditioning matrix, allowing the backbone to generate future predictions `(Î_t+1:t+H_v)` and produce intermediate features `(Z_den,t)` that are conditioned on episode history.
 - For **SVD UNet backbones (VPP)**, a separate memory branch with layer-specific projections is introduced, and its output is added to the original text-conditioned branch, following decoupled cross-attention principles. This ensures the video model's imagined futures are consistent with episode progress.

- **Pathway 2: Direct Injection into Action Policy**: The same memory matrix `G` is provided directly to the action policy for control decisions.
 - For **UNet-backbone policies (VPP)** with token-input action decoders, `G` is concatenated with denoised video tokens `(Z_den,t)` to form the observation-token matrix `(Z_obs,t)`.
 - For **DiT-backbone policies (Cosmos-RF)** with cross-attention action transformers, projected memory tokens `(ρ_n(G))` are appended to the visual conditioning matrix. This ensures the action distribution `(π_θ)` is explicitly history-conditioned.

#### 3.4. Backbone Instantiations

The method is designed to be backbone-agnostic and is demonstrated on two distinct video backbone families:
- **VPP**: A UNet-based video backbone that uses features from a fine-tuned Stable Video Diffusion model.
- **Cosmos-RF**: A Diffusion Transformer-based video backbone, adapted from Cosmos and following the action-decoding setup of MimicVideo.
In both cases, the same Recap Compressor is used, and the memory injection interfaces are adapted to the specific backbone architecture.

#### 3.5. Training Procedure

MemoryVAM employs a two-stage training procedure:
- **Stage 1: Video Model Training**: The memory-augmented video model is trained to predict future observations that respect episode history. The total loss `L` combines the video prediction objective (denoising loss for SVD, flow-matching loss for Cosmos), a reconstruction auxiliary loss (`λ_recon * L_recon`), and the Cue Gate binary cross-entropy loss (`λ_eos * L_eos`). Trainable components include the backbone attention layers, Recap Compressor, memory injection projections, reconstruction decoder, and Cue Gate. The VAE and CLIP text encoder remain frozen. Training is initialized from a memoryless video backbone checkpoint.
- **Stage 2: Action Policy Training**: The video backbone remains frozen to maintain a stable predictive representation. The Recap Compressor, memory injection projections, Cue Gate, and the action head (Video Former, GCDenoiser) continue training with the action-prediction objective. Pathway 1 remains active, ensuring the action policy learns from memory-conditioned backbone features.

#### 3.6. Auxiliary Losses

- **Delta-reconstruction Loss**: A decoder predicts deltas between consecutive CLIP history embeddings (`Δx_j = x_j - x_j-1`). This loss forces the memory tokens to encode *changes* over time, rather than just static scene features, thereby improving temporal coherence and the calibration of the Cue Gate.
- **Cue Gate Supervision**: Uses binary cross-entropy, upsampling positive (completion) frames to address class imbalance. Gradients flow through the memory and language branches of the Cue Gate, but the backbone features `F_vis,t` are detached to prevent the Cue Gate loss from inadvertently altering the core video backbone representation.

### 4. Main Findings and Results

The evaluation of MemoryVAM spanned video prediction quality, policy performance on a simulation benchmark (LIBERO-Mem), real-robot tasks, and ablation studies.

#### 4.1. Video Prediction Quality

The integration of episodic memory significantly improved the video model's predictive capabilities, particularly in maintaining history alignment over long autoregressive rollouts.
- **UNet-based model (VPP)**: Improved single-chunk FVD from 43.36 to 18.32 and long-horizon FVD (at 8H_v) from 37.81 to 19.84.
- **DiT-based model (Cosmos-RF)**: Improved single-chunk FVD from 22.54 to 18.65 and long-horizon FVD (at 8H_v) from 26.11 to 16.24.
These results indicate that memory allows the video backbone to generate futures that are not only visually faithful but also semantically aligned with the episode's hidden task progress.

#### 4.2. Main Benchmark Results (LIBERO-Mem)

On the LIBERO-Mem benchmark, which comprises 10 memory-dependent manipulation tasks, MemoryVAM demonstrated substantial performance gains compared to memoryless baselines and other memory-augmented methods.
- **Memoryless baselines**: Achieved very low success rates, with the UNet-based VPP scoring 5% average success and the DiT-based Cosmos-RF scoring 3%. These policies struggled with tasks requiring counting, sequencing, or spatial reasoning where states appear visually similar but require different actions.
- **MemoryVAM (UNet)**: Improved average success to 42.5%.
- **MemoryVAM (DiT)**: Improved average success to 40.5%.
These results indicate that the memory mechanism is effective across different video backbone architectures.
- **Comparison to other memory-augmented methods**: MemoryVAM generally outperformed existing memory-augmented VLA and diffusion-policy baselines (e.g., Gated Memory Policy at 19.5%, MemoryVLA at 9.5%), especially on tasks where memory needed to be integrated with future scene prediction.

#### 4.3. Real Robot Experiments

MemoryVAM's performance gains transferred to physical robot experiments involving tasks with observation aliasing in the real world.
- **Toy Pickup k× (counting)**: Achieved 78.3% average success (95.0% for 1×, 100.0% for 3×, 40.0% for 5×).
- **Place and Return (spatial recall)**: Achieved 80.0% success.
- **Shell Game (sequential tracking)**: Achieved 75.0% success.
In contrast, the memoryless Cosmos-RF policy achieved negligible success rates (0% on Toy Pickup and Place and Return, 5% on Shell Game). These findings corroborate the simulation results, highlighting the necessity of episodic memory for practical long-horizon manipulation where current visual observations can be ambiguous.

#### 4.4. Ablation Studies

Ablations on the VPP backbone on LIBERO-Mem provided insights into the contributions of individual components.
- **Reconstruction Loss and Completion Timing**: The delta-reconstruction auxiliary loss significantly improved the Cue Gate's timing accuracy. Mean timing error decreased from 44.3 to 35.5 frames at a completion probability threshold `p ≥ 0.5`. At a stricter threshold (`p ≥ 0.9`), the improvement was more pronounced, from 62.0 to 28.8 frames. This suggests the reconstruction loss helps produce a sharper and better-calibrated completion signal, crucial for repetitive tasks.
- **Video Generation Termination Quality**: With memory injection, generated videos exhibited a stop ratio below 1 (0.46), indicating post-completion motion was less than half of pre-completion motion. This implies the video backbone learned to terminate unnecessary motion after task completion. Without memory, the stop ratio was above 1, showing continued spurious motion.
- **Dual Injection Ablation**:
 - **Pathway 1 only (memory in video backbone)**: Achieved 28.5% average success, demonstrating that history-aware backbone features alone carry substantial task-progress information.
 - **Pathway 2 only (memory in action decoder)**: Achieved 7.5% average success, suggesting that directly exposing memory to the action head is insufficient if the video backbone itself remains history-agnostic.
 - **Full model (dual injection)**: Reached 42.5% average success, confirming that memory must simultaneously shape both the imagined future and the downstream action distribution for optimal performance.
- **Memory Analysis**: Additional analyses confirmed that the Cue Gate accurately tracks task progress, differentiating visually identical states based on full history. Shuffling the chronological order of history significantly degraded performance, indicating that temporal ordering is crucial for the Recap Compressor.

### 5. Significance and Potential Impact

MemoryVAM presents a notable advancement in robotic manipulation by addressing a core limitation of video-world-model policies: their inherent memorylessness over long operational horizons. The work offers a generalizable solution that integrates episodic memory directly into the generative backbone, moving beyond treating memory as a peripheral input.

The significance of MemoryVAM lies in several aspects:
- **Enhanced Capability for Complex Tasks**: By enabling policies to recall past, non-visible events, MemoryVAM significantly improves performance on long-horizon, multi-stage manipulation tasks involving counting, spatial recall, and sequential tracking. This opens up opportunities for robots to tackle more intricate and realistic manipulation problems.
- **Architectural Flexibility**: The demonstrated compatibility of MemoryVAM with both UNet (VPP) and Diffusion Transformer (Cosmos-RF) backbones highlights its generalizability across different video world model architectures. This suggests that the proposed memory mechanism is broadly applicable and not constrained to a specific model paradigm.
- **Holistic Memory Integration**: Reconceptualizing episodic memory as an integral component of the world model rather than an auxiliary policy module is a key contribution. This integration allows memory to supervise future prediction and directly constrain policy execution, fostering a more coherent and context-aware understanding of the task and environment.
- **Leveraging Generative Supervision**: The ability to train the memory module with the video generative objective, supplemented by a delta-reconstruction auxiliary loss and episode-boundary supervision, offers a pathway for memory systems to scale with video data and world-model training. This could reduce the sole reliance on potentially sparse or costly action-labeled demonstrations.
- **Autonomous Task Completion**: The Cue Gate provides a practical mechanism for autonomous task termination based on perceived task progress and memory. This feature is critical for deploying robots in real-world scenarios where human intervention for task completion may not always be feasible.
- **Robustness in Real-World Scenarios**: The successful transfer of performance gains from simulation to real-robot experiments, especially under challenging conditions like observation aliasing and execution noise, underscores the practical utility and robustness of MemoryVAM.

The potential impact of MemoryVAM extends to developing more intelligent, autonomous, and capable robotic systems. By empowering robots with robust episodic memory, it could facilitate advancements in areas such as industrial automation, service robotics, and assistive technologies, enabling robots to perform complex tasks over extended periods with reduced human oversight. Future work suggested by the authors, such as exploring recurrent memory for very long deployments and scaling with broader video pre-training, indicates continued avenues for leveraging this integral memory approach.
