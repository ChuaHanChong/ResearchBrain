# Adaptive Base-class Suppression and Prior Guidance Network for One-Shot Object Detection

> [!summary] Summary
> The Base-class Suppression and Prior Guidance (BSPG) network improves one-shot object detection by mitigating base-class bias and providing semantic guidance. This framework achieves state-of-the-art performance on the PASCAL VOC and MS COCO benchmarks, demonstrating particular gains on the challenging MS COCO dataset.

## Problem

- Most conventional object detection models require large amounts of annotated data for each object category, limiting their applicability to novel classes.
- Existing one-shot object detection (OSOD) methods overlook the issue of base-class bias, where models trained on abundant base data struggle with novel categories.
- This base-class bias leads to misclassification of novel objects as base classes, failure to detect novel objects, and lower confidence for novel detections.

## Method

- A novel ==Base-class Suppression and Prior Guidance (BSPG)== network is introduced to directly address base-class bias in one-shot object detection.
- The ==Base-class Suppression (BcS) module== adaptively eliminates base-class detections by comparing similarity between query and proposal features, preventing misclassification.
- The ==Prior Guidance (PG) module== generates class-agnostic semantic prior maps from high-level features to guide the novel-class predictor toward potential novel object regions.

## Results

- The BSPG network consistently outperforms existing state-of-the-art OSOD methods on both **PASCAL VOC** and **MS COCO** datasets, showing significant improvements on the more challenging COCO dataset.
- Ablation studies confirm that both the Base-class Suppression (BcS) module and the Prior Guidance (PG) module contribute to performance improvements, with the full BSPG framework achieving the best results.
- The BSPG framework extends effectively to few-shot detection scenarios, demonstrating superior performance, especially in the **5-shot setting**, by leveraging additional query examples.

## Takeaways

> [!tip] Key Insights
> - One-shot object detection models trained on base classes develop a strong bias toward these categories, leading to poor performance on novel classes.
> - Explicitly addressing base-class bias through adaptive suppression is crucial for improving novel object detection accuracy.
> - Generating and utilizing high-level, class-agnostic semantic prior maps can effectively guide object detection models to novel object regions.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Object detection is a fundamental task in computer vision that has seen remarkable progress with deep learning approaches. However, most conventional detection models require large amounts of annotated data for each object category. One-shot object detection (OSOD) tackles this limitation by aiming to detect objects of novel categories after seeing just a single example.

While OSOD has received increasing attention, most existing approaches focus on improving feature interaction between query and target images for better semantic feature alignment. However, they overlook a critical issue: models trained predominantly on base classes develop a strong bias toward these familiar categories, leading to poor performance on novel classes.

#### 1.1. The Problem of Base-class Bias

One-shot object detection typically involves two stages: training on a set of base categories with abundant annotations, followed by detection of novel categories using just one example. During this process, the model inevitably develops a bias toward base classes due to the imbalanced data distribution between base and novel categories.

This base-class bias manifests as:
1. Misclassification of novel objects as belonging to similar base categories
2. Failure to detect novel objects altogether, especially when base-class instances are present
3. Higher confidence scores assigned to base-class detections than to novel-class detections

Previous OSOD methods primarily focus on how to effectively extract and align features between the query and target images. They typically employ a weight-shared backbone to extract features from both images, followed by feature interaction modules. However, these approaches do not explicitly address the base-class bias problem.

### 2. Key Objectives and Motivation

This paper introduces a novel Base-class Suppression and Prior Guidance (BSPG) network that directly addresses this challenge. The framework introduces two key innovations: a Base-class Suppression (BcS) module that adaptively eliminates base-class detections, and a Prior Guidance (PG) module that generates semantic cues to guide the model toward novel object regions.

### 3. Methodology and Approach

#### 3.1. BSPG Framework Architecture

The BSPG framework consists of three main components:

1. **Base-class Predictor**: A specialized branch for detecting objects from base categories
2. **Novel-class Predictor**: The main detection branch for identifying novel object categories
3. **Prior Guidance Module**: Generates semantic cues to guide detection toward novel objects

The framework uses a weight-shared ResNet-50 backbone to extract features from both the query image (containing the novel object example) and the target image (to be analyzed). These features are then processed through the different components of the architecture.

#### 3.2. Base-class Suppression Module

The Base-class Suppression (BcS) module is designed to adaptively eliminate false positive detections arising from the base-class bias. Unlike a simple post-processing step that would discard all base-class detections, the BcS module intelligently suppresses only those base-class predictions that are likely to be false positives.

The module operates by:

1. Using the base-class predictor to identify potential base-class objects in the target image
2. Computing a similarity map between query and proposal features to determine if a detected base-class object might actually be a novel-class instance
3. Adaptively adjusting the base-class prediction scores based on this similarity

Mathematically, the suppression process can be represented as:

```
P_final = P_N + P_B * (1 - S)
```

Where:
- P_final is the final prediction
- P_N is the novel-class prediction
- P_B is the base-class prediction
- S is the similarity score between query and proposal features

This approach ensures that base-class predictions are suppressed more strongly when they overlap with regions that have high similarity to the novel-class query.

#### 3.3. Prior Guidance Module

The Prior Guidance (PG) module leverages high-level semantic information to generate a class-agnostic prior map that highlights regions likely to contain objects of interest. This prior map serves as a guidance signal for the novel-class predictor.

The PG module works by:

1. Extracting high-level features from the pre-trained ResNet-50 backbone
2. Computing correlations between these features to identify semantically similar regions
3. Generating a prior map that highlights potential object locations
4. Using this prior map to modulate the feature maps used for novel object detection

The prior map visualization demonstrates the effectiveness of this approach:

The prior map effectively highlights regions containing objects similar to the query example, even when those objects belong to novel categories. This semantic guidance helps the model focus on relevant regions and improves detection performance.

#### 3.4. Training Process

The BSPG network is trained in a two-stage process:

1. **Base Training**: The base-class predictor is trained on the base dataset using the traditional Faster R-CNN paradigm. This step allows the model to learn general object detection capabilities.

2. **Novel Training**: The weights of the novel-class predictor are initialized from the base predictor, and then the entire network is trained on the base dataset with episodic training. During each episode, one image is randomly selected as the query, and another as the target. The network learns to detect instances of the query class in the target image.

The loss function for training combines several components:

```
L = L_N^RPN + L_N^CLS + L_N^REG + L_F
```

Where:
- L_N^RPN is the Region Proposal Network loss for novel-class detection
- L_N^CLS is the classification loss for novel-class detection
- L_N^REG is the bounding box regression loss for novel-class detection
- L_F is the final prediction loss

The hyperparameter α controls the balance between base-class suppression and novel-class prediction.

### 4. Main Findings and Results

#### 4.1. Experimental Results

The BSPG framework was evaluated on two standard benchmarks for OSOD:

1. **PASCAL VOC**: A relatively simple dataset with 20 object categories
2. **MS COCO**: A more complex dataset with 80 object categories and more challenging scenarios

For PASCAL VOC, the 20 categories were split into 15 base classes and 5 novel classes for testing. For MS COCO, the 80 categories were split into 60 base classes and 20 novel classes.

#### 4.2. Comparisons with State-of-the-Art Methods

The BSPG network consistently outperforms existing OSOD methods on both datasets:

**PASCAL VOC Results:**
- BSPG achieves higher AP50 scores on novel classes compared to methods like CoAE, SaFT, and AIT
- The performance improvement is more moderate on VOC due to the relatively simpler scenarios

**MS COCO Results:**
- BSPG significantly outperforms previous methods on the more challenging COCO dataset
- The improvements are particularly pronounced in complex scenarios with diverse objects and challenging backgrounds

The visual comparisons demonstrate that BSPG can correctly detect novel objects even in challenging scenarios where previous methods fail. Notably, BSPG avoids many false positives from base classes that plague other approaches.

#### 4.3. Ablation Studies

Comprehensive ablation studies validate the contribution of each component of the BSPG framework:

1. **Base-class Suppression Module**: Removing the BcS module leads to a significant drop in performance, particularly on the MS COCO dataset. This confirms that explicitly addressing base-class bias is crucial.

2. **Prior Guidance Module**: The PG module contributes additional performance improvements by providing semantic cues that guide the detection process. When removed, detection accuracy decreases, especially for small and ambiguous objects.

3. **Combination of BcS and PG**: The full BSPG framework with both modules achieves the best performance, demonstrating the complementary nature of these components.

#### 4.4. Extension to Few-shot Detection

While the BSPG framework is designed for one-shot detection, it can be readily extended to few-shot scenarios by averaging multiple query features. Results show that BSPG outperforms other advanced few-shot object detection methods, verifying its generalization ability.

The performance improvements are particularly significant in the 5-shot setting, where BSPG effectively leverages the additional query examples to improve detection accuracy.

### 5. Significance and Potential Impact

The BSPG network introduces a novel approach to one-shot object detection that directly addresses the critical issue of base-class bias. By incorporating adaptive base-class suppression and semantic prior guidance, BSPG significantly improves detection performance on novel categories without requiring additional training data.

The framework achieves state-of-the-art results on standard OSOD benchmarks, particularly on the challenging MS COCO dataset. The ablation studies confirm the effectiveness of both the Base-class Suppression module and the Prior Guidance module, and their complementary nature when combined.

This work provides important insights into addressing bias issues in few-shot learning scenarios and opens up new avenues for developing more robust and generalizable object detection systems that can quickly adapt to new object categories with minimal supervision.
