# Adaptive Base-class Suppression and Prior Guidance Network for One-Shot Object Detection

> [!summary] Summary
> The Base-class Suppression and Prior Guidance (BSPG) network improves one-shot object detection by mitigating base-class bias and providing semantic guidance. This framework achieves state-of-the-art performance on the PASCAL VOC and MS COCO benchmarks, demonstrating particular gains on the challenging MS COCO dataset.

## Problem

- Most conventional object detection models require large amounts of annotated data for each object category, limiting their applicability to novel classes.
- Existing one-shot object detection (OSOD) methods overlook the issue of base-class bias, where models trained on abundant base data struggle with novel categories.
- This base-class bias leads to misclassification of novel objects as base classes, failure to detect novel objects, and lower confidence for novel detections.

## Method

- A novel ==Base-class Suppression and Prior Guidance (BSPG)== network is introduced to directly address base-class bias in one-shot object detection.
- The ==Base-class Suppression (BcS) module== adaptively eliminates base-class detections by comparing similarity between query and proposal features, preventing misclassification.
- The ==Prior Guidance (PG) module== generates class-agnostic semantic prior maps from high-level features to guide the novel-class predictor toward potential novel object regions.

## Results

- The BSPG network consistently outperforms existing state-of-the-art OSOD methods on both **PASCAL VOC** and **MS COCO** datasets, showing significant improvements on the more challenging COCO dataset.
- Ablation studies confirm that both the Base-class Suppression (BcS) module and the Prior Guidance (PG) module contribute to performance improvements, with the full BSPG framework achieving the best results.
- The BSPG framework extends effectively to few-shot detection scenarios, demonstrating superior performance, especially in the **5-shot setting**, by leveraging additional query examples.

## Takeaways

> [!tip] Key Insights
> - One-shot object detection models trained on base classes develop a strong bias toward these categories, leading to poor performance on novel classes.
> - Explicitly addressing base-class bias through adaptive suppression is crucial for improving novel object detection accuracy.
> - Generating and utilizing high-level, class-agnostic semantic prior maps can effectively guide object detection models to novel object regions.
