# Experiential Reflective Learning for Self-Improving LLM Agents

> [!summary] Summary
> A framework called Experiential Reflective Learning (ERL) allows large language model (LLM) agents to adapt to new environments by generating reusable heuristics from single-attempt task executions. This method injects relevant learned guidelines into the agent's prompt, resulting in a 56.1% success rate on Gaia2, a 7.8% improvement over the ReAct baseline, and increased reliability by up to 10.6%.

## Problem

- General-purpose LLM agents often struggle to adapt to specialized environments with unfamiliar tools and domain-specific conventions.
- Current agents frequently do not effectively leverage past interactions, approaching each new task from scratch and leading to redundant failures.
- Prior experiential learning methods for LLM agents often require multiple task retries, incur scalability issues with growing context, or lose granular details through aggregation.

## Method

- The framework generates ==structured heuristics== from single-attempt task experiences (successes or failures), each containing an analysis and a 'Learned Guideline' with explicit trigger conditions and actionable advice.
- These generated heuristics are stored in a ==persistent heuristic pool==, forming the agent's experiential memory.
- When facing a new task, the system uses an LLM to retrieve and score the top-k most relevant heuristics (based on similarity, diversity, and informativeness) and injects them into the agent's ==system prompt== to guide its execution.

## Results

- ERL achieved a **56.1%** overall success rate on the Gaia2 benchmark, representing a **7.8%** improvement over the ReAct baseline (48.3%) and a **5.2%** improvement over the strongest prior method, ExpeL (50.9%).
- The framework significantly enhanced agent reliability, increasing the pass^3 metric (succeeding on all three runs) by **8.3%** on Execution tasks and **10.6%** on Search tasks.
- Raw trajectories used as few-shot demonstrations failed to improve performance over the baseline, while heuristics consistently outperformed them, offering up to a **23.8%** gain in specific task types for comparable context lengths.

## Takeaways

> [!tip] Key Insights
> - Distilled, structured heuristics provide a more effective and generalizable learning signal for agents compared to raw task trajectories or few-shot demonstrations.
> - LLM-based retrieval of relevant heuristics, considering both task similarity and guideline content, is crucial for performance and outperforms simpler embedding-based or random selection.
> - Heuristics derived from failed tasks are particularly effective for 'Search' tasks, while those from successful tasks are more beneficial for 'Execution' tasks, suggesting a complementary role for different types of experiences.
