# Natural-Language Agent Harnesses

> [!summary] Summary
> This research introduces Natural-Language Agent Harnesses (NLAHs) and an Intelligent Harness Runtime (IHR) to externalize and execute the control logic of AI agents in natural language. The framework facilitates systematic study and comparison of agent control patterns, demonstrating operational viability and achieving a 47.2% task success rate on OSWorld benchmarks with NLAHs compared to 30.4% for native code, while re-centering reliability mechanisms on durable, artifact-backed operations.

## Problem

- The control logic, or "harness," for AI agents is typically embedded in opaque controller code, framework defaults, or runtime conventions, making it difficult to transfer, compare, or systematically ablate.
- Existing natural-language methods for packaging agent control knowledge (e.g., AGENTS.md) lack an explicit, executable representation for comprehensive system-wide contracts, role boundaries, and state semantics.
- The inability to cleanly isolate and study harness components hinders scientific understanding and advancement of agent control mechanisms, limiting systematic design and optimization.

## Method

- Formalize and externalize the design-pattern layer of agent harnesses as explicit, executable ==Natural-Language Agent Harnesses (NLAHs)== using structured natural language.
- Develop an ==Intelligent Harness Runtime (IHR)== that directly interprets NLAH logic, integrating an LLM within its runtime loop to guide actions based on ==harness contracts== and state.
- Define NLAH components including ==contracts==, ==roles==, ==stage structure==, ==adapters==, ==scripts==, ==state semantics== (e.g., file-backed state), and a ==failure taxonomy== to ensure executability and interpretability.

## Results

- The shared runtime and harness logic actively control agent behavior, with Full IHR configurations showing substantial changes in process metrics (e.g., LLM calls, runtime duration) compared to ablated conditions, even when task outcomes remained stable.
- Explicit harness modules demonstrated composability and ablability, with effects concentrated on a small frontier of challenging cases; "self-evolution" improved solve loops, and "file-backed state" enhanced process structure and auditability.
- The NLAH realization of OSWorld's OS-Symphony harness achieved a **47.2%** task success rate, surpassing the native code harness (**30.4%**), primarily by shifting verification and recovery from screen-based plausibility to durable, path-addressable evidence and shell-side operations.

## Takeaways

> [!tip] Key Insights
> - Externalizing agent harness logic into natural language allows for the systematic study, modular composition, and ablation of control patterns, transforming harness engineering into a more scientific discipline.
> - While increased structure in agent harnesses significantly reshapes agent process metrics (e.g., tool calls, LLM calls), it does not uniformly lead to better end-task performance, often acting as a "solved-set replacer" on challenging cases.
> - Migrating native code harnesses to NLAHs can preserve functionality and improve task success by relocating reliability mechanisms from brittle local operations (like GUI repair) to durable, artifact-backed state management and explicit verification.
