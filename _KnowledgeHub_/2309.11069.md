# Dynamic Tiling: A Model-Agnostic, Adaptive, Scalable, and Inference-Data-Centric Approach for Efficient and Accurate Small Object Detection

> [!summary] Summary
> Dynamic Tiling introduces a model-agnostic and inference-data-centric approach for small object detection, adaptively processing image tiles based on initial detection results. This method improves detection accuracy, particularly for small objects, while simultaneously reducing computational overhead compared to uniform tiling techniques.

## Problem

- Small objects have limited pixel representation, making them difficult for detection models to identify accurately.
- Traditional object detection models struggle with extreme scale differences, and small objects at tile boundaries are often fragmented or missed.
- Detecting small objects in high-resolution images demands significant computational resources, hindering real-time applications.

## Method

- Divides the input image into ==initial non-overlapping tiles== for object detection and identifies objects near tile boundaries as potentially fragmented.
- Generates ==dynamic, overlapping patches== selectively around identified potential fragmentations, creating varying degrees of overlap only where needed.
- Aggregates these dynamic patches into composite images using a ==Tile Minimizer== to reduce the total number of neural network forward passes, maintaining efficiency.

## Results

- Dynamic Tiling outperformed existing model-agnostic uniform cropping methods, such as DarkHelp and SAHI, in mean Average Precision (mAP) on the VisDrone 2019 dataset.
- The approach reduced computational overhead by selectively applying overlapping patches and aggregating them with a Tile Minimizer, decreasing the number of neural network forward passes.
- It demonstrated strong adaptability across different operational environments without requiring laborious recalibration, providing a practical solution for real-world deployment.

## Takeaways

> [!tip] Key Insights
> - Applying overlapping patches selectively only where potential object fragmentations are identified significantly reduces computational overhead compared to uniform tiling.
> - Optimizing the inference stage by adaptively analyzing and processing image tiles can achieve accuracy and efficiency gains without requiring model architecture modifications or retraining.
> - Combining tile-based detection for small objects with full-image inference for larger objects provides a comprehensive approach to handle diverse object scales efficiently.

## Detailed Report

### 1. Introduction

Object detection is a fundamental task in computer vision with applications ranging from autonomous driving to medical imaging and surveillance. However, detecting small objects in large images remains particularly challenging due to their limited feature representation and the computational constraints of processing high-resolution images.

The paper "Dynamic Tiling: A Model-Agnostic, Adaptive, Scalable, and Inference-Data-Centric Approach for Efficient and Accurate Small Object Detection" by Son The Nguyen, Theja Tulabandhula, and Duy Nguyen introduces a novel approach that addresses these challenges through what they call "Dynamic Tiling."

Unlike previous approaches that modify model architectures or training data, Dynamic Tiling focuses on improving the inference stage by adaptively analyzing and processing image tiles based on initial detection results. This inference-data-centric approach provides a model-agnostic solution that can be seamlessly integrated with existing object detection frameworks.

### 2. The Small Object Detection Challenge

Small objects present unique challenges for detection algorithms for several reasons:

1. **Limited Information**: Small objects occupy few pixels in an image, providing minimal features for the detection model to identify and locate them accurately.

2. **Scale Variance**: Traditional object detection models struggle with extreme scale differences between small and large objects in the same image.

3. **Boundary Problems**: Small objects positioned near the boundaries of processing tiles are often fragmented or missed entirely.

4. **Computational Constraints**: Processing high-resolution images to detect small objects requires significant computational resources, making real-time applications challenging.

These issues are particularly evident in applications like aerial imagery analysis, where objects of interest (people, vehicles) may occupy only a tiny fraction of the entire image.

### 3. Current Approaches and Limitations

Several strategies have been developed to address small object detection:

1. **Architecture Modifications**: Approaches like feature pyramid networks (FPN) or attention mechanisms can improve small object detection but often require significant architectural changes and retraining.

2. **Super-Resolution Techniques**: Artificially increasing image resolution can enhance small object visibility but introduces computational overhead.

3. **Uniform Tiling (Cropping)**: Dividing images into uniformly overlapping tiles improves detection at the cost of redundant processing.

Uniform tiling methods, while effective, suffer from inefficiency due to applying the same overlapping rate across all tiles regardless of content. They also face challenges in merging detections from different tiles, particularly when objects span multiple patches or are irregularly shaped.

### 4. Dynamic Tiling Methodology

Dynamic Tiling introduces an adaptive approach to the inference process that strategically focuses computational resources where they're most needed. The methodology consists of the following key steps:

1. **Initial Non-Overlapping Tiling**: The input image is divided into a grid of non-overlapping tiles, and object detection is performed on each tile independently.

2. **Boundary Analysis**: The algorithm analyzes the initial detections to identify objects located near tile boundaries (classified as Near-Edge or Near-Corner).

3. **Dynamic Patch Proposal**: Based on the boundary analysis, overlapping patches are selectively generated in areas where objects may be fragmented.

4. **Tile Minimizer**: The dynamically generated patches are aggregated into composite images to reduce the number of forward passes through the neural network.

5. **Size-Based Filtering**: Detection results are filtered based on bounding box size to distinguish between small and large objects.

6. **Full Image Inference**: Object detection is performed on the entire original image to aid in detecting larger objects.

7. **Non-Maximum Suppression (NMS)**: Detections from all processes are combined using NMS to eliminate redundant predictions.

The key innovation lies in applying overlapping patches only where necessary (near detected objects at tile boundaries) rather than uniformly across the entire image, significantly reducing computational overhead while maintaining detection accuracy.

### 5. Key Components

#### 5.1. Potential Fragmented Object Filter

After the initial non-overlapping tiling and object detection, this component identifies objects that might be fragmented due to their proximity to tile boundaries. It classifies detected objects as:

- **Near-Edge**: Objects close to a single edge of a tile
- **Near-Corner**: Objects near the intersection of two edges

The filter uses distance thresholds to determine whether an object is sufficiently close to a boundary to warrant additional analysis.

#### 5.2. Dynamic Patch Proposal

This component generates overlapping patches specifically around the boundaries where potential object fragmentation was identified. Unlike uniform tiling approaches that apply the same overlapping rate everywhere, Dynamic Tiling creates patches with varying degrees of overlap based on the initial detection results.

The mathematical formulation for determining the coordinates of these dynamic patches involves:

```
For a Near-Edge object at position (x, y) with width w and height h:
    if near left edge:
        patch_x = max(0, x - overlap_factor * w)
    if near right edge:
        patch_width = min(image_width, x + w + overlap_factor * w)
```

Similar calculations are performed for all edge cases and corner cases.

#### 5.3. Tile Minimizer

To reduce computational overhead, the Tile Minimizer aggregates multiple dynamic patches into composite images of the same size as the original tiles. This minimizes the number of forward passes through the neural network while preserving the benefits of the dynamic overlapping.

The algorithm can be represented as:

```python
def tile_minimizer(dynamic_patches, tile_size):
    composite_tiles = []
    current_tile = empty_tile(tile_size)

    for patch in dynamic_patches:
        if patch can fit in current_tile:
            place patch in current_tile
        else:
            composite_tiles.append(current_tile)
            current_tile = empty_tile(tile_size)
            place patch in current_tile

    composite_tiles.append(current_tile)
    return composite_tiles
```

#### 5.4. Object Size Filter

This component separates detections based on their size, using a threshold to distinguish between small and large objects. For objects detected in tiles, the emphasis is on small objects, while the full-image inference primarily captures larger objects. This separation helps in the final merging process, reducing conflicts between detections at different scales.

### 6. Experimental Results

The authors evaluated Dynamic Tiling on the VisDrone 2019 dataset, which contains drone-captured images with numerous small objects. The results demonstrate several key findings:

1. **Improved Detection Accuracy**: Dynamic Tiling outperformed existing model-agnostic uniform cropping methods like DarkHelp and SAHI in terms of mean Average Precision (mAP).

2. **Reduced Computational Overhead**: By selectively applying overlapping patches and using the Tile Minimizer, Dynamic Tiling reduced the number of forward passes compared to uniform tiling methods with similar accuracy.

3. **Complementary Full-Image Inference**: The combination of tile-based detection for small objects and full-image inference for larger objects provided comprehensive detection capabilities across different scales.

4. **Adaptability**: The approach demonstrated strong performance across different operational environments without requiring laborious recalibration.

The experimental results highlighted that Dynamic Tiling achieves a better balance between accuracy and efficiency compared to existing approaches, particularly for small object detection in complex scenes.

### 7. Applications and Impact

Dynamic Tiling offers significant benefits for numerous applications requiring small object detection:

1. **Aerial Imagery Analysis**: Improved detection of vehicles, people, and infrastructure in satellite or drone imagery.

2. **Autonomous Driving**: More accurate identification of distant pedestrians, vehicles, and traffic signs.

3. **Medical Imaging**: Enhanced detection of small anomalies in medical scans.

4. **Video Surveillance**: Better tracking of small objects in large surveillance areas.

The model-agnostic nature of Dynamic Tiling is particularly valuable as it allows for implementation with various existing object detection frameworks without requiring architectural changes or retraining. This makes it a practical solution for real-world deployment across different domains.

The inference-data-centric approach also contributes to the broader AI research community by highlighting the importance of optimizing the inference stage, which has received less attention compared to model architecture and training data improvements.

### 8. Conclusion

Dynamic Tiling represents a significant advancement in small object detection by introducing an adaptive, model-agnostic approach that focuses on optimizing the inference process. By selectively applying overlapping patches based on initial detection results, the method achieves a better balance between accuracy and computational efficiency compared to existing techniques.

The key innovation lies in its inference-data-centric philosophy, which recognizes that improvements in how data is processed during inference can be as impactful as model architecture changes or training data enhancements. This approach is particularly valuable for real-world applications where computational resources may be limited and where existing models cannot be easily modified or retrained.

As computer vision continues to expand into more domains and applications, approaches like Dynamic Tiling that improve efficiency without sacrificing accuracy will become increasingly important. The method's adaptability and scalability make it a promising solution for addressing the ongoing challenge of small object detection across various fields.
