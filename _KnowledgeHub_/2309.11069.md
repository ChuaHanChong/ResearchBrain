# Dynamic Tiling: A Model-Agnostic, Adaptive, Scalable, and Inference-Data-Centric Approach for Efficient and Accurate Small Object Detection

> [!summary] Summary
> Dynamic Tiling introduces a model-agnostic and inference-data-centric approach for small object detection, adaptively processing image tiles based on initial detection results. This method improves detection accuracy, particularly for small objects, while simultaneously reducing computational overhead compared to uniform tiling techniques.

## Problem

- Small objects have limited pixel representation, making them difficult for detection models to identify accurately.
- Traditional object detection models struggle with extreme scale differences, and small objects at tile boundaries are often fragmented or missed.
- Detecting small objects in high-resolution images demands significant computational resources, hindering real-time applications.

## Method

- Divides the input image into ==initial non-overlapping tiles== for object detection and identifies objects near tile boundaries as potentially fragmented.
- Generates ==dynamic, overlapping patches== selectively around identified potential fragmentations, creating varying degrees of overlap only where needed.
- Aggregates these dynamic patches into composite images using a ==Tile Minimizer== to reduce the total number of neural network forward passes, maintaining efficiency.

## Results

- Dynamic Tiling outperformed existing model-agnostic uniform cropping methods, such as DarkHelp and SAHI, in mean Average Precision (mAP) on the VisDrone 2019 dataset.
- The approach reduced computational overhead by selectively applying overlapping patches and aggregating them with a Tile Minimizer, decreasing the number of neural network forward passes.
- It demonstrated strong adaptability across different operational environments without requiring laborious recalibration, providing a practical solution for real-world deployment.

## Takeaways

> [!tip] Key Insights
> - Applying overlapping patches selectively only where potential object fragmentations are identified significantly reduces computational overhead compared to uniform tiling.
> - Optimizing the inference stage by adaptively analyzing and processing image tiles can achieve accuracy and efficiency gains without requiring model architecture modifications or retraining.
> - Combining tile-based detection for small objects with full-image inference for larger objects provides a comprehensive approach to handle diverse object scales efficiently.
