# GESTO: Human-Centric Spatio-Temporal Memory for Reasoning in Dynamic Scenes

> [!summary] Summary
> GESTO builds a spatio-temporal memory that couples a persistent 4D scene graph with a two-level activity hierarchy: timestamped atomic human-object interactions grouped into goal-driven events, plus grounding links to persistent objects and places. Built fully automatically from RGB-D streams via VLM interaction extraction, geometric-semantic grounding, LLM event grouping, and context-aware refinement, it scores 0.71 text, 0.75 binary, 0.70 time on retrospective question answering.

## Problem

- 4D scene graphs record what objects existed, where, and when, but carry no activity structure linking objects to the human behavior that drove scene change.
- Hierarchical activity models from video understanding are defined over frames or clips with fixed taxonomies, never grounded in the persistent metric 3D environment a robot navigates.
- The closest activity-grounded graph treats events as a flat set and requires externally supplied temporal boundaries, participating objects, and cross-event object correspondences.

## Method

- **Two-level activity graph** over a swappable ==4D scene-graph== backbone: atomic interactions (human, action, object, interval) grouped by an LLM into goal-driven events partitioning the session timeline.
- **Interaction grounding** links each VLM-extracted interaction to a persistent object node by combining ==box mIoU== above a threshold with ==text-embedding semantic similarity==, arbitrated by an LLM judge on borderline cases.
- **One alternating refinement pass**: event context infers links for unmatched interactions only under unanimous neighbor agreement, then an LLM re-evaluates event membership of relinked interactions.

## Results

- Scores **0.71** text, **0.75** binary F1, **0.70** time, near the externally-grounded baseline (**0.70**/**0.78**/**0.78**) while far exceeding that same framework without ground-truth input (**0.33**/**0.29**/**0.50**).
- On the **40** new cross-domain queries it reaches **0.73** Space2Event and **0.75** Event2Space, beating object-centric and retrieval memories (**0.53**/**0.35** and **0.46**/**0.41** respectively).
- Ablations: removing the event hierarchy collapses time accuracy to **0.40**; removing refinement leaves **30%** of interactions ungrounded and drops time to **0.59**; unsegmented clips drop text to **0.57**.

## Takeaways

> [!tip] Key Insights
> - Storing extra descriptions is not enough: the goal-level hierarchy, not the grounded interactions alone, carries temporal and activity-to-space reasoning.
> - Interaction grounding lets memory separate objects actively used from those merely nearby, a distinction purely object-centric spatial memories cannot make.
> - Current VLMs recognize actions well but localize the manipulated object poorly under occlusion or visual similarity, bounding any appearance-based grounding pipeline.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Robots operating in human environments require sophisticated memory structures to understand and interact with their surroundings. This work addresses the challenge of creating a memory system that extends beyond merely recognizing objects and tracking their locations over time to encompass how humans interact with these objects within goal-directed activities.

Existing research has explored several complementary avenues:
- **3D and 4D Scene Graphs:** These representations organize metric and semantic information about objects, places, and their evolution over time. Systems like Hydra, DAAAM, and Khronos have advanced the ability to build and query persistent spatial and temporal memories. However, these representations are primarily object-centric and generally lack explicit structures for human activities or the purpose behind scene changes. They record *what* and *when* but not *how* or *why* in the context of human behavior.
- **Human-Centric and Activity-Grounded Representations:** Some approaches augment static scenes with human-object interaction edges, such as Social 3D Scene Graphs, but often without full temporal dynamics or hierarchical event structures. Event-Grounding Graphs (EGG) represent a step towards linking events to spatial entities, demonstrating the utility of spatially grounded events. However, EGG treats events as a flat set without hierarchy and relies on externally provided event boundaries, participating objects, and cross-event correspondences, rather than inferring them from observation.
- **Hierarchical Event Representations in Video Understanding:** Research in video analysis has shown that human activity is naturally hierarchical, decomposing goal-directed behavior into atomic actions and higher-level activities. Datasets and models like AVA, MOMA, and Ego4D Goal-Step formalize this structure. The limitation of these approaches is that their hierarchies are typically defined over frames or video clips, often with fixed taxonomies or offline annotations, and are not intrinsically grounded in a persistent metric 3D environment that a robot navigates.

GESTO is positioned to bridge these areas by unifying a dynamic 4D scene graph with a hierarchical activity representation. It aims to autonomously construct this coupled memory, grounding high-level events and fine-grained human-object interactions to persistent scene entities, thereby enabling spatio-temporal reasoning that integrates object, place, and activity information. This addresses the gap where existing 4D scene graphs omit activity structure, and activity representations are either not grounded in persistent 3D scenes or require external supervision for event definition and object association.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop GESTO (Grounded Event and Spatio-Temporal memOry), a unified memory representation, denoted as $G^+$, that concurrently captures the dynamic spatial structure of an environment and the hierarchical temporal structure of human activities. A central aspect of this objective is to ground these activities in the specific objects and places they involve.

The motivations for this work stem from critical limitations in existing robotic memory systems for operating in human environments:

- **Inadequate Retrospective Reasoning:** Current robot memories, even advanced 4D scene graphs, excel at describing the static and dynamic presence of objects and their locations over time. However, they lack the capacity to answer complex human-centric questions that require understanding past activities, such as "Which mug was used to drink coffee this morning?" or "Has this cup already been washed?" Answering such queries necessitates a memory that records how people interacted with the environment and how individual interactions contribute to broader, goal-directed activities.
- **Missing Activity Structure in 4D Scene Graphs:** While 4D scene graphs provide a record of object presence and scene evolution, they typically do not incorporate a notion of the activities that drive these changes. They observe an object moving, but do not inherently understand that a person "prepared coffee" using that object.
- **Lack of Grounding and Autonomy in Activity Representations:** Human behavior modeling often uses hierarchical structures in video understanding, but these structures are usually defined over video frames or clips and are not linked to persistent 3D objects and places within a robot's operational environment. When activity representations *are* grounded (e.g., Event-Grounding Graphs), they often treat events as a flat set without hierarchical composition and require external provision of event boundaries, participating objects, and cross-event correspondences. This reliance on external input limits the autonomy and scalability of such systems for real-world robotic deployment.
- **Difficulty in Cross-Domain Reasoning:** There is a need for a system that allows flexible traversal between geometry and activity semantics. A robot should be able to move from an object to the events it participated in, from an event to the objects and locations it involved, and from a high-level event to its constituent atomic interactions.

GESTO aims to address these motivations by automatically constructing a memory that integrates these disparate elements, allowing robots to perform activity-centric spatio-temporal reasoning without requiring external annotations or fixed taxonomies.

### 3. Methodology and Approach

GESTO constructs its unified memory representation, $G^+ = (G_S, G_A, L)$, from an RGB-D observation stream through a multi-stage pipeline (Figure 2). $G_S$ is a spatio-temporal scene graph (treated as a modular backbone), $G_A$ is a hierarchical activity graph, and $L$ represents grounding links between the two.

**A. Atomic Interaction**
1. **Interaction Extraction:** The streaming RGB-D input is segmented into short, fixed-length video clips (e.g., 15-second clips). A vision-language model (Cosmos-Reason2) processes each clip to identify and extract atomic human-object interactions. Each extracted interaction includes an interaction object label (e.g., "blue cup") and frame-wise bounding boxes for the manipulated object over the interaction's duration.
2. **Interaction Grounding:** Each extracted interaction is initially grounded to a persistent object node ($o \in O$) within the scene-graph backbone ($G_S$, using DAAAM in this work). This grounding process combines:
 - **Geometric Agreement:** Measured by the mean Intersection-over-Union (mIoU) between the bounding boxes of the interaction object and the tracked boxes of the persistent object node. A threshold ($\tau_{mIoU} = 0.3$) is applied.
 - **Semantic Agreement:** Measured by the text-embedding similarity between the interaction object label and the persistent object description. A threshold ($\tau_{sem} = 0.7$) is applied.
 - The candidate node with the highest semantic similarity, exceeding both thresholds, is selected. An LLM judge further verifies candidates with borderline semantic similarity.
 - This initial grounding ($L^{(0)}$) is provisional, as object identities and semantic descriptions in $G_S$ may be refined over time. Interactions without a reliable initial association are temporarily unlinked.

**B. Goal-Driven Event**
1. **Hierarchical Event Construction:** The system groups the atomic interactions into higher-level, goal-driven events ($E$), forming the upper level of the activity graph ($G_A$). An LLM performs this grouping based on principles such as:
 - Each event represents a single coherent goal at a consistent granularity, broader than an atomic interaction but not overly generalized.
 - Similar objects are distinguished by appearance to avoid conflation.
 - The events collectively form a complete, time-ordered partition of all interactions.
 - This process yields an initial assignment of events ($E^{(0)}$). An event inherits the objects, places, and time span of its constituent interactions through their grounding links, maintaining traceability to supporting evidence.

**C. Refinement**
GESTO performs one round of alternating refinement for the grounding links ($L$) and event structure ($E$):
1. **Context-Aware Grounding Refinement ($R_L$):** With the initial event structure ($E^{(0)}$) providing context, interactions that were initially unlinked due to insufficient association can be re-evaluated. If the surrounding, already-grounded interactions and events within an event context consistently suggest a single candidate persistent object node for an unlinked interaction, a new grounding link ($L^{(1)}_{inferred}$) is established. This inference only occurs when there's unambiguous agreement from context, without inventing new nodes or guessing ambiguous cases. The complete set of links becomes $L^{(1)} = L^{(0)} \cup L^{(1)}_{inferred}$.
2. **Event Refinement ($R_E$):** For any interaction whose grounding was modified by $R_L$, a lightweight LLM re-examines its coherence with its assigned event. If the refined grounding makes an interaction inconsistent with its current event, it is reassigned to a compatible neighboring event. If no suitable event exists, a new event is created for that interaction. This step produces the refined event structure ($E^{(1)}$) while $L^{(1)}$ remains unchanged.

**D. Relation-Aware Agent for Question-Answering**
The constructed $G^+$ memory is exposed to a relation-aware tool-calling agent. This agent extends the object-centric tools of DAAAM by adding specific tools to query events, constituent interactions, linked objects, places, and time intervals. This enables the agent to retrieve activity-centric or spatial evidence based on natural language queries, providing answers along with supporting evidence from the memory.

### 4. Main Findings and Results

The evaluation of GESTO involved a series of experiments using a tool-calling agent and the proposed scene representation, primarily on the dataset introduced by EGG.

**A. Experiment Setup**
- **Implementation Details:** The system utilizes 15-second RGB-D video clips. Cosmos-Reason2 extracts atomic interactions and localizes objects, and also performs event grouping and borderline link judgments. FastSAM provides object masks, and sentence-t5-large generates text embeddings.
- **Standard Benchmark:** GESTO was evaluated on the EGG benchmark, which includes 80 queries categorized as text, binary, and time. Text answers are scored by an LLM-based semantic score, binary answers by F1 score, and time answers are correct if within two minutes of ground truth. Node queries were excluded due to unavailable ground-truth point clouds.
- **Extended Queries:** Two new sets of 20 queries each were introduced to specifically test cross-domain reasoning:
 - **Space2Event queries:** Given a place or object, query associated activities (e.g., "What is the red chair used for?").
 - **Event2Space queries:** Given an activity, query involved places and objects (e.g., "Which objects does the person use while working?"). These were scored with the LLM-based semantic score.
- **Baselines and Supervision Settings:** Comparisons were made against DAAAM (object-centric 4D scene graph), ReMEmbR (long-horizon spatio-temporal memory), and EGG (activity-centric baseline). EGG was evaluated in two modes:
 - **EGG (auto-caption):** Uses automatically generated event descriptions but relies on externally provided activity intervals, participating objects, and cross-event object correspondences (i.e., ground-truth grounding).
 - **EGG (w/o GT input):** Exposed to the same automatically constructed and imperfect 4D scene and activity information as GESTO, without external grounding, to enable a fully automatic comparison.

**B. Experiment Results**
- **Standard Benchmark:** GESTO performed comparably to EGG (auto-caption) despite operating in a fully automatic setting without external grounding.
 - **Text Accuracy:** GESTO achieved 0.71, slightly surpassing EGG (auto-caption)'s 0.70.
 - **Binary F1:** GESTO achieved 0.75, close to EGG (auto-caption)'s 0.78.
 - **Time Accuracy:** GESTO achieved 0.70, compared to EGG (auto-caption)'s 0.78. The paper notes time queries are sensitive to activity recognition and object grounding errors.
- **Comparison to fully automatic EGG:** When compared to EGG (w/o GT input), GESTO showed substantial improvements across all standard query types:
 - Text Acc: GESTO 0.71 vs. EGG (w/o GT input) 0.33
 - Binary F1: GESTO 0.75 vs. EGG (w/o GT input) 0.29
 - Time Acc: GESTO 0.70 vs. EGG (w/o GT input) 0.50
 This indicates that GESTO's hierarchical activity structure and grounding mechanism provide a more robust basis for reasoning compared to EGG's framework when both operate on automatically inferred data.
- **Extended Queries (Space2Event & Event2Space):** GESTO demonstrated notable performance in queries explicitly requiring traversal between activity and spatial entities:
 - **Space2Event:** GESTO 0.73, outperforming DAAAM (0.53) and EGG (w/o GT input) (0.60).
 - **Event2Space:** GESTO 0.75, outperforming DAAAM (0.35) and EGG (w/o GT input) (0.50).
 This supports the benefit of grounding activity structure to persistent objects and places, as DAAAM, which lacks explicit human-object interaction structure, performed less well on these categories.
- ReMEmbR outperformed DAAAM on some metrics but was generally outperformed by GESTO across the standard categories.

**C. Ablation Studies**
- **Video Fragmentation:** Removing video fragmentation (processing longer, unsegmented clips) reduced text accuracy (0.71 -> 0.57) and binary F1 (0.75 -> 0.66), indicating that granular clip processing is important for precise interaction detection. Time accuracy remained unaffected.
- **Context-Aware Grounding Refinement:** Disabling refinement left approximately 30% of interactions ungrounded. This particularly impacted temporal accuracy (0.70 -> 0.59) and both Space2Event (0.73 -> 0.65) and Event2Space (0.75 -> 0.61) queries, highlighting its role in establishing complete links.
- **Event Hierarchy:** Removing the event level entirely (retaining only a flat set of grounded atomic interactions) significantly reduced time accuracy (0.70 -> 0.40) and Space2Event accuracy (0.73 -> 0.53). This suggests that the hierarchical organization of interactions into goal-driven events is crucial for effective spatio-temporal reasoning and abstraction, beyond just having grounded interactions.
- Combining both fragmentation and refinement removal resulted in the lowest text (0.53) and temporal (0.50) accuracies.

**D. Egocentric Dataset:** A qualitative demonstration showed GESTO successfully transferring to egocentric observations from EgoLive and HOI4D datasets without retraining, suggesting broad applicability across sensor configurations.

### 5. Significance and Potential Impact

GESTO provides a significant contribution by addressing a core challenge in robotics: enabling intelligent agents to perform complex, human-centric reasoning about dynamic environments. Its key significance lies in the development of a unified memory representation that integrates dynamic spatial scene graphs with a hierarchical understanding of human activities, all constructed autonomously from raw sensor data.

The paper demonstrates that:
- **Hierarchical Activity Abstraction is Critical:** The ablation studies clearly show that the event hierarchy, not just a flat list of interactions, is essential for robust spatio-temporal reasoning, particularly for questions involving temporal scope and high-level summaries of activity. This aligns with cognitive studies on human activity segmentation.
- **Autonomous Construction and Refinement:** GESTO's pipeline, which extracts interactions, groups them into events, and refines grounding links without external supervision, represents an advancement towards more autonomous and adaptable robotic systems. The context-aware grounding refinement mechanism is particularly important for resolving ambiguous associations and increasing the coverage of grounded interactions.
- **Bridging Scene Understanding and Activity Recognition:** By explicitly coupling a persistent 4D scene graph with an activity hierarchy through grounding links, GESTO allows for flexible query traversal between spatial entities (objects, places) and temporal activities. This enables a richer understanding than systems focused solely on objects or activities in isolation.
- **Improved Retrospective Reasoning:** The demonstrated performance on activity-centric question answering, especially in comparison to baselines operating under fully automatic conditions, indicates that GESTO provides a robust foundation for robots to answer questions about past human behavior, object usage, and event contexts. This capability is vital for service robots, collaborative robots, and agents operating in complex human environments.

Potential impacts of this work include:
- **More Capable Service Robots:** Robots with GESTO-like memory could better anticipate human needs, learn routines, assist with tasks, and provide informed responses to user queries about past events (e.g., "Where did I leave my keys after working?").
- **Enhanced Human-Robot Collaboration:** A deeper understanding of human activity context would enable robots to collaborate more effectively, understanding the goals behind human actions and reacting appropriately.
- **Foundational for Long-Term Autonomy:** By autonomously building and refining a comprehensive memory of human-environment interactions, GESTO lays groundwork for robots that can operate and learn over extended periods in dynamic settings without constant human reprogramming or supervision.

**Limitations** identified by the authors include reliance on appearance-based vision-language models for interaction extraction, which can struggle with occluded or visually similar objects, potentially leading to inaccurate grounding. Challenges in semantic mapping and obtaining accurate segmentation masks also introduce noise. Furthermore, the memory grows with session length, highlighting a future direction for detecting and consolidating recurrent activities for long-term deployments. Despite these, GESTO represents a significant step towards human-centric spatio-temporal reasoning for embodied agents.
