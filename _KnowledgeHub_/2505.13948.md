# Memory-Centric Embodied Question Answering

> [!summary] Summary
> A memory-centric framework for Embodied Question Answering (EQA) is introduced, which enhances the utilization of memory by integrating it into the agent's planning, stopping, and answering modules. The system achieves a 9.9% increase in success rate on a new multi-target, multi-region benchmark while significantly reducing exploration steps compared to planner-centric baselines.

## Problem

- Current Embodied Question Answering (EQA) systems predominantly use a "planner-centric" framework that underutilizes the memory module.
- Information stored in memory is primarily leveraged by the answering module, not effectively integrated into planning or stopping decisions.
- This limitation results in inefficient exploration, such as redundant re-exploration or insufficient information gathering, leading to suboptimal task success rates.

## Method

- A "memory-centric" EQA framework, MemoryEQA, is proposed, centralizing memory to guide the planner, stopping module, and answering module.
- It employs a viewpoint-contrastive memory update rule to prevent redundant updates and an entropy-based adaptive retrieval strategy for relevant information.
- A dynamic k-value mechanism adjusts the number of retrieved memories based on query complexity, and a new multi-target benchmark (MT-HM3D) is introduced for evaluation.

## Results

- MemoryEQA achieved a **9.9%** higher success rate (**43.11%**) compared to baselines on the new MT-HM3D benchmark and significantly reduced exploration steps across all evaluated datasets.
- The framework established state-of-the-art results on OpenEQA and demonstrated superior performance on HM-EQA by optimizing exploration and response generation.
- Ablation studies confirmed that the proposed memory update, adaptive retrieval strategies, and memory integration into the planner, stopping, and answering modules cumulatively contribute to enhanced success rates and efficiency.

## Takeaways

> [!tip] Key Insights
> - Integrating memory directly into the planner, stopping, and answering modules fundamentally enhances both the accuracy and efficiency of EQA tasks.
> - Sophisticated memory management, including viewpoint-contrastive updates and entropy-based adaptive retrieval, is crucial for robust performance in dynamic environments.
> - The performance of the underlying Vision-Language Model is a key factor influencing the overall effectiveness of the EQA system.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Embodied Question Answering (EQA) is a challenging task in robotics that requires an autonomous agent to actively explore a dynamic environment, comprehend its context, and answer natural language questions. Current EQA approaches typically employ a "planner-centric" framework, where a planner module coordinates other components such as memory, answering, and stopping modules. A key limitation of these existing methods is the underutilization of the memory module. Information stored in memory is predominantly leveraged by the answering module and often not integrated into the planning or stopping decision-making processes.

This design limitation frequently leads to inefficient exploration, manifesting as redundant exploration of already visited areas or insufficient exploration where critical information is overlooked. Consequently, such planner-centric designs can result in suboptimal task success rates due to inaccurate responses or incomplete information gathering. This work addresses this inefficiency by proposing a "memory-centric" EQA framework, aiming to integrate memory information across all modules to guide exploration, planning, reasoning, and answering, thereby enhancing overall efficiency and accuracy in EQA tasks. The research aims to move beyond memory as a mere repository for final answering, instead positioning it as a core component that actively influences every stage of the embodied agent's interaction with its environment.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop an Embodied Question Answering (EQA) framework that improves upon the efficiency and accuracy of existing methods by making memory a central component of the agent's decision-making process.

The motivation stems from observed limitations in current "planner-centric" EQA systems:
- **Inefficient Memory Utilization:** In prevailing EQA architectures, the memory module's role is often restricted. Its stored information is typically accessed only by the answering module at the final stage of the task. This means that critical historical observations, object attributes, and spatial knowledge gathered during exploration are often not directly available or utilized by the planner or stopping modules.
- **Redundant or Inadequate Exploration:** Without direct access to comprehensive memory, the planner relies predominantly on current observations for navigation and exploration decisions. This can lead to:
 - **Redundant Exploration:** An agent might re-explore areas or re-identify objects for which information has already been collected and stored in memory. For instance, as illustrated in the paper, an agent might re-search for the color of a sofa in the living room even after having successfully identified it, because the planner is not informed by the memory module that this specific piece of information has already been acquired.
 - **Inadequate Exploration:** The agent might fail to explore necessary regions or objects if its planning decisions are not guided by a cumulative understanding of what information has been gathered and what is still required to answer the question. This can lead to premature stopping or incomplete task execution.
- **Suboptimal Success Rates:** The combination of inefficient exploration and incomplete information propagation across modules can ultimately lower the overall success rate of EQA tasks, particularly for complex questions that require synthesizing information from multiple targets or regions.
- **Instability of Long-Term Memory:** Operating in dynamic and complex 3D environments presents challenges for maintaining stable and relevant long-term memory. Irrelevant or noisy updates can corrupt memory, and inefficient retrieval mechanisms can hinder access to pertinent information, adversely affecting planning, reasoning, and answering.

To address these issues, the key objectives of this work are:
- To propose MemoryEQA, a memory-centric EQA framework that integrates memory information into all modules—planner, stopping, and answering—to guide exploration, planning, and reasoning.
- To design specific mechanisms for memory storage, viewpoint-contrastive memory update, and entropy-based adaptive retrieval to ensure that memory is robustly managed and effectively utilized throughout the EQA process.
- To develop a novel benchmark, MT-HM3D, specifically tailored to evaluate the memory capabilities of EQA models by featuring complex, multi-target, multi-region questions.

### 3. Methodology and Approach

The MemoryEQA framework proposes a shift from a planner-centric to a memory-centric design for Embodied Question Answering. It comprises four core modules: a planner, a memory module, a stopping module, and an answering module, with enhanced inter-module interaction facilitated by the central memory component.

#### 3.1. Memory-Centric EQA Framework

The framework reformulates the EQA process where the memory module ($F_M$) contains both retrieval ($f_r^M$) and update ($f_u^M$) functions. Memory information ($M$) is defined as natural language memories ($m_i$) derived from image observations ($o_i$). The planner ($F_P$), stopping module ($F_S$), and answering module ($F_A$) all receive retrieved memory information ($f_r^M(q_p)$, $f_r^M(q_s)$, $f_r^M(q_a)$) along with current observations or the question.

#### 3.2. Planner

The planner extends the conventional frontier-based exploration by incorporating memory guidance. It represents the environment as an occupancy grid map. Frontier cells, which are free cells adjacent to unknown cells, are grouped into regions. Each frontier $D_i$ is evaluated by a utility function that balances expected information gain and navigation cost. Instead of selecting only the highest-utility frontier, the planner retains the top-p candidates. For each candidate, a Vision-Language Model (VLM) assesses its relevance by evaluating the consistency between the current observation (for different directions) and memory information retrieved using a planner-specific query ($q_p$). The direction with the highest relevance score is then chosen, balancing spatial coverage with task-relevant semantic goals.

#### 3.3. Memory Module

This module is equipped with mechanisms for storage, update, and retrieval to ensure effective memory management.

- **Storage:** Observations are converted into structured textual representations, encoded into dense feature vectors ($f_i$) using a unified encoder ($e_c$), and stored in a vector library (L) along with their unique index, position, rotation, and original textual memory ($m_i$). A scene memory library ($M_s$) stores accumulated memory persistently for future tasks within the same environment.

- **Update (Viewpoint-Contrastive Memory Update Rule):** This mechanism prevents redundant or erroneous memory updates. An update is triggered only if *all three* of the following conditions are met:
 1. The agent enters a previously known region, meaning its current position ($p_i$) and orientation ($r_i$) are significantly close to an existing memory entry (Euclidean distance $∥p_i - p_j∥_2 < β_p$ and Euclidean angle $∠(r_i, r_j) < β_r$).
 2. The combined similarity between the current observation ($o_i$) and *all* existing memory observations ($o_j$) exceeds a predefined threshold. This similarity (SIM) is a weighted sum of structural similarity (SSIM) and cosine similarity of feature vectors.
 3. The current observation's field of view is not substantially restricted (e.g., black areas do not exceed half of the observation).
 If these conditions are not met, but the agent is in a *new* region (based on position/rotation thresholds), the observation is directly added as a new memory. When an update is triggered, the new memory replaces the original memory at the same index.

- **Retrieval (Entropy-Based Adaptive Retrieval Strategy):** This approach employs a multi-modal retrieval strategy.
 - **Initial Retrieval:** Before exploration, a combined feature ($f_q$) from the initial observation ($o_0$) and the user question ($q$) is used to retrieve relevant initial memories from the scene memory library ($M_s$), forming the primary memory library ($M$). This occurs once per task.
 - **Step-wise Retrieval:** At each exploration step, different modules (planner, stopping, answering) query the memory library ($M$) for specific information ($M_{cur}$). Retrieval is based on two criteria: the L2 distance between the query feature and memory feature must be below an adaptively adjusted threshold (dependent on the query's entropy), and the cosine similarity between them must exceed a threshold ($\alpha_s$). The entropy-based adjustment ensures that for clearer queries (low entropy), only very close memories are retrieved, while for ambiguous queries (high entropy), a wider matching range is allowed.
 - **Dynamic K-Value Mechanism:** The number of memories retrieved ($k$) for the top-k selection is adaptively adjusted based on the complexity of the user query ($q$) and initial observation ($o_0$). A linear adjustment strategy is used: $k = \lceil k_{min} + β \cdot \text{Entropy}(f_q) \rceil$. This implies that more complex queries or scenes will retrieve a larger amount of memory information.

#### 3.4. Stopping Criterion

The stopping module combines retrieved memory information (using $q_s$) with the current observation and prompts a VLM to estimate the confidence of being able to answer the question. If this confidence exceeds a threshold ($\gamma$), or if the maximum exploration steps are reached, the agent stops exploring, and the answering module is invoked.

#### 3.5. Answering Module

This module is a retrieval-augmented VLM, activated upon stopping. It receives semantically relevant memory content (retrieved using $q_a$) along with the original question. This selective feeding of memory aims to reduce computational overhead and mitigate distractions from irrelevant information, enabling the VLM to generate contextually coherent and accurate responses based on the agent's past experiences.

#### 3.6. Benchmark Construction (MT-HM3D)

To evaluate memory capabilities, the authors constructed MT-HM3D, a dataset based on HM3D scenes. It comprises 1587 question-answer pairs across 500 scenes, generated using GPT-4o and GPT-4-mini, followed by manual verification. Unlike existing datasets, MT-HM3D features questions requiring agents to remember information about multiple targets across different regions. Questions are categorized into: Comparison, Relationship, Counting, and Attribute. Performance is evaluated using success rate (for multiple-choice), GPT score and ROUGE-L (for open-vocabulary), and normalized steps (for efficiency).

### 4. Main Findings and Results

The experiments evaluated MemoryEQA against baseline models, primarily ExploreEQA, across the newly introduced MT-HM3D benchmark and existing HM-EQA and OpenEQA datasets. Various Vision-Language Models (VLMs) were used as foundational models.

#### 4.1. Performance on MT-HM3D

- MemoryEQA, particularly when equipped with GPT-4o, achieved a success rate of 43.11%, representing a 9.9% improvement compared to the baseline ExploreEQA with GPT-4o (33.21%). This substantial gain underscores the importance of the hierarchical memory management in handling multi-target EQA tasks.
- MemoryEQA also demonstrated improved exploration efficiency on MT-HM3D, with a normalized step count of 0.41 (using GPT-4o) compared to the baseline's 0.64.

#### 4.2. Performance on HM-EQA and OpenEQA

- **HM-EQA:** MemoryEQA (with GPT-4o) achieved a success rate of 61.4% and a normalized step count of 0.4, outperforming ExploreEQA (GPT-4o) which obtained 47.4% success and 0.77 normalized steps. This indicates MemoryEQA's effectiveness in optimizing exploration and answering even on datasets not explicitly designed for multi-target evaluation.
- **OpenEQA:** MemoryEQA (with GPT-4o) yielded a GPT score of 30.87, ROUGE-L of 0.32, and normalized steps of 0.58. While the GPT-4o baseline had comparable quality metrics, MemoryEQA consistently reduced exploration steps (0.58 vs. 0.77).
- The results indicate that MemoryEQA establishes a new state-of-the-art on OpenEQA and achieves comparable or superior performance on HM-EQA compared to previous best methods.

#### 4.3. Impact of VLM Selection

- VideoLLM-based EQA methods showed some improvement on MT-HM3D (1.92% to 9.36%) over standard Visual LLMs, attributed to the inherent historical information in video. However, MemoryEQA further enhanced these VideoLLM performances, suggesting that its structured memory management is more effective than raw video memory in EQA tasks.
- Spatial LLMs provided limited benefits, potentially due to the dataset's question distribution not heavily emphasizing spatial relationships, leading their performance to align with general LLMs.
- A clear positive correlation was identified between the foundational VLM's performance and the overall EQA system's effectiveness, highlighting the VLM's critical role in interpreting visual information and complex queries.

#### 4.4. Ablation Studies

- **Memory Strategies (Update, Retrieval, K-value Selection):**
 - The baseline without any proposed memory strategies exhibited poor performance.
 - Introducing the "memory update" (U) strategy alone showed only marginal improvements.
 - Combining "memory update" (U) with "memory retrieval" (R) led to significant performance gains and reduced exploration steps, indicating the value of accessible past experiences.
 - Integrating all three strategies: "memory update" (U), "memory retrieval" (R), and "k-value selection" (K), resulted in the highest success rates and most efficient exploration across benchmarks, demonstrating the cumulative benefit of comprehensive memory management.
- **Memory Integration into Modules (Stopping, Answering, Planner):**
 - Baseline (no memory input to any module) showed low success rates.
 - Integrating memory into the "Stopping Criterion" (S) yielded modest improvements.
 - Adding memory to both "Stopping" and "Answering Modules" (S+A) significantly boosted performance, confirming that memory-enhanced answering effectively resolves ambiguities.
 - Full integration, including memory in the "Planner" (S+A+P), achieved peak success rates and notably reduced exploration steps. This indicates that the planner's access to memory is crucial for optimizing task decomposition and trajectory planning, leading to more efficient exploration by mitigating redundant actions.

#### 4.5. Real-World Experiments

Preliminary experiments using a Unitree Go2 robot in both office and custom-built scenarios demonstrated the framework's practical applicability. The agent successfully answered open-vocabulary questions and avoided re-exploring previously identified objects, affirming the efficacy of the memory-centric approach in physical environments.

### 5. Significance and Potential Impact

This research presents a notable advancement in the field of Embodied Question Answering (EQA) by proposing a "memory-centric" framework, MemoryEQA, which fundamentally re-architects how memory is utilized within an embodied agent.

The significance and potential impact of this work include:

- **Paradigm Shift in EQA Design:** By shifting from a "planner-centric" to a "memory-centric" design, the paper addresses a core limitation of existing EQA systems where memory was an underutilized component. This re-conceptualization provides a more integrated and holistic approach to embodied intelligence, potentially inspiring future research to place memory at the forefront of perception-action loops.
- **Enhanced Performance and Efficiency:** The demonstrated improvements in success rates across multiple benchmarks, particularly the 9.9% gain on the challenging MT-HM3D dataset, indicate a tangible increase in the accuracy of EQA systems. Concurrently, the significant reduction in normalized exploration steps highlights a boost in operational efficiency, making agents more effective in resource-constrained or time-sensitive applications.
- **Robust Memory Management:** The proposed viewpoint-contrastive memory update rule and entropy-based adaptive retrieval strategy offer practical solutions for managing long-term memory in dynamic and complex environments. These mechanisms help in mitigating the impact of noisy or irrelevant information, ensuring that the memory module consistently provides pertinent context to other components.
- **Novel Benchmark for Memory Evaluation:** The introduction of MT-HM3D, a benchmark specifically designed to test memory capabilities through multi-target, multi-region questions, addresses a gap in existing EQA datasets. This will be instrumental in fostering further research focused on developing and evaluating sophisticated memory mechanisms in embodied AI.
- **Broader Applicability to Embodied AI:** The principles and methods developed in MemoryEQA have implications beyond EQA. Robust memory management and its integration into planning and decision-making are critical for various embodied AI tasks, including long-horizon navigation, object manipulation, and human-robot interaction in complex environments.
- **Foundation for Future Research:** This work lays a robust foundation for future investigations into more advanced memory architectures, including hierarchical knowledge representation, symbolic reasoning with retrieved memories, and continuous learning within dynamic environments. The findings also emphasize the continued importance of advancing underlying VLM capabilities for overall EQA system performance.
- **Real-World Potential:** The successful validation in both simulated and initial real-world experiments suggests that MemoryEQA has the potential to contribute to the development of more intelligent and autonomous robotic systems capable of performing complex tasks in real-world settings, such as assistive robotics, exploration, and intelligent surveillance.
