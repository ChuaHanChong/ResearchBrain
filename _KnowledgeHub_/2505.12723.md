# On-Policy Optimization with Group Equivalent Preference for Multi-Programming Language Understanding

> [!summary] Summary
> An integrated reinforcement learning framework, OORL, was introduced to enhance large language models' proficiency in understanding multiple programming languages. This framework leverages on-policy optimization with a novel Group Equivalent Preference Optimization (GEPO) that uses Intermediate Representations to capture functional equivalence, resulting in superior performance on code generation and translation benchmarks, including for low-resource languages.

## Problem

- Large Language Models (LLMs) exhibit a performance disparity between widely adopted and less common programming languages, limiting their universal applicability for code tasks.
- Existing on-policy Reinforcement Learning (RL) approaches using rule-based rewards for code generation often provide only coarse-grained feedback, failing to capture fine-grained functional equivalence.
- Traditional pairwise preference optimization methods are insufficient for situations where multiple distinct code implementations or Intermediate Representations (IRs) can be functionally equivalent.

## Method

- Developed **OORL**, a novel reinforcement learning framework that synergistically combines ==on-policy RL== for foundational correctness and a new off-policy method, Group Equivalent Preference Optimization (GEPO).
- Employed on-policy RL with rule-based rewards derived from unit tests to train LLMs on code translation tasks, ensuring basic code correctness.
- Introduced GEPO, which utilizes groups of functionally equivalent Intermediate Representations (IRs) to provide fine-grained supervision and explicitly enforce consistency among preferred, equivalent code solutions.

## Results

- The Qwen3-**8B**-OORL model achieved an average pass@1 score of 76.31 on the MultiPL-E benchmark, surpassing all baselines and demonstrating enhanced multilingual code generation capabilities.
- OORL obtained the highest average translation scores on the CrossPLEval benchmark, indicating improved code translation proficiency across various source and target languages.
- Ablation studies confirmed that GEPO, particularly with its IR-based group equivalence modeling, yielded substantial performance gains, especially in generalizing to low-resource and previously untrained target languages.

## Takeaways

> [!tip] Key Insights
> - Training LLMs on code translation tasks effectively improves their general comprehension of code functionality across multiple programming languages.
> - Compiler Intermediate Representations (IRs) serve as a potent, language-agnostic mechanism to represent and identify fine-grained functional equivalence in code, which can significantly guide LLM training.
> - Modeling functional equivalence within groups of preferred outcomes (GEPO) provides a more nuanced and effective approach than pairwise comparisons, allowing LLMs to better understand and generate functionally consistent code.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Large Language Models (LLMs) have demonstrated considerable capabilities in code generation tasks. However, a noticeable performance discrepancy exists between their proficiency in widely adopted programming languages (e.g., Python, C++) and their performance in less common or "low-resource" languages. This disparity limits the general applicability of these models and poses challenges for developers working across diverse programming language ecosystems.

Prior research in code LLMs, such as StarCoder, CodeLlama, DeepSeekCoder, and QwenCoder series, has focused on enhancing code generation. Approaches to improve multilingual code understanding and generation include leveraging Intermediate Representations (IRs) to abstract program logic, as seen in IRCoder, Transcoder-IR, CoDist, and LLM Compiler. These methods utilize IRs as a language-agnostic pivot or for specialized compiler tasks.

Reinforcement Learning (RL) has also emerged as a method for aligning LLMs with desired behaviors. On-policy RL algorithms, often utilizing rule-based rewards (e.g., PPO, REINFORCE-style methods), have shown effectiveness in code generation by providing explicit signals for correctness. Concurrently, off-policy methods like Direct Preference Optimization (DPO) and Implicit Policy Optimization (IPO) have been developed to learn from preference data more efficiently, implicitly inferring reward functions without explicit reward model training.

This work contributes to this landscape by specifically addressing the capability gap in multilingual code understanding. It integrates both on-policy and off-policy RL strategies within a novel framework, OORL, focusing on code translation as the primary training task. A key innovation lies in Group Equivalent Preference Optimization (GEPO), an extension of preference optimization tailored to the unique challenge of recognizing functional equivalence across multiple code implementations or Intermediate Representations (IRs). This approach distinguishes itself by explicitly modeling equivalence within groups of preferred responses, which is particularly relevant for the nuanced nature of code functionality where multiple valid solutions can exist. By combining rule-based on-policy learning with IR-based fine-grained preference optimization, the research aims to provide LLMs with a more comprehensive understanding of code functionality across a wider spectrum of programming languages.

### 2. Key Objectives and Motivation

The central objective of this research is to enhance the proficiency of Large Language Models (LLMs) across a broader range of programming languages, aiming to reduce the performance disparity observed between high-resource and low-resource languages. This addresses a "capability gap" that restricts the universal utility of current code LLMs.

The motivation for achieving this objective is multifaceted:

- **Addressing the Capability Gap:** Current state-of-the-art code generation LLMs demonstrate proficient performance in popular languages like Python and C++, but their capabilities diminish when applied to other programming languages. This limitation hinders developers and impacts the universal applicability of these powerful tools.
- **Leveraging Code Translation as a Training Task:** The authors propose using code translation tasks to train LLMs. The rationale is that if an LLM can accurately translate code from one language (e.g., Python) into another, it implies a deeper understanding of the code's functionality, which should translate into comparable performance in code generation tasks for those target languages. This also facilitates the LLM's understanding of inter-language similarities and differences.
- **Limitations of Coarse-Grained Rule-Based Rewards:** While on-policy Reinforcement Learning (RL) with rule-based rewards (e.g., passing unit tests) has been effective in code generation, these rewards are often binary and coarse-grained. They provide a strong signal for overall correctness but lack process-level supervision, limiting the LLM's ability to recognize the functional equivalence of intermediate code components. Fine-grained, process-level rewards are challenging to implement due to the existence of multiple valid implementations for the same code functionality.
- **Opportunity of Preference Optimization:** Preference optimization methods offer an avenue to incorporate finer-grained, process-level constraints into training by leveraging preference data that guides LLM behavior towards desired outcomes.
- **Leveraging Intermediate Representations (IRs) for Functional Equivalence:** High-level programming languages can be overly abstract for LLMs to fully grasp functional nuances, particularly for less common languages. Compiler Intermediate Representations (IRs), being language-agnostic and exposing detailed, low-level operators, are considered more amenable for LLMs to understand. Moreover, functionally equivalent IRs can be generated from source code through different compiler optimization stages (e.g., -Oz, -O3). These variations provide valuable signals for discerning the functional equivalence of different code implementations.
- **Limitations of Traditional Pairwise Preference Optimization (DPO) for Equivalence:** Existing preference optimization methods, such as Direct Preference Optimization (DPO), primarily rely on pairwise comparisons. This approach is deemed insufficient for scenarios where multiple responses or IRs can be considered functionally equivalent. Traditional DPO does not explicitly model this concept of mutual equivalence among a set of preferred outcomes.
- **Developing a Novel Integrated RL Framework:** To address these motivations, the research aims to introduce OORL, a novel RL framework that integrates both on-policy and off-policy strategies. The on-policy component handles basic correctness through rule-based rewards, while the off-policy component, specifically Group Equivalent Preference Optimization (GEPO), addresses the fine-grained functional equivalence using IR groups. GEPO is designed to explicitly compare groups of equivalent and inequivalent IRs, and crucially, to enforce consistency among functionally equivalent IRs within a preferred group.

In summary, the core motivation is to improve LLM code understanding across diverse languages by training on code translation, overcoming the limitations of coarse-grained rewards with a novel preference optimization method (GEPO) that leverages the nuanced functional equivalence captured by IRs, and integrating these into a coherent RL framework (OORL).

### 3. Methodology and Approach

The research introduces On-Policy Optimization with Group Equivalent Preference (OORL), a novel reinforcement learning framework that integrates on-policy and off-policy strategies to enhance Large Language Models' (LLMs) multi-programming language understanding. The framework is applied during training with code translation tasks.

#### 3.1. OORL Framework Overview

OORL combines two primary components: an on-policy RL strategy guided by a rule-based reward and an off-policy Group Equivalent Preference Optimization (GEPO) method. These components are designed to work synergistically, with the on-policy RL ensuring fundamental correctness and GEPO incorporating finer-grained functional equivalence. The combined objective function `L = w_rl · L_OnP + w_gepo · L_GEPO` balances the contributions of these two strategies, where `w_rl` and `w_gepo` are weighting hyperparameters (set to 1 and 0.01, respectively).

#### 3.2. On-policy RL for Code Translation

This component employs an on-policy RL algorithm (specifically REINFORCE++ in experiments) to train LLMs on code translation tasks.

- **Task Definition:** The LLM receives a query `q` containing source code and translates it into a target language, generating a sequence of tokens `o`.
- **RL Setup:**
 - **State (`s`):** Comprises the input `q` and the partially generated translated code `o_<t`.
 - **Action (`a`):** The generation of the next token `o_t` by the policy model.
 - **Policy (`π_θ`):** The LLM being optimized, initialized from a supervised fine-tuned (SFT) reference model `π_ref`.
- **Binary Rule-Based Reward (`R_rule`):** Upon completion of code generation `o`, a binary reward is assigned:
 - `R_rule(q, o) = 1` if the generated code `o` successfully translates `q`. Success implies adherence to standard format, successful compilation, and passing predefined unit tests.
 - `R_rule(q, o) = 0` otherwise.
- **Optimization:** The policy model `π_θ` is optimized using an on-policy RL algorithm to maximize the expected reward, typically including a KL divergence penalty to maintain proximity to `π_ref`. The on-policy RL loss (`L_OnP`) is based on methods like Proximal Policy Optimization (PPO), employing a clipped objective function to maximize advantage estimates while limiting policy changes per step. This component provides a clear signal for overall task completion.

#### 3.3. Group Equivalent Preference Optimization (GEPO) with IRs

GEPO is a novel off-policy preference optimization method designed to address the limitations of coarse-grained rewards and traditional pairwise preference optimization by incorporating fine-grained functional equivalence through Intermediate Representations (IRs).

- **Motivation for IRs:** High-level programming languages can be too abstract for LLMs, particularly for less common ones. Compiler IRs are language-agnostic and expose detailed, low-level operations, facilitating functional understanding. Furthermore, different compiler optimization levels can produce functionally equivalent IRs, offering a source of "winner" examples that should be recognized as equivalent.
- **Preference Data Construction (`D_gpref`):**
 - For each source code prompt `x_g`, a group of "winner" responses `Y_w = {y_1^w..., y_n^w}` and a group of "loser" responses `Y_l = {y_1^l..., y_m^l}` are constructed.
 - `Y_w` consists of `n` functionally equivalent IRs derived from the source code (e.g., from different LLVM optimization levels like -Oz, -O3).
 - `Y_l` consists of `m` inequivalent IRs, which are augmented from the equivalent IRs group (as illustrated in Figure 2). The task is IR translation: high-level code to IRs.
- **GEPO Objective Formulation:**
 - Unlike traditional DPO, GEPO compares *groups* of IR responses. It assumes an implicit reward function `r_ϕ(x_g, y_g)` underlies the preferences.
 - The primary objective term maximizes the probability that the *average reward* of the winner group `Y_w` exceeds the *average reward* of the loser group `Y_l`.
 - Crucially, a constraint is added to bound the *variance* of rewards within the winner group `Y_w` below a threshold `ϵ`. This encourages all `y_i^w ∈ Y_w` to have similar rewards, thereby explicitly enforcing functional equivalence among them.
 - **Derivation:** Following the principles of DPO, the implicit reward `r_ϕ` is related to the log-probability ratio `β log(π_θ(y_g|x_g) / π_ref(y_g|x_g))` plus a partition function term (Equation 7, 15). Substituting this into the constrained objective (Equation 6) and applying a Lagrange multiplier `λ` for the variance constraint transforms it into an unconstrained loss function (`L_GEPO`, Equation 9).
 - `L_GEPO` comprises two terms:
 1. A DPO-like term that operates on the average log-probability ratios of the winner and loser groups, pushing the model to prefer winners over losers on average.
 2. A regularization term, weighted by `λ` (set to 1), that penalizes the variance of the log-probability ratios within the winner group `Y_w`. This minimizes the reward difference between equivalent IRs, enforcing consistency.
- **Optimization:** Minimizing `L_GEPO` directly optimizes `π_θ` to increase the likelihood of generating high-quality, functionally equivalent IRs (winners) over undesired ones (losers), while also promoting consistency among the preferred solutions.

#### 3.4. Experiment Settings

- **Training Data:**
 - On-policy RL: 2400 code translation problems with unit tests from SYNTHETIC-1 and APPS datasets (Python/C++ to Python, C++, Java, PHP, Bash, JavaScript).
 - GEPO: 9600 curated C-to-IR groups from the SLTrans dataset.
- **Implementation Details:**
 - Base LLM: Qwen3-8B.
 - On-policy RL algorithm: REINFORCE++.
 - Optimizer: AdamW (learning rate 5 × 10^-7, no weight decay).
 - Training: Cosine learning rate schedule with 0.03 warm-up ratio, batch size 8, sequence length 8192 tokens, one epoch of instruction tuning using DeepSpeed-Zero stage2 with offload on 4 A100 GPUs (80G memory each).
- **Baselines:** DS-Coder-V2-Lite-Inst, Qwen2.5-Coder-7B-Inst, and Qwen3-8B (non-thinking mode).
- **Evaluation Benchmarks:**
 - **MultiPL-E:** An established benchmark for code generation across 8 mainstream languages (Python, C++, Java, PHP, TypeScript, C#, Bash, JavaScript).
 - **CrossPLEval:** A newly developed multilingual code translation benchmark. It comprises 119 problems from the TACO dataset, manually translated into Python, Java, Go, and C++, with test cases rewritten for 10 languages (including low-resource ones like Scala and Haskell). This results in 3920 independent coding problems.
- **Metric:** Pass@1 rate for both benchmarks.

### 4. Main Findings and Results

The experiments conducted demonstrate the performance of the OORL framework in enhancing multi-programming language understanding and generation capabilities of LLMs.

#### 4.1. Overall Performance

The Qwen3-8B-OORL model, trained with the proposed framework, consistently exhibited superior performance compared to baseline LLMs (DS-Coder-V2-Lite-Inst, Qwen2.5-Coder-7B-Inst, and the base Qwen3-8B) across both code generation and code translation benchmarks.

#### 4.2. MultiPL-E Benchmark (Code Generation)

- **Quantitative Improvement:** On the MultiPL-E benchmark, Qwen3-8B-OORL achieved the highest average pass@1 score of 76.31. This represents a substantial improvement over the second-highest baseline, Qwen2.5-Coder-7B-Inst, and a significant gain over the base Qwen3-8B (65.07).
- **Language Proficiency:** This superior performance was observed across all eight languages evaluated in MultiPL-E, indicating an enhanced ability to generate correct code from natural language instructions in these languages, which are generally well-represented in large code corpora.

#### 4.3. CrossPLEval Benchmark (Code Translation)

- **Code Translation Capabilities:** Qwen3-8B-OORL achieved the highest average translation scores across all evaluated source languages on the CrossPLEval benchmark. This benchmark specifically assesses the model's ability to translate canonical solutions from a source language to various target languages.
- **Generalization to Low-Resource and Untrained Languages:**
 - CrossPLEval includes languages that may be less represented in training data or are considered low-resource (e.g., Scala, Go, TypeScript, C#, Haskell). While absolute translation scores for these challenging targets (Bash, Scala, Haskell) were lower compared to more common languages, Qwen3-8B-OORL demonstrated substantial *relative improvements* over the baselines.
 - For instance, when translating from Python to Haskell, Qwen3-8B-OORL scored 28.48 pass@1, representing a notable gain compared to Qwen3-8B.
 - These results suggest that the OORL framework effectively promotes generalization beyond its direct training data, providing performance boosts for tasks involving low-resource programming languages and untrained target languages.

#### 4.4. Ablation Studies

Ablation studies were conducted to isolate the contribution of each component of the OORL framework:

- **Impact of On-Policy RL Strategy (REINFORCE++):**
 - Training with code translation tasks using the REINFORCE++ algorithm alone significantly improved performance compared to the base Qwen3-8B. The MultiPL-E score increased from 65.06 to 73.60, and the average CrossPLEval score rose from 50.96 to 58.46.
 - This demonstrates that the on-policy RL component, utilizing rule-based rewards derived from unit tests, is effective in refining the LLM's understanding across multiple programming languages and ensuring fundamental correctness.
- **Impact of Off-Policy RL Strategy (DPO vs. GEPO):**
 - **REINFORCE++ + DPO:** Combining REINFORCE++ with Direct Preference Optimization (DPO) yielded only a marginal improvement on CrossPLEval (average score of 58.70) compared to REINFORCE++ alone (58.46). This suggests that DPO, with its pairwise comparison mechanism, had limited effectiveness in capturing the functional equivalence nuances critical for code understanding in this context.
 - **REINFORCE++ + GEPO:** Integrating GEPO with REINFORCE++ resulted in the highest performance observed. The MultiPL-E score reached 76.31, and the average CrossPLEval score reached 63.15. This outcome indicates that GEPO's specific design, which leverages functional equivalence information from IRs and explicitly models equivalence within groups, provides substantial additional performance gains over standard off-policy methods for multi-programming language understanding.

In summary, the main findings indicate that the OORL framework, particularly through the synergistic combination of on-policy RL for foundational correctness and GEPO for fine-grained functional equivalence understanding via IRs, leads to robust improvements in multilingual code generation and translation, with notable generalization capabilities to challenging and low-resource languages.

### 5. Significance and Potential Impact

This research presents a notable advancement in the field of Large Language Model (LLM) development for code-related tasks, with several areas of significance and potential impact:

- **Addressing the Multilingual Capability Gap:** The work directly addresses a key limitation of current code LLMs: their diminished performance in less popular or low-resource programming languages compared to high-resource ones. By enhancing LLMs' proficiency across a wider spectrum of languages, this research contributes to making these powerful tools more universally applicable and equitable for developers working in diverse linguistic ecosystems.
- **Novel Integrated Reinforcement Learning Framework (OORL):** The introduction of OORL, which integrates both on-policy and off-policy RL strategies, represents a methodological contribution. This framework combines the strengths of rule-based reward signals for fundamental correctness (via on-policy RL) with fine-grained functional equivalence learning (via GEPO). This dual approach provides a more comprehensive and robust training paradigm for complex tasks like code understanding and translation.
- **Innovation in Preference Optimization (GEPO):** Group Equivalent Preference Optimization (GEPO) is a significant novel contribution. By extending beyond traditional pairwise comparisons, GEPO explicitly models the concept of equivalence within groups of preferred Intermediate Representations (IRs). This mechanism is particularly well-suited for tasks involving code, where multiple distinct implementations or representations can be functionally equivalent. GEPO's ability to discern and enforce this equivalence offers a more nuanced approach to guiding LLM behavior and could inspire similar group-based preference optimization methods in other domains where multiple valid outputs exist.
- **Enhanced Functional Understanding through IRs:** The effective leveraging of Intermediate Representations (IRs) within the GEPO framework demonstrates a powerful method for guiding LLMs toward a deeper, more abstract understanding of code functionality. By enabling LLMs to recognize mutual equivalence between different IRs derived from the same source code, the approach moves beyond superficial syntactic understanding, which is crucial for robust cross-language transfer.
- **Improved Generalization to Low-Resource Languages:** The observed performance improvements, particularly the relative gains on low-resource and untrained target languages in the CrossPLEval benchmark, underscore the framework's ability to generalize beyond its direct training data. This indicates a potential pathway to making LLMs more effective for a broader range of programming languages without requiring extensive direct training data for each.
- **Practical Implications for Software Development:** More proficient multilingual code LLMs could significantly impact software development workflows. This includes:
 - **Automated Code Translation:** Facilitating faster and more accurate translation of legacy code or cross-platform development.
 - **Enhanced Code Generation:** Providing developers with more reliable code generation capabilities in their preferred or required languages, regardless of their popularity.
 - **Code Debugging and Analysis:** A deeper understanding of functional equivalence could aid in advanced code analysis and debugging tools.
 - **Educational Tools:** Potentially assisting in learning new programming languages by providing accurate translations and highlighting functional similarities.

In conclusion, this research offers a new perspective on enhancing LLMs' understanding capabilities across diverse programming languages by pioneering an integrated RL framework that effectively leverages functional equivalence, paving the way for more versatile and universally applicable code intelligence tools.
