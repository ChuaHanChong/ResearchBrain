# SUSD: Structured Unsupervised Skill Discovery through State Factorization

> [!summary] Summary
> SUSD, a framework from Sharif University of Technology, introduces structured unsupervised skill discovery by integrating state factorization and curiosity-driven weighting into a distance-maximizing approach. This method learns comprehensive, disentangled skill sets in complex environments, outperforming prior baselines in multi-object tasks and achieving better state coverage.

## Problem

- Existing Mutual Information (MI)-based Unsupervised Skill Discovery (USD) methods learn simple, static skills, struggling with dynamic and complex behaviors.
- Distance-Maximizing Skill Discovery (DSD) methods, while improving dynamics, often exhibit a bias towards easily controllable factors, leading to incomplete skill repertoires in multi-object environments.
- Previous USD approaches lack explicit mechanisms to ensure learned skills comprehensively cover all controllable factors or entities within complex, compositional environments.

## Method

- **SUSD** implements Factorized Distance-Maximizing ==Skill Discovery== (DSD) by decomposing the state and skill latent spaces into N independent components, with a factorized mapping function and a factor-wise objective.
- It incorporates a curiosity-based factor weighting mechanism using a conditional density model to dynamically identify and prioritize harder-to-control or less explored environmental factors for skill learning.
- The framework optimizes a skill policy via Soft Actor-Critic (SAC) using an intrinsic reward, which is a curiosity-weighted sum of factor-wise skill rewards, alongside dual gradient updates for mapping functions and a Lagrange multiplier.

## Results

- SUSD consistently outperformed all tested baselines on downstream tasks in factorized environments like Multi-Particle and Kitchen, with "accidental task completions" showcasing its intrinsically useful skills.
- The framework achieved substantially better state coverage, particularly "Worst Agent State Coverage" and "Average Agent State Coverage," ensuring balanced exploration across all factors, including harder-to-control ones.
- SUSD learned a richer latent skill embedding, demonstrated by significantly lower factor-wise Mean Squared Error (MSE) when decoding observations from the latent skill space, confirming comprehensive and disentangled skill representations.

## Takeaways

> [!tip] Key Insights
> - Leveraging the inherent compositional structure of environments through state factorization provides a powerful inductive bias for learning disentangled and comprehensive skill sets.
> - Dynamically weighting the learning process based on factor-wise curiosity is crucial for overcoming the bias towards easily controllable elements and encouraging balanced exploration across all environmental components.
> - Integrating state factorization into a DSD framework allows for the discovery of both dynamic and comprehensive skills, addressing limitations of both MI-based and prior DSD methods.
