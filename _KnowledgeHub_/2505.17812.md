# Seeing It or Not? Interpretable Vision-aware Latent Steering to Mitigate Object Hallucinations

> [!summary] Summary
> Xi'an Jiaotong University researchers introduce VaLSe (Vision-aware Latent Steering), a framework that mitigates object hallucinations in Large Vision-Language Models by generating visual contribution maps to identify image regions influencing model predictions, then using these maps to construct steering samples that guide the model's latent representations toward semantically relevant objects, achieving effective hallucination reduction while maintaining general model capabilities and revealing limitations in existing evaluation metrics like CHAIR that incorrectly flag accurate descriptions due to incomplete ground-truth annotations.

## Problem

- Large Vision-Language Models frequently generate object hallucinations, producing content inconsistent with visual input that undermines reliability and safety for real-world deployment
- Existing hallucination mitigation methods lack interpretability, making it difficult to understand why hallucinations occur and how visual inputs influence model decision-making processes
- Current evaluation metrics for object hallucination assessment have limitations and may incorrectly assess model performance due to incomplete annotations

## Method

- Develop ==VaLSe framework== with three components: ==visual-based token selection== to identify visually-sensitive tokens, ==visual contribution map generation== using attention mechanisms to highlight relevant image regions, and vision-aware latent steering using SVD to compute directional differences between positive and negative samples
- Create positive steering samples by masking irrelevant image regions while preserving core objects, and negative samples using original images, then apply ==latent steering== to adjust internal model representations
- Implement artifact elimination techniques to improve interpretability of generated contribution maps and reduce neural network artifacts

## Results

- VaLSe achieves effective object hallucination mitigation comparable to or better than existing approaches while preserving general model capabilities on MME, GQA, and LLaVA-Bench benchmarks
- Framework generates high-quality visual contribution maps that provide clear insights into model decision-making processes and enable identification of hallucination causes
- Analysis reveals specific limitations in current evaluation methodologies, highlighting the need for more sophisticated and visually grounded assessment approaches for LVLM performance

## Takeaways

> [!tip] Key Insights
> - Visual contribution maps reveal that models focus on wrong or irrelevant image regions when producing hallucinated content, providing clear interpretable evidence of decision-making flaws
> - Latent steering can effectively redirect model attention toward semantically relevant objects without requiring retraining or fine-tuning of the underlying architecture
> - Existing evaluation metrics like CHAIR contain systematic biases that incorrectly penalize accurate model descriptions due to incomplete ground-truth annotations
