# Causal Object-Centric Models for Planning with Monte Carlo Tree Search

> [!summary] Summary
> COMET is an MCTS-based object-centric model-based reinforcement learning algorithm that integrates frozen unsupervised object-centric representations with a transformer-based world model and object-causal attention for enhanced planning. It achieved higher mean normalized scores during early training stages across eight diverse object-oriented visual control tasks, demonstrating improved sample efficiency compared to monolithic and other object-centric baselines.

## Problem

- Model-Based Reinforcement Learning (MBRL) struggles with learning accurate world models in complex visual environments using monolithic state representations.
- Holistic representations fail to capture critical object-level structure and interactions, leading to inefficiency and information overload from irrelevant entities.
- Existing object-centric MBRL approaches often lack explicit object interaction modeling or rely on expensive, supervised instance segmentation masks.

## Method

- Developed **COMET**, an MCTS-based algorithm for planning in a slot-structured latent space, integrating a frozen unsupervised object-centric encoder.
- Employed a transformer-based world model with a novel ==action-object binding mechanism== that fuses action embeddings with individual object slots for next-state prediction.
- Implemented object-causal attention in policy and value networks, using learned per-slot relevance scores to focus on task-relevant objects and modulate attention.

## Results

- COMET achieved a higher mean normalized score in early training phases across eight diverse object-oriented visual control tasks, indicating improved sample efficiency.
- The method demonstrated faster convergence and superior final performance in visually simpler tasks, such as Object Goal and Object Comparison.
- Visualizations confirmed that the object-causal attention mechanism successfully assigned higher relevance scores to task-relevant objects for policy and value prediction.

## Takeaways

> [!tip] Key Insights
> - Structured object-centric representations, when integrated into an MCTS-based planning framework, can improve sample efficiency compared to monolithic approaches.
> - Explicitly binding actions to individual object slots within a transformer architecture allows for more granular and accurate prediction of object-level dynamics.
> - Learning object relevance through a "causal" attention mechanism enables policy and value networks to focus computational resources on task-pertinent entities.
