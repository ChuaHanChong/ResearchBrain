# EHSOD: CAM-Guided End-to-end Hybrid-Supervised Object Detection with Cascade Refinement

> [!summary] Summary
> EHSOD, an end-to-end hybrid-supervised framework, combines fully and weakly annotated data to perform object detection. The system achieves detection performance close to fully supervised methods while requiring a substantially reduced amount of precise bounding box annotations.

## Problem

- Fully supervised object detection requires extensive and expensive bounding box annotations, limiting its scalability and application to new domains.
- Weakly supervised object detection (WSOD), while reducing annotation effort, suffers from significantly lower accuracy compared to fully supervised methods.
- Existing hybrid-supervised methods often rely on complex, multi-stage iterative pseudo-labeling processes that are sensitive to hyperparameters and prone to error accumulation.

## Method

- Introduces EHSOD, an end-to-end ==hybrid-supervised object detection== framework that combines a small amount of fully annotated data with a larger set of weakly annotated images.
- Proposes a ==CAM-RPN module== that integrates Class Activation Maps (CAMs) with a standard Region Proposal Network (RPN) to generate higher-quality region proposals, especially for weakly supervised images.
- Develops a ==Hybrid-Supervised Cascade Module== that progressively refines detection results through multiple stages, incorporating a ==Multiple Instance Detection (MID) head== to leverage image-level labels for classification.

## Results

- EHSOD achieves **75.3%** mAP on PASCAL VOC using only **30%** fully annotated data, representing a **0.8%** mAP drop compared to **100%** fully supervised training (**76.1%** mAP).
- On MS-COCO, EHSOD reaches **37.5%** mAP with **30%** fully annotated data, compared to **40.2%** mAP for full supervision.
- Ablation studies confirm the CAM-RPN improved mAP by **2.1%**, the cascade structure by **1.8%**, and the MID head by **1.5%**.

## Takeaways

> [!tip] Key Insights
> - Integrating Class Activation Maps (CAMs) into the Region Proposal Network significantly improves proposal quality for weakly supervised images.
> - An end-to-end training paradigm can effectively combine full and weak supervision without relying on iterative pseudo-labeling, reducing complexity and hyperparameter sensitivity.
> - A cascade structure with multiple instance learning (MID) heads progressively refines detection results, leveraging image-level labels to enhance classification for weakly supervised data.

## Detailed Report

### 1. Introduction

Object detection is a fundamental task in computer vision that requires both locating objects in images (with bounding boxes) and classifying them into predefined categories. Traditional approaches rely on fully supervised object detection (FSOD), which demands extensive annotation with precise bounding boxes around each object instance. This annotation process is labor-intensive and expensive, creating a significant barrier to developing detection systems for new domains or applications.

To address this challenge, researchers have explored weakly supervised object detection (WSOD), which uses only image-level labels (indicating the presence of object categories without location information). However, WSOD methods typically suffer from significantly lower accuracy compared to fully supervised approaches, limiting their practical utility.

This paper introduces EHSOD (End-to-end Hybrid-Supervised Object Detection), a novel framework that bridges the gap between fully and weakly supervised methods. EHSOD effectively combines a small amount of fully annotated data (with bounding boxes) with a larger set of weakly annotated data (with only image-level labels), creating a practical approach that reduces annotation requirements while maintaining high detection performance.

### 2. The Hybrid Supervision Challenge

Hybrid-supervised object detection (HSOD) presents unique challenges that differentiate it from both fully supervised and weakly supervised methods:

1. **Data Integration**: HSOD needs to effectively leverage two distinct types of supervision – instance-level annotations (bounding boxes) and image-level labels – within a unified training framework.

2. **Cross-Modal Learning**: The system must learn to transfer knowledge from fully annotated examples to improve detection in weakly annotated images.

3. **Performance Gap**: Existing HSOD methods still show a significant performance gap compared to fully supervised methods, especially when the proportion of fully annotated data is small.

Previous HSOD approaches have primarily relied on iterative pseudo-labeling techniques, where the model generates bounding box predictions for weakly supervised images, which are then used as training labels in subsequent iterations. These methods have several limitations:

- High sensitivity to hyperparameters
- Potential error accumulation in pseudo-labels
- Multi-stage training complexity
- Sub-optimal usage of weakly supervised data

EHSOD addresses these limitations by introducing an end-to-end training paradigm that simultaneously leverages both types of supervision without the need for iterative pseudo-labeling.

### 3. EHSOD Framework Architecture

The EHSOD architecture builds upon the two-stage detection paradigm (similar to Faster R-CNN) but introduces significant modifications to enable effective hybrid supervision. The framework consists of two primary components:

1. **CAM-RPN Module**: Enhances region proposal generation by incorporating Class Activation Maps (CAMs) to improve proposal quality for weakly supervised images.

2. **Hybrid-Supervised Cascade Module**: Refines detection results through a series of box heads that progressively improve localization and classification.

The architecture processes both fully supervised and weakly supervised images through the same network but applies different loss functions depending on the available supervision. This approach enables joint optimization of all components during training.

### 4. CAM-RPN Module

The CAM-RPN module is a critical innovation in EHSOD that addresses the challenge of generating high-quality region proposals from weakly supervised images. It combines a traditional Region Proposal Network (RPN) with Class Activation Mapping (CAM) to create a more effective proposal mechanism.

The module consists of:

1. **Standard RPN Branch**: Follows the traditional Faster R-CNN approach to generate class-agnostic proposals.

2. **CAM Branch**: A parallel branch that generates class-specific activation maps highlighting the discriminative regions for each object category.

3. **Fusion Mechanism**: Combines proposals from both branches using Non-Maximum Suppression (NMS) to select the most promising regions.

For the CAM branch, the module employs a segmentation-based approach that generates class activation maps through:

```
A_c = (w_c^T · features) > threshold
```

Where:
- A_c is the binary activation map for class c
- w_c is the weight vector for class c from the classification layer
- The threshold is dynamically determined based on the activation distribution

The CAM branch is trained using a combination of segmentation loss and classification loss:

```
L_CAM = L_CAM-seg + L_CAM-cls
```

For weakly supervised images, the CAM provides crucial localization information that compensates for the absence of bounding box annotations. For fully supervised images, the CAM branch benefits from the precise annotations and generates higher-quality activation maps.

### 5. Hybrid-Supervised Cascade Module

The Hybrid-Supervised Cascade Module builds upon the Cascade R-CNN architecture but adapts it for hybrid supervision through a series of specialized detection heads. Each cascade stage contains:

1. **Standard RCNN Head**: Performs bounding box regression and classification using standard detection techniques.

2. **Multiple Instance Detection (MID) Head**: An auxiliary component that leverages image-level labels to enhance classification learning, especially for weakly supervised images.

The cascade structure progressively refines bounding box predictions through sequential stages with increasing IoU thresholds:

```
Stage 1: IoU threshold = 0.5
Stage 2: IoU threshold = 0.6
Stage 3: IoU threshold = 0.7
```

For fully supervised images, all components of the cascade module are trained with complete supervision. For weakly supervised images, only the classification aspects are trained using image-level labels through the MID head.

The MID head implements a multiple instance learning approach where:
- Each image is treated as a bag of instances (region proposals)
- For a positive class (present in the image), at least one proposal should have a high score
- For negative classes (absent from the image), all proposals should have low scores

This is formulated using a max-pooling operation over proposals:

```
P(y_c = 1 | I) = max_i P(y_c = 1 | r_i)
```

Where:
- P(y_c = 1 | I) is the probability of class c being present in image I
- P(y_c = 1 | r_i) is the probability of class c for region proposal r_i

### 6. Training Process

EHSOD is trained end-to-end with a multi-task loss function that aggregates losses from different components:

```
L_total = L_RPN + L_CAM + ∑_i L_HEAD-i
```

Where:
- L_RPN is the standard RPN loss (classification + regression)
- L_CAM includes CAM segmentation and classification losses
- L_HEAD-i includes proposal classification, box regression, and MID losses for cascade stage i

The training process dynamically adapts to the available supervision:
- For fully supervised images, all loss components are active
- For weakly supervised images, only classification-related losses are used

Key training details:
- Backbone: ResNet-50 or ResNet-101 with Feature Pyramid Network
- Optimizer: SGD with momentum 0.9, weight decay 0.0001
- Learning rate: 0.02 with step decay
- Batch size: 16 images (8 fully supervised, 8 weakly supervised)
- Data augmentation: Random horizontal flipping, color jittering

### 7. Experimental Results

EHSOD demonstrates impressive performance across multiple standard object detection benchmarks. The system was evaluated on PASCAL VOC and MS-COCO datasets under various settings of hybrid supervision.

On PASCAL VOC, EHSOD achieves 75.3% mAP using only 30% fully annotated data, compared to 76.1% mAP for fully supervised detection with 100% annotations. This represents a marginal performance drop of only 0.8% despite using 70% fewer bounding box annotations.

On MS-COCO, which features more complex scenes with multiple small objects, EHSOD achieves 37.5% mAP using 30% fully annotated data, compared to 40.2% mAP for 100% fully supervised training.

Ablation studies confirm the effectiveness of each component:
- CAM-RPN improves mAP by 2.1% over standard RPN
- Cascade structure provides a 1.8% mAP gain over single-stage detection
- MID head contributes 1.5% mAP improvement for weakly supervised images

### 8. Advantages Over Previous Approaches

EHSOD offers several significant advantages over existing hybrid-supervised and weakly-supervised detection methods:

1. **End-to-End Training**: Unlike iterative approaches that require multiple training phases, EHSOD integrates all components into a single end-to-end framework, simplifying training and deployment.

2. **Reduced Hyperparameter Sensitivity**: The system eliminates the need for careful tuning of pseudo-labeling thresholds and confidence scores that plague iterative methods.

3. **Improved Proposal Quality**: The CAM-RPN module generates higher-quality proposals for weakly supervised images by leveraging class activation information.

4. **Progressive Refinement**: The cascade structure enables gradual improvement of detection results rather than relying on a single detection stage.

5. **Scalability**: EHSOD shows consistent performance gains as more fully annotated data becomes available, making it adaptable to different annotation budgets.

Compared to other HSOD methods like BAOD and PCL, EHSOD demonstrates superior performance across all evaluation metrics and annotation ratios. For example, with 30% fully annotated data on PASCAL VOC, EHSOD achieves 75.3% mAP compared to 68.7% for BAOD and 65.2% for PCL.

### 9. Conclusion

EHSOD presents a practical solution to the object detection annotation bottleneck by effectively leveraging a small amount of fully annotated data alongside a larger set of weakly annotated images. The end-to-end architecture with CAM-guided proposals and cascade refinement enables robust detection performance with significantly reduced annotation requirements.

Key contributions of EHSOD include:

1. A novel end-to-end hybrid-supervised detection framework that eliminates the need for iterative pseudo-labeling
2. The CAM-RPN module that improves region proposal quality for weakly supervised images
3. A hybrid-supervised cascade module that progressively refines detection results
4. State-of-the-art performance on standard benchmarks with reduced annotation requirements

These advances make object detection more accessible for applications where extensive annotation is impractical, and point toward future research directions in reducing supervision requirements while maintaining high performance in computer vision tasks.
