# Eureka: Human-Level Reward Design via Coding Large Language Models

> [!summary] Summary
> EUREKA, developed by NVIDIA and academic partners, is an algorithm that leverages Large Language Models to automatically design executable reward functions for reinforcement learning agents. It successfully generates human-level reward code that outperforms manually engineered rewards across various robotic tasks, including complex dexterous manipulation like pen spinning, significantly reducing the bottleneck of reward engineering.

## Problem

- Manually designing effective reward functions for reinforcement learning (RL) is time-consuming, prone to sub-optimality, and a major bottleneck in RL research.
- Traditional methods like Inverse Reinforcement Learning (IRL) require expensive expert demonstrations and produce non-interpretable reward functions.
- While Large Language Models (LLMs) excel at high-level planning, they struggle to translate these plans into precise, low-level control policies for complex motor skills.

## Method

- EUREKA leverages a coding LLM (e.g., GPT-4) to generate free-form, executable Python reward code directly from environment source code and a natural language task description.
- It employs an evolutionary search where the LLM iteratively refines reward candidates based on their performance, using GPU-accelerated RL simulations for rapid evaluation.
- A "reward reflection" mechanism provides automated, fine-grained textual feedback to the LLM on individual reward component contributions and policy training dynamics, enabling targeted code mutations.

## Results

- EUREKA autonomously generated reward functions that outperformed expert human-engineered rewards on **83%** of 29 diverse RL tasks, achieving an average normalized improvement of **52%**.
- It enabled the acquisition of multi-cycle dexterous pen spinning on a simulated anthropomorphic hand, a complex task previously considered unfeasible with manual reward engineering.
- EUREKA significantly outperformed other LLM-based reward design methods like L2R due to its ability to generate free-form, executable reward code and its iterative refinement process.

## Takeaways

> [!tip] Key Insights
> - Integrating automated feedback through "reward reflection" is crucial for LLMs to effectively refine reward functions, enabling targeted and intelligent code modifications.
> - Large Language Models can autonomously discover novel reward functions that diverge from human intuition yet lead to superior performance.
> - Combining LLM-driven code generation with an evolutionary search and high-speed simulation provides a powerful framework for tackling complex, open-ended problems like reward design in RL.
