# Remember the Decision, Not the Description: A Rate-Distortion Framework for Agent Memory

> [!summary] Summary
> DeMem treats bounded agent memory as decision-centric rate-distortion: histories may share one of K runtime slots only when they admit a common near-optimal action. The paper derives an exact forgetting boundary, covering/packing bounds, and NP-hardness, then builds an online learner that splits slots only on statistically certified decision conflict, with near-minimax regret. It scores 0.911/0.920 overall on LoCoMo versus 0.888/0.906 for the best baseline.

## Problem

- Existing agent memory organizes experience by descriptive criteria - semantic relevance, salience, recency, summary fidelity - which do not capture memory's actual purpose: supporting decisions.
- Descriptive similarity poorly predicts evidence compatibility on LoCoMo (Spearman 0.103, AUC 0.548), so retrieval-based memory recovers only 66% of gold evidence under matched budget.
- Prior state-abstraction and bisimulation theory compresses environment states or dynamics for planning, not interaction histories into bounded runtime memory states with decision-loss guarantees.

## Method

- Decision rate-distortion formulation: a K-state query-aware encoder plus decision rule, with distortion measured as lost decision value, yielding an exact forgetting boundary and covering/packing complexity measures.
- DeMem online learner builds cannot-link edges from confidence-bound incompatibility certificates, then greedy graph coloring produces a feasible K-slot partition, frozen per epoch with cluster-level UCB.
- Certification exploration samples each context-action pair to a threshold before trusting cluster-level UCB, separating certifiable positive-margin conflicts from residual compression error in the regret decomposition.

## Results

- On LoCoMo, DeMem reaches 0.911 overall with GPT-4o-mini and 0.920 with GPT-4.1-mini, above Mnemis (0.888/0.906) and EMem-G (0.737/0.812), with the largest gains on Temporal and Open Domain.
- Certified splits fire on only 4.6% of routing events at 85% precision and 63% recall; ablations drop overall judge score from 91.1% to 78.4% without certified split and 53.7% with random split.
- DeMem routing recovers 83% of gold evidence versus 63-66% for cosine/BM25 retrieval (oracle 89%); 85.1% of baseline failures trace to evidence miss or dilution.

## Takeaways

> [!tip] Key Insights
> - Memory budget should be spent on distinctions that change the optimal action, not on descriptive fidelity; two histories merge safely iff they share a near-optimal action.
> - Conservative refinement wins: splitting only on statistically certified conflict beats heuristic, aggressive, or random splitting, and most context pairs turn out decision-compatible.
> - Optimal partitioning is NP-complete, so practical systems need certified greedy approximations; the framework is a decision layer complementing, not replacing, descriptive memory stores.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Large Language Model (LLM) agents are increasingly deployed in long-horizon interaction scenarios, requiring them to utilize information accumulated over extended periods. However, the effective management of runtime memory poses a significant bottleneck for these agents. Existing memory mechanisms, such as retrieval-augmented generation, operating-system-style memory, and graph-structured systems, typically organize past experiences based on descriptive attributes like semantic relevance, salience, recency, or summary fidelity.

This research identifies a gap in these existing approaches: descriptive properties do not directly align with the downstream purpose of memory, which is to support effective decision-making under strict runtime budgets. The paper empirically demonstrates this misalignment on the LoCoMo benchmark, where descriptive similarity is a weak predictor of evidence compatibility (Spearman correlation ρ = 0.103, AUC = 0.548). Current methods often fail to recover critical evidence due to this discrepancy, suggesting that what an agent remembers should be defined by its effect on decision quality rather than its descriptive accuracy.

The work builds upon and differentiates itself from several related research areas:
- **State abstraction and decision-preserving compression:** Prior work in sequential decision-making, including model minimization and bisimulation metrics, focuses on abstracting environment states or dynamics for planning. This paper, in contrast, specifically addresses the compression of *interaction histories* into a limited set of runtime memory states, with the objective of preserving decision quality.
- **Task-driven information bottleneck:** Concepts advocating the preservation of only task-relevant information for downstream decisions are related. This paper specializes this perspective to the memory bottleneck within LLM systems, proposing a formal framework.
- **Control under bounded internal state:** Research on finite-state controllers for partially observable settings examines agents operating with internal state constraints. This work contributes concrete formal tools—an exact forgetting boundary, a memory-distortion frontier, and finite-sample regret guarantees—tailored for the agent memory context.
- **LLM agent memory systems:** A large body of work focuses on developing diverse external and persistent memory mechanisms (e.g., RAG, MemGPT, graph-based memories, learned memory control). This paper offers a complementary perspective by characterizing the fundamental decision loss incurred by bounded memory states and establishing criteria for when histories can be safely merged, rather than proposing a new memory architecture type *per se*.

By framing memory as a decision-centric compression problem, the authors aim to provide a foundational understanding of optimal memory usage for agents, shifting the focus from descriptive accuracy to actionable utility.

### 2. Key Objectives and Motivation

The primary motivation for this research stems from the observation that while large language model (LLM) agents are increasingly applied to tasks requiring long interaction horizons, their performance is constrained by limitations in runtime memory. Existing memory management strategies for LLM agents predominantly rely on descriptive criteria—such as semantic relevance, salience, or summarization quality—to decide what information to store, retrieve, or compress. The authors contend that these descriptive properties do not inherently align with the ultimate purpose of an agent's memory: to support effective decision-making under a constrained computational budget.

The core principle motivating this work is that memory is valuable to an agent not for its ability to faithfully reconstruct the past, but for its capacity to preserve distinctions between histories that are critical for making good decisions. This perspective leads to framing memory management as a *decision-centric rate-distortion problem*. In this framework, the quality of memory is quantified by the loss in achievable decision quality that results from memory compression.

This overarching motivation translates into three specific objectives and contributions:

1. **To formalize when histories can be safely merged without degrading downstream decision quality.**
 - **Contribution:** The research develops a decision-centric theory of "forgetting." This theory provides an *exact forgetting boundary*, delineating conditions under which histories can share a memory state without incurring significant decision conflict. It also derives a *memory-distortion frontier*, which characterizes the optimal trade-off between the allocated memory budget and the maximum achievable decision quality. The underlying mechanism is based on the existence of a common $\epsilon$-optimal action for all histories within a merged memory state.

2. **To develop an online learning mechanism for decision-aware memory management.**
 - **Contribution:** The paper introduces DeMem (Decision-aware Memory), an online memory learner designed to maintain a fixed number of runtime memory states (K slots). DeMem refines its memory partition only when empirical data provide certified evidence that merging certain contexts would lead to a decision conflict. The algorithm is accompanied by theoretical regret guarantees that approach the minimax lower bound, indicating its statistical efficiency. The computational hardness of finding a globally optimal memory partition (proven in Theorem 3) further motivates this online, data-driven approach.

3. **To demonstrate the practical efficacy of this decision-centric memory principle in agent systems.**
 - **Contribution:** DeMem is instantiated as a practical K-slot agent memory system incorporating slot routing and certified refinement. This system is empirically evaluated on both controlled synthetic diagnostics and long-horizon conversational benchmarks. The objective is to determine if organizing memory around decision-relevant distinctions, rather than descriptive ones, leads to consistent performance improvements under identical runtime memory constraints.

Collectively, these objectives aim to establish a principled approach to agent memory design, encapsulated by the maxim: "remember the decision, not the description."

### 3. Methodology and Approach

The methodology of this research integrates theoretical foundations with an algorithmic instantiation and empirical validation. It begins by formalizing a memory-constrained contextual decision problem, derives fundamental limits, and then develops an online learning algorithm to operate within these limits.

#### 3.1. Problem Setup and Fundamental Limits (Section 3)

1. **Memory-Constrained Contextual Decision Model:**
 - The problem is modeled as a contextual bandit where, at each round $t$, a context $x_t = (h_t, q_t)$ (dialogue history and query) is drawn from an unknown distribution. The agent chooses an action $A_t$ and observes a reward $R_t$. The goal is to minimize regret against an oracle that always chooses the optimal action $a^\star(x)$.
 - A strict runtime memory constraint is imposed: the agent's policy $A_t = \pi_t(M_t, Q_t)$ can only access history $H_t$ through one of $K$ internal runtime memory states, $M_t = g_t(H_t, Q_t) \in [K]$. The budget is on these $K$ runtime decision states.

2. **Decision Distortion Under Memory:**
 - For a fixed query $q$, the suboptimality gap for an action $a$ at history $h$ is defined as $\Delta_q(h, a) = \mu^\star_q(h) - \mu_q(h, a)$, representing the loss from not taking the optimal action.
 - The decision distortion $d_q(h, m; \pi_q)$ measures the quality loss when history $h$ is mapped to memory state $m$, and the policy plays action $\pi_q(m)$.
 - The *decision rate-distortion frontier* $\epsilon^\star_\infty(K; q)$ is defined as the minimum possible worst-case decision loss incurred by compressing histories into $K$ memory states for query $q$.

3. **Exact Forgetting Boundary (Theorem 1):**
 - This theorem states that a set of histories $C$ can share a single memory state (with worst-case distortion at most $\epsilon$) if and only if there exists a common action $a \in A$ such that $\Delta_q(h, a) \leq \epsilon$ for all $h \in C$. This means compatibility is purely decision-theoretic, not descriptive.
 - A *pairwise decision distance* $d^\text{dec}_q(h, h')$ is introduced, quantifying the minimum $\epsilon$ for which $h$ and $h'$ can share a state. The *cluster decision radius* $\rho^\text{dec}_q(C)$ is also defined.

4. **Decision Covering and Packing Bounds (Theorem 2):**
 - These bounds establish relationships between the number of memory states $K$ and the achievable distortion $\epsilon$. The decision covering number $N^\text{dec}_\text{cov}(\epsilon; q)$ is the fewest states required to achieve distortion $\epsilon$. The decision packing number $N^\text{dec}_\text{pack}(\epsilon; q)$ is the maximum number of mutually decision-incompatible histories. These provide theoretical limits on memory efficiency.

5. **Computational Hardness of Optimal Memory (Theorem 3):**
 - The paper proves that finding an optimal $K$-state partition to minimize $\epsilon^\star_\infty(K)$ is NP-complete. This theoretical result justifies the need for efficient, approximate online learning algorithms.

#### 3.2. Online Learning with Certified Memory Splits (DeMem - Section 4)

Given the computational hardness and unknown reward function, the authors propose DeMem, an online memory learner built on the principle of splitting memory states *only when data certify a decision conflict*.

1. **Incompatibility Certificates:**
 - DeMem maintains empirical means ($\hat{\mu}_t(x, a)$) and counts ($n_t(x, a)$) for context-action pairs. These are used to construct lower confidence bounds on the pairwise decision distance, $d_t(x, x')$. If $d_t(x, x') > \epsilon$, it serves as a *one-sided cannot-link relation*, statistically certifying that $x$ and $x'$ cannot safely share a memory state (Lemma 1).

2. **Certification Exploration:**
 - To ensure certificates are statistically robust, DeMem employs a certification exploration strategy. Each observed context-action pair is sampled a minimum number of times, $B_t(\gamma)$, before relying on cluster-level Upper Confidence Bound (UCB) for exploitation. This guarantees that sufficient data is collected to detect genuine conflicts.

3. **Budgeted Encoder and Greedy Partitioning (Algorithm 2):**
 - At the start of each epoch, DeMem constructs a *cannot-link graph* where an edge $(x, x')$ exists if their certified decision distance exceeds a threshold $\alpha$.
 - A polynomial-time *greedy coloring subroutine* is used to obtain a feasible $K$-slot partition $P_e$ for this graph. This greedy approach ensures the $K$-slot budget is respected.
 - The *certified realized compression price* $\epsilon^\text{cert}_e = \max_{C \in P_e} \rho_t(C)$ (the maximum certified cluster radius in the partition) is computed, which upper-bounds the true cluster distortion.

4. **DeMem Algorithm (Algorithm 3):**
 - DeMem operates in epochs. Within an epoch, the $K$-slot partition $P_e$ is frozen.
 - For incoming contexts $x_t$, a query-aware encoder $g^{(e)}(x_t)$ maps it to a memory slot. New contexts are assigned using a deterministic fallback router $\phi_e(x)$ that minimizes certified radius upon insertion.
 - Actions are chosen using either certification exploration (if `n(x,a)` is low) or a cluster-level UCB policy.
 - Reward statistics are updated, and new cannot-link edges are identified to refine the partition for the next epoch.

5. **Regret Guarantees (Theorems 4 & 5):**
 - Theorem 4 provides an upper bound on DeMem's cumulative regret, decomposed into three terms: the realized compression error ($T \cdot O(\bar{\epsilon}^\text{cert}_T)$), statistical learning over $K$ memory states ($\tilde{O}(\sqrt{AKT})$), and context-level certification exploration ($O(AN_T B_T(\gamma))$).
 - Theorem 5 establishes a minimax lower bound, showing that DeMem's statistical learning term is near-optimal.

#### 3.3. Agent Memory Instantiation and Theory-Implementation Alignment (Appendix D)

1. **System Components:** The abstract model's components are mapped to a practical agent system. The history $H_t$ plus query $Q_t$ forms the context $x_t$. The encoder $g(H_t, Q_t)$ becomes a query-aware router $e_\theta(x_t)$ that selects one of $K$ memory slots. Each slot $S_k$ stores a bounded textual summary (e.g., up to $L$ characters). The policy $\pi_t(M_t, Q_t)$ is realized by an LLM generating an answer conditioned on the selected slot content and query. Rewards are provided by held-out LLM judges.

2. **Certified Split as a Memory Operation (Algorithm 4):** The theoretical cannot-link criterion is instantiated empirically. A split is triggered if a pair of contexts routed to the same slot are *certified to prefer conflicting actions* with sufficient confidence. This involves comparing reward estimates for candidate actions and their confidence intervals. If the number of active slots is less than $K$, a new slot is created and the original slot is split; otherwise, the split is suppressed (capacity-saturated thresholding).

3. **Approximation Bridge (Proposition 5):** This proposition formally relates the performance of the implemented slot-based agent to the theoretical optimal compression. It decomposes the agent's average distortion into the irreducible compression term $\epsilon^\star_\infty(K)$, a routing error $\eta_\text{route}$, and a state-realization error $\eta_\text{read}$. This allows for analysis of how implementation choices contribute to overall performance.

### 4. Main Findings and Results

The research presents both synthetic and benchmark results to validate its decision-centric memory framework and the DeMem algorithm.

#### 4.1. Synthetic Results (Figure 2)

On a Decoupled Bandit environment designed to explicitly misalign descriptive features with optimal decision identities:
- **Cumulative Regret:** DeMem consistently demonstrated the lowest cumulative regret among all budgeted memory methods, approaching the unconstrained Oracle baseline more closely than description-aware baselines (CLUB-style, Feature-KMeans, Feature-RAG, $\epsilon$-greedy Feature, Random Partition).
- **Memory-Distortion Tradeoff:** DeMem exhibited a more favorable trade-off curve between the memory budget (K slots) and cumulative regret, indicating superior efficiency in utilizing limited memory to minimize decision loss.
- **Mismatch Sensitivity:** As the severity of mismatch ($\alpha$) between descriptive and decision similarity increased, DeMem's performance advantage over description-aware baselines widened. This supports the hypothesis that decision-centric memory is particularly beneficial when descriptive cues are unreliable for action selection.
- **Induced Partition Distortion (Appendix E.1.1, Figure 4):** Direct measurement of the learned partitions confirmed that DeMem consistently yielded the lowest-distortion partitions, and downstream regret was broadly monotone with this induced partition distortion, validating the theoretical mechanism.

#### 4.2. Main Results on LoCoMo and LongMemEval (Table 1, Table 4)

Evaluations on long-horizon conversational memory benchmarks (LoCoMo and LongMemEval) with GPT-4o-mini and GPT-4.1-mini backbones showed:
- **Overall Superiority:** DeMem achieved the highest mean overall scores on both LoCoMo (0.911 for GPT-4o-mini, 0.920 for GPT-4.1-mini) and LongMemEval (0.853 for GPT-4o-mini, 0.896 for GPT-4.1-mini) compared to a range of baselines (FullContext, RAG, LangMem, Mem0, Zep, Nemori, EMem-G, Mnemis).
- **Category-Specific Gains:** The performance gains were particularly pronounced on categories requiring complex memory management, such as Temporal and Open Domain questions on LoCoMo, and cross-session integration tasks (MS, TR) on LongMemEval. These are scenarios where preserving decision-relevant distinctions across disparate interactions is critical.
- **Resource Efficiency:** DeMem demonstrated a favorable accuracy-resource frontier (Figure 3c,d), indicating that its gains stemmed from more efficient utilization of the fixed memory budget rather than increased computational or memory resources.
- **Generalizability:** The performance advantage of DeMem was also observed when evaluated with the Llama-3.1-70B open-weight backbone (Appendix E.7, Table 6), suggesting the principle's broad applicability.

#### 4.3. Results on MemoryArena (Appendix E.4, Table 5)

On the MemoryArena benchmark, which involves interdependent multi-session agentic tasks:
- DeMem achieved the highest average success rate (0.24) across the five SR-based categories (Bundled Web Shopping, Group Travel Planning, Progressive Web Search, Math, Physics), outperforming Long Context, Mem0, and various RAG systems.
- The method showed consistent benefits in tasks requiring information persistence across sessions, reinforcing its ability to retain decision-relevant information for later use.

#### 4.4. Ablation and Robustness (Figure 3b, Appendices D.10, E.10, E.11, E.16, E.17)

- **Component Contribution:** Ablation studies confirmed that all core components of DeMem (certified splitting, decision-aware routing, and specific memory representations) contribute to its performance. Removing certified splitting, in particular, led to substantial performance degradation, validating its importance.
- **Split Mechanism Accuracy:** Certified splits were found to be selective, triggering on only 4.6% of LoCoMo routing events, and accurate, with 85% precision against gold annotations of evidence conflict (Appendix E.11). This indicates that splits are driven by genuine decision conflicts rather than aggressive partitioning.
- **Approximation Bridge Validation (Appendix E.10):** Empirical measurements on an annotated LoCoMo subset supported the theoretical decomposition (Proposition 5), showing that observed distortion was largely accounted for by the sum of compression, routing, and state-realization errors. Routing error was identified as the largest implementation-side contributor to distortion.
- **DeMem-Core Performance (Appendix D.10):** A theory-faithful DeMem-Core variant, retaining only slot structure, routing, and certified refinement, achieved a high overall score (90.8) on LoCoMo, demonstrating that much of the gain originates from the memory organization principle itself.
- **Reward-Channel Robustness (Appendix E.16):** DeMem exhibited graceful degradation under corrupted feedback channels, indicating that its refinement mechanism relies on aggregate feedback reliability rather than perfectly clean observations.
- **Comparison with Adaptive Memory Baselines (Appendix E.17):** DeMem outperformed feedback-aware and memory-action baselines (MemSkill, MemAct) on LoCoMo, indicating the strength of decision-aware certified refinement against learning-based memory policies.

#### 4.5. Prevalence of Description–Evidence Mismatch (Appendix E.13)

Detailed analysis on LoCoMo instances confirmed that descriptive similarity is a weak predictor of evidence compatibility (Spearman $\rho$ = 0.103, AUC = 0.548). This mismatch translated into significant gaps in gold-evidence recall for description-based methods (63-66% vs. 83% for DeMem). Crucially, 85% of description-based failures were attributed to evidence miss or dilution, establishing the practical impact of this mismatch.

#### 4.6. Human–LLM Judge Agreement (Appendix E.14)

A human agreement study on LoCoMo confirmed that the LLM-as-judge protocol provided results consistent with human majority vote ($\kappa = 0.79$, 91.3% agreement), supporting the reliability of the evaluation metrics.

### 5. Significance and Potential Impact

This research introduces a decision-centric framework for budgeted agent memory, reorienting the fundamental understanding and practical implementation of memory management for LLM agents.

**Theoretical Significance:**
- **Novel Framework:** The work provides a formal rate-distortion framework that quantifies memory quality by its impact on downstream decision quality, rather than traditional descriptive fidelity metrics. This shifts the foundational perspective on agent memory.
- **Fundamental Limits:** The derivation of an exact forgetting boundary and a memory-distortion frontier offers theoretical tools to characterize the inherent limits of budgeted memory in terms of achievable decision quality. These are, to the authors' knowledge, novel characterizations in this specific context.
- **Computational Irreducibility:** The proof of NP-completeness for optimal memory allocation (Theorem 3) provides a structural insight into the inherent complexity of the problem, guiding the design of pragmatic, online learning algorithms like DeMem.
- **Guaranteed Performance:** The theoretical regret guarantees for DeMem, demonstrating near-minimax performance, establish a strong benchmark for future adaptive memory systems.

**Practical Significance:**
- **Improved Agent Performance:** Empirically, DeMem consistently improves agent performance across diverse long-horizon tasks, including conversational question-answering and complex agentic tasks, under fixed memory budgets. This validates the practical utility of the decision-centric principle.
- **Efficient Resource Utilization:** The method's ability to achieve better performance without increasing memory or computational resources suggests a more efficient use of limited agent capabilities.
- **Modular Design:** The decision-centric selection criterion is shown to be modular and can be integrated into existing memory architectures, offering a pathway to enhance their decision-making capabilities without requiring a complete system overhaul.
- **Addressing a Critical Bottleneck:** By addressing the misalignment between descriptive memory and decision-making needs, this work tackles a critical bottleneck in the scalability and reliability of LLM agents operating in complex, long-term environments.

**Broader Impact:**
- **Informed Agent Design:** This research encourages a shift in how the AI community evaluates and designs agent memory, promoting a focus on "what matters for action" rather than merely "what is remembered." This perspective can lead to more robust, purposeful, and efficient AI systems.
- **High-Stakes Applications:** The ability to ensure that critical, decision-relevant information is retained is particularly important for high-stakes applications such as clinical decision support, legal analysis, personalized education, and multi-session negotiations. In these domains, discarding subtle but action-critical distinctions in favor of vivid but irrelevant details can have significant negative consequences.
- **Ethical Considerations:** While the paper's primary focus is on technical efficiency, the concept of "forgetting what doesn't matter for decisions" also implicitly touches upon ethical considerations regarding information retention and privacy. Pairing this memory optimization framework with application-specific retention policies and transparency measures can help align technical advancements with broader societal values and user control requirements.

Overall, this work provides both a principled theoretical foundation and a practical algorithmic solution for building more effective and efficient memory systems for language agents, with implications for a wide range of applications.
