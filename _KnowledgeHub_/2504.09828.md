# FATE: A Prompt-Tuning-Based Semi-Supervised Learning Framework for Extremely Limited Labeled Data

> [!summary] Summary
> The FATE framework addresses semi-supervised learning with extremely limited labeled data by introducing a two-stage prompt-tuning approach for pre-trained models. It achieves an average accuracy improvement of 33.74% over state-of-the-art SSL methods, performing robustly even with just one labeled sample per class.

## Problem

- Existing semi-supervised learning (SSL) methods underperform when labeled data is extremely limited (e.g., 1-4 samples per class) due to insufficient discriminative features.
- Generating reliable pseudo-labels for unlabeled data is difficult in label-scarce scenarios, hindering the effectiveness of traditional SSL algorithms.
- Balancing pre-trained knowledge with task-specific adaptations is challenging when only a handful of labeled examples are available, leading to poor generalization or overfitting.

## Method

- ==FATE (Firstly Adapt, Then catEgorize)== introduces a two-stage semi-supervised learning framework built on pre-trained models and parameter-efficient prompt tuning.
- The first stage uses unsupervised learning with ==Distribution-adaptive Prompts (DP)== to adapt the pre-trained model to the downstream data's feature distribution.
- The second stage refines the model with limited labeled data using ==Classification Prompts (CP)== and an adapted SSL method like FixMatch, keeping the pre-trained model parameters frozen.

## Results

- FATE achieved an average accuracy improvement of **33.74%** across **seven** visual classification benchmarks compared to state-of-the-art SSL methods.
- The framework maintained considerable accuracy with just **one** labeled sample per class, a scenario where other methods failed significantly.
- FATE consistently outperformed CLIP's zero-shot baseline and few-shot learning methods across diverse datasets, demonstrating robust performance with varying numbers of labeled samples.

## Takeaways

> [!tip] Key Insights
> - The two-stage prompt tuning approach, with separate adaptation (DP) and classification (CP) prompts, effectively leverages pre-trained models and unlabeled data in extremely label-scarce settings.
> - Parameter-efficient prompt tuning prevents overfitting to very limited labeled data while allowing the model to adapt to the downstream task's feature distribution.
> - Unsupervised adaptation in the first stage helps the model to better understand the feature space of the downstream task, significantly improving performance when classification prompts are introduced in the second stage.
