# FATE: A Prompt-Tuning-Based Semi-Supervised Learning Framework for Extremely Limited Labeled Data

> [!summary] Summary
> The FATE framework addresses semi-supervised learning with extremely limited labeled data by introducing a two-stage prompt-tuning approach for pre-trained models. It achieves an average accuracy improvement of 33.74% over state-of-the-art SSL methods, performing robustly even with just one labeled sample per class.

## Problem

- Existing semi-supervised learning (SSL) methods underperform when labeled data is extremely limited (e.g., 1-4 samples per class) due to insufficient discriminative features.
- Generating reliable pseudo-labels for unlabeled data is difficult in label-scarce scenarios, hindering the effectiveness of traditional SSL algorithms.
- Balancing pre-trained knowledge with task-specific adaptations is challenging when only a handful of labeled examples are available, leading to poor generalization or overfitting.

## Method

- ==FATE (Firstly Adapt, Then catEgorize)== introduces a two-stage semi-supervised learning framework built on pre-trained models and parameter-efficient prompt tuning.
- The first stage uses unsupervised learning with ==Distribution-adaptive Prompts (DP)== to adapt the pre-trained model to the downstream data's feature distribution.
- The second stage refines the model with limited labeled data using ==Classification Prompts (CP)== and an adapted SSL method like FixMatch, keeping the pre-trained model parameters frozen.

## Results

- FATE achieved an average accuracy improvement of **33.74%** across **seven** visual classification benchmarks compared to state-of-the-art SSL methods.
- The framework maintained considerable accuracy with just **one** labeled sample per class, a scenario where other methods failed significantly.
- FATE consistently outperformed CLIP's zero-shot baseline and few-shot learning methods across diverse datasets, demonstrating robust performance with varying numbers of labeled samples.

## Takeaways

> [!tip] Key Insights
> - The two-stage prompt tuning approach, with separate adaptation (DP) and classification (CP) prompts, effectively leverages pre-trained models and unlabeled data in extremely label-scarce settings.
> - Parameter-efficient prompt tuning prevents overfitting to very limited labeled data while allowing the model to adapt to the downstream task's feature distribution.
> - Unsupervised adaptation in the first stage helps the model to better understand the feature space of the downstream task, significantly improving performance when classification prompts are introduced in the second stage.

## Detailed Report

### 1. Introduction

In many real-world machine learning applications, obtaining labeled data is expensive, time-consuming, or even impossible in sufficient quantities. Semi-supervised learning (SSL) has emerged as a promising approach to address this challenge by leveraging both labeled and unlabeled data. However, existing SSL methods often struggle when the labeled data is extremely limited—a common scenario in practice.

The paper "FATE: A Prompt-Tuning-Based Semi-Supervised Learning Framework for Extremely Limited Labeled Data" presents a novel approach to this problem by combining the strengths of pre-trained models, parameter-efficient fine-tuning (PEFT), and SSL techniques.

### 2. Problem Statement

Traditional SSL methods typically assume that a sufficient amount of labeled data is available to establish a reasonable baseline model. This assumption fails in extremely label-scarce scenarios, such as when only a few labeled examples per class are available (e.g., 1-4 samples per class). In these cases, existing SSL approaches tend to underperform due to:

1. The inability to learn discriminative features from limited labeled data
2. Difficulties in generating reliable pseudo-labels for unlabeled data
3. The challenge of properly balancing the pre-trained knowledge and task-specific adaptations

The FATE framework specifically targets these challenges by leveraging the power of pre-trained models and introducing a novel two-stage prompt tuning approach.

### 3. The FATE Framework

FATE (Firstly Adapt, Then catEgorize) is built on the following key ideas:

1. **Two-stage learning process**: First adapting a pre-trained model to the feature distribution of the downstream data using unsupervised learning, then refining it with limited labeled samples
2. **Parameter-efficient prompt tuning**: Using learnable prompts instead of full fine-tuning to avoid overfitting to limited labeled data
3. **Specialized prompts for different tasks**: Distribution-adaptive Prompts (DP) for adapting to data distribution and Classification Prompts (CP) for classification tasks

The framework is compatible with both Vision Transformer (ViT) architectures and Vision-Language Models (CLIP), making it versatile for different types of visual recognition tasks.

### 4. Two-Stage Learning Process

The FATE framework implements a two-stage learning process:

#### 4.1. Stage One: Adaptation Stage

The first stage focuses on adapting the pre-trained model to the feature distribution of the downstream data using unsupervised learning on unlabeled samples. During this stage:

- A set of Distribution-adaptive Prompts (DP) are learned to help the model recognize the characteristics of the downstream data
- For ViT models, contrastive learning is employed to enable DP to recognize different augmented views of the same sample
- For CLIP models, the zero-shot capability is used to generate pseudo-labels for unlabeled samples, and the top-k samples with the highest predicted logits for each class are used to train the DP

The objective is to guide the pre-trained model to better understand the feature space of the downstream task before attempting classification.

#### 4.2. Stage Two: Classification Stage

The second stage focuses on refining the model with limited labeled samples using an SSL method. During this stage:

- A new set of Classification Prompts (CP) are learned while the DP from the first stage are kept frozen
- The FixMatch algorithm is adapted to work with the pre-trained model architecture
- Both labeled and unlabeled data are utilized to train the CP
- The pre-trained model parameters remain frozen throughout both stages

This approach allows the model to leverage the knowledge learned in the adaptation stage while focusing on classification boundaries in the second stage.

### 5. Implementation Details

The FATE framework has different implementations depending on the type of pre-trained model used:

#### 5.1. For Vision Transformers (ViT)

1. **Prompt Structure**: The prompts are implemented as additional learnable tokens prepended to the input sequence
2. **Adaptation Stage**: Contrastive learning is used where different augmented views of the same image are pushed to have similar representations
3. **Classification Stage**: The CP is trained using a modified version of FixMatch, which applies weak augmentation to labeled samples and strong augmentation to unlabeled samples

The loss function in stage one is:

```
L_u = CE Loss(pair-wise similarity)
```

Where CE Loss is the cross-entropy loss and the pair-wise similarity is calculated between embeddings of different augmented views.

In stage two, the loss function combines supervised loss on labeled data and unsupervised loss on unlabeled data:

```
L_s = CE Loss(predicted logits, ground truth)
L_u = CE Loss(predicted logits, pseudo-labels)
```

#### 5.2. For CLIP Models

CLIP consists of an image encoder and a text encoder. The implementation for CLIP:

1. **Stage One**: Uses CLIP's zero-shot capability to select the top-k samples with highest confidence for each class
2. **Prompts Structure**: Learnable parameters are added to the text encoder for CP in stage two
3. **Text Templates**: Uses templates like "A photo of a [CLASS]." to leverage the text-image alignment

### 6. Performance and Results

FATE demonstrates remarkable performance improvements over state-of-the-art SSL methods in extremely label-scarce scenarios:

The key findings include:

1. **Significant Performance Improvement**: FATE achieves an average improvement of 33.74% across seven benchmarks compared to state-of-the-art SSL methods in visual classification tasks using ViT
2. **Strong Performance in Extreme Cases**: With just one labeled sample per class, FATE still achieves considerable accuracy where other methods fail dramatically
3. **Consistent Gains Across Datasets**: The performance gains are consistent across diverse datasets, including CIFAR-100, EuroSAT, Oxford Flowers, Stanford Cars, and SUN397

The experimental results demonstrate that FATE effectively leverages the power of pre-trained models and unlabeled data even when labeled data is extremely scarce.

### 7. Ablation Studies

The authors conducted comprehensive ablation studies to understand the contribution of each component of the FATE framework:

1. **Impact of Distribution-adaptive Prompts (DP) and Classification Prompts (CP)**:
 - Using both DP and CP provides the best performance
 - DP alone improves over the baseline but is not sufficient for optimal performance
 - CP builds upon the foundation laid by DP to further improve classification performance

2. **Feature Visualization**: The feature visualization study demonstrates how FATE helps improve feature clustering:

3. **Effect of Sample Selection in Stage One**:
 - The quality of samples selected for adapting DP in stage one affects the final performance
 - Using the top-k samples with the highest predicted logits from the pre-trained model works well

4. **Performance Across Different Numbers of Labeled Samples**:
 - FATE maintains consistent performance advantages across different numbers of labeled samples per class (1, 2, 4, 8, 16, 32)
 - The relative advantage is most significant when labeled data is extremely limited (1-4 samples per class)

### 8. Comparison with Existing Methods

FATE differs from existing approaches in several important ways:

1. **Compared to Traditional SSL Methods** (FixMatch, MeanTeacher, MixMatch):
 - Traditional SSL methods struggle with extremely limited labeled data
 - FATE's two-stage approach and prompt tuning strategy allow it to perform well even with just one labeled sample per class
 - The gap between FATE and traditional methods grows larger as the number of labeled samples decreases

2. **Compared to Few-Shot Learning Methods** (CoOp, CoCoop, MaPLe):
 - Few-shot learning methods are designed for limited data but don't effectively leverage unlabeled data
 - FATE outperforms these methods by effectively combining the strengths of SSL and prompt tuning
 - The performance gap is particularly pronounced in the one-shot learning scenario

3. **Compared to Standard Fine-Tuning**:
 - Standard fine-tuning with limited labeled data leads to severe overfitting
 - FATE's parameter-efficient prompt tuning approach prevents overfitting while still adapting to the downstream task

### 9. Significance and Impact

The FATE framework makes several significant contributions to the field:

1. **Addressing a Critical Challenge**: FATE tackles the significant limitation of existing SSL methods in extremely label-scarce scenarios, making SSL more applicable to real-world problems.

2. **Novel Integration**: The framework effectively combines the strengths of pre-trained models, prompt tuning, and SSL techniques in a cohesive approach.

3. **Practical Advantages**:
 - **Reduced Labeling Costs**: By effectively leveraging unlabeled data, FATE reduces the need for expensive and time-consuming manual labeling.
 - **Broader Applicability**: FATE makes SSL more accessible to practitioners by providing an effective approach for handling extremely limited labeled data.
 - **Versatility**: The framework is adaptable to different model architectures (ViT and CLIP), increasing its applicability across various vision tasks.

4. **Potential Applications**: FATE could be particularly valuable in domains where labeled data is inherently scarce, such as:
 - Medical imaging for rare conditions
 - Industrial defect detection for uncommon defect types
 - Earth observation for rare environmental events
 - Fine-grained classification tasks with specialized expertise requirements

### 10. Conclusion

The FATE framework represents a significant advancement in semi-supervised learning for scenarios with extremely limited labeled data. By combining the strengths of pre-trained models, parameter-efficient prompt tuning, and SSL techniques in a novel two-stage approach, FATE achieves remarkable performance improvements over existing methods.

The key innovation lies in the specialized prompts (DP and CP) that serve different purposes: adapting to the data distribution and refining classification boundaries. This division of labor, along with the effective use of unlabeled data, enables FATE to perform well even with just one labeled sample per class.

As machine learning continues to extend into domains where labeled data is scarce, frameworks like FATE that can effectively learn from minimal labeled data will become increasingly important. The practical implications of this work include reduced labeling costs, broader applicability of SSL techniques, and improved performance in real-world scenarios with limited labeled data.
