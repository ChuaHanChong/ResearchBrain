# HyperMARL: Adaptive Hypernetworks for Multi-Agent RL

> [!summary] Summary
> HyperMARL introduces an agent-conditioned hypernetwork architecture to address cross-agent gradient interference in shared Multi-Agent Reinforcement Learning (MARL) policies, enabling adaptive cooperation and diverse behaviors without altering standard learning objectives or requiring manual diversity presets. This method achieves performance comparable to No Parameter Sharing (NoPS) in specialized tasks and matches Full Parameter Sharing (FuPS) in homogeneous tasks, supporting up to 30 agents.

## Problem

- No Parameter Sharing (NoPS) approaches facilitate specialized behaviors but incur significant computational overhead and sample inefficiency, especially with many agents.
- Full Parameter Sharing (FuPS) with agent IDs (FuPS+ID) struggles to foster behavioral diversity and specialization due to cross-agent gradient interference from coupling agent IDs and observations.
- Existing methods for promoting diversity in shared MARL policies introduce complexities such as altering learning objectives, requiring manual preset diversity levels, or employing sequential updates.

## Method

- **HyperMARL** utilizes an ==agent-conditioned hypernetwork== architecture, where two hypernetworks generate agent-specific parameters for policies and critics based on an agent context (one-hot ID or learned embedding).
- It explicitly decouples observation-conditioned and agent-conditioned gradients, mitigating cross-agent interference by averaging noise per agent before applying deterministic agent-conditioned transformations.
- Implemented on top of established MARL algorithms like IPPO and MAPPO, HyperMARL functions without altering the standard RL objective, requiring manual diversity presets, or employing sequential updates.

## Results

- In specialized tasks like Dispersion and Navigation, HyperMARL matched NoPS policy performance and achieved comparable behavioral diversity, while FuPS+ID struggled to learn diverse policies.
- HyperMARL's MLP variant demonstrated competitive performance in challenging heterogeneous control tasks like the **17**-agent Humanoid-v2, matching methods with independent actors and sequential updates.
- It achieved comparable final performance to recurrent FuPS in all SMAX environments, demonstrating its ability to converge to homogeneous behaviors when optimal and adaptability to recurrent architectures.

## Takeaways

> [!tip] Key Insights
> - The direct coupling of observation and agent ID inputs within a shared network significantly exacerbates destructive gradient interference, which hinders the emergence of specialized behaviors.
> - An ablation study showed that a FuPS+ID policy conditioned only on agent ID (ignoring observations) outperformed standard FuPS+ID in specialization, demonstrating minimal gradient conflict.
> - Explicitly decoupling observation-conditioned and agent-conditioned gradients via an agent-conditioned hypernetwork enables adaptive behaviors (specialized, homogeneous, or mixed) in shared policies.
