# Playable Environments: Video Manipulation in Space and Time

> [!summary] Summary
> Playable Environments introduces a framework for interactively generating and manipulating 3D videos from a single image, enabling users to control objects, actions, and camera viewpoints. This system integrates 3D scene understanding with multi-object and deformable object handling, achieving improved action correlation and video quality over previous methods.

## Problem

- Prior novel view synthesis methods for dynamic scenes typically lack intuitive user interaction for manipulating scene elements or actions.
- Existing video synthesis approaches often lack explicit camera control, comprehensive multi-object support, and robust 3D environment understanding.
- Previous playable video generation methods were limited to single controllable objects, constrained camera movement, and uniform object appearances.

## Method

- A compositional Neural Radiance Field (NeRF) architecture is developed, extended to model multiple, deformable objects with varying appearances from monocular videos.
- An action module learns discrete actions in an unsupervised manner, and a dynamics network (LSTM) predicts future object states based on user-specified actions and current state.
- A two-phase training procedure optimizes the synthesis module for image reconstruction and the action module using a multi-component loss including a novel 
-MSE and a temporal discriminator to enhance dynamic realism.

## Results

- The method substantially improved action correlation on the Static Tennis dataset, achieving a 
-MSE of **32.8%** and a 
-Acc of **68.1%**, outperforming state-of-the-art baselines.
- Achieved superior video quality on challenging datasets (Tennis, Minecraft), demonstrating a significantly lower Missing Detection Rate (**4.84%** on Tennis) and improved LPIPS/FVD scores.
- Successfully synthesized scenes from novel camera perspectives (LPIPS 0.242, FID 29.2 on Minecraft Camera dataset) and maintained robustness against real-world input noise.

## Takeaways

> [!tip] Key Insights
> - A compositional NeRF design, integrating object-specific MLPs, a ray bending network for deformation, and style embedding layers, effectively handles multi-object, deformable scenes with diverse appearances.
> - Learning camera-relative object movements within the action dynamics network provides intuitive user control over objects, allowing for flexible manipulation akin to video game mechanics.
> - A convolutional feature renderer processes NeRF-generated feature maps to reconstruct sharp images, enhancing robustness to inaccuracies in estimated camera parameters and object localizations.
