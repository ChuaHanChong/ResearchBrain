# Primal-Dual iLQR for GPU-Accelerated Learning and Control in Legged Robots

> [!summary] Summary
> A GPU-accelerated Primal-Dual Iterative Linear Quadratic Regulator (iLQR) solver leverages parallel associative scans to achieve logarithmic computational complexity with prediction horizon length and square-logarithmic complexity with state and control dimensions for optimal control problems in legged robots. This approach demonstrated up to a 700% speedup over CPU-based solvers and enabled real-time centralized control of multiple robots and faster model-based learning.

## Problem

- Model Predictive Control (MPC) for complex robotic systems faces computational intensity, limiting real-time application with long prediction horizons, high-dimensional states, or multi-robot scenarios.
- Traditional DDP and SQP algorithms exhibit computational complexity scaling linearly with horizon length (N) and cubically with state and control dimensions, restricting control frequency and problem scalability.
- Existing GPU acceleration efforts for optimal control often involve partial parallelization, approximations, or focus on batching multiple problems, failing to fully exploit GPU capabilities within a single Optimal Control Problem (OCP).

## Method

- An SQP method is introduced that uses a primal-dual iLQR solver to efficiently solve the underlying equality-constrained Quadratic Program (QP).
- A key innovation is the integration of a parallel associative scan to solve the Karush-Kuhn-Tucker (KKT) system in both the backward and forward passes, achieving logarithmic computational complexity.
- The entire framework is implemented in JAX, allowing for seamless GPU integration, automatic differentiation, a parallel line search, and efficient handling of equality and inequality constraints through multiple shooting and barrier functions.

## Results

- The solver achieved up to a **700%** speedup for Single Rigid Body Dynamics (SRBD)-MPC and **60%** for Whole Body (WB)-MPC compared to state-of-the-art CPU-based solvers, particularly for longer prediction horizons.
- It demonstrated real-time centralized control for multiple robots, managing up to 16 SRBD robots (25 ms per solve) and four WB robots (20 Hz) simultaneously, enabling complex coordinated behaviors like collision avoidance.
- The JAX-based implementation facilitated massive parallelization for model-based learning, achieving real-time factors of up to **570x** for SRBD-MPC and **75x** for WB-MPC when processing 4096 environments concurrently.

## Takeaways

> [!tip] Key Insights
> - Associative scan operations can be effectively adapted to dynamic programming problems, fundamentally reducing computational complexity from polynomial to logarithmic or polylogarithmic for optimal control on parallel architectures like GPUs.
> - A primal-dual formulation combined with a multiple shooting approach enables exact, full temporal, state, and control dimension parallelization on GPUs without relying on approximations.
> - Implementing optimal control solvers in JAX facilitates not only native GPU acceleration but also automatic differentiation, which is crucial for integrating MPC into end-to-end learning pipelines and optimizing controller parameters.
