# Primal-Dual iLQR for GPU-Accelerated Learning and Control in Legged Robots

> [!summary] Summary
> A GPU-accelerated Primal-Dual Iterative Linear Quadratic Regulator (iLQR) solver leverages parallel associative scans to achieve logarithmic computational complexity with prediction horizon length and square-logarithmic complexity with state and control dimensions for optimal control problems in legged robots. This approach demonstrated up to a 700% speedup over CPU-based solvers and enabled real-time centralized control of multiple robots and faster model-based learning.

## Problem

- Model Predictive Control (MPC) for complex robotic systems faces computational intensity, limiting real-time application with long prediction horizons, high-dimensional states, or multi-robot scenarios.
- Traditional DDP and SQP algorithms exhibit computational complexity scaling linearly with horizon length (N) and cubically with state and control dimensions, restricting control frequency and problem scalability.
- Existing GPU acceleration efforts for optimal control often involve partial parallelization, approximations, or focus on batching multiple problems, failing to fully exploit GPU capabilities within a single Optimal Control Problem (OCP).

## Method

- An SQP method is introduced that uses a primal-dual iLQR solver to efficiently solve the underlying equality-constrained Quadratic Program (QP).
- A key innovation is the integration of a parallel associative scan to solve the Karush-Kuhn-Tucker (KKT) system in both the backward and forward passes, achieving logarithmic computational complexity.
- The entire framework is implemented in JAX, allowing for seamless GPU integration, automatic differentiation, a parallel line search, and efficient handling of equality and inequality constraints through multiple shooting and barrier functions.

## Results

- The solver achieved up to a **700%** speedup for Single Rigid Body Dynamics (SRBD)-MPC and **60%** for Whole Body (WB)-MPC compared to state-of-the-art CPU-based solvers, particularly for longer prediction horizons.
- It demonstrated real-time centralized control for multiple robots, managing up to 16 SRBD robots (25 ms per solve) and four WB robots (20 Hz) simultaneously, enabling complex coordinated behaviors like collision avoidance.
- The JAX-based implementation facilitated massive parallelization for model-based learning, achieving real-time factors of up to **570x** for SRBD-MPC and **75x** for WB-MPC when processing 4096 environments concurrently.

## Takeaways

> [!tip] Key Insights
> - Associative scan operations can be effectively adapted to dynamic programming problems, fundamentally reducing computational complexity from polynomial to logarithmic or polylogarithmic for optimal control on parallel architectures like GPUs.
> - A primal-dual formulation combined with a multiple shooting approach enables exact, full temporal, state, and control dimension parallelization on GPUs without relying on approximations.
> - Implementing optimal control solvers in JAX facilitates not only native GPU acceleration but also automatic differentiation, which is crucial for integrating MPC into end-to-end learning pipelines and optimizing controller parameters.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Model Predictive Control (MPC) is a widely adopted framework for generating and controlling complex dynamic behaviors in robotic systems, particularly legged robots. Methods such as Differential Dynamic Programming (DDP), including its variant Iterative Linear Quadratic Regulator (iLQR), and Sequential Quadratic Programming (SQP) have been instrumental in solving the underlying Optimal Control Problems (OCPs) for robotic applications. These methods, exemplified by solvers like OCS2, acados, and crocoddyl, have demonstrated success in real-world hardware deployments.

A persistent challenge in MPC for robotics, especially with increasing problem complexity (longer prediction horizons, higher-dimensional states, or multi-robot scenarios), is computational efficiency. Traditional DDP and SQP algorithms often exhibit computational complexity that scales linearly with the prediction horizon length ($N$) and cubically with the dimensions of the system state ($n$) and control vector ($m$), i.e., $O(N(n+m)^3)$. This scaling can restrict the maximum achievable control frequency, the length of the prediction horizon, and the number of robots that can be simultaneously controlled.

The advent of hardware accelerators like Graphics Processing Units (GPUs) presents an opportunity to overcome these computational bottlenecks through massive parallelization. Previous research has explored GPU acceleration in various ways:
- **Symbolic expression translation:** Tools like Cusadi (Jeon et al.,) convert symbolic expressions for GPU computation but lack the branching and looping capabilities required for full solver implementation.
- **Quadratic Programming (QP) solvers:** Relu-QP (Bishop et al.,) leverages the Alternating Direction Method of Multipliers (ADMM) on GPUs for QP, but its applicability to Nonlinear Programming (NLP) is limited by offline pre-computation requirements.
- **Partial iLQR parallelization:** Some implementations (Lee et al.,) partially utilize GPU capabilities, limiting parallelization to components like line search and gradient computation.
- **Batching multiple OCPs:** Other approaches (Lee et al.,) focus on solving multiple OCPs in parallel without exploiting state or temporal parallelism within a single OCP.
- **Approximate temporal parallelization:** Plancher and Kuindersma extended earlier work by Farshidian et al. to incorporate temporal parallelization in iLQR on GPUs, but this often involves approximations in the backward pass and requires consensus sweeps to maintain consistency.
- **Iterative linear quadratic control:** Frasch et al. proposed methods for iteratively solving linear quadratic control problems using parallel computation, and Wright et al. showed how to partition dynamic programming for parallel computation.

A notable development in this area is the application of parallel associative scan operations to improve the computational complexity of Linear Quadratic Regulator (LQR) problems, as demonstrated by Särkkä and García-Fernández. This approach can achieve an optimal control policy in $O(\log^2(n) \log N + \log^2(m))$ time when parallelized on a GPU, a significant improvement over the $O(N(n+m)^3)$ of classical Riccati Recursion.

This paper addresses the identified gap by introducing a GPU-accelerated SQP method that explicitly utilizes an associative scan-based LQR solver to solve the primal-dual Karush-Kuhn-Tucker (KKT) system. The authors aim to achieve full temporal, state, and control dimension parallelization without approximations, leveraging a multiple shooting formulation, and implementing the entire framework in JAX for seamless GPU integration and automatic differentiation. This positions the work as an advancement in developing highly efficient, exact MPC solvers for complex robotic systems, especially for real-time control and large-scale learning applications.

### 2. Key Objectives and Motivation

The primary motivation for this research stems from the computational intensity of Model Predictive Control (MPC) when applied to complex robotic systems, particularly legged robots. While MPC has proven effective, its real-time application in scenarios demanding long prediction horizons, high-dimensional system states, or the control of multiple agents is often constrained by the computational cost of solving the underlying Optimal Control Problem (OCP).

The key objectives and motivations can be broken down as follows:

- **Overcome computational scaling limitations of existing MPC solvers:**
 - **Current state:** State-of-the-art MPC solvers (e.g., OCS2, acados, crocoddyl) typically exhibit computational complexity that scales linearly with the prediction horizon length ($N$) and cubically with the system state and control input dimensions ($n+m$). This limits their applicability in scenarios requiring rapid update rates or extended foresight.
 - **Motivation:** To enable more advanced and robust control, there is a need for solvers with superior scaling properties. Specifically, the authors aim to achieve logarithmic scaling with horizon length and square-logarithmic scaling with state and control dimensions, leveraging GPU parallelization.

- **Fully exploit modern hardware accelerators (GPUs):**
 - **Current state:** Existing attempts to use GPUs for optimal control often involve partial parallelization (e.g., only line search or gradient computation), approximations in the backward pass, or focus primarily on batching multiple OCPs rather than parallelizing a single OCP across time or state dimensions.
 - **Motivation:** GPUs offer massive parallel processing capabilities, particularly for linear algebra operations. The objective is to develop an MPC implementation that fully utilizes these capabilities across temporal, state, and control dimensions, while maintaining an exact formulation, unlike approximate methods.

- **Enhance MPC capabilities for complex control applications:**
 - **Longer prediction horizons:** Improved computational efficiency allows for longer prediction horizons, which can lead to finer integration steps for better approximation of robot dynamics or more foresight for complex maneuvers.
 - **Integration of advanced estimation:** The reduced computation time could enable the inclusion of sophisticated Moving Horizon Estimators (MHE) within the same optimization loop, paving the way for "end-to-end" MPCs that adapt directly to sensor data.
 - **Scalability across robot morphologies:** Better scaling with state dimension facilitates the application of MPC to robots with higher degrees of freedom or more complex dynamics.
 - **Centralized control for multi-robot systems:** Controlling multiple collaborating robots with a centralized MPC typically results in a rapidly increasing OCP size. The goal is to make such centralized control feasible for a larger number of agents by drastically reducing the computational cost per robot.

- **Accelerate model-based learning frameworks:**
 - **Current state:** Reinforcement Learning (RL) techniques, while powerful, often suffer from slow training processes when integrated with model-based controllers, primarily due to reliance on CPU-based MPC solvers.
 - **Motivation:** By implementing the MPC entirely in JAX and leveraging GPU acceleration, the authors aim to enable seamless coupling with GPU-based simulators (e.g., IsaacLab, Mujoco XLA). This would significantly speed up simulation throughput and the training of RL policies that incorporate MPC in the loop, bridging the gap between learning-based and model-based control.

In summary, the core objective is to develop a novel MPC implementation that leverages GPU parallelization to achieve significantly improved computational complexity, thereby enabling more capable real-time control for single and multi-robot systems, and facilitating faster integration of MPC within machine learning paradigms.

### 3. Methodology and Approach

The authors introduce a novel Model Predictive Control (MPC) implementation for legged robot locomotion based on Sequential Quadratic Programming (SQP). The core innovation lies in leveraging GPU parallelization through a primal-dual Iterative Linear Quadratic Regulator (iLQR) solver that incorporates a parallel associative scan for efficient solution of the Karush-Kuhn-Tucker (KKT) system.

**A. Optimal Control Problem (OCP) Formulation:**
The problem is formulated as a standard OCP:
- **Objective:** Minimize a sum of stage costs $l_i(x_i, u_i)$ and a terminal cost $l_{N+1}(x_{N+1})$.
- **Constraints:**
 - System dynamics: $x_{i+1} = h_i(x_i, u_i)$, an equality constraint.
 - State and control bounds: $x_i \in X_i$, $u_i \in U_i$, inequality constraints.
 - Initial condition: $x_0 = \hat{x}_0$.

**B. Sequential Quadratic Programming (SQP):**
The chosen approach is an SQP method, which iteratively solves a Quadratic Program (QP) derived from a quadratic approximation of the OCP's Lagrangian and a linearization of its constraints around the current guess.
- **Lagrangian:** Defined with state $x$, control $u$, and Lagrangian multipliers (costates) $\lambda$.
- **QP Formulation:** The linearized QP aims to find search directions $\delta x$ and $\delta u$ by minimizing a quadratic objective, subject to a linearized dynamics constraint $\delta x_{i+1} = A_i \delta x_i + B_i \delta u_i + b_i$ and an initial condition $\delta x_0$.
- **Multiple Shooting:** Unlike single shooting methods, this approach keeps both state and control variables as optimization variables, which typically improves numerical stability.

**C. Primal & Dual Problem Solution (Standard Riccati Recursion):**
Conventionally, the equality-constrained QP is solved using the Riccati Recursion, which involves:
- **Backward Pass:** Computes terms $P_i$ and $p_i$ (related to the value function approximation) and the optimal control policy gains $K_i$ (feedback) and $k_i$ (feedforward) by iterating backward in time from the terminal node.
- **Forward Pass:** Applies the computed control policy to propagate the state and control vectors forward in time, starting from the initial condition.
- **Dual Variable Update:** Once $P_i$ and $p_i$ are obtained, the update for Lagrangian multipliers $\delta \lambda_i$ can be computed.

**D. Parallel Associative Scan (Key Innovation):**
To achieve logarithmic computational complexity, the authors integrate a parallel associative scan, a technique primarily based on the work of Särkkä and García-Fernández.
- **Associative Scan Principle:** Given an associative operator $\otimes$, an associative scan computes prefix sums (or products, or any associative accumulation) in $O(\log N)$ time.
- **Conditional Value Function (CVF):** The core idea is to define a Conditional Value Function $V_{i \to j}(x_i, x_j)$ representing the minimal cost to go from state $x_i$ at node $i$ to $x_j$ at node $j$.
- **Associative Operator for Dynamic Programming:** The operator $\otimes$ is defined as $V_{i \to k} \otimes V_{k \to j} = \min_{x_k} \{V_{i \to k} + V_{k \to j}\}$, which is associative.
- **Dual Form of CVF:** The CVF for a quadratic program with affine equality constraints can be represented in its dual form. The authors derive specific combination rules (Equation 10) for the parameters of this dual form when two CVFs are combined using the $\otimes$ operator.
- **Scan Initialization:** The elements for a reverse associative scan are initialized using the CVF $V_{i \to i+1}$ between adjacent states, derived from the linearized dynamics and cost terms (Equations 11 and 12).
- **Parallel Backward Pass:** A parallel associative scan on these initialized CVF elements computes $V_{i \to N+1}(x_i, x_{N+1})$ for all $i$. From these, the $P_i$ and $p_i$ terms (of the value function $V_i(x_i)$) are obtained in parallel. This results in an overall computational complexity of $O(\log^2(n) \log N + \log^2(m))$ for computing the control policy.
- **Parallel Forward Pass:** A second parallel associative scan is used to retrieve the optimal trajectory $\delta x_i$. The linearized dynamics with the optimal control law ($\delta x_{i+1} = \bar{A}_i \delta x_i + \bar{b}_i$) are used to define conditional optimal trajectories $\bar{h}_{i \to j}(\delta x_i, \delta x_j)$, with specific combination rules (Equation 15) for $\bar{A}_{i,j}$ and $\bar{b}_{i,j}$. This scan yields the optimal state updates in $O(\log n \log N + \log m)$ time.

**E. Parallel Line Search:**
- **Method:** A backtracking filter line search is employed to determine the step length $\alpha$ for updating $x$, $u$, and $\lambda$. The filter line search ensures reduction in constraint violation or cost.
- **GPU Parallelization:** To leverage GPU capabilities, a fixed grid of $\alpha$ values (e.g., $\{2^0..., 2^{-9}\}$) is evaluated in parallel. The largest $\alpha$ satisfying the line-search conditions is selected.

**F. Practical Implementation Details:**
- **Gauss-Newton Approximation:** The authors use a Gauss-Newton approximation, ignoring second-order dynamics terms, to ensure convexity of the QP. The cost function is expressed as a nonlinear least squares problem.
- **Inequality Constraints:** Inequality constraints (state and control bounds) are incorporated as a relaxed barrier function (Equation 21). This function is added to the Hessian approximation of the QP to maintain convexity (Equation 22).
- **Receding Horizon Control:** In closed-loop MPC, only one iteration of the algorithm is performed per control loop.
- **Warm-starting:** Each solver call is warm-started by shifting the previous prediction by one time-step to improve robustness and convergence.
- **JAX Implementation:** The entire framework is developed in JAX, a Python library for high-performance numerical computation. This enables automatic differentiation and avoids explicit `while` loops (e.g., in line search, a fixed number of alpha values are checked in parallel), facilitating differentiability and GPU parallelization.

**G. Dynamic Models:**
Two dynamic models are used for OCP formulation and evaluation:
- **Single Rigid Body Dynamics (SRBD):** Approximates the robot as a single rigid body with constant inertia. State $x \in \mathbb{R}^{13}$ (COM position/orientation, linear/angular velocities), control $u \in \mathbb{R}^{3n_c}$ (ground reaction forces, $n_c$ contact points). Simpler, lower dimensionality.
- **Whole Body (WB) Dynamics:** Captures the full robot dynamics including joint positions and velocities. State $x \in \mathbb{R}^{13+2n_{joint}}$, control $u \in \mathbb{R}^{3n_c+n_{joint}}$ (GRFs, joint torques). More complex, higher dimensionality, non-linear dependencies.

This methodology combines a well-established SQP framework with a novel application of parallel associative scans to achieve highly efficient and scalable MPC, specifically designed for GPU architectures.

### 4. Main Findings and Results

The authors conducted a series of experiments to evaluate the performance of their GPU-accelerated MPC framework, designated as "our implementation," against state-of-the-art CPU-based solvers. The comparisons primarily involved `acados` (an SQP solver) for the Single Rigid Body Dynamics (SRBD) model and `crocoddyl` (a DDP solver) for the Whole Body (WB) Dynamics model. All tests were performed on a desktop with an Intel Core i7-13700KF and an NVIDIA RTX 3080, using Mujoco XLA for WB dynamics simulations.

**A. Performance Evaluation and Optimality:**
- **Complex Maneuvers:** The WB-MPC formulation demonstrated the ability to generate complex dynamic maneuvers, such as a barrel roll with an Aliengo robot, converging to a solution in 27 iterations from an infeasible initial guess.
- **Cost Optimality:** In a quadruped trotting scenario under external disturbances (whole-body model, 50Hz control), our implementation achieved approximately a 20% reduction in average cost along the trajectory compared to `acados`, while maintaining comparable solution paths (Figure 2).
- **Real Hardware Validation:** The WB-MPC was successfully deployed on a physical Aliengo robot for real-time control, enabling blind walking on uneven terrain using only proprioceptive data (Figure 1), with the solver running on an Nvidia RTX 4050 laptop GPU.
- **Centralized Multi-Robot Control:** A single centralized MPC successfully controlled two robots simultaneously to perform a collision avoidance task. The robots deviated from their individual desired paths to prevent collision, demonstrating coordinated behavior (Figure 3).
- **Solver Time Breakdown:** A breakdown of average solving times for a quadruped trotting scenario (N=100) showed that our method's computational overhead included approximately 1ms for GPU communication (sending initial state, retrieving commands). The parallel scan constitutes the primary computational phase for search direction evaluation (Figure 4).

**B. Temporal Parallelization (Scaling with Horizon Length):**
The study assessed how average solving time scaled with increasing prediction horizon length (N):
- **SRBD Model:** Our implementation consistently outperformed `acados` across all tested horizon lengths.
- **WB Model:** For prediction horizons smaller than 80 nodes, `crocoddyl` exhibited faster performance. However, for horizons equal to or greater than 80 nodes, our implementation surpassed `crocoddyl`. This initial advantage for `crocoddyl` was attributed to the overhead associated with data transfer to and from the GPU for smaller problems.
- **Achieved Rates:** The proposed formulation could maintain an update rate of 50Hz for a horizon length of 200 nodes (Figure 5).
- **Overall Improvement:** The reported improvements in runtime were up to 60% for WB-MPC and 700% for SRBD-MPC, relative to the state-of-the-art solvers, when varying the prediction horizon length.

**C. State Parallelization (Scaling with Number of Robots):**
The paper evaluated the solver's performance in a centralized control scenario by increasing the number of robots within a single optimization:
- **SRBD Model:** Our implementation significantly outperformed `acados`, achieving a computational time of 25 ms for controlling 16 robots simultaneously, a rate sufficient for real-time control (Figure 6).
- **WB Model:** `crocoddyl` was excluded from this comparison due to model interface limitations. Our algorithm successfully controlled up to four WB robots at 20 Hz (Figure 6). The authors note that this level of performance for the WB model in a centralized multi-robot setup has not been achieved before.

**D. Model-Based Learning (Vectorization Capabilities):**
The JAX-based implementation allows for easy vectorization of MPC computations, which is beneficial for learning scenarios:
- **Batch Parallelization:** Our approach was compared against the batched version of `acados` (which uses OpenMP for CPU-based parallelization of independent MPC instances). Our GPU-accelerated method outperformed `acados` for larger batch sizes, attributed to the higher parallelization capacity of GPUs over CPUs (Figure 7).
- **Massive Parallelization for Learning:** When batched across 4096 environments using Mujoco XLA, the MPC demonstrated significant real-time factors (Table I):
 - **SRBD-MPC:** At 50 Hz control, achieved 370x real-time factor; at 25 Hz, achieved 570x real-time factor.
 - **WB-MPC:** At 50 Hz control, achieved 35x real-time factor; at 25 Hz, achieved 75x real-time factor. These results highlight the potential for accelerating model-based learning algorithms that incorporate MPC.

In summary, the main findings demonstrate that the proposed GPU-accelerated Primal-Dual iLQR solver achieves superior computational efficiency and scalability compared to CPU-based state-of-the-art solvers, particularly for larger prediction horizons, increased state dimensions (e.g., multiple robots), and massive parallelization required for learning applications.

### 5. Significance and Potential Impact

The research presented in "Primal-Dual iLQR for GPU-Accelerated Learning and Control in Legged Robots" offers significant advancements in optimal control for robotics, with potential impacts across several domains.

**A. Breakthrough in MPC Performance and Scalability:**
The most significant contribution is the development of an MPC solver that achieves a computational complexity of $O(\log^2(n) \log N + \log^2(m))$ on GPUs. This logarithmic scaling with horizon length and square-logarithmic scaling with state and control dimensions represents a fundamental improvement over the linear and cubic scaling of conventional MPC algorithms. This theoretical advancement translates directly into practical benefits:
- **Higher Control Frequencies:** Enables faster update rates for MPC, crucial for agile and robust control of highly dynamic systems like legged robots.
- **Longer Prediction Horizons:** Allows controllers to plan further into the future, leading to more sophisticated, stable, and anticipatory behaviors, as well as enabling finer integration steps for better dynamic approximation.
- **Increased State Dimensionality:** The improved scaling with state dimension means the solver can handle more complex robot models (e.g., Whole Body Dynamics) or systems with a greater number of degrees of freedom more efficiently.

**B. Enabling Advanced Control Applications:**
The enhanced computational efficiency has the potential to unlock new capabilities in robotic control:
- **Real-time Centralized Multi-Robot Control:** The demonstrated ability to control up to 16 SRBD robots at 25 ms or four WB robots at 20 Hz from a centralized controller is a notable achievement. This opens avenues for complex collaborative tasks involving multiple agents that were previously limited by computational bottlenecks.
- **Integration of Moving Horizon Estimators (MHE):** The reduced control loop time provides the necessary computational budget to embed MHE within the MPC optimization loop. This could lead to "end-to-end" MPC systems that are more adaptive and reactive to real-time sensor data, potentially improving robustness against environmental uncertainties and model mismatches.
- **Deployment on Resource-Constrained Hardware:** The efficiency on GPUs, even laptop-grade GPUs (e.g., Nvidia RTX 4050), suggests broader applicability for complex MPC tasks on embedded systems often found in robotics.

**C. Accelerating Model-Based Learning:**
The full implementation in JAX, allowing seamless integration with GPU-based simulators (like IsaacLab or Mujoco XLA), provides a critical acceleration for data-driven and learning-based control approaches:
- **Faster Reinforcement Learning (RL) Training:** The current bottleneck of CPU-based MPC solvers in hybrid RL/MPC frameworks is addressed. By speeding up the MPC component, the proposed solver can significantly accelerate the training process of RL policies that use MPC as a bias or integrate learned behaviors, making such approaches more practical.
- **Large-Scale Parallel Simulation for Policy Learning:** The ability to run thousands of MPC instances in parallel across different environments (e.g., 4096 environments with a 75x real-time factor for WB-MPC) provides an unprecedented throughput for generating diverse training data and evaluating policies, potentially leading to more robust and generalized locomotion skills.
- **Development of Differentiable Control Frameworks:** The JAX implementation natively supports automatic differentiation, which is fundamental for many modern machine learning techniques and can facilitate the optimization of controller parameters or the learning of inverse dynamics models directly within the control loop.

**D. Contribution to Open-Source Robotics:**
The release of the code as an open-source repository (https://github.com/iit-DLSLab/mpx) fosters reproducibility and accelerates further research and development in MPC for legged robots and loco-manipulation. This provides researchers and practitioners with a powerful tool for rapid prototyping and exploration of advanced control and learning strategies.

In conclusion, this work significantly pushes the boundaries of real-time optimal control for legged robots by exploiting GPU parallelization with an exact, efficient primal-dual iLQR formulation. Its impact is expected to be observed in more capable and adaptable robotic systems, as well as in the advancement of hybrid model-based and learning-based control methodologies.
