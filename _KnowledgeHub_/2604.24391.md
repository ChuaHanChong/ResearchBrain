# FreqCache: Accelerating Embodied VLN Models with Adaptive Frequency-Guided Token Caching

> [!summary] Summary
> A novel framework, FreqCache, accelerates Vision-Language Navigation (VLN) models by applying adaptive frequency-guided token caching to address limitations of visual-domain methods. It achieved a 1.59x speedup in inference, reducing per-step latency from 637 ms to 401 ms, while maintaining navigation accuracy with an Oracle Success rate of 76.0%.

## Problem

- High computational overhead in Vision-Language Navigation (VLN) models due to repeated, expensive inferences at each timestep, hindering real-time deployment.
- Existing visual-domain token caching methods struggle with viewpoint migration, leading to redundant recomputations and erroneous cache decisions in dynamic environments.
- Current methods fail to robustly identify critical edge information for safe navigation and lack adaptive mechanisms to adjust cache budgets based on temporal scene complexity.

## Method

- **FreqCache** introduces a three-module framework leveraging ==frequency-domain analysis== for adaptive token caching in VLN models.
- It employs ==global amplitude similarity== and ==phase correlation== to establish ==migration-aware token caches==, addressing viewpoint shifts.
- The framework identifies critical edge information via ==high-frequency energy analysis== and dynamically adjusts the token reuse budget using ==spectral entropy== to adapt to scene complexity.

## Results

- FreqCache achieved a **1.59x speedup** in both per-step and episode-level inference latency, reducing average per-step latency from **637 ms to 401 ms**.
- The framework maintained competitive navigation accuracy with **76.0% Oracle Success** and **63.0% Success Rate**, comparable to non-cached baselines.
- An average token reuse ratio of **53.5%** was demonstrated with negligible per-step overhead (**< 2.54 ms**) for its frequency-domain processing modules.

## Takeaways

> [!tip] Key Insights
> - Frequency domain properties, such as amplitude spectrum invariance to translation, provide an intrinsic mechanism to handle viewpoint migration more robustly than visual-domain methods.
> - Orthogonal decoupling of visual information in the frequency domain allows for model-free identification of critical edge features through high-frequency energy analysis.
> - Spectral entropy serves as an intrinsic metric for visual information density, enabling dynamic adjustment of cache budgets based on temporal variations in scene complexity.
