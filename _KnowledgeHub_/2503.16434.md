# Interactive Sketchpad: A Multimodal Tutoring System for Collaborative, Visual Problem-Solving

> [!summary] Summary
> MIT researchers developed Interactive Sketchpad, a multimodal tutoring system utilizing GPT-4o and code execution to provide dynamic, interactive visualizations and hint-based guidance for visual problem-solving. The system significantly improved accuracy on graph algorithms and mathematical functions (e.g., 100% on Maxflow from IsoBench dataset) and received high user satisfaction for enhancing conceptual understanding in various math problems.

## Problem

- Existing intelligent tutoring systems are predominantly text-based, struggling to support tasks requiring visual or spatial reasoning.
- Text-only feedback often falls short in subjects like geometry or calculus where diagrams and sketches are critical for comprehension and problem-solving.
- Traditional AI tutors can hinder active learning by providing direct answers, rather than fostering deeper conceptual understanding through interactive engagement.

## Method

- Interactive Sketchpad uses a pre-trained Large Multimodal Model (LMM), GPT-4o, enhanced with ==code execution via OpenAI Code Interpreter== to generate precise and dynamic visualizations.
- The system provides ==step-by-step textual hints==, fine-tuned on human demonstrations, alongside interactive visual aids displayed on a ==shared whiteboard==.
- Students can input text queries and interact directly with the whiteboard using sketches and annotations, which the LMM processes to provide context-aware feedback.

## Results

- Interactive Sketchpad achieved **100%** accuracy on 'Maxflow', outperforming GPT-4o (**25.0%** on Maxflow) and Visual Sketchpad (**66.3%** on Maxflow).
- User studies showed high satisfaction with an average Likert score of **4.71/5** for Interface Intuitiveness and Accuracy of Visuals, and **4.57/5** for Effectiveness of Hints.
- Qualitative feedback indicated that generated visualizations and the hint-based, iterative guidance significantly improved conceptual understanding and problem-solving engagement for students.

## Takeaways

> [!tip] Key Insights
> - Leveraging LMMs with external code execution for visualization generation dramatically improves accuracy and robustness in visual problem-solving compared to relying solely on internal model reasoning.
> - A multimodal approach combining subtle, hint-based textual guidance with dynamic, interactive visual aids fosters deeper conceptual understanding and active learning.
> - An interactive whiteboard serves as a natural shared workspace, facilitating seamless human-AI collaboration for solving visually complex problems.
