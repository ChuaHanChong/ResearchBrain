# Quantile Reward Policy Optimization: Alignment with Pointwise Regression and Exact Partition Functions

> [!summary] Summary
> Researchers at CLAIRE, EPFL, developed Quantile Reward Policy Optimization (QRPO), a new policy fitting method that allows large language models to be aligned directly with pointwise absolute rewards. This approach makes the intractable partition function analytically tractable, leading to strong performance in chat and coding tasks while exhibiting reduced length bias compared to previous methods.

## Problem

- Policy Improvement (PI) methods for LLM alignment (e.g., PPO, RLHF) can use pointwise absolute rewards but are computationally intensive and complex, requiring online sampling.
- Policy Fitting (PF) methods (e.g., DPO) are simpler and more stable, but are limited to using relative reward signals (e.g., preference pairs) because their objective formulation relies on canceling out an intractable partition function.
- This limitation prevents PF methods from directly utilizing powerful pointwise absolute reward signals from advanced reward models or verifiable metrics, often necessitating the use of more complex PI approaches.

## Method

- QRPO introduces a novel transformation that converts raw, pointwise absolute rewards into =="quantile rewards"==, defined as the cumulative distribution function (CDF) value of the original reward under the reference policy.
- This quantile reward, when sampled from the reference policy, is ==uniformly distributed==, allowing the intractable partition function in the KL-regularized RL objective to become analytically tractable and a constant.
- The simplified objective can then be optimized directly via a simple ==Mean Squared Error (MSE) regression loss==, enabling efficient policy fitting using pointwise absolute rewards.

## Results

- QRPO consistently achieves top-tier performance on chat benchmarks (e.g., **0.2005** ArmoRM reward, **50.6%** AlpacaEval 2 win rate with Llama 8B) and significantly outperforms baselines on a LeetCode coding task with a **32.7%** pass rate.
- The method demonstrates efficient scalability, with performance improving as more reference rewards are used for quantile estimation, and it achieves near-optimal results with very few reference rewards in offline settings.
- QRPO exhibits significantly less length bias in generated responses compared to DPO and SimPO, attributed to its direct utilization of robust absolute reward models designed to counteract such biases.

## Takeaways

> [!tip] Key Insights
> - The partition function in the KL-regularized RL objective can be re-expressed as the moment generating function of the reference reward distribution, highlighting the challenge of its unknown form.
> - By transforming original rewards into quantile rewards, the resulting distribution becomes uniform, regardless of the original reward distribution's complexity.
> - A uniform reward distribution yields an analytically tractable and constant partition function, fundamentally simplifying the policy fitting problem for absolute rewards into a direct regression task.
