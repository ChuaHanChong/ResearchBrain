# RoboMME: Benchmarking and Understanding Memory for Robotic Generalist Policies

> [!summary] Summary
> RoboMME introduces a large-scale, cognitively-inspired benchmark that systematically evaluates memory-augmented Vision-Language-Action (VLA) models across 16 long-horizon robotic manipulation tasks covering temporal, spatial, object, and procedural memory. The research finds that perceptual memory approaches yield the strongest overall performance (44.51% success rate), while symbolic memory excels in tasks requiring explicit counting and grounding.

## Problem

- Existing robotic manipulation benchmarks primarily focus on long-horizon planning but lack explicit memory requirements, often allowing policies to succeed based on immediate observations.
- A standardized, large-scale benchmark is absent, making it difficult to systematically compare and understand different memory architectures for VLA policies in history-dependent scenarios.
- There is a limited understanding of the distinct advantages, limitations, and generalization capabilities of various memory designs (symbolic, perceptual, recurrent) across diverse memory demands in VLA models.

## Method

- Introduced **RoboMME**, a ==cognitively-motivated benchmark== comprising 16 long-horizon, history-dependent manipulation tasks categorized into ==temporal==, ==spatial==, ==object==, and ==procedural memory== types.
- Created a dataset of 1,600 high-quality demonstrations (770,000 timesteps) in the **ManiSkill** simulator, featuring ==multi-view RGB observations== and ==proprioceptive states==.
- Developed and evaluated 14 ==memory-augmented VLA== policy variants based on the **π0.5** backbone, incorporating ==symbolic==, ==perceptual==, and ==recurrent memory== representations with various integration strategies.

## Results

- Perceptual memory, specifically the `FrameSamp+Modul` variant, achieved the highest overall success rate among MME-VLA policies at **44.51%**.
- Symbolic memory with "Oracle" (ground-truth) subgoals demonstrated a high overall success rate of **84.08%**, affirming the strong representational capacity of language for high-level reasoning.
- Human participants achieved an impressive **90.5%** success rate, confirming RoboMME as a genuinely challenging testbed, while initial real-world experiments mirrored simulation findings for symbolic and perceptual memory.

## Takeaways

> [!tip] Key Insights
> - No single memory representation or integration strategy universally outperforms others; the effectiveness of a memory design is highly task-dependent, indicating complementary strengths.
> - Perceptual memory methods, particularly those using frame sampling with a memory-as-modulator integration strategy, generally achieve the strongest overall performance and exhibit favorable efficiency.
> - Symbolic memory, especially when using grounded subgoals, excels in tasks requiring explicit counting, clear subgoal guidance, or short-horizon reasoning.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of robotic manipulation increasingly addresses tasks that require reasoning over extended temporal histories, such as counting repeated actions, tracking objects that become occluded, or replicating observed demonstrations. Such long-horizon and history-dependent scenarios necessitate memory mechanisms, as reliance solely on immediate sensory perception is often insufficient for robust action prediction.

Prior research has explored integrating memory into robotic policies through various representations, including symbolic memory (e.g., tracking 3D points or language-based subgoals), perceptual memory (e.g., multi-frame visual tokens or memory banks), and recurrent memory (e.g., fixed-size latent states via recurrent models). While these approaches have demonstrated the importance of memory, their evaluations have largely been conducted using disparate policy backbones and inconsistent protocols. This fragmentation has limited the systematic understanding, comparison, and generalization of different memory designs across diverse tasks.

Existing robotic manipulation benchmarks have typically focused on aspects like long-horizon planning or task complexity, often implicitly requiring temporal memory but not explicitly enforcing it. Policies in these benchmarks can frequently achieve high success rates by relying on local perception, as object states are continuously updated or decisions can be made from immediate observations. Specialized memory benchmarks, such as MemoryBench, have introduced explicit memory requirements, primarily focusing on spatial memory, but are characterized by a limited number of tasks that are often nearly solved. MIKASA-Robo includes some history-dependent tasks, yet these are often short-horizon, lack sufficient long-term dependencies, and do not provide adequate high-quality demonstrations for effective vision-language-action (VLA) imitation learning.

RoboMME addresses these limitations by introducing a unified, large-scale, and standardized benchmark explicitly designed for evaluating and advancing VLA models in scenarios that demand diverse and challenging memory capabilities. It aims to provide a controlled environment to systematically study memory representations and their integration strategies, thereby facilitating a more comprehensive understanding of memory-augmented robotic manipulation.

### 2. Key Objectives and Motivation

The primary objective of this research is to introduce RoboMME, a large-scale standardized benchmark specifically designed for the evaluation and advancement of Vision-Language-Action (VLA) models in long-horizon, history-dependent robotic manipulation.

The motivation for developing RoboMME stems from several identified challenges within the existing research landscape:
1. **Necessity of Memory for Complex Tasks**: Real-world robotic manipulation tasks frequently require agents to recall and utilize information from past interactions and observations. Examples include counting completed actions, returning objects to previously observed locations after occlusion, identifying specific objects based on prior cues, or accurately reproducing demonstrated motion patterns. Policies that rely solely on instantaneous perception are insufficient for these tasks, underscoring the critical role of memory.
2. **Lack of Standardized Evaluation**: While various memory mechanisms have been integrated into robotic policies, their evaluation has been confined to narrow, often self-designed settings. This absence of a standardized, diverse, and challenging benchmark has impeded systematic comparison of different memory designs, measurement of progress, and a comprehensive understanding of which memory approaches generalize across different types of tasks and memory demands.
3. **Limitations of Existing Benchmarks**: Prior robotic benchmarks either do not explicitly enforce diverse memory requirements, focusing instead on other aspects like planning or task complexity, or they offer tasks that are too simple or lack sufficient data for training modern VLA models via imitation learning. This gap limits the ability to rigorously test and improve memory-augmented policies under conditions that reflect realistic complexities.

To address these motivations, RoboMME pursues a secondary objective: to develop and evaluate a family of memory-augmented VLA models. By building these models on a common backbone (𝜋
0.5
) and systematically exploring different memory representations (symbolic, perceptual, recurrent) and integration strategies (memory-as-context, memory-as-modulator, memory-as-expert), the research aims to provide insights into their respective advantages and limitations.

Ultimately, the research seeks to establish a framework for understanding memory in manipulation, contribute to the development of reliable long-horizon, history-dependent robotic generalist policies, and foster systematic progress in the field by providing a robust and challenging testbed.

### 3. Methodology and Approach

The methodology involves the construction of the RoboMME benchmark and the development of a suite of memory-augmented VLA policies for systematic evaluation.

#### 3.1. RoboMME Benchmark Construction

RoboMME is a simulation benchmark built on the ManiSkill simulator, featuring a tabletop environment and a 7-DOF Franka Panda arm. It comprises 16 distinct long-horizon tasks, divided into four cognitively-motivated task suites:
- **Cognitive Task Design**: Drawing inspiration from human memory theories, memory types are categorized:
 - **Temporal Memory**: Evaluated in the **Counting suite**, focusing on event accumulation, sequence ordering, and transition conditions. Tasks include `PickXTimes`, `BinFill`, `SwingXTimes`, and `StopCube`.
 - **Spatial Memory**: Evaluated in the **Permanence suite**, requiring tracking of object locations under occlusion and scene changes. Tasks include `VideoUnmask`, `ButtonUnmask`, `VideoUnmaskSwap`, and `ButtonUnmaskSwap`.
 - **Object Memory**: Evaluated in the **Reference suite**, assessing referential consistency and object identification from various cues over time. Tasks include `PickHighlight`, `VideoRepick`, `VideoPlaceButton`, and `VideoPlaceOrder`.
 - **Procedural Memory**: Evaluated in the **Imitation suite**, measuring the ability to reproduce previously demonstrated motion patterns. Tasks include `MoveCube`, `InsertPeg`, `PatternLock`, and `RouteStick`.
- **Data Generation**: The benchmark includes 1,600 demonstrations across the 16 tasks, yielding 770,000 high-quality training timesteps. Training episodes are generated by replaying predefined keyframe waypoints. To enhance behavioral diversity and failure recovery, controlled perturbations (5% noise to keyframe waypoints) are injected during data generation, with successful rollouts retained. Tasks are stratified into easy, medium, and hard levels based on scene clutter, horizon length, and environmental dynamics.
- **Observations and Actions**: At each timestep, the robot receives multi-view RGB observations (front- and wrist-mounted cameras) and proprioceptive states (joint positions, end-effector pose, gripper state). Actions are defined in either 8D absolute joint space or 7D absolute end-effector space. Some tasks use video-based observations at the initial step, while all tasks provide image-based observations during execution.

#### 3.2. MME-VLA Suite Development

A family of 14 memory-augmented VLA models (MME-VLA suite) is developed, based on the 𝜋
0.5
backbone, to systematically investigate memory representations and integration mechanisms. A fixed memory budget of 512 tokens is used for all memory-based models.
- **Memory Representations**:
 - **Symbolic Memory**: Task history is summarized as interpretable language subgoals, which can be simple instructions or "grounded" with image coordinates. These subgoals are generated by an auxiliary Vision-Language Model (VLM) (fine-tuned Qwen3-VL-4B or Gemini-2.5-Pro via prompt engineering) or provided by an Oracle. Tokenized subgoals are concatenated with task instructions.
 - **Perceptual Memory**: Retains selected visual tokens from past observations, preserving low-level visual information. Two instantiations are explored:
 - **Frame Sampling (FrameSamp)**: Uniformly samples a subset of historical frames and pools their visual tokens.
 - **Token Dropping (TokenDrop)**: Selects the most informative spatial regions (image patches) from history based on temporal saliency (RGB differences between patches), prioritizing regions with significant changes. M-RoPE positional embeddings are used.
 - **Recurrent Memory**: Compresses the historical visual token sequence into fixed-size latent states through iterative updates, maintaining a bounded memory representation. Two models are adopted:
 - **Recurrent Memory Transformer (RMT)**: Utilizes learnable memory slots that are updated recurrently by attending to segments of observation tokens.
 - **Test-Time Training (TTT)**: Stores memory implicitly in a small set of fast weights of a lightweight feed-forward network, updated online via a self-supervised objective. Output features implicitly capture historical information.
- **Memory Integration Mechanisms (for neural memory tokens)**:
 - **Memory-as-Context**: Memory tokens are directly concatenated with the current input tokens (observations, language) and processed jointly by the VLM expert.
 - **Memory-as-Modulator**: Memory tokens condition the action expert through adaptive LayerNorm (AdaLN). The action expert's intermediate activations are modulated by scale and shift parameters derived from memory-aware representations obtained via cross-attention to memory tokens.
 - **Memory-as-Expert**: A dedicated, lightweight memory expert processes memory tokens independently. The action expert attends to both the VLM expert's features and the memory expert's features, but the VLM and memory experts do not attend to each other, allowing specialized processing while preventing interference.
- **Experimental Protocol**: All VLA models are trained in a multi-task learning setting for 80,000 steps. Evaluations are conducted on all 16 tasks using 50 episodes per task (800 total episodes), with environment seeds distinct from training. Results are averaged over the last three checkpoints and three random seeds. The MME-VLA suite is compared against a non-memory baseline (𝜋
0.5
), a baseline with past actions, SAM2Act+, and MemER. Human performance with an oracle planner is also evaluated to establish an approximate upper bound. Real-world experiments are conducted on four tasks mirroring simulation tasks to assess transferability.

### 4. Main Findings and Results

The experiments conducted on the RoboMME benchmark reveal several findings regarding the performance of memory-augmented VLA policies:

- **Task-Dependent Effectiveness**: No single memory representation or integration strategy consistently achieves the highest performance across all 16 tasks. The effectiveness of a particular memory design is observed to be highly dependent on the specific characteristics and demands of the task.
- **Perceptual Memory Performance**:
 - Perceptual memory methods generally exhibit strong performance. Specifically, `FrameSamp+Modul` achieves the highest overall average success rate (44.51%) among all evaluated non-oracle VLA variants.
 - `FrameSamp` (uniform frame sampling) is more effective than `TokenDrop` (token dropping based on saliency). This suggests that retaining a more global temporal view of the episode (even with downsampling) is beneficial, potentially preserving more contextual information than aggressive visual token pruning.
 - The `memory-as-modulator` integration strategy consistently performs best for perceptual memory. This is attributed to its lightweight, feature-wise conditioning of the action expert, which modulates intermediate activations without substantially altering the core 𝜋
0.5
architecture or disrupting pre-trained representations.
- **Symbolic Memory Performance**:
 - Symbolic memory, particularly with ground-truth subgoals (`GroundSG Oracle`, 84.08% average success), demonstrates a high representational capacity for high-level reasoning.
 - With a fine-tuned VLM (`GroundSG+QwenVL`, 32.70% average success), symbolic memory shows strengths in Counting tasks (e.g., `BinFill`, `PickXTimes`) and tasks requiring clear subgoal guidance for short-horizon reasoning.
 - Grounded subgoals (`GroundSG`) generally outperform simple subgoals (`SimpleSG`) when generated by a fine-tuned VLM, indicating the importance of precise referential grounding for manipulation tasks.
 - However, symbolic memory-based policies demonstrate performance degradation in manipulation-intensive tasks like `StopCube` and `InsertPeg`, where precise visuomotor control is critical and language guidance is limited. They also struggle in cluttered scenes, experiencing issues such as manipulating incorrect objects despite unambiguous subgoals.
 - Using un-fine-tuned VLMs (e.g., `Gemini` via prompt-only) results in lower performance due to domain shift and inaccurate subgoal generation.
- **Recurrent Memory Performance**:
 - Recurrent memory variants (`TTT` and `RMT`) generally exhibit the lowest performance among the memory types tested. This is hypothesized to be due to unstable training when fine-tuning the 𝜋
0.5
backbone with shallow recurrent layers, suggesting that effective recurrence may require deeper architectural integration and specialized pretraining.
- **Comparison with Prior Methods**:
 - `MemER` (42.38% average success) is the strongest among the compared prior methods. Its success in tasks like `ButtonUnmask` and `PickHighlight` is attributed to its hybrid approach of combining perceptual memory (keyframes) with symbolic subgoals, demonstrating the potential benefits of integrating different memory representations.
 - `SAM2Act+` performs poorly on average but achieves the best result on `ButtonUnmaskSwap`, likely due to its use of a robust motion planner for discrete action execution, which mitigates low-level manipulation failures.
 - The baseline `𝜋
0.5
` model without explicit memory (17.93% average success) and `𝜋
0.5
w/ past actions` (19.73% average success) perform significantly lower than memory-augmented variants, confirming the necessity of explicit memory for these tasks.
- **Task Characteristic Dependencies**:
 - Perceptual memory (e.g., `FrameSamp+Modul`) is most effective for motion-centric, time-sensitive, and long-horizon tasks, which require extended visual history and precise low-level motion understanding.
 - Symbolic memory excels in short-horizon and event-salient tasks where clear, high-level subgoal guidance is beneficial.
 - `MemER` shows strong performance on dynamic scene-change tasks, possibly due to its keyframe retention mechanism preserving necessary visual details during execution.
- **Efficiency-Performance Trade-off**: Perceptual memory, particularly `FrameSamp+Modul`, demonstrates a favorable balance between performance gains and computational cost. It offers consistent improvements with modest additional overhead compared to the base `𝜋
0.5
`. Methods relying on external VLM inference for symbolic memory incur substantially higher computational costs (e.g., `GroundSG+QwenVL` requires ~3x, `MemER` ~5x the computation of `𝜋
0.5
`), although caching strategies could reduce this in practice.
- **Real-World Transfer**: Trends observed in simulation, such as symbolic memory excelling in counting-based tasks and perceptual memory performing well in motion-centric tasks, are reported to transfer to real-world robotic manipulation experiments.

### 5. Significance and Potential Impact

The introduction of RoboMME and the systematic study conducted using the MME-VLA suite contribute to the field of robotic manipulation in several ways:

- **Standardized and Comprehensive Benchmark**: RoboMME addresses a critical gap by providing a unified, large-scale, and challenging benchmark specifically designed to evaluate memory-augmented robotic manipulation policies. This standardization enables consistent comparison of different approaches and provides a reliable measure of progress, which was previously hindered by disparate evaluation protocols.
- **Cognitively-Motivated Taxonomy**: The benchmark's design, grounded in a taxonomy of temporal, spatial, object, and procedural memory, offers a structured framework for categorizing and understanding the diverse memory demands inherent in complex robotic tasks. This allows researchers to target specific memory capabilities and gain deeper insights into their functioning.
- **Systematic Understanding of Memory Designs**: The controlled comparison of various memory representations (symbolic, perceptual, recurrent) and integration mechanisms (memory-as-context, memory-as-modulator, memory-as-expert) on a shared VLA backbone (𝜋
0.5
) provides empirical evidence regarding their respective strengths and limitations. This systematic analysis clarifies which designs are more effective under different task conditions.
- **Insights into Task-Dependent Performance**: The finding that no single memory design universally dominates across all tasks, but rather exhibits task-dependent efficacy, is a key insight. This suggests that future advancements may lie in developing hybrid memory architectures that can synergistically combine different forms of memory or adaptively leverage specific memory types based on task requirements.
- **Guidance for Policy Development**: The results offer practical guidance for the development of future robotic generalist policies. Perceptual memory, particularly when integrated via modulation, is identified as a promising direction for achieving a balance between performance and computational efficiency for tasks requiring fine-grained visual history. Symbolic memory remains valuable for high-level reasoning and explicit task decomposition.
- **Foundation for Future Research**: RoboMME establishes a foundation and a rigorous testbed for developing more reliable, long-horizon, and history-dependent robotic generalist agents. It motivates further research into more robust recurrent memory integration, exploration of alternative VLA backbones, and the creation of unified memory frameworks that can dynamically combine diverse memory modalities.
- **Real-World Applicability**: The observed transferability of performance trends from simulation to real-world robotic experiments indicates the practical relevance of the benchmark and the insights derived from it for developing deployable robotic systems.

By providing both a challenging evaluation platform and a systematic analysis of memory designs, this work is positioned to facilitate progress towards more capable and autonomous robots operating in complex, open-world environments.
