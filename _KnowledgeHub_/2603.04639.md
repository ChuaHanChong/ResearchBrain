# RoboMME: Benchmarking and Understanding Memory for Robotic Generalist Policies

> [!summary] Summary
> RoboMME introduces a large-scale, cognitively-inspired benchmark that systematically evaluates memory-augmented Vision-Language-Action (VLA) models across 16 long-horizon robotic manipulation tasks covering temporal, spatial, object, and procedural memory. The research finds that perceptual memory approaches yield the strongest overall performance (44.51% success rate), while symbolic memory excels in tasks requiring explicit counting and grounding.

## Problem

- Existing robotic manipulation benchmarks primarily focus on long-horizon planning but lack explicit memory requirements, often allowing policies to succeed based on immediate observations.
- A standardized, large-scale benchmark is absent, making it difficult to systematically compare and understand different memory architectures for VLA policies in history-dependent scenarios.
- There is a limited understanding of the distinct advantages, limitations, and generalization capabilities of various memory designs (symbolic, perceptual, recurrent) across diverse memory demands in VLA models.

## Method

- Introduced **RoboMME**, a ==cognitively-motivated benchmark== comprising 16 long-horizon, history-dependent manipulation tasks categorized into ==temporal==, ==spatial==, ==object==, and ==procedural memory== types.
- Created a dataset of 1,600 high-quality demonstrations (770,000 timesteps) in the **ManiSkill** simulator, featuring ==multi-view RGB observations== and ==proprioceptive states==.
- Developed and evaluated 14 ==memory-augmented VLA== policy variants based on the **\u03c00.5** backbone, incorporating ==symbolic==, ==perceptual==, and ==recurrent memory== representations with various integration strategies.

## Results

- Perceptual memory, specifically the `FrameSamp+Modul` variant, achieved the highest overall success rate among MME-VLA policies at **44.51%**.
- Symbolic memory with "Oracle" (ground-truth) subgoals demonstrated a high overall success rate of **84.08%**, affirming the strong representational capacity of language for high-level reasoning.
- Human participants achieved an impressive **90.5%** success rate, confirming RoboMME as a genuinely challenging testbed, while initial real-world experiments mirrored simulation findings for symbolic and perceptual memory.

## Takeaways

> [!tip] Key Insights
> - No single memory representation or integration strategy universally outperforms others; the effectiveness of a memory design is highly task-dependent, indicating complementary strengths.
> - Perceptual memory methods, particularly those using frame sampling with a memory-as-modulator integration strategy, generally achieve the strongest overall performance and exhibit favorable efficiency.
> - Symbolic memory, especially when using grounded subgoals, excels in tasks requiring explicit counting, clear subgoal guidance, or short-horizon reasoning.
