# eMEM: A Hybrid Spatio-Temporal Memory System For Embodied Agents

> [!summary] Summary
> eMEM is a hybrid spatio-temporal memory system for embodied agents that integrates LLM-agent memory's temporal consolidation with robotic spatial grounding. The system achieved an 80.8% overall weighted mean score on a novel diagnostic benchmark and demonstrated stable recall performance over simulated durations up to one year, indicating effective long-term memory retention.

## Problem

- Existing LLM-agent memory systems primarily focus on text or conversational contexts and lack native support for spatial coordinates, multi-modal perception, or spatial reasoning crucial for embodied agents.
- Robotics research provides advanced spatial representations, but these are primarily perceptual systems that do not track environmental changes over extended periods, consolidate experience, or support long-term episodic recall.
- Embodied agents require a memory system that is simultaneously searchable by meaning, space, and time to enable complex reasoning about physical environments and past experiences.

## Method

- **eMEM** (Embodied Memory) is a hybrid graph-based memory system designed to run in-process, integrating a working-memory buffer, a consolidation engine, and a 10-tool retrieval surface.
- It employs a biologically inspired tiered memory architecture (Working, Short-term, Long-term, Archived) and a two-phase consolidation pipeline to transform raw observations into compressed, higher-level summaries.
- The system utilizes a multi-index storage approach combining SQLite for relational data, HNSW for semantic search, and R-tree for 3D spatial queries, all unified under a graph data model.

## Results

- eMEM achieved an overall weighted mean score of 80.8 across 988 probes on the new eMEM-Bench v1 diagnostic benchmark.
- The system demonstrated a flat retention curve at ceiling (**100%** hit rate) for room-unique items from 1 hour to 1 year of simulated delay, indicating no measurable forgetting under long-term pressure.
- Ablation studies showed significant performance drops (30 percentage points on context-dependent retrieval and 29 percentage points on DRM lure rejection) for a pure Retrieval-Augmented Generation baseline, highlighting the contributions of eMEM's multi-layer storage and consolidation pipeline.

## Takeaways

> [!tip] Key Insights
> - Integrating temporal and consolidation mechanisms from LLM-agent memory with spatial grounding from robotics is essential for effective memory systems in embodied agents.
> - A biologically-inspired tiered memory architecture and consolidation process can effectively manage memory growth and ensure long-term retention in continuously operating agents.
> - A hybrid multi-index architecture, encompassing relational, semantic, and spatial indexing, provides comprehensive retrieval capabilities necessary for complex spatio-temporal queries.
