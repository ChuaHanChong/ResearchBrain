# Kinematic Nonlinear Spatio-Temporal Trajectory Warping for Contact-Rich Dexterous Manipulation Demonstrations

> [!summary] Summary
> A two-stage, object-centric method that reuses existing contact-rich dexterous demonstrations by warping them nonlinearly in space and time. First, the object trajectory is warped to pass through waypoints, avoid barriers and meet new timing. Then per-frame contact-distribution IK recovers the hand. Across 12 warps from 4 GRAB demos, the hand-object relationship stays within about 1 mm, and the method runs in minutes on a CPU.

## Problem

- MimicGen-style augmentation applies only rigid SE(3) transforms with a fixed hand-object pose, so it cannot reroute intermediate paths, retime segments or avoid obstacles.
- Hand and object trajectories are implicitly coupled, so naive nonlinear warps break that coupling and cause misalignment, penetration or lost contact during dexterous manipulation.
- No simple off-the-shelf solver jointly handles spatial waypoints, temporal shifts, barriers and new start/end configurations for long contact-rich dexterous demonstrations.

## Method

- Spatial waypoint warping (**TransformSegment**): segment displacements blend quadratic shape-preserving and linear direct interpolation via an adaptive factor beta, with ==SLERP==-applied cumulative rotations.
- Barrier-constrained warping inflates convex barrier hulls by the object's bounding ball, an approximate ==Minkowski sum==, and projects intersecting trajectory points outward along centroid rays.
- Temporal retiming fits chord-length ==B-splines== composed into a global C2 timewarp, then per-timestep ==contact-distribution IK== with an ==SDF== barrier penalty recovers the hand pose.

## Results

- At the **3.5 mm** threshold, wrist-to-object distance differs from the original by only **1.0 mm** on average across 12 kitchen warps; it differs by **5.5 mm** at the **10 mm** threshold.
- Mean contact distance ends **1.0 mm** below the original demonstrations at **3.5 mm**. Savitzky-Golay smoothing shifts it by only -**0.62 mm**, and the full pipeline averages about 4.6 minutes on a CPU.
- Contact quality stays near **5.0 mm** with up to **50%** contact deletion or permutation. A rigid-transform baseline loses grasp under non-uniform timewarps, while the method transfers to a Franka gripper and an Allegro hand.

## Takeaways

> [!tip] Key Insights
> - Warp the object first, then re-solve the hand from contact correspondences: this object-centric decoupling keeps coupled hand-object motion consistent under large nonlinear deformations.
> - Rigid-transform plus interpolation augmentation silently fails between known frames when timing is stretched, so dense per-frame contact constraints matter more than smarter interpolation.
> - Reusing the last available contact set limits tasks with rapid finger gaiting, so contact interpolation is the bottleneck for warping truly in-hand dexterous motions.

## Detailed Report

### 1. Overview

Collecting and reconstructing high-quality dexterous demonstrations is labor-intensive, and it slows learning-from-demonstration. Adapting an existing demonstration offers a way to create environmental variations without recording each one from scratch. Adapting a demonstration is difficult because the hand and object trajectories are coupled. Changing one without preserving that relationship can cause misalignment, penetration, or lost contact. Hyojae Park, Arjun S. Lakshmipathy, and Nancy S. Pollard (arXiv:2609.36676v1) take a two-step approach. They change the object's route first, then use the recorded hand–object touch points to reposition the hand along that route. The reported results support retention of the original wrist-to-object-center relationship. That measure is distinct from contact error.

The method warps hand and object trajectories to fit spatial and temporal waypoints, environmental barriers, and new start/end positions. Approximate mappings between original and warped trajectories are color-coded.

### 2. Warp the object, then recover the hand

The user specifies waypoints and barriers. A waypoint can specify a position, a rotation, and original and output timesteps. A barrier is a region the object path must avoid.

The pipeline proceeds in four steps:

1. It spatially fits the object path to the position and orientation waypoints and to any changed endpoints.
1. It moves points out of barrier-intersection regions.
1. It retimes the path with B-spline fitting so that the path meets the waypoint times.
1. It recovers the hand.

Hand recovery relies on **contact correspondences**, which are per-frame point matches between the hand and object meshes. After the object path is set, the method retrieves the most recent original correspondence set mapped to each output frame. It then solves an inverse-kinematics (IK) problem. IK means finding the hand joint and pose parameters whose mesh positions meet the constraints. Here, the solution must reduce the matched-point distances while penalizing hand–barrier intersections. A light smoothing step follows. The correspondences couple the hand to the object at intermediate output frames.

### 3. Where interpolation breaks

The authors built a baseline to test this mechanism. It applies rigid transforms at input frames that map to output frames, then spline-interpolates poses at the frames in between. At these known control points, the baseline can preserve the hand–object relationship. Between them, its hand interpolation is independent of the moving object.

In the authors' example, strong temporal stretching leaves few mapped input frames between output frames 529 and 750. The mapped control timesteps preserve the grasp. Across the stretched interval, however, the interpolated hand can intersect the object or lose contact. In this example, the contact-based method maintains the grasp in the illustrated intermediate frames. This is a qualitative example, and the paper reports no aggregate numerical baseline comparison.

The quantitative evidence covers 12 warp configurations built from four GRAB human-manipulation demonstrations in kitchen-like scenes. The metric, $D_{WO}$, is the mean distance between wrist position and object center across timesteps. At the 3.5 mm IK optimization threshold, the mean absolute change in $D_{WO}$ between original and warped trajectories was 1.0 mm. This value is a distance comparison. It is not a contact-distance score or a task-success measurement.

At that same threshold, the full pipeline took an average of 276.10 seconds (about 4.6 minutes) across the 12 configurations. These runs were CPU-only on an Apple M2 SoC with 16 GB memory.

### 4. Scope

The paper's contribution is an upstream trajectory-warping tool. It treats the object route and the hand's contact as a coupled problem. The authors note that faster techniques may suffice for mild warps without temporal shifts or barriers.

The evaluation has several limits:

- It is in simulation and isolation, so it does not show that generated data improves a learning pipeline or transfers to real robots.
- The method assumes rigid objects and convex barriers.
- Narrow gaps can make iterative barrier resolution fail, and an object route may leave too little clearance for the hand.
- Contact correspondences are reused from the last mapped frame rather than interpolated, so rapid finger or fine-grained contact changes may not be represented.
