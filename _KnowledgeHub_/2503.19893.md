# Visuo-Tactile Object Pose Estimation for a Multi-Finger Robot Hand with Low-Resolution In-Hand Tactile Sensing

> [!summary] Summary
> Researchers develop a visuo-tactile framework that combines low-resolution tactile sensing with visual pose estimation through factor graph optimization, enabling real-time object pose tracking at 13.3 Hz even under high occlusion while using simple binary tactile sensors distributed across a robot hand's interior surface.

## Problem

- Vision-based object pose estimation becomes inaccurate when objects are occluded by robot hands during manipulation
- High-resolution tactile sensors are expensive and impractical for many robotic applications
- Effectively fusing visual, tactile and proprioceptive information in real-time is challenging

## Method

- Factor graph optimization framework that combines visual pose estimates with binary tactile measurements
- Low-resolution tactile sensor pads distributed across robot hand interior
- Geometric constraints derived from hand configuration to prevent physically impossible poses

## Results

- Achieved real-time pose estimation at **13.3** Hz on a real robot setup
- Significantly improved pose accuracy compared to vision-only approaches under occlusion
- Successfully demonstrated on a custom 15-DoF robot hand with 16 tactile sensor pads
- Robust to varying levels of visual noise while maintaining geometric consistency

## Takeaways

> [!tip] Key Insights
> - Simple binary tactile sensors are sufficient when properly integrated with visual information
> - Factor graph formulation enables effective fusion of multiple sensor modalities
> - Geometric constraints from hand configuration help ensure physically plausible pose estimates
