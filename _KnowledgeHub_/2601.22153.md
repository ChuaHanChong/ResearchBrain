# DynamicVLA: A Vision-Language-Action Model for Dynamic Object Manipulation

> [!summary] Summary
> DynamicVLA, from S-Lab at Nanyang Technological University, introduces a compact 0.4B parameter vision-language-action model alongside the Dynamic Object Manipulation (DOM) benchmark, enabling robots to robustly manipulate moving objects in real-world scenarios. The model achieved an average 47.06% success rate on the DOM simulation benchmark, notably outperforming prior baselines, and demonstrated consistent performance on physical robots.

## Problem

- Existing Vision-Language-Action (VLA) models primarily focus on static manipulation, struggling with the complexities of dynamic objects in real-world environments.
- High inference latency in current VLA models creates a "perception–execution gap," leading to outdated actions and task failures when objects are in continuous motion.
- There is a lack of large-scale, standardized datasets and benchmarks specifically designed for evaluating VLA models in dynamic object manipulation tasks.

## Method

- Developed **DynamicVLA**, a compact ==0.4-billion-parameter VLA model== leveraging a ==convolutional vision encoder (FastViT)== and a ==truncated language backbone== for improved efficiency and speed.
- Introduced two execution mechanisms: =="Continuous Inference"== to pipeline inference and execution, and =="Latent-aware Action Streaming"== to explicitly manage temporal misalignment by prioritizing the most recent action predictions.
- Created the ==Dynamic Object Manipulation (DOM) benchmark==, a large-scale dataset with ==200K synthetic== and ==2K real-world episodes==, collected via automated pipelines to provide diverse dynamic tasks for evaluation.

## Results

- **DynamicVLA** achieved an average success rate of **47.06%** on the DOM simulation benchmark, significantly surpassing the best baseline (GR00T-N1.5 at **13.05%**) and reducing task completion time to **8.53 seconds**.
- In real-world evaluations, DynamicVLA consistently outperformed baselines across various dynamic tasks on Franka and PiPER robots, achieving success rates ranging from **50.0%** to **78.3%**.
- Ablation studies confirmed the crucial role of Continuous Inference (increasing SR by **10.95%**) and Latent-aware Action Streaming (increasing SR by **7.34%**) in mitigating latency and temporal misalignment, respectively.

## Takeaways

> [!tip] Key Insights
> - Minimizing inference latency and explicitly addressing temporal misalignment are critical factors for achieving robust and responsive dynamic object manipulation with VLA models.
> - Compact model architectures (0.4B parameters) can effectively achieve high performance in dynamic tasks when paired with efficient execution mechanisms, demonstrating that large parameter counts are not always necessary.
> - Automated data collection, including a "real-world simulator" approach for physical robots, is essential for building scalable and diverse datasets for dynamic robotic tasks, bridging the sim-to-real gap.
