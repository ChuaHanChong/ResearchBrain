# Interactive Language: Talking to Robots in Real Time

> [!summary] Summary
> Robotics at Google presents a framework for real-time, interactive natural language control of physical robots, achieving a 93.5% success rate on over 87,000 unique short-horizon commands and enabling humans to guide robots to complex, long-horizon goals with 85.0% success. The approach also facilitates simultaneous control of multiple robots by a single operator using spoken language, supported by a large-scale language-annotated dataset and a transformer-based policy.

## Problem

- Real-world robots struggled to respond capably and interactively to a large, diverse set of natural language commands in real time.
- Existing language-interactive systems often exhibited slow response times, used blocking parameterized skills, or relied on simplifying assumptions, hindering fluid human-robot collaboration.
- The absence of large-scale, high-quality language-labeled robot datasets impeded the development of robust language-conditioned visuomotor policies.

## Method

- Developed an "Interactive Language" imitation learning framework encompassing high-throughput data collection and real-time interaction.
- Introduced "Event-Selectable Hindsight Relabeling" to efficiently create a large-scale dataset of language-annotated robot trajectories from raw teleoperation.
- Utilized LAVA, a transformer-based policy architecture, to fuse multi-scale visual features and language embeddings for continuous visuomotor control.

## Results

- A single robot policy achieved an estimated 93.5% average success rate on 87,588 unique short-horizon natural language commands in a real-world setting.
- The framework enabled humans to guide robots to 85.0% average success on over 100,000 distinct long-horizon compositional rearrangement goals using real-time language feedback.
- One human operator successfully controlled four robots simultaneously via spoken natural language to accomplish complex long-horizon tasks.

## Takeaways

> [!tip] Key Insights
> - Real-time natural language feedback is critical for successful completion of complex, long-horizon, contact-rich manipulation tasks, increasing success rates from 25% to 85%.
> - Scaling data collection, particularly with event-selectable hindsight relabeling, enables a single robot policy to master a diverse repertoire of over 87,000 unique natural language-conditioned skills.
> - The development of robust short-horizon language-conditioned skills allows for advanced applications such as a single human operator simultaneously guiding multiple robots via spoken language.
