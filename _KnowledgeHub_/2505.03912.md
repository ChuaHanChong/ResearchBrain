# OpenHelix: A Short Survey, Empirical Analysis, and Open-Source Dual-System VLA Model for Robotic Manipulation

> [!summary] Summary
> A comprehensive analysis and open-source implementation of dual-system Vision-Language-Action (VLA) models demonstrates improved robotic manipulation capabilities through prompt tuning and auxiliary task learning, achieving strong performance in dynamic scenarios while reducing computational costs compared to traditional VLA approaches.

## Problem

- Existing VLA models for robotics are computationally expensive and difficult to deploy in real-time applications
- Limited open-source implementations and standardized evaluation frameworks hinder research progress
- Direct fine-tuning of pre-trained VLAs on robotic data leads to performance degradation

## Method

- Development of OPENHELIX, a dual-system architecture combining large pre-trained models with lightweight action generators
- Implementation of prompt tuning strategy with frozen MLLM parameters
- Addition of auxiliary tasks to leverage multimodal reasoning capabilities

## Results

- Successful demonstration of language instruction generalization in enriched testing scenarios
- Improved robustness in dynamic object manipulation tasks through integrated model layers
- Enhanced task performance through auxiliary learning objectives
- Release of accessible open-source implementation with standardized evaluation framework

## Takeaways

> [!tip] Key Insights
> - Projector pre-alignment is critical for connecting upstream and downstream models
> - Visual information significantly improves performance compared to language-only models
> - Current MLLM latent embeddings show limited sensitivity to environmental changes
> - Prompt tuning achieves strong performance while maintaining generalization capability
