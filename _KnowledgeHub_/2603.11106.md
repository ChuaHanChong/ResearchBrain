# RC-NF: Robot-Conditioned Normalizing Flow for Real-Time Anomaly Detection in Robotic Manipulation

> [!summary] Summary
> Researchers from Fudan University and Singapore Management University present RC-NF, a robot-conditioned normalizing flow for real-time, unsupervised anomaly detection in robotic manipulation tasks. This system detects deviations in robot execution and object motion within 100 milliseconds, significantly improving the robustness and adaptability of Vision-Language-Action (VLA) models in dynamic environments.

## Problem

- Vision-Language-Action (VLA) models, trained via imitation learning, exhibit fragility and frequent failures when encountering Out-of-Distribution (OOD) conditions in complex, dynamic real-world environments.
- Existing failure detection methods are limited: classification-based approaches lack scalability for combinatorial failure modes, while VLM-based monitoring incurs multi-second latency, preventing real-time intervention.
- There is a need for a low-latency, unsupervised anomaly detection system that can learn from only successful demonstrations and provide timely signals for corrective actions.

## Method

- Introduced **RC-NF** (==Robot-Conditioned Normalizing Flow==), an unsupervised model that leverages ==Normalizing Flows== conditioned on robot execution state and a task embedding to learn the joint probability distribution of successful task execution.
- Developed the ==Robot-Conditioned Point Query Network (RCPQNet)== as a novel ==affine coupling layer== within the flow, which uses ==FiLM modulation== and dual-branch point feature encoding to decouple and integrate robot state and object features effectively.
- **RC-NF** operates in parallel with VLA policies, continuously computing an ==anomaly score (negative log-likelihood)== and signaling deviations for either state-level rollback (e.g., homing procedure) or task-level replanning.

## Results

- RC-NF achieved state-of-the-art performance on the LIBERO-Anomaly-10 benchmark, outperforming the best baseline by approximately **8%** in AUC and **10%** in Average Precision on average across various anomaly types.
- Demonstrated real-time anomaly detection with a latency under **100 ms** on a physical robot, enabling immediate intervention in the control loop.
- Successfully enhanced the adaptability and robustness of VLA policies in real-world scenarios by enabling automated recovery from state-level OOD (e.g., object repositioning) and facilitating task replanning for task-level OOD (e.g., unexpected environmental changes).

## Takeaways

> [!tip] Key Insights
> - Conditioning normalizing flows with task embeddings and precise robot states enables the system to detect subtle, task-specific deviations from intended manipulation trajectories.
> - Decoupling robot-state information (as query tokens) and object features (as memory tokens) in a cross-attention mechanism within the flow allows for robust and fine-grained multimodal interaction without feature entanglement.
> - Unsupervised learning from only successful demonstrations is sufficient for developing a highly effective real-time anomaly detection system in robotics, avoiding the need for extensive failure data collection.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Recent advancements in Vision-Language-Action (VLA) models, often built upon Vision-Language Models (VLM), have expanded the capabilities of robots to perform complex manipulation tasks based on natural language prompts. These models typically rely on imitation learning from expert demonstrations to map high-level instructions to low-level control actions. However, a significant challenge arises when these VLA models are deployed in dynamic, real-world environments, where conditions may deviate from their training distribution. Such "Out-of-Distribution" (OOD) scenarios can lead to task failures and unreliable operation.

The broader research landscape for robust robotic manipulation includes efforts to improve generalization, adapt to novel situations, and detect failures at runtime. Prior approaches to runtime monitoring generally fall into two categories. One category frames failure detection as a robotic state classification problem, often requiring explicit enumeration of abnormal conditions or predefined preconditions. This method faces limitations in scalability and adaptability to the combinatorial variability of real-world manipulation tasks. A second category involves integrating high-level VLMs into dual-system architectures or dedicated monitoring systems like Sentinel. While these methods leverage advanced reasoning capabilities, they typically incur multi-second latency due to the multi-step inference required, hindering timely intervention in robotic control loops.

This research positions itself as addressing the need for a real-time, low-latency, and unsupervised anomaly detection system specifically designed for robotic manipulation. It draws inspiration from unsupervised anomaly detection techniques used in other domains, such as pedestrian behavior monitoring, to develop a method that does not require explicit examples of failures during training. By focusing on learning the distribution of normal task execution and detecting deviations, this work aims to provide a responsive monitoring solution that complements existing VLA models, thereby enhancing their robustness and adaptability in dynamic and unpredictable environments.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a real-time monitoring model, termed Robot-Conditioned Normalizing Flow (RC-NF), capable of detecting anomalies in robotic manipulation by assessing the consistency between the robot's execution state, the object's motion trajectory, and the intended task. This model aims to provide timely intervention signals for Vision-Language-Action (VLA) systems operating in dynamic and Out-of-Distribution (OOD) environments.

The motivation for this work stems from several limitations observed in current VLA models and existing robotic monitoring approaches:

1. **VLA Model Fragility in OOD Conditions:** While VLA models trained via imitation learning demonstrate proficiency in various tasks, their performance degrades significantly in dynamic real-world environments. These environments frequently present OOD scenarios, which are not covered by the training data, leading to failures and an inability to operate reliably. There is a recognized need for systems that can detect when a robot's execution diverges from its intended task under such conditions.

2. **Limitations of Traditional Monitoring Methods:**
 - **Classification-based approaches** to failure detection require exhaustive enumeration of potential abnormal conditions or manually defined preconditions. This approach is impractical for complex manipulation tasks due to the vast and combinatorial nature of possible failure modes in real-world settings.
 - **High-level VLM-based monitoring systems**, while capable of sophisticated reasoning, typically involve multi-step inference processes that result in multi-second latency. This delay is prohibitive for real-time robotic control, where timely intervention is critical to prevent the accumulation of errors or task failures.

3. **Need for Unsupervised and Low-Latency Detection:** To overcome these limitations, the authors seek an unsupervised anomaly detection method that can learn from only successful task demonstrations, obviating the need for explicit failure data. Crucially, the system must operate with very low latency (under 100 ms) to enable immediate feedback and intervention within the robot's control loop. This rapid response is essential for correcting behavioral drift before it leads to irreversible task failure.

4. **Addressing Different OOD Granularities:** The research is motivated by the understanding that OOD conditions can manifest at different levels. **Task-level OOD** occurs when the overall task instruction no longer aligns with the environment (e.g., a required object disappears). **State-level OOD** involves deviations in the robot's physical configuration or object trajectory while the task instruction remains valid (e.g., an object slips from the gripper). The objective is to provide a monitoring signal that can differentiate and facilitate appropriate handling for both types of OOD.

5. **Enhancing VLA Robustness and Adaptability:** Ultimately, the work aims to develop a "plug-and-play" module that can integrate seamlessly with existing VLA models (e.g., $\pi_0$) without requiring architectural modifications. This integration is intended to provide real-time OOD signals that enable corrective behaviors such as state-level rollback or task-level replanning, thereby enhancing the overall robustness and adaptability of VLA-based robotic systems.

### 3. Methodology and Approach

The proposed methodology introduces the Robot-Conditioned Normalizing Flow (RC-NF) model, an unsupervised, real-time anomaly detection system for robotic manipulation. RC-NF builds upon the principles of Normalizing Flow (NF) and integrates robot-specific and task-aware conditioning to model the joint probability distribution of successful task execution.

#### 3.1. Normalizing Flow Foundation

The work leverages Normalizing Flows, which are neural networks capable of modeling complex probability distributions by transforming them into a simple, tractable distribution (e.g., a Gaussian). This transformation is invertible and differentiable, allowing for explicit probability density estimation. The model's architecture is based on the Glow model, comprising a sequence of invertible transformations, each consisting of an ActNorm layer, a permutation layer (1x1 convolution), and an affine coupling layer. The affine coupling layer splits its input into two parts, using one part to compute scale and shift parameters for an affine transformation applied to the other part, thus ensuring invertibility and tractable Jacobian determinants.

#### 3.2. Robot-Conditioned Normalizing Flow (RC-NF)

RC-NF extends the standard NF by conditioning the flow on specific robotic and task-related information. The model is trained exclusively on data from successful demonstrations.
- **Conditioning Variables (c):** The conditioning context `c` comprises the robot's execution state `s` and a task embedding `τ`.
 - **Robot State (s):** Includes T-dimensional joint state, gripper state, and Cartesian pose over a sliding window.
 - **Task Embedding (τ):** Derived from the task prompt, it is mapped to a surface vector on a T-dimensional hypersphere using spherical uniform encoding. This encoding aims to maximize separation between task embeddings in the latent space.
- **Object Representation (x):** Visual input from the camera stream is processed by SAM2 (Segment Anything Model 2) to obtain object segmentation masks. These masks are then grid-sampled to extract a point-set representation `X` of the manipulated objects, specifically their 2D coordinates over a temporal sliding window.
- **Conditional Mapping:** RC-NF maps the object point set `x` to a Gaussian latent distribution `Z ~ N(μ_task, I)`, where the mean `μ_task` is obtained by broadcasting the task embedding `τ`. The conditional likelihood `p_X|C(x|c)` is computed using the change-of-variables formula, and its negative log-likelihood serves as the anomaly score.

#### 3.3. Robot-Conditioned Point Query Network (RCPQNet)

A core component of RC-NF is the novel affine coupling layer, RCPQNet, which generates the scale `γ` and shift `β` parameters for the affine transformations in the flow. RCPQNet is designed to decouple and integrate robot state and object features while preserving their interaction.
- **Input Processing:** The point set `x` (after ActNorm and Permute layers) is split along the temporal dimension into `x_b` and `x_t`. `x_b` is used as input to RCPQNet along with the conditioning context `c`.
- **Task-aware Robot-Conditioned Query:** The robot state `s` is projected into a latent space and then modulated by the task embedding `τ` using FiLM (Feature-wise Linear Modulation). This produces query tokens that encode both robot context and high-level task goals.
- **Dual-Branch Point Feature Encoding:** This component generates memory tokens from the object point set `x_b`.
 - **Dynamic Shape Branch:** Centers and normalizes each frame's point set to extract shape features, removing translation and scale effects. Features are processed through an MLP, then a GRU for temporal dependencies, and finally a Transformer encoder.
 - **Positional Residual Branch:** Focuses on compensating for the positional information lost during shape normalization, processing the raw point set through a similar MLP-GRU-Transformer sequence.
 - The features from both branches are combined to form memory vectors.
- **Cross-Attention:** The query tokens (from task-aware robot conditioning) and memory tokens (from dual-branch point encoding) interact through cross-attention within a transformer architecture, allowing the model to learn context-aware affine parameters.

#### 3.4. Anomaly Detection and Handling

- **Detection:** During inference, RC-NF operates in parallel with the VLA policy network, continuously observing the visual stream and robot state. The negative log-likelihood of the current configuration, given the task conditions, is computed as the anomaly score. A higher score indicates greater deviation from the learned normal distribution. A static threshold `Upper_T`, calibrated from successful expert demonstrations, is used to trigger an anomaly signal. Debiasing is applied during training to ensure temporal smoothness of anomaly scores.
- **Handling:** Upon anomaly detection, RC-NF provides a signal to a higher-level system to initiate corrective actions.
 - **State-level OOD:** If the task intent remains valid but the robot's trajectory or object state drifts (e.g., object slips), a "homing procedure" is activated. This involves a localized task rollback or trajectory adjustment to return the robot to a state within the nominal distribution.
 - **Task-level OOD:** If the environment no longer matches the instruction (e.g., a drawer closes unexpectedly), RC-NF alerts a high-level controller (human or LLM planner) to initiate task replanning, generating new sub-tasks consistent with the altered environment.

#### 3.5. Experimental Setup

- **Dataset:** LIBERO-Anomaly-10 benchmark, built upon LIBERO-10. It includes three manipulation-specific anomaly types: Gripper Open, Gripper Slippage, and Spatial Misalignment. Anomalies are labeled with a `t_anomaly` timestamp.
- **Baselines:** Two categories: VLM-based monitoring (GPT-5, Gemini 2.5 Pro, Claude 4.5 via Sentinel prompts) and flow-based methods (FailDetect).
- **Evaluation Metrics:** Area Under the ROC Curve (AUC) and Average Precision (AP).
- **Real-World Setup:** Franka Research 3 robotic arm, Intel RealSense D435 depth cameras (wrist and third-person views). The $\pi_0$ VLA model is used as the imitation policy baseline. Bounding boxes for SAM2 are generated using computer graphics in simulation and Gemini 2.5 Pro in the real world.

### 4. Main Findings and Results

The research provides quantitative and qualitative results demonstrating the performance of RC-NF in anomaly detection and its utility in real-world robotic manipulation.

#### 4.1. Performance Comparison on LIBERO-Anomaly-10 Benchmark

RC-NF achieved state-of-the-art performance across all tested anomaly types on the LIBERO-Anomaly-10 benchmark.
- RC-NF surpassed the best baseline by approximately 8% in AUC and 10% in AP on average.
- **Comparison with VLM-based methods:** GPT-5, Gemini 2.5 Pro, and Claude 4.5 showed moderate performance on Gripper Open and Gripper Slippage but exhibited near-random performance (AUC ≈ 0.5, AP ≈ 0.4) on Spatial Misalignment. This indicates a difficulty for VLMs in aligning visual semantics with precise spatial reasoning for specific manipulation deviations. RC-NF demonstrated significantly higher performance in Spatial Misalignment (AUC 0.9676, AP 0.9585), suggesting its ability to compute deviations from the nominal trajectory without relying on high-level semantic understanding.
- **Comparison with FailDetect:** RC-NF outperformed FailDetect, a flow-matching model. This is attributed to RC-NF's refined point-set representation (from SAM2 segmentation) compared to FailDetect's raw image features, and RC-NF's decoupled processing of robot state (as query tokens) and object point features (as memory tokens), which allows for efficient multimodal interaction without feature entanglement.
- **Anomaly Score Visualization:** Visualizations of anomaly scores (Figure 4) demonstrated that RC-NF maintained stable low scores before `t_anomaly` and exhibited a rapid increase after an anomaly occurred. RC-NF's scores were noted to be superior in smoothness, stability, and accuracy compared to FailDetect.

#### 4.2. Ablation Study of RCPQNet Components

An ablation study was conducted to evaluate the contribution of the key components within the Robot-Conditioned Point Query Network (RCPQNet).
- **Effect of Task-Aware Robot-Conditioned Query:**
 - **Without Task Embedding:** Removing the task embedding led to a substantial performance drop, particularly in Spatial Misalignment, where performance decreased nearly threefold. This suggests that task embeddings are critical for encoding spatial intent and differentiating task-specific anomalies. The model without task embedding could only detect dataset-level OODs, not task-specific deviations.
 - **Without Robot State:** The absence of robot-state features resulted in the largest drop in AUC for Gripper Open anomalies. This indicates that robot-state information is essential for reasoning about the relative motion between the robot and the object, which is crucial for detecting gripper-related failures that may not directly involve object displacement.
- **Effect of Dual-Branch Point Feature Encoding:**
 - **Without Positional Residual Branch:** Removing this branch led to a moderate performance decline (average AUC ~0.89), suggesting that absolute spatial information complements the dynamic shape cues by preserving overall shifts in robot-object motion.
 - **Without Dynamic Shape Branch:** This ablation resulted in the greatest performance degradation (average AUC ~0.68), especially for Spatial Misalignment. This highlights the importance of the Dynamic Shape branch in capturing relative movements between objects as shape variations, which provides strong evidence for abnormality, particularly in scenarios involving temporal shape evolution.

#### 4.3. Real-World Evaluation

Real-world experiments demonstrated RC-NF's effectiveness in enhancing the adaptability and robustness of VLA policies (e.g., $\pi_0$) and its successful transfer from simulation.
- **Low Latency:** RC-NF detected anomalies within 100 ms on an Nvidia GeForce RTX 3090 GPU, enabling real-time intervention.
- **Task-Level Anomaly Handling:** In a scenario where the task was "placing the blue ball into the open drawer," and the drawer unexpectedly closed, the $\pi_0$ policy alone failed. With RC-NF integrated, the system detected the anomaly, paused execution, and signaled a high-level controller for task replanning (e.g., reset the ball and open the drawer), leading to successful task completion.
- **State-Level Anomaly Handling:**
 - When a ball was manually repositioned on the table during execution, RC-NF promptly signaled an anomaly and activated a homing procedure to re-align the trajectory, allowing the robot to recover. In contrast, $\pi_0$ continued to move with an empty gripper.
 - Similarly, when the ball rolled behind the gripper, RC-NF immediately detected the anomaly, adjusted the trajectory to the ball's new position, and seamlessly returned control to the VLA once the anomaly score normalized. Without RC-NF, $\pi_0$ would attempt to grasp air.

These results collectively indicate that RC-NF provides low-latency, accurate feedback for both task-level and state-level OOD anomalies, enhancing the robustness and situational awareness of VLA models in physical environments without requiring architectural modifications.

### 5. Significance and Potential Impact

The development of Robot-Conditioned Normalizing Flow (RC-NF) has several significant implications and potential impacts on the field of robotic manipulation and trustworthy AI systems:

1. **Enhanced Robustness and Adaptability of VLA Models:** RC-NF addresses a critical limitation of current Vision-Language-Action (VLA) models, which often struggle with Out-of-Distribution (OOD) conditions in dynamic real-world environments. By providing a real-time monitoring mechanism, RC-NF enables VLA models to operate more reliably, preventing task failures and enhancing their adaptability to unforeseen changes or perturbations. This contributes to making VLA-based robotic systems more practical for deployment outside controlled laboratory settings.

2. **Real-Time Intervention and Safety:** The ability of RC-NF to detect anomalies within 100 milliseconds is a key technical achievement. This low latency is crucial for enabling timely intervention in closed-loop robotic control, preventing minor deviations from escalating into catastrophic failures. This capability has a direct impact on the safety of human-robot interaction and the protection of robotic hardware and manipulated objects.

3. **Unsupervised Anomaly Detection for Robotics:** RC-NF's unsupervised training approach, which relies solely on successful task demonstrations, eliminates the need for extensive and costly collection of failure data. This reduces the burden of dataset creation and allows the system to generalize to novel types of anomalies without explicit prior knowledge, making it a more scalable and practical solution for various robotic tasks.

4. **Comprehensive Anomaly Handling:** The framework's capacity to distinguish between and provide appropriate handling for both state-level and task-level OOD situations (e.g., state rollback versus task replanning) bridges a gap between low-level execution monitoring and high-level cognitive processes. This integrated approach can lead to more intelligent and resilient robotic systems that can self-recover from a broader spectrum of failures.

5. **Plug-and-Play Integration:** The design of RC-NF as a "plug-and-play" module means it can be seamlessly integrated into existing VLA model architectures (such as $\pi_0$) without requiring modifications to the underlying policy. This modularity facilitates adoption and allows current VLA research to benefit from enhanced robustness without requiring fundamental architectural changes.

6. **Advancement in Multi-modal Feature Processing:** The introduction of the Robot-Conditioned Point Query Network (RCPQNet) represents a methodological contribution in how multi-modal information (robot state, task embedding, object point sets) is effectively fused and decoupled within normalizing flows. This structured approach to feature interaction can inspire future work in building robust perception and control systems for robotics.

7. **New Benchmark for Research:** The creation of LIBERO-Anomaly-10, a benchmark specifically designed for manipulation-specific anomaly detection, provides a valuable resource for the research community. This benchmark facilitates standardized evaluation and comparison of future anomaly detection methods, accelerating progress in the field.

In summary, RC-NF represents a step towards more robust and adaptive robotic systems capable of operating autonomously in complex, dynamic environments by providing a real-time, fine-grained, and unsupervised mechanism for detecting and handling execution anomalies.
