# Science-T2I: Addressing Scientific Illusions in Image Synthesis

> [!summary] Summary
> Researchers from NYU, UW, UPenn, and UCSD develop a framework to improve scientific accuracy in text-to-image synthesis through a 20K expert-annotated dataset of scientific phenomena, a specialized reward model (SCISCORE), and a two-stage fine-tuning approach that achieves 50% improvement in scientific realism while matching human-level evaluation capabilities.

## Problem

- Text-to-image models generate visually appealing but scientifically inaccurate images
- Lack of datasets and metrics specifically focused on evaluating scientific realism in generated images
- Existing evaluation methods rely heavily on complex prompt engineering

## Method

- Created **SCIENCE-T2I** dataset with 20K image pairs and 9K prompts covering physics, chemistry, and biology
- Developed **SCISCORE** ==reward model== extending **CLIP** architecture for scientific accuracy evaluation
- Implemented two-stage fine-tuning process combining supervised and online fine-tuning with masking

## Results

- SCISCORE achieves 5% improvement comparable to experienced human evaluators
- Outperforms large multimodal models like GPT-4o in capturing fine-grained visual details
- Fine-tuned FLUX model shows over 50% improvement in scientific accuracy
- Demonstrates strong generalization across both simple and complex scientific scenes

## Takeaways

> [!tip] Key Insights
> - Scientific realism can be improved through targeted dataset creation and specialized reward models
> - Implicit prompt alignment and image encoder enhancement improve understanding of scientific concepts
> - Performance gaps exist between subject-oriented and condition-oriented generation tasks
