# CLAP: Contrastive Latent Action Pretraining for Learning Vision-Language-Action Models from Human Videos

> [!summary] Summary
> The CLAP framework enables Vision-Language-Action (VLA) models to learn robot manipulation skills from diverse human videos by explicitly aligning visual latent actions with physically executable robot trajectories using contrastive pretraining. This approach, which includes a dual-formulation VLA, achieves state-of-the-art performance on real-world bimanual tasks and the LIBERO benchmark, demonstrating improved skill transfer and robustness to environmental perturbations.

## Problem

- Scarcity of high-quality, diverse robotic data severely limits the scalability of Vision-Language-Action (VLA) models for real-world manipulation.
- Existing Latent Action Models (LAMs) learned from human videos suffer from visual entanglement, failing to disentangle pure manipulation skills from irrelevant visual noise.
- Developing VLA models that simultaneously provide high-level semantic reasoning for task planning and precise, high-frequency control for physical interaction is challenging.

## Method

- Introduces **Contrastive Latent Action Pretraining (CLAP)** to align visual latent actions inferred from human videos with a ==physically grounded, quantized latent action space== derived from robot trajectories using ==contrastive learning==.
- Develops a ==dual-formulation VLA framework==: **CLAP-NTP** for high-level reasoning and **CLAP-RF** for high-frequency, precise continuous control.
- Integrates a ==Knowledge Matching (KM) regularization== strategy to mitigate catastrophic forgetting when fine-tuning on specific tasks or embodiments.

## Results

- **CLAP-RF** achieved a **61.0%** mean success rate on real-world bimanual manipulation tasks with the Astribot S1 robot, outperforming generalist baselines.
- Established new generalist SOTA on the **LIBERO benchmark** with **91.0%** average success rate, including **82%** on LIBERO-Long for complex long-horizon tasks.
- **CLAP-NTP** demonstrated strong zero-shot generalization to unseen objects, boosting "Make Bouquets" success to **35%** with human data integration.

## Takeaways

> [!tip] Key Insights
> - Explicitly aligning visual dynamics from human videos with physically executable robot actions via contrastive learning is key to learning disentangled, transferable manipulation skills.
> - A dual-formulation VLA architecture, combining an autoregressive model for high-level reasoning (CLAP-NTP) and a continuous flow-based policy for precise control (CLAP-RF), effectively balances different robotic requirements.
> - Utilizing a quantized latent action codebook derived from robot trajectories provides a robust and shared "physical language" for grounding actions across heterogeneous data sources.
