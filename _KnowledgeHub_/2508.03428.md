# Residual Neural Terminal Constraint for MPC-based Collision Avoidance in Dynamic Environments

> [!summary] Summary
> A novel Residual Neural Terminal Constraint (RNTC) approach combines learning-based real-time maximal safe set approximation with Model Predictive Control (MPC) for collision avoidance in dynamic environments. By learning a non-negative residual, the method guarantees that the derived safe sets are at least as robust as those based on Signed Distance Functions, achieving a 100% collision-free rate on a mobile robot and up to 30% higher success rates in simulation compared to state-of-the-art baselines.

## Problem

- Ensuring MPC recursive feasibility and safety in dynamic, unstructured environments requires real-time determination of a control-invariant terminal set.
- Hamilton-Jacobi (HJ) Reachability Analysis provides formal maximal safe sets but suffers from computational intractability for real-time, high-dimensional, and dynamic applications.
- Existing learning-based HJ approximation methods often assume static environments or do not provide formal safety guarantees, limiting their deployment in safety-critical robotic systems.

## Method

- The ==HJ value function==, representing the maximal safe set, is decomposed into F(x,t) - R(x,t), where F is the ==Signed Distance Function (SDF)== and R is a non-negative residual.
- A ==hypernetwork== processes environmental observations (future SDF sequences) to parametrize a lightweight main network (MLP) that computes the non-negative residual R(x,t) in real-time.
- This learned residual is then used to form a terminal constraint V(x,t) >= 0 within an **RNTC-MPC** framework, ensuring the learned safe set is at least as safe as the SDF-based region.

## Results

- Achieved up to a **30%** higher success rate in collision avoidance in simulation experiments compared to state-of-the-art baselines like DCBF-MPC, with comparable real-time performance.
- Demonstrated a **100%** collision-free success rate in hardware experiments on a mobile robot, significantly outperforming DCBF-MPC (**70%**), VO-MPC (**70%**), and SDF-MPC (**40%**) while maintaining the lowest travel time.
- The residual learning architecture exhibited **five times** faster training convergence and higher accuracy compared to directly learning the value function, consistently classifying unsafe states correctly.

## Takeaways

> [!tip] Key Insights
> - Decomposing the HJ value function as SDF minus a non-negative residual provides a strong inductive bias and a design-time safety guarantee that the learned safe set is at least as conservative as the SDF-defined safe region.
> - Hypernetworks can effectively process time-varying environmental observations to adaptively parameterize a lightweight neural network for real-time approximation of control-invariant terminal sets in dynamic environments.
> - The Combined MSE and Exponential (CME) loss function is effective for training value function approximations, improving convergence and ensuring correct zero-level set identification critical for safety.

## Detailed Report

### 1. How this work fits into the broader research landscape

This work is situated within the field of mobile robotics, specifically focusing on motion planning and control for collision avoidance in complex and dynamic environments. The broader challenge is to enable robots to operate safely and efficiently alongside humans and other moving agents, especially when the robot has limited actuation or when assuming reciprocal collision avoidance is unsafe (e.g., a robot avoiding a human-operated forklift).

**Current State of the Art and Limitations:**
Model Predictive Control (MPC) is a prominent technique for motion planning, but its recursive feasibility and safety in critical applications depend on the design of a control-invariant terminal set. Determining such a set, especially in dynamic environments, is challenging.

- **Traditional Collision Avoidance:** Methods like Signed Distance Functions (SDFs) and Velocity Obstacles (VO) are commonly used for defining collision avoidance constraints within MPC. However, these often do not explicitly address the terminal set design, instead relying on sufficiently long prediction horizons for implicit recursive feasibility. Discrete-time Control Barrier Functions (CBF) offer another approach but also typically lack explicit terminal set considerations.
- **Hamilton-Jacobi (HJ) Reachability Analysis:** This framework can compute maximal control-invariant sets, known as maximal safe sets. It relies on solving the Hamilton-Jacobi-Bellman Variational Inequality. The primary limitation of HJ reachability is its computational intensity ("curse of dimensionality"), rendering it impractical for real-time applications in high-dimensional or time-critical systems, particularly when complete *a priori* environment knowledge is unavailable, as is often the case in dynamic settings.
- **Learning-based Approximations of HJ Reachability:** Recent research has explored using learning, particularly neural networks, to approximate HJ value functions to overcome computational hurdles. Some methods employ parameter conditioning or high-dimensional environment observations. However, these approaches often assume static environments or lack formal guarantees regarding approximation error or safety. The work in, which uses hypernetworks for learning maximal safe sets in static environments, is particularly relevant as a precursor to this paper.

**This Paper's Contribution to the Landscape:**
This research addresses the gap of providing real-time, learning-based approximation of maximal safe sets for MPC in *dynamic* environments, with an explicit safety guarantee. It extends prior work by:
1. Adapting learning-based HJ value function estimation to handle time-varying failure sets arising from dynamic obstacles.
2. Introducing a novel model architecture that leverages a mathematical property of the HJ value function (its relation to the SDF) to provide a design-time guarantee that the estimated safe set is at least as safe as an SDF-based approach. This offers a significant step towards more formally guaranteed learning-based safety in dynamic environments.

### 2. Key objectives and motivation

The primary objective of this research is to enable safe and efficient collision avoidance for mobile robots operating in dynamic, unstructured environments where other agents are present. This is particularly relevant in scenarios where the robot cannot rely on reciprocal collision avoidance (i.e., other agents avoiding the robot), or where the robot's limited actuation makes navigation challenging.

The specific technical objectives and motivations are:

- **Enhancing MPC Safety and Recursive Feasibility:** A crucial component of MPC for safety-critical applications is the design of a control-invariant terminal set. This set ensures that if the robot reaches the terminal state within the prediction horizon, it can safely remain within safe regions thereafter. The paper aims to provide a method for real-time estimation of this maximal safe set (derived from HJ reachability) to be used as a terminal constraint in an MPC formulation, thereby improving its recursive feasibility and overall safety guarantees.
- **Overcoming Computational Barriers of HJ Reachability:** While Hamilton-Jacobi (HJ) reachability analysis can formally define maximal safe sets, its high computational cost due to the "curse of dimensionality" makes it infeasible for online, real-time application in dynamic environments. A key motivation is to develop a learning-based approximation that can estimate these sets efficiently in real-time.
- **Addressing Time-Varying Environments:** Previous learning-based HJ approximation methods often assume static environments or complete *a priori* knowledge. This work aims to extend such approaches to dynamic environments where obstacle positions and velocities change, requiring the safe set to be time-varying and conditioned on current and predicted observations. The assumption is that observed moving obstacles will continue with constant velocity beyond the prediction horizon, allowing for conditioning of the safe set estimation.
- **Guaranteeing Safety in Learning-Based Approaches:** A significant challenge with purely data-driven learning for safety-critical systems is providing formal guarantees. The authors motivate their novel model architecture by exploiting a fundamental mathematical property: the HJ value function, V(x,t), is always less than or equal to the corresponding Signed Distance Function (SDF), F(x,t). This allows V(x,t) to be expressed as F(x,t) minus a non-negative residual function, R(x,t). By learning this non-negative residual, the method aims to inherently guarantee that the learned value function approximation is at least as safe as the SDF-based approach. This provides a strong inductive bias for the learning process and a safety assurance by design.
- **Achieving Real-Time Performance:** To integrate the learned safe set into an online MPC planner, the approximation must be computed in real-time. This motivates the use of a hypernetwork architecture, where a complex network processes environmental observations to rapidly parametrize a simpler, lightweight main network that computes the terminal constraint.

In essence, the research seeks to bridge the gap between formal safety guarantees offered by HJ reachability and the real-time demands of robotic navigation in dynamic, unknown environments by leveraging learning with inherent safety-preserving design principles.

### 3. Methodology and approach

The proposed method, named Residual Neural Terminal Constraint MPC (RNTC-MPC), integrates a learning-based approach for real-time approximation of the maximal safe set as a terminal constraint within a standard MPC framework.

#### 3.1. Problem Formulation

The work considers a nonlinear dynamical system (kinematic unicycle model for experiments) and a discrete-time MPC local planner. The MPC solves a finite-horizon optimal control problem, minimizing a quadratic cost function subject to system dynamics, state/control limits, stage constraints (collision avoidance), and a terminal constraint. The focus is on designing the terminal constraint function, h_{k+N}(x_{k+N}), such that its zero-superlevel set represents the maximal safe set in real-time.

#### 3.2. Hamilton-Jacobi Reachability Analysis in Time-Varying Environments

The maximal safe set S(t) is defined as the complement of the Backward Reachable Tube (BRT) B(t), which is the zero-sublevel set of the HJ value function V(x,t). The value function is computed by solving a Hamilton-Jacobi-Bellman Variational Inequality (HJB-VI) with a terminal condition V(x,T) = F(x,T), where F(x,t) is a failure function (SDF to obstacles). The control objective for computing V(x,t) is to maximize the time to reach the failure set. For dynamic environments, the method makes an assumption that moving obstacles continue with constant velocity beyond the prediction horizon to enable conditioning of the safe set estimation.

#### 3.3. Proposed RNTC-MPC Framework

The core of the methodology is a hybrid neural network model designed to estimate the HJ value function in real-time.

- **Decomposition of Value Function:** A key insight is that the HJ value function V(x,t) is always less than or equal to the corresponding Signed Distance Function (SDF) F(x,t) for all states x. This allows for the decomposition:
 `V_{k+N}(x) = F_{k+N}(x) - R_{k+N}(x)`
 where `R_{k+N}(x)` is a non-negative residual function (`R_{k+N}(x) ≥ 0`).
- **Neural Network Architecture:**
 - **Hypernetwork:** This is a deep Convolutional Neural Network (CNN) that processes local environmental observations. Its input is a sequence of future SDFs, specifically the tail of the SDF sequence (K SDFs from N-K+1 to N) corresponding to the predicted motion of M surrounding agents over the MPC prediction horizon. The hypernetwork's output is the set of parameters (Θ) for the main network.
 - **Main Network:** This is a lightweight Multi-Layer Perceptron (MLP). It takes the robot's state x as input and, using the parameters Θ provided by the hypernetwork, approximates the non-negative residual function `ˆR_{k+N}(x)`.
- **Non-negative Residual Guarantee:** To ensure `ˆR_{k+N}(x) ≥ 0` by design, the output layer of the main network applies the ELU(x) + 1 activation function. This guarantees that the estimated residual is always non-negative, and also maintains a non-zero gradient for all inputs, which aids training.
- **Value Function Approximation:** The final approximated HJ value function is `ˆV_{k+N}(x) = F_{k+N}(x) - ˆR_{k+N}(x)`. By construction, any state classified as unsafe by the SDF `F_{k+N}(x)` (i.e., `F_{k+N}(x) ≤ 0`) will also be classified as unsafe by `ˆV_{k+N}(x)` because `ˆR_{k+N}(x)` is non-negative. This provides a safety guarantee: the learned safe set is at least as safe as the SDF-based one.
- **MPC Integration:**
 - **Stage Constraints:** The first `N` SDFs, `F_{k+i}(x)`, are used as standard collision avoidance stage constraints `h_{k+i}(x) ≥ 0` for `i = 0, ..., N-1`.
 - **Terminal Constraint:** The learned value function approximation `ˆV_{k+N}(x)` serves as the terminal constraint `h_{k+N}(x) ≥ 0`.

#### 3.4. Training Procedure

The model is trained in a supervised fashion:

- **Dataset Generation:** A dataset of obstacle trajectories is generated (e.g., constant velocity model in simulation). For each trajectory, it is split into a "past" component (used to generate the SDF sequence input for the hypernetwork) and a "future" component.
- **Ground Truth Generation:** For each "future" segment, the true HJ value function `V_k(x)` is numerically computed using HJ reachability analysis (e.g., using `hj_reachability` library). This requires discretizing the state space grid.
- **Loss Function:** A Combined MSE and Exponential (CME) loss function is employed:
 `L = γ(V(x) − ˆV(x))^2 + (1 − γ) exp(−V(x)ˆV(x))`
 where `γ ∈` balances the components. This loss is designed for robust convergence, faster training, and to ensure that the optimal prediction `ˆy*` shares the same sign and zero-level set as the target `y`, which is critical for defining safe sets.
- **Optimization:** Mini-batch gradient descent (Adam optimizer) is used to update the hypernetwork's parameters.
- **Robot Model:** Experiments use a kinematic unicycle model for a mobile robot.

#### 3.5. Implementation

The MPC is implemented using the CasADi framework, leveraging C code autogeneration and the MA57 linear solver for real-time performance. The hypernetwork is a PyTorch model, while the main network is implemented using CasADi's symbolic functions to integrate seamlessly into the MPC optimization problem, with its parameters updated by the hypernetwork at each time step.

### 4. Main findings and results

The research presents extensive empirical evaluations in both simulation and hardware, comparing the proposed RNTC-MPC method against three state-of-the-art baselines: SDF-MPC, DCBF-MPC, and VO-MPC. An ablation study also compares it to NTC-MPC (modified for dynamic environments) to highlight the benefit of learning the residual.

#### 4.1. Simulation Experiments (Gazebo Environment)

Experiments involved 100 random initializations of six moving obstacles.
- **Success Rate:** RNTC-MPC achieved the highest success rate across all MPC horizon lengths, demonstrating up to a 30% higher success rate compared to the best baseline (DCBF-MPC). This indicates improved safety and recursive feasibility.
- **Optimization Time:** The proposed method exhibited comparable mean optimization times to the baselines, affirming its real-time performance suitability (typically 4-5 ms per step).
- **Travel Time:** Mean travel times were similar across all methods, suggesting that the improved safety of RNTC-MPC does not significantly compromise mission efficiency.
- **Trade-off Analysis:** RNTC-MPC presented the best compromise between high success rates and low mean travel times.
- **Lateral Deviation:** RNTC-MPC performed comparably to SDF-MPC and DCBF-MPC in terms of mean and maximal lateral deviation, while significantly outperforming VO-MPC.

#### 4.2. Ablation Study (Model Architecture - Appendix A)

This study directly compares RNTC-MPC (learning residual) with NTC-MPC (learning value function directly, as in but adapted for dynamic environments).
- **Faster Convergence:** RNTC-MPC achieved significantly faster convergence during training, reaching an Intersection over Union (IoU) metric on the validation set after 10 epochs that NTC-MPC only reached after 50 epochs (approximately 5 times faster).
- **Higher Accuracy:** RNTC-MPC attained higher final IoU values after 100 epochs for various main network sizes, indicating a more accurate and robust separation of safe and unsafe regions.
- **Safety Guarantee:** Qualitatively, RNTC-MPC successfully classified all states as unsafe if they were unsafe according to the SDF. In contrast, NTC-MPC sometimes assigned positive (safe) values to states that were within the unsafe region of the SDF, which could lead to unsafe actions. This validates the "by-design" safety guarantee of the residual learning approach.

#### 4.3. CME Loss Function Analysis (Appendix B)

The Combined MSE and Exponential (CME) loss function was compared to a standard MSE loss.
- **Improved Convergence and IoU:** The CME loss resulted in significantly faster convergence and higher final IoU values during training compared to MSE loss.
- **Mathematical Properties:** Analysis showed that the optimal prediction `ˆy*` from the CME loss function maintains the same sign and zero-level set as the target `y`, which is crucial for preserving the boundary between safe and unsafe regions.

#### 4.4. Hardware Experiments (Continental Mobile Delivery Robot)

10 trials were conducted for each method in scenarios with 1-2 pedestrians intentionally intersecting the robot's path.
- **Success Rate:** RNTC-MPC achieved a 100% success rate (no collisions), substantially outperforming DCBF-MPC (70%), VO-MPC (70%), and SDF-MPC (40%). This demonstrates a notable improvement in safety performance on a physical robot.
- **Travel Time:** RNTC-MPC exhibited the lowest travel time (12.76 s), indicating superior efficiency in addition to safety.
- **Lateral Deviation:** RNTC-MPC maintained low mean and maximal lateral deviations, comparable to or better than other baselines.
- **Optimization Time:** The method maintained real-time performance on onboard hardware (around 4.20 ms).
- **Overall:** Hardware results reinforced simulation findings, showing RNTC-MPC's robust and safe performance in real-world dynamic environments.

### 5. Significance and potential impact

The research introduces a significant advancement in safe collision avoidance for mobile robots operating in dynamic, unstructured environments. Its significance and potential impact can be summarized as follows:

- **Enhanced Safety with By-Design Guarantees:** The most notable contribution is the development of a learning-based method that provides an inherent, by-design safety guarantee. By modeling the HJ value function as a difference between the SDF and a non-negative residual, and enforcing this non-negativity through the network architecture, the approach ensures that the learned safe set is at least as safe as one derived purely from SDFs. This is crucial for deployment in safety-critical applications where purely data-driven methods often lack formal assurances. The empirical results, particularly the 100% success rate in hardware experiments, validate this enhanced safety.
- **Improved MPC Performance and Robustness:** By providing a real-time, learned approximation of a control-invariant terminal set, the method addresses a long-standing challenge in MPC. This enhances the recursive feasibility and stability of the MPC planner, especially beneficial when operating with short prediction horizons (where traditional methods often struggle). The higher success rates observed across various horizon lengths demonstrate this improved robustness.
- **Real-time Applicability on Onboard Hardware:** The use of a hypernetwork to parametrize a lightweight main network, combined with efficient numerical solvers (CasADi with C code generation and MA57), enables the real-time computation required for online robot navigation. This makes the proposed RNTC-MPC framework practical for deployment on resource-constrained embedded systems commonly found in mobile robots.
- **Effective Handling of Dynamic Environments:** The approach successfully extends learning-based HJ reachability approximations to dynamic environments, which represents a crucial step beyond prior work that often focused on static settings. The ability to condition the safe set estimation on predicted obstacle motions allows robots to respond adaptively to changing environments.
- **Generalizability and Learning Efficiency:** The learning framework, utilizing a strong inductive bias from the value function decomposition and a specialized CME loss function, exhibits faster convergence and higher approximation accuracy during training. This suggests potential for more efficient training and better generalization to unseen dynamic scenarios.
- **Broad Applicability in Robotics:** The method has significant potential for applications in various domains where robots share space with humans or other agents. Examples include cleaning robots in public spaces, intralogistics robots in warehouses, and delivery robots, where non-reciprocal collision avoidance and high safety standards are paramount.

The limitations section points to future work on scalability to higher-dimensional systems, stronger formal guarantees on approximation error, and more sophisticated obstacle motion models, indicating an active research direction with further potential for impact.
