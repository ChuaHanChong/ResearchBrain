# CoMet: Context and Multiplicity Decomposition for Multimodal Uncertainty Estimation

> [!summary] Summary
> CoMet estimates uncertainty for multimodal LLMs by introducing a binary matching variable and splitting predictive uncertainty, measured via Rényi-2 entropy, into a context-specific term (how broad the question's plausible answer space is) and a multiplicity-specific term (how many of those answers stay compatible with the image). Lightweight post-hoc heads predict both from image and prompt alone, beating baselines while staying generation-free.

## Problem

- Sampling-based uncertainty methods aggregate many generations per input, inheriting the model's decoder bias and paying repeated inference cost that makes them impractical at deployment scale.
- Verbalized-confidence and self-verification estimators remain tied to a specific model's generation behavior, and often need extra uncertainty-aware instruction tuning or reinforcement learning on the target model.
- Closed-set measures like logit entropy assume an enumerable answer set, so they do not apply to open-ended multimodal tasks where valid answers are unbounded.

## Method

- A ==binary matching variable== m defines a match-conditioned posterior p(y|x,t,m=1); its ==Rényi-2 collision entropy== splits exactly into a context term log K_t and a multiplicity term.
- An ==MLLM-as-verifier== prompt scores answer correctness, with an affine calibration (beta, gamma) on the Yes/No log-ratio giving the matching probability; p(y|t) comes from greedy prompt clustering over the Cambrian dataset.
- Lightweight ==post-hoc regression heads== fit Z1, Z2 and the context entropy, combined as lambda times u_t plus 2 log Z1 minus log Z2, so inference needs only image and prompt.

## Results

- On open-ended VQA (VQA v2, VizWiz, OK-VQA), CoMet raises average AUROC by **0.100** over the strongest baseline P(Correct) on Qwen3VL-2B, and **0.135** over VL-Uncertainty.
- Error detection averages best across all four backbones (**0.751** versus **0.672** AUROC on Qwen3VL-2B); on MCQ it leads three of four backbones, **0.842** versus **0.802** on Qwen3VL-2B.
- Ablation: both terms give **0.798** average AUROC versus **0.780** for multiplicity alone and **0.686** for context alone; sampling baselines run **2.8** to **5.9** times slower than CoMet.

## Takeaways

> [!tip] Key Insights
> - Reframing uncertainty as semantic compatibility between input and candidate answers, rather than a model's own generation likelihood, decouples the estimate from decoder bias and paraphrase variation.
> - Splitting ambiguity into prompt-induced breadth and input-resolved multiplicity yields complementary signals plus interpretable diagnostics: which half of a multimodal query is actually causing the doubt.
> - Generation-free post-hoc heads can beat sampling methods on open-ended tasks, but sampling stays competitive when an explicit candidate set shrinks the search space, as in MCQ.

## Detailed Report

### 1. Overview

A visual question-answering system can be asked about the same dim indoor image in two ways: “Is that a calico cat?” and “What letter of the alphabet is on the bottle?” Both questions concern the same picture, yet they leave very different answer spaces. The first allows two yes/no possibilities. The second invites a 26-letter answer set, and the small, poorly lit bottles leave more of those letters unresolved.

CoMet (Context and Multiplicity Decomposition) estimates whether a multimodal model is likely to be wrong by separating these two sources of ambiguity. The first is how many answers a question could reasonably invite. The second is how many of those answers the image still supports. CoMet then combines them into one score. Such a score can help a system decide when to trust an answer, abstain, or flag a possible hallucination.

The reported gain is in uncertainty ranking, not answer generation. For Qwen3VL-2B-Instruct, CoMet’s average AUROC on three open-ended VQA benchmarks is **0.785**, versus **0.685** for the strongest baseline, P(Correct), and **0.650** for VL-Uncertainty.

### 2. Two sources, one score

The two uncertainty terms measure different things:

- **Context-specific uncertainty** describes how broadly the question or task defines plausible answers. A yes/no question, for example, has a narrower answer set than “describe this image.”
- **Multiplicity-specific uncertainty** describes how many of those context-plausible answers remain compatible with the image. A clear image may rule out many answers, while an ambiguous or poorly visible scene may leave several.

To formalize this, the authors introduce a binary match variable. It indicates whether a candidate answer is semantically compatible with the image under the given context. They define uncertainty over the answer distribution conditioned on a match. They measure it with Rényi-2 entropy, a concentration-sensitive entropy measure suited to answers that cannot be enumerated as a fixed set.

The practical pipeline has three steps:

1. Prompts from the Cambrian visual-instruction dataset are clustered. The answers in a cluster serve as candidate answers for similar questions.
1. The MLLM verifier is asked whether each candidate is supported.
1. These signals are used to construct uncertainty targets and train lightweight heads.

At inference, the uncertainty module takes the image and question, not a generated answer or sampled candidate set. Two approximations remain. The candidate bank is finite, and the context-breadth term uses a language-model density surrogate rather than the unknown true answer distribution.

### 3. Does the split help?

**Metric.** AUROC measures how well an uncertainty score separates correct from incorrect predictions. For open-ended VQA, correctness is determined by thresholding the benchmark’s soft VQA score.

**Comparison with VL-Uncertainty.** The headline comparison averages VQA v2, VizWiz, and OK-VQA. Zhang, Hu, and Zheng’s [[2411.11919|VL-Uncertainty]] takes a sampling approach: it perturbs images, rephrases questions, generates answers across perturbations, and measures semantic disagreement. CoMet instead separates the breadth of the answer space induced by the question from image-conditioned compatibility. It also avoids generating answers to estimate uncertainty at inference. On this average for Qwen3VL-2B-Instruct, CoMet’s AUROC is 0.785 versus 0.650 for VL-Uncertainty. This is a benchmark average, not a universal guarantee.

**Component ablation.** The more direct test is whether *both* components matter. With Qwen3VL-8B-Instruct, the average AUROC is:

- 0.798 using both components
- 0.780 using only multiplicity-specific uncertainty
- 0.686 using only context-specific uncertainty

The combined system exceeds either single-component version on six of seven displayed task columns. The exception is MMStar, where multiplicity alone scores 0.857 and both terms score 0.853. This supports complementary signals in this experiment, not a proof of the theory.

### 4. Boundaries

CoMet’s contribution is to represent question-induced breadth and image-supported compatibility as distinct sources of uncertainty and to combine them. The ablation supports using both signals in the tested setup. Its scores show better discrimination, but they are not shown to be calibrated probabilities, and CoMet does not make the underlying answers more accurate.

The method avoids autoregressive answer generation and repeated sampling for uncertainty estimation at inference. It still uses the frozen MLLM’s features, however, and the reported system includes lightweight adaptation using benchmark-related examples. Its theoretical decomposition also rests on assumptions about the graphical model and a uniform context-conditioned answer distribution. In practice, that answer distribution is approximated.
