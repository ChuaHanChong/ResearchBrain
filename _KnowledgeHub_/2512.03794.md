# AdaptVision: Efficient Vision-Language Models via Adaptive Visual Acquisition

> [!summary] Summary
> The AdaptVision framework from Tencent Hunyuan allows Vision-Language Models to adaptively acquire visual information through a coarse-to-fine strategy and a novel reinforcement learning algorithm, achieving 97.9% of vanilla model performance while consuming only 33% of visual tokens and demonstrating a 1.67x inference speedup.

## Problem

- Large Vision-Language Models (VLMs) incur substantial computational and memory overhead due to processing a high volume of visual tokens from high-resolution images.
- Existing VLM efficiency methods employ passive, fixed-ratio compression or limited dynamic decisions, lacking fine-grained, adaptive visual token acquisition tailored to specific input needs.
- Training multi-turn VLM policies with standard reinforcement learning (RL) faces challenges like ambiguous credit assignment and imbalanced optimization between tool invocation and answer generation.

## Method

- **AdaptVision** employs a two-turn ==coarse-to-fine== processing strategy: initially analyzing low-resolution images and then adaptively invoking a bounding box tool to crop specific high-resolution regions for detailed analysis only when necessary.
- A composite reward function is designed to balance accuracy and token efficiency, including rewards for correct answers, proper output format, penalties for excessive tool use or 'lucky' low-resolution guesses, and rewards for relevant, minimally-sized crop areas.
- Decoupled Turn Policy Optimization (DTPO) is introduced, which decouples policy loss and advantage estimation by turns, providing more precise credit assignment and balanced optimization for tool-related and outcome-related decisions in the RL framework.

## Results

- AdaptVision achieved **97.9%** of the vanilla model's performance across various benchmarks while reducing visual token consumption to **33%** (compared to **100%**), outperforming all other efficient VLM baselines.
- The framework demonstrated a **1.67x** overall speedup in end-to-end inference time compared to the vanilla model and other dynamic methods.
- DTPO ensured stable and efficient training, with AdaptVision learning to adaptively regulate tool usage, increasing calls for complex tasks and reducing them for simpler ones, unlike standard GRPO which led to unstable and suboptimal tool call ratios.

## Takeaways

> [!tip] Key Insights
> - Emulating human-like active vision, where models adaptively acquire visual information, significantly enhances VLM efficiency and accuracy compared to passive compression methods.
> - Decoupling policy loss and advantage estimation in multi-turn reinforcement learning is crucial for stable and effective optimization of policies that balance multiple, potentially conflicting objectives (e.g., accuracy vs. efficiency).
> - VLMs can learn to autonomously determine the minimum visual information required for specific tasks, adapting their token consumption based on image complexity and question type.
