# ComputerRL: Scaling End-to-End Online Reinforcement Learning for Computer Use Agents

> [!summary] Summary
> The COMPUTERRL framework scales online reinforcement learning for computer use agents, achieving new state-of-the-art accuracy of 48.9% on the OSWorld benchmark and 43.3% on the new OfficeWorld benchmark by integrating an API-GUI interaction paradigm, a scalable distributed environment, and the Entropulse training strategy.

## Problem

- Developing robust LLM-based GUI agents is challenging due to the inherent human-centric design of graphical user interfaces, making machine interaction complex.
- Existing methods like Behavior Cloning suffer from scalability issues, limited generalization, and poor error recovery for diverse and complex desktop tasks.
- Applying Reinforcement Learning to desktop automation has been hindered by computational intensity, slow convergence rates, instability, and a tendency for policies to lose exploratory capacity (entropy collapse) during extended training.

## Method

- An ==API-GUI== interaction paradigm unifies direct GUI interactions with programmatic API calls, complemented by an LLM-based automated workflow for API development to enhance efficiency and versatility.
- A scalable and stable Ubuntu environment with a distributed multi-node clustering infrastructure was developed, capable of orchestrating thousands of concurrent virtual desktop environments for efficient data collection.
- A full-asynchronous RL framework is implemented, featuring multi-LLM driven Behavior Cloning, step-level Group Relative Policy Optimization (GRPO) with verifiable rewards, and the Entropulse strategy for sustained exploration through periodic RL-SFT alternations.

## Results

- AUTOGLM-OS-**9B**, trained with COMPUTERRL, achieved a new state-of-the-art accuracy of **48.9%** on the OSWorld benchmark, representing a **66%** performance gain from the RL phase and surpassing leading baselines.
- The framework also introduced the OFFICEWORLD benchmark and demonstrated a superior average success rate of **43.3%** on office-oriented tasks, outperforming agents like OpenAI CUA o3 (**33.9%**).
- Ablation studies confirmed the API-GUI paradigm significantly improved task completion with fewer steps, and the Entropulse strategy led to substantial performance improvements in the second RL phase by restoring policy entropy.

## Takeaways

> [!tip] Key Insights
> - The API-GUI paradigm significantly improves agent efficiency and versatility, demonstrating a 134% performance gain over GUI-only approaches in desktop automation by effectively combining programmatic and visual interactions.
> - A robust, distributed, and asynchronous RL infrastructure is crucial for overcoming the computational and stability challenges of training agents in complex, high-dimensional desktop environments.
> - The Entropulse strategy successfully counteracts entropy collapse in large-scale RL training, enabling sustained exploration and further performance gains by periodically rejuvenating the policy's exploratory capacity through SFT.
