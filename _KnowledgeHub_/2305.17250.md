# Self-Supervised Reinforcement Learning that Transfers using Random Features

> [!summary] Summary
> This paper introduces Random Features for Model-Free Planning (RaMP), an approach to enable effective transfer learning in reinforcement learning by learning task-agnostic representations. The method learns Q-basis functions from reward-agnostic data offline and quickly adapts to new reward functions online, demonstrating strong performance across various robotic manipulation and locomotion tasks.

## Problem

- Reinforcement learning algorithms struggle to generalize and transfer learned skills to new tasks when reward functions change, often requiring complete retraining.
- Model-free methods entangle environment dynamics, reward functions, and policies, limiting their transfer capabilities.
- Model-based methods, while offering better transfer potential, suffer from compounding errors over long horizons.

## Method

- **RaMP** uses a two-phase approach: an ==offline self-supervised== phase learns task-agnostic representations, followed by an online phase for rapid task adaptation.
- In offline training, the algorithm generates ==random features== and learns corresponding ==Q-basis functions==, each representing the cumulative return for that feature as a reward.
- Online, a new reward function is approximated as a linear combination of random features, and the corresponding Q-function is constructed by linearly combining the learned Q-basis functions for planning via ==Model Predictive Control (MPC)==.

## Results

- RaMP consistently outperformed baseline methods, including model-based and successor feature approaches, in transfer learning across diverse robotic manipulation and locomotion tasks.
- Ablation studies showed that using multi-step Q-learning significantly improved transfer performance, and higher-dimensional random feature spaces (**1024-2048**) led to better results.
- The method demonstrated robustness to pixel observations and showed further performance gains when Q-basis functions were fine-tuned on target tasks.

## Takeaways

> [!tip] Key Insights
> - Environment dynamics can be implicitly captured by learning Q-basis functions corresponding to random features, enabling task-agnostic representation.
> - Decoupling the learning of environment dynamics from specific reward functions allows for effective transfer learning in model-free RL settings.
> - Utilizing multi-step Q-learning for Q-basis functions reduces policy dependence, which improves their transferability to new tasks.

## Detailed Report

### 1. Introduction

Transfer learning remains one of the most significant challenges in reinforcement learning. While humans can easily adapt skills learned in one context to new situations with different objectives, current RL algorithms struggle to generalize across tasks when reward functions change. This paper introduces Random Features for Model-Free Planning (RaMP), a self-supervised approach that enables effective transfer learning by learning task-agnostic representations during offline training and quickly adapting to new reward functions during online deployment.

The core insight behind RaMP is to decouple the learning of environment dynamics from specific reward functions by using random features as basis functions for representing arbitrary rewards. This approach combines the scalability advantages of model-free RL with the transfer capabilities typically associated with model-based methods.

### 2. The Challenge of Transfer Learning in Reinforcement Learning

Traditional reinforcement learning approaches face a fundamental trade-off when it comes to transfer learning. Model-free methods excel at learning optimal policies for specific tasks but struggle to generalize because they entangle environment dynamics, reward functions, and policies in their learned representations. When the reward function changes, these methods typically require complete retraining from scratch.

Model-based approaches offer better transfer potential by explicitly learning environment dynamics that can be reused across different reward functions. However, they suffer from compounding errors in long-horizon tasks, where small inaccuracies in the learned model compound over time, leading to poor performance.

The authors identify this as a critical gap: existing methods cannot simultaneously achieve strong single-task performance, effective transfer across different reward functions, and scalability to high-dimensional observation spaces with long horizons.

### 3. RaMP Algorithm Overview

RaMP addresses these limitations through a two-phase approach that separates offline self-supervised learning from online task adaptation:

#### 3.1. Offline Training Phase

During offline training, RaMP learns from reward-agnostic trajectory data. The algorithm:

1. **Generates Random Features**: Creates a large set of random basis functions φ₁, φ₂..., φₕ using randomly initialized neural networks that map state-action pairs to scalar values.

2. **Learns Q-Basis Functions**: For each random feature φᵢ, trains a corresponding Q-basis function ψᵢ that represents the expected cumulative return when treating φᵢ as the reward function. This is accomplished using multi-step Q-learning to reduce policy dependence.

3. **Captures Environment Dynamics**: The collection of Q-basis functions implicitly encodes information about the environment's transition dynamics without explicitly modeling them.

#### 3.2. Online Adaptation Phase

When presented with a new task and its reward function r(s,a), RaMP:

1. **Approximates the Reward**: Uses linear regression to express the new reward function as a weighted combination of the random features: r(s,a) ≈ Σᵢ wᵢφᵢ(s,a).

2. **Constructs Task-Specific Q-Function**: Combines the learned Q-basis functions using the same weights: Q(s,a) ≈ Σᵢ wᵢψᵢ(s,a).

3. **Plans with Model Predictive Control**: Uses the constructed Q-function for planning optimal action sequences via model predictive control (MPC).

### 4. Technical Implementation

The mathematical foundation of RaMP relies on the linear approximation of reward functions using random features. Given a new reward function r(s,a), the algorithm solves:

```
min_w ||r(s,a) - Σᵢ wᵢφᵢ(s,a)||²
```

The resulting weights w are then used to construct the Q-function for the new task:

```
Q_new(s,a) = Σᵢ wᵢψᵢ(s,a)
```

Key technical innovations include:

- **Multi-step Q-Learning**: Using n-step returns reduces the dependency of Q-basis functions on specific policies, improving transfer performance.
- **High-Dimensional Random Features**: The universal approximation properties of random features ensure that arbitrary reward functions can be accurately represented given sufficient basis dimension.
- **MPC Planning**: Model predictive control enables effective use of the learned Q-functions for action selection without requiring explicit policy learning.

### 5. Experimental Evaluation

The authors evaluate RaMP across diverse robotic manipulation and locomotion tasks, comparing against several strong baselines including model-based methods (MBPO, PETS), successor features (SF), and offline RL methods (CQL).

The experimental domains include:
- **Manipulation Tasks**: Reaching, door opening, faucet operation, button pressing
- **Locomotion Tasks**: Various hopper behaviors (standing, jumping, backward movement)
- **Dexterous Control**: Complex manipulation with high-dimensional action spaces

### 6. Key Results and Performance

The experimental results demonstrate RaMP's effectiveness across multiple dimensions:

#### 6.1. Transfer Learning Performance

RaMP consistently outperforms baseline methods across all tested domains. The algorithm shows particularly strong performance in:
- Quick adaptation to new reward functions
- Maintaining performance across diverse task types
- Scaling to high-dimensional observation and action spaces

#### 6.2. Robustness Analysis

Additional experiments show that RaMP benefits from fine-tuning the Q-basis functions on target tasks, further improving performance. The algorithm also demonstrates robustness when tested on pixel observations and when compared against recent methods like Dreamer.

#### 6.3. Ablation Studies

Critical ablation studies reveal:
- **Basis Dimension**: Performance improves with higher-dimensional random feature spaces, plateauing around 1024-2048 features
- **Multi-step Returns**: Using multi-step Q-learning significantly improves transfer performance
- **Feature Quality**: The choice of random feature architecture affects reward approximation quality

### 7. Significance and Impact

RaMP represents a significant advancement in transfer learning for reinforcement learning with several important implications:

#### 7.1. Theoretical Contributions

The work bridges model-free and model-based RL by showing how random features can implicitly capture environment dynamics without explicit model learning. This provides a new perspective on how to achieve transfer learning while maintaining the scalability advantages of model-free methods.

#### 7.2. Practical Applications

The algorithm's ability to learn from unlabeled trajectory data and quickly adapt to new reward functions has direct applications in:
- **Robotics**: Enabling robots to reuse learned behaviors across different tasks
- **Autonomous Systems**: Allowing agents to adapt to changing objectives
- **Industrial Automation**: Facilitating quick reconfiguration of learned policies

#### 7.3. Methodological Impact

RaMP demonstrates the effectiveness of self-supervised learning in RL, showing how large amounts of reward-agnostic data can be leveraged to improve sample efficiency and transfer performance. The use of random features for reward approximation provides a general framework that could be applied to other transfer learning problems.

The research also highlights the importance of decoupling different components of the RL problem (dynamics, rewards, policies) to enable better generalization—a principle that could inform future algorithm design.

By achieving strong empirical performance across diverse domains while maintaining theoretical grounding, RaMP establishes a new standard for transfer learning in reinforcement learning and opens avenues for developing more general and adaptable AI systems.
