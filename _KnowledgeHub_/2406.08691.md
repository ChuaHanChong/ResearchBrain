# UnO: Unsupervised Occupancy Fields for Perception and Forecasting

> [!summary] Summary
> UNO learns a continuous 4D occupancy field over space and future time from unlabeled LiDAR via a self-supervised classification objective, using an implicit deformable-attention decoder queryable at any (x,y,z,t). It transfers to point cloud forecasting and BEV semantic occupancy, beating fully supervised state-of-the-art with far less labeled data.

## Problem

- Supervised world models rely on costly human annotations restricted to predefined object classes, missing rare or unlabeled road agents entirely.
- Prior unsupervised point cloud forecasting methods must jointly learn world dynamics plus sensor extrinsics/intrinsics and LiDAR reflectivity, needlessly complicating the task.
- 4D-OCC's voxel-grid occupancy with depth-rendering regression introduces quantization error and emphasizes depth accuracy over occupancy classification, so it struggles with moving objects.

## Method

- **UNO**: an ==implicit 4D occupancy decoder== using ==deformable attention== over a ==BEV== feature map, queryable at any continuous spatio-temporal point without voxel quantization.
- ==Occupancy pseudo-labeling== from LiDAR ray geometry, marking space before a return as unoccupied and a small buffer behind the point as occupied, trained with ==balanced binary cross-entropy==.
- Lightweight downstream transfer heads: a frozen-UNO ==ray-depth renderer== for point cloud forecasting, and joint fine-tuning with a ==learnable query embedding== for BEV semantic occupancy.

## Results

- UNO sets state-of-the-art point cloud forecasting on Argoverse 2, nuScenes, and KITTI, e.g. nuScenes NFCD drops from **1.40** to **0.89** versus 4D-OCC.
- Fine-tuned UNO beats supervised MP3 and ImplicitO on BEV semantic occupancy at every label scale, matching their full-data mAP using roughly **10x** fewer labeled frames.
- At matched **70%** precision, UNO achieves much higher occupancy recall than 4D-OCC and ablations across object classes, especially rare ones like strollers and bicyclists.

## Takeaways

> [!tip] Key Insights
> - Balancing positive and negative query supervision matters little for background-dominated point cloud metrics but is critical for learning dynamic-object extent useful downstream.
> - A classification objective over continuous implicit occupancy generalizes better than regression-based depth rendering over quantized voxel grids for capturing multi-modal object dynamics.
> - Self-supervised occupancy pretraining can substitute for most semantic labels, offering strong few-shot transfer when annotated data is scarce.

## Detailed Report

### 1. Introduction

Autonomous driving systems require comprehensive understanding of their surrounding environment to navigate safely and effectively. Current perception and forecasting models typically rely on supervised learning approaches that demand extensive human annotations, which are expensive, time-consuming, and often limited in scale.

The paper "UnO: Unsupervised Occupancy Fields for Perception and Forecasting" introduces a novel approach that leverages vast amounts of unlabeled LiDAR data to learn a continuous 4D (3D space + time) occupancy field. This representation captures the geometry, dynamics, and semantics of the environment without requiring human annotations.

### 2. Research Context

This research is conducted by Ben Agro, Quinlan Sykora, Sergio Casas, Thomas Gilles, and Raquel Urtasun from Waabi and the University of Toronto. It addresses critical challenges in autonomous driving perception:

1. The reliance on limited, expensive human annotations for traditional supervised learning
2. The need for a unified representation that captures both static and dynamic elements of the environment
3. The requirement for accurate forecasting to enable safe decision-making

Current approaches to perception and forecasting often use separate models for different tasks (object detection, segmentation, trajectory prediction) or rely on discrete representations like voxel grids that suffer from quantization errors and resolution limitations.

### 3. The Unsupervised Occupancy Approach

The key innovation in UnO is its formulation of an unsupervised learning task for 4D occupancy prediction. Instead of using human annotations, the authors generate pseudo-labels from LiDAR sensor data, leveraging the physics of how LiDAR works:

1. **LiDAR-based supervision**: When a LiDAR ray hits an object, the space along the ray before the hit point is unoccupied, while the space at the hit point (plus a small buffer) is occupied.

2. **Continuous representation**: Unlike voxel-based methods, UnO represents occupancy as a continuous field, allowing query at any point in 3D space and future time without discretization artifacts.

The mathematical formulation defines the occupancy field as:

$$O(x, y, z, t) \in$$

where values close to 1 indicate occupied space and values close to 0 indicate free space at coordinates (x, y, z) and time t.

### 4. Model Architecture

The UnO model consists of two main components:

1. **LiDAR Encoder**: Processes raw LiDAR point clouds from past time steps to create a Bird's Eye View (BEV) feature representation.

2. **Implicit Occupancy Decoder**: Takes continuous query points (x, y, z, t) and predicts the occupancy probability at those points.

The LiDAR encoder uses a voxelization process followed by a backbone network with residual blocks and deformable attention mechanisms to extract meaningful features from point clouds. The implicit decoder uses interpolation and attention mechanisms to predict occupancy at any query point in continuous 4D space.

Key technical details include:

```python
# Pseudo-code for occupancy prediction at query points
def predict_occupancy(lidar_sweeps, query_points):
    # Encode LiDAR into BEV features
    bev_features = lidar_encoder(lidar_sweeps)

    # For each query point (x,y,z,t)
    occupancy_probs = []
    for point in query_points:
        # Extract features at point location
        features = interpolate_features(bev_features, point)

        # Apply deformable attention
        attended_features = deformable_attention(features, bev_features)

        # Predict occupancy probability
        prob = mlp_decoder(attended_features)
        occupancy_probs.append(prob)

    return occupancy_probs
```

### 5. Training Methodology

The UnO model is trained using a carefully designed loss function that balances positive and negative supervision:

$$L = \lambda_{pos} L_{pos} + \lambda_{neg} L_{neg}$$

Where:
- $L_{pos}$ is the binary cross-entropy loss for occupied points
- $L_{neg}$ is the binary cross-entropy loss for unoccupied points
- $\lambda_{pos}$ and $\lambda_{neg}$ are weighting factors

Points are sampled along LiDAR rays for both positive and negative supervision. To address the class imbalance (most space is unoccupied), the authors use balanced sampling and loss weights.

Training involves processing batches of LiDAR sweeps and predicting occupancy at sampled query points. The key innovation is that this entire process requires no human annotations—just raw sensor data.

### 6. Transfer Learning and Downstream Tasks

One of the most significant contributions of UnO is its ability to transfer the learned occupancy representation to different downstream tasks with minimal adaptation:

1. **Point Cloud Forecasting**: Predicting future LiDAR point clouds by rendering from the occupancy field.

2. **BEV Semantic Occupancy Prediction**: Predicting semantic class labels for occupied areas by fine-tuning the pre-trained model with limited labeled data.

The transfer to point cloud forecasting is achieved by adding a rendering network that uses the occupancy field to predict ray depths. For semantic occupancy prediction, the pre-trained model is fine-tuned with class labels, demonstrating strong few-shot capabilities.

### 7. Experimental Results

The UnO model was evaluated on multiple datasets, including Argoverse 2, nuScenes, and KITTI, with impressive results:

1. **State-of-the-art performance in point cloud forecasting**: UnO outperforms existing methods in forecasting accuracy across all datasets, particularly for longer time horizons.

2. **Superior performance in BEV semantic occupancy prediction**: Especially in low-data regimes, where UnO significantly outperforms fully supervised approaches.

3. **High recall for safety-critical objects**: UnO achieves higher recall for objects in classes relevant to self-driving (pedestrians, cyclists, vehicles) compared to other occupancy-based models.

The experiments also showed that UnO's continuous representation is more accurate than discrete voxel-based methods, particularly for fine details and at longer time horizons.

### 8. Significance and Impact

The significance of UnO extends beyond its performance metrics:

1. **Scalability through unsupervised learning**: By eliminating the need for human annotations, UnO enables training on much larger and more diverse datasets.

2. **Unified representation for multiple tasks**: The continuous 4D occupancy field provides a general-purpose foundation for various perception and forecasting tasks.

3. **Improved safety**: Better performance in detecting and forecasting safety-critical objects like pedestrians and cyclists directly translates to safer autonomous driving systems.

4. **Resource efficiency**: The ability to learn from unlabeled data and transfer to downstream tasks with minimal adaptation reduces development costs.

The research represents a significant step toward building self-driving systems that can learn from and adapt to the real world without constant human supervision.

### 9. Conclusion

UnO presents a novel approach to perception and forecasting for autonomous driving by learning continuous 4D occupancy fields from unlabeled LiDAR data. The key contributions include:

1. A formulation for unsupervised learning of 4D occupancy from raw sensor data
2. A continuous implicit neural representation that avoids quantization errors
3. State-of-the-art performance on point cloud forecasting and semantic occupancy prediction
4. Effective transfer learning to downstream tasks with minimal adaptation

This research addresses fundamental limitations in current perception systems and opens new possibilities for more scalable, adaptable, and accurate self-driving technology. By reducing the reliance on human annotations while improving performance, UnO represents an important advancement toward safer and more capable autonomous vehicles.

Future work could expand on this approach by incorporating additional sensor modalities, extending to even longer time horizons, and exploring real-time implementations for deployment in autonomous vehicles.
