# ManipulaTHOR: A Framework for Visual Object Manipulation

> [!summary] Summary
> Researchers at the Allen Institute for AI introduced ManipulaTHOR, an extension to the AI2-THOR simulator, to enable embodied agents to perform low-level object manipulation in visually complex, physics-enabled environments. They developed the ArmPointNav task as a benchmark, achieving a 39.4% success rate in picking up and relocating objects without disturbance in previously seen scenes with familiar objects, while also demonstrating moderate generalization to novel objects.

## Problem

- Existing Embodied AI environments primarily focus on navigation, lacking robust support for low-level, physics-enabled object manipulation by mobile agents.
- Traditional robotics research often addresses manipulation in controlled settings or with static manipulators, not fully integrating mobile manipulation in cluttered, visually rich 3D environments.
- There is a need for standardized benchmarks and frameworks to train and evaluate agents on combined navigation and fine-grained object interaction tasks, particularly concerning generalization to novel objects and scenes.

## Method

- Developed ManipulaTHOR, an extension of AI2-THOR, integrating a simplified three-jointed robotic arm with 6-DOF hand grasper attached to the agent, supporting forward and inverse kinematics and physics-enabled interactions.
- Introduced the ArmPointNav task, a benchmark requiring agents to navigate to an object, pick it up, and transport it to a target location, involving continuous arm control and 3D collision avoidance.
- Created the ArmPointNav Dataset (APND) using 30 kitchen scenes and 12 object categories, enabling evaluation of end-to-end deep reinforcement learning agents for generalization to novel scenes and unseen object categories.

## Results

- The end-to-end model achieved a 39.4% Success Rate without Disturbance (SRwD) and an 89.9% Pick Up Success Rate (PuSR) for seen objects in test scenes, with successful episodes averaging 78.1 steps.
- Performance moderately decreased when generalizing to novel objects, with SRwD dropping to 32.7% for novel objects in unseen scenes and 32.2% for novel objects in seen scenes, highlighting challenges in handling unfamiliar object geometries.
- Ablation studies demonstrated the critical role of visual input, with a depth-only model (SRwD 39.4%) significantly outperforming an RGB-only model (SRwD 21.2%) and a no-vision agent (SRwD 10.3%).

## Takeaways

> [!tip] Key Insights
> - An end-to-end deep reinforcement learning approach is more effective for complex combined navigation and manipulation tasks like ArmPointNav than disjoint multi-stage policies, which struggle with overall task completion despite specialized sub-task performance.
> - Depth information is more critical for spatial reasoning, collision avoidance, and overall task success in visual object manipulation compared to RGB information.
> - Generalization to novel object categories presents a greater challenge than generalization to novel scenes, suggesting that robust understanding of object geometry and interaction properties is a primary bottleneck for manipulation tasks.
