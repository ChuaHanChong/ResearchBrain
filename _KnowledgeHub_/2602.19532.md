# Bellman Value Decomposition for Task Logic in Safe Optimal Control

> [!summary] Summary
> Bellman Value Decomposition formally breaks down complex Temporal Logic specifications for robotic control into a hierarchy of simpler Value functions. The accompanying VDPPO algorithm trains optimal policies for these decomposed components, outperforming baselines in high-dimensional simulations and demonstrating emergent coordinated behaviors on real robotic hardware for tasks requiring sequential goals and safety.

## Problem

- Real-world robotic tasks require strict safety guarantees and precise temporal sequencing, which standard Reinforcement Learning (RL) and cumulative reward optimization often fail to provide.
- Integrating Temporal Logic (TL) with RL faces issues like sparse binary rewards leading to slow learning, and hand-crafted dense rewards risking misalignment with true TL objectives.
- Representing complex TL specifications using formal automata becomes computationally intractable in high-dimensional state spaces.

## Method

- Introduces ==Value Decomposition Rules (VDR)== to formally decompose complex Bellman Value functions into simpler, "atomic" components based on Temporal Logic operators.
- Derives novel Bellman equations, including a contractive ==Reach-Avoid-Loop (RAℓ)== operator, to solve implicit Value functions arising from recurrent Temporal Logic specifications.
- Develops **VDPPO**, a PPO-based algorithm that uses a single neural network for all decomposed Value functions and another for all policies, leveraging ==one-hot embeddings== for efficient multi-task learning.

## Results

- VDPPO consistently achieved superior performance over baselines (LCRL, TL-MPPI, PPO, PPO-LSTM) in simulations, demonstrating robustness to increasing TL breadth and depth (e.g., up to **128 sequential targets**).
- Parameter sharing in the VDPPO architecture, particularly for the actor network, enhanced success rates and reduced variance, with combined actor/critic sharing yielding up to **N-fold** training speedup.
- Real-world hardware experiments confirmed the approach's effectiveness, showcasing emergent coordinated behaviors, such as dynamic division of labor in a herding task and anticipatory resupply for heterogeneous robotic teams.

## Takeaways

> [!tip] Key Insights
> - While logical identities hold for robustness scores, the `max_alpha` operator prevents direct translation to Value function decomposition, necessitating a dedicated decomposition algebra.
> - Complex Temporal Logic tasks can be systematically transformed into a hierarchy (or graph) of simpler, solvable Bellman Value functions using specific decomposition rules and novel Bellman operators.
> - Parameter sharing across a Decomposed Value Graph (DVG) within a single neural network for both actor and critic significantly boosts training speed (up to N times faster) while preserving high performance for intricate TL objectives.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of robotic learning, particularly Reinforcement Learning (RL), typically focuses on optimizing expected cumulative rewards. This approach often proves inadequate for real-world applications that necessitate strict safety guarantees or precise temporal sequencing of objectives, which are naturally expressed using Temporal Logic (TL). Current methods face challenges in high-dimensional state spaces, where formal automata for TL become unwieldy, and the reliance on sparse binary rewards slows learning significantly. Conversely, hand-crafted dense rewards, while potentially accelerating learning, risk misaligning the learned policy with the true TL objective.

Several lines of research have attempted to integrate RL with TL. Constrained Markov Decision Processes (CMDPs) optimize rewards subject to constraints, often via Lagrangian relaxation, but these typically require substantial tuning and are not inherently designed for general TL objectives. Multi-objective RL approaches aim to find Pareto-optimal policies for multiple reward functions, which differs from the joint satisfaction required by TL specifications. Goal-conditioned RL learns policies for a family of goals, but in TL, all specified conditions must be met simultaneously. Other approaches explicitly address TL specifications in RL through Non-Markovian Reward Decision Processes, approximation of quantitative semantics, or modified Bellman equations. However, these often involve semantic approximations or suffer from the inherent sparsity of rewards over long temporal horizons.

This work positions itself within the landscape by drawing a distinction between the algebra of temporal logic's robustness scores and the algebra of optimal Value functions, noting that direct decomposition of logic does not automatically translate to a decomposition of optimal Value functions due to the presence of the maximization over action sequences. It builds upon previous advancements in Hamilton–Jacobi Reachability (HJR), which provides optimal controllers for fundamental safety and liveness tasks (Reach, Avoid, Reach-Avoid) using max–min Bellman equations, yielding dense and informative learning signals. The authors generalize prior work that demonstrated the exact solvability of certain TL tasks by decomposing their Value functions into sequences of simpler HJR problems. By introducing a Value function decomposition algebra and an associated algorithm, VDPPO, this research aims to provide a method that exactly decomposes TL Value functions into simpler, solvable components, thereby circumventing semantic approximations and mitigating long-horizon reward sparsity.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a robust and efficient method for synthesizing optimal control policies for complex, high-dimensional real-world robotic tasks governed by nuanced Temporal Logic (TL) specifications. This entails balancing multiple goal achievements (liveness) with stringent safety requirements.

The motivation for this work stems from several limitations inherent in existing approaches to robotic control and reinforcement learning when applied to real-world scenarios:

1. **Complexity of Real-World Task Specifications**: Real-world robotic operations rarely involve simple "reach a single goal" objectives. Instead, they require intricate combinations of sequential, concurrent, and recurring goals, alongside persistent safety constraints. Temporal logic offers a formal language to express these complex specifications precisely, but translating these logical statements into executable control policies remains a significant challenge.

2. **Limitations of Traditional Reinforcement Learning (RL)**: Standard RL algorithms, designed to maximize expected cumulative rewards, are often ill-suited for safety-critical tasks. Such tasks typically demand worst-case satisfaction (for safety) or best-case satisfaction (for liveness) over extended horizons, rather than average performance. This fundamental mismatch often leads to policies that are either unsafe or fail to reliably achieve critical goals.

3. **Challenges with Reward Engineering**: When applying RL to TL-specified tasks, engineers face a dilemma:
 - **Sparse Binary Rewards**: Directly mapping TL satisfaction to sparse binary rewards (1 for success, 0 for failure) often results in extremely slow and inefficient learning, especially in large state spaces or for long-horizon tasks, as the agent receives little feedback until terminal conditions are met.
 - **Hand-crafted Dense Rewards**: Attempts to alleviate sparsity through dense, hand-crafted reward functions are labor-intensive and require deep domain expertise. More critically, they risk introducing unintended biases or misalignments, where the agent learns to optimize the proxy reward function rather than the true underlying TL objective, potentially leading to suboptimal or unsafe behaviors.

4. **Cumbersome Formal Automata in High Dimensions**: Representing complex TL specifications using formal automata (e.g., Büchi automata) can become computationally intractable and cumbersome as the state space dimensionality increases. These automata often lead to state-space explosion, making integration with deep learning challenging.

5. **Theoretical Gap between Logic and Optimal Control**: The algebraic properties governing the quantitative semantics of temporal logic (robustness scores) do not directly translate to the algebraic properties of optimal Value functions (which involve a maximization over action sequences). This discrepancy means that logical decomposition alone is insufficient for decomposing optimal control problems, necessitating a dedicated theoretical framework for Value function decomposition.

In response to these challenges, the core motivation is to uncover and exploit the inherent structure within the Bellman Value function itself. By formally demonstrating that the Value for a complex TL task can be decomposed into a structured graph of simpler Values, connected by established or novel Bellman Equations, the authors aim to transform an intractable high-dimensional problem into a series of more manageable sub-problems. This structured approach is intended to facilitate automatic, efficient, and robust policy learning that inherently balances safety and liveness without extensive manual tuning.

### 3. Methodology and Approach

The methodology of this research integrates formal methods, optimal control theory, and deep reinforcement learning to tackle complex temporal logic (TL) specifications in continuous state and action spaces.

**A. Problem Formulation and Preliminaries**
The work considers discrete-time systems $x_{t+1} = f(x_t, a_t)$. Desired trajectory properties are defined by atomic propositions (AP) $r$, represented by real-valued robustness functions $\rho[p]$. These are composed using TL operators (negation $\neg$, conjunction $\land$, Until U, Next X), from which disjunction $\lor$, Finally F, and Globally G are derived. The core objective is an infinite-horizon Optimal Control Problem (OCP) to maximize the robustness score $\rho[p](\xi^\alpha_x)$ for a given predicate $p$, which is captured by the Bellman Value function $V^*[p](x) := \max_\alpha \rho[p](\xi^\alpha_x)$. This objective emphasizes outlying performance (worst-case for safety, best-case for liveness) rather than average cumulative reward. The paper leverages Hamilton–Jacobi Reachability (HJR) concepts, noting that $V^*$ for F, G, and U correspond to Reach, Avoid, and Reach-Avoid problems, for which specific Bellman operators ($B^\gamma_A[V]$ and $B^\gamma_{RA}[V]$) are known to be contractive and converge to the true Value in the limit of discounting.

A critical aspect of the methodology is the explicit recognition of the distinction between the algebra of TL robustness scores and the algebra of Value functions. While logical identities hold for robustness scores, their analogues for Value functions often become inequalities due to the $\max_\alpha$ operator, implying that a simple logical decomposition does not directly yield an optimal Value decomposition.

**B. Value Decomposition Rules (VDR) and Bellman Equations**
The research establishes a formal algebra for Value function decomposition:
- **Theorem 1 (Value Decomposition Rules - VDR)**: This theorem provides four rules for decomposing Value functions:
 1. **Right-Until**: $V^*[p \text{ U } p'](x) = V^*[p \text{ U } v[p']](x)$, where $v[p']$ denotes the AP associated with $V^*[p']$. This means the optimal value to reach $p'$ while satisfying $p$ is the same as reaching a state where $V^*[p']$ is guaranteed, while satisfying $p$.
 2. **OR**: $V^*[p \lor p'](x) = V^*[v[p] \lor v[p']](x)$. The optimal value for OR is the maximum of the individual optimal values.
 3. **Weak-AND**: If $p$ is independent of the action sequence $\alpha$, $V^*[p \land p'](x) = V^*[v[p] \land p']](x)$. This is crucial for specifications where one part (e.g., a safety constraint) has a fixed outcome regardless of how other parts are optimized.
 4. **NEXT**: $V^*[Xp](x) = V^*[Xv[p]](x)$. The optimal value for the next state property depends on the optimal value of the child state.
These rules enable the transformation of a complex Value function into a hierarchy (or graph) of simpler Values, each potentially solvable by "atomic" Bellman equations.

- **Theorem 2 (Multi-Reach-Avoid Value Decomposition)**: For tasks involving the conjunction of N Until predicates and a global safety specification ($\bigwedge_{i \in I} (q_i \text{ U } r_i) \land Gq$), the authors prove that this complex Value function can be recursively decomposed into a structure equivalent to a single Reach-Avoid Value. This effectively means transforming the overall goal into reaching any one target $r_i$ while maintaining general safety $\bigwedge q_i \land q$ and ensuring the ability to satisfy the remaining $N-1$ Until predicates ($p_{-i}$). This recursive application results in $2^N-1$ sub-Values, each solvable with the discounted RA-BE.

- **Theorems 3 & 4 (Recurrent Reach-Avoid Value Decompositions)**: For recurrence specifications, such as $G(\bigwedge_{i \in I} (q_i \text{ U } r_i))$, the Value function is characterized implicitly. Theorem 3 shows that $V^*[G(q \text{ U } r)](x) = V^*[q \text{ U } (r \land Xv[p])](x)$, where $p = G(q \text{ U } r)$, creating a self-referential loop. This generalizes to N coupled Values arranged in a cyclic dependency for multiple recurrent until predicates. To solve these implicit Value functions, Theorem 4 introduces a novel **Reach-Avoid-Loop (RA$\ell$) Bellman operator** ($B^\gamma_{RA\ell}[V_i]$). This operator is proven to be contractive, guaranteeing a unique fixed point that converges to the desired Value in the limit of discounting ($\gamma \rightarrow 1$). The well-posedness of these Values is further discussed by connecting them to the limit of finite recurrence iterations.

**C. Algorithm: Value-Decomposition PPO (VDPPO)**
The theoretical decomposition leads to VDPPO, an algorithm that embeds the decomposed Value Graph (DVG) into a neural network architecture:
1. **valtr (DVG Generation Tool)**: This utility processes an input TL specification, parses it into an Abstract Syntax Tree (AST), applies logical equivalences and rearrangement rules to conform it to the forms amenable to VDR (e.g., Theorem 5 in Appendix H), and generates the DVG. The DVG defines nodes representing predicates and Values, with edges indicating dependencies. It handles cyclic recurrence compositions via special nodes.
2. **Dynamic Programming (DP) for Low-Dimensional Problems**: For simple cases, the DVG enables direct computation of Values using topological sorting and dynamic programming, with cyclic nodes approximated via finite recurrences.
3. **Policy Inference with DVG Traversal**: The policy execution proceeds by starting at the DVG's root node. At each time step, the policy corresponding to the current node is executed. Upon satisfaction of the current node's predicate (based on the state), the policy switches to the appropriate child node in the DVG. This compositional policy synthesis is detailed for OR, weak-AND, NEXT, and right-UNTIL operators, sometimes requiring state augmentation to track the current DVG node.
4. **VDPPO Architecture and Training**: VDPPO is a specialized variant of PPO. Instead of separate neural networks for each sub-Value, it employs a **single two-layer neural network for all Value functions** in the DVG and **another single two-layer network for all corresponding policies**. This is achieved by augmenting the state input with a one-hot embedding of the current DVG node. During training, VDPPO performs rollouts for various nodes concurrently. The advantage and target values for each node are computed using the relevant discounted Bellman equation (A-BE, RA-BE, or RA$\ell$-BE), crucially bootstrapping the current Value estimates from the child nodes in the DVG (represented as a feedback loop). The policy network is trained using the standard PPO objective with the calculated advantage estimates.

**D. Experimental Validation**
The methodology includes validation through extensive simulation experiments across four diverse environments (DoubleInt, Herding, Delivery, Manipulator) and real-world hardware experiments involving heterogeneous robotic teams (Crazyflie drones and Unitree Go2 quadruped) on Herding and Delivery tasks. Baselines include LCRL, TL-MPPI, PPO with robustness as reward, and PPO-LSTM. Performance is measured by finite-horizon TL satisfaction rates and individual subformula satisfaction.

### 4. Main Findings and Results

The research yielded several key findings, both theoretical and empirical, demonstrating the efficacy of Bellman Value decomposition for complex temporal logic tasks.

**A. Theoretical Foundations and Decompositions:**
- **Formalization of Value Decomposition Rules (VDR)**: The study established a formal algebraic connection between Temporal Logic and Bellman Value functions, articulating four Value Decomposition Rules (VDR). These rules delineate specific conditions under which the maximization over action sequences commutes with logical operators (OR, right-Until, weak-AND, NEXT), enabling principled decomposition of complex Value functions. This theoretical contribution distinguishes the algebra of Value functions from that of temporal logic robustness scores, addressing a critical theoretical gap.
- **Multi-Reach-Avoid Value Decomposition (Theorem 2)**: It was formally proven that Value functions for conjunctions of N Until predicates combined with a global safety specification can be recursively transformed into a graph of $2^N-1$ simpler Until-type Value functions. Each of these simpler Values can then be solved using established discounted Reach-Avoid Bellman Equations (RA-BE). This provides a systematic way to break down complex multi-goal, multi-safety objectives.
- **Recurrent Reach-Avoid Value Decompositions (Theorems 3 & 4)**: For tasks requiring persistent goal achievement or revisitation (e.g., $G(q \text{ U } r)$), the research showed that the Value function possesses an implicit, self-referential structure, characterized as a loop of N coupled Values. To address this, a novel **Reach-Avoid-Loop (RA$\ell$) Bellman operator** was introduced and formally proven to be contractive. This guarantees the existence of a unique fixed point that converges to the desired optimal Value in the limit of discounting, providing a robust theoretical tool for approximating such complex recurrent objectives.

**B. Algorithmic Performance in Simulation:**
- **Scalability with Temporal Logic Breadth (Q1)**: In a double integrator environment, VDPPO demonstrated superior performance compared to LCRL, TL-MPPI, PPO, and PPO-LSTM when the complexity of the TL specification increased in breadth (i.e., requiring an agent to visit a larger number of targets in *any order*). VDPPO maintained higher success rates, indicating its ability to manage the combinatorial explosion of possible paths inherent in such specifications.
- **Scalability with Temporal Logic Depth (Q2)**: For TL specifications with increasing depth (i.e., requiring an agent to visit a larger number of targets in a *fixed sequential order*), VDPPO consistently outperformed all baselines. It reliably achieved up to 128 sequential targets, whereas non-decompositional methods struggled significantly, presumably due to the exponentially decreasing probability of randomly satisfying deeply nested TL conditions.
- **Performance on Complex, High-Dimensional Tasks (Q3)**: VDPPO achieved the highest success rates across three challenging simulation environments involving complex dynamics and interactions:
 - **Herding (30D)**: For a heterogeneous team herding multiple targets while avoiding obstacles, VDPPO effectively coordinated agents, outperforming baselines that exhibited excessive caution.
 - **Delivery (18D)**: In a task requiring recurrent target visits and resupply for a heterogeneous team, VDPPO demonstrated sophisticated collaborative behaviors, enabling rapid task completion without collisions.
 - **Manipulator (39D)**: For a robotic arm interacting with objects under sequential TL, VDPPO showed superior performance, particularly in maintaining task completion over longer sequences, unlike baselines that degraded.
- **Ablation Study on Parameter Sharing**: An ablation study on VDPPO's architecture revealed that sharing parameters across the actor (policy) neural network for different Decomposed Value Graph (DVG) nodes improved success rate and reduced variance. While sharing critic (Value function) parameters alone could reduce success rate, combining shared actor and critic parameters yielded performance nearly identical to having no parameter sharing, but with a significant improvement in training speed (up to N times faster, where N is the number of decompositions). This validated the efficiency of the one-hot embedding strategy.

**C. Hardware Validation:**
- **Herding Task**: Real-world experiments using Crazyflie drones and a Unitree Go2 quadruped successfully executed the complex herding task. The VDPPO-trained policy exhibited emergent division of labor: a faster drone initially gathered the "sheep" drones, while the slower quadruped strategically positioned itself to receive and subsequently block the herd from dispersing.
- **Delivery Task**: In the hardware-based delivery task, involving recurrent visits to dynamic targets and resupply for two drones and a quadruped, VDPPO facilitated sophisticated coordination. Drones navigated the arena periphery, while the quadruped anticipated their movements, dynamically adjusting its position to facilitate resupply close to targets. This collaborative behavior enabled efficient deliveries and resupplies without collisions in a constrained environment.

### 5. Significance and Potential Impact

This research contributes to the field of intelligent control and reinforcement learning by offering a systematic and theoretically grounded approach to solving complex robotic tasks specified in Temporal Logic. Its significance and potential impact are multi-faceted:

- **Bridging Formal Methods and Reinforcement Learning**: The work establishes a formal algebraic connection between the high-level expressiveness of Temporal Logic (TL) and the operational efficiency of optimal Value functions. By rigorously proving how complex Value functions can be decomposed, it provides a principled bridge between formal task specification and the synthesis of optimal, executable policies, addressing a long-standing challenge in robotics and control theory.

- **Enhanced Capability for Complex Robotic Missions**: The ability to automatically decompose and learn policies for nuanced combinations of safety and liveness objectives significantly expands the scope of tasks that autonomous robots can reliably perform. This is particularly relevant for applications requiring long-horizon planning, sequential goal achievement, recurrent tasks, and strict safety adherence in uncertain or dynamic environments, such as autonomous driving, drone swarms, industrial automation, and space exploration.

- **Improved Scalability and Learning Efficiency**:
 - **Combating Combinatorial Explosion**: By transforming complex, monolithic TL tasks into a Decomposed Value Graph (DVG) of simpler, interconnected sub-problems, the method effectively mitigates the combinatorial explosion that often plagues automata-based approaches in high-dimensional state spaces.
 - **Accelerated Training**: VDPPO's multi-task learning architecture, utilizing shared neural network parameters conditioned by node embeddings, enables the simultaneous training of policies and Value functions for multiple sub-tasks. This approach is demonstrated to be significantly faster than training individual models, making learning for complex TL specifications more practical and efficient.
 - **Dense Learning Signals**: The reliance on Bellman equations derived from Hamilton-Jacobi Reachability (HJR) provides dense and informative learning signals throughout the learning process, which helps overcome the notorious sparse reward problem prevalent in many RL-TL integrations.

- **Robustness and Real-World Applicability**: The comprehensive validation, spanning diverse simulated environments with varying complexities (multi-agent, heterogeneous dynamics, high-dimensionality) and culminating in successful deployment on real-world hardware, suggests a high degree of robustness and practical applicability. The emergent coordinated behaviors observed in hardware experiments (e.g., division of labor in herding, anticipatory resupply in delivery) highlight the method's capacity to generate sophisticated, adaptive policies.

- **Foundation for Future Research**: The identified limitations, such as the exponential scaling for "any-order" tasks with a very large number of sub-goals and the current lack of explicit running cost minimization or direct handling of stochasticity within the decomposition algebra, present clear avenues for future theoretical and algorithmic advancements. This work provides a strong foundation for exploring approximations, incorporating richer cost functions, and extending the framework to more uncertain or partially observable domains.

In conclusion, this research presents a powerful paradigm for optimal control in the presence of complex temporal logic. By deeply integrating theoretical insights into Value function structure with advanced deep reinforcement learning techniques, it moves closer to enabling autonomous systems to operate safely and effectively in increasingly complex, real-world scenarios.
