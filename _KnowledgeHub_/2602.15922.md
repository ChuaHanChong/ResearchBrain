# World Action Models are Zero-shot Policies

> [!summary] Summary
> DreamZero, a 14B World Action Model (WAM) developed by NVIDIA, enables zero-shot robot policies by jointly predicting future video states and actions from diverse data. It achieves an average task progress of 39.5% on unseen tasks and demonstrates 42% relative improvement in cross-embodiment transfer using video-only demonstrations, all while maintaining real-time control at 7Hz through significant optimization.

## Problem

- Existing VLA models struggle to generalize to unseen physical motions in novel environments — static image-text pretraining provides limited spatiotemporal priors.
- Learning generalist robot policies requires extensive, repetitive, task-specific demonstrations — inefficient and doesn't scale.
- Cross-embodiment transfer is inefficient, typically requiring new action-labeled data for each robot platform.

## Method

- Introduces **DreamZero**, a 14B WAM using an ==autoregressive diffusion transformer== that jointly predicts future video frames and robot actions.
- Leverages a pretrained video diffusion backbone with a ==flow-matching objective== to learn world physics and spatiotemporal dynamics from diverse robot data.
- **DreamZero-Flash**: asynchronous execution with decoupled noise schedules to achieve real-time closed-loop control at ==7Hz==.

## Results

- **62.2%** task progress on seen tasks in unseen environments (vs. **27.4%** for SotA VLAs).
- **39.5%** task progress on 10 entirely unseen tasks (vs. **16.3%** for VLA baselines).
- **42%** relative improvement in cross-embodiment transfer using only 10–20 minutes of video-only demonstrations.
- DreamZero-Flash: **7Hz** inference (**150ms**), achieving **74%** task progress vs. **83%** for full 4-step DreamZero.

## Takeaways

> [!tip] Key Insights
> - Jointly predicting future world states (video) + actions provides powerful spatiotemporal priors for zero-shot generalization.
> - Generalist policies can be learned from diverse, non-repetitive data — reducing reliance on laborious demonstrations.
> - Cross-embodiment transfer with WAMs is highly efficient — video-only demos from other robots or humans suffice.
