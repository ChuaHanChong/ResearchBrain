# RoboMME-Interference: Benchmarking Robot Memory Under Interference

> [!summary] Summary
> RoboMME-Interference extends the RoboMME benchmark to test robot memory under cross-session distraction, inserting k=0,1,3,7 unrelated sessions between a relevant demonstration and a query episode. Evaluating nine memory-augmented pi-0.5 variants shows perceptual memory gains erode steadily as distractors accumulate, but a visual-similarity retrieval step fully restores performance at every interference level.

## Problem

- Existing robot-memory benchmarks measure recall within a single episode or short context, never testing whether memory survives across many unrelated intervening sessions.
- Long-term multi-session recall benchmarks exist for LLMs and show recall collapsing with unrelated history, but no comparable stress test exists for robot memory systems.
- Robot policies with memory mechanisms (retrieval, stores, summarization) are evaluated only under clean, uncluttered histories, leaving interference robustness completely unmeasured.

## Method

- **RoboMME-Interference** constructs a history buffer per query episode containing the relevant demonstration followed by k unrelated distractor sessions drawn from different task families to avoid contradictory cues.
- The benchmark sweeps k in {0,1,3,7} across nine demonstration-separable RoboMME task families, feeding each unmodified memory variant (FrameSamp, TokenDrop, TTT) through its own native mechanism with no retraining.
- **Retrieval-FrameSamp-Modul** adds a ==SigLIP-embedding retrieval== step that splits the buffer into sessions via ==cosine-similarity scene-change detection== and passes only the best-matching session to the policy.

## Results

- FrameSamp-Modul boosts accuracy by **+27.1** percentage points at k0 (**18.2%** to **45.3%**) but decays about **26** points to **19.3%** by k7, nearly back to its no-history floor.
- Memory-integration mechanism matters more than representation: FrameSamp-Modul reaches **45.3%** at k0 versus only **26.7%** (Context) and **27.1%** (Expert) for the same representation.
- Retrieval-FrameSamp-Modul holds steady between **44.7%** and **44.9%** success across all interference levels, fully recovering the no-distractor performance that the unmodified variant loses.

## Takeaways

> [!tip] Key Insights
> - Memory gains measured only in clean, single-episode settings can be illusory in deployment; robustness to interference is a distinct capability that must be tested separately.
> - How memory is integrated into a policy (adaptive conditioning vs. context concatenation vs. dedicated expert) can matter more than which representation is stored.
> - Decay from interference can be localized to a retrieval/selection failure rather than a representation limit, so adding explicit retrieval can recover performance cheaply without retraining.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work addresses a challenge in the field of robotics concerning the practical deployment of robots in dynamic, real-world environments. As robots are increasingly expected to operate across numerous sessions and tasks, they accumulate a substantial history of experience. The ability to recall relevant information from this long, potentially cluttered history is crucial for effective long-term operation.

Existing robot memory systems and benchmarks primarily focus on short-context or single-episode memory. While recent Vision-Language-Action (VLA) policies, such as those by Brohan et al. (2023), Kim et al. (2024), and Black et al. (2024), integrate memory in various forms—including on-demand retrieval, observation stores, and compressed states—their performance under sustained interference remains largely unquantified. Current robot memory benchmarks, including RoboMME (Dai et al., 2026), Chen et al. (2026), and Lei et al. (2026), measure within-episode memory but do not extensively evaluate how memory systems perform as session history lengthens and becomes interspersed with unrelated information.

This contrasts with developments in Large Language Models (LLMs), where long-term, multi-session recall benchmarks (Maharana et al., 2024; Wu et al., 2025; Tavakoli et al., 2025) have revealed a significant degradation in performance when irrelevant history accumulates (Liu et al., 2024). These LLM benchmarks have led to the development of explicit memory toolkits involving retrieval, late interaction, recurrence, and compression—strategies that are beginning to surface in robot policies.

The present work introduces RoboMME-Interference to bridge this gap in robot memory evaluation. By extending the existing RoboMME benchmark, it provides a means to measure the robustness of robot memory systems to cross-session interference, thereby aligning robot memory research with a critical challenge already identified in the LLM domain. It seeks to ascertain whether current robot memory systems can retain useful information when it is embedded within a longer history of unrelated sessions.

### 2. Key Objectives and Motivation

The primary motivation for this research stems from the operational demands on robots in real-world settings. Robots deployed over extended periods will inevitably accumulate experience from a multitude of tasks and sessions. Critical information for a current task might be located far back in this history, surrounded by data from unrelated past activities. For a robot to perform reliably and intelligently, its memory system must therefore be capable of long-context information recall and robust operation in the presence of interference.

The core question motivating this study is: "when a useful prior session is embedded in a longer history of unrelated sessions, are current robot-memory systems still able to recall it?"

Based on this, the key objectives of the work are:

1. **Develop a Cross-Session Interference Benchmark**: To create RoboMME-Interference, a novel benchmark built upon RoboMME, specifically designed to evaluate robot memory systems under varying levels of interference from unrelated past sessions. This involves systematically inserting a controlled number of irrelevant sessions between a relevant prior demonstration and the query episode.
2. **Quantify Performance Decay under Interference**: To measure how the accuracy of current robot memory systems degrades as the number of unrelated sessions (distractors) in the memory history increases. The goal is to directly assess the impact of session length and extraneous memory on recall accuracy.
3. **Benchmark Existing Robot Memory Systems**: To evaluate a selection of nine released memory-augmented policy variants from RoboMME across the newly introduced interference levels. This includes analyzing their performance across different task families and difficulty levels to provide a comprehensive grid of results.
4. **Investigate Recovery Mechanisms**: To explore whether the observed decline in memory performance due to interference can be mitigated. Specifically, the objective is to test if adding a simple retrieval step, designed to selectively extract the relevant information, can restore the memory system's performance to its no-interference level.
5. **Highlight Research Gaps**: To emphasize the importance of long-context memory and robustness to interference for real-world robotic deployments and to demonstrate that current systems largely lack these capabilities, thereby pointing towards future research directions.

Overall, the motivation is to advance robot capabilities towards more autonomous and context-aware operation by addressing a fundamental limitation in their ability to manage and utilize past experiences effectively in complex, dynamic environments.

### 3. Methodology and Approach

The research introduces RoboMME-Interference, a benchmark designed to evaluate robot memory systems under varying levels of cross-session interference. This benchmark extends the existing RoboMME framework.

#### 3.1. Benchmark Design: The History Buffer

For each query episode, a memory buffer is constructed containing:
- **Relevant Lesson**: The original demonstration section providing evidence for the query task.
- **Distractor Sessions**: *k* unrelated sessions are inserted *after* the relevant lesson. The number of distractors *k* is varied across {0, 1, 3, 7}, representing increasing levels of interference (none, light, moderate, strong). A "no-history" baseline with an empty buffer is also used.
- **Distractor Length**: Each distractor session contributes a fixed-length section of history, standardized to 32 stored frames, which corresponds to the sampled-frame budget of FrameSamp, a core perceptual variant. This ensures comparability across different distractor sessions. Distractors are derived from the first 256 raw frames of an episode, subsampled at a stride of 8.
- **Memory Consumption**: All evaluated memory systems process this history buffer using their unmodified mechanisms (e.g., FrameSamp samples frames, TokenDrop selects tokens, recurrent variants process sampled history). No per-condition retraining is performed; only the buffer content changes.

#### 3.2. Task Selection

The benchmark utilizes nine of RoboMME’s sixteen task families. These were selected because their prior relevant information is presented as a self-contained demonstration video, distinct from the execution phase, allowing it to be cleanly separated and inserted into the external history buffer with distractors. The selected tasks include:
- **Imitation Tasks**: MoveCube, InsertPeg, PatternLock, RouteStick.
- **Video-Conditioned Reference Tasks**: VideoRepick, VideoPlaceButton, VideoPlaceOrder.
- **Video-Conditioned Permanence Tasks**: VideoUnmask, VideoUnmaskSwap.

Tasks that interleave their cue within a single execution episode (e.g., counting, button/highlight-based variants) were excluded as they do not offer a separable prior section for cross-session interference.

**Distractor Source**: Distractors are drawn from *different* task families than the query task. This design choice prevents the introduction of conflicting factual information (e.g., a different target cube for the same task) that would complicate the interpretation of performance degradation. Instead, cross-family distractors are simply irrelevant, allowing for a focused assessment of interference robustness.

#### 3.3. Memory Systems Evaluated

The study evaluates nine systems: the base π0.5 policy (Physical Intelligence et al., 2025) which has no memory, and eight memory-augmented variants from RoboMME. These variants combine different memory representations with distinct integration mechanisms:

- **Representations**:
 - **Perceptual**: FrameSamp (reduces or resamples visual-history tokens; Bolya et al., 2023), TokenDrop (Yu et al., 2023).
 - **Recurrent**: TTT (maintains a compressed hidden state via test-time training; Sun et al., 2024), following recurrent memory transformers (Bulatov et al., 2022).
- **Integration Mechanisms**:
 - **Context**: Concatenates memory tokens with the input.
 - **Modulator**: Conditions the policy via adaptive LayerNorm.
 - **Expert**: Routes memory through a dedicated expert using block-wise causal attention (Dai et al., 2026).

Symbolic variants (which use predefined subtask annotations) and recurrent variants without released checkpoints (all RMT, and TTT-Modulator) were excluded.

#### 3.4. Evaluation Procedure

Each of the nine systems was evaluated on all nine eligible task families, with each family comprising 50 test episodes. Success rates were calculated for each memory system across the five history conditions (no-history, k0, k1, k3, k7). Wilson 95% confidence intervals were reported for success rates to account for estimation from a finite set of episodes. The evaluation uses one released checkpoint per system, with each episode evaluated once.

#### 3.5. Retrieval Experiment

To investigate the recoverability of performance decay, a retrieval step was added to FrameSamp-Modul, identified as the strongest variant. The retrieval mechanism operates as follows:
- **Session Segmentation**: The history buffer is first segmented into individual sessions based on visual scene changes. Scene changes are detected by identifying instances where the cosine similarity between adjacent frame embeddings falls below a fixed threshold (0.923), which was chosen to differentiate within-session similarity from across-session differences.
- **Embedding**: Every frame within the history buffer and the robot's current observation are embedded using SigLIP (Zhai et al., 2023).
- **Selection**: The system then identifies the session in the history buffer that contains the frame most visually similar to the current observation. Only this best-matching session is then passed to the FrameSamp-Modul policy.
- The policy and encoder were used as released, and the benchmark's ground-truth session boundaries were not utilized during this process.

### 4. Main Findings and Results

The study presents a comprehensive evaluation of robot memory systems under cross-session interference, yielding several key findings.

#### 4.1. Overall Performance under Interference

- **Baseline Performance**: The π0.5 policy (without memory) achieved an overall success rate of 17.3%.
- **Memory Benefit (k=0)**: When only the relevant lesson was present in the buffer (k=0, no distractors), perceptual memory variants showed a notable increase in accuracy compared to their own no-history baselines. FrameSamp-Modul, the highest-performing variant, boosted accuracy by 27.1 percentage points (pp), from 18.2% (no-history for this system) to 45.3% (k=0). TokenDrop-Modul also showed a gain, reaching 35.3% at k=0 from its no-history baseline of 17.1%.
- **Decay with Interference**: As unrelated sessions accumulated in the history buffer, the performance gains observed at k=0 consistently and steadily eroded across all perceptual memory variants. FrameSamp-Modul's success rate dropped approximately 26 pp, from 45.3% at k=0 to 19.3% at k=7, effectively returning to near its no-history performance level. TokenDrop-Modul similarly decayed by approximately 16 pp, from 35.3% at k=0 to 19.8% at k=7.

#### 4.2. System-Specific Performance

- **Modulator Variants Outperform**: Variants using the "Modulator" integration mechanism (FrameSamp-Modul, TokenDrop-Modul) consistently demonstrated superior performance compared to "Context" and "Expert" variants using the same perceptual representations. For instance, FrameSamp-Modul achieved 45.3% at k=0, while FrameSamp-Context and FrameSamp-Expert reached 26.7% and 27.1%, respectively.
- **Recurrent Variants' Limited Impact**: The recurrent TTT variants (Recurrent-TTT-Expert, Recurrent-TTT-Context) showed minimal improvement, maintaining success rates at or below 18% even at k=0. Their performance remained close to their respective no-history levels throughout the interference conditions.

#### 4.3. Task and Difficulty Variability

- **Task Family Differences**: The impact of memory and its decay under interference varied across the nine task families. Some tasks were more sensitive to memory assistance or interference than others, while some remained challenging for all systems regardless of memory.
- **Difficulty Stratification**: The performance lift from memory was most pronounced on RoboMME’s "easy" and "medium" difficulty episodes. For "hard" episodes, all memory systems tended to perform near the baseline floor, indicating that memory alone was insufficient to resolve the inherent difficulty of these tasks.

#### 4.4. Impact of Retrieval

- **Recovery of Performance**: When a retrieval step was added to FrameSamp-Modul, its k=0 success rate was restored and maintained across all interference levels (k=1, k=3, k=7). Retrieval-FrameSamp-Modul achieved success rates between 44.7% and 44.9% at every interference level, contrasting with the unmodified FrameSamp-Modul's decline from 45.3% to 19.3%.
- **Targeted Recovery**: This recovery was observed on seven of the nine task families where FrameSamp-Modul initially showed a performance gain at k=0. For the two families (VideoUnmask and VideoUnmaskSwap) where memory did not provide an initial benefit, the retrieval-augmented variant performed comparably.
- **Implication for Decay**: This result suggests that the observed decay in performance for unmodified variants is largely attributable to challenges in selecting the relevant information (frames or sessions) from the memory buffer amidst distractors, rather than an inability to process the relevant information itself. The retrieval mechanism, by successfully isolating the pertinent demonstration, allows the policy to operate as if no distractors were present. The effectiveness of the retrieval in this setup was facilitated by the visual similarity between the query and its lesson, and the distinct nature of the cross-family distractors.

### 5. Significance and Potential Impact

This research contributes to the field of robotic intelligence by identifying and quantifying a critical limitation in current robot memory systems and proposing a potential mitigation strategy.

**Addressing a Gap in Benchmarking**: The introduction of RoboMME-Interference fills a crucial gap in the evaluation of robot memory. By systematically testing performance under cross-session interference, it provides a benchmark that more closely reflects the challenges robots face in real-world, long-term deployments. This benchmark can serve as a standardized tool for comparing and advancing memory-augmented robotic policies.

**Highlighting a Fundamental Weakness**: The findings demonstrate that while existing robot memory systems can leverage relevant prior information in short-context scenarios, their performance degrades significantly and consistently when faced with irrelevant information over longer histories. This decay represents a substantial barrier to the practical deployment of robots that need to learn and adapt over extended periods. It indicates that the ability to process memory is often present, but the capacity for *selective attention* or *retrieval* from a cluttered history is underdeveloped.

**Informing Future Design of Robot Memory Systems**: The research underscores the necessity of designing robot memory systems that are not only capable of storing and processing information but also robustly retrieving relevant details amidst distractions. The successful recovery of performance through a simple retrieval step provides empirical evidence that effective filtering mechanisms can mitigate the interference problem. This suggests that future research could focus on integrating sophisticated retrieval components into memory architectures, drawing parallels and insights from retrieval-augmented approaches in LLMs.

**Implications for Real-World Robotics**: For robots to achieve true generalization and operate autonomously in complex environments, they must be able to recall pertinent experiences from their operational history without being overwhelmed by irrelevant data. This work highlights that current systems largely fall short of this requirement and provides a quantitative measure for this deficiency. Developing robust long-context memory with interference robustness is essential for applications ranging from manufacturing to service robotics, where tasks are often repetitive but interspersed with unique events and distractions.

**Guiding Further Research**: The paper explicitly points to more complex scenarios not covered, such as continuous experience streams without clear session boundaries, situations where the relevant experience may not be visually similar, or information spread across multiple sessions. These limitations delineate clear avenues for future research, suggesting a progressive path toward more sophisticated robot memory and retrieval systems. The availability of the benchmark, code, and data further supports and facilitates such future investigations.
