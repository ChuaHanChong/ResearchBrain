# Agent0: Unleashing Self-Evolving Agents from Zero Data via Tool-Integrated Reasoning

> [!summary] Summary
> Agent0, developed by researchers at UNC-Chapel Hill, Salesforce Research, and Stanford University, introduces a fully autonomous framework for evolving high-performing LLM agents from scratch, without human-curated data. The system achieves substantial improvements, such as an 18% increase in mathematical reasoning and a 24% boost in general reasoning for Qwen3-8B-Base models, through a co-evolutionary loop and tool-integrated learning.

## Problem

- Current LLM agents, especially those trained with Reinforcement Learning (RL), heavily depend on massive, high-quality human-curated datasets, creating scalability and cost bottlenecks.
- Existing self-evolution frameworks often suffer from "learning stagnation," as the tasks they generate rarely surpass the model's current capabilities, limiting continuous improvement.
- Many frameworks struggle to foster complex multi-step reasoning and effective external tool integration, often limited to single-round interactions.

## Method

- A fully autonomous, iterative ==co-evolutionary framework== where a ==Curriculum Agent== generates increasingly challenging tasks and an Executor Agent learns to solve them, both initialized from a base LLM.
- Seamless integration of an external code interpreter tool, where the Curriculum Agent is explicitly rewarded for generating tasks that require tool use, establishing a "virtuous cycle."
- ==Ambiguity-Dynamic Policy Optimization (ADPO)== for Executor training, which employs ambiguity-aware advantage scaling and dynamically modulated trust regions to handle noisy pseudo-labels from self-generated data.

## Results

- Agent0 achieved an **18%** average improvement in mathematical reasoning and a **24%** boost in general-domain reasoning on Qwen3-8B-Base models, consistently outperforming existing self-evolutionary and tool-integrated baselines.
- The co-evolutionary loop demonstrated stable, progressive performance improvement over multiple iterations, with the curriculum agent successfully generating more difficult, tool-reliant tasks.
- Ablation studies confirmed the critical roles of Curriculum Agent training, the explicit tool reward, repetition penalty, ADPO, and multi-turn reasoning for the framework's overall effectiveness.

## Takeaways

> [!tip] Key Insights
> - A symbiotic co-evolutionary process between a task-generating Curriculum Agent and a task-solving Executor Agent can drive continuous, autonomous improvement from zero human data.
> - Deeply integrating external tools into the curriculum generation process itself creates a self-reinforcing cycle, leading to the discovery and mastery of increasingly complex, tool-aware reasoning skills.
> - Addressing ambiguity and noise in self-generated training data through mechanisms like ambiguity-aware advantage scaling and dynamic trust regions is crucial for stable and effective self-evolutionary learning.
