# V*: Guided Visual Search as a Core Mechanism in Multimodal LLMs

> [!summary] Summary
> This research introduces V*, an LLM-guided visual search mechanism, to address the visual information bottleneck in Multimodal Large Language Models (MLLMs), enabling them to actively process and reason about high-resolution visual details. The proposed SEAL framework allows MLLMs to identify missing visual information and dynamically search for it, leading to a 20%+ improvement in accuracy over commercial MLLMs like GPT-4V on fine-grained visual reasoning tasks and reduced hallucinations.

## Problem

- Existing end-to-end MLLMs suffer from a 'visual information bottleneck' due to processing low-resolution images, leading to significant loss of fine-grained detail.
- Current MLLMs lack an intrinsic mechanism to actively identify missing visual information or proactively seek it out in complex, high-resolution scenes.
- LLM-tool-using systems rely on text-only processing of visual information, leading to potential data loss and cascaded errors from imperfect vision experts.

## Method

- Introduces ==SEAL (Show, SEArch, and TelL)==, a meta-architecture that integrates an LLM-guided visual search mechanism (==V*==) into existing MLLMs.
- The V* visual search model enables MLLMs to actively query for missing visual details and utilize their internal world knowledge and common sense to guide efficient, ==hierarchical search==.
- A ==Visual Working Memory (VWM)== is constructed to store and integrate global image, question, and dynamically searched target information for the VQA LLM to generate more informed responses.

## Results

- The SEAL framework, incorporating V*, achieved **75.39%** accuracy on the V*Bench benchmark for fine-grained visual grounding, outperforming GPT-4V (**54.97%**) and Gemini Pro (**48.16%**).
- V* significantly reduced the average 'search length' to **4.65 steps** per target, demonstrating an informed search strategy that is more efficient than baseline methods and comparable to human eye fixations.
- The integration of V* maintained the base model's general multimodal capabilities and improved performance on the POPE hallucination benchmark (from **76.5%** to **82.4%**), indicating reduced object hallucination.

## Takeaways

> [!tip] Key Insights
> - Active visual search, inspired by human cognition, is crucial for Multimodal Large Language Models (MLLMs) to achieve precise visual grounding on high-resolution, visually crowded images.
> - Large Language Models (LLMs) can effectively guide visual search using common sense and world knowledge, enhancing efficiency and accuracy beyond generic object detectors.
> - Training MLLMs to identify missing information and incorporate dynamically retrieved visual details into a visual working memory improves reasoning and reduces visual hallucinations.
