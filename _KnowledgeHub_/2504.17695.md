# PICO: Reconstructing 3D People In Contact with Objects

> [!summary] Summary
> A framework combines optimization-based fitting with dense contact modeling to reconstruct 3D human-object interactions from single images, introducing a dataset of 4,123 images with 3D contact annotations across 44 object categories and demonstrating improved generalization to unconstrained scenarios compared to existing approaches.

## Problem

- Existing methods for 3D human-object interaction reconstruction struggle with unconstrained images and arbitrary object categories
- Lack of datasets with dense 3D contact annotations between humans and objects limits development of robust solutions

## Method

- **PICO**-db: New dataset with 4,123 images containing 3D contact annotations for both humans and objects
- PICO-fit: Three-stage optimization method using contact correspondences and image evidence to refine human and object poses

## Results

- Successfully reconstructs 3D interactions with previously untackled object classes in unconstrained settings
- Outperforms existing methods on perceptual realism in real-world scenarios
- Demonstrates competitive performance on unseen InterCap dataset without requiring retraining

## Takeaways

> [!tip] Key Insights
> - Contact information serves as a crucial cue for accurate 3D reconstruction of human-object interactions
> - Combining OpenShape foundation model for object retrieval with contact-based optimization enables handling of diverse object categories
> - Multi-stage optimization separating object registration, alignment and human pose refinement improves reconstruction quality
