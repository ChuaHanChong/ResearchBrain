# Rethinking Progression of Memory State in Robotic Manipulation: An Object-Centric Perspective

> [!summary] Summary
> Researchers introduce LIBERO-Mem, a benchmark for non-Markovian robotic manipulation, and Embodied-SlotSSM, an object-centric Vision-Language-Action framework. This work enables robots to retain object-specific memory for long-horizon tasks and partially observable environments, demonstrating improved performance over baselines in complex manipulation scenarios.

## Problem

- Existing robotic benchmarks predominantly assume Markovian processes, failing to evaluate tasks requiring persistent object-specific memory or historical reasoning.
- Current Vision-Language-Action (VLA) models lack mechanisms to encode and recall object-specific histories, leading to failures in non-Markovian tasks with visual ambiguities.
- Token-based representations in VLA models face scalability issues for long temporal sequences, limiting their applicability in tasks requiring extensive memory.

## Method

- Introducing **LIBERO-Mem**, a non-Markovian benchmark suite featuring 10 tasks designed to stress-test object-centric memory, temporal dependencies, and identity ambiguities.
- Proposing Embodied-SlotSSM, a slot-centric VLA framework that integrates object-centric learning with State-Space Models (SSMs) to maintain structured, persistent object identities.
- Implementing temporal coherence with Slot Attention and a temporal contrastive loss, along with a Slot Dynamics Encoder predicting short-term static latents, to enable context-aware action prediction.

## Results

- Embodied-SlotSSM achieved an **83.0%** average success rate on the general LIBERO-Goal benchmark, outperforming SlotVLA (**75.5%**) and OpenVLA (**32%**) baselines.
- On the new non-Markovian LIBERO-Mem benchmark, Embodied-SlotSSM showed a **14.8%** average subgoal completion rate, a notable improvement over baselines (**5.0%** for OpenVLA/SlotVLA h=8, **0%** for SlotVLA h=1).
- Qualitative analysis demonstrated that the model consistently tracks the same object instance across time, even during occlusion, indicating robust object permanence for long-horizon reasoning.

## Takeaways

> [!tip] Key Insights
> - Integrating structured, object-centric memory provides a strong inductive bias for robust state estimation and decision-making, even in general manipulation tasks.
> - Slot-based State-Space Models (SSMs) can effectively maintain spatio-temporally consistent object identities over extended periods, offering a scalable approach for long-horizon tasks.
> - Object permanence and historical reasoning are critical for handling non-Markovian scenarios where identical visual inputs require different actions based on prior interactions.
