# ACTLLM: Action Consistency Tuned Large Language Model

> [!summary] Summary
> ACTLLM introduces a framework for robot manipulation that unifies visual information interpretation with policy learning through structured, human-interpretable scene descriptions. This approach achieved up to 93.4% success rates in compositional generalization tasks on VIMA-BENCH, outperforming baselines like VIMA, and improved success rates in CLIPORT tasks by up to 13 percentage points.

## Problem

- Robot manipulation systems often separate vision model learning from action policy learning, leading to sub-optimal integration and perception models not ideally suited for policy models.
- Many existing methods use opaque hidden representations for visual observations, hindering interpretability and direct optimization for policy learning.
- Generating effective action policies requires learning a broad spectrum of skills to interpret open-ended language instructions and leverage visual representations efficiently, especially for long-term tasks.

## Method

- **ACTLLM** utilizes ==Large Language Models (LLMs)== to generate structured scene descriptions (e.g., `{(object, color, coordinates)}`) as state representations, enforced by a predefined JSON schema during decoding.
- An action consistency loss is introduced to integrate visual perception with action generation, where actions are derived from an aggregated token embedding of the structured state representation.
- The Markov Decision Process (MDP) is reframed into a multi-turn visual dialogue framework, allowing the model to leverage historical context for improved long-term task execution and decision-making.

## Results

- ACTLLM demonstrated superior compositional generalization, achieving **64.0%** success on CLIPORT `put-shapes-in-bowls` (vs. PAFF's **51.0%**) and **85.8%** on `pack-unseen-objects` (vs. PAFF's **72.8%**).
- It consistently outperformed baselines across VIMA-BENCH L1, L2, and L3 tasks, reaching **90.5%** in L1, **90.9%** in L2, and **93.4%** in L3, surpassing VIMA's success rates.
- Ablation studies confirmed the critical role of task tuning, future state prediction, and multi-turn tuning for in-context generalization, with the full ACTLLM achieving an overall **36.2%** success rate on novel VIMA L4 tasks.

## Takeaways

> [!tip] Key Insights
> - Using structured, human-interpretable scene descriptions as state representations enhances model optimization through clear loss functions and provides stable ground-truth, improving transparency.
> - The action consistency loss effectively aligns visual perception with corresponding actions, ensuring that generated actions are contextually relevant and directly influenced by scene changes.
> - A multi-turn visual dialogue framework enables the model to incorporate historical context, facilitating more informed decision-making and better generalization over variable-length action sequences.
