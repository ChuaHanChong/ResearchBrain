# DyMU: Dynamic Merging and Virtual Unmerging for Efficient VLMs

> [!summary] Summary
> DYMU presents a training-free framework for Vision-Language Models (VLMs) that dynamically reduces visual token counts based on image complexity, overcoming the inefficiency of fixed-length token representations. It achieves up to an 85% reduction in visual tokens while maintaining over 96% of baseline performance across various VLM architectures and benchmarks by employing dynamic merging and virtual unmerging techniques.

## Problem

- Vision-Language Models (VLMs) generate a fixed, excessively large number of visual tokens from images, regardless of image content, leading to high computational costs during inference.
- Existing token reduction methods often apply a fixed compression ratio, failing to adapt to the varying complexity of input images, leading to inefficiencies or performance degradation.
- Improving VLM efficiency typically requires costly and resource-intensive retraining or fine-tuning, which is often infeasible due to closed-source training recipes.

## Method

- DYMU introduces ==Dynamic Token Merging (DToMe)== that adaptively reduces visual token embeddings from the ==Vision Transformer (ViT)== based on image content complexity and learnable layer-wise thresholds.
- It employs ==Virtual Token Unmerging (VTU)== to make the dynamically reduced visual token sequence compatible with pre-trained Large Language Models (LLMs) without explicit expansion, by virtually reconstructing attention dynamics.
- The entire framework is ==training-free== and can be seamlessly integrated into existing pre-trained VLMs that use ViT-based visual encoders and RoPE-based LLMs.

## Results

- DYMU-low reduced the average visual token count by **84.5%** (from **576** to **89±27** tokens) for LLaVA 1.5, while retaining **97.5%** of the original baseline performance across nine benchmarks.
- The framework demonstrated compatibility and efficiency with different visual encoders (SigLIP) and state-of-the-art any-resolution VLMs (LLaVA-OneVision), achieving **~96.5%** of baseline performance with **~14%** of tokens on image benchmarks.
- Ablation studies confirmed Virtual Token Unmerging (VTU) is critical for performance preservation; omitting VTU led to significant performance drops across benchmarks.

## Takeaways

> [!tip] Key Insights
> - Image content complexity varies significantly, making a fixed number of visual tokens for all images inefficient and wasteful.
> - Pre-trained Large Language Models (LLMs) within VLMs are typically fine-tuned to expect a fixed number of visual tokens, making direct reduction of visual tokens problematic for performance.
> - Computational efficiency in VLMs can be substantially improved without requiring expensive retraining or fine-tuning, by intelligently managing visual tokens.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The rapid advancement of Vision-Language Models (VLMs) has revolutionized various computer vision tasks, from image captioning and visual question answering to open-vocabulary object detection. These models typically leverage powerful visual encoders (often Vision Transformers, or ViTs) to extract features from images, which are then projected into the same embedding space as text features and processed by Large Language Models (LLMs). While highly effective, this paradigm introduces a significant computational bottleneck: the visual encoders generate a vast, fixed number of tokens for images, irrespective of their content, which then burdens the LLM. For instance, a high-resolution image might yield thousands of visual tokens, while an accompanying text query consists of only a few dozen. This disparity highlights a major inefficiency.

Prior research has attempted to address this computational overhead primarily in two ways:
1. **Post-Visual Encoding Efficiency**: Many methods focus on reducing the visual token count *after* the initial encoding by the visual encoder. This includes techniques like token pruning, merging, distillation, or resampling performed within the projector layers or the VLM decoder blocks (e.g., LLaMA-VID, Fast-V, SparseVLM, MQT-LLaVA, LLaVA-Prumerge, TokenPacker, ATP-LLaVA, LLaVA-mini, PDrop).
2. **Efficient Vision Transformers (ViTs)**: A separate line of research aims to make the ViT architecture itself more efficient by incorporating mechanisms like token merging (e.g., ToMe) or adaptive token pruning.

However, existing solutions suffer from key limitations:
- **Fixed Compression Ratio**: Most current methods, particularly those that are training-free, apply a predefined, fixed compression ratio. This means a simple, sparse image (e.g., a blank canvas with a small circle) receives the same number of tokens as a highly complex, detailed scene. While some adaptive approaches exist (e.g., ATP-LLaVA), they typically require expensive retraining of the VLM backbone, which is often infeasible due to closed-source training recipes and massive datasets.
- **Limited Scope**: Many methods focus solely on efficiency improvements *after* the visual encoder, overlooking the potential for optimization within the encoder itself, which is the initial source of the high token count.
- **Performance Degradation**: Directly applying ViT efficiency techniques (like ToMe) to the visual encoder of a pre-trained VLM often leads to a significant drop in downstream task performance. This is because the LLM is fine-tuned to expect a specific structure and number of visual tokens.

DYMU directly addresses these limitations. It proposes a novel, training-free framework that dynamically adapts the visual token compression based on the *content complexity* of the input image. By operating entirely training-free, it overcomes the significant barrier of re-training large VLMs. Furthermore, it not only optimizes the visual encoder but also introduces a "Virtual Token Unmerging" mechanism that mitigates the performance degradation typically associated with reducing tokens fed to pre-trained LLMs, making the reduced visual output compatible with existing VLM architectures. This positions DYMU as a significant advancement in making VLMs more computationally efficient, scalable, and adaptable for real-world applications.

### 2. Key Objectives and Motivation

The primary objective of the DYMU framework is to **significantly reduce the computational burden of Vision-Language Models (VLMs) during inference while maintaining high task performance, all without requiring any additional training or fine-tuning of the pre-existing models.**

This objective is driven by several key motivations:

- **Addressing Computational Bottlenecks**: Modern VLMs process high-resolution images or numerous video frames, generating an excessively large number of visual tokens. For instance, a LLaVA-OneVision encoder might produce nearly 9,500 tokens for a single image, vastly outweighing the typical textual query length of around 20-30 tokens. This disproportionate visual token count is the main source of computational cost during VLM inference, impacting speed, memory usage, and energy consumption.
- **Inefficiency of Fixed-Length Visual Tokens**: A critical observation motivating DYMU is that current visual encoders, such as those based on Vision Transformers (ViTs), output a fixed number of tokens regardless of the image content. A visually simple image (e.g., a blank background with a single object) consumes the same computational resources as a complex, cluttered scene. This fixed-length representation is inherently inefficient, as it treats redundant or information-poor regions with the same granularity as semantically rich areas. The authors highlight this by drawing a parallel to text: more words are used to convey more information. VLMs should ideally adapt their visual token count similarly.
- **Need for Adaptive Token Allocation**: Just as a text encoder uses fewer tokens for a short sentence and more for a long one, a visual encoder should ideally adapt its output token count based on the complexity and information density of the image. This "dynamic length" capability would ensure that computational resources are allocated where they are most needed, maximizing efficiency without sacrificing detail for critical information.
- **Minimizing Deployment Friction (Training-Free Approach)**: Fine-tuning or retraining large, state-of-the-art VLMs is extraordinarily resource-intensive, requiring vast datasets and significant computational power. Furthermore, many mainstream VLM architectures do not open-source their full training recipes, making custom retraining infeasible for most researchers and practitioners. DYMU aims to be a "plug-and-play" solution, meaning it can be seamlessly integrated into existing pre-trained VLMs without modifying their weights or requiring any new training. This dramatically lowers the barrier to adoption and accelerates the deployment of more efficient VLMs.
- **Enhanced User Control over Computational Costs**: Current large multimodal models, like GPT-4o, often impose a fixed token cost per image based primarily on resolution. DYMU, by dynamically adapting token counts, offers users more fine-grained control over the computational resources consumed per image, potentially enabling more cost-effective usage in various applications.

In essence, DYMU seeks to bridge the gap between the high performance of modern VLMs and their often prohibitive computational demands, making them more practical, sustainable, and adaptable for diverse real-world use cases.

### 3. Methodology and Approach

DYMU (Dynamic Merging and Virtual Unmerging) is an innovative, training-free framework designed to reduce the computational cost of VLMs. It consists of two primary, synergistic components: Dynamic Token Merging (DToMe) applied to the visual encoder, and Virtual Token Unmerging (VTU) applied to the Large Language Model (LLM) decoder.

#### 3.1. Dynamic Token Merging (DToMe)

DToMe is a method that dynamically reduces the number of visual token embeddings generated by a Vision Transformer (ViT) based on the inherent complexity of the input image. Unlike previous methods that merge a fixed number of tokens, DToMe's key innovation is its adaptive nature.

- **Identifying Redundant Tokens**: DToMe operates within each ViT layer. It takes inspiration from ToMe by employing a bipartite soft matching strategy. For a sequence of `N_i` tokens in layer `i`, tokens are split into two sets (A and B). Each token `t` in set A is matched to the most similar token `t_B` in set B based on the dot product of their key embeddings (`k_i`). This produces a similarity score `S_i[t]` for each potential merge.
- **Adaptive Thresholding**: The crucial difference from fixed merging schemes is the application of a dynamic threshold `τ_i`. Only token pairs `t -> t_B` where `S_i[t] > τ_i` are selected for merging. This threshold allows a *variable* number of tokens to be merged in each image, directly adapting to the image's content redundancy.
- **Tracking and Merging Tokens**: When tokens `t` and `t_B` are merged, their embeddings (`x_i[t]` and `x_i[t_B]`) are averaged, weighted by the sizes of their respective merged position sets (`P_i[t]` and `P_i[t_B]`). The set `P_i[t_B]` is updated to include all original positions previously covered by `t` and `t_B`. Token `t` is then dropped, reducing the sequence length for subsequent layers. This tracking ensures that the influence of the merged original tokens is propagated correctly.
- **Finding Redundancy Thresholds (Crucial for Dynamism)**: The layer-wise thresholds `τ_i` are not hand-tuned but are learned in an inference-only manner from a large dataset of diverse images.
 - The user defines `r_i`, which is the *expected average* number of tokens to be merged in layer `i` across images of *all* complexities.
 - A large batch `B` of images is processed. For each image in the batch and for each layer, the bipartite matching scores are computed.
 - All these scores (from all images in the batch for a specific layer) are pooled. The threshold `τ_i` is then determined as the value such that exactly `B * r_i` merges occur across the entire batch.
 - This batch-level thresholding ensures that images with high redundancy (simpler images) will inherently have more `S_i[t]` scores above `τ_i`, leading to more merges, while complex images with less redundancy will have fewer. This process is performed sequentially for each layer, and the final `τ_i` values are averaged over multiple batches for robustness.
- **Size-Weighted Self-Attention**: To ensure that the self-attention layers correctly account for the fact that some tokens now represent multiple original positions, the attention mechanism is modified to weigh each token based on the size of its merged position set (`|P_i[t]|`).

#### 3.2. Virtual Token Unmerging (VTU)

VTU addresses a critical challenge: pre-trained LLMs in VLMs are typically optimized to receive a fixed number of visual token embeddings. Directly feeding them a reduced, variable-length sequence from DToMe would degrade performance significantly. VTU circumvents this by virtually reconstructing the attention dynamics of a full sequence without explicitly expanding the token embeddings.

- **Motivation for VTU**: When DToMe reduces visual tokens, the LLM, which is typically frozen and fine-tuned on fixed-length inputs, misinterprets the shortened sequence, leading to a performance drop. VTU aims to make the reduced sequence "look like" the full sequence to the LLM.
- **Sequence-Independent Operations**: For LLM operations that process each token independently (e.g., linear layers, activation functions, layer normalization), the reduced set of unique embeddings (`e_un`) can be processed directly, and the result can be mapped back to the original full sequence length (`N`) using the stored mapping matrix `M`. This offers a linear speedup (`O(N_un * D^2)` vs `O(N * D^2)`).
- **Self-Attention with RoPE (Rotary Position Embedding)**: This is the most complex part, as self-attention considers pairwise interactions and incorporates positional embeddings.
 - **Core Idea**: Instead of expanding the unique embeddings (`e_un`) to the full sequence `e` and then computing attention, VTU reconstructs the full attention matrix `A` using `e_un` and the original positional information.
 - **Mathematical Formulation**: The RoPE-based attention similarity `A[m, n]` can be expressed using complex numbers and trigonometric identities. DYMU leverages this to reformulate the full attention matrix `A` in terms of the unique queries (`Q_un`), keys (`K_un`), and the mapping matrix `M` (Equation 10). The key insight is that `CM`, `M^T C`, `SM`, `M^T S` (where `C` and `S` represent cosine and sine of RoPE angles) are sparse matrices. This allows computing `A` efficiently using sparse matrix operations.
 - **Output Re-merging**: After computing the attention output `f(e)`, the resulting embeddings might not exhibit the same redundancy structure as the input. To ensure that subsequent self-attention layers can continue to benefit from token reduction, `f(e)` is re-merged by averaging embeddings at positions that were originally identical (Equation 11). While this introduces a slight approximation, experiments demonstrate a minimal performance drop.
- **Overall Efficiency**: VTU allows the LLM's self-attention to run with a computational complexity of `O(N_un * N * D)` compared to the original `O(N^2 * D)`, where `N_un` is the number of unique tokens and `N` is the original full sequence length. This offers significant theoretical efficiency gains, though practical wall-clock time can be affected by highly optimized dense matrix operations in deep learning libraries.

In summary, DYMU's methodology combines intelligent, content-aware token reduction at the visual encoder stage with a sophisticated "virtual unmerging" mechanism at the LLM stage, ensuring compatibility and performance preservation in a training-free manner.

### 4. Main Findings and Results

DYMU's effectiveness is thoroughly demonstrated through extensive quantitative and qualitative evaluations across diverse VLM architectures, visual encoders, and language models.

#### 4.1. Quantitative Evaluation

- **Efficiency and Performance on LLaVA 1.5**: When applied to LLaVA 1.5 (using a CLIP visual encoder and Vicuna-7B LLM), DYMU achieved remarkable efficiency gains while largely preserving performance:
 - **DYMU-low**: Reduced average visual token count by **84.5%** (from 576 to 89±27 tokens) while maintaining **97.5%** of the original baseline's performance across nine benchmarks (GQA, MMBench, MME, POPE, ScienceQA, SEED-IMG, TextVQA, MMVet, LLaVA-Bench).
 - **DYMU-mid**: Reduced tokens by **66.1%** (195±47 tokens) with **99.2%** of baseline performance.
 - **DYMU-high**: Reduced tokens by **31.6%** (394±57 tokens) with **100.2%** of baseline performance.
 - DYMU consistently outperformed previous training-free fixed-length compression methods (e.g., ToMe, FastV, PDrop, SparseVLM) across various benchmarks, while uniquely offering variable-length output per instance.
 - The largest performance drop was observed in TextVQA, which is highly sensitive to the spatial location of visual tokens, a property that token merging can disrupt.
- **Compatibility with Different Visual Encoders (SigLIP)**: DYMU's efficacy extended to different visual encoders. When integrated with a SigLIP encoder within the LLaVA 1.5 framework, DYMU-SigLIP-low achieved **96.1%** of the baseline performance while reducing tokens by approximately **85%** (from 576 to 90±26 tokens).
- **Compatibility with Any-Resolution VLMs (LLaVA-OneVision)**: DYMU demonstrated consistent effectiveness on LLaVA-OneVision, a state-of-the-art Any-Resolution model employing SigLIP-so400M and a Qwen2 LLM. For instance, DYMU-ov-low achieved ~**96.5%** of the baseline's performance with only ~**14%** of the tokens for image benchmarks. Importantly, this compatibility also extended to video benchmarks, showing DYMU's ability to handle complex operations like arbitrary resolution processing and temporal redundancy.
- **FLOPs Reduction**: Table 1 in the paper indicates significant FLOPs reduction in the attention block with VTU. For example, VTU Attention-low achieved 64.9 MFLOPs compared to 1359.0 MFLOPs for full attention, for a sequence length of 576 reduced to 89 unique tokens.

#### 4.2. Qualitative Analysis

- **Image Complexity vs. Token Count (Figure 3 & Appendix A)**: A strong positive correlation was observed between image complexity (quantified by JPEG compression ratio) and the number of tokens retained by DYMU. Simpler images received significantly fewer tokens, while complex images retained more, demonstrating DToMe's adaptive nature. Visualizations in Appendix A clearly show this dynamic allocation.
- **Fixed vs. Dynamic Token Reduction (Figure 3 Right)**: Comparison on the MME benchmark showed that DYMU (dynamic-length) consistently outperformed ToMe (fixed-length token reduction). The performance gain was most pronounced for complex images, where fixed token reduction methods tend to over-compress due to an insufficient fixed token budget.
- **Importance of Virtual Token Unmerging (Figure 4 & Table 6)**: An ablation study confirmed the critical role of VTU. When VTU was omitted, and the LLM directly received reduced tokens, performance dropped significantly across 8 out of 9 benchmarks for both fixed (ToMe) and variable (DToMe) token reduction methods. This validates VTU's effectiveness in preserving model capabilities.
- **Robustness of Threshold Finding (Figure 5 & Table 7)**: The study showed that DYMU's performance remained robust even when the DToMe thresholds were estimated using a different, independent dataset (Pixmo-Cap vs. LLaVA instruction tuning data). This indicates that the method is not overly sensitive to the specific dataset used for threshold estimation.
- **Controllable Visual Token Length (Figure 6)**: A key qualitative advantage highlighted is the "cost controllability" offered by DYMU. The framework enables users to combine DYMU with other vision tools (e.g., background removal, OCR, object detection) to focus on relevant image regions and further reduce token counts. This showcases DYMU's flexibility in adapting token usage to specific task requirements, allowing for more efficient resource allocation.

In summary, the findings robustly demonstrate that DYMU successfully achieves its objectives of providing significant, dynamic, and training-free visual token compression for VLMs, maintaining high performance across diverse architectures and tasks, and offering unprecedented control over computational costs.

### 5. Significance and Potential Impact

The DYMU framework represents a significant step forward in the field of Vision-Language Models, addressing one of their most pressing practical challenges: computational inefficiency. Its primary significance lies in being the **first training-free framework that dynamically reduces visual token counts in VLMs based on per-image complexity.**

The potential impact of DYMU is substantial and multi-faceted:

- **Enhanced Accessibility and Practicality of VLMs**: By drastically reducing the average visual token count (32-85% reduction demonstrated) while maintaining competitive performance, DYMU makes large VLMs more computationally affordable and faster. This translates to lower inference costs, reduced memory footprint, and faster response times, which are critical for deploying these powerful models in real-world applications such as edge devices, consumer-facing products, and large-scale cloud services where computational resources are a constraint.
- **Cost-Effectiveness and Resource Optimization**: The ability to dynamically adapt token allocation to image complexity means that simpler, less information-dense images consume fewer resources. This intelligent allocation avoids the wasteful processing inherent in fixed-length token systems, leading to more efficient use of computational budget and potentially lower operational costs for VLM-powered services.
- **Plug-and-Play Integration**: The training-free nature of DYMU is a game-changer. It means that researchers and developers can immediately apply this optimization to their existing, pre-trained state-of-the-art VLMs (using ViT-based visual encoders and RoPE-based LLMs) without the need for expensive, time-consuming, and often infeasible fine-tuning or retraining. This accelerates the adoption of efficiency improvements across the VLM ecosystem.
- **Greater User Control**: DYMU provides unprecedented control over computational costs per image. Unlike models that impose a fixed cost based on resolution, DYMU's dynamic adaptation allows users to fine-tune efficiency, even enabling integration with other vision tools (like object detection or background removal) to focus processing on specific, relevant regions. This flexibility empowers developers to build more specialized and resource-efficient VLM applications.
- **Broad Compatibility and Future-Proofing**: The framework's demonstrated compatibility with various VLM architectures, including fixed-resolution and AnyRes models, and different visual encoders (CLIP, SigLIP) and LLMs (Vicuna, Qwen2), highlights its versatility. This suggests that DYMU is likely to remain relevant and applicable to future generations of VLM architectures, extending its long-term impact.

**Future Work**: The authors acknowledge areas for improvement, particularly in preserving VLM performance on spatially sensitive tasks like TextVQA, where token merging might disrupt fine-grained spatial understanding. This suggests future research will focus on more intelligent merging strategies that are robust to such sensitivities. Additionally, extending DYMU to reduce temporal redundancy in videos is identified as a promising direction, which could unlock even greater efficiency for video understanding tasks.

In conclusion, DYMU offers a pragmatic, impactful solution to the efficiency challenges of VLMs, paving the way for their broader and more sustainable deployment across a myriad of applications.
