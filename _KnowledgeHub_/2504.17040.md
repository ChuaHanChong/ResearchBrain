# DyMU: Dynamic Merging and Virtual Unmerging for Efficient VLMs

> [!summary] Summary
> DYMU presents a training-free framework for Vision-Language Models (VLMs) that dynamically reduces visual token counts based on image complexity, overcoming the inefficiency of fixed-length token representations. It achieves up to an 85% reduction in visual tokens while maintaining over 96% of baseline performance across various VLM architectures and benchmarks by employing dynamic merging and virtual unmerging techniques.

## Problem

- Vision-Language Models (VLMs) generate a fixed, excessively large number of visual tokens from images, regardless of image content, leading to high computational costs during inference.
- Existing token reduction methods often apply a fixed compression ratio, failing to adapt to the varying complexity of input images, leading to inefficiencies or performance degradation.
- Improving VLM efficiency typically requires costly and resource-intensive retraining or fine-tuning, which is often infeasible due to closed-source training recipes.

## Method

- DYMU introduces ==Dynamic Token Merging (DToMe)== that adaptively reduces visual token embeddings from the ==Vision Transformer (ViT)== based on image content complexity and learnable layer-wise thresholds.
- It employs ==Virtual Token Unmerging (VTU)== to make the dynamically reduced visual token sequence compatible with pre-trained Large Language Models (LLMs) without explicit expansion, by virtually reconstructing attention dynamics.
- The entire framework is ==training-free== and can be seamlessly integrated into existing pre-trained VLMs that use ViT-based visual encoders and RoPE-based LLMs.

## Results

- DYMU-low reduced the average visual token count by **84.5%** (from **576** to **89±27** tokens) for LLaVA 1.5, while retaining **97.5%** of the original baseline performance across nine benchmarks.
- The framework demonstrated compatibility and efficiency with different visual encoders (SigLIP) and state-of-the-art any-resolution VLMs (LLaVA-OneVision), achieving **~96.5%** of baseline performance with **~14%** of tokens on image benchmarks.
- Ablation studies confirmed Virtual Token Unmerging (VTU) is critical for performance preservation; omitting VTU led to significant performance drops across benchmarks.

## Takeaways

> [!tip] Key Insights
> - Image content complexity varies significantly, making a fixed number of visual tokens for all images inefficient and wasteful.
> - Pre-trained Large Language Models (LLMs) within VLMs are typically fine-tuned to expect a fixed number of visual tokens, making direct reduction of visual tokens problematic for performance.
> - Computational efficiency in VLMs can be substantially improved without requiring expensive retraining or fine-tuning, by intelligently managing visual tokens.
