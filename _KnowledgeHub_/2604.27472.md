# PRTS: A Primitive Reasoning and Tasking System via Contrastive Representations

> [!summary] Summary
> PRTS introduces a Vision-Language-Action (VLA) foundation model that integrates reward-label-free Contrastive Reinforcement Learning (CRL) into its pretraining, equipping it with an intrinsic understanding of "goal reachability." This enables the model to quantify the feasibility of achieving language-specified objectives, leading to enhanced performance in long-horizon tasks and zero-shot generalization across diverse robotic platforms.

## Problem

- Existing Vision-Language-Action (VLA) models, primarily relying on supervised behavior cloning, often lack an intrinsic understanding of "goal reachability" and temporal progress towards objectives.
- Prior methods to inject value awareness into VLAs typically require explicit reward annotations, separate value networks, or suffer from bootstrapping errors and architectural decoupling.
- VLAs struggle with robust long-horizon planning and decision-making because they focus on immediate action prediction rather than broader temporal progress evaluation.

## Method

- **PRTS** reformulates VLA pretraining through ==Goal-Conditioned Reinforcement Learning==, specifically adapting ==Contrastive RL (CRL)== for language-conditioned settings.
- Employs a ==temporal weighting scheme== in a ==bidirectional contrastive objective== to implicitly extract dense goal-reachability supervision from offline trajectories.
- A novel ==role-aware causal mask==, implemented via a custom FlashAttention kernel, integrates CRL into the VLM backbone with minimal overhead.

## Results

- **PRTS** achieved SOTA **98.4%** on LIBERO; highest zero-shot **81.4%** on LIBERO-Plus and **58.8%** on LIBERO-Pro.
- Strong real-world robustness: **73.8%** average success across visual, layout, and object instance shifts.
- Qualitative stress tests confirm consistent recovery from human interventions; CRL values accurately track task progress.

## Takeaways

> [!tip] Key Insights
> - Language-conditioned Contrastive Reinforcement Learning (LC-CRL) can learn a unified embedding space where the inner product of state-action and goal embeddings approximates the log-discounted goal occupancy, quantifying task progress.
> - Implicit, dense goal-reachability supervision can be extracted directly from the temporal structure of offline demonstration trajectories, eliminating the need for explicit reward labels or separate value networks.
> - A custom role-aware causal mask allows the VLM backbone to efficiently compute action predictions, state-action representations, and goal representations in a single forward pass, ensuring scalability for large-scale pretraining.
