# When Does LeJEPA Learn a World Model?

> [!summary] Summary
> Research by Klindt, LeCun, and Balestriero formally defines and proves the conditions under which a Joint-Embedding Predictive Architecture (JEPA), specifically LeJEPA, learns a "World Model" by recovering the true underlying latent variables. It demonstrates that LeJEPA achieves linear identifiability if and only if the latent variables follow an isotropic Gaussian distribution, which then enables optimal latent-space planning.

## Problem

- Lack of formal guarantees that representations learned by Joint-Embedding Predictive Architectures (JEPAs) genuinely reflect the underlying degrees of freedom of the world.
- The absence of a clear definition and specific conditions for when a learned representation qualifies as a "World Model" capable of supporting reliable planning and generalization.
- Learned representations that entangle unrelated latent variables (e.g., an object's position with its color) may hinder generalization to novel compositions or robust planning.

## Method

- Developed a theoretical framework defining a "Gaussian world" where independent, stationary, standard Gaussian latent variables evolve under Ornstein–Uhlenbeck transitions.
- Analyzed LeJEPA's objective function, which minimizes an alignment loss while explicitly regularizing the embedding distribution towards an isotropic Gaussian (Sketched Isotropic Gaussian Regularization, SIGReg).
- Employed spectral analysis, Hermite polynomials, and Sturm–Liouville theory for theoretical proofs, formally verified using the Lean 4 theorem prover, alongside empirical validation in 2D simulations, high-dimensional scaling, and pixel-based robotic control.

## Results

- For a Gaussian world, LeJEPA provably recovers latent variables up to an orthogonal transformation, with empirical validation showing linear identifiability (R² > 0.999) up to 1024 latent dimensions.
- Experiments with varied latent distributions confirm that linear recovery peaks sharply only when the true latents are Gaussian, establishing Gaussianity as a necessary condition for LeJEPA's linear identifiability.
- LeJEPA-trained encoders exhibiting high linear identifiability enable latent-space planning in a robotic control environment with control costs statistically indistinguishable from an oracle controller operating in the true joint space.

## Takeaways

> [!tip] Key Insights
> - LeJEPA achieves linear identifiability—recovering true latent variables up to an orthogonal transformation—if and only if the underlying latent variables follow an isotropic Gaussian distribution.
> - The necessity of Gaussian latents for identifiability in this nonlinear self-supervised setting contrasts with classical linear Independent Component Analysis (ICA), where Gaussianity typically hinders source separation.
> - Orthogonal identifiability of learned representations enables optimal latent-space planning for tasks with rotation-invariant cost functions, thereby forming a functional "World Model" for control.
