# SAKI: Skill Assembly and Kinematic Imitation from Human Videos for Long-Horizon Mobile Manipulation

> [!summary] Summary
> SAKI turns human stereo videos into reusable object-centric skill assets that keep the parts of an interaction that matter (contact, clearance, orientation, terminal alignment) while letting transfer paths adapt. It binds object roles to the current scene and chains skills using whole-body kinematic optimisation and visual replanning. On a real mobile bimanual robot it completes 81.0% of single tasks and 68.9% of long-horizon sequences.

## Problem

- Object-centric imitation from video copies the recovered trajectory as a whole, so the essential interaction geometry stays tangled with demonstrator- and scene-specific detours.
- Closely replaying a demonstrated object path restricts the mobile base's approach and posture, which hurts reach, target observation and collision avoidance in new layouts.
- Existing skill-composition and scene-memory systems do not carry object estimates and terminal robot configuration between independently demonstrated interactions to produce continuous whole-body mobile execution.

## Method

- Video-derived object-task assets: a Codex/GPT agent builds them from FoundationStereo depth and SAM 2 tracks, splitting each demonstration into protected phases and adjustable ==PCHIP-interpolated== transfer segments with roles and contact events.
- Skill assembly with object-role binding selects and orders assets for a goal. A ==smoothstep-weighted endpoint correction== confines layout adaptation to the transfer phase, leaving lift and final-interaction segments unchanged.
- ==Whole-body kinematic imitation== jointly optimises SE(2) base and arm joints against object-point targets. Stateful closed-loop execution uses persistent object estimates to replan remaining motion while preserving the already-committed command prefix.

## Results

- Across seven single tasks SAKI completes **85/105** trials (**81.0%**), with **100%** on can disposal and pouring. Its three continuous sequences reach **31/45** (**68.9%**), including **9/15** for tidying-plus-wiping.
- Ablation replacing reference preparation with direct interpolation of the recovered trajectory drops sequence completion from **68.9%** to **15.6%**, a 53.3-point loss, with whole-body solving and visual feedback kept active.
- With shared perception and execution modules, SAKI scores **45/45** on local tasks versus **31/45** for DITTO-adapted. Frozen skills reused in changed layouts reach **90%**, **100%** and **75%** success.

## Takeaways

> [!tip] Key Insights
> - Separating what an interaction must preserve from how the robot realises it lets one demonstration transfer across layouts. The planner gains freedom without losing task-critical geometry.
> - Faithfully copying demonstrated trajectories can hurt mobile manipulation: rigid paths over-constrain base placement and viewpoint, so selectively relaxing transfer segments matters more than tracking accuracy.
> - Long-horizon composition needs explicit state handoff, meaning persistent object estimates plus the previous terminal configuration. Replans should also keep already-committed motion so updates do not cause discontinuities.

## Detailed Report

### 1. Overview

SAKI addresses a concrete problem. A mobile robot is asked to dispose of a can, put tape in a basket, then wipe a whiteboard. Each interaction was demonstrated separately, and the robot must carry the scene and its own configuration from one stage to the next. Copying a human video directly runs into a bottleneck. A human-video trajectory mixes task-critical interaction with movement specific to the human, original layout, and viewpoint, which can constrain a mobile robot's reach or approach.

SAKI keeps what an interaction requires, such as contact, clearance, orientation, and how the action ends. It does not require the robot to copy the demonstrator's entire route. It binds those requirements to objects in the current scene, then generates coordinated motion for the robot's base, arms, and gripper. On a real robot, some attempts completed the whole sequence.

An autonomous SAKI sequence of can disposal, tape placement, and whiteboard wiping, as described on the authors' project page. Clip labelled 8×; an illustrative recorded run.

### 2. Keep the interaction, change the route

SAKI stores each demonstrated skill as an object-task asset. An object-task asset packages object roles, ordered phases, contact events, an accepted object-motion reference, and rules about what can change. The robot's motion is solved later, for the current scene. Some intervals are protected, for example lift clearance, pouring orientation, or wiping contact. Adjustable segments can be regenerated.

The can-disposal asset shows the split. Its 24-frame reference separates lift, transfer, and final alignment. Endpoint correction is allowed during transfer, but not during the protected lift or final interaction.

Given a goal and supplied dependencies, SAKI selects and orders skills and binds their object roles to scene entities. SAKI does not choose the goal or the dependencies itself; they are supplied.

A whole-body solver then turns the scene-grounded object targets into coordinated base-and-arm motion. It works subject to motion and joint constraints and regularisation for smoothness, posture, base motion, and configured clearance.

Schematic workflow with illustrative execution. On the left, skill assembly selects, orders, and binds assets to current objects. On the right, planning inputs feed an optimisation block, which drives coordinated execution. A feedback loop links updated observations, persistent object state, and updated remaining targets.

### 3. Test the reference, then the sequence

One question is whether preparing the interaction reference matters, given that a planner and visual feedback are already present. A controlled ablation tests this on three continuous sequences: L1 tidying and wiping, L2 collection and pouring, and L3 three-location collection.

Each sequence has 15 initiated trials, for 45 in total. A trial succeeds only if every evaluated stage finishes without resets or human assistance. In the ablation, task-conditioned reference refinement is replaced with direct interpolation of the reconstructed trajectory. Scene binding, whole-body optimisation, visual updates, and replanning stay active in both conditions. Complete-sequence success rises from 7/45 (15.6%) with direct interpolation to 31/45 (68.9%) with the full method, a 53.3-percentage-point difference. Completion improves on each of the three sequences.

The comparison tests reference preparation as a package against direct interpolation. It does not isolate which element of that preparation accounts for the gains. The authors suggest that a fixed interpolated path can constrain base rotation and posture changes useful for reach or observation. Failed ablation trials included poor target observation and collisions.

Successful complete sequences out of 15 initiated trials, "SAKI w/o ref. optimisation" vs "SAKI": L1 Tidying + wiping, 2/15 (13.3%) vs 9/15 (60.0%); L2 Collection + pouring, 4/15 (26.7%) vs 13/15 (86.7%); L3 Three-location collection, 1/15 (6.7%) vs 9/15 (60.0%). Scene grounding, whole-body solving, and online updates are retained.

L1 is the opening task. It assembles three independently prepared assets into one mobile task. All 15 L1 attempts complete can disposal and tape placement, and 9/15 complete the final wiping stage.

### 4. Carry state into the next action

Each stage starts from where the previous one ended. The next skill begins from the preceding terminal base, arm, and gripper state, and keeps object identities and estimates. When an observation is accepted, it can revise unexecuted targets, and the replacement plan keeps the motion that is already committed. One recorded can-disposal run illustrates this. There, the estimated bin position shifted horizontally by 7.12 cm, and the next solve revised the remaining targets while keeping target orientations unchanged.

### 5. Requirements stay, motion is regenerated

SAKI treats an interaction specification as reusable and the robot trajectory as dependent on the scene and the robot's state. In the tested system, the reference-preparation ablation and the connected L1 runs support that separation.
