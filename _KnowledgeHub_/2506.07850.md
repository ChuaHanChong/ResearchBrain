# SAM2Auto: Auto Annotation Using FLASH

> [!summary] Summary
> SAM2Auto introduces a fully automated and training-free pipeline for video annotation, leveraging robust object detection and real-time multi-object video instance segmentation. This system reduces false positives in object detection by 57% and improves Multiple Object Tracking Accuracy (MOTA) by 1393% on the MOT17 dataset, establishing a new baseline for scalable Vision-Language Model dataset creation.

## Problem

- Vision-Language Models (VLMs) face a 'dataset bottleneck' due to the scarcity of high-quality, large-scale paired visual and textual video annotations.
- Traditional manual video annotation is labor-intensive, expensive, time-consuming, and prone to inconsistencies, especially for maintaining consistent object IDs across frames.
- Existing open-world detection and tracking methods often require human intervention or dataset-specific training, limiting their scalability and generalizability for diverse video datasets.

## Method

- SAM2Auto is an end-to-end automated pipeline consisting of ==SMART-OD for robust open-vocabulary object detection== and ==FLASH for real-time multi-object video instance segmentation==.
- SMART-OD integrates SAM2 for mask generation, YOLO-World for object detection on masked inputs, and a robust verification stage using ==SAHI and dynamic thresholding== to minimize false positives.
- FLASH leverages ==ByteTrack for multi-object tracking== with a memory-based SAM2 (ASH module) to propagate polygon segmentations across frames, ensuring temporal consistency and employing post-processing for quality refinement.

## Results

- SMART-OD reduced false positives by **57%** (from 5,861 to 2,516) and improved precision from **59.4%** to **72.8%** on MOT17 training sets compared to a YOLO-World baseline.
- The full SAM2Auto pipeline increased MOTA by **1393%** (from -0.014 to 0.181) and recall by **52.2%** on the MOT17 training set when applying FLASH to SMART-OD detections.
- FLASH achieved the highest IDF1 score (**72.5%**) and ranked second in HOTA (**62.0%**) on the DanceTrack dataset, and the highest mHOTA (**53.7%**) on BDD100K using curated detections.

## Takeaways

> [!tip] Key Insights
> - It is feasible to achieve fully automated, training-free video annotation, providing a new paradigm for VLM dataset creation that eliminates human intervention.
> - The primary bottleneck for end-to-end automated tracking performance is the quality of initial object detections, particularly the suppression of false positives, rather than the tracking component itself.
> - Memory-based segmentation trackers like SAM2ASH can achieve competitive performance in specific scenarios, such as DanceTrack, where objects have distinctive visual characteristics and tracking protocols align with its design.
