# Self-Improving Language Models for Evolutionary Program Synthesis: A Case Study on ARC-AGI

> [!summary] Summary
> SOAR (Self-improving Operators for Automated program Refinements) is a framework that enables large language models (LLMs) to learn to improve their program synthesis and refinement capabilities from their own search experience. Applied to the ARC-AGI benchmark, SOAR achieves 52.00% accuracy on the public test set, establishing a new state-of-the-art for open-source LLM-based inductive methods and demonstrating continuous performance gains beyond fixed model capacities.

## Problem

- Large Language Models (LLMs) often struggle with complex program synthesis tasks, especially those requiring abstract reasoning, failing to provide correct solutions in a single attempt.
- Integrating LLMs into traditional evolutionary search methods leads to performance plateaus, as the LLM's generative and refinement capabilities remain static after initial training.
- Existing LLM-based program synthesis often relies on extensive human-curated datasets for finetuning or hand-crafted domain-specific languages (DSLs), limiting autonomy and scalability.

## Method

- ==SOAR== integrates LLMs into an ==iterative self-improving evolutionary loop== that alternates between a ==Sample&Refine phase== for program generation and a ==Learning phase== for model updates.
- The Sample&Refine phase uses an LLM to generate initial program candidates and iteratively refine them based on execution feedback within a multi-armed bandit framework (REX).
- The Learning phase fine-tunes the LLM using data generated during its own search attempts, leveraging =="hindsight relabeling"== to create synthetic training examples from both successful and unsuccessful programs.

## Results

- SOAR dramatically improves LLM performance on ARC-AGI; for instance, the Qwen-2.5-Coder-7B model's accuracy increases from **14.25%** (search-only) to **36.25%** (SOAR), a **2.5**-fold gain.
- The framework achieves a peak accuracy of **52.00%** on the public ARC-test set by ensembling solutions from various SOAR-trained open-source LLMs, setting a new state-of-the-art for open-source inductive methods.
- SOAR successfully breaks through performance ceilings observed when merely increasing LLM size or search budget with fixed models, demonstrating sustained improvements through iterative learning and test-time adaptation.

## Takeaways

> [!tip] Key Insights
> - Self-improvement allows LLMs to overcome performance plateaus tied to fixed model size or search budget, continuously elevating performance ceilings through adaptive learning.
> - Hindsight relabeling is an effective technique for generating diverse and relevant training data from self-generated search traces, enabling autonomous learning without relying on human-curated datasets.
> - Jointly finetuning LLMs for both program sampling and refinement capabilities (rather than separately) leads to better overall performance, indicating a synergistic relationship between these tasks.
