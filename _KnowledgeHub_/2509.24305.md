# Asynchronous Policy Gradient Aggregation for Efficient Distributed Reinforcement Learning

> [!summary] Summary
> Researchers from AXXX and the Applied AI Institute introduced Rennala NIGT and Malenia NIGT, new asynchronous policy gradient aggregation algorithms designed for efficient distributed reinforcement learning. These algorithms improve upon existing methods by achieving better computational and communication time complexities, such as an O(κε⁻²) communication complexity which improves on AFedPG's O(κε⁻³), and robustly handle heterogeneous environments and computational resources.

## Problem

- Distributed reinforcement learning faces significant challenges from communication bottlenecks, system heterogeneity among agents, and the presence of stragglers.
- Distributed Policy Gradient methods are less explored, especially in scenarios with heterogeneous asynchronous computations and communication constraints.
- Previous asynchronous distributed RL algorithms like AFedPG lacked support for heterogeneous settings, exhibited suboptimal communication time complexity, and scaled unfavorably with the number of agents.

## Method

- Developed two novel algorithms: ==Rennala NIGT== for homogeneous settings and Malenia NIGT for heterogeneous distributed environments, building on Normalized Iterated Gradient (NIGT) techniques and asynchronous optimization.
- The algorithms employ an asynchronous gradient aggregation strategy where a central server waits for any agent to complete computation, allowing faster agents to contribute more and mitigating straggler effects.
- Implemented efficient communication mechanisms, including support for collective operations like AllReduce, to minimize communication overhead between agents and the central server.

## Results

- Rennala NIGT achieved a communication time complexity of O(κε⁻²), a notable improvement over AFedPG's O(κε⁻³) and demonstrated superior scalability with an increasing number of agents (`n`).
- Malenia NIGT established state-of-the-art time complexity for RL problems in heterogeneous, distributed, and asynchronous settings, addressing challenges like diverse reward functions and policy parameterizations.
- Empirical evaluations on MuJoCo tasks showed Rennala NIGT consistently achieved faster convergence and better performance than AFedPG and a Synchronized NIGT baseline under various heterogeneous computation and communication conditions, while Malenia NIGT achieved significantly higher rewards in truly heterogeneous environments.

## Takeaways

> [!tip] Key Insights
> - Asynchronous aggregation schemes that prioritize contributions from faster agents can significantly improve computational efficiency and robustness in heterogeneous distributed RL settings.
> - Integrating momentum and normalization techniques into asynchronous distributed policy gradient methods can yield superior theoretical guarantees for convergence rates and time complexities.
> - Developing distinct but related algorithms, like Rennala NIGT and Malenia NIGT, allows for optimized performance and broader applicability across both homogeneous and heterogeneous distributed learning environments, including federated RL.
