# GATES: Self-Distillation under Privileged Context with Consensus Gating

> [!summary] Summary
> The GATES framework from the University of Maryland, College Park, enables language models to self-improve effectively by using a single model in tutor and student roles, leveraging privileged context and consensus gating to filter self-generated reasoning trajectories. This method achieved an average maj@8 accuracy of 35.4% on public math benchmarks and boosted in-domain student accuracy from 46.0% to 62.0% without relying on external supervision.

## Problem

- Language model fine-tuning often requires reliable external supervision like ground-truth labels or human feedback, which is costly or unavailable.
- Self-distillation, while appealing for dense supervision, risks reinforcing a model's own errors without external validation.
- Developing a robust self-improvement method for LLMs in settings where direct, reliable supervision is absent presents a significant challenge.

## Method

- Introduce **GATES**, a self-distillation framework where a single model acts as a 'tutor' with privileged context (e.g., source document) and a 'student' without.
- Implement 'consensus gating' to filter tutor-generated responses; only questions with sufficient tutor agreement on the answer are used for supervision.
- Distill full, eligible reasoning trajectories from the tutor to the student, providing dense, token-level learning signals that avoid document leakage.

## Results

- GATES achieved **35.4%** average maj@8 accuracy on public math benchmarks, a 15.2 percentage point improvement over the pretrained base model's **20.2%**.
- Student accuracy on held-out in-domain questions increased from **46.0%** for the pretrained model to **62.0%** using GATES.
- Consensus gating was crucial, with un-gated trajectory distillation performing worse (**32.3%** on benchmarks, **54%** in-domain), highlighting its role in robust knowledge transfer.

## Takeaways

> [!tip] Key Insights
> - Asymmetric context within a single model, where a tutor has privileged information and a student does not, creates an effective dynamic for self-distillation.
> - Consensus gating is crucial for filtering unreliable self-generated supervision, preventing the model from reinforcing its own errors.
> - Dense, trajectory-level distillation provides a more stable and effective learning signal for complex reasoning capabilities compared to sparse rewards or answer-only supervision.
