# A Simple Interpretable Transformer for Fine-Grained Image Classification and Analysis

> [!summary] Summary
> The INTR model introduces a simple, inherently interpretable Transformer for fine-grained image classification by having each class actively search for itself within an image. This approach provides built-in, attribute-level visual explanations directly from cross-attention maps, outperforming other interpretable models in identifying distinctive traits across various biological and object datasets.

## Problem

- Deep learning models for image classification often act as "black boxes," lacking transparency in their decision-making processes.
- Existing post-hoc interpretability methods can suffer from low resolution, computational cost, and potential unfaithfulness to the model's true reasoning.
- Prior self-interpretable models often require complex, custom architectures or multi-stage training, limiting their generalizability and ease of use.
- Fine-grained classification tasks necessitate identifying subtle, discriminative attributes, which current explanation methods struggle to pinpoint accurately and consistently.

## Method

- INTR adapts a standard Transformer encoder-decoder architecture, replacing generic object queries with ==learnable class-specific query vectors== for the decoder.
- A ==cross-attention mechanism== within the decoder allows each class-specific query to directly attend to and aggregate relevant image features, forming class-specific feature representations.
- The model uses a single learnable ==class-agnostic presence vector== to classify based on these class-specific features, and is trained end-to-end with standard cross-entropy loss.

## Results

- INTR consistently provides faithful, built-in, attribute-level interpretations across **eight** diverse fine-grained datasets (e.g., birds, fish, butterflies), demonstrating its robust generalizability.
- A human study showed INTR achieved **74.7%** attribute identification accuracy on the CUB dataset, significantly outperforming ProtoPFormer's **42.2%**.
- The model exhibits high sensitivity to subtle attribute manipulations in images, directly altering cross-attention maps and often leading to changes in classification, affirming that predictions are driven by localized attributes.
- INTR achieves classification accuracy comparable to a fine-tuned ResNet-50 on most datasets, with a **9.2%** improvement on the Fish dataset, while offering inherent interpretability.

## Takeaways

> [!tip] Key Insights
> - By designing each class to "search for itself" via dedicated query vectors and cross-attention, the model intrinsically generates faithful, attribute-level visual explanations without additional post-hoc steps.
> - The multi-head attention mechanism naturally learns to localize multiple, distinct attributes for each class, aiding fine-grained differentiation.
> - The mathematical formulation demonstrates that INTR's cross-attention maps are directly tied to prediction logits, providing a strong theoretical basis for their interpretability and addressing the "attention is not explanation" debate.
> - Self-attention among class queries in the decoder allows for contextual reasoning, enabling the model to focus on finer distinguishing attributes when comparing visually similar classes.
