# Turning Video Models into Generalist Robot Policies

> [!summary] Summary
> A new architecture, VERA, enables generalist robot control by decoupling an action-free video generative model for visual planning from a specialized Jacobian Inverse Dynamics Model (J-IDM) for action execution. This approach facilitates zero-shot, language-conditioned manipulation across multiple robot embodiments and complex tasks, outperforming existing end-to-end robot foundation models in reasoning-heavy scenarios.

## Problem

- Developing robot systems that generalize to novel tasks, embodiments, and environments, similar to the capabilities observed in large language models.
- The lack of web-scale, paired robot action data severely limits the generalization capabilities of current Vision-Language-Action (VLA) and World-Action Models (WAMs).
- Existing Inverse Dynamics Models (IDMs) struggle with generalization, data efficiency, and scalability to high-dimensional action spaces, failing to faithfully translate visual plans to actions.

## Method

- A decoupled architecture (VERA) separates visual planning using an action-free video generative model from action execution handled by an embodiment-specific ==Inverse Dynamics Model (IDM)==.
- A novel Jacobian-IDM (J-IDM) is introduced, leveraging an image-space Jacobian to translate predicted visual transitions (via optical flow) into robot actions, trained with a joint forward-inverse objective.
- VERA employs a closed-loop, receding-horizon control: the video planner generates future frames, J-IDM converts a prefix into actions, the robot executes, and the cycle repeats with updated observations.

## Results

- VERA demonstrated zero-shot, language-conditioned manipulation on a real 7-DoF Panda arm, showing robustness to environmental variations and successfully performing complex tasks requiring visual and linguistic reasoning, including those with occlusions.
- A single video planner, when post-trained on diverse data and paired with respective J-IDMs, generalized across different embodiments (7-DoF Panda arm and 16-DoF Allegro hand) for contact-rich manipulation tasks like dexterous cube reorientation.
- J-IDM showed superior scalability with increasing DoFs and approximately **2x** better data efficiency compared to direct IDM baselines, leading to improved action reconstruction accuracy and higher closed-loop task success rates on simulated environments.

## Takeaways

> [!tip] Key Insights
> - Decoupling the visual planner from action execution preserves the video model's strong visuospatial reasoning capabilities, which can be compromised in end-to-end architectures.
> - Integrating classical robotics principles, specifically the Jacobian, into a deep learning framework can create a data-efficient and scalable inverse dynamics model for faithful video-to-action translation.
> - The challenge of scarce action-labeled data can be mitigated by using abundant action-free video data for planning and more readily available, task-agnostic data (potentially self-play generated) for training an embodiment-specific action translator.
