# GraphPlanner: Graph Memory-Augmented Agentic Routing for Multi-Agent LLMs

> [!summary] Summary
> GraphPlanner introduces a graph memory-augmented agentic router for multi-agent large language models, dynamically generating query-specific workflows by selecting heterogeneous LLM backbones and specialized agent roles. This system demonstrated superior performance and efficiency across diverse tasks, achieving state-of-the-art accuracy with significant gains while reducing computational costs and exhibiting robust generalization capabilities.

## Problem

- Existing single-round LLM routers lack multi-step reasoning, task decomposition, and explicit coordination for complex, real-world tasks.
- Multi-round routing systems treat LLM calls as independent events, leading to redundant computations, semantic inconsistencies, and underutilization of heterogeneous LLM strengths.
- Current agentic LLM research often assumes homogeneous LLM backbones for agents and rarely systematically leverages abundant historical interaction memories to improve future coordination.

## Method

- **GraphPlanner** frames agentic routing as a ==Markov Decision Process== (MDP) to enable sequential decision-making for generating adaptive, query-specific workflows.
- It introduces GARNet, a heterogeneous graph neural network, to parameterize the routing policy, which captures and integrates current workflow memory and historical interaction memories through shared 'role hub nodes'.
- The entire routing pipeline is optimized using Proximal Policy Optimization (PPO), a reinforcement learning algorithm, to jointly maximize task-specific performance and minimize computational costs.

## Results

- GraphPlanner achieved state-of-the-art accuracy in 8 out of 10 tasks across two evaluation phases, with an average accuracy gain of +**9.3%** over the best baseline in workflow generation, consistently forming the Pareto frontier for accuracy-cost trade-offs.
- It demonstrated strong zero-shot generalization with **78%** average accuracy on unseen datasets, significantly outperforming baselines, and maintained superior performance with unseen LLM backbones and novel agentic roles.
- The system exhibited efficient training, requiring the smallest GPU compute (1.04 GiB) and total training time (120 minutes) among compared methods, alongside a low inference time of 1.2 seconds per query.

## Takeaways

> [!tip] Key Insights
> - Modeling agentic routing as an MDP allows for dynamic selection of both heterogeneous LLM backbones and specialized agent roles (Planner, Executor, Summarizer), enabling adaptive workflow generation.
> - A heterogeneous graph-based memory structure (GARNet) effectively integrates evolving workflow context and accumulated historical interactions, facilitating more informed and adaptive routing decisions.
> - Reinforcement learning, specifically PPO, successfully addresses the deferred reward problem in multi-step agentic routing, optimizing for long-term task performance and cost-efficiency simultaneously.
