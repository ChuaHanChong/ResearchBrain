# Few-shot Object Detection via Feature Reweighting

> [!summary] Summary
> Researchers from National University of Singapore and University of California, Berkeley developed a few-shot object detection framework using feature reweighting within a one-stage detector. This approach enables models to detect novel object categories from 1-10 examples, achieving a 14.8% mAP on PASCAL VOC Novel Set 1 for 1-shot learning, significantly outperforming previous baselines, and exhibiting faster convergence.

## Problem

- Traditional object detection models require extensive, precisely annotated datasets, posing a challenge for rare or expensive-to-annotate categories.
- Existing few-shot classification methods are not directly extendable to object detection, which demands both accurate class prediction and precise spatial localization.
- Prior few-shot object detection methods often rely on auxiliary unlabeled data or external semantic information, which may not always be available.

## Method

- A one-stage object detection model (adapted **YOLOv2**) incorporating a ==meta feature learner== and a ==class-specific reweighting module== that modulates feature maps based on support examples.
- A ==two-phase training scheme==: initial training on abundant "base classes" to learn generalizable meta features, followed by few-shot fine-tuning on a mixed dataset of base and novel classes.
- A novel ==softmax-based classification loss== function designed for few-shot scenarios to prevent redundant detections and enhance class discrimination.

## Results

- Achieved superior performance on PASCAL VOC, with a **14.8%** mAP for 1-shot learning on Novel Set 1, significantly outperforming the best baseline's **8.2%** mAP.
- Demonstrated enhanced performance on MS-COCO, yielding an AP@[0.5:0.95] of **5.6%** in the 10-shot setting, compared to **3.2%** for the strongest baseline.
- Exhibited significantly faster learning, reaching higher accuracy in approximately **1,200 iterations**, while baselines required around **25,000 iterations** to converge.

## Takeaways

> [!tip] Key Insights
> - Class-specific feature reweighting effectively adapts general meta features for novel object detection by dynamically adjusting feature contributions guided by minimal support examples.
> - A dedicated two-phase training strategy is crucial for learning robust general representations and rapidly adapting to new, data-scarce categories in object detection.
> - Providing precise spatial information (via a binary mask) for support examples significantly improves the reweighting module's ability to generate discriminative class-specific feature vectors.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work presented in this paper addresses a specific challenge within the field of computer vision, focusing on **few-shot object detection**. This area lies at the intersection of general object detection and few-shot learning.

Deep convolutional neural networks (CNNs) have achieved notable successes in object detection tasks, as evidenced by developments in architectures such as R-CNN, Fast R-CNN, Faster R-CNN, YOLO, and SSD. However, these conventional approaches typically demand extensive datasets with a large number of precisely annotated bounding boxes for effective training. This requirement can be problematic for object categories that are inherently rare, difficult to annotate, or for which data collection is resource-intensive (e.g., endangered species, specific medical images, or unique local objects).

Few-shot learning, a subfield of machine learning, aims to enable models to generalize from a very limited number of examples per class. While meta-learning techniques have shown promise in few-shot *classification* (e.g., Matching Networks, Prototypical Networks, MAML), extending these methods directly to object detection is non-trivial. Object detection is a more complex task than classification as it necessitates both accurate class prediction and precise spatial localization (bounding box regression), often in the presence of background clutter or multiple objects. Existing few-shot classification methods do not inherently provide mechanisms for generating bounding box predictions or for handling irrelevant objects within an image.

Prior research has explored related challenges such as weakly-supervised object detection (using image-level labels), few-example object detection (relying on abundant unlabeled data for pseudo-annotations), and zero-shot object detection (detecting entirely unseen categories, often requiring external semantic information). This paper distinguishes itself by focusing on a specific scenario where only a few *bounding box annotations* (1-10 shots) are available for novel classes, without relying on additional unlabeled images or external knowledge. It operates within a transfer learning paradigm, leveraging a larger set of "base classes" with abundant annotations to facilitate learning for these "novel classes."

Thus, this work contributes to bridging the gap between the data-intensive requirements of modern object detectors and the practical need for models that can adapt quickly to new, data-scarce categories, akin to human learning capabilities.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a **few-shot object detector** capable of recognizing and localizing objects from novel categories using only a minimal number of annotated examples.

The motivation for pursuing this objective stems from several practical considerations:

- **Data Scarcity for Rare Categories:** Many real-world object categories, such as specific types of vehicles, endangered animal species, or particular medical conditions, naturally have very few instances available for data collection. Annotating bounding boxes for these rare objects is often time-consuming, expensive, or requires specialized expertise, making it impractical to generate large, fully annotated datasets.
- **Human-like Learning for Computer Vision Systems:** Humans possess the ability to quickly learn to identify new objects from just a few observations. Current deep learning models, despite their performance, often lack this rapid adaptation capability. The development of few-shot detection models aims to imbue computer vision systems with a similar efficiency in learning novel concepts.
- **Deployment of Pre-trained Detectors to New Domains:** Large-scale object detection datasets (e.g., PASCAL VOC, MS-COCO) enable the pre-training of robust detection models. However, the number of categories covered by these datasets is finite and limited compared to the vast diversity of objects in the real world. A few-shot detection capability would allow pre-trained detectors to be adapted for new, application-specific categories with minimal retraining effort and data. This aligns with scenarios where a general detector needs to be deployed for new classes with limited samples.
- **Challenges of Object Detection vs. Classification:** While few-shot learning has been explored in classification tasks, object detection poses additional complexities. It requires predicting not only the class but also the precise location and extent of objects, which can be difficult due to varying object scales, aspect ratios, and the presence of confounding background elements. Standard few-shot classification methods do not directly address these localization requirements.

To address these motivations, the specific objectives include:

1. **Learning Generalizable Meta Features:** Develop a feature extractor that can learn rich, transferable representations from base classes, which are then adaptable to novel classes.
2. **Adaptive Feature Modulation:** Design a mechanism that can effectively utilize a few support examples from novel classes to modulate or reweight these meta features, making them discriminative for the specific novel objects.
3. **End-to-End Trainability:** Integrate these components (feature learner, reweighting module, and detection prediction) into a single, end-to-end trainable framework using a specialized few-shot learning scheme and loss function.
4. **Performance Evaluation:** Empirically demonstrate the model's effectiveness and its advantage over existing baselines across multiple datasets and under various few-shot settings.

### 3. Methodology and Approach

The proposed few-shot object detection model is built upon a one-stage detection framework, specifically adapting the YOLOv2 architecture. It introduces two main components: a meta feature learner and a reweighting module, which are trained end-to-end with a carefully designed learning scheme and loss function.

#### 3.1. Model Architecture

The model consists of three interconnected modules:

1. **Meta Feature Learner (D):** This module serves as the backbone feature extractor. It is implemented using the DarkNet-19 architecture, similar to YOLOv2. Its function is to extract generalizable "meta features" from an input "query" image. Let `I` be the query image; the feature learner produces a meta feature map `F ∈ R^(w × h × m)`, where `w, h` are spatial dimensions and `m` is the number of feature channels.
2. **Reweighting Module (M):** This is a lightweight CNN designed to process "support examples" (few-shot samples of novel classes). For each novel class `i`, it takes a support image `(I_i, M_i)` as input, where `M_i` is a binary mask indicating the target object's bounding box within `I_i`. This mask provides explicit spatial information about the object of interest. The module embeds this support information into a class-specific reweighting vector `w_i ∈ R^m`. This vector `w_i` is intended to capture a global representation of the target object with respect to the `m` meta features.
3. **Detection Prediction Module (P):** This module is responsible for producing the final detection outputs. It takes the *modulated* meta features as input. The modulation occurs via a channel-wise multiplication: `F_i = F ⊗ w_i`. This process adjusts the contribution of each meta feature in `F`, highlighting those important for detecting class `i`. The adapted feature map `F_i` is then fed into `P` to predict for each anchor box: objectness score `o_i`, bounding box location offsets `(x_i, y_i, h_i, w_i)`, and a class-specific classification score `c_i` for class `i`.

#### 3.2. Learning Scheme: Two-Phase Training

To ensure few-shot generalization, a novel two-phase learning scheme is employed:

1. **Phase 1: Base Training:**
 - The model (D, M, P) is trained jointly on abundant annotated data from the "base classes."
 - Training is structured episodically: in each iteration, a "few-shot detection learning task" `T_j` is created. `T_j` consists of a support set `S_j` (containing `N` support images, each from a different base class, with masks) and a query set `Q_j` (query images from base classes with full annotations).
 - The objective is to learn generalizable meta features (D) and a reweighting module (M) that can effectively modulate these features for detection (P) in a few-shot context, even when trained on base classes.

2. **Phase 2: Few-Shot Fine-tuning:**
 - After base training, the model is fine-tuned on a mixed dataset containing both base and novel classes.
 - For novel classes, only `k` annotated bounding boxes are available per class. To maintain balance, `k` boxes are also sampled for each base class.
 - This phase involves significantly fewer iterations than base training, reflecting the "few-shot" adaptation.

#### 3.3. Inference Procedure

After few-shot fine-tuning, the reweighting module is used differently during inference. For a target novel class, the reweighting vector `w_i` is pre-computed by averaging the vectors generated from its `k`-shot support examples. Once averaged, this static `w_i` is used for all subsequent detections of class `i`. This allows the reweighting module (M) to be entirely removed during real-time inference, adding negligible parameters or computational overhead to the base detector.

#### 3.4. Detection Loss Function

The overall detection loss `L_det` is a composite of three components:

- **Bounding Box Loss (L_bbx) and Objectness Loss (L_obj):** These are adapted from YOLOv2, with modifications to balance positive and negative samples for the objectiveness scores.
- **Classification Loss (L_c):** This is a critical component for few-shot learning. Instead of binary cross-entropy (which can lead to redundant detections by treating each class independently), the model employs a **softmax layer** across the `N` novel classes for classification scores. The actual classification score for class `i` is given by `ˆc_i = e^c_i / Σ(e^c_j)` over all `N` classes. A cross-entropy loss is then applied to these softmax-calibrated scores: `L_c = - Σ (1(·, i) log(ˆc_i))`. This design ensures that less probable class predictions are suppressed, preventing multiple detections for the same region across different classes.

#### 3.5. Reweighting Module Input Details

The reweighting module receives a 4-channel input: the 3 RGB channels of the support image and an additional binary "mask" channel (`M_i`). This mask explicitly highlights the region of the target object within the support image, guiding the module to extract relevant features and context for generating the reweighting vector. If multiple target objects are present in a support image, only one is utilized.

### 4. Main Findings and Results

The experiments demonstrate the effectiveness of the proposed few-shot object detection model across various datasets and settings.

- **Superior Performance on PASCAL VOC:** The model consistently outperformed all established baselines (YOLO-joint, YOLO-ft, YOLO-ft-full, LSTD(YOLO), LSTD(YOLO)-full) on the PASCAL VOC dataset. The performance gains were particularly significant in extremely low-shot scenarios (1-3 shots per novel class). These improvements were consistent across three different base/novel class splits and varying numbers of shots (1, 2, 3, 5, 10). For example, in the 1-shot setting, the proposed model achieved an mAP of 14.8% on Novel Set 1, whereas the best baseline (LSTD(YOLO)-full) reached 8.2%.
- **Performance on MS-COCO:** On the more complex MS-COCO dataset, the model also demonstrated superior performance compared to baselines for both 10-shot and 30-shot settings, as measured by various AP metrics (AP@[0.5:0.95], AP@0.5, AP@0.75, and size-specific APs). For instance, in the 10-shot setting, the model achieved an AP@[0.5:0.95] of 5.6%, significantly higher than LSTD(YOLO)-full's 3.2%.
- **Cross-Dataset Transferability:** The model exhibited good transferability in a COCO-to-PASCAL setting, where it was trained on COCO base classes and fine-tuned/evaluated on PASCAL VOC novel classes. It achieved an mAP of 32.29%, outperforming baselines which were in the 28-29% range.
- **Necessity of Two-Phase Training:** The "YOLO-joint" baseline, which trains all classes together, performed poorly, often achieving 0.0 mAP for novel classes. This finding validates the importance of the two-phase training scheme, where knowledge is first represented from base classes and then fine-tuned with few-shot data.
- **Faster Learning Speed:** The proposed model converged significantly faster than the "YOLO-ft-full" baseline. While baselines required around 25,000 iterations to fully converge, the proposed model achieved higher accuracy in approximately 1,200 iterations. This indicates efficient adaptation to novel classes.
- **Interpretable Reweighting Coefficients:**
 - Visualization of reweighting vectors revealed that approximately half of the meta features exhibited notable variance across different classes, suggesting their role in class-specific modulation, while the remaining features were largely shared.
 - t-SNE visualization showed that reweighting vectors for visually similar classes tended to cluster together (e.g., animals, transportation tools), indicating a semantically meaningful representation.
- **Strong Base Feature Representation:** On base classes, the model achieved detection performance (mAP) comparable to the vanilla YOLOv2 detector, indicating that its "meta features" are powerful and generalizable, even before few-shot adaptation.
- **Ablation Studies:**
 - **Reweighting Layer:** Applying reweighting to deeper feature layers (Layer 21) yielded better performance than shallower layers (Layer 13, 20). Modulating only half of the features in Layer 21 did not significantly degrade performance, supporting the idea of shared features.
 - **Loss Functions:** The proposed softmax-based classification loss significantly outperformed single-binary and multi-binary loss functions, demonstrating its effectiveness in suppressing redundant detections.
 - **Reweighting Module Input:** Using an image with a binary mask indicating the object of interest as input to the reweighting module proved superior to using only the image or a cropped object. This highlights the importance of providing precise location and context information for effective feature modulation.

### 5. Significance and Potential Impact

This research contributes to the field of computer vision by addressing the practical and challenging problem of few-shot object detection, which has previously received less attention compared to few-shot classification. The significance and potential impact of this work include:

- **Enabling Object Detection for Data-Scarce Categories:** The model's ability to learn novel object classes from as few as one to ten examples has substantial implications for applications where obtaining large, annotated datasets is infeasible. This includes domains like medical imaging (rare diseases), industrial inspection (unique defects), environmental monitoring (new species), or rapidly evolving fashion and product catalogs.
- **Bridging Human-like Learning with Deep Models:** By demonstrating rapid adaptation and strong generalization from limited examples, the work moves deep learning-based object detectors closer to human-like learning efficiency, potentially reducing the development cycle for new detection tasks.
- **Novel Architectural Contributions:** The introduction of a meta feature learner coupled with a lightweight, class-specific feature reweighting module, integrated within a one-stage detector, represents a novel approach to few-shot object detection. The method's effectiveness validates the utility of dynamically modulating feature contributions based on support examples.
- **Improved Training Paradigm:** The two-phase learning scheme and the carefully designed softmax-based classification loss function offer a robust methodology for training few-shot detectors, mitigating issues like overfitting to limited novel data and suppressing redundant detections. These insights can inform future few-shot learning research.
- **Enhanced Transfer Learning Capabilities:** The model's strong performance in cross-dataset transfer scenarios suggests its potential for robust generalization across different visual domains, requiring minimal adaptation for new targets.
- **Foundation for Future Research:** The detailed analysis of learning speed, reweighting coefficients, and ablation studies provide valuable insights into the inner workings of the model. These analyses can serve as inspiration and a baseline for further advancements in few-shot detection, including exploring more complex scenes, different detector architectures, or integrating other forms of meta-learning.
- **Practical Deployment:** The model's fast adaptation speed and the ability to remove the reweighting module during inference make it suitable for real-world deployment scenarios where new objects might need to be recognized quickly with minimal additional computational overhead. This could also be relevant for lifelong learning systems where models continuously update their knowledge base with new categories.
