# MOBODY: Model Based Off-Dynamics Offline Reinforcement Learning

> [!summary] Summary
> An offline reinforcement learning framework called MOBODY addresses the challenge of learning policies for target environments with mismatched dynamics by explicitly learning target dynamics and leveraging them for exploration. The framework improves performance by an average of 44% over baselines in tasks with gravity and friction shifts, demonstrating robustness in scenarios with significant dynamics discrepancies.

## Problem

- Learning policies for a target environment using a primary offline dataset from a source (e.g., simulator) and a limited offline dataset from the target (e.g., real-world), where dynamics are mismatched.
- Existing methods for 'off-dynamics offline RL' are conservative, optimizing policies primarily in 'low-shift regions' of the state-action space.
- This conservatism restricts exploration, leading to suboptimal performance when optimal target trajectories are in 'high-shift regions' or require actions outside low-shift data.

## Method

- **MOBODY** (Model-Based Off-Dynamics Offline Reinforcement Learning) explicitly learns the ==target dynamics== by decomposing the dynamics model into separate action encoders (for source and target) and shared state encoder and transition function.
- It generates 'fake' target domain transitions by rolling out the current policy within the learned target dynamics model, augmenting the training data.
- Policy optimization uses an enhanced dataset (including real target data, augmented source data, and fake rollouts) combined with a target Q-weighted behavior cloning loss to prioritize actions with high estimated target-domain Q-values.

## Results

- MOBODY achieved an average improvement of **44%** over the best-performing baseline, REAG, across 32 MuJoCo tasks involving gravity and friction shifts.
- It demonstrated superior performance, particularly in challenging scenarios with significant dynamics shifts (e.g., HalfCheetah-Friction-**0.1**, Ant-Friction-5.0), where other methods largely failed.
- Ablation studies confirmed the effectiveness of MOBODY's custom dynamics learning, the cycle transition loss, and the target Q-weighted behavior cloning in improving policy performance and robustness.

## Takeaways

> [!tip] Key Insights
> - Decomposing the dynamics model with shared latent state representations and domain-specific action encoders effectively leverages limited target data and abundant source data under dynamics mismatch.
> - Generating synthetic rollouts using learned target dynamics enables effective policy exploration beyond the static offline datasets, addressing the limitations of conservative existing methods.
> - A target Q-weighted behavior cloning loss acts as a robust regularization mechanism, guiding policy optimization towards high-value actions in the target domain while mitigating out-of-distribution issues.
