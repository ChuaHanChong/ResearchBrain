# Vision-TL-Action: Neuro-Symbolic Trajectory Generation from Visual Observations and Temporal Logic

> [!summary] Summary
> Nankai University, Zhongguancun Academy, and The Hong Kong Polytechnic University researchers introduce Vision-TL-Action, a framework that generates robot action trajectories directly from visual observations and Signal Temporal Logic (STL) specifications. This approach removes the need for explicit object geometry at inference time, achieving trajectory satisfaction coverage that matches or exceeds methods using privileged state information, and demonstrates effective visual-symbolic grounding.

## Problem

- Robotic tasks demand precise reasoning and planning, incorporating temporal deadlines, sequential execution, and safety constraints, often expressed using Signal Temporal Logic (STL).
- Existing learning-based STL planning methods frequently rely on symbolic scene interfaces or privileged information, such as exact metric object geometry, which limits real-world applicability.
- A significant challenge remains in bridging high-level compositional temporal logic planning with low-level visual perception to enable robots to interpret goals directly from visual input.

## Method

- **Vision-TL-Action** processes multi-view visual observations and a ==coordinate-free STL graph== to generate action trajectories without requiring explicit object geometry during inference.
- The framework employs a ==bidirectional graph–vision cross-attention== mechanism to fuse TL node tokens with spatially addressable visual tokens, enabling predicate-to-object grounding.
- A ==conditional flow-matching Temporal U-Net== is used for trajectory generation, conditioned by the fused graph–vision features and the robot's initial state, with an auxiliary grounding objective during training.

## Results

- In Panda manipulation tasks, Vision-TL-Action achieved **67.45%** Success@1024, surpassing an oracle-state baseline (**59.11%**) by **8.33 percentage points**.
- For AntMaze navigation, the model demonstrated **96.35%** Success@256, comparable to the oracle-state result of **96.88%**, indicating it effectively closed the performance gap with privileged information in this domain.
- Predicate-to-object grounding significantly improved attention metrics, increasing correct-object dominance from **0.231** to **0.341** and top-5 hit from **0.487** to **0.978** in Panda, confirming effective visual-symbolic alignment.

## Takeaways

> [!tip] Key Insights
> - Complex temporal logic goals can be successfully interpreted and grounded directly from raw visual input, eliminating reliance on pre-defined or externally provided metric object geometry at inference time.
> - A learned mechanism, specifically cross-attention between TL node tokens and spatial visual tokens, can dynamically bind object-referenced predicates to their corresponding visual evidence.
> - Visually-conditioned trajectory generation can achieve competitive satisfaction coverage for STL specifications, sometimes outperforming systems with privileged, exact object state information.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Robotic systems frequently encounter tasks that necessitate precise reasoning and planning, incorporating elements such as temporal deadlines, sequential execution orders, and safety constraints. Signal Temporal Logic (STL) offers a formal and machine-checkable language for expressing such complex temporal requirements over continuous trajectories. While STL provides a rigorous framework for defining valid trajectories, the process of translating these specifications into executable robot actions remains a distinct and complex planning challenge.

The broader landscape includes several parallel research directions. One area involves Vision-Language-Action (VLA) policies, which aim to map visual observations and natural language instructions directly to robot actions. While VLA models have demonstrated capabilities in various tasks, many representative models do not explicitly condition action generation on compositional STL specifications.

A complementary line of research focuses on learning-based STL planning. These methods learn policies or generate trajectories from STL specifications. However, existing approaches in this domain commonly rely on symbolic or state-based scene interfaces. For example, some models encode exact object geometry within their task graphs, effectively bypassing the perception-to-symbol grounding process required when working with visual observations. This reliance on privileged information, such as precise metric geometry for objects, presents a barrier to deploying these methods in real-world scenarios where only visual data is available.

This work, Vision-TL-Action, positions itself at the intersection of these fields. It aims to bridge the gap between compositional temporal logic planning and visual perception by developing an STL-conditioned trajectory generator that operates directly on visual observations, thereby obviating the need for explicit object geometry at inference time. The paper builds upon prior work like TeLoGraF, which uses graph-encoded STL specifications for trajectory generation, but specifically addresses TeLoGraF's reliance on privileged geometric information. By integrating visual observations, Vision-TL-Action seeks to advance the state of robot planning towards systems that can interpret high-level temporal logic goals in visually rich environments without requiring a pre-defined symbolic representation of the scene.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a method for generating robotic action trajectories that satisfy complex temporal logic specifications using only visual observations and the robot's initial state, without requiring explicit object geometry at inference time. This objective is driven by several key motivations:

1. **Bridging Perception and Symbolic Planning:** Existing temporal logic planning methods, particularly those leveraging learning-based approaches, often assume access to a symbolic representation of the environment, including precise metric geometry of objects (e.g., coordinates, radii). This assumption simplifies the planning problem by externalizing the visual perception and grounding challenges. The motivation is to integrate visual perception directly into the STL-conditioned trajectory generation pipeline, enabling robots to interpret and act upon temporal logic goals from raw visual input.

2. **Eliminating Privileged Information at Inference:** Relying on exact object geometry at inference time limits the applicability of current STL-conditioned planners to scenarios where such precise information is either pre-known or provided by a separate, potentially error-prone, perception module. The researchers are motivated to remove this dependency, aiming for a system that can operate given only a "coordinate-free" STL graph (which specifies predicate types and object identities but not their metric properties) and multi-view images. This reduces the cognitive burden on the system and moves towards a more end-to-end learning paradigm.

3. **Achieving Object-Referenced Predicate Grounding:** A significant challenge in connecting visual input with symbolic temporal logic is binding object-referenced predicates (e.g., "reach object O1") to their corresponding visual evidence in the scene. Current systems often bypass this by having object geometry pre-encoded. A key motivation is to enable this predicate-to-region grounding process to occur dynamically through a learned mechanism, specifically via cross-attention between temporal logic node tokens and spatial visual tokens. This grounding is crucial for the system to correctly interpret which visual features relate to which symbolic elements of the task.

4. **Demonstrating Competitive Performance with Visual Conditioning:** The research is motivated to demonstrate that a model relying solely on visual conditioning can achieve trajectory satisfaction coverage comparable to, or even exceeding, systems that operate with privileged, exact object state information. This would provide empirical evidence for the viability and potential advantages of a vision-centric approach to temporal logic planning in complex robotic tasks.

In summary, the core motivation is to make compositional temporal logic planning more practical and robust for real-world robotic applications by enabling it to directly interpret visual observations and ground symbolic goals within those observations, thereby moving away from reliance on hand-engineered or pre-computed geometric scene descriptions.

### 3. Methodology and Approach

Vision-TL-Action is designed to generate action trajectories by integrating multi-view visual observations with coordinate-free Signal Temporal Logic (STL) specifications. The methodology comprises five main components: Coordinate-Free TL Graph Encoding, Addressable Multi-View Visual Tokens, Graph–Vision Cross-Attention, Predicate-to-Object Grounding, and Flow-Matching Trajectory Generation.

#### 3.1. Coordinate-Free TL Graph Encoding

The input STL formula is converted into a coordinate-free STL graph $G_\Phi$. Unlike prior methods, this graph explicitly excludes metric scene geometry (e.g., object coordinates, sizes). Each node in the graph represents an operator, a temporal interval, or an atomic predicate. Object identities referenced by atomic predicates are represented by categorical indices. These indices are mapped to learned continuous embeddings, $e_{\text{obj}}$, which distinguish objects symbolically without encoding their physical properties. The initial node representation $f_v^{(0)}$ concatenates the operator type, temporal interval, atomic predicate type, object-identity embedding, shape category, and syntax-role indicator. An $L_g$-layer graph-convolutional encoder ($E_{\text{TL}}$) processes this graph structure. Instead of producing a single graph-level embedding, $E_{\text{TL}}$ retains the final representation of each TL node as a separate token, $X \in \mathbb{R}^{N \times d}$, where $N$ is the number of nodes and $d$ is the token dimension. These TL node tokens are then used in the graph–vision cross-attention mechanism.

#### 3.2. Addressable Multi-View Visual Tokens

Multi-view observations $I = \{I^{(c)}\}_{c=1}^C$ (RGB images or synthetic semantic rasters) are processed to extract visual features. A shared visual backbone ($B_{\text{vis}}$) processes each view independently, producing a feature grid. These grid features are flattened into a sequence of local features $f_j$. Each local feature is then projected to the token dimension $d$ to form content tokens $e_j$. To preserve spatial information and view origin, each token is augmented with an "address" $s_j = [\xi_j, \eta_j, \nu_j]^\top$, where $(\xi_j, \eta_j)$ are normalized image-plane coordinates and $\nu_j$ is a normalized view coordinate. This address is linearly projected and added to the content token, creating spatially addressable visual tokens $Z \in \mathbb{R}^{L \times d}$, where $L$ is the total number of visual tokens across all views. This approach ensures that visual tokens carry spatial information without containing symbolic object identities or metric world coordinates.

#### 3.3. Graph–Vision Cross-Attention

To establish correspondence between TL nodes and visual evidence, a bidirectional graph–vision cross-attention mechanism fuses the TL node tokens $X$ and addressable visual tokens $Z$. This module consists of two bidirectional layers, each employing four multi-head attention (MHA) heads.
In the first direction (TL-to-vision), TL node tokens query visual tokens to retrieve scene-dependent evidence. The updated TL node tokens $X^{(\ell)}$ are computed using $MHA_{g \leftarrow v}(\cdot, Z^{(\ell-1)}, Z^{(\ell-1)})$.
In the reverse direction (vision-to-TL), visual tokens are conditioned by the updated TL node tokens. The updated visual tokens $Z^{(\ell)}$ are computed using $MHA_{v \leftarrow g}(\cdot, X^{(\ell)}, X^{(\ell)})$.
This bidirectional exchange allows mutual conditioning, ensuring that both modalities inform each other. After two layers, the final updated token sequences $\hat{X}$ and $\hat{Z}$ are produced. These are then pooled—masked mean over valid TL node tokens for $\hat{X}$ and mean over visual tokens for $\hat{Z}$—and combined via a linear projection to form a fused graph–vision feature $f_{\text{gv}}$.

#### 3.4. Predicate-to-Object Grounding

To explicitly encourage object-referenced atomic predicate (AP) nodes to attend to their corresponding objects in the visual input, an auxiliary predicate-to-object grounding objective ($L_{\text{ground}}$) is introduced during training. For each object-referenced AP node, its object identity is linked to a set of ground-truth visual token indices $R_{k(i)}$ that correspond to the object's location in supervised views. The grounding loss minimizes the negative logarithm of the total attention mass (averaged across attention heads) that an AP node assigns to its correct object region $R_{k(i)}$. This objective functions as training-only supervision; the explicit object projections and target-token indices are not used during inference.

#### 3.5. Flow-Matching Trajectory Generation

The trajectory generation component builds upon the conditional flow-matching Temporal U-Net adopted from TeLoGraF. The complete conditioning vector $c$ for the generator is formed by concatenating the fused graph–vision feature $f_{\text{gv}}$ and an embedding of the initial robot state $e_0$. The model learns a conditional vector field $v_\theta(c, s, \hat{\tau}_s)$, where $s$ is the generative flow time and $\hat{\tau}_s$ is an interpolated trajectory. The learning objective is a flow-matching loss ($L_{\text{FM}}$) which minimizes the squared difference between the predicted velocity and the target velocity required to transform a Gaussian source trajectory to a demonstrated trajectory. The overall training objective $L$ combines $L_{\text{FM}}$ and $L_{\text{ground}}$ with a weighting factor $\lambda_g$.
At inference, starting from a Gaussian noise trajectory, the model numerically integrates the learned vector field to produce a normalized trajectory, which is then denormalized to yield a candidate action trajectory. This process can be repeated $K$ times to generate a set of candidate trajectories.

### 4. Main Findings and Results

The research evaluated Vision-TL-Action in two simulated domains: Panda manipulation and AntMaze navigation, focusing on its ability to replace exact object geometry with visual observations while maintaining or improving trajectory satisfaction coverage.

#### 4.1. Performance–Coverage Analysis

- **Panda Manipulation Task:** Vision-TL-Action achieved 67.45% Success@1024, representing the fraction of tasks for which at least one of 1024 sampled trajectories satisfied the STL specification. This performance surpassed a visual fusion model (62.76%) and an oracle-state baseline (59.11%) that received exact object geometry. The paired improvement over the oracle-state baseline was 8.33 percentage points (pp).
- **AntMaze Navigation Task:** The model achieved 96.35% Success@256, which was comparable to the oracle-state result of 96.88%. The paired difference was -0.52 pp, with a 95% bootstrap interval that crossed zero, suggesting the visual model closed the performance gap with the privileged oracle state in this domain.
- **Performance by Formula Family:** On Panda, Vision-TL-Action showed improvements in conjunction/disjunction and until tasks. On AntMaze, it improved conjunction/disjunction tasks. However, exact state retained an advantage in sequential tasks in both domains.

#### 4.2. Visual-Input Intervention

Interventions were performed on fixed checkpoints by manipulating visual inputs without retraining.
- **Panda:** Dual-view input yielded 65.62% Success@1024. Performance dropped to 56.25% with only the custom camera, 60.16% with only the bird's-eye view, and 23.44% with zero images. This indicates that both camera views contribute complementary evidence, and visual input is substantial.
- **AntMaze:** Dual-view achieved 96.88% Success@256. Target-only input retained 95.31%, suggesting the task-specific target raster is the primary source of visual semantics for this domain. Performance significantly declined with map-only (45.31%) or zero-image (35.94%) inputs, confirming the critical role of target appearance. The maze layout, being fixed, allowed the generator to absorb much of the map information into its learned prior.

#### 4.3. Single Samples versus Candidate Coverage

The analysis distinguished between single-sample performance and candidate-set coverage.
- **Panda:** Vision-TL-Action's Success@1 was 3.39%, compared to 4.69% for exact state. However, at K=1024, Vision-TL-Action (67.45%) surpassed exact state (59.11%).
- **AntMaze:** The single-sample gap was larger (43.75% for Vision-TL-Action vs. 61.46% for exact state), but this narrowed significantly to 96.35% vs. 96.88% by K=256.
These results indicate that while the proposed model generates a competitive diversity of satisfying trajectories, its individual samples are less concentrated on immediate success compared to the exact-state model.

#### 4.4. TL Graph Grounding in Vision

The effectiveness of predicate-to-object grounding was evaluated using metrics such as correct-object dominance, top-5 hit, and ID-swap shift (where attention should follow exchanged object identities in the graph with fixed pixels).
- **Panda:** Grounding significantly increased correct-object dominance (from 0.231 to 0.341), top-5 hit (from 0.487 to 0.978), and ID-swap shift (from 0.019 to 0.317).
- **AntMaze:** The model achieved high dominance (0.815), top-5 hit (0.999), and a substantial ID-swap shift (1.164).
These quantitative results, supported by attention visualizations, demonstrated that the model learns to align object-referenced predicates with their corresponding visual regions, and that attention dynamically shifts with changes in object identity within the coordinate-free TL graph.

### 5. Significance and Potential Impact

The Vision-TL-Action research introduces a direct approach for generating robotic action trajectories from visual observations and structured temporal logic goals, without requiring explicit object geometry at inference time. This represents an advancement in integrating high-level symbolic planning with low-level perception, addressing a limitation prevalent in previous STL-conditioned trajectory generation methods that often relied on privileged state information.

The significance of this work lies in several areas:

1. **Reduced Dependency on Privileged Information:** By demonstrating that a system can operate effectively with a coordinate-free TL graph and visual observations, the research mitigates the need for pre-defined or externally supplied metric object geometry. This simplifies the system architecture and enhances its potential for deployment in dynamic or unstructured environments where precise object localization might be challenging or unavailable.
2. **Validation of Visual-Symbolic Grounding:** The explicit predicate-to-object grounding mechanism, supported by bidirectional cross-attention and a dedicated training objective, validates the feasibility of dynamically establishing correspondence between symbolic task elements and visual scene features. This grounding is a fundamental step towards more robust and interpretable robot intelligence, as it allows the robot to understand "what" in the image relates to "which" part of the abstract task specification.
3. **Competitive Performance with Visual Conditioning:** The achievement of performance comparable to, or exceeding, oracle-state baselines in candidate-set coverage, particularly in the Panda manipulation task, suggests that visual conditioning can be a viable and powerful alternative to privileged state information. This empirical evidence supports continued exploration of vision-centric approaches in robot planning and control.
4. **Foundation for End-to-End Learning Systems:** This work contributes to the development of more end-to-end learning systems for robotics, where a single model can process perceptual input and generate actions based on complex symbolic goals. It lays groundwork for systems that can generalize better across varying scene configurations and task instances, driven by learned visual-symbolic relationships.

**Limitations:**

The paper acknowledges several limitations that frame the scope of its current claims and point to future work:

1. **Training and Evaluation Dependencies:** While the model operates without explicit object geometry at *inference*, object projections are used for supervising the grounding objective during *training*. Furthermore, the Success@K evaluation metric relies on ground-truth STL robustness computed offline using simulator-provided geometry. For the AntMaze domain, synthetic semantic rasters are used instead of unannotated camera images.
2. **Absence of Learned Candidate Ranker:** The current metric, Success@K, measures the coverage of satisfying trajectories within a candidate set rather than the performance of a deployable top-1 trajectory. A fully practical system would require a learned mechanism to rank generated trajectories and select the optimal one.
3. **Lack of Closed-Loop Operation and Real-World Validation:** The current system operates as a one-shot trajectory generator. A truly deployable system would necessitate closed-loop replanning capabilities, allowing the robot to repeatedly observe, reason, act, and adjust its plan in real-time. Validation on physical robots under realistic visual noise and dynamic variations remains a future step.
4. **Data Scarcity for Simulation-to-Real Transfer:** A significant challenge for future development is the lack of large-scale datasets that pair visual observations, temporal tasks, actions, and outcomes from real robots, which are essential for robust simulation-to-real transfer.

Despite these limitations, the research provides a foundation for developing more capable and autonomous robotic systems that can interpret complex temporal logic goals directly from visual perceptions, paving the way for future advancements in generalist robot learning.
