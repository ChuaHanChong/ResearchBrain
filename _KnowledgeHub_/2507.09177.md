# Continual Reinforcement Learning by Planning with Online World Models

> [!summary] Summary
> An Online Agent (OA) framework for Continual Reinforcement Learning mitigates catastrophic forgetting by integrating sparse online world model learning with model predictive control planning. The approach maintains high performance on all learned tasks, achieves the lowest regret on the Continual Bench environment, and includes theoretical no-regret guarantees.

## Problem

- Catastrophic forgetting prevents reinforcement learning agents from continually acquiring new skills without losing proficiency in previous ones.
- Current Continual Reinforcement Learning (CRL) methods often rely on task-specific components or large replay buffers, hindering the development of truly online, memory-efficient agents.
- Existing CRL benchmarks suffer from issues like high computational demands, inconsistent state spaces, or insufficient task overlap for evaluating knowledge transfer.

## Method

- A Model-Based Reinforcement Learning (MBRL) framework, the **Online Agent (OA)**, is proposed, which combines online world dynamics learning with ==model predictive control (MPC)== planning.
- The world model utilizes ==Follow-The-Leader (FTL)== shallow models with ==sparse feature encoding== and analytical incremental updates, ensuring efficient, non-forgetting learning of environmental dynamics.
- Policy generation for specific tasks is achieved via MPC, using the learned world model for simulation and the ==Cross-Entropy Method (CEM)== for optimizing action sequences.
- A new benchmark, "Continual Bench," is introduced, featuring a unified world dynamics and consistent state space across spatially arranged tasks to facilitate robust CRL evaluation.

## Results

- The Online Agent (OA) consistently maintains high success rates on all previously learned tasks, demonstrating robust resistance to catastrophic forgetting comparable to a "Perfect Memory" baseline.
- On the Continual Bench environment, OA achieved the highest average performance (**72.93%**) and the lowest regret (**27.62%**) among all tested model-based and model-free methods.
- Ablation studies confirmed that OA's sparse world model efficiently scales its capacity, and the agent consistently delivered superior average performance across various buffer budget constraints, highlighting its memory efficiency.

## Takeaways

> [!tip] Key Insights
> - A unified world dynamics model can serve as a shared, stable component across diverse tasks, enabling continuous learning and adaptation in reinforcement learning agents through planning.
> - Follow-The-Leader (FTL) shallow models, combined with sparse feature encoding and analytical incremental updates, provide an efficient and theoretically no-regret method for online world model learning.
> - Integrating an online-learned world model with Model Predictive Control (MPC) allows for flexible, task-specific policy generation, circumventing the need to continually re-learn value or policy networks.
