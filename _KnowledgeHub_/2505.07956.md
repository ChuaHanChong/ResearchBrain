# Symbolic Regression with Multimodal Large Language Models and Kolmogorov Arnold Networks

> [!summary] Summary
> A novel symbolic regression framework combines multimodal large language models with Kolmogorov-Arnold Networks to infer mathematical expressions from data plots, achieving higher success rates than Mathematica's FindFormula on randomly generated functions while demonstrating effectiveness with both commercial and open-source LLMs.

## Problem

- Traditional symbolic regression methods often require manual specification of basis functions and struggle with complex expressions
- Existing approaches lack the human-like intuition for inferring functional forms from visual data representations

## Method

- **LLM-LEx** ==algorithm== uses vision-capable LLMs to propose ansatze based on function plots
- **KAN-LEx** ==extension== leverages ==Kolmogorov-Arnold Networks== to handle multivariate functions through ==decomposition into univariate components==

## Results

- Higher success rate than Mathematica's FindFormula in identifying exact expressions for random functions
- Demonstrated resilience to moderate noise levels while maintaining accuracy
- Successfully extended to multivariate functions through KAN decomposition
- Achieved comparable performance using open-source models, making the approach widely accessible

## Takeaways

> [!tip] Key Insights
> - LLMs can effectively emulate human intuition in suggesting appropriate functional forms from visual data
> - Combining genetic algorithms with LLM-guided proposals enables efficient exploration of the solution space
> - Open-source models like codestral can perform comparably to GPT-4 for this task
