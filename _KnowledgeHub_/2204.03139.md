# DiffCloud: Real-to-Sim from Point Clouds with Differentiable Simulation and Rendering of Deformable Objects

> [!summary] Summary
> Researchers at Stanford University developed DIFFCLOUD, an end-to-end differentiable pipeline for inferring physical simulation parameters of highly deformable objects directly from real point cloud sequences, achieving accurate simulation-to-reality alignment over an order of magnitude faster than prior inverse modeling approaches.

## Problem

- Accurately simulating highly deformable objects (e.g., cloth) for robotics is challenging, as physical parameters like stiffness and mass are difficult to tune manually to match real-world behavior.
- Existing "real-to-sim" methods for deformable objects are computationally expensive, requiring extensive dataset generation and training of black-box inverse models, taking hours to days.
- Real-world sensor data, especially point clouds from depth cameras, contain noise, occlusions, and partial observability, which existing methods struggle to handle robustly for accurate parameter inference.

## Method

- **DiffCloud** combines a ==differentiable mesh-based physics simulator (DiffSim)== with ==differentiable point cloud sampling (PyTorch3D)== to create an end-to-end trainable pipeline.
- Physical simulation parameters (e.g., stiffness and mass multipliers) are directly optimized via ==gradient descent== by minimizing a ==unidirectional Chamfer distance loss== between real and simulated point cloud sequences.
- This approach eliminates the need for generating large datasets for inverse model training, instead optimizing parameters in minutes using real-world point cloud observations.

## Results

- **DiffCloud** achieved consistently lower average Chamfer distance compared to inverse model baselines in real robot lift scenarios and comparable or superior performance in complex fold scenarios, indicating better alignment.
- The method demonstrated substantial computational efficiency, reducing parameter optimization time to approximately **10 minutes** per trajectory, which is over an order of magnitude faster than baselines.
- In simulated contact-rich tasks (vest hang, band stretch), **DiffCloud** robustly converged to accurate parameters in **100%** of runs, outperforming baselines that achieved convergence in only **50-80%** of runs.

## Takeaways

> [!tip] Key Insights
> - An end-to-end differentiable pipeline allows direct gradient-based optimization of physical parameters for highly deformable objects, significantly reducing the computational cost of real-to-sim alignment.
> - Leveraging differentiable point cloud sampling and a unidirectional Chamfer distance provides robustness against real-world sensor noise, occlusions, and partial observability, improving practical applicability.
> - Treating parameter inference as a joint perception-inference task avoids explicit correspondence mapping between observed real points and simulated mesh vertices, simplifying the system.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This research addresses the "real-to-sim" problem within the context of robotics, specifically focusing on the manipulation of highly deformable objects. The real-to-sim problem involves inferring parameters of general-purpose simulators from real-world observations to reduce the discrepancy between simulated and real-world behavior.

Traditionally, research in deformable object manipulation has been constrained by the complexities of hardware setups, leading to a limited range of experimental scenarios. Simulators offer a potential solution to accelerate experimentation with new tasks and algorithms, but aligning simulator output with the behavior of real, highly deformable objects remains challenging. This challenge stems from the difficulty of manually tuning complex physical parameters (e.g., mass, stiffness, friction) that govern deformation and interaction.

Previous work on real-to-sim for rigid objects often relies on low-dimensional state representations (e.g., position and orientation), which are insufficient for highly deformable objects that change shape during motion. For deformable objects, inverse models have been explored, often training neural networks on datasets generated by black-box (non-differentiable) simulators. These models typically use RGB videos or low-dimensional state information, requiring extensive domain randomization for generalization or being limited to specific material models and deformation types. The use of point clouds, as explored in this work, aims to circumvent some challenges associated with RGB images, such as the need for contrasting textures and extensive domain randomization.

The advent of differentiable rendering and differentiable simulation presents a new paradigm. Differentiable rendering allows gradient propagation from 2D or 3D observations (like point clouds) back to 3D object properties. Differentiable simulation enables simulators to adjust physical parameters directly via gradient descent, eliminating the need for extensive dataset generation and pre-training required by black-box inverse models. While several differentiable simulators exist, many support only limited interaction types or levels of deformability. Some recent efforts have explored differentiable simulation with real-world observations, but often for low-to-medium deformability or without full support for complex interactions between rigid and deformable objects or robust handling of point cloud noise.

This work specifically leverages advances in differentiable point cloud sampling and differentiable simulation to create an end-to-end differentiable pipeline. It positions itself by focusing on the inference of physical parameters for *highly deformable* objects from *real point cloud sequences*, addressing limitations in existing methods regarding computational efficiency, robustness to noise, and applicability to complex, contact-rich manipulation tasks.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop an automated and efficient method for inferring the physical simulation parameters of highly deformable objects from real-world observations. This inference aims to reduce the "reality gap" by making the behavior of simulated deformable objects match that of their real counterparts.

The motivation for this objective stems from several challenges in current robotic manipulation research:
- **Difficulty in Simulating Deformable Objects Accurately:** Realistic simulation of highly deformable objects, such as cloth, vests, or elastic bands, is complex. Manually tuning physical parameters (e.g., mass, stiffness, friction) within a simulator to accurately reflect real-world material properties is challenging, non-intuitive, and time-consuming.
- **Limitations of Hardware-Based Experimentation:** Conducting extensive experiments with deformable object manipulation on physical hardware is labor-intensive and costly. Simulators offer a scalable alternative, but their utility is directly tied to their realism.
- **Inefficiencies of Existing Real-to-Sim Methods:**
 - **Black-box Inverse Models:** A common approach involves training inverse models (e.g., neural networks) to map sensor observations to simulation parameters. However, these methods require extensive datasets of simulated trajectories generated with varied parameters, leading to substantial computational costs for data collection and model training (hours to days). Furthermore, their performance can be sensitive to the quality and realism of the training data, often requiring augmentations like domain randomization.
 - **State Representation for Deformables:** Unlike rigid objects, the state of deformable objects cannot be captured by simple pose information. Point clouds from depth cameras offer a richer representation, but processing these for inverse model training can be computationally demanding.
- **Need for Robustness to Real-World Noise:** Real sensor data, particularly point clouds from low-cost depth cameras, contains noise and occlusions. Existing methods struggle to account for these artifacts effectively when computing losses or training models.
- **Requirement for an End-to-End Solution:** There is a need for a seamless pipeline that can propagate information from real visual observations (point clouds) through a deformable object's mesh representation and finally to the underlying physical simulation parameters, without requiring explicit correspondence mapping between real and simulated states.

The research is motivated by the potential for a differentiable pipeline to significantly reduce the time and effort required to achieve simulation-to-reality alignment, thereby accelerating the development and testing of novel manipulation tasks and algorithms for deformable objects.

### 3. Methodology and Approach

The proposed method, DIFFCLOUD, addresses the real-to-sim parameter inference problem by combining differentiable point cloud sampling with a differentiable physics simulator. This approach allows for direct optimization of simulation parameters using gradient descent, bypassing the need for extensive dataset generation and inverse model training.

The core components and approach are:

- **Real-World Data Collection:** A robot manipulates highly deformable objects (e.g., cloth) in various scenarios. Two stereo depth cameras capture the scene, generating raw depth images. These are post-processed to produce merged point clouds with the robot arm masked out, resulting in a sequence of real point cloud observations ($\{\textbf{P}_{\text{real}}^t\}_{t=1}^T$).
- **Differentiable Simulation Backend:** The method employs DiffSim, a differentiable mesh-based simulator capable of modeling thin-shell deformables (e.g., cloth) and handling contact interactions with rigid objects. DiffSim represents the simulation state using generalized coordinates and velocities for all objects and uses an implicit Euler method for time integration and collision resolution. It supports gradient propagation from mesh states to physical simulation parameters like mass and stiffness.
- **Differentiable Point Cloud Sampling:** To bridge the gap between real point cloud observations and simulated mesh states, a differentiable point cloud sampler is implemented using PyTorch3D. This sampler generates an N-point, uniform-density point cloud ($\textbf{P}_{\text{sim}}^t$) from the surface of the simulated object's mesh at each timestep $t$. The sampling process involves selecting triangular mesh faces proportional to their area and generating a point on each face using barycentric coordinates. Crucially, this sampling procedure is differentiable, allowing gradients from losses defined on the sampled points to propagate back to the mesh vertices.
- **Loss Function Definition:** To compare the simulated point clouds with the real observations, a unidirectional Chamfer distance is utilized:
 $d_{\text{sim}\rightarrow\text{real}}^{\text{Chamf}} (\textbf{P}_{\text{sim}}, \textbf{P}_{\text{real}}) = \sum_{\textbf{x}_{\text{sim}} \in \textbf{P}_{\text{sim}}} \min_{\textbf{x}_{\text{real}} \in \textbf{P}_{\text{real}}} ||\textbf{x}_{\text{sim}} - \textbf{x}_{\text{real}}||^2_2$.
 This unidirectional formulation is chosen to mitigate the impact of noise artifacts present in real point clouds. By only penalizing simulated points that do not have a close real counterpart, the loss encourages the simulated object to conform to the observed real shape while being less sensitive to noise or missing data in the real point cloud. The loss is typically computed on the last frame of the trajectory or selected informative intermediate frames where deformation is most visible.
- **Gradient Propagation and Optimization:** The overall pipeline is end-to-end differentiable. The loss computed on the sampled simulated point clouds propagates back through the differentiable point cloud sampler to the mesh vertices, and then further through the differentiable simulator to the low-level physical simulation parameters (e.g., stiffness and mass multipliers). These parameters are optimized using gradient descent (e.g., Adam optimizer). The optimization process involves:
 1. Initializing simulation parameters (e.g., stiffness and mass multipliers) to a midpoint within a stable range.
 2. Running the differentiable simulation for the scenario horizon using the current parameters.
 3. Sampling point clouds from the simulated meshes.
 4. Computing the unidirectional Chamfer distance between simulated and real point clouds.
 5. Backpropagating the gradients through the system to update the simulation parameters.
 6. Repeating this process for a fixed number of iterations or until the loss falls below a predefined threshold.
 To ensure numerical stability and encourage meaningful changes, the parameters are optimized as intermediate variables mapped through a sigmoid function to scale them within a defined physical range.

- **Comparison with Baselines:** The method is compared against inverse models (METEORNET, POINTNET++, MLP) that treat the simulator as a black box. These baselines are trained on large datasets of simulated point cloud sequences, which are augmented with partial observability and Gaussian noise to mimic real-world conditions. This comparison highlights the computational efficiency and alignment capabilities of the differentiable approach.

### 4. Main Findings and Results

The experiments conducted evaluated DIFFCLOUD against three inverse model baselines (METEORNET, POINTNET++, MLP) across both real robot manipulation scenarios and purely simulated contact-rich scenarios. The evaluation focused on two key metrics: point cloud alignment (measured by unidirectional Chamfer distance) and computational efficiency.

**Real Robot Experiments (Lift and Fold Scenarios):**
- **Experimental Setup:** A Kinova Gen3 robot arm manipulated five different fabric types (categorized as highly deformable, medium, and shape-retaining) in two scenarios: lifting a cloth from a table ("lift") and folding a cloth in half ("fold"). Point clouds were captured by two Intel RealSense D435 cameras and pre-processed. For DIFFCLOUD, 2D cloth meshes (7x7 grid) were used, and two scalar multipliers for stiffness and mass were learned.
- **Alignment Performance:**
 - **Lift Scenario:** DIFFCLOUD consistently achieved lower average Chamfer distance compared to all three baseline inverse models across the three cloth categories (Figure 4). This indicates a better alignment between the simulated and real object behavior. Qualitatively, the inferred mass and stiffness parameters from DIFFCLOUD correlated with the observed physical properties of the real cloths (e.g., high mass/low stiffness for highly deformable silk-like material, low mass/high stiffness for shape-retaining paper towel) (Figure 3).
 - **Fold Scenario:** In this more complex, self-occlusion-prone scenario, DIFFCLOUD achieved alignment performance comparable to or better than the baselines in 13 out of 15 trajectories (Figure 5). The challenges of perceiving very thin sheets in motion led to outliers for paper towel manipulation, affecting all methods. Despite these challenges, DIFFCLOUD's performance was notable given its reduced computational footprint compared to the baselines.
- **Computational Efficiency:** DIFFCLOUD demonstrated significant efficiency gains. It took an average of 10 minutes per trajectory for parameter optimization in both lift and fold scenarios (Figure 3). In contrast, the baseline inverse models required approximately 2.5 to 5.5 hours for dataset generation and an additional 40 minutes to several hours for training per scenario, before inference could even begin. This represents more than an order of magnitude reduction in time to achieve alignment.

**Further Simulation Experiments (Vest Hang and Band Stretch Scenarios):**
- **Experimental Setup:** Two additional simulated scenarios were used to evaluate performance in contact-rich environments: hanging a vest on a pole ("vest hang") and stretching an elastic band against a pole ("band stretch"). These experiments used fully observable, noise-free point clouds to isolate the effects of contact and deformation modeling from real-world sensor noise.
- **Alignment Performance:** Across 10 held-out test episodes for each scenario, DIFFCLOUD successfully converged to parameters that yielded a Chamfer distance below a predefined threshold (0.0005) in 100% of the runs (Figure 6, 7). The baseline regressors, however, only achieved sub-threshold alignment in 50-80% of their runs. This suggests that DIFFCLOUD is more robust in finding suitable parameters, especially in scenarios involving complex contacts.
- **Computational Efficiency:** In these simulated experiments, DIFFCLOUD averaged 5 minutes per target trajectory to reach the alignment threshold. The baselines still required hours for dataset generation, training, and subsequent inference.

Overall, the findings indicate that DIFFCLOUD can achieve comparable or superior alignment between simulated and real deformable object behavior compared to inverse model baselines. The most significant result is the substantial reduction in the time required for parameter estimation, offering more than an order of magnitude speedup by eliminating the need for large-scale data generation and pre-training.

### 5. Significance and Potential Impact

This research presents a notable advancement in addressing the real-to-sim problem for highly deformable objects, with several implications for robotics and simulation:

- **Accelerated Real-to-Sim Alignment:** The most immediate significance is the substantial reduction in the computational time required for achieving alignment between real and simulated deformable object behavior. By leveraging an end-to-end differentiable pipeline, DIFFCLOUD reduces the parameter estimation process from hours (for data collection and training inverse models) to minutes (for direct gradient-based optimization). This efficiency gain can significantly accelerate research cycles for developing and testing manipulation algorithms for deformable objects.
- **Enhanced Realism in Deformable Object Simulation:** The method's ability to accurately infer physical parameters (mass, stiffness) from real point cloud observations contributes to creating more realistic and predictive simulations of deformable materials. Such realism is critical for transferring policies learned in simulation to the real world (sim-to-real transfer).
- **Robustness to Real-World Observation Challenges:** The use of point clouds as the observation space, combined with a unidirectional Chamfer distance loss, allows the method to operate effectively despite common real-world sensor issues such as partial observability, self-occlusion, and noise. This avoids the need for extensive domain randomization often required by vision-based methods operating on RGB images.
- **Applicability to Complex Manipulation Tasks:** The successful evaluation in contact-rich scenarios (vest hang, band stretch) suggests that DIFFCLOUD is suitable for a broader range of manipulation tasks involving interactions between deformable and rigid objects, which are typically challenging for simulators.
- **Joint Perception-Inference Framework:** The approach treats parameter inference as a joint perception-inference task, eliminating the need for explicit correspondence mapping between observed real points and simulated mesh vertices. This simplifies the pipeline and makes it more generalizable.
- **Foundation for Future Work:** The established differentiable pipeline opens several avenues for future research, including:
 - Relaxing assumptions about known robot geometry and initial object meshes by jointly optimizing these parameters.
 - Incorporating more realistic point cloud rendering, including occlusion and camera noise models, directly into the differentiable pipeline.
 - Jointly optimizing robot actions with physical simulation parameters, leading to more adaptive and robust manipulation strategies.
 - Extending the method to multi-stage, contact-rich tasks involving multiple rigid and deformable objects.
 - Inferring object morphology (mesh shape) along with physical properties, potentially allowing "on-the-fly" creation of realistic simulation scenes from real observations.

In summary, DIFFCLOUD provides a more agile and efficient paradigm for bringing real deformable object behavior into simulation, which is expected to facilitate progress in robotic manipulation of deformable materials and the development of more capable and adaptable robots.
