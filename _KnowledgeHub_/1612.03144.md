# Feature Pyramid Networks for Object Detection

> [!summary] Summary
> Feature Pyramid Networks (FPNs) introduce an architecture that efficiently constructs a multi-scale feature pyramid within deep convolutional neural networks, enhancing low-level features with rich semantic information via top-down pathways and lateral connections. Integrated into a Faster R-CNN system, FPN achieved state-of-the-art single-model results on the COCO detection benchmark, surpassing previous competition winners while maintaining high inference speed.

## Problem

- Traditional object detection systems either relied on computationally expensive image pyramids to handle objects at various scales, leading to slow inference and high memory demands.
- Deep convolutional networks, while inherently multi-scale, produced feature maps where shallow layers lacked semantic strength and deep layers lacked spatial resolution, leading to degraded performance, especially for small objects.
- There was a persistent need for robust multi-scale representations that could achieve high accuracy across object sizes without sacrificing speed or requiring inconsistent train/test time procedures.

## Method

- The paper introduces ==Feature Pyramid Networks (FPNs)==, a novel architecture that leverages the inherent multi-scale hierarchy of deep ConvNets to construct a multi-scale feature pyramid.
- FPN consists of a ==bottom-up pathway== (standard feed-forward ConvNet), a ==top-down pathway== (upsampling semantically rich features), and ==lateral connections== (merging corresponding bottom-up and top-down features).
- It integrates seamlessly into a basic Faster R-CNN system, where Region Proposal Networks and Fast R-CNN utilize the multi-level FPN features with shared network heads across all pyramid levels.

## Results

- FPN-Faster R-CNN achieved **36.2 AP** on the COCO test-dev set with a ResNet-101 backbone, surpassing all single-model COCO 2016 competition winners (e.g., G-RMI: **34.7 AP**).
- It dramatically improved Average Recall for small objects (AR_s) by **12.9 points** for Region Proposal Networks (RPN) and showed a strong **18.2 AP_s** on COCO, without using image pyramids or multi-scale input during testing.
- FPN-based Faster R-CNN maintained high efficiency, being faster than its single-scale ResNet-based counterpart (**0.148s vs 0.32s** per image for ResNet-50).

## Takeaways

> [!tip] Key Insights
> - FPN successfully creates a feature pyramid that is semantically strong at all scales by combining high-level semantic information from deeper layers with precise localization information from shallower layers.
> - The proposed architecture is computationally efficient, allowing for consistent multi-scale processing during both training and testing within deep ConvNets.
> - Parameter sharing of detection heads across all pyramid levels indicates that the FPN effectively produces features with similar semantic levels at different scales.
