# DyGRO-VLA: Cross-Task Scaling of Vision-Language-Action Models via Dynamic Grouped Residual Optimization

> [!summary] Summary
> DyGRO-VLA presents a dynamic grouped residual optimization framework to scale Vision-Language-Action (VLA) models for multi-task robotic manipulation, addressing performance degradation and catastrophic forgetting during reinforcement learning fine-tuning. The framework consistently improved multi-task performance on benchmarks like LIBERO and RoboTwin2.0, demonstrating enhanced robustness for complex tasks.

## Problem

- Reinforcement Learning (RL) optimization for VLA models often leads to task-specific policies, overfitting to a narrow set of tasks and losing cross-task scalability.
- Performance substantially degrades and becomes unstable as the number of tasks for RL optimization increases, sometimes negatively impacting the VLA model initially pre-trained on offline data.
- RL fine-tuning distorts shared feature representations, causing catastrophic forgetting of unrelated tasks and reducing cross-task knowledge sharing.

## Method

- An offline pre-training stage learns a task-sharing latent representation using the Information Bottleneck (IB) principle to extract action-relevant features while discarding nuisance factors.
- An online fine-tuning stage employs a Mixture-of-RL-Residuals (MoRR) policy that predicts action refinements (residuals) to the base model's actions without compromising the learned shared representations.
- MoRR dynamically routes and combines outputs from specialized experts, conditioned on learned task embeddings, to provide targeted corrections and mitigate adverse interference during optimization.

## Results

- Achieved leading or comparable performance across all LIBERO suites, improving average success rate to **97.1%** (**+4.4%** over base model) and significantly boosting long-horizon task performance by **+9.8%** (from **85.2%** to **95.0%**).
- Mitigated inter-task interference by dynamically grouping residual experts, which reduced negative gradient correlations between contrasting tasks while preserving positive alignment within similar task groups.
- Demonstrated robust zero-shot Sim2Real transfer on the RoboTwin2.0 benchmark, achieving **79.2%** success in simulation and matching or surpassing RFT baselines in real-world evaluations without additional fine-tuning.

## Takeaways

> [!tip] Key Insights
> - Standard RL optimizers for VLA models tend to distort pre-trained shared latent representations, causing inter-task interference and catastrophic forgetting rather than improving generalizability.
> - Decomposing policy optimization into a shared base policy and task-specific residual refinements, dynamically grouped via a Mixture-of-Experts, effectively balances task-specific dexterity with cross-task generalization.
> - Information-theoretic regularization (Information Bottleneck) and contrastive learning for task embeddings are crucial for learning stable, shared, and discriminative representations that enable robust multi-task VLA fine-tuning.
