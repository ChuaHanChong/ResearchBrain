# Algebraic Consistency Alone Does Not Certify Temporal Structure in Latent Action Models

> [!summary] Summary
> This paper is a negative-result audit showing that low additivity and reversibility errors in latent action models do not certify that the codes captured temporal structure. Reconstruction alone pushes codes toward a difference of state features, which satisfies both identities for any frame pairing. Proofs, a destroyed-pairing retraining control across five video domains, decoder-family sweeps, and LIBERO policy tests confirm the certificate is uninformative.

## Problem

- Recent latent action models impose additive composition and antisymmetric reversal, then read order-of-magnitude error reductions as label-free proof of captured temporal structure.
- Prior degeneracy guards target magnitude collapse or constant encoders, so they miss a difference-of-features solution that keeps scale, reconstructs well, and satisfies both identities.
- No method reporting these errors destroys its pretraining temporal pairing as a control, trains against violating negatives, or corrects folds against a trained architecture-matched counterpart.

## Method

- An analytical diagnosis with two propositions: feature-space reconstruction bounds the ==additivity residual== by three times the per-pair error regardless of frame order, and ==reversibility== is a functional of the encoder alone.
- A **destroyed-pairing control** via ==successor swapping==, replacing each post-state with a magnitude-matched one from the same recording while holding pre-state fixed, then retraining every arm from scratch.
- A validation protocol plus repair test: baseline-corrected folds against untrained and trained anchors, a ==violation-contrastive hinge loss== demanding the algebra fail on destroyed pairings, a ==two-level ridge action probe==, and seed-budget analysis.

## Results

- A trained unconstrained model already achieves **83-97%** of the reduction against the untrained anchor; the constraint's share of total reduction is only **2.5-17.1%** across five domains.
- Retraining on destroyed pairings raises constrained additivity by **9-37%** yet stays at **0.010-0.041**, below every unconstrained real-pair value; folds range **3.9x** additive versus **32.9x** source-conditioned.
- On LIBERO-SPATIAL destroying the pairing raises constrained success by **0.054** in all thirteen seeds; code action decodability falls from **0.49** unconstrained to **0.22** for constraint plus anchoring.

## Takeaways

> [!tip] Key Insights
> - Any self-consistency metric satisfied identically by a difference-of-features solution cannot distinguish learned structure from a coordinate convention or nuisance state.
> - Report folds against a trained, architecture-matched counterpart: raw ratios against untrained anchors mostly measure how badly an unconstrained architecture violates an untrained identity.
> - Destroying the label or pairing a metric claims to reflect, then retraining, is a cheap decisive control; three-seed budgets flipped a four-point effect's sign.

## Detailed Report

### 1. Overview

Robot manipulation policies need costly action-labelled demonstrations, while action-free video is plentiful. Latent action models try to bridge that gap. They encode a pair of frames as a code for their transition, then use those codes to pretrain a policy. Algebraically regularized versions add two requirements: codes for consecutive changes should add up to the code for the longer change, and reversing a transition should undo it. This paper argues that a low algebraic error shows only that the code satisfies those identities. On its own, it does not show that the code captured which frame followed which, or that it carries useful action information. The strongest check destroys the successor pairing and retrains the constrained model. Its error still beats an unconstrained model trained on real pairings in all five tested source domains.

(a) Adding short transitions compared with the direct long transition. (b) Normalized additivity error for five domains, where the unconstrained real-pair reference is 1.0. Constrained models with destroyed pairing (red) score higher than constrained models with real pairing (black), but stay below 1.0.

### 2. A difference can pass the test

Reconstruction can push a decoded transition toward a difference: the feature for the target frame minus the feature for the source frame. Differences telescope. The transition from *a* to *c* is approximately the transition from *a* to *b* plus the transition from *b* to *c*, because the intermediate feature cancels. Reversing the endpoints changes the sign. Those relations hold even when the frames are not true temporal successors.

Composition is valid. Its limitation is that composition alone cannot establish temporal succession, or distinguish action-relevant change from nuisance change. A low error measures algebraic fit.

The reported additivity error compares two quantities: the direct *a→c* code, and the sum of the *a→b* and *b→c* codes. The discrepancy is divided by the norm of the direct transition. Experiments report the median per-triple normalized error, averaged over seeds.

The choice of baseline matters. In CaptainCook4D, for additivity, the trained unconstrained model's median normalized error is 0.084 and the constrained model's is 0.015. That is a 5.6× reduction against the trained counterpart, versus 69.3× against an untrained anchor. The constraint accounts for 6.7% of the total reduction from that anchor in this comparison. Across five domains, the unconstrained trained counterpart already accounts for 83–97% of the reduction against an untrained anchor.

### 3. Destroy the pairing, then retrain

[[2605.10819|ALAM]] reports 25–85× reductions in algebraic-probe errors, and those ratios are already measured against a trained unconstrained counterpart. The control that ALAM and the other cited methods had not run is to retrain after destroying the temporal pairing.

The control works within each recording. Each successor is replaced with a different post-state from the same recording, approximately matching feature-displacement magnitude. The source and data split stay fixed, and the original successor is never retained. The arms are then retrained from scratch, rather than scoring one fixed model on altered triples. The five domains are CaptainCook4D, HoloAssist, Assembly101, IMPACT, and CholecT50, all using frozen V-JEPA 2.1 features.

Under the constraint, additivity error rises by 9–37% across the domains. It remains below the unconstrained real-pair error in each case. This result does not show that destroying pairing helps learning. It shows that this low-error level can be reached without the original successor relation.

The scope is specific. The control targets the successor relation regularized by ALAM. It does not cover AC-LAM's same-scene, not-necessarily-successive triples.

### 4. What the result covers

The contribution is a diagnosis, not a verdict on latent-action methods. The exact reconstruction argument concerns decoded transitions of the additive form. A bound on the codes themselves additionally requires a linear decoder. For source-conditioned and quantized alternatives, the diagnosis is empirical. The policy experiment is a separate, self-contained LIBERO pipeline, not a direct transfer of a released system.

The authors recommend three checks: compare against a trained, architecture-matched baseline; retrain on destroyed pairings; and run a seed-budget analysis.
