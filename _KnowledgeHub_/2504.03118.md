# NuWa: Deriving Lightweight Task-Specific Vision Transformers for Edge Devices

> [!summary] Summary
> Researchers from Huazhong University of Science and Technology and Australian universities introduce NuWa, a framework that derives lightweight task-specific Vision Transformers from pre-trained models through dimension-specific structured pruning, achieving superior accuracy while enabling deployment on edge devices with significant inference speedups on both GPU and CPU platforms.

## Problem

- Standard Vision Transformers are too computationally expensive and memory-intensive for edge devices
- Pre-trained ViTs contain redundant knowledge irrelevant to specific edge tasks, reducing efficiency and accuracy

## Method

- Two-stage ==pruning== approach combining one-shot pruning for depth, classifier size, and attention heads
- Adaptive pruning strategy for query-key size, value size, expansion size, and embedding dimensions using SVD-based techniques
- Iterative fine-tuning process to recover performance after pruning

## Results

- Outperforms baseline pruning methods (Random Pruning, X-Pruner, NViT) on various sub-tasks
- Achieves significant inference speedups on both GPU and CPU platforms
- Demonstrates improved attention focus on task-relevant features through visualization
- Maintains high accuracy while reducing model size through structured pruning

## Takeaways

> [!tip] Key Insights
> - Dimension-specific pruning strategies are more effective than uniform compression
> - SVD-based decomposition helps preserve important knowledge during pruning
> - Task-specific derivation enables better resource utilization than generic compression
