# Perceiver-Actor: A Multi-Task Transformer for Robotic Manipulation

> [!summary] Summary
> PERCEIVER-ACTOR (PERACT) is a language-conditioned behavior-cloning agent for multi-task 6-DoF robotic manipulation that reformulates the problem as detecting the next best voxel action. The approach leverages a Perceiver Transformer on a voxelized observation space, enabling robust performance across 18 simulated and 7 real-world tasks with only a few demonstrations per task.

## Problem

- Robotic manipulation tasks require precise 6-DoF control, which is challenging to learn end-to-end due to high data costs and scarcity.
- Existing end-to-end deep learning methods for robotics (e.g., image-to-action) are highly data-inefficient, often requiring vast datasets that are impractical to collect.
- Traditional object-centric methods struggle with novel or deformable objects, while prior 3D ConvNet approaches for robot control lack a global receptive field for holistic scene understanding.

## Method

- **PERACT** frames 6-DoF manipulation as a classification task by discretizing actions into ==next best voxel action== predictions, operating on extracted ==keyframe actions==.
- It utilizes a ==Perceiver Transformer== to efficiently process high-dimensional multi-view RGB-D inputs fused into a 100x100x100 ==voxel grid==, conditioned on natural language goals via a ==CLIP encoder==.
- Actions (translation, rotation, gripper state, collision avoidance) are predicted from per-voxel features and global pooled features using ==argmax Q-functions==, trained via ==supervised behavior cloning==.

## Results

- PERCEIVER-ACTOR (PERACT) achieved up to a **34x** improvement in success rates over image-to-action baselines and outperformed 3D ConvNet baselines (C2FARM-BC) by **1.33x** to **2.83x** on simulated tasks.
- The system demonstrated high data efficiency, successfully training a multi-task agent on 7 diverse real-world tasks using only **53** total demonstrations, or a few demonstrations per task.
- Ablation studies confirmed the critical role of language conditioning, the Perceiver Transformer's architecture, and accurate keyframe extraction for the agent's performance.

## Takeaways

> [!tip] Key Insights
> - Formulating robotic manipulation as a 3D voxel-based classification task for "next best voxel action" allows Transformers to operate efficiently with limited data.
> - The Perceiver Transformer's global receptive field on voxelized inputs is crucial for holistic scene understanding, outperforming methods with local receptive fields like 3D ConvNets.
> - Integrating strong 3D structural priors (voxelization) and extracting bottleneck keyframe actions are essential for achieving data-efficient 6-DoF multi-task learning.
