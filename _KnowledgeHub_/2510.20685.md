# C-NAV: Towards Self-Evolving Continual Object Navigation in Open World

> [!summary] Summary
> Researchers at Beihang University and the Chinese Academy of Sciences introduced C-Nav, a framework for continual object navigation, along with the first comprehensive benchmark for this task. C-Nav enables embodied agents to learn new object categories without catastrophic forgetting, improving average success rate over Data Replay by 3.35% on MP3D and achieving up to a 9.7 percentage point higher old-task success rate on HM3D, while utilizing adaptive experience selection for memory efficiency.

## Problem

- Existing object navigation agents operate under static conditions, unable to adapt to dynamic, open-world environments with new object categories, and learning new navigation skills causes 'catastrophic forgetting' of previously acquired knowledge.
- There was no standardized benchmark for evaluating continual learning in multi-modal, long-horizon object navigation tasks.
- Naive data replay for continual learning incurs significant memory overhead and privacy concerns due to storing entire long-horizon trajectories.

## Method

- Developed a new 'continual object navigation benchmark' to systematically evaluate agent performance across sequential tasks with disjoint object categories.
- Proposed **C-Nav**, a continual visual navigation framework, featuring a ==Dual-Path Anti-Forgetting== mechanism to mitigate ==representational drift== and ==policy degradation==.
- Implemented an ==Adaptive Experience Selection== module using the ==Local Outlier Factor (LOF)== algorithm to identify and store only semantically meaningful ==keyframes== from trajectories.

## Results

- C-Nav consistently outperformed baseline continual learning methods, achieving an average **3.35%** SR improvement on MP3D and **2.75%** on HM3D compared to Data Replay, with lower storage costs.
- The framework demonstrated a superior balance between stability and plasticity, achieving a **9.7 percentage point** higher old-task success rate than Data Replay on HM3D in the final stage (**42.61%** vs **32.9%**).
- Adaptive experience selection outperformed uniform sampling and achieved comparable performance to full-length feature replay with only marginal SR drops (**1.3-1.9%**) despite using half the data, demonstrating high memory efficiency.

## Takeaways

> [!tip] Key Insights
> - Catastrophic forgetting in object navigation arises from both representation drift in the multimodal encoder and policy degradation in the action decoder, requiring a dual-path mitigation strategy.
> - Maintaining consistency between frozen previous encoder features and current encoder outputs (feature distillation) is critical for preserving multi-modal alignment.
> - Replaying only salient keyframes, identified as outliers in the feature space, significantly reduces memory overhead and data redundancy compared to storing full trajectories while maintaining high performance.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Embodied artificial intelligence, particularly the task of object-goal navigation, is a significant area of research aimed at developing agents capable of autonomous interaction within physical environments. Current state-of-the-art methods in object navigation typically rely on large-scale datasets and pre-trained models, operating under the assumption of a fixed set of object categories and static training trajectories. These approaches often exhibit robust performance in predefined environments but face considerable challenges when deployed in dynamic, open-world settings.

A primary limitation of existing methods is their vulnerability to "catastrophic forgetting," a phenomenon in machine learning where a model loses previously acquired knowledge upon learning new tasks. While continual learning (also known as incremental or lifelong learning) has seen advancements in uni-modal settings such as image classification, its application to complex embodied decision-making tasks, especially long-horizon object-goal navigation with diverse multi-modal inputs, remains largely unexplored. Embodied navigation requires processing rich sensory data (RGB, depth, pose) and textual instructions over extended sequences of actions, which significantly increases the complexity of knowledge retention and adaptation.

Some related work includes "zero-shot object navigation" methods, which use Vision-Language Models (VLMs) or Large Language Models (LLMs) for reasoning without updating model parameters. While these approaches avoid forgetting and offer generalization, they often depend on intricate reasoning pipelines and manually designed rules, limiting task-specific adaptation and leading to suboptimal performance in novel or complex environments. Conversely, methods that fine-tune pre-trained visual encoders and navigation policies via imitation or reinforcement learning offer strong performance but inherently lack continual learning capabilities and are susceptible to forgetting.

This paper addresses this gap by introducing the continual object navigation problem, where agents must learn new object categories incrementally without forgetting prior navigation skills. It tackles the specific challenges posed by long-horizon, multi-modal tasks, which existing continual learning techniques for image classification or other uni-modal tasks do not adequately cover. The work establishes a benchmark and proposes a novel framework to enable embodied agents to continually adapt to evolving scenarios, a capability deemed essential for practical, real-world deployments.

### 2. Key Objectives and Motivation

The primary objective of this research is to enable embodied agents to perform continual object navigation in dynamic, open-world environments. This overarching goal is motivated by several identified limitations of existing navigation systems and real-world requirements:

1. **Addressing Catastrophic Forgetting:** Traditional object navigation methods are designed for static environments and fixed object categories. When confronted with new object categories or evolving tasks, these models often suffer from catastrophic forgetting, where the acquisition of new skills leads to the degradation or loss of previously learned navigation abilities. This limitation makes them unsuitable for continuous deployment where adaptation is necessary.
2. **Enabling Continual Adaptation:** Practical embodied agents must incrementally refine their navigation capabilities by learning from new data without requiring a complete retraining of the model from scratch or revisiting all historical data. This necessitates mechanisms for robust knowledge retention and efficient skill acquisition for novel objects and instructions.
3. **Managing Multi-modal and Long-horizon Challenges:** Object navigation is a complex task involving long-horizon decision-making and the integration of diverse multi-modal inputs, including RGB images, depth images, pose information, and textual instructions. These characteristics distinguish it from simpler uni-modal continual learning problems, introducing challenges such as "representation drift" in multi-modal encoders and "policy degradation" in action decoders as the agent encounters new data distributions.
4. **Overcoming Data Replay Limitations:** While naive data replay has shown promise in mitigating catastrophic forgetting, its direct application to navigation tasks is problematic. Long sequences of temporally and spatially correlated observations lead to significant storage overhead, privacy concerns related to retaining continuous scene observations, and inefficient memory usage due to high redundancy in adjacent frames.
5. **Establishing a Standardized Evaluation Benchmark:** The lack of a dedicated benchmark for continual object navigation hinders systematic evaluation and advancement in this under-explored area. A clear benchmark is needed to assess the continual learning capabilities of various navigation models and techniques.

To address these motivations, the paper sets out to achieve the following key objectives:

- **Establish a Continual Object Navigation Benchmark:** Create a comprehensive evaluation framework using the HM3D and MP3D datasets within the Habitat simulator, designed to assess continual learning capabilities across various mainstream navigation model architectures and continual learning techniques.
- **Propose C-Nav, a Continual Visual Navigation Framework:** Develop a novel framework that integrates a dual-path anti-forgetting mechanism. This mechanism aims to maintain representation consistency across multi-modal encoders via feature distillation and preserve policy stability within the action decoder through feature replay, specifically designed to avoid the extensive storage of raw trajectories.
- **Develop an Adaptive Experience Selection Module:** Introduce a strategy to identify and retain diverse and informative experiences (keyframes) from navigation trajectories. This module aims to reduce redundancy and minimize memory overhead by treating keyframe selection as an outlier detection problem in the learned representation space.

### 3. Methodology and Approach

The research introduces a framework called C-Nav to address continual object navigation, a task defined by sequential learning of navigation skills for new object categories while retaining proficiency for previously learned ones.

#### 3.1. Problem Definition and Benchmark Setting

- **Continual-ObjectNav:** The agent sequentially learns across *K* tasks, where each task *k* introduces a distinct, disjoint set of goal object categories (*C_k*). Training data *D_k* consists of 3D indoor environments, target object categories, and expert demonstration trajectories. Observations (*o_t*) integrate egocentric RGB-D sensing, agent pose, action history, and object name. Actions (*a_t*) are selected from a discrete space (move\_forward, turn\_left, turn\_right, look\_up, look\_down, stop).
- **Evaluation:** Performance is assessed after each stage *k* on unseen environments using target objects from the cumulative category set (*C_1:k*). Metrics include Success Rate (SR) and Success weighted by Path Length (SPL).
- **Model Architecture:** The agent policy is composed of a multimodal encoder *f* (mapping observations to feature representations *h_t*) and an action decoder *π* (predicting actions based on current and historical features).
- **Datasets:** HM3D and MP3D datasets are used, with object categories and trajectories split into four incremental learning stages. HM3D covers 6 categories and MP3D covers 21, with varying trajectory counts per stage.

#### 3.2. The Proposed Method: C-Nav

C-Nav incorporates two main components to mitigate catastrophic forgetting and enhance efficiency.

#### 3.2.1. Dual-Path Anti-Forgetting

This strategy constrains both the feature extraction (encoder) and policy prediction (decoder) stages to prevent catastrophic forgetting.

- **Representation Consistency with Feature Distillation (L_KD):** To prevent representational drift in the multimodal encoder, feature-level distillation is applied. An ℓ2 distance loss is minimized between the features extracted by the *frozen* encoder from the previous task (*f_k-1*) and the *current* encoder (*f_k*) for a given observation *o_t*. This ensures multi-modal alignment across tasks.
- **Policy Consistency with Feature Replay (L_FR):** To mitigate policy forgetting, a feature buffer stores trajectory features and their corresponding action labels from previous tasks. During training, these are replayed, and a cross-entropy loss is applied between the current action decoder's predictions (*π_k*) and the stored expert actions. A weighting factor *w_t* emphasizes action transitions (where *a_t* differs from *a_t-1*), promoting stability in decision-making.

#### 3.2.2. Adaptive Experience Selection

This module addresses the memory overhead and redundancy of storing full trajectories by selecting only semantically significant keyframes.

- **Outlier Detection in Feature Space:** Keyframe selection is reframed as an outlier detection problem within the visual feature space. Given a trajectory, visual observations are first encoded into feature representations using a pre-trained CLIP model.
- **Local Outlier Factor (LOF):** The Local Outlier Factor algorithm is employed. LOF quantifies how isolated an observation is relative to its neighbors. Frames with a higher LOF score (LOF_k(v_i) > 1) are identified as outliers, indicating significant semantic shifts (e.g., entering new spaces, approaching targets).
- **Feature Buffer Storage:** Instead of raw frames, the *features* of these selected keyframes (encoded by the current multimodal encoder *f_k*) are stored in a feature buffer for subsequent replay. This reduces storage and avoids privacy concerns associated with raw visual data.

#### 3.2.3. Overall Learning Objective

C-Nav's policy is optimized using a composite loss function:
*L* = *L_Curr* + *λ_KD* ⋅ *L_KD* + *λ_FR* ⋅ *L_FR*
where *L_Curr* is the behavior cloning loss for the current task (with inflection weighting), and *λ_KD* and *λ_FR* are weighting coefficients for the feature distillation and feature replay losses, respectively.

#### 3.3. Experimental Setup

- **Multi-modal Encoder:** Consists of a frozen CLIP-ResNet50 for RGB and a PointNav-pretrained ResNet-50 for depth. Linear projection layers transform inputs (RGB, depth, pose, previous action, object name) into feature vectors, which are then concatenated.
- **Optimization:** AdamW optimizer with a linear warmup and decay learning rate schedule.
- **Action Decoders:** Evaluated across four types: RNN-based (2-layer LSTM), Transformer-based (4-layer transformer), Bev-based (4-layer transformer), and LLM-based (Qwen2-0.5B).
- **Hyperparameters:** Inflection weight γ = 3.48; loss balance weights λ_KD = 5, λ_FP = 5.
- **Comparison Methods:** Naive Fine-tuning, LoRA (low-rank adaptation), LwF (learning without forgetting), Model Merge (linear interpolation of weights), and Data Replay (storing *p*=80 original trajectories per category). C-Nav stores *p*=80 trajectory *features* and samples 50% of each trajectory adaptively.

### 4. Main Findings and Results

The experiments conducted across the HM3D and MP3D datasets, utilizing various model architectures, demonstrate the performance and effectiveness of C-Nav.

- **Baseline Performance and Catastrophic Forgetting:** Naive fine-tuning consistently resulted in severe catastrophic forgetting across all four architectures (RNN-based, Transformer-based, Bev-based, LLM-based), showing an average decline of approximately 40% in navigation success rate on previously learned categories by the final stage. LwF demonstrated limited effectiveness. LoRA and model merge provided some mitigation of forgetting but did not fully address the problem. Data replay, while effective in retaining knowledge, incurred substantial storage overhead.
- **C-Nav's Superiority:** C-Nav consistently outperformed existing methods. Compared to data replay (which stores raw trajectories), C-Nav achieved an average SR improvement of 3.35% on MP3D and 2.75% on HM3D across the four architectures, while simultaneously requiring lower storage costs due to its adaptive feature selection. The Bev-based architecture consistently showed higher performance compared to others, with LLM-based models not demonstrating a clear advantage, possibly due to limited training data.
- **Stability-Plasticity Balance:** C-Nav exhibited a superior trade-off between retaining old knowledge (stability) and acquiring new skills (plasticity). Specifically, on the HM3D dataset, C-Nav achieved a 42.61% SR on old tasks in Stage 4, which was 9.7 percentage points higher than the best baseline (Data Replay at 32.9%). Its new-task performance was competitive, showing that C-Nav effectively learned new navigation tasks without significantly sacrificing prior capabilities.
- **Ablation Studies on Dual-Path Anti-forgetting:**
 - Removing the feature-space knowledge distillation (KD) component led to a significant average SR drop of 22% on HM3D and 16% on MP3D across architectures.
 - Removing the feature replay (FR) component resulted in an average SR reduction of 12% on HM3D and 10% on MP3D.
 - These results indicate the complementary roles of the two paths: KD stabilizes representation learning by ensuring consistency in the multi-modal encoder, while FR maintains consistent decision-making within the action decoder under distributional shifts.
 - Further analysis showed that selectively fine-tuning modality-specific projectors within the encoder, coupled with consistency regularization, was more effective than fully freezing the entire multimodal encoder, as full freezing hindered adaptability to new task semantics.
- **Ablation Studies on Adaptive Experience Selection:**
 - C-Nav's adaptive sampling consistently outperformed uniform sampling, achieving SR improvements of 3.65% on HM3D and 3.2% on MP3D when replaying half the trajectory data.
 - When compared to C-Nav using full-length feature replay, adaptive sampling with half the data showed only marginal SR drops (1.9% on HM3D and 1.3% on MP3D), demonstrating its efficiency.
 - Notably, adaptive sampling with half the data improved average SR by 0.8% on HM3D and 2.0% on MP3D compared to full data replay, indicating that selecting informative features is more beneficial than replaying all available features. The method also maintained strong performance at very low retention rates (e.g., 20% memory usage).
- **Comparison with Zero-Shot Method (VLFM):** VLFM, a zero-shot baseline, avoided catastrophic forgetting due to its frozen parameters, but its performance was limited by its inability to learn from new trajectories. C-Nav, as an end-to-end trainable system, continually improved and adapted from experience.
- **Robustness to Stage Order:** C-Nav exhibited minimal performance variation across different task sequences, confirming the robustness of its Dual-Path Anti-Forgetting mechanism to the order in which object categories are encountered.
- **Qualitative Analysis:** A case study demonstrated that while a fine-tuning baseline suffered catastrophic forgetting and misidentified the target, C-Nav successfully navigated to the correct, previously learned object, highlighting its knowledge retention.

### 5. Significance and Potential Impact

This research contributes to the field of embodied AI by addressing a fundamental challenge in robotic navigation: continual learning in dynamic, open-world environments. Its significance and potential impact can be summarized as follows:

- **Advancing Embodied Continual Learning:** The work introduces and formalizes the continual object navigation problem, an area previously underexplored despite its practical importance. By establishing a dedicated benchmark, it provides a standardized framework for evaluating and comparing future continual learning solutions in embodied decision-making. This framework is crucial for fostering further research in robust, adaptive agents.
- **Mitigating Catastrophic Forgetting in Complex Tasks:** C-Nav offers a novel and effective solution to catastrophic forgetting in multi-modal, long-horizon object navigation. The dual-path anti-forgetting mechanism, combining feature distillation for representation consistency and feature replay for policy stability, directly addresses the challenges of distributional shifts in both encoder and decoder components. This is a significant technical advancement for a task requiring the integration of diverse sensory inputs and sequential decision-making.
- **Enhancing Efficiency and Practicality:** The adaptive experience selection module, which leverages outlier detection in feature space (LOF) to identify and store only semantically meaningful keyframes, substantially reduces memory overhead and computational redundancy. This efficiency makes continual learning more scalable and practical for real-world deployment, where storage and processing resources are often constrained, and privacy concerns related to raw data retention are relevant.
- **Broad Applicability and Robustness:** C-Nav's demonstrated effectiveness across a range of mainstream navigation architectures (RNN-based, Transformer-based, Bev-based, and LLM-based) and datasets (HM3D, MP3D) highlights its generality and robustness. Its insensitivity to the order of learning tasks further underscores its suitability for real-world scenarios where object categories may be introduced arbitrarily.
- **Enabling Adaptive Robotic Systems:** The ability of embodied agents to continually learn new object categories without forgetting prior skills is a prerequisite for autonomy in dynamic environments. C-Nav pushes towards self-evolving agents that can adapt to evolving user instructions and environments without costly retraining or human intervention, paving the way for more capable and versatile household robots, service robots, and other AI-driven systems in complex real-world settings.
- **Future Research Directions:** The paper also identifies limitations, such as the need for validation on physical robots for real-world factors like dynamic lighting and sensor noise, and the linear growth of memory usage with task complexity. These point towards crucial future research avenues, including exploring generative replay or trajectory-free approaches, which could further reduce memory demands and enhance the long-term scalability of continual navigation systems.
