# Legged Robot State Estimation With Invariant Extended Kalman Filter Using Neural Measurement Network

> [!summary] Summary
> KAIST researchers developed a hybrid proprioceptive state estimator for legged robots by integrating a Neural Measurement Network (NMN) with an Invariant Extended Kalman Filter (IEKF). This approach enables accurate state estimation across challenging terrains, including those with foot slippage, by training the NMN exclusively on simulation data with smoothness regularization, eliminating the need for real-world data collection.

## Problem

- Traditional proprioceptive state estimators for legged robots often assume non-slip contacts, which is frequently violated in challenging terrains, leading to inaccurate state estimation.
- Visual-inertial odometry systems can suffer from environmental factors like poor lighting or motion blur, limiting their reliability.
- Existing learning-based methods for state estimation typically require extensive and expensive real-world data collection for training, posing a practical barrier.

## Method

- KAIST researchers developed a hybrid proprioceptive state estimator that integrates a **Neural Measurement Network (NMN)** with an **Invariant Extended Kalman Filter (IEKF)**.
- The **NMN**, a ==GRU-MLP== network, is trained exclusively on simulation data to learn measurement models for body linear velocity and contact probabilities from proprioceptive sensor inputs.
- The **IEKF** fuses the robot's dynamics model and IMU data with the learned velocity and contact probability measurements from the NMN, leveraging ==Lie groups== for state representation.

## Results

- The proposed NMN-IEKF approach significantly outperforms a baseline IEKF with ground truth contact, especially on challenging terrains like debris, soft ground, and slippery surfaces.
- Experiments demonstrated robust performance, with the method maintaining accurate state estimates where baseline methods showed significant drift in position, particularly in the z-axis.
- Smoothness regularization during NMN training substantially reduced velocity estimation error and improved the consistency and accuracy of contact probability predictions in real-world deployment.

## Takeaways

> [!tip] Key Insights
> - Combining model-based filtering (IEKF) with a learning-based approach (NMN) yields superior state estimation for legged robots.
> - The Neural Measurement Network (NMN) can be effectively trained using only simulation data, provided appropriate regularization techniques like smoothness loss are applied to bridge the sim-to-real gap.
> - Learning and incorporating contact probabilities and body linear velocity into the state estimator significantly improves performance on challenging terrains with foot slippage.

## Detailed Report

### 1. Introduction

Accurate state estimation is a fundamental requirement for legged robots to navigate diverse environments successfully. Researchers from the Korea Advanced Institute of Science and Technology (KAIST) have developed a novel approach that combines a Neural Measurement Network (NMN) with an Invariant Extended Kalman Filter (IEKF) to achieve robust proprioceptive state estimation for legged robots.

The key innovation of this work lies in using a neural network to learn body linear velocity and contact probabilities from proprioceptive sensor data, which are then integrated as measurement updates in an IEKF framework. Notably, the neural network is trained exclusively on simulation data, eliminating the need for expensive real-world data collection while still achieving robust performance in real-world environments.

### 2. Background and Challenges

State estimation for legged robots presents unique challenges due to their complex dynamics and intermittent contact with the environment. Traditional approaches typically rely on:

1. **Visual-inertial odometry systems** - These can suffer from environmental factors like poor lighting or motion blur.
2. **Proprioceptive state estimators** - Often assume non-slip contacts, which is frequently violated in challenging terrains.
3. **Learning-based methods** - Typically require extensive real-world data for training.

The primary challenges addressed in this research include:

- Achieving accurate state estimation in challenging terrains with foot slippage
- Overcoming the sim-to-real gap when training on simulation data
- Developing a proprioceptive state estimator that doesn't rely on perfect contact assumptions

### 3. Neural Measurement Network Approach

The authors propose using a neural network to learn measurement models for body linear velocity and contact probabilities, which are integrated into an IEKF framework. This hybrid approach combines the benefits of model-based filtering with the learning capabilities of neural networks.

#### 3.1. State Representation

The robot state is represented using Lie groups to leverage the benefits of the IEKF framework. The state includes:

- Robot orientation: $\mathbf{R}_t \in SO(3)$
- Robot position: $\mathbf{p}_t \in \mathbb{R}^3$
- Robot linear velocity: $\mathbf{v}_t \in \mathbb{R}^3$
- Contact point locations: $\mathbf{p}_{c,t} \in \mathbb{R}^3$

#### 3.2. System Dynamics

The system dynamics are modeled based on IMU measurements and contact kinematics:

```
Propagation step:
R̂_t = R̂_{t-1} * exp(ω̂_{t-1}Δt)
v̂_t = v̂_{t-1} + (R̂_{t-1}a_{t-1} + g)Δt
p̂_t = p̂_{t-1} + v̂_{t-1}Δt
```

Where $\mathbf{R}$ is orientation, $\mathbf{v}$ is velocity, $\mathbf{p}$ is position, $\mathbf{\omega}$ is angular velocity, $\mathbf{a}$ is linear acceleration, and $\mathbf{g}$ is gravity.

### 4. System Architecture

The complete system consists of:

1. **Neural Measurement Network (NMN)** - A GRU-MLP network that processes proprioceptive sensor data to estimate body linear velocity and contact probabilities.

2. **Invariant Extended Kalman Filter (IEKF)** - Fuses the robot's dynamics model, IMU data, and the learned measurements from the NMN to estimate the robot's state.

The NMN takes proprioceptive measurements as input:
- Joint positions and velocities
- IMU measurements (linear acceleration and angular velocity)
- Previous contact states

It outputs:
- Body linear velocity estimate
- Contact probability for each leg

The IEKF integrates these learned measurements into its update step, providing a more accurate state estimate than would be possible with either component alone.

### 5. Training Methodology

A key contribution of this work is the training methodology that enables effective sim-to-real transfer. The NMN is trained exclusively on simulation data, with several techniques employed to bridge the sim-to-real gap:

1. **Imitation Loss** - The network is trained to imitate ground truth values for body linear velocity and contact states.

2. **Smoothness Regularization** - A smoothness loss function is applied to encourage temporally consistent outputs, which is crucial for reducing the impact of sensor noise and model discrepancies in the real world:

$$L_{smooth} = \frac{1}{T}\sum_{t=1}^{T} \|\mathbf{y}_t - \mathbf{y}_{t-1}\|^2$$

3. **Early Stopping** - Training is stopped before overfitting to simulation-specific details, which helps generalization to real-world data.

4. **Domain Randomization** - The authors experimented with domain randomization but found that, unlike in typical reinforcement learning applications, it sometimes degraded the performance of the state estimator.

The simulation environment uses a pre-trained locomotion policy to generate diverse motion data for different terrains and scenarios, creating a rich dataset for training the NMN.

### 6. Experimental Setup

The proposed method was evaluated on a quadruped robot (Raibo) across four different terrains:

The experiments tested the robot's state estimation capabilities in:
- Flat terrain (baseline)
- Debris terrain (uneven surfaces with wooden blocks)
- Soft terrain (covered with boric acid powder)
- Slippery surfaces (reduced friction)

The performance was compared against a baseline approach using an IEKF with ground truth contact information. Evaluation metrics included:
- Absolute Trajectory Error (ATE)
- Relative Error (RE)
- Z-axis drift

### 7. Performance Results

The state estimation performance was evaluated across different terrains, with results showing that the proposed NMN-IEKF approach significantly outperforms the baseline, especially in challenging terrains.

Key results include:

1. **Flat Terrain**: Both methods perform well, with the proposed approach showing slightly better z-axis stability.

2. **Debris Terrain**: The NMN-IEKF approach handles the uneven surface much better than the baseline method.

3. **Soft Terrain**: On surfaces with boric acid powder, which causes foot slippage, the proposed method maintains accurate state estimates while the baseline drifts significantly.

4. **Slippery Surfaces**: The proposed approach demonstrates robust performance even when friction is reduced, while the baseline shows substantial z-axis drift.

Similarly, contact probability estimation is more stable and accurate with smoothness regularization.

### 8. Key Findings

The research yielded several important findings:

1. **Hybrid Approach Effectiveness**: Combining model-based filtering (IEKF) with a learning-based approach (NMN) provides superior state estimation performance compared to either method alone.

2. **Simulation-Only Training Viability**: The NMN can be effectively trained using only simulation data, with appropriate regularization techniques to bridge the sim-to-real gap.

3. **Smoothness Regularization Importance**: The smoothness loss function is crucial for reducing the impact of sensor noise and model discrepancies in real-world deployment.

4. **Contact Probability Value**: Learning and incorporating contact probabilities into the state estimator significantly improves performance on challenging terrains with foot slippage.

5. **Domain Randomization Considerations**: Unlike in typical reinforcement learning applications, applying domain randomization during NMN training can sometimes degrade performance for state estimation tasks.

6. **Velocity Estimation Value**: The learned linear velocity measurement model provides particularly valuable information for accurate state estimation.

### 9. Implications and Future Work

This research has several important implications for the field of legged robotics:

1. **Reduced Data Collection Burden**: The successful sim-to-real transfer demonstrated in this work reduces the need for expensive and time-consuming real-world data collection.

2. **Improved Robot Autonomy**: More accurate state estimation enables more capable autonomous navigation of legged robots in complex environments.

3. **Generalization Potential**: The approach provides a framework that could be extended to other types of robots and state estimation problems.

Future work directions might include:

1. Integrating exteroceptive sensors (cameras, LiDAR) with the proprioceptive estimation framework for enhanced performance.

2. Extending the approach to include full body state estimation, including angular velocity and joint states.

3. Developing adaptive estimation techniques that can dynamically adjust to different terrain types and robot behaviors.

4. Exploring the use of more advanced neural network architectures to further improve estimation accuracy.

The NMN-IEKF approach represents a significant step forward in legged robot state estimation, combining the strengths of model-based and learning-based methods while addressing the practical challenges of real-world deployment.
