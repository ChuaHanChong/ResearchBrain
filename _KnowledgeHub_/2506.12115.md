# Eliciting Reasoning in Language Models with Cognitive Tools

> [!summary] Summary
> Researchers at IBM Research - Zurich and ETH Zurich developed "cognitive tools," a modular agentic framework inspired by cognitive psychology, to elicit advanced reasoning in Large Language Models. This approach enhanced LLM performance on mathematical reasoning benchmarks, with GPT-4.1 augmented by these tools achieving 53.0% accuracy on AIME 2024, surpassing the 44.6% of the RL-trained o1-preview model.

## Problem

- The precise mechanisms and origins of advanced reasoning in LLMs, particularly in closed models, remained opaque.
- Existing structured reasoning approaches like "cognitive prompting" lacked explicit modularity, potentially leading to interference and limiting flexible operation sequencing.
- There was an ongoing debate on whether LLM reasoning capabilities are primarily inherent (latent) or largely instilled through post-training methods like Reinforcement Learning from Human Feedback (RLHF).

## Method

- The authors developed "cognitive tools," a set of ==modular functions== encapsulating specific reasoning operations (e.g., understand question, recall related, examine answer, backtracking) within an agentic tool-calling framework.
- These tools are executed internally by the LLM itself in a sandboxed context, with structured intermediate results fed back to the main LLM to guide further reasoning.
- The framework allows the LLM to autonomously and flexibly select and orchestrate cognitive operations as needed, fostering adaptive problem-solving without additional model training.

## Results

- Individual cognitive tools consistently improved LLM performance on the Smolbenchmark dataset, with the "understand question" tool yielding up to a +**26.7%** accuracy increase for Llama3.3-**70B** Instruct.
- The full cognitive tools pipeline consistently enhanced pass@1 accuracy across various open-weight models (e.g., Qwen2.5, Llama3.1, Llama3.3) and challenging math benchmarks (AIME 2024, MATH500, AMC), with Qwen2.5-**32B** Instruct's AIME 2024 accuracy increasing from **17.2%** to **32.1%**.
- GPT-4.1 augmented with cognitive tools achieved **53.0%** pass@1 accuracy on AIME 2024, outperforming its baseline (**32.0%**) and surpassing the **44.6%** achieved by the RL-trained o1-preview model.

## Takeaways

> [!tip] Key Insights
> - LLMs possess strong latent reasoning capabilities that can be elicited through structured, modular cognitive operations, suggesting that pre-training instills foundational reasoning abilities.
> - Modularity and compartmentalization in reasoning workflows, as implemented by cognitive tools, consistently outperform monolithic, predefined prompting approaches like cognitive prompting.
> - Integrating principles from cognitive architectures with modern agentic tool-calling frameworks can enhance LLMs' intrinsic reasoning capabilities by extending the tool-calling paradigm to internal cognitive operations.
