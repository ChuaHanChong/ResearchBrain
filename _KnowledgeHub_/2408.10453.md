# Kubrick: Multimodal Agent Collaborations for Synthetic Video Generation

> [!summary] Summary
> The "Kubrick" framework introduces a multi-agent system that collaborates with the Blender 3D engine to generate high-fidelity synthetic videos from natural language descriptions. It produces videos with enhanced physical correctness, precise camera control, and strong temporal consistency, surpassing purely generative models in visual quality.

## Problem

- Existing end-to-end AI video generation models often produce videos lacking physical motion accuracy, realistic lighting, precise camera control, and temporal consistency.
- Traditional CGI production offers high visual fidelity but is a labor-intensive, expert-dependent process that limits accessibility and scalability.
- Automating high-quality synthetic video creation from text, while maintaining physical accuracy, remains a challenge.

## Method

- A multi-agent framework orchestrates video generation using ==Blender==, featuring an LLM-Director to decompose user prompts into sub-processes (scene, character, motion, lighting, cinematography).
- An LLM-Programmer generates Python-based Blender script snippets for each sub-process, leveraging a function library.
- A VLM-Reviewer provides an iterative visual feedback loop, evaluating rendered intermediate outputs against descriptions and suggesting refinements.
- Retrieval-Augmented Generation (RAG) enhances all agents with specialized knowledge from Blender API documentation and tutorials, improving script correctness and reducing iteration count.

## Results

- "Kubrick" achieved the lowest Frechet Video Distance (FVD) of 2691.44 and Frechet Inception Distance (FID) of 245.43, indicating higher visual quality and fidelity compared to seven state-of-the-art baselines.
- The framework demonstrated superior prompt following with a CLIP Similarity (CLIP-SIM) score of 0.2155 and received higher average scores in user studies across prompt following, character motion stability, camera motion quality, and overall quality.
- RAG integration reduced the average review iterations from 20.25 to 11.90, and using GPT-4V as the backbone for agents further reduced iterations by an average of 34.79%, showcasing efficiency gains.

## Takeaways

> [!tip] Key Insights
> - Combining advanced LLM/VLM reasoning with a physically-based 3D rendering engine enables the automated creation of videos with superior physical correctness, precise control, and temporal consistency.
> - A multi-agent collaborative structure with iterative visual feedback is effective for decomposing and solving complex, multi-modal content creation tasks.
> - Integrating domain-specific knowledge via RAG significantly improves the efficiency and accuracy of AI agents in generating executable code for specialized software like Blender.
