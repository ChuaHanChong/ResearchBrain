# Safe Continuous-time Multi-Agent Reinforcement Learning via Epigraph Form

> [!summary] Summary
> Researchers at Purdue University developed Epigraph-based PINN Actor-Critic Iteration (EPI), a framework for safe continuous-time multi-agent reinforcement learning. EPI effectively manages state constraints in dynamic environments by transforming discontinuous value functions into a continuous form via an epigraph reformulation, consistently outperforming state-of-the-art safe MARL baselines in both cost reduction and constraint satisfaction.

## Problem

- Existing Multi-Agent Reinforcement Learning (MARL) algorithms primarily operate in discrete-time, limiting their applicability to real-world, high-frequency, or irregular-interval continuous dynamics.
- Current continuous-time MARL (CT-MARL) methods based on Hamilton-Jacobi-Bellman (HJB) equations and Physics-Informed Neural Networks (PINNs) struggle with safety constraints that introduce discontinuities into value functions.
- Safe MARL methods primarily exist for discrete-time settings and do not naturally extend to continuous dynamics without relying on fully known system dynamics.

## Method

- Formulates safe continuous-time multi-agent reinforcement learning as a ==Continuous-Time Constrained== Markov Decision Process (CT-CMDP), explicitly including state-dependent safety constraints.
- Introduces an epigraph reformulation that transforms the CT-CMDP problem, converting potentially discontinuous value functions (due to safety constraints) into a continuous and differentiable form suitable for PINN-based learning.
- Develops Epigraph-based PINN Actor-Critic Iteration (EPI), an actor-critic framework that utilizes an inner-outer optimization scheme and z-independent critic networks for stable learning and real-time execution without expensive root-finding.

## Results

- EPI consistently achieved higher cumulative rewards (lower costs) and significantly lower constraint violation rates across various Safe Multi-Particle Environments (MPE) and Safe Multi-Agent MuJoCo benchmarks, outperforming baselines like MACPO, MAPPO-Lag, SAC-Lag, EPPO, and CBF.
- Ablation studies demonstrated that both the target loss and the value gradient iteration (VGI) loss are crucial for performance in infinite-horizon settings, preventing value function drift and ensuring gradient consistency.
- The epigraph reformulation was empirically shown to be critical for handling discontinuous value functions, with its absence leading to severely mis-scaled value predictions and unstable actions.

## Takeaways

> [!tip] Key Insights
> - The epigraph reformulation effectively converts discontinuous value functions caused by state constraints into a continuous form, making them amenable to approximation by neural networks and HJB PDE solvers.
> - Designing critic networks to be z-independent and employing a revised outer optimization for optimal auxiliary state (z*) computation significantly reduces nonstationary noise during training and eliminates costly root-finding at execution.
> - Combining residual, target, and value gradient iteration (VGI) losses in the critic learning provides robust value function approximation and gradient consistency in infinite-horizon settings.
