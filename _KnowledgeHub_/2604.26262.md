# Semantic Foam: Unifying Spatial and Semantic Scene Decomposition

> [!summary] Summary
> Semantic Foam introduces a 3D scene representation that unifies spatial and semantic decomposition by augmenting Radiant Foam's explicit Voronoi mesh with identity features and spatial regularization. This approach enables direct, post-processing-free interaction and editing of 3D scenes, achieving competitive mIoU in object-level segmentation and maintaining high reconstruction fidelity.

## Problem

- Modern 3D reconstruction methods (e.g., 3DGS, NeRFs) produce unstructured representations (millions of primitives) lacking inherent semantic understanding, hindering interactive applications.
- Challenges exist in consistently propagating 2D semantic labels into 3D, leading to issues like unlabeled object interiors, inconsistent signals, and imprecise boundaries in existing neural field and point-based methods.
- Current semantic segmentation techniques often struggle with non-convex objects or require complex post-processing heuristics, limiting direct manipulation of reconstructed scenes.

## Method

- **Semantic Foam** extends Radiant Foam's ==non-overlapping Voronoi mesh== by associating an ==Identity Encoding feature== with each 3D cell to represent semantic instances.
- Introduces a ==2D Identity Loss== (cross-entropy against DEVA masks) and a ==Total Variation Loss== for spatial smoothness.
- Integrates these losses with photometric and geometry regularization, enabling simultaneous learning of appearance, geometry, and semantics.

## Results

- **Semantic Foam** achieved **0.82 mIoU** on Mip-NeRF360, outperforming baseline Gaussian-based methods.
- Successfully enabled direct object extraction, removal, and insertion with robust handling of non-convex object geometries.
- Reconstruction fidelity (PSNR, SSIM, LPIPS) remained nearly identical to the original Radiant Foam.

## Takeaways

> [!tip] Key Insights
> - Augmenting an explicit volumetric mesh structure, like Radiant Foam's Voronoi diagram, with learnable identity features provides an intrinsic, differentiable framework for unified spatial and semantic scene decomposition.
> - An explicit spatial regularization, such as the Total Variation loss applied to identity features across adjacent Voronoi cells, is crucial for achieving clean, consistent semantic boundaries and complete object interiors in 3D.
> - This unified representation intrinsically supports direct 3D scene editing tasks like object extraction, removal, and insertion without requiring complex post-processing or being limited to convex object shapes.
