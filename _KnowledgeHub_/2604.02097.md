# LatentUM: Unleashing the Potential of Interleaved Cross-Modal Reasoning via a Latent-Space Unified Model

> [!summary] Summary
> Researchers at Shanghai Jiao Tong University, Tsinghua University, and UCSD developed LatentUM, a unified model that integrates visual understanding and generation within a shared semantic latent space, eliminating pixel-space mediation. This approach enhances interleaved cross-modal reasoning for tasks like visual spatial planning and action-conditioned world modeling, achieving state-of-the-art performance on relevant benchmarks.

## Problem

- Existing unified models (UMs) rely on distinct visual representations for understanding and generation, necessitating inefficient and error-prone pixel-space mediation.
- The pixel decoding and re-encoding steps in UMs introduce 'codec bias' and 'cross-modal misalignment,' hindering complex reasoning tasks.
- Current UMs often prioritize pixel-level fidelity over semantic correctness, which is less optimal for reasoning-centric tasks like visual planning and self-reflection.

## Method

- **LatentUM** employs ==Model Behavior Aligned Quantization (MBAQ)== to represent visual information as ==semantic tokens==, ensuring these tokens preserve understanding capabilities.
- A ==Mixture-of-Modal Experts (MoME)== autoregressive Transformer processes interleaved text and visual features within a shared ==self-attention== mechanism, allowing generated visual codes to be reasoned over directly.
- A ==decoupled pixel decoder== is optionally used for pixel-level visualization, ensuring the core model's latent space remains focused on semantics rather than pixel reconstruction.

## Results

- **LatentUM** achieved state-of-the-art on the Visual Spatial Planning (VSP) benchmark, with **0.99** average accuracy for fine-grained step-by-step planning, outperforming previous models like **ThinkMorph** (**0.76**).
- On the GenEval benchmark, **LatentUM** with self-reflection achieved a score of **0.92** (with external reward) and **0.87** (with self-reward), demonstrating enhanced instruction-following for visual generation.
- **LatentUM** demonstrated strong capabilities in action-conditioned world modeling, achieving an Average Trajectory Error (ATE) of **1.34** and Relative Pose Error (RPE) of **0.34** on the RECON dataset, showing competitive performance with specialized navigation models.

## Takeaways

> [!tip] Key Insights
> - Unifying visual representations in a shared semantic latent space and eliminating pixel-space mediation allows for more fluid and efficient interleaved cross-modal reasoning.
> - Optimizing visual quantization to preserve the behavior of a pre-trained Vision-Language Model (MBAQ) effectively retains semantic information for understanding tasks.
> - Self-referential reasoning, where the model processes its own semantically-represented visual outputs, significantly improves instruction-following and generation quality.
