# $\mathcal{D(R,O)}$ Grasp: A Unified Representation of Robot and Object Interaction for Cross-Embodiment Dexterous Grasping

> [!summary] Summary
> This research from the National University of Singapore (NUS) presents D(R, O) Grasp, a framework that employs an "interaction-centric" representation to achieve efficient and generalizable dexterous grasping. The system demonstrates an 87.53% success rate in simulation and 89% in real-world tasks on novel objects, while generating grasps in under one second.

## Problem

- Existing robot-centric grasping methods are fast but lack generalization across different robotic hand embodiments, requiring extensive re-training for each new hand.
- Current object-centric grasping methods generalize well across hands and objects but are computationally slow due to the need for post-prediction optimization steps like inverse kinematics.
- Developing a unified representation that can achieve both broad generalization (across hands and objects) and high efficiency for dexterous grasping remains a significant challenge.

## Method

- Introduces D(R, O) (Distance between Robot and Object), a unified representation as a point-to-point distance matrix between sampled robot hand and object points, encoding their interaction geometry.
- Employs a configuration-invariant pretraining method for the robot encoder, using point-level contrastive learning to teach the network to align features across different robot hand configurations.
- Utilizes a Conditional Variational Autoencoder (CVAE) to predict the D(R, O) matrix, and then efficiently derives final robot joint configurations through multilateration, 6D link pose estimation via SVD, and iterative joint optimization.

## Results

- D(R, O) Grasp achieved an average success rate of 87.53% in simulation across three diverse dexterous hands and 89% in real-world experiments on novel objects with the LEAP Hand.
- The method generates grasps in less than one second in simulation, significantly outperforming optimization-based baselines (e.g., DFC >1800 seconds) and learning-based methods with post-optimization (e.g., GenDexGrasp 14-25 seconds).
- It demonstrated high robustness to partial object point cloud inputs (maintaining high success rates with 50% occlusion) and successfully generated diverse and firm grasps for various objects and desired palm orientations.

## Takeaways

> [!tip] Key Insights
> - An 'interaction-centric' D(R, O) representation, encoding the distance between robot hand and object points, unifies robot-specific details with object geometry for improved generalization.
> - Configuration-invariant pretraining using contrastive learning allows a robot encoder to understand hand articulation consistently, regardless of joint configuration, which is crucial for cross-embodiment transfer.
> - Deriving robot joint configurations from the D(R, O) matrix via multilateration, SVD-based link pose estimation, and efficient optimization provides a fast and robust method for grasp generation.
