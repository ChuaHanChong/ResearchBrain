# RoboHarness: A Memory-Augmented Policy Harness for Vision-Language-Action Model Robustness via In-Context Adaptation

> [!summary] Summary
> RoboHarness is a memory-augmented policy harness that makes frozen vision-language-action policies robust out-of-distribution without fine-tuning. It combines contrastive dual-memory retrieval over past successes and failures, a vision-language orchestrator that attributes failure causes, Model Context Protocol tools that edit visual and linguistic inputs, and offline memory consolidation, yielding an average 56.6% absolute success-rate gain across three backbones.

## Problem

- Scaling-centric VLA foundation models act as stateless controllers, discarding execution history and lacking the long-term memory needed to adapt under out-of-distribution perturbations.
- Retrieval-augmented robot frameworks store only successful demonstrations, a success bias that leaves them without causal attribution to diagnose why a rollout failed.
- Agentic LLM planners reason from a zero-start with rigid tool integration, so they cannot dynamically intervene in the ongoing perception-action stream or correct stale attributions.

## Method

- ==Dual-Memory RAG== splits a memory bank into success and failure partitions, retrieving top-k **CLIP**-embedded exemplars so the orchestrator gets both positive guidance and negative counterfactuals. Retrieval is keyed on `Sim(E(o_t, l_t), ...)` — the initial observation and the instruction, once per task — so the per-entry diagnostic annotation is a stored *field*, never the index.
- An ==attribution-driven vision-language orchestrator== (Qwen3-VL-32B) matches the observation-memory gap to tool descriptions, parameterizes them, and synthesizes a sensory-first chain of interventions.
- Five ==MCP tools== (Paint-to-Action, Eraser, Prompt-Refiner, Chaining-Step, Encore) plus ==offline dual-stage consolidation== that re-diagnoses trajectories and refines stored attributions across tasks. The base VLA policy stays **frozen** throughout — no parameter updates.

## Results

- On LIBERO-PRO with a frozen backbone, success rose from **2.33%** to **57.2%** under layout shifts and from **0.86%** to **55.2%** under semantic task perturbations; average absolute gain across three backbones is **56.6%**.
- On the new LIBERO-RoboHarness suite, Visual Focus went from **1.7%** to **76.9%** and Clutter Removal from **31.8%** to **74.4%**; long-horizon chaining improved **89.1%** absolute.
- Ablations: dual memory cut reasoning turns from **7.40** (no memory) to **1.07**; rich consolidated retrieval reached **60.1%** clutter success versus **48.8%** limited and **19.2%** none.

## Takeaways

> [!tip] Key Insights
> - Failures under distribution shift are often perceptual or linguistic rather than motor, so editing the policy's inputs can recover competence that fine-tuning would otherwise chase.
> - Storing failures alongside successes is what makes retrieval diagnostic; success-only memory still leaves the planner exploring stochastically with high variance.
> - Orchestrator guidance without grounded retrieval was actively harmful, dropping below the plain baseline, so tool-calling agents need good priors before intervening.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Vision-Language-Action (VLA) models represent a paradigm in robotics for end-to-end manipulation, integrating multimodal perception, linguistic grounding, and continuous motor control into unified policies. These models, exemplified by works like $\pi_0$ and OpenVLA, leverage extensive web-scale datasets to enable control by translating visual observations and natural language instructions into low-level motor commands. However, the transition of robotic agents from controlled laboratory settings to open-world environments introduces challenges related to robust in-context adaptation. Existing VLA policies often exhibit limitations in handling out-of-distribution (OOD) scenarios, which encompass variations in object appearance, lighting, and language.

Current approaches to address OOD generalization partially mitigate these issues. Scaling-centric foundation models, while leveraging large datasets for generalization, typically function as stateless controllers. They discard execution history, which limits their long-term memory capabilities essential for OOD adaptation. Retrieval-augmented frameworks, such as RICL and MemER, incorporate past demonstrations from vector databases to condition policy execution. However, these methods primarily focus on successful trajectories, leading to a "success bias" that hinders the diagnosis of failures arising from perceptual discrepancies. Both categories of approaches often treat knowledge as static, allowing initial misattributions to persist across tasks. More recent agentic frameworks, which utilize Large Language Models (LLMs) and Vision-Language Models (VLMs) for planning and tool integration, often operate as zero-start reasoners. They lack dynamic orchestration capabilities to intervene actively in the perception-action stream or possess an experiential memory that evolves with interaction.

RoboHarness positions itself within this landscape by addressing these identified limitations. It aims to provide a unified framework that incorporates long-term memory for accumulating and reusing execution experience, facilitates causal attribution and failure-aware strategic adjustment, enables dynamic orchestration of external tools for active intervention, and includes a self-evolving consolidation mechanism for refining stored experiences. Rather than fine-tuning VLA model parameters, RoboHarness acts as a "policy harness" that augments frozen VLA models with external mechanisms for robust in-context adaptation at query time. This approach contrasts with parameter-heavy fine-tuning methods (e.g., X-VLA) by offering a parameter-efficient, plug-and-play solution. By explicitly learning from both successes and failures through a dual-memory structure and employing dynamic tool-mediated interventions, RoboHarness seeks to bridge the gap between static VLA policies and the requirements for adaptive, robust robotic agents in complex, varied environments.

### 2. Key Objectives and Motivation

The primary objective of this research is to enhance the robustness of existing, frozen Vision-Language-Action (VLA) models when confronted with out-of-distribution (OOD) tasks and environmental variations, without requiring any parameter fine-tuning of the base VLA policies. The authors aim to achieve this by developing a memory-augmented policy harness that facilitates in-context adaptation.

The motivation behind this work stems from several fundamental limitations observed in current VLA models:

1. **Limited Robustness to Out-of-Distribution Conditions:** While VLA models demonstrate proficiency in in-distribution scenarios, their performance degrades significantly when encountering variations in object appearance, lighting, background clutter, or linguistic instructions that were not extensively covered during training. This lack of robustness to perceptual noise and environmental changes limits their deployability in open-world settings.
2. **Absence of Long-Term Memory:** Traditional VLA models often operate as stateless controllers, discarding execution history after each action or task. This prevents them from accumulating and leveraging past experiences—both successes and failures—to inform future decisions and adapt to novel or challenging situations. The inability to recall and apply relevant prior knowledge leads to repeated errors and inefficient learning.
3. **Lack of Causal Failure Attribution:** Existing retrieval-augmented generation (RAG) frameworks in robotics predominantly focus on retrieving successful demonstrations. This "success bias" means they lack mechanisms to diagnose the root causes of failures, distinguish between perceptual ambiguities and planning deviations, or identify patterns to avoid. Without causal attribution, VLA models cannot strategically adjust their approach when problems arise.
4. **Inadequate Dynamic Intervention Capability:** Static VLA policies struggle to adapt to unforeseen circumstances dynamically. While some agentic frameworks offer LLM/VLM-based planning, they often rely on rigid tool integration and lack the flexibility to dynamically orchestrate interventions that can modulate the perception-action stream in real-time. This limits their ability to recover from execution stagnation or unforeseen environmental changes.
5. **Stagnation of Knowledge:** In current systems, stored knowledge and experiences are often static. There is no continuous mechanism to refine or update these experiences based on new observations, which can lead to the persistence of suboptimal attributions or intervention strategies. An adaptive system requires a self-evolving knowledge base.

To address these motivations, RoboHarness is formulated around four core requirements:
- **Long-Term Memory:** To store and reuse past execution experiences.
- **Causal Attribution:** To diagnose failures and enable strategic adjustments.
- **Dynamic Tool Orchestration:** To actively intervene in the perception-action stream using external tools.
- **Self-Evolving Consolidation:** To continuously refine stored experiences and prevent knowledge stagnation.

By fulfilling these requirements, the authors aim to transform frozen VLA policies into more robust and adaptive robotic controllers without incurring the computational cost and data requirements associated with continuous fine-tuning.

### 3. Methodology and Approach

RoboHarness is designed as a memory-augmented policy harness with a decoupled architecture, comprising an Online Execution Workflow for real-time task intervention and an Offline Memory Consolidation Workflow for asynchronous long-term knowledge refinement.

**A. Online Execution Workflow**
This workflow enables robust task-level adaptation through three sequential modules: Dual-Memory Retrieval-Augmented Generation (RAG), an Attribution-Driven Vision-Language Orchestrator, and MCP Intervention.

1. **Dual-Memory RAG:**
 - **Dual-Memory Storage Design:** A memory bank $M$ is constructed with two partitions: $M_{succ}$ for successful interventions (positive guidance) and $M_{fail}$ for failed attempts with attribution signals (negative evidence). Each experience entry $e_i$ is stored in a semi-schema format, including a multimodal embedding ($E_i$), natural language task description ($T_i$), success indicator ($S_i$), diagnostic annotation ($D_i$), keyframe representations ($V_i$), structured scene ($O_i$), and an extensible metadata bundle ($I_i$) for tool-execution parameters.
 - **Similarity-Based Retrieval Strategy:** A pre-trained CLIP encoder projects the current task context (initial observation $o_t$ and instruction $l_t$) into a joint embedding space. The system retrieves the top-k most similar experiences from $M$, forming $H_t$, which includes both success exemplars and failure precedents. This tripartite input ($H_t, o_t, l_t$) serves as grounding for the orchestrator.

2. **Attribution-Driven Vision-Language Orchestrator:**
 - This module, powered by a multimodal large language model (MLLM, specifically Qwen3-VL-32B), performs joint reasoning over observations, instructions, and retrieved memories to diagnose failures and orchestrate interventions.
 - **Semantic Tool Discovery and Intent Alignment:** The orchestrator identifies intervention needs by assessing the gap between the current state ($o_t$) and retrieved prototypes ($H_t$). It then performs zero-shot matching against semantic tool descriptions to select a candidate toolset whose functions align with the diagnosed failure cause.
 - **Knowledge-Augmented Parameterization:** Following tool selection, the orchestrator derives specific execution parameters ($\theta_i$) for each tool. These parameters are determined by characterizing the deviation of $o_t$ and $l_t$ from historical priors $H_t$ across visual, semantic, and temporal dimensions. For example, for a "Paint" tool, parameters like color/texture, material, and target-object-mask are derived.
 - **Chain-of-Intervention Synthesis:** The orchestrator synthesizes the selected and parameterized tools into an ordered intervention chain ($\Phi_{mcp}$). This orchestration follows two principles: Sensory-First (perceptual corrections precede physical recovery) and Logical Dependency (causal interference removal precedes downstream reasoning).

3. **MCP Intervention:**
 - This module executes the intervention chain $\Phi_{mcp}$ using a set of five instantiated Model Context Protocol (MCP) tools, designed for common VLA failures, while maintaining extensibility.
 - **Paint-to-Action (Visual Domain Shift):** Performs non-parametric domain adaptation by modifying the visual input $o_t$. It uses visual overlay or texture replacement, with SAM3 segmentation to target specific regions. This helps mitigate shifts by aligning current perceptions with successful past experiences.
 - **Eraser (Causal Confusion):** Removes irrelevant objects from the visual input $o_t$. The orchestrator identifies distractors based on $o_t$ and $H_t$, SAM3 extracts masks, and OpenCV Telea inpainting removes them prior to policy inference.
 - **Prompt-Refiner (Instruction-Pattern Mismatch):** Refines natural language instructions $l_t$ when their wording or task structure deviates from successful historical patterns in $H_t$. It rewrites colloquial or ambiguous instructions into concise, executable commands (e.g., "Pick up... and place...").
 - **Chaining-Step (Temporal Compounding):** Addresses long-horizon tasks by decomposing a macro sequence of actions into aligned sub-tasks. It assigns temporal bounds and integrates "Reset & Buffer" mechanisms between sub-tasks to mitigate context degradation over long horizons.
 - **Encore (Execution Stagnation):** Resolves deadlocks or execution failures by initiating key-state recovery. Based on failure precedents in $H_t$, it specifies retry bounds and wait times, resets counters, and can roll back the robot state via an averaged reverse trajectory, triggering a "Reset & Retry" if needed.

**B. Offline Memory Consolidation Workflow**
This asynchronous workflow continuously refines the Dual-Memory Bank.

1. **Stage 1: Initial Diagnosis:** Upon task termination, the orchestrator performs an initial diagnosis of the latest trajectory, creating a new experience entry ($e_{new}$), which is then added to the Dual-Memory Bank $M$.
2. **Stage 2: Memory Consolidation:** The system retrieves top-N similar experiences ($E_{sim}$) from $M$. The orchestrator then performs batch-level differential analysis, comparing $e_{new}$ with $E_{sim}$ to correct historical failure descriptions, optimize intervention plans, and update the existing entries. This self-correction loop ensures that the memory base iteratively improves and prevents knowledge stagnation.

Together, these workflows form a closed-loop adaptive system where online interventions are informed by an evolving, dual-partition memory, enabling robust adaptation without parameter updates to the base VLA model.

### 4. Main Findings and Results

The experimental evaluation of RoboHarness was conducted across three backbone VLA models ($\pi_0$, $\pi_{0.5}$, and SmolVLA) on two benchmarks: the standard LIBERO-PRO and a newly proposed LIBERO-RoboHarness suite.

**Overall Performance:**
RoboHarness achieved an average absolute success rate gain of 56.6% across the tested backbone models. This included an absolute improvement of 89.1% in long-horizon task chaining, indicating its effectiveness in complex sequential tasks.

**Results on LIBERO-RoboHarness:**
The LIBERO-RoboHarness suite was designed to evaluate in-context adaptation under five specific OOD challenge dimensions:

- **Environmental and Linguistic Variations:**
 - For `Visual Focus` (selecting a target from identical, novel objects), $\pi_{0.5}$-LIBERO's success rate increased from 1.7% to 76.9% with RoboHarness, demonstrating improved referential grounding.
 - In `Clutter Removal` (grasping targets amidst dense distractors), $\pi_{0.5}$-LIBERO's success rate improved from 31.8% to 74.4%, suggesting that MCP interventions aid in isolating task-relevant objects.
 - For `Noisy Prompt` (intent extraction from colloquial or ill-structured instructions), SmolVLA-LIBERO achieved 98.3% success after instruction refinement by RoboHarness, indicating enhanced linguistic robustness.
- **Execution Stability and Long-Horizon Tasks:**
 - In `Execution Fragility` (critical maneuvers prone to minor slips), RoboHarness elevated success rates above 87% for all tested models by introducing recovery-oriented interventions. While baseline rates were already relatively high, RoboHarness reduced remaining rare failures through rollback and retry mechanisms.
 - For `Task Chaining` (long-horizon sorting of multiple objects), RoboHarness facilitated robust performance, with $\pi_{0.5}$-LIBERO maintaining 96.0% success through the final sub-task. This improvement is attributed to subtask decomposition and control-flow reset, mitigating compounding errors.

**Results on LIBERO-PRO:**
RoboHarness also demonstrated effectiveness on the LIBERO-PRO benchmark, which assesses robustness against layout (Position-swap) and semantic (Task-level) shifts.

- **Position-Level Layout Shifts (LIBERO-PRO Pos):** The $\pi_{0.5}$ baseline achieved an average success rate of 2.33%. With RoboHarness, this increased to 57.2%, suggesting that memory-guided visual interventions enhance object grounding under layout changes.
- **Task-Level Semantic Perturbations (LIBERO-PRO Task):** The baseline's average success rate was 0.86%, which improved to 55.2% with RoboHarness. These gains indicate that RoboHarness effectively prepares the input and task context for the underlying frozen VLA policy, rather than directly replacing its low-level control.

**Runtime Latency:**
The amortized runtime overhead over a 1000-step LIBERO task showed that RAG retrieval and SAM3-based tools introduced negligible latency. VLM orchestration was identified as the primary additional computational cost. However, since RoboHarness invokes these modules before rollout rather than at every policy step, low-level execution remained largely unaffected.

**Ablation Studies:**
- **Efficacy of the Dual-Memory Bank:**
 - The study measured "Average Turns-to-Success" (number of reasoning-intervention loops).
 - `No Memory` baseline consistently reached execution timeout (Mean = 7.40 turns).
 - `Success-Only` memory reduced turns to 1.47 but exhibited high variance.
 - `RoboHarness (Dual)` achieved a near-optimal 1.07 turns, demonstrating that the dual-memory bank constrained the orchestrator's search space, enabling directed decision-making.
- **Impact of Dual-Stage Memory Consolidation:**
 - **Qualitative Reasoning Depth:** Evaluated by Qwen3-VL-32B scoring of generated instruction coherence. `Rich RAG` (RoboHarness's dual-stage consolidation) consistently achieved the highest ratings, indicating more focused reasoning trajectories and reduced ineffective actions.
 - **Quantitative Performance (Clutter Removal):** `No RAG` achieved 19.20% success, and `Limited RAG` (single-stage online attribution) improved to 48.80%. `Rich RAG` (RoboHarness) achieved 60.10% success, indicating higher strategic efficiency and precision from the refined memory data.

These results collectively indicate that RoboHarness consistently improves in-context adaptation and policy robustness across diverse OOD scenarios by augmenting frozen VLA policies with memory-guided diagnosis and dynamic interventions.

### 5. Significance and Potential Impact

RoboHarness introduces a framework that addresses several limitations inherent in current Vision-Language-Action (VLA) models, particularly concerning their robustness and adaptability in out-of-distribution (OOD) environments. The work's significance and potential impact can be understood through several key contributions:

1. **Enhanced Robustness and Generalization:** The primary impact is the significant improvement in VLA model robustness under various OOD conditions, including visual domain shifts, environmental clutter, noisy linguistic instructions, execution fragility, and long-horizon task chaining. By achieving substantial success rate gains (e.g., 56.6% average absolute gain, 89.1% in long-horizon tasks), RoboHarness demonstrates a practical method for making robotic policies more reliable in varied and unpredictable settings, which is crucial for real-world deployment.

2. **Parameter-Free and Plug-and-Play Adaptability:** A notable aspect of RoboHarness is its ability to robustify *frozen* VLA policies without requiring parameter fine-tuning. This "policy harness" approach offers a computationally efficient and scalable solution. It reduces the need for extensive OOD data collection and retraining, thereby lowering the barrier for deploying existing VLA models in new domains and challenges. This modularity allows for the quick integration of improved robustness mechanisms into various VLA backbones.

3. **Learning from Failures through Dual-Memory Retrieval:** The introduction of a contrastive dual-memory bank, which explicitly stores both successful and failed execution traces, represents a departure from success-biased retrieval-augmented generation (RAG) systems. This mechanism enables causal failure attribution, allowing the system to diagnose the root causes of problems and learn "what not to do" in addition to "what to do." This capability is fundamental for developing truly intelligent and resilient robotic agents that can adapt strategically.

4. **Dynamic and Context-Aware Intervention:** The Attribution-Driven Vision-Language Orchestrator, powered by a multimodal LLM, dynamically selects and parameterizes a chain of Model Context Protocol (MCP) tools. This dynamic orchestration allows for targeted interventions that modulate the perception-action stream at query time, based on the specific context and diagnosed failure mode. This enables active adaptation, such as visual domain adaptation, distractor removal, instruction rewriting, and execution recovery, providing a level of control and flexibility that static VLA policies lack.

5. **Self-Evolving Knowledge Base:** The asynchronous Dual-Stage Memory Consolidation workflow ensures that the memory bank is not static but continuously refines and updates stored experiences. By performing cross-task differential analysis, the system corrects historical failure descriptions and optimizes intervention plans. This self-correction loop prevents knowledge stagnation and enables iterative improvement of the system's adaptive capabilities over time without manual intervention or further training of the base model.

6. **Guidance for Future Research:** The work highlights the importance of external mechanisms for VLA robustness and provides a concrete framework for building such systems. Future work, as suggested by the authors, includes expanding the MCP tool repository, investigating more granular failure attribution using advanced multimodal models, and exploring the transferability of these memory-guided interventions to diverse real-world robotic platforms. This indicates a direction for research in robotics that focuses on meta-learning and adaptive reasoning layers over powerful but static base policies.

In summary, RoboHarness contributes a practical and effective strategy for enhancing the resilience and adaptability of VLA models, making a step towards more capable and robust robotic systems in complex and dynamic environments.
