# MemoNav: Working Memory Model for Visual Navigation

> [!summary] Summary
> MemoNav introduces a working memory model for visual navigation, integrating Short-Term, Long-Term, and Working Memory with a selective forgetting mechanism. This biologically inspired approach improves an agent's ability to focus on goal-relevant information and construct global scene representations, leading to superior performance in multi-goal image-goal navigation within unfamiliar indoor environments.

## Problem

- Existing topological map-based navigation methods often use all node features, leading to inefficient decision-making due to redundant or irrelevant information.
- Topological map nodes typically offer only local representations, hindering the agent's ability to form a holistic, global understanding of the entire scene for long-range planning.
- Current memory models struggle with the complexities of long-horizon and multi-goal navigation tasks, often leading to redundant re-exploration.

## Method

- A working memory model is developed, consisting of Short-Term Memory (STM) for local observations, Long-Term Memory (LTM) for global scene context, and a dynamically constructed Working Memory (WM).
- A selective forgetting module is introduced to filter out less goal-relevant STM nodes by evaluating attention scores, thus focusing the agent's memory on critical information.
- A trainable 'global node' serves as the LTM, aggregating STM features to provide a high-level, scene-level understanding and facilitating feature fusion across the topological map.

## Results

- MemoNav achieves a **7.9%** to **8.5%** improvement in Success Rate (SR) and Progress (PR) over the baseline VGM in multi-goal tasks (2-goal, 3-goal, 4-goal) across Gibson and Matterport3D datasets.
- Ablation studies confirm that both the selective forgetting module and the Long-Term Memory (LTM) contribute significantly to performance, with their synergistic combination yielding the best results.
- The optimal forgetting threshold is task-dependent, with more aggressive forgetting proving beneficial for harder, longer-horizon multi-goal tasks, demonstrating adaptive memory management.

## Takeaways

> [!tip] Key Insights
> - Modeling memory akin to human working memory, with distinct STM, LTM, and WM components, improves an agent's ability to navigate efficiently and robustly.
> - Selective forgetting of irrelevant information is crucial for optimizing memory utilization, especially in complex, multi-goal navigation tasks.
> - Incorporating a learned global scene representation (LTM) provides vital context that complements local observations, enhancing long-range planning capabilities.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The paper addresses the challenging field of **Embodied AI**, specifically focusing on **Image-Goal Navigation (ImageNav)**. This task requires an autonomous agent to navigate to a designated goal location, provided only by an image of the destination, within unfamiliar indoor environments. It has garnered significant attention due to its potential applications in robotics, autonomous systems, and assistive technologies.

Central to ImageNav is the concept of **scene memory**, which is crucial for decision-making in partially observable and unseen environments. Prior research has explored various memory mechanisms, broadly categorized into:
- **Metric map-based methods:** Reconstruct explicit top-down maps of the environment.
- **Stacked memory-based methods:** Chronologically store past observations.
- **Topological map-based methods:** Represent the environment as a graph of sparse landmarks or nodes, often favored for their efficiency and scalability in large scenes.

MemoNav positions itself within the topological map-based category, building upon and extending state-of-the-art methods like Visual Graph Memory (VGM). The authors identify two key limitations in existing topological map-based approaches that hinder efficient navigation, particularly in complex, long-horizon, and multi-goal scenarios:
1. **Unawareness of useful nodes:** Current methods often use all node features in the topological map for decision-making, regardless of their relevance to the current goal. This can lead to inefficient exploration and decision-making, as the agent may be misled by redundant or uninformative information.
2. **Local representation:** Each node in a topological map typically represents only a small local area. This limits the agent's ability to form a higher-level, holistic semantic and geometric understanding of the entire scene, which is vital for robust long-range planning.

To overcome these limitations, MemoNav draws inspiration from **cognitive neuroscience**, specifically the classical concept of **working memory (WM)** in human cognition and navigation. This brain-inspired approach aligns with a growing trend in AI research to leverage biological principles for developing more intelligent and adaptive systems, especially in reinforcement learning contexts where memory management is critical for long-term reasoning. By proposing a memory model with distinct Short-Term Memory (STM), Long-Term Memory (LTM), and Working Memory (WM) components, MemoNav aims to create a more efficient, goal-attentive, and globally aware memory system for embodied agents. This work therefore advances the field by offering a novel, biologically-inspired memory architecture that tackles fundamental challenges in robust and efficient visual navigation.

### 2. Key Objectives and Motivation

The primary objective of this research is to significantly enhance the performance of embodied agents in **image-goal navigation (ImageNav)**, particularly in **challenging multi-goal tasks within unfamiliar environments**. The authors are driven by the recognition that current approaches, while effective to some extent, suffer from inefficiencies stemming from their memory architectures.

The specific objectives and motivations underpinning MemoNav are:

- **To address inefficient exploration and decision-making:** Existing methods, particularly those based on topological maps, tend to use all accumulated historical observations (node features) for decision-making. The motivation here is that not all historical data is equally relevant to the current goal. Irrelevant or redundant information can dilute the crucial signals and lead to sub-optimal actions, prolonged exploration, and poor path efficiency. MemoNav seeks to filter out this "noise."
- **To overcome the lack of global scene representation:** While topological maps are good for local connectivity, individual node features often represent only a small, local area. The authors are motivated to enable the agent to acquire a higher-level, global understanding of the entire scene, which is critical for long-range planning and robust navigation, especially when local information might be ambiguous or limited by partial observability.
- **To develop a more robust memory model for long-horizon and multi-goal tasks:** Multi-goal navigation, where an agent must sequentially reach multiple destinations, requires sophisticated memory management. The agent needs to recall relevant past experiences, distinguish between critical and trivial information, and adapt its memory content as goals change. Existing models struggle with this complexity, often leading to redundant re-exploration. MemoNav is explicitly designed to tackle these challenges by leveraging selective attention and global context.
- **To draw inspiration from human cognitive mechanisms:** A core motivation is the effectiveness of human working memory, which seamlessly integrates short-term sensory data with long-term knowledge to focus on task-relevant information. The authors believe that emulating this biological mechanism can lead to more efficient and intelligent AI navigation systems. This bio-inspired approach seeks to build systems that process information more akin to how humans manage cognitive load during navigation.

In essence, MemoNav aims to build an image-goal navigation agent that is not only proficient at finding its way but does so intelligently by consciously managing its memory, focusing on what's truly important for the task at hand, much like a human navigator would.

### 3. Methodology and Approach

MemoNav introduces a novel memory model inspired by human working memory to improve image-goal navigation. It integrates three types of scene representations: Short-Term Memory (STM), Long-Term Memory (LTM), and Working Memory (WM). The overall approach is built upon the Visual Graph Memory (VGM) framework, extending its memory capabilities.

The methodology unfolds through a five-step navigation pipeline:

1. **STM Generation:** As the agent explores, a map updating module continuously builds a topological map. Node features on this map, derived from current observations (RGB-D panoramic images) using a pretrained encoder (F_enc), constitute the **Short-Term Memory (STM)**. These features are local and dynamic, representing the transient aspects of the visited environment.
2. **Selective Forgetting Module:** This is a crucial component designed to increase efficiency by reducing redundancy in the STM. It operates by evaluating the attention scores ({α_i}) of each STM node, generated by the goal decoder (D_goal) based on its relevance to the goal embedding (e_goal). Nodes with attention scores below a predefined threshold (p, empirically set to 20% by default) are "forgotten" – meaning they are temporarily excluded from the navigation pipeline and disconnected from their neighbors. This process ensures that the agent primarily focuses on goal-relevant information. Importantly, forgotten nodes can be restored if the agent revisits their location or if a new goal is set in multi-goal tasks, reflecting the temporary nature of forgetting. This module is active during evaluation and deployment, not training, indicating a post-processing selective attention mechanism.
3. **LTM Generation:** To address the limitation of local representation, MemoNav introduces a **Long-Term Memory (LTM)** in the form of a trainable, zero-initialized "global node" (n_global) added to the topological map. This LTM node connects to all other nodes in the map and progressively aggregates STM features through memory encoding. The LTM serves two primary purposes:
 - It learns a high-level, scene-level feature, providing a global perspective of the environment.
 - It facilitates feature fusion, acting as a "bypath" to connect potentially isolated sub-graphs within the topological map, especially after some nodes have been forgotten.
4. **Working Memory (WM) Generation:** The **Working Memory (WM)**, essential for action generation, is constructed by encoding the *retained* STM and the LTM. This encoding is performed by a **Graph Attention Module (GATv2)**. GATv2 is chosen for its ability to adaptively assign weights to neighboring nodes based on their features, which is particularly suitable for dynamic environments and multi-goal tasks where the importance of nodes can vary. The generated WM (M_w) thus combines goal-relevant local information from the retained STM with the global, scene-level understanding from the LTM.
5. **Action Generation:** The WM (M_w) is then passed as keys and values to two Transformer decoders: D_cur and D_goal. D_cur takes the current observation embedding (e_cur) as a query, generating a feature vector f_cur. Similarly, D_goal takes the goal embedding (e_goal) as a query, generating f_goal. Finally, an LSTM-based policy network takes the concatenation of f_cur, f_goal, and e_cur to produce an action distribution, leading to the agent's navigation action.

**Training and Evaluation:**
- **Base Model:** MemoNav builds upon VGM, inheriting its topological map construction and localization approach.
- **Training Pipeline:** The models are initially trained via imitation learning, minimizing the negative log-likelihood of ground-truth actions. This is followed by fine-tuning using Proximal Policy Optimization (PPO) to enhance exploratory capabilities, maintaining the reward and auxiliary loss settings of VGM.
- **Datasets:** Experiments are conducted in the Habitat simulator using the Gibson and Matterport3D scene datasets. The authors created a specific multi-goal dataset for Gibson scenes and utilized multi-goal datasets from MultiON for Matterport3D, with varying numbers of sequential goals to test task difficulty.
- **Metrics:** Standard metrics are used: Success Rate (SR) and Success weighted by Path Length (SPL) for 1-goal tasks, and Progress (PR) and Progress weighted by Path Length (PPL) for multi-goal tasks.

This comprehensive methodology, integrating selective attention, global context, and adaptive graph processing, aims to create a highly efficient and intelligent navigation system.

### 4. Main Findings and Results

The experimental evaluation of MemoNav consistently demonstrates its superiority over existing image-goal navigation methods, particularly in complex multi-goal scenarios.

#### 4.1. Quantitative Results

- **Overall Performance:** MemoNav significantly outperforms all compared methods (CNNLSTM, ANS, NTS, TSGM, VGM) in terms of success rate (SR) and progress (PR) across all difficulty levels (1-goal, 2-goal, 3-goal, 4-goal) in both Gibson and Matterport3D scenes (Table 1).
- **Strong Multi-goal Gains:** The performance gains are most pronounced in multi-goal tasks. In Gibson, compared to its baseline VGM, MemoNav improved SR by 7.9%, 8.5%, and 7.4% on 2, 3, and 4-goal tasks, respectively. This highlights MemoNav's enhanced ability to manage information across sequential goals and longer horizons.
- **Efficiency:** While MemoNav consistently achieves higher success rates, its efficiency metrics (SPL/PPL) are also competitive, often outperforming baselines, indicating that it reaches goals via more efficient paths.
- **Generalizability:** The consistent improvements observed across both Gibson and Matterport3D datasets demonstrate MemoNav's ability to generalize to different scene types, which is crucial for real-world applicability.

#### 4.2. Ablation Studies and Analysis

A thorough ablation study confirms the critical contribution of each proposed component:

- **Individual Component Efficacy:** Applying the forgetting module alone, or the LTM alone, each yields noticeable performance improvements over the baseline (VGM).
- **Synergistic Effect:** The combination of the forgetting module and LTM leads to even larger gains. Crucially, the full MemoNav model, incorporating the synergy among all three components (forgetting module, LTM, and GATv2 for WM), achieves the best performance. For instance, the full model boosts SR/PR by 10.3% (1-goal), 7.9% (2-goal), 8.5% (3-goal), and 7.4% (4-goal) compared to the VGM baseline (Table 2).
- **Critical Role of LTM:** Variants that disable the LTM (excluding it from WM, randomly replacing its features, or averaging STM features instead of learning the LTM) consistently show performance drops (Table 3). This validates the LTM's vital role in learning robust scene-level features and facilitating effective feature fusion across the graph.
- **Forgetting Threshold Impact:** The optimal forgetting threshold (p) is task-dependent (Figure 4). For easier tasks (1-goal, 2-goal), a lower `p` (less forgetting) is optimal. However, for harder, longer-horizon multi-goal tasks (3-goal, 4-goal), a higher `p` (more aggressive forgetting) proves more beneficial. This indicates that MemoNav intelligently leverages forgetting to focus on increasingly specific, goal-relevant regions as the task complexity increases, preventing the agent from being overwhelmed by extraneous information in well-explored areas. Statistical analysis further shows that retained nodes are indeed closer to the goal and shortest paths, especially in harder tasks (Figure 11).

#### 4.3. Qualitative Comparisons and Visualization

- **Efficient Routes:** Qualitative results (Figure 5) illustrate that MemoNav plans significantly shorter, smoother, and more efficient trajectories compared to CNNLSTM and VGM. It effectively avoids redundant exploration steps and common navigation pitfalls like getting trapped in bottlenecks.
- **Dynamic Memory Usage:** Visualizations of multi-goal trajectories (Figure 12) demonstrate MemoNav's ability to strategically forget distant or irrelevant nodes, focusing its working memory on areas pertinent to the current and upcoming goals. This adaptive memory management leads to more focused and efficient path planning.
- **LTM Dynamics:** Analysis of the LTM's feature variation (L2 distance between consecutive LTM features) shows stability in familiar areas and sharp increases when the agent encounters novel scenes (Figure 14). This confirms the LTM's role in assimilating new exploratory experiences and maintaining a dynamic global scene representation.

#### 4.4. Identified Limitations

The authors acknowledge some limitations: the forgetting module is currently a post-processing step (introducing a slight lag), it doesn't reduce the memory footprint (as forgotten node features are still needed for localization), and the forgetting threshold `p` is fixed rather than adaptive. They also point out a potential negative societal impact due to data bias (Gibson scenes primarily represent western architectural styles).

### 5. Significance and Potential Impact

MemoNav represents a substantial advancement in the field of embodied AI, particularly in visual navigation, by offering a novel and biologically-inspired solution to complex memory management challenges. Its significance and potential impact can be summarized as follows:

- **Bridging Cognitive Neuroscience and AI:** The most prominent impact of MemoNav lies in its successful translation of human working memory principles (STM, LTM, WM, and selective attention/forgetting) into a functional AI architecture. This work provides compelling empirical evidence that cognitive models can inspire more robust and efficient AI systems, fostering further interdisciplinary research between neuroscience and artificial intelligence. This could lead to AI agents that are not only high-performing but also more interpretable and aligned with human cognitive processes.
- **Enhanced Navigation Performance and Efficiency:** By intelligently managing scene memory, MemoNav significantly improves success rates and path efficiency in image-goal navigation tasks. The selective forgetting mechanism directly addresses the issue of redundant information, allowing the agent to focus its computational resources on goal-relevant observations. This is crucial for real-world robotic applications where computational efficiency and reliable navigation in complex environments are paramount.
- **Robustness in Challenging Scenarios:** The demonstrated superiority in multi-goal and long-horizon tasks is particularly impactful. These scenarios closely mimic real-world robotic operations, where agents must perform a sequence of tasks in dynamic environments. MemoNav's ability to adapt its memory (through LTM and dynamic forgetting) across changing goals makes it a more robust and adaptable solution for complex missions.
- **Advancement in Topological Mapping:** While building on existing topological map-based methods, MemoNav addresses their core limitations regarding local representation and redundancy. The LTM provides a much-needed global scene context, while the forgetting module ensures that the topological map remains efficient and goal-focused, transforming it into a more dynamic and intelligent knowledge base.
- **Foundation for Future Research:** The paper not only presents a strong solution but also clearly outlines its own limitations (e.g., fixed forgetting threshold, post-processing nature of forgetting). These identified areas provide clear and promising directions for future research, such as developing end-to-end trainable forgetting mechanisms, adaptive thresholding, and methods to further optimize memory footprint. This self-awareness contributes to the progressive nature of scientific inquiry.
- **Real-world Applications:** The involvement of Tencent Maps in this research underscores the potential for direct real-world applications. Improved image-goal navigation capabilities can accelerate the development of autonomous mobile robots for logistics, exploration, surveillance, and personal assistance. In particular, more efficient navigation in previously unseen indoor environments has vast implications for applications ranging from automated warehouse operations to home robotics and even disaster response.

In conclusion, MemoNav offers a significant leap forward in embodied AI by providing an intelligent memory model that allows agents to navigate complex environments with unprecedented efficiency and robustness, drawing profound inspiration from the elegance of human cognition.
