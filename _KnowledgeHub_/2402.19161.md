# MemoNav: Working Memory Model for Visual Navigation

> [!summary] Summary
> MemoNav introduces a working memory model for visual navigation, integrating Short-Term, Long-Term, and Working Memory with a selective forgetting mechanism. This biologically inspired approach improves an agent's ability to focus on goal-relevant information and construct global scene representations, leading to superior performance in multi-goal image-goal navigation within unfamiliar indoor environments.

## Problem

- Existing topological map-based navigation methods often use all node features, leading to inefficient decision-making due to redundant or irrelevant information.
- Topological map nodes typically offer only local representations, hindering the agent's ability to form a holistic, global understanding of the entire scene for long-range planning.
- Current memory models struggle with the complexities of long-horizon and multi-goal navigation tasks, often leading to redundant re-exploration.

## Method

- A working memory model is developed, consisting of Short-Term Memory (STM) for local observations, Long-Term Memory (LTM) for global scene context, and a dynamically constructed Working Memory (WM).
- A selective forgetting module is introduced to filter out less goal-relevant STM nodes by evaluating attention scores, thus focusing the agent's memory on critical information.
- A trainable 'global node' serves as the LTM, aggregating STM features to provide a high-level, scene-level understanding and facilitating feature fusion across the topological map.

## Results

- MemoNav achieves a **7.9%** to **8.5%** improvement in Success Rate (SR) and Progress (PR) over the baseline VGM in multi-goal tasks (2-goal, 3-goal, 4-goal) across Gibson and Matterport3D datasets.
- Ablation studies confirm that both the selective forgetting module and the Long-Term Memory (LTM) contribute significantly to performance, with their synergistic combination yielding the best results.
- The optimal forgetting threshold is task-dependent, with more aggressive forgetting proving beneficial for harder, longer-horizon multi-goal tasks, demonstrating adaptive memory management.

## Takeaways

> [!tip] Key Insights
> - Modeling memory akin to human working memory, with distinct STM, LTM, and WM components, improves an agent's ability to navigate efficiently and robustly.
> - Selective forgetting of irrelevant information is crucial for optimizing memory utilization, especially in complex, multi-goal navigation tasks.
> - Incorporating a learned global scene representation (LTM) provides vital context that complements local observations, enhancing long-range planning capabilities.
