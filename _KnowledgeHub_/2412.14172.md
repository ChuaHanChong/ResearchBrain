# Learning from Massive Human Videos for Universal Humanoid Pose Control

> [!summary] Summary
> This paper introduces a universal humanoid control system that learns to generate diverse robot actions from large-scale human video data

## Problem

- Traditional humanoid control methods are limited by expensive demonstration collection and lack of diversity
- Existing approaches struggle to learn generalizable actions from human videos due to different kinematic structures
- Need for scalable methods to leverage abundant video data for humanoid control

## Method

- ==Introduce Humanoid==-X dataset with 20M+ humanoid robot poses paired with text descriptions
- Develop UH-1 model that translates text commands into humanoid actions using transformer architecture
- Create pipeline for mining videos, generating captions, retargeting human motion to robots, and learning control policies

## Results

- UH-1 achieves superior performance compared to baselines on standard metrics
- Nearly **100%** success rate on real robot deployment across diverse tasks
- Scaling up training data significantly improves generalization ability
- Model demonstrates robustness in real-world scenarios beyond simulation

## Takeaways

> [!tip] Key Insights
> - Natural language provides effective interface between human commands and robot actions
> - Discretizing actions into tokens enables efficient learning from large-scale data
> - Two control modes (keypoint-based and direct action) offer flexibility for different tasks
> - Motion retargeting and RL policy learning ensure physically feasible robot motions
