# SceneStreamer: Continuous Scenario Generation as Next Token Group Prediction

> [!summary] Summary
> SceneStreamer introduces a unified autoregressive Transformer framework that generates continuous, interactive driving scenarios by modeling entire dynamic scenes as a sequence of discrete tokens. Policies trained within these generated environments demonstrate improved robustness and generalization capabilities for autonomous driving planners.

## Problem

- Existing traffic simulators, like log-replay systems, lack interactivity, preventing background agents from dynamically responding to an ego vehicle's actions, which limits closed-loop AD policy evaluation.
- Many data-driven generative models for traffic scenarios rely on one-shot motion prediction or static initial states, leading to covariate shift and unrealistic outcomes when unrolled over long simulations.
- Prior methods often separate scenario generation into inefficient two-stage processes (initialization then motion), making it difficult to model dynamic agent populations and continuous agent entry/exit in an open-world traffic system.

## Method

- **SceneStreamer** represents the entire dynamic driving scene, including map, traffic lights, and heterogeneous agent states and motions, as a structured sequence of discrete tokens.
- An encoder-decoder Transformer autoregressively predicts the next token group, employing a novel token group attention mechanism with a structured causal mask to enforce semantic and temporal dependencies.
- A 'state-forcing' mechanism allows for continuous simulation with dynamic agent populations, enabling flexible scenario generation, motion prediction, and scene densification (injecting new agents) within a unified framework.

## Results

- SceneStreamer achieves competitive Maximum Mean Discrepancy (MMD) scores for initial state realism, demonstrating its ability to generate realistic agent distributions and generalize across diverse agent types.
- Reinforcement learning policies trained in SceneStreamer-generated scenarios consistently outperform those trained on log-replay data, showing higher route completion rates, lower collision rates, and improved average rewards.
- The framework exhibits strong performance on the Waymo Sim Agents Challenge test set, achieving competitive realism and behavioral likelihood metrics for a general-purpose simulation environment.

## Takeaways

> [!tip] Key Insights
> - A unified autoregressive tokenization approach, where agent states are generated relative to local map segments, ensures semantic and physical consistency over long generative sequences, preventing implausible scenarios.
> - Structured generation order, including autoregressive prediction of agent attributes (type, map segment ID, relative state dimensions), is critical for maintaining realism and avoiding invalid configurations.
> - Training autonomous driving planners in diverse, adaptively generated interactive scenarios, rather than static log-replay data, significantly enhances their robustness and generalization capabilities.
