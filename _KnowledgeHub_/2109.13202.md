# MiniHack the Planet: A Sandbox for Open-Ended Reinforcement Learning Research

> [!summary] Summary
> Researchers at Facebook AI Research and collaborators introduced MiniHack, an open-source sandbox that utilizes NetHack's game engine and description language to provide a highly customizable and scalable platform for reinforcement learning research. This framework enables the creation of diverse environments to target specific RL challenges, demonstrating that current baseline algorithms struggle significantly as task complexity increases.

## Problem

- Existing complex RL benchmarks (e.g., full games) make it difficult to isolate and evaluate specific agent capabilities, often leading to overfitting to fixed levels.
- Simplified RL environments are effective for prototyping but demand significant engineering effort to scale and incorporate richer dynamics.
- Researchers lacked a customizable, performant, and richly dynamic 2D grid-world environment design tool that bridges the gap between these extremes.

## Method

- Develops **MiniHack**, a sandbox framework built upon ==NetHack's game engine== and its native ==description file (des-file) DSL==, for defining custom RL environments.
- Provides a user-friendly Python ==`LevelGenerator`== class and ==Gym interface== to programmatically construct environments, define flexible ==reward functions==, and manage observation/action spaces.
- Leverages NetHack's pre-implemented entities (580+ monster types, 450+ item types) and their complex interaction rules to easily create rich and diverse tasks.

## Results

- Baseline RL algorithms successfully solve simpler MiniHack tasks but exhibit significant performance degradation or outright failure when faced with incrementally increased complexity in navigation and skill acquisition challenges.
- MiniHack effectively ports and enriches existing benchmarks like MiniGrid, demonstrating that even minor additions of NetHack's complexities push current RL baselines to their limits.
- The framework supports Unsupervised Environment Design (UED), with PAIRED-trained agents achieving improved zero-shot transfer to complex, unseen environments.

## Takeaways

> [!tip] Key Insights
> - MiniHack provides a unique bridge between highly complex, fixed game environments and overly simplified testbeds, offering both control and inherent richness.
> - The modular design facilitates isolating specific RL challenges and enables systematic, incremental scaling of environmental complexity.
> - By utilizing NetHack's pre-existing game logic and assets, MiniHack allows for the rapid creation of complex, dynamic environments with minimal engineering effort.
