# SEM: Enhancing Spatial Understanding for Robust Robot Manipulation

> [!summary] Summary
> Researchers at Horizon, Beijing, developed SEM, a diffusion-based framework that creates a unified spatial representation by projecting multi-view image features and robot states into a shared 3D coordinate frame. This approach yields an average success rate of 78.38% on RoboTwin 2.0 tasks and significantly improves 3D and embodiment generalization over baselines in both simulation and real-world manipulation.

## Problem

- Mainstream robot manipulation models often lack explicit 3D reasoning, relying on 2D image backbones that limit understanding of 3D geometry and object relationships.
- Existing methods typically process visual and robot state features independently, leading to inconsistent feature spaces and hindering seamless integration of diverse sensory data.
- Policies struggle with 3D and embodiment generalization, performing poorly with varying camera viewpoints, object arrangements, or when transferring skills to different robot platforms.

## Method

- **SEM** is a ==diffusion-based== framework that establishes a ==unified spatial representation== by projecting multi-view image features and joint-centric robot states into a common 3D robot base frame.
- Introduces a ==Spatial Enhancer== module that integrates camera models and depth information to generate 3D positional embeddings from 2D visual features.
- Employs a ==Robot State Encoder== with forward kinematics and ==joint graph attention== to model robot embodiment structure and provide a joint-centric spatial representation.

## Results

- Achieved **78.38%** average success on **16** RoboTwin 2.0 tasks, outperforming DP3 (**56.25%**) and RDT (**41.25%**).
- Improved 3D spatial generalization with slower success-rate decay under camera-height variation compared to RDT (zero-shot).
- Multi-embodiment training improved UR5 task performance by **+5.5%**; consistently outperformed RDT on 7 real-world tasks with **+25.8%** higher average success rate.

## Takeaways

> [!tip] Key Insights
> - Constructing a unified spatial representation in the robot base frame effectively aligns multi-modal inputs, reducing ambiguity from varying viewpoints and diverse robot embodiments.
> - Explicitly injecting 3D information via a spatial enhancer is crucial for policies to robustly reason about 3D geometry, significantly improving performance.
> - Joint graph attention within the robot state encoder enables effective modeling of robot embodiment structure, promoting generalization across different robot platforms and joint configurations.
