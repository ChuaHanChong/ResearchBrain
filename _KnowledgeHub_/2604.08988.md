# SEA-Eval: A Benchmark for Evaluating Self-Evolving Agents Beyond Episodic Assessment

> [!summary] Summary
> SEA-Eval is the first benchmark for Self-Evolving Agents, formalizing them as an Evolutionary Flywheel coupling an Execution Hub and a Cognition Hub. It pairs success rate with token consumption over sequential task streams (correlated, orthogonal, implicit-intent) under clean and noisy memory. Evaluating five agent frameworks, it finds up to 31.2x token gaps at comparable success rates, exposing pseudo-evolution.

## Problem

- Existing LLM agents suffer episodic amnesia: memory resets at every task boundary, so interaction experience never becomes reusable cross-task cognitive assets or expanded action spaces.
- Mainstream agent benchmarks use the isolated task episode as evaluation unit, making cross-task knowledge accumulation and continuous capability growth structurally impossible to observe.
- Success-rate-dominated static metrics treat efficiency as a single-task property, hiding whether execution overhead converges with experience, so pseudo-evolution stays invisible.

## Method

- Formal **SEA** tuple (environment, action space, ==stratified persistent memory==, ==distillation function==, ==selective transfer function==) with the dual-hub **Evolutionary Flywheel** as minimal sufficient architecture and two named failure modes.
- Flywheel-grounded metric system: ==success rate== and ==token consumption== as primaries, plus auxiliary ==efficiency evolution rate==, ==SR growth slope==, ==alignment convergence rate==, execution steps, self-correction and intervention counts.
- Dataset of 32 variable-slot atomic tasks across three difficulty tiers composed into 92 ==correlated==, ==orthogonal-same== and ==orthogonal-similar== sequences, with a ==noise-injection condition== preloading 20 unrelated skills.

## Results

- Across five frameworks success rates cluster at **85%-96.7%**, yet token consumption diverges by up to **31.2x** on individual tasks; OpenClaw's first round costs **14.8x** Codex's.
- GenericAgent shows genuine evolution: **68.0%** token reduction from round one to three, median change rate **-78%** on identical tasks and **-55%** transferring to similar instances.
- OpenClaw's overhead stays flat across repetitions and rises to **+22.2%** median under orthogonal-similar interference, the only agent turning positive, confirming shortcut memorization over strategy learning.

## Takeaways

> [!tip] Key Insights
> - Equal success rates can mask an order-of-magnitude cost gap; the convergence trajectory of execution overhead, not the endpoint score, reveals genuine learning.
> - Repeating the identical task is insufficient evidence of evolution: only varied instances after unrelated interference separate generalizable strategy distillation from rote memorization.
> - Caching and prompt compression confound efficiency measurements, so apparently low consumption can reflect billing mechanics rather than improved execution strategy.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development of Large Language Model (LLM) agents has progressed, enabling capabilities such as reasoning, planning, and tool use within iterative action loops. These agents demonstrate utility in domains like software engineering and workflow orchestration. Recent advancements have moved agents beyond text-based reasoning to system-native architectures, achieving deeper integration with operating systems and applications. This transition facilitates a state of "digital embodiment," allowing agents to operate directly on graphical user interfaces (GUIs), Document Object Models (DOMs), and low-level system interfaces. This operational shift, combined with the capacity to maintain persistent memory across tasks, points toward the emergence of Self-Evolving Agents (SEAs).

Prior research has advanced various technical components relevant to SEAs. On the execution side, efforts have focused on tool creation (Qian et al., 2023), skill library construction (Wang et al., 2023), large-scale tool selection (Qin et al., 2024), and embodied AI that extends perception-action paradigms (Brohan et al., 2023; Wahle et al., 2022). On the cognitive side, work has explored memory system construction (Shinn et al., 2023; Zhao et al., 2024; Packer et al., 2023), planning and reasoning (Wei et al., 2022; Yao et al., 2023), and self-reflection mechanisms (Madaan et al., 2023; Gou et al., 2024).

However, a recurring limitation in existing LLM-based agents is "episodic amnesia." This concept, extended from cognitive science, describes agents that possess procedural skills but fail to encode specific experiences into persistent memory for cross-task reuse. Current LLM agents typically reset their cognitive state at each task boundary, preventing the accumulation of experience. While continual learning research addresses forgetting (e.g., Kirkpatrick et al., 2017), these approaches often define evolution at the algorithm level and presuppose specific update mechanisms or operate over closed task distributions, differing from the architectural-level, open-ended environmental evolution defined for SEAs.

This paper identifies a gap: existing work often treats execution and cognition capabilities as isolated techniques rather than interdependent components of a closed-loop system. Consequently, current evaluation frameworks, such as WebArena (Zhou et al., 2024), OSWorld (Xie et al., 2024), and AgentBench (Liu et al., 2025), are designed around single-task episodes with memory resets. This episodic paradigm measures immediate competence but is structurally unable to assess cross-task knowledge accumulation, continuous capability growth, or the dynamic convergence of execution efficiency as experience is gained. This creates a "capability illusion" where agents with comparable success rates may have fundamentally different evolutionary qualities that are undetectable by existing benchmarks.

This work contributes to the landscape by formally defining the SEA paradigm and introducing a benchmark, SEA-Eval, which is designed to address the limitations of existing evaluation methods by assessing continuous evolution and efficiency dynamics across sequential tasks.

### 2. Key Objectives and Motivation

The primary objectives of this research are:

1. **Formalize the Self-Evolving Agent (SEA) Paradigm:** To establish a theoretical framework for SEAs, defining their foundational characteristics as digital embodiment and continuous cross-task evolution. This formalization includes proposing the "Evolutionary Flywheel" as the minimal sufficient architecture required for SEAs to function and to provide a criterion for distinguishing genuine evolution from "pseudo-evolution."

2. **Develop a Dedicated Evaluation Benchmark for SEAs:** To address the limitations of existing episodic evaluation frameworks, the paper aims to introduce SEA-Eval. This benchmark is designed to quantify evolutionary gain, evolutionary stability, and implicit alignment convergence by employing sequential task streams and specific metrics that track dynamic changes in performance and efficiency over time.

3. **Empirically Evaluate Leading Agent Frameworks:** To apply SEA-Eval to current agent frameworks, such as GenericAgent and OpenClaw, to assess their evolutionary capabilities. The goal is to identify current bottlenecks in SEA development and to demonstrate the utility of SEA-Eval in revealing differences in evolutionary quality that are not apparent with traditional success rate metrics.

The motivation for these objectives stems from the observation that while current LLM agents demonstrate strong performance in individual tasks, they lack the ability to accumulate and leverage experience across different tasks. This "episodic amnesia" prevents agents from improving their efficiency or adapting their strategies over time, leading to static toolsets and repeated reasoning from scratch. Existing benchmarks, by focusing on isolated task success, fail to capture these long-term evolutionary dynamics. This creates a scenario where two agents might achieve similar success rates, but one might be genuinely learning and becoming more efficient, while the other is merely repeating zero-shot reasoning, a distinction that current evaluations cannot make. The paper seeks to bridge this "evaluative gap" by providing a framework and benchmark capable of distinguishing genuine, cost-reducing evolution from pseudo-evolution.

### 3. Methodology and Approach

The research establishes a formal definition of Self-Evolving Agents, proposes a minimal architectural design, and then constructs a benchmark, SEA-Eval, grounded in these principles.

**SEA Paradigm Formalization:**
An SEA is defined as a tuple SEA = (E, A, M, Φ, Ψ), where:
- E: An open-ended digital environment with dynamic states and heterogeneous interactions.
- A: An open and extensible action space that can expand autonomously.
- M: A persistent stratified memory across task boundaries, including procedural (M_p), episodic (M_e), and declarative (M_d) knowledge.
- Φ: An experience distillation function that maps raw interaction trajectories (τ) to structured memory updates (ΔM).
- Ψ: A selective cross-task memory transfer function that integrates updates from ΔM into persistent memory (M_t+1).

Two foundational characteristics define an SEA:
1. **Complex Interaction in Open-ended Environments:** Agents operate directly on raw GUI pixels, DOM trees, and low-level system interfaces (digital embodiment), synthesizing new tools as needed (autonomous tool synthesis).
2. **Continuous, Multi-turn Evolution:** Agents maintain persistent memory (M) across tasks, transforming historical experiences into cognitive priors that reconfigure subsequent task execution (implicit user alignment).

**The Evolutionary Flywheel Architecture:**
The paper introduces the "Evolutionary Flywheel" as a minimal sufficient architecture, composed of two coupled hubs:
1. **Execution Hub:** The sensory-motor interface for digital embodiment, handling multimodal perception and action execution, including autonomous tool synthesis.
2. **Cognition Hub:** Implements Φ and Ψ functions. It provides execution guidance by integrating retrieved context and plans, and performs experience distillation by abstracting reusable strategies and updating persistent memory after task completion.

The flywheel operates in three phases: Execution (generating trajectory τ), Distillation (Φ processes τ into ΔM, Ψ selectively integrates it into M), and Augmented Execution (M guides subsequent tasks, reducing cost). Failure modes, distillation failure (Φ fails to generalize) and retrieval failure (Execution Hub cannot access relevant M entries), both result in execution cost failing to decrease.

**SEA-Eval Evaluation Framework:**
SEA-Eval evaluates agents across two dimensions:
1. **Intra-task Execution Reliability:** Assesses immediate execution capability in complex, uncertain environments without relying on prior experience, covering complex scenario adaptation and error recovery robustness.
2. **Long-term Evolutionary Performance:** Assesses systematic performance improvement and stability across sequential tasks, including evolutionary gain (cost reduction), evolutionary stability (retaining capabilities), and implicit alignment convergence (decreasing user intervention).

**Metric Design:**
- **Primary Metrics:**
 - **Success Rate (SR):** Baseline for task completion.
 - **Token Consumption (T):** Core signal for genuine evolution; its monotonic convergence indicates effective learning.
- **Intra-task Auxiliary Metrics:**
 - **Execution Steps (S):** Number of decision-making steps.
 - **Self-Correction Frequency (N_fix):** Autonomous error identification and recovery.
 - **User Intervention Rate (N_undo):** Manual corrections, quantifying misalignment.
- **Long-term Auxiliary Metrics:**
 - **Efficiency Evolution Rate (K_eff):** Rate of token consumption change across sequential tasks.
 - **SR Growth Slope (K_SR):** Rate of SR improvement.
 - **Alignment Convergence Rate (K_align):** Rate of decrease in user intervention frequency.

**Dataset Design:**
The dataset combines atomic tasks with sequential task streams under varying noise conditions.
- **Atomic Task Construction:** 32 tasks (12 Easy, 18 Normal, 2 Hard) cover Web Automation and Local System Operations. Tasks include variable slots to prevent rote memorization.
- **Sequential Task Construction:**
 - **Correlated Sequences:** `R1 → R2 → R3 → A2 → A3`. Measures learning from identical repetitions (R1-R3) and generalization to similar instances (A2, A3).
 - **Orthogonal Sequences:** `A1 → B → C → D → A1` (Orth-Same) and `A1 → B → C → D → A2` (Orth-Similar). Measures retention robustness against cross-domain interference.
- **Noise Injection Mechanism:**
 - **Clean Condition:** Agent starts with empty memory.
 - **Noisy Condition:** Agent preloaded with 20 unrelated skills to simulate memory congestion and assess retrieval robustness.

**Experimental Setup:**
Five representative SEAs were evaluated: GenericAgent (GA), OpenClaw, Hermes, Claude Code, and Codex. Foundation models were configured per agent architecture and task requirements. All evaluations were performed in isolated containerized sandbox environments with a 15-minute timeout.

### 4. Main Findings and Results

The empirical evaluation using SEA-Eval revealed significant differences in evolutionary capabilities among leading agent frameworks.

**Overall Performance Overview (Easy-Correlated Sequence):**
- **Token Consumption Disparity:** A substantial difference in token consumption was observed. OpenClaw’s R1 mean token consumption was 14.8 times higher than Codex and remained 17.6 times higher than GenericAgent (GA) at the R3 stage (after multiple learning rounds). This was attributed to OpenClaw’s lack of prompt compression.
- **Divergent Evolutionary Efficiencies:** GA exhibited a steep exponential decline in token consumption (88% optimization from R1 to R2), demonstrating strong iterative optimization. Claude Code showed a fast-then-stable pattern. Codex remained largely flat, attributed to its high initial efficiency leaving limited optimization headroom. OpenClaw showed negligible reduction, indicating pseudo-evolution.
- **Efficiency-Reliability Synergy:** Agents with lower token consumption (GA, Claude Code, Codex) generally maintained high success rates (85%–95%), suggesting that efficient execution strategies contribute to task completion. Hermes was an outlier with high token consumption and low success rates, indicating systemic inefficiency beyond just timeout issues.

**Evolutionary Capability Analysis:**
- **Pronounced Efficiency on Identical Tasks:** GA demonstrated the most significant evolutionary efficiency, with a median R3 vs. R1 token consumption change rate of -78%. Codex showed a modest -28%, but this was contextualized by its already low initial token consumption.
- **Distinct Evolutionary Paradigms:** Two paradigms emerged:
 1. **Iterative Optimization (GA):** Characterized by progressive token compression and declining learning curves.
 2. **First-Shot Convergence (Claude Code, Codex):** Tended to achieve near-optimal states in the first execution, with subsequent rounds showing limited variation, partly due to prompt caching mechanisms.
 - OpenClaw displayed "pseudo-evolution," with token consumption remaining largely unchanged across rounds.
- **Transfer to Similar Tasks:** GA’s learning effectively transferred to similar tasks, showing a median A3 vs. R1 change rate of -55%. While transfer magnitude was similar across agents, stability varied. Hermes, Claude Code, and Codex exhibited volatility with some cases of sharply increased token consumption. OpenClaw’s apparent stability in transfer was attributed to its general stagnation rather than robust transfer.
- **Retention Under Interference:** GA retained learning gains even when unrelated distractor tasks were interleaved, with median efficiency improvements of -35.2% (Orth-Same) and -29.2% (Orth-Similar). However, some instability was noted, attributed to its memory retrieval mechanism.
- **OpenClaw's Shortcut Memorization:** Under the Orth-Similar condition (similar tasks after interference), OpenClaw’s median token consumption increased by +22.2%, contrasting with a slight improvement in Orth-Same. This indicates "shortcut memorization," where the agent performs well on identical tasks but deteriorates dramatically when task variants or context changes occur, failing to generalize.

**Comprehensive Capability Profile:**
An 8-dimensional composite score (SR, TC, K_eff(Evo), K_eff(Conv), K_trans, K_eff(Stab-Id), K_eff(Stab-Sim), K_eff(Ret)) revealed a consistent ranking: GA > Claude Code > Codex > OpenClaw > Hermes.
- **Efficient Learning Type (GA):** Ranked first, demonstrating strong experience accumulation and strategy optimization (high K_eff(Evo), K_eff(Conv), K_trans, K_eff(Ret)). Its main area for improvement was memory retrieval stability under orthogonal interference (lowest K_eff(Stab-Id) score).
- **Stable Enhancement Type (Claude Code, Codex):** Benefited from caching, achieving high normalized TC scores and stability (high K_eff(Stab-Id), K_eff(Stab-Sim)). Claude Code balanced learning and stability, showing optimization on similar tasks after interference. Codex pursued extreme efficiency and consistency at the cost of learning capability (low K_eff(Conv), K_eff(Ret)).

These findings collectively highlight a fundamental tradeoff in current agent design between learning depth and execution stability.

### 5. Significance and Potential Impact

This research contributes to the field of LLM agents in several ways, with implications for future development and evaluation:

1. **Formalization of the Self-Evolving Agent (SEA) Paradigm:** The paper provides a formal definition of SEAs, grounded in concepts of digital embodiment and continuous cross-task evolution. This theoretical framework, including the "Evolutionary Flywheel" architecture, offers a principled basis for understanding and designing agents that can accumulate experience. It also establishes a clear criterion for distinguishing genuine evolution from "pseudo-evolution," addressing a conceptual ambiguity in the field.

2. **Introduction of SEA-Eval as a Dedicated Benchmark:** By moving beyond episodic assessment, SEA-Eval fills a critical gap in agent evaluation. Its design, incorporating sequential task streams, persistent memory configurations, and dynamic metrics like token consumption convergence, enables the direct measurement of evolutionary dynamics, including learning, generalization, and robustness to interference. This shift in evaluation methodology provides more comprehensive insights into an agent's capabilities than traditional success rate metrics alone.

3. **Revelation of Evolutionary Bottlenecks:** The empirical evaluation using SEA-Eval exposes a significant "evolutionary bottleneck" in mainstream agent frameworks. The findings demonstrate that agents with comparable task success rates can exhibit vastly different token consumption efficiencies and evolutionary trajectories. This disparity underscores that success rate alone creates a "capability illusion" and that the sequential convergence of execution efficiency is a crucial indicator of true evolutionary quality. This insight can guide developers toward building agents that are not only effective but also continuously improving and resource-efficient.

4. **Guidance for Future Research:** The paper lays a foundation for addressing several open challenges in the development of continuously adaptive digital entities. These include:
 - **Autonomous Bootstrapping:** Enabling SEAs to initiate their own evolutionary cycles without explicit human prompts.
 - **Balancing Reasoning Depth and Efficiency:** Optimizing the use of LLMs for both complex reasoning and latency-sensitive execution, possibly through heterogeneous multi-model orchestration.
 - **Multi-agent Co-evolution:** Extending the SEA paradigm to systems of multiple agents that can share knowledge and achieve collective evolutionary gains.
 - **Subjective Preference Alignment:** Developing evaluation methods that capture subtle, subjective aspects of user alignment beyond intervention rates.
 - **Safety and Governance:** Designing frameworks that ensure the safe and controllable evolution of agents with autonomous self-modification capabilities.
 - **Transition to Embodied AI:** Recognizing the architectural isomorphism between digital and physical embodiment, positioning digital environments as a testbed for mechanisms required by physical robotic systems.

Overall, this work signifies a step toward more capable and efficient autonomous systems by providing both a theoretical framework and a practical tool for evaluating agents' continuous learning and adaptation abilities.
