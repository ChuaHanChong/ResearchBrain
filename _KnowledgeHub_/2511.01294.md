# Kinematify: Open-Vocabulary Synthesis of High-DoF Articulated Objects

> [!summary] Summary
> Kinematify is a framework that automates the generation of kinematics-aware articulated 3D object models from static RGB images or text, even for high-degree-of-freedom and multi-branched structures. It achieves a 2.92° average axis angle error on everyday objects and reduces the Tree Edit Distance to 1.32 on robotic platforms, producing models suitable for real-world robot manipulation.

## Problem

- Creating detailed kinematic models for high-DoF articulated objects, such as URDFs, requires substantial manual effort.
- Existing high-fidelity methods often rely on motion sequences or predefined articulation priors, limiting their applicability to static inputs or novel objects.
- Prior program-synthesis approaches struggle with the complexity of high-DoF or multi-branched kinematic structures.
- There is a need for physically consistent and functionally valid articulated models derived from static inputs for robot interaction and simulation.

## Method

- The framework begins by generating ==part-aware 3D segmented meshes== and their implicit ==Signed Distance Functions (SDFs)== from RGB images or textual descriptions.
- A ==Monte Carlo Tree Search (MCTS)== algorithm is employed to infer the ==kinematic topology==, transforming an undirected connection graph into a directed tree using a ==multi-term reward function==.
- Joint types are predicted using a Vision-Language Model, and precise joint parameters (pivot, axis) are estimated through a novel ==Distance-Weighted Contact-Aware Virtual Linkage (DW-CAVL)== optimization that minimizes separation and penetration under virtual motion.

## Results

- Achieved an average axis angle error of **2.92°** for everyday objects and **16.06°** for robotic platforms, significantly outperforming previous methods.
- Reduced the Tree Edit Distance on robotic platforms to an average of **1.32**, accurately recovering complex multi-branched kinematic structures like those in humanoid robots.
- Generated kinematic models were successfully deployed in both simulation and real-world robot manipulation tasks (e.g., drawer opening, pouring), demonstrating physical consistency and direct usability for online planning.

## Takeaways

> [!tip] Key Insights
> - Combining part-aware 3D geometry with an MCTS-driven topological search effectively infers complex, multi-branched kinematic structures, even without explicit motion data.
> - The DW-CAVL objective, leveraging differentiable rigid motions and weighted SDF evaluations, can accurately infer joint parameters from static contact regions by optimizing for virtual motion consistency and collision avoidance.
> - The MCTS reward function's emphasis on structural regularity, static stability, contact strength, and symmetry is crucial for resolving ambiguities in high-DoF kinematic tree inference.
