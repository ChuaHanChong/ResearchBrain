# Learning to Forget -- Hierarchical Episodic Memory for Lifelong Robot Deployment

> [!summary] Summary
> A new framework, H^2-Emv, equips humanoid robots with a scalable and personalized episodic memory by combining online hierarchical memory construction with an incrementally learned, relevance-based forgetting mechanism. This approach led to a 45% reduction in memory size and 35% less query-time compute, while improving question-answering accuracy by 70% through adaptive user feedback.

## Problem

- Robots in lifelong deployment face prohibitive memory growth and slow query times due to the continuous generation of vast amounts of multimodal data.
- Existing artificial episodic memory systems lack robust mechanisms for selective, relevance-based forgetting, leading to inefficient memory management unlike human cognition.
- The subjective nature of "relevance" necessitates adaptive, personalized memory retention strategies rather than static, pre-defined metrics for effective human-robot interaction.

## Method

- An **H^2-Emv** architecture is introduced for online, incremental construction of a ==hierarchical episodic memory==, structuring raw observations into recursively summarized nodes.
- A ==decay-based forgetting mechanism== selectively removes expired memory nodes by utilizing a ==Large Language Model (LLM)== to estimate a numeric relevance factor based on node content, context, and learned rules.
- A ==feedback-based relevance learning== component dynamically updates natural-language ==relevance rules== from user interactions, enabling the system to personalize both memory summarization and forgetting processes.

## Results

- H^2-Emv achieved a **45%** reduction in memory size and **35%** lower query-time computation compared to non-forgetting systems over long histories.
- Question-answering accuracy improved by **70%** in second-round queries after user feedback, demonstrating the system's successful adaptation to user-specific relevance.
- The framework transferred effectively to real-world humanoid robot deployment (Armar-7), showing sustained performance improvements and efficient memory management on complex, long-term data.

## Takeaways

> [!tip] Key Insights
> - Online hierarchical memory construction is crucial for robustly handling continuous data streams and creating memory structures compatible with efficient, relevance-based forgetting mechanisms.
> - Integrating user feedback to incrementally learn natural-language relevance rules significantly improves the effectiveness of both selective forgetting and memory summarization, adapting to user-specific priorities.
> - Relevance-based forgetting, when guided by learned user preferences, allows for efficient memory management (reduced size and compute) while enabling performance improvements over time, compensating for initial information loss.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work addresses a challenge in autonomous robotics: the need for robots to possess and utilize episodic memory (EM) for verbalizing past experiences in human-robot interaction. While humans naturally remember and selectively forget, artificial systems, particularly those operating continuously over long durations, face severe limitations in storage and computational resources if they retain all information. Existing approaches to episodic memory verbalization (EMV) in robotics include end-to-end neural networks and systems that convert robot experiences into text, often leveraging large language models (LLMs). Some prior work has explored techniques like retrieval-augmented generation or hierarchical tree-based memory representations to structure and search these ever-growing memories.

However, these systems generally do not incorporate mechanisms for selective forgetting that adapt to user-defined relevance. Previous methods, including the authors' prior work on H-Emv, primarily focused on structuring EM for efficient retrieval but still produced an indefinitely expanding memory. This paper introduces a solution to this scalability issue by integrating online memory construction, a decay-based forgetting mechanism with LLM-based relevance estimation, and an incremental learning component that adapts forgetting and summarization based on user feedback. This positions the work as an advancement in developing scalable, personalized, and adaptable episodic memory systems for long-term human-robot collaboration, drawing inspiration from cognitive science on human forgetting and memory consolidation.

### 2. Key Objectives and Motivation

The primary objective of this research is to enable humanoid robots to develop and maintain a scalable, personalized episodic memory (EM) throughout their operational lifespan, allowing them to verbalize past experiences efficiently and relevantly. The motivation stems from several core challenges:

1. **Storage and Computational Limits:** Robots continuously perceive multimodal data, leading to an exponentially growing EM. Indefinitely retaining all past experiences quickly exceeds available storage and renders real-time querying impractical. This necessitates selective information management.
2. **Lack of Universal Relevance Definition:** What constitutes "relevant" information varies significantly across different use cases and individual users. A fixed, pre-programmed relevance criterion would limit the robot's adaptability and utility in diverse interactive scenarios. Therefore, the system needs to dynamically learn and adapt its understanding of relevance based on ongoing interaction.
3. **Inefficient Querying:** Even with structured memory, an excessively large EM increases the computational cost and time required to retrieve specific information, hindering the robot's ability to respond promptly to user inquiries about its past. Selective forgetting can alleviate this by reducing the search space.
4. **Enhancing Human-Robot Collaboration:** For robots to engage in natural and effective long-term collaboration, they must be able to recall and articulate pertinent past events. This requires a memory system that not only stores information but also prioritizes and retains details that are important to the user, thereby facilitating more meaningful verbalization.

To address these motivations, the authors propose H²-Emv with three specific objectives:
- To enable **online, incremental construction** of a hierarchical episodic memory, shifting the computational burden of memory organization away from query time.
- To implement a **decay-based forgetting mechanism** that utilizes a large language model to estimate the relevance of expiring memories, conditioned on a set of natural-language rules. This aims to reduce memory size and query-time compute.
- To develop a system for **incremental learning of relevance rules** from user feedback. This allows the robot to adapt its forgetting and summarization processes to user-specific priorities over time, thereby personalizing its memory.

### 3. Methodology and Approach

The H²-Emv framework extends an existing hierarchical episodic memory verbalization (H-Emv) system by incorporating online memory construction, relevance-based forgetting, and feedback-based relevance learning.

**System Architecture Overview (H²-Emv):**
The system processes a timestamped stream of raw multimodal observations (e.g., perception, proprioception). From these observations, it continuously builds and updates a hierarchical history tree (H), representing episodic memory. This tree consists of multiple levels: raw scene graph instants (L1), event summary nodes (L2), goal summary nodes (L3), and higher-level summary nodes (L>3). An agentic LLM efficiently explores this history tree to answer natural language questions about the robot's past.

**Key Contributions:**

1. **Online History Tree Construction:**
 - **Incremental Grouping and Summarization:** The system adapts the recursive grouping and summarization algorithm from H-Emv to an online setting. When a new observation arrives, an LLM is prompted with the current grouping of items and the new node. The LLM, guided by natural-language relevance rules, produces an updated grouping. This process iterates bottom-up until no further changes occur.
 - **Time-Aware Grouping:** To address issues like temporal gaps (e.g., robot inactivity overnight), a time-aware incremental grouping and summarization algorithm is introduced (Algorithm 1 and 2). This algorithm uses time-based visibility cutoffs and clustering to prevent merging temporally distant items, ensuring that the hierarchy reflects meaningful temporal segments.

2. **Relevance-Based Forgetting:**
 - **Decay Mechanism:** Each node `n` in the history tree is assigned an initial expiration time `τ_n`, calculated based on its end time, a default timespan (`∆tℓ`) specific to its hierarchical level, and a level-dependent multiplier (`γℓ`).
 - **Relevance Estimation:** After each online history tree update, the system recursively traverses nodes from top-down. If a node's expiration time `τ_n` is in the past, an LLM is prompted to estimate a numeric relevance factor `α`. This estimation considers the node, its parent (as context), and the current set of natural-language relevance rules. The LLM can return a numerical score (as a lifetime multiplier) or "inf" for indefinite retention.
 - **Lifetime Extension and Forgetting:** The node's expiration time is then extended by `α · ∆tℓ`. If it remains expired, the node is forgotten. Parent nodes' expiration times are updated to be no earlier than their children's, preventing premature forgetting of higher-level summaries.
 - **Placeholder Mechanism:** Forgotten nodes are replaced by placeholders that retain only the time range and the first line of their summary. These summaries are hidden during verbalization but available to the grouping LLM, ensuring contextual consistency in higher-level summaries.

3. **Dialog Manager & Relevance Learning:**
 - **Dialog Flow:** A dialog manager, implemented using an LLM, routes user utterances. Questions are directed to the EMV module, while user feedback is sent to the relevance learning component.
 - **Feedback-based Rule Update:** The relevance learning component employs an LLM to dynamically update the set of natural-language relevance rules. This LLM processes user feedback (e.g., "You should always remember X") and can add, modify, or remove rules to refine the system's understanding of relevance. These updated rules then influence both subsequent summarization during online tree construction and relevance estimation during forgetting.

**Experimental Setup:**

- **Simulated Robot Recordings (TEACh Dataset):**
 - **Dataset:** Concatenated episodes from TEACh simulation, creating long histories of 5 and 25 episodes.
 - **QA Pairs:** Grammar-generated, timestamped question-answering pairs, specifically designed in two rounds to test relevance learning. The first question targets an event likely to be forgotten, and user feedback is provided. The second question, targeting a similar or generalized event, assesses whether the system learned from the feedback.
 - **Metrics:** QA accuracy (correct/partially correct answers, evaluated by an LLM judge), final and average tree size, and LLM token costs for QA and forgetting. Performance improvement from round one to round two (`S1c/p` vs. `S2c/p`) is a key metric.
 - **Baselines:** A systematic ablation study was conducted, comparing the full H²-Emv system (`ours`) against variants with removed online construction, forgetting, or relevance learning, as well as offline history tree construction and flat (non-hierarchical) baselines.
- **Real-World Humanoid Robot Recordings (Armar-7):**
 - **Dataset:** 20.5 hours of multimodal data from Armar-7 performing household tasks, curated into five long histories with human-annotated and LLM-refined QA pairs.
 - **Method:** Similar metrics and a subset of ablations were used to assess transferability to real-world complexities. QA classification was manually corrected due to domain shift for the LLM judge.
- **Real-World Humanoid Robot Deployment:**
 - **Live Operation:** H²-Emv was deployed live on Armar-7 for multiple weeks. Online history tree construction and forgetting were offloaded to a GPU server, running asynchronously. Forgetting was scheduled nightly or when the update queue was empty, and designed to be interruptible. The dialog manager was integrated into the robot's existing LLM-based dialog system.

### 4. Main Findings and Results

The evaluation of H²-Emv demonstrated the effectiveness of its components across simulated and real-world scenarios.

**Performance–Efficiency Trade-offs:**
- Forgetting mechanisms, while necessary for efficiency, initially reduced first-round QA performance. Systems with forgetting (e.g., `ours`) showed roughly half the first-round success rate compared to non-forgetting systems (`no forg.`). This reduction is an expected consequence of information removal.
- Concurrently, forgetting significantly reduced memory footprint, with smaller final tree sizes, and lowered the growth rate of QA token costs, indicating improved computational efficiency.
- Online history tree construction, compared to offline methods, led to lower QA token costs at question time, as the tree building effort was distributed during robot operation rather than being concentrated at query time. Offline systems, while producing more compact trees, incurred higher total compute costs at query time due to the on-demand tree construction.

**Impact of Feedback-Based Relevance Learning:**
- A key finding was the substantial improvement in QA performance from the first to the second round for systems incorporating feedback-based relevance learning (`ours`, `offl. full`). For instance, `ours` showed a 70% increase in second-round accuracy in Armar-7 experiments, demonstrating its ability to adapt to user priorities.
- In contrast, methods without relevance learning (`no learning`, `offl. no forg.`) either stagnated or experienced performance degradation in the second round, which was attributed to increased information overload and higher likelihood of false retrieval in a growing memory.
- For shorter histories (5 episodes), `ours` achieved second-round performance comparable to the non-forgetting baseline (`no forg.`) despite a considerably smaller memory size, indicating that learned forgetting can effectively compensate for information loss.

**Interaction of Components:**
- Relevance estimation without feedback-based learning was found to be largely ineffective, as arbitrary relevance decisions yielded limited benefits. However, when combined with feedback-based relevance learning, a synergistic effect was observed, leading to performance gains while managing resources.
- Ablation studies indicated that applying feedback-based relevance learning to both forgetting and summarization processes was beneficial for overall system performance, particularly in more diverse real-world data.
- The forgetting mechanism showed greater compatibility with online history tree construction compared to offline or flat histories. This was hypothesized to be due to a shared recency bias and the online construction's tendency to build deeper hierarchies, preserving higher-level summaries. Offline-built trees were more severely impacted by initial time-based forgetting.

**Scaling and Baselines:**
- H²-Emv demonstrated scalability to long histories (25 simulated episodes), maintaining low storage and compute requirements while improving performance through feedback.
- Non-hierarchical baselines (`flat full`, `flat no forg.`) were largely ineffective for relevance-based forgetting without the hierarchical structure, and suffered from exploding compute costs for longer histories, confirming that flat memory representations are not suitable for lifelong scenarios.

**Real-World Application:**
- The system successfully transferred to real-world recordings from the Armar-7 robot. In this more complex environment, H²-Emv was the only system to show a clear performance improvement from round one to round two, while other forgetting systems stagnated and non-forgetting systems declined.
- Qualitative examples demonstrated successful generalization of learned relevance rules (e.g., for "valuable items").
- Live deployment on Armar-7 confirmed manageability of delays (average 47 ± 41 seconds for online tree construction) and the asynchronous forgetting mechanism's ability to control tree size without blocking real-time operations. Most observed failures were attributed to retrieval errors within the EMV module rather than forgotten information.

### 5. Significance and Potential Impact

The H²-Emv framework contributes to the field of robotics by addressing the challenge of scalable and personalized episodic memory for lifelong robot operation. Its significance and potential impact include:

- **Enabling Lifelong Robot Deployment:** By incorporating selective forgetting and online memory construction, H²-Emv provides a solution to the fundamental problem of unbounded memory growth, which is critical for robots deployed over extended periods. This moves towards more practical and sustainable autonomous agents.
- **Personalized Human-Robot Interaction:** The ability to learn user-specific relevance definitions from natural language feedback allows the robot's memory to adapt to individual preferences and evolving task priorities. This personalization enhances the quality and relevance of robot verbalizations, fostering more natural and effective long-term human-robot collaboration.
- **Improved Efficiency and Responsiveness:** The reduction in memory size (45%) and query-time computational load (35%) directly translates to faster response times for user questions. This is crucial for interactive applications where latency is a critical factor. The asynchronous nature of online construction and forgetting also optimizes resource utilization.
- **Adaptive Memory Management:** The system's capacity to improve its performance over time (e.g., 70% accuracy increase in second-round queries) demonstrates robust adaptive learning. This ensures that the robot's memory becomes more aligned with user needs the longer it operates and interacts.
- **Robust Framework for Future Development:** H²-Emv provides an extensible architecture that can be further developed to incorporate more complex forms of multimodal feedback, generalize relevance learning across different modalities, address multi-user scenarios, and integrate advanced cognitive science models of memory (e.g., mechanisms for prioritizing surprising or emotionally salient events).
- **Practical Applicability:** The successful transfer and deployment on a real-world humanoid robot, Armar-7, indicates the system's potential for practical application in realistic human environments, moving beyond simulated testbeds. While acknowledging current limitations related to LLM inference delays, the framework is positioned to benefit from future advancements in real-time language models.
- **Interpretability of Relevance:** The use of natural language rules for relevance estimation allows for direct inspection and manual modification, which can be beneficial for debugging and fine-tuning the robot's memory behavior.
