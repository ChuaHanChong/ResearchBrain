# Learning to Forget -- Hierarchical Episodic Memory for Lifelong Robot Deployment

> [!summary] Summary
> A new framework, H^2-Emv, equips humanoid robots with a scalable and personalized episodic memory by combining online hierarchical memory construction with an incrementally learned, relevance-based forgetting mechanism. This approach led to a 45% reduction in memory size and 35% less query-time compute, while improving question-answering accuracy by 70% through adaptive user feedback.

## Problem

- Robots in lifelong deployment face prohibitive memory growth and slow query times due to the continuous generation of vast amounts of multimodal data.
- Existing artificial episodic memory systems lack robust mechanisms for selective, relevance-based forgetting, leading to inefficient memory management unlike human cognition.
- The subjective nature of "relevance" necessitates adaptive, personalized memory retention strategies rather than static, pre-defined metrics for effective human-robot interaction.

## Method

- An **H^2-Emv** architecture is introduced for online, incremental construction of a ==hierarchical episodic memory==, structuring raw observations into recursively summarized nodes.
- A ==decay-based forgetting mechanism== selectively removes expired memory nodes by utilizing a ==Large Language Model (LLM)== to estimate a numeric relevance factor based on node content, context, and learned rules.
- A ==feedback-based relevance learning== component dynamically updates natural-language ==relevance rules== from user interactions, enabling the system to personalize both memory summarization and forgetting processes.

## Results

- H^2-Emv achieved a **45%** reduction in memory size and **35%** lower query-time computation compared to non-forgetting systems over long histories.
- Question-answering accuracy improved by **70%** in second-round queries after user feedback, demonstrating the system's successful adaptation to user-specific relevance.
- The framework transferred effectively to real-world humanoid robot deployment (Armar-7), showing sustained performance improvements and efficient memory management on complex, long-term data.

## Takeaways

> [!tip] Key Insights
> - Online hierarchical memory construction is crucial for robustly handling continuous data streams and creating memory structures compatible with efficient, relevance-based forgetting mechanisms.
> - Integrating user feedback to incrementally learn natural-language relevance rules significantly improves the effectiveness of both selective forgetting and memory summarization, adapting to user-specific priorities.
> - Relevance-based forgetting, when guided by learned user preferences, allows for efficient memory management (reduced size and compute) while enabling performance improvements over time, compensating for initial information loss.
