# CityNavAgent: Aerial Vision-and-Language Navigation with Hierarchical Semantic Planning and Global Memory

> [!summary] Summary
> CityNavAgent introduces a comprehensive approach for aerial Vision-and-Language Navigation in urban environments, allowing unmanned aerial vehicles (UAVs) to follow natural language instructions. The system, developed through a modular architecture, achieves robust zero-shot navigation capabilities by integrating open-vocabulary perception, hierarchical semantic planning, and a global memory module, outperforming existing state-of-the-art methods on aerial VLN benchmarks.

## Problem

- Existing Vision-and-Language Navigation (VLN) methods primarily focus on indoor environments and struggle with the unique challenges of complex urban aerial navigation.
- Aerial navigation lacks predefined navigation graphs, involves an exponentially larger continuous action space, and requires understanding complex urban semantics for long-horizon planning.
- Developing AI agents for urban aerial navigation necessitates zero-shot capabilities to operate in new environments without extensive pre-training.

## Method

- **CityNavAgent** proposes a modular architecture consisting of an ==Open-Vocabulary Perception Module==, a Hierarchical Semantic Planning Module (HSPM), and a Global Memory Module.
- The Open-Vocabulary Perception Module uses GPT-4V, GroundingDINO, and semantic segmentation to generate 3D semantic point clouds, enabling recognition of objects and landmarks without predefined vocabularies.
- The HSPM breaks down complex instructions into landmark, object, and motion-level subgoals, while the Global Memory Module maintains a topological graph of historical trajectories to improve navigation efficiency and spatial awareness.

## Results

- CityNavAgent achieved a Success Rate (SR) of **63.8%** and Success weighted by Path Length (SPL) of **48.7%** on AirVLN-S, and SR of **58.4%** and SPL of **45.3%** on AirVLN-Enriched, outperforming state-of-the-art methods.
- Ablation studies confirmed that removing the Hierarchical Semantic Planning Module (HSPM) reduced SR by **18.5%**, Global Memory Module by **15.2%**, and Open-vocabulary Perception by **22.7%**, demonstrating the contribution of each component.
- The system exhibits robust zero-shot navigation capabilities, enabling operation in diverse urban settings without environment-specific pre-training.

## Takeaways

> [!tip] Key Insights
> - Decomposing long-horizon navigation tasks into a hierarchy of landmark, object, and motion subgoals effectively manages complexity in continuous aerial environments.
> - Integrating open-vocabulary perception with LLMs allows the agent to understand diverse urban semantics without requiring prior training on specific environments.
> - A global memory module, storing historical trajectories in a topological graph, enhances navigation efficiency and robustness by enabling the reuse of successful paths and improved spatial awareness.

## Detailed Report

### 1. Introduction

Vision-and-Language Navigation (VLN) represents a challenging task requiring AI agents to navigate environments by following natural language instructions while processing visual inputs. While VLN has shown impressive progress in indoor environments, aerial navigation in complex urban environments presents unique challenges that existing approaches struggle to address.

CityNavAgent introduces a comprehensive approach to aerial VLN in urban environments. It enables unmanned aerial vehicles (UAVs) to navigate urban settings using natural language instructions without requiring pre-training on specific environments. This zero-shot capability is crucial for real-world applications where pre-training on every possible environment is impractical.

### 2. Challenges in Aerial Navigation

Aerial navigation differs fundamentally from traditional indoor VLN tasks in several key aspects:

1. **Lack of Navigation Graphs**: Indoor VLN typically relies on predefined navigation graphs, which are unavailable in continuous aerial settings.

2. **Exponential Action Space**: The continuous nature of aerial environments creates an exponentially larger action space for long-horizon exploration.

3. **Complex Urban Semantics**: Urban environments contain diverse buildings, landmarks, and structures that must be recognized and understood.

4. **Long-Horizon Planning**: Navigation instructions often involve traversing significant distances with multiple waypoints and landmarks.

These challenges necessitate a new approach that combines semantic understanding, hierarchical planning, and memory mechanisms to enable effective aerial navigation.

### 3. System Architecture

CityNavAgent employs a modular architecture with three primary components:

1. **Open-Vocabulary Perception Module**: Processes visual inputs to identify relevant objects and structures in the scene.

2. **Hierarchical Semantic Planning Module (HSPM)**: Breaks down complex navigation tasks into manageable sub-goals at three levels: landmark, object, and motion.

3. **Global Memory Module**: Maintains a topological graph of historical trajectories to enhance navigation efficiency.

### 4. Open-Vocabulary Perception Module

The perception module leverages a combination of large language models and computer vision techniques to extract semantic information from the visual input:

1. **Image Captioning**: Uses GPT-4V to generate detailed captions for panoramic view images, providing a semantic description of the scene.

2. **Object Detection**: Employs GroundingDINO to identify bounding boxes around objects mentioned in the captions.

3. **Semantic Segmentation**: Utilizes a segmentation model to generate fine-grained semantic masks for detected objects.

4. **Geometric Projection**: Projects semantic masks and depth information into a 3D semantic point cloud.

This process enables the agent to recognize objects and landmarks without being constrained to a predefined vocabulary, allowing for true open-vocabulary perception.

The 3D semantic point cloud provides a rich representation of the environment that supports both semantic reasoning and spatial planning. The point cloud includes information about the type, location, and size of objects, which is crucial for identifying landmarks and planning paths.

### 5. Hierarchical Semantic Planning Module

The HSPM addresses the complexity of long-horizon navigation by decomposing the task into a hierarchy of planning problems:

#### 5.1. Landmark-level Planning

At the highest level, landmark planning decomposes the long-horizon navigation instruction into a sequence of landmark subgoals. The landmark planner analyzes the natural language instruction and identifies key landmarks mentioned in the route:

```
Input: "Go straight to the telephone booth at the end of the road. Then find the white statue on your right."
Output: ["telephone booth at the end of the road", "white statue on your right"]
```

This landmark decomposition makes the navigation task more manageable by providing clear intermediate targets.

#### 5.2. Object-level Planning

For each landmark subgoal, the object-level planner identifies relevant objects in the scene that can guide the agent toward the landmark. This is achieved by reasoning about spatial relationships and visual cues:

```
Input: Current observation and next landmark "telephone booth"
Output: "Look for street signs, traffic lights, and buildings that lead toward the end of the road."
```

The object planner identifies an "object region of interest" (OROI) that will best lead the agent toward the next landmark, acting as a local attractor to guide navigation.

#### 5.3. Motion-level Planning

The motion planner converts the high-level guidance from the object planner into executable waypoints for the UAV. It calculates the optimal trajectory to reach the identified OROI while avoiding obstacles:

```python
def motion_planner(current_position, target_oroi, point_cloud):
    # Calculate optimal waypoint sequence
    waypoints = []
    obstacle_map = extract_obstacles(point_cloud)

    # A* path planning to target
    path = a_star_search(current_position, target_oroi, obstacle_map)

    # Convert path to executable waypoints
    for point in path:
        waypoints.append((point.x, point.y, point.z))

    return waypoints
```

The motion planner uses a combination of A* search and potential field methods to generate smooth and obstacle-free trajectories.

### 6. Global Memory Module

The Global Memory Module addresses the challenge of maintaining spatial awareness during navigation by storing and utilizing historical trajectory information:

1. **Memory Graph Representation**: Maintains a topological graph where nodes represent locations with associated visual observations, and edges represent viable paths between locations.

2. **Graph Update Mechanism**: When the agent navigates close to a previously visited location, it fuses the current trajectory with the historical memory graph.

3. **Graph Search**: When given a target description, the module searches the memory graph to find relevant historical observations and trajectory information:

```
Query: "Find path to phone booth"
Result: [Node_23 → Node_28 → Node_32] with confidence 0.7
```

The global memory provides several benefits:
- Reduces the action space by reusing successful navigation strategies
- Enables backtracking and global path optimization
- Improves navigation robustness through experience accumulation

### 7. Experimental Results

CityNavAgent was evaluated on two benchmarks:

1. **AirVLN-S**: A standard benchmark for aerial navigation
2. **AirVLN-Enriched**: A newly created dataset with more detailed and complex instructions

The evaluation used standard metrics for VLN tasks:
- **Success Rate (SR)**: Percentage of successful navigation episodes
- **Success weighted by Path Length (SPL)**: SR weighted by the ratio of shortest path length to actual path length
- **Navigation Error (NE)**: Average distance between final position and target

CityNavAgent significantly outperformed existing state-of-the-art methods on both benchmarks:

| Method | AirVLN-S SR (%) | AirVLN-S SPL (%) | AirVLN-Enriched SR (%) | AirVLN-Enriched SPL (%) |
|------------------|-----------------|------------------|------------------------|--------------------------|
| Random | 12.5 | 5.8 | 10.2 | 4.6 |
| VLN-BERT | 38.7 | 25.9 | 34.2 | 22.5 |
| CLIP-Nav | 45.1 | 32.4 | 41.5 | 30.2 |
| CityNavAgent | **63.8** | **48.7** | **58.4** | **45.3** |

The ablation studies demonstrated the importance of each component:
- Removing the HSPM reduced success rate by 18.5%
- Removing the Global Memory Module reduced success rate by 15.2%
- Removing the Open-vocabulary Perception reduced success rate by 22.7%

These results confirm that each module plays a crucial role in the system's overall performance.

### 8. Limitations and Failure Cases

Despite its impressive performance, CityNavAgent faces several challenges:

1. **Instruction Ambiguity**: When instructions contain ambiguous references (e.g., "white building" in a city with multiple white buildings), the agent may identify the wrong target.

2. **Perception Failures**: Visual perception can fail in challenging conditions, such as when identifying reflective buildings or small objects at a distance.

3. **Reasoning Failures**: The agent sometimes struggles with complex spatial reasoning, particularly when instructions involve subtle distinctions or multiple sequential steps.

4. **Computational Requirements**: The current implementation relies on external APIs for LLM-based reasoning, which introduces latency and connectivity dependencies.

### 9. Impact and Applications

CityNavAgent opens up possibilities for numerous real-world applications:

1. **Search and Rescue**: UAVs could navigate complex disaster areas following natural language instructions from emergency responders.

2. **Urban Delivery**: Enabling aerial delivery vehicles to navigate cities based on human-provided directions.

3. **Infrastructure Inspection**: Facilitating inspection of bridges, buildings, and other infrastructure through intuitive language commands.

4. **Aerial Photography**: Allowing photographers to position drones through natural language instructions rather than manual controls.

The zero-shot capabilities of CityNavAgent are particularly important for these applications, as they enable deployment in new environments without requiring environment-specific training.

### 10. Conclusion

CityNavAgent represents a significant advancement in aerial vision-and-language navigation by introducing a modular architecture that combines open-vocabulary perception, hierarchical semantic planning, and global memory. This approach effectively addresses the unique challenges of aerial navigation in urban environments, enabling robust zero-shot navigation capabilities.

The hierarchical planning approach effectively breaks down complex navigation tasks into manageable components, while the global memory module enhances navigation efficiency by leveraging historical trajectory information. Together, these components enable CityNavAgent to achieve state-of-the-art performance on aerial VLN benchmarks.

Future work could focus on improving the system's robustness to instruction ambiguity, enhancing perception capabilities in challenging visual conditions, and developing more efficient on-device implementations that reduce dependencies on external APIs. Additionally, exploring the transfer of these capabilities to real-world UAV platforms represents an important direction for practical deployment.
