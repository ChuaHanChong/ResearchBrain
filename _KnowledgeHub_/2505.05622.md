# CityNavAgent: Aerial Vision-and-Language Navigation with Hierarchical Semantic Planning and Global Memory

> [!summary] Summary
> CityNavAgent introduces a comprehensive approach for aerial Vision-and-Language Navigation in urban environments, allowing unmanned aerial vehicles (UAVs) to follow natural language instructions. The system, developed through a modular architecture, achieves robust zero-shot navigation capabilities by integrating open-vocabulary perception, hierarchical semantic planning, and a global memory module, outperforming existing state-of-the-art methods on aerial VLN benchmarks.

## Problem

- Existing Vision-and-Language Navigation (VLN) methods primarily focus on indoor environments and struggle with the unique challenges of complex urban aerial navigation.
- Aerial navigation lacks predefined navigation graphs, involves an exponentially larger continuous action space, and requires understanding complex urban semantics for long-horizon planning.
- Developing AI agents for urban aerial navigation necessitates zero-shot capabilities to operate in new environments without extensive pre-training.

## Method

- **CityNavAgent** proposes a modular architecture consisting of an ==Open-Vocabulary Perception Module==, a Hierarchical Semantic Planning Module (HSPM), and a Global Memory Module.
- The Open-Vocabulary Perception Module uses GPT-4V, GroundingDINO, and semantic segmentation to generate 3D semantic point clouds, enabling recognition of objects and landmarks without predefined vocabularies.
- The HSPM breaks down complex instructions into landmark, object, and motion-level subgoals, while the Global Memory Module maintains a topological graph of historical trajectories to improve navigation efficiency and spatial awareness.

## Results

- CityNavAgent achieved a Success Rate (SR) of **63.8%** and Success weighted by Path Length (SPL) of **48.7%** on AirVLN-S, and SR of **58.4%** and SPL of **45.3%** on AirVLN-Enriched, outperforming state-of-the-art methods.
- Ablation studies confirmed that removing the Hierarchical Semantic Planning Module (HSPM) reduced SR by **18.5%**, Global Memory Module by **15.2%**, and Open-vocabulary Perception by **22.7%**, demonstrating the contribution of each component.
- The system exhibits robust zero-shot navigation capabilities, enabling operation in diverse urban settings without environment-specific pre-training.

## Takeaways

> [!tip] Key Insights
> - Decomposing long-horizon navigation tasks into a hierarchy of landmark, object, and motion subgoals effectively manages complexity in continuous aerial environments.
> - Integrating open-vocabulary perception with LLMs allows the agent to understand diverse urban semantics without requiring prior training on specific environments.
> - A global memory module, storing historical trajectories in a topological graph, enhances navigation efficiency and robustness by enabling the reuse of successful paths and improved spatial awareness.
