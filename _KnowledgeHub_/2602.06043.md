# Shared LoRA Subspaces for almost Strict Continual Learning

> [!summary] Summary
> Researchers at Johns Hopkins University developed "Share," a Parameter-Efficient Continual Finetuning (PaCT) framework that dynamically updates a single, shared low-rank subspace for large pre-trained models. Operating without data replay or increased model size, Share achieves up to 100x parameter reduction and 281x memory savings while maintaining performance comparable to non-continual LoRA and demonstrating backward knowledge transfer in various tasks.

## Problem

- Large pre-trained models require computationally expensive and memory-intensive fine-tuning for new tasks, often leading to catastrophic forgetting of previous knowledge.
- Existing Parameter-Efficient Fine-Tuning (PEFT) methods like LoRA often necessitate storing separate adapters for each task, resulting in a growing memory footprint.
- Traditional continual learning approaches typically rely on data replay, model expansion, or increasing model size, which violate strict continual learning constraints.

## Method

- The "Share" framework proposes a Parameter-Efficient Continual Finetuning (PaCT) approach that learns and dynamically refines a single, shared low-rank subspace across tasks.
- It replaces numerous task-specific LoRA adapters with a continually evolving representation, using Singular Value Decomposition (SVD) to identify and update principal basis vectors.
- Knowledge is integrated by analytically recalculating task coefficients for all tasks onto the newly updated subspace, operating without data replay or an increasing model size.

## Results

- Achieved up to 100x parameter reduction and 281x memory savings compared to standard LoRA methods for multi-task adaptation.
- Demonstrated performance comparable to or marginally exceeding non-continually trained LoRA and upper-bound baselines, under strict replay-free conditions, including evidence of backward knowledge transfer (e.g., CoLA score improving from 56.00 to 59.81).
- Maintained robust performance across diverse modalities, including natural language understanding (GLUE), image classification, 3D pose estimation, and text-to-image generation, and effectively handled asynchronous learning of multiple adapters.

## Takeaways

> [!tip] Key Insights
> - LoRA adapters for diverse tasks and modalities can be effectively represented and continually learned within a common, shared low-rank subspace.
> - Dynamically refining this shared subspace and analytically recalculating task coefficients enables backward knowledge transfer, where performance on older tasks can improve after learning new ones.
> - Strict continual learning, characterized by replay-free operation and minimal parameter growth, is achievable with high efficiency and performance for large pre-trained models.
