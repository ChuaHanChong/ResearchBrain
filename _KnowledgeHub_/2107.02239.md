# Vision Xformers: Efficient Attention for Image Classification

> [!summary] Summary
> Researchers from IIT Bombay developed "Vision X-formers," a family of vision transformer architectures that integrate linear attention, convolutional embeddings, and Rotary Position Embedding. These models achieve comparable or improved classification accuracy while significantly reducing GPU memory consumption by up to 7x and lowering data requirements.

## Problem

- Standard Vision Transformers (ViTs) suffer from quadratic computational and memory complexity in their self-attention mechanism, making them impractical for high-resolution images or resource-constrained environments.
- Vanilla ViTs lack inherent inductive biases for 2D image structures, necessitating vast amounts of training data to achieve competitive performance.
- The high computational demands and large model sizes of state-of-the-art transformer models limit their accessibility for researchers and practitioners with limited computing resources.

## Method

- Replacing standard quadratic self-attention with ==efficient linear attention mechanisms== (Performer, Linformer, Nyströmformer) to create "Vision X-formers" (ViX).
- Integrating convolutional layers as initial embedding layers into ViX models, forming =="Hybrid ViX"==, to introduce image-specific inductive biases.
- Incorporating ==Rotary Position Embedding (RoPE)== instead of standard 1D learnable position embeddings to improve the encoding of positional information within vision sequences.

## Results

- Vision Nyströmformer (ViN) achieved a **~16%** improvement in Top-1 accuracy over vanilla ViT on CIFAR-10 (**65.06%** vs. **56.81%**) while using less than one-third of ViT's GPU memory.
- Hybrid ViX models, incorporating convolutional embeddings, delivered accuracy gains of up to **~28%** (e.g., Hybrid ViP on CIFAR-10) with only a slight increase in parameters and negligible memory impact.
- The developed Vision X-formers demonstrated up to a **7x** reduction in GPU memory requirements (e.g., Vision Linformer used **2.2 GB** compared to ViT's **14.1 GB** for the same batch size).

## Takeaways

> [!tip] Key Insights
> - Linear attention mechanisms can match or surpass the performance of quadratic attention while drastically reducing computational and memory resources, making transformers more accessible.
> - Introducing convolutional embeddings provides crucial inductive biases for image data, leading to substantial accuracy gains across various transformer architectures, particularly in data-scarce settings.
> - Rotary Position Embedding (RoPE) effectively captures positional information, further enhancing the classification accuracy of both linear and hybrid vision transformers without increasing parameter count.
