# Emergence of Spatial Representation in an Actor-Critic Agent with Hippocampus-Inspired Sequence Generator

> [!summary] Summary
> A study from the University of Freiburg presents a model where hippocampal sequences and spatial representations emerge from the intrinsic recurrent circuitry of the CA3 region, acting as a temporal memory buffer. When integrated into an actor-critic reinforcement learning agent for egocentric navigation, the model develops biologically plausible place fields and remapping, exhibiting enhanced navigation performance, especially under sparse sensory input, compared to standard recurrent networks.

## Problem

- Existing computational models often describe the function of hippocampal sequences but lack a direct, mechanistic explanation for their generation from intrinsic circuitry.
- Understanding how robust spatial representations are formed for navigation under sparse or noisy sensory input, given the extreme sparsity of Dentate Gyrus (DG) activity.
- Integrating neurobiologically inspired mechanisms into modern reinforcement learning (RL) frameworks to evaluate their functional utility in goal-directed tasks.

## Method

- An actor-critic RL agent was implemented for ==egocentric visual navigation== in a 3D maze environment.
- The Dentate Gyrus (DG) was modeled as a sparsification module, converting visual inputs into sparse representations consistent with biological DG activity.
- The CA3 region was implemented as a fixed, prewired linear recurrent neural network (shift register) designed to intrinsically generate fixed 'theta sequences' from sparse DG inputs, acting as a temporal memory buffer.

## Results

- The CA3 sequence-generating agent reliably solved continuous maze navigation tasks, outperforming LSTM and state-space model agents under sparse DG input conditions, and demonstrating robustness to increasing input noise.
- Through learning, units in the DG, CA3, and decoder layers developed spatially localized place fields, which exhibited remapping with changes in reward location and showed distance-dependent spatial tuning in CA3.
- Analysis confirmed the causal role of units with high spatial information for agent performance, and population-level spatial kernels in the decoder layer demonstrated the emergence of pronounced and smoothly varying spatial representations.

## Takeaways

> [!tip] Key Insights
> - Intrinsic recurrent circuitry, inspired by hippocampal CA3 dynamics, can mechanistically generate temporal sequences that are crucial for building robust spatial representations, even from sparse and transient inputs.
> - A synergistic relationship exists between sparse sensory encoding (DG-like activity) and sequence-generating dynamics (CA3-like), which leads to superior navigation performance under specific sparse input conditions.
> - Biologically plausible hippocampal features, such as localized place fields, distance-dependent spatial kernels, and remapping in response to goal changes, naturally emerge within a goal-directed learning agent leveraging this sequence-generating mechanism.
