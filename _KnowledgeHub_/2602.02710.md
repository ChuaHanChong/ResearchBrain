# Maximum Likelihood Reinforcement Learning

> [!summary] Summary
> Maximum Likelihood Reinforcement Learning (MaxRL), developed by researchers primarily at Carnegie Mellon University, introduces a sampling-based framework that approximates maximum likelihood optimization for tasks with binary outcome feedback. MaxRL demonstrates superior scaling with increased computational resources, mitigates issues like pass@k degradation in Large Language Models (LLMs), and achieves up to 20x test-time scaling efficiency on mathematical reasoning benchmarks by generating a higher number of correct solutions.

## Problem

- Many modern learning problems (e.g., code generation, multi-step LLM reasoning) rely on binary outcome feedback, implicitly defining a likelihood of success, but direct maximum likelihood optimization is precluded by non-differentiable sampling.
- Standard Reinforcement Learning (RL) is used as a workaround but only optimizes a first-order approximation of the true maximum likelihood objective.
- Conventional RL methods lead to issues like underexploration of hard, low-success inputs and 'distribution sharpening' (pass@k degradation) in LLMs, where solution diversity is lost.

## Method

- MaxRL introduces a ==compute-indexed family of objectives== that smoothly interpolates between standard expected reward and exact maximum likelihood, allowing more faithful approximation with increased sampling compute.
- It proposes a simple, ==on-policy gradient estimator== that averages score functions exclusively from successful trajectories, proving it to be an unbiased estimator for the compute-indexed MaxRL objective.
- The framework employs a ==control variate for variance reduction== by normalizing rewards with the per-task mean, and provides a unifying weight-function view to characterize various RL objectives.

## Results

- MaxRL closely matches cross-entropy performance in image classification and significantly outperforms REINFORCE on maze navigation, demonstrating superior scaling with additional training compute.
- On GSM8K, MaxRL showed greater resistance to overfitting and pass@k degradation, maintaining healthier output diversity and achieving higher peak performance over longer training durations compared to RLOO and GRPO.
- When training Qwen3 models on mathematical reasoning benchmarks, MaxRL consistently Pareto-dominated GRPO, achieving higher pass@1 while simultaneously improving pass@k, leading to up to **20x** test-time scaling efficiency gains.

## Takeaways

> [!tip] Key Insights
> - Standard RL's objective (expected pass rate) optimizes only the leading (first-order) term of a Maclaurin expansion of the true log-likelihood gradient.
> - The maximum likelihood gradient can be equivalently expressed as the expected score function of a model *conditioned on successful outcomes*.
> - Increasing sampling compute within MaxRL doesn't just reduce variance but directly allows the algorithm to optimize a progressively more accurate approximation of the maximum likelihood objective itself.
