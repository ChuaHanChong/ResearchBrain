# Episodic Memory Model for Learning Robotic Manipulation Tasks

> [!summary] Summary
> A robotic episodic memory model allows industrial robots to acquire complex manipulation tasks from a single human demonstration, enabling semantic understanding and autonomous execution with integrated exception handling. This approach reduces programming effort and enhances robot adaptability and reliability in dynamic manufacturing environments.

## Problem

- Traditional robot programming is complex, time-consuming, and demands specialized expertise, hindering rapid deployment and accessibility.
- Existing machine learning methods, like Learning from Demonstration (LfD) and deep learning, require extensive data for each new skill and often lack robust generalization for complex, complete tasks.
- Industrial applications need highly reliable, predictable, and adaptable robotic systems capable of understanding task logic and handling unforeseen exceptions.

## Method

- Decomposes the robot's environment into modular "elements," each associated with an application-independent finite state machine (FSM) defining its characteristic behaviors.
- Synthesizes an Application State Machine (ASM) by observing state changes during a single human demonstration, semantically recording commands and robot paths (e.g., "Move to Tray").
- Implements a robust exception handling mechanism that allows the robot to detect novel states, request human guidance, and incrementally learn new states and transitions.

## Results

- The system successfully learned a complete machine tending workflow from a single demonstration, including multiple conditional branches, and autonomously executed the task.
- Robots demonstrated semantic understanding of actions (e.g., "pick next available object") and generalized task logic to varying object positions and environmental conditions.
- The integrated exception handling mechanism allowed the robot to detect unknown states (e.g., a full outfeed tray) and incrementally learn from human-demonstrated resolutions.

## Takeaways

> [!tip] Key Insights
> - Modeling tasks through an episodic memory structure, inspired by human cognition, enables robots to learn and retain complex sequences of actions and their underlying logic.
> - Decomposing the robotic work cell into application-independent elements, each governed by its own finite state machine, provides modularity and reusability for task representation.
> - Capturing semantic locations and state changes during demonstrations allows robots to generalize beyond specific coordinates, adapting to variations in the environment.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development of robotic systems for industrial applications has traditionally relied on explicit programming, a process that is often time-consuming, expensive, and requires specialized expertise. Conventional programming methods involve defining all system elements and their interactions through strict instructions, typically taking weeks or months for implementation and verification. Efforts to simplify this include modular programming, template-based frameworks, and graphical programming tools, which aim to enhance reusability and reduce programming burden. However, these methods often remain domain-specific and still necessitate an expert programmer for efficient and reliable deployment across diverse applications.

Recent advancements in machine learning (ML), artificial intelligence (AI), and deep learning (DL) have opened new avenues for making industrial robots more accessible. Learning from Demonstration (LfD), also known as Programming by Demonstration (PbD), is a prominent approach where robots learn tasks by observing human demonstrations. Traditional LfD often involves an offline learning phase, utilizing techniques such as Gaussian Mixture Models (GMM), Bayesian networks, or dynamical system control to learn trajectories or action sequences from collected data. While effective in some scenarios, these methods frequently require substantial amounts of data or prior knowledge for each new skill and may not generalize robustly to unforeseen environmental conditions, leading to unpredictable outcomes.

More advanced LfD paradigms, such as one-shot learning or learning from a single demonstration, aim to reduce data requirements. Some approaches integrate hierarchical task networks and bi-directional communication with a tutor, while others combine meta-learning with imitation using deep learning to leverage past experience for new skills. However, deep learning-based methods, despite their generalization capabilities, typically demand large volumes of diverse training data, posing a challenge for novel robot users or specialized industrial applications. Reinforcement Learning (RL) presents another approach, focusing on sequential decision-making problems by learning policies, often through automatic demonstration generation and methods like Deep Q-networks.

Drawing inspiration from cognitive science, particularly human memory models, is another direction in robotics research. Human long-term memory is broadly categorized into procedural, semantic, and episodic memory. Procedural memory, associated with unconscious skill acquisition through repetition, is often modeled by artificial neural networks for fast recognition and reaction. Semantic memory stores facts, data, and logical relations, developed through observation and conscious learning, and can be modeled by expert systems or knowledge graphs. Episodic memory, the focus of this paper, stores experiences and event sequences, allowing for their conscious recall and combination into more abstract constructs. Various computational models for episodic memory have been proposed, often utilizing neural networks, knowledge graphs, or state-based representations to manage and recall experience sequences.

The current work addresses a recognized gap: despite these innovations, no single method has achieved the degree of reliability, predictability, and generality required for widespread adoption in the manufacturing industry. The paper proposes an episodic memory model designed to enable industrial robots to learn complex manipulation tasks from a single human demonstration, similar to how an apprentice learns, thereby reducing programming effort and enhancing adaptability in industrial settings while maintaining high standards of reliability and accuracy.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop an episodic memory model that enables industrial robots to learn and perform complex manipulation tasks from a single demonstration. This approach aims to replicate the human learning process of an apprentice, who observes a task once and then can reproduce it accurately.

The motivation for this work stems from several challenges inherent in conventional industrial robot programming and existing machine learning-based approaches:

- **Simplifying Robot Programming:** Traditional robot programming is often described as a burden due to its complexity, requiring weeks or months of specialized effort for implementation and verification. The authors seek to simplify or eliminate this programming effort, making robots more accessible to inexperienced users and reducing deployment time.
- **Addressing Limitations of Deep Learning and LfD:** While deep learning and standard LfD methods are effective for skill learning, they typically demand large amounts of diverse training data. This makes them less practical for teaching complete, complex tasks, such as assembly or machine tending, which involve intricate logic and a sequence of related sub-tasks. The proposed model aims to overcome this data-intensive requirement by learning from a single demonstration.
- **Enabling Complex Task Comprehension:** Current methods often struggle with teaching robots to understand and perform complete tasks that require complex logic. The objective is for the robot to comprehend sequences of actions, decompose tasks into sub-tasks, retain essential steps, and recall how these steps were performed, moving beyond mere trajectory replication.
- **Ensuring Industrial Reliability and Predictability:** Industrial manufacturing demands extremely high levels of predictability, reliability, and accuracy. The authors are motivated to build a model that meets these stringent industrial requirements, differentiating their approach from research methods that may lack the robustness for real-world production environments.
- **Facilitating Generalization and Adaptability:** The goal is not just to mimic a demonstrated path but for the robot to understand the semantic meaning of actions and generalize. For instance, instead of learning to pick from a specific coordinate, the robot should learn to pick the "next available object." This enables adaptability to variations in the environment, such as different tray configurations or test results, without needing explicit reprogramming for each scenario.
- **Integrating Exception Handling:** Real-world industrial environments are dynamic and can present unforeseen circumstances. The research aims to equip the robot with the ability to detect unknown conditions, stop, request human intervention, and then learn from that intervention, allowing for continuous and incremental task improvement.
- **Leveraging Cognitive Models:** By explicitly drawing inspiration from human episodic memory, the authors seek to imbue robots with a structured way to store and recall experiences, thereby providing a more human-like cognitive ability for ordering and structuring knowledge for future use.

In summary, the core motivation is to create an economic, efficient, and convenient method for teaching industrial robots complex tasks with high reliability, significantly reducing the dependency on expert programmers and extensive training data, while incorporating mechanisms for adaptive learning from environmental changes and exceptions.

### 3. Methodology and Approach

The proposed methodology centers on an episodic memory model that enables robots to learn complex manipulation tasks from a single demonstration, analogous to an apprentice learning from observation. The approach involves decomposing the robot's environment into a set of interacting "elements," each governed by a finite state machine, and then synthesizing an Application State Machine (ASM) from observed demonstrations.

**A. System Decomposition and Element State Machines:**
The first step involves conceptually separating the robot's work environment into distinct "elements," such as the robotic arm, grippers, trays, and a test machine. These elements are identified either through a vision system or configured manually during commissioning. Crucially, each element is associated with an application-independent finite state machine (FSM). These element FSMs encode the characteristic behavior of their respective components, including discrete physical and operational states (e.g., "Machine Full," "Ready to Get"), conditions that trigger state transitions, and specific commands (e.g., "open door," "Grip"). Certain states are designated as "active" to signal interaction with other elements, such as "Getting Object" or "Giving Object" for a test machine, indicating when it is interacting with the robot. This modular design promotes reusability across different applications. The system also integrates contextual information, such as test results (e.g., "Result Positive" or "Result Negative") into the test machine's states, allowing for conditional logic.

**B. Learning Work Instructions from Single Demonstration:**
The learning process begins with a human tutor demonstrating the desired task sequence using the robot, for instance, through lead-through programming. During this demonstration, a data collector module continuously gathers information from all observable elements. This raw data is then processed by a data augmentation module to extract the current state of each element. The system specifically monitors changes in element states, such as robot motion (RM), gripper motion (GM), and standstill (SS).

The core of learning involves constructing an Application State Machine (ASM) dynamically:
1. **Initial ASM States:** The ASM is initialized with common states like "Start," "Init," "System Config," "Idle," and an "Exception" state.
2. **State and Transition Synthesis:** As the demonstration progresses, the learning system observes changes in element states and synthesizes a sequence of states for the ASM. Each new observed state combination forms a new state in the ASM, with a transition from the previous state.
3. **Command and Path Recording:** Any commands issued by the element state machines (e.g., "Grip," "MoveL") are recorded and associated with the corresponding ASM state. For movable elements like the robot, path information is captured. Significantly, location information for robot motions is recorded semantically (e.g., {"Move to", "Tray"}) rather than as absolute metric coordinates. The semantic location is inferred based on which element is "active" when the robot completes a move.
4. **Loop and Branch Identification (Task State Pruning):** After the demonstration, the initially linear ASM chain undergoes a "pruning" process. The system identifies duplicate states based on their properties (type, transition condition, commands). When duplicates are found, the later state in the chain is removed, and transitions are re-pointed to the earlier state, forming loops. This process distinguishes between erroneous loops (e.g., due to measurement jitter) and genuine loops or branches that represent repeated process steps or variations (e.g., demonstrating the task for both "good" and "bad" test results, leading to a branching path in the ASM). This allows the robot to learn conditional logic without explicit programming.

**C. Execution of Learned Task:**
Once an application is learned and the ASM is generated, it is stored in a library. For execution, the system continuously monitors its work cell elements. Upon detecting a trigger (e.g., a full input tray), the system loads and executes the corresponding ASM. The robot's actions are guided by the ASM, transitioning between states as the underlying elements change. During execution, semantic locations recorded in the ASM are replaced with known metric locations for the elements.

**D. Exception Handling:**
A key aspect of the methodology is its approach to unforeseen situations. If the ASM encounters a state combination during execution that was not part of the initial demonstration, it transitions to a special "Exception state." In this state, the system interacts with the user to determine the next course of action. The user can either direct the system to continue (implying the unseen state is now an allowed transition) or request to "learn" the new condition. If the latter, the user demonstrates the resolution, and the system re-enters learning mode to add new states and transitions to the ASM, enabling continuous, incremental learning.

**E. Software Platform Architecture:**
The system's software architecture utilizes a message broker (RabbitMQ) as its core for flexible and asynchronous communication between various components (robot, trays, test machine). Messages are standardized in JSON format for cross-language compatibility. Each physical component is encapsulated by a "driver," which consists of three sub-modules: a Facade (interface to the message broker), a Decorator (implements logic and representation of the element), and a Bridge (provides the communication link to the physical element). As an example, the ABB YuMi robot driver handles two arms and grippers, providing functionalities like independent control, lead-through programming support, real-time data access, and synchronous command execution, managed through multiple dedicated threads communicating with the robot controller via TCP/IP.

### 4. Main Findings and Results

The research successfully implemented and validated the proposed episodic memory model through a machine tending application using an ABB IRB 14000 (YuMi) collaborative robot equipped with smart grippers. The experimental setup involved simple wooden blocks, infeed and outfeed trays, and a simulated test machine.

The key findings and results are as follows:

- **Successful One-Shot Task Learning:** The system demonstrated the ability to learn a complete machine tending workflow from a single demonstration for each possible branch of the task. This workflow involved picking parts from an infeed tray, placing them into a test machine, waiting for a simulated test result (good or bad), picking the part from the machine, and then sorting it into the appropriate outfeed tray based on the result.
- **Semantic Understanding and Generalization:** A significant result was the robot's capacity for semantic understanding of actions rather than merely replicating taught paths. For example, during execution, the robot would pick the "next available object" from the infeed tray and place it into the "next available empty slot" in the target outfeed tray. This demonstrated generalization beyond specific, pre-taught coordinates or object positions, implying a higher-level comprehension of the task logic.
- **Autonomous Execution of Learned Task:** After a single demonstration (covering both possible test outcomes), the robot was able to autonomously execute the entire machine tending process. The system monitored changes in the environment (e.g., the introduction of a full infeed tray) to trigger and guide the execution of the learned application state machine.
- **Effective Exception Handling:** The system's ability to handle unforeseen circumstances was validated. When the robot encountered a novel situation—specifically, an outfeed tray becoming full, a condition not demonstrated during the initial training—it detected this "yet unknown state." The system stopped execution and prompted for human intervention, illustrating its capacity to identify deviations from learned patterns and request guidance. This mechanism is crucial for continuous, incremental learning in dynamic industrial environments.
- **Reduced Programming Effort:** The approach demonstrated that explicit programming instructions for the machine tending application were not required. The entire logic and execution sequence were derived automatically from the single demonstration, significantly reducing the human programming burden.
- **Modular and Reusable Element Models:** The design principle of element-specific finite state machines was validated. These FSMs, describing the generic behavior of components like grippers, trays, or test machines, were indeed independent of the specific application, suggesting their reusability across various robotic tasks.
- **Robust Software Platform:** The underlying software architecture, utilizing a message broker and modular drivers, facilitated robust communication and interaction between diverse system components, supporting the real-time data collection and execution required for the learning process.

In essence, the experiments confirmed that the episodic memory model allowed the robot to not only perform the demonstrated steps but also to understand the underlying logic and generalize across specific instances, and crucially, to identify and learn from unexpected events.

### 5. Significance and Potential Impact

This research presents a significant contribution to the field of industrial robotics and cognitive AI, with several potential impacts:

- **Democratization of Robot Programming:** The most immediate impact lies in its potential to dramatically simplify robot programming. By enabling robots to learn complex tasks from a single demonstration, the approach could make industrial automation accessible to non-expert users, reducing the dependency on specialized programmers and lowering entry barriers for small and medium-sized enterprises (SMEs).
- **Accelerated Deployment and Flexibility:** The ability to teach a robot a new task in a single demonstration, instead of weeks or months of programming, can significantly accelerate the deployment of robotic systems in manufacturing. This also enhances the flexibility of production lines, allowing for rapid re-tasking or adaptation to new product variants or process changes.
- **Enhanced Robot Adaptability and Robustness:** The semantic understanding of tasks, rather than mere trajectory recall, allows robots to generalize beyond the exact demonstrated conditions. This makes robotic systems more adaptable to variations in the workspace (e.g., object locations, changes in tray content). Furthermore, the integrated exception handling mechanism allows robots to detect unforeseen circumstances and learn from human intervention, leading to more robust and reliable operation in dynamic industrial environments.
- **Advancement in Cognitive Robotics:** By directly implementing a model inspired by human episodic memory, this work contributes to the development of more "cognitive" robots. It moves beyond reactive control towards systems that can comprehend, retain, and reason about past experiences and task logic, mimicking a fundamental aspect of human intelligence. This could open avenues for more intuitive human-robot collaboration.
- **Bridging the Gap between AI Research and Industrial Needs:** The research addresses a critical need in industrial automation: bridging the gap between data-intensive AI approaches (like deep learning) and the practical requirements for high reliability, predictability, and one-shot learning in real-world manufacturing settings. The focus on low-data learning for complex tasks makes this approach particularly relevant for industrial use cases where extensive training data may be impractical to collect.
- **Foundation for Continuous Learning Systems:** The mechanism for incremental learning from exceptions provides a framework for robots to continuously improve their task knowledge over time. As new unexpected situations arise, the robot can be guided to learn appropriate responses, gradually expanding its capabilities and reducing the need for downtime or expert intervention.
- **Reusability and Modularity:** The concept of application-independent element state machines promotes modularity and reusability of robotic components and their behaviors, streamlining the design and integration of complex robotic work cells.

Overall, this research represents a step towards creating more autonomous, intelligent, and user-friendly industrial robots that can adapt and learn in dynamic manufacturing environments with reduced programming overhead and increased operational reliability.
