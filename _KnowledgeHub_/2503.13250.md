# MindEye-OmniAssist: A Gaze-Driven LLM-Enhanced Assistive Robot System for Implicit Intention Recognition and Task Execution

> [!summary] Summary
> MindEye-OmniAssist, developed at Huazhong University of Science and Technology, presents a gaze-driven assistive robot system that leverages LLMs and VFMs to interpret complex, implicit user intentions from gaze patterns. The system successfully executes a wide range of previously undefined tasks, demonstrating a high success rate in intention recognition and action planning.

## Problem

- Traditional gaze-based control systems for assistive robots are limited to basic, predefined tasks and a restricted set of commands.
- Existing methods struggle with robustly recognizing complex, implicit user intentions in open-ended environments.
- Reliance on artificially constructed domain-specific knowledge or fixed object databases severely restricts robot versatility and generalizability.

## Method

- An integrated hardware system combines a head-mounted eye tracker, collaborative robotic arms, and multiple depth cameras for sensing and action.
- A gaze-based implicit intention recognition module utilizes ==YOLO-World (VFM)== for open-vocabulary object detection and a custom Transformer-based network to analyze gaze patterns over objects.
- DeepSeek-R1 (LLM) is used to infer high-level user intentions from sequences of gazed-upon objects and generate robot action plans, with a gaze-driven verbal confirmation mechanism for user feedback.

## Results

- The proposed intention recognition network achieved an average accuracy of **96.52%** (experiment-based) and **93.63%** (subject-based), outperforming Midas-Net and fixation-based methods.
- The MindEye-OmniAssist system demonstrated a **74.5%** overall success rate across 55 trials for diverse, undefined assistive tasks.
- The LLM successfully inferred user intentions in **94.5%** of trials and generated appropriate action plans in **96.2%** of recognized intentions.

## Takeaways

> [!tip] Key Insights
> - Leveraging Vision Foundation Models (VFMs) and Large Language Models (LLMs) enables open implicit intention recognition from gaze, extending beyond predefined tasks.
> - A multi-scale CNN and Transformer-based network, processing extracted gaze features, significantly improves implicit intention recognition accuracy compared to traditional fixation-based methods.
> - LLMs can effectively translate high-level, implicitly inferred user intentions into sequences of low-level robotic actions, providing adaptable task execution.
