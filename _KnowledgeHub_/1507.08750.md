# Action-Conditional Video Prediction using Deep Networks in Atari Games

> [!summary] Summary
> This paper presents deep neural network architectures capable of predicting future image frames in complex, action-dependent Atari game environments for extended periods. The models successfully generate visually realistic long-term predictions and are shown to be useful for controlling pre-trained reinforcement learning agents and enhancing exploration strategies for model-free agents.

## Problem

- Developing models that can predict future visual observations in complex, action-dependent environments like Atari games, which have high-dimensional data and intricate object dynamics.
- Enabling model-based reinforcement learning from raw pixels, as previous video prediction methods often lacked external control inputs or struggled with long-term, high-dimensional sequences.
- Addressing the challenge of predicting the consequences of an agent's actions, which is crucial for planning and efficient learning in reinforcement learning scenarios.

## Method

- Developed two deep neural network architectures (==Feedforward Encoding== and ==Recurrent Encoding with LSTM==) that follow an ==encoding-transformation-decoding== paradigm.
- Integrated action information into the prediction process using ==multiplicative interactions== within the transformation layers, allowing the model to learn different transformations for different actions.
- Employed ==deconvolutional layers== for decoding the action-conditioned features back into high-resolution pixel space to generate the predicted next frame.

## Results

- Proposed deep architectures generated visually-realistic frames for up to **30-500 steps**, outperforming baselines in Mean Squared Error (MSE) over **100-step** predictions.
- When used to replace emulator frames, a pre-trained DQN controller achieved significantly better-than-random scores, indicating the semantic usefulness of the predictions for control.
- An 'informed exploration' strategy, using the predictive model to guide a DQN agent towards least-visited states, improved DQN's performance in **three out of five** games, notably QBert.

## Takeaways

> [!tip] Key Insights
> - The models learned to disentangle objects directly controlled by the agent (high variance factors) from background or autonomously moving objects (low variance factors).
> - Implicitly, the models discovered meaningful relationships between actions, showing positive correlations for similar actions and negative for opposing ones.
> - Curriculum learning with multi-step prediction was effective in stabilizing training and reducing compounding errors for long-term video generation.
