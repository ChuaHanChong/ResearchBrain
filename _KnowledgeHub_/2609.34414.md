# From World Models to World Action Models: Rethinking Next-State Prediction

> [!summary] Summary
> CF-WAM is a world-action model that treats RGB, DINOv3 semantic, depth, and hand-object segmentation videos as interchangeable projections of one future. Each training step samples a single projection through a shared VAE and Mixture-of-Transformers. The same projections let unpaired human and robot data co-train shared dynamics. It reaches 82.50% on RoboCasa-GR1, 82.65% on LIBERO-Plus, and up to 84% in real-world tests.

## Problem

- Existing world models and world-action models fix the next-state target before training, as RGB, a single latent, or a static target mix, locking in one representation's inductive bias.
- Static multi-target designs predict all modalities every step, which raises compute and forces modality-specific features to compete for limited action-conditioning capacity, diluting action-relevant state changes.
- Human-robot transfer relies on staged pretraining, retargeting conversion, or paired demonstrations, because appearance-dominated future targets fail to expose dynamics shared across embodiments.

## Method

- **Dynamic Projection Sampling**: each training sample draws one of four future-state projections (RGB, DINOv3 semantics, depth, hand-object segmentation), all rendered as video and encoded by one shared ==VAE==.
- **Projection-conditioned generation**: a representation prompt appended to the task instruction tells a ==Mixture-of-Transformers== ==video-diffusion== world expert and ==flow-matching== action expert which coordinate system to predict.
- Unpaired Human-Robot learning: EgoDex human clips co-train with robot data via source sampling, and a ==masked action loss== supervises only shared end-effector dimensions for humans and adds joints for robots.

## Results

- RoboCasa-GR1: **82.50%** average success over 24 tasks, **7.33 points** above WALA and **10.5** above FastWAM, with novel pick-and-place reaching **85.00%**.
- Ablation: dynamic sampling of all four projections reaches **79.00%**, versus **76.25%** for the best single state and only **68.75%** for compute-matched static multi-state; adding unpaired human data lifts it to 82.50%.
- LIBERO-Plus zero-shot OOD: **82.65%** average versus FoMoVLA **80.50%** and FastWAM **51.36%**. Real world: the Interaction variant scores **84.00%** versus pi0.5 at **62.33%**, and per-task oracle projection selection reaches **87.00%**.

## Takeaways

> [!tip] Key Insights
> - Rotating supervision targets across training steps can beat predicting all targets jointly, because multi-target heads compete for shared capacity while sampling accumulates complementary constraints without interference.
> - The best future representation is task-dependent: geometry suits precise 3D placement, interaction suits insertion, and appearance suits deformables, which suggests selecting the target per task at inference.
> - Abstract, appearance-light future targets make unpaired human video more useful for robot learning than RGB alone, without retargeting or paired demonstrations for cross-embodiment transfer.

## Detailed Report

### 1. Overview

A robot manipulating objects works from a visual observation and a task instruction. To act well, its forecast of the future should help choose an action, not only show what the scene will look like. The paper argues that a fixed future target, such as RGB, semantics, geometry, or interaction labels, can preserve some action-relevant information while obscuring other parts of the transition. This matters especially when learning jointly from human and robot experience, whose viewpoints, appearances, bodies, and action spaces differ.

The authors keep one world-action model (WAM), called CF-WAM, and train it to predict different descriptions of the same future, one at a time. They do not commit to a single description, and they do not predict all descriptions at once. On RoboCasa-GR1, CF-WAM reports an 82.50% average success rate across 24 tasks. WALA, the strongest prior WAM baseline reported there, reaches 75.17%. The detailed per-task table specifies 50 closed-loop rollouts per task. These are benchmark averages and do not show that the method wins every task.

Additional closed-loop RoboCasa-GR1 trajectories across diverse objects, receptacles, viewpoints, and motions.

### 2. One model, four views

There are four candidate future descriptions:

- visual RGB videos
- semantic videos derived from DINOv3
- geometric depth videos
- interaction segmentation videos

Each training sample selects one of these projections. Every sample starts from the same time-aligned current RGB observation, and only the future sequence changes. A prompt identifies which projection was selected. The same VAE and world/action model handle all of these video-form targets, so the model does not get four separate prediction branches on every example. In the authors' account, this schedule lets complementary constraints accumulate across training steps. That is an interpretation, not a directly observed latent structure.

The same setup supports learning from both humans and robots. Human and robot episodes need not be paired by task, episode, or time. Human wrist motion supervises the shared end-effector action dimensions. Robot-specific joint dimensions are trained from robot data and masked out for human samples.

Overview of CF-WAM: a 1-of-4 representation selector and shared VAE/world expert, a shared world expert and action expert, and end-effector and joint action dimensions for human and robot data, with masked dimensions.

### 3. Does changing the view matter?

The authors tested this with a Dynamic-State ablation on RoboCasa-GR1, measured by success rate. In this ablation, projections are sampled during training and visual prediction is used at inference. Each single-state baseline uses its one representation for both training and inference. Dynamic-State over all four projections reaches 79.00%. The best single-state baseline, Visual, reaches 76.25%.

A second variant, Static Multi-State, predicts all four descriptions at each update. Under a comparison matched by overall training compute, it scores 68.75%, compared with 79.00% for Dynamic-State. The static method has higher per-step computation, so the match holds only at the level of overall compute.

The authors read this gap as interference: simultaneous objectives compete for action-conditioning capacity. The scores and the attention maps below are consistent with that reading, but they do not isolate interference as the only cause.

CF-WAM (top) and Static Multi-State (bottom). Warmer colors indicate video locations receiving stronger action-stream attention. CF-WAM maps appear more localized around manipulation-relevant areas, while static maps appear more diffuse.

Note that these ablations do not include human data, which is part of the full 82.50% model. Under the same visual future-state supervision, adding unpaired human data raises average success from 76.25% to 78.25%. Combining human experience with dynamic supervision reaches 82.50%.

### 4. Changing the forecast

CF-WAM's contribution is not simply adding more targets. It varies the description of the same future across training updates while keeping the model shared. On RoboCasa-GR1, this outperformed both fixed single targets and simultaneous supervision of all four targets. The authors' claim that complementary constraints accumulate remains their interpretation of these measurements.
