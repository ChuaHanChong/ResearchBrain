# Agnostics: Learning to Code in Any Programming Language via Reinforcement with a Universal Learning Environment

> [!summary] Summary
> Agnostics introduces a post-training pipeline for large language models (LLMs) that enables code synthesis in any programming language, particularly low-resource ones, by leveraging a universal reinforcement learning environment. The framework reformulates coding problems into a language-agnostic I/O format and utilizes an efficient code execution sandbox, allowing small LLMs to achieve state-of-the-art performance for Lua, Julia, and R, and significantly improving Fortran and OCaml code generation accuracy on the Ag-LCB-X benchmark.

## Problem

- Large language models (LLMs) for code generation show a significant performance disparity between high-resource and low-resource programming languages.
- The scarcity of pre-training data for low-resource languages limits LLM knowledge and effective fine-tuning.
- Post-training LLMs to improve performance on low-resource languages typically demands extensive, language-specific engineering for datasets, test harnesses, and reinforcement learning infrastructure.

## Method

- **Agnostics** reformulates existing coding datasets into a uniform, ==language-agnostic== input/output (I/O) format, eliminating the need for language-specific unit tests or function signatures.
- A universal reinforcement learning (RL) environment is used, judging code correctness solely by its external I/O behavior, which minimizes per-language engineering effort.
- A robust and efficient code execution sandbox, built with containerization, resource limits, and optimizations like RAM disks and cached containers, verifies generated code in any target language.

## Results

- Agnostics-trained Qwen 3 **4B** and **8B** models achieved state-of-the-art performance on Lua, Julia, and R on the Ag-LCB-X benchmark, rivaling or surpassing larger open-weight models (**16B**–**70B** parameters).
- For OCaml and Fortran, the framework significantly improved base model scores from near zero to approximately **7%** and 15-**17%** respectively on Ag-LCB-X, outperforming some frontier models on Fortran.
- Qualitative analysis revealed a shift in error profiles, with Agnostics-trained models exhibiting fewer fundamental syntax and misuse errors, and a higher proportion of algorithmic logic flaws, indicating a better grasp of language fundamentals.

## Takeaways

> [!tip] Key Insights
> - Evaluating code correctness based purely on external I/O behavior enables a language-agnostic verification mechanism, dramatically reducing the engineering overhead for LLM post-training.
> - Reinforcement learning with binary pass/fail rewards leads to more robust model learning compared to partial rewards, which can be exploited.
> - Small open-weight LLMs can achieve competitive or superior performance on low-resource languages when trained with this generalized and efficient post-training pipeline, scaling across different model families and sizes.
