# Astra: Efficient Transformer Architecture and Contrastive Dynamics Learning for Embodied Instruction Following

> [!summary] Summary
> Astra is an efficient Transformer architecture for embodied instruction following, introducing trajectory attention and learnable action queries to better process multimodal sequences. It also incorporates Contrastive Dynamics Learning (CDL) for enhanced environmental understanding and multimodal alignment. The model achieves superior performance across challenging benchmarks, including a 70.67% success rate on unseen ManiSkill tasks and faster convergence on VIMA-Bench, by more effectively leveraging multimodal trajectory structure and learning dynamics.

## Problem

- Existing Transformer-based VLA models primarily use causal attention, which is suboptimal for multimodal trajectories where tokens within segments (e.g., state images, action dimensions) lack inherent causal order.
- Autoregressive generation of action dimensions in previous approaches can be inefficient, as the embedding of a preceding token may not optimally encapsulate the most relevant information for predicting the subsequent action dimension.
- Traditional dynamics learning methods for embodied agents are often complex, requiring generative modules (e.g., video generators), and struggle to efficiently align all three modalities: vision, language, and action.

## Method

- Introduces "trajectory attention," a novel self-attention mechanism that allows bidirectional attention within segments (prompt, state, action) while maintaining causal attention between segments.
- Proposes "learnable action queries," where each query is dedicated to extracting information for a specific action dimension, enabling parallel and more targeted action generation.
- Develops "==Contrastive Dynamics Learning (CDL)==," an encoding-based auxiliary objective that trains the model to distinguish between valid and invalid environmental dynamics, improving multimodal alignment with minimal architectural overhead.

## Results

- Astra consistently outperformed baselines (e.g., DT, Gato, VIMA) across VIMA-Bench generalization levels (e.g., **97.08%** on L1, **49.50%** on L4), demonstrating higher accuracy and faster convergence with comparable or fewer parameters.
- Achieved a **70.67%** success rate on "All" unseen ManiSkill tasks, substantially outperforming Gato (**40.00%**) and VIMA (**19.33%**), and exhibited improved robustness with capabilities like "instantaneous regrasp."
- Demonstrated superior zero-shot generalization on CALVIN's challenging ABC→D setting, achieving an average task length of **3.29**, surpassing baselines like GR-1 (**3.06**) and RoboFlamingo (**2.48**).

## Takeaways

> [!tip] Key Insights
> - Modifying Transformer attention masks to allow bidirectional attention *within* multimodal segments (e.g., visual observations from multiple cameras, multi-dimensional actions) significantly improves contextual understanding of embodied instruction following trajectories.
> - Dedicated, learnable action queries can more efficiently extract relevant information for predicting specific action dimensions in parallel, outperforming sequential autoregressive generation.
> - A lightweight, encoding-based contrastive learning objective can effectively enhance a model's internal representation of environmental dynamics and improve multimodal alignment without requiring complex generative modules.
