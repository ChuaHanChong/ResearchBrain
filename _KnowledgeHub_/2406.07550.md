# An Image is Worth 32 Tokens for Reconstruction and Generation

> [!summary] Summary
> TiTok, a Transformer-based 1-Dimensional Tokenizer, introduces a new method for representing images with an extremely compact sequence of tokens. It enables high-quality image reconstruction and generation using as few as 32-64 tokens, leading to orders of magnitude faster inference speeds compared to traditional diffusion models.

## Problem

- Image generation models, such as diffusion models and autoregressive transformers, demand substantial computational resources and time for both training and inference.
- Existing image tokenization methods typically rely on 2D grid-based representations, requiring hundreds or thousands of tokens, which introduces spatial redundancy and limits efficiency.
- Developing an efficient image tokenization method that compresses visual information while preserving details essential for high-quality reconstruction and generation is a key challenge.

## Method

- Introduces **TiTok** (==Transformer-based 1-Dimensional Tokenizer==), an architecture comprising a ==Vision Transformer encoder==, a ==Vector Quantizer==, and a ==Vision Transformer decoder==.
- Encodes an image into a compact ==1D latent representation==, using as few as 32-64 tokens, departing from conventional ==2D grid-based tokenization==.
- Employs a ==two-stage training== procedure: a ==warm-up stage== using ==proxy codes== from a pre-trained ==MaskGIT-VQGAN==, followed by fine-tuning the decoder to directly regress pixel values.

## Results

- TiTok achieves reasonable image reconstruction quality with only **32 tokens**, with quality improving up to **128 tokens** before diminishing returns.
- For image generation, TiTok-L-32 (256×256 resolution) generates images **169× faster** than DiT-XL/2 with a comparable gFID score of **2.5**.
- At 512×512 resolution, TiTok-L-64 generates images **410× faster** than DiT-XL/2, achieving a gFID of **3.8**.

## Takeaways

> [!tip] Key Insights
> - High-quality image reconstruction and generation are achievable with significantly fewer tokens (as low as 32-64) than previously considered necessary.
> - Utilizing a 1D tokenization approach with Vision Transformers allows for more efficient allocation of representational capacity by focusing on semantically meaningful regions rather than rigid 2D grids.
> - Breaking from 2D grid constraints enables dramatic reductions in token count, leading to substantial gains in generation speed without compromising image quality.

## Detailed Report

### 1. Introduction

Image generation models have seen remarkable progress in recent years, with diffusion models and autoregressive transformers producing increasingly realistic outputs. However, these models often require substantial computational resources and time for both training and inference. A key challenge in this field has been developing efficient image tokenization methods that compress visual information while preserving details necessary for high-quality reconstruction and generation.

The paper "An Image is Worth 32 Tokens for Reconstruction and Generation" introduces TiTok (Transformer-based 1-Dimensional Tokenizer), a novel approach that challenges the conventional wisdom of using 2D grid-based tokenization for images. As shown in Figure 1, TiTok operates by encoding an image into a compact sequence of just 32-64 tokens while still enabling high-quality reconstruction and generation.

### 2. TiTok Architecture

TiTok consists of three primary components:

1. **Vision Transformer Encoder**: Transforms an input image into a compact 1D latent representation.
2. **Vector Quantizer (VQ)**: Discretizes the continuous latent tokens into a finite set of codes from a learnable codebook.
3. **Vision Transformer Decoder**: Reconstructs the image from the quantized latent tokens.

The architecture stands apart from previous approaches by using a 1D sequence of tokens rather than a 2D grid to represent images. This seemingly simple change has profound implications for image compression and generation efficiency.

In mathematical terms, the TiTok process can be described as:

1. The input image $x \in \mathbb{R}^{H \times W \times 3}$ is first divided into $N$ patches.
2. These patches are processed by a Vision Transformer encoder to produce a continuous latent representation.
3. The Vector Quantizer maps the continuous values to a discrete set of codes from a codebook $\mathcal{Z} = \{z_k\}_{k=1}^K$.
4. The quantized tokens $\hat{z} \in \{z_1, z_2..., z_K\}^M$ (where $M \ll N$) represent the compressed image.
5. The decoder reconstructs the image from these tokens.

The most striking aspect is that $M$ can be as small as 32, dramatically smaller than the hundreds or thousands of tokens used in previous approaches.

### 3. 1D vs 2D Tokenization

Traditional image tokenizers like VQGAN use 2D grid-based representations where each token corresponds to a specific spatial region of the image. This approach has drawbacks:

1. **Spatial redundancy**: Adjacent regions in images often contain similar information.
2. **Inflexibility**: The grid structure limits the model's ability to focus on semantically meaningful regions.
3. **Scaling issues**: Larger images require quadratically more tokens.

TiTok's 1D tokenization breaks free from these constraints. Each token in TiTok's representation can attend to the entire image, allowing the model to allocate its limited token budget more efficiently. This is conceptually similar to how humans describe images - we don't describe every pixel but focus on salient objects and features.

The authors draw inspiration from image understanding tasks where Vision Transformers extract high-level semantic information and output compact 1D sequences. TiTok extends this concept to ensure the 1D representation contains sufficient information for both semantic understanding and detailed reconstruction.

### 4. Training Methodology

Training TiTok effectively requires a thoughtful approach. The authors employ a two-stage training procedure:

1. **Warm-up Stage**: TiTok is initially trained to predict discrete codes generated by a pre-trained MaskGIT-VQGAN model (called "proxy codes"). This provides a strong initialization.

2. **Decoder Fine-tuning**: After warm-up, the encoder and quantizer are frozen, and the decoder is fine-tuned to directly regress pixel values using a standard VQGAN training recipe.

This two-stage approach helps overcome optimization challenges associated with joint training of encoder, quantizer, and decoder components.

The loss function combines several terms:

$$\mathcal{L} = \mathcal{L}_{\text{recon}} + \lambda_1 \mathcal{L}_{\text{percep}} + \lambda_2 \mathcal{L}_{\text{adv}} + \lambda_3 \mathcal{L}_{\text{VQ}}$$

Where:
- $\mathcal{L}_{\text{recon}}$ is the reconstruction loss (L2 or L1 norm)
- $\mathcal{L}_{\text{percep}}$ is a perceptual loss using LPIPS
- $\mathcal{L}_{\text{adv}}$ is an adversarial loss with a patch discriminator
- $\mathcal{L}_{\text{VQ}}$ is the vector quantization loss

For generation, TiTok is integrated with MaskGIT, an autoregressive transformer that predicts masked tokens in a non-autoregressive manner, enabling efficient parallel training and controllable inference speed.

### 5. Experimental Results

The authors conduct extensive experiments to evaluate TiTok's performance on image reconstruction and generation tasks. Results are reported on the ImageNet-1K dataset at 256×256 and 512×512 resolutions.

A key finding is that TiTok achieves reasonable image reconstruction quality with just 32 tokens - a remarkably small number compared to traditional approaches that use hundreds or thousands of tokens. As the number of tokens increases, reconstruction quality improves, but with diminishing returns after about 128 tokens.

The authors explore three model sizes: TiTok-S (small), TiTok-B (base), and TiTok-L (large), varying in parameter count and capacity. As expected, larger models achieve better performance, especially when the token budget is severely constrained.

For image generation, TiTok is integrated with MaskGIT and compared against state-of-the-art models including diffusion models like DiT-XL/2 and LDM-4, as well as other autoregressive approaches. TiTok achieves competitive Fréchet Inception Distance (FID) scores while using dramatically fewer tokens, leading to substantial speedups in generation time.

### 6. Speed and Performance Tradeoffs

One of the most impressive aspects of TiTok is the dramatic speed improvements it achieves while maintaining high generation quality. As shown in Figure 2, TiTok models significantly outperform existing approaches in the speed-quality tradeoff:

At 256×256 resolution, TiTok-L-32 (using 32 tokens) generates images 169× faster than DiT-XL/2 while achieving a comparable gFID score of 2.5. At 512×512 resolution, TiTok-L-64 (using 64 tokens) is 410× faster than DiT-XL/2 with a gFID of 3.8.

These speed improvements come from the dramatically reduced number of tokens that need to be processed during generation. Whereas diffusion models require hundreds of denoising steps and 2D tokenizers process hundreds of tokens, TiTok can generate high-quality images with just a few dozen tokens.

### 7. Scaling Properties

Figure 3 illustrates how TiTok's performance scales with the number of tokens and model size:

Several key patterns emerge:

1. **Reconstruction quality** (measured by FID) improves as the number of tokens increases, with larger models (TiTok-L) consistently outperforming smaller ones.

2. **Linear probe accuracy**, which measures how well the tokens preserve semantic information, also scales with token count and model size. TiTok-L with 128 tokens achieves nearly 60% accuracy, indicating strong semantic preservation.

3. **Generation quality** improves rapidly up to about 64 tokens, after which the gains diminish. This suggests that for generation tasks, a relatively small number of tokens (32-64) may be sufficient.

4. **Sampling speed** decreases with more tokens but remains orders of magnitude faster than competing approaches. Even with 256 tokens, TiTok maintains a significant speed advantage.

### 8. Conclusion and Significance

The paper demonstrates that effective image representation and generation can be achieved with far fewer tokens than previously thought. By breaking free from the constraints of 2D grid-based tokenization, TiTok enables more efficient allocation of representational capacity, focusing on semantically meaningful regions rather than uniformly across the image.

The key contributions and implications include:

1. **Efficiency breakthrough**: Demonstrating that as few as 32 tokens can suffice for reasonable image reconstruction and high-quality generation, challenging conventional wisdom.

2. **Architectural innovation**: Introducing a 1D tokenization approach that leverages the global attention capabilities of Vision Transformers to create more flexible image representations.

3. **Speed improvements**: Achieving orders of magnitude faster generation speeds while maintaining competitive quality, which could enable real-time image generation applications previously thought impractical.

4. **Scaling insights**: Providing empirical evidence on how model size, token count, and training strategies affect performance, guiding future research in efficient image generation.

The approach opens new possibilities for applications requiring real-time image generation and manipulation, from creative tools to augmented reality. Moreover, the compact representation learned by TiTok may have applications beyond generation, such as efficient image storage, retrieval, and transmission.

As compute-efficient AI becomes increasingly important, TiTok represents a significant step toward more sustainable and accessible image generation technology.
