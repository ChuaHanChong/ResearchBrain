# LearNAT: Learning NL2SQL with AST-guided Task Decomposition for Large Language Models

> [!summary] Summary
> Peking University researchers develop LearNAT, a framework that enables open-source language models to match GPT-4's performance on natural language to SQL translation tasks through AST-guided task decomposition and margin-aware reinforcement learning, achieving an 80% decomposition success rate while reducing token consumption through efficient pruning strategies.

## Problem

- Existing NL2SQL approaches rely heavily on closed-source LLMs, raising concerns about accessibility, privacy, and cost
- Open-source LLMs struggle with complex queries involving implicit objectives and semantic gaps with database schemas
- Existing fine-tuning approaches for open-source LLMs focus narrowly on SQL query generation itself, neglecting the step-by-step reasoning process needed for complex queries

## Method

- ==AST-guided task decomposition== using Monte Carlo Tree Search to break down complex queries
- Margin-aware reinforcement learning framework combining supervised fine-tuning with direct preference optimization
- Adaptive demonstration reasoning system that dynamically selects relevant examples

## Results

- Achieved GPT-4 level performance using a **7B** parameter open-source model
- **80%** decomposition success rate with significant reduction in token consumption, outperforming Chain-of-Thought and naive MCTS baselines through AST-guided pruning
- Competitive or superior performance on Spider-dev and BIRD-dev benchmarks compared to existing methods

## Takeaways

> [!tip] Key Insights
> - Abstract Syntax Trees can effectively guide task decomposition and provide reliable reward signals for reinforcement learning
> - Combining node-level and structural similarity metrics improves accuracy of reward estimation
> - Dynamic selection of demonstrations enhances model performance on complex queries

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

- **NL2SQL as a Growing Field:** Natural Language to SQL (NL2SQL) is a well-established research area aimed at simplifying database access for non-technical users. The field has gained significant momentum with the rise of LLMs, which offer a promising avenue for bridging the gap between natural language and structured queries.
- **LLMs in NL2SQL:** This paper specifically addresses the limitations of existing LLM-based NL2SQL approaches. The prevalent method currently depends on closed-source LLMs (like GPT-4) that leverage prompt engineering. While effective, this approach poses concerns regarding accessibility, privacy, and cost. This work highlights the performance gap between these closed-source models and open-source alternatives.
- **Task Decomposition and Reinforcement Learning:** The paper situates itself within the growing body of research exploring task decomposition and reinforcement learning to improve LLM reasoning. This is inspired by work in mathematical problem-solving, where step-by-step reasoning has been shown to enhance performance. The paper specifically references the "Let's think step by step" strategy.
- **Bridging the Gap:** This paper directly addresses the challenge of making open-source LLMs competitive with closed-source models in complex NL2SQL tasks. The work aims to democratize NL2SQL capabilities by showing that careful task decomposition can narrow the performance gap while offering benefits like greater control, transparency, and lower computational costs.
- **Related Works Highlighted:**
 - **Prompt Engineering:** The paper acknowledges the importance of prompt engineering in NL2SQL, citing works like DIN-SQL and MAC-SQL. However, it emphasizes the limitations of these methods when applied to open-source models.
 - **Model Fine-tuning:** Fine-tuning open-source LLMs is explored as an alternative, but the paper notes that existing research focuses on SQL query generation, neglecting the reasoning process.
 - **Reinforcement Learning:** The paper positions itself within the research that uses Monte Carlo Tree Search (MCTS) to guide LLM reasoning and Direct Preference Optimization (DPO) to align LLMs with desired behavior. The paper distinguishes itself by using Abstract Syntax Trees (ASTs) to quantify node rewards and introduce a margin-aware DPO framework.

### 2. Key Objectives and Motivation

- **Overarching Objective:** To improve the performance of open-source LLMs on complex NL2SQL tasks, making them competitive with closed-source models.
- **Specific Objectives:**
 - To develop a novel framework (LearNAT) that integrates task decomposition and reinforcement learning.
 - To create a Decomposition Synthesis Procedure that uses ASTs to guide efficient task decomposition.
 - To implement Margin-aware Reinforcement Learning to enable fine-grained, step-level optimization.
 - To develop Adaptive Demonstration Reasoning to dynamically select relevant examples for enhanced decomposition.
- **Motivation:**
 - The need to democratize database access by providing accessible and cost-effective NL2SQL solutions.
 - Addressing the limitations of closed-source LLMs in terms of openness, privacy, and computational cost.
 - Overcoming the challenges of complex NL2SQL tasks where user queries have implicit objectives and semantic gaps with database schemas.
 - Improving LLMs' reasoning abilities for complex structured prediction tasks.

### 3. Methodology and Approach

- **LearNAT Framework:** The core of the paper lies in the LearNAT framework, which combines task decomposition and reinforcement learning. The framework is structured around three key components:
 - **Decomposition Synthesis Procedure:** This component aims to generate training data for offline reinforcement learning. It uses MCTS to search for suitable task decompositions. A key innovation is the use of Abstract Syntax Trees (ASTs) to guide the search and implement pruning strategies, which addresses the challenges of the vast search space and the unreliability of self-evaluation in LLMs.
 - **Margin-Aware Reinforcement Learning:** This component refines the LLMs decomposition abilities. This consists of two phases; supervised fine-tuning on successful decomposition trajectories, and direct preference optimization with AST margins using constrastive action pairs.
 - **Adaptive Demonstration Reasoning:** This component enhances LLMs performance further by selecting the most suitable demonstration from the training dataset to guide the process.

- **Decomposition Synthesis Procedure Details:**
 - Formulates task decomposition as a tree search problem using MCTS.
 - Uses an LLM to generate subtasks and sub-SQL queries at each MCTS state.
 - Classifies MCTS actions as Progressive, Redundant, or Invalid, pruning Redundant and Invalid actions to improve efficiency.
 - Estimates state rewards based on the similarity between the current AST and the target SQL AST, using node-level and structural similarity metrics.
 - Incorporates a self-improvement demonstration mechanism by selecting top-3 most similar queries as demonstrations to be included in the prompt.

- **Margin-Aware Reinforcement Learning Details:**
 - Fine-tunes the LLM in a supervised manner using correct decomposition trajectories.
 - Employs Direct Preference Optimization (DPO) to suppress incorrect subtask outputs.
 - Introduces an AST-based margin-aware DPO framework that distinguishes between varying levels of correctness in steps, enabling more precise optimization.

- **Adaptive Demonstration Reasoning Details:**
 - Constructs an embedding cache of demonstration query-SQL pairs.
 - Uses the tuned LLM to generate embeddings for the new SQL query
 - Computes similarity between the new query embedding and each cached embedding.
 - Selects the top-k most similar query-SQL pairs as demonstrations.

### 4. Main Findings and Results

- **Decomposition Synthesis Procedure Performance:** The Decomposition Synthesis Procedure achieved an 80.00% decomposition success rate, outperforming CoT and naive MCTS baselines while significantly reducing token consumption due to AST-guided pruning.
- **Superior performance:** Achieved GPT-4-level performance with a 7B parameter open-source model. Significantly outperforms prompt engineering and fine-tuning baselines, especially those using GPT-4.
- **Spider and BIRD Benchmark Results:** LearNAT demonstrated significant improvements on Spider-dev and BIRD-dev benchmarks, achieving competitive or superior performance compared to existing state-of-the-art methods, even with smaller model sizes (7B, 14B, 32B parameters) compared to some closed-source models used in baselines.
- **Ablation Study Results:** The ablation study demonstrated the importance of each component in LearNAT. Removing AST-guided decomposition, reinforcement learning, adaptive demonstration reasoning, or specific elements like the SFT stage or margin-aware DPO led to performance degradation.
- **AST Similarity Analysis:** The analysis of AST similarity showed that both node similarity and structural similarity are important for accurate reward estimation, with node similarity playing a slightly more critical role.

### 5. Significance and Potential Impact

- **Democratization of NL2SQL:** The paper's key significance lies in demonstrating that well-designed task decomposition and reinforcement learning strategies can significantly narrow the performance gap between open-source and closed-source LLMs in NL2SQL. This contributes to the democratization of database access by making it more accessible and cost-effective.
- **Advancement of LLM Reasoning:** The research provides valuable insights into enhancing LLMs' reasoning abilities for complex structured prediction tasks. The use of ASTs for guiding task decomposition and reward estimation is a novel approach that can be applied to other structured prediction problems.
- **Practical Applications:** The improved NL2SQL performance achieved by LearNAT has the potential to benefit a wide range of applications, including business intelligence, data analysis, and question-answering systems. By enabling non-technical users to easily query and interact with databases, LearNAT can empower them to make data-driven decisions.
- **Research Directions:** The paper identifies limitations in the current framework, such as the inefficient application of task decomposition to simpler queries. This suggests future research directions focused on adaptive task decomposition techniques that dynamically balance reasoning cost and performance.
