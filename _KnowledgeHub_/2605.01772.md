# Anticipation-VLA: Solving Long-Horizon Embodied Tasks via Anticipation-based Subgoal Generation

> [!summary] Summary
> Anticipation-VLA is a hierarchical framework that enables Vision-Language-Action (VLA) models to reliably perform long-horizon embodied tasks by adaptively generating multimodal subgoals. This approach leverages an "Anticipation Model" to dynamically adjust planning granularity and consistently outperforms existing baselines in both simulated and real-world robotic tasks, showing up to a 107% improvement in unseen real-world configurations.

## Problem

- Existing VLA models experience compounding errors over long task sequences, leading to policy failures.
- Current task decomposition methods rely on fixed-granularity subtask planning, which is either too fine-grained (increasing complexity) or too sparse (insufficient guidance).
- This lack of adaptive planning limits the scalability and robustness of VLA models for complex, long-horizon real-world scenarios.

## Method

- Introduces **Anticipation-VLA**, a hierarchical framework for long-horizon tasks that integrates an "==Anticipation Model==" for high-level planning with a low-level VLA policy.
- Develops the Anticipation Model to recursively and adaptively generate ==multimodal subgoals== (textual instructions and corresponding visual images) based on current observations and task progress.
- Implements dynamic subgoal management, re-planning every K timesteps by using an ==Optimal Value Function== to evaluate progress and adapt subgoal granularity (refine, pop, or reset).

## Results

- Anticipation-VLA achieved an **80.8%** average success rate on the LIBERO benchmark and doubled the success rate (**4.2%**) on the VLABench "Hammer Nail & Hang Picture" task compared to baselines.
- In real-world experiments, the framework consistently outperformed baselines (e.g., \u03c00.5), showing a **107%** improvement in unseen task configurations and being the only model to achieve non-zero success in the unseen "Spell Words" task.
- Ablation studies confirmed that adaptive planning, visual subgoals, and textual predictions are all essential and complementary components for robust real-world manipulation, particularly validating the importance of adaptive granularity.

## Takeaways

> [!tip] Key Insights
> - Adaptive and recursive multimodal subgoal generation is crucial for mitigating compounding errors and achieving robust execution in long-horizon embodied tasks.
> - A Unified Multimodal Model (UMM) can effectively implement both the anticipation model for subgoal generation and the optimal value model for evaluating task progress.
> - Reformulating the optimal value model as a classification task for progress assessment simplifies learning from sparse, trajectory-level rewards and enhances practical applicability.
