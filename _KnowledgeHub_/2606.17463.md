# WeaveLA: Event Driven Cross-Subtask Latent Memory Weaving for Repetitive Robot Manipulation

> [!summary] Summary
> WeaveLA introduces an event-driven, action-side latent memory weaving interface for Vision-Language-Action (VLA) policies, enabling them to effectively handle repetitive manipulation tasks by transferring sub-task completion information. The system improves aggregate success rates by over 5% and achieves substantial gains on challenging multi-repetition tasks, like SWINGXTIMES, where baseline models struggle.

## Problem

- Current Vision-Language-Action (VLA) policies struggle with repetitive and sequential manipulation tasks due to a lack of explicit mechanisms for cross-subtask information transfer.
- Short-window VLAs cannot effectively track accumulated progress or count repetitions when visual inputs are perceptually similar across different stages of a task.
- Existing memory-augmented VLA approaches often incur high computational costs with per-frame memory writes or lack the specificity to route concise information directly to the subsequent action expert.

## Method

- **WeaveLA** integrates an event-driven, action-side memory mechanism into frozen VLA backbones, triggering memory writes specifically at sub-goal completion events during task rollout.
- A query-driven ==Memory Weaver== module compresses multimodal perceptual features from completed sub-tasks into compact latent memories using attention pooling.
- These latent memories directly condition the action expert of the subsequent sub-task via an additional memory-conditioned AdaRMS step in Gemma blocks, ensuring lightweight modulation and preserving the base policy.

## Results

- WeaveLA improved aggregate average success rates on RoboMME from **19.0%** to **24.7%** (6-task scale) and from **17.3%** to **23.3%** (16-task scale) compared to the Weaver-off baseline.
- On SWINGXTIMES (N=3), a challenging repetition task, success increased from **0%** to **47.8%** (6-task scale) and from **4%** to **30%** (16-task scale) with WeaveLA.
- The system maintained robust performance using a model-internal "latent-shift" event detector, largely replicating oracle trigger results for most tasks, and showed consistent gains in small-scale real-robot experiments on PICKXTIMES.

## Takeaways

> [!tip] Key Insights
> - Sub-goal completion events serve as efficient and causally-aligned temporal units for transferring condensed information between sequential sub-tasks.
> - Directly conditioning the action expert with compact latent memories is more effective for repetition-aware control than diluting information through VLM backbones or language prompts.
> - A lightweight, modular memory interface can significantly enhance VLA performance on specific memory-dependent tasks without boosting generic capabilities or requiring full retraining of the base policy.
