# Planning from Imagination: Episodic Simulation and Episodic Memory for Vision-and-Language Navigation

> [!summary] Summary
> An embodied agent called SALI (Space-Aware Long-term Imaginer) was developed at Shanghai Jiao Tong University, integrating a reality-imagination hybrid memory system to enhance Vision-and-Language Navigation in unfamiliar environments. This system, inspired by human episodic simulation, enabled the agent to generate and leverage future scene information, leading to state-of-the-art results on the R2R and REVERIE benchmarks, with R2R's Success rate weighted by Path Length (SPL) improving by 6-8% in unseen test splits.

## Problem

- Vision-and-Language Navigation (VLN) agents exhibit significant performance degradation when deployed in unfamiliar or unseen environments.
- Existing imaginative mechanisms in VLN agents produce transient predictions that are not integrated into a persistent, long-term memory system, limiting robust reasoning.
- There is a need for embodied agents to better align unfamiliar visual observations with navigation instructions and generalize knowledge, similar to human cognitive abilities like episodic memory and simulation.

## Method

- A **SALI** (Space-Aware Long-term Imaginer) agent is proposed, incorporating a ==reality-imagination hybrid memory== system that fuses real-time observations with generated future scenes.
- A ==topological memory map== (G_t) is dynamically updated with four types of nodes: visited, current, navigable, and imagination nodes, storing mixed-granularity visual and spatial information.
- A ==recurrent imagination module==, organized as a tree, iteratively generates future semantic, depth, and RGB images, alongside probable waypoints, which are then integrated into the memory map.
- Dynamic action planning utilizes a ==multimodal transformer== and an ==adaptive fusion policy== to weigh real and imagined information when selecting the next navigation step.

## Results

- SALI achieved state-of-the-art performance on the R2R benchmark, improving the Success rate weighted by Path Length (SPL) by **6-8%** (SPL of **74**) on the Test Unseen split compared to previous models.
- The agent also established new state-of-the-art on the REVERIE benchmark with the highest Remote Grounding Success (RGS) of **34** and RGSPL of **25** on the Test Unseen split.
- Ablation studies confirmed that the reality-imagination hybrid memory system significantly outperformed reality-only or imagination-only approaches, and dynamic fusion of imagined information yielded better results than a fixed weighting.
- Quantitative analysis revealed the largest performance gains on complex instructions involving both room and object terms (S3), indicating enhanced commonsense reasoning capabilities.

## Takeaways

> [!tip] Key Insights
> - Integrating a hybrid memory system that combines real observations with imagined future scenarios significantly enhances an agent's ability to generalize and navigate effectively in unseen environments.
> - Episodic simulation, by generating fine-grained visual features and higher-level spatial structures, allows agents to perform complex commonsense reasoning about object-room associations.
> - The dynamic weighting of imagined information, adapting its influence on decision-making as navigation progresses, proves more effective than a fixed fusion factor.
> - Auxiliary models for room type refinement and waypoint prediction are crucial for improving the fidelity of imagined information and aiding navigation decisions.
