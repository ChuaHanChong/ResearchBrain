# GRAM: Generalization in Deep RL with a Robust Adaptation Module

> [!summary] Summary
> Researchers from Mitsubishi Electric Research Laboratories (MERL) and MIT developed GRAM, a deep reinforcement learning framework that unifies adaptive performance in familiar environments with robust generalization to novel, unseen conditions. GRAM dynamically adjusts robot behavior based on environmental uncertainty, achieving strong adaptive performance in in-distribution scenarios and robust generalization to out-of-distribution dynamics on a quadruped robot, both in simulation and hardware.

## Problem

- Deep reinforcement learning policies struggle to generalize effectively to both in-distribution (ID) and out-of-distribution (OOD) environmental conditions.
- Existing contextual RL methods excel at ID adaptation but often fail in OOD scenarios, while robust RL methods provide OOD generalization but typically lead to conservative and suboptimal ID performance.
- There is a need for a unified deep RL framework that can seamlessly integrate adaptive ID performance and robust OOD generalization without a significant trade-off.

## Method

- **GRAM** (Generalization in Deep RL with a Robust Adaptation Module) extends a ==teacher-student architecture== by incorporating an ==Epistemic Neural Network (Epinet)== as part of a ==robust adaptation module==.
- The Epinet quantifies ==uncertainty== about the deployment environment, using variance in its latent feature estimates to discern between ID (low variance) and OOD (high variance) contexts.
- The robust adaptation module dynamically blends the Epinet's mean latent feature estimate (for adaptive behavior) with a predefined ==robust latent feature== (for robust behavior), based on this uncertainty, using a ==confidence score==.
- A ==joint training pipeline== combines standard RL with ==adversarial RL==, using different latent feature inputs, to simultaneously optimize for adaptive ID performance and robust OOD generalization within a single policy.

## Results

- GRAM achieved ID performance (**0.92** normalized task return) comparable to contextual RL and domain randomization, while significantly outperforming them in near OOD (**0.79**) and far OOD (**0.58**) contexts in simulation.
- On a Unitree Go2 quadruped robot, GRAM demonstrated faster time-to-goal in moderate tasks (average **8.17s**) and maintained a **100%** success rate in challenging, far OOD hardware tasks (e.g., **9 kg** payload, slippery surfaces), where baselines largely failed.
- The framework showed robust zero-shot sim-to-real transfer, successfully navigating diverse outdoor terrains and transitions in real-world experiments, indicating strong practical applicability.

## Takeaways

> [!tip] Key Insights
> - Epistemic Neural Networks can effectively quantify environmental uncertainty, allowing a policy to differentiate between familiar (ID) and novel (OOD) dynamics in real-time.
> - Dynamically combining an adaptive latent feature estimate with a fixed robust latent feature, guided by uncertainty, enables a seamless transition between adaptive and robust control strategies.
> - A unified training approach, incorporating both standard and adversarial reinforcement learning, can train a single policy that inherently possesses both the capacity to adapt to known conditions and remain robust to unforeseen ones.
