# An Atomic Skill Library Construction Method for Data-Efficient Embodied Manipulation

> [!summary] Summary
> Researchers from JD Explore Academy and academic partners developed a "Three-Wheeled" framework for embodied manipulation, enabling robots to dynamically build and update an atomic skill library. This method allows for comparable or improved performance with significantly less data, showing enhanced generalization to novel tasks with success rates up to 80-100% on reordered block tasks, across different VLA models.

## Problem

- End-to-end Vision-Language-Action (VLA) models demand massive task-specific data, leading to a "data explosion" problem that hinders real-world scalability.
- Existing atomic skill decomposition methods rely on manually predefined, static skill sets, which lack adaptability and cannot expand to unforeseen tasks or dynamic environments.
- Current embodied manipulation systems struggle to efficiently generalize to new tasks and varying environmental configurations without extensive, costly retraining.

## Method

- Introduces a "==Three-Wheeled Self-Driven== **Atomic Skill Library Construction** Method" comprising interconnected VLP (Vision-Language-Planning), VLA (Vision-Language-Action), and Atomic Skill Wheels.
- Utilizes a VLP Agent Wheel, integrating models like Prismatic, Dino-X, SAM-2, and GPT-4, for automatic, intelligent task decomposition and planning, incorporating scene descriptions and spatial intelligence.
- Employs an Atomic Skill Wheel for dynamic skill definition, library expansion through few-shot fine-tuning of VLA models (e.g., Octo, RDT-1B), and self-driven adaptation based on VLA performance characteristics.

## Results

- Achieved comparable or superior manipulation performance with significantly less data than end-to-end baselines, for example, improving the 'Pour Water' success rate by **20%** (**80%** vs **60%**) for out-of-distribution objects.
- Demonstrated enhanced performance with the same total data volume by strategically distributing it for skill acquisition, leading to a **40%** increase in success rate for 'Pick & Place Banana' (**70%** vs **30%**) with out-of-distribution objects.
- Enabled robust adaptability to entirely new tasks, with the system successfully performing novel sequences (e.g., reordered block tasks) with 80-**100%** success rates, whereas end-to-end methods consistently failed (**0%**).

## Takeaways

> [!tip] Key Insights
> - Dynamically constructing and updating an atomic skill library in a data-driven manner effectively overcomes the limitations of both end-to-end data explosion and static skill sets, enabling continuous learning and adaptability.
> - Integrating powerful VLP models like GPT-4 with robust visual perception (object detection, segmentation, spatial relations) provides a strong foundation for intelligent task decomposition and effective management of atomic skills.
> - Structuring data collection around specific atomic skills, rather than entire end-to-end tasks, significantly enhances data efficiency and promotes generalization capabilities across varying object positions and novel task sequences.
