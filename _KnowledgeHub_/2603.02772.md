# Agentic Self-Evolutionary Replanning for Embodied Navigation

> [!summary] Summary
> The Agentic Self-Evolutionary Replanning (SERP) framework enables embodied agents to dynamically adapt their action models and perform cross-level replanning by integrating local self-evolution and global graph-based reasoning. This approach achieves over 10% higher success rates on complex planning tasks and 20-40% greater token efficiency compared to existing methods in both simulated and real-world environments.

## Problem

- Embodied navigation systems frequently encounter failures due to environmental uncertainties, perception errors, and limitations within the robot's action models.
- Current replanning (RP) methods maintain static robot action models, which prevents agents from learning from execution failures and improving their intrinsic capabilities.
- Iterative LLM-based global replanning is computationally inefficient, leading to high token usage and latency when processing large, comprehensive semantic scene graphs.

## Method

- Introduced Agentic Self-Evolutionary Replanning (SERP), a cross-level framework that enables dynamic model evolution through runtime learning for enhanced resilience.
- Developed Local Agentic Self-Evolution (ASE), which employs In-context Learning with Auto-Differentiation (ILAD) to adapt the robot's action model parameters and loss function weights based on execution feedback.
- Proposed Global Graph ==Chain-of-Thought== (GCOT), a mechanism that dynamically distills large scene graphs into smaller, task-relevant subsets for token-efficient LLM-based global replanning.

## Results

- SERP achieved over **10%** higher success rates on complex planning tasks and demonstrated superior robustness in adapting to suboptimal initial parameter settings compared to baselines.
- The GCOT component yielded substantial token efficiency, attaining over **20%** higher Reduced Graph Token Ratio (RGTR) in searching tasks and over **40%** higher in planning tasks compared to the SayPlan baseline.
- Real-world experiments validated ASE's ability to adapt control parameters for navigating narrow passages and GCOT's capacity to identify and redirect to alternative viable goals in dynamic environments.

## Takeaways

> [!tip] Key Insights
> - The integration of gradient-based optimization (Auto-Differentiation) with LLM-driven global parameter resets (In-context Learning) within ILAD allows robots to escape local optima and achieve robust self-evolution.
> - Decoupling the search for relevant scene elements (using a smaller CLIP model) from high-level reasoning (using an LLM) significantly reduces token expenditure and computational overhead during global replanning.
> - Enabling robots to evolve their internal action models from experience shifts the paradigm from merely circumventing failures to actively enhancing fundamental execution capabilities, leading to more resilient agents.
