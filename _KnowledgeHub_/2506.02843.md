# Random Registers for Cross-Domain Few-Shot Learning

> [!summary] Summary
> This study reveals that learnable prompts can hinder Vision Transformer generalization in cross-domain few-shot learning, while randomly initialized prompts, termed random registers, improve it. A two-stage method, Random Registers Enhanced Attention Perturbation (REAP), is proposed to leverage this insight, achieving state-of-the-art performance by enhancing attention perturbation and adapting effectively to new target domains.

## Problem

- Vision Transformers (ViTs) struggle to generalize effectively across significant domain gaps when very few labeled examples are available in the target domain.
- Standard prompt tuning strategies, commonly used for adapting pre-trained ViTs, unexpectedly degrade performance in cross-domain few-shot learning (CDFSL) scenarios.
- There is a lack of understanding regarding how prompt tuning mechanisms specifically influence ViT transferability when confronting substantial domain shifts.

## Method

- Observed that ==random Gaussian noise (random registers)== appended to input tokens consistently improves ViT transferability in CDFSL, contrasting the negative effect of learnable prompts.
- Interpreted the role of random registers as implicitly performing ==sharpness-aware minimization (SAM)==, guiding the model to flatter, more generalizable minima in the loss landscape.
- Developed ==Random Registers Enhanced Attention Perturbation (REAP)==, a two-stage strategy that perturbs clustered semantic image regions with random noise during source training and utilizes learnable registers for efficient target-domain adaptation.

## Results

- REAP achieved state-of-the-art average performance across four diverse target-domain datasets (CropDiseases, EuroSAT, ISIC2018, ChestX) in both **1-shot** and **5-shot** settings.
- Quantitative analysis using Centered Kernel Alignment (CKA) demonstrated that random registers significantly increase the similarity between source and target domain features, confirming improved domain-agnostic learning.
- Qualitative visualizations of attention maps showed that REAP leads to more focused and valid attention on semantic objects within target images, indicating enhanced generalization capabilities.

## Takeaways

> [!tip] Key Insights
> - Learnable prompts, when trained on the source domain, can absorb domain-specific information, leading to overfitting and sharper loss landscapes, which ultimately harms ViT generalization to new target domains.
> - Random registers introduce controlled perturbations that push the model towards flatter loss minima, functioning as a form of sharpness-aware minimization to learn more robust and domain-agnostic features.
> - Perturbing semantically meaningful clustered regions of image patches with random noise during source training is more effective for enhancing transferability than random masking, and learnable registers are optimal for rapid adaptation during target-domain fine-tuning.
