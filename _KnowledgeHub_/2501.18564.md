# SAM2Act: Integrating Visual Foundation Model with A Memory Architecture for Robotic Manipulation

> [!summary] Summary
> Researchers from the University of Washington, NVIDIA, and AI2 developed SAM2Act, a robotic manipulation policy integrating the SAM2 visual encoder with a multi-view transformer, achieving 86.8% success on RLBench tasks and demonstrating robust generalization. An extension, SAM2Act+, introduces a novel memory architecture, enabling 94.3% success on new memory-dependent benchmarks and outperforming prior methods by 39.3%.

## Problem

- Robotic manipulation policies often lack high precision and robust generalization to diverse, unseen environments and objects.
- Existing imitation learning policies typically operate on a Markovian assumption, lacking mechanisms for spatial memory crucial for complex sequential tasks.
- A lack of standardized benchmarks exists to systematically evaluate spatial memory capabilities in robotic manipulation.

## Method

- **SAM2Act**: A multi-view robotic ==transformer== architecture that integrates a fine-tuned SAM2 visual encoder for rich, multi-resolution visual embeddings and a cascaded multi-resolution upsampling mechanism for enhanced precision.
- **SAM2Act**+: An extension that incorporates an explicit memory architecture (memory bank, encoder, and attention) to allow the policy to retain and condition on past observations and actions.
- MemoryBench: A new benchmark with non-Markovian tasks specifically designed to test spatial memory and action recall in robotic manipulation.

## Takeaways

> [!tip] Key Insights
> - Integrating pre-trained visual foundation models like SAM2, particularly their multi-resolution features, significantly enhances a robot's spatial reasoning and precision in 3D manipulation tasks.
> - Explicitly modeling memory through a dedicated architecture within a robotic transformer enables policies to successfully complete complex, non-Markovian tasks requiring recall of past spatial information.
> - A systematic benchmark with non-Markovian task design is crucial for driving research and evaluating the spatial memory capabilities of robotic manipulation policies.
