# Phi-4-reasoning Technical Report

> [!summary] Summary
> Microsoft researchers develop a 14B parameter language model specialized in reasoning through careful data curation and a combination of supervised fine-tuning and reinforcement learning, achieving performance competitive with much larger models while maintaining efficiency through targeted training on complex reasoning tasks.

## Problem

- Existing reasoning-focused language models require massive parameter counts, limiting their practical deployment
- Difficult to maintain strong reasoning capabilities while reducing model size and computational requirements

## Method

- Carefully curated ==dataset combining web-sourced and synthetic reasoning problems== with high-quality responses
- ==Two-stage training approach== using supervised fine-tuning followed by reinforcement learning for math reasoning
- Specialized architecture modifications including ==longer context and reasoning block tokens==

## Results

- Outperforms significantly larger open-weight models like DeepSeek-R1-Distill-Llama-**70B** on reasoning benchmarks
- Shows strong generalization to algorithmic problem solving and planning tasks
- Maintains high performance on general-purpose skills like instruction following and long-context QA
- Offers flexible accuracy vs token length tradeoffs between base and plus versions

## Takeaways

> [!tip] Key Insights
> - High-quality data curation and targeted training can enable smaller models to match larger ones' reasoning ability
> - Combining supervised fine-tuning with reinforcement learning provides complementary benefits
> - Models exhibit strong generalization to unseen reasoning tasks not directly targeted in training
