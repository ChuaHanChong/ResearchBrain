# TurboMPC: Fast, Scalable, and Differentiable Model Predictive Control on the GPU

> [!summary] Summary
> TurboMPC is a GPU-native, differentiable Model Predictive Control (MPC) solver that supports expressive formulations crucial for robotics applications, bridging advanced optimization with modern GPU-accelerated learning. It achieves substantial speedups and robust performance in both simulations and on autonomous racing hardware, enabling long-horizon planning and automated parameter tuning.

## Problem

- Traditional CPU-based MPC solvers lack scalability for the large batch sizes and parallel computations demanded by modern GPU-accelerated learning pipelines in robotics.
- Existing GPU-based differentiable MPC solvers often simplify problem classes, omitting essential features like implicit integrators, cross-time-coupled costs, or state inequality constraints required for realistic robotics applications.
- An architectural mismatch exists between high-level automatic differentiation frameworks (like JAX) and low-level GPU kernel execution, hindering the efficient co-design of fast and differentiable solvers.

## Method

- Developed **TurboMPC**, a GPU-native differentiable MPC solver, utilizing a Sequential Quadratic Programming (SQP) outer loop for nonlinear Optimal Control Problems (OCPs).
- Employed a custom ==Alternating Direction Method of Multipliers (ADMM)== inner solver, adapted for efficient slack variable handling, with adaptive step-size and problem rescaling for enhanced robustness.
- Designed a co-located architecture combining a JAX frontend for high-level control and automatic differentiation with a performance-optimized fused CUDA backend for the ADMM loop, leveraging `cuDSS` for sparse linear systems.

## Results

- TurboMPC achieved up to **14.6x** speedup for forward and **9.4x** for backward passes over `mpc.pytorch` (and up to **58x**/**15x** over `mpc.pytorch`/`acados` with looser tolerance) on linear-system Reinforcement Learning benchmarks.
- On autonomous racing hardware, GPU-accelerated Bayesian optimization with TurboMPC achieved a ~**50x** speedup for parameter tuning, leading to **2.44** m/s faster average racing speeds compared to hand-tuned baselines.
- The solver scaled to planning horizons exceeding 8000 discretization nodes in racing, enabling multi-corner planning, and successfully demonstrated differentiability for humanoid imitation learning and neural network training while satisfying constraints.

## Takeaways

> [!tip] Key Insights
> - A custom ADMM inner solver with adaptive step-size tuning and a specialized, smoothed projection for slack variables enhances convergence and robustness, particularly during parameter exploration in learning environments.
> - Implicit differentiation for the backward pass, combined with `cuDSS` as a uniform sparse direct factorization primitive, allows for efficient gradient computation despite differing sparsity structures between forward and backward passes.
> - A careful co-design involving JAX for the outer loop and a fused CUDA kernel for the ADMM inner loop minimizes GPU overheads, enabling both low-latency online control and high-throughput batched offline evaluation.
