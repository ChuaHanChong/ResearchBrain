# Personalized Exercise Recommendation with Semantically-Grounded Knowledge Tracing

> [!summary] Summary
> Researchers at ETH Zürich and LMU Munich developed ExRec, a comprehensive framework for personalized exercise recommendation that integrates semantically-grounded knowledge tracing with reinforcement learning. ExRec achieved substantial gains in student knowledge improvement, particularly through its Model-Based Value Estimation (MVE) which enhanced continuous RL algorithm performance by up to 2.4 percentage points, especially in dynamic learning scenarios and when scaling to larger question corpuses.

## Problem

- Existing Knowledge Tracing (KT) models for exercise recommendation often neglect the semantic content of questions, relying on identifier-based embeddings that limit generalization.
- Computational inefficiency arises from representing a student's state as their entire exercise history, hindering scalability for long learning sequences.
- Reward computation in Reinforcement Learning (RL) for recommendations is inefficient, often requiring extensive inference over many questions to assess knowledge improvement, which limits real-time application.
- Prior systems often lacked flexibility, supporting only a single RL algorithm or relying on hardcoded rewards and pre-defined question-KC graphs.

## Method

- **ExRec** implements an end-to-end framework starting with LLM-powered automated ==Knowledge Concept== (KC) annotation and mapping to solution steps.
- It employs contrastive learning to generate semantically rich embeddings for questions, solution steps, and KCs, moving beyond simple ID-based representations.
- A calibrated recurrent Knowledge Tracing (KT) model processes these embeddings to create compact student state representations and directly predict KC mastery.
- An RL framework, using the calibrated KT model as an environment, incorporates Model-Based Value Estimation (MVE) for continuous Q-learning methods, leveraging the KT model structure to stabilize and improve value function estimation and reward computation.

## Results

- MVE consistently boosted the performance of continuous value-based RL algorithms (DDPG, SAC, TD3) across all four evaluation tasks, with up to 2.4 percentage points higher knowledge improvement compared to baselines.
- MVE-augmented models demonstrated robustness to extended question corpuses, maintaining or improving performance, while non-MVE models experienced performance drops.
- Ablation studies showed that LLM-based KC annotation yielded higher quality KCs, and contrastive learning increased semantic coherence for KC retrieval (F1 score from **0.2305** to **0.8865**).
- KC calibration significantly reduced the Mean Absolute Error (MAE) for direct KC-level knowledge state prediction from **0.08** to **0.028**, validating efficient and accurate mastery estimation.

## Takeaways

> [!tip] Key Insights
> - Integrating semantically-grounded representations of questions and KCs significantly enhances the generalizability of recommendation systems to new content.
> - Efficiently predicting KC mastery directly from the KT model's latent student state, rather than inferring from numerous questions, is crucial for scalable reward calculation in RL.
> - Model-Based Value Estimation (MVE) stabilizes and improves the performance of continuous Q-learning algorithms by providing more structured and informed value estimates, particularly beneficial in dynamic learning environments.
> - LLMs can effectively automate the creation of high-quality, consistent KC annotations, reducing the reliance on costly and often inconsistent manual processes.
