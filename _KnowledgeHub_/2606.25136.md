# Memory Retrieval in Visuomotor Policies for Long-Horizon Robot Control

> [!summary] Summary
> HALO, a visuomotor policy, improves long-horizon robot control by mitigating spurious correlations and error accumulation in memory retrieval. It achieves this by distilling task-relevant priors from Vision-Language Models through Video Question-Answering and employing top-k sparse attention, resulting in 41% average absolute task success in simulation and 55% in real-world scenarios.

## Problem

- Robots need robust memory to perform diverse, long-horizon tasks in partially observable environments, but existing reactive visuomotor policies lack sufficient retrieval capabilities.
- Direct application of attention-based memory in robotic imitation learning leads to spurious correlations, causing policies to attend to task-irrelevant information.
- Long-horizon closed-loop execution can cause error accumulation, where small prediction errors compound in memory, leading to model drift and cascading failures.

## Method

- HALO, an attention-based visuomotor policy, integrates a memory retrieval mechanism from past observations and actions.
- It distills task-relevant priors from Vision-Language Models (VLMs) through a co-trained Video Question-Answering (VQA) objective to guide the retrieval mechanism.
- Top-k sparse attention is employed to limit the influence of noisy or irrelevant historical information, selecting only the most salient memory entries at each timestep.

## Results

- HALO achieved an average absolute task success of **41%** in simulation and **55%** in real-world scenarios, surpassing the Standard Transformer baseline (**22%** sim, **36%** real) and other prior methods.
- VLM-induced priors through VQA supervision improved average task success by **10%**, while top-k sparsification contributed a **9%** improvement and reduced model drift (Jensen-Shannon Divergence from **0.07** to **0.06**).
- The top-k sparse attention mechanism outperformed alternative sparsification strategies (e.g., Gated Attention) and latent-state compression methods like LSTM or Mamba.

## Takeaways

> [!tip] Key Insights
> - Distilling VLM priors through VQA provides effective supervision for memory retrieval, directing attention to causally relevant information and suppressing spurious correlations.
> - Top-k sparse attention significantly reduces model drift and error accumulation over long horizons by selectively retrieving only the most salient historical entries.
> - Co-training VQA with action prediction is crucial for grounding VLM priors in robotic control, proving more effective than pretraining or omitting VQA supervision.
