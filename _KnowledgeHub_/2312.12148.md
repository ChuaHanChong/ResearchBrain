# Parameter-Efficient Fine-Tuning Methods for Pretrained Language Models: A Critical Review and Assessment

> [!summary] Summary
> This paper provides a comprehensive review and assessment of Parameter-Efficient Fine-Tuning (PEFT) methods for pretrained language models, systematically categorizing existing techniques. An extensive empirical evaluation demonstrates that PEFT methods significantly reduce computational costs and memory requirements while achieving performance comparable to or better than full fine-tuning across various benchmarks.

## Problem

- Fine-tuning large language models (LLMs) requires substantial computational resources and GPU memory, making adaptation impractical for many researchers and organizations.
- High memory usage and slow training/inference times limit the accessibility and practical application of LLMs.
- Full fine-tuning can lead to catastrophic forgetting of pretrained knowledge in low-resource scenarios.

## Method

- ==Parameter-Efficient Fine-Tuning (PEFT)== adapts large pretrained models by updating only a small subset of existing parameters or introducing a limited number of new trainable parameters.
- PEFT methods are systematically categorized into five main types: ==Additive, Partial, Reparameterized, Hybrid, and Unified Fine-Tuning==.
- Specific techniques include ==Adapter-based methods== (e.g., (IA)³), ==Prompt-based methods== (e.g., Prefix Tuning), and low-rank adaptation (e.g., ==LoRA, QLoRA==).

## Results

- PEFT methods reduced memory usage on LLaMA-13B-Alpaca, with (IA)³ by **33.55%**, LoRA by **39.46%**, and QLoRA by **76.86%** compared to full fine-tuning.
- Most PEFT methods achieved performance comparable to or better than full fine-tuning on various benchmarks, despite updating significantly fewer parameters.
- On the GLUE benchmark, ProPELT demonstrated the best average performance with relatively few trainable parameters, while Prompt Tuning, though requiring the fewest parameters, yielded lower performance.

## Takeaways

> [!tip] Key Insights
> - PEFT methods significantly reduce computational and memory requirements compared to full fine-tuning, making large language models more accessible.
> - Many PEFT techniques achieve comparable or even improved performance relative to full fine-tuning on various benchmarks while using a fraction of the trainable parameters.
> - The effectiveness of PEFT in reducing memory usage becomes more pronounced as model size increases, highlighting their value for very large models.

## Detailed Report

### 1. Introduction

Large language models (LLMs) have revolutionized natural language processing, but their enormous size presents significant challenges for fine-tuning on downstream tasks. A 13-billion parameter model requires substantial computational resources, making adaptation impractical for many researchers and organizations with limited resources. This challenge has spurred the development of Parameter-Efficient Fine-Tuning (PEFT) methods, which aim to adapt these powerful models to specific tasks while minimizing computational costs.

This paper provides a comprehensive review and assessment of PEFT methods for pretrained language models (PLMs). Unlike previous surveys that either lack coverage of the latest developments or sufficient experimental validation, this review offers both a systematic categorization and extensive empirical evaluation of representative PEFT techniques.

### 2. Background and Motivation

Transformer-based PLMs like BERT, GPT, and more recently, models like LLaMA, have demonstrated remarkable performance across various NLP tasks. However, adapting these models through full fine-tuning requires updating all parameters, leading to prohibitive computational and storage costs. For instance, fine-tuning GPT-3 (175B parameters) would require approximately 350GB of GPU memory just to store the model parameters and gradients in half-precision.

Parameter-Efficient Fine-Tuning addresses these limitations by updating only a small subset of parameters or introducing a limited number of trainable parameters while keeping the majority of the pretrained model frozen. This approach offers several advantages:

1. Reduced computational requirements
2. Lower memory usage
3. Faster training and inference
4. Better generalization in low-resource scenarios
5. Prevention of catastrophic forgetting of pretrained knowledge

As PLMs continue to grow in size, PEFT methods become increasingly important for making these models accessible and practical for a wider range of applications and users.

### 3. Categorization of PEFT Methods

Based on comprehensive analysis, PEFT methods can be classified into five main categories:

1. **Additive Fine-Tuning**: Introduces new parameters while keeping the original model frozen
2. **Partial Fine-Tuning**: Updates only a subset of the original model parameters
3. **Reparameterized Fine-Tuning**: Transforms the parameter space to reduce the number of trainable parameters
4. **Hybrid Fine-Tuning**: Combines multiple PEFT approaches
5. **Unified Fine-Tuning**: Integrates various PEFT methods into a single framework

This categorization provides a systematic framework for understanding the diverse landscape of PEFT methods and their underlying principles.

### 4. Additive Fine-Tuning Methods

Additive fine-tuning methods add new parameters to the PLM architecture while keeping the original parameters frozen. Key examples include:

**Adapter-based Methods**:
Adapters are small neural networks inserted between layers of the pretrained model. The original adapter design introduced by Houlsby et al. consists of a down-projection, a non-linearity, and an up-projection, effectively creating a bottleneck architecture.

Subsequent developments include:
- **Sequential Adapter**: The first adapter method for PLMs
- **Adapter Fusion**: Combines multiple pretrained adapters
- **(IA)³**: Introduces scaling vectors for key model components
- **Parallel Adapter**: Places adapters in parallel rather than sequentially
- **Hyperformer++**: Uses hypernetworks to generate adapter parameters

**Prompt-based Methods**:
These methods add trainable parameters to the input space or hidden states:

- **Prompt Tuning**: Adds trainable soft prompts to the input embeddings
- **Prefix Tuning**: Prepends trainable prefix vectors to the hidden states of each transformer layer

Additive fine-tuning methods are particularly effective because they preserve the original knowledge encoded in the pretrained model while adding task-specific capabilities through the new parameters.

### 5. Partial Fine-Tuning Methods

Partial fine-tuning selectively updates a subset of the original model parameters. These methods include:

**BitFit**: Updates only the bias terms of the model while keeping other parameters frozen

**Diff Pruning**: Learns sparse differences from the pretrained model using L0 regularization

**Child-Tuning**: Identifies and updates only the task-relevant parameters while freezing others

**FISH Mask**: Selects parameters to fine-tune based on their importance to the target task

These methods leverage the insight that not all parameters contribute equally to model performance on specific tasks. By identifying and updating only the most relevant parameters, they achieve efficient adaptation while maintaining much of the pretrained knowledge.

### 6. Reparameterized Fine-Tuning Methods

Reparameterized fine-tuning transforms the parameter space to enable more efficient updates. The most prominent example is:

**Low-Rank Adaptation (LoRA)**: Approximates weight updates using low-rank decomposition.

Instead of directly updating a weight matrix W, LoRA parameterizes the update as:

ΔW = BA

Where B ∈ ℝ^(d×r) and A ∈ ℝ^(r×k) are low-rank matrices with rank r ≪ min(d,k).

Variants of LoRA include:
- **AdaLoRA**: Adaptively allocates parameter budget based on importance
- **QLoRA**: Combines LoRA with 4-bit quantization to reduce memory requirements
- **KronA**: Uses Kronecker products for parameter-efficient representation

The effectiveness of LoRA comes from its ability to capture most of the variation in weight updates using a small number of parameters, making it particularly suitable for very large models.

### 7. Hybrid and Unified Fine-Tuning Methods

**Hybrid Methods** combine different PEFT approaches to leverage their complementary strengths:
- **MAM Adapter**: Combines adapter-based and mask-based approaches
- **AutoPEFT**: Automatically searches for the optimal combination of PEFT methods

**Unified Methods** integrate various PEFT techniques into a single framework:
- **AdaMix**: Unifies multiple adapter methods
- **ProPELT**: Provides a probabilistic framework for learning and selecting PEFT methods

These approaches offer greater flexibility and potential for optimization across different tasks and models but may require more complex implementation and tuning.

### 8. Experimental Results and Performance Comparison

The paper presents extensive experimental evaluations of 11 representative PEFT methods across multiple tasks. Key findings include:

1. **Parameter Efficiency**: All PEFT methods significantly reduce the number of trainable parameters compared to full fine-tuning. For instance, in experiments with LLaMA-7B-Alpaca:

2. **Performance Comparison**: Most PEFT methods achieve comparable or even better performance than full fine-tuning on various benchmarks.

3. **Memory Usage**: PEFT methods significantly reduce memory requirements. For LLaMA-13B-Alpaca:
 - (IA)³ reduces memory usage by 33.55%
 - LoRA reduces memory usage by 39.46%
 - QLoRA reduces memory usage by 76.86%

4. **Efficiency vs. Performance Trade-offs**:
 - ProPELT achieves the best average performance on GLUE benchmark with relatively few trainable parameters
 - Prompt tuning requires the fewest parameters but yields lower performance
 - Sequential adapter requires more parameters than several other methods but achieves better performance on GLUE

5. **Scaling Benefits**: PEFT methods become more effective in reducing memory usage as model size increases, making them particularly valuable for very large models.

### 9. Applications and Future Directions

PEFT methods have demonstrated value in several advanced applications:

1. **Multi-task Learning**: Enabling efficient adaptation to multiple tasks while sharing knowledge
2. **Cross-lingual Transfer**: Facilitating adaptation to low-resource languages
3. **Backdoor Attack and Defense**: Improving model robustness against malicious fine-tuning

Future research directions include:
- Developing more efficient PEFT methods for even larger models
- Enhancing the effectiveness of PEFT methods for specific domains
- Exploring the theoretical foundations of PEFT effectiveness
- Combining PEFT with other efficiency techniques like quantization and pruning
- Investigating the use of PEFT for aligning models with human values

### 10. Conclusion

Parameter-Efficient Fine-Tuning methods have emerged as a crucial approach for adapting large pretrained language models to specific tasks while minimizing computational costs. This review provides a systematic categorization of PEFT methods into additive, partial, reparameterized, hybrid, and unified approaches, offering a comprehensive understanding of the current landscape.

The extensive experimental evaluation demonstrates that PEFT methods can achieve comparable or even better performance than full fine-tuning while using only a fraction of the trainable parameters and significantly reducing memory requirements. These benefits become more pronounced as model size increases, making PEFT particularly valuable for adapting very large language models.

As language models continue to grow in size and capability, PEFT methods will play an increasingly important role in making these powerful models accessible and practical for a wider range of applications and users with limited computational resources. Further research into optimizing and combining these methods will be essential for maximizing their potential benefits.
