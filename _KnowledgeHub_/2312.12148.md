# Parameter-Efficient Fine-Tuning Methods for Pretrained Language Models: A Critical Review and Assessment

> [!summary] Summary
> This paper provides a comprehensive review and assessment of Parameter-Efficient Fine-Tuning (PEFT) methods for pretrained language models, systematically categorizing existing techniques. An extensive empirical evaluation demonstrates that PEFT methods significantly reduce computational costs and memory requirements while achieving performance comparable to or better than full fine-tuning across various benchmarks.

## Problem

- Fine-tuning large language models (LLMs) requires substantial computational resources and GPU memory, making adaptation impractical for many researchers and organizations.
- High memory usage and slow training/inference times limit the accessibility and practical application of LLMs.
- Full fine-tuning can lead to catastrophic forgetting of pretrained knowledge in low-resource scenarios.

## Method

- ==Parameter-Efficient Fine-Tuning (PEFT)== adapts large pretrained models by updating only a small subset of existing parameters or introducing a limited number of new trainable parameters.
- PEFT methods are systematically categorized into five main types: ==Additive, Partial, Reparameterized, Hybrid, and Unified Fine-Tuning==.
- Specific techniques include ==Adapter-based methods== (e.g., (IA)³), ==Prompt-based methods== (e.g., Prefix Tuning), and low-rank adaptation (e.g., ==LoRA, QLoRA==).

## Results

- PEFT methods reduced memory usage on LLaMA-13B-Alpaca, with (IA)³ by **33.55%**, LoRA by **39.46%**, and QLoRA by **76.86%** compared to full fine-tuning.
- Most PEFT methods achieved performance comparable to or better than full fine-tuning on various benchmarks, despite updating significantly fewer parameters.
- On the GLUE benchmark, ProPELT demonstrated the best average performance with relatively few trainable parameters, while Prompt Tuning, though requiring the fewest parameters, yielded lower performance.

## Takeaways

> [!tip] Key Insights
> - PEFT methods significantly reduce computational and memory requirements compared to full fine-tuning, making large language models more accessible.
> - Many PEFT techniques achieve comparable or even improved performance relative to full fine-tuning on various benchmarks while using a fraction of the trainable parameters.
> - The effectiveness of PEFT in reducing memory usage becomes more pronounced as model size increases, highlighting their value for very large models.
