# Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality

> [!summary] Summary
> The Structured State Space Duality (SSD) framework establishes a mathematical connection between Transformers and Structured State Space Models (SSMs) through the lens of structured matrices. This framework enables the development of the SSD algorithm for efficient SSM computation and the Mamba-2 architecture, which achieves better perplexity on language modeling tasks with fewer FLOPs compared to Mamba and Transformer++ models.

## Problem

- Transformer architectures have quadratic computational complexity with respect to sequence length, limiting their application for very long sequences.
- A lack of a unified theoretical understanding between different sequence modeling families like Transformers and Structured State Space Models (SSMs) hinders the transfer of architectural and algorithmic optimizations.
- Previous implementations of SSMs faced computational bottlenecks that limited the practical use of larger state dimensions, impacting model capacity.

## Method

- The ==Structured State Space Duality (SSD)== framework is introduced, establishing a mathematical connection where ==SSMs== are represented as ==semiseparable matrices== and generalize ==linear attention==.
- A novel ==SSD algorithm== is developed for efficient computation of SSMs by leveraging the ==block decomposition== properties of semiseparable matrices, balancing ==linear recurrence== with hardware-efficient matrix multiplication.
- **Mamba-2**, an improved SSM architecture, is designed based on SSD insights, incorporating ==parallel projections==, additional normalization, and ==multi-head patterns== inspired by Transformers.

## Results

- Mamba-2 achieves better perplexity on the Pile language modeling dataset with fewer FLOPs compared to both Mamba and Transformer++ models.
- The SSD algorithm significantly outperforms previous optimized selective scan implementations for SSMs, especially when utilizing larger state dimensions, improving computational efficiency.
- Mamba-2 demonstrates superior performance on the synthetic associative recall task, particularly with larger state dimensions, compared to prior Mamba and attention-based models.

## Takeaways

> [!tip] Key Insights
> - Both Structured State Space Models (SSMs) and certain variants of attention mechanisms (linear attention) can be understood as operations involving structured matrices, revealing a mathematical duality.
> - SSMs are mathematically equivalent to multiplication by semiseparable matrices, a class of structured matrices well-studied in numerical linear algebra, enabling the transfer of efficient algorithms.
> - Insights from the Structured State Space Duality (SSD) framework allow for the incorporation of Transformer-like design principles, such as parallel projections and multi-head patterns, into SSM architectures to enhance performance.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

#### 1.1. Introduction

The field of sequence modeling has been dominated by Transformer architectures since their introduction in 2017. However, their quadratic computational complexity with respect to sequence length has remained a significant limitation, particularly for processing long sequences. In parallel, Structured State Space Models (SSMs) have emerged as promising alternatives that offer linear scaling in sequence length while still delivering competitive performance.

In the paper "Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality," authors Tri Dao and Albert Gu establish a profound mathematical connection between these seemingly different model families through a framework called Structured State Space Duality (SSD).

### 2. Key Objectives and Motivation

#### 2.1. Objectives of the SSD Framework

The SSD framework provides a unified mathematical perspective on sequence modeling architectures by revealing that both Transformers and SSMs can be understood as operations involving structured matrices. This insight enables the transfer of optimizations between model families and leads to the development of more efficient algorithms and improved architectures.

### 3. Methodology and Approach

#### 3.1. Theoretical Framework: Structured State Space Duality

The SSD framework is built on the fundamental insight that sequence transformations can be represented as matrix multiplication operations. When computing the output of a sequence model, we can view this as multiplying the input sequence by a transformation matrix M:

Y = MX

where X represents the input sequence and Y the output sequence.

The key discovery is that both SSMs and certain variants of attention mechanisms (specifically, linear attention) can be represented as operations involving structured matrices with specific patterns. This connection allows for the development of algorithms that leverage the mathematical properties of these matrices to achieve better computational efficiency.

#### 3.2. SSMs and Semiseparable Matrices

A central component of the SSD framework is the equivalence established between SSMs and semiseparable matrices. Semiseparable matrices are a well-studied class of structured matrices in numerical linear algebra.

A semiseparable matrix has the property that any submatrix contained strictly below (or above) the main diagonal has low rank. Mathematically, a lower semiseparable matrix M can be represented as:

$$
M_{i,j} = \begin{cases}
C_i^T A_{i,j} B_j & \text{if } i \geq j \\
D_{i,j} & \text{if } i < j
\end{cases}
$$

where the matrices A, B, C, and D have specific structures.

The authors demonstrate that the recurrent computation in an SSM can be exactly represented as multiplication by a semiseparable matrix. This means that the linear-time recurrence of SSMs:

$$h_t = \bar{A}h_{t-1} + \bar{B}x_t$$
$$y_t = \bar{C}h_t$$

is equivalent to multiplication by a semiseparable matrix with a specific structure.

#### 3.3. Structured Masked Attention

The authors further extend their framework by introducing the concept of Structured Masked Attention (SMA), which generalizes linear attention mechanisms through the lens of structured matrices.

In standard softmax attention, the attention weights between tokens are computed using the softmax function:

$$\text{Attention}(Q, K, V) = \text{softmax}(QK^T)V$$

The authors show that linear attention variants can be viewed as operations involving structured matrices. Specifically, when the softmax is replaced with other similarity functions, linear attention becomes equivalent to:

$$\text{LinearAttention}(Q, K, V) = (Q \odot (K^T V))$$

where ⊙ represents the appropriate tensor contraction. This operation can be interpreted as a multiplication by a structured matrix, connecting it to the semiseparable representation of SSMs.

The SSD framework reveals that a specific class of SSMs is mathematically equivalent to linear attention with a causal mask, which the authors term "1-Semiseparable SMA." This equivalence is visualized in Figure 4.

#### 3.4. The SSD Algorithm

Based on the established mathematical connections, the authors develop a novel algorithm called SSD for computing SSMs. The SSD algorithm leverages the block decomposition properties of semiseparable matrices to balance the tradeoff between the linear SSM recurrence and the quadratic dual form.

The algorithm works by decomposing the semiseparable matrix into blocks with specific structures:
1. Diagonal blocks that directly map inputs to outputs
2. Low-rank blocks that map inputs to states
3. Low-rank blocks that transform states
4. Low-rank blocks that map states to outputs

This decomposition allows for an efficient implementation that balances:
- The linear complexity of the recurrent formulation (advantageous for very long sequences)
- The parallelism and hardware efficiency of matrix multiplication (advantageous for modern accelerators)

The SSD algorithm achieves significant performance improvements over previous implementations of SSMs, particularly for large state dimensions. It is especially efficient when implemented using modern accelerators with high-performance matrix multiplication units.

Benchmarks show that SSD outperforms the optimized selective scan implementation used in Mamba and becomes more advantageous as the state dimension increases (Figure 9).

#### 3.5. Mamba-2 Architecture

Leveraging insights from the SSD framework, the authors introduce Mamba-2, an improved SSM architecture that incorporates design principles from Transformers. Key architectural improvements include:

1. **Parallel projections**: The original Mamba architecture computes the SSM parameters sequentially, while Mamba-2 computes them in parallel, similar to how multi-head attention works in Transformers.

2. **Extra normalization**: Mamba-2 incorporates additional normalization layers, similar to modern Transformer designs.

3. **Multi-head patterns**: Inspired by multi-head attention, Mamba-2 splits the computation across multiple heads, each with its own parameters.

4. **Efficient training optimizations**: The architecture supports tensor parallelism and sequence parallelism for distributed training.

### 4. Main Findings and Results

#### 4.1. Experimental Results

The authors conduct extensive experiments to validate the effectiveness of both the SSD algorithm and the Mamba-2 architecture:

1. **Associative recall task**: On this synthetic benchmark, Mamba-2 significantly outperforms both Mamba and attention-based models, especially with larger state dimensions.

2. **Language modeling**: On the Pile dataset, Mamba-2 achieves better perplexity than both Mamba and Transformer++ models while requiring fewer FLOPs.

3. **Efficiency benchmarks**: The SSD algorithm demonstrates significant speed advantages over the optimized scan implementation, especially with larger state dimensions.

The experimental results demonstrate that Mamba-2 is not only more efficient than Transformers in handling long sequences but also achieves better performance on standard language modeling benchmarks. Additionally, the SSD algorithm enables the use of much larger state dimensions than was previously practical with SSMs, further enhancing model capacity and performance.

### 5. Significance and Potential Impact

#### 5.1. Implications and Future Directions

The SSD framework introduces several important implications for sequence modeling:

1. **Unified understanding**: By establishing mathematical connections between Transformers and SSMs, the framework provides a unified view of sequence models that could lead to further architectural innovations.

2. **Algorithmic transfer**: The framework enables the transfer of algorithmic optimizations between model families, as demonstrated by the application of Transformer-style parallelism techniques to SSMs.

3. **Architectural improvements**: The insights from SSD led to significant improvements in the Mamba architecture, suggesting that further cross-pollination between model families could yield additional benefits.

The theoretical foundations established in this work open several directions for future research:

- Exploring non-causal variants of Mamba for bidirectional modeling
- Developing SSM variants with different structured matrix patterns
- Further bridging the gap between softmax attention and linear-complexity models
- Applying interpretability techniques from Transformers to SSMs

The semiseparable matrix representation also provides new mathematical tools for analyzing the expressivity and limitations of different sequence models. For example, the block decompositions shown in Figures 3 and 4 illustrate how different structured patterns in the matrix can lead to models with different computational properties and inductive biases.

```python
# Example pseudocode for the SSD algorithm
def ssd_forward(x, A, B, C, D, block_size):
    """
    Implements the SSD algorithm for efficient SSM computation
    x: input sequence [batch, length, dim]
    A, B, C, D: SSM parameters
    block_size: size of blocks for decomposition
    """
    length = x.shape[1]
    num_blocks = (length + block_size - 1) // block_size

    # Initialize output
    y = torch.zeros_like(x)

    # Initialize state
    h = torch.zeros([batch, state_dim, dim])

    for i in range(num_blocks):
        # Get current block
        start_idx = i * block_size
        end_idx = min((i + 1) * block_size, length)
        x_block = x[:, start_idx:end_idx, :]

        # Direct input to output (diagonal block)
        y[:, start_idx:end_idx, :] = D @ x_block

        # Input to state (low-rank block)
        h_new = B @ x_block

        # State update (low-rank block)
        h = A @ h + h_new

        # State to output (low-rank block)
        y[:, start_idx:end_idx, :] += C @ h

    return y
```

The SSD framework represents a significant advancement in our understanding of sequence models, revealing deep connections between seemingly different architectures and enabling more efficient algorithms. Mamba-2, built on these insights, demonstrates that SSMs can match or exceed the performance of Transformers while maintaining linear scaling in sequence length, potentially opening new possibilities for modeling very long sequences in natural language processing, time series analysis, and other domains.
