# A Finite Sample Analysis of Distributional TD Learning with Linear Function Approximation

> [!summary] Summary
> Peng et al. provide the first non-asymptotic statistical analysis for distributional Temporal Difference (TD) learning with linear function approximation, demonstrating that learning the entire return distribution is statistically as efficient as learning its expectation. Their proposed Linear-Categorical TD (Linear-CTD) algorithm achieves an O(T⁻¹ᐟ²) L2 convergence rate and matches the sample complexity of classical Linear-TD.

## Problem

- Classical policy evaluation estimates only the expected return, which is insufficient for risk-sensitive decision-making and understanding outcome uncertainty.
- While distributional TD learning (DRL) emerged to estimate full return distributions, its non-asymptotic statistical properties with function approximation were largely unexplored.
- It was unknown whether the statistical efficiency observed in tabular DRL (learning distributions being as efficient as expectations) would persist when using function approximation for scalability.

## Method

- An improved Linear-Categorical TD (**Linear-CTD**) algorithm is proposed, which uses linear function approximation and categorical parameterization to represent return distributions.
- Linear-CTD is derived by applying linear stochastic approximation to solve the projected distributional Bellman equation, acting as a preconditioned semi-gradient descent that mitigates issues with categorical support scaling.
- The analysis utilizes a fine-grained examination of the linear-categorical Bellman equation and exponential stability arguments for random matrices to establish non-asymptotic convergence bounds.

## Results

- The work establishes the first non-asymptotic statistical guarantees for distributional TD learning under linear function approximation.
- Linear-CTD achieves an O(T⁻¹ᐟ²) L2 convergence rate and its sample complexity matches state-of-the-art bounds for classical Linear-TD learning.
- Empirical evaluations confirm Linear-CTD's stable convergence across different categorical supports and its improved performance over vanilla stochastic semi-gradient descent (SSGD), which struggles with larger support numbers.

## Takeaways

> [!tip] Key Insights
> - Learning the full return distribution with linear function approximation does not incur additional statistical cost compared to learning only its expectation.
> - The preconditioning mechanism within Linear-CTD is essential for robust convergence rates that are independent of the number of categorical supports (K).
> - Linear-CTD generalizes classical Linear-TD by preserving the mean estimation property, ensuring consistent expected value estimates.
