# Global Prior Meets Local Consistency: Dual-Memory Augmented Vision-Language-Action Model for Efficient Robotic Manipulation

> [!summary] Summary
> OptimusVLA, a dual-memory augmented Vision-Language-Action model, enhances robotic manipulation by incorporating Global Prior Memory for efficient action generation and Local Consistency Memory for temporal robustness. The framework achieves higher success rates across simulation and real-world tasks, along with a 2.9x real-world inference speedup.

## Problem

- VLA models suffer from low inference efficiency due to a large distributional gap between generic noise priors and structured target action distributions, requiring numerous denoising steps.
- Current VLA models exhibit poor robustness to temporal dependencies, struggling with task phase awareness and producing jittery control due to a lack of action history context.
- Existing approaches to incorporate temporal context (e.g., long observation sequences, repeated VLM invocation) often incur high computational overhead and memory usage.

## Method

- **OptimusVLA** introduces a hierarchical VLA framework augmented with a ==Global Prior Memory== (GPM) and a ==Local Consistency Memory== (LCM).
- GPM constructs a task-level prior action distribution by retrieving semantically similar trajectories from an offline memory bank, adaptively adjusting noise scale and Number of Function Evaluations (NFE) based on retrieval confidence.
- LCM dynamically models recent action history using a consistency layer and a Mamba-based module to predict a consistency bias, which is then injected into the sampled action chunk to promote temporal coherence.

## Results

- Achieved an average **98.6%** success rate on LIBERO and **38%** on RoboTwin 2.0 Hard, outperforming existing baselines like \pi_{**0.5**} (**96.9%** and **29%** respectively).
- Delivered a **2.9x** inference speedup in real-world evaluations and up to **6.5x** faster inference in simulation, reducing the average Number of Function Evaluations to 3.2 on LIBERO from 10.0.
- Demonstrated enhanced robustness in real-world generalization tasks (**85.0%** success rate) and long-horizon tasks (**64.0%** success rate), with ablation studies confirming the independent contributions of GPM and LCM.

## Takeaways

> [!tip] Key Insights
> - Leveraging task-level, semantics-conditioned priors via GPM significantly narrows the prior-target distributional gap, leading to faster, more feasible action generation with fewer denoising steps.
> - A lightweight memory mechanism (LCM) effectively provides temporal awareness by modeling recent action history, enabling smoother trajectories and robust behavior in multi-stage tasks without incurring substantial computational cost.
> - Adaptive control over noise scale and NFEs, guided by the confidence in retrieved priors, balances efficiency with the necessary exploration for robust action generation.
