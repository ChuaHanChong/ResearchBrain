# Beyond Sliding Windows: Learning to Manage Memory in Non-Markovian Environments

> [!summary] Summary
> Adaptive Stacking introduces a meta-algorithm enabling reinforcement learning agents to learn selective memory retention, allowing them to manage fixed-size working memory effectively in non-Markovian environments. This approach achieves performance comparable to or exceeding traditional fixed-window methods while utilizing significantly less memory and demonstrating superior generalization, such as 100% success on mazes 62,500 times longer than training examples.

## Problem

- Reinforcement learning (RL) agents struggle to operate efficiently in partially observable, non-Markovian environments that require remembering information over long time horizons.
- Traditional memory management, like Frame Stacking (FS), uses a fixed-size window of recent observations, leading to prohibitive computational and memory costs for long dependencies (k*) and poor generalization.
- Existing sequence models (RNNs, Transformers) often still rely on fixed context windows, limiting their ability to handle very long-term, sparse dependencies effectively.

## Method

- **Adaptive Stacking** (AS) is introduced as a meta-algorithm that allows RL agents to learn which observations to retain or discard in a fixed-size working memory stack.
- Memory management is integrated into the standard RL loop, where agents learn memory actions (which observation to pop) alongside environment actions to maximize cumulative reward.
- AS is architecture-agnostic, applicable to various RL algorithms (e.g., Q-learning, PPO) and neural network architectures (MLP, LSTM, ==Transformer==).

## Results

- Adaptive Stacking with minimal memory (κ) achieved returns comparable to or superior to oracle Frame Stacking (k*) on memory-intensive tasks like TMaze, demonstrating significantly lower passive memory regret.
- AS agents showed superior out-of-distribution generalization, maintaining **100%** success rates on mazes up to length 10^6 after training on mazes of length 16, while oracle FS (k*=16) failed.
- The benefits of Adaptive Stacking were consistently observed across diverse deep learning architectures (MLP, LSTM, Transformer) and various complex domains, including XorMaze, Rubik's Cube, MiniGrid-Memory, and FetchReach.

## Takeaways

> [!tip] Key Insights
> - Optimal decision-making in many non-Markovian environments depends on a minimal sufficient memory (κ), which can be much smaller and sparser than the full Markovian history (k*).
> - By learning to selectively prune irrelevant past observations, agents can form more compact, reward-relevant internal states, drastically reducing computational and memory requirements.
> - The meta-algorithm provides theoretical guarantees for convergence to an optimal policy with memory size k ≥ κ for both unbiased (Monte Carlo) and biased (TD-learning) value estimates under certain conditions.
