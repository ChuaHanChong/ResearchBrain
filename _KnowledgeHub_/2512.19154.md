# Beyond Sliding Windows: Learning to Manage Memory in Non-Markovian Environments

> [!summary] Summary
> Adaptive Stacking introduces a meta-algorithm enabling reinforcement learning agents to learn selective memory retention, allowing them to manage fixed-size working memory effectively in non-Markovian environments. This approach achieves performance comparable to or exceeding traditional fixed-window methods while utilizing significantly less memory and demonstrating superior generalization, such as 100% success on mazes 62,500 times longer than training examples.

## Problem

- Reinforcement learning (RL) agents struggle to operate efficiently in partially observable, non-Markovian environments that require remembering information over long time horizons.
- Traditional memory management, like Frame Stacking (FS), uses a fixed-size window of recent observations, leading to prohibitive computational and memory costs for long dependencies (k*) and poor generalization.
- Existing sequence models (RNNs, Transformers) often still rely on fixed context windows, limiting their ability to handle very long-term, sparse dependencies effectively.

## Method

- **Adaptive Stacking** (AS) is introduced as a meta-algorithm that allows RL agents to learn which observations to retain or discard in a fixed-size working memory stack.
- Memory management is integrated into the standard RL loop, where agents learn memory actions (which observation to pop) alongside environment actions to maximize cumulative reward.
- AS is architecture-agnostic, applicable to various RL algorithms (e.g., Q-learning, PPO) and neural network architectures (MLP, LSTM, ==Transformer==).

## Results

- Adaptive Stacking with minimal memory (κ) achieved returns comparable to or superior to oracle Frame Stacking (k*) on memory-intensive tasks like TMaze, demonstrating significantly lower passive memory regret.
- AS agents showed superior out-of-distribution generalization, maintaining **100%** success rates on mazes up to length 10^6 after training on mazes of length 16, while oracle FS (k*=16) failed.
- The benefits of Adaptive Stacking were consistently observed across diverse deep learning architectures (MLP, LSTM, Transformer) and various complex domains, including XorMaze, Rubik's Cube, MiniGrid-Memory, and FetchReach.

## Takeaways

> [!tip] Key Insights
> - Optimal decision-making in many non-Markovian environments depends on a minimal sufficient memory (κ), which can be much smaller and sparser than the full Markovian history (k*).
> - By learning to selectively prune irrelevant past observations, agents can form more compact, reward-relevant internal states, drastically reducing computational and memory requirements.
> - The meta-algorithm provides theoretical guarantees for convergence to an optimal policy with memory size k ≥ κ for both unbiased (Monte Carlo) and biased (TD-learning) value estimates under certain conditions.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This paper addresses a critical and long-standing challenge in Reinforcement Learning (RL): enabling agents to operate effectively in **partially observable, non-Markovian environments** while facing **computational and memory constraints**. This problem becomes particularly acute when deploying agents in "big worlds," where relevant information might be sparsely distributed over long temporal distances.

Traditionally, RL algorithms are formulated under the Markov assumption, implying that the current observation contains all necessary information for optimal decision-making. However, real-world scenarios often violate this assumption. Past observations frequently hold crucial context, leading to non-Markovian dependencies. Existing approaches to tackle this issue include:

- **Belief State Estimation in POMDPs:** While theoretically sound, maintaining a belief state (a distribution over true underlying states) is computationally intractable for complex, high-dimensional environments due to exponential scaling.
- **Frame Stacking (FS):** This is the predominant practical heuristic, where a fixed window of the `k` most recent observations (and actions) is concatenated to form the agent's input. While effective for short-term dependencies (e.g., in Atari games where `k=4` frames capture motion), its limitations become severe in domains requiring much longer memory horizons (`k*`). Increasing `k` leads to an exponential increase in observation space dimensionality, causing prohibitive computational (e.g., `Ω(k^2)` for Transformers) and memory requirements, hindering sample efficiency and generalization.
- **Sequence Models (RNNs, Transformers, SSMs):** These architectures are designed to process sequential data and implicitly learn hidden state representations from histories. While powerful, they often still rely on Frame Stacking for bounded computation during online learning (e.g., back-propagation through time for RNNs, context window for Transformers). Papers like Ni et al. (2023) have shown Transformers can remember cues over long periods but struggle with credit assignment, still using FS to define the context window.
- **Dynamic Memory Architectures (NTM, DNC):** More ambitious neural architectures, such as Neural Turing Machines and Differentiable Neural Computers, aimed to provide explicit, differentiable external memory. While offering high expressivity, their training complexity and computational overhead have limited their practical adoption and scalability in mainstream RL.
- **State Abstraction and Memory Management Actions:** Some work has focused on learning compact predictive memory representations or providing agents with explicit actions to manage memory (e.g., Peshkin et al., 1999; Demir, 2023). However, these often retain a FIFO-like memory structure for full stacks or use intrinsic motivation heuristics, which may not guarantee optimality or robust performance.

This paper positions itself as a **meta-algorithm** that builds "Beyond Sliding Windows." Instead of developing a new underlying sequence model or relying on fixed-size memory heuristics, Adaptive Stacking (AS) provides a general framework for agents to *learn to manage their memory*. It directly addresses the limitation that while `k*` (the theoretically optimal memory length for full observability) might be very large, `κ` (the *minimal sufficient memory* to maintain optimal decision-making) can be much smaller. This approach aligns with cognitive neuroscience insights into human working memory, which employs selective gating mechanisms to retain task-relevant information and filter distractors.

Furthermore, the paper draws parallels to challenges in **Long Context Modelling in Large Language Models (LLMs)** (discussed in Appendix A). LLMs also face issues like quadratic complexity of self-attention, recency bias, attention dilution, and the impact of distractors in long contexts. Adaptive Stacking offers a conceptual solution in RL that could inspire similar memory-pruning mechanisms in LLMs to improve efficiency and robustness. By learning to discard irrelevant context, AS could mitigate issues prevalent in current LLM architectures, such as the "lost in the middle" phenomenon.

### 2. Key Objectives and Motivation

The primary motivation for this work stems from the inherent limitations of conventional memory management strategies in reinforcement learning, particularly Frame Stacking, when applied to increasingly complex and realistic environments.

The **key motivations** can be summarized as:
1. **Addressing Computational and Memory Scalability in Non-Markovian Environments:** Real-world tasks often exhibit long-term, non-Markovian dependencies. Frame Stacking, the prevailing approach, requires the memory window size (`k*`) to grow with the degree of non-Markovianness. This leads to prohibitive increases in computational load and memory footprint for both action inference and policy learning, especially for deep sequence models like Transformers (which scale quadratically with `k`).
2. **Exploiting Sparsity of Causal Dependencies:** The central insight is that many highly non-Markovian environments do not require remembering *all* past observations. Instead, optimal decision-making might only depend on a relatively *small, sparse subset* of observations (`κ`) over the relevant time scale, even if these observations are separated by long temporal distances. Frame Stacking fails to leverage this sparsity.
3. **Enhancing Sample Efficiency and Generalization:** A large, unpruned memory stack (as in Frame Stacking with large `k*`) not only consumes more resources but also expands the policy's input space, potentially leading to poor sample efficiency and generalization capabilities. A compact, task-relevant memory representation could alleviate these issues.
4. **Drawing Inspiration from Cognitive Science:** The paper is motivated by findings in cognitive neuroscience, where human working memory selectively retains task-relevant information and filters out distractors, thus operating efficiently under limited capacity.

Based on these motivations, the **key objectives** of this research are:
1. **Propose Adaptive Stacking (AS) as a Meta-Algorithm:** Introduce a general-purpose meta-algorithm that enables RL agents to *learn* to selectively retain or discard observations in a fixed-size working memory (`k`). This contrasts with Frame Stacking's passive, FIFO (first-in, first-out) approach.
2. **Quantify Resource Savings:** Demonstrate that by allowing `κ ≪ k*`, Adaptive Stacking can achieve substantial savings in computational and memory requirements for various agent architectures (MLP, LSTM, Transformer).
3. **Provide Theoretical Guarantees:** Establish theoretical foundations for Adaptive Stacking, including convergence guarantees to an optimal policy, under conditions where standard RL algorithms struggle (i.e., when memory is limited to `κ`). This involves analyzing its behavior with unbiased value estimates (Monte Carlo) and biased estimates (TD-learning).
4. **Empirically Validate Performance:** Conduct comprehensive experiments across challenging memory-intensive tasks to demonstrate that Adaptive Stacking leads to better memory management, improved sample efficiency, and superior generalization compared to Frame Stacking, especially under tight memory budgets or unknown `k*`.

### 3. Methodology and Approach

The core contribution of this paper is **Adaptive Stacking (AS)**, a meta-algorithm designed to provide reinforcement learning agents with explicit control over their working memory.

#### 3.1. Adaptive Stacking Mechanism

- **Memory Stack:** Unlike Frame Stacking, which rigidly stores the `k` most recent observations, AS maintains a memory stack `s_t = [x_i1..., x_ik]` of fixed size `k`. The last element `x_ik` is always the current observation `x_t`.
- **Memory Actions:** When a new observation `x_t+1` arrives and the stack is full, the agent performs two actions:
 1. An **environment action** `a_t ∈ A`.
 2. A **memory action** `i_t ∈ {1..., k}`. This action dictates *which* observation in the current stack `s_t` should be "popped" (removed) to make space for `x_t+1`. The new observation `x_t+1` is then "pushed" onto the stack.
- **Integrated RL Loop:** This memory management decision is integrated directly into the standard RL loop. The agent's policy `π_k(a_t, i_t | s_t)` is now defined over both environment actions and memory actions, and it learns to maximize the same long-term accumulated reward signal. This means memory management is learned end-to-end, driven by its impact on future rewards.
- **Generality:** AS is a meta-algorithm, meaning it can be applied on top of various underlying RL algorithms (e.g., Q-learning, PPO) and neural network architectures (MLP, LSTM, Transformer), transforming how they handle sequential inputs.

#### 3.2. Theoretical Analysis

The paper provides significant theoretical groundwork for AS, addressing critical questions about convergence and optimality:
- **Minimal Sufficient Memory (κ):** The authors define `κ` as the smallest memory length for which an optimal policy can exist, even in a non-Markovian environment. This is a crucial distinction from `k*`, the length required for the environment to be Markovian with respect to raw observations.
- **Convergence with Unbiased Value Estimates (Theorem 1, Corollaries 2 & 3):**
 - **Theorem 1:** States that if an RL algorithm uses *unbiased value estimates* (e.g., Monte Carlo returns in policy gradient methods like REINFORCE) and is guaranteed to converge under Frame Stacking with `k ≥ k*`, it will also converge under Adaptive Stacking with `k ≥ κ`. This is a powerful result, as `κ` can be much smaller than `k*`.
 - **Corollaries 2 & 3:** Extend this to episodic Monte Carlo policy gradient with softmax-linear policies and entropy regularization, and to unichain average-reward settings, respectively.
- **Value-Consistency (Assumption 4.1, Theorem 2):**
 - **Assumption 4.1 (Value-Consistency):** Postulates that for a given memory state `s_t` and policy `π_k`, all possible underlying full histories `x_t:t-k*` that could lead to `s_t` must yield the same expected future value `V_πk(x_t:t-k*)`. This ensures that the memory compression performed by AS does not discard information critical for discerning value. The paper notes that this assumption holds for a wide range of common RL tasks (e.g., goal-reaching with sparse rewards).
 - **Theorem 2 (Partial-order Preserving):** Under the value-consistency assumption, if one AS policy `π1_k` has a lower value than another `π2_k` in the induced memory process, this ordering also holds for their values conditioned on the true underlying histories. This property is crucial for the convergence of value-based methods.
- **Convergence with TD-Learning (Theorem 5):** Leverages Theorem 2 to show that Q-learning, when applied to the AS-induced decision process with `k ≥ κ` and under the value-consistency assumption, converges to an optimal policy. This is significant because TD-learning uses biased, bootstrapped estimates, which generally complicate convergence in POMDPs.
- **Computational and Memory Efficiency (Table 1):** The theoretical analysis quantifies the resource savings. For MLP and LSTM, AS reduces complexity from `Ω(k*)` to `Ω(κ)`. For Transformers, it reduces compute from `Ω(k*^2)` to `Ω(κ^2)` and memory from `Ω(k*)` to `Ω(κ)`, representing substantial gains when `κ ≪ k*`.

#### 3.3. Experimental Setup

- **Environments:** The authors use a suite of memory-intensive tasks:
 - **Passive-TMaze and Active-TMaze:** Canonical memory tasks, in both episodic and continual settings, where `k*` scales with maze length, but `κ = 2` (remembering the initial goal cue and current position).
 - **XorMaze:** A more complex T-maze variant requiring memory of two cues and their XOR logical combination.
 - **2x2 Rubik's Cube:** Partially observable task where only one face is visible at a time.
 - **MiniGrid-Memory:** A grid-world requiring navigation based on an early-seen goal object.
 - **FetchReach (Modified):** A continuous control robotics task where goal position is only briefly observable, demanding long-term memory of the goal and short-term memory of joint positions for velocity inference.
- **Baselines:**
 - **FrameStack (FS) with `k = κ`:** A naive baseline using insufficient memory.
 - **FrameStack (FS) with `k = k*`:** An "oracle" baseline that knows the true optimal memory length.
- **RL Algorithms & Architectures:** Experiments are conducted with Q-learning (tabular) and Proximal Policy Optimization (PPO) using various deep learning architectures: Multi-Layer Perceptrons (MLP), Long Short-Term Memory (LSTM), and Transformers.
- **Metrics:** Beyond standard returns, critical metrics include: Memory Regret (goal cue absent from memory), Active Memory Regret (goal cue seen but not stored), and Passive Memory Regret (goal cue in memory but discarded). These metrics specifically evaluate the learned memory management.

### 4. Main Findings and Results

The experiments consistently demonstrate the effectiveness and efficiency of Adaptive Stacking across a variety of memory-intensive tasks and agent architectures.

1. **Superior Memory Management and Performance:**
 - In both continual Passive-TMaze and Active-TMaze tasks (Figure 4), Adaptive Stacking (AS) with minimal memory (`k = κ = 2`) achieves returns comparable to, or even exceeding, the oracle FrameStack (FS) with `k = k*`. This is particularly evident as maze length (and thus `k*`) increases.
 - Crucially, AS (`κ`) exhibits significantly lower **passive memory regret** than FS (`κ`), meaning it successfully learns to preserve the critical goal cues over long delays, unlike FS which blindly discards old information. FS (`κ`) often fails entirely to solve tasks with `k* > κ`.
 - Even the oracle FS (`k*`) incurs some memory regret in continual tasks, as it must re-observe cues, whereas AS actively decides when to reset memory.

2. **Enhanced Generalization Capabilities:**
 - Experiments on episodic Passive-TMaze with random corridor lengths (Figure 5) show that AS (`κ`) outperforms FS (`κ`) and matches FS (`k*`) in returns and memory regret.
 - A striking result (Figure 1 in the paper, also detailed in Supplementary Figures 24-28) is AS's ability to **generalize to maze lengths far exceeding what was seen during training**. When trained on a maze of length 16 and tested on length 10^6, AS (κ=2) achieves 100% success rate across all architectures (MLP, LSTM, Transformer). In contrast, the oracle FS (k*=16) fails completely in this extreme out-of-distribution scenario.
 - This superior generalization is attributed to AS learning more compact, reward-relevant agent states by discarding irrelevant observations, which prevents overfitting to specific `k*` values.

3. **Architecture Agnosticism:**
 - The benefits of Adaptive Stacking are consistently observed regardless of the underlying neural network architecture—MLP, LSTM, or Transformer (Figures 10-11 for Passive-TMaze, Figure 6 for other domains). This highlights AS's strength as a general meta-algorithm applicable to diverse deep RL setups.
 - Interestingly, even LSTM and Transformer models using oracle FS (`k*`) can struggle with generalization or exhibit performance degradation, reinforcing that intelligent memory management is a key factor beyond just model capacity. Ni et al. (2023) also found LSTMs struggle with memory assignment and Transformers with credit assignment, a behavior consistent with FS's limitations even with powerful sequence models.

4. **Performance Across Diverse and Complex Domains:**
 - AS successfully transfers its advantages to more complex tasks like the XorMaze, Rubik's Cube, MiniGrid-Memory, and the modified FetchReach (Figure 6).
 - In FetchReach, AS (`κ = 4`) even outperforms the oracle FS (`k* = 50`), especially under extreme distribution shifts (e.g., remembering the goal after 10^6 steps). This suggests that `k*` might be an overly pessimistic bound, and a learned `κ` can be more effective.

5. **Validation of Theoretical Predictions:**
 - The empirical results strongly support the theoretical claims, demonstrating that AS can learn optimal policies with a memory size `k ≥ κ` (minimal sufficient memory) and yield significant compute and memory savings. The value-consistency assumption (Assumption 4.1) appears to hold true for the benchmarks tested, allowing TD-learning to converge effectively.

### 5. Significance and Potential Impact

The work presented in "BEYOND SLIDING WINDOWS: LEARNING TO MANAGE MEMORY IN NON-MARKOVIAN ENVIRONMENTS" represents a significant step forward in developing more efficient, scalable, and robust reinforcement learning agents, with implications extending beyond RL to other sequential decision-making and context-dependent AI systems.

1. **Enabling Scalable RL in Complex Environments:** The most direct impact is on the deployment of RL agents in "big worlds"—large, complex, partially observable environments with long-term dependencies. By effectively reducing the necessary memory footprint from `k*` (the full Markovian history length) to `κ` (the minimal causally relevant memory), Adaptive Stacking drastically cuts down computational and memory costs. This unlocks the potential for using deep RL in scenarios previously deemed intractable due to resource limitations.
2. **Improved Generalization and Robustness:** Learning to selectively retain only reward-relevant observations leads to more compact and abstract agent states. This fosters superior out-of-distribution generalization, as the agent is less susceptible to overfitting to specific temporal patterns or irrelevant distractors present during training. This is crucial for real-world applications where agents must perform reliably in novel or changing conditions.
3. **Broad Applicability as a Meta-Algorithm:** Adaptive Stacking is introduced as a general meta-algorithm that can be seamlessly integrated with existing and future RL algorithms (e.g., Q-learning, PPO) and diverse neural architectures (MLP, LSTM, Transformers). Its modularity and compatibility make it a versatile tool for the broader RL community, allowing researchers to enhance their current methods without fundamental architectural redesigns.
4. **Strong Theoretical Foundations:** The paper provides solid theoretical guarantees for policy optimality and convergence under Adaptive Stacking for both unbiased (Monte Carlo) and biased (TD-learning) value estimation methods. This theoretical grounding increases confidence in the algorithm's reliability and provides a framework for understanding its behavior. The introduction of `κ` (minimal sufficient memory) as a key concept is a valuable theoretical contribution.
5. **Cognitive Inspiration and Plausibility:** The approach is inspired by the selective gating mechanisms observed in human working memory. This alignment with biological intelligence hints at a more plausible and efficient way for AI systems to process and retain information, potentially opening avenues for more human-like learning behaviors.
6. **Potential Impact on Long-Context Language Models (LLMs):** The challenges addressed by Adaptive Stacking—managing long contexts, mitigating recency bias, reducing attention dilution, and filtering distractors—are highly relevant to the current frontier of LLM research. The principles of learning to actively prune irrelevant information for reward maximization in RL could inspire novel context management strategies in LLMs, improving their efficiency, coherence, and ability to reason over vast amounts of text.
7. **Future Research Directions:** The paper also delineates the boundaries of its value-consistency assumption, particularly noting its potential breakdown in tasks involving unobservable reward machines. This opens fruitful avenues for future research into combining Adaptive Stacking with explicit state inference mechanisms or exploring how agents can learn robustly even when value consistency is partially violated. The comparison to dynamic memory networks and other forms of state abstraction also sets the stage for further theoretical and empirical comparisons.

In conclusion, Adaptive Stacking offers a pragmatic yet theoretically sound solution to a fundamental problem in RL, making significant contributions to both the theory and practice of building intelligent agents capable of navigating complex, memory-demanding environments.
