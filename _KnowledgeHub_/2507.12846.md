# Enter the Mind Palace: Reasoning and Planning for Long-term Active Embodied Question Answering

> [!summary] Summary
> The "Mind Palace Exploration" framework enables embodied robots to answer complex questions by integrating long-term, multi-episodic memory with active environmental exploration. It demonstrates 12-28% higher answer correctness and 77% fewer retrieved images than baselines in a new Long-term Active Embodied Question Answering (LA-EQA) task, successfully deploying on a real robot in a 1,000 m² office.

## Problem

- Existing Embodied Question Answering (EQA) systems are limited to either short-term exploration or single-episode memory recall, failing to integrate both for long-term understanding.
- Large Vision-Language Models (VLMs) and Large Language Models (LLMs) struggle with the vast scale and temporal complexity of accumulated robot data due to limited context windows and lack of persistent memory.
- There was no effective framework to balance active exploration of the current environment with efficient retrieval of specific, relevant information from extensive long-term memory.

## Method

- Introduces "**Mind Palace** Exploration" for the novel Long-term Active Embodied Question Answering (LA-EQA) task, which combines memory retrieval with active exploration.
- Develops a "Robotic **Mind Palace**" using hierarchical scene graphs to represent episodic world instances, organizing past and present environmental knowledge.
- Employs an LLM-based reasoning and planning component that strategically selects relevant past world instances and areas, interweaving exploration of the current environment with targeted memory recall, optimized by Value-of-Information-based early stopping.

## Results

- Mind Palace Exploration achieves 12-**28%** higher answer correctness and **16%** higher exploration efficiency compared to state-of-the-art baselines in LA-EQA tasks across diverse environments.
- The method demonstrates high memory retrieval efficiency, using **77%** fewer retrieved images than VLM-based methods while maintaining or improving accuracy, with early stopping further reducing retrieved images by 7.13 on average.
- Successfully deployed on a legged robot in a real 1,000 m² office, leveraging 10 past episodes spanning 6 months of inspections, saving 3-10 room searches for practical day-to-day tasks.

## Takeaways

> [!tip] Key Insights
> - Structured, hierarchical memory representations (episodic scene graphs) are essential for embodied agents to manage and leverage vast amounts of temporally-complex environmental data over extended periods.
> - Intelligent, LLM-driven planning that explicitly interleaves active exploration with selective memory retrieval significantly enhances both answer correctness and information-gathering efficiency in long-term tasks.
> - Value-of-Information principles can be effectively applied to create early stopping criteria for memory retrieval, optimizing the exploration-recall trade-off and reducing computational overhead without compromising performance.
