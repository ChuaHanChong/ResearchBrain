# DeepEyes: Incentivizing "Thinking with Images" via Reinforcement Learning

> [!summary] Summary
> DeepEyes enables Vision-Language Models (VLMs) to perform 'thinking with images' by dynamically integrating visual re-perception into their reasoning process through end-to-end reinforcement learning. This approach, developed by researchers from Xiaohongshu Inc. and Xi'an Jiaotong University, achieves notable performance improvements, including an 18.9% accuracy gain on V* Bench and a 1.8% reduction in hallucinations on POPE compared to baselines.

## Problem

- Existing Vision-Language Models (VLMs) primarily rely on text-based Chain-of-Thought (CoT) reasoning, treating visual input as static and limiting dynamic visual re-evaluation.
- Prior methods for integrating visual tools often use rigid, pre-defined workflows or require separate, specialized models, leading to sub-optimal performance and poor generalization.
- Lack of a native mechanism for iterative visual reasoning within VLMs, unlike human cognition which seamlessly integrates visual perception and re-evaluation during thought.

## Method

- Introduces ==Interleaved Multimodal Chain-of-Thought (iMCoT)==, allowing the VLM to autonomously invoke an image zoom-in tool to crop and re-incorporate specific visual regions during reasoning.
- Utilizes an agentic ==Reinforcement Learning framework== with a ==composite reward design==, including a conditional tool usage bonus, to incentivize effective visual tool utilization without cold-start supervised fine-tuning.
- Employs a ==tool-use-oriented data selection== mechanism that prioritizes samples where visual tool use provides significant information gain, drawing from diverse fine-grained, chart, and reasoning datasets.

## Results

- DeepEyes achieved **90.1%** accuracy on V* Bench, an **18.9%** gain over the baseline Qwen2.5-VL 7B, and improved HR-Bench 4K by **6.3%** and HR-Bench 8K by **7.3%**.
- It demonstrated improved visual grounding and reduced hallucinations, achieving **87.7%** accuracy on POPE (a **1.8%** increase) by enabling the model to zoom in and verify object presence.
- Qualitative analysis revealed emergent human-like reasoning patterns, including visual search, comparison, and confirmation, and distinct stages of tool-use learning during RL.

## Takeaways

> [!tip] Key Insights
> - The ability for Vision-Language Models to perform dynamic visual re-perception (thinking with images) can emerge natively through end-to-end reinforcement learning.
> - A conditional tool usage reward, given only when a tool is used and the final answer is correct, effectively incentivizes efficient and purposeful tool exploitation during RL training.
> - The model's tool-calling behavior evolves through distinct stages during RL, from exploration to high-frequency usage, culminating in efficient and selective tool utilization.
