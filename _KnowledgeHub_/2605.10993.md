# ECHO: Continuous Hierarchical Memory for Vision-Language-Action Models

> [!summary] Summary
> Researchers from Xi'an Jiaotong University developed ECHO, a memory framework for Vision-Language-Action (VLA) models that organizes manipulation experiences into a continuous hierarchical space using hyperbolic geometry. This system achieved a 12.8% absolute improvement in success rate on the challenging LIBERO-Long benchmark and demonstrated enhanced compositional generalization to unseen tasks by leveraging structured memory.

## Problem

- Existing Vision-Language-Action (VLA) models often rely on linear or flat memory systems, which lack the structural priors needed to represent the inherent hierarchical nature of complex manipulation tasks.
- Inefficient experience retrieval is a common issue as models resort to global similarity searches over flat memory banks, which do not scale well and may not yield semantically relevant memories.
- VLA models with flat memory struggle with compositional generalization, limiting their ability to abstract and reuse skills from past experiences for novel, compositionally different long-horizon tasks.

## Method

- ECHO introduces a Hyperbolic Autoencoder (HAE) that maps Euclidean VLA latent states into a continuous hyperbolic memory space, where entailment constraints enforce hierarchical containment relationships.
- An autonomous memory consolidation process asynchronously refines the long-term memory tree during idle periods through topological expansion for new semantic branches and semantic compaction to deepen the hierarchy.
- Hierarchical beam search with geometric entailment constraints enables efficient, coarse-to-fine retrieval, while geometric interpolation in the hyperbolic space synthesizes 'virtual memories' for novel task compositions.

## Results

- ECHO achieved a 93.5% success rate on the LIBERO-Long benchmark, an absolute improvement of 12.8% over the Vanilla "
" baseline's 80.7%.
- The framework demonstrated enhanced cross-suite compositional generalization, raising the average success rate from 80.70% to 89.31% on LIBERO-Long when memory was populated solely from source-suite experiences.
- Ablation studies confirmed that the hyperbolic memory organization, cone-tree retrieval, and autonomous memory consolidation each cumulatively contribute to the overall performance gains, with preliminary real-world tests showing a 58.3% to 70.0% average success rate improvement.

## Takeaways

> [!tip] Key Insights
> - Hyperbolic geometry provides an effective continuous space for organizing manipulation experiences hierarchically, allowing abstraction and containment relationships to be modeled with low distortion.
> - Imposing geometric entailment-cone constraints within the hyperbolic space significantly improves retrieval efficiency by allowing structured, top-down searches that filter out irrelevant memory branches.
> - Asynchronous memory consolidation, through mechanisms like topological expansion and semantic compaction, continuously refines the hierarchical memory structure, enhancing its utility for long-term task learning and reuse without interrupting real-time control.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of robotic control has seen advancements with Vision-Language-Action (VLA) models such as RT-2, OpenVLA, and $\pi_0$, which are designed to interpret visual observations and text instructions to generate robot actions. A recognized challenge for these models, particularly in complex and long-horizon manipulation tasks, is the effective utilization of past experiences. Traditional memory systems integrated into embodied agents often store historical experiences as linear sequences or flat vector banks. These approaches have limitations in efficiently retrieving knowledge and supporting generalization because they lack structural priors that reflect the inherent hierarchical nature of manipulation tasks, where high-level goals decompose into sub-goals and atomic actions.

This paper addresses these limitations by drawing inspiration from the hierarchical organization of human memory. It situates itself within a line of research that seeks to enhance embodied intelligence through robust memory systems capable of supporting progress tracking and experience reuse over extended periods. Furthermore, the work leverages hyperbolic geometry, a technique previously employed in areas like lexical taxonomies and graph-structured data to embed hierarchical relationships with low distortion. By applying this geometric prior to VLA memory organization, ECHO aims to provide a continuous, structured, and scalable memory solution that moves beyond flat storage paradigms. This contributes to the broader effort of enabling VLA models to exhibit more advanced decision-making and generalization capabilities by developing memory architectures that capture and exploit the semantic hierarchies of robotic manipulation tasks.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a novel memory framework for Vision-Language-Action (VLA) models that can effectively manage and leverage past experiences for complex, long-horizon manipulation tasks. The motivation stems from several identified deficiencies in existing memory-augmented VLA architectures:

1. **Limited Memory Capacity and Organization**: Current VLA models, when augmented with memory, predominantly rely on linear or flat storage mechanisms. This means experiences are often stored as unordered temporal slices or a flat collection of vectors.
2. **Lack of Structural Priors**: This flat organization lacks structural priors for manipulation categories. It fails to capture the inherent containment and subordination relationships that naturally exist in complex tasks, where high-level instructions (e.g., "prepare breakfast") are composed of sub-tasks (e.g., "fry eggs") and even finer-grained action primitives (e.g., "grasp spatula").
3. **Inefficient Experience Retrieval**: Without structural organization, retrieving relevant past experiences becomes inefficient. Models often resort to global similarity searches over a flat memory bank, which can be computationally expensive and may not yield the most semantically relevant memories, especially as the memory bank grows.
4. **Limited Generalization to Unseen Compositions**: The inability to organize experiences hierarchically hinders the model's capacity for hierarchical generalization. Humans can transfer memories from similar categories by abstracting common subgoals and action patterns. Existing flat memory systems struggle to extract such common knowledge and apply it to new, compositionally different long-horizon tasks, forcing models to "replay" exact past trajectories rather than generalize.
5. **Challenges with Hierarchical Structures in Continuous Spaces**: While discrete tree structures could model hierarchy, they are prone to combinatorial explosion when dealing with fine-grained action variations. Implementing a continuous hierarchical memory requires a suitable geometry that can effectively measure distances and relationships across different abstraction levels without rigid, discrete links.

To address these motivations, the paper proposes ECHO, a framework designed to:
- Organize manipulation experiences in a Continuous Hierarchical Space using hyperbolic geometry.
- Enable efficient, coarse-to-fine, top-down retrieval of experiences by modeling abstraction levels and partial containment relations via hyperbolic metrics and entailment-cone constraints.
- Support compositional memory reuse by allowing the synthesis of unseen memories through geometric interpolation in the continuous hyperbolic space, providing experiential priors for novel task compositions.

By overcoming the limitations of flat memory storage, ECHO aims to significantly improve the performance and generalization capabilities of VLA models in long-horizon robotic manipulation.

### 3. Methodology and Approach

ECHO is introduced as a plug-and-play memory module designed to integrate with existing VLA policies, specifically demonstrated with the $\pi_0$ foundation model. Its methodology encompasses a Hyperbolic Autoencoder, autonomous memory consolidation, hierarchical retrieval, and a system integration strategy.

**Hyperbolic Autoencoder (HAE) and Entailment Constraints:**
The core of ECHO's memory organization is a Hyperbolic Autoencoder (HAE). This component maps Euclidean latent states, derived from the VLA backbone, into a continuous hyperbolic memory space. The Lorentz model is chosen for its stable closed-form operations for distance computation and geometric transformations. The HAE's training objective, $L_{AE}$, comprises three components:
1. **Reconstruction Loss ($L_{recon}$)**: Ensures the decoder can accurately reconstruct Euclidean features from the hyperbolic embeddings.
2. **Lorentzian Distance Penalty ($\lambda d_L$)**: Encourages a hierarchical structure by penalizing large Lorentzian distances between parent and child embeddings.
3. **Entailment Penalty ($\gamma L_{entail}$)**: A crucial mechanism for imposing a topological prior. It constrains child states ($z_c$) to lie within the "entailment cone" of their parent task embedding ($z_p$). The penalty is activated if the exterior angle $\phi(z_p, z_c)$ exceeds the parent's cone half-angle $\omega(z_p)$, thus enforcing a hierarchical containment relationship.

**Parent-Child Memory Construction:**
Hierarchical relationships are established with weak supervision. Global language instructions provide parent-level semantic representations, while sub-goal transition states, extracted by a VLM-guided module, serve as child-level representations. Each memory entry $M_i$ stores the hyperbolic embedding ($z_i$), global instruction ($g_i$), sub-goal description ($s_i$), and corresponding action chunk ($a_i$). This design allows ECHO to build hierarchical memories from successful robot rollouts without requiring explicit human-annotated skill trees.

**Autonomous Memory Consolidation:**
ECHO employs an asynchronous process to refine its long-term memory tree during robot idle periods. Newly observed sub-goal transition states are initially stored in an unconsolidated memory pool and are committed to the long-term tree only after passing a task-level consistency check. This supports continuous memory enrichment without impacting real-time control.
The memory tree's structural evolution involves two mechanisms:
1. **Topological Expansion**: If a new trajectory feature $z_{new}$ cannot be entailed by any existing path (i.e., $\forall\mu \in T_L, \phi(z_{new}, z_{\mu}) > \omega(z_{\mu})$), a new semantic branch is created to accommodate it.
2. **Semantic Compaction**: When an existing memory node $\mu$ exhibits high internal heterogeneity (e.g., a sufficient fraction of its child entries violate its entailment cone), it is split. Specifically, a Lorentzian K-Means split is performed to progressively deepen the hierarchy, refining broad macro-action memories into more precise micro-action memories.
**Geometric Memory Synthesis**: The continuous hyperbolic space facilitates compositional memory reuse. For novel tasks that partially match multiple stored experiences without an exact counterpart, ECHO synthesizes a temporary "virtual memory" by interpolating along the Lorentzian geodesic between relevant retrieved memories. This synthesized representation acts as a temporary action prior during inference.

**Hierarchical Retrieval and Alignment:**
Memory retrieval in ECHO is a top-down process using hierarchical beam search. Given a query vector $q$ (current task-conditioned latent state), the system traverses paths in the memory tree where candidate nodes $z_{\mu}$ satisfy the geometric entailment constraint $\phi(q, z_{\mu}) \leq \omega(z_{\mu})$. This geometric filtering mechanism restricts the search to relevant subtrees, improving efficiency over global linear scans. Retrieved hyperbolic memory nodes are then mapped to the tangent space and aligned with the current latent state via a lightweight cross-attention module, producing a task-conditioned long-term memory prior, $z_{mem}$.

**Plug-and-Play System Integration:**
To manage storage overhead and ensure memory quality, a VLM-guided semantic downsampling module is used. A fine-tuned Qwen2-VL-7B-Instruct model acts as both a planner (decomposing instructions into sub-goals) and a judge (detecting sub-goal transitions and verifying trajectory consistency). Only high-quality, successful experiences are committed to the memory bank.
A dynamic gating network ($\beta_{gate}$) adaptively fuses the local short-term context ($z_{short}$) with the long-term memory representation ($z_{mem}$) to create a fused context vector $z_{ctx}$. This $z_{ctx}$ is then decoded back into Euclidean feature space ($v_{prior}$) and injected into the $\pi_0$ policy's action pathway via a similarity-modulated residual connection. The injection strength ($\alpha_t$) is adjusted based on the alignment between the current state and retrieved memory, ensuring that poorly matched memories have limited influence on the base policy and maintain its stability.

### 4. Main Findings and Results

The evaluation of ECHO was conducted across multiple environments, including the LIBERO simulation benchmark, cross-suite generalization tests, ablation studies, and preliminary real-world robotic experiments.

**Performance on Standard LIBERO Suites:**
ECHO consistently demonstrated improved performance compared to the Vanilla $\pi_0$ baseline across all standard LIBERO suites (Spatial, Object, Goal, Long-10) and LIBERO-Plus. The most substantial gain was observed on LIBERO-Long (a 10-task sequence), where ECHO achieved a success rate of 93.5%, an absolute improvement of 12.8% over Vanilla $\pi_0$'s 80.7%. On LIBERO-Plus, designed for high-complexity scenes, ECHO also showed an improvement from 54.2% to 56.5%. Comparisons with other VLA models like Octo, OpenVLA, MAP-VLA, and MemoryVLA indicated competitive or superior performance, particularly against locally reproduced baselines.

**Cross-suite Compositional Generalization:**
To assess its ability to generalize to unseen task compositions, ECHO was tested on the LIBERO-Long suite with its memory bank populated exclusively by experiences from LIBERO-Spatial, LIBERO-Object, and LIBERO-Goal, deliberately excluding any target-suite LIBERO-Long trajectories. In this setting, ECHO improved the average success rate from Vanilla $\pi_0$'s 80.70% to 89.31%. Retrieval-path analysis for successful rollouts revealed that ECHO did not merely replay exact target-task trajectories. Instead, it activated reusable source-memory branches representing transferable skills, such as object-to-plate placement and plate-relative spatial relations, indicating compositional reuse of manipulation experiences.

**Ablation Study:**
An ablation study on LIBERO-Long quantified the contribution of each ECHO component:
- **Vanilla $\pi_0$**: 80.70% success rate.
- **$\pi_0$ + Short-term Buffer Only**: Increased to 88.81%, indicating the importance of episode-level context.
- **$\pi_0$ + Flat Memory (Euclidean kNN)**: Showed a modest improvement to 83.25% but with higher variance, suggesting that flat retrieval can select semantically adjacent but execution-incompatible priors.
- **$\pi_0$ + Hyperbolic Memory (Distance kNN)**: Achieved 91.11%, demonstrating that hyperbolic geometry effectively organizes reusable experiences across abstraction levels.
- **$\pi_0$ + Cone Tree Retrieval (Hyperbolic + entailment-cone filtering)**: Further improved to 92.04%, validating the benefit of structured, top-down hierarchical search.
- **Full ECHO (Cone Tree + Consolidation)**: Achieved the highest success rate of 93.48%, confirming the cumulative benefit of all proposed components, particularly background memory consolidation.

**Real-world Experiments:**
Preliminary real-world evaluations on a Franka Emika Panda robot for three tabletop manipulation tasks (Place Banana in Bowl, Stack Blocks, Insert Circle into Base) showed that ECHO improved the average success rate from 58.3% (Vanilla $\pi_0$) to 70.0%.

**Memory Organization and System Analysis:**
Analysis of the consolidated memory bank demonstrated that memory nodes are distributed across multiple depths, indicating a refined hierarchy. Background consolidation contributed to the decomposition of coarse experience clusters into finer semantic branches. Retrieval visits spanned multiple levels of the hierarchy, confirming the utilization of the top-down structure for coarse-to-fine access. System analysis also indicated that a moderate base memory injection strength maintained policy stability and that hyperbolic cone-tree retrieval exhibited lower latency scaling with increasing memory size compared to standard vector search.

### 5. Significance and Potential Impact

The development of ECHO represents a methodological advancement in enhancing the capabilities of Vision-Language-Action (VLA) models for robotic manipulation, particularly for long-horizon and compositionally complex tasks.

The work's primary significance lies in its direct address of a core limitation in existing VLA memory architectures: the lack of hierarchical organization. By introducing a continuous hierarchical memory space grounded in hyperbolic geometry, ECHO moves beyond flat memory storage paradigms. This is significant because it provides a mechanism for VLA models to structure their experiences in a manner that more closely aligns with human cognitive organization, which is conducive to abstracting and reusing knowledge.

The demonstrated improvements in execution success rates, particularly the 12.8% absolute gain on the challenging LIBERO-Long benchmark, suggest that structured, hierarchically organized memory can substantially enhance task completion for sequential, multi-subgoal operations. The strong performance in cross-suite compositional generalization is particularly impactful. By enabling the policy to solve unseen long-horizon tasks using only source-suite memories, ECHO illustrates a pathway towards more robust and transferable robotic intelligence. This implies that robots equipped with ECHO could potentially learn a repertoire of atomic skills and then recombine them to tackle novel, complex tasks without requiring extensive retraining or demonstrations for every new composition. This capability reduces the data burden and increases the versatility of VLA models.

Furthermore, the architectural choices of ECHO, such as the autonomous memory consolidation and hyperbolic cone-tree retrieval, contribute to practical deployment. The asynchronous consolidation refines the memory structure without disrupting real-time control, while the efficient hierarchical retrieval mechanism addresses scalability concerns as memory banks grow, suggesting applicability to lifelong learning scenarios.

The preliminary positive results in real-world robotic experiments indicate the potential for ECHO to be deployed in physical settings, translating its simulated advantages into tangible improvements in robotic performance. This could lead to more reliable and adaptable robots in various application domains requiring complex manipulation.

Future work on scaling to larger lifelong memory banks and improving memory verification points towards continued development in creating more robust and generalizable embodied agents. Overall, ECHO contributes to the development of more intelligent and adaptable robotic systems by endowing them with a memory system that more effectively organizes, retrieves, and reuses learned experiences.
