# LOPAL: Local Performance-Aware Active Learning from Imperfect Demonstrations

> [!summary] Summary
> LOPAL is an active learning framework that allows robots to learn from imperfect human demonstrations by leveraging local performance information. It generates improved robot trajectories by intelligently combining high-quality segments from multiple demonstrations and actively guides users to provide targeted corrections in areas lacking good data, reducing teaching effort and enhancing task performance by up to 27.31%.

## Problem

- Robot performance in Learning from Demonstration (LfD) strongly depends on the quality of human demonstrations, which are often suboptimal and inconsistent, even within a single demonstration.
- Existing LfD methods often average behaviors or prune entire demonstrations, failing to address intra-demonstration variability and potentially discarding valuable local insights.
- Current active learning strategies do not explicitly incorporate local variations in demonstration quality to guide data acquisition, leading to inefficient data collection efforts.

## Method

- **LOPAL** encodes demonstrations using a Gaussian Mixture Model (GMM) that includes local performance values (smoothed quality measures) and a phase variable to represent multimodal data.
- It generates reference trajectories via ==Gaussian Mixture Regression (GMR)==, conditioning the motion on a phase-dependent performance target set above the mean to selectively follow high-performing demonstration segments.
- An active data acquisition mechanism identifies low-performance regions, modulates the robot's motion (e.g., slowing down and interpolating), and uses a shared autonomy approach to facilitate targeted user corrections.

## Results

- In simulation, LOPAL (LP-GMR+I) significantly reduced penalties and enhanced learning efficiency compared to vanilla GMR and other LfD baselines, achieving performance comparable to RL methods without extensive exploration.
- During real-world pipe inspection, LP-GMR+I demonstrated superior task performance, achieving up to **27.31%** improvement over GMR and better performance with fewer demonstrations.
- LOPAL reduced perceived physical workload (lower user energy injected) and mental workload for participants compared to other shared autonomy teaching methods, by providing effective feedback and guiding corrections.

## Takeaways

> [!tip] Key Insights
> - Explicitly encoding and leveraging local performance information enables the robot to synthesize higher-quality trajectories by combining optimal segments from various imperfect human demonstrations.
> - Performance-guided modulation of robot behavior (e.g., speed reduction and interpolation in low-quality regions) implicitly signals the need for user input, thereby reducing the user's physical and mental workload.
> - Active data acquisition, focused on areas lacking high-quality data, allows for more efficient learning by prioritizing user teaching effort where it is most critical.
