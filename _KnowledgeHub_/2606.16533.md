# Kairos: A Native World Model Stack for Physical AI

> [!summary] Summary
> Kairos is a unified world model stack designed for Physical AI that integrates world representation and robotic control to learn from diverse experiences, maintain persistent states, and operate efficiently. It achieves competitive performance across embodied and general world model benchmarks with significantly reduced inference latency and memory usage.

## Problem

- Existing world models struggle to synthesize knowledge from diverse data types (open-world videos, human behavior, robot interaction), leading to incomplete competencies.
- Maintaining consistent world states over long temporal horizons is challenging for current systems, which often degrade due to reliance on purely local continuation heuristics.
- A disconnect exists between world understanding and embodied control, as current models often fail to learn how an embodied agent's actions reliably change future states for effective decision-making.

## Method

- A Native Pre-training Paradigm with a Cross-Embodiment Data Curriculum (CEDC) progressively learns physical laws, behavioral semantics, and embodied grounding from heterogeneous data sources.
- A unified Diffusion Transformer (DiT) architecture incorporates Hybrid Linear Temporal Attention (Gated Linear, Sliding Window, Dilated Sliding Window) to ensure coherent, long-horizon world state maintenance.
- Deployment-aware system co-design, including timestep distillation and hardware-aware optimizations (e.g., mixed-parallel inference, FP8 quantization), ensures efficient real-time operation under real-world constraints.

## Results

- Kairos-4B achieved a total score of 9.30 on WorldModelBench-robot, outperforming all baselines with high instruction following (2.36) and physics adherence (4.96).
- The model attained a state-of-the-art average score of 90.8 on LIBERO-Plus after fine-tuning, showcasing strong generalization in complex bimanual manipulation tasks.
- It demonstrated high inference efficiency, with significantly lower memory usage (23.5GB) and computational complexity (2.3 PFlops) compared to larger models, resulting in orders-of-magnitude faster inference.

## Takeaways

> [!tip] Key Insights
> - Purely local temporal models are inherently insufficient for accurate long-horizon prediction, necessitating mechanisms that preserve global state consistency to avoid irreducible excess risk.
> - A hybrid multi-scale temporal attention mechanism, combining gated linear attention for long-term memory with sliding window and dilated attention for short-to-mid-term dynamics, enables robust, consistent long-horizon generation by geometrically damping error accumulation.
> - Systematically integrating knowledge from diverse data sources—general physical laws, human-centric behavior, and robot interactions—through a progressive curriculum significantly enhances world-modeling capabilities and action grounding.
