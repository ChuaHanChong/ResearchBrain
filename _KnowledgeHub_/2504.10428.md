# Learning with Positive and Imperfect Unlabeled Data

> [!summary] Summary
> A framework from Yale University enables learning binary classifiers using positive and imperfect unlabeled data through an iterative constrained optimization approach, demonstrating polynomial-time algorithms for handling distribution shifts and corrupted data while providing theoretical guarantees based on VC-dimension bounds.

## Problem

- Classical Positive-Unlabeled (PU) learning assumes perfect alignment between positive and unlabeled data distributions, which is unrealistic in practice
- Existing approaches fail when unlabeled data is corrupted or exhibits distribution shift

## Method

- Introduces ==Positive and Imperfect Unlabeled (PIU) Learning== model that handles misaligned distributions
- Develops efficient approximation algorithm using ==constrained L1-regression== and list-decoding techniques
- Solves multiple instances of ==Pessimistic-ERM== optimization iteratively

## Results

- Achieves misclassification error of **ε** with polynomial runtime and sample complexity
- Enables learning from smooth distributions using only positive samples
- Provides **first algorithm** for detecting truncation in non-product distributions
- Demonstrates applications in parameter estimation for exponential family distributions

## Takeaways

> [!tip] Key Insights
> - Sample complexity is characterized by the VC-dimension of the hypothesis class
> - Distribution shifts can be handled by focusing on regions where previous iterations performed poorly
> - Connection to truncated statistics enables parameter estimation under unknown censoring
