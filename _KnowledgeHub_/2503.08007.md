# MoRE: Unlocking Scalability in Reinforcement Learning for Quadruped Vision-Language-Action Models

> [!summary] Summary
> Researchers integrate mixture-of-experts architectures with reinforcement learning to create MoRE, a vision-language-action model for quadruped robots that learns from mixed-quality data while achieving superior performance across six different skills compared to baseline methods in both simulated and real-world environments.

## Problem

- Current vision-language-action models for robots rely heavily on high-quality expert demonstration data, which is expensive and time-consuming to collect
- Existing approaches struggle to effectively learn from mixed-quality data including failed trajectories, limiting scalability

## Method

- Develop **MoRE** architecture combining multiple LoRA expert modules within a multimodal LLM backbone
- Implement reinforcement learning-based training objective to learn from both successful and failed trajectories
- Utilize conservative regularization for stable training with mixed-quality offline data

## Results

- Outperforms baseline methods across six different quadruped robot skills in simulation
- Successfully transfers to real-world deployment on Unitree Go2 robot
- Ablation studies confirm importance of both MoE architecture and RL training components
- Demonstrates improved generalization to out-of-distribution scenarios

## Takeaways

> [!tip] Key Insights
> - Mixture-of-experts architecture enables specialization for different robotic tasks while maintaining generalization
> - RL-based training allows effective use of suboptimal data without compromising model performance
> - Conservative regularization helps prevent overconfident predictions when learning from failed examples
