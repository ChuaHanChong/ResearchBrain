# Visual In-Context Prompting

> [!summary] Summary
> DINOv is a unified visual segmentation framework that extends in-context prompting to generic vision tasks using purely visual cues, demonstrating strong open-set generalization and competitive performance across various benchmarks. It unifies referring and generic segmentation within a single architecture, leveraging diverse data effectively.

## Problem

- Existing visual prompting models primarily address referring segmentation, lacking robust capabilities for generic vision tasks like open-set object detection or panoptic segmentation.
- Visual prompts, often represented as dense masks, hinder generalization to entirely novel concepts and struggle with identifying multiple instances of the same semantic concept.
- Bridging the gap between LLM-style in-context learning and pixel-level vision tasks, as current vision models have limited adaptability to new tasks via visual examples alone.

## Method

- DINOv introduces a unified encoder-decoder architecture, building on MaskDINO principles, with a specialized ==PromptEncoder== that reuses the internal vision encoder to process diverse visual prompts (masks, boxes, points).
- It formulates generic segmentation by aggregating in-context examples across a batch to form ==category representatives== and referring segmentation via a =="self-referring" strategy==.
- The model employs ==dual decoder queries== (generic queries for object proposals and interactive point queries for specific instance segmentation) and is jointly trained on semantically labeled (COCO) and pixel-annotated (SA-1B) datasets.

## Results

- DINOv-L achieves **57.7 PQ** on COCO 2017 panoptic segmentation, nearly matching the text-prompted MaskDINO-L baseline and significantly surpassing other visual-prompted models like SegGPT-L (**43.4 PQ**).
- For out-of-domain open-set segmentation, DINOv demonstrates strong zero-shot generalization on ADE20K with **23.2 PQ**, outperforming or matching previous text-prompted open-set models.
- In zero-shot video object segmentation, DINOv-T achieves **73.3 J&F** on DAVIS2017, outperforming SEEM-T (**60.4 J&F**) and other non-video-trained models.

## Takeaways

> [!tip] Key Insights
> - Visual in-context prompting can be successfully extended to generic vision tasks, enabling strong open-set generalization without relying on explicit text labels or large-scale vision-language models for semantic knowledge.
> - A dedicated prompt encoder that reuses the vision encoder and focuses on fine-grained appearance features is critical for effective visual in-context learning, outperforming external pre-trained vision-language encoders.
> - Joint training on both semantically labeled and pixel-level annotated datasets, combined with a dual-query decoder, yields synergistic improvements for both generic and referring segmentation tasks.
