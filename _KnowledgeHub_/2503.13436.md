# Unified Autoregressive Visual Generation and Understanding with Continuous Tokens

> [!summary] Summary
> Google DeepMind's UniFluid unifies visual generation and understanding within a single autoregressive framework by leveraging continuous visual tokens and a pre-trained Gemma large language model backbone. The model demonstrates that joint training on both tasks improves image generation quality and achieves competitive performance across diverse visual understanding and editing applications.

## Problem

- Existing multimodal AI models often specialize in either visual generation or understanding, lacking a unified framework that can perform both tasks seamlessly.
- Many autoregressive image generation models rely on discrete visual tokens, which can lead to information loss and quantization artifacts.
- The challenge of integrating visual and textual modalities into a single, consistent autoregressive framework while overcoming the limitations of discrete tokenization for images.

## Method

- ==UniFluid== develops a unified autoregressive framework that processes both discrete text tokens and ==continuous visual tokens== within a single decoder-only transformer backbone.
- It employs a ==continuous Variational Autoencoder (VAE)== for image tokenization during generation and a pre-trained ==SigLIP encoder== for understanding, with task-specific prediction heads for text (classification) and images (diffusion).
- The framework uses a ==unified loss function== combining cross-entropy for text and a diffusion loss for continuous visual tokens, along with ==dynamic random-order generation== for image tokens during training.

## Results

- UniFluid, trained with a unified objective, achieved better image generation quality (e.g., FID **7.20** for 2B models) compared to a model trained solely for text-to-image (FID **7.88**).
- The hyperparameter lambda (λ) effectively controls the trade-off between generation and understanding performance; a smaller λ (e.g., 0.005) yields high-fidelity generation while retaining significant understanding ability.
- The model demonstrated strong transferability to various downstream tasks, achieving competitive results on 4 image captioning benchmarks and 20 visual question answering tasks, and successfully performing image editing.

## Takeaways

> [!tip] Key Insights
> - Unified training on both generation and understanding tasks can mutually benefit each other, leading to improved image generation quality compared to generation-only models.
> - A stronger pre-trained large language model backbone significantly enhances performance across both visual generation and understanding tasks within the unified framework.
> - Random-order image generation during training is crucial for achieving high-quality image synthesis, while raster-order processing may slightly benefit understanding tasks.
