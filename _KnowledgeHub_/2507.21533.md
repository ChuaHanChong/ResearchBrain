# Model Predictive Adversarial Imitation Learning for Planning from Observation

> [!summary] Summary
> The Model Predictive Adversarial Imitation Learning (MPAIL) framework unifies Inverse Reinforcement Learning and Model Predictive Control, enabling end-to-end planning from observation to learn reward functions and control policies from sparse, observation-only demonstrations. It achieves improved out-of-distribution generalization and robust real-world performance with better interaction efficiency.

## Problem

- Existing imitation learning methods often employ a two-stage process (offline IRL, online MPC), which is inefficient and lacks online adaptability for real-world scenarios.
- Policy-based Adversarial Imitation Learning (AIL) struggles with out-of-distribution generalization, robustness, and interpretability, particularly with ambiguous, observation-only expert data.
- Direct integration of reward learning with planning for real-world, observation-only imitation learning, especially on robotic platforms, remains underexplored and presents practical deployment challenges.

## Method

- Introduces Model Predictive Adversarial Imitation Learning (**MPAIL**), a framework that unifies ==Inverse Reinforcement== Learning (IRL) and Model Predictive Control (MPC) into an interactive, end-to-end learning paradigm.
- Utilizes Model Predictive Path Integral (MPPI) as an embedded planner to optimize trajectories based on a learned reward function and a bootstrapped value function, directly incorporating planning into the adversarial training loop.
- Employs an Adversarial Inverse Reinforcement Learning (AIRL) formulation to learn reward functions directly from observation-only state transitions, without requiring expert actions, and integrates online dynamics model learning when a prior model is unavailable.

## Results

- Demonstrated improved out-of-distribution generalization in simulated navigation tasks, with MPAIL agents successfully reaching goals from states where policy-based GAIL agents consistently failed.
- Successfully reproduced real-world expert trajectories with an average Relative Cross-Track-Error (CTE) of **0.17 m** from a single, partially observable demonstration, outperforming GAIL and a two-stage IRL-MPC approach.
- Achieved optimality with less than half the interaction steps compared to GAIL on a navigation task when an approximate prior model was available, indicating favorable interaction efficiency.

## Takeaways

> [!tip] Key Insights
> - Online deployment of a learned reward function through continuous planning is essential for achieving robust out-of-distribution generalization, going beyond the mere learning of the reward itself.
> - Integrating the planner directly into the learning process creates a more effective adversarial dynamic, enabling more complete and stable training of reward and value functions from ambiguous, real-world observation-only data.
> - The combination of learned single-step costs and a generalized value function is critical for robust planning behavior, allowing the agent to both follow expert demonstrations and generalize intent beyond immediate observed states.
