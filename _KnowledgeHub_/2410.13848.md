# Janus: Decoupling Visual Encoding for Unified Multimodal Understanding and Generation

> [!summary] Summary
> Janus introduces a unified multimodal AI model that resolves the inherent granularity conflict between visual understanding and image generation tasks by employing separate visual encoders for each. This decoupled encoding strategy enables the model to achieve improved performance across both multimodal understanding benchmarks, such as a 41% improvement on MME, and high-quality image generation.

## Problem

- Unified multimodal AI models typically use a single visual encoder, which struggles to simultaneously meet the distinct visual granularity requirements of understanding and generation tasks.
- Multimodal understanding requires high-level semantic information, while image generation necessitates fine-grained spatial and textural details.
- This inherent conflict leads to suboptimal performance, where unified models often excel at one task at the expense of the other.

## Method

- ==Janus== employs ==dual visual encoders==: a ==SigLIP encoder== for high-level semantic understanding and a ==VQ tokenizer== for fine-grained visual generation.
- Specialized adaptors map features from these distinct encoders into the input space of a single, unified Large Language Model.
- A three-stage training process, including adaptor training, unified pretraining, and supervised fine-tuning, integrates the components and optimizes performance across tasks.

## Results

- Janus achieved a **41%** improvement on the MME dataset and a **30%** improvement on the GQA dataset for multimodal understanding.
- For visual generation, the model obtained FIDs of **8.53** on COCO-30K and **10.10** on MJHQ-30K, demonstrating high-quality image output.
- Ablation studies confirmed that the decoupled encoding approach prevents the significant performance trade-offs observed when a single visual encoder is used for both understanding and generation.

## Takeaways

> [!tip] Key Insights
> - Decoupling visual encoding for distinct tasks (understanding vs. generation) is crucial for overcoming performance trade-offs in unified multimodal models.
> - A single Large Language Model can effectively manage both multimodal understanding and image generation when provided with appropriately encoded visual features.
> - A multi-stage training methodology allows for the effective integration and optimization of specialized visual encoders and a unified LLM within a multimodal framework.
