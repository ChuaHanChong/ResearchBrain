# QDGset: A Large Scale Grasping Dataset Generated with Quality-Diversity

> [!summary] Summary
> QDGset extends QDG-6DoF, a Quality-Diversity grasp sampler, into a data-augmentation pipeline: object meshes are deformed by per-axis scaling, and grasp archives found on the reference object bootstrap the evolutionary search on each deformed variant. Stopping right after bootstrapping cuts evaluations per robust grasp by up to 20%, yielding 62M 6DoF parallel-jaw grasps over 40k objects.

## Problem

- Prior synthetic grasp datasets sample poses with simple priors like antipodal plus random, making grasp discovery sample-inefficient and costly to scale to many objects.
- Real-world collected or hand-annotated grasp datasets give high quality labels but cannot scale to the volume data-driven grasp policies need for generalization.
- Existing QD grasp sampling restarts optimization from scratch for every new object, discarding prior archives and capping how fast object coverage can grow.

## Method

- Mesh augmentation applies a diagonal per-axis scaling matrix with factors drawn from [0.5, 1.5] to each object point cloud, producing new-but-similar graspable objects.
- QD transfer learning seeds the new object's evolutionary run with the reference object's success archive as initial population, then halts right after the bootstrap generation.
- Dataset assembly merges six object sources (KIT, 3DNet, YCB, GraspNet-1Billion, EGAD, ShapeNet), rescales oversized ShapeNet meshes to YCB-like sizes, and downsamples meshes above 300kB.

## Results

- Across 431 runs, 76% produced more robust grasps when stopped after bootstrapping; on beneficial objects the ratio improved from 20.7 to 16.4 evaluations per robust grasp.
- Transfer succeeded for 78% of 1304 reference objects (10/10 augmentations yielding at least 500 grasps), with augmented-object grasp quality distributions matching the core sets.
- The released dataset holds 62M grasps on 40353 objects, roughly 3.5x the grasps and 4.5x the objects of ACRONYM, mostly 1000-5000 grasps per object.

## Takeaways

> [!tip] Key Insights
> - Warm-starting evolutionary search helps only early: after 100k evaluations the bootstrapped runs fall behind, since inherited populations constrain exploration into local minima.
> - Cheap geometric mesh perturbation plus archive reuse is a general recipe for scaling any simulation-validated dataset, not just grasping.
> - Augmentation range must match the deployment domain; too-small perturbations collapse grasps into center-of-mass alignments and degrade downstream policy quality.
