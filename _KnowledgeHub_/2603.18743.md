# Memento-Skills: Let Agents Design Agents

> [!summary] Summary
> Memento-Skills introduces a system for Large Language Model (LLM) agents to continually learn and improve without updating core model parameters, treating reusable skills as an external, evolving memory. The system achieved a 13.7 percentage-point increase in test accuracy on the GAIA benchmark and more than doubled the baseline performance on the HLE dataset, enabling autonomous agent design and adaptation.

## Problem

- Existing LLM agents are often deployed as "frozen models," preventing them from continually learning from deployment experiences due to the high computational and data costs of parameter updates.
- Frozen LLMs are stateless, lacking the ability to retain knowledge across interactions or adapt efficiently to new tasks, leading to suboptimal performance over time.
- Traditional memory-augmented LLMs often use passive storage of interaction logs, and semantic retrieval mechanisms frequently fail to prioritize behavioral utility for effective skill selection.

## Method

- **Memento-Skills** externalizes learning into an evolving ==skill library==, defining skills as persistent, structured markdown units encapsulating executable code and contextual prompts.
- Implements a ==closed-loop Read–Write Reflective Learning== mechanism, drawing from the ==Stateful Reflective Decision Process (SRDP)==, where the agent iteratively evaluates execution outcomes to update, rewrite, and discover new skills.
- Develops a behavior-aligned skill router, **Memento-Qwen**, trained with ==one-step offline reinforcement learning== using a ==multi-positive InfoNCE loss==, to optimize for execution success rather than purely semantic similarity during skill retrieval.

## Results

- The system achieved a **66.0%** test accuracy on the GAIA benchmark, a **13.7 percentage-point improvement** over the **52.3%** baseline without skill optimization, and more than doubled the baseline performance on HLE, reaching **38.7%** accuracy versus **17.9%**.
- Over multiple learning rounds, training success rates consistently improved, with GAIA increasing from **6**5.1%** to 91.6%** and HLE from **3**0.8%** to 54.5%**, demonstrating continuous refinement of the skill library.
- The behavior-aligned skill router, Memento-Qwen, outperformed semantic baselines with a **Recall@1 of 0.60** (vs. 0.32 for BM25 and 0.54 for Qwen3-Embedding) and increased the end-to-end judge success rate to **0.80**.

## Takeaways

> [!tip] Key Insights
> - Continual learning for LLMs can be effectively achieved by evolving an external skill library without modifying the core LLM parameters, enabling agents to autonomously design and improve task-specific behaviors.
> - Framing skill retrieval as a one-step Markov Decision Process and optimizing for behavioral utility through offline reinforcement learning significantly enhances the effectiveness of skill selection over semantic similarity alone.
> - Structured, domain-aligned skill libraries facilitate substantial cross-task generalization, allowing skills refined in one context to be reused effectively for unseen tasks within the same domain.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of artificial intelligence, particularly with the advent of Large Language Models (LLMs), has seen significant advancements in learning from experience. LLMs demonstrate proficiency through methods such as few-shot learning, supervised fine-tuning, and post-training. However, a prevalent challenge in deploying LLM agents is the high computational and data cost associated with continually updating their parameters. Consequently, many LLM agents are deployed as "frozen models," meaning their parameters remain fixed after pre-training. This fixed-parameter approach limits an agent's ability to learn from novel deployment experiences, rendering it stateless and unable to adapt efficiently to new tasks or rectify past mistakes.

Prior research has explored various forms of automatic skill learning. Some approaches generate text-only guides, primarily functioning as prompt optimizations, while others focus on single-task trajectories, which often result in limited transferability of learned skills. For instance, Memento 2 introduced the Stateful Reflective Decision Process (SRDP) to address the statelessness of frozen LLMs by augmenting agents with an episodic memory. Similarly, case-based reasoning LLM agents have validated the principle of memory-based adaptation across domains like deep search, data science, and software engineering.

Memento-Skills positions itself within this landscape by extending the SRDP framework to a skill-centric paradigm. It distinguishes itself by treating reusable, executable skills—rather than raw episodic traces or simple prompt modifications—as the primary unit of external, evolving memory. This approach aims to provide a generalist agent that can autonomously construct, adapt, and improve task-specific agents through experience, thus functioning as an "agent-designing agent." The work seeks to bridge the gap between theoretical memory-based learning frameworks and practical, deployable systems that enable continual learning without requiring updates to the LLM's core parameters.

### 2. Key Objectives and Motivation

The primary objective of Memento-Skills is to develop a generalist, continually-learnable LLM agent system capable of autonomously designing, adapting, and improving task-specific agents through cumulative experience. This overarching goal is motivated by several key limitations observed in contemporary LLM agent deployments:

1. **Cost and Complexity of LLM Parameter Updates:** Traditional methods for improving LLM performance, such as fine-tuning, necessitate extensive data and computational resources for parameter optimization via backpropagation. In practical deployment scenarios, the expense and intricate nature of continuous parameter updates mean that LLM agents are often deployed with frozen parameters. This fixed state prevents them from learning directly from live interactions.
2. **Statelessness and Lack of Continual Learning:** Frozen LLM agents rely solely on their pre-trained knowledge and the limited context window for novel tasks. They cannot retain knowledge across interactions or learn from their own deployment experiences, leading to a fundamental inability to adapt and improve over time. The system remains static, offering consistent but potentially suboptimal performance, akin to a student who reliably achieves a C+.
3. **Dependence on Human-Designed Agents:** Existing LLM agent systems often rely on human intervention to design, prompt, or fine-tune agents for specific tasks. This manual overhead limits scalability and autonomy, restricting the development of truly generalist agents that can tackle a wide array of unforeseen problems without explicit human instruction for each new task.
4. **Ineffective Memory Utilization:** While prior work on memory-augmented LLMs exists, some approaches focus on passive storage of interaction logs (episodic memory). The motivation for Memento-Skills is to transition from passive memory to an active, structured "skill library" where knowledge is encoded as reusable, executable components. This shift is intended to facilitate more principled and effective learning.
5. **Alignment of Retrieval with Behavioral Utility:** Semantic similarity-based retrieval (e.g., using embeddings) for task-relevant information often fails to capture *behavioral utility*—whether executing a retrieved item would actually lead to task success. The motivation is to develop a retrieval mechanism that optimizes for actual execution outcomes, ensuring that the selected "memory" is indeed the most effective "skill" for the current task.

In summary, Memento-Skills aims to overcome the rigidity of frozen LLMs by externalizing learning into an evolving skill memory, thereby enabling continual self-improvement and autonomous agent design at deployment time, without the high costs of model retraining.

### 3. Methodology and Approach

Memento-Skills is constructed upon a memory-based reinforcement learning framework that incorporates stateful prompts and a specific mechanism for continual learning. The core methodology can be broken down into several interconnected components:

#### 3.1. Skill as the Unit of Memory

The system defines "skills" as persistent, evolving memory units. These skills are stored as structured markdown files and encapsulate both behavior (executable code) and context (declarative specifications and prompts). This allows knowledge to be carried forward and adapted across interactions. Elementary skills, such as Web search and terminal operations, form the initial base library.

#### 3.2. Read–Write Reflective Learning Mechanism

The system operates on a closed-loop Read–Write Reflective Learning mechanism, drawing from the theoretical foundation of Memento 2's Stateful Reflective Decision Process (SRDP).
- **Read Phase (Policy Improvement):** Upon receiving a new task, a behavior-trainable skill router selects the most relevant skill from the skill library. This retrieval is conditioned on the current stateful prompt. The LLM then executes the multi-step workflow defined by the retrieved skill. This process aims to retrieve the most behaviorally relevant skill to guide the frozen LLM's actions.
- **Write Phase (Policy Evaluation and Improvement):** After execution, the agent receives feedback on the outcome. This feedback is used to update and expand the skill library. The write operation is not a simple append of interaction logs; instead, it involves skill-level reflective updates. This includes:
 - **Failure Attribution:** An LLM-based selector examines the execution trace and judge's rationale to identify the specific skill responsible for an error.
 - **Skill Rewriting:** A skill rewriter proposes targeted, file-level updates to the identified skill's prompt or code (e.g., adding guardrails, alternative strategies) to address the observed failure mode while maintaining generality.
 - **Skill Discovery:** If a skill's empirical success rate (utility) falls below a threshold, indicating that in-place patching is insufficient, the system escalates to discover new skills. This might involve restructuring an existing skill folder with a fundamentally different approach or synthesizing an entirely new skill to cover novel regions of the task space.
 - **Unit-Test Gate:** All skill mutations are validated by an automatic unit-test gate, where a synthetic test case is generated and executed through the updated skill, with results scored by a judge. This mechanism prevents regression.
The LLM parameters remain fixed throughout this process; all adaptation occurs through the evolution of externalized skills and prompts. The system augments the state to `x_t := (s_t, M_t)` to recover the Markov property, where `s_t` is the current state and `M_t` is the evolving skill memory.

#### 3.3. Behavior-Aligned Skill Router

To overcome the limitations of purely semantic retrieval (e.g., BM25 or embedding routers), which prioritize lexical or semantic similarity over behavioral utility, a specialized skill router is trained.
- **One-Step Offline Reinforcement Learning:** Skill routing is framed as a one-step Markov Decision Process (MDP), where the state is the query, the action is selecting a skill, and the reward indicates whether the skill is appropriate. The router is trained with single-step offline RL, specifically using a multi-positive InfoNCE loss, to optimize for *execution success* rather than just semantic proximity.
- **Synthetic Query Generation:** To obtain sufficient training data, a local skill database is crawled, and a subset of skills is used to synthesize realistic user routing goals. An LLM-based judge filters and verifies the quality of these synthetic queries, generating paired data of positive queries (target skill should be selected) and hard negatives (same domain but incorrect skill).
- **Routing Policy:** The learned score is interpreted as a soft Q-function, leading to a Boltzmann routing policy that maximizes a KL-regularized objective. This policy aims to place high probability mass on rewarding skill-query pairs while suppressing hard negatives.
- **Retrieval Pipeline:** The overall retrieval pipeline combines sparse (BM25) and dense (embedding-based) retrieval, fuses candidate skills using score-aware reciprocal rank fusion, and can optionally apply a cross-encoder reranker.

#### 3.4. Experimental Setup

The system's performance is evaluated on the General AI Assistants (GAIA) benchmark and Humanity's Last Exam (HLE) dataset. Experiments compare the full Memento-Skills system against a "Read-Write ablation" baseline, which includes skill retrieval, LLM execution, and feedback collection but disables all skill-level optimization (failure attribution, skill rewriting, skill discovery). The underlying LLM used in experiments is Gemini-3.1-Flash.

### 4. Main Findings and Results

The experiments conducted with Memento-Skills demonstrated improvements in task performance and skill acquisition, supported by the self-evolving mechanism and behavior-aligned routing.

#### 4.1. Performance on General AI Assistants (GAIA) Benchmark

- **Training Accuracy:** Across three reflective learning rounds, the overall training success rate increased from 65.1% on the first attempt to 91.6% by the third round. This indicated continuous refinement of the skill library.
- **Test Set Accuracy:** On the unseen test set, Memento-Skills achieved an overall accuracy of 66.0%. This represented a 13.7 percentage-point gain over the Read-Write ablation baseline, which scored 52.3%. This confirms that the skill optimization pipeline contributes beyond basic retrieval and execution.
- **Cross-Task Transfer:** Analysis revealed limited cross-task transfer on GAIA. Most skills optimized during training were not triggered during testing due to the benchmark's highly diverse questions with minimal overlap in reasoning patterns.

#### 4.2. Performance on Humanity’s Last Exam (HLE) Benchmark

- **Training Accuracy:** Over four training rounds (R0-R3), the overall training success rate rose from 30.8% to 54.5%, with consistent improvements observed across all subject categories. Humanities and Biology showed substantial gains, reaching 66.7% and 60.7% respectively by R3.
- **Test Set Accuracy:** On the test set, Memento-Skills achieved 38.7% overall accuracy, which more than doubled the Read-Write baseline's score of 17.9%. This represents a 20.8 percentage-point gain.
- **Cross-Task Transfer:** Unlike GAIA, HLE's structured subject taxonomy facilitated significant skill transfer. Skills refined on training questions within a subject (e.g., Biology) were frequently reused for unseen test questions in the same domain, confirming that domain-aligned skill libraries enhance cross-task generalization.

#### 4.3. Skill Library Growth and Organization

- **GAIA Learning:** After learning on GAIA, the skill library expanded from 5 atomic skills to 41 skills, forming a compact library.
- **HLE Learning:** Learning on HLE led to a more extensive library, growing to 235 skills that spread across a wider embedding space, reflecting the breadth of its eight academic domains.
- **Semantic Coherence:** Visualizations (t-SNE projections) showed that learned skills clustered into semantically coherent neighborhoods, each corresponding to a domain-specific capability acquired through reflective self-evolution. This densification of the embedding space contributed to improved performance over learning rounds.

#### 4.4. Skill Router Performance Evaluation

- **Offline Retrieval Quality:** Memento-Qwen (the behavior-aligned router) consistently outperformed both BM25 and the Qwen3-Embedding baseline on synthetic query-skill pairs. Recall@1 for Memento-Qwen was 0.60, compared to 0.32 for BM25 and 0.54 for Qwen3-Embedding. This demonstrated a relative gain of 10% over the strongest semantic baseline for top-1 retrieval.
- **End-to-End Execution Effectiveness:** Memento-Qwen also improved real execution metrics. The route hit rate increased from 0.29 (BM25) and 0.53 (Qwen3) to 0.58. The judge success rate (whether the full trajectory solved the task) rose from 0.50 (BM25) and 0.79 (Qwen3) to 0.80. These results indicate that optimizing for behavioral similarity, rather than just lexical or semantic proximity, leads to more effective skill selection and task completion.

### 5. Significance and Potential Impact

The Memento-Skills system presents a significant development in the field of LLM agents, with several potential impacts:

1. **Enabling Continual Learning for Frozen LLMs:** The primary significance lies in demonstrating a practical method for LLMs to continually learn and adapt from deployment experience without necessitating costly and resource-intensive parameter updates. This "deployment-time learning" paradigm offers a scalable solution for enhancing the capabilities of existing LLMs, making them more adaptable and useful over their operational lifespans. It reduces the barrier for entry for organizations that may not have the computational resources for frequent fine-tuning.

2. **Autonomous Agent Design and Improvement:** By introducing the concept of an "agent-designing agent," Memento-Skills moves beyond systems that require human-designed prompts or agents for each new task. The system's ability to autonomously construct, adapt, and improve task-specific agents through iterative skill generation and refinement represents a step towards more autonomous and generalist AI systems.

3. **Bridging Theory and Practice in Memory-Based Learning:** Memento-Skills concretely instantiates the theoretical framework of the Stateful Reflective Decision Process (SRDP) from Memento 2. This bridges theoretical guarantees of convergence and optimal policy iteration with a deployable, practical system, providing a robust foundation for memory-based LLM agents.

4. **Enhanced Skill Retrieval through Behavioral Alignment:** The development of a behavior-aligned contrastive router, trained via single-step offline reinforcement learning, demonstrates that optimizing for execution success, rather than just semantic similarity, is critical for effective skill selection. This approach significantly improves the relevance and utility of retrieved skills, leading to more reliable agent performance.

5. **Facilitating Cross-Task Generalization:** The results on the Humanity's Last Exam benchmark highlight that structured, domain-aligned skill libraries are a key enabler for substantial cross-task transfer. This finding suggests a pathway for building LLM agents that can generalize capabilities across related tasks, addressing a persistent challenge in AI agent development.

6. **Modular and Efficient Architecture:** The system's design, characterized by independent "knobs" (stronger LLM, more episodes, better embeddings) for performance improvement, allows for flexible and targeted optimization. This modularity means that advancements in any one component can independently contribute to overall system performance, promoting efficient development and maintenance.

7. **Foundation for Future Research:** Memento-Skills opens avenues for further research into scaling skill libraries, analyzing more precise convergence rates, and integrating advanced safety mechanisms (e.g., sandbox safety) into self-evolving agent systems. Its emphasis on external, interpretable skill artifacts could also contribute to more transparent and explainable AI agent behavior.
