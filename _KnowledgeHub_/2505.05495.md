# Learning 3D Persistent Embodied World Models

> [!summary] Summary
> Researchers introduce a persistent embodied world model that integrates an explicit 3D memory into a video diffusion model for action-guided RGB-D video generation. This approach significantly improves spatial consistency in generated long-horizon trajectories and enhances performance in downstream tasks like model predictive control and policy learning in novel environments.

## Problem

- Existing video-based world models are "myopic," lacking a persistent memory of unseen parts of the environment, leading to inconsistencies when revisiting previously observed areas.
- The absence of long-term spatial consistency prevents embodied agents from making consistent, long-horizon plans in complex, partially observed 3D environments.
- Relying solely on 2D image representations for memory neglects critical 3D spatial priors, making it difficult to accurately capture and regenerate scene geometry and object permanence.

## Method

- Developed a "Persistent Embodied World Model" that integrates an explicit 3D memory, called DINO-Map, into an action-guided RGB-D video diffusion model (based on CogVideoX).
- Employs Plücker embeddings to represent agent actions as precise pixel-wise controls for the video diffusion model, ensuring accurate conditioning on camera pose transformations.
- Constructs the 3D DINO-Map by unprojecting DINO-v2 features from RGB-D observations into a volumetric grid and injects these features into the video diffusion model via dedicated cross-attention expert blocks.

## Results

- Achieved an FVD score of 91.885, outperforming the Navigation World Model (194.040) and Image Memory (124.038), while attaining the highest Scene Revisit Consistency (SRC) at 81.7%.
- Demonstrated improved performance in Model Predictive Control and policy learning in new environments, with the model achieving a SIM of 70.8% for trajectory ranking compared to NWM's 68.7%.
- Successfully synthesized long video trajectories (up to 112 frames) while preserving 3D consistency and showed robustness in generalizing to novel, unseen scenes.

## Takeaways

> [!tip] Key Insights
> - Integrating a dynamically updated 3D feature map directly into a video diffusion model effectively maintains long-term spatial consistency in ego-centric video generation.
> - Representing actions via Plücker embeddings provides a robust mechanism for fine-grained, pixel-level control, crucial for accurate action-guided video synthesis.
> - A two-stage training approach, fine-tuning the video backbone first then training memory-specific blocks, efficiently integrates 3D memory without degrading the generative model's base capabilities.
