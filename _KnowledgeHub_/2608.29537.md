# AGM: Achievement-Grounded Memory for Closed-Loop Agents with Frozen VLA Policies

> [!summary] Summary
> AGM (Achievement-Grounded Memory) closes the loop around a frozen vision-language-action policy by representing a task as a typed subgoal sequence plus a progress pointer that advances only when physical evidence confirms the subgoal. Gripper-load events trigger verification; frozen point tracking and language-conditioned cross-view SigLIP comparison, read by a 2.43M-parameter head, decide success. It reaches 100% on PickXTimes and 84% BinFill, beating the best memory baseline by 7.1 points.

## Problem

- Frozen VLA policies execute open-loop action chunks without any representation of task progress, so they cannot decide whether to continue, retry, or terminate.
- In repetitive counting manipulation, stages are perceptually aliased: the current image cannot reveal which repetition is underway, and past-action context recovers almost none of the gap.
- Existing external memory advances progress after every manipulation attempt, so a missed grasp or slipped object becomes a persistent task-state error, sometimes worse than no memory.

## Method

- A hysteretic ==gripper-load finite-state machine== localizes interaction events, and a compatibility function triggers verification only for event types matching the current subgoal's type label.
- ==Coherent-motion grasp verification== runs frozen ==CoTracker3== over a point grid around the projected end-effector, taking the top-fraction median upward displacement as kinematic evidence the object rose.
- ==Language-conditioned cross-view placement verification== feeds frozen ==SigLIP== pre/post-release front and wrist embeddings, their difference, proprioception and subgoal text to a 2.43M-parameter head; reversibility-aware thresholds drive advance, retain, or rollback.

## Results

- AGM averages **55.96%** on RoboMME Counting, beating MemER's **48.83%** and nearly doubling the frozen base policy's **28.78%**, with **100.00%** PickXTimes and **84.00%** BinFill.
- The frozen policy collapses from **100%** at one repetition to **0%** by five; AGM holds **100%** at every count, and **60-100%** on a physical robot.
- Ablations: proprioception-only grasp checks give **98.0/78.0%**, flattened thresholds drop BinFill to **74.0%**, and attempt-based writing with identical memory scores **32.0%** versus **100.0%**.

## Takeaways

> [!tip] Key Insights
> - Reliable embodied memory depends on when a write is justified, not on memory capacity: gate every state update on observed outcomes.
> - A compact pointer plus 231M frozen perception parameters beat LoRA-finetuned 4B VLM memories, so verification discipline can substitute for external model scale.
> - Recovery policy should follow reversibility: strict acceptance is safe when re-grasping can fix errors, but falsely rejects irreversible drops and stalls progress.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This work is positioned within the field of embodied AI, specifically addressing challenges in robotic manipulation using Vision-Language-Action (VLA) models. The paper relates to several ongoing research directions:

**Vision-Language-Action Models and Skill Composition:** Large-scale VLA models are capable of mapping visual observations and language instructions directly to continuous actions. Due to the high cost associated with fine-tuning such models for every new downstream task, a prevalent strategy involves keeping the core VLA policy frozen and composing its pre-trained skills through language-conditioned subgoals. While this approach offers flexibility, the authors identify a limitation: frozen policies inherently lack an internal representation of task progress. In repetitive manipulation tasks, different stages can be perceptually aliased, making it difficult for the policy to infer task progress from visual observations alone. This work aims to supply this missing task-progress state without altering the frozen policy or its subgoal interface.

**Memory for Long-Horizon Embodied Agents:** The challenge of maintaining task state under partial observability is a foundational problem in artificial intelligence. Contemporary approaches in embodied AI often involve sophisticated memory mechanisms, such as LLM-based memory streams, episodic reflections, spatial memory architectures, or experience retrieval systems. Existing methods frequently focus on scaling the *capacity* of memory (what information is stored or retrieved). In contrast, this research argues that for repetitive manipulation, a compact subgoal pointer can be sufficient, provided that updates to this memory are *justified*. The paper highlights a failure mode where memory systems that update based on every *attempted* action can turn transient execution errors into persistent task-state errors, suggesting that the timing and justification of memory writes are more critical than merely increasing memory capacity.

**Verifying Manipulation Outcomes:** The verification of action outcomes is essential for robust robotic control. Previous work has explored various methods, including fine-tuned vision-language models for success detection, multimodal reasoning for failure explanation, and runtime monitors for detecting plan-execution misalignment. These often involve querying large models at fixed intervals or analyzing failures post hoc. This paper differentiates itself by proposing a system that triggers verification based on proprioceptive gripper-load transitions, thereby localizing *when* verification is needed. Furthermore, it leverages frozen perception modules (a point tracker for kinematic evidence of grasp success and a vision-language encoder for semantic evidence of placement success) to determine *what* was achieved, requiring the training of only a small, specialized verification head. This approach aims for efficiency by avoiding large-model inference during runtime and integrating verification directly into the control loop.

### 2. Key Objectives and Motivation

The primary motivation for this research stems from an identified fundamental limitation of frozen Vision-Language-Action (VLA) policies when applied to long-horizon, repetitive manipulation tasks. While frozen VLA policies offer a broad range of manipulation skills, they typically execute "action chunks" in an open-loop manner, meaning they do not inherently track or represent task progress. This absence of internal state prevents the agent from reliably deciding whether to continue, retry a failed action, roll back to a previous state, or terminate a task.

The authors pinpoint that this limitation becomes particularly pronounced in repetitive and counting-based manipulation scenarios. In such contexts, task stages can be "perceptually aliased," meaning that the visual appearance of the environment at different points in a sequence may be identical or highly similar. For example, after placing an object into a container, the current visual observation alone may not convey which repetition in a sequence of placements has just occurred or is about to occur. Even if the frozen policy possesses the necessary low-level skills for individual grasps and placements, the lack of a persistent task state can lead to cumulative errors and task failures.

A common remedy proposed in prior research is the integration of external memory. However, the authors identify a critical failure mode in conventional memory-augmented approaches. If external memory is advanced after *every manipulation attempt*, rather than after a verified achievement, local execution errors can escalate into persistent task-state errors. For instance, a robot might attempt to grasp an object but miss, or successfully grasp it but then drop it before placement, or fail to establish the intended object-target relationship upon release. If such an attempt is prematurely recorded as "progress" in memory, the system becomes misaligned with the actual physical state of the world, leading to incorrect subsequent actions, such as attempting to pick up an object that is not present or placing an object into an already full container. This observation leads to the central question motivating this work: it is not merely *what* information to store in memory, but crucially, *when* to update this memory with new progress.

Against this background, the key objectives of this research are:

1. **Develop a Lightweight Closed-Loop Framework:** To design Achievement-Grounded Memory (AGM) as a framework that integrates verification into the control loop of frozen VLA policies.
2. **Represent Task Progress with Disciplined Updates:** To represent a task as a simple, ordered sequence of subgoals with a dynamic "progress pointer." The core objective is to ensure that this pointer advances *only* when the current subgoal's completion is physically verified by observable evidence, rather than by mere action attempts.
3. **Utilize Proprioceptive Cues for Verification Timing:** To employ proprioceptive interaction cues (e.g., gripper-load state changes) to determine *when* a potential achievement has occurred, thereby localizing the moments that require visual verification.
4. **Leverage Frozen Foundation Models for Verification Content:** To determine *what* was achieved by sourcing kinematic and semantic evidence from pre-trained, frozen foundation models. Specifically, a frozen point tracker is used for kinematic evidence of grasp success, and a frozen vision-language encoder is used for language-conditioned cross-view comparison to verify placement success.
5. **Minimize Trainable Parameters:** To achieve these verification capabilities with a minimal number of trainable parameters, specifically by training only a small "verification head" (2.43M parameters) on top of the frozen foundation models, thus avoiding the need for test-time inference with large, fine-tuned models.
6. **Enable Robust Recovery Mechanisms:** To support not only advancement on success but also retention of the current state on minor failures (e.g., failed grasp) and recovery-aware rollback on more significant but recoverable failures (e.g., failed planar placement).

By pursuing these objectives, the research aims to convert open-loop execution into a more robust closed loop of execution, verification, and progress, thereby enhancing the reliability of frozen VLA policies for complex, long-horizon manipulation tasks.

### 3. Methodology and Approach

AGM is designed as a lightweight, closed-loop framework for frozen VLA policies. The methodology centers on grounding every update of a compact task memory in observable execution evidence.

**Problem Formulation:** The system operates with a frozen, subgoal-conditioned vision-language-action policy $\pi_{\theta}(A_t | o_t, g_t)$. The observation $o_t$ includes front-view and wrist-view images, gripper opening width, and end-effector pose. $g_t$ is a language subgoal, and $A_t$ is an action chunk. The policy's parameters $\theta$ remain fixed.

**Task Representation and Memory:**
A task instruction is first expanded into an ordered sequence of subgoals, $G = \{(g_k, c_k)\}_{k=1}^T$. Each subgoal $g_k$ is associated with a type $c_k \in \{\text{grasp, place-rev, place-irrev, other}\}$. `place-rev` denotes recoverable placement (e.g., on a flat surface, allowing re-grasping), while `place-irrev` denotes irreversible placement (e.g., into a container, where retrieval is difficult after release). The system maintains a compact task memory $M_t = (G, p_t)$, where $p_t$ is a dynamic progress pointer indicating the current subgoal index. The frozen VLA policy is conditioned on the current subgoal $g_{p_t}$.

**Achievement-Grounded Memory Transitions:**
The core principle of AGM is that the progress pointer $p_t$ is updated only after compatible interaction events occur and their outcomes are verified.
1. **Event Localization:** A hysteretic finite-state machine monitors the gripper opening width $w_t$ to detect significant interaction events $e_t \in \{\emptyset, G_+, R_+, R_0\}$.
 - $G_+$: Stable loaded grasp (gripper closes on an object).
 - $R_+$: Release from a loaded state (object dropped).
 - $R_0$: Release from an empty state (gripper opens without holding anything).
 Only events compatible with the current subgoal type $c_{p_t}$ (e.g., $G_+$ for a grasp subgoal, $R_+$ for a placement subgoal) trigger the verification process.
2. **Verification:** After a compatible event $\tau_n$, AGM collects an event-dependent observation window and performs visual verification to determine an achievement decision $bv_n \in \{0, 1\}$.
3. **Pointer Transition:** Based on $bv_n$, the progress pointer $p_t$ transitions according to predefined rules (Eq. 21):
 - **Advance:** If $bv_n = 1$ (verified achievement), the pointer advances to the next subgoal: $\min(p_t + 1, T)$.
 - **Retain:** If $bv_n = 0$ (failed grasp), the pointer remains unchanged: $p_t$.
 - **Rollback:** If $bv_n = 0$ and the current subgoal $c_{p_t}$ is `place-rev` (recoverable placement), the pointer rolls back to the associated grasp subgoal, allowing the agent to re-attempt the entire grasp-and-place sequence.

 Terminal consistency checks and bounded deadlock safeguards are also implemented to prevent indefinite stalls or premature termination.

**Detailed Event-Triggered Achievement Verification:**

- **Coherent-Motion Grasp Verification:**
 - **Trigger:** When a $G_+$ event occurs.
 - **Process:** The system records the end-effector position at the grasp instant and buffers a subsequent front-view lifting video clip. The end-effector position is projected into the image frame to define a query region.
 - **Point Tracking:** A frozen point tracker (CoTracker3) is used to track a regular grid of points sampled around the projected end-effector position within the lifting clip. It provides point trajectories and visibility scores.
 - **Achievement Metric:** Valid tracks (with high visibility) are identified. Grasp success is determined by $r_{G,n}$, the median vertical displacement of the top $\rho$ (e.g., 1/3) of valid tracks exhibiting the largest upward motion. A grasp is considered successful if $r_{G,n}$ exceeds a threshold $\delta_G$. This mechanism verifies that the manipulated object coherently moves upward with the gripper.
- **Language-Conditioned Cross-View Placement Verification:**
 - **Trigger:** When an $R_+$ event occurs.
 - **Process:** For each placement subgoal $g_k$, a normalized achievement query $q_k$ is derived. Event-relative observation windows (before and after release) are extracted from both front and wrist cameras.
 - **Feature Extraction:** A frozen vision-language encoder (SigLIP) extracts embeddings from these visual windows and from the language query $q_k$.
 - **Event Representation:** A comprehensive event representation $f_n$ is constructed by concatenating these visual embeddings (including pre/post-event differences), proprioceptive context, and the text query embedding.
 - **Prediction:** A lightweight multilayer perceptron $h_{\psi}$ (the trainable verification head) predicts the placement achievement probability $s_{P,n}$ from $f_n$.
 - **Decision:** Placement is accepted if $s_{P,n}$ exceeds a type-specific threshold $\kappa_c$. Crucially, $\kappa_c$ is more permissive for irreversible container placements (where false rejection is costly) and stricter for recoverable planar placements (where re-attempting is possible).

**Verifier Training:**
The verification head is trained offline on a dataset of 788 execution events collected from the RoboMME training split. This dataset includes events from both AGM-controlled executions (representing deployment distribution) and an attempt-based controller (to capture failure cases like missed grasps or misplacements). Environment predicates are used exclusively for generating ground-truth labels during training. The training process uses class-weighted cross-entropy and updates only the 2.43M parameters of the verification head, keeping the VLA policy, point tracker, and vision-language encoder frozen.

### 4. Main Findings and Results

The research paper presents empirical results across simulation and physical robot experiments to evaluate Achievement-Grounded Memory (AGM). The findings address four main questions:

**Q1: Task Success Improvement over Baselines:**
AGM demonstrated a notable improvement in task success rates on the RoboMME Counting benchmark.
- **Overall Performance:** AGM achieved an average success rate of 55.96% across four tasks (PickXTimes, BinFill, SwingXTimes, StopCube), outperforming the strongest memory-augmented baseline, MemER (48.83%), by 7.1 percentage points. It also substantially surpassed the frozen base policy $\pi_{0.5}$ (28.78%).
- **Gripper-Interaction Tasks:** For tasks heavily reliant on gripper interactions (PickXTimes and BinFill), where perceptual aliasing is a significant challenge, AGM achieved 100.00% and 84.00% success rates, respectively. These results represent new state-of-the-art for these specific tasks within the benchmark.
- **Efficiency:** AGM achieved these gains while being more resource-efficient. It adds 231M frozen external parameters (CoTracker3 and SigLIP) but trains only a 2.43M parameter verification head. This contrasts with other memory-augmented baselines that often fine-tune large 4B vision-language models.
- **Non-Gripper Tasks:** On SwingXTimes and StopCube, whose subgoals are not anchored to gripper interactions, AGM by design defers to the frozen base policy and shows identical performance, confirming its specialized scope.

**Q2: Effect of Repetition Depth:**
The performance of policies was analyzed across varying repetition counts (N=1 to N=5) for PickXTimes and BinFill.
- **Frozen Policy Limitations:** The frozen $\pi_{0.5}$ policy performed well at N=1 (100.0% on PickXTimes, 90.0% on BinFill) but saw its success rate collapse to 0.0% by N=5 on both tasks. This indicates that while the policy possesses the individual manipulation skills, it lacks the persistent task state necessary for accurate counting and long-horizon execution.
- **AGM's Robustness to Repetition:** AGM effectively addressed this limitation. On PickXTimes, it maintained a 100.0% success rate across all repetition counts (N=1 to N=5). On BinFill, the success rate gradually decreased to 66.7% at N=5, with remaining failures attributed to the increasing physical difficulty of placing objects into an increasingly occupied container, rather than progress tracking errors.
- **Generalizability Across Backbones:** AGM demonstrated improvements even when applied to a weaker, subgoal-conditioned $\pi_0$ backbone, lifting its average success rate from near zero to 44.0% for PickXTimes and 8.0% for BinFill. This suggests that the benefits of achievement-grounded writing are a property of the framework's interface rather than contingent on a specific, highly capable base policy. An example rollout showed AGM successfully recovering from a failed grasp by retaining the pointer and retrying.

**Q3: Ablation Studies (Grasp Verification Modality and Reversibility-Aware Thresholds):**
Ablations provided insight into the contribution of specific design choices.
- **Grasp Verification:** Replacing the CoTracker3-based coherent-motion grasp verification with a proprioception-only check (stable gripper load plus end-effector lift) resulted in slight drops: PickXTimes went from 100.0% to 98.0%, and BinFill from 84.0% to 78.0%. This indicates that while verified writing itself provides the majority of the benefit, the visual coherent-motion test contributes a consistent, albeit smaller, margin by directly confirming object movement.
- **Reversibility-Aware Thresholds:** Removing the distinction between `place-rev` and `place-irrev` by flattening the acceptance thresholds (making all placements judged strictly) marginally affected PickXTimes (100.0% to 98.0%). However, it significantly reduced BinFill's success rate from 84.0% to 74.0%. This highlights the importance of permissive thresholds for irreversible actions. A strict threshold for `place-irrev` could falsely reject correct placements (e.g., into a container), leading to the pointer stalling on an already completed subgoal.

**Q4: Real-Robot Validation:**
AGM's efficacy was confirmed on a physical robot platform.
- **Replication of Failure Mode:** Bare policies (even after retraining on real demonstrations) exhibited the same progress-tracking failures observed in simulation, collapsing at higher repetition counts.
- **AGM's Transferability:** AGM successfully transferred to the physical robot, achieving 100.0% success on PickXTimes across all N. For BinFill, it maintained 100.0% through N=2 and decayed to 60.0% at N=5. Similar to simulation, residual failures at higher N were attributed to increased physical difficulty in placing objects into a crowded bin, rather than memory errors.
- **Backbone Independence:** The benefits of AGM were also observed with the weaker $\pi_0$ backbone on the physical robot, further supporting the idea that achievement-grounded writing is a property of the interface. Real-robot rollouts qualitatively demonstrated the system's ability to maintain a correct count even when a human replenished objects during execution.

### 5. Significance and Potential Impact

The Achievement-Grounded Memory (AGM) framework represents a contribution to the field of embodied AI, particularly in enhancing the capabilities of robotic manipulation agents. Its significance and potential impact can be summarized as follows:

- **Addressing a Core Limitation in Frozen VLA Policies:** AGM directly tackles a fundamental challenge faced by frozen Vision-Language-Action (VLA) policies: their inherent inability to robustly track task progress, especially in repetitive or perceptually ambiguous environments. By introducing a mechanism to reliably ground task state updates in verifiable physical evidence, it extends the practical applicability of these powerful, pre-trained models to long-horizon, non-Markovian tasks without requiring expensive fine-tuning of the core policy.

- **Shifting the Paradigm of Memory Design:** The research emphasizes that for embodied agents, the "when to write" is as, if not more, critical than the "what to store" in memory. By demonstrating that disciplined, evidence-based memory updates, even with a compact progress pointer, can outperform memory-augmented baselines that simply record attempts, AGM provides a new perspective on designing memory systems for robotic agents. This principle of "achievement-grounded" updates could inform the design of more robust memory architectures in future embodied AI systems.

- **Efficiency and Practicality for Real-World Deployment:** A key strength of AGM is its lightweight nature. It achieves substantial performance gains by leveraging existing frozen foundation models (point trackers, vision-language encoders) and training only a small, specialized verification head (2.43M parameters). This circumvents the need for test-time inference with large, fine-tuned vision-language models, making it a more computationally efficient and practical solution for deployment on physical robots, where computational resources can be constrained.

- **Enhanced Robustness and Error Recovery:** The closed-loop system of execution, verification, and flexible pointer transitions (advance, retain, rollback) significantly improves the robustness of robotic manipulation. It allows the agent to detect and recover from transient execution failures (e.g., missed grasps, failed placements) that would otherwise lead to persistent task-state errors and ultimate task failure in open-loop systems. This capability is crucial for developing reliable autonomous agents that can operate effectively in unstructured and unpredictable environments.

- **Generalizability Across Policies and Platforms:** The demonstration that AGM delivers consistent gains across different VLA backbones (e.g., $\pi_0$ and $\pi_{0.5}$) and transfers effectively from simulation to physical robot hardware without requiring framework modifications underscores its generalizability. This suggests that the principles of achievement-grounded memory are broadly applicable and not tied to specific policy architectures or simulation artifacts.

- **Implications for Future Research:** While currently anchored to prehensile events, the framework lays the groundwork for expanding its "verification vocabulary" to include a broader range of interaction detectors for non-prehensile manipulation (e.g., pushing, sliding, tool use). This could lead to more versatile and capable robotic systems that can tackle an even wider array of manipulation tasks. More broadly, the paper's central insight – that memory discipline is paramount – offers a valuable direction for future research in long-horizon autonomy.
