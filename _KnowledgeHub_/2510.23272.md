# Code Aesthetics with Agentic Reward Feedback

> [!summary] Summary
> AesCoder enables large language models to generate aesthetically pleasing code for visually-oriented tasks like plot generation and webpage design. It achieves this by integrating a multi-agent reward framework and specialized training, allowing smaller models to outperform larger counterparts.

## Problem

- Large Language Models (LLMs) struggle to produce aesthetically pleasing code for visually-oriented tasks such as data visualizations or web pages, often resulting in suboptimal visual outputs.
- Current reward systems for training coding LLMs rely on single textual modalities, limiting their ability to assess visual and interactive aesthetics.
- There is a lack of large-scale instruction-tuning datasets and dedicated benchmarks specifically designed for evaluating code aesthetics, particularly for interactive web design.

## Method

- The **AesCoder** pipeline was developed, combining a large-scale instruction-tuning dataset (==AesCode==-358K) and a multi-agent reward framework for comprehensive aesthetic feedback.
- An Agentic Reward Framework was implemented, employing execution, static aesthetics (via GPT-5 multimodal LLM), and interactive aesthetics (via WebVoyager with GPT-4o) agents to provide diverse feedback signals.
- A two-stage training approach was used, starting with Supervised Fine-Tuning (SFT) on AesCode-358K, followed by Reinforcement Learning (RL) using the GRPO algorithm with Agentic Reward Feedback (GRPO-AR).
- A new benchmark, OpenDesign, was created to enable efficient and automated assessment of webpage aesthetics from both static and interactive perspectives.

## Results

- AesCoder models (**4B** and **7B**) consistently achieved improvements in aesthetic quality, showing lower error rates and higher 'good rates' on Python-based plot generation tasks (PandasPlotBench).
- On the OpenDesign benchmark for webpage design, AesCoder models demonstrated substantial gains in static and interactive aesthetics, outperforming large open-source models (**30B**-**685B** parameters).
- AesCoder-**4B** surpassed leading proprietary models like GPT-4o and GPT-4.1 on both PandasPlotBench and OpenDesign, achieving comparable aesthetic scores to GPT-5 and Claude Sonnet 4, as validated by human evaluations.

## Takeaways

> [!tip] Key Insights
> - Multi-modal, agent-based reward feedback is essential for guiding LLMs to generate aesthetically pleasing code, significantly outperforming approaches that rely solely on textual rewards.
> - Specialized instruction-tuning on a curated dataset combined with reinforcement learning from agentic aesthetic feedback allows smaller open-source LLMs (4B, 7B) to achieve competitive performance against much larger open-source and proprietary models.
> - The concept of 'code aesthetics' for visually rendered outputs can be effectively defined, measured, and incorporated into LLM training, extending the scope of AI-generated content quality beyond functional correctness.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The rapid advancements in Large Language Models (LLMs) have positioned them as indispensable tools for developers, excelling in traditional code-related tasks such as code generation, completion, and bug fixing. Models like DeepSeek-Coder, Qwen-Coder, and various fine-tuned variants have demonstrated remarkable proficiency in producing functionally correct code in programming languages. However, this paper identifies a critical gap: while LLMs are adept at generating code that *works*, they frequently falter when the output's quality is inherently tied to its *visual presentation* and *user experience*. This includes tasks such as generating data visualizations (e.g., Matplotlib, Seaborn, Plotly charts) or designing web pages (HTML/CSS). In these visually-oriented contexts, LLM-generated code often produces suboptimal aesthetics, characterized by issues like overlapping elements, inconsistent color schemes, and disorganized structures.

This work directly addresses this deficiency by introducing the concept of "code aesthetics," which refers to the aesthetic appeal of the *execution result* of visually-oriented code. It bridges the burgeoning field of **Aesthetics of AI-Generated Content (AIGC)**, which explores the visual quality and human preference alignment of AI-generated text, images, and other media, with the domain of **code generation**. Unlike previous AIGC aesthetics research that largely focuses on static images or textual layouts, this paper extends the concept to interactive code output, requiring a deeper understanding of visual structure, spatial layout, and interactive consistency.

Furthermore, the paper significantly contributes to the evolution of **reward systems in Reinforcement Learning (RL) for LLMs**. Current reward mechanisms for training coding LLMs primarily rely on single textual modalities, such as code executability, unit test success, or process-aware feedback. These methods, while effective for functional correctness, are inherently limited in assessing visual and interactive aesthetics. By proposing a multi-agent system for reward feedback that integrates textual, visual, and interactive assessments, the paper offers a novel approach to guide LLM training toward human-aligned aesthetic preferences. This aligns with the broader trend of **Reinforcement Learning from Human Feedback (RLHF)** but extends it into a multimodal and interactive domain.

Finally, the development of a new large-scale instruction-tuning dataset (AesCode-358K) and a dedicated benchmark (OpenDesign) is crucial for advancing research in this nascent area. The paper leverages the "LLM-as-a-Judge" paradigm, a growing methodology for evaluating LLM outputs where powerful LLMs are used to score other models, to ensure efficient and scalable aesthetic assessment. By demonstrating that even smaller open-source models can achieve competitive performance against much larger and proprietary systems through specialized training, this research democratizes access to advanced capabilities in aesthetic code generation, influencing the future development of more capable and user-friendly coding assistants.

### 2. Key Objectives and Motivation

The primary objective of this research is to **enhance the aesthetic quality of code generated by Large Language Models (LLMs)**, specifically for visually-oriented programming tasks. The authors aim to enable LLMs to produce not just functionally correct, but also visually appealing and user-friendly outputs in domains such as Python-based plot generation and webpage design.

This ambitious objective is driven by several key motivations:
- **Addressing a Critical Gap in LLM Capabilities:** While LLMs have become proficient in traditional code generation and functional programming tasks, they consistently struggle with the aesthetic dimension of visually-oriented code. They often generate code that results in poor visual outcomes, such as cluttered charts or poorly laid-out web pages. This limitation prevents LLMs from serving as truly comprehensive assistants for tasks where visual quality is paramount.
- **Defining and Measuring "Code Aesthetics":** The paper recognizes that "aesthetics" in code, especially when it pertains to visual output, has been an underexplored concept. There is a fundamental question of whether LLMs can develop an "awareness of the aesthetics of their own code." This necessitates defining what code aesthetics entails for visually rendered outputs and developing methods to objectively measure it.
- **Limitations of Existing Reward Systems:** Current reinforcement learning methods for training coding LLMs predominantly rely on single textual modalities (e.g., code executability, unit test success). These systems are inherently incapable of assessing visual appeal or interactive user experience, rendering them ineffective for tasks requiring aesthetic judgment. A new, multimodal reward mechanism is therefore essential.
- **Lack of Specialized Datasets and Benchmarks:** The absence of large-scale instruction-tuning datasets and dedicated benchmarks for evaluating code aesthetics, particularly for interactive web design, impedes progress in this area. To properly train and evaluate LLMs for aesthetic code generation, tailored resources are required.
- **Improving User Experience and Practical Utility:** By enabling LLMs to generate aesthetically pleasing code, the research aims to make these AI assistants more valuable and intuitive for developers, designers, and general users. This can lead to more efficient prototyping, higher-quality automated designs, and a more seamless user experience when interacting with LLM-generated visual artifacts.

In essence, the research seeks to elevate LLM capabilities beyond mere functionality to encompass the critical dimension of design aesthetics, fostering a new generation of visually intelligent coding assistants.

### 3. Methodology and Approach

The research introduces AesCoder, a novel pipeline designed to enhance code aesthetics, comprising dataset construction, a multi-agent reward framework, a two-stage training approach, and a new benchmark.

#### 3.1. The AesCode-358K Dataset

To provide supervised instruction-tuning for code aesthetics, the authors constructed AesCode-358K, a large-scale dataset focusing on two key domains:
- **Python-Based Plot Generation:** Instructions were adapted from the existing VisCode-200K dataset. To ensure high quality and optimal aesthetics, Python code snippets were regenerated using Qwen3-Coder-480B-A35B-Instruct-FP8. Rigorous quality control involved limiting libraries and validating code executability using Jupyter Notebook, resulting in 158K high-quality plot data points.
- **Webpage Design:** A four-step process was employed:
 1. **Seed Keyword Corpus:** GPT-4o generated keywords across five categories (General Website, 3D Design, Data Visualization, Game Dev, UI Component).
 2. **Instruction Generation:** GPT-4o produced diverse webpage design instructions from these keywords.
 3. **Semantic Analysis and Deduplication:** Instructions were embedded and visualized using t-SNE, followed by K-Means clustering to remove redundancy, resulting in 200K refined instructions.
 4. **HTML Generation & Filtering:** GPT-5 and Qwen3-Coder-480B-A35B-Instruct-FP8 generated HTML code. The quality of generated HTML was validated by rendering pages with Playwright and Selenium, and then asking GPT-5 to score the visual outputs, selecting the higher-scoring code.

#### 3.2. Agentic Reward Framework

Recognizing the limitations of single-modality reward signals for code aesthetics, the authors propose a multi-agent system to provide comprehensive feedback:
- **Execution Agent:** Verifies code executability. For HTML, it extracts code, applies HTMLHint for basic syntax validation (e.g., `<!DOCTYPE html>`, tag pairing, unique IDs), and assigns a score of 1 for success and -1 for failure.
- **Static Aesthetics Agent:** Evaluates the visual quality of rendered outputs from full-page screenshots. GPT-5 (a multimodal LLM) acts as the judge, using a chain-of-thought approach. It scores the webpage on three dimensions: instructional alignment (40 points), visual elements (30 points), and layout/cohesion (30 points), aggregating them into a total static score.
- **Interactive Aesthetics Agent:** Assesses the usability and interactivity of webpages, crucial for dynamic content. It utilizes the WebVoyager framework with GPT-4o as the multimodal model. The agent plans interactions, executes them in a headless browser environment, and records binary success/failure for each interaction by comparing screenshots. These are aggregated into an interactive score.
- **Reward Aggregation:** The final reward `r` is a weighted sum of the scores from the three agents: `r = w_exec · r_exec + w_static · r_static + w_interact · r_interact`, allowing flexible emphasis on different aesthetic dimensions.

#### 3.3. AesCoder Training

The training process consists of two stages:
- **Stage I: Supervised Fine-Tuning (SFT) on AesCode-358K:** Two base models, Qwen3-4B-Instruct-2507 and Qwen2.5-Coder-7B-Instruct, are fine-tuned on the AesCode-358K dataset. This stage aims to impart foundational knowledge of aesthetic code generation.
- **Stage II: Reinforcement Learning (RL) with Agentic Reward Feedback (GRPO-AR):** To enhance generalization and robustness, the SFT models undergo reinforcement learning using the GRPO (Group Reinforcement Policy Optimization) algorithm integrated with the Agentic Reward framework. RL training data is sourced from WebSight v0.2, with original webpage descriptions rewritten by GPT-4o to generate more natural user instructions, avoiding overlap with the SFT data. The agentic reward system provides `r_i` for each generated output `o_i`, from which advantages `(r_i - mean(r)) / std(r)` are calculated to update the policy model using the GRPO objective.

#### 3.4. OpenDesign Benchmark

To enable efficient and automated assessment of webpage aesthetics, the authors developed OpenDesign, a new benchmark comprising 840 real-world webpage design cases. It evaluates models from both static (using the Static Aesthetics Agent) and interactive (using the Interactive Aesthetics Agent) perspectives. The benchmark's reliability was validated through ranking consistency with the Design Arena platform (Spearman's ρ = 0.98, Kendall's τ = 0.91) and strong alignment between LLM scoring and human preferences (GPT-human agreement = 80.9%).

### 4. Main Findings and Results

The experimental results demonstrate the significant effectiveness of the AesCoder pipeline in improving the aesthetic quality of LLM-generated code across various tasks and model scales.

- **Overall Performance Enhancement:** Both AesCoder-4B and AesCoder-7B consistently achieve substantial improvements over their respective base models (Qwen3-4B-Instruct-2507 and Qwen2.5-Coder-7B-Instruct) across all evaluation metrics.
- **PandasPlotBench Performance:** On Python-based plot generation tasks, AesCoder models exhibit lower error rates (e.g., AesCoder-4B at 0.09 vs. baseline's 0.13), higher average scores, and increased "good rates" (scores > 75), indicating a stronger capability to generate correct and aesthetically pleasing plotting code.
- **OpenDesign Benchmark Performance:** For webpage design tasks, AesCoder models show remarkable gains in both static aesthetics (instructional alignment, visual elements, structural cohesion) and interactive aesthetics.
 - AesCoder-4B achieves a total static aesthetics score of 81.92 and an interactive score of 1.04, significantly outperforming its baseline (73.26 static, 0.67 interactive).
 - AesCoder-7B similarly shows strong improvements (81.23 static, 0.94 interactive vs. baseline's 46.27 static, 0.38 interactive).
- **Outperforming Large Open-Source Models:** Notably, AesCoder models, despite their smaller parameter scales (4B and 7B), match or surpass the performance of much larger open-source models ranging from 30B to 685B parameters (e.g., Qwen3-Coder-480B-A35B, DeepSeek-V3.1) on the OpenDesign benchmark. This highlights the efficiency and effectiveness of the proposed data and training methodology.
- **Competitive with Proprietary Models:** AesCoder-4B surpasses leading proprietary models like GPT-4o and GPT-4.1 on both PandasPlotBench and OpenDesign. While GPT-5 and Claude Sonnet 4 still maintain a slight overall advantage, AesCoder achieves comparable scores across several aesthetic dimensions, demonstrating its state-of-the-art capabilities among open-source systems.
- **Human Evaluation Validation:** Human evaluation results corroborate the quantitative findings, showing that AesCoder models consistently outperform strong open-source baselines and maintain a near 50% win rate against proprietary models like Claude Sonnet 4 and GPT-5, further validating the efficacy of the agentic reward framework.
- **Generalization and Effectiveness of Agentic Reward:**
 - Training curves for GRPO-AR show a steady increase in reward scores, indicating that the multi-agent reward framework provides stable and informative feedback, enabling continuous improvement across different model families and sizes.
 - Ablation studies confirm the crucial role of the agentic reward framework. A simplified variant that solely relies on textual reward modeling significantly underperforms the full GRPO-AR method, underscoring that multimodal and interactive feedback is essential for truly aligning models with human-perceived aesthetics.
- **Superiority over DPO and RFT:** GRPO-AR consistently outperforms other popular RLHF methods like Direct Preference Optimization (DPO) and Rejection Sampling Fine-Tuning (RFT) on OpenDesign, demonstrating its superior ability to enhance both visual quality and structural robustness of generated webpages.

Qualitative case studies further illustrate AesCoder-4B's ability to generate designs that are superior to or on par with state-of-the-art models across various web design categories.

### 5. Significance and Potential Impact

This research marks a significant step forward in the capabilities of Large Language Models (LLMs) and their application in code generation, with profound implications for the future of AI-assisted development and design.

- **Establishment of "Code Aesthetics" as a Research Field:** By defining and rigorously addressing the concept of "code aesthetics" in the context of visually-oriented output, this paper formally establishes a crucial new research direction. It shifts the focus from merely functional correctness to encompassing the critical dimension of design quality and user experience, which is paramount in many real-world applications.
- **Advancing Multimodal Understanding in LLMs:** The agentic reward framework is a pioneering approach that allows LLMs to "perceive" and "understand" the visual and interactive qualities of their generated code. This capability moves LLMs beyond textual modality, enabling them to reason about visual structure, spatial layout, and interactive coherence, which is essential for more sophisticated AI-generated content.
- **Robust Framework for Evaluation and Training:** The creation of the large-scale AesCode-358K dataset and the OpenDesign benchmark provides much-needed resources for the community. These tools offer a standardized and efficient way to train and evaluate LLMs for aesthetic code generation, accelerating future research and development in this domain. The reliability analysis of OpenDesign, correlating it with human judgment, further solidifies its utility.
- **Enhanced Practical Utility of Coding LLMs:** The significant performance gains achieved by AesCoder models translate directly into more capable and user-friendly coding assistants. Developers and designers can leverage these enhanced LLMs for tasks like generating production-ready data visualizations, prototyping web pages with better UI/UX, and creating interactive components, thereby streamlining workflows and elevating the quality of AI-assisted outputs.
- **Innovation in Reinforcement Learning for LLMs:** The integration of the multi-agent reward feedback system with the GRPO algorithm (GRPO-AR) represents a novel advancement in Reinforcement Learning from Human Feedback (RLHF). It demonstrates how complex, multimodal feedback can effectively guide LLM training for tasks that require nuanced aesthetic and interactive judgments, paving the way for similar methodologies in other complex AIGC domains.
- **Democratization of Advanced AI Capabilities:** The remarkable achievement of smaller, open-source AesCoder models (4B, 7B) in outperforming and rivalling much larger proprietary models (e.g., GPT-4o, GPT-4.1) is particularly impactful. This showcases that with specialized data and sophisticated training techniques, smaller models can achieve state-of-the-art performance, making advanced AI capabilities more accessible and reducing reliance on computationally intensive, closed-source giants. This can foster innovation across a broader scientific and industrial landscape.

In conclusion, "Code Aesthetics with Agentic Reward Feedback" not only pushes the technical boundaries of LLMs in code generation but also opens up new avenues for AI to understand and create content with a sophisticated sense of design and user experience, bridging the gap between functional code and artistic expression.
