# Code as Policies: Language Model Programs for Embodied Control

> [!summary] Summary
> Robotics at Google developed 'Code as Policies,' a method that enables pre-trained code-writing language models to directly synthesize executable Python programs for robot control. This approach facilitates precise spatial-geometric reasoning, generalizes to diverse tasks with few examples, and was demonstrated across various real robot platforms for tasks like drawing, manipulation, and navigation.

## Problem

- Existing methods for language-conditioned robot control struggle with the 'data burden,' requiring extensive and costly training data for each new skill or scenario.
- Prior large language model (LLM) approaches for robotics are limited to high-level planning, abstracting away from the perception-action feedback loop and hindering their ability to influence low-level control, generalize feedback modes, or express precise spatial relationships.
- Traditional symbolic methods are brittle and do not generalize well to novel or unseen instructions due to their reliance on explicitly defined rules.

## Method

- Pre-trained code-writing Large Language Models (LLMs) are used to directly synthesize Python programs, called Language Model Programs (LMPs), that serve as robot policies, react to perceptual inputs, and parameterize low-level control APIs.
- A few-shot prompting strategy provides the LLM with API hints and examples of instruction-to-code translations, including the use of third-party libraries (e.g., NumPy) for complex spatial-geometric reasoning.
- A novel hierarchical code generation technique allows the LLM to recursively define new functions, enabling the creation of more complex, multi-layered policy logic and facilitating more robust code generation.

## Results

- Hierarchical code generation achieved a 95% pass rate on the new robotics-themed RoboCodeGen benchmark and improved HumanEval P@1 to 39.8% for Codex code-davinci-002, outperforming flat generation and previous state-of-the-art.
- Code as Policies achieved 96% accuracy on object selection and 100% on position selection in spatial-geometric reasoning benchmarks, significantly outperforming Chain-of-Thought (68% and 48%) and vanilla natural language (39% and 30%).
- The method was successfully deployed on real UR5e robot arms and mobile Everyday Robots, demonstrating robust performance for tasks like drawing shapes, tabletop manipulation with nuanced spatial queries, and mobile navigation in real-world environments.

## Takeaways

> [!tip] Key Insights
> - Generating executable Python code allows language models to directly influence low-level robot control, enabling precise spatial-geometric reasoning and incorporating behavioral commonsense by leveraging external libraries like NumPy.
> - Hierarchical code generation, where a language model recursively defines undefined functions, improves performance on both general code synthesis and complex robotics-specific tasks by enabling more structured and longer code.
> - Leveraging large pre-trained code-writing language models significantly reduces the data burden traditionally associated with training robot policies, allowing for broad generalization with few-shot examples.
