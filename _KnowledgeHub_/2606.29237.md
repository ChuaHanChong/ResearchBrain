# MoPe: Motion Permanence for Robust Monocular Gaussian Mapping in Dynamic Environments

> [!summary] Summary
> The MoPe framework enhances monocular Gaussian mapping in dynamic environments by applying Motion Permanence, a principle that temporally propagates dynamic evidence to maintain an object's dynamic identity. This method reduces ghosting artifacts and map contamination, yielding improvements in tracking accuracy and generating leaner, more accurate static world models.

## Problem

- Monocular visual SLAM systems, particularly those using 3D Gaussian Splatting, frequently generate "ghosting" artifacts by incorporating moving objects into the static map.
- Current state-of-the-art uncertainty-aware dynamic SLAM methods are memoryless, estimating dynamic regions based on instantaneous observations, which allows temporarily stationary dynamic objects to contaminate the static scene representation.
- These corrupted static maps hinder reliable localization, navigation, and decision-making for autonomous robots that rely on an accurate static world model.

## Method

- Introduces "==Motion Permanence==" to temporally propagate dynamic identity by accumulating dynamic evidence using ==SE(3) kinematic propagation== and ==bounded Bayesian log-odds fusion== of per-frame uncertainty.
- Integrates the persistent dynamic posterior into tracking (down-weighting residuals), mapping (lower optimization weight), and Gaussian insertion (a "==fail-closed== gate" prevents dynamic content from being added).
- Employs a ==Gaussian-level post-cleanup== mechanism that progressively attenuates the opacity of dynamic Gaussians identified through a multi-view dynamic ratio, rather than aggressively deleting them.

## Results

- Achieved improved tracking accuracy, reducing Average Trajectory Error (ATE RMSE) by **15.2%** to **17.4%** across Wild-SLAM, Bonn, and TUM RGB-D dynamic datasets compared to the WildGS-SLAM baseline.
- Produced cleaner static map reconstructions with significantly reduced "ghosting" artifacts, particularly evident in dynamic-human sequences and on an artifact-focused benchmark where Mean Background MAE for the tail segment improved from **20.649** to **20.021**.
- Demonstrated enhanced computational efficiency, processing frames faster (**65.3 ms** total per frame) and using less memory (**5.3 GB**) than the baseline, attributed to the conservative Gaussian insertion strategy.

## Takeaways

> [!tip] Key Insights
> - Dynamic-ness is fundamentally a temporal property defined by motion history, not an instantaneous observation, necessitating a temporal memory mechanism for robust identification.
> - Bounded Bayesian log-odds fusion provides an effective and robust method to accumulate and propagate dynamic evidence across frames, preventing saturation and allowing adaptation to changing object motion states.
> - A conservative "fail-closed" approach to Gaussian insertion, informed by persistent dynamic evidence, reduces map contamination while also improving computational efficiency and memory usage by limiting the growth of dynamic Gaussians.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The work addresses a persistent challenge in visual Simultaneous Localization and Mapping (SLAM): achieving robust performance in dynamic environments, particularly for monocular systems. Traditional visual SLAM systems often assume static scenes, treating moving objects as outliers. Recent advancements, such as those leveraging dense, differentiable alignment architectures like DROID-SLAM, and particularly 3D Gaussian Splatting (3DGS) for high-fidelity scene representation, have improved mapping and rendering quality. However, dynamic elements continue to pose a fundamental obstacle, often leading to "ghosting" artifacts where transient objects are erroneously incorporated into the static map.

Existing approaches to dynamic SLAM within the 3DGS framework include:
- **Binary masking:** Methods like UP-SLAM and RGD-SLAM use motion residuals or semantic probabilities to create binary masks, but these can be brittle and discard valuable boundary information.
- **Uncertainty-aware methods:** WildGS-SLAM, a state-of-the-art approach, predicts a continuous 2D uncertainty map from foundation features to softly weight tracking and mapping. While avoiding hard binary decisions, this method estimates uncertainty independently for each frame, rendering it effectively "memoryless." This allows dynamic content to be absorbed into the static map if a moving object momentarily appears static (e.g., a paused pedestrian).
- **Temporal modeling:** Some systems attempt temporal consistency, but often at the object or mask level (e.g., DGS-SLAM, DyGS-SLAM using object-track association), or by baking uncertainty into a slowly evolving static representation (VarSplat). 4D Gaussian Splatting addresses dynamic geometry explicitly, which is distinct from maintaining a static map. Critically, continuous, image-space soft-weighting pipelines have lacked an explicit mechanism for persistent dynamic identity over time.

This paper identifies a "representation-level mismatch" in current uncertainty-aware monocular Gaussian mapping. It argues that dynamic-ness is a temporal property defined by motion history, not an instantaneous appearance cue. The work positions itself to fill the gap of temporal memory in uncertainty estimation for Gaussian Splatting SLAM, aiming to provide a persistent understanding of dynamic regions rather than relying solely on per-frame observations. This directly tackles the problem of dynamic objects corrupting the static world model, which has implications beyond rendering for localization, navigation, and decision-making in robotic autonomy.

### 2. Key Objectives and Motivation

The primary objective of this research is to enhance the robustness of monocular Gaussian mapping in dynamic environments by introducing a temporal understanding of dynamic regions, thereby preventing persistent ghosting artifacts and map contamination.

The motivation for this work stems from several limitations observed in current state-of-the-art monocular Gaussian Splatting SLAM systems:
- **Memoryless uncertainty estimation:** While methods like WildGS-SLAM employ uncertainty weighting to handle dynamic elements, they typically estimate this uncertainty independently for each frame based solely on instantaneous image evidence. This makes the system "memoryless."
- **Persistent ghosting artifacts:** When a dynamic object (e.g., a pedestrian) slows, pauses, or reappears after occlusion, a single frame might assign it low uncertainty, leading to its appearance being "baked" into the static map. This results in persistent ghosting or afterimages, corrupting the geometry and novel-view rendering.
- **Corruption of static map for downstream tasks:** For autonomous robots, these artifacts are not merely visual imperfections. A static map corrupted by intermittent dynamic content can mislead localization, navigation stacks, and other downstream decision-making modules that rely on an accurate representation of the static world.
- **Conceptual mismatch:** The paper posits that treating dynamic-ness as an instantaneous appearance property, rather than a temporal property defined by motion history, is a fundamental conceptual mismatch. What distinguishes a paused pedestrian from a wall is not their current appearance, but their past motion.

To address these issues, the paper introduces the principle of **Motion Permanence**: the idea that an object's dynamic identity should persist over time, analogous to object permanence in cognitive development. This principle aims to prevent dynamic content from being inadvertently absorbed into the static map due to momentary stillness or occlusion. The goal is to accumulate and leverage historical dynamic evidence to make more informed decisions during the SLAM process.

### 3. Methodology and Approach

MoPe (Motion Permanence) extends a monocular Gaussian mapping pipeline by incorporating a temporally propagated dynamic state. The methodology is structured around three integrated components: (i) temporal evidence accumulation for Motion Permanence, (ii) posterior-guided optimization with dynamic-aware Gaussian insertion, and (iii) a Gaussian-level post-cleanup.

**A. Motion Permanence via Temporal Evidence Accumulation**

The core of MoPe is the accumulation of dynamic evidence over time, transforming transient per-frame uncertainty into a persistent dynamic posterior.
1. **Per-frame measurement:** For each frame *t*, an uncertainty branch predicts a per-pixel uncertainty map `β_t(u)`, which is converted into a confidence weight `w_t(u)` and a frame-wise dynamic evidence score `d_unc_t(u) = 1 - w_t(u)`. Optionally, a weak semantic prior `d_sem_t(u)` from an off-the-shelf segmentation model can be incorporated to provide a soft lower bound on dynamic likelihood for likely-transient classes. The combined per-frame measurement `m_t(u)` is the maximum of `d_unc_t(u)` and `d_sem_t(u)`.
2. **SE(3) Kinematic Propagation:** To maintain dynamic identity across changing camera viewpoints, the previous frame's dynamic posterior `p_{t-1}` is warped into the current frame using the estimated camera motion `T_{t-1→t}` and current depth information `D_t`. This generates `p̃_{t-1→t}(u)`.
3. **Bounded Bayesian Log-Odds Fusion:** The propagated historical state `L_{t-1→t}` (log-odds of `p̃_{t-1→t}`) is fused with the current frame's measurement `logit(m_t(u))` in a bounded log-odds space. The update rule is `L_t(u) = clip(L_{t-1→t}(u) + γ logit(m_t(u)), -c, c)`, where `γ` is a measurement gain and `c` is a clipping bound. The resulting `L_t(u)` is then converted back to a probability `p_t(u)` via the sigmoid function `σ(·)`.
 - **Rationale for log-odds:** Bayesian updates simplify to additions in log-odds space, dynamic and static evidence are treated symmetrically, and the clipping bound `c` prevents saturation, allowing regions previously deemed dynamic to eventually become static if they consistently stop moving.
 The resulting `p_t(u)` serves as a persistent estimate of dynamic identity.

**B. Posterior-Guided Optimization and Gaussian Insertion**

The persistent dynamic posterior `p_t(u)` is integrated into various stages of the SLAM pipeline:
1. **Tracking Robustness:** During pose estimation, residuals in regions with a high `p_t(u)` are down-weighted by a factor of `(1 - p_t(u))`. This makes the tracker less sensitive to slowly moving or temporarily stationary distractors, preventing them from corrupting camera pose estimation.
2. **Memory-Aware Mapping:** The accumulated posterior informs the rendering objective during mapping. Regions with persistent dynamic evidence receive lower optimization weight, influencing the photometric and depth supervision terms.
3. **Dynamic-Aware Gaussian Insertion:** A crucial component is the "fail-closed" gate for Gaussian insertion. A pixel `u` is admitted for Gaussian insertion only if its dynamic insertion score `s_t(u) = max(p_t(u), η M_sem_t(u))` (where `M_sem_t` is an optional semantic support mask and `η` a conservative floor) falls below a threshold `τ_ins`. This rule biases the system towards skipping insertion if the region is persistently dynamic, preferring omission over contamination. If a region is confidently static later, insertion can occur then.

**C. Gaussian-Level Post-Cleanup**

As a final safeguard, a post-cleanup mechanism addresses dynamic Gaussians that might have inadvertently been inserted due to imperfect observations or repeated occlusions.
1. **Dynamic Ratio Calculation:** For each Gaussian `g_i`, the system projects it into multiple keyframes and collects evidence of its dynamic behavior. A "dynamic ratio" `r_dyn_i` is calculated as the count of dynamic observations (`h_dyn_i`) divided by the total valid observations (`h_obs_i`).
2. **Progressive Opacity Decay:** Gaussians with sufficient multi-view support and a high dynamic ratio are identified as cleanup candidates. Instead of aggressive hard-deletion, their opacity `α_i` is progressively attenuated using `α_i ← max(ρ α_i, α_min)`, where `ρ` is a decay factor and `α_min` is a lower bound. This gradual decay suppresses persistent dynamic residuals and afterimages while preserving potentially valid background structure.

### 4. Main Findings and Results

The evaluation of MoPe was conducted on several datasets and metrics, comparing it against established baselines.

**A. Tracking Robustness**
- MoPe demonstrated improved tracking accuracy across all three dynamic datasets: Wild-SLAM MoCap, Bonn, and TUM RGB-D benchmarks.
- The Average Trajectory Error (ATE RMSE) showed reductions of 17.4% on Wild-SLAM (0.46 → 0.38 cm), 15.6% on Bonn (2.31 → 1.95 cm), and 15.2% on TUM (1.51 → 1.28 cm) compared to the WildGS-SLAM baseline.
- The most significant gains were observed in sequences with intermittently moving objects (e.g., dynamic-human scenes in Wild-SLAM), supporting the hypothesis that Motion Permanence prevents the tracker from incorrectly locking onto temporarily stationary distractors.

**B. Map Quality and Artifact Suppression**
- **Wild-SLAM MoCap Dataset:** MoPe generally improved reconstruction, particularly in human-dynamic sequences like "Crowd" and "Person," where both ATE and rendering metrics (PSNR, SSIM, LPIPS) improved. For instance, "Person" showed ATE improvement from 0.800 to 0.650 and PSNR from 20.31 to 20.85.
- **Artifact-Focused Benchmark (iphone_wandering):** On the challenging `iphone_wandering` sequence, designed to isolate residual ghosting, MoPe achieved the cleanest background reconstruction. It showed a slight improvement in Mean Background PSNR (18.401 → 18.410) and Mean Background MAE (19.187 → 19.183) over a semantic-prior baseline. Its advantage was particularly clear in the "tail" segment (Tail BG PSNR 18.102 → 18.418, Tail BG MAE 20.649 → 20.021), where persistent afterimages are most prevalent.
- **Qualitative Results:** Visual comparisons (Figure 2, Figure 3) confirmed that MoPe effectively prevented dynamic pedestrians from being baked into the static map, resulting in cleaner rendered scenes without floating residuals.
- **Targeted Improvement:** The paper notes that improvements are targeted. On certain cluttered sequences with continuous motion (e.g., ANYmal2) or near-static clutter (e.g., Stones, Table1), some pixel-level metrics occasionally fell slightly below the baseline. This is attributed to the conservative nature of MoPe's insertion, which might reduce fine detail in non-dynamic regions but consistently benefits dynamic-human scenarios.

**C. Efficiency**
- Despite adding temporal processing, MoPe introduced minimal overhead. The temporal posterior propagation and log-odds update added only 0.3 ms to tracking runtime (24.5 → 24.8 ms per frame).
- Overall, MoPe was faster (65.3 vs. 69.7 ms total per frame) and more memory-efficient (5.3 vs. 5.8 GB) than the baseline. This is attributed to the "fail-closed" insertion gating, which keeps the Gaussian map leaner by preventing the insertion of dynamic content, thereby accelerating mapping (45.2 → 40.5 ms) and reducing memory usage.

**D. Ablation Study**
- An ablation study on `iphone_wandering` confirmed the complementary contributions of each component. Starting with temporal fusion, progressively adding the semantic prior, insertion gating, and opacity decay consistently improved background preservation metrics.
- The full MoPe pipeline achieved the best performance across all four background metrics, with the most pronounced effect on the "tail" segment MAE (20.862 → 20.021), indicating its effectiveness in suppressing stubborn afterimages.

**E. Hyperparameter Sensitivity**
- MoPe demonstrated stability across a broad range of the insertion threshold `τ_ins` ([0.3, 0.7]), indicating it does not require fine-tuning. Performance only degraded at extreme values where insertion was either excessively starved or the fail-closed guard was effectively disabled.

### 5. Significance and Potential Impact

This work presents a notable advancement in robust monocular Gaussian mapping, particularly for dynamic environments. The introduction of **Motion Permanence** as a guiding principle addresses a fundamental limitation of previous uncertainty-aware SLAM systems: their memoryless nature regarding dynamic identity. By elevating dynamic-ness from an instantaneous appearance property to a persistent temporal state, MoPe offers a more reliable and robust scene representation.

The significance and potential impact include:
- **Enhanced Robotic Autonomy:** The core contribution of preventing dynamic content from corrupting the static map directly supports more reliable robot autonomy. Accurate static maps are crucial for localization, navigation, path planning, and downstream decision-making modules. By reducing ghosting and artifacts, MoPe contributes to a more trustworthy world model for robots operating in real-world, dynamic settings.
- **Improved Scene Representation Quality:** The method consistently yields cleaner reconstructions, particularly in challenging dynamic-human scenarios where intermittent motion frequently leads to artifacts in other systems. This results in higher fidelity maps that better reflect the true static environment.
- **Novel Temporal Uncertainty Management:** MoPe introduces a practical mechanism for temporal evidence accumulation through geometry-consistent SE(3) propagation and bounded Bayesian log-odds fusion of uncertainty. This approach provides a concrete method for managing persistent dynamic state within dense uncertainty fields, which is a gap in current continuous soft-weighting pipelines.
- **Efficiency Gains through Conservatism:** The "fail-closed" insertion strategy, guided by the persistent dynamic posterior, not only improves map quality but also leads to a leaner Gaussian map. This counterintuitively results in reduced computational cost and memory footprint, demonstrating that a more accurate and robust representation can also be more efficient.
- **Generalizability to Intermittent Dynamics:** The strongest gains observed on dynamic-human scenes, characterized by stop-and-go motion, highlight MoPe's effectiveness in precisely the scenarios where memoryless systems fail. This demonstrates its targeted utility for common real-world dynamic situations.

While the method exhibits conservatism, potentially leading to slight reductions in fine detail in some sequences, its targeted improvements and overall robustness represent a practical step toward addressing a critical bottleneck in representation-centric autonomy. Future work could focus on extending Motion Permanence to more unstructured environments by refining depth error tolerance and exploring attention mechanisms to complement purely geometric warping, further broadening its applicability.
