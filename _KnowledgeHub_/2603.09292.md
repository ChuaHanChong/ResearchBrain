# See, Plan, Rewind: Progress-Aware Vision-Language-Action Models for Robust Robotic Manipulation

> [!summary] Summary
> The See, Plan, Rewind (SPR) framework improves robust robotic manipulation by providing Vision-Language-Action (VLA) models with spatially-grounded progress awareness and an integrated error recovery mechanism. It demonstrated reduced performance degradation (18.8%) on out-of-distribution tasks and enabled successful execution of complex real-robot tasks where baselines failed.

## Problem

- Existing Vision-Language-Action (VLA) models often lack a concrete, quantitative understanding of task progress, leading to error accumulation and inefficient execution.
- Prior attempts at progress monitoring rely on abstract linguistic or binary signals, which lack explicit spatial grounding for precise robot action and reliable error detection.
- Current failure recovery mechanisms are typically data-intensive, requiring costly collection of failure-specific data or dependence on auxiliary models.

## Method

- The See, Plan, Rewind (SPR) framework provides progress-aware reasoning through a continuous cycle: See (perceive state), Plan (generate 2D trajectory to subtask), and Rewind (error recovery).
- Tasks are decomposed into fine-grained, spatially-grounded 2D subgoals with semantic descriptions, extracted automatically from existing demonstrations without extra human annotation.
- An intrinsic 'Rewind' mechanism is implemented for error recovery, using progress-based anomaly detection to trigger a brief, learned retraction to disengage from erroneous states.

## Results

- Achieved an average **91.8%** success rate on the LIBERO benchmark, representing a **5.0%** improvement over the MolmoAct baseline, with an **8.2%** gain on long-horizon tasks.
- Demonstrated state-of-the-art out-of-distribution (OOD) robustness on LIBERO-Plus, exhibiting the smallest average performance degradation (**18.8%**) compared to baselines like OpenVLA-OFT (**27.0%**).
- Successfully executed real-robot tasks such as 'Tidy up the Table' (**30%** success rate for 3 objects, baselines failed) and 'Push-T' (**40%** success, baselines failed), showcasing generalization beyond pick-and-place.

## Takeaways

> [!tip] Key Insights
> - Formalizing task progress as explicit, spatially-grounded 2D subgoals provides robot-interpretable milestones, crucial for fine-grained task execution and effective error detection.
> - Integrating a data-efficient error recovery mechanism (Rewind), trained on synthesized reverse trajectories, allows for autonomous failure management without requiring additional failure data or auxiliary models.
> - A unified framework combining progress awareness and intrinsic recovery significantly enhances robustness and generalization capabilities in challenging long-horizon and out-of-distribution manipulation scenarios.
