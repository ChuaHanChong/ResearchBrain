# Skills in Weights, Memory in Code: Hybrid Learning for Memory-Dependent Robot Manipulation

> [!summary] Summary
> HyMeS is a hybrid framework for memory-dependent manipulation that keeps a flow-matching VLA Markovian and fine-tuned only for motor skills, while a coding agent learns executable symbolic memory in code space from rollout feedback. That memory selects differentiable stage constraints whose gradients steer denoising, with multimodal stage verification updating memory. On RoboMemArena it lifts task success from 41.3% to 60.1% over the same policy weights.

## Problem

- Modern VLA policies are Markovian by construction, conditioning on the current observation or a short window, so aliased observations admit incompatible action modes.
- Memory-augmented VLAs bake memory into weights and train end to end, entangling memory acquisition with motor learning and demanding demonstrations covering combinatorial task states.
- Existing inference-time steering methods compute guidance reactively from current observations or external signals, maintaining no episode-level memory and reading nothing back from the policy.

## Method

- Hybrid learning splits capability: ==flow-matching== imitation fine-tunes motor skills in weight space, while a coding agent revises an executable program of constraint-selection, verification, and memory-update rules from rollout traces.
- ==Memory-conditioned steering== adds the gradient of a stage-specific ==differentiable constraint reward== to the flow-matching velocity field, with a sigmoid schedule attenuating guidance near contact-rich interaction.
- **PACE** verification fuses proprioceptive latches with multi-frame ==Qwen3-VL-8B== completion judgments, advancing a stage only when at least 3 of the 5 most recent queries pass.

## Results

- On 12 RoboMemArena tasks over 160 episodes, cumulative success rose from **52.5%** to **66.2%** and task success from **41.3%** to **60.1%** versus the same fine-tuned policy.
- It beat the memory-augmented baseline by **4.5** cumulative and **14.5** task-success points; on the SO-101 robot task success went from **25.7%** to **57.1%**.
- Ablations: rollout-refined programs added **8.5** cumulative and **18.4** task-success points; vision-only verification lost **16.0/21.7** points, proprioception-only **8.8/8.4**.

## Takeaways

> [!tip] Key Insights
> - Splitting discrete combinatorial memory logic into editable code and continuous motor competence into weights makes demonstration budget scale with skills, not task configurations.
> - Symbolic memory readable at every control step lets failures be localized to memory update, motor execution, or event verification instead of an opaque latent buffer.
> - Unreliable memory can hurt: the memory-augmented baseline fell below the reactive policy under occlusion, so verified stage transitions matter more than memory capacity.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of robot manipulation has seen significant advancements with the development of Vision-Language-Action (VLA) models. These models, exemplified by systems like π$_{0.5}$ and π$_{0.6}$, have demonstrated broad manipulation capabilities, generalizing across various objects, scenes, and language instructions. They are proficient at acquiring and executing a wide range of low-level motor skills.

Despite this progress, a fundamental limitation of most current VLA models is their Markovian design. These models typically generate each action from the current observation or a short, fixed-length history. However, many real-world manipulation tasks are non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories. For instance, tasks that involve counting repetitions, recalling object properties observed earlier, or remembering past locations necessitate persistent memory beyond immediate observations.

Existing approaches to address this memory limitation in VLAs generally fall into two categories. One category involves extending the observation context or incorporating learned memory modules directly into the policy, training the history-conditioned policy end-to-end from robot demonstrations. While these methods can imbue policies with memory, they often entangle memory acquisition with motor skill learning. This entanglement can lead to high data demands, as robot demonstrations must cover a combinatorial space of memory configurations, even for situations where no new physical skill is required. Furthermore, the learned latent memory buffers can be difficult to inspect or modify, limiting interpretability and debuggability.

A complementary line of research focuses on steering pretrained generative policies at inference time. These methods inject guidance into action sampling from various sources such as human interactions, value functions, goal-conditioned dynamics models, or VLM-synthesized rewards. While preserving the base policy's skill prior, these steering mechanisms are typically reactive, relying on current observations or external signals, and do not maintain episode-level memory for long-horizon tasks. Information flow in these systems is often unidirectional, with limited feedback from policy execution back to the steering mechanism.

Separately, coding agents, which use Large Language Models (LLMs) to write executable code, have been applied in robotics for tasks like composing control APIs, generating reward functions, or orchestrating low-level policies as tools. These agents often operate at a sub-task granularity, either replacing the low-level policy or commanding it, but generally leave the underlying action generation process untouched.

This work introduces HyMeS, a hybrid learning framework that positions itself by addressing the limitations of these existing paradigms. It aims to bridge the gap between proficient Markovian motor skills and the need for long-horizon memory by separating motor skill learning (in weight space) from memory strategy learning (in code space). By leveraging a coding agent to steer a frozen Markovian VLA with explicit, interpretable memory, and by incorporating a bidirectional feedback loop for memory updates, HyMeS proposes a novel architecture that seeks to overcome the data inefficiency, interpretability challenges, and reactive limitations of prior memory-augmented VLA and steering approaches.

### 2. Key Objectives and Motivation

The primary objective of this research is to enable robots to perform memory-dependent manipulation tasks reliably, which are common in real-world scenarios but challenging for conventional Markovian VLA policies. The motivation stems from several limitations observed in the current state of robotic control:

1. **Addressing Non-Markovian Tasks:** Many real-world manipulation tasks are non-Markovian. This means that the optimal action at any given moment does not solely depend on the current observation but also on information gathered from earlier in the interaction history. Examples include tasks where a specific count of actions must be performed based on an initial cue, or where an object needs to be moved to a location previously occupied by another. Standard VLA policies, by design, are largely Markovian, operating on the current observation or a short, fixed-length context. This structural limitation causes them to fail in tasks requiring long-horizon memory and reasoning.

2. **Overcoming Data Inefficiency of End-to-End Memory Learning:** Existing memory-augmented VLA approaches often attempt to learn memory capabilities end-to-end within the policy's weight space. This involves training the policy with extended observation contexts or dedicated memory modules from robot demonstrations. A significant drawback of this approach is its data inefficiency. Memory logic, especially for combinatorial and discrete aspects (e.g., specific counts or complex sequences), requires demonstrations that cover a vast space of memory configurations. This can be prohibitively expensive to collect, even when the underlying motor skills are simple and already present. The current work is motivated to decouple this, requiring demonstrations only for reusable motor skills, not for every history-dependent task variation.

3. **Enhancing Interpretability and Editability:** When memory logic is encoded implicitly within a neural network's weights, it becomes difficult to inspect, debug, or modify. Latent memory buffers are opaque, hindering understanding of *why* a policy made a certain decision or *how* to correct a memory-related error. The motivation for HyMeS includes creating an explicit, symbolic, and executable memory representation that is transparent and amenable to direct revision, enabling easier diagnosis and improvement of memory strategies.

4. **Leveraging Existing VLA Motor Competence:** Modern VLAs have demonstrated considerable skill in low-level motor control. The research is motivated by the idea of building upon this established motor competence rather than relearning it with every memory-dependent task. By keeping the VLA policy Markovian and freezing its weights after initial motor skill training, the system can benefit from the VLA's broad skill repertoire without requiring it to implicitly learn complex memory logic.

5. **Closing the Loop for Robust Memory Management:** Prior steering methods often lack a robust feedback mechanism from execution back to the steering logic, particularly for updating persistent memory. A key motivation is to implement a reliable, closed-loop mechanism for verifying stage completion and updating symbolic memory based on real-time robot execution feedback, incorporating both proprioceptive and visual cues to ensure accuracy.

In summary, the key objectives are to develop a hybrid framework that effectively separates low-level motor skill learning (in a fixed VLA) from high-level memory management and reasoning (in an executable code-based agent), thereby enabling data-efficient compositional generalization, improving task success in non-Markovian scenarios, and enhancing the interpretability and diagnosability of robot behavior.

### 3. Methodology and Approach

HyMeS operates as a hybrid learning framework that integrates a flow-matching VLA for low-level motor skills with an executable heuristic program for high-level memory management. This approach separates the learning of motor skills from memory strategies, employing different learning mechanisms for each component.

#### 3.1. Overall Architecture and Interaction Loop

The system consists of a pretrained VLA (e.g., π$_{0.5}$) and an executable heuristic program P = (C, V, U), which contains constraint-selection rules (C), event-verification rules (V), and memory-update rules (U). During operation, the coding agent applies a frozen version of P to instantiate context-dependent stage rules and an initial symbolic memory state `s_1` based on the language instruction `ℓ` and initial observation `o_1`. The interaction proceeds in a closed-loop:

1. **Constraint Selection (R_t):** The program `P` selects a differentiable constraint `R_t = C(s_t, o_t, ℓ)` based on the current symbolic memory `s_t`, observation `o_t`, and instruction `ℓ`.
2. **Action Steering (a_t):** The selected constraint `R_t` guides the pretrained VLA to generate an action chunk `a_t = Steer(π_θ*, R_t, o_t, ℓ)`.
3. **Progress Verification (e_t):** A stage-progress event `e_t` is verified by `V` from observations and executed action chunks within a sliding window `W_t`.
4. **Memory Update (s_t+1):** If an event is accepted, the program `U` updates the symbolic memory `s_t` to `s_t+1` and advances the task stage.

#### 3.2. Motor-Skill Learning in Weight Space

The motor component is a Markovian flow-matching policy `π_θ(a_t | o_t, ℓ)`. This policy is initialized from a pretrained VLA and then fine-tuned using gradient-based imitation learning on an expert demonstration dataset D. The objective is to learn a velocity field `v_θ` by minimizing the difference between the policy's predicted velocity and the true velocity required to transform Gaussian noise `ϵ` into an expert action `a` over a flow timestep `τ`. Critically, once this fine-tuning is complete, the policy's parameters `θ*` remain fixed. This ensures that memory acquisition and management do not modify the fundamental motor skills learned by the VLA.

#### 3.3. Memory-Strategy Learning in Code Space

The memory component maintains an explicit symbolic state `s_t`, which includes the active plan stage `ρ_t`, task bindings, repeated-event counts, and persistent interaction states. This `s_t` serves as an executable estimate of the task state `z_t`. Unlike learned history embeddings, `s_t` is updated by transparent, executable rules.

The program P is developed iteratively through a process of heuristic learning driven by a coding agent (e.g., an Opus 4.8 model). In each iteration, a candidate program `P^(n)` is executed, generating a symbolic execution trace `ξ_n`. This trace, along with stage-wise verdicts `b_n` from the benchmark, is fed back to the coding agent. The agent then compares the progress reported by the system with the benchmark's ground truth, diagnoses failures (e.g., mis-specified constraints or incorrect verification rules), and revises `P^(n)` to `P^(n+1)`. This learning process updates the software logic (code) rather than neural network parameters, relying on rollout feedback and not requiring expert action labels or gradients. The best-performing program `P*` from development rollouts is then used during evaluation.

#### 3.4. Memory-Conditioned Action Steering

At each control step, the symbolic memory `s_t` and active stage `ρ_t` are used to select a differentiable constraint `R_ρt(a, o_t; s_t)`. For example, a "reaching" stage might instantiate a constraint that minimizes the squared distance between the end-effector position of an action `a` and a target grounded from symbolic memory. This selected constraint is then injected into the flow-matching velocity field:
`v̂ = v_θ*(a_τ, τ | o_t, ℓ) + λ_t∇_aτ R_ρt(a_τ, o_t; s_t)`
The gradient of `R_ρt` steers the denoising process of the VLA, biasing action generation towards behaviors consistent with the current memory state. The guidance strength `λ_t` is dynamically attenuated as the policy approaches the interaction region, allowing the learned motor policy to dominate during contact-rich execution while memory guides higher-level behavior selection.

#### 3.5. Multimodal Progress Verification and Memory Update (PACE)

Reliable updates to the symbolic memory depend on accurately determining if a stage has been completed. HyMeS introduces Proprioception-And-Completion-driven stagE-switching (PACE). PACE combines two complementary evidence streams:

1. **Proprioceptive Evidence:** Detects action-dependent motion patterns (e.g., gripper state, joint positions) and preserves persistent events through symbolic latches.
2. **Visual Evidence:** Provided by a VLM (Qwen3-VL-8B) which judges stage completion from the active stage and a sequence of up to five recent RGB frames. This multi-frame context helps disambiguate ongoing actions from completed ones.

PACE periodically issues completion queries, combining binary judgments from both streams (`d_r = e^(r)_prop ∨ e^(r)_vlm`). To enhance robustness and suppress isolated errors, a stage-progress event fires only when at least `k` out of `w` most recent queries indicate completion (e.g., `w=5, k=3`). Upon event acceptance, the memory update rules `U` advance the stage, modify the memory contents (bindings, counters, persistent states) based on the current observation, and activate the constraint for the next stage. This bidirectional loop ensures that memory updates are grounded in physical execution feedback.

### 4. Main Findings and Results

The research presents quantitative and qualitative results from experiments conducted in both simulation (RoboMemArena) and on a real-world SO-101 robot.

#### 4.1. Quantitative Results

- **RoboMemArena Simulation:**
 - **Overall Performance:** HyMeS significantly improved robot performance on 12 memory-dependent tasks. Compared to the baseline Markovian π$_{0.5}$ policy (using identical policy weights), HyMeS increased the Cumulative Success Rate (CSR) from 52.5% to 66.2% and the Task Success Rate (TSR) from 41.3% to 60.1%.
 - **Comparison with PrediMem:** HyMeS outperformed PrediMem, an existing memory-augmented baseline, achieving a 14.5-point higher TSR and a 4.5-point higher CSR. This suggests that HyMeS is more effective at converting intermediate progress into successful task completion.
 - **Category-Specific Gains:**
 - **Counting, Transferring, and Sequence Tasks:** HyMeS showed the largest TSR gains on these categories (30.0, 26.6, and 22.5 points over π$_{0.5}$, respectively), directly supporting the benefits of explicit counters, object-location associations, and stage state management. For counting tasks, HyMeS achieved 50.0% TSR compared to PrediMem's 36.7%, despite a slightly lower CSR, indicating more reliable full-task completion once initial stages succeed.
 - **Occlusion Tasks:** This category remained challenging. While PrediMem performed worse than the reactive π$_{0.5}$ (38.3% vs. 50.4% CSR), HyMeS matched π$_{0.5}$ on CSR (50.6%) and improved TSR by 7.0 points (to 47.0%), suggesting that verified stage transitions mitigate some negative effects of unreliable memory in visually ambiguous conditions.
- **Real-World Experiments (SO-101 Robot):**
 - On three memory-dependent tasks, HyMeS increased the overall TSR from 25.7% (for π$_{0.5}$) to 57.1%.
 - Specific tasks showed significant gains: Observe-and-pick-up (from 2/10 to 7/10), Number-Guided Button Pressing (from 7/15 to 11/15), and Put-Back Block (from 0/10 to 2/10). These results validated the effectiveness of executable memory and steering on physical hardware for various memory requirements (cue retention, counting, source-location associations). Challenges remained in tasks where visuomotor policy robustness was affected by environmental factors (e.g., illumination variations in Put-Back Block).

#### 4.2. Demonstration Cost and Inspectability

The system demonstrated efficient use of demonstrations. All results were achieved with a single fine-tuned VLA checkpoint per platform. Memory acquisition did not require additional policy weight updates or demonstrations for new history-dependent task configurations. The symbolic state was readable at every control step, allowing localization of failures to specific components like memory updates, motor execution, or event verification.

#### 4.3. Qualitative Results

- **Memory-Guided Execution:** Visualizations on the SO-101 robot demonstrated that HyMeS effectively used stored memory (e.g., target color observed initially) to guide the VLA towards the correct object, resolving target ambiguity that a purely reactive policy could not address after the visual cue was removed.
- **Interpretable Failure Modes:** Analysis of failures showed that the symbolic memory and activated constraints were often correct. Failures primarily arose from motor execution issues (e.g., aiming deviations leading to missed grasps, jittering causing spurious presses) or stage-completion verification problems (e.g., shallow presses not being recognized as complete). This interpretability is a direct benefit of the explicit memory representation.

#### 4.4. Ablation Studies

Ablation studies on a six-task subset highlighted the contributions of two key components:

- **Rollout-Driven Heuristic Learning:** Replacing the one-shot initial program `P^(0)` with the rollout-refined program `P*` improved CSR by 8.5 points and TSR by 18.4 points. This validated the effectiveness of using rollout experience as feedback for learning memory-management heuristics.
- **Multimodal PACE:** Relying on either visual-only or proprioception-only completion signals degraded performance significantly. Vision-only verification reduced CSR by 16.0 points and TSR by 21.7 points compared to full HyMeS. Proprioception-only verification reduced CSR by 8.8 points and TSR by 8.4 points. This indicates that the complementary evidence from both proprioceptive and visual signals is crucial for robust and reliable stage transition verification.

### 5. Significance and Potential Impact

This research presents HyMeS, a hybrid learning framework that addresses a significant challenge in robot manipulation: enabling robust performance on memory-dependent, non-Markovian tasks using largely Markovian VLA policies. The significance and potential impact of this work include:

1. **Bridging the Gap in VLA Capabilities:** HyMeS provides a method to extend the capabilities of powerful, pre-trained VLA models to tasks requiring long-horizon reasoning and memory, a known limitation of current Markovian architectures. By leveraging existing motor competence while addressing memory externally, it enhances the applicability of these foundation models to more complex real-world scenarios.

2. **Data-Efficient Compositional Generalization:** A key contribution is the separation of motor-skill learning from memory-strategy learning. This approach reduces the data requirements for memory-dependent tasks, as demonstrations are only needed for reusable motor skills, not for every combinatorial variation of task memory. This data efficiency can accelerate the development and deployment of robots in diverse settings.

3. **Enhanced Interpretability and Diagnosability:** The use of an explicit, executable symbolic memory (code space) offers a significant advantage in terms of interpretability. Unlike opaque latent memory buffers in end-to-end models, the symbolic state in HyMeS is readable, allowing researchers and developers to directly inspect the robot's understanding of the task and diagnose memory-related failures. This transparency can streamline debugging and refinement processes.

4. **Robust Memory Management through Multimodal Verification:** The introduction of Proprioception-And-Completion-driven stagE-switching (PACE) demonstrates a practical approach to reliable memory updates. By combining proprioceptive and multi-frame visual evidence, PACE ensures that memory state transitions are grounded in actual physical execution, reducing the likelihood of erroneous updates that could derail long-horizon tasks.

5. **New Paradigm for Robot Learning:** HyMeS proposes a hybrid learning paradigm that combines gradient-based learning for low-level continuous control with heuristic learning in code space for high-level discrete logic. This demonstrates a viable strategy for integrating the strengths of neural networks with the advantages of symbolic reasoning, potentially inspiring future research into similar hybrid architectures for complex robotic tasks.

6. **Practical Real-World Applicability:** The successful deployment and validation of HyMeS on a real-world SO-101 robot underscore its practical potential. The demonstrated improvements in task success rates on physical hardware suggest that this framework could be directly applicable to various industrial and service robotics applications requiring memory, counting, or sequential execution.

Potential long-term impacts include the development of more autonomous and adaptable robotic systems capable of handling a broader range of complex, multi-stage tasks without constant human intervention or extensive task-specific retraining. The framework also opens avenues for future work, such as exploring hierarchical and multimodal memory representations to handle even more open-ended instructions and longer-horizon manipulation problems, and addressing remaining challenges related to motor competence and inference latency.
