# Adaptive Chain-of-Focus Reasoning via Dynamic Visual Search and Zooming for Efficient VLMs

> [!summary] Summary
> Researchers from Beijing Institute of Technology and BIGAI developed Adaptive Chain-of-Focus (Adaptive-CoF), a framework enabling Vision-Language Models to perform efficient multimodal reasoning by adaptively deciding when and where to zoom into image regions. This approach reduces unnecessary zoom-in operations by 75% and visual token consumption by 50% for equivalent accuracy, while establishing new state-of-the-art results on high-resolution and complex reasoning benchmarks.

## Problem

- Existing "think-with-image" Vision-Language Models (VLMs) incur substantial computational costs due to proactive and frequent visual zooming, leading to excessive token generation.
- Current methods struggle to balance the need for fine-grained visual detail, crucial for complex tasks, with the computational efficiency required for practical VLM deployment.
- Interactive VLMs often lack an adaptive mechanism to dynamically determine whether and where to focus attention on image regions based on the specific query and current context.

## Method

- An ==Adaptive Chain-of-Focus (Adaptive-CoF)== framework allows the VLM to iteratively refine visual understanding by selectively invoking "zoom-in" operations on key regions only when assessed as necessary.
- The model is trained using a ==two-stage pipeline==: initial Supervised Fine-tuning (SFT) on a custom MM-Adaptive-CoF dataset, which includes fine-grained reasoning trajectories.
- Reinforcement Learning (RL) with Group Relative Policy Optimization (GRPO) and a novel ==Adaptive Group-Aware Reward (AGAR)== is then applied to optimize the model for both accuracy and efficient, adaptive visual interaction.

## Results

- Adaptive-CoF achieved state-of-the-art performance on high-resolution benchmarks like V* Bench (**90.1**) and HR-Bench 4K, and the MME-RealWorld-Lite comprehensive reasoning benchmark, surpassing larger models.
- The framework demonstrated exceptional computational efficiency, reducing zoom-in operations by **75%** and visual token usage by **50%** to achieve comparable peak accuracy against existing baselines.
- Adaptive-CoF exhibited intelligent behavior by inversely correlating zoom-in operations with input image resolution, performing significantly fewer calls at higher resolutions when sufficient detail was already present.

## Takeaways

> [!tip] Key Insights
> - Vision-Language Models can be trained to adaptively allocate visual processing resources, dynamically deciding whether to zoom or respond, leading to substantial efficiency gains over proactive approaches.
> - A meticulously constructed dataset, incorporating diverse zoom-in requirements and step-by-step reasoning trajectories, is essential for effectively supervising and shaping adaptive visual search behaviors in VLMs.
> - The design of an adaptive, group-aware reward mechanism in reinforcement learning is crucial for guiding the model to balance accuracy with computational efficiency by explicitly penalizing superfluous visual explorations.
