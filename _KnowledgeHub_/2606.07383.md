# RhinoVLA Technical Report

> [!summary] Summary
> RhinoVLA is a Vision-Language-Action (VLA) model designed for real-time deployment on edge hardware, addressing computational bottlenecks and enabling cross-robot generalization. The system achieves an end-to-end inference frequency of 11.69 Hz on the Huixi R1 SoC, surpassing the 10 Hz real-time requirement, while maintaining competitive task performance with an average 90.0% success rate on the LIBERO benchmark.

## Problem

- Existing VLA models are computationally demanding, exceeding the capabilities of onboard edge hardware for real-time (10 Hz) closed-loop control.
- The number of visual and context tokens in VLM backbones (e.g., from MLP projection operators) is a significant bottleneck for inference latency on edge platforms.
- Integrating heterogeneous robot datasets with disparate camera layouts, sensing modalities, and action definitions makes learning a unified policy challenging for cross-robot generalization.

## Method

- Developed a token-efficient VLA architecture using a 2.13B Qwen3-VL backbone with 64 merged visual tokens and a 0.40B Action Expert to reduce computational load.
- Implemented algorithm-system co-design for the Huixi R1 edge SoC, incorporating hardware-aware compilation, mixed-precision (W8A16) execution, and parallel visual encoding.
- Introduced a cross-robot learning framework using a View Registry, a unified 72D physical state-action slot space with binary masks, and robot-instance LoRA modules for embodiment-specific adaptation.

## Results

- Achieved an end-to-end inference frequency of 11.69 Hz on the Huixi R1 SoC, demonstrating real-time capability and a 2x speedup over an unoptimized baseline.
- Demonstrated competitive task performance, with an average 90.0% success rate on the LIBERO benchmark (e.g., 82.4% on LIBERO-Long, outperforming "0 by 9.4 points) and effective real-robot performance on diverse tasks across three platforms.
- Confirmed the effectiveness of robot-instance LoRA modules in adapting to embodiment variations, showing consistent improvements in masked flow-matching loss and Mean Absolute Error for held-out action prediction.

## Takeaways

> [!tip] Key Insights
> - The count of visual and context tokens, rather than solely model size, is a critical bottleneck for achieving real-time inference speeds of VLA models on edge devices.
> - Algorithm-hardware co-design, including specialized compilation and mixed-precision techniques, is essential to translate theoretical hardware throughput into practical real-time performance for complex VLA models.
> - Low-Rank Adaptation (LoRA) modules can effectively provide robot-specific residual corrections for a shared Action Expert, enabling efficient cross-robot generalization and adaptation across diverse embodiments with a unified policy.
