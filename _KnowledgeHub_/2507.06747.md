# LOVON: Legged Open-Vocabulary Object Navigator

> [!summary] Summary
> LOVON is a framework enabling legged robots to perform long-horizon, open-vocabulary object navigation in complex environments by integrating LLM-based planning, open-vocabulary visual perception with motion blur filtering, and a Language-to-Motion Model. The system achieves high success rates in simulations and real-world scenarios while being adaptable across various robot platforms and significantly reducing training time.

## Problem

- Integrating high-level LLM planning with low-level perception and motion control remains challenging for legged robots performing complex, long-horizon tasks.
- Real-world robotic navigation faces issues such as visual instability (jittering, blur) caused by robot motion, temporary target occlusions, and difficulty grounding language instructions to robust robot actions in unstructured environments.
- Existing research often focuses on single robotic tasks or isolated components, lacking a unified system for robust, open-world, open-vocabulary object navigation by agile legged platforms.

## Method

- **LOVON** unifies an LLM-based ==Task Planner== for hierarchical decomposition of high-level instructions, an open-vocabulary visual detection model (YOLO-11) for object identification, and a Language-to-Motion Model (L2MM) for precise motion prediction and control.
- It incorporates a Laplacian Variance-Based Motion Blur Filtering technique to preprocess camera frames, improving detection reliability during robot locomotion by replacing blurred images with the last clear frame.
- A transformer-based L2MM predicts robot motion vectors and adaptive task states (mission and search states) based on multimodal inputs, guiding the robot through functional logic for task execution, object searching, and mission accomplishment.

## Results

- The Laplacian Variance-Based Motion Blur Filtering method, combined with a moving average filter, increased the qualified frame rate by **25%**, ensuring more stable visual input for object detection.
- LOVON achieved an average **1.00** Success Rate in Gym-Unreal simulations across diverse scenes (e.g., ParkingLot, UrbanCity, SnowVillage), matching state-of-the-art performance with significantly reduced training time (**1.5** hours vs. 360 hours for TrackVLA).
- Real-world experiments on Unitree Go2, B2, and H1-2 robots demonstrated successful open-world adaptation, multi-goal tracking, dynamic object following, and robustness to disturbances like object displacement or physical robot interference.

## Takeaways

> [!tip] Key Insights
> - Mitigating motion blur during legged robot locomotion is crucial for robust real-time open-vocabulary object detection, with Laplacian Variance Filtering improving the qualified frame rate significantly.
> - A specialized Language-to-Motion Model (L2MM) can effectively translate multimodal inputs (language instructions, visual detection, internal states) into precise robot control and adaptive state transitions for complex tasks.
> - Integrating hierarchical LLM planning with robust perception and a dedicated motion model enables legged robots to perform complex, long-horizon, multi-goal tasks in unstructured environments with enhanced autonomy.
