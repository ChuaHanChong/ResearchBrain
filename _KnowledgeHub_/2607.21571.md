# Beyond Episodic Evaluation: Memory Architectural Bottlenecks in Sequential Embodied Question Answering

> [!summary] Summary
> This research introduces Sequential-EQA, a diagnostic evaluation protocol for Embodied Question Answering (EQA) agents that assesses memory reuse across continuous queries, mirroring real-world operation. The study demonstrates that while simple memory persistence does not guarantee performance gains, structured 3D spatial memory leads to a simultaneous increase in answer accuracy by +33.3% and a decrease in navigation cost by +53.3% in simulation, a trend confirmed on a real robot.

## Problem

- Existing Embodied Question Answering (EQA) evaluations use an episodic formulation, resetting agent memory after each question, which is unrealistic for continuous real-world robot operation.
- Traditional EQA requires agents to re-explore environments for every new question, leading to computational inefficiency and redundant effort for long-horizon tasks.
- There is an implicit assumption that merely preserving an agent's memory state across tasks will uniformly improve efficiency and performance, without diagnosing the quality of memory reuse.

## Method

- The authors introduce **Sequential-EQA**, a novel ==evaluation protocol== where an agent's memory state persists and is carried forward across multiple consecutive questions within the same environment.
- They adapted four existing EQA agents, representing different memory paradigms (==lightweight geometric==, ==dense episodic semantic==, ==structured 3D spatial-semantic==, and ==implicit latent memory==), to this sequential setting without re-training.
- Performance is quantified using both task success (==Memory Advantage==) and navigation efficiency (==Step Advantage==) metrics, and findings are validated on a real-world quadruped robot.

## Results

- The 3D-Mem agent, which uses structured 3D spatial-semantic memory, achieved a **+33.3%** Memory Advantage in accuracy and a **+53.3%** Step Advantage in efficiency under sequential evaluation in simulation.
- Agents with lightweight geometric (ExploreEQA), dense episodic semantic (MemoryEQA), or implicit latent memory (UniNavid) showed minimal or inconsistent performance gains, with Memory Advantage (MA) typically below **3%**.
- Real-robot validation confirmed that structured spatial memory is critical, with 3D-Mem improving its success rate from **20%** (episodic) to **40%** (sequential), while less robust architectures struggled with physical noise and error.

## Takeaways

> [!tip] Key Insights
> - Simply preserving an agent's internal memory state across sequential queries does not uniformly lead to improved performance or effective knowledge accumulation.
> - Structured, spatially grounded 3D memory architectures are crucial for breaking the accuracy-efficiency trade-off, enabling simultaneous improvements in task success and navigational efficiency.
> - Architectural bottlenecks in existing episodic EQA agents, such as semantic interference or out-of-distribution degradation, become apparent and amplified in sequential settings, hindering effective knowledge reuse.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Embodied Question Answering (EQA) is an established field within artificial intelligence that requires an agent to perceive, reason, and interact within a physical environment to respond to natural language queries. Over recent years, significant advancements have been made in EQA benchmarks and systems, enabling agents to achieve performance across various visually grounded questions in complex scenes. These benchmarks typically focus on increasing dataset scale, improving question naturalness, and expanding environmental diversity.

However, a fundamental characteristic of most existing EQA evaluations is their "episodic formulation." In this traditional approach, each question is treated as an independent task, and the agent's internal state, including its memory, maps, and perceptual representations, is reset between episodes. This episodic paradigm, while simplifying evaluation, diverges from the operational requirements of real-world robots, which are expected to function continuously and reuse knowledge acquired from prior interactions to perform subsequent tasks efficiently.

Related work has begun to address aspects of continual learning and long-horizon tasks in embodied AI. Examples include benchmarks that introduce lifelong navigation memory or evaluate agents that reason and plan over extended active question-answering interactions. Memory architectures themselves have been extensively explored in embodied AI, utilizing representations such as semantic maps, voxel maps, scene graphs, and structured memory. These structures enable localization, object search, and reasoning within a single episode by integrating observations over time. However, the performance of these memory mechanisms under conditions where memory must persist across multiple, temporally linked queries remains an under-explored area.

This paper distinguishes itself by focusing on a diagnostic evaluation protocol for *existing* episodic EQA agents. Instead of developing a new method specifically designed for long-horizon operation, it examines how current memory architectures intrinsically support or hinder knowledge accumulation when simply transitioned from an episodic to a sequential evaluation paradigm without modifying their training procedures or model weights. The work specifically investigates whether these architectures encode environmental knowledge in a form that supports long-horizon reuse or if they primarily function as short-term navigation aids, thereby addressing a critical gap in understanding the reusability of learned knowledge in continuous embodied AI operation.

### 2. Key Objectives and Motivation

The primary objective of this research is to systematically investigate how different memory architectures behave when Embodied Question Answering (EQA) agents are evaluated sequentially. This involves assessing agents tasked with answering multiple questions consecutively within the same scene, with their internal memory state carried forward across queries.

The motivation for this investigation stems from several factors:

1. **Mismatch with Real-World Operation:** Real-world robotic systems, ranging from domestic assistants to industrial robots, operate continuously. They are required to accumulate, retain, and selectively reuse information obtained from past interactions to perform subsequent tasks efficiently. The traditional episodic evaluation paradigm in EQA, where an agent's internal state is reset after each question, is increasingly misaligned with this practical requirement.
2. **Inefficiency of Redundant Exploration:** In episodic EQA, agents must repeat intensive exploration, perception, localization, mapping, and navigation processes from scratch for every new question. This "re-exploration" is computationally expensive and time-consuming, becoming prohibitively inefficient as embodied agents move toward continuous, long-horizon operation. Maintaining persistent memory is identified as an unavoidable necessity to overcome this redundancy.
3. **Unchallenged Assumptions about Memory Reuse:** There is an implicit assumption in current systems that merely preserving an agent’s memory "on" across tasks will uniformly improve efficiency without degrading decision quality. This research challenges this assumption, seeking to understand if and how different memory structures actually support beneficial knowledge transfer.
4. **Identification of Architectural Bottlenecks:** The authors aim to identify critical architectural bottlenecks that prevent existing EQA agents from effectively reusing memory in sequential settings. This involves diagnosing failure modes that arise when agents, originally trained for short-horizon episodic tasks, are exposed to continuous, multi-query histories.
5. **Necessity of Structured Memory:** The research is motivated by the hypothesis that simple memory preservation is often insufficient. It seeks to highlight the necessity of structured, spatially grounded memory architectures that can effectively map persistent visual observations onto metric 3D geometry to preserve visual-semantic evidence in a coherent scene representation.
6. **Bridging Simulation and Reality:** A further motivation is to validate findings in simulated environments on real-world mobile robots. This step is crucial to demonstrate that identified architectural bottlenecks generalize beyond idealized simulations and are critical for enabling continuous, intelligent operation in physical environments, which inherently involve sensing and actuation noise.

In essence, the paper seeks to move EQA evaluation beyond isolated tasks to a more realistic continuous operating paradigm, diagnosing the effectiveness of various memory architectures under these conditions and identifying the properties necessary for robust knowledge accumulation and reuse.

### 3. Methodology and Approach

To address their objectives, the authors introduce a novel evaluation protocol called **Sequential-EQA** and apply it to existing EQA agents. Their approach is designed to isolate the contribution of memory architecture rather than task-specific training for sequential operation.

#### 3.1. A. Sequential-EQA Evaluation Protocol

The core of the methodology is a redefinition of the EQA task from an episodic to a sequential formulation:

- **Problem Formulation:**
 - **Episodic Evaluation (Standard):** For each question `q_i` in a set `Q` within an environment `E`, the agent's memory `m` is re-initialized to a null state (`m_0 = ∅`). The trajectory `τ_i` is generated based on `q_i` and `m_0`. This prevents knowledge transfer between questions.
 - **Sequential Evaluation (Proposed):** Memory is accumulated across `Q`. The memory `m_i` at the terminal state of `q_i` becomes the initial state `m_{0,i+1}` for the subsequent question `q_{i+1}`. This allows the agent to leverage accumulated environmental context.

- **Sequentializing an Existing Benchmark:**
 - The authors convert widely used EQA benchmarks, specifically OpenEQA, into a sequential setting. This is done by grouping all questions from the same environment `E_k` into an ordered sequence `S_k`.
 - The order of questions within a sequence is randomly shuffled once with a fixed seed and remains constant for all evaluations. The length of these sequences varies by scene.

- **Evaluation Metrics:** The efficacy of memory retention is quantified using both task success and navigational efficiency metrics:
 - **Accuracy Metrics:**
 - **Success Rate (SR):** Mean accuracy under episodic resets.
 - **Success Rate with Memory (SR_mem):** Mean accuracy under state persistence.
 - **Memory Advantage (MA):** Absolute performance gain: `SR_mem - SR`.
 - **Efficiency Metrics:**
 - **Path Length (PL):** Total navigation cost without memory reuse.
 - **Path Length with Memory (PL_mem):** Total cost when leveraging prior exploration.
 - **Step Advantage (SA):** Normalized efficiency gain: `((PL - PL_mem) / PL) * 100%`.

#### 3.2. B. Memory Representation Paradigms and Evaluated Agents

The authors select four representative EQA agents that embody different memory mechanisms, spanning VLM-agent and VLA (Vision-Language-Action) paradigms. These agents were originally designed for episodic evaluation, and are adapted without re-training to investigate their intrinsic memory properties.

1.  **ExploreEQA:** A VLM-agent utilizing **lightweight geometric memory**. It maintains a 2D occupancy map of traversable space and frontier scores. Memory primarily encodes where the agent has been, not rich semantic observations.
2.  **MemoryEQA:** A VLM-agent with **dense episodic semantic memory**. It builds an explicit semantic library, binding RGB frames, spatial poses, natural language descriptions, and feature embeddings. Entries are stored as independent pose-tagged events rather than a fused global structure.
3.  **3D-Mem:** A VLM-agent with **structured 3D spatial-semantic memory**. It constructs a persistent metric 3D reconstruction of the environment, fusing visual embeddings directly to 3D coordinates. This creates a spatially consistent representation for both layout and objects.
4.  **UniNavid:** A VLA agent with **implicit latent memory**. This end-to-end model fine-tunes a transformer-based VLM to predict navigation waypoints from a short window of sequential RGB frames and a query. Memory is implicit in the model's attention state, limited by its short training horizon.

#### 3.3. C. Memory Adaptation Protocol

A crucial aspect of the methodology is the "minimal persistence protocol" applied to transition agents from episodic to sequential evaluation:

- **No Model Modification:** Agent model weights and training procedures remain strictly unchanged.
- **State Inheritance:** The agent's terminal memory state from the `i`-th query is directly carried forward as the initial state for the `(i+1)`-th query within the same scene, without truncation or summarization.
- **Query Update:** Only the task-specific natural language input is replaced for the next query, and any goal-directed planners are re-initialized accordingly.
This protocol ensures that any observed performance differences are solely attributable to the architecture and structure of the inherited memory representation, rather than to any learned sequential behaviors or re-calibration.

#### 3.4. D. Experimental Setup

- **Dataset:** OpenEQA is used, regrouped by scene to form sequential queries. The distribution of questions per scene is analyzed, showing a majority of scenes with 10-13 questions.
- **Foundation Model:** Qwen3 VL 8B-Instruct VLM with FB8 quantization.
- **Compute Resources:** Experiments are run on A5000 GPUs.

#### 3.5. E. Real-Robot Validation

To confirm the generalizability of simulation findings, the authors deployed a **Unitree Go2 quadruped robot** equipped with an Intel RealSense D435i depth camera and onboard LiDAR L2.
- **Environments:** Experiments were conducted in diverse physical indoor (lab space, lobby, hallway) and outdoor (rooftop terrace) settings.
- **Trials:** Each environment involved five questions, with both episodic and sequential trials conducted. The robot started at the same location for each query, but sequential trials preserved state across the five questions.

### 4. Main Findings and Results

The experiments conducted under the Sequential-EQA protocol, both in simulation and on a real robot, revealed distinct behaviors of different memory architectures.

#### 4.1. A. Sequential Memory Does Not Uniformly Improve Performance

A central finding is that simply preserving internal state across sequential queries does not guarantee successful environmental knowledge accumulation or consistent performance improvement.

- **Accuracy and Efficiency Trade-off:**
    - **Limited Memory Advantage (MA) for most agents:** ExploreEQA, UniNavid, and MemoryEQA showed minimal Memory Advantage (MA < 3%).
        - **ExploreEQA** retains geometric traversability but lacks object-level semantic evidence, meaning it remembers visited areas but not *what* was observed.
        - **UniNavid**, trained episodically on short horizons, experiences out-of-distribution degradation when exposed to continuous, multi-query histories. Its inherited recurrent context does not form a reusable scene representation.
        - **MemoryEQA** stores rich semantic information (RGB frames, poses, descriptions) but as independent, pose-tagged events rather than a globally aligned scene structure. This increases retrieval noise as history accumulates.
    - **Breaking the Trade-off with 3D-Mem:** In contrast, **3D-Mem** significantly improved both answer accuracy and navigation efficiency, demonstrating a +33.3% MA and +53.3% SA. This indicates that by anchoring observations to metric 3D geometry, the agent's past exploration enriches a coherent scene representation, leading to more correct answers with less navigation.
- **Joint Efficiency vs. Accuracy Visualization (Figure 3):** This visualization confirmed that only 3D-Mem moved towards the desirable region of higher accuracy and lower navigation cost. Other methods either maintained similar accuracy with reduced navigation (due to premature stopping or biases towards familiar regions) or showed inconsistent changes.
- **Key Takeaways:**
    - Persistence ≠ Accumulation: Merely retaining state does not ensure knowledge accumulation.
    - Spatial Grounding is Critical: Only spatially grounded memory (3D-Mem) yielded simultaneous gains in accuracy and efficiency.
    - Decoupling of Efficiency and Success: Shorter paths for other agents did not necessarily mean better reasoning, often indicating premature termination in familiar but information-lacking regions.
    - Structured Memory for Cross-query Accumulation: Geometrically structuring observations allowed 3D-Mem's representation to become more useful over subsequent queries.

#### 4.2. B. Dynamics Across Query Position

Analysis of performance metrics by query position (`i`) within a sequence (Figure 4) provided further insights:

- **Navigation Time:** All methods generally exhibited a decrease in navigation time under memory reuse as sequences progressed. This suggests that even weak memory can reduce repeated exploration or bias agents towards familiar areas.
- **Accuracy:** Unlike navigation time, accuracy revealed a clearer distinction.
 - ExploreEQA, UniNavid, and MemoryEQA showed no stable improvement in accuracy across query positions. Gains and losses alternated, indicating their retained state did not consistently improve scene understanding.
 - Only 3D-Mem demonstrated sustained positive accuracy changes across query positions, consistent with a representation that becomes more complete and useful over time.

#### 4.3. C. Qualitative Analysis

Qualitative examples (Figure 5) illustrated the behavioral differences:

- **3D-Mem Example:** In an episodic setting, 3D-Mem re-explored large portions of an apartment for each of three questions, answering only 1 of 3 correctly. In the sequential setting, with persistent 3D memory, the agent navigated directly to previously observed regions. Path length significantly dropped, and all three questions were answered correctly, demonstrating that prior exploration provided a spatially consistent record for retrieval.
- **UniNavid Example:** On another scene, UniNavid showed minimal changes in navigation efficiency between episodic and sequential settings, despite some accuracy improvements, highlighting its limited ability to leverage sequential context for efficient path planning.

#### 4.4. D. Real-Robot Validation

The real-world deployment on a Unitree Go2 quadruped robot (Figure 6) confirmed the simulation trends:

- **UniNavid:** Achieved low accuracy (15%) in both episodic and sequential settings across environments, exhibiting erratic rotation and failing to leverage prior knowledge. This reinforced that its implicit memory struggle with sequential context generalizes to physical conditions.
- **3D-Mem:** Maintained its strong performance, improving its success rate from 20% (episodic) to 40% (sequential).
- **MemoryEQA:** Showed an improvement from 40% to 47% accuracy with memory.
- **ExploreEQA:** Experienced a slight decrease from 33% to 26%, which the authors suggest might be due to the small test size.

These results indicated that physical sensing noise and actuation error amplify the weaknesses of less robust memory architectures, making structured spatial memory critical for deployable continuous EQA agents.

### 5. Significance and Potential Impact

This research carries several significant implications and potential impacts on the field of embodied AI and robotics:

1. **Introduction of a Novel Evaluation Protocol:** The development of Sequential-EQA provides a diagnostic evaluation protocol that shifts the focus from isolated, episodic tasks to continuous, multi-query operations. This more closely mirrors real-world robotic deployment, offering a framework for assessing agents' memory reuse efficacy without requiring modifications to underlying models or environments. This protocol can serve as a new standard for benchmarking memory capabilities in embodied agents.
2. **Identification of Critical Architectural Bottlenecks:** The work empirically identifies and characterizes a critical architectural gap: memory persistence does not automatically translate to effective knowledge accumulation. It demonstrates that existing memory structures, while effective in episodic settings, can suffer from semantic interference, out-of-distribution degradation, or lack of spatial grounding when simply "left on" in sequential contexts. This understanding is crucial for guiding future architectural design.
3. **Emphasis on Structured, Spatially Grounded Memory:** The research provides strong evidence for the necessity of structured 3D spatial memory. It shows that architectures which anchor visual-semantic evidence to metric 3D geometry effectively break the accuracy-efficiency tradeoff in sequential settings, simultaneously achieving higher answer accuracy and lower navigation costs. This finding suggests a fundamental direction for developing more capable continuous embodied agents.
4. **Guidance for Future Research and Development:** By exposing hidden failure modes in memory reuse, the paper motivates the development of new memory architectures that are intrinsically designed for compositional knowledge accumulation across queries. Future work can focus on how to build more robust, generalizable, and scalable spatial memory structures, rather than solely increasing memory capacity or relying on short-horizon training.
5. **Bridging the Simulation-to-Reality Gap:** The validation of findings on a real mobile robot confirms that the identified bottlenecks are not mere simulation artifacts. This strengthens the applicability of the research to physical robotics, emphasizing that robust spatial memory is critical for enabling continuous, intelligent operation under realistic sensing and actuation noise in physical environments.
6. **Enabling Lifelong Embodied Assistants:** Ultimately, resolving the memory-efficiency bottleneck identified in this work is positioned as a key factor for unlocking truly continuous, lifelong embodied assistants. Such agents would be capable of operating reliably in human environments over extended periods (days or weeks), moving beyond the current limitation of isolated, minutes-long episodes, and thereby enhancing the utility and autonomy of future robotic systems.
