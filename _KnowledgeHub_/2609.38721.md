# UniEvo-VL: An On-policy Self-Distillation Training Recipe for Multimodal Model Self-improvement

> [!summary] Summary
> UniEvo-VL is a self-evolving training recipe for unified multimodal image generators. The model critiques its own drafts, rewrites the prompt to fix detected errors, then distills an EMA teacher conditioned on that revised prompt into a student seeing only the original prompt, matching flow velocities along the student's own denoising trajectories. On Qwen-Image-2512 it lifts GenEval from 0.747 to 0.818.

## Problem

- Prior self-improving unified models select self-generated outputs for fine-tuning or preference optimization, or recast interactions into captioning and judgment tasks, without distilling corrections into denoising predictions.
- Reflection-tuning methods use explicit critiques to refine images only at inference time, so the original-prompt generator never internalizes the corrective guidance it repeatedly receives.
- A textual critique such as 'restore the missing object' states the desired fix but not how intermediate denoising predictions should change, while reward-based optimizers compress feedback into scalars.

## Method

- ==Critique-conditioned privileged prompts==: the understanding mode critiques each draft along semantic, text and quality axes, then synthesizes a revised prompt explicitly addressing the detected discrepancies.
- Post-revision verification: regenerate from the revised prompt with the same noise, and keep the training triple only if the critic accepts the new image against the original prompt.
- ==On-policy self-distillation== via ==transition matching==: an ==EMA teacher== conditioned on the revised prompt supplies velocity targets on student-sampled latents, with an ==MSE loss== on the six noisiest steps that updates generator ==LoRA==.

## Results

- The verified variant raises direct generation from **0.748 to 0.818** on GenEval, **31.92 to 35.07** on GenEval2 Soft-TIFA, and **0.769 to 0.790** on OCR.
- With one reflection pass, the evolved model still beats the reflected base model: **0.848 vs 0.826** on GenEval and **46.23 vs 42.52** on GenEval2, so the gains go beyond inference-time revision.
- A stronger GPT-5.6-Luna critic reaches **0.882** on GenEval. Gains concentrate on hard prompts (**+67 points** on the GenEval hard subset), while easy prompts regress by **1-4 points**.

## Takeaways

> [!tip] Key Insights
> - Conditioning a same-model teacher on textual critique turns it into dense per-step supervision, with no need for paired target images, differentiable rewards or scalar-reward policy gradients.
> - The critic caps how far self-evolution can go: stronger judges give larger but skill-dependent gains, and position and attribute binding barely improve under either critic.
> - Training only on corrected failures focuses gains on hard cases but erodes easy ones, so self-improvement loops need explicit protection for behavior that is already correct.

## Detailed Report

### 1. Overview

A text-to-image prompt asks for **two green suitcases to the left of a blue giraffe**. In one matched example, the base model draws one green suitcase. The trained model, generating directly from the same request, draws two, alongside the giraffe. This is a single illustrative example, not proof of general success. The underlying bottleneck is practical. A text-to-image model may recognize that a draft violates a request, yet fail to turn that diagnosis into better denoising decisions when it sees only the original prompt. UniEvo-VL aims to bridge that gap by transferring corrective information into the direct-generation policy.

### 2. From critique to training signal

The model first generates a draft from the original prompt $p$. A fixed multimodal critic then checks the image against $p$. Its critique covers semantic constraints, counts and relations, requested text, and visual quality, and it returns accept or revise. The method discards invalid or unusable critiques, and an accepted draft yields no corrective pair. For a draft that needs revision, the method writes a standalone revised prompt $\tilde{p}$ that restates the request along with its corrections.

In the verified variant, the model regenerates from $\tilde{p}$ with the same seed. The pair is kept only if the critic accepts that new image against the original prompt. The regenerated image filters the data. It is not a training target.

Training is **on-policy**: it follows the intermediate denoising states that the current student actually visits. The student runs under $p$. At those same latent states, its predictions are compared with those of an EMA teacher conditioned on $\tilde{p}$. The revised prompt is therefore **privileged information**: the teacher sees it, but the student does not. The loss is a squared-error match between deterministic latent transitions. The method updates only the student generator LoRA and keeps the teacher targets detached.

The proposed UniEvo-VL training loop, not a measured result. The kitten images are explanatory examples. Only the generator LoRA is updated, and the critic stays fixed. Deployment uses the original prompt directly.

The closest contrast is [ReflectionFlow](https://www.alphaxiv.org/abs/2504.16080). It trains a corrector on flawed-image/reflection/improved-image triplets and uses it for iterative inference-time refinement. UniEvo-VL instead distills revised-prompt conditioning into direct generation from the original request, without using a corrected image as the distillation target.

### 3. What the paired comparison shows

The key test asks two things: whether training improves direct generation, and whether it replaces the benefit of reflection. The evaluated checkpoints were trained with post-revision verification, and all outputs are scored against the original request. Official GenEval is the unweighted mean of six detector-based category accuracies. It is an automated score, not a human judgment.

On this metric, direct generation rises from **0.748** for the base model to **0.818** after training. With one inference-time reflection, the base reaches **0.826** and the trained model **0.848**. Training therefore nearly matches, but does not reach, the reflected base model in direct generation. Training plus reflection scores highest. Reflection still improves the trained model, so training and inference-time correction are complementary rather than substitutes.

Verification has a cost. Only about 10–21% of acquisition attempts are accepted, roughly five to ten attempts per accepted pair. Each attempt adds a regeneration and another critique. The paper reports optimizer updates, not a fixed compute budget.

### 4. A correction becomes capability

The teacher uses the corrective language to shape predictions at states the student actually visits. The direct-generation gain shows that some of that benefit remains once the student returns to the original prompt. This is a focused demonstration on Qwen-Image-2512, not evidence that multimodal models generally self-improve across tasks or architectures.
