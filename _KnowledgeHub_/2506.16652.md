# CodeDiffuser: Attention-Enhanced Diffusion Policy via VLM-Generated Code for Instruction Ambiguity

> [!summary] Summary
> CodeDiffuser, developed by researchers from Columbia University, Toyota Research Institute, and others, introduces a modular framework for robotic manipulation that addresses natural language ambiguity. It leverages Vision-Language Models to generate interpretable code for 3D attention map creation, which then guides a diffusion-based visuomotor policy, achieving high success rates on complex tasks in both simulation and the real world.

## Problem

- Robotic manipulation systems struggle to interpret and execute tasks from ambiguous natural language instructions due to a lack of modularity in end-to-end models.
- Existing language-conditioned imitation learning policies often fail to fully leverage rich semantic information from language and vision, leading to poor generalization in multi-modal scenarios.
- Bridging abstract high-level task specifications with precise low-level robot control remains a challenge, particularly in complex, contact-rich manipulation tasks.

## Method

- A modular framework, **CodeDiffuser**, is proposed that decomposes the problem into VLM-based code generation, ==3D attention map== computation using perception APIs and Visual Foundation Models, and a low-level visuomotor policy.
- Vision-Language Models (e.g., ChatGPT-4o) generate executable Python code from natural language instructions and visual observations, directing a set of perception APIs to identify task-relevant objects and regions.
- Custom 3D attention map generation APIs leverage ==Visual Foundation Models (DINOv2, SAM)== to fuse multi-view observations and create precise 3D attention maps, which condition a ==Denoising Diffusion Probabilistic Model== for continuous trajectory generation.

## Results

- CodeDiffuser achieved an **86.5%** total success rate in simulation and an **80%** total success rate in real-world experiments on ambiguous manipulation tasks, significantly outperforming language-conditioned baselines (e.g., **5.5%** for Lang-DP (PCD)).
- The VLM-generated code successfully produced accurate 3D attention maps aligning with complex and ambiguous instructions, achieving **97%** success on 'Hang Mug' and **94%** on 'Pack Battery' tasks in simulation.
- The attention-conditioned diffusion policy maintained high success rates (**>90%**) even as task ambiguity increased, demonstrating improved data efficiency and generalization with approximately **120** demonstrations.

## Takeaways

> [!tip] Key Insights
> - End-to-end imitation learning models struggle significantly with natural language ambiguity, and simply scaling demonstration data does not effectively resolve this limitation.
> - A modular framework that explicitly resolves language ambiguity via VLM-generated code and 3D attention maps can substantially improve visuomotor policy performance and robustness to varying degrees of instruction specificity.
> - The 3D attention map serves as an effective intermediate representation, successfully bridging high-level semantic reasoning from VLMs with low-level continuous action generation by a diffusion policy.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of robotic manipulation is rapidly advancing, largely driven by progress in deep learning and large foundation models. However, a significant challenge remains: interpreting and executing tasks from ambiguous natural language instructions. Current state-of-the-art methods, primarily language-conditioned imitation learning (IL) policies, often struggle with this ambiguity because they employ end-to-end models. These models are tasked with simultaneously handling high-level semantic understanding (e.g., "which mug?") and low-level action generation (e.g., "how to grasp and place it"), leading to a lack of modularity, interpretability, and suboptimal performance, especially when instructions are vague.

This paper directly addresses this critical limitation by introducing a novel modular framework. It positions itself against several existing paradigms:

- **End-to-End Imitation Learning:** Methods like Action Chunking Transformer (ACT) and Diffusion Policy (DP) have shown impressive results in dexterous manipulation. However, the paper demonstrates that their performance degrades significantly with increased language ambiguity, and simply scaling data doesn't resolve this. CodeDiffuser proposes to augment these low-level policies with a pre-processing step that resolves ambiguity.
- **Foundational Vision Models (VFMs) for Robotics:** Models like DINOv2 and Segment Anything Model (SAM) have demonstrated powerful zero-shot generalization for 2D vision tasks. Robotic systems increasingly leverage these for perception (e.g., GenDP, 3D Diffuser Actor). CodeDiffuser integrates these VFMs into its perception pipeline, but crucially, it uses VLM-generated code to *condition* their application to specific task-relevant regions, going beyond generic object detection or feature extraction. This is a key differentiator from methods like GenDP, which focus on category-level generalization without nuanced language understanding, or 3D Diffuser Actor, which uses 3D features but requires manual keypose definitions and may lack continuous trajectory control.
- **Code Generation for Robotics:** The use of Large Language Models (LLMs) and Vision-Language Models (VLMs) to generate code for robotics (e.g., VoxPoser, ReKep) has gained traction for high-level planning and zero-shot performance. These methods typically rely on motion planning or optimization for trajectory generation. CodeDiffuser builds on this by using VLM-generated code as an *interpretable and executable intermediate representation* for perception, but critically, it then feeds this structured perceptual information into a *learned visuomotor policy* from human demonstrations. This hybrid approach aims to combine the semantic reasoning of VLMs with the smooth, learned control capabilities of IL, which is an advantage over purely code-generated or optimization-based approaches that may struggle with complex, contact-rich dynamics (e.g., stowing books).

In essence, CodeDiffuser's unique contribution lies in its modular decomposition. Instead of an end-to-end model trying to understand high-level semantics and generate low-level actions simultaneously, it introduces an explicit intermediate representation – the 3D attention map – generated by VLM-controlled perception APIs. This map effectively resolves language ambiguity by highlighting task-relevant regions, thereby simplifying the task for the downstream low-level policy. This modularity enhances interpretability, robustness, and the ability to handle a broader range of ambiguous instructions and complex manipulation tasks.

### 2. Key Objectives and Motivation

The primary objective of this research is to enable robotic manipulation systems to robustly accomplish tasks specified by natural language instructions, even when those instructions exhibit ambiguity or vagueness. The authors identify several key motivations for this work:

- **Addressing Language Ambiguity:** Natural language, while intuitive for human-robot interaction, is inherently ambiguous. Instructions like "Hang a mug on a branch" offer multiple valid choices if several mugs or branches are present. Existing end-to-end language-conditioned policies struggle with this multi-modality, leading to low success rates. CodeDiffuser aims to provide a systematic solution to resolve this ambiguity.
- **Improving Modularity and Interpretability:** Current end-to-end imitation learning models, by jointly handling high-level semantic understanding and low-level action generation, often lack modularity and interpretability. This makes debugging difficult and limits their adaptability to variations. The authors are motivated to introduce a framework with clear interfaces between semantic reasoning and action generation.
- **Enhancing Semantic Understanding:** Existing imitation learning methods often fail to fully leverage the rich semantic information available in language and vision. The motivation is to integrate powerful Vision-Language Models (VLMs) into the robot's pipeline to perform deeper semantic reasoning and effectively interpret abstract concepts within instructions.
- **Bridging High-Level Reasoning and Low-Level Control:** There's a persistent challenge in robotics to effectively bridge abstract, high-level task specifications with precise, low-level robot control. The paper is motivated to create an "interpretable and executable interface" (VLM-generated code) that can translate human-like reasoning into actionable information for visuomotor policies.
- **Tackling Challenging Manipulation Tasks:** The authors aim for a system capable of handling not just simple pick-and-place, but also more complex scenarios involving contact-rich manipulation (e.g., stowing books) and multi-object interactions, where language ambiguity can compound the difficulty.
- **Overcoming Data Scarcity Limitations:** The paper investigates whether simply increasing demonstration data can resolve ambiguity for existing methods and finds it often does not. This motivates their architectural change, suggesting that a more structured approach is needed to effectively learn from demonstrations in ambiguous settings.

In essence, the core motivation is to move beyond the limitations of monolithic end-to-end policies by introducing a modular, VLM-driven framework that explicitly resolves instruction ambiguity through an interpretable intermediate representation, thereby enabling more robust and generalizable robotic manipulation.

### 3. Methodology and Approach

CodeDiffuser proposes a novel modular robotic manipulation framework designed to handle ambiguous natural language instructions. It systematically decomposes the problem into three main components: VLM-based code generation, 3D attention map computation, and a low-level visuomotor policy.

**A. Problem Statement and Decomposition:**
The learning goal is framed as matching action distributions `p(a|o_t, l)` (actions given observations and language instructions). The authors observe that in the presence of language ambiguity, this distribution becomes highly multi-modal (e.g., 18 possible battery-slot pairs). They propose to decompose this distribution using a task-relevant latent representation `z_t`, specifically a 3D attention map: `p(a|o_t, l) = ∫ p(a|z=z_t)p(z=z_t|o_t, l) dz_t`. Here, `p(a|z=z_t)` is modeled by a low-level visuomotor policy, and `p(z=z_t|o_t, l)` is handled by a VLM generating code.

**B. Code Generation using Vision-Language Models (VLMs):**
- **Role:** The VLM (e.g., ChatGPT-4o) acts as the high-level semantic interpreter. It translates a natural language instruction and visual observations into executable Python code.
- **Mechanism:** The VLM is prompted with a few in-context examples of how to use a predefined set of "perception APIs" to generate 3D attention maps. At inference time, it receives new instructions and observations and generates corresponding code.
- **Semantic and Spatial Reasoning:** The generated code can perform advanced reasoning. For instance, if an instruction is "Hang the blue mug on the left branch," the code can first detect all mugs, then use another VLM call (via `sel_name`) to identify the "blue mug," and finally use spatial reasoning functions (via `sel_pos`) to pinpoint the "left branch." This modularity allows for complex, multi-step interpretation.

**C. API for 3D Attention Map Generation (interfacing with Visual Foundation Models - VFMs):**
The VLM-generated code interacts with a set of custom-designed perception APIs that bridge semantic meaning with 3D observations. These APIs leverage powerful VFMs:
- **`detect(object_name)`:**
 - Takes multi-view RGBD observations and an object category name.
 - Uses DINOv2 to extract 2D semantic feature maps from each view.
 - Fuses these 2D features and depth information into a 3D point cloud (`P`) with associated 3D semantic features (`F`). This often follows approaches like D3Fields.
 - Compares these 3D features to a pre-annotated "reference DINOv2 feature" for the object category to compute similarity scores for each point.
 - Clusters points belonging to the same object category into distinct "object instances" using DBSCAN based on similarity and density. Each cluster centroid represents an instance.
- **`sel_pos(object_list, spatial_relation)`:**
 - Selects a target instance from a list of detected objects based on spatial relations (e.g., "far away," "close to," "left").
 - This function itself can involve an internal VLM call to generate code that computes distances or compares coordinates to identify the spatially relevant instance.
- **`sel_name(object_list, semantic_attribute)`:**
 - Selects a target instance based on semantic attributes (e.g., "Bob's mug," "blue mug").
 - Project the 3D object instances onto 2D images, overlay bounding boxes, and feed this composite image to a VLM (e.g., GPT-4o) for instance selection.
 - Once a specific object instance (or instances) is selected by the VLM-generated code, Segment Anything Model (SAM) is prompted using the projected 2D bounding boxes.
 - The 2D segmentations from multiple views are fused into 3D space to generate a 3D attention map (`I`). This binary map highlights points belonging to the task-relevant object instances.
- **Output:** The combined state representation `z` for the downstream policy is the concatenated 3D point cloud (`P`) and the 3D attention map (`I`).

**D. Visuomotor Policy Learning:**
- **Model:** The low-level policy is modeled as a Denoising Diffusion Probabilistic Model (DDPM), similar to Diffusion Policy.
- **Input:** Instead of raw RGB observations, the policy is conditioned on the combined state representation `z = (P, I)`, where `P` is the 3D point cloud and `I` is the 3D attention map. This allows the policy to leverage both general scene geometry and task-specific attention.
- **Architecture:** PointNet++ is used to process the point cloud inputs, with an added residual connection to effectively propagate attention information.
- **Output:** The policy predicts a sequence of 6D end-effector poses (continuous trajectory) to complete the task.
- **Training:** The policy is trained using human demonstrations collected via teleoperation (real-world) or scripted policies (simulation). A lightweight annotation process generates ground-truth 3D attention maps for training.

In summary, CodeDiffuser decouples high-level semantic understanding from low-level control. VLMs provide reasoning capabilities to interpret ambiguous instructions and generate perception code. This code then directs VFMs to produce precise 3D attention maps, which in turn guide a learned diffusion-based policy for robust, continuous trajectory generation.

### 4. Main Findings and Results

The experiments conducted in both simulation (SAPIEN) and real-world (ALOHA system) settings provide strong evidence for the effectiveness of CodeDiffuser.

**A. Analysis of Existing Imitation Learning Algorithms (Section IV-B):**
- **Limitations with Ambiguity:** State-of-the-art imitation learning methods (ACT, Diffusion Policy with RGB and Point Cloud inputs) show significant performance degradation as task ambiguity (number of picking/placing options) increases. For example, in the "Pack Battery" task, success rates for DP (PCD) dropped from 96% in a 1x1 scenario to 33% in a 4x12 scenario.
- **Failure Patterns:** Failures primarily occurred at the stage with the highest ambiguity (e.g., picking failures with more picking options, placing failures with more placing options).
- **Data Scaling Insufficiency:** Simply increasing the number of demonstrations (from 30 to 540 episodes) did not effectively resolve the ambiguity issue; performance often plateaued at low success rates, indicating that architectural changes are necessary.

**B. Evaluation of 3D Attention Maps (Section IV-C):**
- **Alignment with Instructions:** The VLM-generated code successfully produced accurate 3D attention maps that aligned with human instructions, even for complex or ambiguous commands (e.g., "Hang a mug on a branch" or instructions with self-correction like "Hang the red mug... Sorry, the green mug."). This demonstrates the VLM's ability to interpret nuanced language and ground it visually.
- **Quantitative Success:** A quantitative benchmark in simulation showed high success rates (97/100 for Hang Mug, 94/100 for Pack Battery) for the language-to-3D attention pipeline, indicating effective attention to task-relevant areas.
- **Baseline Comparison (G-SAM2):** Direct prompting of Grounded-SAM2 (even with GPT-4o selection) failed to achieve any success (0/100), highlighting that CodeDiffuser's pipeline effectively leverages VLM's reasoning and 3D representations for fine-grained semantic and spatial understanding that simpler baselines lack.

**C. Evaluation of Attention-Conditioned Diffusion Policy (Section IV-D):**
- **Data Efficiency with Attention:** The attention-conditioned policy achieved high success rates (>90%) with approximately 120 demonstrations, indicating that the 3D attention map is an effective representation for guiding the visuomotor policy.
- **Robustness to Ambiguity:** The policy's performance remained consistently high even as task ambiguity (number of picking and placing options) increased, demonstrating that the 3D attention map effectively resolves ambiguity for the low-level policy.
- **Improved Generalization:** The 3D attention module significantly improved the policy's ability to generalize to unseen scenarios with higher ambiguity (e.g., trained on 1x2 options, generalized well to 1x3 and 1x4 options), as the attention mechanism directs the policy's focus to relevant visual regions.

**D. Evaluation of the Entire System (Section IV-E):**
- **Simulation Performance:**
 - CodeDiffuser significantly outperformed language-conditioned baselines (Lang-DP, Lang-ACT) on "Hang Mug" and "Pack Battery" tasks. For instance, CodeDiffuser achieved 86.5% total success rate compared to 5.5% for Lang-DP (PCD) and 6% for Lang-ACT, demonstrating the substantial benefit of the VLM-generated code and 3D attention.
 - The 3D attention mechanism also improved the performance of other base imitation learning algorithms when integrated (e.g., Lang-ACT with 3D Attention to 61% vs. Lang-ACT's 6%).
 - 2D attention (as an ablation) also showed strong performance (84.5% total), but 3D attention was preferred for real-world robustness.
 - A residual connection in PointNet++ was shown to be important, improving performance from 61% (without residual) to 86.5% (with residual).
- **Real-World Performance:**
 - CodeDiffuser consistently outperformed baselines (Lang-DP (RGB), Lang-DP (Colored PCD)) on real-world tasks (Hang Mug, Pack Battery, Stow Book).
 - Achieved 80% total success rate compared to 15% and 6.7% for baselines, demonstrating its practical effectiveness on challenging, contact-rich manipulation tasks.
- **Qualitative Results:** Visual examples show CodeDiffuser effectively interprets varying degrees of instruction specificity (from ambiguous "Put a battery on a slot" to precise "Put the rightmost battery...") and executes tasks accordingly.
- **Failure Analysis:** The majority of failures (65-80%) occurred during task execution (e.g., placing failure, picking failure), while code generation and perception modules remained relatively stable and highly successful (e.g., 95% success for code generation for stowing book). This suggests that the VLM-driven perception pipeline is robust, and future work can focus on refining the low-level policy and recovery mechanisms.

### 5. Significance and Potential Impact

CodeDiffuser presents a significant advancement in robotic manipulation, particularly for tasks involving human-robot interaction via natural language. Its key significance lies in:

- **Robustness to Language Ambiguity:** By explicitly addressing and resolving ambiguity through an interpretable, VLM-generated code-to-attention pipeline, the system dramatically improves task success rates compared to conventional end-to-end imitation learning methods. This is crucial for real-world deployment where instructions are rarely perfectly unambiguous.
- **Enhanced Interpretability and Modularity:** The modular design, separating high-level semantic understanding from low-level motor control, offers greater interpretability. Researchers can inspect the generated code and 3D attention maps to understand the robot's "thought process" and pinpoint failure points, a significant advantage over opaque end-to-end models. This modularity also makes the system more adaptable and amenable to updates.
- **Leveraging Foundational Models Effectively:** CodeDiffuser intelligently combines the power of large Vision-Language Models (VLMs) for semantic reasoning with Visual Foundation Models (VFMs) like DINOv2 and SAM for robust perception. It demonstrates a novel way to orchestrate these powerful models to produce actionable information for robot control, going beyond simple feature extraction.
- **Applicability to Complex Tasks:** The demonstrated success on challenging tasks involving contact-rich manipulation (e.g., stowing books) and multi-object interactions highlights the system's potential for real-world scenarios in manufacturing, logistics, or service robotics, where such complexities are common.
- **Guidance for Future Research:** The systematic evaluation of existing imitation learning methods and the detailed failure analysis provide valuable insights for the robotics community. The finding that more data alone doesn't solve ambiguity issues, and that a robust perception pipeline can stabilize the overall system, points to fruitful directions for future research.

**Potential Impact:**
- **More Intuitive Human-Robot Interaction:** Enabling robots to understand and act upon ambiguous natural language makes them more user-friendly and accessible, reducing the need for precise, engineered commands.
- **Generalizable Robot Skills:** The ability to handle varying task specifications and unseen scenarios through the attention mechanism contributes to more generalizable robotic skills, reducing the need for extensive retraining for minor task variations.
- **Industrial Automation:** Tasks like "pack battery" and "stow books" are highly relevant to warehouse automation and manufacturing. CodeDiffuser's robustness in these settings could accelerate adoption in such industries.
- **Future Embodied AI:** This work contributes to the broader goal of embodied AI, where intelligent agents can reason about and interact with the physical world based on high-level human instructions.

**Limitations and Future Directions (as identified by authors):**
- **Dependency on VLMs and VFMs:** The system's performance is bounded by the capabilities of the underlying VLMs and VFMs. Future advancements in these foundational models will directly benefit CodeDiffuser.
- **Object-Level Perception API:** The current perception APIs operate at an object level, making it challenging to generalize to instructions involving deformable objects (e.g., "grab the top of the circle of dough"). Extending the API to handle deformable objects or fine-grained part manipulation is a clear future direction.
- **Annotation Process:** The lightweight manual annotation for reference DINOv2 features, while feasible for current scales, could become a bottleneck for very large-scale training datasets. Simplifying or automating this annotation process is a promising area for future work to scale the method.

In conclusion, CodeDiffuser represents a significant step towards more intelligent and adaptable robotic systems, offering a compelling solution to a long-standing challenge in robot learning and human-robot interaction.
