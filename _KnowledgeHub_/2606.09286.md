# VAIC: Vision-Guided Humanoid Agile Object Interaction Control via Decoupled Commands

> [!summary] Summary
> The VAIC framework enables humanoid robots to perform agile object interactions using onboard depth vision and proprioception, guided by decoupled high-level commands. It infers unobservable object dynamics and adapts to severe visual occlusion, achieving up to 91.7% success rates in diverse simulated interaction tasks and demonstrating generalization on physical hardware.

## Problem

- Current humanoid controllers often rely on dense, joint-level reference trajectories, which are impractical for real-world autonomy or high-level teleoperation.
- Existing methods assume perfect state observability of objects and environment, which is unattainable in physical deployments due to visual occlusion, sensor noise, and blind spots.
- A "deployment gap" persists, making it challenging to transfer simulated humanoid capabilities to physical robots for complex object interaction tasks.

## Method

- Developed **VAIC**, a two-stage distillation framework that trains a privileged teacher and then a vision-guided student policy.
- Introduced a decoupled command interface (velocity targets and binary interaction phase indicators) to provide high-level user intent without requiring dense reference motions.
- Implemented a recurrent Object Adaptation module that implicitly infers dynamic object states from onboard depth streams, proprioception, and decoupled commands, even under severe visual occlusion.

## Results

- VAIC achieved success rates of **66.7%** for box carrying, **91.7%** for cart interaction, and **83.3%** for skateboard interaction in simulation, consistently outperforming existing baselines.
- The framework demonstrated robustness to variations in object sizes, interaction distances, and initializations, and successfully generalized to unseen dynamics and out-of-distribution commands on real hardware.
- Mechanism analysis revealed the Object Adaptation module accurately tracks object states under severe occlusion, with the binary interaction phase being crucial for preventing temporal drift during dynamic transitions.

## Takeaways

> [!tip] Key Insights
> - Decoupling high-level user intent from low-level interaction execution via simple commands effectively bridges the gap between ideal simulation and robust physical deployment.
> - Implicitly inferring unobservable object dynamics and environmental states from noisy onboard perception and proprioception is critical for adaptive, whole-body interaction.
> - A two-stage distillation approach with an asymmetrically conditioned student policy allows learning complex interaction skills without relying on dense reference trajectories or perfect state knowledge during deployment.
