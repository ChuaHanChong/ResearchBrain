# Searching in Space and Time: Unified Memory-Action Loops for Open-World Object Retrieval

> [!summary] Summary
> STAR (SpatioTemporal Active Retrieval) is an AI-powered framework that enables service robots to retrieve objects in dynamic, open-world environments using natural language instructions that involve appearance, spatial, and temporal attributes. It achieves higher success rates in various object search tasks by integrating memory queries and embodied actions within a unified decision-making loop, and demonstrates transferability to a physical robot.

## Problem

- Service robots struggle with open-world object retrieval in dynamic environments where objects are frequently moved, requiring continuous adaptation and understanding of natural language spatio-temporal queries.
- Existing methods for object search often focus on either spatial or temporal aspects, lacking a unified approach to jointly reason about past observations and current environmental interactions.
- A lack of benchmarks exists for evaluating active spatio-temporal object search in dynamic environments, hindering the development of robots that can learn and adapt over long periods.

## Method

- Introduces **STAR**, a framework using an LLM-based policy that unifies memory retrieval (searching in time via a non-parametric long-term memory) and embodied actions (searching in space via environmental interaction) within a single decision loop.
- Develops a non-parametric long-term memory that stores timestamped, posed, and semantically embedded observations, enabling efficient multimodal querying (semantic, temporal, spatial).
- Employs a working memory updated by action-outcome trajectories, providing context for the LLM policy to select between temporal (memory query) and spatial (robot skill) actions.

## Results

- STAR achieved higher execution success rates across all five task families in Visible Object Search, demonstrating particular advantages in attribute-based and spatio-temporal tasks compared to scene-graph and temporal-retrieval-only baselines.
- In Interactive Object Search, STAR showed improved success rates (e.g., 0.67 for class-based tasks in Oracle mode) by leveraging temporal recall and visual context to guide complex interactions with hidden objects.
- The framework successfully transferred to a physical Tiago robot, exhibiting robust performance in a real-world mock apartment environment and outperforming baselines in several task types.

## Takeaways

> [!tip] Key Insights
> - Unifying memory access and physical interaction allows robots to strategically leverage historical information to resolve ambiguous queries and actively probe the environment for fresh perceptual evidence.
> - An LLM-based policy can effectively manage a unified action space, deciding whether to query past observations or execute physical actions based on task instructions and accumulated working memory.
> - Dynamic, open-world environments necessitate benchmarks that capture long-term environmental changes and require active spatio-temporal reasoning, rather than relying on static scenes or passive reasoning.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The research addresses the problem of open-world object retrieval for service robots operating in dynamic environments. This problem sits at the intersection of several subfields within robotics and artificial intelligence, including object search, embodied agents, long-term memory, and vision-language models.

Existing approaches to object search and robot navigation often focus on either spatial or temporal aspects, but rarely integrate both in a flexible, open-world manner:
- **Object Search and Scene Representations:** Early methods for object navigation utilized geometric reasoning, while later approaches incorporated semantic representations like scene graphs or learned priors. More recent work has explored dynamically updating representations of predefined or open-vocabulary objects. However, these methods typically assume that critical information resides in the current scene state and do not effectively handle retrospective queries about past object states.
- **Interactive Object Search:** This area focuses on robots using manipulation actions (e.g., opening cabinets) to find occluded objects. While involving interaction, these systems often rely on predefined object vocabularies or representations updated only to reflect the current state, lacking historical context.
- **Temporal Reasoning:** Approaches from areas like video retrieval and grounded temporal reasoning model dynamics, but often operate in passive reasoning contexts or lack integration with embodied interaction. Dynamic scene graphs represent both space and time, but have generally been applied in closed-world settings with fixed vocabularies.
- **Benchmarks:** Previous benchmarks for object search often assume static environments or evaluate passive reasoning over recorded data, rather than requiring active reasoning about dynamic changes over time.
- **LLM Agents for Robotics:** Large Language Models (LLMs) and Vision-Language Models (VLMs) have enabled advancements in robot planning and control by leveraging common-sense reasoning. These systems facilitate plan-execute-check loops by coupling reasoning with perception and control. However, they frequently operate over the current scene and within short temporal contexts, limiting their ability to reason about long-term environmental changes or historical observations.
- **Memory and Scene Representations:** Robotics research uses various memory structures. Parametric representations like scene graphs capture the current world state but typically overwrite past information. Long-term semantic mapping aims for persistent object-level maps, but primarily emphasizes the current belief rather than retaining accessible histories of past states. Non-parametric approaches store raw observations for retrieval, but memory often functions as an external module consulted prior to action, rather than being an integrated component of the active decision-making loop.

This paper positions STAR as a unified approach that bridges these gaps by integrating spatial and temporal search capabilities within an active decision-making framework. It aims to overcome the limitations of prior work by enabling open-world, natural language-guided object retrieval in dynamic environments, where robots must reason about both the current state and historical information, and actively interact with the environment.

### 2. Key Objectives and Motivation

The primary objective of this research is to enable service mobile robots to retrieve objects in complex, dynamic, open-world environments, where retrieval requests can involve combinations of open-vocabulary appearance attributes, spatial context, and temporal properties.

The motivation for this work stems from several challenges inherent in this problem domain:
- **Open-world object references:** Robots cannot know in advance all possible objects they might be asked to retrieve, necessitating a system that does not rely on pre-programmed knowledge of every potential target. This implies a need for open-vocabulary understanding and generalizability.
- **Dynamic environments:** Objects in human-populated environments are frequently moved. A robot might have observed an object at a specific location previously, but it may no longer be there. This requires the robot to account for the possibility of environmental change and historical data becoming stale.
- **Embodied interaction:** Retrieving an object often requires physical interaction with the environment, such as opening drawers or manipulating other objects that occlude the target. The robot must be capable of executing these actions as part of its search strategy.
- **Joint spatio-temporal reasoning:** The core challenge identified is that solving this problem requires the robot to reason jointly about *space* (where an object is, how to reach it, how to manipulate its surroundings) and *time* (when it was last observed, its typical locations, and how it might have moved). Existing methods tend to compartmentalize these aspects, focusing on one or the other.
- **Unifying memory and action:** The paper argues for the necessity of treating memory queries (searching in time) and physical actions (searching in space) as integral components of a single decision-making process. This unification is motivated by the need for an active agent that can strategically retrieve information from its past experiences and probe its current environment to resolve ambiguous or challenging retrieval requests.

To address these motivations, the paper outlines three specific contributions:
1. **Proposing STAR:** A framework designed to unify search in time (memory retrieval) and search in space (embodied actions) for open-world object retrieval.
2. **Introducing STARBench:** A benchmark specifically created for spatiotemporal object search tasks in dynamic household environments, filling a perceived gap in existing evaluation methods.
3. **Demonstrating Performance:** To show that STAR can outperform existing scene-graph and temporal-search-only baselines across various task types within STARBench, and to demonstrate its transferability to a physical robot.

### 3. Methodology and Approach

STAR (SpatioTemporal Active Retrieval) is presented as a unified framework that integrates memory queries and embodied actions within a single decision-making loop. Its design enables a robot to retrieve objects based on spatio-temporal natural language instructions in dynamic, open-world settings.

The core of STAR's methodology is an LLM-based policy that operates on a unified action space, deciding whether to perform a temporal action (querying long-term memory) or a spatial action (interacting with the current environment).

**A. System Overview**
STAR is structured around two types of memory:
1. **Long-Term Memory (M):** A non-parametric, efficiently searchable storage of past observations. This memory is built asynchronously before a retrieval task, as the robot patrols its environment, collecting observations over time.
2. **Working Memory (H):** A task-relevant, dynamically updated memory that serves as the context for the LLM policy.

The LLM policy uses the working memory and the task instruction to select actions, the outcomes of which further update the working memory, creating an iterative decision loop.

**B. Non-Parametric Long-Term Memory (M)**
The long-term memory stores past observations (m_t = (t, x_t, embed(o_t), o_t)) in a vector database, enabling efficient retrieval. Each record includes:
- **Timestamp (t):** Discrete time step of the observation.
- **Robot Pose (x_t):** Spatial location of the robot when the observation was made.
- **Semantic Embedding (embed(o_t)):** A vector representation derived from a language caption of the visual observation (o_t).
- **Raw Visual Observation (o_t):** The original egocentric camera observation.

This structure allows for multimodal querying via multiple indices:
- **Semantic index:** For text-based queries, using caption embeddings.
- **Temporal index:** For queries related to specific times or temporal sequences.
- **Spatial index:** For queries about objects observed around particular locations.
The memory is designed to be task-agnostic during construction, capturing a broad history that can be later queried for specific tasks.

**C. Working Memory Update with Spatio-temporal Actions**
The working memory (H_k) is an action-outcome trajectory that summarizes the robot's progress on the current task. It is initialized with the user's natural language instruction (ℓ) and updated incrementally.
The LLM policy selects an action (a_k = (f, θ)_k), which consists of a tool (f) and its arguments (θ). The action is then executed, and its outcome (y_k) is appended to the working memory.

The unified action space encompasses two main categories of tools:
- **Temporal Actions (Search in Time):** These tools query the long-term memory (M).
 - **Examples:** `SemanticQuery(text_description)`, `TemporalQuery(time_interval)`, `SpatialQuery(location)`.
 - **Mechanism:** The LLM policy outputs text arguments (θ) for these tools. Internally, these arguments are converted into vector representations (e.g., language embeddings for semantic queries). These vectors are then used to compute similarities against the respective indices in M to retrieve the top-r matching memory records. These retrieved records (y_k) provide historical context.
- **Spatial Actions (Search in Space):** These tools enable the robot to act and perceive in the current environment.
 - **Examples:** `Navigate(target_pose)`, `Detect(object_class)`, `Pick(object_id)`, `Open(receptacle_id)`.
 - **Mechanism:** The LLM policy outputs parameters (θ) for these robot skills. Upon execution, the robot receives perception feedback (e.g., raw sensor data, object detections, success/failure signals) from the environment, which constitutes the outcome (y_k). This allows the agent to acquire fresh perceptual evidence and validate hypotheses about the current world state.

The working memory is updated by concatenating the executed action and its outcome: H_k+1 = H_k ⊕ (a_k, y_k).

**D. Action Selection with Working Memory**
The LLM policy (π(a | ℓ, H_k, R_k)) selects the next action based on the instruction (ℓ), the current working memory (H_k), and the remaining action budget (R_k). The budget helps the policy prioritize actions, favoring less exploratory options when the budget is low. The loop continues until the object is retrieved or the budget is exhausted. The specific LLM used for experiments is GPT-o3.

**E. STARBench Benchmark**
To evaluate STAR, a new benchmark called STARBench was developed, leveraging the VirtualHome simulator (Unity3D). Key characteristics of STARBench include:
- **Dynamic Environments:** Unlike many existing benchmarks, STARBench features environments that evolve over time due to simulated exogenous factors (e.g., human activity changing object locations), necessitating spatio-temporal reasoning.
- **Long-Term Data Collection:** Agents patrol the environment for 3-6 simulated days, collecting 1200-1500 observations (with associated captions and poses) daily, which forms the basis for long-term memory.
- **Task Types:**
 - **Visible Object Search:** Target objects are directly observable (though possibly in a new location).
 - **Interactive Object Search:** Requires manipulation (e.g., opening receptacles) to find hidden objects.
 - **Commonsense Object Search:** Requires reasoning about likely object locations even if never observed before.
- **Task Families (for Visible and Interactive):**
 - **Class-based:** "Find a book."
 - **Attribute-based:** "Find the red mug."
 - **Spatial:** "Find the mug on the table."
 - **Spatial-Temporal:** "Find the book that was on the desk yesterday."
 - **Spatial-Frequentist:** "Find the mug that is usually by the sink."
- **Environmental Knowledge Modes:**
 - **Oracle mode:** Agents have access to ground-truth object class labels and relationships for memory construction and scene graphs.
 - **Realistic mode:** Agents rely on predictions from state-of-the-art perception models, reflecting real-world conditions.
- **Baselines:** Performance is compared against a random agent, a scene-graph-based agent (SG+S), and a temporal-retrieval-only agent (TR+S).

**F. Real-World Evaluation**
STAR was also deployed on a Tiago robot in a mock apartment environment to assess its transferability and performance in a physical setting, using 9 tasks per type.

### 4. Main Findings and Results

The experimental evaluation aimed to assess STAR's ability to reason jointly over object attributes, space, and time, retrieve hidden objects through interaction, efficiently utilize physical actions, leverage common sense, and transfer to real-world scenarios.

**A. Joint Spatio-temporal Reasoning (Visible Object Search)**
- **Overall Performance:** STAR consistently demonstrated higher execution success rates across all five task families (Class-based, Attribute-based, Spatial, Spatial-Temporal, Spatial-Frequentist) in the Visible Object Search category compared to baseline approaches (Random, SG+S, TR+S).
- **Complementary Strengths:** While TR+S performed better on tasks requiring temporal recall (e.g., Spatial-Temporal, Spatial-Frequentist) and SG+S showed advantages in class-based and spatial reasoning, STAR combined these benefits effectively.
- **Pronounced Advantages:** STAR's performance advantage was particularly evident in attribute-based and spatiotemporal tasks, where reasoning about both object properties and past states was necessary to identify the target object.
- **Active Perceptual Evidence Gathering:** An analysis of action distribution revealed that STAR executed a higher proportion of physical actions (navigation, detection) compared to TR+S. This indicates STAR's strategic use of active environmental probing to update potentially stale memory information and acquire fresh perceptual evidence when temporal recall was insufficient or uncertain, contributing to its improved success.

**B. Retrieval of Hidden Objects (Interactive Object Search)**
- **Success in Interaction:** In interactive object search tasks (requiring actions like opening receptacles), STAR achieved higher success rates across all task families compared to TR+S. For instance, in Oracle mode, STAR showed a success rate of 0.67 for class-based tasks compared to TR+S's 0.56, and similar improvements across other families.
- **Disambiguation:** The paper reported that temporal recall and visual context enabled STAR to correctly identify and open the target receptacle, a task where baselines struggled due to the need for long action chains or the presence of similar, nearby receptacles. This suggests STAR's ability to leverage historical knowledge to guide complex interactions.

**C. Efficiency of Physical Actions**
- **Physical Action Count:** STAR, on average, utilized approximately 1.5 to 2 times the minimal (optimal) number of physical actions required for successful retrieval in both Visible and Interactive Object Search tasks. For example, in Visible tasks, STAR's total physical actions were around 4.74-4.93 compared to an optimal 3. In Interactive tasks, STAR's total physical actions were 8.16-8.27 compared to an optimal 5. This indicates a trade-off between robustness/success and efficiency in terms of physical robot movements.

**D. Commonsense Reasoning (Commonsense Object Search)**
- **Locating Unobserved Objects:** For tasks where the target object had never been observed in memory, STAR demonstrated the ability to locate it by employing common sense reasoning about likely object placements. STAR achieved a success rate of 0.57 in both Oracle and Realistic modes, significantly outperforming TR+S (0.19-0.43) and SG+S (0.10).

**E. Real-World Deployment**
- **Robustness on Tiago Robot:** In evaluations on a physical Tiago robot in a mock apartment, STAR showed robust performance, successfully locating objects in the real environment. It surpassed TR+S in several task types (e.g., Class-based, Attribute-based, Spatial, Spatial-Frequentist) and performed consistently well across all. The Random baseline failed almost entirely. This indicates the practical applicability and transferability of the STAR framework beyond simulation.

### 5. Significance and Potential Impact

The development of STAR and STARBench contributes to the field of embodied AI and robotics in several ways, with potential implications for future robotic systems.

**A. Addressing a Critical Gap:**
The work addresses a significant challenge in robotics: enabling open-world object retrieval in dynamic environments with instructions incorporating both spatial and temporal references. This represents a more realistic scenario for service robots than static or closed-world settings and extends the capabilities of current embodied agents.

**B. Unified Spatio-Temporal Reasoning:**
STAR's core contribution is its unified treatment of memory queries (searching in time) and embodied actions (searching in space) within a single decision loop. This integration allows robots to strategically leverage historical information, adapt to environmental changes, and actively gather new evidence. This approach offers a framework for more intelligent and adaptive robot behavior in complex, unstructured settings.

**C. Novel Benchmark for Dynamic Environments:**
The introduction of STARBench fills a gap in existing evaluation tools. By providing a benchmark for spatiotemporal interactive object search in dynamic household environments, it enables systematic evaluation and comparison of methods designed for persistent, evolving robotic tasks. This can accelerate research in areas like long-term autonomy and dynamic scene understanding.

**D. Enhanced Robot Capabilities:**
The demonstrated performance of STAR, particularly in handling attribute-based, spatiotemporal, and interactive tasks where baselines struggle, suggests that this framework can lead to more capable service robots. Its ability to find hidden objects by reasoning about past states and to locate unobserved items through common sense inference indicates a step towards more versatile and intelligent robotic assistants.

**E. Practical Real-World Applicability:**
The successful transfer of STAR to a physical Tiago robot in a mock apartment demonstrates the framework's practical feasibility beyond simulation. This suggests its potential for deployment in real-world applications where robots need to operate effectively over extended periods in changing human environments.

**F. Future Research Directions:**
The work also points to promising future research avenues, such as developing strategies for efficient memory management (e.g., forgetting or compressing less relevant information) and policy abstraction to distill high-level primitives, which could further improve the scalability and efficiency of such systems. This suggests a roadmap for continued advancement in robust, long-term embodied intelligence.
