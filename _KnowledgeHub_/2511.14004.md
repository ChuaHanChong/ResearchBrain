# Searching in Space and Time: Unified Memory-Action Loops for Open-World Object Retrieval

> [!summary] Summary
> STAR (SpatioTemporal Active Retrieval) is an AI-powered framework that enables service robots to retrieve objects in dynamic, open-world environments using natural language instructions that involve appearance, spatial, and temporal attributes. It achieves higher success rates in various object search tasks by integrating memory queries and embodied actions within a unified decision-making loop, and demonstrates transferability to a physical robot.

## Problem

- Service robots struggle with open-world object retrieval in dynamic environments where objects are frequently moved, requiring continuous adaptation and understanding of natural language spatio-temporal queries.
- Existing methods for object search often focus on either spatial or temporal aspects, lacking a unified approach to jointly reason about past observations and current environmental interactions.
- A lack of benchmarks exists for evaluating active spatio-temporal object search in dynamic environments, hindering the development of robots that can learn and adapt over long periods.

## Method

- Introduces **STAR**, a framework using an LLM-based policy that unifies memory retrieval (searching in time via a non-parametric long-term memory) and embodied actions (searching in space via environmental interaction) within a single decision loop.
- Develops a non-parametric long-term memory that stores timestamped, posed, and semantically embedded observations, enabling efficient multimodal querying (semantic, temporal, spatial).
- Employs a working memory updated by action-outcome trajectories, providing context for the LLM policy to select between temporal (memory query) and spatial (robot skill) actions.

## Results

- STAR achieved higher execution success rates across all five task families in Visible Object Search, demonstrating particular advantages in attribute-based and spatio-temporal tasks compared to scene-graph and temporal-retrieval-only baselines.
- In Interactive Object Search, STAR showed improved success rates (e.g., 0.67 for class-based tasks in Oracle mode) by leveraging temporal recall and visual context to guide complex interactions with hidden objects.
- The framework successfully transferred to a physical Tiago robot, exhibiting robust performance in a real-world mock apartment environment and outperforming baselines in several task types.

## Takeaways

> [!tip] Key Insights
> - Unifying memory access and physical interaction allows robots to strategically leverage historical information to resolve ambiguous queries and actively probe the environment for fresh perceptual evidence.
> - An LLM-based policy can effectively manage a unified action space, deciding whether to query past observations or execute physical actions based on task instructions and accumulated working memory.
> - Dynamic, open-world environments necessitate benchmarks that capture long-term environmental changes and require active spatio-temporal reasoning, rather than relying on static scenes or passive reasoning.
