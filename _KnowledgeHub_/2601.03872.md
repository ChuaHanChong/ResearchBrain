# Atlas: Orchestrating Heterogeneous Models and Tools for Multi-Domain Complex Reasoning

> [!summary] Summary
> ATLAS introduces a dual-path framework to dynamically orchestrate diverse large language models and external tools, enabling superior complex reasoning across multiple domains. This system achieved an average accuracy of 63.5% on in-distribution tasks, outperforming RouterDC by 10.1%, and demonstrated robust generalization on out-of-distribution tasks with a 13.1% improvement over baselines through learned model-tool synergies.

## Problem

- Existing LLM tool usage relies on rigid, pre-configured invocation logic, limiting adaptability to diverse tasks and model capabilities.
- Current LLM routing methods select models in isolation, overlooking the performance benefits from synergistic integration with external tools.
- Reinforcement Learning applications for LLMs often optimize individual components rather than jointly leveraging the combined strengths of multiple models and tools.

## Method

- Developed ATLAS, a ==dual-path framework== balancing efficiency for domain-specific tasks with generalization for open-domain reasoning.
- Implemented a ==training-free cluster-based routing mechanism== for known domains, which uses query embeddings and empirical statistics to select optimal model-tool pairs.
- Introduced an ==RL-driven multi-step routing approach== for open-domain scenarios, modeling reasoning as a sequential decision task with an augmented action space and optimizing policy using PPO with a composite reward function.

## Results

- Achieved an average accuracy of **63.5%** on in-distribution tasks, surpassing the strongest baseline, RouterDC, by **10.1%**.
- Demonstrated robust generalization on out-of-distribution tasks, with ATLAS(RL) reaching an average accuracy of **59.4%**, which was **13.1%** higher than RouterDC.
- Attained an average accuracy of **68.9%** across five multi-modal datasets, outperforming the strongest single-tool baseline by **4.3%**, by effectively integrating multi-modal tools.

## Takeaways

> [!tip] Key Insights
> - Strategic orchestration of heterogeneous LLMs and external tools can enable smaller open-source models to rival or exceed larger proprietary systems in complex reasoning.
> - A dual-path architecture, combining cluster-based routing for efficiency in known domains and RL-driven routing for generalization in open domains, is effective.
> - Reinforcement learning can teach transferable collaborative decision principles for model and tool selection, leading to robust performance on out-of-distribution tasks.
