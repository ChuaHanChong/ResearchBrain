# RLinf: Flexible and Efficient Large-scale Reinforcement Learning via Macro-to-Micro Flow Transformation

> [!summary] Summary
> RLinf, developed by researchers from Tsinghua University, Infinigence AI, and other institutions, presents a system for large-scale reinforcement learning using a Macro-to-Micro Flow Transformation (M2Flow) paradigm. It decouples logical workflow programming from physical execution to dynamically optimize resource utilization and execution modes, achieving substantial speedups in complex RL tasks involving LLMs and embodied agents.

## Problem

- Modern RL training systems struggle with the inherent heterogeneity and dynamicity of workflows involving diverse components like LLM generation, inference, and training.
- Existing fixed execution modes (collocated or disaggregated) lead to low hardware utilization due to 'long-tail problems' and resource imbalances.
- Current systems lack flexibility, requiring extensive manual tuning or significant code changes to adapt to varying workloads, increasing programming complexity and hindering optimal training speed.

## Method

- **RLinf** introduces Macro-to-Micro Flow Transformation (M2Flow), which separates high-level logical workflow programming from fine-grained physical execution planning.
- It employs a 'Worker' abstraction with adaptive communication, elastic pipelining for spatial scheduling, and automatic context switching for temporal scheduling.
- A profiling-guided scheduler automatically determines optimal execution plans by evaluating temporal, spatial, and hybrid scheduling policies based on estimated execution time and memory usage.

## Results

- RLinf achieved **1.10x** to **1.58x** speedup for Reasoning RL (Qwen2.5-GRPO) and **38.7%** to **69.6%** speedup for PPO compared to veRL, a state-of-the-art baseline.
- For Embodied RL, RLinf-Hybrid showed 52.2–**69.1%** higher throughput on ManiSkill, and RLinf-Temporal was **37.8%** to **143.4%** faster than SimpleVLA-RL on LIBERO tasks.
- The profiling-guided scheduler accurately estimates performance (errors below **5%**) and efficiently finds optimal plans (within 7x10^-4 to 5.98 seconds), demonstrating its effectiveness in adapting to diverse workloads.
- Models trained with RLinf demonstrated improved performance, including up to 20 points higher on math reasoning benchmarks for Qwen2.5 models and increased success rates for OpenVLA on embodied tasks.

## Takeaways

> [!tip] Key Insights
> - Decoupling logical workflow from physical execution provides a flexible and efficient way to orchestrate diverse and dynamic RL components.
> - Dynamically adapting between temporal, spatial, and hybrid execution modes is crucial for maximizing hardware utilization and training throughput across heterogeneous RL workloads.
> - An efficient, profiling-guided search policy can effectively navigate complex scheduling spaces to identify optimal resource allocation and execution strategies without manual intervention.
