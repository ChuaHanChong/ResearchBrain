# Light-Weight Vision Transformer with Parallel Local and Global Self-Attention

> [!summary] Summary
> This paper introduces Light-Weight PLG-ViT, an efficient vision transformer architecture designed for resource-constrained hardware. It achieves competitive accuracy on vision benchmarks while significantly reducing computational requirements, making ViTs viable for deployment on edge devices in applications such as autonomous driving.

## Problem

- Vision Transformers (ViTs) possess high computational intensity, including large parameter counts and memory requirements.
- The significant floating-point operations (FLOPs) and latency of standard ViTs limit their deployment on resource-constrained edge devices.
- Real-time applications, such as autonomous driving, are impractical with conventional ViTs due to their computational demands.

## Method

- Introduced ==Light-Weight PLG-ViT==, an efficient vision transformer architecture based on the ==Parallel Local-Global Vision Transformer (PLG-ViT)==.
- Implemented strategic modifications including optimized downsampling using strided convolutions, an enhanced global attention branch, and careful balancing of model width and depth.
- Developed an optimized ==Feed-Forward Network (CCF-FFN+)== incorporating SiLU activation, Gated Residual Networks, and a reduced expansion factor to improve efficiency.

## Results

- Achieved **79.5%** top-1 accuracy on ImageNet with LW PLG-ViT-A (**5M parameters**) and **77.8%** with LW PLG-ViT-R, maintaining competitive performance for their size.
- Reduced parameters by a factor of **5** compared to the original PLG-ViT, requiring **25-**40%** fewer** operations than comparable models for typical input sizes.
- Demonstrated robust object detection performance across diverse autonomous driving datasets (BDD100k, GERALD, SVIRO, NuScenes), confirming real-time viability on edge hardware.

## Takeaways

> [!tip] Key Insights
> - Strategic architectural modifications, including optimized downsampling and an enhanced FFN design, enable significant reduction in computational cost while preserving accuracy.
> - Light-Weight PLG-ViT variants exhibit favorable computational complexity scaling with increasing input dimensions compared to other vision models.
> - Careful balancing of model width and depth, combined with adjusted regularization, can effectively reduce parameters for efficient ViT deployment on edge devices.

## Detailed Report

### 1. Introduction

Vision Transformers (ViTs) have demonstrated impressive performance across various computer vision tasks, potentially surpassing traditional Convolutional Neural Networks (CNNs). However, their computational intensity limits deployment on resource-constrained hardware, particularly in time-sensitive applications like autonomous driving.

This paper introduces Light-Weight PLG-ViT, an efficient vision transformer architecture that maintains high accuracy while significantly reducing computational requirements. The design makes vision transformers viable for deployment on edge devices and embedded systems.

### 2. Background and Motivation

Vision Transformers have revolutionized computer vision by applying self-attention mechanisms to process visual data. Unlike CNNs that use localized convolution operations, ViTs divide images into patches and apply global attention across all patches, enabling them to capture long-range dependencies.

However, this global attention mechanism comes at a high computational cost, making standard ViTs impractical for edge devices with limited resources. Key challenges include:

1. High parameter count and memory requirements
2. Significant floating-point operations (FLOPs)
3. Latency issues for real-time applications

Several lightweight ViT variants have emerged to address these issues, including MobileViT and EdgeViT, which often combine CNN and transformer components. The PLG-ViT (Parallel Local-Global Vision Transformer) provides a promising foundation by separating attention into parallel local and global paths, but further optimization is needed for deployment on highly constrained hardware.

### 3. PLG-ViT Architecture

The PLG-ViT architecture employs a hierarchical design with four stages of decreasing spatial resolution and increasing channel dimensions. Its distinctive feature is the Parallel Local-Global Self-Attention (PLG-SA) mechanism that processes information through two parallel paths:

1. **Local Window-based Multi-Head Self-Attention (Window-MHSA)**: Processes patches within local windows, preserving spatial information
2. **Global Multi-Head Self-Attention (Global-MHSA)**: Captures long-range dependencies by processing downsampled representations of the entire feature map

The model processes input images through:

1. A CNN stem that extracts initial features
2. Four transformer stages with decreasing spatial dimensions
3. Lightweight downsampling modules between stages
4. Transformer blocks containing PLG-SA and feed-forward networks (FFN)

### 4. Lightweight Design Strategy

To create Light-Weight PLG-ViT variants, the authors implemented several strategic modifications to the original architecture:

1. **Optimized Downsampling**: Replaced the original downsampling operation with a lightweight alternative using strided convolutions, reducing parameter count while maintaining information flow.

2. **Enhanced Global Branch**: Removed the average pooling operation in the global attention path and used direct max pooling, preserving more discriminative features.

3. **Parameter Reduction**: Carefully balanced the model's width (channels) and depth (layers) to minimize parameters while maintaining performance.

4. **Regularization Adjustments**: Removed dropout layers since the reduced parameter count already provides implicit regularization against overfitting.

These modifications resulted in two variants:

- **LW PLG-ViT-A**: Optimized for accuracy, with approximately 5 million parameters
- **LW PLG-ViT-R**: Optimized for runtime, with further reductions in computational complexity

Both variants maintain the core PLG-SA mechanism while substantially reducing computational requirements compared to the original PLG-ViT.

### 5. Feed-Forward Network Designs

The paper introduces an optimized feed-forward network design called CCF-FFN+ (Channel-Changing Feed-Forward Network Plus), which improves upon the existing CCF-FFN used in the original PLG-ViT.

The CCF-FFN+ incorporates:

1. **SiLU Activation**: Replacing GeLU with Sigmoid Linear Unit for improved gradient flow
2. **Gated Residual Networks (GRN)**: Adding learnable gates to control information flow
3. **Reduced Expansion Factor**: Decreasing intermediate channel dimensions while maintaining representational capacity
4. **Simplified Architecture**: Removing dropout layers and optimizing the layer sequence

These modifications result in a more efficient feed-forward network with fewer parameters and improved feature transformation capabilities.

### 6. Computational Complexity Analysis

One of the key contributions is a thorough analysis of computational complexity across different input image sizes. This analysis is critical for real-world applications where input dimensions may vary.

The analysis reveals that:

1. LW PLG-ViT variants maintain lower GFLOPs across all input dimensions compared to conventional transformers
2. The complexity scaling is more favorable than many CNN-based approaches
3. For typical input sizes in autonomous driving (e.g., 1280×720), the LW PLG-ViT variants require 25-40% fewer operations than comparable models
4. The gap in computational efficiency widens as input dimensions increase

This scalability is particularly important for autonomous driving applications, where high-resolution inputs are common and processing must occur in real-time.

### 7. Performance Evaluation

The authors evaluated their Light-Weight PLG-ViT variants on several standard benchmarks:

**ImageNet Classification Performance:**
- LW PLG-ViT-A: 79.5% top-1 accuracy with only 5M parameters
- LW PLG-ViT-R: 77.8% top-1 accuracy with further reduced computation

**Object Detection and Segmentation:**
- COCO dataset: Competitive performance with larger models while maintaining lower complexity
- NuScenes: Strong performance on autonomous driving-specific detection tasks

**Ablation Studies:**
- Each architectural modification was systematically evaluated
- Removal of regularization techniques provided additional performance gains
- The CCF-FFN+ design contributed significantly to efficiency without accuracy loss

The experiments demonstrate that the lightweight designs maintain competitive accuracy while substantially reducing computational requirements.

### 8. Application to Autonomous Driving

The Light-Weight PLG-ViT architecture shows particular promise for autonomous driving applications, where computational resources are limited but visual perception requirements are demanding.

The model was evaluated on multiple transportation-related datasets:

1. **BDD100k**: Urban driving scenes with various vehicles and traffic elements
2. **GERALD**: Railway signaling detection for autonomous train systems
3. **SVIRO**: In-vehicle monitoring for passenger detection and behavior analysis
4. **NuScenes**: 3D object detection for autonomous navigation

Across these datasets, the LW PLG-ViT variants demonstrated:
- Robust detection performance in diverse environmental conditions
- Accurate operation in challenging scenarios (night, rain, complex urban environments)
- Competitive or superior performance compared to specialized models
- Significantly lower computational requirements enabling real-time processing

The ability to process various perception tasks while maintaining efficiency makes the architecture particularly suitable for integrated autonomous driving systems where multiple visual understanding tasks must run concurrently on limited hardware.

### 9. Conclusion

The Light-Weight PLG-ViT architecture successfully addresses the challenge of deploying vision transformers on resource-constrained hardware. By redesigning the original PLG-ViT architecture with focused efficiency improvements, the authors have created models that:

1. Reduce parameters by a factor of 5 compared to the original PLG-ViT
2. Maintain competitive accuracy on standard vision benchmarks
3. Scale efficiently with increasing input dimensions
4. Perform robustly across diverse autonomous driving applications

The key innovations—optimized downsampling, enhanced CCF-FFN+ design, and strategic regularization adjustments—provide a template for future lightweight transformer designs. These improvements enable vision transformers to be deployed in real-world edge computing scenarios where computational resources are limited but visual understanding requirements remain demanding.

The work demonstrates that with careful architectural design, the power of transformer-based attention mechanisms can be harnessed even on resource-constrained platforms, opening new possibilities for advanced computer vision in autonomous vehicles, robotics, and mobile applications.
