# CORA: Adapting CLIP for Open-Vocabulary Detection with Region Prompting and Anchor Pre-Matching

> [!summary] Summary
> CORA, a DETR-style framework, adapts CLIP for open-vocabulary object detection using region prompting and anchor pre-matching to address distribution mismatch and improve generalization. It achieved 41.7 AP50 on novel classes on COCO OVD, outperforming prior methods by 2.4 AP50 without extra training data, and 22.2 APr on rare classes on LVIS OVD.

## Problem

- Traditional object detection is limited to predefined categories, hindering real-world applicability for novel objects.
- Adapting Vision-Language Pre-trained Models (VLPMs) like CLIP for region-level detection faces a distribution mismatch between whole-image training and region-level inference.
- Existing open-vocabulary detection (OVD) approaches often require additional image-text data, multiple inference passes, or struggle with generalization to novel classes.

## Method

- Introduces CORA, a ==DETR-style framework== that adapts CLIP for Open-Vocabulary Detection through two main innovations.
- Employs =="Region Prompting"== to bridge the distribution gap between CLIP's whole-image training and region-level feature extraction by augmenting features with learnable prompts.
- Utilizes =="Anchor Pre-Matching"== to associate object queries with dynamic anchor boxes and pre-match them with categories, enabling efficient single-pass, class-aware regression for novel classes.

## Results

- Achieved **41.7 AP50** on novel classes on the COCO OVD benchmark, surpassing previous state-of-the-art by **2.4 AP50** without additional training data.
- Obtained **22.2 APr** on rare classes on the LVIS OVD benchmark (without extra data) and **28.1 APr** (with extra data), outperforming existing methods.
- Ablation studies demonstrated Region Prompting improved novel class classification performance from **63.9%** to **74.1%**, and Anchor Pre-Matching enhanced localization across diverse domains.

## Takeaways

> [!tip] Key Insights
> - Directly applying whole-image pre-trained features (like CLIP's) to region-level object detection leads to a distribution mismatch that can be mitigated through adaptive region prompting.
> - Class-aware object localization for open-vocabulary detection can be achieved efficiently in a single inference pass by pre-matching object queries with target categories.
> - Strategic training techniques, such as class dropout and CLIP-aligned labeling, are important for enhancing generalization to novel and rare object categories.
