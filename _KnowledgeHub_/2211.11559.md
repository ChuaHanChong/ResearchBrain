# Visual Programming: Compositional visual reasoning without training

> [!summary] Summary
> VISPROG, developed by the PRIOR team at Allen Institute for AI, introduces a neuro-symbolic approach that generates executable programs for visual reasoning tasks using large language models and in-context learning. The system enables adaptable visual reasoning without task-specific training and produces predictions along with visual rationales explaining the reasoning process.

## Problem

- Traditional end-to-end trainable models for visual reasoning tasks often require large datasets for each specific task.
- Such approaches frequently struggle with compositional generalization and fail to handle the long tail of diverse real-world visual tasks.

## Method

- The system leverages an LLM (GPT-3) as a ==Program Generator== to translate natural language instructions into executable Python-like programs using in-context learning.
- A ==Program Interpreter== executes these generated programs by invoking specialized ==Visual Modules== that perform specific visual processing (e.g., object detection, image manipulation) and knowledge retrieval tasks.
- This approach operates at a higher level of abstraction, composing state-of-the-art vision models and non-neural subroutines without requiring any ==task-specific fine-tuning==.

## Results

- VISPROG achieved a **2.7-point** accuracy gain over a baseline VQA model on a subset of the GQA dataset for compositional visual question answering.
- It demonstrated a strong zero-shot accuracy of **62.4%** on the NLVR2 benchmark, indicating its ability to generalize to new tasks without image pair training.
- The system successfully performs diverse language-guided image editing operations and achieves a **6**3.7%** tagging F1 score** for factual knowledge object tagging, along with generating interpretable visual rationales for its reasoning.

## Takeaways

> [!tip] Key Insights
> - Large language models can effectively generate complex, executable programs for visual tasks through in-context learning with only a few examples.
> - Decomposing complex visual reasoning tasks into sequences of operations performed by modular, specialized visual components enhances interpretability and adaptability.
> - Combining the symbolic reasoning capabilities of LLMs with powerful pre-trained vision models enables robust visual reasoning without task-specific training.
