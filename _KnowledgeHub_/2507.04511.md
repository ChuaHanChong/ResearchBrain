# FA: Forced Prompt Learning of Vision-Language Models for Out-of-Distribution Detection

> [!summary] Summary
> The paper introduces the "Forced prompt leArning" (FA) framework, a new approach for Out-of-Distribution (OOD) detection using Vision-Language Models (VLMs) like CLIP. It improves OOD detection by deeply enriching the model's understanding of in-distribution (ID) data through a novel forced prompt learning strategy, achieving state-of-the-art performance across various benchmarks, with up to a 16.09% increase in average AUROC and a 38.7% reduction in average FPR95 on challenging datasets in few-shot settings.

## Problem

- Existing OOD detection methods, particularly those based on Vision-Language Models (VLMs), frequently rely on resource-intensive external OOD datasets or struggle with generalizing OOD-related knowledge.
- Current VLM-based OOD detection approaches often focus on explicitly acquiring 'OOD-related knowledge,' which is limited in its ability to generalize to diverse, unseen OOD data.
- Many traditional and VLM-based OOD methods face challenges such as high computational costs, reliance on extensive labeled in-distribution (ID) datasets, or difficulties in effectively generalizing, especially in few-shot learning scenarios.

## Method

- Introduces =="Forced prompt leArning" (FA)==, a CLIP-based framework that utilizes both frozen "original prompts" and learnable ==forced prompts== for each in-distribution (ID) class to enhance OOD detection.
- Employs a novel ==Forced Cross-Entropy (FCE) loss== to compel the learnable forced prompts to capture richer, more diversified, and salient semantic descriptions of ID classes.
- Maintains parameter efficiency comparable to existing prompt learning methods like CoOp by freezing original prompts and sharing learnable context vectors across classes for the forced prompts.

## Results

- Achieves state-of-the-art OOD detection performance across conventional and challenging benchmarks (e.g., ImageNet-1k, OpenImage-O, NINCO), consistently outperforming baselines, particularly in few-shot settings.
- In the 1-shot setting, FA_GL reduced average FPR95 from **31.62%** to **27.81%** and improved average AUROC from **92.01%** to **93.26%** on ImageNet-1k OOD benchmarks.
- Demonstrates robustness and insensitivity to the forced coefficient
K, and maintains in-distribution classification accuracy while outperforming baselines on diverse ID datasets, including challenging low-resolution ones like EuroSAT, with improvements of up to **16.09%** in average AUROC.

## Takeaways

> [!tip] Key Insights
> - Superior OOD detection can be achieved by thoroughly exploiting and enriching in-distribution (ID) knowledge, rather than explicitly attempting to acquire OOD-related knowledge.
> - Compelling Vision-Language Models (VLMs) to learn more discriminative and detailed features for ID classes implicitly enhances the separation between ID and OOD samples in the embedding space.
> - The use of a 'forced coefficient' within the FCE loss function prompts the learnable prompt to significantly surpass the generic representation provided by a stable, frozen original prompt, thereby deepening ID understanding.
