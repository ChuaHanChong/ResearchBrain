# Mimicking-Bench: A Benchmark for Generalizable Humanoid-Scene Interaction Learning via Human Mimicking

> [!summary] Summary
> This paper introduces a comprehensive benchmark for teaching humanoid robots to interact with environments by mimicking human demonstrations

## Problem

- Existing humanoid benchmarks lack large-scale human demonstration data needed to study scene geometry generalization
- Current methods are limited by small-scale, manually collected demonstrations
- Technical challenges in transferring skills from humans to humanoids remain unsolved

## Method

- Created **Mimicking-Bench**, the first benchmark for learning generalizable ==humanoid-scene interaction== through ==human mimicking==.
- Integrated a large dataset of **20K synthetic** and **3K real** human interactions across **11K** diverse object shapes.
- Constructed a complete skill-learning pipeline combining ==motion retargeting==, ==tracking==, and ==imitation learning==.
- Provided a standardized evaluation framework for comparing different approaches across the pipeline.

## Results

- Best combination achieves **54%** average success rate across **6** household interaction tasks.
- Performance improves approximately linearly with the **log** of training data size.
- Tasks requiring precise hand control remain challenging even with human demonstrations.
- Demonstrated effectiveness of the human-mimicking paradigm while identifying areas needing improvement.

## Takeaways

> [!tip] Key Insights
> - Using large-scale human demonstration data significantly improves task success rates compared to learning from scratch
> - Appropriate algorithm selection for each pipeline stage (retargeting, tracking, imitation) is critical for performance
> - Human mimicking approach enables more natural motion generation than pure reinforcement learning
> - Elevation map visual inputs outperform RGBD camera inputs for spatial understanding
