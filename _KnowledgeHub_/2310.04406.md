# Language Agent Tree Search Unifies Reasoning Acting and Planning in Language Models

> [!summary] Summary
> Language Agent Tree Search (LATS) unifies reasoning, acting, and planning capabilities in language models by adapting Monte Carlo Tree Search to incorporate external environmental feedback and LM-powered self-reflection. The framework achieves competitive or state-of-the-art results across diverse tasks, including reaching 92.7% Pass@1 accuracy on HumanEval and improving performance on interactive question answering and web navigation.

## Problem

- Existing LM-based reasoning methods (e.g., CoT, ToT) primarily rely on internal knowledge, often leading to factual hallucinations, error propagation, and an inability to incorporate real-time external feedback.
- Current LM acting methods (e.g., ReAct, Reflexion) are 'reflexive', exploring only a single trajectory at a time and lacking deliberate multi-path planning or deep lookahead in combinatorial action spaces.
- There was no single general framework that effectively unified reasoning, acting, and sophisticated planning while robustly incorporating continuous external feedback and self-reflection in language models.

## Method

- ==Language Agent Tree Search (LATS)== unifies reasoning, acting, and planning by framing problem-solving as a tree search, where each node represents a state with a history of actions and observations.
- It adapts ==Monte Carlo Tree Search (MCTS)== with six core operations: Selection (using UCT), Expansion (sampling multiple LM actions and executing them in the environment), Simulation, and Backpropagation.
- LATS introduces a novel ==LM-powered value function== that combines an LM's self-generated correctness score with a self-consistency score, and incorporates ==LM-generated self-reflection== for strategy refinement based on failures.

## Results

- Achieved **0.71** Exact Match (EM) on HotPotQA using GPT-3.5, outperforming strong baselines like ReAct (**0.32 EM**) and Reflexion (**0.51 EM**) by unifying CoT and ReAct prompting.
- Attained **92.7%** Pass@1 accuracy on HumanEval with GPT-4 and **83.8%** with GPT-3.5, surpassing Reflexion (**91.0%** and **68.1%** respectively) and demonstrating the value of external test suite feedback.
- Secured an average score of **75.9** and a **38.0%** success rate on WebShop with GPT-3.5, outperforming prompting-based methods (ReAct: **53.8** score, **28.0 SR**) and achieving competitive performance against fine-tuning approaches without additional model training.

## Takeaways

> [!tip] Key Insights
> - Monte Carlo Tree Search (MCTS) can be effectively adapted for language agents because many LM tasks allow convenient reversion to earlier states, bypassing a common challenge for model-free MCTS.
> - Pre-trained Large Language Models (LMs) can function not only as decision-makers but also as sophisticated heuristic state evaluators and self-reflection generators within a search framework, providing a 'semantic gradient signal'.
> - Unifying reasoning, acting, and planning with continuous external feedback and self-correction allows LMs to engage in deliberate, multi-path exploration, moving beyond greedy, reflexive problem-solving.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development of autonomous agents capable of complex reasoning and decision-making has been a long-standing goal in artificial intelligence. Traditionally, this domain was dominated by reinforcement learning (RL). However, the advent of large language models (LMs) like GPT-3, PaLM, and Llama 2, with their remarkable reasoning and adaptive capabilities, has opened a new paradigm for agent design.

Prior work in leveraging LMs for complex tasks can be broadly categorized into:
- **LM for Reasoning:** Methods like Chain-of-Thought (CoT) prompting and its variants (e.g., self-consistency, least-to-most prompting) enabled LMs to decompose problems into sequential steps. However, these methods often suffer from error propagation and rely solely on the LM's internal knowledge, leading to factual hallucinations or limitations in adapting to external information.
- **Search-Guided LM Reasoning:** More advanced techniques like Tree-of-Thought (ToT) and Reasoning via Planning (RAP) introduced search algorithms (DFS, BFS, or MCTS) to explore multiple reasoning paths. While improving planning, these methods generally operate in isolation, lacking the critical incorporation of real-time external feedback from an environment. RAP, for instance, uses MCTS but assumes the LM can act as an accurate world model for simulations, which is a strong assumption and often requires additional training.
- **LM for Acting (Language Agents):** Approaches like ReAct (Reasoning and Acting) integrated LMs with external environments by allowing them to interleave reasoning thoughts with actionable steps and receive observations. Extensions like Self-Refine and Reflexion further enhance this by using self-improvement mechanisms to refine single trajectories. However, a key limitation of these methods is their "reflexive" nature; they tend to explore only one path at a time and do not deliberately consider alternative choices or plan deeply ahead in a combinatorial action space.
- **Tool-Use LMs:** A related area focuses on equipping LMs with external tools (APIs, search engines, calculators) to augment their capabilities. While providing access to external knowledge, these typically integrate into the acting framework rather than offering a generalized planning mechanism over interactive steps.

The authors identify a critical gap in the existing landscape: no single framework effectively unifies *reasoning*, *acting*, and *planning* while robustly incorporating *external feedback* and *self-reflection*. Current search methods (ToT, RAP) lack external feedback, while acting methods (ReAct, Reflexion) lack deliberate multi-path planning. LATS is positioned as the first general framework to bridge this gap, leveraging the strengths of each paradigm. It explicitly addresses the need for LMs to move beyond reflexive decision-making towards a more thoughtful, adaptive, and systematic problem-solving approach, akin to human deliberation. Furthermore, the paper highlights a key insight: the ability to conveniently revert to earlier states in many LM tasks circumvents a major challenge of model-free Monte Carlo Tree Search (MCTS) in traditional reinforcement learning, making MCTS particularly suitable for language agents without requiring a trained environment model.

### 2. Key Objectives and Motivation

The primary objective of this research is to advance the capabilities of language models toward becoming general autonomous agents. The authors aim to achieve this by developing a "unified framework for decision-making and reasoning with language models" that systematically combines reasoning, acting, and planning.

The motivation for LATS stems directly from the identified shortcomings of existing LM-based agent designs:

1. **Lack of Flexibility:** Current prompting techniques, such as CoT or ReAct, generate responses autoregressively. This greedy decoding limits their ability to explore alternative continuations or reasoning paths from a given state, often leading to suboptimal or incorrect solutions on complex tasks.
2. **Limited Sensibility to External Feedback:** Reasoning-focused methods (e.g., CoT, ToT, RAP) primarily rely on the LM's internal knowledge. This dependency can lead to "fact hallucination" and error propagation, as the models cannot readily incorporate or learn from real-world observations or external validation. LMs, as noted by recent research, struggle to self-correct their internal reasoning without external input.
3. **Inadequate Adaptability in Planning:** While some methods introduce planning (e.g., ToT, RAP), they often employ simpler search algorithms (like DFS or BFS) or are constrained by assumptions about the LM's ability to act as a perfect world model. Furthermore, these agents are static and cannot effectively learn from past trial-and-error experiences or adapt their planning strategies based on environmental conditions.
4. **Absence of Unification:** Critically, no existing framework simultaneously addresses all three pillars of intelligent agency: reasoning, acting, and sophisticated planning with continuous external feedback and self-correction.

LATS is explicitly motivated to overcome these challenges by introducing deliberation and adaptability into LM-based agents. The core insight is that Monte Carlo Tree Search (MCTS), highly successful in domains like Go and Atari, can be powerfully adapted to language agents. This adaptation is made feasible by the unique property of many LM tasks: the ability to easily revert to prior states, which traditionally poses a significant hurdle for model-free MCTS in other domains. By integrating MCTS with LM-powered components (for value estimation and self-reflection), LATS aims to enable more robust, adaptive, and intelligent problem-solving by LMs.

### 3. Methodology and Approach

Language Agent Tree Search (LATS) is presented as a general framework that unifies reasoning, acting, and planning in language models by leveraging Monte Carlo Tree Search (MCTS) and the in-context learning capabilities of LMs.

**Core Philosophy:**
LATS expands upon the ReAct paradigm (interleaving thoughts and actions) by framing problem-solving as a tree search. Instead of generating a single, linear trajectory, LATS explores a combinatorial space of possible reasoning and acting steps. It repurposes pre-trained LMs not just as agents, but also as sophisticated state evaluators and intelligent feedback generators.

**LM Agent Foundation:**
The agent is initialized using a pre-trained language model ($p_\theta$). This LM acts as the base decision-maker, generating actions and thoughts. The action space (`A`) includes both permissible environmental actions (e.g., API calls, web commands) and reasoning traces (`Z`), similar to CoT. For tasks without external feedback (pure reasoning), it can default to a CoT-based prompting framework. A key aspect is that LATS samples `n` actions from $p_\theta$ at each step, promoting diverse exploration, rather than greedily decoding a single best action.

**The Monte Carlo Tree Search Adaptation:**
LATS adapts the MCTS algorithm, which is typically used in reinforcement learning for sequential decision-making, to the unique characteristics of language models and interactive environments.

- **Nodes and State Representation:** Each node `s` in the search tree represents a "state" comprising the original input `x`, the sequence of actions taken `a_1...i`, and the sequence of observations received `o_1...i` up to the current step `i`. This structure effectively stores the history of interaction with the environment.

- **Six Core Operations:** LATS performs a sequence of six operations repeatedly until a solution is found or a computational budget is reached:

 1. **Selection:** Starting from the root, the algorithm traverses the tree to select the most promising node for expansion. It uses the UCT (Upper Confidence bounds applied to Trees) formula, which balances exploration (visiting less-explored nodes) and exploitation (visiting nodes with high estimated value).
 2. **Expansion:** Once a leaf node is selected, LATS expands the tree by sampling `n` new actions from the LM agent. Each sampled action is executed in the external environment, which then provides a corresponding observation. These new action-observation pairs form `n` new child nodes, which are added to the search tree, typically stored in an external long-term memory.
 3. **Evaluation (Novel LM-Powered Value Function):** A critical component, this operation assigns a scalar value `V(s)` to each newly generated child node. Unlike traditional MCTS that might rely on a learned value function, LATS leverages the LM's in-context learning capabilities. The value function is a combination of two components:
 - **LM Score (`LM(s)`):** The LM itself is prompted to reason about the current state (after receiving environmental feedback) and provide a numerical correctness score (e.g., 1-10) for the trajectory so far. This allows the LM to act as a heuristic evaluator.
 - **Self-Consistency Score (`SC(s)`):** This component incorporates the heuristic that actions sampled multiple times at the same state are more likely to be correct.
 The final value is `V(s) = λ * LM(s) + (1 - λ) * SC(s)`, where `λ` is a hyperparameter balancing the two. This offers a flexible and efficient heuristic without requiring additional training.
 4. **Simulation:** From the expanded node, the algorithm continues to expand and evaluate nodes, prioritizing those with the highest value, until a terminal state is reached (either success or failure). If the task is successfully completed, the search terminates.
 5. **Backpropagation:** The outcome (reward `r`) from a completed trajectory (successful or unsuccessful) is used to update the estimated values (`V(s)`) and visit counts (`N(s)`) of all nodes along the path from the terminal state back to the root. These updated values then inform future UCT selections.
 6. **Reflection:** If a simulated trajectory results in failure, the LM is prompted to generate a verbal self-reflection. This reflection summarizes the errors and proposes alternative strategies. Both the failed trajectory and the corresponding reflection are stored in memory and incorporated as additional context for the LM in subsequent iterations. This provides a "semantic gradient signal" that allows the agent to learn from its mistakes without explicit reinforcement learning optimization.

**Strategic Advantages of LATS:**
- **Generality:** Supports both purely internal reasoning tasks and interactive decision-making tasks by defining a unified space of thoughts and actions.
- **Deliberation:** MCTS enables a principled search, balancing exploration and exploitation to select high-value options and explore promising alternatives.
- **Adaptability:** Integrates external feedback and self-reflection, allowing the agent to adapt and improve its problem-solving strategy dynamically.
- **Flexibility:** Modular design allows for independent modification of the base LM agent, reflection generator, and value function, adapting to different LMs and environments.
- **Efficiency (for Tree Search):** While more computationally intensive than simple prompting, it is demonstrated to be more efficient than other tree-based LM methods (ToT, RAP) in terms of nodes expanded and tokens consumed for successful trajectories.

### 4. Main Findings and Results

The experimental evaluation of LATS across diverse domains — interactive question-answering (HotPotQA), programming (HumanEval, MBPP), web navigation (WebShop), and mathematical reasoning (Game of 24) — consistently demonstrates its effectiveness and generality.

**HotPotQA (Interactive QA):**
- **Reasoning-based Setting (CoT-LATS):** LATS, when configured for internal reasoning, achieved an Exact Match (EM) score of 0.62 using GPT-3.5, outperforming strong reasoning-only baselines like ToT (0.55 EM) and RAP (0.60 EM).
- **Acting-based Setting (ReAct-LATS):** In the interactive setting, LATS (0.63 EM) significantly surpassed ReAct (0.32 EM), Reflexion (0.51 EM), and even simple adaptations of search algorithms like ToT (ReAct) (0.39 EM) and RAP (ReAct) (0.54 EM). This highlights that merely combining search with acting is insufficient; LATS's specific MCTS adaptation for LM agents is crucial.
- **Combined Strategy:** The highest performance was achieved when LATS combined both CoT and ReAct prompting (0.71 EM), indicating the importance of both internal reasoning and external feedback.

**Programming (HumanEval, MBPP):**
- **HumanEval (GPT-4):** LATS achieved a state-of-the-art Pass@1 accuracy of 92.7% with GPT-4, surpassing Reflexion (91.0%) and the base GPT-4 LM (80.1%).
- **HumanEval (GPT-3.5):** With GPT-3.5, LATS achieved 83.8% Pass@1, a substantial improvement over Reflexion (68.1%) and RAP (63.1%).
- **MBPP (GPT-3.5):** LATS demonstrated consistent strong performance, achieving 81.1% Pass@1, outperforming Reflexion (70.0%) and RAP (71.4%).
- These results underscore the critical role of external observations (test suite feedback) and systematic search in solving complex programming tasks, where internal LM reasoning alone is insufficient.

**WebShop (Complex Decision-Making):**
- LATS achieved an average score of 75.9 and a success rate (SR) of 38.0% using GPT-3.5.
- This performance is remarkable as it significantly surpasses purely prompting-based methods like ReAct (53.8 score, 28.0 SR) and Reflexion (64.2 score, 35.0 SR).
- Notably, LATS also outperformed gradient-based fine-tuning methods (e.g., IL+RL: 62.4 score, 28.7 SR; Fine-tuning: 67.5 score, 45.0 SR for SR, but lower score) without requiring additional model training. This demonstrates LATS's ability to achieve competitive or superior performance gradient-free in complex interactive environments.

**Game of 24 (Pure Reasoning):**
- LATS (CoT) achieved a success rate of 0.44 with GPT-3.5, outperforming other reasoning-specific search methods like RAP (0.40) and ToT (0.20). This validates LATS's effectiveness even for purely internal reasoning tasks, benefiting from its principled search and value function.

**Ablation Studies and Efficiency Analysis:**
- **Self-Reflection:** Removing self-reflection from LATS resulted in a noticeable performance drop (0.05 EM on HotPotQA), confirming its utility in refining strategies.
- **Search Algorithm:** Replacing MCTS with a simpler DFS (similar to ToT's heuristic pruning) led to a significant performance decrease (0.21 EM drop), emphasizing the superiority of MCTS's principled exploration-exploitation balance.
- **LM Value Function:** The LM-powered value function was shown to be crucial; its removal led to a dramatic 0.26 EM drop on HotPotQA, underscoring its role in effectively guiding the search using external feedback.
- **Efficiency:** Despite using a tree search, LATS demonstrated comparable asymptotic sample complexity to other tree-based methods (ToT, RAP) but generally expanded fewer nodes and consumed fewer tokens on average for successful trajectories. This indicates that LATS's more principled search mechanism leads to practical efficiency gains in terms of computational cost per successful task.

In summary, LATS consistently achieves competitive or state-of-the-art results across a broad spectrum of challenging tasks, proving its versatility and efficacy as a unified framework for enhancing LM decision-making and reasoning.

### 5. Significance and Potential Impact

**Significance:**
LATS represents a significant step forward in the development of intelligent language agents. Its primary contribution lies in being the **first general framework to unify reasoning, acting, and planning capabilities within language models**, effectively addressing critical limitations of prior work. By integrating Monte Carlo Tree Search, external environmental feedback, and LM-powered self-reflection and value functions, LATS enables a more deliberate and adaptive problem-solving mechanism than previously possible.

The ability of LATS to achieve state-of-the-art performance in diverse and challenging domains (e.g., 92.7% Pass@1 on HumanEval with GPT-4, and gradient-free performance comparable to fine-tuning on WebShop with GPT-3.5) highlights its profound impact. It demonstrates that LMs, when augmented with sophisticated search and feedback mechanisms, can transcend their "reflexive" nature and engage in more complex, human-like deliberation. The novel LM-powered value function and the integration of semantic self-reflection provide efficient ways for the agent to learn from experience and guide its search without requiring extensive training. This modularity also allows for future improvements to individual components.

**Potential Impact:**
- **Towards Generalist Agents:** LATS pushes the frontier towards creating more robust and generalist autonomous agents powered by LMs. Its unified nature suggests applicability to a wide range of real-world problems that require both logical reasoning and interaction with dynamic environments.
- **Enhanced Automation:** In domains like programming and web navigation, LATS's superior performance could lead to more reliable and efficient automation tools, from automated code generation and debugging assistants to intelligent online shopping bots.
- **Improved Human-AI Collaboration:** By making LM agents more capable and interpretable (through explicit reasoning steps and self-reflection), LATS could foster more effective collaboration between humans and AI systems.
- **New Research Directions:** The framework opens up new avenues for research in LM-based planning, multi-agent systems, and more complex, open-ended environments like simulations or robotics, where the "reversion property" might be carefully managed.

**Limitations:**
Despite its advancements, LATS has two main limitations:
1. **Computational Cost:** Compared to simpler autoregressive prompting methods (like ReAct), LATS incurs a higher computational cost due to the tree-structured search and multiple LM queries per step. While the authors demonstrate that LATS is more efficient than other tree-based methods and that the "number of sampled nodes (n)" can be adjusted for a performance-efficiency trade-off, this remains a practical consideration for large-scale or real-time deployment.
2. **Environment Reversion Assumption:** LATS relies on the assumption that the environment allows "reverting to earlier states." This property is true for many digital environments (e.g., programming test suites, web browsing, text-based games) but is not universally applicable to all real-world interactive scenarios (e.g., physical robot manipulation without perfect state reset).

**Ethical Considerations:**
The authors acknowledge the dual nature of advancing LM agent capabilities. While LATS can enable beneficial applications, improved autonomous decision-making in LMs also carries potential risks, such as facilitating harmful uses or increasing security vulnerabilities (e.g., executing malware). Conversely, the framework's emphasis on high-level linguistic reasoning, explicit actions, and self-reflection could enhance interpretability and promote greater alignment with human intentions, as the decision-making process is more transparent than purely black-box autoregressive generation. The authors appropriately call for continued research to understand and mitigate these risks.

#### 5.1. Conclusion

Language Agent Tree Search (LATS) represents a significant methodological contribution to the field of large language model agents. By ingeniously adapting Monte Carlo Tree Search to LM capabilities and integrating external feedback with LM-powered value functions and self-reflection, LATS successfully unifies reasoning, acting, and planning. Its robust empirical performance across diverse, challenging tasks validates its effectiveness and generality, setting new benchmarks in areas like code generation and web navigation. While computational cost and environmental assumptions remain considerations, LATS lays a critical foundation for the development of more deliberate, adaptive, and truly autonomous language model-based agents, pushing the boundaries of AI problem-solving.
