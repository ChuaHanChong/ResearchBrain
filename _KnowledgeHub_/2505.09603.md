# DataMIL: Selecting Data for Robot Imitation Learning with Datamodels

> [!summary] Summary
> DataMIL introduces a framework for selecting the most beneficial data from large, diverse datasets for robot imitation learning by using datamodels to estimate each data point's impact on target task performance. This method consistently outperforms heuristic-based selection strategies in both simulation and real-world robot tasks, achieving an average 61% success rate in real-world experiments while enabling cross-embodiment transfer.

## Problem

- Generalist robot policies, while trained on large datasets, frequently underperform on specific tasks requiring specialized skills.
- Selecting the most beneficial data for fine-tuning these policies from vast, diverse datasets is challenging, with existing heuristic methods (e.g., visual or state-action similarity) often failing to directly optimize for policy performance.
- Naive data combination strategies can degrade policy performance due to task-irrelevant information, distribution shifts between datasets, or variations in data quality.

## Method

- **DataMIL** introduces a method for selecting data for robot imitation learning by adapting the 'datamodels' framework, which predicts the influence of individual training data points on model performance.
- It uses a surrogate loss function, specifically validation loss on task-specific data, to estimate data point influence, thereby avoiding the need for expensive real-world policy rollouts during the selection process.
- The framework employs two main estimators for datamodels (regression and metagradient-based) and consists of three steps: datamodel estimation, selection of top-performing data points, and final policy training on the selected data combined with target task data.

## Results

- DataMIL consistently outperformed existing heuristic-based baselines in both simulated and real-world robot environments.
- On real robot tasks, DataMIL achieved an average success rate of **61%**, surpassing the next best method (STRAP) by 21 percentage points across diverse tasks and robot platforms.
- The framework effectively demonstrated cross-embodiment transfer, selecting data from one robot platform that improved performance on a different robot, and successfully scaled to larger policy networks like Octo using a metagradient-based estimator.

## Takeaways

> [!tip] Key Insights
> - A surrogate loss function based on validation loss on task-specific data can effectively stand in for expensive real-world policy rollouts during data selection, accurately predicting data utility.
> - The datamodels framework can identify training data points that most improve policy performance on a target task, even selecting data from seemingly unrelated tasks or different robot embodiments, which is crucial for cross-embodiment transfer.
> - Performance-aware data selection, as implemented by DataMIL, consistently outperforms traditional heuristic-based methods, demonstrating that optimizing directly for policy improvement is more effective than relying on similarity metrics.
