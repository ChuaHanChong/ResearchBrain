# PatchWorld: Gradient-Free Optimization of Executable World Models for Agent Environments

> [!summary] Summary
> PatchWorld turns offline text-agent trajectories into executable Python world models with an explicit symbolic belief state. An LLM acts as a gradient-free optimizer and repairs the program from replay counterexamples. Patches are accepted only if held-out replay improves. The simple variant reaches 76.4% macro success in live lookahead with zero LLM calls in prediction, and it exposes a fidelity-utility tradeoff.

## Problem

- Text-agent environments are black-box partially observable settings where the latent state is never exposed, yet prior text world models predict the next observation from recent history and keep no persistent belief for multi-step simulation.
- Unstructured natural-language observations make code world models brittle, because one latent fact has many phrasings and small wording changes break exact replay even when the underlying dynamics are correct.
- Offline logs underdetermine the belief, since memorizing and structured programs both replay training data perfectly, and fitting the logs alone cannot show which program will generalize to unseen episodes.

## Method

- An LLM synthesizes an ==executable Python belief-state program== with a ==symbolic belief==, an ==action-update rule==, a ==correction step== from real observations, and a separate ==readout== that renders text, from trajectories alone.
- ==Counterexample-guided inductive synthesis== replays trajectories, turns typed prediction failures into counterexamples, and prompts the LLM to patch the code. A patch is accepted only if the full ==validation replay score== improves.
- ==Contrastive mining== of failure and success transitions guides the repair. **PatchWorld-Residual** adds a human-specified, train-only ==residual memory== of exact state signatures to improve surface fidelity, while **PatchWorld-Simple** stays purely symbolic.

## Results

- On seven AgentGym environments, PatchWorld-Simple reaches **76.4%** macro live success, beating PoE-World (**69.3%**) and WorldCoder (**64.4%**) and matching LLM-Direct (**75.7%**), which spends about **64k** lookahead tokens per task against **zero**.
- PatchWorld-Residual raises one-step Token F1 from **0.57** to **0.69**, but live success drops from **76.4%** to **72.9%**. Word2World has the top fidelity (**0.85** F1) yet only **63.5%** success.
- Ablations show that removing state parsing costs **24.5** success points, contrastive mining **12.9**, and the repair loop **7.9**. Induction takes **17 to 28** LLM calls and **300k to 503k** tokens per environment.

## Takeaways

> [!tip] Key Insights
> - Observation fidelity and decision utility are separate goals. Matching surface text does not give action-discriminative predictions, so evaluate world models on downstream decisions as well as reconstruction.
> - An LLM can serve as a symbolic optimizer that builds an inspectable, locally repairable program, moving inference cost offline so that decision-time prediction is ordinary Python.
> - A validation-replay gate on counterexample-guided patches guards against memorizing training transitions, and the gain comes from the belief interface plus contrastive repair, not from a lookup cache.

## Detailed Report

### 1. Overview

PatchWorld addresses a practical gap for text agents. After each action, an agent sees only a text description of a partly hidden world. It has no access to the simulator's underlying state or transition rules. A plausible next sentence is not necessarily a useful account of what an action changes. PatchWorld uses an LLM to turn offline observation–action logs into an executable Python model. It then uses replay failures as counterexamples for proposing local code repairs. Across seven environments, this predictor supports live action choice without an LLM inside its prediction module.

### 2. From logs to a patchable model

The program keeps a "belief," which is the agent's own structured approximation of the hidden state, built from what it has observed. It is not the true simulator state. The program runs a cycle:

1. It parses and corrects the belief from an observation.
1. It predicts the belief after a candidate action.
1. It renders a predicted observation.
1. It corrects the belief again when the true observation arrives.

The symbolic belief keeps action effects separate from the wording used to describe them.

Building the model follows a fixed sequence. PatchWorld first mines a compact contrastive set from training trajectories by grouping action types and outcome types, including success-like and failure-like outcomes. An LLM then synthesizes a complete executable Python model. Replaying that model exposes typed failures. The LLM receives counterexamples and diagnostics and proposes a patch. A patch is accepted only when the validation replay score improves. Training supplies the examples, validation gates repair, and the test set is reserved for final reporting. This gate reduces the risk of patches that fix shown examples but regress elsewhere. It does not certify correctness beyond the tested data.

Offline training trajectories are clustered by action and outcome signatures into a contrastive transition set. An LLM synthesizes a program under a fixed interface, and the model is replayed against training/validation evidence. Failures become counterexamples, and candidate patches are accepted only if the replay score improves. This depicts the proposed workflow, not a measured accuracy gain.

### 3. Matching LLM lookahead at zero prediction tokens

The evaluation covered seven AgentGym environments. PatchWorld-Simple has the highest code-based live-lookahead score, with 76.4% macro episode success, versus 75.7% for LLM-Direct under the shared procedure. "Macro" means the unweighted mean of the seven environments' episode-success percentages. This is a one-step lookahead result. It is not evidence of general superiority in longer planning or other settings.

The saving applies at prediction time: PatchWorld-Simple uses zero lookahead-prediction tokens per task, versus 63,897 for LLM-Direct. It does **not** eliminate LLM calls from the whole live agent. Candidate generation and the shared reranker still use LLMs, and inducing the program has an offline LLM cost.

Episode-success percentages under the paper's shared one-step lookahead protocol, with an unweighted seven-environment average. PatchWorld-Simple averages 76.4, LLM-Direct 75.7, ReAct 74.4, and PatchWorld-Residual 72.9. Simple is not best in every environment: it is low on AlfWorld, and Wordle is a 100% tie across all methods.

### 4. Text match is not task success

Closer text reproduction does not necessarily mean better action choices. The paper compares two matched Qwen3-Coder-480B variants using two measures:

- **Token F1** measures overlap between the predicted and reference next-observation tokens.
- **Live success** measures completed episodes under the shared one-step lookahead procedure.

PatchWorld-Residual adds a train-only lookup for normalized observation–action keys. The lookup is used only when the next observation is unique; otherwise prediction falls back to symbolic readout. Adding this human-specified residual-memory bias lifts test Token F1 from 0.57 to 0.69. It also accompanies a fall in live macro success from 76.4% to 72.9%.

The authors interpret this as a fidelity–utility tradeoff. In their view, a selector needs predictions that distinguish action consequences, not just wording that resembles the reference. The comparison establishes the variants' measured difference. It does not establish that residual memory is the sole possible cause of worse action rankings.

### 5. A model you can inspect

Text prediction alone is not the whole job. PatchWorld makes the action-update rules executable and testable. Its results show that better surface match and better action guidance are distinct aims.
