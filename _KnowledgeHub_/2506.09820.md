# CoRT: Code-integrated Reasoning within Thinking

> [!summary] Summary
> The CoRT framework enables Large Reasoning Models to efficiently leverage Code Interpreters for complex mathematical reasoning, achieving higher accuracy and significantly reducing token usage by optimizing interaction patterns. It introduces a novel hint-engineering data synthesis method and an end-to-end training pipeline combining supervised, rejection, and reinforcement learning.

## Problem

- Large Reasoning Models (LRMs) struggle with precision and efficiency in complex mathematical operations and symbolic problem-solving, areas where Code Interpreters (CIs) excel.
- High-quality, human-annotated data for code-integrated reasoning is scarce, making it difficult to teach LRMs effective CI interaction.
- Existing tool-integrated reasoning approaches often exhibit inefficiencies such as "delayed code computation" (performing text-based reasoning before using CI) and "code result distrust" (unnecessarily verifying CI outputs).

## Method

- The **CoRT** framework introduces "==Hint-engineering==," a novel and sample-efficient method for synthesizing high-quality code-integrated reasoning data by strategically inserting hints to guide LRM behavior.
- An end-to-end training pipeline combines Supervised Fine-Tuning (SFT) for initial learning, Rejection Fine-Tuning (RFT) to filter suboptimal reasoning traces, and Code-integrated Reinforcement Learning (RL) for refined policy learning.
- A "strong-to-weak distillation" strategy facilitates RL training on smaller models, incorporating a persistent execution environment and a custom dual reward system to enhance code integration and reduce errors.

## Results

- Hint-Engineering-RFT-**32B** achieved **81.3%** average accuracy on mathematical reasoning benchmarks, competitive with leading models, despite being trained on only 30 manually annotated samples.
- Hint-Engineering models demonstrated 30-**50%** lower token consumption compared to baselines while maintaining or improving performance, notably achieving similar performance to QwQ-**32B** with **50%** fewer tokens.
- Code behavior analysis showed Hint-Engineering shifted CI usage from primarily verification (**82.4%**) to a balanced mix of direct calculation (**51.1%**) and verification (**48.9%**), indicating more efficient and appropriate tool integration.

## Takeaways

> [!tip] Key Insights
> - "Hint-engineering," which uses a small set of 30 high-quality, strategically hinted samples, significantly improves model efficiency by guiding immediate CI use for calculations and fostering trust in CI outputs.
> - Reinforcement Learning (RL) yields substantial performance gains (approximately 8% absolute accuracy) for smaller models, fundamentally enhancing their ability to consistently find correct solutions.
> - A dual reward system in RL, including a code execution penalty, effectively encourages correct CI usage and further improves performance.
