# MemoryArena: Benchmarking Agent Memory in Interdependent Multi-Session Agentic Tasks

> [!summary] Summary
> Researchers from Stanford, UCSD, UIUC, Princeton, University of Pittsburgh, and 2077AI introduce MEMORYARENA, a benchmark for evaluating AI agent memory in interdependent multi-session tasks across four diverse domains. This benchmark reveals that current state-of-the-art large language models and augmented memory systems consistently achieve low success rates, exposing a significant gap in their ability to sustain performance and utilize memory over long-horizon, complex tasks.

## Problem

- Existing benchmarks either focus on isolated factual recall or single-session actions, failing to capture the tightly coupled nature of memory and action over extended periods.
- Current action-focused benchmarks often treat memory as a 'flat context' within the model's context window, not requiring explicit long-term retention or inter-session information transfer.
- Real-world agentic behavior demands continuous acquisition, storage, and utilization of knowledge across multiple, interdependent sessions, which current evaluations do not adequately assess.

## Method

- Introduction of MEMORYARENA, a novel evaluation gym designed with human-crafted multi-session, interdependent tasks that necessitate explicit memory usage across sessions.
- The benchmark structures evaluations around a 'Memory-Agent-Environment loop' where agents distil experiences into a persistent memory system after each completed subtask session.
- Tasks are instantiated across four diverse domains: Bundled Web Shopping, Preference-constrained Group Travel Planning, Progressive Information Searching, and Sequential Formal Reasoning.

## Results

- All evaluated methods achieved low Task Success Rates and Task Progress Scores in MEMORYARENA, demonstrating the benchmark's high difficulty and the persistent limitations of current agent capabilities.
- Analysis of 'Success Rate at subtask depth k' (SR@k) revealed a consistent performance decay across all methods and environments, indicating agents struggle to sustain execution as dependencies span more sessions.
- External memory and RAG systems offered specific benefits in tasks like Progressive Web Search (reducing attention saturation) and Formal Reasoning (providing curated context), but generally incurred higher execution latency compared to long-context agents.

## Takeaways

> [!tip] Key Insights
> - MEMORYARENA exposes a significant challenge for current state-of-the-art LLMs and memory systems in interdependent multi-session tasks, contradicting performance reported on traditional recall-based benchmarks.
> - The benchmark frames agent memory as a Partially Observable Markov Decision Process (POMDP) problem, interpreting performance decay as 'belief drift' due to accumulating errors in the agent's implicit state estimate.
> - External memory and RAG systems do not consistently outperform long-context models, often due to representation mismatches and a lack of joint optimization between memory mechanisms and agent training objectives.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The development of sophisticated Large Language Model (LLM) agents that can perform complex tasks autonomously is a major frontier in AI research. A critical challenge for these agents is the ability to remember and utilize information over extended periods and across multiple interactions. This paper addresses a significant gap in the current evaluation landscape for such LLM agents, specifically concerning their memory capabilities.

Existing benchmarks typically fall into two categories, each with its own limitations:
1. **Memorization-focused benchmarks:** These evaluate an agent's ability to recall past conversations or text (e.g., LoCoMo, LongMemEval, MemoryAgentBench). While effective at measuring factual recall from long contexts, they often lack agentic decision-making, environment dynamics, or action-dependent consequences. They assess memory in isolation, failing to capture how memory *guides* future actions in an interactive setting.
2. **Action-focused benchmarks:** These evaluate an agent's ability to act in dynamic environments (e.g., SWE-Bench, WebArena, WebShop). However, these are predominantly designed for single-session tasks. In such settings, the entire interaction history often fits within the model's context window, treating memory as a "flat context" rather than requiring explicit long-term retention or inter-session information transfer. Consequently, success in these benchmarks does not reliably reflect an agent's ability to retain and utilize information over extended horizons where early interactions introduce latent constraints for future decisions.

The authors argue that real-world agentic behavior necessitates a tighter coupling between memorization and action, occurring over multiple, interdependent sessions. This work positions itself as the first to specifically design a benchmark, MEMORYARENA, that enforces this multi-session, interdependent task structure, thereby evaluating memory as a functional and integral component of an agent's overall performance within a continuous "Memory-Agent-Environment loop." This bridges the gap left by previous benchmarks, moving towards a more holistic and realistic assessment of agent intelligence.

### 2. Key Objectives and Motivation

The primary objective of this research is to introduce **MEMORYARENA**, a novel and unified evaluation gym designed to rigorously benchmark the effectiveness and usefulness of agent memory in **multi-session, interdependent agentic tasks**.

The core motivations behind MEMORYARENA are:
- **Address the gap in current evaluations:** Existing benchmarks either assess memorization or action in isolation, failing to capture their tightly coupled nature in real-world scenarios.
- **Simulate realistic agent behavior:** In practical applications, agents acquire knowledge through interaction, store it in memory, and then rely on that memory to solve future, often related, tasks. This process unfolds over multiple interactions or "sessions."
- **Evaluate memory as a functional component:** The paper advocates for treating memorization not merely as recall, but as an active component of an agent's decision-making process within a "Memory-Agent-Environment loop," where actions elicit feedback, feedback updates memory, and memory conditions subsequent actions across sessions.
- **Expose limitations of current SOTA agents:** By designing tasks where later actions are underspecified without correctly tracking task-relevant information from prior sessions, the authors aim to reveal persistent challenges that state-of-the-art agents and memory systems face.
- **Drive advancements in long-horizon agent memory:** By exposing these gaps, MEMORYARENA seeks to catalyze the development of more robust memory mechanisms and agent architectures capable of sustained, intelligent behavior over extended, interdependent tasks.

### 3. Methodology and Approach

The methodology revolves around the design and implementation of MEMORYARENA, a benchmark platform that structures agent evaluations around a **Memory-Agent-Environment loop** across multiple sessions.

#### 3.1. Task Design Principles

MEMORYARENA consists of human-crafted tasks with explicitly interdependent subtasks. This interdependency is crucial: successful completion of later subtasks requires agents to learn from earlier actions and feedback, distill experiences into memory, and then utilize that memory to guide subsequent decisions.

#### 3.2. Four Distinct Evaluation Domains

To provide a comprehensive evaluation, MEMORYARENA instantiates tasks across four diverse domains, each posing unique memory and reasoning challenges:

1. **Bundled Web Shopping:** Agents must purchase a bundle of related products over multiple sessions. Later purchases require recalling attributes (e.g., compatibility, preferences) of earlier items to ensure consistency.
2. **Preference-constrained Group Travel Planning:** An initial itinerary is planned for one traveler, with additional participants joining incrementally. New travelers introduce individual or partial-group constraints that interact with existing plans, demanding precise recall of prior activities and preferences.
3. **Progressive Information Searching:** Agents accumulate and reuse information across multiple search steps. Each step adds a new condition, and the final answer must satisfy all cumulatively introduced constraints.
4. **Sequential Formal Reasoning (Math & Physics):** Reflects research-level scientific reasoning, where complex theoretical claims depend on extended chains of intermediate results, definitions, and lemmas. Verifying a claim requires careful reuse of previously established conclusions, testing long-term memory and multi-step formal reasoning.

#### 3.3. The Memory-Agent-Environment Loop

The core conceptual framework is the "Memory-Agent-Environment loop" operating over multi-session tasks.
- A task comprises multiple subtasks ($S = \{s_i\}_{i=1}^n$), executed sequentially.
- Each subtask ($s_i$) runs as a separate session.
- Crucially, once a session terminates, its interaction trace is no longer directly accessible to the agent.
- Agents are equipped with a **persistent memory system (M)**, initialized as empty, which stores information across subtask sessions. This memory system defines two abstract functions:
 - **RETRIEVE(M, s_i, history_in_session):** Returns task-relevant memory given the current subtask and session history.
 - **UPDATE(M, session_trace):** Incorporates information from a completed subtask into M.
- At each action step, the agent retrieves relevant memory, and actions are selected based on a memory-conditioned policy.
- After subtask completion, M is updated, carrying forward distilled knowledge to influence future decision-making in subsequent subtasks.

#### 3.4. Experimentation Setup and Agent Categories

The study evaluates various state-of-the-art agents equipped with different memory paradigms:

1. **Long-context Agents (0D memory):** LLMs that directly use their large context windows to append verbatim interaction history (e.g., GPT-5.1-mini, Gemini-3-Flash). They represent a baseline where "memory" is simply the extended context.
2. **External Memory Agents (1D or 2D memory):** Agents augmented with learned or curated mechanisms for information abstraction, consolidation, and retrieval (e.g., MemGPT, Mem0, ReasoningBank). 1D refers to flat memory structures, while 2D refers to structured memory (e.g., graph-based).
3. **Retrieval-Augmented Generation (RAG) Systems (0D, 1D, or 2D memory):** Agents using an indexed document store to retrieve past information based on methods like BM25, embedding-based retrieval, or structured RAG (e.g., MemoRAG, GraphRAG).

#### 3.5. Evaluation Metrics

- **Task Success Rate (SR):** The percentage of tasks where all subtasks are fully and correctly solved.
- **Task Progress Score (PS):** Measures the fraction of subtasks correctly completed within a task, providing a fine-grained signal of partial progress.
- **Soft Progress Score (sPS):** Introduced for particularly challenging environments like Group Travel Planning, where partial credit is given based on the fraction of constraints satisfied within a subtask, to allow for more informative comparisons.
- **SR at subtask depth k (@k):** Measures the success rate specifically at the k-th subtask, characterizing how well agents sustain execution as dependencies span more sessions (i.e., long-horizon stability).
- **Latency:** Subtask completion time as a diagnostic measure of end-to-end execution efficiency.

### 4. Main Findings and Results

The experiments conducted using MEMORYARENA revealed several critical insights into the current capabilities of LLM agents and their memory systems:

1. **Low Overall Performance and High Task Difficulty:** All evaluated methods, including state-of-the-art LLMs and advanced memory/RAG systems, achieved low Task Success Rates (SR) and Task Progress Scores (PS). This indicates that MEMORYARENA poses a significantly challenging benchmark and exposes a substantial gap in current agent capabilities for interdependent multi-session tasks.
2. **Gap between Partial Progress and Full Success:** Most methods showed much higher PS than SR, especially in domains like Bundled Web Shopping and Progressive Web Search. This suggests that agents can make progress on individual subtasks but struggle to integrate these partial successes into globally consistent solutions over the entire task horizon.
3. **Group Travel Planning: The Most Challenging Environment:** This domain consistently yielded near-zero SR and PS across all methods, even with the introduction of a soft Progress Score (sPS). The complexity of planning 30-slot itineraries with interdependent constraints across multiple travelers demands exceptional memorization and long-chain reasoning, which remains beyond current agents.
4. **External Memory and RAG Not Universally Beneficial:** Surprisingly, augmenting GPT-5-mini with external memory or RAG systems did not consistently outperform the model's full long-context history alone. This was attributed to:
 - **Representation Mismatch:** External memory systems often return compressed or reordered information that might not align well with the agent's in-context learning over raw, verbatim history.
 - **Training Mismatch:** Current external memory systems are not jointly optimized with the task agent, leading to suboptimal query formulation and integration of retrieved information.
5. **When External Memory Helps:** Performance gains from external memory were observed in specific scenarios:
 - **Progressive Web Search:** Where individual subtask traces can exceed 120k tokens, external memory mitigates attention saturation and error accumulation by selectively abstracting and distilling relevant information.
 - **Formal Reasoning:** For highly complex and domain-specific reasoning, external memory helps by providing curated relevant context.
 - Retrieval-based approaches (RAG) were found to be more robust in tasks requiring precise reuse of earlier subtask information (e.g., formal reasoning, group travel planning) compared to external memory systems relying on heavier abstraction.
6. **Performance Decay with Subtask Interdependency:** The "Success Rate at subtask depth k" (SR@k) analysis showed a consistent decay across all methods and environments (Figure 3). This highlights a fundamental struggle for agents to sustain execution and maintain task state as dependencies span more sessions. While long-context agents degrade faster in very long-trace tasks (like Progressive Web Search), RAG systems exhibited slower decay in scenarios demanding precise information reuse.
7. **Latency Trade-offs:** Long-context agents generally exhibited the lowest execution latency, while external memory systems incurred the highest, with RAG systems falling in between. This indicates that more complex memory operations often come with a performance cost, although no systematic relationship between memory complexity (0D, 1D, 2D) and latency was observed, suggesting optimization opportunities.

### 5. Significance and Potential Impact

MEMORYARENA represents a significant step forward in the evaluation of AI agents, with several profound implications for future research and development:

1. **New Standard for Agent Memory Evaluation:** By explicitly focusing on interdependent, multi-session tasks within a "Memory-Agent-Environment loop," MEMORYARENA establishes a more realistic and rigorous benchmark that moves beyond isolated recall or single-session action. It provides a testbed to assess memory as a truly functional component of intelligent behavior.
2. **Exposing Critical Limitations of Current Agents:** The uniformly low success rates across state-of-the-art LLMs and their augmented memory systems reveal a fundamental challenge in long-horizon, state-tracking capabilities. This directly contradicts the near-saturated performance often reported on traditional recall-based memory benchmarks, highlighting a disconnect between current evaluation metrics and real-world agentic demands.
3. **Reframing Agent Memory as a POMDP Problem:** The paper insightfully views MEMORYARENA as a testbed for Partially Observable Markov Decision Processes (POMDPs). The observed performance decay with subtask depth can be interpreted as "belief drift," where errors in the agent's implicit state estimate accumulate. External memory systems can thus be seen as mechanisms for approximating belief-state estimation. This framing provides a theoretical foundation and a clearer direction for developing memory systems that can effectively track and update latent task states.
4. **Guiding Future Research Directions:**
 - **Joint Optimization:** The findings underscore the need for jointly optimizing memory representations and agent training objectives. Current memory systems, often designed for generic recall, lack the capacity to preserve task-relevant "sufficient statistics" for belief tracking. Agents, in turn, are not effectively trained to query, interpret, and integrate structured memory outputs.
 - **Memory-Latency Trade-offs:** The observed differences in latency highlight the practical importance of considering efficiency alongside effectiveness, especially for repeatedly accessed memory in multi-session settings.
 - **Beyond Recall:** The benchmark shifts the focus from mere factual recall to the *utility* of memory in guiding complex, interdependent decision-making. This will encourage the development of memory systems that are not just large, but smart, adaptive, and task-aware.
5. **Accelerating Development of Robust AI Agents:** By providing clear challenges and a platform for comparison, MEMORYARENA will undoubtedly spur innovation in memory architectures, reasoning mechanisms, and learning paradigms for LLM agents, ultimately leading to more capable and reliable AI systems for real-world applications.

In conclusion, MEMORYARENA is a timely and essential contribution that fundamentally reshapes how agent memory is evaluated. By exposing the Achilles' heel of current LLM agents—their inability to effectively utilize memory in dynamic, interdependent, multi-session contexts—it sets a clear agenda for the next generation of AI research in autonomous agents.
