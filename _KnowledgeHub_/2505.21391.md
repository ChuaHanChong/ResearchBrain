# Finite Sample Analysis of Linear Temporal Difference Learning with Arbitrary Features

> [!summary] Summary
> Researchers from the University of Virginia derived the first finite-sample L2 convergence rates for linear Temporal Difference (TD) learning algorithms when using arbitrary, potentially linearly dependent features. This work provides an L2 rate of O(ln t / t) for both discounted and average-reward settings, demonstrating that convergence to a solution set can be theoretically guaranteed under more realistic conditions.

## Problem

- Most theoretical analyses for linear TD(λ) assume linearly independent features, which is often not practical in real-world applications and limits theoretical guarantees.
- Previous work lacked finite-sample L2 convergence rates for linear TD(λ) in both discounted and average-reward settings under the general condition of arbitrary features.
- Traditional stochastic approximation frameworks typically prove convergence to a unique solution point, which is insufficient when arbitrary features lead to a set of solutions for the learned parameters.

## Method

- Developed a novel, generalized ==stochastic approximation== (SA) framework capable of proving L2 convergence rates for algorithms that converge to a potentially unbounded set of solutions, rather than a single point.
- Applied this generalized SA framework to the discounted TD(λ) setting by rigorously verifying all assumptions, including characterizing the solution set and showing negative definiteness of the expected update.
- Extended the application to the more complex average-reward TD(λ) setting by introducing a novel feature matrix decomposition and analyzing an extended parameter vector, ensuring the SA framework's assumptions were met.

## Results

- Established the first L2 convergence rates for linear TD(λ) with arbitrary features in the discounted setting, showing an expected squared distance to the solution set converges at an O(ln t / t) rate.
- Provided the first L2 convergence rates for linear TD(λ) with arbitrary features in the average-reward setting, demonstrating that both the average reward estimate and the distance to the weight solution set converge at an O(ln t / t) rate.
- Empirical experiments on a variant of Boyan's chain with a rank-deficient feature matrix corroborated the theoretical finding that the weight vector converges to the *set* of optimal weights.

## Takeaways

> [!tip] Key Insights
> - A generalized stochastic approximation framework can be constructed using a Lyapunov function based on the squared Euclidean distance to a solution set, allowing analysis of convergence to unbounded solution sets.
> - Linear TD(λ) with arbitrary features can still achieve finite-sample L2 convergence rates comparable to those established for linearly independent features (e.g., O(ln t / t) for standard learning rates).
> - In the presence of linearly dependent features, the parameters of linear TD(λ) converge to a *set* of solutions, but the estimated value function (Xw) itself converges to a unique value.
