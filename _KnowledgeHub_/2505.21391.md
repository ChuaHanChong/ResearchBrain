# Finite Sample Analysis of Linear Temporal Difference Learning with Arbitrary Features

> [!summary] Summary
> Researchers from the University of Virginia derived the first finite-sample L2 convergence rates for linear Temporal Difference (TD) learning algorithms when using arbitrary, potentially linearly dependent features. This work provides an L2 rate of O(ln t / t) for both discounted and average-reward settings, demonstrating that convergence to a solution set can be theoretically guaranteed under more realistic conditions.

## Problem

- Most theoretical analyses for linear TD(λ) assume linearly independent features, which is often not practical in real-world applications and limits theoretical guarantees.
- Previous work lacked finite-sample L2 convergence rates for linear TD(λ) in both discounted and average-reward settings under the general condition of arbitrary features.
- Traditional stochastic approximation frameworks typically prove convergence to a unique solution point, which is insufficient when arbitrary features lead to a set of solutions for the learned parameters.

## Method

- Developed a novel, generalized ==stochastic approximation== (SA) framework capable of proving L2 convergence rates for algorithms that converge to a potentially unbounded set of solutions, rather than a single point.
- Applied this generalized SA framework to the discounted TD(λ) setting by rigorously verifying all assumptions, including characterizing the solution set and showing negative definiteness of the expected update.
- Extended the application to the more complex average-reward TD(λ) setting by introducing a novel feature matrix decomposition and analyzing an extended parameter vector, ensuring the SA framework's assumptions were met.

## Results

- Established the first L2 convergence rates for linear TD(λ) with arbitrary features in the discounted setting, showing an expected squared distance to the solution set converges at an O(ln t / t) rate.
- Provided the first L2 convergence rates for linear TD(λ) with arbitrary features in the average-reward setting, demonstrating that both the average reward estimate and the distance to the weight solution set converge at an O(ln t / t) rate.
- Empirical experiments on a variant of Boyan's chain with a rank-deficient feature matrix corroborated the theoretical finding that the weight vector converges to the *set* of optimal weights.

## Takeaways

> [!tip] Key Insights
> - A generalized stochastic approximation framework can be constructed using a Lyapunov function based on the squared Euclidean distance to a solution set, allowing analysis of convergence to unbounded solution sets.
> - Linear TD(λ) with arbitrary features can still achieve finite-sample L2 convergence rates comparable to those established for linearly independent features (e.g., O(ln t / t) for standard learning rates).
> - In the presence of linearly dependent features, the parameters of linear TD(λ) converge to a *set* of solutions, but the estimated value function (Xw) itself converges to a unique value.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Temporal Difference (TD) learning, introduced by Sutton, is a foundational algorithm in reinforcement learning (RL) primarily used for policy evaluation. Its efficacy stems from combining dynamic programming principles with stochastic approximation (SA) methods. For applications involving large or continuous state spaces, tabular representations of value functions become impractical. Linear TD(λ) addresses this by employing linear function approximation, where value functions are approximated as a linear combination of features and weights.

Establishing theoretical guarantees for linear TD(λ), particularly concerning its convergence rates, has been a significant area of research. A prevalent limitation in much of the existing theoretical literature, as summarized in Table 1 of the paper, is the assumption that the features used in the linear approximation are linearly independent. This assumption simplifies mathematical analysis by ensuring the uniqueness of solutions and the positive definiteness of certain matrices, which is crucial for proving convergence.

However, the assumption of linearly independent features is often not practical in real-world applications. For instance, in continual learning paradigms where data arrives sequentially, rigorously verifying feature independence is challenging. Prominent researchers like Dayan, Tsitsiklis and Roy, and more recently Wang and Zhang, have identified the relaxation of this assumption as an important future research direction.

Previous efforts to address this limitation, such as Wang and Zhang, provided asymptotic (almost sure) convergence guarantees for the discounted setting, but did not extend to finite-sample L2 convergence rates or the average-reward setting. Such asymptotic results, while theoretically important, do not provide bounds on performance within a finite number of steps, which is critical for practical applications.

This work positions itself within this landscape by directly tackling the challenge of arbitrary (potentially linearly dependent) features. It aims to provide finite-sample L2 convergence rates, thereby offering stronger theoretical guarantees that are more relevant for practical deployment than previous asymptotic results. Furthermore, it expands the analysis to both discounted and average-reward settings, addressing a gap in the existing literature where such comprehensive analyses with arbitrary features were absent. The novelty also lies in developing a generalized stochastic approximation framework that can handle convergence to a *set* of solutions, rather than a single unique point, which naturally arises when features are linearly dependent.

### 2. Key Objectives and Motivation

The primary objective of this research is to establish the first L2 convergence rates for the linear TD(λ) algorithm when operating under *arbitrary features*. This explicitly removes the restrictive assumption of linear independence, which has been a cornerstone of most prior theoretical analyses for this algorithm.

The work pursues this overarching objective across two fundamental settings in reinforcement learning:
1. **Discounted Setting (γ < 1):** To derive L2 convergence rates for linear TD(λ) in environments where future rewards are discounted.
2. **Average-Reward Setting (γ = 1):** To derive L2 convergence rates for linear TD(λ) in environments where the long-term average reward is the performance metric.

A crucial motivation for this research stems from the practical limitations and theoretical desiderata surrounding the linear independence assumption. As highlighted by several prior works, features in real-world scenarios are often not linearly independent. This can occur in complex domains where feature engineering leads to redundancy, or in dynamic learning environments like continual learning where verifying independence is infeasible. The absence of rigorous finite-sample guarantees under such realistic conditions limits the confidence in applying linear TD(λ) in practical systems.

The standard theoretical approach for TD learning typically assumes a unique solution point for the learned parameters. However, with arbitrary features, the underlying Bellman equations may have multiple solutions, forming a solution *set* rather than a single point. This non-uniqueness poses a significant challenge for traditional stochastic approximation analyses that rely on convergence to a unique fixed point. Therefore, a key motivation is to develop a robust analytical framework capable of characterizing and proving convergence *to a solution set*, rather than to a single point.

Furthermore, the paper explicitly aims to achieve these theoretical guarantees without introducing any modifications to the linear TD(λ) algorithm itself or imposing additional assumptions beyond those typically required for Markov chain ergodicity. This ensures that the results are directly applicable to the standard form of the algorithm already in use. The goal is to provide a unified theoretical understanding that matches the convergence rates of existing analyses that *do* assume feature independence, thereby demonstrating that this practical relaxation does not necessarily compromise performance guarantees.

### 3. Methodology and Approach

The core methodological contribution of this paper is the development of a novel stochastic approximation (SA) framework that enables the analysis of convergence to a *set* of solutions, rather than a single point, especially when the solution set can be unbounded. This generalized SA result (Theorem 3) is then specialized and applied to provide finite-sample L2 convergence rates for linear TD(λ) in both discounted and average-reward settings.

**Generalized Stochastic Approximation Framework (Theorem 3):**
The paper considers a general iterative update rule: $w_{t+1} = w_t + \alpha_t H(w_t, Y_{t+1})$, where $H$ is the incremental update function and $Y_t$ is a time-homogeneous Markov chain. The framework relies on several assumptions (A1-A5):
- **A1 (Lipschitz Continuity):** The update function $H$ is Lipschitz continuous with respect to $w$ and bounded at $w=0$.
- **A2 (Markov Chain Stationary Distribution):** The Markov chain $Y_t$ has a unique stationary distribution $d_Y$.
- **A3 (Solution Set Properties):** The solution set $W^*$ (defined by the expected update $h(w) = E[H(w, Y_t)]$) is non-empty, closed, and convex. Crucially, $W^*$ does not need to be bounded.
- **A4 (Lyapunov Function Decreasing Property):** There exists a constant $C_{A4} > 0$ such that $\langle \nabla L(w_t), h(w_t) \rangle \le -C_{A4} L(w_t)$, where $L(w) = \frac{1}{2} d(w, W^*)^2$ is a novel Lyapunov function defined as half the squared Euclidean distance from $w$ to the set $W^*$.
- **A5 (Bounds and Mixing Property):** This assumption introduces key technical elements to handle unbounded solution sets and Markovian noise. It states that $Xw^*$ is bounded for $w^* \in W^*$, $\|H(w,y)\|$ is bounded by $C_{A5}(\|Xw\|+1)$, and a geometric mixing property (decaying correlation) holds, bounded by $C_{A5}\tau^n (\|Xw\|+1)$. The reliance on $\|Xw\|$ rather than $\|w\|$ is critical as $W^*$ can be unbounded, but the value function $Xw^*$ is unique (or bounded).

The proof strategy for Theorem 3 involves:
1. **Lyapunov Function:** The function $L(w)$ is central. Its gradient $\nabla L(w) = w - \Gamma(w)$ (where $\Gamma(w)$ is the orthogonal projection of $w$ onto $W^*$) and its 1-smoothness property are leveraged.
2. **Recursive Bounding:** An inequality for $E[L(w_{t+1})]$ is derived based on $E[L(w_t)]$ by expanding $L(w_{t+1})$ and bounding terms related to the noise and expected update. This involves:
 - Bounding $\|H(w_t, Y_t)\|^2$ using Assumption A5 and Lemma 2 (which relates $\|Xw\|$ to $d(w, W^*)$).
 - Bounding the cross-term $\langle w_t - \Gamma(w_t), H(w_t, Y_t) - h(w_t) \rangle$ by decomposing it into three parts and utilizing Assumption A5's mixing property, along with a Lemma (Lemma 17) that bounds the difference between iterates $w_i - w_{t-\tau_{\alpha_t}}$.
3. **Gronwall-type Argument:** The derived recursive inequality for $E[L(w_t)]$ is then solved using techniques similar to the discrete Gronwall inequality, resulting in the stated L2 convergence rate.

**Application to Discounted TD(λ) (Theorem 1):**
1. **Mapping to SA:** The Discounted TD update is mapped to the SA form by defining $Y_{t+1} = (S_t, A_t, S_{t+1}, e_t)$ and $H(w,y) = (R_{t+1} + \gamma x(S_{t+1})^T w - x(S_t)^T w)e_t$. The expected update $h(w) = E[H(w,Y_t)]$ is shown to be $Aw+b$.
2. **Solution Set $W^*$:** The solution set $W^*$ is defined as $\{w | Aw+b=0\}$. Wang and Zhang previously established that $W^*$ is non-empty, closed, and convex.
3. **Negative Definiteness (Assumption A4):** It is shown that $h(w) = A(w - \Gamma(w))$ and that the matrix $A$ is negative definite on the orthogonal complement of its kernel ($\mathrm{ker}(A)^\perp$). This is critical because $w - \Gamma(w) \in \mathrm{ker}(A)^\perp$, directly satisfying Assumption A4: $\langle \nabla L(w), h(w) \rangle = (w - \Gamma(w))^T A (w - \Gamma(w)) \le -C_7 \|w - \Gamma(w)\|^2$.
4. **Assumption A5 Verification:** Lemma 8 and Lemma 18 verify the bounding and mixing properties, respectively, including the dependence on $\|Xw\|$.

**Application to Average-Reward TD(λ) (Theorem 2):**
This setting presents greater complexity due to the non-uniqueness of the differential value function (solutions are $v_\pi + c\mathbf{1}$).
1. **Feature Matrix Decomposition:** A novel decomposition of the feature matrix $X = X_1 + X_2$ is introduced. $X_1$ is constructed such that $\mathbf{1} \notin \mathrm{col}(X_1)$, and $X_2 = \mathbf{1}\theta^T$ is a rank-one matrix related to the all-ones vector. This decomposition simplifies the matrix $A$ in the Bellman equation to $A = X_1^T D_\pi (P_\lambda - I)X_1$.
2. **Characterizing $W^*$:** The decomposition is crucial for proving that $W^*$ is non-empty (Lemma 15) and for characterizing $W^*$ as $\{w^*\} + \mathrm{ker}(X_1)$, where $\mathrm{ker}(X_1) = \{w | Xw = c\mathbf{1}, c \in \mathbb{R}\}$. This elucidates how feature dependencies lead to a set of solutions, where vectors in $\mathrm{ker}(X_1)$ correspond to adding a constant to the value function approximation.
3. **Combined Parameter Vector:** The algorithm parameters $(\hat{J}_t, w_t)$ are combined into an extended vector $e\mathbf{w}_t = (\hat{J}_t, \Pi w_t)^T$, where $\Pi$ is the projection matrix onto $\mathrm{ker}(X_1)^\perp$. The update for $e\mathbf{w}_t$ is then shown to fit the SA framework (Lemma 9).
4. **Negative Definiteness (Assumption A4):** For this extended system, the expected update $h(e\mathbf{w})$ is formulated, and it's shown that the associated matrix $eA$ is negative definite on $\mathbb{R} \times \mathrm{ker}(X_1)^\perp$ when the learning rate scaling $c_\beta$ is sufficiently large (Lemma 10). This ensures Assumption A4 is met.
5. **Assumption A5 Verification:** Similar to the discounted case, modified versions of Assumption A5 are verified for the combined parameter vector, leveraging the feature decomposition and the boundedness of $e\mathbf{X}e\mathbf{w}^*$ (Lemma 11).
6. **Distance Relation:** A key observation (Lemma 20) links the distance to the extended solution set $fW^*$ with the individual errors: $d(e\mathbf{w}_t, fW^*)^2 = (\hat{J}_t - J_\pi)^2 + d(w_t, W^*)^2$.

By rigorously verifying all assumptions of the general SA theorem for both discounted and average-reward TD(λ), the paper provides a unified method to establish the desired finite-sample L2 convergence rates.

### 4. Main Findings and Results

The paper establishes significant theoretical advancements regarding the convergence of linear TD(λ) under more general conditions than previously available.

**1. General Stochastic Approximation Result (Theorem 3):**
The foundational finding is a novel stochastic approximation (SA) theorem that provides L2 convergence rates for iterative algorithms that converge to a *set* rather than a unique point. Specifically, for an algorithm $w_{t+1} = w_t + \alpha_t H(w_t, Y_{t+1})$ with learning rates $\alpha_t = \alpha/(t+t_0)^\xi$ ($\xi \in (0.5, 1]$), the expected squared distance to the solution set $W^*$ converges as:
$E[L(w_t)] \le C_{Thm3,1} \left(\frac{t_0}{t}\right)^{\lfloor\kappa\rfloor} L(w_0) + C_{Thm3,2} \frac{\ln(t+t_0)}{(t+t_0)^{\min(2\xi-1, \lfloor\kappa\rfloor-1)}}$.
Here, $L(w_t) = \frac{1}{2} d(w_t, W^*)^2$ is half the squared Euclidean distance to the set $W^*$, and $\kappa = \alpha C_{A4}$ relates to the step size and the negative definiteness of the expected update. This theorem is notable because it applies to possibly *unbounded* solution sets and accounts for Markovian noise, extending existing SA theory. For the common choice of $\xi=1$, the rate simplifies to $O(\ln t / t)$.

**2. Finite Sample Analysis for Discounted TD(λ) (Theorem 1):**
Leveraging the general SA result, the paper provides the first L2 convergence rate for linear TD(λ) with *arbitrary features* in the discounted setting ($\gamma < 1$). The iterates $w_t$ generated by the algorithm converge to the solution set $W^* = \{w | Aw+b=0\}$ with an L2 rate matching that of Theorem 3:
$E[d(w_t, W^*)^2] \le C_{Thm1} \left(\frac{t_0}{t}\right)^{\lfloor\kappa_1\rfloor} d(w_0, W^*)^2 + C_{Thm1} \frac{\ln(t+t_0)}{(t+t_0)^{\min(2\xi-1, \lfloor\kappa_1\rfloor-1)}}$.
For standard learning rate choices ($\xi=1$), this rate is $O(\ln t / t)$. Importantly, this rate is comparable to existing results that require the strong assumption of linearly independent features (e.g., Bhandari et al., Srikant and Ying), demonstrating that relaxing the feature independence assumption does not necessarily degrade the finite-sample performance guarantees. The paper notes that $Xw_t$ converges to a unique value estimate $\hat{v}_\pi = Xw^*$ (for any $w^* \in W^*$), which is the unique fixed point of a projected Bellman equation.

**3. Finite Sample Analysis for Average-Reward TD(λ) (Theorem 2):**
The paper also delivers the first L2 convergence rate for linear TD(λ) with *arbitrary features* in the average-reward setting ($\gamma=1$). The combined parameters $(\hat{J}_t, w_t)$ are shown to converge to a corresponding solution set $fW^*$ with an L2 rate:
$E[(\hat{J}_t - J_\pi)^2 + d(w_t, W^*)^2] \le C_{Thm2} \left(\frac{t_0}{t}\right)^{\lfloor\kappa_2\rfloor} [(\hat{J}_0 - J_\pi)^2 + d(w_0, W^*)^2] + C_{Thm2} \frac{\ln(t+t_0)}{(t+t_0)^{\min(2\xi-1, \lfloor\kappa_2\rfloor-1)}}$.
This rate, too, becomes $O(\ln t / t)$ for $\xi=1$. This extends the theoretical understanding of average-reward TD learning beyond scenarios with full-rank features, a significant contribution given the increased complexity of this setting.

**4. Empirical Validation:**
Experiments conducted on a variant of Boyan’s chain, intentionally designed with a rank-3 feature matrix (15 states, 5 actions, 5 features, but only 3 linearly independent features), empirically corroborate the theoretical findings. The results, as shown in Figures 1 and 2, demonstrate that the distance of the weight vector $w_t$ to the *set* of optimal weights $W^*$ indeed converges, supporting the conceptual shift from point convergence to set convergence. Different values of $\lambda$ and initial learning rates ($\alpha_0$) show varied convergence speeds, consistent with theoretical expectations.

### 5. Significance and Potential Impact

The significance of this work lies in addressing a long-standing theoretical gap in reinforcement learning, fulfilling a desideratum recognized since the early days of temporal difference learning research. By providing the *first* finite-sample L2 convergence rates for linear TD(λ) under *arbitrary features* in both discounted and average-reward settings, this paper significantly broadens the theoretical understanding and applicability of these fundamental algorithms.

**1. Relaxation of Restrictive Assumptions:** The most immediate impact is the removal of the linear independence assumption on features. This assumption has been a barrier to applying theoretical guarantees in many practical scenarios where features might be redundant, overcomplete, or difficult to verify for independence (e.g., in continual learning, online learning, or complex control systems with rich feature representations). The new results allow practitioners to use standard linear TD(λ) without concern for feature rank, knowing that convergence and its rate are guaranteed.

**2. Advancement in Stochastic Approximation Theory:** The development of Theorem 3, a general stochastic approximation result for convergence to a potentially unbounded *set*, is a significant theoretical contribution in its own right. Most prior SA work focuses on convergence to a single point or a bounded set. This extension provides a powerful tool for analyzing a wider class of algorithms, especially in optimization and control, where solution sets are common. The novel use of a Lyapunov function based on the distance to a set is a methodological breakthrough with broad applicability.

**3. Unified Framework for Diverse Settings:** The paper's ability to provide a unified theoretical framework that applies to both discounted and average-reward settings, traditionally analyzed separately due to their distinct characteristics, highlights the robustness of the new methodology. This streamlined approach simplifies the landscape of TD learning theory.

**4. Practical Implications:**
 - **Increased Confidence:** Researchers and engineers can apply linear TD(λ) with greater confidence in diverse real-world applications, even when feature dependencies are present or unknown.
 - **Benchmarking:** The derived L2 convergence rates (e.g., $O(\ln t / t)$ for standard step sizes) provide a benchmark for evaluating the performance of TD(λ) and related algorithms in settings with arbitrary features. It shows that, at least asymptotically with respect to time, the performance rate does not suffer from feature dependencies.

**5. Foundational for Future Research:** The techniques developed in this work—particularly the novel Lyapunov function and the feature matrix decomposition for the average-reward setting—are presented as transferable to the analysis of other linear reinforcement learning algorithms. This opens avenues for extending finite-sample guarantees to a broader suite of linear RL methods (e.g., Q-learning, Sarsa, Actor-Critic variants) under arbitrary features. The paper explicitly outlines several future directions, including extending the analysis to non-linear function approximation (e.g., Neural Tangent Kernels), establishing other convergence modes (e.g., almost sure, L_p, high-probability bounds), and integrating advanced averaging techniques like Polyak-Ruppert averaging for improved rates.
