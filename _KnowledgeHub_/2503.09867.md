# Oh-A-DINO: Understanding and Enhancing Attribute-Level Information in Self-Supervised Object-Centric Representations

> [!summary] Summary
> OH-A-DINO addresses the deficiency of self-supervised vision models and slot-based methods in capturing non-geometric object attributes by augmenting DINOv2 features with VAE-learned object-level latents. This method achieves superior multi-object instance retrieval performance, reaching 56.4% Top-10 Precision on the CLEVR dataset, substantially outperforming existing baselines.

## Problem

- State-of-the-art self-supervised vision models (e.g., DINOv2, CLIP) and slot-based methods (e.g., SlotDiffusion) struggle to reliably capture non-geometric object attributes like color, material, and texture in multi-object scenes.
- This limitation leads to systematic errors in fine-grained object disambiguation, impacting critical downstream tasks such as instance retrieval, robotic manipulation, and goal-conditioned policies.
- Enhancing these representations typically involves computationally expensive retraining of large backbone models, which is often impractical.

## Method

- The ==Object-Aware-DINO (OH-A-DINO)== method augments features from a pre-trained ==DINOv2 model== with ==object-centric latent vectors==, offering a modular and efficient enhancement strategy.
- A ==PCA-based segmentation procedure== isolates individual object patches from images, which are then used to train a Variational Autoencoder (VAE) to learn fine-grained, attribute-level latent representations.
- The global scene feature (DINOv2 CLS token) is concatenated with the VAE-learned latent vector for each object patch to create a robust combined representation that integrates both global context and fine-grained attributes.

## Results

- OH-A-DINOv2 achieved **56.4%** Top-10 Precision for multi-object instance retrieval on CLEVR, a significant improvement over DINOv2 (**13.0%**), DINOv3 (**13.7%**), CLIP (**14.7%**), and SlotDiffusion (**12.0%**).
- The method demonstrated substantial gains in matching non-geometric attributes, with OH-A-DINOv2 achieving **96.6%** precision for color on CLEVR, compared to DINOv2's **40.8%**.
- On the real-world Stanford Cars dataset, OH-A-DINOv2 showed improved color consistency with a lower average Euclidean distance to reference color (0.432) compared to DINOv2 (0.512) and CLIP (0.524).

## Takeaways

> [!tip] Key Insights
> - Self-supervised vision models effectively capture geometric attributes (shape, size) but consistently fail to preserve non-geometric surface-level cues (color, material), leading to poor performance in attribute-level disambiguation.
> - Simply scaling up self-supervised models (e.g., from DINOv2-S to DINOv2-L) does not inherently resolve the bottleneck in capturing fine-grained attribute information.
> - A lightweight, modular augmentation strategy, such as combining global context with dedicated object-level latent learning, can effectively recover missing attribute information without costly retraining of the backbone model.
