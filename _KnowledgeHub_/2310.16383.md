# Open-NeRF: Towards Open Vocabulary NeRF Decomposition

> [!summary] Summary
> Open-NeRF decomposes Neural Radiance Fields by open-vocabulary text queries. It uses an integrate-and-distill paradigm: GroundingDINO proposes regions, SAM turns them into masks, SAM-Track aligns masks of the same object across views, per-object openclip embeddings are fused, then distilled into a direction-independent embedding field with hierarchical object/part/background levels. It beats LERF on AUPRC and FPR95 across scenes.

## Problem

- Instance-decomposition NeRFs learn semantic or per-object codes but need ground-truth 2D mask annotations, making labeling cost prohibitive for real-world scenes.
- Feature-distillation fields using LSeg or DINO features are confined to closed-set classes like COCO, and fail on novel or long-tail in-the-wild objects.
- Language-grounded fields locate open-vocabulary queries only approximately, so flexible querying and accurate 3D segmentation remain a trade-off nobody resolves.

## Method

- ==Integrate-and-distill paradigm==: region proposals prompt ==SAM== for masks, a tracking model assigns per-pixel object IDs by majority vote inside each mask, aligning the same object across viewpoints.
- Per-object embedding fusion: crop sub-images per mask, encode with ==openclip==, sum and renormalize embeddings so fused vectors stay unit-norm for dot-product text relevancy, then paint them per-pixel.
- Open-vocabulary embedding field: an extra ==direction-independent NeRF branch== trained by ==Huber distillation loss== with weight 0.1, plus hierarchical object/part/background levels backfilled by ==LSeg==.

## Results

- Mean AUPRC rises over LERF by **26.3** points on Toy-1, **24.8** on Kitchen, **23.2** on Toy-3 and **32.2** on Car, with FPR95 falling correspondingly.
- Long-tail queries improve most: 'Lava Monster' AUPRC goes **21.3** to **86.5**, 'Harry Potter' **60.1** to **91.2**; Desktop mean AUPRC **78.8** to **88.9**.
- Ablating multi-view integration drops Kitchen mean AUPRC from **80.7** to **66.6**, with 'Glasses' falling **78.2** to **63.1**, confirming integration drives occlusion robustness.

## Takeaways

> [!tip] Key Insights
> - Fuse foundation-model outputs across views before distilling into 3D; per-view distillation inherits each view's recognition and granularity inconsistencies as field noise.
> - Keep semantic fields direction-independent, like density, so an object's identity cannot change with viewing angle during volume rendering.
> - Hierarchical object/part/background embeddings let one field answer queries at multiple scales, but background still needs a dense per-pixel extractor.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Neural Radiance Fields (NeRFs) have advanced 3D reconstruction and novel view synthesis by representing scenes as continuous 5D radiance fields. While NeRFs excel at rendering, manipulating individual objects within these reconstructed scenes—such as extraction, removal, or alteration—necessitates decomposing the 3D field into its constituent objects. This decomposition is the focus of the current work.

Existing approaches to NeRF decomposition exhibit varying capabilities and limitations. Some methods (e.g.,) learn semantic information or unique object codes by introducing auxiliary field components. However, these often depend on extensive 2D ground-truth mask annotations, incurring significant labeling costs. Other techniques, such as Feature Field Distillation (FFD) and N3F, distill 2D image features from pre-trained extractors like OpenCLIP-LSeg and DINO into the 3D field. While these methods can localize objects, they are typically restricted to closed-set scenarios, meaning they can only recognize objects from a predefined set of classes (e.g., those found in datasets like COCO).

More recent advancements, such as Language Embedded Radiance Fields (LERF), have sought to overcome the closed-set limitation by grounding language embeddings from models like OpenCLIP into NeRFs. This enables locating objects based on open-vocabulary queries. However, LERF primarily provides approximate object locations and lacks the capability for precise 3D segmentation, which limits its utility for fine-grained object manipulation.

In parallel, the field of 2D segmentation has seen progress with the advent of large-scale, off-the-shelf models like the Segment Anything Model (SAM). SAM, trained on the extensive SA-1B dataset, can generate mask proposals for open-world images. This capability presents an opportunity to inform 3D decomposition with flexible 2D segmentation. However, directly transferring SAM’s 2D knowledge to 3D NeRFs introduces inconsistencies across different viewpoints, manifesting as variable recognition confidence due to occlusion or indistinct features, and inconsistent mask granularity for the same object when viewed from different angles (Figure 3).

This research positions itself within this landscape by addressing the inherent trade-off in current NeRF decomposition methods between the flexibility of open-vocabulary query processing and the accuracy of 3D segmentation. It aims to leverage the open-world segmentation capabilities of models like SAM while mitigating their cross-view inconsistency issues to achieve both precise 3D segmentation and flexible open-vocabulary querying.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a method for decomposing Neural Radiance Fields (NeRFs) into objects that can be identified using open-vocabulary queries, while simultaneously achieving high accuracy in 3D segmentation.

The motivation for pursuing this objective stems from several challenges and opportunities within the field of 3D scene understanding and manipulation:

- **Enabling Object Manipulation in 3D Scenes:** For practical applications such as augmented reality, robotics, or content creation, it is crucial to interact with individual objects within a 3D reconstruction. This necessitates the ability to isolate and precisely segment specific objects from the broader scene represented by a NeRF. Without effective decomposition, object-level editing or interaction remains challenging.
- **Addressing Limitations of Existing Decomposition Methods:**
 - **High Annotation Costs:** Many earlier NeRF decomposition techniques rely on costly 2D ground-truth mask annotations for supervision, which limits their scalability and applicability to diverse real-world scenes.
 - **Closed-Set Restrictions:** Feature distillation methods, while effective for predefined categories, are unable to handle "out-of-distribution" or novel objects encountered in open-world scenarios. This constrains their use in real-time or dynamic environments where object types are not known beforehand.
 - **Lack of Segmentation Precision for Open-Vocabulary Queries:** While methods like LERF have introduced open-vocabulary querying to NeRFs, they primarily provide approximate localization rather than precise 3D segmentation. This imprecision hinders applications requiring accurate object boundaries for tasks such as object extraction or modification.
- **Leveraging Advancements in 2D Foundation Models:** The emergence of powerful 2D segmentation models, such as SAM, presents a significant opportunity. SAM can generate mask proposals for arbitrary objects in images without prior training on specific classes, making it suitable for open-world scenarios. This capability motivates exploring how such 2D knowledge can be integrated into 3D NeRFs.
- **Overcoming 2D-to-3D Knowledge Transfer Challenges:** A direct distillation of 2D mask proposals from models like SAM into a 3D field is problematic due to inconsistencies across different viewpoints. Specifically:
 - **Recognition Inconsistency:** An object's recognition confidence can vary significantly across viewpoints due to factors like occlusion or a lack of distinctive features from certain angles.
 - **Granularity Inconsistency:** SAM may generate masks with differing levels of detail or completeness for the same object when viewed from various perspectives, leading to fragmented or inconsistent 3D representations.
 Addressing these inconsistencies is critical to building a robust 3D decomposition system.

By achieving precise open-vocabulary NeRF decomposition, this work aims to enable novel applications in fields such as robotics for more intelligent object interaction, and vision-language interaction for intuitive control and understanding of complex 3D environments.

### 3. Methodology and Approach

The proposed method, Open-vocabulary Embedded Neural Radiance Fields (Open-NeRF), introduces an "integrate-and-distill" paradigm combined with hierarchical embeddings to achieve accurate 3D segmentation based on open-vocabulary queries. The approach involves several interconnected stages:

#### 3.1. Integrate-And-Distill Paradigm

This paradigm comprises three primary steps:

1. **2D Knowledge Extraction:**
 - Given a collection of input images and their corresponding camera parameters, the system first generates 2D mask proposals.
 - A region proposal generator, specifically **GroundingDINO** with a Swin-B backbone, is utilized to produce bounding box proposals for objects within each image.
 - These bounding boxes then serve as prompts for the **Segment Anything Model (SAM)** (using the `sam-vit-h-4b8939` checkpoint) to generate precise 2D mask proposals.
 - Sub-images are cropped according to these mask proposals.

2. **Multi-view Knowledge Integration:**
 - **Proposals Alignment:** To ensure consistency across different viewpoints, mask proposals belonging to the same physical object in 3D space must be aligned. **SAM-Track** is employed for this purpose, tracking objects and background regions across frames and providing per-pixel ID predictions. Rather than directly using the tracking model's segmentation, the method counts the frequency of pixel IDs within each SAM-generated mask proposal and assigns the dominant ID to the entire mask, thereby aligning proposals from different views to the same object.
 - **Embedding Fusion:** For each identified object ($O_j$) that appears in multiple views, a set of corresponding sub-images is collected. These sub-images are fed into the image encoder of **OpenCLIP** (ViT-B-32-quickgelu version, trained on LAION-400M) to obtain normalized image embeddings. To integrate the knowledge from these multi-view embeddings for a single object, they are averaged and then re-normalized to produce a single, fused per-object embedding ($E_{f_j}$). This fusion process aims to create a consistent and robust object representation that is less susceptible to viewpoint-dependent variations.
 - **Per-Pixel Embedding Generation:** The fused per-object embeddings ($E_{f_j}$) are then assigned to all pixels within their corresponding mask proposals in the 2D images, resulting in per-pixel image embeddings ($E$).

3. **Knowledge Distillation into 3D Fields:**
 - **Open-Vocabulary Embedding Field:** An additional branch, termed the "open-vocabulary embedding field," is integrated into the NeRF model architecture. This branch is designed to predict a view-independent feature vector, $e(x_n)$, for any given 3D coordinate $x_n$.
 - **Volume Rendering for Embeddings:** Similar to how NeRF renders color and density, the predicted 3D field embeddings are aggregated along camera rays using volume rendering techniques. This process yields a rendered per-pixel field embedding ($\hat{E}(r)$) for each ray. Importantly, the embedding function $e$ is direction-independent, ensuring that the semantic information of an object remains constant regardless of the viewing direction.
 - **Optimization:** The NeRF model is optimized using a composite loss function: $L = L_p + \lambda L_e$.
 - $L_p$ is a photometric loss (Mean Squared Error) between the ground-truth image colors and the rendered colors.
 - $L_e$ is a distillation loss (Mean Huber loss) calculated between the rendered field embedding ($\hat{E}(r)$) and the corresponding per-pixel integrated image embedding ($E[h,w]$) obtained in the previous step. The weighting parameter $\lambda$ is set to 0.1.
 - To prevent interference with the original NeRF's ability to render scenes, the embedding field operates independently, meaning $L_e$ solely optimizes the embedding branch.

#### 3.2. Hierarchical Embedding

Open-NeRF employs a hierarchical embedding strategy to support queries at different scales and granularities. This involves extracting image embeddings at three distinct levels:

- **Object Level:** Region proposal generation (GroundingDINO) identifies complete objects.
- **Part Level:** Similar region proposal techniques are used, but at finer granularities, to identify parts of objects.
- **Background Level:** For expansive and amorphous background regions (e.g., grass, sky), conventional region proposal methods are less effective. Instead, a per-pixel feature extractor, **LSeg**, is directly utilized due to its strong performance on a comprehensive set of background categories.
Per-pixel embeddings are first assigned for identified objects and parts. For any remaining unassigned pixels, embeddings generated by OpenCLIP-LSeg are used directly. This combined approach creates a hierarchical representation within the 3D field, allowing for varying levels of detail in decomposition. During inference, the system can automatically select the appropriate level (object or part) based on relevancy scores, favoring part-level predictions if a sufficient number of pixels demonstrate higher relevancy at that level (default N=100 pixels).

#### 3.3. Open-vocabulary Querying

To enable open-vocabulary queries, Open-NeRF calculates relevancy scores between a given text query and the learned 3D embeddings:

- A text encoder from **OpenCLIP** converts the input query $q$ into a normalized text embedding $e_t(q)$.
- For any 3D coordinate $x_n$, the relevancy score $S_r(x_n)$ is computed as the dot product between its field embedding $e(x_n)$ and the query embedding $e_t(q)$.
- For 2D segmentation of novel views, the rendered field embedding $e_r(r)$ for a given ray $r$ is used to calculate the relevancy score via a dot product with $e_t(q)$.
- NeRF decomposition is then performed by applying a threshold to these relevancy scores to determine which 3D points belong to the queried object. The model dynamically selects the optimal hierarchical level (object, part, or background) for a query by comparing the maximum relevancy scores from each level.

### 4. Main Findings and Results

The experimental evaluation of Open-NeRF demonstrates its capabilities in open-vocabulary NeRF decomposition, comparing it against state-of-the-art methods such as LERF and LSeg-based approaches like FFD. The evaluation used both established datasets and a custom dataset of 10 diverse real-world scenes, including environments like offices, markets, bookstores, and natural landscapes, featuring numerous long-tail objects.

#### 4.1. Quantitative Results

Open-NeRF consistently outperformed LERF across multiple metrics, particularly in open-vocabulary scenarios involving common and long-tail objects.

- **AUPRC (Area Under the Precision-Recall Curve):** Open-NeRF achieved higher AUPRC scores across nearly all tested scenes and objects. For instance, in the 'Toy-1' scene, it improved the AUPRC for 'Lego' by 26.3%. In the 'Kitchen' and 'Garden' scenes, the mean AUPRC saw an increase of 9.8%. For challenging long-tail objects, Open-NeRF achieved 86.5% AUPRC for 'Lava Monster' compared to LERF's 21.3%, and 91.2% for 'Harry Potter' versus LERF's 60.1%. In the 'Desktop' scene (Table 2 in paper), Open-NeRF consistently showed better AUPRC, for example, 94.5% for 'iPhone' (LERF: 83.3%) and 91.2% for 'VR Glasses' (LERF: 73.6%), leading to a mean AUPRC improvement of 10.1%.
- **FPR95 (False Positive Rate at 95% True Positive Rate):** Open-NeRF exhibited a lower FPR95, indicating more precise segmentation with fewer false positives. For 'Lava Monster', Open-NeRF's FPR95 was 3.8% compared to LERF's 47.0%. In the 'Desktop' scene, Open-NeRF significantly reduced FPR95 for objects like 'Wireless Mouse' (1.3% vs. 42% for LERF) and 'Apple Watch' (4.3% vs. 21.3% for LERF), achieving a mean FPR95 of 3.32% compared to LERF's 10.15%.

#### 4.2. Qualitative Results

Visually, Open-NeRF demonstrated superior performance in NeRF decomposition.

- **Segmentation Accuracy:** Open-NeRF generated accurate segmentations for both common and novel objects, irrespective of the viewpoint. In contrast, LERF provided only approximate localizations.
- **Open-Vocabulary Flexibility:** Open-NeRF showed the ability to locate objects based on diverse open-vocabulary queries, including product names, brands (e.g., "Gucci" for a purse), colors (e.g., "Yellow Box" for a candy box), and specific text inscriptions.
- **Hierarchical Understanding:** The method displayed versatility in grouping objects (e.g., identifying multiple items as "Toys") or segmenting them individually with more specific queries. It also successfully decomposed entire objects (e.g., "car") into their parts (e.g., "wheels," "license plate").

#### 4.3. Ablation Study

An ablation study specifically on the integration procedure within the integrate-and-distill paradigm highlighted its importance.
- Incorporating the integration step significantly improved performance, particularly for scenes containing occluded objects or those difficult to recognize from certain perspectives. For example, the 'Glass of Water' achieved 78.2% AUPRC with integration, versus 63.1% without. Similarly, the 'Lego Excavator' in the 'Kitchen' scene showed a 13% improvement in AUPRC due to the integration procedure. This reinforces the contribution of consolidating multi-view 2D knowledge.

#### 4.4. Limitations of LSeg-based Methods

The paper noted that methods based on LSeg, such as FFD, struggled to provide satisfactory results for open-world scenes with novel objects or complex open-vocabulary queries. While CLIP-LSeg performed acceptably for common background elements (e.g., 'table', 'vase', 'grass'), it failed to segment novel objects like 'football' or 'Lava Monster', and could not effectively respond to queries like 'Gucci' or 'Yellow Boxes'. Consequently, 3D decomposition methods relying on LSeg similarly failed in these challenging scenarios.

#### 4.5. NeRF Decomposition and Editing Applications

Open-NeRF's ability to generate accurate 3D decomposition results was visually demonstrated for queries like 'Lego excavator' and 'rabbit toy'. Furthermore, the practical utility of the decomposition was shown through query-guided texture modifications, transforming objects (e.g., a 'table' or 'table and vase') to a 'frozen' style based on the decomposition outputs.

### 5. Significance and Potential Impact

The research on Open-NeRF represents a notable contribution to the field of 3D computer vision and NeRF-based scene understanding, with several areas of significance and potential impact:

- **Bridging the Gap in NeRF Decomposition:** Open-NeRF successfully addresses a recognized trade-off in NeRF decomposition between the flexibility of open-vocabulary querying and the accuracy of 3D segmentation. By providing a method that achieves both, it moves beyond the limitations of prior techniques that either required costly manual annotations, were restricted to closed-set categories, or provided only approximate object localization.
- **Enhanced 3D Scene Understanding and Interaction:** The ability to decompose 3D scenes into precise, queryable objects based on natural language enables a more nuanced and interactive understanding of reconstructed environments. This includes identifying objects by their descriptive attributes (brand, color, material, text) and handling queries at different granularities (whole objects or parts).
- **Robustness in Challenging Scenarios:** The "integrate-and-distill" paradigm, particularly the multi-view knowledge integration, enhances the robustness of object recognition and segmentation. This approach mitigates issues of viewpoint inconsistency, such as partial occlusion or indistinct features, which previously hindered the direct application of 2D segmentation models to 3D.
- **Enabling Advanced Applications:**
 - **Robotics:** More accurate 3D object decomposition can facilitate precise object manipulation, grasping, and interaction for robotic systems operating in complex, unstructured environments.
 - **Vision-Language Interaction:** It paves the way for more intuitive and natural language-driven control and querying of 3D scenes, benefiting applications in virtual reality, augmented reality, and human-computer interfaces.
 - **3D Content Creation and Editing:** The demonstrated capability for query-guided texture modifications illustrates how Open-NeRF can serve as a foundation for advanced 3D scene editing, enabling users to modify specific objects within a NeRF using text prompts.
- **Effective Integration of Foundation Models:** The work showcases a methodology for effectively integrating multiple large-scale, off-the-shelf foundation models (SAM, OpenCLIP, GroundingDINO, SAM-Track) into a coherent framework for a complex 3D task. This approach capitalizes on the strengths of these models and suggests a general paradigm for leveraging advancements in 2D perception for 3D reconstruction and understanding.
- **Future Scalability:** As the performance of underlying foundation models like OpenCLIP and SAM continues to improve, Open-NeRF is positioned to benefit from these advancements, suggesting a path for continuous enhancement without requiring fundamental architectural changes.

In summary, Open-NeRF offers a promising solution to a critical challenge in 3D vision, facilitating a new generation of applications that require flexible, precise, and semantically rich interaction with reconstructed 3D environments.
