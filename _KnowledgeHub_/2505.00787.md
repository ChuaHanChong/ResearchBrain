# Constructing an Optimal Behavior Basis for the Option Keyboard

> [!summary] Summary
> The Option Keyboard Basis (OKB) method constructs an optimal behavior basis for the Option Keyboard, enabling autonomous agents to find optimal solutions for any linear multi-task reinforcement learning problem in a zero-shot manner. This approach achieves optimality with potentially fewer base policies than existing Convex Coverage Set methods and demonstrates the capacity to optimally solve certain classes of non-linear tasks.

## Problem

- Existing multi-task reinforcement learning methods like Generalized Policy Improvement (GPI) do not guarantee optimal solutions for novel tasks.
- Convex Coverage Set (CCS) methods, which guarantee optimality for linear tasks, suffer from computational expense and poor scalability, as the number of required policies grows exponentially with reward features.
- The Option Keyboard (OK) method offered enhanced expressivity but lacked a principled way to construct an optimal set of base policies, limiting its potential for efficient zero-shot optimal transfer.

## Method

- The **Option Keyboard Basis** (OKB) algorithm iteratively builds a minimal set of ==base policies== and trains an associated meta-policy to achieve optimality for any linear task.
- OKB identifies "corner weights" from the current policy set that are not optimally covered by the Option Keyboard, then learns new optimal base policies for these under-represented tasks.
- The method employs Successor Features (SFs) and a Universal SF Approximator (USFA) to efficiently represent and combine policies, along with an actor-critic framework for meta-policy training.

## Results

- In multi-task environments like Minecart and Highway, OKB consistently achieved near-optimal performance with significantly fewer base policies (e.g., 2-3) compared to the state-of-the-art SFOLS method.
- OKB demonstrated superior scalability in the FetchPickAndPlace domain, where its performance advantage over SFOLS notably increased as the number of reward features grew from 2 to 8.
- The method successfully solved a non-linear sequential reward task in the Item Collection domain, outperforming a specialized non-linear method (SIP) and a Deep Q-Network baseline, empirically validating its expanded applicability.

## Takeaways

> [!tip] Key Insights
> - OKB constructs a behavior basis that allows the Option Keyboard to achieve an expressiveness at least equivalent to a Convex Coverage Set, guaranteeing zero-shot optimality for all linear tasks with potentially fewer base policies.
> - The Option Keyboard with an OKB-derived basis is strictly more expressive than a CCS, enabling optimal solutions for specific classes of non-linear tasks that can be represented as state-dependent switches between optimal linear policies.
> - The iterative selection of base policies based on identified "corner tasks" is crucial for the efficiency and optimality guarantees of the OKB method, outperforming uniform task sampling.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of reinforcement learning (RL) has achieved success in complex sequential decision-making problems, but traditional RL algorithms often require extensive environmental interaction to learn a single policy for a single task. Multi-task RL addresses this limitation by aiming to enable agents to identify solutions for new tasks with minimal or no additional interactions, often by learning and combining specialized base policies.

One approach for combining policies in a zero-shot manner leverages successor features (SFs) and Generalized Policy Improvement (GPI). GPI can combine a set of base policies to produce a new policy that is at least as effective as any individual base policy for a novel task. However, GPI-derived policies are not guaranteed to be optimal. For tasks expressible as a linear combination of reward features, optimality can be ensured by computing a Convex Coverage Set (CCS), which is a set of policies that includes an optimal policy for any linear task. A significant challenge with CCS-based methods is their computational expense and scalability limitations, as the number of policies in a CCS can grow exponentially with the number of reward features, making them impractical for complex domains.

The Option Keyboard (OK) method extends GPI by employing a learned meta-policy that dynamically combines base policies by assigning state-dependent linear weights to reward features. This mechanism allows the OK to represent a broader range of behaviors than GPI and potentially solve tasks beyond those with linear rewards. However, the performance of the OK is critically dependent on the selection of its underlying base policies. Existing OK-based methods typically assume a predefined set of base policies or rely on expert knowledge, without providing a principled mechanism for constructing an optimal set. This gap in the literature represents an open problem: the identification of an optimal behavior basis for the OK that can guarantee zero-shot identification of optimal solutions for any linear tasks. This paper addresses this specific open problem.

### 2. Key Objectives and Motivation

The primary objective of this research is to solve the open problem of constructing an optimal behavior basis for the Option Keyboard (OK) that enables zero-shot identification of optimal solutions for any linear task. This overarching goal is broken down into several specific objectives and is motivated by current limitations in multi-task reinforcement learning.

**Key Objectives:**

- **Develop an Efficient Construction Method:** Introduce a novel method, termed Option Keyboard Basis (OKB), designed to efficiently identify an optimal behavior basis for the OK.
- **Guarantee Optimality for Linear Tasks:** Prove that the OKB-constructed behavior basis allows the OK to optimally solve any task within the family of linearly expressible reward functions (i.e., that it can express all policies found within a Convex Coverage Set).
- **Reduce Base Policy Count:** Demonstrate that OKB significantly reduces the number of base policies required to ensure zero-shot optimality in new tasks compared to existing approaches, thereby addressing the scalability issues of methods like CCS.
- **Enhance Expressivity for Non-linear Tasks:** Provide a theoretical proof that OKB is strictly more expressive than a CCS, enabling specific classes of non-linear tasks to be solved optimally. This expands the capabilities of multi-task RL beyond strictly linear reward functions.
- **Empirical Validation:** Empirically evaluate the OKB method in challenging, high-dimensional reinforcement learning domains to demonstrate its performance advantage over state-of-the-art GPI-based approaches, particularly as task complexity increases.

**Motivation:**

- **Addressing Sample Inefficiency:** Traditional RL requires extensive interactions to learn a single task. Multi-task RL aims to improve sample efficiency and generalization, and developing a robust behavior basis is central to this.
- **Limitations of GPI:** While Generalized Policy Improvement (GPI) enables policy combination, it does not guarantee optimality for new tasks.
- **Scalability Issues of CCS:** Convex Coverage Sets (CCS) offer optimality guarantees for linear tasks but suffer from significant computational costs and poor scalability, with the number of required policies potentially growing exponentially with the number of reward features. This bottleneck prevents their application in complex, high-dimensional scenarios.
- **Unrealized Potential of OK:** The Option Keyboard (OK) offers enhanced expressivity over GPI by using a learned meta-policy. However, without a principled method for selecting its base policies, the full potential of the OK for efficient and optimal transfer learning remains unrealized. A systematic way to construct its behavior basis is necessary to unlock its capabilities, especially for linear tasks and certain non-linear ones.
- **Demand for Broader Task Solvability:** Current methods are often confined to linear reward functions. The ability to optimally solve certain non-linear tasks with minimal additional learning would represent a significant advancement, motivating the exploration of OK's extended expressivity.

### 3. Methodology and Approach

The Option Keyboard Basis (OKB) method is introduced to construct an optimal behavior basis for the Option Keyboard (OK) and its associated meta-policy. The methodology iteratively builds a set of base policies and trains a meta-policy to ensure optimal task solutions.

**Core Algorithm (OKB – Algorithm 1):**
OKB begins by initializing with a single base policy optimized for an arbitrary starting task, establishing an initial set of base policies (Π) and their corresponding Successor Features (SFs). It maintains two partial Convex Coverage Sets (CCSs): Ψ_base for the SFs of the base policies and Ψ_OK for the policies generated by the OK using the current base policies. An empty set `W_sup` is also initialized to store weights of tasks the meta-policy has been trained on.

The algorithm proceeds in an iterative loop:

1. **Meta-Policy Update (OK-LS – Algorithm 2):** In each iteration, OKB calls the `OK-LS` subroutine to update the meta-policy (`ω`).
 - `OK-LS` identifies "corner weights" from the current partial CCS (`Ψ_OK`) that have not yet been used for training. Corner weights are crucial because, if optimal policies exist for all corner weights, then optimality is ensured for all linear tasks.
 - These newly identified corner weights are added to `W_sup`, the set of tasks used to train the meta-policy.
 - The `TrainOK` subroutine (Algorithm 3) is then invoked to train the meta-policy `ω` using the base policies `Π_k` and the tasks in `W_sup`. `TrainOK` employs an actor-critic RL framework. The critic learns the action-value function of the meta-policy, and the actor updates `ω` via policy gradients. Exploration is managed by adding clipped Gaussian noise to the meta-policy's output. The OK policy, `π_OK_ω`, is defined as `arg max_a∈A max_π∈Π ψ_π(s, a) · ω(s)`.
 - After training `ω`, `OK-LS` computes the SF vectors of the policies induced by the OK for each task in `W_sup`, updating `Ψ_OK`.
 - Redundant policies are removed from `Ψ_OK` using `RemoveDominated`. This `OK-LS` loop continues until no new corner weights are identified for training.

2. **Base Policy Augmentation:**
 - Following the meta-policy update, OKB identifies a set of candidate tasks (`C`) that the OK, with its current base policies `Π_k` and meta-policy `ω`, cannot optimally solve. This is determined by verifying if the optimal policy for a task `w` (`π_∗_w`) is expressible by `Π_OK(Π_k)`.
 - **Condition for OK Optimality (Theorem 4.2):** This condition is checked by examining the advantage function `A_ω_∗_r (s, a)`. If `A_ω_∗_r (s, a) > 0` for any `(s, a)`, it indicates that the current OK policy cannot represent an optimal action for task `r`, implying suboptimality. This check helps prioritize which tasks require new base policies. In practice, a mean positive advantage over sampled experiences is calculated.
 - If `C` is empty, it means the current `Π_k` and `ω` can optimally solve all linear tasks, and the algorithm terminates.
 - If `C` is not empty, a task `w` is selected from `C` (e.g., the one with the highest positive advantage for `ω`), and a new optimal base policy (`π_w`) is learned for this task. This new policy is added to `Π_k` and its SFs to `Ψ_base`.
 - `RemoveDominated` is applied to `Π_k` and `Ψ_base` to eliminate redundant base policies that do not uniquely contribute to solving any task.

**Successor Features and Universal SF Approximators:**
The method relies on Successor Features (SFs) to efficiently perform Generalized Policy Evaluation (GPE) and Generalized Policy Improvement (GPI), assuming reward functions are linear with respect to reward features `ϕ(s, a, s′)`. In the experimental evaluation, a Universal SF Approximator (USFA) is used. Instead of training a separate neural network for each base policy's SFs, a single USFA `ψ(s, a, w)` is trained, conditioned on task vectors `w`. This approach aims to reduce memory and computational costs while maintaining approximation quality.

**Experimental Setup:**
Experiments are conducted in various challenging domains (Minecart, FetchPickAndPlace, Item Collection, Highway) with high-dimensional state spaces. Comparisons are made against SFOLS (a state-of-the-art GPI-based method for CCS construction) and OKB-Uniform (an OKB variant where tasks for base policy learning are selected uniformly, rather than based on the `C` set). To ensure fair comparison, OKB is constrained to allocate half its budget to learning base policies and the other half to meta-policy training. Performance is evaluated using mean normalized returns and 95% bootstrapped confidence intervals across 15 random seeds.

### 4. Main Findings and Results

The research presents both theoretical guarantees and empirical validations for the Option Keyboard Basis (OKB) method.

**Theoretical Findings:**

- **Optimal Behavior Basis for Linear Tasks (Theorem 4.3):** OKB is proven to return a set of base policies (`Π_k`) and a meta-policy (`ω`) such that `|Π_k| ≤ |CCS|` and the induced OK policy (`π_OK_ω (·; Π_k)`) is optimal for any linearly expressible task (`M ∈ M_ϕ_lin`). This implies that the expressiveness of the OK with the OKB-derived basis is at least equal to that of a Convex Coverage Set (`CCS ⊆ Ψ_OK(Π_k)`), guaranteeing zero-shot optimality for all linear tasks. A key aspect of this finding is that OKB can achieve this with a number of base policies potentially smaller than the size of the full CCS, addressing a major scalability limitation of previous CCS-based methods.
- **Enhanced Expressivity for Non-linear Tasks (Proposition 4.4):** OKB is shown to be strictly more expressive than a CCS. It can optimally solve certain classes of non-linear tasks. Specifically, if the optimal policy for a non-linear task `r` can be expressed by alternating, as a function of the state, between policies that are themselves optimal for some linear task (i.e., policies in the CCS induced by `ϕ`), then the OK using the `Π_k` learned by OKB can represent this optimal policy. This expands the applicability of OKB beyond strictly linear reward functions.
- **Robustness to Approximation Errors:** The paper extends previous work on GPI's optimality gap (Theorem 4.5). It is noted that since OK generalizes GPI, `q_∗_w(s, a) − q_π_OK_ω_w (s, a) ≤ q_∗_w(s, a) − q_π_GPI_w (s, a)`. Furthermore, when the condition for OK optimality (Proposition 4.1, Equation 8) is met, the optimality gap for OK becomes zero. This implies that OK and OKB provide transfer learning strategies that are more robust to approximation errors in base policies' SFs compared to GPI.

**Empirical Findings:**

- **Effective CCS Approximation with Fewer Policies (Q1):** Experiments in the Minecart and Highway domains (with d=3 reward features) demonstrate that OKB consistently outperforms SFOLS and OKB-Uniform in terms of mean normalized return (Figure 2). OKB achieves near-optimal performance with a small number of base policies (e.g., 2-3 in Minecart), indicating its efficiency in approximating a CCS. The comparison with OKB-Uniform highlights the importance of OKB's selective task acquisition strategy (using corner weights) over uniform sampling.
- **Performance Advantage with Increased Complexity (Q2):** In the FetchPickAndPlace domain, with varying numbers of reward features (d ranging from 2 to 8), the performance gap between OKB and SFOLS significantly increases as `d` grows (Figure 3). This suggests that OKB scales more effectively and its advantage becomes more pronounced in more complex problems, where the CCS size would grow exponentially. The narrowing gap between OKB and OKB-Uniform for higher `d` values suggests that a larger number of reward features inherently increases the expressivity of the Option Keyboard itself.
- **Solving Non-linear Tasks (Q3):** In the Item Collection domain, designed with a non-linear sequential reward function, OKB successfully solves the task more rapidly than SIP (a specialized method for non-linear tasks) and substantially outperforms a baseline Deep Q-Network (DQN) agent learning from scratch (Figure 4). This empirical result supports Proposition 4.4, demonstrating OKB's capability to address certain non-linear tasks.
- **Qualitative Behavior and Temporal Consistency:** Visualization of the meta-policy's actions in the Highway domain (Figure 5) indicates that OKB learns to select base policies in a temporally consistent manner. This suggests that the method effectively identifies and utilizes temporally extended behaviors, similar to options, which contributes to solving tasks.

### 5. Significance and Potential Impact

This research presents a significant contribution to the field of multi-task reinforcement learning, addressing an open problem concerning the optimal construction of behavior bases for the Option Keyboard.

- **Resolution of an Open Problem:** The paper provides a principled and theoretically guaranteed method (OKB) for identifying an optimal behavior basis for the Option Keyboard. This resolves a prior limitation where the OK's performance was critically dependent on an unsystematic choice of base policies.
- **Enhanced Efficiency and Scalability:** OKB significantly reduces the number of base policies required to achieve zero-shot optimality for linear tasks compared to state-of-the-art methods that construct a full Convex Coverage Set (CCS). This efficiency addresses the critical scalability challenge posed by the exponential growth of CCS size with increasing reward features, making optimal multi-task learning more feasible in complex, high-dimensional environments.
- **Broader Applicability to Non-linear Tasks:** By proving that OKB is strictly more expressive than a CCS, the method extends its utility beyond strictly linear reward functions. It demonstrates the ability to optimally solve specific classes of non-linear tasks where solutions involve switching between optimal policies for linear sub-problems. This expands the scope of problems that can be addressed by multi-task RL with optimality guarantees.
- **Robustness to Approximation Errors:** The theoretical analysis indicates that the Option Keyboard, especially with an optimally constructed basis, can mitigate or entirely avoid optimality gaps that arise from function approximation errors in base policies' successor features, a common challenge in deep RL. This robustness improves the reliability of learned transfer strategies.
- **Advancement in Multi-task RL:** The work contributes to the development of more sample-efficient and generalizable RL agents. By providing a structured way to build a foundation of reusable behaviors, OKB enables agents to adapt more quickly and effectively to new tasks with less environmental interaction.
- **Foundational for Future Research:** The paper lays groundwork for several future directions, including the integration of temporally extended meta-policies with learned termination conditions for even greater flexibility and efficiency. Furthermore, identified connections with Multi-Objective Reinforcement Learning (MORL) suggest potential for unified representations that could enhance both sample efficiency and generalization across multiple objectives.
