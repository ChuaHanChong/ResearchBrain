# AD-CLIP: Adapting Domains in Prompt Space Using CLIP

> [!summary] Summary
> AD-CLIP proposes a data-driven prompt learning framework within CLIP's prompt space, addressing unsupervised domain adaptation by learning domain-invariant and class-generalizable prompts. The method establishes new performance benchmarks on Office-Home, VisDA-2017, and Mini-DomainNet, with average accuracy improvements up to 2.2% over previous state-of-the-art.

## Problem

- Deep learning models struggle with the "domain-shift problem" where training and test data distributions diverge, limiting generalization in real-world applications.
- Traditional Unsupervised Domain Adaptation (UDA) methods, often relying on CNNs, lack "semantic richness" to capture deeper conceptual relationships for robust generalization across visually diverse domains.
- Prior attempts to apply CLIP to UDA used ad-hoc prompting or neglected intrinsic visual distributions, leading to suboptimal performance or overfitting.

## Method

- Utilizes ==frozen CLIP vision and text backbones==, integrating only a minimal set of learnable projector networks for style and content features.
- Develops a novel ==prompt learning scheme== that dynamically combines a ==Domain-Agnostic Token (DAT)== and image-specific context tokens derived from multi-scale visual features.
- Introduces a ==Target-to-Source Style Mapping Network== to approximate source domain style characteristics from target data, enabling robust inference without explicit source access.

## Results

- Achieved state-of-the-art average accuracy across UDA benchmarks: **90.5%** on Office-Home, **92.7%** on VisDA-2017, and **91.4%** on Mini-DomainNet (with ViT-L/14 backbone).
- Outperformed previous state-of-the-art methods by an average of **1.8%** on Office-Home, **2.2%** on VisDA-2017, and **1.6%** on Mini-DomainNet.
- t-SNE visualizations confirm that AD-CLIP successfully achieves both domain invariance and class discriminativeness in the learned text embeddings, validating its core objective.

## Takeaways

> [!tip] Key Insights
> - Leveraging multi-scale visual features for content extraction consistently improves performance, indicating the importance of nuanced visual information for prompts.
> - The Domain-Agnostic Token is critical for learning domain-invariant representations, while the Target-to-Source Style Mapping Network prevents overfitting and maintains performance during target-only inference.
> - Both Entropy Minimization and KL Divergence Loss terms are indispensable for promoting discriminative alignment within the target domain and ensuring distributional similarity between source and target prompt embeddings.
