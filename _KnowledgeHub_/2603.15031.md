# Attention Residuals

> [!summary] Summary
> The Kimi Team introduced Attention Residuals (AttnRes) for deep neural networks, which replaces standard residual connections' fixed additive accumulation with learned, content-dependent softmax attention over preceding layer outputs. The scalable Block AttnRes variant mitigated hidden-state growth and dilution, achieving lower validation loss and outperforming baselines by up to 7.5 points on multi-step reasoning tasks like GPQA-Diamond.

## Problem

- Standard residual connections in deep networks, especially with PreNorm, lead to uncontrolled growth in hidden-state magnitudes, progressively diluting early-layer information and limiting effective model depth.
- The uniform, fixed-weight aggregation of preceding layer outputs prevents selective, content-aware retrieval of information, hindering deeper layers from effectively accessing relevant earlier representations.
- Implementing full cross-layer attention directly incurs substantial memory and communication overhead, making it impractical for large-scale model training and inference.

## Method

- **AttnRes** (Attention Residuals) replaces the additive residual update with a ==softmax attention-weighted sum== over all preceding layer outputs, using layer-specific learnable pseudo-queries to enable content-dependent information aggregation.
- **Block AttnRes** (Block Attention Residuals) partitions layers into blocks, performing standard residual summations within blocks and applying ==cross-layer attention== only over these block-level representations, reducing overhead from O(Ld) to O(Nd).
- Infrastructure optimizations, including cross-stage caching for pipeline parallelism during training and a two-phase computation strategy with memory-efficient prefilling for inference, ensure practical scalability with minimal overhead.

## Results

- Block AttnRes consistently achieved lower validation loss across all model sizes, matching the baseline's performance with **1.25x** less compute.
- The model maintained bounded and periodically patterned output magnitudes across depth, mitigating hidden-state growth, and resulted in a more uniform distribution of gradient magnitudes compared to the baseline.
- Block AttnRes demonstrated improved performance on downstream benchmarks, including **+7.5 points** on GPQA-Diamond, **+3.6 points** on Minerva Math, and **+3.1 points** on HumanEval, across multi-step reasoning and code generation tasks.

## Takeaways

> [!tip] Key Insights
> - A formal duality exists between depth-wise accumulation in residual networks and sequential recurrence in RNNs, suggesting that content-dependent attention can similarly enhance information flow across network depth.
> - Replacing fixed residual aggregation with learnable softmax attention effectively mitigates the 'PreNorm dilution' problem, leading to bounded hidden-state magnitudes and more uniform gradient distributions across layers.
> - Optimal architectural scaling shifts towards deeper, narrower networks when using AttnRes, indicating its ability to better leverage increased model depth under fixed compute and parameter budgets.
