# Scalable Offline Model-Based RL with Action Chunks

> [!summary] Summary
> MAC introduces a model-based offline reinforcement learning approach that uses action chunks and flow-based generative policies to tackle complex, long-horizon tasks. It achieves state-of-the-art performance on challenging manipulation benchmarks, outperforming prior model-based methods and many model-free algorithms.

## Problem

- Scaling offline model-free reinforcement learning to complex, long-horizon tasks due to pathologies in off-policy temporal difference value learning.
- The inherent trade-off in model-based value expansion between needing long rollouts to reduce value function bias and short rollouts to mitigate compounding model errors.
- Modeling complex, high-dimensional, and potentially multi-modal action distributions in offline reinforcement learning settings.

## Method

- Develops ==action-chunk dynamics== and reward models that predict future states and rewards over `n` steps, significantly reducing autoregressive model calls and error accumulation.
- Employs expressive flow action-chunk policies with rejection sampling to generate value-maximizing action sequences while staying within the data distribution.
- Utilizes policy distillation to train an efficient one-step MLP action-chunk policy, accelerating the computationally intensive flow sampling process.

## Results

- Achieves state-of-the-art performance on challenging long-horizon goal-conditioned robotic manipulation tasks from OGBench (**100M** transitions), outperforming prior model-based and many model-free methods.
- Demonstrates that action chunking significantly reduces compounding model prediction errors, and the flow-based rejection sampling policy is critical for tasks with complex behavioral distributions.
- Identified a limitation where MAC, along with other model-based RL approaches, struggles on contact-rich robotic locomotion tasks due to difficulties in modeling highly erratic dynamics.

## Takeaways

> [!tip] Key Insights
> - Action chunking effectively mitigates compounding model prediction errors over extended imaginary rollouts, which is crucial for tackling long-horizon tasks.
> - Combining expressive flow-based policies with rejection sampling provides a robust mechanism to generate diverse, value-maximizing action chunks while preventing model exploitation.
> - On-policy model rollouts, combined with multi-step returns facilitated by action chunks, enable deeper value expansion and significantly reduce bias accumulation in long-horizon tasks.
