# VLMbench: A Compositional Benchmark for Vision-and-Language Manipulation

> [!summary] Summary
> The VLMbench framework, developed by researchers at UCSC and the University of Michigan, provides a compositional benchmark for language-guided robotic manipulation by automatically generating diverse 6-DoF tasks and language instructions. Evaluation with a 6D-CLIPort baseline highlights the critical challenges in precise object localization and 6-DoF control from multimodal inputs.

## Problem

- Embodied AI agents lack the ability to perform complex, precise object manipulation guided by natural language instructions.
- Existing robotic manipulation benchmarks are limited by their lack of scalability, modularity for compositional tasks, adaptability to novel objects, and insufficient language diversity.
- Creating diverse, physics-realistic 6-DoF manipulation demonstrations with varied language instructions is labor-intensive and difficult to scale.

## Method

- Developed AMSolver, an automatic system that generates diverse 6-DoF robotic manipulation demonstrations using rule-based unit tasks and object-centric representations.
- Created VLMbench, a benchmark leveraging AMSolver to feature eight categorized tasks with compositional language and variations, implemented in CoppeliaSim.
- Introduced 6D-CLIPort, a keypoint-based vision-and-language agent extending CLIPort to 6-DoF actions, serving as a baseline to evaluate VLMbench's challenges.

## Results

- The 6D-CLIPort agent consistently outperformed "Language-Only" and "Vision-Only" baselines, affirming the joint necessity of both visual and language inputs for task success.
- Tasks requiring precise and continuous 6-DoF pose adjustments, such as "Pour" tasks, exhibited very low success rates, indicating current models' limitations in handling dynamic constraints.
- Ablation studies demonstrated that accurate object localization (position estimation) from multimodal inputs is a major bottleneck, as providing ground-truth position significantly boosted performance more than ground-truth orientation.

## Takeaways

> [!tip] Key Insights
> - Complex manipulation tasks can be systematically decomposed into modular "unit tasks" defined by end-effector constraints (e.g., position, orientation), facilitating automatic and scalable data generation.
> - A principled approach can automatically generate diverse 6-DoF manipulation demonstrations with corresponding compositional language instructions, overcoming data collection bottlenecks.
> - Accurate object localization and precise 6-DoF control, especially regarding orientation in continuous, multi-step tasks, remain critical challenges for current vision-language manipulation models.
