# FUNCTO: Function-Centric One-Shot Imitation Learning for Tool Manipulation

> [!summary] Summary
> This paper introduces FUNCTO, a framework that enables robots to learn and generalize tool manipulation skills from a single human demonstration by focusing on function-centric correspondences rather than geometric similarities. It demonstrates high success rates (79.5%) in generalizing to novel tools with significant geometric variations, substantially outperforming existing one-shot and behavioral cloning methods in data efficiency and generalization capability.

## Problem

- Existing One-Shot Imitation Learning (OSIL) methods for robot tool manipulation struggle to generalize to novel tools that exhibit significant geometric variations while serving the same function (intra-function variations).
- Current robot learning systems primarily rely on shallow visual or geometric correspondences, which fail when tools like a mug and a teapot, both used for 'pouring,' have drastically different shapes and topologies.
- Traditional behavioral cloning methods are data-hungry and still show limited generalization to unseen tools with substantial geometric differences, making robot teaching inefficient for versatile tool use.

## Method

- **FUNCTO** proposes a ==Function-Centric One-Shot Imitation== Learning framework that uses a 3D functional keypoint representation to establish correspondences based on the tool's functional roles.
- The framework extracts three functional keypoints (grasp, center, function points) from a single human video using Grounding-SAM, Cotracker, and VLMs with mark-based visual prompting to capture tool usage semantics.
- Functional keypoints are transferred to novel tools using a combination of VLMs for coarse region proposals and dense semantic correspondence for fine-grained point transfer, followed by an alignment process that includes VLM-refined function axis alignment for optimal task execution.

## Results

- FUNCTO achieved a high success rate of **79.5%** for novel tool generalization across five diverse manipulation functions, significantly outperforming the best OSIL baseline (DINOBOT) which reached **57.5%**.
- With a single human demonstration, FUNCTO outperformed behavioral cloning methods (e.g., ACT, Diffusion Policy) trained on 50 demonstrations, which struggled with unseen tools (20-**30%** success rate), demonstrating superior data efficiency.
- Failure analysis revealed that grasping stability and robust trajectory planning in contact-rich tasks (e.g., brushing, pounding) were the primary challenges, indicating areas for future work in closed-loop control and multi-modal feedback.

## Takeaways

> [!tip] Key Insights
> - Generalizing robot tool manipulation to geometrically varied but functionally similar tools requires focusing on invariant functional elements and behaviors rather than superficial visual or geometric correspondences.
> - Vision-Language Models (VLMs) can provide crucial commonsense knowledge to refine functional alignments, such as determining optimal pouring angles for different containers, enabling robust skill transfer across diverse tool shapes.
> - A single human demonstration, when combined with VLM and dense semantic correspondence, is sufficient to provide rich cues for localizing and transferring functional keypoints to novel tools, making one-shot imitation learning highly data-efficient compared to data-intensive behavioral cloning.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The ability of robots to use tools is a long-standing goal in artificial intelligence and robotics, promising to unlock a vast array of practical applications. Within this domain, **One-Shot Imitation Learning (OSIL)** has emerged as a highly desirable approach, aiming to teach robots complex skills from a single human demonstration. This efficiency contrasts sharply with traditional robot programming or data-intensive reinforcement learning/behavioral cloning methods.

However, a critical bottleneck for existing OSIL methods in tool manipulation is their limited generalization to novel tools, particularly when these tools exhibit significant **geometric variations** while serving the same function (termed "intra-function variations"). For instance, while a human can intuitively apply the skill of "pouring" using a mug, a teapot, or even a saucepan, current robot learning systems struggle to transfer this skill across such geometrically diverse objects. Prior OSIL methods typically rely on establishing "shallow" correspondences based on visual or geometric similarities, employing techniques like keypoint-based pose estimation, global point set registration, shape warping, or invariant region matching. These methods implicitly assume that demonstration and test tools must share highly similar shapes or appearances, an assumption that frequently breaks down in real-world scenarios. Some previous works also necessitate extensive in-domain pre-training, further limiting their adaptability to entirely novel or out-of-domain tools.

Concurrently, **Behavioral Cloning (BC)** models, trained on large datasets of expert demonstrations, have shown promise in generalizing to unseen configurations. However, they are often data-hungry and still exhibit limitations when confronted with substantial geometric differences in tools, requiring massive datasets to achieve even moderate generalization compared to the one-shot paradigm.

FUNCTO addresses this fundamental challenge by shifting the paradigm from purely geometric or visual correspondences to **function-centric correspondences**. Inspired by cognitive anthropology, which highlights invariant human behavioral patterns when using different tools for the same purpose, FUNCTO posits that the key to generalization lies in understanding the *functional roles* of tool parts rather than their exact geometric forms. This work positions itself at the forefront of robust, data-efficient robot learning for tool manipulation, aiming to bridge the gap between human-like intuitive generalization and current robotic capabilities. It builds upon advancements in vision-language models (VLMs) and dense semantic correspondence, integrating them into a structured, interpretable framework for skill transfer.

### 2. Key Objectives and Motivation

The primary objective of FUNCTO is to enable a robot to **imitate a tool manipulation behavior demonstrated in a single human video and generalize that skill to novel tools that support the same function, despite significant intra-function geometric variations**. This means the robot should be able to perform functionally equivalent tasks, even if the new tool looks very different from the one used in the demonstration.

The motivation for this research stems from a clear observation and a significant limitation in current robotics:
- **Human Intuition vs. Robot Capability:** Humans effortlessly generalize tool use. For example, once they learn to pour with a mug, they can readily apply the same "pouring" skill to a teapot, a pitcher, or a saucepan, recognizing the functional equivalence despite vast differences in shape, size, and topology (e.g., handles, spouts, body shapes). Robots, however, currently lack this intuitive understanding.
- **Limitations of Prior Work:** Existing one-shot imitation learning (OSIL) methods for tool manipulation fall short because they primarily focus on establishing correspondences based on geometric or visual similarity. When confronted with tools that are functionally similar but geometrically dissimilar (e.g., a mug vs. a teapot), these methods fail to identify the critical functional elements (like a pouring spout or a grasping handle) and their relevant spatial relationships.
- **The Invariance Problem:** The core motivating question is: "What remains invariant among tools with the same function despite significant intra-function variations?" The paper proposes that the invariant aspect is the *spatiotemporal pattern of behavior* related to the tool's function, rather than its static geometry. For instance, the act of "pouring" always involves manipulating a specific part of the tool (the "function point") towards a target.

By focusing on these functional invariants through a novel "function-centric" approach, FUNCTO aims to overcome the generalization barrier faced by existing methods, making robot teaching more intuitive and efficient.

### 3. Methodology and Approach (FUNCTO Framework)

FUNCTO (Function-Centric OSIL for Tool Manipulation) is a modular framework designed to establish functional correspondences using a 3D functional keypoint representation. It factorizes the problem into three distinct stages:

#### 3.1. Functional Keypoint Extraction

This stage processes a single human demonstration video ($V_H$) to extract critical functional information about the tool's usage.
- **Demonstration Tool Tracking:** The process begins by localizing and segmenting the demonstration tool and target in the initial video frame using **Grounding-SAM**. Keypoints are uniformly sampled on the tool, and their 3D motions are tracked throughout the video using **Cotracker** and depth information. To ensure motion independence from absolute positions, keypoint trajectories are transformed into the target object's frame.
- **Keyframe Discovery:** Since functional keypoints may not be visible throughout the entire demonstration, FUNCTO identifies four crucial keyframes:
 - **Initial Keyframe ($I_0$):** Tool in its initial state.
 - **Grasping Keyframe ($I_g$):** When the human hand grasps the tool (detected by an off-the-shelf hand-object detector).
 - **Function Keyframe ($I_f$):** When the tool-target interaction begins (identified by unsupervised change point detection based on velocity statistics).
 - **Pre-Function Keyframe ($I_p$):** A frame just before $I_f$ where tool-target occlusion is minimal, crucial for reliable function point detection.
- **Functional Keypoint Detection:** Three 3D functional keypoints are identified:
 - **Grasp Point ($p_t^{grasp}$):** The intersection of the hand and tool masks in $I_g$.
 - **Center Point ($p_t^{center}$):** The 3D center of the tool in $I_0$.
 - **Function Point ($p_t^{func}$):** The most challenging to detect, as it requires commonsense knowledge of tool usage. FUNCTO leverages **Vision-Language Models (VLMs)** with **mark-based visual prompting**. A meta-prompt defines the function point, and then the VLM is prompted with $I_p$ (where occlusion is low) and the task description ($l_H$) to select the function point from a set of candidate points on the tool's boundary.
- **Trajectory Generation:** Once detected in their respective keyframes, these three functional keypoints are tracked over time using the computed relative transformations, yielding their full 3D trajectories $\{K_t^H\}$. Additionally, an "effect point" ($p_{eff}$) is defined as the 3D location on the target where the interaction occurs, effectively linking the function point to the target.

#### 3.2. Function-Centric Correspondence Establishment

This is the core novelty, enabling generalization by transferring functional knowledge.
- **Functional Keypoint Transfer:** The functional keypoints from the demonstration tool ($K_0^H$) are transferred to the novel test tool ($K_0^R$). This involves:
 - **Coarse-Grained Region Proposal:** $p_0^{func}$ and $p_0^{grasp}$ are projected to the 2D image plane ($I_0$). This marked $I_0$ serves as a crucial reference for the VLM when proposing coarse candidate regions for the corresponding 2D function and grasp points on the *test tool image* ($o_R$). The reference from the human demonstration is vital as it encodes the intended action.
 - **Fine-Grained Point Transfer:** A pre-trained **dense semantic correspondence model** is then used to precisely transfer 2D function and grasp points from $I_0$ to the candidate regions on $o_R$. The 3D center of the test tool becomes $q_0^{center}$. The effect point on the target ($q_{eff}$) is scaled based on the target's 3D dimensions.
- **Function-Centric Correspondence (Geometric Constraints):** This step formulates geometric constraints on the 3D functional keypoints to define the desired test tool state at the function keyframe ($t_f$), represented as a rigid transformation ($T_{func}$).
 - **Function Plane Construction:** For both demonstration ($K_{t_f}^H$) and test ($K_0^R$) tools, a function plane is constructed using three vectors: the function axis ($u$, from center to function point), a grasp vector ($v$, from function point to grasp point), and their cross-product, the normal vector ($n$).
 - **Alignment Steps:**
 1. **Function Point Alignment:** Aligns the function points of the demonstration and test tools, ensuring interaction occurs at the correct location.
 2. **Function Plane Alignment:** Aligns the normal vectors of the function planes, ensuring correct orientation.
 3. **Function Axis Alignment (with VLM Refinement):** Aligns the function axes, which represent the operational direction (e.g., pouring angle). Crucially, due to structural differences (e.g., mug vs. teapot requiring different tilt angles), direct rigid alignment is insufficient. FUNCTO refines this alignment using a VLM. It applies a range of angle offsets to the test tool's function axis, renders synthetic combined point clouds of the test tool and target for each offset, and then prompts the VLM (with the human $I_f$ as reference) to select the optimal configuration for task success. This "commonsense knowledge" from the VLM ensures the tool is tilted correctly.
- The rigid transformation $T_{func}$ and the predicted test tool state at $t_f$ ($K_{t_f}^R$) are then computed by combining these alignments. The predicted function point on the test tool is further adjusted to align with the effect point on the target.

#### 3.3. Functional Keypoint-Based Action Planning

In the final stage, the robot's end-effector trajectory is generated and executed.
- **Tool Pose Representation:** The functional keypoint trajectories are converted into a sequence of SE(3) poses ($T_t^H$, $T_t^R$) using the function axis and normal vector for orientation, and the function point for translation.
- **Tool Trajectory Optimization:** Given the initial test tool pose ($T_{init}$), the derived function keyframe pose ($T_{func}$), and the reference demonstration trajectory ($\{T_t^H\}$), an optimization problem is solved. The objective is to minimize the difference between the test tool's predicted functional keypoint trajectory and the reference, subject to constraints like the initial and function keyframe poses, velocity limits, and collision avoidance. **CasADi** and **IPOPT** are used for symbolic modeling and solving.
- **Tool Trajectory Execution:** The optimized test tool trajectory is transformed into the robot's base frame. A task-oriented grasp pose is sampled using **GraspGPT** around the grasp point. Finally, the robot executes the trajectory using operational space control.

### 4. Main Findings and Results

FUNCTO's performance was rigorously evaluated through extensive real-robot experiments across diverse tool manipulation tasks and compared against various baselines.

#### 4.1. Experimental Setup

- **Platform:** Kinova Gen3 7-DoF robotic arm with an Azure Kinect RGB-D camera.
- **Tasks:** Five common tool manipulation functions: pour, cut, scoop, brush, and pound. For each function, five tasks were designed, varying in generalization difficulty:
 - **Spatial Generalization (Seen):** Same tool as demonstration, but randomly positioned.
 - **Instance Generalization (Unseen):** Different instances of the same tool category.
 - **Category Generalization (Unseen):** Tools from entirely different categories but serving the same function.
- **Demonstrations:** FUNCTO used a *single* human RGB-D video demonstration per function. Behavioral Cloning (BC) baselines were trained on *50* human demonstrations per function for a fair comparison.
- **Evaluation:** 10 trials per task, with average success rate as the metric.

#### 4.2. Quantitative Comparison to OSIL Baselines

FUNCTO was compared against state-of-the-art modular OSIL methods: **DINOBOT** (vision foundation model-based), **DITTO** (visual correspondence model-based), and **ORION** (geometric feature registration).

- **Spatial Generalization:** All methods performed well, achieving success rates above 70%, indicating competence in handling pose variations of seen tools.
- **Novel Tool Generalization (Instance and Category):** This is where FUNCTO demonstrated significant superiority.
 - Existing baselines (DINOBOT, DITTO, ORION) experienced substantial performance drops (20-40% reduction) when generalizing to novel tool instances and categories. For example, transferring "pour" from a mug to a teapot proved challenging for baselines due to drastic geometric and topological differences. Similarly, challenges arose with tools of different sizes (e.g., large mallet vs. small hammer for pounding).
 - **FUNCTO achieved a high success rate of 79.5% for novel tool generalization across all five functions**, significantly outperforming the best baseline, DINOBOT (which achieved 57.5%). This highlights FUNCTO's ability to establish functional correspondences despite large intra-function geometric variations.

#### 4.3. Quantitative Comparison to Behavioral Cloning (BC) Baselines

FUNCTO was also compared with leading BC methods: **ACTION CHUNKING TRANSFORMER (ACT)** and **DIFFUSION POLICY (DP)**, both leveraging DINO-ViT for visual features, and **3D DIFFUSION POLICY (DP3)** (3D visual representation). These BC methods were trained with 50 human demonstrations.

- **Seen Tools:** BC baselines achieved 50-60% success rates, showing some spatial generalization. FUNCTO (with 1 demo) performed even better, reaching 84%.
- **Unseen Tools (Intra-function Variations):** BC baselines struggled severely, with success rates approximately half that of the seen category (around 20-30%). This underscores their limitation in handling significant geometric variations despite large training datasets.
- **FUNCTO (1 demo) achieved a remarkable 79.5% success rate on unseen tools**, demonstrating vastly superior data efficiency and generalization capabilities compared to BC methods for this specific challenge. BC methods trained with fewer demonstrations (10 or 1) reportedly failed to produce meaningful results.

#### 4.4. Failure Analysis

The modularity of FUNCTO allowed for detailed analysis of failure modes:
- **Primary Failures:**
 - **Grasping (highest):** Unstable contact, tool flipping or slipping during manipulation. This suggests a need for more robust, possibly adaptive, grasping mechanisms or online state tracking.
 - **Trajectory Planning:** Unexpected collisions, especially in contact-rich tasks (e.g., brushing a plate). This points to the need for visual-tactile feedback for intricate interactions.
- **Other Failures:**
 - **Functional Keypoint Transfer (less significant):** Errors mainly due to incorrect candidate region proposals by VLMs, indicating room for VLM improvement.
 - **Correspondence Errors:** Attributed to inaccurate depth information, highlighting the importance of robust 3D perception.

#### 4.5. Ablation Studies

Two key ablation studies investigated the design choices in the function-centric correspondence establishment:

- **Functional Keypoint Transfer Strategies:**
 - The proposed **Demo+VLM+DSC** (using demonstration reference, VLM for coarse regions, and dense semantic correspondence for fine-grained points) consistently outperformed other strategies in both Average Keypoint Distance (AKD) and Average Precision (AP).
 - Relying solely on VLM (Demo+VLM) showed reasonable performance but lacked precision.
 - Solely relying on dense semantic correspondence (Demo+DSC) failed with large intra-function variations.
 - **VLM (zero-shot)** without a human demonstration reference performed the worst, strongly justifying the paper's point that human demonstrations provide invaluable cues for test keypoint localization.
- **Function-Centric Correspondence (Alignment Strategies):**
 - **Function point alignment** was found to be the most effective, ensuring interaction at the desired tool location regardless of shape.
 - **VLM refinement for function axis alignment** statistically improved performance. Without it, rigid alignment of function axes could lead to infeasible poses, especially when tool structures differ significantly (e.g., pouring angle for a mug vs. a teapot). The VLM's commonsense reasoning helped determine the optimal functional tilt.

### 5. Significance and Potential Impact

FUNCTO represents a significant advancement in the field of robot imitation learning, particularly for tool manipulation. Its core contribution is the novel formulation of **function-centric correspondence using a 3D functional keypoint representation**. By explicitly focusing on the functional aspects of tool use, rather than solely on geometric or visual similarities, FUNCTO effectively addresses a long-standing challenge: enabling robots to generalize demonstrated manipulation skills to novel tools with the same function, even when those tools exhibit substantial geometric variations.

The practical impact of FUNCTO is substantial:
- **Enhanced Generalization:** It allows robots to move beyond "seen" tools or geometrically similar instances, tackling the more complex problem of cross-category generalization for functionally equivalent tasks. This is a critical step towards more versatile and adaptable robotic systems in unstructured environments.
- **High Data Efficiency:** By achieving impressive generalization from a *single human demonstration*, FUNCTO drastically reduces the data collection and labeling burden typically associated with robot learning, making robot teaching more accessible and scalable. This contrasts sharply with data-hungry behavioral cloning approaches that require hundreds or thousands of demonstrations.
- **Interpretability:** The explicit representation of functional keypoints and trajectories offers a high degree of interpretability, which is valuable for debugging, understanding robot behavior, and potentially integrating with traditional task and motion planning frameworks.
- **Leveraging Foundation Models:** FUNCTO effectively demonstrates how advanced Vision-Language Models (VLMs) and dense semantic correspondence models can be integrated into a structured robotic pipeline to provide crucial commonsense knowledge and precise visual correspondences, which are otherwise difficult to infer from raw sensory data.

#### 5.1. Limitations and Future Directions

Despite its promising results, the paper candidly acknowledges several limitations, pointing towards exciting avenues for future research:
- **Functional Keypoint Visibility and Collinearity:** The current system assumes clear visibility of functional keypoints from the camera, which may not always hold (e.g., in egocentric views). Additionally, collinearity of the three functional keypoints in 3D can cause issues, although this is uncommon for everyday tools. Future work could explore multi-view perception or more robust 3D reconstruction techniques to address visibility.
- **Open-Loop Execution:** The current pipeline operates in an open-loop manner, making it susceptible to unexpected state changes or external disturbances. Integrating an online state tracking module (potentially with multiple calibrated cameras) and enabling closed-loop execution would significantly enhance robustness and allow for reactive adjustments during task execution.
- **Multi-modal Function Modeling:** Functions are inherently multi-modal (e.g., a mug can be used for "forward pouring" or "side pouring"). FUNCTO currently imitates only a single usage based on one demonstration. Future work could explore leveraging few-shot human demonstrations to capture and model the multi-modality of a function, perhaps with sophisticated human-robot interaction systems to explicitly define and differentiate various sub-behaviors.
- **Contact-Rich Tasks:** Failures in contact-rich tasks like brushing or pounding suggest the need for incorporating visual-tactile feedback, allowing the robot to sense and react to physical interactions more effectively.

Overall, FUNCTO lays a strong foundation for developing intelligent robotic systems that can learn and generalize tool manipulation skills in a human-like, intuitive, and data-efficient manner, moving closer to the vision of truly versatile and adaptable robots.
