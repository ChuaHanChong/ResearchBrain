# FUNCTO: Function-Centric One-Shot Imitation Learning for Tool Manipulation

> [!summary] Summary
> This paper introduces FUNCTO, a framework that enables robots to learn and generalize tool manipulation skills from a single human demonstration by focusing on function-centric correspondences rather than geometric similarities. It demonstrates high success rates (79.5%) in generalizing to novel tools with significant geometric variations, substantially outperforming existing one-shot and behavioral cloning methods in data efficiency and generalization capability.

## Problem

- Existing One-Shot Imitation Learning (OSIL) methods for robot tool manipulation struggle to generalize to novel tools that exhibit significant geometric variations while serving the same function (intra-function variations).
- Current robot learning systems primarily rely on shallow visual or geometric correspondences, which fail when tools like a mug and a teapot, both used for 'pouring,' have drastically different shapes and topologies.
- Traditional behavioral cloning methods are data-hungry and still show limited generalization to unseen tools with substantial geometric differences, making robot teaching inefficient for versatile tool use.

## Method

- **FUNCTO** proposes a ==Function-Centric One-Shot Imitation== Learning framework that uses a 3D functional keypoint representation to establish correspondences based on the tool's functional roles.
- The framework extracts three functional keypoints (grasp, center, function points) from a single human video using Grounding-SAM, Cotracker, and VLMs with mark-based visual prompting to capture tool usage semantics.
- Functional keypoints are transferred to novel tools using a combination of VLMs for coarse region proposals and dense semantic correspondence for fine-grained point transfer, followed by an alignment process that includes VLM-refined function axis alignment for optimal task execution.

## Results

- FUNCTO achieved a high success rate of **79.5%** for novel tool generalization across five diverse manipulation functions, significantly outperforming the best OSIL baseline (DINOBOT) which reached **57.5%**.
- With a single human demonstration, FUNCTO outperformed behavioral cloning methods (e.g., ACT, Diffusion Policy) trained on 50 demonstrations, which struggled with unseen tools (20-**30%** success rate), demonstrating superior data efficiency.
- Failure analysis revealed that grasping stability and robust trajectory planning in contact-rich tasks (e.g., brushing, pounding) were the primary challenges, indicating areas for future work in closed-loop control and multi-modal feedback.

## Takeaways

> [!tip] Key Insights
> - Generalizing robot tool manipulation to geometrically varied but functionally similar tools requires focusing on invariant functional elements and behaviors rather than superficial visual or geometric correspondences.
> - Vision-Language Models (VLMs) can provide crucial commonsense knowledge to refine functional alignments, such as determining optimal pouring angles for different containers, enabling robust skill transfer across diverse tool shapes.
> - A single human demonstration, when combined with VLM and dense semantic correspondence, is sufficient to provide rich cues for localizing and transferring functional keypoints to novel tools, making one-shot imitation learning highly data-efficient compared to data-intensive behavioral cloning.
