# General In-Hand Object Rotation with Vision and Touch

> [!summary] Summary
> RotateIt is a robotic system enabling continuous, multi-axis in-hand object rotation for diverse objects, trained purely in simulation and successfully deployed to the real world. It employs a two-stage reinforcement learning approach that distills an oracle policy with privileged information into a visuotactile policy capable of inferring object properties from vision and touch data.

## Problem

- Most advanced in-hand manipulation systems are tailored for specific objects or require extensive human demonstrations, limiting generalization to novel objects.
- Achieving continuous, large-angle, multi-axis object re-orientation with dexterous hands remains challenging, often limited to single-axis rotation.
- Bridging the sim-to-real gap for complex manipulation tasks that require inferring unknown object properties from noisy real-world sensory inputs is difficult.

## Method

- A two-stage training pipeline is used: an 'oracle' policy is trained in simulation with ground-truth object properties, then a visuotactile transformer is trained to infer these properties from realistic, multimodal sensor inputs.
- The system integrates robot proprioception, object depth images from an RGBD camera, and discretized contact locations from vision-based tactile sensors, processed by a transformer architecture for temporal modeling.
- The oracle policy explicitly encodes object shape information (via PointNet features) and physical properties to enhance robustness and generalization across a diverse set of objects.

## Results

- RotateIt successfully transferred from simulation to an AllegroHand robot, achieving continuous multi-axis rotation on diverse real-world objects, outperforming proprioception-only baselines.
- Explicit object shape encoding reduced the oracle policy's generalization performance drop on out-of-distribution (OOD) objects from 22% to 8%.
- Combining vision and rich tactile sensing reduced the sensorimotor policy's OOD generalization gap from 41% (proprioception-only) to 15%, demonstrating the critical value of multimodal input for real-world dexterity.

## Takeaways

> [!tip] Key Insights
> - Explicitly providing object shape information to the control policy substantially improves in-hand manipulation performance and generalization, especially for objects with irregular geometries.
> - Fusing rich visual and tactile feedback is crucial and synergistic for robust dexterous manipulation, significantly enhancing generalization to novel objects and closing the sim-to-real gap.
> - Transformer architectures are effective at processing the temporal history of multimodal sensory data to accurately infer complex object properties for precise control.
