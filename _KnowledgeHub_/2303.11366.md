# Reflexion: Language Agents with Verbal Reinforcement Learning

> [!summary] Summary
> Reflexion reinforces language agents without weight updates. After each failed trial, the agent turns the feedback signal into a written self-reflection and stores it in an episodic memory buffer that conditions the next attempt. It improves sequential decision-making, reasoning and coding, reaching 91% pass@1 on HumanEval versus GPT-4's 80%.

## Problem

- Traditional reinforcement learning needs large numbers of training samples and expensive fine-tuning, so LLM agents cannot learn quickly from a few trial-and-error attempts.
- Scalar rewards from the environment are sparse and give little guidance on what went wrong, so credit assignment over long agent trajectories is hard.
- Prior LLM agents such as ReAct do not carry lessons across episodes, so they repeat the same mistakes on the next attempt.

## Method

- An ==Actor== LLM (ReAct or ==Chain-of-Thought==) generates trajectories, an ==Evaluator== scores them, and a ==Self-Reflection== model converts sparse scalar or binary feedback into ==verbal lessons== for the next trial.
- ==Short-term memory== holds the current trajectory, while ==long-term episodic memory== stores the reflections. A bounded buffer of about 1-3 past reflections is added to the Actor's prompt in later trials.
- The framework accepts several feedback types: environment ==binary rewards==, heuristics such as ==repeated-action detection==, exact-match checks, and ==self-written unit tests== for code, with no gradient updates.

## Results

- On ALFWorld, ReAct plus Reflexion completes **130 of 134** tasks within **12** trials, an absolute gain of **22%** over the baseline, which plateaus.
- On HotPotQA, Reflexion improves exact-match accuracy by about **20%** over the baseline. On HumanEval it reaches **91% pass@1** versus GPT-4's **80%**, and also gains on Rust.
- Ablations on hard HumanEval Rust show that dropping self-reflection or test generation lowers accuracy: the full method scores **68%**, omitting tests gives **52%**, and omitting reflection gives **60%**.

## Takeaways

> [!tip] Key Insights
> - Verbal feedback is a cheap, interpretable stand-in for gradient updates: textual memory alone can give test-time learning without fine-tuning the model.
> - Converting sparse rewards into natural-language reflections gives denser, more actionable credit assignment, and it works only if the model can reason about its own errors.
> - Gains depend on feedback quality. Unreliable self-generated tests cause false positives (MBPP Python regressed) and open-ended search such as WebShop saw no gain, so the evaluator is the bottleneck.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The rapid advancements in large language models (LLMs) have enabled them to excel at various natural language processing tasks, leading to their increasing use as core components for goal-driven agents interacting with external environments. Prior works like ReAct, SayCan, Toolformer, and Generative Agents have demonstrated the feasibility of building autonomous decision-making systems on LLM foundations. However, these approaches have predominantly relied on in-context examples for teaching agents, largely due to the prohibitive computational cost and extensive training samples required for traditional reinforcement learning (RL) methods involving weight fine-tuning of massive LLMs.

Reflexion emerges as a response to this fundamental challenge, seeking to bridge the gap between static in-context learning and computationally intensive full-scale RL. It positions itself within the growing landscape of self-improvement and self-refinement techniques for LLMs. Existing work in this area, such as Self-Refine and Pryzant et al., has explored iterative refinement through self-evaluation, but these methods are often limited to single-generation reasoning tasks or involve heuristic-based retries without deep learning from past mistakes over multiple episodes. Other approaches, like those by Paul et al. and Xie et al., have experimented with intermediate feedback or stochastic search, but Reflexion distinguishes itself by building a persistent, explicit, and interpretable memory of "verbal" experiences.

In the domain of programming, prior methods like AlphaCode, CodeT, Self-Debugging, and CodeRL have focused on test-driven development or debugging. While effective, many of these rely on ground truth test cases or specific actor-critic RL setups that can be complex. Reflexion offers a lightweight alternative that integrates self-generated unit tests and leverages self-reflection to iteratively improve code, demonstrating language-agnostic capabilities and applicability to pass@1 eligibility.

By proposing "verbal reinforcement learning," Reflexion carves out a unique niche. Instead of numerical reward signals guiding gradient updates, it transforms environmental feedback into natural language summaries, creating a "semantic gradient signal." This paradigm mimics human learning through reflection on past failures, allowing LLM agents to learn efficiently in a few-shot manner without requiring expensive model fine-tuning. It represents a significant step towards more adaptable, interpretable, and human-like learning for language agents.

### 2. Key Objectives and Motivation

The primary motivation behind Reflexion is to overcome the inherent limitations of current large language model (LLM) agents in learning from trial-and-error. Traditional reinforcement learning (RL) methods, which are typically used for sequential decision-making, demand extensive training samples and costly model fine-tuning (i.e., updating model weights via gradient descent). Given the enormous scale and parameter counts of modern LLMs, such fine-tuning is computationally prohibitive for dynamic, online learning in diverse environments. Consequently, existing LLM agents often rely on a limited set of in-context examples to guide their behavior, which restricts their adaptability and ability to recover from mistakes.

The key objective of this work is to propose **Reflexion**, a novel framework that enables language agents to learn from prior failures through "verbal reinforcement." This framework aims to reinforce LLM agents not by altering their internal weights but by providing them with linguistic feedback that guides their future decision-making.

More specifically, the objectives include:
- **Developing a mechanism for verbal reflection:** To convert various types of task feedback signals (e.g., binary success/failure, scalar values) into meaningful, free-form natural language summaries.
- **Establishing an episodic memory system:** To store these reflective texts as part of the agent's long-term memory, allowing the agent to recall and learn from past experiences in subsequent trials. This aims to induce better decision-making and prevent repetitive mistakes.
- **Demonstrating flexibility and broad applicability:** To show that Reflexion is versatile enough to integrate different forms and sources of feedback (external environment signals or internally simulated evaluations) and can be effectively applied across a diverse range of challenging tasks, including sequential decision-making, complex coding problems, and intricate language reasoning.
- **Exploring emergent self-reflection:** To investigate the extent to which LLMs can inherently engage in self-reflection and how this emergent property can be harnessed for practical learning.
- **Contributing new benchmarks:** To introduce LeetcodeHardGym, a new, challenging code-generation environment, to further push the boundaries of agent capabilities.

In essence, the authors are motivated to create a lightweight, interpretable, and efficient learning paradigm for LLM agents that mimics human-like iterative learning through introspection and experience accumulation.

### 3. Methodology and Approach

Reflexion is conceived as a modular, iterative optimization process that leverages three distinct large language models (LLMs) and a novel memory mechanism to achieve verbal reinforcement. The core idea is to transform sparse environmental feedback into rich, textual self-reflections, which then serve as contextual hints for the agent in subsequent trials, guiding it to learn from past mistakes without updating its underlying model weights.

**Core Components:**

1. **Actor ($M_a$):** This is the primary LLM that generates text and actions based on current state observations and its accumulated memory. The paper explores various Actor models like Chain of Thought (CoT) for reasoning and ReAct for sequential decision-making, demonstrating the framework's compatibility with different action generation strategies. A crucial aspect is the Actor's conditioning on both short-term (current trajectory) and long-term (reflective text) memory, allowing for informed decision-making.

2. **Evaluator ($M_e$):** The Evaluator's role is to assess the quality of the outputs generated by the Actor. This component is flexible, accommodating different types of reward signals:
 - **Exact Match (EM) Grading:** For reasoning tasks like HotPotQA, where a precise answer is expected.
 - **Pre-defined Heuristics:** For decision-making tasks like AlfWorld, simple rules (e.g., detecting repeated actions, inefficient planning) are used to signal failure.
 - **LLM-as-Evaluator:** For more complex scenarios, another instance of an LLM can be prompted to provide a reward score or classification (e.g., success/failure) for decision-making and programming tasks.

3. **Self-Reflection Model ($M_{sr}$):** This is also an LLM, central to the "verbal reinforcement" aspect. Given a sparse reward signal (e.g., binary success/fail), the current trajectory, and the agent's persistent memory, $M_{sr}$ generates nuanced, specific textual feedback. This feedback translates a simple signal into actionable linguistic insights (e.g., "I should have taken a different action at step X because..."). This detailed, interpretable feedback is key to the agent's ability to learn semantically.

4. **Memory:** Reflexion employs a dual-tier memory system:
 - **Short-term memory:** The current trajectory history of actions and observations within an episode.
 - **Long-term memory (`mem`):** A buffer that stores the verbal self-reflections generated by $M_{sr}$. This episodic memory is appended after each trial and is typically bounded (e.g., 1-3 most recent reflections) to manage LLM context window limitations. This memory serves as additional context for the Actor in subsequent trials, providing "self-hints."

**The Reflexion Process (Algorithm 1):**

The process unfolds iteratively:
1. **Initialization:** The Actor, Evaluator, and Self-Reflection models are initialized. The Actor's policy includes a memory component.
2. **First Trial:** The Actor interacts with the environment, generating an initial trajectory ($\tau_0$).
3. **Evaluation:** The Evaluator scores $\tau_0$, yielding a scalar reward ($r_0$).
4. **Initial Reflection:** The Self-Reflection model analyzes $\tau_0$ and $r_0$ to produce a verbal summary ($sr_0$), which is then stored in `mem`.
5. **Iterative Loop:** For subsequent trials, the Actor generates a new trajectory ($\tau_t$), now conditioned on the accumulated `mem`. The Evaluator assesses $\tau_t$. If the task is not yet successful, the Self-Reflection model generates a new verbal reflection ($sr_t$) based on the latest trajectory and reward, and $sr_t$ is appended to `mem`. This loop continues until the task is successfully completed or a maximum number of trials is reached.

**Task-Specific Adaptations:**

- **Sequential Decision-Making (AlfWorld):** Uses ReAct as Actor. Self-evaluation is via LLM classification or a simple heuristic (detecting repeated actions or excessive actions). Memory stores up to 3 reflections.
- **Reasoning (HotPotQA):** Uses CoT or ReAct. Exact match grading provides binary success/failure. Memory stores up to 3 reflections. Ablation studies examine the unique contribution of verbal self-reflection versus mere episodic memory of trajectories.
- **Programming (HumanEval, MBPP, LeetcodeHardGym):** This task uniquely uses self-generated unit tests. The Actor (LLM) is prompted to produce diverse tests. These tests are filtered for syntactic validity and executed. The success/failure of these tests acts as the primary feedback for the Evaluator. Memory stores 1 reflection, given the often immediate feedback in programming. The new LeetcodeHardGym benchmark, featuring 40 hard Leetcode questions published after GPT-4's pre-training cutoff, is introduced to ensure fair evaluation against state-of-the-art models.

This comprehensive approach allows Reflexion to learn from granular feedback and translate it into actionable linguistic advice, fostering efficient and interpretable learning for LLM agents.

### 4. Main Findings and Results

The experiments conducted across diverse tasks—sequential decision-making, language reasoning, and programming—demonstrate that Reflexion significantly outperforms strong baselines and, in several cases, achieves new state-of-the-art results.

#### 4.1. Sequential Decision-Making (ALFWorld)

- **Significant Improvement:** Reflexion + ReAct, particularly when using a simple heuristic for self-evaluation (detecting hallucinations or inefficient planning), successfully completes 130 out of 134 tasks. This represents an absolute improvement of 22% over the baseline ReAct-only approach.
- **Iterative Learning:** The learning curve shows that Reflexion agents continue to improve steadily over 12 consecutive trials, indicating effective long-term learning and adaptation. In contrast, ReAct-only performance plateaus much earlier, around trials 6-7, with a persistent hallucination rate.
- **Error Correction:** Reflexion effectively mitigates common errors such as an agent hallucinating possession of an item or engaging in inefficient, repetitive planning. The self-reflection process allows the agent to distill long, failed trajectories into actionable "self-hints," enabling it to identify early mistakes and exploit its experience memory for thorough exploration.

#### 4.2. Reasoning (HotPotQA)

- **Clear Performance Gains:** Reflexion consistently outperforms all baseline approaches (CoT-only, ReAct-only, CoT (GT)-only) by substantial margins across several learning steps.
- **No Baseline Improvement:** Baseline approaches failed to show probabilistic improvement on tasks that were initially failed, meaning they could not recover or learn from their mistakes in subsequent trials.
- **Enhanced Reasoning (with Ground Truth):** Even when provided with ground truth context (CoT (GT)), the baseline agent failed 39% of questions. Reflexion, however, helped this agent correct mistakes, improving accuracy by an absolute 14%, showcasing its ability to refine reasoning processes even with perfect information access.
- **Value of Self-Reflection:** An ablation study comparing full Reflexion to an agent with only episodic memory (most recent trajectory) demonstrated that self-reflection provides an additional 8% absolute boost in learning. This result underscores that the verbal explanation generated by the self-reflection step is more effective than just remembering the raw trajectory for iterative learning.

#### 4.3. Programming (HumanEval, MBPP, LeetcodeHardGym)

- **State-of-the-Art Achievements:** Reflexion sets new state-of-the-art pass@1 accuracy on several benchmarks:
 - HumanEval (Python): 91.0%, significantly surpassing the previous best of GPT-4 at 80.1%.
 - HumanEval (Rust): 68.0% (GPT-4 baseline was 60.0%).
 - MBPP (Rust): 75.4% (GPT-4 baseline was 70.9%).
 - Leetcode Hard (Python): 15.0% (GPT-4 baseline was 7.5%).
- **Mixed Results on MBPP (Python):** Reflexion performed slightly worse on MBPP (Python) (77.1% vs. GPT-4's 80.1%). Analysis attributed this to a significantly higher false positive rate (16.3%) of self-generated unit tests for MBPP (meaning internal tests pass but the solution is incorrect) compared to HumanEval (1.4%). This highlights the reliance on the quality of self-generated tests.
- **Ablation Study (HumanEval Rust):**
 - **Test Generation Omission:** Omitting the internal test generation and execution steps led to a significant drop in accuracy (52% vs. 60% baseline), indicating that the agent struggles to self-reflect effectively without concrete unit test feedback.
 - **Self-Reflection Omission:** Removing the natural language explanation step after failed unit tests (leaving only raw test feedback) yielded no improvement over the baseline (60% accuracy). This crucial finding suggests that "blind trial and error debugging techniques without self-reflection are ineffective on harder tasks" like complex program writing. The verbalization of errors and actionable insights is paramount.

In summary, the results convincingly demonstrate that Reflexion's verbal reinforcement paradigm is highly effective, leading to substantial performance gains and establishing new benchmarks, particularly in tasks requiring iterative refinement and complex problem-solving.

### 5. Significance and Potential Impact

The Reflexion framework introduces a highly significant paradigm for advancing the capabilities of language agents, with far-reaching potential impacts on artificial intelligence research and applications.

**Significance:**
- **Lightweight and Efficient Learning:** One of Reflexion's most significant contributions is its ability to enable agents to learn from trial-and-error without requiring expensive, full-scale fine-tuning of large language models. By using linguistic feedback, it offers a computationally lightweight alternative to traditional gradient-based reinforcement learning, making adaptive LLM agents more accessible and practical.
- **Interpretable Reinforcement:** Unlike numerical reward signals in traditional RL, Reflexion's "verbal reinforcement" provides human-understandable feedback. This translates sparse success/failure signals into detailed, actionable insights in natural language, offering a more interpretable and diagnosable learning process. This interpretability can be crucial for understanding agent behavior, especially in complex or safety-critical applications.
- **Leveraging LLM Emergent Properties:** The work successfully harnesses the emergent property of "self-reflection" in LLMs, demonstrating that these models can not only process and generate language but also introspect on their own performance and generate self-corrective advice. This opens new avenues for exploring intrinsic learning mechanisms in large models.
- **Enhanced Performance and SOTA Results:** The consistent and substantial performance improvements across diverse and challenging tasks (decision-making, reasoning, programming) and the achievement of new state-of-the-art results underscore the practical effectiveness of the Reflexion framework. The particularly impressive jump on HumanEval Python (from 80.1% to 91.0% pass@1) highlights its prowess in code generation.
- **Explicit Episodic Memory:** The framework's incorporation of an explicit, persistent episodic memory of reflective experiences is a key differentiator. This allows agents to accumulate wisdom over multiple trials, unlike methods that only rely on short-term context or single-step refinement.

**Potential Impact:**
- **More Capable and Robust AI Agents:** Reflexion can lead to the development of more adaptable and robust AI agents that can learn continuously in dynamic environments. This is vital for applications requiring real-world interaction, such as robotics, advanced personal assistants, and complex task automation.
- **Bridging RL and NLP:** It offers a novel perspective on integrating reinforcement learning principles with natural language processing, potentially inspiring new hybrid approaches that combine the strengths of both fields.
- **Improved Code Generation and Debugging:** The significant gains in programming tasks could accelerate the development of AI-powered coding assistants that are more proficient at self-correction and bug fixing, potentially revolutionizing software development workflows.
- **Safer and More Aligned AI:** The interpretable nature of verbal reinforcement could contribute to addressing concerns around AI alignment and safety. By monitoring the self-reflections, developers could gain insights into an agent's reasoning processes and ensure its intentions align with desired outcomes, especially when interacting with external tools or sensitive information.

**Limitations:**
Despite its strengths, Reflexion is not without limitations. It inherently relies on the quality of the underlying LLM's self-evaluation capabilities; if the LLM cannot accurately assess its own mistakes or generate helpful feedback, the learning process will suffer. As an optimization technique, it may still converge to sub-optimal local minima. The current memory component is a simple sliding window, and the authors suggest future work could explore more advanced structures like vector embedding databases. Practical limitations of test-driven development (e.g., for non-deterministic or impure functions) also apply to its programming applications.

**Future Directions:**
The authors propose extending Reflexion to incorporate more advanced traditional RL concepts, such as value learning in natural language or off-policy exploration techniques. Further research into sophisticated memory architectures is also suggested to handle larger and more complex sets of experiences.

In conclusion, Reflexion represents a significant leap towards developing more intelligent, adaptable, and interpretable language agents by introducing an innovative "verbal reinforcement learning" paradigm that harnesses the power of self-reflection in large language models. Its impact is likely to be profound across various domains where autonomous agents interact and learn from their environments.
