# EGG-SR: Embedding Symbolic Equivalence into Symbolic Regression via Equality Graph

> [!summary] Summary
> Researchers from the University of Texas at El Paso and Purdue University developed Egg-SR, a unified framework that embeds symbolic equivalence into modern symbolic regression algorithms via equality graphs. This approach improved accuracy for Monte Carlo Tree Search, Deep Reinforcement Learning, and Large Language Model-based methods, achieving, for instance, <1E-6 NMSE with Egg-MCTS on trigonometric datasets while maintaining stable training and minimal computational overhead.

## Problem

- Symbolic regression (SR) is an NP-hard problem, leading to an exponential growth in the search space for mathematical expressions.
- Current SR algorithms redundantly explore functionally equivalent but syntactically distinct expressions, wasting computational resources.
- A unified and scalable method to integrate symbolic equivalence (e.g., using equality graphs) into diverse modern learning-based SR frameworks was lacking.

## Method

- Egg-SR introduces a module that extends ==equality graphs== (e-graphs) to compactly represent symbolically equivalent expressions for grammar-based symbolic regression.
- For Monte Carlo Tree Search (Egg-MCTS), symbolic equivalence is embedded via e-graph-based backpropagation to simultaneously update statistics for equivalent paths, preventing redundant exploration.
- For Deep Reinforcement Learning (Egg-DRL), the framework uses an e-graph-based policy gradient estimator that aggregates probabilities and rewards across equivalent generated sequences to stabilize training.
- For Large Language Models (Egg-LLM), the framework enriches feedback prompts with multiple equivalent expressions extracted from e-graphs, guiding the LLM toward more informed predictions.

## Results

- Egg-MCTS consistently discovered expressions with lower median Normalized Mean Squared Error (NMSE) (e.g., <1E-6 on trigonometric datasets) and maintained a broader and deeper search tree compared to standard MCTS.
- Egg-DRL achieved smaller NMSE values for discovered expressions and exhibited a reduction in the variance of the estimated objective, leading to more stable policy updates.
- Integrating Egg into LLM-SR (GPT-**3.5**, Mistral) enabled the discovery of higher-quality expressions with lower NMSE values on both in-distribution and out-of-distribution scientific benchmarks.
- The e-graph representation demonstrated substantially less memory consumption for equivalent expressions and contributed minimal runtime overhead to the overall DRL pipeline.

## Takeaways

> [!tip] Key Insights
> - Equality graphs efficiently encode symbolic equivalence, allowing for compact representation of functionally identical expressions by sharing common sub-expressions, leading to significant memory savings.
> - Integrating equivalence into MCTS results in a tighter regret bound by effectively reducing the branching factor of the search tree, focusing computational effort on genuinely distinct paths.
> - Aggregating rewards for equivalent expressions in DRL provides an unbiased gradient estimator with lower variance, contributing to more stable and efficient policy updates.
> - The Egg module introduces negligible computational overhead to the overall symbolic regression pipeline, making its integration practical and scalable.
