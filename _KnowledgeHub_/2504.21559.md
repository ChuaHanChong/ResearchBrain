# Black-Box Visual Prompt Engineering for Mitigating Object Hallucination in Large Vision Language Models

> [!summary] Summary
> Black-Box Visual Prompt Engineering (BBVPE) mitigates object hallucination in Large Vision Language Models (LVLMs) by strategically applying visual cues to input images, without requiring access to model internals. This approach improved accuracy on the POPE Random benchmark by up to 1.77% for LLaVA 1.5 and 1.50% for GPT-4o.

## Problem

- Large Vision Language Models (LVLMs) frequently hallucinate objects, incorrectly claiming to perceive objects not present in images.
- This object hallucination reduces the reliability and utility of LVLMs in sensitive applications.
- Current mitigation techniques often require access to internal model parameters, preventing their use with black-box proprietary LVLMs like GPT-4o.

## Method

- The ==Black-Box Visual Prompt Engineering (BBVPE)== framework modifies input images with ==visual cues== to guide LVLMs toward accurate visual understanding.
- It leverages an ==object segmentation model== to identify objects, then applies various visual prompt types (e.g., bounding boxes, reverse blur, crop).
- A trained ==Visual Prompt Router== selects the most effective visual prompt for each image-query pair to minimize hallucination.

## Results

- BBVPE consistently improved LVLM accuracy on the POPE and CHAIR hallucination benchmarks, outperforming baselines across all tested models.
- On the POPE Random benchmark, BBVPE increased accuracy by **1.77%** for LLaVA 1.5, **1.50%** for GPT-4o, and **0.91%** for Claude 3.0-Sonnet.
- The visual prompt router, trained on COCO, demonstrated effective generalization by improving performance on unseen datasets like GQA.

## Takeaways

> [!tip] Key Insights
> - Object hallucination in LVLMs often arises from imperfect alignment between vision and language components, compounded by pre-training data biases.
> - The optimal type of visual prompt for reducing hallucination varies significantly across different LVLMs (e.g., GPT-4o vs. LLaVA) and datasets.
> - Dynamically selecting the most effective visual prompt for a given image and query, rather than using a fixed prompt, yields better hallucination mitigation.
