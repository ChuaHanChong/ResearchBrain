# Black-Box Visual Prompt Engineering for Mitigating Object Hallucination in Large Vision Language Models

> [!summary] Summary
> Black-Box Visual Prompt Engineering (BBVPE) mitigates object hallucination in Large Vision Language Models (LVLMs) by strategically applying visual cues to input images, without requiring access to model internals. This approach improved accuracy on the POPE Random benchmark by up to 1.77% for LLaVA 1.5 and 1.50% for GPT-4o.

## Problem

- Large Vision Language Models (LVLMs) frequently hallucinate objects, incorrectly claiming to perceive objects not present in images.
- This object hallucination reduces the reliability and utility of LVLMs in sensitive applications.
- Current mitigation techniques often require access to internal model parameters, preventing their use with black-box proprietary LVLMs like GPT-4o.

## Method

- The ==Black-Box Visual Prompt Engineering (BBVPE)== framework modifies input images with ==visual cues== to guide LVLMs toward accurate visual understanding.
- It leverages an ==object segmentation model== to identify objects, then applies various visual prompt types (e.g., bounding boxes, reverse blur, crop).
- A trained ==Visual Prompt Router== selects the most effective visual prompt for each image-query pair to minimize hallucination.

## Results

- BBVPE consistently improved LVLM accuracy on the POPE and CHAIR hallucination benchmarks, outperforming baselines across all tested models.
- On the POPE Random benchmark, BBVPE increased accuracy by **1.77%** for LLaVA 1.5, **1.50%** for GPT-4o, and **0.91%** for Claude 3.0-Sonnet.
- The visual prompt router, trained on COCO, demonstrated effective generalization by improving performance on unseen datasets like GQA.

## Takeaways

> [!tip] Key Insights
> - Object hallucination in LVLMs often arises from imperfect alignment between vision and language components, compounded by pre-training data biases.
> - The optimal type of visual prompt for reducing hallucination varies significantly across different LVLMs (e.g., GPT-4o vs. LLaVA) and datasets.
> - Dynamically selecting the most effective visual prompt for a given image and query, rather than using a fixed prompt, yields better hallucination mitigation.

## Detailed Report

### 1. Introduction

Large Vision Language Models (LVLMs) have demonstrated impressive capabilities in understanding and generating text based on visual inputs. However, they frequently suffer from "object hallucination" - incorrectly claiming to see objects that aren't present in images. This undermines their reliability and utility in critical applications such as healthcare, autonomous systems, and assistive technologies.

Most existing solutions to hallucination require access to model internals, making them unusable with proprietary LVLMs like GPT-4o or Claude 3. This paper introduces a novel approach called Black-Box Visual Prompt Engineering (BBVPE) that works with any LVLM without requiring access to internal parameters or architecture. The method strategically modifies input images with visual cues that help guide the model toward more accurate visual understanding.

### 2. Understanding Object Hallucination

Object hallucination occurs when an LVLM incorrectly claims to see objects that aren't present in an image. This problem stems from several factors:

1. Imperfect alignment between vision encoders and language decoders
2. Biases in pre-training data
3. The tendency of generative models to "fill in" details based on context

For example, when shown an image of a breakfast setting with donuts, an LVLM might hallucinate "three donuts" when only one is present, or claim to see a "pastry" alongside the donut when no pastry exists. These errors can propagate into downstream reasoning, leading to compounded inaccuracies.

The severity of hallucination can be measured using benchmarks like POPE (Precision of Object Presence Evaluation) and CHAIR (Caption Hallucination Assessment with Image Relevance), which systematically test whether models hallucinate objects by asking direct questions about object presence.

### 3. Black-Box Visual Prompt Engineering Framework

The BBVPE framework introduces a systematic approach to mitigating hallucinations without modifying the LVLM itself. The framework consists of three key components:

1. **Visual Prompt Pool**: A collection of visual cues (bounding boxes, circles, arrows, etc.) that can be applied to input images
2. **Scoring Function**: A method to evaluate how effectively each visual prompt reduces hallucination
3. **Visual Prompt Router**: A model that learns to select the optimal visual prompt for each image and query

The approach works by first detecting objects in an image using a segmentation model (such as SAM - Segment Anything Model), then strategically applying visual prompts to highlight relevant objects. The framework then uses a router model to predict which visual prompt type will most effectively reduce hallucination for a given image.

The mathematical formulation can be expressed as finding the optimal visual prompt $v^*$ that maximizes accuracy for a given image $x$ and question $q$:

$$v^* = \arg\max_{v \in \mathcal{V}} S(f(x_v, q), y)$$

Where:
- $\mathcal{V}$ is the visual prompt pool
- $x_v$ is the image with visual prompt $v$ applied
- $f(x_v, q)$ is the LVLM's response
- $S(f(x_v, q), y)$ is the scoring function comparing the response to ground truth $y$

### 4. Visual Prompt Types and Their Effects

The research examines several types of visual prompts and their effectiveness in reducing hallucination:

1. **Bounding Boxes**: Rectangular outlines around detected objects
2. **Crop**: Zooming in on relevant regions of the image
3. **Reverse Blur**: Blurring everything except relevant objects
4. **Circle**: Circular highlights around objects
5. **Arrow**: Directional pointers toward relevant objects
6. **Center Point**: Dots placed at the center of objects
7. **Colored Box**: Bounding boxes with colored fills

Different visual prompts have varying effects on different LVLMs. For example, as shown in Figure 3, when prompted with the same image of donuts and coffee:

- The base image might trigger hallucinations about "three donuts"
- A "reverse blur" prompt may correctly identify a single donut
- Other prompts like "circle" or "arrow" might introduce different hallucinations

Initial experiments revealed that the optimal visual prompt differs across models and datasets:
- "Reverse blur" works best for LLaVA and InstructBLIP
- "Crop" performs better for GPT-4o and Claude 3.0-Sonnet

This variability highlights the need for a dynamic selection mechanism rather than a one-size-fits-all approach.

### 5. The Visual Prompt Router

The visual prompt router is a neural network trained to predict which visual prompt will most effectively reduce hallucination for a given image. The router uses a CLIP vision encoder to extract image features, followed by a Multi-Layer Perceptron (MLP) to predict scores for each visual prompt type.

Training the router involves:

1. Creating a dataset of image-question pairs with ground truth answers
2. Applying each visual prompt type to each image
3. Querying the LVLM with these prompted images
4. Calculating the accuracy score for each prompt
5. Training the router to predict the prompt with the highest accuracy

The router is optimized using a softmax cross-entropy loss:

$$\mathcal{L} = -\frac{1}{N} \sum_{i=1}^{N} \log \frac{\exp(s_{i,y_i})}{\sum_{j=1}^{|\mathcal{V}|} \exp(s_{i,j})}$$

Where $s_{i,j}$ is the predicted score for the $j$-th visual prompt on the $i$-th image, and $y_i$ is the index of the best-performing prompt.

### 6. Experimental Results

The BBVPE approach was evaluated on multiple benchmarks including POPE and CHAIR, using both open-source LVLMs (LLaVA 1.5, InstructBLIP) and proprietary models (GPT-4o, Claude 3.0-Sonnet).

Key findings include:

1. **Consistent Improvement**: BBVPE consistently outperformed baselines (no visual prompt, random prompt selection, and fixed prompt type) across all tested models and benchmarks.

2. **Significant Gains**: For the POPE Random benchmark, BBVPE improved accuracy by:
 - 1.77% for LLaVA 1.5
 - 1.27% for InstructBLIP
 - 1.50% for GPT-4o
 - 0.91% for Claude 3.0-Sonnet

3. **Gap to Oracle Performance**: While effective, BBVPE still performs below the "Oracle" (which uses the optimal prompt for each individual image-question pair), indicating room for further improvement.

4. **Cross-Dataset Generalization**: The router model trained on COCO dataset demonstrated strong generalization capabilities when applied to unseen datasets like GQA.

5. **Computational Efficiency**: BBVPE adds minimal computational overhead compared to more complex methods like fine-tuning or reinforcement learning from human feedback.

### 7. Advantages Over Existing Methods

BBVPE offers several key advantages over existing hallucination mitigation approaches:

1. **Black-Box Compatibility**: Works with any LVLM without requiring access to internal weights or architecture, making it applicable to proprietary models.

2. **No Retraining Required**: Unlike training-based methods that require model fine-tuning, BBVPE works with pre-trained models as-is.

3. **Input-Side Modification**: By modifying the input image rather than the model or decoding process, BBVPE maintains the model's original capabilities while improving its perception.

4. **Computational Efficiency**: The approach adds minimal overhead in terms of latency and computational resources, especially compared to methods requiring multiple forward passes.

5. **Interpretability**: The visual prompts provide explicit cues about which objects the model is focusing on, adding a layer of transparency to the process.

### 8. Limitations and Future Work

Despite its effectiveness, BBVPE has several limitations that suggest directions for future research:

1. **Limited to Natural Images**: The current approach works best with natural images and may not generalize to abstract or synthetic visuals.

2. **Bounding Box Limitations**: Current visual prompts use bounding boxes, which may not capture fine-grained object details. Future work could explore mask-based prompts for more precise object highlighting.

3. **Question-Agnostic Router**: The current router doesn't consider the question when selecting a visual prompt. Incorporating question context could further improve performance.

4. **Focus on Object Hallucination**: BBVPE primarily addresses object hallucination rather than attribute or relation hallucinations, which remain challenging problems.

5. **Dependence on Object Localization**: The method relies on accurate object detection, and errors in object localization can propagate to visual prompt selection.

Future enhancements could include:
- Developing question-aware routing mechanisms
- Exploring combinations of multiple visual prompts
- Integrating visual prompting with textual prompt engineering
- Extending the approach to video understanding tasks

### 9. Conclusion

Black-Box Visual Prompt Engineering represents a significant advancement in addressing the critical challenge of object hallucination in Large Vision Language Models. By strategically applying visual cues to images, BBVPE improves LVLM perception without requiring access to model internals, making it a practical solution for both open-source and proprietary models.

The demonstrated effectiveness across multiple benchmarks and models suggests that visual prompting is a promising direction for improving LVLM reliability. As LVLMs continue to be deployed in critical applications, techniques like BBVPE that enhance their factual accuracy will be essential for ensuring safe and trustworthy AI systems.

By focusing on input-side modifications rather than model architecture changes, BBVPE offers an accessible approach that can be immediately applied to existing LVLMs, providing a bridge solution while more comprehensive approaches to hallucination mitigation continue to be developed.
