# PersonaVLM: Long-Term Personalized Multimodal LLMs

> [!summary] Summary
> PersonaVLM introduces an agent framework designed for Multimodal Large Language Models (MLLMs) to achieve long-term, dynamic personalization through a novel memory architecture and a two-stage collaborative process. This framework demonstrates improved personalized understanding and alignment, outperforming proprietary models like GPT-4o in open-ended generation based on factual accuracy and personality alignment.

## Problem

- Existing MLLMs and personalization methods struggle with static user traits, fixed context windows, and a "one-size-fits-all" approach to output alignment, failing to capture evolving user preferences over long interactions.
- Current personalization techniques often lack mechanisms for proactively managing or updating user-specific knowledge from dynamic multimodal interactions.
- There is a lack of high-quality training data and comprehensive benchmarks specifically designed for evaluating long-term, dynamic, and multimodal personalization in MLLMs.

## Method

- The **PersonaVLM** framework proposes a ==personalized memory architecture== that includes a dynamic user personality profile (==Big Five traits==) and a ==multi-type memory database== (core, procedural, semantic, and episodic memories).
- It employs a ==two-stage collaborative process== (Response and Update) which utilizes ==multi-step reasoning== and ==timeline-based retrieval== to generate and refine personalized responses.
- A dedicated training pipeline leverages a ==synthetic large-scale multimodal dataset== and a ==two-stage fine-tuning== approach (==Supervised Fine-Tuning== followed by ==Reinforcement Learning==) to teach memory management, multi-turn reasoning, and alignment.

## Results

- PersonaVLM improved the baseline by **22.4%** on Persona-MME (**128k context**) and **9.8%** on PERSONAMEM, demonstrating superior personalized understanding compared to open-source models and being competitive with or outperforming GPT-4o in various configurations.
- The framework achieved robust personalized alignment, leading the next-best model by **9.16%** on the Persona-MME alignment sub-task and showing a greater than **12%** gain over the baseline on the P-SOUPS benchmark.
- In open-ended generation, PersonaVLM achieved a **79% win rate** against GPT-4o, based on factual accuracy and personality alignment, as evaluated by an automated judge (Gemini-2.5-Pro).

## Takeaways

> [!tip] Key Insights
> - Dynamic memory architectures, integrating evolving personality profiles and multi-type multimodal memory databases, are crucial for effective long-term personalization in MLLMs.
> - A multi-stage agentic retrieval and reasoning process allows MLLMs to proactively manage and leverage long-term user context beyond fixed context windows, leading to more precise and personalized responses.
> - Continuous personality evolution mechanisms, dynamically updated after each interaction, are essential for adapting to subtle shifts in user traits and preferences over extended dialogues.
