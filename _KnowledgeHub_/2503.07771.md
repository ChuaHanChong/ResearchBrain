# RoboCopilot: Human-in-the-loop Interactive Imitation Learning for Robot Manipulation

> [!summary] Summary
> RoboCopilot, developed by UC Berkeley researchers, presents an interactive imitation learning system for robot manipulation, integrating a bilateral teleoperation interface with bimanual robots. The system allows human operators to provide real-time corrections during autonomous execution, significantly improving learning efficiency and policy performance for complex, contact-rich tasks.

## Problem

- Traditional imitation learning methods for robot manipulation suffer from covariate shift, leading to compounding errors when robots encounter states unseen in demonstration data.
- Offline learning from demonstrations is data-inefficient, typically requiring large datasets to achieve robust performance and lacking adaptability to novel situations or real-time error correction.
- Existing teleoperation interfaces often lack intuitive control mechanisms and seamless switching between autonomous and human operation, hindering effective human-in-the-loop learning for complex tasks.

## Method

- **RoboCopilot** introduces a human-in-the-loop interactive imitation learning framework that integrates a compliant, bilateral teleoperation device with a mobile bimanual manipulator.
- The system employs an adapted ==Human-Gated DAgger (HG-DAgger)== algorithm, allowing human operators to provide targeted corrections during autonomous execution, which are then used to update the policy.
- It features a seamless software framework for intuitive switching between autonomous policy execution and human teleoperation, enabling efficient data collection for error correction.

## Results

- RoboCopilot consistently outperformed offline behavior cloning in simulation, with Batched DAgger achieving near-perfect success rates on most tasks.
- In real-world industrial part picking, the system achieved over **90%** success rate after interactive training, up from **60%** with offline methods.
- The system successfully mastered a complex, long-horizon bimanual kitchen task with only 20 demonstrations, requiring 30-**50%** fewer demonstrations than offline behavior cloning for comparable performance.

## Takeaways

> [!tip] Key Insights
> - Interactive learning with targeted human interventions significantly enhances policy performance and learning efficiency compared to offline behavior cloning, especially for complex manipulation tasks.
> - A kinematically similar, bilateral teleoperation interface with force feedback is crucial for enabling intuitive human control and effective real-time correction of robot behaviors.
> - The integration of a compliant bimanual robot with an interactive learning framework allows for mastering long-horizon, contact-rich bimanual tasks with fewer demonstrations.
