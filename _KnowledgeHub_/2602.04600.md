# Act, Sense, Act: Learning Non-Markovian Active Perception Strategies from Large-Scale Egocentric Human Data

> [!summary] Summary
> Researchers from Shanghai Jiao Tong University introduced CoMe-VLA, a framework that enables robots to learn non-Markovian active perception strategies from large-scale egocentric human data. The system integrates cognitive awareness and a dual-track memory to proactively resolve information uncertainty, achieving an 83.3% mean success rate in complex manipulation tasks while significantly reducing reliance on robot-specific demonstrations.

## Problem

- Existing robotic manipulation methods exhibit perceptual passivity, struggling when crucial information is out of view, occluded, or requires proactive investigation.
- Current active perception approaches often lack a rigorous theoretical framework and fail to leverage complex body movements or physical interaction for information discovery.
- Transferring complex human active perception behaviors to robots is challenging due to the cross-embodiment gap and the need for memory and cognitive awareness in long-horizon, non-Markovian tasks.

## Method

- Formalized active perception as a Non-Markovian Decision Process (NMDP) driven by information gain and decision branching, categorizing it into Information Discovery and Information Enrichment paradigms.
- Developed CoMe-VLA (Cognitive and Memory-aware Vision-Language-Action), an architecture based on a Vision-Language Model augmented with a Cognitive Auxiliary Head for sub-task transitions and a Dual-Track Memory System for historical context.
- Employed a three-stage progressive training pipeline, pretraining on large-scale egocentric human data (CaptainCook4D, Ego-Exo4D) and fine-tuning on robot teleoperation data aligned in a unified egocentric action space.

## Results

- CoMe-VLA achieved a mean Success Rate of 83.3% and a mean Search Time of 97.9s across five long-horizon tasks, substantially outperforming state-of-the-art general-purpose VLAs (e.g., OpenVLA-OFT: 12.7% SR).
- Increasing human data from 400k to 800k samples boosted performance from 72.0% to 87.3% SR, demonstrating that large-scale human data reduces the dependency on extensive robot-specific supervision.
- Ablation studies confirmed the critical roles of cognition (removing it reduced SR to 22.7%) and memory (removing it reduced SR to 40.7%), with the dual-track memory significantly outperforming single or partial memory systems.

## Takeaways

> [!tip] Key Insights
> - Active perception is inherently non-Markovian, requiring an explicit memory system and cognitive awareness to handle long-horizon tasks and adaptive decision-making.
> - Large-scale egocentric human data effectively provides dense exploratory priors, drastically reducing the amount of robot-specific data needed for successful transfer of active perception strategies.
> - The dual-track memory (visual and proprioceptive) and a dedicated cognitive auxiliary head are critical for maintaining consistent self- and environmental awareness, enabling autonomous transitions between exploratory and exploitative behaviors.
