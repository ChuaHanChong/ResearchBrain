# Rendering-Aware Reinforcement Learning for Vector Graphics Generation

> [!summary] Summary
> ServiceNow Research and Mila developed Rendering-Aware Reinforcement Learning (RLRF), a method that integrates visual feedback from rendered SVG outputs into the training of Vision-Language Models for vector graphics generation. This approach enabled a Qwen2.5VL-7B model to achieve state-of-the-art performance on the SVG-Stack-Hard test set, reducing MSE from 8.60 to 1.03 and improving SSIM from 79.40 to 95.10, while also enhancing code efficiency.

## Problem

- Existing Vision-Language Models (VLMs) for SVG generation are "rendering unaware," optimizing only for token-level losses without direct feedback on the visual fidelity or efficiency of rendered outputs.
- This lack of visual grounding leads to issues such as visual misalignments, hallucinated elements, repetitive code, and poor generalization in generated SVGs.
- The inherent non-differentiability of rendering discrete SVG code into pixel images prevents direct gradient-based optimization from visual feedback in autoregressive VLM training.

## Method

- A two-stage training approach first applies ==supervised fine-tuning== (SVG-SFT) to a VLM, then refines it using Reinforcement Learning from Rendering Feedback (RLRF).
- RLRF involves generating multiple SVG rollouts, rendering them into pixel images, and computing a scalar composite reward based on visual fidelity, semantic alignment, and code efficiency.
- Policy optimization is performed using Group Relative Policy Optimization (GRPO), which updates the VLM's policy to maximize the expected reward from rendering feedback, circumventing non-differentiability.

## Results

- RLRF achieves new state-of-the-art Im2SVG performance on SVG-Stack-Hard, with a Qwen2.5VL-**7B** model reducing MSE to 1.03 from 8.60 (SFT baseline) and improving SSIM to 95.10, while significantly enhancing code efficiency by reducing the penalty from -2.8k to -334.
- The method demonstrates strong generalization to Text2SVG and out-of-distribution SVG datasets (Emoji, Fonts, Icons), often outperforming larger, proprietary VLMs like GPT-4o and Gemini 1.5 Pro in visual fidelity and code compactness.
- A user study confirmed that RLRF-generated SVGs are preferred by professional designers for both visual fidelity (**42.7%** preference vs. **12%** for SFT) and editability (**59.2%** preference vs. **15%** for SFT).

## Takeaways

> [!tip] Key Insights
> - Reinforcement learning effectively integrates non-differentiable rendering feedback into autoregressive VLM training, bridging the gap between discrete code generation and continuous visual outcomes.
> - A meticulously designed composite reward function, balancing pixel-level fidelity, semantic alignment (e.g., DreamSim, VLM-as-judge), and code efficiency, is crucial for generating practical and editable vector graphics.
> - Online reinforcement learning with sufficient exploration (e.g., higher sampling temperatures, increased rollouts) fosters deeper understanding of SVG structure and improves generalization beyond pattern memorization.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The generation of structured visual code from perceptual inputs, often termed the "inverse rendering code generation problem," is a burgeoning field within artificial intelligence. It aims to translate complex visual information (images or text descriptions) into executable code that faithfully reproduces the target content. This task has seen significant advancements with the rise of Vision-Language Models (VLMs) and large language models (LLMs), which are adept at visual-symbolic reasoning and autoregressive sequence generation.

Scalable Vector Graphics (SVG) is a particularly attractive target format due to its compactness, editability, resolution independence, and natural alignment with the token-based generation processes of language models. Recent research, including works like StarVector (Rodriguez et al., 2025b), has framed SVG generation as a code synthesis problem, leveraging VLMs pretrained on vast datasets of vision, natural language, and code. These models typically employ supervised learning (SFT) on tokenized SVG sequences, achieving good syntactic correctness and visual accuracy on relatively short and simple examples.

However, a critical limitation in these existing VLM approaches is their inherent "rendering unawareness." During supervised training, these models optimize token-level losses but never actually "see" or evaluate the rendered visual output of the SVG code they generate. This disconnect leads to several failure modes: models struggle with consistency over long sequences, hallucinate visual elements, enter repetitive loops, or lose grounding when facing complex or out-of-distribution inputs. While differentiable rendering techniques exist (e.g., DiffVG for continuous primitive parameters), they are incompatible with the discrete, token-by-token generation process of autoregressive VLMs, which makes direct gradient propagation through the rendering step infeasible.

This paper addresses precisely this critical gap. It introduces Reinforcement Learning from Rendering Feedback (RLRF) as a post-training strategy to inject visual feedback directly into the learning loop of autoregressive VLMs for SVG generation. By embracing the non-differentiability of rendering as an opportunity for evaluative feedback suitable for reinforcement learning, RLRF bridges the gap between SVG code generation and its visual manifestation. This places the work at the intersection of multimodal AI, code generation, and reinforcement learning, pushing the boundaries of what VLMs can achieve in structured visual synthesis by making them "rendering-aware." It seeks to overcome the limitations of purely supervised methods by providing a richer, more accurate training signal derived from the actual visual output.

### 2. Key Objectives and Motivation

The core objective of this research is to **enhance the SVG generation capabilities of autoregressive Vision-Language Models (VLMs) by integrating visual feedback from rendered SVG outputs into the training process.**

The primary motivations driving this objective are:

- **Addressing the "Rendering Unawareness" of Current VLMs:** Existing VLM-based SVG generation methods are trained using token-level losses (e.g., negative log-likelihood) on SVG code. While this ensures syntactic correctness, models never receive direct feedback on the *visual fidelity* or *efficiency* of their generated code when rendered into an image. This lack of visual grounding leads to significant issues such as misalignments, hallucinated shapes, repetitive code structures, or failure to generalize to complex visual patterns.
- **Overcoming Non-Differentiability Challenges:** The process of rendering SVG code into a pixel image is inherently non-differentiable in the context of discrete, autoregressive token generation. This prevents the use of standard backpropagation techniques from a rendered image loss directly to the model's parameters. The authors are motivated to find an alternative mechanism to leverage this valuable visual information.
- **Improving Fidelity, Efficiency, and Generalization:** The ultimate goal is to enable VLMs to produce SVGs that are not only syntactically correct but also:
 - **Visually Accurate:** Faithfully reconstruct the input image or align with the text prompt.
 - **Semantically Coherent:** Capture the high-level meaning and structure of the visual content.
 - **Code Efficient:** Generate compact, editable, and well-structured SVG code, avoiding redundancy and excessive length.
 - **Robust and Generalizable:** Perform well on diverse and even out-of-distribution inputs, developing a deeper understanding of SVG structure rather than merely memorizing patterns.

By introducing RLRF, the authors aim to transform VLMs from mere SVG *syntax generators* into sophisticated *visual code synthesizers* that can iteratively refine their outputs based on observable visual consequences, much like a human designer would.

### 3. Methodology and Approach

The proposed RLRF (Reinforcement Learning from Rendering Feedback) method employs a two-stage training approach to refine the SVG generation capabilities of pretrained VLMs.

**Stage 1: Supervised Fine-Tuning on Images and SVGs (SVG-SFT)**
The first stage involves traditional supervised fine-tuning. A base VLM (e.g., Qwen2.5-VL or StarVector) is adapted to the image-to-SVG (Im2SVG) task. Given a conditioning input (image or text prompt, denoted `xc`) and a ground-truth SVG token sequence (`xs`), the model minimizes the negative log-likelihood of generating `xs` conditioned on `xc`. This teacher-forcing approach efficiently trains the model to predict the next token, building a foundational understanding of SVG syntax, structure, and basic visual patterns. After this stage, the model, `pθ_sft`, can generate plausible SVG code but lacks direct visual awareness of its rendered outputs.

**Stage 2: Reinforcement Learning from Rendering Feedback (RLRF)**
In the second stage, the SVG-SFT model's conditional distribution `pθ` is reinterpreted as a stochastic policy. The core idea is to introduce a feedback loop based on the visual rendering of the generated SVG code.

1. **SVG Rollouts:** For each input `xc`, the VLM generates multiple SVG sequences, referred to as "rollouts" (`o`). This involves sampling discrete tokens autoregressively.
2. **Rendering and Reward Computation:** Each generated SVG rollout `o` is then rendered into a pixel image (`I_pred`) using a standard SVG renderer (e.g., CairoSVG). This rendered image is compared to the original input image (`I_in`) or evaluated against the text prompt. A composite scalar reward `R(xc, o)` is computed based on this comparison.
3. **Policy Optimization with GRPO:** The model's policy `pθ` is updated to maximize the expected reward `E[R(xc, o)]`. To handle the discrete sampling steps and non-differentiable rendering, the authors employ Group Relative Policy Optimization (GRPO) (Guo et al., 2025). GRPO is a policy gradient method that:
 - Avoids the need for a separate value network (critic) by centering rewards within a batch (`A_i = R(xc, o_i) - mean(R_batch)`).
 - Maintains policy stability by using a clipped probability ratio, similar to PPO (Proximal Policy Optimization) (Schulman et al., 2017), preventing large policy updates.
 - Optionally includes a KL regularization term (`βD_KL(pθ || pθ_sft)`) to prevent catastrophic forgetting of the initial SFT policy, though ablations later show this might not always be necessary or beneficial.

**Composite Reward Function Design:**
A crucial aspect of RLRF is the meticulously designed composite reward function, which provides rich and targeted feedback without human annotations:

- **Image Reconstruction Rewards:**
 - **L2 Distance (`R_img`):** Measures pixel-level fidelity between the normalized input image `I_in` and rendered prediction `I_pred`. Normalization ensures emphasis on structural and color discrepancies rather than brightness.
 - **L2 Canny:** An edge-aware variant where Canny edge detection is applied to both images before computing L2 distance, focusing on structural alignment and crisp contours.
- **Semantic Similarity Rewards:**
 - **DreamSim (`R_sim`):** For Im2SVG, this metric (Fu et al., 2023) combines features from CLIP, OpenCLIP, and DINOv2 via cosine similarity to assess perceptual and semantic alignment between `I_in` and `I_pred`.
 - **DreamSim Canny:** Applies edge detection before DreamSim to emphasize shape-focused semantic similarity.
 - **CLIP Similarity (for Text2SVG):** Computes cosine similarity between the text prompt embedding and the rendered SVG image embedding.
 - **VLM as a Judge (for Text2SVG):** A separate strong VLM (Qwen2.5VL-7B) is prompted to evaluate the generated SVG's alignment, visual resemblance, and aesthetic quality against the text prompt, providing a higher-level semantic reward.
- **Code Efficiency Rewards:**
 - **SVG Length Deviation (`R_len`):** Penalizes predicted SVG token lengths (`L_pred`) that deviate excessively from the ground truth length (`L_gt`). Specifically, it applies a quadratic penalty if `L_pred` exceeds half of `L_gt`, encouraging compact and non-redundant code.

The final reward `R_total` is a weighted sum of these individual components, allowing for flexible tuning to balance different aspects of SVG quality. The weights of these components are not explicitly stated in the core paper, but it is clear that they are tuned for optimal performance.

**Implementation Details:**
The method uses Qwen2.5-VL models (3B, 7B) for Im2SVG and Qwen3-8B for Text2SVG. SVG-Stack (1.7M pairs) is used for SFT, while a curated subset of 20k high-entropy samples from SVG-Stack is used for RLRF. Training is performed on H100/A100 GPUs, using GRPO with a batch size of 32 images and 64 rollouts per image. vLLM is leveraged for efficient rollout generation.

### 4. Main Findings and Results

The RLRF method demonstrates significant improvements in SVG generation across various benchmarks and metrics, outperforming supervised fine-tuning (SVG-SFT) and several strong baselines.

#### 4.1. Im2SVG Results (Table 1, Figure 2, 7, 12)

- **State-of-the-Art Performance:** RLRF sets a new state-of-the-art on the SVG-Stack-Hard test set. For instance, the Qwen2.5VL-7B model, after SVG-SFT and RLRF, achieves an MSE of 1.03, SSIM of 95.10, DINO of 98.70, and LPIPS of 3.08. These are substantial improvements over the SVG-SFT baseline (MSE 8.60, SSIM 79.40, DINO 93.00, LPIPS 16.58) and surpass even larger commercial VLMs like GPT-4o and Gemini 1.5 Pro, and specialized image processing methods.
- **Balanced Improvement:** Unlike image processing methods (e.g., LIVE, VTracer) which achieve very low MSE but generate extremely long and inefficient SVG code (e.g., -18.3k to -99.7k token efficiency), RLRF significantly improves both visual fidelity (lower MSE, LPIPS; higher SSIM, DINO) and code efficiency. For Qwen2.5VL-7B, RLRF reduces the code efficiency penalty from -2.8k to -334, indicating much more compact and meaningful SVG code generation.
- **Qualitative Fidelity:** Qualitative examples (Figure 2, 7) show RLRF generating coherent, well-aligned SVGs that capture fine details and complex structures, correcting misalignments and missing elements often seen in SVG-SFT outputs. The "apple" and "strawberry" examples (Figure 1, 12) showcase RLRF's ability to handle complex lighting and gradient effects, even on out-of-distribution styles.

#### 4.2. Text2SVG Results (Table 4, Figure 3, 8, 9)

- **Strong Generalization:** RLRF enables models to generalize to the Text2SVG task, consistently producing SVGs that align closely with user prompts, even when trained only on image captions (Flickr30k, MM-Icons) without direct SVG supervision for these tasks.
- **Outperforming Baselines:** Qwen3-8B with RLRF approaches OmniSVG's performance and significantly outperforms other open-source and closed-source VLMs like Qwen3-32B, GPT-4o, and Gemini 1.5 Pro on MM-Icon and MM-Illustration datasets (Table 4). This is particularly noteworthy given that Qwen3-8B is a smaller, text-only model that learns visual coherence purely through the VLM-as-judge reward signal.
- **Reasoning Capability:** Figure 9 illustrates how RLRF-trained models can incorporate a `<think>` phase, planning the SVG generation process based on the text prompt, leading to more structured and semantically rich outputs.

#### 4.3. Generalization Across SVG Benchmarks (Table 3, Figure 10, 11)

- RLRF models exhibit robust generalization to out-of-distribution datasets (SVG-Emoji, SVG-Fonts, SVG-Icons) that were not seen during training.
- For example, on SVG-Emojis, Qwen2.5VL-7B + RLRF improves MSE from 6.39 (SVG-SFT) to 4.93, and DINO from 90.99 to 93.50, while dramatically improving code efficiency. Similar trends are observed on SVG-Fonts.
- While image processing methods often excel at pixel-level metrics on these simple glyphs, RLRF provides a superior balance of visual quality and code efficiency/editability.

#### 4.4. Ablation Studies (Figure 4, 5, 6, 13, Table 2, 5)

- **Importance of SVG Exploration:** Higher sampling temperatures (e.g., 1.0-1.2) and an increased number of rollouts (up to 64) consistently improve performance by promoting diversity and richer reward signals (Figure 4, 5).
- **Role of KL Term:** Removing the KL divergence penalty in the GRPO objective improved reward progression and avoided early saturation without causing instability, suggesting the reward function sufficiently regularizes the policy (Figure 6).
- **Necessity of SFT:** Running RLRF directly on instruction-tuned models without initial SVG-SFT yielded poor results (Table 2), highlighting that SVG-SFT is crucial for building a foundational SVG proficiency before RL refinement.
- **Impact of Rewards:** The composite reward function, combining L2, L2 Canny, DreamSim, and the length penalty, consistently achieved the best overall performance, balancing pixel-level accuracy, semantic alignment, and code compactness (Figure 13, Table 5). L2-based rewards improve reconstruction, while DreamSim-based rewards enhance perceptual and semantic consistency.
- **Reward Hacking:** The authors identified and mitigated several reward hacking cases, such as the "Small ViewBox Hack" (model generating tiny viewboxes for high L2 scores) and "Text-in-Image Hack" (model using `<text>` primitive to render prompts), demonstrating practical considerations in RL system design.

#### 4.5. User Study (Figure 14)

- A user study confirmed that RLRF significantly improves both **fidelity** (preferred in 42.7% of comparisons vs. 12% for SFT) and **editability** (preferred in 59.2% vs. 15% for SFT) of generated SVGs compared to SFT alone. Professional designers noted RLRF's cleaner structure and more interpretable paths.

### 5. Significance and Potential Impact

The "Rendering-Aware Reinforcement Learning for Vector Graphics Generation" paper makes several significant contributions with far-reaching potential impacts:

1. **Bridging the Code-Rendering Gap for VLMs:** The most significant contribution is demonstrating that reinforcement learning can effectively bridge the gap between discrete code generation by autoregressive VLMs and the continuous visual feedback from rendering. This addresses a fundamental limitation in existing VLM-based approaches, which were "rendering-unaware," leading to improved visual fidelity and semantic coherence in generated SVGs. This is a novel application of online RL to inverse rendering code generation tasks.

2. **Enabling High-Quality, Efficient, and Editable Vector Graphics:** By optimizing for a composite reward that balances pixel-level accuracy, semantic alignment, and code efficiency, RLRF allows VLMs to generate SVGs that are not just visually appealing but also practical. The resulting SVGs are compact, well-structured, and easily editable, making them suitable for real-world design and development workflows. This contrasts sharply with traditional image processing methods that produce bloated, unstructured, and often semantically meaningless SVG code.

3. **Enhanced Generalization and Robustness:** The RLRF framework significantly improves the generalization capabilities of VLMs, enabling them to handle out-of-distribution visual domains (e.g., emojis, fonts, icons) and complex styles (e.g., shadows, gradients) that were not explicitly seen during training. This suggests that learning from rendering feedback fosters a deeper, more robust understanding of SVG structure and visual semantics, moving beyond mere pattern memorization.

4. **A General Framework for Code-Driven Visual Synthesis:** While the paper focuses on SVG, the core idea of RLRF is highly generalizable. The authors explicitly state its potential applicability to other inverse rendering code generation tasks such as:
 - **Web Development:** Generating HTML/CSS/JavaScript from visual designs or text prompts.
 - **Scientific Visualization:** Synthesizing LaTeX/TikZ code for diagrams and figures.
 - **3D Modeling:** Generating 3D rendering code or CAD models from images or descriptions.
 - **UI/UX Design:** Creating user interface code from mockups or textual specifications.
 This positions RLRF as a foundational step towards a broader paradigm for AI-driven visual creation where models can "self-correct" based on rendered outcomes.

5. **Democratizing High-Quality Design Tools:** By enabling smaller, open-source VLMs to produce high-quality vector graphics (e.g., Qwen2.5VL-7B outperforming much larger models and even some proprietary models), RLRF has the potential to democratize access to advanced design automation tools. This could empower a wider range of users, from designers to developers, to create and manipulate vector assets more efficiently.

6. **Insights into Reward Design for Structured Outputs:** The detailed ablation studies on the various reward components (L2, Canny, DreamSim, Length Deviation, VLM-as-judge) provide valuable insights into how to construct effective, automated reward signals for complex, structured generative tasks. This learning is crucial for future research in areas where human feedback is expensive or difficult to obtain.

In summary, RLRF represents a significant advancement in the field of AI-driven graphic design and code generation. By intelligently integrating rendering feedback into the training loop, it transforms VLMs into more capable, creative, and robust tools for synthesizing structured visual content, opening new avenues for automated design and content creation.
