# KVzip: Query-Agnostic KV Cache Compression with Context Reconstruction

> [!summary] Summary
> KVzip is a query-agnostic KV cache compression method for large language models that leverages context reconstruction to determine the importance of key-value pairs. This approach reduces KV cache size by 3-4 times and decoding latency by 2 times, effectively addressing memory and latency bottlenecks in long-context and multi-query applications while maintaining performance.

## Problem

- Transformer-based Large Language Models (LLMs) suffer from significant memory and latency overhead due to Key-Value (KV) caches, which grow quadratically with context length.
- Existing query-aware KV eviction methods are effective for single-query tasks but fail in multi-query scenarios or when a compressed cache needs to be reused, leading to repeated computation and performance degradation.
- The need for reusable compressed KV caches without requiring re-computation for every new query remains a challenge for practical LLM deployment.

## Method

- **KVzip** introduces a query-agnostic ==KV cache eviction== algorithm that scores KV pair importance based on their contribution to reconstructing the original context.
- It simulates context reconstruction by using a 'repeat prompt' and assigning importance scores to KV pairs based on the maximum attention they receive during this process.
- The method employs chunked scoring to manage the quadratic computational complexity of long contexts, reducing it to linear with context length (O(m * n_c)).

## Results

- KVzip achieves a 3 to 4 times reduction in KV cache size and approximately a 2 times reduction in decoding latency, with negligible performance loss across various LLMs and benchmarks.
- It consistently outperforms existing query-aware KV eviction methods in multi-query and reusable-cache scenarios, maintaining near-lossless performance where baselines significantly degrade.
- When combined with 4-bit KV cache quantization, KVzip reduced a LLaMA3-**8B**'s **16.3GB** cache to just **1.2GB** while preserving model performance, demonstrating substantial memory efficiency.

## Takeaways

> [!tip] Key Insights
> - An LLM's ability to reconstruct its own input context serves as a robust, query-agnostic metric for identifying the most crucial KV pairs for general contextual understanding.
> - The attention patterns observed during context reconstruction are sparser than typical self-attention, indicating that many KV pairs are indeed redundant for retaining core context.
> - KV features deemed important for context reconstruction show significant overlap with those relevant across diverse downstream tasks, supporting the generalizability of the approach.
