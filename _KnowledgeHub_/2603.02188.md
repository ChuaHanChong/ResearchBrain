# Multi-Head Low-Rank Attention

> [!summary] Summary
> Multi-Head Low-Rank Attention (MLRA) enhances large language model inference efficiency and scalability for long contexts in distributed environments. It achieves state-of-the-art perplexity and zero-shot reasoning accuracy while demonstrating substantial decoding speedups and reduced Key-Value (KV) cache loading compared to previous methods.

## Problem

- Long-context inference in large language models (LLMs) is bottlenecked by Key-Value (KV) cache loading, leading to memory-bound operations and high latency during decoding.
- Existing efficient attention mechanisms, such as Multi-Head Latent Attention (MLA), use a single, non-partitionable latent head, which creates a sharding bottleneck for Tensor Parallelism (TP) in distributed decoding.
- This sharding limitation forces each GPU in a TP configuration to redundantly load the entire KV cache, negating the benefits of TP for weight sharding and increasing memory traffic.

## Method

- ==MLRA== decomposes the latent attention computation into independent, partitionable ==low-rank branches== by shifting the summation from the KV computation to the attention output.
- ==MLRA-4== explicitly splits the latent head into four distinct latent heads, where attention is computed independently for each branch using the full set of query heads, and the resulting outputs are summed. This design inherently supports efficient ==4-way Tensor Parallelism==.
- ==Variance calibration== is integrated through scaling factors for query and KV latent states and attention outputs to ensure variance alignment between RoPE and NoPE components and maintain stable training.

## Results

- MLRA-4 achieved the lowest average perplexity (**13.672**) and highest average zero-shot accuracy (**58.84%**) across tested benchmarks using a 2.9B parameter Llama-3 model.
- It delivered a **2.8x** speedup over MLA and up to **1.26x** speedups over GQA for long-context decoding (up to 2M tokens) on a single NVIDIA H100 GPU.
- MLRA-4 reduced per-device KV cache loading to **1.5d_h** with 4-way Tensor Parallelism, significantly outperforming MLA (**4.5d_h**) and GLA-2 (**2.5d_h**) and matching GTA with fewer TP devices.

## Takeaways

> [!tip] Key Insights
> - Shifting the summation of block-wise projections from the KV computation to the attention output enables the creation of independent, low-rank attention branches that can be efficiently sharded.
> - Decomposing the latent attention mechanism into multiple distinct heads (e.g., four in MLRA-4) directly resolves the sharding bottleneck observed in single-head latent attention approaches under Tensor Parallelism.
> - Applying variance-calibrating scaling factors to latent states and attention outputs is crucial for stable convergence and improved perplexity when combining multiple attention components and branches.
