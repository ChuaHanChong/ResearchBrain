# MathCoder-VL: Bridging Vision and Code for Enhanced Multimodal Mathematical Reasoning

> [!summary] Summary
> Researchers from CUHK introduce MathCoder-VL, a multimodal large language model that leverages code supervision and synthesized data to enhance mathematical reasoning capabilities, achieving state-of-the-art performance across mathematical benchmarks while outperforming GPT-4V on geometry tasks through a novel two-stage training approach combining image-to-code training and mathematical instruction fine-tuning.

## Problem

- Large multimodal models struggle with mathematical reasoning tasks that require integrating visual and textual information
- Existing datasets lack high-quality, math-specific cross-modal data needed for effective training

## Method

- Developed ==ImgCode-8.6M dataset== using model-in-the-loop approach to translate math images into executable code
- Created ==MM-MathInstruct-3M dataset== combining collected K12 problems with synthetically generated figures and solutions
- Implemented ==two-stage training process== with image-to-code mid-training followed by mathematical instruction fine-tuning

## Results

- Outperformed GPT-4o on plane geometry tasks by a significant margin
- Achieved superior performance on multi-step problems compared to GPT-4o
- Demonstrated competitive results against closed-source models like GPT-4-turbo and Claude3.5-Sonnet
- Successfully generated diverse new math figures and problems through the ==FigCodifier pipeline==

## Takeaways

> [!tip] Key Insights
> - Code supervision provides precise alignment between visual and textual modalities
> - Combining real and synthetic data with verified solutions improves model performance
> - Two-stage training approach enables effective learning of both visual-code relationships and mathematical reasoning
