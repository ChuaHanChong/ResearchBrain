# CoRe-WAM: Correspondence-Aligned Temporal Residuals for World Action Models

> [!summary] Summary
> CoRe-WAM is a world-action model that conditions manipulation policies on correspondence-aligned visual change. Its TraceDelta module uses a frozen tracking model to transport historical visual features to current token locations, computes signed differences in the shared frozen feature space, and injects them as validity-gated residuals into head-camera tokens. Training only 1.59M parameters, it reaches 92.22% clean success on 50 RoboTwin 2.0 tasks.

## Problem

- Differencing pretrained features at the same grid location mixes genuine feature evolution with changes in which scene content occupies that location when objects or cameras move.
- Prior temporal methods feed trajectories as separate motion tokens or auxiliary supervision, so they add history without defining what content should be compared across observations.
- World-action models focus on future prediction targets, leaving unanswered how a policy should relate its current observation to its recent observed history.

## Method

- **TraceDelta** transports historical visual features to current token positions using a frozen Trace Anything correspondence map, then computes a signed difference against current features in the shared frozen space.
- A **validity mask** records whether each sampled correspondence is finite and inside the camera region, zeroing invalid residuals after adaptation so biases cannot leak into masked positions.
- A lightweight 2048-256-512 **adapter** with a learned scalar maps differences into the Motus understanding dimension, scattering residuals onto 60 head-camera tokens while the direct current-observation path stays intact.

## Results

- Across 50 RoboTwin 2.0 tasks, clean success is **92.22%** and randomized **89.60%**, gains of **3.56** and **2.58 points** over Motus, with only **1.59M** optimized parameters (**~0.02%**).
- Ablation shows unaligned Raw Delta reaches **90.16%** clean, below the **91.34%** history-free Current-only variant, while aligned TraceDelta adds **2.06 points** over Raw Delta.
- Transferred to a StarVLA policy under matched budget, clean success rises from **58.10%** to **67.62%**; Astribot S1 deployment gets **28/30** in-distribution and **25/30** OOD trials.

## Takeaways

> [!tip] Key Insights
> - Establish correspondence before differencing features: unaligned temporal differences can hurt, performing worse than using no history at all.
> - Correspondence is more useful as a transport operator over pretrained features than as a separate trajectory representation fused into the policy.
> - Large temporal gains are reachable with frozen backbones and tiny adapters, but online correspondence estimation adds inference latency, roughly 510 ms per step.

## Detailed Report

### 1. Overview

A robot handling objects has two kinds of visual information. The current image shows the scene now, and recent images show what just happened. Robots need history because manipulation is about how a scene changes, not only what is visible now. History is useful only when the robot relates the same scene content across time. When an object or camera moves, one image coordinate can show different content from one observation to the next. Subtracting visual features at the same image location can then compare different things: the difference mixes a change in the object's features with a change in what occupies that location.

CoRe-WAM first finds the historical counterpart of each current image region and then compares those matched regions. This change signal supplements the current-scene input rather than replacing it.

The result was measured on RoboTwin 2.0. Success rate is averaged equally across the 50 tasks rather than pooled across episodes. CoRe-WAM reports a 92.22% clean success rate, 3.56 percentage points (pp) above Motus. This clean aggregate uses the higher task score from two evaluations with 50 and 100 episodes per task. Its randomized success is 89.60%, 2.58 pp above Motus, and uses the reported aggregate.

A point at current position p corresponds to historical point q, while the same-coordinate historical point p′ depicts different content. Same-location subtraction compares "Mismatched content"; using the correspondence compares "Matched content." The images and correspondences are illustrative.

### 2. A comparison that follows the scene

A frozen tracking model estimates which historical location corresponds to each current visual region. The model samples historical visual features at that location and subtracts them from the current features. A small adapter converts the signed difference into the policy's visual-token representation, and a validity mask suppresses unusable matches. The output is a feature-change signal after matching. It does not measure displacement.

In the Motus implementation, the pretrained backbone stays frozen while about 1.59 million parameters are optimized. The adapter has dimensions 2048 → 256 → 512. Its residual is added only to the 60 head-camera tokens, which are arranged in a 6 × 10 grid at packed token indices 10–69. The direct current-observation path remains intact. The original Motus joint-attention pathway carries the augmented visual conditioning to action generation. Neither trajectory coordinates nor tracker features are added as separate policy tokens. If history is unavailable, the temporal branch is bypassed.

The closest comparison is 4D-WAM, which also uses Trace Anything trajectory information, but uses it as a training-time teacher. CoRe-WAM instead uses correspondence at inference to transport historical pretrained visual features to current locations before differencing them.

(a) The TraceDelta residual joins the projected current tokens before the Motus understanding, video, and action experts interact through joint attention and produce an action chunk. (b) Trace Anything maps current point p to historical point q. The aligned and current features are differenced and passed through an adapter, and masked-invalid entries are set to zero. The examples are schematic, not measured outputs.

### 3. What the controls establish

A skeptic could ask whether the gain comes from the added adapter or from supplying history at all. The capacity-matched Raw Delta control uses the same visual-adapter architecture but differences features at fixed grid locations. The full model instead transports history before differencing. The control checkpoints were evaluated over all 50 tasks, with 100 episodes per task and split, seed 42.

The full model reports 92.22% clean and 89.60% randomized success. Raw Delta reports 90.16% and 87.66%, which gives gaps of 2.06 and 1.94 pp. These component controls are single-run evaluations, while the full model uses the aggregate protocol. The gaps are therefore descriptive, not paired-seed estimates. Relative to Current-only, Raw Delta's effect varies by task. This evidence is consistent with the proposed mechanism, but it does not prove that correspondence is the only cause of the overall gains.

Clean/randomized/average success: Motus 88.66/87.02/87.84; LoRA-only 90.90/87.30/89.10; Current-only 91.34/87.82/89.58; Raw Delta 90.16/87.66/88.91; TraceDelta 92.22/89.60/90.91. TraceDelta uses aggregate results, and the three component controls are single-run. The gaps are descriptive rather than paired-seed estimates.

### 4. Match first, then compare

The aligned difference organizes history by matched content without representing the trajectory itself. Matched history supplements the present-scene pathway rather than standing in for it. The main boundary is cost: correspondence is estimated online, and the authors identify the added correspondence and feature-processing overhead as a limitation.
