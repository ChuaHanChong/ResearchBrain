# Augmenting Replay in World Models for Continual Reinforcement Learning

> [!summary] Summary
> Monash University researchers introduced WMAR (World Models with Augmented Replay), an algorithm that extends DreamerV3 with a memory-efficient augmented replay buffer for Continual Reinforcement Learning. WMAR substantially reduced catastrophic forgetting (average 0.071 vs 0.665 for baseline) in tasks without shared structure, while also demonstrating backward transfer in tasks with shared structure using approximately half the memory of a standard DreamerV3 setup.

## Problem

- Catastrophic forgetting in Continual Reinforcement Learning (CRL) when agents sequentially learn new tasks, leading to degradation of performance on previously acquired knowledge.
- Traditional replay-based methods in CRL often demand large memory capacities to store past experiences, limiting their scalability and computational feasibility.
- A need for robust model-based RL approaches for CRL that effectively leverage learned world models to mitigate forgetting and facilitate knowledge transfer without requiring explicit task identifiers.

## Method

- **WMAR** extends the ==DreamerV3== algorithm by integrating a ==memory-efficient augmented replay buffer== designed for Continual Reinforcement Learning.
- The augmented replay buffer consists of two parallel buffers: a short-term ==FIFO buffer== for recent experiences and a long-term ==global distribution-matching== (LTDM) buffer that uses ==reservoir sampling== to maintain diversity of older experiences.
- Rollouts are ==spliced into smaller, fixed-size chunks== (512 states) before being added to the LTDM buffer, ensuring a more representative sample distribution and efficient memory usage.

## Results

- WMAR drastically reduced catastrophic forgetting in tasks without shared structure (Atari games), achieving an average forgetting score of **0.071**, a substantial improvement over the **0.665** observed in the DreamerV3 baseline.
- For tasks with shared structure (OpenAI Procgen CoinRun variants), WMAR demonstrated backward transfer, achieving an average forgetting score of **-0.077**, indicating performance improvements on earlier tasks after learning new, similar tasks.
- WMAR achieved these enhanced continual learning capabilities with an augmented replay buffer requiring approximately **half the memory capacity** compared to a typical single DreamerV3 buffer.

## Takeaways

> [!tip] Key Insights
> - Integrating a dual replay buffer strategy, comprising both short-term (FIFO) and long-term (distribution-matching) components, significantly enhances a world model's ability to mitigate catastrophic forgetting in continual learning scenarios.
> - Replaying experiences to update the world model itself, rather than solely the policy, serves as an effective mechanism for continuous adaptation and knowledge preservation across diverse tasks.
> - Memory-efficient replay, achieved through techniques like spliced rollouts and reservoir sampling, can provide robust continual learning performance with reduced memory footprint, addressing a key scalability challenge.
