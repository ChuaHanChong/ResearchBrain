# A Clean Slate for Offline Reinforcement Learning

> [!summary] Summary
> A unified framework for offline reinforcement learning from Oxford researchers introduces standardized evaluation protocols and a single-file implementation architecture, while demonstrating how combining components from existing approaches leads to two new algorithms (TD3-AWR and MoBRAC) that achieve stronger performance across multiple benchmarks through careful ablation and systematic integration.

## Problem

- Inconsistent evaluation protocols and unclear problem definitions make it difficult to fairly compare offline RL algorithms
- Complex, entangled implementations obscure the impact of individual algorithmic choices
- Existing methods show poor generalization across different types of tasks

## Method

- Developed rigorous taxonomy of offline RL evaluation variants with explicit quantification of ==tuning budgets==
- Created Unifloral framework that integrates core components from diverse methods into unified hyperparameter space
- Provided clean, minimal JAX implementations to improve code clarity and training speed

## Results

- TD3-AWR outperformed ReBRAC baseline on 6 of 9 datasets through integration of IQL components
- MoBRAC achieved state-of-the-art performance among model-based methods on most benchmarks
- JAX implementations demonstrated significant speedups compared to existing offline RL libraries
- Established clear protocols for reproducible evaluation and fair algorithm comparison

## Takeaways

> [!tip] Key Insights
> - Model-based methods tend to overfit to locomotion tasks and perform poorly on other domains
> - "Distractor policies" with high peak but inconsistent performance can mislead hyperparameter tuning
> - Combining aspects of multiple existing approaches in a systematic way enables better generalization
