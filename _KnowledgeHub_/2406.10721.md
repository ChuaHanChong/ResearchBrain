# RoboPoint: A Vision-Language Model for Spatial Affordance Prediction for Robotics

> [!summary] Summary
> ROBOPOINT is a vision-language model that predicts exact 2D spatial affordance points from natural language instructions for robotic tasks. It leverages a novel, scalable synthetic data generation pipeline to achieve superior accuracy in object and free-space affordance prediction, significantly enhancing real-world manipulation and navigation capabilities while retaining general VLM knowledge.

## Problem

- Existing Vision-Language Models (VLMs) struggle to provide precise, actionable instructions for robots, often producing coarse outputs like bounding boxes or requiring external object detectors.
- Language is inherently ambiguous, especially for exact spatial locations or object-free regions, making it difficult for robots to interpret precise commands for manipulation.
- Collecting diverse, annotated real-world data for precise spatial reasoning and affordance prediction in robotics is costly and time-consuming.

## Method

- ROBOPOINT is an instruction-tuned VLM (based on Vicuna-v1.5-13B with a CLIP vision encoder) designed to predict exact 2D keypoint affordances (target action points) in an image.
- A fully automatic synthetic data generation pipeline creates a large, diverse dataset for both object-referencing and novel "free space" affordance prediction, overcoming data collection bottlenecks.
- The model is co-finetuned on a mix of VQA data, LVIS data (for bounding box grounding), and the generated synthetic object and free space reference data to balance general VLM capabilities with precise robotic control.

## Results

- ROBOPOINT achieved **49.82%** accuracy on the RoboRefIt benchmark (object reference) and **46.77%** on the WHERE2PLACE dataset (free space reference), outperforming state-of-the-art baselines like GPT-4o.
- In real-world robotic manipulation tasks, ROBOPOINT demonstrated an average success rate **39.5%** higher than GPT-4V, showcasing its ability for precise object rearrangement and relational reasoning.
- The model retained general VLM capabilities, performing on par with its base model (LLaVA-v1.5-13B) across standard VQA benchmarks, confirming effective instruction tuning without sacrificing common sense.

## Takeaways

> [!tip] Key Insights
> - Predicting specific 2D image keypoints offers greater precision and versatility for robotic actions than bounding boxes, eliminating the need for pre-defined action primitives.
> - Scalable synthetic data generation, particularly for "free space" affordances, is crucial for enabling VLMs to understand and predict interaction points in vacant regions without relying on explicit objects.
> - A diverse instruction-tuning data mix is essential for preventing catastrophic forgetting of common sense knowledge while introducing domain-specific robotic capabilities, leading to a general yet precise VLM.
