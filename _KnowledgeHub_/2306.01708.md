# TIES-Merging: Resolving Interference When Merging Models

> [!summary] Summary
> TIES-MERGING introduces a three-step approach to combine multiple fine-tuned models into a single multitask model by explicitly resolving parameter interference stemming from redundant changes and sign disagreements. This method consistently outperforms existing merging techniques across NLP and vision tasks, demonstrating average performance improvements up to 3.6% on T5-large models and superior out-of-domain generalization.

## Problem

- Existing model merging methods often suffer from performance degradation due to parameter interference between different fine-tuned models.
- Redundant, low-magnitude parameter changes introduced during fine-tuning interfere with more influential changes from other models when merged.
- Parameter values often have conflicting signs across different fine-tuned models, leading to cancellation or shrinkage when simply averaged.

## Method

- ==TIES-MERGING (TRIM, ELECT, MERGE)== is a three-step method that operates on =="task vectors"==, which are the differences between fine-tuned and initial pre-trained model parameters.
- ==TRIM== removes redundant parameter changes by setting low-magnitude values in each task vector to zero, retaining only the top-k% influential parameters.
- ==ELECT== resolves sign disagreements for each parameter by electing a dominant sign based on the greater total magnitude across all trimmed task vectors, and ==DISJOINT MERGE== then averages only the parameter values whose signs align with the elected sign.

## Results

- TIES-MERGING consistently outperformed baselines like Simple Averaging and Task Arithmetic across NLP (T5) and Vision (ViT) modalities, model sizes, and fine-tuning settings, with average improvements up to **3.6%** on T5-large and **2.5%** on PEFT models.
- It demonstrated superior out-of-domain generalization, outperforming the strongest baseline by **1.0%** (T5-base) and **4.4%** (T5-Large) on held-out tasks.
- The method exhibited more graceful performance degradation when merging a larger number of tasks, served as a better initialization strategy for subsequent fine-tuning, and improved robustness when merging multiple checkpoints from the same task.

## Takeaways

> [!tip] Key Insights
> - Parameter interference in model merging primarily stems from redundant low-magnitude changes and sign disagreements across task-specific fine-tuned models.
> - Explicitly trimming redundant parameters and resolving sign conflicts can significantly improve merged model performance by preserving influential parameter magnitudes.
> - The correct sign direction for a parameter is crucial, as demonstrated by catastrophic performance drops when signs are flipped for high-magnitude parameters, and accurately estimating the optimal sign vector is key to bridging the performance gap with full multitask training.
