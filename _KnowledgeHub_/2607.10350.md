# ABot-AgentOS: A General Robotic Agent OS with Lifelong Multi-modal Memory

> [!summary] Summary
> ABot-AgentOS introduces a general robotic Agent Operating System (AgentOS) that integrates multi-modal memory and a deliberative agent layer for robust, cross-embodiment execution of long-horizon tasks, coupled with EmbodiedWorldBench for comprehensive evaluation. The system achieved up to an 11.99% higher Task Success Rate on its benchmark and demonstrated improved performance across five memory benchmarks with its self-evolving graph memory.

## Problem

- Existing robotic foundation-model systems often lack an intermediate agent layer for robust task decomposition, tool invocation, and error recovery, leading to a reasoning-execution gap.
- Current robotic agent systems are frequently tied to specific hardware or control APIs, hindering generalization and cross-robot transferability.
- Embodied agents lack persistent, multi-modal memory systems capable of reliably storing and retrieving rich, source-grounded experience across extended interactions.

## Method

- Developed **ABot-AgentOS**, a general-purpose ==Agent Operating System== providing a ==deliberative layer== above low-level robot controllers for reasoning, memory, tool use, and verification.
- Implemented a ==Universal Multi-modal Graph Memory== system that converts online observations into compact, structured ==typed-graph records== for robust long-term recall, augmented with a ==failure-driven lifelong self-evolution== mechanism that diagnoses failures and promotes validated fixes.
- Created **EmbodiedWorldBench**, a comprehensive ==benchmark== for evaluating long-horizon embodied tasks across diverse scenes with dynamic events and NPC interaction.

## Results

- ABot-AgentOS improved the Task Success Rate (TSR) by **11.99%** and Goal Completion Rate (GCR) by **10.84%** compared to a single-controller ReAct baseline on the EmbodiedWorldBench.
- The Universal Multi-modal Graph Memory system consistently outperformed strong baselines across **five** distinct memory benchmarks (LoCoMo, OpenEQA, Mem-Gallery, NExT-QA, EgoLife), often approaching human performance.
- The lifelong self-evolution mechanism demonstrated consistent improvements across all five memory benchmarks, with scores improving (e.g., LoCoMo from **87.5** to **88.7** and NExT-QA Acc@All from **76.5** to **80.6**).

## Takeaways

> [!tip] Key Insights
> - A hierarchical agent architecture, comprising a main LLM for semantic planning, a Skill Runner for procedural execution, and a multi-stage Verifier, effectively bridges the reasoning-execution gap in complex tasks.
> - Representing multi-modal embodied experience as a compact, auditable typed graph significantly enhances long-term recall, relational grounding, and temporal reasoning compared to traditional memory approaches.
> - A failure-driven self-evolution loop allows the memory pipeline to continuously adapt and improve its writing, retrieval, and answering policies over time, fostering truly adaptive agents.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

The field of embodied intelligence is progressing towards integrating artificial intelligence into physical environments. Recent advancements in Vision-Language Models (VLMs) and Vision-Language-Action (VLA) systems have enhanced robotic perception, language understanding, and action prediction capabilities. However, a gap persists in translating high-level semantic reasoning into robust multi-step physical execution, achieving generalization across diverse robot morphologies, and enabling long-term, persistent memory for continuous interaction.

This work builds upon three main lines of existing research:
- **Robotic Foundation-Model Systems:** Approaches such as Galaxea G0, Hi Robot, and the RoboBrain lineage integrate fast perception-action policies with deliberative reasoning. These systems connect abstract conceptual grounding with concrete motor execution and explore memory architectures (e.g., RoboMemory, Agentic Robot). However, they often exhibit coupling to specific model stacks, embodiments, or control interfaces, limiting generalization.
- **General Agent Research:** Systems like ReAct, Toolformer, and SWE-agent have demonstrated the utility of explicit reasoning, tool use, and executable workflows for language models in digital environments. This concept extends to robotics with systems such as Gemini Robotics, SayCan, Inner Monologue, Voyager, and AutoGen, which highlight the importance of grounded skill use, feedback, and reusable skills. Nevertheless, physical execution introduces complexities absent in most software agents, including partial observability, actuation uncertainty, ambiguous completion signals, and the necessity for environmental state verification.
- **Long-Term Memory for Agents:** Developments from generative agents to MemoryBank, MemGPT, and Mem0 have shown the importance of persistent user memory, hierarchical context management, and scalable memory infrastructure. These systems indicate that agents should not rely solely on current prompts or parametric model memory. For embodied agents, memory requires a more robust substrate, capable of binding dialogue, egocentric visual evidence, object states, identities, places, temporal and spatial relations, and task traces in an auditable and retrievable format.

Collectively, existing systems present three primary limitations:
1. **Reasoning-Execution Gap:** Many foundation-model-based robotic systems directly map model outputs to actions or utilize monolithic pipelines, lacking an intermediate agent layer for task decomposition, tool invocation, skill delegation, verification, and recovery.
2. **Embodiment-Generalization Gap:** Robotic agent systems are often tightly integrated with specific hardware, control APIs, or environmental assumptions, which impedes cross-robot transferability.
3. **Persistent Embodied-Memory Gap:** Current short-term buffers or text-only memory modules are insufficient for reliably preserving multi-modal, relational, and source-grounded experience across extended interactions.

Furthermore, there is a recognized need for benchmarks that transcend isolated tasks like navigation or manipulation, offering instead long-horizon, multi-scene scenarios with dynamic events and trace-grounded scoring to evaluate complex embodied agent capabilities. ABot-AgentOS aims to address these identified gaps and evaluation needs by providing a general operating system, a comprehensive benchmark, and a multi-modal memory system.

### 2. Key Objectives and Motivation

The primary objective of this work is to introduce **ABot-AgentOS**, a general robotic Agent Operating System, designed to serve as a deliberative agent layer positioned above low-level robot controllers. This system aims to enable embodied reasoning, memory, tool use, verification, and cross-embodiment execution for long-horizon tasks.

The motivation behind ABot-AgentOS is rooted in addressing the aforementioned critical gaps in current embodied AI research:

1. **Bridging the Reasoning-Execution Gap:** The motivation is to provide a structured intermediate layer that can translate the high-level semantic reasoning capabilities of VLMs into reliable, multi-step physical actions. This layer is designed to manage task decomposition, invoke tools and skills, delegate subtasks, and perform multi-stage verification to ensure planned actions are executed correctly and achieve desired environmental changes.
2. **Enabling Embodiment Generalization:** The system seeks to decouple the high-level cognitive processes from specific robot hardware and control interfaces. By abstracting robot capabilities into a unified "Skills and Tools" layer and adopting a plugin-based skill integration paradigm, ABot-AgentOS is motivated to facilitate adaptation across heterogeneous robotic forms, from humanoids to quadrupedal robots, without extensive retraining of the core agent logic.
3. **Establishing Persistent Embodied Memory:** A key motivation is to develop a robust, long-term memory system that goes beyond short-term contextual buffers. This memory system is intended to store multi-modal, relational, and source-grounded experience—including dialogue, visual observations, object states, spatial relationships, and task traces—in a compact, auditable format. The goal is to allow agents to recall past interactions and apply accumulated knowledge over continuous operation.
4. **Facilitating Lifelong Learning and Evolution:** The paper motivates the integration of a failure-driven self-evolution loop within the memory system. This is intended to enable continuous improvement of the memory pipeline by diagnosing failures in writing, retrieval, or reasoning, and promoting validated fixes as "evo-assets" to subsequent operational splits. This mechanism is motivated by the need for agents to learn from their mistakes and adapt over extended periods.
5. **Addressing Evaluation Needs with a Comprehensive Benchmark:** Recognizing the limitations of existing benchmarks, a significant objective is to introduce **EmbodiedWorldBench**. This benchmark is motivated by the need for a standardized evaluation framework capable of assessing long-horizon embodied tasks that involve complex interactions across diverse scenes (indoor, outdoor, hybrid), dynamic events, NPC dialogue, and require hierarchical planning, tool-augmented problem solving, and error recovery.
6. **Supporting Practical Deployment:** The work also outlines a deployment-oriented objective to develop a training pipeline that can transfer ABot-AgentOS-style long-horizon planning and tool-use capabilities from large teacher models to smaller, deployable agent models. This is motivated by the need for efficient and scalable real-world robot agent deployments.

### 3. Methodology and Approach

ABot-AgentOS employs a multi-faceted approach encompassing a novel agent architecture, a multi-modal memory system, a comprehensive evaluation benchmark, and a training pipeline for deployable models.

#### 3.1. ABot-AgentOS Architecture

The system is designed as a general-purpose robotic Agent Operating System (Agent OS) that functions as a deliberative layer above low-level robot controllers and hardware. It integrates multi-modal perception, memory, reasoning, planning, and skill execution across diverse robotic platforms.
- **Edge-Cloud Collaborative LLM Architecture:** A lightweight Tiny LLM operates on the edge for low-latency tasks like perception, instruction understanding, and routine decision-making. For complex reasoning, long-horizon planning, or ambiguity resolution, the system can escalate requests to a cloud-based Large LLM.
- **Agent Harness:** This layer comprises three components:
 - **Verification-aware ReAct:** Extends the ReAct paradigm by incorporating a verifier module to enhance the robustness of agent operations.
 - **Context Management:** Selects, compresses, and retrieves relevant information from observations, dialogue history, robot states, and memory for the current interaction.
 - **Skill Evolvement:** Manages the refinement, reuse, and expansion of the agent's skill set through continuous interaction.
- **Skills and Tools Layer:** Robot capabilities are abstracted into a unified interface for manipulation, navigation, motion control, vision, and other extensible tools. This modularity allows the same agent system to function across various robot embodiments.
- **Multi-modal Memory System:** Features edge-side private memory for robot-specific and sensitive information, and cloud-side common memory for shareable knowledge (e.g., reusable map representations). This system supports knowledge transfer and personalization while maintaining privacy.

#### 3.2. Agent Harness Detail

The Agent Harness implements a hierarchical LLM agent framework to manage long-horizon embodied tasks, separating roles into a main LLM, a Skill Runner, and a Verifier.
- **Scene-Conditioned Task Planning (Main LLM):** The main LLM acts as the semantic planner. It interprets user instructions considering the current scene, map memory, robot state, and available skills. It forms high-level, revisable plans with explicit completion conditions, deciding between direct tool invocation and delegation to the Skill Runner.
- **Skill Runner for Procedural Execution:** This component handles multi-step subtasks, operating as a skill-level subagent with an isolated local context. It manages intermediate states, repeated observations, and local recovery, returning only compressed outcomes to the main LLM to prevent detail overload.
- **Multi-Stage Verification (Verifier):** The Verifier ensures consistency between the agent's internal beliefs and the observed environment state. It performs:
 - **Runtime Verification:** Monitors trajectory and skill states for progress, stagnation, or inconsistent behavior.
 - **Skill-level Verification:** Checks if delegated subtasks semantically meet their objectives.
 - **Finish-time Verification:** Evaluates the entire execution history against the original instruction and any new requirements before task termination.
- **Edge-Cloud Collaborative Routing:** A learned routing policy determines whether requests are handled by the on-device small model or escalated to a cloud model for more complex reasoning, balancing latency and computational cost.

#### 3.3. Memory System Detail

The memory system provides a persistent, external substrate for embodied experience, represented as a typed graph G=(V, E).
- **Graph Memory Representation:** Nodes (v ∈ V) denote entities or evidence units, while edges (e ∈ E) denote relations (temporal, semantic, spatial, identity, interaction, provenance). Each node stores compact, JSON-style information with schema version, source reference, time reference, and provenance, allowing traceability. The schema includes nodes for source containers, evidence units, entities, places, sessions, and semantic events.
- **Multi-modal Memory Updating:** A memory-writing service converts online observations (e.g., video, dialogue, traces) into compact graph records. This involves semantic compression rather than raw storage, linking records to sessions, places, times, and sources. Lightweight maintenance merges near-duplicate nodes and supersedes stale facts via temporal edges.
- **Retrieval and Grounded Answering:** At runtime, queries are converted into semantic and structural signals. A hybrid retriever selects candidate seed nodes using embeddings, lexical matching, and metadata. These seeds are expanded through typed graph edges to form a local evidence subgraph, which is then serialized as compact context. The answerer is instructed to ground its responses in this retrieved evidence and report uncertainty if evidence is insufficient. Retrieval traces are recorded for audit and failure analysis.
- **Failure-Driven Lifelong Self-Evolution:** This mechanism operates across ordered, disjoint data splits (D1...DT). After evaluating a split, observed failures are diagnosed from retrieval and answer traces. A constrained failure-to-asset loop proposes, compiles (into JSON DSL evo-assets), and gates (via target and regression checks) pipeline-level improvements. Accepted assets, such as query-rewriting or evidence-selection policies, are promoted only to later splits, preventing data leakage and enabling cumulative improvement.
- **Edge-Cloud Collaborative Memory Management:** Memory is partitioned into edge-side private memory and cloud-side common memory. A privacy judgment mechanism classifies memory items (e.g., PII vs. public environmental info) to ensure that only non-sensitive, shareable knowledge is synchronized to the cloud.

#### 3.4. EmbodiedWorldBench

This benchmark evaluates embodied agents in 16 executable indoor, outdoor, and hybrid scenes with four difficulty levels and over 200 tasks.
- **Scenario Definition:** Each evaluation case is a self-contained scenario defined by a spatial map (M), initial state (S0), observation rules (O), NPC behaviors (N), and success criteria (C).
- **Benchmark Construction:** Utilizes photo-realistic 3D environments from UnrealZoo. Annotators manually create structured semantic maps (points, rooms, polygons).
- **Query Generation:** A task generation framework, guided by LLMs and human annotators, creates multi-difficulty tasks (navigation, object search, NPC dialogue, dynamic events). Strict information visibility boundaries ensure agents rely on autonomous perception.
- **Evaluation Procedure and Metrics:** Agents execute closed-loop episodes in UnrealZoo, using NavMesh-based navigation and VLM-based observation tools. Evaluation is trace-grounded, using Task Success Rate (TSR) and Goal Completion Rate (GCR) as primary metrics. Geometric conditions are programmatically checked, while semantic conditions are assessed by an LLM judge based on run-derived evidence.

#### 3.5. Model Training (Deployment-Oriented)

A closed-loop training pipeline is designed to transfer ABot-AgentOS capabilities to smaller, deployable agent models.
- **Text-Based Environment and Task Construction:** Natural-language instructions are converted into stateful sandbox instances with environmental states, failure triggers, and human personas.
- **Teacher Trajectory Distillation and SFT:** A strong teacher model generates ReAct-style interaction traces in the sandbox. These traces are filtered by an LLM-as-a-Judge for quality and used for supervised fine-tuning (SFT) of the student policy.
- **RL: Online Exploration with LLM-as-a-Judge Reward:** The SFT-initialized student policy undergoes online reinforcement learning (RL) in the sandbox. A frozen LLM-as-a-Judge provides turn-level and episode-level rewards, which are converted into relative advantages using GiGPO for policy optimization.
- **Self-Evolving Reward Engine:** This engine produces rewards, validates their reliability via a Meta-Judge, and converts low-quality judgments into localized prompt updates through a multi-agent workflow (Cluster, Analyzer, Refiner, Validator stages). This ensures the reward prompt continuously improves.

### 4. Main Findings and Results

The evaluation of ABot-AgentOS involved both agent-level performance on a subset of EmbodiedWorldBench and standalone memory system performance across several established benchmarks.

#### 4.1. Agent Evaluation on EmbodiedWorldBench Subset

- **Improved Task Success with ABot-AgentOS Architecture:** When using the same Qwen3.6-Plus LLM, the ABot-AgentOS architecture achieved a Task Success Rate (TSR) of 61.96% and a Goal Completion Rate (GCR) of 68.79%. This represented an 11.99% increase in TSR and a 10.84% increase in GCR compared to a single-controller ReAct baseline (TSR: 49.97%, GCR: 57.95%) using the same Qwen3.6-Plus model.
- **Impact of Stronger Main LLM:** Integrating a more powerful main LLM, DeepSeek-V4-Pro, within the ABot-AgentOS architecture further improved performance, achieving a TSR of 68.18% and a GCR of 74.62%. This indicated that stronger base models can enhance task interpretation, local recovery, and termination decisions within the proposed architecture.
- **Analysis:** The results suggested that the hierarchical execution, explicit task memory, skill-level feedback, and finish-time verification components of ABot-AgentOS contributed to better handling of multi-stage progress, local search, evidence gathering, and verified termination in long-horizon embodied tasks, mitigating issues like context drift and premature termination observed in single-controller baselines. Remaining challenges included fine-grained active observation, visual evidence verification, and spatial reasoning in complex scenes.

#### 4.2. Memory Evaluation

The memory module was evaluated on five distinct benchmarks: LoCoMo, OpenEQA, Mem-Gallery, NExT-QA, and EgoLife, with both a static memory system and a self-evolving variant.

- **LoCoMo (Long-Term Conversational Memory):** ABot-AgentOS Static achieved an overall score of 87.5, surpassing the strongest reproduced memory baseline (Mem0: 85.6) and approaching human performance (87.9).
- **OpenEQA (Embodied Question Answering):** ABot-AgentOS Static achieved up to 59.9 overall with 24 frames, outperforming listed scene-graph, caption-memory, and 3DGS memory baselines under reported reference numbers. On ScanNet, it reached 62.8.
- **Mem-Gallery (Multi-modal Long-Term Conversational Memory):** ABot-AgentOS Static obtained an overall score of 88.6, exceeding listed textual and multi-modal memory baselines. The system demonstrated particular strength in visual-centric reasoning, conflict detection, and answer refusal categories.
- **NExT-QA (Temporal Video Reasoning):** ABot-AgentOS Static reached 76.5 Acc@All on the validation set, improving over the previous memory-based GraphVideoAgent baseline by 3.2 points. Gains were most pronounced in causal and temporal questions.
- **EgoLife (Egocentric Daily-Life Question Answering):** ABot-AgentOS-Qwen3.5-Flash achieved 65.4% average accuracy, outperforming listed conventional VQA and most agentic memory-based methods while utilizing only one retrieved frame per query.

#### 4.3. Lifelong Self-Evolution Results

The failure-driven lifelong self-evolution mechanism demonstrated consistent improvements across all five benchmarks:
- **LoCoMo:** Overall score improved from 87.5 to 88.7.
- **OpenEQA:** Overall score improved from 59.9 to 60.4.
- **Mem-Gallery:** Overall score improved from 88.6 to 89.0, with targeted gains in knowledge resolution, conflict detection, and multi-entity reasoning.
- **NExT-QA:** Acc@All showed the largest absolute gain, improving from 76.5 to 80.6.
- **EgoLife:** Average accuracy improved from 65.4% to 66.2%, with the largest category gain on TaskMaster.

These gains were achieved under a strict split-wise protocol where evo-assets from a given split were only promoted and applied to subsequent, unseen splits, preventing data leakage. This indicated that the memory pipeline could improve through targeted, auditable updates to its writing, retrieval, and answering policies.

### 5. Significance and Potential Impact

ABot-AgentOS represents a foundational development in embodied AI, proposing a general-purpose robotic agent operating system that integrates advanced reasoning, multi-modal memory, and robust execution capabilities. Its significance and potential impact span several areas:

**Architectural Advancement for Embodied Agents:** The modular Agent OS architecture, decoupling high-level cognitive reasoning from low-level physical actuation, is significant. This design directly addresses the reasoning-execution and embodiment-generalization gaps, offering a reusable, unified framework that can adapt to diverse robot platforms. This promotes cross-body transferability, reducing the cost and complexity of deploying advanced AI capabilities across different robotic hardware.

**Enhanced Long-Horizon Task Execution:** The empirical results demonstrate that the ABot-AgentOS architecture, with its hierarchical control, task memory, skill-level feedback, and multi-stage verification, can improve task success and goal completion rates on complex, long-horizon embodied tasks. This suggests a pathway for robots to perform more reliably in real-world scenarios requiring multi-step planning, interaction, and error recovery, moving beyond isolated, short-duration actions.

**Robust and Continuously Evolving Memory System:** The Universal Multi-modal Graph Memory is a key innovation. By converting multi-modal experience into structured, source-grounded graph records, it significantly enhances long-term recall, multi-modal identity and relation grounding, and temporal reasoning. Its strong performance across various memory benchmarks, often surpassing existing state-of-the-art memory systems, highlights its capability to provide agents with rich, auditable contextual awareness. Furthermore, the failure-driven lifelong self-evolution loop introduces a critical mechanism for continuous improvement, enabling the memory pipeline to adapt and refine its processes over time based on real-world feedback or evaluation outcomes. This capability is crucial for building truly adaptive and intelligent agents that can learn from experience and minimize recurring errors.

**Comprehensive and Executable Evaluation Benchmark:** The introduction of EmbodiedWorldBench is significant for the broader research community. By providing an executable benchmark that covers a wide spectrum of long-horizon tasks across indoor, outdoor, and hybrid scenes, with dynamic events and NPC interaction, it offers a standardized and rigorous platform for assessing the capabilities of next-generation embodied agents. Its trace-grounded scoring ensures reproducibility and fine-grained failure analysis, supporting systematic research and development.

**Path Towards Deployable Robotic Agents:** The description of a deployment-oriented training pipeline, leveraging text-based environments, teacher trajectory distillation, supervised fine-tuning, reinforcement learning with LLM-as-a-Judge rewards, and a self-evolving reward engine, outlines a practical strategy for transferring complex behaviors to smaller, more efficient agent models. This approach, combined with the edge-cloud collaborative architecture, suggests a scalable and cost-effective pathway for the real-world deployment of advanced robotic agents.

In summary, ABot-AgentOS lays a foundation for building robotic agents that are not only capable of sophisticated perception and action but can also remember, reason, evaluate their own progress, and continuously learn throughout their operational lifespan in complex physical environments. While challenges remain in large-scale real-world validation and further enhancing interaction depth, this work represents a step towards more capable, general-purpose embodied AI.
