# PAL: Program-aided Language Models

> [!summary] Summary
> Program-aided Language Models (PAL) from Carnegie Mellon University enhance Large Language Models' reasoning by prompting them to generate Python programs, which are then executed by an external interpreter. This approach achieves state-of-the-art few-shot accuracy across 13 mathematical, symbolic, and algorithmic datasets, significantly improving robustness to numerical complexity compared to existing methods like Chain-of-Thought.

## Problem

- Large Language Models (LLMs) excel at decomposing complex problems into logical steps (e.g., via Chain-of-Thought prompting) but frequently make errors during the execution or calculation phase.
- LLMs, being pattern matchers, are not inherently reliable for precise arithmetic, symbolic, or logical computation, especially with complex numbers or intricate manipulations.
- This limitation leads to situations where an LLM's reasoning chain might be conceptually correct, but its final numerical or logical answer is erroneous due to calculation mistakes.

## Method

- PAL introduces a novel prompting strategy where the Large Language Model generates an ==interleaved sequence of natural language comments and executable Python code== as intermediate reasoning steps.
- Instead of the LLM performing internal calculations, the generated Python program is passed to and executed by a ==standard, external Python interpreter==.
- The final solution is derived directly from the interpreter's output, effectively ==decoupling the LLM's problem decomposition capabilities== from the precise execution of computational steps.

## Results

- PAL achieved state-of-the-art few-shot accuracy across all **13** evaluated mathematical, symbolic, and algorithmic reasoning datasets, outperforming larger models like PaLM-540B and Minerva-540B using Chain-of-Thought.
- On GSM8K, PAL reached **72.0%** accuracy, surpassing CoT with Codex (**65.6%**); on the harder GSM-HARD dataset, PAL maintained **61.2%** accuracy, demonstrating superior robustness compared to CoT's drop to **23.1%**.
- PAL showed substantial gains across BIG-Bench Hard symbolic and algorithmic tasks, with improvements ranging from **8.8%** to **23.7%** over Chain-of-Thought on datasets such as COLORED OBJECTS, PENGUINS, OBJECT COUNTING, and REPEAT COPY.

## Takeaways

> [!tip] Key Insights
> - Integrating Large Language Models (LLMs) with external symbolic interpreters, such as a Python interpreter, is an effective strategy for achieving accurate and robust reasoning.
> - The primary benefit of PAL comes from offloading precise computation to a deterministic external interpreter, rather than solely from prompting LLMs to generate structured code for internal execution.
> - The inclusion of natural language comments and meaningful variable names within the Python code prompts is crucial for the LLM's performance and its ability to generate correct and grounded programs.
