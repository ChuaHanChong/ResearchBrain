# ARM: Adaptive Reasoning Model

> [!summary] Summary
> The Adaptive Reasoning Model (ARM) enables large reasoning models to adaptively select appropriate reasoning formats based on task difficulty, reducing token generation by an average of 30% and up to 70% on easy tasks while maintaining strong performance. This approach, using an adapted reinforcement learning algorithm, mitigates the "overthinking" problem and achieves a ~2x training speedup.

## Problem

- Large Reasoning Models (LRMs) suffer from an "overthinking" problem, applying elaborate "Long Chain-of-Thought" (Long CoT) reasoning uniformly across all tasks regardless of difficulty.
- This indiscriminate application leads to excessive token generation, substantial computational overhead, increased inference latency, and can sometimes degrade performance.
- Existing solutions often rely on manual token budget estimations or require specialized, length-constrained model training, which are neither practical nor adaptively efficient.

## Method

- ARM employs a two-stage training framework: Supervised Fine-tuning (SFT) to understand four reasoning formats (Direct Answer, Short CoT, Code, Long CoT), followed by Reinforcement Learning (RL).
- It introduces ==Adaptive Group Relative Policy Optimization (Ada-GRPO)==, an RL algorithm that overcomes =="format collapse"== by encouraging exploration of diverse reasoning formats through a ==format diversity scaling factor==.
- ARM supports three inference modes: Adaptive (autonomous selection), Instruction-Guided (user-specified format), and Consensus-Guided (efficient formats first, then Long CoT if disagreement).

## Results

- ARM reduces token cost by an average of **~30%** and up to **~70%** on easy tasks, while maintaining reasoning performance comparable to models that exclusively use Long CoT.
- The model effectively learns to adapt its reasoning strategy, primarily using efficient formats for easy commonsense tasks and shifting to elaborate formats like Code and Long CoT for complex problems.
- Ada-GRPO achieves approximately a **~2x** speedup in training time compared to traditional GRPO by encouraging the generation of shorter, more efficient responses during the RL roll-out stage.

## Takeaways

> [!tip] Key Insights
> - Large Reasoning Models can be trained to dynamically adjust their reasoning depth and token usage based on task complexity, moving beyond a uniform reasoning approach.
> - Reinforcement learning algorithms can be specifically adapted, via mechanisms like diversity scaling, to prevent 'format collapse' and encourage the balanced utilization of multiple problem-solving strategies.
> - Integrating and adaptively selecting from a palette of reasoning formats allows AI models to achieve an optimal balance between high accuracy and computational efficiency.
