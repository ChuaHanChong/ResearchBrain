# GaussMemory: Task-Driven 3D Gaussian Scene Memory for Long-Horizon Robotic Manipulation

> [!summary] Summary
> GaussMemory equips VLA robots with a persistent 3D Gaussian scene memory whose update and readout are unified in one differentiable cross-attention module (UMA), letting task loss teach the memory which objects to track precisely versus discard. It beats MemoryVLA on LIBERO Goal/Long-10 and beats pi0-FAST on VLABench by +5.2% and +6.0%.

## Problem

- Prior 3D-structured memory systems like ConceptGraphs use hand-crafted update rules such as thresholded matching, fixed-rate averaging, and hard pruning, decoupled from task performance.
- 2D perceptual memory banks such as MemoryVLA and multi-scale stores like MEM operate in token space without explicit 3D geometry, so they cannot answer precise spatial queries.
- Existing systems treat memory update and readout as independent non-differentiable stages, giving every scene element equal importance regardless of task relevance.

## Method

- Temporal Gaussian Scene Memory: persistent 3D Gaussian primitives augmented with timestamps, sub-task index, object ID, and existence probability, organized into object-centric groups via Gaussian Grouping.
- Unified Memory Attention (UMA): shared cross-attention where observation tokens and task-conditioned readout queries jointly attend to memory, producing both LLM-bound spatial context and soft correspondence signals for update.
- Learned update gate and lifecycle: attention-weighted evidence drives a sigmoid gate eta_k for position blending, plus existence-probability decay for pruning and threshold-based insertion of novel objects, all trained end-to-end via the diffusion action loss.

## Results

- On LIBERO, GaussMemory reaches 96.8% Goal and 94.1% Long-10 success rate, edging out MemoryVLA's 96.4% and 93.4%, with the memory-versus-no-memory gap growing from +4.0 to +11.7 as horizon lengthens.
- On VLABench, GaussMemory scores 56.4% SR / 68.2% PS on Track 1 and 24.0% SR / 45.6% PS on Track 6, beating pi0-FAST by +5.2% and +6.0% SR respectively.
- Ablations show 3D Gaussian memory alone adds +8.0 over the no-memory backbone, learned active gating adds a further +3.7, and unified UMA beats a decoupled match-plus-readout baseline by +2.3 points on Long-10.

## Takeaways

> [!tip] Key Insights
> - Unifying memory read and write in one differentiable attention module lets bidirectional coupling emerge: task-relevant objects get updated aggressively while background is preserved, without hand-designed rules.
> - Memory's benefit scales with task horizon, so short-horizon benchmarks understate the value of persistent explicit-geometry memory relative to long-horizon deployment.
> - Explicit 3D geometry, not merely the presence of a memory buffer, is the decisive factor: a 2D-token version of the same architecture underperforms the 3D Gaussian variant substantially.

## Detailed Report

### 1. How this work fits into the broader research landscape

Long-horizon robotic manipulation tasks necessitate a persistent spatial memory to retain information about objects, their identities, and their 3D positions over extended periods, especially when objects become occluded or scene states change. Recent advancements in Vision-Language-Action (VLA) models, such as OpenVLA and π0, have shown promise by leveraging pre-trained vision-language knowledge to map visual observations and language instructions directly to robotic actions. However, these models often operate with limited or no persistent memory, making them ineffective for tasks requiring recall of past states or understanding of occluded objects.

Existing approaches to equip VLA systems with temporal memory exhibit limitations:
- **2D Perceptual-Cognitive Memory (e.g., MemoryVLA):** While effective, these systems fundamentally operate in a 2D token space, lacking explicit 3D geometry. This prevents them from answering precise spatial queries essential for manipulation, such as object-to-object relative positioning.
- **Multi-scale Embodied Memory (e.g., MEM):** Similar to 2D approaches, these systems process memory in 2D token space without explicit 3D geometric representations.
- **Language-Based Memory (e.g., SayPlan):** These methods store text descriptions of past states, offering compactness and LLM compatibility but sacrificing geometric precision entirely.
- **3D-Structured Memory (e.g., ConceptGraphs):** While maintaining explicit 3D geometry through scene graphs, these systems typically rely on hand-crafted, fixed rules for memory updates (e.g., thresholded matching, fixed-rate averaging, hard pruning). Crucially, their memory update and readout mechanisms are often decoupled and non-differentiable with respect to the downstream task performance. This means they function as "passive recorders" that treat every scene element with equal importance, regardless of its relevance to the current or future task.

This paper proposes a shift from passive, rule-based memory to an "active, task-driven spatial memory." It argues that a robot's memory should not merely record observations but actively learn *how* to remember—identifying which objects require precise tracking, how aggressively to update their states, and what information to discard, all learned end-to-end from task performance. This active paradigm is realized by unifying memory update and readout into a single cognitive process, enabling bidirectional information flow where task requirements influence memory update strategies and vice versa. The work leverages 3D Gaussian Splatting (3DGS) as a geometric substrate, noted for its incrementality, explicit 3D geometry, and tokenizability, making it suitable for integration into VLA architectures.

### 2. Key objectives and motivation

The overarching objective of this research is to develop a persistent spatial memory system for robots engaged in long-horizon manipulation tasks that overcomes the limitations of existing approaches.

The primary motivations and specific objectives are:
1. **Address the limitations of passive memory systems:** Existing 3D memory systems function merely as passive recorders. They store observations using fixed, hand-crafted rules and treat every scene element (e.g., a critical grasp target versus an irrelevant background wall) with equal importance. This inflexibility hinders performance in long-horizon tasks where specific object states or relationships become crucial for successful task completion, particularly under occlusion (e.g., knowing which of two identical drawers holds a specific object after an intervening sub-task).
2. **Shift from passive recording to active, task-driven learning:** The core motivation is to enable a robot's memory to actively learn *how to remember*. This includes discerning which objects to track precisely, how aggressively to update their states based on new observations, and what information to discard as irrelevant. This learning process is intended to be end-to-end, without reliance on hand-designed rules.
3. **Unify memory update and readout:** A critical problem in current systems is the decoupling of memory update and readout. The paper posits that these are two sides of the same cognitive process, and bidirectional information flow is necessary. Task needs (readout) should directly shape how memory is stored (update), and conversely, memory updates should inform readout strategies. This coupling allows the overall task loss to genuinely sculpt memory behavior, ensuring that memory management directly serves task performance.
4. **Leverage 3D Gaussian Splatting (3DGS) as a geometric substrate:** The research aims to instantiate this active memory vision using 3DGS due to its inherent properties:
 - **Natural Incrementality:** Individual Gaussians can be added, removed, or repositioned without disrupting the entire scene, facilitating dynamic memory management.
 - **Explicit Geometry:** Each Gaussian explicitly encodes position, covariance, and opacity, providing the precise 3D spatial information critical for manipulation planning.
 - **Tokenizability:** Gaussian features can be encoded into compact tokens, which can then be seamlessly integrated into the LLM backbone of VLA architectures alongside language and 2D visual tokens.
5. **Develop Unified Memory Attention (UMA):** A specific objective is to realize the unified memory update and readout paradigm through a novel attention mechanism, UMA. This module is designed to process observation tokens and task-conditioned readout queries in shared cross-attention layers, thereby enabling bidirectional information flow and making the entire memory lifecycle end-to-end differentiable with respect to the action prediction loss.
6. **Integrate 3D Gaussian Splatting as a temporal scene memory within a VLA framework:** To the authors' knowledge, this system aims to be the first to integrate 3DGS as a continuously updated temporal scene memory within a VLA framework, where these memory tokens are directly consumed by an LLM for action prediction.

### 3. Methodology and approach

GaussMemory is designed to integrate active, task-driven 3D spatial memory into a VLA framework for long-horizon robotic manipulation. The system consists of three main components: a Temporal Gaussian Scene Memory, Unified Memory Attention (UMA), and a Prismatic VLM backbone with a diffusion action head.

**A. Problem Formulation**
The system addresses long-horizon manipulation tasks defined by a high-level language instruction `L` that decomposes into `T` sub-tasks `{τ_1, ..., τ_T}`. At each timestep `t`, the robot receives multi-view RGB images `{I_t^v}` and its proprioceptive state `s_t`, aiming to predict actions `a_t` to complete sub-tasks while maintaining persistent memory.

**B. Temporal Gaussian Scene Memory (M_t)**
This is the core data structure, comprising a set of augmented Gaussian primitives persistently maintained across the task horizon.
- **Augmented Gaussian Primitives:** Each Gaussian `G_i` includes standard 3DGS attributes (position `μ_i`, covariance `Σ_i`, opacity `α_i`, color `c_i`, spherical harmonic features `h_i`) augmented with temporal metadata: creation timestamp (`t_c_i`), modification timestamp (`t_m_i`), sub-task index (`τ_i`), object ID (`o_i`), and existence probability (`e_i`).
- **Temporal Feature Encoding:** Each Gaussian is encoded into a feature vector `g_mem_i` by an MLP, further enhanced with 3D Fourier positional encoding (`PE_3D(μ_i)`) and a relative temporal positional encoding (`PE_rel_T(t_m_i, t)`) to capture its age relative to the current time, aiding generalization across varying episode lengths.
- **Object-Centric Organization:** Object instance IDs are assigned to groups of Gaussians using Gaussian Grouping guided by DINO features, allowing the memory to be structured around distinct objects `G_j = {G_i : o_i = j}`.

**C. Unified Memory Attention (UMA)**
UMA is the central mechanism responsible for simultaneously reading from and writing to the 3D Gaussian memory in a differentiable manner, facilitating bidirectional information flow. It processes information in four stages:
1. **Construct Unified Query:**
 - **Observation Tokens (Q_obs):** A feed-forward 3DGS encoder (FF-3DGS, specifically MVSplat) processes multi-view RGB images to generate `M` live Gaussians. These are then aggregated into `N_o` object-level tokens, `q_obs_j`, using pooling and 3D positional encoding of object centroids.
 - **Readout Queries (Q_read):** `K` learnable tokens, `q_read_k`, are conditioned on the global language instruction `L` (via CLIP text encoder) and the current sub-task index `τ_t` (via temporal positional encoding).
 - These two sets of queries are concatenated to form the `Unified Query Q_uni = [Q_obs; Q_read]`.
2. **Self-Attention – Observation-Task Exchange:** `Q_uni` undergoes self-attention layers. This allows observation tokens to become "task-aware" by attending to readout queries, and readout queries to become "perceptually grounded" by attending to observation tokens. The output is the `Contextualized Unified Query U_ctx`.
3. **Cross-Attention Against Memory:** `U_ctx` then queries the `Temporal Gaussian Scene Memory M_t`. Keys and values for the cross-attention are derived from the stored memory Gaussians (`G_mem`). The cross-attention mechanism incorporates a learned relative-time bias (`B_T`) to modulate attention based on the recency of memory entries.
4. **Read and Write Streams:** After multiple UMA layers, the final output `Q^(L)` is split into two streams:
 - **Read Stream → LLM Input:** The contextualized readout queries (`Q_read,(L)`) are linearly projected to form `Z_mem`, which serves as 3D spatial context input for the LLM backbone.
 - **Write Stream → Memory Update:** The observation rows of the final cross-attention matrix produce a soft correspondence matrix `A_match`. This matrix drives the entire memory lifecycle:
 - **Evidence Aggregation:** `w_k` measures the match strength for each memory entry `k` based on `A_match`.
 - **Position Estimation:** A new observed position `˜μ_obs_k` for memory entry `k` is calculated as a soft-aggregation of matching live observation positions.
 - **Learned Update Gate (`η_k`):** A neural network (`MLP_η`) takes as input the attention-weighted observation features, match strength `w_k`, and relative age of the memory entry to output `η_k ∈ (0, 1)`. This `η_k` acts as a learned update coefficient, determining how aggressively the memory Gaussian's position (`μ_mem_k`) is updated towards `˜μ_obs_k`. Higher `η_k` indicates greater trust in the new observation.
 - **Existence Management:** Each Gaussian's existence probability `e_k` is updated based on `w_k`. Gaussians with `e_k` below a threshold (`θ_e`) are pruned.
 - **Novel Object Insertion:** Live observations that exhibit low match to existing memory entries are inserted into the memory as new Gaussians with a probability determined by an `MLP_ins`.

**D. LLM Backbone and Action Generation**
The system adopts the same Prismatic VLM backbone (DINOv2 and SigLIP vision encoders paired with a Llama-2-7B LLM) as several baseline VLA models to ensure fair comparison. The LLM receives a concatenated token sequence `Z` comprising `Z_mem` (from UMA), `Z_2D` (from the Prismatic vision encoder), `Z_L` (language tokens), and `Z_S` (proprioceptive state tokens). The LLM then generates action tokens, which are decoded by a diffusion-based action head into 7-DoF actions `a_t = [∆p, ∆r, g]`, and a binary sub-task completion signal.

**E. End-to-End Training**
The total loss `L` comprises four terms: `L_action` (standard diffusion action-prediction objective), `L_complete` (binary cross-entropy for sub-task completion), `L_temporal` (encourages coherent memory for static objects), and `L_update` (supervises memory positions against ground truth with task-relevance weighting). Crucially, gradients flow through `A_match` and `η_k` within UMA, allowing the task loss to directly optimize memory update behavior. Training is conducted in two stages: pre-training and freezing FF-3DGS, followed by joint training of UMA, projectors, and the LLM (using LoRA) on full-length episodes.

### 4. Main findings and results

The experimental evaluation of GaussMemory was conducted on two benchmarks: LIBERO and VLABench.

**A. LIBERO Results**
GaussMemory was compared against 10 published VLA methods across LIBERO’s four suites: Spatial, Object, Goal, and Long-10.
- **Superiority on Long-Horizon and Spatial Tasks:** GaussMemory achieved a success rate (SR) of 96.8% on the Goal suite and 94.1% on the Long-10 suite, outperforming MemoryVLA (96.4% and 93.4% respectively) and all other baselines. These suites specifically test spatial precision and long-horizon reasoning.
- **Complementarity with 2D Memory:** While MemoryVLA maintained a slight edge on the Spatial and Object suites (98.4%), where short-horizon semantic recognition is often dominant, GaussMemory demonstrated strong performance in these areas as well (96.4% and 96.2%).
- **Importance of 3D Geometry:** An ablation study replacing 3D Gaussians with 2D tokens within the GaussMemory framework resulted in a 90.2% SR on Long-10, which is below both the full 3D GaussMemory model and MemoryVLA. This indicates that the explicit 3D geometric representation is a decisive factor contributing to the performance gains, not just the presence of memory.
- **Scaling with Task Horizon:** The performance improvement of GaussMemory over a memoryless baseline (`Ours w/o memory`) consistently increased with task horizon: +4.0% on Spatial, +8.6% on Goal, and +11.7% on Long-10. This confirms that persistent 3D memory becomes increasingly critical as tasks accumulate more state changes.
- **Per-Task Performance:** GaussMemory ranked first on 9 out of 10 individual Long-10 tasks, with MemoryVLA leading only on one semantic-heavy task.

**B. VLABench Results** GaussMemory was evaluated on VLABench, a large-scale benchmark designed for long-horizon reasoning.
- **Performance on Track 1 and Track 6:** GaussMemory achieved 56.4% SR on Track 1 (in-distribution skill acquisition), outperforming π0 -FAST (51.2%) by +5.2%. On Track 6 (long-horizon composite tasks), the advantage was larger, with GaussMemory achieving 24.0% SR compared to π0 -FAST’s 18.0% (+6.0%).
- **3D vs. 2D Memory:** An ablation comparing 3D Gaussian memory to a 2D token buffer (with the same UMA architecture and backbone) showed that the 2D version yielded substantially lower results (51.4% / 19.0% on Track 1/6) than the full 3D model (56.4% / 24.0%). This further reinforced that the 3D geometric representation, rather than just the presence of a memory buffer, is the key contributor to performance.
- **Amplified Memory Advantage:** VLABench tasks feature significantly longer horizons (500+ timesteps) than LIBERO (approx. 120 timesteps). The growing performance gap between GaussMemory and baselines (e.g., +5.2% on Track 1 to +6.0% on Track 6) mirrored the trend observed in LIBERO, where the memory advantage scales with task horizon.
- **Cross-Benchmark Consistency:** The consistency of results across both benchmarks (memory is a major factor, advantage increases with horizon, most pronounced on spatially demanding tasks) supports the generality and effectiveness of the active 3D Gaussian memory paradigm.

**C. Ablation Studies (LIBERO Long-10)**
Detailed ablations provided insights into component contributions:
- **Foundation of 3D Gaussian Memory:** Simply adding a persistent 3D Gaussian memory with a fixed, passive update rate (`η=0.3`) yielded the largest single gain (+8.0% over `w/o memory`), rising from 82.4% to 90.4%. This highlights the fundamental benefit of the 3D geometric representation itself.
- **Active Learning of Update Strategy:** Replacing the fixed `η` with a learned, attention-derived update rate provided an additional +2.4% (90.4% to 92.8%). Further enhancements from an MLP-modulated `η` (+0.4%) and soft existence management (+0.9%) brought the total gain from `w/o memory` to +11.7% (94.1%). This demonstrated the effectiveness of learning *how* to update memory based on task relevance.
- **Unified vs. Decoupled Read/Write:** A baseline with a decoupled memory read/write mechanism achieved 91.8% SR, 2.3% lower than the unified UMA (94.1%). This indicates that the bidirectional coupling inherent in UMA provides additional benefits beyond merely the 3D representation.
- **View Count Robustness:** The memory contribution (e.g., +11.7% on Long-10) far exceeded the contribution of additional camera views (e.g., adding a third view without memory only added +1.6% to Long-10), confirming that gains are primarily from the 3D memory, not just more visual input.
- **Memory Capacity:** Performance scaled positively with Gaussian count up to 32K (the default), beyond which marginal returns diminished. This suggests that the learned existence management effectively prunes redundant Gaussians, maintaining an optimal memory size.

**D. Emergent Memory Behavior**
Visualizations confirmed the emergence of a task-driven update strategy:
- **Differential Update Rates:** Manipulated objects (e.g., a drawer during closing, a bowl during grasping) exhibited a high learned update coefficient (`η ≈ 0.74`), indicating aggressive updating based on new observations. In contrast, background Gaussians maintained a low `η ≈ 0.06`, preserving their accumulated estimates. This differential updating emerged automatically from end-to-end task-level supervision without hand-crafted rules.
- **Dynamic Memory Size:** The active Gaussian count remained well below the 32K capacity. Insertion spikes occurred during significant scene changes (e.g., new objects appearing), while pruning events maintained equilibrium, demonstrating adaptive memory management.

### 5. Significance and potential impact

GaussMemory represents an advancement in robotic spatial memory systems for long-horizon manipulation, addressing several fundamental limitations of current VLA models.

**Significance:**
- **Paradigm Shift to Active Memory:** The work introduces a novel paradigm of "active, task-driven" spatial memory, where the robot learns *how* to remember, dynamically prioritizing and updating information based on task relevance. This is a departure from conventional passive recording systems that treat all scene elements uniformly.
- **Unified Memory Management:** By integrating memory update and readout into a single, differentiable Unified Memory Attention (UMA) mechanism, the system enables bidirectional information flow. This allows task needs to directly sculpt memory behavior through end-to-end training, a capability absent in decoupled systems.
- **Robust 3D Geometric Representation:** Leveraging 3D Gaussian Splatting provides an inherently incremental, explicit, and tokenizable 3D geometric substrate for persistent memory. This addresses the critical need for precise spatial understanding that 2D-based and language-only memory systems lack.
- **Empirical Performance Improvement:** GaussMemory demonstrates consistent and significant performance gains on challenging long-horizon and spatially demanding tasks across two major benchmarks (LIBERO and VLABench). The ablations clearly show that both the 3D representation and the active, unified memory management contribute substantially to these improvements.
- **Emergent Intelligent Behavior:** The observation that the system automatically learns differential update strategies (e.g., aggressively updating manipulated objects while preserving background information) without explicit programming highlights an emergent form of intelligence in memory management, driven solely by task success.

**Potential Impact:**
- **Enhanced Robotic Autonomy:** By providing robots with a more robust, adaptive, and spatially precise memory, GaussMemory could enable more reliable and autonomous operation in complex, dynamic, and open-ended environments over long durations. This is crucial for real-world applications where objects may be occluded, moved, or introduced over time.
- **Foundation for Future Embodied AI:** The proposed active memory paradigm could serve as a foundational component for next-generation embodied AI systems, influencing the design of future VLA models and generalist robotic policies that require a deeper, task-aware understanding of their environment.
- **Improved Long-Horizon Planning:** The ability to retain and dynamically update precise 3D information about objects is critical for complex, multi-step manipulation plans, allowing robots to re-plan or recover from errors by querying an accurate and up-to-date scene state.
- **Bridging Cognitive Science and Robotics:** The conceptual inspiration drawn from cognitive science (e.g., bidirectional coupling of memory processes) could encourage further interdisciplinary research between cognitive science and robotic memory system design.
- **More Efficient Resource Utilization:** The learned pruning and adaptive update rates contribute to more efficient use of memory resources, focusing computational effort on task-relevant information rather than indiscriminately storing all observations.

In summary, GaussMemory offers a principled and empirically validated approach to imbue VLA robots with a task-driven, actively managed 3D spatial memory, pushing the boundaries of what is achievable in long-horizon robotic manipulation.
