# Self-Evolving Embodied Agents via Skill-Harness Evolution

> [!summary] Summary
> SHAPER is a train-free self-evolving framework that adapts embodied agents by optimizing model-external artifacts: a textual reusable skill and a Python context-code harness, while planner and executor weights stay frozen. Rollout critiques form a textual gradient; the same frozen VLM acts as optimizer under beam search. Success rises from 28.25% to 34.50% on VLABench and 32.5% to 49.8% on ESI-Bench.

## Problem

- Supervised fine-tuning and reinforcement post-training need model weights, task demonstrations or rewards, and extra optimization runs, blocking adaptation when weights or interaction data are unavailable.
- Train-free code-centric robot systems assume programmable robot APIs, debugging hooks, and execution monitors that are absent or incomplete under fixed, restricted action interfaces.
- Prior self-evolving agents edit either the skill or the code harness alone, never co-optimizing reusable procedural guidance and context construction from embodied rollouts.

## Method

- **Train-free agent factorization** splits the agent into frozen planner, frozen executor, textual skill, and a ==build_context harness==; only the skill-harness pair is optimized against expected rollout reward.
- **Rollout-guided textual diagnosis** uses a round-level judger over before/after observations plus an episode summarizer over non-visual metadata to form a compact ==textual gradient== without full visual trajectories.
- **Two-stage skill-then-harness evolution** prompts the same frozen model as optimizer, sandbox-validates generated harness code against import/IO/timeout rules, and keeps top-K candidates by ==validation beam search==.

## Results

- VLABench: SHAPER reaches **34.50%** overall versus **28.25%** seed agent, **23.25%** direct VLA, and **24.00%** same-data SFT; gains grow under shift (**+10.0** points on the unseen task form).
- ESI-Bench: **49.8%** micro and **42.9%** macro accuracy versus **32.5%**/**31.2%** seed, exceeding the published GPT-5 passive single-view macro reference of **40.3%** with a frozen **27B** planner.
- Test-time scaling fails here: MG-Select and VOTE score **21.38%** and **22.00%**, below direct VLA execution; artifact evolution costs about **$2.25-$2.83** once, not per deployment.

## Takeaways

> [!tip] Key Insights
> - Agent performance lives partly outside the weights: editing procedural guidance and context construction can beat same-data fine-tuning without touching any parameters.
> - Skill and harness contributions are non-additive, so ablation rows should be read as complete agent configurations rather than independent effect estimates.
> - One-time artifact optimization amortizes across deployments, unlike per-episode test-time sampling whose cost scales with usage and here even hurt accuracy.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

Embodied Artificial Intelligence (AI) is progressing from isolated policy models to complex agent systems, frequently built around large-scale foundation models. These models, such as vision-language-action (VLA) and multimodal foundation models, enable agents to perceive environments, interpret instructions, reason, and act in both simulated and physical spaces. However, the performance of such agents is not solely dependent on the neural network weights of these models. External components—including reusable skills, context construction, action interfaces, output parsing, and execution wrappers—significantly influence agent behavior, particularly in embodied settings with constrained action interfaces and partial visual feedback.

Traditional methods for adapting embodied agents, such as Supervised Fine-Tuning (SFT) and Reinforcement Learning (RL), involve updating model parameters. While effective, these approaches demand access to model weights, task-specific demonstrations or reward signals, and additional computational resources for training. These requirements can be restrictive when models are proprietary, interaction data is scarce, or computational budgets are limited.

An alternative direction involves train-free embodied adaptation, where procedural knowledge and improvements occur external to the model parameters. Prior work in agentic robotics has explored language models writing or revising robot programs and accumulating skills, often by generating executable code that interacts with robot-specific APIs. While powerful, this approach is contingent on the availability of such programmable interfaces, debugging tools, and execution monitors, which may not be present in all embodied environments with fixed or restricted action spaces.

This research addresses the gap in train-free adaptation for embodied agents operating through fixed action interfaces, focusing on improving the procedural guidance and context provided to a frozen (parameter-fixed) foundation model. It differentiates itself from prior work that modifies model parameters, focuses solely on skill evolution, or synthesizes code harnesses without co-optimizing reusable procedural guidance. The proposed SHAPER framework aims to systematically adapt embodied agents by evolving both their reusable skills and context-code harnesses, without altering the underlying model parameters.

### 2. Key Objectives and Motivation

The primary objective of this research is to develop a self-evolving framework for train-free embodied agent adaptation that operates without modifying the parameters of the underlying foundation model. The key motivations driving this objective are:

- **Addressing limitations of parameter-updating adaptation:** Existing methods like SFT and RL require access to model weights, extensive task-specific data (demonstrations or rewards), and significant computational resources for retraining. These prerequisites often limit adaptation in real-world scenarios where models are frozen, proprietary, data is scarce, or training is computationally expensive or undesirable.
- **Extending train-free adaptation beyond code-centric approaches:** While train-free methods that generate or repair executable code for robot APIs have shown promise, they rely on the availability of such programmable interfaces and debugging hooks. Many embodied environments, however, feature fixed or restricted low-level action interfaces that do not expose such functionalities. The research seeks a method that can adapt agents in these fixed-interface settings.
- **Optimizing model-external components:** The performance of embodied agents built around foundation models depends not only on the model weights but also on external, non-parametric components. These include reusable skills (procedural guidance like natural language instructions, action recipes, or recovery rules) and the context-code harness (which structures observations, prior actions, and feedback for the planner). The motivation is to explore whether systematic optimization of these external components can lead to performance improvements comparable to or exceeding parameter updates.
- **Reusing a frozen model for dual roles:** The research aims to demonstrate that a single, frozen Vision-Language Model (VLM) checkpoint can serve both as the agent's upper-level planner during environment interaction and as an artifact optimizer during the evolution process. This dual role eliminates the need for a separate optimization model and simplifies the adaptation pipeline.
- **Enabling self-evolution through target-environment rollouts:** The motivation is to create an adaptation mechanism where a small set of target-environment trajectories and outcomes can automatically drive revisions to the skills and context harness. This allows the agent system to iteratively improve its performance through self-reflection on its own experiences.

In essence, the paper seeks to demonstrate that skill-and-harness optimization offers a practical and competitive route to self-evolving embodied agents, particularly when model training is economically or technically prohibitive.

### 3. Methodology and Approach

The SHAPER framework proposes a train-free embodied adaptation strategy centered on the non-parametric optimization of reusable skills and a context-code harness, while keeping the underlying Vision-Language Model (VLM) planner and executor parameters frozen.

#### 3.1. Train-Free Agent Factorization

The methodology conceptualizes an embodied agent as comprising four components:
- **VLM Planner (Mθ):** The core neural model, with parameters θ, responsible for high-level reasoning and generating interface-level commands. This component's parameters remain frozen.
- **Executor (Aϕ):** A low-level component (e.g., a VLA actor or an environment action API wrapper) that translates the planner's commands into executed actions. Its parameters ϕ also remain frozen.
- **Reusable Skill (s):** Textual procedural guidance (e.g., natural language instructions, action recipes, failure recovery rules, task decomposition strategies) embedded in the planner's prompt. This is a non-parametric artifact to be optimized.
- **Context-Code Harness (h):** A programmable component (e.g., a Python function) that selects, formats, and organizes observations, prior actions, execution outcomes, and feedback to be presented to the planner. This is also a non-parametric artifact to be optimized.

The agent's operation at time *t* is defined as generating a planner response *y_t* conditioned on the task instruction *g*, current observation *o_t*, skill *s*, and the context *h* applied to the trajectory prefix *τ<t*. The executor *Aϕ* then maps *y_t* to an action *a_t*. The optimization objective is to find *s* and *h* that maximize the expected task-level reward *R* over rollouts in a target environment.

#### 3.2. Rollout-Guided Textual Diagnosis

SHAPER employs a hierarchical diagnostic process to convert environment rollouts into actionable textual feedback:
- **Round-Level Judger:** For each planner round (a sequence of actions generated from a single planner call), a "judger" (a frozen VLM prompted for diagnosis) analyzes the immediate before-and-after observations, the planner's response, and the executed action. It identifies localized issues such as incorrect subgoals, lack of progress, or executor mismatches, without processing the full visual trajectory.
- **Episode Summarizer:** After an episode, a separate "summarizer" (also a frozen VLM) aggregates the round-level critiques, non-visual metadata (commands, execution lengths, runtime errors), terminal harness context, and the final task outcome. This generates a compact, non-visual episode summary, *e_c(g)*.
- **Textual Gradient:** Summaries from a batch of training episodes, combined with aggregate execution statistics, form the "textual gradient," *Γ(c)*. This gradient exposes cross-round patterns such as unproductive repetition, instruction drift, missing progress tracking, harmful context, and parsing errors, providing concrete feedback for artifact optimization.

#### 3.3. Two-Stage Skill-Harness Evolution

The core optimization process unfolds in two stages:
- **Optimizer Role:** The same frozen foundation model used as the planner is re-prompted to act as an "artifact optimizer." Conditioned on the current skill *s*, harness *h*, textual gradient *Γ(c)*, and optimization history, it proposes new candidate artifacts *c' = (s', h')*.
- **Two-Stage Schedule:**
 1. **Skill Evolution:** Initially, the skill *s* is optimized while the seed harness *h_0* remains fixed. The optimizer proposes new skills *s'*.
 2. **Harness Evolution:** After a best skill *s*⋆ is selected, the harness *h* is optimized while *s*⋆ remains fixed. The optimizer proposes new harnesses *h'*.
- **Validation and Selection:**
 - **Sandboxing:** Generated harness code is subjected to a sandbox environment to ensure it defines the required context function, avoids unsafe operations (e.g., imports, file I/O, dynamic execution), and completes within a timeout. Invalid candidates are rejected, and their errors provide feedback to the optimizer.
 - **Validation Set Evaluation:** Valid candidates are evaluated on a fixed validation set (*D_val*) to estimate their performance (*J_val(c)*).
 - **Beam Search:** SHAPER maintains a beam *B_r* of top-performing candidates. In each round, new proposals are added to the beam, and the top-K candidates (based on validation performance) are retained for the next round.
- The final output is the highest-scoring candidate *(s⋆, h⋆)* found across all evolution rounds. This optimized pair replaces the initial skill and harness, enhancing the agent's behavior without any changes to the VLM planner or executor parameters.

### 4. Main Findings and Results

The SHAPER framework was evaluated on two distinct embodied environments: VLABench and ESI-Bench, which feature different low-level action interfaces.

#### 4.1. VLABench Results

VLABench is a language-conditioned manipulation benchmark focusing on implicit language understanding, common-sense reasoning, and long-horizon tasks. The evaluation used four custom held-out splits (C1-C4) varying target categories and task forms. The agent system used Qwen3.6-27B as the frozen planner and the official VLABench π0 checkpoint as the VLA actor executor.

- **Main Performance:**
 - The "Seed Agent" (frozen planner with initial skill/harness) achieved a 28.25% overall success rate, outperforming direct VLA execution (23.25%) and same-data Supervised Fine-Tuning (SFT) (24.00%) without any model parameter changes.
 - Full skill-harness evolution (SHAPER) further increased the success rate to 34.50%, representing a 6.25-point improvement over the Seed Agent and a 10.50-point improvement over SFT.
 - Test-time scaling baselines (MG-Select and VOTE) applied directly to the VLA actor or on top of the Seed Agent performed worse than or similar to the unscaled Seed Agent, suggesting that SHAPER's improvements are not due to additional inference-time sampling.

- **Generalization Across Shifts:**
 - SHAPER showed generalization capabilities under distribution shifts. On the in-domain C1 split, it improved by 2.5 points over the seed (42.5% vs 40.0%).
 - The gains were more pronounced under distribution shifts: +6.0 points for unseen targets (C2), +10.0 points for an unseen task form (C3), and +6.5 points when both were unseen (C4). The largest gain was observed when transferring to the Common Sense & World Knowledge task form (C3).

- **Artifact Ablations:**
 - Skill-only evolution resulted in a 33.50% success rate (+5.25 points over seed).
 - Harness-only evolution achieved 30.50% (+2.25 points over seed).
 - Full SHAPER (34.50%) combined these effects, with the evolved harness contributing an additional +1.00 point after skill evolution. The effects were not strictly additive across all splits, suggesting interaction between skill and harness optimization.

- **Actor-Aware Recovery (Case Study):** A VLABench case study demonstrated how an evolved skill improved an agent's ability to "Fetch the Landmark Cases in Property Law book." The seed skill led to repetitive, unproductive actions when the book was partially retrieved. The evolved skill, by explicitly incorporating actor-aware command adaptation, progress checks, and command changes upon detecting stagnation, enabled the agent to successfully complete the task in fewer environment steps.

#### 4.2. ESI-Bench Results

ESI-Bench evaluates embodied spatial intelligence, requiring agents to actively acquire visual evidence. The agent used the same Qwen3.6-27B planner, interacting through the benchmark's fixed action API.

- **Main Performance:**
 - Full SHAPER achieved 49.8% micro accuracy and 42.9% macro accuracy, significantly improving upon the Seed Agent's 32.5% micro and 31.2% macro accuracy. This represents a 17.3 micro-point and 11.7 macro-point gain.
 - Skill-only evolution (41.1% micro, 38.6% macro) also showed substantial improvement over the seed, with full SHAPER adding another 8.7 micro points and 4.3 macro points.
 - The macro score of SHAPER (42.9%) was numerically higher than the published GPT-5 Passive Single-view reference (40.3%), indicating competitive performance for a frozen 27B planner without parameter updates.

- **Category-Level Behavior:**
 - Skill Evolution improved 6 out of 10 categories over the seed.
 - Adding the evolved harness further improved categories like Specular Reflection (20.0% to 60.0%), Perceptual Grounding (59.2% to 69.4%), and Spatial Relations (37.3% to 54.9%). Some categories remained unchanged or saw slight decreases, which might be influenced by small sample counts.

- **Evidence-Aware Visual Memory (Case Study):** A reflection task in ESI-Bench illustrated the impact of harness evolution. The raw harness, based on recency, discarded early visual evidence of a reflected target jar. The evolved harness implemented a sparse, evidence-aware memory, retaining keyframes (like the initial reflection) and using deterministic crops and structured context to facilitate cross-view matching. This enabled the agent to correctly identify the reflected object with high confidence, whereas the seed harness led to unproductive exploration and failure.

#### 4.3. Optimization Efficiency

The acquisition of evolved artifacts is a one-time cost. The reported token usage for an entire evolution run was approximately $2.25 for VLABench and $2.83 for ESI-Bench (API-equivalent costs, excluding simulator/GPU infrastructure). This cost does not scale with deployment, unlike test-time scaling methods.

### 5. Significance and Potential Impact

The SHAPER framework presents a significant contribution to the field of embodied AI by demonstrating a viable and efficient method for adapting agents without modifying their core neural network parameters.

The significance and potential impact include:

- **Enabling Adaptation of Frozen Models:** SHAPER provides a practical solution for scenarios where access to model weights is restricted (e.g., proprietary foundation models), or where retraining is computationally prohibitive, data-scarce, or undesirable due to concerns about catastrophic forgetting or model stability. This democratizes the adaptation process for users who lack the resources or permissions for full model fine-tuning.
- **Cost-Effectiveness and Scalability:** The one-time, low API-equivalent cost for evolving skills and harnesses is a key advantage. Unlike methods that require continuous inference-time sampling or aggregation, SHAPER's adaptation cost does not scale with the number of deployments or evaluation episodes. This makes it a cost-efficient alternative for long-term agent operation and widespread deployment.
- **Enhanced Generalization:** The results on VLABench demonstrate that evolved artifacts can lead to improved generalization, particularly under distribution shifts (unseen target categories or task forms). This suggests that optimizing the agent's external components helps it better leverage the reasoning capabilities of the frozen foundation model across varied conditions.
- **Improved Interpretability and Controllability:** Modifying textual skills and Python-based context harnesses is potentially more interpretable and controllable than directly adjusting millions of neural network parameters. Developers can directly inspect, understand, and even manually refine the logic encapsulated in the skills and harnesses.
- **Addressing Fixed Action Interfaces:** By focusing on adapting agents that interact through fixed or restricted action interfaces (rather than programmable robot APIs), SHAPER broadens the applicability of train-free adaptation to a wider range of embodied environments and robotic platforms.
- **Foundational for Agent Systems:** This work reinforces the growing understanding that deployed embodied agents are complex systems, where model-external components are as crucial as the models themselves. It lays groundwork for future research into systematic engineering and optimization of these "scaffolds" for more robust and capable agents.

Future work includes cross-embodiment transfer and validation on real-robot systems, which would further establish the robustness and practical utility of skill-and-harness evolution in diverse physical contexts.
