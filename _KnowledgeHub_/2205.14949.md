# HiViT: Hierarchical Vision Transformer Meets Masked Image Modeling

> [!summary] Summary
> HiViT is a hierarchical Vision Transformer architecture designed for efficient Masked Image Modeling pre-training. It removes computationally intensive local operations in early stages, enabling a 1.9x speed-up over Swin Transformer during MIM while achieving 84.2% top-1 accuracy on ImageNet-1K.

## Problem

- Existing hierarchical Vision Transformers (ViTs) like Swin Transformer face computational inefficiencies when applied to Masked Image Modeling (MIM) due to complex structural operations.
- Their "local inter-unit operations" (e.g., shifting window attention, patch merging) prevent the efficient discarding of masked tokens, leading to higher computational costs during MIM pre-training.
- The challenge is to design a hierarchical ViT that retains the benefits of multi-resolution feature maps while enabling efficient MIM pre-training by addressing these computational bottlenecks.

## Method

- HiViT introduces a modified ==hierarchical Vision Transformer== architecture that minimizes or removes "local inter-unit operations," which are inefficient for ==Masked Image Modeling (MIM)== pre-training.
- Early stages of the network replace ==window attention== with simple MLP blocks and use linear merging operations for downsampling.
- The architecture consolidates stages, removing the fourth stage found in typical hierarchical ViTs and extending the third (main) stage to apply ==global attention== across tokens.

## Results

- HiViT-B achieves **83.8%** top-1 accuracy on ImageNet-1K in supervised learning and **84.2%** when pre-trained with MIM, outperforming ViT-B by **2.0%** and Swin-B by **0.3%**.
- It demonstrates a **1.9x speed-up** over Swin Transformer during Masked Image Modeling pre-training, indicating substantial computational savings without performance loss.
- HiViT shows strong transfer learning capabilities, achieving **51.2% APbox** and **44.2% APmask** on COCO for object detection and **51.2% mIoU** on ADE20K for semantic segmentation.

## Takeaways

> [!tip] Key Insights
> - Local inter-unit operations like window attention in hierarchical Vision Transformers create a computational bottleneck for efficient Masked Image Modeling (MIM).
> - These computationally intensive local operations can be replaced with simpler MLP blocks and linear merging operations without sacrificing performance, while significantly improving MIM pre-training efficiency.
> - The hierarchical structure itself is more important for performance than the specific local inter-unit operations, and consolidating network stages can improve both efficiency and accuracy.
