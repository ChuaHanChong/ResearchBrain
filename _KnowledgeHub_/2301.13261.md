# Emergence of Maps in the Memories of Blind Navigation Agents

> [!summary] Summary
> AI agents trained to navigate using only egomotion sensing spontaneously construct internal spatial representations of their environment. These "blind" agents achieved 95.1% success and 62.9% SPL, demonstrating memory utilization over long horizons (1,000 steps) and enabling behaviors like shortcut taking and allocentric map decoding with 32.5% IoU, significantly outperforming untrained baselines.

## Problem

- The mechanisms behind the strong navigation performance of "map-free" neural network models remain unclear.
- It is unknown if artificial intelligent agents can spontaneously develop internal spatial representations, or cognitive maps, solely through navigation training.
- Understanding if mapping is a fundamental strategy for navigation in intelligent embodied agents, akin to biological systems, needed further investigation under controlled conditions.

## Method

- Researchers trained "blind" AI agents in a simulated 3D environment using ==reinforcement learning== for a point-goal navigation task.
- Agents were restricted to only egomotion sensing (relative position and heading changes) and utilized a generic LSTM-based recurrent neural network.
- The experimental setup deliberately excluded explicit mapping modules, direct mapping supervision, or architectural biases for spatial representation.

## Results

- "Blind" agents achieved a **95.1%** success rate and **62.9%** SPL in novel environments, demonstrating comparable performance to sighted agents while surpassing a clairvoyant baseline.
- Memory utilization was critical, with performance gains observed up to 1,000 steps of temporal context, equivalent to remembering information over approximately 89 meters.
- Probes initialized with a trained agent's memory navigated significantly more efficiently (**85.0%** SPL vs. **62.9%** SPL for the original agent), taking shortcuts and exhibiting free space inference, and performed equally well on reverse paths.
- Trained agents' internal memory allowed an external decoder to predict allocentric occupancy maps with **32.5%** IoU, a notable improvement over untrained memory (**12.5%** IoU), and showed a selective "forgetting" of exploratory detours.

## Takeaways

> [!tip] Key Insights
> - Effective navigation is possible with only egomotion sensing, indicating that agents must rely on internal memory and representations.
> - The internal memory developed by trained agents encodes rich spatial information, enabling them to infer free space, take shortcuts, and navigate bidirectionally.
> - Challenging agents with limited sensory input (blindness) can compel the spontaneous emergence of decodable, allocentric spatial maps within generic recurrent neural network architectures.
