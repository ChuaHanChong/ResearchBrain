# RADIOv2.5: Improved Baselines for Agglomerative Vision Foundation Models

> [!summary] Summary
> RADIOv2.5 from NVIDIA Research establishes new baselines for agglomerative vision foundation models by addressing multi-resolution inconsistencies and computational inefficiencies, achieving state-of-the-art performance across dense visual tasks and Vision-Language Model benchmarks. It demonstrates improved robustness by eliminating resolution-dependent mode switching and enhances efficiency through novel token compression techniques.

## Problem

- Existing agglomerative vision foundation models exhibit "mode switching" behavior, where feature distributions change dramatically with input resolution, leading to inconsistent performance.
- Teacher models have varying activation magnitudes and feature distributions, causing unbalanced learning in multi-teacher distillation.
- High-resolution visual encoders produce excessive output tokens, which significantly bottleneck the efficiency and performance of Vision-Language Models due to quadratic attention complexity.

## Method

- Implemented a ==Multi-Resolution Training (MRT)== schedule, augmented with Mosaic Augmentation, allowing the student model to learn consistently from all teachers across multiple resolutions.
- Applied ==PCA-Hadamard Isotropic Standardization (PHI-S)== to balance teacher contributions by normalizing activation magnitudes and distributions, improving training stability.
- Integrated a ==token merging technique== inspired by ToMeSD, which uses bipartite soft matching to efficiently compress visual tokens while preserving essential information for Vision-Language Models.

## Results

- Multi-resolution training eliminated "mode switching," resulting in consistent accuracy across input resolutions, with specific improvements such as **+2.8** mIoU on ADE20k and **+3.4** average VLM score.
- Outperformed prior agglomerative models (e.g., SAM-CLIP, Theia, UNIC) on dense tasks, with RADIOv2.5-B exceeding DINOv2-g-reg's ADE20k performance despite being significantly smaller.
- Achieved state-of-the-art VLM performance, with configurations showing a **6.7-point** average VLM score increase by using SigLIP as a teacher and a **5.9-point** average increase from efficient token merging.

## Takeaways

> [!tip] Key Insights
> - Simultaneously training across multiple resolutions with adaptive teacher handling (like mosaic augmentation for SAM) effectively mitigates resolution-dependent "mode switching" and improves model robustness.
> - Properly balancing teacher contributions via methods like PHI-S is crucial for stable training and allows seemingly challenging teachers, like SAM, to become genuinely beneficial for diverse tasks.
> - Token merging strategies, when applied judiciously, can drastically reduce the token count from high-resolution vision encoders while retaining sufficient information for significant performance gains in Vision-Language Models.
