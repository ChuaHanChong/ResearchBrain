# Hierarchical Entity-centric Reinforcement Learning with Factored Subgoal Diffusion

> [!summary] Summary
> HECRL is a hierarchical entity-centric reinforcement learning framework that integrates unsupervised object-centric representations and a conditional diffusion model for subgoal generation, tailored for offline learning from pixel observations. It demonstrates over a 150% increase in success rate on long-horizon, multi-entity manipulation tasks like PPP-Cube Image compared to non-hierarchical baselines.

## Problem

- Long-horizon tasks with sparse rewards are challenging for standard RL, especially when combined with high-dimensional image observations.
- Environments with multiple interacting entities suffer from combinatorially complex state spaces, making learning and generalization difficult for existing offline Goal-Conditioned RL (GCRL) methods.
- Learning effectively from fixed, potentially suboptimal offline datasets requires robust and sample-efficient algorithms that avoid exploiting out-of-distribution actions.

## Method

- A modular, two-level ==hierarchical== framework is proposed, using pre-trained unsupervised Deep Latent Particles (DLPv2) to extract object-centric representations from raw pixel inputs.
- A low-level GCRL agent, based on EC-IQL and an Entity Interaction Transformer (EIT) architecture, executes actions to achieve immediate subgoals.
- A high-level entity-centric conditional diffusion model (Subgoal Diffuser) generates sparse, multi-modal intermediate subgoals, which are then filtered and selected using the low-level value function to ensure reachability and progress.

## Results

- HECRL consistently achieves state-of-the-art performance on image-based long-horizon multi-object manipulation tasks, exhibiting over a **150%** increase in success rate on the challenging PPP-Cube Image task compared to non-hierarchical baselines.
- The Subgoal Diffuser generates subgoals that modify significantly fewer entities (1.0-1.4 entities on average in state-based tasks) compared to AWR-based approaches (2.8-2.9 entities), providing simpler subtasks for the low-level policy.
- The framework demonstrates non-trivial zero-shot compositional generalization, successfully operating with an increased number of entities (e.g., trained on 3 cubes, tested on up to 6 cubes) and outperforming flat entity-centric baselines in these out-of-distribution scenarios.

## Takeaways

> [!tip] Key Insights
> - Combining hierarchical planning with explicit factored (entity-centric) representations and generative diffusion models effectively addresses the combinatorial complexity and long horizons in multi-object environments.
> - Conditional diffusion models are superior to deterministic regression for generating subgoals, as they can sample distinct, valid multi-modal subgoals that involve sparse entity modifications, rather than ambiguous averages.
> - Value-based filtering and selection of subgoals at test-time are crucial for guiding the high-level policy, ensuring that generated subgoals are reachable by the low-level agent and lead towards the ultimate goal.
