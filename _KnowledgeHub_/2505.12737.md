# Option-aware Temporally Abstracted Value for Offline Goal-Conditioned Reinforcement Learning

> [!summary] Summary
> The paper introduces Option-aware Temporally Abstracted (OTA) value learning, a method to improve value function estimation in hierarchical offline goal-conditioned reinforcement learning for long-horizon tasks. This approach achieves superior performance on benchmarks like OGBench, such as increasing success rates from 12% to 92% on HumanoidMaze-giant by providing more order-consistent value signals to high-level policies.

## Problem

- Offline Goal-Conditioned Reinforcement Learning (GCRL) struggles with long-horizon tasks, as accurately estimating value functions for distant goals from static datasets is challenging.
- Existing hierarchical offline GCRL methods, like HIQL, often fail on complex tasks because their high-level policies cannot reliably generate appropriate subgoals.
- The underlying value functions in these methods suffer from "order inconsistency," producing unreliable advantage estimates for long-horizon planning, which hinders high-level policy learning.

## Method

- Introduces Option-aware ==Temporally Abstracted== (OTA) value learning, which modifies the value function's temporal-difference (TD) update to be option-aware.
- The TD update considers an n-step transition (s,sΩ)(s, s_Ω)(s,sΩ), where sΩ is the state reached after executing nnn primitive actions, effectively contracting the effective planning horizon for value estimation.
- The discount factor (γ) is applied only once to the target value at the end of the n-step option, maintaining a stronger long-term signal compared to standard n-step TD learning.

## Results

- OTA significantly surpasses state-of-the-art hierarchical (HIQL) and non-hierarchical baselines on long-horizon OGBench tasks, for example, improving success rate on HumanoidMaze-giant from **12%** (HIQL) to **92%**.
- The method successfully learns more "order consistent" value functions, showing monotonic value increases along optimal trajectories for distant goals and achieving a higher order consistency ratio (rcr_crc).
- Experiments confirm that OTA's unique option-aware TD target is crucial for its performance, as neither standard n-step TD learning nor simply increasing the discount factor yielded comparable improvements.

## Takeaways

> [!tip] Key Insights
> - The primary bottleneck in hierarchical offline GCRL for long-horizon tasks is the high-level policy's failure to generate effective subgoals, not the low-level policy's execution ability.
> - This high-level policy failure is rooted in the "order inconsistency" of the value function, which provides unreliable advantage estimates for states far from the goal.
> - A specific design of temporal abstraction, where the discount is applied once per option rather than per step, is crucial for learning robust and order-consistent value functions over long horizons.

## Detailed Report

### 1. How This Work Fits into the Broader Research Landscape

This paper operates within the critical and rapidly evolving domain of **Offline Goal-Conditioned Reinforcement Learning (GCRL)**. Offline RL is a paradigm where agents learn optimal policies solely from pre-collected datasets, without any further interaction with the environment. This is highly desirable for real-world applications (e.g., robotics, healthcare) where online data collection is costly, unsafe, or impractical. GCRL specifically aims to train policies that can reach arbitrary specified goal states from given initial states, rather than optimizing for a single, fixed task.

A significant challenge in both offline RL and GCRL is **long-horizon tasks**, where reaching a goal requires a long sequence of actions. Traditional value-based methods often struggle in these scenarios due to the inherent difficulty of accurately estimating value functions for distant goals, leading to noisy and unreliable learning signals. This issue is compounded in offline settings where the agent cannot actively explore to refine its value estimates.

To address long-horizon challenges, **Hierarchical Reinforcement Learning (HRL)** methods have gained prominence. These approaches decompose complex tasks into simpler sub-tasks, often involving a high-level policy that sets subgoals and a low-level policy that executes primitive actions to reach those subgoals. The paper identifies Hierarchical Implicit Q-Learning (HIQL) as a state-of-the-art hierarchical method in offline GCRL, which learns value functions using Implicit Q-Learning (IQL) and extracts policies via Advantage-Weighted Regression (AWR).

Another relevant area is the **Option Framework**, which introduces "options" as temporally extended actions or sub-policies. Options allow agents to plan at a higher level of abstraction, enabling more efficient exploration and planning over longer time horizons. While the option framework has been foundational in online HRL, its direct application to improving value function learning in *offline* GCRL, particularly within hierarchical structures, has been less explored.

This work specifically fits into the landscape by:
- **Diagnosing a Key Bottleneck in HRL for Offline GCRL:** It identifies that the high-level policy's inability to generate appropriate subgoals, rather than the low-level policy's execution, is the primary failure point in HIQL for long-horizon tasks.
- **Pinpointing the Cause:** The root cause is attributed to the *order inconsistency* of the value function in long-horizon settings, where the advantage estimates become unreliable.
- **Introducing a Novel Value Learning Scheme:** It proposes a simple yet effective modification to value function learning—Option-aware Temporally Abstracted (OTA) value learning—that integrates temporal abstraction into the temporal-difference (TD) update process. This differentiates it from existing hierarchical methods by directly improving the value function's robustness to long horizons, rather than solely focusing on policy architecture or subgoal generation mechanisms.
- **Bridging Concepts:** It effectively bridges ideas from hierarchical RL (subgoals), offline RL (dataset learning), and temporal abstraction (options) to overcome a significant limitation in the field. By refining the value function using option-aware targets, OTA aims to unlock the full potential of hierarchical policies in complex, long-horizon offline GCRL problems.

### 2. Key Objectives and Motivation

The central objective of this research is to enhance the performance of offline goal-conditioned reinforcement learning (GCRL) methods, particularly in long-horizon tasks. The authors identify a critical limitation within existing state-of-the-art hierarchical methods, such as HIQL, and aim to address it by improving the underlying value function learning.

The key motivations and objectives are:

1. **Identify the Bottleneck in Hierarchical Offline GCRL for Long-Horizon Tasks:** Despite advancements, hierarchical offline GCRL still struggles with complex, long-horizon tasks. The first objective is to systematically pinpoint whether the failure lies in the low-level policy's ability to execute actions or the high-level policy's ability to generate meaningful subgoals. Through empirical analysis (using an "oracle" high-level policy), the authors motivate that the high-level policy is the primary bottleneck.

2. **Uncover the Root Cause of High-Level Policy Failure:** Following the identification of the high-level policy as the bottleneck, the next objective is to understand *why* it fails. The authors hypothesize that an inaccurate or noisy value function, which provides the learning signals (advantage estimates) for the high-level policy, is responsible. They specifically investigate the "order inconsistency" of the learned value function: whether the value estimates correctly reflect the relative distances to the goal over long temporal horizons. They observe that for large state-goal distances, the sign of the advantage estimate frequently becomes incorrect, severely hindering high-level policy learning.

3. **Propose a Robust Value Learning Scheme for Long Horizons:** Motivated by the observation that value functions perform well for short horizons, the core objective is to design a value function learning scheme that can produce clear and order-consistent advantage estimates even for distant goals. The proposed solution should mitigate the "noise" and "order inconsistency" seen in conventional value functions for long-horizon planning.

4. **Leverage Temporal Abstraction to Contract Effective Horizon Length:** The paper's specific objective for achieving robust value learning is to incorporate temporal abstraction into the temporal-difference (TD) learning process. By considering "options" (temporally extended sequences of actions) as the basic units for value updates, the aim is to effectively "contract" the planning horizon, making the value estimation problem more tractable for distant goals.

5. **Empirically Validate the Effectiveness of the Proposed Method:** The final objective is to experimentally demonstrate that the new "Option-aware Temporally Abstracted (OTA) value function" significantly improves the high-level policy's ability to generate subgoals, leading to superior overall performance on challenging, long-horizon tasks from realistic benchmarks like OGBench.

In essence, the research aims to make hierarchical offline GCRL more robust and scalable to real-world long-horizon challenges by fundamentally improving how value functions are learned to provide reliable signals for high-level decision-making.

### 3. Methodology and Approach

The paper's methodology builds upon Hierarchical Implicit Q-Learning (HIQL) and introduces a novel modification to its value function learning component.

#### 3.1. Preliminaries: HIQL Background

The research operates within the standard Offline GCRL framework, defined by a Markov Decision Process (MDP) with a goal space ($G$) identical to the state space ($S$). The objective is to learn a goal-conditioned policy $\pi(a|s,g)$ from an offline dataset $D$ of trajectories. A sparse reward function $r(s,g) = -1\{s \neq g\}$ is used, meaning the optimal value $|V^*(s,g)|$ corresponds to the discounted temporal distance to the goal.

HIQL employs a hierarchical policy structure:
- **High-level policy ($\pi_h$):** Predicts a $k$-step subgoal $s_{t+k}$ given the current state $s_t$ and final goal $g$.
- **Low-level policy ($\pi_l$):** Produces primitive actions $a_t$ to reach the subgoal $s_{t+k}$ from $s_t$.

Both policies are extracted using **Advantage-Weighted Regression (AWR)**, which weights samples by an exponentiated advantage term. The crucial aspect is that HIQL uses a *single, shared goal-conditioned value function $V(s,g)$* for both high-level ($V_h$) and low-level ($V_l$) advantages. This value function is learned using an IQL-based expectile loss:
$L(V) = E_{(s,s') \sim D, g \sim p(g)} [L_{\tau_2} (r(s, g) + \gamma \bar{V}(s', g) - V(s, g))]$, where $L_{\tau_2}$ is the expectile loss and $\bar{V}$ is a target network. The critical point here is the 1-step temporal difference (TD) update structure $r(s, g) + \gamma \bar{V}(s', g)$.

#### 3.2. Motivation and Bottleneck Analysis

The authors begin by analyzing HIQL's failures in long-horizon tasks.
1. **Bottleneck Identification:** They replace $\pi_h$ with an *oracle high-level policy* ($\pi_h^{\text{oracle}}$) that always provides optimal short-horizon subgoals. The resulting "HIQL$_{\text{OS}}$" variant achieves significantly higher success rates than standard HIQL (Figure 1). This strongly indicates that the **high-level policy's inability to generate appropriate subgoals** is the main bottleneck.
2. **Root Cause of High-Level Policy Failure:** They then investigate the value function $V_h$ used for high-level policy learning. By visualizing $V_h(s_t, g)$ along optimal trajectories and converting values to temporal distances $d_h(s_t, g)$, they observe a crucial problem: **order inconsistency**. While $V_h$ is accurate near the goal, its estimates become non-monotonic and erroneous when the state $s_t$ is far from the goal $g$ (Figure 2). This leads to incorrect signs in the high-level advantage estimate $A_h(s_t, s_{t+k}, g) = V_h(s_{t+k}, g) - V_h(s_t, g)$, causing improper subgoal regression and high-level policy failure.

#### 3.3. Proposed Solution: Option-aware Temporally Abstracted (OTA) Value

Motivated by the robustness of value estimates for short horizons, the authors propose a simple yet effective solution: **Option-aware Temporally Abstracted (OTA) value learning**.

The core idea is to leverage the concept of an **option** to reduce the effective horizon length in the value function's temporal-difference update. An option starting from state $s_t$ is defined as a sequence of $n$ primitive actions (or until the goal is reached) extracted from trajectories in the offline dataset. Let $s_\Omega$ be the state reached after executing such an option from $s_t$.

The value learning objective for the high-level policy, $V_h^{\text{OTA}}$, is reformulated to be option-aware:
$L(V_h^{\text{OTA}}, n) = E_{(s,s_\Omega) \sim D, g \sim p(g)} [L_{\tau_2} (r(s_\Omega, g) + \gamma \bar{V}_h^{\text{OTA}}(s_\Omega, g) - V_h^{\text{OTA}}(s, g))]$

Key aspects of this modification:
- **Temporal Abstraction:** Instead of a 1-step transition $(s, s')$, the value update now considers an $n$-step transition $(s, s_\Omega)$. This effectively "contracts" the planning horizon for the value function, as it is updated over sequences of $n$ primitive actions.
- **Reward at Option End:** The immediate reward $r(s_\Omega, g)$ is computed at the end of the option (i.e., when $s_\Omega$ is reached).
- **Target Value at Option End:** The target value $\bar{V}_h^{\text{OTA}}(s_\Omega, g)$ is also computed from the state $s_\Omega$.
- **Fixed Discount Factor:** Crucially, the discount factor $\gamma$ remains unchanged and is applied only once to the target value, regardless of the abstraction factor $n$. This differs from standard $n$-step TD learning, where the target would be discounted by $\gamma^n$, potentially leading to excessive decay. OTA's approach maintains a stronger long-term signal while still benefiting from the horizon contraction.

#### 3.4. Policy Learning with OTA

The high-level policy $\pi_h$ is then learned using AWR, but now utilizing the improved, order-consistent $V_h^{\text{OTA}}$ for its advantage term $A_h(s_t, s_{t+k}, g) = V_h^{\text{OTA}}(s_{t+k}, g) - V_h^{\text{OTA}}(s_t, g)$. The low-level policy learning remains similar to HIQL, often using the same value function (or a separate one, but the paper implies sharing $V_h^{\text{OTA}}$ based on the original HIQL design).

The framework, therefore, keeps the hierarchical policy structure of HIQL but fundamentally improves the quality of the value signals that guide the high-level policy, especially in long-horizon contexts. The abstraction factor $n$ is a new hyperparameter introduced by OTA, determining the degree of temporal abstraction.

### 4. Main Findings and Results

The paper presents compelling evidence for the effectiveness of the Option-aware Temporally Abstracted (OTA) value learning scheme.

1. **High-Level Policy as the Bottleneck (Figure 1):** Initial experiments rigorously demonstrate that in complex, long-horizon tasks (e.g., AntMaze, HumanoidMaze), HIQL's low success rates (often below 20%) are not due to the low-level policy's inability to reach short-horizon subgoals. When the high-level policy is replaced by an oracle ($\text{HIQL}_{\text{OS}}$), success rates jump significantly (e.g., to ~90%). This confirms that the *high-level policy's failure to generate appropriate subgoals* is the primary bottleneck.

2. **Order Inconsistency of HIQL's Value Function (Figure 2):** A detailed analysis of HIQL's learned high-level value function ($V_h$) reveals that while it performs well for states near the goal, it becomes highly inaccurate and exhibits "order inconsistency" as the distance between the state and goal increases. Specifically, the conversion of $V_h$ to temporal distances ($d_h$) shows non-monotonic behavior, implying that the sign of the advantage estimate $A_h$ can frequently be incorrect for long horizons. This explains why the high-level policy struggles to learn effectively.

3. **Superior Performance on OGBench (Figure 4, Table 6):** OTA achieves substantial performance improvements over all baselines on challenging tasks from OGBench, a comprehensive offline GCRL benchmark.
 - It consistently outperforms non-hierarchical methods (GCBC, GCIVL, GCIQL, QRL, CRL), which largely fail on long-horizon tasks.
 - Crucially, OTA significantly surpasses HIQL, the state-of-the-art hierarchical baseline. The performance gap widens notably with increasing maze size and task complexity (e.g., HumanoidMaze-giant, where HIQL achieves 12% and OTA achieves 92%).
 - This superior performance extends to high-dimensional visual robotic manipulation tasks (Visual-cube, Visual-scene), demonstrating its applicability beyond state-based maze environments.

4. **Improved Value Order Consistency with OTA (Figure 5):** The core hypothesis—that OTA improves value function quality—is empirically validated. Visualizations of $V_h^{\text{OTA}}$ along optimal trajectories show a much more monotonic increase compared to HIQL's $V_h$, even for large state-goal distances. Quantitatively, OTA yields a higher "order consistency ratio" ($r_c$) across all analyzed tasks, confirming that its value estimates provide more reliable directional signals for high-level advantage estimation.

5. **Effect of Abstraction Factor 'n' (Figure 6):** Experiments varying the abstraction factor $n$ demonstrate that:
 - $n=1$ (equivalent to HIQL's 1-step TD) leads to poor value learning for long horizons.
 - Increasing $n$ generally improves the value function's suitability for long horizons and increases the order consistency ratio $r_c$.
 - However, excessively large $n$ can lead to a drop in $r_c$, suggesting a balance is needed to avoid information loss due to over-abstraction.

6. **Distinction from Standard N-step TD and Increased Discount Factor (Table 1):** The authors confirm that OTA's efficacy is not merely a consequence of using an n-step lookahead or an increased discount factor.
 - Implementing standard n-step TD learning (with the original $\gamma$) in HIQL shows almost no improvement in success rate or $r_c$.
 - Similarly, increasing the discount factor to $\gamma^{1/n}$ (to mimic a slower decay over $n$ steps) also fails to outperform standard HIQL.
 - These results highlight that the *specific design of OTA's option-aware target*, where $\gamma$ is applied once at the end of the option (regardless of $n$), is crucial for achieving robust, order-consistent value estimates.

7. **Scalability Comparison to Quasimetric RL (Table 2):** OTA, which uses a TD-based IQL loss, demonstrates better scalability to high-dimensional state spaces (e.g., HumanoidMaze, Visual-scene) compared to Quasimetric RL (QRL). QRL, relying on min-max optimization, struggles to achieve comparable success rates in these complex environments, underscoring the practical advantages of OTA's TD-based approach.

In summary, the main findings robustly confirm that OTA effectively addresses the value order inconsistency problem in long-horizon offline GCRL, leading to a significantly improved ability for high-level policies to generate subgoals and achieve complex tasks.

### 5. Significance and Potential Impact

The research presented in this paper holds significant implications for the field of reinforcement learning and its real-world applications.

1. **Advancement in Offline GCRL for Long-Horizon Tasks:** Offline Goal-Conditioned Reinforcement Learning (GCRL) is crucial for practical applications where active environment interaction is infeasible. However, long-horizon tasks have remained a major bottleneck. OTA provides a substantial step forward by enabling hierarchical policies to tackle these tasks with high success rates, as demonstrated on challenging benchmarks like OGBench. This directly expands the scope of problems that can be addressed by offline RL.

2. **Clear Diagnosis of a Fundamental Problem:** The paper's rigorous analysis identifying the high-level policy and, specifically, the *order inconsistency* of the value function as the root cause of failure in hierarchical offline GCRL is a significant contribution. This diagnostic insight provides a clear direction for future research, moving beyond architectural complexities to address the core problem of reliable value estimation over extended horizons.

3. **Simplicity and Effectiveness of the Solution:** The proposed OTA method is described as "simple yet effective." By modifying only the value function's temporal-difference target to be "option-aware," OTA achieves remarkable performance gains without introducing complex new architectures or training paradigms. This simplicity makes it easier to implement, integrate into existing frameworks, and potentially generalize to other value-based offline RL algorithms.

4. **Improved Generalization and Robustness:** Learning an order-consistent value function that accurately reflects discounted temporal distances to the goal, even for distant states, enhances the generalization capabilities of the high-level policy. Such policies are more robust in varying environments and can navigate complex state spaces more reliably.

5. **Practical Impact on Robotics and Autonomous Systems:** The demonstrated success on visual robotic manipulation and complex maze navigation tasks has direct implications for real-world robotics. Systems can potentially learn complex, long-horizon skills from pre-recorded human demonstrations or prior failed attempts, reducing the need for extensive and costly online training. This could accelerate the deployment of intelligent autonomous agents.

6. **Insights into Temporal Abstraction:** The work highlights the critical role of temporal abstraction, specifically through the option framework, in making value function learning tractable for long horizons. The clear distinction between OTA's approach and standard n-step TD learning or simply adjusting the discount factor offers valuable insights into how temporal abstraction should be integrated into value-based methods. This could inspire new research into tailored temporal abstraction mechanisms for different RL challenges.

7. **Foundation for Future Work:** OTA opens several avenues for future research, including:
 - Developing adaptive mechanisms for selecting the optimal abstraction factor $n$.
 - Exploring theoretical guarantees for the order consistency of OTA's value function.
 - Applying the option-aware value learning concept to other types of offline RL algorithms or to online settings where long-horizon planning remains a challenge.
 - Investigating its synergy with other goal-conditioned learning techniques.

In conclusion, "Option-aware Temporally Abstracted Value for Offline Goal-Conditioned Reinforcement Learning" offers a principled, effective, and impactful solution to a long-standing challenge in modern reinforcement learning, with significant potential to accelerate the development of capable AI systems in complex real-world environments.
