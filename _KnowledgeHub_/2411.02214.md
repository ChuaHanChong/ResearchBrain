# DexHub and DART: Towards Internet Scale Robot Data Collection

> [!summary] Summary
> Researchers at MIT's Improbable AI Lab developed DART (Dexterous Augmented Reality Teleoperation) and DexHub, an integrated system that uses AR for low-latency teleoperation of virtual robots in cloud simulation and a public data hub, to enable internet-scale robot data collection. This approach achieved 2.1 times faster data collection than real-world methods and generated policies that exhibited greater robustness and zero-shot Sim2Real transfer in diverse environments.

## Problem

- The development of generalist robotic systems is limited by the scarcity of diverse and high-quality data.
- Current robot data collection methods are labor-intensive, suffer from scalability issues, and primarily focus on single-arm robots with narrow scope.
- Existing simulation-based teleoperation systems often face challenges with latency, visual fidelity, and lack intuitive interfaces for large-scale data generation.

## Method

- DART (==Dexterous Augmented Reality Teleoperation==) provides an AR-based platform for controlling robots in cloud-hosted MuJoCo simulations, leveraging local rendering on AR devices (e.g., Apple Vision Pro) and low-latency gRPC communication for hand tracking and simulation state.
- DexHub (Robot Data Hub on Cloud) serves as a continuously growing, open-sourced cloud repository for robot learning data, offering APIs for both contributing and retrieving collected robot interactions.
- The system supports various robots and allows users to import custom scenes, features one-click resets, and enables instant task switching to improve operator efficiency and reduce fatigue.

## Results

- DART achieved **2.1** times faster data collection throughput in user studies compared to real-world teleoperation setups, completing tasks like bolt and nut sorting at **7.8** parts/minute versus **3.6** parts/minute for real systems.
- Policies trained with DART-collected simulation data showed zero-shot Sim2Real transfer and significantly higher success rates in challenging real-world scenarios; for example, achieving **60%** success with background changes (vs. **10%** for real-world policies) and **70%** with unseen distractions (vs. **0%**).
- User feedback indicated DART was more enjoyable, less fatiguing, and offered better visual observation, with intuitive hand tracking being sufficient and preferred over heavier kinematic teacher devices.

## Takeaways

> [!tip] Key Insights
> - AR-driven teleoperation in cloud simulation significantly increases data collection throughput and reduces operator physical and cognitive fatigue compared to real-world teleoperation.
> - Low-latency communication of hand-tracking data and simulation states, combined with local AR rendering, overcomes the visual latency issues common in streamed simulation environments.
> - Policies trained on aggressively augmented simulation data from DART demonstrate superior robustness and zero-shot Sim2Real transfer compared to policies trained on real-world data, even in novel and challenging environments.
