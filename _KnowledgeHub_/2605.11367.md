# 3D-Belief: Embodied Belief Inference via Generative 3D World Modeling

> [!summary] Summary
> Researchers at Johns Hopkins University developed 3D-Belief, a generative 3D world model that infers and updates explicit, uncertainty-aware, and semantically grounded 3D beliefs from partial observations. This model, leveraging 3D Gaussian Splatting within a diffusion framework, significantly improves 3D object and room completion, and achieves higher success rates in open-vocabulary object navigation tasks in both simulated and real-world environments.

## Problem

- Existing visual generative models primarily operate in 2D pixel space, lacking explicit 3D representations and uncertainty modeling required for embodied agents in 3D environments.
- Embodied agents struggle to maintain spatially consistent scene memory, reason about unobserved regions, and sequentially update their understanding of the 3D world under partial observability.
- Current generative world models often produce single, deterministic predictions, which are insufficient for robust decision-making when inherent uncertainty about unseen regions exists.

## Method

- The **3D-Belief** model formulates world modeling as embodied belief inference in 3D space, using 3D ==Gaussian Splatting== (3DGS) as its core explicit 3D scene representation.
- It employs a ==diffusion model== framework that applies noise and denoises directly to the 3D scene representation (Gaussian primitives), promoting global geometry modeling and multi-view consistency.
- The architecture integrates a U-ViT backbone with an MVS-style 3DGS predictor for geometric consistency and a CLIP-distilled semantic head for open-vocabulary semantic predictions of 3D regions.

## Results

- 3D-Belief achieved superior 2D visual quality, outperforming baselines in both scene memory (e.g., PSNR 28.81 in AI2-THOR) and scene imagination (e.g., FID 47.24 in AI2-THOR).
- It consistently surpassed baselines on the new 3D-CORE benchmark for 3D object and room completion, demonstrating improved geometry, semantics (e.g., BEV IoU of 0.484 for object completion at **55%** visibility), and long-horizon consistency (e.g., LPIPS 0.123 for object permanence).
- The model significantly enhanced open-vocabulary object navigation performance, achieving higher success rates (**59.17%** in simulation, **55.56%** in real-world) and efficiency compared to reconstruction, 2D imagination, and VLM-based baselines.

## Takeaways

> [!tip] Key Insights
> - Explicit 3D scene representations, such as 3D Gaussian Splatting, provide a strong prior for cross-view consistency and reduce drift compared to 2D-only generative models, improving performance in embodied tasks.
> - Modeling uncertainty through multi-hypothesis belief sampling is crucial for robust planning in partially observable environments, leading to improved task success.
> - Directly integrating open-vocabulary semantic information into the 3D belief state allows for efficient, task-relevant reasoning without continuous reliance on external Large Vision-Language Models during inference.
